Name (Table)

This property identifies the Table.

Syntax

None

Parameters

None

Return Values

Returns a String value that specifies a name of the Table.

Remarks

The default value of the Name property is a zero-length string ("").

Field names cannot be longer than 64 characters.

The Name property is read/write on Column, Group, Key, Index, Table, and User objects. This Name property is read-only on Catalog, Procedure, and View objects.

Example

The following code demonstrates how to use the Name property with a Table.

    objCat.Create strConn
    Set objTable = CreateObject("adoxce.table.3.1")
    Set objCol = CreateObject("adoxce.column.3.1")

    objCol.Name = "myColumn"
    objCol.Type = 3

    objTable.Name = strTempTableName
    objTable.Columns.Append objCol
    objTable.Columns.Append objCol
    objCat.Tables.Append objTable
