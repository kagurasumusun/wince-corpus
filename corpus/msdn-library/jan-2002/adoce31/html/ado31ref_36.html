Precision

This property returns the total number of digits defined in a field.

Syntax

None

Parameters

None

Return Values

Returns a Byte value.

Remarks

The Precision property is read-only for Column objects already appended to a collection. This property returns the total number of defined digits in a field.

The default value for this property is zero (0). The Precision property must be greater than zero.

Example

This example demonstrates how to use the Precision property with a Column.

    'Create myTable
    table.Name = "myTable"
    table.Columns.Append "col1", adNumeric
    table.Columns("col1").Precision = 28
    table.Columns("col1").NumericScale = 10
    cat.Tables.Append table
