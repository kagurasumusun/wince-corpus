Mode

This property describes the permissions for modifying data for the current connection.

connection.Mode

Constants

The following table shows the constants available to the Mode property.

Constant Value Description
adModeUnknown 0 Specifies that the permissions have not yet been set or cannot be determined
adModeRead 1 Specifies read-only permissions
adModeWrite 2 Specifies write-only permissions
adModeReadWrite 3 Specifies read/write permissions
adModeShareDenyRead 4 Prevents others from opening a connection with read permissions
adModeShareDenyWrite 8 Prevents others from opening a connection with write permissions
adModeShareExclusive 12 Prevents others from opening a connection
adModeShareDenyNone 16 Allows others to open a connection with any permissions, and restricts others from denying read/write access to anyone

Return Values

The Mode property returns a Long value.

Remarks

The default value for the Mode property is adModeUnknown. The Mode property is a Long value.

When used with the proprietary Windows CE data source, the Mode property always returns the constant asModeReadWrite.
