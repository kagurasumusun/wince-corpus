Description

This property returns a string from the data source provider that describes an error.

error.Description

Return Values

The return value of this property is a string.

Remarks

This property is read-only.

The data source provider sets the Description property. This property is supported by both the proprietary Windows CE data source and third-party OLE DB data source providers.
