Source (Recordset)

This property specifies the source for the data in a recordset, either an SQL statement or table name.

var = recordset.Source

Return Values

This property returns a string value.

Remarks

Use the Source property to specify a data source for a Recordset object.

The default value of the Source property is a zero-length string ("").

This property is read/write until the Open method is called. After the Open method has been called, this property remains read-only until the Close method is called successfully.
