MoveNext

This method moves the active row pointer to the next row

recordset.MoveNext

Parameters

None.

Return Values

None.

Remarks

Use the MoveNext method to move the current record position one record forward, toward the bottom of the recordset. If the last record is the current record and you call the MoveNext method, ADOCE sets the current record to the position after the last record in the Recordset object, and EOF is TRUE. An attempt to move forward when the EOF property is already TRUE generates an error.
