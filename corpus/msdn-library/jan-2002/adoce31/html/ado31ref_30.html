Name (Index)

This property identifies the Index.

Syntax

None

Parameters

None

Return Values

Returns a String value that specifies a name of the Index.

Remarks

The default value of the Name property is a zero-length string ("").

Field names cannot be longer than 64 characters.

The Name property is read/write on Column, Group, Key, Index, Table, and User objects. This Name property is read-only on Catalog, Procedure, and View objects.

Example

The following code demonstrates how to use the Name property with an Index.

    idx.Name = "Index1"
    idx.PrimaryKey = False
    idx.Columns.Append stColumnName
