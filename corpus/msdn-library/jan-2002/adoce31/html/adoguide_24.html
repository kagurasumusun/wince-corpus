SQL and ADOCE

The ADOCE control provides an ADO-compatible interface to an underlying database engine using a simple subset of Structured Query Language (SQL). Using SQL commands with ADOCE provides a simple object model while exposing the features of the underlying database engine. The following topics discuss using SQL with ADOCE.
