Key Object

This object represents a primary, foreign, or unique key field from a database table.

The following tables show the properties and collections that the Key object supports.

Property or Collection Description
Name Identifies the name of the Key
Type Indicates the data type of the Key; primary, foreign, or unique
RelatedTable Indicates the name of the related table
DeleteRule Indicates the action performed when a primary Key is deleted
UpdateRule Indicates the action performed when a primary Key is updated

Collection Description
Columns Contains all Column objects of the Key

Parameters

None

Return Values

None

Remarks

None

Example

The following code demonstrates how to create a Key object.

Dim objCat, objTable, objKey, strConn

    Set objCat = CreateObject("adoxce.catalog.3.1")
    objCat.Create strConn

    Set objTable = CreateObject("adoxce.table.3.1")
    objTable.Create
    Set key = CreateObject("adoxce.key.3.1")

    strConn="Provider=Microsoft.SQLSERVER.OLEDB.CE.1.0;Data Source=d:\adoce\ssce\test\test.mdb"

    'Create myTable
    table.Name = "myTable"
    table.Columns.Append "col1", adNumeric
    table.Columns("col1").Precision = 28
    table.Columns("col1").NumericScale = 10
    cat.Tables.Append table

    'Create myKey
    key.Name = "myKey"
    key.Type = adKeyUnique
    key.Columns.Append "col1"
    cat.Tables("myTable").Keys.Append key

    'List keys
    MsgBox ("Number of keys: " & cat.Tables("myTable").Keys.Count)
    For i = 0 To cat.Tables("myTable").Keys.Count - 1
