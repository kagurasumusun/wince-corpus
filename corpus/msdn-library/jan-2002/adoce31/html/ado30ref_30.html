Requery

This method refreshes the entire contents of the recordset from the data source.

recordset.Requery

Parameters

None.

Return Values

None.

Remarks

Calling the Requery method is equivalent to calling the Close and Open methods in succession.

The Requery method refreshes the current cursor. If you want to change the cursor's definition, you have to close the recordset, and then open a recordset with new cursor properties.
