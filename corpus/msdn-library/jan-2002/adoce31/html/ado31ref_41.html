Type (Column)

This property specifies the data type of a Column object.

Syntax

None

Constants

Sets or returns a Long value that is one of the following constants:

Constant Description
adTinyInt Exact numeric value, precision 3 scale 0. Refer to the OLE DB Programmer's Reference for more details on this type.
adSmallInt Exact numeric value, precision 5 scale 0. Refer to the OLE DB Programmer's Reference for more details on this type.
adInteger Exact numeric value, precision 10 scale 0. Refer to the OLE DB Programmer's Reference for more details on this type.
adBigInt Exact numeric value, precision 19 scale 0. Refer to the OLE DB Programmer's Reference for more details on this type.
adUnsignedTinyInt Unsigned version of adTinyInt
adUnsignedSmallInt Unsigned version of adSmallInt
adUnsignedInt Unsigned version of adInteger
adUnsignedBigInt Unsigned version of adBigInt
adSingle Single precision floating point number
adDouble Double precision floating point number
adCurrency Currency type. Refer to the OLE DB Programmer's Reference for more details on this type.
adDecimal Variant decimal type. Refer to the OLE DB Programmer's Reference for more details on this type.
adNumeric Numeric type. Refer to the OLE DB Programmer's Reference for more details on this type.
adBoolean Variant Boolean type. 0 is false and ~0 is true
adUserDefined User-defined data type of variable length. Refer to the OLE DB Programmer's Reference for more details on this type.
adVariant Automation Variant. Refer to the OLE DB Programmer's Reference for more details on this type.
adGuid Globally Unique Identifier. Refer to the OLE DB Programmer's Reference for more details on this type.
adDate Automation date. Refer to the OLE DB Programmer's Reference for more details on this type.
adDBDate Database date data structure. Refer to the OLE DB Programmer's Reference for more details on this type.
adDBTime Database time data structure. Refer to the OLE DB Programmer's Reference for more details on this type.
adDBTimestamp Database timestamp structure. Refer to the OLE DB Programmer's Reference for more details on this type.
adBSTR Pointer to a BSTR. Refer to the OLE DB Programmer's Reference for more details on this type.
adChar Fixed-length character string
adVarChar Variable-length character string
adLongVarChar Long variable-length character string
adWChar Wide fixed-length character string
adVarWChar Wide variable-length character string
adLongVarWChar Long, wide variable-length character string
adBinary Fixed-length binary data
adVarBinary Variable-length binary data
adLongVarBinary Long variable-length binary data

Parameters

None

Return Values

None

Remarks

The default value is adVarWChar.

This property is read/write until the Column object is appended to a collection or to another object, after which it is read-only.

Examples

This example demonstrates how to use the Type (Column) property.

Dim cat, tbl, col, stTableName, strConn

    Set cat = CreateObject("adoxce.catalog.3.1")
    Set col = CreateObject("adoxce.column.3.1")
    Set tbl = CreateObject("adoxce.table.3.1")

    strConn = "Provider=SQLOLEDB;Data Source=DATBTEST;Initial Catalog=TEST;User Id=sa;Password=;"

    col.Name = "col1"
    tbl.Name = "temp_table"
    tbl.Columns.append col

    cat.activeconnection = strConn
    If adox_ExistsTable(cat, tbl.Name) Then
        cat.tables.Delete tbl.Name
    End If

    cat.tables.append tbl
    Debug.Print cat.tables(tbl.Name).Columns("col1").Type

End Sub
