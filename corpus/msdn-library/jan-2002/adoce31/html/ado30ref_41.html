Attributes (Field)

This property returns a value that specifies one or more characteristics of a Field object. 

var = field.Attributes

Constants

The following table shows the constants that are used with the Attributes property.

Constant Value Description
adFldMayDefer 2 The field value is deferred. The field values are not retrieved from the data source with the entire record, only when a field is accessed explicitly.
adFldUpdatable 4 The field can be written.
AdFldUnknownUpdatable 8 The provider cannot determine if you can write to the field.
adFldFixed 16 The field contains fixed-length data. This is set for all data types except adVarWChar, adLongVarWChar, adVarbinary, and adLongVarbinary.
adFldIsNullable 32 The field accepts NULL.
adFldMayBeNull 64 NULL can be read from the field.
adFldLong 128 The field is a Long binary field or that you can use the AppendChunk and GetChunk methods.
adFldRowID 256 The field contains a record identifier, such as record number, unique identifier, and so on.

Return Values

This property returns an Integer value

Remarks

For a Field object, the return value specifies characteristics of the field and can be a sum of one or more of the values.

ADOCE never returns the values adFldRowVersion and adFldCacheDeferred.

This property is read-only.

Examples

The following code example shows how to set the constants for the Attributes property.

Const adFldMayDefer = 2
Const adFldUpdatable = 4
Const adFldUnknownUpdatable = 8
Const adFldFixed = 16
Const adFldIsNullable = 32
Const adFldMayBeNull = 64
Const adFldLong = 128
Const adFldRowID = 256

The following code example shows how to display field attributes using the Attributes property.

Dim rs, n
Set rs = CreateObject ("ADOCE.Recordset.3.1")
rs.Open "myTable"
For n = 0 to rs.Fields.Count -1
     MsgBox rs.Fields(n).Attributes
Next
