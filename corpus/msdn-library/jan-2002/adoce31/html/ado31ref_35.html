ParentCatalog (Table)

Specifies the parent catalog of a table or column to provide access to provider-specific properties.

Syntax

None

Parameters

None

Return Values

Sets and returns a Catalog object. Setting ParentCatalog to an open Catalog allows access to provider-specific properties prior to appending a table or column to a Catalog collection.

Remarks

Some data providers allow provider-specific property values to be written only at creation (when a table or column is appended to its Catalog collection). To access these properties before appending these objects to a Catalog, specify the Catalog in the ParentCatalog property first.

An error occurs when the table or column is appended to a different Catalog than the ParentCatalog.

Examples

The following code demonstrates how to append a table.

Dim objCat, objTable1, objTable2, objCol1, objCol2, strConn
    strConn = "Provider=Microsoft.SQLSERVER.OLEDB.CE.1.0; Data Source=c:\temp\SSCETest.db;"

    Set objCat = CreateObject("adoxce.catalog.3.1")

    Set objTable1 = CreateObject("adoxce.table.3.1")
    Set objTable2 = CreateObject("adoxce.table.3.1")

    Set objCol1 = CreateObject("adoxce.column.3.1")
    Set objCol2 = CreateObject("adoxce.column.3.1")

    If Dir("c:\temp\SSCETest.db") <> "" Then Kill ("c:\temp\SSCETest.db")
    objCat.Create strConn

    'Create table01
    objTable1.Name = "table01"
    objCol1.Name = "column01"
    objCol1.Type = 2
    objTable1.Columns.Append objCol1

    'Create table02
    objTable2.Name = "table02"
    objCol2.Name = "column02"
    objCol2.Type = 2
    objTable2.Columns.Append objCol2

    Set objTable1.ParentCatalog = objCat
    Set objCat = Nothing

    objTable1.ParentCatalog.Tables.Append objTable1
    objTable1.ParentCatalog.Tables.Append objTable2

    Set objTable1 = Nothing
    Set objTable2 = Nothing

    Set objCol1 = Nothing
    Set objCol2 = Nothing

    MsgBox "Done..."
End Sub
