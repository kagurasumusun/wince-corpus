DefinedSize

This property determines the data capacity of a Field object and returns the defined size of the field in characters.

Syntax

None

Parameters

None

Return Values

Returns a number that specifies the maximum length of the field.

Remarks

The proprietary Windows CE data source supports two string types: strings with less than 256 characters, and memo strings of up to 32,733 Unicode characters. These lengths are set when the table is created and are enforced when setting data. For strings with less than 256 characters, DefinedSize returns the length specified when the table was created. For text fields that have an undefined length, DefinedSize returns the maximum number of characters the field can hold, which is 32,733 Unicode characters.

See the provider-specific documentation for information regarding the use of the DefinedSize property with OLE DB provider data sources.

Example

This example demonstrates the DefinedSize property of a Column.

    col.Type = 202 'which is adVarWChar
    col.Name = "fld"
    col.DefinedSize = 101

    tbl.Name = "TempTableName01"
    tbl.Columns.Append col
