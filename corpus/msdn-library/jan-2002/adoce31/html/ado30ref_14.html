Close (Connection)

This method closes an active connection and physically closes the channel of communication.

Connection.Close

Parameters

None.

Return Values

None.

Remarks

The Close method closes the connection. The data source provider frees the resources associated with the connection when the Close method is called. After a connection is closed, calling a method that requires an open connection returns an error from the data source.

Use the Open method to reestablish the connection to the data source.

This method works with all data sources.

Examples

The following code example shows how to use the Close method to close a connection.

Dim cn
Set cn = CreateObject("ADOCE.Connection.3.1")
cn.Open "myDatabase.cdb"
'Insert code here to open a table and manipulate data.

'The following lines close the connection and
'release the object reference from the variable.
cn.Close
Set cn = Nothing
