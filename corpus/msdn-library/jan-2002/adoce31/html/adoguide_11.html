Connecting to a Data Source

Before you can manipulate information in a database, you must open a connection to a valid data source. The Connection object is used to represent a connection to a data source. Multiple connections can be made to a single data source or many data sources. Each individual connection to a data source is represented by a single connection object. The ADOCE control can connect to the proprietary Windows CE data source and to OLE DB provider data sources. To open a connection to a data source, create a variable that represents the connection and then create an ADOCE Connection object using the Set statement and CreateObject function. The following code sample shows how to do this.

Dim connDatabase
Set connDatabase = CreateObject(“ADOCE.Connection.3.1”)

When using the CreateObject function to create a reference to the ADOCE version 3.1 control, you must include the version number. If the version number is omitted from the string, an earlier version of the control is used. If no earlier version of the control exists on the device, an error is returned.

Once a Connection object is created, you can use the properties and methods of the Connection object to open, close, and manipulate a connection. The following code shows how to open a connection to a database on the device using the Open method.

connDatabase.ConnectionString = “data source = \MyDatabase.cdb”
connDatabase.Open

In this code sample, the connection string property is set before the Open method is executed. The Open method is used without any parameters. A connection string can also be used as a parameter of the Open method. When connecting to the proprietary Windows CE data source, specify the name of the database file (*.cdb) and the pathway to the file in the ConnectionString property.

To connect to an OLE DB provider data source, use the open method and the necessary parameters to connect to the data source. For details on the parameters, check the documentation provided by your OLE DB provider.

After you have made and saved your modifications to the database, close the connection to the data source. The following code example shows how to use the Close method to close a connection.

connDatabase.Close
Set connDatabase = Nothing
'Removes the reference to the connection object
