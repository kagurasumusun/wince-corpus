Property Object

This object represents a dynamic characteristic of an ADOCE object that is defined by the provider.

The following table shows the four built-in properties of the Property object.

Property Description
Name Indicates the identity of the Property
Type Indicates an integer that specifies the property data type
Value_ Indicates a variant that contains the property setting
Attributes Indicates characteristics of the property specific to the provider (Long value)

Parameters

None

Return Values

None

Remarks

ADOCE objects have two types of properties: built-in and dynamic.

Built-in properties are implemented in ADOCE and are immediately available to any new object, using the MyObject.Property syntax. They do not appear as Property objects in an object's Properties collection, so although you can change their values, you cannot modify their characteristics.

Dynamic properties are defined by the underlying data provider, and appear in the Properties collection for the appropriate ADOCE object. For example, a property specific to the provider may indicate if a Recordset object supports transactions or updating. These additional properties will appear as Property objects in that Recordset object's Properties collection. Dynamic properties can be referenced only through the collection, using the MyObject.Properties(0) or MyObject.Properties("Name") syntax.

You cannot delete either kind of property.
