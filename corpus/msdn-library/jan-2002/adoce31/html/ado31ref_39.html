RelatedTable

This property indicates the name of the related table.

Syntax

None

Parameters

None

Return Values

Sets and returns a String value.

Remarks

The default value is an empty string ("").

If the key is a foreign key, then RelatedTable is the name of the table that contains the key.

Examples

This example demonstrates how to use the RelatedTable property.

    Set tbl = CreateObject("adoxce.table.3.1")
    Set m_cat.ActiveConnection = m_cnn

    Set col = CreateObject("adoxce.column.3.1")
    col.Name = "fld"
    col.Type = 2
    tbl.Name = "RelatedTable01"
    tbl.Columns.Append col
