Count

This property specifies the number of fields in a recordset or errors in an Errors collection.

object.Count

Parameters

object
Object that evaluates to a Recordset object or Errors collection.

Return Values

This property returns a Long value.

Remarks

The Count property is read-only.

Examples

The following code example shows how to display the number of fields in the MsysIndexes table using the Count property.

Dim rs
Set rs = CreateObject("ADOCE.Recordset.3.1")
rs.Open "MSysIndexes"
MsgBox rs.Fields.Count
rs.Close
Set rs = Nothing

The following code example shows how to loop through a table and display the names of the fields using the Count property.

Dim rs, n
Set rs = CreateObject("ADOCE.Recordset.3.1")
rs.Open "myTable"
For n = 0 to rs.Fields.Count -1
     Msgbox rs.Fields(n).Name
Next
