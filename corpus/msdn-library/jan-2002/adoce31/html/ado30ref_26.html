MovePrevious

This method moves the active row pointer to the previous row.

recordset.MovePrevious

Parameters

None.

Return Values

None.

Remarks

Use the MovePrevious method to move the current record position one record backward, toward the top of the recordset. If the first record is the current record and you call the MovePrevious method, ADOCE sets the current record to the position before the first record in the Recordset object, and BOF is TRUE. An attempt to move backward when the BOF property is already TRUE generates an error.

This method may not be supported in some recordsets.
