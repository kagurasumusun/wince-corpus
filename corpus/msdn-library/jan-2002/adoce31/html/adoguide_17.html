Using Transactions to Collect Data

When collecting data, it is sometimes necessary to gather a group of related data. If data collection is interrupted for some reason and cannot be completed, it might be better to abort than to save incomplete data. In this case, a transaction can be used.

Note   The Windows CE native database (Object Store and .cdb files) do not support transactions. This is dependant on the OLE DB provider as to whether they support transactions or not.

A transaction is started using the BeginTrans method. Data can be collected and stored in memory but will not be written to the database until the CommitTrans method is called. If an error occurs or for some reason the data is not collected, calling the RollbackTrans method will delete all the captured data from memory and end the transaction. The default level of the IsolationLevel property is adXactChaos. Set the IsolationLevel property if a higher level of isolation is necessary. In general, since databases on Windows CE devices usually have only a single user, it is not necessary to set a higher level of isolation.

If a transaction is aborted, you can reset the recordset by using the Requery method. The Requery method reopens the current recordset by querying the data source using the same information that was used when the current recordset was opened.

The following code example shows how to use a transaction to prevent the collection of partial data.

Dim cn, rs
'Insert code here to open a connection to a data source
'and open the table in the data source, myTable.
cn.BeginTrans
'Insert data collection code here.
If MsgBox("Save all changes?", vbYesNo) = vbYes Then
  cn.CommitTrans
Else
  cn.RollbackTrans
End If
