Partnerships and Synchronization

The first time you connect a mobile device to a desktop computer, Microsoft ActiveSync 3.1 asks you to set up a partnership with the mobile device. When setting up a partnership, you select synchronization and file conversion settings, which are contained in a file on the desktop computer. This file enables the desktop computer to recognize the device. Only devices that have a partnership with a desktop computer can synchronize information between the two computers.

Partnerships are stored in ActiveSync and have the same name as the corresponding device. The desktop computer can set up partnerships with many different mobile devices, but a device can have partnerships with only two computers.

Once a partnership is set up between the mobile device and the desktop computer, ActiveSync presents a list of files which you can choose to synchronize with the device. By default a limited amount of information is synchronized to conserve storage space on the device. You can modify the amount of information synchronized for each information type.

By default, ActiveSync will synchronize continuously with the desktop computer. You can change the synchronization mode by selecting to synchroinize only when you first connect or only when you manually start this process.
