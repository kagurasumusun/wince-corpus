Attributes

This property describes column characteristics.

Syntax

None

Constants

Sets or returns a Long value. The value specifies characteristics of the table represented by the Column object and can be a combination of the following constants:

Constant Description
AdColFixed The column is a fixed length
AdColNullable The column may contain null values

Parameters

None

Return Values

None

Remarks

The default value is zero (0), which is neither adColFixed nor adColNullable.

Example

This following example demonstrates how to display field attributes using the Attributes property.

Dim rs, n
    Set rs = CreateObject(“ADOXCE.recordset”)
    Rs.Open “myTable”
    For n = 0 to rs.Fields.Count –1
    MsgBox rs.Fields(n).Attributes
    Next
