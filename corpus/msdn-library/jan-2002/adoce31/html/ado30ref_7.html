Methods

The following table shows the methods that the ADOCE control supports.

Method Description
AddNew Inserts a new row into the recordset
AppendChunk Appends data to a large text or binary data Field.
BeginTrans Starts a new transaction on the connection
CancelUpdate Cancels changes held in memory
Clone Duplicates a recordset
Close (Connection) Closes an active connection and physically closes the channel of communication
Close (Recordset) Closes a recordset
CommitTrans Commits the current transaction on the connection
Delete Deletes a row from a recordset
Execute Executes a command against the connection that is not expected to return rows
Find Returns a recordset that matches specified search criteria
GetChunk Returns all, or a portion, of the contents of a large text or binary data Field object.
GetRows Returns data stored in a recordset
Move Moves the position of the current record in a recordset
MoveFirst Makes the first row active
MoveLast Makes the last row active
MoveNext Moves the active row pointer to the next row
MovePrevious Moves the active row pointer to the previous row
Open (Connection) Opens a connection to a data source
Open (Recordset) Defines and opens recordsets, and runs SQL commands
OpenSchema Obtains database schema information from the provider.
Requery Refreshes the entire contents of the recordset from the data source
RollbackTrans Cancels any changes made during the current transaction and ends the transaction
Seek Locates a record in an indexed recordset and makes that record the current record
Supports Determines if a recordset supports certain features
Update Commits changes held in a recordset to the database on a Windows® CE-based device
