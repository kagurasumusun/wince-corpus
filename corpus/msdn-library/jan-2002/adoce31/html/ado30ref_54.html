Filter

This property returns or sets the type of filter on the current recordset.

recordset.Filter [= value]

Constants

The following table shows the constants that are used with the Filter property.

Constant Value Description
adFilterNone 0 Removes the current active filter and returns to viewing all rows.

Return Values

This property returns a Long value.

Remarks

The default value for this read/write property is adFilterNone.

Once a filter is set, only rows that match the filter requirements appear in the recordset. The Move methods and BOF and EOF are available to navigate through the filtered recordset.

If no rows in the recordset match the filter, the recordset appears to be empty until the filter is removed. When the filter is removed (by setting this property to adFilterNone) all rows in the recordset become available and the cursor is repositioned in the first row in the recordset.

The only type of filter supported by ADOCE is an array of bookmarks. This array can contain unique bookmark values that point to records in the Recordset object.
