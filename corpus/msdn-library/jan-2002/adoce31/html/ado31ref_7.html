Table Object

This object represents a database table, including columns, indexes, and keys.

The following tables show the properties and collections that the Table object supports.

Property Description
Name Indicates the identity of the table
Type Indicates the type of a table
ParentCatalog Specifies the parent catalog of a table or column to provide access to provider-specific properties
DateCreated Indicates the date the object was created
DateModified Indicates the date the object was last modified

Collection Description
Columns Contains all Column objects of the table
Indexes Contains all Index objects of a table
Keys Contains all Key objects of a table
Properties Contains all the Property objects for a specific instance of an object

Parameters

None

Return Values

None

Remarks

Note   Your data provider may not support all properties of Table objects. An error will occur if you have set a value for a property that the provider does not support. For new Table objects, the error will occur when the object is appended to the collection. For existing objects, the error will occur when setting the property.

When creating Table objects, the existence of an appropriate default value for an optional property does not guarantee that your provider supports the property. For more information about which properties your provider supports, see your provider documentation.

Example

The following example creates a new Table object.

Dim tbl, col
    Set tbl = CreateObject("ADOXCE.TABLE.3.1")
    Set col = CreateObject("ADOXCE.COLUMN.3.1")

    If colType = "" Then col.Type = adSmallInt Else col.Type = colType
    tbl.Name = stName
    col.Name = "fld1"

    tbl.Columns.Append col
    cat.Tables.Append tbl
End Sub
