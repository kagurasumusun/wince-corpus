Open (Connection)

This method opens a connection to a data source.

connection.Open([ConnectionString As String], [UserID As String], [Password As String][OpenOptions As OpenOptionEnum])

Parameters

ConnectionString
Optional string used to open a data source. This string can contain the entire connection string or just the name of the data source.
UserID
Optional string used to pass the user identifier to connect to the data source. Ignored if the user identifier information is contained in the ConnectionString.
Password
Optional string used to pass the user password to the data source. Ignored if the password information is contained in the ConnectionString.
Open
Optional value, ConnectOptionEnum that determines whether this method should return after (synchronously) or before (asynchronously) the connection is established. The following table shows the acceptable values.
Constant Value Description
adAsyncConnect 16 Opens the connection asynchronously. The ConnectComplete event may be used to determine when the connection is available.
adConnectUnspecified -1 Default. Opens the connection synchronously.

Return Values

None.

Remarks

Upon successful completion of the Open command, the connection is live.

Providers can supply additional parameters for the ConnectionString used with the Open method. Check your provider's documentation for more information. If you are developing generic code, use only the above parameters to open a connection to a data source.

Examples

The following code example shows how to use the Open method using the three optional parameters and how to use a single compound statement in the ConnectionSting parameter.

Dim cn
Set cn = CreateObject("ADOCE.Connection")
'Opens a connection to a data source provider
strConn = "Provider=SQLOLEDB;Data Source=DATBTEST;Initial Catalog=TEST;User Id=sa;Password=;"
cn.Open strConn

The following code example shows how to connect to the default object store.

'Opens a connection to the default object store
Cn.Open
Cn.Open "provider=cedb"
