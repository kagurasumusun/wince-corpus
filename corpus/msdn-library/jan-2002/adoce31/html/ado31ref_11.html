Keys Collection

This collection contains all Key objects of a table.

Parameters

The following table shows the properties and methods for the Keys collection.

Property Description
Count Returns the number of keys contained in the collection

Method Description
Append Adds a new key to the collection. The Append method for a Keys collection is unique for ADOXCE
Item Access a key in the collection
Delete Removes a key from the collection
Refresh Updates the objects in the collection to reflect the schema of the current database

Return Values

None

Remarks

None

Example

The following code demonstrates how to create a new key.

Dim col, ky, tbl
    Set col = CreateObject("adoxce.column.3.1")
    Set ky = CreateObject("adoxce.key.3.1")
    Set tbl = CreateObject("adoxce.table.3.1")

    col.Name = "fld"
    col.Type = 2
    tbl.Name = tblOne
    tbl.Columns.Append col

    'create primary key
    ky.Name = "fld1"
    ky.Type = adKeyPrimary
    ky.Columns.Append tbl.Columns(0).Name
    tbl.Keys.Append ky

    cat.Tables.Append tbl

    Set ky = Nothing
    Set ky = CreateObject("adoxce.key.3.1")
    Set col = Nothing
    Set col = CreateObject("adoxce.column.3.1")

    ky.Name = "Key1"
    ky.Type = adKeyForeign
    ky.RelatedTable = tbl.Name
    col.Name = tblMany.Columns(0).Name
    col.RelatedColumn = tbl.Columns(0).Name

    ky.Columns.Append col
    tblMany.Keys.Append ky

    Set tbl = Nothing
    Set col = Nothing
    Set ky = Nothing
End Sub
