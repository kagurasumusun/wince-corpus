Properties Collection

This collection contains all of the Property objects for a specific instance of an object.

Remarks

Some ADOCE objects have a Properties collection made up of Property objects. Each Property object corresponds to a characteristic of the ADOCE object specific to the provider.

Note   See the Property object topic for a more detailed explanation of how to use Property objects.
