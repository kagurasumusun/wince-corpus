Recordset Object

A recordset is a virtual database table whose fields and rows correspond to a subset of the fields and rows in an actual database table on a Windows CE-based device.

Use the CreateObject method to create a new Recordset object.

The following table shows the methods that the Recordset object supports.

Method Description
AddNew Inserts a new row into the recordset
CancelUpdate Cancels changes held in memory
Clone Duplicates a recordset
Close Closes a recordset
Delete Deletes a row from the recordset
Find Returns a recordset that matches specified search criteria
GetRows Returns data stored in the recordset
Move Moves the position of the current record in the recordset
MoveFirst Makes the first row active
MoveLast Makes the last row active
MoveNext Moves the active row pointer to the next row
MovePrevious Moves the active row pointer to the previous row
Open Defines and opens recordsets, and runs structured query language (SQL) commands
Requery Refreshes the entire contents of the recordset from the data source
Seek Locates a record in an indexed recordset and makes that record the current record
Supports Determines if the recordset supports certain features
Update Commits changes held in the recordset to the database on a Windows CE-based device

The following table shows the properties that the Recordset object supports.

Property Description
AbsolutePage Returns the index of a page to move for a new current record
AbsolutePosition Returns the ordinal position of the current record of a recordset
ActiveConnection Sets the current database connection
BOF Returns whether the current record position is before the first record in a recordset
Bookmark Returns a bookmark that uniquely identifies a record in a recordset
CacheSize Returns the number of records from a recordset that are cached locally in memory
CursorType Returns the type of cursor used in a recordset
EditMode Returns the editing status of the current record
EOF Returns that the current record position is after the last record in a recordset
Filter Returns or sets a filter on the current recordset
Index Returns or sets the number that uniquely identifies an object in a collection
LockType Returns the type of locks placed on records during editing
PageCount Returns the number of pages of data a recordset contains
PageSize Returns the number of records that constitute one page in a recordset
Properties (Collection) Returns additional metadata about the recordset (Not required to be supported by an OLE DB provider)
RecordCount Returns a Long value that specifies the current number of records in a recordset
Source Returns the source for the data in a recordset, either an SQL statement or a table name
State Describes the current state of the recordset

Remarks

Use the CreateObject method to create a new Recordset object.

Examples

The following code example shows how to instantiate a Recordset object.

Dim rstCustomers, fldName
Set rstCustomers = CreateObject("ADOCE.Recordset.3.1")
rstCustomers.Open "customers"
Set fldName = rstCustomers.Fields("Name")
MsgBox fldName.Value
rstCustomers.Close
Set fldName = Nothing
Set rstCustomers = Nothing
