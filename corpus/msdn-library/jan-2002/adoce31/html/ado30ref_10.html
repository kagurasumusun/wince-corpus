BeginTrans

This method starts a new transaction on the connection.

Connection.BeginTrans() As Long

Parameters

None.

Return Values

The BeginTrans method returns a Long value that specifies the level of the started transaction. A value of 1 represents the first or root transaction.

Remarks

An error is returned when the BeginTrans method is used with the proprietary Windows® CE data source.

The BeginTrans method starts a new transaction on the Connection object. When called, this method takes the connection out of auto-commit mode. To end the transaction, either the CommitTrans method or the RollbackTrans method must be called.

Some data source providers allow nested transactions, although an error may arise if a new transaction is initiated while another is still pending.

Examples

The following code example shows how to use BeginTrans to start a new transaction.

Dim cn, rs
'Insert code here to open a connection to a data source
'and open the table in the data source, myTable.
cn.BeginTrans
'Insert data collection code here.
If MsgBox("Save all changes?", vbYesNo) = vbYes Then
  cn.CommitTrans
Else
  cn.RollbackTrans
End If
