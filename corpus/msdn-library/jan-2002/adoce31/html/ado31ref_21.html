ActiveConnection

This property indicates the ADOCE Connection object to which the Catalog belongs.

Syntax

None

Parameters

object
Object that evaluates to a Catalog object.

Return Values

Returns the active Connection object.

Remarks

The default value is a Null object reference.

Examples

The following example demonstrates how to set the ActiveConnection property to a valid, open connection which opens the catalog.

    Dim cat, strConn, strDataSource, i

    strDataSource = "pubs.db"
    strConn = "provider=microsoft.sqlserver.oledb.ce.1.0;data source=" & strDataSource & ";"

    Set cat = CreateObject("adoxce.catalog")

    On Error Resume Next
    cat.ActiveConnection = strConn
    …
End Sub
