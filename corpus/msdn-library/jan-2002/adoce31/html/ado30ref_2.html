Connection Object

This object represents a connection to a data source. The data source can be the proprietary Windows CE data source or an OLE DB database.

The following table shows the methods that the Connection object supports.

Method Description
BeginTrans Starts a new transaction on the connection
Close Closes an active connection and physically closes the channel of communication
CommmitTrans Commits the current transaction on the connection
Open Opens a connection to a data source
OpenSchema Obtains database schema information from the provider.
Execute Executes a command against the connection that is not expected to return rows
RollbackTrans Cancels any changes made during the current transaction and ends the transaction

The following table shows the properties that the Connection object supports.

Property Description
Attributes Returns or sets transaction attributes on the current connection
ConnectionString String used to connect to a data source
DefaultDatabase Sets the default database for the current connection
Errors (Collection) Collection containing errors returned from the provider
IsolationLevel Returns or sets the transaction isolation level for the current connection
Mode Describes the permissions for modifying data of the current connection
Properties (Collection) Collection used for setting and retrieving information about the provider
Provider Returns or sets the OLE DB data provider for the session
State Describes the state of the current connection
Version Returns the version of the ADOCE control being used

Remarks

The Connection object connects to the proprietary Windows CE data store and the OLE DB data providers.

The BeginTrans, CommitTrans, and RollbackTrans methods cause an error if they are used with the proprietary Windows CE data source.

The Filter, Attributes, and IsolationLevel properties cause an error if they are used with the proprietary Windows CE data source.

The proprietary Windows CE data source does not support the Properties collection of the Connection object.

Multiple connections can be open to a data source at the same time.

The are no events associated with the Connection object.

Examples

The following code example shows how to create a Connection object.

Dim cn
Set cn = CreateObject("ADOCE.Connection.3.1")
cn.Open "myDatabase.cdb"
cn.Close
Set cn = Nothing
