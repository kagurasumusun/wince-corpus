Data Manipulation Language Statements

The following statements make up the data manipulation language portion of SQL for ADOCE:

  • DELETE
  • INSERT
  • SELECT – Join
  • SELECT – Like
  • SELECT – Order By
  • SELECT – Projection
  • SELECT – Restricted
  • SELECT – Simple

For more information about using SQL with ADOCE, see the topic SQL Overview.
