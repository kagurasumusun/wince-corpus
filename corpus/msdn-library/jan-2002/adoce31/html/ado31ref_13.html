Tables Collection

This collection contains all the Table objects in a Catalog.

Parameters

The following tables show the properties and methods for the Tables collection.

Count
Returns the number of tables contained in the collection
Method Description
Append (Tables) Adds a new table to the collection
Item Accesses a table in the collection
Delete Removes a table from the collection
Refresh Updates the objects in the collection to reflect the current database's schema

Remarks

Some providers may return other schema objects, such as a View, in the Tables collection. Therefore, some ADOXCE collections may contain references to the same object. Should you delete the object from one collection, the change will not be visible in another collection that references the deleted object until the Refresh method is called on the collection. For example, with the OLE DB Provider for Microsoft Jet, Views are returned with the Tables collection. If you drop a View, you must Refresh the Tables collection before the collection will reflect the change.

Examples

The following example demonstrates how to use the Tables collection

Dim m_cat, m_col, tbl, col, strConn, stTableName, stColumnName, stExp, stAct

    Set m_cat = CreateObject("adoxce.catalog.3.1")
    Set m_col = CreateObject("adoxce.column.3.1")
    Set tbl = CreateObject("adoxce.table.3.1")
    Set col = CreateObject("adoxce.column.3.1")

    'strConn = "provider=microsoft.sqlserver.oledb.ce.1.0;data source=pubs.db;"
    strConn = "provider=microsoft.jet.oledb.4.0;data source=temp.mdb;"
    m_cat.ActiveConnection = strConn

    stTableName = "ColAppScen18"
    If adox_ExistsTable(m_cat, stTableName)

m_cat.Tables.Delete stTableName
    End If

    tbl.Name = stTableName

    stColumnName = "Column1"
    m_col.Name = stColumnName
    m_col.Type = adSmallInt

    tbl.Columns.Append m_col
    m_cat.Tables.Append tbl

    'Create a new column
    col.Name = "Column2"
    col.Type = adSmallInt

    'Set parentcatalog
    col.ParentCatalog = m_cat

    col.Properties.Refresh

    m_cat.Tables(stTableName).Columns.Append col

    stExp = "Column2"
    stAct = m_cat.Tables(stTableName).Columns(1).Name

    Debug.Print stExp, stAct

    'Cleanup
    m_cat.Tables.Delete stTableName
    Set tbl = Nothing
    Set col = Nothing
    Set m_cat = Nothing

End Sub
