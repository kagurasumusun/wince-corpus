Properties Collection (Recordset)

This property exposes additional metadata about the recordset.

recordset.Properties(integer) or recordset.properties("Name")

Return Values

This property returns a collection of string objects.

Remarks

The proprietary Windows CE data source does not support the Properties collection. If this collection is queried when used with the proprietary Windows CE data source, an empty collection will be returned.

Support of this collection is provider dependent. Check the data provider’s documentation to see what is supported.
