Field Object

This object is not directly created because it exists only in the context of a recordset. Use the Set method to refer to a specific Field object.

The following table shows the methods that the Field object supports.

Method Description
AppendChunk Appends data to a large text or binary data Field.
GetChunk Returns all, or a portion, of the contents of a large text or binary data Field object.

The following table shows the properties that the Field object supports.

Property Description
ActualSize Specifies the actual length, in bytes, of a field’s value
Attributes Returns a value that specifies one or more characteristics of a Field object
DefinedSize Determines the data capacity of a Field object, and returns the defined size of the field in characters
Name Returns the name of a field
NumericScale Returns the number of defined digits to the right of the decimal separator in the field
Precision Returns the total number of digits defined in a field
Type Specifies the data type of a Field object
UnderlyingValue Specifies the current value of a Field object in the database
Value Specifies the current value of a Field object in the recordset

Remarks

The Field object has no events. With the exception of Value and ActualSize, all properties of the Field object are read-only.

Examples

The following code example shows how to use a Field object to display data in a table.

Dim rs, f
Set rs = CreateObject("ADOCE.Recordset.3.1")
rs.Open "MSysTables"
Set f = rs.Fields(0)
Msgbox f.Value, ,f.Name
