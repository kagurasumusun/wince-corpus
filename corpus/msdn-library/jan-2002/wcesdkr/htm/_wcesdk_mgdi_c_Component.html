mgdi_c Component

The mgdi_c component provides support for the graphics device interface (GDI). The GDI is responsible for the display of text and images on display devices and printers. It processes graphical function calls from a Windows-based application and passes them to the appropriate device driver, which generates the output on the display hardware.

Functions for Application Developers

The mgdi_c component includes the following functions for application developers, which are defined in the Wingdi.h header file. To import these functions, you need to link to the mgdi_c.lib file.
