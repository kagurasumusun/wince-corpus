EnumTimeFormatsProc

This function is an application-defined callback function. It is called as a result of a call to the EnumTimeFormats function, and receives a pointer to a string buffer that contains a time format string. 

BOOL CALLBACK EnumTimeFormatsProc(
LPWSTR lpTimeFormatString );

Parameters

lpTimeFormatString
[out] Pointer to a string buffer that contains a null-terminated time format string.

Return Values

TRUE continues enumeration. FALSE stops enumeration.

Remarks

Windows CE supports only the Unicode version of this function.

An application registers an EnumTimeFormatsProc function by passing its address to the EnumTimeFormats function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later
