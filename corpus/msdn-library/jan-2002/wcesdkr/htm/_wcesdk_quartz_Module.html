quartz Module

The quartz module is the core DirectShow module. This module is divided into two parts: quartz1 and quartz2.

Quartz Components

The quartz module contains the following components.

Component Description
ACMWRAP ACM wrapper filer.
ASYNCRDR Asynchronous file reader.
AVIDEC AVI Video decompressor. Uses ICM.
AVIMSR AVI parser/splitter.
DSNDOUT DirectSound audio renderer.
IMAGE Video renderer.
MIDIDM Supports DirectShow MIDI playback.
MPGADEC MPEG1 audio decoder. Supports layers 1 and 2.
MPGSPLIT MPEG1 parser/splitter.
MPGVDEC MPEG1 video decoder.
OVMIXER2 Overlay mixer.
QTRDR QuickTime parser/splitter.
SCMDOUT Script command renderer used for WMT scripting.
URLRDR URL asynchronous reader.
WAVEMSR Wave/AIFF/au/snd file parser.
WAVEOUT WaveOut audio renderer.
