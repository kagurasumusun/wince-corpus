TerminateExtension

The TerminateExtension function unloads the ISAPI DLL. This optional entry point function is called by the Web server when the Web server is ready to unload the DLL from its process. 

BOOL WINAPI TerminateExtension(
DWORD dwFlags );

Parameters

dwFlags

A DWORD that specifies whether the Web server should shut down the extension.

Value Description
HSE_TERM_MUST_UNLOAD The Web server always passes this flag. ISAPIs must unload when TerminateExtension is called.

Remarks

Because TerminateExtension is never called by the Web server until all outstanding requests have been processed, it is not necessary to include code to wait for outstanding requests within TerminateExtension.

This function is not exported by the httpextn component of the Windows CE operating system.
