ppp Module

The ppp module supports the Point-to-Point Protocol (PPP) and provides random access server (RAS) functionality.

Functions for Application Developers

The ppp module contains the following functions for application developers, which are defined in the Ras.h header file. To import these functions, you need to link to the ppp.lib file.
