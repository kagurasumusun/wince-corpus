EqualPins

Checks if two pins are on the same object. 

BOOL EqualPins(
IUnknown *pPin1,
IUnknown *pPin2);

Parameters

pPin1
Address of one pin.
pPin2
Address of the other pin.

Return Values

Returns TRUE if the pins are both on the same object, or FALSE otherwise.
