IPOutlookItemCollection::Find

This method is not supported in Windows CE Platform Builder 3.0.

This method finds the first Pocket Outlook item in a collection that passes the specified restriction. 

HRESULT Find( BSTR pwszRestriction, IDispatch ** ppolItem );

Parameters

pwszRestriction
[in] A restriction string that defines which items to find. This must contain a boolean expression that evaluates to TRUE or FALSE for any item. Enclose property names between brackets. You can combine expressions with AND and OR. Comparison operators are the following: <, <=, >, >=, = or <>.

For example, the restriction string [CompanyName] = “Microsoft” returns the first item that has Microsoft as the company.

ppolItem
[out] A pointer to a pointer to the item found by the method. This is set to NULL if no item passes the restriction.

Return Values

S_OK indicates success. If an error occurs, the appropriate HRESULT value is returned. If no item matches the restriction, the return value is S_OK and ppolItem is set to NULL.

Remarks

An item without the specified property set will not pass a restriction regardless of the restriction string. For example, if you do not set the email address for a contact, the contact will not be found using the restriction string [Email1Address]<>foo@bar.com even though it does not have foo@bar.com associated with it.

Find does not support restrictions based on the following item properties: BodyInk, ReminderTime, Recipients.

Use FindNext to find subsequent items in a collection that pass the restriction.

Code Example [Visual Basic]

The following Visual Basic® code snippet shows how set the current home city as Seattle:

Sub SetHomeCity(polApp As PocketOutlook.Application)
Dim pCity as PocketOutlook.CityItem
Set strQuery = “[NAME] = “ & Chr(34) & “Seattle, WA” & Chr(34)
Set pCity = polApp.GetDefaultFolder(olFolderCities).Items.Find(strQuery)
polApp.HomeCity = pCity
polApp.CurrentCityIndex = olHomeCity
End Sub

Code Example [C++]

The following C++ code snippet shows how to set the home city as Seattle:

void SetHomeCity(IPOutlookApp *polApp)
{
IFolder *pFolder;
IPOutlookItemCollection *polItems;
ICity *pCity;

// Get the cities folder
polApp->GetDefaultFolder(olFolderCities, &pFolder);

// Get the cities Items collection
pFolder->get_Items(&polItems);

// Find Seattle, WA
polItems->Find(TEXT(“[Name] = \”Seattle, WA\””), (IDispatch **) &pCity);

// Make Seattle, WA the home city
polApp->put_HomeCity(pCity);
polApp->put_CurrentCityIndex(olHomeCity);

// Release objects
pFolder->Release();
polItems->Release();
pCity->Release();
}
