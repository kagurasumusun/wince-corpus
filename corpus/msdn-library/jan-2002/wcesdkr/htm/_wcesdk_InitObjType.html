InitObjType

This function is not supported in Windows CE Platform Builder.

The InitObjType function allows an ActiveSync service provider on the device to either initialize data and return a pointer to the IReplObjHandler interface at loading, or free allocated resources at termination.

BOOL InitObjType (
LPWSTR lpszObjType,
IReplObjHandler *ppObjHandler,
UINT uPartnerBit);

Parameters

lpszObjType
[in] Long pointer to the null-terminated string that contains the name of the object type. NULL if InitObjType is called during termination, in which case ActiveSync service provider should free allocated resources.
ppObjHandler
[out] Pointer to a pointer to the IReplObjHandler interface.
uPartnerBit
[in] It is 1 if the desktop currently connected is partner #1, and it is 2 if the currently connected desktop is partner #2.

Return Values

TRUE if completed successfully, otherwise it is FALSE.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Cesync.h
