DB_PEGOID_CHANGED

This message is sent when an object in the object store has been modified. This message is obsolete for all supported versions of Windows CE. Use DB_CEOID_CHANGED.

DB_PEGOID_CHANGED oidChanged = (PEGOID) wParam;
oidParent = (PEGOID) lParam;

Parameters

oidChanged
Identifier of the object that was modified.
oidParent
Identifier of the parent object of the modified object.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 Windbase.h Winbase.h
