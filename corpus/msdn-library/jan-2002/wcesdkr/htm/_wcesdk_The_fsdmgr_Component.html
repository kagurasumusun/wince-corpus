fsdmgr Component

This component supports the file system driver (FSD) manager. The FSD manager manages all system interactions with installable FSDs. It creates file handles, registers volumes, installs necessary functions, and maps application calls to the installed functions. FSD manager invokes these functions when an application accesses folders and files on mounted volumes using the file system functions.

Functions for Application Developers

The fsdbase component includes the following functions for application developers, which are defined in the Fsdmgr.h header file. To import these functions, you need to link to the fsdmgr.lib file.

FSDMGR_CreateFileHandle
FSDMGR_CreateSearchHandle
FSDMGR_DeregisterVolume
FSDMGR_GetDiskInfo
FSDMGR_GetVolumeName
FSDMGR_ReadDisk
FSDMGR_ReadDiskEx
FSDMGR_RegisterVolume
FSDMGR_WriteDisk
FSDMGR_WriteDiskEx
