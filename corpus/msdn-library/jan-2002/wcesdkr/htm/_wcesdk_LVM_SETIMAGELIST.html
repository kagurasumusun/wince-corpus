LVM_SETIMAGELIST

This message assigns a new image list to a list view control. You can send this message explicitly or by using the ListView_SetImageList macro. 

LVM_SETIMAGELIST wParam = (WPARAM)(int) iImageList;
lParam = (LPARAM)(HIMAGELIST) himl;

Parameters

iImageList
Type of image list. It is one of the following values:

Value Description
LVSIL_NORMAL Image list with large icons
LVSIL_SMALL Image list with small icons
LVSIL_STATE Image list with state images

himl
Handle to the image list to assign

Return Values

The handle to the image list previously associated with the control indicates success. NULL indicates otherwise.

Remarks

Windows CE supports a new value for the iImageList parameter (WPARAM). The LVSIL_HEADER constant specifies that, in report view, the image list will be displayed in the list view’s header control.

Related macro: ListView_SetImageList
