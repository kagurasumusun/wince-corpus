LoadFSD

This function is called by a device driver to load its associated file system driver (FSD).

BOOL LoadFSD (
HANDLE hDevice,
LPCWSTR lpFSDName);

Parameters

hDevice
Handle to a registered device, obtained when a block device driver is called with the IOCTL DISK_IOCTL_INITIALIZED.
lpFSDName
Pointer to the name of the FSD to load.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

LoadFSD is called by a block device driver to load a file system driver. For example, the block device driver Atadisk.dll loads the file system driver Fatfs.dll.

Requirements
