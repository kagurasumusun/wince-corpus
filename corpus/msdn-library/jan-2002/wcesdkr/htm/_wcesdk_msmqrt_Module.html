msmqrt Module

The msmqrt module supports the main Message Queuing run-time API set.

Functions for Application Developers

The msmqrt module includes the following functions for application developers, which are defined in the mq.h header file. To import these functions, you need to link to the msmqapix.lib file.

Function
MQCloseCursor
MQCloseQueue
MQCreateCursor
MQCreateQueue
MQDeleteQueue
MQFreeMemory
MQGetMachineProperties

MQOpenQueue
MQPathNameToFormatName
MQReceiveMessage
