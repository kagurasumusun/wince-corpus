locusa Component

The locusa component provides national language support (NLS) for the United States. It exposes the same APIs as the coreloc component.

Functions for Application Developers

The locusa component includes the following functions for application developers, which are defined in the Winnsl.h header file. To import these functions, you need to link to the locusa.lib file.
