RemoveDirectory

This function deletes an existing empty directory. A remote application interface (RAPI) version of this function exists, and it is called CeRemoveDirectory.

BOOL RemoveDirectory(
LPCTSTR lpPathName);

Parameters

lpPathName
[in] Pointer to a null-terminated string that specifies the path of the directory to be removed. The path must specify an empty directory, and the calling process must have delete access to the directory.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Winbase.h   Coredll.lib, Fsmain.lib
