WM_ENTERMENULOOP

This message informs an application's main window procedure that a menu modal loop has been entered. 

WM_ENTERMENULOOP fIsTrackPopupMenu = (BOOL) wParam;

Parameters

fIsTrackPopupMenu
Boolean that specifies whether the window menu was entered using the TrackPopupMenu function. Set to TRUE if the window menu was entered using TrackPopupMenu, or to FALSE if it was not.

Return Values

An application should return zero if it processes this message.

Remarks

The DefWindowProc function returns zero.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Winuser.h
