mixerClose

The mixerClose function closes the specified mixer device. 

MMRESULT mixerClose(
HMIXER hmx );

Parameters

hmx
Handle to the mixer device. This handle must have been returned successfully by the mixerOpen function. If mixerClose is successful, hmx is no longer valid.

Return Values

Returns MMSYSERR_NOERROR if successful or an error otherwise. Possible error values include the following:

Value Description
MMSYSERR_INVALHANDLE Specified device handle is invalid.

Requirements
