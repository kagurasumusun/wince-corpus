CAMThread::Reply

Retrieves a DWORD value to the requesting thread and releases it, signaling completion of the request. 

void Reply(
DWORD dw);

Parameters

dw
Value returned by the CAMThread::CallWorker member function on the client side.

Return Values

No return value.
