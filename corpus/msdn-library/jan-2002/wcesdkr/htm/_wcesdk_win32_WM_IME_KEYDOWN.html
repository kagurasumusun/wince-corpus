WM_IME_KEYDOWN

This message is sent to an application by the IME to notify the application of a key press. The Parameters and return value for this message are identical to the WM_KEYDOWN message. An application can process this message or pass it to the DefWindowProc function to generate a matching WM_KEYDOWN message. This message is usually generated by the IME to keep message order.

WM_IME_KEYDOWN nVirtKey = (int) wParam;lKeyData = lParam;

Parameters

nVirtKey
Virtual-key code.
lKeyData
Key data.
