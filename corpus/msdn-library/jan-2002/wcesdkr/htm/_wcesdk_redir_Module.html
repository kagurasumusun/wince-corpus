redir Module

The redir module implements the network redirector module and provides support for Win32 Wnet APIs.

Functions for Application Developers

The redir module contains the following functions for application developers, which are defined in the Winnetwk.h header file. To import these functions, you need to link to the redir.lib file.

Function
WnetAddConnection3
WnetCancelConnection2
WnetCloseEnum
WnetConnectionDialog1
WnetDisconnectDialog
WnetDisconnectDialog1

WnetGetConnection
WnetGetUniversalName
