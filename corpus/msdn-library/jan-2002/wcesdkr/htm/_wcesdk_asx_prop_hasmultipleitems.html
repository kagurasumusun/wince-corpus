HasMultipleItems

Retrieves a value specifying whether the current Advanced Stream Redirector (ASX) file contains multiple ENTRY items.

Compatibility: Windows Media Player

[ bMultiple = ] MediaPlayer.HasMultipleItems

Parameters

bMultiple
Boolean value specifying whether the ASX file contains multiple ENTRY tags. If true, the ASX file playlist contains multiple items. This property is read-only with no default value.
