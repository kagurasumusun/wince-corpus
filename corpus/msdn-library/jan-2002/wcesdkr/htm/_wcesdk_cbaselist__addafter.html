CBaseList::AddAfter

Inserts a list of nodes after the specified node. 

BOOL AddAfter(
POSITION pos,
CBaseList *pList);

Parameters

pos
Position after which to add the list of nodes.
pList
Pointer to the list of objects to add.

Return Values

Returns TRUE if successful; otherwise, returns FALSE.
