CFactoryTemplate::IsClassID

Determines if the class identifier (CLSID) passed matches the CLSID assigned to this class template. 

BOOL IsClassID(
REFCLSID rclsid );

Parameters

rclsid
CLSID being tested.

Return Values

Returns TRUE if the CLSIDs are the same; otherwise, returns FALSE.
