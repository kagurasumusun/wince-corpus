NTLMSetUserInfo

This function adds user information to the local database.

BOOL SEC_ENTRY NTLMSetUserInfo(
IN LPTSTR pszUser ,
IN LPTSTR pszPassword , );

Members

pszUser
[in] Specifies the user name. The user name is created if it does not exist.
pszPassword
[in] Specifies the password, maximum 15 characters.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later NTLMSSP.dll
