TabCtrl_GetCurFocus

This macro returns the index of the item that has the focus in a tab control. You can use this macro or send the TCM_GETCURFOCUS message explicitly.

int TabCtrl_GetCurFocus( HWND hwnd );

Parameters

hwnd
Handle to the tab control.

Return Values

The index of the tab item that has the focus indicates success.

Remarks

The item that has the focus may be different from the selected item.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
