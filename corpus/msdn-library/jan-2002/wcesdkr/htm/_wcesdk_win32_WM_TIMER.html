WM_TIMER

This message is posted to the installing thread's message queue or sent to the appropriate TimerProc callback function after each interval specified in the SetTimer function used to install a timer. 

WM_TIMER  wTimerID = wParam; tmprc = (TIMERPROC *) lParam;

Parameters

wTimerID
Specifies the timer identifier.
tmprc
Pointer to an application-defined callback function that was passed to the SetTimer function when the timer was installed.

Return Values

An application should return zero if it processes this message.

Remarks

The WM_TIMER message is a low-priority message. The GetMessage and PeekMessage functions retrieve this message only when no other higher-priority messages are in the thread’s message queue.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Winuser.h
