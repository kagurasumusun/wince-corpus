CeSvcRemove

This function removes a handle.

HRESULT CeSvcRemove( 
LPTSTR pszSvcNameSvc,
LPTSTR pszSvcClass,
DWORD dwSvcFlags);

Parameters

pszSvcName
[in] Handle to a registry subkey. Can be NULL.
pszSvcClass
[in] Handle to a registry subkey. Can be NULL.
dwSvcFlags
[in] Handle to a registry subkey. Can be NULL.

Return Values

S_OK indicates success. On failure an appropriate Win32 error code is returned.

Remarks

This function is part of CEUTIL, a utility DLL for dealing with desktop registry entries for Windows CE. CEUTIL functions are for use by desktop applications that need to communicate remotely with Windows CE–based devices. These functions are not available to applications running on Windows CE–based devices.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS   Ceutil.h
