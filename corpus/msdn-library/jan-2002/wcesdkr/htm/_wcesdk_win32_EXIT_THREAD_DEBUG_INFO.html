EXIT_THREAD_DEBUG_INFO

This structure contains an exiting thread’s exit code.

typedef struct _EXIT_THREAD_DEBUG_INFO {
DWORD dwExitCode;
} EXIT_THREAD_DEBUG_INFO;

Members

dwExitCode
Specifies the exit code for the thread.
