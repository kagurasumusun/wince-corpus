fatfs Module

The fatfs module implements the file allocation table (FAT) file system. This module is included in the full-version OS.

Functions for Operating System Developers

The fatfs module contains the following function for operating system configuration, which is defined in the fatui.h header file. To import this function, you need to link to the fat.lib file.
