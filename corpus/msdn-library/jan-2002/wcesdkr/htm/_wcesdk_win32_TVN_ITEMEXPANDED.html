TVN_ITEMEXPANDED

This notification message notifies a tree view control’s parent window that a parent item's list of child items has expanded or collapsed. It is sent in the form of a WM_NOTIFY message. 

TVN_ITEMEXPANDED pnmtv = (NM_TREEVIEW FAR *) lParam

Parameters

pnmtv
Pointer to an NMTREEVIEW structure. The itemNew member is a TVITEM structure that contains valid information about the parent item in the hItem, state, and lParam members. The action member indicates whether the list expanded or collapsed. For a list of possible values, see the description of the TVM_EXPAND message.

Return Values

The return value is ignored.

Requirements

Windows CE OS 1.0 and later Commctrl.h
