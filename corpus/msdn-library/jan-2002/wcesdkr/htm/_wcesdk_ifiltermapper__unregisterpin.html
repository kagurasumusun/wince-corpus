IFilterMapper::UnregisterPin

Removes the registration of this pin from the registry. 

HRESULT UnregisterPin(
CLSID Filter,
LPCWSTR Name);

Parameters

Filter
[in] Globally unique identifier (GUID) of the filter that this pin is part of.
Name
[in] Name of the pin.

Return Values

Returns an HRESULT value.
