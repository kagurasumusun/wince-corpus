CSourceSeeking::GetPreroll

Sets the preroll time to zero. 

HRESULT GetPreroll(
LONGLONG *pPreroll );

Parameters

pPreroll
Returned preroll time of zero.

Return Values

Returns E_POINTER if pPreroll is invalid; otherwise, returns S_OK.
