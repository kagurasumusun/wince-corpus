waveui Component

The waveui component implements the user interface for the audio configuration dialog boxes.

Functions for Operating System Developers

The waveui component contains the following functions for application developers, which are defined in the Waveui.c file. To import these functions, you need to link to the Waveui.lib file.

waveui_AcmDlgProc
