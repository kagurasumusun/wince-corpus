IPOutlookApp::Logoff

This method is not supported in Windows CE Platform Builder 3.0.

This method logs the user off of a Pocket Outlook session. Make this the last method called for a Pocket Outlook object.

HRESULT Logoff();

Requirements

Runs On Versions Defined in Include Link to
Windows CE OS 2.0 and later pimstore.h
