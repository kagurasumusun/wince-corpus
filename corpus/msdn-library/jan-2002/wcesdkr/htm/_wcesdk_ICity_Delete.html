ICity::Delete

This method is not supported in Windows CE Platform Builder 3.0.

This method deletes a city item.

HRESULT Delete();

Return Values

S_OK indicates the city item was successfully deleted. If the city could not be deleted, the appropriate HRESULT value is returned. If you attempt to delete a city that is stored in ROM, you get the error code E_CITYINROM.

Requirements

Runs On Versions Defined in Include Link to
Windows CE OS 2.0 and later pimstore.h
