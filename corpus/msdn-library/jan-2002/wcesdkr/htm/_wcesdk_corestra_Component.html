corestra Component

The corestra component supports the “A” (ASCII) version of sprintf-style string handling.

Functions for Application Developers

The corestra component includes the following functions for application developers, which are defined in the Stdlib.h header file. To import these functions, you need to link to the corestra.lib file.

Function
_snprintf
Sprintf
Sscanf
Vsprintf
