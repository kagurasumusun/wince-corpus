AudioStream

Sets or retrieves a value specifying the stream number of the current audio stream.

Compatibility: Windows Media Player

MediaPlayer.AudioStream [ = lStream ]

Parameters

lStream
Long value specifying the stream number of the current audio stream. This property is read/write.

Remarks

This property is useful if your content contains multiple audio streams. For example, if a clip contains several audio streams encoded in different languages, this property can specify which language the Microsoft® Windows Media™ Player control uses when it renders the content.
