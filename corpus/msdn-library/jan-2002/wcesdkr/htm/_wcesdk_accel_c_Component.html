accel_c Component

The accel_c component provides client-side support for user accelerator tables.

Functions for Application Developers

The accel_c component includes the following functions for application developers, which are defined in the C_accel.h header file. To import these functions, you need to link to the accel_c.lib file.

Function
CreateAccelatorTable
DestroyAccelatorTable
