rectapi Component

The rectapi component provides graphics device interface (GDI) support for rectangles.

Functions for Application Developers

The rectapi component includes the following functions for application developers, which are defined in the Winuser.h header file. To import these functions, you need to link to the rectapi.lib file.

Function
CopyRect
EqualRect
InflateRect
IntersectRect
IsRectEmpty
OffsetRect
PtInRect
SetRect
SetRectEmpty
SubtractRect
UnionRect
