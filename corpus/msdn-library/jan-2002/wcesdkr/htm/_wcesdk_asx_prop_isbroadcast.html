IsBroadcast

Retrieves a value specifying whether the source is broadcast.

Compatibility: Windows Media Player

[ bBroadcast = ] MediaPlayer.IsBroadcast

Parameters

bBroadcast
Boolean value specifying whether the source is broadcast. If true, the source is broadcast. This property is read-only with no default value.

Remarks

Viewing a broadcast clip is analogous to viewing a television program. Functions such as pause, fast-forward, and rewind are not available.
