Windows CE Modules and Components

Because minimization of memory use is a major design goal, Microsoft® Windows® CE is built from a number of discrete modules. By selecting only those modules that your system requires, you can minimize the memory that is needed for your Windows CE operating system (OS). Each module contains a collection of related application programming interface (API) functions. In addition, some modules contain one or more submodules, or components; each of which can contain its own collection of API functions.

Windows CE modules that include one or more optional components are referred to as componentizable modules. Examples of a componentizable module include the coredll module and the gwe module. Each of these modules provides full or partial support for major features of the OS and can be tailored to the needs of a given embedded application.

The “Windows CE Modules” topic lists all of the modules that compose the Windows CE OS. Those modules that have public functions or components are linked to topics that describe them in greater detail.
