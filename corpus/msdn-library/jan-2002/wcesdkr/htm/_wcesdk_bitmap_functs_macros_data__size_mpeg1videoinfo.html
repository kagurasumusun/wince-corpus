SIZE_MPEG1VIDEOINFO

Calculates the size of the specified MPEG-1 video image. 

SIZE_MPEG1VIDEOINFO(
pv)

Parameters

pv
Pointer to the MPEG1VIDEOINFO structure that specifies the video image.

Return Values

Returns the byte size of the specified MPEG1VIDEOINFO structure.
