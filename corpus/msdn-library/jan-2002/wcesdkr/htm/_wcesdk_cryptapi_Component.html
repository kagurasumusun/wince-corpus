cryptapi Component

The cryptapi component supports cryptography. Cryptography provides a way to distribute files in secret code, or cipher, so that only intended recipients can read them. Cryptography ensures data integrity and secure communication in your Windows CE–based application.

Functions for Application Developers

The cryptapi component includes the following functions for application developers, which are defined in the Wincrypt.h header file. To import these functions, you need to link to the cryptapi.lib file.
