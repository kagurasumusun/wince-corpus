FreeMediaType

Frees a task-allocated AM_MEDIA_TYPE structure from memory. 

void WINAPI FreeMediaType(
AM_MEDIA_TYPE& mt);

Parameters

mt
Address of the structure.

Return Values

No return value.

Remarks

The structure should have been initialized by a call to CopyMediaType.
