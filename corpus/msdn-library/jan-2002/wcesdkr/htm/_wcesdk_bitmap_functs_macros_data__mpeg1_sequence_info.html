MPEG1_SEQUENCE_INFO

Retrieves the sequence header for the specified MPEG-1 video image. 

MPEG1_SEQUENCE_INFO(
pv)

Parameters

pv
Pointer to an MPEG1VIDEOINFO structure.

Return Values

Returns the bSequenceHeader data member of the specified MPEG1VIDEOINFO structure.
