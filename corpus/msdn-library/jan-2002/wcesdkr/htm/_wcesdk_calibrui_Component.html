calibrui Component

The calibrui component implements the user interface for calibration. This component is responsible for drawing the various screens used when calibrating the touch screen.

Functions for Operating System Developers

The calibrui component includes the following functions for operating system configuration, which are defined in the ClaibrUi.h header file.
