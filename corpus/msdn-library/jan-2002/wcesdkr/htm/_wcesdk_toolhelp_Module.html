toolhelp Module

The toolhelp module implements the ToolHelp debugger and supports the ToolHelp API functions.

Functions for Application Developers

The toolhelp module contains the following functions for application developers, which are defined in the Toolhelp.h header file. To import these functions, you need to link to the toolhelp.lib file.
