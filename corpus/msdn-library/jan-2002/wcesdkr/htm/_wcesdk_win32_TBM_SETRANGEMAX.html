TBM_SETRANGEMAX

This message sets the maximum position for the slider in a trackbar. 

TBM_SETRANGEMAX wParam = (WPARAM) fRedraw;
lParam = (LPARAM) lMaximum;

Parameters

fRedraw
Redraw flag. If set to TRUE, the trackbar is redrawn after the range is set. If set to FALSE, the message sets the range but does not redraw the trackbar.
lMaximum
Maximum position for the slider.

Return Values

None.

Remarks

If the current slider position is greater than the new maximum, the TBM_SETRANGEMAX message sets the slider position to the new maximum value.
