IInputMethod2::SetImData

This method is implemented to respond to an application’s request to set input method (IM)-specific data within the IM.

HRESULT SetImData(
DWORD dwSize,
void *pvImData);

Parameters

dwSize
Specifies the size of the buffer pointed to by pvImData.
pvImData
Void pointer to a data buffer in the application. The application is providing information for the IM. The size and format of the data are defined by the IM.

Return Values

An appropriate HRESULT value is returned.

Remarks

Use this method and IInputMethod2::GetImData to send data to and from an application.

On Windows CE for the Palm-size PC, the input panel calls SetImInfo when an application has asked to alter IM-specific information in the SipSetInfo function. This is done by the application providing a non-null pointer for the pvImData member of the SIPINFO structure. The application can then pass information directly to the IM.
