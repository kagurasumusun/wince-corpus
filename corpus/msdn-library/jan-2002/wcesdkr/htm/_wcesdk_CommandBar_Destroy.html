CommandBar_Destroy

This macro destroys the command bar. 

void CommandBar_Destroy(
HWND hwndCB);

Parameters

hwndCB
Handle to the command bar’s window. This handle is returned by the CommandBar_Create function when the command bar is created.

Return Values

None.

Remarks

The CommandBar_Destroy function calls the DestroyWindow function to destroy the command bar. If the command bar’s parent window is being destroyed, it is not necessary to call CommandBar_Destroy.
