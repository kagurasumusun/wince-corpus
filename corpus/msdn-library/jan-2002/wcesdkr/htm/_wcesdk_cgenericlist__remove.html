CGenericList::Remove

Removes the specified node from the list. 

OBJECT *Remove(
POSITION pos );

Parameters

pos
Position in the list of nodes to remove.

Return Values

Returns the pointer to the object that was removed.

Remarks

This member function calls the CBaseList::RemoveI member function.
