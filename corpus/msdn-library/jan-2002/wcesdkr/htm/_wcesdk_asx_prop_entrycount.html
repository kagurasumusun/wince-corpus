EntryCount

Retrieves the number of entries contained in the current Advanced Stream Redirector (ASX) file.

Compatibility: Windows Media Player

[ iCount = ]MediaPlayer.EntryCount

Parameters

iCount
Integer value specifying the number of ENTRY elements in the current ASX file. If there are no entries in the ASX file, the value is zero.

Remarks

This property is read-only.

See Also

GetCurrentEntry, SetCurrentEntry, GetMediaParameter, GetMediaParameterName
