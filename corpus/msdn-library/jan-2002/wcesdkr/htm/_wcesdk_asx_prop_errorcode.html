ErrorCode

Retrieves a value specifying the current error code.

Compatibility: Windows Media Player

[ lErrCode = ] MediaPlayer.ErrorCode

Parameters

lErrCode
Long value specifying the current error code. This property is read-only.

ErrorDescription, HasError, SendErrorEvents
