TreeView_SetImageList

This macro sets the normal or state image list for a tree-view control and redraws the control using the new images. You can use this macro or send the TVM_SETIMAGELIST message explicitly.

HIMAGELIST TreeView_SetImageList(
hwnd,
himl,
iImage );

Parameters

hwnd
Handle to the tree view control.
himl
Handle to the image list. If himl is NULL, the message removes the specified image list from the tree view control.
iImage
Type of image list to set. It is one of the following values:

Value Description
TVSIL_NORMAL Indicates the normal image list, which contains selected, nonselected, and overlay images for the items of a tree view control.
TVSIL_STATE Indicates the state image list. You can use state images to indicate application-defined item states. A state image is displayed to the left of an item’s selected or nonselected image.

Return Values

The HIMAGELIST handle to the previous image list, if any, indicates success. NULL indicates failure.

Remarks

Related message: TVM_SETIMAGELIST
