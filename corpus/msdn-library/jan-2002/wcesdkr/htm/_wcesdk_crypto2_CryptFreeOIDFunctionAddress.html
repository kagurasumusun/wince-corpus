CryptFreeOIDFunctionAddress

This function releases a handle returned by the CryptGetOIDFunctionAddress or CryptGetDefaultOIDFunctionAddress function by decrementing the reference count on the function handle. In some cases, the DLL file associated with the function is unloaded. For more information, see the Remarks section later in this topic.

BOOL WINAPI CryptFreeOIDFunctionAddress(
HCRYPTOIDFUNCADDR hFuncAddr,
DWORD dwFlags
);

Parameters

hFuncAddr
[in] Handle of the function previously obtained from a call to the CryptGetOIDFunctionAddress or CryptGetDefaultOIDFunctionAddress function.
dwFlags
[in] Reserved for future use and must be zero.

Return Values

If the function succeeds, the return value is nonzero (TRUE).

If the function fails, the return value is zero (FALSE).

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 or later Wincrypt.h   Crypt32.lib
