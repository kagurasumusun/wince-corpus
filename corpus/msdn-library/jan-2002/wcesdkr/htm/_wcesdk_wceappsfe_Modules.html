wceappsfe Modules

The wceappsfe module group supports the following Windows CE application modules: Microsoft Pocket Word and Microsoft Pocket Outlook.

The wceappsfe modules support group contains the following modules.

Module Description Notes Library
IMAP4 Microsoft Exchange Server client-server messaging and groupware module. Exposes no public functions. Imap4.lib
LABLEDIT Pocket Inbox module. Exposes no public functions. Labledit.lib
MAILUTIL Pocket Inbox module. Exposes no public functions. Mailutil.lib
MSGSTORE Pocket Inbox module. Exposes no public functions. Msgstore.lib
OFFICE Supports Microsoft pocket applications. Exposes no public functions. Office.lib
PIMPRINT Supports Microsoft pocket applications. Exposes no public functions. Pimprint.lib
PMAIL Pocket Inbox module. Exposes no public functions. Pmail.lib
PWD_RES Supports Microsoft Pocket Word. Exposes no public functions. Pwd_res.lib
PWORD Supports Microsoft Pocket Word. Exposes no public functions. Pword.lib
PWWIFF Supports Microsoft Pocket Word. Exposes no public functions. Pwwiff.lib
RICHED20 Supports Microsoft pocket applications. Exposes no public functions. Riched20.lib
SMTP Supports the Simple Mail Transfer Protocol (SMTP). Exposes no public functions. Smtp.lib
TNEFEX Supports the Transport Neutral Encapsulation Format (TNFE) utilities; Pocket Inbox module. Exposes no public functions. Tnefex.lib
TNEFU Supports the Transport Neutral Encapsulation Format (TNFE) utilities; Pocket Inbox module. Exposes no public functions. Tnefu.lib
