CSource::AddPin

Adds a pin to the source filter. 

HRESULT AddPin(
CSourceStream *pStream );

Parameters

pStream
Pointer to the CSourceStream object associated with the pin.

Return Values

Returns S_OK if successful, or E_OUTOFMEMORY if no memory is available.
