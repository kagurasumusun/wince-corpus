fspass Component

The fspass component supports password functionality.

Functions for Operating System Developers

The fspass component includes the following functions for operating system configuration, which are defined in the Winbase.h header file. To import these functions, you need to link to the fspass.lib file.

Function
CheckPassword
GetPasswordActive
SetPassword
SetPasswordActive

Functions for Application Developers

The fspass component includes the following function for application developers, which is defined in the Winbase.h header file. To import this function, you need to link to the fspass.lib file.

Function
CheckPassword
