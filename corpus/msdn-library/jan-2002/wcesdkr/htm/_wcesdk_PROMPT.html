PROMPT

This command changes the command prompt for the command processor.

PROMPT [text]

Parameters

text
Specifies a new command prompt.

Remarks

A prompt can consist both of normal characters and the following codes for special characters or sequences of characters:

Code Special Character
$A ampersand (&)
$B pipe (|)
$C left parenthesis
$D current date
$E escape code, ASCII code 27
$F right parenthesis
$G greater than sign (>)
$L less than sign (<)
$P current path
$Q equal sign (=)
$S space
$T Current time
$_ Carriage return and line feed
$$ Dollar sign ($)
