waveOutBreakLoop

This function breaks a loop on a specified waveform output device and allows playback to continue with the next block in the driver list.

MMRESULT waveOutBreakLoop(
HWAVEOUT hwo );

Parameters

hwo
Handle to the waveform-audio output device.

Return Values

One of the values described in the following table is returned.

Value Description
MMSYSERR_NOERROR Success.
MMSYSERR_INVALHANDLE Specified device handle is invalid.
MMSYSERR_NODRIVER No device driver is present.
MMSYSERR_NOMEM Unable to allocate or lock memory.

Remarks

The blocks making up the loop are played to the end before the loop is terminated.

Calling this function when nothing is playing or looping has no effect, and the function returns zero.

Requirements
