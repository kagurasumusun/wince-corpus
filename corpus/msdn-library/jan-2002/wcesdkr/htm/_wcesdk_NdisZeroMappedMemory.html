NdisZeroMappedMemory

This function fills a block of memory that was mapped with a preceding call to the NdisMMapIoSpace function with 0s.

VOID NdisZeroMappedMemory(
IN PVOID Destination,
IN ULONG Length );

Parameters

Destination
Specifies the base virtual address of a block of mapped memory.
Length
Specifies the number of bytes to be filled with 0s.

Remarks

An network adapter driver can call this function to 0-initialize mapped device memory. The given Destination and Length must be a proper subrange of the range specified when the driver called the NdisMMapIoSpace function.

This function is optimized, and a network adapter driver can call this function any time that it needs to clear a mapped memory range.
