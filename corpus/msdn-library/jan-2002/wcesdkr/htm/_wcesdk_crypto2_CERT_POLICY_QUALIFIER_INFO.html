CERT_POLICY_QUALIFIER_INFO

This structure contains an object identifier specifying the qualifier and qualifier-specific supplemental information.

The CERT_POLICY_QUALIFIER_INFO structure is a component of the CERT_POLICY_INFO structure.

typedef struct _CERT_POLICY_QUALIFIER_INFO {
LPSTR pszPolicyQualifierId;
CRYPT_OBJID_BLOB Qualifier;
} CERT_POLICY_QUALIFIER_INFO,  *PCERT_POLICY_QUALIFIER_INFO;

Members

pszPolicyQualifierId
Object identifier (OID) specifying the qualifier.
Qualifier
The CRYPT_OBJID_BLOB structure containing qualifier-specific supplemental information.
