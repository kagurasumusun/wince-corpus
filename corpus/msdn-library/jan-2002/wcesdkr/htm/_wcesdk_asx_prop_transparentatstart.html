TransparentAtStart

Sets or retrieves a value specifying whether the Microsoft® Windows Media™ Player control image output window is transparent before play begins.

Compatibility: Windows Media Player

MediaPlayer.TransparentAtStart [ = bTransparent ]

Parameters

bTransparent
Boolean value specifying whether the Windows Media Player control is transparent before play begins and after play ends. If true, the control is transparent. This property is read/write with a default value of false.
