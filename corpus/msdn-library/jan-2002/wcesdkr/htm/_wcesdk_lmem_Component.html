lmem Component

The lmem component provides local heap and memory allocation.

Functions for Application Developers

The lmem component includes the following functions for application developers, which are defined in the Winbase.h header file. To import these functions, you need to link to the lmem.lib file.

Function
GetProcessHeap
HeapAlloc
HeapCreate
HeapDestroy
HeapFree
HeapReAlloc
HeapSize
LocalAlloc
LocalFree
LocalReAlloc
LocalSize
