DeleteMediaType

Deletes a task-allocated AM_MEDIA_TYPE structure. 

void WINAPI DeleteMediaType(
AM_MEDIA_TYPE *pmt);

Parameters

pmt
Pointer to an AM_MEDIA_TYPE structure.

Return Values

No return value.

Remarks

The structure should have been created by a call to CreateMediaType.
