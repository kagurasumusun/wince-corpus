ITask::Save

This method is not supported in Windows CE Platform Builder 3.0.

This method saves a Task item.

HRESULT Save();

Return Values

S_OK indicates that the Task item was saved successfully. If the Task cannot be saved, the appropriate HRESULT value is returned.

Code Example [Visual Basic]

The following Visual Basic® code snippet creates and saves a task:

Sub CreateTask(polApp As PocketOutlook.Application)
Dim polTask As PocketOutlook.TaskItem
Set polTask = polApp.CreateItem(olTaskItem)
polTask.Subject = “A Task”
polTask.StartDate = #4/5/1999#
polTask.DueDate = #5/5/1999#
polTask.Importance = olImportanceHigh
polTask.Save
End Sub

Code Example [C++]

The following C++ code snippet creates and saves a task:

void CreateTask(IPOutlookApp *polApp)
{
ITask *pTask;
SYSTEMTIME st;
DATE date;

// Create task
polApp->CreateItem(olTaskItem, (IDispatch **) &pTask);
pTask->put_Subject(TEXT(“A Task”));

// Convert Monday, 4/5/99 to a DATE
memset(&st, 0, sizeof(SYSTEMTIME));
st.wMonth = 4;
st.wDay = 5;
st.wYear = 1999;
polApp->SystemTimetoVariantTime(&st, &date);

// Set the start date and save the task
polTask->put_StartDate(date);
polTask->put_Importance(olImportanceHigh);
polTask->Save()

// Release objects
pTask->Release();
}
