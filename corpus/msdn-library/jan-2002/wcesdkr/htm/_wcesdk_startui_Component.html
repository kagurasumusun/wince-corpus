startui Component

The startui component implements the user interface for the startup screen. This implementation shows the user name, information, notes, and so on.

Functions for Operating System Developers

The startui component includes the following functions for application developers, which are defined in the Startui.h header file.

Function
Startup_Initialize
Startup_DlgProc
Startup_WantStartupScreen
Startup_PowerOnNotification
Startup_PowerOffWhileStartupActiveNotification
