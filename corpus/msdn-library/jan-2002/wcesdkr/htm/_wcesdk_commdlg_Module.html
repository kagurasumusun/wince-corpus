commdlg Module

The commdlg module supports the implementation of common dialog boxes. Common dialog boxes are system-defined dialog boxes that standardize how users perform common, complex operations.

Functions for Application Developers

The commdlg module contains the following functions for application developers, which are defined in the Commdlg.h header file. To import these functions, you need to link to the commdlg.lib file.

Function
ChooseColor
CommDlgExtendedError
PageSetupDlg
PrintDlg
