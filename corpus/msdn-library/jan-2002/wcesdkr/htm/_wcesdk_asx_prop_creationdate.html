CreationDate

Retrieves a value specifying the date and time when the clip was created.

Compatibility: Windows Media Player

[ dCreation = ] MediaPlayer.CreationDate

Parameters

dCreation
Date value specifying the date and time when the clip was created. This property is read-only and the default value is Sat Dec 30 00:00:00 PST 1899.

Remarks

This property returns valid data only if the FileName property is set.
