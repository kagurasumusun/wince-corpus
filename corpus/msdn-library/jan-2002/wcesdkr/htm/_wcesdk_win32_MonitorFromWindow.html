MonitorFromWindow

This function retrieves a handle to the display monitor that has the largest area of intersection with the bounding rectangle of a specified window. 

HMONITOR MonitorFromWindow(
HWND hwnd,
DWORD dwFlags
);

Parameters

hwnd
[in] Handle to the window of interest.
dwFlags
[in] DWORD that determines the return value of the function when the window does not intersect any of the display monitors. It is one of the following values:

Value Description
MONITOR_DEFAULTTONEAREST Return value is a handle to the display monitor that is nearest to the window.
MONITOR_DEFAULTTONULL Return value is NULL.
MONITOR_DEFAULTTOPRIMARY Return value is a handle to the primary display monitor.

Return Values

If the window intersects one or more display monitor rectangles, the return value is an HMONITOR handle to the display monitor that has the largest area of intersection with the window. If the window does not intersect a display monitor, the return value depends on the value of dwFlags.

Remarks

If the window is currently minimized, MonitorFromWindow uses the rectangle of the window before it was minimized.
