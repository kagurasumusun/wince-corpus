CGenericList::Get

Retrieves the object at the specified position. 

OBJECT *Get(
POSITION pos );

Parameters

pos
Position in the list from which to retrieve the object.

Return Values

Returns a pointer to an object.

Remarks

This member function calls the CBaseList::GetI member function.
