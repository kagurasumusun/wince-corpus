Volume

Sets or retrieves a value specifying the volume, in hundredths of decibels.

Compatibility: Windows Media Player, ActiveMovie

MediaPlayer.Volume [ = lVolume ]

Parameters

lVolume
Long value specifying the volume, in hundredths of decibels. This property is read/write with a default value of –600.

Remarks

Possible values for this property are from –10,000 to zero. Zero specifies full volume and –10,000 specifies no volume.

Not all devices support 10,000 discrete steps of volume.
