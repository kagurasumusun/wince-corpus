CB_GETCOUNT

This message is sent by an application to retrieve the number of items in the list box of a combo box. 

CB_GETCOUNT wParam = 0; lParam = 0;

Return Values

The number of items in the list box indicates success. CB_ERR indicates that an has occurred.

Remarks

The index is zero-based, so the returned count is one greater than the index value of the last item.
