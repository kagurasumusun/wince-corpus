CQueue::CQueue

Constructs a CQueue object. 

CQueue(
int n );
CQueue( );

Parameters

n
Size of the queue to create.

Return Values

No return value.

Remarks

If constructed with no parameters, the size of the queue is set to DEFAULT_QUEUESIZE.
