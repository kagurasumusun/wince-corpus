DIBSIZE

Calculates the byte size of the specified (device-independent) bitmap. 

DIBSIZE(
bi)

Parameters

bi
A Win32 BITMAPINFOHEADER structure that specifies the source bitmap.

Return Valuess

Returns the byte size of the bi parameter.
