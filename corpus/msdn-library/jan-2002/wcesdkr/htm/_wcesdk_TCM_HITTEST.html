TCM_HITTEST

This message determines which tab, if any, is at a specified screen position. You can send this message explicitly or by using the TabCtrl_HitTest macro. 

TCM_HITTEST wParam = 0;
lParam = (LPARAM)(TC_HITTESTINFO FAR *) pinfo;

Parameters

pinfo
Pointer to a TCHITTESTINFO structure that specifies the screen position to test.

Return Values

The index of the tab indicates success. –1 indicates that no tab is at the specified position.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
