CSource::FindPinNumber

Retrieves the number of the pin supporting a given IPin interface. 

int FindPinNumber(
IPin *iPin );

Parameters

iPin
IPin interface of the pin to retrieve.

Return Values

Returns the pin number or –1 if no matching pin number is found.
