msgque Component

The msgque component provides message-queueing support.

Functions for Application Developers

The msgque component includes the following functions for application developers, which are defined in the Winuser.h header file. To import these functions, you need to link to the msgque.lib file.

Function
DispatchMessage
GetMessage
GetMessagePos
GetMessageSource
MsgWaitForMultipleObjects
MsgWaitForMultipleObjectsEx
PeekMessage
PostMessage
PostQuitMessage
PostThreadMessage
SendMessage
SendNotifyMessage
