IPegasusFileFilter : IUnknown

This interface is implemented by a file converter DLL. The Pocket Internet Explorer uses OLE to create an instance of an IPegasusFileFilter object.

Methods Description
IPegasusFileFilter::FilterOptions Displays a dialog box that lets the user select among the file filtering options supported by a file filter.
IPegasusFileFilter::FormatMessage Formats a message string.
IPegasusFileFilter::NextConvertFile Called by the Pocket Internet Explorer when the user selects a conversion type from the Pocket Internet Explorer conversion selection dialog box.

Requirements

Runs On Versions Defined in Include Link to
Windows CE OS 1.0 and later Replfilt.h
