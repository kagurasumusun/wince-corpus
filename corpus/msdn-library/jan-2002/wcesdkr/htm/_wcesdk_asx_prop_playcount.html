PlayCount

Sets or retrieves a value indicating the number of times a clip plays.

Compatibility: Windows Media Player, ActiveMovie

MediaPlayer.PlayCount [ = lCount ]

Parameters

lCount
Long value indicating the number of times a clip plays. This property is read/write with a default value of 1.

Remarks

If the value of this property is zero, the clip plays repeatedly, restarting as soon as it reaches the end.
