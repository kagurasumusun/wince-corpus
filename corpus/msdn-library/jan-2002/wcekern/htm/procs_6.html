Improving Timer and Scheduling Management

Windows CE 3.0 adds several features that enable you to control how much time a thread is scheduled for and how much data a thread loads. Windows CE 3.0 also improves timer efficiency and adds functions that enable you to time threads. The following sections explain how to effectively utilize these added features.
