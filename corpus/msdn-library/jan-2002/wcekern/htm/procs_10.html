Timing a Thread

The GetThreadTimes function obtains timing information for a thread. For Windows CE 2.10, GetThreadTimes returns the total time a thread has been running.

The Windows CE 3.0 release enhances GetThreadTimes by returning the thread creation time, how much time the thread has been executing in kernel mode, and how much time the thread has been executing in user mode. These times do not include time spent executing system threads or waiting in a suspended or blocked state. If the thread has exited, GetThreadTimes returns the thread exit time.
