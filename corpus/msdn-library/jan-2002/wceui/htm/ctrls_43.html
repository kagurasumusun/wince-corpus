Using Advanced List View Features

In Windows CE, you can set the order of the columns that display in report view by setting the iOrder member in the LVCOLUMN structure when you add a column to a list view control. You also can set the column order by using the LVM_GETCOLUMNORDERARRAY and LVM_SETCOLUMNORDERARRAY messages.

To display an image from an image list next to the title of a column in report view, specify LVCF_IMAGE in the mask member and LVCFMT_IMAGE in the fmt member. When you add a column to a list view control, specify the zero-based index of an image in the list in the iImage member of the LVCOLUMN structure.

List view controls in Windows CE support a custom draw service, which enables you to customize the appearance of a list view. If a list view provides this service, it sends the NM_CUSTOMDRAW message at specific times during drawing operations.

Windows CE supports a list view style for creating a virtual list view, which is LVS_OWNERDATA. The only data that a virtual list view manages is data that is related to input focus and item selection. All other data is managed by the owner of the list view. This restriction on the amount of data that the virtual list view manages enables a list view to handle very large data sets, especially when the data is stored in a database that has its own methods for data access.
