Creating a Multiple-Part Status Bar

A status bar can have many different parts, with each displaying a different line of text. You divide a status bar into parts by sending the parent window an SB_SETPARTS message, which specifies the number of parts to be created and the address of an integer array. The array contains one element for each part, and each element specifies the client coordinate of the right edge of a part.

A status bar can have a maximum of 255 parts, although applications typically use fewer parts. You retrieve a count of the parts in a status bar, as well as the coordinate of the right edge of each part, by sending the window an SB_GETPARTS message.

The status bar has a simple mode that is useful for displaying Help text for menu items while a user scrolls through the menu. You can put a status bar in simple mode by sending it an SB_SIMPLE message. In simple mode, a status bar displays only one part. When the text of the window is set, the window is invalidated, but the window is not redrawn until the next WM_PAINT message. Waiting for the message reduces screen flicker by minimizing the number of times that the window is redrawn.

The string that a status bar displays while in simple mode is maintained separately from the strings that it displays while it is not in simple mode. This means that you can put the window in simple mode, set its text, and switch out of simple mode without the original text being changed.

Windows CE supports a message related to the status bar, known as SBN_SIMPLEMODECHANGE, that a status bar sends when the simple mode changes as a result of receiving an SB_SIMPLE message.
