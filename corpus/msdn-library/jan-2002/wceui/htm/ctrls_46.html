Adding and Editing Item Labels

Typically, you specify the text of the label of an item when you add the item to the tree-view control. The TVM_INSERTITEM message includes a TVITEM structure that defines the properties of the item, including a string that contains the text of the label.

A tree-view control allocates memory for storing each item; the text of the item labels takes up a significant portion of this memory. If you maintain a copy of the strings in the tree-view control, you can decrease the memory requirements of the control by specifying the LPSTR_TEXTCALLBACK value in the pszText member of TVITEM, instead of passing actual strings to the tree view. Using LPSTR_TEXTCALLBACK causes the tree-view control to retrieve the text of the label of an item from the parent window when the item needs to be redrawn.

A user can directly edit the labels of items in a tree-view control that has the TVS_EDITLABELS style. A user begins editing by clicking the label of the item that has the focus. An application begins editing by using the TVM_EDITLABEL message. The tree-view control notifies the parent window when editing begins, and when editing is canceled or completed. When a user or application completes editing, the parent window is responsible for updating the label of the item, if appropriate.

When a user begins editing the label, a tree-view control sends its parent window a TVN_BEGINLABELEDIT notification message. By processing this notification message, an application can accept the editing of some labels and reject the editing of others. Returning zero accepts editing, and returning nonzero rejects editing.

When a user cancels or completes editing the label, a tree-view control sends its parent window a TVN_ENDLABELEDIT notification message. The pszText member of TVITEM is zero if editing is canceled.
