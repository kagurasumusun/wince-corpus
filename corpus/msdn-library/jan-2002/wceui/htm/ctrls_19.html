Choosing a Control Style

In Windows CE, you can use only the SS_CENTERIMAGE style in conjunction with the SS_BITMAP style.




The following code shows how to use the SS_BITMAP style.



SendMessage( hStatic, STM_SETIMAGE, IMAGE_BITMAP, (LPARAM) hBitmap );




If you specify the SS_CENTERIMAGE style and do not specify either the SS_ICON style or the SS_BITMAP style, the static control behaves as if you had specified the SS_BITMAP style.



Windows CE does not support the SS_SIMPLE style, but you can emulate this style by using the SS_LEFT or SS_LEFTNOWORDWRAP style. Windows CE also does not support the SS_BLACKFRAME, SS_BLACKRECT, SS_GRAYFRAME, SS_GRAYRECT, SS_OWNERDRAW, SS_WHITEFRAME, and SS_WHITERECT styles, but you can use the WM_PAINT message to achieve the same results.
