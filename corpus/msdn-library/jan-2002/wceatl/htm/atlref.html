ATL for Windows CE Reference

The ATL for Windows CE Reference contains documentation for all the Active Template Library classes supported in the SDKs included in this eMbedded Visual Tools package.

Windows CE supports almost all of the standard Active Template Library classes. Because Windows CE runs on platforms that are different from the desktop Windows platforms, it has some different requirements. In order to meet these requirements, the designers of Windows CE have made changes to a few of the classes in the library.

For more information, see Differences between ATL for Windows CE and Standard ATL.

A typical reference page (topic) includes the following elements:

Syntax
Appears in a shaded area near the top of the page.
Parameters
Provide details regarding the arguments in the syntax
Remarks
Consist of explanations and notes for using the element.
Sample code
Provides a snippet to demonstrate use of the element.
Requirements
Provides information on the
  • Version of Windows CE required.
    Example: Windows CE versions: 2.11 and later
  • Name of the header file that contains the declaration code. Header files are found in an include directory under each SDK.
    Example: Header file: Atlbase.h
  • Window CE platform(s) that this element will run on. This release of the documentation includes support for the H/PC Pro, Palm-size PC 1.2, and Pocket PC platforms. (The Palm-size PC 1.2 may appear in the IDE as "Palm-size PC 2.11"—a reference to the Windows CE version on which it is based.)
    Example: Platform: Pocket PC
See also
Provides links to related topics.
