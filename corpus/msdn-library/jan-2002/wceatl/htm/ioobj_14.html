IOleObjectImpl::GetExtent

This method retrieves the display size in HIMETRIC units (0.01 millimeter per unit) of a running control. The size is stored in the m_sizeExtent data member.

STDMETHOD ( GetExtent )(
DWORD dwDrawAspect, 
SIZEL *psizel );

Parameters

dwDrawAspect
[in] Value indicating the aspect of the object whose limit is to be retrieved; the value is obtained from the enumerations DVASPECT and from DVASPECT2. Note that newer objects and containers that support optimized drawing interfaces support the DVASPECT2 enumeration values. Older objects and containers that do not support optimized drawing interfaces may not support DVASPECT2. The most common value for this method is DVASPECT_CONTENT, which specifies a full rendering of the object within the container.
*psizel
[out] Pointer to where the size of the object is to be returned.

Remarks

A container calls IOleObjectImpl::GetExtent on a running object to retrieve the current display size for it. If the container can accommodate that size, it will normally do so because the object, knows what size it should be better than the container does. A container normally makes this call as part of initializing an object.

The display size returned by GetExtent may differ from the size last set by IOleObject::SetExtent because the latter method dictates the display space of the object, at the time the method is called but does not necessarily change the native size of the object, as determined by the application.

Requirements
