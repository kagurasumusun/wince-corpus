CComTearOffObject::m_pOwner

This data member is a pointer to a CComObject derived from the owner class. The pointer is initialized to NULL during construction.

CComObject<Owner>* m_pOwner;

Parameters

Owner
[in] The class for which a tear-off is being implemented.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
