IRunnableObjectImpl::LockRunning

This method locks the control into the running state.

Most implementations of IRunnableOBjectImpl::LockRunning call CoLockObjectExternal.

OleLockRunning is a helper function that conveniently repackages the functionality offered by IRunnableObjectImpl::LockRunning. With the release of OLE 2.01, the implementation of OleLockRunning was changed to call QueryInterface, ask for IRunnableObjectImpl, and then call IRunnableObjectImpl::LockRunning. In other words, you can use the interface and the helper function interchangeably.

STDMETHOD ( LockRunning )(
BOOL fLock,
BOOL fLastUnlockCloses );

Parameters

fLock
[in] TRUE locks the object into its running state. FALSE unlocks the object from its running state.
fLastUnlockCloses
[in] TRUE specifies that if the connection being released is the last external lock on the object, the object should close. FALSE specifies that the object should remain open until closed by the user or another process.

Return Value

S_OK
If the value of fLock is TRUE, the object was successfully locked; if the value of fLock is FALSE, the object was successfully unlocked.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
