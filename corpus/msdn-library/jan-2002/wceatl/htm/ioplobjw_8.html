IOleInPlaceObjectWindowlessImpl::SetObjectRects

The container calls this method to inform the control that its size and/or position has changed.

Updates the m_rcPos data member and the control display for the control. Only the part of the control that intersects the clip region is displayed. If a control display was previously clipped but the clipping has been removed, this function can be called to redraw a full view of the control. 

STDMETHOD ( SetObjectRects )(
LPCRECT prcPos,
LPCRECT prcClip );

Parameters

prcPos
Pointer to the position of the in-place object.
prcClip
Pointer to the outer rectangle containing the in-place position rectangle for the object.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
