CComPtr::operator =

This operator assigns a pointer to the operand.

T* operator =(
T* lp ); 

T* operator =(
CComQIPtr< T, piid >& lp );

T* operator =(
const CComPtr< T >& lp );

Remarks

When assigning a pointer type derived from T, the operator sets p to the given T*. When assigning a CComPtr, the operator sets p to the member pointer of lp.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
