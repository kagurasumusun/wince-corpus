IViewObjectExImpl::GetExtent

This method retrieves the display size of the control in HIMETRIC units (0.01 millimeter per unit) from the m_sizeExtent data member.

The OLE-provided implementation of IViewObject2::GetExtent searches the cache for the size of the view object.

The GetExtent method in the IOleObject interface provides some of the same information as IViewObject2::GetExtent.

This method must return the same size as DVASPECT_CONTENT for all the new aspects in DVASPECT2. IOleObject::GetExtent must do the same thing.

If one of the new aspects is requested in dwAspect, this method can either fail or return the same rectangle as for the DVASPECT_CONTENT aspect.

STDMETHOD ( GetExtent )(
DWORD dwDrawAspect, 
LONG lindex, 
DVTARGETDEVICE* ptd, 
LPSIZEL lpsizel );

Parameters

dwDrawAspect
[in] Requested view of the object whose size is of interest. Valid values are taken from the enumerations DVASPECT and from DVASPECT2. Note that newer objects and containers that support optimized drawing interfaces support the DVASPECT2 enumeration values. Older objects and containers that do not support optimized drawing interfaces may not support DVASPECT2.
lindex
[in] Portion of the object that is of interest. Currently only -1 is valid.
ptd
[in] Pointer to the DVTARGETDEVICE structure defining the target device for which the size of the object should be returned.
lpsizel
[out] Pointer to where the size of the object is returned.

Return Value

This method supports the standard return value E_OUTOFMEMORY, as well as the following:

S_OK
The extent of the object was successfully returned.
OLE_E_BLANK
An appropriated cache is not available.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
