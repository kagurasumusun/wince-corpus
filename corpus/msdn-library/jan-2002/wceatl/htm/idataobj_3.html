IDataObjectImpl::DUnadvise

This method terminates a connection previously established through DAdvise.

STDMETHOD ( DUnadvise )(
DWORD dwConnection );

Parameters

dwConnection
[in] DWORD token that specifies the connection to remove. Use the value returned by IDataObjectImpl::DAdvise when the connection was originally established.
