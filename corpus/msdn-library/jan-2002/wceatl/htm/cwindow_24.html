CWindow::GetDlgItemText

The first implementation of this method retrieves the text from a control. The second implementation of this method allows you to copy the text in a control to a BSTR. It returns TRUE if the text is successfully copied; otherwise, it returns FALSE.

The GetDlgItemText function sends a WM_GETTEXT message to the control.

UINT GetDlgItemText(
int nID,
LPTSTR lpStr,
int nMaxCount )
const; 

BOOL GetDlgItemText(
int nID,
BSTR& bstrText )
const;

Parameters

nID
[in] Specifies the identifier of the control that receives the message.
lpStr
[out] Pointer to the buffer to receive the title or text.
nMaxCount
[in] Specifies the maximum length, in characters, of the string to be copied to the buffer pointed to by lpStr. If the length of the string exceeds the limit, the string is truncated.
bstrText
Unicode string that contains the text for the control.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
