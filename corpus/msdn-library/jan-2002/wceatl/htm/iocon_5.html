IOleControlImpl::OnMnemonic

This method informs the control that a user has pressed a specified keystroke. 

STDMETHOD ( OnMnemonic )(
LPMSG pMsg );

Parameters

pMsg
[in] Pointer to the MSG structure describing the keystroke to be processed.

Return Value

The ATL implementation returns E_NOTIMPL.

Remarks

If a control changes the contents of its CONTROLINFO structure, it must notify its container by calling IOleControlSiteImpl::OnControlInfoChanged.

A container of a control is allowed to cache the CONTROLINFO structure of the control, provided that the container implements IOleControlSiteImpl::OnControlInfoChanged to know when it must update its cached information.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
