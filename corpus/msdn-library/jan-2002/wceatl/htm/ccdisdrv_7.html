CComDispatchDriver::operator IDispatch*

This operator converts a CComDispatchDriver object to an IDispatch pointer by returning the p data member. 

operator IDispatch*( );

Remarks

If the CComDispatchDriver object is pDD, the following two statements are equivalent:

pMyDisp=(IDispatch*)(pDD)
pMyDisp= pDD.p

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
