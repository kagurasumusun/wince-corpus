ISpecifyPropertyPagesImpl::GetPages

This method fills the array in the CAUUID structure with the CLSIDs for the property pages that can be displayed in the property sheet of the object. ATL uses the property map of the object to retrieve each CLSID.

The CAUUID structure is caller-allocated, but is not initialized by the caller. The ISpecifyPropertyPagesImpl::GetPages method fills the cElements field in the CAUUID structure. This method also allocates memory for the array pointed to by the pElems field in CAUUID using CoTaskMemAlloc. Then, it fills the newly allocated array. After this method returns successfully, the structure contains a counted array of UUIDs, each UUID specifying a property page CLSID.

STDMETHOD ( GetPages )(
CAUUID* pPages );

Parameters

pPages
[out] Pointer to a caller-allocated CAUUID structure that must be initialized and filled before returning. The pElems field in the CAUUID structure is allocated by the callee with CoTaskMemAlloc and freed by the caller with CoTaskMemFree.

Return Value

This method supports the standard return value E_UNEXPECTED, as well as the following:

S_OK
The array was filled successfully.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
