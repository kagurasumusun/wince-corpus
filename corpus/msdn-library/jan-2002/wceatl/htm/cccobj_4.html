CComContainedObject::GetControllingUnknown

This method returns the m_pOuterUnknown member pointer, that is inherited through the Base class, which holds the IUnknown of the owner object. This method may be virtual if Base has declared the DECLARE_GET_CONTROLLING_UNKNOWN macro.

IUnknown* GetControllingUnknown( );

Return Value

The IUnknown of the owner object.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also

CComObjectRootEx::m_pOuterUnknown, DECLARE_GET_CONTROLLING_UNKNOWN
