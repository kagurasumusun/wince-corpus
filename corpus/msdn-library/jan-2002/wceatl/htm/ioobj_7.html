IOleObjectImpl::DoVerbInPlaceActivate

This method activates the control in place. If activation succeeds, the method notifies the container the control has been activated.

Activates the control in place by calling CComControl::InPlaceActivate. Unless the data member m_bWindowOnly of the control class is TRUE, DoVerbInPlaceActivate first attempts to activate the control as a windowless control. This activation attempt is possible only if the container supports IOleInPlaceSiteWindowless. If that fails, the function attempts to activate the control with extended features. This activation attempt is also possible only if the container supports IOleInPlaceSiteEx. If that fails, the function attempts to activate the control with no extended features. Again, this activation attempt is possible only if the container supports IOleInPlaceSite. If activation succeeds, the function notifies the container the control has been activated.

HRESULT DoVerbInPlaceActivate(
LPCRECT prcPosRect ,
HWND hwndParent );

Parameters

prcPosRect
[in] Pointer to the rectangle the container wants the control to draw into.
hwndParent
[in] Handle of the window containing the control. Not used in the ATL implementation.

Return Value

One of the standard HRESULT values.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
