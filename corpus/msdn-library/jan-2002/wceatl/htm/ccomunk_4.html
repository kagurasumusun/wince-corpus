CComUnkArray::end

This method returns a pointer to one past the last IUnknown pointer in the collection.

IUnknown** end( );

Return Value

A pointer to an IUnknown interface pointer.

Remarks

The CComUnkArray methods begin and end can be used to loop through all connection points. For example, both methods will loop through all connection points when an event is fired.

IUnknown** p = m_vec.begin();
while(p != m_vec.end())
{
   // Do something with *p.
   p++;
}

Requirements

  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
