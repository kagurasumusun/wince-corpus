IOleObjectImpl

This class implements the IOleObject interface through which a container communicates with a control.

The IOleObject interface is the principle interface through which a container communicates with a control. The IOleObjectImpl class provides a default implementation of this interface and implements IUnknown by sending information to the dump device in debug builds.
