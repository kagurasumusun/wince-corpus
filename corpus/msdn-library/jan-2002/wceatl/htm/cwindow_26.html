CWindow::GetFont

This method retrieves the current font of a window by sending a WM_GETFONT message to the window.

HFONT GetFont( )
const;

Return Value

A font handle.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
