IQuickActivateImpl::GetContentExtent

This method retrieves the current display size for a running control. The size is for a full rendering of the control and is specified in HIMETRIC units.

STDMETHOD ( GetContentExtent )(
LPSIZEL pSize );

Parameters

pSize
Pointer to LPSIZEL that receives the display size for a control.

Return Value

S_OK
The content extent was successfully returned.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
