IViewObjectExImpl

This class implements the IViewObject, IViewObject2, and IViewObjectEx interfaces. These interfaces support a variety of control display features.

The IViewObject, IViewObject2, and IViewObjectEx interfaces enable a control to display itself directly, and to create and manage an advise sink to notify the container of changes in the control display. The IViewObjectEx interface provides support for extended control features such as flicker-free drawing, non-rectangular and transparent controls, and hit-testing. For example, the IViewObjectEx interface can show how close a mouse click must be to be considered on the control. Class IViewObjectExImpl provides a default implementation of these interfaces and implements IUnknown by sending information to the dump device in debug builds.
