IPropertyPageImpl::Deactivate

This method destroys the dialog box window created with Activate.

It is important that property pages not keep the dialog box around as an optimization. In a property sheet with many property pages, memory consumption would become excessive if all property pages kept their dialog boxes created at all times. Destroying the dialog box prevents excessive memory consumption due to a very large number of created controls in the dialog boxes. If the frame wishes to keep pages alive while they are not visible, it can use IPropertyPageImpl::Show for that purpose. The decision is ultimately left to the frame.

STDMETHOD ( Deactivate )( void );

Return Value

This method supports the standard return value E_UNEXPECTED, as well as the following:

S_OK
The dialog was successfully destroyed.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
