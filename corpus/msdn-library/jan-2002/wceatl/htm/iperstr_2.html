IPersistStreamInitImpl::GetClassID

The IPersistStreamInitImpl::GetClassID method retrieves the class identifier, CLSID, for an object, used in later operations to load object-specific code into the context of the caller.

STDMETHOD ( GetClassID )(
CLSID *pClassID );

Parameters

*pClassID
[out]Points to the location of the CLSID on return. The CLSID is a globally unique identifier (GUID) that uniquely represents an object class that defines the code that can manipulate the data of the object.

Return Values

S_OK
The CLSID was successfully retrieved.
E_FAIL
The CLSID could not be retrieved.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
