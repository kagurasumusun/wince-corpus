IOleInPlaceObjectWindowlessImpl::OnWindowMessage

This method dispatches a message from a container to a windowless control that is in-place active.

A container calls this method to send window messages to a windowless object that is in-place active

STDMETHOD ( OnWindowMessage )(
UINT msg, 
WPARAM wParam, 
LPARAM lParam, 
LRESULT *plResult );

Parameters

msg
Message identifier as passed by Windows CE.
wParam
As passed by Windows CE. Specifies additional message-specific information. The contents of this parameter depend on the value of the msg parameter.
lParam
As passed by Windows CE. Specifies additional message-specific information. The contents of this parameter depend on the value of the msg parameter.
*plResult
Windows CE result code. Specifies the result of the message processing and depends on the message sent.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
