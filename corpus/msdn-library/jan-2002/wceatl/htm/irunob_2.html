IRunnableObjectImpl::GetRunningClass

This method returns the CLSID of the running control. The ATL implementation sets lpClsid to GUID_NULL.

If an embedded document was created by an application that is not available on the user's computer, the document, by a call to CoTreatAsClass, may be able to display itself for editing by emulating a class that is supported on the user's machine. In this case, the CLSID returned by a call to IRunnableObjectImpl::GetRunningClass will be that of the class being emulated, rather than the native class of the document.

STDMETHOD ( GetRunningClass )(
LPCLSID lpClsid );

Parameters

lpClsid
[out] Pointer to the class identifier of an object.

Return Value

This method returns the standard return value E_UNEXPECTED.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
