IPersistStorageImpl::InitNew

This method initializes a new storage. The ATL implementation delegates to the IPersistStreamInit interface.

A container application can call this method when it needs to initialize a new object, such as, with an InsertObject command.

An object that supports the IPersistStorageImpl interface must have access to a valid storage object at all times while it is running. This includes the time just after the object has been created but before it has been made persistent. The container of the object must provide the object with a valid IStorage pointer to the storage during this time through the call to IPersistStorageImpl::InitNew. Depending on the state of the container, a temporary file might have to be created for this purpose.

If the object wants to retain the IStorage instance, it must call IUnknown::AddRef to increment its reference count.

After the call to IPersistStorageImpl::InitNew, the object is in either the loaded or running state. For example, if the object class has an in-process server, the object will be in the running state. However, if the object uses the default handler, the call from the container to InitNew only invokes the implementation of the handler which does not run the object. Later if the container runs the object, the handler calls the IPersistStorageImpl::InitNew method for the object.
