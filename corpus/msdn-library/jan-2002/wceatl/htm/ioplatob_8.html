IOleInPlaceActiveObjectImpl::TranslateAccelerator

This method processes menu accelerator-key messages from the container. 

STDMETHOD ( TranslateAccelerator )(
LPMSG pMsg );

Parameters

pMsg
Pointer to the MSG structure describing the keystroke to be processed.

Return Value

The ATL implementation returns E_NOTIMPL.

Remarks

An object created by an EXE object application gets keystrokes from its own message pump, so the container does not get those messages.

If you need to implement this method, you wrap the call to the TranslateAccelerator function of the Window.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
