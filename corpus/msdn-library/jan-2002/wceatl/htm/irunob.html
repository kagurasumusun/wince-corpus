IRunnableObjectImpl

This class implements the IRunnableObject interface, which enables a container to force a control to run, lock it into a running state, or determine if it is running.

The IRunnableObjectImpl class provides a default implementation of this interface and implements IUnknown by sending information to the dump device in debug builds.
