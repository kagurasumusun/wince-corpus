CComVariant

The CComVariant class wraps the VARIANT type, which consists of a tagged union, as well as a member indicating the value type stored in the union and is typically used with Automation. 

class CComVariant : public tagVARIANT

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
