IOleObjectImpl::DoVerbPrimary

This method defines the action taken when the user double-clicks the control. By default, set to display the property pages. For example, to play a video or go in-place active, override this in your control class to invoke a different behavior on double-click. 

HRESULT DoVerbPrimary(
LPCRECT prcPosRect ,
HWND hwndParent );

Parameters

prcPosRect
[in] Pointer to the rectangle the container wants the control to draw into.
hwndParent
[in] Handle of the window containing the control.

Return Value

One of the standard HRESULT values.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
