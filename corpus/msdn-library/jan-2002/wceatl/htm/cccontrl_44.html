CComControl::SetDirty

This method sets the m_bRequiresSave data member to the value in bDirty. You should call SetDirty(TRUE) to flag that the control has changed since it was last saved. The value of m_bRequiresSave is retrieved with GetDirty.

void SetDirty(
BOOL bDirty );

Parameters

bDirty
[in] Value of the data member m_bRequiresSave.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
