CWindow::IsChild

This method determines whether the specified window is a child window.

BOOL IsChild(
HWND hWnd )
const;

Parameters

hWnd
Handle to the window to be tested.

Return Values

Nonzero indicates that the window is a child or descendant window of the specified parent window. Zero indicates that the window is not a child or descendant window of the specified parent window.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
