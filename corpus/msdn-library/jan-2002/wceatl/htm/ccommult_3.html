CComMultiThreadModel::Increment

This method increments the specified variable in a thread-safe way. 

static ULONG WINAPI Increment(
LPLONG p );

Parameters

p
[in] Pointer to the variable to be incremented.

Return Value

If the result of the increment is zero, then Increment returns zero. If the result of the increment is nonzero, the return value is also nonzero but may not equal the result of the increment.

Remarks

This static method calls the Windows CE function InterlockedIncrement, which increments the value of the variable pointed to by p. InterlockedIncrement prevents more than one thread from simultaneously using this variable.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
