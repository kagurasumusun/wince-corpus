CWindow::GetDlgCtrlID

This method retrieves the identifier of a window, for child windows only.

GetDlgCtrlID accepts child window handles as well as handles of controls in dialog boxes. An application sets the identifier for a child window when it creates the window by asigning the identifier value to the hmenu parameter when calling the CreateWindow or CreateWindowEx function.

int GetDlgCtrlID( )
const;

Return Values

The identifier of the control indicates success. Zero indicates failure. For example, an invalid value for the hwndCtl parameter, will cause the function to fail. To get extended error information, call GetLastError.

Requirements

  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
