CComModule::Init

This method initializes all data members.

HRESULT Init(
_ATL_OBJMAP_ENTRY* p,
HINSTANCE h,
const GUID* plibid = NULL );

Parameters

p
[in] A pointer to an array of object map entries.
h
[in] The HINSTANCE passed to DLLMain or WinMain.
plibid
[in] A pointer to the LIBID of the type library associated with the project.

Return Value

A standard HRESULT value.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
