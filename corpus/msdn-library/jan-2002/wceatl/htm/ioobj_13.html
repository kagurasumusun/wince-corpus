IOleObjectImpl::GetClientSite

This method puts the pointer in the m_spClientSite data member into ppClientSite and increments the reference count on the pointer.

Link clients most commonly call the IOleObjectImpl::GetClientSite method in conjunction with the IOleClientSite::GetContainer method to traverse a hierarchy of nested objects. A link client calls IOleObjectImpl::GetClientSite to get a pointer to the client site of the link source. The client then calls IOleClientSite::GetContainer to get a pointer to the container of the link source. Finally, the client calls IOleContainer::QueryInterface to get IOleObjectImpl and IOleObjectImpl::GetClientSite to get the client site for the container within the container. By repeating this sequence of calls, the caller can eventually retrieve a pointer to the master container in which all the other objects are nested.

STDMETHOD ( GetClientSite )(
IOleClientSite **ppClientSite );

Parameters

ppClientSite
[out] Address of IOleClientSite pointer variable that receives the interface pointer to the client site of the object. If an object does not yet know the client site, or if an error has occurred, **ppClientSite must be set NULL. Each time an object receives a call to IOleObjectImpl::GetClientSite, it must increase the reference count on **ppClientSite. It is the responsibility of the caller to call Release when it is done with **ppClientSite.
