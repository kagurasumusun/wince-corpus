CRegKey::DeleteValue

This method removes a value field from m_hKey. 

LONG DeleteValue(
LPCTSTR lpszValue );

Parameters

lpszValue
[in] Specifies the value field to remove.

Return Value

If successful, returns ERROR_SUCCESS; otherwise, it is an error value.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
