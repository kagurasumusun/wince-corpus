AtlAxGetHost

This global function obtains a direct interface pointer to the container for a specified window, given its handle. 

ATLINLINE ATLAPI AtlAxGetHost(
HWND h,
IUnknown** pp);

Parameters

h
[in] A handle to the window that is hosting the control.
pp
[out] The IUnknown of the container of the control.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlhost.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
