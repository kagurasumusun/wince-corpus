CComQIPtr::operator <

Checks if the internal pointer is less than another pointer.

bool operator <(
T* pT )
const;

Parameters

pT
[in] Pointer to be compared with the internal pointer.

Return value

Returns TRUE if the internal pointer is less than another pointer; otherwise it is FALSE.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
