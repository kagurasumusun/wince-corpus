CDialogImpl::DialogProc

This method processes the messages sent to the dialog box.

The DialogProc static method implements the dialog box procedure and uses the default message map to direct messages to the appropriate handlers.

You can override DialogProc to provide a different mechanism for handling messages.

static LRESULT CALLBACK DialogProc(
HWND hWnd,
UINT uMsg,
WPARAM wParam,
LPARAM lParam );

Parameters

hWnd
[in] The handle to the dialog box.
uMsg
[in] The message sent to the dialog box.
wParam
[in] Additional message-specific information.
lParam
[in] Additional message-specific information.

Return Value

TRUE if the message is processed; otherwise, it is FALSE.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
