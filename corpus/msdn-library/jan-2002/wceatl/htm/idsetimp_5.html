IDispEventImpl::GetTypeInfoCount

This method retrieves the number of type information interfaces that an object provides (either 0 or 1).

The function may return zero, which indicates that the object does not provied any type information. In this case, the object may still be programmable through IDispatch or a VTBL, but does not provide run-time type information for browsers, compilers, or other programming tools that access type information. This can be useful for hiding an object from browsers.

STDMETHOD ( GetTypeInfoCount )(
UINT* pctinfo );

Parameters

pctinfo
Points to a location that receives the number of type information interfaces provided by the object. If the object provides type information, this number is 1; otherwise, the number is 0.

Return Values

The return value obtained from the returned STDMETHOD is one of the following:

Return value Description
S_OK Success
E_NOTIMPL Failure

Requirements

  Header file: Declared in Atlcom.h.
  Platform: H/PC Pro, Palm-size PC, Pocket PC
