CComControl::FireOnChanged

This method calls CFirePropNotifyEvent::FireOnChanged to notify all connected IPropertyNotifySink interfaces that the specified control property has changed if your control class derives from IPropertyNotifySink. If your control class does not derive from IPropertyNotifySink, this method returns S_OK.

HRESULT FireOnChanged(
DISPID dispID );

Parameters

dispID
[in] Identifier of the property that has changed.

Return Value

One of the standard HRESULT values.

Remarks

This function is safe to call even if your control does not support connection points.

Example

STDMETHODIMP CMyCtrl::put_MyText(BSTR newVal)
{
// Store newVal in CComBstr member.
m_bstrMyText = newVal;

// Note the DISPID for the MyText property is 1 in this example.
FireOnChanged(1);

return S_OK;
}

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
