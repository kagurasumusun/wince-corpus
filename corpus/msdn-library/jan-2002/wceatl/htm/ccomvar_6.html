CComVariant::Copy

This method copies a VARIANT to the CComVariant object.

HRESULT Copy(
const VARIANT* pSrc );

Parameters

pSrc
[in] A pointer to the VARIANT to be copied

Return Value

A standard HRESULT value.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
