AtlSetChildSite

This global function sets the site of the child object to the IUnknown of the parent object. 

HRESULT AtlSetChildSite(
IUnknown* punkChild,
IUnknown* punkParent);

Parameters

punkChild
[in] A pointer to the IUnknown interface of the child.
punkParent
[in] A pointer to the IUnknown interface of the parent.

Return Value

A standard HRESULT value.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
