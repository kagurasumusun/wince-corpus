IPersistStorageImpl::IsDirty

This method checks whether data in the object has changed since it was last saved. The ATL implementation delegates to the IPersistStreamInit interface.

The dirty flag for an object is conditionally cleared in the IPersistStorageImpl::Save method.

For example, you could optimize a File::Save operation by calling the IPersistStorageImpl::IsDirty method for each object and then calling the IPersistStorageImpl::Save method only for those objects that are dirty.

Treat any error return codes as an indication that the object has changed. In other words, unless this method explicitly returns S_FALSE, assume that the object needs to be saved.

A container with one or more contained objects must maintain an internal dirty flag that is set whenever any of its contained objects are dirty.

STDMETHOD ( IsDirty )( void );

Return Values

S_OK
The object has changed since it was last saved.
S_FALSE
The object has not changed since the last save.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
