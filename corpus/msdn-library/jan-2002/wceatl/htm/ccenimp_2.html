CComEnumImpl::Init

This method initilizes the enumerator. You must call this method before passing a pointer to the enumerator interface back to any clients. Only call this method once—initialize the enumerator, use it, then throw it away.

static void init ( T** );

Remarks

If you pass pointers to items in an array held in another object and you do not ask the enumerator to copy the data, you can use the pUnk parameter to ensure that the object and the array it holds are available for as long as the enumerator needs them. The enumerator simply holds a COM reference on the object to keep it alive. The COM reference is automatically released when the enumerator is destroyed.

Requirements
