CComModule::UpdateRegistryFromResourceD

This method runs the script contained in the resource specified by lpszRes or nResID. If bRegister is TRUE, this method registers the object in the system registry; otherwise, it unregisters the object.

HRESULT WINAPI UpdateRegistryFromResourceD(
LPCTSTR lpszRes,
BOOL bRegister,
struct _ATL_REGMAP_ENTRY* pMapEntries = NULL );
 
HRESULT WINAPI UpdateRegistryFromResourceD(
UINT nResID,
BOOL bRegister,
struct _ATL_REGMAP_ENTRY* pMapEntries = NULL );

Parameters

lpszRes
[in] A resource name.
nResID
[in] A resource ID.
bRegister
[in] Indicates whether the object should be registered.
pMapEntries
[in] A pointer to the replacement map storing values associated with the replaceable parameters of a script. ATL automatically uses %MODULE%. To use additional replaceable parameters, see Remarks for details. Otherwise, use the NULL default value.

Return Value

A standard HRESULT value.

Remarks

By specifying the DECLARE_REGISTRY_RESOURCE or DECLARE_REGISTRY_RESOURCEID macro, UpdateRegistryFromResourceD will be invoked automatically when your object map is processed.

To substitute replacement values at run time, do not specify the DECLARE_REGISTRY_RESOURCE or DECLARE_REGISTRY_RESOURCEID macro. Instead, create an array of _ATL_REGMAP_ENTRIES structures, where each entry contains a variable placeholder paired with a value to replace the placeholder at run time. Then call UpdateRegistryFromResourceD, passing the array for the pMapEntries parameter. This adds all the replacement values in the _ATL_REGMAP_ENTRIES structures to the replacement map of the Registrar.

To statically link to the ATL Registry Component, the Registrar, see UpdateRegistryFromResourceS.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
