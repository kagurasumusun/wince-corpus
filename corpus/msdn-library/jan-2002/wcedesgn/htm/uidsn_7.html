User Input Devices

Input devices enable users to interact with the user interface. Windows CE supports several types of user input devices, such as a keyboard, a mouse, a touch screen, a stylus, and voice recognition, though input devices that are available on a specific device might vary. For general design considerations for user input devices, see The Windows Interface Guidelines for Software Design.
