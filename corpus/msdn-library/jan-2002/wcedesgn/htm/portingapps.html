Porting an Application to Windows CE

Because Windows CE is based on the Win32 API set, you should be able to port applications that were developed for a Windows-based desktop operating system to a Windows CE platform without major modifications. To optimize an application for a Windows CE-based platform, you need to consider the following differences between Windows CE and the other Windows-based desktop platforms:

  • Windows CE does not support 16-bit APIs, and only supports a subset of the entire Win32 API set. Some of the APIs used in the code of the desktop application might not be portable to Windows CE.
  • Windows CE features a unique set of extension APIs that might not have any counterparts in the Win32 API set.
  • The hardware design and functionality of most Windows CE-based platforms differs from desktop platforms.
  • The User Interface (UI) of most Windows CE-based platforms considerably differs from the UI featured in Windows desktop-based platforms.
  • Windows CE supports a subset of the development tools and programming environments that are available for Windows desktop-based platforms.
  • The Windows CE OS is based entirely on a Unicode environment.

The following chapter provides a set of guidelines on how to successfully port an application from a Windows-based desktop computer to a Windows CE-based platform.
