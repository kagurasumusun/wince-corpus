Hardware Considerations

Most Windows CE-based devices feature hardware configurations that considerably differ from the hardware setups found on most desktop-based devices. When porting an application from a desktop-based computer to a Windows CE-based platform you must consider the following hardware issues:

  • Because Windows CE is designed for devices that have a limited supply of memory and your target device might not have a disk drive or any other mass-storage device, you must limit the RAM requirements of your application and associated data and resources.
  • If you port an application to a Windows CE-based platform that operates on batteries you need to consider the limited power resources on the Windows CE-based device. Avoid cycling the CPU unnecessarily by calling energy-consuming functions such as PeekMessage. To check whether your application consumes too much battery power, you can poll the system by calling the GetPowerStatusEx function to determine the battery status.
    • Because most Windows CE-based devices have limited power resources, you need to limit the use of common desktop computer hardware that consumes a large amount of battery power, such as a modem.
