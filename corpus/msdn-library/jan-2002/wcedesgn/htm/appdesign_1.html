Basic Programming Considerations

When creating an application for a Windows CE-based platform you need to consider various programming issues that are specific to the Windows CE OS.

Windows CE is based on the Win32 API set. To develop Windows CE-based applications, you must familiarize yourself with the Win32 programming environment. Because Windows CE is designed for embedded platforms and is much smaller than Windows NT or other Windows desktop-based operating systems, it does not support the entire set of Win32 APIs. Conversely, Windows CE also features APIs that were specifically designed for embedded systems and therefore are not supported by Windows-based desktop platforms.

Before you start writing your application, you first need to understand how the target platform is configured. The configuration of the target platform determines what kind of user interface and shell is required.

You also need to familiarize yourself with the hardware design of your target device. Some of the hardware features that are present in desktop-based platforms, such as a keyboard, are entirely missing from Windows CE-based platforms. You need to consider the following hardware factors when writing an application for a Windows CE-based platform:

  • Most CE-based systems do not run on an Intel x86 compatible microprocessor.
  • The target device might not include a keyboard or a screen display.
  • Most Windows CE-based devices do not use a mouse for user input, but instead let the user interact with the application by tapping on the touchscreen with a stylus.
  • The memory and power resources on different target devices might vary.
  • Most Windows CE-based devices don’t have a hard disk.
  • Because of limited memory resources, memory allocation might fail on a Windows-CE based platform.
