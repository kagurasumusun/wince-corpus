UI Considerations

Some of the greatest differences between a desktop computer and a Windows CE-based platform are in the UI. Differences in UI design also exist between the various Windows CE-based platforms. You need to take all these differences in UI design into consideration when porting an application from a desktop computer to a Windows CE-based device.

  • Windows CE-based devices generally feature smaller screens that are less flexible to communicate information. You might have to modify your application to fit in these smaller constraints. When porting an application to a Windows CE-based device make sure not to code static layouts because different target devices can have different screen dimensions and aspect ratios. Instead, use the GetSystemMetrics function to obtain the screen dimensions and use those to define window size.
  • The available palette can be quite restricted. Some devices support a color screen, although probably with a more restricted palette than a typical PC. Some Windows CE-based devices support only grayscale graphics with a low resolution. When porting an application make sure that bitmaps and icons are in an appropriate format for the target device. LCD screens can be difficult to view in some settings, so keep the contrast as high as possible
  • Some Windows CE-based platforms might entirely lack a screen, so that you might have to develop a different method to communicate information.
  • Most Windows CE-based platforms do not feature a mouse-like pointing device, but instead use a touch screen or stylus to enable the user to input information and navigate the UI. Some Windows CE-based devices might not have a pointing device at all, but instead use arrow keys, hardware buttons or speech recognition for user interaction.
  • Most Windows CE-based devices are too small to support a full-size keyboard. The keyboards on most devices are rather small and might not contain a full set of alphanumeric characters. Many Windows CE-based platforms feature an input panel instead of a keyboard to enable the user to communicate with the application. The user can enter characters with the stylus by way of a touchscreen. Because character input through a touchscreen tends to be more difficult for user than via a keyboard, you might consider minimizing text entry via the touchscreen and instead select another method of user communication.

For a detailed set of guidelines on how to design a UI for a Windows CE-based platform see the chapter Designing a User Interface for Windows CE.
