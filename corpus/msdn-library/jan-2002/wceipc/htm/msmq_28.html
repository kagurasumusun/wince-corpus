Backing Up an MSMQ Installation

The Windows CE version of MSMQ can be backed up programmatically.

To backup MSMQ

  1. Stop MSMQ by issuing the following command: 
    MSMQADM.EXE -f \temp\msmqadm.exe stop

    The output file will be empty if MSMQ has been successfully stopped, or it will contain an error message if it was not.

  2. Back up the MSMQ registry key
    [HKEY_LOCAL_MACHINE\Software\Microsoft\MSMQ]
    and the MSMQ storage directory, which is given by value "BaseDir" of said key.
  3. On a fresh machine, you can restore the backup by installing MSMQ using the following command. 
    msmqadm.exe -f \temp\msmqadm.txt register install NETREG
  4. Instead of using the registration step above, restore the MSMQ registry key and contents of the MSMQ base directory, and then reboot MSMQ.

    Note   Backup/restore will perform very poorly in the presence of transactional queues. Because tracking transactional messages is distributed, information vital to consistency of the transactional queue is present on both the source and destination machines. If one machine is restored to some previous state when the other is not, consistency is irrevocably lost. The only practical way to back up machines in the presence of transactional queues is to stop both source and destination and then perform the backup.
