Log Files

Effective with version 3.0, Windows CE MSMQ supports logging. The log file is called MQLOGFILE.TXT and resides in the MSMQ storage directory. When MSMQ is started and stopped or a fatal error is encountered (such as a corrupt file or a request for connection from unidentified computer), the condition is logged. The size of the log is controlled by the “LogSize” DWORD value. When the file reaches half of the specified size, it is renamed MQLOGFILE.OLD and a new MQLOGFILE.TXT file is created.
