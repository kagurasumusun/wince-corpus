Security

There are two levels of security to consider when you implement a distributed application:

  • Network security refers to who can access a computer. At this security level, DCOM security on Windows CE 3.0 is equivalent to that of the Windows NT 4.0, SP5, implementation, which uses the Windows NT LAN Manager system security package (NTLMSSP).
  • Local security refers to what a user is permitted to do on a computer after gaining access. This security level is defined by the operating system on the target computer. Windows CE regulates access to critical system components as a whole, instead of on a resource-by-resource basis, as is done on Windows NT.

On DCOM in Windows CE , security checking consists of authentication and access control.
