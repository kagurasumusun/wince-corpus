Creating and Opening a Registry Key

Create a registry key by calling the RegCreateKeyEx function. Windows CE automatically opens the key after you create it. If the key already exists, a call to RegCreateKeyEx simply opens the key for processing. Also, you can use the RegOpenKeyEx function to open a key. The difference between these two functions is that RegOpenKeyEx does not create a new key if the key did not exist previously.
