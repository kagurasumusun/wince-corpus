IOCTL_COLLECTOR_UNREGISTER

This input/output control makes a request to call Ioctl_Unregister_DataCollector. This request is made by calling KernelIoControl with IOCTL_COLLECTOR_UNREGISTER.

Parameters

dwIoControlCode
Set to IOCTL_COLLECTOR_UNREGISTER. Supports calling Ioctl_Unregister_DataCollector.
lpInBuf
Set to Ioctl_Unregister_DataCollector PId parameter.
nInBufSize
Set to Ioctl_Unregister_DataCollector dwIDSize parameter.
lpOutBuf
Set to Ioctl_Unregister_DataCollector pBuffer parameter.
nOutBufSize
Set to Ioctl_Unregister_DataCollector dwBufSize parameter.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later
