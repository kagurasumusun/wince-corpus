Shell Components

To support certain shell functions, you can add the corresponding shell components. For example, if you plan to enable shortcuts on your shell, you can add the Shortcut component, which provides the SHCreateShortcut and SHGetShortcutTarget functions.

The following table shows the shell components that you can add and the functions they support.

Component Supported functions
Fileinfo SHGetFileInfo

SHGetSpecialFolderPath
Fileopen GetOpenFileNameW

GetSaveFileNameW
Shellapis Shell_NotifyIcon

SHAddToRecentDocs
Shexec ShellExecuteEx
Shmisc SHShowOutOfMemory

SHLoadDIBitmap
Shortcut SHCreateShortcut

SHGetShortcutTarget

Note To support nonstandard naming conventions on some platforms, and to enable users to rename some of the special folders if they choose to do so, ensure that you use the SHGetSpecialFolderPath function to find the name and location of a special folder.

In addition to these components, you can also add other shell components to supplement your Windows CE shell. These other shell components provide the following features:

  • Common controls
  • Common dialog boxes
  • Control Panel components

Refer to the Cesysgen.bat file in the Minshell configuration for an example of how to include other shell components.
