CEL_PROCESS_CLOSE

This structure identifies a process handle that has been closed using CloseHandle.

typedef struct __CEL_PROCESS_CLOSE {
HANDLE hProcess;
} CEL_PROCESS_CLOSE, *PCEL_PROCESS_CLOSE;

Members

hProcess
This is the handle of the process that has been closed.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Celog.h
