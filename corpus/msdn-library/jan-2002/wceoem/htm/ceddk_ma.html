READ_PORT_BUFFER_UCHAR

This macro reads a number of bytes from the specified port I/O address into a buffer.

VOID READ_PORT_BUFFER_UCHAR (
PUCHAR Port,
PUCHAR Buffer,
ULONG Count )

Parameters

Port
[in] Pointer to the port, which must be a mapped memory range in I/O space.
Buffer
[in] [out] Pointer to a buffer into which an array of UCHAR values is read.
Count
[in] Specifies the number of bytes to be read into the buffer.

Return Values

None.

Remarks

The size of the buffer must be large enough to contain at least the specified number of bytes.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ceddk.h
