Ioctl_Unregister_DataCollector

This function is called to unregister a logging engine from Collection Manager.

Ioctl_Unregister_DataCollector(
LPVOID pId,
DWORD dwIDSize,
LPVOID pBuffer,
DWORD dwBufSize );

Parameters

pId
Pointer to a buffer that stores an identifier that uniquely identifies the logging engine to Collection Manager. The default logging engine uses a GUID to uniquely identify itself.
dwIDSize
Size of the buffer pointed to by pID.
pBuffer
Pointer to a buffer in which Collection Manager writes a result.
dwBufSize
Size of the buffer pointed to by pBuffer.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Oemioctl.c
