IOCTL_SET_KERNEL_COMM_DEV

This input/output control supports a call to SetKernelCommDev. A request to call SetKernelCommDev is made by calling OEMIoControl with IOCTL_SET_KERNEL_COMM_DEV.

Parameters

dwIoControlCode
Set to IOCTL_SET_KERNEL_COMM_DEV. Supports a call to SetKernelCommDev.
lpInBuf
Not used; set to NULL.
nInBufsize
Contains the KERNEL_SVC flag; KERNEL_SVC_PPSH, for example.
lpOutBuf
Not used; set to NULL.
nOutBufSize
Contains the kernel comm flag; KERNEL_COMM_ETHER, for example.
lpBytesReturned
Not used; may be set to NULL.

Return Values

If TRUE is returned, then the input/output control was successfully processed; otherwise, FALSE is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Pkfuncs.h
