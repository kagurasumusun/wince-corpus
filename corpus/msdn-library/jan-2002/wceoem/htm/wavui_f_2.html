waveui_BeforeDialogBox

This function displays the Format Choose or Filter Choose dialog box.

void waveui_BeforeDialogBox (
LPVOID pChooseStruct,
BOOL fIsFormatDialog);

Parameters

pChooseStruct
Pointer to the chooser structure.
fIsFormatDialog
Flag indicating whether the chooser structure is ACMFORMATCHOOSE, if the flag is TRUE, or ACMFILTERCHOOSE, if the flag is FALSE.

Return Values

None.

Remarks

This function is called right before DialogBoxParam is called.

The replaceable component could choose here, for instance, that the element fdwStyle should not allow the flag ACMFORMATCHOOSE_STYLEF_SHOWHELP for this project.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Waveui.c
