CeRegisterReplNotification

This function registers to receive object store and mounted database volume notifications.

BOOL CeRegisterReplNotification(
CENOTIFYREQUEST *pRequest
);

Parameters

pRequest
Pointer to a CENOTIFICATION structure that requests notifications be sent to an identified window. If pRequest is NULL, the previous notification request is removed.

Return Values

If the registration succeeds, then TRUE is returned; otherwise, FALSE is returned.

Remarks

Only one application can register to receive replication notification changes. If an application is already registered to receive notifications and a second application registers, the first application will loose all notifications. This can lead to a poor user experience.
