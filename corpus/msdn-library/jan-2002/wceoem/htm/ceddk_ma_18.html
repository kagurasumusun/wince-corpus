WRITE_REGISTER_BUFFER_UCHAR

This macro writes a number of bytes from a buffer to the specified register.

VOID WRITE_REGISTER_BUFFER_UCHAR (
PUCHAR Register,
PUCHAR Buffer,
ULONG Count )

Parameters

Register
[in] Pointer to the register, which must be a mapped range in memory space.
Buffer
[in] [out] Pointer to a buffer from which an array of UCHAR values is to be written.
Count
[in] Specifies the number of bytes to be written to the register.

Return Values

None.

Remarks

The size of the buffer must be large enough to contain at least the specified number of bytes.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ceddk.h
