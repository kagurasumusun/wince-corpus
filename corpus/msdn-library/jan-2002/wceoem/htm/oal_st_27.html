CEL_PROCESS_TERMINATE

This structure identifies a process that has terminated.

typedef struct __CEL_PROCESS_TERMINATE {
HANDLE hProcess;
} CEL_PROCESS_TERMINATE, *PCEL_PROCESS_TERMINATE;

Members

hProcess
Handle of the process that has terminated.
