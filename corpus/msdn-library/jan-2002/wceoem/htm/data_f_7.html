CeGetReplOtherBitsEx

This function gets a private replication bit that can be used by the replication process.

BOOL CeGetReplOtherBitsEx(
PCEGUID pguid,
CEOID oid,
LPDWORD lpbits
);

Parameters

pguid
Pointer to a CEGUID that identifies a mounted database volume or the internal object store.
oid
Object identifier to query.
lpbits
A buffer to a DWORD that stores a bit mask that can be used to detect if the private replication bit is sit or cleared. The mask returned is valid for only bit zero. The bit is either set or not set and the meaning is based on a how an application uses it.

Return Values

If the function succeeds, then TRUE is returned; otherwise, FALSE is returned. The value of lpbits will be either 0x0 or 0x1.
