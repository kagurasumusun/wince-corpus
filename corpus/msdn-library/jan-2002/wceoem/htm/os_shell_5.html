Common Controls

Common controls offer users a familiar interface for performing common tasks, which makes applications easier to learn and use. Most common controls send the WM_NOTIFY message instead of the WM_COMMAND message that is sent by window controls. To support common controls on your shell, include the Commctrl component in your Cesysgen.bat file. This component provides the following common controls:

  • Command band
  • Command bar
  • Date and time picker
  • Header control
  • Image list
  • List view
  • Month calendar control
  • Progress bar
  • Property sheet
  • Rebar
  • Status bar
  • Tab control
  • Toolbar
  • Tooltip
  • Trackbar
  • Tree view
  • Up-down control
