EDBG_BOOT_CALLBACK_FUNC

This function allows a desktop application to get called back whenever a BOOTME message is received from a device.

void EDBG_BOOT_CALLBACK_FUNC(
PVOID pParam,
PEDBG_BOOTME_DATA pBootmeData );

Parameters

pParam
Pointer to a parameter passed with a call to EdbgDeregisterBootCallback or EdbgRegisterBootCallback.
pBootmeData
Pointer to an EDBG_BOOTME_DATA message structure that contains Ethernet address information related to the target device.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ethdbg.h    

See Also

EDBG_BOOTME_DATA, EdbgDeregisterBootCallback, EdbgRegisterBootCallback
