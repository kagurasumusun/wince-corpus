ASSERT

This macro invokes the macro DBGCHK with a default (“Unknown”) module name.

ASSERT (Expression)

Return Values

None.

Remarks

This macro may be used to check the value of a Boolean expression and produce a DebugBreak if the expression evaluates FALSE. Calling this macro assumes that a global variable dpCurSettings has already been defined, where dpCurSettings must be a DBGPARAM structure. This macro calls the DBGCHK macro with a default (“Unknown”) module name.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Dbgapi.h
