lpParallelPortGetByteFunc

This global variable is defined in the kernel and points to the OEMParallelPortGetByte function by default.

int (*lpParallelPortGetByteFunc)(void);

Remarks

If the Cesh kernel services are redirected using SetKernelCommDev, the kernel modifies this pointer to point to a function that formats data appropriately for the specified transport.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Nkintr.h
