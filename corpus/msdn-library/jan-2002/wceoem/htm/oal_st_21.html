CEL_MUTEX_CREATE

This structure specifies that a mutex has been created.

typedef struct __CEL_MUTEX_CREATE {
HANDLE hMutex;
WCHAR szName[0];
} CEL_MUTEX_CREATE, *PCEL_MUTEX_CREATE;

Members

hMutex
Handle of the mutex that was created.
szName
Null-terminated string containing the name of the mutex that was created if specified. This corresponds to the lpName parameter of CreateMutex.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Celog.h
