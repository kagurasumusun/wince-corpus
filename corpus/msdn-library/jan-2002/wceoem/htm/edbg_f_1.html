EdbgCancelRegisterClient

This function cancels an EDBG client registration that is in progress.

BOOL EdbgCancelRegisterClient(
CHAR * ServiceName
CHAR * DeviceName );

Parameters

ServiceName
[in] Name of the service for which the client is being registered. This value is NULL terminated and has a maximum length of MAX_SVCNAME_LEN characters.
DeviceName
[in] Name of the device to communicate with, for example, Odo42.

Return Values

Returns TRUE is the client is successfully deregistered. Otherwise, returns FALSE.

Remarks

This function, when given a service name and a device name, deregisters an EDBG client that is in the process of registering. Because EdbgRegisterClient blocks either until an error occurs or until a connection is established, this function can be used to implement a time-out for the registration process. By using the EDBG_CFGFL_MULTIINST flag, multiple clients can register at the same time. In this case, this function cancels only one of the registrations.
