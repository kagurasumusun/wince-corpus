CEL_CRITSEC_LEAVE

This structure logs the event that occurs when a thread leaves a critical section that is being waited on by another thread.

typedef struct __CEL_CS_LEAVE {
HANDLE hCS;
HANDLE hOwnerThread;
} CEL_CRITSEC_LEAVE, *PCEL_CRITSEC_LEAVE;

Members

hCS
Handle of the critical section.
hOwnerThread
Handle of the thread that gets the critical section when the current thread leaves.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Celog.h
