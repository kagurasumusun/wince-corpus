waveui_Init

This function initializes a Waveui component.

void waveui_Init (void);

Return Values

None.

Remarks

This function is called at boot when Waveapi is loaded.

This function also informs the Waveui of the HINSTANCE that it can use to load resources.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Waveui.c
