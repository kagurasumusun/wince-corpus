EdbgResetDevice

This function sends a reset command to a device over the Ethernet debug interface. This function is supported only on a development workstation.

BOOL EdbgResetDevice(
CHAR *DeviceName,
UCHAR Id,
BOOL CleanBoot );

Parameters

DeviceName
[in] Character which is currently unsupported and must be NULL.
Id
[in] Identifier of the client registered using EdbgRegisterClient.
CleanBoot
[in] If TRUE, requests that the device object store be cleared before rebooting.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This function requires support for the original equipment manufacturer (OEM) I/O Control IOCTL_HAL_REBOOT. To guarantee that the device has actually been reset, applications can call EdbgRegisterBootCallback and wait for the BOOTME message from the device.

Only applications which have previously registered an EDBG client may call this function since the DeviceName parameter is currently unsupported.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ethdbg.h
