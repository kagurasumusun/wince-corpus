_SH4CacheLines

This variable defines the number of cache lines available to the kernel. By default, the SH4 ODO implementation sets this variable to 512.

Remarks

The variable must be declared in a code section, not a data section. If the value is not stored in a code section, the value will not be set properly when the kernel initializes.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later
