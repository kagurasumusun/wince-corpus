EdbgRegisterBootCallback

This function registers a routine with the Edbg.dll library to be called when BOOTME packets are received. This function is available only on the desktop.

BOOL EdbgRegisterBootCallback(
UCHAR Id,
EDBG_BOOT_CALLBACK_FUNC pCallBack,
PVOID pParam );

Parameters

Id
[in] Identifier of the client. Passing in ID_ALL_DEVICES registers callback for all devices.
pCallBack
[in] Pointer to the address in memory of the callback function.
pParam
[in] Pointer to the parameter to pass to the callback function (plus BOOTME data).

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This routine starts a thread to listen for the BOOTME packets that are broadcast by the Ethernet boot loader when a device is reset. The caller can register for a specific client or for all devices. Note that devices may send several BOOTME packets while waiting for commands from the development workstation; thus, not every callback necessarily indicates that a device has been reset.

This function is implemented only in Edbg.dll that is loaded by an application on the development workstation; it is not implemented in the OAL on the target device.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ethdbg.h   Edbg.dll
