WRITE_REGISTER_USHORT

This macro writes a USHORT value to the specified address.

VOID WRITE_REGISTER_USHORT (
PUSHORT Register,
USHORT Value )

Parameters

Register
[in] Pointer to the register, which must be a mapped range in memory space.
Value
[in] Specifies a USHORT value to be written to the register.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ceddk.h
