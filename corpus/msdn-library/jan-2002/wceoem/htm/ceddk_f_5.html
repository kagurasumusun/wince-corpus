MmMapIoSpace

This function maps the specified physical address range to nonpaged system space, providing a directly-mapped virtual address to the device.

PVOID MmMapIoSpace (
PHYSICAL_ADDRESS PhysicalAddress,
ULONG NumberOfBytes,
BOOLEAN CacheEnable );

Parameters

PhysicalAddress
[in] Specifies the starting physical address of the I/O range to be mapped.
NumberOfBytes
[in] Specifies the number of bytes to be mapped.
CacheEnable
[in] Indicates whether the physical address range can be mapped as cached memory. For device registers, this value is usually FALSE.

Return Values

This function returns the base virtual address that maps the base physical address for the range. If space for mapping the range is insufficient, this function returns NULL.

Remarks

Device drivers call this function during initialization to get a logical address for their device memory if a call to HalTranslateBusAddress indicates that the bus-relative device memory range can be mapped to system memory space. For example, drivers of PIO devices that allocate long-term I/O buffers can call this function to make such a buffer accessible or to make device memory accessible.
