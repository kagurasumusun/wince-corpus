CEL_SEM_DELETE

This structure identifies a semaphore that has been deleted from memory.

typedef struct __CEL_SEM_DELETE {
HANDLE hSem;
} CEL_SEM_DELETE, *PCEL_SEM_DELETE;

Members

hSem
Handle of the semaphore that was created.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Celog.h
