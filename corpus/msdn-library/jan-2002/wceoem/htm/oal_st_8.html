CEL_EVENT_SET

This structure is passed when an event is set with SetEvent.

typedef struct __CEL_EVENT_SET { 
HANDLE hEvent; 
} CEL_EVENT_SET, *PCEL_EVENT_SET;

Members

hEvent
Handle of the event that is being set.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Celog.h
