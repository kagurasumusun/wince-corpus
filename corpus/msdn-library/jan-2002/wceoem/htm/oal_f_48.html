OEMNMIHandler

This function enables a non-maskable interrupt (NMI) to be captured by an OEM.

void OEMNMIHandler (void);

Return Values

None.

Remarks

You must implement this function if you are targeting an x86 platform. This function is designed to handle critical power issues only. All critical power issues must be resolved in this function before returning to the kernel. Once this function returns to the kernel, the system is halted.

For a sample implementation of this function, see the CEPC platform source code in Fwpc.c, which is located in the %_WINCEROOT%\Platform\Cepc\Kernel\Hal\X86 directory.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Fwpc.c
