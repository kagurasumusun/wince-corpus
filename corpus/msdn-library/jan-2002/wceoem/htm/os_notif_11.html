Notification Messages and Message Buffers

The notification subsystem defines messages that you can use to determine functionality in the system. See the Notifext.hxx header file for details.

The following table shows the messages.

Message Description
WM_USER_ANNUNCIATOR Sent to the WndProc of the notification when the user clicks on an annunciator, one of the icons that are displayed in the tray on the Windows taskbar to represent an application that is running.
WM_USER_PACKET_DISPOSE Sent to inform the OEM that the UI parts of the notification packet are to be removed and to free the packet.
WM_USER_PACKET_NEW Received when a new modification packet has arrived. You must create the structure and appropriate UI.
WM_USER_ALARM Received when a user notification must be activated.

The notification subsystem defines the following buffer sizes:

SMALL_MESSAGE
SMALL_HEADER
BIG_MESSAGE

See the Notifext.hxx header file for details.
