CacheSync

This function flushes the cache.

VOID CacheSync (
int flags );

Parameters

flags
Can be one of the following:    

Value Description
CACHE_SYNC_DISCARD Write back and discard all cached data.
CACHE_SYNC_INSTRUCTIONS Discard all cached instructions.
CACHE_SYNC_WRITEBACK Write back but do not discard cached data.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Pkfuncs.h
