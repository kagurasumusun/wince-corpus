FATUIEvent

Implement this function to receive events of file allocation table (FAT) file system scans and disk formatting.

int FATUIEvent (
HANDLE hModule,
PCWSTR pszVol,
PFATUIDATA pfui );

Parameters

hModule
Handle to module containing string resources.
pszVol
Pointer to the name of the FAT file object store. If set to NULL, indicating that the volume could not be determined, FATUIEvent will set pszVol to IDS_FATUI_VOLUME_NAME as the default volume name.
pfui
Pointer to a FATUIDATA structure that characterizes the type of event.

Return Values

The following table shows the response flags that can be returned by this function.

Value Description
FATUI_NONE No action.
FATUI_YES Perform the specified action.
FATUI_NO Do not perform the specified action.
FATUI_DELETE Delete the specified file, directory, or cluster.
FATUI_CANCEL Cancel the current FAT file system operation.

Remarks

You may optionally implement your own version of this function and build the component as a library linked to the component FAT file system. Windows CE provides a default FATUI component.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Fatui.h
