SetKMode

This function allows an application to switch between kernel and user modes.

BOOL SetKMode (
BOOL fMode );

Parameters

fMode
Setting to TRUE enters kernel mode; setting to FALSE enters user mode.

Return Values

This function returns the mode prior to the current call to SetKMode: TRUE if previous mode was kernel mode; FALSE if previous mode was user mode.

Remarks

To allow nested operation, you can set fMode to the value returned from an initial call to SetKMode, in order to return to the original state.
