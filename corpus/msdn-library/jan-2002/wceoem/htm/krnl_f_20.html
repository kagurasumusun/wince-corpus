ProfilerHit

This function is implemented in the kernel and is called by the profiler ISR to record a profiling sample.

void ProfilerHit (
unsigned int ra );

Parameters

ra
Exception program counter (EPC) returned by GetEPC.

Return Values

None.

Requirements

Windows CE OS 3.0 and later
