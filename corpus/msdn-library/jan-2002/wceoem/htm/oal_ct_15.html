KD_IOCTL_ENUM_CBP

This input/output control is used to enumerate the code breakpoints that are set. It is passed to OEMKDIoControl.

Parameters

dwIoControlCode
Set to KD_IOCTL_ENUM_CBP.
lpBuf
Pointer to a buffer that allocates space for a KD_BPINFO structure.
nBufSize
Size of the buffer pointed to by lpInBuf. This is set to the size of the KD_BPINFO structure.

Remarks

The ulCount member of KD_BPINFO is incremented from 0 to n, where n is the number of available breakpoints.

Return Values

If TRUE is returned, then the input/output control was successfully processed; otherwise, FALSE is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Pkfuncs.h
