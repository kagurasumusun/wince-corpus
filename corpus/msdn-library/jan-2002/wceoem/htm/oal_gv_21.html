lpWriteDebugStringFunc

This global variable is defined in the kernel and points to the OEMWriteDebugString function by default.

void (*lpWriteDebugStringFunc)(unsigned short *str);

Remarks

If the Cesh kernel services are redirected using SetKernelCommDev, the kernel modifies this pointer to point to a function that formats data appropriately for the specified transport.

For debug message output in the OEM adaptation layer (OAL), call through this function pointer instead of directly calling OEMWriteDebugString. This ensures that debug message output is not lost if the debug message transport is redirected through SetKernelCommDev.
