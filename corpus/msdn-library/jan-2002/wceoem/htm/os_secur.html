Securing a Platform

Platform Builder allows you to secure your Windows CE–based platform by certifying applications before they run, thereby protecting your system from potentially unsafe applications. When certifying applications, you can designate a module as trusted or not trusted. The kernel can then use this information to prevent unauthorized applications from loading or to limit their access to the system.

In addition to certifying applications, you can also add a cryptographic service provider (CSP) to your system if you implement the Microsoft Cryptography application programming interface (CAPI). A CSP creates and destroys cryptographic keys and uses them to perform a variety of cryptographic operations. By allowing you to add CSPs, Platform Builder lets you select the CSPs with the encryption algorithms and key lengths that you want.
