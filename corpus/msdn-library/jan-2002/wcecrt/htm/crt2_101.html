_scalb

Scales argument by a power of 2.

Routine Required Header
_scalb <float.h> 

double _scalb( double x, long exp );

Parameters

x
Double-precision floating-point value
exp
Long integer exponent

Libraries

All versions of the C run-time libraries.

Return Values

_scalb returns an exponential value if successful. On overflow (depending on the sign of x), _scalb returns +/– HUGE_VAL.

Remarks

The _scalb function calculates the value of x * 2exp.
