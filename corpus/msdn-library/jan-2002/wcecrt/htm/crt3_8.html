_statusfp

Get the floating point status word.

Routine Required Header
_statusfp <float.h> 

unsigned int _statusfp( void );

Libraries

All versions of the C run-time libraries.

Return Value

The bits in the value returned indicate the floating-point status.

Many math library functions modify the 8087/80287 status word, with unpredictable results.

Remarks

The status word is a combination of the 8087/80287/80387 status word and other conditions detected by the 8087/80287/80387 exception handler, such as floating-point stack overflow and underflow. Unmasked exceptions are checked for before returning the contents of the status word. This means that the caller is informed of pending exceptions.
