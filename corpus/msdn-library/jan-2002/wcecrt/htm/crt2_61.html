isspace, iswspace

This routine returns nonzero if c is a particular representation of a space character.

Routine Required Header
isspace <ctype.h>
iswspace <ctype.h> 

int isspace( int c );
int iswspace( wint_t c );

Parameters

c
Integer to test

Libraries

All versions of the C run-time libraries.

Return Values

isspace returns a non-zero value if c is a white-space character (0x09 – 0x0D or 0x20). iswspace returns a non-zero value if c is a wide character that corresponds to a standard white-space character or is one of an implementation-defined set of wide characters for which iswalnum is false. Each of these routines returns 0 if c does not satisfy the test condition.

The result of the test condition for the isspace function depends on the LC_CTYPE category setting of the current locale. For iswspace, the result of the test condition is independent of locale.
