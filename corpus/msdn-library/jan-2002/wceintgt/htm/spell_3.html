Creating the Spelling-Checker Handle

A spelling session is defined as all of the resources that the spelling checker uses for a particular application, including any dictionaries and created structures. The first instruction that your spelling checker performs is to create a spelling-checker handle. Your application uses this handle to associate a call to a spelling-checker function call with a specific spelling session. Because a device can have several applications that use the spelling-checker engine, all of the functions in the spelling-checker API use the spelling-checker handle to distinguish different spelling sessions.
