Receiving Spelling Suggestions from the Spelling Checker

After you have determined that a word in the input buffer of the SPLBUFFER structure is misspelled, you should call the SplSuggest function. Like the SplReplace function, the SplSuggest function returns one or more suggestions for a misspelled word. However, SplReplace can return up to eight possible suggestions.

In addition to returning spelling suggestions, the SplSuggest function also can “score” the suggestions. A score is a number that indicates how much a replacement word differs from the original misspelled word. A low score indicates that the misspelled word was changed slightly, while a high score indicates that the word was changed a great deal. You can use suggestion scores in your application to exclude some words from the list of alternatives.

After the SplSuggest function finishes processing, you can access the output buffer through the aspl parameter of the SPLBUFFER structure. The aspl parameter is an array of SPLSUGGEST structures. The first member of a SPLSUGGEST structure points to a word in the output buffer. If you choose to use scores, the second member contains a score for that word.

To receive spelling suggestions from the spelling checker

  1. If you want to use scores, set SPL_SCORE_SUGGESTIONS by using the SplSetOptions function.
  2. Set the size and location of the output buffer by using the cwcOut and pwszOut parameters of the SPLBUFFER structure.

    This SPLBUFFER structure is the same structure that is returned by your original call to the SplCheck function.

  3. Set the aspl, cwcUsed, and cspl parameters of the SPLBUFFER structure to receive the appropriate data.

    The SplSuggest function returns an array of pointers to the output buffer in the aspl parameter, the size of the output buffer that is used in the cwcUsed parameter, and the number of suggestions in the cspl parameter.

  4. Call the SplSuggest function.
