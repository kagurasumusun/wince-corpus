Running Silent Mode Setup from the Command Line

ActiveSync 3.0 Setup runs Silent Mode if it is called with certain command-line parameters. The simplest way to start Setup in silent mode is to use the "silent" keyword on the command line. This command-line keyword causes setup to use the default settings. The following example shows how to execute silent mode from the command line.

D:\Main\Setup.exe silent

If you have special needs and want to control the behavior of Setup, create a Silent.ini file or modify the sample Silent.ini file. To use the sample INI file, put the full path and filename of the INI file in quotes on the command line. Note that the path can be relative or absolute. The following samples show how to call a Silent.ini file from the command line. 

D:\Main\Setup.exe "silent.ini"
D:\Main\Setup.exe "\\Server\Public\Microsoft ActiveSync\silent.ini"

It is important to note that the ActiveSync setup program (setup.exe) is located in the Main directory on the ActiveSync CD. The ActiveSync setup program is not the Setup.exe application located in the root directory. For ActiveSync to work properly, you must have the Main directory and all its subdirectories as they are on the CD.
