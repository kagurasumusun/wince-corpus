Between the Network and Transport Layers and Session Layer

Windows Sockets (Winsock), and Simple Network Management Protocol (SNMP) operate between the session layer and the network and transport layers.

The Windows Sockets API is an open, public specification based on the Berkeley (BSD) Sockets APIs. Windows CE 3.0 continues to support a subset of Winsock 1.1 specification. The Winsock interface may be used to communicate using both the TCP/IP and IrDA protocols. Windows CE version 3.0 support extensions to the Winsock 1.1 specification known as IrSock to handle ad hoc networking using Infrared.

For more information on Winsock, see Windows Sockets.

New to Windows CE 3.0 is Simple Network Management Protocol (SNMP). Windows CE version 3.0 supports SNMPv2c agent and it is possible to add third-party providers, known as Management Information Bases (MIBs). Windows CE version 3.0 ships with 3 MIBs, MIB II (supports the TCP/IP stack), Host MIB (supports info about the host device), and a sample MIB (providing an example for third-parties to implement their own MIB). Note SNMP is source code compatible with Windows NT, thus MIBs written for Windows NT can be easily ported to Windows CE.

For more information on SNMP, see Simple Network Management Protocol Agent Support.
