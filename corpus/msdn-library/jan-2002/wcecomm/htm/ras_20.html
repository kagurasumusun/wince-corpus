Connection Registry Settings

Registry settings are DWORDS in the key HKLM\Comm\ppp\Parms.

AckDupCR   // Send ack for a CR with same Identifier as previously acked CR if non-0
MaxCRRetries   // Number of times to resend a CR when not getting an ACK before giving up
MaxTRRetries   // Number of times to resend a TR when not getting an ACK before giving up
MaxCRFails   // Max number of RCR_M events before giving up (fail to converge)
ReqTimeoutMillis   // Time to wait before resending a CR or TR when no ACK received
