The Backlog Parameter

Windows Sockets server applications generally create a socket and then use the listen() function on it to listen for connection requests. One of the parameters passed when calling listen() is the backlog of connection requests that the application would like Windows Sockets to queue for it. The Windows Sockets 1.1 specification indicates that the maximum allowable value for backlog is 5. Windows CE accepts a backlog of 5.
