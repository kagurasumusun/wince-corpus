Frequently Asked Questions About DHCP on Windows CE

  • How does Windows CE networking handle suspend and resume?

    Because Windows CE has no way of knowing whether a network card was removed and reinserted while suspended, which might place the device on a different network, Windows CE treats suspend and resume the same as net card extraction and reinsertion.

  • How does Windows CE networking handle network card extraction and reinsertion?

    When the network card is reintroduced on a device, the networking components check to see if there had previously been settings, such as a DHCP lease, for this card. If there is a lease, the system attempts to renew the lease. If the system receives an ACK for the renewal, the system continues as normal. If the system receives a NAK for the renewal, the system assumes that the device has switched networks and restarts the initialization of the card from scratch, including requesting a new IP address from the DHCP server..

    Note   Because the DHCP client is not notified when the system time changes, unexpected results may occur if the system time is changed dynamically. If the system time is changed, you should reset the network interface, or initiate a renew sequence by using the IP helper APIs to resynchronize the DHCP client with the new system time.

  • Does Windows CE support multiple network cards per device?

    Yes. Each card is independently assigned an address. One or more cards can be assigned static or dynamic addresses. If the cards are assigned addressed by using a DHCP server, each card is handled independently with regard to renewals, card insertion and removal, and so on, because the cards will usually be on different subnets.

  • Can Windows CE handle multiple IP addresses per physical network card?

    Yes, but you need to assign the addresses manually by using the registry or the IP Helper APIs.
