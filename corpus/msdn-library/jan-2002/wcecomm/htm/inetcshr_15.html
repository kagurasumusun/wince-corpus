Enabled

Specifies whether auto dial is enabled.

Path

HKEY_LOCAL_MACHINE\Comm\AutoDial

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF. A non-zero value enables auto dial. A value of 0 specifies that auto dial is not enabled.

Default Value

0
