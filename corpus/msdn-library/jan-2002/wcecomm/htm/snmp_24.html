Address Translation Group

The Address Translation Group contains a translation table for converting a network address into a subnetwork-specific address. This table is unified and applies across all of the interfaces. The following table shows the variables of the Address Translation Group and their properties.

Name Type Access Description
atTable     IP to subnetwork address translation table:
atIfIndex Integer R/W Index into interface table
atPhysAddress PhysAddress R/W Media-dependent physical address
atNetAddress* IpAddress R/W IP address that corresponds to the physical address
