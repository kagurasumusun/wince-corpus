EnablePacketFiltering

Specifies whether the packet filter is enabled.

Path

HKEY_LOCAL_MACHINE\Comm\ConnectionSharing

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF. A non-zero value enables the packet filter. A value of 0 specifies that the packet filter is not enabled.

Default Value

0, or FALSE.

Remarks

This subkey enables filtering in the NAT driver such that any unsolicited connections over the public network interface are blocked. Connections originating on the local network and connections mapped through the Network Address Translator are unaffected by this subkey.
