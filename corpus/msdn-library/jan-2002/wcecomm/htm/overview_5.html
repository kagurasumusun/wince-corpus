Network and Transport Layers

Software that operates at the network layer fragments, routes, and reassembles data. The transport layer works with the network layer to package and transfer data that it receives from the session layer.

The Transmission Control Protocol/Internet Protocol (TCP/IP) operates at the network and transport layers. IP operates at the Network layer and TCP operates at the Transport layer. TCP/IP is an industry standard communication protocol that defines methods for packaging data into packets for transmission over a network. The TCP/IP stack introduced some new features as well as some enhanced functionality in Windows CE version 3.0. Fast retransmit, dead gateway detection, selective acknowledgements, window Scaling, better plug and play support are some of the new features introduced in Windows CE version 3.0. Also, performance improvements have been made in addition to providing more options that are now configurable via the registry.

DHCP in Windows CE version 3.0 now supports Automatic IP. Automatic IP enables Windows CE devices to participate in a network (such as a home network) without a DHCP server being present and without requiring that the device be configured with a static IP address.

For more information on TCP/IP, see Transmission Control Protocol/Internet Protocol and Windows Sockets.

Internet Protocol Helper (IP Helper) APIs are new to Windows CE version 3.0. IP Helper is an API that assists in the network administration of the local device. IP Helper provides programmatic interfaces to manage the Route and ARP tables, retrieve information about network adapters and interfaces, the TCP/IP (TCP, IP, UDP etc.) stack, network connections as well as provide notification of network events.

For more information on IP Helper, see Internet Protocol Helper APIs.

For infrared communications Windows CE supports the Infrared Data Association (IrDA) standards using the IrDA protocols at the network and transport layers.

For more information on using the IrDA protocols, see Windows Sockets.
