Physical Layer

The physical layer of the ISO/OSI model consists of the physical characteristics of the media used by two (or more) computers to communicate with to each another. Hardware in the physical layer converts electrical signals into binary code, which is passed to the data-link layer. Examples of physical layer media supported by Windows CE include Ethernet (IEEE 802.3), Infrared (IrDA FIR/SIR), Token-ring (IEEE802.5), and serial (RS-232). Other physical media types may be supported by emulating one of the natively supported media (e.g. 802.11, HomePNA, and Cable Modem can be supported by emulating Ethernet).

Windows CE provides broad support for integration of physical layer hardware into the system. Supported internal bus interfaces include USB, PCMCIA/Compact Flash, PCI and ISA. A system may also have a more integrated hardware design, using a processor or ASIC (Application-Specific Integrated Circuit with the networking functionality included. These interfaces are covered in the Windows CE Device Driver Kit (DDK) documentation.

Windows CE 3.0 ships with a number of sample drivers. These include the following samples:

  • NE2000 Ethernet sample driver, which supports ISA, PCI and PCMCIA
  • Sample USB Hid driver that can be used as an example for a 3rd party to implement a network enabled USB driver
  • Wireless (Proxim) sample driver
  • Fast IR and Serial IR sample driver
  • Unimodem driver which supports AT-command-based modems
  • Serial device driver
  • AsyncMac miniport (WAN miniport)

Windows CE provides the CEDDK service to simplify the implementation of ASIC drivers. CEDDK abstracts the bus-specific characteristics.

For more information on communicating using serial ports, see Serial Communications and Windows Sockets documentation. For more information on infrared communications, see Serial Communications and Windows Sockets. For more information about each driver type please see the Windows CE driver developer kit (DDK) documentation. For information about modem support please see the Telephony documentation. For information about network media supported through the Network Driver Interface Specification (NDIS) please see the Network Driver Interface Specification documentation.
