The Network Driver Interface Specification (NDIS) Interface

Microsoft networking protocols use the Network Driver Interface Specification (NDIS) to communicate with network card drivers. Much of the Open Systems Interconnection (OSI) model link layer functionality is implemented in the protocol stack. This makes development of network card drivers much simpler.

For more information about NDIS, see Network Driver Interface Specification Support.
