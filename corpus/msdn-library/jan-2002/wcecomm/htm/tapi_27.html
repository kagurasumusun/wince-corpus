GenericModem Key

The following table shows the registry settings for the HKEY_LOCAL_MACHINE\Drivers\PCMCIA\CompanyX-GenericModem-1234 key.

Registry key Description Type Typical value
DeviceArrayIndex Driver-specific description; this key is set always to 1 for V1 PC Card devices. DWORD 1
DLL Specifies the name of the import DLL.   Serial.dll
Prefix Device prefix.   COM
ResetDelay Specifies a number of milliseconds of delay that are used during the PC Card reset sequence; this key is optional. DWORD 300 (this value is the default value for this key)
