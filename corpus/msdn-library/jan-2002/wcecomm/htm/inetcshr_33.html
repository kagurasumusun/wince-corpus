RedialPauseTimeMS

Specifies the amount of time, in milliseconds, that auto dial should wait before retrying a connection.

Path

HKEY_LOCAL_MACHINE\Comm\Autodial

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF

Default Value

0
