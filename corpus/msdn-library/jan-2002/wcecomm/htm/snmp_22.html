System Group

The System Group provides general information about the managed system, such as contact, administration, location, and service information. The following table shows the variables of the System Group and their properties.

Name Type Access Description
sysDescr Octet string R/O Description of the entity (name and version number)
sysObjectID Object ID R/O The Product (OS)’s identifier under the Vendor's subtree in1.3.6.1.4.1
sysUpTime TimeTicks R/O Time since last SNMP reboot (in hundredths of a second)
sysContact Octet string R/W Contact person name and information
sysName Octet string R/W Fully qualified domain name for the node
sysLocation Octet string R/W Physical location of the node
sysServices Integer R/O Services that are provided by the node (bitmapped; OSI model)
sysORID Object ID R/O SNMP identifier (sysObjectID value)
sysORDescr Octet string R/O Description of resources (sysDescr value)
sysORUpTime TimeTicks R/O Last time that this row was changed

Note  Windows CE 3.0 does not support the sysORTable and sysORTable variables, which are defined in RFC1907.
