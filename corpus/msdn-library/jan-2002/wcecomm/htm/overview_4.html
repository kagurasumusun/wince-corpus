Between the Data-Link Layer and Network and Transport Layers

Operating at the data-link layer, or between the data-link layer and the network layer, are the Microsoft Telephony API (TAPI), Unimodem and the point-to-point protocol (PPP) and Serial Line Internet Protocol (SLIP) for direct serial and dial-up connections.

TAPI version 2.0 and some features from TAPI version 2.1 are new in Windows CE version 3.0. TAPI is a set of APIs that simplifies and abstracts the details of making telephony connections between two or more devices. TAPI abstracts call-control functionality to allow different, and seemingly incompatible, communication protocols to expose a common interface to applications through its support of telephony service providers. Windows CE 3.0 ships with one Telephony Service provider, the Unimodem service provider, which supports AT command based, modems. Windows CE 3.0 does support installable service providers enabling ISVs, OEMs and IHVs to add additional Telephony service providers under TAPI for example VoIP (H323, SIP, MGCP etc.), ISDN, cell phones etc.

New to TAPI in Windows CE version 3.0 is support for inbound calls for both data and voice, supplementary services (call forward, hold, park, conferencing etc.), support for multiple calls, better/more efficient application message notifications as well as enhanced call center support, etc. As with previous versions of TAPI, the availability of these features depends upon the underlying telephony service provider and hardware.

For more information on TAPI and Unimodem, see Telephony API.

Remote Access Service (RAS) is a management API used for setting up data-link connections, and operates closely with PPP. New in Windows CE version 3.0 is the ability to make multiple RAS connections.

For more information on RAS, see Remote Access Service.
