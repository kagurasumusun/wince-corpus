MIB-II

MIB-II is defined in RFC 1213, which supersedes RFC 1156. The objects that MIB-II supports fall under the following groups:

  • System Group
  • Interfaces Group
  • Address Translation Group
  • IP Group
  • ICMP Group
  • TCP Group
  • UDP Group
  • SNMP Group

    Note   The Egp Group is not supported in Windows CE.
