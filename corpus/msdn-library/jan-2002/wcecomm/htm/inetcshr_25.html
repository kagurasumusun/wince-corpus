IsEnabled

Specifies whether the service is enabled.

Path

HKEY_LOCAL_MACHINE\Comm\ConnectionSharing\Servers\Service

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFF. A non-zero value enables the service. A value of 0 specifies that the service is not enabled.

Default Value

0
