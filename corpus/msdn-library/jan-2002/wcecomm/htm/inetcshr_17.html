EnableDnsProxy

Specifies whether DNS proxy is enabled.

Path

HKEY_LOCAL_MACHINE\Comm\ConnectionSharing

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF. A non-zero value enables DNS proxy on the private interface specified in the PrivateInterface subkey. A value of 0 specifies that DNS proxy is not enabled.

Default Value

0, or FALSE.

Remarks

To use DNS proxy, EnableDhcpAllocator must also be non-zero.
