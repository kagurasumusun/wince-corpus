PPP Registry Keys

To configure the behavior of the configuration protocols—for example, LCP—used by the PPP client, you can set the following optional registry values in the HKEY_LOCAL_MACHINE\Comm\Ppp\Parms registry key on the client device.

The following table describes the registry settings for

HKEY_LOCAL_MACHINE\Comm\Ppp\Parms.

Registry key Type Default Description
AckDupCr DWORD 1 Sends an Ack for a Configure-Request with the same identifier as the previously acknowledged Configure-Request (if the value of this key is set to non-0).
AllowSuspend DWORD 0 Controls suspension behavior of a device.

To allow the device to auto-suspend while a PPP session is active, this key must be set to 1.

Note   This registry key is read during session creation. Any change to this key will affect subsequent PPP sessions that are created, but not currently active sessions.
MaxConfigure DWORD 10 Indicates the number of Configure-Request packets sent without receiving a valid Configure-Ack, Configure-Nak or Configure-Reject before assuming that the peer is unable to respond.
MaxFailure DWORD 5 Indicates the number of Configure-Nak packets sent without sending a Configure-Ack before assuming that the configuration in not converging.
MaxTerminate DWORD 2 Indicates the number of Terminate-Request packets sent without receiving a Terminate-Ack before assuming that the peer is unable to respond.
RestartTimer DWORD 3 Indicates the time to wait before resending a Configure-Request or Terminate-Request when no Ack has been received (units are seconds).
