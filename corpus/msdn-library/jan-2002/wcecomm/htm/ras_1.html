Overview of RAS

RAS operates in the upper layers of the International Organization for Standardization Open Systems Interconnection (ISO/OSI) model for network communication. In Windows CE, RAS supports only IP-based protocols. The following diagram illustrates the role of RAS within the Windows CE 3.0 communications architecture.

In the Windows CE RAS architecture, RAS communicates directly with PPP to establish a connection to a remote access server. RAS uses PPP to package data packets from multiple protocols and forward them to a server over point-to-point links.

When creating an application requiring a connection to a remote access server, use Windows CE RAS functions to manipulate the transport layer of the selected Windows CE–based device.
