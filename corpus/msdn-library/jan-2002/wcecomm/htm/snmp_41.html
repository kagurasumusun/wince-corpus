SnmpTfx API Functions

The extension-agent DLL calls the functions shown in the following table to initialize, use, and clean up the SnmpTfx framework environment.

Function Description
SnmpTfxOpen Initializes the SnmpTfx framework application; it must be called from the SnmpExtensionInit subagent routine.
SnmpTfxQuery Resolves SNMP requests that contain variables within one or more of the registered MIB subtrees of the SNMP extension agent, by using the SnmpTfx framework.
SnmpTfxClose Deallocates resources and closes the SnmpTfx framework application.
