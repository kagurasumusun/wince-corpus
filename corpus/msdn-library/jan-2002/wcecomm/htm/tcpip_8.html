Core Protocol Stack Components

The core protocol stack components are those shown between the NDIS and TDI interfaces in the illustration included in Architectural Model. Windows CE implements these components in Tcpstk.dll. The Microsoft stack is accessible through the Winsock interface and the NDIS interface. The Winsock interface for Windows CE does not provide raw access to the protocol stack.
