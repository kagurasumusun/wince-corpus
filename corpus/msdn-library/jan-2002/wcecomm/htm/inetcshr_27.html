PrivateInterface

Specifies a list of names of the NDIS adapter instances for the private interfaces; for example, Ne20002.

Path

HKEY_LOCAL_MACHINE\Comm\ConnectionSharing

Value Type

REG_MULTI_SZ

Valid Range

A list of names of either valid NDIS adapters or valid dial-up networking connectoids.

Default Value

None

Remarks

If the list contains multiple private interfaces, those interfaces all must have the same subnet value in their IP addresses. For example, if PrivateInterface equals "Ne20001";"Ne20002" and the Ne20001 interface has an IP address of 169.254.0.1, the Ne20002 interface can have an IP address of 169.254.0.2, but not 192.168.0.1.
