ICS for OEMs

This section contains additional information about Internet Connection Sharing (ICS) for original equipment manufacturers (OEMs). This section discusses:

  • Network Address Translation (NAT) editor APIs that can be used to directly examine network packets for certain kinds of network traffic that cannot be translated by the NAT driver without further information.
  • Steps required to load an administrative web page onto a ICS gateway, so that users can preconfigure the registry keys that define mappings between the names of devices on the home network and IP addresses.

For more information about ICS, see Internet Connection Sharing. For more information about NAT, see Network Address Translation.
