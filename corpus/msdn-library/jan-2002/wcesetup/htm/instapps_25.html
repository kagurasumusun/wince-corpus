Current Processors and Device Platforms

Windows CE supports a wide variety of processors and device platforms. This section describes the current list of supported processors and device platform names. You can use this information when creating an .inf file.

A processor type value is a number associated with the type of processor in a Windows CE-based device. You can find a list of all currently supported processor type values in the Winnt.h header file. These values have a PROCESSOR_ prefix. You can also retrieve the processor type value from a device by calling the GetSystemInfo function, and examining the dwProcessorType member of the SYSTEM_INFO structure that GetSystemInfo retreives. The following table describes the possible values for dwProcessorType.

Processor Name Processor Type Value
ARM720 1824
Hitachi SH3 10003
Hitachi SH4 10005
MIPS R4XXX 4000
StrongARM SA11XX 2577

Note   The MIPS R3900 binaries are binary-compatible with all MIPS R3XXX and R4XXX processors. Use the R3900 binaries to ensure that files will run on all MIPS processors.

The StrongARM SA1100 binaries are binary-compatible with the ARM720 processor. Use the SA1100 binaries to ensure that files will run on both processors.

The device platform name and Windows CE version number are two strings that Windows CE uses to identify a target platform. You can retrieve the device platform name using the SystemParametersInfo function, with the SPI_GETPLATFORMTYPE flag set in the (?) parameter. You can retrieve the Windows CE version number using the GetVersionEx function, with the OSVERSIONINFO.dwMajoVersion and dwMinorVersion values. The following table describes device platform names and OS version numbers currently in use on Windows CE-based devices.

Device Name Device Platform Name Windows CE version number
H/PC 1.0 Unsupported. Use v1 PPCLoad  
H/PC 2.0 “HPC” 2.0
H/PC 3.0 “HPC Pro” 2.11
Palm-size PC 1.0 “Palm PC” 2.1
Palm-size PC 2.0 “Palm PC” 2.11
Pocket PC “Palm PC” 3.0
