Installing Applications

Developers of Windows CE–based platforms have created a series of techniques to use for installing applications to a Windows CE-based device. These techniques include:

  • Using the CAB Wizard to create application device-side setup packages with Windows CE cabinet (.cab) files.
  • Using the Application Manager application, CeAppMgr.exe, to install applications to the Windows CE–based device.
