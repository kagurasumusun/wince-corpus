Losing and Restoring Surfaces

It is impossible to lose surfaces in Windows CE. However, to allow for compatiblility of applications from the other Windows OS’s, the methods still function. The IDirectDrawSurface5::Restore method and the IDirectDraw4::RestoreAllSurfaces method return DD_OK.
