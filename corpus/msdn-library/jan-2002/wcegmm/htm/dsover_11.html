DirectSound Waveform Driver Emulation

The WaveBuff.dll component presents itself to the Waveform API manager as a waveform device driver, but is in fact just a DirectSound client. This allows for simultaneous support of both the DirectSound and waveform APIs. It is not recommended that this waveform emulation layer be used for audio streaming. Applications wishing to perform audio streaming should instead use the DirectSound API.
