Utility Classes

The DirectShow SDK includes several utility classes that provide C++ class encapsulation of many of the required Win32 functions, multimedia data structures, and object list and queue manipulation. These classes are briefly described in this section, which contains the following topics.

  • Win32 Classes
  • List and Queue Classes
  • Multimedia Data Type Classes
  • COM Utility Classes
  • Debugging Classes
