Data Flow in the Filter Graph

This article describes how media data moves through the filter graph. It is intended for developers who are writing their own custom filters. Application developers generally do not have to worry about the topics covered here.

This article focuses on the shared memory transport, using the IMemInputPin and IMemAllocator interfaces. It contains the following sections:

  • Push versus Pull
  • Threads
  • Generating New Samples
  • Processing a Sample
  • End of Stream
  • Flushing
  • Critical Sections in Filters
  • Base Classes for Data Flow
