Web Server Requirements

The following list describes the requirements for the computer that runs the Web server and its associated ASP-page interpreter:

  • The computer can be any device that can run the Mincomm configuration of the Windows CE operating system, version 3.0 or higher.
  • For communications purposes, the computer requires a TCP/IP network interface.
  • The Web server requires approximately 40 KB of RAM.
  • The ASP-page interpreter requires approximately 45 KB of RAM.
