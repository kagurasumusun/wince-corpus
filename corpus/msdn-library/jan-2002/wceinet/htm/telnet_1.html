Sample Telnet Server Requirements

The following list describes the requirements for the system to run the telnet sample:

  • The computer can be any device that can run the Mincomm configuration of the Windows CE operating system, version 2.12 or higher.
  • For communications purposes, the computer requires a TCP/IP network interface.
  • The computer requires approximately 10 KB of available RAM.
  • The application cmd.exe must be present on the device.
