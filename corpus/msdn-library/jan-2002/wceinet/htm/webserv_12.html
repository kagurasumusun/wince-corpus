Authentication Restrictions

Versions of Windows CE prior to 3.0 did not implement NTLM. If you install the Web server on a Windows CE 2.11 or 2.12 device platform keep in mind that authentication support is limited to Basic authentication and the server will ignore the NTLM registry value.

If authentication is set up on a virtual root, the Web server checks the password that is sent by the browser against the password that is set in Control Panel under Password.
