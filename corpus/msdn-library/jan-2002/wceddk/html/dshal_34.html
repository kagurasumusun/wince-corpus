IDsDriverCaptureBuffer::Stop

The IDsDriverCaptureBuffer::Stop method causes the sound buffer to stop capturing. 

HRESULT Stop( );

Return Values

Returns DS_OK if successful, or one of the following error values otherwise:

  • DSERR_INVALIDCALL
  • DSERR_INVALIDPARAM

Remarks

For primary buffers, the driver should set the current position to zero (the beginning of the buffer) when this method is called. For secondary buffers, the driver should set the current position of the buffer to the sample after the last sample captured (don't reset it to zero).
