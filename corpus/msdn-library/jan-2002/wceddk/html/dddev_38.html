UpdateNonLocalHeap

Note   This callback function is not currently used on Windows CE.

The UpdateNonLocalHeap callback function notifies the driver of the base addresses of each non-local heap in turn. 

DWORD __stdcall UpdateNonLocalHeap(
LPDDHAL_UPDATENONLOCALHEAPDATA lpd );

Parameters

lpd
Pointer to a DDHAL_UPDATENONLOCALHEAPDATA structure that contains the heap information.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
