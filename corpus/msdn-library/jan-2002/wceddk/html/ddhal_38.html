GetDriverData

The GetDriverData function is used to obtain a pointer to the driver data that is associated with the current object.

virtual DDGPEDriverData*
GetDriverData (
void );

Parameters

None

Return Values

This function returns a pointer to the driver data that has been attached to the current object.
