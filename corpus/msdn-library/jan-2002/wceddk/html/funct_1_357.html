RDF_READER_SWALLOW

The RDF_READER_SWALLOW callback function does a mechanical swallow. This callback function is optional.

NTSTATUS (*ReaderFunction[RDF_READER_SWALLOW])(
  PSMARTCARD_EXTENSION SmartcardExtension);

Parameters

SmartcardExtension
Points to the smart card extension of the device. SmartcardExtension->MajorIoControlCode must be set to IOCTL_SMARTCARD_SWALLOW.

Return Values

This function returns an NTSTATUS value. Possible values are the following.

Value Meaning
STATUS_SUCCESS Function successfully executed.
STATUS_NO_MEDIA No card is in the reader.
STATUS_IO_TIMEOUT The request has timed out.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later
