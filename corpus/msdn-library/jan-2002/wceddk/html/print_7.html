Sample Printer Driver

Microsoft Windows CE Platform Builder 3.0 includes a sample PCL printer driver that provides support for PCL-3 compatible printers. This sample is not intended to be a full featured printer drivers; it is provided mainly to assist OEMs and IHVs in writing printer drivers for Windows CE, or porting desktop printer drivers to Windows CE. The sample driver supports color printing.

Microsoft has tested the sample PCL printer driver with the following printers:

  • HP DeskJet models 340, 694C, 695, 890/95, and 2000.
  • HP LaserJet 5P, 6P, 4000, and 5Si.

Note that the LaserJet 6P supports printing via FastIR, while the LaserJet 4000 and 5Si support network printing.

The sample printer driver has some limitations that OEMs and IHVs should be aware of before using that driver as the basis for other printer drivers. First, the sample driver assumes that every call to its DrvCopyBits function corresponds to exactly one print band, which is the full width of the page and starts at the left side. Second, older versions of the driver requested that bitmaps be in RGB format, but actually required them to be in BGR format. For Windows CE 3.0 and later, the printer driver will receive the pixel format that it asks for.
