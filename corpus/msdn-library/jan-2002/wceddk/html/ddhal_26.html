DDGPEDriverData

This section describes the DDGPEDriverData data structure.

typedef struct DDGPEDriverData
{
DDGPEStandardHeader;
DWORDdwDriverFlag;

} DDGPEDriverData;

The DDGPEDriverData structure is used by various DDGPE classes to allow your driver to store custom information. See the DDGPE class definitions for more information on using this structure.

DDGPEStandardHeader

See DDGPEStandardHeader for more information.

dwDriverFlag

This field can contain driver-specific flags that need be attached to the DDGPE object.
