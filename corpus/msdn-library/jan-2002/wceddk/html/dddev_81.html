DDHAL_DESTROYDRIVERDATA

The DDHAL_DESTROYDRIVERDATA structure contains information necessary to destroy a driver. This structure passes the information to the DirectDraw HAL DestroyDriver callback function. 

typedef struct _DDHAL_DESTROYDRIVERDATA
{
LPDDRAWI_DIRECTDRAW_GBL    lpDD;
HRESULT                    ddRVal;
LPDDHAL_DESTROYDRIVER      DestroyDriver;
} DDHAL_DESTROYDRIVERDATA;

Members

lpDD
Pointer to the DDRAWI_DIRECTDRAW_GBL structure that represents the DirectDraw object.
ddRVal
Passes the DirectDraw return values.
DestroyDriver
This member is used by DirectDraw and should not be filled in by the driver.
