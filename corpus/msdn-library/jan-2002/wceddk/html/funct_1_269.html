NdisRawReadPortUchar

This function reads a byte from a given I/O port on the NIC.

VOID NdisRawReadPortUchar(
IN ULONG Port,
OUT PUCHAR Data );

Parameters

Port
Specifies the I/O port. This address falls in a range that was mapped during initialization with the NdisMRegisterIoPortRange function.
Data
Pointer to a caller-supplied variable in which this function returns a byte read in from the port.

Remarks

This function runs faster than the NdisImmediateReadPortUchar function because it need not map a bus-relative I/O port address onto a host-dependent logical port address at every call.

A driver that calls this function can run at any IRQL.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Ndis.h
