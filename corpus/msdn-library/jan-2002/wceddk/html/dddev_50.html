GetVideoPortFlipStatus

The GetVideoPortFlipStatus callback function indicates whether a V-sync has occurred since the flip was performed on the specified surface. This callback is required. 

DWORD __stdcall GetVideoPortFlipStatus(
LPDDHAL_GETVPORTFLIPSTATUSDATA pgvpfsd );

Parameters

pgvpfsd
Pointer to a DDHAL_GETVPORTFLIPSTATUSDATA structure that contains the information about the flip status of the specified surface.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED

Remarks

This function allows Ddraw.dll to fail locks on a surface that was recently flipped from so the HAL doesn't have to account for this.

If a video V-sync has not occurred since the flip was performed on the specified surface, the HAL should set the ddRVal member of the DDHAL_GETVPORTFLIPSTATUSDATA structure to DDERR_WASSTILLDRAWING.
