Blt

The Blt callback function performs a bit block transfer. 

DWORD __stdcall Blt(
LPDDHAL_BLTDATA pbd );

Parameters

pbd
Pointer to a DDHAL_BLTDATA structure that contains the information required for the driver to perform a bit block transfer.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED

Remarks

An example implementation of this callback function (Blt32) can be found in the IGS sample driver source code.
