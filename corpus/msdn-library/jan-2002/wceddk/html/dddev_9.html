DestroyDriver

The DestroyDriver callback function destroys a DirectDraw driver. 

DWORD __stdcall DestroyDriver(
LPDDHAL_DESTROYDRIVERDATA pddd );

Parameters

pddd
Pointer to a DDHAL_DESTROYDRIVERDATA structure that contains information necessary to destroy the driver.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
