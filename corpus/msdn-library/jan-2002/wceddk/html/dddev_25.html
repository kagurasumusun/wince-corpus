SetOverlayPosition

The SetOverlayPosition callback function changes the display coordinates of an overlay surface. 

DWORD __stdcall SetOverlayPosition(
LPDDHAL_SETOVERLAYPOSITIONDATA psopd );

Parameters

psopd
Pointer to a DDHAL_SETOVERLAYPOSITIONDATA structure that contains the information required to change the display coordinates of an overlay surface.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
