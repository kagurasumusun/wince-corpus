NodeSize

The NodeSize function returns the total size, in bytes, of the current heap, excluding any subsequent nodes.

DWORD NodeSize (void };

Parameters

None

Return Values

This function returns the total size, in bytes, of the current heap. This size does not include any (subsequent) subheaps.
