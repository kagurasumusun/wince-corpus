Victoria PCI Graphics Development Board for Windows CE

OEMs who wish to use the ATI sample display driver will need to obtain the Victoria PCI Graphics Development Board for Windows CE, a product that facilitates developing PCI-based graphics subsystems for Windows CE-based platforms. The board supports features such as:

  • A 33 MHz PCI interface
  • The ATI Rage XL graphics controller with 2-D, 3-D, video/alpha blending, and digital video output features
  • ATI Rage Theater features such as NTSC and PAL encoders/decoders, comb filters, and macrovision detection and encryption
  • A stereo audio decoder
  • CCIR 656, S-video, composite, and RF video inputs
  • S-video, composite, and VGA video outputs
  • Software support for Windows CE 3.0 and Beta release 2 of Microsoft TV.

This product is available from ATI through the ATI website at http://www.ati.com/na/pages/resource_centre/dev_rel/embedded_devices.html; OEMs should obtain it directly from ATI, and consult ATI’s documentation, website, and support services for any sales or hardware related questions about the product.
