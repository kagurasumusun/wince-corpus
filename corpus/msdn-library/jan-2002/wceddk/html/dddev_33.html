GetDriverInfo

The GetDriverInfo callback function gives device drivers a new mechanism for providing driver-specific information, such as pointers to driver callbacks, to the DirectDraw runtime.

DWORD __stdcall GetDriverInfo(
LPDDHAL_GETDRIVERINFODATA lpData );

Parameters

lpData
Pointer to a DDHAL_GETDRIVERINFODATA structure that contains the driver-specific information.

Return Values

Returns the following value:

  • DDHAL_DRIVER_HANDLED
