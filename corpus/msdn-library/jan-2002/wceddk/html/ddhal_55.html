ColorKey

The ColorKey function is used to obtain the color key for the current surface.

virtual DWORD ColorKey (void );

Parameters

None

Return Values

This function returns the color key for the current surface. For drivers that use a range of color keys, this value corresponds to that set using SetColorKeyLow.
