IOCTL_HID_TRANSFER_EVENT

This control code registers an event handle for the HID class driver to use to be signaled applications when an HID class device generates data.

Parameters

hDevice
Handle to the HID class device.
dwIoControlCode  
Specifies this code.
lpInBuffer
Pointer to an input buffer containing an SHiddiTransferEvent structure.
nInBufferSize
Specifies the length of the input buffer.
lpOutBuffer
NULL.
nOutBufferSize
Not used.
lpBytesReturned
Specifies the total number of bytes returned.
lpOverlapped
NULL.

Remarks

The input buffer contains an SHiddiTransferEvent structure. No output is expected.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later
