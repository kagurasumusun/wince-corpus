GetPhysicalModeId

In some cases, it may become necessary to separate two or more display surfaces. If one GDI surface is differentiated from another display surface, the current GDI mode does not necessarily identify the current physical, or actual, mode of the display. The GetPhysicalModeId, along with the m_dwPhysicalModeID member variable, described below, allow the driver to maintain this mode information.

virtual DWORD GetPhysicalModeId (void );

Parameters

None

Return Values

This function returns the current mode of the display. If the current primary surface is not the GDI surface, this physical mode might differ from GDI’s current mode index.
