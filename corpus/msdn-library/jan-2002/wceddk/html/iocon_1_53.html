IOCTL_SMARTCARD_SWALLOW

This causes the smart card reader to swallow the card.

Parameters

dwOpenData
Handle returned from a call to the smart card reader driver’s XXX_Open function.
dwCode
Specifies this code.
pBufIn
Ignored
dwLenIn
Ignored.
pBufOut
Ignored.
dwLenOut
Must be set to zero.
pdwActualOut
Must be set to zero.

Return Values

One of the following status values:

Status Meaning
STATUS_SUCCESS The smart card was swallowed.
STATUS_NO_MEDIA There is no card in reader.
STATUS_IO_TIMEOUT The operation has timed out.
STATUS_NOT_SUPPORTED The card reader does not support swallowing.

Note: Smart card reader drivers return Windows NT status values, rather than Win32 error values, as the return values from the driver’s callback function.
