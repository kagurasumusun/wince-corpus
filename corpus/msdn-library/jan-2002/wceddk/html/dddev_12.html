SetColorKey

The SetColorKey callback function sets the color key value for the specified surface. 

DWORD __stdcall SetColorKey(
LPDDHAL_SETCOLORKEYDATA psckd );

Parameters

psckd
Pointer to a DDHAL_SETCOLORKEYDATA structure that contains the information necessary to set the color key value for the specified surface.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOCKEYHW
  • DDHAL_DRIVER_NOTHANDLED
