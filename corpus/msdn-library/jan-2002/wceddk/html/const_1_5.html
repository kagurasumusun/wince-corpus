PC Card Window Speeds

Window speed masks specify the access speed for a memory or I/O window. The following table shows the defined window speed masks.

Speed mask Description
WIN_SPEED_EXP_MASK Exponent mask
WIN_SPEED_EXP_1NS 1 nanosecond
WIN_SPEED_EXP_10NS 10 nanoseconds
WIN_SPEED_EXP_100NS 100 nanoseconds
WIN_SPEED_EXP_1US 1 microsecond
WIN_SPEED_EXP_10US 10 microseconds
WIN_SPEED_EXP_100US 100 microseconds
WIN_SPEED_EXP_1MS 1 millisecond
WIN_SPEED_EXP_10MS 10 milliseconds
WIN_SPEED_MANT_MASK Mantissa mask
WIN_SPEED_MANT_10 1.0
WIN_SPEED_MANT_12 1.2
WIN_SPEED_MANT_13 1.3
WIN_SPEED_MANT_15 1.5
WIN_SPEED_MANT_20 2.0
WIN_SPEED_MANT_25 2.5
WIN_SPEED_MANT_30 3.0
WIN_SPEED_MANT_35 3.5
WIN_SPEED_MANT_40 4.0
WIN_SPEED_MANT_45 4.5
WIN_SPEED_MANT_50 5.0
WIN_SPEED_MANT_55 5.5
WIN_SPEED_MANT_60 6.0
WIN_SPEED_MANT_70 7.0
WIN_SPEED_MANT_80 8.0
WIN_SPEED_USE_WAIT Use wait if available.
