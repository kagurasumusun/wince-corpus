UpdateOverlay

The UpdateOverlay callback function repositions or modifies the visual attributes of an overlay surface. 

DWORD __stdcall UpdateOverlay(
LPDDHAL_UPDATEOVERLAYDATA puod );

Parameters

puod
Pointer to a DDHAL_UPDATEOVERLAYDATA structure that contains the information required to update the overlay surface.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
