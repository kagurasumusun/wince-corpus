DDHAL_DDCOLORCONTROLCALLBACKS

The DDHAL_DDCOLORCONTROLCALLBACKS structure contains the color control callback functions used by the driver. 

typedef struct _DDHAL_DDCOLORCONTROLCALLBACKS
{
DWORD                          dwSize;
DWORD                          dwFlags;
LPDDHALCOLORCB_COLORCONTROL    ColorControl;
} DDHAL_DDCOLORCONTROLCALLBACKS;
typedef DDHAL_DDCOLORCONTROLCALLBACKS FAR *LPDDHAL_DDCOLORCONTROLCALLBACKS;

Members

dwSize
Size of the structure. This parameter must be initialized before the structure is used.
dwFlags
Indicates which of the color control functions are implemented in 32-bit code.

Flag Usage
DDHAL_COLOR_COLORCONTROL Indicates that the ColorControl callback is implemented in 32-bit code.

ColorControl
Pointer to the driver’s implementation of the ColorControl callback.

Remarks

This structure can be queried from the driver using GetDriverInfo with GUID_ColorControlCallbacks.

This structure contains the entry points in the display driver that DirectDraw calls. Entries that the display driver does not use should be set to NULL.
