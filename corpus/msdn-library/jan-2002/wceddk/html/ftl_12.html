Detecting a Block Device

When a block device is connected to a Windows CE–based platform, the Device Manager calls the driver’s detection function, which is listed among the driver’s registry keys. The detection function attempts to recognize the type of block device hardware that is present by querying the device. If the driver recognizes the device, the Device Manager loads the block device driver into memory. This detection and load process is standard procedure for PC Card devices only.
