SetColorKeyHigh

This function can be used to specify the high value for a range of color keys specific to the specified surface.

virtual void SetColorKeyHigh (
DWORD dwColorKey );

Parameters

dwColorKey
The high value in the surface’s color key range.

Return Values

This function returns a new SurfaceHeap object, containing memory that has been allocated by the specified parent heap. If allocation fails, this function will return NULL.
