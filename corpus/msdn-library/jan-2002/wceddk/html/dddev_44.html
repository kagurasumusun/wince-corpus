CreateVideoPort

The CreateVideoPort callback function notifies the HAL after a video port is created. This callback is optional. 

DWORD __stdcall CreateVideoPort(
LPDDHAL_CREATEVPORTDATA pcvpd );

Parameters

pcvpd
Pointer to a DDHAL_CREATEVPORTDATA structure that contains the information required for the driver to create a video port.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
