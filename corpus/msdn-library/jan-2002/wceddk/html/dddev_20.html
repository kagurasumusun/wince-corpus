Flip

The Flip callback function makes the surface memory associated with the back buffer surface become associated with the front buffer surface. 

DWORD __stdcall Flip(
LPDDHAL_FLIPDATA pfd );

Parameters

pfd
Pointer to a DDHAL_FLIPDATA structure that contains information necessary to perform a flip.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED

Remarks

An example implementation of this callback function (Flip32) can be found in the IGS sample driver source code.
