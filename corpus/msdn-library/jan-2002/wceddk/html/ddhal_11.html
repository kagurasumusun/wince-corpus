32-Bit Versus 16-bit

Windows CE is a purely 32-bit environment. This means that its DirectDraw implementation is not compatible with the 16-bit mechanism offered by the Desktop DDHAL model. Any callbacks you have implemented in 16 bits must be converted to 32 bits when moving to the Windows CE DirectDraw HAL implementation.
