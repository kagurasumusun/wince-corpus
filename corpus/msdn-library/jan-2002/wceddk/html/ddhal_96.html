DDHAL Callbacks and Capabilities

There are various DDHAL callbacks and caps structures. You should create each of these structures in a global variable and set them up when they are declared, so DDGPE can access them at any time. You should then use these global variables when populating the DDHALINFO structure in your buildDDHALInfo implementation.

Each of these structures is described in detail in the DirectDraw Hardware Abstraction Layer document in the DirectDraw DDK.

DDHAL_DDCALLBACKS cbDDCallbacks
DDHAL_DDEXEBUFCALLBACKS cbDDExeBufCallbacks
DDHAL_DDPALETTECALLBACKS cbDDPaletteCallbacks
DDHAL_DDSURFACECALLBACKS cbDDSurfaceCallbacks
DDHAL_DDCOLORCONTROLCALLBACKS ColorControlCallbacks
DDHAL_DDMISCELLANEOUSCALLBACKS MiscellaneousCallbacks
DDHAL_DDMISCELLANEOUS2CALLBACKS Miscellaneous2Callbacks
DDHAL_DDHALMEMORYCALLBACKS HalMemoryCallbacks
DDHAL_DDVIDEOPORTCALLBACKS VideoPortCallbacks
DDHAL_DDKERNELCALLBACKS KernelCallbacks
DDMORECAPS MoreCaps
DDKERNELCAPS KernelCaps
