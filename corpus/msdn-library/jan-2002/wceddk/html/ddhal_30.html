DDGPE Base Classes

This section lists the DDGPE base classes and shows the functions they export. See the following sections for more detailed descriptions of each of the functions.

The DirectDraw Graphics Primitive Engine consists of the following classes:

DDGPE Class Serves as the base class for DirectDraw display drivers.
DDGPESurf Class The representation of a surface to the display driver
SurfaceHeap Class An alternate heap manager.
