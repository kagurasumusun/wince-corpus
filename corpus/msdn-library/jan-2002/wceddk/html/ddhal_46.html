SetDriverData

This function is used to store any data your driver wishes to attach to the DDGPE object, regardless of how you have subclassed the object in your driver.

The driver data is neither created nor released by the DDGPE object; the driver is responsible for this. The DDGPE object simply stores a pointer to the memory you have allocated. If you are setting the driver data, your driver should be sure to check that the driver data that is already attached to the selected DDGPE object is properly released.

virtual void SetDriverData (
DDGPEDriverData *pDriverData );

Parameters

pDriverData
A pointer to the driver data that should be attached to this DDGPE object. Your driver is responsible for allocating and releasing the memory associated with this object.

Return Values

None
