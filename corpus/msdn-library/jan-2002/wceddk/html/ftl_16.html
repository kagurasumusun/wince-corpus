Sample Block Device Drivers

Windows CE Platform Builder 3.0 provides three sample block device drivers. Code for these drivers is available in the \Public\Common\Oak\Drivers\ directory of your Platform Builder installation, in the subdirectories ATADISK, SRAMDISK, and RAMDISK. This section describes the programming details of the ATADISK sample block driver.
