Implementing a Block Device Driver

The following sections describe how to implement a block device driver for Windows CE. Block device drivers must satisfy the following:

  • export the stream interface functions
  • perform the correct startup sequence
  • support device detection
  • use the correct registry keys
  • properly respond to power cycles
  • provide an Install_Driver function.
