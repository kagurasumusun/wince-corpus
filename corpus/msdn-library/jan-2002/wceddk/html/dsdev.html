DirectSound and Waveform Device Drivers

The DirectSound implementation in Windows CE can use the standard Waveform Audio device driver model with only a few minor differences, described below. This approach minimizes the effort required to get DirectSound running on Windows CE platforms that already support waveform audio. For a detailed description of waveform audio drivers for Windows CE, see Audio Drivers.
