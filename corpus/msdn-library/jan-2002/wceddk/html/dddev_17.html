AddAttachedSurface

The AddAttachedSurface callback function attaches a surface to another surface. 

DWORD __stdcall AddAttachedSurface(
LPDDHAL_ADDATTACHEDSURFACEDATA paasd );

Parameters

paasd
Pointer to a DDHAL_ADDATTACHEDSURFACEDATA structure that contains information required for the driver to attach a surface to another surface.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
