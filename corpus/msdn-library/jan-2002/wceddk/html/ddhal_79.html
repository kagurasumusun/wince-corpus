Alloc

Given a number of bytes to allocate, this function reserves a block of memory from the specified heap. A new SurfaceHeap object is created to encapsulate this block of memory. When the resulting heap is destroyed, it is marked for reuse.

SurfaceHeap *Alloc (
DWORD size );

Parameters

size
The size, in bytes, for the new subheap allocated from the current heap.

Return Values

This function returns a new SurfaceHeap object, containing memory that has been allocated by the specified parent heap. If allocation fails, this function will return NULL.
