SetColorKey

The SetColorKey function sets the color key for the current surface. This function sets the low and high color key to the same value. If you wish to set the color key to a range of values, you should use the SetColorKeyLow and SetColorKeyHigh functions.

virtual void SetColorKey (
DWORD dwColorKey );

Parameters

dwColorKey
The surface’s color key.

Return Values

None
