Registry Keys for Built-In Block Devices

Built-in block devices, ones that are an integral part of a Windows CE–based platform, are recognized based on the HKEY_LOCAL_MACHINE\Drivers\BuiltIn\ key. A driver called MyDriver should use the registry entries shown in the following example in Windows CE version 2.1 and later.

HKEY_LOCAL_MACHINE
  [Drivers]
    [BuiltIn]
      [MyDriver]
        SZ: Prefix = DSK
        SZ: Dll = MyDriver.DLL
        SZ: Index = DWORD:1
        SZ: Order = DWORD:1
        SZ: IOCTL = DWORD:4
        SZ: FSD = FATFS.DLL
        SZ: Folder = My Folder

The value of the Folder key is optional.
