Print Spooling in Windows CE

Windows CE does not ship a separate Printer Spooler component, as do the desktop versions of Windows. Spooling or background printing can be implemented in the printer driver itself. However, print spooling typically consumes a lot of memory, so memory limitations may be a problem. A practical print spooler would almost certainly have to implement an aggressive compression scheme to store spooled documents before printing. Several third party companies have implemented print spoolers for Windows CE.
