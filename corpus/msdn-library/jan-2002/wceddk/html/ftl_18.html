Further Information on Using Block Devices with Windows CE

Consult the following sources for further information on using block devices with Windows CE:

  • Microsoft Windows CE Platform SDK

    Information on the FAT file system I/O control codes.

  • Microsoft Windows CE Platform Builder version 3.0

    Information on building custom Windows CE OSs and adapting Windows CE to custom hardware, and details on customizing the M-Systems TrueFFS driver.

  • The M-Systems, Inc., Web site

    Details about linear flash memory technologies including the DiskOnChip device, details on enhancements and extensions to the TrueFFS driver that is included with the Windows CE Platform Builder.

  • The Personal Computer Memory Card International Association (PCMCIA) Web site

    Information on the mechanical, electrical, and software specifications for PC Cards.
