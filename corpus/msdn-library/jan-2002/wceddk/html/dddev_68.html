DDHAL_CANCREATEVPORTDATA

The DDHAL_CANCREATEVPORTDATA structure contains information necessary to indicate whether a video port can be created. This structure passes the information to the DirectDraw HAL CanCreateVideoPort callback function. 

typedef struct _DDHAL_CANCREATEVPORTDATA
{
LPDDRAWI_DIRECTDRAW_LCL    lpDD;
LPDDVIDEOPORTDESC          lpDDVideoPortDesc;
HRESULT                    ddRVal;
LPDDHALVPORTCB_CANCREATEVIDEOPORT    CanCreateVideoPort;
} DDHAL_CANCREATEVPORTDATA;

Members

lpDD
Pointer to the DDRAWI_DIRECTDRAW_LCL structure that represents the DirectDraw object.
lpDDVideoPortDesc
Pointer to a DDVIDEOPORTDESC structure that contains a description of the video port being created.
ddRVal
Passes the DirectDraw return values.
CanCreateVideoPort
This member is used by DirectDraw and should not be filled in by the driver.
