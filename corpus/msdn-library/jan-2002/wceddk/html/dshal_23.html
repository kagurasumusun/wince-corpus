IDsDriverCapture Interface

The IDsDriverCapture interface is the main control interface for the capture driver. This interface is nearly functionally identical to the IDsDriver interface, except that it adds sound capture capabilities.

The IDsDriverCapture interface contains the following methods:

IUnknown Methods Description
AddRef Increments the reference count.
QueryInterface Retrieves pointers to supported interfaces.
Release Decrements the reference count.
IDsDriverCapture Methods
Close Returns the object back to system use.
CreateCaptureBuffer Creates the capture buffer.
GetCaps Populates a DSDRIVERCAPS structure.
GetDriverDesc Retrieves a description of the driver.
Open Acquires the device for exclusive use.
