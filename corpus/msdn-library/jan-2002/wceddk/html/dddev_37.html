GetSysmemBltStatus

The GetSystemBltStatus callback function queries the status of an asynchronous DMA operation. 

DWORD __stdcall GetSysmemBltStatus(
LPDDHAL_GETBLTSTATUSDATA pgbsd );

Parameters

pgbsd
Pointer to a DDHAL_GETBLTSTATUSDATA structure that returns the blit status information.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED

Remarks

The prototype for this callback is identical to that of GetBltStatus. It is entirely legal for drivers to implement one routine and point both the GetSysmemBltStatus and the GetBltStatus callbacks at the same routine.
