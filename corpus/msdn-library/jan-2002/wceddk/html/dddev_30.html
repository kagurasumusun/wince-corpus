DestroyPalette

The DestroyPalette callback function destroys a specified palette. 

DWORD __stdcall DestroyPalette(
LPDDHAL_DESTROYPALETTEDATA pdpd );

Parameters

pdpd
Pointer to a DDHAL_DESTROYPALETTEDATA structure that contains information necessary to destroy the specified palette.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
