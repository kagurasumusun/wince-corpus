PixelFormat

This function is used to obtain the DDGPE-style pixel format for the current surface. It is a read-only attribute and cannot be changed after the surface is created.

virtual EDDGPEPixelFormat
PixelFormat (void );

Parameters

None

Return Values

This function returns the pixel format for the current surface.
