IOCTL_SERIAL_SET_DTR

This code sets the Data Terminal Ready (DTR) signal to high.

Parameters

dwOpenData
Handle returned from a call to the COM_Open function.
dwCode
Specifies this code.
pBufIn
Ignored.
dwLenIn
Ignored.
pBufOut
Ignored.
dwLenOut
Ignored.
pdwActualOut
Ignored.
