GetDriverGUID

This function allows your driver to obtain the driver-specific GUID that has been applied to the specified object. You should use this function instead of accessing the corresponding member variable directly.

virtual GUID GetDriverGUID (void );

Parameters

None

Return Values

The function returns the GUID for the specified object.
