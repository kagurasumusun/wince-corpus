DSK_Init

This function initializes disk devices, such as ATA, SRAM, and linear flash memory disks. After loading the device’s driver DLL, the Device Manager calls this function and passes to it the active key. This function verifies that the media is accessible. It then creates a client context structure for use by the device driver. For PC Card devices, it calls the CardRequestWindow and CardMapWindow functions to map the disk memory to device memory, and registers itself as a client driver with PC Card Services, if any PC Card is in use.
