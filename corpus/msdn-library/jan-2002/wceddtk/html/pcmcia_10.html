General Troubleshooting

The following are potential CEPC configuration issues:

  • If the CEPC has an IDE hard disk, it uses one of the I/O port ranges for ATA Flash cards.

    The ATA driver will try to use the secondary I/O port range. There is a limit of two IDE/ATA disks in the system, whether they are PCMCIA ATA Flash cards or IDE disk drives.

  • There are 4 standard COM port I/O ranges.

    The Windows CE PCMCIA modem driver will try to use 0x2E8 first, then 0x3E8. These are COM4: and COM3:, respectively, on the CEPC. However, on Windows CE the first PCMCIA modem is COM2:. This is done to avoid collisions with the debug COM port and the first serial port on a typical PC.

  • The Windows CE PCMCIA driver was written to control an Intel 82365 PCIC socket controller chip.

    The Windows CE PCMCIA driver uses IRQ 11 and uses 64K of low memory at 0xD0000-0xDFFFF for accessing common and attribute memory spaces. Slot 1 uses 0xD0000-0xD7FFF and slot2 uses 0xD8000-0xDFFFF.

When using a CEPC, do the following:

  • Verify that the system allows the use of memory 0xD0000-0xDFFFF
  • Verify that the IDE port addresses are available
  • Verify that I/O ports 0x3E0-0x3E3 are not being used by any other device on the ISA bus.
  • Verify that IRQ 11 is available.
  • Verify that no devices on the ISA bus are responding to memory addresses in the 0xD0000-0xDFFFF range.
