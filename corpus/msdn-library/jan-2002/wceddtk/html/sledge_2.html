General Troubleshooting

When the client instance of Sledge.exe has been running for a long time, Sledge.exe may terminate with a WSAECONNREFUSED error. The following screen shot shows the output for a sample error. 

Log created at 21:05:42.323 on 11/13/1999

Parsing command line script" packets-per-conn 100"
  PACKETS-PER-CONN: 100
Parsing command line script" serv-hostname host1"

Q to quit
In sledge @ line 461: Processing script file
In sledge @ line 479: Processing interactive commands

Sledge[0,TCP]: connect(0x0200 0x07D1 0x9D38970C) failed WSAECONNREFUSED (5 times)
Log ended at 21:05:54.354 on 11/13/1999

This error may occur due to the following reasons:

  • The host machines running the client and server instances of Sledge.exe may not be able to see each other on the TCP/IP network.

    Check the TCP/IP connectivity between the two machines using the Ping.exe utility.

  • There may be no server instance of Sledge.exe running on the server host machine.

    Verify that the server host machine has a server instance of Sledge.exe running before the client instance is started on the client host machine.
