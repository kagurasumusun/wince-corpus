Pcmintr test cases

These test cases test the following PC Card Services APIs using a single function modem card:

  • CardRequestIRQ
  • CardReleaseIRQ

The ISR function specified by CardRequestIRQ is tested by simulating modem interrupts.

The smoke test cases check the API for a particular card offset address and Configuration Option Register (COR) values.

The full test cases test for various combinations of card offset addresses and COR register values. These test cases also check boundary conditions by passing incorrect parameter values, such as a wrong socket number, to a function. The function should then return the appropriate error code. For example, if the parameter contains a bad socket number, the CERR_BAD_SOCKET error should be returned.

The Pcmintr 3 test case tests CardRequestIRQ using threads.

These test cases should not be run with a memory card. A modem card should be present when the test is finished.

Syntax/Parameters

The following command lines show the syntax for the test cases. 

rats pcmintr 0   - Smoke test for slot 1.
rats pcmintr 1   - Full test for slot 1.
rats pcmintr 2   - Smoke test for slot 2.
rats pcmintr 3   - Full test for slot 2.
rats pcmintr 5   - Force testintr to be only client device driver loaded
rats pcmintr 6   - Clear registry setting set by option 5

Troubleshooting

  • Because the 0x3F8 address in an x86 microprocessor conflicts with COM1:, which is used for debugging, it is not used as a card offset address in a CEPC.
  • In the debug window, a summary of results appears at the end of the test.
  • All of the tests should pass.

    If one of the tests has failed, analyze the debug output.

  • Some tests are expected to return with error codes.

    The result obtained should match the expected result.
