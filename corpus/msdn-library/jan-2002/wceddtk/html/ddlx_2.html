General Troubleshooting

Limitations have been place on the following:

  • Command line

    Maximum of 16 arguments and 128 characters.

  • Drvioctl.cpp

    Of all the required entry points that must be present in an installable device driver DLL, only the Gen_IOControl function is implemented. There are placeholders for all required entry points, but those placeholders only return a passing value if they are called. Developers are encouraged to implement these features as they are needed.
