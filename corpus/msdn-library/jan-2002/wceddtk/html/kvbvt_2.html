General Troubleshooting

The following messages may occur during testing:

  • "Exception !!! - Should not have happened"

    A write to a committed memory caused an exception.

  • "No Exception !!! - An Exception should have occurred"

    A write to a de-committed or released virtual memory did not cause an exception as expected.

  • "Go Unhandled"

    The try/catch exception handling is part of both tests. This is not an error because Kvbvt.dll will catch these exceptions when running under the debugger; no command line switches are actually passed to the tests.

  • Tux unknown command error

    Occurs if one or more of the .dll files that Tux.exe requires is missing.
