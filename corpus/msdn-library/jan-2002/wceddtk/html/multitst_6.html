General Troubleshooting

  • The summary statistics from Kato after each test describe the status of each test.
  • All keyboard messages generate a Kato LOG_DETAIL message. The type, virtual key code, character, and LPARAM of the message are included in the log message. This information can be useful for later determining what key sequence generated a failure.
  • During every test, the test name and instructions are displayed. If no keys are pressed for 20 seconds, the test times out and allows you to quit.
  • If the .dll files that Tux requires are missing, a Tux unknown command error is displayed.
