General Troubleshooting

The most common error encountered is a failure to connect to the remote server. This may be caused by one of the following:

  • A defective or intermittent modem device or other hardware.

    A common scenario is a null modem or modem adapter that does not have all the handshaking signal lines connected.

  • Failure of the telephone system when using a dial-up connection.
  • An incorrect telephone number.
  • An incorrect baud or related parameter.

The progress of a call may be monitored using the RASDIALEVENT messages in the debug output. The following messages appear during a typical call:

  • OpenPort

    RAS is initializing the device.

  • PortOpened

    The device has been initialized and a call is being made.

  • DeviceConnected

    A physical link has been established to the remote server.

  • AllDevicesConnected

    All physical links have been completed and RAS connection negotiation has started.

  • Authenticate

    A password authentication request from the remote server has been received.

  • AuthAck

    A reply to the password authentication request has been sent.

  • Authenticated

    The remote server has verified the password.

  • Connected

    The RAS connection has completed successfully.

  • Disconnected

    The RAS connection has been terminated.

Some of the more common RAS error codes encountered while running the test include the following:

  • ERROR_NO_CARRIER, ERROR_NO_ANSWER

    The RAS client was unable to make a physical connection to the server. This error normally occurs while a call is in the PortOpened state and may be the result of any of the hardware or configuration errors listed previously.

  • ERROR_DEVICE_DOES_NOT_EXIST

    The device listed in the RAS phonebook entry is not present. For example, a PCMCIA modem may not be in the slot.

  • ERROR_PORT_ALREADY_OPEN

    The device listed in the RAS phonebook entry is unavailable because it is already being used by another process.

  • ERROR_LINE_BUSY

    A busy signal has been received.

  • ERROR_PORT_DISCONNECTED, ERROR_DISCONNECTION

    The physical connection has been dropped unexpectedly. This error can occur either because of hardware problems or because RAS connection negotiation has been rejected.

  • ERROR_ACCT_DISABLED

    The RAS account you are trying to use has been disabled on the server and must be enabled by an administrator.

  • ERROR_NO_DIALIN_PERMISSION

    The RAS account you are trying to use does not have dial-in permission on the RAS server.

  • ERROR_AUTHENTICATION_FAILURE

    The password has been rejected. Windows CE does not allow RAS phonebook entry passwords to be copied and will display the password authentication dialog box the first time authentication is requested. This can be avoided by using a blank password or by setting Always Allow Directly Connected Devices To Connect Without A Password on the RAS server.
