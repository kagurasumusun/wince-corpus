Running the Test

The architecture of the USB client driver relies on a separate Device Driver Loader/TUX Extender DLL module (DDLX), which is used to automate the large number of USB test cases.

The following command line shows the syntax for using Tux.exe and Ddlx.dll to run the test, where test_case is the specific test case or range of test cases to run.

tux –o –d ddlx.dll –c usbbvt.dll -x test_case

The following command line shows the syntax for using Tux.exe and Ddlx.dll to run the entire test.

tux –o –d ddlx.dll –c usbbvt.dll

The following command line shows the syntax for outputting a list of all available test cases. 

tux –o –l –d ddlx.dll –c usbbvt.dll

Usbbvt.dll uses the RegisterClientSettings API to register itself as the client driver that will be loaded when the Intel I80930Ax test board is connected. This registration is performed either during the connection of the unknown device, which occurs when the USB subsystem presents the user with a dialog prompt for the driver DLL name (Usbbvt.dll), or during execution of the Usbload.exe utility.

The following command line shows the syntax for installing the Usbbvt.dll driver.

s usbload.exe usbbvt.dll

Once registered, the client driver is not loaded until a USB device is connected. At that time, USB enumerates the device and uses callback to notify Usbbvt.dll of the event. The USB client driver then accepts control of the device and callback because it is now fully installed in memory.

Once Usbbvt.dll is installed as an Intel I80930Ax test board client driver, any corresponding devices inserted from that point on will use it as a client driver. Usbbvt.dll does not affect any devices that have already been connected before its registration.

The following command line shows the syntax for listing the currently registered USB drivers.

s usbload.exe

The registry entries for Usbbvt.dll that are installed and reported by the Usbload.exe utility are as follows:

[USB]
     [LoadClients]
         [1118_37642]
             [Default]
                 [0_0_0]
                     [USBBVT I80930AE Driver]
                         SZ: DLL = usbbvt
     [ClientDrivers]
         [USBBVT I80930AE Driver]

After it is no longer needed, the Usbbvt.dll client driver can be unloaded with the Usbload.exe utility. This is necessary so that normal USB functionality can resume. All devices that were using the driver must be disconnected to fully remove it from memory.

The following command line shows the syntax for uninstalling the Usbbvt.dll driver:

s usbload.exe usbbvt.dll unload
