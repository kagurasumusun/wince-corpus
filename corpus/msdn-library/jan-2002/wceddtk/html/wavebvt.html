Wave Build Verification Test

The Wave Build Verification test, Wavebvt.dll, verifies the wave API functions. Each test is run interactively—the tester verifies the results by listening. Since the wave API calls are eventually routed to the audio drivers, the test cases indirectly test the audio drivers.

Windows CE supports waveform audio devices. Applications can access the audio device using the wave API. A waveform audio driver is responsible for processing messages from the Wave API Manager to play and record waveform audio.

The test cases in the Wave Build Verification test include the passing of bad parameters, which send buffers to the driver to play and record in the standard PCM format. The test automatically verifies if correct error codes are being returned for bad parameters; however, the testing of audio input and output requires manual verification.
