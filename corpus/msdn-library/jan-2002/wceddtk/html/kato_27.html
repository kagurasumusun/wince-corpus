CKato::SetItemData

This function associates a 32-bit application-specific value with the CKato object that can later be retrieved by GetItemData.

BOOL SetItemData (
DWORD dwItemData );

Parameters

dwItemData
A 32-bit value to be associated with the CKato object.

Return Values

Nonzero if successful; otherwise, 0.

Remarks

SetItemData and GetItemData allow applications to associate application-specific data to a CKato object. This could be a single value, a pointer to a structure of data, a next pointer for a linked list, and so on.
