Function Table

The function table is used by a Tux test DLL module as a way of exporting its test cases to Tux. A test DLL module usually creates a static array of FUNCTION_TABLE_ENTRY structures, filling in each of the fields with the relevant information. Each structure in the function table array represents a single test or test group in the test DLL module. The FUNCTION_TABLE_ENTRY structure is described in the following topic. See Tuxdemo.h for a sample function table.
