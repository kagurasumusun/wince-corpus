USB Build Verification Test

The USB Build Verification test, Usbbvt.dll, uses an Intel I8x930Ax USB evaluation board in loopback mode to verify bulk, interrupt, and isochronous universal serial bus (USB) transfers. Blocks of data are sent to the evaluation board, and returning data is verified for accuracy for each transfer type. In addition, all three transfer types are run in separate threads simultaneously to stress the USB driver and to evaluate the USB system throughput.

The following table shows the hardware requirements.

Requirements Description
Intel I8x830Ax evaluation board. USB Transfer Verification test is based on Intel I8x9300 AX USB evaluation board in loopback mode.

The following table shows the software requirements.

Requirements Description
Usbbvt.dll Test .dll file.
Usbload.exe Utility required for loading Usbbvt.dll.
Tux.exe Tux Test Harness, which is required for executing the test.
Kato.dll Kato Logging Engine, which is required for logging test data.
Tooltalk.dll Application required by Tux.exe and Kato.dll. Handles the transport between the target device and the development workstation.
Ddlx.dll Device Driver Loader and Tux Extender, which is required because the test runs in driver mode (Device.exe).
