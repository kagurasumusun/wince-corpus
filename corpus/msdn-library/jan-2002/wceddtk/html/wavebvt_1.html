Running the Test

The following command line shows the syntax for using Tux.exe to run the test, where test_case is the specific test case or range of test cases to run.

tux –o –d wavebvt.dll [-c "-p wave files path"] [–x test_case]

The following command line shows the syntax for using Tux.exe to run the entire test.

tux –o –d wavebvt

The following command line shows the syntax for running the audio output tests.

tux –o –d wavebvt.dll –x10-37

The following command line shows the syntax for running the audio input tests.

tux –o –d wavebvt.dll –x60-99

The following command line shows the syntax for playing .wav files from a particular directory, such as \storage card\.

tux –o –d wavebvt.dll –c “–p \storage card\” –x99

Most of the tests prompt the user for validation after playing a sound. It is left to the user to determine if the quality of the sound played was satisfactory.

Tests 61–65 record sound in different formats. When these tests are run, a message box is displayed before recording begins. Start recording after clearing this message box.

After each test case finishes, a status report is displayed indicating whether it passed, failed, skipped, or aborted. After all of the specified test cases have finished, a summary of results is displayed.

The following source files are included in the Wave Build Verification test:

  • PlaySnd.cpp

    Contains tests for sndPlaySound and playSound functions.

  • Wavein.cpp

    Contains tests for waveIn* functions.

  • Waveout.cpp

    Contains tests for waveOut* functions.

  • Waverec.cpp

    Contains depth test waveRecordToFileTest, which records sound input from the user and stores it as .wav files in the test directory.

  • Waveplay.cpp

    Contains depth tests WavePlayFileTest, which plays back the sound recorded by WaveRecordToFileTest. Contains PlayAllWaveFilesTest, which plays all files in the storage disk path that is specified on the command line.

  • WaveFile.cpp

    Contains a c++ class that implements the functionality of opening, closing, reading and writing from .wav files.

Wavebvt3.wav PCM, 11025 kHz, 16-bit, mono.
Wavebvt4.wav PCM PCM, 11025 kHz, 16-bit, stereo.

Wavebvt6.wav PCM, 22050 kHz, 8-bit, stereo.

Wavebvt8.wav PCM 22050 kHz, 16-bit, stereo.
Count.wav PCM, 11025 kHz, 8-bit, mono.

If the audio driver does not support a particular format, the test that uses the corresponding wave file will fail and can be ignored.

Before you run the test, you should copy the .wav files in the Waveacm\Image directory to the \Windows directory on the target device. If you copy these .wav files to another directory, such as a storage card directory, you should specify the path in the command line when you run the test.

In addition to the standard Tux.exe parameters for selecting tests to run, PSerial.dll supports its own parameter, -p, that is passed by using the Tux –c parameter.
