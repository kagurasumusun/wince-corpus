Smart Card Resource Manager Build Verification Test

The Smart Card Resource Manager Build Verification test, Scardbvt.dll, includes multi-smart card queries, tracking, access, and direct access tests.

The following table shows the hardware requirements.

Requirements Description
Smart card reader such as PCMCIA SCM Reader, BullTLP3 Serial Reader, or STC USB Reader. The reader driver is related to the hardware; different hardware may use different drivers.
PC/SC compliance test card Test uses compliance test cards to verify reader function.

The following table shows the software requirements.

Requirements Description
Scardbvt.dll Test .dll file.
Tux.exe Tux Test Harness, which is required for executing the test.
Kato.dll Kato Logging Engine, which is required for logging test data.
Tooltalk.dll Application required by Tux.exe and Kato.dll. Handles the transport between the target device and the development workstation.
