Touch Screen Test Cases

This test suite verifies that the touch screen driver is working properly.

Verifies detection of a single tap on the screen. This test case requires user interaction, which determines its success or failure.

Test Case 42 - Double Tap Test

Verifies detection of a double tap. This test case requires user interaction, which determines its success or failure.

Verifies smooth detection of a pen drag. This test case requires user interaction, which determines its success or failure.
