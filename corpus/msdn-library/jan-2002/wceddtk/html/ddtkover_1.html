Prerequisites for Running the DDTK Tests

The following hardware is required for running the DDTK tests:

  • Development workstation

    Platform Builder is installed on the development workstation. In addition, it can be used to run the debugger.

  • Target device

    The hardware that runs a Platform Builder custom platform.

The following hardware is optional for running the DDTK tests:

  • Debugger machine

    A machine that is dedicated for debugging and capturing test logs.

To perform the steps required for running the DDTK tests

  1. Install Platform Builder on your development workstation.
  2. Create an operating system (OS) image with all of the necessary components, including the DDTK30 component. For information, see the Platform Builder documentation.
  3. Build the DDTK tests.

    For information, see Building the DDTK Tests.

  4. Run the DDTK tests on the target device. For information, see Running the DDTK Tests.

    For tests that require Tux.exe, the required files on the target device are:

    • Tux.exe
    • Kato.dll
    • Tooltalk.dll
    • The test .dll file

      For example, if the test is named Tuxdemo, the test .dll file will be named Tuxdemo.dll.

    For all other tests, the required files on the target device are:

    • Test .exe file
    • Related .dll and other miscellaneous files
