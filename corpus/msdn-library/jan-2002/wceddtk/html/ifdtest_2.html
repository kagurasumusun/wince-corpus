General Troubleshooting

Even if this test is successful, there may still be problems with the smart card reader driver when used by the Smart Card Resource Manager. To verify whether this driver works correctly with the Smart Card Resource Manager, run the Smart Card Resource Manager Build Verification test.

For information about smart cards, see the Microsoft Windows Smart Card Toolkit
