Interrupt Latency Timing Test

The Interrupt Latency Timing test, Iltiming.exe, is used to benchmark and verify the real-time performance of the Windows© CE operating system (OS) on a custom hardware platform.

This test measures interrupt service routine (ISR) and interrupt service thread (IST) latencies—the time for the Windows CE OS to respond to interrupts. The ISR latency is the time interval that begins when the hardware interrupt line is set at the CPU and ends when the OEM ISR code begins execution. The IST latency is the time interval from the end of the OEM ISR routine to the beginning of the IST.

The main thread of the Iltiming.exe application waits on the SYSINTR_TIMING interrupt event, thus becoming the IST. As soon as the event is triggered, the IST receives the current time. The time stamps used by Iltiming.exe are the counter values of the high-resolution timer since the last system tick. The OEM exports a special function, PerfCountSinceTick, by calling the KernelIoControl function with the IOCTL_HAL_ILTIMING I/O control. The Iltiming.exe application starts and stops the testing in the OEM Adaptation Layer (OAL) and gets the ISR timings with IOCTL_HAL_ILTIMING.

The following table shows the software requirements.

Requirements Description
Iltiming.exe Main test executable file.
Iltiming_dll.dll Test .dll file.
Implement IOCTL_HAL_ILTIMING in the OAL For information, see Iltiming.h and the Oemioctl.c sample file.
