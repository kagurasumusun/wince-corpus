General Troubleshooting

  • Some Fslogo.dll test cases deliberately corrupt file system information on the storage card.

    It is necessary to format the card after running these test cases and before trying to use the card as a real file system. Older test case versions made the card uncorrectable unless the partition information was reset with a Windows 9x machine.

  • The FAT file system has problems handling storage card volumes formatted with multi-sector clusters.
  • When an error occurs, a Win32 error code is printed.
  • If the .dll files that Tux requires are missing, a Tux unknown command error is displayed.
