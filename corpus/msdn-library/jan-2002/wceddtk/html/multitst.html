Multiple Driver Test

The Multiple Driver test, Multitst.dll, provides several test cases for the audio, display, touch screen, and keyboard drivers. It is an interactive test program—the tester needs to manually verify most test results.

The following table shows the hardware requirements.

Requirements Description
Sound card, microphone, and speakers Required for audio test cases.
Keyboard Required for keyboard test cases.
Device with touch screen Required for touch screen test cases.

The following table shows the software requirements.

Requirements Description
Multitst.dll Test .dll file.
Tux.exe Tux Test Harness, which is required for executing the test.
Kato.dll Kato Logging Engine, which is required for logging test data.
Tooltalk.dll Application required by Tux.exe and Kato.dll. Handles the transport between the target device and the development workstation.
