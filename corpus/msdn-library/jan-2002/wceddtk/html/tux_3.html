Tux Test Module Interface

All Tux test modules must contain the following:

  • A function table to define all test cases in the test module.
  • A ShellProc function to handle Tux-related messages.
  • One or more TestProc test case functions, located in the function table.

This section provides an overview of all structures, messages, and functions used by a Tux Test DLL module. A sample test, named Tuxdemo, has been written to illustrate how to write a Tux test module. The source files for Tuxdemo are referenced in the following topics and should be used as a template for creating your first test DLL.
