Printer Driver Test

The Printer Driver test, Prnttest.dll, tests the printer driver by testing the most important GDI functions. These functions are tested because the printer driver works closely with GDI modules and Prnport.dll. If the printed output matches the expected output, the test is successful; otherwise, an error has occurred in the printer driver.

The Printer Driver test consists of two parts: an automatic printing test and a manual test.

The following table shows the hardware requirements.

Requirements Description
Supported printer One of the following printers:
  • HP DeskJet 694C
  • HP DeskJet340
  • HP LJ5P
  • HP LJ6P
  • HP LJ4000
  • HP LJ5Si

The following table shows the software requirements.

Requirements Description
Prnttest.dll Test .dll file.
Tux.exe Tux Test Harness, which is required for executing the test.
Kato.dll Kato Logging Engine, which is required for logging test data.
Tooltalk.dll Application required by Tux.exe and Kato.dll. Handles the transport between the target device and the development workstation.
