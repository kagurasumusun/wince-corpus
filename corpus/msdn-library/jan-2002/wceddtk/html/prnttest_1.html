Running the Test

The following command line shows the syntax for using Tux.exe to run the test, where test_case is the specific test case or range of test cases to run.

tux –o –d prnttest –x test_case

The following command line shows the syntax for using Tux.exe to run the entire test.

tux –o –d prnttest

After each test case finishes, a status report is displayed indicating whether it passed, failed, skipped, or aborted. After all of the specified test cases have finished, a summary of results is displayed.

The following table shows the test cases sorted by printer connection type.

Test Case Description
1–10 Test suite for IRDA printing.
101–110 Test suite for serial port 57600 printing. Printer must be set to this speed.
201–210 Test suite for serial port 9600 printing. Printer must be set to this speed.
301–310 Test suite for parallel port printing, CEPC only. The CEPC must have an extra parallel card that has its I/O address set to 0x278.
401–410 Test suite for network printing. The Ethernet PC card must be plugged into the PCMCIA slot.

Manual Test 1

This manual test tests whether the printer driver can correctly handle different sizes of paper. It applies to IRDA, serial, parallel, and network printing and runs only one printing job. It prints different text strings inside of the printable area, which is outlined as a rectangle.

To run this test

  1. Type the following command line. 
    tux -o -d prnttest -x600
  2. Select the correct port.
  3. Select one of the following paper sizes to print: Letter, Legal, A4, or B5.

    For these paper sizes, the printing output should be a full page. The top and left margins should be less than or equal to 6.5 millimeters.

    This test ignores the user's margin input; it always prints in full-page mode. This test prints only in monochrome mode.

Manual Test 2

This manual test tests whether the printer driver can correctly detect a printer error and resume correctly. This test applies to IRDA, serial, and parallel printing. It runs only one printing job, which has one page of text.

To run this test

  1. Enter one of the following command lines, according to your printer connection:
    • IRDA 
      tux -o -d prnttest –x1
    • Serial (57600 baud) 
      tux -o -d prnttest -x101
    • Parallel 
      tux -o -d prnttest -x301
  2. Pull out the paper drawer when the following debugger terminal output appears: 
    DrawPageFullText Starts

    After 45 seconds, the printer driver outputs an error message dialog box with Retry and Cancel buttons and the following display: 

    Timeout on printer on port xxxx
  3. Push back the paper drawer and choose Retry.

    The printing job should continue and print out a full page of text.

    – Or –

    Choose Cancel.

    The printing job should stop.

Manual Test 3

This manual test tests whether the printer driver can correctly handle aborting an action from the printing status dialog. This test applies to IRDA, serial, parallel, and network printing.

To run this test

  1. Enter one of the following command lines, according to your printer connection:
    • IRDA 
      tux -o -d prnttest –x1
    • Serial (57600 baud) 
      tux -o -d prnttest -x101
    • Parallel 
      tux -o -d prnttest -x301
    • Network 
      tux -o -d prnttest -x401
  2. Choose Cancel if a printing status dialog box with a cancel button is displayed.

    The printing job should now be canceled. However, up to half a page of text may still continue to print, depending on how much data is left in the print buffer.

Network printing test cases

Test cases 401–410 test network printing.

To run the network printing test cases

  1. Boot the MAXALL target device.
  2. After calibration, plug in the network card.
  3. When the NE2000 Compatible Ethernet Driver Setting dialog appears, verify that the default selection is selected under Obtain An IP Address Via DHCP.
  4. Choose OK.
  5. Choose Communication in Control Panel.
  6. In the Communications Properties dialog box, change the target device name.
  7. Choose OK.
  8. Choose Network in Control Panel.
  9. In the Network Configuration dialog box, choose Identification.
  10. Type your user name, password and domain name.
  11. Choose OK.
  12. Type the following command line to run network printing. 
    tux -o -d prnttest -x401-410

    This test runs 10 print jobs for a total of 25 pages.

  13. Enter the network printer path in the network printer dialog box.
  14. After Prnttest.dll receives the network printer path, it will start to print.
