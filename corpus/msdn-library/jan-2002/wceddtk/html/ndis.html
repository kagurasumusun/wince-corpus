NDIS Test

The NDIS test tool, NDISTest, allows you to perform functionality, stress, and performance tests on NDIS miniport drivers. NDISTest is implemented as a protocol driver and ships with a set of LAN test scripts.

NDISTest performs two important tasks: it verifies the driver operations of your network interface card and ensures that your product conforms to the Network Driver Interface Specification (NDIS) version 4.0. Note that NDIS version 3.0 drivers are no longer being certified for Windows NT, Windows 95/98, or Windows CE.

NDISTest achieves high flexibility by using the Hapi script interpreter, Hapi.exe. The Hapi script interpreter provides a simple, pseudo C-language environment that has built-in variable types and a control flow that resembles the C language. Hapi.exe reads the Hapi.ini configuration file, sets up the correct configuration, and initializes the underlying Ndistst.dll file.

After it has been initialized by Hapi.exe, Ndistst.dll registers the underlying Ndtsys.dll file, which performs the functionality of a Windows CE protocol driver. Ndtsys.dll communicates with the underlying miniport driver through the NDIS wrapper, and passes the results of each driver query back to the Hapi script interpreter.

NDISTest function testing verifies the functionality of each NDIS request that is supported by the network card driver. NDISTest tests the packet send and receive functions by emulating a transport layer protocol driver and communicating with the network card driver through the NDIS wrapper. To test a variety of network configurations, multiple instances of NDISTest are bound to each driver; NDISTest can simulate up to eight network stacks installed on the same machine.

NDISTest performance testing determines how well a network card handles the sending and receiving of data at full media bandwidth. NDISTest stress testing sends many small packets, and packets containing degenerate buffers.

The following features are new for the Windows CE 3.0 version of NDISTest:

  • Performance testing
  • Stress testing
  • Support for testing IrDA drivers
  • Support for testing Token Ring miniport drivers

NDISTest for Windows CE versus Windows NT

Because NDISTest for Windows CE is similiar to NDISTest for Windows NT, it is recommended you familiarize yourself with the Windows NT version of the NDISTest software as documented in the Microsoft Windows NT Device Driver Kit. The following are the primary differences between the Windows CE and Windows NT versions of NDISTest:

  • Windows CE NDISTest does not support the TDI tests.
  • Windows CE NDISTest lacks a GUI to configure and start the tests.
  • Windows CE NDISTest supports drivers for Ethernet, Token Ring, and IrDA. It does not support drivers for ATM, 1394, WAN and TDI.
  • Unlike Windows NT, Windows CE NDISTest supports a family of microprocessors.

    NDISTest is supported on any reference platform that supports PCMCIA. NDISTest on Windows CE has been successfully tested on x86, SH3, and SH4 microprocessors; functionality with other microprocessors is not guaranteed.

Requirements Description
PC Card Storage device that fits in a PCMCIA slot.

The following table shows the software requirements.

Requirements Description
Hapi.exe Script interpreter, which executes the tests and displays the results.
Hapi.ini Hapi configuration file.
H_core.dll Hapi core .dll file.
Ndistst.dll Hapi extension .dll file, which makes NDIS specific commands available to the Hapi shell.
Ndtsys.dll Windows CE NDIS protocol driver and stream interface driver. It is registered with Device.exe in Ndistst.dll.
Script files Test scripts files (*.tst) to run, which are located in the Cescripts directory.
