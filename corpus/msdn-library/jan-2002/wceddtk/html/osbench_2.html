                INTERPRETING THE OSBENCH RESULTS
-------------------------------------------------------------------
  OSBench measures key operating system timings as closely as
  possible. All tests use the QueryPerformanceCounter (QPC) to get
  time stamps. The frequency of the counter and the overhead of
  calling this function must be taken into account when
  analyzing the results.

  Some operations take a very small time to complete. The overhead
  of calling QPC becomes significant. In these case, the operation
  is looped for a fixed number of iterations per sample (IPS).
  The IPS is listed with each test. IPS of 1 means QPC is called
  around only one instance of the operation. This will show
  variation in the run times of the operation. For larger IPS,
  the individual run times are averaged out, but the average
  time is far more accurate. A noteable side effect of this
  looping is that the cache cannot be flushed between each
  iteration of the operation. For tests of IPS = 1, the test is
  run with both a cache flush on each sample and without a cache
  flush on each sample.

  The cache sync   status is noted for each test (CS = YES/NO)
  The interprocess status is noted for each test (IP = YES/NO)
