Masks test cases

These test cases test the following PC Card Services APIs with memory and I/O cards:

  • CardGetStatus
  • CardGetEventMask
  • CardSetEventMask
  • CardRequestSocketMask
  • CardReleaseSocketMask
  • CardResetFunction

The smoke test case checks the APIs for a particular value of the event mask parameter.

The full test case checks the APIs for a range of values for the event mask parameter. Both the global and local mask settings are tested. The callback events are checked in the callback function to determine whether the setting and masking of hard and artificial events is occurring.

Boundary and parameter checking are performed for both test cases. Invalid parameters, handles, and sockets are passed to verify the proper return of error codes. Testing with threads is also performed.

The CardReset function is tested for various socket and function pairs.

Syntax/Parameters

The following command lines show the syntax for the test cases. 

rats masks 0     - Smoke test for slot 1 and  2
rats masks 1     - Full test for slot 1 and 2

Troubleshooting

  • In the debug window, a summary of results appears at the end of the test.
  • All of the tests should pass.

    If one of the tests has failed, analyze the debug output.

  • Some tests are expected to return with error codes.

    The result obtained should match the expected result.
