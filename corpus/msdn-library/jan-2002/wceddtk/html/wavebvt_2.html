General Troubleshooting

All tests should pass, with some exceptions:

  • A device may not support a particular format, such as 22 kHz PCM.

    The results of the test cases that use wave files of this format can be ignored. Note that the test might still pass if the device has ACM drivers loaded.

  • A device may only support audio output, not input.

    In this case, only audio output test cases should be run.

  • Many of the tests will fail if you do not copy the test .wav files to the \Windows directory of the device.

    Run the test again after copying the .wav files.

  • If the .dll files that Tux requires are missing, a Tux unknown command error is displayed.
