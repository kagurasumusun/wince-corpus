TAPI Test

The TAPI test, Xtapimc.exe, verifies basic Telephony API (TAPI) functionality, especially the ability to complete outbound calls.

This test repeatedly sets up and dials a call on a TAPI-enabled device. It does not attempt any communication beyond simple device connection. Up to 15 of the 19 TAPI 1.5 APIs are tested. It may be used as a build verification test (BVT); as a breadth test, by varying command-line settings; and as a stress test, by setting it to dial multiple times.

The following table shows the hardware requirements.

Requirements Description
A TAPI device External modem, PCMCIA modem, null modem, or IR modem.

The following table shows the software requirements.

Requirements Description
Xtapimc.exe Test .exe file.
Common library files Located in the Netlib directory.
