TestProc Function

The TestProc function prototype is used for all test cases listed in the module's function table. The following is the syntax for a test case function named TestProcExample.

TESTPROCAPI TestProcExample (
UINT uMsg,
TPPARAM tpParam,
LPFUNCTION_TABLE_ENTRY lpFTE )

Parameters

uMsg
TestProc functions are always called with known defined message value in the uMsg parameter.
tpParam
Dependent on the uMsg parameter and is usually a pointer to a structure for that message type.
lpFTE
Pointer to the DLL’s global function table array, which represents the current test. From this pointer, the DLL can reference all fields in the function table entry, such as the lpDescription, dwUserData and dwUniqueID.

Remarks

TestProc functions should return TPR_NOT_HANDLED for all messages that are not handled. See Tuxdemo.cpp for sample TestProc implementations.
