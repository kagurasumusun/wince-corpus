General Troubleshooting

The Windows CE NE2000 sample driver does not support querying. When a NE2000 card is used with NDISTest, the following OIDs will cause certain tests to fail. The following errrors should be ignored:

  • OID_MULTICAST_LIST

    1c_multi tests fail

  • OID_GEN_CURRENT_PACKET_FILTER

    1c_filtr tests fail

  • OID_GEN_MEDIA_CONNECT_STATUS

    1c_media tests fail

The following errors applies to the Windows NT version of NDISTest:

  • One of the test scripts fails when run as part of the full test suite, but passes when run alone.

    This is most likely a resource problem. The tests that are run before the failing test may fail to free a resource properly. Alternatively, the previous script may have left the card in a state that is incompatible with the failing script. However, this is unlikely because each script closes all open instances before exiting.

  • A command error dialog box is displayed while running the test.

    Choose Cancel to exit NDISTest. If the problem is a breakpoint within NDISTest, a message will be written to the debugger just before the breakpoint is hit. If the problem is a bug check or a crash, perform a stack dump to determine where the fault occurred. If the problem appears to be within NDISTest, verify that any parameters your driver may have passed to NDISTest are correct.

For the latest version of NDISTest for Windows NT and supporting documentation see this Microsoft FTP site. It contains a self-extracting archive file Ndisbeta.exe that you can download to an empty subdirectory and extract using the following command:

ndisbeta -d
