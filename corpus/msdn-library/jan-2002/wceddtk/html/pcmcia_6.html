Pcmconf test cases

These test cases test the following PC Card Services APIs with I/O cards:

  • CardRequestConfiguration
  • CardReleaseConfiguration
  • CardRequestIRQ
  • CardReleaseIRQ.

The smoke test cases check the APIs for a particular value of the configuration register and card offset address parameters.

The full test cases check for various values of the configuration register, PC card offset address, fRegister, and status register parameters.

Boundary and parameter checking are performed for all test cases. Invalid parameters, handles, and sockets are passed to verify the proper return of error codes. Testing with threads is also performed.

Some I/O cards may not support the soft resetting of the card; for example, when the MSB of ConfigReg is one.

Syntax/Parameters

The following command lines show the syntax for the test cases. 

rats pcmconf 0     - Smoke test for slot 1
rats pcmconf 1     - Full  test for slot 1
rats pcmconf 2     - Smoke test for slot 2
rats pcmconf 3     - Full test for slot 2

Troubleshooting

  • Some I/O cards may not support the soft resetting of the card.
  • In the debug window, a summary of results appears at the end of the test.
  • All of the tests should pass.

    If one of the tests has failed, analyze the debug output.

  • Some tests are expected to return with error codes.

    The result obtained should match the expected result.
