Sledge Test

The Sledge test, Sledge.exe, is an application that can be used to send and receive data via TCP/IP, IrDA or IrCOMM.

Sledge.exe exercises and stress tests several network protocol layers on a Windows CE platform, including Winsock, TCP/IP, IrDA, and PPP. It also tests the NDIS library and any associated NDIS intermediate or miniport drivers. It can be used as a simple functional test to verify that end-to-end data transfer can be successfully achieved on a Windows CE platform via TCP/IP, IrDA or IrCOMM. This test is especially useful for developers working on network drivers.

Sledge.exe can be run in either client or server mode. A client instance of Sledge.exe is run against a server instance of Sledge.exe. Typically, the client and server instances are run on two different machines, one of them being a Windows CE platform. The server instance must be started before the client instance.

The following table shows the hardware requirements.

Requirements Description
Target device This is typically the Windows CE platform on which the client instance of Sledge.exe is run. If the test requires TCP/IP, this host should have an Ethernet or modem card or a serial communications port to interface with an external modem. If the test requires IrDA/IrCOMM, this host should have an IR card or a serial communications port to interface with an IR dongle.
Development workstation This is the host on which the server instance of Sledge.exe is run. If the test requires TCP/IP, this host should have an Ethernet or modem card or a serial communications port to interface with an external modem. If the test requires IrDA/IrCOMM, this host should have an IR card or a serial communications port to interface with an IR dongle.

The following table shows the software requirements.

Requirements Description
Sledge.exe (Windows CE version) Windows CE Sledge test executable.
Sledge.exe (Windows NT version) Windows NT Sledge test executable.
