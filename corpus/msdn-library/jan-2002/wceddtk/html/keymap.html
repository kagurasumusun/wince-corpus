Keyboard Mapping Test

The Keyboard Mapping test, Keymap.dll, provides several manual tests of the keyboard and its driver based on an English (US) keyboard. The keyboard tests are interactive, requiring the tester to visually verify the results of a test.

The Keyboard Mapping test has two main parts:

  • A generic test engine, the Keyboard Mapping Engine, which verifies that each virtual key is correctly converted into a UNICODE character by the keyboard driver.
  • A sample test case for the Standard American English Keyboard that uses the test engine to test the keyboard.
