KatoDestroy

This function destroys a CKato object.

BOOL KatoDestroy (
HKATO hKato );

Return Values

Nonzero if successful; otherwise, 0.

Parameters

hKato
Handle to a CKato object.

Remarks

All CKato objects that are created by calling KatoCreate must be destroyed by calling KatoDestroy.
