PCMCIA Driver Test

The PCMCIA Driver test tests Device.exe and Pcmcia.dll. Windows CE has support for two types of device drivers: built-in and installable. With the exception of the serial and PCMCIA drivers, all built-in drivers are linked into Nk.exe and Gwes.exe.

Device.exe, the Window CE Device Manager, loads all installable device drivers. After Device.exe loads Pcmcia.dll, the PC Card Services APIs notify Device.exe any time a PC card is inserted into or removed from a PCMCIA slot, which is called a socket event. When a socket event is detected, Device.exe attempts to find the correct client driver to load, based on entries in the registry and information provided by Pcmcia.dll. If the correct client driver is found, Device.exe loads the driver into its process space and registers the driver as active. An application may also request a driver be loaded into memory by Device.exe by using the RegisterDevice API.

Once a client driver is loaded, it uses the same PC Card Services APIs used by Device.exe to communicate with Pcmcia.dll. Using these APIs, a client driver can retrieve information about the inserted PC card, configure the PC card, and perform I/O functions on the PC card.
