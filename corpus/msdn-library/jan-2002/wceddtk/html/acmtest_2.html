General Troubleshooting

  • There should be no test case failures.
  • In general, the test case will skip if an ACM driver is not detected, which should not be viewed as a failure.
  • If no filter drivers are found, the acmFilter test cases will skip.
  • If no CODECs or converters are found, the acmFormat test cases will skip.
  • If the .dll files that Tux requires are missing, a Tux unknown command error is displayed.
