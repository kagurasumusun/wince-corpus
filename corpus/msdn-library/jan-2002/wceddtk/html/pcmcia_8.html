Pcmwin test cases

These test cases test the following PC Card Services APIs with memory and I/O cards:

  • CardRequestWindow
  • CardReleaseWindow
  • CardMapWindow
  • CardModifyWindow

The smoke test cases check the API for a particular attribute, access speed and size for CardRequestWindow, CardMapWindow, and CardModifyWidow.

The full test cases test the CardRequestWindow and CardReleaseWindow with a combination of attribute, access speed, and size parameters. The various combinations are tested for common, I/O, and attribute memory spaces. CardMapWindow is tested with various PC card offset values.

Boundary and parameter checking is performed for all test cases. Invalid parameters, handles, and sockets are passed to verify the proper return of error codes. Testing with threads and various clients is also performed.

Syntax/Parameters

The following command lines show the syntax for the test cases. 

rats pcmwin 0    - Smoke test for slots 1 and 2
rats pcmwin 1    - Full test for slots 1 and 2

Troubleshooting

  • Not all I/O cards support 16-bit access

    When the Attributes to CardRequestWindow is set to 16-bit access, some cards may fail in CardMapWindow.

  • In the debug window, a summary of results appears at the end of the test.
  • All of the tests should pass.

    If one of the tests has failed, analyze the debug output.

  • Some tests are expected to return with error codes.

    The result obtained should match the expected result.
