SPM_UNLOAD_DLL

This message is sent once to the DLL immediately before it is unloaded.

Parameters

uMsg
SPM_UNLOAD_DLL message.
spParam
Not Used.

Return Values

Return SPR_HANDLED or SPR_NOT_HANDLED to continue.
