Running the Test

Before running the test, insert the smart card reader into the PCMCIA slot. The following command line shows the syntax for running the test.

ifdtest [parameters]

If you do not input any reader device names, the test program scans the system to find all available smart card reader devices and then performs the test on the devices found.

The following table shows the general test case parameters.

Parameter Description
-d Dumps all of the I/O.
-m Manual test.
-r device_name Opens the reader using device_name.
-sa Skips card monitor test.
-sb Skips general reader test.
-sc Skips resource manager simulation.
-sd Skips card tests.
-v vendor_name Opens reader using vendor_name.
-t test Runs only a specific card test.
