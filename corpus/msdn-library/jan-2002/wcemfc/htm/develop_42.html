Automation Support for Date and Time

The COleDateTime class provides a more precise way to represent date and time information than CTime. COleDateTime provides finer granularity and a greater range.

The COleDateTimeSpan class represents elapsed time, such as the difference between two COleDateTime objects. The COleDateTime and COleDateTimeSpan classes are designed to be used with the COleVariant class used in Automation.

Although the COleDateTime class has a greater range of values and finer granularity than the CTime class, it requires more storage per object than CTime. There are also some special considerations when working with the underlying DATE type.

COleDateTime objects can be used to represent dates between January 1, 100, and December 31, 9999. COleDateTime objects are floating point values, with an approximate resolution of 1 millisecond. COleDateTime is based on the DATE data type (see COleDateTime::operator DATE).
