CRecentFileList::UpdateMenu

This method updates the menu display of the most recently used (MRU) file list.

virtual void UpdateMenu(
CCmdUI* pCmdUI );

Parameters

pCmdUI
Specifies a pointer to the CCmdUI object for the MRU file list menu.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxadv.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
