CCeDBProp::SetShort

This method sets the value of a short integer property.

void SetShort(
short iVal );

Parameters

iVal
Specifies the value of the property.

Remarks

You can only call SetShort on a property of the type CCeDBProp::Type_Short.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
