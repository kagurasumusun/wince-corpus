CList::GetAt

This method retrieves the element or a reference of, that is associated with a specified position. The position parameter is a key for the list. It is not the same as an index, and you cannot operate on the position value yourself.

TYPE& GetAt(
POSITION position ); 

TYPE GetAt(
POSITION position )
const;

Parameters

TYPE
Specifies the template parameter specifying the type of object in the list.
position
Specifies a POSITION value returned by a previous GetHeadPosition or Find method call.

Return Value

If the list is const, GetAt returns a copy of the element at the head of the list. This allows the function to be used only on the right side of an assignment statement and protects the list from modification.

If the list is not const, GetAt returns a reference to the element at the head of the list. This allows the function to be used on either side of an assignment statement and thus allows the list entries to be modified.
