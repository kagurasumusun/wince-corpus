CStatusBarCtrl

This class provides the functionality of the Windows CE common status bar control. A status bar control is a horizontal window, usually displayed at the bottom of a parent window, in which an application can display various kinds of status information.

The CStatusBarCtrl class provides the functionality of the Windows common status bar control. This control, and therefore the CStatusBarCtrl class, is available only to programs running under Windows CE, Windows 98 and Windows NT version 3.51 and later.

Remarks

MFC for Windows CE does not support the following methods of the standard MFC CStatusBarCtrl class:

  • CStatusBarCtrl::GetTipText
  • CStatusBarCtrl::SetTipText
  • CStatusBarCtrl::SetBkColor
  • CStatusBarCtrl::SetIcon

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
