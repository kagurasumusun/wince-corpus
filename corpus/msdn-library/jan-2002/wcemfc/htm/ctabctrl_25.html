CTabCtrl::SetItem

This method sets some or all of the attributes of a tab.

BOOL SetItem(
int nItem,
TCITEM* pTabCtrlItem );

Parameters

nItem
Specifies the zero-based index of the item.
pTabCtrlItem
Specifies the pointer to a TCITEM structure that contains the new item attributes. The mask member specifies which attributes to set. If the mask member specifies the TCIF_TEXT value, the pszText member is the address of a null-terminated string and the cchTextMax member is ignored.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

See the example for GetItem.

Requirements
