CList::InsertBefore

This method adds an element to this list before the element at the specified position.

POSITION InsertBefore(
POSITION position,
ARG_TYPE newElement );

Parameters

position
Specifies a POSITION value returned by a previous GetNext, GetPrev, or Find method call.
ARG_TYPE
Specifies the template parameter specifying the type of the list element. This list element can be a reference.
newElement
Specifies the element to be added to this list.

Return Value

A POSITION value that can be used for iteration or list element retrieval; it is NULL if the list is empty.

Example

// Define myList.
CList<CString,CString&> myList;

// Add three elements to the list.
POSITION pos = myList.AddHead(CString("XYZ"));
pos = myList.InsertBefore(pos, CString("ABC"));
pos = myList.InsertBefore(pos, CString("123"));

// Verify the head element is the one expected.
ASSERT(CString("123") == myList.GetHead());

Requirements
