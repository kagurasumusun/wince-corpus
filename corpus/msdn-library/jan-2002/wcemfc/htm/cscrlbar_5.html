CScrollBar::GetScrollLimit

This method retrieves the maximum scrolling position of the scroll bar. 

int GetScrollLimit( );

Return Value

Specifies the maximum position of a scroll bar if successful; otherwise, it is zero.

Example

See the example for CWnd::OnHScroll shown in the CScrollBar::GetScrollInfo method.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
