CSliderCtrl::Create

This method creates a slider control and attaches it to the CSliderCtrl object.

To construct a CSliderCtrl, call the constructor, then call Create.

Depending on the values set for dwStyle, the slider control can have either a vertical or horizontal orientation. It can have tick marks on either side, both sides, or neither. It can also be used to specify a range of consecutive values.

To apply extended window styles to the slider control, call CreateEx instead of Create.

BOOL Create(
DWORD dwStyle,
const RECT& rect,
CWnd* pParentWnd,
UINT nID );

Parameters

dwStyle
Specifies the slider control style. Apply any combination of slider control styles, to the control.
rect
Specifies the slider control size and position. It can be either a CRect object or a RECT structure.
pParentWnd
Specifies the slider control parent window, usually a CDialog. It must not be NULL.
nID
Specifies the slider control ID.

Return Value

Nonzero if initialization was successful; otherwise, it is zero.

Requirements
