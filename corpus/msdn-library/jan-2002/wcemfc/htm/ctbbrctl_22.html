CToolBarCtrl::GetItemRect

This method retrieves the bounding rectangle of a button in a toolbar control. This method does not retrieve the bounding rectangle for buttons whose state is set to TBSTATE_HIDDEN.

BOOL GetItemRect(
int nIndex,
LPRECT lpRect )
const;

Parameters

nIndex
Specifies the zero-based index of the button for which to retrieve information.
lpRect
Specifies the address of a RECT structure or a CRect object that receives the coordinates of the bounding rectangle.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
