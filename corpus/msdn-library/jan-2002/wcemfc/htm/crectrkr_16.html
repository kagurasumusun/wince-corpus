CRectTracker::m_sizeMin

This data member contains a CSize object that represents the minimum size of the rectangle. This data member is used only by the AdjustRect method. Both default values, cx and cy, are calculated from the default system value for the border width. 

CSize m_sizeMin;

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
