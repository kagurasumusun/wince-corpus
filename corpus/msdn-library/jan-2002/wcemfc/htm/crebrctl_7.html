CReBarCtrl::EndDrag

This method terminates the drag-and-drop operation in the rebar control.

This method implements the behavior of the Windows CE message RB_ENDDRAG. 

void EndDrag( );

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
