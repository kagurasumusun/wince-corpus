CGdiObject::DeleteObject

This method deletes the GDI object by freeing all system storage associated with it. The storage associated with the CGdiObject object is not affected by this call. An application should not call DeleteObject on a CGdiObject object that is currently selected into a device context.

When a pattern brush is deleted, the bitmap associated with the brush is not deleted. The bitmap must be deleted independently.

BOOL DeleteObject ( );

Return Value

Nonzero if the GDI object was successfully deleted; otherwise, it is zero.

Remarks

In Windows CE, if the GDI object is currently selected into a device context, this method returns FALSE.
