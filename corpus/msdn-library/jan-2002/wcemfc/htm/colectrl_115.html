COleControl::OnSetClientSite

This method is called by the framework when the container has called the control IOleControl::SetClientSite method.

Override this function to do any special processing of this notification. In particular, overrides of this function should call the base class.

virtual void OnSetClientSite( );

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
