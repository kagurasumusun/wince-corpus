COleObjectFactory::VerifyUserLicense

This method verifies the design-time license for the control.

virtual BOOL VerifyUserLicense( );

Return Value

Nonzero if the design-time license is valid; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
