CDateTimeCtrl::GetMonthCalFont

This method gets the font used by the month calendar control of the date and time picker control. The CFont object pointed to by the return value is a temporary object and is destroyed during the next idle processing time.

CFont* GetMonthCalFont( )
const;

Return Value

A pointer to a CFont object, or NULL if it is unsuccessful.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxdtctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
