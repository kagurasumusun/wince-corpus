CTimeSpan::GetMinutes

This method retrieves the number of minutes in the current hour represented by this CTimeSpan object. The range is –59 through 59.

GetMinutes will return a valid value if the object on which it operates was initialized with an amount of seconds that can be held in four bytes (+/-2,147,483,647). If your CTimeSpan object holds an eight-byte value, you should use GetMinutes64 to return the number of minutes.

int GetMinutes( )
const;

Example

// example for CTimeSpan::GetHours, CTimeSpan::GetMinutes,
// CTimeSpan::GetSeconds
CTimeSpan ts( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ASSERT( ts.GetHours() == 1 );
ASSERT( ts.GetMinutes() == 5 );
ASSERT( ts.GetSeconds() == 12 );
