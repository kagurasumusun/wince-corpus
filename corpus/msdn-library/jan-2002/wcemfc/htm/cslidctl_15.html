CSliderCtrl::GetSelection

This method retrieves the starting and ending positions of the current selection in a slider control.

void GetSelection(
int& nMin,
int& nMax )
const;

Parameters

nMin
Specifies the reference to an integer that receives the starting position of the current selection.
nMax
Specifies the reference to an integer that receives the ending position of the current selection.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also

CSliderCtrl::SetSelection, CSliderCtrl::ClearSel
