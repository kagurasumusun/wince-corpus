COlePropertyPage::GetObjectArray

This method retrieves a pointer to the array of IDispatch interface pointers of the objects being edited by the page. It sets the pnObjects parameter to the number of elements in the returned array.

LPDISPATCH* GetObjectArray(
ULONG* pnObjects );

Parameters

pnObjects
Specifies a pointer to an unsigned long integer that receives the number of objects being edited by the page.

Return Value

Pointer to an array of IDispatch pointers, which are used to access the properties of each control on the property page. The caller must not release these interface pointers.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
