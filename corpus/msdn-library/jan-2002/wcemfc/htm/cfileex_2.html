CFileException::CFileException

This constructor creates an instance of a CFileException object that stores the cause code and the operating-system code in the object.

Do not use this constructor directly, but rather call the global function AfxThrowFileException.

The variable lOsError applies only to CFile and CStdioFile objects. The CMemFile class does not handle this error code.

CFileException(
int cause = CFileException::none,
LONG lOsError = –1,
LPCTSTR lpszArchiveName = NULL);

Parameters

cause
Specifies an enumerated type variable that indicates the reason for the exception. See CFileException::m_cause for a list of the possible values.
lOsError
Specifies an operating-system-specific reason for the exception, if available. The lOsError parameter provides more information than cause does.
lpszArchiveName
Points to a string containing the name of the CArchive object that caused the exception, if available.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
