CMap::CMap

This constructor creates an instance of an empty map. As the map grows, memory is allocated in units of nBlockSize entries.

CMap(
int nBlockSize = 10 );

Parameters

nBlockSize
Specifies the memory-allocation granularity for extending the map.

Example

// Declares a map of ints to points.
CMap<int,int,CPoint,CPoint> myMap(16);

Requirements

  Windows CE versions: 1.0 and later
