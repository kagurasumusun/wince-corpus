COleControl::DrawContent

This method is called by the framework when the appearance of the control needs to be updated. This method directly calls the overridable OnDraw method.

void DrawContent(
CDC* pDC,
CRect& rc );

Parameters

pDC
Specifies a pointer to the device context.
rc
Specifies the rectangular area to be drawn in.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
