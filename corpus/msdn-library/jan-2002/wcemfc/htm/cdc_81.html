CDC::SetAttribDC

This method sets the attribute device context, m_hAttribDC. This method does not attach the device context to the CDC object. Only the output device context is attached to a CDC object.

virtual void SetAttribDC(
HDC hDC );

Parameters

hDC
A Windows device context.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
