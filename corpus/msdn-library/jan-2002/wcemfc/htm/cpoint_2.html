CPoint::CPoint

This constructor creates an instance of a CPoint object. If no parameters are given, x and y members are not initialized.

CPoint( ); 

CPoint(
int initX,
int initY ); 

CPoint(
POINT initPt ); 

CPoint(
SIZE initSize ); 

CPoint(
DWORD dwPoint );

Parameters

initX
Specifies the value of the x member of CPoint.
initY
Specifies the value of the y member of CPoint.
initPt
Specifies the POINT structure or CPoint that specifies the values used to initialize CPoint.
initSize
Specifies the SIZE structure or CSize that specifies the values used to initialize CPoint.
dwPoint
Sets the x member to the low-order word of dwPoint and the y member to the high-order word of dwPoint.

Example

CPoint  ptUndefined;
CPoint  ptTopLeft(0,0);

// This works from a POINT, too.

POINT  ptHere;
ptHere.x = 35;
ptHere.y = 95;

CPoint  ptMFCHere(ptHere);

// This works from a SIZE as well.

SIZE  sHowBig;
sHowBig.cx = 300;
sHowBig.cy = 10;

CPoint ptMFCBig(sHowBig);

// This also works from a DWORD.

DWORD  dwSize;
dwSize = MAKELONG(35, 95);

CPoint ptFromDouble(dwSize);
ASSERT(ptFromDouble == ptMFCHere);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
