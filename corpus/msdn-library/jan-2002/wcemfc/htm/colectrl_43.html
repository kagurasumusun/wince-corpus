COleControl::GetBorderStyle

This method retrieves the value of the stock BorderStyle property.

short GetBorderStyle( );

Return Value

Returns one if the control has a normal border; returns zero if the control has no border.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also

COleControl::SetBorderStyle, COleControl::OnBorderStyleChanged
