CWnd::SetForegroundWindow

This method puts the thread that created the window into the foreground and activate the window.

BOOL SetForegroundWindow ( );

Remarks

This method activates the specified window and brings the thread that created it to the foreground, but the system does not automatically assign a higher priority to the foreground thread, as it does in Windows 98 and Windows NT.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
