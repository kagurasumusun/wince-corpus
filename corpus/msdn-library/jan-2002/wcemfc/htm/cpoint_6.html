CPoint::operator !=

This operator checks for inequality between two points.

BOOL operator !=(
POINT point )
const;

Parameters

point
Contains a POINT structure or CPoint object.

Return Value

Nonzero if the points are not equal; otherwise, it is zero.

Example

CPoint ptFirst(256, 128);
CPoint ptTest(111, 333);

ASSERT(ptFirst != ptTest);

// This works with POINTs, too.

POINT pt;
pt.x = 333;
pt.y = 111;

ASSERT(ptTest != pt);

// Note that pt != ptTest isn't correct!

Requirements
