CWinApp::ExitInstance

This method is called by the framework from within the Run method to exit this instance of the application.

Do not call this method from anywhere but within the Run method.

The default implementation of this function writes framework options to the .ini file of the application. Override this function to clean up when your application terminates.

virtual int ExitInstance( );

Return Value

The exit code of the application; 0 indicates no errors, and values greater than 0 indicate an error. This value is used as the return value from WinMain.

Example

// MySampleApp.cpp.

int CMySampleApp::ExitInstance()
{
  // TODO: Add your specialized code here and/or
  // call the base class.

  if ( m_pMySampleMem )
    delete m_pMySampleMem;
  
  DoCleanup();

  return CWinApp::ExitInstance();
}

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
