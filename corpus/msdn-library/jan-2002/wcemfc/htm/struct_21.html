PAINTSTRUCT

This structure contains information that can be used to paint the client area of a window.

typedef struct _PAINTSTRUCT {
   HDC  hdc;
   BOOL fErase;
   RECT rcPaint;
   BOOL fRestore;
   BOOL fIncUpdate;
   BYTE rgbReserved[32];
} PAINTSTRUCT;

Members

hdc
Identifies the display context to be used for painting.
fErase
Specifies whether the background needs to be redrawn. It is not 0 if the application should redraw the background. The application is responsible for drawing the background if a Windows window-class is created without a background brush.
rcPaint
Specifies the upper-left and lower-right corners of the rectangle in which the painting is requested.
fRestore
Reserved member. It is used internally by Windows.
fIncUpdate
Reserved member. It is used internally by Windows.
rgbReserved[32]
Reserved member. A reserved block of memory used internally by Windows.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Winuser.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
