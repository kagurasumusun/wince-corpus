CToolBarCtrl::GetStyle

This method gets the styles currently applied to a toolbar control.

DWORD GetStyle( )
const;

Return Value

A DWORD containing a combination of toolbar control styles.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
