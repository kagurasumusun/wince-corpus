Structures

MFC for Windows CE supports all the standard MFC structures the same way as standard MFC does except that it does not support all of the data members in the CPrintInfo class.

For information about the MFC for Windows CE structures, see the following topics:

  • CCreateContext
  • CPrintInfo
  • CRunTimeClass

For information about other structures used in MFC, see Structures Used in MFC.

For information about where these structures fit into the Windows CE class hierarchy, see Classes Not Derived from CObject.
