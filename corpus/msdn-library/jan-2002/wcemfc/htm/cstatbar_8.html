CStatusBar::GetItemRect

This method copies the coordinates of the indicator specified by nIndex into the structure pointed to by lpRect. Coordinates are in pixels relative to the upper-left corner of the status bar.

void GetItemRect(
int nIndex,
LPRECT lpRect )
const;

Parameters

nIndex
Specifies the index of the indicator whose rectangle coordinates are to be retrieved.
lpRect
Points to a RECT structure or a CRect object that will receive the coordinates of the indicator specified by nIndex.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
