CImageList::ExtractIcon

This method creates an icon based on an image and its related mask in an image list.

HICON ExtractIcon(
int nImage );

Parameters

nImage
Specifies the zero-based index of the image.

Return Value

Handle of the icon if successful; otherwise, it is NULL.

Example

// Pointer to the myImageList.
extern CImageList* pmyImageList;
extern CDC* pmyDC;

int   i, dx, cx, cy, nCount = pmyImageList->GetImageCount();
HICON hIcon;

::ImageList_GetIconSize(*pmyImageList, &cx, &cy);

// Draw the images of the image list on the DC.
for (dx=0,i=0;i < nCount;i++)
{
  hIcon = pmyImageList->ExtractIcon(i);

  pmyDC->DrawIcon(dx, 0, hIcon);
  dx += cx;
}

Requirements
