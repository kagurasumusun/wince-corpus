CCmdUI::SetCheck

This method sets the user-interface item for this command to the appropriate check state.

virtual void SetCheck(
int nCheck = 1 );

Parameters

nCheck
Specifies the check state to set. If 0, clears; if 1, checks; and if 2, sets indeterminate.

Remarks

The CCmdUI::SetCheck method works for menu items and toolbar buttons. The indeterminate state applies only to toolbar buttons.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
