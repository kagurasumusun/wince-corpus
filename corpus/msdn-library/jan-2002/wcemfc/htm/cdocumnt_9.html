CDocument::GetNextView

This method iterates through all views of the document. The method returns the view identified by rPosition and then sets rPosition to the POSITION value of the next view in the list. If the retrieved view is the last in the list, then rPosition is set to NULL.

virtual CView* GetNextView(
POSITION& rPosition )
const;

Parameters

rPosition
Specifies a reference to a POSITION value returned by a previous call to the GetNextView or GetFirstViewPosition methods. This value must not be NULL.

Return Value

A pointer to the view identified by rPosition.

Example

// This example uses CDocument::GetFirstViewPosition
// and GetNextView to repaint each view.
void CMyDoc::OnRepaintAllViews()
{
   POSITION pos = GetFirstViewPosition();
   while (pos != NULL)
   {
      CView* pView = GetNextView(pos);
      pView->UpdateWindow();
   }
}
