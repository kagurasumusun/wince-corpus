CColorDialog::OnColorOK

This method allows you to reject a color that a user enters in a common color dialog box for any application-specific reason. Override this method to provide custom validation of the color entered in the dialog box. 

virtual BOOL OnColorOK( );

Return Value

Nonzero if the dialog box should not be dismissed; otherwise zero to accept the color that is entered.

Remarks

The user can select a color by one of the following two methods:

  • Clicking a color on the color palette. The RGB values of the selected colors are reflected in the appropriate RGB edit boxes.
  • Entering values in the RGB edit boxes.

Overriding OnColorOK allows you to reject a color that the user enters in a common color dialog box for any application-specific reason.

Normally, you do not need to use this function because the framework provides default validation of colors and displays a message box if an invalid color is entered.
