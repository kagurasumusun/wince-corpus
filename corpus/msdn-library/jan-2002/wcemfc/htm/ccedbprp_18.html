CCeDBProp::SetFiletime

This method sets the value of a FILETIME property.

void SetFiletime(
FILETIME filetime );

Parameters

filetime
Specifies the value of the FILETIME property.

Remarks

You can only call SetFiletime on a property of the type CCeDBProp::Type_Filetime.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
