CCeDBDatabase::m_bEOF

This data member contains the end of file flag.

BOOL m_bEOF;

Remarks

This flag is only set to TRUE by the SeekNext method, when it reaches the end of the database. To use m_bEOF when reading records sequentially, set the m_bAutoSeekNext flag to TRUE.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also

CCeDBDatabase::m_bAutoSeekNext, CCeDBDatabase::SeekNext
