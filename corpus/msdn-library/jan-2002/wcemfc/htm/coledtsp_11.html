COleDateTimeSpan::GetTotalSeconds

This method retrieves the number of seconds this COleDateTimeSpan object represents.

The return values from this function range between approximately –3.16e11 to 3.16e11.

double GetTotalSeconds( )
const;

Return Value

This date/time-span value expressed in seconds. Although this function is prototyped to return a double, it always returns an integer value.

Remarks

For other functions that query the value of a COleDateTimeSpan object, see the following methods:

  • GetDays
  • GetHours
  • GetMinutes
  • GetSeconds
  • GetTotalDays
  • GetTotalHours
  • GetTotalMinutes

Example

// Example for COleDateTimeSpan::GetTotalXxx functions.
COleDateTimeSpan ts( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ASSERT( ts.GetTotalDays() == 3 );
ASSERT( ts.GetTotalHours() == 73 );
ASSERT( ts.GetTotalMinutes() == 4385 );
ASSERT( ts.GetTotalSeconds() == 263112 );
