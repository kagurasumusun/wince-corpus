CFrameWnd::GetHeight

This method retrieves the height of a command bar.

int GetHeight( );

Remarks

The CFrameWnd::GetHeight method is not included in the rectangle of the client area.

This method of the CFrameWnd class is unique to Windows CE.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
