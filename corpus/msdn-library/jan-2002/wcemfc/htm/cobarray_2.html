CObArray::CObArray

This constructor creates and instance of an empty CObject pointer array. The array grows one element at a time.

CObArray( );

Remarks

The following table shows other constructors that are similar to CObArray::CObArray.

Class Constructor
CByteArray CByteArray( );
CDWordArray CDWordArray( );
CPtrArray CPtrArray( );
CStringArray CStringArray( );
CUIntArray CUIntArray( );
CWordArray CWordArray( );

Example

CObArray array; //Array with default blocksize.
CObArray* pArray = new CObArray; //Array on the heap with default
// blocksize

Requirements
