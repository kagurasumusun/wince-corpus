CEdit::SetMargins

This method sets the left and right margins of this edit control.

void SetMargins(
UINT nLeft,
UINT nRight );

Parameters

nLeft
Specifies the width of the new left margin, in pixels.
nRight
Specifies the width of the new right margin, in pixels.

Remarks

For more information, see the Windows CE message EM_SETMARGINS.

Example

See the example for CEditView::GetEditCtrl.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also

CEdit::GetMargins, EM_SETMARGINS
