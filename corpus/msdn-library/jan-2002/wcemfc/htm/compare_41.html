Automation Types

MFC for Windows CE supports the Automation type classes the same way the standard MFC library supports them, with the exception that it does not support the Format method of the COleDateTime and COleDateTimeSpan classes.

For information about the MFC for Windows CE Automation type classes, see the following topics:

  • COleCurrency
  • COleDateTime
  • COleDateTimeSpan
  • COleVariant

For information about where the automation type classes fit into the Windows CE class hierarchy, see Classes Not Derived from CObject.
