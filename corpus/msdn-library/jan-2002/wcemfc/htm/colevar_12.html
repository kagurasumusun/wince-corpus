COleVariant::operator LPVARIANT

This casting operator accesses the underlying VARIANT structure for this COleVariant object.

Caution   Changing the value in the VARIANT structure accessed by the pointer returned by this function changes the value of this COleVariant object.

operator LPVARIANT( );

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
