CTreeCtrl::GetItemText

This method retrieves the text of the item specified by hItem.

CString GetItemText(
HTREEITEM hItem )
const;

Parameters

hItem
Specifies the handle of the item whose text is to be retrieved.

Return Value

A CString object containing the text of the item.

Example

See the example for CTreeCtrl::GetNextItem.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
