CToolBarCtrl::AddStrings

This method adds a new string or strings to the list of strings available for a toolbar control. Strings in the buffer must be separated by a null character.

int AddStrings(
LPCTSTR lpszStrings );

Parameters

lpszStrings
Specifies the address of a buffer that contains one or more null-terminated strings to add to the string list of the toolbar. The last string must be terminated with two null characters.

Return Value

The zero-based index of the first new string added if it is successful; otherwise, it is –1.

Remarks

You must ensure that the last string has two null terminators. To properly format a constant string, you might write it as:

// one null added automatically
lpszStrings = "Only one string to add\0";

or:

// adds three strings with one call
lpszStrings = "String 1\0String 2\0String 3\0";

You should not pass a CString object to this function since it is not possible to have more than one null character in a CString.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
