CTreeCtrl::GetNextVisibleItem

This method retrieves the next visible item of hItem.

HTREEITEM GetNextVisibleItem(
HTREEITEM hItem )
const;

Parameters

hItem
Handle of a tree item.

Return Value

The handle of the next visible item; otherwise, it is NULL.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
