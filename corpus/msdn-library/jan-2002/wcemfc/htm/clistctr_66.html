CListCtrl::SetTextBkColor

This method sets the background color of text in a list view control.

BOOL SetTextBkColor(
COLORREF cr );

Parameters

cr
A COLORREF specifying the new text background color. For more information, see the Windows CE structure COLORREF.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

// Use the 3D button face color for the text background.
COLORREF crBkColor = ::GetSysColor(COLOR_3DFACE);
pmyListCtrl->SetTextBkColor(crBkColor);
ASSERT(pmyListCtrl->GetTextBkColor() == crBkColor);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
