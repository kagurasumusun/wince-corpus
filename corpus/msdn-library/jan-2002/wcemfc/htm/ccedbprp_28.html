CCeDBProp::operator =

The assignment operator copies the m_CePropVal data member of the CCeDBProp object. If the property being copied is a string or a BLOB, the CCeDBProp object to which its value is being assigned makes a copy of the pointer to the string or data buffer belonging to the other property, but does not own it. The memory is not released when the CCeDBProp object to which it is assigned is destroyed.

CCeDBProp& operator=(
const CCeDBProp& prop );

Parameters

prop
Specifies the CCeDBProp object being copied.

Requirements

  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
