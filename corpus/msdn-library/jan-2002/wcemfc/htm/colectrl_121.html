COleControl::ParentToClient

This method translates a point relative to the origin of the container to a point relative to the control origin. On input pPoint is relative to the origin of the parent, upper-left corner of the container. On output pPoint is relative to the origin of the client are of the ActiveX control, upper-left corner of the client area of the control.

virtual UINT ParentToClient(
LPCRECT lprcBounds,
LPPOINT pPoint,
BOOL bHitTest = FALSE )
const;

Parameters

lprcBounds
Specifies a pointer to the bounds of the OLE control within the container. Not the client area but the area of the entire control including borders and scroll bars.
pPoint
Specifies a pointer to the parent, container, point to be translated into the coordinates of the client area of the control.
bHitTest
Specifies whether or not hit testing is to be done on the point.

Return Value

If bHitTest is FALSE, returns HTNOWHERE. If bHitTest is TRUE, returns the location in which the parent, container, point landed in the client area of the ActiveX control and is one of the following mouse hit-test values:

  • HTBORDER   In the border of a window that does not have a sizing border.
  • HTBOTTOM   In the lower horizontal border of the window.
  • HTBOTTOMLEFT   In the lower-left corner of the window border.
  • HTBOTTOMRIGHT   In the lower-right corner of the window border.
  • HTCAPTION   In a title-bar area.
  • HTCLIENT   In a client area.
  • HTERROR   On the screen background or on a dividing line between windows. This is the same as HTNOWHERE except that the DefWndProc Windows function produces a system beep to indicate an error.
  • HTGROWBOX   In a size box.
  • HTHSCROLL   In the horizontal scroll bar.
  • HTLEFT   In the left border of the window.
  • HTMAXBUTTON   In a Maximize button.
  • HTMENU   In a menu area.
  • HTMINBUTTON   In a Minimize button.
  • HTNOWHERE   On the screen background or on a dividing line between windows.
  • HTREDUCE   In a Minimize button.
  • HTRIGHT   In the right border of the window.
  • HTSIZE   In a size box, the same as HTGROWBOX.
  • HTSYSMENU   In a Control menu or in a Close button in a child window.
  • HTTOP   In the upper horizontal border of the window.
  • HTTOPLEFT   In the upper-left corner of the window border.
  • HTTOPRIGHT   In the upper-right corner of the window border.
  • HTTRANSPARENT   In a window currently covered by another window.
  • HTVSCROLL   In the vertical scroll bar.
  • HTZOOM   In a Maximize button.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
