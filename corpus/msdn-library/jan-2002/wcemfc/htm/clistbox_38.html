CListBox::SetCurSel

This method selects a string and scrolls it into view, if necessary. When the new string is selected, the list box removes the highlight from the previously selected string.

Use this method only with single-selection list boxes. It cannot be used to set or remove a selection in a multiple-selection list box.

int SetCurSel(
int nSelect );

Parameters

nSelect
Specifies the zero-based index of the string to be selected. If nSelect is –1, the list box is set to have no selection.

Return Value

LB_ERR if an error occurs.

Example

// Pointer to the myListBox.
extern CListBox* pmyListBox;

// Select the last item in the list box.
int nCount = pmyListBox->GetCount();
if (nCount > 0)
  pmyListBox->SetCurSel(nCount–1);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
