CDC::IntersectClipRect

This method creates a new clipping region by forming the intersection of the current region and the rectangle specified by x1, y1, x2, and y2. The GDI clips all subsequent output to fit within the new boundary. 

int IntersectClipRect(
int x1,
int y1,
int x2,
int y2 );

int IntersectClipRect(
LPCRECT lpRect );

Parameters

x1
The logical x-coordinate of the upper-left corner of the rectangle.
y1
The logical y-coordinate of the upper-left corner of the rectangle.
x2
The logical x-coordinate of the lower-right corner of the rectangle.
y2
The logical y-coordinate of the lower-right corner of the rectangle.
lpRect
The rectangle. You can pass a CRect object or a pointer to a RECT structure for this parameter.

Return Value

The type of the new clipping region. It can be any of the following values:

COMPLEXREGION
New clipping region has overlapping borders.
ERROR
Device context is not valid.
NULLREGION
New clipping region is empty.
SIMPLEREGION
New clipping region has no overlapping borders.

Remarks

The width and height must not exceed 32,767.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
