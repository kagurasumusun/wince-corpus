CStatusBarCtrl::GetBorders

This method retrieves the current widths of the horizontal and vertical borders and of the space between rectangles of the status bar control. These borders determine the spacing between the outside edge of the control and the rectangles within the control that contain text.

BOOL GetBorders(
int* pBorders )
const; 

BOOL GetBorders(
int& nHorz,
int& nVert,
int& nSpacing )
const;

Parameters

pBorders
Specifies the address of an integer array having three elements. The first element receives the width of the horizontal border, the second receives the width of the vertical border, and the third receives the width of the border between rectangles.
nHorz
Specifies the reference to an integer that receives the width of the horizontal border.
nVert
Specifies the reference to an integer that receives the width of the vertical border.
nSpacing
Specifies the reference to an integer that receives the width of the border between rectangles.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

VERIFY( GetRect(1, &rectPane1) );

int borderArray[3];

VERIFY( GetBorders(borderArray) );

int nHorz, nVert, nSpacing;

VERIFY( GetBorders(nHorz, nVert, nSpacing) );

Requirements
