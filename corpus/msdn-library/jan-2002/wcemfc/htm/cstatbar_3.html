CStatusBar::CommandToIndex

This method gets the indicator index for a specified identifier. The index of the first indicator is zero.

int CommandToIndex(
UINT nIDFind )
const;

Parameters

nIDFind
Specifies the string ID of the indicator whose index is to be retrieved.

Return Value

The index of the indicator if it is successful; –1 if it is not successful.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
