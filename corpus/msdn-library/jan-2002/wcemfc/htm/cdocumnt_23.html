CDocument::SetModifiedFlag

This method is called after any modifications are made to the document. By calling this method consistently, you ensure that the framework prompts the user to save changes before closing a document. Typically you should use the default value of TRUE for the bModified parameter. To mark a document as clean, or unmodified, call this function with a value of FALSE.

virtual void SetModifiedFlag(
BOOL bModified = TRUE );

Parameters

bModified
Specifies the flag indicating whether the document has been modified.

Requirements

  Header file: Declared in Afxwin.h
