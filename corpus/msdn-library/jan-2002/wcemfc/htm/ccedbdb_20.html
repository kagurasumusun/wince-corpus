CCeDBDatabase::SeekFirst

This method positions the read/write pointer to the first record in the database.

CEOID SeekFirst( );

Return Values

The object identifier of the first record, or zero if the seek operation fails. To get extended error information, call GetLastError.

Remarks

If the database was opened using a key sort property, the corresponding sort order is used to determine the first record.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
