CFile::Remove

This method deletes the file specified by the path. It does not remove a directory.

The Remove member function throws an exception if the connected file is open or if the file cannot be removed. This is equivalent to the DEL command.

static void PASCAL Remove( 
LPCTSTR lpszFileName );

Parameters

lpszFileName
Specifies a string that is the path to the desired file. The path can be relative or absolute but cannot contain a network name.

Example

// Example for the CFile::Remove method.
TCHAR* pFileName = _T("test.dat");
Try
{
    CFile::Remove(pFileName);
}
CATCH (CFileException, pEx)
{
#ifdef _DEBUG
    afxDump << "File " << pFileName << " cannot be removed\n";
#endif
}
END_CATCH
