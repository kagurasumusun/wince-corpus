CFile::Flush

This method forces any data remaining in the file buffer to be written to the file. 

virtual void Flush( );

Remarks

Using Flush does not guarantee that CArchive will flush the buffers. If you use an archive, call CArchive::Flush first.

Example

See the example for CFile::SetFilePath.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
