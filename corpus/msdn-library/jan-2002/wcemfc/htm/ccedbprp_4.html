CCeDBProp::GetBool

This method retrieves the value of a property, when the property's data type is a Boolean.

bool GetBool( )
const;

Return Values

The value of the property.

Remarks

You can call GetBool only on a property of the type CCeDBProp::Type_Bool.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: Pocket PC
