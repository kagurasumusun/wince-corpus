CCmdUI::m_pSubMenu

This data member contains a pointer to the contained submenu, a CMenu object represented by the CCmdUI object.

CMenu* m_pSubMenu;

Remarks

The value of this data member is NULL if the item is not a menu. If the submenu is a pop-up, m_nID contains the identifier of the first item in the pop-up menu.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
