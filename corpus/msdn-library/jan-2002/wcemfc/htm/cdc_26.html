CDC::FrameRect

This method draws a border around the rectangle specified by lpRect.

void FrameRect(
LPCRECT lpRect,
CBrush* pBrush );

Parameters

lpRect
Pointer to a RECT structure or CRect object that contains the logical coordinates of the upper-left and lower-right corners of the rectangle. You can also pass a CRect object for this parameter.
pBrush
Identifies the brush to use for framing the rectangle.

Remarks

The method uses the given brush to draw the border. The width and height of the border is always 1 logical unit.

If the bottom coordinate of the rectangle is less than or equal to top, or if right is less than or equal to left, the rectangle is not drawn.

The border drawn by FrameRect is in the same position as a border drawn by the Rectangle method using the same coordinates, if Rectangle uses a pen that is 1 logical unit wide. The interior of the rectangle is not filled by FrameRect.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
