CSliderCtrl::GetRange

This method retrieves the maximum and minimum positions for the slider in a slider control. This method copies the values into the integers referenced by nMin and nMax.

void GetRange(
int& nMin,
int& nMax )
const;

Parameters

nMin
Specifies the reference to an integer that receives the minimum position.
nMax
Specifies the reference to an integer that receives the maximum position.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
