CSplitterWnd::OnInvertTracker

This method is called by the framework during resizing of splitters.

Override OnInvertTracker for advanced customization of the imagery of the splitter window. The default imagery is similar to the splitter in Microsoft Works for Windows or Microsoft Windows 98, in that the intersections of the splitter bars are blended together.

virtual void OnInvertTracker(
const CRect& rect );

Parameters

rect
Specifies the reference to a CRect object specifying the tracking rectangle.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
