CWinApp::m_hPrevInstance

This data member corresponds to the hPrevInstance parameter passed by Windows CE to WinMain.

The m_hPrevInstance data member is always set to NULL in a Windows CE application. To find previous instances of an application, use CWnd::FindWindow.

HINSTANCE m_hPrevInstance;

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
