CRgn::operator HRGN

This operator gets the attached Windows CE GDI handle to the CRgn object. This operator is a casting operator, which supports direct use of an HRGN object.

operator HRGN( )
const;

Return Value

If successful, a handle to the Windows GDI object is represented by the CRgn object; otherwise, it is NULL.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
