AfxOleUnregisterClass

This function removes the control or property page class entry from the Windows registration database.

BOOL AFXAPI AfxOleUnregisterClass(
REFCLSID clsID,
LPCSTR pszProgID );

Parameters

clsID
Specifies the unique class ID of the control or property page.
pszProgID
Specifies the unique program ID of the control or property page.

Return Value

Nonzero if the control or property page class was successfully unregistered; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palms-size PC, Pocket PC
