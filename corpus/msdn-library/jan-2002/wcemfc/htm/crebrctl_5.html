CReBarCtrl::DeleteBand

This method deletes a band from a rebar control.

This method implements the behavior of the Windows CE message RB_DELETEBAND. 

BOOL DeleteBand(
UINT uBand );

Parameters

uBand
Specifies the zero-based index of the band to be deleted.

Return Value

Nonzero if the band deleted successfully; otherwise, it is zero.

Example

  UINT nCount = m_wndReBar.GetReBarCtrl().GetBandCount();

  if (nCount > 0)
    m_wndReBar.GetReBarCtrl().DeleteBand(nCount - 1);

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
