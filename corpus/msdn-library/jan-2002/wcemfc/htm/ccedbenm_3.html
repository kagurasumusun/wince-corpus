CCeDBEnum::Next

This method retrieves the next CCeDBDatabase object in the enumeration. This function returns NULL if no more databases are found.

CEOID Next ( );

Return Values

The object identifier (CEOID) of the next database in the object store.

Remarks

If the CCeDBEnum object is constructed with an application-defined identifier other than zero, Next only enumerates the databases with the specified identifier. Otherwise, it enumerates all the databases in the object store.

Repeated calls to Next return the CEOIDs of the databases being enumerated. Enumeration ends when Next returns NULL or the CCeDBEnum object is destroyed.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
