COleControl::ResetVersion

This method initializes the version number to a specified value.

You can improve the binary initialization performance of a control by using ResetVersion and ResetStockProps to override COleControl::OnResetState. See the example at COleControl::ResetStockProps.

void ResetVersion(
DWORD dwVersionDefault );

Parameters

dwVersionDefault
Specifies the version number to be assigned to the control.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also

COleControl::ResetStockProps, COleControl::SerializeVersion
