CReBarCtrl::GetBarHeight

This method retrieves the height of the rebar bar.

UINT GetBarHeight( )
const;

Return Value

Returns a value that represents the height, in pixels, of the control.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
