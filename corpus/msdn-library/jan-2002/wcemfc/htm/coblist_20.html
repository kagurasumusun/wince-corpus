CObList::RemoveHead

This method removes the element from the head of the list and obtains a pointer to it. 

CObject* RemoveHead( );

Return Value

Returns the CObject pointer previously at the head of the list.

Remarks

You must ensure that the list is not empty before calling RemoveHead. If the list is empty, then the Debug version of MFC for Windows CE asserts. Use IsEmpty to verify that the list contains elements.

Example

See CObList::CObList for a listing of the CAge class.

CObList list;
CAge* pa1;
CAge* pa2;

list.AddHead( pa1 = new CAge( 21 ) );
list.AddHead( pa2 = new CAge( 40 ) ); // List now contains (40, 21).
ASSERT( *(CAge*) list.RemoveHead() == CAge( 40 ) );  // Old head
ASSERT( *(CAge*) list.GetHead() == CAge( 21 ) );  // New head
delete pa1;
delete pa2;

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcoll.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
