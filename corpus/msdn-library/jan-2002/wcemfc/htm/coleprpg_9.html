COlePropertyPage::OnHelp

This method is called by the framework when the user requests online Help. Override this method if your property page must perform any special action when the user accesses Help. The default implementation does nothing and returns FALSE.

virtual BOOL OnHelp(
LPCTSTR lpszHelpDir );

Parameters

lpszHelpDir
Specifies the directory containing the Help file of the property page.

Return Value

The default implementation returns FALSE.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
