CCmdUI::Enable

This method enables or disables the user-interface item for this command.

virtual void Enable(
BOOL bOn = TRUE );

Parameters

bOn
Specifies TRUE to enable the item, FALSE to disable it.

Example

BEGIN_MESSAGE_MAP(CFileDoc, CDocument)
    // Many ON_* macros removed...
    ON_UPDATE_COMMAND_UI(ID_FILE_SAVE, OnUpdateFileSave)
END_MESSAGE_MAP()
.
.
.
void CFileDoc::OnUpdateFileSave(CCmdUI* pCmdUI)
{
    // Enable the menu item if the file has been modified.
    pCmdUI->Enable(m_fModified);
}
