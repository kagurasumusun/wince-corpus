CMonthCalCtrl::SizeMinReq

This method displays the month calendar control to the minimum size that displays one month. 

BOOL SizeMinReq(
BOOL bRepaint = TRUE );

Parameters

bRepaint
Specifies whether the control is to be repainted. By default, TRUE. If FALSE, no repainting occurs.

Return Value

Nonzero if the month calendar control is sized to its minimum; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxdtctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
