CSyncObject

This class is a pure virtual class that provides functionality common to the synchronization objects in Windows CE.

Remarks

MFC for Windows CE 3.0 supports CMutex, as well as CEvent and CCriticalSection.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxmt.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also
