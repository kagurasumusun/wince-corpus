COleStreamFile::COleStreamFile

This constructor creates an instance of a COleStreamFile object. If lpStream is NULL, the object is not associated with a COM stream; otherwise, the object is associated with the supplied COM stream.

COleStreamFile(
LPSTREAM lpStream = NULL );

Parameters

lpStream
Pointer to the Ole stream to be associated with the object.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxole.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
