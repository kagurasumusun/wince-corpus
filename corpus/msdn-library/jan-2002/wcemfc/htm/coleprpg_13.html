COlePropertyPage::SetControlStatus

This method changes the status of a property page control. If the status of a property page control is dirty when the property page is closed or the Apply button is chosen, the control property will be updated with the appropriate value.

BOOL SetControlStatus(
UINT nID,
BOOL bDirty );

Parameters

nID
Contains the ID of a property page control.
bDirty
Specifies if a field of the property page has been modified. Set to TRUE if the field has been modified, FALSE if it has not been modified.

Return Value

TRUE, if the specified control was set; otherwise, it is FALSE.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
