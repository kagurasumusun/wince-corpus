CDialog::GetDefID

This method gets the identifier of the default push button control for a dialog box. This is usually an OK button.

DWORD GetDefID( )
const;

Return Value

A 32-bit value (DWORD). If the default pushbutton has an identifier value, the high-order word contains DC_HASDEFID and the low-order word contains the identifier value. If the default pushbutton does not have an identifier value, the return value is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
