CImageList::GetDragImage

This method retrieves the temporary image list that is used for dragging.

static CImageList* PASCAL GetDragImage(
LPPOINT lpPoint,
LPPOINT lpPointHotSpot );

Parameters

lpPoint
Specifies the address of a POINT structure that receives the current drag position.
lpPointHotSpot
Specifies the address of a POINT structure that receives the offset of the drag image relative to the drag position.

Return Value

If successful, it is a pointer to the temporary image list that is used for dragging; otherwise, it is NULL.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
