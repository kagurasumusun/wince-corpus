IMPLEMENT_DYNAMIC

Generates the C++ code necessary for a dynamic CObject-derived class with run-time access to the class name and position within the hierarchy. Use the IMPLEMENT_DYNAMIC macro in a .CPP module, then link the resulting object code only once.

IMPLEMENT_DYNAMIC(
class_name,
base_class_name );

Parameters

class_name
The actual name of the class (not enclosed in quotation marks).
base_class_name
The name of the base class (not enclosed in quotation marks).

Remarks

Use the IMPLEMENT_DYNAMIC macro in the implementation file (.CPP) of your class. This macro takes as arguments the name of the class and its base class, as follows:

IMPLEMENT_DYNAMIC( CPerson, CObject );

The IMPLEMENT_DYNAMIC macro should be evaluated only once during a comp8ilation and therefore should not be used in an interface file (.H) that could potentially be included in more than one file.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palms-size PC, Pocket PC
