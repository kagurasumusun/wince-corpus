COleControl::GetAppearance

This method retrieves the value of the stock Appearance property.

short GetAppearance ( );

Return Value

The return value specifies the current appearance setting as a short, VT_I2, value, if successful. This value is zero if the appearance of the control is flat and one if the control appearance is three dimensional .

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
