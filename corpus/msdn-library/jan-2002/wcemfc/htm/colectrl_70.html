COleControl::InvalidateControl

This method invalidates an area of the displayed control, causing it to be redrawn.

If lpRect has a NULL value, the entire control will be redrawn. If lpRect is not NULL, this indicates the portion of the control rectangle that is to be invalidated. In cases where the control has no window, or is currently inactive, the rectangle is ignored, and a call is made to the IAdviseSink::OnViewChange method of the client site. Use this function instead of CWnd::InvalidateRect or InvalidateRect.

void InvalidateControl(
LPCRECT lpRect = NULL,
BOOL bErase = TRUE );

Parameters

lpRect
Specifies a pointer to the region of the control to be invalidated.
bErase
Specifies whether the invalidated control is to be erased. If TRUE, the invalidated control is erased. If FALSE, the invalidated control remains unchanged.

Requirements
