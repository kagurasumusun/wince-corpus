CFrameWnd::CreateView

This method creates a view that is not derived from CView within a frame. Use this method to create views that are not CView-derived within a frame. After calling CreateView, you must manually set the view to active and set it to be visible; CreateView does not automatically perform these tasks.

CWnd* CreateView(
CCreateContext* pContext,
UINT nID = AFX_IDW_PANE_FIRST);

Parameters

pContext
Specifies the type of view and document.
nID
Specifies the ID number of a view.

Return Value

Pointer to a CWnd object if it is successful; otherwise, it is NULL.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
