COleControl::GetMessageString

This method retrieves the status bar text for a menu item. The default implementation attempts to load a string resource identified by nID.

virtual void GetMessageString(
UINT nID,
CString& rMessage )
const;

Parameters

nID
Specifies a menu item ID.
rMessage
Specifies a reference to a CString object through which a string will be returned.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
