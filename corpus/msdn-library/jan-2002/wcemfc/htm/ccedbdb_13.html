CCeDBDatabase::GetLastModified

This method retrieves the date and time when the database was last modified.

FILETIME GetLastModified( )
const;

Return Values

A FILETIME structure that contains the last date and time when the database was modified.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
