CListCtrl::GetItemState

This method retrieves the state of a list view item.

The state of an item is specified by the state member of the Windows CE structure LVITEM. When you specify or change the state of an item, the stateMask member specifies which state bits you want to change. 

UINT GetItemState(
int nItem,
UINT nMask )
const;

Parameters

nItem
Specifies the index of the item whose state is to be retrieved.
nMask
Mask specifying which state flags of the item to return.

Return Value

The state flags for the specified list view item.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

// Make sure the focus is set to the list view control.
pmyListCtrl->SetFocus();

// Select all of the items that are completely visible.
int n = pmyListCtrl->GetTopIndex();
int nLast = n + pmyListCtrl->GetCountPerPage();

for (;n < nLast;n++)
{
  pmyListCtrl->SetItemState(n, LVIS_SELECTED, LVIS_SELECTED);
  ASSERT(pmyListCtrl->GetItemState(n, LVIS_SELECTED) == LVIS_SELECTED);
}

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
