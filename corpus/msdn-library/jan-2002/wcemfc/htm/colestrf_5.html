COleStreamFile::CreateStream

This method safely creates a new stream in the supplied storage object where a failure is a normal, expected condition. A file exception is thrown if the open fails and pError is not NULL.

BOOL CreateStream(
LPSTORAGE lpStorage,
LPCTSTR lpszStreamName,
DWORD nOpenFlags = modeReadWrite|shareExclusive|modeCreate,
CFileException* pError = NULL );

Parameters

lpStorage
Points to the OLE storage object that contains the stream to be created. Cannot be NULL.
lpszStreamName
Specifies a name of the stream to be created. Cannot be NULL.
nOpenFlags
Specifies the access mode to use when opening the stream. Exclusive, read/write, and create modes are used by default. For a complete list of the available modes, see CFile::CFile.
pError
Points to a CFileException object or NULL. Supply this parameter if you want to monitor possible exceptions generated by attempting to create the stream.

Return Value

Nonzero if the stream is created successfully; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxole.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
