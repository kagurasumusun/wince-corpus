COleControl::OnSetData

This method is called by the framework to replace the control data with the specified data. If the data is in the persistent property set format, the default implementation modifies the state of the control accordingly. Otherwise, the default implementation does nothing. If bRelease is TRUE, then a call to ReleaseStgMedium is made; otherwise, not.

Override this function to replace the data in a control with the specified data.

virtual BOOL OnSetData(
LPFORMATETC lpFormatEtc,
LPSTGMEDIUM lpStgMedium,
BOOL bRelease );

Parameters

lpFormatEtc
Specifies a pointer to a FORMATETC structure specifying the format of the data.
lpStgMedium
Specifies a pointer to a STGMEDIUM structure in which the data resides.
bRelease
Specifies TRUE if the control should free the storage medium; specifies FALSE if the control should not free the storage medium.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
