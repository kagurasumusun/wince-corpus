CWnd::GetScrollPos

This method retrieves the current position of the scroll box of a scroll bar. The current position is a relative value that depends on the current scrolling range. For example, if the scrolling range is 50 to 100 and the scroll box is in the middle of the bar, the current position is 75.

int GetScrollPos(
nt nBar )
const;

Parameters

nBar
Specifies the scroll bar to examine. The parameter can take one of the following values:
  • SB_HORZ   Retrieves the position of the horizontal scroll bar.
  • SB_VERT   Retrieves the position of the vertical scroll bar.

Return Value

Specifies the current position of the scroll box in the scroll bar if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
