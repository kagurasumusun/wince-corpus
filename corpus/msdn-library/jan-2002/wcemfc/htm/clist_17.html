CList::IsEmpty

This method determines whether this list is empty.

BOOL IsEmpty( )
const;

Return Value

Nonzero if this list is empty; otherwise, it is zero.

Example

// Define myList.
CList<CString,CString&> myList;

// Add three elements to the list.
myList.AddTail(CString("XYZ"));
myList.AddTail(CString("ABC"));
myList.AddTail(CString("123"));

// Remove the head element until the list is empty.
CString str;
while (!myList.IsEmpty())
{
  str = myList.RemoveHead();
  TRACE(_T("%s\r\n"), (LPCTSTR) str);
}

Requirements
