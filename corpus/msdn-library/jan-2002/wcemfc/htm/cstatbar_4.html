CStatusBar::Create

This method creates a status bar, or a child window, and associates it with the CStatusBar object. It also sets the initial font and sets the height of the status bar to a default value.

BOOL Create(
CWnd* pParentWnd,
DWORD dwStyle = WS_CHILD | WS_VISIBLE | CBRS_BOTTOM,
UINT nID = AFX_IDW_STATUS_BAR );

Parameters

pParentWnd
Specifies a pointer to the CWnd object whose Windows CE window is the parent of the status bar.
dwStyle
Specifies the status-bar style. In addition to the standard Windows CE styles, these styles are supported.
  • CBRS_TOP   Control bar is at top of frame window.
  • CBRS_BOTTOM   Control bar is at bottom of frame window.
  • CBRS_NOALIGN   Control bar is not repositioned when the parent is resized.
nID
Specifies the child-window ID of the toolbar.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
