CStatusBar::SetPaneInfo

This method sets the specified indicator pane to a new identifier, style, and width.

void SetPaneInfo(
int nIndex,
UINT nID,
UINT nStyle,
int cxWidth );

Parameters

nIndex
Specifies the index of the indicator pane whose style is to be set.
nID
Specifies the new identifier for the indicator pane.
nStyle
Specifies the new style for the indicator pane.
cxWidth
Specifies the new width for the indicator pane.

Remarks

The following indicator styles are supported:

  • SBPS_NOBORDERS   No 3-D border around the pane.
  • SBPS_POPOUT   Reverse border so that text “pops out.”
  • SBPS_DISABLED   Do not draw text.
  • SBPS_STRETCH   Stretch pane to fill unused space. Only one pane per status bar can have this style.
  • SBPS_NORMAL   No stretch, borders, or pop-out.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
