CTabCtrl::SetCurFocus

This method implements the behavior of the Windows CE message TCM_SETCURFOCUS. 

void SetCurFocus(
int nItem );

Parameters

nItem
Specifies the index of the tab that gets the focus.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
