CFont::operator HFONT

This operator returns the Windows CE GDI handle to the font attached to the CFont object.

operator HFONT( )
const;

Return Value

The handle of the Windows CE GDI font object attached to CFont if successful; otherwise, it is NULL.

Example

// This code fragment shows the usage of the CFont::operator HFONT
// operator.

// Initialize a CFont object with the characteristics given
// in a LOGFONT structure.
LOGFONT lf;
memset(&lf, 0, sizeof(LOGFONT));          // Clear out structure.
lf.lfHeight = 12;                         // Request a 12-pixel-height
                                          // font.
lstrcpy(lf.lfFaceName, _T("Arial"));
// Request a face name "Arial".

CFont font1;
font1.CreateFontIndirect(&lf);  // Create the font.

// The CFont::operator HFONT operator automatically converts font1 from
// CFont* to HFONT.
CFont* font2 = CFont::FromHandle(font1);

// Use the font you just created.
CClientDC dc(this);
CFont* def_font = dc.SelectObject(font2);
dc.ExtTextOut(5, 5, ETO_OPAQUE, NULL _T("Hello"), NULL);
dc.SelectObject(def_font);

// Finished with the font, now delete the font object.
font1.DeleteObject();

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
