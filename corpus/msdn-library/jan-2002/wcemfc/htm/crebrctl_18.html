CReBarCtrl::GetTextColor

This method retrieves the default text color for a rebar control.

This method implements the behavior of the Windows CE message RB_GETTEXTCOLOR. 

COLORREF GetTextColor( )
const;

Return Value

Returns a COLORREF value that represents the current default text color.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
