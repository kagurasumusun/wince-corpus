CControlBar::CalcInsideRect

This method adjusts for the correct sizing of a control bar that has a gripper.

void CalcInsideRect(
CRect& rect,
BOOL bHorz )
const;

Parameters

rect
Specifies the size and position of the control bar as a CRect object.
bHorz
Indicates that the bar is horizontally or vertically oriented. The bHorz parameter is nonzero if the bar is horizontally oriented and is zero if it is vertically oriented.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
