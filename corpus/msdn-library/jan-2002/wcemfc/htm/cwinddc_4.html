CWindowDC::m_hWnd

This data member contains the window handle to the CWnd object used to construct the CWindowDC object. The m_hWnd data member is a protected variable of type HWND.

HWND m_hWnd;

Example

This is the example from the CWindowDC class

// Get a dc for a CWnd object pointer.
CWindowDC dc(pWnd);

// Send my private massage.
::SendMessage(pWnd->m_hWnd, WM_MYMESSAGE, 0, 0);

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
