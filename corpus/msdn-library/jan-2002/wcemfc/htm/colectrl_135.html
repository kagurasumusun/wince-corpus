COleControl::SerializeVersion

This method serializes or initializes the version information of the control.

You can improve the binary persistence performance of a control by using SerializeVersion, SerializeExtent, and SerializeStockProps to override COleControl::Serialize. 

DWORD SerializeVersion(
CArchive& ar,
DWORD dwVersionDefault,
BOOL bConvert = TRUE );

Parameters

ar
Specifies a CArchive object to serialize to or from.
dwVersionDefault
Specifies the current version number of the control.
bConvert
Indicates whether persistent data should be converted to the latest format when it is saved, or maintained in the same format it had when it was loaded.

Return Value

Returns the version number of the control. If the specified archive is loading, SerializeVersion returns the version loaded from that archive. Otherwise, it returns the currently loaded version.

For an example, see the code at SerializeExtent.
