COleDateTimeSpan::GetMinutes

This method retrieves the minute portion of this date/time-span value.

The return values from this function range between – 59 and 59.

long GetMinutes( )
const;

Return Value

Returns the minutes portion of this date/time-span value.

Remarks

For other functions that query the value of a COleDateTimeSpan object, see the following methods:

  • GetDays
  • GetHours
  • GetSeconds
  • GetTotalDays
  • GetTotalHours
  • GetTotalMinutes
  • GetTotalSeconds

Example

COleDateTimeSpan ts( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ASSERT( ts.GetMinutes() == 5 );

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
