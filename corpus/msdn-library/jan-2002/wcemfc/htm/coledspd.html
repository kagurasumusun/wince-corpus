COleDispatchDriver

This class implements the client side of Automation. Dispatch interfaces provide access to the methods and properties of an object.

COleDispatchDriver does not have a base class.

Methods of COleDispatchDriver attach, detach, create, and release a dispatch connection of type IDispatch. Other methods use variable argument lists to simplify calling IDispatch::Invoke.

This class can be used directly, but it is generally used only by classes created by ClassWizard. When you create new eMbedded Visual C++ 3.0 classes by importing a type library, ClassWizard derives the new classes from COleDispatchDriver.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
