CToolBar::LoadToolBar

This method loads the toolbar specified by lpszResourceName or nIDResource.

BOOL LoadToolBar(
LPCTSTR lpszResourceName );

( virtual BOOL, BOOL ) LoadToolBar(
UINT nIDResource );

Parameters

lpszResourceName
Specifies the pointer to the resource name of the toolbar to be loaded.
nIDResource
Specifies the resource ID of the toolbar to be loaded.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

See the example for CToolBar::CreateEx.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
