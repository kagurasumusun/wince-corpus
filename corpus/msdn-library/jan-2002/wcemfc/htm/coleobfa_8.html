COleObjectFactory::RegisterAll

This method registers all of the application's object factories with the system DLLs. This method is usually called by CWinApp::InitInstance when the application is launched.

static BOOL PASCAL RegisterAll( );

Return Value

Nonzero if the factories are successfully registered; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
