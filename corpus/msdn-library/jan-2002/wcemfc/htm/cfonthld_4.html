CFontHolder::GetDisplayString

This method retrieves a string that can be displayed in the property browser of a container.

BOOL GetDisplayString(
CString& strValue );

Parameters

strValue
Specifies the reference to the CString that will hold the display string.

Return Value

Nonzero if the string is successfully retrieved; otherwise, zero.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
