CWindowDC

This class is derived from CDC. It calls the Windows CE GetWindowDC function at construction time and ReleaseDC function at destruction time. This means that a CWindowDC object accesses the entire screen area of a CWnd, both client and nonclient areas.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
