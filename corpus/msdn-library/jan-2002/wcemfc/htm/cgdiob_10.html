CGdiObject::GetObjectType

This method retrieves the type of the specified object.

UINT GetObjectType ( )
const;

Return Value

The type of the object, if successful; otherwise, it is zero. The value can be one of the following:

  • OBJ_BITMAP   Bitmap
  • OBJ_BRUSH   Brush
  • OBJ_FONT   Font
  • OBJ_PAL   Palette
  • OBJ_PEN   Pen
  • OBJ_EXTPEN   Extended pen
  • OBJ_REGION   Region
  • OBJ_DC   Device context
  • OBJ_MEMDC   Memory device context
  • OBJ_METAFILE   Metafile
  • OBJ_METADC   Metafile device context
  • OBJ_ENHMETAFILE   Enhanced metafile
  • OBJ_ENHMETADC   Enhanced-metafile device context

Remarks

Windows CE 1.0 does not support the following return values:

  • OBJ_ENHMETADC
  • OBJ_ENHMETAFILE
  • OBJ_EXTPEN
  • OBJ_METADC
  • OBJ_METAFILE
  • OBJ_PAL

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
