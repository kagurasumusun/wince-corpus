CCeDBProp::GetShort

This method retrieves the value of a property, when the property's data type is a signed short integer.

short GetShort( )
const;

Return Values

The value of the property.

Remarks

You can only call GetShort on a property of the type CCeDBProp::Type_Short.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
