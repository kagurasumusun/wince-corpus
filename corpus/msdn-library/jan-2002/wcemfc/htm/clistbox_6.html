CListBox::Create

This method initializes the Windows CE list box and attaches it to the CListBox object.

To construct a CListBox object, call the constructor, then call Create

BOOL Create(
DWORD dwStyle,
const RECT& rect,
CWnd* pParentWnd,
UINT nID );

Parameters

dwStyle
Specifies the style of the list box. Apply any combination of list-box styles to the box.
rect
Specifies the list-box size and position. Can be either a CRect object or a RECT structure.
pParentWnd
Specifies the parent window for a list box, usually a CDialog object. It must not be NULL.
nID
Specifies the control ID for the list box.

Return Value

Nonzero if it is successful; otherwise it is zero.

Remarks

When Create executes, Windows sends the WM_CREATE, message to the list-box control.

This message is handled by default by the OnCreate, method in the CWnd base class. To extend the default message handling, derive a class from CListBox, add a message map to the new class, and override the preceding message-handler methods. For example, to perform needed initialization for a new class, override OnCreate.

Apply the following window styles to a list-box control.

  • WS_CHILD   Always
  • WS_VISIBLE   Usually
  • WS_DISABLED   Rarely
  • WS_VSCROLL   To add a vertical scroll bar
  • WS_HSCROLL   To add a horizontal scroll bar
  • WS_GROUP   To group controls
  • WS_TABSTOP   To allow tabbing to this control

Windows CE supports a new list box style, called LBS_EX_CONSTSTRINGDATA. When an application inserts a string into a list box that has this style, the list box stores the pointer passed to it by the application rather than copying the string. This saves RAM resources when you have a large table of strings in ROM that you want to insert into a list box. All list boxes in Windows CE have the LBS_HASSTRINGS style by default.

Example

// pParentWnd is an external pointer to the parent window.
extern CWnd* pParentWnd;
// The pointer to my list box.
extern CListBox* pmyListBox;

pmyListBox->Create(WS_CHILD|WS_VISIBLE|LBS_STANDARD|WS_HSCROLL,
  CRect(10,10,200,200), pParentWnd, 1);

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
