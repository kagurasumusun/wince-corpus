ConstructElements

This function is called when new array, list, and map elements are constructed. The default version initializes all bits of the new elements to 0 and calls the stored objects' constructors in a loop. 

template< class TYPE >
void AFXAPI ConstructElements( TYPE* pElements,
int nCount );

Parameters

TYPE
Template parameter specifying the type of the elements to be constructed.
pElements
Specifies the pointer to the elements.
nCount
Specifies the number of elements to be constructed.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxtempl.h
  Platform: H/PC Pro, Palms-size PC, Pocket PC
