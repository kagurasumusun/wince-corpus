CWnd::PreCreateWindow

This method is called by the framework before the creation of the Windows CE window attached to this CWnd object.

Never call this function directly.

virtual BOOL PreCreateWindow(
CREATESTRUCT& cs );

Parameters

cs
Specifies a CREATESTRUCT structure.

Return Value

Nonzero if the window creation should continue; zero to indicate creation failure.

Remarks

The default implementation of this function checks for a NULL window class name and substitutes an appropriate default. Override this method to modify the CREATESTRUCT structure before the window is created.

Each class derived from CWnd adds its own functionality to its override of PreCreateWindow. By design, these derivations of PreCreateWindow are not documented. To determine the styles appropriate to each class and the interdependencies between the styles, you can examine the MFC for Windows CE source code for the base class of your application. If you choose to override PreCreateWindow, you can determine whether the styles used in the base class of your application provide the functionality you need by using information gathered from the MFC for Windows CE source code.

Example

// Alter the styles of the main frame window.
BOOL CMainFrame::PreCreateWindow(CREATESTRUCT& cs)
{
   // Create a window without min/max buttons or sizable border.
   cs.style = WS_OVERLAPPED | WS_SYSMENU | WS_BORDER;

   // Size the window to 1/3 screen size and center it.
   cs.cy = ::GetSystemMetrics(SM_CYSCREEN) / 3;
   cs.cx = ::GetSystemMetrics(SM_CXSCREEN) / 3;
   cs.y = ((cs.cy * 3) - cs.cy) / 2;
   cs.x = ((cs.cx * 3) - cs.cx) / 2;

    return CFrameWnd::PreCreateWindow(cs);
}
