CTreeView

This class simplifies use of the tree control and of CTreeCtrl, the class that encapsulates tree-control functionality, with the document-view architecture of MFC.

For more information on this architecture, see the overview for the CView class and the cross-references cited there.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcview.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
