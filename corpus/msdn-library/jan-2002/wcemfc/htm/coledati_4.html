COleDateTime::GetAsSystemTime

This method creates a COleDateTime object based on the time data stored in a SYSTEMTIME data structure. GetAsSystemTime stores the resulting time in the referenced sysTime object. The SYSTEMTIME data structure initialized by this function will have its wMilliseconds member set to zero.

BOOL GetAsSystemTime(
SYSTEMTIME& sysTime )
const;

Parameters

sysTime
Specifies a reference to a SYSTEMTIME structure to be converted to a date/time value and copied into the new COleDateTime object.

Return Value

TRUE if it is successful. It is FALSE if the conversion fails, or if the COleDateTime object is NULL or invalid.

Remarks

See GetStatus for more information on the status information held in a COleDateTime object.
