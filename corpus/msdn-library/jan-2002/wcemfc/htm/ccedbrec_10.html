CCeDBRecord::GetRecordID

This method retrieves the record identifier.

CEOID GetRecordID();

Return Values

A pointer to the record identifier, or NULL if RecordID is out of range.

Requirements

  Windows CE versions: 3.0 and later
  Header file: Declared in Wcedb.h
  Platform: Pocket PC
