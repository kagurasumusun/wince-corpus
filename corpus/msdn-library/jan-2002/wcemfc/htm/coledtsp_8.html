COleDateTimeSpan::GetTotalDays

This method retrieves this date/time-span value expressed in days.

The return values from this function range between approximately – 3.65e6 and 3.65e6.

double GetTotalDays( )
const;

Return Value

This date/time-span value expressed in days. Although this function is prototyped to return a double, it always returns an integer value.

Remarks

For other functions that query the value of a COleDateTimeSpan object, see the following methods:

  • GetDays
  • GetHours
  • GetMinutes
  • GetSeconds
  • GetTotalHours
  • GetTotalMinutes
  • GetTotalSeconds

Example

// Example for COleDateTimeSpan::GetTotalXxx functions.
COleDateTimeSpan ts( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ASSERT( ts.GetTotalDays() == 3 );
ASSERT( ts.GetTotalHours() == 73 );
ASSERT( ts.GetTotalMinutes() == 4385 );
ASSERT( ts.GetTotalSeconds() == 263112 );
