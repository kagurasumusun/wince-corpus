CCeDocList::GetSelectedPathname

This method gets the path associated with the selected item.

BOOL GetSelectedPathname(
LPTSTR pszPath, 
WORD nSize );

Parameters

pszPath
Pointer to the path of the selected item in the doclist.
nSize
Specifies the length, in characters, of the buffer that receives the path.

Return Value

TRUE or nonzero indicates success; FALSE or zero indicates failure.

Requirements

  Windows CE versions: 3.0 and later
  Header file: Declared in Afxext.h
  Platform: Pocket PC
