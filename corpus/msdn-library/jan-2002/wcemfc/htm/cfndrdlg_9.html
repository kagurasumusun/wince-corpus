CFindReplaceDialog::IsTerminating

This method is called from your callback function to determine whether the user has decided to terminate the dialog box. If this function returns nonzero, you should call the DestroyWindow function of the current dialog box and set any dialog box pointer variable to NULL. Optionally, you can also store the find/replace text last entered and use it to initialize the next find/replace dialog box.

BOOL IsTerminating( )
const;

Return Value

Nonzero if the user has decided to terminate the dialog box; otherwise, it is zero.

Example

See the example for CFindReplaceDialog::GetFindString.
