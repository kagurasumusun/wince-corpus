CPropExchange

CPropExchange establishes the context and direction of a property exchange.

This class supports the implementation of persistence for your ActiveX controls. Persistence is the exchange of the state information of the control , usually represented by its properties, between the control itself and a medium. CPropExchange can be used to initialize or serialize the properties of a control upon the load or creation of a control.

CPropExchange does not have a base class.

The framework constructs an object derived from CPropExchange when it is notified that the properties of an OLE control are to be loaded from or stored to persistent storage.

The framework passes a pointer to this CPropExchange object to the DoPropExchange function of your control. If you used ClassWizard to create the starter files for your control, the DoPropExchange function calls COleControl::DoPropExchange. The base-class version exchanges the stock properties of the control. Modify the version of your derived class to exchange properties you have added to your control.

The ExchangeProp and ExchangeFontProp methods of CPropExchange are able to store properties to and load them from different media.
