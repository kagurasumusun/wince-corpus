CMenu::DeleteTempMap

This method is called automatically by the CWinApp idle-time handler. DeleteTempMap deletes any temporary CMenu objects created by the FromHandle method. DeleteTempMap detaches the Windows CE menu object attached to a temporary CMenu object before deleting the CMenu object.

static void PASCAL DeleteTempMap( );

Example

// The following example is correct:
CMenu::DeleteTempMap();

// The following example is incorrect.
// DeleteTempMap() is a static member and cannot be called
// within the scope of an instantiated CMenu object.
pMenu->DeleteTempMap();  // Causes compiler error

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
