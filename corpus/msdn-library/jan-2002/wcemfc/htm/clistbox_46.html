CListBox::SetTopIndex

This method ensures that a particular list-box item is visible. The system scrolls the list box until either the item specified by nIndex appears at the top of the list box or the maximum scroll range has been reached.

int SetTopIndex(
int nIndex );

Parameters

nIndex
Specifies the zero-based index of the list-box item.

Return Value

Zero if it is successful, or LB_ERR if an error occurs.

Example

// Pointer to the myListBox.
extern CListBox* pmyListBox;

// Set the first visible item in the list box to be the middle item
pmyListBox->SetTopIndex(pmyListBox->GetCount()/2);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
