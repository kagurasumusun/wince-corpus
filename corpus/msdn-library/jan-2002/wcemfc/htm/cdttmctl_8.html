CDateTimeCtrl::GetTime

This method retrieves the selected time from a DTP control.

Store the time information in a COleDateTime class, a CTime class, or a SYSTEMTIME structure.

DWORD GetTime(
CTime& timeDest )
const; 

BOOL GetTime(
COleDateTime& timeDest )
const; 

DWORD GetTime(
LPSYSTEMTIME pTimeDest )
const;

Parameters

timeDest
In the first version, a reference to a COleDateTime object that receives the system time information. In the second version, a reference to a CTime object that receives the system time information.
pTimeDest
Pointer to the SYSTEMTIME structure to receive the system time information. Must not be NULL.

Return Value

In the first version, nonzero if the time is successfully written to the COleDateTime object; otherwise, it is zero. In the second and third versions, a DWORD value equal to the dwFlag member set in the NMDATETIMECHANGE structure.

Remarks

The return value DWORD in the second and third versions, above, indicates whether the date and time picker control is set to no-date status, as indicated in the NMDATETIMECHANGE structure member dwFlags. If the value returned equals GDT_NONE, the control is set to no-date status and uses the DTS_SHOWNONE style. If the value returned equals GDT_VALID, the system time is successfully stored in the destination location.

Example

void CDatesDlg::OnButton2()
{
   // Gain a pointer to the control.
   CDateTimeCtrl* pCtrl = (CDateTimeCtrl*) GetDlgItem(IDC_DATETIMEPICKER1);
   ASSERT(pCtrl != NULL);

   // Get a CTime
   CTime timeTime;
   DWORD dwResult = pCtrl->GetTime(timeTime);
   if (dwResult == GDT_VALID)
   {
      // The user checked the box and specified data.
      CString str;

      // Is it a time-only control or a date-only control?
      if ((pCtrl->GetStyle() & DTS_TIMEFORMAT) == DTS_TIMEFORMAT)
         str = timeTime.Format(_T("%X"));
      else
         str = timeTime.Format(_T("%x"));
      AfxMessageBox(str);
   }
   else
   {
      // The user cleared the "none" box.
      AfxMessageBox(_T("Time not set!"));
   }

   // Calling as SYSTIME is much the same, but calling COleDateTime
   // tests the state of the COleDateTime object for validity to
   // see if the user did or did not check the "none" box.
}
