CEdit::GetMargins

This method retrieves the left and right margins of this edit control. The margins are measured in pixels.

DWORD GetMargins( )
const;

Return Value

The width of the left margin in the low-order WORD and the width of the right margin in the high-order WORD.

Remarks

For more information, see the Windows CE message EM_GETMARGINS.

Example

See the example for CEditView::GetEditCtrl.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also
