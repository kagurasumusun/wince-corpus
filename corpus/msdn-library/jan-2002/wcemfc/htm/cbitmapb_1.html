CBitmapButton Methods

Construction Methods

Method Description
CBitmapButton Constructs a CBitmapButton object.
LoadBitmaps Initializes the object by loading one or more named bitmap resources from the application resource file and attaching the bitmaps to the object.
AutoLoad Associates a button in a dialog box with a CBitmapButton object, loads the bitmap by name, and sizes the button to fit the bitmap.

Operations Methods

Method Description
SizeToContent Sizes the button to accommodate the bitmap.
