CTime::operator +, -

These operators add and subtract CTimeSpan objects to and from CTime objects.

Use the third overloaded operator to subtract one CTime object from another to yield a CTimeSpan object.

CTime objects represent absolute time. CTimeSpan objects represent relative time. 

CTime operator +(
CTimeSpan timeSpan )
const; 

CTime operator –(
CTimeSpan timeSpan )
const; 

CTimeSpan operator –(
CTime time )
const;

Example

// example for CTime::operator  +, -
CTime t1( 1999, 3, 19, 22, 15, 0 ); // 10:15PM March 19, 1999
CTime t2( 1999, 3, 20, 22, 15, 0 ); // 10:15PM March 20, 1999
CTimeSpan ts = t2 - t1;  // Subtract 2 CTimes
ASSERT( ts.GetTotalSeconds() == 86400L );
ASSERT( ( t1 + ts ) == t2 );  // Add a CTimeSpan to a CTime.
ASSERT( ( t2 - ts ) == t1 );  // Subtract a CTimeSpan from a CTime.
