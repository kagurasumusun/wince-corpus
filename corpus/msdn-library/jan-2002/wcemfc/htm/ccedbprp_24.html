CCeDBProp::SetType

This method sets the data type of a property.

void SetType(
CCeDBProp::enType nType );

Parameters

nType
Specifies the data type of the property. It is one of the following values:
Value Description
CCeDBProp::Type_Short A signed short integer
CCeDBProp::Type_Ushort An unsigned short integer
CCeDBProp::Type_Long A signed long integer
CCeDBProp::Type_Ulong An unsigned long integer
CCeDBProp::Type_Filetime A FILETIME structure
CCeDBProp::Type_String A null-terminated wide (Unicode) character string, not a CString object
CCeDBProp::Type_Blob A CEBLOB structure

Remarks

When you call SetType, any data belonging to the property is lost. The new data value is zero or NULL, depending on the data type.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
