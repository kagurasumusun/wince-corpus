COleControl::GetForeColor

This method retrieves the value of the stock ForeColor property.

OLE_COLOR GetForeColor( );

Return Value

The return value specifies the current foreground color as an OLE_COLOR value, if successful. This value can be translated to a COLORREF value with a call to TranslateColor.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
