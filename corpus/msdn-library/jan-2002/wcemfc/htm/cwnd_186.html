CWnd::SetProperty

This method sets the ActiveX control property specified by dwDispID. This method should be called only on an ActiveX control.

void AFX_CDECL SetProperty(
DISPID dwDispID,
VARTYPE vtProp, ... );

Parameters

dwDispID
Identifies the property to be set. This value is usually supplied by Component Gallery.
vtProp
Specifies the type of the property to be set. For possible values, see the Remarks section for COleDispatchDriver::InvokeHelper.
...
Specifies a single parameter of the type specified by vtProp.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
