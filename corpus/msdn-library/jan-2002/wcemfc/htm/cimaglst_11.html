CImageList::DragEnter

This method locks updates to the window specified by pWndLock during a drag operation, and displays the drag image at the position specified by point.

static BOOL PASCAL DragEnter(
CWnd* pWndLock,
CPoint point );

Parameters

pWndLock
Specifies the pointer to the window that owns the drag image.
point
Specifies the position at which to display the drag image. Coordinates are relative to the upper left corner of the window, not the client area.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Remarks

The coordinates are relative to the upper left corner of the window, so you must compensate for the widths of window elements, such as the border, title bar, and menu bar when specifying the coordinates.

If pWndLock is NULL, this function draws the image in the display context associated with the desktop window. The coordinates are relative to the upper left corner of the window.

This function locks all other updates to the given window during the drag operation. If you need to do any drawing during a drag operation, such as highlighting the target of a drag-and-drop operation, you can temporarily hide the dragged image by using the CImageList::DragLeave method.
