CMonthCalCtrl::SetMaxSelCount

This method sets the maximum number of days that can be selected in a month calendar control.

This method implements the behavior of the Windows CE message MCM_SETMAXSELCOUNT. 

BOOL SetMaxSelCount(
int nMax );

Parameters

nMax
Specifies the value that will be set to represent the maximum number of selectable days.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// The control needs to have the MCS_MULTISELECT style
// for the following code to work.
void CDatesDlg::OnButton2()
{
   // Gain a pointer to the control.
   CMonthCalCtrl* pCtrl = (CMonthCalCtrl*) GetDlgItem(IDC_MONTHCALENDAR1);

   // Change the maximum selection count.
   pCtrl->SetMaxSelCount(10);

   // Check that the change was really made.
   ASSERT(pCtrl->GetMaxSelCount() == 10);
}

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxdtctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
