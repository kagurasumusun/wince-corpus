CHeaderCtrl::Layout

This method retrieves the size and position of a header control within a specified rectangle. This method is used to determine the appropriate dimensions for a new header control that is to occupy the specified rectangle.

BOOL Layout(
HDLAYOUT* pHeaderLayout );

Parameters

pHeaderLayout
Specifies the pointer to an HDLAYOUT structure, which contains information used to set the size and position of a header control.

Return Value

Nonzero if successful; otherwise, it is zero.

Example

// Pointer to the myheader control.
extern CHeaderCtrl* pmyHeaderCtrl;
HDLAYOUT  hdl;
WINDOWPOS wpos;
RECT      rc;

// Reposition the header control so that it is placed at
// the top of its client area in the parent window.
pmyHeaderCtrl->GetParent()->GetClientRect(&rc);

hdl.prc = &rc;
hdl.pwpos = &wpos;
pmyHeaderCtrl->Layout(&hdl);

pmyHeaderCtrl->SetWindowPos(
  CWnd::FromHandle(wpos.hwndInsertAfter),
  wpos.x,
  wpos.y,
  wpos.cx,
  wpos.cy,
  wpos.flags | SWP_SHOWWINDOW);

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
