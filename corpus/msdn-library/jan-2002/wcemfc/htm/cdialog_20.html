m_bFullScreen

The Boolean value of this data member determines whether a dialog box is automatically set to the size of the client area.

BOOL m_bFullScreen;

Remarks

The default value is TRUE; that is, the dialog occupies the entire client area. Set this value to FALSE before calling DoModal or CreateDialog for modeless dialogs so that the dialog box is not automatically set to the size of the client area.

When a modal dialog is instantiated, CDialog automatically creates a CCeCommandBar that is empty, to prevent any application menus from dropping down. Dialog boxes can own their own instance of CCeCommandBar, defined in the CDialog-derivitive class as in a CFrameWnd-derivitive class, and create CCeCommandBar during OnInitDialog.

Requirements

  Windows CE versions: 3.0 and later
  Header file: Declared in Afxwin.h
  Platform: Pocket PC
