CToolBarCtrl::AddString

This method adds a new string, passed as a resource identifier, to the internal list of strings of the toolbar.

int AddString(
UINT nStringID );

Parameters

nStringID
Specifies the resource identifier of the string resource to add to the string list of the toolbar control.

Return Value

The zero-based index of the first new string added if it is successful; otherwise, it is –1.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
