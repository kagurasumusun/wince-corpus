CTreeCtrl::GetParentItem

This method retrieves the parent of hItem.

HTREEITEM GetParentItem(
HTREEITEM hItem )
const;

Return Value

The handle of the parent item; otherwise, it is NULL.

Parameters

hItem
Specifies the handle of a tree item.

Example

See the example for CTreeCtrl::EnsureVisible.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
