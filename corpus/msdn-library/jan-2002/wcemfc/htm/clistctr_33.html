CListCtrl::GetNextSelectedItem

This method retrieves the index of the list item identified by pos, then sets pos to the POSITION value. You can use GetNextSelectedItem in a forward iteration loop if you establish the initial position with a call to GetFirstSelectedItemPosition.

You must ensure that your POSITION value is valid. If it is invalid, then the Debug version of the MFC for Windows CE asserts.

int GetNextSelectedItem(
POSITION& pos )
const;

Parameters

pos
A reference to a POSITION value returned by a previous call to GetNextSelectedItem or GetFirstSelectedItemPosition. The value is updated to the next position by this call.

Return Value

The index of the next selected item in the list view control.

Example

The following code sample demonstrates the usage of this method.

CListCtrl* pListCtrl = (CListCtrl*) GetDlgItem(IDC_YOURLISTCONTROL);
ASSERT(pListCtrl != NULL);

POSITION pos = pList->GetFirstSelectedItemPosition();
if (pos == NULL)
   TRACE0("No items were selected!\n");
else
{
   while (pos)
   {
      int nItem = pList->GetNextSelectedItem(pos);
      TRACE1("No items were selected!\n");
      // You could do your own processing on nItem here.
   }
}
