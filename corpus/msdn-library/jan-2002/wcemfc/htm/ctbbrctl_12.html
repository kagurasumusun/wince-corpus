CToolBarCtrl::Create

This method specifies the style of the toolbar control. Toolbars must always have the WS_CHILD style.

You construct a CToolBarCtrl object in two steps. First call the constructor, then call Create, which creates the toolbar control and attaches it to the CToolBarCtrl object.

BOOL Create(
DWORD dwStyle,
const RECT& rect,
CWnd* pParentWnd,
UINT nID );

Parameters

dwStyle
Specifies the style of the toolbar control. Toolbars must always have the WS_CHILD style. In addition, you can specify any combination of toolbar styles and window styles as described under the Remarks section.
rect
Optionally specifies the size and position of the toolbar control. It can be either a CRect object or a RECT structure.
pParentWnd
Specifies the parent window of the toolbar control. It must not be NULL.
nID
Specifies the ID of the toolbar control.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Remarks

Apply the following window styles to a toolbar control.

  • WS_CHILD   Always
  • WS_VISIBLE   Usually
  • WS_DISABLED   Rarely

See CreateWindow for a description of window styles.

Optionally, apply a combination of common control styles.

Apply a combination of toolbar styles to either the control or the buttons themselves. The styles are described in the topic Toolbar Controls and Button Messages in the API Reference.

To use extended toolbar styles, call SetExtendedStyle after you call Create. To create a toolbar with extended window styles, call CToolBarCtrl::CreateEx instead of Create.

The toolbar control automatically sets the size and position of the toolbar window. The height is based on the height of the buttons in the toolbar. The width is the same as the width of the client area of the parent window. The CCS_TOP and CCS_BOTTOM styles determine whether the toolbar is positioned along the top or bottom of the client area. By default, a toolbar has the CCS_TOP style.
