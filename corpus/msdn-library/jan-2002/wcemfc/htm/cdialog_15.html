CDialog::OnSetFont

This method specifies the font a dialog-box control uses when drawing text. The dialog-box control uses the specified font as the default for all dialog-box controls. 

virtual void OnSetFont(
CFont* pFont );

Parameters

pFont
Pointer to the font. Used as the default font for all controls in this dialog box.

Remarks

The dialog editor sets the dialog-box font as part of the dialog-box template resource.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
