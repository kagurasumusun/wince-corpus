CReBarCtrl::BeginDrag

This method puts the rebar control in drag-and-drop mode.

It implements the behavior of the Windows CE message RB_BEGINDRAG. 

void BeginDrag(
UINT uBand,
DWORD dwPos = (DWORD)–1 );

Parameters

uBand
Specifies the zero-based index of the band which affects the drag-and-drop operation.
dwPos
Specifies a DWORD value that contains the starting mouse coordinates. The horizontal coordinate is contained in the LOWORD and the vertical coordinate is contained in the HIWORD. If you pass (DWORD)–1, the rebar control will use the position of the mouse the last time the control thread called GetMessage or PeekMessage.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
