CTabCtrl::RemoveImage

This method removes the specified image from the image list of a tab control. The tab control updates the image index of each tab so that each tab remains associated with the same image.

void RemoveImage(
int nImage );

Parameters

nImage
Specifies the zero-based index of the image to remove.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also

CTabCtrl::GetImageList, CTabCtrl::SetImageList
