CControlBar::OnUpdateCmdUI

This method is called by the framework to update the status of the toolbar or status bar.

virtual void OnUpdateCmdUI(
CFrameWnd* pTarget,
BOOL bDisableIfNoHndler ) = 0;

Parameters

pTarget
Pointer to the main frame window of the application. This pointer is used for routing update messages.
bDisableIfNoHndler
Flag that indicates whether a control that has no update handler should be automatically displayed as disabled.

Remarks

To update an individual button or pane, use the ON_UPDATE_COMMAND_UI macro in your message map to set an update handler appropriately.

OnUpdateCmdUI is called by the framework when the application is idle. The frame window to update must be a child window, at least indirectly, of a visible frame window. OnUpdateCmdUI is an advanced overridable method.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
