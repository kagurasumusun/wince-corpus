CCeSaveModifiedDlg

This class presents a dialog box with four options: Yes, No, Cancel, and Save As. It does not actually call any document-related member functions, but uses CCeSaveModifiedDlg::DoModal to return IDYES, IDNO, IDCANCEL, or ID_FILE_SAVE_AS.

This class is a refinement for the Pocket PC of the MessageBox used by CDocument::SaveModified in other versions of MFC. The application can also directly use this class.
