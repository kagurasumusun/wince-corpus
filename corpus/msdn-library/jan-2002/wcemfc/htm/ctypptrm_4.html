CTypedPtrMap::RemoveKey

This method looks up the map entry corresponding to the supplied key and, if the key is found, removes the entry.

BOOL RemoveKey(
KEY key );

Parameters

KEY
Template parameter specifying the type of the map keys.
key
Specifies the key for the element to be removed.

Return Value

Nonzero if the entry was found and successfully removed; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxtempl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
