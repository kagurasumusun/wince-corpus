CWinApp::OnHelp

If enabled, help is called by the framework when the user presses the F1 key.

afx_msg void OnHelp( );

Remarks

You must add an 

ON_COMMAND( ID_HELP, OnHelp )

statement to your CWinApp class message map to enable this method. Usually you will also add an accelerator-key entry for the F1 key. Enabling the F1 key is only a convention, not a requirement.

The default implementation of this message-handler function determines the Help context that corresponds to the current window, dialog box, or menu item and then calls Winhelp.exe. If no context is currently available, the function uses the default context.

Override this method to set the Help context to something other than the window, dialog box, menu item, or toolbar button that currently has the focus. Call WinHelp with the desired Help context ID.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
