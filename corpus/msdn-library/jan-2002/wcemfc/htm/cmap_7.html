CMap::InitHashTable

This method initializes the hash table. For best performance, the hash table size should be a prime number. To minimize collisions, the size should be roughly 20 percent larger than the largest anticipated data set.

void InitHashTable(
UINT hashSize,
BOOL bAllocNow = TRUE );

Parameters

hashSize
Specifies the number of entries in the hash table.
bAllocNow
Specifies the next hash table to allocate. The default is TRUE.

Example

CMap<int,int,CPoint,CPoint> myMap;
  int i;

  myMap.InitHashTable( 257 );

  // Add 10 elements to the map.
  for (i=0;i < 200;i++)
    myMap[i] = CPoint(i, i);

  // Remove the elements with even key values.
  CPoint pt;
  for (i=0; myMap.Lookup( i, pt ) ;i+=2)
  {
    myMap.RemoveKey( i );
  }

#ifdef _DEBUG
  ASSERT(myMap.GetCount() == 100);
    afxDump.SetDepth( 1 );
    afxDump << "myMap: " << &myMap << "\n";
#endif
