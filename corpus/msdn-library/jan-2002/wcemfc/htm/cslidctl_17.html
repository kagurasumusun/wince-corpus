CSliderCtrl::GetTic

This method retrieves the position of a tick mark in a slider control.

int GetTic(
int nTic )
const;

Parameters

nTic
Specifies the zero-based index identifying a tick mark.

Return Value

Returns the position of the specified tick mark or – 1 if nTic does not specify a valid index.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
