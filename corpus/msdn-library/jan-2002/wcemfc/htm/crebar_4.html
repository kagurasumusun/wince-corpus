CRebar::Create

This method creates a rebar.

BOOL Create(
CWnd* pParentWnd,
DWORD dwCtrlStyle = RBS_BANDBORDERS,
DWORD dwStyle = WS_CHILD | WS_VISIBLE | WS_CLIPSIBLINGS | WS_CLIPCHILDREN | CBRS_BOTTOM | CBRS_TOP,
UINT nID = AFX_IDW_REBAR );

Parameters

pParentWnd
Specifies a pointer to the CWnd object whose Windows CE frame window is the parent of the status bar.
dwCtrlStyle
Specifies the rebar control style. By default, RBS_BANDBORDERS, which displays narrow lines to separate adjacent bands within the rebar control.
dwStyle
Specifies the rebar window styles.
nID
Specifies the rebar's child-window ID.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// Define a pointer to a CRebar in your class definition,
// such as: CReBar* m_pReBar; More often, however, you
// would probably specify an instance in your class
// definition, such as: CReBar m_ReBar;
m_pReBar = new CReBar();
m_pReBar->Create(this);
m_wndDlgBar.Create(this, IDR_MAINFRAME, CBRS_ALIGN_TOP,
   AFX_IDW_DIALOGBAR);
m_pReBar->AddBar(&m_wndDlgBar);

Requirements

  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
