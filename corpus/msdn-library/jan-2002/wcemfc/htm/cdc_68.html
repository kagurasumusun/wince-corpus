CDC::RectVisible

This method determines whether any part of the specified rectangle lies within the clipping region of the display context.

virtual BOOL RectVisible(
LPCRECT lpRect )
const;

Parameters

lpRect
Pointer to a RECT structure or a CRect object that contains the logical coordinates of the specified rectangle.

Return Value

Nonzero if any portion of the given rectangle lies within the clipping region; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
