CMapPtrToWord

This class supports maps of 16-bit words keyed by void pointers.

Because the methods of CMapPtrToWord are similar to the methods of class CMapStringToOb, use the CMapStringToOb reference documentation for method specifics. Wherever you see a CObject pointer as a function parameter or return value, substitute WORD. Wherever you see a CString or a const pointer to char as a method parameter or return value, substitute a pointer to void.

BOOL CMapStringToOb::Lookup( const char* <key>,
                             CObject*& <rValue> ) const;

for example, translates to

BOOL CMapPtrToWord::Lookup( const void* <key>, WORD& <rValue> ) const;

CMapWordToPtr incorporates the IMPLEMENT_DYNAMIC macro to support run-time type access and dumping to a CDumpContext object. If you need a dump of individual map elements, you must set the depth of the dump context to one or greater.

Pointer-to-word maps may not be serialized.

When a CMapPtrToWord object is deleted, or when its elements are removed, the pointers and the words are removed. The entities referenced by the key pointers are not removed.
