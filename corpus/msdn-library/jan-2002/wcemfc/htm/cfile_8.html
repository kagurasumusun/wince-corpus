CFile::GetFileTitle

This method retrieves the file title for a specified file. For example, when you call GetFileTitle to generate a message to the user about the file \MyDocuments\Untitled.txt, the file title (Untitled) is returned. The file title typically does not include the extension.

In Windows 98, the file title typically does not include the extension. For an explanation of this, see GetFileTitle in the Platform SDK.

To return the entire path of the file, including the name, call GetFilePath. To return just the name of the file, Myfile.wri, call GetFileName.

virtual CString GetFileTitle( ) 
const;

Return Value

The title of the specified file.
