CTabCtrl::SetPadding

This method sets the amount of space (padding) around the icon and label of each tab in a tab control.

void SetPadding(
CSize size );

Parameters

size
Sets the amount of space (padding) around the icon and label of each tab in a tab control.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
