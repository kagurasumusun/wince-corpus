CSyncObject::Lock

This method gains access to the resource controlled by the synchronization object.

If the synchronization object is signaled, Lock returns successfully and the thread now owns the object. If the synchronization object is nonsignaled (unavailable), Lock waits for the synchronization object to become signaled up to the number of milliseconds specified in the dwTimeOut parameter. If the synchronization object did not become signaled in the specified amount of time, Lock returns failure.

virtual BOOL Lock(
DWORD dwTimeout = INFINITE );

Parameters

dwTimeout
Specifies the amount of time to wait for the synchronization object to be available (signaled). If INFINITE, Lock waits until the object is signaled before returning.

Return Value

Returns nonzero if the function was successful; otherwise, it is zero.

Requirements
