CWnd::GetTopLevelParent

This method obtains a pointer to the top-level parent of the window. CWnd::GetTopLevelParent is similar to CWnd::GetTopLevelFrame and GetTopLevelOwner; however, it ignores the value set as the current owner window.

CWnd* GetTopLevelParent( )
const;

Return Value

Identifies the top-level parent window of the window.

The returned pointer may be temporary and should not be stored for later use.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
