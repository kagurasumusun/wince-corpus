CRect::Height

This method calculates the height of CRect by subtracting the top value from the bottom value. The resulting value can be negative.

The rectangle must be normalized or this method may fail. You can call NormalizeRect to normalize the rectangle before calling this method.

int Height( )
const;

Return Value

Returns the height of CRect.

Example

CRect rect(20, 30, 80, 70);

int nHt = rect.Height();

// nHt is now 40
ASSERT(nHt == 40);
