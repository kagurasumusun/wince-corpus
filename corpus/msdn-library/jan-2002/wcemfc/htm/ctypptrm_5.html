CTypedPtrMap::SetAt

This method inserts an element in a map. First, the key is looked up. If the key is found, then the corresponding value is changed; otherwise a new key-value element is created.

void SetAt(
KEY key,
VALUE newValue );

Parameters

KEY
Template parameter specifying the type of the map keys.
key
Specifies the key value of the newValue.
VALUE
Template parameter specifying the type of values stored in this map.
newValue
Specifies the object pointer that is the value of the new element.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxtempl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
