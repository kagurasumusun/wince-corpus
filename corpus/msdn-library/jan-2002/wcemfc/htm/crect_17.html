CRect::SetRectEmpty

This method makes a CRect object a null rectangle by setting all coordinates to zero.

void SetRectEmpty( );

Example

CRect rect;
rect.SetRectEmpty();

// rect is now (0, 0, 0, 0)
ASSERT(rect.IsRectEmpty());

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
