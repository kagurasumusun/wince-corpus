CEditView::SetPrinterFont

This method sets the printer font to the font specified by pFont.

If you want your view to always use a particular font for printing, include a call to SetPrinterFont in the OnPreparePrinting function of your class. This virtual function is called before printing occurs, so the font change takes place before the contents of the view are printed.

void SetPrinterFont( 
CFont* pFont );

Parameters

pFont
Specifies a pointer to an object of type CFont. If NULL, the font used for printing is based on the display font.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
  Platform: H/PC Pro
