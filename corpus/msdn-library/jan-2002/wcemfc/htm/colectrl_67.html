COleControl::InternalGetFont

This method retrieves a CFontHolder object for the stock Font property.

CFontHolder& InternalGetFont( );

Return Value

A reference to a CFontHolder object that contains the stock Font object.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also
