CObArray::RemoveAt

This method removes one or more elements starting at a specified index in an array. In the process, it shifts down all the elements above the removed element(s). It decrements the upper bound of the array but does not free memory.

If you try to remove more elements than are contained in the array above the removal point, then the Debug version of the library asserts.

The RemoveAt method removes the CObject pointer from the array, but it does not delete the object itself.

void RemoveAt(
int nIndex,
int nCount = 1 );

Parameters

nIndex
Specifies an integer index that is greater than or equal to zero and less than or equal to the value returned by GetUpperBound.
nCount
Specifies the number of elements to remove.

Remarks

The following table shows other methods that are similar to CObArray::RemoveAt.

Example

See CObList::CObList for a listing of the CAge class used in all collection examples.

// Example for CObArray::RemoveAt.

   CObArray array;
   CObject* pa;

   array.Add( new CAge( 21 ) ); // Element 0
   array.Add( new CAge( 40 ) ); // Element 1
   if( ( pa = array.GetAt( 0 ) ) != NULL )
   {
       array.RemoveAt( 0 );  // Element 1 moves to 0.
       delete pa; // Delete the original element at 0.
   }
#ifdef _DEBUG
   afxDump.SetDepth( 1 );
   afxDump << "RemoveAt example: " << &array << "\n";
#endif

The results from this program are as follows:

RemoveAt example: A CObArray with 1 elements
    [0] = a CAge at $4606 40
