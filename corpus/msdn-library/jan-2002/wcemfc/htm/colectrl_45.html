COleControl::GetClassID

This method retrieves the COM class identifier of the control. The COleControl::GetClassID method is usually implemented by the IMPLEMENT_OLECREATE_EX macro.

virtual HRESULT GetClassID(
LPCLSID pclsid ) = 0;

Parameters

pclsid
Specifies the pointer to the location of the class ID.

Return Value

Nonzero if the call was not successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
