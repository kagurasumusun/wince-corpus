CSplitterWnd::ActivateNext

This method is called by the framework to execute the Next Pane or Previous Pane command.

This method is a high level command that is used by the CView class to delegate to the CSplitterWnd implementation.

virtual void ActivateNext(
BOOL bPrev = FALSE );

Parameters

bPrev
Indicates which window to activate. TRUE for previous; FALSE for next.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
