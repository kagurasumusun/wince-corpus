COleControl::AmbientDisplayName

This method retrieves the name of the control as specified by the container. 

CString AmbientDisplayName( );

Return Value

The name of the OLE control. The default is a zero-length string.

Remarks

The name the container has assigned to the control can be used in error messages displayed to the user. Note that the container is not required to support this property.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
