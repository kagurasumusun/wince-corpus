COleControl::FireClick

This method fires the stock Click event. If this event is defined as a custom event, you determine when the event is fired.

For automatic firing of a Click event to occur, the control Event map must have a stock Click event defined.

void FireClick( );

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
