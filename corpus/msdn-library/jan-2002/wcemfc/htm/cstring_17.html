CString::Insert

This method inserts a single character or a substring at the given index within the string. The nIndex parameter identifies the first character that will be moved to make room for the character or substring. If nIndex is zero, the insertion occurs before the entire string. If nIndex is higher than the length of the string, the method concatenates the present string and the new material provided by either ch or pstr.

int Insert(
int nIndex,
TCHAR ch ); 

int Insert(
int nIndex,
LPCTSTR pstr );

Parameters

nIndex
Specifies the index of the character before which the insertion will take place.
ch
Specifies the character to be inserted.
pstr
Specifies a pointer to the substring to be inserted.

Return Value

Returns the length of the changed string.

Example

//The following example demonstrates the use of CString::Insert.
  CString str("HockeyBest");
  int n = str.Insert(6, _T("is "));
  ASSERT(n == str.GetLength());
  _tprintf("1: %s\n", (LPCTSTR) str);

  n = str.Insert(6, ' ');
  ASSERT(n == str.GetLength());
  _tprintf("2: %s\n", (LPCTSTR) str);

  n = str.Insert(555, '!');
  ASSERT(n == str.GetLength());
  _tprintf("3: %s\n", (LPCTSTR) str);

//this code generates these lines of output:

1: Hockeyis Best
2: Hockey is Best
3: Hockey is Best!
