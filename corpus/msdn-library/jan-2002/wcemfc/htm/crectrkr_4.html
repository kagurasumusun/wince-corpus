CRectTracker::Draw

This method draws the outer lines and inner region of a rectangle. The style of the tracker determines how the drawing is done.

void Draw(
CDC* pDC )
const;

Parameters

pDC
Specifies a pointer to the device context on which to draw.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
