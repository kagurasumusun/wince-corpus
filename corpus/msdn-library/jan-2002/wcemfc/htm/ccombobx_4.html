CComboBox::Clear

This method clears the selection in the edit control of the combo box.

void Clear( );

Remarks

To delete the selection and copy the deleted contents to the clipboard, use the Cut method.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Delete the text from the combo box edit control.
pmyComboBox->SetEditSel(0, -1);
pmyComboBox->Clear();

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
