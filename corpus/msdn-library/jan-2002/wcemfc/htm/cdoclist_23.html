CCeDocList::SetItemState

This method changes the state of an item in the doclist.

BOOL SetItemState(
int nItem, 
UINT nState, 
UINT nStateMask );

Parameters

nItem
The index number for the item.
nState
Specifies values for states to be changed.
nStateMask
Specifies which states are to be changed.

Return Value

TRUE or nonzero indicates success; FALSE or zero indicates failure.

Requirements

  Windows CE versions: 3.0 and later
  Header file: Declared in Afxext.h
  Platform: Pocket PC
