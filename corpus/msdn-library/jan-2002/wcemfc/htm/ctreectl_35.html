CTreeCtrl::Select

This method selects the specified tree view item, scrolls the item into view, or redraws the item in the style used to indicate the target of a drag-and-drop operation.

If nCode contains the value TVGN_CARET, the parent window receives the TVN_SELCHANGING and TVN_SELCHANGED notification messages. In addition, if the specified item is the child of a collapsed parent item, the parent list of child items is expanded to reveal the specified item. In this case, the parent window receives the TVN_ITEMEXPANDING and TVN_ITEMEXPANDED notification messages.

BOOL Select(
HTREEITEM hItem,
UINT nCode );

Parameters

hItem
Specifies the handle of a tree item.
nCode
Specifies the type of action to take. This parameter can be one of the following values:
  • TVGN_CARET   Sets the selection to the given item.
  • TVGN_DROPHILITE   Redraws the given item in the style used to indicate the target of a drag-and-drop operation.
  • TVGN_FIRSTVISIBLE   Scrolls the tree view vertically so that the given item is the first visible item.

Return Value

Nonzero if it is successful; otherwise, it is zero.
