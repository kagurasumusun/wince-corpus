CDateTimeCtrl::SetRange

This method sets the minimum and maximum allowable system times for a DTP control.

BOOL SetRange(
const COleDateTime* pMinRange,
const COleDateTime* pMaxRange );

BOOL SetRange(
const CTime* pMinRange, 
const CTime* pMaxRange );

Parameters

pMinRange
Pointer to a COleDateTime object or a CTime object containing the earliest time allowed in the CDateTimeCtrl object.
pMaxRange
Pointer to a COleDateTime object or a CTime object containing the latest time allowed in the CDateTimeCtrl object.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Remarks

In the implementation of MFC for Windows CE, you can specify COleDateTime or CTime usages. If the COleDateTime object has a NULL status, the range is removed. If the CTime pointer or the COleDateTime pointer is NULL, the range is removed.

Example

See the example for CDateTimeCtrl::GetRange.

Requirements
