CListView::DrawItem

By default, this member function does nothing. Override this member function to implement drawing for an owner-draw CListCtrl object.

virtual void DrawItem(
LPDRAWITEMSTRUCT lpDrawItemStruct );

Remarks

The CListView::DrawItem method is called by the framework when a visual aspect of an owner-draw list view changes. The itemAction member of the DRAWITEMSTRUCT structure defines the drawing action that is to be performed.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcview.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
