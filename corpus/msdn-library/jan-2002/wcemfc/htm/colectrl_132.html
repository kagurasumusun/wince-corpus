COleControl::SelectStockFont

This method selects the stock Font property into a device context.

CFont* SelectStockFont(
CDC* pDC );

Parameters

pDC
Specifies the device context into which the font will be selected.

Return Value

A pointer to the previously selected CFont object. You should use CDC::SelectObject to select this font back into the device context when you are finished.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
