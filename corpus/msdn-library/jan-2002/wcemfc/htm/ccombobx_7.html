CComboBox::Create

This method creates the Windows CE combo box and attaches it to the CComboBox object.

BOOL Create(
DWORD dwStyle,
const RECT& rect,
CWnd* pParentWnd,
UINT nID );

Parameters

dwStyle
Specifies the style of the combo box. Apply any combination of combo box styles to the box.
rect
Pointer to the position and size of the combo box. Can be a RECT structure or a CRect object.
pParentWnd
Specifies the parent window of the combo box, usually a CDialog. It must not be NULL.
nID
Specifies the combo box’s control identifier.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Remarks

To construct a CComboBox object, call the constructor, then call Create.

To extend default message handling, derive a class from CComboBox, add a message map to the new class, and override the preceding message-handler methods. Override OnCreate, for example, to perform needed initialization for a new class.

Apply the following window styles to a combo box control. :

  • WS_CHILD   Always
  • WS_VISIBLE   Usually
  • WS_DISABLED   Rarely
  • WS_VSCROLL   To add vertical scrolling for the list box in the combo box
  • WS_HSCROLL   To add horizontal scrolling for the list box in the combo box
  • WS_GROUP   To group controls
  • WS_TABSTOP   To include the combo box in the tabbing order

Windows CE version 2.12 and later supports a new extended style for combo boxes, CBS_EX_CONSTSTRINGDATA. When an application inserts a string in the list part of a combo box that has this style, the combo box stores the pointer passed by the application rather than copying the string. This saves RAM resources when you have a large table of strings in ROM that you want to insert in a combo box.

All combo boxes in Windows CE have the LBS_HASSTRINGS style by default.

Windows CE does not support the CBS_SIMPLE, CBS_OWNERDRAWFIXED, or CBS_OWNERDRAWVARIABLE styles.

Example

// pParentWnd is an external pointer to the parent window.
extern CWnd* pParentWnd;
// The pointer to a combo box.
extern CComboBox* pmyComboBox;

pmyComboBox->Create(
    WS_CHILD|WS_VISIBLE|WS_VSCROLL|CBS_DROPDOWNLIST,
    CRect(10,10,200,100), pParentWnd, 1);

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
