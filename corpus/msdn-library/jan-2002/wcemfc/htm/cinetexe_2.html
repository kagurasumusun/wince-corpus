CInternetException::CInternetException

This constructor creates an instance of a CInternetException object. To throw a CInternetException, call the MFC for Windows CE global function AfxThrowInternetException.

CInternetException(
DWORD dwError );

Parameters

dwError
Specifies the error that caused the exception.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxinet.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
