CFontHolder Methods

Construction Methods

Method Description
CFontHolder Constructs a CFontHolder object.

Operations Methods

Method Description
FontToCEFont Transforms the current font into an IFont and makes it the current font.
GetFontDispatch Returns the IDispatch interface of the font.
GetDisplayString Retrieves the string displayed in the property browser of a container.
GetFontHandle Returns a handle to a Windows font.
InitializeFont Initializes a CFontHolder object.
ReleaseFont Disconnects the CFontHolder object from the IFont and IFontNotification interfaces.
RestoreFont Releases a font, previously saved by FontToCEFont and restores it to the saved font.
Select Selects a font resource into a device context.
SetFont Connects the CFontHolder object to an IFont interface.
