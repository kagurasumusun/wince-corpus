Creating Applications

You can create your own MFC applications from scratch by opening an empty workspace in the eMbedded Visual C++ IDE and then writing your own files.

But unless you have a particular reason to do that, you'll find creating applications much simplified by using the wizards offered by the IDE. Which wizards are available depends on which SDKs you have installed. For example, only if you have installed the Pocket PC SDK will you see the Pocket PC MFC AppWizard (exe). This wizard guides you in creating an MFC application specifically for the Pocket PC.

Wizards are designed to be self-explanatory. The following documentation summarizes highlights of the steps each MFC wizard offers.

  • ActiveX Controls
  • Dynamic Link Libraries
  • Executable Files
  • Pocket PC Executable Files

For the use of the IDE wizards in general, see documentation for the IDE.
