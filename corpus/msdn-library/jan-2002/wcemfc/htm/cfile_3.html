CFile::Abort

This method closes the file associated with this object and makes the file unavailable for reading or writing. If you do not close the file before destroying the object, the destructor closes it for you.

The Abort method does not throw an exception on failures. Abort does not ASSERT if the file was not opened or closed previously.

If you used new to allocate the CFile object on the heap, you must delete it after closing the file. Abort sets m_hFile to CFile::hFileNull.

virtual void Abort( );

Example

// Example for the CFile::Abort method.
CStdioFile fileTest;
TCHAR* pFileName = _T("test.dat");
TRY
{
  // Do something here that may throw exceptions.
  fileTest.Open( pFileName, CFile::modeWrite );
}
CATCH_ALL( e )
{
  fileTest.Abort();  // Closes a file safely and quietly.
  THROW_LAST();
}
END_CATCH_ALL

Requirements

  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
