CCeDocList

Use CCeDocList to display lists of documents in a consistent way.

The CCeDocList class wraps the operating system implementation of the DocList window type, with additional features for integration with an MFC Doc/View architecture. The class owns its own CCeCommandBar, initialized with a shared new menu item, during its lifetime, and forwards commands from it to its parent window. It sends a creation-time notification to its parent so that the application can customize DocList and CCeCommandBar attributes. This class responds to the shared new command by sending the ID_FILE_NEW command to the application. It responds to the DLN_ITEMACTIVATED notification, for example, when a user selects a file, by calling CWinApp::OnOpenDocument . For other DLN_ notifications, the parent window should use ON_NOTIFY message maps.
