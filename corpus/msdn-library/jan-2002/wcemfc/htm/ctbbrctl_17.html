CToolBarCtrl::GetButtonCount

This method retrieves a count of the buttons currently in the toolbar control.

int GetButtonCount( )
const;

Return Value

Returns the count of the buttons.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
