CCmdTarget::GetIDispatch

This method retrieves the IDispatch pointer from an automation method that returns an IDispatch pointer or takes an IDispatch pointer by reference.

LPDISPATCH GetIDispatch(
BOOL bAddRef );

Parameters

bAddRef
Specifies whether to increment the reference count for the object.

Return Value

The IDispatch pointer associated with the object.

Remarks

For objects that call CCmdTarget::EnableAutomation in their constructors, making them automation enabled, this function returns a pointer to the MFC implementation of IDispatch that is used by clients who communicate through the IDispatch interface. Calling this function automatically adds a reference to the pointer, so it is not necessary to make a call to IUnknown::AddRef.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
