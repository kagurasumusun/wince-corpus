CWnd::ShowDoneButton

CWnd-derivitives call this method when they define an OnOK handler, using the ON_COMMAND(IDOK) message map, and want it to be called when the Done button is pressed. In other words, CWnds call this to own the Done button.

BOOL ShowDoneButton(
BOOL bShow );

Parameters

bShow
TRUE displays the button, FALSE hides it.

Return Value

TRUE, non-zero, indicates success; FALSE indicates failure.

Remarks

Only one CWnd can own the Done button at one time. The owner of the Done button is the last CWnd to call ShowDoneButton(TRUE). This method is automatically called by the framework when the window is destroyed, but a CWnd can relinquish ownership earlier by calling ShowDoneButton(FALSE).

When there are no owners of the Done button, the framework hides the Done button from the TaskBar. In addition, the framework manages the visibility of the Done button based on the activation of the frame window (CFrameWnd).

Dialog boxes do not need to call ShowDoneButton(), because the operating system automatically adds one.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: Pocket PC
