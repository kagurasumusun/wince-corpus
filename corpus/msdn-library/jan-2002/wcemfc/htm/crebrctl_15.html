CReBarCtrl::GetRect

This method retrieves the bounding rectangle for a specified band in a rebar control.

This method implements the behavior of the Windows CE message RB_GETRECT. 

BOOL GetRect(
UINT uBand,
LPRECT prc )
const;

Parameters

uBand
Specifies the zero-based index of a band in the rebar control.
prc
Specifies a pointer to a RECT structure that will receive the bounds of the rebar band.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

CRect rc;
m_wndReBar.GetReBarCtrl().GetRect(0, &rc);
CString msg;
msg.Format(_T("rect.left = %d, rect.top = %d,
   rect.right = %d, rect.bottom = %d"), rc.left,
   rc.top, rc.right, rc.bottom);
AfxMessageBox(msg);

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
