CCeCommandBar Methods

Constructors Methods

Method Description
CCeCommandBar Creates and initializes a CCeCommandBar object.
ResetCommandBar Removes all menus, combo boxes, buttons, and adornments from the command bar.

Operations Methods

Method Description
AddAdornments Adds a Close button, and optionally, Help and OK buttons, to the command bar.
DrawMenuBar Repositions and redraws the command bar after a command bar menu is modified.
GetMenuBar Retrieves a pointer to a menu on the command bar.
GetNumButtons Gets the count of the buttons in the toolbar.
InsertComboBox Adds a combo box to the command bar.
InsertMenuBar Adds a menu bar to the command bar.
InsertSeperator Adds a separator to the command bar.
WrapAtButton Makes the specified button the last button in the current row.
