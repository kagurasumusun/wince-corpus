COleStreamFile::OpenStream

This method opens an existing stream. A file exception is thrown if the open fails and pError is not NULL.

BOOL OpenStream(
LPSTORAGE lpStorage,
LPCTSTR lpszStreamName,
DWORD nOpenFlags = modeReadWrite|shareExclusive,
CFileException* pError = NULL );

Parameters

lpStorage
Points to the OLE storage object that contains the stream to be opened. Cannot be NULL.
lpszStreamName
Specifies the name of the stream to be opened. Cannot be NULL.
nOpenFlags
Specifies an access mode to use when opening the stream. Exclusive and read/write modes are used by default. For the complete list of the available modes, see CFile::CFile.
pError
Points to a CFileException object or NULL. Supply this parameter if you want to monitor possible exceptions generated by attempting to open the stream.

Return Value

Nonzero if the stream is opened successfully; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxole.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
