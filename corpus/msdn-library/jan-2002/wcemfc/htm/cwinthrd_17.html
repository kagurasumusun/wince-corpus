CWinThread::m_bAutoDelete

This data member contains a Boolean value that specifies whether the CWinThread object should be automatically deleted at thread termination. 

BOOL m_bAutoDelete;

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
