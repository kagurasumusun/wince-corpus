CEdit::GetFirstVisibleLine

This method determines the topmost visible line in an edit control.

int GetFirstVisibleLine( )
const;

Return Value

The zero-based index of the topmost visible line. For single-line edit controls, the return value is zero.

Remarks

For more information, see the Windows CE message EM_GETFIRSTVISIBLELINE.

Example

// The pointer to my edit.
extern CEdit* pmyEdit;

int nFirstVisible = pmyEdit->GetFirstVisibleLine();

// Scroll the edit control so that the first visible line
// is the first line of text.
if (nFirstVisible > 0)
{
  pmyEdit->LineScroll(-nFirstVisible, 0);
}

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
