CPropExchange::ExchangeVersion

This method is called by the framework to handle persistence of a version number.

virtual BOOL ExchangeVersion(
DWORD& dwVersionLoaded,
DWORD dwVersionDefault,
BOOL bConvert );

Parameters

dwVersionLoaded
Specifies the reference to a variable where the version number of the persistent data being loaded will be stored.
dwVersionDefault
Specifies the current version number of the control.
bConvert
Indicates whether to convert persistent data to the current version or keep it at the same version that was loaded.

Return Value

Nonzero if the function succeeded; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
