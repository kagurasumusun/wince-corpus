CListCtrl::GetItemCount

This method retrieves the number of items in a list view control.

int GetItemCount( )
const;

Return Value

The number of items in the list view control.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

int nCount = pmyListCtrl->GetItemCount();

// Delete all of the items from the list view control.
for (int i=0;i < nCount;i++)
{
  pmyListCtrl->DeleteItem(0);
}

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
