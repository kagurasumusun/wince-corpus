CStatusBar::GetItemID

This method copies the coordinates of the indicator specified by nIndex into the structure pointed to by lpRect. Coordinates are in pixels relative to the upper-left corner of the status bar.

UINT GetItemID(
int nIndex )
const;

Parameters

nIndex
Specifies the index of the indicator whose identifier is to be retrieved.

Return Value

The ID of the indicator specified by nIndex.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
