CImageList::GetSafeHandle

This method retrieves the m_hImageList data member.

HIMAGELIST GetSafeHandle( )
const;

Return Value

A handle to the attached image list; otherwise, it is NULL if no object is attached.

Example

// Pointer to the myImageList.
extern CImageList* pmyImageList;

// Get the safe handle to the image list.
HIMAGELIST hImageList = pmyImageList->GetSafeHandle();

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
