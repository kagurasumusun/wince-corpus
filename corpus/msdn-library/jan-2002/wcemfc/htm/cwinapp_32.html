CWinApp::SaveAllModified

This method is called by the framework to save all documents when the main frame window in the application is to be closed, or through a WM_QUERYENDSESSION message.

The default implementation of this method calls the CDocument::SaveModified method in turn for all modified documents within the application.

virtual BOOL SaveAllModified( );

Return Value

Nonzero if safe to terminate the application; zero if not safe to terminate the application.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
