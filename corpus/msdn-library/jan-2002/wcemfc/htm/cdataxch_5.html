CDataExchange::PrepareEditCtrl

This method is called by the framework to prepare the specified edit control for dialog data exchange (DDX) and validation (DDV).

HWND PrepareEditCtrl(
int nIDC );

Parameters

nIDC
Specifies the identifier of the edit control to be prepared for DDX or DDV.

Return Value

The HWND of the edit control being prepared for DDX or DDV.

Remarks

Use PrepareCtrl for all nonedit controls.

Preparation consists of two things. First, PrepareEditCtrl stores the control HWND in the CDataExchange class. The framework uses this handle to restore the focus to the previously focused control in the event of a DDX or DDV failure. Second, PrepareEditCtrl sets a flag in the CDataExchange class to indicate that the control whose data is being exchanged or validated is an edit control.

Implementers of custom DDX or DDV routines should call PrepareEditCtrl for all edit controls for which they are exchanging data through DDX or validating data through DDV.
