CComboBox::DeleteString

This method deletes a string in the list box of a combo box.

int DeleteString(
UINT nIndex );

Parameters

nIndex
Specifies the index to the string to delete.

Return Value

If the return value is greater than or equal to zero, it is a count of the strings remaining in the list. The return value is CB_ERR if nIndex specifies an index greater than the number of items in the list.

Remarks

All items following nIndex now move down one position. For example, if a combo box contains two items, deleting the first item causes the remaining item to be in the first position. nIndex=0 for the item in the first position.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Delete every other item from the combo box.
for (int i=0;i < pmyComboBox->GetCount();i++)
{
   pmyComboBox->DeleteString( i );
}

Requirements

  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
