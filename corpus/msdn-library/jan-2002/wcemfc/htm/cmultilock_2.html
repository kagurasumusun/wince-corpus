CMultiLock::CMultiLock

This method constructs a CMultiLock object. This function is called after creating the array of synchronization objects to be waited on. It is usually called from within the thread that must wait for one of the synchronization objects to become available.

CMultiLock(
CSyncObject* ppObjects[ ],
DWORD dwCount,
BOOL bInitialLock = FALSE );

Parameters

ppObjects
Specifies the array of pointers to the synchronization objects to be waited on. Cannot be NULL.
dwCount
Specifies the number of objects in ppObjects. Must be greater than zero.
bInitialLock
Specifies whether to initially attempt to access any of the supplied objects.

Requirements

  Windows CE versions: 3.0 and later  
  Header file: Declared in Afxmt.h
  Platform: Pocket PC
