COleControl::OnDoVerb

This method is called by the framework after a control verb has been executed. The default implementation uses the ON_OLEVERB and ON_STDOLEVERB message map entries to determine the proper function to invoke.

Override this function to change the default handling of verb.

virtual BOOL OnDoVerb(
LONG iVerb,
LPMSG lpMsg,
HWND hWndParent,
LPCRECT lpRect );

Parameters

iVerb
Specifies the index of the control verb to be invoked.
lpMsg
Specifies a pointer to the Windows message that caused the verb to be invoked.
hWndParent
Specifies the handle to the parent window of the control. If the execution of the verb creates a window (or windows), hWndParent should be used as the parent.
lpRect
Specifies a pointer to a RECT structure into which the coordinates of the control, relative to the container, will be copied.

Return Value

Nonzero if the call was successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
