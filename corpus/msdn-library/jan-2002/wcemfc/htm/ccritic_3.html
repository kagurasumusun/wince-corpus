CCriticalSection::Lock

This method gains access to the critical section object. 

BOOL Lock( ); 

BOOL Lock(
DWORD dwTimeout );

Parameters

dwTimeout
Specifies a timeout value. Lock ignores this parameter value.

Return Value

Nonzero if the function was successful; otherwise, it is zero.

Remarks

Lock is a blocking call that does not return until the critical section object is signaled or is unlocked and becomes available.

If timed waits are necessary, you can use a CMutex object instead of a CCriticalSection object.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxmt.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
