CWnd::WindowProc

This method provides a CE procedure (WindowProc) for a CWnd object. It dispatches messages through the window message map.

virtual LRESULT WindowProc(
UINT message,
WPARAM wParam,
LPARAM lParam );

Parameters

message
Specifies the Windows message to be processed.
wParam
Provides additional information used in processing the message. The parameter value depends on the message.
lParam
Provides additional information used in processing the message. The parameter value depends on the message.

Return Value

The return value depends on the message.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
