CPrintInfo::GetFromPage

This method retrieves the number of the first page to be printed. This is the value specified by the user in the Print dialog box, and it is stored in the CPrintDialog object referenced by the m_pPD member. If the user has not specified a value, the default is the first page of the document.

UINT GetFromPage( )
const;

Return Value

The number of the first page to be printed.

Requirements
