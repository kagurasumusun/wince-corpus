CSize::operator !=

This operator checks for inequality between two sizes.

BOOL operator !=(
SIZE size )
const;

Return Values

Returns nonzero if the sizes are not equal, otherwise, it is zero.

Example

CSize sz1(222, 222);
CSize sz2(111, 111);

ASSERT(sz1 != sz2);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
