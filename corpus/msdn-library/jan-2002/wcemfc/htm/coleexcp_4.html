COleException::m_sc

This data member holds the COM status code (SCODE) that indicates the reason for the exception. The value of this variable is set by AfxThrowOleException.

SCODE m_sc;

Example

try {
  // ...
  // Some OLE call
  // ...
}
catch (COleException *e) {

  TRACE ("COleException caught. SCODE = %x\n", e->m_sc);
  e->Delete();
}

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
