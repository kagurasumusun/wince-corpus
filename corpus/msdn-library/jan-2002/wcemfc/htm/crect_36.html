CRect::operator |

This operator obtains a CRect object that is the union of CRect and rect2. The union is the smallest rectangle that contains both rectangles.

Both of the rectangles must be normalized or this function may fail. You can call NormalizeRect to normalize the rectangles before calling this function.

CRect operator|(
const RECT& rect2 )
const;

Parameters

rect2
Contains a RECT or CRect.

Return Value

A CRect that is the union of CRect and rect2.

Example

CRect  rect1(100,   0, 200, 300);
CRect  rect2(  0, 100, 300, 200);
CRect  rect3;

rect3 = rect1 | rect2;

CRect  rectResult(0, 0, 300, 300);
ASSERT(rectResult == rect3);
