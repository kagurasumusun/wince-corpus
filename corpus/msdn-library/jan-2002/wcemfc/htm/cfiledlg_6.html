CFileDialog::GetFileTitle

This method retrieves the title of the file entered in the dialog box. The title of the file includes only its prefix. For example, GetFileTitle will return TEXT for the file \My Document\Text.dat.

CString GetFileTitle( )
const;

Return Value

The title of the file.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxdlgs.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
