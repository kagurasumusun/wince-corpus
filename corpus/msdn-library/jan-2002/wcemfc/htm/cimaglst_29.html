CImageList::Replace

This method replaces an image in an image list with a new image.

Call this method after calling CImageList::SetImageCount to assign the new, valid images to the placeholder image index numbers.

BOOL Replace(
int nImage,
CBitmap* pbmImage,
CBitmap* pbmMask );

int Replace(
int nImage,
HICON hIcon );

Parameters

nImage
Specifies the zero-based index of the image to replace.
pbmImage
Specifies a pointer to the bitmap containing the image.
pbmMask
Specifies a pointer to the bitmap containing the mask. If no mask is used with the image list, this parameter is ignored.
hIcon
Specifies a handle to the icon that contains the bitmap and mask for the new image.

Return Value

The version returning BOOL returns nonzero if it is successful; otherwise, it is zero.

The version returning int returns the zero-based index of the image if successful; otherwise, –1.

Example

See the example for CImageList::SetImageCount.

Requirements
