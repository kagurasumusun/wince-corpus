CSpinButtonCtrl::GetAccel

This method retrieves acceleration information for a spin button control.

UINT GetAccel(
int nAccel,
UDACCEL* pAccel )
const;

Parameters

nAccel
Specifies the number of elements in the array specified by pAccel.
pAccel
Specifies a pointer to an array of UDACCEL structures that receives acceleration information.

Return Value

Number of accelerator structures retrieved.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
