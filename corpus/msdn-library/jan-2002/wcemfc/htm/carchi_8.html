CArchive::IsBufferEmpty

This method determines whether the internal buffer of the archive object is empty. This function is supplied to support programming with the MFC Windows Sockets class CSocketFile. You do not need to use it for an archive associated with a CFile object.

BOOL IsBufferEmpty( ) 
const;

Return Value

Nonzero if the archive’s buffer is empty; otherwise, it is zero.

Remarks

The reason for using IsBufferEmpty with an archive associated with a CSocketFile object is that the buffer of the archive might contain more than one message or record. After receiving one message, you should use IsBufferEmpty to control a loop that continues receiving data until the buffer is empty. For more information, see the CAsyncSocket::Receive method.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
