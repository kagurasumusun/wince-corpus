COleControl::OnFreezeEvents

This method is called by the framework when control events are frozen or unfrozen. Override this method if you need to implement additional behavior when event handling is frozen or unfrozen. The default implementation does nothing.

virtual void OnFreezeEvents(
BOOL bFreeze );

Parameters

bFreeze
TRUE if the event handling of the control is frozen; otherwise, it is FALSE.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
