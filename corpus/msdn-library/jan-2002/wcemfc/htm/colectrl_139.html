COleControl::SetCapture

This method causes the container window of the control to take possession of the mouse capture on behalf of the control.

Otherwise,, this function causes the control itself to take possession of the mouse capture. This is the same as CWnd::SetCapture.

CWnd* SetCapture( );

Return Value

A pointer to the CWnd window object that previously received mouse input.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also

COleControl::GetCapture, COleControl::ReleaseCapture
