Derived View Classes

The following table shows the view classes that MFC for Windows CE 3.0 supports, along with their relationships to one another. The capabilities of your view class depend on the MFC view class from which it derives. To use these classes in your application, derive the application's view classes from them.

MFC for Windows CE 3.0 does not support CRichEditView, CHtmlView, CRecordView, CDaoRecordView. or COleDBRecordView.

View Classes

Class Description
CView Base class of all views.
CCtrlView Base class of CTreeView, CListView, and CEditView. These classes let you use document/view architecture with the indicated Windows common controls.
CEditView A simple view based on the Windows edit box control. Allows entering and editing text and can be used as the basis for a simple text editor application.
CListView A view containing a CListCtrl object.
CTreeView A view containing a CTreeCtrl object, for views that resemble the Workspace window in embedded Visual C++.
CScrollView Base class of CFormView. Implements scrolling the view's contents.
CFormView A form view, a view that contains controls. A forms-based application provides one or more such form interfaces, as do the AppWizards.
