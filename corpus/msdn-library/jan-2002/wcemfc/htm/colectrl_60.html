COleControl::GetNotSupported

This method is called in place of the Get method of any property where retrieval of the property by the control user is not supported, for example, a property that is write-only.

void GetNotSupported( );

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
