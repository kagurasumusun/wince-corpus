CCeDBRecord::DeleteProp

This method deletes a property from the record.

void DeleteProp(
WORD wPropIdent );

Parameters

wPropIdent
Specifies the application-defined identifier of the property to delete.

Return Values

None.

Remarks

DeleteProp releases the pointer to a property stored in the internal list of the CCeDBRecord object and frees its member strings and CEBLOB structure. The internal list of the record only contains pointers to properties that are created by calling ReadCurrRecord. If the property has been added using the AddProp or AddProps method, DeleteProp does not free its memory.

In a Windows CE object store database, you can delete a property on which a sort order is defined without any adverse effects. By default, when a database is opened with an active sort property, records that do not contain the corresponding property are placed last in the sort order. If the sort property is defined in CCeDBDatabase::Create or CCeDBDatabase::SetSortProps with the flag Sort_UnknownFirst, the records are placed first.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
