COleControl::ExchangeVersion

This method serializes or initializes the state of the version information of a control. Typically, this will be the first method called by a control override of COleControl::DoPropExchange. When loading, this method reads the version number of the persistent data, and sets the version attribute of the CPropExchange object accordingly. When saving, this method writes the version number of the persistent data.

BOOL ExchangeVersion(
CPropExchange* pPX,
DWORD dwVersionDefault,
BOOL bConvert = TRUE );

Parameters

pPX
Specifies a pointer to a CPropExchange object. The framework supplies this object to establish the context of the property exchange, including its direction.
dwVersionDefault
Specifies the current version number of the control.
bConvert
Indicates whether persistent data should be converted to the latest format when saved, or maintained in the same format that was loaded.

Return Value

Nonzero of the function succeeded; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
