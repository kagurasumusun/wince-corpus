CFontHolder::SetFont

This method releases any existing font and connects the CFontHolder object to an IFont interface.

void SetFont(
LPFONT pNewFont );

Parameters

pNewFont
Specifies the pointer to the new IFont interface.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
