Property Sheets

The CPropertySheet class in MFC for Windows CE is the same as it is in the standard MFC library, with the following two exceptions:

  • Windows CE does not support property sheet wizards.
  • You cannot place an icon in the caption of a property sheet.

For information about where the CPropertySheet class fits into the Windows CE class hierarchy, see Window Class Categories and Classes Derived from CObject.
