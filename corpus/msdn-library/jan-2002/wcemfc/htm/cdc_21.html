CDC::ExcludeClipRect

This method creates a new clipping region that consists of the existing clipping region minus the specified rectangle. 

int ExcludeClipRect(
int x1,
int y1,
int x2,
int y2 );

virtual int ExcludeClipRect(
LPCRECT lpRect );

Parameters

x1
The logical x-coordinate of the upper-left corner of the rectangle.
y1
The logical y-coordinate of the upper-left corner of the rectangle.
x2
The logical x-coordinate of the lower-right corner of the rectangle.
y2
The logical y-coordinate of the lower-right corner of the rectangle.
lpRect
The rectangle. Can also be a CRect object.

Return Value

The type of the new clipping region. It can be any of the following values:

COMPLEXREGION
The region has overlapping borders.
ERROR
No region was created.
NULLREGION
The region is empty.
SIMPLEREGION
The region has no overlapping borders.

Remarks

The width of the rectangle, specified by the absolute value of x2 – x1, must not exceed 32,767 units. This limit applies to the height of the rectangle as well.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
