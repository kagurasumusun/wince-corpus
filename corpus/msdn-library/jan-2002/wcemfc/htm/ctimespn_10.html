CTimeSpan::GetTotalSeconds

This method retrieves the total number of complete seconds in this CTimeSpan object.

GetTotalSeconds will return a valid value if the object on which it operates was initialized with an amount of seconds that can be held in four bytes (+/-2,147,483,647). If your CTimeSpan object holds an eight-byte value, you should use GetTotalSeconds64 to return the number of seconds.

LONG GetTotalSeconds( )
const;

Example

// example for CTimeSpan::GetTotalHours, CTimeSpan::GetTotalMinutes
// and CTimeSpan::GetTotalSeconds
CTimeSpan ts( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ASSERT( ts.GetTotalHours() == 73 );
ASSERT( ts.GetTotalMinutes() == 4385 );
ASSERT( ts.GetTotalSeconds() == 263112 );
