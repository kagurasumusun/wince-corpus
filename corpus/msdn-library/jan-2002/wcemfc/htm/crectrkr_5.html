CRectTracker::DrawTrackerRect

This method is called by the framework whenever the position of the tracker has changed while inside the Track or TrackRubberBand method. The default implementation makes a call to CDC::DrawFocusRect, which draws a dotted rectangle.

Override this method to provide different feedback during the tracking operation.

virtual void DrawTrackerRect(
LPCRECT lpRect,
CWnd* pWndClipTo,
CDC* pDC,
CWnd* pWnd );

Parameters

lpRect
Specifies a pointer to the RECT that contains the rectangle to draw.
pWndClipTo
Specifies a pointer to the window to use in clipping the rectangle.
pDC
Specifies a pointer to the device context on which to draw.
pWnd
Specifies a pointer to the window on which the drawing will occur.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
