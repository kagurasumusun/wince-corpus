CTreeCtrl::SetItem

This method sets the attributes of the specified tree view item.

In the TVITEM structure, the hItem member identifies the item, and the mask member specifies which attributes to set.

If the mask member or the nMask parameter specifies the TVIF_TEXT value, the pszText member or the lpszItem is the address of a null-terminated string and the cchTextMax member is ignored. If mask (or nMask) specifies the TVIF_STATE value, the stateMask member or the nStateMask parameter specifies which item states to change and the state member or nState parameter contains the values for those states.

BOOL SetItem(
TV_ITEM* pItem );

BOOL SetItem(
HTREEITEM hItem,
UINT nMask,
LPCTSTR lpszItem,
int nImage,
int nSelectedImage,
UINT nState,
UINT nStateMask,
LPARAM lParam );

Parameters

pItem
Specifies a pointer to a TVITEM structure that contains the new item attributes.
hItem
Specifies the handle of the item whose attributes are to be set. See the hItem member of the TVITEM structure.
nMask
Specifies the integer specifying which attributes to set. See the mask member of the TVITEM structure.
lpszItem
Specifies the address of a string containing the text of the item.
nImage
Specifies the index of the image of the item in the image list of the tree view list. See the iImage member of the TVITEM structure.
nSelectedImage
Specifies the index of the selected image of the item in the image list of the tree view control. See the iSelectedImage member of the TVITEM structure.
nState
Specifies values for the states of the item. See the State member of the TVITEM structure.
nStateMask
Specifies which states are to be set. See the stateMask member of the TVITEM structure.
lParam
Specifies a 32-bit application-specific value associated with the item.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// The pointer to my tree control.
extern CTreeCtrl* pmyTreeCtrl;
// The point to hit test.
extern CPoint myPoint;

// Show the item at the point myPoint in bold.
UINT uFlags;
HTREEITEM hItem = pmyTreeCtrl->HitTest(myPoint, &uFlags);

if ((hItem != NULL) && (TVHT_ONITEM & uFlags))
{
  pmyTreeCtrl->SetItem(hItem, TVIF_STATE, NULL, 0, 0, TVIS_BOLD,
    TVIS_BOLD, 0);
}
