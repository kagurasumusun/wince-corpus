CAsyncSocket::GetPeerName

This method retrieves the address of the peer socket to which this socket is connected.

BOOL GetPeerName(
CString& rPeerAddress,
UINT& rPeerPort );

BOOL GetPeerName(
SOCKADDR* lpSockAddr,
int* lpSockAddrLen );

Parameters

rPeerAddress
Reference to a CString object that receives a dotted number IP address.
rPeerPort
Reference to a UINT that stores a port.
lpSockAddr
A pointer to the SOCKADDR structure that receives the name of the peer socket.
lpSockAddrLen
A pointer to the length of the address in lpSockAddr in bytes. On return, the lpSockAddrLen argument contains the actual size of lpSockAddr returned in bytes.

Return Value

Nonzero if the function is successful; otherwise, it is zero, and a specific error code can be retrieved by calling GetLastError. The following errors apply to this method:

WSANOTINITIALISED
A successful AfxSocketInit must occur before using this API.
WSAENETDOWN
The Windows CE Sockets implementation detected that the network subsystem failed.
WSAEFAULT
The lpSockAddrLen argument is not large enough.
WSAEINPROGRESS
A blocking Windows CE Sockets call is in progress.
WSAENOTCONN
The socket is not connected.
WSAENOTSOCK
The descriptor is not a socket.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxsock.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
