SYSTEMTIME Support for Date and Time

The CTime class has constructors that accept system and file times from Win32, using the SYSTEMTIME and FILETIME structures. If you use CTime objects for these purposes, you must modify their initialization accordingly, as described in this topic.

MFC for Windows CE still provides CTime constructors that take time arguments of the MS-DOS style.

The CTime constructors are:

  • CTime( const SYSTEMTIME& sysTime );
  • CTime( const FILETIME& fileTime );

The fileTime parameter is a reference to a Win32 FILETIME structure, which represents time as a 64-bit value, a more convenient format for internal storage than a SYSTEMTIME structure and the format used by Win32 to represent the time of file creation.

If your code contains a CTime object initialized with the system time, you should use the SYSTEMTIME constructor.

You most likely will not use CTime FILETIME initialization directly. If you use a CFile object to manipulate a file, CFile::GetStatus retrieves the file timestamp via a CTime object initialized with a FILETIME structure.
