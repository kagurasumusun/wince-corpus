CDC::ReleaseOutputDC

This method sets the m_hDC member to NULL.

virtual void ReleaseOutputDC( );

Remarks

This method cannot be called when the output device context is attached to the CDC object. Use the Detach method to detach the output device context.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
