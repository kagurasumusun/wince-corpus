CWnd::OnRenderAllFormats

The clipboard owner OnRenderAllFormats method is called by the framework when the owner application is being destroyed.

The Clipboard owner should render the data in all the formats it is capable of generating and pass a data handle for each format to the Clipboard by calling the SetClipboardData Windows CE function. This ensures that the Clipboard contains valid data even though the application that rendered the data is destroyed. The application should call the CWnd::OpenClipboard method before calling the SetClipboardData Windows CE function and call the CloseClipboard Windows CE function afterward.

afx_msg void OnRenderAllFormats( );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
