CPrintInfo::m_pPD

This data member contains a pointer to the CPrintDialog object used to display the Print dialog box for the print job. The m_pPD member is a public variable declared as a pointer to CPrintDialog.

CPrintDialog* m_pPD;

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
  Platform H/PC Pro
