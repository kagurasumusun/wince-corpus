CPalette::GetNearestPaletteIndex

This method returns the index of the entry in the logical palette that most closely matches the specified color value.

UINT GetNearestPaletteIndex(
COLORREF crColor)
const;

Parameters

crColor
Specifies the color to be matched.

Return Value

Returns the index of an entry in a logical palette. The entry contains the color that most nearly matches the specified color.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
