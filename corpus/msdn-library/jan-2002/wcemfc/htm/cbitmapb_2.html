CBitmapButton::CBitmapButton

This constructor creates an instance of a CBitmapButton object. 

CBitmapButton( );

Remarks

After creating the CBitmapButton object, call CButton::Create to create the Windows button control and attach it to the CBitmapButton object.

Example

// Declare a bitmap button object on the stack.
CBitmapButton myButton;

// Declare a bitmap button object on the heap.
CBitmapButton* pmyButton = new CBitmapButton;

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also

CBitmapButton::LoadBitmaps, CBitmapButton::AutoLoad, CBitmapButton::SizeToContent, CButton::Create
