CImageList::DeleteTempMap

This method deletes any temporary CImageList objects created by CImageList::FromHandle, but does not destroy any handles, such as hImageList, which may be temporarily associated with the ImageList objects.

static void PASCAL DeleteTempMap( );

Remarks

The CImageList::DeleteTempMap function is automatically called by the CwinApp idle-time handler.

Example

// The following example is correct:
CImageList::DeleteTempMap();

// The following example is incorrect:
// DeleteTempMap() is a static member and cannot be called
// within the scope of an instantiated CImageList object.
PImageList->DeleteTempMap();  // Causes compiler error

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
