CWnd::HideCaret

This method hides the caret by removing it from the display screen. 

void HideCaret( );

Remarks

Although the caret is no longer visible, it can be displayed again by using the CWnd::ShowCaret method. Hiding the caret does not destroy its current shape.

Hiding is cumulative. If HideCaret has been called five times in a row, the ShowCaret method must be called five times before the caret will be shown.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
