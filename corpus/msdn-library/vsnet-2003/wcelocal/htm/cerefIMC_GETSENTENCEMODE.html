IMC_GETSENTENCEMODE

This message is sent by an application to an input method editor (IME) window to obtain current sentence mode.

msg = (UINT) WM_IME_CONTROL;
wParam = (WPARAM) IMC_GETSENTENCEMODE;
lParam = 0;

Parameters

lParam
Not used.

Return Values

Returns a combination of IME sentence mode values.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Imm.h Imm.h
