IImeIPointNotifySink

This interface is a callback interface implemented by the IME user interface (UI) component. The IME conversion service calls the methods of this interface to notify the UI of composition buffer changes and to request action and information from the IME UI.

The following table shows the methods in VTable order.

IUnknown method Description
IUnknown::QueryInterface Returns pointers to supported interfaces.
IUnknown::AddRef Increments the reference count.
IUnknown::Release Decrements the reference count.
IImeIPointNotifySink method Description
IImeIPointNotifySink::SetCursorPos Receives information about the position of the insertion point in the composition string.
IImeIPointNotifySink::SetResultStr Receives information about the string of the composition result.
IImeIPointNotifySink::IsReadingHalfKana Specifies whether the IME UI expects the half-width character in the reading string.
IImeIPointNotifySink::SetResultReadStr Receives information about the reading string of the composition result.
IImeIPointNotifySink::SetCompositionReadStr Receives information about the reading string of the current composition.
IImeIPointNotifySink::SetCompositionStr Receives information about the current composition string.
IImeIPointNotifySink::SetResultClause Receives the clause information of the result string.
IImeIPointNotifySink::SetResultReadClause Receives the clause information of the reading string of the composition result.
IImeIPointNotifySink::SetCompositionReadClause Receives the clause information of the reading string of the current composition.
IImeIPointNotifySink::SetCompositionClause Receives the clause information of the current composition string.
IImeIPointNotifySink::SetCompositionReadAttr Receives the attribute information of the reading string of the current composition.
IImeIPointNotifySink::SetCompositionAttr Receives the attribute information of the current composition string.
IImeIPointNotifySink::SetTargetClause Receives information about the target clause.
IImeIPointNotifySink::SetCandidateStr Receives information about the candidate list.
IImeIPointNotifySink::SetCandidateSelection Receives information about the current candidate selection.
IImeIPointNotifySink::SetDeltaPos Receives information about the starting position of any changes in the composition string.
IImeIPointNotifySink::GenerateMessage Implemented to be notified of the composition buffer updates.
