IMEWRD

This structure contains information about the user-defined word in the user dictionary.

typedef struct _IMEWRD {
  WCHAR *pwchReading;
  WCHAR *pwchDisplay;
  Union { 
      ULONG ulPos;
      Struct {
          WORD nPos1; 
          WORD nPos2; 
      };
  };
  ULONG *rgulAttrs[2];
  INT cbComment;
  IMEUCT uct;
  VOID *pvComment;
} IMEWRD, *PIMEWRD;

Members

pwchReading
Specifies the string that contains the reading string of the word in Unicode.
pwchDisplay
Specifies the string that contains the word in Unicode.
ulPos
Specifies the part-of-speech number.
nPos1
Reserved. Use the ulPos member instead.
nPos2
Reserved. Use the ulPos member instead.
rgulAttrs[2]
Set the value to NULL. Ignored.
cbComment
Set the value to 0. Ignored.
uct
Set the value to 0. Ignored.
pvComment
Set the value to NULL. Ignored.
