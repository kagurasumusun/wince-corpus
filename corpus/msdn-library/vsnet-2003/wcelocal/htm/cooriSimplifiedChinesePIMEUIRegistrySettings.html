Simplified Chinese PIME UI Registry Settings

The Simplified Chinese Pocket IME allows you to supply a customized UI module. To use a custom UI module on your platform, you need to update the UI Module registry subkey under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Layouts for your IME.

Shuang Pin

The following table shows the UI module entry for the HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Layouts\e0010804 registry key. The e0010804 subkey is the keyboard layout value assigned to the Shuang Pin IME.

Registry key Type Default value Description
UI Module REG_SZ Msimeuic.dll The DLL name for the UI module.

Pinyin

The following table shows the UI module entry for the HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Layouts\e0020804 registry key. The e0020804 subkey is the keyboard layout value assigned to the Pinyin IME.

Registry key Type Default value Description
UI Module REG_SZ Msimeuic.dll The DLL name for the UI module.
