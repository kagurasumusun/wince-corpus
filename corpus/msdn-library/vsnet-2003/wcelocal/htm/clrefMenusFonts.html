Menus and Fonts

Font linking solves part of the rendering problems that occur with menus that result from a UI switch. You can flag each application that supports UI switching, and have the OS check for this flag when applying fonts.

The following sample shows how to set the registry values to control menus under these circumstances.

HKEY_LOCAL_MACHINE\SYSTEM\GWE\Menu\PopFnt\<locale>
    lfHeight = "Ht"
    lfWeight = "Wt"
    lfCharSet  = "CS"
    lfItalic  = "It"
    lfFaceName = "Nm"
HKEY_LOCAL_MACHINE\SYSTEM\GWE\Menu\PopFnt\<locale>
    lfHeight = "Ht"
    lfWeight = "Wt"
    lfCharSet  = "CS"
    lfItalic  = "It"
    lfFaceName = "Nm"
