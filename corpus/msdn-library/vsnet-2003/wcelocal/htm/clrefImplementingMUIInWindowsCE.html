Implementing an MUI

To achieve the goal of end user-switchable language in a specific device, several things have to be coordinated. The following list shows the coordination requirements.

  • The device must have the locale data, code pages, and fonts for all the UI languages to be supported. These are configured when the device ROM image is created or can be added later.
  • The operating system UI resources, such as the localized resources for the default language, must be set in ROM. Additional languages can be included in the device ROM image, or potentially installed later.
  • The application developer must provide the UI resources for applications on the device for all the supported languages on the device.

Applications that do not follow the correct procedures will display in the wrong language when an end user switches a device's UI language, and will provide an inferior end user experience.
