ImmLockIMCC

This function enables an input method editor (IME) to get a pointer to an input method context (IMC) component that can be a member of the IMC. 

LPVOID WINAPI ImmLockIMCC( 
HIMCC hIMCC
);

Parameters

hIMCC
[in] Handle to IMC component

Return Values

Pointer to the IMC component indicates success. NULL indicates failure.

Remarks

Windows CE does not use the lock count.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Imm.h Imm.h Coreimm.lib
