Special Locale Considerations

The system default locale selects certain aspects of the system that may not be fully switchable later. Because of this, it may not be possible to build an MUI that switches between certain languages, particularly between multiple East Asian languages, such as between Chinese, Japanese, and Korean. Typically, platform developers build devices that switch between related languages that share a single code page, such as the 1252 code page that is shared by most western European languages.

In addition, locale content that is set in the registry is not switchable. The values are set when the device boots, and are fixed afterward. This implies that folders such as My Documents and Favorites will not switch to the new UI, nor will registry-set display strings such as "My Computer".
