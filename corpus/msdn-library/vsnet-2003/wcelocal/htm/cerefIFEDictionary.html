IFEDictionary

This interface supports the creation of a user dictionary. Windows CE .NET supports this interface for Pocket IME only.

The IFEDictionary interface includes the following methods.

IUnknown method Description
IUnknown::QueryInterface Returns pointers to supported interfaces.
IUnknown::AddRef Increments the reference counts.
IUnknown::Release Decrements the reference count.
IFEDictionary method Description
IFEDictionary::Open Opens a specific user dictionary.
IFEDictionary::Close Closes the user dictionary.
IFEDictionary::GetHeader Obtains the dictionary header from the dictionary file.
IFEDictionary::DisplayProperty Not supported.
IFEDictionary::SetHeader Not supported.
IFEDictionary::Create Creates a user dictionary in Pocket IME format.
IFEDictionary::GetPosTable Obtains the public part-of-speech (POS) table.
IFEDictionary::GetWords Obtains word entries from a dictionary.
IFEDictionary::NextWords Obtains the next word entries from the dictionary.
IFEDictionary::ExistWord Checks whether a specific word exists in the dictionary.
IFEDictionary::Reserved1 Reserved.
IFEDictionary::RegisterWord Registers a word in the dictionary.

Remarks

To create an instance of the IFEDictionary class, call the CreateIFEDictionaryInstance function instead of the CoCreateInstance function, which is provided by the standard Component Object Model (COM) library.
