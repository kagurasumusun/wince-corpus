IFEDictionary::GetHeader

This method obtains the dictionary header from a dictionary file.

HRESULT IFEDictionary::GetHeader(
CHAR *pchFileName,
IMESHF *pShf,
IMEFMT *pjfmt,
ULONG *pdicat
);

Parameters

pchFileName
[in] Specifies the pointer to the path to the dictionary file.
pShf
[out] Specifies the pointer to an IMESHF structure that receives the header information of the dictionary.
pjfmt
[out] Specifies the pointer to an IMEFMT variable that receives information about the dictionary format.

The following table lists valid dictionary format.

IME type Description
IFED_UNKNOWN Dictionary type is unknown.
IFED_PIME2_BIN_USER Dictionary is user type.
IFED_PIME2_BIN_SYSTEM Dictionary is compact type.
IFED_PIME2_BIN_STANDARD_SYSTEM Dictionary is standard type.
pdicat
[out] Specifies the pointer to a ULONG variable that receives information about the type of the dictionary.

The following table provides a list of valid dictionary types.

Dictionary type Description
dicatNone Dictionary type undefined
dicatGeneral General dictionary

Return Values

This method has the following return values.

Return value Description
S_OK Dictionary header successfully obtained.
IFED_E_INVALID_FORMAT Invalid file format.
E_FAIL An unexpected error has occurred.
