ImmSetOpenStatus

This function opens or closes the IME.

BOOL ImmSetOpenStatus(
HIMC hIMC, 
BOOL fOpen
);

Parameters

hIMC
[in] Handle to the input context. For Microsoft® Windows® CE versions 2.10 and later, if hIMC is NULL, then the open status for the current active context is returned.
fOpen
[in] Open flag. If TRUE, the IME is opened; otherwise, it is closed.

Return Values

Nonzero indicates success. Zero indicates failure.

Remarks

This function causes a IMN_SETOPENSTATUS message to be sent to the application.

Requirements

Windows CE OS .NET 4.0 and later Imm.h Imm.h Coreimm.lib
