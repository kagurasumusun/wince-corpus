SetUserDefaultUILanguage

The SetUserDefaultUILanguage function sets the LANGID for the current user's UI language selection.

BOOL SetUserDefaultUILanguage(
LANGID langid
);

Parameters

langid
The language identifier (LANGID) to set for the user's default UI language.

Return Values

Returns TRUE if success, FALSE otherwise.

Remarks

The new LANGID will not take effect until the device is reset.

For more information about language identifiers, see Language Identifiers and Locales.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Winnls.h Windows.h Coreloc.lib
