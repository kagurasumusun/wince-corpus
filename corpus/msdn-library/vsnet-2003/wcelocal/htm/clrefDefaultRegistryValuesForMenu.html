Default Registry Values for Menu

The font used in a Microsoft® Windows® CE .NET menu can be based on hard coded values or based on registry values. The default hard coded font values are as follows.

lfHeight = 13;
lfWidth = 0;
lfEscapement = 0;
lfOrientation = 0;
lfWeight = FW_BOLD for Bar menus and FW_NORMAL for Popup menus
lfItalic = FALSE;
lfUnderline = FALSE;
lfStrikeOut = FALSE;
lfCharSet = ANSI_CHARSET;
lfOutPrecision = OUT_DEFAULT_PRECIS;
lfClipPrecision = CLIP_DEFAULT_PRECIS;
lfQuality = DEFAULT_QUALITY;
lfPitchAndFamily = DEFAULT_PITCH | FF_SWISS;
lfFaceName = "MS Sans Serif"

Bar Menu Settings

The registry settings that control the system bar menu are as follows.

HKEY_LOCAL_MACHINE\SYSTEM\GWE\Menu\BarFnt
    lfHeight = "Ht"
    lfWeight = "Wt"
    lfCharSet  = "CS"
    lfItalic  = "It"
    lfFaceName = "Nm"

Pop-up Menu Settings

The registry settings that control the system pop-up menu are:

HKEY_LOCAL_MACHINE\SYSTEM\GWE\Menu\PopFnt
    lfHeight = "Ht"
    lfWeight = "Wt"
    lfCharSet  = "CS"
    lfItalic  = "It"
    lfFaceName = "Nm"
