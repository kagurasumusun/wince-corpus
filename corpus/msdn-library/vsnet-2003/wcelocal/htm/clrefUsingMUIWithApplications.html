Using the MUI With Applications

To enable your applications to change the UI language, you implement satellite MUI Resource DLLs. In this method, each supported language has its resources in a separate DLL.

Each DLL uses the same resource identifiers, but the resources themselves and their related binaries are localized. The name of each DLL indicates the language (locale) of its resources.

Note   The localizable resources for the system-default language remain in the core executable.

Because the language detection APIs and registry keys return the UI language Locale Identifiers, it is logical to name satellite DLLs correspondingly. For example, instead of naming files res_eng.dll or res_en.dll for English, use res409.dll.
