IFEDictionary::GetPosTable

This method obtains the public part-of-speech table. 

HRESULT IFEDictionary::GetPosTable(
POSTBL **prgPosTbl,
int *pcPosTbl
);

Parameters

prgPosTbl
[out] Specifies the address of the pointer to an array of POSTBL structures.
pcPosTbl
[out] Specifies the pointer to an INT variable that receives the count of the part-of-speech tables in POSTBL. This parameter can be NULL.

Return Values

This method returns the pointer to the array of POSTBL structures that reside in the IME conversion kernel module. You do not need to free the buffer when you finish using the object.

This method has the following return values.

Return value Description
S_OK Part of speech table successfully obtained.
E_FAIL An unexpected error has occurred.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Msime.h Msime.h
