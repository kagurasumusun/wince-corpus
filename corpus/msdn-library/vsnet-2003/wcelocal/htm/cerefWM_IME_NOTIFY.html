WM_IME_NOTIFY

This message is sent to an application to notify it of changes to the IME window. An application processes this message if it is responsible for managing the IME window.

WM_IME_NOTIFY
dwCommand = (DWORD) wParam;
dwData = (DWORD) lParam;

Parameters

dwCommand
Specifies one of the following command values:
IMN_CHANGECANDIDATE IMN_SETCOMPOSITIONFONT
IMN_CLOSECANDIDATE IMN_SETCOMPOSITIONWINDOW
IMN_CLOSESTATUSWINDOW IMN_SETCONVERSIONMODE
IMN_GUIDELINE IMN_SETOPENSTATUS
IMN_OPENCANDIDATE IMN_SETSENTENCEMODE
IMN_OPENSTATUSWINDOW IMN_SETSTATUSWINDOWPOS
IMN_SETCANDIDATEPOS  
dwData
Specifies a command-specific value.

Return Values

Returns a command-specific value.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Imm.h Imm.h
