KatoDebug

This function enables or disables the ability to route log to the local debugger.

BOOL KatoDebug(
BOOL fEnabled, 
DWORD dwMaxLogVerbosity, 
DWORD dwMaxCommentVerbosity,
DWORD dwMaxLevel 
);

Parameters

fEnabled
TRUE enables debug logging; FALSE disables debug logging.
dwMaxLogVerbosity
Specifies the maximum log verbosity value that can be sent to debug logging.
dwMaxCommentVerbosity
Specifies the maximum comment verbosity value that can be sent to debug logging.
dwMaxLevel
Specifies the maximum log hierarchical level that can be sent to debug logging.

Return Values

Nonzero if successful; otherwise, 0.

Remarks

This function allows the log output to be routed to the current active debugger. This functionality may be useful when debugging an application and you want to see your log output intermixed with other application debug output.
