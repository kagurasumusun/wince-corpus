Tux Test Harness

The Tux test harness (Tux) is a 32-bit client/server test harness that executes test modules stored in dynamic-link library (.dll) files. Tux groups tests, maintains statistics, and provides a user interface (UI). With Tux, you can write clean, short, and platform-independent test cases without the overhead required to write a complete application.

You can administer and execute tests on both a local and remote development workstation because Tux is a client/server application. The Tux client can run in stand-alone mode with no server required, which allows you to execute test cases and test scripts from the command line. You can also control multiple clients simultaneously with a single Tux server.
