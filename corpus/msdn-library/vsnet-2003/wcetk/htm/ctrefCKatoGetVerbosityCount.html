CKato::GetVerbosityCount

This function queries the number of times a given verbosity has been logged in a given level.

INT GetVerbosityCount(
DWORD dwVerbosity, 
DWORD dwLevel 
);

Parameters

dwVerbosity
Specifies the verbosity level you want to query. This value can range from 0 to KATO_MAX_VERBOSITY.
dwLevel
Specifies the level in which to perform the query. You may query any level from the root level (0) down to the logger's current level. A value of -1 performs the query at the logger's current level.

Return Values

The number of times the given verbosity has been logged in the given level. If dwLevel is greater than the current logging level, the return value is 0. If an error occurs, the return value is -1.

Remarks

GetVerbosityCount is usually called by applications that need to keep statistics about the number of times a particular verbosity is logged. Usually particular verbosity values are associated with concepts such as pass and fail. If you structure your log in this manner, you can use GetVerbosityCount to query the number of passes and failures that have occurred within a given level.
