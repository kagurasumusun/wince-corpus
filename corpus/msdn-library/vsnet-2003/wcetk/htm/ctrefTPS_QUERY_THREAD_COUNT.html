TPS_QUERY_THREAD_COUNT

This structure indicates the number of threads and is filled in by the TestProc function.

DWORD dwThreadCount;
} TPS_QUERY_THREAD_COUNT, *LPTPS_QUERY_THREAD_COUNT;
