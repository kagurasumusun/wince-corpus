KatoSetItemData

This function associates a 32-bit application-specific value with a CKato object. This value can later be retrieved by KatoGetItemData.

BOOL KatoSetItemData(
HKATO hKato, 
DWORD dwItemData 
);

Parameters

hKato
Handle to a CKato object.
dwItemData
A 32-bit value to be associated with the CKato object.

Return Values

Nonzero if successful; otherwise, 0.

Remarks

KatoSetItemData and KatoGetItemData allow applications to associate application-specific data to a CKato object. This could be a single value, a pointer to some structure of data, a next pointer for a linked list, and so on.
