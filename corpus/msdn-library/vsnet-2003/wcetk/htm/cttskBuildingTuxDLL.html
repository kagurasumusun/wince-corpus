Building a Tux DLL with Platform Builder

A Tux DLL is a module that defines the characteristics of a test for the CETK. For information about functions, messages, and structures that you can include in a Tux DLL, see Tux Test Module Reference.

You can build a Tux DLL using Platform Builder. You can also build a Tux DLL from the command line. For information about building a Tux DLL from the command line, see Building a Tux DLL From the Command Line.

To build a Tux DLL using Platform Builder, you must first prepare a platform in which to create a project for the Tux DLL.

To prepare a platform for the Tux DLL

  1. From the File menu, choose New Platform, and then create a new platform with the New Platform Wizard.
    Note   In creating your platform, do not choose the Tiny Kernel configuration. You cannot run the CETK on a platform built from the Tiny Kernel configuration, because the client software for the CETK cannot detect the OS image for the platform.
  2. From the Build menu, choose Build Platform.

After preparing a platform, you can create a project for the Tux DLL.

To create a project for the Tux DLL

  1. From the File menu, choose New Project or File.
  2. Choose the Projects tab, and then select WCE Dynamic-Link Library.
  3. In the Project name box, type a name for the project.

    For example, in the Project name box, type TuxDll.

  4. Choose OK.
  5. Choose An empty project, and then choose Finish.

After creating a project, you can copy files that define a framework for the Tux DLL to the directory for your project. For more information about the framework, see Implementing a Tux Test Suite with TuxSkel.

To add the files for the Tux DLL to the project

  1. Copy all files from the %_WINCEROOT%\Others\Wcetk\Tux\Tuxskel directory to the directory for the project.

    In this example, copy the files from the %_WINCEROOT%\Others\Wcetk\Tux\Tuxskel directory to the %_WINCEROOT%\Public\Platform\TuxDll directory.

  2. From the Project menu in Platform Builder, choose Insert, and then choose Files.
  3. In the Files of type box, choose All Files (*.*).
  4. Browse to the directory for the project, and then select all of the files that you copied.

    In this example, browse to the %_WINCEROOT%\Public\Platform\TuxDll directory and then select the files that you copied.

  5. Choose OK.

After adding the files for the Tux DLL to the project, you can link the project to the Kato Logging Engine (Kato). For more information about Kato, see Kato Logging Engine.

To link the project to Kato

  1. From the Project menu, choose Settings.
  2. In the Settings For box, choose All Configurations.
  3. Choose the Link tab.
  4. In the Object/library modules box, type kato.lib at the end of the existing value.
  5. Choose OK.

After linking the project to Kato, you can specify the header and library files to use. You can use the header and library files that are provided with Tux.

To select the directories for header and library files

  1. From the Tools menu, choose Options.
  2. Choose the Directories tab.
  3. Add the %_WINCEROOT%\Others\Wcetk\Tux\Inc directory to the Directories list.
  4. Add the %_WINCEROOT%\Others\Wcetk\Tux\Lib\CPU\Retail directory to the Directories list.
  5. Choose OK.

Finally, you can use Platform Builder to build the Tux DLL.

To build the Tux DLL

  • From the Build menu, choose Build <Project name>.dll.

    In this example, choose Build TuxDll.dll.
