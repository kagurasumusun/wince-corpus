ShellProc Structures

The following table shows the structures that are used by the ShellProc function and its messages.

Structure Description
SPS_LOAD_DLL Pointed to by the spParam parameter for the ShellProc function. This structure can be used to query the Tux DLL for build information.
SPS_SHELL_INFO Pointed to by the spParam parameter for the ShellProc function. This structure can be used to pass information about the Tux shell to the Tux DLL.
SPS_REGISTER Stores a pointer to the Tux DLL function table.
SPS_BEGIN_TEST Contains the function table entry and other information for the next test to execute.
SPS_END_TEST Contains the function table entry and other information for the test that previously executed.
SPS_EXCEPTION Contains information about the exception that was generated.
