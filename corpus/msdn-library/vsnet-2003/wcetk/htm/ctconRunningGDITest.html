Running the Graphics Device Interface Test

The GDI Test executes the tux –o –d gdiapi.dll command line on default execution. The test compares the display output to the output of a GPE–based display driver. If the output of the display driver does not match the output rendered by the GPE–based display driver, the test lists the coordinates and pixel values that do not match. To view the output of a GPE–based display driver, boot a target device with the flat display driver and then run the test.

You can modify the GDI Test by running test cases 10, 11, 20, 21, 60, 61, 62, or 63. These test cases configure any test case that runs after. The default configuration runs the GDI tests with automatic verification of test results by running the 11, 21, 63, and 100-1302 test cases. To run the GDI Test with manual verification, you can use the tux –o –d gdiapi.dll –x 1,10,20,63,100-1302 command line.

The following table shows the test cases for the GDI Test.

Test case Description
1: Display Configuration List information relevant to the configuration of the display, such as resolution and color depth.
10: Manual verification Configures the test to allow you to manually verify that the results of the test are correct.
11: Automatic verification Configures the test to automatically verify that the results of the test are correct.
20: Disable Ddi_test.dll Configures the test to not use Ddi_test.dll to verify that the results of the test are correct.
21: Enable Ddi_test.dll Configures the test to use Ddi_test.dll to verify that the results of the test are correct.
60: Primary DC Configures the test to use the primary device context (DC).
61: Memory DC Configures the test to use the memory DC.
62: Default DC Configures the test to use the default DC.
63: Window DC Configures the test to use the window DC.
100-104: Clip Tests the functionality of clipping using different shapes.
200-219: Draw Draws basic shapes including rectangles, triangles, circles and ellipses. This test case also creates a variety of bitmap images.
600-607: Brush and pen Paints on the display using a variety of sizes and types of pens and brushes.
800-805: Device context Creates, retrieves, saves, and restores a device context.
900-905: Device objects Verifies device objects.
1100-1108, 1200-1203, 1300-1302: Text Writes text to a variety of locations on the display. This test does not run if the font required by the test is not available.

Remarks

This test library can have one or more optional command-line entries to change the behavior of the test. To specify one or more optional command-line entries to the test library, you must use the –c command-line option. This option forces Tux to pass the specified string into the test library.
