TestProc Messages

The following table shows the TestProc messages for Tux.

Message Description
TPM_EXECUTE Sent to the TestProc function each time Tux asks the function to execute its test code.
TPM_QUERY_THREAD_COUNT Sent once to the TestProc function to query the default number of threads that need to be created to execute the test.
