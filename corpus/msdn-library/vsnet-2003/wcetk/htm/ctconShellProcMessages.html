ShellProc Messages

The following table shows the ShellProc messages for Tux.

Message Description
SPM_LOAD_DLL Sent once to the DLL immediately after the DLL loads.
SPM_UNLOAD_DLL Sent once to the DLL immediately before the DLL unloads.
SPM_SHELL_INFO Sent once to the DLL immediately following the SPM_LOAD_DLL message to give the DLL information about Tux.
SPM_REGISTER Sent once to the DLL immediately following the SPM_SHELL_INFO message to query the DLL for its function table.
SPM_START_SCRIPT Sent to the DLL immediately before a script starts. This message is sent to all loaded DLLs, including loaded DLLs that are not in the script.
SPM_STOP_SCRIPT Sent to the DLL after the script stops. This message is sent when the script reaches its end or when you stop the script.
SPM_BEGIN_GROUP Sent to the DLL before a single test or group of tests from that DLL executes.
SPM_END_GROUP Sent to the DLL after a group of tests from that DLL finishes running. This message gives the DLL time to clean up after it runs.
SPM_BEGIN_TEST Sent to the DLL immediately before a single test executes.
SPM_END_TEST Sent to the DLL after a single test case from the DLL executes.
SPM_EXCEPTION Sent to the DLL whenever code execution in the DLL causes an exception fault.
