Windows CE .NET Test Kit

The Microsoft® Windows® CE .NET Test Kit (CETK) is a tool that you can use to test device drivers for the Windows CE operating system (OS). The CETK incorporates command-line tests into a graphical user interface (GUI) that you can use to test drivers that you develop for the Windows CE OS. The test tools in the CETK provide feedback on the functionality of your drivers. The binaries for the CETK are verified to support the CPUs and hardware reference platforms that Windows CE supports.

The CETK also allows you to run a custom test through the use of a User-Defined Test Wizard. The wizard leads you through the process of running a custom test on your Windows CE-based device.

The CETK uses the Tux test harness, Kato logging engine, device driver loader, and Tux extender technologies to create and run test cases. For more information, see Tux Test Harness, Kato Logging Engine, and Device Driver Loader and Tux Extender.

Note   You can install source files for the tests that ship with the CETK. The source files are provided to assist you in debugging your device drivers and to assist you in creating custom tests for the CETK. Some of the source files that are provided do not build. Source files for certain tests are not provided.
To install the source files, run Setup.exe from the Cetksource directory. If you install Microsoft Platform Builder from DVD, you can find the Cetksource directory in the root directory of the DVD. If you install Platform Builder from CD, you can find the Cetksource directory in the root directory of the sixth CD.
