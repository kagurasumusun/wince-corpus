General Troubleshooting

DDLX has the following limitations.

  • The command line supports a maximum of 16 arguments and 128 characters.
  • Of all the required entry points that must be present in a DLL for an installable device driver, only the Gen_IOControl function is implemented in the Drvioctl.cpp file. There are placeholders in the Drvioctl.cpp file for all required entry points, but the placeholders return only a passing value if they are called. You can implement these features as needed.
