Editing the Command Line for a Test

You can edit the command line for a test to modify the behavior of the test. See the documentation for each of the CETK Tests for information about the command-line options for each test.

To edit the command line for a test

  1. In the CETK window, right-click the test for which you want to modify the command line, and then choose Edit Command Line.
  2. In the Command line for this test box, add any options that the test supports to the command line.
  3. Choose Temporary and applies only to this device to temporarily apply the change only to the target device with which you are working.

    - or -

    Choose Permanent and applies to all devices to permanently apply the change to all instances of the test in the CETK window.

  4. Choose OK.
    Note   The CETK tool automatically appends the parameter -f <logfile> entry to the command line when a test runs. This command-line entry stores the results of the test in a log file. You should not add your own –f switch to the command line.

If you decide that you want to undo the changes that you made to the command line for a test, you can revert to the default command line for the test.

To revert to the default command line for a test

  1. In the CETK window, right-click the test for which you want to revert the command line to the default command line, and then choose Edit Command Line.
  2. Choose Restore.
  3. Choose OK.
