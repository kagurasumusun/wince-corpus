IMsRdpClient Property Methods

This interface gets or sets the properties of the Remote Desktop ActiveX control described in the following table. This interface was added for RDP 5.1 clients.

Property Description
AdvancedSettings2 Retrieves a pointer to the IMsRdpClientAdvancedSettings interface. The interface sets advanced settings for the client control.

For more information, see IMsTscAdvancedSettings interface.
ColorDepth The color depth for the control's connection. Values include 8, 15, 16 and 24 bits per pixel.
ExtendedDisconnectReason Extended information about the control's reason for disconnection.

For more information, see IMsRdpClient::get_ExtendedDisconnectReason.
SecuredSettings2 Retrieves a pointer to the IMsRdpClientSecuredSettings interface. The interface sets secured settings for the client control.

For more information, see IMsTscSecuredSettings interface.

Remarks

These properties cannot be set when the control is connected, unless otherwise indicated.

See Also

IMsRdpClientSecuredSettings, IMsTscSecuredSettings
