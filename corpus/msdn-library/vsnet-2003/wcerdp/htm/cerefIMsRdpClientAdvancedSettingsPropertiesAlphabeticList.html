IMsRdpClientAdvancedSettings Properties

Following is a list of the properties you can set and retrieve using the property methods of the IMsRdpClientAdvancedSettings interface. Unless otherwise indicated, access is read/write. This interface was added for RDP 5.1 clients.

For a description of each property, information about its syntax, and a functional grouping of the properties, see IMsRdpClientAdvancedSettings Property Methods.

IMsRdpClientAdvancedSettings derives from the IMsTscAdvancedSettings interface. For additional properties, see the IMsTscAdvancedSettings interface.
