IMsTscAx::put_UserName

This method sets the value of the UserName property, which specifies the user name logon credential.

HRESULT put_UserName(
BSTR userName
);

Parameters

userName
[in] The string value UserName is to be set to.

Return Values

Value Description
S_OK Virtual channel was correctly created.
nonzero error code An error occurred.

Remarks

Setting UserName is optional. If it is not set, the user can choose a username when the Windows Logon dialog box appears during the connection.

UserName can be set only if the control is not in the connected state. The method returns E_FAIL if it is called after the control is connected. You can check if the control is connected by calling IMsTscAx::get_Connected.
