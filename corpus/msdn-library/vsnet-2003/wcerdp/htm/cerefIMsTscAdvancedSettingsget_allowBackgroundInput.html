IMsTscAdvancedSettings::get_allowBackgroundInput

This method retrieves the value of the allowBackgroundInput property, which determines whether or not background input mode is enabled. When background input is enabled the client can accept input when the client does not have focus.

HRESULT get_allowBackgroundInput(
long *pallowBackgroundInput
);

Parameters

pallowBackgroundInput
[out] A pointer to the value of the allowBackgroundInput property. The value is 1 if the mode is enabled, 0 if disabled.

Return Values

Value Description
S_OK Value correctly retrieved.
nonzero error code An error occurred.
