IMsTscNonScriptable::get_BinaryPassword

This method retrieves the password part of a connection password for the Remote Desktop ActiveX control, in binary (nonportable) encoded format.

If you first call put_ClearTextPassword to set a password in clear-text format, you can then convert the password to binary-encoded format by calling get_BinaryPassword.

HRESULT get_BinaryPassword(
BSTR *pBinaryPassword
);

Parameters

pBinaryPassword
[out] Pointer to a string that receives the password part in binary-encoded format. This should not be considered a securely encrypted format.

Return Values

Value Description
S_OK Password successfully obtained.
nonzero error code An error occurred.

Remarks

A binary-encoded password consists of a binary password and a binary salt value. It is not in a human-readable format.

To set a password in binary-encoded format, you must call both put_BinaryPassword and put_BinarySalt.

You can call get_BinarySalt to retrieve the binary salt part of the password.

For more information about converting clear-text passwords to encoded passwords, see put_ClearTextPassword.

This method allocates the memory for the buffer pointed to by pBinaryPassword pCon. C/C++ applications must call SysFreeString to free the memory. This is not required for Visual Basic clients.
