Registry Settings for the Windows CE Device

The MSTSC executable uses RDP binary configuration files by default.

The following code example shows the default configuration parameters:

screen mode id:i:2
desktopwidth:i:800
desktopheight:i:600
session bpp:i:16
winposstr:s:0,0,0,0,0,0
auto connect:i:0
full address:s:
compression:i:1
keyboardhook:i:1
audiomode:i:0
redirectdrives:i:0
redirectprinters:i:1
redirectcomports:i:0
redirectsmartcards:i:1
displayconnectionbar:i:1
autoreconnection enabled:i:1
username:s:
domain:s:
alternate shell:s:
shell working directory:s:
disable wallpaper:i:1
disable full window drag:i:1
disable menu anims:i:1
disable themes:i:0
disable cursor setting:i:0
bitmapcachepersistenable:i:1
