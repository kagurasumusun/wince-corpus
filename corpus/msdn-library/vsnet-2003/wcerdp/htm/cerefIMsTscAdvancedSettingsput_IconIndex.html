IMsTscAdvancedSettings::put_IconIndex

This method sets the value of the IconIndex property, which specifies the index of the icon within the current IconFile file. An IconFile file contains icon data. Please refer to IMsTscAdvancedSettings::put_IconFile for more information about icon files and indices.

HRESULT put_IconIndex(
LONG IconIndex
);

Parameters

IconIndex
[in] Specifies the index of an icon within the current IconFile file.

Return Values

Value Description
S_OK The index was correctly specified.
nonzero error code An error occurred.
