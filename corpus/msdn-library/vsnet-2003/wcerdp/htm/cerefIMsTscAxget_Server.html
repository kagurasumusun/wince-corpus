IMsTscAx::get_Server

This method retrieves the value of the Server property, which specifies which Terminal Services server the current control is connected to.

HRESULT get_Server(
BSTR *pServer
);

Parameters

pServer
[out] A pointer to the value of the Server property.

Return Values

Value Description
S_OK The value was correctly retrieved.
nonzero error code An error occurred.

Remarks

This method allocates the memory for the buffer pointed to by pServer. C/C++ applications must call SysFreeString to free the memory. This is not required for Visual Basic clients.
