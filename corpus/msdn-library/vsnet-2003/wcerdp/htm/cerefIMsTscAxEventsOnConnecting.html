IMsTscAxEvents::OnConnecting

This method is called when the client control begins connecting to a server in response to a call to IMsTscAx::Connect.

VOID OnConnecting ();

Parameters

None.

Return Values

None.

Remarks

Implement this method in your event sink to receive notification that the control has begun connecting.
