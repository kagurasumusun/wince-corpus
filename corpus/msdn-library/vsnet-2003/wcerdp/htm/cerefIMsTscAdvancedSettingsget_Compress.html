IMsTscAdvancedSettings::get_Compress

This method retrieves the value of the Compression property, which determines whether compression is enabled.

HRESULT get_Compress(
long *pCompress
);

Parameters

pCompress
[out] A pointer to the value of the Compression property. 1 if compression is enabled, 0 otherwise.

Return Values

Value Description
S_OK The value was correctly retrieved.
nonzero error code An error occurred.
