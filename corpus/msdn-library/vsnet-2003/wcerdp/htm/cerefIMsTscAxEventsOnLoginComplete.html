Microsoft Windows CE .NET  

IMsTscAxEvents::OnLoginComplete

Called when the client control has successfully logged on to a terminal server, following the display of the Windows Logon dialog box.

VOID OnLoginComplete ();

Parameters

None.

Return Values

None.

Remarks

Implement this method in your event sink to receive notification that the control has completed logon.
