IMsTscAx::get_DesktopWidth

This method retrieves the value of the DesktopWidth property, the width in pixels of the current control's remote desktop.

HRESULT get_DesktopWidth(
LONG *pVal
);

Parameters

pVal
[out] A pointer to the value of the DesktopWidth property.

Return Values

Value Description
S_OK DesktopWidth was correctly retrieved.
nonzero error code An error occurred.
