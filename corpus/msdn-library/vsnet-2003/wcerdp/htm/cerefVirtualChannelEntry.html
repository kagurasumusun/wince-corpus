VirtualChannelEntry

This function is an application-defined entry point for the client-side DLL of an application that uses Terminal Services virtual channels. Terminal Services calls this entry point to pass a set of function pointers to the client DLL. The client calls these functions to work with virtual channels. Your VirtualChannelEntry implementation must call VirtualChannelInit to initialize access to virtual channels.

BOOL VCAPITYPE VirtualChcannelEntry(
PCHANNEL_ENTRY_POINTS pEntryPoints
);

Parameters

pEntryPoints
[in] Pointer to a CHANNEL_ENTRY_POINTS structure that contains pointers to the client-side virtual channel functions.

This pointer is no longer valid after the VirtualChannelEntry function returns. You must make a copy of this structure in extension-allocated memory for later use.

Return Values

Value Description
TRUE DLL correctly loaded.
FALSE An error occurred. DLL unloaded.

Requirements
