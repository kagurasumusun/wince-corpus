IMsTscAdvancedSettings::get_BitmapPersistence

This method retrieves the value of the BitmapPeristence property, which determines whether bitmap caching is enabled or disabled. Note the misspelling of the method and its parameter in the released version of the control.

HRESULT get_BitmapPeristence(
long *pBitmapPersistence
);

Parameters

pBitmapPersistence
[out] Pointer to the value of the BitmapPersistence property. The value is 1 if the property is enabled, 0 if disabled.

Return Values

Value Description
S_OK The value was correctly retrieved.
nonzero error code An error occurred.
