IMsTscAdvancedSettings

The IMsTscAdvancedSettings dual interface includes methods to retrieve and set properties that enable bitmap caching, compression, and printer and clipboard redirection. You can also specify icon data and the names of virtual channel client DLLs.

IMsTscAdvancedSettings includes the following property methods in Vtable order:

  • put_Compress
  • get_Compress
  • put_BitmapPersistence
  • get_BitmapPersistence
  • put_allowBackgroundInput
  • get_allowBackgroundInput
  • put_KeyBoardLayoutStr
  • put_PluginDlls
  • put_IconFile
  • put_IconIndex
  • put_ContainerHandledFullScreen
  • get_ContainerHandledFullScreen
  • put_DisableRdpdr
  • get_DisableRdpdr
