IMsRdpClient::SetVirtualChannelOptions

This method sets the virtual channel options for the Remote Desktop ActiveX control. This method was added for RDP 5.1 clients.

Call this method after calling IMsTscAx::CreateVirtualChannels, but before establishing a connection with IMsTscAx::Connect. This method sets additional options on virtual channels that have been created with CreateVirtualChannels.

HRESULT SetVirtualChannelOptions(
BSTR chanName,
LONG chanOptions
);

Parameters

chanName
[in] The name of the virtual channel specified in the call to IMsTscAx::CreateVirtualChannels.
chanOptions
[in] The options to set for the virtual channel specified by ChanName. For a description of possible options, see CHANNEL_DEF. For more information, see the following Remarks section.

Return Values

Value Description
S_OK Options were correctly set.
nonzero error code An error occurred.

Remarks

RDP 5.1 Clients An example of using this method would be to declare the channel as remote control persistent by setting the CHANNEL_OPTION_REMOTE_CONTROL_PERSISTENT flag. This means that the channel would not be closed when a remote control connects to or disconnects from the session connected to the client. For more information, see Remote Control Persistent Virtual Channels.
