IMsTscSecuredSettings::put_StartProgram

This method sets the value of the StartProgram property, which specifies the program to be started on the Terminal Services server upon connection.

HRESULT put_StartProgram(
BSTR programName
);

Parameters

programName
[in] The string value the StartProgram property is to be set to.

Return Values

Value Description
S_OK Property was correctly set.
nonzero error code An error occurred.
