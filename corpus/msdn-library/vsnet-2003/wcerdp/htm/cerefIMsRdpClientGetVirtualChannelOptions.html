IMsRdpClient::GetVirtualChannelOptions

This method retrieves the options set for a virtual channel. This method was added for RDP 5.1 clients.

HRESULT GetVirtualChannelOptions(
BSTR ChanName,
LONG *pChanOptions
);

Parameters

ChanName
[in] The name of a virtual channel that was specified in the call to IMsTscAx::CreateVirtualChannels.
pChanOptions
[out] The options set for the virtual channel specified by ChanName. For a description of possible options, see CHANNEL_DEF.

Return Values

Value Description
S_OK Options were correctly retrieved.
nonzero error code An error occurred.

See Also

IMsRdpClient, IMsRdpClient::SetVirtualChannelOptions
