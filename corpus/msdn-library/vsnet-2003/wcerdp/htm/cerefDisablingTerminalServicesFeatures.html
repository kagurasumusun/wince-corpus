Disabling Terminal Services Features

For enhanced security, you might choose to disable Terminal Services features such as clipboard redirection and printer redirection for clients that connect to Terminal Services servers using the Remote Desktop ActiveX Control.

To disable Terminal Services features

  1. Add the following keys to the registry of the client computer. 
    HKEY_LOCAL_MACHINE\Software\Microsoft\Terminal Server\DisableClipRedirection
HKEY_LOCAL_MACHINE\Software\Microsoft\Terminal Server\DisablePrinterRedirection
  2. Set the value of both keys to DWORD 1.
