IMsRdpClientNonScriptable

This interface provides a method to send notifications about device changes and a method to send a series of keystrokes to the Remote Desktop ActiveX control. Methods of this interface can only be accessed through the Vtable. This interface was added in RDP 5.1 clients such as Windows XP and Windows CE .NET.

IMsRdpClientNonScriptable derives from the IMsTscNonScriptable interface. It includes all the IMsTscNonScriptable methods and provides additional methods.

The following is the virtual function table for IMsRdpClientNonScriptable.

IUnknown Methods

IMsTscNonScriptable Methods

IMsRdpClientNonScriptable Methods

Method Description
NotifyRedirectDeviceChange Notifies the device-redirection component of the Remote Desktop ActiveX control that a device change has occurred on the system. This method passes WM_DEVICECHANGE notifications to the control.
SendKeys Sends a series of keystrokes to the control. The keystrokes are in scan code form, which is the keyboard data from the actual physical keys.
