IMsTscAdvancedSettings::put_Compress

This method sets the value of the Compression property, which enables or disables compression.

HRESULT put_Compress(
long compress
);

Parameters

compress
[in] The value the Compression property is to be set to. If 0, compression is disabled. If any other value, compression is enabled.

Return Values

Value Description
S_OK Value was correctly set.
nonzero error code An error occurred.
