Remote Desktop ActiveX Control Interface

The Remote Desktop Microsoft® ActiveX® Control supplies the following interfaces:

  • IMsRdpClient
  • IMsRdpClientAdvancedSettings
  • IMsRdpClientNonScriptable
  • IMsRdpClientSecuredSettings
  • IMsTscAdvancedSettings
  • IMsTscAx
  • IMsTscAxEvents
  • IMsTscNonScriptable
  • IMsTscSecuredSettings
