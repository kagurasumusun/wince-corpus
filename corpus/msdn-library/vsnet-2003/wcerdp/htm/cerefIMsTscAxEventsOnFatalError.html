Microsoft Windows CE .NET  

IMsTscAxEvents::OnFatalError

This method is called when the client control encounters a fatal error.

VOID OnFatalError(
long errorCode
);

Parameters

errorCode
[in] Specifies the error code.
Error Code Description
0 An unknown error has occurred.
1 Internal error code 1.
2 Out of memory.
3 Window creation error.
4 Internal error code 2.
5 Internal error code 3 (invalid state).
100 Winsock initialization error.

Return Values

None.

Remarks

In response to this event, the container displays an error message and shuts down.
