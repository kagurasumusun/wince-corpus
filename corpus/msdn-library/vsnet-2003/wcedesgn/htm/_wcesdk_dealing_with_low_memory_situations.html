Managing Low-Memory Situations

Even if you have fine-tuned your application to minimize its memory usage, you will encounter occasions when the system runs very low on RAM. Windows CE-based applications operate in an almost perpetual low-memory environment. At a programming level, a low-memory situation can manifest itself to the application in the following ways:

  • A call to the VirtualAlloc function returns a 0, which indicates that the function failed to allocate memory.
  • Either the LocalAlloc or the HeapAlloc function returns a 0, which indicates that an attempt to increase the size of a heap has failed.
  • Windows CE returns a stack fault error to your application, which indicates that a stack allocation has failed.
    Note   Low-memory situations can be caused indirectly. For example, a call to the CreateWindow function can cause these types of memory failure.
