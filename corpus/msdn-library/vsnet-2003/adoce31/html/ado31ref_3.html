Column Object

This object represents a column from a table, index, or key.

The following table shows the properties that the Column object supports.

Property Description
Name Identifies the column
Type Specifies the data type of the column
Attributes Determines if the column is fixed-length, and if it can contain null values
DefinedSize Specifies the maximum size of the column
NumericScale Specifies the scale with numeric data values
Precision Specifies the maximum precision with numeric data value
ParentCatalog Specifies the Catalog that owns the column
RelatedColumn Specifies the name of the related column in the related table (key columns only)
SortOrder Specifies whether the sort order is ascending or descending (index columns only)

Collection Description
Properties Accesses provider-specific properties

Remarks

Use the Column object to set the properties that apply to a column in a table, index or key.

The Column object can be associated with a Catalog object by assigning the ParentCatalog property.

Key columns are related to other columns using the RelatedColumn property.

The Properties collection lists provider-specific properties.

Example

The following code demonstrates how to create a new column.

Set objCol = CreateObject("adoxce.column.3.1")
    objCol.Type = 2
    objCol.Name = "newColumn"
