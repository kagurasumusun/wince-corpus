Type (Table)

This property indicates the type of a table.

Syntax

None

Parameters

None

Return Values

Returns a String value that specifies the type of table; for example, "TABLE", "SYSTEM TABLE", or "GLOBAL TEMPORARY".

Remarks

This property is read-only.
