Catalog Object

This object contains Table collections, which describe the schema catalog of a data source.

A schema is a description of a database to the database management system (DBMS), generated by using the data definition language (DDL), which is provided by the DBMS. The schema actually defines a particular view of some aspect of the database; that is, it defines the attributes (or fields) that will be visible, the domains (permissible values) of these attributes, and information concerning their form and location.

The following table shows the methods that the Catalog object supports.

Method Description
Create Creates a new data source and opens a new ADOCE Connection to that data source

The following table shows the properties the Catalog object supports.

Property Description
ActiveConnection Indicates the ADOCE Connection object to which the Catalog belongs

Remarks

You can modify the Catalog object by adding or removing objects or by modifying existing objects. Some providers may not support all of the Catalog objects or may support only viewing schema information.

Examples

The following code sample shows how to create a Catalog object.

Dim col, tbl, cat, strDataSource, strConn
    strDataSource = "pubs.db"

    Set cat = CreateObject("ADOXCE.CATALOG")
    Set tbl = CreateObject("ADOXCE.TABLE")
    Set col = CreateObject("ADOXCE.COLUMN")

    col.Name = "colName"
    col.Type = adInteger

    tbl.Name = "temp_table"
    tbl.Columns.Append col

    strConn = "provider=SQLOLEDB;data source=" & strDataSource & ";"
    cat.ActiveConnection = strConn

Set col = Nothing
Set tbl = Nothing
vSet cat = Nothing
