Attributes (Connection)

This property returns or sets transaction attributes on the current connection.

var = connection.Attributes

Return Values

The default value for the Attributes property is FALSE (0). The following table shows the constants and their values. Not all OLE DB providers support these values.

Constant Value Description
adXactCommitRetaining 131072 Performs a retaining commit transaction, by calling the CommitTrans method.
adXactAbortRetaining 262144 Performs a retaining abort transaction by calling the AbortTrans method.

Remarks

This property is a bitmask Long value.

When used with the proprietary Windows CE data source, the default value of FALSE (0) is returned.
