Type

This property specifies the data type of a Field object. 

var = field.Type

Remarks

This property is read-only.

The above list includes all possible constants. Check the provider documentation to see which constants are supported.

Examples

The following code example shows how to set the constants for the Type property.

Const adBoolean = 11
Const adDate = 7
Const adDouble = 5
Const adInteger = 3
Const adLongVarBinary = 205
Const adLongVarWChar = 203
Const adSmallInt = 2
Const adUnsignedInt = 19
Const adUnsignedSmallInt = 18
Const adVarBinary = 204
Const adVarWChar = 202

The following code example shows the data types of all fields in the MyTable table.

Dim rs, n
Set rs = CreateObject ("ADOCE.Recordset.3.1")
rs.Open "myTable"
For n = 0 to rs.Fields.Count -1
     MsgBox rs.Fields(n).Type
Next
