Create

This method creates a new Catalog object.

Syntax

Catalog.Create ConnectString

Parameters

Catalog
A valid Catalog object.
ConnectString
A String value used to connect to the data source.

Return Values

Creates and opens a new ADOCE Connection object.

Remarks

The Create method creates and opens a new ADOCE Connection to the data source specified in the ConnectString parameter. If successful, the new Connection object is assigned to the ActiveConnnection property.

An error will occur if the provider does not support the creation of new Catalogs. Check the provider's documentation for further details.

Example

The following code shows how to call the Create method of a Catalog object.

Dim cat

    Set cat = CreateObject("adoxCE.catalog")

    If Dir("test.db") <> "" Then
        Kill ("test.db")
    End If

    strConn = "provider=microsoft.sqlserver.oledb.ce.1.0;data source=test.db"

    cat.Create strConn

    Set cat = Nothing
End Sub
