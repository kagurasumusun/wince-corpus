Provider

This property returns or sets the OLE DB data provider for the session.

connection.Provider

Return Values

This property returns a string value.

Remarks

This property can also be set using the ConnectionString property.

This property is read/write until the Open method is called. After the Open method has been called, this property remains read-only until the Close method is called successfully.

This property is read/write.

The default value of the Provider property is CEDB which connects to the proprietary Windows CE data source.
