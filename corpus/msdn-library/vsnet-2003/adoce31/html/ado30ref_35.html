Properties

The following table shows the properties that the ADOCE control supports.

Property Description
AbsolutePage Returns which page to move for a new current record
AbsolutePosition Returns the ordinal position of the current record of a recordset
ActiveConnection Sets the current database connection
ActualSize Returns the actual length, in bytes, of a field’s value
Attributes (Connection) Returns or sets transaction attributes on the current connection
Attributes (Field) Returns a value that specifies one or more characteristics of a Field object
BOF Returns whether the current record position is before the first record in a recordset
Bookmark Returns a bookmark that uniquely identifies a record in a recordset
CacheSize Returns the number of records from a recordset that are cached locally in memory
ConnectionString Connects to a data source
Count Returns the number of fields in a recordset
CursorType Returns the type of cursor used in a recordset
DefaultDatabase Sets the default data source for the current connection
DefinedSize Returns the data capacity of a Field object, and returns the defined size of the field in characters
Description Returns a string from the provider that describes the error
EditMode Returns the edit status of the current record
EOF Returns the number of the current record position that is after the last record in a recordset
Errors (Collection) Contains chained errors returned from the provider
Filter Returns or sets a filter on the current recordset
HelpContext Returns the Help context identifier related to an error generated by the data source
HelpFile Returns the path to the Windows® CE Help file that contains information about the error generated by the data source
Index Returns or sets the number that uniquely identifies an object in a collection
IsolationLevel Returns or sets the isolation level for the current connection
LockType Returns the type of locks placed on records during editing
Mode Returns the permissions for modifying data of the current connection
Name Returns the name of a field
NativeError Returns the native error number of the error
Number Returns the OLE error number
NumericScale Returns the number of defined digits to the right of the decimal separator in the field
PageCount Returns the number of pages of data a recordset contains
PageSize Returns the number of records that constitute one page in a recordset
Precision Returns the total number of digits defined in a field
Properties Collection (Connection) Contains information about the provider
Properties Collection (Recordset) Returns additional metadata about the recordset (Not required to be supported by an OLE DB provider)
Provider Returns or sets the OLE DB provider for the session
RecordCount Returns a Long value that specifies the current number of records in a recordset
Source (Error) Returns a string that contains the name of the object or application that generated the error
Source (Recordset) Returns the source for the data in a recordset, either an SQL statement or table name
State (Connection) Describes the state of the current connection
State (Recordset) Describes the current state of the recordset
Type Returns the data type of a Field object
UnderlyingValue Returns the current value of a Field object in the database
Value Returns the current value of a Field object in the recordset
Version Returns the version of the provider library used
