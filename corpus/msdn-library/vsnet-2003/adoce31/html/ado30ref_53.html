Errors (Collection)

This property contains chained errors returned from the provider.

connection.Errors

Return Values

This property returns a collection of Error objects.

Remarks

The default of this property is an empty collection.

The Errors collection supports the standard behavior of a collection. You can use the Item and Clear methods on the collection and the For Each syntax for looping through the collection.

This collection only holds errors returned from the data source.

The proprietary Windows CE data source returns an Errors collection when an error occurs.
