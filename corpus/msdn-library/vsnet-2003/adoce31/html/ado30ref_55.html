HelpContext

This property returns the Help context identifier related to an error generated by the data source.

error.HelpContext

Return Values

This property returns a Long value.

Remarks

Context identifiers are not supported by Windows CE Help files. If the provider does supply a context identifier, it is passed through to this property. The value of the HelpContext can be stored and later used by a desktop computer’s Help file.

The HelpContext property is read-only.
