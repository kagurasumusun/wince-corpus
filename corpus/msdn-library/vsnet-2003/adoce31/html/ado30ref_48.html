DefaultDatabase

This property sets the default database for the current connection.

connection.DefaultDatabase

Return Values

This property returns a string value.

Remarks

The default for this read/write property is a zero-length string ("").

Once the DefaultDatabase property has been set, SQL strings can use an unqualified syntax to access objects in that database. If this property has not been set, you must qualify your database objects with the name of the database.
