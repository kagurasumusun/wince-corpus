Unique

This property indicates whether the index keys must be unique.

Syntax

None

Parameters

None

Return Values

Sets and returns a Boolean value.

Remarks

The default value is False.

This property is read-only on Index objects already appended to a collection.

Examples

This example demonstrates how to use adKeyUnique of the Unique property of an Index.

    'Create myTable
    table.Name = "myTable"
    table.Columns.Append "col1", adNumeric
    table.Columns("col1").Precision = 28
    table.Columns("col1").NumericScale = 10
    cat.Tables.Append table

    'Create myKey
    key.Name = "myKey"
    key.Type = adKeyUnique
    key.Columns.Append "col1"
    cat.Tables("myTable").Keys.Append key

    'List keys
    MsgBox ("Number of keys: " & cat.Tables("myTable").Keys.Count)
    For i = 0 To cat.Tables("myTable").Keys.Count – 1
        Debug.Print cat.Tables("myTable").Keys(i).Name
    Next I
