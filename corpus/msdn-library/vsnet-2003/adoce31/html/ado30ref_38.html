ActiveConnection

This property sets the current database connection.

var = recordset.ActiveConnection

Return Values

Returns a reference to the Connection object that owns this recordset.

Remarks

You can pass a valid connection definition string to this property. In the case that a connection definition string is passed to the ActiveConnection property, and an existing Connection object to match the string does not exist, a new Connection object is created.

The default value of this property is NULL.

The ActiveConnection property is read/write when the Recordset object is closed and read-only when the Recordset object is open.
