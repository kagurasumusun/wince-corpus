Database Conversion

When a database is moved between a desktop computer and a Windows CE–based device, the data must be converted from one database format to another. Data exported to a desktop computer is converted to either the Microsoft Access database or other ODBC database formats with an .mdb file extension. Data imported to a device is converted to the proprietary Windows CE database format with a .cdb file extension. The two database file formats are not compatible with each other.
