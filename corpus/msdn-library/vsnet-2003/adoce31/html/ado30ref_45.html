ConnectionString

This property contains the string used to connect to a data source.

connection.ConnectionString

Return Values

This property returns a string value.

Remarks

This property is read/write until the Open method is called. While a connection is open, the ConnectionString property is read-only. When the Close method is called, the ConnectionString property returns to read/write status.

To access the proprietary Windows CE data source, set the Provider property to CEDB.

The default value of the ConnectionString property is a zero-length string ("").

If values other then the data source are specified in the ConnectionString, use keyword pairs for each value. If only the data source is being specified, do not use keyword pairs.

Examples

The following code examples show how to set the ConnectionString property.

Cn.Provider = "CEDB"
Cn.ConnectionString = " \mydb.cdb"
