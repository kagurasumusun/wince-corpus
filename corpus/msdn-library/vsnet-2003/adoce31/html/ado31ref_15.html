Append (Columns)

This method adds a new Column object to the Columns collection.

Syntax

Col.App Column [, Type] [, DefinedSize]

Parameters

The following table shows the Parameters for the Append method for a Columns collection.

Parameter Description
Column Required. The Column object to append or the name of the column to create and append.
Type Optional. A Long value specifying the data type of the column. The Type parameter corresponds to the Type property of a Column object.
DefinedSize Optional. A Long value specifying the size of the column. The DefinedSize parameter corresponds to the DefinedSize property of a Column object.

Return Values

None

Remarks

Note   An error will occur when appending a Column to the Columns collection of an Index if the Column does not already exist in a Table that is already appended to the Tables collection.

Example

The following example shows how to append a Column to a collection.

Private Sub cmdSSCE_Click()

    Dim m_cat, m_col, tbl, col, strConn, stTableName, stColumnName, stExp, stAct
    
    Set m_cat = CreateObject("adoxce.catalog.3.1")
    Set m_col = CreateObject("adoxce.column.3.1")
    Set tbl = CreateObject("adoxce.table.3.1")
    Set col = CreateObject("adoxce.column.3.1")
    
    'strConn = "provider=microsoft.sqlserver.oledb.ce.1.0;data     source=pubs.db;"
    strConn = "provider=microsoft.jet.oledb.4.0;data source=temp.mdb;"
    m_cat.ActiveConnection = strConn

    stTableName = "ColAppScen18"
    If adox_ExistsTable(m_cat, stTableName) m_cat.Tables.Delete     stTableName
    End If

    tbl.Name = stTableName

    stColumnName = "Column1"
    m_col.Name = stColumnName
    m_col.Type = adSmallInt

    tbl.Columns.Append m_col
    m_cat.Tables.Append tbl

    'create a new column
    col.Name = "Column2"
    col.Type = adSmallInt

    'Set parentcatalog
    col.ParentCatalog = m_cat

    m_cat.Tables(stTableName).Columns.Append col

    stExp = "Column2"
    stAct = m_cat.Tables(stTableName).Columns(1).Name

    Debug.Print stExp, stAct

    'cleanup
    m_cat.Tables.Delete stTableName
    Set tbl = Nothing
    Set col = Nothing
    Set m_cat = Nothing

End Sub
