Clustered

This property indicates whether the object is clustered.

Syntax

None

Parameters

None

Return Values

Sets and returns a Boolean value.

Remarks

The default value is False.

This property is read-only on Index objects already appended to a collection.

Example

This example demonstrates how to use the Clustered property of an Index.

    'Enumerate Tables
    For Each tblLoop In cat.Tables
        'Enumerate Indexes
        For Each idxLoop In tblLoop.Indexes
            Debug.Print tblLoop.Name & " " & _
                idxLoop.Name & " " & idxLoop.Clustered
        Next idxLoop
    Next tblLoop
