Index Object

This object represents an index from a database table.

The following tables show the properties and collections that the Index object supports.

Property Description
Clustered Indicates whether the index is clustered
IndexNulls Indicates whether records that have NULL values in their index fields have index entries
Name Indicates the identity of the index
ParentCatalog Indicates the Catalog that owns the index
PrimaryKey Indicates whether the index represents the primary key on the table
Unique Indicates whether the index keys must be unique

Collection Description
Columns Accesses the database columns of the index
Properties Accesses the provider-specific index properties

Parameters

None

Return Values

None

Remarks

Note   An error will occur when appending a Column to the Columns collection of an Index if the Column does not already exist in a Table object already appended to the Tables collection.

Example

The following code demonstrates how to create a new index.

Dim idx, prps

Set idx = CreateObject("adoxce.index.3.1")
Set prps = idx.Properties
