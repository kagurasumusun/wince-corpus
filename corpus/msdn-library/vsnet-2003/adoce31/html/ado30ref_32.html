Seek

This method locates a record in an indexed recordset and makes that record the current record.

recordset.seek (KeyValues As Array, SeekOption As SeekEnum)

Parameters

KeyValues
An array of Variant values. Each element of the array should contain a value to compare against each corresponding column in the index.
SeekOption
A SeekEnum value that specifies the type of comparison to be made between the columns of the index and the corresponding KeyValues. The following table shows the comparison constants.
Constant Description
adSeekAfterEQ Seeks a key equal to KeyValues, or the key just after where that match would have occurred
adSeekAfter Seeks a key just after where a match with KeyValues would have occurred
adSeekBeforeEQ Seeks a key equal to KeyValues or the key just before where that match would have occurred
adSeekBefore Seeks a key just before where a match with KeyValues would have occurred
adSeekFirstEQ Seeks the first key equal to KeyValues
adSeekLastEQ Seeks the last key equal to KeyValues

Return Values

None.

Remarks

To use this method, the Recordset object’s CursorLocation property cannot have a value of adUseClient and the Recordset object must have been opened with a CommandTypeEnum value of asCmdTableDirect.

Use the Seek method in conjunction with the Index property if the underlying provider supports indexes on the Recordset object. To determine whether the underlying provider supports indexes, use the Supports(adIndex) method.

If Seek does not find the desired row, no error occurs and the row is positioned at EOF. You can set the Index property to the desired index before executing this method.
