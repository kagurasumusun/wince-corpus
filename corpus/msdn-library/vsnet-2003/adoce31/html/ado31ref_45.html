UpdateRule

This property indicates the action performed when a primary key is updated.

Syntax

None

Constants

Sets and returns a Long value that is one of the following constants:

Constant Description
adRINone No action
adRICascade Cascade changes
adRISetNull Set the foreign key value to null
adRISetDefault Set the foreign key value to the default

Parameters

None

Return Values

None

Remarks

The default value is adRINone.

This property is read-only on Key objects already appended to the collection.

Examples

The following code demonstrates how to create a new foreign key and uses the Keys Append Method, Key Type, RelatedColumn, RelatedTable and UpdateRule Properties (VB). It assumes two tables (Customers and Orders) exist.

    'Define the foreign key
    kyForeign.Name = "CustOrder"
    kyForeign.Type = adKeyForeign
    kyForeign.RelatedTable = "Customers"
    kyForeign.Columns.Append "CustomerId"
    kyForeign.Columns("CustomerId").RelatedColumn = "CustomerId"
    kyForeign.UpdateRule = adRICascade

    'Append the foreign key
    cat.Tables("Orders").Keys.Append kyForeign
