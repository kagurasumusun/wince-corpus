Execute

This method executes a command against the connection that is not expected to return a recordset.

Connection.Execute(CommandText As String, [RecordsAffected As Long][Options As Options]) As Recordset

Parameters

CommandText
Command to execute against the connection. The syntax of the string to be used for this parameter is provider-specific. The string can be standard SQL syntax or any type of command that the provider supports.
RecordsAffected
Optional variable for obtaining the number of affected records.

Options

Optional bitmask for execution options

Return Values

Returns a recordset if the CommandText command is able to generate one.

Remarks

If results are generated by the data source from the command sent by the Execute method, a new default recordset is returned. If no results are generated, the data source returns a NULL object reference. If no resultant recordset is desired from the command, the return value can be ignored.

When used with the proprietary Windows® CE data source, an adUnknown value is returned in the RecordsAffected parameter.

Examples

The following code example shows how to use the Execute method.

Dim cn, strSQL
Set cn = CreateObject("ADOCE.Connection.3.1")
strSQL = "DROP TABLE myTable"
cn.Open "myDatabase.cdb"
cn.Execute(strSQL)
cn.Close
Set cn = Nothing
