SortOrder

This property indicates the sort sequence for the column (index columns only).

Syntax

None

Constants

Sets and returns a Long value that is one of the following constants:

Constant Description
adSortAscending The sort sequence for the column is ascending
adSortDescending The sort sequence for the column is descending

Parameters

None

Return Values

None

Remarks

The default value is adSortAscending.

This property only applies to Column objects in the Columns collection of an Index.

Example

This example demonstrates the SortOrder property of a Column that has been appended to the Columns collection of an Index. The difference between ascending and descending indexes is shown.

    idxAscending.Columns.append "Country"
    idxAscending.Columns("Country").SortOrder = adSortAscending
    idxAscending.Name = "ascending"

    catNorthwind.tables("employees").indexes.append idxAscending

    rstEmployees.Index = idxAscending.Name
    rstEmployees.open "employees", cnn, adOpenKeyset, adLockOptimistic, adCmdTableDirect
    With rstEmployees
        .movefirst
        Debug.Print "  Country - Name"

        Do While Not .EOF
            Debug.Print "    " & !Country & " - " & _
                !FirstName & " " & !LastName
            .movenext
        Loop

        .Close
    End With
