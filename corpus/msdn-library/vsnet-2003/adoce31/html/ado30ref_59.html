LockType

This property specifies the type of locks placed on records during editing.

recordset.LockType

Constants

The following table shows the constants used by the LockType property.

Constant Value Description
adLockReadOnly 1 Default. Read-only, records cannot be added, deleted or changed.
adLockPessimistic 2 Pessimistic locking, row by row. The provider ensures successful editing of the records by locking records at the data source. Records can be added, deleted and changed.
adLockOptimistic 3 Optimistic locking, row by row. The provider uses optimistic locking in a row by row fashion. Records can be added, deleted and changed.

Return Values

This property returns an Integer value.

Remarks

Use the LockType property to determine what type of locking the provider should use when opening a Recordset object or to return the type of locking in use on an open Recordset object. The LockType property is read/write when the recordset is closed and read-only when it is open.

The proprietary Windows CE data source does not support adLockPessimistic. Instead, the proprietary Windows CE data source substitutes adLockOptimistic.

Using the unsupported adLockBatchOptimistic constant returns an error from the data source provider.
