Type (Key)

This property indicates the data type of the key.

Syntax

None

Constants

Sets or returns a Long value that is one of the following constants:

Constant Description
adKeyPrimary The key is a primary key
adKeyForeign The key is a foreign key
adKeyUnique The key is unique

Parameters

None

Return Values

None

Remarks

The default value is adKeyPrimary.

This property is read-only on Key objects already appended to a collection.

Examples

This code example demonstrates how to use the Type (Key) property.

Dim cat, tbl, key, strConn
    Set cat = CreateObject("adoxce.catalog.3.1")
    Set tbl = CreateObject("adoxce.table.3.1")
    Set key = CreateObject("adoxce.key.3.1")

    strConn = "provider=microsoft.sqlserver.oledb.ce.1.0;data source=pubs.db;"

    cat.activeconnection = strConn

    tbl.Name = "test_table"
    tbl.Columns.append "fld1", 2    'adsmallint

    key.Name = " test "
    key.Type = 1    'adKeyPrimary
    key.Columns.append tbl.Columns(0).Name

    tbl.Keys.append key

    If adox_ExistsTable(cat, tbl.Name) Then
        cat.tables.Delete tbl.Name
End Sub
