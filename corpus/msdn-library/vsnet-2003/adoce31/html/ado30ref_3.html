Error Object

This object returns error information from a data source provider when an error occurs.

The following table shows the properties that the Error object supports.

Properties Description
Description Returns a string from the provider that describes the error
HelpContext Returns the Help context identifier related to an error generated by the data source
HelpFile Returns the path to the Windows® CE Help file that contains information about the error generated by the data source
NativeError Returns a provider-specific error number
Number Returns the OLE error number
Source Returns a string that contains the name of the object or application that generated the error

Remarks

The Error object has no methods or events.

All properties of the Error object are read-only.

Until an error has occurred, all the properties of an Error object returns NULL.

All data sources can return an Error object.

Error objects are contained in the Errors collection which is property of the Connection object.

Examples

The following code example shows how to read the properties of an Error object by iterating through an Errors collection.

Dim cn, errObj
Set cn = CreateObject("ADOCE.Connection.3.1")
'Code here would open a connection to a data source.

'When an error occurs use the following loop to
'iterate through the Error objects in the collection.
For Each errObj In cn.Errors
  MsgBox errObj.Number & " - " & errObj.Description
Next
