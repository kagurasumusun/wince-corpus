EditMode

This property specifies the editing status of the current record.

recordset.EditMode

Constants

The following table shows the constants used for the EditMode property.

Constant Value Description
adEditNone 0 No editing operation is in progress.
adEditInProgress 1 Data in the current record has been modified but not saved.
adEditAdd 2 The AddNew method has been invoked, and the current record in the copy buffer is a new record that is not saved in the database.

Return Value

This property returns an Integer value.

Remarks

Use the EditMode property to determine the editing status of the current record. If an editing process has been interrupted, you can test for pending changes and determine whether to use the Update method or the CancelUpdate method.

For more information about the EditMode property under different editing conditions, see the AddNew method.

Examples

The following code example shows how to set the constants for the EditMode property.

Const adEditNone = 0
Const adEditInProgress = 1
Const adEditAdd = 2
