State (Connection)

This property describes the state of the current connection.

connection.State

Constants

The following table shows the constants that are available for use with the State property.

Constant Value Description
adStateClosed 0 Default. The object is closed.
adStateOpen 1 The object is open.

Return Values

This property returns a Long value.

Remarks

This read-only Variant property defaults to adStateClosed.

Use this property to determine if a connection is open or closed.
