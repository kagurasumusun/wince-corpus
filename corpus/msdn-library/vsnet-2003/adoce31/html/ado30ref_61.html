Name

This property returns the name of a field.

var =field.Name

Return Values

This property returns a string value that specifies a name.

Remarks

The default value of the Name property is a zero-length string ("").

Field names cannot be longer than 64 characters.

This property is read-only.

Examples

The following code example shows how to display the names of all fields in the MyTable table.

Dim rs, n
Set rs = CreateObject ("ADOCE.Recordset.3.1")
rs.Open "myTable"
For n = 0 to rs.Fields.Count -1
MsgBox rs.Fields(n).Name
Next
