Supports

This method determines if the recordset supports specified features.

Boolean = recordset.Supports(CursorOptions)

Parameters

CursorOptions
Long expression. The following table shows the values that can be used singly or in combination for the CursorOptions parameter.
Constant Value Description
adAddNew 16778240 Supports the AddNew method
adApproxPosition 16384 Supports the AbsolutePosition and AbsolutePage properties
adBookmark 8192 Supports the Bookmark property
adDelete 16779264 Supports the Delete method
adMovePrevious 512 Supports the MovePrevious and Move methods to move the current record position backward
adUpdate 16809984 Supports the Update method
adHoldRecords 256 Retrieves more records or changes the next retrieve position without committing all pending changes
adResync 131072 Updates the cursor with the data that is visible in the underlying database, using the Resync method
adUpdateBatch 65536 Not supported

Return Values

OLE DB providers can return TRUE for any of the above constants, depending on their capabilities. See the provider documentation for more information.

The proprietary Windows CE data source always returns FALSE for any of the following constants: adHoldRecords, adResync, and adUpdateBatch. All other constants can return TRUE when used with the proprietary Windows CE data source.

Remarks

Use the Supports method to determine what types of functionality a Recordset object supports. If a Recordset object supports the features whose corresponding constants are in CursorOptions, the Supports method returns TRUE. Otherwise, it returns FALSE.

Examples

The following code example shows how to set the constants for the Supports method.

Const adHoldRecords = &H00000100
Const adMovePrevious = &H00000200
Const adAddNew = &H01000400
Const adDelete = &H01000800
Const adUpdate = &H01008000
Const adBookmark = &H00002000
Const adApproxPosition = &H00004000
Const adUpdateBatch = &H00010000
Const adResync = &H00020000
Const adNotify = &H00040000
