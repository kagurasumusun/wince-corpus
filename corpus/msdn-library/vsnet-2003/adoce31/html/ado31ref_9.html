Columns Collection

This collection contains all Column objects of a table, index, or key.

Constants

The Append method for a Columns collection is unique for ADOXCE.

Method Description
Append Adds a new column to the collection

The following tables show the methods and properties that are standard to ADOCE collections.

Method Description
Item Accesses a column in the collection
Delete Removes a column from the collection
Refresh Updates the objects in the collection to reflect the current database's schema

Property Description
Count Returns the number of columns contained in the collection

Parameters

None

Return Values

None

Remarks

Note   An error will occur when appending a Column to the Columns collection of an Index if the Column does not already exist in a Table that is already appended to the Tables collection.

Example

The following code demonstrates how to append a Column object.

' create myKey
    key.Name = "myKey"
    key.Type = adKeyUnique
    key.Columns.Append "col1"
    cat.Tables("myTable").Keys.Append key
