Open (Recordset)

This method defines and opens recordsets, and runs SQL commands.

recordset.Open Source, ActiveConnection, CursorType, LockType, Options

Parameters

Source
Required. Variant that is a table name or an SQL statement.
ActiveConnection
Optional. The database file (.cdb) that is opened on the Windows® CE-based device. This parameter is available on the following platforms: Microsoft® Windows® CE, Handheld PC Professional Edition, Version 3.0, Microsoft® Windows® CE for the Palm-size PC, and Microsoft® Platform Builder version 2.12.
CursorType
Optional. The type of movement that is enabled for navigating through the recordset. Also affects how updates to the underlying database are reflected in the Recordset object. The following table shows the acceptable values.
Constant Value Description
adOpenForwardOnly 0 Forward-only cursor. Identical to a static cursor except that you can only scroll forward through records. In ADOCE, this cursor type does not improve performance. For compatibility with ADO for desktop computers, however, it remains the default.
adOpenKeyset 1 Keyset-driven cursor. Additions, changes, and deletions by other users are not visible. All types of movement through the recordset are enabled.
adOpenDynamic 2 Dynamic cursor. Additions, changes, and deletions by other users are visible, and all types of movement through the recordset are allowed, except for bookmarks, if the provider doesn't support them.
adOpenStatic 3 Static cursor. A static copy of a set of records that you can use to find data or generate reports. Additions, changes, or deletions by other users are not visible.

Using other values results in a LockType of 1 (adOpenKeyset). Dynamic-type and static-type cursors are not available in ADOCE.

LockType
Optional. Determines what type of locking, or concurrency, the provider should use when opening the Recordset object. The default value for this parameter is adLockReadOnly. The following table shows the acceptable values.
Constant Value Description
adLockReadOnly 1 Read-only. You cannot add, delete, or change records.
adLockPessimistic 2 Pessimistic locking, record by record. The provider does what is necessary to ensure successful editing of the records, usually by locking records at the data source immediately upon editing. You can add, delete, and change records.
adLockOptimistic 3 Optimistic locking, record by record. The provider uses optimistic locking, locking records only when you call the Update method. You can add, delete, and change records.

Using other values results in a LockType of 3 (adLockOptimistic), unless the table itself is read-only. In that case, the LockType is 1 (adLockReadOnly). For compatibility with ADO for desktop computers, the default LockType is 1 (adLocklReadOnly). Pessimistic and optimistic batch locking are not supported by the proprietary Windows® CE data source.

Options
Optional. Specifies how the provider should evaluate the Source parameter. The following table shows the acceptable values.
Constant Value Description
adCmdText 1 Evaluates Source as an SQL statement.
adCmdTable 2 Evaluates Source as a table name from the system table MsysTables.
adCmdStoredProc 4 Evaluates Source as a stored procedure from the system table MsysProcs.
adCmdUnknown 8 Default. The type of command in the Source parameter is unknown.
adCmdTableDirect 512 Evaluates CommandText as a table name whose columns are all returned.

Return Values

Returns a Recordset object.

Remarks

The Open method is read-only by default.

No Command object exists in ADOCE, so the Source parameter must be a string.

If you know what type of command you are using, setting the Options parameter instructs ADOCE to go directly to the relevant code. If the Options parameter does not match the type of command in the Source parameter, an error occurs when you call the Open method.

When you call the Open method with an SQL command that does not return rows, such as CREATE TABLE, no recordset is returned and the state of the recordset remains closed.

An SQL statement can be no longer than 2,048 characters. A statement longer then this limit will cause an error to occur.

An OLE DB provider may allow additional constants to be used with the Options parameter.

Examples

The following code example shows how to set the CursorType and LockType and use the Open method.

Const adOpenKeyset = 1
Const adLockOptimistic = 3

Dim rstLocked, rstUpdateable
Set rstLocked = CreateObject("ADOCE.Recordset.3.1")
Set rstUpdateable = CreateObject("ADOCE.Recordset.3.1")

'The default is to open a read-only, forward-only recordset.
rstLocked.Open "myTable"
'Additional parameters for write acccess to a recordset
rstUpdateable.Open "myTable2","", adOpenKeyset, adLockOptimistic
