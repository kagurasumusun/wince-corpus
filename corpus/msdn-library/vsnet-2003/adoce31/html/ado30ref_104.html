Filtering Errors

Filtering errors occur when a database is being transferred between a desktop computer and a Windows® CE–based device. The error value is contained and returned in the HRESULT variable. An HRESULT of zero specifies that database filtering was successful. Any value other then zero specifies that the filtering operation was not successful.

The following table shows common HRESULT values. Additional definitions of HRESULT values can be found in the Winerror.h file provided in the Platform SDK.

HRESULT value Value Description
S_OK 0x00000000 Operation successful
E_UNEXPECTED 0x8000FFFF Unexpected failure
E_NOTIMPL 0x80004001 Not implemented
E_OUTOFMEMORY 0x8007000E Failed to allocate necessary memory
E_INVALIDARG 0x80070057 One or more arguments are invalid
E_NOINTERFACE 0x80004002 No such interface is supported
E_POINTER 0x80004003 Invalid pointer
E_HANDLE 0x80070006 Invalid handle
E_ABORT 0x80004004 Operation aborted
E_FAIL 0x80004005 Unspecified failure
E_ACCESSDENIED 0x80070005 General access denied
