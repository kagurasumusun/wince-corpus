IsolationLevel

This property returns or sets the level of transaction isolation for the current connection.

connection.IsolationLevel

Constants

The following table shows the possible IsolationLevel constants.

Constant Value Description
adXactUnspecified -1 Specifies that the provider is using a different isolated level than specified, but that the level cannot be determined
adXactChaos (Default) 16 Specifies that you cannot overwrite pending changes from more isolated changes
adXactBrowse 256 Specifies that from one transaction you can view changes uncommitted to the database in other transactions
adXactReadUncommitted 256 Same as adXactBrowse.
adXactCursorStability 4096 Specifies that from one transaction you can view changes in other transactions only after they have been committed to the database
adXactReadCommitted 4096 Same as asXactCursorStability
adXactRepeatableRead 65536 Specifies that from one transaction you cannot see changes made in other transactions, but that re-querying can result in updated recordsets
adXactSerializable 1048576 Specifies that transactions are conducted in isolation from other transactions
adXactIsolated 1048576 Same as adXactSerializable

Return Values

The IsolationLevel property returns a Long value.

Remarks

The default value of the IsolationLevel property is adXactChaos.

The setting does not take effect until the BeginTrans method is called.

If the level of isolation you request is not available, the provider may supply the next greater level of isolation.
