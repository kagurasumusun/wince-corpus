Supported SQL Statements

The ADOCE control supports a subset of the ANSI Structured Query Language (SQL). This subset allows you to use SQL statements to create, query and modify databases, tables, and recordsets. For detailed information on ADOCE support of SQL, see the SQL reference in this documentation.

Windows CE has some features that are not found in standard databases—for example, sorting null characters to the beginning or end of the table, and supporting unsigned numeric data types. You can create tables and indexes using nonstandard sort orders and types; however, this is not recommended. ADOCE SQL supports these features to the extent necessary to port existing desktop computer ADO applications to the Windows CE platform.

The following table shows the basic SQL statements and variations ADOCE supports.
