PrimaryKey

Indicates whether the index represents the primary key on the table.

Syntax

None

Parameters

None

Return Values

Set and returns a Boolean value.

Remarks

The default value is False.

This property is read-only on Index objects already appended to a collection.

Example

This example demonstrates how to set the PrimaryKey of an Index object.

Dim m_cat, m_cnn, m_idx, m_strConn

    m_strConn = "Provider=Microsoft.SQLSERVER.OLEDB.CE.1.0; Data Source=\pubs.db;"

    Set m_cnn = CreateObject("adoce.connection.3.1")
    Set m_cat = CreateObject("adoxce.catalog.3.1")
    Set m_idx = CreateObject("adoxce.index.3.1")
    m_cnn.open m_strConn

    m_idx.PrimaryKey = True

    If m_idx.PrimaryKey Then MsgBox "Passed" Else MsgBox "Failed"

    Set m_cat = Nothing
    Set m_cnn = Nothing
    Set m_idx = Nothing
End Sub
