RollbackTrans

This method cancels any changes made during the current transaction and ends the transaction.

connection.RollbackTrans

Parameters

None.

Return Values

None.

Remarks

After committing or rolling back a transaction using the RollbackTrans method, the connection is in auto-commit mode until the BeginTrans method is called.

If a connection is not open or there is no current transaction, using the RollbackTrans method causes an error.

When used with the proprietary Windows® CE data source, the RollbackTrans method raises an error.

Examples

The following code example shows how to cancel changes to a recordset using the RollbackTrans method.

Dim cn, rs
'Insert code here to open a connection to a data source
'and open the table in the data source, myTable.
cn.BeginTrans
'Insert data collection code here.
If MsgBox("Save all changes?", vbYesNo) = vbYes Then
  cn.CommitTrans
Else
  cn.RollbackTrans
End If
