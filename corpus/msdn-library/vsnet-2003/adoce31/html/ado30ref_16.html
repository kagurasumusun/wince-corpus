CommitTrans

This method commits the current transaction on the connection.

recordset.CommitTrans()

Parameters

None.

Return Values

None.

Remarks

After committing a transaction with the CommitTrans method, the connection is in auto-commit mode until the BeginTrans method is called.

An error occurs if there is not a currently open transaction. Use the OpenTrans method to open a connection to the data source.

The CommitTrans method creates an error if used on the proprietary Windows® CE data source.

Examples

The following code example shows how to use the CommitTrans method.

Dim cn, rs
'Insert code here to open a connection to a data source
'and open the table in the data source, myTable.
cn.BeginTrans
'Insert data collection code here.
If MsgBox("Save all changes?", vbYesNo) = vbYes Then
  cn.CommitTrans
Else
  cn.RollbackTrans
End If
