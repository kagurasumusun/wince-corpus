Name (Key)

This property identifies the Key.

Syntax

None

Parameters

None

Return Values

Returns a String value that specifies a name of the Key.

Remarks

The default value of the Name property is a zero-length string ("").

Field names cannot be longer than 64 characters.

The Name property is read/write on Column, Group, Key, Index, Table, and User objects. This Name property is read-only on Catalog, Procedure, and View objects.

Example

The following code demonstrates how to use the Name property with a Key.

    'create primary key
    ky.Name = "fld1"
    ky.Type = adKeyPrimary
    ky.Columns.Append tblOne.Columns(0).Name

    tblOne.Keys.Append ky
    cat.Tables.Append tblOne

    Set ky = Nothing
    Set ky = CreateObject(“adoxce.key.3.1”)
    Set col = Nothing
    Set col = CreateObject(“adoxce.column.3.1”)

    ky.Name = "Key1"
    ky.Type = adKeyForeign
    ky.RelatedTable = tblOne.Name

    col.Name = tblMany.Columns(0).Name
    col.RelatedColumn = tblOne.Columns(0).Name
