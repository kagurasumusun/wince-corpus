State (Recordset)

This property describes the current state of the recordset.

recordset.State

Constants

The following table shows the valid constants for use with the State property.

Constants Value Description
adStateClosed 0 The object is closed.
adStateOpen 1 The object is open.

Return Values

This property returns a variant value.

Remarks

This read-only property defaults to adStateClosed.
