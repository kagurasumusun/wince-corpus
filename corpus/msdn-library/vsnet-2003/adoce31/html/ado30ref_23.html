MoveFirst

This method makes the first row active.

recordset.MoveFirst

Parameters

None.

Return Values

None.

Remarks

Use the MoveFirst method to move the current record position to the first record in the recordset.

Support for this method varies depending on the OLE DB provider.

This method may not be supported in some recordsets.
