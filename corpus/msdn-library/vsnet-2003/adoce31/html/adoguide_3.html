Converting Data to a Desktop

When an ADOCE database is exported from a Windows CE device, it is converted to an .mdb file on a desktop computer that can be read and manipulated by Microsoft Access. Because the Windows CE database system is less robust than Microsoft Access and other ODBC data sources, this conversion results in little or no information loss. This topic describes the conversion process in detail.

Table Conversion

Because the desktop computer name length, 64 characters, is larger than the device name length, 31 characters, no table name conversion is required.

Tables are not converted or copied to the desktop computer in the following cases:

  • The table is a system table.
  • The table does not have an entry in the MSysTables table and corresponding entries in related system tables. For example, non-ADOCE databases are not converted.

Field Conversion

Both .mdb files and .cdb files support file names of 64 characters; therefore, field names map directly from ADOCE to Microsoft Access.

Index Conversion

All indexes on the device are created on the desktop computer. If the index on the device has a name beginning with the text PrimaryKey, the index is created as a Unique index. The only other attributes that are used when tables are converted are Ascending and Descending.

Conversion Options

Windows CE filters may have user options. When converting .mdb data into the proprietary Windows CE data source format, the default for the "Overwrite existing tables" option is TRUE. When the default is used, the data in the tables is replaced with the converted data. If this option is set to FALSE, the new tables are renamed.
