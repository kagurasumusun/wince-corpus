Listing All ADOCE Tables

The MSysTables system table contains a list of all the database tables. This system table only works for the CEDB provider. It will not work for OLE DB providers.The following code example shows how to list all ADOCE tables using the RecordCount and MoveNext methods.

Dim rs, rc, strList, r
Set rs = CreateObject("ADOCE.Recordset.3.1")
‘ Views tables in the Object Store
rs.Open "MSysTables", "Provider=CEDB", adOpenKeyset, adLockOptimistic
‘ Views tables within a .cdb file
rs.Open.”MsysTables”, “\DBName.cdb”, adOpenKeyset, adLockOptimistic
rc = rs.RecordCount
For r = 0 To rc - 1
   strList = strList & rs.fields("TableName").Value & vbCrLf
   rs.MoveNext
Next
rs.Close
MsgBox strList,,"ADOCE Tables"
Set rs = Nothing
