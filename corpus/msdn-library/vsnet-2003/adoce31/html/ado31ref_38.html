RelatedColumn

This property indicates the name of the related column in the related table (key columns only).

Syntax

None

Parameters

None

Return Values

Sets and returns a String value that is the name of the related column in the related table.

Remarks

The default value is an empty string ("").

This property is read-only for Column objects already appended to a collection.

Examples

This example demonstrates how to use the RelatedColumn property.

Dim col, ky, tbl
    Set col = CreateObject("adoxce.column.3.1")
    Set ky = CreateObject("adoxce.key.3.1")
    Set tbl = CreateObject("adoxce.table.3.1")

    col.Name = "fld"
    col.Type = 2
    tbl.Name = tblOne
    tbl.Columns.Append col

    'Create primary key
    ky.Name = "fld1"
    ky.Type = adKeyPrimary
    ky.Columns.Append tbl.Columns(0).Name
    tbl.Keys.Append ky

    cat.Tables.Append tbl

    Set ky = Nothing
    Set ky = CreateObject("adoxce.key.3.1")
    Set col = Nothing
    Set col = CreateObject("adoxce.column.3.1")

    ky.Name = "Key1"
    ky.Type = adKeyForeign
    ky.RelatedTable = tbl.Name
    col.Name = tblMany.Columns(0).Name
    col.RelatedColumn = tbl.Columns(0).Name

    ky.Columns.Append col
    tblMany.Keys.Append ky

    Set tbl = Nothing
    Set col = Nothing
    Set ky = Nothing
End Sub
