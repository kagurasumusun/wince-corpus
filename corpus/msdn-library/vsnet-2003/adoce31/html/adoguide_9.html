Programming with ADOCE

The ADOCE control allows you to programmatically create and modify databases on Windows CE-based devices. The Connection object is used by the ADOCE control to connect to a data source. The cornerstone of ADOCE data access is the Recordset object. Data is read and manipulated in a database through this object. The Field object consists of the fields of a recordset. A Field object exists only in the context of a Recordset object; therefore, it should not be explicitly created. The Fields collection contains a Field object for each column in a Recordset object. The Errors collection contains information about provider data source errors, should they occur.

This section of documentation discusses how to write an application using the ADOCE control to create, access, and modify databases on a Windows CE device. For specific information about the properties, methods, and events that are supported by the ADOCE control, see the ADOCE reference that accompanies this guide.
