HelpFile

This property returns the path to a Windows CE Help file that contains information about the error generated by the data source.

error.HelpFile

Return Values

This property returns a string value.

Remarks

On a Windows CE-based device, the HelpFile property contains the path to a Windows CE Help file. If there is no Help topic or file related to the error, this property returns an empty string.

The HelpFile property is a read-only string value.
