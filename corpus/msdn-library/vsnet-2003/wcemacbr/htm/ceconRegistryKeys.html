Network Bridging Registry Settings

The registry stores information necessary to configure the system for applications and hardware devices. The registry also contains information that the operating system continually references during operation.

Microsoft® Windows® CE .NET uses the registry to control the miniport drivers that are bound to a network bridge.

The following table shows the registry settings for HKEY_LOCAL_MACHINE\Comm\Mbridge.

Value : type Description
MaxBufferMemory : REG_DWORD Default setting is 200 Kbytes. Maximum amount of memory resources used for buffering.
MaxTableMemory : REG_DWORD Default setting is 100 Kbytes. Maximum amount of memory resources used for forwarding table.
DisableSTA : REG_DWORD Spanning tree algorithm (STA) is enabled by default if this value is not specified. Enables or disables STA.
Bind : MULTI_SZ Specifies the allowable adapter for MBridge to bind. Default value not set in the registry. This entry is required and must be filled out by the OEM.
Linkage\Route : MULTI_SZ Default setting is MBRIDGE1. Specifies the adapter name exported by MBridge.
