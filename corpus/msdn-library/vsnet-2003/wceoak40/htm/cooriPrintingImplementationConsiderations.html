Printing Implementation Considerations

You can include the Printing feature in your platform by choosing the feature from the Catalog. Choosing the Printing feature sets the appropriate environmental variable for enabling the feature.

The following table shows the environmental variable that enables the Printing feature.

Environment variable Description
SYSGEN_PRINTING When this variable is set, the Printing feature is included in the OS image.

When this variable is not set, the Printing feature is excluded from the image.
