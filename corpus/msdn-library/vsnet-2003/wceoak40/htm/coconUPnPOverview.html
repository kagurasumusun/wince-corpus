Universal Plug and Play (UPnP) Overview

The Universal Plug and Play (UPnP) feature for Microsoft® Windows® CE .NET provides an architectural framework for creating self-configuring, self-describing devices and services. Networks managed by UPnP require no configuration by users or network administrators because UPnP supports automatic discovery. UPnP enables a device to dynamically join a network, obtain an IP address, and convey its capabilities on request. Control points can use the UPnP application programming interface (API) to learn about the presence and capabilities of devices that are registered on the network. A device can leave a network automatically when it is no longer in use.
