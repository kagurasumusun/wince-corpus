Operating System Features

The core operating system (OS) services provide a common foundation for all Microsoft® Windows® CE .NET operating systems. They enable low-level tasks such as process, thread, and memory management and provide some file system functionality.

The full capabilities of Windows CE are brought to your platform through operating system features. Component services, networking capabilities, multimedia support, and many other capabilities are contained within individual operating systems features.

You can select individual operating system features in Microsoft Platform Builder version 4.1 and add them to your platform. For more information, see Catalog Features. Some features require that other features be present on your platform. Platform Builder will automatically work out these dependencies and add the appropriate supporting features to your platform. For example, if you add the Voice Over IP feature to your platform, Platform Builder will automatically include, among other things, the TCP/IP feature.

Some features may have special hardware requirements and others may have special design considerations or security requirements.
