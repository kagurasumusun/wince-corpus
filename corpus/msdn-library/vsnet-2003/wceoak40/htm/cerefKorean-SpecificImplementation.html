Korean-specific Implementation

You can choose a variety of different options in the catalog for Korean-specific internationalization. Each catalog selection automatically sets a corresponding collection of environment variables that enable the feature.

The following table shows the environment variables that correspond to specific IME catalog features for Korean.

Environment variable Description
SYSGEN_K_IME97 When this variable is set, Korean IME97 will be included in the OS image.

The following table shows the environment variables that correspond to specific IM catalog features for Korean.

Environment variable Description
SYSGEN_MSIMK=0 When this variable is set, a soft keyboard that allows Hangul input will be included in the OS image.
