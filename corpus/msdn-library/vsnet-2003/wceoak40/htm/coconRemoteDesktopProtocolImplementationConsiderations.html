Remote Desktop Protocol Implementation Considerations

The following SYSGEN variables control the RDP features listed.

SYSGEN variable Feature
SYSGEN_RDP Adds base RDP components, the MSTSC executable, and the MSTSCAX ActiveX dynamic-link library (DLL).
SYSGEN_AUDIO Enables audio redirection from the server to the RDP client.
SYSGEN_PRINTING Enables local printer redirection from the server to the RDP client.
SYSGEN_REDIR Enables network printer redirection.
SYSGEN_SMARTCARD Enables smart card redirection for terminal server login and application usage. All the supported smart card drivers include this variable.
Note   The default Terminal Server Client (MSTSC) bitmaps are based upon Windows XP themes and thus have a large memory footprint. The MSTSC bitmaps have been moved to a separate library (arcxpui) that can be selected optionally to obtain the Windows XP UI. Without the arcxpui library, the autoreconnect will display a conventional win32 dialog.
There is no noticeable reduction in size because the default build retains the Windows XP User Interface by default. OEMs who want to reduce the size can remove the arcxpui library from MSTSC_COMPONENTS in cesysgen.bat.
