Web Server (HTTPD) Overview

The Web Server (HTTPD) feature for Microsoft® Windows® CE .NET supports monitoring, configuring, and remotely controlling your device through the use of a Hypertext Transfer Protocol (HTTP) server. The Web server provides this service for network printers, scanners, and other shared equipment.
