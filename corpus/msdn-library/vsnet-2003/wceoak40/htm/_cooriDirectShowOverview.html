DirectShow Overview

The DirectShow feature for Microsoft® Windows® CE .NET is an architecture for streaming media. Microsoft DirectShow® provides for high-quality playback of multimedia streams. It supports a wide variety of formats, including Advanced Streaming Format (ASF), Motion Picture Experts Group (MPEG), Audio-Video Interleaved (AVI), MPEG Audio Layer-3 (MP3), and WAV files. DirectShow is integrated with other Microsoft DirectX® technologies. It automatically detects and uses video and audio acceleration hardware when available, but also supports systems without acceleration hardware.

The DirectShow feature provides a platform with the underlying infrastructure to support the capabilities of DirectShow. This feature does not provide media codecs or filter graphs to support playback of any media. The DirectShow Audio and DirectShow Video features provide the actual codecs and rendering support for playback.

Element Information
Dependencies Requires DirectDraw and DirectSound, and Urlmon for platforms without full browser support

DirectShow simplifies media playback and format conversion. At the same time, it provides access to the underlying stream control architecture for applications that require custom solutions. You can also create your own DirectShow components to support new formats or custom effects.

Examples of the types of applications you can write with DirectShow include DVD players, video editing applications, AVI to ASF converters, and MP3 players.

DirectShow is based on the Component Object Model (COM). To write a DirectShow application, you must understand COM client programming. For most applications, you do not need to implement your own COM objects. DirectShow provides the components you need. If you want to extend DirectShow by writing your own components, however, you must implement them as COM objects.

To use the URL Reader module of DirectShow urlrdr in a platform that does not have full browser support, the platform must contain the Microsoft Internet Explorer urlmon component. If you are configuring your platform manually, you must be sure that the urlmon component is included in the IE_MODULES setting in Cesysgen.bat. This dependency is handled automatically for configurations created with Microsoft Platform Builder.
