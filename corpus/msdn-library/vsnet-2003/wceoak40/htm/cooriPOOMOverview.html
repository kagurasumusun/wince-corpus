Pocket Outlook Object Model Overview

The Pocket Outlook Object Model feature for Microsoft® Windows® CE .NET uses a modified and reduced feature set to permit Microsoft Outlook® data to be shared between a desktop computer and the more-limited storage space on a portable device. The Pocket Outlook Object Model (POOM) is based on the Outlook model.

Feature Summary

The following table shows operating system design information for Pocket Outlook Object Model.

Element Information
Dependencies The Pocket Outlook Object Model feature includes the data stores for mail, contacts, tasks, and addresses and the application programming interface (API) needed to access and manipulate these stores.
Hardware considerations None.
