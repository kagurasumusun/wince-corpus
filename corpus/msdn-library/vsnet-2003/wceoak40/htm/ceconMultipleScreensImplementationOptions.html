Multiple Screens Implementation Considerations

The Multiple Screens feature exists in a single implementation that you can either include or exclude. Choosing the Multiple Screens feature in the Platform Wizard or from the feature Catalog sets the SYSGEN_MULTIMON environment variable.

The following table shows the environment variables that enable the Multiple Screens feature.

Environment variable Description
SYSGEN_MULTIMON When this variable is set to 1, the Multiple Screens feature is included in the OS image.

When this variable is not set, the Multiple Screens feature is excluded from the image.
