Windows Media Technologies Implementation Considerations

The following table shows the relevant environmental variables.

Environment variable Description
SYSGEN_DSHOW_WMT Adds Windows Media technologies to your platform
SYSGEN_DSHOW_WMT_ASXV1 ASX v1 and M3U file support
SYSGEN_DSHOW_WMT_ASXV2 ASX v2 file support
SYSGEN_DSHOW_WMT_ASXV3 ASX v3 file support
SYSGEN_DSHOW_WMT_MULTI Windows Media multicast and multi bit rate
SYSGEN_DSHOW_WMT_NSC NSC file support
SYSGEN_DSHOW_WMT_LOCAL Windows Media streaming from local storage
SYSGEN_DSHOW_WMT_HTTP Windows Media streaming over HTTP
SYSGEN_DSHOW_WMT_MMS Windows Media streaming over MMS
