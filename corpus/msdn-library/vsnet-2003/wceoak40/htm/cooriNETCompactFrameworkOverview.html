.NET Compact Framework Beta Release Overview

The Microsoft® .NET Compact Framework Beta Release is a hardware-independent program execution environment for secure downloadable applications optimized for resource-constrained computing devices. It offers a choice of languages, initially Microsoft Visual Basic® and Microsoft Visual C#™, and eliminates the common problems faced with language interoperability.

Note   The .NET Compact Framework Beta Release is included with Windows CE .NET for experimentation purposes only. No license is allowed for including .NET Compact Framework in a final (retail) platform build. You also cannot legitimately export software development kits (SDKs) using the .NET Compact Framework Beta Release.
