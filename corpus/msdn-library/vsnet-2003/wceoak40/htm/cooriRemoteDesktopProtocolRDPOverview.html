Remote Desktop Protocol Overview

The Remote Desktop Protocol feature for Microsoft® Windows® CE .NET allows you to connect remotely to a desktop computer running Microsoft Windows NT®, Windows 2000, and Windows XP Professional, or a server running Microsoft® Windows NT® Server 4.0, Terminal Server Edition.

The Remote Desktop Protocol allows a thin client to execute Windows applications within a Windows graphical user interface (GUI) environment, even though they are actually being executed on the server.

Feature Summary

The following table shows operating system requirements for Remote Desktop Protocol.

Element Information
Dependencies A Terminal Server running RDP version 4.0 or later
Hardware considerations A serial or Ethernet connection for network communication between the Windows CE client and the server
