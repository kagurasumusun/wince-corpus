Direct3D Overview

The Direct3D feature for Microsoft® Windows® CE .NET is designed to provide easy-to-use, basic support for interactive three-dimensional (3-D) graphics applications. It is a drawing interface that provides device-dependent access to 3-D video-display hardware in a device-independent manner.

Microsoft Direct3D® is a low-level 3-D application programming interface (API) that is ideal for developers who need to enable 3-D applications such as advertising displays, computer-aided design (CAD) applications, games, and other high-performance multimedia applications.

Rendering 3-D graphics is a very computationally intensive process. Although Direct3D does provide a software emulation mode, the reality is that your device will require 3-D graphics rendering hardware to run all but the simplest Direct3D applications. Additionally, Direct3D is only supported on floating point enabled CPUs.
