Touch Screen (Stylus) Implementation Considerations

You can include the Touch Screen (Stylus) feature in your platform by choosing the feature from the Catalog. Choosing the Touch Screen (Stylus) feature sets the appropriate environmental variable for enabling the feature.

The following table shows the environmental variable that enables the Touch Screen (Stylus) features.

Environment variable Description
SYSGEN_TOUCH When this variable is set, the Touch Screen (Stylus) feature is included in the OS image.

When this variable is not set, the Touch Screen (Stylus) feature is excluded from the image.
