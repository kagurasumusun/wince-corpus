Adding Internet Options to the Control Panel

When you add the sample Internet Explorer 5.5 Internet Options Control Panel (SYSGEN_INETCPL) to your project, the shell Control Panel will include an icon for Internet Options. The Internet Settings property pages allow the user to set Start and Search pages, clear Cache and History, and specify connection and security settings. Complete source files for the Internet Control Panel Feature are in the %_WINCEROOT%\Public\IE\OAK\INETCPL folder.

For information about customizing the user interface, see Creating a Custom Shell.
