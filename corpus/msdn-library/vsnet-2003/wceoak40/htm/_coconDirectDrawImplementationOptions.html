DirectDraw Implementation Considerations

The DirectDraw feature is implemented as a single unit. The only complexity with including DirectDraw on your platform is to make sure that your 2-D graphics hardware and drivers are DirectDraw enabled.

If you are considering porting existing DirectDraw code from the Windows desktop, you should keep in mind that there are specific hardware-related situations where the Windows CE implementation behaves differently than the Windows desktop implementation. Key differences are as follows:

  • DirectDraw cannot change the display mode. It can only operate in the mode that is set for the Windows CE device.
  • On platforms with multiple screens, DirectDraw will only work on the primary display device. All other screens are left under the control of the graphics device interface (GDI).
  • DirectDraw is not supported on platforms with screen rotation. DirectDraw and screen rotation are mutually exclusive features. The rflat driver does not have any DirectDraw entry points.

The following table shows the environment variables that enable the DirectDraw feature.

Environment variable Description
SYSGEN_DIRECTDRAW Set to the value 1 to enable DirectDraw.
