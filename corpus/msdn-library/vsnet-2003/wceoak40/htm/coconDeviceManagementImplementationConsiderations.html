Device Management Implementation Considerations

The following table shows the SYSGEN variables that control the device management features listed.

SYSGEN variable Description
SYSGEN_SERVICES Equips the build with Services.exe within which the device management engine runs.
SYSGEN_OLE_GUIDS Allows you to generate globally unique identifiers (GUIDs).
SYSGEN_CRYPTO Needed for security features.
__SYSGEN_WCELOAD Includes Wceload and Unload, which are needed for installing and uninstalling packages.
SYSGEN_URLMON Needed for URL resolution.
