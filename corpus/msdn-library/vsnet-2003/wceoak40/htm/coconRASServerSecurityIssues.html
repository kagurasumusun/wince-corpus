RAS Server Implementation Considerations

A RAS server can be configured through the use of the RasIOControl function or by setting registry values. RasIOControl can be used to change settings dynamically while the system is running. Registry value settings are only read at system boot time. Note that whenever RasIOControl is used to change RAS server settings it will automatically update the registry settings so that the changes will remain in effect across system warm boots.

The following configuration tasks can be performed through RasIOControl:

  • Globally enable or disable the RAS server
  • Configure the lines on which the server should listen for incoming calls
  • Set the allowed authentication types
  • Set the supported data encryption types
  • Allow or disallow TCP header and data compression
  • Set the allowed user names and passwords
