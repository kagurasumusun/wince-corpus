Smart Card Services Overview

The Smart Card Services feature for Microsoft Windows CE provides a smart card subsystem to link the smart card reader hardware and applications that are smart card aware. The subsystem consists of the resource manager application programming interface, reader hardware device drivers, reader helper library, and base service providers. Additionally, the subsystem supports CryptoAPI and the Windows CE device driver model.

The Smart Card cryptographic service provider (CSP) for Windows CE is based on the Windows for Smart Card desktop operating system.
