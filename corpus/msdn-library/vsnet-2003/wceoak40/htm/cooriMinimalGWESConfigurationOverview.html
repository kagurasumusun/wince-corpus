Minimal Configurations Overview

The Minimal Configuration features for Microsoft® Windows® CE .NET allow you to build platforms that have levels of Graphics, Windowing, and Events Subsystem (GWES) support that are intermediate between the headless platforms and display-based platforms that Windows CE provides.

The following table describes the Minimal Configuration features.

Feature Description
Minimal GWES Configuration Provides basic windowing and message queue support
Minimal Notifications Configuration Provides support for notifications
Minimal Input Configuration Provides support for keyboard input
Minimal GDI Configuration Provides graphics device interface (GDI) support, including TrueType fonts, text drawing, and palette support
Minimal Window Manager Configuration Provides support for window management

Feature Summary

The following table shows operating system design information for the Minimal Configuration features.

Element Information
Dependencies The Minimal GWES Configuration requires the Device Manager feature.

The Minimal Notifications Configuration requires the Minimal GWES Configuration and Database Support features.

The Minimal Input Configuration requires the Minimal GWES Configuration and the System Password features.

The Minimal GDI Configuration requires the Minimal Input Configuration feature and either the National Language Support (NLS) feature or the English (US) National Language Support only feature.

The Minimal Window Manager Configuration requires the Minimal GDI Configuration and Waveform Audio features.
Hardware considerations None.
