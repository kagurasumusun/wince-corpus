User Interface Implementation Considerations

The User Interface feature is included in all display-based platforms by default. You can, however, choose a shell and set custom options by choosing features from the Catalog or by setting appropriate environmental variables.

The following table shows the environmental variable for the User Interface feature.

Environment variable Description
SYSGEN_XPSKIN When this variable is set, the Windows XP-like Sample Skin is included in the OS image.

When this variable is not set, the Windows XP-like Sample Skin is excluded from the OS image.
SYSGEN_REPLACESKIN When this variable is set, a custom skin is included in the OS image.

When this variable is not set, a custom skin is excluded from the OS image.
SYSGEN_MENU_OVERLAP When this variable is set, the Overlapping Menus feature is included in the OS image.

When this variable is not set, the Overlapping Menus feature is excluded from the OS image.
SYSGEN_MENU_TAP_UI When this variable is set, Tap UI Menus are included in the OS image.

When this variable is not set, Tap UI Menus are excluded from the OS image.
SYSGEN_STANDARDSHELL When this variable is set, the Standard Shell feature is included in the OS image.

When this variable is not set, the Standard Shell feature is excluded from the OS image.
SYSGEN_TASKMAN When this variable is set, the Taskman Sample Shell feature is included in the OS image.

When this variable is not set, the Taskman Sample Shell feature is excluded from the OS image.
SYSGEN_WBTSHELL When this variable is set, the Windows Thin Client Shell feature is included in the OS image.

When this variable is not set, the Windows Thin Client Shell feature is excluded from the OS image.
