Digital Rights Management Implementation Considerations

There are some special implementation considerations that you must take into account when you include the Digital Rights Management (DRM) feature in your platform. First, you must obtain a custom signed DRM module from Microsoft. Second, the presence of DRM on a platform also affects debugging on that platform.

Adding DRM to your platform

Although DRM appears in the Microsoft Platform Builder feature Catalog, the software components that enable DRM do not ship with Platform Builder. An OEM wanting to include DRM on its platform must register with Microsoft to obtain the necessary DRM components. Microsoft will then provide unique, digitally signed components to the OEM. Although these components are unique to each OEM, they can play back any DRM version 7 protected content. To request licensing instructions for DRM version 7 in Windows CE, send e-mail to wmla@microsoft.com.

If you do not have signed DRM components and still attempt to include DRM in your platform, your build will fail.

Your platform must support a unique 128-byte device identifier that can be exposed through OEMIoControl calls using the IOCTL_HAL_GET_DEVICEID I/O control code. For more information about formatting the device identifier, see DEVICE_ID. For applications to be able to read protected content from those media, your platform must also be able to read device identifiers from portable storage media, such as compact flash.

Debugging with DRM

To maintain the integrity of DRM, Platform Builder does not allow kernel debugging when DRM components are present on a platform. If you plan to include DRM in your platform, you should plan to incorporate DRM at the end of your development cycle so that you can debug the rest of your platform first.

DRM also has a similar affect on application development. For more information, see Writing Applications on DRM-Enabled Platforms.

Specific DRM Features

The following table shows the individual features your platform can contain for Digital Rights Management. Your platform can contain one or more of these features.

Feature Description
DRM for Portable Devices Provides the core functionality for DRM. It allows you to transfer content from a desktop computer to the local store of a Windows CE device or to a supported portable media device connected to a Windows CE device.
License Acquisition OCX Allows a Windows CE platform to negotiate the request, acceptance, and transfer of DRM licenses from Microsoft DRM license servers.
