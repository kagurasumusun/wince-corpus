Simplified Chinese-specific Implementation

You can choose a variety of different options in the catalog for Simplified Chinese-specific internationalization. Each catalog selection automatically sets a corresponding collection of environment variables that enable the feature.

The following table shows the environment variables that correspond to specific IME catalog features for Simplified Chinese.

Environment variable Description
SYSGEN_MSPY2_SC When this variable is set, the MSPY2 IME binaries will be included in the OS image.
SYSGEN_MSPY2_DB_1 When this variable is set, the 1.1MB database will be included in the OS image.

The user must set one of the DB_1, DB_3, or DB_7 databases.
SYSGEN_MSPY2_DB_3 When this variable is set, the 1.3MB database will be included in the OS image.

The user must set one of the DB_1, DB_3, or DB_7 databases.
SYSGEN_MSPY2_DB_7 When this variable is set, the 1.7MB database will be included in the OS image.

The user must set one of the DB_1, DB_3, or DB_7 databases. By default, if the user does not set a database, the 1.7MB database will be included in the image.

The following table shows the environment variables that correspond to specific IM catalog features for Simplified Chinese.

Environment variable Description
SYSGEN_PIME_SC When this variable is set, the Simplified Chinese Shuang Pin IME and IM will be included in the OS image.
