Japanese-specific Implementation

You can choose a variety of different options in the catalog for Japanese-specific internationalization. Each catalog selection automatically sets a corresponding collection of environment variables that enable the feature.

The following table shows the environment variables that correspond to specific IME catalog features for Japanese.

Environment variable Description
SYSGEN_IME98 When this variable is set, IME98 will be included in the OS image.
SYSGEN_IME98_COMPACT_DATA When this variable is set, the compact system dictionary will be included in the OS image. By default, if you include IME98 in the OS image, this database is selected.

You must choose either the compact dictionary or the standard dictionary with IME98.
SYSGEN_IME98_STANDARD_DATA When this variable is set, the standard system dictionary will be included in the OS image.

You must choose either the compact dictionary or the standard dictionary with IME98.
SYSGEN_PIME When this variable is set, Pocket IME will be included in the OS image.
SYSGEN_PIME_SUPPLEMENTAL_DATA When this variable is set, a supplemental dictionary will be included in the OS image.
SYSGEN_PIME_NAME_PLACE_DATA When this variable is set, a name and place dictionary will be included in the OS image.
SYSGEN_TESTIME When this variable is set, TESTIME will be included in the OS image.

The following table shows the environment variables that correspond to specific IM catalog features for Japanese.

Environment variable Description
SYSGEN_IM_RADICAL When this variable is set, search by radical engine that enables Kanji character selection by radical will be included in the OS image.
SYSGEN_IM_STROKE When this variable is set, search by stroke engine that enables Kanji character selection by character stroke will be included in the OS image.
SYSGEN_IM_KANA When this variable is set, an on-screen keyboard that enables input of Hiragana and Katakana will be included in the OS image.
SYSGEN_IM_ROMA When this variable is set, an on-screen keyboard that enables input of Western alphabet will be included in the OS image.
