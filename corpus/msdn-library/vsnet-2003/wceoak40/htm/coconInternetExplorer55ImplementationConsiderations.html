Internet Explorer 5.5 Implementation Considerations

The following table shows the functionality of the Internet Explorer modules and their dependencies.

Sysgen flag Description Run-time dependency
SYSGEN_MSHTML Provides core browser functionality including display and layout, HTML editing, forms, cookies, cache, cascading style sheets, Microsoft ActiveX® Framework, DHTML, Java language applet support, HTML component (htc), and offline browsing. Requires Mlang.dll and Urlmon.dll.
SYSGEN_MLANG Provides support for multiple languages and editing. Requires Shdocvw.dll and Mshtml.dll.
SYSGEN_SHDOCVW Provides the default implementations for the browser UI. OLE Control implementation providing an ActiveX interface for shell and mshtml document viewing.
Includes WebBrowser control, context menu, and file download support. 		Requires Mlang.dll and Mshtml.dll.
SYSGEN_URLMON Provides support for URL monikers, asynchronous pluggable protocols, hit logging, and security zones. Requires Wininet.dll.
SYSGEN_WININET Provides interface with Windows Sockets.Caching, support for FTP and HTTP, SSL2 and SSL3, and Passport authentication. Requires Windows Sockets.
SYSGEN_JSCRIPT Microsoft JScript® 5.5 host scripting engine.  
SYSGEN_VBSCRIPT Microsoft VBScript® 5.5 host scripting engine.  
SYSGEN_IESAMPLE Sample browser UI (Iesample.exe). Requires Shdocvw.dll.
