Command Processor Implementation Considerations

You can include the Command Processor and Console Window features in your platform by choosing these features from the Catalog. Choosing one of these features sets the appropriate environmental variable for enabling the feature.

The following table shows the environmental variables that enable the Command Processor and Console Window features.

Environment variable Description
SYSGEN_CMD When this variable is set, the Command Processor feature is included in the OS image.

When this variable is not set, the Command Processor feature is excluded from the image.
SYSGEN_CONSOLE When this variable is set, the Console Window feature is included in the OS image.

When this variable is not set, the Console Window feature is excluded from the image.
