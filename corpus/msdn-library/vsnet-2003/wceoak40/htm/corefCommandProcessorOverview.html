Command Processor Overview

The Command Processor feature for Microsoft® Windows® CE .NET includes a command processor shell (Cmd.exe) that is similar to Command.com in Windows 95 and Cmd.exe in Microsoft Windows NT®. The command processor shell is a command-line-driven shell that provides a limited number of commands. The Console Window feature is available on display-based systems to provide a window through which the Command Processor can provide output and accept input.

Feature Summary

The following table shows operating system design information for the Command Processor and Console Window features.

Element Information
Dependencies The Command Processor feature requires the Standard IO (STDIO) feature. For headless platforms, the Command Processor feature also requires the FormatMessage API and Full C Run-Time features and either the National Language Support (NLS) feature or the English (US) National Language Support only feature. The Console Window feature requires the Command Processor feature.
Hardware considerations None.
