Software-based Input Panel Implementation Options

You can include the Software-based Input Panel features in your platform by choosing the features from the Catalog. Choosing the Software-based Input Panel features set the appropriate environmental variable for enabling the features.

The following table shows the environmental variables that enable the Software-based Input Panel features.

Environment variable Description
SYSGEN_SOFTKB When this variable is set, the SIP driver is included in the OS image.

When this variable is not set, the SIP driver is excluded from the image.
SYSGEN_MSIM When this variable is set, the SIP for Small Screens feature is included in the OS image.

When this variable is not set, the SIP for Small Screens feature is excluded from the image.
SYSGEN_LARGEKB When this variable is set, the SIP for Large Screens feature is included in the OS image.

When this variable is not set, the SIP for Large Screens feature is excluded from the image.
SYSGEN_SIPSELECT When this variable is set, the Input Method Selection Sample Application is included in the OS image.

When this variable is not set, the Input Method Selection Sample Application is excluded from the image.
