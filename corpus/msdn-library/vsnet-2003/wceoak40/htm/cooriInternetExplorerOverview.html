Internet Explorer 5.5 Overview

The Internet Explorer 5.5 feature for Microsoft® Windows® CE .NET provides an HTML/DHTML parsing and rendering engine, a browser control host, a simple browser UI, television-style navigation, and multiple-language support. The browser control host and HTML engine are comparable in functionality to that of Microsoft Internet Explorer 5.5.
