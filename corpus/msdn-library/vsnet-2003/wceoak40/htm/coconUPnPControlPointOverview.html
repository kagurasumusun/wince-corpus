Control Point API Overview

The Control Point API feature for Microsoft® Windows® CE .NET uses the Universal Plug and Play (UPnP) application programming interface (API) to learn about the presence and capabilities of devices that are registered on the network. A device can leave a network automatically when it is no longer in use.
