Mouse Implementation Considerations

You can include the Mouse feature in your platform by choosing the feature from the Catalog. Choosing the Mouse feature sets the appropriate environmental variable for enabling the feature.

The following table shows the environmental variable that enables the Mouse feature.

Environment variable Description
SYSGEN_CURSOR When this variable is set, the Mouse feature is included in the OS image.

When this variable is not set, the Mouse feature is excluded from the image.
