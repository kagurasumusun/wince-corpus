Traditional Chinese-specific Implementation

You can choose a variety of different options in the catalog for Traditional Chinese-specific internationalization. Each catalog selection automatically sets a corresponding collection of environment variables that enable the feature.

The following table shows the environment variables that correspond to specific IME catalog features for Traditional Chinese.

Environment variable Description
SYSGEN_PIME_TC When this variable is set, the Traditional Chinese Pocket IME and IM binaries will be included in the OS image.
Note   For the Chinese Pocket IME, the input methods are tightly related and cannot be used as a separate component for installation.
