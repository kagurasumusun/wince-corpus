Minimal Configurations Implementation Options

You can include the Minimal Configuration features in your platform by choosing these features from the Catalog. Choosing a Minimal Configuration feature sets that appropriate environmental variable for enabling the feature.

The following table shows the environmental variables that enable the Minimal Configuration features.

Environment variable Description
SYSGEN_MINGWES When this variable is set, the Minimal GWES Configuration is included in the OS image.

When this variable is not set, the Minimal GWES Configuration is excluded from the image.
SYSGEN_MINNOTIFY When this variable is set, the Minimal Notifications Configuration is included in the OS image.

When this variable is not set, the Minimal Notifications Configuration is excluded from the image.
SYSGEN_MININPUT When this variable is set, the Minimal Input Configuration is included in the OS image.

When this variable is not set, the Minimal Input Configuration is excluded from the image.
SYSGEN_MINGDI When this variable is set, the Minimal GDI Configuration is included in the OS image.

When this variable is not set, the Minimal GDI Configuration is excluded from the image.
SYSGEN_MINWMGR When this variable is set, the Minimal Window Manager Configuration is included in the OS image.

When this variable is not set, the Minimal Window Manager Configuration is excluded from the image.
