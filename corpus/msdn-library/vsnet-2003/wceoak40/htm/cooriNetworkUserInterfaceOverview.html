Network User Interface Overview

The Network User Interface feature for Microsoft® Windows® CE .NET defines configuration settings for the Network and Dial-up Connections icon in Control Panel. Network User Interface provides a set of dialog boxes that could be used by other applications. You can modify or omit these dialog boxes to match the users' experience desired for their devices.

You can find the source code for the implemented dialog boxes in the %_WINCEROOT%\Public\Common\Oak\Drivers\Netui directory.
