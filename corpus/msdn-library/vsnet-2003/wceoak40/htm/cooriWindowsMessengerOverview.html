Windows Messenger Overview

The Windows® Messenger application in Microsoft® Windows CE provides a real–time voice and text communications. Windows Messenger is presence–enabled, which means that you can see who is available online before you try to contact them and you can control your online status as displayed to others, as well as to whom that status is displayed.

The Windows Messenger client application has two backends:

  1. The Communications Service. This is based on the Session Initiation Protocol and coupled with the RTC (Real Time Communications) Client API, thus enabling communication via an SIP server in the enterprise.
  2. .NET Messenger Service. This enables you to communicate with contacts using a .NET Passport.
