Creating a Browser Container Application

When you add the Internet Explorer 5.5 sample browser (SYSGEN_IESAMPLE) to your project, your operating system includes a simple browser shell application, Iesample.exe. This browser shell includes a standard menu bar and address window. If you are creating a custom browser shell, you should use this sample browser as a starting point.

Platform Builder also includes sample code for a full-screen browser container called "IESIMPLE", which you can modify, compile, and incorporate into your operating system image. The IESIMPLE sample code is located at %_WINCEROOT%\Public\IE\OAK\IESimple.

For more information, see Creating an Internet Browser Container Application.
