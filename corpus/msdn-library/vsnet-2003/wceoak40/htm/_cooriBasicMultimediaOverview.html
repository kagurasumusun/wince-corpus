Basic Multimedia Overview

The basic multimedia features for Microsoft® Windows® CE .NET are provided to make it easy for you to add support to your platform for common multimedia tasks. These features are a subset of the full range of multimedia features available in Windows CE. You can use these features to add simple sound support as well as playback local or streaming support for common media formats.

These features do not need to be added to your platform as a group. You can choose among them and only include the ones that meet the needs of your platform.

Brief descriptions of the basic multimedia features are provided below along with links to more detailed information.

Waveform Audio

This feature provides basic support for sound playback and capture. It includes an application programming interface (API) to support playback and capture as well as an API to support a hardware audio mixer. For more information, see Waveform Audio Overview.

WMA and MP3 Local Playback

This feature provides support for playing Windows Media Audio (.wma) or MP3 files from local storage such as system memory or Compact Flash memory. This is an audio-only feature and does not provide any video playback capabilities. All media decoding is done through Microsoft DirectShow® filters. For more information, see DirectShow Overview.

WMA and MP3 Streaming

This feature provides support for playing Windows Media Audio (.wma) or MP3 files from a streaming source. This feature also has the ability to play back from local storage such as system memory or Compact Flash memory. This is an audio-only feature and does not provide any video playback capabilities. All media decoding is done through DirectShow filters. For more information, see DirectShow Overview.

WMV and MPEG-4 Streaming

This feature provides support for playing Windows Media Video (.wmv) or MPEG-4 files from a streaming source. This feature also has the ability to play back from local storage such as system memory or Compact Flash memory. This feature provides both audio and video output for .wmv and MPEG-4 sources. All media decoding is done through DirectShow filters. For more information, see DirectShow Overview.
