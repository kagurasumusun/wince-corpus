IUPnPDeviceFinder:IDispatch

This interface enables an application to find a device.

The following table lists and describes this interface's members.

Method Description
IUPnPDeviceFinder::CancelAsyncFind Cancels an asynchronous search.
IUPnPDeviceFinder::CreateAsyncFind Creates an asynchronous search.
IUPnPDeviceFinder::FindByType Searches synchronously for devices by device or service type.
IUPnPDeviceFinder::FindByUDN Searches synchronously for a device by its UDN.
IUPnPDeviceFinder::StartAsyncFind Starts an asynchronous search.

Requirements
