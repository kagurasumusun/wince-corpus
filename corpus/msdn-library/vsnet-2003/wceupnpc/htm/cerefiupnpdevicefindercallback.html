IUPnPDeviceFinderCallback:IDispatch

This interface allows UPnP to communicate the results of an asynchronous search to an application.

The following table lists and describes this interface's members.

Method Description
IUPnPDeviceFinderCallback::DeviceAdded Indicates that a device has been added to the network.
IUPnPDeviceFinderCallback::DeviceRemoved Indicates that a device has been removed from the network.
IUPnPDeviceFinderCallback::SearchComplete Indicates that a search for all network devices has been completed.
