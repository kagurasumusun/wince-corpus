waveInClose

This function closes the specified waveform-audio input device.

MMRESULT waveInClose(
HWAVEIN hwi 
);

Parameters

hwi
Handle to the waveform-audio input device. If the function succeeds, the handle is no longer valid after this call.

Return Values

One of the values described in the following table is returned.

Value Description
MMSYSERR_NOERROR Success.
MMSYSERR_INVALHANDLE Specified device handle is invalid.
MMSYSERR_NODRIVER No device driver is present.
MMSYSERR_NOMEM Unable to allocate or lock memory.
WAVERR_STILLPLAYING There are still buffers in the queue.

Remarks

If there are input buffers that have been sent with the waveInAddBuffer function and that have not been returned to the application, the close operation will fail. Call the waveInReset function to mark all pending buffers as done.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Mmsystem.h   Coredll.lib
