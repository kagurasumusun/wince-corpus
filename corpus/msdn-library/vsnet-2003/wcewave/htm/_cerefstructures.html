Waveform Audio Structures

The following table shows the structures that used by the wave API.

Structure Description
MMTIME Contains timing information for different types of multimedia data.
PEG_USER_NOTIFICATION Contains user notification settings and preferences.
WAVEFORMATEX Defines the format of waveform-audio data.
WAVEHDR Defines the header used to identify a waveform-audio buffer.
WAVEINCAPS Describes the capabilities of a waveform-audio input device.
WAVEOUTCAPS Describes the capabilities of a waveform-audio output device.
