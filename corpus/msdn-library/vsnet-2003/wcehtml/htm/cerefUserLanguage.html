userLanguage

This property retrieves the operating system's natural language setting.

[ sLanguage = ] object.userLanguage

Possible Values

sLanguage is a string that receives the language code from the system.

The property is read-only and has no default value.

Remarks

This property reflects the setting in the Your locale (location) box in the Regional Options of Control Panel — for example, English (United States).

Applies To

clientinformation, navigator objects
