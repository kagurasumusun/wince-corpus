MSHTML Interfaces

The following table shows the interfaces that are supported in MSHTML in Microsoft Windows CE .NET and the corresponding scripting objects. For more information about these interfaces and scripting objects, see this Microsoft Web site.

Interface Description Corresponding object
ICustomDoc Implemented by MSHTML to allow a host to set the MSHTML IDocHostUIHandler interface. Not scriptable
IDisplayPointer Provides methods that control display pointers, which enable you to mark sections of an HTML document for editing, based on the document's onscreen rendering. Not scriptable
IDisplayServices Provides methods that enable you to work with display pointers and the insertion point as they relate to the onscreen layout. Not scriptable
IDocHostShowUI Allows a host to supply mechanisms for showing message boxes and Help. Not scriptable
IDocHostUIHandler This custom interface enables an application hosting the WebBrowser Control or automating Microsoft Internet Explorer to replace the menus, toolbars, and context menus used by MSHTML. Not scriptable
IDocHostUIHandler2 This custom interface extends IDocHostUIHandler with a method that facilitates Internet Explorer registry changes. Not scriptable
IElementBehavior Provides a notification mechanism so that MSHTML can communicate with a behavior. Not scriptable
IElementBehaviorCategory Used to identify a DHTML behavior by category. Not scriptable
IElementBehaviorFactory Provides a standard mechanism for MSHTML to locate and instantiate a DHTML behavior. Not scriptable
IElementBehaviorFocus Allows an element behavior to provide its own focus rectangle. Not scriptable
IElementBehaviorRender Implemented by a binary element behavior in order to take part in the layout process. Not scriptable
IElementBehaviorSite Provides communication between MSHTML and a DHTML behavior. Not scriptable
IElementBehaviorSiteCategory Provides DHTML behaviors with a way of identifying other behaviors by category. Not scriptable
IElementBehaviorSiteOM Provides event services to DHTML behaviors. Not scriptable
IElementBehaviorSubmit Allows element behaviors resident in a form to submit data. Not scriptable
IElementNamespace Provides a standard mechanism for creating an element behavior. Not scriptable
IElementNamespaceFactory Provides a standard mechanism for creating element behaviors for a namespace. Not scriptable
IElementNamespaceFactoryCallback Provides a standard mechanism for hosts of MSHTML to resolve tagnames. Not scriptable
IElementNamespaceTable Provides a mechanism for a host of MSHTML to add its own namespaces and to create tags for those namespaces. Not scriptable
IElementSegment Provides methods that control a fragment of HTML markup in the current editable selection that consists of a single element. Not scriptable
IHighlightRenderingServices Provides methods that enable you to control which sections of a document are highlighted on the screen and the style of highlighting. Not scriptable
IHighlightSegment Enables you to control a highlighted section of a document. Not scriptable
IHTMLAnchorElement Designates the destination of a hypertext link. a
IHTMLAnchorElement2 Designates the destination of a hypertext link. It extends the IHTMLAnchorElement interface. a
IHTMLAreaElement Specifies the shape of a hot spot in a client-side image map. area
IHTMLAreasCollection A collection of areas that make up the image map. areas
IHTMLAreasCollection2 Extends the IHTMLAreasCollection interface. areas
IHTMLAttributeCollection Provides the ability to programmatically access items in an element's attribute collection. attributes
IHTMLAttributeCollection2 Extends the IHTMLAttributeCollection interface. attributes
IHTMLBaseElement Specifies the document's base URL. base
IHTMLBaseFontElement Sets a base font value to use as the default font when rendering text. baseFont
IHTMLBGsound Provides the methods for controlling background sound elements. bgSound
IHTMLBlockElement Provides access to properties and methods available to most block elements. Not scriptable
IHTMLBodyElement Provides access to the body element, and specifies the beginning and end of the document body. BODY
IHTMLBodyElement2 Provides additional access to the body element. BODY
IHTMLBookmarkCollection Provides the ability to programmatically access items in a bookmark collection. BODY
IHTMLBRElement Inserts a line break. br
IHTMLButtonElement Renders content as an HTML button. button
IHTMLCaret Provides methods that control the insertion point (caret) in the editor. Not scriptable
IHTMLChangeLog Provides a method to retrieve information stored in a change log about the changes in a markup container. Not scriptable
IHTMLChangePlayback Provides a method to play back change records from a change log. Not scriptable
IHTMLChangeSink Provides notification when a change has occurred in a markup container's contents. Not scriptable
IHTMLCommentElement Indicates a comment that will not be displayed. comment
IHTMLComputedStyle Provides access to the current style of objects as they are displayed on the screen. The interface also enables you to take a snapshot of the internal formatting of one object at a particular point in time and compare it to the internal formatting of another object. Not scriptable
IHTMLControlElement A base interface for control type elements such as IHTMLImgElement. Not scriptable
IHTMLControlRange Contains a range of control type elements. It is used for control selection and represents an array of controls that can be operated on as a group. Not scriptable
IHTMLCurrentStyle Provides the ability to programmatically access the element's style properties. Not scriptable
IHTMLCurrentStyle2 Enables you to programmatically access the style properties of an element. Not scriptable
IHTMLDataTransfer Provides access to predefined clipboard formats for use in data transfer operations. Not scriptable
IHTMLDDElement Provides access to the dd object. dd
IHTMLDialog Provides access to information about an HTML dialog box. window
IHTMLDialog2 Provides access to information about an HTML dialog box. window
IHTMLDialog3 Provides access to information about an HTML dialog box. window
IHTMLDivElement Used with the IHTMLElement::className property to represent different kinds of containers. div
IHTMLDivPosition Enables you to specify how adjacent text is aligned with respect to a div object. Not scriptable
IHTMLDListElement Denotes a definition list. dl
IHTMLDocument Used to retrieve information about a document, to examine and modify the HTML elements and text within the document, and to process related events. A document object represents the HTML document in a given browser window. document
IHTMLDocument2 Retrieves information about the document, and examines and modifies the HTML elements and text within the document. document
IHTMLDocument3 Provides access to additional properties and methods of the document objects. document
IHTMLDocument4 Provides access to additional properties and methods of the document object, which represents the HTML document in a given browser window. document
IHTMLDOMAttribute Provides the ability to programmatically access the properties and methods that are common to all element objects. attribute
IHTMLDOMChildrenCollection Provides the ability to programmatically access and manipulate items in the collection. BODY
IHTMLDOMImplementation Provides the ability to programmatically access all the nodes in the document object model (DOM), iterate the nodes, insert and remove nodes, and retrieve the attributes of a node. implementation
IHTMLDOMNode Provides the ability to programmatically access all the nodes in the document object model (DOM), iterate the nodes, insert and remove nodes, and retrieve the attributes of a node. document
IHTMLDOMTextNode Provides the ability to programmatically access the data in a document object model's (DOM) text node. TextNode
IHTMLDTElement Provides access for controlling the text wrapping characteristics of the IHTMLDTElement object. dt
IHTMLEditHost Enables you to customize the way elements are resized and moved. Not scriptable
IHTMLEditServices Provides methods that enable you to add or remove edit designers and control the current selection. Not scriptable
IHTMLElement Provides the ability to programmatically access the properties and methods that are common to all element objects. All element objects
IHTMLElement2 Enables you to programmatically access the properties and methods that are common to all element objects. All element objects
IHTMLElement3 Enables you to programmatically access the properties and methods that are common to all element objects. All element objects
IHTMLElementCollection Provides access to a collection of element objects. elements
IHTMLElementCollection2 Extends the IHTMLElementCollection interface. elements
IHTMLElementDefaults Provides the ability to programmatically set default properties on an element behavior. defaults
IHTMLEmbedElement Provides access to the embed object. Not scriptable
IHTMLEventObj Provides access to the event processes, such as the element in which the event occurred, the state of the keyboard keys, the location of the mouse, and the state of the mouse buttons. event
IHTMLEventObj2 Provides access to the IHTMLEventObj interface and to other properties of the event, such as attributes and bookmarks. event
IHTMLEventObj3 Provides access to the IHTMLEventObj interface and event properties that provide information such as the state of the keyboard keys. event
IHTMLFieldSetElement Draws a box around the text and other elements it contains. This element is useful for grouping elements in a form and for distinctively marking text in a document. fieldSet
IHTMLFontElement Specifies a new font face, size, and color to use for rendering the enclosed text. font
IHTMLFontNamesCollection Collects all the font names supported by the system. The collection is created by using the system font enumeration calls. Not scriptable
IHTMLFontSizesCollection Collects all the font sizes available for a font on the system. The collection of fonts and sizes that this is built from is maintained in the IHTMLOptionsHolder object. This interface is returned when that collection is accessed. Not scriptable
IHTMLFormElement Specifies that the contained controls take part in a form. form
IHTMLFormElement2 Extends the IHTMLFormElement interface. form
IHTMLFrameBase Provides access to properties and methods that are common to frame and iframe elements. Not scriptable
IHTMLFrameBase2 Provides access to an additional method that is common to the IHTMLFrameElement and IHTMLIFrameElement objects. Not scriptable
IHTMLFrameElement Specifies an individual frame within a frameSet. frame
IHTMLFrameElement2 Specifies an individual frame within an IHTMLFrameSetElement. frame
IHTMLFramesCollection2 A zero-based collection of all frame elements if the document contains the frameSet element. frames
IHTMLFrameSetElement Specifies a frameset. frameSet
IHTMLGenericElement Provides data binding capabilities to an element. xml
IHTMLHeaderElement Renders text as a heading style. H1 through H6
IHTMLHRElement Draws a horizontal rule. hr
IHTMLIFrameElement Creates inline floating frames. iframe
IHTMLImageElementFactory Used to create new instances of the img element. Not scriptable
IHTMLImgElement Provides access to some of the properties and methods supported by the img element and the input element of the image type. The other properties and methods are accessible through the IHTMLImgElement interface. Common properties of img, input, input type=image
IHTMLInputButtonElement Specifies a type of input control. input, input type=reset, input type=submit
IHTMLInputElement Specifies any type of input control. input, input type=checkbox, input type=file, input type=hidden, input type=image, input type=password, input type=radio, input type=reset, input type=submit, input type=text
IHTMLInputFileElement Specifies a type of input control. input, input type=file
IHTMLInputHiddenElement Specifies a type of input control. input, input type=hidden
IHTMLInputImage Specifies a type of input control. input, input type=image
IHTMLInputTextElement Specifies a type of input control. input, input type=password, input type=text
IHTMLIsIndexElement Indicates that the document contains a searchable index. isIndex
IHTMLLabelElement Specifies a label for a control-like element. label
IHTMLLegendElement Inserts a caption into the box drawn by the fieldSet element. If given, this element must be the first element in fieldSet. legend
IHTMLLIElement Denotes one item of a list. li
IHTMLLinkElement Provides methods to access a link element that is used to specify a link to an external document. link
IHTMLLinkElement2 Provides access to additional properties and methods of link element objects. link
IHTMLLocation Contains information about the current URL. location
IHTMLMapElement Specifies a collection of hot spots for a client-side image map. map
IHTMLMarqueeElement Used to specify a marquee element. marquee
IHTMLMetaElement Represents the meta element. meta
IHTMLMetaElement2 Provides access to additional properties for the meta element. meta
IHTMLMimeTypesCollection Exists for compatibility with other browsers. Not scriptable
IHTMLNamespace Exists for compatibility with other browsers. namespace
IHTMLNamespaceCollection A collection of all namespace objects associated with the document. namespaces
IHTMLNextIdElement Provides access to the methods associated with the nextID element. nextID
IHTMLObjectElement Inserts an object into the HTML page. object
IHTMLObjectElement2 Denotes an object on an HTML page. draws text and HTML as an ordered list. object
IHTMLOListElement Draws text and HTML as an ordered list. ol
IHTMLOpsProfile Provides methods that request read access to a user's profile information and that perform read actions on the userProfile element. userProfile
IHTMLOptionButtonElement Specifies a form input control. input, input type=checkbox, input type=radio

IHTMLOptionElementFactory Creates new instances of the option element. Not scriptable
