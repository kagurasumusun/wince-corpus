MSHTML Prototypes

MSHTML in Microsoft® Windows® CE .NET supports the following function prototypes. For more information about these functions, see this Microsoft Web site.

Prototype Description
SHOWHTMLDIALOGEXFN Defines the function type for the ShowHTMLDialogEx function.
SHOWHTMLDIALOGFN Defines the function type for the ShowHTMLDialog function.
