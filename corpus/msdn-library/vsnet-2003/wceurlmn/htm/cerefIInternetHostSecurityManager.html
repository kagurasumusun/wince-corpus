IInternetHostSecurityManager

This interface is provided by the HTML host for components to use to manage security.

Method Description
IInternetHostSecurityManager::GetSecurityId Retrieves the security identification of the host.
IInternetHostSecurityManager::ProcessUrlAction Retrieves the policy associated with the Uniform Resource Locator (URL) action in the specified context.
IInternetHostSecurityManager::QueryCustomPolicy Retrieves the custom policy associated with the specified key in the given context.

Remarks

Use SID_SInternetHostSecurityManager to request this interface when using IServiceProvider::QueryService.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Urlmon.idl Urlmon.h Urlmon.lib
