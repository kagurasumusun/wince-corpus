URLZONEREG

This enumeration contains the registry location values. 

typedef enum _URLZONEREG {
URLZONEREG_DEFAULT = 0,
URLZONEREG_HKLM,
URLZONEREG_HKCU
} URLZONEREG;

Constants

Value Description
URLZONEREG_DEFAULT Use the default registry location.
URLZONEREG_HKLM Use HKEY_LOCAL_MACHINE.
URLZONEREG_HKCU Use HKEY_CURRENT_USER.
