IInternetProtocol::UnlockRequest

This method frees any resources associated with a lock. 

HRESULT UnlockRequest(VOID);

Parameters

None.

Return Values

Returns S_OK if successful or an error value otherwise.

Remarks

This method is called only if IInternetProtocol::LockRequest was called.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Urlmon.idl Urlmon.h Urlmon.lib
