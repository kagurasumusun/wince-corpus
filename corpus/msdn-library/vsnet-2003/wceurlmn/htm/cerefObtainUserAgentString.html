ObtainUserAgentString

This function retrieves the user agent string in use.

HRESULT ObtainUserAgentString(
DWORD dwOption,
LPCSTR pcszUAOut,
DWORD *cbSize
);

Parameters

dwOption
Reserved. Must be set to zero.
pcszUAOut
Address of a string value that contains the user agent string currently being used.
cbSize
Address of an unsigned long integer value that contains the length of the string.

Return Values

This function returns one of the values shown in the following table.

Value Description
E_INVALIDARG One of the parameters is invalid.
E_OUTOFMEMORY The operation ran out of memory.
NOERROR The function completed successfully.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Urlmon.idl Urlmon.h Urlmon.lib
