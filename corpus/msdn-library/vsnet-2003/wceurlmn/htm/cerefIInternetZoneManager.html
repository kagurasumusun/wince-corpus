IInternetZoneManager

This interface is used by a host to control the security zone infrastructure.

Method Description
IInternetZoneManager::CreateZoneEnumerator Creates a zone enumerator.
IInternetZoneManager::DestroyZoneEnumerator Destroys a zone enumerator.
IInternetZoneManager::GetZoneActionPolicy Retrieves the policy associated with the specified URL action.
IInternetZoneManager::GetZoneAt Retrieves the zone associated with the specified index on the given enumerator.
IInternetZoneManager::GetZoneAttributes Retrieves the zone attributes.
IInternetZoneManager::GetZoneCustomPolicy Retrieves the named custom policy associated with the zone.
LogAction Not currently implemented.
PromptAction Not currently implemented.
IInternetZoneManager::SetZoneActionPolicy Sets the action policy associated with a zone.
IInternetZoneManager::SetZoneAttributes Sets the zone attributes.
IInternetZoneManager::SetZoneCustomPolicy Sets a named custom policy associated with a zone.
