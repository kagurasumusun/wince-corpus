CreateAsyncBindCtxEx

This function creates an asynchronous bind context for use with asynchronous monikers. 

HRESULT CreateAsyncBindCtxEx(
IBindCtx *pbc,
DWORD dwOptions,
IBindStatusCallback *pBSCb,
IEnumFORMATETC *pEnum,
IBindCtx **ppBC,
DWORD reserved
);

Parameters

pbc
Address of the IBindCtx interface.
dwOptions
Unsigned long integer value that contains the option values.
pBSCb
Address of the IBindStatusCallback interface.
pEnum
Address of the IEnumFORMATETC interface.
ppBC
Address of a pointer to the IBindCtx interface that is returned.
reserved
Reserved. Must be set to zero.

Return Values

Returns S_OK if successful or an error value otherwise.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Urlmon.idl Urlmon.h Urlmon.lib
