IInternetSecurityMgrSite

This interface is provided by an HTML host to be used by components to manage the user interface of the security manager.

Method Description
IInternetSecurityMgrSite::EnableModeless Enables the use of modeless pop-up windows.
IInternetSecurityMgrSite::GetWindow Retrieves the handle to the parent window.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Urlmon.idl Urlmon.h Urlmon.lib
