IInternetSecurityManager::MapUrlToZone

This method retrieves the zone index for the specified URL. 

HRESULT MapUrlToZone(
LPCWSTR pwszUrl,
DWORD *pdwZone,
DWORD dwFlags
);

Parameters

pwszUrl
[in] Address of a string value that contains the URL.
pdwZone
[out] Address of an unsigned long integer variable that specifies the zone index.
dwFlags
[in] Unsigned long integer value that specifies flags that control this method. If the value is set to ISECMGR_PREPEND_FILE, IInternetSecurityManager::MapUrlToZone adds file: to the beginning of the URL stored in pwszUrl.

Return Values

Returns E_INVALIDARG if pdwZone is set to NULL or S_OK otherwise

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Urlmon.idl Urlmon.h Urlmon.lib
