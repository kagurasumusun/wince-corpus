App Element

App elements exist within the AppsReport element and are used to report the install state of an application.

<App
Manufacturer="Producer of the application"
Name="Name of the application"
Ver="Version of the application"
Lang="Language of the application"
/>

Attributes

Manufacturer

Required. Specifies the producer of the application. This may be an empty string.

Name

Required. Specifies the name of the application.

Ver

Required. Specifies the version number of the application. If unknown, set to 0.

Lang

Required. A string that specifies the default language of the client system as it shipped from the factory. This string is a standard locale code of the form LL-CC. LL is a 2-letter language code and CC is a 2-letter country/region code representing the particular dialect of the language.
If unknown, default to the OS language.
