transport Element

This element exists within the devmgmt-sysinfo element and is used by the server to determine the client's network characteristics. It provides information about the network configuration of the client and is used by the server to determine the nearest download server.

<transport
ip="IP address of this device"
subnet="Subnet mask of this device"
bandWidth="Speed of the link this device is connecting over"
MAC="MAC ID of the device"
/>

Attributes

ip

Required. A string that gives the IP address of this device.

subnet

Required. A string that gives the IP subnet mask for this device.

bandWidth

Optional. A string that gives the speed of the current link for this connection in bits per second.

MAC

Required. A string that represents the MAC identifier of the device.
