devmgmt-sysinfo Element

This element exists within the devmgmt element and is used to describe the configuration of the device.

<devmgmt-sysinfo
version="version number of the client that generated the data"
type="type of data - DELTA|FULL"
/>

Attributes

version

Required. Represents the version number of the client component that generated the sysinfo data. Primarily for future use. For Windows CE .NET, this should be set to 1.0.

type

Required. Represents the type of data in the sysinfo body. Primarily for future use. For Windows CE .NET, this should always be set to FULL.
