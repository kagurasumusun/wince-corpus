fileSystem Element

fileSystem elements exist within the storage element and are used to provide information about an installed file system.

<fileSystem
name="name of the file system"
size="size of the file system in kilobytes"
usedSpace="used space in the file system in kilobytes"
/>

Attributes

name

Required. A string that specifies the name of the file system.

size

Required. Indicates the size of the file system in KB.

usedSpace

Required. Indicates used space in the file system in KB.
