reportfsentries

This command generates a file system report and posts it to a URL.

reportfsentries [filesys path] [dst url]

Parameters

filesys path
Absolute file system path to include in the report. If this is a directory, all files and directories under this one are included in the report.
dst url
The URL where the report should be posted. This URL can be in the HTTP:, HTTPS:, FILE:, or PART: schemes.
