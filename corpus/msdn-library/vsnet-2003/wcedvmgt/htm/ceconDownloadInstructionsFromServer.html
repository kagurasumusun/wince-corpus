Download Instructions from the Server

The download instructions are an XML document and contain information about one or more downloads and each download can include the download of one or more files. Download instructions can optionally include the command line of a program to run after the download is completed.

Optional and Required Installs

By default, the device will only automatically install items that are marked as Required="YES".

In order to install optional applications, the control panel UI on the device opens the Client database and searches through it for each entry that is set to Required="NO". Each entry where Required is set to NO is added to the List of available applications in the UI.

When the user selects an application to download, the UI adds this Package ID to a Server Request List. The device then sends the package request to the server. The server responds with the XML download instructions and the device schedules a download task. The status of the item is set to downloading in the client database.

Download Instructions XML Elements

The following table shows the download instructions from the server XML elements.

Element Description
RDM-Operation Element Topmost element in the XML data. All other elements are nested within it.
Contents Element Contains descriptions and instructions for a given offering.
Download Element Used to describe a download offering.
CopyFile Element Used to describe the bits that the client should download.
PostInstall Element Used to tell the client to run a specific command.

Download Instructions Schema

The following schema shows the download instructions from the server.

<RDM-Operation>
   <Contents ID="Unique ID of this task">
      <Download
         StartTime="Start time (in GMT)"
         DeltaTime="Reoccurrence interval"
         Type="Type of task - Download or Poll. Default=Download"
         Flags="Connection type flags"
         Required="Yes|No. Default=No" >
         <CopyFile
            Url="Source URL for this file"
            Dest="Where to download this file to"
            Signature="Signature of the file as signed by a server in the TSL" />
         <PostInstall
            Command="command line to run" />
      />
   />
/>

Download Instructions Sample

The following code example shows download instructions from the server.

<RDM-Operation>
   <Contents ID="FE046C21-9272-49e0-83D7-8975566184F0">
      <Download 
         StartTime="2001-10-31 15:30:00" 
         DeltaTime="0000-00-07 00:00:00" 
         Flags="05 00 00 00" 
         Required="Yes">
         <CopyFile Url="https://server/drop/secpatch.cab" Dest="\temp\secpatch.cab" /> 
         <PostInstall Command="\temp\secpatch.cab" /> 
      </Download>
   </Contents>
</RDM-Operation>
