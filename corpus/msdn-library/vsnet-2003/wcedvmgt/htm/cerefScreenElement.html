screen Element

This element exists within the devmgmt-sysinfo element and is used to provide information about the display of the device.

<screen
hRes="pixel width"
vRes="pixel height"
type="color or mono"
numColors="number of colors"
/>

Attributes

hRes

Required. Indicates the display width in pixels.

vRes

Required. Indicates the display height in pixels.

type

Required. Indicates the type of the current display. Values are Mono or Color.

numColors

Required. Indicates the number of colors supported by the display.
