Device Management Software Requirements

The device management software requires both device and desktop-side components.

Device Components

For full functionality, the device must have the core device management service and the script engine installed. In addition, applications that programmatically access the device management system need to link to the device management SDK library. To use the default provisioning model, a Web browser is required. To allow for secure Web exchanges, a root certificate for the device management server is also required.

Desktop-side Components

The device management server works best with Microsoft Systems Management Server (SMS). In addition to normal SMS server requirements, the device proxy is also required. If an alternate server is used, it must support the protocol requirements of the device management client.
