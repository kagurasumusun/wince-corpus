identity Element

This element exists within the devmgmt element and is used to identify the client. If the client is configured to poll the server anonymously, this element is not required.

This element is optional.

<identity
deviceName="Device name"
userName="Name of current user"
domain="Windows NT Domain"
/>

Attributes

deviceName

Required. Represents the NETBIOS name of the device.

userName

Required. Represents the current user name.

domain

Optional. Represents the Microsoft Windows NT domain.
