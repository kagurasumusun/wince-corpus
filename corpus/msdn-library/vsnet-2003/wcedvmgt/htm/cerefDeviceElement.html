device Element

This element exists within the devmgmt-sysinfo element and is used to describe the configuration of the device.

<ceDevice
class="Device class"
modelDescription="OEM description of the device model"
cpuType="Type of CPU"
cpuArch="CPU architecture"
cpuLevel="CPU level"
ISA="instruction set architecture"
/>

Attributes

class

Required. Represents the class of device, for example, PocketPC and H/PC.

modelDescription

Required. Represents the model of the device, for example, Compaq Ipaq 3600.

cpuType

Required. Represents the type of CPU, for example, StrongARM.

cpuArch

Required. Represents the CPU architecture, for example, Intel.

cpuLevel

Required. Represents the CPU level, for example, 0.

ISA

Required. Represents the instruction set architecture, for example, x86_32.
