PostInstall Element

This element exists within the Download element and is used to tell the client to run a specific command, for example, to start the install.

<PostInstall
Command="command line to run"
/>

Attributes

Command

Required. Specifies the command the device should execute. Typically, this is the name of the .cab file that was downloaded. Depending on the entry, the following behaviors are possible:
  • Leaving the command blank indicates that the package is to be downloaded and stored.
  • Specifying the filename of the package that was downloaded causes the package to be executed with the registered application for the extension. If no registered application is found, the package will be stored.
  • Alternately, any command can be executed on the package installed by listing the .exe name of the command with the fully qualified path to the executable and then listing the fully qualified path to the stored package as the command line argument, if needed.
