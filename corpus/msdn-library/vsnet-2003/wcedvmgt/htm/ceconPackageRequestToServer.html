Package Request to the Server

Package Request XML Elements

The following table shows the package request XML elements.

Element Description
packages Element Used to provide information about the packages the device has received from the server.
package Element Used to provide information about a package.

Package Request Schema

The following code example shows the package request schema.

<packages>
   <package
      ID="Package GUID"
   />
   <package
      ID="Package GUID"
   />
/>

Package Request Sample

The following code example is a package request to the server.

POST /devmgmt/poll HTTP/1.1
X-Device-UUID: 934F9095-1DC6-49b9-918D-C36E5B2FBDB2
X-Device-client-version: 1.0
X-Device-Action: PackageRequest
<packages>
      <package ID="E9C4C404-A802-460b-B8AF-6BF1D72AF594" /> 
      <package ID="4A9D1F33-76CC-42d2-93BE-F1D86B7FBA36" /> 
      <package ID="2C0E13E1-4C20-4dc2-A80E-368FD63F986F" /> 
</packages>
