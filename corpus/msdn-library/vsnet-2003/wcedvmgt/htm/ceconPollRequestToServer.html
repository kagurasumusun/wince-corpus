Poll Request to the Server

The end user or administrator configures the device to poll a specific server at a specific time and interval. This is done either through the API or through the user interface (UI).

The polling interval is specified in the registry. This polling interval specifies how often to contact the server. If a connection attempt fails for a period, the client will retry after the retry timeout. This will be repeated depending on the number of entries specified in the registry. The default values are one hour for the polling interval and 3 minutes for retries with the maximum number of retries being five. The poll task never expires and is thus, always rescheduled.

The polling is achieved as a standard HTTP POST. The polling format describes the format of the Poll data that is sent to the server, which is the device proxy in the case of the Microsoft Systems Management Server (SMS).

The polling information sent to the server has two parts:

  • HTTP headers
  • POST data in XML

Poll Request XML Elements

The following table shows the Poll request XML elements.

Element Description
devmgmt Element Topmost element in the XML data sent to the server. All other elements are nested within it.
identity Element Used to identify the client.
devmgmt-sysinfo Element Used to describe the configuration of the device.
device Element Used to describe the configuration of the device.
osVersion Element Used to describe the OS configuration of the device.
binFile Element Used to provide information about .bin files on the device.
screen Element Used to provide information about the display of the device.
transport Element Used by the server to determine the client's network characteristics.
power Element Used to provide information about the current power status of the client.
memory Element Used to provide information about the memory of the device.
storage Element Used to provide information about the file systems on the device.
fileSystem Element Used to provide information about an installed file system.
packages Element Used to provide information about the packages the device has received from the server.
package Element Used to provide information about a package.

Poll Request Schema

The following schema is the recommended schema for a Poll request to the server. This is required for the SMS and can be modified subject to the server requirements. For more information, see the documentation about the server requirements.

<devmgmt>
   <identity
      deviceName="Device name"
      userName="Name of current user"
      domain="Windows NT Domain"
      />
   <devmgmt-sysinfo
      version="version number of the client that generated the data"
      type="Type of data - DELTA|FULL" >
      <device
         class="Device class"
         modelDescription="OEM description of the device model"
         cpuType="Type of CPU"
         cpuArch="CPU architecture"
         cpuLevel="CPU level"
         ISA="instruction set architecture"
         />
      <osVersion
         major="Major version number of the OS"
         minor="Minor version number of the OS"
         buildNum="Build number of the OS"
         CodePage="OS CodePage"
         localeID="Locale ID" >
         <binFile
            pid="PID"
            ver="Version"
            xipRegion="XIP region"
            />
         />
      <screen
         hRes="pixel width"
         vRes="pixel height"
         type="Color or mono"
         numColors="number of colors"
         />
      <transport
         ip="IP address of this device"
         subnet="Subnet mask of this device"
         bandWidth="Speed of the link this device is connecting over"
         MAC="MAC ID of the device"
         />
      <power
         AC="Current AC power status"
         battery="Current battery charge state"
         batteryPercent="Percentage of battery life remaining"
         backup="Current backup battery charge state"
         backupPercent="Percentage of backup battery life remaining"
         />
      <memory
         total="total physical memory in bytes"
         program="memory allocated to programs in bytes"
         programFree="free memory allocated to programs in bytes"
         storage="memory allocated to storage in bytes"
         storageFree="free memory allocated to storage in bytes"
         />
      <storage>
         <fileSystem
            name="name of the file system"
            size="size of the file system in kilobytes"
            usedSpace="used space in the file system in kilobytes"
            />
         />
      <packages>
         <package
            ID="Package GUID"
            />
         />
      />
   />

Poll Request Sample

The following code example shows a Poll request to the server.

POST /devmgmt/poll HTTP/1.1
X-Device-Timestamp: 2001-11-07 18:20:20
X-Device-UUID: 934F9095-1DC6-49b9-918D-C36E5B2FBDB2
X-Device-Auth: 72066466-B755-4913-87E5-9844BCF3FDA3
X-Device-client-version: 1.0
X-Device-Action: Poll
<devmgmt>
   <identity deviceName="craigma-ipaq" userName="craigma" domain="NTDEV" />
   <devmgmt-sysinfo version="1.0" type="full">
      <ceDevice class="Palm PC2" modelDescription="Compaq iPAQ H3600" cpuType="StrongARM" cpuArch="Intel" cpuLevel="0" ISA="x86_32" /> 
      <osVersion major="3" minor="0" buildNum="9348" CodePage="1236" localeID="1033" >
         <binFile pid="{13D65099-CE43-11D0-A2AD-0020357512E7}" ver="1.0" xipRegion="OS Core" /> 
         <binFile pid="{23C46454-CE43-4650-AG7D-0145357512F8}" ver="1.6" xipRegion="Apps" /> 
      </osVersion>
      <screen vRes="240" hRes="320" type="Color" numColors="65536" /> 
      <transport ip="157.59.244.92" subnet="255.255.252.0" bandWidth="10000" /> 
      <power AC="Connected" battery="High" batteryPercent="95" backup="High" backupPercent="100" /> 
      <memory total="31944" program="15984" programFree="3584" storage="15960" storageFree="13002" /> 
      <storage>
         <fileSystem name="root" size="1002" usedSpace="500" /> 
         <fileSystem name="backup" size="1462" usedSpace="700" /> 
         <fileSystem name="data" size="150" usedSpace="120" /> 
      </storage>
      <packages>

         <package ID="2C0E13E1-4C20-4dc2-A80E-368FD63F986F" /> 
      </packages>
   </devmgmt-sysinfo>
</devmgmt>
