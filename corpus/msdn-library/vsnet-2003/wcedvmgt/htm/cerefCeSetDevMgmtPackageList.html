CeSetDevMgmtPackageList

This function writes or deletes a record in a device management package database.

HRESULT CeSetDevMgmtPackageList(
PDMSINVRECORD pRecord,
DWORD dwFlags
);

Parameters

pRecord
[in] The entry data to be written or deleted. The function locates the record with the same package or application name specified in dwFlags. Writing a record is the default action. If the record cannot be found when attempting to write it, the record is appended to the database.
dwFlags
[in] Specifies one of the flags shown in the following table.
FLAG Description
PACKAGE_WRITE Overwrite or append a record (default).
PACKAGE_DELETE Delete the record that was found.
PACKAGE_BY_APPNAME Look for the record using the application name.
PACKAGE_BY_ID Look for the record using the package identifier.

Return Values

Returns S_OK if the task is scheduled successfully. This function also supports the standard return value E_INVALIDARG.
