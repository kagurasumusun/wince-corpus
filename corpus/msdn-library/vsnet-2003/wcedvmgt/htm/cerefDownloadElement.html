Download Element

This element exists within the Contents element and is used to describe a download offering.

<Download
StartTime="Start time (in GMT)"
DeltaTime="Reoccurrence interval"
Flags="Download control flags"
Required="Yes|No. Default=No"
/>

Attributes

StartTime

Required. Specifies the time to start the download.
This attribute's value is specified as "<4 digit year>-<month number>-<month day> <hours>:<minutes>:<seconds>"

DeltaTime

Optional. Specifies when this download should reoccur. The default is never.
This attribute's value is specified as "<4 digit year>-<month number>-<month day> <hours>:<minutes>:<seconds>"

Flags

Required. Specifies the connection criteria and the connection control for download. Flags is a bit field. The following table describes each bit field.
Bit Description
0x1 Means that the operation can proceed across a slow link.
Note   A slow link is defined as any connection slower than 1 Mbps.
0x2 Means that the operation can proceed across a fast link.
0x4 Means that the device must be docked for the operation to proceed.
0x80000000 Means the task is a recurring task.
An OR operation is performed on the flags to create the required control. For example, if a download task is to be executed under any network speed and is a recurring download, then the flags are computed using the following operation:
0x80000000 OR 0x1 OR 0x2 = 0x80000003
In the download instruction, this is written in reverse as Flags = 03000080.

Required

Optional. Specifies the install type. Valid options are "Yes" or "No". The default action is No.
