CopyFile Element

CopyFile elements exist within the Download elements and are used to describe the bits a client should download.

<CopyFile
Url="Source URL for this file"
Dest="Where to download this file to"
Signature="Signature of the file as signed by a server in the TSL"
/>

Attributes

Url

Required. Specifies the source URL for this file.

Dest

Required. Specifies the location on the device to which the file should be copied.

Signature

Optional. Specifies the signature of the file as signed by a server in the Trusted Server List (TSL).

Remarks

Specifying the URL ending with a trailing forward slash, /, indicates to the client that is a CopyDir instead of a CopyFile. For example, https://server/sample/ indicates that the entire sample directory is to be downloaded.

Multiple CopyFiles may be embedded in the same download instruction.
