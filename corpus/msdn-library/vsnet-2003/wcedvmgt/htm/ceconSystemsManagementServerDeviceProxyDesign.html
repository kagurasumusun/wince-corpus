Systems Management Server Device Proxy Design

The Systems Management Server (SMS) Device Proxy is responsible for acting as a proxy between the Windows CE device client and the SMS server infrastructure. The SMS device proxy performs the following functions:

  • Maintains a mapping between the SMS identifier of a client device and the Unique Device identifier as specified by the device client.
  • Responds to device polling requests and, when appropriate, supplies a correctly formatted XML document as the response.
  • Retrieves information from the SMS.
  • Tells the device whether or not inventory (hardware and software) is required.
  • Receives logging information from the device and reports this to the SMS.
  • Collects inventory from the device and reports inventory information to the SMS.
  • Adds a Windows CE Devices environment to the existing SMS installation to allow an SMS administrator to target devices.

The proxy server's role is to make each device client behave as similarly as possible to a native SMS client, so that as few changes as possible are necessary to the SMS server to allow SMS to manage the device clients.
