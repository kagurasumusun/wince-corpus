Microsoft Windows CE .NET  

savereg

This command reads the contents of a .reg file. 

savereg [reg output file] [base key]

Parameters

reg output file
The .reg file where the registry contents should be saved.
base key
Specifies the path within the registry at which to start saving. Everything below the given path is saved. If this argument is specified as the empty string, the entire registry is saved.
