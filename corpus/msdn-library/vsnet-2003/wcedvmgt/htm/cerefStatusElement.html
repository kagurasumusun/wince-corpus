status Element

This element is the topmost and only element in case of a status report.

<status
code="Code"
ID="PackageID"
Type="Type of task"
Text="Textual description"
/>

Attributes

code

Required. Code is replaced by either 100 for success, or 200 for failure.

ID

Required. Specifies the identifier of the package, as specified in the ID attribute of the Contents block of the Download XML.

Type

Required. Type of task is replaced by the type of task and can either be Download or Install.

Text

Optional. Specifies a textual description of the event not exceeding 140 characters.
