Failure Recovery

If the device fails to make a connection to the server, it will retry the communication after the RetryTime has expired up to a maximum of RetryLimit times. The default RetryTime is 15 minutes and the default RetryLimit is 5. For more information, see Device Management Registry Settings.

If the RetryLimit is reached on a connection without contacting the server, the device will attempt to contact the server on any other connections that meet the event's connection criteria. The device will automatically try all the networks at the device's disposal to contact the requested server.

If the RetryLimit is reached on a connection after contacting the server, the device will attempt to contact the server on any other connections that meet the event's connection criteria.

If all possible options for retry are exhausted, the device will raise an event so that the user interface can notify the user that the event failed.

If the event is reoccurring, then the next event will be scheduled.
