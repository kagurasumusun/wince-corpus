power Element

This element exists within the devmgmt-sysinfo element and is used to provide information about the current power status of the client.

<power
AC="Current AC power status"
battery="Current battery charge state"
batteryPercent="Percentage of battery life remaining"
backup="Current backup battery charge state"
backupPercent="Percentage of backup battery life remaining"
/>

Attributes

AC

Required. A string that specifies the current AC power status of the client. This is retrieved through SYSTEM_POWER_STATUS_EX.ACLineStatus.
The values for this attribute can be any of the following:
  • "Disconnected"
  • "Connected"
  • "Unknown"

battery

Required. A string that specifies the current battery charge state of the client. This is retrieved through SYSTEM_POWER_STATUS_EX.BatteryFlag.
The values for this attribute can be any of the following:
  • "High"
  • "Low"
  • "Critical"
  • "Charging"
  • "No system battery"
  • "Unknown"

batteryPercent

Required. A string that specifies the current percentage of battery charge remaining. This is retrieved through SYSTEM_POWER_STATUS_EX.BatteryLifePercent.
The values for this attribute can be either "Unknown" or a decimal integer less than or equal to 100 (<= 100).

backup

Required. A string that specifies the current backup battery charge state of the client. This is retrieved through SYSTEM_POWER_STATUS_EX.BackupBatteryFlag.
The values for this attribute can be any of the following:
  • "High"
  • "Low"
  • "Critical"
  • "Charging"
  • "No system battery"
  • "Unknown"

backupPercent

Required. A string that specifies the current percentage of backup battery charge remaining. This is retrieved through SYSTEM_POWER_STATUS_EX.BackupBatteryLifePercent.
The values for this attribute can be either "Unknown" or a decimal integer less than or equal to 100 (<= 100).
