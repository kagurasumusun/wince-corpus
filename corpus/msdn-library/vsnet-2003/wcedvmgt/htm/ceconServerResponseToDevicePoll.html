Server Response to the Device Poll

Server Response to Device Poll XML Elements

The following table shows the server response to the device Poll XML elements.

Element Description
RDM-Operation Element Topmost element in the XML data. All other elements are nested within it.
packages Element Used to provide information about the packages the device has received from the server.
package Element Used to provide information about a package.
add Element All packages that are to be added come under this element.
remove Element All packages that are to be removed come under this element.

Server Response to Device Poll Schema

The following schema shows the responses from the server to a device Poll request. The response to a device poll includes some configuration items, such as instructions to the client to return inventory at the next poll. It also includes zero or more download offerings for the device to process and download. The client expects these responses and the server needs to send it in the schema described below. Any changes will result in an erroneous instruction to the device management client.

<RDM-Operation>
   <packages>
      <add>
         <package
            ID="Package GUID"
            Required="Yes | No"
            Name="Name of the offered package"
            ShortDescription="A short description of the offered package"
            LongDescription="A long description of the offered package"
         />
      />
      <remove>
         <package
            ID="Package GUID"
         />
      />
   />
/>

Server Response to Device Poll Samples

The following code example is a server response where no packages apply or there are no changes.

<RDM-Operation>
   <packages>
      <add></add>
      <remove></remove>
   </packages>
</RDM-Operation>

The following code example is a server response where there are packages to be added or removed.

<RDM-Operation>
   <packages>
      <add>
         <package ID="9D5EDC9E-883F-49d8-B25F-039CFDD99969" Required="Yes" Name="Sec Patch1" ShortDescription="Security Patch" LongDescription="" /> 
         <package ID="6761BA0F-FBCC-48b8-A722-B9C265F244CE" Required="No" Name="Sales Application" ShortDescription="Sales automation app" LongDescription="" /> 
      </add>
      <remove>
         <package ID="AF93AFF5-F406-4ecb-89EC-B9E3DA3A9D73" /> 
         <package ID="F72CF274-D50D-4349-83E5-51AF08F4DDC6" /> 
      </remove>
   </packages>
</RDM-Operation>
