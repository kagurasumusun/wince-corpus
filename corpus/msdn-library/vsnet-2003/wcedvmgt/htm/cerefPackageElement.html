package Element

package elements exist within the packages element and are used to provide information about a package.

<package
ID="Package GUID"
Required="Yes | No"
Name="Name of the offered package"
ShortDescription="A short description of the offered package"
LongDescription="A long description of the offered package"
/>

Attributes

ID

Required. A string that specifies the GUID of this package.

Required

Required only when this package is a sub-element of the add Element. This specifies whether this package is mandatory or not.

Name

Required only when this package is a sub-element of the add element. Specifies the package name.

ShortDescription

Required only when this package is a sub-element of the add element. Specifies the short description of the offered package and has a maximum of 140 characters.

LongDescription

Optional. This is used only when the package is a sub-element of the add element. Specifies the long description of the offered package and has a maximum of 512 characters.
