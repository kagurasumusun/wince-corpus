osVersion Element

This element exists within the devmgmt-sysinfo element and is used to describe the OS configuration of the device.

<osVersion
major="Major version number of the OS"
minor="Minor version number of the OS"
buildNum="Build number of the OS"
CodePage="OS CodePage"
localeID="Locale ID"
/>

Attributes

major

Required. Specifies the major version of the OS on the client.

minor

Required. Specifies the minor version of the OS on the client.

buildNum

Required. Specifies the build number of the OS on the client.

CodePage

Required. Specifies the default CodePage of the system.

localeID

Required. Specifies the default locale identifier.
