Directory Element

Directory elements appear nested in a FileReport element and are used to describe file system directories currently on the client system.

<Directory
Name="Directory name"
Created="Creation date"
LastAccessed="Last access date"
Attributes="File system attributes"
/>

Attributes

Name

Required. Specifies the name of the directory.

Created

Required. Specifies the time and date when this directory was created. This attribute's value is specified as "<4 digit year>-<month number>-<month day> <hours>:<minutes>:<seconds>".

LastAccessed

Required. Specifies the time and date when the contents of this directory were last accessed. This attribute's value is specified as "<4 digit year>-<month number>-<month day> <hours>:<minutes>:<seconds>".

Attributes

Required. Specifies the attributes for the directory. This can be an empty string or a combination of any of the defined attribute strings separated with vertical bars.
The following table lists the directory attributes that can be used.
Directory attributes Description
ARCHIVE The directory was archived.
COMPRESSED The contents of the directory are compressed.
HIDDEN The directory is hidden.
READONLY The directory is read-only and cannot be modified.
SYSTEM The directory is considered a system directory.
TEMPORARY The directory is temporary.
