Internet Explorer 5.5

Microsoft® Internet Explorer 5.5 for Microsoft® Windows® CE is a highly compatible, feature-rich browser control for the Windows CE operating system. Web developers, OEMs, independent software vendors (ISVs), and independent hardware vendors (IHVs) can use the technologies provided by Internet Explorer 5.5 for Windows CE to build a custom browser for a specific device or market. Because Internet Explorer 5.5 for Windows CE does not include a browser shell application, no documentation about the browser UI is included.

Note that Internet Explorer 5.5 for Windows CE is not an extension or upgrade of Pocket Internet Explorer. In fact, both browsers can exist on the same platform. Internet Explorer 5.5 for Windows CE does not attempt to provide backwards compatibility with Pocket Internet Explorer or its custom interfaces.

Internet Explorer 5.5 for Windows CE supports the same features as the Microsoft Win32® version of Internet Explorer 5.5, except for the following:

  • Downloadable Microsoft ActiveX® controls
  • PNG image file format
  • Gopher protocol
  • Recreation Software Advisory Council on the Internet (RSACi) rating system
  • Filters and transitions
  • Default behaviors other than client capabilities

By default, a platform that includes Internet Explorer 5.5 for Windows CE also includes support for the following features:

  • Windows Internet Services (WinInet), including FTP protocol support, Private Communications Technology (PCT) 1.0 and Secure Sockets Layer (SSL) versions 2.0 and 3.0, Server Gated Crypto (SGC) security protocols, and Passport authentication
  • URL Moniker Services, including Hit Logging, URL Security Zones, and Asynchronous Pluggable Protocol
  • Internet Explorer Multiple-Language API

The following features, if supported on a specific Windows CE .NET platform, are documented elsewhere in this SDK reference:

  • MSHTML and DHTML API and Document Object Model
  • Web Browser Control Host
  • Television-style Navigation
  • Microsoft JScript® 5.5 run-time engine
  • Microsoft VBScript® 5.5 run-time engine
