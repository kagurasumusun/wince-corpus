towlower

Convert character to lowercase.

Routine Required Header
towlower <ctype.h> 
int towlower( wint_t c );

Parameter

c
Character to convert

Libraries

All versions of the C run-time libraries.

Return Value

Each of these routines converts a copy of c, if possible, and returns the result. There is no return value reserved to indicate an error.

Remarks

This routine converts a given uppercase letter to a lowercase letter if possible and appropriate.

Example

/* TOUPPER.C: This program uses toupper and tolower to
 * analyze all characters between 0x0 and 0x7F. It also
 * applies _toupper and _tolower to any code in this
 * range for which these functions make sense.
 */

#include <conio.h>
#include <ctype.h>
#include <string.h>

char msg[] = "Some of THESE letters are Capitals\r\n";
char *p;

void main( void )
{
   _cputs( msg );

   /* Reverse case of message. */
   for( p = msg; p < msg + strlen( msg ); p++ )
   {
      if( islower( *p ) )
         _putch( _toupper( *p ) );
      else if( isupper( *p ) )
         _putch( _tolower( *p ) );
      else
         _putch( *p );
   }
}

Output

Some of THESE letters are Capitals
sOME OF these LETTERS ARE cAPITALS
