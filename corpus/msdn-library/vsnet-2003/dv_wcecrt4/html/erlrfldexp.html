ldexp

Computes a real number from the mantissa and exponent.

Routine Required Header
ldexp <math.h> 
double ldexp( double x, int exp );

Parameters

x
Floating-point value
exp
Integer exponent

Libraries

All versions of the C run-time libraries.

Return Value

The ldexp function returns the value of x * 2exp if successful. On overflow (depending on the sign of x), ldexp returns +/– HUGE_VAL.

Example

/* LDEXP.C */

#include <math.h>
#include <stdio.h>

void main( void )
{
   double x = 4.0, y;
   int p = 3;

   y = ldexp( x, p );
   printf( "%2.1f times two to the power of %d is %2.1f\n", x, p, y );
}

Output

4.0 times two to the power of 3 is 32.0
