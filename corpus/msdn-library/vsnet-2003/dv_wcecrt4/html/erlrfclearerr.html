clearerr

Resets the error indicator for a stream

Routine Required Header
clearerr <stdio.h> 
void clearerr( FILE *stream );

Parameters

stream
Pointer to FILE structure

Libraries

All versions of the C run-time libraries.

Return Values

None

Remarks

The clearerr function resets the error indicator and end-of-file indicator for stream. Error indicators are not automatically cleared; once the error indicator for a specified stream is set, operations on that stream continue to return an error value until clearerr, fseek, or fsetpos is called.

Example 

/* CLEARERR.C: This program creates an error
 * on the standard input stream, then clears
 * it so that future reads won't fail.
 */

#include <stdio.h>

void main( void )
{
   int c;
   /* Create an error by writing to standard input. */
   putc( 'c', stdin );
   if( ferror( stdin ) )
   {
      printf( "Write error" );
      clearerr( stdin );
   }

   /* See if read causes an error. */
   printf( "Will input cause an error? " );
   c = getc( stdin );
   if( ferror( stdin ) )
   {
      printf( "Read error" );
      clearerr( stdin );
   }
}

Output

Write error: No error
Will input cause an error? n
