FindClose

This function closes the specified search handle. The FindFirstFile and FindNextFile functions use the search handle to locate files with names that match a specified name.

A remote application programming interface (RAPI) version of this function exists, and it is named CeFindClose (RAPI). 

BOOL FindClose( 
HANDLE hFindFile 
);

Parameters

hFindFile
[in] Search handle. This handle must have been previously opened by the FindFirstFile function.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

After the FindClose function is called, the handle specified by the hFindFile parameter cannot be used in subsequent calls to either the FindNextFile or FindClose function.

FindClose operates only on file search handles. Use the CloseHandle function to close search handles opened by the CeFindFirstDatabaseEx function.
