DB_CEOID_FILE_DELETED

This message is sent when a file is deleted.

DB_CEOID_CHANGED oidChanged = (CEOID) wParam; 
oidParent = (CEOID) lParam;

Parameters

oidChanged
Identifier of the object that was modified.
oidParent
Identifier of the parent object of the modified object.

Return Values

None.

Remarks

This message is only sent to the process that has registered as the replication process with CeRegisterReplNotification.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.01 and later Winbase.h Windbase.h Coredll.lib

See Also

CeRegisterReplNotification
