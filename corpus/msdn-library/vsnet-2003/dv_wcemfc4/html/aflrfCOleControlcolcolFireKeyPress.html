COleControl::FireKeyPress

This method fires the stock KeyPress event. If this event is defined as a custom event, you determine when the event is fired.

void FireKeyPress( 
USHORT* pnChar );

Parameters

pnChar
Specifies a pointer to the character value of the key pressed.

Remarks

The recipient of the event may modify pnChar; for example, convert all lowercase characters to uppercase. If you want to examine the modified character, override OnKeyPressEvent.

For automatic firing of a KeyPress event to occur, the control Event map must have a stock KeyPress event defined.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
