COleControl::SerializeStockProps

This method serializes or initializes the COleControl stock properties: Appearance, BackColor, BorderStyle, Caption, Enabled, Font, ForeColor, and Text.

void SerializeStockProps( 
CArchive& ar );

Parameters

ar
Specifies a CArchive object to serialize to or from.

Remarks

You can improve the binary persistence performance of a control by using SerializeStockProps, SerializeExtent, and SerializeVersion to override COleControl::Serialize.

Example

For an example, see the code at SerializeExtent.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
