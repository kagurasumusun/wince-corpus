Using this MFC Documentation

Documentation for this release is targeted at Independent Software Vendor developers who have experience using MFC to develop desktop applications. Expect to continue to use your experience and resources (such as books and other references) that you have used in MFC desktop development. (If you are new to MFC, consider getting started by reading the second edition of Programming Windows with MFC by Jeff Prosise, available from Microsoft Press.)

  • The Guide section focuses on the differences in class support you will find between desktop and Windows CE. The Guide portrays these differences by descriptive text and by graphical (hierarchical) charts. It also reviews certain aspects of MFC programming (such as Document/View architecture), and points out examples of changes to be considered when developing applications for Windows CE.

    The MFC Guide is meant to be a supplement to the eMbedded Visual C++ documentation, where you will find many additional topics dealing with MFC development.

  • The Samples section offers brief documentation on the many sample MFC projects that ship with Microsoft® eMbedded Visual C++®. These samples demonstrate the use of many of the classes available for Windows CE development. Each topic in the Samples section provides a button control that lets you automatically open the sample in the eMbedded Visual C++ IDE.
  • The heart of the MFC documentation is the Reference section, where you will find all of and only those MFC classes and members that are supported in the SDKs included with this package. To locate information on a class or member, use the Help Index or Search functions.

This documentation is meant to be used in conjunction with other Help files included in the Help collection, especially topics provided by your target SDK and basic Windows CE topics.
