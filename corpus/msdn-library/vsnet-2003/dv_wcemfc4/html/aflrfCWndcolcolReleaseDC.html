Microsoft Foundation Class Library for Windows CE  

CWnd::ReleaseDC

This method releases a device context, freeing it for use by other applications. The effect of the ReleaseDC method depends on the device-context type.

The application must call the ReleaseDC method for each call to the GetWindowDC method and for each call to the GetDC method.

int ReleaseDC( 
CDC* pDC );

Parameters

pDC
Identifies the device context to be released.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h

See Also

CWnd::GetDC, CWnd::GetWindowDC
