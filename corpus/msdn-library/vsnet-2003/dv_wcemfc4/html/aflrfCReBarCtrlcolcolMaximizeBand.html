CReBarCtrl::MaximizeBand

This method resizes a band in a rebar control to either its ideal or largest size.

This method implements the behavior of the Windows CE message RB_MAXIMIZEBAND. 

void MaximizeBand( 
UINT uBand );

Parameters

uBand
Specifies the zero-based index of the band to be maximized.

Example

UINT nCount = m_pReBarCtrl->GetBandCount();

for (UINT i=0; i<nCount; i++)
  m_pReBarCtrl->MaximizeBand(i);

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
