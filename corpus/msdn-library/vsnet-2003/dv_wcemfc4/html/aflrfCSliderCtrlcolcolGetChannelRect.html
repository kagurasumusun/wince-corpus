CSliderCtrl::GetChannelRect

This method retrieves the size and position of the bounding rectangle for a slider control channel. The channel is the area over which the slider moves and which contains the highlight when a range is selected.

void GetChannelRect( 
LPRECT lprc ) 
const;

Parameters

lprc
A pointer to a CRect object that contains the size and position of the channel bounding rectangle when the function returns.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
