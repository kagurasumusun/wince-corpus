CTimeSpan::operator +=, -=

These operators add and subtract a CTimeSpan object to and from this CTimeSpan.

const CTimeSpan& operator +=( 
CTimeSpan timeSpan ); 

const CTimeSpan& operator –=( 
CTimeSpan timeSpan );

Example

// Example for CTimeSpan::operator +=, -=
CTimeSpan ts1( 10 ); // 10 seconds
CTimeSpan ts2( 100 ); // 100 seconds
ts2 -= ts1;
ASSERT( ts2.GetTotalSeconds() == 90 );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
