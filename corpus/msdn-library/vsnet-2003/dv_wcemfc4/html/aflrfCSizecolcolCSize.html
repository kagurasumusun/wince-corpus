CSize::CSize

This constructor creates an instance of a CSize object. If no parameters are specified, cx and cy members are not initialized.

CSize( ); 

CSize( 
int initCX, 
int initCY ); 

CSize( 
SIZE initSize ); 

CSize( 
POINT initPt ); 

CSize( 
DWORD dwSize );

Parameters

initCX
Sets the cx member for the CSize.
initCY
Sets the cy member for the CSize.
initSize
Specifies the SIZE structure or CSize object used to initialize CSize.
initPt
Specifies the POINT structure or CPoint object used to initialize CSize.
dwSize
Specifies the DWORD used to initialize CSize. The low-order word is the cx member and the high-order word is the cy member.

Example

CSize szEmpty();
CSize szPointA(10, 25);

SIZE sz;
sz.cx = 10;
sz.cy = 25;
CSize szPointB(sz);

POINT pt;
pt.x = 10;
pt.y = 25;
CSize szPointC(pt);

CPoint ptObject(10, 25);
CSize szPointD(ptObject);  

DWORD dw = MAKELONG(10, 25);
CSize szPointE(dw);

ASSERT(szPointA == szPointB);
ASSERT(szPointB == szPointC);
ASSERT(szPointC == szPointD);
ASSERT(szPointD == szPointE);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
