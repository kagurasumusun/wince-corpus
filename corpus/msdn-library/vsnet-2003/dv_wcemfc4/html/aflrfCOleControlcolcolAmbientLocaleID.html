Microsoft Foundation Class Library for Windows CE  

COleControl::AmbientLocaleID

This method returns the locale identifier of the container. 

LCID AmbientLocaleID( );

Return Value

The value of the LocaleID property of the container, if any. If this property is not supported, this function returns zero.

Remarks

MFC for Windows CE only supports the AmbientLocaleID method if the OLEAMBIENTTHEREADLOCALE flag is not defined.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
