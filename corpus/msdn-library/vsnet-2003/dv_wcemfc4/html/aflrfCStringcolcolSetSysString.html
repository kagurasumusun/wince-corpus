CString::SetSysString

This method reallocates the BSTR referenced by pbstr, and copies the contents of the CString object into it, including the NULL character. The value of the BSTR referenced by pbstr may change. The method throws a CMemoryException if insufficient memory exists.

This method is normally used to change the value of strings passed by reference for OLE Automation.

BSTR SetSysString( 
BSTR* pbstr ) 
const;

Parameters

pbstr
Specifies a pointer to a character string.

Return Value

Returns the new string.

Remarks

For more information about OLE reallocation functions in Windows CE, see ::SysReallocStringLen and ::SysFreeString.

Example

// create an OLE string
BSTR bstr = ::SysAllocString(L"Golf is fun!");

// create a CString and change the OLE
// string to the contents of the BSTR
CString str("Hockey is best!");
BSTR bstr2 = str.SetSysString(&bstr);

// Now, both bstr and bstr2 reference a single instance of
// the "Hockey" string. The "Golf" string has been freed.
ASSERT(bstr2 == bstr);

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
