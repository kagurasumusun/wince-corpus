CWnd::MapWindowPoints

This method converts, or maps, a set of points from the coordinate space of the CWnd to the coordinate space of another window.

void MapWindowPoints( 
CWnd* pwndTo, 
LPPOINT lpPoint, 
UINT nCount ) 
const; 

void MapWindowPoints( 
CWnd* pwndTo, 
LPRECT lpRect ) 
const;

Parameters

pwndTo
Identifies the window to which points are converted. If this parameter is NULL, the points are converted to screen coordinates.
lpRect
Specifies the rectangle whose points are to be converted.
lpPoint
Specifies a pointer to an array of POINT structures that contain the set of points to be converted.
nCount
Specifies the number of POINT structures in the array pointed to by lpPoint.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
