Microsoft Foundation Class Library for Windows CE  

COleControl::AmbientForeColor

This method retrieves the value of the ambient ForeColor property.

OLE_COLOR AmbientForeColor( );

Return Value

The current value of the ambient ForeColor property of the container, if any. If not supported, this function returns the system-defined Windows CE text color.

Remarks

The ambient ForeColor property is available to all controls and is defined by the container. Note that the container is not required to support this property.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
