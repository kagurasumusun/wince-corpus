COleControl::AmbientFont

This method retrieves the value of the ambient Font property.

LPFONTDISP AmbientFont( );

Return Value

A pointer to the ambient Font dispatch interface of the container. The default value is NULL. If the return is not equal to NULL, you are responsible for releasing the font by calling its IUnknown::Release method.

Remarks

The ambient Font property is available to all controls and is defined by the container. Note that the container is not required to support this property.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
