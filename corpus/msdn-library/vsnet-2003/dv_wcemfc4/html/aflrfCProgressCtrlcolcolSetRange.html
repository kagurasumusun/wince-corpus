CProgressCtrl::SetRange

This method sets the upper and lower limits of the range of the progress bar control, and redraws the bar to reflect the new ranges.

The method SetRange32 sets the 32-bit range for the progress control. 

void SetRange( 
short nLower, 
short nUpper ); 

void SetRange32( 
int nLower, 
int nUpper );

Parameters

nLower
Specifies the lower limit of the range. The default is zero.
nUpper
Specifies the upper limit of the range. The default is 100.

Example

CProgressCtrl myCtrl;

// Create a smooth child progress control.
myCtrl.Create(WS_CHILD|WS_VISIBLE|PBS_SMOOTH, CRect(10,10,200,30), 
  pParentWnd, 1);

// Set the range to be 0 to 100.
myCtrl.SetRange( 0, 100 );

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
