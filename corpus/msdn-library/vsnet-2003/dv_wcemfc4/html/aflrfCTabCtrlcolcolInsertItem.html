CTabCtrl::InsertItem

This method inserts a new tab in an existing tab control.

BOOL InsertItem( 
int nItem, 
TCITEM* pTabCtrlItem ); 

BOOL InsertItem( 
int nItem, 
LPCTSTR lpszItem ); 

BOOL InsertItem( 
int nItem, 
LPCTSTR lpszItem,

UINT nMask, 
int nItem, 
LPCTSTR lpszItem, 
int nImage, 
LPARAM lParam, 
DWORD dwState, 
DWORD dwStateMAsk );

Parameters

nItem
Specifies the zero-based index of the new tab.
pTabCtrlItem
Specifies the pointer to a TCITEM structure that specifies the attributes of the tab.
lpszItem
Specifies an address of a null-terminated string that contains the text of the tab.
nImage
Specifies the zero-based index of an image to insert from an image list.
nMask
Specifies which TCITEM structure attributes to set. Can be zero or a combination of the following values:
  • TCIF_TEXT   The pszText member is valid.
  • TCIF_IMAGE   The iImage member is valid.
  • TCIF_PARAM   The lParam member is valid.
  • TCIF_RTLREADING   The text of pszText is displayed using right-to-left reading order on Hebrew or Arabic systems.
  • TCIF_STATE   The dwState member is valid.
lParam
Specifies an application-defined data associated with the tab.
dwState
A Reference to a DWORD value receiving the state information. Can be one of the following values:
Value Description
TCIS_BUTTONPRESSED The tab control item is selected.
TCIS_HIGHLIGHTED The tab control item is highlighted, and the tab and text are drawn using the current highlight color. When using highlight color, this will be a true interpolation, not a dithered color.
dwStateMask
Specifies the mask specifying which of the state flags of the item to return. For a list of values, see the nMask member of the TCITEM structure.

Return Value

Zero-based index of the new tab if it is successful; otherwise, it is –1.

Example

BOOL CDialogDlg::OnInitDialog()
{
  // Other initialization.
  
  TCITEM tcItem;
  tcItem.mask = TCIF_TEXT;
  tcItem.pszText = _T("Tab #1");

  m_tabCtrl.InsertItem(0, &tcItem);
  
  return TRUE;  // Return TRUE unless you set the focus to a control.
}
