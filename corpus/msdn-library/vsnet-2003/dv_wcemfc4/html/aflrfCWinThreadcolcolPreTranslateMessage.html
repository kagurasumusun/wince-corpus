Microsoft Foundation Class Library for Windows CE  

CWinThread::PreTranslateMessage

Override this method to filter window messages before they are dispatched to the Windows CE TranslateMessage and DispatchMessage functions.

This method is used only in user-interface threads.

virtual BOOL PreTranslateMessage( 
MSG* pMsg );

Parameters

pMsg
Points to a MSG structure containing the message to process.

Return Value

Nonzero if the message was fully processed in PreTranslateMessage and should not be processed further. Zero if the message should be processed in the normal way.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
