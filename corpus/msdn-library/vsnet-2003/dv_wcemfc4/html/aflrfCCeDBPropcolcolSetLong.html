CCeDBProp::SetLong

This method sets the value of a long integer property. 

void SetLong( 
long lVal );

Parameters

lVal
Specifies the value of the property.

Remarks

You can only call SetLong on a property of the type CCeDBProp::Type_Long.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Wcedb.h
