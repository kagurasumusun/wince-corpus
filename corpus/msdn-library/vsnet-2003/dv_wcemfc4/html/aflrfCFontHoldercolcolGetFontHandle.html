CFontHolder::GetFontHandle

This method retrieves a handle to a Windows CE font.

The ratio of cyLogical and cyHimetric is used to calculate the proper display size, in logical units, for the point size of the font expressed in MM_HIMETRIC units For example the display size = (cyLogical / cyHimetric) * font size. The implementation with no parameters returns a handle to a font sized correctly for the screen.

HFONT GetFontHandle( ); 

HFONT GetFontHandle( 
long cyLogical, 
long cyHimetric );

Parameters

cyLogical
Specifies the height, in logical units, of the rectangle in which the control is drawn.
cyHimetric
Specifies the height, in MM_HIMETRIC units, of the control.

Return Value

A handle to the Font object; otherwise, it is NULL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Afxctl.h
