COleControl::GetFont

This method retrieves the value of the stock Font property. Note that the caller must release the object when finished.

LPFONTDISP GetFont( );

Return Value

A pointer to the font dispatch interface of the control stock Font property.

Remarks

Within the implementation of the control, use InternalGetFont to access the control stock Font object.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h

See Also

COleControl::SetFont, COleControl::AmbientFont, COleControl::InternalGetFont
