CString::GetAt

This method retrieves a single character specified by an index number. The overloaded subscript ([]) operator is a convenient alias for GetAt.

TCHAR GetAt( 
int nIndex ) 
const;

Parameters

nIndex
Specifies the zero-based index of the character in the CString object. The nIndex parameter must be greater than or equal to 0 and less than the value returned by GetLength. The Debug version of the Microsoft Foundation Class Library for Windows CE validates the bounds of nIndex; the Release version does not.

Return Value

This is a TCHAR containing the character at the specified position in the string. Single character at zero-based index.

Example

The following example demonstrates the use of CString::GetAt.

// example for CString::GetAt
CString s( "abcdef" );
ASSERT( s.GetAt(2) == 'c' );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
