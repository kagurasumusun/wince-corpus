CStatusBar::GetPaneInfo

This method sets nidentifier, nStyle, and cxWidth to the identifier, style, and width of the indicator pane at the location specified by nIndex.

void GetPaneInfo( 
int nIndex, 
UINT& nID, 
UINT& nStyle, 
int& cxWidth ) 
const;

Parameters

nIndex
Specifies the index of the pane whose information is to be retrieved.
nID
Specifies the reference to a UINT that is set to the identifier of the pane.
nStyle
Specifies the reference to a UINT that is set to the style of the pane.
cxWidth
Specifies the reference to an integer that is set to the width of the pane.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
