CToolBar::SetBitmap

This method sets the bitmap image for the toolbar. For example, call SetBitmap to change the bitmapped image after the user takes an action on a document that changes the action of a button.

BOOL SetBitmap( 
HBITMAP hbmImageWell );

Parameters

hbmImageWell
Specifies the handle of a bitmap image that is associated with a toolbar.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
