Run-Time Object Model Support

MFC for Windows CE supports all the run-time object model classes the same way the standard MFC library supports them.

For information about the MFC for Windows CE run-time support classes, see the following topics:

  • CArchive
  • CDumpContext
  • CRuntimeClass

For information about where the run-time object model support classes fit into the Windows CE class hierarchy, see Classes Not Derived from CObject.
