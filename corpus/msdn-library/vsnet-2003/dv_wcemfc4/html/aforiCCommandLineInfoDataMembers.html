CCommandLineInfo Data Members

Data Member Description
m_bShowSplash Indicates whether a splash screen should be shown.
m_nShellCommand Indicates the shell command to process.
m_strFileName Indicates the filename to be opened or printed; empty if the shell command is New or DDE.
