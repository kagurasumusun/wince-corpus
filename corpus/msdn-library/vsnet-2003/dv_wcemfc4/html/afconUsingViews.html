Using Views

The responsibilities of the view are to graphically display the data of the document and to accept and interpret user input as operations on the document. Your tasks in writing your view class are to:

  • Write the OnDraw member function of your view class. This function renders the data of the document.
  • Connect appropriate Windows messages and user-interface objects such as menu items to message-handler member functions in the view class.
  • Implement those handlers to interpret user input.

In addition, you may need to override other CView member functions in your derived view class. In particular, you may want to override OnInitialUpdate to perform special initialization for the view and OnUpdate to do any special processing needed just before the view redraws itself. For multipage documents, you also must override OnPreparePrinting to initialize the Print dialog box with the number of pages to print and other information.
