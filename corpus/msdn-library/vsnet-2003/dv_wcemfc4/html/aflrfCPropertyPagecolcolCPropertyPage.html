CPropertyPage::CPropertyPage

This constructor creates an instance of a CPropertyPage object. The object is displayed after all of the following conditions are met:

  • The page has been added to a property sheet using CPropertySheet::AddPage.
  • The DoModal or Create method of the property sheet has been called.
  • The user has selected (tabbed to) this page.

If you have multiple parameters—for example, if you are using an array—use CPropertySheet::Construct instead of CPropertyPage.

CPropertyPage( ); 

CPropertyPage( 
UINT nIDTemplate, 
UINT nIDCaption = 0 ); 

CPropertyPage( 
LPCTSTR lpszTemplateName, 
UINT nIDCaption = 0 );

Parameters

nIDTemplate
Specifies the ID of the template used for this page.
nIDCaption
Specifies the ID of the name to be placed in the tab for this page. If zero, the name will be taken from the dialog template for this page.
lpszTemplateName
Points to a string containing the name of the template for this page. Cannot be NULL.

Example

// Declare a CStylePage object, which is a CPropertyPage-derived class.
CStylePage stylePage;

// Declare a CPropertyPage object with IDD_SHAPE, the ID of the 
// template used for this page. 
CPropertyPage shapePage(IDD_SHAPE);

Requirements
