Microsoft Foundation Class Library for Windows CE  

COleControl::GetClientRect

This method retrieves the size of the control client area.

virtual void GetClientRect( 
LPRECT lpRect ) 
const;

Parameters

lpRect
Specifies a pointer to a RECT structure containing the dimensions of the client area in a windowless control; that is, the size of the control minus window borders, frames, scroll bars, and so on. The lpRect parameter indicates the size of the client rectangle in the control, not its position.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
