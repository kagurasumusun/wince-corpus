CPrintDialog::PrintDraft

This method determines whether or not the printer should print in draft mode.

BOOL PrintDraft( ) const;

Return Values

TRUE if the dwFlags member of pd structure is set to PD_SELECTDRAFTMODE, which occurs if the user selected the Draft mode check box; otherwise, it is FALSE.

Remarks

Windows-based desktop platforms do not support this method.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxdlgs.h
