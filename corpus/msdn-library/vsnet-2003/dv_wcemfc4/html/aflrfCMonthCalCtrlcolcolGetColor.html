CMonthCalCtrl::GetColor

This method retrieves the color of an area of the month calendar control specified by nRegion.

COLORREF GetColor( 
int nRegion ) 
const;

Parameters

nRegion
Specifies the region of the month calendar control from which the color is retrieved. For a list of values, see the nRegion parameter of SetColor.

Return Value

A COLORREF value specifying the color associated with the portion of the month calendar control, if successful. Otherwise, this method returns –1.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxdtctl.h
