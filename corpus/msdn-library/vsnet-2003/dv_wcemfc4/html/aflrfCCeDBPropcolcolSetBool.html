CCeDBProp::SetBool

This method sets a Boolean value. 

void SetBool (
BOOL bBool );

Parameters

bBool
Specifies the Boolean value.

Remarks

You can call SetBool only on a property of the type CCeDBProp::Type_Bool.

Requirements

Windows CE versions: 2.0 and later
