CReBarCtrl::GetRowCount

This method retrieves the number of rows of bands in a rebar control.

This method implements the behavior of the Windows CE message RB_GETROWCOUNT. 

UINT GetRowCount( ) 
const;

Remarks

Return Value

A UINT value that represents the number of band rows in the control.

Example

UINT nRowCount = m_wndReBar.GetReBarCtrl().GetRowCount();
CString msg;
msg.Format(_T("Row Count is %d"), nRowCount);
AfxMessageBox(msg);

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
