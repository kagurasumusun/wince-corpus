CFileException::m_lOsError

This data member contains the operating-system error code for this exception. For a listing of error values, see your operating-system technical manual. This data member is a public variable of type LONG.

LONG m_lOsError;

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
