Classes Unique to Windows CE

MFC for Windows CE supports the following classes that do not exist in the desktop version.

CCeCommandBar CCeDocList
CCeDBDatabase CCeDocListDocTemplate
CCeDBEnum CCeSaveModifiedDlg
CCeDBProp CCeSocket
CCeDBRecord  

These classes encapsulate features unique to Windows CE. For example, MFC for Windows CE contains four database classes (CCeDBDatabase, CCeDBRecord, CCeDBProp, and CCeDBEnum) that support the simple Windows CE database functionality.

Another class unique to MFC for Windows CE is CCeSocket. Windows CE does not support true asynchronous socket communication, but the CCeSocket class simulates asynchronous notification for certain socket events. Use this class instead of CAsyncSocket for Windows CE–based socket applications.

Yet another unique class is CCeCommandBar. The command bar is a common control that combines the functionality of a menu bar and a toolbar, and is designed specifically for devices with small displays.

Windows CE also defines the unique window message WM_HIBERNATE, which notifies an application when system resources are running low. When an application receives this message, it should try to release as many resources as possible. Every Windows CE-based application must implement a handler for the WM_HIBERNATE message. Place the handler in a class derived from CWnd.

The CCeDocList class wraps the operating system implementation of the DocList window type, with additional features for integration with an MFC Doc/View architecture. The class owns its own CCeCommandBar, initialized with a shared new menu item, during its lifetime, and forwards commands from it to its parent window. It sends a creation-time notification to its parent so that the application can customize DocList and CCeCommandBar attributes. This class responds to the shared new command by sending the ID_FILE_NEW command to the application. For example, it calls CWinApp::OnOpenDocument in response to the DLN_ITEMACTIVATED notification when a user selects a file. For other DLN_ notifications, the parent window should use ON_NOTIFY message maps.

The CCeDocListDocTemplate class is a refinement of the SDI application type, as facilitated by CSingleDocTemplate. Using this class lets an application exist in DocList mode when no document is open, and the user selects a file to open or uses the Shared New command to create a new document.

The CCeSaveModifiedDlg class presents a dialog box with four options: Yes, No, Cancel, and Save As. It does not actually call any document-related member functions, but uses CCeSaveModifiedDlg::DoModal to return IDYES, IDNO, IDCANCEL, or ID_FILE_SAVE_AS. The class is a refinement for the Pocket PC of the MessageBox used by CDocument::SaveModified in other versions of MFC. The application can also directly use this class.
