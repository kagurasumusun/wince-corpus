CListCtrl::GetTextBkColor

This method retrieves the text background color of a list view control.

COLORREF GetTextBkColor( ) 
const;

Return Value

A 32-bit value used to specify an RGB color.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

// Use the 3D button face color for the text background.
COLORREF crBkColor = ::GetSysColor(COLOR_3DFACE);
pmyListCtrl->SetTextBkColor(crBkColor);
ASSERT(pmyListCtrl->GetTextBkColor() == crBkColor);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h

See Also

CListCtrl::SetTextBkColor, CListCtrl::GetTextColor
