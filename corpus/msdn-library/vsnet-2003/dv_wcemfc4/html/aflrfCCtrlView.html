Microsoft Foundation Class Library for Windows CE  

CCtrlView

This class and its derivatives, CEditView, CListView, and CTreeView, adapt the document-view architecture to the common controls supported by Windows CE.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
