CComboBox::GetDroppedState

This method determines whether the list box of a drop-down combo box is visible.

BOOL GetDroppedState( ) 
const;

Return Value

Nonzero if the list box is visible; otherwise, it is zero.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Show the dropdown list box if it is not already dropped.
if (!pmyComboBox->GetDroppedState())
  pmyComboBox->ShowDropDown(TRUE);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
