CBitmapButton::LoadBitmaps

This method loads bitmap images identified by their resource names or identifier numbers, or when the AutoLoad method cannot be used. For example, use this method to create a bitmap button that is not part of a dialog box.

BOOL LoadBitmaps( 
LPCTSTR lpszBitmapResource, 
LPCTSTR lpszBitmapResourceSel = NULL, 
LPCTSTR lpszBitmapResourceFocus = NULL, 
LPCTSTR lpszBitmapResourceDisabled = NULL );

BOOL LoadBitmaps( 
UINT nIDBitmapResource, 
UINT nIDBitmapResourceSel = 0, 
UINT nIDBitmapResourceFocus = 0, 
UINT nIDBitmapResourceDisabled = 0 );

Parameters

lpszBitmapResource
Points to the null-terminated string that contains the name of the bitmap for a bitmap button normal or up state. Required.
lpszBitmapResourceSel
Points to the null-terminated string that contains the name of the bitmap for a bitmap button selected or down state. May be NULL.
lpszBitmapResourceFocus
Points to the null-terminated string that contains the name of the bitmap for a bitmap button focused state. May be NULL.
lpszBitmapResourceDisabled
Points to the null-terminated string that contains the name of the bitmap for a bitmap button disabled state. May be NULL.
nIDBitmapResource
Specifies the resource identifier number of the bitmap resource for a bitmap button normal or up state. Required.
nIDBitmapResourceSel
Specifies the resource identifier number of the bitmap resource for a bitmap button selected or down state. May be 0.
nIDBitmapResourceFocus
Specifies the resource identifier number of the bitmap resource for a bitmap button focused state. May be 0.
nIDBitmapResourceDisabled
Specifies the resource identifier number of the bitmap resource for a bitmap button disabled state. May be 0.

Return Value

Nonzero if it is successful; otherwise it is zero.

Example

CBitmapButton myButton;

// Create the bitmap button (must include the BS_OWNERDRAW style).
myButton.Create(NULL, WS_CHILD|WS_VISIBLE|BS_OWNERDRAW, 
  CRect(10,10,100,100), pParentWnd, 1);

// Load the bitmaps for this button.
myButton.LoadBitmaps(IDB_UP, IDB_DOWN, IDB_FOCUS, IDB_DISABLE);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxext.h
