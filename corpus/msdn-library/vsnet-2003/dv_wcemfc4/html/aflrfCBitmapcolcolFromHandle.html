CBitmap::FromHandle

This method obtains a pointer to a CBitmap object given a Windows CE GDI bitmap. 

static CBitmap* PASCAL FromHandle( 
HPALETTE hPalette );

Parameters

hPalette
Specifies a Windows GDI palette.

Return Value

A pointer to a CBitmap object if it is successful; otherwise, it is NULL.

Remarks

If a CBitmap object is not attached to the handle, a temporary CBitmap object is created and attached. This temporary CBitmap object is valid until the next time the application has idle time in its event loop, at which time all temporary graphic objects are deleted. That is, the temporary object is only valid during the processing of one window message.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
