COleControl::ThrowError

This method signals that an error has occurred in an ActiveX control. This method should only be called from within a Get or Set method for an OLE property, or the implementation of an OLE automation method. If you need to signal errors that occur at other times, you should fire the stock Error event.

void ThrowError( 
SCODE sc, 
UINT nDescriptionID, 
UINT nHelpID = –1 ); 

void ThrowError( 
SCODE sc, 
LPCTSTR pszDescription = NULL, 
UINT nHelpID = 0 );

Parameters

sc
Specifies the status code value to be reported.
nDescriptionID
Specifies the string resource ID of the exception to be reported.
nHelpID
Specifies the help ID of the topic to be reported on.
pszDescription
Specifies a string containing an explanation of the exception to be reported.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
