CCeDBEnum::CCeDBEnum

This constructor creates an instance of a CCeDBEnum object and begins an enumeration of the databases in the object store.

CCeDBEnum ( 
DWORD dwIdent = 0);

Parameters

dwIdent
Specifies the application-defined identifier of the databases to enumerate. The default value of this parameter is zero. When zero is specified, the enumerator enumerates all databases in the object store. If a value other than zero is passed, the enumerator enumerates only those databases that have this type identifier value.

Remarks

Constructing the enumerator begins the enumeration. To get the CEOID of the next database in the object store with the specified identifier, call the method Next. The enumeration ends when Next returns NULL or the CCeDBEnum object is destroyed.

Assign a database its application-defined identifier when you call CCeDBDatabase::Create or by calling CCeDBDatabase::SetIdent.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Wcedb.h
