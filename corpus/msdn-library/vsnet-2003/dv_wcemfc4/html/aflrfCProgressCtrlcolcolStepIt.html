CProgressCtrl::StepIt

This method advances the current position for a progress bar control by the step increment and redraws the bar to reflect the new position. The step increment is set by the CProgressCtrl::SetStep method.

int StepIt( );

Return Value

Returns the previous position of the progress bar control.

Example

CProgressCtrl myCtrl;

// Create a child progress control.
myCtrl.Create(WS_CHILD|WS_VISIBLE, CRect(10,10,200,30), pParentWnd, 1);

// Advance the position to the next step.
myCtrl.StepIt();

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
