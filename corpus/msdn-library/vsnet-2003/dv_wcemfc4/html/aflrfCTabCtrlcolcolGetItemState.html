CTabCtrl::GetItemState

This method retrieves the state of the tab control item identified by nItem. The state of an item is specified by the dwState member of the TCITEM structure. 

DWORD GetItemState( 
int nItem, 
DWORD dwMask, ) 
const;

Parameters

nItem
Specifies the zero-based index number of the item for which to retrieve state information.
dwMask
Specifies the mask specifying which of the state flags of the item to return. For a list of values, see the mask member of the TCITEM structure.
dwState
Specifies a reference to a DWORD value receiving the state information. It can be one of the following values:
Value Description
TCIS_BUTTONPRESSED The tab control item is selected.
TCIS_HIGHLIGHTED The tab control item is highlighted, and the tab and text are drawn using the current highlight color. When using highlight color, this will be a true interpolation, not a dithered color.

Return Value

Nonzero if it is successful; otherwise, it is zero. If successful, dwState receives the state information.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
