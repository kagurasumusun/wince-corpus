CCriticalSection::CCriticalSection

This constructor creates an instance of a CCriticalSection object.

CCriticalSection( );

Remarks

To access or release a CCriticalSection object, create a CSingleLock object and call its Lock and Unlock methods. If the CCriticalSection object is being used stand-alone, call its Unlock method to release it.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxmt.h
