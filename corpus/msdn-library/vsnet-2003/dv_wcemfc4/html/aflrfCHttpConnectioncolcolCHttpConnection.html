CHttpConnection::CHttpConnection

This constructor creates an instance of a CHttpConnection object. You never create a CHttpConnection directly. Rather, you create an object by calling CInternetSession::GetHttpConnection. 

CHttpConnection( 
CInternetSession* pSession, 
HINTERNET hConnected, 
LPCTSTR pstrServer, 
DWORD dwContext ); 

CHttpConnection(

INTERNET_PORT nPort = INTERNET_INVALID_PORT_NUMBER, 
LPCTSTR pstrUserName = NULL,

DWORD dwContext = 1 ); 

CHttpConnection( 
CInternetSession* pSession, 
LPCTSTR pstrServer, 
DWORD dwFlags = 0, 
INTERNET_PORT nPort = INTERNET_INVALID_PORT_NUMBER, 
LPCTSTR pstrUserName = NULL, 
LPCTSTR pstrPassword = NULL, 
DWORD dwContext = 1 );

Parameters

pSession
Pointer to a CInternetSession object.
hConnected
Valid handle to an Http session.
pstrServer
Pointer to a string containing the Http server name.
dwContext
Context identifier for the CHttpConnection object.
nPort
A number that identifies the TCP/IP port to use on the server.
pstrUserName
Pointer to a string containing the user name.
pstrPassword
Pointer to a string containing the access password.
dwFlags
Indicates the two options available for this parameter, Redirect and Secure. The default is 0. See the options for dwFlags in the Remarks section.

Remarks

MFC for Windows CE supports only the following values for the dwFlags parameter:

  • INTERNET_FLAG_NO_AUTO_REDIRECT
  • INTERNET_FLAG_SECURE

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxinet.h
