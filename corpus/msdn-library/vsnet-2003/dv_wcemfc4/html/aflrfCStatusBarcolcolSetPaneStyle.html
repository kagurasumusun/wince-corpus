CStatusBar::SetPaneStyle

This method sets the pane style of a status bar. The pane style determines how the pane appears.

void SetPaneStyle( 
int nIndex, 
UINT nStyle );

Parameters

nIndex
Specifies the index of the pane whose style is to be set.
nStyle
Specifies the style of the pane whose style is to be set.

Remarks

For a list of styles available for status bars, see SetPaneInfo.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
