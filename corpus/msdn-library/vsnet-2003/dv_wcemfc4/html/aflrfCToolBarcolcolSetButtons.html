CToolBar::SetButtons

This method sets the command identifier of each toolbar button to the value specified by the corresponding element of the array lpIDArray. If an element of the array has the ID_SEPARATOR value, a separator is created in the corresponding position of the toolbar. This method also sets the style of each button to TBBS_BUTTON and the style of each separator to TBBS_SEPARATOR, and assigns an image index to each button. The image index specifies the position of the image of the button within the bitmap.

BOOL SetButtons( 
const UINT* lpIDArray, 
int nIDCount );

Parameters

lpIDArray
Specifies the pointer to an array of command Ids. It can be NULL to allocate empty buttons.
nIDCount
Specifies the number of elements in the array pointed to by lpIDArray.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Remarks

You do not need to account for separators in the bitmap because this function does not assign image indexes for separators. If your toolbar has buttons at positions 0, 1, and 3 and a separator at position 2, the images at positions 0, 1, and 2 in your bitmap are assigned to the buttons at positions 0, 1, and 3, respectively.

If lpIDArray is NULL, this function allocates space for the number of items specified by nIDCount. Use SetButtonInfo to set the attributes of each item.

Requirements

  Windows CE versions: 2.10 and later
