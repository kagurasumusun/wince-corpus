CEvent::Unlock

This method releases the event object. This method is called by threads that currently own an automatic event to release it after they are done, if their lock object is to be reused. If the lock object is not to be reused, the Cevent::Unlock method will be called by the destructor of the lock object.

BOOL Unlock( );

Return Value

Nonzero if the thread owned the event object and the event is an automatic event; otherwise, it is zero.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxmt.h
