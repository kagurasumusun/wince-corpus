Microsoft Foundation Class Library for Windows CE  

COleControl::GetCapture

This method determines whether a windowless, activated control object has the mouse capture.

CWnd* GetCapture( );

Return Value

If the control is activated and windowless, returns this if the control currently has the mouse capture, as determined by the control container, or NULL if it does not have the capture.

Otherwise, returns the CWnd object that has the mouse capture, this is the same as CWnd::GetCapture.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
