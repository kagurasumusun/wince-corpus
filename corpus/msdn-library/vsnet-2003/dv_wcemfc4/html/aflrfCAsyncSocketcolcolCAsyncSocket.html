CAsyncSocket::CAsyncSocket

This constructor creates an instance of a blank socket object. After constructing the object, you must call its Create method to create the SOCKET data structure and bind its address. On the server side of a Windows CE Sockets communication, when the listening socket creates a socket to use in the Accept call, do not call Create for that socket.
