CWinApp::m_bHelpMode

This data member contains a Boolean value that is set to TRUE if the application is in Help context mode, this is conventionally invoked with SHIFT + F1, and FALSE if not. Examine this flag if you want to implement special handling when in the Help mode.

The m_bHelpMode data member is a public variable of type BOOL.

BOOL m_bHelpMode;

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
