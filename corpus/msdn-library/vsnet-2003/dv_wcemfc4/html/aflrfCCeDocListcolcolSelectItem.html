Microsoft Foundation Class Library for Windows CE  

CCeDocList::SelectItem

This method causes the item associated with the path to be selected.

HRESULT SelectItem( 
LPTSTR pszPath, 
BOOL bVisible );
pszPath
Pointer to the string containing the pathname.
bVisible
Indicates whether the document has become visible or invisible.

Return Value

TRUE or nonzero indicates success; FALSE or zero indicates failure.

Requirements

Windows CE versions: 3.0 and later
Header file: Declared in Afxext.h
