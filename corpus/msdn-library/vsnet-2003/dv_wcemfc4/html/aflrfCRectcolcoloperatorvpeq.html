CRect::operator |=

This operator sets a CRect object equal to the union of itself and the parameter passed in the rect parameter. The union is the smallest rectangle that contains both source rectangles.

Both of the rectangles must be normalized or this method may fail. You can call NormalizeRect to normalize the rectangles before calling this method.

void operator |=( 
const RECT& rect );

Parameters

rect
Contains a CRect or RECT.

Example

CRect  rect1(100,   0, 200, 300);
CRect  rect2(  0, 100, 300, 200);

rect1 |= rect2;

CRect  rectResult(0, 0, 300, 300);
ASSERT(rectResult == rect1);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
