CListCtrl::GetCountPerPage

This method calculates the number of items that can fit vertically in the visible area of a list view control when in list view or report view.

int GetCountPerPage( ) 
const;

Return Value

The number of items that can fit vertically in the visible area of a list view control when in list view or report view.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

// Make sure the focus is set to the list view control.
pmyListCtrl->SetFocus();

// Select all of the items that are completely visible.
int n = pmyListCtrl->GetTopIndex();
int nLast = n + pmyListCtrl->GetCountPerPage();

for (;n < nLast;n++)
{
  pmyListCtrl->SetItemState(n, LVIS_SELECTED, LVIS_SELECTED);
  ASSERT(pmyListCtrl->GetItemState(n, LVIS_SELECTED) == LVIS_SELECTED);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
