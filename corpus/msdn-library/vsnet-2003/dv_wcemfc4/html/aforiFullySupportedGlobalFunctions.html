Fully Supported Global Functions

MFC for Windows CE includes support for many global functions, including those in the following table. MFC for Windows CE also supports AfxParseURL, but does not support Gopher or FTP service types.

Available in Windows CE but not in the desktop version of MFC is AfxGetCeSocketWindow. Use this function to retrieve a window handle to which you can send socket notifications.

For the most complete information, look for the function name in the Help index.
