CTime::GetLocalTm

This method gets a struct tm that contains a decomposition of the time contained in this CTime object. GetLocalTm returns local time.

struct tm* GetLocalTm( 
struct tm* ptm = NULL ) 
const;

Parameters

ptm
Points to a buffer that will receive the time data. If this pointer is NULL, an internal, statically allocated buffer is used. The data in this default buffer is overwritten as a result of calls to other CTime methods.

Return Value

A pointer to a filled-in struct tm as defined in the include file Time.h.

Example

// example for CTime::GetLocalTm
CTime t( 1999, 3, 19, 22, 15, 0 ); // 10:15PM March 19, 1999
struct tm* osTime;  // A pointer to a structure containing time 
                    // elements.
osTime = t.GetLocalTm( NULL );
ASSERT( osTime->tm_mon == 2 ); // Note zero-based month!

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
