Microsoft Foundation Class Library for Windows CE  

CDataExchange::CDataExchange

This method constructs a CDataExchange object.

CDataExchange( 
CWnd* pDlgWnd, 
BOOL bSaveAndValidate );

Parameters

pDlgWnd
Pointer to the parent window that contains the control. Usually this is a CDialog-derived object.
bSaveAndValidate
If TRUE, this object validates data and writes data from the controls to the members. If FALSE, this object moves data from members to controls.

Remarks

Construct a CdataExchange object to store extra information in the data exchange object to pass to the window CWnd::DoDataExchange method.

Example

CYourDataExchange dx(this, FALSE);

TRY
{
   DoDataExchange(&dx);
}
CATCH(CUserException, e)
        { 
    // Some part of the exchange went wrong,
    // but the user has been notified.
        }

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
