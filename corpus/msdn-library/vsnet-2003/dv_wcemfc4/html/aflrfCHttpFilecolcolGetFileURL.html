Microsoft Foundation Class Library for Windows CE  

CHttpFile::GetFileURL

This method returns the name of the HTTP file as a Uniform Resource Locator (URL). Use this method only after a successful call to SendRequest or on a CHttpFile object successfully created by OpenURL.

virtual CString GetFileURL( ) 
const;

Return Value

A CString object containing a URL referencing the resource associated with this file.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxinet.h
