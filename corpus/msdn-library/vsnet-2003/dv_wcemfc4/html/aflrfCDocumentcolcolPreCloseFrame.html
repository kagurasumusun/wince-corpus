CDocument::PreCloseFrame

This method is called by the framework before the frame window is destroyed. You can override this method to provide custom cleanup, but be sure to call the base class as well.

The default of PreCloseFrame does nothing in CDocument.

virtual void PreCloseFrame( 
CFrameWnd* pFrame );

Parameters

pFrame
Specifies the pointer to the CFrameWnd that holds the associated CDocument object.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
