CTime

A CTime object represents an absolute time and date, based on coordinated universal time (UTC), which is equivalent to Greenwich mean time (GMT). The local time zone is controlled by the TZ environment variable.

CTime does not have a base class.

When creating a Ctime object, settings for the nDST parameter are by default set to 0 to indicate that standard time is in effect. It will compute whether standard time or daysavings time is in effect.

tm_isdst is a required field. If not set, its value is undefined and the return value from mktime is unpredictable. If timeptr points to a tm structure returned by a previous call to asctime, gmtime, or localtime, the tm_isdst field contains the correct value.

A companion class, CTimeSpan, represents a time interval.

The CTime and CTimeSpan classes are not designed for derivation. Because there are no virtual functions, the size of CTime and CTimeSpan objects is exactly 8 bytes. Most methods are inline.

The upper date limit is 1/18/2038. For a wider range of dates, see COleDateTime.

Remarks

MFC for Windows CE does not support the following methods of the CTime class:

  • GetGmtTm
  • Format
  • FormatGmt

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
