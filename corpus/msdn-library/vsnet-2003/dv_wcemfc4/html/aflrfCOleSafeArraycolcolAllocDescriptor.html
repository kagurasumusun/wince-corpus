COleSafeArray::AllocDescriptor

This method allocates memory for the safe array descriptor. On error, the method throws a CMemoryException or COleException.

void AllocDescriptor( 
DWORD dwDims );

Parameters

dwDims
Specifies the number of dimensions in the safe array.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
