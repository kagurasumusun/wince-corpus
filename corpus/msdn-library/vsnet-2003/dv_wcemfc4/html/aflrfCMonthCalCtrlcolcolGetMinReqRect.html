CMonthCalCtrl::GetMinReqRect

This method retrieves the minimum size required to display a full month in a month calendar control.

This method implements the behavior of the Windows CE message MCM_GETMINREQRECT. 

BOOL GetMinReqRect( 
RECT* pRect ) 
const;

Parameters

pRect
Specifies a pointer to a RECT structure that will receive bounding rectangle information. This parameter must be a valid address and cannot be NULL.

Return Value

If successful, this method returns nonzero and lpRect receives the applicable bounding information. If unsuccessful, the method returns zero.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxdtctl.h
