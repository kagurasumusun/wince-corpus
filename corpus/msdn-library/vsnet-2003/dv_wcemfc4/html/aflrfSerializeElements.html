Microsoft Foundation Class Library for Windows CE  

SerializeElements

CArray, CList, and CMap call this function to serialize elements. The default implementation does a bit-wise read or write.

template< class TYPE > 
void AFXAPI SerializeElements( 
CArchive& ar, TYPE* pElements, 
int nCount );

Parameters

TYPE
Template parameter specifying the type of the elements.
ar
Specifies an archive object to archive to or from.
pElements
Specifies the pointer to the elements being archived.
nCount
Specifies the number of elements being archived

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxtempl.h
