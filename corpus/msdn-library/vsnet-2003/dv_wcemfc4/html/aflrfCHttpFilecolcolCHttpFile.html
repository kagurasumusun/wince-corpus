CHttpFile::CHttpFile

This constructor creates an instance of a CHttpFile object.

You never construct a CHttpFile object directly; rather, call CInternetSession::OpenURL or CHttpConnection::OpenRequest instead.

CHttpFile( 
HINTERNET hFile, 
HINTERNET hSession, 
LPCTSTR pstrObject, 
LPCTSTR pstrServer, 
LPCTSTR pstrVerb, 
DWORD dwContext );

CHttpFile( 
HINTERNET hFile, 
LPCTSTR pstrVerb, 
LPCTSTR pstrObject, 
CHttpConnection* pConnection );

Parameters

hFile
Specifies a handle to an Internet file.
hSession
Specifies a handle to an Internet session.
pstrObject
Specifies a pointer to a string containing the CHttpFile object.
pstrServer
Specifies a pointer to a string containing the name of the server.
pstrVerb
Specifies a pointer to a string containing the method to be used when sending the request. Can be POST, HEAD, or GET.
dwContext
Specifies the context identifier for the CHttpFile object. See the Remarks section for more information about this parameter.
pConnection
A pointer to a CHttpConnection object.

Remarks

The default value for dwContext is sent by MFC for Windows CE to the CHttpFile object from the CInternetSession object that created the CHttpFile object. When you call CInternetSession::OpenURL or CHttpConnection to construct a CHttpFile object, you can override the default to set the context identifier to a value of your choosing. The context identifier is returned to CInternetSession::OnStatusCallback to provide status on the object with which it is identified.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxinet.h
