CTime::GetMinute

This method retrieves the minute, based on local time, in the range 0 through 59. This method calls GetLocalTm, which uses an internal, statically allocated buffer. The data in this buffer is overwritten as a result of calls to other CTime methods.

int GetMinute( ) 
const;

Example

// example for CTime::GetHour, CTime::GetMinute, and CTime::GetSecond
CTime t( 1999, 3, 19, 22, 15, 0 ); // 10:15PM March 19, 1999
ASSERT( t.GetSecond() == 0 );
ASSERT( t.GetMinute() == 15 );
ASSERT( t.GetHour() == 22 );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
