Microsoft Foundation Class Library for Windows CE  

CSpinButtonCtrl::GetPos

This method retrieves the current position of a spin button control. When it processes the value that is returned, the control updates its current position based on the caption of the buddy window. The control returns an error if there is no buddy window or if the caption specifies an invalid or out-of-range value.

int GetPos( ) 
const;

Return Value

The current position in the low-order word. The high-order word is nonzero if an error occurred.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
