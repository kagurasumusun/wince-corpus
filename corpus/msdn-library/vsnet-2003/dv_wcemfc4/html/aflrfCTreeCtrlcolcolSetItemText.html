CTreeCtrl::SetItemText

This method sets the text of the item specified by hItem.

BOOL SetItemText( 
HTREEITEM hItem, 
LPCTSTR lpszItem );

Parameters

hItem
Specifies the handle of the item whose text is to be set.
lpszItem
Specifies the address of a string containing the new text for the item

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// The pointer to my tree control.
extern CTreeCtrl* pmyTreeCtrl;
// The point to hit test.
extern CPoint myPoint;

// Clear the text of the item at point myPoint.
UINT uFlags;
HTREEITEM hItem = pmyTreeCtrl->HitTest(myPoint, &uFlags);

if ((hItem != NULL) && (TVHT_ONITEM & uFlags))
{
  pmyTreeCtrl->SetItemText(hItem, NULL);
}

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
