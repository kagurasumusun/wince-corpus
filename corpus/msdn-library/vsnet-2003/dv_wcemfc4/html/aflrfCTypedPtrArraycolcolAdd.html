CTypedPtrArray::Add

This method adds a new element to the end of an array, growing the array by one.

int Add( 
TYPE newElement );

Parameters

TYPE
Template parameter specifying the type of element to be added to the array.
newElement
Specifies the element to be added to this array.

Return Value

Returns the index of the added element.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxtempl.h
