CReBarCtrl::SetTextColor

This method sets the default text color for a rebar control.

This method implements the behavior of the Windows CE message RB_SETTEXTCOLOR. It is provided to support text color flexibility in a rebar control.

COLORREF SetTextColor( 
COLORREF clr );

Parameters

clr
Specifies a COLORREF value that represents the new text color in the CReBarCtrl object.

Return Value

The COLORREF value representing the previous text color associated with the CReBarCtrl object.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
