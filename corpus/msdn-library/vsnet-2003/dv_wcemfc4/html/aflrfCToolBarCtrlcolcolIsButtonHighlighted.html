CToolBarCtrl::IsButtonHighlighted

This method checks the highlight state of a toolbar button.

BOOL IsButtonHighlighted( 
int nID ) 
const;

Parameters

nID
The command ID for the toolbar button.

Return Value

Nonzero if the button is highlighted; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
