CDC::GetPixel

This method retrieves the RGB color value of the pixel at the point specified by x and y.

COLORREF GetPixel( 
int x, 
int y ) 
const;

COLORREF GetPixel( 
POINT point ) 
const;

Parameters

x
The logical x-coordinate of the point to examine.
y
The logical y-coordinate of the point to examine.
point
The logical x- and y-coordinates of the point to examine.

Return Value

For either version of the function, an RGB color value for the color of the given point. It is –1 if the coordinates do not specify a point in the clipping region.

Remarks

The point must be in the clipping region. If the point is not in the clipping region, the function has no effect and returns –1.

Not all devices support the GetPixel function. For more information, see the RC_BITBLT raster capability under the GetDeviceCaps method.

The GetPixel method has two forms. The first takes two coordinate values; the second takes a POINT structure or a CPoint object.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
