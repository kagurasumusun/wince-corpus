Microsoft Foundation Class Library for Windows CE  

ActiveX Type Wrappers

MFC for Windows CE supports the CFontHolder class the same way standard MFC does except that it only supports a subset of the IFont interfaces. MFC for Windows CE does not support the CPictureHolder class.

For information about where the CFontHolder class fits into the Windows CE class hierarchy, see Classes Not Derived from CObject.
