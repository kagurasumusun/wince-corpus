CTypedPtrArray

This class provides a type-safe wrapper for objects of class CPtrArray or CObArray. When you use CTypedPtrArray rather than CPtrArray or CObArray, the C++ type-checking facility helps eliminate errors caused by mismatched pointer types.

template< 
class BASE_CLASS, 
class TYPE > 
class CTypedPtrArray : 
public BASE_CLASS

Parameters

BASE_CLASS
Specifies the base class of the typed pointer array class; must be an array class (CObArray or CPtrArray).
TYPE
Specifies the type of the elements stored in the base-class array.

Remarks

In addition, the CTypedPtrArray wrapper performs much of the casting that would be required if you used CObArray or CPtrArray.

Because all CTypedPtrArray functions are inline, use of this template does not significantly affect the size or speed of your code.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxtempl.h
