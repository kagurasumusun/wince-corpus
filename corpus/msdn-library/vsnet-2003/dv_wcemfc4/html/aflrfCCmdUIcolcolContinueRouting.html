Microsoft Foundation Class Library for Windows CE  

CCmdUI::ContinueRouting

This method tells the command-routing mechanism to continue routing the current message down the chain of handlers.

void ContinueRouting( );

Remarks

This is an advanced method that should be used in conjunction with an ON_COMMAND_EX handler that returns FALSE.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
