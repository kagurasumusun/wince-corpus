CWnd::GetOpenClipboardWindow

This method obtains the handle to the window that currently has the clipboard open.

static CWnd* PASCAL GetOpenClipboardWindow( );

Return Value

The handle of the window that currently has the Clipboard open if the method is successful; otherwise, it is NULL.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
