Microsoft Foundation Class Library for Windows CE  

CDC::SaveDC

This method saves the state of the device context by copying state information, such as clipping region, selected objects, and mapping mode, to a context stack maintained by Windows CE. The saved device context can later be restored by using RestoreDC.

virtual int SaveDC( );

Return Value

An integer identifying the saved device context. It is zero if an error occurs. This return value can be used to restore the device context by calling RestoreDC.

Remarks

SaveDC can be used any number of times to save any number of device-context states.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
