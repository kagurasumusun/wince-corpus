CRgn::SetRectRgn

This method creates a rectangular region. The CRgn object must already have been initialized with a valid Windows CE region before calling SetRectRgn.

Unlike CreateRectRgn, however, it does not allocate any additional memory from the local Windows CE application heap. Instead, it uses the space allocated for the region stored in the CRgn object. The points given by x1, y1, x2, and y2 specify the minimum size of the allocated space.

Use this method instead of the CreateRectRgn method to avoid calls to the local memory manager.

void SetRectRgn ( 
int x1, 
int y1, 
int x2, 
int y2 ); 

void SetRectRgn( 
LPCRECT lpRect );

Parameters

x1
Specifies the x-coordinate of the upper-left corner of the rectangular region.
y1
Specifies the y-coordinate of the upper-left corner of the rectangular region.
x2
Specifies the x-coordinate of the lower-right corner of the rectangular region.
y2
Specifies the y-coordinate of the lower-right corner of the rectangular region.
lpRect
Specifies the rectangular region. Can be either a pointer to a RECT structure or a CRect object.

Remarks

The CRgn::SetRectRgn method is included for compatibility with existing code. The CRgn::SetRectRgn method in Windows CE just calls CRgn::CreateRectRgn; you do not save a memory allocation by using this method.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
