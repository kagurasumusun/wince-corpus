CSplitterWnd::GetColumnInfo

This method obtains information about the specified column. 

void GetColumnInfo( 
int col, 
int& cxCur, 
int& cxMin ) 
const;

Parameters

col
Specifies a column.
cxCur
Specifies a reference to an int to be set to the current width of the column.
cxMin
Specifies a reference to an int to be set to the current minimum width of the column.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
