CFindReplaceDialog::MatchCase

This method determines whether the user wants to match the case of the find string exactly.

BOOL MatchCase( ) 
const;

Return Value

Nonzero if the user wants to find occurrences of the search string that matches the case exactly of the search string; otherwise, it is zero.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxdlgs.h
