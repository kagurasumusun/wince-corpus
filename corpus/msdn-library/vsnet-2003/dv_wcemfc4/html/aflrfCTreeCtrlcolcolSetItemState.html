CTreeCtrl::SetItemState

This method sets the state of the item specified by hItem. For information about states, see CTreeCtrl::GetItem.

BOOL SetItemState( 
HTREEITEM hItem, 
UINT nState, 
UINT nStateMask );

Parameters

hItem
Specifies the handle of the item whose state is to be set.
nState
Specifies new states for the item.
nStateMask
Specifies which states are to be changed.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

See the example for CTreeCtrl::GetItemState.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
