CMemFile::Memcpy

This method is called by the CMemFile overrides of CFile::Read and CFile::Write to transfer data to and from the memory file. Override this method to change the way that CMemFile handles copying memory files.

virtual BYTE* Memcpy( 
BYTE* lpMemTarget, 
const BYTE* lpMemSource, 
UINT nBytes );

Parameters

lpMemTarget
Specifies the pointer to the memory block into which the source memory will be copied.
lpMemSource
Specifies the pointer to the source memory block.
nBytes
Specifies the number of bytes to be copied.

Return Value

Returns a copy of lpMemTarget.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Afx.h

See Also

CFile::Read, CFile::Write
