Microsoft Foundation Class Library for Windows CE  

CMemoryException

This class encapsulates an out-of-memory exception condition. No further qualification is necessary or possible. Memory exceptions are thrown automatically by new. For example, if you write your own memory functions using malloc, you are responsible for throwing memory exceptions.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
