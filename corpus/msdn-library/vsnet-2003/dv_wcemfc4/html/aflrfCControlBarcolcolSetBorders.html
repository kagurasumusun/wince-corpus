Microsoft Foundation Class Library for Windows CE  

CControlBar::SetBorders

This method sets the size of the borders of a control bar.

void SetBorders( 
int cxLeft = 0, 
int cyTop = 0, 
int cxRight = 0, 
int cyBottom  = 0 );

void SetBorders( 
LPCRECT lpRect );

Parameters

cxLeft
Specifies the width, in pixels of the left border of the control bar.
cyTop
Specifies the height, in pixels of the top border of the control bar.
cxRight
Specifies the width, in pixels, of the right border of the control bar.
cyBottom
Specifies the height, in pixels, of the bottom border of the control bar.
lpRect
A pointer to a CRect object that contains the width, in pixels, of each border of the control bar object.

Example

The following code example sets the top and bottom borders of the control bar to 5 pixels, and the left and right borders to 2 pixels:

m_myControlBar.SetBorders(2, 5, 2, 5);

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxext.h
