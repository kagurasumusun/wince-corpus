CCeDocListDocTemplate

This class is a refinement of the SDI application type, as facilitated by CSingleDocTemplate. Using this class lets an application exist in DocList mode when no document is open. The user selects a file to open or uses the Shared New command to create a new document.

After adding this document type to the application, call the ShowDocList member to initially create a CCeDocList.

See DocList Creation for instances in which a CCeDocList is created. Also see Changes to the CCeSaveModifiedDlg for related file management issues.

Derivation

CSingleDocTemplate

Remarks

The DocList is automatically created in the following two ways:

  • When CCeDocListDocTempate::ShowDocList is called.
  • When documents are closed with CDocument::OnCloseDocument, also called implicitly through CWinApp::OnCloseDocument, and the application has not received a WM_CLOSE message.

Requirements

Windows CE versions: 3.0 and later
Header file: Declared in Afxwin.h
