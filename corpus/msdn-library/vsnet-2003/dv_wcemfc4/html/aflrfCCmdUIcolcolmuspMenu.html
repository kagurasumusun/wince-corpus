Microsoft Foundation Class Library for Windows CE  

CCmdUI::m_pMenu

This data member contains a pointer to the menu, a CMenu object, represented by the CCmdUI object.

CMenu* m_pMenu;

Remarks

This data members value is NULL if the item is not a menu.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
