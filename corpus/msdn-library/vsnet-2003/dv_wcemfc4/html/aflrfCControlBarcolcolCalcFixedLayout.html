CControlBar::CalcFixedLayout

This method calculates the horizontal size of a control bar.

virtual CSize CalcFixedLayout( 
BOOL bStretch, 
BOOL bHorz );

Parameters

bStretch
Indicates whether the bar should be stretched to the size of the frame. The bStretch parameter is nonzero when the bar is not a docking bar, and zero when it is docked or floating.
bHorz
Indicates that the bar is horizontally or vertically oriented. The bHorz parameter is nonzero if the bar is horizontally oriented, and zero if it is vertically oriented.

Return Value

The control bar size, in pixels, of a CSize object.

Remarks

Control bars such as toolbars can stretch horizontally or vertically to accommodate the buttons contained in the control bar.

If bStretch is TRUE, stretch the dimension along the orientation provided by bHorz. When bHorz is FALSE, the control bar is stretched vertically. If bStretch is FALSE, no stretch occurs. The following table shows the possible permutations and resulting control-bar styles of bStretch and bHorz.
