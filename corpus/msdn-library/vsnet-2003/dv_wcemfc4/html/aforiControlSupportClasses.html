Microsoft Foundation Class Library for Windows CE  

Control Support Classes

MFC for Windows CE supports the CImageList class the same way standard MFC does, and it does not support the CDockState class at all.

For information about where the CImageList class fits into the Windows CE class hierarchy, see Classes Derived from CObject.
