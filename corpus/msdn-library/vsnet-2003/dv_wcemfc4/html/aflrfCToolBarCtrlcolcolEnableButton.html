CToolBarCtrl::EnableButton

This method enables or disables the specified button in a toolbar control. When a button has been enabled, it can be pressed and checked. To change more than one button state, consider calling SetState instead.

BOOL EnableButton( 
int nID, 
BOOL bEnable = TRUE );

Parameters

nID
Specifies the command identifier of the button to enable or disable.
bEnable
TRUE to enable the button; FALSE to disable the button.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
