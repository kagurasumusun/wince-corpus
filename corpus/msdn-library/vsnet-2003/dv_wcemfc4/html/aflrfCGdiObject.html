CGdiObject

This class is the abstract base class for various kinds of Windows CE graphics device interface (GDI) objects such as bitmaps, regions, brushes, pens, palettes, and fonts. You never create a CGdiObject directly. Rather, you create an object from one of its derived classes, such as CPen or CBrush.

Remarks

MFC for Windows CE supports the following methods of the CGdiObject class differently than the standard MFC does:

  • CGdiObject::CreateStockObject
  • CGdiObject::DeleteObject
  • CGdiObject::GetObjectType

MFC for Windows CE does not support the UnrealizeObject method of the CGdiObject class.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
