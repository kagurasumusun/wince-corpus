CWinApp::SetRegistryKey

This method causes application settings to be stored in the registry instead of .ini files. 

void SetRegistryKey( 
LPCTSTR lpszRegistryKey ); 

void SetRegistryKey( 
UINT nIDRegistryKey );

Parameters

lpszRegistryKey
Specifies a pointer to a string containing the name of the key.
nIDRegistryKey
Specifies the ID/index of a key in the registry.

Remarks

This method sets m_pszRegistryKey, which is then used by the GetProfileInt, GetProfileString, WriteProfileInt, and WriteProfileString methods of CWinApp. If this method has been called, the list of most recently-used (MRU) files is also stored in the registry. The registry key is usually the name of a company. It is stored in a key of the following form: HKEY_CURRENT_USER\Software\<company name>\<application name>\<section name>\<value name>.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
