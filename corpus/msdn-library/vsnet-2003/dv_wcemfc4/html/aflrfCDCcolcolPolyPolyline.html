CDC::PolyPolyline

This method draws multiple series of connected line segments.

BOOL PolyPolyline( 
const POINT* lpPoints, 
const DWORD* lpPolyPoints, 
int nCount );

Parameters

lpPoints
Pointer to an array of structures that contains the vertices of the polylines. The polylines are specified consecutively.
lpPolyPoints
Pointer to an array of variables that specifies the number of points in the lpPoints array for the corresponding polygon. Each entry must be greater than or equal to two.
nCount
The total number of counts in the lpPolyPoints array.

Return Value

Nonzero if the function is successful; otherwise, it is zero.

Remarks

The line segments are drawn by using the current pen. The figures formed by the segments are not filled. The current position is neither used nor updated by this function.

See Also

CDC::Polyline, CDC::PolylineTo
