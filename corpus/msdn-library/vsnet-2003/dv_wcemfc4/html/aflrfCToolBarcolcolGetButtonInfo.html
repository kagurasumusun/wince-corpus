CToolBar::GetButtonInfo

This method retrieves the control identifier, style, and image index of the toolbar button or separator at the location specified by nIndex. Those values are assigned to the variables referenced by nID, nStyle, and iImage. The image index is the position of the image within the bitmap that contains images for all the toolbar buttons. The first image is at the zero position.

If nIndex specifies a separator, iImage is set to the separator width in pixels.

void GetButtonInfo( 
int nIndex, 
UINT& nID, 
UINT& nStyle, 
int& iImage ) 
const;

Parameters

nIndex
Specifies the index of the toolbar button or separator whose information is to be retrieved.
nID
Specifies the reference to a UINT that is set to the command ID of the button.
nStyle
Specifies the reference to a UINT that is set to the style of the button.
iImage
Specifies the reference to an integer that is set to the index of the image of the button within the bitmap.

Requirements

  Windows CE versions: 2.10 and later
