CDocument::GetTitle

This method retrieves the title of the document, which is usually derived from the filename of the document.

const CString& GetTitle( ) 
const;

Return Value

Returns the title of the document.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
