CFindReplaceDialog::m_bShowBar

The Boolean value of this data member determines whether the Find/Replace Continuation Bar is displayed.

BOOL m_bShowBar;

Remarks

The CFindReplaceDialog class has been specialized to work better with the Palm-size PC form factor. Pressing the Find or Replace button contained in the initial Find/Replace dialog box sends the usual find/replace messages to the parent window. The application is expected to decide whether continuation of the find/replace activity should take place, so before returning from those handlers, m_bShowBar should be set to TRUE if the continuation bar should be displayed. This continuation bar sends the same messages to the parent window.

The default value for this member is TRUE.

Requirements

Windows CE versions: 3.0 and later
Header file: Declared in Afxdlgs.h
