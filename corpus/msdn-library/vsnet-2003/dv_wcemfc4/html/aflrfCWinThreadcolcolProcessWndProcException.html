CWinThread::ProcessWndProcException

This method is called by the framework whenever the handler does not catch an exception thrown in one of the message or command handlers of your thread.

virtual LRESULT ProcessWndProcException( 
CException* e, 
const MSG* pMsg );

Parameters

e
Points to an unhandled exception.
pMsg
Points to a MSG structure containing information about the windows message that caused the framework to throw an exception.

Return Value

–1 if a WM_CREATE exception is generated; otherwise, it is zero.

Remarks

Do not call this method directly.

The default implementation of this method handles only exceptions generated from the following messages:

Command Action
WM_CREATE Fail.
WM_PAINT Validate the affected window, thus preventing another WM_PAINT message from being generated.

Override this method to provide global handling of your exceptions. Call the base functionality only if you wish to display the default behavior.

This method is used only in threads that have a message pump.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
