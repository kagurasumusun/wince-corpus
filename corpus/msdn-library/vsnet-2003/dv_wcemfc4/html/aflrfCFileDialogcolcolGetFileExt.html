CFileDialog::GetFileExt

This method retrieves the extension of the file name entered into the dialog box. For example, if the name of the file entered is Data.txt, GetFileExt returns the txt extension.

CString GetFileExt( ) 
const;

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxdlgs.h
