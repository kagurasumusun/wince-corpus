CComboBox::Copy

This method copies the selection in the edit control of the combo box to the clipboard in CF_TEXT format.

void Copy( );

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Copy the text from the combo box edit control to the clipboard.
pmyComboBox->SetEditSel(0, -1);
pmyComboBox->Copy();

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h

CComboBox::Clear, CComboBox::Cut, CComboBox::Paste
