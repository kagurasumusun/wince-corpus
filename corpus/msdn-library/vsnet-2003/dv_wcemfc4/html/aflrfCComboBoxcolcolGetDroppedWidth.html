CComboBox::GetDroppedWidth

This method retrieves the minimum allowable width, in pixels, of the list box of a combo box.

int GetDroppedWidth( ) 
const;

Return Value

If successful, the minimum allowable width, in pixels; otherwise, it is CB_ERR.

Remarks

This method only applies to combo boxes with the CBS_DROPDOWN or CBS_DROPDOWNLIST.

By default, the minimum allowable width of the drop-down list box is zero. The minimum allowable width can be set by calling SetDroppedWidth. When the list box portion of the combo box is displayed, its width is the larger of the minimum allowable width or the combo box width.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Find the longest string in the combo box.
CString str;
CSize   sz;
int     dx=0;
CDC*    pDC = pmyComboBox->GetDC();
for (int i=0;i < pmyComboBox->GetCount();i++)
{
  pmyComboBox->GetLBText( i, str );
  sz = pDC->GetTextExtent(str);

  if (sz.cx > dx)
    dx = sz.cx;
}
pmyComboBox->ReleaseDC(pDC);

// Adjust the width for the vertical scroll bar and the left and right
// border.
dx += ::GetSystemMetrics(SM_CXVSCROLL) + 2*::GetSystemMetrics(SM_CXEDGE);

// If the list box width is too small, adjust it so that every item is 
// completely visible.
if (pmyComboBox->GetDroppedWidth() < dx)
{
  pmyComboBox->SetDroppedWidth(dx);
  ASSERT(pmyComboBox->GetDroppedWidth() == dx);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
