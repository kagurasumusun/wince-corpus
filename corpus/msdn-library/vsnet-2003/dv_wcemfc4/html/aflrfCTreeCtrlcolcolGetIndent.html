CTreeCtrl::GetIndent

This method retrieves the amount, in pixels, that child items are indented relative to their parent items.

UINT GetIndent( ) 
const;

Return Value

The amount of indentation measured in pixels.

Example

// The pointer to my tree control.
extern CTreeCtrl* pmyTreeCtrl;

// Double the indent.
UINT uIndent = pmyTreeCtrl->GetIndent();
pmyTreeCtrl->SetIndent(2*uIndent);

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
