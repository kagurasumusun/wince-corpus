CImageList::Create

This method creates an image list and attaches it to the CImageList object.

To construct a CImageList object, call the constructor; then call Create.

BOOL Create( 
int cx, 
int cy, 
UINT nFlags, 
int nInitial, 
int nGrow ); 

BOOL Create( 
UINT nBitmapID, 
int cx, 
int nGrow, 
COLORREF crMask );

int nImage1, 
CImageList& imagelist2, 
int nImage2, 
int dx, 
int dy ); 

BOOL Create( 
CImageList* pImageList );

Parameters

cx
Specifies the dimensions of each image, in pixels.
cy
Specifies the dimensions of each image, in pixels.
nFlags
Specifies the type of image list to create. This parameter can be a combination of the following values, but it can include only one of the ILC_COLOR values.
Value Description
ILC_COLOR Use the default behavior if none of the other ILC_COLOR* flags is specified. Typically, the default is ILC_COLOR4; but for older display drivers, the default is ILC_COLORDDB.
ILC_COLOR4 Use a 4-bit (16 color) device-independent bitmap (DIB) section as the bitmap for the image list.
ILC_COLOR8 Use an 8-bit DIB section. The colors used for the color table are the same colors as the halftone palette.
ILC_COLOR16 Use a 16-bit (32/64k color) DIB section.
ILC_COLOR24 Use a 24-bit DIB section.
ILC_COLOR32 Use a 32-bit DIB section.
ILC_COLORDDB Use a device-dependent bitmap.
ILC_MASK Uses a mask. The image list contains two bitmaps, one of which is a monochrome bitmap used as a mask. If this value is not included, the image list contains only one bitmap.
nInitial
Specifies the number of images that the image list initially contains.
nGrow
Specifies the number of images by which the image list can grow when the system needs to resize the list to make room for new images. This parameter represents the number of new images the resized image list can contain.
nBitmapID
Specifies the resource identifiers of the bitmap to be associated with the image list.
crMask
Specifies the color used to generate a mask. Each pixel of this color in the specified bitmap is changed to black, and the corresponding bit in the mask is set to one.
lpszBitmapID
Specifies a string containing the resource identifiers of the images.
imagelist1
Specifies a reference to a CImageList object.
nImage1
Specifies the index of the first existing image.
imagelist2
Specifies a reference to a CImageList object.
nImage2
Specifies the index of the second existing image.
dx
Specifies the offset of the x-axis of the second image in relationship to the first image, in pixels.
dy
Specifies the offset of the y-axis of the second image in relationship to the first image, in pixels.
pImageList
Specifies a pointer to a CImageList object.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// Pointer to the myImageList.
extern CImageList* pmyImageList;

pmyImageList->Create(32, 32, ILC_COLOR8, 0, 4);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
