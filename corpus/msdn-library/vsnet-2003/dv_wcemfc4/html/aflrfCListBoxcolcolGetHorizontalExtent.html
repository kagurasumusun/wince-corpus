CListBox::GetHorizontalExtent

This method retrieves the width in pixels by which the list box can be scrolled horizontally. This is applicable only if the list box has a horizontal scroll bar.

int GetHorizontalExtent( ) 
const;

Return Value

The scrollable width of the list box, in pixels.

Example

// Pointer to the myListBox.
extern CListBox* pmyListBox;

// Find the longest string in the list box.
CString str;
CSize   sz;
int     dx=0;
CDC*    pDC = pmyListBox->GetDC();
for (int i=0;i < pmyListBox->GetCount();i++)
{
  pmyListBox->GetText( i, str );
  sz = pDC->GetTextExtent(str);

  if (sz.cx > dx)
    dx = sz.cx;
}
pmyListBox->ReleaseDC(pDC);

// Set the horizontal extent only if the current extent is not large enough.
if (pmyListBox->GetHorizontalExtent() < dx)
{
  pmyListBox->SetHorizontalExtent(dx);
  ASSERT(pmyListBox->GetHorizontalExtent() == dx);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
