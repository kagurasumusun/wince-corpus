CFileException::ThrowOsError

This method throws a CFileException that corresponds to a specified lOsError value. 

static void PASCAL ThrowOsError( 
LONG lOsError 
LPCTSTR lpszFileName = NULL);

Parameters

lOsError
Specifies an operating-system-specific error code.
lpszFileName
Specifies a pointer to the string containing the name of the file that caused the exception, if available.

Example

// Example for the CFileException::ThrowOsError method.
CFileException::ThrowOsError( 5 );  // "access denied"

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
