CToolBarCtrl::SetDisabledImageList

This method sets the image list that the toolbar control uses to display disabled buttons.

This method implements the behavior of the Windows CE message TB_SETDISABLEDIMAGELIST.

CImageList* SetDisabledImageList( 
CImageList* pImageList );

Parameters

pImageList
Specifies a pointer to a CImageList object containing the images to be used by the toolbar control to display disabled button images.

Return Value

A pointer to a CImageList object that was previously used by the toolbar control to display disabled button images.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
