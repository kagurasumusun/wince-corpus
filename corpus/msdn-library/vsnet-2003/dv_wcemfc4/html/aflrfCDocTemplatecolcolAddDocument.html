CDocTemplate::AddDocument

This method adds a document to a template. The derived class CSingleDocTemplate overrides this method. If you derive your own document-template class from CDocTemplate, the derived class must override this method.

virtual void AddDocument( 
CDocument* pDoc );

Parameters

pDoc
A pointer to the document to be added.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h

See Also

CDocTemplate::RemoveDocument, CSingleDocTemplate
