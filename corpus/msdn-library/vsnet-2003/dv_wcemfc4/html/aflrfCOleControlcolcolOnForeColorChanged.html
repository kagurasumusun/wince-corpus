Microsoft Foundation Class Library for Windows CE  

COleControl::OnForeColorChanged

This method is called by the framework when the stock ForeColor property is changed. The default implementation calls InvalidateControl.

Override this function if you want notification after this property changes.

virtual void OnForeColorChanged( );

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
