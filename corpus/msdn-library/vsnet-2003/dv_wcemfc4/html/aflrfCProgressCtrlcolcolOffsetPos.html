CProgressCtrl::OffsetPos

This method advances the current position of the progress bar control by the increment specified by nPos, and redraws the bar to reflect the new position.

int OffsetPos( 
int nPos );

Parameters

nPos
Specifies the amount to advance the position.

Return Value

Returns the previous position of the progress bar control.

Example

CProgressCtrl myCtrl;

// Create a child progress control.
myCtrl.Create(WS_CHILD|WS_VISIBLE, CRect(10,10,200,30), pParentWnd, 1);

// Offset the position by one-fourth of the total range.
int nLower, nUpper;
myCtrl.GetRange( nLower, nUpper );
myCtrl.OffsetPos( (nUpper-nLower)/4 );

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
