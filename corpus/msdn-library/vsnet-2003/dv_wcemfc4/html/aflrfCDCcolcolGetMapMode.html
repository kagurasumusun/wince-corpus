Microsoft Foundation Class Library for Windows CE  

CDC::GetMapMode

This method retrieves the mapping mode. 

int GetMapMode ( ) 
const;

Return Value

The mapping mode.

Remarks

The only mapping mode Windows CE supports is MM_TEXT, so the CDC::GetMapMode method always returns MM_TEXT unless an error occurs, in which case it returns zero.

MM_TEXT
Each logical unit is converted to 1 device pixel. Positive x is to the right; positive y is down.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
