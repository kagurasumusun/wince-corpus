Microsoft Foundation Class Library for Windows CE  

CFindReplaceDialog::IsBarVisible

This method determines whether the Find/Replace Continuation Bar is currently displayed. 

BOOL IsBarVisible();

Return Value

TRUE (non-zero) if the Find/Replace Continuation Bar is currently displayed, FALSE if it is not.

Remarks

If the application wants to cancel the Find/Replace operation while the Continuation Bar is visible, it should call CFindReplaceDialog::OnClose().

This method is unique to MFC for Windows CE.

Requirements

Windows CE versions: 3.0 and later
Header file: Declared in Afxdlgs.h
