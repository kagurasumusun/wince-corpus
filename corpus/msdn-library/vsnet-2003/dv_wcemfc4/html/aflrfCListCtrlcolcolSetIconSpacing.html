CListCtrl::SetIconSpacing

This method sets the spacing between icons in list view controls set to the LVS_ICON style.

The SetIconSpacing method implements the behavior of the Windows CE macro, ListView_SetIconSpacing. You can use this macro or send the LVM_SETICONSPACING message explicitly.

CSize SetIconSpacing( 
CSize size ); 

CSize SetIconSpacing( 
int cx, 
int cy );

Parameters

cx
The distance, in pixels, between icons on the x-axis.
cy
The distance, in pixels, between icons on the y-axis.
size
A CSize object specifying the distance, in pixels, between icons on the x- and y-axes.

Return Value

A CSize object containing the previous values for icon spacing.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

// Leave lots of space between icons.
pmyListCtrl->SetIconSpacing(CSize(100, 100));

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
