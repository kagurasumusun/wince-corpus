CArray::InsertAt

The first implementation of this method inserts one element, or multiple copies of an element at a specified index in an array. In the process, by incrementing the index, it shifts up the existing element at this index, and it shifts up all the elements above it.

The second implementation inserts all the elements from another CArray collection, starting at the nStartIndex position.

The SetAt method, in contrast, replaces one specified array element and does not shift any elements.

void InsertAt( 
int nIndex, 
ARG_TYPE newElement, 
int nCount = 1 );

void InsertAt( 
int nStartIndex, 
CArray* pNewArray );

Parameters

nIndex
An integer index that may be greater than the value returned by GetUpperBound.
ARG_TYPE
Template parameter that specifies the type of elements in this array.
newElement
Specifies the element to place in this array.
nCount
The number of times this element should be inserted; defaults to one.
nStartIndex
An integer index that may be greater than the value returned by GetUpperBound.
pNewArray
Specifies another array that contains elements to add to this array.

Example

// Example for CArray::InsertAt

CArray<CPoint,CPoint> ptArray;

ptArray.Add(CPoint(10,20));           // Element 0
ptArray.Add(CPoint(30,40));           // Element 1 (will become element 2)
ptArray.InsertAt(1, CPoint(50,60));   // New element 1

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
