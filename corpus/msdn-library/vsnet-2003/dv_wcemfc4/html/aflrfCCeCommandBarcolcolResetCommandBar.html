Microsoft Foundation Class Library for Windows CE  

CCeCommandBar::ResetCommandBar

This method removes all menus, combo boxes, buttons, and adornments from the command bar, while preserving the command bar. 

void ResetCommandBar();

Remarks

Use this method to remove any combo boxes and menus that are inserted with the InsertComboBox and InsertMenuBar methods. This method is useful for switching between different configurations of a command bar.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Wcebar.h
