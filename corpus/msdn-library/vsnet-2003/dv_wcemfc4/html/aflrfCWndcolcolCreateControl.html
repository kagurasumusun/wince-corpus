CWnd::CreateControl

This method creates an ActiveX control that will be represented in the MFC program by a CWnd object. CreateControl is a direct analog of the CWnd::Create method, but it creates an ActiveX control instead of an ordinary window.

Parameters

pszWindowName
Specifies a pointer to the text to be displayed in the control. Sets the value of the control Caption or Text property, if any. If NULL, the control Caption or Text property is not changed.
pszClass
This string may contain the OLE, short name, (ProgID) for the class, that is., CIRC3.Circ3Ctrl.1. The name needs to match the same name registered by the control. Alternatively, the string may contain the string form of a CLSID, contained in braces, that is, {9DBAFCCF-592F-101B-85CE-00608CEC297B}. In either case, CreateControl converts the string to the corresponding class ID.
dwStyle
Specifies the Windows CE styles. The available styles are listed under the Remarks section.
rect
Specifies the control size and position. It can be either a CRect object or a RECT structure.
pParentWnd
Specifies the control parent window. It must not be NULL.
pSize
The size of the object in memory.
ppt
Pointer to the target pointer.
nID
Specifies the control ID.
pPersist
Specifies a pointer to a CFile containing the persistent state for the control. The default value is NULL, indicating that the control initializes itself without restoring its state from any persistent storage. If not NULL, it should be a pointer to a CFile-derived object which contains the control persistent data, in the form of either a stream or a storage. This data could have been saved in a previous activation of the client. The CFile can contain other data, but must have its read-write pointer set to the first byte of persistent data at the time of the call to CreateControl.
bStorage
Indicates whether the data in pPersist should be interpreted as IStorage or IStream data. If the data in pPersist is a storage, bStorage should be TRUE. If the data in pPersist is a stream, bStorage should be FALSE. The default value is FALSE.
bstrLicKey
Specifies the Optional license key data. This data is needed only for creating controls that require a run-time license key. If the control supports licensing, you must provide a license key for the creation of the control to succeed. The default value is NULL.
clsid
Specifies the unique class ID of the control.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Remarks

Only a subset of the Windows dwStyle flags are supported for CreateControl:

  • WS_VISIBLE   Creates a window that is initially visible. This is required if you want the control to be visible immediately, like ordinary windows.
  • WS_DISABLED   Creates a window that is initially disabled. A disabled window cannot receive input from the user. Can be set if the control has an Enabled property.
  • WS_BORDER   Creates a window with a thin-line border. Can be set if the control has a BorderStyle property.
  • WS_GROUP   Specifies the first control of a group of controls. The user can change the keyboard focus from one control in the group to the next by using the direction keys. All controls defined with the WS_GROUP style after the first control belong to the same group. The next control with the WS_GROUP style ends the group and starts the next group.
  • WS_TABSTOP   Specifies a control that can receive the keyboard focus when the user presses the TAB key. Pressing the TAB key changes the keyboard focus to the next control of the WS_TABSTOP style.

Example

// This code is generated by the Control Wizard.
// It wraps the call to CreateControl in the call to Create.
class CGenocx : public CWnd
{
protected:
  DECLARE_DYNCREATE(CGenocx)
public:
  CLSID const& GetClsid()
  {
    static CLSID const clsid
      = { 0x8a6bbfeb, 0xf9bb, 0x11d1, { 0xb9, 0xc9, 0x0, 
      0x60, 0x8, 0x93, 0xb0, 0xfe } };
    return clsid;
  }
  virtual BOOL Create(LPCTSTR lpszClassName,
    LPCTSTR lpszWindowName, DWORD dwStyle,
    const RECT& rect,
    CWnd* pParentWnd, UINT nID,
    CCreateContext* pContext = NULL)
  {
    return CreateControl(GetClsid(), lpszWindowName, 
    dwStyle, rect, pParentWnd, nID); 
  }
...
};
