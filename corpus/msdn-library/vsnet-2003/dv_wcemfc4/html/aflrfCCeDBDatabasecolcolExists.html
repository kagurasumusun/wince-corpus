CCeDBDatabase::Exists

This method determines whether the specified database exists in the object store.

static BOOL Exists( 
LPCWSTR szName );

static BOOL Exists( 
CEOID CeOID );

Parameters

szName
Specifies the null-terminated string that contains the name of the database.
CeOID
Specifies the object identifier of the database.

Return Values

TRUE indicates that the database exists in the object store. FALSE indicates that the database could not be found.

Remarks

This is a static method. Do not call it from a specific database object.

This method does not indicate whether the object with the specified object identifier is a database. It only indicates whether an object identifier exists.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Wcedb.h
