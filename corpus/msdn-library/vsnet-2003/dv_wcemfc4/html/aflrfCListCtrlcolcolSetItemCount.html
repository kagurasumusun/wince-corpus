CListCtrl::SetItemCount

This method prepares a list view control for adding a large number of items. The SetItemCount method allocates memory for the specified number of items.

The SetItemCount method implements the behavior of the Windows CE macro, ListView_SetItemCount. You can use this macro or send the LVM_SETITEMCOUNT message explicitly.

By calling this method before adding a large number of items, you enable a list view control to reallocate its internal data structures only once rather than every time you add an item.

void SetItemCount( 
int nItems );

Parameters

nItems
Specifies the number of items that the control will ultimately contain.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;
CString str;

// Add 1024 items to the list view control.
pmyListCtrl->SetItemCount(1024);

for (int i=0;i < 1024;i++)
{
  str.Format(TEXT("item %d"), i);
  pmyListCtrl->InsertItem(i, str);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
