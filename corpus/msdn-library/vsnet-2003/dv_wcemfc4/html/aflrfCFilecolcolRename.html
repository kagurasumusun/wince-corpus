CFile::Rename

This method renames the specified file. Directories cannot be renamed. This is equivalent to the REN command.

static void PASCAL Rename( 
LPCTSTR lpszOldName, 
LPCTSTR lpszNewName );

Parameters

lpszOldName
Specifies the old path.
lpszNewName
Specifies the new path.

Example

// Example for the CFile::Rename method.
extern TCHAR* pOldName;
extern TCHAR* pNewName;

try
{
    CFile::Rename( pOldName, pNewName );
}
catch(CFileException* pEx )
{
#ifdef _DEBUG
    afxDump << "File " << pOldName << " not found, cause = "
            << e->m_cause << "\n";
#endif
    pEx->Delete();
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
