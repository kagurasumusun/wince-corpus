CInternetFile::CInternetFile

This constructor creates an instance of a CInternetFile object.

You never create a CInternetFile object directly. Instead, create an object of one of its derived classes by calling CHttpConnection::OpenRequest.

Parameters

hFile
A handle to an Internet file.
pstrFileName
A pointer to a string containing the name of the file to be opened.
pConnection
A pointer to a CInternetConnection object.
bReadMode
Specifies whether to set this file with read-only status.
hSession
A handle to an Internet session.
pstrServer
A pointer to a string containing the name of the server.
dwContext
The context identifier for opening the file.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxinet.h
