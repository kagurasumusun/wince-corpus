CMap::IsEmpty

This method determines whether the map is empty.

BOOL IsEmpty( ) 
const;

Return Value

Nonzero if this map contains no elements; otherwise, it is zero.

Example

CMap<int,int,CPoint,CPoint> myMap;

// Add 10 elements to the map.
for (int i=0;i < 10;i++)
   myMap.SetAt( i, CPoint(i, i) );

myMap.RemoveAll();

ASSERT(myMap.IsEmpty());

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
