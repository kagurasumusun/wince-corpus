CImageList::Write

This method writes an image list object to an archive.

BOOL Write( 
CArchive* pArchive );

Parameters

pArchive
Specifies a pointer to a CArchive object in which the image list is to be stored.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// Pointer to the myImageList.
extern CImageList* pmyImageList;

// Open the archive to store the image list in.
CFile   myFile(TEXT("myfile.data"), CFile::modeCreate | CFile::modeWrite);
CArchive ar(&myFile, CArchive::store);

// Store the image list in the archive.
pmyImageList->Write(&ar);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
