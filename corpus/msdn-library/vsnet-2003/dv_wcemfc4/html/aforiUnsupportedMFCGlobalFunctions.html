Unsupported MFC Global Functions

Windows CE does not support the following MFC global functions:

AfxDaoInit AfxOleLockApp
AfxDaoTerm AfxOleLockControl
AfxDbInit AfxOleSetEditMenu
AfxDbInitModule AfxOleSetUserCtrl
AfxGetInternetHandleType AfxOleTypeMatchGuid
AfxInitRichEdit AfxOleUnlockApp
AfxNetInitModule AfxOleUnlockControl
AfxOleCanExitApp AfxOleParseURL
AfxOleGetMessageFilter AfxThrowDaoException
AfxOleGetUserCtrl AfxThrowDBException
