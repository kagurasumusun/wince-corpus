CFrameWnd::IsTracking

This method determines whether the splitter bar in the window is currently being moved.

BOOL IsTracking( ) 
const;

Return Value

Nonzero if a splitter operation is in progress; otherwise, it is zero.

Requirements

Windows CE versions: 1.0 and later
