CRect::operator !=

This operator determines whether rect is not equal to the CRect object by comparing the coordinates of their upper-left and lower-right corners.

Both of the rectangles must be normalized or this method may fail. You can call NormalizeRect to normalize the rectangles before calling this method.

BOOL operator !=( 
const RECT& rect ) 
const;

Parameters

rect
Refers to a source rectangle. Can be a RECT or CRect.

Return Value

Nonzero if it is not equal; otherwise, it is zero.

Example

CRect rect1(35, 150, 10, 25);
CRect rect2(35, 150, 10, 25);
CRect rect3(98, 999,  6,  3);

ASSERT(rect1 != rect3);

// This works just fine against RECTs, as well.

RECT test;
test.left = 35;
test.top = 150;
test.right = 10;
test.bottom = 25;

ASSERT(rect3 != test);
