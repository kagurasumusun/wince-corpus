COleControl::AmbientShowGrabHandles

This method determines whether grab handles should be displayed. Note that the container is not required to support this property.

BOOL AmbientShowGrabHandles( );

Return Value

Nonzero if grab handles should be displayed; otherwise, it is zero. If this property is not supported, this function returns nonzero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
