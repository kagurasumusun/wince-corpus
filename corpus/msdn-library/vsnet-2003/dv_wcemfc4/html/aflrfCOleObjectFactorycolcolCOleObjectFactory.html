COleObjectFactory::COleObjectFactory

This constructor creates an instance of a COleObjectFactory object, initializes it as an unregistered object factory, and adds it to the list of factories. You must register this object before using it.

COleObjectFactory( 
REFCLSID clsid, 
CRuntimeClass* pRuntimeClass, 
BOOL bMultiInstance, 
LPCTSTR lpszProgID );

Parameters

clsid
Specifies the reference to the OLE class ID this object factory represents.
pRuntimeClass
Specifies a pointer to the run-time class of the eMbedded Visual C++ objects this factory can create.
bMultiInstance
Indicates whether a single instance of the application can support multiple instantiations. If TRUE, multiple instances of the application are launched for each request to create an object.
lpszProgID
Specifies a pointer to a string containing a verbal program identifier, such as Microsoft Excel.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
