CDocument::CDocument

This constructor creates an instance of a CDocument object. The framework handles document creation for you. Override the OnNewDocument method to perform initialization on a per-document basis; this is important in single document interface (SDI) applications.

CDocument( );

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
