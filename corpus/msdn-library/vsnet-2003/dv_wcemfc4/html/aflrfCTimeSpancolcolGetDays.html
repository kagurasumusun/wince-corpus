CTimeSpan::GetDays

This method retrieves the number of complete days represented by this CTimeSpan object. This value may be negative if the time span is negative.

GetDays will return a valid value if the object on which it operates was initialized with an amount of seconds that can be held in four bytes (+/-2,147,483,647). If your CTimeSpan object holds an eight-byte value, you should use GetDays64 to return the number of days.

LONG GetDays( ) 
const;

Example

// example for CTimeSpan::GetDays
CTimeSpan ts( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ASSERT( ts.GetDays() == 3 );

Requirements

  Windows CE versions: 1.0 and later
