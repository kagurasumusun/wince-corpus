CSliderCtrl::GetThumbRect

This method retrieves the size and position of the bounding rectangle for the slider (thumb) in a slider control.

void GetThumbRect( 
LPRECT lprc ) 
const;

Parameters

lprc
Specifies a pointer to a CRect object that contains the bounding rectangle for the slider when the function returns.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
