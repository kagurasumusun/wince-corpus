CWnd::SetDlgCtrlID

This method sets the window identifier or control identifier for the window to a new value. The window can be any child window, not only a control in a dialog box. The window cannot be a top-level window.

int SetDlgCtrlID( 
int nID );

Parameters

nID
Specifies the new value to set for the control identifier.

Return Value

The previous identifier of the window, if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
