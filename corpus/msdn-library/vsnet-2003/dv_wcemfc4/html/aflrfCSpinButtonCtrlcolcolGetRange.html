CSpinButtonCtrl::GetRange

This method retrieves the upper and lower limits (range) for a spin button control.

The method GetRange32 retrieves the spin button control range as a 32-bit integer.

DWORD GetRange( ); 
const; 

void GetRange( 
int &lower, 
int& upper ) 
const;

void GetRange32( 
int &lower, 
int& upper ) 
const;

Parameters

lower
Specifies the reference to an integer that receives the lower limit for the control.
upper
Specifies the reference to an integer that receives the upper limit for the control.

Return Value

The first version returns a 32-bit value containing the upper and lower limits. The low-order word is the upper limit for the control, and the high-order word is the lower limit.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
