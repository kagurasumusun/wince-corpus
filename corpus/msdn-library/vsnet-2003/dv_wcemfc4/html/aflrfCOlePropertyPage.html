Microsoft Foundation Class Library for Windows CE  

COlePropertyPage

This class is used to display the properties of a custom control in a graphical interface, similar to a dialog box. For example, a property page may include an edit control that allows the user to view and modify the caption property of the control.

Each custom or stock control property can have a dialog control that allows the user of the control to view the current property value and modify that value if needed.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
