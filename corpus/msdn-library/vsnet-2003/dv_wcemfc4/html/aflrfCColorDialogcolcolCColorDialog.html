CColorDialog::CColorDialog

This constructor creates an instance of a CColorDialog object and initializes its first appearance. 

CColorDialog( 
COLORREF clrInit = 0, 
DWORD dwFlags = 0, 
CWnd* pParentWnd = NULL );

Parameters

clrInit
Specifies the default color selection. If no value is specified, the default is RGB(0,0,0) (black).
dwFlags
Specifies a set of flags that customize the function and appearance of the dialog box.
pParentWnd
Specifies a pointer to parent or owner window of the dialog box.

Example

// Show the Color dialog with the default settings.
CColorDialog dlg;
dlg.DoModal();

// Show the open Color dialog with red as the selected color.
CColorDialog dlg(RGB(255, 0, 0), CC_FULLOPEN);
dlg.DoModal();

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxdlgs.h
