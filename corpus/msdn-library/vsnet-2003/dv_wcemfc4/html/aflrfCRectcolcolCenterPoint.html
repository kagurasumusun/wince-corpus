CRect::CenterPoint

Cpoint CenterPoint( ) 
const;

Return Value

A CPoint object that is the centerpoint of CRect.

Example

// Code from this OnDraw( ) implementation can be pasted into an 
// application to draw lines that will look like the letter Y in a
// screen.

void CYourView::OnDraw( CDC* pDC )
{
   // Get the size and position of the client area of the window.

   CRect rect;
   GetWindowRect( &rect );

   // Move the current pen to the top-left of the window. Call the
   // TopLeft( ) member of CRect here and it returns a CPoint object
   // that you can pass to the override of CDC::MoveTo( ) that accepts
   // a CPoint.

   pDC->MoveTo( rect.TopLeft( ));

   // Draw a line from the top-left to the center of the window.
   // CenterPoint( ) gives the middle point of the window as a CPoint, and
   // since CDC::LineTo( ) has an override that accepts a CPoint, it can
   // be passed along.

pDC->LineTo( rect.CenterPoint( ));

   // Now, draw a line to the top-right of the window. There is no CRect
   // member which returns a CPoint for the top-right of the window, so
   // we will reference the CPoint members directly and call the 
   // CDC::LineTo( ) override which takes two integers.

   pDC->LineTo( rect.right, rect.top );

   // The top of the Y is drawn. Now, draw the stem. Start from the center
   // point.

   pDC->MoveTo( rect.CenterPoint( )0;

   // Then draw to the middle of the bottom edge of the window. We will
   // get the x-coordinate from the x member of the CPoint that is returned by CenterPoint( ), and the y value comes directly from the rect.

   pDC->LineTo( rect.CenterPoint( ).x, rect.bottom );
}

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
