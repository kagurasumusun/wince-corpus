CEdit::CanUndo

This method determines whether the last edit operation can be undone.

BOOL CanUndo( ) 
const;

Return Value

Nonzero if the last edit operation can be undone by a call to the Undo method; zero if it cannot be undone.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h

CEdit::Undo, CEdit::EmptyUndoBuffer
