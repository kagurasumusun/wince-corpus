Microsoft Foundation Class Library for Windows CE  

COleControl::IsSubclassedControl

This method is called by the framework to determine whether the control subclasses are a Windows CE control. You must override this function and return TRUE if your OLE control subclasses a Windows CE control.

virtual BOOL IsSubclassedControl( );

Return Value

Nonzero if the control is subclassed; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
