Microsoft Foundation Class Library for Windows CE  

CFile

This class is the base class for Microsoft Foundation Classes (MFC) for Windows CE file classes. It provides unbuffered, binary disk input/output (I/O) services, and indirectly supports text files and memory files through its derived classes. CFile works in conjunction with the CArchive class to support serialization of MFC for Windows CE objects.

The hierarchical relationship between this class and its derived classes allows programs to operate on all file objects through the polymorphic CFile interface. For example, a memory file behaves like a disk file.

Use CFile and its derived classes for general-purpose disk I/O.

Normally, a disk file is opened automatically on CFile construction and closed on destruction. Static member functions permit you to interrogate the status of a file without opening the file.

Remarks

You can use the CFile class to access files in the Windows CE object store.

MFC for Windows CE does not support the following methods of the CFile class:

  • Duplicate
  • LockRange
  • UnlockRange

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
