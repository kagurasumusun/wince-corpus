Microsoft Foundation Class Library for Windows CE  

AfxGetResourceHandle  

This function accesses the application’s resources directly by using the HINSTANCE handle returned, for example, in calls to the Windows function FindResource.

HINSTANCE AfxGetResourceHandle( );

Return Value

An HINSTANCE handle where the default resources of the application are loaded.

Example

//Load the menu specifying the module handle where resource is to be 
//found & resource ID
HMENU hMenu = ::LoadMenu(AfxGetResourceHandle(), MAKEINTRESOURCE(IDR_PANEL));

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxwin.h

See Also

AfxGetInstanceHandle, AfxSetResourceHandle
