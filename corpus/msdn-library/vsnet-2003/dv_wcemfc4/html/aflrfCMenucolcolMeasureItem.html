Microsoft Foundation Class Library for Windows CE  

CMenu::MeasureItem

This method is called by the framework when a menu with the owner-draw style is created. By default, this method does nothing. Override this method and fill in the MEASUREITEMSTRUCT structure to inform Windows CE of the menu dimensions.

See CWnd::OnMeasureItem for a description of the MEASUREITEMSTRUCT structure.

virtual void MeasureItem( 
LPMEASUREITEMSTRUCT lpMeasureItemStruct );

Parameters

lpMeasureItemStruct
Specifies a pointer to a MEASUREITEMSTRUCT structure.

Example

// Override MeasureItem() to return the size of the menu item.
// CColorMenu is a CMenu-derived class. 

#define COLOR_BOX_WIDTH     20
#define COLOR_BOX_HEIGHT    20

void CColorMenu::MeasureItem(LPMEASUREITEMSTRUCT lpMIS)
{
  // All items are of fixed size.
  lpMIS->itemWidth = COLOR_BOX_WIDTH;
  lpMIS->itemHeight = COLOR_BOX_HEIGHT;
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
