CArray::Add

This method adds a new element to the end of an array, growing the array by one.

int Add( 
ARG_TYPE newElement );

Parameters

ARG_TYPE
Template parameter that specifies the type of arguments referencing elements in this array.
newElement
The element to add to this array.

Return Value

The index of the added element.

Remarks

If SetSize is used with an nGrowBy value greater than one, extra memory may be allocated. However, the upper bound increases by only one.

Example

// Example for CArray::Add
CArray<CPoint,CPoint> ptArray;

CPoint pt(10,20);
ptArray.Add(pt);            // Element 0
ptArray.Add(CPoint(30,40)); // Element 1

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
