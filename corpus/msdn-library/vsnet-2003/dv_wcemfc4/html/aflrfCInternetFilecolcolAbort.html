CInternetFile::Abort

This method closes the file associated with this object and makes the file unavailable for reading or writing. If you have not closed the file before destroying the object, the destructor closes it for you.

When handling exceptions, Abort differs from Close in two important ways. First, the Abort function does not throw an exception on failures because it ignores failures. Second, Abort does not ASSERT if the file has not been opened or was closed previously.

virtual void Abort( );

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxinet.h
