Microsoft Foundation Class Library for Windows CE  

COleControl::OnKeyPressEvent

This method is called by the framework after the stock KeyPress event has been fired.

Override this function if you want notification after this event occurs.

virtual void OnKeyPressEvent( 
USHORT nChar );

Parameters

nChar
Contains the virtual key code value of the key pressed. For a list of standard virtual key codes, see Winuser.h

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h

COleControl::FireKeyPress, COleControl::OnKeyDownEvent, COleControl::OnKeyUpEvent
