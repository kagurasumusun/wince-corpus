CAsyncSocket::Close

This method closes the socket and releases the socket descriptor; further references to the socket fail with the error WSAENOTSOCK. If this is the last reference to the underlying socket, the associated naming information and queued data are discarded. The destructor of the socket object calls Close.

For CAsyncSocket, but not for CSocket, the semantics of Close are affected by the socket options SO_LINGER and SO_DONTLINGER.

virtual void Close( );

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Afxsock.h
