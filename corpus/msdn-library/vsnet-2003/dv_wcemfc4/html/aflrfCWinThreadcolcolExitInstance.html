CWinThread::ExitInstance

This method is called by the framework to exit this instance of the thread. It is called either from within the rarely overridden Run method, or if a call to InitInstance fails.

virtual int ExitInstance( );

Return Value

The exit code in a thread; 0 indicates no errors, and values greater than 0 indicate an error. This value can be retrieved by calling GetExitCodeThread.

Remarks

Do not call this method from anywhere but within the Run method. This method is used only in user-interface threads.

The default implementation of this function deletes the CWinThread object if m_bAutoDelete is TRUE. Override this function if you wish to perform additional clean-up when your thread terminates. Your implementation of ExitInstance should call the base class version after your code is executed.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
