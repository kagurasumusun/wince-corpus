CEditView::PaginateTo

This method puts page numbers on the pages of a print job stored in a specified CPrintInfo object. 

BOOL PaginateTo( 
CDC* pDC, 
CPrintInfo* pInfo );

Parameters

pDC
Specifies the pointer to the device context associated with the print job.
pInfo
Specifies the pointer to the CPrintInfo object that will be paginated.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxext.h
