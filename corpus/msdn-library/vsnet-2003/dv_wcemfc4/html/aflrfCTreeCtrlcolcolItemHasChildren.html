CTreeCtrl::ItemHasChildren

This method determines whether the tree item specified by hItem has child items. If so, then use CTreeCtrl::GetChildItem to retrieve those child items.

BOOL ItemHasChildren( 
HTREEITEM hItem ) 
const;

Parameters

hItem
Specifies the handle of a tree item.

Return Value

Nonzero if the tree item specified by hItem has child items; zero if it does not.

Example

See the example for CTreeCtrl::GetSelectedItem.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
