CCeCommandBar::GetNumButtons

This method returns a count of the buttons currently in the toolbar.

int GetNumButtons() 
const

Return Value

An integer indicating the number of buttons in the toolbar.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Wcebar.h
