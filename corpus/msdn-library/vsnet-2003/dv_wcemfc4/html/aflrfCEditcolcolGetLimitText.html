CEdit::GetLimitText

This method retrieves the text limit for this CEdit object. The text limit is the maximum amount of text, in bytes, that the edit control can accept.

UINT GetLimitText( ) 
const;

Return Value

The current text limit, in bytes, for this CEdit object.

Remarks

For more information, see the Windows CE message EM_GETLIMITTEXT.

Example

// The pointer to my edit control.
extern CEdit* pmyEdit;
// The new text of the edit control.
extern LPCTSTR lpszmyString;
int nLength = strlen(lpszmyString);

// The text limit needs to be at least the size of the new string.
if (pmyEdit->GetLimitText() < nLength)
  pmyEdit->SetLimitText(nLength);

pmyEdit->SetWindowText(lpszmyString);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
