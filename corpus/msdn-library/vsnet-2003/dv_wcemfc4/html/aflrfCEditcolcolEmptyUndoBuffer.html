CEdit::EmptyUndoBuffer

This method resets or clears the undo flag of an edit control. The edit control will now be unable to undo the last operation. The undo flag is set whenever an operation within the edit control can be undone. 

void EmptyUndoBuffer( );

Remarks

The undo flag is automatically cleared whenever the SetWindowText method is called.

For more information, see the Windows CE message EM_EMPTYUNDOBUFFER.

Example

// The pointer to my edit.
extern CEdit* pmyEdit;

// Clear the undo buffer.
if (pmyEdit->CanUndo())
{
  pmyEdit->EmptyUndoBuffer();
  ASSERT(!pmyEdit->CanUndo());
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
