CListBox::SetHorizontalExtent

This method sets the width, in pixels, by which a list box can be scrolled horizontally. If the size of the list box is smaller than this value, the horizontal scroll bar will horizontally scroll items in the list box. If the list box is as large or larger than this value, the horizontal scroll bar is hidden.

To respond to a call to SetHorizontalExtent, the list box must have been defined with the WS_HSCROLL style.

This method is not useful for multicolumn list boxes. For multicolumn list boxes, call the SetColumnWidth method.

void SetHorizontalExtent( 
int cxExtent );

Parameters

cxExtent
Specifies the number of pixels by which the list box can be scrolled horizontally.

Example

// Pointer to the myListBox.
extern CListBox* pmyListBox;

// Find the longest string in the list box.
CString str;
CSize   sz;
int     dx=0;
CDC*    pDC = pmyListBox->GetDC();
for (int i=0;i < pmyListBox->GetCount();i++)
{
  pmyListBox->GetText( i, str );
  sz = pDC->GetTextExtent(str);

  if (sz.cx > dx)
    dx = sz.cx;
}
pmyListBox->ReleaseDC(pDC);

// Set the horizontal extent so every character of all strings 
// can be scrolled to.
pmyListBox->SetHorizontalExtent(dx);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
