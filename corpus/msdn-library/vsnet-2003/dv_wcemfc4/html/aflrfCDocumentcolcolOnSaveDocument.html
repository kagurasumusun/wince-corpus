CDocument::OnSaveDocument

This method is called by the framework as part of the File Save or File Save As command. The default implementation of this method opens the specified file, calls CObject::Serialize to write the data in the document to the file, and then marks the document as clean.

Override this method if you want to perform special processing when the framework saves a document. For example, you might write an application where documents represent records in a database rather than separate files.

virtual BOOL OnSaveDocument( 
LPCTSTR lpszPathName );

Parameters

lpszPathName
Points to the fully qualified path to which the file should be saved.

Return Value

Nonzero if the document was successfully saved; otherwise, it is zero.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
