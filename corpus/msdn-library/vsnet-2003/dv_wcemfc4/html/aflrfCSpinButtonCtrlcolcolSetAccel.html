CSpinButtonCtrl::SetAccel

This method sets the acceleration for a spin button control.

BOOL SetAccel( 
int nAccel, 
UDACCEL* pAccel );

Parameters

nAccel
Specifies the number of UDACCEL structures specified by pAccel.
pAccel
Specifies a pointer to an array of UDACCEL structures, which contain acceleration information. Elements should be sorted in ascending order based on the nSec member.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
