CListCtrl::Create

This method creates the list view control and attaches it to the CListCtrl object.

To construct a CListCtrl, call the constructor, then call Create.

BOOL Create( 
DWORD dwStyle, 
const RECT& rect, 
CWnd* pParentWnd, 
UINT nID );

Parameters

dwStyle
Specifies style for the list control. Apply any combination of list control styles to the control. Set extended styles specific to a control using ClistCtrl::SetExtendedStyle.
rect
Specifies the size and position of the list control. It can be either a CRect object or a RECT structure.
pParentWnd
Specifies the parent window of the list control, usually a CDialog. It must not be NULL.
nID
Specifies the list control ID.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Remarks

Windows CE supports a new list view style, called LVS_OWNERDATA, that specifies a virtual list view control. Windows CE versions prior to 2.0 do not support the LVS_OWNERDATA style.

Example

// pParentWnd is a pointer to the parent window.
CWnd* pParentWnd;
// Pointer to the list view control.
CListCtrl* pmyListCtrl;

pmyListCtrl->Create(
  WS_CHILD|WS_VISIBLE|WS_BORDER|LVS_REPORT,
  CRect(10,10,400,200), pParentWnd, 1);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
