CProgressCtrl::GetPos

This method retrieves the current position of the progress bar. The position of the progress bar control is not the physical location on the screen, but rather is between the upper and lower range indicated in SetRange.

int GetPos( );

Return Value

Returns the position of the progress bar control.

Example

CProgressCtrl myCtrl;

// Create a child progress control.
myCtrl.Create(WS_CHILD|WS_VISIBLE, CRect(10,10,200,30), pParentWnd, 1);

// Set the new position to half of the current position.
myCtrl.SetPos( myCtrl.GetPos()/2 );

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
