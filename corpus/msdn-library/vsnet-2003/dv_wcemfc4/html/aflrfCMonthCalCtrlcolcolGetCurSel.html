CMonthCalCtrl::GetCurSel

This method retrieves the system time portrayed by the currently selected date.

This method implements the behavior of the Windows CE message MCM_GETCURSEL.

This method fails if the style MCS_MULTISELECT is set.

In the MFC for Windows CE implementation of GetCurSel, you can specify a COleDateTime usage, a CTime usage, or a SYSTEMTIME structure usage.

BOOL GetCurSel( 
LPSYSTEMTIME pDateTime ) 
const; 

BOOL GetCurSel( 
CTime& refDateTime ) 
const; 

BOOL GetCurSel( 
COleDateTime& refDateTime ) 
const;

Parameters

refDateTime
Specifies a reference to a COleDateTime object or a CTime object. Receives the current time.
pDateTime
Specifies a pointer to a SYSTEMTIME structure that will receive the currently-selected date information. This parameter must be a valid address and cannot be NULL.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxdtctl.h
