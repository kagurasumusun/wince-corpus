CListBox::GetItemRect

This method retrieves the dimensions of the rectangle that bounds a list-box item as it is currently displayed in the list-box window.

int GetItemRect( 
int nIndex, 
LPRECT lpRect ) 
const;

Parameters

nIndex
Specifies the zero-based index of the item.
lpRect
Specifies a long pointer to a RECT structure that receives the list-box client coordinates of the item.

Return Value

LB_ERR if an error occurs.

Example

// Pointer to the myListBox.
extern CListBox* pmyListBox;

// Dump all bounds of the items.
#ifdef _DEBUG
  CString str;
  RECT r;
  for (int i=0;i < pmyListBox->GetCount();i++)
  {
    pmyListBox->GetItemRect( i, &r );

    str.Format(_T("item %d: left = %d, top = %d, right = %d, 
      bottom = %d\r\n"),
      i,
      r.left,
      r.top,
      r.right,
      r.bottom);
    afxDump << str;
  }
#endif

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
