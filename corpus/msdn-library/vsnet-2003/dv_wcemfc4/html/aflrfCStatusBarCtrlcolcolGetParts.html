CStatusBarCtrl::GetParts

This method retrieves a count of the parts in a status bar control. This method also retrieves the coordinate of the right edge of the specified number of parts.

int GetParts( 
int nParts, 
int* pParts ) 
const;

Parameters

nParts
Specifies the number of parts for which to retrieve coordinates. If this parameter is greater than the number of parts in the control, the message retrieves coordinates for existing parts only.
pParts
Specifies the address of an integer array having the same number of elements as the number of parts specified by nParts. Each element in the array receives the client coordinate of the right edge of the corresponding part. If an element is set to –1, the position of the right edge for that part extends to the right edge of the status bar.

Return Value

The number of parts in the control if it is successful, otherwise, it is zero.

Example

int pParts[2];

int nParts = GetParts( 2, pParts );

Requirements

  Windows CE versions: 2.10 and later
