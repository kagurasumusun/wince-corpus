CRect::Width

This method calculates the width of a CRect object by subtracting the left value from the right value. The width can be negative.

The rectangle must be normalized or this method may fail. You can call NormalizeRect to normalize the rectangle before calling this method.

int Width( ) 
const;

Return Value

Returns the width of CRect.

Example

CRect rect(20, 30, 80, 70);

int nWid = rect.Width();

// nWid is now 60
ASSERT(nWid == 60);

Requirements
