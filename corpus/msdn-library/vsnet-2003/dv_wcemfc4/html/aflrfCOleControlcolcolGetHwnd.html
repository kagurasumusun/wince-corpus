Microsoft Foundation Class Library for Windows CE  

COleControl::GetHwnd

This method retrieves the value of the stock hWnd property.

OLE_HANDLE GetHwnd( );

Return Value

The OLE control window handle, if any; otherwise, it is NULL.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
