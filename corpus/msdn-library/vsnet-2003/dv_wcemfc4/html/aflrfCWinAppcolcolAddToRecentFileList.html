CWinApp::AddToRecentFileList

This method adds the file specified by lpszPathName to the MRU file list. You should call the LoadStdProfileSettings method to load the current MRU file list before you use this method.

The framework calls this method when it opens a file or executes the Save As command to save a file with a new name.

virtual void AddToRecentFileList( 
LPCTSTR lpszPathName );

Parameters

lpszPathName
Specifies the path of the file.

Example

   // This adds the pathname c:\temp\test.doc to the top of
   // the most recently used (MRU) list in the File menu.
    AfxGetApp()->AddToRecentFileList("c:\\temp\\test.doc");

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
