Microsoft Foundation Class Library for Windows CE  

COleControl::DoSuperclassPaint

This method redraws an ActiveX control that has been subclassed from a Windows CE control.

void DoSuperclassPaint( 
CDC* pDC, 
const CRect& rcBounds );

Parameters

pDC
Specifies a pointer to the device context of the control container.
rcBounds
Specifies the area in which the control is to be drawn.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
