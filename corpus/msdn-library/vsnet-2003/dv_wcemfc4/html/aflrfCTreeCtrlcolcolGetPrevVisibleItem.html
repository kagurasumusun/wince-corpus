CTreeCtrl::GetPrevVisibleItem

This method retrieves the previous visible item of hItem.

HTREEITEM GetPrevVisibleItem( 
HTREEITEM hItem ) 
const;

Parameters

hItem
Specifies the handle of a tree item.

Return Value

The handle of the previous visible item; otherwise, it is NULL.

Example

// The pointer to my tree control.
extern CTreeCtrl* pmyTreeCtrl;
// The item that previous visible items will be displayed in bold.
extern HTREEITEM hmyItem;

// Show all of the previous visible items of hmyItem in bold.
HTREEITEM hItem = hmyItem;

while (hItem != NULL)
{
  pmyTreeCtrl->SetItemState(hItem, TVIS_BOLD, TVIS_BOLD);
  hItem = pmyTreeCtrl->GetPrevVisibleItem(hItem);
}

Requirements

  Windows CE versions: 1.0 and later
