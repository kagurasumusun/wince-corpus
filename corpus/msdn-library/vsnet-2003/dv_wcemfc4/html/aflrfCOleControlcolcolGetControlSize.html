Microsoft Foundation Class Library for Windows CE  

COleControl::GetControlSize

This method retrieves the position and size of the ActiveX control.

Note that all coordinates for control windows are relative to the upper-left corner of the control.

void GetControlSize( 
int* pcx, 
int* pcy );

Parameters

pcx
Specifies the width of the control in pixels.
pcy
Specifies the height of the control in pixels.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h

See Also

COleControl::GetRectInContainer, COleControl::SetControlSize
