CToolBarCtrl::SetButtonSize

This method sets the size of the buttons in the toolbar control. The button size must always be at least as large as the bitmap size it encloses. This method must be called only before adding any bitmaps to the toolbar. If the application does not explicitly set the button size, it defaults to 24 by 22 pixels.

BOOL SetButtonSize( 
CSize size );

Parameters

size
Specifies the width and height, in pixels, of the buttons.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

See the example for CToolBar::GetToolBarCtrl.

Requirements

  Windows CE versions: 2.10 and later
