CComboBox::GetItemDataPtr

This method retrieves the application-supplied 32-bit value associated with the specified combo box item as a pointer (void*).

void* GetItemDataPtr( 
int nIndex ) 
const;

Parameters

nIndex
Contains the zero-based index of an item in the list box of a combo box.

Return Value

Retrieves a pointer, or –1 if an error occurs.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;
extern LPVOID    lpmyPtr;

// Check all the items in the combo box; if an item's data 
// pointer is equal to my pointer, then reset it to NULL.
for (int i=0;i < pmyComboBox->GetCount();i++)
{
  if (pmyComboBox->GetItemDataPtr(i) == lpmyPtr)
  {
    pmyComboBox->SetItemDataPtr(i, NULL);
  }
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
