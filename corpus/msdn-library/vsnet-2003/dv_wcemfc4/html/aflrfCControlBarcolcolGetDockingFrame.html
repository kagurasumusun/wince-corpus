CControlBar::GetDockingFrame

This method obtains a pointer to the frame window to which your control bar is docked.

CFrameWnd* GetDockingFrame( ) 
const;

Return Value

A pointer to a frame window if successful; otherwise, it is NULL.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxext.h
