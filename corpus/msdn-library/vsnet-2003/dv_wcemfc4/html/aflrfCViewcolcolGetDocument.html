CView::GetDocument

This method retrieves a pointer to the document of view document. This allows you to call the methods of the document.

CDocument* GetDocument( ) 
const;

Return Value

A pointer to the CDocument object associated with the view. NULL if the view is not attached to a document.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
