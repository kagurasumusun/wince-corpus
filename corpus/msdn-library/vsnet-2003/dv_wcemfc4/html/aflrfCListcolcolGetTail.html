CList::GetTail

This method retrieves the CObject pointer that represents the tail element of this list.

You must ensure that the list is not empty before calling GetTail. If the list is empty, then the Debug version of the Microsoft Foundation Class Library for Windows CE asserts. Use IsEmpty to verify that the list contains elements.

TYPE& GetTail( );

TYPE GetTail() 
const;

Parameters

TYPE
Specifies the template parameter specifying the type of elements in the list.

Return Value

If the list is const, GetTail returns a copy of the element at the tail of the list. This allows the function to be used only on the right side of an assignment statement and protects the list from modification.

If the list is not const, GetTail returns a reference to the element at the tail of the list. This allows the function to be used on either side of an assignment statement and thus allows the list entries to be modified.

Example

// Define myList.
CList<CString,CString&> myList;

// Add an element to the end of the list.
myList.AddTail(CString("ABC"));

// Verify the element was added to the end of the list.
ASSERT(CString("ABC") == myList.GetTail());

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
