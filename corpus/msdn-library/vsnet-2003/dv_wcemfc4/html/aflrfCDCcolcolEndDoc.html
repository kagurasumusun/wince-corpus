CDC::EndDoc

This method ends a print job started by a call to the StartDoc method.

int EndDoc( );

Return Value

Greater than or equal to zero if the function is successful, or a negative value if an error occurs. The following list shows common error values:

SP_ERROR
General error.
SP_OUTOFDISK
Not enough disk space is available for spooling, and no more space will become available.
SP_OUTOFMEMORY
Not enough memory is available for spooling.
SP_USERABORT
User ended the job through the print manager.

Remarks

This method replaces the ENDDOC printer escape, and should be called immediately after finishing a successful print job.

If an application encounters a printing error or a canceled print operation, it must not attempt to cancel the operation by using EndDoc or AbortDoc. The GDI automatically cancels the operation before returning the error value.

This method should not be used inside metafiles.

Example

See the example for CDC::StartDoc.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxwin.h
