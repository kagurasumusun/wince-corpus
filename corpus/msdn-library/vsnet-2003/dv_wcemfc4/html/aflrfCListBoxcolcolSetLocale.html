CListBox::SetLocale

This method sets the locale identifier for this list box. If SetLocale is not called, the default locale is obtained from the system. This system default locale can be modified by using the Regional, or International application in Control Panel.

LCID SetLocale( 
LCID nNewLocale );

Parameters

nNewLocale
Specifies the new locale identifier, LCID, value to set for the list box.

Return Value

The previous locale identifier, LCID, value for this list box.

Example

// Pointer to the myListBox.
extern CListBox* pmyListBox;
// My LCID to use.
LCID mylcid = MAKELCID(MAKELANGID(LANG_SPANISH, SUBLANG_SPANISH_MEXICAN), 
  SORT_DEFAULT);

// Force the list box to use my locale.
pmyListBox->SetLocale(mylcid);
ASSERT(pmyListBox->GetLocale() == mylcid);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
