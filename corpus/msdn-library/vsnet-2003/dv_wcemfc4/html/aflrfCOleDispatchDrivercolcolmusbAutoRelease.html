COleDispatchDriver::m_bAutoRelease

This data member contains a flag that specifies whether the COM object accessed by m_lpDispatch will be automatically released when either ReleaseDispatch is called or this COleDispatchDriver object is destroyed.

By default, m_bAutoRelease is set to TRUE in the constructor.

BOOL m_bAutoRelease

Example

// Clean up by forcing Release to be called
// on COleDispatchDriver object and delete.
if (bError)
{
  pDisp.m_bAutoRelease = TRUE;
  delete pDisp;
  pDisp = NULL;
}

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
