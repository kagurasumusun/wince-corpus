CListBox::GetCaretIndex

This method determines the index of the item that has the focus rectangle in a multiple-selection list box. The item may or may not be selected.

int GetCaretIndex( ) 
const;

Return Value

The zero-based index of the item that has the focus rectangle in a list box. If the list box is a single-selection list box, the return value is the index of the item that is selected, if any.

Example

// Pointer to the myListBox.
Extern ClistBox* pmyListBox;
// Point where mouse was clicked.
Extern CPoint myPoint;

BOOL bOutside;
UINT uItem = pmyListBox->ItemFromPoint(myPoint, bOutside);

If (!bOutside)
{
  // Set the anchor to be the middle item.
  PmyListBox->SetAnchorIndex(uItem);
  ASSERT(pmyListBox->GetAnchorIndex() == uItem);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
