COleControl::OnGetViewExtent

This method called by the framework in response to a container IViewObjectEx::GetExtent request. Override this method if your control uses two-pass drawing, and its opaque and transparent parts have different dimensions.

virtual BOOL OnGetViewExtent( 
DWORD dwDrawAspect, 
LONG lindex, 
DVTARGETDEVICE* ptd, 
LPSIZEL lpsizel );

Parameters

dwDrawAspect
Specifies the DWORD describing which form, or aspect, of an object is to be displayed. Valid values are taken from the enumeration DVASPECT or DVASPECT2.
lindex
Specifies the portion of the object that is of interest. Currently only –1 is valid.
ptd
Points to the DVTARGETDEVICE structure defining the target device for which the size of the object should be returned.
lpsizel
Points to the location where the display size closest to the proposed size and extent mode in the DVEXTENTINFO structure of the object size is returned.

Return Value

Nonzero if extent information is successfully returned; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h

See Also

DVTARGETDEVICE, COleControl::OnGetViewRect, DVEXTENTINFO
