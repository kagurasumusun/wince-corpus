CToolBar::SetButtonText

This method sets the text on a button.

BOOL SetButtonText( 
int nIndex, 
LPCTSTR lpszText );

Parameters

nIndex
Specifies the index of the button whose text is to be set.
lpszText
Points to the text to be set on a button.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

See the example for CToolBar::GetToolBarCtrl.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
