CComboBox::ShowDropDown

This method shows or hides the list box of a combo box that has the CBS_DROPDOWN or CBS_DROPDOWNLIST style. By default, a combo box of this style shows the list box.

void ShowDropDown( 
BOOL bShowIt = TRUE);

Parameters

bShowIt
Specifies whether the drop-down list box is to be shown or hidden. A value of TRUE shows the list box. A value of FALSE hides the list box.

Remarks

This method has no effect on a combo box created with the CBS_SIMPLE style.

Example

See the example for CComboBox::GetDroppedState.

Requirements

Windows CE versions: 1.0 and later
