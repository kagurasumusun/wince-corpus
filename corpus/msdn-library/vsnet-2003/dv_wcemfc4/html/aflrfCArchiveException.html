CArchiveException

A CArchiveException object represents a serialization exception condition. The CArchiveException class includes a public data member that indicates the cause of the exception.

CArchiveException objects are constructed and thrown inside CArchive methods. You can access these objects within the scope of a CATCH expression. The cause code is independent of the operating system.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
