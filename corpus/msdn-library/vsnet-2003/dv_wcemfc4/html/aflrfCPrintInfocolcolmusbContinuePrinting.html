CPrintInfo::m_bContinuePrinting

This data member indicates whether the framework should continue the print loop.

If you are doing print-time pagination, you can set this member to FALSE in your override of CView::OnPrepareDC once the end of the document has been reached. You do not have to modify this variable if you have specified the length of the document at the beginning of the print job using the SetMaxPage method. The m_bContinuePrinting member is a public variable of type BOOL.

BOOL m_bContinuePrinting;

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
