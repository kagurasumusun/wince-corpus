COleSafeArray::Copy

This method creates a copy of an existing array. On error, the method throws a CMemoryException or COleException.

void Copy( 
LPSAFEARRAY* ppsa );

Parameters

ppsa
Specifies a pointer to a location in which to return the new array descriptor.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h

See Also

SafeArrayCopy, SAFEARRAY
