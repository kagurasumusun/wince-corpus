CList::CList

This constructor creates an instance of an empty ordered list. As the list grows, memory is allocated in units of nBlockSize entries.

CList( 
int nBlockSize = 10 );

Parameters

nBlockSize
Specifies the memory-allocation granularity for extending the list.

Example

// This code defines myList as a list of strings
// such that memory gets allocated in chunks of
// 16 strings.
CList<CString,CString&> myList(16);

// This code defines myList2 as a list of ints
// such that memory gets allocated in chunks of
// 128 ints.
CList<int,int> myList2(128);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
