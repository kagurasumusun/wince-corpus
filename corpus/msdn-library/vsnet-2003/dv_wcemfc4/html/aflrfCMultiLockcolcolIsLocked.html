CMultiLock::IsLocked

This method determines if the specified object is nonsignaled (unavailable).

BOOL IsLocked( 
DWORD dwItem );

Parameters

dwItem
The index in the array of objects corresponding to the object whose state is being queried.

Return Value

Nonzero if the specified object is locked; otherwise, it is zero.

Requirements

Windows CE versions: 3.0 and later
Header file: Declared in Afxmt.h
