CEditView::GetBufferLength

This method retrieves the current number of characters in the buffer of the edit control, not including the terminating null character.

UINT GetBufferLength( ) 
const;

Return Value

The length of the string in the buffer.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxext.h
