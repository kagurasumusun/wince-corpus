CWnd::SetFont

This method sets the current font of the window to the specified font.

void SetFont( 
CFont* pFont, 
BOOL bRedraw = TRUE );

Parameters

pFont
Specifies the new font.
bRedraw
If TRUE, redraw the CWnd object.

Requirements
