CStatusBarCtrl::SetMinHeight

This method sets the minimum height of the drawing area in a status bar control. The minimum height is the sum of nMin and twice the width in pixels, of the vertical border of the status bar control.

void SetMinHeight( 
int nMin );

Parameters

nMin
Specifies the minimum height in pixels, of the control.

Example

int CMyCStatusBarCtrl::OnCreate(LPCREATESTRUCT lpCreateStruct) 
{
  if (CStatusBarCtrl::OnCreate(lpCreateStruct) == -1)
    return -1;
  
  SetMinHeight(40);

  return 0;
}

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
