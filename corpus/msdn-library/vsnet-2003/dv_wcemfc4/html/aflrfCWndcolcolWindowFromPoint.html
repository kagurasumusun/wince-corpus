CWnd::WindowFromPoint

This method retrieves the window that contains the specified point. The point argument must specify the screen coordinates of a point on the screen.

WindowFromPoint does not retrieve a hidden or disabled window, even if the point is within the window. An application should use the CWnd::ChildWindowFromPoint method for a nonrestrictive search.

static CWnd* PASCAL WindowFromPoint( 
POINT point );

Parameters

point
Specifies a CPoint object or POINT data structure that defines the point to be checked.

Return Value

Returns a pointer to the window object in which the point lies. It is NULL if no window exists at the given point. The returned pointer may be temporary and should not be stored for later use.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
