CListCtrl::GetSelectionMark

This method retrieves the selection mark from a list view control. This method implements the behavior of the Windows CE macro LISTVIEW_GETSELECTIONMARK. You can use this macro or explicitly send the LVM_GETSELECTIONMARK message.

int GetSelectionMark( );

Return Value

The zero-based selection mark, or –1 if there is no selection mark.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

// Set the selection mark to the first item only if no other item is
// selected.
if (pmyListCtrl->GetSelectionMark() == –1
     pmyListCtrl->SetSelectionMark(0);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
