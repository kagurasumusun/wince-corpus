COleSafeArray::GetUBound

This method retrieves the upper bound for any dimension of a safe array.

On error, the method throws a COleException.

void GetUBound( 
DWORD dwDim, 
long* pUBound );

Parameters

dwDim
Specifies the array dimension for which to get the upper bound.
pUBound
Specifies a pointer to the location to return the upper bound.

Example

COleSafeArray saMatrix;
DWORD numElements[] = {10, 5};

// Creates a two dimensional safearray of type VT_I2 
// with size 10x5 elements, with all indices starting at zero,default.
saMatrix.Create(VT_I2, 2, numElements);

long lUBound;
ASSERT(saMatrix.GetDim() == 2);

// Get upper bound for first dimension.
saMatrix.GetUBound(1, &lUBound);

ASSERT(lUBound == 9);

// Get upper bound for the second dimension.
saMatrix.GetUBound(2, &lUBound);

ASSERT(lUBound == 4);

COleSafeArray saVector;
SAFEARRAYBOUND rgsabounds[] = { {5, 1} };

// Creates a one dimensional safearray of type VT_I1 
// with size five elements, with the index starting at one.
saVector.Create(VT_I1, 1, rgsabounds);

// Get upper bound for first dimension.
saVector.GetUBound(1, &lUBound);

ASSERT(lUBound == 5);

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
