CImageList::SetBkColor

This method sets the background color for an image list.

COLORREF SetBkColor( 
COLORREF cr );

Parameters

cr
Specifies the background color to set. It can be CLR_NONE. In that case, images are drawn transparently using the mask.

Return Value

The previous background color if successful; otherwise, it is CLR_NONE.

Example

// Pointer to the myImageList.
extern CImageList* pmyImageList;

// Set the background color to white.
pmyImageList->SetBkColor(RGB(255, 255, 255));
ASSERT(pmyImageList->GetBkColor() == RGB(255, 255, 255));

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
