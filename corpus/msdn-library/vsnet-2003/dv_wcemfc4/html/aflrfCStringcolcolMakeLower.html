CString::MakeLower

This method converts this CString object to a lower-case string.

void MakeLower( );

Example

The following example demonstrates the use of CString::MakeLower.

// example for CString::MakeLower
CString s( "ABC" );
s.MakeLower();
ASSERT( s == "abc" );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
