CReBarCtrl::SetOwner

This method sets the parent window for a rebar control.

This method implements the behavior of the Windows CE message RB_SETPARENT.

Note that this method uses pointers to CWnd objects for both the current and selected owner of the rebar control, rather than handles to windows.

This method does not change the actual parent that was set when the control was created; rather it sends notification messages to the window you specify.

CWnd* SetOwner( 
CWnd* pWnd );

Parameters

pWnd
Specifies a pointer to a CWnd object to set as the owner of the rebar control.

Return Value

Returns a pointer to a CWnd object that is the current owner of the rebar control.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
