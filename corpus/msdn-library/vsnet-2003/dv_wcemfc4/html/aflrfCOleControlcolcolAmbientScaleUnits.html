COleControl::AmbientScaleUnits

This method retrieves the type of units used by the container. 

CString AmbientScaleUnits( );

Return Value

Returns a string containing the ambient ScaleUnits of the container. If this property is not supported, this function returns a zero-length string.

Remarks

The ambient ScaleUnits property of the container can be used to display positions or dimensions, labeled with the chosen unit, such as twips or centimeters. Note that the container is not required to support this property.

Requirements

  Windows CE versions: 2.0 and later
