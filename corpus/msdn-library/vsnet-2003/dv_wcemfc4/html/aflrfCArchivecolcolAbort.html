CArchive::Abort

This method closes the archive without throwing an exception. The CArchive destructor normally calls CArchive::Close, which flushes any data that has not been saved to the associated CFile object. This can cause exceptions.

When catching these exceptions, it is a good idea to use Abort, so that destructing the CArchive object does not cause further exceptions. When handling exceptions, CArchive::Abort does not throw an exception on failures because Abort ignores failures.

If you use new to allocate the CArchive object on the heap, then you must delete it after closing the file.
