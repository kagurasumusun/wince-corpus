Microsoft Foundation Class Library for Windows CE  

AfxGetThread

This function retrieves a pointer to the CWinThread object representing the currently executing thread. It must be called from within the desired thread.

CWinThread* AfxGetThread( );

Return Value

Returns a pointer to the currently executing thread.

Example

//Print the current thread ID in the Debug Window
TRACE("Current Thread ID = 0x%X\n", AfxGetThread()->m_nThreadID);

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxwin.h
