CArray::ElementAt

This method retrieves a temporary reference to the specified element within the array and implements the left-side assignment operator for arrays.

TYPE& ElementAt( 
int nIndex );

Parameters

TYPE
Template parameter that specifies the type of elements in the array.
nIndex
An integer index that is greater than or equal to zero and less than or equal to the value returned by GetUpperBound.

Return Value

A reference to an array element.

Example

See the example for GetSize.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
