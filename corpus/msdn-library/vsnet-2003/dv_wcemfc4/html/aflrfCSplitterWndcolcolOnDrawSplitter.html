CSplitterWnd::OnDrawSplitter

This method is called by the framework to draw and specify the exact characteristics of a splitter window.

Override OnDrawSplitter for advanced customization of the imagery for the various graphical components of a splitter window. The default imagery is similar to the splitter in Microsoft Works for Windows or Microsoft Windows 98, in that the intersections of the splitter bars are blended together.

virtual void OnDrawSplitter( 
CDC* pDC, 
ESplitType nType, 
const CRect& rect );

Parameters

pDC
Specifies a pointer to the device context in which to draw. If pDC is NULL, then CWnd::RedrawWindow is called by the framework and no split window is drawn.
nType
Specifies a value of the enum ESplitType, which can be one of the following:
  • splitBox   The splitter drag box.
  • splitBar   The bar that appears between the two split windows.
  • splitIntersection The intersection of the split windows. This element will not be called when running on Windows 98.
  • splitBorder   The split window borders.
rect
Specifies a reference to a CRect object specifying the size and shape of the split windows.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
