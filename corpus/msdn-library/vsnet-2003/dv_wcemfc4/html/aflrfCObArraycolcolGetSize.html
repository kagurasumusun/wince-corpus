CObArray::GetSize

This method retrieves the size of the array. Since indexes are zero-based, the size is one greater than the largest index.

int GetSize( ) 
const;

Remarks

The following table shows other methods that are similar to CObArray::GetSize.

Example

See CObList::CObList for a listing of the CAge class used in all collection examples.

CObArray myArray;

  // Add elements to the array.
  for (int i=0;i < 10;i++)
    myArray.Add( new CAge( i ) );

  // Add 100 to all the elements of the array.
  for (i=0;i < myArray.GetSize();i++)
  {
    CAge*& pAge = (CAge*&) myArray.ElementAt(i);
    delete pAge;
    pAge = new CAge( 100+i );
  }

#ifdef _DEBUG
    afxDump.SetDepth( 1 );
    afxDump << "myArray: " << &myArray << "\n";
#endif
