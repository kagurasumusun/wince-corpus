Microsoft Foundation Class Library for Windows CE  

CWinApp::Run

This method provides a default message loop. Run acquires and dispatches Windows CE messages until the application receives a WM_QUIT message. 

virtual int Run( );

Return Value

Returns an int value that is returned by WinMain.

Remarks

If the message queue in the application currently contains no messages, Run calls OnIdle to perform idle-time processing. Incoming messages go to the PreTranslateMessage method for special processing and then to the Windows CE function TranslateMessage for standard keyboard translation; finally, the DispatchMessage Windows CE function is called.

Run is rarely overridden, but you can override it to provide special behavior.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
