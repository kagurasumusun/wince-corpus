Microsoft Foundation Class Library for Windows CE  

CInternetConnection

This class manages your connection to an Internet server.

It is the base class for the MFC for Windows CE class, CHttpConnection. This class provides additional functionality for communicating with the respective HTTP server.

To communicate directly with an Internet server, you must have a CInternetSession object and a CInternetConnection object.

Remarks

Windows CE does not support methods for connecting with FTP and Gopher servers.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxinet.h
