CListBox::SetItemData

This method sets a 32-bit value associated with the specified item in a list box.

int SetItemData( 
int nIndex, 
DWORD dwItemData );

Parameters

nIndex
Specifies the zero-based index of the item.
dwItemData
Specifies the value to be associated with the item.

Return Value

LB_ERR if an error occurs.

Example

// Pointer to the myListBox.
extern CListBox* pmyListBox;

// Set the data of each item to be equal to its index.
for (int i=0;i < pmyListBox->GetCount();i++)
{
  pmyListBox->SetItemData(i, i);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
