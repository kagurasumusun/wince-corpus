CTypedPtrMap::operator [ ]

This operator is used on the left side of an assignment statement (an l-value) to retrieve a map element. If there is no map element with the specified key, then a new element is created. There is no right side (r-value) equivalent to this operator because there is a possibility that a key may not be found in the map. 

VALUE& operator [ ]( 
BASE_CLASS::BASE_ARG_KEY key );

Parameters

VALUE
Template parameter specifying the type of values stored in this map.
BASE_CLASS
Template parameter specifying the base class of this map class.
key
Specifies the key of the element to be looked up or created in the map.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxtempl.h
