CDialog::MapDialogRect

This method converts the dialog-box units of a rectangle to screen units. 

void MapDialogRect( 
LPRECT lpRect ) 
const;

Parameters

lpRect
Pointer to a RECT structure or CRect object that contains the dialog-box coordinates to convert.

Remarks

Dialog-box units are stated in terms of the dialog-box base unit derived from the average width and height of characters in the font used for dialog-box text. One horizontal unit is one-fourth of the dialog-box base-width unit, and one vertical unit is one-eighth of the dialog-box base height unit.

The GetDialogBaseUnits Windows CE function returns size information for the system font. You can specify a different font for each dialog box if you use the DS_SETFONT style in the resource-definition file. The MapDialogRect Windows function uses the appropriate font for this dialog box.

The MapDialogRect method replaces the dialog-box units in lpRect with pixels so that the rectangle can be used to create a dialog box or position a control within a box.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
