CHeaderCtrl::SetHotDivider

This method implements the behavior of the Windows CE message HDM_SETHOTDIVIDER. It is provided to support header item drag and drop.

int SetHotDivider( 
Cpoint pt ); 

int SetHotDivider( 
int nIndex );

Parameters

pt
The position of the pointer. The header control highlights the appropriate divider based on the position of the pointer.
nIndex
The index of the highlighted divider.

Return Value

The index of the highlighted divider.

Example

// Pointer to the myheader control.
extern CHeaderCtrl* pmyHeaderCtrl;
// The point where the mouse cursor is.
extern Cpoint myPoint;

pmyHeaderCtrl->SetHotDivider(myPoint);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
