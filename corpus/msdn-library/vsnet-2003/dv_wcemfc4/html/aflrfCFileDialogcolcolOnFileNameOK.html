Microsoft Foundation Class Library for Windows CE  

CFileDialog::OnFileNameOK

Override this method only if you want to provide custom validation of file names that are entered into a common file dialog box. Usually, you do not need to use this method because the framework provides default validation of file names and displays a message box if an invalid file name is entered. 

virtual BOOL OnFileNameOK( );

Return Value

One if the filename is not a valid filename; otherwise, it is zero.

Remarks

If one is returned, the dialog box will remain displayed for the user to enter another filename. The dialog procedure dismisses the dialog if the return is zero. Other nonzero return values are currently reserved and should not be used.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxdlgs.h
