Microsoft Foundation Class Library for Windows CE  

AfxThrowMemoryException

This function throws a memory exception. Call this function if calls to underlying system memory allocators (such as malloc and the LocalAlloc Windows CE function) fail. You do not need to call it for new because new will throw a memory exception automatically if the memory allocation fails.

void AfxThrowMemoryException( );

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afx.h
