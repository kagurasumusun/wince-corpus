CWnd::OnFontChange

This method is called by the framework for all top-level windows in the system after an application changes the pool of font resources. For example, through the AddFontResource or RemoveFontResource Windows CE function.

An application that adds or removes fonts from the system should send the WM_FONTCHANGE message to all top-level windows.

To send this message, use the SendMessage Windows CE function with the hWnd parameter set to HWND_BROADCAST.

afx_msg void OnFontChange( );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
