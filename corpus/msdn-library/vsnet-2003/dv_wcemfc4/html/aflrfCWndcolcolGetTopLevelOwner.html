CWnd::GetTopLevelOwner

This method obtains a pointer to the top-level window. The top-level window is the window that is a child of the desktop. If CWnd has no attached window, this function returns NULL.

CWnd* GetTopLevelOwner( ) 
const;

Return Value

Identifies the top-level window. The returned pointer may be temporary and should not be stored for later use.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
