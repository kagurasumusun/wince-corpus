CImageList::SetDragCursorImage

This method creates a new drag image by combining the specified image, typically a mouse cursor image, with the current drag image.

BOOL SetDragCursorImage( 
int nDrag, 
CPoint ptHotSpot );

Parameters

nDrag
Specifies the index of the new image to be combined with the drag image.
ptHotSpot
Specifies the position of the hot spot within the new image.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Remarks

Because the dragging functions use the new image during a drag operation, you should use the Windows CE ShowCursor function to hide the actual mouse cursor after calling CImageList::SetDragCursorImage. Otherwise, the system may appear to have two mouse cursors for the duration of the drag operation.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
