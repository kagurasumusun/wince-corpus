CToolBarCtrl::SetIndent

This method sets the indentation for the first button in a toolbar control.

BOOL SetIndent( 
int iIndent );

Parameters

iIndent
Specifies the value specifying the indentation, in pixels.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
