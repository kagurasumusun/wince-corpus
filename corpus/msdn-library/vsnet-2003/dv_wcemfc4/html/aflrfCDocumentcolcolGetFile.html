CDocument::GetFile

This method retrieves a pointer to a CFile object.

virtual CFile* GetFile( 
LPCTSTR lpszFileName, 
UINT nOpenFlags, 
CFileException* pError );

Parameters

lpszFileName
Specifies a string that is the path to the desired file. The path may be relative or absolute.
pError
Specifies a pointer to an existing file-exception object that indicates the completion status of the operation.
nOpenFlags
Specifies the sharing and access mode. Specifies the action to take when opening the file. Use the bitwise OR (|) operator to combine options listed in the CFile constructor CFile::CFile. One access permission and one share option are required; the modeCreate and modeNoInherit modes are optional.

Return Value

A pointer to a CFile object.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
