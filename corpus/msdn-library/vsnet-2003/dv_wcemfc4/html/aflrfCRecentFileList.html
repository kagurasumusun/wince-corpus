Microsoft Foundation Class Library for Windows CE  

CRecentFileList

This class is a CObject class that supports control of the most recently used (MRU) file list. Files can be added to or deleted from the MRU file list, the file list can be read from or written to the registry or an .ini file, and the menu displaying the MRU file list can be updated.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxadv.h
