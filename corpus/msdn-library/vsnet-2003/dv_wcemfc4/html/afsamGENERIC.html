Microsoft Foundation Class Library for Windows CE  

GENERIC

The GENERIC application demonstrates some of the basic functionality of Windows CE. This application creates the main application window and draws a horizontal and vertical line. Each line bisects the client area, creating four equal quadrants. The application captures the message WM_LBUTTONDOWN, and processes it according to the quadrant in which the user tapped the stylus.

Quadrant Action
Top Left: Exits the application
Top Right: Toggles the mouse capture on/off
Bottom Left: Changes the Z-order of the window
Bottom Right: Draws a square with the lower left corner at the point of the stylus tap.

The drawing is done in the OnPaint handler, using the Polyline function.

This sample demonstrates the following keywords:

CDC::Polyline CWnd::SetWindowPos
CFrameWnd::LoadFrame CWnd::ShowWindow
CWnd::GetClientRect CWnd::UpdateWindow
CWnd::InvalidateRect PostQuitMessage
CWnd::OnLButtonDown ReleaseCapture
