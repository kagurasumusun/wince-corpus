CListBox::GetTopIndex

This method retrieves the zero-based index of the first visible item in a list box. Initially, item zero is at the top of the list box, but if the list box is scrolled, another item may be at the top.

int GetTopIndex( ) 
const;

Return Value

The zero-based index of the first visible item in a list box if successful, LB_ERR otherwise.

Example

// Pointer to the myListBox.
extern CListBox* pmyListBox;

// Want an item in the bottom half to be the first visible item.
int n = pmyListBox->GetCount()/2;
if (pmyListBox->GetTopIndex() < n)
{
  pmyListBox->SetTopIndex(n);
  ASSERT(pmyListBox->GetTopIndex() == n);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
