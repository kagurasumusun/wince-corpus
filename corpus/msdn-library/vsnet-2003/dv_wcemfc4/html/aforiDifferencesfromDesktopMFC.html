Differences from Desktop MFC

Most of the desktop MFC library is supported for Windows CE platforms—but not everything. If an MFC class or member is supported in Windows CE, you can find it documented by looking in the Help index, or by looking in the alphabetical listing in the Reference.

This chapter of the Guide provides two overviews of the differences between desktop and Windows CE coverage. The first overview is by list according to the groupings shown below. The second is by hierarchical chart. These summaries are provided as a convenience. When you are actually planning your project and writing code, be sure to use the individual topics in the Reference as the most accurate guide.

Classes

  • Fully supported
  • Supported but modified
  • Not supported

Global Functions

  • Fully supported
  • Not supported

  • Disabled (includes substitutes)

Windows CE Structures

  • Supported
  • Not supported
