Microsoft Foundation Class Library for Windows CE  

CPrintInfo::GetMaxPage

This method retrieves the number of the last page of the document. This value is stored in the CPrintDialog object referenced by the m_pPD data member.

UINT GetMaxPage( ) 
const;

Return Value

Returns the number of the last page of the document.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
