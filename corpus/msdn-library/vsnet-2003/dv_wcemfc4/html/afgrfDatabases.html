Microsoft Foundation Class Library for Windows CE  

Databases

MFC for Windows CE contains four database classes (CCeDBDatabase, CCeDBRecord, CCeDBProp, and CCeDBEnum) unique to Windows CE. These classes support the simple Windows CE database functionality. MFC for Windows CE does not support other MFC database classes, such as CDaoxxx or COleDataxxx.

The CCeDBDatabase class encapsulates a database in the object store. A Windows CE database is not a full-function database, but a general-purpose structured collection of data.

Each Windows CE object store database has a unique name. You can also assign an application-defined type identifier to a database. Use this identifier to group similar databases.

A Windows CE database can have up to four sort properties that specify how the records are ordered.

If you specify a sort property when you open a database and there are records in the database that do not contain the property on which the database is being sorted, those records are placed last in the sort order. If the sort property is defined with the flag SORT_UNKNOWNFIRST, those records are placed before the sorted records instead.

A Windows CE database supports only one level of hierarchy. Multiple databases cannot share records. Every record has a unique object identifier and is present in exactly one database.

A database can have up to CEDB_MAXSORTORDER sort properties, which are used to determine the order in which records are arranged. To do a seek operation on a property value, that property must be a property specified in the sort order of the database.

Two sort properties in the same database cannot have the same application-defined identifier.

If no sort order is specified when a database is opened, the order in which the records are sorted is undefined.

For a sample of database operation in Windows CE, try the WCEDBTST sample.
