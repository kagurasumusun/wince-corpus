CCeDBDatabase::AddRecord

This method adds a new record to the database.

BOOL AddRecord( 
CCeDBRecord* pRecord ); 

BOOL AddRecord( 
CCeDBRecord* pRecord, 
CeOID& retID );

Parameters

pRecord
Specifies the pointer to the record to add to the database.
CeOID&
References the object identifier of the database.
RetID
Returns a unique identifier for the record object.

Return Values

TRUE indicates that the record was successfully added. FALSE indicates that there was an error. To get extended error information, call GetLastError.

The overloaded method lets you obtain the CeOID of the record you just added to the database.

Remarks

The position at which the record is entered depends on the sort orders in force for the database. If there are no sort orders defined, the record is placed at the end.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Wcedb.h
