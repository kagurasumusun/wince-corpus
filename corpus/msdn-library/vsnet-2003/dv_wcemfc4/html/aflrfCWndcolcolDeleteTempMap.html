Microsoft Foundation Class Library for Windows CE  

CWnd::DeleteTempMap

This method is called automatically by the idle time handler of the CWinApp object. It deletes any temporary CWnd objects created by the FromHandle method.

static void PASCAL DeleteTempMap( );

Example

// The following example is correct:
CWnd::DeleteTempMap();

// The following example is incorrect.
// DeleteTempMap() is a static member and cannot be called 
// within the scope of an instantiated CWnd object.
pWnd->DeleteTempMap();  // Causes a compiler error.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
