CArray::SetAt

This method sets the array element at the specified index. SetAt does not cause the array to grow. Use the SetAtGrow method if you want the array to grow automatically.

void SetAt( 
int nIndex, 
ARG_TYPE newElement );

Parameters

nIndex
An integer index that is greater than or equal to zero and less than or equal to the value returned by GetUpperBound.
ARG_TYPE
Template parameter that specifies the type of arguments used for referencing array elements.
newElement
Specifies the new element value to store at the specified position.

Remarks

You must ensure that your index value represents a valid position in the array. If it is out of bounds, the Debug version of the library asserts.

Example

See the example for GetAt.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
