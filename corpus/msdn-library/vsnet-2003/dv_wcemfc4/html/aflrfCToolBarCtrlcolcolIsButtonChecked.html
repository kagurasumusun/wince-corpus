CToolBarCtrl::IsButtonChecked

This method determines whether the specified button in a toolbar control is checked.

BOOL IsButtonChecked( 
int nID ) 
const;

Parameters

nID
Specifies the command identifier of the button in the toolbar.

Return Value

Nonzero if the button is checked; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
