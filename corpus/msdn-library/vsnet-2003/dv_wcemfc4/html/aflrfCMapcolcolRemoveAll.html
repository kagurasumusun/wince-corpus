Microsoft Foundation Class Library for Windows CE  

CMap::RemoveAll

This method removes all the values from this map by calling the DestructElements global helper function.

The method works correctly if the map is already empty.

void RemoveAll( );

Example

CMap<int,int,CPoint,CPoint> myMap;

// Add 10 elements to the map.
for (int i=0;i < 10;i++)
  myMap.SetAt( i, CPoint(i, i) );

myMap.RemoveAll();

ASSERT(myMap.IsEmpty());

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
