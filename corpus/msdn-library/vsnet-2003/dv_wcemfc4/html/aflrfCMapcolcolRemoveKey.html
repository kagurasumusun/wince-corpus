CMap::RemoveKey

This method removes the map entry corresponding to the supplied key.

The DestructElements helper function is used to remove the entry.

BOOL RemoveKey( 
ARG_KEY key );

Parameters

ARG_KEY
Template parameter specifying the type of the key.
key
Specifies the key for the element to be removed.

Return Value

Nonzero if the entry was found and successfully removed; otherwise, it is zero.

Example

CMap<int,int,CPoint,CPoint> myMap;

  // Add 10 elements to the map.
  for (int i=0;i < 10;i++)
    myMap.SetAt( i, CPoint(i, i) );

  // Remove the elements with even key values.
  POSITION pos = myMap.GetStartPosition();
  int    nKey;
  CPoint pt;
  while (pos != NULL)
  {
    myMap.GetNextAssoc( pos, nKey, pt );

    if ((nKey%2) == 0)
      myMap.RemoveKey( nKey );
  }

#ifdef _DEBUG
    afxDump.SetDepth( 1 );
    afxDump << "myMap: " << &myMap << "\n";
#endif

Requirements

Windows CE versions: 1.0 and later
