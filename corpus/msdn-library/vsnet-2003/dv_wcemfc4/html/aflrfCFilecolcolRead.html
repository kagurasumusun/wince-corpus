CFile::Read

This method reads data into a buffer from the file associated with the CFile object.

virtual UINT Read( 
void* lpBuf, 
UINT nCount );

Parameters

lpBuf
Specifies the pointer to the user-supplied buffer that is to receive the data read from the file.
nCount
Specifies the maximum number of bytes to be read from the file. For text-mode files, carriage return–linefeed pairs are counted as single characters.

Return Value

The number of bytes transferred to the buffer. Note that for all CFile classes, the return value may be less than nCount if the end of file was reached.

Remarks

You can use the Cfile::Open method to read files in the Windows CE object store.

Example

// Example for the CFile::Read method.
extern CFile cfile;
TCHAR pbuf[100];
UINT nBytesRead = cfile.Read( pbuf, 100 );

For another example see CFile::Open.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
