CCeDBProp::GetBlob

This method retrieves the value of a property, when the property's data type is a binary large object (CEBLOB).

CEBLOB GetBlob( ) 
const;

Return Values

A pointer to the string represented by the property.

Remarks

You can only call GetBlob on a property of the type CCeDBProp::Type_Blob.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Wcedb.h

See Also

CCeDBProp::SetBlob, CEBLOB
