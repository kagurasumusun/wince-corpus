COleControl::GetFontTextMetrics

This method retrieves the text metrics of a CFontHolder object. Such a font can be selected with the COleControl::SelectFontObject function. COleControl::GetFontTextMetrics will initialize the TEXTMETRIC structure pointed to by lptm with valid metrics information about the fontHolder font if successful, or fill the structure with zeros if not successful. You should use this function instead of GetTextMetrics when painting your control because controls, like any embedded OLE object, may be required to render themselves into a metafile.

void GetFontTextMetrics( 
LPTEXTMETRIC lptm, 
CFontHolder& fontHolder );

Parameters

lptm
Pointer to a TEXTMETRIC structure.
fontHolder
Reference to a CFontHolder object.

Remarks

The TEXTMETRIC structure for the default font is refreshed when the SelectFontObject function is called. You should call COleControl::GetFontTextMetrics only after selecting the stock Font property to assure the information it provides is valid.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
