CPoint::operator -=

This operator subtracts the x, or cx, member of the right operand from the x member of the CPoint and the y, or cy, member of the right operand from the y member of the CPoint.

For example, subtracting CPoint(5, – 7) from a variable which contains CPoint(30, 40) changes the variable to CPoint(25, 47).

void operator –=( 
SIZE size ); 

void operator–=( 
POINT point );

Parameters

size
Contains a SIZE structure or CSize object.
point
Contains a POINT structure or CPoint object.

Example

CPoint  ptStart(100, 100);
CSize  szOffset(35, 35);

ptStart -= szOffset;

CPoint  ptResult(65, 65);

ASSERT(ptResult == ptStart);

// This also works on SIZE.

ptStart = CPoint(100, 100);

SIZE  sz;
sz.cx = 35;
sz.cy = 35;

ptStart -= sz;

ASSERT(ptResult == ptStart);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
