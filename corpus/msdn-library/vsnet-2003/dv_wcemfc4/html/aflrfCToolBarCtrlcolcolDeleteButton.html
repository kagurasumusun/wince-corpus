CToolBarCtrl::DeleteButton

This method deletes a button from the toolbar control.

BOOL DeleteButton( 
int nIndex );

Parameters

nIndex
Specifies the zero-based index of the button to delete.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
