Microsoft Foundation Class Library for Windows CE  

CDC::DPtoLP

This method does not do anything in Windows CE. It is included for compatibility with existing code.

void DPtoLP ( 
LPPOINT lpPoints, 
int nCount = 1 ) 
const;

void DPtoLP ( 
LPRECT lpRect ) 
const;

void DPtoLP ( 
LPSIZE lpSize ) 
const;

Parameters

lpPoints
Pointers to an array of POINT structures or CPoint objects.
nCount
The number of points in the array.
lpRect
Pointer to a RECT structure or CRect object. This parameter is used for converting a rectangle from device points to logical points.
lpSize
Pointer to a SIZE structure or CSize object.

Remarks

In Windows CE, you cannot change the window and viewport origins or extents, which means that device coordinates are always the same as logical coordinates. Because of this, the CDC::DPtoLP method does not do anything with the values you pass it.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
