CDC::Polyline

This method draws a set of line segments connecting the points specified by lpPoints. The lines are drawn from the first point through subsequent points using the current pen.

BOOL Polyline( 
LPPOINT lpPoints, 
int nCount );

Parameters

lpPoints
Pointer to an array of POINT structures or CPoint objects to connect.
nCount
The number of points in the array. This value must be at least two.

Return Value

Nonzero if the function is successful; otherwise, it is zero.

Remarks

Unlike the LineTo method, the Polyline method neither uses nor updates the current position.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
