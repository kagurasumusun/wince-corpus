Microsoft Foundation Class Library for Windows CE  

CButton

This class encapsulates the functionality of a Windows CE button, which is a small rectangular control that a user can turn on or off by tapping it with a pointing device.

Remarks

The CButton class provides the functionality of Windows button controls. A button control is a small, rectangular child window that can be clicked on and off. Buttons can be used alone or in groups, and can be labeled or appear without text. A button typically changes appearance when the user clicks it.

Typical buttons are the check box, radio button, and pushbutton. A CButton object can become any of these, according to the button style specified at its initialization by the Create method.

In addition, the CBitmapButton class derived from CButton supports creation of button controls labeled with bitmap images instead of text. A CBitmapButton can have separate bitmaps for the up, down, focused, and disabled states of a button.

You can create a button control from a dialog template or directly in your code. In both cases, call the constructor CButton to construct the CButton object; then call the Create method to create the Windows button control and attach it to the CButton object.

Construction can be a one-step process in a class derived from CButton. Write a constructor for the derived class and call Create from within the constructor.

To handle Windows CE notification messages sent by a button control to its parent, usually a class derived from CDialog, add a message-map entry and message-handler method to the parent class for each message.

Each message-map entry takes the following form:

ON_Notification( id, memberFxn )

where id specifies the child window identifier of the control sending the notification and memberFxn is the name of the parent method you have written to handle the notification.

The prototype of the parent function is as follows:

afx_msg void memberFxn( );

Potential message-map entries are as follows:

Map entry Sent to parent when...
ON_BN_CLICKED The user clicks a button.
ON_BN_DOUBLECLICKED The user double-clicks a button.

If you create a CButton object from a dialog resource, the CButton object is automatically destroyed when the user closes the dialog box.

If you create a CButton object within a window, you may need to destroy it. If you create the CButton object on the heap by using the New function, you must call Delete on the object to destroy it when the user closes the Windows button control. If you create the CButton object on the stack, or it is embedded in the parent dialog object, it is destroyed automatically.

MFC for Windows CE does not support the following CButton class methods:

  • GetBitmap
  • SetBitmap
  • GetIcon
  • SetIcon
  • GetCursor
  • SetCursor

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
