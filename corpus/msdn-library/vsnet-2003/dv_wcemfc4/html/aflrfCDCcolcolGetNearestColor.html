Microsoft Foundation Class Library for Windows CE  

CDC::GetNearestColor

This method retrieves the solid color that best matches a specified logical color. The specified device must be able to represent this color.

COLORREF GetNearestColor( 
COLORREF crColor ) 
const;

Parameters

crColor
The color to be matched.

Return Value

An RGB (red, green, blue) color value that defines the solid color closest to the crColor value that the device can represent.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
