Microsoft Foundation Class Library for Windows CE  

COleControl::OnKeyDownEvent

This method is called by the framework after the stock KeyDown event has been fired.

Override this function if your control needs access to the key information after the event has been fired.

virtual void OnKeyDownEvent( 
USHORT nChar, 
USHORT nShiftState );

Parameters

nChar
Specifies the virtual key code value of the pressed key. For a list of standard virtual key codes, see Winuser.h
nShiftState
Contains a combination of the following flags:
  • SHIFT_MASK   The SHIFT key was pressed during the action.
  • CTRL_MASK   The CTRL key was pressed during the action.
  • ALT_MASK   The ALT key was pressed during the action.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
