Microsoft Foundation Class Library for Windows CE  

CButton::Create

This method creates the Windows CE button control and attaches it to the CButton object. 

BOOL Create( 
LPCTSTR lpszCaption, 
DWORD dwStyle, 
const RECT& rect, 
CWnd* pParentWnd, 
UINT nID );

Parameters

lpszCaption
Specifies the button control text.
dwStyle
Specifies the button control style. Apply any combination of button styles to the button.
rect
Specifies the button control size and position. It can be a CRect object or a RECT structure.
pParentWnd
Specifies the button control parent window, usually a CDialog. It must not be NULL.
nID
Specifies the button control identifier.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Remarks

You construct a CButton object in two steps. First call the constructor, then call Create, which creates the Windows button control and attaches it to the CButton object.

If the WS_VISIBLE style is given, Windows CE sends the button control all the messages required to activate and show the button.

Apply the following window styles to a button control:

  • WS_CHILD   Always
  • WS_VISIBLE   Usually
  • WS_DISABLED   Rarely
  • WS_GROUP   To group controls
  • WS_TABSTOP   To include the button in the tabbing order

Windows CE does not support the following button styles:

  • BS_BITMAP
  • BS_ICON
  • BS_LEFTTEXT
  • BS_PUSHBOX
  • BS_TEXT
  • BS_USERBUTTON

Use the BS_RIGHTBUTTON style instead of BS_LEFTTEXT to place a checkbox or radio button to the right of the associated text. Use the BS_OWNERDRAW style to create the effects otherwise, achieved with the BS_USERBUTTON, BS_BITMAP or BS_ICON button styles.

Example

CButton myButton1, myButton2, myButton3, myButton4;

// Create a push button.
myButton1.Create(_T("My button"), WS_CHILD|WS_VISIBLE|BS_PUSHBUTTON, 
  CRect(10,10,100,30), pParentWnd, 1);

// Create a radio button.
myButton2.Create(_T("My button"), WS_CHILD|WS_VISIBLE|BS_RADIOBUTTON, 
  CRect(10,40,100,70), pParentWnd, 2);

// Create an auto 3-state button.
myButton3.Create(_T("My button"), WS_CHILD|WS_VISIBLE|BS_AUTO3STATE, 
  CRect(10,70,100,100), pParentWnd, 3);

// Create an auto check box.
myButton4.Create(_T("My button"), WS_CHILD|WS_VISIBLE|BS_AUTOCHECKBOX, 
  CRect(10,100,100,130), pParentWnd, 4);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
