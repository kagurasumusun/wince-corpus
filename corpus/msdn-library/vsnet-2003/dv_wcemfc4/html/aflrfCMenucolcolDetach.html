Microsoft Foundation Class Library for Windows CE  

CMenu::Detach

This method detaches a Windows CE menu from a CMenu object and retrieves its menu handle. The m_hMenu data member is set to NULL.

HMENU Detach( );

Return Value

The handle, of type HMENU, to a Windows CE menu, if successful; otherwise, it is NULL.

Example

CMenu mnu;
HMENU hmnu = AfxGetMainWnd()->GetMenu()->GetSafeHmenu();
mnu.Attach( hmnu );

// Now you can manipulate the window menu as a CMenu
// object.

hmnu = mnu.Detach();

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
