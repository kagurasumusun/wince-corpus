CFrameWnd::EndModalState

This method changes a frame window from modal to modeless. EndModalState enables all of the windows disabled by BeginModalState.

virtual void EndModalState( );

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
