CToolBarCtrl::GetDisabledImageList

This method retrieves the image list that a toolbar control uses to display disabled buttons.

This method implements the behavior of the Windows CE message TB_GETDISABLEDIMAGELIST.

CImageList* GetDisabledImageList( ) 
const;

Return Value

A pointer to a CImageList object, or NULL if no disabled image list is set.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h

See Also

CToolBarCtrl::SetDisabledImageList, CToolBarCtrl::GetImageList
