CScrollView::GetTotalSize

This method retrieves the current horizontal and vertical sizes of the scroll view.

CSize GetTotalSize( ) 
const;

Return Value

The total size of the scroll view in logical units. The horizontal size is in the cx member of the CSize return value. The vertical size is in the cy member.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h

CScrollView::GetDeviceScrollSizes, CScrollView::SetScrollSizes
