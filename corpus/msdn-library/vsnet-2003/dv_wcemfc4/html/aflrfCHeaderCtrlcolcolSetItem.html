CHeaderCtrl::SetItem

This method sets the attributes of the specified item in a header control.

BOOL SetItem( 
int nPos, 
HDITEM* pHeaderItem );

Parameters

nPos
Specifies the zero-based index of the item to be manipulated.
pHeaderItem
Specifies the pointer to an HDITEM structure that contains information about the new item.

Return Value

Nonzero if successful; otherwise, it is zero.

Example

See the example for CHeaderCtrl::GetItem.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h

See Also

CHeaderCtrl::GetItem, CHeaderCtrl::GetItemCount
