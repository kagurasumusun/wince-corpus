Microsoft Foundation Class Library for Windows CE  

CListView

The CListView class simplifies use of the list control and of CListCtrl, the class that encapsulates list-control functionality, with MFC for Windows CE document-view architecture. For more information on this architecture, see the overview for the CView class and the cross-references cited there.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcview.h

CView, CCtrlView, CListCtrl, View Classes
