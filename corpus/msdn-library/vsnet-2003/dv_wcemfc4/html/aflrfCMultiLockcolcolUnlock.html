CMultiLock::Unlock

This method releases the synchronization object owned by CMultiLock. This function is called by the CMultiLock destructor. 

BOOL Unlock( ); 

BOOL Unlock( 
LONG lCount, 
LPLONG lPrevCount = NULL );

Parameters

lCount
Number of reference counts to release. Must be greater than 0. If the specified amount would cause the object count to exceed its maximum, the count is not changed and the function returns FALSE.
lPrevCount
Points to a variable to receive the previous count for the synchronization object. If NULL, the previous count is not returned.

Return Value

Nonzero if the function was successful; otherwise, it is zero.

Remarks

The first form of Unlock tries to unlock the synchronization object managed by CMultiLock. The second form of Unlock does nothing in Windows CE and always returns FALSE. By default, CMultiLock returns TRUE. lCount and lpPrevCount are exactly the same as the parameters of CSingleLock::Unlock. The second form of Unlock is rarely applicable to multilock situations.

Requirements

Windows CE versions: 3.0 and later
Header file: Declared in Afxmt.h
