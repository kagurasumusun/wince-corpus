COleVariant::Detach

This method detaches the underlying VARIANT object from this COleVariant object. This method sets the VARTYPE for this COleVariant object to VT_EMPTY.

After calling COleVariant::Detach, it is the caller’s responsibility to call VariantClear on the resulting VARIANT structure.

VARIANT Detach( );

Return Type

The underlying VARIANT value of this COleVariant object.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
