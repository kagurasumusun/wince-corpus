CTimeSpan::operator +, -

These two operators add and subtract CTimeSpan objects to and from each other.

CTimeSpan operator +( 
CTimeSpan timeSpan ) 
const;

CTimeSpan operator –( 
CTimeSpan timeSpan ) 
const;

Example

// example for CTimeSpan::operator +, -
CTimeSpan ts1( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
CTimeSpan ts2( 100 ); // 100 seconds
CTimeSpan ts3 = ts1 + ts2;
ASSERT( ts3.GetSeconds() == 52 ); // 6 mins, 52 secs

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
