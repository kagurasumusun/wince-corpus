CWnd::ClientToScreen

This method converts the client coordinates of a specified point or rectangle on the display to screen coordinates. The ClientToScreen method uses the client coordinates in the POINT or RECT structure or the CPoint or CRect object pointed to by lpPoint or lpRect to compute new screen coordinates; it then replaces the coordinates in the structure with the new coordinates. The new screen coordinates are relative to the upper-left corner of the system display.

The ClientToScreen method assumes that the given point or rectangle is in client coordinates.

void ClientToScreen( 
LPPOINT lpPoint ) 
const; 

void ClientToScreen( 
LPRECT lpRect ) 
const;

Parameters

lpPoint
Points to a POINT structure or CPoint object that contains the client coordinates to be converted.
lpRect
Points to a RECT structure or CRect object that contains the client coordinates to be converted.

Example

// Resize dialog to client's size.
void CAboutDlg::OnButton1() 
{
  CRect myRect;
  GetClientRect(&myRect);

  ClientToScreen(myRect);
  MoveWindow(myRect.left, myRect.top,
    myRect.Width(), myRect.Height());
}

Requirements

  Windows CE versions: 1.0 and later
