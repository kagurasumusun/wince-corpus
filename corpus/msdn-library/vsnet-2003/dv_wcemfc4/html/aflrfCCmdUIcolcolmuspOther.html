Microsoft Foundation Class Library for Windows CE  

CCmdUI::m_pOther

This data member contains a pointer to the CWnd object, such as a toolbar or status bar, that sent the notification.

CWnd* m_pOther;

Remarks

This data members value is NULL if the item is a menu or a non-CWnd object.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
