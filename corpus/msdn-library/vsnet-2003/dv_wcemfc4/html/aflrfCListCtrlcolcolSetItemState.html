CListCtrl::SetItemState

This method changes the state of an item in a list view control.

The state of an item is a value that specifies the availability of that item, indicates user actions, or otherwise, reflects the status of the item. A list view control changes some state bits, such as when the user selects an item. An application might change other state bits to disable or hide the item, or to specify an overlay image or state image.

BOOL SetItemState( 
int nItem, 
LVITEM* pItem ); 

BOOL SetItemState( 
int nItem, 
UINT nState, 
UINT nMask );

Parameters

nItem
Specifies the index of the item whose state is to be set.
pItem
Specifies the address of an LVITEM structure, as described in the API Reference. The stateMask member of a structure specifies which state bits to change. The state member also contains the new values for those bits. The other members are ignored.
nState
Specifies the new values for the state bits.
nMask
Specifies the mask specifying which state bits to change.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

// Make sure the focus is set to the list view control.
pmyListCtrl->SetFocus();

// Select all of the items that are completely visible.
int n = pmyListCtrl->GetTopIndex();
int nLast = n + pmyListCtrl->GetCountPerPage();

for (;n < nLast;n++)
{
   pmyListCtrl->SetItemState(n, LVIS_SELECTED, LVIS_SELECTED);
   ASSERT(pmyListCtrl->GetItemState(n, LVIS_SELECTED) == LVIS_SELECTED);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
