Microsoft Foundation Class Library for Windows CE  

COleControl::GetClientSite

This method queries an object for the pointer to its current client site within its container.

The returned pointer points to an instance of IOleClientSite. The IOleClientSite interface, implemented by containers, is the view of the object context: where it is anchored in the document, where it gets its storage, user interface, and other resources. 

LPOLECLIENTSITE GetClientSite( );

Return Value

A pointer to the current client site of the control in its container.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
