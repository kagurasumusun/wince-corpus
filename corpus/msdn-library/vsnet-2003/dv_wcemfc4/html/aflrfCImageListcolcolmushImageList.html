CImageList::m_hImageList

This data member contains the handle to the image list attached to this object. The m_hImageList data member is a public variable of type HIMAGELIST.

HIMAGELIST m_hImageList;

Example

// Pointer to the myImageList.
extern CImageList* pmyImageList;

// Get the safe handle to the image list.
HIMAGELIST hImageList = pmyImageList->m_hImageList;

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
