Microsoft Foundation Class Library for Windows CE  

CCeDBProp::SetDouble

This method sets the value of a double property. 

void SetDouble (
DOUBLE dDouble );

Parameters

dDouble
Specifies the value of the property.

Remarks

You can call SetDouble only on a property of the type CCeDBProp::Type_Double.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Wcedb.h
