Microsoft Foundation Class Library for Windows CE  

CPrintInfo::GetToPage

This method retrieves the number of the last page to be printed. This is the value specified by the user in the Print dialog box, and it is stored in the CPrintDialog object referenced by the m_pPD member. If the user has not specified a value, the default is the last page of the document.

UINT GetToPage( ) 
const;

Return Value

The number of the last page to be printed.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
