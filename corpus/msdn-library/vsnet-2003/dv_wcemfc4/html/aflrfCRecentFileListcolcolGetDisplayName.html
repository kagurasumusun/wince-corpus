CRecentFileList::GetDisplayName

This method obtains the display name for a file in the most recently used (MRU) file list, for use in the menu display of the MRU list. If the file is in the current directory, the function leaves the directory off the display. If the filename is too long, the directory and extension are stripped. If the filename is still too long, the display name is set to an empty string unless bAtLeastName is nonzero.

BOOL GetDisplayName( 
CString& strName, 
int nIndex, 
LPCTSTR lpszCurDir, 
int nCurDir, 
BOOL bAtLeastName = TRUE) 
const;

Parameters

strName
Specifies the full path of the file whose name is to be displayed in the menu list of MRU files.
nIndex
Specifies the zero-based index of the file in the MRU file list.
lpszCurDir
Specifies the string holding the current directory.
nCurDir
Specifies the length of the current directory string.
bAtLeastName
If nonzero, bAtLeastName indicates that the base name of the file should be returned, even if it exceeds the maximum display length. The base name of the file is passed as the nMaxDispLen parameter to the CRecentFileList constructor.

Return Value

FALSE if there is no filename at the specified index in the MRU file list.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxadv.h
