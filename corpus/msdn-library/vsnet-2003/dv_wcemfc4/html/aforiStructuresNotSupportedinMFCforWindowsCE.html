Structures Not Supported in MFC for Windows CE

Windows CE does not support the following structures used in desktop MFC.

CDaoDatabaseInfo HSE_VERSION_INFO
CDaoErrorInfo HTTP_FILTER_AUTHENT
CDaoFieldInfo HTTP_FILTER_CONTEXT
CDaoIndexInfo HTTP_FILTER_LOG
CDaoIndexFieldInfo HTTP_FILTER_PREPROC_HEADERS
CDaoParameterInfo HTTP_FILTER_RAW_DATA
CDaoQueryDefInfo HTTP_FILTER_URL_MAP
CDaoRelationInfo HTTP_FILTER_VERSION
CDaoRelationFieldInfo LINGER
CDaoTableDefInfo MINMAXINFO
CDaoWorkspaceInfo NCCALCSIZE_PARAMS
CFileStatus WINDOWPLACEMENT
