CPropertySheet::GetPageCount

This method determines the number of pages currently in the property sheet.

int GetPageCount( ) 
const;

Return Value

The number of pages in the property sheet.

Example

This is the code example for CPropertySheet::GetPageCount.

// Get the number of property pages from CPropertySheet.
CPropertySheet* sheet = (CPropertySheet*) GetParent( );
int count = sheet->GetPageCount( );

for (int i = 0; i < count; i++)
{
   CPropertyPage* page = (CPropertyPage*) sheet->GetPage(i);

   // Add your code here.
   // …
}

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxdlgs.h
