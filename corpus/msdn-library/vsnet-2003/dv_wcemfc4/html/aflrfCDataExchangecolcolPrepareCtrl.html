CDataExchange::PrepareCtrl

This method is called by the framework to prepare the specified control for dialog data exchange (DDX) and validation (DDV).

HWND PrepareCtrl( 
int nIDC );

Parameters

nIDC
Specifies the identifier of the control to prepare for DDX or DDV.

Return Value

The HWND of the control being prepared for DDX or DDV.

Remarks

Use PrepareEditCtrl for edit controls; use this method for all other controls. Preparation consists of storing the control HWND in the CDataExchange class. The framework uses this handle to restore the focus to the previously focused control in the event of a DDX or DDV failure.

Implementors of custom DDX or DDV routines should call PrepareCtrl for all nonedit controls for which they are exchanging data through DDX or validating data through DDV.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
