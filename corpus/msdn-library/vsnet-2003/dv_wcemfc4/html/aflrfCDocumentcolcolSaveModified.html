CDocument::SaveModified

This method is called by the framework before a modified document is closed. The default implementation of CDocument::SaveModified method displays a message box asking the user whether to save the changes to the document, if any have been made.

Override this method if your program requires a different prompting procedure. This is an advanced overridable.

virtual BOOL SaveModified( );

Return Value

Nonzero if it is safe to continue and close the document; zero if the document should not be closed.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
