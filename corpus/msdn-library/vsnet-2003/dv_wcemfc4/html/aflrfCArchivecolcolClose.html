CArchive::Close

This method flushes any data remaining in the buffer, closes the archive, and disconnects the archive from the file. No further operations on the archive are permitted. After you close an archive, you can create another archive for the same file or you can close the file.

void Close( );

Remarks

The method Close ensures that all data is transferred from the archive to the file, and it makes the archive unavailable. To complete the transfer from the file to the storage medium, you must first use CFile::Close and then destroy the CFile object.

Example

See the example for CArchive::WriteString.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
