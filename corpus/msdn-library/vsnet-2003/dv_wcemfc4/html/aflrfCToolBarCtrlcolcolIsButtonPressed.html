CToolBarCtrl::IsButtonPressed

This method determines whether the specified button in a toolbar control is pressed. Consider calling GetState if you want to retrieve more than one button state.

BOOL IsButtonPressed( 
int nID ) 
const;

Parameters

nID
Command identifier of the button in the toolbar.

Return Value

Nonzero if the button is pressed, otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
