CWinThread::SuspendThread

This method increments the suspend count of the current thread. If any thread has a suspend count above zero, that thread does not execute. The thread can be resumed by calling the ResumeThread method.

DWORD SuspendThread( );

Return Value

The previous suspend count of the thread if it is successful; otherwise, it is 0xFFFFFFFF.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
