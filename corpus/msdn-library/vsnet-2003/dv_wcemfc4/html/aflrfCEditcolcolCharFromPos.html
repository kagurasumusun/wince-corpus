CEdit::CharFromPos

This method retrieves the zero-based line and character indexes of the character nearest the specified point in this CEdit control.

int CharFromPos( 
CPoint pt ) 
const;

Parameters

pt
Specifies the coordinates of a point in the client area of this CEdit object.

Return Value

The character index in the low-order WORD, and the line index in the high-order WORD.

Example

#ifdef _DEBUG
  // The pointer to my edit.
  extern CEdit* pmyEdit;
  // The point where the user clicked the mouse.
  extern CPoint myPt;

  int n = pmyEdit->CharFromPos(myPt);
  int nLineIndex = HIWORD(n);
  int nCharIndex = LOWORD(n);
  TRACE(TEXT("nLineIndex = %d, nCharIndex = %d\r\n"), nLineIndex, nCharIndex);
#endif

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
