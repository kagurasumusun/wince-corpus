CCmdTarget::EndWaitCursor

This method should be called after you call the CCmdTarget::BeginWaitCursor method to return from the hourglass cursor to the previous cursor. The framework also calls this method after it calls the hourglass cursor.

void EndWaitCursor( );

Example

// This example illustrates the most common case of displaying 
// the hourglass cursor during lengthy processing of a 
// command handler implemented in a CCmdTarget-derived class,
// such as a document or view.

void CMyView::OnSomeCommand()
{
   BeginWaitCursor(); // Display the hourglass cursor.

   // Do some lengthy processing.

   EndWaitCursor(); // Remove the hourglass cursor.
}

// The followingexample illustrates RestoreWaitCursor.
void CMyView::OnSomeCommand()
{
   BeginWaitCursor(); // Display the hourglass cursor.

   // Do some lengthy processing.

   // The dialog box normally changes the cursor to the 
   // standard arrow cursor and leaves the cursor in as the 
   // standard arrow cursor when the dialog box is closed.
   CMyDialog dlg;
   dlg.DoModal();

   // You must call RestoreWaitCursor here to change the 
   // cursor back to the hourglass cursor.
   RestoreWaitCursor();

   // Do more lengthy processing.

   EndWaitCursor(); // Remove the hourglass cursor.
}

// In the above example, the dialog was invoked between the pair of 
// calls to BeginWaitCursor and EndWaitCursor. Sometimes it may not 
// be clear whether the dialog is invoked between a pair of calls to 
// BeginWaitCursor and EndWaitCursor. You can call RestoreWaitCursor,
// even if BeginWaitCursor is not previously called.  This case is 
// illustrated below, where CMyView::AnotherFunction does not need to 
// know whether it is called in the context of an hourglass cursor.
void CMyView::AnotherFunction()
{
   // Some processing ...

   CMyDialog dlg;
   dlg.DoModal();
   RestoreWaitCursor();

   // More processing ...
}

// If the dialog is invoked from a method of some non-CCmdTarget,
// you can call CWinApp::DoWaitCursor with a 0 parameter value to 
// restore the hourglass cursor.
void CMyObject::AnotherFunction()
{
   CMyDialog dlg;
   dlg.DoModal();
   AfxGetApp()->DoWaitCursor(0); // Same as CCmdTarget::RestoreWaitCursor   
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
