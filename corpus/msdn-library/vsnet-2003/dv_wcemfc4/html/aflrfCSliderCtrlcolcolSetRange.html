CSliderCtrl::SetRange

This method sets the range, both minimum and maximum positions, for the slider in a slider control.

void SetRange( 
int nMin, 
int nMax, 
BOOL bRedraw = FALSE );

Parameters

nMin
Specifies the minimum position for the slider.
nMax
Specifies the maximum position for the slider.
bRedraw
Specifies the redraw flag. If this parameter is TRUE, the slider is redrawn after the range is set; otherwise, the slider is not redrawn.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
