CObArray::InsertAt

This method inserts an element into the array. The first implementation of InsertAt inserts one element, or multiple copies of an element, at a specified index in an array. In the process, it shifts up the existing element at this index, by incrementing the index, and it shifts up all the elements above it. The second implementation inserts all the elements from another CObArray collection, starting at the nStartIndex position.

The SetAt method, in contrast, replaces one specified array element and does not shift any elements.

void InsertAt( 
int nIndex, 
CObject* newElement, 
int nCount = 1 ); 

void InsertAt( 
int nStartIndex, 
CObArray* pNewArray );

Parameters

nIndex
Specifies an integer index that may be greater than the value returned by GetUpperBound.
newElement
Specifies the CObject pointer to be placed in this array. A newElement of value NULL is allowed.
nCount
Specifies the number of times this element should be inserted (defaults to 1).
nStartIndex
Specifies an integer index that may be greater than the value returned by GetUpperBound.
pNewArray
Specifies another array that contains elements to be added to this array.

Example

See CObList::CObList for a listing of the CAge class used in all collection examples.

// Example for CObArray::InsertAt.

    CObArray array;
    
    array.Add( new CAge( 21 ) ); // Element 0
    array.Add( new CAge( 40 ) ); // Element 1 (will become 2).
    array.InsertAt( 1, new CAge( 30 ) );  // New element 1
#ifdef _DEBUG
    afxDump.SetDepth( 1 );
    afxDump << "InsertAt example: " << &array << "\n";
#endif

The results from this program are as follows:

InsertAt example: A CObArray with 3 elements
    [0] = a CAge at $45C8 21
    [1] = a CAge at $4646 30
    [2] = a CAge at $4606 40
