CPalette::Operator_HPALETTE

Use this operator to get the attached Windows CE GDI handle of the CPalette object. This casting operator supports direct use of an HPALETTE object.

operator HPALETTE( ) 
const;

Return Value

If the return is successful, a handle to the Windows CE GDI object represented by the CPalette object; otherwise, it is NULL.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxwin.h
