Typed Template Collections

MFC for Windows CE supports all the typed template collection classes the same way the standard MFC library supports them.

For information about the MFC for Windows CE typed template collection classes, see the following topics:

  • CTypedPtrArray
  • CTypedPtrList
  • CTypedPtrMap

For information about where the typed template collection classes fit into the Windows CE class hierarchy, see Classes Not Derived from CObject.
