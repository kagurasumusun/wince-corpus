CStatusBarCtrl::GetRect

This method retrieves the bounding rectangle of a part in a status bar control.

BOOL GetRect( 
int nPane, 
LPRECT lpRect ) 
const;

Parameters

nPane
Specifies the zero-based index of the part whose bounding rectangle is to be retrieved.
lpRect
Specifies the address of a RECT structure that receives the bounding rectangle.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

CRect rectPane1;

VERIFY( GetRect(1, &rectPane1) );

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
