COleDateTimeSpan Operators

Operator Description
operator double Converts this COleDateTimeSpan value to a double.
operator = Copies a COleDateTimeSpan value.
operator +, - Add and subtract COleDateTimeSpan values.
operator +=, -= Add and subtract a COleDateTimeSpan value from this COleDateTimeSpan object.
operator ==, !=, <,>, <=, >= Compares two COleDateTimeSpan values.

Archive and Dump Operators

Operator Description
operator << Outputs a COleDateTimeSpan value to CArchive or CDumpContext.
operator >> Inputs a COleDateTimeSpan object from CArchive.
