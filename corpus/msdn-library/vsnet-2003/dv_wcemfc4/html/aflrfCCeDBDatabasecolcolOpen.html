CCeDBDatabase::Open

This method opens the database and, optionally, specifies which sort order to use.

BOOL Open( 
CEOID CeOID, 
const CCeDBProp* pKeyProp = NULL, 
const CWnd* pWndNotify = NULL);

BOOL Open( 
LPCWSTR szName, 
const CCeDBProp* pKeyProp = NULL, 
const CWnd* pWndNotify = NULL);

Parameters

CeOID
Specifies the object identifier of the database.
szName
Specifies the null-terminated string that contains the name of the database.
pKeyProp
Specifies the pointer to a sort property that represents the primary key for the sort order in which to search the database or list its records. The sort property must be a sort property established for this database in the Create or SetSortProps method. If the sort order is not important, set this parameter to zero.
pWndNotify
Specifies the pointer to the window that should receive notification messages if another thread modifies the database while your application has it open. If your application does not need to receive notifications, set this parameter to NULL.

Return Values

TRUE indicates that the operation succeeded. FALSE indicates that the database could not be opened. To get extended error information, call GetLastError.

Remarks

All seek operations performed on the database use the sort order specified in pKeyProp. To select a different sort order, you must reopen the database. If no sort order is specified, the order in which the records are sorted is undefined.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Wcedb.h
