Microsoft Foundation Class Library for Windows CE  

CRgn::FromHandle

This method obtains a pointer to a CRgn object when you have a handle to a Windows CE region. If a CRgn object is not already attached to the handle, a temporary CRgn object is created and attached. This temporary CRgn object is valid only until the next time the application has idle time in its event loop, at which time all temporary graphic objects are deleted. Another way of saying this is that the temporary object is only valid during the processing of one window message.

static CRgn* PASCAL FromHandle( 
HRGN hRgn );

Parameters

hRgn
Specifies a handle to a Windows region.

Return Value

A pointer to a CRgn object. If the function was not successful, the return value is NULL.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
