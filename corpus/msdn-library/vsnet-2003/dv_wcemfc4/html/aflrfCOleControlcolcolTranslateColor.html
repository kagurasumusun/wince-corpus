COleControl::TranslateColor

This method converts an OLE_COLOR value to a COLORREF value. This function is useful to translate the stock ForeColor and BackColor properties to COLORREF types used by CDC methods.

COLORREF TranslateColor( 
OLE_COLOR clrColor, 
HPALETTE hpal = NULL );

Parameters

clrColor
Specifies an OLE_COLOR data type. For more information, see the Windows CE OleTranslateColor function.
hpal
Specifies a handle to an optional palette; can be NULL.

Return Value

An RGB (red, green, blue) 32-bit color value that defines the solid color closest to the clrColor value that the device can represent.

Remarks

Windows CE only supports the following OLE_COLOR types supported by the Windows-based desktop platforms:

  • 0x00bbggrr
  • 0x800000xx, where xx is the index used by GetSysColor.

MFC for Windows CE does not support the hPal argument. Always pass NULL for this argument.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
