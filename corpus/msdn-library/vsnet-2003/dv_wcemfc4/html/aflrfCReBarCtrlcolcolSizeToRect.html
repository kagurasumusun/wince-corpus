CReBarCtrl::SizeToRect

This method attempts to find the best layout of the bands for the specified rectangle.

This method implements the behavior of the Windows CE message RB_SIZETORECT.

Note that this method uses a CRect object as a parameter, rather than a RECT structure.

BOOL SizeToRect( 
CRect& rect );

Parameters

rect
Specifies a reference to a CRect object that specifies the rectangle that the rebar control should be sized to.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
