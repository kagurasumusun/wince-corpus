CEditView::dwStyleDefault

This data member is a static member that you pass in the dwStyle parameter of the Create method to obtain the default style for the CEditView object.

static AFX_DATA const DWORD dwStyleDefault();

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxext.h
