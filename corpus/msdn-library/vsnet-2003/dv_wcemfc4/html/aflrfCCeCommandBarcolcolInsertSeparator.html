Microsoft Foundation Class Library for Windows CE  

CCeCommandBar::InsertSeparator

This method inserts a separator button on the command bar. 

BOOL InsertSeparator( 
int nWidth = 6, 
int nButton = CMDBAR_END);

Parameters

nWidth
Specifies the width, in pixels, of the separator button.
nButton
Specifies the zero-based index of a button in the command bar.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This method places the separator in the button position indicated by nButton. A separator does not receive user input.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Wcebar.h
