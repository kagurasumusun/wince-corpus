CClientDC::CClientDC

This constructor creates an instance of a CClientDC object that accesses the client area of the CWnd pointed to by pWnd. The constructor calls the Windows CE function GetDC. 

CClientDC( 
CWnd* pWnd );

Parameters

pWnd
Specifies the window whose client area the device context object accesses.

Remarks

An exception of type CResourceException is thrown if the Windows GetDC call fails. A device context may not be available if Windows CE has allocated all of its available device contexts. Your application competes for the five common display contexts available at any given time under Windows CE.

Example

// Get a dc for a CWnd object pointer.
CClientDC dc(pWnd);

// Send my private massage.
::SendMessage(pWnd->m_hWnd, WM_MYMESSAGE, 0, 0);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
