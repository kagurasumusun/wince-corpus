CReBarCtrl::IDToIndex

This method converts a band identifier to a band index in a rebar control.

This method implements the behavior of the Windows CE message RB_IDTOINDEX. 

int IDToIndex( 
UINT uBandID ) 
const;

Parameters

uBandID
Specifies the application-defined identifier of the specified band, passed in the wID member of the REBARBANDINFO structure when the band is inserted.

Return Value

The zero-based band index if successful; otherwise, it is –1. If duplicate band indices exist, the first one is returned.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
