CComboBox::InsertString

This method inserts a string into the list box of a combo box.

int InsertString( 
int nIndex, 
LPCTSTR lpszString );

Parameters

nIndex
Contains the zero-based index to the position in the list box that receives the string. If this parameter is –1, the string is added to the end of the list.
lpszString
Pointer to the null-terminated string that is to be inserted.

Return Value

The zero-based index of the position at which the string was inserted. The return value is CB_ERR if an error occurs. The return value is CB_ERRSPACE if insufficient space is available to store the new string.

Remarks

Unlike the AddString method, the InsertString method does not cause a list with the CBS_SORT style to be sorted.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Insert items between existing items.
CString str;
int n = pmyComboBox->GetCount();
for (int i=0;i < n;i++)
{
   str.Format(_T("item string %c"), (char)('A'+i));
   pmyComboBox->InsertString( 2*i, str );
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
