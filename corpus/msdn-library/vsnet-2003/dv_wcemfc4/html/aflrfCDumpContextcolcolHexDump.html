CDumpContext::HexDump

This method dumps an array of bytes formatted as hexadecimal numbers.

void HexDump( 
LPCTSTR lpszLine, 
BYTE* pby, 
int nBytes, 
int nWidth );

Parameters

lpszLine
Specifies a string to output at the start of a new line.
pby
Specifies a pointer to a buffer containing the bytes to dump.
nBytes
Specifies the number of bytes to dump.
nWidth
Specifies the maximum number of bytes dumped per line; that is, not the width of the output line.

Example

// Example for the CDumpContext::HexDump method.
char test[] = "This is a test of CDumpContext::HexDump\n";
afxDump.HexDump( ".", (BYTE*) test, sizeof test, 20 );

The output from this program is:

    . 54 68 69 73 20 69 73 20 61 20 74 65 73 74 20 6F 66 20 43 44
    . 75 6D 70 43 6F 6E 74 65 78 74 3A 3A 48 65 78 44 75 6D 70 0A
    . 00

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
