Microsoft Foundation Class Library for Windows CE  

CEdit::CEdit

This constructor creates and instance of a CEdit object. Use Create to construct the Windows CE edit control.

CEdit( );

Example

// Declare a local CEdit object.
CEdit myEdit;

// Declare a dynamic CEdit object.
CEdit* pmyEdit = new CEdit;

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
