CWinThread::Run

This method provides a default message loop for user-interface threads. Run acquires and dispatches Windows CE messages until the application receives a WM_QUIT message. This method is rarely overridden.

virtual int Run( );

Return Value

An int value that is returned by the thread. This value can be retrieved by calling GetExitCodeThread.

Remarks

If the message queue in the thread currently contains no messages, Run calls OnIdle to perform idle-time processing. Incoming messages go to the PreTranslateMessage method for special processing and then to the Windows function TranslateMessage for standard keyboard translation. Finally, the DispatchMessage Windows function is called.

This method is used only in user-interface threads.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
