CColorDialog::GetColor

This method returns a COLORREF structure that contains the RGB values for the color selected in the color dialog box. 

COLORREF GetColor( ) 
const;

Return Value

A COLORREF value that contains the RGB information for the color selected in the color dialog box.

Remarks

Call this function after calling DoModal to retrieve the information about the color the user selected.

Example

// Get the selected color from the CColorDialog.
CColorDialog dlg;
if (dlg.DoModal() == IDOK)
{
  COLORREF color = dlg.GetColor();
  TRACE("RGB value of the selected color - red = %u, 
    green = %u, blue = %u\n",
    GetRValue(color), GetGValue(color), GetBValue(color));
}

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxdlgs.h
