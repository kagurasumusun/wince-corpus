CFileDialog::GetFileName

This method retrieves the name of the filename entered in the dialog box. The name of the file includes both the prefix and the extension. For example, GetFileName will return TEXT.DAT for the file \My Documents\Text.dat.

CString GetFileName( ) 
const;

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxdlgs.h
