Microsoft Foundation Class Library for Windows CE  

CCommandLineInfo

This class aids in parsing the command line when an application starts.

An MFC application typically creates a local instance of this class in the InitInstance function of its application object. This object is then passed to CWinApp::ParseCommandLine, which repeatedly calls ParseParam to fill the CCommandLineInfo object. The CCommandLineInfo object is then passed to CWinApp::ProcessShellCommand to handle the command-line arguments and flags.

You can use this object to encapsulate the following command-line options and parameters:

Command-line argument Command executed
app New file
app filename Open file
app /p filename Print file to default printer
app /pt filename printer driver port Print file to specified printer
app /dde Start up and wait for DDE command
app /Automation Start up as an OLE automation server
app /Embedding Start up to edit an embedded OLE item

Derive a new class from CCommandLineInfo to handle other flags and parameter values. Override ParseParam to handle the new flags.

Remarks

MFC for Windows CE supports the CCommandLineInfo::ParseParam method differently than the standard MFC library does.

MFC for Windows CE does not support the following data members in the CCommandLineInfo class:

  • m_bRunAutomated
  • m_bRunEmbedded
  • m_strDriverName
  • m_strPortName
  • m_strPrinterName

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
