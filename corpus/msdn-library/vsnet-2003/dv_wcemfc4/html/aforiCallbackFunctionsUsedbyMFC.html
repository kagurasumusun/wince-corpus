Callback Functions Used by MFC

One callback function appears in the MFC for Windows CE Library. A description of callback functions that are passed to,CDC::SetAbortProc follows this topic. For the general usage of the callback functions, see the Remarks section of these member functions. Note that all callback functions must trap MFC exceptions before returning to Windows CE, since exceptions cannot be thrown across callback boundaries.
