Microsoft Foundation Class Library for Windows CE  

CHttpFile::Close

This method closes a CHttpFile and frees its resources. Use this method only after a successful call to SendRequest or on a CHttpFile object successfully created by OpenURL.

virtual void Close( );

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxinet.h
