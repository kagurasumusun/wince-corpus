CObject::operator delete

For the Release version of the library, this operator simply frees the memory allocated by operator new. In the Debug version, operator delete participates in an allocation-monitoring scheme designed to detect memory leaks. If you override operators new and delete, you forfeit the diagnostic capability.

void PASCAL operator delete( 
void* p );

void PASCAL operator delete( 
void* p, 
void* pPlace );

void PASCAL operator delete( 
void* p, 
LPCSTR lpszFileName, 
int nLine );

Parameters

p
Pointer to the block of allocated memory.
pPlace
Pointer to location of the allocated memory.
lpszFileName
Long pointer to a string that is the path to the desired file.
nLine
Specifies the number of lines to allocate in the memory.

Example

See CObList::CObList for a listing of the CAge class used in the CObject examples.

void CAge::operator delete(void* p)
{
  free(p);
}

void CAge::operator delete(void *p, LPCSTR lpszFileName, int nLine)
{
  free(p);
}

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afx.h
