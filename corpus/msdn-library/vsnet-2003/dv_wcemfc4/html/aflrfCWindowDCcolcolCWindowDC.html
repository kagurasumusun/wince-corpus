CWindowDC::CWindowDC

This constructor creates and instance of a CWindowDC object that accesses the entire screen area, both client and nonclient, of the CWnd object pointed to by pWnd. The constructor calls the Windows CE GetDC function.

An exception, of type CResourceException, is thrown if the Windows CE GetWindowDC call fails. A device context may not be available if Windows has already allocated all of its available device contexts. Your application competes for the five common display contexts available at any given time under Windows CE.

CWindowDC( 
CWnd* pWnd );

Parameters

pWnd
Specifies the window whose client area the device-context object will access.

Example

// Get a dc for a CWnd object pointer.
CWindowDC dc(pWnd);

// Send my private massage.
::SendMessage(pWnd->m_hWnd, WM_MYMESSAGE, 0, 0);

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
