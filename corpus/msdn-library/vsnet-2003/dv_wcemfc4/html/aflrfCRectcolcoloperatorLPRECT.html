CRect::operator LPRECT

This operator converts a CRect object to an LPRECT. When you use this method, you do not need the address-of a (&) operator. This operator will be automatically used when you pass a CRect object to a method that expects an LPRECT.

operator LPRECT( );

Example

void CYourView::OnInitialUpdate()
{
   // CWnd::GetWindowRect() takes a LPRECT, but we can
   // simply pass the CRect object because of the LPRECT
   // cast operator in the CRect class.

   CRect rect;
   GetWindowRect(rect);

   // Similarly, CWnd::MoveWindow() takes a LPCRECT but
   // the LPCRECT cast operator is used implicitly:

   MoveWindow(rect, FALSE);

   // ... more code here ...
}

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
