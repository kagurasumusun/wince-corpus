CCtrlView::CCtrlView

This constructor creates an instance of a CCtrlView object. The framework calls the constructor when a new frame window is created or a window is split. 

CCtrlView( 
LPCTSTR lpszClass, 
DWORD dwStyle );

Parameters

lpszClass
The Windows CE class name of the view class.
dwStyle
The style of the view class.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxext.h
