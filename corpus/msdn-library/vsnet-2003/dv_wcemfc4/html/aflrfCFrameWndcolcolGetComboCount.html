Microsoft Foundation Class Library for Windows CE  

CFrameWnd::GetComboCount

This method retrieves the number of items in the list box part of a combo box on the command bar.

int GetComboCount ( );

Return Value

Returns the number of items in the list box of the combo box. The number returned is one greater than the index value of the last item in the list box, the index is zero-based. This method returns CB_ERR if an error occurs.

Remarks

This method of the CFrameWnd class is unique to Windows CE.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
