CRecentFileList::CRecentFileList

This constructor creates an instance of an CRecentFileList class object.

The format string pointed to by lpszEntryFormat should contain %d, which will be used for substituting the index of each MRU item. For example, if the format string is file%d then the entries will be named file0, file1, and so on.

CRecentFileList( 
UINT nStart, 
LPCTSTR lpszSection, 
LPCTSTR lpszEntryFormat, 
int nSize, 
int nMaxDispLen = AFX_ABBREV_FILENAME_LEN );

Parameters

nStart
Specifies the offset for the numbering in the menu display of the MRU file list.
lpszSection
Points to the name of the section of the registry or the .ini file of the application where the MRU file list is read and written.
lpszEntryFormat
Points to a format string to be used for the names of the entries stored in the registry or the .ini file of the application.
nSize
Specifies the maximum number of files in the MRU file list.
nMaxDispLen
Specifies the maximum length, in characters, available for the menu display of a filename in the MRU file list.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxadv.h
