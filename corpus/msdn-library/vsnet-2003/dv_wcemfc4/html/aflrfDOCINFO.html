Microsoft Foundation Class Library for Windows CE  

DOCINFO

This structure contains the information necessary for printing documents.

typedef struct { 
 int cbSize; 
 LPCTSTR lpszDocName; 
 LPCTSTR lpszOutput; 
 LPCTSTR lpszDatatype; 
 DWORD fwType;
} DOCINFO;

Members

cbSize
Specifies the structure size, in bytes.
lpszDocName
Long pointer to a null-terminated string that specifies the name of the document.
lpszOutput
Long pointer to a null-terminated string that specifies the name of an output file. If this pointer is NULL, the output will be sent to the device identified by the device context handle that was passed to the StartDoc function.
lpszDatatype
Unsupported; set to zero.
fwType
Unsupported; set to zero.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Wingdi.h
