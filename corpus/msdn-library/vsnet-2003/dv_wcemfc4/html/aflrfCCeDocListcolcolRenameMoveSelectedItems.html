CCeDocList::RenameMoveSelectedItems

This method displays the Rename/Move dialog box for selected items.

BOOL RenameMoveSelectedItems();

Return Value

TRUE or nonzero indicates success; FALSE or zero indicates failure.

Requirements

Windows CE versions: 3.0 and later
