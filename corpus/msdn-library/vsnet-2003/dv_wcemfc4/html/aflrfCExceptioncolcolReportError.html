CException::ReportError

This method reports error text in a message box to the user.

virtual int ReportError( 
UINT nType = MB_OK, 
UINT nMessageID = 0 );

Parameters

nType
Specifies the style of the message box. Apply any combination of the message-box styles to the box. If you do not specify this parameter, the default is MB_OK.
nMessageID
Specifies the resource identifier, string table entry, of a message to display if the exception object does not have an error message. If zero, the message, No error message is available, is displayed.

Return Value

An AfxMessageBox value; otherwise, zero if there is not enough memory to display the message box. See AfxMessageBox for the possible return values.

Example

CFile fileInput;
CFileException ex;

// Try to open a file for reading.
// The file will absolutely not
// exist because there are too many explicit
// directories in the name.

// If the call to Open() fails, ex will be
// initialized with exception
// information. The call to ex.ReportError() will
// display an appropriate
// error message to the user, such as
// "\Too\Many\Bad\Dirs.DAT contains an
// invalid path." The error message text is
// appropriate for the
// file name and error condition.

if (!fileInput.Open(_T("\\Too\\Many\\Bad\\Dirs.DAT"), CFile::modeRead, &ex))
{
  ex.ReportError();
}
else
{
  // The file was opened, so perform whatever work
  // with fileInput which we were planning.
  // :
  fileInput.Close();
}
