CPropExchange::ExchangeBlobProp

This method serializes a property that stores binary large object (BLOB) data. The CArchivePropExchange::ExchangeBlobProp, CResetPropExchange::ExchangeBlobProp, and CPropsetPropExchange::ExchangeBlobProp methods override this pure virtual method.

The value of the property is read from or written to, as appropriate, the variable referenced by phBlob. If hBlobDefault is specified, it will be used as the default value of the property. This value is used if the serialization of the control fails for any reason.

virtual BOOL ExchangeBlobProp( 
LPCTSTR pszPropName
HGLOBAL* phBlob
HGLOBAL hBlobDefault = NULL ) = 0;

Parameters

pszPropName
Specifies the name of the property being exchanged.
phBlob
[out]Specifies a pointer to the BLOB that is retrieved.
hBlobDefault
Specifies the default value for the property.

Return Value

Nonzero if the exchange was successful; zero if it is unsuccessful.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
