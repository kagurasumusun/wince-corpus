CAsyncSocket::OnAccept

This method is called by the framework to notify a listening socket that it can accept pending connection requests.

virtual void OnAccept ( 
int nErrorCode );

Parameters

nErrorCode
The most recent error on a socket. The following error codes apply to the OnAccept method:
  • 0   The function executed successfully.
  • WSAENETDOWN   The Windows CE Sockets implementation detected that the network subsystem failed.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Afxsock.h
