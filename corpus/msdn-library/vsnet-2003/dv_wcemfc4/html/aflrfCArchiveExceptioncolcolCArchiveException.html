CArchiveException::CArchiveException

This constructor instantiates a CArchiveException object and stores the value of cause in the object.

CArchiveException( 
int cause = CArchiveException::none,
LPCTSTR lpszArchiveName = NULL );

Parameters

cause
An enumerated type variable that indicates the reason for the exception. For a list of the enumerators, see the CArchiveException::m_cause data member.
lpszArchiveName
Points to a string containing the name of the CArchive object that caused the exception, if available.

Remarks

You can create a CArchiveException object on the heap and throw it yourself, or let the global function AfxThrowArchiveException handle it.

Do not use this constructor directly; instead, call the global function AfxThrowArchiveException.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
