CReBarCtrl::SetBandInfo

This method sets the characteristics of an existing band in a rebar control.

This method implements the behavior of the Windows CE message RB_SETBANDINFO. 

BOOL SetBandInfo( 
UINT uBand, 
REBARBANDINFO* prbbi );

Parameters

uBand
Specifies the zero-based index of the band to receive the new settings.
prbbi
Specifies a pointer to a REBARBANDINFO structure that defines the band to be inserted. You must set the cbSize member of this structure to sizeof(REBARBANDINFO) before sending this message.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

int nCount = m_wndReBar.GetReBarCtrl().GetBandCount();
CString strText = "Band #:";

for (int i=0; i<nCount; i++)
{
  LPREBARBANDINFO prbbi = 
    (LPREBARBANDINFO)alloca(sizeof(REBARBANDINFO));
  prbbi->cbSize = sizeof(REBARBANDINFO);
  CString strText;
  strText.Format(_T("Band #: %d"), i);
  LPTSTR lpszText = strText.GetBuffer(strText.GetLength());
  prbbi->lpText = lpszText;
  prbbi->cch = lstrlen(lpszText) + 1;
  prbbi->fMask = RBBIM_TEXT;

  m_wndReBar.GetReBarCtrl().SetBandInfo(i, prbbi);

  strText.ReleaseBuffer();
}

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
