Microsoft Foundation Class Library for Windows CE  

Synchronization Classes

MFC for Windows CE supports synchronization classes in the same way as desktop MFC, except that waiting for a process or thread is not supported by CEvent::SetEvent and CEvent::ResetEvent.

For information about the MFC for Windows CE synchronization classes, see the following topics:

  • CCriticalSection
  • CEvent
  • CMutex
  • CSyncObject

For information about where these synchronization classes fit into the Windows CE class hierarchy, see Classes Derived from CObject.
