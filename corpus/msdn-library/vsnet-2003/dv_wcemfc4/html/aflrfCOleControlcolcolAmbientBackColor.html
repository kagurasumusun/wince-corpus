Microsoft Foundation Class Library for Windows CE  

COleControl::AmbientBackColor

This method retrieves the value of the ambient BackColor property. The ambient BackColor property is available to all controls and is defined by the container. The container is not required to support this property.

OLE_COLOR AmbientBackColor( );

Return Value

The current value of the ambient BackColor property of the container, if any. If the property is not supported, this method returns the system-defined Windows CE background color.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
