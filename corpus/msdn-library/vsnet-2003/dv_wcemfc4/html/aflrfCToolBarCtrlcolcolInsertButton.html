CToolBarCtrl::InsertButton

This method inserts a button in a toolbar control.

The image and/or string whose index you provide must have previously been added to the toolbar control list using AddBitmap, AddString, and/or AddStrings.

BOOL InsertButton( 
int nIndex, 
LPTBBUTTON lpButton );

Parameters

nIndex
Specifies the zero-based index of a button. This function inserts the new button to the left of this button.
lpButton
Specifies the address of a TBBUTTON structure containing information about the button to insert. See CToolBarCtrl::AddButtons for a description of the TBBUTTON structure.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
