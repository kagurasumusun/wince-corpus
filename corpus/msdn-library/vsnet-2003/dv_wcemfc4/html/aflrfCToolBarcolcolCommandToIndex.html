CToolBar::CommandToIndex

This method returns the index of the first toolbar button, starting at position 0, with a command identifier that matches nIDFind.

int CommandToIndex( 
UINT nIDFind );

Parameters

nIDFind
Specifies the command ID of a toolbar button.

Return Value

The index of the button, or –1 if no button has the given command ID.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
