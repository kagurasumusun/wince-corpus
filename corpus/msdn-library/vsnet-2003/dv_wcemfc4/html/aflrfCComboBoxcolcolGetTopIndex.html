CComboBox::GetTopIndex

This method retrieves the zero-based index of the first visible item in the list box portion of the combo box.

int GetTopIndex( ) 
const;

Return Value

The zero-based index of the first visible item in the list box portion of the combo box if successful, CB_ERR otherwise.

Remarks

Initially, item zero is at the top of the list box, but if the list box is scrolled, another item may be at the top.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Make an item in the bottom half to be the first visible item.
int n = pmyComboBox->GetCount()/2;
if (pmyComboBox->GetTopIndex() < n)
{
  pmyComboBox->SetTopIndex(n);
  ASSERT(pmyComboBox->GetTopIndex() == n);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
