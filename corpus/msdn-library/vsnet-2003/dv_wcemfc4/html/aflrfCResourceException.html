Microsoft Foundation Class Library for Windows CE  

CResourceException

A CResourceException object is generated when Windows CE cannot find or allocate a requested resource. No further qualification is necessary or possible.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
