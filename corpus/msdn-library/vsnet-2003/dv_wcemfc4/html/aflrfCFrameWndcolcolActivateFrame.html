CFrameWnd::ActivateFrame

This method activates and restores the frame window so that it is visible and available to the user. The CFrameWnd::ActivateFrame method is usually called after a non-user interface event such as a DDE, OLE, or other event that may show the frame window or its contents to the user.

virtual void ActivateFrame( 
int nCmdShow = – 1);

Parameters

nCmdShow
Specifies the parameter to pass to CWnd::ShowWindow. By default, the frame is shown and correctly restored.

Remarks

The default implementation activates the frame and brings it to the top of the Z-order and, if necessary, carries out the same steps in the main frame window of the application.

Override this method to change how a frame is activated. For example, you can force MDI child windows to be maximized. Add the appropriate functionality, then call the base class version with an explicit nCmdShow.

Example

void CChildFrame::ActivateFrame(int nCmdShow) 
{
  // Create the child frame window as maximized.
  nCmdShow = SW_MAXIMIZE;
  
  CMDIChildWnd::ActivateFrame(nCmdShow);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
