Microsoft Foundation Class Library for Windows CE  

CFileDialog::GetPathName

This method retrieves the full path of the file entered in the dialog box. The path of the file name includes the title of the file plus the entire directory path. For example, GetPathName will return \My Documents\Text.dat for the file \My Documents\Text.dat.

CString GetPathName( ) 
const;

Return Value

The full path of the file is returned.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxdlgs.h

See Also

CFileDialog::GetFileName, CFileDialog::GetFileExt, CFileDialog::GetFileTitle
