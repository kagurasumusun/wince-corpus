CObList::FindIndex

This method conducts a sequential scan from the head of the list, stopping on the nIndexth element.

POSITION FindIndex( 
int nIndex ) 
const;

Parameters

nIndex
Specifies the zero-based index of the list element to be found.

Return Value

A POSITION value that can be used for iteration or object pointer retrieval; it is NULL if nIndex is too large. The framework generates an assertion if nIndex is negative.

Example

See CObList::CObList for a listing of the CAge class.

CObList list;
POSITION pos;

list.AddHead( new CAge( 21 ) );
list.AddHead( new CAge( 40 ) ); // List now contains (40, 21).
if( ( pos = list.FindIndex( 0 )) != NULL )
{
    ASSERT( *(CAge*) list.GetAt( pos ) == CAge( 40 ) );
}
