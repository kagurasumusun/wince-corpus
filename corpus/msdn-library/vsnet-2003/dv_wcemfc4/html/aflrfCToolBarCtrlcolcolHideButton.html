CToolBarCtrl::HideButton

This method hides or shows the specified button in a toolbar control. To change more than one button state, consider calling SetState instead.

BOOL HideButton( 
int nID, 
BOOL bHide = TRUE );

Parameters

nID
Specifies the command identifier of the button to hide or show.
bHide
TRUE to hide the button, FALSE to show it.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
