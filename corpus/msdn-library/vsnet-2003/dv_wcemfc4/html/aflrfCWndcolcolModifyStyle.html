CWnd::ModifyStyle

This method modifies a window style. Styles to be added or removed can be combined by using the bitwise OR (|) operator. For more information about the available window styles, see CreateWindow.

BOOL ModifyStyle( 
DWORD dwRemove, 
DWORD dwAdd, 
UINT nFlags = 0 );

Parameters

dwRemove
Specifies window styles to be removed during style modification.
dwAdd
Specifies window styles to be added during style modification.
nFlags
Flags to be passed to SetWindowPos, or zero if SetWindowPos should not be called. The default is zero. See the Remarks section for a list of preset flags.

Return Value

Nonzero if style was successfully modified; otherwise, it is zero.

Remarks

If nFlags is nonzero, ModifyStyle calls the Windows CE API function SetWindowPos and redraws the window by combining nFlags with the following four preset flags:

  • SWP_NOSIZE   Retains the current size.
  • SWP_NOMOVE   Retains the current position.
  • SWP_NOZORDER   Retains the current Z order.
  • SWP_NOACTIVATE   Does not activate the window.

To modify a window extended styles, see ModifyStyleEx.

Example

// This example adds the WS_CLIPCHILDREN style to the window.
// No Styles are removed from the window.

void CMyView::OnInitialUpdate()
{
  CView::OnInitialUpdate();
  ModifyStyle(0, WS_CLIPCHILDREN);
}

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
