CCmdUI::SetRadio

This method sets the user-interface item for this command to the appropriate check state.

virtual void SetRadio( 
BOOL bOn = TRUE );

Parameters

bOn
Specifies TRUE to enable the item; otherwise, it is FALSE.

Remarks

Th CCmdUI::SetRadio method operates like SetCheck, except that it operates on user-interface items acting as part of a radio group. Clearing other items in the group is not automatic, unless the items maintain the radio-group behavior.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
