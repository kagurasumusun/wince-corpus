CMonthCalCtrl::GetMonthDelta

This method retrieves the, scroll rate, for a month calendar control. The scroll rate is the number of months that the control moves its display when the user clicks a scroll button.

This method implements the behavior of the Windows CE message MCM_GETMONTHDELTA. 

int GetMonthDelta( ) 
const;

Return Value

The scroll rate for the month calendar control. The scroll rate is the number of months that the control moves its display when the user clicks a scroll button once.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxdtctl.h
