CList::InsertAfter

This method adds an element to this list after the element at the specified position.

POSITION InsertAfter( 
POSITION position, 
ARG_TYPE newElement );

Parameters

position
Specifies a POSITION value returned by a previous GetNext, GetPrev, or Find method call.
ARG_TYPE
Specifies the template parameter specifying the type of the list element.
newElement
Specifies the element to be added to this list.

Return Value

A POSITION value that can be used for iteration or list element retrieval is returned.

Example

// Define myList.
CList<CString,CString&> myList;

// Add three elements to the list.
POSITION pos = myList.AddHead(CString("XYZ"));
pos = myList.InsertAfter(pos, CString("ABC"));
pos = myList.InsertAfter(pos, CString("123"));

// Verify the tail element is the one expected.
ASSERT(CString("123") == myList.GetTail());

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
