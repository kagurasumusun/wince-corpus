Microsoft Foundation Class Library for Windows CE  

COleDateTime::m_dt

This data member contains the underlying DATE structure for this COleDateTime object.

Caution   Changing the value in the DATE object accessed by the pointer returned by this function will change the value of this COleDateTime object. It does not change the status of this COleDateTime object.
DATE m_dt;

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
