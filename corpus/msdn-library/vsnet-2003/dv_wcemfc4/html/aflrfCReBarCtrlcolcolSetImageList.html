CReBarCtrl::SetImageList

This method assigns an image list to a rebar control.

BOOL SetImageList( 
CImageList* pImageList );

Parameters

pImageList
Specifies a pointer to a CImageList object containing the image list to be assigned to the rebar control.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
