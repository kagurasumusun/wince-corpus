CToolBarCtrl::CommandToIndex

This method retrieves the zero-based index for the button associated with the specified command identifier.

UINT CommandToIndex( 
UINT nID ) 
const;

Parameters

nID
Command ID whose button index you want to find.

Return Value

The zero-based index for the button associated with the command ID.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
