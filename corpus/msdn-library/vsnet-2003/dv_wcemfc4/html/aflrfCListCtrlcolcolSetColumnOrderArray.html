CListCtrl::SetColumnOrderArray

This method sets the left-to-right order of columns in a list view control.

The SetColumnOrderArray method implements the behavior of the Windows CE macro ListView_SetColumnOrderArray. You can use this macro or send the LVM_SETCOLUMNORDERARRAY message explicitly.

BOOL SetColumnOrderArray( 
int iCount, 
LPINT piArray );

Parameters

piArray
A pointer to a buffer containing the index values of the columns in the list view control, from left to right. The buffer must be large enough to contain the total number of columns in the list view control.
iCount
Number of columns in the list view control.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
