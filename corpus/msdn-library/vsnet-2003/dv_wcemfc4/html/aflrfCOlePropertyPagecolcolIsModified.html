COlePropertyPage::IsModified

This method determines whether the user has changed any values on the property page.

BOOL IsModified( );

Return Value

TRUE if the property page has been modified.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
