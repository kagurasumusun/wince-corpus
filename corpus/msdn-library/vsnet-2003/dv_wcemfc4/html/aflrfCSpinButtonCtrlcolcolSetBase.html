CSpinButtonCtrl::SetBase

This method sets the base for a spin button control. The base value determines whether the buddy window displays numbers in decimal or hexadecimal digits. Hexadecimal numbers are always unsigned; decimal numbers are signed.

int SetBase( 
int nBase );

Parameters

nBase
Specifies the new base value for the control. It can be 10 for decimal or 16 for hexadecimal.

Return Value

The previous base value if successful, or zero if an invalid base is given.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
