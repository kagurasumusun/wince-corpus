CTabCtrl::SetItemState

This method sets the state of the tab control item identified by nItem. 

BOOL SetItemState( 
int nItem, 
DWORD dwMask, 
DWORD dwState );

Parameters

nItem
Specifies the zero-based index number of the item for which to set state information.
dwMask
Specifies the mask specifying which state flags of the item to set. For a list of values, see the mask member of the TCITEM structure.
dwState
Specifies a reference to a DWORD value containing the state information. It can be one of the following values:
Value Description
TCIS_BUTTONPRESSED The tab control item is selected.
TCIS_HIGHLIGHTED The tab control item is highlighted, and the tab and text are drawn using the current highlight color. When using highlight color, this will be a true interpolation, not a dithered color.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
