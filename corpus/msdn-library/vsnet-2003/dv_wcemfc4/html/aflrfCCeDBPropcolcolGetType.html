CCeDBProp::GetType

This method retrieves the data type of a property.

CCeDBProp::enType GetType( ) 
const;

Return Values

The data type of the property. It is one of the values shown in the following table.

Value Description
CCeDBProp::Type_Short A signed short integer
CCeDBProp::Type_Ushort An unsigned short integer
CCeDBProp::Type_Long A signed long integer
CCeDBProp::Type_Ulong A unsigned long integer
CCeDBProp::Type_Filetime A FILETIME structure
CCeDBProp::Type_String A null-terminated wide (Unicode) character string, not a CString
CCeDBProp::Type_Blob A CEBLOB structure

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Wcedb.h

See Also

CCeDBProp::SetType, CEBLOB, FILETIME
