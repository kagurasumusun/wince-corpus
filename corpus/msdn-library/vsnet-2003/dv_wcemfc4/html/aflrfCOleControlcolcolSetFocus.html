COleControl::SetFocus

This method causes the container window of the control to take possession of the input focus on behalf of the control. The input focus directs keyboard input to the container window, and the container dispatches all subsequent keyboard messages to the OLE object that calls SetFocus. Any window that previously had the input focus loses it.

If the control is not windowless, this method causes the control itself to take possession of the input focus, the same as CWnd::SetFocus.

CWnd* SetFocus( );

Return Value

A pointer to the CWnd window object that previously had the input focus, or NULL if there is no such window.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
