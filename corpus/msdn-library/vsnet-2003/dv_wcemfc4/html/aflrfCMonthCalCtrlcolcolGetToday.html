CMonthCalCtrl::GetToday

This method retrieves the date information for the date specified as today for a month calendar control.

This method implements the behavior of the Windows CE message MCM_GETTODAY.

In the MFC for Windows CE implementation of GetToday, you can specify a COleDateTime usage, a CTime usage, or a SYSTEMTIME structure usage.

BOOL GetToday( 
CTime& refTime ) 
const; 

BOOL GetToday( 
COleDateTime& refDateTime ) 
const; 

BOOL GetToday( 
LPSYSTEMTIME pDateTime ) 
const;

Parameters

refDateTime
Specifies a reference to a COleDateTime or CTime object indicating the current day.
pDateTime
Specifies a pointer to a SYSTEMTIME structure that will receive the date information. This parameter must be a valid address and cannot be NULL.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

void CDatesDlg::OnButton1() 
{
  // Gain a pointer to the control.
  CMonthCalCtrl* pCtrl = (CMonthCalCtrl*) GetDlgItem(IDC_MONTHCALENDAR1);

  COleDateTime timeToday;
  if (pCtrl->GetToday(timeToday))
  {
    // Format the date information from the value we received
    // and post a message box about it.
    CString str = timeToday.Format(VAR_DATEVALUEONLY);
    AfxMessageBox(str);

    // Set the control's "today" indicator to be five
    // days previous.
    timeToday -= 5;
    pCtrl->SetToday(timeToday);
  }
  else
  {
    // Something is wrong!
    ASSERT(FALSE);
  }
}

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxdtctl.h
