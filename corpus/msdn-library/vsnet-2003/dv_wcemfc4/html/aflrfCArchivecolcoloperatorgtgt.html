CArchive::operator >>

This operator loads the indicated object or primitive type from the archive.

Return Value

A CArchive reference that enables multiple insertion operators on a single line.

Remarks

The last two versions above are specifically for loading 64-bit integers.

If you use the IMPLEMENT_SERIAL macro in your class implementation, the extraction operators overloaded for CObject call the protected ReadObject function, with a nonzero run-time class pointer. This function, in turn, calls the Serialize function of the class.

Example

int i;
extern CArchive ar;
if( ar.IsLoading() )
  ar >> i;

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
