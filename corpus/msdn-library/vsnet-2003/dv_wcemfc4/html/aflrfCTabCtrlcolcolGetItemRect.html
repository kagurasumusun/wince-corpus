CTabCtrl::GetItemRect

This method retrieves the bounding rectangle for the specified tab in a tab control.

BOOL GetItemRect( 
int nItem, 
LPRECT lpRect ) 
const;

Parameters

nItem
Specifies the zero-based index of the tab item.
lpRect
Specifies the pointer to a RECT structure that receives the bounding rectangle of the tab. These coordinates use the current mapping mode of the viewport.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

See the example for CPropertySheet::GetTabControl.

Requirements

  Windows CE versions: 1.0 and later
