CFindReplaceDialog::MatchWholeWord

This method determines whether the user wants to match entire words only.

BOOL MatchWholeWord( ) 
const;

Return Value

Nonzero if the user wants to match only the entire words of the search string; otherwise, it is zero.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxdlgs.h
