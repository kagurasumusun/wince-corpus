CToolBar::GetButtonStyle

This method retrieves the style of a button or separator on the toolbar. The style of a button determines how the button appears and how it responds to user input.

UINT GetButtonStyle( 
int nIndex ) 
const;

Parameters

nIndex
Specifies the index of the toolbar button or separator style to be retrieved.

Return Value

The style of the button or separator specified by nIndex.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
