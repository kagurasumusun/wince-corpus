CFindReplaceDialog::ReplaceAll

This method determines whether the user wants all occurrences of the string to be replaced.

BOOL ReplaceAll( ) 
const;

Return Value

Nonzero if the user has requested that all strings matching the replace string be replaced; otherwise, it is zero.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxdlgs.h
