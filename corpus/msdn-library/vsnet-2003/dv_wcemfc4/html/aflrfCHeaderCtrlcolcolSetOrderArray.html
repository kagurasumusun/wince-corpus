CHeaderCtrl::SetOrderArray

This method implements the behavior of the Win32 macro HDM_SETORDERARRAY, as described in the Platform SDK. It is provided to support header item ordering.

BOOL SetOrderArray( 
int iCount, 
LPINT piArray );

Parameters

iCount
The number of header control items.
piArray
A pointer to the address of a buffer that receives the index values of the items in the header control, in the order in which they appear from left to right.

Return Value

Nonzero if successful; otherwise, it is zero.

Example

See the example for CHeaderCtrl::GetOrderArray.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
