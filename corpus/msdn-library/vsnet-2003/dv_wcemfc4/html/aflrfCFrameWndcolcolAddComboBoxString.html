CFrameWnd::AddComboBoxString

This method adds a string to a combo box on the command bar, and associates it with a data element. This method adds the string at the end of the list of strings in the list box of the combo box.

BOOL AddComboBoxString ( 
UINT uiStringResourceID, 
long lItemData = 0);

BOOL AddComboBoxString ( 
LPCTSTR szString, 
long lItemData = 0);

Parameters

uiStringResourceID
Specifies the resource identifier of a resource that contains the null-terminated string to be added to the combo box.
szString
Specifies a pointer to the null-terminated string to be added to the combo box.
lItemData
Specifies a new value to be associated with the item. You can use this parameter to pass a pointer to a data structure that contains additional information about the selection.

Return Value

Nonzero indicates success. Zero indicates failure.

Remarks

Use the CB_GETITEMDATA message to retrieve the data you pass to this method in the lItemData parameter.

This method of the CFrameWnd class is unique to Windows CE.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
