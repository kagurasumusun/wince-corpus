CTime::GetAsSystemTime

This method converts the time information stored in the CTime object to a Windows CE–compatible SYSTEMTIME structure. GetAsSystemTime stores the resulting time in the referenced timeDest object. The SYSTEMTIME data structure initialized by this function will have its wMilliseconds member set to zero.

BOOL GetAsSystemTime( 
SYSTEMTIME& timeDest ) 
const;

Parameters

timeDest
Specifies a reference to a SYSTEMTIME structure to be converted to a date/time value and copied into the new CTime object.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// Convert CTime to FILETIME
CTime time(CTime::GetCurrentTime());
SYSTEMTIME timeDest;
time.GetAsSystemTime(timeDest);
FILETIME fileTime;
::SystemTimeToFileTime(&timeDest, &fileTime);

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
