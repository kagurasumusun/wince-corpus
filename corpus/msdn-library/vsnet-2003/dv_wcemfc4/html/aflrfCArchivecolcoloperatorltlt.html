CArchive::operator <<

This operator stores the indicated object or primitive type to the archive.

friend CArchive& AFXAPI operator <<( 
CArchive& ar, 
const CObject* pOb );

CArchive& operator <<( 
unsigned u )

Return Value

A CArchive reference that enables multiple extraction operators on a single line.

Remarks

The last two versions above are specifically for storing 64-bit integers.

If you use the IMPLEMENT_SERIAL macro in your class implementation, the insertion operator overloaded for CObject calls the protected WriteObject. This function, in turn, calls the Serialize function of the class.

Example

long l;
int i;
extern CArchive ar;
if( ar.IsStoring() )
  ar << l << i;

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
