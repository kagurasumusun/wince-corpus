CListBox::GetSel

This method retrieves the selection state of an item. This method works with both single- and multiple-selection list boxes.

int GetSel( 
int nIndex ) 
const;

Parameters

nIndex
Specifies the zero-based index of the item.

Return Value

A positive number if the specified item is selected; otherwise, it is zero. The return value is LB_ERR if an error occurs.

Example

// Pointer to the myListBox.
extern CListBox* pmyListBox;

// Dump all of the items select state.
#ifdef _DEBUG
  CString str;
  for (int i=0;i < pmyListBox->GetCount();i++)
  {
    str.Format(_T("item %d: select state is %s\r\n"),
    i,
    pmyListBox->GetSel( i ) > 0 ? _T("true") : _T("false"));
    afxDump << str;
  }
#endif

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
