CWinApp::LoadOEMIcon

This method loads the Windows CE predefined icon resource specified by nIDIcon.

Use the LoadOEMIcon or LoadStandardIcon method to access the predefined Windows CE icons.

HICON LoadOEMIcon( 
UINT nIDIcon ) 
const;

Parameters

nIDIcon
Specifies an OIC_ manifest constant identifier that specifies a predefined Windows CE icon. You must have #define OEMRESOURCE before #include <afxwin.h> to access the OIC_ constants in Windows.h.

Return Value

A handle to an icon if it is successful; otherwise, it is NULL.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h

See Also

CWinApp::LoadStandardIcon, CWinApp::LoadIcon
