CWinThread::m_pActiveWnd

This data member contains a pointer to a CWnd object. Use this data member to store a pointer to the active window object of your thread.

The MFC for Windows CE will automatically terminate your thread when the window referred to by m_pActiveWnd is closed. If this thread is the primary thread for an application, the application will also be terminated. If this data member is NULL, the active window for the CWinApp object of the application will be inherited. m_pActiveWnd is a public variable of type CWnd*.

Typically, you set this member variable when you override InitInstance. In a worker thread, the value of this data member is inherited from its parent thread.

CWnd* m_pActiveWnd;

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
