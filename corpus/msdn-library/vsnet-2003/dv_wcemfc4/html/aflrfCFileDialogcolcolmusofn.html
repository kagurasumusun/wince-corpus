CFileDialog::m_ofn

This data member is an OPENFILENAME structure. Use this structure to initialize the appearance of a File Open or File Save As dialog box after it is constructed but before it is displayed with the DoModal method. For example, you can set the lpstrTitle member of m_ofn to the caption you want the dialog box to have.

OPENFILENAME m_ofn;

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxdlgs.h
