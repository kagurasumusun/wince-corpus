CTypedPtrList::AddHead

This method adds elements to the head of the list. The first implementation adds a new element before the head of the list. The second implementation adds another list of elements before the head.

POSITION AddHead( 
TYPE newElement );

void AddHead( 
CTypedPtrList< BASE_CLASS, TYPE >*
pNewList ); 

POSITION AddTail( 
TYPE newElement );

Parameters

TYPE
Specifies the type of the elements stored in the base-class list.
newElement
Specifies the object pointer to be added to this list. A NULL value is allowed.
BASE_CLASS
Specifies the base class of the typed pointer list class; must be a pointer list class (CObList or CPtrList).
pNewList
Specifies a pointer to another CTypedPtrList object. The elements in pNewList will be added to this list.

Return Value

The first version returns the POSITION value of the newly inserted element.

Requirements

  Windows CE versions: 1.0 and later
