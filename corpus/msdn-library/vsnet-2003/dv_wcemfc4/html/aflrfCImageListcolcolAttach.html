CImageList::Attach

This method attaches an image list to a CImageList object.

BOOL Attach( 
HIMAGELIST hImageList );

Parameters

hImageList
Specifies a handle to an image list object.

Return Value

Nonzero if the attachment was successful; otherwise, it is zero.

Example

// Pointer to myImageList.
extern CImageList* pmyImageList;
// A handle to an image list that will be attached.
extern HIMAGELIST hmyImageList;

// Attach the image list handle to the CImageList object.
pmyImageList->Attach(hmyImageList);

// Add a new icon to the image list.
pmyImageList->Add(AfxGetApp()->LoadStandardIcon(IDI_QUESTION));

// Detach the handle from the CImageList object.
pmyImageList->Detach();

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h

See Also

CImageList::Detach, CImageList::GetSafeHandle
