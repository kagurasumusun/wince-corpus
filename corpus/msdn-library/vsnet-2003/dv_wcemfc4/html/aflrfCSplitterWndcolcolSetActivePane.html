CSplitterWnd::SetActivePane

This method is called by the framework to set a pane as active when the user changes the focus to a pane within the frame window. You may explicitly call SetActivePane to change the focus to the specified view.

Specify pane by providing either a row and column, or by providing pWnd.

virtual void SetActivePane( 
int row, 
int col, 
CWnd* pWnd = NULL );

Parameters

row
If pWnd is NULL, specifies the row in the pane that will be active.
col
If pWnd is NULL, specifies the column in the pane that will be active.
pWnd
Specifies a pointer to a CWnd object. If NULL, the pane specified by row and col is set active. If not NULL, specifies the pane that is set active.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
