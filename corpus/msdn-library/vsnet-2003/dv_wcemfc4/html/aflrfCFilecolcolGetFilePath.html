CFile::GetFilePath

This method retrieves the full path of a specified file. For example, when you call GetFilePath to generate a message to the user about the file \MyDocuments\Untitled.txt, the file path, \MyDocuments\Untitled.txt, is returned. To return just the name of the file (Untitled.txt), call GetFileName. To return the title of the file, Untitled, call GetFileTitle.

virtual CString GetFilePath( ) 
const;

Return Value

The full path of the specified file.

Example

See the example for GetFileName.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
