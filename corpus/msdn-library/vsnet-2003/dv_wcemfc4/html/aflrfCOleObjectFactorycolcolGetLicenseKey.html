COleObjectFactory::GetLicenseKey

This method retrieves the unique license key from the control DLL and stores it in the BSTR pointed to by pbstrKey.

The default implementation of this method returns zero and stores nothing in the BSTR. If you use WCE MFC ActiveX ControlWizard to create your project, ControlWizard supplies an override that retrieves the license key of the control.

virtual BOOL GetLicenseKey( 
DWORD dwReserved, 
BSTR* pbstrKey );

Parameters

dwReserved
Reserved for future use.
pbstrKey
Specifies a pointer to a BSTR that will store the license key.

Return Value

Nonzero if the license-key string is not NULL; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h

See Also

COleObjectFactory::VerifyUserLicense, COleObjectFactory::VerifyLicenseKey
