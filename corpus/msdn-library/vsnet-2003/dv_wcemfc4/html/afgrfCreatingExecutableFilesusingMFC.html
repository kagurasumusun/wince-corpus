Creating Executable Files using MFC

Use the MFC AppWizard (exe) to create executable files.

To access the wizard, open the New dialog box by choosing File | New. Select the Projects tab to display available wizards.

  • Step 1 of 4 of the wizard lets you choose between SDI and dialog-based architecture, and lets you specify what language you want your Resources in.
  • Step 2 of 4 presents a set of options dependent on the architecture choices you make in Step 1. In either case, you can enable TCP/IP communication, generate Help files, and provide for ActiveX controls.
    • If in Step 1 you choose SDI architecture, you can specify CommandBars, a Status Bar, a Print Preview, and modify the length of the MRU list.
    • If in Step 1 you choose a dialog-based architecture, here is where you can retitle your dialog.
  • Step 3 of 4 lets you specify whether the MFC library should be statically linked at build time or linked as a shared DLL at run time. This step also lets you choose to have automatic comments generated in your source code.
  • Step 4 of 4 gives you the chance to make changes in the names the wizard has generated automatically.

The following table outlines the items you can specify in Step 1 of 4 of the wizard.

To... Do This...
Specify the architecture Select Single document to generate an SDI-based project. You can then select Document/View architecture support if you want to use CDocument and CView base classes. If you are porting a non-MFC application, clear the checkbox.

-Or-

Select Dialog based to generate a program that displays a dialog box for user input based on a dialog-template resource. You can change the title of your dialog in step 2 of the wizard.
Specify the language for your resources Use the drop-down list to select from among the languages available on your system. If you select a language other than English, the DLL for that language must be already installed. The filenaming convention is APPWZXXX.DLL, where XXX is a three-letter language identifier.

The following table outlines the items you can specify in Step 2 of 4 of the wizard.

To... Do This...
Let your program communicate over TCP/IP networks Select Windows Sockets.
Provide Windows Help on the target device Select Windows Help.
Let your program use ActiveX controls Select ActiveX Controls.
Specify command bar, toolbar, etc. These options are not available for dialog-based applications. Select Basic CommandBar to add a basic command bar ("New", "Open," etc.).

Select CommandBar with toolbar buttons to add a command bar that includes buttons.

Select Internet Explorer ReBars to implement Internet Explorer-style rebars.

Select MFC 2.0-compatible CommandBar to implement MFC 2.0-compatible CommandBars (across the top of the window). This option is available only with Document/View architecture.
Support a status bar Select Status bar. This option is not available for MFC 2.0-compatible control bar applications.
Support print preview feature Select Printing (2.1 only). This option is available only for SDI applications with Document/View architecture, and is not available if MFC 2.0-compatible CommandBar is selected.
Specify number of files to list in MRU list Enter a number in the How many files... control. This option is available for all SDI-based applications.

The following table outlines the items you can specify in Step 3 of 4 of the wizard.

To... Do This...
Generate source file comments Select Yes to automatically generate comments in the source code.
Specify link method To link the MFC library as a shared DLL so that your program calls it at run time, select As a shared DLL.

To link the MFC library at build time, select As a statically linked library.

The following table outlines the items you can specify in Step 4 of 4 of the wizard.

To... Do This...
Change file names, base classes Use the edit boxes to make changes to the automatically generated names. You can also change the base class of some files. For example, here is where you could substitute CScrollView for CView as the base view class for a Document/View application.
