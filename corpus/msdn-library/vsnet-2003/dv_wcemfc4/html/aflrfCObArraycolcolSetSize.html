CObArray::SetSize

This method establishes the size of an empty or existing array, allocating memory if necessary. If the new size is smaller than the old size, the array is truncated and all unused memory is released. For efficiency, call SetSize to set the size of the array before using it. This prevents the need to reallocate and copy the array each time an item is added.

The nGrowBy parameter affects internal memory allocation while the array is growing. Its use never affects the array size as reported by GetSize and GetUpperBound.

void SetSize( 
int nNewSize, 
int nGrowBy = –1 );

Parameters

nNewSize
Specifies the new array size, number of elements. Must be greater than or equal to zero.
nGrowBy
Specifies the minimum number of element slots to allocate if a size increase is necessary.

Example

See CObList::CObList for a listing of the CAge class used in all collection examples.

CObArray myArray;
  int i;

  // Allocate memory for at least 32 elements.
  myArray.SetSize(32, 128);

  // Add elements to the array.
  CAge** ppAge = (CAge**) myArray.GetData();
  for (i=0;i < 32;i++,ppAge++)
    *ppAge = new CAge( i );

  // Only keep first 5 elements and free extra (unused) bytes.
  myArray.SetSize(5, 128);
  myArray.FreeExtra();
