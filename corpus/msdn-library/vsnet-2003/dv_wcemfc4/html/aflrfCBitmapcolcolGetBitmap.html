CBitmap::GetBitmap

This method retrieves information about a CBitmap object. This information is returned in the BITMAP structure referred to by pBitmap.

int GetBitmap( 
BITMAP* pBitMap );

Parameters

pBitMap
Specifies the pointer to a BITMAP structure. Must not be NULL.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
