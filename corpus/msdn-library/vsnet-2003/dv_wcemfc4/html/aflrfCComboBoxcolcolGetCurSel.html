CComboBox::GetCurSel

This method determines which item in the combo box is selected, and returns an index to the list.

int GetCurSel( ) 
const;

Return Value

The zero-based index of the selected item in the list box of a combo box, or CB_ERR if no item is selected.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Select the next item of the selected item in the combo box.
int nIndex = pmyComboBox->GetCurSel();
int nCount = pmyComboBox->GetCount();
if ((nIndex != LB_ERR) && (nCount > 1))
{
  if (++nIndex < nCount)
    pmyComboBox->SetCurSel(nIndex);
  else
    pmyComboBox->SetCurSel(0);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
