CReBarCtrl::GetBandCount

This method retrieves the count of bands currently in the rebar control.

This method implements the behavior of the Windows CE message RB_GETBANDCOUNT.

UINT GetBandCount( ) 
const;

Return Value

The number of bands assigned to the control.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
