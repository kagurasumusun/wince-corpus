CDumpContext::CDumpContext

This constructor creates an instance of a CDumpContext object. The afxDump object is constructed automatically. 

CDumpContext( 
CFile* pFile = NULL);

Parameters

pFile
Specifies a pointer to the CFile object that is the dump destination.

Remarks

Do not write to the underlying CFile while the dump context is active; otherwise, you will interfere with the dump. Under the Windows CE environment, the output is routed to the debugger through the Windows CE function OutputDebugString.

Example

// Example for the CDumpContext::CdumpContext method.
CFile f;
if( !f.Open( "dump.txt", CFile::modeCreate | CFile::modeWrite ) ) {
   afxDump << "Unable to open file" << "\n";
   exit( 1 );
}
CDumpContext dc( &f );

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
