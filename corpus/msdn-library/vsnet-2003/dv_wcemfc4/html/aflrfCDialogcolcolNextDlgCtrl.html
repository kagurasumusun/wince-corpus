CDialog::NextDlgCtrl

This method moves the focus to the next control in the dialog box. If the focus is at the last control in the dialog box, it moves to the first control.

void NextDlgCtrl( ) 
const;

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
