COleControl::SetRectInContainer

This method sets the control rectangle relative to its container, expressed in device units. If the control is open, it is resized; otherwise, the container OnPosRectChanged function of the container is called.

BOOL SetRectInContainer( 
LPRECT lpRect );

Parameters

lpRect
Specifies a pointer to a rectangle containing the new coordinates of the control relative to the container.

Return Value

Nonzero if the call was successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h

See Also

COleControl::GetRectInContainer, COleControl::GetControlSize
