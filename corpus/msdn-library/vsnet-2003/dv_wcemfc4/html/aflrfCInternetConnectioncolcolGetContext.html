CInternetConnection::GetContext

This method returns the context identifier for this session.

DWORD GetContext( ) 
const;

Return Value

Returns the application-assigned context ID.

Remarks

The context ID is originally specified in CInternetSession and propagates to CInternetConnection- and CInternetFile-derived classes, unless specified differently in the call to a function that opens the connection. The context ID is associated with any operation of the given object and identifies the operation status information returned by CInternetSession::OnStatusCallback.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxinet.h
