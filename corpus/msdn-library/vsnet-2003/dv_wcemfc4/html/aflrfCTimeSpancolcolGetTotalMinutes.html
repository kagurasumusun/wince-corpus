CTimeSpan::GetTotalMinutes

This method retrieves the total number of complete minutes in this CTimeSpan object.

GetTotalMinutes will return a valid value if the object on which it operates was initialized with an amount of seconds that can be held in four bytes (+/-2,147,483,647). If your CTimeSpan object holds an eight-byte value, you should use GetTotalMinutes64 to return the number of minutes.

LONG GetTotalMinutes( ) 
const;

Example

// example for CTimeSpan::GetTotalHours, CTimeSpan::GetTotalMinutes
// and CTimeSpan::GetTotalSeconds
CTimeSpan ts( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ASSERT( ts.GetTotalHours() == 73 );
ASSERT( ts.GetTotalMinutes() == 4385 );
ASSERT( ts.GetTotalSeconds() == 263112 );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
