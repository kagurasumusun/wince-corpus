CListBox::CListBox

This constructor initializes the Windows CE list box and attaches it to the CListBox.

To construct a CListBox, call the constructor, then call Create.

CListBox( );

Example

// Declare a local CListBox object.
CListBox myListBox;

// Declare a dynamic CListBox object.
CListBox* pmyListBox = new CListBox;

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
