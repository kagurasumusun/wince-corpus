CList::AddTail

This method adds a new element or list of elements to the tail of this list. The list can be empty before the operation.

POSITION AddTail( 
ARG_TYPE newElement );

void AddTail( 
CList* pNewList );

Parameters

ARG_TYPE
Template parameter specifying the type of the list element, this can be a reference.
newElement
The element to be added to this list.
pNewList
A pointer to another CList list. The elements in pNewList will be added to this list.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h

See Also

CObList::GetTail, CObList::RemoveTail
