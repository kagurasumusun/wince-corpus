CPrintInfo::GetOffsetPage

This method retrieves the offset when printing multiple DocObject items from a DocObject client. This value is referenced by the m_nOffsetPage member. The first page of your document will be numbered the m_nOffsetPage value + 1 when printed as a DocObject with other active documents. The m_nOffsetPage member is valid only if the m_bDocObject value is TRUE.

UINT GetOffsetPage( ) 
const;

Return Value

Returns the number of pages preceding the first page of a DocObject item being printed in a combined DocObject print job.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
