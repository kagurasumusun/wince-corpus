Microsoft Foundation Class Library for Windows CE  

CPaintDC::m_hWnd

This data member contains the handle to the window to which this CPaintDC object is attached. m_hWnd is a protected variable of type HWND.

HWND m_hWnd;

Example

// Get a dc for a CWnd object pointer.
CPaintDC dc(pWnd);

// Send my private massage.
::SendMessage(pWnd->m_hWnd, WM_MYMESSAGE, (LPARAM) &dc.m_ps, 0);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
