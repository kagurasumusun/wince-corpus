Microsoft Foundation Class Library for Windows CE  

COlePropertyPage::OnEditProperty

This method is called by the framework when a property is about to be edited. Override this method to set the focus to the appropriate control on the page. The default implementation does nothing and returns FALSE.

virtual BOOL OnEditProperty( 
DISPID dispid );

Parameters

dispid
Specifies the dispatch ID of the property being edited.

Return Value

The default implementation returns FALSE. Overrides of this method should return TRUE.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
