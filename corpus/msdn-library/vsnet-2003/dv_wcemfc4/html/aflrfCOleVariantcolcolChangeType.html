COleVariant::ChangeType

This method converts the type of VARIANT value in this COleVariant object to the type specified by vartype.

void ChangeType( 
VARTYPE vartype, 
LPVARIANT pSrc = NULL );

Parameters

vartype
The VARTYPE for this COleVariant object.
pSrc
A pointer to the VARIANT object to be converted. If this value is NULL, this COleVariant object is used as the source for the conversion.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
