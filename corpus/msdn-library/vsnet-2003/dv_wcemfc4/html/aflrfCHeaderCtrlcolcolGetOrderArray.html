CHeaderCtrl::GetOrderArray

This method implements the behavior of the Win32 message HDM_GETORDERARRAY, as described in the Platform SDK. It is provided to support header item ordering.

BOOL GetOrderArray( 
LPINT piArray, 
int iCount = –1);

Parameters

piArray
A pointer to the address of a buffer that receives the index values of the items in the header control, in the order in which they appear from left to right.
iCount
The number of header control items.

Return Value

Nonzero if successful; otherwise, it is zero.

Remarks

If you use the default value of iCount, GetOrderArray fills the parameter using GetItemCount.

Example

// Pointer to the myheader control.
Extern CheaderCtrl* pmyHeaderCtrl;

// Reverse the order of the items in the header control,
// that is, make the first item the last one, the last item
// the first one, and so on...
int nCount = pmyHeaderCtrl->GetItemCount();
LPINT pnOrder = (LPINT) malloc(nCount*sizeof(int));
ASSERT(pnOrder != NULL);

PmyHeaderCtrl->GetOrderArray(pnOrder, nCount);

Int i, j, nTemp;
For (i=0,j=nCount-1;i < j;i++,j--)
{
  nTemp = pnOrder[i];
  pnOrder[i] = pnOrder[j];
  pnOrder[j] = nTemp;
}
pmyHeaderCtrl->SetOrderArray(nCount, pnOrder);
free(pnOrder);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
