Microsoft Foundation Class Library for Windows CE  

CHeaderCtrl::GetItemRect

This method implements the behavior of the Win32 message HDM_GETITEMRECT, as described in the Platform SDK.

BOOL GetItemRect( 
int nIndex, 
LPRECT lpRect ) 
const;

Parameters

nIndex
The zero-based index of the header control item.
lpRect
A pointer to the address of a RECT structure that receives the bounding rectangle information.

Return Values

Nonzero if successful; otherwise, it is zero.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
