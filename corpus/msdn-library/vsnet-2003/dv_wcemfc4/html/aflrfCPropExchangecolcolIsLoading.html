CPropExchange::IsLoading

This method determines whether properties are being loaded to the control or stored from it.

BOOL IsLoading( );

Return Value

Nonzero if properties are being loaded; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
