CFile::Seek

This method repositions the pointer in a previously opened file. The Seek method permits random access to the contents of a file by moving the pointer a specified amount, absolutely or relatively. No data is actually read during the seek. If the requested position is larger than the size of the file, the file length will be extended to that position, and no exception will be thrown.

When a file is opened, the file pointer is positioned at offset zero, the beginning of the file.

virtual LONG Seek( 
LONG lOff, 
UINT nFrom );

Parameters

lOff
Specifies the number of bytes to move the pointer.
nFrom
Specifies the pointer movement mode. Must be one of the following values:
  • CFile::begin   Move the file pointer lOff bytes forward from the beginning of the file.
  • CFile::current   Move the file pointer lOff bytes from the current position in the file.
  • CFile::end   Move the file pointer lOff bytes from the end of the file. Note that lOff must be negative to seek into the existing file; positive values seek past the end of the file.

Return Value

If the requested position is legal, Seek returns the new byte offset from the beginning of the file. Otherwise, the return value is undefined and a CFileException object is thrown.

Example

// Example for the CFile::Seek method.
extern CFile cfile;
long lOffset = 1000;
long lActual;
lActual = cfile.Seek( lOffset, CFile::begin );

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afx.h
