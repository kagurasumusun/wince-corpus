COleSafeArray::Redim

This method changes the least significant, rightmost, bound of a safe array.

On error, it throws a COleException.

void Redim( 
SAFEARRAYBOUND* psaboundNew );

Parameters

psaboundNew
Specifies a pointer to a new safe array bound structure containing the new array bound. Only the least significant dimension of an array may be changed.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
