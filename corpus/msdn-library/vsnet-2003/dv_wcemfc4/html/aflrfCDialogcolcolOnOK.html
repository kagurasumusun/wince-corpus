Microsoft Foundation Class Library for Windows CE  

CDialog::OnOK

This method is called by the framework when the user chooses the OK button. The OK button uses the identifier IDOK.

virtual void OnOK( );

Remarks

Override this method to perform the OK button action. If the dialog box includes automatic data validation and exchange, the default implementation of this method validates the dialog-box data and updates the appropriate variables in your application.

If you implement the OK button in a modeless dialog box, you must override the OnOK method and call DestroyWindow from within it. Do not call the base-class method, because it calls EndDialog, which makes the dialog box invisible but does not destroy it.

Example

// MyDialog.cpp
#include "MyDialog.h"

void CMyDialog::OnOK() 
{
  // TODO: Add extra validation here.
  
  // Ensure that the UI got the necessary input from the user 
  // before closing the dialog. The default OnOK closes this.
  if ( m_nMyValue == 0 ) // Is a field still empty?
  {
    AfxMessageBox("Please enter a value for MyValue");
    return; // Tell the user that the dialog cannot be closed without
            // entering the necessary values and do not close the dialog.
  }

  CDialog::OnOK(); // This closes the dialog and DoModal returns.
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
