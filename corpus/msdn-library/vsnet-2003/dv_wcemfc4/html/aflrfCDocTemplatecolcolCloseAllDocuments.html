CDocTemplate::CloseAllDocuments

This method closes all open documents. This method is used as part of the File Exit command. The default implementation of this method calls the CDocument::DeleteContents method to delete the data in the document and closes the frame windows for all the views attached to the document.

virtual void CloseAllDocuments( 
BOOL bEndSession );

Parameters

bEndSession
Specifies whether the session is being ended. It is TRUE if the session is ended; otherwise, it is FALSE.

Remarks

Override this function if you will require the user to perform special cleanup processing before the document is closed. For example, if the document represents a record in a database, override this function to close the database.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
