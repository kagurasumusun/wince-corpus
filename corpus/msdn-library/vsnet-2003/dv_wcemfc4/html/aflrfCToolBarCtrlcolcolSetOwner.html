CToolBarCtrl::SetOwner

This method sets the owner window for the toolbar control. The owner window is the window that receives notifications from the toolbar.

void SetOwner( 
CWnd* pWnd );

Parameters

pWnd
Specifies the pointer to the CWnd or CWnd-derived object that will be the new owner window for the toolbar control.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
