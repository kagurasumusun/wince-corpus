CComboBox::SetItemData

This method sets the 32-bit value associated with the specified item in a combo box. Use the SetItemDataPtr method if the 32-bit item is to be a pointer.

int SetItemData( 
int nIndex, 
DWORD dwItemData );

Parameters

nIndex
Contains a zero-based index to the item to set.
dwItemData
Contains the new value to associate with the item.

Return Value

CB_ERR if an error occurs.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Set the data of each item to be equal to its index.
for (int i=0;i < pmyComboBox->GetCount();i++)
{
  pmyComboBox->SetItemData(i, i);
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
