CDC::GetCurrentPen

This method retrieves a pointer to the selected CPen object. This method may return temporary objects.

CPen* GetCurrentPen( ) 
const;

Return Value

Pointer to a CPen object, if successful; otherwise, it is NULL.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
