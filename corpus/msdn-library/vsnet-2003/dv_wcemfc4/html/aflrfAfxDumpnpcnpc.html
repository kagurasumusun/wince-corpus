Microsoft Foundation Class Library for Windows CE  

AfxDump  

This function dumps the state of an object while debugging. AfxDump calls an object’s Dump method and sends the information to the location specified by the afxDump variable. AfxDump is available only in the Debug version of MFC.

Your program code should not call AfxDump, but should instead call the Dump method of the appropriate object.

void AfxDump( 
const CObject* pOb );

Parameters

pOb
A pointer to an object of a class derived from CObject.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afx.h
