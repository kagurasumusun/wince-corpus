CSliderCtrl::SetSelection

This method sets the starting and ending positions for the current selection in a slider control.

void SetSelection( 
int nMin, 
int nMax );

Parameters

nMin
Specifies the starting position for the slider.
nMax
Specifies the ending position for the slider.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
