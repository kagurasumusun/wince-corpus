CList::RemoveAll

This method removes all the elements from this list and releases the associated memory. No error is generated if the list is already empty.

void RemoveAll( );

Example

// Define myList.
CList<CString,CString&> myList;

// Add three elements to the list.
myList.AddTail(CString("XYZ"));
myList.AddTail(CString("ABC"));
myList.AddTail(CString("123"));

// Remove all of the elements in the list.
myList.RemoveAll();

// Verify the list is empty.
ASSERT(myList.IsEmpty());

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
