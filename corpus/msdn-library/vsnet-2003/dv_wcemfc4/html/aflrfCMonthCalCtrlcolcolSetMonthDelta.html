CMonthCalCtrl::SetMonthDelta

This method sets the, scroll rate, for a month calendar control. The scroll rate is the number of months that a month calendar control moves its display when the user clicks a scroll button.

This method implements the behavior of the Windows CE message MCM_SETMONTHDELTA. 

int SetMonthDelta( 
int iDelta );

Parameters

iDelta
Specifies the number of months to be set as the control scroll rate. If this value is zero, the month delta is reset to the default, which is the number of months displayed in the control.

Return Value

The previous scroll rate. If the scroll rate has not been previously set, the return value is zero.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxdtctl.h
