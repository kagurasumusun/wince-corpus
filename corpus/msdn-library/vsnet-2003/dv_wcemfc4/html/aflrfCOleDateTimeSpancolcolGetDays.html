COleDateTimeSpan::GetDays

This method retrieves the day portion of this date/time-span value.

The return values from this function range between approximately – 3,615,000 and 3,615,000.

long GetDays( ) 
const;

Return Value

Returns the day portion of this date/time-span value.

Remarks

For other functions that query the value of a COleDateTimeSpan object, see the following methods:

  • GetHours
  • GetMinutes
  • GetSeconds
  • GetTotalDays
  • GetTotalHours
  • GetTotalMinutes
  • GetTotalSeconds

Example

COleDateTimeSpan ts( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ASSERT( ts.GetDays() == 3 );

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
