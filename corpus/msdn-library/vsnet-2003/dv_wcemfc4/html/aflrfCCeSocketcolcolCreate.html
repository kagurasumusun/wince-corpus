CCeSocket::Create

This method creates the Windows socket after an instance of a socket object is created.

virtual BOOL Create ( 
UINT nSocketPort = 0);

Parameters

nSocketPort
Specifies a well-known port to use with the socket, or zero if Windows CE Socket selects a port.

Return Values

TRUE indicates that the socket was successfully created. FALSE indicates that the operation failed.

Remarks

The CceSocket::Create method attaches the Windows socket to the CCeSocket object. Create calls Bind to bind the socket to the specified address.

If the socket is a listening socket, this method also ensures that the socket is open for reading.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Wcesock.h
