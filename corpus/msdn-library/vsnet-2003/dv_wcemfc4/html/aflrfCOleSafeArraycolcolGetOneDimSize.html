COleSafeArray::GetOneDimSize

This method retrieves the number of elements in a one-dimensional COleSafeArray object. 

DWORD GetOneDimSize( );

Return Value

Returns the number of elements in the one-dimensional safe array.

Example

VARIANT varColInfo[3];

// Initialize VARIANTs.
for (int i = 0; i < 3; i++)
  VariantInit(&varColInfo[i]);

// Column Name.
varColInfo[0].vt = VT_BSTR;
varColInfo[0].bstrVal = ::SysAllocString(L"Name");

// Column Type.
varColInfo[1].vt = VT_UI4;
varColInfo[1].lVal = 1;

COleSafeArray sa;
// Create a one dimensional safearray of VARIANTs
// and initialize it with varColInfo VARIANT array.
sa.CreateOneDim(VT_VARIANT, 2, varColInfo);

// Check that the dimension is two.
ASSERT(sa.GetOneDimSize() == 2);

// Increase safearray size by one.
sa.ResizeOneDim(3);

// Populate the last element of the safearray, Column Size.
varColInfo[2].vt = VT_I4;
varColInfo[2].lVal = 30;

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
