CWnd::ReflectLastMsg

This method is called by the framework to reflect the last message to the child window.

This method calls SendChildNotifyLastMsg if the window identified by hWndChild is an OLE control or a window in the permanent map.

static BOOL PASCAL ReflectLastMsg( 
HWND hWndChild, 
LRESULT* pResult = NULL );

Parameters

hWndChild
A handle to a child window.
pResult
The result generated by the child window to be returned by the parent window. Can be NULL.

Return Value

Nonzero if the message was handled; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
