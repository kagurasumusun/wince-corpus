Microsoft Foundation Class Library for Windows CE  

COleControl::GetText

This method retrieves the value of the stock Text or Caption property. Note that the caller of this function must call SysFreeString on the string returned in order to free the resource. Within the implementation of the control, use InternalGetText to access the stock Text or Caption property of the control.

BSTR GetText( );

Return Value

The current value of the control text string or a zero-length string if no string is present.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h

See Also

COleControl::InternalGetText, COleControl::SetText
