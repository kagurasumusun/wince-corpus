CListBox::SetCaretIndex

This method sets the focus rectangle to the item at the specified index in a multiple-selection list box. SetCaretIndex scrolls the listbox if necessary, to bring the set item into view, however, no visible focus rectangle is created. 

int SetCaretIndex( 
int nIndex, 
BOOL bScroll = TRUE );

Parameters

nIndex
Specifies the zero-based index of the item to receive the focus rectangle in the list box.
bScroll
If this value is zero, the item is scrolled until it is fully visible. If this value is not zero, the item is scrolled until it is at least partially visible.

Return Value

LB_ERR if an error occurs.

Example

// Pointer to the mLlistBox.
extern CListBox* pmyListBox;

// Set the caret to be the middle item.
pmyListBox->SetCaretIndex(pmyListBox->GetCount()/2);
ASSERT(pmyListBox->GetCaretIndex() == pmyListBox->GetCount()/2);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
