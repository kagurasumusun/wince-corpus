COleDispatchDriver::GetProperty

This method retrieves the object property specified by dwDispID.

void GetProperty( 
DISPID dwDispID, 
VARTYPE vtProp, 
void* pvProp ) 
const;

Parameters

dwDispID
Identifies the property to be retrieved. This value is usually supplied by ClassWizard.
vtProp
Specifies the property to be retrieved. For possible values, see the Remarks section for COleDispatchDriver::InvokeHelper.
pvProp
Specifies the address of the variable that will receive the property value. It must match the type specified by vtProp.

Example

CString IMyComObject::GetString()
{
    CString result;
    GetProperty(0x1, VT_BSTR, (void*)&result);
    return result;
}

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
