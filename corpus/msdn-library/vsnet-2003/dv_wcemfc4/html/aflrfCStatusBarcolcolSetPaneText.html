CStatusBar::SetPaneText

This method sets the pane text to the string pointed to by lpszNewText. After you call SetPaneText, you must add a UI update handler to display the new text in the status bar. 

BOOL SetPaneText( 
int nIndex, 
LPCTSTR lpszNewText, 
BOOL bUpdate = TRUE );

Parameters

nIndex
Specifies the index of the pane whose text is to be set.
lpszNewText
Specifies a pointer to the new pane text.
bUpdate
If TRUE, the pane is invalidated after the text is set.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// This Sets and displays text for pane index 4 and id ID_PANE_FOUR.
SetPaneText (4, _T("My New Status Bar Text"), TRUE)

// The UI handler in the message map updates the status bar text:
ON_UPDATE_COMMAND_UI ( ID_PANE_FOUR, OnUpdatePane )

//In the appropriate .cpp file add:
void CMyClass::OnUpdatePane (CCmdUI *pCmdUI)  {     pCmdUI->Enable ();  }

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
