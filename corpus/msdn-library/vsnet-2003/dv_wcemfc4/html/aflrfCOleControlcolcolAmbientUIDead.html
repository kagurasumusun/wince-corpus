COleControl::AmbientUIDead

This method determines whether the control should respond to user-interface actions. For example, a container might set this to TRUE in design mode.

BOOL AmbientUIDead( );

Return Value

Nonzero if the control should respond to user-interface actions; otherwise, it is zero. If this property is not supported, this function returns zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
