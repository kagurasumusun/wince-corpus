Microsoft Foundation Class Library for Windows CE  

CWnd::RunModalLoop

This method retrieves, translates, or dispatches messages until ContinueModal returns FALSE. By default, ContinueModal returns FALSE after EndModalLoop is called. Returns the value provided as nResult to EndModalLoop.

int RunModalLoop( 
DWORD dwFlags = 0 );

Parameters

dwFlags
Specifies the Windows message to be sent. Can be one of the following values:
  • MLF_NOIDLEMSG   Do not send WM_ENTERIDLE messages to the parent.
  • MLF_NOKICKIDLE   Do not send WM_KICKIDLE messages to the window.
  • MLF_SHOWONIDLE   Show the window when message queue goes idle.

Return Value

Specifies the value of the nResult parameter passed to the EndModalLoop method, which is then used to end the modal loop.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
