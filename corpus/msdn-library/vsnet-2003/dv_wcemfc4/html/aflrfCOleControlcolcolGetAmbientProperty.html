COleControl::GetAmbientProperty

This method retrieves the value of the specified ambient property. If you use GetAmbientProperty to retrieve the ambient DisplayName and ScaleUnits properties, set vtProp to VT_BSTR and pvProp to CString*. If you are retrieving the ambient Font property, set vtProp to VT_FONT and pvProp to LPFONTDISP*.

BOOL GetAmbientProperty( 
DISPID dwDispid, 
VARTYPE vtProp, 
void* pvProp );

Parameters

dwDispid
Specifies the dispatch ID of the desired ambient property.
vtProp
Specifies a variant type tag that specifies the type of the value to be returned in pvProp.
pvProp
Specifies a pointer to the address of the variable that will receive the property value or return value. The actual type of this pointer must match the type specified by vtProp.
vtProp Type of pvProp
VT_BOOL BOOL*
VT_BSTR CString*
VT_I2 short*
VT_I4 long*
VT_R4 float*
VT_R8 double*
VT_CY CY*
VT_COLOR OLE_COLOR*
VT_DISPATCH LPDISPATCH*
VT_FONT LPFONTDISP*

Return Value

Nonzero if the ambient property is supported; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
