Microsoft Foundation Class Library for Windows CE  

Support Classes

MFC for Windows CE supports the following classes the same way the standard MFC library does, with the one exception that you cannot use the SetCursor method of the CRectTracker class.

  • CCmdUI
  • CDataExchange
  • CLongBinary
  • COleDispatchDriver
  • CPropExchange
  • CRectTracker
  • CWaitCursor

MFC for Windows CE does not support the COleCmdUI, CDaoFieldExchange, CDBVariant, CFieldExchange, and COleDataObject support classes.

For information about where the support classes fit into the Windows CE class hierarchy, see Classes Not Derived from CObject.
