CWnd::OnPaint

This method is called by the framework when Windows CE or an application makes a request to repaint a portion of an application window. The WM_PAINT message is sent when the UpdateWindow or CWnd::RedrawWindow method is called.

afx_msg void OnPaint( );

Remarks

A window may receive internal paint messages as a result of calling the RedrawWindow method with the RDW_INTERNALPAINT flag set. In this case, the window may not have an update region. An application should call the GetUpdateRect method to determine whether the window has an update region. If GetUpdateRect returns zero, the application should not call the CWnd::BeginPaint and CWnd::EndPaint methods.

It is the responsibility of an application to check for any necessary internal repainting or updating by looking at its internal data structures for each WM_PAINT message because a WM_PAINT message may have been caused by both an invalid area and a call to the RedrawWindow method with the RDW_INTERNALPAINT flag set.

An internal WM_PAINT message is sent only once by Windows. After an internal WM_PAINT message is sent to a window by the UpdateWindow method, no further WM_PAINT messages will be sent or posted until the window is invalidated or until the RedrawWindow method is called again with the RDW_INTERNALPAINT flag set.

For information on rendering an image in document/view applications, see CView::OnDraw.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
