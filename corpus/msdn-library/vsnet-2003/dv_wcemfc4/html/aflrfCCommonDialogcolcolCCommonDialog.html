CCommonDialog::CCommonDialog

This constructor creates an instance of a CCommonDialog object.

CCommonDialog( 
CWnd* pParentWnd );

Parameters

pParentWnd
Pointer to the parent or owner window object of type CWnd to which the dialog object belongs. If it is NULL, the parent window of the dialog object is set to the main application window.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxdlgs.h
