Microsoft Foundation Class Library for Windows CE  

CCmdTarget

CCmdTarget is the base class for the Microsoft Foundation Class Library for Windows CE message-map architecture. A message map routes commands or messages to the methods that you write to handle them. A command is a message from a menu item, command button, or accelerator key.

Key framework classes derived from CCmdTarget include CView, CWinApp, CDocument, CWnd, and CFrameWnd. If you want a new class to handle messages, derive the class from one of these CCmdTarget-derived classes. A class is rarely derived directly from CCmdTarget.

CCmdTarget includes methods that handle the display of an hourglass cursor. Display the hourglass cursor when you expect a command to take a noticeable time interval to execute.

Dispatch maps, similar to message maps, are used to expose OLE automation IDispatch functionality. By exposing this interface, other applications, such as Visual Basic, can call into your application.

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
