CTabCtrl::SetItemSize

This method sets the width and height of the tab control items.

CSize SetItemSize( 
CSize size );

Parameters

size
Specifies the new width and height in pixels of the tab control items.

Return Value

Returns the old width and height of the tab control items.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
