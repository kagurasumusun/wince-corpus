CScrollView::FillOutsideRect

This method fills the area of the view that appears outside of the scrolling area. Use FillOutsideRect in the CWnd::OnEraseBkgnd handler of your scroll view method to prevent excessive background repainting.

void FillOutsideRect( 
CDC* pDC, 
CBrush* pBrush );

Parameters

pDC
Specifies the device context in which the filling is to be done.
pBrush
Specifies the brush with which the area is to be filled.

Example

BOOL CScaleView::OnEraseBkgnd( CDC* pDC )
{
    CBrush br( GetSysColor( COLOR_WINDOW ) ); 
    FillOutsideRect( pDC, &br );
    return TRUE;                   // Erased
}

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
