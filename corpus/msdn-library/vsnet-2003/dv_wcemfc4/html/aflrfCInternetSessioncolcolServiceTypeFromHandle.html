Microsoft Foundation Class Library for Windows CE  

CInternetSession::ServiceTypeFromHandle

This method gets the type of service from the Internet handle.

DWORD ServiceTypeFromHandle( 
HINTERNET hQuery );

Parameters

hQuery
Specifies a handle to an Internet query.

Return Value

The Internet service type. The following service types are recognized by MFC for Windows CE:

Service type Return value
HTTP INTERNET_SERVICE_HTTP
File AFX_INET_SERVICE_FILE

CInternetSession will throw an AfxThrowNotSupportedException for unsupported service types.

The return value AFX_INET_SERVICE_FILE is used only by MFC for Windows CE and is not recognized by Windows CE. This feature allows the client to access local files in the same way he or she would access Internet services.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Afxinet.h
