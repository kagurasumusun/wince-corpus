CTabCtrl::GetCurSel

This method retrieves the currently selected tab in a tab control.

int GetCurSel( ) 
const;

Return Value

Returns the zero-based index of the selected tab if successful or –1 if no tab is selected.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h

See Also
