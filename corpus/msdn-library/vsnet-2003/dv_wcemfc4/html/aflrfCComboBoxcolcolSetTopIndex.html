CComboBox::SetTopIndex

This method ensures that an item is visible in the list box portion of the combo box. The system scrolls the list box until the item specified by nIndex appears at the top of the list box or the maximum scroll range is reached.

int SetTopIndex( 
int nIndex );

Parameters

nIndex
Specifies the zero-based index of the list box item.

Return Value

Zero if it is successful, or CB_ERR if an error occurs.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Set the first visible item in the combo box to be the middle item
pmyComboBox->SetTopIndex(pmyComboBox->GetCount()/2);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxwin.h
