CArray::RemoveAll

This method removes all the elements from this array. If the array is empty, the function still works.

void RemoveAll( );

Example

CArray<CPoint,CPoint> myArray;

// Add elements to the array.
for (int i=0;i < 10;i++)
  myArray.Add( CPoint(i, 2*i) );

myArray.RemoveAll();

#ifdef _DEBUG
    afxDump.SetDepth( 1 );
    afxDump << "myArray: " << &myArray << "\n";
#endif

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxtempl.h
