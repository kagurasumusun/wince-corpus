CBitmapButton::AutoLoad

This method associates a button in a dialog box with a CBitmapButton object. This method loads the bitmap by name and sizes the button to fit the bitmap. 

BOOL AutoLoad( 
UINT nID, 
CWnd* pParent );

Parameters

nID
The button’s control identifier.
pParent
The pointer to the object that owns the button.

Return Value

Nonzero if it is successful; otherwise it is zero.

Remarks

Use the AutoLoad function to initialize an owner-drawn button in a dialog box as a bitmap button. Instructions for using this function are in the remarks for the CBitmapButton class.

Example

CBitmapButton myButton;

// Initialize the owner-drawn button with the identifier IDC_MYBUTTON as
// a bitmap button. This code is used in the OnInitDialog handler of
// my dialog.
myButton.AutoLoad(IDC_MYBUTTON, this);

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxext.h
