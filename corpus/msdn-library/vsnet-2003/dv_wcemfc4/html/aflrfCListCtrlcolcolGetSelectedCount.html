CListCtrl::GetSelectedCount

This method retrieves the number of selected items in the list view control.

UINT GetSelectedCount( ) 
const;

Return Value

The number of selected items in the list view control.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

UINT i, uSelectedCount = pmyListCtrl->GetSelectedCount();
int  nItem = -1;

// Update all of the selected items.
if (uSelectedCount > 0)
{
  for (i=0;i < uSelectedCount;i++)
  {
    nItem = pmyListCtrl->GetNextItem(nItem, LVNI_SELECTED);
    ASSERT(nItem != -1);
    pmyListCtrl->Update(nItem); 
  }
}

Requirements

Windows CE versions: 1.0 and later
Header file: Declared in Afxcmn.h
