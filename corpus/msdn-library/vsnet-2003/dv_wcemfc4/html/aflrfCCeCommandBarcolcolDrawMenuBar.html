Microsoft Foundation Class Library for Windows CE  

CCeCommandBar::DrawMenuBar

This method repositions and redraws the command bar after a menu in the command bar is modified.

BOOL DrawMenuBar( 
int nButton ) 
const;

Parameters

nButton
Specifies the zero-based index of the menu bar within the command bar.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

Always call this method after modifying a menu in a command bar.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Wcebar.h
