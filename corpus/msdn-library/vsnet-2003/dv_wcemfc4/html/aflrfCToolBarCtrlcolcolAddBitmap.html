CToolBarCtrl::AddBitmap

This method adds one or more button images to the list of button images stored in the toolbar control. You can use the Windows CE API CreateMappedBitmap to map colors before adding the bitmap to the toolbar.

If you pass a pointer to a CBitMap object, you must ensure that the bitmap is not destroyed until after the toolbar is destroyed.

int AddBitmap( 
int nNumButtons, 
UINT nBitmapID );

int AddBitmap( 
int nNumButtons, 
CBitmap* pBitmap );

Parameters

nNumButtons
Specifies the number of button images in the bitmap.
nBitmapID
Specifies the resource identifier of the bitmap that contains the button image or images to add.
pBitmap
Pointer to the CBitmap object that contains the button image or images to add.

Return Value

Zero-based index of the first new image if it is successful; otherwise, it is –1.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
