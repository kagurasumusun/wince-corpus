ISdpWalk::WalkNode

This method is used to walk an SDP node. 

HRESULT WalkNode(
NODEDATA  *pData,
ULONG  state
);

Parameters

pData
[in] Pointer to the NodeData structure containing the contents of the current element. If pData is either a sequence or an alternative, state is valid.
state
[in] State of the operation. When the container is found, state is nonzero. When the end of the container is reached, state is 0.

Remarks

If this method returns S_NO_RECURSE, the contents of the container was not walked.

Return Values

None.
