BTHNS_INQUIRYBLOB

This structure contains additional parameters for device inquiries.

typedef struct _BTHNS_INQUIRYBLOB {
ULONG           LAP;
unsigned char   length;
unsigned char   num_responses;
}BTHNS_INQUIRYBLOB, *PBTHNS_INQUIRYBLOB;

Members

LAP
The LAP from which the inquiry access code is derived when the inquiry procedure is made. By default, this value is set to GIAC, 0x9e8b33. Unless you know what this value should be, it is best to leave it set to the default value, especially if you set the length and num_responses.
length
Amount of time allowed to perform the query. This is measured in units of 1.28 seconds (time to query=length*1.28 seconds). The default value is 16.
num_responses
Maximum number of devices to retrieve information on before stopping the inquiry. The default value is 16.

Remarks

If lpBlob is NULL, the default values are used. BthNsLookupBegin returns only after the device inquiry times out or after the maximum number of queried devices specified in num_responses are found.
