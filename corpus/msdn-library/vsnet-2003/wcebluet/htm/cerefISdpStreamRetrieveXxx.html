ISdpStream::RetrieveElementInfo

This method retrieves element information from the stream in a pointer-alignment-safe manner.

HRESULT RetrieveElementInfo(
UCHAR  *pStream, 
SDP_TYPE  *pElementType, 
SDP_SPECIFICTYPE  *pElementSpecificType, 
ULONG  *pElementSize, 
ULONG  *pStorageSize, 
UCHAR  **ppData
);

Parameters

pStream
[in] Pointer to the stream containing the element.
pElementType
[out] Destination pointer for the element type.
pElementSpecificType
[out] Destination pointer for the element's specific type.
pElementSize
[out] Destination pointer for the element's size.
pStorageSize
[out] Destination pointer for the storage size.
ppData
[out] Destination pointer for the element's data.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Bthapi.idl Bthapi.h
