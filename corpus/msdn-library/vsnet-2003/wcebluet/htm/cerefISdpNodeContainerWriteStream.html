ISdpNodeContainer::WriteStream

This method converts the contents of the container into a valid, well-formed raw SDP stream.

HRESULT WriteStream(
UCHAR  *pStream,
ULONG  *pNumBytesWritten
);

Parameters

pStream
[in] Pointer to the destination stream.
pNumBytesWritten
[out] The number of bytes written to pStream.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Bthapi.idl Bthapi.h
