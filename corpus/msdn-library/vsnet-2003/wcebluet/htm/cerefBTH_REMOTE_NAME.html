BTH_REMOTE_NAME

This structure is used to obtain the user-friendly name of another Bluetooth device. The user-friendly name is used to enable the user to distinguish one Bluetooth device from another.

typedef struct _BTH_REMOTE_NAME {
BT_ADDR   bt;
WCHAR     szNameBuffer[248]; 
 } BTH_REMOTE_NAME, *PBTH_REMOTE_NAME;

Members

bt
Target device.
szNameBuffer [248]
Returned name.
