Bluetooth Application Implementation

In Windows CE, the primary way an application can use Bluetooth is through the Winsock interface, which exposes RFCOMM protocol. The Winsock Interface Sample demonstrates the use of this interface.

Virtual COM ports are also exposed, but this interface is designed to be enabled under existing OS services such as UNIMODEM or terminal emulators.
