socket()

To create a Bluetooth socket, use:

af = AF_BTH
type = SOCK_STREAM
protocol = BTHPROTO_RFCOMM

The following example code shows how to use socket to create a Bluetooth socket.

SOCKET s = socket (AF_BTH, SOCK_STREAM, BTHPROTO_RFCOMM);

For more information about the socket function, see socket in the Winsock reference.
