NodeData

This structure defines the node data in a Service Discovery Protocol (SDP) record.

typedef struct NodeData {
USHORT         type;
USHORT         specificType;
NodeDataUnion  u;
} NodeData;

Members

type
Specifies the SDP_TYPE.
specificType
Specifies the SDP_SPECIFICTYPE.
u
Specifies the NodeDataUnion.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Bthapi.idl
