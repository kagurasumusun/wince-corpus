ISdpRecord:IUnknown

This interface is used to manage the contents of an SDP record.

Method Description
ISdpRecord::CreateFromStream Populates an SDP record with attributes and their values based on the provided raw SDP stream.
ISdpRecord::GetAttribute Retrieves the value of an attribute in an SDP record.
ISdpRecord::GetAttributeAsStream Retrieves the value of an attribute as a raw SDP stream.
ISdpRecord::GetAttributeList Retrieves a list of attributes contained in the SDP record.
ISdpRecord::SetAttribute Adds or replaces an attribute and its value.
ISdpRecord::SetAttributeFromStream Adds or replaces an attribute and its value from a raw SDP stream.
ISdpRecord::GetServiceClass Retrieves the service class globally unique identifier (GUID)
ISdpRecord::Walk Walks the attributes in an SDP record.
ISdpRecord::WriteToStream Creates a raw SDP stream based on the contents of the SDP record.
