ISdpStream:IUnknown

This interface is used to manage streamed data.

Method Description
ISdpStream::ByteSwap* Converts data from system-specific byte ordering into SDP network byte order.
IsdpStream::NormalizeUuid Coverts the data UUID into a GUID.
ISdpStream::Retrieve* Retrieves data from the stream in a pointer-alignment-safe manner.
ISdpStream::RetrieveElementInfo Retrieves the information of an element from the stream in a pointer-alignment-safe manner.
ISdpStream::RetrieveRecords Retrieves a record from the stream in a pointer-alignment-safe manner.
ISdpStream::Validate Parses the raw SDP stream to ensure it is valid and well formed.
ISdpStream::VerifySequenceOf Parses the raw SDP stream to ensure the sequence of elements is valid and well formed.
ISdpStream::Walk Walks a raw SDP stream, calling ISdpWalk::WalkStream for each element.
