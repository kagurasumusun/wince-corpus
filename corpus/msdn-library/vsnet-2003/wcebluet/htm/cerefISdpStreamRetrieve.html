ISdpStream::Retrieve*

The Retrieve* methods retrieve data of the indicated type (*) from the stream in a pointer-alignment-safe manner.

HRESULT Retrieve*(
UCHAR  *pStream,
OutputType  *outputElement
);

The following table displays the variables for Retrieve.

Retrieve

method (*)

 Output type Output element
Uuid128 GUID *pUuid128
Uint16 USHORT *pUint16
Uint32 ULONG *pUint32
Uint64 ULONGLONG *pUint64
Uint128 PSDP_ULARGE_INTEGER_16 *pUint128
Int16 SHORT *pInt16
Int32 LONG *pInt32
Int64 LONGLONG *pInt64
Int128 PSDP_LARGE_INTEGER_16 *pInt128

For example, if you wanted to retrieve Uint64, you would use the following syntax.

HRESULT RetrieveUint64
UCHAR      *pStream,
ULONGLONG  *pUint64
);

Parameters

pStream
[in] Pointer to the stream containing the data.
outputElement
[out] Destination pointer for the retrieved data.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Bthapi.idl Bthapi.h
