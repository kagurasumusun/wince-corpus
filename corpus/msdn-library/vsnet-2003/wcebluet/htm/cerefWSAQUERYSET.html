WSAQUERYSET

This structure is a generic Winsock structure that other service search protocols use for searching. The options discussed in this topic are specific to Bluetooth queries. For more generic uses of this structure, please refer to the WSAQUERYSET for Winsock.

The following member descriptions indicate how the WSAQUERYSET structure is used to construct a query. When a parameter is marked as (Optional), a NULL pointer can be supplied, indicating that the parameter will not be used for search criteria.

Members

dwNameSpace
This value must be set to NS_BTH for Bluetooth queries.
dwNumberOfCsAddrs
Ignored for queries.
dwNumberOfProtocols
Ignored.
dwOutputFlags
Ignored for queries.
dwSize
Reflects the value of sizeof(WSAQUERYSET). This is a versioning mechanism.
lpBlob
This context varies depending upon the function. For a complete description of this value, see BthNsLookupServiceBegin or BthNsLookupServiceNext.
lpcsaBuffer
Ignored for service queries. When a name inquiry is performed and LUP_RETURN_ADDR is specified in the BthNsLookupServiceNext dwFlags argument, the Bluetooth address of a particular device will be returned in lpcsaBuffer>RemoteAddr.lpSockaddr.
lpNSProviderId
Ignored.
lpServiceClassId
(Required) Identifies the services class in the form of a GUID.
lpszComment
Ignored.
lpszContext
Ignored.
lpszQueryString
Ignored.
lpszServiceInstanceName
When LUP_CONTAINERS is specified in BthNsLookupServiceBegin and LUP_RETURN_NAME is specified in the call to BthNsLookupServiceNext on this handle, the name of the particular device is returned in this parameter.
lpVersion
Ignored.

Remarks

For service queries, the WSAQUERYSET is used in the following manner.

Field Subfield Description
lpqsRestrictions dwNumber sizeof(WSAQUERYSET)
  lpServiceClassId (Optional) The most specific Bluetooth UUID.
  dwNameSpace NS BTH
  dwNumberOfCsAddrs 1
  lpcsaBuffer If LUP_RES_SERVICE is not set, the RemoteAddr.lpSockaddr member specifies the Bluetooth address of the remote device to query.
  lpBlob If lpBlob is NULL, the UUID specified in the lpServiceClassId is used for an SDP service search. If lpBlob is not NULL, it points to a BTHNS_RESTRICTIONBLOB structure that contains more specific search parameters. In this case, lpServiceClassId is ignored.
  * All other WSAQUERYSET fields are ignored.
dwControlFlags LUP_CONTAINER Must NOT be set.
  LUP_RES_SERVICE Specifies to search only the local SDP database.
