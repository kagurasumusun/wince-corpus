ISdpWalk:IUnknown

This interface is used to walk the stream.

Note   It is the application programmer's responsibility to implement this interface and to pass a pointer for it to the IsdpNodeContainer::Walk and/or IsdpRecord::Walk interface.
Method Description
ISdpWalk::WalkNode Walks an SDP node.
ISdpWalk::WalkStream Walks an SDP stream.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Bthapi.idl Bthapi.h
