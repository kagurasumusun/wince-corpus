ISdpStream::Validate

This method parses the provided raw SDP stream, ensuring the stream is valid and well formed. 

HRESULT Validate(
UCHAR  *pStream,
ULONG  size,
ULONG_PTR  *pErrorByte
);

Parameters

pStream
[in] Pointer to the stream to validate.
size
[in] Number of bytes in the stream at pStream.
pErrorByte
[out] Offset of the incorrect byte if an error is in the stream.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Bthapi.idl Bthapi.h
