SdpQueryUuid

This structure contains the UUID to query for attribute or attribute service searching.

typedef struct _SdpQueryUuid{
SdpQueryUuidUnion  u;
USHORT  uuidType;
} SdpQueryUuid;

Members

u
Defines the SdpQueryUuidUnion value. This value is one of SDP_ST_UUID128, SDP_ST_UUID32, or SDP_ST_UUID16.
uuidType
Identifies the UUID type.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Bthsdpdef.h
