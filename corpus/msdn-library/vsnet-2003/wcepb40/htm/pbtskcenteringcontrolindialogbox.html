Centering a Control in the Dialog Box

  1. Select the control to center.
  2. Choose Center In Dialog from the Layout menu, and then choose one of the following options:
    • Vertical, which centers controls vertically in the dialog box.
    • Horizontal, which centers controls horizontally in the dialog box.
