Call Tree View

The Call Tree view presents the call tree of your code for a specified data range in tabular format.

Below the name of a function, the Call Tree view displays nodes that represent the functions called by that function in the specified path of execution. The values for each node summarize the timing data for the instances of the function.

With the Call Tree option bar, you can select a timing value by which to sort the functions and set criteria to filter the data that is displayed. You can apply your selections incrementally to each subsequent level of the call tree as you expand it, or you can apply your selections to the entire Call Tree view. For more information, see Filtering Data in the Call Tree View.

The Call Tree view does not display data from Remote Call Profiler summary view (.icx) files.

For information about opening a Call Tree view window, see Opening a View Window.
