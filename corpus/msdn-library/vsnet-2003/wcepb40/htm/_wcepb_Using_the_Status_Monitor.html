Status Monitor

The right side of the status bar in the IDE displays the status of each remote service as an icon. You can hover over an icon to display the name of the corresponding remote service and a description of its status. For more information about remote services, see Remote Services on a Target Device.

The following table shows the remote services that the status monitor displays.

Remote service Possible status value
Target Control (CESH) Stopped, Running, Waiting, and Timed Out
Target Messages (CETerm) Stopped, Running, and Waiting
Debugger Stopped, Running, Waiting, and Breaking
Download Waiting to Download, Downloading, and Not Downloading
Build Building, and Not Building
Connection Not Connected, Waiting to Connect, and Connected
