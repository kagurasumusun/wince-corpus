Creating a New Source File

  1. Choose New Project or File from the File menu, and then choose the Files tab.
  2. Select the type of source file that you want to create.
  3. Select or clear the Add To Project check box, if necessary.

    If you selected Add to Project, select a project from the list.

  4. Type a name in the File Name box.
  5. Type a path in the Location box.
  6. Choose OK.
