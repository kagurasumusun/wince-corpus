IeXdiCodeBreakpoint:IUnknown

This interface provides the Extended Debugging Interface (eXDI) methods that implement the server code breakpoint services for the debugger.

Methods

Method Description
IeXdiCodeBreakpoint::GetAttributes Retrieves the code breakpoint’s current characteristics.
IeXdiCodeBreakpoint::SetState Enables or disables a breakpoint.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later exdi.idl
