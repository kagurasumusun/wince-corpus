Dialog Box Testing

You can simulate the run-time behavior of a dialog box from within the dialog editor without compiling your application. This provides immediate feedback on the appearance and performance of controls, and thus accelerates the UI design process.

You can use test mode for the following tasks:

  • Typing text
  • Selecting from combo box lists
  • Turning options on and off
  • Choosing commands
  • Testing the tab order
  • Testing the grouping of controls, such as radio buttons or check boxes
  • Testing dialog box keyboard shortcuts for controls that have mnemonic keys defined

When you test a dialog box, it is usually displayed at a location relative to the main application window. If the Absolute Align check box is selected on the More Styles property page, the dialog box is displayed at a position relative to the upper-left corner of the screen.
