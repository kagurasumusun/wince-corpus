Ppshell Class Driver

Platform Builder and Cesh.exe support the parallel port interface on the development workstation. They use the parallel port device driver, Ppshell.sys, to communicate with the parallel port hardware on the development workstation. As an option, you can install Ppshell.sys after you set up Platform Builder on the development workstation.

The Ppshell.sys driver has been rebuilt to make it a parallel class driver. The updated version of the driver now uses the underlying Windows-based desktop platforms parallel port arbitrator Parport.sys file. Incorporating this concept into the driver allows you to continue using the system parallel ports while using the Ppshell.sys driver. The new Ppshell.sys driver is a legacy driver, meaning that it is binary-compatible with Windows-based desktop platforms.

To use the new Ppshell.sys driver, you must run the Ppshell.vbs script to install the driver and update the registry.

Note   You must set the parallel port mode to PS/2, bidirectional, or Enhanced Parallel Port (EPP) by means of the basic input/output system (BIOS), jumpers, or configuration utility.

In addition, you must manually enable the parallel port interrupts using the Device Manager Port Setting tab.

To manually enable parallel port interrupts

  1. To verify that the interrupt appears, choose View Resources by Type from the View menu in Device Manager.
  2. Right-click My Computer on the desktop and select Properties.
  3. Select the Hardware tab, then choose Device Manager.
  4. Select the parallel ports you want to use with Ppshell.sys, then right-click the ports and select Properties\Port Settings then choose Use any interrupt assigned to this port.
  5. Choose OK and reboot.
