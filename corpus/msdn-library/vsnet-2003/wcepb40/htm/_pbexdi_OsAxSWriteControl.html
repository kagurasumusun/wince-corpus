OsAxSWriteControl

This function is reserved for writing OS run-time information. The IeXdiServer::IoCtl method calls this function.

HRESULT WINAPI OsAxSWriteControl(
IeXdiServer *pieXdiServer,
USHORT Processor,
DWORD dwTargetBaseAddress,
const BYTE *pbIn,
DWORD dwTransferCount 
);

Parameters

pieXdiServer
Passes a pointer to the eXDI server.
Processor
Passes the processor type.
dwTargetBaseAddress
Passes the control identifier.
pbIn
Passes in the raw buffer.
dwTransferCount
Passes the number of bytes to read, if applicable.

Return Values

This function has the following return values.

Return value Description
S_OK Function is successful.
EXDI_E_CANNOTWHILETGTRUNNING Cannot proceed while target is running.
EXDI_E_NOTIMPL Not implemented.
EXDI_E_OUTOFMEMORY Failed to allocate necessary memory.
EXDI_E_INVALIDARG One or more arguments is invalid.
EXDI_E_ABORT Operation aborted.
EXDI_E_FAIL Unspecified failure occurred.
EXDI_E_COMMUNICATION Communication error occurred between host driver and target.

Remarks

The IeXdiServer::Ioctl method must call the OsAxSWriteControl function when the first DWORD of the pbBufferIn buffer that is passed into the IeXdiServer::Ioctl method equals DbgKdWriteControlSpaceApi, or 0x00003138.

Similarly, the IeXdiServer::Ioctl method must call the OsAxSReadControl function when the first DWORD of the pbBufferIn buffer that is passed into the IeXdiServer::Ioctl method equals DbgKdReadControlSpaceApi, or 0x00003137.

You must extract the parameters for the OsAxSWriteControl or OsAxSReadControl function from the pbBufferIn buffer for the IeXdiServer::Ioctl method.
