Creating a New Window for an Open Source File

  1. Switch to the source window.
  2. Choose the New Window command from the Window menu.

    A second copy of the source file is displayed with a suffix that shows the number of source windows that are open. As you open more windows showing the source file, the suffix value increases. You can scroll and split each window independently. You can make changes to the source file from any window.

  3. When you first open a file, if you select the Open as Read-Only check box in the Open dialog box, the current window and any split windows remain read-only.
