OS Image Selection

Before you download an OS image to a target device, you must choose a type of OS image to build. You can choose a debug OS image or a release OS image. You can choose to enable debugger support in either type of OS image. For more information about the type of debugging that you can perform with each type of OS image, see OS Image Types.
