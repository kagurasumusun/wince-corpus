Displaying Permanently the Text-based Menu Bar that is Compatible with a Screen Reader

  1. Choose Options from the Tools menu, and then choose the Workspace tab.
  2. Select the Use Screen Reader Compatible Menus check box.

Platform Builder displays a text-based menu bar at the top of the UI. If you are using this option, you cannot customize the menus by adding graphics.
