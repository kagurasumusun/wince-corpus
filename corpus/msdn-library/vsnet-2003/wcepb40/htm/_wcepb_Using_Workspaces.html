Workspaces

When you create a new platform, you create a workspace also. A workspace can contain multiple projects, including subprojects, but only one platform. A workspace contains the following elements:

  • Each workspace also includes a .wce file, which tracks all the information about the platform.
  • A project file tracks all of the information necessary to create a user feature. A project has a .pbp extension.
  • A subproject is a project that is a dependency of another project. This dependency may consist of shared files, which need to be built in the subproject first, or it may include shared resources that need updating in the subproject first.
  • A platform is a specific implementation of a Windows CE OS on a target device. A workspace can contain only one platform.

After you create a workspace, you can add new projects, new configurations to an existing project or platform, and subprojects.

Platform Builder creates the following files when you create a workspace:

  • A .pbw file, which is used to store information about the workspace, at the workspace level, such as a list of the platform or projects. Use the Open Workspace command to open this file.

You can create a new workspace by using the New Platform Wizard to create a platform, which also creates a workspace.

You can also create a workspace by copying it from another computer. If you want to copy a workspace to a new workspace directory on the current computer, copy the entire workspace directory and sub directories and then modify corresponding directory paths in the .wce file.

If the workspace that you have copied from another computer contains a platform based on microprocessors that are not installed on the current computer, the corresponding configurations will be dimmed in the Select Active Configuration list on the Build toolbar.

If you open a workspace that contains a platform based on microprocessors that you have uninstalled, the corresponding configurations will be dimmed in the Select Active Configuration list on the Build toolbar.
