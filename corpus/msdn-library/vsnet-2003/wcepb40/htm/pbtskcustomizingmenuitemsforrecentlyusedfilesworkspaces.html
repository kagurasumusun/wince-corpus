Customizing Menu Items for Recently Used Files and Workspaces

You can open files and project workspaces that you have used recently by selecting the name of the file or workspace from a menu. You can choose whether the recently used files and workspaces are listed on the File menu or on submenus of the File menu. You can also customize the number of files and workspaces listed.

  1. Choose Options from the Tools menu, and then choose the Workspace tab.
  2. To list recently used files and workspaces on submenus of the File menu, select the Show Recently Used Items On Submenus check box.

    – or –

    To list recently used files and workspaces on the File menu itself, clear the Show Recently Used Items On Submenus check box.

  3. To change the number of recently used files listed, enter the number in the Recent File List Contains box.
  4. To change the number of recently used workspaces listed, enter the number in the Recent Workspace List Contains box.
