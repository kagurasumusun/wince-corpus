Moving Text Using Drag-and-Drop Editing with the Right Mouse Button

  1. Select the text that you want to move.
  2. Use the right mouse button to drag the text to a new location.

    A shortcut menu appears, asking if you want to move or copy the selected text.

  3. At any time during a drag-and-drop operation, you can press the left mouse button to cancel the operation.
