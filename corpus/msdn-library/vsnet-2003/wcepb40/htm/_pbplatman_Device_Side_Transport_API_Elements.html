Device-Side Transport API Elements

The following table shows the API elements that you can use to create the device-side part of a custom transport.

API Description
CreateTransport Returns a pointer to a CTransport object.
CTransport Provides methods to initialize and terminate the device-side part of the transport and to establish a new connection between the desktop computer and the target device.
CConnection Provides methods that exchange data between the desktop computer and the target device after a connection has been established.
