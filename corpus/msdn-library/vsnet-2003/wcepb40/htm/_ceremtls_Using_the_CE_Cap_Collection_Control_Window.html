Remote Call Profiler Collection Control Window

The Remote Call Profiler Collection Control window allows you to control data collection during a profiling run. You can manually turn profiling on and off at any time during the profiling run. You can launch an application and choose whether or not to automatically collect profiling data while the application runs. The Collection Control window also displays a summary of the information collected during the profiling run.

Note   Microsoft recommends that you do not use the Collection Control window and the Remote Call Profiler API functions simultaneously to control data collection.
