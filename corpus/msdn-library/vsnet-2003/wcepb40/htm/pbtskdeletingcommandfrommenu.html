Deleting a Command from a Menu

  1. Display the toolbar that has the command you want to delete.
  2. Choose Customize from the Tools menu, and then choose the Commands tab.

    The Customize dialog box must remain open; however, you can move it.

  3. Select the menu on the toolbar that has the command you want to delete.
  4. Drag the command off the menu.
