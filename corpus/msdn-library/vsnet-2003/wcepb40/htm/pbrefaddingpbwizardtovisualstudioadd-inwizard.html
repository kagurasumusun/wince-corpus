Adding the Platform Builder Add-in Wizard

The Platform Builder Add-in Wizard installs in the correct location when you run Setup for Platform Builder. Once installed, you access the Platform Builder wizard from the Visual C++ Add-in Wizard of Microsoft Visual Studio .NET.

For more information, see Creating Add-ins with the Add-in Wizard.
