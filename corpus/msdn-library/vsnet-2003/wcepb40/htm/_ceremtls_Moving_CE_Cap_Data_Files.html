Remote Call Profiler Data File Sharing

If you want to move an instrumented executable file from the directory in which Remote Call Profiler builds the file to a different directory or analyze Remote Call Profiler data on a computer other than the computer that collected the data, you must ensure that the symbol information associated with the data is available at the new location for the data file. Use one of the following methods to ensure that the symbol information can be accessed:

  • Copy the .icp file, executable files, and symbol information files to a single directory on the computer on which to view the data. For more information, see Copying Profiling Data to a Second Development Workstation.
  • Use the symbol path in the Remote Call Profiler viewer to specify paths to the executable files and symbol information files. In most cases, you must place the executable file and its corresponding symbol information files in the same folder. For more information, see Resolving Symbol Names.
  • Create a summary view data (.icx) file. An .icx file contains the data necessary to open summary views in the Remote Call Profiler viewer. For more information, see Creating a Summary View File.
