Building a CEPC OS Image for Use with an Ethernet Card

  1. Open a command prompt window, and then change to %_WINCEROOT%.
  2. Change to Wince400\Public\Common\Oak\Misc.
  3. At the command prompt, type the following text string. 
    wince x86 i486 CE "Enterprise Terminal" CEPC
  4. Type the following text string. 
    blddemo
  5. Change to %_FLATRELEASEDIR% and edit the Platform.reg file.
  6. Search the Platform.reg file for one of the following text strings, depending on whether the Ethernet card in the Windows CE PC-based hardware development platform (CEPC) is an ISA card or a PCI card. 
    IF CEPC_NE2000_ISA

    – or – 

    IF CEPC_NE2000_PCI
  7. Change the Platform.reg file under HKEY_LOCAL_MACHINE\Comm\NE20001\Parms.

    The following table shows the registry keys to change.

    Registry key Value
    BusType=dword Type 1 for ISA or 5 for PCI.
    InterruptNumber=dword Type the Ethernet card IRQ. This value must be supplied in hexadecimal format.
    IoBaseAddress=dword Type the Ethernet card I/O address. This value must be supplied in hexadecimal format. It is generally displayed in hexadecimal format and must not be converted.
  8. Save the Platform.reg file, and then type one of the following commands at the command prompt in %_FLATRELEASEDIR%. 
    set CEPC_NE2000_ISA=1

    – or – 

    set CEPC_NE2000_PCI=1
  9. Set the environment variable for the display driver that is appropriate for your device.

    For information about environment variables, see Environment Variables.

  10. Type the following text string to create the OS image. 
    makeimg
