Toolbar Creation and Customization

You can create toolbars to work more efficiently. You can include copies of frequently used buttons and menus from existing toolbars or you can create a toolbar for a special purpose, such as one that provides buttons for macros.

You can customize toolbars by deleting buttons or by adding buttons, menus, and commands. If you add a new button, command, or other item to a toolbar that does not have an associated button, button name, or button image, you must create one or more of these items for the new item.

When you delete a default button from a toolbar, the button is still available in the Customize dialog box in the Deleted Commands or All Commands category on the Commands tab. However, when you delete a toolbar button with a custom appearance, its appearance is permanently lost, although the command is still available.

To save a toolbar button with a custom appearance, create a toolbar for storing unused buttons, move the button to this storage toolbar, and then hide the storage toolbar.
