IeXdiEnumDataBreakpoint:IUnknown

This interface implements the Extended Debugging Interface (eXDI) server data breakpoint services for the debugger.

Methods

Method Description
IeXdiEnumDataBreakpoint::Next Retrieves an array of a given number of pointers in the enumerated list.
IeXdiEnumDataBreakpoint::Skip Skips a number of data breakpoint objects in the list.
IeXdiEnumDataBreakpoint::Reset Resets the current position in the enumerated list to the first data breakpoint object.
IeXdiEnumDataBreakpoint::GetCount Returns the total number of data breakpoint objects in the enumerated list.
IeXdiEnumDataBreakpoint::GetNext Returns a pointer to the next data breakpoint object in the enumerated list.
IeXdiEnumDataBreakpoint::DisableAll Disables data breakpoint with objects in the enumerated list.
IeXdiEnumDataBreakpoint::EnableAll Enables data breakpoints with objects in the enumerated list.

Requirements
