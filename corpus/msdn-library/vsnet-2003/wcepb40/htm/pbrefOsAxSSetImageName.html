OsAxSSetImageName

This function specifies the full path to the downloaded image. It is assumed that any modules used in the image will reside in the same directory.

HRESULT WINAPI OsAxSSetImageName(
LPCWSTR szImageName
);

Parameters

szImageName
The name of the downloaded image.

Return Values

This function has the following return values.

Return value Description
S_OK Function is successful.
EXDI_E_OUTOFMEMORY Failed to allocate necessary memory.
EXDI_E_INVALIDARG One or more arguments are invalid.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later osaxs.dll osaxs.h
