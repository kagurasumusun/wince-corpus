Project Folders

Project files are organized into folders in the FileView window of Project view. Platform Builder creates a folder for source files, header files, and resource files. You can reorganize these folders and create new ones. You can use folders to organize explicitly logical clusters of files within the hierarchy of a project. All file folder names should be unique.

Use the File Extensions box of the folder's property page to add a new type of file to a project. If the file name extension of the added file is listed in the File Extensions box for the folder, Platform Builder automatically adds the file to the folder.
