Selecting Output Directories

  1. Choose Settings from the Project menu, and then choose the General tab.
  2. Select the project configuration.
  3. Select the file or project for which you want to set directories

    If you select a project, you can set both intermediate and output directories. If you select a file, you can set only the intermediate directory.

  4. Enter the directory name for the intermediate files, such as .obj files, in the Intermediate Files box.
  5. If you are setting directories for a project, type the directory name for the final output files, such as .exe files, in the Output Files box.
