Displaying Memory Dump Information for a Heap

  1. From the Window menu, choose a heap list window.

    For information about opening a heap list window, see Displaying Heap Information for a Process.

  2. In the heap list window, select a heap.
  3. From the File menu, choose Heap Dump.

    The heap dump window displays memory dump information corresponding to the memory address of the heap that you selected.
