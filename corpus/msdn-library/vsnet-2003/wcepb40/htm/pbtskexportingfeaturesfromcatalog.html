Exporting Features from the Catalog

  1. From the Platform menu, select Export Wizard.
  2. On the Welcome to the Export Wizard page, choose Next.
  3. In the Catalog window, select the feature you want to export, and choose Add. Repeat this step for as many features as you want to add to the installation file.
  4. Choose Next.
  5. Verify the source directories for the features you have exported by expanding the nodes in the tree view. Uncheck any that are incorrect or unneeded.
  6. Choose Add Directory to add an entire folder to your installation file.

    - or -

    Choose Add File to add an individual file to your installation file.

  7. If you want to alter the directory the files will be installed to, select the file or directory and enter the new path in the Destination box.
  8. Choose Next.
  9. On the Catalog Feature File Information page, type the name you want the Catalog feature (.cec) file to have in the File name box.
  10. In the Description box, type a description that will be placed in the .cec file.
  11. In the Vendor box, type your company name.
  12. Choose Next.
  13. On the MSI File Information page, enter the path where the installer package will be created in the Path and file name box.
  14. In the Title box, enter the title for the installation package.
  15. In the Description box, enter a description for the installation package.
  16. In the Locale language list, select the language for the installation package.
  17. If you want to include an End User License Agreement (EULA), select the End User License Agreement check box, and enter the path to the text file containing your EULA in the EULA box.
  18. Choose Next.
  19. Choose Finish to build your installer package
