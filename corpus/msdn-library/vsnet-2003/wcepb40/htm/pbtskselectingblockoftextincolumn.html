Selecting a Block of Text in a Column

  1. Point to the beginning of the text that you want to select.
  2. Press the ALT key and press the left mouse button without releasing it.
  3. Move the mouse to point at the end of the text that you want to select and release the ALT key, and then release the left mouse button.

    When you release the left mouse button, the block of text is selected, and the text is available for cut, copy, delete, and indent operations.

  4. To cancel the column selection, press the left mouse button.
    Note   When you use proportional fonts in the text editor window, the column positions you select in the first line may not correspond exactly to the subsequent lines you select. The text editor selects the character most directly in line with the start and end columns, ignoring the actual character count.
