Error 2004: PDB and DBG Errors

PDB file referenced by an EXE/DLL was not found.  
Full symbol/type resolution may not be possible.

An associated .dbg file that contains required symbolic debugging information for a profiled .exe or .dll file is missing. Some or all of the symbols may not resolve correctly. Place the correct .dbg file in the same folder as the profiled executable, the system symbols path, or a folder specified by the Symbol Path option in the Remote Call Profiler viewer.

File contains no debug information.  Full symbol/type resolution may not be possible.

No symbolic debugging information (.pdb and/or .dbg files) was created for the .exe file that is being profiled. No symbols or types will resolve for the profiled .exe or DLL file. Rebuild the profiled executable with the /Zi compile option to generate a program database (.pdb) file containing the symbolic debugging information.
