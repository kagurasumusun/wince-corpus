Selecting the Supported Transport Layers for an SDK

  1. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.

  2. Choose the Transports tab.
  3. Select the transport layers you want to support in your SDK.

    You can use any or all of the built-in protocols (ActiveSync, PPP, TCP/IP, or KITL) or you can include a custom protocol by choosing the Add button. For more information, see Adding a Custom Transport Layer to an Exported SDK.

    You cannot edit or delete any of the built-in protocols.

  4. Choose OK.
