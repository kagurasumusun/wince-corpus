Running a Macro from the Macro Dialog Box

  1. Choose Macro from the Tools menu.
  2. Select the file containing the macro to run in the Macro File box.

    If this file is not in the list, install the file, and then select it in the Macro File box.

  3. Double-click the macro name that you want to run in the Macro Name box.

    - or -

    Select the macro name that you want to run in the Macro Name box, and then choose Run.
