Defining a Mnemonic Key for a Control Without Command Text

  1. Enter command text for the control by using a static text control.

    In the command text, type an ampersand (&) in front of the letter you want as the mnemonic key.

  2. Verify that the static text control immediately precedes the control it labels in the tab order.
