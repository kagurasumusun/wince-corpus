Bitmap Conversion to a Toolbar

You can create a new toolbar by converting a bitmap to the button image for a toolbar. Usually the bitmap contains several button images on a single bitmap, with one image for each button. Although images can be any size the default is 16 x 16 pixels. You can specify the button image size in the New Toolbar dialog box when you choose Toolbar Editor from the Image menu in the graphics editor.

You can change the command identifiers of the buttons on the new toolbar by using the button property pages.
