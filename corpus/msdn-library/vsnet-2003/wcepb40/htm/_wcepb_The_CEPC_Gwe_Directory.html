MyBSP GWE Directory

The GWE directory contains files that include device-specific code for the Graphics, Windowing, and Events Subsystem (GWES), which is an integrated graphics device interface (GDI), window manager, and event manager. Although most of the functionality for GWES is contained in the precompiled static libraries in Public\Common\Oak\Lib, part of the functionality of GWES is device-specific. The device-specific source code belongs in the GWE directory and is used to build Gwes.exe.

The following table shows the directories included in the GWE directory.

Directory Description
All Sources file that instructs Build.exe to link the components built from the Battery and Nleddrv directories into the Gwe_drv.lib library
Battery Source code files for the battery driver
Buildexe Sources file and other files used to build Gwes.exe by linking all previously built GWES libraries and Coredll
Nleddrv Source code files for the LED driver
