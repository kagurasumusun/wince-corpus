Creating a Device Driver

Be sure that the appropriate workspace is open before you create files for your project.

  1. Choose New Project or File from the File menu.
  2. Choose the Projects tab in the New dialog box.

    If no workspace is open, the Projects tab is not displayed.

  3. Choose WCE Dynamic-Link Library as the type of feature to create.
  4. Type a project name in the Project Name box, and then choose OK.
  5. Choose the kind of DLL project you want to create in the WCE Dynamic-Link Library - Step 1 of 1 dialog box.
  6. Choose Finish.
  7. Choose the FileView tab to display the FileView window.
  8. Expand the list of files for the device driver project.
  9. Edit the appropriate files so that they contain the information necessary for a complete device driver project.
