Public Configuration Directories

The Public directory contains a group of configuration directories for the Windows CE OS. Each configuration directory contains the batch file that defines the environment variables for that configuration and the Build Demo tool, Blddemo.bat, which is used to build the demonstration object files and Cesysgen.bat. The Files directories included in the configuration directories contain binary image builder (.bib) and registry (.reg) files.
