Finding Binary Data

You can search for either ASCII strings or hexadecimal bytes. For example, to find the string Hello, you can search for either Hello or its hexadecimal equivalent, 48 65 6C 6C 6F.

  1. Choose Find from the Edit menu.
  2. Select a previous search string from the Find What list, type the data to find, or type a regular expression to match a pattern.
  3. To match a pattern, choose the button to the right of the Find What box to display a list of regular expressions.

    When you select an expression from this list, it is substituted as the search text in the Find What box. If you use regular expressions, be sure the Regular Expression check box is selected.

  4. Select any of the Find options.
  5. Choose Find Next.
