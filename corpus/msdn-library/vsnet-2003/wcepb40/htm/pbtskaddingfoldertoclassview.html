Adding a Folder to ClassView

The new folder can contain any classes belonging to the project but cannot contain files that are not classes, such as text or resource files. To organize other types of files, go to the related view, for example, FileView or ResourceView.

  1. In the ClassView window, select the project you want to add a folder to.
  2. Right-click, and then choose New Folder from the Shortcut menu.

    You can nest folders under folders you create, but not under a class.

  3. Once you have created a new folder for a project, drag any classes you want to the folder to organize your project classes.

    You cannot move classes from a project to a folder under a different project.
