Development Language Selection for an SDK

Microsoft provides two integrated development environments (IDEs) designed for developing applications for Windows CE-based devices: Visual Studio .NET and eMbedded Visual C++. They consist of an integrated set of windows, tools, menus, toolbars, directories, and other elements to help create, test, and debug a Windows CE-based application.

SDKs support applications written in eMbedded Visual C++ and Visual Studio .NET. Your SDK must be compiled to include support for one or more of these development environments.
