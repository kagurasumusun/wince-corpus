Positioning a Command Button Along the Right or Bottom of the Dialog Box

  1. Select a command button to position.
  2. Choose Arrange Buttons from the Layout menu, and then choose one of the following options:
    • Right, which positions the button along the right edge of the dialog box.
    • Bottom, which positions the button along the bottom edge of the dialog box.

If you select a control other than a command button, its position is not affected.
