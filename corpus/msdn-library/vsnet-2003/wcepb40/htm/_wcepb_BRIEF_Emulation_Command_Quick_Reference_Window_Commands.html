Window Commands

The following table shows BRIEF window command emulation.

BRIEF command Platform Builder text editor command
Center Line in Window WindowScrollToCenter
Change Window WindowSwitchPaneUp, WindowSwitchPaneDown, WindowSwitchPaneLeft, WindowSwitchPaneRight

(A default key binding is not provided for this command)
Create Window WindowSplitHorizontal, WindowSplitVertical
Delete Window WindowDeleteRowUp, WindowDeleteRowDown, WindowDeleteColumnLeft, WindowDeleteColRight
Line to Bottom of Window WindowScrollToBottom
Line to Top of Window WindowScrollToTop
Quick Window Switch WindowSwitchPaneUp, WindowSwitchPaneDown, WindowSwitchPaneLeft, WindowSwitchPaneRight
Resize Window WindowSplit
Zoom Window Toggle WindowMaximize
