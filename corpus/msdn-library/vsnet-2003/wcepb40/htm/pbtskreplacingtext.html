Replacing Text

  1. Move the insertion point to where you want to begin your search.

    The text editor uses the location of the insertion point to select a default search string.

  2. Choose Replace from the Edit menu.
  3. Type the search string or use the list to select from up to 16 previous search strings in the Find What box.
  4. Type the replacement text in the Replace With text box.
  5. Choose the button with the arrow to the right of the box to display a list of tagged expressions that you can use as replacement text.
  6. Select any of the remaining Replace options.
  7. Start the search by choosing the Find Next, Replace, or Replace All button.
