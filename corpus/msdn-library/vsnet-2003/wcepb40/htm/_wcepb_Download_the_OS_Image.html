OS Image Download

The Target menu in the IDE provides functionality that allows you to download an OS image to a target device. Before you download an OS image, you must configure a connection to the target device. For more information about configuring a connection, see Configuring a Connection for Downloading and Debugging.

For information about downloading an OS image to a target device, see Downloading an OS Image to a Target Device. For a target device with flash memory, you can jump to an OS image that already exists in memory. For information about jumping to an OS image, see Jumping to an OS Image on the Target Device.
