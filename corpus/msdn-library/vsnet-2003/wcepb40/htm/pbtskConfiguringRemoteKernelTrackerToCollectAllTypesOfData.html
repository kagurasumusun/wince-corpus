Configuring Remote Kernel Tracker to Collect All Types of Data

The following procedure describes how to configure Remote Kernel Tracker so that it records data such as interrupts, TLB misses, and kernel calls.

To configure Remote Kernel Tracker to collect all types of data

  1. From the Platform menu, choose Settings.
  2. Choose the Build Options tab.
  3. Select the Enable Profiling check box.
  4. Choose OK.
