Command Modifiers

You can specify one or more command modifiers preceding a command, optionally separated by spaces or tabs. As with commands, modifiers must be indented.

The following table shows Nmake.exe command modifiers.

Modifier Description
@command Prevents display of the command. Display by commands is not suppressed. By default, Nmake.exe echoes all executed commands. Use /S to suppress display for the entire .mak file. Use .SILENT to suppress display for part of the .mak file.
–[number ]command Turns off error checking for command. By default, Nmake.exe stops when a command returns a nonzero exit code. If –number is used, Nmake.exe stops if the exit code exceeds number. Spaces or tabs cannot appear between the hyphen and number. At least one space or tab must appear between number and command. Use /I to turn off error checking for the entire .mak file; use .IGNORE to turn off error checking for part of the .mak file.
!command Executes command for each dependent file if command uses $** to specify all dependent files in the dependency or $? To specify all dependent files in the dependency with a later time stamp than the target.
