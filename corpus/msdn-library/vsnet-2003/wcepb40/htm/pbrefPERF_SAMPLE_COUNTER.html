PERF_SAMPLE_COUNTER

This counter provides a count that is either 1 or 0 for each sampling interrupt. The CounterData value represents the number of samples that have a value of 1. The following table shows the details of this counter.

Element Value
X CounterData
Y N/A
Time base N/A
Data Size 4 Bytes
Display Suffix No suffix
Calculation (X1-X0)/(B1-B0)
