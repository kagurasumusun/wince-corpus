Startup Server Additions to an SDK

A startup server provides a mechanism to initiate a connection to a target device. By supporting a startup server in your SDK, you allow Platform Manager to start a Platform Manager transport in eMbedded Visual C++. You must select at least one startup server for your SDK.

For more information about startup servers, and for a complete list of the startup servers that Platform Manager supports, see Startup Server Selection.
