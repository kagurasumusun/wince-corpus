Including an Existing Project As a Subproject

  1. Open the workspace that has the project to which you want to add a subproject.
  2. Choose Dependencies from the Project menu.
  3. Select the project to have the subproject in the Select Project To Modify list.
  4. Select the project on which you want the project to depend in the Dependent On The Following Project(s) box.
  5. Choose OK.
