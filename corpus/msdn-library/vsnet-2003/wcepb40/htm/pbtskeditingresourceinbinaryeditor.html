Editing a Resource in the Binary Editor

  1. Select the byte to edit.

    The TAB key moves the focus between the hexadecimal and ASCII sections of the binary editor. Use the PAGE UP and PAGE DOWN keys to move through the resource one screen at a time.

  2. Type the new value.

    The value changes immediately in both the hexadecimal and ASCII sections.
