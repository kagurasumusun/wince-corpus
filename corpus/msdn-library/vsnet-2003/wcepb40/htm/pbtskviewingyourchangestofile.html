Viewing Your Changes to a File

  1. Select the file with the changes that you want to view.

    You can select only a single file, which you must have checked out. This method reports only the differences between this version and the master version.

  2. Choose Source Control from the Project menu, and then choose Show Differences.

    Your source code control system displays the differences or reports that the files are identical.
