Saving a Screen Image

  1. From the Window menu, choose the window containing the screen image that you want to save.
  2. From the File menu, choose Save as.
  3. Navigate to the directory in which you want to save the file.
  4. In the File name box, type a name for the file.
  5. Choose OK.
