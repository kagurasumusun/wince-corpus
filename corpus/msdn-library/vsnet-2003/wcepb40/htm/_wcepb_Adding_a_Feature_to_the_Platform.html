Additions to a Platform

You can add to a Microsoft Windows CE–based platform by inserting a feature from the Catalog, inserting a project using the Insert command from the Project menu, or using a project wizard to create a project. Files, such as those for audio and video, can be inserted into a platform using the same approach as used for projects.

When you create a project, or add a project, file, or Catalog feature to a platform, it will be included in the final OS image by default. You can control whether an individual feature, project, or file is excluded from the image using the General tab on the Platform Settings dialog box.

By default, the Catalog contains pre-existing Windows CE features. You can extend the Catalog by first creating and then importing Catalog feature files (.cec) into the IDE. Third-party features can also be imported into the Catalog using the Microsoft Installer database files generated by the Export Wizard.

For more information about the Catalog, see Platform Modification and Object Icon Types.
