Creating a Resource Template

  1. From the Project menu, choose Insert, and then choose Resource.
  2. Select a resource from the Resource Type box, and choose New.

    – or –

    Copy a resource from another resource file.

  3. Modify the resource.

    This resource, once saved as a template, can be copied to save effort on positioning controls, inserting text, and so on.

  4. Choose Save As from the File menu.
  5. Select a resource template (.rct) file in the Save As Type list.
  6. Choose Save to save the template.
  7. Repeat all of the previous steps in this procedure for the remaining templates.
