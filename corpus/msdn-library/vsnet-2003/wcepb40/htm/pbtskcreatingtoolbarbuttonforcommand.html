Creating a Toolbar Button for a Command

  1. Display the toolbar to which you want to add a button.
  2. Choose Customize from the Tools menu, and then choose the Commands tab.
  3. Select All Commands in the Category list, and then select the command in the Commands box.
  4. Drag the command to the toolbar.

    If the command does not have a default button, the Button Appearance dialog box appears.

  5. Select a button image for the command from the Images area.

    – or –

    Use a graphics application to create a custom button image.

    – or –

    Create a button with text on it.
