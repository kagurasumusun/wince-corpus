Accessing Kernel Run-Time Information

The eXDI driver can access run-time operating system information by linking to the OSAxS dynamic-link library (DLL). At a minimum, the driver should connect the IeXdiserver::IoCtl method to the OsAxs ReadControl and WriteControl functions.
