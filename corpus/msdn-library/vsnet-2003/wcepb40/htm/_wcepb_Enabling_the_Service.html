Service Enabling

Once each service is configured for the appropriate port, the IOCTL_OAL_REBOOT I/O controller is used to force a warm boot. Upon rebooting, the OAL should examine the arguments area that was set by IOCTL_SET_KERNEL_DEV_PORT. The exact implementation of this will depend on the ports that are supported. For example, a CEPC determines which serial port should be used for initial debugging messages by checking the bootargs structure in the OEMInitDebugSerial function in %_WINCEROOT%\Platform\Cepc\Kernel\Hal\X86\Debug.c.
