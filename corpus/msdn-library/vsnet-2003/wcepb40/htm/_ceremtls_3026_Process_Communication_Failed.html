Error 3026: Process Communication Failed

Process communication error. IceCap.dll cannot communicate with ConPMon.exe. 
Initialization aborted

Communication with the logging control executable file ConPMon.exe was lost during initialization of the process. Use Task Manager to make sure the logging control is off, and then try logging again.
