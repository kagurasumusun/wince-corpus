Control Selection

To size, align, move, copy, or delete controls, you select them and then perform the operation you want. In most cases, you need to select more than one control to use the sizing and alignment tools on the Dialog toolbar.

When you select a control, it has a shaded border with solid or hollow sizing handles, which are small squares that appear in the selection border. When you select multiple controls, the active control has solid sizing handles, and all the other selected controls have hollow sizing handles. In an environment capable of displaying multiple on-screen controls, the active control is the control that will be affected by current cursor movements, commands, and text entry.

When sizing or aligning multiple controls, the dialog editor uses the active control to determine how other controls are sized or aligned. By default, the active control is the last control you selected, but you can change it.
