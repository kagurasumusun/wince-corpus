Public IABASE OAK Directory

The OAK directory contains component files, such as development tools. The following table shows the directories included in the OAK directory.

Directory Description
Files This directory contains the Intltrns directory, which contains files that include localized device-specific strings for supported languages.
Misc Files common to all development projects.
