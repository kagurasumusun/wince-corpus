Controlling Profiling Using the Device Keyboard when Running the Profile-Enabled OS Image

For a CEPC, the keyboard drivers implement various types of profiling control for the following device keys.

  1. Press F8 to start Monte Carlo profiling.

    Received data is transferred to a RAM buffer.

  2. Press F9 to start instrumented kernel profiling.
  3. Press F11 to start Monte Carlo profiling with symbol lookups in the profiler ISR.
  4. Press F12 to stop profiling.
