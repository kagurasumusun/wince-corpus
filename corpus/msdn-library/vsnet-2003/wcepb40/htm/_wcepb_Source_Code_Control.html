Source Code Control

Source code control systems enable you to track changes to source code files during software development. With Microsoft® Platform Builder you can integrate a source code control system into your development environment. If you install a source code control system that conforms to the Microsoft Source Code Control Interface source code control system, you can access source code control functionality directly from the Platform Builder menus.

Certain source code control operations require you to use the applications or features of your installed source code control system. These operations include administrative tasks, such as designating locations for master copies of files, creating network connections, setting permissions for drives and directories, and adding user information and permissions to the source code control system.

If your installed source code control system supports operations in addition to the ones that conform to Microsoft Source Code Control Interface, Platform Builder provides access to these options from the Advanced buttons. Advanced buttons can be found in several dialog boxes, including the Source Control tab of the Options command from the Tools menu, the Add to Source Control dialog box, and the Check In File(s) dialog box of the Source Control command from the Project menu. If no other operations are available, the Advanced buttons either appear dimmed or do not appear.

Until you install a source code control system that conforms to the Microsoft Source Code Control Interface, the source code control menu commands do not appear.

To use Platform Builder integrated source code control:

  • Install a source code control system that conforms to the Microsoft Source Code Control Interface.
  • Complete all of the administrative tasks that are required by your source code control system. These tasks may include designating locations for master versions of files, creating network connections, setting permissions for drives and/or directories, and adding user information and permissions to the system.

Once you have completed the preceding tasks, you can gain access to the Platform Builder integrated source code control commands from buttons on the Standard toolbar.
