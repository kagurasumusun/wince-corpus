OsAxSGetNrS

This function finds the nearest symbol whose base address is less than the given offset. If fAbs is true, the offset is an absolute memory address. Otherwise, it is an offset from the base of the given module. Place the symbol name in the buffer to which szSym points. If fAbs is true and szMod is not NULL, place the name of the module containing the symbol in szMod. If not NULL, szSym and szMod must be caller-allocated buffers, with szSym being at least 256 characters in size, and szMod being at least _MAX_PATH characters in size. Currently, OsAxSGetNrS only knows about public symbols. If the given address falls on a non-public symbol, such as a static variable, the returned symbol will be the nearest public symbol rather than the actual symbol.

HRESULT WINAPI OsAxSGetNrS(
IeXdiServer *pieXdiServer,
int fAbs,
DWORD dwOfs,
WCHAR *szMod,
WCHAR *szSym 
);

Parameters

pieXdiServer
Passes a pointer to the eXDI server.
fAbs
Indicates whether offset is relative to the module base address (fAbs == 0) or absolute base address (fAbs != 0) in Windows CE.
dwOfs
Returns the offset or the absolute address of the symbol.
szMod
Optional. Passes the module name that contains the symbol to locate.
szSym
Passes the symbol name to locate.

Return Values

This function has the following return values.

Return value Description
S_OK Function is successful.
EXDI_E_CANNOTWHILETGTRUNNING Cannot proceed while target is running.
EXDI_E_NOTIMPL Not implemented.
EXDI_E_OUTOFMEMORY Failed to allocate necessary memory.
EXDI_E_INVALIDARG One or more arguments is invalid.
EXDI_E_ABORT Operation aborted.
EXDI_E_FAIL Unspecified failure occurred.
EXDI_E_COMMUNICATION Communication error occurred between host driver and target.
