Property Page

Property pages control the appearance and the behavior of resources and differ according to their purpose. For example, a graphics resource property page contains information on the identifier, language, condition, and file name, as well as a resource preview. But a property page for a command button control in a dialog box contains several tabs of information, each with many style bits to modify the control behavior. When you make a change on a property page, it takes effect immediately. You cannot cancel changes made on a property page.

You can use shortcut keys associated with the text editor to cut, copy, and paste text. In general, you can use these shortcut keys in any edit control on the property page.

You can control the behavior of the Properties window to suit your working style, or the nature of the resource-editing task. Click the Pushpin button in the upper-left corner of the property page to toggle it to one of the states shown in the following table.

The Properties window remains visible even when you are working in another window. Pressing ENTER after you change a value in the Properties window makes the Editing window active, but leaves the Properties window visible.
Pressing ENTER or ESC dismisses the Properties window. This is useful if you want to concentrate on working in an editing window, but need to display the Properties window briefly to change one or two values.
