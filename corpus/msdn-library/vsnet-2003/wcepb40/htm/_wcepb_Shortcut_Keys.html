Shortcut Keys

Shortcut keys offer an alternative method for performing keyboard actions. Some of the commands in Platform Builder are assigned shortcut keys by default.

Use commands in Platform Builder to complete the following actions:

  • Change the existing shortcut key assignments
  • Create new shortcut keys for commands that do not have shortcut keys by default
  • Assign more than one shortcut key for any command
  • Delete shortcut key assignments.
  • Assign shortcut keys for each editor
  • Reset all shortcut keys to their default settings
  • Display the current shortcut keys, including custom key settings and editor emulation
