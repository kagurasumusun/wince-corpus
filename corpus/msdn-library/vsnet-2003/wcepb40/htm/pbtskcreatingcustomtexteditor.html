Creating a Custom Text Editor

  1. Choose Options from the Tools menu.
  2. Choose the Compatibility tab.
  3. Select a standard text editor on which to base your custom text editor in the Current Source Editor Emulation box.

    The Options area lists the text editor's current options.

  4. Select or clear the appropriate check box to create the text editor behavior that you want.

    The name of the custom text editor reflects the name of the standard text editor. For example, if you customize the BRIEF emulation, the custom text editor is named Custom (BRIEF).

  5. Choose OK.
