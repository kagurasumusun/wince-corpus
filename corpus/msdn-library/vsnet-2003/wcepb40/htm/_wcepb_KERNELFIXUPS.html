KERNELFIXUPS

This configuration option specifies whether Romimage.exe relocates sections to which the kernel can write.

KERNELFIXUPS = OFF | ON

Parameters

OFF
The sections to which the kernel can write are not relocated.
ON
By default, the sections to which the kernel can write are relocated to the start of RAM.
