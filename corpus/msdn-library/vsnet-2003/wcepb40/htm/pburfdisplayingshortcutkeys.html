Displaying Shortcut Keys

  • Choose Keyboard Map from the Help menu, and then perform one or more of the following actions in any order:
    • Select Editor, Command, Keys, or Description to sort the shortcut key list alphabetically in different ways.
    • Choose the Copy button to copy the list to the Clipboard so that you can paste the list into a word processor or other text editor.
    • Choose the Print button to print a copy of the list.
    • Select All Commands, Bound Commands, or a category name from the Category list to filter the shortcut key list.
