Converting a Bitmap to a 4-Color Format

Because Microsoft Windows® CE versions 2.0 and later support 8-bit color, color resources for these applications do not require conversion.

  1. Open the image in the resource editor.
  2. Double-click the blank area of the left pane of the graphics editor window to open the Bitmap Properties dialog box.
  3. Choose a number in the Colors drop-down box.

    Select 4 to convert the bitmap to a 4-color image.

    Note   Do not keep two separate image sources to develop for target devices at the same time. If the link flags are set correctly, the images convert automatically between 4-color and 16-color bitmaps during linking.
