Multilingual User Interface

The Multilingual User Interface (MUI) allows users to change the language of the user interface (UI), and can be used for any locale that has a supported code page. A platform developer can use the MUI to generate a single ROM image for multiple target languages and markets.

Note   The system default locale selects certain aspects of the system that may not be completely switched later later. Because of this, it may not be possible to build an MUI that switches between certain languages, especially between multiple East Asian languages, such as between Chinese, Japanese, and Korean. Additionally, locale content that is set in the registry is not switchable, since the values are set when the device boots, and are fixed afterward.

In order for a user to switch languages in a specific device, that device must have the locale data, code pages, and fonts for all the UI languages to be supported. These are configured when the device ROM image is created, or can be added later.

Also, you must set any needed operating system UI resources in ROM, such as the localized resources for the default languages. Additional languages can be included in the device ROM image, or potentially installed later.

The following steps show how to implement a multilingual UI:

  1. Install the MUI APIs. To do this, drag and drop the Multiple Language Support catalog feature from the Catalog window onto the FeatureView display of your platform. For more information, see Adding a Feature from the Catalog.
  2. Create the MUI Modules. To do this, use CREATEMUI<LCID>, Multiui.bib, and *.MUI files. For more information about the MUI Module creation process, see MUI Module Creation. For information about registry settings used in creating the MUI Modules, see Locale Identifiers.
  3. Build a multilingual ROM image. For more information, see Multilingual ROM Image.
