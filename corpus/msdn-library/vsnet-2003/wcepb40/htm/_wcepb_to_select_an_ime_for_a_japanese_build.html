Selecting an IME for a Japanese Build

  1. Create the IME variable in your build environment
  2. Set IME to PIME or TESTIME to add the pocket IME or TESTIME to your OS image, respectively.

    If you do not set IME to PIME or TESTIME in your build environment, Platform Builder selects IME98 by default.
