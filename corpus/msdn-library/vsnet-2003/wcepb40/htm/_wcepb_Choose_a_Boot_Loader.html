Boot Loader Selection

You can use a boot loader to manage the boot process of a target device by initializing the device and by allowing the download service to download an OS image to and start the OS image on the device.

In order to use a download service, you must first port a boot loader for Windows CE to the target device. You can port the boot loader to the target device by using a number of methods, including creating a floppy disk that boots the device or storing the boot loader in flash memory on the device. For more information about a boot loader, see Creating a Boot Loader.

The Ethernet boot loader feature (Eboot.bin) downloads an OS image to a CEPC and starts the OS image on the CEPC. Eboot.bin works with either an Ethernet connection or a parallel port connection.

The files required to create a boot disk for a CEPC are located in the %CEPBDir%\Cepb\Utilities directory. Run Websetup.exe and then run Cepcboot.144 to copy the required data to a boot disk.

To boot an OS image on a custom target device, you must develop your own boot loader. For more information about developing a boot loader, see Boot Loader Development.
