Adding a String Table Entry

  1. Select the new-item box, which is a blank rectangle, at the end of a string segment.
  2. Type the new string.

    When you start typing, the focus shifts to the String property page. The text is entered in the Caption box, and the string is given the next identifier in sequence.

  3. Press ENTER to place the new string in the string table.

Null strings are not accepted in Windows string tables. If you create a null string entry in the string table, the entry is deleted when you close the string editor.
