IeXdiClientNotifyRunChg::NotifyRunStateChange

This method is used to indicate a change in the target's run state.

HRESULT NotifyRunChange(
RUN_STATUS_TYPE ersCurrent,
HALT_REASON_TYPE ehrCurrent,
ADDRESS_TYPE CurrentExecAddress,
DWORD dwExceptionCode
);

Parameters

ersCurrent
[in]Supplies the current run status type.
ehrCurrent
[in]Supplies the current halt reason type.
CurrentExecAddress
[in]Current program or instruction pointer if run status is halted. Otherwise, it is undefined.
dwExceptionCode
[in]Indicates the exception type or source.

Return Values

This method has the following return values.

Return value Description
S_OK Function is successful.
EXDI_E_NOTIMPL Not implemented.
EXDI_E_OUTOFMEMORY Failed to allocate necessary memory.
EXDI_E_INVALIDARG One or more arguments are invalid.
EXDI_E_ABORT Operation aborted.
EXDI_E_FAIL Unspecified failure occurred.
EXDI_E_COMMUNICATION Communication error occurred between host driver and target.
EXDI_E_USEDBYCONCURRENTTHREAD Cannot proceed immediately because resource is already used by concurrent thread.

Remarks

This interface is used in conjunction with the IeXdiServer::StartNotifyingRunChg method. In order to receive notification of run state events, you must create a class that inherits from IeXdiClientNotifyRunChg, and overrides NotifyRunStateChange. A pointer to this class is then passed into a call to IeXdiServer::StartNotifyingRunChg.

All four parameters are passed into the callback when a run state change occurs. None of the parameters are passed back to the system.

The values of ehrCurrent, CurrentExecAddress, and dwExceptionCode are dependent upon the value of the first parameter, ersCurrent. The table below displays when these parameters are valid.
