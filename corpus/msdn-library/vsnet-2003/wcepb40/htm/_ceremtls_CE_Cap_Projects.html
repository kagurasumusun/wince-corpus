Remote Call Profiler Projects

The Remote Call Profiler viewer displays information in a hierarchical structure of projects, processes, and threads. Each project represented in the viewer corresponds to one .icp file. For information about opening an .icp file as a project in the Remote Call Profiler viewer, see Opening a Remote Call Profiler Project.
