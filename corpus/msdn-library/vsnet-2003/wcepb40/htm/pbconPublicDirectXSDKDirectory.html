Public DirectX SDK Directory

The SDK directory contains component files. The following table shows the directories included in the SDK directory.

Directory Description
Inc Header files for SDK components.
Lib Library files for SDK components that are contained in directories with the following formats:

Cpu\Debug

Cpu\Retail

An example is Sh3\Debug.
Samples Sample applications.
