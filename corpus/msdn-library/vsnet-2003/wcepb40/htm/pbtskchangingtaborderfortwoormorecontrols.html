Changing the Tab Order for Two or More Controls

  1. Choose Tab Order from the Layout menu.
  2. Specify where the change in order will begin.

    To do this, hold down the CTRL key and select the control before the one where you want the changed order to begin. For example, if you want to change the order of controls from 7 through 9, select control 6 first.

  3. Double-click the control to set a specific control to number 1, first in the tab order.
  4. Reset the tab order by selecting the controls in the order you want the TAB key to follow.
  5. Press ENTER to exit.
