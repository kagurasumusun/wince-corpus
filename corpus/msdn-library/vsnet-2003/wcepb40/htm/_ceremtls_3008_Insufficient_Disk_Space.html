Error 3008: Insufficient Disk Space

Insufficient disk space to create log file.  Profiling set to 'never'.

Disk full while writing log file. Profiling set to 'off'. Some data was lost.

The hard disk on the development workstation became full before or during the profiling run. The .icp file does not contain complete data for the profiling run.
