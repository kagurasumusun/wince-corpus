ROMSTART

This configuration option specifies the starting address of the ROM image. 

ROMSTART = address

Parameters

address
The starting address, in hexadecimal format, of the ROM image.

Remarks

This configuration option, along with ROMSIZE and ROMWIDTH, defines the .abx data format.
