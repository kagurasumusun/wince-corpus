Creating a Platform Directory

  1. Copy the appropriate sample platform directory, including the subdirectories and their contents, to a new directory.

    The \Platform\Cepc directory contains sample source code for a CEPC.

    The directory name cannot contain the following characters: quotation marks (" and "), backslash (\), pipe (|), slash mark (/), comma (,), colon (:), question mark (?), angle brackets (< and >), or period (.).

    The following code example shows how to copy the contents of the \Platform\Cepc directory to \Platform\MyPlat. 

    cd %_WINCEROOT%\Platform
xcopy Cepc MyPlat /E /V /I
  2. Remove unnecessary subdirectories from your platform directory.

    For example, if your platform will support only MIPS microprocessors, remove all the subdirectories for non-MIPS microprocessors.

  3. Add or modify device driver code for a specific hardware development platform in the \Platform\PlatformName\Drivers directory.
