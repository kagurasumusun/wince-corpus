X86BOOT

This configuration option specifies an initial jump operation code for a boot loader for an x386 or higher microprocessor.

X86BOOT = OFF | ON

Parameters

OFF
By default, there is no initial operation code inserted into the instruction stream.
ON
The initial operation code 0xE9, jump near, is inserted into the instruction stream as the first instruction.
