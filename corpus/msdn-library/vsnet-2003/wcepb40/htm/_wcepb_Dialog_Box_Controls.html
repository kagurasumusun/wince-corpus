Dialog Box Controls

You can add controls to a dialog box by using the Controls toolbar, which enables you to choose the control and to drag it to the dialog box. When displayed, the toolbar stays positioned above other open windows in the workspace.

The fastest way to add controls to a dialog box, reposition existing controls, or move controls from one dialog box to another is to use the drag-and-drop method. The control's position is outlined with a dotted line until it is dropped into the dialog box. When you add a control to a dialog box with the drag-and-drop method, the control is given a default height appropriate to that control type. When you add a control to a dialog box or reposition it, its final placement is determined either by guides and margins, or whether you have the layout grid turned on.

Once you add a control to the dialog box, you can use the property page to change properties, such as command text. There you can select multiple controls and change their properties all at once.

With the dialog editor you can create dialog boxes that include the standard control types shown on the Controls toolbar. By default, the Controls toolbar is displayed when the dialog editor is open, but if you close it before exiting the dialog editor, you must explicitly open it the next time you open the dialog editor.

When you are using the dialog editor, you can toggle the display of the Controls toolbar or the Dialog toolbar by selecting them from the list of available toolbars and windows.

You can add controls to a dialog box by using the Controls toolbar to choose the control, then place the control in the dialog box. You can control properties, such as its identifier, whether it is initially visible at run time, and so on.
