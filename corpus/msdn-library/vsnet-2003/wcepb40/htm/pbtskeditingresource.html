Editing a Resource

  1. Choose the ResourceView tab to see a list of the resources in your project.
  2. Double-click a resource.

    The resource appears in a new window along with the appropriate resource editor. For example, if you double-click a bitmap, the bitmap appears in a new window along with the graphics editor.

  3. Edit your resource using the tools provided by the specified resource editor.
