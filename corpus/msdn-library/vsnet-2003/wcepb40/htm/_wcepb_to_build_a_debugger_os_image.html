Building an OS Image with the Kernel Debugger Enabled

  1. From the Platform menu, choose Settings.
  2. In the Settings For box, choose a debug configuration.
  3. On the Build Options tab, select the Enable Kernel Debugger check box, and then choose OK.
  4. From the Build menu, choose Build Platform.
