Building an SDK

  • From the Platform menu, select Build SDK.

    You must configure the SDK using the Export SDK Wizard before you can build an SDK. For more information, see Exporting an SDK.

The Building Your SDK page displays information regarding the build process and the location of the SDK MSI file. Once the build has completed, choose Finish to complete the export process.
