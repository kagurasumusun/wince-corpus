Public Datasync Directory

The Public Datasync directory contains files for the Datasync project, which supports data synchronization between a Windows-based desktop computer and Windows CE-based portable devices.

Directory Description
Cesysgen Files that are used to build the selected Windows CE modules and components
OAK OS component files
