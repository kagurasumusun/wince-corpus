Displaying Text, an Icon, or Both on a Toolbar Button

  1. Display the toolbar that has the button you want to change.
  2. Choose Customize from the Tools menu.

    The Customize dialog box must remain open; however, you can move it.

  3. Right-click the button that you want to change on the toolbar, and then choose Button Appearance from the shortcut menu.
  4. To display text, choose Text Only or Image And Text, type the text in the Button Text box, and then choose OK.
  5. To display an image, choose Image Only or Image And Text, select an image in the Images area, and then choose OK.

You cannot change the text and icon format for a button that displays a menu when you choose it. When you display text on a toolbar button, the button does not display a ToolTip.
