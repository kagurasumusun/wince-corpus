Directory Setting

Platform Builder provides several options that you can use to set and search the directories for your project files. You can change the directory paths that are searched for certain file types and edit the search order.

Platform Builder searches directories in the order in which they appear in the Directories list. Directory information is stored in registry entries, but you can change the paths or search order within Platform Builder.

The Setup application, Setup.exe, determines the initial directory paths for several file types and updates the Directories list with these paths. The following table shows these file types.

Type Path
Executable files Specifies the location of the build utilities, such as the Microsoft Program Maintenance Utility (Nmake.exe). This tool is also known as the NMAKE tool.
Header files Specifies where the compiler should look for header files, such as Stdio.h.
Library files Specifies where the linker should look for libraries to resolve external references.
Source files Specifies where the debugger should look for default source files, such as Microsoft Foundation Classes (MFC) for Windows CE and run-time libraries.
