Platform Creation with the New Platform Wizard

You can configure your platform using the New Platform Wizard. Through a series of interactive dialog boxes, the New Platform Wizard allows you to perform the following tasks.

  • Choose a preconfigured BSP.
  • Select a base OS configuration for your platform.
  • Select some initial OS features.

After you have chosen your initial settings, the New Platform Wizard sets up the environment with files that support the OS configuration you have selected.

The features included in your platform depend on the OS configuration that you select. You can build a system with little more than a kernel, a system with a complex graphical user interface (UI) and preinstalled applications, or any type of system in between. For information on all the included Windows CE OS configurations, see Selecting a Configuration.
