Project Directory Cleaning

When you run the Clean command, Platform Builder deletes all intermediate files that were created during a build process, for example, .obj and .pch files, as well as output files, such as the .exe or dynamic-link library (.dll) files. The location of these files corresponds to the location specified on the General tab of the Project Settings dialog box, in the Intermediate Files and Output Files boxes.
