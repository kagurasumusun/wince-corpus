Restoring a Deleted Default Menu to a Toolbar

  1. Display the toolbar to which you want to restore the menu.
  2. Choose Customize from the Tools menu, and then choose the Commands tab.
  3. Select Menus in the Category list.
  4. Drag the menu that you want to restore from the Commands box to the toolbar.
