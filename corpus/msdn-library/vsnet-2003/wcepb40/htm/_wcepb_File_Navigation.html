File Navigation

The text editor provides a variety of methods to move around in a source file. In addition to standard Windows navigation, the text editor includes an assortment of commands that enable you to move to almost any location in a file. Furthermore, the text editor includes several advanced navigation features, such as virtual space, matching group delimiters, and matching conditional statements.

You can move between open files with the Window menu, or by pressing CTRL+TAB or CTRL+SHIFT+TAB.
