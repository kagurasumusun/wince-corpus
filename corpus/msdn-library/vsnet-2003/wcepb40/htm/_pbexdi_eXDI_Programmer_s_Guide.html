eXDI Programmer's Guide

The Extended Debugging Interface (eXDI) Programmer's Guide describes how you can create and use eXDI Drivers and eXDI Plug-ins. The following table describes the tools with links to the relevant guide topics.

Tools Description
eXDI Drivers Enables the integrated development environment (IDE) or plug-ins to access a specific target control system.
eXDI Plug-ins Provides additional debugging functionality.
Module Information Access Provides the IDE with module specific information.
