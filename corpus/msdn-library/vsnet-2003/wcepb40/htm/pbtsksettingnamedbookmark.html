Setting a Named Bookmark

  1. Move the insertion point to the line and column where you want Setting a Named Bookmark.
  2. Choose Bookmarks from the Edit menu.
  3. Type a name for the bookmark in the Name box.
  4. Choose Add to add the named bookmark to the list of bookmarks and to set the bookmark at the insertion point.
  5. Choose Close.
