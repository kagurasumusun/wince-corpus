Enabling or Disabling a Breakpoint in the Breakpoints Dialog Box

  1. From the Edit menu, choose Breakpoints, and then find the breakpoint in the Breakpoints list.
  2. Select or clear the check box next to the breakpoint that you want to disable.
  3. Choose OK.
  4. You can also use the SPACEBAR to toggle the state of one or more breakpoints in the Breakpoints list.
