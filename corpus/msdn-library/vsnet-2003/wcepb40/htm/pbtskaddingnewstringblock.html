Adding a New String Block

  1. Open a version information resource.
  2. Choose New Version Info Block from the Insert submenu of the Project menu.

    This command appends an additional string information block into the current version information resource, and then opens the Block Header property page.

  3. On the Block Header property page, choose the appropriate language and character set for the new block.
