eXDI Plug-ins

A plug-in is a stand-alone application that can be launched by the IDE from the Debugger Plug-ins menu bar. The Debugger Plug-ins menu bar does not exist unless at least one plug-in is registered with the IDE. Plug-ins provide a wide array of behavior to eXDI. For example, you can create a plug-in that provides alternative methods for downloading an operating system (OS) image, rather than using a boot loader.

A plug-in must create a window for itself at run time. The plug-in should expose one COM interface, IPluginFn. This interface provides the methods that allow the plug-in to communicate with eXDI. The IPluginFn interface is a custom interface with the following interface identifier:

IID=A7C2D841-183F-11D3-80F3-0000F8040381

The methods that the IPluginFn interface provides allow the IDE to launch and close. You must implement these methods within your plug-in.

You must also register your plug-ins in the HKEY_LOCAL_MACHINE\Software\Microsoft\eXdi\PlugIns registry key. For each plug-in, you must create a registry entry that matches the name that you want to display for the plug-in on the Tools menu in the IDE. You must also specify the CLSID for the plug-in as the value for the registry entry.
