Invoking IntelliSense Options with a Menu Command

  1. Right-click in a source file to view the shortcut menu.
  2. Choose from the following commands from the shortcut menu or the Edit menu:
    • List Members
    • Type Info
    • Parameter Info
    • Complete Word
