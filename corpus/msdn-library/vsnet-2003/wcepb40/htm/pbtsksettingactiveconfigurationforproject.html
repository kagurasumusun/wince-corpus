Setting the Active Configuration for a Project

  1. Choose Workspace from the View menu.
  2. Choose the FileView tab on the Workspace window.
  3. Choose Set Active Configuration from the Build menu, and then select a configuration.

    – or –

    Select a configuration in the Select Active Configuration list on the Build toolbar.

    To view the Build toolbar, point to a blank area on the menu bar, right-click, and then choose Build.
