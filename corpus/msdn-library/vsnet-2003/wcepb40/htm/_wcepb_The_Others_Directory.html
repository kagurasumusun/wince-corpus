Others Directory

The Others directory contains run-time COFF library (.lib) and dynamic-link library (.dll) files, as well as the methods for including them in an OS image. This directory also contains Microsoft Foundation Classes (MFC) for Windows CE, Active Template Library (ATL) for Windows CE header files, registry files, and batch files that are used to add files to an OS image. Pbmerge.exe helps build the OS configuration.

The following table shows the directories included in the Others directory.

Directory Description
ATL Source files for adding ATL run-time files to a platform
DOTNET .NET processor specific binaries and portable Microsoft® .NET Compact Framework Beta Release files
MFC Source files for adding MFC run-time files to a platform
SAMPLES Sample ATL and MFC applications
WCETK The Windows CE Test Kit client (target) files
