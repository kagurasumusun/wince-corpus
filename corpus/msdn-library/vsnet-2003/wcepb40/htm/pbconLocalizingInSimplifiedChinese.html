Simplified Chinese Localization

Three important localization features for Simplified Chinese are fonts, Input Method Editors (IMEs), and input methods (IMs). Platform Builder installs the Simsun TrueType font by default, but also provides the Sunfun TrueType font for the Simplified Chinese locale. The following table shows the IMEs that are included with Platform Builder for Simplified Chinese products.

IME Description
Microsoft Pinyin IME 2.0 for Windows CE An intelligent, bigram-based IME. Platform Builder offers a choice between three distinct lexical databases.
Shuang Pin Pocket IME A compact IME that provides a sample customizable UI model.
Pinyin Pocket IME A compact IME that provides a sample customizable UI model.

For more information about the Simplified Chinese IMEs, see Simplified Chinese Pocket IME and Simplified Chinese Pinyin IME.

In addition to two IMEs, Platform Builder supports the U.S. keyboard for the Simplified Chinese build.

Platform Builder also provides the following IM.

IM Description
Shuang Pin A IM with a soft keyboard that allows Shuang Pin input and is closely tied to the Shuang Pin Pocket IME.

For more information about Simplified Chinese input methods, see Simplified Chinese Input Method.
