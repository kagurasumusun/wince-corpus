Creating a Platform

  1. From the File menu, choose New Platform.

    The New Platform Wizard appears.

  2. Choose Next.

    New Platform Wizard – Step 2, Board Support Packages (BSPs) appears.

  3. Select one or more of the Available BSPs.

    For a complete list and description of the BSPs, see the Board Support Packages.

    The list includes all available BSPs for the CPUs that were selected when the software was installed. The list of supported CPUs is defined in the Catalog feature file (.cec) for each BSP.

  4. On the Board Support Packages page, choose Next.

    New Platform Wizard – Step 3, Platform Configuration appears.

  5. Enter a name for your platform in the Platform Name box.

    You can type a new path for the platform in the Location box or use the Browse button to select a platform directory. The path cannot be longer than 32 characters and cannot contain spaces.

  6. Select a platform configuration from the Available Configurations area, and then choose Next.

    For a complete list and description of configurations, see Included OS Configurations.

  7. If you have selected a platform configuration that includes variants, the variant page for that configuration will appear. Select the configuration variant you want to use, and then choose Next.

    The New Platform Wizard asks you to select the OS features to be included in the platform configuration. A limited selection of features will be presented on one or two pages.

  8. Select the feature you want to include in your platform, and then choose Next.

    - or –

    If you want to accept all the default options that follow, including the Build Options, choose Finish.

  9. The Special Feature Notifications page appears, listing the special notifications associated with the features in your platform. Choose Next.

    A congratulations page appears, with options for ending the wizard.

  10. Choose Done to create the new platform, or select one of the options to proceed.
