Deleting a Performance Counter

  1. Use the unlodctr utility with the .ini and .h files to uninstall the counter information from the registry.

    The unloadctr utility succeeds only if a performance key exists in the Services subkey for the application. For more information, see Removal of Counter Names and Descriptions from the Registry.

  2. Under the Services subkey corresponding to the application, delete the performance key.

    For more information, see Deleting the Application's Performance Key.
