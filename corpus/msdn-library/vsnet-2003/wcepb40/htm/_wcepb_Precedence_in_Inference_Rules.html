Precedence in Inference Rules

If an inference rule is defined multiple times, Nmake.exe uses the highest-precedence definition. The following list shows the order of precedence, from highest to lowest:

  1. An inference rule defined in a .mak file. Later definitions have precedence.
  2. An inference rule defined in Tools.ini. Later definitions have precedence.
  3. A predefined inference rule.
