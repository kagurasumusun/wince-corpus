Modifying the SDK Product Properties

  1. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.

  2. Choose the Product Properties tab.
  3. In the Product Name for MSI installation box, type the product name to generate a new SDK installation.

    - or -

    In the list, choose a name previously used to update an existing SDK installation file.

    The product name is the name that will appear in the Add/Remove Programs dialog box of Control Panel.

  4. In the Manufacture name box, choose the name of your company.
  5. In the Locale language box, choose the language for your SDK.
  6. In the Product version box, enter the project version.

    For more information about these properties, see SDK Installation and Product Properties.

  7. Choose OK.
