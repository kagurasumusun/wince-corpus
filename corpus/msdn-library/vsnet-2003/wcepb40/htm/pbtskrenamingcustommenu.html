Renaming a Custom Menu

  1. Display the toolbar that has the custom menu you want to rename.
  2. Choose Customize from the Tools menu.

    The Customize dialog box must remain open; however, you can move it.

  3. Right-click the custom menu that you want to rename, and then choose Button Appearance.
  4. Type the new menu name in the Button Text box.
  5. To specify a letter as the shortcut key, insert an ampersand (&) before the letter.
