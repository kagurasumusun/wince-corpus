Windows CE Event Tracking Engine

Replacing the engine

To replace the Windows CE event-tracking engine with your own engine, create your own Celog.lib, then re-sysgen.

Retaining the dwCeLogTLBMiss counter

To retain the dwCeLogTLBMiss counter when replacing the Windows CE Tracking Engine, you should declare the counter as follows:

extern dwCeLogTLBMiss;

This counter is incremented whenever a TLB miss occurs. It is occasionally logged as a CELID_SYSTEM_TLB event. The counter is reset by the logging engine after it is logged. The OEM is responsible for resetting the counter to 0 after logging it.

Maintaining DWORD alignment

The default implementation of Celog.lib ensures that all information sent to the "collector" accurately describes the size of the data being sent in bytes. But data is sent in increments of whole DWORDs, so some padding may be added. Before the data can be processed and viewed, the data size must be DWORD aligned.
