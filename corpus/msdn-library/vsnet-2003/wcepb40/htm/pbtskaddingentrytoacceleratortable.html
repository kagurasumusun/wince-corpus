Adding an Entry to an Accelerator Table

  1. Select the last entry in the accelerator table.
  2. Type the key to use as a shortcut key.

    The Accel Properties dialog box appears.

  3. Select an identifier from the ID list and a key in the Key list.
  4. Change the modifier and type, if necessary.

    The modifier specifies whether the key is a combination formed with CTRL, ALT, or SHIFT. The type indicates whether the key is an ASCII or a virtual-key value.

  5. Press ENTER.
