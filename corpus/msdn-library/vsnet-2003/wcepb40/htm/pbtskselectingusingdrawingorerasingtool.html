Selecting and Using a Drawing or Erasing Tool

  1. Select one of the following buttons on the Graphics toolbar:
    • The Eraser tool paints over the graphic with the current background color when you click the left mouse button. When you click the right mouse button, it replaces the current foreground color with the current background color.
    • The Pencil tool draws a constant line width of one pixel.
    • The Brush tool shape and size are determined by the option selector.
    • The Airbrush tool randomly distributes color pixels around the center of the brush.
  2. If necessary, select colors and a brush using one of the following methods:
    • Click the left mouse button to select a foreground color or the right mouse button to select a background color from the Colors palette.
    • Select a shape representing the brush to use in the options selector.
  3. Point to the place on the graphic where you want to start drawing or painting.

    The cursor changes shape according to the tool selected.

  4. Click the left mouse button for the foreground color or the right mouse button for the background color, and hold it as you draw.
