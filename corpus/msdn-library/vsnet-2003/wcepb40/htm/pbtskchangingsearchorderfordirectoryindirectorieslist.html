Changing the Search Order for a Directory in the Directories List

  1. Choose Options from the Tools menu, and then choose the Directories tab.
  2. If necessary, select the microprocessor in the Processor list.
  3. Select the type of files for the directory in the Show Directories For list.
  4. Select the directory that you want to move in the Directories list.
  5. Drag the selected directory to its new position.

Directories are searched in the order in which they appear in the list.
