Creating a Menu Item

Create a menu according to the steps in Creating a Menu on the Menu Bar, or open an existing menu.

  1. Select the menu's new-item box.

    – or –

    Select an existing menu item and press the INS key.

    The new-item box is inserted before the selected item.

  2. Type the menu item name.

    When you start typing, the focus shifts to the Menu Item property page, and the text you type appears in the Caption box.

    You can define a mnemonic key that enables the user to select the menu command. Type an ampersand (&) in front a letter to specify it as the mnemonic key. A user can select the menu command by typing that letter.

  3. On the property page, select the menu item styles that apply.
  4. Type the prompt string in the Prompt box that you want to appear in your application's status bar.

    This creates an entry in the string table with the same resource identifier as the menu item that you created.

  5. Press ENTER to complete the menu item.

    The new-item box is selected so you can create additional menu items.
