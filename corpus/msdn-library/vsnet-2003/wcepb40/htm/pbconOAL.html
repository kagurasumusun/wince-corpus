OAL Development

An OEM adaptation layer (OAL) is the layer between the Windows CE kernel and the hardware of your target device. You create the OAL from the initial configuration of the Windows CE kernel and platform startup through the addition of device-specific functionality and enhancement.

The following list shows some of the elements included in Platform Builder to assist you:

  • Programming guidelines and design information
  • An application programming interface (API)
  • Debugging tools and services
