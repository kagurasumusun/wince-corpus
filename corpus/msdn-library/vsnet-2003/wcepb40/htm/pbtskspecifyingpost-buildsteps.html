Specifying Post-Build Steps

  1. Select the project for which you want to specify the build steps on the FileView tab of the Workspace window.
  2. Choose Settings from the Project menu, and choose the Post-build Step tab.
  3. Enter a description of this step in the Post-build Description box.

    The description that you enter here is echoed to the output window when this step is executed.

  4. Enter your OS batch file commands, environment variables, and build-rule macros in the Post-build Command(s) box.
