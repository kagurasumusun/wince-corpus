Exporting an SDK

  1. Create the platform for which you want to make an SDK.
  2. From the Build menu, choose Generate Platform Headers to generate the platform headers for the OS features.
  3. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard, if you have not run it on the current platform previously.

  4. On the Welcome to the Export SDK Wizard page, choose Next.
  5. On the Product Properties page, type the product name in the Product Name for MSI installation box.

    This is the name that will appear in the Add/Remove Programs dialog box of Control Panel.

  6. In the Manufacture name box, type the name of your company.
  7. In the Locale language box, choose the language for your SDK.
  8. In the Product version area, enter the project version.
  9. Choose Next.

    For more information about these properties, see SDK Installation and Product Properties.

  10. On the Development Languages page, select the development languages your SDK supports.
  11. If you have chosen to support the Microsoft® .NET Compact Framework Beta Release, select the profile for your SDK in the SDK Will Support list.
    Note   The .NET Compact Framework requires certain features be included in the OS image. The selection of a .NET Compact Framework will not be valid without these features to support it.
  12. If you have chosen to support Microsoft eMbedded Visual C++® 4.0, select the development application frameworks you want to support by selecting the appropriate check boxes.
  13. Choose Next.

    The basic configuration of your SDK is now complete.

  14. Choose Build My SDK Now to export your SDK.

    - or -

    Choose Modify the SDK Options to configure additional SDK options.

    For more information about the SDK options available, see Software Development Kit Customization.

    - or -

    Choose Done to continue to work in the IDE.

    You can configure your SDK or build it at another time using the commands available from the Platform menu. If you change your platform, you must run the Generate Platform Headers command again.
