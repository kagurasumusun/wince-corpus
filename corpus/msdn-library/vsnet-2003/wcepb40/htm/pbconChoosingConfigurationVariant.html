Configuration Variants

A configuration variant is a more specific form of a base configuration. After a configuration has been selected as a starting point, you can further refine the platform by selecting one of the configuration variants offered in the New Platform Wizard.

For example, Media Appliance is a category of devices, but it may be implemented as a number of possible media devices. You can target which specific feature set will be included in the initial platform by choosing the specific configuration variant that best implements your required features.

The New Platform Wizard uses configuration variants to determine which features it should include by default while it goes through the steps of creating the platform.

Note   Variants are not available to all base configurations.
