Driver Development

To assist you in creating custom device drivers, Platform Builder includes the following elements that you can use to create Windows CE device drivers:

  • Device driver development guidelines and reference documentation
  • Code samples

The following path shows the location of the Platform Builder device driver code samples: %_WINCEROOT%\Platform\BSP\Drivers.
