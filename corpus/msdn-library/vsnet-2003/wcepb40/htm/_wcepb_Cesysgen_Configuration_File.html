Cesysgen Configuration File

Note   Sysgen.bat calls this tool. Do not call this tool directly. The following documentation is provided for completeness and informational purposes only.

The Cesysgen configuration file (Cesysgen.bat) specifies the environment variables that Nmake.exe uses to create the Windows CE project. Use Cesysgen.bat to specify which Windows CE OS modules and features to install on the target device.

Some modules, such as the OS kernel module (nk), are required. Some features contain selectable features — for example, the file system module (filesys), the Graphics, Windowing, and Events Subsystem (GWES) module (gwes), and the OS core system DLL module (coredll).

To create a customized version of Windows CE, modify a copy of the file Cesysgen.bat in %_PUBLICROOT%\Myproj\Oak\Misc, where Myproj is the Windows CE project. Based on these modifications, Cesysgen.bat sets the value of the feature environment variables.

After Cesysgen.bat sets these environment variables, Sysgen.bat calls Nmake.exe to process these specifications, build the modules, and copy the modules for the OS image.

cesysgen

Example

The following code example shows the default that is used by the Cesysgen.bat file in the %_PUBLICROOT%\IABASE\Oak\Misc directory. 

set COREDLL_COMPONENTS=%COREDLL_COMPONENTS% cryptapi rsa32
set CE_MODULES=%CE_MODULES% rsaenh
if "%SYSGEN_CRYPTO_RSABASE%" == "1" set CE_MODULES=%CE_MODULES% rsabase

Remarks

Each Windows CE OS configuration included in Platform Builder contains specific environment variables that are used to define or exclude certain features.
