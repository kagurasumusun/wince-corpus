_CPUINDPATH

If RELEASETYPE is DDK, OAK, SDK, or PLATFORM, and WINCECPU is not set, which is the case when the source code is microprocessor-independent, _CPUINDPATH specifies a qualifier that defines the CPU-dependent directories. In this release of Platform Builder, this macro definition is the same as _CPUDEPPATH. Do not set this variable.
