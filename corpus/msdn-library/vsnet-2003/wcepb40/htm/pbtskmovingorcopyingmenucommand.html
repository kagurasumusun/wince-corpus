Moving or Copying a Menu Command

  1. Display the toolbar that has the menu command you want to move or copy.
  2. Display the toolbar that has the menu to which you want to move or copy the menu command.
  3. Choose Customize from the Tools menu, and then choose the Commands tab.

    The Customize dialog box must remain open; however, you can move it.

  4. Select the menu on the toolbar that has the menu command you want to move or copy.
  5. To move the menu command, drag it over the menu to which you want to move the menu command.
  6. When the menu displays a list of commands, point to where you want the menu command to appear on the menu, and then release the mouse button.
  7. To copy the menu command, press CTRL, and then drag the menu command to the menu to which you want to copy the command.
  8. When the menu displays a list of commands, point to where you want the menu command to appear on the menu, and then release the mouse button.
