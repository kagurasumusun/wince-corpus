Creating a Command Prompt Build Window

  1. Select the Start button, select Programs, select Accessories, and then select Command Prompt.
  2. At the command prompt, type the following text string. 
    set _PROJECTROOT=<DRIVE:\>Wince400\Public\MyPlatform
  3. Type the following text string. 
    set _FLATRELEASEDIR=<DRIVE:\>Wince400\Release
  4. Type the following text string. 
    set _WINCEROOT=<DRIVE:\>Wince400
  5. Change to %_WINCEROOT\Public\Common\Oak\Misc.
  6. Run Wince.bat.

    The following example shows the syntax for running Wince.bat. 

    Wince.bat CPUFamily CPU CE MyProject MyPlatform
  7. Set additional environment variables as needed.

You can now run the Build Demo tool (Blddemo.bat).
