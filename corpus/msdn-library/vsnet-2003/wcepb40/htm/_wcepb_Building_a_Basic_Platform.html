Platform Creation

When you create a basic platform, you configure the platform, build an operating system (OS) image, transfer the OS image to a target device, and debug the platform.

The following table shows the major steps involved in building a basic platform.

Step Description
Platform Creation with the New Platform Wizard Configure a platform with the New Platform Wizard. You select a board support package (BSP) for your device, choose an OS configuration and variant, and select the features you wish to include with your platform. Some OS configurations may not include a variant or feature selection pages.
Platform Building Build an OS image based on a platform you have configured. To build an OS image, you select a retail or debug build configuration, modify the platform settings as needed, such as enabling kernel debugger, and then build the image.

When you configure a platform, both debug and release configurations are automatically created.
Platform Downloading Download the OS image from your development workstation to a target device, such as a hardware development platform, and then boot the OS.

To download the OS image, you use an OS image file, Nk.bin, and download it over communications hardware, such as an Ethernet, parallel, or serial connection using the integrated development environment (IDE).

Platform Debugging Use kernel debugger to debug code in the Microsoft® Windows® CE .NET kernel as well as Windows CE–based applications. The kernel is the main module of the OS. To use kernel debugger, you need to build a debugger OS image by enabling kernel debugger before you build the image.

In a typical platform development scenario, you build a basic OS image, transfer it to a target, such as a Windows CE PC-based hardware development platform (CEPC), and then refine and debug the platform on the hardware development platform. During the process of refining and debugging the platform, you can customize the platform by altering the features and projects included.

For more information about options for customizing a platform, see Platform Customization.
