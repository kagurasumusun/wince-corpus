Overriding Remote Call Profiler API Functions

Remote Call Profiler offers you three ways to disable Remote Call Profiler API Functions in your code without deleting them.

The SuspendProfile function allows you to disable all profiling for sections of code that contain StartProfile and StopProfile functions. This functionality is useful when you wish to stop profiling a section of code in an external module, but do not want to remove the StartProfile and StopProfile function calls.

The ResumeProfile function cancels the action of a SuspendProfile function and returns the suspend/resume state to ON.

You can also disable the Remote Call Profiler API functions in your application by setting the preprocessor directive profile to zero in the Cecap.h file and then rebuilding the application. You can find the Cecap.h file in the Sdk\Platman\Include directory in the top-level Platman directory for Platform Manager.

The following code example shows how to disable the Remote Call Profiler API functions in the Cecap.h file.

#ifndef PROFILE
#define PROFILE 0
#endif

You can use this functionality to force profiling in an application that contains StartProfile and StopProfile functions. When the Remote Call Profiler API functions are disabled, you can control data collection with the Profile setting in the Icecap.ini file and with the Profiler Status Control window.
