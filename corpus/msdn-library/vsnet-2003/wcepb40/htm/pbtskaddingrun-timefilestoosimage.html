Adding Run-Time Files to a Platform

  1. Choose the FeatureView tab on the Workspace window, and then click to expand the list of the features in the platform.
  2. If the Catalog is not open, choose Catalog from the View menu to display the Catalog window.

    - or -

    Click the Catalog button on the Standard toolbar to display the Catalog window.

  3. Click to expand Core OS and IABASE.
  4. Right-click an implementation in the Catalog, and then select Add to Platform to add the feature to the platform.

    - or -

    Drag an implementation from the Catalog and drop it in the FeatureView window.

    Note   If you include the debug configuration of a dynamic-link library file (.dll), copy the .dll and the corresponding program database file (.pdb) to the %_WINCEROOT%\Public\Myplatform\Wince410\BSP\Cesysgen\Oak\Target\CPUfamily\Debug directory.
    If you include the release configuration of a .dll file, copy the .dll and the release configuration of the corresponding .pdb file to the %_WINCEROOT%\Public\Myplatform\Wince410\BSP\Cesysgen\Oak\Target\CPUfamily\Release directory.
    When the Build Release Directory tool (Buildrel.bat) is run, the .dll and .pdb files are copied to the _FLATRELEASEDIR directory.
  5. Right-click the newly added feature, and then choose Settings.
  6. Choose Release Copy in the Build Step box in the Platform Settings dialog box to see the custom build setting for the feature.

    This setting ensures that the necessary binary files are copied to your release directory, and that the required .bib, .reg, .dat, and .db entries are merged into the Project.bib file in your release directory.

  7. Choose Cancel or OK to close the Platform Settings dialog box.
