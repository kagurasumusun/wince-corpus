Moving or Copying Files from One Workspace to Another

  1. Select the files in the FileView window that you want to move or copy.
  2. Choose Cut from the Edit menu to move the files.

    – or –

    Choose Copy from the Edit menu to copy the files.

  3. Close the current workspace.
  4. Open the destination workspace.
  5. Select the correct project or project folder to receive the files.
  6. Choose Paste from the Edit menu.
