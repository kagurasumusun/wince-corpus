Creating a New Resource from a Template

  1. From the Project menu, choose Insert, and then choose Resource.
  2. Select a resource type, and then double-click the resource icon to create a default resource template object.

    – or –

    Choose the plus sign (+) next to a resource to move through the hierarchy of your customized template files grouped under that resource. Double-click the specific template file to create a new resource based on that customized template.
