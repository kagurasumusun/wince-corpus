Error 2006: Failed to Load Symbols

Failed to load Symbols for ModuleName

The symbol engine was unable to load function name information from the .pdb or .dbg file for the module. Address and offset information will be displayed instead of function names in Remote Call Profiler views. This error is often caused by a failure to load the .exe file for the module. For more information, see Error 2009: Failed to Load Image.
