Modifying Configuration Files to Add a Feature to a Platform

This procedure explains how to modify source code configuration files and image configuration files to add a feature to a platform.

  1. Create a separate directory for the feature.

    The following code example shows how to create the directory called MyComp.

    Note   If you are modifying a platform project directory created using the IDE, the IDE names a subdirectory wince400. Typically, platform project directories created by hand do not contain a wince400 subdirectory.
    cd %_WINCEROOT%\Public\MyProj\wince400
mkdir Mycomp
  2. Copy the Catalog Feature files into this new directory. For information about Catalog Feature files, see Catalog Customization.
  3. Modify or create a dirs file in the MyProj\wince400 directory to include the feature directory.

    The following code example shows a dirs file that includes the MyProj directory. 

    DIRS = \
MyProj
  4. Create a sources file in the MyProj\wince400\MyComp directory to include the feature code files.

    The following code example shows some macro variables that your feature may use. 

    TARGETNAME=MyComp
TARGETTYPE=PROGRAM
TARGETLIBS=$(_COMMONSDKROOT)\lib\$(_CPUINDPATH)\coredll.lib
SOURCES=MyComp.c
EXEENTRY=WinMain
  5. Create a makefile file in the MyProj\wince400\MyComp directory.

    The following code example shows the only executable line in the .mak file. 

    !Include $(_MAKEENVROOT)\makefile.def
  6. Modify the Project.bib file in the MyProj\wince400\Oak\Files directory to include an entry for the executable file.

    The following code example shows a possible entry in the Project.bib file: 

    MODULES
;  Name          Path                                 Memory   Type
:  ------------  --------------------------------------------------
mycomp.exe       $(_FLATRELEASEDIR)\mycomp.exe        NK       S

    This entry loads the Mycomp.exe output file in an area in memory called NK. The file is loaded as a system file in the Windows CE OS image. If you want the feature to start at a particular time during startup, you also must modify the Project.reg file in the MyProj\Wince400\Oak\Files directory.
