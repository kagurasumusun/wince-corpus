Platform Debugging and Testing

The integrated development environment (IDE) is equipped with a variety of tools that allow a user to thoroughly test and debug a platform.

The following table lists the debugging and testing tools included in the IDE, with a brief description of each.

Debugging and testing tool Description
Platform and Application Debugging The kernel debugger controls the behavior of an operating system (OS) image and provides the user with information regarding the performance of that image.

The application debugger controls the behavior of a single application running on a downloaded OS image.
Extended Debugging Interface The Extended Debugging Interface (eXDI) allows the end user to control and debug a target device using a third-party device driver and a hardware probe or emulator.
Emulator The Emulator emulates the behavior of Microsoft® Windows® CE .NET–based platforms built using the IDE on a standard development workstation.
Remote Tools Remote tools allow a user on a development workstation to perform a variety of programming tasks on a Windows CE-based target device, such as downloading a file to the target device and monitoring the status and performance of the target device.
Remote Utility Development A remote utility is a distributed application that resides in part on a target device and in part on a development workstation. The parts of the remote utility communicate with each other over Platform Manager. By using the Platform Manager application programming interface (API), you can develop a remote utility that leverages existing Platform Manager functionality.
Platform Manager Platform Manager manages the communications between a desktop computer and a Windows CE-based target device. Platform Manager allows development tools to download and connect to the target device in a media-independent manner.

The IDE also uses a separate test tool called the Windows CE Test Kit (CETK). This test tool replaces the tool formerly known as the Driver Development Test Kit (DDTK) and improves on the DDTK functionality by incorporating the tests into an easy-to-use user interface (UI). It is provided to assist OEMs in testing the port of their drivers to the OS. This tool is not included in the IDE and must be accessed outside of Platform Builder.

The CETK is located on the Windows Start menu under Programs, in the same location as Platform Builder.

Documentation for this tool is available within the CETK tool itself.
