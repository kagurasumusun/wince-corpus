Error 3009: No Processor Timing Information

This processor cannot be accurately timed with this program.
The processor is either an Intel Clone or is below 80386 level.

Remote Call Profiler requires a CPU that has an x86 architecture to be 80386 or later. Some CPUs do not implement the return of timing information correctly.
