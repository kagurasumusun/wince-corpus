Specifying Custom Build Rules

  1. Choose Settings from the Project menu.
  2. Use the Project Settings box and the Settings for list to select a project, or individual source files or output files, from configurations for which you want to specify a custom build rule or rules.

    By default, a number of file types have rules associated with them, such as a text file containing C or C++ source code (.cxx) files. You cannot specify a custom build rule for these files. If you select files of this type, the Custom Build tab becomes unavailable.

  3. Select the Custom Build tab.

    If you have made multiple selections, the Input File text specifies multiple selections. If the Custom Build Tab is not visible, then Custom Build rules are not applicable to the feature or file that you have selected in the workspace.

  4. Enter a description in the Description box.
  5. Select the first line in the Commands box, and then type the command that you want to run on the input file.

    If you type more than one command in the grid, the build process runs them in order, from top to bottom. The command must include all required options. You may want to use a directory macro to specify the location for the output file.

  6. Select the first line in the Outputs box, and then enter the name of an output file that is created by the build commands that you specified in the Commands box.

    If the commands create more than one output file, type additional names in the subsequent lines of the Outputs box.
