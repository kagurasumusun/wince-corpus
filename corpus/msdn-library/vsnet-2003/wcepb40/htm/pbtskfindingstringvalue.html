Finding a String Value

  1. Choose Find from the Edit menu.
  2. Select a previous search string from the Find What list.

    – or –

    Type the string you want to find.

    – or –

    Type a regular expression to match a pattern.

  3. To match a pattern, choose the button to the right of the Find What box to display a list of regular expressions.

    When you select an expression from this list, it is substituted as the search text in the Find What box. If you use regular expressions, be sure that the Regular Expression check box is selected.

  4. Select any of the Find options.
  5. Choose Find Next.
