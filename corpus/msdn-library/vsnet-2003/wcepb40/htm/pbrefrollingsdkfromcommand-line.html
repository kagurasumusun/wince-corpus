Rolling an SDK from the Command Line

Platform Builder will support a command-line interface to roll an SDK. This is provided to support automation. In order to roll an SDK from the command line, an SDK must have been previously configured and built using the Export SDK Wizard. Any changes to the configuration must be made from the Export SDK Wizard.

The following code example shows how to roll the SDK at the command-line:

CEPB [myproj.wce] /ROLL

Parameters

[myproj.wce]
Specifies the Platform Builder Project for which the SDK should be rolled.
/ROLL
Specifies to Roll the SDK.
