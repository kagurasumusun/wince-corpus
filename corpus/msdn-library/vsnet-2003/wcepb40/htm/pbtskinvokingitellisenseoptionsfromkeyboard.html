Invoking IntelliSense Options from the Keyboard

  1. Press CTRL+ALT+T to view the Members list.
  2. Press CTRL+T to view type info.
  3. Press CTRL+SHIFT+SPACE to view parameter info.
  4. Press CTRL+SPACE Completing the Current Word.

    Pressing CTRL+SPACE on an empty line opens the Members list populated with global variables.

These are default key mappings for the IntelliSense options.
