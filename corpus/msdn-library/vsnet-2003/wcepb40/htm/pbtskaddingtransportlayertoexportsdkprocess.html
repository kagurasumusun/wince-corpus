Adding a Transport Layer to the Catalog

If you want other developers to be able to include your transport layer in their platforms, you can create a Catalog feature file (.cec) and add it to the Catalog.

  1. Use any text editor to create the .cec file for your transport layer.
  2. Save the .cec file in the workspace.

    You can view the .cec file on the FileView tab of the Workspace window.

  3. Choose Manage Catalog Features from the File menu.
  4. Select Import.
  5. Choose the .cec file in the Import Catalog Features dialog box, and then choose Open.
  6. Choose Catalog from the View menu to display the Catalog.

    - or –

    Click the Catalog button on the Standard toolbar to display the Catalog.

  7. Click to expand the entry in the Catalog window that corresponds to the value you specified in the group statement in your .cec file.

    Your newly added feature appears under this entry.
