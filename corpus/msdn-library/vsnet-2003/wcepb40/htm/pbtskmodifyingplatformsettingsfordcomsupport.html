Modifying Platform Settings for DCOM Support

  • Edit the Cesysgen.bat file for your platform, using any text editor.

    The following code example shows what to add to your Cesysgen.bat file to enable support for DCOM. 

    REM // COM and desktop compatible OLE
if not "%IABASE_DCOM%"=="1" goto skipdcom
set DCOM_MODULES=dllhost dcomssd rpcrt4 rpcltccm rpcltscm ole32 oleaut32 uuid
set OLE32_COMPONENTS=dcomole
goto skipole
:skipdcom
set CE_MODULES=%CE_MODULES% uuid ole32 oleaut32
set OLE32_COMPONENTS=ole232 com docfile msf exp
:skipole
