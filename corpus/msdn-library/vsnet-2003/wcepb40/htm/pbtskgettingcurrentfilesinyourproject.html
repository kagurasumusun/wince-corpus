Getting Current Files in Your Project

  1. Select the files that you want to get on the FileView tab of the Workspace window.
  2. Choose Source Control from the Project menu, and then choose Get Latest Version.

    The Get Latest Version dialog box appears, with check marks next to the files that you have selected. The list includes all of the files in the project directory that are in the source code control system.

  3. Select or clear the check box for any files in the list.
  4. Choose OK.

    The source code control system copies all of the selected files with changes by other developers to your local directory.
