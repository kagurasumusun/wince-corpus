Sorting Members in a Class

By default, ClassView groups the members that are displayed under a class in alphabetical order. You can also group class members by their access specifier: private, protected, or public. The sort order applies to all classes in all projects on the workspace.

  1. Select a class member node in any project.
  2. Right-click to display the shortcut menu.
  3. Choose Group By Access to toggle the grouping.

    If the command is checked, the members are grouped by access specifier. If not, they are grouped alphabetically.
