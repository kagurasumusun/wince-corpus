Feature Additions to a Platform

Features are added to a platform by selecting the appropriate feature in the Catalog and dragging it to the FeatureView window or by choosing Add to Platform from the shortcut menu for the feature.

When a feature is added to a platform, the corresponding source code configuration files, makefiles (.mak) files, dirs files, sources files, and header files are built into component files. Cesysgen.bat includes these built component files or corresponding prebuilt component files into the ROM image. These features can be excluded from the image or from being built using the General tab on the Platform Settings dialog box.

When a feature supplied with the integrated development environment (IDE) is added to a platform, Cesysgen.bat is used to perform a dependency checking process, which ensures that any required features will be included in your platform automatically.
