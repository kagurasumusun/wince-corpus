Stamping an OS Image File with a Valid Windows CE Run-time License Number

  1. From the File menu, select License Binary Image.

    The License Binary Image dialog box is displayed.

  2. Type the path for the binary file you want to license in the Select Binary box, or use the browse button to select the binary file.
  3. Type the license key in the License Key (25 digits) box.
  4. Select Stamp Binary to license the binary file.
