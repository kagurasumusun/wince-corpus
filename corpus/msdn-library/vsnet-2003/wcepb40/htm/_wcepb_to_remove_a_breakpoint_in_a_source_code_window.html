Removing a Breakpoint in a Source Code Window

  1. Move the insertion point to the line containing the breakpoint that you want to remove.
  2. Choose the Insert/Remove Breakpoint button on the Build toolbar.

    - or -

  3. Right-click, and then choose Remove Breakpoint from the shortcut menu.
