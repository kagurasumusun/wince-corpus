Configuring the Connection to a Target Device Using Platform Manager

The following procedure sets the properties for a Platform Manager device.

To configure the connection to a target device using Platform Manager

  1. From the Tools menu, choose any remote tool.
  2. From the Connection menu of the remote tool window, choose Configure Windows CE Platform Manager.
  3. Expand the Windows CE .NET Default Platform node.

    - or -

    Expand the node corresponding to your platform.

  4. Select Default Device, and then choose Properties.

    - or -

    If you created a device, select the entry for your device, and then choose Properties.

  5. In the Transport box, choose a transport, and then choose Configure.
  6. Customize the settings for the transport, and then choose OK.
  7. In the Startup Server box, choose a startup server, and then choose Configure.
  8. Customize the settings for the startup server, and then choose OK.
  9. Choose OK.
