Source Code Browsing

The Source Code Browsing feature extends the existing source code control system by allowing the integrated development environment (IDE) to display the location of the primary source code supporting a feature, and in most cases, the code itself. This makes it easier to understand which source code sections contribute to a particular operating system (OS) feature, and speeds the customization of the target device. Source Code Browsing is not intended to allow you to build an OS feature from the FeatureView window.

To use this feature, the source code must be registered in the Catalog, and it must be selected in your platform. For each feature that has source code, the FeatureView window displays all the source projects as a subordinate node. The SOURCES file will be available in the right mouse menu on the project node. The menu will have "Display Sources File".

Syntax

To display source code information in the FeatureView window, the Platform Builder IDE collects a Sysgen variable, the relative path for the directory where the SOURCES file is located, and a project description that the Project View will display. These are imported into the Catalog, and drive the tree control for the feature display.

You import this information into the Catalog for your platform through .cec files, using the #SRCCODE command.

#SRCCODE(type, path[, Description])
type
This allows two build file types, SOURCES and DIRS, which are included for compatibility with earlier Platform Builder versions. These file types are text files that allow the Platform Builder IDE to track what source code is included in a project.
path
This points to the directory containing the SOURCES file that defines the project. If the directory or the SOURCES file is not present, the FeatureView window will not display the node representing the project. The Platform Builder IDE also uses this path when you display the property page for the project or for any source file.
description
This contains the friendly description for the project, which will be displayed in the FeatureView window. The description field is only valid for SOURCES projects.

In the following example, the source code for the File System Manager feature is located in a SOURCES file in the %_WINCEROOT%\… directory.

#SRCCODE(SOURCES,"$(_WINCEROOT)\…", "File System Manager")
