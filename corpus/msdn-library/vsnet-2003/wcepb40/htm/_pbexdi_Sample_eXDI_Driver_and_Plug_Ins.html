eXDI Sample Driver and Plug-ins

The eXDI driver and plug-ins provide five code samples that illustrate how to create plug-ins that can extend the functionality of the debugger and eXDI drivers.

The following table lists the code samples included in eXDI.

Code sample Description
eXDI driver for KdStub Demonstrates a sample driver for the Kernel Debugger Stub (KdStub).

This code sample is located in the %CEPBDir%\Cepb\Exdi\Sampledriver\KdSeXdi1 directory.
eXDI driver for hardware probe Demonstrates how to implement an eXDI driver for the kernel debugger. This sample is designed for a hardware probe and executes properly if the corresponding hardware is available.

This code sample is located in the %CEPBDir%\Cepb\Exdi\Sampledriver\AmcCodeTap directory.
Complex data breakpoint trigger Demonstrates a sample plug-in giving a UI for supporting the full power of eXDI data breakpoints.

This code sample is located in the %CEPBDir%\Cepb\Exdi\Plugins\Cdbp directory.
Memory download and execute Demonstrates alternative methods for downloading — besides using a boot loader — direct memory access.

This code sample is located in the %CEPBDir%\Cepb\Exdi\Plugins\Ramdax directory.
Trace point Demonstrates capturing information when passing through specific memory locations from the target.

This code sample is located in the %CEPBDir%\Cepb\Exdi\Plugins\Tracepoint directory.
