Opening a Log Settings File

  1. From the File menu, choose Open.
  2. Navigate to the directory that contains your log settings file.
  3. In the File name box, enter the name of the .pml file containing the selections that you want to use.

    If there is a log file associated with the log settings file, Remote Performance Monitor starts recording data in that log when the settings file opens.

  4. Choose Open.
