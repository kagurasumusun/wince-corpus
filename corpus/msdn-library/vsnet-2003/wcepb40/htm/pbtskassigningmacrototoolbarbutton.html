Assigning a Macro to a Toolbar Button

  1. Choose Customize from the Tools menu.
  2. Choose the Commands tab.
  3. Select Macros in the Category list.
  4. Drag the macro name from the Commands box to the toolbar where you want a button for the macro.
  5. Select an image for the toolbar button under Images in the Button Appearance dialog box, and then choose OK.

    The IDE adds a button with that image to the toolbar.
