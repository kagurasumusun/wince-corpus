Environment Variables

An environment variable contains information about an aspect of the operating system (OS) environment, such as a drive, path, or configuration string.

When you create a new OS environment with Platform Builder, the integrated development environment (IDE) sets specific environment variables based on the platform settings you select. Once you complete the creation process, you can set or unset the environment variables from a command prompt build window, a batch file, any application in the execution path, or in the IDE itself.

In the IDE, you can set or unset an environment variable in the Environment tab of the Platform Settings dialog box. You can also set the LOCALE and _FLATRELEASEDIR environment variables in the Locale and General tabs of the Platform Settings dialog box.

For more information about using the Platform Settings dialog box, see Customizing a Platform.

The ROM Image Builder tool, Romimage.exe, uses a binary image builder (.bib) file to determine which modules and files to combine when forming the ROM image, and where to place the modules in memory.

The CESYSGEN flags, available for all OS configurations, also control the contents of an OS image.
