MSI-Based Installer Modification

The self-installing Windows installer package (.msi) files contain all the information necessary to install the SDK. The .msi file is a single, convenient package containing all elements of an application installation, including the files installed and any accompanying registry information, dependency data, installation instructions, and so on. If you want to make changes to the installer file, you can do so after the SDK has been generated using any of the standard MSI tools. For more information about modifying an MSI package, see the Windows Installer SDK documentation.
