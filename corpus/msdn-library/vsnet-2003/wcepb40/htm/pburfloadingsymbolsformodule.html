Loading Symbols for a Module

  • Right-click a module in the Modules and Symbols window, and then choose Load Symbols from the shortcut menu.

    - or -

    Choose the Load Symbols button on the window toolbar.

    Note   Load Symbols is only available if the symbols have been unloaded.
