Adding a Custom Menu to a Toolbar

  1. Display the toolbar to which you want to add a custom menu.
  2. Choose Customize from the Tools menu, and then choose the Commands tab.

    The Customize dialog box must remain open; however, you can move it.

  3. Select New Menu in the Category list.

    New Menu appears in the Commands box.

  4. Drag New Menu to the toolbar.

    Platform Builder assigns a default name, such as Custom Menu 1.

  5. To rename the custom menu, right-click the name on the toolbar, and then choose Button Appearance.
  6. Type the new name in the Button Text box.
  7. To specify a letter as the shortcut key, insert an ampersand (&) before the letter.
  8. To add a command to the custom menu, select the menu name on the toolbar to display an empty box.
  9. Select a category for the command in the Category list, and then drag the command from the Commands box to the empty box.
