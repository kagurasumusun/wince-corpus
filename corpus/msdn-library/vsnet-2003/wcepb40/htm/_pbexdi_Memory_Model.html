Memory Model

eXDI assumes that the target platform's memory model consists of one linear virtual address space of 4 GB for all processes, as used by Windows CE .NET. In the case of the x86 microprocessor, it disables memory segmentation, but it uses page translation. There is only one virtual address space at any time for all processes, but you can protect individual processes from one another. The virtual address space is identical for both code and data, for any microprocessor that allows that kind of differentiation.

If virtual memory is not active, the driver should try to access the same address in physical memory.
