Selecting Multiple Controls

  1. Select the pointer on the Controls toolbar.
  2. Drag the pointer to draw a selection box around the controls that you want to select.

    Controls partially outside the selection box are not selected.

  3. When you release the left mouse button, all controls inside the selection box are selected.

    Once you have selected one or more controls, you can add or remove individual controls without disturbing the selection as a whole.

  4. Hold down the SHIFT key and select the control to remove it from the selection or add it to the selection.
