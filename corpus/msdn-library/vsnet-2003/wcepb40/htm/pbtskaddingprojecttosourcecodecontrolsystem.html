Adding a Project to a Source Code Control System

  1. Choose Workspace from the View menu.
  2. Select an existing project on the FileView tab.
  3. Choose Source Control from the Project menu, and then choose Add To Source Control.

    The installed source code control system displays one or more dialog boxes, requesting source code control project information.

  4. Enter the information that is required by the installed source code control system.

    The Add To Source Control dialog box appears, with files in the workspace selected.

  5. To add the files to a source code control system and also check out the files, select the Keep Checked Out check box.
  6. Optionally, type a comment about the files in the Comment text box.
  7. Modify any additional options.

    If your source code control system supports additional options, an Advanced button appears on the Add To Source Control dialog box, which you can choose to modify those additional options.

  8. Choose OK.
