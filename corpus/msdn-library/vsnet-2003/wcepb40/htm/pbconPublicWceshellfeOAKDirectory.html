Public Wceshellfe OAK Directory

The OAK directory contains component files, such as development tools. The following table shows the directories included in the OAK directory.

Directory Description
Ctlpnl Files that provide support for Control Panel applications.
Files This directory contains source files for the Wceshellfe project. It also contains the Intltrns directory, which contains files that include localized device-specific strings for supported languages.
Ftpupdate Files that provide support for the FLASH Update sample application.
Inc Include files.
Inputmethods Files that provide support for input methods.
Lang This directory contains the IME directory, which contains files and directories that provide support for input method editors.
Lib Libraries required in order to build Wceshellfe project components. The libraries are contained in directories with the following formats:
  • Cpu\Debug
  • Cpu\Retail

An example is Sh3\Retail.

Do not include your libraries in this directory.

If you want to modify project-specific files, copy those files into your project tree and then build that project. You must also update the sources file in the code, in order to correctly link with the appropriate library.
Taskman Files that provide support for a sample Task Manager shell.
