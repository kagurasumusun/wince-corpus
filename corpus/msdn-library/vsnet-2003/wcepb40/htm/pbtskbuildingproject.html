Building a Project

  1. Choose the FileView tab on the Workspace window.
  2. Choose Build project or Rebuild All on the Build menu.

    The Build window of the Output Area displays the build progress. Once the build has completed, it will display the total number of errors and warnings found during the build. If there is no activity in the Build window, you can monitor the status from the status bar, which displays the Building icon.
