LDEFSTACK

This macro definition sets stack size above 64 KB. This macro definition applies to all threads in the application. The following code example shows how to set a desired stack maximum of 128 KB.

LDEFSTACK=/STACK:131072

When you create thread stacks that are larger than the default size, the amount of memory available for other threads is decreased. Each thread stack reserves the amount of memory specified in stacksize when it is created, and each process is limited to 32 MB of virtual address space.
