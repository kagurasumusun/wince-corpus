MyBSP Drivers Directory

The Drivers directory contains device drivers for your platform.

The build process typically creates a dynamic-link library (.dll) from the source code in each of these directories, and saves it in Cepc\Target\<cpu>\Debug or Retail, depending on the value of the WINCEDEBUG environment variable.
