Document Windows

Document windows are associated with the project workspace. When you close a project, Platform Builder records the characteristics for the document windows, such as positions, sizes, selections, splitting, and so on. When you open the project again, Platform Builder restores these characteristics.

Document windows include the following types of windows:

  • Editor windows, either for text or resources.
  • The resource browser window (except when it is used for active project resources in the project workspace).

When you are working with documents by using a text editor or other resource editors, you can switch to full-screen mode.

The status bar displays useful information, such as the currently selected menu command or the action of the button currently under the pointer. The status bar also displays progress information about the current operation. In a text editor window, the status bar shows the line and column position of the insertion point, the state of the record keystrokes and column mode, whether the text editor is in insertion mode or overstrike mode, and whether the file is set for read-only access. Additionally, you can display the clock on the status bar.
