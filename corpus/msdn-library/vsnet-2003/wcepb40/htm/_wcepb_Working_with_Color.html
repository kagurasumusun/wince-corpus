Color

The graphics editor includes features that specifically handle and customize colors. You can set a foreground or background color, fill bounded areas with color, or select a color on a graphic to use as the current foreground or background color.

The graphics editor Colors palette includes 16 standard colors. In addition, you can create custom colors. You can save custom color palettes on disk and load them as needed. The Colors palette used most recently is saved and loaded when you restart the IDE.

The Palette tab displays up to 256 colors. Changing colors on the Palette tab immediately changes the corresponding color in the graphic. The colors on the Palette tab are always solid colors and indicate any color that the installed video card can display.

Except for the Eraser, tools on the Graphics toolbar draw with the current foreground or background color when you click the left or right mouse button, respectively.
