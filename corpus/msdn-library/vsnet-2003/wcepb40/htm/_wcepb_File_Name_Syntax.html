File Name Syntax

File name syntax in commands represents features of the first dependent file name, which may be an implied dependent. File name features are the file's drive, path, base name, and extension as specified, and not as it exists on disk. Use %s to represent the complete file name. Use %|[parts]F to represent parts of the file name, where parts can be zero or more of the letters shown in the following table, in any order.

Note   A vertical bar (|) follows the percent sign (%).

The following table shows Nmake.exe file name syntax.

Letter Description
No letter Complete name, which is the same as %s
d Drive
p Path
f File base name
e File extension
