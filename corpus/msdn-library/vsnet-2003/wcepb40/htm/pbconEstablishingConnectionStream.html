Connection Streams

The Platform Manager API exposes an IPMConnectionStream interface that represents a communication stream between a desktop computer and a target device. You can establish such a connection over any communications hardware. For more information about establishing a connection stream with different types of communications hardware, see Transport Selection.

To learn more about connection streams, refer to the TimeViewer sample in the SDK\Samples\Timeviewer directory under the top-level Platman directory for Platform Manager.
