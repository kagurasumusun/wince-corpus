Adding or Removing a .cec File from the Catalog

  1. Open a command prompt build window.
  2. Run Pbcec.exe. The following example shows the syntax for running Pbcec.exe. 
    Pbcec.exe .cecfilename [options]

    You can use one or more of the following options:

    /? Show this help screen

    /r Remove .cec files instead of import

    /silent Silent mode (suppress all output)

    /list Lists all .cec files in the Catalog

    /clean Removes all .cec files from the Catalog

    If there is a syntax error in the .cec file you are adding to the Catalog, you will not be able to import it. An error message is displayed that briefly describes the syntax error.
