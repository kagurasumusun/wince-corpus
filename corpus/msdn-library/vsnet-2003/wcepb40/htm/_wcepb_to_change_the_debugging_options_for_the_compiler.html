Changing the Debugging Options for the Compiler

  1. Choose the FileView tab on the Workspace window.
  2. Choose a project for which you want to change the debugging options.
  3. From the Project menu, choose Settings.
  4. Choose the C/C++ tab.
  5. Select an item in the Category list.
  6. Change your debugging options, and then choose OK.
