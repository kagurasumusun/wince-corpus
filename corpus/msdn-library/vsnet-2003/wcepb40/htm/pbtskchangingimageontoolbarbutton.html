Changing the Image on a Toolbar Button

  1. Display the toolbar that has the button with the image you want to change.
  2. Choose Customize from the Tools menu.

    The Customize dialog box must remain open; however, you can move it.

  3. Right-click the button that you want to change, and then choose Button Appearance on the shortcut menu.
  4. Select the image that you want on the toolbar button in the Images area.

You can change the button so that it has text on it.
