Building an eMbedded Visual C++ 4.0 Application with an Imported SDK

  1. From the Start menu, choose Programs, and then choose eMbedded Visual C++ 4.0.
  2. From the File menu, choose New.
  3. Choose the type of application you want to build on the Projects tab of the New dialog box, type a name in the Project name box, and then choose OK.
  4. Choose the type of application you want to create, and then choose Finish.
  5. Choose OK on the New Project Information dialog box to create the project.
  6. On the Build toolbar, choose the SDK, the type of image you want to build, and the target device.
  7. Choose Build <projectname> from the Build menu to build the project.
