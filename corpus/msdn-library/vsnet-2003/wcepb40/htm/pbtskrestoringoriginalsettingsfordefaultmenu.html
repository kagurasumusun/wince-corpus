Restoring the Original Settings for a Default Menu

  1. Display the toolbar that has the menu for which you want to restore the settings.
  2. Choose Customize from the Tools menu.

    The Customize dialog box must remain open; however, you can move it.

  3. Right-click the menu name on the toolbar, and then choose Reset from the shortcut menu.

    This restores the default menu to its original image, commands, and submenus. Platform Builder restores default submenus to their original form and removes custom submenus.
