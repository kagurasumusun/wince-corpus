CAB Wizard Overview

To install a device driver or application, you must create a cabinet (.cab) file. A .cab file acts as a container, holding all necessary device driver or application files in one location, and thus ensuring that all these files are present at installation time. You create a .cab file by first creating an .inf file, and then using the CAB Wizard command-line tool (Cabwiz.exe) at the command-line prompt. The CAB Wizard can be found in %CEPBDir%\CEPB\Bin.

Note   Cabwiz.exe, Makecab.exe, and Cabwiz.ddf must reside in the same directory on your development workstation.
