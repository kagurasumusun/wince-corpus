Assigning a Toolbar Button to a WizardBar Toolbar Command

  1. Verify that the toolbar on which you want the WizardBar toolbar command to appear is visible.
  2. Choose Customize from the Tools menu, and then choose the Commands tab.
  3. Select WizardBar in the Category list.

    The Commands list displays all of the available WizardBar toolbar commands.

  4. Select a WizardBar toolbar command, and then drag it to the toolbar.
  5. Select the image for the toolbar button in the Button Appearance dialog box, and then choose OK.
