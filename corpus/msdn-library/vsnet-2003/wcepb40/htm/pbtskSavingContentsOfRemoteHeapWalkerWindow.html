Saving the Contents of a Remote Heap Walker Window

  1. From the Window menu, choose the window whose contents you want to save as a text file.
  2. From the File menu, choose Save.
  3. Navigate to the directory in which you want to save the text file.
  4. In the File name box, type a name for the file.
  5. Choose OK.
