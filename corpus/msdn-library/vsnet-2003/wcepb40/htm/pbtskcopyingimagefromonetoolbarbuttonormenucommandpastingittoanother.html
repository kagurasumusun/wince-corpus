Copying an Image from One Toolbar Button or Menu Command and Pasting It to Another

  1. Display the toolbar that has the image you want to copy and the toolbar to which you want to copy the image.
  2. Choose Customize from the Tools menu, and then choose the Commands tab.

    The Customize dialog box must remain open; however, you can move it.

  3. To copy a toolbar button image, right-click the toolbar button that has the image you want to copy, and then choose Copy Button Image from the shortcut menu.
  4. To copy a menu command image, select the menu that has the command image that you want to copy, right-click the menu command, and then choose Copy Button Image from the shortcut menu.
  5. To paste the copied image to a toolbar button, right-click the toolbar button that you want to paste the image onto, and then choose Paste Button Image from the shortcut menu.

    – or –

    To paste the copied image to a menu command, select the menu that has the command to which you want to paste the image, right-click the menu command, and then choose Paste Button Image from the shortcut menu.

You can copy an image from one button to another only if the other button is also on a toolbar - either the same toolbar or a different one. You cannot change a default button image.
