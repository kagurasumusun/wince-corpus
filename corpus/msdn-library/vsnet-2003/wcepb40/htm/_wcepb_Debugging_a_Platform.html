Platform Debugging

You can use the IDE to debug an OS image on a target device. The following table shows the debugging options supported by the IDE.

Debugging Option Description
Kernel Debugger The kernel debugger integrates all of the functionality required to configure device connections and download images to a target device.
Extended Debugging Interface Extended Debugging Interface (eXDI) allows you to control and debug a target device using a third party device driver and a hardware probe or emulator.
