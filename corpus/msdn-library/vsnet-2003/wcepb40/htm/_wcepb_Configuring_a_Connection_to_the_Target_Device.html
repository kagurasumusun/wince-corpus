OS Image Download Considerations

You can download an OS image from a development workstation to a target device by using any communications hardware that Platform Manager supports. You can add support for your hardware to Platform Manager if Platform Manager does not support it. If you cannot use the provided Ethernet, serial, or parallel download service with your hardware, you will also need to create a custom download service. For more information about download services, see Download Service Selection.

For information about hardware that Platform Manager supports and about adding support for other hardware, see Download Service Selection. Before you prepare to download an OS image to a target device with the IDE, consider the following items:

  • Hardware Configuration
  • OS Image Selection
  • Boot Loader Selection
