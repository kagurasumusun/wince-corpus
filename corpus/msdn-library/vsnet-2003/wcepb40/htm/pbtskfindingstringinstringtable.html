Finding a String in the String Table

  1. Open the string table in the ResourceView window by double-clicking the left mouse button on its icon.
  2. Choose Find from the Edit menu.
  3. Select a previous search string from the Find What list, type the command text or resource identifier of the string to find, or type a regular expression to match a pattern.
  4. To match a pattern, choose the button to the right of the Find What box to display a list of regular expressions.

    When you select an expression, it is substituted as the search text in the Find What box. If you use regular expressions, be sure that the Regular Expression check box is selected.

  5. Select any of the Find options.
  6. Choose Find Next.

When a string editor window is displayed, you can add or delete entries in a string table. Horizontal lines in the string editor window separate string table segments.
