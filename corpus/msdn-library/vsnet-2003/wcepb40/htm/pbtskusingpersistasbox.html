Using the Persist As Box

  1. Select the file in the FileView window.
  2. Choose Properties from the shortcut menu, choose the General tab, and then change the string in the Persist As box.

    For example, to add the C:\Basefiles\Mybase.cpp file to a project that is located at C:\Myproject\Project1, change C:\Basefiles\Mybase.cpp to ..\..\Basefiles\Mybase.cpp.

    This requires that all users of the project maintain the same directory structure for the project.

    – or –

    Define an environment variable, such as BASEFILES, that contains C:\Basefiles on the user's computer, and then change the string in the Persist As box from C:\Basefiles\Mybase.cpp to $(BASEFILES)\Mybase.cpp.

The Microsoft Program Maintenance Utility (Nmake.exe) is case-sensitive. You must use uppercase letters for environment variable names. For more information about the Nmake.exe utility, also known as the Nmake tool, see Nmake Tool.
