Modifying Emulation Settings for an SDK

  1. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.

  2. Choose the Emulation tab.
  3. In the Emulation Image box, choose the emulation image you want to use for the SDK.

    You must have included the Emulator BSP in your platform before you can enable Emulator support in your SDK.

  4. If you want to allow application developers to use the Ethernet card on their development workstation to work with the Emulator, select the Ethernet Support check box.

    For more information, see Emulated Hardware.

  5. If you want to allow application developers to map ports from the Emulator to their development workstation, select the Ports Available to be Configured check box.

    For more information, see Emulated Hardware.

  6. If you want the Emulator image to have a fixed window size, select the Fixed Screen Resolution option, and set the screen size and color depth.

    - or -

    Select the Emulator Skins option, and choose Add to select the folder containing your Emulator skins.

    For more information about Emulator Skins, see Emulator Skin.

  7. Choose OK.
