Public Datasync OAK Directory

The OAK directory contains component files, such as development tools. The following table shows the directories included in the OAK directory.

Directory Description
Ctlpanel This directory contains files that provide support for the Control Panel.
Files This directory contains the Intltrns directory, which contains files that include localized device-specific strings for supported languages.
Lib Libraries required in order to build Datasync project components. The libraries are contained in directories with the following formats:
  • Cpu\Debug
  • Cpu\Retail

An example is Sh3\Retail.

Do not include your libraries in this directory.

If you want to modify project-specific files, copy those files into your project tree and then build that project. You must also update the sources file in the code, in order to correctly link with the appropriate library.
