Creating a Cascading Menu

  1. Select the new-item box on the menu where you want the cascading menu to appear, and then, type the name of the menu item that, when selected, will cause the cascading menu to appear.

    When you start typing, the focus shifts to the Menu Item property page, and the text that you type appears in the Caption box.

    – or –

    Select an existing menu item that you want to be the parent item of the cascading menu.

  2. Select the Pop-up check box on the property page.

    This marks the menu item with the cascading menu symbol. A new-item box appears to its right.

  3. Add additional menu items to the cascading menu according to the previous steps in this procedure.
