Enabling the Copy Command to Work on the Current Line Even If There Is No Selection

  1. Choose Options from the Tools menu.
  2. Choose the Compatibility tab, and then select the Enable Copy Without Selection check box.

    This enables the Copy command to work on the current line if there is no selection.
