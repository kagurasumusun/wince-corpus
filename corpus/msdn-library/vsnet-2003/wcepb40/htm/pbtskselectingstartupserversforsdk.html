Selecting the Startup Servers for an SDK

  1. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.

  2. Choose the Startup Servers tab.
  3. Select the startup servers you want to support in your SDK.

    You can use any or all of the built-in startup servers (ActiveSync, CESH, or Manual server) or you can include a custom startup server by choosing the Add button. For more information, see Startup Server Additions to an SDK.

    You cannot edit or delete any of the built-in startup servers.

  4. Choose OK.
