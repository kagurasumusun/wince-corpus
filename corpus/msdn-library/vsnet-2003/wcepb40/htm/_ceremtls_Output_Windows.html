Output Window

The Remote Call Profiler Output window displays messages, warnings, and errors from the .icp file and the Remote Call Profiler viewer.

In the event of an error, Remote Call Profiler displays an error message in a dialog box. To display information about an error message, find the topic that corresponding to the numeric code associated with the message.
