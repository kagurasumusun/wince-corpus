Changing the Magnification Factor

  1. Select the graphics editor pane whose magnification factor you want to change.
  2. Choose the Magnify tool on the toolbar.

    The cursor changes to the Magnify tool, and magnification-factor options appear in the option selector on the Graphics toolbar. If the current magnification factor matches an option, that option is highlighted.

  3. Select the desired magnification factor.

For all graphics editor panes with a magnification factor of 4 or greater, you can display a grid that delimits the individual pixels.
