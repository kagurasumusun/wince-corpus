Microsoft Windows CE .NET  

Public Directory

The Public directory contains the following directories.

Directory Description
Common Windows CE OS component files, common to all Windows CE development projects, as well as directories containing platform-independent libraries, all supplied by Microsoft.
DATASYNC Files and directories for the Datasync project, which contains the components that support data synchronization between a Windows-based desktop computer and Windows CE-based portable devices.
DCOM Files and directories required to add support for Distributed Component Object Model (DCOM) to a platform.
DIRECTX Files and directories for the Directx project, which contains the components that support Microsoft® DirectX®.
HLBASE Files and directories for the HLBASE project, which contains the components that support headless-based devices.
IABASE Files and directories for the IABASE project, which contains the components that support display-based devices
IE Files and directories for the IE project, which contains the components that support the Microsoft Internet Explorer 5.5 for Windows CE modules.
NETCF Files and directories for the Netcf project, which contains the components that support Microsoft® .NET Compact Framework Beta Release.
RDP Files and directories for the RDP project, which contains the components that support the Remote Desktop Protocol (RDP).
SCRIPT Files and directories for the Script project, which contains the components that support Microsoft JScript® 5.5 development system and Microsoft Visual Basic®, Scripting Edition (VBScript) 5.5 programming language.
SERVERS Files and directories for the Hypertext Transfer Protocol (HTTP) Server Extension interface.
SPEECH Files and directories for the Speech project, which contains the components that support the Microsoft Speech Application Programming Interface (SAPI) 5.0.
VIEWERS Files and directories for the Viewers project, which contains the components that support Microsoft File Viewers.
WCEAPPSFE Files for the Japanese version of the Wceapps project which contains the components that support Microsoft WordPad word processing software and Microsoft Inbox electronic messaging software.
WCESHELLFE Files for the Japanese version of the Wceshell project which contains the components that support Microsoft WordPad word processing software and Microsoft Inbox electronic messaging software.
