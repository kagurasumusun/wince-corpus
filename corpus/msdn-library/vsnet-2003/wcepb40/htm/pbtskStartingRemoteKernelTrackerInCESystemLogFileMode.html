Starting Remote Kernel Tracker in File Mode

  1. From the Tools menu, choose Remote Kernel Tracker.
  2. In the Remote Kernel Tracker window, from the File menu, choose Open.
  3. Select a .clg file to open.

    - or -

    In the File name box, type the name of a .clg file to open.

  4. Choose Open.
