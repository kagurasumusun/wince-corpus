Creating a New Toolbar

  1. Choose Customize from the Tools menu, and then choose the Toolbars tab.
  2. Choose New, type a name for the new toolbar in the Toolbar Name box, and then choose OK.
  3. Move the Customize dialog box so that you can see the new toolbar, and then choose the Commands tab.
  4. Select the category that has the item you want to add to the new toolbar in the Category list.
  5. Drag the item to the new toolbar.
