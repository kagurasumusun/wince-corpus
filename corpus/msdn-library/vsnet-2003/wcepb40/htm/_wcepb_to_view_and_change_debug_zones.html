Viewing and Changing Debug Zones

  1. From the Target menu, choose CE Debug Zones.

    – or –

    Right-click the Modules and Symbols window, and then choose Debug Zones from the shortcut menu.

    The Names box in the Debug Zones dialog box displays all of the processes and modules, and the Debug Zones box displays the debug zones for the module at the top of the list.

    – or –

    Right-click a process name in the Processes window, and then choose Debug Zones from the shortcut menu.

    The Names box in the Debug Zones dialog box displays all of the processes and modules, and the Debug Zones box displays the debug zones for the selected process.

  2. In the Name box, select a module or process to display the associated debug zones.

    If you select a terminated process or a module that was previously unloaded, a message to that effect is displayed and the dialog box contents are refreshed.

  3. Select or clear the check boxes in the Debug Zones dialog box to turn debug zones on or off, and then choose Close.

    The changes take effect immediately.
