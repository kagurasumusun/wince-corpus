Platform Manager

Platform Manager is a communications technology that manages the communications between a development workstation and a Microsoft® Windows® CE .NET–based target device. Platform Manager allows development tools to download and connect to the target device in a media-independent manner. Platform Builder, Microsoft eMbedded Visual C++® 4.0, and the Microsoft .NET Compact Framework Beta Release use Platform Manager to download files such as applications, Microsoft ActiveX® controls, run times, and remote-tool clients to the target device.

Platform Manager supports connectivity between a development workstation and a target device at two discrete levels. At one level, Platform Manager supports connectivity between an application on a development workstation and a target device, also known as application connectivity. At a different level, Platform Manager supports connectivity at the kernel level in Platform Builder, also known as kernel connectivity. For more information, see Application Connectivity and Kernel Connectivity.

Platform Manager has two parts: the device-side part, which resides on the target device, and the host-side part, which resides on the development workstation. The device-side part of Platform Manager includes the device-side transport layer files as well as the functionality that enables a tool for Windows CE to access the platform. The tool uses the device-side part of Platform Manager to communicate through the appropriate hardware connection from the development workstation to your target device.
