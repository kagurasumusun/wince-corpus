File Additions to a Platform

Files are added to a platform by inserting an existing project from the Project menu. Files can include any type of file, and including them directly in your platform allows you to add audio, video, and icons.

Note   Do not place .cec files in a dependent project's root directory. If a .cec file is present in the root directory, Buildrel.exe processes that folder regardless of whether the associated components are actually installed. This results in a build process error and halts the build.

If your file requires other features to process it, you must make sure that those features are included in your platform. The file can be excluded from the image or from being built using the General tab on the Platform Setting dialog box. Additionally, you can add custom build settings from the Custom Build tab and define file attributes from the BIB Info tab. These attributes define the file's properties on the target device.

By default, files are entered into CE.bib as files. Files will automatically appear in the Windows directory on your device.
