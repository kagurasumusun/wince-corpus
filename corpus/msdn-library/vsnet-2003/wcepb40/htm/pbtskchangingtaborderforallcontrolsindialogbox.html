Changing the Tab Order for All Controls in a Dialog Box

  1. Choose Tab Order from the Layout menu.

    A number in the upper-left corner of each control shows its place in the current tab order.

  2. Set the tab order by selecting each control in the order you want the TAB key to follow.
  3. Press ENTER to exit.
