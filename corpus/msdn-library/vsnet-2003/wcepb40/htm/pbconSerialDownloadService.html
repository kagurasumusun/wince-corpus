Serial Download Service

The serial download service downloads an OS image to a target device over a serial port connection using the boot loader for Windows CE.

For the serial download service, you cannot configure the device-side settings at run time. However, you can change the baud rate by modifying the code in the OS image and recompiling it. At line 63 in the Halserkitl.c file in the Platform\Cepc\Kernel\Hal directory in the directory where you installed Windows CE, change the value of DEF_BAUD_DIVISOR. To determine the baud rate, divide a rate of 115,200 bits per second by the DEF_BAUD_DIVISOR constant. For example, to set a baud rate of 38,400 bits per second, set DEF_BAUD_DIVISOR to 3.
