String Editor

The string editor enables you to edit your application's string table. A string table is a Windows resource that contains a list of identifiers, values, and command text for all the strings in your application. For example, the status-bar prompts are located in the string table. An application can have only one string table. You can use the Find command to locate specific strings in the string table. You can change the properties of several strings at the same time.

String tables make it easy to localize your application into different languages. If all strings are in a string table, you can localize the application by translating the strings and other resources without changing the source code.

With the string editor, you can edit an application's string table resource. In a string table, strings are grouped into segments, or blocks, of 16 strings. The segment that a string belongs to is determined by the value of its identifier. For example, strings with identifiers from 0 through 15 are in one segment, strings with identifiers from 16 through 31 are in a second segment, and so on. Therefore, when you move a string from one segment to another, you must change its identifier.

Individual string segments are loaded on demand to conserve memory. For this reason, developers usually try to group strings into logical groupings of 16 or less and then use each group or segment only when needed.

You can search for one or more strings in the string table and use regular expressions with the Find command to locate strings that match a pattern. Also, you can select multiple strings and change their properties at the same time.
