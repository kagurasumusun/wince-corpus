Editing a Macro

  1. Choose Macro from the Tools menu.
  2. Select the file containing the macro to edit in the Macro File box.

    If this file is not in the list, install the file, and then select it in the Macro File box.

  3. Select the macro to edit in the Macro Name box.
  4. Choose Edit.
  5. Make the changes you want.
  6. Save the macro file.
