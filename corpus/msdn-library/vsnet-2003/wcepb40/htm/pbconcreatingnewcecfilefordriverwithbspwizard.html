Creating a .cec File for a Driver

You can use the BSP Wizard to create a Catalog feature file (.cec) for a driver that is compatible with a specific BSP. If you want a .cec file for a driver that is not compatible with a specific BSP, you can use the CEC Editor to modify the .cec file that the BSP Wizard has created.

For more information about the BSP Wizard and the CEC Editor, see BSP Wizard Overview and CEC Editor CEC Editor.

To create a BSP-specific Catalog feature file

  1. From the Platform menu, choose BSP Wizard, and then choose Next.

    Choose Add driver to an existing BSP, select a BSP from the list, and then choose Next.

  2. In the Catalog feature (.cec) file name field, enter a file name,
  3. In the Catalog feature (.cec) file directory field, enter a path for the .cec file, and then choose Next.
  4. Choose the Add Driver button, and then, on the Type tab, from the list, select the type of the driver that you are creating a .cec file for.
    Note   Choosing the correct type for the driver informs the IDE about your device's characteristics. Accuracy is important if more than one of this driver type exists in an image or another instance of this driver type exists in an image.
  5. On the General tab, enter the appropriate information into the Name, Vendor, Version, Size, and Description fields.
  6. On the Variables tab, enter any variables associated with the driver by choosing the Add button.
  7. On the Build Info tab, enter the appropriate information into the Full path to the build file that builds this driver and the Registry File to copy to the flat release directory fields.
  8. Choose OK.

    Your driver appears in the Catalog as part of the BSP. You can add other drivers by repeating steps 1 through 10.

  9. Choose Next, and then choose Finish.

To create a nonspecific Catalog feature file

  1. From the Tools menu, choose CEC Editor.
  2. From the File menu, browse for your .cec file, and then choose Open.
  3. In the left pane of the CEC Editor, select your driver, and then, in the right pane, choose the Advanced tab.

    You can modify or remove the value in the BSP Directory field to reflect the BSPs that can use your driver. If you want your driver to be usable with any BSP, leave this field blank.

  4. In the left pane, choose the BSP icon.
  5. In the right pane, select one of the items from the Step list, which indicates when the driver should be built.
  6. In the CPUs field, choose the microprocessors you want to support with your driver.

    - or -

    Choose the Standard button to choose the default CPUs that are installed on the development workstation.

  7. In the Supported Core OS field, choose the OS configurations that you want the driver to support.

    It is recommended that you choose Select All or Select None.

  8. In the left pane, choose the PreMakeImg icon.
  9. In the right pane, select one of the items from the Step list, which indicates when the driver should be built.
  10. In the CPUs field, choose the microprocessors you want to support with your driver.

    - or -

    Choose the Standard button to choose the default CPUs that are installed on the development workstation.

  11. In the Supported Core OS field, choose the OS configurations that you want the driver to support.

    It is recommended that you choose Select All or Select None.

  12. When you have made all of your changes, from the File menu, choose Save.
