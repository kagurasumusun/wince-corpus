Assigning a Macro to a Key Sequence

  1. Choose Customize from the Tools menu.
  2. Choose the Keyboard tab.
  3. Select Macros in the Category list.
  4. Select the macro to which to assign a key sequence in the Commands box.
  5. Enter the key sequence in the Press New Shortcut Key box.
  6. Choose Assign.
