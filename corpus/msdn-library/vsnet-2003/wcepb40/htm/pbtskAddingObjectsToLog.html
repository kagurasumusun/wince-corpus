Adding Objects to a Log

  1. From the Edit menu, choose Add To Log from the Edit menu.
  2. From Objects, select an object or set of objects to monitor, and then choose Add.
  3. Repeat the previous step for any additional devices that you want to monitor, and then choose Done.
