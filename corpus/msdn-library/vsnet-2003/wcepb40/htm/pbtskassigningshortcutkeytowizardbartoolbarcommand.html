Assigning a Shortcut Key to a WizardBar Toolbar Command

  1. Choose Customize from the Tools menu, and then choose the Keyboard tab.
  2. Select WizardBar in the Category list.
  3. Select the command to which you want to assign the shortcut key in the Commands list.

    For more information about the shortcut keys that can be assigned to the WizardBar toolbar commands, see Keyboard Access for the WizardBar Toolbar.

  4. Place the cursor in the Press New Shortcut Key box, press the shortcut key or key combination that you want, and then choose Assign.

    If you press a key or key combination that is invalid, no key appears. You cannot assign key combinations with ESC, F1, or combinations such as CTRL+ALT+DELETE that are being used already by your OS.

    If you press a key or key combination that currently is assigned to another command, that command appears in the dialog box under Currently Assigned To.
