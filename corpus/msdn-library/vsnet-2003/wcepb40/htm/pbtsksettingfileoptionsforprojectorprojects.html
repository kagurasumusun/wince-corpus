Setting File Options for a Project or Projects

  1. Choose Settings from the Project menu, and then choose the General tab.
  2. Expand the project or projects that contain the files for which to specify settings in the Project Settings box.
  3. Select the files, and then, on any of the available tabs, select the options to apply to these files.

    The available tabs depend on the files or configurations that you have selected. Only those tabs with settings common to the selections appear. Similarly, on each tab, only the settings that are common to all of the selected files are available.

If you specify settings that are incompatible with the type of feature you chose when you created the project, you may get unexpected results.
