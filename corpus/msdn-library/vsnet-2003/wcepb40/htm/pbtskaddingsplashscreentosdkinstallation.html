Adding a Splash Screen to an SDK Installation

  1. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.

  2. Choose the Splash Screen tab.
  3. Select the Show OEM splash screen at SDK installation check box.
  4. In the Bitmap box, type the location of the bitmap you want to use or choose Browse to find its location.
  5. In the Duration in seconds box, set the duration for the bitmap to be displayed.
  6. Choose OK.
