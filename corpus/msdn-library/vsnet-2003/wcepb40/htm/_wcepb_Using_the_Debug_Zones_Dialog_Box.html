Debug Zones Dialog Box

The Debug Zones dialog box allows you to view debug zones for processes and modules. You can also turn debug zones on and off from this dialog box.

The following table shows when the Debug Zones menu item and button are enabled.

Condition Enabled
Kernel debugger is attached to the target device, the target device is currently running, and Target Control (CESH) is running. Yes. The Names box and the check box in the Debug Zones box are populated by the Cesh.exe gi mod and gi proc commands. The text fields in the Debug Zones box are populated by the Cesh.exe zo [p|m] index command, where p is for process, m is for modules, and index is the index number from the process or module list.
Kernel debugger is not attached to the target device, the target device is currently running, and Target Control (CESH) is running. Same as in the previous table cell.
Target device is at a debug stop. No
Target device is empty. No
Kernel debugger is attached to target device, the target device is currently running, and Target Control (CESH) is not running. No
The kernel debugger is not attached to the target device, the target device is currently running, and Target Control (CESH) is not running. No
