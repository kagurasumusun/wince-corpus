Viewing the Source Code Where a Breakpoint is Set

  1. From the Edit menu, choose Breakpoints.
  2. Select a location breakpoint in the Breakpoints list.
  3. Choose Edit Code.

    This action takes you to the source code for a breakpoint that is set at a line number or function name. In the case of function names, the debugger must be running for this to work.
