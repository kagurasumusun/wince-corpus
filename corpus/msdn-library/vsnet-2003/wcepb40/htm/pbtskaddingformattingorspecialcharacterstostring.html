Adding Formatting or Special Characters to a String

  1. Select the string to modify.
  2. Choose Properties from the View menu.
  3. Add any of the standard escape sequences to the text in the Caption box.

The following table shows the standard escape sequences.

Special character Escape sequence
New line \n
Carriage return \r
Tab \t
Backslash (\) \\
ASCII character \ddd (octal notation)
Alert (bell) \a
