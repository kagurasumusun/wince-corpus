Creating a New Resource

  1. Choose Resource from the Insert submenu of the Project menu.

    The IDE creates the new resource and assigns it a unique identifier; for example, IDD_Dialog1.

  2. Change the resource identifier by right-clicking the resource, choosing Properties, and entering the new identifier in the ID box of the property page.
