Transport API

The Transport API set is divided between a desktop-side transport interface and a device-side transport interface. The desktop side of the Transport API exposes the ITransport and ITransportConnection interfaces. These interfaces provide functionality that allows you to create a desktop-side transport module. The device side of the Transport API provides a standard dynamic-link library (DLL) file, which exports the CreateTransport function as a single entry point.

In the top-level Platman directory for Platform Manager, the Tl.h and Tl.idl files for the transport interfaces are located in the SDK\Platman\Include directory.
