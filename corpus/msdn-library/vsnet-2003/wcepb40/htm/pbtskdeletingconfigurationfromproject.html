Deleting a Configuration from a Project

  1. Choose Workspace from the View menu.
  2. Choose the FileView tab on the Workspace window.
  3. Choose Configurations from the Build menu.
  4. Expand the project in the Projects And Configurations box from which you want to delete a configuration.
  5. Select the configuration to remove, and then choose Remove.
  6. Choose Yes to remove the configuration, and then choose Close.
