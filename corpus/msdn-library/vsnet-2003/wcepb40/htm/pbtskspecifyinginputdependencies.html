Specifying Input Dependencies

  1. Choose Settings from the Project menu.
  2. Select the project configuration, and then select the file for which you want Specifying Input Dependencies.
  3. Choose the General tab.
  4. Select the Always Use Custom Build Step check box if the file type is already handled by the build system, such as a text file containing .cpp or a resource script (.rc) file.
  5. Choose the Custom Build tab.
  6. Choose the Dependencies button.
  7. Enter all of the input files in the User-defined Dependencies box.
