Subprojects

A subproject is a project that is a dependency of another project. This dependency may consist of shared files, which need to be built in the subproject first, or it may include shared resources that need updating in the subproject first. The dependency relationship is established in the Project Dependencies dialog box.

When the project that builds the feature contains a subproject, the subproject is built first. If the subproject does not build, the feature will not build.

For example, you might build an .exe file that depends on a static library. If the static library is a subproject of the project that builds the .exe file, Platform Builder updates the library before building the .exe file.
