IeXdiClientNotifyMemChg:IUnknown

This interface provides the Extended Debugging Interface (eXDI) methods that implement notification of memory changes for the debugger.

Methods

Method Description
IeXdiClientNotifyMemChg::NotifyMemoryChange Reads from a set of coprocessor registers that define the target's state.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later exdi.idl
