Modifying the Development Language Support for an SDK

  1. From the Platform menu, choose Configure SDK.
  2. This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.
  3. Choose the Development Languages tab
  4. Select the development languages your SDK supports.
  5. If you have chosen to support the Microsoft® .NET Compact Framework Beta Release, select the profile for your SDK in the SDK Will Support box.
  6. If you have chosen to support eMbedded Visual C++® 4.0, select the development application frameworks you want to support by selecting the appropriate check boxes.
  7. Choose OK.
