Checking Out a File

  1. Select the files that you want to check out on the FileView tab of the Workspace window.
  2. Choose Source Control from the Project menu, and then choose Check Out.

    The Check Out File(s) dialog box appears, with check marks next to the files that you have selected.

  3. Optionally, type a comment in the Comment box.

    Not all source code control systems support comments when checking out files. If yours does not, this text box does not appear.

  4. Choose OK.

To be prompted when you check out a file for editing, set the source control option from the Tools menu.
