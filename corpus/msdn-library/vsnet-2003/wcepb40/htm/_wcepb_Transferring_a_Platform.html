Platform Downloading

After you build a platform, you must download the operating system (OS) image that is associated with the platform to a target device. The integrated development environment (IDE) provides a mechanism that allows you to download, using a number of types of communications hardware, an OS image to a target device.

To download an OS image to a target device, you must first configure a connection from a development workstation to the target device. For more information about establishing such a connection, see OS Image Download.
