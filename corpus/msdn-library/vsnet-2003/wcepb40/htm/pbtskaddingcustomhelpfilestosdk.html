Adding Custom Help Files to an SDK

  1. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.

  2. Choose the Help tab.
  3. Select the Include Custom Help Files in the SDK check box.
  4. In the Path to Master CHM (Compiled Help) File box, type the path of the OEMHELP.CHM file.

    - or -

    Choose the Browse button to locate the file.

  5. If your Help file includes links to additional Help files, choose Add, and browse to the file you want to include.

    Each file must be added individually.

  6. Choose OK.
