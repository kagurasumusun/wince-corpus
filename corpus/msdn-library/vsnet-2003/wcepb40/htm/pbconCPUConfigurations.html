CPU Configurations

CPU Configurations contain information about the specific processor your platform uses, and whether it is a debug or a release configuration. An SDK installation must be configured to work on the specific processor for your platform. You must also specify whether the SDK will work against the debug or release configuration of your platform.

The debug version of a platform may contain additional headers and source code, which allow differing functionality from the release version. The SDK incorporates this information to allow access to these additional components.

Note   This information is necessary only for rolling an SDK for eMbedded Visual C++.
