SYNCHRONIZE_DRAIN

If this macro definition is set to 1, Build.exe waits for all earlier directories to finish building before starting the current directory. This macro definition allows you to ensure that all previous .lib files are built prior to building the current directory, which uses all the previous libraries. Because Build.exe automatically determines and handles dependencies, you will rarely use SYNCHRONIZE_DRAIN.
