Using the Kernel Debugger with a Release OS Image

  1. From the Platform menu, choose Settings.
  2. In the Settings For box, choose a release configuration.
  3. From the Platform menu, choose Settings, and then select the Enable Kernel Debugger check box on the Build Options tab.
