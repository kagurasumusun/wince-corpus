OsAxSGetVirtual2PhysAddr

This function translates the virtual address to the corresponding physical address using the kernel tables. ReadVirtualMemory or WriteVirtualMemory should call this function only if directly accessing the translation look-aside buffer (TLB) does not succeed. Only virtual addresses between 0 and 7FFFFFFF can be translated. Kernel pages, when applicable (on microprocessors other than SHX or MIPS), are locked, so they can be read directly through the TLB. On SHX and MIPS, the kernel memory is directly mapped from physical memory to the same address, for example, 0x80000000 to 0x80000000. Note that this function calls back IeXdiServer::ReadVirtualMemory and prevents re-entrance to itself. This function does not check to assure that the translation is currently active or that the OS is in a correct state. This must be checked by the calling procedure.

HRESULT WINAPI OsAxSGetVirtual2PhysAddr(
IeXdiServer *pieXdiServer, 
__int64 va, 
__int64 *ppa 
);

Parameters

pieXdiServer
Passes a pointer to the eXDI server.
va
Passes the virtual address that is to be translated.
ppa
Returns the corresponding physical address.

Return Values

This function has the following return values.

Return value Description
S_OK Function is successful.
EXDI_E_CANNOTWHILETGTRUNNING Cannot proceed while target is running.
EXDI_E_NOTIMPL Not implemented.
EXDI_E_OUTOFMEMORY Failed to allocate necessary memory.
EXDI_E_INVALIDARG One or more arguments is invalid.
EXDI_E_ABORT Operation aborted.
EXDI_E_FAIL Unspecified failure occurred.
EXDI_E_COMMUNICATION Communication error occurred between host driver and target.
