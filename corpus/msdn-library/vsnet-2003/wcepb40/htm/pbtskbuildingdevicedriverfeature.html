Building a Device Driver

  1. Choose the FeatureView tab on the Workspace window.
  2. Right-click the platform icon, and then choose Settings.

    – or –

    Choose Settings from the Platform menu.

  3. Choose the Environment tab.
  4. Type WINCEOEM in the Variable box, and then type 1 in the Value box, to include the paths for the DDK and Oak header files in the build.
  5. Choose Set, and then choose OK.
  6. Choose Build filename.dll from the Build menu to build all of the project files for the device driver.

    If you use this approach, you may have to provide some header files and .lib files. You must be on the FileView tab of the Workspace window, with filename.dll selected.

    – or –

    Choose Build Selected Features from the Build menu to build the project files for the device driver.

    You must be on the FeatureView tab of the Workspace window, with filename.pbp selected.

    – or –

    Choose Build Platform from the Build menu to build the entire platform, including the device driver.

    You must be on the FeatureView of the Workspace window, with the name of the platform selected.
