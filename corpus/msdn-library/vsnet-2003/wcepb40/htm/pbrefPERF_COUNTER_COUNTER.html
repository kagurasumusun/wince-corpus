PERF_COUNTER_COUNTER

The following table shows how PERF_COUNTER_COUNTER tracks the rate of counts. This is the most common counter.

Element Value
X CounterData
Y PerfTime
Time base PerfFreq
Data Size 4 Bytes
Display Suffix /Sec
Calculation (X1-X0)/((Y1-Y0)/TB)
