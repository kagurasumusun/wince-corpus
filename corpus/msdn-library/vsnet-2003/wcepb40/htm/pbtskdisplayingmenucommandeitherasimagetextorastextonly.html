Displaying a Menu Command Either As an Image and Text or As Text Only

  1. Display the toolbar that has the menu command you want to change.
  2. Choose Customize from the Tools menu.

    The Customize dialog box must remain open; however, you can move it.

  3. Select the menu that has the menu command you want to change.
  4. Right-click the menu command that you want to change, and then choose Image Only, Text Only, or Image and Text from the shortcut menu.

Some commands do not have an image associated with them and can only be displayed on a menu as text. A menu command cannot be displayed as an image only.
