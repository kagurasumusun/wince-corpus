OsAxSGetSOf

This function finds the given public symbol, in a specific module, object, or function, if specified. It returns the symbol's absolute address if fAbs is true, or the offset from the base of the module if fAbs is false. If szFct is given, szSrc must also be given. This method must wait for the eXDI driver to retrieve a list of all modules from the target, which could take some time.

HRESULT WINAPI OsAxSGetSOf(
IeXdiServer *pieXdiServer,
int fAbs, 
WCHAR *szSym, 
WCHAR *szMod, 
WCHAR *szSrc, 
WCHAR *szFct, 
DWORD *pdwOfs 
);

Parameters

pieXdiServer
Passes a pointer to the eXDI server.
fAbs
Indicates if offset to be return is relative to the module base address (fAbs == 0) or absolute (fAbs != 0) in Windows CE.
szSym
Name of the symbol to locate.
szMod
Optional. Name of the module that contains the symbol to locate.
szSrc
Optional. Name of the source object that contains the symbol to locate.
szFct
Optional. Name of the function that contains the symbol to locate.
pdwOfs
Returns the symbol's absolute address.

Return Values

This function has the following return values.

Return value Description
S_OK Function is successful.
EXDI_E_CANNOTWHILETGTRUNNING Cannot proceed while target is running.
EXDI_E_NOTIMPL Not implemented.
EXDI_E_OUTOFMEMORY Failed to allocate necessary memory.
EXDI_E_INVALIDARG One or more arguments is invalid.
EXDI_E_ABORT Operation aborted.
EXDI_E_FAIL Unspecified failure occurred.
EXDI_E_COMMUNICATION Communication error occurred between host driver and target.

Requirements
