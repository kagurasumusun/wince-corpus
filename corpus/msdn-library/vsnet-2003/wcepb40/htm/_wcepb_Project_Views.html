Project Views

The IDE can be viewed in Platform view and Project view. Use Platform view to view and modify your platform; use Project view to view and modify a custom feature. Menu items and windows that are applicable only to building projects or platforms are available only from Project view or Platform view respectively. Menu items and toolbars that apply to both platforms and projects are available in both views.

Switch from Platform view to Project view by selecting the corresponding button on the Standard toolbar.

The following table shows the windows that are available in Project view.

Window Description
FileView Displays files that are associated with the projects you have created.
ClassView Displays the classes that are defined in your projects. Expanding the folders shows the classes; expanding a class shows its members.
ResourceView Displays the resource files that are included in your projects. Expanding the resource type folders shows the resources.

The following table shows the windows that are available in Platform view.

Window Description
FeatureView Displays files that are associated with the features that you have created.
ParameterView Displays platform source configuration files for the Common, Hardware Specific, and Project Specific directories.

Switch from one window to another by choosing the tabs in Project or Platform view.

Note   None of these tabs is available for empty projects. Resource view is only available for features that contain resources.
