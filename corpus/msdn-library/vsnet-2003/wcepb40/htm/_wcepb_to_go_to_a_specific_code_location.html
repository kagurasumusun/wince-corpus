Going to a Specific Code Location

  • Right-click a line in the Call Stack window, and then choose Go to Code from the shortcut menu.

    The code location is displayed in either the source window or the Disassembly window, and a green triangle marks the location. A green triangle also marks the line in the Call Stack window.
