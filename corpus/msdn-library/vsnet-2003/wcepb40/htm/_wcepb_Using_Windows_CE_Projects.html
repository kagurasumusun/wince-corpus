Windows CE Projects

The following table shows the projects that contain Windows CE modules and features in Platform Builder.

Project Description
Common Core operating system modules.
Datasync Data synchronization modules.
DirectX Modules that support DirectX, waveform audio, the DVD-Video API, or Windows Media.
IE Internet Explorer 5.5 for Windows CE modules.
NetCF .NET Compact Framework Beta modules
PIM Outlook for Windows CE.
RDP Remote Desktop Protocol modules.
Servers Modules that support the Hypertext Transfer Protocol (HTTP) Server Extension interface.
Script Active Script modules for the Pocket Internet Explorer Internet browser.
Speech Modules that support the Speech Application Programming Interface 5.0.
Viewers Microsoft File Viewer modules.
Wceappsfe Windows CE application modules: WordPad and Inbox.
Wceshellfe Windows CE shell modules: Handheld PC-style shell, Pocket Internet Explorer, Help, Control Panel applications.

Because Windows CE modules are contained in multiple projects, Cesysgen.bat commands include the project name when setting a module, unless the module is in the Common project. The following code example shows the Cesysgen.bat command that would set the control module in the Wceshellfe project:

WCESHELLFE_MODULES=control

When you build a platform, the Master Build tool (Cebuild.exe) runs the Sysgen tool (Sysgen.bat) and the Build tool (Build.exe) in every project identified in the _DEPTREES environment variable. Sysgen.bat creates the modules and features and generates the platform header files; Build.exe builds the source code. If you want to run Sysgen.bat on every project in your platform without building source code, call the following Sysgen.bat command for every project in your platform:

sysgen -p <project>

Alternatively, you can use the following Cebuild.bat command to run Sysgen.bat in all projects specified in _DEPTREES.

cebuild -q
