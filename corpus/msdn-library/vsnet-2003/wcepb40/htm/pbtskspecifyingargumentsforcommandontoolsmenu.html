Specifying Arguments for a Command on the Tools Menu

  1. Choose Customize from the Tools menu, and then choose the Tools tab.
  2. Select the command for which you want to specify arguments in the Menu Contents box.
  3. Type the arguments that you want in the Arguments box.

    – or –

    Select the arrow next to the Arguments box to display a list of macros.

  4. Choose Close.
