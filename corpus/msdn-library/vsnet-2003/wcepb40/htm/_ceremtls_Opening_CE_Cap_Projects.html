Opening a Remote Call Profiler Project

  1. From the File menu of the Remote Call Profiler window, choose Open.
  2. Navigate to the directory in which the .icp file is located.
  3. Select the file.

    - or -

    In the File name box, type the name of the file.

  4. Choose Open.
