Modifying the SDK Installation Properties

  1. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.

  2. Choose the Installation Properties tab.
  3. In the Export SDK to box, type the directory in which you want to place the SDK installation file or choose Browse to find to the location.
  4. In the Platform name box, type the name of your platform.
  5. In the MSI file name box, type a name for the MSI file.
  6. Select Compress files into the MSI database file (more compact) or Leave files uncompressed in installation subfolder (faster).

    The MSI file will contain the entire SDK.

  7. If you want to automatically install the SDK to the current development workstation, select the Run MSI installation locally after successful build check box.

    For more information about these properties, see SDK Installation and Product Properties.

  8. Choose OK.
