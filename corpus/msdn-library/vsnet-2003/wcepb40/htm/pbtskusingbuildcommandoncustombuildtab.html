Using the #BUILD Command on the Custom Build Tab

  1. From the Platform menu, choose Settings to display the Platform Settings dialog box, and then select a feature in the FeatureView window.
  2. Choose the Custom Build tab, and then choose the applicable configuration in the Settings For window.
  3. Choose Feature Build or Release Copy in the Build Step box. The Feature Build option builds the platform. The Release Copy option copies the platform to the _FLATRELEASEDIR directory.
  4. Choose the New icon in the Actions for This Build Step box. The New Build Action dialog box is displayed.
  5. Choose Custom Command in the Action box.
  6. Type the path from which to start executing the command, or select the path using the browse button, in the Path in Which to Start Command box.
  7. Type the full path for the command, including the executable filename, in the Full Path to Command box.
  8. Choose OK to close the New Build Action dialog box.
  9. Choose OK to close the Platform Settings dialog box.
