Error 3007: Maximum Threads Exceeded

Maximum number of profiled threads exceeded.  Some data may have been lost.

The specified maximum number of threads that can be profiled at one time was exceeded during profiling.

You can change the specified maximum with the MaxThreads setting in the Icecap.ini file.
