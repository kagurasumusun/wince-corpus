Enabling or Disabling a Breakpoint in a Source Code Window

  1. Select the line containing the breakpoint that you want to enable or disable.
  2. Right-click, and then choose Enable Breakpoint or Disable Breakpoint from the shortcut menu.

    If the breakpoint is being enabled, the hollow circle in the left margin changes to a red dot.

    - or -

    If the breakpoint is being disabled, the red dot in the left margin changes to a hollow circle.
