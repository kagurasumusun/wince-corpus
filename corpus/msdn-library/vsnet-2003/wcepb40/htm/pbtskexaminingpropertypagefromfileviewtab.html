Examining a Property Page from the FileView Tab

  • Select the file for which you want to examine the property page on the FileView tab of the Workspace window, and then press ALT+ENTER.

    - or -

    Right-click the file on the FileView tab of the Workspace window to display the shortcut menu, and then choose Properties.

    - or -

    Select the file on the FileView tab of the Workspace window, and then choose Properties from the View menu.
