Building Selected Non-Core OS Features

You can choose to build one or more .pbp files, as well as dirs, sources, and .mak files, and prebuilt component files, using the Build Selected Features command. This command is not available for items that are excluded from the build.

  1. Select one or more non-core OS features in the FeatureView window.
  2. Select Build Selected Features from the Build menu.

    - or -

    Right-click, and then choose Build Selected Features from the shortcut menu.
