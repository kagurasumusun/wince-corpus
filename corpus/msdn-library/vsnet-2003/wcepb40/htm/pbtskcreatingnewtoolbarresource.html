Creating a New Toolbar Resource

  1. Choose Resource from the Insert submenu of the Project menu.
  2. Select Toolbar in the Resource Type list, and then choose New.
  3. If a plus sign appears next to the toolbar resource type, select it.

    The plus sign means that toolbar templates are available.

  4. Select a template, and choose OK.
