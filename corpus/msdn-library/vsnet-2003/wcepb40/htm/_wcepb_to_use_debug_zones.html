Using Debug Zones

  1. Define and initialize debug zones in the application source code.

    For information on defining debug zones, see Defining Debug Zones.

  2. Declare a DBGPARAM structure in the source code.

    For information on the DBGPARAM structure, see Declaring a DBGPARAM Structure.

  3. Call the DEBUGREGISTER macro to register the DBGPARAM structure with the debugging subsystem.

    For information on the DEBUGREGISTER macro, see Registering Debug Zones.
