Selecting a Color

  • Choose a color from the Colors palette with the left mouse button to select a foreground color.

    – or –

    Choose a color from the Colors palette with the right mouse button to select a background color.

The graphics editor provides the Fill tool for filling an enclosed graphic area with the current drawing color or the current background color.
