Transport Layer Development

Platform Builder uses a transport layer to communicate between a host computer and a connected device. Platform Builder includes host and server code for TCP/IP and Point-to-Point Protocol (PPP) communications. You can develop your own transport layers, if necessary.

You can use Platform Builder to create a transport layer project. The WCE Transport Layer Wizard creates both host-side and target-side projects. To build the host-side part, you must have eMbedded Visual C++ 4.0 or later installed. Do not change the globally unique identifier (GUID) that is generated by the WCE Transport Layer Wizard for the host-side part.

After you build the host-side part, you must modify the software development kit (SDK) related build methods to include that part in the SDK.
