IPublisherManagement::StopPublishing

This method indicates that the Publish/Subscribe Manager does not want to receive data. The Publish/Subscribe Manager calls this method. For more information about the Publish/Subscribe Manager, see Publisher Characteristics.

HRESULT StopPublishing();

Parameters

None.

Return Values

The following table shows the return values for this method.

Value Description
S_OK The call was successfully completed.
E_FAIL Unable to complete the call.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later CePubSub.idl CEPubSub.h (for desktop), CEPubSubPS.h (for device)
