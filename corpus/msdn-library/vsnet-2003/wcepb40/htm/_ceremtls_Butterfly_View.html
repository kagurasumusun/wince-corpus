Butterfly View

The Butterfly view displays the relationship between calling and called functions in a tabular format.

The Butterfly view displays the following timing data:

  • In the top pane, timing information about instances of the selected function called by the function displayed in the property row.
  • In the center pane, timing information about all instances of a selected function in the data range.
  • In the bottom pane, timing information about instances of the selected function calling the function named in the property row.

The columns of information displayed in each pane of the Butterfly view are independently configured. You can choose the sort order for the caller and called function panes. For more information about sorting, see Sorting Data in the Butterfly View.

For information about opening a Butterfly view window, see Opening a View Window.
