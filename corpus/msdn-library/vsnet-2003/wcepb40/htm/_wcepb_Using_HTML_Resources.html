HTML Resources

An HTML resource is an HTML file stored and compiled as part of your resource script. When you create a new HTML resource, it is included in the resource script of the active project, providing you with access to the HTML page and simplifying distribution of your application.

HTML resources were created to support the CHtmlView class; however, you can insert one into any project just as you would any other Windows resource.

You can use an HTML resource for the following tasks:

  • Creating a Web page using the text editor's syntax coloring for HTML tags.
  • Previewing a Web page as you develop it.
  • Displaying a Web page as the default or home page in your application.
