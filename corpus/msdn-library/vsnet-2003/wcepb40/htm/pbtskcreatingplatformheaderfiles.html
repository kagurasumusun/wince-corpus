Generating Platform Header Files

  • Choose Generate Platform Headers or Regenerate Platform Headers from the Build menu.

    This is necessary only when you want to regenerate platform headers between builds. Cebuild.bat automatically generates platform header files when you choose Build Platform or Rebuild Platform from the Build menu.

    The Generate Platform Headers command will generate platform headers based on changes you have made to your platform, while the Regenerate Platform Headers command regenerates all platform headers.
