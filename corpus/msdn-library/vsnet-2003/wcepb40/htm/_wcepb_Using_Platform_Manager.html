Platform Manager and the SDK

Platform Manager is a communications technology that manages how a desktop computer interacts with a target device. Microsoft eMbedded Visual C++ and Visual Studio .NET operate through Platform Manager to download applications and OS images to your target device. Platform Manager also connects your target device to debugging tools that are available on the desktop computer.

You can create an SDK that provides information to Platform Manager about the tools and transport options Platform Builder has included on the target platform. Your SDK must contain at least one transport layer for communication with the device. For more information about Platform Manager, see Platform Manager.
