Configuring eXDI Hardware-Assisted Debugging

  1. Install the eXDI driver provided by the third-party probe or emulator vendor.
    Note   A new driver installation for a different probe overrides any previously installed driver.
  2. From the Target menu, choose Configure Remote Connection.
  3. Choose the Services tab, and then select the Use Hardware Debugger check box.
  4. In the Select eXdi Driver box, choose the appropriate eXdi driver, and then choose OK.
    Note   The Use Hardware Debugger choice is available only if an eXDI driver is installed. Driver installation sets a registry value that causes the Use Hardware Debugger choice to appear in the list.
    These settings are saved on a per-user basis, not by project. If you change projects, you must reset these values accordingly. The hardware debugger can communicate over any connection that the third-party driver supports. The driver itself may require some additional configuration that is not required by Platform Builder at this stage.
