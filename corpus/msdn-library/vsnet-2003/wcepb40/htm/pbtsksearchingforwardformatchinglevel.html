Searching Forward for a Matching Level

  • Use the key combination you have chosen to invoke the LevelDown command.

    The command begins searching for one of the opening delimiters. When it is found, the cursor is positioned at the matching closing delimiter. If a matching delimiter is not found, the text editor beeps.
