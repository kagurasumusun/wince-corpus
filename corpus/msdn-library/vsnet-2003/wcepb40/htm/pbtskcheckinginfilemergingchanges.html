Checking In a File and Merging Changes

  1. Select the file to check in on the FileView tab of the Workspace window.
  2. Choose Source Control from the Project menu, and then choose Get Latest Version.

    The Get Latest Version dialog box appears, with a check mark next to the file that you have selected. The list includes all files in the project directory that are in the source code control system.

  3. Select or clear the check box for any files in the list that you have changed.
  4. Choose OK.
  5. The source code control system copies the master files to your local copies. If there is a file with changes in both your local copy and the master copy, the source code control system notifies you that you have changes to merge. You then need to follow the recommended procedures in your source code control system to reconcile and verify those changes.
  6. Repeat steps 1 through 3.

    While you have been verifying the last set of changes, another set of changes may have been created.

  7. When your source code control system reports that there are no more files to merge, select the files that you want to check in.
  8. Choose Source Control from the Project menu, and then choose Check In.

    The Check In File(s) dialog box appears, with check marks next to the files that you have selected. The list includes all files in the project directory.

  9. Select or clear the check box for any files in the list.
  10. Choose OK.
  11. To check in a file by using the shortcut menu in the text editor windows, right-click to display the shortcut menu, and then choose Check In.
