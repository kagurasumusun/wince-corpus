Call Trace and Function Trace Views

The Call Trace view and Function Trace view display the entry and exit events of functions in a specified data range.

The Call Trace view is a spreadsheet-like data grid that displays the properties of profiling events in specified threads from an .icp file. The Function Trace view uses the same source data and method of display as the Call Trace view, but the Function Trace view displays a restricted subset of functions.

For each event in a Call Trace view or Function Trace view, you can display a Call Stack window that shows timing information for all functions on the call stack at the time that the event occurred.

You can synchronize multiple trace views so that each view scrolls to the event nearest to the time selected from the Timeline window or from your current view. For more information, see Synchronizing a Trace View to the Timeline.

For information about opening a Call Trace or Function Trace view window, see Opening a View Window.
