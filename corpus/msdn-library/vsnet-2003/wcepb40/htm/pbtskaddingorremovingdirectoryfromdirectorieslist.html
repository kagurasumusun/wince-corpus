Adding or Removing a Directory from the Directories List

  1. Choose Options from the Tools menu, and then choose the Directories tab.
  2. If necessary, select the microprocessor in the Processor list.
  3. Select the type of files for the directory in the Show Directories For list.
  4. To add a directory, in the Directories list, scroll to the bottom of the list, double-click the blank line (indicated by an empty rectangle), and then type the directory name.
  5. To remove a directory, select it, and then press DEL.
