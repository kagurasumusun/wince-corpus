Adding User-Defined Files to an SDK

  1. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.

  2. Choose the Additional Files tab.
  3. Choose Add.
  4. In the Source Folder box, type the path where the files reside.

    - or -

    Choose the Browse button to locate the folder.

    You can add as many source folders as you need.

  5. If you want to include the subfolders of the source folder, select the Include Subfolders check box.
  6. For each source folder, type the name of the target folder in the Target Folder box.

    The target folder is a relative path inside the SDK installation folder. If subfolders were included from the source folder, they will appear in the target folder along with their contents.

  7. Choose OK.
