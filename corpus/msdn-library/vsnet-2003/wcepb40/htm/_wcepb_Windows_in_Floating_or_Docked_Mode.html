Windows in Floating or Docked Mode

Platform Builder opens various dockable windows, such as the Output window, as you work.

Dockable windows have two display modes: floating or docked. In floating mode, a window has a thin title bar and can appear anywhere on your screen. A floating window is always on top of all other windows.

The window positions for windows in docked mode are not associated with the current project; the window positions remain the same, no matter which project you open. However, the locations of the windows in docked mode can differ, depending on whether you are editing or debugging. You can create one layout with your choice of windows in docked mode for editing and another layout with a different choice of windows in docked mode for debugging. You can create a third layout when editing in full-screen mode. When you switch from editing to debugging, the layout changes.

There is a shortcut menu associated with the docking area along the border of the application window. If you right-click in the docking area or on a toolbar, the shortcut menu displays commands to show or hide all the dockable windows, and to customize the toolbars.
