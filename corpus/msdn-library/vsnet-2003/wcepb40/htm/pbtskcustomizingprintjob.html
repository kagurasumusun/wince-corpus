Customizing a Print Job

  1. Choose Page Setup from the File menu.
  2. In the Header and Footer boxes, type header or footer text, print control codes, or both.
  3. Use the right arrow to display a menu that enables you to insert control codes into the text box.
  4. You can enter separate alignment options for file name, page number, current time, and current date. Always enter the alignment option first, then the data.

    For example, &L&F&C&P specifies that the file name (&F) be left-aligned (&L) and that the page number (&P) be center-aligned (&C).

  5. In the Margins area, type the left, right, top, and bottom measurements.
  6. Choose OK.
