Restore a Deleted Default Command to a Menu

  1. Display the toolbar that has the menu to which you want to restore the command.
  2. Choose Customize from the Tools menu, and then choose the Commands tab.
  3. Choose Deleted Commands in the Category list.
  4. Drag the deleted default command from the Commands box over the menu on the toolbar.
  5. When the menu displays a list of commands, point to where you want the command to appear on the menu, and then release the mouse button.
