Public Common Directory

The Common directory contains Windows CE OS component files, supplied by Microsoft, which are common to all Windows CE development projects. It also includes directories that contain the platform-independent libraries supplied by Microsoft. The following table shows these directories.

Directory Description
Cesysgen Files that are used to build the selected Windows CE modules and components
DDK Header files for the driver development kit (DDK)
OAK OS component files
SDK Software development kit (SDK) component files
