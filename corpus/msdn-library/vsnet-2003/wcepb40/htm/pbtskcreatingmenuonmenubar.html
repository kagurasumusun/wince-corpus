Creating a Menu on the Menu Bar

  1. Select the new-item box, which is a blank rectangle on the menu bar.

    – or –

    Move the new-item box to a blank area with the RIGHT ARROW and LEFT ARROW keys.

  2. Type the menu name.

    When you start typing, the focus automatically shifts to the Menu Item property page, and the text that you type appears both in the Caption box and in the menu editor window.

    You can define a mnemonic key that enables the user to select the menu with the keyboard. Type an ampersand (&) in front of a letter to specify it as the mnemonic key. Be sure that all the mnemonic keys on a menu bar are unique.

    Once you have given the menu a name on the menu bar, the new-item box shifts to the right, and another new-item box opens below it for adding menu items.

  3. To create a single-item menu on the menu bar, clear the Pop-up check box on the Menu Item property page.
