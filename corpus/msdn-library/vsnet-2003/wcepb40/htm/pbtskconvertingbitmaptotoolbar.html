Converting a Bitmap to a Toolbar

  1. Open an existing bitmap resource in the graphics editor.
  2. Choose Toolbar Editor from the Image menu.

    The New Toolbar Resource dialog box appears.

  3. You can change the width and height of the images in the Button Width and Button Height boxes to match the bitmap.

    The toolbar is then displayed in the toolbar editor.

  4. Open the property page for the toolbar button by choosing Properties from the View menu.
  5. Type in a new identifier, or select an identifier from the list.
