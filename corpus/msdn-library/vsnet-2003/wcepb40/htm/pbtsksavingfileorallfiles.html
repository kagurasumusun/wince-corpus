Saving a File or All Files

  1. Switch to the source window.
  2. Choose Save from the File menu.

    If you already named the file, the Save command saves changes without displaying the Save As dialog box. If your file is unnamed, the Save As dialog box appears.

  3. Type the file name in the File Name box.
  4. Select the drive and directory where you want to save the file.
  5. Choose Save.

    – or –

    Choose Save All from the File menu to save all open files.
