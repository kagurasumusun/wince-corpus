Setting a Breakpoint at a Source Code Line

  1. In a source window, move the insertion point to the line where you want the application to break.

    If you want to set a breakpoint at a source statement extending across two or more lines, you must set the breakpoint at the last line of the statement.

  2. Choose the Insert/Remove Breakpoint button on the Build toolbar.

    A red dot appears in the left margin of your source code, indicating that the breakpoint is set.
