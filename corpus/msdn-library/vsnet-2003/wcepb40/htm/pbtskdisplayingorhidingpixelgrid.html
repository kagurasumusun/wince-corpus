Displaying or Hiding the Pixel Grid

  1. Choose Grid Settings from the Image menu.
  2. Select the Pixel Grid check box to display the grid, or clear the box to hide the grid.

Because many of the drawing tools are available from the keyboard, sometimes it is useful to hide the Graphics toolbar.
