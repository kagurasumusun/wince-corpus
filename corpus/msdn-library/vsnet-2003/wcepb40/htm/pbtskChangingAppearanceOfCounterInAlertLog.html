Changing the Appearance of a Counter in the Alert Log

  1. From the Edit menu, choose Edit Alert.
  2. In the Color area, select a color for the line.
  3. In the Alert If area, select Over or Under, and then type a number for the alert-warning criteria.
  4. In the Run Program on Alert area, select First Time or Every Time, and then type the complete path for the program that you want to run whenever the specified alert occurs.
  5. Choose OK.
