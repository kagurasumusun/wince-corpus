Using the Go To Dialog Box

  1. Choose Go To from the Edit menu.
  2. Select the option you want in the Go To What box.

    A box appears, whose format and name depends on the item selected in the Go To What box. For example, the Enter Bookmark box appears if you select Bookmark and the Enter Line Number box appears if you select Line. If the Go To What option is undefined, this box is grayed out and unavailable.

  3. Enter any additional information required in this box.
  4. Choose one of the navigation buttons: Go To, Previous, or Next.
