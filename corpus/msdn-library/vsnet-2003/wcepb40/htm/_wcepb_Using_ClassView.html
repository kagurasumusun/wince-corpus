ClassView

ClassView provides simple and direct ways to perform common tasks with your application classes. From the ClassView window, you can navigate among class members, modify interfaces, set breakpoints for the integrated debugger, or generate a new form for your project. You can also use ClassView to add the initial code for classes and members. Additionally, you can modify the display in the ClassView window.

By using the features that are available in ClassView, you can navigate among your source code files without having to think about which file to open. You can perform the following tasks by selecting ClassView icons or options from the shortcut menu:

  • Creating a new class or form
  • Jumping directly to code, such as class or function definitions and declarations
  • Creating function or method declarations and implementations
  • Jumping to the dialog editor

Also, ClassView interacts closely with the text editor, dynamically updating the text editor display to reflect code as you type it without having to first save the file that you are working in.

When you expand a project in ClassView, ClassView displays the classes that are included in that project. If you expand any class, ClassView displays the members in that class.
