Selecting Additional Folders to Search

  1. Choose Find In Files from the Edit menu.
  2. Choose the Advanced button.

    The Look In Additional Folders box appears in the dialog box.

  3. If necessary, select the Look In Folders For Project Source Files check box or the Look In Folders For Project Include Files check box, or both.

    The Project Source and Project Include directories are in the same path as the project directory.

  4. Double-click the highlighted blank rectangle in the Look In Additional Folders box to add a folder.
  5. Type the path and file name.

    – or –

    Choose the Browse button to display the Choose Directory dialog box to change drives and directories.
