Stopping the Build of Multiple Projects

  • Choose Stop Build from the Build menu.

    The IDE stops the currently executing rule, if possible; otherwise, it stops the build as soon as the currently executing rule finishes. The build of the project currently in progress ends.

    A message box appears, asking if you want to continue building using the remaining projects. If you choose Yes, the batch build continues from the next project in the list. If you choose No, the entire batch build is stopped.
