IeXdiPPCContext:IUnknown

This interface provides the Extended Debugging Interface (eXDI) context methods specific to the PPC processor for the debugger.

Methods

Method Description
IeXdiPPCContext::GetContext Reads from a set of microprocessor or co-processor registers that define the target's state.
IeXdiPPCContext::SetContext Writes to a set of microprocessor or co-processor registers that define the target's state.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later exdi.idl
