ROMSIZE

This configuration option specifies the size of the ROM. 

ROMSIZE = size

Parameters

size
The size, in bytes, of the ROM.

Remarks

This configuration option, along with ROMSTART and ROMWIDTH, defines the .abx data format. The following code example shows how a CONFIG section can use configuration options to define the .abx format for a 4-MB target device. 

ROMSTART=80000000 
ROMSIZE=400000  
ROMWIDTH=32

In this example, Romimage.exe creates one 4-MB absolute binary data format file with extension .ab0.
