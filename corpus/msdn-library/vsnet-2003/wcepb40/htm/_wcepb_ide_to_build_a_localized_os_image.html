Building a Localized OS Image

  1. From the Platform menu, choose Settings.
  2. On the Locale tab, select the additional languages you want to support from the Locales list.
  3. In the Default Languages box, select the default language for your platform, and then choose OK.
  4. From the Build menu, choose Build Platform.
