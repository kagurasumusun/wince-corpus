Reverting to an Empty Catalog

If the Catalog for Platform Builder becomes corrupt, you can clean the underlying database using the following procedure. If you clean the database using this procedure, any .cec files that you imported since you installed Platform Builder will be disassociated from the Catalog. After cleaning the database, you will need to import these .cec files to associate them with the Catalog again. For more information about importing a .cec file, see Adding a .cec File to the Catalog.

To revert to an empty Catalog

  1. Close Platform Builder.
  2. At a command prompt, change directory to %CEPBDIR%\Cepb\Bin.
  3. At the command prompt, type cleandb.bat, and then press ENTER.
  4. After the Cleandb.bat command completes, open Platform Builder.
