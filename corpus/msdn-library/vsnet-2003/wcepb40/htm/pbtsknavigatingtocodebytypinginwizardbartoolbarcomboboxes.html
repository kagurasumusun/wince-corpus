Navigating to Code by Typing in the WizardBar Toolbar Combo Boxes

  1. Place the focus on a WizardBar toolbar combo box. The drop-down list opens.

    To place the focus on a WizardBar toolbar combo box from the keyboard, you must first assign a shortcut key to it.

  2. Begin typing the first few letters of the class, filter, or member that you want to start.

    As you type, the list is updated to include only those entries that match what you enter, and the box fills with the first complete possible match.

  3. When the element that you want appears, press TAB to move to the next combo box.

    Pressing ENTER performs the default action for the current context. Pressing TAB moves you to the next combo box without performing the default action. In either case, the WizardBar toolbar combo boxes update their hierarchical dependencies. For example, when you select a new class, the Members list is updated to reflect all members of that class.
