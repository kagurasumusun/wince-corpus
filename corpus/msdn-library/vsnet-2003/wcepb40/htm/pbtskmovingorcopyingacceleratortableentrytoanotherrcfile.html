Moving or Copying an Accelerator Table Entry to Another .rc File

  1. Open the accelerator editor windows in both .rc files.
  2. Select the entry to move.
  3. Choose Copy or Cut from the Edit menu.
  4. Select an entry in the target .rc file.
  5. Choose Paste from the Edit menu.
