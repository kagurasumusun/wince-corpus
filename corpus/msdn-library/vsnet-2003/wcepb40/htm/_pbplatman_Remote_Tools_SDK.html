Remote Utility Development

A remote utility is a distributed application that resides in part on a target device and in part on a development workstation. The parts of a remote utility communicate with each other over Platform Manager. By using the Platform Manager application programming interface (API), you can develop a remote utility that leverages existing Platform Manager functionality. For more information about Platform Manager, see Platform Manager.

One example of a remote utility is a remote tool. A remote tool allows you to use a development workstation to remotely perform a variety of programming tasks on a target device. By default, Platform Manager is bundled with several remote tools. For more information about remote tools, see Remote Tools.

You can download the device-side part of a remote utility using Platform Manager. To display a menu item for the remote utility in the integrated development environment (IDE) on the development workstation, you must register the desktop-side part of the remote utility in the Tools menu of the IDE.

Platform Manager provides a collection of code libraries and utilities that you can use to perform the following tasks:

  • Write development tools for the Microsoft® Windows® CE .NET operating system (OS).
  • Create a distributed application that communicates with a target device in a transport-independent manner.
  • Distribute Microsoft ActiveX® controls that can be used by application developers.
  • Create a custom transport layer, such as universal serial bus (USB) or Small Computer System Interface (SCSI), for remote tool development. For more information about creating a custom transport, see Custom Transport Creation.

Platform Manager also provides an infrastructure, known as the Publish/Subscribe Infrastructure, that allows you to publish and subscribe to data. This infrastructure allows you to, for example, create a publisher on a target device to publish device-related data that you can collect through subscribers on the development workstation. For more information, see Publish/Subscribe Infrastructure.
