Changing the Width of a Drop-down List Box on a Toolbar

  1. Choose Customize from the Tools menu, and then choose the Toolbars tab.
  2. Select the drop-down list box on the toolbar.
  3. Point to the left or right border of the drop-down list box.
  4. When the pointer changes to a double-headed arrow, drag the border of the drop-down list box to change its width.
