Adding a .cec File to the Catalog

  1. From the File menu, choose Manage Catalog Features.
  2. Select Import.
  3. Select the .cec file in the Import Catalog Features dialog box, and then choose Open.

    If there is a syntax error in the .cec file, you will not be able to import it. An error message is displayed that briefly describes the syntax error.

  4. Choose the Refresh button to update the Catalog and ensure that your feature will be displayed.
  5. Choose OK.
  6. If the Catalog is not open, choose Catalog from the View menu to display the Catalog.

    - or -

    Choose the Catalog button on the Standard toolbar to display the Catalog.

  7. Click to expand the entry in the Catalog window that corresponds to the value you specified in the Group statement in your .cec file.

    Your newly added feature appears under this entry. For more information about adding a new version of a feature to the Catalog, see Export Wizard.
