AUTOSIZE

For RAM-only images: This configuration option allows all unused image RAM to be used as system RAM and object store RAM without modification of the .bib memory parameters. This configuration option can also be used to take more memory from the RAM section and provide it to the RAMIMAGE section.

AUTOSIZE = OFF | ON

Parameters

OFF
By default, Romimage.exe does not combine unused image RAM.
ON
Romimage.exe combines the RAM and image memory regions into one region with the image filled from the lowest address to the highest. The RAM parameters in the table of contents are modified to allow the system to use all remaining RAM.
