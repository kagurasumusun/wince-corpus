Importing an Existing HTML File as a Resource

  1. Choose Resource from the Insert submenu of either the Project or Platform menu.
  2. Select HTML in the Resource Type list, and choose Import.
  3. Navigate to the location of the HTML file in the Import Resource dialog box, and choose Import.

If your imported HTML file contains calls to bitmaps or other graphics, you may want to import the corresponding graphic files into your resource script to ensure their availability when the user runs the application. Use the res: Protocol to display these graphics from your page. The res: Protocol supports displaying a resource that resides in a compiled .dll file or .exe. file.
