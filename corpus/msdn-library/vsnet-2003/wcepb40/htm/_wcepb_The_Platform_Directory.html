Platform Directory

The Platform directory contains high-level directories where device-specific files are stored. Each directory in the Platform directory has the same name as a hardware development platform.

Directory Description
CEPC Files and directories for the Windows CE PC-based hardware development platform
Emulator Files and directories for the Windows CE-based virtual hardware development platform
Geode Files and directories for the National Geode SP4SC30 hardware and software development platform
ARMIntegrator Files and directories for the ARM Integrator hardware and software development platform
Aspen Files and directories for the Hitachi SH4 hardware and software development platform
DDB5476 Files and directories for the NEC Vr5432 hardware and software development platform
Eagle Files and directories for the NEC Vr4122 hardware and software development platform
Keywest Files and directories for the Hitachi SH3 hardware and software development platform
SA11x0BD Files and directories for the Intel SA-1110 hardware and software development platform
XSC1BD Files and directories for the Intel Xscale hardware and software development platform
