Adding a Command or Other Item to a Menu

  1. Display the toolbar that has the menu to which you want to add a command or other item.
  2. Choose Customize from the Tools menu, and then choose the Commands tab.

    The Customize dialog box must remain open; however, you can move it.

  3. Select a category for the command or other item in the Category list.

    For example, to add a menu command that runs a macro, select Macros.

  4. If you do not see the command you want under a particular category, select All Commands in the Category list.
  5. Drag the item you want from the Commands box over the menu on the toolbar.
  6. When the menu displays a list of commands, point to where you want the item to appear on the menu, and then release the mouse button.
