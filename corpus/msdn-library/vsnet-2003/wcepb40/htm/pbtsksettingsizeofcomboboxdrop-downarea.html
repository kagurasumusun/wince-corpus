Setting the Size of the Combo Box Drop-down Area

  1. When you select a drop-down combo box or drop-down list box to size it, only the right and left sizing handles are active. Use these handles to set the width of the box as it is displayed initially.
  2. Choose the drop-down arrow at the right of the combo box.

    The outline of the control changes to show the size of the combo box with the drop-down area extended.

  3. Use the bottom sizing handle to change the initial size of the drop-down area.
  4. Choose the drop-down arrow again to close the drop-down portion of the combo box.
