Opening a Resource File as Text

There may be times when you want to view the contents of an .rc file without opening it in a resource editor. For example, you may want to search for a string across all dialog boxes in the resource file without having to open each one separately.

You can open the resource file in text format to view all the resources it contains, and perform operations supported by the text editor.

Note   Do not put #ifdef code in the .rc file. Although the resource compiler supports it, the resource editor may remove the #ifdef code. If you want to include #ifdef code, be sure that it is in a file — typically with an .rc2 extension — or in a macro, where the resource editor cannot alter it.
  1. Choose Open from the File menu, and navigate to the resource file that you want to view in text format.
  2. Select Text from the Open As list.
