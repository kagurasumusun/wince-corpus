Building Selected Files

  1. Select the files in the FileView window.
  2. Right-click, and then choose Compile file from the shortcut menu.

    If the project file you are compiling is dependent on any other file, such as a .pch file, confirm that the dependent file exists and is up-to-date before compiling this file.

    If you specified a custom build rule for a file when you chose Compile, the IDE runs that rule with the file as input and produces the output as specified.
