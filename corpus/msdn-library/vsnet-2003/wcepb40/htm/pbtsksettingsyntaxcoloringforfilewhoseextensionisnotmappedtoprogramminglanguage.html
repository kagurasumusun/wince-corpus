Setting Syntax Coloring for a File Whose Extension Is Not Mapped to a Programming Language

  1. Open the Langext.dat file.

    This file resides in the same directory as Cepb.exe.

  2. Add the file names that you want to color.
  3. Save the file.

The Langext.dat file pairs file names with a language. This file is consulted only when extension matching fails.
