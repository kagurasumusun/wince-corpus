Building Multiple Projects Using the Batch Build Command

  1. Choose the FileView tab on the Workspace window.
  2. Choose Batch Build from the Build menu.
  3. Clear the check box for each project that you do not want to build in the Project Configurations box.
  4. Choose Build to build only those files of each selected project that are out-of-date.

    – or –

    Choose Rebuild All to build all files for each selected project.

The results for each project are separated in the Output window by a line containing the name of the project being built.
