Obtaining the Path of the Release Directory for Your Platform

To obtain the path of the release directory for your platform

  1. Open your platform.
  2. From the Platform menu, choose Settings.
  3. Choose the General tab.
  4. View the Release Directory box.

    The Release Directory box shows the path of the release directory for your platform.
