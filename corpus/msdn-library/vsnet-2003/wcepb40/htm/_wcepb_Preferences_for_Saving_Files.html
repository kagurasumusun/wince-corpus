Preferences for Saving Files

You can set preferences for saving files — such as whether to be prompted before saving — in the Options dialog box. By default, the text editor saves all changed files before building an application. The following table shows available options for saving files.

Save option Description
Save before running tools Saves files before you build a project or run a build utility, such as the Microsoft Program Maintenance Utility, Nmake.exe. This tool is also known as the NMAKE tool.
Prompt before saving files Confirms, with a dialog box prompt, that you want to save files.
Automatic reload of externally modified files Reloads, automatically, externally modified files that have been loaded, but not yet changed, by the text editor.
