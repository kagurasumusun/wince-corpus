Opening a Resource for Binary Editing

  1. Open the project or .rc file that contains the resource to edit.
  2. Select the specific resource file to edit.
  3. Click the right mouse button and choose Open Binary Data.

    To use the binary editor on a resource edited in another editor window, close the other editor window first.

    If you open a resource with a format that the IDE does not recognize, such as a VERSION, RCDATA, or custom resource, the resource is opened in the binary editor.
