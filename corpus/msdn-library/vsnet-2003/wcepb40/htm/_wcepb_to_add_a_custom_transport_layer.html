Adding a Custom Transport Layer to an Exported SDK

  1. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.

  2. Choose the Transports tab.
  3. Choose Add.
  4. In the Name box, enter an appropriate name of the transports.

    Platform Builder displays this name later as the name of your transport on the Transport tab of the SDK Configuration Settings dialog box.

  5. In the Host-side File box, enter the location of the host-side transport dynamic-link library (DLL) file component.

    You can browse for the location of your part by choosing the Browse button.

    Platform Builder automatically loads the globally unique identifier (GUID) that is associated with the transport DLL. Do not change the GUID that was generated by the WCE Transport Layer Wizard for the host-side component.

  6. In the Target-side Files box, enter the location of the target-side transport DLL component.

    You can browse for the location of your components by choosing the Browse button.

  7. Enter the appropriate DLL component for each chip set that your SDK supports.
  8. Choose OK to add the component to the Select Platform Manager Options dialog box.
  9. Choose OK.
