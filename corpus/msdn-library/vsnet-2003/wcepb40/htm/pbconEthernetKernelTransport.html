Ethernet Kernel Transport

The Ethernet kernel transport establishes a kernel-level connection to a target device other an Ethernet connection. Typically, the Ethernet kernel transport automatically uses the target device that you selected for the Ethernet download service. Select a different target device if you do not want to use the target device that you selected for the Ethernet download service.
