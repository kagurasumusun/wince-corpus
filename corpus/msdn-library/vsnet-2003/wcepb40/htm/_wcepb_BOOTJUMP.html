BOOTJUMP

This configuration option moves the jump page to another address within the RAM image space other than the default starting location of the Ramstart address specified in the memory table. 

BOOTJUMP = address | NONE

Parameters

address
The hexadecimal address to which the boot loader jumps on startup.
NONE
Disables writing the jump-to-startup code at the start of the image.

Remarks

A jump page, which contains code generated by Romimage.exe, is usually found at the start of an image. After a reset, the microprocessor begins execution at the jump page. If BOOTJUMP is not defined, Romimage.exe generates a jump from the jump page to the StartUp address in the image. This is the default case. If BOOTJUMP=NONE, the jump page is not generated, and the StartUp point is assumed to be at the beginning of the image. If BOOTJUMP=x, Romimage.exe generates a jump from the jump page to some OEM-supplied startup code, which eventually jumps to StartUp.
