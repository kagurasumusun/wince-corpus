Packages

A package object contains one of more files that you want to download to a target device to extend the functionality of a remote utility. You can use a package object to, for example, associate additional tools and ActiveX controls with the SDK for a platform. When a remote utility requests that Platform Manager download a package, Platform Manager loads the files that match the target device to which it is connected.

The Platform Manager API exposes an IPMPackage interface for a package. You can associate each file in a package with a specific OS version and CPU. You can register a package with a particular platform or with Platform Manager. If you register a package with Platform Manager, then the package is available to all platforms. To see how to create packages and register them with Platform Manager, look at the Samplesreg.vbs file in the SDK\Samples\Bin directory under the top-level Platman directory for Platform Manager.

To see how a simple distributed tool can download the device-side portion of the tool to a target device using packages, refer to the TimeViewer sample in the SDK\Samples\Timeviewer directory under the top-level Platman directory for Platform Manager.
