Loading a Custom Colors Palette

  1. Choose Load Palette from the Image menu.
  2. Navigate to the correct directory and select the palette to load.
  3. Choose OK.
    Note   The graphics editor cannot restore the default Colors palette. To restore the default settings, save the default Colors palette as a palette (.pal) file; for example, Standard.pal or Default.pal.

Because the graphics editor has no way to restore the default Colors palette, save the default Colors palette as a palette (.pal) file, such as Standard.pal or Default.pal, so that you can easily restore the default settings.
