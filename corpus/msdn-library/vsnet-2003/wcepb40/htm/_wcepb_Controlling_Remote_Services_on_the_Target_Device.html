Remote Services on a Target Device

The services that run on a target device are called remote services. You can control the following remote services from the Target menu in the IDE:

  • Target Control (CESH)
  • Target Messages (CETerm)
  • Debugger

CESH and CETerm start by default when you download any type of OS image to a target device over an Ethernet connection, a parallel port connection, a serial port connection, or a connection to the Emulator. The debugger starts by default after you download a debugger-enabled OS image or a debug OS image. The Status Monitor displays the status of each remote service. For more information about CESH, see Windows CE Console Debug Shell Tool.

If a remote service is running, you cannot change the settings in the Configure Remote Connection dialog box. If you change a setting, you must disconnect the IDE from your target device before you can save the new setting.
