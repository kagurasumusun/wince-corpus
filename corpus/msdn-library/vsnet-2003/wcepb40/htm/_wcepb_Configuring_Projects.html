Project Configuration

Projects are controlled by their configuration settings. Specifying settings at the overall configuration level for the project is sufficient for most projects. But if you prefer, you can specify different settings within a configuration for various files or a folder of files.

You can specify settings at the following levels within a configuration for a project:

  • Overall configuration level

    Settings specified at this level apply to all actions. Any settings specified at the configuration apply to every file in the project unless they are overridden at the file level.

  • File level

    Settings specified at this level apply to file-level actions, such as compiling. Any settings specified for the file apply only to that file and override any settings specified at the overall configuration level for the project.

You can specify some types of settings, such as linking, only at the overall configuration level. File settings override options set at the overall configuration level.
