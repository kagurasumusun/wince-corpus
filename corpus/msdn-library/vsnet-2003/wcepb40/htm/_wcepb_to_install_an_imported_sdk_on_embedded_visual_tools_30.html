Installing an Imported SDK on an Application Development Platform

  1. Open the .msi file that contains the SDK.
  2. On the Setup Wizard welcome page, choose Next.
  3. On the End-User License Agreement page, choose I Accept the Terms in the License Agreement, and choose Next.
  4. On the Customer Information page, enter your information in the User Name and Organization boxes.
  5. To select the program feature you want to install, choose Custom.

    - or -

    To install the entire SDK, choose Complete.

  6. If you want to change the installation directory, browse to the folder you want to use.
  7. Choose Next.
  8. On the Ready to Install page, choose Install to install the SDK to your computer.
  9. Choose Finish to complete the SDK installation.
