Using the eXDI Hardware-Assisted Debugger

  1. Create or open a workspace that uses the same CPU as the target device.

    To perform source-level debugging, the workspace .bin file should be the same as the code downloaded to the target.

  2. From the Debug menu, choose Go to start the debugger.

    When the debugger starts successfully, the message Debugger connection established appears on the Debug tab of the Output window. You can begin debugging the target immediately.

    Note   You can download an OS image even while the debugger is running. The Download/Initialize command is always available.
