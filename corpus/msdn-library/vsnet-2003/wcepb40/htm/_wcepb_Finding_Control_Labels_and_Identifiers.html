Control Label and Identifier Searching

You can use the Find command for the following tasks:

  • Searching for labels for static text controls
  • Searching for multiple instances of the same word across dialog boxes
  • Searching for a dialog box in a long list
  • Making changes in dialog boxes
  • Checking consistency
  • Searching for the contents of a dialog box when you do not know its identifier
  • Searching for control or dialog box identifiers if you remember the identifier, but not the contents
