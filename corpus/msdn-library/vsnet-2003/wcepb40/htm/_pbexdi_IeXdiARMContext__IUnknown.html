IeXdiARMContext:IUnknown

This interface provides the eXdi context methods specific to the ARM processor for the debugger.

Methods

Method Description
IeXdiARMContext::GetContext Reads from a set of CPU/coprocessor registers that define the state of the target.
IeXdiARMContext::SetContext Writes to a set of CPU/coprocessor registers that define the state of the target.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later exdi.idl
