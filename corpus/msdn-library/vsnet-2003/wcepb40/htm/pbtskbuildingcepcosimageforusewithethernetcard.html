Building a CEPC OS Image for Use with an Ethernet Card

  1. Use the New Platform Wizard to create a platform, selecting the CEPC board support package (BSP) and the Enterprise Terminal OS configuration. For information about creating a platform, see Platform Creation with the New Platform Wizard.
  2. Choose Build Platform from the Build menu to build the platform.
  3. Open the Platform.reg file, located in %_WINCEROOT%\Public\MyPlatform\RelDir\Configuration.
  4. Search the Platform.reg file for one of the following text strings, depending on whether the Ethernet card in the Windows CE PC-based hardware development platform (CEPC) is an ISA card or a PCI card. 
    IF CEPC_NE2000_ISA

    – or – 

    IF CEPC_NE2000_PCI
  5. Change the Platform.reg file under HKEY_LOCAL_MACHINE\Comm\NE20001\Parms. The following table shows the registry keys to change.
    Registry key Value
    BusType=dword Type 1 for ISA or 5 for PCI.
    InterruptNumber=dword Type the Ethernet card IRQ. This value must be supplied in hexadecimal format.
    IoBaseAddress=dword Type the Ethernet card I/O address. This value must be supplied in hexadecimal format. It is generally displayed in hexadecimal format and must not be converted.
  6. Save the Platform.reg file.
  7. Select Settings from the Platform menu, and then choose the Environment tab.
  8. Type CEPC_NE2000_ISA in the Variable box, and then type 1 in the Value box.

    - or –

    Type CEPC_NE2000_PCI in the Variable box, and then type 1 in the Value box.

  9. Select Make Image on the Build menu.
