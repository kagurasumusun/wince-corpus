BSP Environment Variables

BSP variables define the level of optional support available with a platform. There are two categories of BSP variables. The BSP_NO variables define options not supported by a BSP or platform and the BSP variables, which are used to choose a default driver implementation for each class of device. For example, if your platform does not have a USB controller or USB host controller, then setting BSP_NOUSB = 1 in your platform batch file is appropriate. This tells the Platform Builder IDE and the build scripts that USB is not a supported option on your platform. If your platform contains a Permedia3 display controller as a default, then set BSP_DISPLAY_PERM3 = 1 in your platform batch file.

The environment variables in the following table allow component selection. Set the environment variable to add support for the component. In some cases the Platform.bib file for the platform of interest may need to be updated to support a particular flag, not all do. The following table contains of all the known BSP variables.

Environment variable Description
BSP_CLICKS Add tap and click support.
BSP_DBGLED Adds debug LED support.
BSP_DBGSER_UART1 Adds serial debug support.
BSP_DISPLAY_ATI Adds ATI display driver, Ddi_ati.dll, to the OS image.
BSP_DISPLAY_FLAT Adds FLAT display driver, Ddi_flat.dll, to the OS image.
BSP_DISPLAY_MEDIAGX Adds Geode/MediaGX display driver, ddi_gx.dll.
BSP_DISPLAY_MQ200 Adds MQ200 display driver, ddi_mq200.dll.
BSP_DISPLAY_NOP Adds stub display driver, ddi_nop.dll to the OS image.
BSP_DISPLAY_PERM3 Adds Perm3 display driver, ddi_perm3.dll.
BSP_DISPLAY_RFLAT Adds rotated-FLAT display driver, ddi_rflat.dll
BSP_DISPLAY_RMEDIAGX Adds rotated Geode/MediaGX display driver, ddi_rgx.dll.
BSP_DISPLAY_SA_LCD Adds SA11xx LCD display support.
BSP_DISPLAY_SALCD2 Adds SA11xx LCD display support for a second LCD.
BSP_DISPLAY_TVIA5000 Adds TVIA5000 display driver, ddi_tvia5.dll.
BSP_ENABLE_FSREGHIVE Controls whether hive based registry is enabled by default. This requires DiskOnChip support. This variable is specific to the Geode platform.
BSP_FPEMUL Adds floating-point emulation support.
BSP_ICS Adds Internet Connection Sharing support. This variable is specific to the Geode platform.
BSP_ICS_PUBLIC_VMINI Specifies that the shared debug Ethernet interface be used as the public interface in an Internet Connection Sharing configuration. This variable is specific to the Geode platform.
BSP_KEYBD_ATSCAN Set this variable if you are using the Microsoft Natural Internet Keyboard. This variable is specific to the Eagle platform.
BSP_KEYBD_JPN1 Selects the Japanese1 keyboard/mouse driver. When LOCALE = 0411 and this variable is not set, you select the Japanese2 keyboard and mouse driver.
BSP_KEYBD_NOP Adds the stub keyboard and mouse driver.
BSP_NIC_DC21X4 Adds the DEC21140 NDIS miniport driver.
BSP_NIC_DP83815 Adds the DP83815 (MacPhyter) NDIS miniport driver.
BSP_NIC_NE2000_ISA Adds ISA NE2000 NIC driver.
BSP_NIC_NE2000_PCI Adds PCI NE2000 NIC driver.
BSP_NIC_RTL8139 Adds RTL8139 NIC support.
BSP_NIC_SMSC100 Adds SMSC 100 NDIS miniport driver.
BSP_PCMCIA_I82365 Adds PCMCIA I82365 support.
BSP_PCMCIA_TI1250 Adds PCMCIA TI1250 support.
BSP_RNDISMINI_NET2890 Adds NET2890 RNDIS support.
BSP_SERIAL2 Adds serial port 2 support.
BSP_SERIAL3 Adds serial port 3 support.
BSP_USB_OHCI Adds USB OHCI driver. The UHCI driver cannot be included in the OS image.
BSP_USB_UHCI Adds USB UHCI driver. The OHCI driver cannot be included in the OS image.
BSP_WAVEDEV_ENSONIQ Adds ENSONIQ audio support.
BSP_WAVEDEV_ES1371 Adds ES1371 audio support.
BSP_WAVEDEV_IGS5000 Adds IGS5000 audio support.
BSP_WAVEDEV_TVIA5000 Adds TVIA5000 audio support.
