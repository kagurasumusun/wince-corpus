Viewing Events While They Occur

Remote Kernel Tracker supports a Live From Device option, which provides the ability to view data while the data is collected. The Live From Device option is available in both the data collection mode and the limited buffer mode. It may be enabled or disabled at any time in either of these modes. File mode does not support the Live From Device option.

Note   To effectively use the Live From Device option, it is recommended that you choose a zoom range of at least 1000 milliseconds (ms). Choosing a zoom range of less than 1000 ms may make it difficult to follow the activity of your system.

The Live From Device option is enabled by default when you start Remote Kernel Tracker in data collection or limited buffer mode. To toggle the Live From Device option, see Enabling or Disabling the Live From Device Option.
