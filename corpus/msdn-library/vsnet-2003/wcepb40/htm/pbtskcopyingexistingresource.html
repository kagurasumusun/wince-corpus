Copying an Existing Resource

  1. Select the resource to copy.
  2. Choose Copy, and then choose Paste from the Edit menu.

    – or –

    To copy resources from either an existing resource file or an executable file to your current resource file, have both files open at the same time. Then use the drag-and-drop method to move items from one file to another.
