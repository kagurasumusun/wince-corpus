WINCEMAP

This macro definition specifies whether mapfile files (.map) are generated during compile time. This macro definition is set to 1 by default, which adds the appropriate linker .map file flags to the compile flags. WINCEMAP is useful for evaluating faults, if you are not running the code in the debugger.
