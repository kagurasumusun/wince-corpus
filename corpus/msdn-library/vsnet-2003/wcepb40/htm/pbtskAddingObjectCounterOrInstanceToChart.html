Adding an Object, Counter, or Instance to a Chart

  1. From the Edit menu, choose Add To Chart.
  2. From the Object dialog box, select an object to monitor.

    When you select an object, the content of the Counter and Instance dialog boxes updates to display the available items for that object on the chosen device.

  3. In the Counter dialog box, select one or more counters.

    Choose Explain to display a definition of the selected counter.

  4. If applicable, in the Instance dialog box, select one or more instances.
  5. Choose a line color, plot scale, line width, and line style setting, and then choose Add.
  6. Repeat the previous four steps any additional object or device that you want to monitor, and then choose Done.

    To save your chart selections in a settings file, from the File menu choose Save Chart Settings As.
