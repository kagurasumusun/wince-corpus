Adding Support for Resource Files

When you add a resource script file (.rc) to a project in an existing OS image, you must add Microsoft Foundation Classes (MFC) for Windows CE header files to your Include directory locations. If the MFC header files are not present when you build the platform, you receive an error message stating that the header file Afxres.h cannot be opened.

  1. From the File menu, choose Open Workspace, and then select a platform.
  2. From the File menu, choose Options, and then choose the Directories tab.
  3. In the Directories box, choose the Browse (...) button to specify the directory where the header files are located.

    If Platform Builder is installed in the default location, the files are located in %_WINCEROOT%\Others\MFC\Include directory.

  4. Choose OK.
