East Asian Locale Localization

The operating system (OS) and applications have been localized for East Asian languages. Platform Builder includes localized .res files and .str files contained in locale specific folders for the following languages: Japanese (0411), Korean (0412), Simplified Chinese (0408), and Traditional Chinese (0404). To create an image for other East Asian locales, you must manually create a directory structure for the localized .res and .str files, or change the locale enumerator used for the existing folders and reuse the translations. When you set an East Asian locale as the default, the platform will install the appropriate line breaking code and font file for that locale. However, you will need to manually select optional locale-specific features, such as the Input Method Editor, from the Catalog's International node.

Platform Builder allows you to choose compressed or non-compressed fonts in a variety of styles and languages. For more information about fonts, see Font Versions.

As an alternative or companion to a keyboard, you can employ on-screen Input Methods (IM), such as a soft keyboard or a handwriting IM, in your application for processing user-drawn numbers, letters, characters, and symbols. The Windows CE Handwriting Recognition Engine, HWX, currently recognizes all 94 characters of the ASCII character set. It also recognizes all of the available glyph characters or ideographs for Traditional Chinese, Japanese, and Korean, and produces the corresponding Unicode output.
