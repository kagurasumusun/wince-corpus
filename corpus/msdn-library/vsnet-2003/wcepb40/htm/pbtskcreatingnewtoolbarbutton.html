Creating a New Toolbar Button

  1. Assign an identifier to the blank button at the right end of the toolbar.
  2. Open the property page for that toolbar button to edit the ID box.

    – or –

    Select the blank button at the right end of the toolbar, and begin drawing. The default button command identifier, ID_BUTTON<n>, is assigned.
