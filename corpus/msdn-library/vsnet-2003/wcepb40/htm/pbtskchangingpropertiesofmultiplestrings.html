Changing the Properties of Multiple Strings

  1. Hold down the CTRL key while selecting each string.
  2. Choose Properties from the View menu.

    The Multiple Selection Properties property page appears. Changes you make on this page are reflected on each item selected. If you need to undo a change, choose Undo from the Edit menu. The change is undone on each item selected.
