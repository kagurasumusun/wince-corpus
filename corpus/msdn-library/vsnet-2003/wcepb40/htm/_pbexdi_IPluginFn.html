IPluginFn

This interface provides the methods to enable communication and control for the Extended Debugger Interface (eXDI) plug-ins.

Methods

The following table shows the methods that are supported by eXDI.

Method Description
IPluginFn::StartUp Starts the plug-in.
IPluginFn::ShutDown Closes the plug-in.
IPluginFn::NotifyCollectorShutDown Not currently used.
IPluginFn::GetPropertyPage Not currently used.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later vmplugin.idl
