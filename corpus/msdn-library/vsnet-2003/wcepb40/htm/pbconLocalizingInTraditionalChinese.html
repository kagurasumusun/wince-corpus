Traditional Chinese Localization

Three important localization features for the Traditional Chinese language are fonts, Input Method Editors (IMEs), and input methods (IMs). Platform Builder installs the Mingliu TrueType font by default, but also provides support for the Msming TrueType font for the Traditional Chinese locale. The following table shows the IMEs that are included with Platform Builder for Traditional Chinese products.

IME Description
Phonetic Pocket IME A compact IME that provides a sample customizable UI model.
Chang Jei Pocket IME A compact IME that provides a sample customizable UI model.

For more information about which configurations support IME, see Included OS Configurations.

For more information about how to customize the Traditional Chinese Pocket IME, see Traditional Chinese Pocket IME.

In addition to the IME, Platform Builder supports the U.S. keyboard for Traditional Chinese build.

Platform Builder also provides the following IMs.

IM Description
Phonetic A IM with a soft keyboard that allows phonetic input and is closely tied to the Phonetic IME.
Chang Jei A IM with a soft keyboard that allows Chang Jei input and is closely tied to the Chang Jei IME.
HWX A handwriting recognition engine for supporting user-drawn ideographs and characters. Platform Builder includes a sample UI named Mboxcht.

Platform Builder includes a sample UI for HWX that is similar to Multibox for Japanese.
Mboxcht A sample IM for Traditional Chinese handwriting input that works with the HWX engine. The source code is located in %_WINCEROOT%\Public\Common\Sdk\Samples\Mboxcht.

For more information about Traditional Chinese input methods, see Traditional Chinese Input Method.

GB18030 Data Converter

GB18030-2000 is a new Chinese character-encoding standard set by the People's Republic of China. This standard contains many characters and has new conformance requirements for desktop operating systems.

As an embedded operating system, Windows CE is not currently required to adhere to the new standard.

To support platform developers whose target device includes scenarios that access Web content or receive content from desktop operating systems, Windows CE .NET provides a GB18030 data converter that converts GB18030-based content to a native encoding that the operating system is able to display. The support only provides display of the converted content. No support is provided for edits or saves in the GB18030 encoding format.

Windows CE .NET provides fonts that cover the GB2312 standard. However, it does not provide a font that covers the full range of GB18030 standard characters, or other components that may be required to fully comply with the GB18030 standard.

To include this component in your platform, select the GB18030 data converter in the Catalog window and drag and drop it into the FeatureView window.

For more information about the GB18030 Data Converter, see GB18030 Data Converter.
