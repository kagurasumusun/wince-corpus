When IntelliSense Is Unavailable

The following describes situations when the IntelliSense options may not work as you expect:

  • There is a code error above the cursor.

    If there is an incomplete function or other coding error above the location of the insertion point, IntelliSense will be unable to parse the code elements and therefore will not work. You can enclose the applicable code in comment delimiters to enable IntelliSense again.

  • The insertion point is inside a code comment.

    If the insertion point is within a comment in your source file, the List Members, Parameter Info, and Type Info options will not work automatically. However, you can still invoke them from the menu or keyboard.

  • The insertion point is inside a string literal.

    If the insertion point is inside the quotation marks around a string literal, IntelliSense options will not be available. For example: 

    MessageBox(hWnd, "String literal|"))
  • The automatic options are turned off.

    IntelliSense works automatically by default, but it can be disabled.
