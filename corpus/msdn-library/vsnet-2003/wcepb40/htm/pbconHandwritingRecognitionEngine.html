Handwriting Recognition Engine

The Windows CE handwriting recognition engine, HWX, currently recognizes all 94 characters of the ASCII character set. In addition, the engine recognizes all of the available glyph characters, known as ideographs, for Chinese, Japanese, and Korean, and produces their corresponding Unicode outlet.

Handwriting recognition uses the same application programming interface (API) in all languages. For information about language specific flags, see HwxALCValid and HwxALCPriority, which describe the alphabet code (ALC) values).

The following table shows the Windows CE modules that provide support for the handwriting recognition engine HWX.

Locale Module
Chinese, Traditional Hwxcht
Japanese Hwxjpn
Korean Hwxkor
USA Hwxusa

To add the handwriting recognition engine to your platform for applicable locales, select the module for the desired locale in the Catalog window, and drag and drop it into the FeatureView window.

For more information on handwriting recognition, see Recognizing a Hand-Drawn Character and Performing Handwriting Recognition.
