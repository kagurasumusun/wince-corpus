Excluding a Feature or Project from Being Built in a Configuration

  1. From the Platform menu, choose Settings, and then choose the General tab.
  2. In the left pane, expand nodes to navigate to the feature or project that you want to exclude, and then select the feature or project.
  3. Choose Build, but exclude from image to build the feature or project but exclude the feature or project from the OS image.

    - or -

    Choose Exclude from build and image to exclude the feature or project from the build and from the OS image.
