Selecting the Supported OS Image for an SDK

  1. From the Platform menu, choose Configure SDK.

    This will start the Export SDK Wizard if it has not been run previously for the current platform. For more information about using the Export SDK Wizard, see Exporting an SDK.

  2. Choose the CPU tab.
  3. Select the check box next to the CPU Family you want to support.
  4. In the list next to the CPU family you have chosen, choose the Platform Builder configuration you want to support.
  5. Choose OK.
