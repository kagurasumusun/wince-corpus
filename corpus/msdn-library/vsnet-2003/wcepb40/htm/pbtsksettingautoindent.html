Setting Auto Indent

  1. Choose Options from the Tools menu.
  2. Choose the Tabs tab.
  3. Select the option you want in the Auto Indent area. Select None to disable Auto Indent, Default to sets the tab and indent size to the previous level, or Smart to use Smart Indent to automatically indent the text based on the context of the previous lines.
  4. Choose OK.
