Text Editor Settings Commands

The following table shows text editor settings commands available in the text editor.

Command Description
FindToggleCaseSensitivity Toggles the search case sensitivity on or off.
FindToggleMatchWord Toggles whole word matching on or off.
FindToggleOvertype Toggles between inserting and replacing typing.
FindToggleRegExpr Toggles the regular expression search on and off.
FindToggleAllDocs Toggles searching across all open documents on or off.
ToggleViewWhitespace Toggles between showing or hiding the tab characters.
