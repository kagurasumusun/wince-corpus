Dialog Box Editing

Each dialog box has a tab order and mnemonic keys. Alternatively, a keyboard user can press a mnemonic key to move the input focus from one control to another.

The tab order is the order in which the TAB key moves the input focus from one control to the next within a dialog box. Usually the tab order proceeds from left to right in a dialog box, and from top to bottom. Each control has a property page with a Tabstop check box, which is used to determine whether a control actually receives input focus.

Controls that do not have the Tabstop property set also need to be part of the tab order. This can be important, for example, when you define mnemonic keys for controls that do not have command text. Static text that contains a mnemonic for a related control must immediately precede the related control in the tab order.

If your dialog box contains overlapping controls, changing the tab order may change the way that the controls are displayed. Controls that come first in the tab order are always displayed on top of any overlapping controls that follow them in the tab order.

Once you enter Tab Order mode, you can press ESC to disable the ability to change the tab order.

Typically, keyboard users move the input focus from one control to another in a dialog box with the TAB and ARROW keys. However, you can define a mnemonic key that enables users to choose a control by pressing a single key.

All the mnemonics within a dialog box should be unique. You can use the Check Mnemonics command on the shortcut menu to check your dialog box for duplicate mnemonic keys.
