Resizing an Entire Graphic Using the Property Page

  1. Open the graphic whose properties you want to change.
  2. Choose Properties from the View menu.
  3. Type the new dimensions in the Width and Height boxes.

    When you increase the graphic's size, the graphics editor extends the graphic to the right, down, or both, and fills the new area with the current background color. The graphic is not stretched.

    When you decrease the graphic's size, the graphics editor crops the graphic on the right or bottom edge, or both.

You can use the Width and Height properties to resize only the entire graphic, and not a partial selection.
