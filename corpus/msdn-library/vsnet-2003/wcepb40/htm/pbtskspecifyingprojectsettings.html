Specifying Project Settings

  1. Choose Settings from the Project menu.
  2. Select the project or projects on the General tab.
  3. Select a configuration in the Settings For list or select All Configurations.
  4. Make the desired changes to the project.
  5. Choose OK to save the settings.

If you specify settings that are incompatible with the type of feature you chose when you created the project, you may get unexpected results.
