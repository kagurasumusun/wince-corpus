OUTPUT

This configuration option specifies the optional output directory where Romimage.exe places the resulting image file. 

OUTPUT = path

Parameters

path
The full path where Romimage.exe places the output.

Remarks

By default, Romimage.exe puts the output in the same directory as the first module file.
