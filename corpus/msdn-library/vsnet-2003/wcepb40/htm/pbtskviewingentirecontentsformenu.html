Viewing the Entire Contents for a Menu

If you add a command to a menu, and the command does not appear on the menu when you want to use it, the command may be hidden because it is not available in the current editor. To verify that the command was added to the menu, you can view the entire contents for a menu — that is, all of the commands on the menu — for all editors, at the same time.

  1. Choose Customize from the Tools menu, and then choose the Commands tab.
  2. Select All Editors in the Show Menus For list.

    If the missing command is listed when you display commands for All Editors, it will appear on the menu in any editor where it applies.
