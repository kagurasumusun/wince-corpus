Renaming a Macro

  1. Choose Macro from the Tools menu.
  2. Select the file containing the macro Renaming in the Macro File box.

    If this file is not in the list, install the file, and then select it in the Macro File box.

  3. Select the macro Renaming in the Macro Name box.
  4. Choose Edit.
  5. Go to the SUB block containing the macro's code.
  6. Change the name of the macro on the line containing the macro's name.
  7. Save the macro file.
