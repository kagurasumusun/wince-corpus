Saving an Edited Resource File

  1. Choose Save from the File menu. The resource is saved using its current name.

    – or –

    Choose Save As from the File menu.

  2. Select the directory path in the Save In list.
  3. Type the file name in the File Name box.
  4. Choose OK.

    The resource is saved using the name in the File Name box.
