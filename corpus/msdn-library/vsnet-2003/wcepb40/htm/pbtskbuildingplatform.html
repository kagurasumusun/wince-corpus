Building a Platform

  1. Choose an active configuration in the Select Active Configuration lists on the Build toolbar.

    The configuration specifies your target board support package (BSP), microprocessor, and whether you are building a debug or release version of your platform.

  2. Choose Build Platform from the Build menu to build the files that have changed since the last build.

    – or –

    Choose Rebuild Platform to build all of the files in the platform.

    Note   To stop the build process, choose Stop Build from the Build menu or choose the Stop button on the Build toolbar
