IPMPlatform::AddStartupServer

This method adds a startup server object to the IPMPlatform interface of type bstrPackageName.

HRESULT AddStartupServer(
BSTR bstrStartupServerId,
VARIANT_BOOL bDefault,
IPMStartupServerInfo **ppiStartupServer 
);

Parameters

bstrStartupServerId
[in] GUID of the startup server object to be added.
bDefault
[in] Optional; If TRUE, the startup server object becomes the default startup server. The default value is TRUE.
ppiStartupServer
[out] Pointer to a pointer to the IPMStartupServerInfo interface.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Cemgr.idl Platform.h
