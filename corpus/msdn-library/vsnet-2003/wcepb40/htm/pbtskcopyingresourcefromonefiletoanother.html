Copying a Resource from One File to Another

  1. Open both files. The copy you are copying from is the source file; the file you are copying to is the target file.

    Be sure that both resource files are visible.

  2. Select the resource to copy in the source file.
  3. Hold down the CTRL key while you drag the resource to the target file.

    Dragging the resource without holding down the CTRL key moves the resource rather than copies it.

To avoid conflicts with resource identifiers or values in the existing file, the IDE may change the transferred resource's value, or name and value, when these are copied to the new file.
