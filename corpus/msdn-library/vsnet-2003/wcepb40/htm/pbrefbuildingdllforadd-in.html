Building the DLL for the Add-in

The following steps show how to build the DLL for an add-in

To build the DLL for the add-in

  1. From the Visual C++ 6.0 IDE, open the project for the add-in.
  2. On the Build menu, choose Build dll, where dll is the name of the DLL.
