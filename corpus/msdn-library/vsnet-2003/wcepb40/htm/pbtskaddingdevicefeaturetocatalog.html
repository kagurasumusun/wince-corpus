Adding a Device Driver to the Catalog

If you want other developers to be able to include your device driver in their platforms, you can create a Catalog feature file (.cec) and add it to the Catalog.

  1. Use any text editor to create the .cec file for your device driver.
  2. Save the .cec file in the workspace.

    You can view the .cec file on the FileView tab of the Workspace window.

  3. From the File menu, choose Manage Catalog Features.
  4. Select Import.
  5. In the Import Catalog Features dialog box, choose the .cec file, and then choose Open.
  6. From the View menu, choose Catalog to display the Catalog.

    - or –

    On the Standard toolbar, choose the Catalog button to display the Catalog.

  7. Expand the entry in the Catalog window that corresponds to the value you specified in the group statement in your .cec file.

    Your newly added feature appears under this entry.
