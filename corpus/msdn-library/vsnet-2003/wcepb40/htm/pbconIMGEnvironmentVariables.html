IMG Environment Variables

The IMG environment variables are used only to remove a module from the image, but the associated registry entry is left intact. They should only be used in a Platform.bib file. These variables allow you to transfer files across Ppsh rather than including them in your image. These are for convenience only and should not be used in a released product.
