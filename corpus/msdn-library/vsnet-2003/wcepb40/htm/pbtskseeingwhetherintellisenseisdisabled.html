Seeing If IntelliSense is Disabled

  1. Choose Options from the Tools menu.
  2. Choose the Editor tab in the Options dialog box.
  3. If no check boxes are selected in the Statement Completion Options area, then IntelliSense is disabled.

    Each check box corresponds to an individual IntelliSense option.

Even when automatic statement completion is disabled, you can always explicitly invoke any of the individual options. For more information on modifying IntelliSense options, see IntelliSense Option Modification.
