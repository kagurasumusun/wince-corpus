Adding Files to a Project

  1. Open the project to which you want to add files.
  2. Choose Insert from the Project menu, and then choose Files.
  3. Specify the type of files to add in the Files Of Type list.
  4. Select one or more files.
  5. Choose OK.

You can also use the shortcut menu from the FileView window.
