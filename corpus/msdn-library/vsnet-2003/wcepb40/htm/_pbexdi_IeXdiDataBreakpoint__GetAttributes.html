IeXdiDataBreakpoint::GetAttributes

This method gets the data breakpoint's current characteristics.

HRESULT GetAttributes( 
PADDRESS_TYPE pAddress, 
PADDRESS_TYPE pAddressMask, 
DWORD *pdwData, 
DWORD *pdwDataMask, 
BYTE *pbAccessWidth, 
PMEM_TYPE pmt, 
BYTE *pbAddressSpace, 
PDATA_ACCESS_TYPE pda, 
DWORD *pdwTotalBypassCount, 
DWORD *pdwBypassedOccurences, 
BOOL *pfEnabled
);

Parameters

pAddress
[out] Returns the address of the data on which the data breakpoint operates.
pAddressMask
[out] Returns the mask that is applied on the address for comparison for matching bits.
pdwData
[out] Returns the value of the data accessed. Only bits set in the data mask are significant.
pdwDataMask
[out] Returns the mask to apply on pdwdata.
pbAccessWidth
[out] Returns the data width in bits.
pmt
[out] Returns data memory type.
pbAddressSpace
[out] Returns the address space of the data breakpoint if the value pointed to by pmt is mtPhysicalOrPeriIO.
pda
[out] Returns the data access type — read access, write access, or both.
pdwTotalBypassCount
[out] Returns the number of times the trigger of a microprocessor halt should be bypassed when the breakpoint condition is met.
pdwBypassedOccurences
[out] Returns the number of bypasses related to this breakpoint that have already been seen.
pfEnabled
[out] Returns true if the breakpoint is enabled.

Return Values

This method has the following return values.

Return value Description
S_OK Function is successful.
EXDI_E_CANNOTWHILETGTRUNNING Cannot proceed while target is running.
EXDI_E_NOTIMPL Not implemented.
EXDI_E_OUTOFMEMORY Failed to allocate necessary memory.
EXDI_E_INVALIDARG One or more arguments are invalid.
EXDI_E_ABORT Operation aborted.
EXDI_E_FAIL Unspecified failure occurred.
EXDI_E_COMMUNICATION Communication error occurred between host driver and target.
EXDI_E_USEDBYCONCURRENTTHREAD Cannot proceed immediately because resource is already used by concurrent thread.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later exdi.idl
