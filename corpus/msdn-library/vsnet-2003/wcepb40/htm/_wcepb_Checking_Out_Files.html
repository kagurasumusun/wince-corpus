File Checkout

When you check out a file, the source code control system that you have installed changes the status of the file from read-only to read and write. The system also records that you have checked out the file, and the Check Out command is dimmed, which indicates that the file is unavailable. You then have the necessary permissions to revise the file. Your source code control system may include a mechanism for exclusive use. If it does, you can specify that you have the file checked out, and that no one else can check out that file.

Some source code control systems allow multiple developers to check out the same file. In this case, the source code control system merges the changes from the developers when each one checks in the file.
