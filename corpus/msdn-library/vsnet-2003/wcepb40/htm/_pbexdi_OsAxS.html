OsAxS

These functions provide the ability to access Microsoft® Windows® CE run-time information. They are found in the OsAxS.dll file.

The following table shows the functions that are supported by the Extended Debugging Interface (eXDI).

Function Description
OsAxSGetSOf Finds the given symbol.
OsAxSGetNrS Finds the nearest symbol whose base address is less than the given offset.
OsAxSGetVirtual2PhysAddr Translates a virtual address to the corresponding physical address using the kernel tables.
OsAxSReadControl Reserved. Gives read access to operating system (OS) run-time information.
OsAxSSetImageName Specifies the location of the .bin file used by the Platform Builder session that invoked the eXDI driver.
OsAxSWriteControl Reserved. Gives write access to OS run-time information.
