Menu Customization on Toolbars

You can move or copy an existing menu to a toolbar or from one toolbar to another. You can also create a new menu on a toolbar and delete a menu from a toolbar.

When you delete a default menu, the menu is still available in the Customize dialog box in the Menus category on the Commands tab. However, when you delete a custom menu, it is permanently deleted. To remove and save a custom menu, create a toolbar for storing unused menus, move the menu to this toolbar, and then hide the toolbar.
