Font Versions

East Asian font files tend to take up a large amount of memory. Font versions provide options for the content and size of font files that can be included on your platform. The font files are available in both compressed and non-compressed formats.

Character removal is based on character ranges corresponding to national standards and code pages. Bitmap removal is to all files in a font collection, retaining critical and commonly used sizes for the UI display. For point sizes not defined in the files, the rasterizer uses the TrueType outline data for that glyph.

The different versions of a font have been given unique names; however, the file name must be changed to the standard font file name before it is used in the image. The following font versions are included in the %_WINCEROOT%\public\common\oak\files directory.
