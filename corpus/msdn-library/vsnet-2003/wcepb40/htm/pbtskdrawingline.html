Drawing a Line

  1. Select the Line tool from the Graphics toolbar.
  2. If necessary, select colors and a brush using one of the following methods:
    • Click the left mouse button to select a foreground color or click the right mouse button to select a background color from the Colors palette.
    • Select a shape representing the brush to use in the options selector.
  3. Place the cursor at the line's starting point.
  4. Drag to the line's endpoint.
