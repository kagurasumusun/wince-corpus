IPMPackageFile::Architecture

This method obtains the microprocessor architecture of the CPU object associated with the package file object.

HRESULT Architecture(
int *pwArchitecture 
);

Parameters

pwArchitecture
[out] Pointer to the microprocessor architecture of the CPU object.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Cemgr.idl Packagefile.h
