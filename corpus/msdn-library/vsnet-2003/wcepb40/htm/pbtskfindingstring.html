Finding a String

  1. Move the insertion point to where you want to begin your search.

    The text editor uses the location of the insertion point to select a default search string.

  2. Choose Find from the Edit menu.
  3. Type the search string or use the list to select from up to 16 previous search strings in the Find What box.
  4. Select any of the Find options.
  5. Start the search by choosing the Find Next or Mark All buttons.

    The Find dialog box disappears when the search begins.

  6. Use the Find Next or Find Previous shortcut keys, or the equivalent toolbar buttons on the Edit toolbar to continue your search.

    The default shortcut key for Find Next is F3 and the default key combination for Find Previous is SHIFT+F3.

You can use buttons on the Edit toolbar to change whether searches are case-sensitive, match whole words, or use regular expressions.
