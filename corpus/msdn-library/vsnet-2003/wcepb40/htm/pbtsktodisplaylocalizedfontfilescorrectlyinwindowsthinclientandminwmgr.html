Displaying Localized Font Files Correctly in a Project

To include font files in the final OS image, you must add these files to the Project.bib file for your project. You can copy the necessary .bib entries from the webpad enterprise Project.bib file.

  1. Open your Project.bib file in %_WINCEROOT%\Public\Myproj\Oak\Files and the webpad enterprise Project.bib file in %_WINCEROOT%\Public\Iabase\Oak\Files.
  2. In the webpad enterprise Project.bib file, copy the section that starts with IF LOCALE=0411, includes IF LOCALE=0404, and ends with ENDIF.
  3. Paste this section into the FILES section of your Project.bib file, and then save your changes.
  4. Search for "FONT linking and EUDC" in %_WINCEROOT%\Public\Iabase\Oak\Files\Project.reg.
  5. Copy this section to the end of your Project.reg file.

After making these changes, you can set LOCALE to 0411 (Japanese), 0412 (Korean), or 0804 (simplified Chinese) and make an OS image that includes and displays the correct fonts for these locales.
