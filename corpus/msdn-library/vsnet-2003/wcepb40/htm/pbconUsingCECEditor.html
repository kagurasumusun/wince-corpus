CEC Editor

The CEC Editor is a tool, accessed from the Tools menu, with which you can create and edit .cec files. The CEC Editor displays the individual Catalog items from the .cec file that is being edited, along with the properties for each Catalog object.

For more information about creating and modifying .cec files, see Catalog Feature Files.
