Desktop Details

The files associated with this sample contain changes to the creation of a Remote Performance Monitor extension DLL.

The following three files are specific to Remote Performance Monitor:

  • CETickStats.cpp

    This file contains the DllMain, DllRegisterServer, and DllUnregisterServer functions. The primary difference between the Performance Monitor for Windows-based desktop platforms and Remote Performance Monitor is location of information for Remote Performance Monitor in the registry.

  • PerfGen.cpp

    Remote Performance Monitor requires the addition of a function that obtains a pointer to the IPMConnection interface. In this sample, the SetITLConnectionCETickStats function obtains this pointer. It is not necessary to make any changes to this function.

  • GetTickData.cpp, GetTickData.h

    The GetTickData.cpp file contains the Remote Performance Monitor specific code that interacts with the .exe file on the device.

The following files are modified but are not specific to Remote Performance Monitor:

  • CEStructs.h
  • DataGen.h
  • datagen.cpp
  • genctrnm.h
  • perfmsg.h
