IeXdiServer::DoRangeStep

This method commands the target to step out of an address range and then halt.

HRESULT DoRangeStep(
ADDRESS_TYPE FirstAddress,
ADDRESS_TYPE LastAddress
);

Parameters

FirstAddress
[in] First address of the address range of which the method steps out.
LastAddress
[in] Last address of the address range of which the method steps out.

Return Values

This method has the following return values.

Return value Description
S_OK Function is successful.
EXDI_E_NOTIMPL Not implemented.
EXDI_E_OUTOFMEMORY Failed to allocate necessary memory.
EXDI_E_ABORT Operation aborted.
EXDI_E_FAIL Unspecified failure occurred.
EXDI_E_COMMUNICATION Communication error occurred between host driver and target.
EXDI_E_TGTWASNOTHALTED The target was not halted.
EXDI_E_NORESAVAILABLE No resource available to do single step.
EXDI_E_INVALIDARG One or more arguments are invalid.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later exdi.idl
