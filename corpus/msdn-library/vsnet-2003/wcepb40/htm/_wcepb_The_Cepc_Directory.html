MyBSP Directory

The MyBSP directory contains the files and directories that Microsoft supplies for a hardware development platform.

Directory Description
Cesysgen Files that are used to build the selected Windows CE modules and components.
Drivers Files that provide the device drivers for your platform.
Eboot Files that provide support for the Ethernet boot loader.
Files This directory contains the project-specific files that are used to build the OS image, initial directory structure, initialized databases, and initialized registry.
GWE Files that provide support for the Graphics, Windowing, and Events Subsystem (GWES) feature, which is an integrated graphics device interface (GDI), window manager, and event manager.
Inc This directory contains device-specific header files, which define the interrupt identifiers, the microprocessor control registers, and other hardware resources that are specific to a hardware development platform.
Kernel This directory contains the device-specific source code files for the OEM adaptation layer (OAL).
Lib Libraries required in order to build components of your project. The libraries are contained in directories with the following formats:
  • Cpu\Debug
  • Cpu\Retail

An example is Sh3\Retail.

Do not include your libraries in this directory. If you want to modify project-specific files, you must first copy those files into your project tree, and then build that project. You must also update the sources file in the code in order to correctly link with the appropriate library.
Sboot Files that provide support for the x86 serial boot loader.
target This directory contains binary and executable files for your hardware development platform.
