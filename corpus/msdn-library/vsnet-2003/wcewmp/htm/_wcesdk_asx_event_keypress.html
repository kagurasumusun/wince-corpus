KeyPress

This event occurs when the user presses and releases a key.

Compatibility: Windows Media Player, ActiveMovie

<SCRIPT FOR="MediaPlayer" EVENT="KeyPress(iKeyAscii)" LANGUAGE="JScript">
    //insert script commands//
</SCRIPT>

Parameters

iKeyAscii
An Integer value specifying a standard numeric ANSI keycode.

Remarks

If the value of the SendKeyboardEvents property is true, this event occurs when the Windows Media Player control has focus and the user presses and releases a key. If SendKeyboardEvents is false, this event does not occur.
