ContactPhone

This property contains a value representing the station's contact telephone number.

Compatibility: Windows Media Player

[ "sPhone" = ] MediaPlayer.ContactPhone

Parameters

sPhone   
String value representing the station's contact telephone number. This property is read-only with no default value.

Remarks

This property only returns valid information for Advanced Streaming Format (ASF) content being received from a station (defined IP address and port number). Station information is stored in a Windows Media Station (.nsc) file.
