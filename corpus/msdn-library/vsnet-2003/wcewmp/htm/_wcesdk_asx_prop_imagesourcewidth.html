ImageSourceWidth

This property contains a value specifying the original image width of the current clip, in pixels.

Compatibility: Windows Media Player, ActiveMovie

[ lWidth = ] MediaPlayer.ImageSourceWidth

Parameters

lWidth
Long value specifying the original image width, in pixels. This property is read-only with no default value.

Remarks

If the FileName property is not set, this property returns zero.
