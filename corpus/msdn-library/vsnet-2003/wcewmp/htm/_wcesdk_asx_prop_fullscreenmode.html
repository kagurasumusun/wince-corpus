FullScreenMode

This property specifies whether to expand the area of the playback panel to fill the entire screen.

Compatibility: ActiveMovie

[form.]object.FullScreenMode [ = { True | False } ]

Remarks

Run-time access: read-only. Design-time access: read/write.

Settings

Setting Description
True Use full-screen mode.
False Do not use full-screen mode.
