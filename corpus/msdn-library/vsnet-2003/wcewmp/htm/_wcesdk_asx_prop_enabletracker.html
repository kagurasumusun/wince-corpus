EnableTracker

This property specifies whether the trackbar control is enabled.

Compatibility: Windows Media Player

MediaPlayer.EnableTracker [ = bTracker ]

Parameters

bTracker
Boolean value specifying whether the trackbar is enabled. If true, the tracker is enabled. This property is read/write with a default value of true.

Remarks

The Windows Media Player control displays the trackbar only when the ShowControls and ShowTracker properties are both true.
