ErrorCorrection

This property contains the error correction type of the current clip.

Compatibility: Windows Media Player

[ "sErrCorrection" = ] MediaPlayer.ErrorCorrection

Parameters

sErrCorrection
String value specifying the error correction type of the current clip. It can have one of the following possible values.
Value Description
Standard Standard error correction.
None No error correction.

This property is read-only with a default value of Standard.

Remarks

This property returns an empty string if the FileName property is not set.
