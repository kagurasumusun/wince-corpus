VideoBorderWidth

This property specifies the width of the video border, in pixels.

Compatibility: Windows Media Player

MediaPlayer.VideoBorderWidth [ = lWidth ]

Parameters

lWidth
Long value specifying the width of the video border, in pixels. This property is read/write with a default value of zero.

Remarks

Windows Media Player control draws a video border around the video display panel with a width specified by this property and in the color specified by the VideoBorderColor property.

The default value of zero indicates that the Windows Media Player does not display any video border.
