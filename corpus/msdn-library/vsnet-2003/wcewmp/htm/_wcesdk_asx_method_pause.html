Pause

This method suspends playback at the current position in the clip.

Compatibility: Windows Media Player, ActiveMovie

MediaPlayer.Pause( )

Return Values

None.

Remarks

This method performs the same action as clicking the pause button on the control bar.

If the value of the SendPlayStateChangeEvents property is true and the file is playing, calling this method causes a PlayStateChange event to occur.

When a file is paused, the client control does not give up any system resources, such as the audio device.

This method also resets the Rate property to the default value of 1.0.
