SendOpenStateChangeEvents

This property specifies whether the Windows Media Player control sends open state change events.

Compatibility: Windows Media Player

MediaPlayer.SendOpenStateChangeEvents [ = bSendOpenState ]

Parameters

bSendOpenState
Boolean value specifying whether open state change events are enabled. If true, the Windows Media Player control sends open state change events. This property is read/write with a default value of true.
