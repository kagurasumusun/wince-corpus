VideoBorderColor

This property specifies the color of the video border.

Compatibility: Windows Media Player

MediaPlayer.VideoBorderColor [ = clrBorder ]

Parameters

clrBorder
OLE_COLOR value specifying the color of the video border. This property is read/write. The default video border color is black.

Remarks

Windows Media Player control draws a video border around the video display panel in the color specified by this property and with a width specified by the VideoBorderWidth property.
