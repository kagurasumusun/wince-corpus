CodecCount

This property contains the number of installable codecs used by the current clip.

Compatibility: Windows Media Player

[ "lCount" = ] MediaPlayer.CodecCount

Parameters

lCount
Long value representing the number of installable codecs. This property is read-only with no default value.

GetCodecDescription, GetCodecInstalled, GetCodecURL
