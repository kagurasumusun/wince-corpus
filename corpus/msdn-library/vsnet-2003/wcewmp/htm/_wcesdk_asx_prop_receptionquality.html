ReceptionQuality

This property contains the percentage of packets received in the last 30 seconds.

Compatibility: Windows Media Player

[ lPercent = ] MediaPlayer.ReceptionQuality

Parameters

lPercent
Long value specifying the percentage of packets received in the last 30 seconds. This property is read-only with no default value.

Remarks

Every second, Windows Media Player control monitors the number of packets received, lost, and recovered during streaming. The value of this property represents the percentage of packets not lost over the past 30 seconds.

Each time file playback stops and restarts, this property resets to zero. It does not reset if file playback is paused.

This property returns valid information only during run time and only if the FileName property is set.
