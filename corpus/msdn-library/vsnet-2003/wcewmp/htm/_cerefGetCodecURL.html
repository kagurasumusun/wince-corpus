GetCodecURL

This method retrieves the URL location containing additional information about the given codec.

Compatibility: Windows Media Player

sRetVal = MediaPlayer.GetCodecURL(
lCodecNum
)

Parameters

lCodecNum
Long value indicating the codec number.

Return Values

Returns a String value indicating the URL location that contains additional information about the given codec. This method returns a null string if the specified codec is not found.

Remarks

Codec numbers start with 1. You will get an error if you use zero. Typically, the codec number is 1 for audio and 2 for video. Valid values for codec numbers range from 1 to the value of the CodecCount property.
