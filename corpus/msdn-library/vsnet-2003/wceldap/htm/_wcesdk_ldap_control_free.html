ldap_control_free

This function frees an LDAPControl structure.

ULONG ldap_control_free(
LDAPControl *Control
);

Parameters

Control
[in] LDAPControl structure to free.

Return Values

If the function succeeds, the return value is LDAP_SUCCESS.

If the function fails, it returns an error code. See the LDAP_RETCODE enumeration for a list of possible return values.

Remarks

Use the ldap_control_free function to dispose of a previously allocated LDAPControl structure.
