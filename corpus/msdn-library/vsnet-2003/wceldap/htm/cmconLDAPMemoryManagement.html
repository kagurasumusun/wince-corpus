LDAP Memory Management

The following table shows the functions that provide memory management capability.

Function Description
ldap_control_free Frees an LDAPControl structure.
ldap_controls_free Frees an array of LDAPControl structures.
ldap_memfree Frees memory that was allocated from the LDAP heap.
ldap_msgfree Frees the results obtained from a previous call to ldap_result or to one of the synchronous search routines.
ldap_value_free Frees a structure that was returned by a call to the ldap_get_values function.
ldap_value_free_len Frees berval structures that were returned by a call to the ldap_get_values_len function.
