ldap_msgfree

This function frees the results obtained from a previous call to ldap_result or to one of the synchronous search routines.

ULONG ldap_msgfree(
LDAPMessage *res
);

Parameters

res
[in] Result or chain of results to free.

Return Values

If the function succeeds, it returns one of the following constants to indicate the type of message freed.

Return value
LDAP_RES_ADD
LDAP_RES_BIND
LDAP_RES_COMPARE
LDAP_RES_DELETE
LDAP_RES_EXTENDED
LDAP_RES_MODDN
LDAP_RES_MODIFY
LDAP_RES_SEARCH_ENTRY
LDAP_RES_SEARCH_REFERENCE
LDAP_RES_SEARCH_RESULT

Remarks

Call ldap_msgfree to free the result structure pointed to by the res parameter. The return value indicates the type of result freed.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Winldap.h Winldap.h Wldap32.lib
