Error Handling Functions

The following table shows the functions you can use to obtain or handle error messages.

Function Description
ldap_err2string Converts a numeric LDAP error code into a character string describing the error.
ldap_result2error Parses a message and returns the error code.
LdapGetLastError Retrieves the last error code returned by an LDAP call.
LdapMapErrorToWin32 Translates an LdapError value to the closest Microsoft® Win32® error code.
