ldap_get_dn

This function retrieves the distinguished name for a given entry.

UNICODE PTCHAR ldap_get_dn(
LDAP *ld,
LDAPMessage *entry
);

Parameters

ld
[in] Session handle.
entry
[in] Entry whose distinguished name is to be retrieved.

Return Values

If the function succeeds, it returns the distinguished name as a character string.

If the function fails, it returns NULL and sets the session error parameters in the LDAP data structure.

Remarks

The ldap_get_dn function retrieves the distinguished name for an entry that was returned by ldap_first_entry or ldap_next_entry. When the returned name is no longer needed, free the string by calling the ldap_memfree function.
