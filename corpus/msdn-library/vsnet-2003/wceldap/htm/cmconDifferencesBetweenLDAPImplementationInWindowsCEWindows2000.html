Differences Between the LDAP Implementation in Windows CE and Windows XP

If you are familiar with the Windows XP implementation of LDAP, you will be similarly familiar with the implementation available in Windows CE, which is largely the same. The following table shows the support distinctions:

Feature Available Support
Client-side operations Supported
Server-side operations Not Supported
Unicode Supported
Active Directory Service Interface (ADSI) Not Supported
