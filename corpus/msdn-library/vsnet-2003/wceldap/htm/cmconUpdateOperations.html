Update Operations

The update operations let you add and modify information in a specific directory. The following table shows the LDAP update operations that are supported in Windows CE.

Operation Description
add Creates a new directory entry.
delete Removes an entry from the directory.
modify Updates an existing directory entry.
modify DN Renames or moves entries in the directory.
