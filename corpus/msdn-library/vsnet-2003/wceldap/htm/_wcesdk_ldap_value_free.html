ldap_value_free

This function frees a structure that was returned by a call to the ldap_get_values function.

ULONG ldap_value_free(
UNICODE PTCHAR *vals
);

Parameters

vals
Structure to free.

Return Values

If the function succeeds, the return value is LDAP_SUCCESS.

If the function fails, it returns an error code. See the LDAP_RETCODE enumeration for a list of possible return values.

Remarks

Call ldap_value_free to free a structure that was returned by ldap_get_values.
