ldap_dn2ufn

This function converts a distinguished name to a user-friendly format.

UNICODE PTCHAR ldap_dn2ufn(
UNICODE PTCHAR dn
);

Parameters

dn
[in] Distinguished name to convert.

Return Values

If the function is successful, it returns the user-friendly name as a character string.

If the function fails, the return value is NULL.

Remarks

When given an entry's distinguished name, ldap_dn2ufn returns a character string containing the entry name in a user-friendly format. The nature of the user-friendly format depends on the directory service implementation and the type of entry. The return value remains in memory-allocated space until you call the ldap_memfree function.
