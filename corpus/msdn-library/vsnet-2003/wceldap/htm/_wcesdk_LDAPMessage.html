LDAPMessage

This structure is used by LDAP functions to return results and error information.

typedef ldapmsg LDAPMessage, *PLDAPMessage;

Members

None.

Remarks

LDAPMessage creates an opaque data type when a search or a traversal function is called.

To free the LDAPMessage structure when it is no longer needed, call the ldap_msgfree function.
