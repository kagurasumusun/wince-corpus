HeaderView_t

This class provides the ability to draw the nonclient area of a header control.

Method Description
HeaderView_t::CalcOffset Calculates an offset that is used to determine where to draw the header bitmap and text.
HeaderView_t::DrawButtonBorder Draws the border of a button in a header control.
HeaderView_t::Height Determines the height with which the header should be drawn.
