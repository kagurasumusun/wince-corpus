Gdi::SaveDC_I

This method saves the current state of the specified device context by copying data describing selected objects and graphic modes, such as the bitmap, brush, palette, font, pen, region, and drawing mode, to a context stack.

static WINGDIAPI int WINAPI SaveDC_I(
HDC hdc
);

Parameters

hdc
[in] Handle to the device context to be saved.

Return Values

If the function succeeds, the return value identifies the saved device context.

If the function fails, the return value is zero. To get extended error information, call GetLastError.

Remarks

This method is an internal version of the SaveDC function.

You can use the Gdi::SaveDC_I method any number of times to save any number of instances of the state of the context.

You can restore a saved state at a later time by using the Gdi::RestoreDC_I method.
