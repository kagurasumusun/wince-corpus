VirtualSetPageFlags

This function maps the VSPF_* defines to SH4 virtual page attribute flags and sets the flags for all the pages in the range specified by the lpvAddres and cbSize parameters. These flags correspond to bits in the Page Table Entry Assistance PTEA register. VirtualSetPageFlags should only be called by the SH4 PCMCIA driver.

BOOL VirtualSetPageFlags(
LPVOID lpvAddress, 
DWORD cbSize, 
DWORD dwFlags, 
LPDWORD lpdwOldFlags 
);

Parameters

lpvAddress
Starting virtual address of the memory region affected by VirtualSetPageFlags.
cbSize
Size of the lpvAddress memory region.
dwFlags
Contains the page flags to be applied to the memory region. The following table shows the valid flags.
Flag Description
VSPF_NONE Flag equal to 0.
VSPF_8BIT Flag equal to 0 (default).
VSPF_VARIABLE PCMCIA I/O space, data width is determined by the IOIS#16 signal.
VSPF_IOSPACE PCMCIA I/O space, 8-bit data path width.
VSPF_COMMON PCMCIA common memory space, 8 bit.
VSPF_ATTRIBUTE PCMCIA attribute memory space, 8 bit.
VSPF_16BIT Use in combination with another flag to implement 16-bit data path width.

All of these flags can be combined with the following flag as needed.

Flag Description
VSPF_TC Timing control for areas 5 and 6 (PCMCIA areas).

If VSPF_TC is specified, timing control register 1 is used to control timing for the region. If VSPF_TC is not specified, then timing control register 0 is used. The PCMCIA driver does not use VSPF_TC.

Other valid flag combinations are listed in the following table.

Flag Description
VSPF_IOSPACE | VSPF_16BIT PCMCIA I/O space 16-bit data path width.
VSPF_COMMON | VSPF_16BIT PCMCIA common memory space, 16 bit.
VSPF_ATTRIBUTE | VSPF_16BIT PCMCIA attribute memory space, 16 bit.
lpdwOldFlags
Pointer to a DWORD to receive the previous set of page flags for the memory region so they can be restored if needed.

Return Values

TRUE indicates success; FALSE indicates failure.

Remarks

The PCMCIA driver uses combinations of VSPF_IOSPACE, VSPF_COMMON, VSPF_ATTRIBUTE, VSPF_16BIT, VSPF_VARIABLE and VSPF_8BIT to map pages in the three PCMCIA memory spaces at 8 or 16 bit data path widths.
