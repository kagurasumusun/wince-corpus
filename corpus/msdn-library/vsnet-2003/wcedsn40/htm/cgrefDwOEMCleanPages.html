dwOEMCleanPages

This variable is set to signal the kernel how much memory should be zeroed to enable the device to boot. Any memory not zeroed at boot will be zeroed in a separate thread.

DWORD dwOEMCleanPages;

Parameters

None.

Return Values

None.

Remarks

If dwOEMCleanPages is set to 0 then all memory is zeroed, the default value.

Determine if enough memory has been zeroed at boot by creating a process that runs before any other applications in the system by placing it in HCLH\Init. When the application runs, enter kernel mode by calling SetKMode and access the data in KInfoTable[KINX_MINPAGEFREE]. This value indicates how much memory has been used to boot to that point. If you need to determine how much memory is required to fully boot your system, at an idle state use the application again and launch it after the system is fully up and idle.
