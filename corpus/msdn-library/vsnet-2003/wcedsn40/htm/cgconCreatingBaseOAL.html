Creating a Base OAL

In this step, you enable the serial port for debugging, initialize communication settings, and establish a system tick.

To create a base OAL

  1. Enable debugging over the serial port by implementing the required port settings, baud rate, and communications settings on the target device in the OEMInitDebugSerial function, and then implementing the other OAL serial port functions. For more information about setting up the serial port, see Enabling the Debug Serial Port.
  2. Implement the OEMInit function to register the interrupts for the interval timer. This function provides a system tick for your target device. For more information, see Implementing OEMInit.

Once your OAL has successfully passed the test in step 2, you are ready to enhance the functionality of your OAL by implementing the other features you choose to support on your target device.

For more information about features related to the OAL, see the following topics:

  • Interrupt Latency Timing
  • Cache Flush Routines
  • Kernel Independent Transport Layer
  • OEMAddressTable
  • Kernel States
  • Kernel Scheduler
  • Supported OAL APIs
  • Supporting CPU Utilization Functionality
  • Retrieving Registry-Targeted Data from the OAL
