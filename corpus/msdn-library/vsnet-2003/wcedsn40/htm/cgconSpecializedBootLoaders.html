Specialized Boot Loaders

Microsoft® also provides boot loaders with particular specialties in addition to the Ethernet boot loader provided with each board support package (BSP). Currently, these specialized boot loaders only address the needs of x86 platform solutions.

For more information about the specialized boot loaders, see one of the following topics:

  • x86 ROM Boot Loader
  • x86 BIOS Boot Loader
  • x86 Serial Boot Loader
