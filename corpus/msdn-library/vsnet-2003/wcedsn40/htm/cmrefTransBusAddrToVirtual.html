TransBusAddrToVirtual

This function translates a PCI bus-relative address to a system virtual address.

BOOL TransBusAddrToStatic(
IN INTERFACE_TYPE InterfaceType,
IN ULONG BusNumber,
IN PHYSICAL_ADDRESS BusAddress,
IN ULONG Length,
IN OUT PULONG AddressSpace,
OUT PPVOID MappedAddress
);

Parameters

InterfaceType
[in] Set to PCIBus of type INTERFACE_TYPE. This is the only one currently supported.
BusNumber
[in] The PCI bus number where the device resides.
BusAddress
[in] The PCI bus-relative address of registers and ports on the device.
Length
[in] The number of bytes to map on the device.
AddressSpace
[in] Indicates whether what is being mapped lives in PCI IO space or memory space
MappedAddress
[out] The virtual address where the physical address was mapped.

Return Values

TRUE if successful. FALSE if failure.

Remarks

The difference between TransBusAddrToVirtual and TransBusAddrToStatic is that TransBusAddrToStatic does not create a static mapping.

This function is used by a driver that just wants to get at its register and does not need to share this mapping.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Ceddk.h
