Ethernet Debug Drivers

The Ethernet debug driver, located in the %_WINCEROOT%\Public\Common\Oak\Drivers\Ethdbg directory, talks directly to the Ethernet controller. Microsoft provides implementations for a number of popular controllers.

The following table shows the location of the sample Ethernet debug drivers.

Sample driver Location
Am79c970dbg.lib %_WINCEROOT%\Public\Common\Oak\Drivers\Ethdbg\AM79C970
Dec21140dbg.lib %_WINCEROOT%\Public\Common\Oak\Drivers\Ethdbg\DEC21140
Dp83815dbg.lib %_WINCEROOT%\Public\Common\Oak\Drivers\Ethdbg\DP83815
Ne2kdbg.lib %_WINCEROOT%\Public\Common\Oak\Drivers\Ethdbg\NE2000
Rtl8139dbg.lib %_WINCEROOT%\Public\Common\Oak\Drivers\Ethdbg\RTL8139
Smc9000.lib %_WINCEROOT%\Public\Common\Oak\Drivers\Ethdbg\SMC9000
Smsc100.lib %_WINCEROOT%\Public\Common\Oak\Drivers\Ethdbg\SMSC100
