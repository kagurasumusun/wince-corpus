Using Internal GDI Methods

When you implement the methods to customize the UI, you usually need to call functions that are part of the graphics device interface (GDI). When an application developer calls a GDI function, the GDI function is processed by a thunk that then calls an internal version of the GDI function. When you create a skin, the architecture for creating a skin requires you to bypass the thunk, which you can do by calling the internal versions of the GDI functions directly. Windows CE provides these internal versions of the GDI functions as methods of three classes. The following table shows these classes that contain the internal GDI methods that you can use when creating a skin.

Class Description
Gdi Provides access to internal GDI functions that you can use when drawing controls.
GweBypassCoredllThunk_t Provides access to internal GDI functions that you can use when drawing controls.
StockObjectHandles Provides methods for retrieving handles to predefined stock objects.
