OEMInterruptHandlerFIQ

This function is implemented by the OEM to provide fast interrupt request (FIQ) support for the ARM microprocessor. 

void OEMInterruptHandlerFIQ (void);

Parameters

None.

Return Values

None.

Remarks

This function must be part of the OAL for any ARM build to succeed, even if it is just a stub. This function has a C calling convention with a limited stack space of 256 bytes. If no FIQs are generated by the hardware, then the function should remain empty. The FIQ is intended as a quick entry/exit interrupt. As such, there are a few limitations on this code:

  • OEMInterruptHandlerFIQ cannot return a value to the kernel to invoke an IST. However, it can perform urgent processing and generate an IRQ, which may then return a SYSINTR value.
  • FIQs do not nest and may interrupt any IRQ interrupt handler. Nested interrupts can be achieved in OEMInterruptHandler by calling INTERRUPTS_ON.
  • An FIQ ISR may not alter any memory that is updated elsewhere with the interlocked functions. To maintain performance of the FIQ handling, interlocked restart is not enabled for FIQ.
