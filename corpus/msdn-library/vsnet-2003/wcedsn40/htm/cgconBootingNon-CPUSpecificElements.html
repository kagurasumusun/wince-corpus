Booting Non-CPU Specific Elements

Once your kernel is initialized, it will perform the following steps.

To boot non-CPU specific elements

  1. Create the Filesys.exe event SYSTEM/FSReady and launch Filesys.exe.
  2. Wait for the event to be triggered. See the Filesys.exe Boot Process.
  3. Filesys.exe initializes the object store.
  4. Filesys.exe sets the SYSTEM/FSReady event to release the kernel from waiting on the thread.
  5. Filesys.exe waits for the kernel to finish initializing.
  6. The kernel reads the registry for the values for the following registry keys.

    HKEY_LOCAL_MACHINE\Loader\SystemPath

    HKEY_LOCAL_MACHINE\SYSTEM\OOM\cbLow and cpLow

    HKEY_LOCAL_MACHINE\SYSTEM\KERNEL\InjectDLL

    HKEY_LOCAL_MACHINE\MUI\Enable and SysLang

    HKEY_CURRENT_USER\MUI\CurLang

  7. The kernel sets up the out of memory handler until another application resets it.
  8. The kernel initializes the multi-language user interface (UI) if required.
  9. The kernel signals the waiting Filesys.exe.
