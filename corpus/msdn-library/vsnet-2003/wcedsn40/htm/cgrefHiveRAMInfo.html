HiveRAMInfo

This structure contains information for use in conjunction with the IOCTL_HAL_GET_HIVE_RAM_REGION IOCTL.

typedef struct HiveRAMInfo {
WORD wVersion;
WORD wFlags;
HiveRAMRegion SystemRegion;
} HiveRAMInfo;

Members

wVersion
This version of this structure. Set to 1.
wFlags
The required and only supported flag is HIVE_REGION_COMBINED. This means that the system and the user are in the same hive.
SystemRegion
The region to use for the system hive; this is of type HiveRAMRegion.

Remarks

This structure is extensible, so you must fill in the wVersion parameter to prevent future incompatibility. The registry calls the IOCTL_HAL_GET_HIVE_RAM_REGION IOCTL during the first boot phase to determine whether there is a region of RAM suitable to store the data.
