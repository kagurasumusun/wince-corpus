IOCTL_HAL_GET_DEVICE_INFO

This input/output control provides information about the systems parameter information (SPI) codes supported by SystemParametersInfo. A request to retrieve the systems parameter information (SPI) codes is made by calling OEMIoControl with IOCTL_HAL_GET_DEVICE_INFO.

Parameters

dwIoControlCode
Set to IOCTL_HAL_GET_DEVICE_INFO to get information about the systems parameter information (SPI) codes supported by SystemParametersInfo.
lpInBuf
Pointer to a DWORD containing one of the SPI_* codes in the following table.
Value Description
SPI_GETPLATFORMTYPE String specifying the type of Windows CE device.
SPI_GETOEMINFO String specifying OEM information that distinguishes this specific device from others of the same type.
nInBufsize
Size in bytes of lpInBuf, which must be 4.
lpOutBuf
Pointer to the output buffer supplied by the caller. Your OAL implementation should place the information requested by the parameters dwIoControlCode and lpInBuf into lpOutBuf, set lpBytesReturned to indicate the size of the data in lpOutbuf, and return TRUE. If the size of the requested information exceeds the buffer size specified by nOutBufSize, call SetLastError with the flag ERROR_INSUFFICIENT_BUFFER and return the value FALSE.
nOutBufSize
Specifies the maximum number of bytes that can be returned in lpOutBuf. The caller sets this value.
lpBytesReturned
Number of bytes returned in lpOutBuf.

Return Values

If TRUE is returned, the input/output control was successfully processed; otherwise, FALSE is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later   Pkfuncs.h
