Internet Explorer 5.5 for Windows CE Features

Internet Explorer 5.5 for Windows CE is the most desktop-compatible, feature-rich browser for the Windows CE operating system. Choose this browser when building a platform that will provide full Internet access, such as an Internet appliance or an interactive television that offers browsing capabilities.

You can use the Internet Explorer Component Object Model (COM) interfaces to build a custom browser or to add browser controls to an application. Alternatively, you can use the sample Internet Explorer container application source files (Iesample.*) to create a browser shell and user interface designed specifically for your target device. The browser host supports the use of pointing devices and 5-key navigational systems as well as keyboard and touch screen input.

The browser is capable of rendering documents that contain HTML, Dynamic HTML, and CSS data formats. XML support is available if the MSXML parser is included in the platform. As a scripting host, Internet Explorer supports Microsoft JScript® 5.5 and Microsoft Visual Basic® Scripting Edition, Microsoft VBScript® 5.5, when these features are included on a platform.
