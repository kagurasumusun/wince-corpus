Rebooting the Target Device

You have the option of implementing IOCTL_HAL_REBOOT in OEMIoControl to reboot the target device. For example, you can display a dialog box to query the user to reboot the target device. Platform Builder provides a sample implementation in the %_WINCEROOT\Platform\Cepc\Kernel\Hal directory.
