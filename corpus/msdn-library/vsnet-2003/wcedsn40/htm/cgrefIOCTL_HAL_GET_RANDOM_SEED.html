IOCTL_HAL_GET_RANDOM_SEED

This input/output control returns random bytes from a hardware source.

Parameters

dwIoControlCode
Set to IOCTL_HAL_GET_RANDOM_SEED.
lpInBuf
Set to NULL.
nInBufSize
Set to 0.
lpOutBuf
Set to the address of an allocated output buffer for storing the random bytes.
nOutBufSize
Set to the size of the output buffer.
lpBytesReturned
DWORD pointer to receive the size of data returned in lpOutBuf.

Return Values

If TRUE is returned, the input/output control was successfully processed; otherwise, FALSE is returned.

Remarks

This request is used by the random number generator to query the platform hardware for additional sources of random data, such as a high-frequency counter. If the system has provided support for IOCTL_HAL_GET_RANDOM_SEED, TRUE is returned for a successful operation. The number of bytes of random data returned may be less than nOutBufSize. If no suitable random source is present on the platform or the request fails, FALSE is returned. If FALSE is returned, call GetLastError for details.
