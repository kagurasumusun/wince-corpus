KLibAllocShareMem

This function allocates memory that can be shared between the ISR and IST.

BOOL KLibAllocShareMem(
DWORD nPages,
BOOL fNoCache,
LPVOID *pVa,
LPVOID *pPa
);

Parameters

nPages
Number of pages of memory to allocate.
fNoCache
If set to TRUE, non-cached memory is used; otherwise, cached memory is used.
pVa
Pointer to a virtual memory location that can be used by the IST to access the memory.
pPa
Pointer to a statically mapped virtual address that can be used by the ISR to access the memory.

Return Values

None.

Remarks

The OEM that installed the ISR handler is responsible for getting the pPa pointer to the OAL. This can be done by using KernelLibIoControl.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Pkfuncs.h Coredll.lib
