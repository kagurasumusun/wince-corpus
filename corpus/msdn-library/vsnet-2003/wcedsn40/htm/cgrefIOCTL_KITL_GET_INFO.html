IOCTL_KITL_GET_INFO

This input/output control is called to return information that is specific to the KITL transport.

Remarks

The parameters and semantics are left up to the implementer. The OEM can implement this IOCTL to provide KITL information to applications and drivers.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Pkfuncs.h
