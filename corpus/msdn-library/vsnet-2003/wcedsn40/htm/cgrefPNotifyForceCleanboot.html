pNotifyForceCleanboot

This function is called by Filesys.exe when a cold boot of the object store is about to occur.

void pNotifyForceCleanboot(
DWORD dwReserved1,
DWORD dwReserved2,
DWORD dwReserved3,
DWORD dwReserved4
);

Parameters

dwReserved1
Reserved, always set to 0.
dwReserved2
Reserved, always set to 0.
dwReserved3
Reserved, always set to 0.
dwReserved4
Reserved, always set to 0.

Return Values

None.

Remarks

If you expect to have a warm reset of the object store where the state is preserved and pNotifyForceCleanboot is called, the state of the memory used by Filesys.exe was not persevered.

If you expected to have pNotifyForceCleanboot called on a warm reset or cold boot and it is not, then it means that the state of the memory was not cleaned before Filesys.exe was launched.

If Filesys.exe finds its signature still in RAM on a cold or warm boot, it assumes that it should use the state of the memory as is and not reinitialize.
