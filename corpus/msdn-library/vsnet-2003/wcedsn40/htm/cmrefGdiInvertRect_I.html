Gdi::InvertRect_I

This method inverts a rectangle in a window by performing a logical NOT operation on the color values for each pixel in the interior of the rectangle.

static WINUSERAPI BOOL WINAPI InvertRect_I(
HDC hdc,
const RECT *lprc
);

Parameters

hdc
[in] Handle to the device context.
lprc
[in] Pointer to a RECT structure that contains the logical coordinates of the rectangle to be inverted.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

On monochrome screens, Gdi::InvertRect_I makes white pixels black and black pixels white. On color screens, the inversion depends on how colors are generated for the screen. Calling Gdi::InvertRect_I twice for the same rectangle restores the display to its previous colors.
