IOCTL_HAL_GET_HIVE_RAM_REGION

This IOCTL allows you to specify a region of RAM to hold the registry hive instead of using it as a memory-mapped file on a file system.

Parameters

dwIoControlCode
[in] Set to this IOCTL, IOCTL_HAL_GET_HIVE_RAM_REGION.
lpInBuf
[in] Ignored, set to NULL.
nInBufsize
[in] Ignored, set to 0.
lpOutBuf
[out] A pointer to a HiveRAMInfo structure filled in by this IOCTL.
nOutBufSize
[in] The size of a HiveRAMInfo structure, for example, sizeof(HiveRAMInfo).
lpBytesReturned
[out] Ignored, set to NULL.

Return Values

If returns TRUE, the IOCTL was successfully processed; otherwise, returns FALSE.

Remarks

The registry calls the IOCTL_HAL_GET_HIVE_RAM_REGION IOCTL during the first boot phase to determine whether there is a region of RAM suitable to store the data. The registry data will be stored into the given region of RAM and will persist as long as that RAM persists.

When registry data is stored in a RAM region, the user hive and system hive are stored together. There is no separate user hive, so there is no way to maintain separate copies of HKEY_CURRENT_USER for each user. Therefore, all users will share the same registry. User profile directories will still be created for each user, and will be placed in the object store as specified by the ProfileDir registry subkey. For more information, see User Profile Storage.

The following code example shows an example implementation of IOCTL_HAL_GET_HIVE_RAM_REGION. 

    case IOCTL_HAL_GET_HIVE_RAM_REGION : {
        HiveRAMInfo *pRAMInfo = (HiveRAMInfo*) lpOutBuf;

        if (lpInBuf || nInBufSize || !lpOutBuf || (nOutBufSize != sizeof(HiveRAMInfo))) {
            SetLastError(ERROR_INVALID_PARAMETER);
            break;
        }
        
        pRAMInfo->wVersion = 1;
        pRAMInfo->wFlags = HIVE_REGION_COMBINED;
        pRAMInfo->SystemRegion.lpStart = (LPVOID)0x80100000;
        pRAMInfo->SystemRegion.dwLength = 0x00020000;
        pRAMInfo->SystemRegion.dwVirtCopyFlags = PAGE_NOCACHE;
        
        return TRUE;
    }

The SystemRegion.lpStart and SystemRegion.dwLength members are fully under your control; the values shown here are example values.
