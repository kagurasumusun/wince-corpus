SHx Variables

The SH3 OEM adaptation layer (OAL) requires the following variables to be exported in order to compile and link the kernel:

  • _SH3CacheLines
  • _SH3DSP
  • _SH3FQCR_Fast

The SH4 OEM adaptation layer (OAL) requires the following variable to be exported in order to compile and link the kernel:

  • _SH4CacheLines

These variables must be declared in a code section, not a data section, or the variable's value will not be set properly when the kernel initializes.

For sample implementations of these variables, see the Fw.src file in the %_WINCEROOT%\Platform\Keywest\Kernel\Hal\Sh directory.
