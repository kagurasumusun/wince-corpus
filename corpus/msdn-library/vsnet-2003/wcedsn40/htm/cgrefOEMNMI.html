OEMNMI

This function is implemented by the OEM to support a non-maskable interrupt. This function is specific to SH3 and SH4.

Parameters

In register bank, 1 is the exceptions block.

Return Values

The return value is stored in r0.

Remarks

This function is treated like a normal ISR in that it can return a SYSINTR_* value to the kernel. The registers r0-r3 and r6 are available for use during the NMI by default.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later     Nk*.lib
