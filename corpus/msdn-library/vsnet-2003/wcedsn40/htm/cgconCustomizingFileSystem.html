Customizing the File System

You can customize your file system by modifying the registry type, changing how the file system stores data, and adding support for user profiles. You can also request additional security keys and synchronize file and database information.

The following topics describe these modifications:

  • Customizing File Storage
  • Customizing the Registry
  • User Profiles
  • Request Additional Secure Registry Keys
  • File and Database Replication
