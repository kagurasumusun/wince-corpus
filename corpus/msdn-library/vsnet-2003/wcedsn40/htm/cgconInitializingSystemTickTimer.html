Initializing the System Tick Timer

The system tick timer should be initialized in OEMInit with a call to InitClock, also defined in the OAL.

If the target device contains high-resolution timers OEMInit should also set the pQueryPerformanceCounter and pQueryPerformanceFrequency global variables. For more information about high-resolution timers, see Supporting High-Resolution Timers.
