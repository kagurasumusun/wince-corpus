Customizing Common Controls

You can customize a subset of the common controls when you create a skin. To customize a common control, change the code contained in the appropriate file in the %_WINCEROOT%\Public\Common\Oak\Drivers\Skinnableui\Commctrl directory. Each control corresponds to a C++ class that contains methods that are implemented in the files in this directory. You customize the control by modifying the implementation of these methods.

The following table shows the common controls that you can customize, the name of the class that contains the methods that you must implement to customize the control, and the file in the %_WINCEROOT%\Public\Common\Oak\Drivers\Skinnableui\Commctrl directory that contains the implementation of those methods.

Common control Class File name Customizable element
header control HeaderView_t Headerview.cpp The position of the header bitmap and text, the border of buttons that the header control contains, and the height of the header control.
progress bar ProgressBarView_t Progressview.cpp The code used to draw the entire progress bar.
rebar RebarView_t Rebarview.cpp The gripper and the spacing between items in the rebar.
tab control TabView_t Tabview.cpp The code for drawing the tab control.
toolbar ToolBarView_t Toolbarview.cpp The location at which a button image on the toolbar is drawn when the user presses or checks the corresponding button, the border of buttons on the toolbar, drop-down arrows on the toolbar, the bounding rectangle of the face of a button on the toolbar, the amount of horizontal and vertical space that the border and sides on a button on the toolbar occupy, and the system-defined bitmaps displayed on toolbar buttons.
trackbar TrackBarView_t Trackbarview.cpp The channel, focus rectangle, thumb, and tick marks for the trackbar.

Because a command band is both a rebar and a toolbar, you also can customize the command band by customizing the rebar and toolbar. You can customize the command bar by customizing the buttons and combo boxes that the command bar contains. You can customize a property sheet by customizing the tab controls that the property sheet contains. For information on customizing buttons and combo boxes, see Customizing Window Controls.

You cannot customize the following common controls by using a skin:

  • Date and time picker
  • Image list
  • List view
  • Month calendar control
  • Status bar
  • ToolTip control
  • Tree view
  • Up-down control

The %_WINCEROOT%\Public\Common\Oak\Drivers\Skinnableui\Commctrl directory also contains the Commctrlview.cpp file, which implements the CommCtrlView_t::Init method. You can implement this method to perform any one-time initializations that you need when customizing the common controls.

For more information about common controls, see Working with Common Controls.
