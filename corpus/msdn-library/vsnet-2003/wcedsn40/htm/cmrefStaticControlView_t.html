StaticControlView_t

This class provides methods for drawing a customizable UI for a static control.

Method Description
StaticControlView_t::DrawStaticImage Draws an image on a static control. The image can be either a bitmap or an icon.
StaticControlView_t::DrawStaticText Draws the text for a static control.
StaticControlView_t::ResizeRectToImage Computes the rectangle used to resize the static control window to the image size.
