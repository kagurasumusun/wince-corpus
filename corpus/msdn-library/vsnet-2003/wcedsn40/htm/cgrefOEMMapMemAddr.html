OEMMapMemAddr

This function is used to handle downloads that are destined for flash. It remaps a flash-resident address to a unique RAM-based address so that flash images can be temporarily cached in RAM while the download occurs. This provides enough time to handle the flash update while not stalling the download process because the flashing operation typically takes more time than downloading does.

LPBYTE OEMMapMemAddr(
DWORD dwImageStart,
DWORD dwAddr
);

Parameters

dwImageStart
Start address of image.
dwAddr
Address of a BIN record. If this address lies in a platforms flash address space, typically the offset from dwImageStart is computed and added to a RAM-based file cache area.

Return Values

Address at which the BIN record should be copied to provide file caching before and during the flash update process.

Requirements

Windows CE OS .NET 4.0 and later Platform code Blcommon.h
