The IESample Browser

The IESample user interface has many of the features of Internet Explorer 5.5 for Windows, including forward and backward navigation, Favorites, and Search. The following illustration shows the default IESample window.

If you are creating a custom container application we strongly recommend that you use the IESample source code (or IESimple for a full-screen application) as your starting point, adding or removing features as needed.

For example, you may wish to add online help. IESample does not include the online help system used by other Windows platforms and their applications. Windows CE applications use a help system provided by Pocket Internet Explorer. However, you can add online help by creating a Help button on the menu bar that opens an html file containing user help information. The help page can contain a navigation button to close the help page, or the user can use the Back button on the browser itself to navigate back to the original page.

You may also want to display the current security zone in the browser status bar. For information about adding the URL Security Zone status to IESample, see Displaying the Current Security Zone.

For information about default registry settings for IESample, see IESample Registry Settings.
