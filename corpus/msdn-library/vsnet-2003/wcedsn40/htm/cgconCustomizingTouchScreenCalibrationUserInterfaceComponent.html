Customizing the Touch Screen Calibration User Interface Component

The Touch Screen Calibration User Interface component, Calibrui, controls the appearance of the Windows CE touch screen calibration window. User calibration is necessary because of the physical nature of touch screen devices. For example, on the Handheld PC (H/PC), a user is prompted to tap the stylus at various points, indicated by a cross-hair cursor, on the screen before the device is ready for first use.

If your application has a dramatically different touch screen display size or orientation, you may want to replace the default Calibrui component with a UI that is more appropriate for your target platform. To customize Calibrui, modify and rebuild the code located in %_WINCEROOT%\Public\Common\Oak\Drivers\Calibrui. A touch screen calibration UI component must implement the following functions, as defined by the Calibrui.h header file:

  • TouchCalibrateUI_DrawConfirmationScreen
  • TouchCalibrateUI_HandleUserInputMessage
  • TouchCalibrateUI_Initialize
  • TouchCalibrateUI_WaitForConfirmation

In addition, the Calibrui component uses the following function:

  • TouchCalibrateUI_Done
