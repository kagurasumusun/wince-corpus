Residential Gateway Security

This feature has the following potential security risks:

With a Windows CE-based gateway device, a user can tunnel point-to-point from a public network into a private network, using PPTP. Point-to-point tunneling provides a user with the ability to connect to a home or small office network from a remote computer. The built-in firewall will prevent this connection by default for security reasons. However, you can configure the firewall to allow this connection by creating a static port mapping for TCP port 1723. For more information about PPTP server, see RAS Server/PPTP Server Incoming

IPv6 is not enabled by default when added to the image for security reasons. You can enable IPv6 with the sample network administrator ISAPI only if the device supports a persistent registry. Most sample CEPC images, for example, do not support a persistent registry.

Note   Ensure you understand the security consequences of enabling IPv6 routing on the device.

The Common.reg file disables IPv6 routing if the IPv4 network address translator (NAT) is also included in the image. You can change or remove that restriction from the Common.reg file or you can add the following to your Project.reg file:

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\ipv6hlp]
   "Prefix"="V6H"
   "Dll"="ipv6hlp.dll"
   "Index"=dword:1
   "Order"=dword:4

IPv6

IPv6 is not enabled by default when added to the image for security reasons. You can enable IPv6 with the sample network admin ISAPI only if the device supports a persistent registry.

If you would like to enable IPv6 during the build so it is enabled by default, complete the following steps:

Note   Microsoft recommends you review the IPv6 documentation and the security docs in particular to make sure you understand the security consequences of enabling IPv6 routing on the device.
  1. Currently Common.reg disables IPv6 routing if the v4 NAT is also included in the image. You can change or remove that restriction from Common.reg as follows. First, locate the following section of the file. 
    ; @CESYSGEN IF CE_MODULES_IPV6HLP && !CE_MODULES_IPNAT
[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\ipv6hlp]
   "Prefix"="V6H"
   "Dll"="ipv6hlp.dll"
   "Index"=dword:1
   "Order"=dword:4
; @CESYSGEN ENDIF   

; @CESYSGEN IF CE_MODULES_IPNAT
[HKEY_LOCAL_MACHINE\Comm\AFD]
   "Stacks"=multi_sz:"tcpstk","irdastk","btd"
; @CESYSGEN ENDIF

    Recognize that the section is prefaced by the following comment. 

    ; Disable IPv6 by default if IPNAT selected.  This is to avoid compromising 
; security for gateway devices, since the v6 firewall does not filter 
; routed packets.  For OEMs where this is not a concern, the following 
; setting may be removed.  Also, the user may enable IPv6 through the 
; NatAdmin sample configuration web page.
  2. Change the comments as follows. 
    ; removed the IF that excluded this
[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\ipv6hlp]
   "Prefix"="V6H"
   "Dll"="ipv6hlp.dll"
   "Index"=dword:1
   "Order"=dword:4

; and comment out (or remove) the following so that this key does not get set.
; @CESYSGEN IF CE_MODULES_IPNAT
;[HKEY_LOCAL_MACHINE\Comm\AFD]
;   "Stacks"=multi_sz:"tcpstk","irdastk","btd"
; @CESYSGEN ENDIF
