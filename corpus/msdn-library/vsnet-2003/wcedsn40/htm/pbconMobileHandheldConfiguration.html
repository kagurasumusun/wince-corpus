PDA or Mobile Handheld Device Configuration

Form-Factor Target

The PDA or Mobile Handheld configuration is targeted to provide functionality for personal digital assistants (PDAs) and clamshell-and-keyboard styled devices. A mobile handheld is a portable device that gives the user access to a variety of functionality including Internet access, an address book, a calendar, and e-mail. PDAs allow users to carry powerful business tools in a small, lightweight device.

The PDA or Mobile Handheld configuration allows a wide range of functionality. There are two variants of the Mobile Handheld configuration that can be selected during the creation of the platform from the New Platform Wizard. The variants are described in the following table.

Configuration variant Description
PDA/Mobile Handheld

Includes the base operating system, the Standard Windows CE Shell, ActiveSync, and a choice of browsers and other applications.
PDA/Mobile Handheld with Applications Includes the features in the PDA/Mobile Handheld variant, as well as Inbox, Windows Media Player, and WordPad.

The features and Sysgen variables listed in the preceding table are those required for this configuration, and are referred to as anchored features. Anchored features include both those features and Sysgen variables required by the specified configuration and any other features you choose to add to your platform. When you build a new platform, however, you will notice that additional elements can show up in the feature list. These additional elements, referred to as nonanchored features, are included when the anchored features have dependencies on operating system elements not specifically included with the selected configuration.

While you may be able to select from among the anchored features as you work through the New Platform Wizard, the nonanchored features that are included based on the choices you make cannot be removed from the configuration.
