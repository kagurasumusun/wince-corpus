Bluetooth Protocol Architecture

The complete protocol stack consists of both Bluetooth-specific protocols and non-Bluetooth-specific protocols. The protocol stack was designed to enable the re-use of existing protocols for various functions. This also allows for the adaptation of existing applications to work with Bluetooth and to ensure that these applications work smoothly and are interoperable.

For more information, see Bluetooth Protocol Stack Architecture in the device driver development guide. Also, see the Bluetooth Protocol Stack for more information about the Bluetooth stack implementation in Windows CE.
