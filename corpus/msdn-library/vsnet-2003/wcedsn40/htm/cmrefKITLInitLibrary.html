KITLInitLibrary

This function initializes the Kernel Independent Transport Layer (KITL) subsystem for use by a client/server application.

BOOL KITLInitLibrary(
LPCWSTR pszRegKeyRoot
);

Parameters

pszRegKeyRoot
Pointer to a string that specifies the root registry location where all the relative KITL information is stored. A client process always passes NULL.

Return Values

If KITL is initialized, TRUE is returned; otherwise, FALSE is returned.

Remarks

All applications that load Kitldll.dll must call KITLInitLibrary before performing any KITL application programming interfaces (APIs).
