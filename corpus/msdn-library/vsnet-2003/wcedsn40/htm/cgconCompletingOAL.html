Completing an OAL

Completing an OAL is the final step of creating an OAL. In this stage, you can implement any other features you choose to support.

To complete an OAL

  1. Implement process logging functions in the OAL.
  2. Create a CEDDK.
  3. Define extension memory.
  4. Erase the object store.
  5. Implement support for high-resolution timers.
  6. Configure the system registry.
