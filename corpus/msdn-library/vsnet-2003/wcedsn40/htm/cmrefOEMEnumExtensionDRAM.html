OEMEnumExtensionDRAM

This function returns information about extension DRAM, if present on the device.

DWORDOEMEnumExtensionDRAM(
PMEMORY_SECTION pMemSections,
DWORD cMemSections
);

Parameters

pMemSections
[in/out] Address of the MEMORY_SECTION array.
cMemSections
[in] Number of entries in pMemSections.

Return Values

The number of memory sections that are described to the kernel.

Remarks

This function is called only once and requires that all the MEMORY_SECTION information is complete. Confirm that the number of filled memory sections is less than cMemSections.

If your platform only has, and will only ever have, two noncontiguous memory sections, you can continue to use OEMGetExtensionDRAM.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Nkintr.h Nkintr.h
