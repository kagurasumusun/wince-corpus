HeaderView_t::DrawButtonBorder

This method draws the border of a button in a header control.

static void DrawButtonBorder(
HDC hdc,
DWORD style,
LPRECT prc,
BOOL fItemSunken
);

Parameters

hdc
[in] Handle to a device context.
style
[in] DWORD that specifies the style of the button border. The following table shows the possible values.
Header control styles Description
HDS_BUTTONS Causes each header item to look and behave like a button. This style is useful if an application carries out a task when the user clicks an item in the header control.
HDS_DRAGDROP Enables drag-and-drop reordering of header items.
HDS_FULLDRAG Causes the header control to display column contents even while a user resizes a column.
HDS_HIDDEN Allows you to hide a header control by setting its height to zero. This style is useful when you use the control as an information container instead of a visual control.
HDS_HORZ Orients a header control horizontally.
HDS_HOTTRACK Enables hot tracking.
prc
[in] Pointer to a RECT structure that specifies the bounding rectangle of the button.
fItemSunken
[in] Boolean that specifies whether to draw the border with a sunken edge. TRUE indicates that the border should be drawn with a sunken edge. FALSE indicates that the border should not be drawn with a sunken edge.

Return Values

None.
