MainMemoryEndAddress

This global variable specifies the next available address following the first available contiguous block of memory.

DWORD MainMemoryEndAddress;

Remarks

Setting this global variable is optional. The file Config.bib sets the main memory size. Setting MainMemoryEndAddress within the function OEMInit allows you to alert the system that extended RAM is available. You can identify whether extended RAM is available by calling OEMGetExtensionDRAM or pNKEnumExtensionDRAM.

Requirements
