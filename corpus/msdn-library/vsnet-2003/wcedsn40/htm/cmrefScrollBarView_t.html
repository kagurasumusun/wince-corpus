ScrollBarView_t

This class provides methods for drawing scroll bars.

Method Description
ScrollBarView_t::DrawScrollBar Draws a scroll bar.
ScrollBarView_t::GetScrollRects Calculates rectangles that are used for drawing and hit testing scroll bars.
ScrollBarView_t::GetThumbPixel Retrieves the top thumb coordinate for a vertical scrollbar and the left thumb coordinate for a horizontal scrollbar.
ScrollBarView_t::ScrollHitTest Determines where a specified point is located within a scroll bar.
ScrollBarView_t::TrackThumb Determines where to position the scroll thumb given a specified point, then redraws the thumb at that location.
