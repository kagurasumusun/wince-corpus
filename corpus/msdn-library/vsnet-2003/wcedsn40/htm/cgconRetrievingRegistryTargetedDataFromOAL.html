Retrieving Registry-Targeted Data from the OAL

There are times when data is collected during the boot process that must be communicated to the rest of the system in order to coordinate the system state. If the OAL initializes a PCI based card to a know state, that information needs to be propagated to the PCI plug and play manager to avoid any conflict with IRQ and I/O space. You can obtain state information during the early boot phase and then save it to the system registry prior to any applications, other then the kernel, Filesys.exe, and possibly Device.exe, being started. The process starts with IOCTL_HAL_INITREGISTRY from Filesys.exe. IOCTL_HAL_INITREGISTRY indicates that the system registry is ready to accept data from the OAL. You can then use the following functions to add data to the system registry:

  • RegCreateKeyEx
  • RegQueryValueEx
  • RegSetValueEx
  • RegCloseKey
