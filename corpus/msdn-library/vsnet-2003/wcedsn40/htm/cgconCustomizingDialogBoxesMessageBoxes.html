Customizing Dialog Boxes and Message Boxes

A dialog box is a temporary window that contains controls. A dialog box is used to display status information and to prompt the user for input. Windows CE supports two types of dialog boxes: modal and modeless. A modal dialog box requires the user to supply information or dismiss the dialog box before enabling the application to continue. A modeless dialog box enables the user to supply information and return to a previous task without closing the dialog box.

A message box is a modal dialog box that displays a message and prompts for user input. A message box typically contains a text message and one or more predefined buttons. The message box component, Msgbox, controls the appearance and behavior of message boxes. Windows CE allows you to customize the size and location of message boxes for your platform by specifying new values for the associated registry keys.

To include message boxes and dialog boxes with a complete UI in your platform

  1. Ensure that the Gwe module includes the following components:
    • dlgmgr
    • dlgmnem
    • msgbox
    • msgbox28
  2. Ensure that your Cesysgen.bat file includes the messagedialogboxthunk component.

    The following code example shows the line that the cesysgen.bat file should contain to include the messagedialogboxthunk component. 

    set COREDLL_COMPONENTS=%COREDLL_COMPONENTS% messagedialogboxthunk

For more information about dialog boxes and message boxes, see Creating Dialog Boxes and Message Boxes.
