TransportGetDevCfg

This function is used by KITL to get the device side KITL transport configuration information.

PFN_GETDEVCFG TransportGetDevCfg(
LPBYTE pbBuffer,
PUSHORT pcbBuffer
);

Parameters

pbBuffer
Pointer to a buffer used to receive the data from the transport.
pcbBuffer
Set to the size of the buffer when called and then reset by the KITL transport to the size of data written to the pbBuffer buffer.

Return Values

Returns TRUE if data is added to the buffer; otherwise, returns FALSE. If the transport has no device configuration information like a serial port, set pcbBuffer to 0 and return TRUE.

Remarks

Assign TransportGetDevCfg to the pfnGetDevCfg member of KITLTRANSPORT during OEMKitlInit.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Kitl.h Kitl.h
