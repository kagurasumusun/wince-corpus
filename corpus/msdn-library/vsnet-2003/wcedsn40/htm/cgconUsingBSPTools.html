Using the BSP Tools

The BSP tools in the Platform Builder IDE allow you to accomplish the following tasks:

  • Create a new BSP by cloning an existing BSP and adding it to the IDE Catalog using the BSP Wizard.
  • Add an existing BSP to the IDE Catalog by creating a new BSP definition with the BSP Wizard.
  • Use your BSP in a sample platform by using the new Platform Wizard tool. For more information, see Platform Creation with the New Platform Wizard.
  • Export a BSP for use by OEM customers by using the Export Wizard tool.
  • Import a third-party BSP into the IDE Catalog.
