ComboBoxView_t

This class provides methods for drawing portions of the user interface associated with a combo box.

Method Description
ComboBoxView_t::DrawFocus Draws a focus rectangle around the item in the edit control of a combo box.
ComboBoxView_t::TopCoordinate Retrieves the y-coordinate of the top of the bounding rectangle for a combo box.
ComboBoxView_t::WindowStyleCustomization Sets the border style for a combo box.

Remarks

The drawing is restricted to the nonclient area.
