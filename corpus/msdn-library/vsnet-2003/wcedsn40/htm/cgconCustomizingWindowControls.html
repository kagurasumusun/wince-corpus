Customizing Window Controls

You can customize the window controls when you create a skin. To customize a window control, change the code contained in the files that are located in the appropriate subdirectory of the %_WINCEROOT%\Public\Common\Oak\Drivers\Skinnableui\Gwe directory. Each control corresponds to a C++ class that contains methods that are implemented in the files in these subdirectories. You customize the control by modifying the implementation of these methods.

The following table shows the window controls that you can customize, the name of the class that contains the methods that you must implement to customize the control, and the subdirectory and file in the %_WINCEROOT%\Public\Common\Oak\Drivers\Skinnableui\Gwe directory that contains the implementation of those methods.

Window control Class Subdirectory and file name Customizable element
button ButtonView_t Btnctl\Buttonview.cpp The state and style of push buttons; the text in a group box; the code used to paint a group box; the text or focus rectangle of a button; the initialization of the device context for drawing a button; the code used to hit test a button, which is the process of detecting whether the user clicked the mouse or tapped the stylus within the rectangle for a button; and the code used to draw radio buttons, check boxes, and buttons.
combo box ComboBoxView_t Cmbctl\Comboboxview.cpp The style of the border of the combo box, the focus rectangle around an item in the list box portion of the combo box, and the y-coordinate of the top of the bounding rectangle for the combo box.
list box ListBoxView_t Lbctlview\Listboxview.cpp The height of items in the list box, the focus rectangle around an item in the list box, and the y-coordinate at which the text of an item in the list box should be drawn.
scroll bar ScrollBarView_t Sbcmn\Sbcmnview.cpp The rectangles used to draw and hit test the scroll bar, the code for retrieving the top thumb coordinate for a vertical scrollbar and the left thumb coordinate for a horizontal scrollbar, the code for determining where a specified point is located within a scroll bar, the code for determining where to position and draw the scroll thumb for a specified point, and the code for drawing the scroll bar.
static control StaticControlView_t Stcctl\Statctlview.cpp The image for the static control and the formatting of the text for the static control.

For more information about window controls, see Working with Window Controls.
