KitlSendRawData

This function sends raw data to the host computer but by-passes all the KITL protocol layers to do so.

BOOL KitlSendRawData(
LPBYTE pbData,
WORD wLength
);

Parameters

pbData
Pointer to a BYTE buffer.
wLength
Length of the BYTE buffer pointed to by pbData.

Return Values

If the send is successful, TRUE is returned; otherwise, FALSE is returned.

Remarks

OEMs must call this function if, for any reason, they must send data through the transport without KITL's knowledge. Note that the data sent will not be seen by KITL on the desktop. The purpose of this function is to provide a way to safely send transport-specific handshakes, such as DHCP/ARP, when using an Ethernet transport.
