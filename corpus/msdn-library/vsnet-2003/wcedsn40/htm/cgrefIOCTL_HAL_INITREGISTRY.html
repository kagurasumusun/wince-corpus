IOCTL_HAL_INITREGISTRY

This input/output control is used by Filesys.exe to signal that the registry is active and that data from the OAL can now be propagated to the registry. It is called before any other applications are started, so that the OAL may modify the registry settings used by all applications.

Parameters

dwIoControlCode
Set to IOCTL_HAL_INITREGISTRY.
lpInBuf
[in]Set to NULL.
nInBufSize
Set to 0.
lpOutBuf
Set to NULL
nOutBufSize
Set to 0
lpBytesReturned
Set to NULL.

Return Values

If the function succeeds then TRUE is returned otherwise FALSE is returned.

Remarks

When this IOCTL is called from Filesys.exe the registry is fully enabled and ready to accept data from the OAL.

Use the following APIs to write data into the registry. These are OAL-only functions corresponding exactly to the standard Win32 registry APIs. Registry APIs that are not on this list do not have equivalents that are usable in the OAL:

  • NKRegCreateKeyEx
  • NKRegOpenKeyEx
  • NKRegQueryValueEx
  • NKRegCloseKey
  • NKRegSetValueEx

The registry will be updated before starting any application that is registered in the HKEY_LOCAL_MACHINE\Init registry key.
