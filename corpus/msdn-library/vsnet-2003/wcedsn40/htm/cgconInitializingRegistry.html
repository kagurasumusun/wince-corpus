Initializing the Registry

To initialize the registry, call OEMIoControl with IOCTL_HAL_GETREGSECUREKEYS.

On the first call, OEMIoControl will query the size of the buffer required and then query again for the data. For registry specific considerations, see the Object Store Based Registry and File-Based Registry.
