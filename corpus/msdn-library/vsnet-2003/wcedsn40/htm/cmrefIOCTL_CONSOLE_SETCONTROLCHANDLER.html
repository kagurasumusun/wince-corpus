IOCTL_CONSOLE_SETCONTROLCHANDLER

This input/output control allows a console application to be aborted with CRTL+C. It is passed to DeviceIoControl.

Parameters

hDevice
Set to the handle of the device.
dwIoControlCode
Set to IOCTL_CONSOLE_SETCONTROLCHANDLER.
lpInBuf
Set to NULL.
nInBufSize
Set to 0.

Return Values

If TRUE is returned, the input/output control was successfully processed; otherwise, FALSE is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later   Console.h
