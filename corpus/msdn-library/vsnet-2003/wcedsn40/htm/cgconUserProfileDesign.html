User Profiles

There is a maximum of one user logged in at a time, or it is possible to have no user logged in. To log a user in, call SetCurrentUser with the user name and a data blob. SetCurrentUser will pass the user name and data blob to the security subsystem for encryption and decryption services. To log a user out, log another user in or call SetCurrentUser with a NULL name and data blob.

The type of registry, which is determined by the OEM, in use with user profiles changes the registry swapping behavior in the following ways.

Registry type Behavior
Hive based Each user has its own associated user hive that will be mounted when they are logged in and unmounted when they are logged out. The user hive contains all registry data rooted at HKEY_CURRENT_USER.
Object store (RAM) HKEY_CURRENT_USER is part of the persistent registry and is the same for all users. This means that no registry swapping is done when a user logs in or out and changes by one user may affect other users.
