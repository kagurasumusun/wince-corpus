Kernel States

During normal operation, the kernel will make calls to required functions and optional OEM API. This kernel operational state is known as normal mode.

The following modes are the four other kernel operational states:

  • Suspend Mode
  • OEM Power Off Mode
  • Resume Mode
  • OEM Resume Mode
