BD_ADDR

This structure is used by all Bluetooth stack layers. It is used to identify the address of a Bluetooth device.

#pragma pack(push, 1)
typedef struct   __bd_addr {
union {
   struct {
      unsigned int  LAP : 24; 
      unsigned int  UAP : 8; 
     };
   unsigned int SAP; 
  };
unsigned short  NAP; 
} BD_ADDR;
#pragma pack(pop)

Members

Correspond to the Bluetooth Core Specification for Bluetooth Device Address.

Remarks

Exposed user APIs, such as port emulation and WinSock interfaces, use another type, BT_ADDR, as defined in Ws2bth.h:

typedef ULONGLONG bt_addr, *pbt_addr, BT_ADDR, *PBT_ADDR;
