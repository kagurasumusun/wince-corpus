INTERFACE_TYPE

This enumeration contains values for hardware interfaces.

typedef enum _INTERFACE_TYPE {
InterfaceTypeUndefined = -1,
Internal,
Isa,
Eisa,
MicroChannel,
TurboChannel,
PCIBus,
VMEBus,
NuBus,
PCMCIABus,
CBus,
MPIBus,
MPSABus,
ProcessorInternal,
InternalPowerBus,
PNPISABus,
PNPBus,
MaximumInterfaceType
} INTERFACE_TYPE, *PINTERFACE_TYPE;

Elements

InterfaceTypeUndefined
The interface type is undefined.
Internal
System or microprocessor bus.
Isa
Industry Standard Architecture (ISA) bus.
Eisa
Extended ISA bus.
MicroChannel
Is not used unless the bus is supported.
TurboChannel
Is not used unless the bus is supported.
PCIBus
PCI bus.
VMEBus
Is not used unless the bus is supported.
NuBus
Is not used unless the bus is supported.
PCMCIABus
Is not used unless the bus is supported.
CBus
Is not used unless the bus is supported.
MPIBus
Is not used unless the bus is supported.
MPSABus
Is not used unless the bus is supported.
ProcessorInternal
Is not used unless the bus is supported.
InternalPowerBus
Is not used unless the bus is supported.
PNPISABus
Is not used unless the bus is supported.
PNPBus
Is not used unless the bus is supported.
MaximumInterfaceType
Maximum interface value. There are no interface values greater than this.

Remarks

You can add to your Ceddk.dll implementation whatever support you want. These are bus and interface descriptors that are used in functions such as HalTranslateBusAddress to determine how to translate between the address provided and a system address.
