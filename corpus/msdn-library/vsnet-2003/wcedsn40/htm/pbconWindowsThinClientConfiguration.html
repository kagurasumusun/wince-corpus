Windows Thin Client Configuration

Form-Factor Target

The Windows Thin Client configuration provides functionality for remote desktop terminals through support for Microsoft Terminal Services Client. Formerly known as Windows-based Terminal (WBT), the Windows Thin Client includes a constrained shell, the Microsoft Remote Desktop Protocol (RDP), and the Citrix ICA protocol. OEM build instructions for the Citrix ICA protocol are in the %_WINCEROOT%\Public\Rdp\Oak\Ica directory.

The Windows Thin Client has SNMP and local browser capabilities, along with RDP 5.1 and the possibility of including additional Windows CE OS features.

This configuration defaults to the Thin Client Shell formerly known as the Windows Based Terminal. The Thin Client Shell creates an environment targeted at building terminals for deploying remote applications.

There are two variants of the Windows Thin Client that may be selected during the creation of the platform from the New Platform Wizard. The variants are described in the following table.

Configuration variant Description
Windows Thin Client A minimal version of Microsoft Windows CE that includes the core operating system (OS) and features necessary to support Microsoft Terminal Services Client — including Terminal Services Client's own constrained shell and the RDP.
Windows Thin Client with Browser Similar to the Basic/Standard version, with the addition of Internet Explorer 5.5 and the required support features.

The features and Sysgen variables listed in the preceding table are those required for this configuration, and are referred to as anchored features. Anchored features include both those features and Sysgen variables required by the specified configuration and any other features you choose to add to your platform. When you build a new platform, however, you will notice that additional elements may show up in the feature list. These additional elements, referred to as nonanchored features, are included when the anchored features have dependencies on operating system elements not specifically included with the selected configuration.

While you may be able to select from among the anchored features as you work through the New Platform Wizard, the nonanchored features that are included based on the choices you make cannot be removed from the configuration.
