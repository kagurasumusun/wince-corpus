Microsoft Windows CE .NET  

IOCTL_CELOG_REGISTER

This input/output control registers the required event tacking APIs with the kernel.

Parameters

hModule
Handle to the DLL. Must be set to KMOD_CELOG.
dwIoControlCode
Set to IOCTL_CELOG_REGISTER.
lpInBuf
Pointer to a buffer that contains the CeLogExportTable structure.
nInBufSize
Set to size of CeLogExportTable.
lpOutBuf
Set to NULL.
nOutBufSize
Set to 0.
lpBytesReturned
Set to NULL.

Return Values

If the kernel can initialize the event tracking system TRUE is returned, otherwise FALSE is returned.

Remarks

This IOCTL is only used if an OEM replaces the default event tracking DLL, Celog.dll, with their own DLL.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later
