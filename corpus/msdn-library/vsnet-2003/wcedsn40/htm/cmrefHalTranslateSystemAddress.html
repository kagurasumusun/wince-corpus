HalTranslateSystemAddress

This function translates a system physical address to a bus-relative, logical address, which can be handed off to a bus controller, for example, a DMA bus controller.

BOOLEAN HalTranslateSystemAddress(
IN INTERFACE_TYPE InterfaceType,
IN ULONG BusNumber,
IN PHYSICAL_ADDRESS SystemAddress,
OUT PPHYSICAL_ADDRESS TranslatedAddress
)

Parameters

InterfaceType
[in] The type of bus on which the DMA controller resides.
BusNumber
[in] Bus number.
SystemAddress
[in] System physical address to be translated.
TranslatedAddress
[out] Translated bus-relative logical address.

Return Values

TRUE if successful. FALSE if failure.

Remarks

Translation between any of the bus interface types listed in INTERFACE_TYPE is supported, however the BSPs provided in the box only support PCI bus translations.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Ceddk.h
