OEMSetRealTime

This function sets the real-time clock.

BOOL OEMSetRealTime( 
LPSYSTEMTIME lpst 
);

Parameters

lpst
[in] Long pointer to the buffer containing the current time in SYSTEMTIME format.

Return Values

TRUE indicates success; FALSE indicates failure.

Remarks

This function is called by the kernel to set the real-time clock. This function must be reentrant and, thus, must protect the hardware from multiple accesses.

If your hardware provides two digits to hold the value for the year, you must add additional code to avoid the year 2000 problem. For more details, see RTC.C in the CEPC platform directory.
