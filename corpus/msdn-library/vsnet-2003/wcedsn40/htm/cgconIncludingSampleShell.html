Including the Sample Shell

The Sample shell shows how to write a shell that can display a desktop and a taskbar window. You can use this shell as a starting point for developing your own custom shell. Platform Builder includes source code for the Sample shell in %_WINCEROOT%\Public\Wceshellfe\Oak\Taskman.

To implement this shell, include the Taskman component in your Cesysgen.bat file. Refer to the Cesysgen.bat file in the Web Pad - Enterprise configuration for an example of how to include these components.

The Sample shell provides the following functionality:

  • Creates a full-screen desktop window and a zero-height taskbar window that are registered with the Graphics, Windowing, and Events Subsystem (GWES) so that certain windows can be hidden behind the desktop. Shortcut keys, such as ALT+TAB, CTRL+ESC, and CTRL+ALT+BACKSPACE, are sent to the taskbar window.
  • Provides a Task Manager window that lists all of the running top-level windows and enables a user to switch to or stop an application. The shortcut keys ALT+TAB, CTRL+ESC, and CTRL+ALT+BACKSPACE invoke the Task Manager window.
  • Provides a Run button that enables a user to launch a file.

The Sample shell cannot run in the same configuration as the Handheld PC style shell.
