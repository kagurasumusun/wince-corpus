Gdi::MonitorFromPoint_I

This method retrieves a handle to the screen that contains a specified point. 

static HMONITOR WINAPI MonitorFromPoint_I(
POINT pt,
DWORD dwFlag
);

Parameters

pt
[in] POINT structure that specifies the coordinates of the point of interest in virtual screen coordinates.
dwFlag
[in] DWORD that determines the return value of the method when none of the screens contain the point. The following table shows a list of possible return values.
Value Description
MONITOR_DEFAULTTONEAREST The return value is a handle to the screen that is nearest to the point.
MONITOR_DEFAULTTONULL The return value is NULL.
MONITOR_DEFAULTTOPRIMARY The return value is a handle to the primary screen.

Return Values

If one of the screens contains the point, the return value is an HMONITOR handle to that screen. If none of the screens contains the point, the return value depends on the value of dwFlag.

Remarks

This method is an internal version of the MonitorFromPoint function.
