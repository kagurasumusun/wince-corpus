Establishing Connections through HCI

Using HCI_EstablishDeviceContext during registration, the upper layer establishes a connection to the lower layer by supplying a table of event and command completion callbacks (HCI_EVENT_INDICATION and HCI_CALLBACKS). The upper layer, in return, receives a function table for the lower layer interface in HCI_INTERFACE.
