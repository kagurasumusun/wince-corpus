Call OEMInit

During OEMInit, you must initialize all hardware peripherals needed to support the platform, initiate the debug KITL transport if one is required, and set any kernel variables that are required by the kernel to enable or alter functionality.

For the kernel to operate, you must set up the following areas:

  • KITL that can be initialized at boot or on demand when a debug service on the device starts.
  • Provide LED debug support. While optional, it is helpful when debugging the kernel.
  • Set pWriteDebugLED = OEMWriteDebugLED.
  • Set up the system tick.
  • Decide what timer interrupt source to use for the system tick. It will depend on the CPU and external sources.
  • Initiate the kernel required 1 milliseconds (ms) tick interval.
  • HookInterrupt your timer ISR.
  • Enable RTC.
  • Update the interrupt mask with OEMInit within the BasePSR. This clears the interrupt mask to prevent interrupts from accidentally being delivered during the kernel initialization.
