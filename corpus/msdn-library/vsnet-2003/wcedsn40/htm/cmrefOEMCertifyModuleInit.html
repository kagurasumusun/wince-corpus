OEMCertifyModuleInit

This function enables the OS loader to notify the OEM that a new module is being loaded. This notification allows the OEM to decide whether the module should be verified for safety.

BOOL OEMCertifyModuleInit( 
LPTSTR lpModuleName 
);

Parameters

lpModuleName
Pointer to a buffer allocated by the OS that contains the module name, not including path. If lpModuleName is NULL, no module name is available for the new module being loaded. This name is the name passed into CreateProcess or LoadLibrary. For example, calling LoadLibrary(MYDLL) causes MYDLL to be passed to the OEM. Likewise, calling CreateProcess(\Windows\Myexe.exe) causes \Windows\Myexe.exe to be passed to the OEM.

Return Values

TRUE indicates success; FALSE indicates failure.

Remarks

To implement this function, assign the address of this function to the pOEMLoadInit global pointer in OEMInit of the OAL. In the OAL, the OS exposes pOEMCertifyModuleInit, which the loader calls each time a new module is loaded. This global pointer may also be called before the previous module has been completely supplied, in the event that the loader should fail to load a module completely and fail the actual loading process.

Only modules that are not in ROM are passed to the OEM. All ROM modules are assumed to be trusted by the OEM.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later     Nk*.lib
