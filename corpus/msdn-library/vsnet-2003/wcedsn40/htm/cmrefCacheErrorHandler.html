CacheErrorHandler

This function handles cache errors that occur on a MIPS platform. 

LEAF_ENTRY(CacheErrorHandler);

Parameters

None.

Return Values

None.

Remarks

This function must be implemented for all MIPS platforms.

The kernel initializes the vector table to this function when a cache error occurs on a MIPS processor. By default, the kernel does not set up the CPU to make a call this function on an error. For more information on enabling the cache error, see the MIPS microprocessor documentation.
