Residential Gateway Configuration

Form-Factor Target

The Residential Gateway configuration is targeted to provide functionality for a networked device that is preconfigured to share an Internet connection with one or more in-home networks. There is only one variant of the Residential Gateway configuration, which includes support for dial-up networking, WAN/LAN Ethernet or wireless networking, Network Address Translation (NAT)/Firewall, HTTP/FTP servers for configuration, Universal Plug and Play (UPnP), and Internet Connection Sharing with Media Access Control (MAC) Internet Protocol (IP) bridging.

Configuration Details

The following table lists the required catalog features and Sysgen variables associated with this configuration.

Catalog Sysgen variable Residential Gateway
Debug Shell SYSGEN_SHELL X
Internet Connection Sharing (ICS) SYSGEN_GATEWAY X
Network Utilities (IpConfig, Ping, Route) SYSGEN_NETUTILS X
Device Host API SYSGEN_UPNP_DEVICE X
Compression SYSGEN_NKCOMPR X
Database support SYSGEN_FSDBASE X
Authentication Services (SSPI) SYSGEN_AUTH X
NTLM SYSGEN_AUTH_NTLM X

The features and Sysgen variables listed in the preceding table are those required for this configuration, and are referred to as anchored features. Anchored features include both those features and Sysgen variables required by the specified configuration and any other features you choose to add to your platform. When you build a new platform, however, you will notice that additional elements can show up in the feature list. These additional elements, referred to as nonanchored features, are included when the anchored features have dependencies on operating system elements not specifically included with the selected configuration.

While you may be able to select from among the anchored features as you work through the New Platform Wizard, the nonanchored features that are included based on the choices you make cannot be removed from the configuration.
