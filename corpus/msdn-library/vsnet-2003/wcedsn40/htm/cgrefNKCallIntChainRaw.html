NKCallIntChainRaw

This function is called by the OEM from the OAL when they would like to chain an IRQ event.

DWORD NKHookIntChainRaw(
DWORD dwIRQ
);

Parameters

dwIRQ
Identifies the IRQ value.

Return Values

If no ISR has handled the IRQ event, SYSINTR_CHAIN is returned. Otherwise, a valid SYSINTR value is returned to the OEM. The OEM must then pass this value back to the kernel so the IST can be triggered.

Remarks

The OEM has full control of what IRQ values can be chained and which ones can not. When this function is called there is no work done to enable C in the installed ISR. An OEM should only call this function if they have already performed the work required to enable C code. This typically requires that all registers be saved before calling NKCallIntChainRaw and then restoring them when the API completes.
