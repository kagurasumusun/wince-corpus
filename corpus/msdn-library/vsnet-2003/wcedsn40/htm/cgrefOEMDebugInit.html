OEMDebugInit

This function is the first called by the BLCOMMON framework when a boot loader is started. It initializes the debug transport, usually just initializing the debug serial UART.

BOOL OEMDebugInit (void);

Parameters

None.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Platform code Blcommon.h
