Displaying the Current Security Zone

Security Zones allow users to assign specific levels of security to Web sites, based on their origin. For example, sites on a corporate intranet typically have a greater degree of trust, thus fewer security restrictions, than unknown Internet sites. Whenever a user attempts to open or download content from the Web, the browser checks the security settings for that Web site's zone. A user can tell which zone the current Web page is in by looking at the status pane located to the far right of the Internet Explorer status bar.

By default the current Security Zone is not displayed on the IESample browser. The following list describes the steps necessary to add this functionality to the browser:

  1. Create a project that includes the IESample feature.
  2. From the Platform Builder menu choose File, Open, then navigate to the %_WINCEROOT%\Public\Ie\Oak\Iesample folder and open the sources file as text.
  3. Add the following preprocessor directiveto the sources file:
    CDEFINES=$(CDEFINES) -DZONEDISPLAY
    and save the file.
  4. Build the project, or if do not want to build the entire project at this time, run the build tool, build.exe, with the -c flag, from the %_WINCEROOT%\Public\Ie\Oak\Iesample folder to build only a new iesample.exe.
    Note   You can change the width of the individual panes in the status bar to better accommodate the security zones information by modifying the settings in the CMainWnd::CreateStatusBar function in mainwnd.cpp.
