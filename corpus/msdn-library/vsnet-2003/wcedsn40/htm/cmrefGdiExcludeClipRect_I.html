Gdi::ExcludeClipRect_I

This method creates a new clipping region that consists of the existing clipping region minus the specified rectangle.

static WINGDIAPI int WINAPI ExcludeClipRect_I(
HDC hdc, 
int nLeftRect, 
int nTopRect, 
int nRightRect, 
int nBottomRect
);

Parameters

hdc
[in] Handle to the device context.
nLeftRect
[in] Integer that specifies the logical x-coordinate of the upper-left corner of the rectangle.
nTopRect
[in] Integer that specifies the logical y-coordinate of the upper-left corner of the rectangle.
nRightRect
[in] Integer that specifies the logical x-coordinate of the lower-right corner of the rectangle.
nBottomRect
[in] Integer that specifies the logical y-coordinate of the lower-right corner of the rectangle.

Return Values

The return value specifies the complexity of the new clipping region. NULLREGION indicates that the region is empty. SIMPLEREGION indicates that the region is a single rectangle. COMPLEXREGION indicates that the region is more than one rectangle. ERROR indicates that no region was created.

Remarks

This method is an internal version of the ExcludeClipRect function.

The lower and right edges of the specified rectangle are not excluded from the clipping region.
