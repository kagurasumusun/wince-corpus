TranSetDevCfg

This function is called to set up the host computer transport with the device-side configuration information.

BOOL TranSetDevCfg(
TRANSPORTID id,
LPCVOID pData,
USHORT cbData
);

Parameters

id
Valid TRANSPORTID returned from TranCreate.
pData
Pointer to a data buffer that store the device-side transport configuration information.
cbData
Size of the pData buffer, in bytes.

Return Values

TRUE indicates success and FALSE indicates failure.

Remarks

This function is called during the initial handshake with the device. KITL calls TranSetDevCfg when it receives the device transport information.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Kitltran.h
