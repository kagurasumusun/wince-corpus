OEMIdle

This function is called by the kernel to place the CPU in the idle state when there are no threads ready to run.

void OEMIdle(
DWORD dwIdleParam 
);

Parameters

dwIdleParam
Used by MIPS CPU only. Base value for program status register (PSR) to allow interrupts to be enabled.

Return Values

None.

Remarks

Exceptions are blocked when this routine is called and must not be re-enabled unless the function is going to return immediately.

OEMIdle should place the CPU into a reduced power mode and halt it. It is important to be able to resume execution quickly upon receiving an interrupt.

For performance management data, OEMIdle can track the amount of time it is being run by using the curridlelow and curridlehigh kernel global variables.

This function takes a parameter that is only used by the MIPS CPU and that is undefined for other CPUs. It is a base value for the PSR to allow interrupts to be enabled.
