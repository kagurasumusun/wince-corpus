CertifyModule

This function, which is called from OEMCertifyModule, streams the bytes of a module for certification.

BOOL CertifyModule(
PBYTE pbBlock, 
DWORD cbBlock 
);

Parameters

pbBlock
[in] Pointer to a block of bytes from the module being certified.
cbBlock
[in] Number of bytes in the current block.

Return Values

TRUE indicates success; FALSE indicates that an error occurred while scanning the file.

Remarks

Because this function is called from the OEMCertifyModule function, it takes the same parameters as OEMCertifyModule. This function is part of the Loadauth.lib component.

Requirements

Windows CE OS 2.10 and later N/A   Loadauth.lib
