Selecting a Configuration

Microsoft® Platform Builder provides basic configurations as starting points for the creation of an operating system (OS). The configurations are provided to give you a head start with a specific class of device. They are intended to reduce product development time — in combination with a board support package (BSP) — and to decrease the time it takes to put your product on the market. Once a basic configuration has been chosen, you can modify it to suit your specific needs.

There are 13 basic configurations included with Platform Builder. They are available from the New Platform Wizard. The following table lists the included configurations, and a description for each.

Configuration Description
Cell Phone/Smart Phone Provides the standard OS features required for building mobile handsets with wireless data, rich graphics, and 160x220 nominal display resolution. The Cell Phone/Smart Phone configuration includes the Standard Windows CE Shell and can optionally include Microsoft Pocket Internet Explorer, Inbox electronic messaging software, and Microsoft ActiveSync® 3.0 technologies.
Custom Device Provides the starting point for devices that require a software configuration that can be fully customized. These devices range from simple network devices with no display, to full-featured appliances with graphical displays, Internet browsing capabilities, and rich multimedia playback features.
Digital Imaging Device Provides the starting point for digital imaging devices that range from digital cameras with wireless connectivity to network printers and multi-function peripherals.
Industrial Automation Device Provides the starting point for industrial automation devices, such as human-machine interface (HMI) panels or programmable logic controllers (PLCs).
Internet Appliance Provides the starting point for browser-based consumer Internet appliances, with a fixed display, such as a CRT or LCD, and a keyboard.
Media Appliance Provides the starting point for devices that playback or store music, video, and other electronic media.
PDA or Mobile Handheld Device Provides the starting point for a range of personal digital assistant (PDAs) or mobile devices with a clam-shell-and-keyboard design.
Residential Gateway Provides the starting point for network devices that connect to the Internet with a dial-up or broadband connection, and which share that connection with a wired or wireless home network.
Retail Point-of-Sale Device Provides the starting point for a range of devices, from self-service kiosks and electronic payment terminals, to retail point-of-sale terminals.
Set-Top Box (TV Browser) Provides a baseline for devices that are connected to a television for display of Internet and media content. A typical application might be a video-over-DSL Set-Top Box with a browser-based TV user interface. This configuration includes the Standard Windows CE Shell and has TV navigation features, which are turned on by default in the browser.
Tiny Kernel Provides a starting point for the smallest functional Windows CE operating system image.
Web Pad Provides the basic functionality for consumer Web pads with a touch-screen user interface (UI) and 640x480 or larger display. The Standard Windows CE Shell and applications can be used or custom versions substituted, or it can be an entirely browser-based UI.
Windows Thin Client Provides the starting point for remote-desktop terminals, including those features necessary to support Terminal Services Client, such as a constrained shell and the Remote Desktop Protocol (RDP).
