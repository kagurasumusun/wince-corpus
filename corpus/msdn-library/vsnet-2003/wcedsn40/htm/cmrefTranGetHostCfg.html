TranGetHostCfg

This function is called to retrieve and host computer-specific configuration information.

BOOL TranGetHostCfg(
TRANSPORTID id,
LPVOID pBuffer,
PUSHORT pcbBuffer
);

Parameters

id
Valid TRANSPORTID returned from TranCreate.
pBuffer
Pointer to a buffer to store the transport-specific configuration information.
pcbBuffer
Pointer to a buffer that contains the size of the pBuffer passed in and then the number of bytes copied to pBuffer on exit.

Return Values

None.

Remarks

This function is called during the initial handshake with the device. KITL calls TranGetHostCfg when it needs to send the host transport information to the device..

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Kitltran.h
