WRITE_PORT_UCHAR

This macro writes a byte to the specified port address.

VOID WRITE_PORT_UCHAR(
PUCHAR Port, 
UCHAR Value 
)

Parameters

Port
[in] Pointer to the port, which must be a mapped memory range in I/O space.
Value
[in] Specifies a byte to be written to the port.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ceddk.h Ceddk.h
