File and Database Replication

Data replication is used to synchronize the data stored on a Windows CE device with data stored in another location. The data could be file system objects such as files and directories. OS databases can also be synchronized.

Windows CE .NET provides two different replication mechanisms: Bit-Based Replication and Counter-Based Replication. The Bit-Based Replication mechanism has been present in Windows CE since version 2.1. It is based on maintaining bits of replication information on each object in the file system or database volume. It supports synchronization with up to two external stores. The Counter-Based Replication mechanism is a new feature of Windows CE .NET. It maintains a generation counter for each object in the file system or database volume. The generation counters make it possible to synchronize with any number of external stores. It is designed to reduce the quantity of work a synchronization application would have to do, and to minimize the amount of data it would have to store.

Note   The device-side ActiveSync modules rely on the bit-based replication model.
