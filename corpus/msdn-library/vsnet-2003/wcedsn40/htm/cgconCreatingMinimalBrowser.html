Creating a Minimal Browser

The IESample browser application obtains its features by implementing the IWebBrowser2 interface. Microsoft recommends that you use the IESample code as a starting point for your custom browser. However, if your platform requires a browser application with extremely limited functionality, for example one that only opens, closes, and perhaps prints HTML files that are located on the user's machine or a local network, you can use the Internet Explorer Browser Control Host to create a browser with a very small footprint.

The IWebBrowser2 interface provides methods for creating the browser interface and for displaying and printing html pages. For more information about implementing this interface, see Internet Explorer Browser Control Host.

For instructions on adding the browser application to your platform, see Additions to a Platform.
