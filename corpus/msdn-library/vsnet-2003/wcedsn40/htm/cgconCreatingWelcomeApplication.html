Creating a Welcome Application

You can create a welcome application that runs when the user starts the device for the first time. You can use this application to gather information from the user, such as the name of the user and a name for the device.

To create a welcome application for Windows CE

  1. Add the application to the startup group by creating a link to your application and modifying a project .bib file and .dat file to put the link to your application in the startup folder on the image.

    The following code example shows the code that you need to add to your Project.bib file. 

    welcome.lnk      $(_FLATRELEASEDIR)\welcome.lnk       NK SH

    The following code example shows the code that you need to add to your Project.dat file. 

    Directory("\Windows\Startup"):-File("welcome.lnk","\Windows\startup\welcome.lnk")

    You can also use the launch sequence in the registry to automatically launch your application. For information about using the launch sequence in the registry, see Configuring the Process Boot Phase.

    When your application finishes, your application should delete the link from the startup folder.

  2. Ensure that your application runs to completion before other applications run to ensure that users have completed any steps necessary before using the operating system.

    One method that you can use to ensure that your application runs to completion before other applications run is to make your application window a topmost window on the system. You also need to handle attempts from other applications to obtain the focus. The following code example shows how to make you application window the topmost window. 

    // Put the window on top and show it.
SetWindowPos(hWnd, HWND_TOPMOST, 0, 0, 0, 0, 
SWP_NOMOVE | SWP_NOSIZE | SWP_SHOWWINDOW);
  3. Include a call to the TouchCalibrate function before doing anything that requires user input, if your device uses a touch screen.
  4. Acquire other information that you need from the user, such as a device name and owner information.
