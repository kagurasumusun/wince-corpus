HalAllocateCommonBuffer

This function allocates memory, locks it down, and maps it so that it is simultaneously accessible from both the processor and a device for DMA operations.

PVOID HalAllocateCommonBuffer(
IN PDMA_ADAPTER DmaAdapter,
IN ULONG Length,
OUT PPHYSICAL_ADDRESS LogicalAddress,
IN BOOLEAN CacheEnabled
);

Parameters

DmaAdapter
[in] Pointer to DMA adapter descriptor structure, DMA_ADAPTER_OBJECT.
Length
[in] Size of buffer to allocate.
LogicalAddress
[out] Pointer to the bus-relative, logical address buffer used by the DMA controller on the specified bus.
CacheEnabled
Ignored. The buffer returned is always at an uncached virtual address.

Return Values

Pointer to allocated buffer to be used by the device driver, or NULL if failure.

Remarks

Allocates a shared buffer of locked, physically contiguous pages, and returns the virtual address to be used by the DMA device driver and the logical address to be used by the DMA adapter for DMA operations.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Ceddk.h
