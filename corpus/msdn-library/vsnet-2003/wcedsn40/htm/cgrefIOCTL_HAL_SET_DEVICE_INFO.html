IOCTL_HAL_SET_DEVICE_INFO

This input/output control is called to set the data returned by IOCTL_HAL_GET_DEVICE_INFO.

Parameters

dwIoControlCode
Set to IOCTL_HAL_SET_DEVICE_INFO.
lpInBuf
[in]Points to a buffer that can contains a string and a DWORD that represents the data to be changes. This DWORD is at the front of the string and can be set to on of the following values: SPI_GETPLATFORMTYPE or SPI_GETOEMINFO. The string can be any string and length that is supported by the platform.
nInBufSize
Set to the size of the buffer pointed to by lpInBuf.
lpOutBuf
Set to NULL
nOutBufSize
Set to 0
lpBytesReturned
Set to NULL.

Remarks

This IOCTL should only be enabled in a test platform and not on a retail device. It allows you to take a platform like the CEPC and force it to mimic another device type.

Sample Code

case << IOCTL_HAL_SET_DEVICE_INFO>>  :
   if (nInBufSize >= sizeof(DWORD)) {
     len = *(LPDWORD)lpInBuf;
     switch (len) {
     case SPI_GETPLATFORMTYPE :
       nInBufSize -= sizeof(DWORD);
       if (nInBufSize <= sizeof(HALPlatformStr)){
           memcpy (HALPlatformStr, ((LPBYTE)lpInBuf)+sizeof(DWORD),            nInBufSize);
           retval = TRUE;
       } else {
           SetLastError(ERROR_INVALID_PARAMETER);
       }
       break;
     default :
       SetLastError(ERROR_INVALID_PARAMETER);
       break;
     }
   } else {
     SetLastError(ERROR_INVALID_PARAMETER);
   }
break;
