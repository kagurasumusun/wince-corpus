pNKEnumExtensionDRAM Customization

If there is more than one noncontiguous RAM section, you need to implement the pNKEnumExtensionDRAM function pointer. The pNKEnumExtensionDRAM variable is capable of reporting up to 15 different noncontiguous RAM regions and like OEMGetExtensionDRAM, it is called during the cold boot phase. If pNKEnumExtensionDRAM is set, OEMGetExtensionDRAM is not called during the boot process. Note that when adding multiple sections that there is a performance impact for every memory section that is added to the kernel. The impact is due to the kernel tracking and searching for free physical memory in different memory sections.
