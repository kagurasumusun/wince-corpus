OEMPowerOff

This function is invoked when the OFF button is pressed or the Graphics, Windowing, and Events Subsystem (GWES) times out on its power-off timer. It is responsible for any final power-off state and putting the CPU into suspend mode.

void OEMPowerOff (void);

Parameters

None.

Return Values

None.

Remarks

When this function is called, the target device is entering the suspend state. For more information on the suspend state, see Application Power Management.

Requirements
