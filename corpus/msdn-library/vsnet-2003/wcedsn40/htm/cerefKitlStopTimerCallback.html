KitlStopTimerCallback

This function makes a call to a timer that should be disabled.

BOOL KitlStopTimerCallback(
PFN_KITLTIMERCB pfnCB,
LPVOID lpParam
);

Parameters

pfnCB
Pointer to a callback function to be called when the timer is removed.
lpParam
User-defined value passed back to the callback function.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
