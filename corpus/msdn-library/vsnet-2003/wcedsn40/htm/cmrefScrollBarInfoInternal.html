ScrollBarInfoInternal

This structure contains internal information about a scroll bar.

struct ScrollBarInfoInternal {
SCROLLINFO si;
BOOL bInSetSBInfo;
int nThumbPos;
SCROLL_STATE dwState;
UINT nTrackStart;
UINT fnBar;
UINT idTimer;
};

Members

si
SCROLLINFO structure that specifies additional information about the scroll bar.
bInSetSBInfo
Reserved for internal use.
nThumbPos
Integer that specifies the pixel position of the top of thumb.
dwState
SCROLL_STATE value that specifies the internal state of the scroll bar.
nTrackStart
Unsigned integer that tracks the position of the top of thumb.
fnBar
Unsigned integer that indicates whether the scroll bar is part of the nonclient area or part of a control. The following table shows the possible values.
Value Description
SB_BOTH Both horizontal and vertical scroll bars.
SB_CTL Scroll bar control.
SB_HORZ Horizontal scroll bar.
SB_VERT Vertical scroll bar.
idTimer
Unsigned integer that specifies an identifier for a timer.
