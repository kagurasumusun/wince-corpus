Enabling Antialiased Fonts

You can enable antialiased fonts as the default if your display driver supports antialiased fonts. Windows CE uses antialiased fonts by default if you add the HKEY_LOCAL_MACHINE\System\Gdi\Fontsmoothing registry key. If this key is present, and you do not want your application to get an antialiased font, you must specify NONANTIALIASED_QUALITY in the LOGFONT structure for your application. If this key is not present, and you want your application to get an antialiased font, you must specify ANTIALIASED_QUALITY in the lfQuality parameter of the LOGFONT structure for your application.

Add the HKEY_LOCAL_MACHINE\System\GDI\ForceGRAY16 registry key to allow the TrueType font renderer to use 4-bit antialiasing for font-sizes which do not support 4-bit antialiasing.

Add the HKEY_LOCAL_MACHINE\System\GDI\ExpensiveAntialias registry key to use an alternative antialiasing algorithm in the GPE Emul library. Any display driver using the Emul library can thus take advantage of two possible anti-aliasing algorithms.
