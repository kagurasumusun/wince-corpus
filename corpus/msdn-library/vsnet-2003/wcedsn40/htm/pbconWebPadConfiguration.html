Web Pad Configuration

Form-Factor Target

The Web Pad configuration is targeted to provide functionality for portable devices that are primarily intended for accessing the Internet. The Web Pad configuration focuses on providing the necessary support structure for Internet-based applications, including communications and networking features. The Web Pad configuration provides support for a mouse-based user interface (UI) and a stylus-based touch screen and UI.

This configuration is tuned for Web pads by including wireless networking and defaulting to touch-screen input.

The Web Pad configuration allows a wide range of functionality. There are three variants of the Web Pad configuration that may be selected during the creation of the platform from the New Platform Wizard. The variants are described in the following table.

Configuration variant Description
Web Pad Provides the basic functionality for a consumer Web pad with touch-screen UI and 640 x 480 or larger display. It includes the Standard Windows CE Shell, Microsoft Internet Explorer 5.5, Windows Media player, and the necessary wireless networking, communications, and mobile-device support features.
Web Pad with Applications Provides the basic functionality for a consumer Web pad with touch-screen UI and 640 x 480 or larger display. Identical to the Basic Web Pad version, with the addition of Pocket Word, Inbox client companion to Microsoft Outlook®, Microsoft ActiveSync, and Help for Microsoft Windows CE.
Enterprise Web Pad with Applications Provides the basic functionality for an enterprise Web pad with touch-screen UI and 640 x 480 or larger display. Similar to the standard Web pad version, with the addition of enterprise networking, distributed application development, and Windows thin-client–related technologies for richer integration into the enterprise IT infrastructure.

The features and Sysgen variables listed in the preceding table are those required for this configuration, and are referred to as anchored features. Anchored features include both those features and Sysgen variables required by the specified configuration and any other features you choose to add to your platform. When you build a new platform, however, you will notice that additional elements may show up in the feature list. These additional elements, referred to as nonanchored features, are included when the anchored features have dependencies on operating system elements not specifically included with the selected configuration.

While you may be able to select from among the anchored features as you work through the New Platform Wizard, the nonanchored features that are included based on the choices you make cannot be removed from the configuration.

Note   If you add Internet Protocol version 6 (IPv6), IPv4 is also added to the configuration.
