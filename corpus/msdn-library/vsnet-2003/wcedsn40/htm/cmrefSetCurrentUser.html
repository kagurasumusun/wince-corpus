SetCurrentUser

This function sets the current user as logged in. 

BOOL SetCurrentUser( 
LPCWSTR lpszUserName, 
LPBYTE lpbUserSecret, 
DWORD dwDataSize, 
BOOL bCreateIfNew 
);

Parameters

lpszUserName
NULL-terminated string containing the user's logon name. The name must be a valid filename because a directory is created that contains the user's personal data. User names are case-insensitive.
lpbUserSecret
Buffer of user-specific opaque secret data such as a password.
dwDataSize
Size of the user secret.
bCreateIfNew
Creates a new user, if it does not already exist.

Return Values

Returns TRUE if the new user was logged in. If the given user was already logged in, returns FALSE and leaves that user logged in; in this case GetLastError returns ERROR_USER_EXISTS. If the call fails for any other reason, returns FALSE and logs out the current user.

Remarks

SetCurrentUser is accessible only to trusted applications.

Logs a user in, adjusts the registry as applicable, and provides the user secret to the security subsystem to unlock the user's credentials. Logs out the previous user, if present.

If the new user is the same as the previous user, the call fails and GetLastError returns ERROR_USER_EXISTS, leaving the same user logged in and makes no call to the security subsystem. In any other case, when SetCurrentUser fails, the current user is logged out and no user will be logged in.
