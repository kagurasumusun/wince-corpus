Choosing the Correct Registry Type

Choosing the correct registry type will improve the characteristics and behavior of your device. When selecting a registry for your device, you can select either a RAM-based (object-store-based) registry or a hive-based registry.

The appropriate registry type is dependent on the type of data storage you include in your device. The type of data storage, in turn, is determined by whether your device will typically warm-boot (maintaining the RAM contents) or cold-boot (losing all RAM contents).

Use the following table to determine the appropriate registry type for each type of data storage.


Data storage		 Normal boot Choose registry type
Description
RAM Warm RAM-based Slow initialization on the first (cold) boot; subsequent (warm) boots are fast due to the presence of RAM.
Persistent storage other than RAM Cold Hive-based Fast cold boot because data is loaded efficiently from the file system it is stored on.

Warm boots with the hive-based registry are slower than warm boots on the RAM-based registry because the data must also be loaded.

If your legacy code uses a RAM-based registry that saves and restores on persistent storage, consider changing to the hive-based registry to speed the save and restore process.
