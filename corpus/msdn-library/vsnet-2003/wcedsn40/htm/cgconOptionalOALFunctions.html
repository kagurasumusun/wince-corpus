Optional OAL Functions

The following functions log process and thread interaction:

  • pLogThreadCreate
  • pLogThreadDelete
  • pLogProcessCreate
  • pLogProcessDelete
  • pLogThreadSwitch

The following functions save and restore the object store based registry:

  • pReadRegistryFromOEM
  • pWriteRegistryToOEM

The following functions report a module trust level to the kernel:

  • pOEMLoadInit
  • pOEMLoadModule

The following functions save the context of co-processor registers on a thread context switch:

  • OEMSaveCoProcRegister
  • OEMRestoreCoProcRegister
  • OEMInitCoProcRegisterSavedArea

The following function is called when the system is about to halt the system due to an unrecoverable error.

  • lpNKHaltSystem

The following function is called by Filesys.exe when the object store will be cleaned and re-initialized.

  • pNotifyForceCleanboot

The following functions are required to enable event tracking:

  • CeLogData
  • CeLogInterrupt
  • CeLogSetZones

The following functions are included to support the ARM FPU kernel:

  • OEMSaveVFPCtrlRegs
  • OEMRestoreVFPCtrlRegs
  • OEMHandleVFPException
