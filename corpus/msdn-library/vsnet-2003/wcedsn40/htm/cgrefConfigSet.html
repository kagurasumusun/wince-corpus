ConfigSet

This function sets the base address of a resource. The base address is defined by the Base field of the pRsrc structure and the offset to the register that controls the resource address decoder is defined by the Offset member. This function is called when the PCI bus is assigning base addresses to all resources on the PCI bus.

static BOOL ConfigSet(
PPCI_RSRC pRsrc
);

Parameters

pRsrc
[in] A pointer to a PCI_RSRC structure.

Return Values

Returns TRUE if success, FALSE if failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Gdcfg.c
