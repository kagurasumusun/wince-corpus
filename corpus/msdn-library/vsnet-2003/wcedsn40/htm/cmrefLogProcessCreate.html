LogProcessCreate

This function logs the creation of a process.

void LogProcessCreate( 
DWORD dwProcID 
);

Parameters

dwProcID
[in] Identifier of the process.

Return Values

None.

Remarks

You may implement this function and assign its address to the pLogProcessCreate kernel global variable. The identifier passed in dwProcID is a unique identifier that is only used to distinguish one process from another and cannot be used to query for additional information from the operating system.

Implementation of this function is optional.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later     Nk*.lib
