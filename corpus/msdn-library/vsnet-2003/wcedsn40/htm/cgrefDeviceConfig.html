DeviceConfig

This function is the main entry point called by the PCI bus driver to configure a device in a non-standard way. 

DWORD DeviceConfig(
DWORD Command, 
PPCI_DEV_INFO pInfo,
PPCI_RSRC pRsrc1,
PPCI_RSRC pRsrc2,
DWORD *pMemSize,
DWORD *pIoSize
);

Parameters

Command
[in] The following table shows the possible values for Command; set to one of these.
Flag Description
PCIBUS_CONFIG_RSRC Calls ConfigRsrc to gather device resources and update the total memory and I/O size requirements.
PCIBUS_CONFIG_SET Calls ConfigSet to set base addresses for device resources.
PCIBUS_CONFIG_SIZE Calls ConfigSize to query device resource sizes.
PCIBUS_CONFIG_INIT Calls ConfigInit to perform any device initialization procedures if necessary.
pInfo
[in] A pointer to a PCI_DEV_INFO structure.
pRsrc1
[in] A pointer to a PCI_RSRC structure.
pRsrc2
[in] A pointer to a PCI_RSRC structure.
pMemSize
[in] A pointer to a memory resource size accumulator.
pIoSize
[in] A pointer to an I/O resource size accumulator.

Return Values

The following table shows the possible return values.

Return value Description
ERROR_SUCCESS If the call to the function specified by the flag in the Command parameter succeeds.
ERROR_GEN_FAILURE If the call to the function specified by the flag in the Command parameter fails.
ERROR_BAD_COMMAND If the flag specified by the Command parameter is not recognized.

Remarks

The actual name of this function needs to be specified by the ConfigEntry value under the device's registry key. The following registry key example shows this:

[HKEY_LOCAL_MACHINE\Drivers\Builtin\PCI\Template\Permedia3]
    "ConfigDll"="perm3_cfg.dll"
    "ConfigEntry"="DeviceConfig"

ConfigDll is required only if DeviceConfig is implemented in a separate DLL from the device driver. If ConfigDll is not specified, the DeviceConfig function is assumed to be implemented in the device driver DLL.

DeviceConfig is called by the PCI bus driver during four different stages. It is first called with the parameter Command equal to PCIBUS_CONFIG_RSRC during the resource information gathering stage. DeviceConfig is expected to return the size of the resources it requires. DeviceConfig is called next with Command equal to PCIBUS_CONFIG_SET to set the base address registers (BARs) with addresses generated the PCI bus driver. The third call to DeviceConfig is used when the PCI bus driver is enumerating the bus and requesting size information of the resources it requires. Finally, the PCI bus driver calls DeviceConfig with Command equal to PCIBUS_CONFIG_INIT to allow DeviceConfig to perform any initialization steps required by the device if necessary.

Gdcfg.c gives an example of how to implement DeviceConfig in such a way that mimics the normal operation of the PCI bus driver. It is a good starting point for modification in order to construct your own DeviceConfig routine.
