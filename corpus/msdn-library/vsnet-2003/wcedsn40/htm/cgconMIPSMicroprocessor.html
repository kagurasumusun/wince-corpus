MIPS Microprocessor

MIPS ISRs are limited to using a subset of the available microprocessor registers. Specifically, a MIPS ISR can only use registers AT, V0, A0, A1, A2, and A3. Use the following design principals when creating an OAL for a MIPS microprocessor:

  • The ISR must return by means of j ra.
  • Implement a system-timer ISR that sets the variables CurMSec and DiffMSec.
  • OEMInit needs to register the system-timer ISR to handle the system timer and update CurMSec and DiffMSec.
  • Create the OAL function GetTickCount to return a value from the interval timer.
  • The OEMIdle function takes a single parameter that is only used by the MIPS CPU.

    This parameter is undefined for other CPUs. It is the base program status register (PSR) value and sets interrupts to be enabled. The following code sample shows how OEMIdle is defined for the MIPS microprocessor.

  • Nested interrupts

    The SHx kernel utilizes a structure that provides the kernel with information about which nested interrupts are masked while the current interrupt is being handled. To gain access to this structure, the IntrPrio global variable must be declared in the OAL.
