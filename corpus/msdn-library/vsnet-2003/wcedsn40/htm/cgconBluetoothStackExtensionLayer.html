Enhancing the Bluetooth Stack

Bluetooth is an emerging technology that is constantly being improved. New Bluetooth–based devices with increased functionality become available all the time. To keep pace with these changes, Microsoft® Windows® CE .NET provides you with a flexible stack implementation, so that you can easily add new supports to enhance the base stack functionality of Windows CE. For example, Windows CE provides you with the ability to write a stack extension layer, to which you can easily add your own SCO (synchronous connection-oriented) support, even though this support is currently unavailable.

The following topics discuss the Bluetooth stack extension layer in more detail:

  • Bluetooth Protocol Architecture
  • Writing an Extension Layer
  • Interface References
  • Establishing Connections through HCI
  • Stack Extension Layer Design Considerations
  • Bluetooth Stack Extension Layer Sample

A reference is also provided to help you take extend the Bluetooth stack. For more information about the stack extension layer functions, I/O control codes (IOCTLs), and structures, see the topics in the Bluetooth Stack Extension Layer Reference node.
