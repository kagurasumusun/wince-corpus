SetCleanRebootFlag

This function resets the object store when a device is reset.

void SetCleanRebootFlag (void);

Parameters

None.

Return Values

None.

Remarks

When you call this function during a device reset, Windows CE ignores the contents of the object store and replaces the current data with the default data found in the .bin file. This information is the same as when a device is forced into a cold reset.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later   Pkfuncs.h
