Choosing Graphics Hardware

You should use a PC-style display orientation for your device. For example, originate in the top left and use horizontal scan lines and linear framebuffer memory. For more information, see Creating a Custom Shell.

For display drivers, you should use a 32-bit bus to framebuffer memory. For more information, see Display Drivers.
