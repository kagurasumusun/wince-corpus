x86 ROM Boot Loader Building

Running build from the %_WINCEROOT%\Platform\Geode\Romboot directory or running the provided batch file, B.bat, will build the boot loader. The batch file is useful for rebuilding nearly all of the code on which the boot loader is dependent. The build creates the component libraries such as NIC drivers, eboot, and romboot libraries, links the executable, and then runs Romimage. The result of the build is a Romboot.rom image that can be flashed onto the platform's system flash/ROM chip.
