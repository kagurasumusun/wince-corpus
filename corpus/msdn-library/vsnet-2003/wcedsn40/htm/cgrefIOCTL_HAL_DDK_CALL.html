IOCTL_HAL_DDK_CALL

This IOCTL is called by the Ceddk.dll to implement the HalGetBusDataByOffset and HalSetBusDataByOffset functions. This IOCTL calls the OEM functions OEMGetBusDataByOffset and OEMSetBusDataByOffset to read and write configuration cycle data to the PCI and ISA busses.

Parameters

dwIoControlCode
[in] Set to this IOCTL, IOCTL_HAL_DDK_CALL.
lpInBuffer
[in] Points to a BUSDATA_PARMS structure. The first DWORD of this structure is set to IOCTL_HAL_GETBUSDATA or IOCTL_HAL_SETBUSDATA to indicate a read or write operation, respectively.
nInBufferSize
[in] The size of lpInBuffer, in this case the size of the BUSDATA_PARMS structure.
lpOutBuffer
[in] Set to NULL.
nOutBufferSize
[in] Set to NULL.
lpBytesReturned
[in] Set to NULL.
lpOverlapped
[in] Set to NULL.

Return Values

TRUE if successful, FALSE otherwise.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Platform OAL Pkfuncs.h
