Creating a Full-screen Browser

The %_WINCEROOT%\Public\Ie\Oak\Iesimple folder contains the source files for a browser container that provides both the window user interface (UI) of IESample and full-screen browser without menu, address, and status bars. The user can toggle between the two UI modes. In all other respects, the IESimple browser has the same functionality as IESample.

An executable IESimple application is provided as a module in Platform Builder 4.1, in the %_WINCEROOT%\Public\Ie\Oak\Lib\platform folders. To add the IESimple module, iesimple.lib, to your project, use the sysgen variable __SYSGEN_IESIMPLE.

For more information about adding a new module to your platform, see Platform Customization.

The registry settings for IESimple are the same as those for IESample. For more information, see IESample Registry Settings.
