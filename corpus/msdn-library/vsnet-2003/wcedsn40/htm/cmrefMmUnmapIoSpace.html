MmUnmapIoSpace

This function unmaps a specified address range previously mapped by MmMapIoSpace.

VOID MmUnmapIoSpace( 
PVOID BaseAddress, 
ULONG NumberOfBytes 
);

Parameters

BaseAddress
[in] Pointer to the base virtual address to which the physical pages were mapped.
NumberOfBytes
[in] Specifies the number of bytes that were mapped.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later   Ceddk.h
