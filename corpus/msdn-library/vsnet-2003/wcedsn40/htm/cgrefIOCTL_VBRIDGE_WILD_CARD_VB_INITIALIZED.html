IOCTL_VBRIDGE_WILD_CARD_VB_INITIALIZED

This input/output control is used by VMINI to find out if VBridge has been initialized by the kernel and OAL code.

Parameters

dwIoControlCode
IOCTL_VBRIDGE_WILD_CARD.
lpInBuf
IOCTL_VBRIDGE_WILD_CARD_VB_INITIALIZED.
nInBufSize
Not used.
lpOutBuf
Points to 4 bytes of memory to receive TRUE or FALSE.
nOutBufSize
Not used.
lpBytesReturned
Size of DWORD for successful call.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Pkfuncs.h
