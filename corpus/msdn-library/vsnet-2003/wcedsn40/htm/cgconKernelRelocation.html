Kernel Relocation

During this stage, kernel data is relocated and global data from the image is copied to the kernel data area.

If using a debug build, the kernel must be part of the image, otherwise the following message is sent and the boot is halted.

"ERROR: Kernel must be part of ROM image!"

MainMemoryEndAddress, a kernel variable that is set to the value of the ulRAMEnd member of the table of contents header that is part of the OS image, is initialized to the end of RAM. The value of ulRAMEnd is based on the RAM section of the Config.bib file and what effect other flags have on ROMIMAGE. For example, the AUTOSIZE flag can use more or less memory then specified by the RAMIMAGE section and therefore affect the RAM size. You can access MainMemoryEndAddress during the OEMInit stage where you can increase or decrease the RAM size.
