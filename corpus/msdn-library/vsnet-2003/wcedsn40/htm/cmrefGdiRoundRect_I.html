Gdi::RoundRect_I

This method draws a rectangle with rounded corners. The current pen outlines the rectangle and the current brush fills the rectangle.

static WINGDIAPI BOOL WINAPI RoundRect_I(
HDC hdc, 
int nLeftRect, 
int nTopRect, 
int nRightRect, 
int nBottomRect, 
int nWidth, 
int nHeight
);

Parameters

hdc
[in] Handle to the device context.
nLeftRect
[in] Integer that specifies the x-coordinate of the upper-left corner of the rectangle.
nTopRect
[in] Integer that specifies the y-coordinate of the upper-left corner of the rectangle.
nRightRect
[in] Integer that specifies the x-coordinate of the lower-right corner of the rectangle.
nBottomRect
[in] Integer that specifies the y-coordinate of the lower-right corner of the rectangle.
nWidth
[in] Integer that specifies the width of the ellipse used to draw the rounded corners.
nHeight
[in] Integer that specifies the height of the ellipse used to draw the rounded corners.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

This method is an internal version of the RoundRect function.

This method neither uses nor updates the current position.
