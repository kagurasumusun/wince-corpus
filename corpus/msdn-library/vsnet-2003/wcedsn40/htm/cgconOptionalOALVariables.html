Optional OAL Variables

The following variables are used by the GetIdleTime function to determine the amount of time that the system is idle:

  • idleconv
  • curridlelow
  • curridlehigh

The following variable is used by the kernel to determine what threads will and will not have unused stack space removed in low memory conditions.

  • dwNKMaxPrioNoScav

The following variable is used to change the default resolution on the real-time clock alarm interrupt.

  • dwNKAlarmResolutionMSec

The following variables are used to set the size of the buffer area and to enable/disable the save/restore functionality respectively:

  • cbNKCoProcRegSize
  • fNKSaveCoProcReg

The following variable enables support for more then one XIP region.

  • OEMRomChain

The following variable sets the default thread quantum for each new thread.

  • dwDefaultThreadQuantum

The following variable determines how much memory is zeroed on boot and how much can be lazily zeroed.

  • dwOEMCleanPages

Overriding some of the values in GetSystemInfo allow the BSP to convince some applications into thinking they are on a particular CPU type.

This can be used in situations like when Wceload.exe only knows about processor types stored in Winnt.h and any new value returned from the BSP would confuse Wceload and cause applications not to be installed.

Note   This functionality is only available for ARM and x86 processors.
  • CEProcessorType
