OEMInterruptDone

This function signals completion of interrupt processing.

void OEMInterruptDone( 
DWORD idInt 
);

Parameters

idInt
[in] Interrupt identifier.

Return Values

None.

Remarks

The kernel calls this function when a device driver calls InterruptDone. The system cannot be pre-empted when this function is called.

OEMInterruptDone should re-enable the interrupt if the interrupt was previously masked.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later   Nkintr.h Nk*.lib
