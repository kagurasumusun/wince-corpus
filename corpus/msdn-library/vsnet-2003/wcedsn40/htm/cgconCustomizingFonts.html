Customizing Fonts

You can change the appearance of your OS by customizing fonts. Windows CE allows you to replace fonts, specify a directory from which the OS should load fonts, enable ClearType, enable antialiased fonts, enable linked fonts, change the font size for the Help system, enable end-user-defined-characters (EUDC), and enable line breaking for non-Roman fonts, such as many Asian-language characters.
