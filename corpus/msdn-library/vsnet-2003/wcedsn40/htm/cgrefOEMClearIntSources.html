OEMClearIntSources

This function is called by IOCTL_HAL_PRESUSPEND; this function initializes things so that whether or not a wake event has occurred since calling this function can be determined. The Power Manager will call this function before a suspend, and OEMPowerOff will then check if any wake events have occurred before finally suspending. It usually clears fInterruptWakeup.

void OEMClearIntSources(void);

None.

None.
