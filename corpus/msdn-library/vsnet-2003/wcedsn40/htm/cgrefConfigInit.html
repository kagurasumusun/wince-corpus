ConfigInit

This function is called by DeviceConfig in response to the PCIBUS_CONFIG_INIT command. It is called at the end of the PCI bus configuration and enumeration cycle so that any device-specific initialization steps may be performed.

static BOOL ConfigInit(
PPCI_DEV_INFO pInfo 
);

Parameters

pInfo
[in] A pointer to a PCI_DEV_INFO structure.

Return Values

Returns TRUE if success, FALSE if failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Gdcfg.c
