Creating an Internet Browser Container Application

When you add the IESample Internet Client feature to your custom platform, or select a configuration, such as Web Pad, that includes IESample, your operating system will include a fully functional Internet browser application based on Microsoft® Internet Explorer 5.5 for Windows CE. You can use the IESample browser application as is, or you can modify the source code to add or remove features. Alternatively, you can use the IESimple sample application to create a browser application that also provides a windowless or full-screen mode. Finally, if your platform requires only the most minimal functionality, you can create your own browser application from the interfaces provided by the Browser Control Host feature.
