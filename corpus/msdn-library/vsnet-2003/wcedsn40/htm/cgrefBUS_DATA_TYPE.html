BUS_DATA_TYPE

This enumeration contains values for bus configuration accesses.

typedef enum _BUS_DATA_TYPE {
ConfigurationSpaceUndefined = -1,
Cmos,
EisaConfiguration,
Pos,
CbusConfiguration,
PCIConfiguration,
VMEConfiguration,
NuBusConfiguration,
PCMCIAConfiguration,
MPIConfiguration,
MPSAConfiguration,
PNPISAConfiguration,
MaximumBusDataType
} BUS_DATA_TYPE, *PBUS_DATA_TYPE;

Elements

ConfigurationSpaceUndefined
The bus configuration is undefined.
Cmos
Is not used unless the bus is supported.
EisaConfiguration
Extended ISA bus configuration.
Pos

CbusConfiguration
Is not used unless the bus is supported.
PCIConfiguration
PCI bus configuration.
VMEConfiguration
Is not used unless the bus is supported.
NuBusConfiguration
Is not used unless the bus is supported.
PCMCIAConfiguration
Is not used unless the bus is supported.
MPIConfiguration
Is not used unless the bus is supported.
MPSAConfiguration
Is not used unless the bus is supported.
PNPISAConfiguration
Is not used unless the bus is supported.
MaximumBusDataType
The maximum value for a bus configuration.
