ConfigSize

This function is similar to ConfigRsrc because it queries the device for resource information. In this case, it fills out fields in the pInfo structure member. If the resource is memory-mapped, the MemLen and MemBase fields of pInfo are updated to reflect the base address and size of the memory resource. If the resource is I/O-mapped, the IoLen and IoBase fields of pInfo are updated to reflect the base address and size of the I/O resource.

static BOOL ConfigSize(
PPCI_DEV_INFO pInfo 
);

Parameters

pInfo
[in] A pointer to a PCI_DEV_INFO structure.

Return Values

Returns TRUE if success, FALSE if failure.

Requirements
