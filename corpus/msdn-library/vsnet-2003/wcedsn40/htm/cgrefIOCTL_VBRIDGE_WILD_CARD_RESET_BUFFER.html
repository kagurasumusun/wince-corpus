IOCTL_VBRIDGE_WILD_CARD_RESET_BUFFER

This input/output control is used by VMINI to request VBridge to reset its Tx/Rx buffers.

Parameters

dwIoControlCode
IOCTL_VBRIDGE_WILD_CARD.
lpInBuf
IOCTL_VBRIDGE_WILD_CARD_RESET_BUFFER.
nInBufSize
Not used.
lpOutBuf
Not used.
nOutBufSize
Not used.
lpBytesReturned
Not used.

Return Values

None.

Remarks

This IOCTL is passed in lpInBuf of IOCTL_VBRIDGE_WILD_CARD.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Pkfuncs.h
