bProfileTimerRunning

This variable indicates if the Monte Carlo profiling timer is running or not.

extern BOOL bProfileTimerRunning;

Remarks

If set to TRUE, the Monte Carlo profiling timer is running, and if not running is set to FALSE.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later
