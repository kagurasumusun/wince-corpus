ListBoxView_t

This class provides methods for drawing the UI associated with a list box.

Method Description
ListBoxView_t::DrawFocus Draws or removes a focus rectangle around a list box item.
ListBoxView_t::ItemHeight Retrieves the height of an item in a list box.
ListBoxView_t::TopCoordinate Determines the y-coordinate at which the text for a list box item should be drawn.
