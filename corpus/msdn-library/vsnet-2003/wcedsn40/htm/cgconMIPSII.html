Initializing the MIPS Kernel

All MIPS BSPs are required to initialize OEMTLBSize to the number of translation look-aside buffer (TLB) entries supported by the CPU before calling KernelStart.

The kernel calls FlushICache to flush the instruction cache and get to a known state. FlushICache or FlushDCache must be implemented by the OEM in the OAL. The kernel flushes the data cache by calling FlushDCache to get to a known state.

To initialize the MIPS kernel, do the following steps:

  • Implement FlushDCache in the OAL.
  • Relocate kernel data.
  • Perform serial debug operations.
  • Call OEMInit.
  • Perform memory initializations.
  • Perform other initializations.

At this point, the scheduler is able to run and schedule threads.
