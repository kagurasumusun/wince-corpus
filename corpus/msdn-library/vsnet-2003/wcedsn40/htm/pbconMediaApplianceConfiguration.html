Media Appliance Configuration

Form-Factor Target

The Media Appliance configuration is targeted to provide functionality for a wide range of devices for which media delivery is the key feature. Media appliances include electronic book readers, electronic picture frames, audio devices, and media storage devices.

The Media Appliance configuration allows a wide range of functionality. There are five variants of the Media Appliance configuration that can be selected during the creation of the platform from the New Platform Wizard. The variants are described in the following table.

Configuration variant Description
Digital Audio Receiver/Jukebox Networked device that stores, decodes, and plays Windows Media Audio and MP3 music files.
Digital Media Receiver Networked device without local storage that decodes and plays music and video files over a network.
Portable Audio Player with Wireless Networking Portable device that stores, decodes and plays music files.
Portable DVD Player Portable device that plays back and navigates DVDs.
Electronic Picture Frame Digital display device that retrieves and displays pictures from the Internet or a home network.

The features and Sysgen variables listed in the preceding table are those required for this configuration, and are referred to as anchored features. Anchored features include both those features and Sysgen variables required by the specified configuration and any other features you choose to add to your platform. When you build a new platform, however, you will notice that additional elements can show up in the feature list. These additional elements, referred to as nonanchored features, are included when the anchored features have dependencies on operating system elements not specifically included with the selected configuration.

While you may be able to select from among the anchored features as you work through the New Platform Wizard, the nonanchored features that are included based on the choices you make cannot be removed from the configuration.
