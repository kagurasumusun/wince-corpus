Gdi::DrawFocusRect_I

This method draws a rectangle in the style used to indicate that the rectangle has the focus.

static WINUSERAPI BOOL WINAPI DrawFocusRect_I(
HDC hDC, 
const RECT *lprc
);

Parameters

hDC
[in] Handle to the device context.
lprc
[in] Long pointer to a RECT structure that specifies the logical coordinates of the rectangle.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

This method is an internal version of the DrawFocusRect function.

Because Gdi::DrawFocusRect_I is a method that performs an XOR operation, calling the method a second time with the same rectangle removes the rectangle from the screen.

This method draws a rectangle that you cannot scroll. To scroll an area that contains a rectangle drawn by this method, call Gdi::DrawFocusRect_I to remove the rectangle from the screen, scroll the area, and then call Gdi::DrawFocusRect_I again to draw the rectangle in the new position.
