Designing Operating System Elements

Microsoft® Windows® CE .NET offers standard configurations and implementations for many operating system (OS) elements. These elements have been designed to accommodate a wide variety of use scenarios but in some cases your platform's specific design requirements may require additional capabilities. This topic explains how you modify, extend, or completely replace various elements of Windows CE.

Design Time Elements

Some OS elements exist only to facilitate the development process. They handle such tasks as loading OS images onto your development device. The following topics provide information about modifying or creating design time OS elements:

  • Creating a Boot Loader
  • Creating a BSP

Low-Level Elements

Low-level elements provide basic services to support many, if not all, of the applications that will run on your platform. These elements handle such tasks as memory management and event notification. The following topics provide information about modifying, extending, or designing low-level OS elements:

  • Creating an OEM Adaptation Layer
  • Customizing Memory
  • Implementing Notifications
  • Customizing the File System
  • Enhancing the Bluetooth Stack
  • Creating a Secure Device
  • Optimizing Your Platform
  • Creating a Signature

User Elements

User elements are visible to your platform's users or affect the overall configuration of your platform. These elements shape how the user will interact with your platform and the applications running on it. The following topics provide information about modifying, extending, or designing user OS elements.

  • Customizing the User Interface
  • Creating a Custom Shell
  • Selecting a Configuration
  • Choosing an Internet Browser
  • Creating an Internet Browser Container Application
