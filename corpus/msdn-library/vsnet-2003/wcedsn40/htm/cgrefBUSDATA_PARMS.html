BUSDATA_PARMS

This structure is used by HalSetBusDataByOffset and HalGetBusDataByOffset when calling the OAL.

typedef struct  BUSDATA_PARMS{
IN  DWORD Function;  
OUT ULONG ReturnCode;  
IN  BUS_DATA_TYPE BusDataType;
IN  ULONG BusNumber;
IN  ULONG SlotNumber;
IN  PVOID Buffer;
IN  ULONG Offset;
IN  ULONG Length;
} BUSDATA_PARMS, *PBUSDATA_PARMS;

Members

Function
[in] Set to IOCTL_HAL_GETBUS_DATA or IOCTL_HAL_GETBUS_DATA.
ReturnCode
[out] The return code from the Function.
BusDataType
[in] The BUS_DATA_TYPE.
BusNumber
[in]The bus number.
SlotNumber
[in] The slot or device number.
Buffer
[in] Pointer to a buffer.
Offset
[in] The offset into the buffer.
Length
[in] The length of the buffer.
