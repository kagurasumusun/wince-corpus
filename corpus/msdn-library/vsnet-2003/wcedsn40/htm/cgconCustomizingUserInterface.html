Customizing the User Interface

You can customize the user interface (UI) by doing any of the following:

  • Creating a skin to customize common controls, window controls, and the nonclient area of windows.
  • Customizing UI components, such as Out of Memory UI, Startup UI, and Touch Screen Calibration UI.
  • Customizing dialog boxes and message boxes, including the size and location of message boxes and the implementation of dialog boxes and message boxes for headless systems.
  • Customizing system colors, such as the colors used for buttons, title bars, and text.
  • Customizing fonts by replacing fonts, enabling antialiased fonts, specifying the directory from which the operating system (OS) loads fonts, enabling Microsoft® ClearType® display technology, enabling linked fonts, changing the font size for the Help system, enabling end-user-defined characters (EUDC), and enabling line breaking for many non-Roman fonts.
