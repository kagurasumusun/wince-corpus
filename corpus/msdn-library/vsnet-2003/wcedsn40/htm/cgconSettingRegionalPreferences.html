Setting Regional Preferences

Platform Builder offers the Regional Settings application in the Control Panel, which allows users to set the preferences for the appearance of numbers, currencies, dates, and times. The following table shows the modules that you can include in your Cesysgen.bat file to include the Regional Settings application with Control Panel.

Module Description
intll Includes a Regional Settings Control Panel application with landscape orientation in your platform.
intlp Includes a Regional Settings Control Panel application with portrait orientation in your platform.
Note   The landscape versions of Control Panel applications are fully supported and tested by Microsoft. The portrait versions of these applications are provided as a convenience to platform developers and are not fully supported or tested by Microsoft. If you are using the Web Pad - Enterprise configuration, the CPLMAIN_LP flag enables you to switch between portrait and landscape orientations.
