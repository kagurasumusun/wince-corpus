GetAvailDriverMemory

This callback function is not used on Microsoft® Windows® CE .NET.

The GetAvailDriverMemory callback function determines how much free memory is in the driver's private heaps (that is, heaps that the driver did not expose to DirectDraw). 

DWORD __stdcall GetAvailDriverMemory(
LPDDHAL_GETAVAILDRIVERMEMORYDATA   pgadmd 
);

Parameters

pgadmd
[in/out] Pointer to a DDHAL_GETAVAILDRIVERMEMORYDATA structure that contains the driver memory information.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
