HcdPdd_Open

This function is the HC driver open routine.

DWORD HcdPdd_Open(
DWORD dwDeviceContext,
DWORD dwAccessCode,
DWORD dwShareMode 
);

Parameters

dwDeviceContext
[in] Specifies a pointer to the device context returned from the HcdPdd_Init function.
dwAccessCode
Not used.
dwShareMode
Not used.

Return Values

Drivers return 1.

Remarks

This function is the standard stream interface driver open routine. It currently is not used.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Ohcdddsi.h or Uhcdddsi.h
