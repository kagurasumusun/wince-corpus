Structures Associated with Direct3D Callback Functions

The following table shows the structures associated with the Direct3D Driver Functions.

Structure Description
D3DHAL_CONTEXTCREATEDATA Contains all of the information that D3dContextCreate needs to create a new context.
D3DHAL_CONTEXTDESTROYDATA Contains the information that D3dContextDestroy needs to delete a context.
D3DHAL_DRAWPRIMITIVES2DATA Contains the information required by D3dDrawPrimitives2 to render primitives.
D3DHAL_VALIDATETEXTURESTAGESTATEDATA Contains the information required for the driver to determine and return its ability to support multitexturing using the current state.
