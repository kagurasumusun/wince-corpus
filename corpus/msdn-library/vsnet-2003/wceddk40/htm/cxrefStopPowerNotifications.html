StopPowerNotifications

This function allows applications and drivers to stop receiving power notification events.

BOOL StopPowerNotifications(
HANDLE h
);

Parameters

h
[in] The handle returned from RequestPowerNotifications.

Return Values

ERROR_SUCCESS
The notification has been successfully deleted.
ERROR_INVALID_PARAMETER
Bad handle value.
ERROR_FILE_NOT_FOUND
Handle value does not exist.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Pm.h
