Victoria PCI Graphics Development Board

If you use the ATI sample display driver, you will need to obtain the Victoria PCI Graphics Development Board for Windows CE, a product that facilitates developing PCI-based graphics subsystems for Windows CE-based platforms. The board supports features such as:

  • A 33 MHz PCI interface
  • The ATI Rage XL graphics controller with 2-D, 3-D, video/alpha blending, and digital video output features
  • ATI Rage Theater features such as NTSC and PAL encoders/decoders, comb filters, and macrovision detection and encryption
  • A stereo audio decoder
  • CCIR 656, S-video, composite, and RF video inputs
  • S-video, composite, and VGA video outputs
  • Software support for Windows CE .NET and Microsoft TV

Obtain this product directly from ATI, and consult ATI's documentation, website, and support services for any sales or hardware related questions about the product. Microsoft makes no warranties of any kind for the suitability of this product for any purpose.
