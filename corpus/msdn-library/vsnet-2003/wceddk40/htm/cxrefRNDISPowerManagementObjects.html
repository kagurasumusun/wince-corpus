RNDIS Power Management Objects

For NDIS to consider a device power management aware, it must respond to the three power-management objects listed in the following table. If the device returns a failure status code in response to a query for OID_PNP_CAPABILITIES, then the host will consider the device as not being power manageable. NDIS decides whether to query this object based on the underlying bus technology that the Remote NDIS device is connected to. Some buses are power-manageable, like USB, so it is expected that these types of Remote NDIS devices will support the minimal objects to be considered power manageable.

Support OID Description
Optional OID_PNP_CAPABILITIES The NIC's Power Management abilities
Optional OID_PNP_QUERY_POWER A query to determine whether the device can transition to a specific power state
Optional OID_PNP_SET_POWER A command to set the device to specified power state
