Display Driver Preparation

The steps you can take to create a non-GPE display driver that is prepared for DirectDraw support are described as follows:

  1. Consult the Display Drivers topic found in the device driver development guide. You should create a working display driver using the methods described in that guide.
  2. Test the driver and ensure that it works properly. You can also use this opportunity to add acceleration to certain operations in your display driver.

Once you have your basic Windows CE–based display driver written and tested, see DDHAL Functionality Implementation Without GPE.
