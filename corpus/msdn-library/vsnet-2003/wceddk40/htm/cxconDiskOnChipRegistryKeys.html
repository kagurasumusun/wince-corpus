DiskOnChip Registry Keys

The Device Manager uses several registry subkeys under the HKEY_LOCAL_MACHINE\Drivers key when loading the TrueFFS/CE driver. Built-in devices, such as the DiskOnChip, rely on the registry settings to be present at boot time. Therefore, these keys must be part of the default registry. This section describes the registry entries the Device Manager will use to install the TrueFFS/CE driver.

Every TrueFFS/CE registry entry is in the following format.

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\TrueFFSXX] 
    "Dll" = "TrueFFS.dll"
    "Prefix" = "DSK"
    "IClass"="{A4E7EDDA-E575-4252-9D6B-4195D48BB865}"
    "Order" = dword:1
    "WindowBase" = dword:D0000
    "DocBaseyy" = dword:D8000

The following table describes the [HKEY_LOCAL_MACHINE\Drivers\BuiltIn\TrueFFSXX] registry entry.

Registry entry Value Description
Dll TrueFFS.dll The name of the driver.
Prefix DSK Prefix (used for IOCTLs).
IClass A4E7EDDA-E575-4252-9D6B-4195D48BB865 GUID that defines the driver's exposed interface.
Order dword:1 For system use.
WindowBase dword:D0000 The WindowBase of the DiskOnChip.

The following is the HKEY_LOCAL_MACHINE\Drivers\BuiltIn\TrueFFSyy registry entry.

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\TrueFFSyy]
    "DeviceArrayIndex"=dword:XXX
    "IClass" = "{A4E7EDDA-E575-4252-9D6B-4195D48BB865}"
    "DOC_ACCESS_TYPE"=dword:8
    "ADDRESS_SHIFT " =dword:8

The following table describes the HKEY_LOCAL_MACHINE\Drivers\BuiltIn\TrueFFSyy registry entry.

Registry entry Value Description
DeviceArrayIndex dword:XXX The order that the system loads the devices, 0, 1, 2, and so on.
IClass {A4E7EDDA-E575-4252-9D6B-4195D48BB865} GUID that defines the driver's exposed interface.
DOC_ACCESS_TYPE dword:8 This field is optional. The default is 8. Can be set to 8h, 10h, or 20h.
ADDRESS_SHIFT dword:8 This field is optional. The default is 8. Can be set to 8h, 10h, or 20h.

DiskOnChip Profile 

[HKEY_LOCAL_MACHINE\System\StorageManager\Profiles\TRUEFFS_DOC]
    "Name"="DiskOnChip M-Systems"
    "Folder"="DiskOnChip"
