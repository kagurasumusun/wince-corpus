Memory Technology Drivers

The Windows CE TrueFFS driver accesses different types of linear flash memory hardware through software modules called memory technology drivers (MTDs). Each type of linear flash memory requires its own MTD because individual MTDs are designed to interact with specific linear flash memory chips. For this reason, you can omit any MTDs that will not be implemented on your target platform. For example, if your platform supports only built-in DiskOnChip hardware, you can omit the MTDs for Intel-based linear flash memory chips. However, if you need to support a new type of linear flash memory, you must create the MTD for that hardware.

To include an MTD in your Windows CE TrueFFS driver, call the MTDs registration routine in the Flcustom.c file, which is located in %_WINCEROOT%\Public\Common\Oak\Drivers\Trueffs. The following table shows existing MTDs and their corresponding registration routines.

  Series 2000 flRegisterCDSN
  FlashLite (8-bit mode) flRegisterI28F008
  FlashLite (16-bit mode) flRegisterI28F016

  Series II (16-bit mode) flRegisterI28F016
  Series II+ flRegisterI28F016
  Series 100 MiniCard (8-bit mode) flRegisterI28F008
  Series 100 MiniCard (16-bit mode) flRegisterI28F016

  Value Series 100 (8-bit mode) flRegisterI28F008
