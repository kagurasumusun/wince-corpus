NDIS_MEDIUM

typedef enum _NDIS_MEDIUM {
NdisMedium802_3,
NdisMedium802_5,
NdisMediumFddi,
NdisMediumWan,
NdisMediumLocalTalk,
NdisMediumDix,
NdisMediumArcnetRaw,
NdisMediumArcnet878_2,
NdisMediumAtm,
NdisMediumWirelessWan,
NdisMediumIrda,
NdisMediumBpc,
NdisMediumCoWan,
NdisMedium1394,
NdisMediumMax,
} NDIS_MEDIUM, *PNDIS_MEDIUM;

Elements

NdisMedium802_3
Specifies an Ethernet (802.3) medium.
NdisMedium802_5
Specifies a Token Ring (802.5) medium.
NdisMediumWan
Specifies a WAN.
NdisMediumDix
Specifies DEC/Intel/Xerox (DIX) Ethernet medium.
NdisMediumWirelessWan
Specifies various types of wireless medium.
NdisMediumIrda
Specifies infrared (IrDA) medium.
NdisMediumBpc
Specifies a broadcast architecture medium.
NdisMediumCoWan
Specifies a connection-oriented WAN medium, not supported.
NdisMedium1394
Specifies IEEE 1394 medium.
NdisMediumMax
Specifies an upper bound.

Remarks

None.
