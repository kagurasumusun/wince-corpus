USB Connectivity

A USB Function controller driver for platforms that includes the appropriate USB Function controller hardware is provided. By means of this driver, the USB Function controller hardware appears to Windows CE as a virtual serial port. Similarly, the desktop computer must have a similar host-side USB serial driver. With the platform and the desktop computer so configured, the standard serial-port based mechanisms for connectivity can be used over a USB connection. You can find the files necessary for implementing USB connectivity in %_WINCEROOT%\Platform\MyPlatform\Drivers\Serial_SL11. These files support the Scanlogic Corporation's SL11 USB Function controller chipset.

There is no support for allowing a platform to appear as a USB peripheral to other host computers. This is because only the host side of the USB client/host architecture is implemented. That is, the HCD and USB driver modules supplied do not provide facilities to connect a platform to a desktop computer that is running as a USB host. You could implement this functionality, but the platform would still require USB Function controller hardware.
