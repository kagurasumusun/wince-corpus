DDHAL Structures

The following topics contain tables of the Microsoft® DirectDraw® hardware abstraction layer (DDHAL) structures:

  • DDHAL Callback Structures
  • Color Control Structure
  • DirectDraw Structures
  • DirectDrawClipper Structures
  • DirectDrawPalette Structures
  • DirectDrawSurface Structures
  • Display Memory Structures
  • Display Driver Structures
  • Miscellaneous Structures
  • Video Port Structures

The preceding structures have been grouped into the DirectDraw categories in which they are used.

Note   The memory for all DirectX structures should be initialized to 0 before the structure is used. In addition, all structures that contain a dwSize member should set the member to the size of the structure, in bytes, before use. The following example performs these tasks on a common structure, DDCORECAPS:
DDCORECAPS ddcorecaps; // Can't use this yet.
ZeroMemory(&ddcorecaps, sizeof(ddcorecaps));
ddcorecaps.dwSize = sizeof(ddcorecaps);
// Now the structure can be used.
