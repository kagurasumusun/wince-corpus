Persistent Database on RFA

Any mounted file systems support databases, regardless of the storage mechanism of the file system. The only requirement is that the flash device driver supports the DISK_INFO_FLAG_PAGEABLE feature. There are database APIs that allow you to create and mount database volumes in the object store or on external storage devices. For more information on the object store, see Object Store. All operations on new database volumes are the same as operations on the object store databases. The new database volume contains both the data and an integrity log that tracks changes for atomic operations.
