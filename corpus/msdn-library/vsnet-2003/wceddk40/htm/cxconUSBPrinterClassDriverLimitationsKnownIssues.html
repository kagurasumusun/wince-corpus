USB Printer Class Driver Limitations and Known Issues

There are a few limitations and known issues with the USB printer class driver.

  • Windows CE only has a PCL printer driver, so the following entry is hard-coded into the registry to load the PCL driver. This will enable testing all USB printers that support PCL print format. 
    HKEY_LOCAL_MACHINE\Printers\<IEEE_1284_Device_String>\Driver:"PCL.DLL".
  • However, non-PCL printers still support ASCII-only printing with the default PCL driver. Also, you can load third party printer drivers so you can use a different driver to support printing on non-PCL printers.
  • The USB printer driver uses a hard-coded LPT: value in the registry so it automatically shows up in WordPad that there are two LPT1: ports, even though device manager has only started the USB Printer driver and assigned it the LPT1: name. The printer's IEEE_1284_Device_String appears correctly in WordPad.
