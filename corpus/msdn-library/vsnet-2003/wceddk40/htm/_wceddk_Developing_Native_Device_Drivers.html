GWES Loaded Device Drivers

Device drivers loaded by GWES, present a standard set of functionality for all devices of a particular class. GWES loads certain drivers if GWES is the only client of such devices. This makes accessing the drivers much faster.

The following list shows the device drivers that GWES loads:

  • Display
  • Keyboard
  • Mouse
  • Touch

The following list shows the device drivers that are part of GWES:

  • Battery
  • Notification LED
