KeybdEventCallbackEx

This function is a prototype of the callback function passed to the KeybdDriverInitializeEx function.

void KeybdEventCallbackEx(
UINT32 VirtualKey,
KEY_STATE_FLAGS KeyEvent 
);

Parameters

VirtualKey
[in] Specifies code for the virtual key or event.
KeyEvent
[in] Specifies if the KeyStateDownFlag is set or cleared.

Return Values

None.

Remarks

The keyboard driver does not implement this function. This is the prototype of the function passed into the driver by the user input system when it calls the KeybdDriverInitializeEx function. The driver calls the callback function whenever there is a keyboard event.

The KeyStateDownFlag field in the KeyEvent parameter is set for a key-down event and clear for a key-up event. All other bits must be 0. The VirtualKey parameter has more than just the virtual key information. See Keybddr.h for a description of the information in this parameter.

When a keyboard is connected or disconnected, an event must be signaled with the appropriate connect-event code or disconnect-event code set in the VirtualKey parameter.
