ACM_Init

This function initializes an ACM driver.

PVOID ACM_Init(
DWORD   dwInfo 
);

Parameters

dwInfo
Specifies information passed to the RegisterDevice function.

Return Values

Returns a DWORD, which is passed to the ACM_Open and ACM_Deinit functions, or NULL if unable to initialize the device.

Remarks

The ACM Driver Wrapper library (Acmdwrap.lib) calls the DriverProc function with the DRV_LOAD message.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later     Acmdwrap.lib
