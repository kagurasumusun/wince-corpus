DDHAL Macros

The following table lists the macros provided by DirectDraw with their corresponding descriptions.

Macro Description
GET_LPDDRAWSURFACE_GBL_MORE Traverses from a DDRAWI_DDRAWSURFACE_GBL structure to a DDRAWI_DDRAWSURFACE_GBL_MORE structure.
SURFACE_PHYSICALVIDMEM Retrieves a linear physical memory address for the surface, given a global surface object.
