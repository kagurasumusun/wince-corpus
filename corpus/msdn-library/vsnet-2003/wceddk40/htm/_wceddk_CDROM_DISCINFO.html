CDROM_DISCINFO

This structure contains general information on the CD-ROM, such as the first and last track.

typedef struct CDROM_DISCINFO {
ULONG Reserved; 
ULONG FirstTrack; 
ULONG LastTrack; 
MSF_ADDR LeadOutTrackAddr; 
UCHAR FirstSession; 
UCHAR LastSession; 
UCHAR ReqSession; 
UCHAR RetSession; 
UCHAR LogicStartAddr; 
} CDROM_DISCINFO, *PCDROM_DISCINFO;

Members

Reserved
Reserved for future use. Must be zero.
FirstTrack
This is the first track of the session.
LastTrack
The last track of the session.
LeadOutTrackAddr
The address of the lead out track of session.
FirstSession
The first session on the disc.
LastSession
The last session on the disc.
ReqSession
Requested session.
RetSession
The returned session.
LogicStartAddr
Logical start address of the session.
