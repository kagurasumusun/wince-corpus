Block Drivers

Devices that read or write data in blocks of a fixed size use block device drivers. Block devices do not allow you to read or write individual bytes of data. Common block sizes are 512 bytes, 1 KB, 2 KB, and 4 KB. Block devices are ideally suited to mass storage and persistent storage applications, such as disk drives or nonvolatile RAM disks. Some common types of block devices are hard disks and Advanced Technology Attachment (ATA) flash memory disks in miniature card, PC Card, and Compact Flash card form factors.

If you want your driver to interface with the file allocation table (FAT) file system or file system driver (FSD) Manager, your block driver should expose the stream interface. For more information on the stream interface, see Stream Interface Drivers. The Device Manager manages drivers that expose the stream interface. For more information on the Device Manager, see Device Manager. The stream interface exposes file I/O functions in order to interact with applications. The most important of the I/O functions for block device drivers is the XXX_IOControl function that handles all I/O requests to block devices.
