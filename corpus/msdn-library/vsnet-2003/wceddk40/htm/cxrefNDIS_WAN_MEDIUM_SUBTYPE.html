NDIS_WAN_MEDIUM_SUBTYPE

This enumeration specifies a set of medium subtypes for WAN medium. 

typedef enum _NDIS_WAN_MEDIUM_SUBTYPE {
NdisWanMediumHub,
NdisWanMediumX_25,
NdisWanMediumIsdn,
NdisWanMediumSerial,
NdisWanMediumFrameRelay,
NdisWanMediumAtm,
NdisWanMediumSonet,
NdisWanMediumSW56K,
NdisWanMediumPPTP,
NdisWanMediumL2TP,
NdisWanMediumIrda,
NdisWanMediumParallel,
NdisWanMediumPppoe,
} NDIS_WAN_MEDIUM_SUBTYPE, *PNDIS_WAN_MEDIUM_SUBTYPE;

Elements

NdisWanMediumHub
Specifies a remote access server (RAS) hub.
NdisWanMediumX_25
Specifies an X.25 medium.
NdisWanMediumIsdn
Specifies an ISDN medium.
NdisWanMediumSerial
Specifies a serial line.
NdisWanMediumSW56K
Specifies a switched 56K medium.
NdisWanMediumPPTP
Specifies a switched 56K medium.
NdisWanMediumL2TP
Specifies a Layer 2 Tunneling Protocol (L2TP) line.
NdisWanMediumIrda
Specifies an IrDA (infrared) medium.
NdisWanMediumParallel
Specifies a parallel line.
NdisWanMediumPppoe
Specifies a point-to-point protocol over Ethernet (PPOE) medium.

Remarks

OID_WAN_MEDIUM_SUBTYPE uses this enumeration for the miniport driver to define a list of media subtypes that it can support.
