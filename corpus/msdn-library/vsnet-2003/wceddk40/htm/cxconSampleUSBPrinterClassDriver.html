Sample USB Printer Class Driver

The USB printer class driver sample is in %_WINCEROOT%\Public\Common\Oak\Drivers\USB\Class\Printer. The driver DLL is USBPRN.dll. This sample driver is not backward compatible.

The USB printer class driver is fully complaint with the USB Printer Device Class Specification, Version 1.0, and follows the interfaces outlined in the specification. For information about the USB specification or the USB printer class specification, see the USB Web site.

This driver provides a universal solution for printing on Windows CE OSs through the USB port. The goal is to write the USB printer class driver as a transport driver that plugs into the existing print driver architecture.
