DirectDraw Implementation Guide

The Implementation Guide contains the following topics:

  • DirectDraw Architecture contains an illustration of how the new architecture fits into Windows CE. This group of topics outlines the design of the architecture for display drivers written to support DirectDraw under Windows CE. This group of topics concludes with a comparison of this architecture to the design of the DirectDraw HAL for the Windows desktop.
  • DirectDraw Display Driver Creation describes the steps required to build a working DirectDraw display driver as quickly as possible.
  • DirectDraw Display Driver Creation Without DDGPE describes how to create a display driver that supports DirectDraw without using any GPE-based classes.
  • DDHAL Porting from the Desktop discusses how to convert source code from an existing DDHAL for Windows desktop into the DDHAL for a Windows CE–based display driver.
