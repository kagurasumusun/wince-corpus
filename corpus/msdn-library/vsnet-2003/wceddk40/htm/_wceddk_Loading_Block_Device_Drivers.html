Block Driver Loading

You should include registry keys under the platform's HKEY_LOCAL_MACHINE\Drivers\Builtin registry key so that the Device Manager loads the block device driver when the platform starts. For more information on the Device Manager, see Device Manager.

Block device drivers for PC Card block devices or similar removable hardware use the HKEY_LOCAL_MACHINE\Drivers\PCMCIA registry key so that the Device Manager loads the driver when you connect the relevant block device to the system.
