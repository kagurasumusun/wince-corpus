Direct3D Device Driver Interface

The Microsoft® Direct3D® device driver interface (DDI) is a graphics interface that allows vendors to provide hardware acceleration for Direct3D. The interface is flexible, allowing vendors to provide Direct3D acceleration according to hardware capabilities. Driver writers implement the Direct3D DDI as an integral part of the display driver.

The topics referred to here describe the Direct3D architecture and interface, and provide implementation guidelines for Direct3D driver writers. To gain the most from these topics, it is assumed that you are familiar with the Direct3D and Microsoft DirectDraw® application programming interfaces (APIs), and that you have an in-depth understanding of the Microsoft Windows® CE .NET display driver model, including DirectDraw Display Drivers. Please keep the following restrictions in mind when using the DirectDraw API set.

Note   You can enable both GDI multiple screens and DirectDraw entry points in your display driver. However, there are significant restrictions on using the DirectDraw API set while running multiple screens on your system. Also, the GDI screen rotation cannot be used with DirectDraw at all. For more information about GDI multiple screens and screen rotation, see the Multiple Screen and Screen Rotation topics under Display Driver Extension.

All Direct3D drivers for Windows CE .NET and later must conform to the Microsoft DirectX® 8.0 or later Direct3D driver model.

The Direct3D DDI is explained in more detail in the following topics:

  • Direct3D Implementation Guide contains practical information about creating a Windows CE–based Direct3D driver.
  • The Direct3D Driver Reference is made up of the Direct3D Driver Functions, Direct3D Driver Structures, and Direct3D Driver Enumerations, which provide reference pages for the functions, structures, and enumerations needed to implement a Direct3D driver.
