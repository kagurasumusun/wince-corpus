TrueFFS Driver Registry Key Modification

The Device Manager manages and uses several registry keys to load, track, and unload linear flash memory drivers. These keys are under the HKEY_LOCAL_MACHINE\Drivers registry key. For built-in devices, such as DiskOnChip, the registry settings must be present at startup time; therefore, these keys must be part of the default registry. However, a user can install keys for removable media, such as linear flash memory PC Cards, on first use of the device.
