Waveform Audio Driver

A waveform audio driver is responsible for processing messages from the waveform API Manager to play and record waveform audio. Waveform audio drivers are implemented as stream interface drivers loaded by the Device Manager. All audio drivers use the prefix WAV to name their stream interface functions, yielding function names such as WAV_Open and WAV_IOControl. Beginning with Microsoft® Windows® CE .NET, DirectSound is supported with the new messages in WAV_IOControl.
