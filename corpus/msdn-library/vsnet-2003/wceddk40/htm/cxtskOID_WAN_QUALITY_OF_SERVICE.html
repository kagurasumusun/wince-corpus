OID_WAN_QUALITY_OF_SERVICE

This object requests the miniport driver to return the quality of service that it supports.

The quality of service returned for this query should be a worst-case estimate, specified as one of the following system-defined values:

Service quality value Description
NdisWanRaw Specifies a raw binding, in which the NIC driver puts all packets on the network unmodified.
NdisWanErrorControl Specifies an error control binding.
NdisWanReliable Specifies a reliable binding.
When a NIC driver calls NdisMIndicateStatus with a line-up indication, it provides QOS information for a specified link.
