D3dContextCreate

This function creates a context.

DWORD
  (*APIENTRY *LPD3DHAL_CONTEXTCREATECB)(
     LPD3DHAL_CONTEXTCREATEDATA   pccd
     );

Parameters

pccd
Points to a D3DHAL_CONTEXTCREATEDATA structure that contains the information required to create a context and the data that the driver should store in the new context.

Return Values

D3dContextCreate returns one of the following callback codes:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED

Remarks

D3dContextCreate must be implemented in drivers that support Direct3D. It should perform the following steps:

  • Initialize the driver's context with all information required by the driver to perform rendering. This includes associating the rendering target and depth buffer that lpDDS and lpDDSZ point to, respectively, with the context.
  • Generate a unique context identifier for this new context and return it in dwhContext. Direct3D will use this context identifier in every subsequent callback it makes to this Direct3D device. The driver must never create a context handle of zero.
  • Set ddrval to DD_OK upon success, and to D3DHAL_OUTOFCONTEXTS if it cannot create the context.
  • Return DDHAL_DRIVER_HANDLED upon return.

State is not shared between contexts; therefore, the driver must maintain full state information for each context. This state will be changed by any subsequent calls to D3dDrawPrimitives2.

The driver must be able to reference all texture handles that are created within the created context. This is so that the driver can clean up all driver-specific data related to textures created within this context when a D3dContextDestroy call is made.
