Display Driver Samples

Code for the sample drivers is in %_WINCEROOT%\Public\Common\OAK\Drivers\Display.

The following table shows some files that can help you work with both monolithic and GPE-based display drivers.

File Description
Winddi.h This file contains all the core definitions for both display and printer device drivers. Consult this file if you are creating a monolithic driver, because it describes all of the entry points, data types, and symbolic constants that you need to receive and process drawing requests from GWES.

This file also contains important definitions for display driver writers who are using GPE, because many GWES data structures percolate through the GPE layer into the GPE objects.
Emul.h This file describes the set of raster drawing helpers inside the raster emulation library. Creating fast raster output is very important for display driver writers, because more than 95% of the pixels on a display screen are drawn using raster drawing calls.

The emulation library provides a reasonably good solution for drawing raster data in software. However, whenever your display device has the ability to perform any of the drawing using accelerated hardware, you should consider using the hardware in place of the raster emulation library.
GPE.h This file contains the basic set of data structures and symbol definitions that you will need to use the GPE library.
GPE source files If you install the Private tree, you can find these files at %_WINCEROOT%\Private\Winceos\ Coreos\Gwe\Mgdi\Gpe.
