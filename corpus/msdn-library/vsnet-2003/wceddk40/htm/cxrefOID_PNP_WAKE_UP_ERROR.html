OID_PNP_WAKE_UP_ERROR

This object indicates the number of false wake-ups signaled by the miniport's NIC. A false wake-up occurs when the NIC wakes up the system when it shouldn't have. For example, the NIC could erroneously wake up the system due to an inexact pattern match.

An intermediate driver whose upper edge receives this request must always propagate the request to the underlying miniport by calling NdisRequest.
