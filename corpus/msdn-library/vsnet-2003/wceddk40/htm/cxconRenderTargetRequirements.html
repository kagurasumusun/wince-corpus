Render Target Requirements

Color buffers and depth buffers have the following requirements:

  • Color Buffers: If the hardware is unable to support a render target that is also to be used as a texture — that is, the device cannot render to a texture— the device must fail calls to the IDirect3DDevice8::SetRenderTarget and IDirect3D8::CreateDevice methods on such surfaces. These methods are described in the Windows CE Direct3D SDK documentation. The fact that a render target is to be used as a texture is signified by the presence of the DDSCAPS_TEXTURE flag in the surface description. For more information, see the dwCaps member of the DDSCAPS structure.
  • Depth Buffers: If the hardware is unable to support a particular combination of render target and depth-buffers, then the device must fail any API calls that would cause this invalid scenario to occur, and where this mismatch can be detected, such as in calls to the IDirect3D8::CreateDevice method. These methods are described in the Direct3D and DirectDraw SDK documentation sets, respectively. An example of such a mismatch might be when the render target and depth buffer are of different bit depths. It is not acceptable to transparently alter the format of either the render target or the depth-buffer to cause an invalid combination to work properly. It is acceptable to silently increase the precision of the depth buffer.
