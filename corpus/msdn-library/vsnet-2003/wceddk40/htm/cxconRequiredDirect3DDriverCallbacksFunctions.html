Required Direct3D Driver Callbacks and Functions

The following table lists the Direct3D callback functions that must be implemented in a Direct3D driver.

Required callback Description
D3dContextCreate Creates a context.
D3dContextDestroy Destroys a context.
D3dCreateSurfaceEx Creates an association between a texture handle and a surface. Also called to remove associations.
D3dDrawPrimitives2 Renders primitives and returns updated state to Direct3D.
D3dValidateTextureStageState Performs texture stage state validation that is required for all drivers that support texturing.

In order to support Direct3D, a driver must minimally support DirectDraw and must also implement certain DirectDraw DDI functions and callbacks. Those pertinent to Direct3D support are listed in the following table.

DDI function Description
HALInit This function retrieves the capabilities of the graphics hardware. In this initialization function the driver indicates that it supports Direct3D.
GetDriverInfo The run time queries this callback with globally unique identifiers (GUIDs) for additional information about the driver. Several GUIDs pertain specifically to the driver's Direct3D support.

DirectDraw function and callback implementation details are discussed in DirectDraw Callback Functions.
