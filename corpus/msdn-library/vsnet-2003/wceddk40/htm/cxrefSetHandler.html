SetHandler

Required function MDD uses to set miscellaneous features of the PDD.

typedef BOOL (* PFN_PDD_SET)(
IN  UINT    uiRequestId,
IN  PVOID   pvData,
IN  ULONG   ulDataLength
);

Parameters

uiRequestId
The following table shows the constants defined for uiRequestId that the PDD needs to implement.
Constant Value Description
REQ_ID_HARD_RESET 0x00000001 SET:: Hard reset..
REQ_ID_SOFT_RESET 0x00000002 SET:: Soft reset..
REQ_ID_ENABLE_INT 0x00000003 SET:: Enable Interrupt
REQ_ID_DISABLE_INT 0x00000004 SET:: Disable Interrupt
pvData
Pointer to the data buffer.
ulDataLength
Specifies the length of the data content in the message.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Rndismini.h Rndismini.h
