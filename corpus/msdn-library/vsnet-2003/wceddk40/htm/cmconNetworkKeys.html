Network Keys

A network key is a key used for network encryption under the WEP algorithm. Under 802.11, a wireless station can be configured with up to four network keys, with the key index values being 0, 1, 2, and 3. When an access point or a wireless station transmits an encrypted message using a key that is stored in a specific key index, the transmitted message indicates the key index that was used to encrypt the message body. The receiving access point or wireless station can then retrieve the key that is stored at the key index and use it to decode the encrypted message body.
