SurfaceHeap Class

The SurfaceHeap class is a heap management class that should be used when the abilities of the Node2D class do not satisfy the requirements of your driver. It is most useful when your driver is capable of supporting surface types of different bit depths.

Your driver is not required to use the SurfaceHeap class. However, it is recommended that if you start your driver from scratch, or when you start extending DDHAL support in your driver, that you migrate from Node2D to SurfaceHeap.

The following table lists the methods defined in the SurfaceHeap class.

Function Description
SurfaceHeap::Address Retrieves the address of the current heap.
SurfaceHeap::Alloc Reserves a block of memory from the specified heap.
SurfaceHeap::Available Determines the amount of nonallocated memory in the current heap.
SurfaceHeap::Constructors Various ways to create SurfaceHeap objects are provided.
SurfaceHeap::Free Releases memory from the current heap.
SurfaceHeap::NodeSize Retrieves the size, in bytes, of the current heap, excluding subsequent nodes.
SurfaceHeap::Size Retrieves the total size of the current heap.

For a description of the SurfaceHeap class, see SurfaceHeap Class Definition.
