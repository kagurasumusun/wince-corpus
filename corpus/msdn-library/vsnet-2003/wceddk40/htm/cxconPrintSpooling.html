Print Spooling

Unlike the desktop versions of the Windows OS, no separate printer spooler component exists in Windows CE. With Windows CE, spooling or background printing is implemented in the printer driver itself. However, print spooling typically consumes a large amount of memory, so memory limitations may be a problem. A practical print spooler almost always has to implement a complicated compression scheme to store spooled documents before printing. Several third-party companies implement print spoolers for Windows CE.
