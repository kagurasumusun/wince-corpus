Driver Development Processes

When you develop your device driver for Microsoft® Windows® CE, you can follow any number of processes. The following table shows some typical processes used to develop a device driver.

Topic Description
Driver Development Tools Compares Platform Builder with Microsoft Visual Studio®.
Driver Code Structure Compares layered code to monolithic code.
Driver Debugging Compares different debugging methods.
Driver Testing Explains how to test your device driver.
Driver Migration Shows you how to migrate, or port, your driver from previous versions of Windows CE.
Driver Integration into the IDE Explains how to integrate your driver into the Platform Builder IDE.
Third Party Device Drivers Show you where you can find information about third party device drivers, driver validation, and board support package (BSP) certification.
