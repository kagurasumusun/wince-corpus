UNIT_ConnectionRequestProcessed_Request

This structure is used by IOCTL_UNIT_CONNECTION_REQUEST_PROCESSED.

typedef struct{
PVOID ucrp_RegistrationToken;
PVOID ucrp_Request;
NTSTATUS ucrp_Status;
} UNIT_ConnectionRequestProcessed_Request ;

Members

ucrp_RegistrationToken
The registration token value from a previous IOCTL_UNIT_REGISTER_SUBUNIT command.
ucrp_Request
The opaque value passed in during the UNIT_ConnectToRemotePlugCB call.
ucrp_Status
The NTSTATUS value that the Subunit wants to return for the asynchronous connection request.
