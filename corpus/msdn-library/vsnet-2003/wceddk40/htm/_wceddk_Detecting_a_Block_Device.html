Block Driver Detection

When you connect a block device to a platform, the Device Manager calls the driver's detection function. The registry keys for your driver specify the detection function. The detection function attempts to recognize the type of block device hardware that is present by querying the device. If the driver recognizes the device, the Device Manager loads the block device driver into memory. This detection and load process is standard procedure for PC Card devices only. For more information on the Device Manager, see Device Manager.
