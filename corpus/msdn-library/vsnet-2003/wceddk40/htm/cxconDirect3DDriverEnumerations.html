Direct3D Driver Enumerations

Enumerated types that are used by both Microsoft® Direct3D® drivers and applications, such as D3DRENDERSTATETYPE, are described in the Direct3D software development kit (SDK) documentation. For more information, see Direct3D Enumerated Types.

Direct3D Driver Resources lists the include files that define Direct3D enumerated types. Additional information for writing a Direct3D driver can be found in Direct3D Device Driver Interface.
