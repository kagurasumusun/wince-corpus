Socket Interfaces

The socket interface controls the access of the TrueFFS/CE driver to sockets in which linear flash memory hardware resides. For PC Cards, the interface components consist of the PC Card socket API. For built-in DiskOnChip devices, the socket interface is a specially designed software component. If you implement DiskOnChip hardware but not PC Card sockets, you only need to keep the DiskOnChip socket layer.

To call the registration routine for built-in DiskOnChip hardware, use the flRegisterFixedFlash function. To call the registration routine for PC Card-based linear flash memory hardware, use the flRegisterCS function.
