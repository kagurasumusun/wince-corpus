DVD-Video Renderer Enumerations

The following table lists some of the enumerations used in the DVD-Video control interface.

Enumeration Description
EDVDAspectRatioMode Defines constants used to describe the aspect ratio mode.
EDVDAudioFreq Defines constants used to describe the audio frequency.
EDVDAudioStreamType Defines constants used to describe the format of the audio stream.
EDVDDisplayAspectRatio Defines constants used to describe the display aspect ratio.
EDVDLpcmQuantization Defines constants used to describe the width of the LPCM.
EDVDSyncEventType Defines constants used to describe synchronization events.
EHighlightAction Defines constants used to describe the action state of the current highlight.
