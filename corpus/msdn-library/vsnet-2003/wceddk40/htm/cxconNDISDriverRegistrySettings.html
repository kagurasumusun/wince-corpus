NDIS Driver Registry Settings

Windows CE uses the registry for dynamic installation and binding of device drivers. Your driver installation program must make sure to create the appropriate registry settings for your miniport driver in the Windows CE-based registry.

The following list shows some of the registry settings provided in Windows CE Driver Development Guide:

  • AsyncMac Registry Settings
  • IrCOMM and IrSIR
  • IrComm Driver Registry Settings
  • Kingston PCI NE2000
  • Linksys ISA NE2000
  • NDIS Adapter Binding Management APIs
  • NDIS Plug and Play Support
  • Network Bridging Registry Settings
  • Virtual Private Networking
  • SNMP Registry Settings
  • Unimodem Registry Settings
  • UPnP Registry Settings
  • USB Driver Registry Settings
  • WinInet Registry Settings
