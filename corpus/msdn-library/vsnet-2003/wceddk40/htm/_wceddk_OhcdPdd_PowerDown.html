HcdPdd_PowerDown

This function is the HC driver power-off handler.

void HcdPdd_PowerDown(
DWORD dwDeviceContext 
);

Parameters

dwDeviceContext
[in] Specifies a pointer to the device context returned from the HcdPdd_Init function.

Return Values

None.

Remarks

This function is called when the system is turned off. This function must call the HcdMdd_PowerDown function to enable the MDD to save state information. Then, any processing specific to the platform, such as removing power from the host controller hardware, is performed. No system calls can be made from within this function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Ohcdddsi.h or Uhcdddsi.h
