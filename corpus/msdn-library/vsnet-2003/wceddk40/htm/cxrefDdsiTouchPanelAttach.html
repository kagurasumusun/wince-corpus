DdsiTouchPanelAttach

This function is called when the MDD's DLL entry point gets a DLL_PROCESS_ATTACH message.

LONG DdsiTouchPanelAttach (void);

Parameters

None.

Return Values

Returns 0.

Remarks

In many systems, the touch driver is only loaded by one process. However, it is possible that Transcriber will also load the touch DLL, although Transcriber does not use it to touch hardware. For this reason it is important that the DDSI attach and detach routines, not modify hardware or interrupt state. Such system updates should only be made in response to DdsiTouchPanelEnable and DdsiTouchPanelDisable calls. They can initialize global variables, events, and so on. In this case, each process loading the touch driver will get its own copy.

If drivers have an absolute requirement to initialize hardware during DLL loading, they can implement a global memory section to ensure that only one process actually touches hardware.
