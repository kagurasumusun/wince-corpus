USB Frame Functions

The following table shows the frame functions that control the physical characteristics of frame timing on the bus.

Function Description
GetFrameLength Gets a current USB frame length.
GetFrameNumber Gets a current USB frame number.
ReleaseFrameLengthControl Releases exclusive access to USB frame-length control.
SetFrameLength Changes the USB frame length.
TakeFrameLengthControl Registers for exclusive access to control the USB frame length.
