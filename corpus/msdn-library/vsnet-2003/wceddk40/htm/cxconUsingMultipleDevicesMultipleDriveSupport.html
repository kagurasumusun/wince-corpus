Multiple Devices and Multiple Drive Support

The TrueFFS/CE driver supports multiple drives and devices.

Multiple drives on same DiskOnChip device

Utilizing the DiskOnChip Millennium Plus enables you to create up to four storage devices to be located on a single physical DiskOnChip device. The sequence of mounting the drives can be determined by setting the appropriate value for the DeviceArrayIndex TrueFFS/CE registry entry.

MultiDOC

It is possible to use more than one DiskOnChip. Each DiskOnChip appears as a separate device. The MultiDOC feature allows you to utilize more than one DiskOnChip device using only one instance of the driver. This feature allows you the flexibility in choosing any combination of capacities and form factor of DiskOnChip devices in your system, for example, have a DiskOnChip located at physical address xD0000 and another DiskOnChip on address xD8000, and so on. In order to notify the driver you intend to use more than one device, the DOCBaseXX registry entry should be added. The DOCBase10 corresponds to the base address of the second DiskOnChip device in the system; this device is now carrying the path ended with TrueFFS1x, for example HKEY_LOCAL_MACHINE\Drivers\BuiltIn\TrueFFS10.

The following example holds eight entries to accommodate two physical DiskOnChip Millennium Plus devices, where the fist one is located as physical address xD0000 and the second DiskOnChip is located at address xD8000. Every one of them is re-partitioned to carry four partitions.

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\TrueFFS] 
    "Dll" = "TrueFFS.dll" 
    "Prefix" = "DSK" 
    "Order" = dword:1 
    "WindowBase" = dword:D0000 
    "DocBase10" = dword:D8000 
    "DeviceArrayIndex"=dword:0
    "IClass" = "{A4E7EDDA-E575-4252-9D6B-4195D48BB865}"
