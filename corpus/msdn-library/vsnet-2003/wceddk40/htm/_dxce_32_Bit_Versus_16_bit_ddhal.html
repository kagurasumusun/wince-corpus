32-Bit vs. 16-Bit

Windows CE is a purely 32-bit environment. This means that its DirectDraw implementation is not compatible with the 16-bit mechanism offered by the Desktop DDHAL model. Any callbacks that were implemented in 16 bits must be converted to 32 bits when moving to the Windows CE–based DirectDraw HAL implementation.
