PCI Bus Enumerator Template

In order to take advantage of the capabilities of the PCI bus enumerator, information must be added to the HKEY_LOCAL_MACHINE\Drivers\BuiltIn\PCI\Template registry key so that the enumerator is able to detect your device.

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\PCI\Template\MYNIC]
    "Class"=dword:02
    "SubClass"=dword:00
    "ProgIF"=dword:0
    "VendorID"=multi_sz:"1234","5678"
    "DeviceID"=multi_sz:"1111","2222"
    "Dll"="NDIS.dll"
    "Entry"="NdisPCIBusDeviceInit"

To determine if a PCI card matches the appropriate values, the PCI bus enumerator uses the settings in the previous example.

Note   The VendorID and DeviceID registry values work in pairs. For example, a PCI card would match the above example if VendorID=1234 and DeviceID=1111, or, VendorID=5678 and DeviceID=2222. The Dll and Entry values are used to inform the PCI bus enumerator which driver it must notify when a match is found and a device instance is created. For a PCI NIC using NDIS, the Dll value should always be set to "ndis.dll" and the Entry value must be set to "NdisPCIBusDeviceInit".

By default, NDIS will look in HKEY_LOCAL_MACHINE\Comm\<miniport name> for the location of the miniport driver. If you desire to use a miniport name that is different from the template name you can set the value "Miniport"=<miniport name>. For example:

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\PCI\Template\MYNIC]
    "Miniport"="sample"

will cause NDIS to look for miniport driver information in HKEY_LOCAL_MACHINE\Comm\SAMPLE instead of HKEY_LOCAL_MACHINE\Comm\MYNIC.

Additional registry settings can be a part of the template if so desired. Te settings will not be used by the PCI bus enumerator but will be copied to the instance settings for use by the miniport driver.

When a match is found, the PCI bus enumerator creates an instance in the registry. This instance includes specific resources assigned to the adapter such as the bus type, bus number, IRQ, system interrupt value and memory addresses. The name of the instance entry will be <TemplateName><n>, where <n> starts at 1 and counts up for each successive device that is found matching the template.
