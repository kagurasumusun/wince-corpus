Bluetooth Transport Layer Driver Samples

There are three sample transport layer drivers.

Sample transport layer driver Description
BTHUSB Sample HCI USB transport layer driver.
BTHUART Sample HCI UART transport layer driver.
BTHUNIV Universal transport manager for Bluetooth. It is a layer that links to the HCI layer and manages the Bluetooth devices connected to the host with different transports.

The source code for these samples can be found under %_PUBLICROOT%\Common\Oak\Drivers\Bluetooth\Transports.
