DSDMP_MSG

This structure contains the message value and driver instance.

typedef struct _DSDMP_MSG{
  DWORD    dwMsg;
  DWORD    dwInstance;
} DSDMP_MSG;

Members

dwMsg
Contains the message value.

The following messages are supported for dwMsg.

DSDM_CREATEBUFFER DSDM_DELETEBUFFER
DSDM_DUPLICATEBUFFER DSDM_STOP
DSDM_GETPOSITION DSDM_GETSTATUS
DSDM_LOCK DSDM_PLAY
DSDM_SETFORMAT DSDM_SETFREQUENCY
DSDM_SETNOTIFICATIONS DSDM_SETPOSITION
DSDM_SETVOLUMEPAN DSDM_UNLOCK
dwInstance
Pointer to a driver buffer instance data.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Dsdriver.h
