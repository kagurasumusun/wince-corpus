Notification LED Samples

%_WINCEROOT%\Platform\EAGLE\GWE\NLEDDRV contains full sample code for a notification LED driver. Nleddrv.cpp contains the NLED functions to implement for your platform. The sources file tells the build tool to build Nleddrv.lib. Nleddrv.lib eventually links with Battery.lib to produce Gwe_drv.lib. Gwe_drv.lib then links with other OS modules to produce GWES.exe.

The following directories provide stubbed sample code for notification LED drivers:

  • %_WINCEROOT%\Platform\ASPEN\GWE\NLEDDRV
