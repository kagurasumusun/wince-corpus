Installing the USB Printer Class Driver

  1. Include the USB printer class driver in the Windows CE OS binary image. If the driver is not in the Nk.bin image, you can also manual copy the Usbprn.dll driver DLL to your release directory on your development workstation or to the \Windows directory on the target platform.
  2. Set up the correct registry entries for the printer driver on your target platform.
  3. Attach the USB printer to the target platform.

    If you have the correct registry entries set up on the target platform and if the USB printer is class-compliant, then the USB subsystem will load the USB printer driver automatically.

    If you do not have the correct registry settings on the device, the system will display an Unknown Device dialog box. Type USBPRN in this dialog box and then press ENTER, which will load the USB Printer class driver and set the correct registry entries so the driver can load automatically next time.
