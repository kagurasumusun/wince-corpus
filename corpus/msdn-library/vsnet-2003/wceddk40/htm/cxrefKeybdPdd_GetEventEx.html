KeybdPdd_GetEventEx

This function is called by the upper layer to retrieve keyboard events after the keyboard system interrupt is signaled.

INT WINAPI KeybdPdd_GetEventEx (
UINT32 VirtualKeys[16],
UINT32 ScanCodes[16],
KEY_STATE_FLAGS  KeyEvents[16]
);

Parameters

VirtualKeys
[in] Specifies the buffer in which to put detected virtual keys.
ScanCodes
[in] Specifies the buffer in which to put scan codes.
KeyEvents
[in] Specifies the buffer in which to put key state flags.

Return Values

Number of key events; a value of 0 is allowed.

Remarks

This function supports the implementation of the Keyboard Driver lower layer.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Keybdpdd.h
