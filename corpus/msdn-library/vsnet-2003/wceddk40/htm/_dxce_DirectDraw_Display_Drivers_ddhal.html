DirectDraw Display Drivers

Topics related to Microsoft® DirectDraw® display drivers describe the architecture that implements the DirectDraw hardware abstraction layer (DDHAL) as part of the Microsoft Windows® CE .NET–based device driver interface (DDI), and outline the steps that are required to create a Windows CE–based graphics display driver that supports DirectDraw. These topics also discuss how you can extend the capabilities of your display driver and act as a companion and optional extension to the Display Drivers topic.

DirectDraw display drivers are discussed in detail under the following main topics:

  • DirectDraw Implementation Guide contains an overview of the DirectDraw architecture and practical information about creating a Windows CE–based display driver that supports DirectDraw. It also includes information about porting your DDHAL from the desktop.
    Note   It is assumed in some of the topics that you are using Graphics Primitive Engine (GPE) classes from Microsoft.
  • DirectDraw Driver Extension contains information on how you can extend your display driver by taking advantage of your hardware or DirectDraw Graphics Primitive Engine (DDGPE).
  • DirectDraw Driver Support describes the different files that driver writers should reference. These files are provided to help you create a DirectDraw display driver.
  • DirectDraw Driver Reference details the callbacks, macros, and structures that can be implemented by your driver.
