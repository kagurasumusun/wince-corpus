Application Suspend Time-outs

OEMs may choose to write applications that manage system power states directly, without customizing the power manager. To enable this, applications must disable both GWES and Power Manager power management and handle power states as desired. For more information about disabling GWES and Power Manager power management, see Power Manager Suspend Timeouts.

The Power Manager may not be able to determine the state that it should resume after a suspend occurs. If OEMs choose to allow the system to resume fully after each suspend, this may not be an issue. However, if OEMs choose to have real-time clock alarms that partially wake the system, they may need to modify the Power Manager in any event.
