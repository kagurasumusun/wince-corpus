XXX_Write

This function writes data to the device.

DWORD XXX_Write(
DWORD hOpenContext,
LPCVOID pBuffer,
DWORD Count 
);

Parameters

hOpenContext
[in] Handle to the open context of the device. The call to the XXX_Open function returns this identifier.
pBuffer
[out] Pointer to the buffer that contains the data to write.
Count
[in] Specifies the number of bytes to write from the pSourceBytes buffer into the device.

Return Values

The number of bytes written indicates success. A value of –1 indicates failure.

Remarks

An application uses the WriteFile function to write to the device. The operating system, in turn, invokes this function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later
