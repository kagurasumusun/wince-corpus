OID_IRDA_MAX_SEND_WINDOW_SIZE

This object identifier is optional for IrDA miniport drivers.

This object identifier requests the maximum number of outgoing frames that the miniport driver's NIC can handle at one time. This number is the maximum send window size. IrLAP uses this number to limit the number of frames it transmits at one time. The miniport driver typically uses this object identifier as a patch for hardware that cannot keep up with the infrared signal over a full-sized window of 7 frames. The valid values for this object identifier are 1-7.
