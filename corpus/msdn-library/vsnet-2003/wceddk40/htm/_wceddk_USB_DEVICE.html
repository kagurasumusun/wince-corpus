USB_DEVICE

This structure contains general information about USB devices.

typedef struct {
UCHAR bLength,
UCHAR bDescriptorType,
USHORT bcdUSB,
UCHAR bDeviceClass,
UCHAR bDeviceSubClass,
UCHAR bDeviceProtocol,
UCHAR bMaxPacketSize0,
USHORT idVendor,
USHORT idProduct,
USHORT bcdDevice,
UCHAR iManufacturer,
UCHAR iSerialNumber,
UCHAR bNumConfigurations
} USB_DEVICE;

Members

bLength
Size in bytes of this structure.
bDescriptorType
The constant value DEVICE.
bcdUSB
The version number of the USB Specification for which the device is compliant, in binary-coded decimal form. For example, version 2.10 is represented as 0x210.
bDeviceClass
A device class code. Device class codes are assigned by the USB working group. If this field is 0 each of the USB device's interfaces within a configuration specifies its own class information. The interfaces act independently. If this field is between 0x01 and 0xFE inclusive, the USB device supports different device classes on different interfaces; this field represents the aggregate of all the interfaces, and the interfaces may not act independently. The bDeviceClass value 0xFF is vendor specific.
bDeviceSubClass
A device subclass code. Device subclass codes are assigned by the USB working group. The meaning of the value in this field depends on the value in the bDeviceClass member. If bDeviceClass is reset to 0, bDeviceSubClass must also be reset to 0.
bDeviceProtocol
A protocol code. Protocol codes are assigned by the USB working group. The meaning of the value in this field depends on the values in the bDeviceClass and bDeviceSubClass fields. The value 0xFF indicates a vendor-specific protocol.
bMaxPacketSize0
The maximum packet size allowed for endpoint 0. Only the values 8, 16, 32, and 64 are valid.
idVendor
A vendor identifier. Vendor identifiers are assigned by the USB working group.
idProduct
A product identifier. Product identifiers are assigned by manufacturers.
bcdDevice
The USB device's release number, in binary-coded decimal format.
iManufacturer
Index of a string descriptor describing the manufacturer.
iSerialNumber
Index of a string descriptor containing the USB device's serial number.
bNumConfigurations
The number of possible configurations for the USB device.

Remarks

This structure is defined in the Universal Serial Bus Specification, revision 1.1.
