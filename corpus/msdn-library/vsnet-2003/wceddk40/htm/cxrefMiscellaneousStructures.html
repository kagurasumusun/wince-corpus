Miscellaneous Structures

The following table shows the miscellaneous structures and their corresponding descriptions.

Structure Description
DDHAL_GETAVAILDRIVERMEMORYDATA Contains memory information for the specified surface type.
DDHAL_GETHEAPALIGNMENTDATA Contains data on required alignments from a particular heap.
DDHAL_UPDATENONLOCALHEAPDATA Contains the heap information required by the UpdateNonLocalHeap callback.
