Linear Flash Memory Device Detection

At startup time or when a linear flash memory device is inserted, the Device Manager calls the DetectTFFSDisk function, which the TrueFFS/CE driver exposes. The detection function attempts to recognize the type of linear flash memory hardware that is present by querying the device. If the media type is detected, the Device Manager loads the TrueFFS/CE driver into memory. This detection-and-load process is standard procedure not only for the TrueFFS/CE driver, but also for all stream interface drivers. However, the detection function of the TrueFFS/CE driver is unique among other driver functions for PC Card devices because the function attempts to recognize media without using the information in the card information structure (CIS) of the PC Card device.

By querying the linear flash memory hardware directly to detect the type of linear flash memory device, the TrueFFS/CE driver is able to detect Compact Flash Interface (CFI)-compliant devices, such as the Strata-based linear flash memory device. CFI is a specification for providing size and formatting information for linear flash memory devices directly on the devices so that drivers such as TrueFFS/CE can be forward compatible with newer hardware. You must set up the registry on your platform so that the Device Manager calls DetectTFFSDisk when a linear flash memory card is inserted.
