Controlling Multisampling

Two render states control multisample rendering.

D3DRS_MULTISAMPLEANTIALIAS

A BOOL value that determines how individual samples are computed when using a multisample render target buffer. When set to TRUE, the multiple samples are computed so that full-scene antialiasing is performed by sampling at different sample positions for each multiple sample. When set to FALSE, the multiple samples are all written with the same sample value (sampled at the pixel center), which allows nonantialiased rendering to a multisample buffer. This render state has no effect when rendering to a single sample buffer. The default value is TRUE.

See the DirectX 8.0 SDK documentation for more details.

D3DRS_MULTISAMPLEMASK

Each bit in this mask, starting at the LSB, controls modification of one of the samples in a multisample render target. Thus, for an 8-sample render target, the low byte contains the 8 write enables for each of the 8 samples. This render state has no effect when rendering to a single sample buffer. The default value is 0xFFFFFFFF.

This render state enables use of a multisample buffer as an accumulation buffer, doing multi-pass rendering of geometry where each pass updates a subset of samples. See the DirectX 8.0 SDK documentation for more details.
