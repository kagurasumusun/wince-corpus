Serial Port Driver Samples

You have the option of staying with the old serial port design, or switching to the new one. To use the new design, you must modify two build variables. The TARGETLIBS variable must list the Com_mdd_ex.lib library instead of Com_mdd.lib, and you must add the string "-DUSE_NEW_SERIAL_MODEL" to the CDEFINES variable in the SOURCES file. In the lower layer, the HWTxIntrHandler function must map to the SL_TxIntrEx function instead of SL_TxIntr, for backward compatibility. See the Com16650 sample driver.
