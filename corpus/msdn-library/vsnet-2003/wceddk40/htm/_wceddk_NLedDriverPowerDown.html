NLedDriverPowerDown

This function sends a power status change notification to the LED devices.

VOID NLedDriverPowerDown(
BOOL power_down 
);

Parameters

power_down
[in] TRUE indicates power is turning off. FALSE indicates power is turning on.

Return Values

None.

Remarks

This function can take action as appropriate for the LED devices, such as turning them off.

Implement this GWES function as part of porting device drivers.

The NLedDriverPowerDown function sends a power status change notification to the LED devices. The following code example shows an implementation of NLedDriverPowerDown for a platform with no LEDs.

VOID WINAPI
NLedDriverPowerDown(
                   BOOL power_down
                   )
{
    return;
}

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Led_drvr.h
