HWOpen

This function is called by the upper layer to open the serial device.

BOOL HWOpen(
PVOID pContext 
);

Parameters

pContext
[in] Pointer to a context structure returned by the HWInit function that contains implementation-specific data describing the hardware device.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This function applies power to the serial hardware. This function is part of the implementation of the lower layers of the serial port drivers.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Serhw.h
