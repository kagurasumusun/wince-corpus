NDIS Features in Windows CE

Microsoft® Windows® CE .NET OS supports NDIS 5.1 and includes many features that improve support for network driver development.

The following table shows NDIS features that are available in Windows CE .NET.

Feature Description
Packet send cancellation New APIs for NDIS protocols allow pending packets to be cancelled, and introduce an additional handler that notifies NDIS miniports of packet cancellations.
Hardware offloading Object identifiers for TCP/IP transport task offloading to a network interface card (NIC).
Wireless WAN Support Object identifiers for supporting wireless WAN miniport drivers.
Signal strength Object identifiers for requesting the strength of the signal in decibels that the miniport driver's NIC receives and for setting a signal strength threshold.
64-bit counters Larger 64-bit statistical counters provide sustained high-speed throughput.
MediaSense An interface for monitoring media state.
Wake on LAN Object identifiers for defining a wakeup packet to the NIC hardware.
Deserialize miniport The ability for miniport drivers to handle synchronization internally.
Packet stacking Access to packet descriptors in a stack of layered NDIS drivers improves performance. Earlier versions of NDIS required intermediate drivers to allocate a new NDIS_PACKET to encapsulate send and receive data that they passed on to other layers.
Machine name notification NDIS can now pass the machine name down to the miniport driver.
Power management Object identifiers for supporting power management features.
