USB Serial Host Driver

To enable USB connectivity, the desktop computer also needs a USB driver that enables communication with the device through a USB connection. This driver is available in Microsoft® Platform Builder, and is called USB Serial Host driver, WCEUSBSH.SYS. Note that this driver is not for use on Windows CE-based platforms. It is the desktop software required to enable USB connectivity between desktop computers and Windows CE-based platforms. Microsoft® ActiveSync® version 3.5 installs this driver on desktop computers. The main task of the USB Serial Host driver is to expose the standard Win32 serial interface to the upper-level application, such as ActiveSync, so that the application can use the USB connection as if it were a standard serial port connection.

If your platform uses ActiveSync to connect to desktop computers, you do not need to do anything else to enable USB connectivity. However, if your platform does not use ActiveSync, but requires USB connectivity, then you must provide the USB Serial Host Driver to your customers. Typically, you provide a setup application to customers that installs the necessary desktop connectivity components, including this driver and an appropriate .INF file.

The installation procedure for the USB Serial Host driver is no different than installing any other driver on your desktop computer.
