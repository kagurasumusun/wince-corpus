Copying Vertex and Index Buffers in the DP2 Stream

A new DP2 token, D3DDP2OP_BUFFERBLT, has been added to support optimal copying and updating of index and vertex buffers. This token is very similar to the existing D3DDP2OP_TEXBLT which copies and updates textures but has been modified to support sub-buffer copying rather than simple rectangles.
