Enabling Built-in Linear Flash on the Hitachi SH7729 HARP SDB

The Hitachi SH7729 HARP SDB has 32 MB of IntelStrata flash that you can use for the boot loader, OS image, storage, or persistent storage. There is a 512K region reserved for the boot loader program starting at physical address 0. The remaining 31.5 MB region is available for persistent storage.

  1. Near the IntelStrata flash on the main board, open jumper 14 (jmp14).

    This jumper allows writing to the system flash.

  2. Set the DIP switch S1 as shown in the following table.
    S1-1 S1-2 S1-3 S1-4 Description
    X X Off X System flash writing enabled.
    X X On X Flash is write protected.
