AddAttachedSurface

This callback function attaches a surface to another surface. 

DWORD __stdcall AddAttachedSurface(
LPDDHAL_ADDATTACHEDSURFACEDATA   paasd 
);

Parameters

paasd
[in/out] Pointer to a DDHAL_ADDATTACHEDSURFACEDATA structure that contains information required for the driver to attach a surface to another surface.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 and later. Version 2.12 requires DXPAK 1.0 or later. Ddrawi.h
