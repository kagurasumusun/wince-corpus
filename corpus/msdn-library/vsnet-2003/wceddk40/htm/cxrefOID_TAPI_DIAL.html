OID_TAPI_DIAL

The OID_TAPI_DIAL object requests the miniport driver to dial the specified number on the specified call.

Support for this request is optional.

This request uses an NDIS_TAPI_DIAL structure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Ndistapi.h Ntddndis.h and Ndistapi.h
