PCI Bus Enumerator Registry Settings

Windows CE supports a PCI bus enumerator that detects any device located on the PCI bus. After detecting the device, the PCI bus enumerator assigns all necessary resources to the device and informs the appropriate driver that the device is present. You can use the PCI bus enumerator to simplify the work necessary to develop and configure an NDIS miniport driver on Windows CE.

The following topics discuss these registry settings in detail:

  • PCI Bus Enumerator Template
  • Installable ISR Registry Settings
  • Miniport Driver Registry Entry
  • NIC Instance Specific Registry Settings
