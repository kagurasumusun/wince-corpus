SetColorKey

This callback function sets the color key value for the specified surface. 

DWORD __stdcall SetColorKey(
LPDDHAL_SETCOLORKEYDATA   psckd 
);

Parameters

psckd
[in/out] Pointer to a DDHAL_SETCOLORKEYDATA structure that contains the information necessary to set the color key value for the specified surface.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
  • DDHAL_DRIVER_NOCKEYHW

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 and later. Version 2.12 requires DXPAK 1.0 or later. Ddrawi.h
