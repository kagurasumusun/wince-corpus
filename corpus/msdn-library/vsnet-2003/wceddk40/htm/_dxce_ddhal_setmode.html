SetMode

This function is not currently used on Windows CE.

The SetMode callback function sets the display mode. 

DWORD __stdcall SetMode(
LPDDHAL_SETMODEDATA   psmd 
);

Parameters

psmd
[in/out] Pointer to a DDHAL_SETMODEDATA structure that contains the information required to set the display mode.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
