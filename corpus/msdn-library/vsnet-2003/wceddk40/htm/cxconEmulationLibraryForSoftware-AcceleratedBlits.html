Emulation Library for Software-Accelerated Blits

Sample code for creating an emulation library for software-accelerated blits is in %_WINCEROOT%\Public\Common\OAK\Drivers\Display\Emul. The library contains emulated blit functions with destination pixel depths of 2, 8, and 16 bits per pixel. You can use the emulated blits to improve performance over the default blit processing provided in the GPE. Of particular interest to embedded system developers is that the source code can serve as a template for writing additional software-accelerated blits that are tailored to the display hardware.
