Display Drivers

The display device driver interface (DDI) is a subset of the Microsoft® Windows NT® DDI. The Microsoft Windows® CE .NET operating system (OS) uses only the basic graphics engine functions and driver functions from the Windows NT display DDI. The following list shows the differences between display drivers based on Windows CE and Windows NT:

  • Windows CE–based display drivers always present the same functionality; therefore, the graphics device interface (GDI) does not query a driver for information about its capabilities.
  • Windows CE–based display drivers cannot reject an operation as too complex, and then call back into GDI to have the operation broken into simpler primitives. Because all Windows CE–based display drivers support the same functionality, the GDI breaks up complex operations before calling the display driver.
  • Windows CE–based display drivers are compiled as user-mode dynamic-link libraries (DLLs).

Display drivers on Windows CE are implemented similarly to display drivers on Windows NT. For more information, see the Microsoft Windows 2000 Driver Development Kit (DDK).
