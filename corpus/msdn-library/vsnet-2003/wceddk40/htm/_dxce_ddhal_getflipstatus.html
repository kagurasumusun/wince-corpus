GetFlipStatus

This callback function indicates whether the surface has finished its flipping process. 

DWORD __stdcall GetFlipStatus(
LPDDHAL_GETFLIPSTATUSDATA   pgfsd 
);

Parameters

pgfsd
[in/out] Pointer to a DDHAL_GETFLIPSTATUSDATA structure that contains information necessary to determine whether a previous flip has finished and the current flip can proceed.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
  • DDERR_CURRENTLYNOTAVAIL

Remarks

An example implementation of this callback function (GetFlipStatus32) can be found in the IGS sample driver source code.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 and later. Version 2.12 requires DXPAK 1.0 or later. Ddrawi.h
