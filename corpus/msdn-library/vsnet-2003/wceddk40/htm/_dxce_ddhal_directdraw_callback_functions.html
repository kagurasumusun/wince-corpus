DirectDraw Callback Functions

The following table shows the Microsoft® DirectDraw® callback functions with their corresponding descriptions.

Function Description
CanCreateSurface Indicates whether a surface can be created.
CreatePalette Creates a DirectDrawPalette object for the DirectDraw object.
CreateSurface Creates a DirectDrawSurface object for the DirectDraw object.
DestroyDriver Destroys a DirectDraw driver.
FlipToGDISurface Makes the surface to which the graphics device interface (GDI) writes the primary surface.
GetScanLine Gets the current scan line.
SetColorKey Sets the color key value for the specified surface.
SetExclusiveMode Sets a DirectDraw object to exclusive mode.
SetMode Sets the display mode.
WaitForVerticalBlank Helps the application synchronize itself with the vertical blanking interval (VBI).
