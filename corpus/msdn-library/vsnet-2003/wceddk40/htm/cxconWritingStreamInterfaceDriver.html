Stream Interface Driver Implementation

The following topics explain the issues that affect your design decisions as you implement a stream interface driver dynamic-link library (DLL). Topics discuss how to create a DLL containing the required entry points for stream interface drivers and how to regulate either single access or multiple access to a driver.
