DrvDisableSurface

This function is used by the graphics device interface (GDI) to notify a driver that the surface created by the DrvEnableSurface function for the current device is no longer needed.

VOID DrvDisableSurface(
IN DHPDEV dhpdev 
);

Parameters

dhpdev
[in] Handle to the PDEV structure that describes the physical device whose surface is to be released.

Return Values

None.

Remarks

The driver should free any memory and resources used by the surface associated with PDEV as soon as the physical device is disabled.

If the physical device has an enabled surface, the GDI calls this function before calling DrvDisablePDEV.

This function is required for graphics drivers.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Winddi.h
