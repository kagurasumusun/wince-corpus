DdsiTouchPanelSetMode

This function sets information about the touch screen device.

BOOL DdsiTouchPanelSetMode(
ULONG iIndex,
LPVOID lpInput 
);

Parameters

iIndex
[in] Specifies the mode to set. The following table shows the modes you can set.
Value Description
TPSM_SAMPLERATE_HIGH_ID Sets the sample rate to the high rate.
TPSM_SAMPLERATE_LOW_ID Sets the sample rate to the low rate.
lpInput
[out] Pointer to one or more memory locations where the update information resides. Points to one or more memory locations where the queried information should be placed.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This function supports the implementation of the touch screen driver.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Tchddsi.h
