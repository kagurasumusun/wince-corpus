NDIS Driver Implementation Guide

You can create a customized miniport driver for a Windows CE–based platform by following the steps that are provided in the Windows CE .NET Driver Development documentation on how to write a miniport driver. Because Windows CE does not require backward compatibility with legacy drivers, it does not support full network interface card (NIC) drivers or monolithic network drivers.

The following list shows the key features of NDIS support for Windows CE–based platforms:

  • Portability of drivers between platforms that support NDIS
  • Network adapter miniport driver support
  • Support for intermediate (including layered) and upper-level drivers
  • Support for Ethernet (802.3), Token Ring (802.5), and IrDA medium types
  • Support for the wide area network (WAN) medium type
  • Support for ISA, PCI, and PC Card devices
  • Dynamic binding of adapters, and support for Plug and Play
  • Support for multiple network adapters that are bound to the same protocol
