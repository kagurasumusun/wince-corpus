VVCR_Complete_Request

This structure identifies the request made, and permits the virtual VCR driver to complete the appropriate request.

typedef struct {
PVOID vvcr_RequestIdentifier;
BOOL vvcr_Status;
} VVCR_Complete_Request;

Members

vvcr_RequestIdentifier
A request identifier, as previously returned in the response structure of an IOCTL_VVCR_EVENT request. This identifier uniquely identifies the request made, and permits the virtual VCR driver to complete the appropriate request.
vvcr_Status
A Boolean that defines whether the application wishes to convey that it successfully completed the given request, or whether it wishes to convey that the request was not successfully completed.
