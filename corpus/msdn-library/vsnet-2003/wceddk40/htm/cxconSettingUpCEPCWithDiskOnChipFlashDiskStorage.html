Setting Up a CEPC with DiskOnChip Flash Disk Storage

  1. Install the DiskOnChip by aligning it properly on the 32 dual in-line package (DIP) mount on-board the DiskOnChip Evaluation Board ISA card.
    Warning   Mounting the DiskOnChip incorrectly can cause irreversible damage to the flash disk.
  2. In your release directory, insert the following entries or verify that the following entries exist in the Platform.reg file. 
    [HKEY_LOCAL_MACHINE\Drivers\BuiltIn\TrueFFS] 
    "Dll" = "TrueFFS.dll" 
    "Prefix" = "DSK" 
    "Order" = dword:1 
    "WindowBase" = dword:D0000 
    "DocBase10" = dword:D8000 
    "DeviceArrayIndex"=dword:0
    "IClass" = "{A4E7EDDA-E575-4252-9D6B-4195D48BB865}"

    - or -

    Verify that these entries are under the HKEY_Local_Machine\Drivers\BuiltIn key.

    Entries in Common.reg under the HKEY_Local_Machine\Drivers\PCMCIA key are designated for the PC Card and are different.

  3. In your release directory, insert the following entries to common.reg file. 
    [HKEY_LOCAL_MACHINE\System\StorageManager\Profiles\TRUEFFS_DOC]
    "Name"="DiskOnChip M-Systems"
    "Folder"="DiskOnChip"

    - or -

    Verify that these entries are under the HKEY_Local_Machine\Drivers\BuiltIn key.

    Entries in Common.reg undter the HKEY_Local_Machine\Drivers\PCMCIA key are designated for the PC Card and are different from DiskOnChip entries.

    For specific mounting features such as AutoFormat, see Storage Manager.

  4. On the DiskOnChip Evaluation Board ISA card, configure the WindowBase address.

    The following table shows the jumper settings.

    WindowBase address JP1 1-2 JP1 3-4 JP1 5-6
    C8000 Short N.C. N.C.
    D0000 (Default) N.C. Short N.C.
    D8000 N.C. N.C. Short
  5. On the DiskOnChip Evaluation Board ISA card, configure the Window Size.

    The following table shows the jumper settings.

    Window Size JP2 1-2 JP2 2-3
    32 KB Short N.C.
    8 KB (Default) N.C. Short
  6. On the CEPC motherboard, install the DiskOnChip Evaluation Board ISA card into one of the free ISA slots.
  7. Set the environment flag SYSGEN_TRUEFFS equal to 1.
  8. Clear the BSP_NODOC environment variable.

    The previously mentioned variable introduces the required DiskOnChip registry entries into Platform.reg file. If the WindowBase address on the DiskOnChip Evaluation Board is set to an address different from the default, then change the WindowBase key from DWORD: D0000 to the new address, which is either C8000 or D8000.

  9. Create, download, and execute your image.
