D3dCreateSurfaceEx and Backing Surfaces

D3dCreateSurfaceEx is also called for backing surfaces. This allows the driver to allocate a driver-side structure for the surface and thus respond to the D3DDP2OP_TEXBLT token for a system to video texture download.

It is very important that the driver not fail D3dCreateSurfaceEx for backing surface formats for which it does not support the pixel format. Such surfaces may be created for use with the software rasterizer. The driver should simply ignore backing surfaces it does not support. (Alternatively, the driver can create a driver-side structure, but the corresponding handle will never subsequently be sent to the driver.) Failing D3dCreateSurfaceEx for these surfaces will cause a failure code to be propagated to the application and the driver can potentially affect an emulation-only application.
