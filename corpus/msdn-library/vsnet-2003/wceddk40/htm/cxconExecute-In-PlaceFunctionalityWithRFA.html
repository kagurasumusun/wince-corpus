Execute-In-Place Functionality with RFA

Execute in place (XIP) is the ability to run a program directly from flash memory instead of copying the program into RAM memory and running it from there. To support XIP, a flash device must be linear so it can be mapped into a memory window and read directly through the window as if the flash memory were RAM or ROM. Certain flash devices have this linear interface and support direct code execution from the flash chips. ATA products do not support XIP because they contain a micro-controller chip that performs disk emulation, which prevents direct access to the flash memory components.

Implementing XIP from a built-in flash device such as RFA does not require use of a file system or block driver. The file system is only required to access flash memory as a random-access storage device. You can implement XIP if your platform provides built-in flash memory such as RFA. Due to the nature of flash memory, sharing both XIP and data storage is very problematic and requires sophisticated software solutions or specialized flash memory. You can have multiple XIP address spaces.
