DDGPE Base Classes

The DirectDraw Graphics Primitive Engine (DDGPE) base classes can be used to extend the GPE classes to support DirectDraw. You will be using several of the methods very often in the implementation of the DirectDraw HAL portion of your display driver, so it is important that you familiarize yourself with the information in topics related to the DDGPE base classes.

The following table lists the DDGPE base classes.

Class Description
DDGPE Class Serves as the base class for DirectDraw display drivers.
DDGPESurf Class The representation of a surface to the display driver.
SurfaceHeap Class An alternate heap manager.

See the previous topics for more detailed descriptions of each of the functions.
