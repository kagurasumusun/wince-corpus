KeybdDriverSetMode

This function sets mode information for the keyboard device.

BOOL KeybdDriverSetMode(
INT iKeybdId,
INT iIndex,
LPVOID lpInput 
);

Parameters

iKeybdId
[in] Identifier of the keyboard for which to set the information.
iIndex
[in] Set to the KBDI_AUTOREPEAT_INFO_ID identifier to retrieve keyboard auto repeat information.
lpInput
[in] Pointer to an input buffer. The format of the buffer is controlled by iIndex.

Return Values

TRUE indicates success. FALSE indicates failure. Extended error information is available through GetLastError.

Remarks

If iIndex is KBDI_AUTOREPEAT_INFO_ID, lpInput must point to a KBDI_AUTOREPEAT_INFO structure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Keybddr.h

GetLastError, KeybdDriverGetInfo
