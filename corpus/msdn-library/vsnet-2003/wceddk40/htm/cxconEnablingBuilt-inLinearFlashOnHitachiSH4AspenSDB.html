Enabling Built-in Linear Flash on the Hitachi SH7750 HARP SDB

The Hitachi SH7750 HARP SDB has 32 MB of IntelStrata flash that you can use for the boot loader, OS image, storage, or persistent storage.

  1. Add WRITE_REGISTER_ULONG(0xA4040000, READ_REGISTER_ULONG(0xA4040000) | 1); to OEMInit in %_WINCEROOT%\Platform\ASPEN\KERNEL\HAL\CFW.C as shown in the following code example. 
    void OEMInit(){
WRITE_REGISTER_ULONG(0xA4040000, READ_REGISTER_ULONG(0xA4040000) | 1); // FLASH write protect off
}
  2. Set DIP switch S1 as shown in the following table.
    S1-1 S1-2 S1-3 S1-4 Description
    X X Off X System flash writing enabled.
    X X On X Flash is write protected.
