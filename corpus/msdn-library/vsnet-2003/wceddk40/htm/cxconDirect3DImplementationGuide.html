Direct3D Implementation Guide

The following topics contain practical information about creating a Windows CE–based Direct3D driver:

  • Direct3D Implementation Requirements provides detailed descriptions about implementing a particular feature in the driver.
  • Direct3D Driver Callbacks and Functions contains information about the callbacks that make up the Direct3D DDI.
  • Direct3D Driver Initialization lists the steps necessary for the driver to indicate its Direct3D capabilities.
  • Cross Platform Direct3D Driver Development contains information regarding cross platform Direct3D driver development.
  • Direct3D Core Functionality contains information about the features that are central to implementing core functionality in a Direct3D driver.
  • Advanced Direct3D Driver Topics describes Direct3D specialty topics and optimizations.
  • DirectX 8.0 DDI Support discusses features that are supported by the DirectX 8.0 DDI.
  • Direct3D Driver Resources describes the different header files that you should reference when developing a Direct3D driver.

For more details on the Direct3D architecture, see Direct3D Architecture.
