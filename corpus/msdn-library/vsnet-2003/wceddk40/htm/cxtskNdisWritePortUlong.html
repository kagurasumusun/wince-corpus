NdisWritePortUlong

The NIC driver calls this function to write a ULONG to an I/O port.

VOID NdisWritePortUlong(
IN NDIS_HANDLE  NdisAdapterHandle,
IN ULONG   Port,
IN ULONG   Data
);

Parameters

NdisAdapterHandle
Specifies the handle that the NDIS interface library associates with the network interface card.
Port
Specifies the I/O port.
Data
Specifies the ULONG value to write to Port.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Ndis.h Ndis.h
