Notification LED Drivers

A notification LED driver handles turning on and off the notification LED on the hardware platform. You can use the notification subsystem APIs to implement PUN_LED notifications if you customize %_WINCEROOT%\Public\Common\OAK\Notify\Notifext.cxx for your platform. For more information on the notification subsystem, see Implementing Notifications.

The following table shows the notification LED driver functions you must implement.

Function Description
NLedDriverGetDeviceInfo Returns information about the notification LED device.
NLedDriverInitialize Initializes the notification LED.
NLedDriverPowerDown Sends a power status change notification to the LED devices.
NLedDriverSetDevice Changes the setting of the notification LED.

The following table shows the GWES functions that are pass through functions to the notification LED driver functions.

Function Description
NLedGetDeviceInfo A pass through function to NLedDriverGetDeviceInfo.
NLedSetDevice A pass through function to NLedDriverSetDevice.
