DDGPESurf::SetDirectDrawSurface

This method associates the given DirectDraw surface with the current DDGPESurf object.

virtual void SetDirectDrawSurface(
LPDDRAWI_DDRAWSURFACE_LCL   lpDDSurface 
);

Parameters

lpDDSurface
A pointer to an existing DirectDraw surface. The DirectDraw surface will be associated with the current GPE surface. Any existing DirectDraw surface associated with this surface will be replaced. The driver is responsible for management of surfaces replaced in this manner.

Return Values

The return value is S_OK if the method is successful. Otherwise, an error code is returned.

Remarks

You would use this method to associate a known DirectDraw surface with a known DDGPESurf object, after setting up each of them to be complete surfaces referencing bits at the same memory location. This method merely associates the two structures and does nothing to adjust memory locations or any other elements of either structure.
