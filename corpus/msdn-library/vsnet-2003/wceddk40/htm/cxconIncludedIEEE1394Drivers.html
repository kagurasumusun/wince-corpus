IEEE 1394 Drivers

The following table shows the included IEEE 1394 drivers.

IEEE 1394 driver Description DLL or executable Library Sysgen, built into the BSP, linked in the BSP or driver Source directory
Audio Video Control (AV/C) Protocol The "shared" components for the AV/C protocols of the IEEE 1394 stack. These components are required for supporting any audio/video interfaces on the platform. avc.dll     No sources
AV/C VCR Subunit Driver Sample driver for supporting (or being a client to) an IEEE 1394 AV/C VCR or Tape Recorder subunit on the 1394 bus avc_vcr.dll avc_vcr.lib Sysgen Common\Oak\Drivers\1394\Drivers\Client\avc_vcr
AV/C VCR Virtual Subunit Driver Sample virtual driver for exporting an IEEE 1394 VCR Subunit – for example, to emulate that functionality on the IEEE 1394 bus avc_vvcr.dll avc_vvcr.lib Sysgen Common\Oak\Drivers\1394\Drivers\Virtual\avc_vvcr
AV/C Streaming Filter Driver Optional filter driver that is needed by the IEEE 1394 AV/C VCR Subunit and any virtual Subunit drivers. avc_stream.dll avc_stream.lib Sysgen Common\Oak\Drivers\1394\Drivers\Client\avc_stream
AV/C Virtual Subunit Core The "shared" components for supporting AV/C Virtual subunit devices on the platform. For ex, if there are eight Virtual Subunits on the platform, they will need this core component avc_unit.dll avc_unit.lib Sysgen Common\Oak\Drivers\1394\Drivers\Virtual\avc_unit
Non-AV/C Web Camera Driver Sample driver for supporting (or being a client to) a IEEE 1394 digital web camera subunit on the 1394 bus 1394dcam.dll 1394dcam.lib Sysgen Common\Oak\Drivers\1394\Drivers\Client\1394dcam
Non-AV/C Web Camera Virtual Driver Sample virtual driver for exporting an IEEE 1394 digital web camera Subunit – for example to emulate the videoconferencing camera functionality on the IEEE 1394 bus virtdcam.dll virtdcam.lib Sysgen Common\Oak\Drivers\1394\Drivers\Virtual\1394dcam
Serial Bus Protocol 2 (SBP-2) The "shared" components of the IEEE 1394 stack for supporting any "computer peripheral" type of 1394 devices sbp2.dll     No sources
SBP-2 Storage Driver Sample driver for supporting any IEEE 1394 SCSI block devices (ie storage devices). scsiblk.dll     No sources
Tools & Diagnostics         Common\Oak\Drivers\1394

Device Enumeration Module Enumerates 1394 devices on the 1394 bus setupapi.dll   linked No sources
1394 WDM Layer Driver Module WDM Layer for the 1394 stack wdmlib.dll   linked No sources
1394 Bus Level Driver 1394 Bus Layer Driver 1394bus.dll   linked No sources
1394 OHCD Driver Module OHCD Driver module for the 1394 driver stack 1394ohcd.dll   linked Common\Oak\Drivers\1394\Drivers\oemohci
PCI to 1394 Driver Module PCI Layer of the 1394 Driver Stack cewdmmgr.dll   linked No sources
61883 Client Driver Module 61883 Layer of the 1394 Driver Stack 61883.dll   linked No sources
Diagnostics Virtual Driver A virtual version of the diagnostic test program 1394vdev.dll 1394vdev.lib linked Common\Oak\Drivers\1394\Test\Driver\1394vdev
1394 Topology Map Test Program A Topology test program for 1394 networks topomap.exe   linked Common\Oak\Drivers\1394\Test\Ui\topomap
