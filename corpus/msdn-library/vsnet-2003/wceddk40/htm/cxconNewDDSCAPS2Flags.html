New DDSCAPS2 Flags

A new flag, DDSCAPS2_DISCARDBACKBUFFER, has been introduced to indicate that preservation of the back buffer is not required. It will be set on the primary surface and the back buffers if the application has set D3DSWAPEFFECT_DISCARD on the Present API.

DX8 runtimes now set another new flag, DDSCAPS2_NOTUSERLOCKABLE, on the primary and the back buffers if the flipping chain is not lockable, or on any render target that is not lockable. This allows drivers to do behind the scenes optimization. Note that it is still possible to lock the surfaces so the driver will need to handle these cases, but such locks will be very infrequent and are not expected to be fast.
