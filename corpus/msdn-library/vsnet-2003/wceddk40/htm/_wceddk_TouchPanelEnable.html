TouchPanelEnable

This function enables and re-enables the touch screen.

BOOL TouchPanelEnable(
PFN_TOUCH_PANEL_CALLBACK pfnCallback
);

Parameters

pfnCallback
[in] A pointer to a touch screen callback function that will be called to handle pen events.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

After this function returns, the touch screen generates pen events.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Tchddi.h
