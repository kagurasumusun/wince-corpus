%_WINCEROOT%\Public\Common\OAK\Drivers\Keybd contains translation libraries for standard 101-key multifunction keyboards. It also builds hardware interface libraries for the PS/2 8042 keyboard controller and a null, no hardware keyboard controller. All of the sample platforms use keyboard drivers based on MDD code in %_WINCEROOT_%\Public\Common\OAK\Drivers\Keybd. All of the sample platforms support AT keyboards. The following table shows the five libraries that link to build the driver.

Library Description
Keyboard controller interface Very hardware platform specific.
Interrupt service thread Can be used on most platforms.
Scancode to virtual key mapping Different combinations of the scancode to virtual key, virtual key to character, and virtual key remap libraries create all varieties of international keyboards.
Virtual key to character mapping Different combinations of the scancode to virtual key, virtual key to character, and virtual key remap libraries create all varieties of international keyboards.
Virtual key remapping Different combinations of the scancode to virtual key, virtual key to character, and virtual key remap libraries create all varieties of international keyboards.

Virtual key remapping is required on platforms that do not have a physical keyboard. Virtual key remapping generates virtual keys based on the state of particular physical keys and modifiers such as SHIFT, ALT, and so on.

Some platforms use the PS/2 keyboard controller, which links during Sysgen. Some platforms use controller-specific code that is in their Platform or CSP directories.

Sample code for keyboard drivers is provided in the following directories:

  • %_WINCEROOT%\Platform\ARMINTEGRATOR\Drivers\KBDMOUSE
  • %_WINCEROOT%\Platform\ASPEN\Drivers\KEYMSE2
  • %_WINCEROOT%\Platform\EAGLE\Drivers\PS2KBDMOUSE
  • %_WINCEROOT%\Platform\EMULATOR\Drivers\KBDMOUSE
  • %_WINCEROOT%\Platform\KEYWEST\Drivers\KEYMSE2
  • %_WINCEROOT%\Platform\SA11X0BD\Drivers\KBDMOUSE
  • %_WINCEROOT%\Public\Common\Oak\Drivers\Keybd

%_WINCEROOT%\Public\Common\Oak\Drivers\Keybd is a layered driver. This driver generates virtual keys based on the state of particular physical keys and modifier keys such as SHIFT, ALT, and so on. This driver also shows how to remap virtual keys. The virtual key remapping handles the case where the NUMLOCK key is engaged while a SHIFT key and a numeric keypad key are pressed. When this happens, key presses on the numeric keypad should behave as if the NUMLOCK key is not active. For example, the 8 keypad key should generate a cursor up key event.
