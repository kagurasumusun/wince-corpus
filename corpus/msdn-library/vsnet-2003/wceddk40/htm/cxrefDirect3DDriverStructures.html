Direct3D Driver Structures

This topic is divided into two main groupings: the first grouping consists of the D3DHAL_XXX structures defined in D3dnthal.h on the Microsoft® Windows NT® operating system (OS), and D3dhal.h on Microsoft Windows CE .NET OS; the second grouping consists of the remaining structures, including device description structures and other Microsoft Direct3D® structures defined in D3dcaps.h and D3dtypes.h. DDHAL Resources lists the include files that contain Direct3D structure definitions.

Direct3D callbacks and their parameter structures are described in Direct3D Driver Functions. Additional information for writing a Direct3D driver can be found in Direct3D Device Driver Interface.

The Direct3D driver structures are divided into the following main topics:

  • D3DNTHAL_XXX Structures contains all the Direct3D driver structures whose names have the form D3DNTHAL_XXX.
  • D3DHAL_XXX Structures contains all the Direct3D driver structures whose names have the form D3DHAL_XXX.
  • Structures Associated with Direct3D Callback Functions lists the structures related to the callback functions.
  • Other Direct3D Driver Structures contains all the structures that do not begin with D3DHAL_.
