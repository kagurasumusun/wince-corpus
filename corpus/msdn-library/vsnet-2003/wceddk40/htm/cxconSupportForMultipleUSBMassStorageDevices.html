Support for Multiple USB Mass Storage Devices

The USB Storage class driver can support multiple USB storage devices connected to the Windows CE system. Because the storage driver is a stream interface driver, you will be limited to connecting only 10 devices at a time, which is the limitation of the stream interface naming convention.
