USB Pipe Functions

The following table shows the pipe functions that open and close communication channels between a USB device driver and a USB device.

Function Description
AbortPipeTransfers Aborts all transfers on an open USB pipe.
ClosePipe Closes an open pipe handle.
IsDefaultPipeHalted Deprecated. It always returns FALSE because the default pipe never halts.
IsPipeHalted Checks if a USB pipe is in a halted state.
OpenPipe Opens a pipe for communication with a USB device.
ResetDefaultPipe Resets the default pipe to a USB device.
ResetPipe Resets an open USB pipe.
