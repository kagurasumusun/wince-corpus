IOCTL_SMARTCARD_CANCEL_BLOCKING

This code cancels any calls to the smart card reader driver's XXX_IOControl call that are blocking, such as IOCTL_SMARTCARD_IS_ABSENT and IOCTL_SMARTCARD_IS_PRESENT.

Parameters

dwOpenData
[in] Handle returned from a call to the smart card reader driver's XXX_Open function.
dwCode
[in] Specifies this code.
pBufIn
Ignored.
dwLenIn
Ignored.
pBufOut
Ignored.
dwLenOut
Ignored.
pdwActualOut
Ignored.

Return Values

The status value STATUS_SUCCESS.

Requirements

Runs on Versions Defined in Include Link to
Microsoft® Windows® CE OS 3.0 and later Winsmcrd.h Winsmcrd.h  

See Also
