OID_802_11_INFRASTRUCTURE_MODE

This object identifier when set, requests the miniport driver to set the 802.11 NIC's infrastructure mode to a specified value. The infrastructure mode determines how the 802.11 NIC connects to the network. Setting the infrastructure mode resets the network association algorithm.

When queried, this OID requests the miniport driver to return the 802.11 NIC's infrastructure mode setting.
