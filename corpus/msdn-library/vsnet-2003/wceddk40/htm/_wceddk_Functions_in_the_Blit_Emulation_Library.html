Functions in the BitBlT Emulation Library

The emulation library includes the following functions. You can add additional functions, if necessary. Source code is in %_WINCEROOT%\Public\Common\Oak\Drivers\Display\Emul.

EmulatedBltAlphaText02
Special-case fast blit function for rendering antialiased text. This function assumes a mask surface containing the 4-bpp alpha bitmap for the glyph.
File name ROP Source bit depth Target bit depth
Ebalph02.cpp AAF0 – 02
EmulatedBltAlphaText08
Special-case fast blit function for rendering antialiased text. This function assumes a mask surface containing the 4-bpp alpha bitmap for the glyph and an 8BPP target surface that is in 32-bit RGB mode.
File name ROP Source bit depth Target bit depth
Ebalph02.cpp AAF0 – 08 (332 mode only)
