Smart Card Driver Registry Settings

Each device driver needs several entries in the registry to make the driver visible to the Device Manager and to enable event logging. The following table shows the values drivers need to have in the registry under HKEY_LOCAL_MACHINE\System\CurrentControlSet\Services\SmartCardDriver.

Subkey Value Description
Start DWORD:0x0000002 A value of 2 makes the driver start automatically. During development, it is recommended to use a Start value of 3, which forces the driver to start manually.
Type DWORD:0x0000001 A value of 1 identifies the driver as a kernel-mode driver.
Group "Smart Card Reader" Every driver has to be a member of the Group "Smart Card Reader", because the Smart Card Resource Manager waits for this group to start.
ErrorControl DWORD:0x0000001 A value of 1 lets the system continue to boot even if the driver fails, but it shows an error message if the driver fails to load.

The following is a sample Smart Card registry key.

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\SmartCard]
    "Prefix"="SCA"
    "Dll"="scard.dll"
    "Index"=dword:1
    "Order"=dword:1
