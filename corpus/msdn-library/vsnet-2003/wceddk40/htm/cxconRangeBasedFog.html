Range Based Fog

Fog can also be range-based. Range-based fog is useful because with normal z, or depth-based fog an object can appear at the side of the view, but then as the viewer rotates toward it, the object disappears back into the fog because its z-value changes. This is illustrated in the following figure. If fog is based on range instead of depth, it does not vary as the viewer rotates in place. This is compelling for flight simulators, tank games, and other applications where it is undesirable to have objects disappearing and reappearing in the distance as the viewer rotates. To set up fog to be range-based, D3DPRASTERCAPS_FOGRANGE and the D3DRENDERSTATE_RANGEFOGENABLE render state should be set. This render state works only with D3DVERTEX vertices. When the application specifies D3DLVERTEX or D3DTLVERTEX vertices, the F (fog) component of the RGBF fog value should already be corrected for range.

Range Based Fog

Note that if only fog within a specified range is visible, the viewer can rotate without objects coming in and out of the fog as with normal z or depth-based fog. That is, objects that were visible, remain visible, regardless of the rotation.
