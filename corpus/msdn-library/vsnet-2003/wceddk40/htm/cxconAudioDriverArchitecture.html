Audio Driver Architecture

The following topics discuss the audio driver architecture in more detail:

  • Unified Audio Model (UAM) contains information about the new audio architecture which unifies Wave audio and Microsoft® DirectSound® audio.
  • Audio MDD and PDD provides an alternative to using the UAM.
  • Audio Compression Manager Drivers contains information about the different Audio Compression Manager (ACM) driver types and how to develop an ACM driver.
