INQUIRY_DATA

This structure contains information on the CD-ROM device.

typedef struct _INQUIRY_DATA {
UCHAR inqDevType; 
UCHAR inqRMB; 
UCHAR inqVersion; 
UCHAR inqAtapiVersion; 
UCHAR inqLength; 
UCHAR inqReserved[3]; 
UCHAR inqVendor[8]; 
UCHAR inqProdID[16]; 
UCHAR inqRev[4]; 
UCHAR inqReserved2[60]; 
} INQUIRY_DATA, *PINQUIRY_DATA;

Members

inqDevType
Bits 5-7: Peripheral Qualifier
Bits 0-4: Device Class
inqRMB
Bit 7: Removable device
inqVersion
Bits 6-7: ISO Version
Bits 3-5: ECMA Version
Bits 0-2: ANSI Version
inqAtapiVersion
Bit 7: AEN – Asynchronous Event Notification Capability
Bit 6: TIO – Terminate I/O Process support
Bit 5: Reserved
Bit 4: Reserved
Bits 0-3: Data Format
inqLength
Additonal data length.
InqReserved[3]
Reserved.
InqVendor[8]
Manufacturer's name in ASCII.
InqProdID[16]
Product's name in ASCII.
InqRev[4]
Product's version in ASCII.
inqReserved2[60]
Reserved.

Remarks

This data structure directly corresponds to the Sense data returned by the ATA packet interface driver. More information is available in the Small Computer System Interface Specification.
