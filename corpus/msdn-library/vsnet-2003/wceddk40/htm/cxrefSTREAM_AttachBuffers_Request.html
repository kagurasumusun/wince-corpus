STREAM_AttachBuffers_Request

This structure is used by IOCTL_STREAM_ATTACH_BUFFER.

typedef struct{
    STREAM_SESSION_ID       sab_Session;
    ULONG                   sab_NumberOfBuffers;
    struct 
    {
        PVOID                   sabb_Memory;
        ULONG                   sabb_Length;
    }                       sab_Buffers[1];   
}  STREAM_AttachBuffers_Request;

Members

sab_Session
The STREAM_SESSION_ID handle obtained from a previous call using IOCTL_STREAM_START_RECV_SESSION or IOCTL_STREAM_START_XMIT_SESSION.
sab_NumberOfBuffers
The total number of buffers to attach.
sab_Buffers
This is an array of pointer-and-length pairs of the memory you want assigned for each buffer. Each index in the array refers to a different buffer, and there must be sab_NumberOfBuffers entries.
