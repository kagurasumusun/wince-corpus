Battery Drivers

The battery driver is the interface that provides information to the Graphics, Windowing, and Events Subsystem (GWES) about the power level of the main battery, backup battery, and AC power supply of a hardware platform. The battery driver builds into a library that statically links into GWES. This library implements the functions and variables declared in Battery.h.

The following table shows the battery driver functions you must implement.

Function Description
BatteryDrvrGetLevels Returns the number of levels that the battery driver is capable of returning in the BatteryFlag and BackupBatteryFlag members of the SYSTEM_POWER_STATUS_EX2 structure.
BatteryDrvrGetStatus Returns the status of the main and backup batteries.
BatteryDrvrSupportsChangeNotification Determines whether the battery driver can report when the batteries were changed.

Also, see BatteryGetLifeTimeInfo, which retrieves the time you last changed the batteries, the amount of time you have used the batteries, and the amount of time you used the batteries before you replaced them.
