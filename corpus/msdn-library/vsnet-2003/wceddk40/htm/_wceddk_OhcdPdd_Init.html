HcdPdd_Init

This function initializes a host controller interface plus any platform-specific hardware and structures.

DWORD HcdPdd_Init(
DWORD dwContext 
);

Parameters

dwContext
[in] Pointer to a string indicating the active registry key for the HC driver.

Return Values

A pointer to PDD-specific data structure indicates success. NULL indicates failure.

Remarks

This function is called at system initialization to detect and configure the host controller interface hardware. As part of the processing for this function, the HcdMdd_CreateHcdObject function is called to initialize the MDD and host controller interface hardware.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Ohcdddsi.h or Uhcdddsi.h
