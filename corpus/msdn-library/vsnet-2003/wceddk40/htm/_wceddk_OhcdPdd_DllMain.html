HcdPdd_DllMain

This function is the main DLL entry point for the PDD portion of a host controller interface driver.

BOOL HcdPdd_DllMain(
HANDLE hinstDLL,
DWORD dwReason,
LPVOID lpvReserved 
);

Parameters

hinstDLL
[in] Handle to a DLL instance.
dwReason
[in] Specifies a reason code.
lpvReserved
[in] Pointer to a system parameter.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This function enables the PDD to perform any necessary processing at DLL entry time. Generally, this function does little because most initialization is performed by the HcdPdd_Init function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Ohcdddsi.h or Uhcdddsi.h
