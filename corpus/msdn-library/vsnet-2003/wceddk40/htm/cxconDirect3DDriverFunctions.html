Direct3D Driver Functions

This topic provides you with reference pages for the callback functions and their associated structures in the Microsoft® Direct3D® driver application programming interface (API). All callback names are pseudonyms that you decide on.

Direct3D Driver Resources lists the include file that contains Direct3D function prototypes.

For general Direct3D data structure definitions, see Direct3D Driver Structures. Additional information for writing a Direct3D driver can be found in Direct3D Device Driver Interface.

The following table lists the Direct3D callback functions.

Required callback Description
D3dContextCreate Creates a context.
D3dContextDestroy Destroys a context.
D3dCreateSurfaceEx Creates an association between a texture handle and a surface. Also called to remove associations.
D3dDrawPrimitives2 Renders primitives and returns updated state to Direct3D.
D3dValidateTextureStageState Performs texture stage state validation that is required for all drivers that support texturing.
