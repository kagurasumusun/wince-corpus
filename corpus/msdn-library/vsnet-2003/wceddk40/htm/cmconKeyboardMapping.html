Keyboard Mappings

The following topics contain tables to map keyboard-hardware PC/XT scan codes to virtual-key codes and virtual-key codes to Unicode characters for several languages:

  • Virtual-Key Codes
  • Keyboard Layouts
  • Brazilian Keyboard
  • Japanese Keyboard
  • Dutch Keyboard
  • French Keyboard
  • German Keyboard
  • Italian Keyboard
  • Japanese Keyboard
  • Korean Keyboard
  • Portuguese Keyboard
  • Spanish Keyboard
  • Swedish Keyboard
  • United Kingdom Keyboard
  • United States Keyboard

Standard PS/2 controllers convert AT scan codes generated by standard keyboards into XT scan codes. Some platforms that have PS/2 compatible keyboard connectors may not have controllers that perform this translation.

Language-specific scan code translation in the sample keyboard drivers is implemented using libraries. The sample keyboard drivers combine the following libraries:

  • A keyboard controller-specific library.
  • A keyboard IST-handling library.
  • A scan code to virtual key translation library.
  • A virtual key to character translation library.
  • A virtual key remapping library.

Sample translation libraries are provided for standard US English, two types of Japanese, and one type of Korean keyboard. Mappings for both AT and XT scan code sets are included. Supporting these languages on a platform with a new type of keyboard controller requires that you write a new controller interface library, and possibly, depending on your hardware, an IST library. These new libraries can then be linked with the appropriate translation libraries to produce a complete keyboard driver DLL. More extensive customization may be necessary for custom keyboards.
