ClearType

Windows CE .NET provides support for Microsoft ClearType® fonts. ClearType display technology uses characteristics of LCDs to make electronically produced text seem less jagged and more like printed type on paper, improving the readability of the text. ClearType increases the effective screen resolution on LCDs by manipulating the red, green, and blue subpixels that make up each pixel on a color screen. By mathematically adjusting the signal from these subpixels, ClearType creates text in which the letters have smoother edges.

ClearType on Windows CE has the same functionality as the desktop operating system (OS). On the desktop OS ClearType is not supported for displays that are 8 bits per pixel (bpp) because the system palette is changeable. The same is true for Windows CE. ClearType on Windows CE is only supported on systems with display resolutions greater than 16 bpp.

ClearType on Windows CE only implements a vertical striping algorithm. When the screen is rotated, it will display ClearType using vertical striping, hence, ClearType will be available in all orientations.

ClearType does not perform well with some fonts, so it is up to you to ensure that all the fonts on the system are tested for legibility. ClearType may not work well with some TrueType fonts.

ClearType can be enabled per application or across an entire OS.

To indicate support for ClearType, be sure that GetGraphicsCaps returns GCAPS_CLEARTYPE. If the driver does not return GCAPS_CLEARTYPE, support for ClearType will not be enabled.

BltPrepare assigns the function pointers to point to the ClearType blit routines in GWES. These routines do the appropriate table lookup to pick up the color for the pixels to display on the screen. The function pointers must be set based on bpp.

Class ClearTypeBlt : public GPE
SCODE ClearTypeBltDst16 (GPEBltParms *);
SCODE ClearTypeBltDst24 (GPEBltParms *);
SCODE ClearTypeBltDst32 (GPEBltParms *);

The following functions are used with ClearType:

  • SetClearTypeBltMasks
  • SetClearTypeBltGamma

Ensure that a call to SetClearTypeBltMasks is made. In the case of a standard configuration of colors in a 16-bit color depth, use SetClearTypeBltMasks(0xf800, 0x7c0, 0x003f).

Also, ensure that a call to SetClearTypeBltGamma is made. If a parameter is not available, use DEFAULT_CT_GAMMA.
