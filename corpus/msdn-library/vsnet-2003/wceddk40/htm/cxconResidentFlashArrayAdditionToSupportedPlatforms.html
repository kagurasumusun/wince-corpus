Resident Flash Array Addition to Supported Platforms

To add linear flash memory as a built-in part of a supported platform, you can use a resident flash array (RFA). An RFA is one or more raw linear flash memory chips that are included as part of a motherboard design.

The TrueFFS driver natively supports DiskOnChip devices, but an enhancement allows it to support IntelStrata Flash (DA28F640J5) on the Hitachi SH7729 HARP SDB and the Hitachi SH7750 HARP SDB. Each platform has 16 MB of flash available for persistent storage. Additionally, the Intel Persistent Storage Manager (IPSM) works on the SA-1110/SA-1111 Development platform.

Third party software vendors, such as DataLight Inc., have developed products that work well with different types of flash and work well with Windows CE.

In order for the TrueFFS driver to work properly, the OS image cannot be stored in flash and has to loaded into RAM. There is a 512 KB region reserved for the boot loader located at the starting address of flash memory. If the flash is corrupted, you may have to update the boot loader. The NOR flash is noticeably slower than NAND or other types of memory when writing and erasing operations are performed. Because you know the physical address of the flash for these reference platforms, the WindowBase value is set to zero for these platforms.

The following registry key examples are necessary to enable RFA:

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\TffsRFA]
    "Dll" = "TrueFFS.dll" 
    "Prefix" = "DSK" 
    "Order" = dword:1 
    "WindowBase" = dword:0 
    "DeviceArrayIndex"=dword:1
    "IClass" = "{A4E7EDDA-E575-4252-9D6B-4195D48BB865}"
[HKEY_LOCAL_MACHINE\System\StorageManager\Profiles\TRUEFFS_RFA]    
    "Name"="Resident Flash Array TrueFFS"
    "Folder"="RFA Disk"
