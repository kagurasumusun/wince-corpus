Miscellaneous Callback Functions

The following table shows miscellaneous callback functions with their corresponding descriptions.

Function Description
GetAvailDriverMemory Determines how much free memory is in the driver's private heaps.
GetHeapAlignment Queries the surface alignment requirements.
GetSysmemBltStatus Queries the status of an asynchronous direct memory access (DMA) operation.
UpdateNonLocalHeap Notifies the driver of the base addresses of each nonlocal heap in turn.
