DDHAL Porting from the Desktop

While every attempt was made to avoid significant deviation in DDGPE from the Desktop DDHAL specification, there are still several steps that must be taken to convert from one model to the other.

This topic and its subtopics discuss what is necessary to convert a DDHAL desktop implementation into a DDGPE-compatible Windows CE–based DDHAL implementation. While the conversion to a device driver that is not derived from DDGPE is not specifically discussed, the topics referenced here will still be of use to developers who decided to ignore DDGPE.

Before you start porting any DDHAL display driver from a Desktop implementation, you should already have a working DDGPE-based driver. Make sure you followed the steps outlined in DirectDraw Display Driver Creation to create a driver that you can modify with the code in your Desktop DDHAL.
