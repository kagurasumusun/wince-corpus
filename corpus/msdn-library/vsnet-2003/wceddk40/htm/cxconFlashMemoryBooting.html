Flash Memory Booting

You can boot your kernel image directly from a flash memory device instead of from ROM. Booting the OS image from flash implies XIP, which also means that booting is possible only on built-in flash devices or a flash device that is memory-mapped directly onto the system bus. One method for implementing flash memory booting involves writing a separate boot loader program that copies the OS image to the built-in flash device and executes that image.
