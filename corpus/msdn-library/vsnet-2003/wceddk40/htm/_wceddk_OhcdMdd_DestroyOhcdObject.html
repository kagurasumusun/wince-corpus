HcdMdd_DestroyHcdObject

This function cleans up a host controller interface driver object.

BOOL HcdMdd_DestroyOhcdObject(
LPVOID lpvOhcdObject 
);

Parameters

lpvOhcdObject
[in] Pointer to a host controller driver object.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This function should be called when a host controller interface controller is removed, or if an error occurs during initialization, to enable the MDD to clean up internal data structures.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Ohcdddsi.h or Uhcdddsi.h
