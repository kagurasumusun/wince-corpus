HWGetStatus

This function specifies the hardware status API.

ULONG HWGetStatus(
PVOID pContext,
LPCOMSTAT lpStat 
);

Parameters

pContext
[in] Pointer to a context structure returned by the HWInit function that contains implementation-specific data describing the hardware device.
lpStat
[out] Pointer to an LPCOMMSTAT structure to hold status.

Return Values

Zero indicates success. A value of –1 indicates failure.

Remarks

See ClearCommError for a description of lpStat.

This function supports the implementation of the lower layers of serial port drivers.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Serhw.h

ClearCommError, HWInit
