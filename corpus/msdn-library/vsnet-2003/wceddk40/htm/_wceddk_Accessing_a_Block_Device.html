Block Driver Accessing

There are two methods for accessing block devices, depending on whether the device is native to a platform or whether you can remove the device.

Drivers for built-in block devices access their devices by mapping the address space of the device directly into the address space of the operating system. The driver should use the MmMapIoSpace function to map the block device into system memory.

Block device drivers for PC Card block devices need to use a memory window to access their devices. For more information on PC Card block devices, see PC Card Driver Samples. The driver can get a memory window by using PC Card Services functions and then use the memory window to read and write data between the driver and the block device. For more information on PC Card Services functions, see PC Card Driver Architecture.
