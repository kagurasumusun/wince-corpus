802.11 Security

Security options for 802.11 include authentication services and encryption services based on the wired equivalent privacy (WEP) algorithm. WEP is a set of security services used to protect 802.11 networks from unauthorized access, such as eavesdropping; in this case the capture of wireless network traffic. When data encryption is enabled, secret shared encryption keys are generated and used by the source station and the destination station to alter frame bits, thus avoiding disclosure to eavesdroppers. For information about 802.11 security, see this Microsoft Web site. For additional details on 802.11 and wireless network security, see Secure Your Wireless Network.
