FLAT Sample Display Driver

The FLAT driver is a simple display driver that does not implement any hardware acceleration. However, the FLAT sample display driver implements software acceleration features, supports 8, 16, 24, and 32 bit color depths, and supports any physical resolution supported by the BIOS. The FLAT driver works with the ATI Rage, ATI Expert, Savage4, Savage2000, nVidia TNT2, Voodoo3 2000, Voodoo3 3000, Matrox G200, and Matrox G400 video chip sets. Be sure to run vesatest.exe to verify the platform's VESA BIOS is 2.0 or later and supports the desired mode.

Because of its wide support for video chip sets and its overall flexibility, the FLAT driver makes a good basis for you to implement hardware-accelerated display drivers for your own hardware. The FLAT driver is also good driver for you to use when evaluating Windows CE, because it works with display hardware that is readily available in the marketplace. However, when a built-in display driver is available for a chipset, it is recommended that developers use this driver. In general, they offer better performance by taking advantage of the hardware features that are often times not exposed through the VESA BIOS.

The FLAT sample is the default display driver for most x86-based platforms. It requires that the display card support VESA BIOS Extensions 2.0 or higher. At boot time, the boot loader must set the video mode; the FLAT driver is incapable of setting the video mode on its own. On x86 platforms this is handled by the LoadCEPC.exe tool and the BIOS. Therefore, you must update your CEPC boot disks for in order to have the correct boot loader that works with the FLAT display driver. For more information about LoadCEPC.exe options, run loadcepc /? – the /L option will be of interest in setting the display mode.

Note   If you use the /D switch to specify the display mode, you cannot use the DDI_FLAT driver.

To build and explicitly include the FLAT driver in an image, set BSP_DISPLAY_FLAT=1 in the platform build settings environment.

The FLAT sample display driver is available in %_WINCEROOT%\Public\Common\OAK\Drivers\Display\VGAFlat.
