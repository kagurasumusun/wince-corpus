DestroyDriver

This callback function destroys a DirectDraw driver. 

DWORD __stdcall DestroyDriver(
LPDDHAL_DESTROYDRIVERDATA   pddd 
);

Parameters

pddd
[in/out] Pointer to a DDHAL_DESTROYDRIVERDATA structure that contains information necessary to destroy the driver.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 and later. Version 2.12 requires DXPAK 1.0 or later. Ddrawi.h
