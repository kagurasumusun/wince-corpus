UNIT_RegisterSubunit_Request

This structure is used by IOCTL_UNIT_REGISTER_SUBUNIT.

typedef struct {
ULONG urs_SubunitType;
PVOID urs_Context;
PDEVICE_OBJECT urs_ParentDeviceObject;
UNIT_AllocateLocalPlugCB *urs_AllocateLocalPlug;
UNIT_FreeLocalPlugCB *urs_FreeLocalPlug;
UNIT_ConnectToRemotePlugCB *urs_ConnectToRemotePlug;
UNIT_DisconnectFromRemotePlugCB *urs_DisconnectFromRemotePlug;
} UNIT_RegisterSubunit_Request;

Members

urs_SubunitID
The AV/C subunit identifier for the subunit driver.
urs_ParentDeviceObject
The parent device of your subunit driver. AVC_STREAM or another filter driver.
urs_Context
The context value that the unit filter driver is to pass in as an argument into the urs_ConnectToPlug and urs_DisconnectFromPlug callback functions.
urs_AllocateLocalPlug
A pointer to a function called when an outside node has requested that the registered subunit allocate a local plug.
urs_FreeLocalPlug
A pointer to a function called when an outside node has requested that the registered subunit free a previously allocated local plug.
urs_ConnectToRemotePlug
A pointer to a function called when an outside node has requested that the registered subunit launch a connection attempt to a particular plug on an arbitrary node.
