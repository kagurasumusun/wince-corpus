DirectSound Driver Structures

The following table shows the Microsoft® DirectSound® structures that are passed to the driver.

Structure Description
DSDVR_MESSAGE_PARAMS DirectSound driver structure that is a union containing members passed to the WAV_IOControl function.
DSDMP_MSG Contains the message value and driver instance.
