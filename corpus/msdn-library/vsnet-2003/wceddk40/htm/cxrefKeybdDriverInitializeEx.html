KeybdDriverInitializeEx

This function initializes the keyboard driver.

void KeybdDriverInitializeEx (
PFN_KEYBD_EVENT_CALLBACK_EX pfnKeybdEventCallbackEx
);

Parameters

pfnKeybdEventCallbackEx
[in] Pointer to a function used as the callback into the input system.

Return Values

TRUE indicates success. FALSE indicates failure. Extended error information is available through GetLastError.

Remarks

This function should call the KeybdPdd_InitializeDriverEx function, and then start a driver interrupt service thread.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Keybddr.h
