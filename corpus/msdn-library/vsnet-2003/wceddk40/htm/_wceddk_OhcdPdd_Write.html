HcdPdd_Write

This function is the HC driver write routine.

DWORD HcdPdd_Write(
DWORD dwOpenContext 
);

Parameters

dwOpenContext
[in] Pointer to the device context returned from the HcdPdd_Init function.

Return Values

Drivers return –1.

Remarks

This function is the standard stream interface driver write routine. It currently isnot used.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Ohcdddsi.h or Uhcdddsi.h
