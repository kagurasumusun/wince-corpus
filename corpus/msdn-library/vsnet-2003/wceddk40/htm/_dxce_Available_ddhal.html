SurfaceHeap::Available

This method can be used to determine the amount of memory that has not yet been allocated from the current heap.

DWORD Available(void);

Parameters

None.

Return Values

This method returns the total number of bytes available in the current heap.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 and later. Version 2.12 requires DXPAK 1.0 or later. Ddgpe.h Ddgpe.h Ddgpe.lib
