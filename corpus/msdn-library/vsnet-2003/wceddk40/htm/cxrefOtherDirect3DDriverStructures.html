Other Direct3D Driver Structures

The following table lists all the Microsoft Direct3D® driver structures that do not begin with D3DHAL_.

Structure Description
D3DDEVICEDESC_V1 Describes the 3D capabilities of a device.
D3DLIGHTINGCAPS Describes the lighting capabilities of a device.
D3DPRIMCAPS Defines the capabilities for each primitive type.
D3DTRANSFORMCAPS Describes the transform capabilities of a device.
