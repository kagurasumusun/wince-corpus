D3DNTHAL_DP2OPERATION

This enumeration is type defined as D3DHAL_DP2OPERATION in Dx95type.h, the shorter form is used here for clarity. Either form is equally valid on Microsoft Windows® 2000 and later implementations, but only the shorter form can be used on Microsoft Windows CE .NET.

When porting the desktop drivers that use the D3DNTHAL_XXX structure form, the Dx95type.h header file can be used to translate to the correct forms for Windows CE–based drivers.
