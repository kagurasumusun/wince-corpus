DDGPE::InDisplay

This method returns whether the scanline is in display. The default implementation returns 0. Your driver is supposed to override this method by polling the hardware register(s).

virtual int InDisplay(void);

Parameters

None.

Return Values

A return value of 0 indicates that the scanline is not in display. Return value of 1 indicates otherwise.
