HCD Module PDD Functions

The following table shows the DDSI functions exposed by the PDD layer.

Function Description
HcdPdd_CheckConfigPower Checks power for a requested configuration.
HcdPdd_Close The HCD close routine.
HcdPdd_Deinit The HCD de-initialization routine.
HcdPdd_DllMain The main DLL entry point for the PDD portion of a host controller interface driver.
HcdPdd_Init Initializes a host controller interface plus any platform-specific hardware and structures.
HcdPdd_IoControl The HCD IOCTL routine.
HcdPdd_Open The HCD open routine.
HcdPdd_PowerDown The HCD power-off handler.
HcdPdd_PowerUp The HCD power-up handler.
HcdPdd_Read The HCD read routine.
HcdPdd_Seek The HCD seek routine.
HcdPdd_Write The HCD write routine.
