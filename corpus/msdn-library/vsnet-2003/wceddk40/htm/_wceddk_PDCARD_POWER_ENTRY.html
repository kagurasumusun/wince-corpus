PDCARD_POWER_ENTRY

This structure indicates the voltage levels that a socket controller can produce.

typedef struct {
UINT8 uPowerLevel;
UINT8 fSupply;
} PDCARD_POWER_ENTRY;

Members

uPowerLevel
Specifies the voltage in 0.1 volt increments.
fSupply
Specifies the voltage source, Vcc, Vpp1, or Vpp2.

Remarks

It supports the implementation of the driver described in the sample PC Card socket driver.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Sockserv.h Sockserv.h
