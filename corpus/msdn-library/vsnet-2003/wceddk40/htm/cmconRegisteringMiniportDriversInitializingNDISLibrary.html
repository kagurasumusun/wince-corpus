Initializing the NDIS Wrapper

All NDIS miniport and intermediate drivers must provide a DriverEntry function. When a miniport driver is loaded, the operating system creates a driver object for the miniport driver and calls the DriverEntry function, which creates an association between the miniport driver and the NDIS library and registers the miniport with NDIS.

The following parameters are passed into the DriverEntry function:

  • A pointer to the driver object, which was created by the I/O system
  • A pointer to the registry path, which specifies where driver-specific parameters are stored

Within the context of the DriverEntry function, the miniport calls the NdisMInitializeWrapper function and then the NdisMRegisterMiniport function. DriverEntry first calls NdisMInitializeWrapper with the parameters that are passed to DriverEntry, which returns a wrapper handle. DriverEntry then passes the handle to NdisMRegisterMiniport.
