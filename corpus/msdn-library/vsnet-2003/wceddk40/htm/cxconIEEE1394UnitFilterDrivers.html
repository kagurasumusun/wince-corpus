IEEE 1394 Unit Filter Drivers

The unit filter driver (AVC_UNIT) is an optional component that should be included to export functionality from your product through an AV/C subunit. An AV/C subunit that exports functionality to other devices on the IEEE 1394 bus is called a virtual subunit. The unit filter driver acts both as a central repository and an intermediary for AV/C units. The AV/C Digital Interface Command Set General Specification contains the definitive definition and explanation of what constitutes a unit. An AV/C compatible device on the bus contains an AV/C unit. Conceptual structures within the device that serve different purposes may be AV/C subunits. For instance, an AV/C compliant camcorder will export both a unit representing the entire camcorder as well as both a camera subunit and a VCR subunit. The unit manages details such as the power state of the device, details about which subunits it contains, and coordination over the association of serial bus plugs with subunit plugs.

When external devices send AV/C commands to query or request that particular plugs be manipulated, they communicate with the unit filter driver. When a virtual subunit driver chooses to make itself and serial bus plugs visible to other devices on the bus, it does so by coordinating with the unit filter driver.

The hierarchy of where the unit filter driver is enumerated by WDM, and where it lies in respect to virtual subunits is important.

Virtual subunit drivers are enumerated by WDM as children of the AV/C driver. The Streaming Filter Driver is inserted between the virtual subunit driver and AV/C automatically as a lower filter driver definition.

The hierarchy of where the unit filter driver is enumerated by WDM, and where it lies in respect to virtual subunits is important.

Virtual subunit drivers are enumerated by WDM as children of the AV/C driver. Typically, the AVC_STREAM driver, the streaming filter driver, is inserted between the virtual subunit driver and AV/C automatically as a lower filter driver definition.

AVC_UNIT is only included in an IABASE or HLBASE build with the SYSGEN_1394_AVC_VIRTUAL environment variable.

IEEE 1394 Unit Filter Driver API Definition

The following table shows the unit filter driver IOCTLs.

IOCTL Description
IOCTL_UNIT_CONNECTION_REQUEST_PROCESSED Permits a subunit to notify the unit driver that it has completed processing a previous UNIT_ConnectToRemotePlugCB request.
IOCTL_UNIT_DISCONNECTION_REQUEST_PROCESSED Permits a subunit to notify the unit driver that it has completed processing a previous UNIT_DisconnectFromRemotePlugCB request.
IOCTL_UNIT_DEREFERENCE_CONNECTION_PLUG Permits a subunit to release and free any resources associated with a remote plug provided by a previous call to UNIT_ConnectToRemotePlugCB.
IOCTL_UNIT_PROCESS_REGISTRY_PLUGS Reads plug definitions from the registry and calls the allocate and free callbacks into the subunit to process them.
IOCTL_UNIT_QUERY_LOCAL_PLUGS Permits the caller to determine the state of the plugs that are associated with your registered subunit.
IOCTL_UNIT_ALLOCATE_LOCAL_PLUG Permits the caller to allocate and export a local plug.
IOCTL_UNIT_FREE_LOCAL_PLUG Permits the caller to free a previously allocated local plug.
IOCTL_UNIT_REGISTER_SUBUNIT Permits a subunit to provide a group of functions that the unit filter driver should call in particular situations.
IOCTL_UNIT_DEREGISTER_SUBUNIT Permits a subunit to remove itself from global consideration to the unit filter driver.

The following table shows the unit filter driver functions.

Function Description
UNIT_AllocateLocalPlugCB Must be provided by the subunit driver. It is called by the unit filter driver when an outside node has requested that a subunit allocate and connect itself to a local serial bus plug.
UNIT_FreeLocalPlugCB Provided by a subunit driver, is called by the unit filter driver when an outside node has requested that a subunit disconnect itself and free a local serial bus plug.
UNIT_ConnectToRemotePlugCB Called by the unit filter driver when a request has arrived requesting that your subunit actively initiate a connection to a particular serial bus plug on a particular node.
UNIT_DisconnectFromRemotePlugCB Called by the unit filter driver when a request has arrived requesting that your subunit disconnect from a particular remote plug, which is one previously connected through UNIT_ConnectToRemotePlugCB.
UNIT_OpenUnitDevice Permits a subunit driver to open the appropriate unit filter driver.
UNIT_CloseUnitDevice Permits a subunit driver to close and free references to the unit driver obtained in a previous call to UNIT_OpenUnitDeviceObject.
