Resident Flash Array

The two major types of flash memory architecture are ATA flash and linear flash memory. Both conform to the industry standard PC Card form factor, and you can use them interchangeably in PC Card sockets. However, there are significant differences between the two architectures that affect their performance.

ATA cards emulate the behavior of an ATA-style hard drive by means of linear flash memory components and a special microcontroller chip, which performs hardware emulation of an ATA-style hard disk. An ATA card appears as an ordinary hard drive to an operating system. ATA-style hard disks are block devices, and ATA cards require block device drivers. The ATADISK sample block device driver works with block devices that conform to the industry standard Advanced Technology Attachment (ATA) Specificiation. Most ATA flash disks will work with the ATADISK driver. For more information on the ATADISK driver sample, see Sample ATADISK Driver.

Linear flash memory takes its name from the fact that, unlike ATA-style flash, the individual storage locations form a contiguous range of memory addresses, and you can access each of them directly. You can directly read linear flash memory as though it were RAM or ROM. A software driver layer, referred to as the flash translation layer (FTL), can emulate a disk drive on linear flash memory devices. This eliminates the need for special controller hardware. Linear flash memory devices that operate in this block-oriented way use the driver layer to translate data to and from a block format.

M-Systems, Inc. provides the FTL software component. This component is the TrueFFS driver. The TrueFFS driver exposes the stream interface to the operating system. For more information on the stream interface, see Stream Interface Drivers. Currently, the TrueFFS driver in supports linear flash memory in several form factors such as minicards, industry standard PC Cards, and built-in DiskOnChip devices. The TrueFFS driver supports some linear flash devices that reside on system boards, also known as Resident Flash Arrays. The TrueFFS driver supports these as block devices. For more information on the TrueFFS driver, see M-System's TrueFFS Driver Sample.
