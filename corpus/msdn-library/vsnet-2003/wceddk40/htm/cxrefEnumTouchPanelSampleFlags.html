enumTouchPanelSampleFlags

This enumeration specifies information about a given touch sample sent to the input system. The values are stored in TOUCH_PANEL_SAMPLE_FLAGS.

enum enumTouchPanelSampleFlags {
TouchSampleValidFlag =        0x01,.
TouchSampleDownFlag =         0x02,
TouchSampleIsCalibratedFlag = 0x04,
TouchSamplePreviousDownFlag = 0x08,
TouchSampleIgnore =           0x10,
TouchSampleMouse =            0x40000000
};

Elements

TouchSampleValidFlag
This flag is set to indicate a valid reading. The driver is allowed to report back an invalid reading to the input system, which will be ignored, but these should be kept to an absolute minimum.
TouchSampleDownFlag
This flag shows the state of finger or stylus. When the finger or stylus is pressed to the touch screen, the driver will be reporting back readings with both the TouchSampleValidFlag and TouchSampleDownFlag flags set. When the stylus or finger is removed from the touch screen, the driver is REQUIRED to send back at least one reading with the TouchSampleValidFlag flag set but the TouchSampleDownFlag flag cleared to indicate that the stylus or finger is up.
TouchSampleIsCalibratedFlag
This flag is set by the driver to notify the input system that it is not necessary to further calibrate the XY coordinates of the sample.
TouchSamplePreviousDownFlag
This flag shows the state from the previous valid sample. It is not necessary for the driver to report this to the input system but it is useful in the driver itself.
TouchSampleIgnore
This flag is set to ignore the sample.
TouchSampleMouse
This flag is reserved.
