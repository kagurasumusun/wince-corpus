PDCardGetAdapter

This function returns power-save mode status and capabilities.

STATUS PDCardGetAdapter(
UINT32 uSocket,
PPDCARD_ADAPTER_STATE pState 
);

Parameters

uSocket
[in] Specifies a number identifying the PC Card socket for which to return information. Valid values depend on the number of PC Card sockets present on the platform.
pState
[out] Pointer to a PDCARD_ADAPTER_STATE structure containing the socket's status and capabilities.

Return Values

Returns one of the return codes in the Cardserv.h header file.

Remarks

When the system is in low-power mode, the ADP_STATE_POWERDOWN bit is set. When the PC Card socket is turned off, the bit ADP_STATE_POWEROFF is set. When the PC Card socket is in full-power mode, the state is either 0 or ADP_STATE_MAINTAIN. This function is called in critical power situations, so it should not block or yield.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Sockserv.h
