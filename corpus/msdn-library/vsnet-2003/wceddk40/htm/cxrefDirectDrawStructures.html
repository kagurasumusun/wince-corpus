DirectDraw Structures

The following table shows the DirectDraw structures with their corresponding descriptions.

Structure Description
DDHAL_CANCREATESURFACEDATA Contains information necessary to indicate whether a surface can be created.
DDHAL_CREATEPALETTEDATA Contains information necessary to create a DirectDrawPalette object for this DirectDraw object.
DDHAL_CREATESURFACEDATA Contains information necessary to create a surface.
DDHAL_DESTROYDRIVERDATA Contains information necessary to destroy a driver.
DDHAL_FLIPTOGDISURFACEDATA Contains information necessary to make the surface to which the GDI writes the primary surface.
DDHAL_GETSCANLINEDATA Returns the scan line.
DDHAL_SETEXCLUSIVEMODEDATA Contains information necessary to set a DirectDraw object to exclusive mode.
DDHAL_SETMODEDATA Contains information necessary to set the display mode.
DDHAL_WAITFORVERTICALBLANKDATA Contains the vertical blank information.
DDRAWI_DIRECTDRAW_GBL Contains the global DirectDraw data that can be shared between object instances.
DDRAWI_DIRECTDRAW_INT Contains the DirectDraw object's interface information.
DDRAWI_DIRECTDRAW_LCL Contains local data for each individual DirectDraw object.
