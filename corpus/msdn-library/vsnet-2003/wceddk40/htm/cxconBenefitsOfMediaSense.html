Benefits of MediaSense

One of the primary benefits of the MediaSense feature is its improved and faster detection of a network disconnect. A network capable device that has been disconnected from the network is not in every case an error. It may be an intended configuration such as a temporary solution. For instance, a mobile user who is traveling with a laptop that has a non-removable Ethernet adapter with the TCP/IP protocol loaded may want to run a network application such as Internet Explorer in offline mode. Without MediaSense, the time it would take for such an application to recognize that a network is not available would be greatly increased. MediaSense support allows applications to complete connectivity tests extremely quickly and offer an offline mode to the user.

Another benefit of MediaSense is the shorter boot and resume times. Numerous Windows CE–based networking services that are launched at system boot time are also subject to extended timeouts either built into the protocols that they implement, such as DHCP client, or because of long TCP/IP connect timeouts. The former can query NDIS for a connectivity state directly while the latter will use a much shorter TCP/IP timeout without a need for an application code change. Also, if a device has two or more network connections it is possible that due to a routing configuration only one of them will carry all outbound traffic. If the NIC carrying the traffic becomes disconnected from the network, all network connectivity will fail because the device will continue to attempt to send all packets through a disconnected interface. With MediaSense the routing configuration will reflect the disconnected status of the NIC and the packets will be sent out using another network interface.

MediaSense optimizes routing clients for faster routing convergence as well. A routing protocol periodically verifies the network link state with specific routing packets. The update interval may be 30 seconds or longer, adding to the convergence time. With MediaSense there are specific optimizations that a routing client can implement.

  • On a Connect event, use route update over the link that generated an event.
  • On a Disconnect event, mark the link status and update all neighbors.

MediaSense also offers improved network management. Tools for network management under MediaSense will be able to collect additional information about desktop computer interfaces. For example, an interface MIB may indicate that the interface is down due to a physical wire disconnect rather than being turned off through software.
