NDIS Timers

A driver creates a timer for polling or timing out operations. The driver associates a function with the timer, and then calls the associated function when the period specified in the timer expires. Timers can be one-shot or periodic. Once you set a periodic timer, it continues to fire at the expiration of every period until explicitly cleared. A one-shot timer must be reset each time it fires.

The following table shows the NDIS time functions.

Function Description
NdisMInitializeTimer Creates and initializes timers.
NdisMSetTimer Sets or resets a one-shot timer.
NdisMSetPeriodicTimer Sets a periodic timer.
NdisMCancelTimer Clears a timer.
