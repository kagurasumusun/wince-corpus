USB Device Drivers Testing

You can test USB drivers with the Microsoft® Windows® CE .NET Test Kit (CETK). View the CETK documentation by opening the CETK from the Windows Start menu and choosing All Programs, choosing Microsoft Windows CE .NET 4.1, and then choosing Windows CE .NET 4.1 Test Kit.

The sample USB HID driver and the USB 8x930Ax peripheral kit and evaluation board from Intel Corporation can also be used to assist in testing USB scenarios.
