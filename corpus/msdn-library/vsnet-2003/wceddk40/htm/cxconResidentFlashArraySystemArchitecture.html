Resident Flash Array System Architecture

A flash memory driver is a layered driver consisting of two parts. The first part is a lower-edge FTL driver that handles all wear-leveling algorithms specific to the flash chip. The second part is an upper-edge driver that typically interfaces with an appropriate installable file system (FSD) driver at the application level. You have to implement a flash file system as a block driver that takes on all the inherited properties of a stream interface in addition to those of a block driver.

FATFS does not directly read or write to the flash memory hardware. Instead, FATFS indirectly calls the flash driver by invoking the driver's IOControl routine with the appropriate control codes. The upper edge of the driver interprets those control codes, while the lower-edge flash memory driver performs all low-level hardware access. If FATFS is not used, you must develop a customized file system driver in place of FATFS, which communicates directly with the flash memory block driver.
