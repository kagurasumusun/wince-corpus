D3DRENDERSTATE_SCENECAPTURE

This render state is one value of the D3DRENDERSTATETYPE enumerated type. This render state is handled along with the other render states in D3dDrawPrimitives2.

The driver responds to D3DRENDERSTATE_SCENECAPTURE by passing TRUE for begin scene information and FALSE for end scene information to capture geometric data within a frame.

See the Perm3 sample driver for an example implementation.

Render State Value Type Default Value
BOOL TRUE
