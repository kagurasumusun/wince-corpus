NDIS Events

You can use events to synchronize operations between two threads of execution. A driver allocates an event and initializes it. IF necessary, a driver thread may wait on an event, specifying the event and a maximum time to wait. The thread's wait is satisfied when the event is signaled, or when the specified maximum wait-time interval expires, whichever occurs first.

Function Description
NdisInitializeEvent Allocates and initializes an event. Events are unsignaled when they are created and must be set in order to signal waiting threads.
NdisWaitEvent Puts a driver thread into a wait state.
NdisSetEvent Signals the event. Typically, a cooperating thread sets the event. Events remain signaled until a thread calls NdisReset Event.
NdisResetEvent Resets and event to an unsignaled state. Signaled Events remain signaled until a thread calls NdisReset Event.
