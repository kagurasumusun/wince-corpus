HCD Module MDD Functions

The following table shows the MDD functions that the PDD layer must call.

Function Description
HcdMdd_CreateMemoryObject Creates the host controller interface shared memory area.
HcdMdd_DestroyMemoryObject Cleans up a host controller interface memory object.
HcdMdd_CreateHcdObject Creates and initializes a host controller interface driver object.
HcdMdd_DestroyHcdObject Cleans up a host controller interface driver object.
HcdMdd_PowerUp HCD MDD power-up handler.
HcdMdd_PowerDown HCD MDD power-down handler.
