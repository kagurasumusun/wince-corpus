DirectDrawClipper Structures

The following table shows the DirectDrawClipper structures with their corresponding descriptions.

Structure Description
DDRAWI_DDRAWCLIPPER_GBL Contains the global DirectDrawClipper data.
DDRAWI_DDRAWCLIPPER_INT Contains the DirectDrawClipper object's interface information.
DDRAWI_DDRAWCLIPPER_LCL Contains local data for each individual DirectDrawClipper object.
