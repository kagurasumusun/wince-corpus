PC Card Registry Keys

To detect PC Cards, the Device Manager initiates a detection sequence to determine the card type. The following registry example shows the default registry entries that the Device Manager requires in order to initiate the detection sequence.

[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\TrueFFS]
    "Prefix" = "DSK"
    "Dll" = "TrueFFS.DLL"
    "IOCTL" = "DWORD:4"
    "IClass"="{A4E7EDDA-E575-4252-9D6B-4195D48BB865}"
[HKEY_LOCAL_MACHINE\Drivers\PCMCIA\Detect\90]
    "Dll" = "TrueFFS.DLL"
    "Entry" = "DetectTFFSDisk"

The value of the Folder entry, under the subkey TrueFFS, is optional and is not part of the default registry. Its value determines the folder names that are associated with linear flash memory devices. The default name is Storage Card for the first device, Storage Card2 for the second, and so on. You can change the value for the Folder entry to the name of the folder. For example, if you change the value to Flash Disk, Flash Disk will be the actual name of the first device. The second device will be Flash Disk2, and so on.

The subkey 90, under the Detect subkey, is an example and can be any number. Its value determines the order in which the Device Manager searches for the TrueFFS/CE driver when it is attempting to detect an unknown type of PC Card.

TrueFFS PCMCIA Profile

[HKEY_LOCAL_MACHINE\System\StorageManager\Profiles\TRUEFFS_PCMCIA]    
    "Name"="PCMCIA TrueFFS"
    "Folder"="Storage Card"
