USB Mass Storage Class Driver Limitations and Known Issues

There are a few limitations and known issues with the storage class driver.

  • The driver currently does not support DVD so these devices will not work with the Windows CE driver.
  • USB devices that claim CBI transport but do not use the interrupt endpoint, for example LaCie devices, take a while to time-out during driver loading.
  • The driver does interact with the serial numbers, which must be present, static, and unique.
  • Some USB mass storage class devices are not recognized because they do not fully comply with the USB specification. These devices can be loaded using the vendor identifier (VID) and product identifier (PID) combination, and then Usbmsc.dll reads its bInterfaceSubClass and bInterfaceProtocol from the host's registry or you provide this information.
