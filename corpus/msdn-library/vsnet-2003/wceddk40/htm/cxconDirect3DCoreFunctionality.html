Direct3D Core Functionality

The following topics describe the features that are central to implementing core functionality in a Direct3D driver.

  • Direct3D Context Management contains information on how the driver should draw.
  • Direct3D Texture Management contains information about texture support.
  • Primitive Drawing and State Changes discusses the layout of command and vertex buffers. It also describes how the driver should process these.
  • FVF (Flexible Vertex Format) describes FVF functionality.
