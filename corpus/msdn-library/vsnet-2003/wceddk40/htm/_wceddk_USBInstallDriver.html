USBInstallDriver

This function installs a USB client driver.

BOOL USBInstallDriver(
LPCWSTR szDriverLibFile 
);

Parameters

szDriverLibFile
[in] Specifies the driver DLL name.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This function is called by the USB driver module when an unrecognized device is attached to the USB and the user enters the client driver DLL name. It registers a unique client identifier string with the USB driver module and sets up any client driver settings.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later   Usbdi.h
