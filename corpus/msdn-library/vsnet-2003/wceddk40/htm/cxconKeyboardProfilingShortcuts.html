Keyboard Profiling Shortcuts

The default drivers for AT and XT keyboards have built in shortcuts that turn profiling on and off. The shortcuts are implemented by the scan code processing libraries in %_WINCEROOT%\Public\Common\OAK\Drivers\Keybd\Scanvk. Disable the shortcuts by commenting out #define PROFILE 1 in the source files for the libraries. The following table shows the shortcut key and the associated function call.

Shortcut key Function call
F8 ProfileStart(200, PROFILE_OBJCALL);
F9 ProfileStart(200, PROFILE_BUFFER);
F10 ProfileStart(200, PROFILE_KCALL);
F11 ProfileStart(1000, 0);
F12 ProfileStop();

For the description of the parameters see ProfileStart and ProfileStop.
