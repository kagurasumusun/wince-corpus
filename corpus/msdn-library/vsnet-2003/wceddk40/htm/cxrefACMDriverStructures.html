ACM Driver Structures

The following table shows the structures related to the Audio Compression Manager (ACM) driver.

Structure Description
ACMDRV_MESSAGE_PARAMS Contains members passed to the ACM_IOControl function.
ACMDRVFORMATSUGGEST Contains client-specified input arguments to the AcmFormatSuggest function. The ACM fills in this structure with the client's input arguments and passes it to an ACM driver with an ACMDM_FORMAT_SUGGEST message.
ACMDRVOPENDESC Used by the ACM for passing information to an ACM driver after the ACM sends the driver an ACM_Open function.
ACMDRVSTREAMHEADER Describes a source buffer and a destination buffer associated with a conversion stream.
ACMDRVSTREAMINSTANCE Describes an instance of a conversion stream.
ACMDRVSTREAMSIZE Contains information needed by an ACM driver to respond to an ACMDM_STREAM_SIZE message.
