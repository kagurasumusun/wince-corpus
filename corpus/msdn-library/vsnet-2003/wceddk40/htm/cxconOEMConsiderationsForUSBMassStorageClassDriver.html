Installing the USB Mass Storage Class Driver

  1. Include the USB storage class driver is in the Windows OS binary image. If the driver is not in the Nk.bin image, you can also manual copy the driver DLL, called Usbmsc.dll, to your release directory on your development machine or to the \Windows directory on the target platform.
  2. Set up the correct registry entries for the storage driver on your target platform as described in the previous section.
  3. Attach the USB storage device to the target platform.

    If you have the correct registry entries set up on the target platform and if the USB device is class-compliant, then the USB subsystem loads the storage driver automatically.

    If you do not have the correct registry settings on the Windows CE device, the system displays an Unknown Device dialog box. Type USBMSC in this dialog box and then press ENTER. This loads the USB storage class driver and sets the correct registry entries so the driver can load automatically next time.
