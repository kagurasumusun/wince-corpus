HcdPdd_Read

This function is the HC driver read routine.

DWORD HcdPdd_Read(
DWORD dwOpenContext 
);

Parameters

dwOpenContext
[in] Specifies a pointer to the device context returned from the HcdPdd_Init function.

Return Values

Drivers return –1.

Remarks

This function is the standard stream interface driver read routine. It currently is not used.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Ohcdddsi.h or Uhcdddsi.h
