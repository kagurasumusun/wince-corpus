DirectSound

DirectSound provides low-latency mixing, hardware acceleration, and direct access to the sound device. The technology provides this functionality while maintaining compatibility with existing device drivers.

DirectSound enables pulse code modulation (PCM) sound capture and playback. It also supports property sets, which allows application developers to take advantage of extended services offered by sound cards and their associated drivers.
