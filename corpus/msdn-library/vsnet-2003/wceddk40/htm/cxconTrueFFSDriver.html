M-System's TrueFFS Driver Sample

Linear flash memory devices are used for persistent storage in embedded systems. Linear flash memory takes its name from the fact that, unlike Advanced Technology Attachment (ATA) flash memory, the individual storage locations form a linear range of memory addresses, each of which can be accessed directly. Linear flash memory uses a software driver layer to emulate a disk drive, which eliminates the need for special purpose controller hardware. Linear flash memory devices use the driver layer to translate data to and from a block format that the OS can understand.

This driver layer is called the flash translation layer (FTL). The FTL software implemented is the True Flash File System for Microsoft® Windows® CE .NET (TrueFFS/CE) driver, licensed from M-Systems, Inc. The TrueFFS/CE driver exposes the standard stream interface to the OS. Linear flash memory is supported in several form-factors, MiniCards from Intel, industry-standard PC Cards, and built-in DiskOnChip devices from M-Systems, Inc.
