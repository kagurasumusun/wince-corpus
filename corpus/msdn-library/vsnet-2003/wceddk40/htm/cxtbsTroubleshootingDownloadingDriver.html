Troubleshooting: Downloading an OS Image

The following table shows problems you may encounter in the process of downloading your OS image.

Problem Possible solution
Your OS image download does not start or finish. Check the connection to the target device. Keep in mind that the OS image download is through Trivial File Transfer Protocol (TFTP), so heavy network traffic may affect your OS image download. Ensure that the Windows CE Debug Shell tool (CESH) is set up correctly. For example, if you want to debug through an Ethernet connection, ensure that CESH is configured for Ethernet debugging.

For more information on CESH, see Windows CE Console Debug Shell Tool.
The only output on your target device is JUMPING TO HEXADECIMAL NUMBER. There may be a problem with the hardware configuration. Check the messages from a serial port on your target device for further assistance.

For more information on receiving messages from a serial port, see Troubleshooting: Debugging a Driver.
