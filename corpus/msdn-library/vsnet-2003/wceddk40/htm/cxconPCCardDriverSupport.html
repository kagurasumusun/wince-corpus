PC Card Driver Samples

There are complete driver implementations in %_WINCEROOT\Public\Common\OAK\Drivers\PCMCIA. This directory contains MDD code and PDD code for I82365 (ISA) and TI1250 (PCI) compatible controllers.

Additional sample PC Card driver code appears in the following directories:

  • %_WINCEROOT%\Platform\ASPEN\Drivers\PCMCIA
  • %_WINCEROOT%\Platform\EAGLE\Drivers\PCMCIA
  • %_WINCEROOT%\Platform\KEYWEST\Drivers\PCMCIA
  • %_WINCEROOT%\Platform\SA11X0BD\Drivers\PCMCIA
