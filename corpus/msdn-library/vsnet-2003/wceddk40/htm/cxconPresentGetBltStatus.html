Present and GetBltStatus

For DX8 the runtime no longer calls GetBltStatus on blits involving system memory surfaces. This was always the behavior on Microsoft® Windows® 2000 and is now the behavior on Windows 98 and Windows Me also. The result is that asynchronous DMA to or from system memory surfaces is no longer possible. DX8 drivers should not page lock system memory surfaces by themselves, and system memory to video memory transfers should be synchronous.
