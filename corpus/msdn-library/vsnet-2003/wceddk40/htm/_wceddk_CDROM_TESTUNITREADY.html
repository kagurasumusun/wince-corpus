CDROM_TESTUNITREADY

This structure contains information on whether or not the unit is ready.

typedef struct CDROM_TESTUNITREADY {
ULONG Reserved; 
BOOL bUnitReady; 
} CDROM_TESTUNITREADY, *PCDROM_TESTUNITREADY;

Members

Reserved
Reserved for future use. Must be zero.
bUnitReady
Queries whether the unit is ready.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Cdioctl.h Cdioctl.h
