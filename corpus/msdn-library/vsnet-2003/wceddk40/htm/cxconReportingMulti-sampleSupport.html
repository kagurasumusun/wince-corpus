Reporting Multisample Support

A driver reports the multisample capabilities of the hardware by specifying the number of samples per pixel for each surface format it reports. DDPIXELFORMAT has been extended to include a structure called MultiSampleCaps. This structure has fields that let the driver express the number of samples per pixel for both flip (full screen) and blit (windowed) multi-sampling. Each of these fields is a WORD in which each bit indicates support for a given number of samples per pixel. Hence, the driver can express support for several different sample counts with a single surface format entry.
