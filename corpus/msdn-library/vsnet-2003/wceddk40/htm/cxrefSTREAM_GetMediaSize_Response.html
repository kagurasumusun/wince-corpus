STREAM_GetMediaSize_Response

This structure is used by IOCTL_STREAM_GET_MEDIA_SIZE.

typedef struct{
    ULONG         sgms_PacketSize;
    ULONG         sgms_FrameSize;
}  STREAM_GetMediaSize_Response;

Members

sgms_PacketSize
Will be filled in with the size, in bytes, of an individual packet for the given media type. The packet size is immutable, and defined by the appropriate sections of IEC-61883.
sgms_FrameSize
Will be filled in with the current value for the frame size for the given media type. The frame size represents a collection of packets that make up a buffer, used for IOCTL_STREAM_ATTACH_BUFFER. For some media types, such as DV, a logical frame represents a viewable video frame as well. The frame size value has a default, that is established at the point when an application calls CreateFile against the device, value, but can be overridden by a later call to IOCTL_STREAM_SET_MEDIA_SIZE. The value returned here is the current value, not the default value.
