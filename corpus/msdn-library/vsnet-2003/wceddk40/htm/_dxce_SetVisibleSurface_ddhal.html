DDGPE::SetVisibleSurface

This method causes an existing GPE surface to be flipped to the display. If the bWaitForVBlank parameter is TRUE, the method waits until the vertical blank has begun, then it flips the given surface to the screen.

virtual void SetVisibleSurface(
GPESurf  *pSurf,
BOOL     bWaitForVBlank = FALSE
);

virtual void SetVisibleSurface(
GPESurf  *pSurf,
DWORD    dwData,
BOOL     bWaitForVBlank = FALSE 
);

Parameters

pSurf
A pointer to the surface that will be displayed.
dwData
A placeholder for extra information into the driver.
bWaitForVBlank
Indicates whether the flip should wait to synchronize with a vertical blank.

Return Values

None.

Remarks

You should override this method in your driver to enable surface flipping for your hardware. dwData can be used if you need to pass more information to perform the flip.
