USB Miscellaneous Functions

The following table shows miscellaneous functions for tasks related to interacting with the USB system software.

Function Description
FindInterface Searches for a specific interface on a USB device.
GetDeviceInfo Gets a pointer to a device information structure.
GetUSBDVersion Returns the version number of the USB driver interface present on a Windows CE–based platform.
LoadGenericInterfaceDriver Is called by USB drivers to load drivers for other interfaces on a device.
OpenClientRegistryKey Opens a registry key associated with a USB client driver.
RegisterClientDriverId Is called to register a unique string to identify a USB client driver.
RegisterClientSettings Is called to set up USB driver load settings.
RegisterNotificationRoutine Registers a callback for device notifications.
TranslateStringDescr Translates a USB string descriptor into a null-terminated string.
UnRegisterNotificationRoutine Removes a device notification callback.
