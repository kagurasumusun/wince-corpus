OID_802_11_TX_ANTENNA_SELECTED

This object identifier when set, requests the miniport driver to set, to a specified value, the antenna number that identifies the currently selected transmit (TX) antenna. A value of 0xffffffff indicates that all TX antennas are selected.

When queried, it requests the miniport driver to return the antenna number that identifies the currently selected transmit antenna.

The antenna value is defined as follows.

typedef  ULONG   NDIS_802_11_ANTENNA;
