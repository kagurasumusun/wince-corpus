UpdateVideoPort

This callback function starts, stops, and changes the video port. 

DWORD __stdcall UpdateVideoPort(
LPDDHAL_UPDATEVPORTDATA   puvpd 
);

Parameters

puvpd
[in/out] Pointer to a DDHAL_UPDATEVPORTDATA structure that contains the information required to update the video port.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 and later. Version 2.12 requires DXPAK 1.0 or later. Ddrawi.h
