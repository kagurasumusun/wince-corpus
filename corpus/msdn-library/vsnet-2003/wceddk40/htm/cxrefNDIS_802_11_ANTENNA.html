NDIS_802_11_ANTENNA

This data type is used to set and return the 802_11 antenna selected for receiving on the radio.

typedef 
ULONG NDIS_802_11_ANTENNA;

Remarks

OID_802_11_RX_ANTENNA_SELECTED sets and returns the target antenna. -1 equals all antennas.
