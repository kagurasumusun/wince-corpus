Driver Testing

While developing your driver, you can test it. The Windows CE Test Kit (CETK) provides tests for each class of devices. Within the CETK, you can choose the appropriate tests to perform on your device driver and the tool remotely runs the tests on your target device.

For information about using the CETK, from the Windows Start menu, under Programs, open the CETK. It is in the same location as Platform Builder.
