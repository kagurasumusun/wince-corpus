Flash Partitioning

You can treat flash as a single contiguous address space. In this configuration, you can use the flash for XIP or for data storage. Data storage can include one or more of the registry, database, or user data files managed by the FAT or other file system driver.

Multiple partition support enables you to logically divide the flash into separate partitions. With a code plus data configuration, you can use one partition for XIP, and use the other for data storage. Another configuration that might be of interest is dividing the flash into two data storage partitions. One partition provides data storage managed by the RFA driver for database, registry, or user data files accessed through the FAT or other installable file system. The other partition provides data storage managed exclusively by OEM-defined code. This is a data plus data configuration.
