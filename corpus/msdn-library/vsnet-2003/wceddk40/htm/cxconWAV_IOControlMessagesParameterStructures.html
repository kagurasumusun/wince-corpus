WAV_IOControl Messages and Parameter Structures

The Unified Audio Model (UAM) has new IOCTL values and message parameters. These have been added to support the DirectSound and hardware mixer middleware extensions to the wave audio streaming driver model.

The following are the new WAV_IOControl values and messages.

DirectSound

dwcode = IOCTL_DSDVR_MESSAGE

pBufIn = pointer to DSDVR_MESSAGE_PARAMS

dwLenIn = sizeof(DSDVR_MESSAGE_PARAMS)

The rest of the WAV_IOControl parameters are the same as IOCTL_WAV_MESSAGE in previous versions.

Hardware Mixer

dwcode = IOCTL_MIX_MESSAGE

pBufIn = pointer to MMDRV_MESSAGE_PARAMS

dwLenIn = sizeof(MMDRV_MESSAGE_PARAMS)

The rest of the WAV_IOControl parameters are the same as IOCTL_WAV_MESSAGE in the previous versions of the Microsoft® Windows® CE operating system (OS).

The new messages and their related structures are specified in DirectSound Driver Messages, Audio Mixer Messages, and DirectSound Driver Structures.
