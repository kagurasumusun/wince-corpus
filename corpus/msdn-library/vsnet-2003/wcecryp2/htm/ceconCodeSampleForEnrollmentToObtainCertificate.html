Microsoft Windows CE .NET  

Code Sample for Enrollment to Obtain a Certificate

Before adding a Windows CE .NET–based wireless device to a Microsoft Windows XP network, you must first obtain a valid authentication certificate for the Windows CE device. To obtain the certificate, the Windows CE device must first physically connect to the network, enroll, and be authenticated by a certificate authority.

Platform Builder includes an enrollment tool that you can build and use to obtain a certificate for the Windows CE device. The tool is named Enroll.exe, and it is located in the %_WINCEROOT\Public\Common\Sdk\Samples directory. Procedures listed in this topic assume that you are familiar with building a platform using Platform Builder.

The three major steps you must perform to enroll a Windows CE device onto an 802.1x wireless network are described in the following table.

Major step Description
Prepare the Windows CE device Adds Enroll.exe to the Windows CE device.
Obtain a certificate Connects the Windows CE device to a network to obtain a certificate from a certificate authority.
Logon to the wireless network Starts the wireless network protocol and logs you on to the Windows XP network.

To prepare a Windows CE device for enrollment

  1. Start Platform Builder.
  2. Create a platform for your Windows CE .NET device and ensure that the Platform.bib file includes the Enroll.exe component.
  3. Ensure that the following SYSGEN variables are set in the platform you are creating:
    • SYSGEN_WININET
    • SYSGEN_ETH_80211
    • SYSGEN_AUTH_SCHANNEL
  4. Build and download the platform to your Windows CE device.

You are now ready to obtain a certificate for the Windows CE device.

To obtain a certificate

  1. Remove the wireless network card from the device, and then install a wired network interface card.
  2. Connect a network cable from a network repeater to the network interface card.
  3. From the Start menu, choose Run.
  4. In the Run dialog box, type enroll -<name> (where <name> is the name of a certificate server on the Windows XP network), and then choose OK.

    A Windows logon dialog box appears.

  5. Type your Windows networking user name, domainm and password, and then choose OK.
  6. From the Start menu, choose Settings, and then choose Control Panel.
  7. In Control Panel, choose Certificates, and then choose My Certificates to verify that a certificate containing your name has been downloaded.

You are now ready to start the network protocol on the Windows CE device and log on to the network.

To log on to the wireless network

  1. Remove the network interface card, and then install the wireless network card.

    A dialog box appears containing the name of the wireless network card in the title bar. The name varies, depending on the name of the card.

  2. In the Wireless Network Card dialog box, choose the Wireless Information tab, choose the name of the network to which you want to connect, and then choose Connect.

    The Wireless Network Properties dialog box appears.

  3. In the Wireless Network Properties dialog box, select the Enable 802.1X authentication on this network check box.
  4. In the EAP list, choose TLS, and then choose Properties.
  5. In the Authentication Properties dialog box, choose the certificate for the domain you are using, choose OK, and then choose OK again to close the Wireless Network Properties dialog box.

    After a short period of time, the User Logon dialog box appears.

  6. In the User Name and Domain boxes, type your user name and domain, and then choose OK.

    The Select a Certificate dialog box appears.

  7. Choose the certificate that you obtained in the earlier procedure, and then choose OK.

    After a brief period of time, the Windows CE device is connected to the wireless network.
