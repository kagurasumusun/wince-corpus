Handling Synchronization Errors

An error dialog box should never be displayed during normal synchronization. ActiveSync suppresses all dialog boxes during synchronization to avoid interrupting the process and changing the focus. When a user starts a resolution cycle by clicking Resolve items, the service provider can display an error dialog box in the sequence in the preceding section. The dialog box should be informative and describe how to resolve the problem or prevent future occurrences. Title the dialog box with the following string.

program-name Error
