IEnumReplItem::GetFolderHandle

This method gets a handle (HREPLFLD) to the folder that is currently being enumerated.

hHREPLFLD GetFolderHandle( );

Parameters

None.

Return Values

Returns the handle (HREPLFLD) to the folder being enumerated.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later   Cesync.h
