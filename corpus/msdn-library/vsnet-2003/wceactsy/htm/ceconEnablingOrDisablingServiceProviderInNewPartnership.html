Enabling or Disabling a Service Provider in a New Partnership

To specify whether a service provider is enabled by default for all new partnerships, set the DWORD Disabled value to 0 or 1 for the following registry key.

HKEY_LOCAL_MACHINE\Software\Microsoft\Windows CE Services\Services\Synchronization\All\object-type

Setting Disabled to 0 or omitting it enables the service provider by default when ActiveSync creates a new partnership. Setting it to 1 disables the service provider by default when ActiveSync creates a new partnership.
