Running Silent Mode Setup from the Command Line

ActiveSync 3.0 Setup can run Silent Mode directly from the command line. The simplest way is to use the "silent" keyword. Setup uses the default settings.

D:\Main\Setup.exe silent

If you need to control the behavior of Setup, modify the sample Silent.ini file or create a new one. To use the sample INI file, add the full path and file name of the INI file in quotes to the command line. The path can be relative or absolute.

D:\Main\Setup.exe "silent.ini"
D:\Main\Setup.exe "\\Server\Public\Microsoft ActiveSync\silent.ini"

The ActiveSync setup program (Setup.exe) is located in the Main directory on the ActiveSync CD. The ActiveSync setup program is not the Setup.exe application located in the root directory. For ActiveSync to work properly, you must configure the Main directory and all its subdirectories as they are on the CD.
