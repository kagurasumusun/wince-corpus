Running ActiveSync Silent Mode Setup Using System Management Server

To run ActiveSync 3.0 in Silent Mode using System Management Server

  1. Ensure the minimum system requirements are met.
  2. Modify the Silent.ini file templates as required.
  3. Make sure the Main directory is configured the same as the Main directory on the ActiveSync CD.
  4. Create a System Management Server package, using the directory from Step 3 as the source.
  5. Run setup.exe on the target machine with the desired arguments.

Consult the System Management Server documentation for details on configuring the System Management Server package to run setup.exe on a target machine with the desired arguments, and distributing the package to your users. For System Management Server 1.2, read the documentation on Service Pack 3 about unattended installation on a Windows NT machine running the System Management Server PCMSERVICE.

Setup places the wcesetup.log file in the directory where Setup installed the ActiveSync application, or in the %tmp% directory if setup is unsuccessful. For more information about interpreting the wcesetup.log file, see Determining if the Setup was Successful.

If you have any other changes necessary to customize the ActiveSync setup, you can run the changes after setup is complete.
