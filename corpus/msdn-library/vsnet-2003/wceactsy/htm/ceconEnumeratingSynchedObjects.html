Enumerating Synched Objects

Object enumeration on a device is handled different than on a desktop.

When the device is connected, the ActiveSync manager enumerates each file-system object (except files in ROM or the \windows directory) and calls the ObjectNotify function of each ActiveSync provider. The ActiveSync provider decides if it will synchronize the given file-system object, and if so, tells the ActiveSync manager how many synchronized objects are contained in the file-system object. This is usually one object, but if a file-system object represents many synchronized objects it might be greater.

In Windows CE version 2.1 and later, the FindObjects function can be added to the device service provider.
