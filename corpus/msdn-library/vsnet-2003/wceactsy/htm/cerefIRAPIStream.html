IRAPIStream

This interface extends the IStream:IUnknown interface with two methods that allow the setting of timeouts.

Method Description
IRAPIStream::SetRapiStat Sets the value of the timeout value for the IStream::Read method.
IRAPIStream::GetRapiStat Gets the current value of the timeout for the IStream::Read method.

Remarks

The SetRapiStat and GetRapiStat methods are modeled after the IStream::Stat method.

Requirements
