Registering a File Extension Type

Windows CE Explorer, like Windows Explorer, lets you customize a type name, as displayed in the details view of Windows Explorer, and an icon for any file extension (for example, .pwd).

File filters are registered under HKEY_CLASSES_ROOT.

HKEY_CLASSES_ROOT\.file-extension
    \(Default) = classname
HKEY_CLASSES_ROOT\classname
    \(Default) = <name displayed in Explorer Type column>
    \DefaultIcon = <file name or index of icon for this type>
