Silent Mode Setup for ActiveSync

System administrators often need to install applications with a specific configuration, without requiring user intervention. The ActiveSync Setup program provides automated installation and configuration through Silent Mode Setup, which includes the following features:

  • Can be run by a single command, without further user interaction.
  • Can use a configuration file located anywhere on the local machine or network to control the setup process.
  • Supports status and error logging.
  • Supports System Management Server versions 1.2 and 2.0.
  • Supports both new installations and upgrades from previous versions of WCES.

There are several limitations, however.

  • Other applications on the ActiveSync 3.0 CD are not supported in Silent Mode.
  • Uninstall for ActiveSync 3.0 does not support Silent Mode — there is no Silent Uninstall.
  • If you installed a previous version of WCES using the unattended installation feature, the scripts you used previously are not compatible with ActiveSync 3.0 Silent Mode Setup.
  • If you are using System Management Server, the System Management Server version number must be 1.2 (with Service Pack 3) or later.
  • If using System Management Server 1.2, user systems running Windows 95 and later must have the user logged off before Setup.
  • If using System Management Server 1.2, user systems running Microsoft Windows NT® must have the user logged on before Setup.
    Note   Microsoft System Management Server is not required to run ActiveSync Silent Mode Setup.
