Understanding Partnerships

When a user connects a Windows CE–based device to a desktop computer for the first time, ActiveSync creates a partnership, which describes what information is updated and created by ActiveSync when a user initially connects a Windows CE–based device to a desktop computer. When ActiveSync sets up a partnership, the user can specify which service provider providers are active. For example, a user can choose to synchronize the Calendar, Contacts, and Tasks each time the device is connected to the desktop computer.

The New Partnership dialog box lists applications on the device and the desktop computer that have a service provider. Marking or clearing the check box next to a pair of applications enables or disables the corresponding service provider. If a service provider is enabled, the Settings button is available and a user can click it to change synchronization settings for that service provider.
