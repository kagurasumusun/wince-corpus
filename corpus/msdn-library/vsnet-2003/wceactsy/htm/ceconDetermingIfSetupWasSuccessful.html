Determining if the Setup was Successful

ActiveSync writes to the Wcesetup.log file during setup, whether normal or silent. The file records what occurred, including errors and whether setup completed successfully. This log file is created in a temporary directory.

If setup is successful, Wcesetup.log is copied to the directory in which ActiveSync is currently installed. If setup fails, the file is copied to the directory specified by the TMP environment variable.

Reinstalling or upgrading ActiveSync overwrites the log. Deleting ActiveSync deletes it.

Note   You can find the ActiveSync installation directory in the HKEY_LOCAL_MACHINE\Software\Microsoft\Windows CE Services\InstalledDir registry key.

The following table describes the three types of messages ActiveSync places in Wcesetup.log.

Message Description
ERROR Some condition prevents Setup from continuing, such as not enough disk space, incorrect OS, or a minimum requirement not met. Setup places an ERROR message in the log prior to exiting.
WARNING Setup has experienced a non-fatal problem. The WARNING message alerts the administrator to take preventative measures so that later silent setups will not run into problems.
STATUS Setup adds a STATUS message for every step in the setup. The STATUS message informs the administrator about the entire setup process.
