Enumerating Device Objects

Enumerating objects on a device differs from enumerating objects on a desktop. In contrast to desktop enumeration, the service manager enumerates each object and calls the ObjectNotify function of each device provider when a user connects a device. If an object on a device needs synchronizing, the device provider must inform the service manager.
