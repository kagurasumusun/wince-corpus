Handling Initialization Errors

Error messages during service provider initialization should be implemented, but shown only if the synchronization engine has set BSF_SHOW_FATAL_ERRORS. While ActiveSync is initializing a service provider, the service provider should display these error messages as errors occur. ActiveSync cannot dynamically reinitialize a service provider until the user disconnects and reconnects the device, so the user cannot recreate the error message.

When the user invokes the Resolve Items command, ActiveSync first prompts the user to disconnect and reconnect the device. This reinitializes all service providers, in effect retrying them. During this reinitialization, the service provider can again generate its error message. These error messages should be formatted as shown for the synchronization errors.
