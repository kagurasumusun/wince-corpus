Initialization and Termination

InitObjType is called to both initialize and terminate the device ActiveSync provider. If the ActiveSync provider supports synchronization of multiple object types, InitObjType will be called once for each object type, with the given lpszObjType non-NULL. When ActiveSync terminates, the given lpszObjType is NULL and the ActiveSync provider should release any resources it allocated.

ActiveSync supports synchronizing two desktop computers with a Windows CE–based device by using "partner bits." The ActiveSync manager passes a partner bit to InitObjType when initializing an ActiveSync provider. This bit is 1 if the connected desktop PC is the first partner and 2 if it is the second partner. ActiveSync providers can use these partner bits to determine whether an object is "dirty" (changed) with respect to the specific active partnership.
