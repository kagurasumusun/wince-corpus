Writing the Desktop StockPor Provider

The StockPor ActiveSync desktop provider is implemented as Stsync.dll. This DLL exposes two COM interfaces, IReplStore and IReplObjHandler. Although an ActiveSync provider can synchronize multiple object types, the sample code supports synchronization of only one object type, StockPor.
