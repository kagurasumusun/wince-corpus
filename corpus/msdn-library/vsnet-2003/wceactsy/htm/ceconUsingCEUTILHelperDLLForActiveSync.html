Using the CEUTIL Helper DLL for ActiveSync

You can use the CEUTIL DLL to manage desktop registry entries for ActiveSync. CEUTIL encapsulates the top-level registry locations to ensure forward-compatibility. It also provides helper functions for browsing device partnerships and querying the settings for the currently connected or selected device. This DLL is compatible with and a replacement for the Microsoft Win32® registry API that is used when referring to subkeys under the ActiveSync root.

Use CEUTIL to perform the following tasks:

  • Register desktop file filters
  • Register desktop synchronization services
  • Access device partnership settings that are used for both file filters and synchronization services
  • Add custom menu items
