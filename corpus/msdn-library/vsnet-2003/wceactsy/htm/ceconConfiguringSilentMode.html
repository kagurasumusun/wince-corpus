Configuring Silent Mode

This section describes how to run ActiveSync Setup in Silent Mode from the command line, how to run Silent Mode using System Management Server, and how to create a silent mode .ini file.

Silent Mode behavior is controlled by the Silent.ini file, which contains the setup options. The following code sample describes a simple Silent.ini file.

; Settings for silent install
[ActiveSync]
InstallDir = %ProgramFilesDir%\Microsoft ActiveSync
UsePreviousPort = 1
CommPort =
ResetRasServerPorts = 1
DesktopIcon = 1
Reboot = 1

The file structure is the same as a Windows INI file, and uses the following syntax:

  • Lines that start with a semicolon (;) are treated as comments.
  • Sections begin with a name in brackets. The Silent.ini file contains only the [ActiveSync] section.
  • Within sections, "Setting = Value" statements answer questions that would normally appear during setup.

A Silent.ini file contains six settings. A setting can have no value, such as the CommPort setting in the above example. In such cases ActiveSync uses the default value.

InstallDir %ProgramFilesDir%\Path or %SystemDrive%\Path or Path

The InstallDir setting describes where Setup should place the ActiveSync 3.0 files. Setup replaces %ProgramFilesDir% with the path to the Program Files directory of the Windows disk, such as "C:\Program Files". ActiveSync replaces %SystemDrive% with the drive letter of the Windows Disk, such as "C:" Path can be any directory. Setup creates the directory if it does not exist. If you do not set a value, Setup defaults to %ProgramFilesDir%\ActiveSync. Setup ignores the InstallDir setting if ActiveSync or WCES is already installed on the user's system and uses the existing directory instead.

UsePreviousPort 1 or 0

The UsePreviousPort setting controls whether Setup should use an existing COM port setting, if a setting exists. 1 is yes, 0 is no. The default value is 1. Setup ignores UsePreviousPort if ActiveSync or WCES is already installed on the user's system.

CommPort COM1 or COM2 or COM3 or COM4

The CommPort setting controls which COM port ActiveSync should check for devices. By default, no COM port is selected. ActiveSync 3.0 uses the port declared in previous versions of ActiveSync. Setup ignores CommPort if UsePreviousPort is 1, ActiveSync or WCES is already installed, and a COM port was previously set.

ResetRasServerPorts 1 or 0

The ResetRasServerPorts setting controls whether Setup should reset the COM ports used by RAS. 1 is yes, 0 is no. The default value is 1. Setup ignores ResetRasServerPorts if the CommPort setting is non-empty, or if Setup finds a previously-declared port.

DesktopIcon 1 or 0

The DesktopIcon setting declares if Setup should put a shortcut to ActiveSync on the user's desktop. 1 is yes, 0 is no. The default value is 1.

Reboot 1 or 0

The Reboot setting controls whether Setup should reboot the machine. 1 is yes, 0 is no. The default value is 1. If 0, ActiveSync will not force a reboot. However, the user may still require a reboot. The setup log will show if a reboot is necessary.
