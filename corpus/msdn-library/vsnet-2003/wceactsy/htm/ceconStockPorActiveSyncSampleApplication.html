StockPor ActiveSync Sample Application

The Windows CE Software Development Kit (SDK) provides the StockPor sample application that shows how ActiveSync service providers are developed. StockPor includes the following files.

Directory File name Description
  stockpor.cpp Source file shared by both desktop and device application.
  common.h Header file for structures and constants shared by the application and the ActiveSync provider.
  resource.h Header file for resource constants
  stockpor.rc Resource file shared by both desktop and device application.

for the desktop application

  stockpor.ico Desktop application icon file
  stocks.cpp The rest of desktop application source code.

for ActiveSync service provider's desktop component

  mainmod.cpp Header file for classes, structures and constants

for ActiveSync service provider's device component

  stdevs.cpp Source file that implements the ActiveSync device component.

StockPor tracks stock holdings. It runs with the same user interface on both desktop PCs and CE-based devices. The ActiveSync service provider is implemented such that changes or deletions made on either machine can be synchronized continuously while the device is linked to the desktop.

The object type is named "Stock." After the ActiveSync service provider is installed in Windows CE Services, Stock appears in the ActiveSync status window the same way Appointment or Task is displayed for Microsoft Outlook.

The desktop and device applications share much of the user-interface code. Platform-dependent code and data are separated into the CStock class, which is defined differently for the desktop and the device, as illustrated in the following code from stockpor.cpp.

// define class CStocks
#ifdef UNDER_CE
   #include "device\stocks.h"
#else
   #include "desktop\stocks.h"
#endif

The CStore class defines many platform dependent methods.

Method Description
BOOL Open (LPSTR lpszFile, BOOL fFailOnNew) Open the stock portfolio database.
BOOL SetupDlg (HWND hDlg, UINT uParam) Setup dialog box for user to change stock data.
BOOL Add (HWND hDlg ) Add a new stock.
BOOL Change (HWND hDlg, UINT uParam) Change the stock data.
void Delete (UINT uParam) Delete the selected stock.
void OnDataChange (void) Called whenever stock data is changed.
BOOL BeforeAddChg (void) Called before a stock is about to be added or changed.

Similarly, desktop methods are in desktop\stocks.cpp and device methods are in device\stocks.cpp.
