IEnumReplItem::Reset

This method resets the enumeration sequence to the beginning.

HRESULT Reset();

Parameters

None.

Return Values

Value Description
S_OK The enumeration sequence was reset to the beginning
S_FALSE The enumeration sequence was not reset to the beginning.

Requirements
