SPVCONTEXT

SPVCONTEXT contains strings passed into an ISpVoice::Speak call through a <Context> XML tag. See the XML Schema : SAPI whitepaper for more details.

typedef [restricted] struct SPVCONTEXT{
LPCWSTR  pCategory;
LPCWSTR  pBefore;
LPCWSTR  pAfter;
} SPVCONTEXT;

Members

pCategory
String passed in with the identifier attribute.
pBefore
String passed in with the Before attribute.
pAfter
String passed in with the After attribute.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.1 and later Sapi.idl Sapi.h
