SpFindBestToken

SpFindBestToken enumerates the token category and finds the single best match (if any) based on the required and optional attributes.

Found in: sphelper.h 

SpFindBestToken(
const WCHAR *pszCategoryId, 
const WCHAR *pszReqAttribs, 
const WCHAR *pszOptAttribs, 
ISpObjectToken **ppObjectToken
);

Parameters

pszCategoryId
[in] The string CategoryId on which to base the enumerations.
pszReqAttribs
[in] The string of the required attributes for the token.
pszOptAttribs
[in] The string of the optional attributes for the token. The order in which the tokens are listed in ppObjectToken is based on the order they match pszOptAttribs.
ppObjectToken
[out] The single best matched token found.

Return Values

Value Description
S_OK Function completed successfully.
SPERR_NOT_FOUND No items match the given attributes.
FAILED (hr) Appropriate error message.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.1 and later Sphelper.h
