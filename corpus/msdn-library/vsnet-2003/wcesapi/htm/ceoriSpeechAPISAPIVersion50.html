Speech API (SAPI) Version 5.0

The Microsoft® Speech SDK 5.0 is the developer kit for the Microsoft® Windows environment. Tools, information, and sample engines and applications are provided to help you integrate and optimize your speech recognition and speech synthesis engines with the new Microsoft Speech API 5.0 (SAPI 5.0).

Redistribution Code Rights

Read and understand the Redistributable Code Rights before building applications or engines. This document outlines which files can be redistributed with our own products. It also describes limitations for modifying the Speech SDK 5.0 files and samples.
