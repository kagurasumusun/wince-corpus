SPDISPLAYATTRIBUTES

These attributes can be used to properly format the display text of phrase elements.

typedef enum tagSPDISPLYATTRIBUTES{
SPAF_ONE_TRAILING_SPACE = 0x02,
SPAF_TWO_TRAILING_SPACES = 0x04,
SPAF_CONSUME_LEADING_SPACES = 0x08,
SPAF_ALL = 0x0F // Used internally for parameter validation
} SPDISPLAYATTRIBUTES;

Elements

SPAF_ONE_TRAILING_SPACE
Inserts one trailing space, used for most words.
SPAF_TWO_TRAILING_SPACES
Insert two trailing spaces, often used after a sentence final '.' .
SPAF_CONSUME_LEADING_SPACES
Consume leading space, often used for '.' . If this is absent then the word should have a leading space by default.
SPAF_ALL
A combination of all the above flags.
