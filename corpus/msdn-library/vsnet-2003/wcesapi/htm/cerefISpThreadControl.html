ISpThreadControl

The ISpThreadControl interface inherits from the ISpNotifySink interface.

Method Description
ISpThreadControl::ExitThreadEvent Returns the event passed to the ISpThreadTask::ThreadProc method.
ISpThreadControl::NotifyEvent Returns the Win32 event handle that will be set when the Notify() method is called.
ISpThreadControl::StartThread Initializes a thread and returns a window handle.
ISpThreadControl::TerminateThread Forces immediate termination of the thread.
ISpThreadControl::ThreadCompleteEvent Returns an event that the client can use to wait until the thread processing has completed.
ISpThreadControl::ThreadHandle Returns the thread handle of the allocated thread.
ISpThreadControl::ThreadId Returns the thread identifier of the allocated thread.
ISpThreadControl::WaitForThreadDone Specifies the time interval to wait before ending thread processing.
ISpThreadControl::WindowHandle Returns the window handle associated with the thread.
