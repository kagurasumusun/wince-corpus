ISpSREngineSite

The interface ISpEngineSite is implemented by SAPI and is called by the SR engine. It is used used by the SR engine to get audio data, retrieve grammar information, send event events, and return recognition information to SAPI.

Implemented By

SAPI. Applications or engines do not implement this method.

Created By

SAPI. The SR engine obtains a pointer to this interface when the ISpSREngine::SetSite is called, after SAPI creates the SR engine.

Method Description
ISpSREngineSite::AddEvent Sends an event to SAPI.
ISpSREngineSite::DataAvailable Retrieves the amount of data that can be read using ISpSREngineSite::Read without blocking.
ISpSREngineSite::GetContextMaxAlternates Passes back the maximum number of alternates that should be generated for the specified recognition context.
ISpSREngineSite::GetMaxAlternates Passes back the maximum number of alternates that should be generated for the specified rule.
ISpSREngineSite::GetResource Retrieves a named resource from a grammar.
ISpSREngineSite::GetRuleInfo Retrieves information about a CFG rule.
ISpSREngineSite::GetStateInfo Retrieves information on the transitions from a CFG state.
ISpSREngineSite::GetTransitionProperty Retrieves semantic property information for a transition in a grammar.
ISpSREngineSite::GetWordInfo Retrieves information about a CFG word.
ISpSREngineSite::IsAlternate Determines whether one rule is a valid alternate of another.
ISpSREngineSite::ParseFromTransitions Produces an ISpPhraseBuilder result from a list of transitions.
ISpSREngineSite::Read Reads audio data from the input stream.
ISpSREngineSite::Recognition Returns a recognition result (final, partial, or false) to SAPI.
ISpSREngineSite::SetBufferNotifySize Sets the amount of data to be available before data available event is set.
ISpSREngineSite::SetRuleClientContext Sets an engine-defined pointer on a CFG rule.
ISpSREngineSite::SetWordClientContext Sets an engine-defined pointer on a CFG word.
ISpSREngineSite::Synchronize Informs SAPI that the engine is ready process changes in its grammars.
ISpSREngineSite::UpdateRecoPos Returns the current position of the recognizer in the stream.
