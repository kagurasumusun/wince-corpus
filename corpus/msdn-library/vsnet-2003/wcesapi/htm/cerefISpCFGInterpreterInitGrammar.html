ISpCFGInterpreter::InitGrammar

ISpCFGInterpreter::InitGrammar initializes a grammar that is loaded from an object or DLL.

HRESULT InitGrammar(
const WCHAR *pszGrammarName,
const void **pvGrammarData
);

Parameters

pszGrammarName
[in] Address of a null-terminated string of the grammar to be loaded.
pvGrammarData
[in] Address of a pointer to the serialized binary grammar.

Return Values

Value Description
S_OK Function completed successfully.
FAILED(hr) Appropriate error message.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.1 and later Sapiddk.idl Sapiddk.h
