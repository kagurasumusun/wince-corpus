ISpCFGInterpreter::Interpret

ISpCFGInterpreter::Interpret examines a grammar and generates new properties and text replacements.

HRESULT Interpret(
ISpPhraseBuilder *pPhrase,
const ULONG ulFirstElement,
const ULONG ulCountOfElements,
ISpCFGInterpreterSite *pSite
);

Parameters

pPhrase
[in] Address of the ISpPhraseBuilder interface containing the phrase information.
ulFirstElement
[in] Value specifying the location on the first element in pPhrase.
ulCountOfElements
[in] Value specifying the number of phrase elements in pPhrase.
pSite
[in] Address of the ISpCFGInterpreterSite interface containing which can be used to attach semantic properties or text replacements to the parent phrase.

Return Values

Value Description
S_OK Function completed successfully.
FAILED(hr) Appropriate error message.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.1 and later Sapiddk.idl Sapiddk.h
