ISpThreadControl::TerminateThread

ISpThreadControl::TerminateThread forces immediate termination of the thread.

This function should be used with caution, as unintended results can occur. This method should only be used to force a thread to stop when all other attempts to stop this thread have been unsuccessful.

HRESULT TerminateThread ( void );

Parameters

None.

Return Values

Value Description
S_OK Function completed successfully.
