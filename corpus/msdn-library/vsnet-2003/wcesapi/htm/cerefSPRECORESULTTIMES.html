SPRECORESULTTIMES

SPRECORESULTTIMES contains the time information for speech recognition. This data structure is used by the ISpRecoResult::GetResultTimes method.

typedef struct SPRECORESULTTIMES{
FILETIME ftStreamTime;
ULONGLONG ullLength;
DWORD dwTickCount;
ULONGLONG ullStart;
} SPRECORESULTTIMES;

Members

ftStreamTime
Number of 100 nanosecond units in universal time coordinate (UTC) time from January 1, 1601 to the start of the current result. This is the same as calling the Win32 GetSystemTimeAsFileTime() function for the result.
ullLength
Value containing the length of the phrase specified in 100 nanosecond units.
dwTickCount
Number of 100 nanosecond units elasped from the start of the system to the start of the current result.
ulStart
Value containing the total 100 nanosecond units from the start of the stream to the start of the phrase.
