ISpVoice

The ISpVoice interface enables an application to perform text synthesis operations. Applications can speak text strings and text files, or play audio files through this interface. These can be done synchronously or asynchronously.

Applications can choose a specific TTS voice using the ISpVoice::SetVoice method. The state of the voice (for example, rate, pitch, and volume), can be modified using SAPI XML tags that are embedded into the spoken text. Some attributes, like rate and volume, can be changed in real time using the ISpVoice::SetRate and ISpVoice::SetVolume methods. Voices can be set to different priorities using the ISpVoice::SetPriority.

ISpVoice inherits from the ISpEventSource interface. An ISpVoice object forwards events back to the application when the corresponding audio data has been rendered to the output device.

Methods

Method Description
ISpVoice::DisplayUI Displays the requested UI.
ISpVoice::GetAlertBoundary Retrieves the event that is currently being used as the insertion point for alerts.
ISpVoice::GetOutputObjectToken Retrieves the object token for the current output object.
ISpVoice::GetOutputStream Retrieves a pointer to the current output stream.
ISpVoice::GetPriority Retrieves the current voice priority level.
ISpVoice::GetRate Retrieves the current text rendering rate adjustment.
ISpVoice::GetStatus Retrieves the current rendering and event status associated with this ISpVoice instance.
ISpVoice::GetSyncSpeakTimeout Retrieves the timeout interval for synchronous speech operations for this ISpVoice instance.
ISpVoice::GetVoice Retrieves the object token that identifies the voice used in text synthesis.
ISpVoice::GetVolume Retrieves the current output volume level of the synthesizer.
ISpVoice::IsUISupported Determines if the specified type of UI is supported.
ISpVoice::Pause Pauses the voice at the nearest alert boundary and closes the output device.
ISpVoice::Resume Sets the output device to the RUN state and resumes rendering.
ISpVoice::SetAlertBoundary Specifies which event should be used as the insertion point for alerts.
ISpVoice::SetOutput Sets the current output object. A value of NULL can be used to select the default audio device.
ISpVoice::SetPriority Sets the priority for the voice. Normal, Alert, Over.
ISpVoice::SetRate Sets the text rendering rate adjustment in real time.
ISpVoice::SetSyncSpeakTimeout Sets the timeout interval in milliseconds after which, synchronous Speak and SpeakStream calls to this instance of the voice will timeout.
ISpVoice::SetVoice Sets the identity of the voice used for text synthesis. By default, the ISpVoice will use the voice information set in Control Panel.
ISpVoice::SetVolume Retrieves the current output volume level of the synthesizer.
ISpVoice::Skip Causes the voice to skip ahead the specified number of items within the current speak request.
ISpVoice::Speak Submits a string for rendering.
ISpVoice::SpeakCompleteEvent Returns an event handle that will be signaled when the voice has completed speaking all pending requests.
ISpVoice::SpeakStream Speaks the contents of a stream.
ISpVoice::WaitUntilDone Blocks the caller until either the voice has completed speaking or the specified time interval has elapsed.
