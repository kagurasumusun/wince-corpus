ISpPhrase

This is the main interface to access information contained in a phrase. It allows applications to retrieve recognition information such as the recognized [or hypothesized] text, the recognized rule, and semantic tag or property information. It also allows an application to serialize the phrase data to a stream, to enable persisting of recognitions to the disk, the network, or memory.

Methods

Methods Description
ISpPhrase::Discard Discards the requested data from the phraset.
ISpPhrase::GetPhrase Retrieves ::CoTaskMemAlloc'ed block of memory containing SPPHRASE, the data associated with this phrase.
ISpPhrase::GetSerializedPhrase Retrieves ::CoTaskMemAlloc'ed block of memory containing SPSERIALIZEDPHRASE, the serialized data associated with this phrase.
ISpPhrase::GetText Retrieves the display text of the elements from this phrase and constructs a ::CoTaskMemAlloc'ed string by applying the bDisplayAttributes of each SPPHRASEELEMENT.
