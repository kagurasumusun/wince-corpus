ISpSREngine

This is the main interface engine developers must implement to have a working SAPI SR engine. Engine vendors need to implement this interface in an INProc COM object with the threading model “Both”. This object can also implement the ISpObjectWithToken interface. SR engines can also have additional objects implementing ISpTokenUI, ISpSRAlternates, and a custom engine-extension object.

Full details on how an SR engine interacts with SAPI and how the methods of this interface are implemented is given in the SR Engine Guide in the white papers section of the help.

Applications do not directly call the methods on this interface, all calls are made by SAPI.

Implemented By

SR Engine developers as the main interface between their SR engine and SAPI.

How Created

Only SAPI will directly create this object. When an application creates a RecoContext object, either shared or InProc, then SAPI will find the appropriate recognizer object token and create the object implementing this interface from the CLSID in the object token.

ISpSREngine::GetPropertyNum Retrieves a numerical property attribute from the SR engine.
ISpSREngine::GetPropertyString Retrieves a text property attribute from the SR engine.
ISpSREngine::IsPronounceable Asks the engine if it is able to generate a pronunciation for a word.
ISpSREngine::LoadProprietaryGrammar Instructs the engine to load an engine specific grammar.
ISpSREngine::LoadSLM Instructs the engine to load a Dictation statistical language model (SLM).
ISpSREngine::OnCreateGrammar Informs the engine of the creation of a grammar.
ISpSREngine::OnCreateRecoContext Informs the engine of the creation of a recognition context.
ISpSREngine::OnDeleteGrammar Informs the engine of the deletion of a grammar
ISpSREngine::OnDeleteRecoContext Notifies the engine that a recognition context is being destroyed.
ISpSREngine::PrivateCall Engine-specific call to the engine.
ISpSREngine::PrivateCallEx Engine-specific call to the engine which allows data to be returned from the engine.
ISpSREngine::RecognizeStream Begins recognition processing on a stream.
ISpSREngine::RuleNotify Notifies the SR engine of the rule information in CFG grammars.
ISpSREngine::SetAdaptationData Provides text data for language model adaptation to the engine.
ISpSREngine::SetContextState Informs the engine if a recognition context has been activated or deactivated.
ISpSREngine::SetGrammarState Informs the engine if a grammar has been activated or deactivated.
ISpSREngine::SetPropertyNum Sets a numerical property attribute on the SR engine.
ISpSREngine::SetPropertyString Sets a text property attribute on the SR engine.
ISpSREngine::SetProprietaryRuleIdState Sets the proprietary grammar rule identifier state.
ISpSREngine::SetProprietaryRuleState Sets the proprietary grammar rule state.
ISpSREngine::SetRecoProfile Informs the engine of the current recognition profile token.
ISpSREngine::SetSite Sets the ISpSREngineSite interface for the engine to use.
ISpSREngine::SetSLMState Sets the recognition state of the SLM to active or inactive.
ISpSREngine::SetTextSelection Informs the engine of the displayed and selected areas of the text buffer.
ISpSREngine::SetWordSequenceData Sets the text buffer information.
ISpSREngine::UnloadProprietaryGrammar Instructs the engine to unload an engine specific grammar.
ISpSREngine::UnloadSLM Instructs the engine to unload an SLM.
ISpSREngine::WordNotify Notifies the SR engine of the words in CFG grammars.
