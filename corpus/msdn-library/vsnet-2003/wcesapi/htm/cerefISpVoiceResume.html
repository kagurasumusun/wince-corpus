ISpVoice::Resume

ISpVoice::Resume decrements the pause count (which is incremented by ISpVoice::Pause) if the voice is currently paused. If the pause count hits zero, attempts to reclaim the output device and resumes rendering. This method has no effect if the voice was not in a paused state.

HRESULT Resume (void);

Parameters

None.

Return Values

Value Description
S_OK Function completed successfully.
FAILED(hr) Appropriate error message.

Requirements
