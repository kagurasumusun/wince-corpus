ISpTTSEngineSite

The ISpTTSEngineSite interface is implemented by the SAPI SpVoice object. It is used to write audio data and events.

Note   The ISpTTSEngineSite interface inherits from ISpEventSink. This interface is where AddEvents and GetEventInterest can be found.
Method Description
ISpTTSEngineSite::CompleteSkip Notifies the SpVoice object that the last skip request has been completed and to pass it the results.
ISpTTSEngineSite::GetActions Queries the ISpVoice to determine what action(s) to perform.
ISpTTSEngineSite::GetRate Retrieves the base rate adjustment that should be used by the engine.
ISpTTSEngineSite::GetSkipInfo Retrieves the number and type of items to be skipped in the text stream.
ISpTTSEngineSite::GetVolume Retrieves the base volume level that should be used by the engine.
ISpTTSEngineSite::Write Sends output data (typically audio) to SAPI.
