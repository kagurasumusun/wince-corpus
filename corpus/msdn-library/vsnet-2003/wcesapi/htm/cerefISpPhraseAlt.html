ISpPhraseAlt

The ISpPhraseAlt interface is implemented on a phrase alternate object that can be obtained by calling the ISpRecoResult::GetAlternates method. The ISpPhraseAlt object is the interface that enables applications to retrieve alternate phrase information from an SR engine, and to update the SR engine's language model to reflect committed alternate changes.

Methods in Vtable Order

ISpPhraseAlt Methods Description
ISpPhrase Inherits from ISpPhrase and all those methods are accessible from an ISpPhraseAlt object.
ISpPhraseAlt::Commit Replaces a section of the parent phrase to which this alternate corresponds.
ISpPhraseAlt::GetAltInfo Retrieves data elements associated with an alternate phrase.
