ISpObjectWithToken

This interface is implemented by any object which is associated with an object token. When the method ISpObjectToken::CreateInstance is called on the object token, then SAPI will create the associated object. If this object implements ISpObjectWithToken then the SetObjectToken method will be called, passing in a reference to the object token. This allows an object to find out which object token is creating it, and to get or set data in the object token.

Applications do not need to implement this interface. A TTS or SR engine or custom audio device or lexicon may want to implement this interface to get access to the object token than they are associated with.

Implemented By

  • Applications do not implement this interface. An SR or TTS engine or any other object that is being created from an object token can implement this interface.
  • The following objects implement this interface currently in SAPI. The TTS and SR Engines shipped with the SAPI 5.0 also implement this interface.

    SpMMAudioEnum

    SpRecPlayAudio

    SpUnCompressedLexicon

    SpCompressedLexicon

How Created

SAPI creates the object implementing this interface when the ISpObjectToken::CreateInstance method is called.

Methods in Vtable Order

ISpObjectWithToken Methods Description
ISpObjectWithToken::GetObjectToken Retrieves an object token.
ISpObjectWithToken::SetObjectToken Binds the instance object to the specified token.
