SPRUNSTATE

This enumeration defines the voice running state.

typedef enum SPRUNSTATE{
SPRS_DONE = (1L << 0),
SPRS_IS_SPEAKING = (1L << 1) 
} SPRUNSTATE;

Elements

SPRS_DONE
The voice has completed processing all queued streams.
SPRS_IS_SPEAKING
The voice instance currently has the audio claimed.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.1 and later Sapi.idl Sapi.h
