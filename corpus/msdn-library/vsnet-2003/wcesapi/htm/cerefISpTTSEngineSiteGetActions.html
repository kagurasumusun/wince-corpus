ISpTTSEngineSite::GetActions

ISpTTSEngineSite::GetActions queries the SpVoice object to determine what real-time action(s) to perform. An engine should call this method frequently during the rendering process to be as responsive as possible. SAPI returns a DWORD indicating which action(s) contained in the SPVESACTIONS enumeration should be performed.

DWORD GetActions ( void );

Parameters

None.

Return values

DWORD containing one or more values from SPVESACTIONS specifying the action(s) to perform.
