ISpThreadTask::WindowMessage

ISpThreadTask::WindowMessage implements the processing of window messages. Not all applications will need a window and this method can be left unimplemented. If the caller of ISpThreadControl::StartThread passes a non-null HWND pointer then the client must implement this function and must also use a MessageWaitForMultipleObjects() loop in the ThreadProc.

virtual LRESULT STDMETHODCALLTYPE WindowMessage(
void *pvTaskData,
HWND hWnd,
UINT Msg,
WPARAM wParam,
LPARAM lParam
) = 0;

Parameters

pvTaskData
[in] Pointer passed to ISpTaskManager::CreateThreadControl.
hWnd
[in] A window handle.
Msg
[in] The type of window message.
wParam
Message-specific information. This will change based on the Msg value.
lParam
Message-specific information. This will change based on the Msg value.

Return Values

The return value is message specific.
