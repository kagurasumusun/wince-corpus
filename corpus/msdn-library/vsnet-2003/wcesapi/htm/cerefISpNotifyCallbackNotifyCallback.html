ISpNotifyCallback::NotifyCallback

ISpNotifyCallback::NotifyCallback is implemented by the client of the SpEventSource object. When this method is called, the wParam and lParam parameters are set to those specified by the client when it called the ISpNotifySource::SetNotifyCallbackInterface method. The client should examine the appropriate event source object for events.

HRESULT NotifyCallback(
WPARAM wParam,
LPARAM lParam
);

Parameters

wParam
[in] wParam parameter is specified by the client when it called the ISpEventSource::SetNotifyCallback interface.
lParam
[in] lParam parameter is specified by the client when it called the ISpEventSource::SetNotifyCallback interface.

Return Values

Clients should return S_OK. Other values can be used for debugging purposes, but will be ignored by SpEventSource objects.
