SPEVENT

SPEVENT contains information about an event. Events are passed from the TTS or SR engines or audio devices back to applications.

typedef [restricted] struct SPEVENT{
WORD eEventId;
WORD elParamType;
ULONG ulStreamNum;
ULONGLONG ullAudioStreamOffset;
WPARAM wParam;
LPARAM lParam;
} SPEVENT;

Members

elParamType
The parameter type of type SPEVENTLPARAMTYPE.
eEventId
The event identifier of type SPEVENTENUM.
ulStreamNum
The input stream number of associated with the event.
ullAudioStreamOffset
The byte offset into the audio stream associated with the event that the event was fired at. For synthesis, the output stream is the synthesized data. For recognition, this indicates the position in the input audio stream.
wParam
The generic word field. For event identifiers with the SPFEI_LPARAM_IS_POINTER set, this is the size, in bytes, for the data pointed to by lParam. In some cases, the type of event will change the function of this parameter. See SPEVENTENUM for information about specific events.
lParam
The generic event field. For event identifiers with the SPFEI_LPARAM_IS_POINTER set, this points to the data allocated by CoTaskMemAlloc. The caller is responsible for freeing this memory using CoTaskMemFree(). In some cases, the type of event will change the function of this parameter. See SPEVENTENUM for information about specific events.
