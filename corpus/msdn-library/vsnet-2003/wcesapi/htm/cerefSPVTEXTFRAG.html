SPVTEXTFRAG

SPVTEXTFRAG is the structure through which input text is passed to the TTS engine. The text passed to an ISpVoice::Speak call will typically be parsed for SAPI 5 XML, and the resulting list of SPVTEXTFRAGs will be passed to an ISpTTSEngine::Speak call.

typedef struct SPVTEXTFRAG{
struct SPVTEXTFRAG *pNext;
SPVSTATE State;
LPCWSTR pTextStart;
ULONG ulTextLen;
ULONG ulTextSrcOffset;
} SPVTEXTFRAG;

Members

pNext
Pointer to the next text fragment in list. NULL indicates the end of the list.
State
The current XML attribute state.
pTextStart
Pointer to the beginning of the string associated with this fragment.
ulTextLen
The length, in characters, of the string associated with this fragment.
ulTextSrcOffset
Original character offset of pTextStart within the string passed to ISpVoice::Speak.

Requirements
