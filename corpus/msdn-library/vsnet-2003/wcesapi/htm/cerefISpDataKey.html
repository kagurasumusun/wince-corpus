ISpDataKey

The ISpDataKey interface provides a mechanism for storing and retrieving string and other data. The main use for this interface is in conjunction with object tokens, which implement the ISpObjectToken interface, which inherits from this interface. For example, data can be stored in an object token representing a recognizer or TTS engine by using this interface.

Implemented By

  • SpObjectToken object. This is the standard class used for all existing SAPI object tokens. The data for each object token is stored in the registry.
  • SpDataKey object. This class stores the data associated with the data key in the registry.
  • Applications or engines can implement this interface directly if they want to provide a custom data key implementation.
