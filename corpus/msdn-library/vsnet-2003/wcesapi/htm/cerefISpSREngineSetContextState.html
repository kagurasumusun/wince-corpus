ISpSREngine::SetContextState

ISpSREngine::SetContextState is called by SAPI to indicate that a recognition context has been stopped or started by the application calling ISpRecoContext::SetContextState. When using standard CFG and Dictation grammars the engine may not need to take any account of the context state, as SAPI will automatically activate and deactivate the grammars contained in the context as necessary. When using proprietary grammars it may be necessary to look at this information, however.

HRESULT SetContextState(
void *pvEngineContext,
SPCONTEXTSTATE eContextState
);

Parameters

pvEngineContext
[in] Pointer to the engine's data for this context, as returned from a previous call to OnCreateRecoContext.
eContextState
[in] The SPCONTEXTSTATE enumeration value specifying the new recognition context state.

Return Values

Value Description
S_OK Function completed successfully.
FAILED (hr) Appropriate error message.
