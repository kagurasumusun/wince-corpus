SPSTREAMFORMAT

This enumeration aids the developer in avoiding subtle bugs introduced by typos. The enumeration can be used with the helper function SpConvertStreamFormatEnum and the helper class CSpStreamFormat. These helpers allow the developer, in most cases, to avoid creating a WAVEFORMATEX structure by hand, which can introduce subtle errors.

Elements

The enumeration elements contain a list of all common audio formats from the uncompressed PCM formats to the more highly compressed formats available as standard on the Windows operating systems that SAPI 5 is designed to run on.
