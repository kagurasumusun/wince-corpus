ISpTranscript

A transcript is a string associated with a piece of audio data. The SAPI SpStream object supports the ISpTranscript interface for wav audio files.

Associated Class IDs

The following class IDs (CLSID) can be used with this interface. A complete CLSID listing for all interfaces is in the Class IDs section.

  • CLSID_SpStream

Methods

Method Description
ISpTranscript::AppendTranscript Gets the current transcript.
ISpTranscript::GetTranscript Adds the current text to the transcript.
