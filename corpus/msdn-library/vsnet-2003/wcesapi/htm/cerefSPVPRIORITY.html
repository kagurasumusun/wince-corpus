SPVPRIORITY

This enumeration defines the priorities which voices can have.

typedef enum SPVPRIORITY{
SPVPRI_NORMAL = 0,
SPVPRI_ALERT = (1L << 0),
SPVPRI_OVER = (1L << 1)
} SPVPRIORITY;

Elements

SPVPRI_NORMAL
Normal priority.
SPVPRI_ALERT
Alert priority.
SPVPRI_OVER
Over priority - the voice should mix its audio with all other audio on the system with no synchronization.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.1 and later Sapi.idl Sapi.h
