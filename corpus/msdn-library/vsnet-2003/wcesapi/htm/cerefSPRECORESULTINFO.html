SPRECORESULTINFO

SPRECORESULTINFO is the result structure passed from the engine to SAPI.

typedef struct SPRECORESULTINFO{
ULONG cbSize;
SPRESULTTYPE ResultType;
BOOL fHypothesis;
BOOL fProprietaryAutoPause;
ULONGLONG ullStreamPosStart;
ULONGLONG ullStreamPosEnd;
SPGRAMMARHANDLE hGrammar;
ULONG ulSizeEngineData;
void *pvEngineData;
ISpPhraseBuilder *pPhrase;
} SPRECORESULTINFO;

Members

cbSize
Total size, in bytes, of this structure.
eResultType
Type of result object (CFG, SLM, or Proprietary).
fHypothesis
If TRUE then this recognition is a hypothesis.
fProprietaryAutoPause
This field is only used for SPERT_PROPRITARY grammars. If TRUE, the recognition will pause.
ullStreamPosStart
Starting position within the input stream.
ullStreamPosEnd
Ending position within the input stream.
hGrammar
Required for SPERT_SLM and SPERT_PROPRIETARY, otherwise this value is NULL
ulSizeEngineData
Specifies the size of pvEngineData.
pvEngineData
Pointer to the engine data.
pPhrase
Pointer to phrase object

Requirements
