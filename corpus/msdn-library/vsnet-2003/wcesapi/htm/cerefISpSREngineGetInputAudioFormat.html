ISpSREngine::GetInputAudioFormat

ISpSREngine::GetInputAudioFormat locates which audio formats the engine supports and whether the engine can support a particular format on not.

Audio formats in SAPI are described by two parameters: a GUID, and for wave formats, a WAVEFORMATEX structure.

The first two parameters in this method define the audio format that SAPI is asking the engine about. If these parameters are set to a specific format, then the engine should see if it can support this format, and return that format or the nearest format the engine can support in the second pair of parameters to this function. Alternatively, if the first two parameters are NULL, then the engine should return in the second pair of parameters its preferred audio format.

HRESULT GetInputAudioFormat(
const GUID *pguidSourceFormatId,
const WAVEFORMATEX *pSourceWaveFormatEx,
GUID *pguidDesiredFormatId,
WAVEFORMATEX **ppCoMemDesiredWaveFormatEx,
);

Parameters

pSourceFormatId
[in] The GUID of the audio format SAPI is asking the engine if it supports. This will either be NULL, indicating that the engine should select its preferred audio format, or will be set to a given format, which the engine should see if it can support.
pSourceWFEX
[in] Address of the WAVEFORMATEX structure containing information about the audio format SAPI is querying the engine about. This will only be set if pSourceFormatId is equal to SPDFID_WaveFormatEx.
pDesiredFormatId
[out] The GUID of the format that the engine can support.
ppCoMemDesiredWFEX
[out] For wave formats, the engine should CoTaskMemAlloc a WAVEFORMATEX structure and fill the details of the format it can support and then place the address of the structure in this parameter. For non-wave formats it should place NULL in this parameter.

Return Values

Value Description
S_OK Function completed successfully.
FAILED (hr) Appropriate error message.
