SPWORDTYPE

This enumeration specifies the change state of a word/pronunciation combination in a lexicon. It allows an engine to determine what word pronunciation changes have occurred because it last checked using the ISpLexicon::GetGenerationChange method.

typedef enum SPWORDTYPE{
eWORDTYPE_ADDED = (1L << 0),
eWORDTYPE_DELETED = (1L << 1)
} SPWORDTYPE;

Elements

eWORDTYPE_ADDED
The word has been added to the lexicon.
eWORDTYPE_DELETED
The word has been deleted from the lexicon.
