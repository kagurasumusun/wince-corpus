IspRecoGrammar

The ISpRecoGrammar interface enables applications to utilize manage the words and phrases that the SR engine will recognize.

A single SpRecognizer object can have multiple SpRecoContext objects associated with it. And similarly, a single SpRecoContext object can have multiple SpRecoGrammar objects associated with it. Using a one-to-many relationship with SpRecoContext objects and SpRecoGrammar objects allows applications to separate types of recognizable phrases and content into separate objects for clearer application logic. Each SpRecoGrammar object can also have a context-free-grammar and a Dictation grammar loaded simultaneously (for example, use the CFG if possible, but return to Dictation if CFG fails to parse).

See "Designing Grammar Rules" for examples of how to create context-free-grammars.

Methods in Vtable Order

ISpRecoGrammar Methods Description
ISpGrammarBuilderr Inherits from ISpGrammarBuilder and all those methods are accessible from an ISpRecoGrammar object.
ISpRecoGrammar::GetGrammarId Retrieves the grammar identifier associated with the application.
ISpRecoGrammar::GetGrammarState Retrieves recognition grammar state information.
ISpRecoGrammar::GetRecoContext Retrieves the context object that created this grammar.
ISpRecoGrammar::IsPronounceable Determines if the word has a pronunciation.
ISpRecoGrammar::LoadCmdFromFile Loads a Command and Control grammar from a file.
ISpRecoGrammar::LoadCmdFromMemory Loads a Command and Control grammar from memory.
ISpRecoGrammar::LoadCmdFromProprietaryGrammar Loads an engine proprietary format Command and Control grammar.
ISpRecoGrammar::LoadCmdFromResource Loads a Command and Control grammar from a Win32 resource.
ISpRecoGrammar::LoadDictation Loads and initializes a Dictation topic.
ISpRecoGrammar::SaveCmd Allows applications using dynamic grammars to save the current grammar state to a stream.
ISpRecoGrammar::SetDictationState Sets a Dictation state to active or inactive.
ISpRecoGrammar::SetGrammarState Sets the state of a grammar to either Disabled, Enabled, or Exclusive. Changing the state affects the state of all the active rules in the grammar.
ISpRecoGrammar::SetRuleIdState Activates or deactivates a rule by its RuleID.
ISpRecoGrammar::SetRuleState Activates or deactivates a rule by its RuleName.
ISpRecoGrammar::SetTextSelection Sets the insertion point (using word sequence data buffer).
ISpRecoGrammar::SetWordSequenceData Sets word sequence data used by <TEXTBUFFER>.
ISpRecoGrammar::UnloadDictation Unloads the active Dictation topic from the grammar.
