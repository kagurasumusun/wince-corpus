SPEVENTSOURCEINFO

A structure used by ISpEventSource::GetInfo to pass back event information. 

typedef struct SPEVENTSOURCEINFO{
ULONGLONG ullEventInterest;
ULONGLONG ullQueuedInterest;
ULONG ulCount;
} SPEVENTSOURCEINFO;

Members

ullEventInterest
Event identifier flags of type SPEVENTENUM marking events which invoke a notification.
ullQueuedInterest
Queue of event identifiers. These remain until ISpEventSource::GetEvents removes them.
ulCount
Number of events currently queued.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.1 and later Sapi.idl Sapi.h
