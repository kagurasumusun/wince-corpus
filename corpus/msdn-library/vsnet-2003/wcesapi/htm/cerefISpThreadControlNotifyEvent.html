ISpThreadControl::NotifyEvent

ISpThreadControl::NotifyEvent returns the event handle passed to the ISpThreadTask::ThreadProc method. This event will be set when the ISpThreadControl::NotifyEvent method is called.

HANDLE NotifyEvent ( void );

Parameters

None.

Return Values

Returns the event handle.
