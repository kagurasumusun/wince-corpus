ISpNotifySource::GetNotifyEventHandle

ISpNotifySource::GetNotifyEventHandle retrieves the Win32 event object handle. This event can be used in any of the Win32 WaitForxxx methods. Do not close the returned handle, as it is owned by the event source object. Calling this method will automatically initialize the event source to use an event handle if no other notification mechanism has been initialized.

HANDLE GetNotifyEventHandle (void);

Parameters

None.

Return Values

Value Description
Win32 event handle Initialized by SetNotifyWin32Event on this instance.
INVALID_HANDLE_VALUE Interface not initialized.
