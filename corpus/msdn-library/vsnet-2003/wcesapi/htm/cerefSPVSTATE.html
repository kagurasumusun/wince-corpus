SPVSTATE

SPVSTATE is a member of SPVTEXTFRAG, and contains information about the XML state associated with a string. A linked list of SPVTEXTFRAGs is passed into every ISpTTSEngine::Speak call after the SpVoice object has parsed the SAPI 5 XML passed into ISpVoice::Speak.

typedef [restricted] struct SPVSTATE{
SPVACTIONS eAction;
LANGID LangID;
WORD wReserved;
long EmphAdj;
long RateAdj;
ULONG Volume;
SPVPITCH PitchAdj;
ULONG SilenceMSecs;
SPPHONEID *pPhoneIds;
SPPARTOFSPEECH ePartOfSpeech;
SPVCONTEXT Context;
} SPVSTATE;

Members

eAction
Describes the action to be performed with the associated text fragment. The typical action is to Speak (SPVA_Speak) the fragment.
LangID
The language identifier associated with this text. Set through the <Lang> XML tag.
wReserved
Reserved for future use.
EmphAdj
Specifies whether the text should be emphasized - zero indicates no emphasis, one indicates emphasis. Set through the <Emph> XML tag.
RateAdj
The rate associated with this text. Set through the <Rate> XML tag. This value should be combined with the baseline rate (either the default, or a value set by ISpVoice::SetRate) to yield the final rate value.
Volume
The volume associated with this text. Set through the <Volume> XML tag. This value should be combined with the baseline volume (either the default, or a value set by ISpVoice::SetVolume) to yield the final volume value.
PitchAdj
The pitch associated with this text. Set through the <Pitch> XML tag.
SilenceMSecs
The length of a silence, in milliseconds, to be inserted into the audio output. SilenceMSecs is always 0 unless eAction is SPVA_Silence. Set through the <Silence> XML tag.
pPhoneIds
A pronunciation (possibly associated with text) to be inserted into the audio output. This value is a pointer to a null-terminated array of SPPHONEIDs. Set through the <Pron> XML tag.
ePartOfSpeech
An SPPARTOFSPEECH value to be associated with this text. Set through the <PartOfSp> XML tag.
Context
An SPVCONTEXT to be associated with this text. Set through the <Context> XML tag.
