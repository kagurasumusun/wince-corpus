SPEVENTLPARAMTYPE

This enumeration represents pointers to types of parameters.

typedef enum SPEVENTLPARAMTYPE{
SPET_LPARAM_IS_UNDEFINED = 0,
SPET_LPARAM_IS_TOKEN,
SPET_LPARAM_IS_OBJECT,
SPET_LPARAM_IS_POINTER,
SPET_LPARAM_IS_STRING,
} SPEVENTLPARAMTYPE;

Elements

SPET_LPARAM_IS_UNDEFINED
The SPEVENT.lParam value represents an undefined value.

For all TTS events, except SPEI_VOICE_CHANGE and SPEI_TTS_BOOKMARK, the event type is SPET_LPARAM_IS_UNDEFINED.

SPET_LPARAM_IS_TOKEN
The SPEVENT.lParam value represents a pointer to an ISpObjectToken object.

For example, the TTS voice change event (SPEI_VOICE_CHANGE) includes a pointer to the new voice's object token, so the lParam type is SPET_LPARAM_IS_TOKEN.

SPET_LPARAM_IS_OBJECT
The SPEVENT.lParam value represents a pointer to an object.

For example, the speech recognition even (SPEI_RECOGNITION) includes a pointer to the recognition result (ISpRecoResult), so the lParam type is SPET_LPARAM_IS_OBJECT.

SPET_LPARAM_IS_POINTER
The SPEVENT.lParam value represents a memory pointer.
SPET_LPARAM_IS_STRING
The SPEVENT.lParam value represents a pointer to a string.

For example, the TTS bookmark event (SPEI_TTS_BOOKMARK) includes a pointer the bookmark name, so the lParam type is SPET_LPARAM_IS_OBJECT.
