Winsock Secure Sockets

Windows CE supports the Private Communication Technology protocol 1.0 and Secure Sockets Layer (SSL) versions 2.0 and 3.0 security protocols. These protocols are available either through WinInet or directly from Winsock. Adding security to an application using these Winsock extensions requires few changes to an application. Once a secure socket is connected, the application may send and receive data on that socket unaware that the data over the wire is encoded.
