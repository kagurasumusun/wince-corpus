WPUOpenCurrentThread

This function opens a handle to the current thread that can be used with overlapped functions in a layered service provider. This is intended to be used by layered service providers that want to initiate overlapped I/O from non-application threads. This function is not supported in Windows CE .NET.

INT WPUOpenCurrentThread(
LPWSATHREADID lpThreadId,
LPINT lpErrno 
);

Parameters

lpThreadId
[out] Pointer to a WSATHREADID structure that can then be passed to an overlapped function.
lpErrno
[out] Pointer to the error code.

Return Values

This function always returns SOCKET_ERROR.

Error Codes

Error value Description
WSANOTINITIALISED A successful WSPStartup call must occur before using this function.

Remarks

This function is not supported in Windows CE .NET.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Ws2spi.h
