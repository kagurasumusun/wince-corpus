gethostbyaddr Function

The WSALookupServiceBegin query uses SVCID_INET_HOSTNAMEBYADDR as the service class GUID. The host address is supplied in lpszServiceInstanceName as a dotted Internet string (for example, "192.9.200.120"). Ws2.dll specifies LUP_RETURN_BLOB and the NSP places a hostent structure in the BLOB (using offsets instead of pointers as described above). NSPs should honor these other LUP_RETURN_* flags as well.

Flag Description
LUP_RETURN_NAME Returns the h_name parameter from hostent structure in lpszServiceInstanceName.
LUP_RETURN_ADDR Returns addressing information from hostent in CSADDR_INFO structures, port information is defaulted to zero.
