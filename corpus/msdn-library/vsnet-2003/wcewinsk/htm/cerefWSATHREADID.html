WSATHREADID

This structure enables a provider to identify a thread on which asynchronous procedure calls (APCs) can be queued using the WPUQueueApc function.

typedef struct _WSATHREADID {
HANDLE ThreadHandle;
DWORD Reserved;
} WSATHREADID, *LPWSATHREADID;

Members

ThreadHandle
Handle to the thread identifier.
Reserved
Reserved.
