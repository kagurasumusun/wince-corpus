WPUCloseSocketHandle

This function closes an existing socket handle.

int WPUCloseSocketHandle(
SOCKET s,
LPINT lpErrno 
);

Parameters

s
[in] Handle to socket created with WPUCreateSocketHandle.
lpErrno
[out] Pointer to the error code.

Return Values

If no error occurs, WPUCreateSocketHandle returns zero. Otherwise, it returns SOCKET_ERROR, and a specific error code is available in lpErrno.

Error value Description
WSAENOTSOCK Descriptor is not a socket created by WPUCreateSocketHandle.

Remarks

The WPUCloseSocketHandle function closes an existing socket handle created by WPUCreateSocketHandle. This function removes the socket from the internal socket table of Ws2_32.dll. The owning service provider is responsible for releasing any resources associated with the socket.
