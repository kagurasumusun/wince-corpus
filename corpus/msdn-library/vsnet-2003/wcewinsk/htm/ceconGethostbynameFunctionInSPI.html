gethostbyname Function in the SPI

The WSALookupServiceBegin query uses SVCID_INET_HOSTADDRBYNAME as the service class GUID. The host name is supplied in lpszServiceInstanceName. Ws2.dll specifies LUP_RETURN_BLOB and the NSP places a hostent structure in the BLOB (using offsets instead of pointers as described previously). NSPs should honor these other LUP_RETURN_* flags as well.

Flag Description
LUP_RETURN_NAME Returns the h_name member from hostent structure in lpszServiceInstanceName.
LUP_RETURN_ADDR Returns addressing information from hostent in CSADDR_INFO structures, port information is defaulted to zero. Note that this routine does not resolve host names consisting of a dotted internet address.
