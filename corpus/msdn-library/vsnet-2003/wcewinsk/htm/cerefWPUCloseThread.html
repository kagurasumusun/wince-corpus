WPUCloseThread

This function closes a thread opened with a call to WPUOpenCurrentThread. This function is not supported in Microsoft Windows CE .NET operating system (OS).

INT WSPAPI WPUCloseThread(
LPWSATHREADID lpThreadId,
LPINT lpErrno 
);

Parameters

lpThreadId
[in] Pointer to a WSATHREADID structure that identifies the thread context. This structure must have been initialized by a previous call to WPUOpenCurrentThread.
lpErrno
[out] Pointer to the error code.

Return Values

This function always returns SOCKET_ERROR.

Error value Description
WSANOTINITIALISED A successful WSPStartup call must occur before using this function.

Remarks

This function is not supported in Windows CE .NET.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Ws2spi.h
