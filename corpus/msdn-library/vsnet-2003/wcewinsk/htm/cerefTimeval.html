timeval

This structure is used to specify time values. It is associated with the Berkeley Software Distribution (BSD) file Time.h.

struct timeval {
long tv_sec;
long tv_usec;
};

Members

tv_sec
Time value, in seconds.
tv_usec
Time value, in microseconds.
