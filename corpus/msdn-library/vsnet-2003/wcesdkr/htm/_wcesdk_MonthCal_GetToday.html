Microsoft Windows CE 3.0  

MonthCal_GetToday

This macro retrieves the date information for the date specified as “today” for a month calendar control.

BOOL MonthCal_GetToday(HWND hwndMC, 
LPSYSTEMTIME lpToday );

Parameters

hwndMC
Handle to a month calendar control.
lpToday
Long pointer to a SYSTEMTIME structure that will receive the date information.

Return Values

Nonzero indicates success. Zero indicates otherwise.

Remarks

Related message: MCM_GETTODAY

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h   Commctrl.lib
