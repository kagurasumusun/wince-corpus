IntToWstr

Converts a given integer value to a wide string representation. 

void IntToWstr(
int i,
LPWSTR wstrDest);

Parameters

i
Integer value to be converted.
wstrDest
LPWSTR that will contain the resulting wide string.

Return Values

No return value.
