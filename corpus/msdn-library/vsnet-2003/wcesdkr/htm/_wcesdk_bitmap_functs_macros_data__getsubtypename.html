GetSubtypeName

Retrieves the name for a given GUID subtype. 

TCHAR * GetSubtypeName(
const GUID *pSubtype);

Parameters

pSubtype
Pointer to a GUID for a given video subtype.

Return Values

Returns the debug name of this GUID, or UNKNOWN if the name is not known.
