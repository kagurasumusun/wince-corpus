Microsoft Windows CE 3.0  

SCardForgetReader

This function removes a previously introduced reader from control by the smart card subsystem. It is removed from the smart card database, including from any reader group to which it may have been added.

LONG SCardForgetReader(
IN SCARDCONTEXT hContext, 
IN LPCTSTR szReaderName );

Parameters

hContext
Handle to the resource manager context. The resource manager context is set by a previous call to SCardEstablishContext.
szReaderName
Null-terminated string that contains the friendly name of the reader to be removed from the smart card database.

Return Values

Value Description
Succeeds SCARD_S_SUCCESS
Fails An error value (see Smart Card Error values for a list of all error values)

Remarks

SCardForgetReader is a database management function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Winscard.h   Winscard.lib
