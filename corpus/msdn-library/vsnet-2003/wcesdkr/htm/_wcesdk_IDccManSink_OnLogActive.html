Microsoft Windows CE 3.0  

IDccManSink::OnLogActive

This method indicates that a connection is established between the client application and the connection manager.

STDMETHODIMP IDccManSink::OnLogActive( void );

Return Values

This method should always return NOERROR.

Remarks

The IDccManSink::OnLogActive method is implemented by a client application and is called when a socket connection is established between the client application and the connection manager.

When this notification occurs, the Windows CE connection manager starts any applications that are registered with the registry key HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\AutoStartOnConnect.

During this notification is a good time for the client application to initialize the remote application programming interface (RAPI) by calling the RAPI function CeRapiInit. A call to CeRapiInit does not return until a connection is established between the desktop computer and the Windows CE–based device.

For more information, see Invoking Functions from a Desktop Computer.
