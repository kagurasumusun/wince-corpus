asp Module

The asp module supports the implementation of Active Server Pages (ASP). ASP provides an open application environment in which you can combine HTML pages, scripts, and ActiveX components to create Web-based applications. The asp module exposes no public functions.

Components

The asp module contains the following components.

Component Description Notes Library
ASPCOLCT Collection of ASP objects. Exposes no public functions. Aspcolct.lib
ASPCORE Required component for all configurations. Exposes no public functions.  
ASPPARSE Supports header files and ASP preprocessor directives. Exposes no public functions. Aspparse.lib
