Microsoft Windows CE 3.0  

ErrorDescription

Retrieves a value specifying the description of the current error state.

Compatibility: Windows Media Player

[ "sError" = ] MediaPlayer.ErrorDescription

Parameters

sError
String value specifying the description of the current error state. This property is read-only with no default value.
