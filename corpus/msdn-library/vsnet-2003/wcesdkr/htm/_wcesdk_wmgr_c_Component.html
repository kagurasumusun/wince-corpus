wmgr_c Component

The wmgr_c component implements the window manager.

Functions for Application Developers

The wmgr_c component includes the following functions for application developers, which are defined in the Winuser.h header file. To import these functions, you need to link to the wmgr_c.lib file.

Function
EnableWindow
GetClassInfo
GetMouseMovePoints
GetSysColor
IsWindowEnabled
Mouse_event
RegisterClass
SendInput
UnregisterClass
