Microsoft Windows CE 3.0  

CharPrev

This function returns a pointer to the preceding character in a string. 

LPTSTR CharPrev (
LPCTSTR lpszStart, 
LPCTSTR lpszCurrent 
);

Parameters

lpszStart
[in] Pointer to the beginning of the null-terminated string.
lpszCurrent
[in] Pointer to a character in a null-terminated string.

Return Values

A pointer to the preceding character in the string, or to the first character in the string if the lpszCurrent parameter equals the lpszStart parameter, indicates success.
