Microsoft Windows CE 3.0  

TabCtrl_GetItemRect

This macro retrieves the bounding rectangle for a tab in a tab control. You can use this macro or send the TCM_GETITEMRECT message explicitly.

BOOL TabCtrl_GetItemRect( 
HWND hwnd, 
int iItem, 
RECT FAR *prc );

Parameters

hwnd
Handle to the tab control.
iItem
Index of the tab.
prc
Pointer to a RECT structure that receives the bounding rectangle of the tab, in viewport coordinates.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
