Microsoft Windows CE 3.0  

SCardBeginTransaction

This function starts a transaction, waiting for the completion of all other transactions before it begins.

When the transaction starts, all other applications are blocked from accessing the smart card during the transaction.

LONG SCardBeginTransaction(
IN SCARDHANDLE hCard );

Parameters

hCard
Handle to the reference value obtained from a previous call to SCardConnect.

Return Values

Value Description
Succeeds SCARD_S_SUCCESS
Fails An error value (see Smart Card Error values for a list of all error values)

Remarks

SCardBeginTransaction is a smart card and reader access function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Winscard.h   Winscard.lib
