Microsoft Windows CE 3.0  

fsreg Component

The fsreg component provides support for the Windows CE registry.

Functions for Application Developers

The fsreg component includes the following functions for application developers, which are defined in the Winreg.h header file. To import these functions, you need to link to the fsreg.lib file.

Function
RegCloseKey
RegCreateKeyEx
RegDeleteKey
RegDeleteValue
RegEnumKeyEx
RegEnumValue
RegFlushKey
RegOpenKeyEx
RegQueryInfoKey
RegQueryValueEx
RegSetValueEx
