Microsoft Windows CE 3.0  

REGFILTERPINS2

Contains information for registering a filter through the IFilterMapper2 interface. 

typedef struct
{
DWORD dwFlags;
UINT  cInstances;
UINT  nMediaTypes; 
const REGPINTYPES * lpMediaType;
UINT  nMediums;
const REGPINMEDIUM *lpMedium;
const CLSID *clsPinCategory;
} REGFILTERPINS2;

Members

dwFlags
Combination of REG_PINFLAG flags.
cInstances
Number of instances of the pin, if known.
nMediaTypes
Number of media types supported by this pin.
lpMediaType
Array of nMediaTypes REGPINTYPES providing media type information.
nMediums
Number of mediums.
lpMedium
Array of REGPINMEDIUM containing medium information for each pin.
clsPinCategory
Pin category (for kernel streaming pins) as defined in the Windows NT DDK.
