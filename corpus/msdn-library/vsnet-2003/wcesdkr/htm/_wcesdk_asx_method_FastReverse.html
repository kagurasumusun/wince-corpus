Microsoft Windows CE 3.0  

FastReverse

Scans rapidly backward through the current presentation.

Compatibility: Windows Media Player

MediaPlayer.FastReverse( )

Return Values

No return value.

Remarks

This method performs the same action as the user holding down the fast-reverse button on the control bar. In an ASF file, you can also fast-reverse by stopping the clip, setting the Rate property to a negative value, and restarting the clip.
