Microsoft Windows CE 3.0  

RegisterEditor

This function allows a NAT editor to register with the NAT driver when a pointer to this function is passed to the EditorInitialize function.

NTSTATUS RegisterEditor( 
PIP_NAT_REGISTER_EDITOR RegisterContext )

Parameters

RegisterContext
[in] Pointer to an IP_NAT_REGISTER_EDITOR structure that specifies protocol and function information.

Return Value

STATUS_SUCCESS indicates success. A non-zero value indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Natedit.h Natedit.h Coredll.dll
