Microsoft Windows CE 3.0  

TBM_SETTICFREQ

This message sets the interval frequency for tick marks in a trackbar. For example, if the frequency is set to two, a tick mark is displayed for every other increment in the trackbar’s range. The default setting for the frequency is one; that is, every increment in the range is associated with a tick mark. 

TBM_SETTICFREQ wParam = (WPARAM) wFreq; 
lParam = 0;

Parameters

wFreq
Frequency of the tick marks.

Return Values

None.
