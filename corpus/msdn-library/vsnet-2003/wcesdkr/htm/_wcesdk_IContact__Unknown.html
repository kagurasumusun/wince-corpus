IContact::Unknown

This interface is not supported in Windows CE Platform Builder 3.0.

Represents a contact in the Contacts folder. Use the following methods to save, delete, duplicate or display a contact. Use the IPOutlookCollection interface to add new contacts or retrieve existing ones.

Methods in Vtable Order

Method Description
IContact::Save Saves a contact.
IContact::Delete Deletes a contact.
IContact ::Copy Duplicates a contact.
IContact ::Display Displays a contact.

Requirements

Runs On Versions Defined in Include Link to
Windows CE OS 2.0 and later pimstore.h
