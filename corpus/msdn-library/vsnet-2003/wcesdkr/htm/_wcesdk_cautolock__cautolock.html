Microsoft Windows CE 3.0  

CAutoLock::CAutoLock

Takes a pointer to a critical section object and locks it. 

CAutoLock(
CCritSec *plock);

Parameters

plock
Pointer to a critical section object.

Return Values

No return value.

Remarks

The critical section is unlocked when the CAutoLock object is destroyed.
