Microsoft Windows CE 3.0  

ICity::Save

This method is not supported in Windows CE Platform Builder 3.0.

This method saves a city item. This saves changes to any city in RAM. If the user cold-boots a Windows CE device, any new cities saved in RAM or changes to cities stored in ROM are lost.

HRESULT Save();

Return Values

S_OK indicates that the city item was saved successfully. If the city cannot be saved, the appropriate HRESULT value is returned.

Remarks

You can save changes to properties of cities stored in ROM only in Pocket Outlook version 1.1 or later. If you are running an earlier version of Pocket Outlook and you try to save changes to properties of a city stored in ROM, Save returns E_CITYINROM.

Code Example [Visual Basic]

The following Visual Basic® code snippet copies, modifies and saves a city:

Sub SaveCity(polApp As PocketOutlook.Application)
Dim polCities As PocketOutlook.Items
Dim polCity As PocketOutlook.CityItem
' Get collection and copy an existing city
Set polCities = polApp.GetDefaultFolder(olFolderCities).Items
Set pCity = polCities.Find("[Name] = & Chr(34) & "Tegucigalpa” & Chr(34)).Copy
' Set properties that are unique for new city
Set pCity.Longitude = -8800
Set pCity.Latitude = 1550
Set pCity.AirportCode = “SAP”
Set pCity.Name = "San Pedro Sula"
' Save the new city
pCity.Save
End Sub

Code Example [C++]

The following C++ code snippet shows how copy, modify, and save a city:

void SaveCity(IPOutlookApp *polApp)
{
IFolder *pFolder;
IPOutlookItemCollection *pItems;
ICity *pCity, *pCity2;

// Get the cities folder and items collection
polApp->GetDefaultFolder(olFolderCities, &pFolder);
pFolder->get_Items(&pItems);

// Copy existing city to new city
pItems->Find(TEXT(“[Name] = “Tegucigalpa”) &pCity2);
pCity2->Copy(&pCity);

// Set properties unique to new city
pCity->put_Longitude(-8800);
pCity->put_Latitude(1550);
pCity->put_AirportCode(TEXT(“SAP”));
pCity->put_Name(TEXT(“San Pedro Sula”));

// Save the new city
pCity->Save();
}
