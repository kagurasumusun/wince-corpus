IBasicVideo::get_SourceWidth

Retrieves the source rectangle width. 

HRESULT get_SourceWidth(
long *pSourceWidth);

Parameters

pSourceWidth
[out] Current width.

Return Values

Returns an HRESULT value.

Remarks

This method has no effect on the source rectangle x-axis coordinate.
