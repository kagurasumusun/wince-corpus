Microsoft Windows CE 3.0  

LVM_SCROLL

This message scrolls the content of a list view control. You can send this message explicitly or by using the ListView_Scroll macro. 

LVM_SCROLL wParam = 0; 
lParam = MAKELPARAM(
(int) dx, 
(int) dy );

Parameters

dx
Specifies the amount of horizontal scrolling in pixels. If the list view control is in list view, this value specifies the number of columns to scroll.
dy
Specifies the amount of vertical scrolling in pixels

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

Related macro: ListView_Scroll

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
