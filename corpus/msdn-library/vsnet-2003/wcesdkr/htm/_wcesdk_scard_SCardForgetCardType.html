Microsoft Windows CE 3.0  

SCardForgetCardType

This function removes an introduced smart card from the smart card subsystem.

LONG SCardForgetCardType(
IN SCARDCONTEXT hContext, 
IN LPCTSTR szCardName );

Parameters

hContext
Handle to the resource manager context. The resource manager context is set by a previous call to SCardEstablishContext.
szCardName
Null-terminated string that contains the friendly name of the card to be removed from the smart card database.

Return Values

Value Description
Succeeds SCARD_S_SUCCESS
Fails An error value (see Smart Card Error values for a list of all error values)

Remarks

SCardForgetCardType is a database management function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Winscard.h   Winscard.lib
