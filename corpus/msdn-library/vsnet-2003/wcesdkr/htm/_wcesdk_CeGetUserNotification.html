Microsoft Windows CE 3.0  

CeGetUserNotification

This function retrieves notification information associated with a handle.

BOOL CeGetUserNotification (
HANDLE hNotification, 
DWORD cBufferSize, 
LPDWORD pcBytesNeeded, 
LPBYTE pBuffer );

Parameters

hNotification
[in] Handle to the notification.
cBufferSize
[in] Size of the buffer.
pcBytesNeeded
[out] Pointer to the number of bytes needed.
pBuffer
[out] Pointer to a buffer to hold the requested information.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

In the event the buffer size is insufficient, this function fails and returns the necessary buffer size in pcBytesNeeded. In any other cases of failure, ERROR_INVALID_PARAMETER is set and pcBytesNeeded is 0.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 and later Notify.h   Notify.lib
