IContact::Copy

This method is not supported in Windows CE Platform Builder 3.0.

This method copies a Contact item.

HRESULT Copy(ITEMTYPE ** ppolItem );

Parameters

ppolItem
[out] Pointer to a pointer to the copy of the Contact item.

Return Values

S_OK indicates the Contact item was copied successfully. If an error occurs, the appropriate HRESULT value is returned.

Remarks

Code Example [Visual Basic]

The following Visual Basic® code snippet copies a contact:

Sub CopyContact(polApp As PocketOutlook.Application)
Dim polContact As PocketOutlook.ContactItem
Dim polItems As PocketOutlook.Items
Set polItems = polApp.GetDefaultFolder(olFolderContacts).Items
Set strQuery = “[LastName] = “ & Chr(34) & “Fleming” & Chr(34) & “AND [FirstName] “ & Chr(34) & “Brian” & Chr(34)
Set polContact = polItems.Find(strQuery).Copy
polContact.CompanyName = “Microsoft”
polContact.Save;
End Sub

Code Example [C++]

The following C++ code snippet copies and saves a new contact:

void CopyContact(IPOutlookApp *polApp)
{
IContact *pContact, *pContact2;
IFolder *pFolder;
IPOutlookItemCollection *pItems;

// Get the contact
polApp->GetDefaultFolder(olFolderContacts, &pFolder);
pFolder->get_Items(&pItems);
pItems->Find(TEXT(“[LastName] = \”Fleming\” AND [FirstName] = \”Brian\””), &pContact);

// Copy the contact and change the company name
pContact->Copy(&pContact2)
pContact2->put_CompanyName(TEXT(“Microsoft”));

// Save the change
pContact2->Save();

// Release objects
pContact->Release();
pContact2->Release();
pFolder->Release();
pItems->Release();
}
