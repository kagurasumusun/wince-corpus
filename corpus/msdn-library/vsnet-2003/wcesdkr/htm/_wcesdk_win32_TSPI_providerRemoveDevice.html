Microsoft Windows CE 3.0  

TSPI_providerRemoveDevice

The TSPI_providerRemoveDevice function notifies the TSP when a device has been removed from the system. The TSP should mark or remove any line or phone devices associated with the removed device.

LONG TSPIAPI TSPI_providerRemoveDevice(
LPCWSTR lpszDeviceName );

Parameters

lpszDeviceName
Pointer to the name of the device that has been removed.

Return Values

Returns zero if the function succeeds or an error number if an error occurs. Possible return values are as follows:

LINEERR_OPERATIONFAILED, LINEERR_NOMEM, LINEERR_INVALPARAM.

Remarks

This function is specific to Windows CE.

Requirements

Runs On Versions Defined in Include Link to
Windows CE OS 3.0 and later Tapicomn.h
