Microsoft Windows CE 3.0  

CeGetRandomSeed

This function returns a random seed that can be used in an algorithm.

__int64 CeGetRandomSeed (void);

Return Values

A random 64-bit number that is based on the operations of the kernel.

Remarks

If this function is not prototyped in Winbase.h for a particular implementation of Windows CE version 3.0 and later, it is still available. Declare the function using the syntax above.
