Microsoft Windows CE 3.0  

CeGetCurrentTrust

This function retrieves the assigned trust level of a process.

DWORD CeGetCurrentTrust (void);

Return Values

The following table shows the possible values that can be returned.

Value Description
OEM_CERTIFY_TRUST (2) The OEM trusts the module to perform any OS function calls.
OEM_CERTIFY_RUN (1) The OEM trusts the module to run, but restricts the module from making certain function calls.

The trust level is assigned by an OEM when a process is loaded. A DLL can call this function to determine whether its trust level is sufficient to complete all operations. If the DLL is required to run in a trusted mode and is loaded in a non-trusted module, then the DLL in its DLLEntryPoint can return FALSE to abort the load.
