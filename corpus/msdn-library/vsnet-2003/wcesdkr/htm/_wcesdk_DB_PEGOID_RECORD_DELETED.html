Microsoft Windows CE 3.0  

DB_PEGOID_RECORD_DELETED

This message is sent when a record has been deleted from the object store. This message is obsolete for all currently supported versions of Windows CE. Use DB_CEOID_RECORD_DELETED.

DB_PEGOID_RECORD_DELETED oidDeletedRec = (PEGOID) wParam;
oidParent = (PEGOID) lParam;

Parameters

oidDeletedRec
Identifier of the record that was deleted.
oidParent
Identifier of the parent object of the deleted record.
