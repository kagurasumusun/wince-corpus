Microsoft Windows CE 3.0  

CHECK_SYSTEMGUID

This macro checks a CEGUID to determine if it identifies the object store database volume

BOOL CHECK_SYSTEMGUID( 
PCEGUID pceguid);

Parameters

pceguid
Pointer to the CEGUID to check.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Windbase.h Winbase.h Fsdbase.lib
