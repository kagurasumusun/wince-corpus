wmbase Component

The wmbase component provides support for the window manager.

Functions for Application Developers

The wmbase component includes the following functions for application developers, which are defined in the Winuser.h header file. To import these functions, you need to link to the wmbase.lib file.

Function
CreateWindowEx
DestroyWindow
GetClassLong
GetDoubleClickTime
GetSystemMetrics
GetWindowThreadProcessId
IsWindow
IsWindowVisible
SetClassLong
