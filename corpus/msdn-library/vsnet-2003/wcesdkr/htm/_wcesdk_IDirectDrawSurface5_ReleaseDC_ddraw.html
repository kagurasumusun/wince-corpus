IDirectDrawSurface5::ReleaseDC

The IDirectDrawSurface5::ReleaseDC method releases the handle of a device context previously obtained by using the IDirectDrawSurface5::GetDC method.

HRESULT ReleaseDC(
HDC hDC);

Parameters

hDC
Handle to a device context previously obtained by IDirectDrawSurface5::GetDC.

Return Values

If the method succeeds, the return value is DD_OK.

If the method fails, the return value may be one of the following error values:

DDERR_GENERIC
DDERR_INVALIDOBJECT
DDERR_INVALIDPARAMS
DDERR_SURFACELOST
DDERR_UNSUPPORTED

Remarks

This method also unlocks the surface previously locked when the IDirectDrawSurface5::GetDC method was called.

Requirements

Runs on Versions Declared in Link to
Windows CE OS 2.12 or later. Version 2.12 requires DXPAK 1.0 or later. ddraw.h ddraw.lib
