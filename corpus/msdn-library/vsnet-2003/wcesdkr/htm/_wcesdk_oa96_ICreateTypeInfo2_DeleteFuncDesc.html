ICreateTypeInfo2::DeleteFuncDesc

This method deletes a function description specified by the index number. 

HRESULT DeleteFuncDesc( 
unsigned int index);

Parameters

index
Index of the function whose description is to be deleted. The index should be in the range of 0 to 1 less than the number of functions in this type.

Return Values

One of the values described in the following table is returned.

Value Description
S_OK Success.
E_OUTOFMEMORY Out of memory.
E_INVALIDARG One or more of the parameters is invalid.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Oaidl.h
