Microsoft Windows CE 3.0  

msmq Modules

The msmq module support Message Queuing functionality. Message Queuing supports communication between the various parts of a distributed application. Message Queuing technology enables applications that are running at different times to communicate across networks and systems that might be offline temporarily. To accomplish this functionality, applications communicate with each other by sending messages to various message queues.

The msmq group contains the following modules.

Module Description Notes Import file
MQOA Supports Message Queuing Server. Exposes no public functions. Mqoa.lib
MSMQADM Provides Message Queuing administration and configuration functionality. Exposes no public functions. Msmqadm.lib
MSMQD Supports the main Message Queuing engine, which is implemented in a device driver. Exposes no public functions. Msmqd.lib
MSMQRT Supports the main Message Queuing run-time API set. Implements the Message Queuing API set. Msmqapix.lib
NETREGD Provides network-registration functionality. Required in a DHCP environment to register a Windows CE-based device with WINS and provide NetBIOS service. Netregd.lib
Visadm Visual front end for MSMQADM.exe and the Message Queuing configuration. Exposes no public functions. Visadm.lib
