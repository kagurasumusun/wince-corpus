IInputMethod2::Hiding

This method is implemented to perform any saving routines before the input panel is hidden.

HRESULT Hiding( void );

Return Values

An appropriate HRESULT value is returned.

Remarks

This method is called by the system when the user toggles the visible state of the input panel off. Programmatically, this occurs when the SIPF_ON flag is toggled off in the SIPINFO structure. Hiding the input panel allows the user to see more of the current application. The input panel is hidden upon return from this call. Use this method to save any data the input method (IM) needs to display when the input panel becomes visible again. The data is used to reinitialize the input panel and IM in the IInputMethod2::Showing method.
