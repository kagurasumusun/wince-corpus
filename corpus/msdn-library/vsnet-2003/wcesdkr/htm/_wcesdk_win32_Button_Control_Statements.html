Microsoft Windows CE 3.0  

Button Control Statements

buttonClass controlText, id

Parameters

buttonClass
Specifies one of the following classes: AUTO3STATE, AUTOCHECKBOX, AUTORADIOBUTTON, CHECKBOX, PUSHBOX, PUSHBUTTON, RADIOBUTTON, STATE3, or USERBUTTON.
controlText
Specifies the window text for the control.
id
Specifies the control identifier.
