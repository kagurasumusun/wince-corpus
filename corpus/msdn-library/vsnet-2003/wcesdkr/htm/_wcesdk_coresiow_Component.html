coresiow Component

The coresiow component supports the Unicode version of standard input/output (stdio). The APIs that are supported by coresiow are part of the C run-time library functions.

Functions for Application Developers

The coresiow component includes the following functions for application developers, which are defined in the Stdio.h header file. To import these functions, you need to link to the coresiow.lib file.
