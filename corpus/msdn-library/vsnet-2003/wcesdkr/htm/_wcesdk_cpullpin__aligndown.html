Microsoft Windows CE 3.0  

CPullPin::AlignDown

Aligns a LONGLONG value down to the next LONG boundary. 

LONGLONG AlignDown(
LONGLONG ll,
LONG lAlign );

Parameters

ll
Element to be aligned.
lAlign
Alignment boundary.

Return Values

Returns the ll value aligned to lAlign.

Remarks

Aligning downward is a truncation operation.
