CBasePin::QueryId

Retrieves an identifier for the pin. 

HRESULT QueryId(
LPWSTR *Id);

Parameters

Id
Pin identifier.

Return Values

Returns an HRESULT value.

Remarks

This member function implements the IPin::QueryId method. By default, this member function uses the pin name in the m_pName data member, so implementing this member function in your derived filter class is not normally required.
