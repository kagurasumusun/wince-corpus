NK Components

The nk module contains the following components.

Component Description Notes Library
CEFNK Provides CEF support Exposes no public functions. Cefnk.lib
COREDLL Provides core functionality to other modules. This module is a basic Windows CE OS module. Must be included in all Windows CE–based platforms, but not all of its components are required. Coredll.lib
HAL OEM component that abstracts the kernel from the hardware. Exposes functions to the OEM. None
NKCOMPR Supports file compression. Exposes no public functions. Nkcompr.lib
NKNOCOMP Removes the file compression component from your configuration. Exposes no public functions. Nknocomp.lib
NKNOCEFNK Stubs out CEF support Exposes no public functions. Nknofnk.lib
SCHEDLOG Assists OEMs using the LogThread* and LogProcess* APIs. Exposes functions to the OEM. Schedlog.lib
