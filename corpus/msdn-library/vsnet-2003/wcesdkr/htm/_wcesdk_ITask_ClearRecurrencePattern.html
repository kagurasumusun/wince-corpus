ITask::ClearRecurrencePattern

This method is not supported in Windows CE Platform Builder 3.0.

This method clears the recurrence for a task and marks it as a single instance.

HRESULT ClearReccurencePattern();

Return Values

S_OK indicates that the recurrence was cleared successfully. If an error occurs, the appropriate HRESULT value is returned.

Requirements

Runs On Versions Defined in Include Link to
Windows CE OS 2.0 and later pimstore.h
