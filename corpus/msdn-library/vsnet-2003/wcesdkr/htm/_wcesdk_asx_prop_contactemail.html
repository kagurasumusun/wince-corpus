Microsoft Windows CE 3.0  

ContactEmail

Retrieves a value representing the station's e-mail address.

Compatibility: Windows Media Player

[ "sAddress" = ] MediaPlayer.ContactEmail

Parameters

sAddress
String value representing the station's e-mail address. This property is read-only with no default value.

Remarks

This property only returns valid information for Advanced Streaming Format (ASF) content being received from a station (defined IP address and port number). Station information is stored in a Microsoft® Windows Media™ Station (.nsc) file.
