coresioa Component

The coresioa component supports the “A” (ASCII) version of standard input/output (stdio). The APIs that are supported by coresioa are part of the C run-time library functions.

Functions for Application Developers

The coresioa component includes the following functions for application developers, which are defined in the Stdio.h header file. To import these functions, you need to link to the coresioa.lib file.
