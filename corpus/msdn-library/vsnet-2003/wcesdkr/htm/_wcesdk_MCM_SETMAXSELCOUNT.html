Microsoft Windows CE 3.0  

MCM_SETMAXSELCOUNT

This message sets the maximum number of days that can be selected in a month calendar control.

MCM_SETMAXSELCOUNT wParam = (WPARAM)(INT) iMax; 
lParam = 0;

Parameters

iMax
INT value that is set to represent the maximum number of selectable days.

Return Values

Returns nonzero if successful, and returns zero otherwise. This message fails if applied to a month calendar control that does not use the MCS_MULTISELECT style.

Remarks

Related macro: MonthCal_SetMaxSelCount

Requirements

Windows CE OS 2.0 and later Commctrl.h
