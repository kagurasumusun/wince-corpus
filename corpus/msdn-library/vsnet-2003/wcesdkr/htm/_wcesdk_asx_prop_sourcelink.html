Microsoft Windows CE 3.0  

SourceLink

Retrieves a value specifying the path to the current clip.

Compatibility: Windows Media Player

[ "sPath" = ] MediaPlayer.SourceLink

Parameters

sPath
String value specifying the path to the current clip. This property is read-only with no default value.

Remarks

Multiple clips can appear in one Advanced Stream Redirector (ASX) file. Retrieve this property to determine where the current clip file resides.

This property returns valid information only if the FileName property has been set.
