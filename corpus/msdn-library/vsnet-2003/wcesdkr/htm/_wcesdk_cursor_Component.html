cursor Component

The cursor component implements cursor functionality.

Functions for Application Developers

The cursor component includes the following functions for application developers, which are defined in the Winuser.h header file. To import these functions, you need to link to the cursor.lib file.

Function
ClipCursor
GetClipCursor
GetCursor
GetCursorPos
LoadCursor
SetCursor
SetCursorPos
ShowCursor
