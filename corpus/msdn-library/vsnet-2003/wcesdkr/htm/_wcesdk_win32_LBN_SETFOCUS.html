Microsoft Windows CE 3.0  

LBN_SETFOCUS

This notification message is sent by an application when a list box receives the keyboard focus. The parent window of the list box receives this notification message through the WM_COMMAND message. 

LBN_SETFOCUS idListBox = (int)LOWORD(wParam);
hwndListBox = (HWND) lParam;

Parameters

idListBox
Identifier of the list box.
hwndListBox
Handle to the list box.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Winuser.h
