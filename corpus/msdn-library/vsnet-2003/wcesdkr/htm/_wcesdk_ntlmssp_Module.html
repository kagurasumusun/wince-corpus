ntlmssp Module

The ntlmssp module supports the Microsoft Windows NT® LAN Manager secure-socket provider.

Functions for Application Developers

The ntlmssp module contains the following function for application developers, which is defined in the Sspi.h header file. To import this function, you need to link to the ntlmssp.lib file.
