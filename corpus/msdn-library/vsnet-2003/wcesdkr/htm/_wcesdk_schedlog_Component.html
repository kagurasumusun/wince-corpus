schedlog Component

The schedlog component provides functions to assist OEMs using the LogThread* and LogProcess* APIs.

Functions for Operating System Developers

The schedlog component includes the following functions for operating system configuration, which are defined in the Schedlog.h header file. To import these functions, you need to link to the Schedlog.lib file.

Function
SchedLogGetProcessName
SchedLogGetThreadProgramCounter
SchedLogTranslate
