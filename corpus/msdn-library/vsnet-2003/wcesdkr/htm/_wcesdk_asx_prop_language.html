Microsoft Windows CE 3.0  

Language

Sets or retrieves a value specifying the current locale used for national language support.

Compatibility: Windows Media Player

MediaPlayer.Language [ = lLCID ]

Parameters

lLCID
Long value that corresponds to an LCID identifying a locale for national language support. This property is read/write.
