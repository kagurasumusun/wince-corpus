Microsoft Windows CE 3.0  

CoTaskMemFree

This function frees a block of task memory previously allocated through a call to the CoTaskMemAlloc or CoTaskMemRealloc function. 

void CoTaskMemFree(
void pv);

Parameter

pv
[in] Void pointer to the memory block to be freed.

Return Values

None.

Remarks

The CoTaskMemFree function, using the default OLE allocator, frees a block of memory previously allocated through a call to the CoTaskMemAlloc or CoTaskMemRealloc function.

The number of bytes freed equals the number of bytes that were originally allocated or reallocated. After the call, the memory block pointed to by pv is invalid and can no longer be used.

The pv parameter can be NULL, in which case this method has no effect.

Passing into this function any invalid and, under some circumstances, NULL pointers result in unexpected termination of the application.
