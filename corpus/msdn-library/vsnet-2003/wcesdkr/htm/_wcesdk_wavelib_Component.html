wavelib Component

The wavelib component supports the wave API set that is used to implement wave (.wav) audio files.

Functions for Application Developers

The wavelib component includes the following functions for application developers, which are defined in the Mmsystem.h header file. To import these functions, you need to link to the wavelib.lib file.
