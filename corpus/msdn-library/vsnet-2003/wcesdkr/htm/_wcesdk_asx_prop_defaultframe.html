Microsoft Windows CE 3.0  

DefaultFrame

Sets or retrieves a value representing the default target HTTP frame.

Compatibility: Windows Media Player

MediaPlayer.DefaultFrame [ = "sFrame" ]

Parameters

sFrame
String value representing the default target HTTP frame. This property is read/write.

Remarks

This property specifies which browser frame displays a new location when a URL-type ScriptCommand event occurs. If the ScriptCommand event specifies the frame, however, the property is ignored.
