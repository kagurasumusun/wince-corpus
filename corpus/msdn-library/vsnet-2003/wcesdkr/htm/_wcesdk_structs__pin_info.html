PIN_INFO

Contains information about a pin. 

typedef struct  _PinInfo
{
IBaseFilter  *pFilter;
PIN_DIRECTION dir;
WCHAR achName[ 128 ];
}        PIN_INFO;

Members

pFilter
Pointer to the IBaseFilter interface of the owning filter.
dir
Direction of the pin (input or output).
achName
Name of the pin.
