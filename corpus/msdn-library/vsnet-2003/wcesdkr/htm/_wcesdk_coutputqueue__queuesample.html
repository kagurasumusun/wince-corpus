COutputQueue::QueueSample

Queues a sample. 

void QueueSample(
IMediaSample *pSample );

Parameters

pSample
Pointer to the sample to be passed to the connected input pin.

Return Values

No return value.

Remarks

The critical section must be held when this is called.
