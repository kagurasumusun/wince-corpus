DeleteUrlCacheGroup

This function releases the specified GROUPID and associated state in the cache index file.

BOOL DeleteUrlCacheGroup ( 
GROUPID GroupId,
DWORD dwFlags, 
LPVOID lpReserved);

Parameters

GroupId
[in] GROUPID value associated with the cache group to be released.
dwFlags
[in] Unsigned long integer value containing the flags to control the cache group deletion. This can be set to CACHEGROUP_FLAG_FLUSHURL_ONDELETE, which deletes all cache entries associated with this group, unless the entry belongs to another group.
lpReserved
[in] Reserved; set to NULL.

Return Values

Returns TRUE if successful, or FALSE otherwise

Requirements

Windows CE OS 2.12 and later Wininet.h   Wininet.lib
