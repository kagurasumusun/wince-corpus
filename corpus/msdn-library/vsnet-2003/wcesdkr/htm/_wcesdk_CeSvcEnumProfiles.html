Microsoft Windows CE 3.0  

CeSvcEnumProfiles

This function enumerates all the profiles currently stored in the registry. It returns the partnership ID and an open handle to the partnership key.

HRESULT CeSvcEnumProfiles( 
PHCESVC phSvc, 
DWORD lProfileIndex,
PDWORD plProfile);

Parameters

phSvc
[out] Pointer to a handle to a registry subkey.
lProfileIndex
[in] Index for subkey returned. Caller should initialize to 0 and increment for each additional subkey.
plProfile
[out] Pointer to a device identifier.

Return Values

S_OK indicates success. On failure an appropriate Win32 error code is returned. When no more profiles can be found, the function returns ERROR_NO_MORE_ITEMS.

Remarks

This function is part of CEUTIL, a utility DLL for dealing with desktop registry entries for Windows CE. CEUTIL functions are for use by desktop applications that need to communicate remotely with Windows CE–based devices. These functions are not available to applications running on Windows CE–based devices.
