fileopen Component

The fileopen component supports the Open and Save As common dialog boxes.

Functions for Application Developers

The fileopen component includes the following functions for application developers, which are defined in the Commdlg.h header file. To import these functions, you need to link to the fileopen.lib file.

Function
GetOpenFileName
GetSaveFileName
