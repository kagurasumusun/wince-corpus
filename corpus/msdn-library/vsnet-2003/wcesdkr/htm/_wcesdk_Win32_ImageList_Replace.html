Microsoft Windows CE 3.0  

ImageList_Replace

This function replaces an image in an image list with a new image. 

BOOL WINAPI ImageList_Replace(
HIMAGELIST himl, 
int i, 
HBITMAP hbmImage, 
HBITMAP hbmMask );

Parameters

himl
[in] Handle to the image list.
i
[in] Index of the image to replace.
hbmImage
[in] Handle to the bitmap that contains the image.
hbmMask
[in] Handle to the bitmap that contains the mask. If no mask is used with the image list, this parameter is ignored.

Return Values

Nonzero indicates success. Zero indicates failure.

Remarks

The ImageList_Replace function copies the bitmap to an internal data structure. Be sure to use the DeleteObject function to delete hbmImage and hbmMask after the function returns.
