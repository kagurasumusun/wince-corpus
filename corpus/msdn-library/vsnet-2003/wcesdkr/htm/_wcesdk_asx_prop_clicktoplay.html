Microsoft Windows CE 3.0  

ClickToPlay

Sets or retrieves a value specifying whether the user can toggle playback by clicking the video image.

Compatibility: Windows Media Player

MediaPlayer.ClickToPlay [ = bClick ]

Parameters

bClick
Boolean value specifying whether the user can toggle playback by clicking the video image. If true, playback toggling is enabled. This property is read/write with a default value of true.

Remarks

If the value of this property is true, clicking anywhere in the image display window toggles playback. (When a clip is playing, clicking the image pauses playback. When a clip is paused, clicking the image starts playback again).
