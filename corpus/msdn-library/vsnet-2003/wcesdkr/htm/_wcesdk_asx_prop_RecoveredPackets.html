Microsoft Windows CE 3.0  

RecoveredPackets

Retrieves a value specifying the number of packets recovered.

Compatibility: Windows Media Player

[ lPackets = ] MediaPlayer.RecoveredPackets

Parameters

lPackets
Long value specifying the number of packets recovered. This property is read-only with no default value.

Remarks

Each time file playback stops and restarts, this property resets to zero. It does not reset if file playback is paused.

This property returns valid information only during run time and only if the FileName property is set.
