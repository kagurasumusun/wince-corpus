shortcut Component

The shortcut component provides support for shell-related shortcuts.

Functions for Application Developers

The shortcut component includes the following functions for application developers, which are defined in the Shellapi.h header file. To import these functions, you need to link to the shortcut.lib file.

Function
SHCreateShortcut
SHGetShortcutTarget
