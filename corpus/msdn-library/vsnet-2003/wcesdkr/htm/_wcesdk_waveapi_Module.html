waveapi Module

The waveapi module supports the Audio Compression Manager (ACM), Mapper, and the Wave API Manager (WAM).

WAVEAPI Components

The waveui module contains the following components.

Component Description Notes Library
WAPIWAVE     Wapiwave.lib
WAPIACM Audio Compression Manager.   Wapiacm.lib
WAPIMAP Mapper.   Wapimap.lib
WAVEUI Supports the Wave User Interface. Exposes functions for the OEM. Waveui.lib
