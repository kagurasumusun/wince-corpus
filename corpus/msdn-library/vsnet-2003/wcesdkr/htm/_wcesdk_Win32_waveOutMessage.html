Microsoft Windows CE 3.0  

waveOutMessage

This function sends messages to the waveform output device drivers.

MMRESULT waveOutMessage(
HWAVEOUT hwo, 
UINT uMsg, 
DWORD dw1, 
DWORD dw2 );

Parameters

hwo
Handle to an open waveform-audio output device, or a DeviceID value between 0 and the value returned by waveOutGetNumDevs.
uMsg
Message to send.
dw1 and dw2
Specifies message parameters.

Return Values

The value returned from the driver indicates success.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Mmsystem.h   Wavelib.lib
