Microsoft Windows CE 3.0  

VideoBorder3D

Sets or retrieves a value specifying whether or not the three-dimensional video border effect is enabled.

Compatibility: Windows Media Player

MediaPlayer.VideoBorder3D [ = bBorder3D ]

Parameters

bBorder3D
Boolean value specifying whether or not the 3-D video border effect is enabled. If true, the 3-D border is enabled. This property is read/write with a default value of false.

Remarks

The 3-D video border is 1 pixel wide. It is drawn around the video display panel and the video border, if one is present.
