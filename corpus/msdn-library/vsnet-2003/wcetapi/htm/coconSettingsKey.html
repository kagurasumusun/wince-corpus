Settings Key

The Settings key contains commands for configuring various modem settings. The following table shows the registry settings for the HKEY_LOCAL_MACHINE\Drivers\PCMCIA\CompanyX-GenericModem-1234\Unimodem\Settings key.

Value : type Description
Answer Default setting is ATA<cr>. Answers an incoming call.
Blind_Off Default setting is X4. Disables blind dialing.
Blind_On Default setting is X3. Enables blind dialing.
CallSetupFailTimeout Default setting is S7=<#>. Calls time-out register.
DccRetries Default setting is 3. The number of times to retry direct cable connection.
DialBilling Default setting is <$>. Specifies whether the modem supports the '$' wait for credit card prompt tone (bong). A value of 0 indicates that this capability is not supported. If it is not supported, Unimodem will insert multiple commas to cause the modem to wait. If this registry value is not present, support for '$' is assumed.
DialPrefix Default setting is D. Prefix for any dial command.
DialSuffix Default setting is <;>. Extends a dialing string across multiple commands. Unimodem breaks long dial commands into approximately 40-character strings because many modems cannot handle longer commands. This suffix character is used to indicate to the modem that the dial sequence is continued in the next command.
FlowHard Default setting is AT\Q3<cr>. Enables hardware flow control.
FlowOff Default setting is AT\Q<cr>. Disables all flow control.
FlowSoft Default setting is AT\Q1<cr>. Enables software flow control.
MaxCmd Default setting is 40. The maximum command length.
MdmLogFile Default setting is 0. Controls logging of modem commands and responses. 0 = no logging, 1 = write commands, and responses to a log file named mdmlogN.txt where N is the line device identifier.
Monitor Default setting is ATS0=0<cr>. Listen for incoming calls
PPPMTU Default setting is 1500. The size, in bytes, of the maximum transfer unit that PPP should use on this device.
Prefix Default setting is AT. The modem command prefix.
Pulse Default setting is P. Dial prefix that is used for pulse dialing, such as ATDP.
Reset Default setting is ATZ<cr>. Resets modem.
Terminator Default setting is <cr>. Configuration command suffix; this key is added to the end of any command sequences that are sent to the modem by Unimodem.
Tone Default setting is T. Dial prefix that is used for tone dialing, such as ATDT.
