TSPI_providerCreateLineDevice

This function is called by TAPI in response to the receipt of a system plug-and-play notification of a new device associated with the TSP.

LONG TSPIAPI TSPI_providerCreateLineDevice(
HKEY hActive,  
LPCWSTR szDevKey
LPCWSTR szDevName 
);

Parameters

hActive
The handle to the open registry key for the active instance of the device key.
szDevKey
The registry path string to the device key.
szDevName
The new name of the device, for example COM2:.

Return Values

Returns zero if the request succeeds or an error number if an error occurs. Possible return values are:

LINEERR_BADDEVICEID, LINEERR_NOMEM, LINEERR_OPERATIONFAILED.

Remarks

TAPI calls the TSPI-provider CreateLineDevice when it receives a plug-and-play system notification that a new device, which is associated with the TSP, has been added to the system. This association is indicated in the registry key of the new device. If the TSP chooses to create a line device, it should also send a PHONE_LINE message to TAPI.

Requirements
