TAPI Functions

The Windows CE .NET implementation of TAPI 2.0 supports a set of APIs that let you create various types of applications that implement telephony functionality. Windows CE also supports the TAPI telephone device API set.

The Tapi.dll library file exports all of the TAPI functions that can be used to create TAPI applications. TAPI function prototypes, as well as TAPI structures, are defined in the Tapi.h header file.

Asynchronous functions return either a TAPI error code or a request identifier. When the request is completed, the application receives a LINE_REPLY message that contains the result code for the operation and the request identifier.
