Unimodem Key

The following table shows the registry settings for the HKEY_LOCAL_MACHINE\Drivers\PCMCIA\CompanyX-GenericModem-1234\Unimodem key.

Value : type Description
DevConfig : REG_HEX Binary structure that indicates the serial device capabilities (baud, parity, and so on). Default settings are:

10,00, 00,00 78,00,00,00
10,01,00,00, 00,4B,00,00
00,00, 08, 00, 00,00,00,00
DeviceType : REG_DWORD Default setting is 0. Specifies the device type; the values are specified in the Unimodem.h header file in the OAK directory.
FriendlyName : REG_SZ Specifies the name that is displayed to the user by TAPI applications.
TSP : REG_SZ Provides the TSP name that services this port. This key is set always to Unimodem.dll for version 1 and 1.01 devices.
