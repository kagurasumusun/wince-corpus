lineSetTollList

This function manipulates the toll list.

LONG WINAPI lineSetTollList(
HLINEAPP hLineApp,
DWORD dwDeviceID,
LPCWSTR lpszAddressIn
DWORD dwTollListOption
);

Parameters

hLineApp
The application handle returned by lineInitializeEx. If an application has not yet called the lineInitializeEx function, it can set the hLineApp parameter to NULL.
dwDeviceID
The device identifier for the line device on which the call is intended to be dialed, so that variations in dialing procedures on different lines can be applied to the translation process.
lpszAddressIn
A pointer to a null-terminated string containing the address from which the prefix information is to be extracted for processing. This parameter must not be NULL, and it must be in the canonical address format.
dwTollListOption
The toll list operation to be performed. This parameter uses one and only one of the following constants.
Value Description
LINETOLLLISTOPTION_ADD A prefix is to be added to the toll list.
LINETOLLLISTOPTION_REMOVE A prefix is to be removed from the toll list.

Return Values

Returns zero if the request succeeds or a negative error number if an error occurs. Possible return values are as follows:

  • LINEERR_BADDEVICEID
  • LINEERR_NODRIVER
  • LINEERR_INVALAPPHANDLE
  • LINEERR_NOMEM
  • LINEERR_INVALADDRESS
  • LINEERR_OPERATIONFAILED
  • LINEERR_INVALPARAM
  • LINEERR_RESOURCEUNAVAIL
  • LINEERR_INIFILECORRUPT
  • LINEERR_UNINITIALIZED
  • LINEERR_INVALLOCATION.
