Installation Options

The minimum configuration of MSMQ consists of the installation of only MSMQD.DLL and MSMQRT.DLL. In this case, your application must set up the MSMQ registry configuration by installing MSMQD as a built-in device driver. The network cannot have dynamic IP addresses and the DNS must provide reverse lookup.

The maximum configuration includes all MSMQ modules. It includes the VISADM utility and configuration tools.

Before MSMQ can be configured, you must copy all DLLs and MSMQADM.EXE to the Windows directory and VISADM.EXE and CETCHA.EXE to the Windows\Programs\MSMQ directory.

There are three main methods of installing MSMQ:

  • Installing MSMQ using MSMQADM.EXE
  • Installing MSMQ using Visadm
  • Installing MSMQ using the registry

The installation topics assume that the MSMQ binaries have been copied to RAM or ROM of the target machine.
