Filtering Messages (COM)

Receiving applications can use any message property or combination of properties to filter out a set a messages from a queue. Filters can be constructed to remove the desired messages from the queue when they are found or leave them there.

The examples provided here show two general purpose message-property filters: one based on the application-specific information of a message and the other based on the message class. These examples could be easily modified to search for a specific message label, create time, or message identifier.
