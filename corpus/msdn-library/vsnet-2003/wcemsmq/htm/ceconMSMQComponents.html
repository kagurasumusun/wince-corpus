MSMQ Module

The following table lists components that make up the Windows CE MSMQ module.

Component Description
MSMQD.DLL Main MSMQ engine implemented as a device driver.
MSMQRT.DLL MSMQ run-time component that implements MSMQ API.
MQOA.DLL Component that supports the message queuing server.
MSMQADM.EXE MSMQ administration and configuration tool.
VISADM.EXE Visual front-end for MSMQADM.EXE and MSMQ configuration. Source code for this utility is provided in the %_WINCEROOT%\Public\MSMQ\SDK\Samples directory.
SRMPISAPI.DLL ISAPI extension that forwards SRMP requests to MSMQ service. This is included only in Windows CE .NET and only if the SRMP component is included.
