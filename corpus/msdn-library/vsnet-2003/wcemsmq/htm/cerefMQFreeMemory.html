MQFreeMemory

This function frees memory allocated by MSMQ.

VOID MQFreeMemory(
PVOID pvMemory
);

Parameters

pvMemory
[in] Pointer to the memory to be freed.

Return Values

None.

Remarks

Whenever an application passes VT_NULL in an aPropVar array and MSMQ allocates memory for the returned property value (for example, puuid and pwszVal), MQFreeMemory must be called.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later. Versions prior to 2.12 require the MSMQ add-on pack. Mq.h Mq.h Msmqrt.lib
