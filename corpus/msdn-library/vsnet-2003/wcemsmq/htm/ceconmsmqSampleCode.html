MSMQ Sample Code

The following sample codes for MSMQ are located in the %_WINCEROOT%\Public\MSMQ\SDK\Samples directory:

  • CLI

    This is a utility that allows user to execute MSMQ APIs from the command line. Type 'h' at the command prompt to get a summary of available commands.

  • VISADM

    This is a visual wrap around MSMQADM. Its use is discussed in the MSMQ administration section of this document.

  • CETCHA

    This is convenient tool that lets a user test MSMQ installation visually. It implements a distributed drawing board that can be shared by two computers. To run, compile CETCHA for Desktop and CE device or two CE devices and run it on both computers. Select OK in response to the first dialog box, then when the drawing surface appears, select File->Queue and put the name of the other computer on each device. After that, when you draw in CETCHA on one computer, the picture will be transferred through MSMQ to the other.

    Control-Click clears the screen. You can make one CETCHA instance a "server" – it will echo the reflected picture back to the computer on which the user is drawing – by selecting File->Server.
