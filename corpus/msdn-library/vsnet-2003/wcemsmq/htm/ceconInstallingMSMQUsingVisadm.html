Installing MSMQ Using Visadm

MSMQADM.EXE uses a console interface but not all Windows CE platforms include a console device driver. To use MSMQADM on one of these platforms you must supply registration commands on its command line and redirect output to the file. The sample program VISADM does just that.

VISADM is a dialog box with an edit control that allows users to input MSMQADM commands as they would appear on the command line, and view the output in a textbox above. There is also a Shortcuts dialog box that automates several frequently used commands and lets users view the MSMQ log file and MSMQ-specific registry entries.

To install MSMQ using Visadm

  1. Run VISADM.EXE.
  2. Select Install from the Shortcuts menu, and then select Registers from the Shortcuts menu.
  3. Reboot the computer.
  4. Run CETCHA.EXE to verify installation.

    You can use Stop from the Shortcuts menu to stop the MSMQ driver after it has been installed and Start from the Shortcuts menu to restart it.

Selecting Log from the Shortcuts menu displays the MSMQ log file. Selecting Verify from the Shortcuts menu interprets registry settings and produces readable information about MSMQ installation.

You can customize your installation options by using direct MSMQADM commands from VISADM command prompt. Type them in the edit box as if you were supplying command line for MSMQADM and hit the Enter key to execute. The output appears in the read-only edit box above.
