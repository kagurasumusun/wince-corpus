Requesting Report Messages (COM)

To request report messages, a report queue must be specified and tracing must be enabled. Once a message has been sent with tracing enabled, you can use Active Directory Manager to view the report messages Message Queuing sent to the report queue.

Report queues are typically specified by the MSMQ Administrator through Active Directory Manager. You can select a know report queue, or specify a new queue and Active Directory Manager will create the queue for you.

Note   Report queues are typically created through Active Directory Manager. If you want to create a report queue using MSMQQueueInfo.Create, be sure to specify the following queue type (GUID) when creating the queue.
{55EE8F32-CCE9-11CF-B108-0020AFD61CE9}

To enable tracing

  1. Using Active Directory Manager, make sure a report queue has been specified.
  2. In your application, define the structures needed to send the message.
  3. Call MSMQQueueInfo.Open to open the destination queue with send access.
  4. Specify MSMQMessage.Trace, setting it to MQMSG_SEND_ROUTE_TO_REPORT_QUEUE.
  5. Optional. Specify other message properties as needed.
  6. Call MSMQMessage.Send to send the message.
  7. Call MSMQQueue.Close to close the destination queue.
