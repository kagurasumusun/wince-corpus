MSMQQueue.IsOpen

This read-only property indicates whether or not the queue is open.

HRESULT get_IsOpen( 
Boolean *pisOpen 
);

Parameters

pisOpen
TRUE if the queue is open, otherwise FALSE.

Return Values

The following table describes the common return values.

Value Description
S-OK Success
E_INVALIDARG One or more arguments are invalid
E_NOTIMPL The function contains no implementation
E_OUTOFMEMORY Out of memory

Remarks

MSMQQueue.IsOpen returns 1 only when MSMQQueue.Handle is set to a valid queue handle. If Message Queuing has set MSMQQueue.Handle to INVALID_HANDLE_VALUE, MSMQQueue.IsOpen will always return 0.
