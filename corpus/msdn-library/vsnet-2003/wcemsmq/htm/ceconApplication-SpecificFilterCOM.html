Application-Specific Filter (COM)

This filter retrieves all message with a specific value of application-specific information.

This filter removes messages from the queue. When a message with the desired application-specific information is found, MSMQQueue.ReceiveCurrent is called to remove the message, and MSMQQueue.PeekCurrent is called to look at the next message. When a message is removed from the queue, the cursor is automatically moved to the next message in the queue.

Note   If you do not want to remove messages from the queue, use MSMQQueue.PeekCurrent to look at the current message, and use MSMQQueue.PeekNext to move the cursor and look at the next message.

To create an application-specific filter

  1. Declare the MSMQQueueInfo, MSMQQueue, and MSMQMessage objects needed to create the filter.
  2. Call MSMQQueueInfo.Open to open the queue with receive access. Note receive access allows you to peek at and retrieve messages.
  3. Call MSMQQueue.PeekCurrent to peek at the first message in the queue. (You must point the cursor to the first message in the queue before using the cursor to navigate through the queue.)
  4. Filter out the messages in the queue. Note that MSMQQueue.ReceiveCurrent and MSMQQueue.PeekCurrent are used if the message is removed, while MSMQQueue.PeekNext is used if the message is does not fit the search criteria.
  5. Call MSMQQueue.Close to close the queue.
