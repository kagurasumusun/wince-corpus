Creating a Secure Windows CE .NET Device

Maricia Alforque
Microsoft Corporation

Updated April 2002

Applies to: Microsoft® Windows® CE .NET operating systems and applications developers who are familiar with Microsoft security technologies and Win32 programming interfaces.

Summary

Security services are an essential part of the operating systems. Communications services, user applications, file systems and data store, and network services all require protection from data tampering, unauthorized users, and rogue applications. This article describes the Windows CE .NET features that allow operating systems developers and applications developers to create a device with optimum security to meet their requirements.

For more information about Windows CE security, see Creating a Secure Device in the product documentation.
