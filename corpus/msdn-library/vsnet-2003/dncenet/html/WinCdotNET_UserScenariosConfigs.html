Predefined Configurations in Windows CE .NET

J.P. Brastad
Microsoft Corporation

Updated April 2002

Applies to: Platform developers seeking more information about the pre-defined configurations that are included with Microsoft® Windows® CE .NET.

Summary

Microsoft Platform Builder version 4.0 provides basic configurations as starting points for the creation of an operating system (OS). These pre-defined configurations are provided to help developers get started creating an OS for a specific class of device. They are intended to reduce product development time—when used in combination with a board support package (BSP)—and to decrease the time it takes to put your product on the market. Once a basic configuration has been chosen, you may modify it to suit your specific needs.

The following basic configurations are included with Platform Builder 4.0:

  • Cell Phone/Smart Phone
  • Custom Device
  • Digital Imaging Device
  • Industrial Automation Device
  • Internet Appliance
  • Media Appliance
  • PDA or Mobile Handheld Device
  • Residential Gateway
  • Retail Point-of-Sale Device
  • Set-Top Box (TV Browser)
  • Tiny Kernel
  • Web Pad
  • Windows Thin Client

For more information about user scenarios for configurations in Windows CE .NET, see Selecting a Configuration in the product documentation.
