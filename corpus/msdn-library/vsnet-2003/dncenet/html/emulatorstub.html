Windows CE .NET  

Critical Information about the Windows CE .NET Emulator

Paul Lewis
Microsoft Corporation

Updated July 2002

Applies to:
    Developers of platforms and applications based on Microsoft® Windows® CE .NET 4.0 and 4.1.

Summary

The Emulator for Microsoft Windows CE .NET is a tool you can use to develop, test, and debug a Windows CE–based platform and applications. On a development workstation, the tool emulates the hardware of a Windows CE–based device.

For information about the Emulator, see Emulator in the documentation for Windows CE .NET 4.1. The documentation describes how to use the Emulator and also discusses the architecture of the Emulator, scenarios in which you may want to use the Emulator, and limitations of the Emulator.
