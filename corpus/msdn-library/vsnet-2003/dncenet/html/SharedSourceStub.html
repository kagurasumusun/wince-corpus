Shared Source Code in Windows CE .NET 4.1

Mandy Oei
Microsoft Corporation

September 2002

Applies to:
    Microsoft® Windows® CE .NET 4.1 developers using Microsoft Platform Builder.

Summary

Under the Microsoft Shared Source License Agreement, Windows CE provides access to source code, which is known as Shared Source code.

Having access to Shared Source code is helpful for the following reasons:

  • Shared Source code can enhance your understanding of the inner design of a component, and thus shorten the amount of time spent debugging code. For example, if you are writing code for a wireless network driver, you can examine the Shared Source code for that driver to debug your code faster.
  • Shared Source code can aid in your diagnoses of problems with a platform. For example, if there is a conflict in a previously created platform, you can examine the Shared Source code for that platform configuration to diagnose the problem.
  • Shared Source code can aid in your configuration of Windows CE on new hardware. For example, if you have a new hardware component, you can examine available Shared Source code that belongs to a similar hardware component. Studying a similar component can help you gain a better understanding of how to configure Windows CE on the new hardware component.

For information about using Shared Source code, see Shared Source Code in the product documentation.
