Comparison of Internet Explorer 5.5 and the Windows CE .NET Internet Browsers

Nola Van Vugt
Microsoft Corporation

August 2002

Applies to
    Microsoft® Windows® CE .NET platform developers and Web developers.

Summary

Microsoft® Windows® CE offers a choice of two different Internet browser features, each of which is optimized for different device requirements.

Internet Explorer 5.5 for Windows CE is the most desktop-compatible, feature-rich browser for the Windows CE operating system. Choose this browser when building a platform that will provide full Internet access, such as an Internet appliance or an interactive television that offers 5-key navigation and browsing capabilities. Optimizations for the embedded platform allow Internet Explorer for Windows CE to have a footprint that is approximately 2 MB smaller than its desktop counterpart.

Moreover, like its desktop counterpart, Internet Explorer 5.5 for Windows CE is capable of rendering documents that contain HTML, Dynamic HTML, and CSS data formats. There is limited support for HTML editing, and XML support is available if the MSXML parser is included in the platform. As a scripting host, Internet Explorer supports Microsoft JScript® 5.5, Microsoft Visual Basic® Scripting Edition, and Microsoft VBScript® 5.5, when these features are included on a platform.

Pocket Internet Explorer is the browser of choice for devices that require a Web browser but have stringent memory requirements and small displays, such as those on handheld devices or mobile phones. Choose Pocket Internet Explorer for controlled-content browsing. For example, content provided by a subscription service that offers content optimized for small form-factor browsers or when the browser is used only to access an intranet. Pocket Internet Explorer has a ROM footprint of just 800 KB.

For a detailed comparison of the features offered by Internet Explorer 5.5 for Windows CE, Pocket Internet Explorer, and Internet Explorer for Windows-based desktop platforms, see Choosing an Internet Browser in the Platform Builder product documentation.

For more information about designing a browser container in Windows CE, including information about the sample browser container applications, see Creating an Internet Browser Container Application in the Platform Builder product documentation. The sample browser container application, IESAMPLE, provides the familiar Internet Explorer user interface, including forward and backward navigation, Favorites, and Search. Source code for a full-screen browser is also provided in Platform Builder.
