JScript 5.5 Features

JScript includes the following features:

  • JScript is widely supported. If your application needs to run on any Internet platform, anywhere, JScript is the scripting language of choice.
  • JScript is loosely typed. You cannot explicitly declare data types in JScript. Moreover, in many cases, JScript performs conversions automatically when needed. For example, if you add a number to an item consisting of text (a string), the number is converted to text.
  • JScript is able to evaluate code at run time. This allows you to redefine your program dynamically, giving scripts, especially on a DHTML page, greater flexibility.
  • JScript's prototype-based object orientation provides the benefits of an object-oriented language without statically defined classes.
  • JScript includes support for regular expressions.
  • JScript supports error handling, using the try-throw-catch exception handler.
    Note   Script authoring is not supported.

A complete description of both ECMA and non-ECMA features of JScript 5.5 is available at this Microsoft Web site.
