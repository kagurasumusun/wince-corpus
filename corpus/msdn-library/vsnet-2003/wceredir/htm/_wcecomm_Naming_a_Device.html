Naming a Device

To use the redirector, a Windows CE–based device must have a unique name. The device name can be changed in the System Control Panel, or preconfigured by setting the REG_SZ value under the HKEY_LOCAL_MACHINE\Ident\Name key. The name must include:

  • From 1 to 15 characters.
  • A leading character in the range 'a'-'z' or 'A'-'Z.'
  • The remaining characters in the range 'a'-'z', 'A'-'Z', '0'-'9', or '-.'
    Note   Check with your network administrator to determine a valid name.

The System Control Panel does not check for invalid names, however the redirector will not function correctly if an invalid name is entered. This restriction also applies to other computer names accessed through the redirector, so servers whose names do not fit the name restrictions mentioned earlier may not be accessible to Windows CE.

If the host name has been changed from the default value, the new host name is registered on the network when a network interface is initialized. The host name is also registered on the network if it is changed using the sethostname function. If the device name is not changed from the default, or if there is an error registering the name, a dialog box appears prompting the user to change the device name and retry the operation.
