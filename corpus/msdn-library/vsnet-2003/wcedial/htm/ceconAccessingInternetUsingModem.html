Accessing the Internet Using a Modem

With a modem installed, a Windows CE–based device can be used to establish a RAS connection. If your device is not equipped with a modem, a PC Card modem or an external modem is required to use RAS. See the modem manufacturer's installation guide.

With a Windows CE device, a user can access the Internet. Using Windows CE and RAS, a user can make an Internet Protocol (IP) call over a PPP connection to an Internet host computer.

A corporation can establish a remote access server using Windows CE-based device with connections through a router to the Internet. The server can operate isolated from the corporate network for added security. Users can dial one number for both Internet access and access to the corporate local area network (LAN).
