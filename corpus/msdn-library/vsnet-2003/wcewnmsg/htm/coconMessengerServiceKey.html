Messenger Service Registry Settings

The following table shows the registry values for the HKEY_CURRENT_USER\Software\Microsoft\MessengerService key. These values are set by the operating system developers should not be modified by application developers using the Registry Editor.

Value : type Description
FirstTimeUser : REG_DWORD Default setting is 0. This value can be set to either 0 (True) or 1 (False). If set to 0, the Messenger Service wizard is launched the first time that Windows Messenger is launched. If set to 1, the wizard is not launched.
PrimaryService : REG_SZ Default setting is "MSN Messenger Service". Specifies the primary messenger service.
IMSBHide : REG_DWORD Default setting is 1 (enabled). Specifies whether the Instant Messenger status bar is displayed or not.
Server : REG_SZ Specifies the server. Default setting is "messenger.hotmail.com."
Installation Directory : REG_SZ Specifies the directory to which Messenger Service will be installed. Defaults to "Windows <file://\\Windows>".
