Windows Messenger Security

Users should verify the login name before responding to messages to avoid information disclosure to unknown individuals. The login name is available in the Properties dialog box. In addition, users should not rely on nicknames because different contacts can have the same nicknames.

Default Registry Settings

You should be aware of the registry settings that impact security. If a value has security implications you will find a Security Note in the registry settings documentation.

For information on Windows Messenger registry settings, see Windows Messenger Registry Settings.
