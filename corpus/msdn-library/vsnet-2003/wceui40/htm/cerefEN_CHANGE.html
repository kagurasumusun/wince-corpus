EN_CHANGE

This message indicates that the user has taken an action that could have altered text in an edit control. Unlike the EN_UPDATE message, this message is sent after Windows CE updates the screen. The parent window of the edit control receives this message through the WM_COMMAND message. 

EN_CHANGE 
idEditCtrl = (int) LOWORD (wParam);
hwndEditCtrl = (HWND) lParam;

Parameters

idEditCtrl
Identifier of the edit control.
hwndEditCtrl
Handle to the edit control.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Winuser.h Windows.h  

See Also

EN_UPDATE, WM_COMMAND
