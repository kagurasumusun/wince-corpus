BM_GETCHECK

This message is sent by an application to retrieve the check state of a radio button or check box. 

BM_GETCHECK wParam = 0; 
lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

A button created with the BS_AUTOCHECKBOX, BS_AUTORADIOBUTTON, BS_AUTO3STATE, BS_CHECKBOX, BS_RADIOBUTTON, or BS_3STATE returns one of the values described in the following table.

Value Description
BST_CHECKED The button is checked.
BST_INDETERMINATE The button is grayed, indicating an indeterminate state (applies only if the button has the BS_3STATE or BS_AUTO3STATE style).
BST_UNCHECKED The button is unchecked.

If the button has any other style, the return value is zero.

Requirements

Runs On Versions Defined in Include Link to
Windows CE OS 1.0 and later Winuser.h
