Adding Tab Stops and Margins

To set tab stops in a multiline edit control, use the EM_SETTABSTOPS message. The default placement for a tab stop is every eight characters. When you add text to the edit control, tab characters in the text automatically generate space up to the next tab stop. The EM_SETTABSTOPS message does not cause Windows CE to redraw the text automatically. To redraw the text, call the InvalidateRect function. The EM_SETTABSTOPS message applies to multiline edit controls only.

To set the width of the left margin and the right margin for an edit control, use the EM_SETMARGINS message. After you send this message, Windows CE redraws the edit control to reflect the new margin settings. You can retrieve the width of the left margin or the right margin by sending the EM_GETMARGINS message. By default, the margins of the edit control are set to be just wide enough to accommodate the largest character horizontal overhang, known as a negative ABC width, for the font that currently is in use in the edit control.
