ListView_GetImageList

This macro retrieves the handle to an image list used for drawing list view items. You can use this macro or send the LVM_GETIMAGELIST message explicitly. 

HIMAGELIST ListView_GetImageList( 
HWND hwnd, 
int iImageList 
);

Parameters

hwnd
Handle to the list view control.
iImageList
Image list to retrieve. It is one of the following values.
Value Description
LVSIL_NORMAL Image list with large icons.
LVSIL_SMALL Image list with small icons.
LVSIL_STATE Image list with state images.

Return Values

The handle to the specified image list indicates success. NULL indicates failure.

Remarks

Windows CE supports a new value for the iImageList parameter. The LVSIL_HEADER constant specifies that the image list to be retrieved is the image list displayed in the list view's header control in report view.

Related message: LVM_GETIMAGELIST

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
