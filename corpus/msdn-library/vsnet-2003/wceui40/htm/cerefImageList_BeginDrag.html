ImageList_BeginDrag

This function begins dragging an image. 

BOOL WINAPI ImageList_BeginDrag(
HIMAGELIST himlTrack, 
int iTrack, 
int dxHotspot, 
int dyHotspot 
);

Parameters

himlTrack
[in] Handle to the image list.
iTrack
[in] Index of the image to drag.
dxHotspot and dyHotspot
[in] Specifies the location of the drag position relative to the upper-left corner of the image.

Return Values

Nonzero indicates success. Zero indicates failure.

Remarks

This function creates a temporary image list that is used for dragging. In response to subsequent WM_MOUSEMOVE messages, you can move the drag image by using the ImageList_DragMove function. To end the drag operation, you can use the ImageList_EndDrag function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h   Commctrl.lib, Imgctl.lib
