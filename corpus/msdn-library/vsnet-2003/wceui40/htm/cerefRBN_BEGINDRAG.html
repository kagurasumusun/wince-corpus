RBN_BEGINDRAG

This message is sent by a rebar control when the user begins dragging a band. It is sent in the form of a WM_NOTIFY message. 

RBN_BEGINDRAG lpnmrb = (LPNMREBAR)lParam;

Parameters

lpnmrb
Long pointer to a NMREBAR structure that contains information about the notification.

Return Values

Return zero to allow the rebar to continue the drag operation or nonzero to abort the drag operation.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
