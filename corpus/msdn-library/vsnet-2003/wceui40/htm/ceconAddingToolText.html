Adding Tool Text

When you add a tool to a ToolTip control, the lpszText member of the TOOLINFO structure must specify the address of the string to display for the tool. You can change the text any time after you add the tool by using the TTM_UPDATETIPTEXT message.

If the high-order word of lpszText is 0, the low-order word must be the identifier of a string resource. When the ToolTip control needs the text, the system loads the specified string resource from the application instance that the hinst member of TOOLINFO identifies.

If you specify the LPSTR_TEXTCALLBACK value in lpszText, the ToolTip control notifies the window that the hwnd member of TOOLINFO specifies whenever the ToolTip control needs to display text for the tool. The ToolTip control notifies the window by sending a TTN_GETDISPINFO notification to the window. This notification includes a pointer to the NMTTDISPINFO structure, which contains an NMHDR structure that specifies the window handle and the application-defined identifier for the tool. The window examines these structures to determine the tool for which the ToolTip needs text, and the window fills the appropriate structure members with information that the ToolTip control needs to display the string.

The maximum length of the ToolTip text is 80 characters. Because of a limitation in the current version of the DrawText function, the ToolTip clips and does not wrap overly long ToolTip text that does not include spaces when the string is too long to fit in the ToolTip window. This clipping occurs regardless of any settings that are present in the control.

Many applications create toolbars that contain tools that correspond to menu commands. For such tools, your application can be more convenient for the user if the ToolTip control displays the same text as the corresponding menu item. The operating system (OS) automatically strips the ampersand (&) accelerator characters from all of the strings that an application passes to a ToolTip control, unless the control has the TTS_NOPREFIX style.

To retrieve the text for a tool, use the TTM_GETTEXT message.
