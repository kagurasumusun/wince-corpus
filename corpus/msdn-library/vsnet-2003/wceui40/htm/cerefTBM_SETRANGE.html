TBM_SETRANGE

This message sets the range — minimum and maximum positions — for the slider in a trackbar. 

TBM_SETRANGE wParam = (WPARAM)(BOOL) fRedraw; 
lParam = (LPARAM)MAKELONG(lMinimum,lMaximum);

Parameters

fRedraw
Redraw flag. If set to TRUE, the trackbar is redrawn after the range is set. If set to FALSE, the message sets the range but does not redraw the trackbar.
lMinimum
Minimum position for the slider.
lMaximum
Maximum position for the slider.

Return Values

None.

Remarks

If the current slider position is outside the new range, the TBM_SETRANGE message sets the slider position to the new maximum or minimum value.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
