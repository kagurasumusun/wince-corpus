TBM_GETLINESIZE

This message retrieves the size of the line for a trackbar. The line size affects how much the slider moves for the TB_LINEUP and TB_LINEDOWN messages.

Retrieves the number of logical positions the trackbar's slider moves in response to keyboard input from the arrow keys, such as the RIGHT ARROW or DOWN ARROW keys. The logical positions are the integer increments in the trackbar's range of minimum to maximum slider positions. 

TBM_GETLINESIZE wParam = 0; 
lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

Returns a 32-bit value that specifies the line size for the trackbar.

Remarks

The default setting for the line size is 1.

The trackbar also sends the TB_LINEUP and TB_LINEDOWN messages to its parent window when the user presses the arrow keys.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
