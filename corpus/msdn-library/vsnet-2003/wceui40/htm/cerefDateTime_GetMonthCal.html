DateTime_GetMonthCal

This macro retrieves the handle to a date and time picker's (DTP) child month calendar control.

HWND DateTime_GetMonthCal( 
HWND hwndDP
);

Parameters

hwndDP
Handle to a DTP control.

Return Values

Returns the handle to a DTP control's child month calendar control.

Remarks

DTP controls create a child month calendar control when the user clicks the drop-down arrow. When the month calendar is no longer needed, it is destroyed. Therefore, your application must not rely on a static handle to the DTP's child month calendar.
