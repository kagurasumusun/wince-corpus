ImageList_SetIconSize

This function sets the dimensions of images in an image list and removes all images from the list. 

BOOL WINAPI ImageList_SetIconSize(
HIMAGELIST himl, 
int cx, 
int cy 
);

Parameters

himl
[in] Handle to the image list.
cx
[in] Width, in pixels, of the images in the image list. All images in an image list have the same dimensions.
cy
[in] Height, in pixels, of the images in the image list. All images in an image list have the same dimensions.

Return Values

Nonzero indicates success. Zero indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h   Commctrl.lib, Imgctl.lib
