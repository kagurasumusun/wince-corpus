LVN_ENDLABELEDIT

This message notifies a list view control parent window about the end of label editing for an item. It is sent in the form of a WM_NOTIFY message. 

LVN_ENDLABELEDIT pdi = (LV_DISPINFO FAR *) lParam;

Parameters

pdi
Pointer to an NMLVDISPINFO structure. The item member of this structure is an LVITEM structure whose iItem member identifies the item being edited. The pszText member of item contains a valid value when the LVN_ENDLABELEDIT message is sent, regardless of whether the LVIF_TEXT flag is set in the mask member of the LVITEM structure.

If the user cancels editing, the pszText member of the LVITEM structure is NULL; otherwise, pszText is the address of the edited text.

Return Values

If the pszText member of the LVITEM structure is non-NULL, return TRUE to set the item's label to the edited text. Return FALSE to reject the edited text and revert to the original label.

If the pszText member of the LVITEM structure is NULL, the return value is ignored.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
