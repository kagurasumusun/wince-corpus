Undoing Text Operations

Every edit control maintains an undo flag that indicates whether an application can reverse the most recent operation, such as a text deletion, on the control. The edit control sets the undo flag to indicate that the operation can be undone and resets it to indicate that the operation cannot be undone. You can determine the setting of the undo flag by sending the control an EM_CANUNDO message.

To undo the most recent operation, send the control an EM_UNDO message. An operation can be undone if no other operation on the edit control occurs first. For example, a user can delete text, replace the text or undo the deletion, and then delete the text again or undo the replacement. The EM_UNDO message applies to both single-line and multiline edit controls. The EM_UNDO message always succeeds for single-line edit controls, but can fail for multiline edit controls.
