TreeView_GetFirstVisible

This macro retrieves the first visible item in a tree-view control window. You can use this macro, or you can explicitly send the TVM_GETNEXTITEM message with the TVGN_FIRSTVISIBLE flag.

HTREEITEM TreeView_GetFirstVisible( 
hwnd 
);

Parameters

hwnd
Handle to the tree view control.

Return Values

The handle to the item indicates success. NULL indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h

TreeView_GetNextVisible, TreeView_GetPrevVisible, TVM_GETITEMRECT, TVM_GETNEXTITEM
