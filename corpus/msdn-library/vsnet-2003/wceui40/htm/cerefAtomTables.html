Atom Tables

The global atom table is the atom table that is available to all applications. When an application places a string in the global atom table, the OS generates an atom that is unique throughout the OS. Any application that has the atom can obtain the string that the atom identifies by querying the global atom table.

Windows CE does not allow an application to define a local atom table that is available only within the application itself.
