RectInRegion

This function determines whether any part of the specified rectangle is within the boundaries of a region. 

BOOL RectInRegion(
HRGN hrgn, 
const RECT *lprc
);

Parameters

hrgn
[in] Handle to the region.
lprc
[in] Long pointer to a RECT structure that contains the coordinates of the rectangle. The lower and right edges of the rectangle are not included.

Return Values

Nonzero indicates that any part of the specified rectangle lies within the boundaries of the region. Zero indicates that no part of the specified rectangle lies within the boundaries of the region.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Wingdi.h Windows.h Coredll.lib
