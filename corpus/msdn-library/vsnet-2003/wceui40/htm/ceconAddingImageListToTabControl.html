Adding an Image List to a Tab Control

Each tab can have an icon that is associated with it. An index specifies the icon into the image list for the tab control. When you create a tab control, it has no image list that is associated with it. You can use the ImageList_Create function to create an image list. You can assign it to a tab control by using the TCM_SETIMAGELIST message.

You can add an image to the image list of a tab control just as you would add one to any other image list. To ensure that each tab remains associated with its assigned image, remove images by using the TCM_REMOVEIMAGE message instead of the ImageList_Remove function.

Because destroying a tab control does not destroy an associated image list, you must destroy the image list separately. Retaining the image list might be useful if you want to assign the same image list to multiple tab controls.

To retrieve the handle to the image list that currently is associated with a tab control, you can use the TCM_GETIMAGELIST message.
