TabCtrl_HighlightItem

This macro sets the highlight state of a tab item.

BOOL TabCtrl_HighlightItem(
HWND hwndTab, 
INT idItem, 
WORD fHighlight 
);

Parameters

hwndTab
Handle to the tab control.
idItem
Zero-based index of a tab control item.
fHighlight
Value that specifies the highlight state to be set. If this value is nonzero, the tab is highlighted. If this value is zero, the tab is set to its default state.

Return Values

Nonzero indicates success. Zero indicates otherwise.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
