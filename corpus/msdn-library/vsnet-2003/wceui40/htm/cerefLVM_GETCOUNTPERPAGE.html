LVM_GETCOUNTPERPAGE

This message calculates the number of items that can fit vertically in the visible area of a list view control when in list or report view. Only fully visible items are counted. You can send this message explicitly or by using the ListView_GetCountPerPage macro. 

LVM_GETCOUNTPERPAGE wParam = 0; 
lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

The number of fully visible items indicates success. If the current view is icon or small icon view, the return value is the total number of items in the list view control.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
