CommandBar_InsertComboBox

This function inserts a combo box into the command bar. 

HWND CommandBar_InsertComboBox(
HWND hwndCB, 
HINSTANCE hInst, 
int iWidth, 
UINT dwStyle, 
WORD idComboBox, 
WORD iButton
);

Parameters

hwndCB
Handle to the command bar's window. This handle is returned by the CommandBar_Create function when the command bar is created.
hInst
Handle to the application instance.
iWidth
Integer that contains the width, in pixels, of the combo box.
dwStyle
Specifies the window styles to apply to the combo box. The WS_VISIBLE and WS_CHILD styles are applied automatically. For descriptions of other styles you can apply, see Window and Message Box Styles.
idComboBox
Identifier of the combo box to insert.
iButton
Zero-based index of a button in the command bar. CommandBar_InsertComboBox inserts the combo box to the left of this button.

Return Values

The window handle to the combo box indicates success. NULL indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h   Commctrl.lib
