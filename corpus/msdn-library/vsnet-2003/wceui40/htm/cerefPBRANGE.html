PBRANGE

This structure contains information about the high and low limits of a progress bar control. This structure is used with the PBM_GETRANGE message. 

typedef struct {
int iLow;
int iHigh; } 
PBRANGE, *PPBRANGE;

Members

iLow
Specifies the current low limit for the progress bar control.
iHigh
Specifies the current high limit for the progress bar control.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
