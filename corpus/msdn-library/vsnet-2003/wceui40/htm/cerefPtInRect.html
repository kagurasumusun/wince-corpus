PtInRect

This function determines whether the specified point lies within the specified rectangle. A point is within a rectangle if it lies on the left or top side or is within all four sides. A point on the right or bottom side is considered outside the rectangle. 

BOOL PtInRect(
const RECT *lprc, 
POINT pt
);

Parameters

lprc
Long pointer to a RECT structure that contains the specified rectangle.
pt
Specifies a POINT structure that contains the specified point.

Return Values

Nonzero indicates that the specified point lies within the rectangle. Zero indicates that the specified point does not lie within the rectangle.

To get extended error information, call GetLastError.

Requirements
