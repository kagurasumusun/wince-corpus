TCM_SETPADDING

This message sets the amount of space (padding) around each tab’s icon and label in a tab control. You can send this message explicitly or by using the TabCtrl_SetPadding macro. 

TCM_SETPADDING wParam = 0; 
lParam = MAKELPARAM(cx,cy);

Parameters

wParam
Not used.
cx and cy
Amount of horizontal and vertical padding, in pixels.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
