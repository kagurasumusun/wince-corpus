TB_SETCMDID

This message sets the command identifier of a toolbar button. 

TB_SETCMDID wParam = (WPARAM)(UINT) index; 
lParam = (WPARAM)(UINT) cmdId;

Parameters

index
Zero-based index of the button for which the command identifier is to be set.
cmdId
Command identifier.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
