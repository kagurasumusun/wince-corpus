Using Overlays in Image Lists

Every image list includes a list of indexes to be used as overlays. An overlay is an image drawn transparently over another image. Any image that currently is in the image list can be used as an overlay. You can specify up to four overlays for each image list.

You can add the index of an image to the list of overlays by using the ImageList_SetOverlayImage function, and by specifying the handle to the image list, the index of the existing image, and the overlay index that you want. The overlay indexes are one-based, instead of zero-based, because an overlay index of zero means that no overlay will be used.

Specify an overlay when you draw an image by calling the ImageList_Draw function or the ImageList_DrawEx function. The overlay is specified by performing a logical OR operation between the flags for drawing styles that you want to use and the result of the INDEXTOOVERLAYMASK macro. INDEXTOOVERLAYMASK formats the overlay index for its inclusion with the flags that are used with these functions.
