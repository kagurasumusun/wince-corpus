TabCtrl_GetRowCount

This macro retrieves the current number of rows of tabs in a tab control. You can use this macro or send the TCM_GETROWCOUNT message explicitly.

int TabCtrl_GetRowCount( 
HWND hwnd 
);

Parameters

hwnd
Handle to the tab control.

Return Values

Returns the number of rows of tabs.

Remarks

Only tab controls that have the TCS_MUTLILINE style can have multiple rows of tabs.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
