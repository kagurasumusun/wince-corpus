ListView_GetExtendedListViewStyle

This macro retrieves the extended styles that are currently in use for a specified list view control. 

DWORD ListView_GetExtendedListViewStyle(
HWND hwndLV 
);

Parameters

hwndLV
Handle to a list view control.

Return Values

Returns a DWORD value that represents the styles currently in use for a specified list view control. This can be a combination of extended styles.

Remarks

Related message: LVM_GETEXTENDEDLISTVIEWSTYLE

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
