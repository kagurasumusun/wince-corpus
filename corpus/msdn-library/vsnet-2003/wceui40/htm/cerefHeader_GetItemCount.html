Header_GetItemCount

This macro retrieves a count of the items in a header control. You can use this macro or send the HDM_GETITEMCOUNT message explicitly. 

int Header_GetItemCount( 
hwndHD 
);

Parameters

hwndHD
Handle to the header control.

Return Values

The number of items indicates success. –1 indicates failure.

Remarks

The Header_GetItemCount macro is defined as follows. 

#define Header_GetItemCount(hwndHD)\
(int)SendMessage((hwndHD), HDM_GETITEMCOUNT, 0, 0L)

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h   Commctrl.lib
