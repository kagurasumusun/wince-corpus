NMDATETIMEFORMATQUERY

This structure is used with the DTN_FORMATQUERY message. 

typedef struct tagNMDATETIMEFORMATQUERY{
NMHDR nmhdr;
LPCTSTR pszFormat;
SIZE szMax;} 
NMDATETIMEFORMATQUERY, FAR *LPNMDATETIMEFORMATQUERY;

Members

nmhdr
NMHDR structure that contains information about this message.
pszFormat
Pointer to a null-terminated substring that defines a DTP control callback field. The substring is one or more X characters followed by a NULL.
szMax
SIZE structure that must be filled with the maximum size of the text to be displayed in the callback field.

Remarks

The NMDATETIMEFORMATQUERY structure contains information about a date and time picker (DTP) control callback field. It contains a substring (taken from the control's format string) that defines a callback field. The structure receives the maximum allowable size of the text that will be displayed in the callback field.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
