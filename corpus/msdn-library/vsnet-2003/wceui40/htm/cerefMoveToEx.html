MoveToEx

This function updates the current position to the specified point and optionally retrieves the previous position.

WINGDIAPI BOOL WINAPI MoveToEx(
HDC hdc,
int X,
int Y,
LPPOINT lpPoint
);

Parameters

hdc
[in] Handle to a device context.
X
[in] Integer that specifies the x-coordinate of the new position, in logical units.
Y
[in] Integer that specifies the y-coordinate of the new position, in logical units.
lpPoint
[out] Pointer to a POINT structure that receives the previous position. If this parameter is a NULL pointer, MoveToEx does not retrieve the previous position.

Return Values

A nonzero value indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

The MoveToEx function affects all drawing functions.

Requirements
