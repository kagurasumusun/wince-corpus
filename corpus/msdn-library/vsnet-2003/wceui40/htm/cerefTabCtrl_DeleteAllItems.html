TabCtrl_DeleteAllItems

This macro removes all items from a tab control. You can use this macro or send the TCM_DELETEALLITEMS message explicitly.

BOOL TabCtrl_DeleteAllItems( 
HWND hwnd 
);

Parameters

hwnd
Handle to the tab control.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
