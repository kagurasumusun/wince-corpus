TCM_DESELECTALL

This message resets items in a tab control, clearing any that were set to the TCIS_BUTTONPRESSED state.

TCM_DESELECTALL wParam = (WPARAM) (DWORD) fExcludeFocus;
lParam = 0;

Parameters

fExcludeFocus
Boolean that specifies the scope of the item deselection. If this parameter is set to FALSE, all tab buttons are reset. If it is set to TRUE, then all tab items except for the one currently selected are reset.
lParam
Not used.

Return Values

The return value for this message is not used.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
