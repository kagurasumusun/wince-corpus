NM_KILLFOCUS

Notifies a control's parent window that the control has lost the input focus. NM_KILLFOCUS is sent in the form of a WM_NOTIFY message. 

NM_KILLFOCUS lpnmh = (LPNMHDR) lParam;

Parameters

lpnmh
Address of an NMHDR structure that contains additional information about this message.

Return Values

The return value is ignored by the control.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
