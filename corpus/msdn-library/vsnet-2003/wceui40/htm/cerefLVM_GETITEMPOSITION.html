LVM_GETITEMPOSITION

This message retrieves the position of a list view item. You can send this message explicitly or by using the ListView_GetItemPosition macro. 

LVM_GETITEMPOSITION wParam = (WPARAM)(int) i; 
lParam = (LPARAM)(POINT FAR *) ppt;

Parameters

i
Index of the list view item.
ppt
Pointer to a POINT structure that receives the position of the item's upper-left corner, in view coordinates.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
