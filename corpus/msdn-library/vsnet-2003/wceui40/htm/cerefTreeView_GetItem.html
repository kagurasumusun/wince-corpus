TreeView_GetItem

This macro retrieves some or all of the attributes of a tree-view item. You can use this macro or send the TVM_GETITEM message explicitly.

BOOL TreeView_GetItem( 
hwnd, 
pitem 
);

Parameters

hwnd
Handle to the tree view control.
pitem
Pointer to a TVITEM structure that specifies the information to retrieve and receives information about the item. When the TVM_GETITEM message is sent, the hItem member identifies the item to retrieve information about, and the mask member specifies the attributes to retrieve.

If the mask member specifies the TVIF_TEXT value, the pszText member must contain the address of the buffer that receives the item text and the cchTextMax member must specify the size of the buffer.

If the mask member specifies the TVIF_STATE value, the stateMask member must specify the item state bits to retrieve. On output, the state member contains the values of the specified state bits.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
