Creating Tracking ToolTips

A ToolTip control also supports tracking ToolTips, which are ToolTip windows that you can position dynamically on the screen. By rapidly updating the position, the ToolTip window appears to move smoothly, or track. This functionality can be useful if you need ToolTip text to follow the position of the pointer as it moves.

To create a tracking ToolTip, use the TTM_ADDTOOL message and include the TTF_TRACK flag in the uFlags member of the accompanying TOOLINFO structure.

Your application must manually activate and deactivate a tracking ToolTip by using the TTM_TRACKACTIVATE message. While your ToolTip is active, your application must supply the location at which the ToolTip window appears by using the TTM_TRACKPOSITION message. Tracking ToolTip controls do not support the TTF_SUBCLASS style, so you must forward all mouse events from the parent window to the child window by using TTM_RELAYEVENT messages.

The following table shows the two placement styles that the TTM_TRACKPOSITION message can use when the message causes the ToolTip control to display the window.

Placement style Description
Next to the corresponding tool in a position that the control chooses. The location that is chosen is relative to the coordinates that you provide when you use this message. In this case, the ToolTip window appears to move beside the corresponding tool. This behavior is the default behavior.
At the pixel location that you specify when you use TTM_TRACKPOSITION. The control does not attempt to change the location of the ToolTip window from the coordinates that you provide. You must include the TTF_ABSOLUTE value in the uFlags member of the TOOLINFO structure when you create the tool to prompt this behavior.
