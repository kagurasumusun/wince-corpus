ListView_SetSelectionMark

This macro sets the selection mark in a list view control.

INT ListView_SetSelectionMark(
HWND hwndLV, 
INT iIndex 
);

Parameters

hwndLV
Handle to a list view control.
iIndex
Zero-based index of the list view item to be selected.

Return Values

Returns the previous selection mark, or –1 if there is no previous selection mark.

Remarks

The selection mark is the item index from which a multiple selection starts. This macro does not affect the selection state of the item.

Related message: LVM_SETSELECTIONMARK

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
