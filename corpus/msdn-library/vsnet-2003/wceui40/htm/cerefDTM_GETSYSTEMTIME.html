DTM_GETSYSTEMTIME

This message retrieves the currently selected time from a date and time picker (DTP) control and places it in a specified SYSTEMTIME structure.

DTM_GETSYSTEMTIME wParam = 0; 
lParam = (LPARAM) lpSysTime;

Parameters

wParam
Not used.
lpSysTime
Long pointer to the SYSTEMTIME structure that receives the system time information. This parameter must be a valid address and cannot be NULL.

Return Values

Returns GDT_VALID if the time information was placed successfully in the specified structure; or the message can return GDT_NONE if the control was set to the DTS_SHOWNONE style and the control check box was not selected.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
