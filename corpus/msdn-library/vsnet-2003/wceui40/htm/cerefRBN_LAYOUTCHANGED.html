RBN_LAYOUTCHANGED

This message is sent by a rebar control when you change the layout of the control’s bands. It is sent in the form of a WM_NOTIFY message. 

RBN_LAYOUTCHANGED lpnmhdr = (LPNMHDR) lParam;

Parameters

lpnmhdr
Long pointer to an NMHDR structure that contains additional information about this message.

Return Values

The return value for this message is not used.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h

WM_NOTIFY, NMHDR
