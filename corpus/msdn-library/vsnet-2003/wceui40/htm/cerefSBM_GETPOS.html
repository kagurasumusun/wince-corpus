SBM_GETPOS

This message is sent by an application to retrieve the current position of the scroll box of a scroll bar control. The current position is a relative value that depends on the current scrolling range. For example, if the scrolling range is 0 through 100 and the scroll box is in the middle of the bar, the current position is 50. 

SBM_GETPOS  wParam = 0; 
lParam = 0;

Return Values

The current position of the scroll box in the scroll bar indicates success.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
