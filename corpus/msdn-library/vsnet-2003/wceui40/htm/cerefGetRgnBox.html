GetRgnBox

This function retrieves the bounding rectangle of the specified region. 

int GetRgnBox(
HRGN hrgn, 
LPRECT lprc
);

Parameters

hrgn
[in] Handle to the region.
lprc
[out] Long pointer to a RECT structure that receives the bounding rectangle.

Return Values

The return value specifies the region's complexity. NULLREGION indicates that the region is empty. SIMPLEREGION indicates that the region is a single rectangle. COMPLEXREGION indicates that the region is more than a single rectangle. Zero indicates that the hrgn parameter does not identify a valid region

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Wingdi.h Windows.h Coredll.lib
