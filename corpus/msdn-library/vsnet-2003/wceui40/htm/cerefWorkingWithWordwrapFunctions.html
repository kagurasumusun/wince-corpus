Working with Wordwrap Functions

You can direct a multiline edit control to add or remove a soft line-break character—two carriage returns and a line feed—automatically at the end of wrapped text lines. An application can turn this feature on or off by sending an EM_FMTLINES message to the edit control. This message applies only to multiline edit controls and does not affect a line that ends with a hard line break—one carriage return and a line feed that are typed by a user.
