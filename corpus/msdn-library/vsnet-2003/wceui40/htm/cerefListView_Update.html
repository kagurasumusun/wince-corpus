ListView_Update

This macro updates a list view item. If the list view control has the LVS_AUTOARRANGE style, this macro causes the list view control to be arranged. You can use this macro or send the LVM_UPDATE message explicitly. 

BOOL ListView_Update( 
HWND hwnd, 
int iItem 
);

Parameters

hwnd
Handle to the list view control.
iItem

Index of the item to update.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Commctrl.h
