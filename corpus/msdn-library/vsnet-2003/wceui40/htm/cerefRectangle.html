Rectangle

This function draws a rectangle. The current pen outlines the rectangle and the current brush fills it. 

BOOL Rectangle(
HDC hdc, 
int nLeftRect, 
int nTopRect, 
int nRightRect, 
int nBottomRect
);

Parameters

hdc
[in] Handle to the device context.
nLeftRect
[in] Specifies the logical x-coordinate of the upper-left corner of the rectangle.
nTopRect
[in] Specifies the logical y-coordinate of the upper-left corner of the rectangle.
nRightRect
[in] Specifies width of the rectangle.
nBottomRect
[in] Specifies height of the rectangle.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

The current position is neither used nor updated by Rectangle. The extreme bottom and right edges of rectangle are not drawn because the bottom and right coordinates are treated as the width and height respectively of the rectangle instead of its edges.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Wingdi.h Windows.h Coredll.lib
