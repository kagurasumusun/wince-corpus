EM_SETREADONLY

This message sets or removes the read-only style (ES_READONLY) of an edit control. 

EM_SETREADONLY 
wParam = (WPARAM)(BOOL) fReadOnly;
lParam = 0L;

Parameters

fReadOnly
Boolean value that specifies whether to set or remove the ES_READONLY style. A value of TRUE sets the ES_READONLY style; a value of FALSE removes the ES_READONLY style. For more information, see Control Styles.
lParam
Not used; set to 0.

Return Values

Nonzero indicates success. Zero indicates failure.

Remarks

When an edit control has the ES_READONLY style, the user cannot change the text within the edit control.

To determine whether an edit control has the ES_READONLY style, use the GetWindowLong function with the GWL_STYLE flag.
