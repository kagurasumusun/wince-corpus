User Interface Services

The User Interface Services guide contains the following top-level topics:

  • Introduction to User Interface Services on Windows CE

    This topic provides an overview of the Graphics, Windowing, and Events Subsystem (GWES) module and, specifically, Windows CE User Interface Services. It also explains the specific components included in GWES and how those components work together to provide window management, event handling, and power management features. GWES also supports controls, menus, dialog boxes, resources, user input, and the graphics device interface (GDI).

  • Working with Windows and Messages

    This topic discusses windowing and messaging features. Emphasis is placed on creating, sizing, positioning, and destroying windows as well as sending and responding to messages.

  • Using Window Properties

    This topic discusses how to use window properties, which consist of any data that an application assigns to a window, usually as a handle to window-specific data.

  • Using Atoms

    This topic describes how to use atoms, which are 16-bit integers that identify strings that an application stores together with the integer.

  • Using Resources

    This topic provides information about resources such as dialog and message boxes, menus, icons, carets, bitmaps, and timers.

  • Creating Controls

    This topic explains how to add standard controls to a user interface (UI).

  • Receiving Keyboard Input

    This topic discusses how Windows CE supports keyboard input and describes how to use virtual keys.

  • Working with Graphics

    This topic describes the GDI included in Windows CE, including how to use GDI functions to draw lines, curves, closed figures, and bitmapped images. This topic also discusses how to control the color and style of the items that you draw and how to display the items on displays, printers, and other devices.

The User Interface Services documentation also includes a Programmer's Reference that describes the application programming interfaces (APIs) you can use to create a UI.
