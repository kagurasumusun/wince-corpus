NMLVFINDITEM

This structure that contains information the owner needs to find items requested by a virtual list view control. This structure is sent to the owner during notification using the LVN_ODFINDITEM message. 

typedef struct _NMLVFINDITEM {
NMHDR hdr;
int iStart;
LVFINDINFO lvfi;} 
NMLVFINDITEM, *PNMLVFINDITEM;

Members

hdr
NMHDR structure that contains information on this message.
iStart
Item index to act as the start of the search.
lvfi
LVFINDINFO structure that contains information necessary to perform a search.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
