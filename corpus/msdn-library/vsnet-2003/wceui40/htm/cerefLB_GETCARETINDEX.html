LB_GETCARETINDEX

This message is sent by an application to determine the index of the item that has the focus rectangle in a multiple-selection list box. The item may or may not be selected. 

LB_GETCARETINDEX wParam = 0; 
lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

The return value is the zero-based index of the list box item that has the focus rectangle. If the list box is a single-selection list box, the return value is the zero-based index of the item selected, if any.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Winuser.h
