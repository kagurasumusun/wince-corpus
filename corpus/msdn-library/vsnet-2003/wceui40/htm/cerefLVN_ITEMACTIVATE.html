LVN_ITEMACTIVATE

This message is sent by a list view control when the user activates an item. It is sent in the form of a WM_NOTIFY message. 

LVN_ITEMACTIVATE lpnmlv = (LPNMLISTVIEW)lParam;

Parameters

lpnmlv
Long pointer to an NMLISTVIEW structure that contains message data. The iItem, iSubItem, and ptAction members contain data about the activated item. If the item was activated from the keyboard, the ptAction member will contain –1 in its x and y members.

Return Values

The application receiving this message must return zero.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Commctrl.h
