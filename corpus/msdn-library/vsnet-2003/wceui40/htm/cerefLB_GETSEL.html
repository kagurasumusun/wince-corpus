LB_GETSEL

This message is sent by an application to retrieve the selection state of an item. 

LB_GETSEL wParam = (WPARAM) index; 
lParam = 0;

Parameters

index
Zero-based index of the item.
lParam
Not used.

Return Values

A value greater than zero indicates that an item has been selected. Zero indicates otherwise. LB_ERR indicates that an error has occurred.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Winuser.h
