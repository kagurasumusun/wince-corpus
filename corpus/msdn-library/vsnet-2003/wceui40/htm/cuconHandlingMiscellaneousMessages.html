Handling Miscellaneous Messages

The TTM_GETCURRENTTOOL and TTM_GETTOOLINFO messages fill a TOOLINFO structure with information about a tool that you have registered with a ToolTip control. The TTM_SETTOOLINFO message enables you to change the information that a ToolTip control maintains for a particular tool. The TTM_DELTOOL message deletes a tool from a ToolTip control.

The following table shows the messages that the window procedure for the TOOLTIPS_CLASS window class handles.

Message Default processing
WM_CREATE Ensures that the ToolTip control has the WS_EX_TOOLWINDOW and WS_POPUP window styles. This message also allocates memory and initializes internal variables.
WM_DESTROY Frees resources that the OS allocated for the ToolTip control.
WM_GETFONT Returns the handle of the font that the ToolTip control uses to draw text.
WM_MOUSEMOVE Hides the ToolTip window.
WM_PAINT Draws the ToolTip window.
WM_SETFONT Sets the handle of the font that the ToolTip control uses to draw text.
WM_TIMER Hides the ToolTip window if the tool changes position or if the cursor moves outside the tool. Otherwise, this message shows the ToolTip window.
WM_SETTINGCHANGE Resets internal variables that depend on system metrics.
