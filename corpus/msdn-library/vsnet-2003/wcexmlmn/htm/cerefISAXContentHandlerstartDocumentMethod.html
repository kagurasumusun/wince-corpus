ISAXContentHandler::startDocument Method

This method receives notification of the beginning of a document. The reader invokes the startDocument method only once. It is invoked before any other methods in the ISAXContentHandler interface, with the exception of the putDocumentLocator method.

HRESULT startDocument();

Parameters

None.

Return Values

S_OK
Returned if successful.
E_FAIL
Returned if the parse operation should be aborted.

Requirements
