CUSTDATAITEM

This structure is used for holding custom data.

typedef struct tagCUSTDATAITEM {
GUID guid;
VARIANTARG varValue;
} CUSTDATAITEM, *LPCUSTDATAITEM;

Members

guid
Globally unique identifier (GUID) for this data item.
varValue
Value of this data item.
