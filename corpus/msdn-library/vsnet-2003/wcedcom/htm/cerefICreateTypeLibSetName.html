ICreateTypeLib::SetName

This method sets the name of the type library.

HRESULT SetName( 
OLECHAR FAR *szName
);

Parameters

szName
Null-terminated string that contains the name to be assigned to the library.

Return Values

One of the values described in the following table is returned.

Value Description
S_OK Success.
STG_E_INSUFFICIENTMEMORY Out of memory.
E_OUTOFMEMORY Out of memory.
E_INVALIDARG One or more of the parameters is invalid.
TYPE_E_INVALIDSTATE The state of the type library is not valid for this operation.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Oaidl.h Oaidl.h
