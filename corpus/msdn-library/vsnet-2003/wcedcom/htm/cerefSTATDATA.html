STATDATA

This structure specifies each advisory connection. It is used for enumerating current advisory connections. It holds data returned by the IEnumSTATDATA enumerator. This enumerator interface is returned by IDataObject:DAdvise. Each advisory connection is specified by a unique STATDATA structure.

typedef struct tagSTATDATA { 
FORMATETC    formatetc; 
DWORD    grfAdvf; 
IadviseSink  *pAdvSink; 
DWORD   dwConnection; 
} STATDATA;

Members

formatetc
FORMATETC structure for the data of interest to the advise sink. The advise sink receives notification of changes to the data specified by this FORMATETC structure.
grfAdvf
ADVF enumeration value that determines when the advisory sink is notified of changes in the data.
pAdvSink
Pointer for the IAdviseSink interface that will receive change notifications.
dwConnection
The token that uniquely identifies the advisory connection. This token is returned by the method that sets up the advisory connection.
