DVASPECTINFO

This structure is used in the IViewObject::Draw method to optimize rendering of an inactive object by making more efficient use of the GDI. The pvAspect parameter in IViewObject::Draw points to this structure. 

typedef struct STRUCT tagDVASPECTINFO {
UNIT  cb; 
DWORD  dwFlags; 
} DVASPECTINFO;

Members

cb
Size of the structure in bytes. The size includes this member as well as the dwFlags member.
dwFlags
A value taken from the DVASPECTINFOFLAG enumeration.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later Ocidl.h Ocidl.h
