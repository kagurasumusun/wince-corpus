IProvideClassInfo2:IProvideClassInfo

This interface is a simple extension to IProvideClassInfo for the purpose of making it quick and easy to retrieve an object's outgoing interface IID for its default event set. The mechanism, the added IProvideClassInfo2::GetGUID method, is extensible for other types of GUIDs as well.

When to Implement

An object implements this interface to provide type information for its outgoing interfaces.

When to Use

Call the method in this interface to obtain type information on an object's outgoing interfaces.

Methods in Vtable Order

IProvideClassInfo method Description

IProvideClassInfo2 method Description
GetGUID Returns the GUID for the object's outgoing IID for its default event set.
