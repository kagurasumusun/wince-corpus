CoFileTimeNow

This function returns the current time as a FILETIME structure.

HRESULT CoFileTimeNow(
FILETIME *lpFileTime 
);

Parameters

lpFileTime
[out] Pointer to return the FILETIME structure.

Return Values

S_OK
The current time was converted to a FILETIME structure.
