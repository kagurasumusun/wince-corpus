ResourceRequest

This function allows drivers to use the resources made available by ResourceRelease.

BOOL ResourceRequest(
DWORD dwResId, 
DWORD dwBase, 
DWORD dwLen
);

Parameters

dwResId
[in] The resource identifier, which is a label for a set of numbers. The following table shows the existing resource identifiers and their values.
Resource Identifier Value
RESMGR_IRQ 0x00001
RESMGR_IOSPACE 0x00002

Resource identifiers between the values in the following table are for your use. Values below RESMGR_BASE_OEM are reserved. Values above RESMGR_MAX_OEM are reserved for future use. The following table shows these resource identifiers and their values.

Resource Identifier Value
RESMGR_BASE_OEM 0x00080000
RESMGR_MAX_OEM 0x000FFFFF
dwBase
[in] The smallest numbered resource to request.
dwLen
[in] The number of resources to request. The range of resources requested is dwBase + dwLen – 1.

Return Values

TRUE indicates success. FALSE indicates failure.

You cannot wind up with a partial allocation or a partial release of resources.
