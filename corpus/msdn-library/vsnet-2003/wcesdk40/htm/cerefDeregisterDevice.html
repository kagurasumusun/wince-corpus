DeregisterDevice

This function deregisters a registered device. This function is superseded by DeactivateDevice.

BOOL DeregisterDevice(
Handle hDevice
);

Parameters

hDevice
[in] Handle to a registered device returned from RegisterDevice.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This function is superseded by DeactivateDevice.

The Device Manager calls this function when a device is removed from the system or if the system has been shut down. This function calls the device driver's XXX_Deinit function.

The DeregisterDevice function can be used if a device is removed from the system or is being shut down.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later   Winbase.h
