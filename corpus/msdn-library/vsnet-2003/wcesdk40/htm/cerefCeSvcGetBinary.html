CeSvcGetBinary

This function reads a binary value from a registry subkey and copies the data into a buffer.

HRESULT CeSvcGetBinary( 
HCESVC hSvc, 
LPCTSTR pszValName,
LPBYTE lpData, 
LPDWORD pcbVal
);

Parameters

hSvc
[in] Handle to a registry subkey.
pszValName
[in] Pointer to a null-terminated string that contains the name of the value.
lpData
[out] Long pointer to the buffer for read data.
pcbVal
[in/out] Pointer to a variable that specifies the size, in bytes, of the buffer pointed to by the lpData parameter. When the function returns, this variable contains the size of the data copied to lpData.

Return Values

S_OK indicates success. On failure an appropriate Win32 error code is returned.

Remarks

This function is part of CEUTIL, a utility DLL for dealing with desktop registry entries for Windows CE. CEUTIL functions are for use by desktop applications that need to communicate remotely with Windows CE–based devices. These functions are not available to applications running on Windows CE–based devices.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later   Ceutil.h
