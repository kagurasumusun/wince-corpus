RequestDeviceNotifications

This function requests notifications for the appearance and disappearance of device interfaces.

HANDLE RequestDeviceNotifications(
const GUID *devclass,
HANDLE hMsgQ
BOOL fAll
);

Parameters

devclass
[in] Pointer to a device interface GUID. If it is NULL, then notifications are requested for all device interfaces. NULL is not recommended because it creates extra work for the Device Manager and, for most uses, is unnecessary. Typically you know in advance what interfaces you are interested in.
hMsgQ
[in] A handle to a message queue received from CreateMsgQueue.
fAll
[in] Notifications for all currently existing devices are sent if fAll is TRUE. Otherwise if fAll is FALSE, then notifications are sent only for subsequent changes.

Return Values

A notification handle. Do not attempt to wait on this handle, only wait on the message queue handle. This handle should only be used as the parameter to StopDeviceNotifications.

Remarks

The message queue referenced by hMsgQ should have been created with fixed-size messages. The maximum size of a message depends on the interface type requested but cannot exceed MAX_DEVCLASS_NAMELEN in any case.

The notifications sent to hMsgQ will be structured as a sequence of DEVDETAIL structures with extra TCHAR types on the end to account for the instance names. For more information on the defined GUIDs see Device Interface Classes.
