AdvertiseInterface

This function allows a device driver to announce what interfaces it exposes.

BOOL AdvertiseInterface(
const GUID *devclass,
LPCWSTR name,
BOOL fAdd
);

Parameters

devclass
[in] Points to a device interface GUID. It cannot be NULL.
name
[in] A name for the interface instance. Use this name to identify this instance in whatever way the interface proscribes and so must be unique in the interface's access namespace. Therefore, "DSK2:" might be available in both the generic stream interface namespace and the block interface namespace, and probably, but not necessarily, refer to the same actual driver.
fAdd
[in] TRUE if the interface has just come online. FALSE if it has just been taken offline.

Return Values

TRUE if successful, FALSE otherwise. Failure causes include non-uniqueness of the GUID and name, permission denied, and insufficient memory to track the interface. Will also fail an attempt to remove an interface that was never added.

Remarks

Adding an interface this way allocates resources within the Device Manager; be certain to advertise its removal before the driver is unloaded.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Winbase.h
