LogDroppedPacket

This function is used by client DLLs that monitor dropped packets.

typedef VOID (*PNAT_LOG_DROPPED_PACKET)(
DWORD SourceAddr,  
DWORD DestAddr, 
USHORT SourcePort, 
USHORT DestPort, 
DWORD PacketSize,
BYTE Protocol,
DWORD Proto1, 
DWORD Proto2,
DWORD Proto3, 
DWORD Proto4
);

Parameters

SourceAddr
The source network address of the computer or networked device that initiated the packet that was dropped. The value is provided in TCP/IP network byte order format.
Security Note   This information is taken from the packet data, and may have been faked or spoofed.
DestAddr
The destination network address for the packet that was dropped. The value is provided in TCP/IP network byte order format.
SourcePort
The source port number from which the packet originated. The value is provided in TCP/IP network byte order format.
DestPort
The destination port number for which the packet was targeted. The value is provided in TCP/IP network byte order format.
PacketSize
The size of the packet that was dropped.
Protocol
Indicates the network protocol (TCP, UDP) for this connection. Protocol is indicated by one of the NAT_PROTOCOL * flags devined in IPNat.h.
Proto1
Protocol-specific data.
Proto2
Protocol-specific data.
Proto3
Protocol-specific data.
Proto4
Protocol-specific data.
Note   The values for the protocol-specific data depend on the specific protocol in use. The following table shows the corresponding values for the TCP and ICMP protocols. These values are not used for UDP.
TCP ICMP
Proto1 = SequenceNumber Proto1 = ICMP Type value (ICMPv6_ROUTER_SOLICIT, ICMPv6_ROUTER_ADVERT, etc. as defined in ICMP6.h).
Proto2 = AckNumber Proto2 = ICMP Code value (ICMPv6_ADDRESS_UNREACHABLE, ICMPv6_PORT_UNREACHABLE, etc. as defined in ICMP6.h).
Proto3 = WindowSize Proto3 Not used.
Proto4 = ProtocolHeader Proto4 Not used.

Return Values

None.

Remarks

This function is on the critical path for NAT, and therefore must return quickly to prevent degradation of performance.

Requirements
