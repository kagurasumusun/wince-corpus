REGINI

This structure is used for passing additional registry settings to ActivateDeviceEx before the driver is loaded.

typedef struct _REGINI {
LPCWSTR lpszVal;
LPBYTE pData;
DWORD dwLen;
DWORD dwType;
} REGINI;

Members

lpszVal
The name of a value to be added to the device instance key.
pData
A pointer to the data to be added as the value.
dwLen
Length of the data referenced by pData.
dwType
The registry type of the named value.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Devload.h Devload.h
