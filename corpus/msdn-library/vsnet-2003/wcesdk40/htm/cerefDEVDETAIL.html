DEVDETAIL

This structure contains information about a device and one of its interfaces.

typedef struct {
GUID guidDevClass;
DWORD dwReserved;
BOOL fAttached;
int cbName;
TCHAR szName[1]; 
} DEVDETAIL, *PDEVDETAIL;

Members

guidDevClass
The device interface identifier for this notification.
dwReserved
Do not use.
fAttached
TRUE if the device interface is present, FALSE otherwise.
cbName
Byte count of the interface's name.
szName
The interface's name.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Pnp.h Pnp.h
