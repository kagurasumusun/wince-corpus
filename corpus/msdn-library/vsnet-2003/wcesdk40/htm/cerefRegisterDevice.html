RegisterDevice

This function registers a new device. This function is superseded by ActivateDeviceEx.

HANDLE RegisterDevice( 
LPCWSTR lpszType, 
DWORD dwIndex, 
LPCWSTR lpszLib, 
DWORD dwInfo
);

Parameters

lpszType
[in] Long pointer to the null-terminated string that contains the device identifier prefix. For example COM, DEV, PGR. It must be 3 characters long.
dwIndex
[in] Specifies the device identifier index. Must be a number from 0 through 9. For example, the index value for COM2 is 2.
lpszLib
[in] Long pointer to the null-terminated string that contain that device driver DLL module name.
dwInfo
[in] Specifies instance information.

Return Values

This function is superseded by ActivateDeviceEx.

A handle to a device indicates success. Zero indicates failure. This handle is obtained from the driver's XXX_Init function and is passed to the XXX_Open, XXX_Deinit, XXX_PowerUp, and XXX_PowerDown functions.

For devices that expose the stream interface, the drivers are DLL files. Each driver is initialized by a call to the RegisterDevice function. The Device Manager calls this function on behalf of the driver. However, applications can load their own special-purpose stream interface, in which case they also call this function to register the driver. The lpszLib parameter is used to open the device. The lpszType parameter is a three-character string that is used to identify the function entry points in the DLL so that multiple devices can exist in one DLL. The lpszLib parameter is the name of the DLL that contains the entry points. dwInfo is passed in to the initialization routine.

Remarks

The DeregisterDevice function can be used if a device is removed from the system or is being shut down where the handle was returned from a call to RegisterDevice.
