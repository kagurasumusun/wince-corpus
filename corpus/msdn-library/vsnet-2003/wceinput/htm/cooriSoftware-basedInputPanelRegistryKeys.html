Input Panel Registry Settings

The HKEY_CURRENT_USER\ControlPanel\Sip\AllowChange registry value determines whether an application is allowed to change the SIP window state. Because it is only read when the SIP is initialized, you must reset the device for any changes of this registry value to take effect.

 [HKEY_LOCAL_MACHINE\Drivers\BuiltIn\SIP]
    "Prefix"="SIP"
    "Dll"="softkb.DLL"
    "Order"=dword:1
    "Index"=dword:0
IF TESTSIP
; SIP input method (IM) values
[HKEY_CURRENT_USER\ControlPanel\Sip]
    "AllowChange"=dword:1
    "DefaultIm"="{42429667-ae04-11d0-a4f8-00aa00a749b9}"
    "DragStyle"=dword:1
; Default keyboard initial delay and autorepeat
[HKEY_CURRENT_USER\ControlPanel\Keybd]
    "InitialDelay"=dword:177
    "RepeatRate"=dword:8
[HKEY_CLASSES_ROOT\CLSID\{42429667-ae04-11d0-a4f8-00aa00a749b9}]
@=LOC_KEYBOARD
    "KBMode"=dword:5
[HKEY_CLASSES_ROOT\CLSID\{42429667-ae04-11d0-a4f8-00aa00a749b9}
\InprocServer32]
    @="\\windows\\msim.dll"
[HKEY_CLASSES_ROOT\CLSID\{42429667-ae04-11d0-a4f8-00aa00a749b9}
\IsSIPInputMethod]
    @="1"
[HKEY_CLASSES_ROOT\CLSID\{42429667-ae04-11d0-a4f8-00aa00a749b9}
\DefaultIcon]
    @="\\windows\\msim.dll,0"
ENDIF TESTSIP

To control the bottom-most location of the SIP window, define the HKEY_CURRENT_USER\ControlPanel\Sip\MenuBarHeight registry key. The following code example shows how to set this registry key.

[HKEY_CURRENT_USER\ControlPanel\Sip]
    "MenuBarHeight"=dword:height in pixels

For example, if MenuBarHeight is set to 26, the SIP window will not position itself lower than 26 pixels from the bottom of the screen.
