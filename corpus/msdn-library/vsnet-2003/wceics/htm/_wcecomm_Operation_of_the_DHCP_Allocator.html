DHCP Allocator Operation

When the gateway boots, the gateway sends out a DHCP discover packet to determine if another DHCP server is present. If the gateway locates another DHCP server, ICS turns off its DHCP services until the gateway restarts or cycles its power. The gateway monitors the network to detect when a DHCP server becomes available, and turns off the DHCP services on the gateway if a server does become available. The allocator monitors UDP port 67 of the local-area interface of the gateway device to detect DHCP requests from clients on the network.

The allocator assigns addresses to clients on the network based on the IP subnet of the current address that is specified for the network connection between the gateway and the network. If the allocator is statically assigned an address, then the allocator assigns addresses on the same subnet. The allocator also uses the hardware address of the client, which is contained in the DHCP request, to compose the address that the allocator assigns to the client. Each assignment carries the address of the DHCP allocator as both the default gateway and the DNS server. ICS defends each address using Address Resolution Protocol (ARP) to ensure that no address conflicts exist.

Note   You should not use Automatic IP to obtain an address for the private network interface of the gateway computer.

The following table shows the messages received by the DHCP allocator, and the action taken in response to each message.

Message Description
DHCPDISCOVER Sent by the client to obtain an offer from the allocator. The allocator generates an address using the Auto IP hashing scheme, subject to conflict-detection, and replies to the client with a DHCPOFFER message.
DHCPREQUEST Sent by a client either to request a previously offered address, or to extend a lease on a previously assigned address. If no conflict is detected, the allocator generates a DHCPACK message.
DHCPDECLINE Sent by the client when the client detects an address conflict. The allocator takes no action other than to log an event or update its statistics.
DHCPRELEASE Sent by the client to relinquish an address. The allocator takes no action.
DHCPINFORM Sent by a client to obtain options information from the allocator without acquiring an address from the allocator. The allocator responds with a DHCPACK message that contains the default gateway, the DNS proxy address, both, or neither, depending upon the configuration of the allocator.
