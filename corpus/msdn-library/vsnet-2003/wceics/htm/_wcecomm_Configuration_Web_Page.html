ICS Configuration Web Page

You can configure the registry keys that define mappings between the names of devices on the network and IP addresses by using a configuration tool, such as an administrative Web page.

Note   The OEM is responsible for creating such a Web page. Windows CE includes a sample configuration Web page that shows OEMs an example of how to configure the settings and provide a user interface (UI) that allows the user to change these settings.

To configure the Windows CE-based gateway remotely by using a Web page

  • Use an Internet browser on a remote host to navigate to the IP address of the Windows CE-based gateway.

Follow the instructions on the configuration Web page.
