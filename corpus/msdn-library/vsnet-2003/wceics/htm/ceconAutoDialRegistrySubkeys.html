Auto Dial Registry Subkeys

The following table shows the registry subkeys that you can use to configure auto dial. These subkeys are located under the HKEY_LOCAL_MACHINE\Comm\AutoDial registry key. Auto dial reads these registry values every time that auto dial attempts to make a connection.

Subkey Description
Enabled Specifies whether auto dial is enabled.
FailRetryWaitMS Specifies the amount of time, in milliseconds, during which further calls to auto dial return an error immediately and do not result in attempts to call the RAS functions, if three attempts to establish a RAS connection have previously failed within the same length of time.
IdleTimeoutMS Specifies the amount of time, in milliseconds, after which auto dial drops the connection.
RasEntryName1 Specifies the name of the RAS phone book entry to use.
RasEntryName2 Specifies the name of the RAS phone book entry to use on the second attempt to establish a connection.
RedialAttempts Specifies the number of redial attempts that auto dial should make.
RedialPauseTimeMS Specifies the amount of time, in milliseconds, that auto dial should wait before retrying a connection.
