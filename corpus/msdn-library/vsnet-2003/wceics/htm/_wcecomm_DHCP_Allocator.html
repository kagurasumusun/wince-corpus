DHCP Allocator

ICS can configure clients on the network automatically by using DHCP. Windows CE does not support the services required to operate a full DHCP server. Windows CE does support, however, a subset of these services called the DHCP allocator. Windows CE implements the DHCP allocator as part of the ipnat component (Ipnat.dll).
