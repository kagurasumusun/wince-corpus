IWebBrowser2::PutProperty

This method sets the value of a property associated with the object.

HRESULT PutProperty( 
BSTR szProperty,
VARIANT vtValue
);

Parameters

szProperty
[in] BSTR that specifies the name of the property to set.
vtValue
[in] VARIANT of type VT_BSTR that specifies the new value of the property.

Return Values

Returns one of the following values.

Value Description
S_OK The operation was successful.
E_INVALIDARG One or more parameters are invalid.
E_OUTOFMEMORY There was not enough memory to complete the operation.
