DWebBrowserEvents2:IDispatch

This interface designates an event sink interface that an application must implement to receive event notifications from a WebBrowser control or from the Microsoft® Internet Explorer application. Note that not all of the events listed below are supported by the WebBrowser control.

Method Description
DWebBrowserEvents2::BeforeNavigate2 Fires before navigation occurs in the given object on either a window or frameset element.
DWebBrowserEvents2::CommandStateChange Fires when the enabled state of a command changes.
DWebBrowserEvents2::DocumentComplete Fires when a document has been completely loaded and initialized.
DWebBrowserEvents2::DownloadBegin Fires when a navigation operation is beginning.
DWebBrowserEvents2::DownloadComplete Fires when a navigation operation finishes, is halted, or fails.
DWebBrowserEvents2::FileDownload Fires to indicate that a file download is about to occur. If a file download dialog box is to be displayed, this event is fired prior to the display of the dialog box.
DWebBrowserEvents2::NavigateComplete2 Fires after a navigation to a link is completed on either a window or frameSet element.
DWebBrowserEvents2::NavigateError Fires when an error occurs during navigation.
DWebBrowserEvents2::NewWindow2 Fires when a new window is to be created.
DWebBrowserEvents2::OnFullScreen Fires when the IWebBrowser2::FullScreen property is changed.
DWebBrowserEvents2::OnMenuBar Fires when the IWebBrowser2::MenuBar property is changed.
DWebBrowserEvents2::OnQuit Fires before the Internet Explorer application quits.
DWebBrowserEvents2::OnStatusBar Fires when the IWebBrowser2::StatusBar property is changed.
DWebBrowserEvents2::OnTheaterMode Fires when the IWebBrowser2::TheaterMode property is changed.
DWebBrowserEvents2::OnToolBar Fires when the IWebBrowser2::ToolBar property is changed.
DWebBrowserEvents2::OnVisible Fires when the IWebBrowser2::Visible property of the object is changed.
DWebBrowserEvents2::PrivacyImpactedStateChange Fired when an event occurs that impacts privacy or when a user navigates away from a URL that has impacted privacy.
DWebBrowserEvents2::ProgressChange Fires when the progress of a download operation is updated on the object.
DWebBrowserEvents2::PropertyChange Fires when the IWebBrowser2::PutProperty method of the object changes the value of a property.
DWebBrowserEvents2::SetSecureLockIcon Fires when there is a change in encryption level.
DWebBrowserEvents2::StatusTextChange Fires when the status bar text of the object has changed.
DWebBrowserEvents2::TitleChange Fires when the title of a document in the object becomes available or changes.
DWebBrowserEvents2::WindowClosing Fires when the window of the object is about to be closed by script.
