ITravelLogStg:IUnknown

This interface provides methods which create, enumerate, and remove entries in the travel log.

Method Description
ITravelLogStg::CreateEntry Inserts a new entry in the travel log.
ITravelLogStg::EnumEntries Creates an enumerator for travel log entries.
ITravelLogStg::GetCount Specifies the number of entries in the travel log.
ITravelLogStg::GetRelativeEntry Gets an entry from the travel log.
ITravelLogStg::RemoveEntry Deletes an entry from the travel log.
ITravelLogStg::TravelTo Navigates to an entry.
