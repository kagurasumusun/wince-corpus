Browser Control Host Registry Settings

The following settings in the registry key HKEY_CURRENT_USER\AppEvents\Schemes\Apps\Explorer specify the sounds that are associated with browser events.

[Subkey\]Value : type Description
ActivatingDocument\.current : REG_SZ Default setting is\\windows\\done.wav
Navigating\.current : REG_SZ Default setting is\\windows\\start.wav
GoForward\.current : REG_SZ Default setting is\\windows\\goforward.wav
GoBack\.current : REG_SZ Default setting is\\windows\\goback.wav
Bonk\.current : REG_SZ Default setting is\\windows\\bonk.wav
