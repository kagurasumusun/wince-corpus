IWebBrowser2::Offline

This method sets or retrieves a VARIANT_BOOL value that indicates whether the object is currently operating in offline mode. 

HRESULT IWebBrowser2::get_Offline(
VARIANT_BOOL *pbOffline
);

HRESULT IWebBrowser2::put_Offline(
VARIANT_BOOL bOffline
);

Parameters

pbOffline
Pointer to a variable of type VARIANT_BOOL that receives one of the following values
bOffline
VARIANT_BOOL that specifies one of the following values.
Value Description
VARIANT_TRUE The WebBrowser control is offline.
VARIANT_FALSE Default. The WebBrowser control is not offline.

Return Values

Returns S_OK if successful, or an error value otherwise.

Remarks

In offline mode, the browser is forced to read HTML pages from the local cache rather than from the source document.
