DWebBrowserEvents2::WindowClosing

This method fires when the window of the object is about to be closed by script.

void WindowClosing( 
VARIANT_BOOL IsChildWindow,
VARIANT_BOOL *Cancel
);

Parameters

IsChildWindow
[in] VARIANT_BOOL that specifies whether the window was created from script. Can be one of the following values.
Value Description
VARIANT_FALSE Window was not created from script.
VARIANT_TRUE Window was created from script.
Cancel
[in, out] Pointer to a cancel flag. VARIANT_BOOL value that specifies whether the window is prevented from closing. Can be one of the following values.
Value Description
VARIANT_FALSE Window is allowed to close.
VARIANT_TRUE Window is prevented from closing.

Return Values

None.

Event DISPID

DISPID_WINDOWCLOSING

The DISPID for this event is defined in Exdispid.h. Use this value to identify the event handler when implementing IDispatch::Invoke.

Remarks

This event is fired when a window is closed from script, using the window.close method.

The default behavior of Internet Explorer is to close windows that were created by script without asking the user. If an attempt is made to close the main InternetExplorer or WebBrowser control window through script, the user is prompted.
