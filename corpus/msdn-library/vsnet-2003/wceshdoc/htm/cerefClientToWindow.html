IWebBrowser2::ClientToWindow

This method converts the client coordinates of a point to window coordinates.

HRESULT ClientToWindow( 
int *pcx,
int *pcy
);

Parameters

pcx
[in, out] Pointer to the x-coordinate of the point to convert, in client coordinates. When IWebBrowser2::ClientToWindow returns, this variable contains the x-coordinate of the point in window coordinates.
pcy
[in, out] Pointer to the y-coordinate of the point to convert, in client coordinates. When IWebBrowser2::ClientToWindow returns, this variable contains the y-coordinate of the point in window coordinates.

Return Values

Returns S_OK if successful, or an error value otherwise.

Remarks

Client coordinates are relative to the upper-left corner of the client area, and window coordinates are relative to the upper-left corner of a window.

The WebBrowser object ignores this method.
