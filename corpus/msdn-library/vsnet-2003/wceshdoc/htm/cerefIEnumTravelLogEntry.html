IEnumTravelLogEntry:IUnknown

This interface provides methods necessary to perform a travel log enumeration.

Method Description
IEnumTravelLogEntry::Clone Creates a copy of the current state of enumeration.
IEnumTravelLogEntry::Next Retrieves the next items in the enumeration sequence.
IEnumTravelLogEntry::Reset Resets the enumeration sequence.
IEnumTravelLogEntry::Skip Skips over the next specified number of elements.
