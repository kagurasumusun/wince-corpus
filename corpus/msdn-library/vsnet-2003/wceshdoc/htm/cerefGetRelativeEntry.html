ITravelLogStg::GetRelativeEntry

This method gets an entry from the travel log.

HRESULT GetRelativeEntry( 
int iOffset,
ItravelLogEntry **ptle
);

Parameters

iOffset
[in] Integer that specifies an offset relative to the current position.
ptle
[out] Address of a pointer to the entry at the specified offset.

Return Values

Returns S_OK if successful, or an error value otherwise.

Remarks

ITravelLogStg::GetRelativeEntry returns the entry specified by the offset. A positive offset returns entries after the current entry; a negative one returns entries before the current entry. Zero returns the current entry.
