DWebBrowserEvents2::DownloadComplete

This method fires when a navigation operation finishes, is halted, or fails.

void DownloadComplete(VOID);

Parameters

None.

Return Values

None.

Event DISPID

DISPID_DOWNLOADCOMPLETE

The DISPID for this event is defined in Exdispid.h. Use this value to identify the event handler when implementing IDispatch::Invoke.

Remarks

Unlike DWebBrowserEvents2::NavigateComplete2, which is fired only when a URL is successfully navigated to, this event is always fired after a navigation starts. Any animation or "busy" indication that the container needs to display should be connected to this event.

Each DWebBrowserEvents2::DownloadBegin event will have a corresponding DWebBrowserEvents2::DownloadComplete event.
