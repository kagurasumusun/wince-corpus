DWebBrowserEvents2::TitleChange

This method fires when the title of a document in the object becomes available or changes.

void TitleChange( 
BSTR Text
);

Parameters

Text
[in] BSTR that specifies the new document title.

Return Values

None.

Event DISPID

DISPID_TITLECHANGE

The DISPID for this event is defined in Exdispid.h. Use this value to identify the event handler when implementing IDispatch::Invoke.

Remarks

Because the title might change while an HTML page is downloading, the URL of the document is set as the title. After the title specified in the HTML page, if there is one, is parsed, the title is changed to reflect the actual title.
