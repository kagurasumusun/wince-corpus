DWebBrowserEvents2::ProgressChange

This method fires when the progress of a download operation is updated on the object. 

void ProgressChange( 
long Progress,
long ProgressMax
);

Parameters

Progress
[in] long that specifies the amount of total progress to show, or -1 when progress is complete.
ProgressMax
[in] long that specifies the maximum progress value.

Return Values

None.

Event DISPID

DISPID_PROGRESSCHANGE

The DISPID for this event is defined in Exdispid.h. Use this value to identify the event handler when implementing IDispatch::Invoke.

Remarks

The container can use the information provided by this event to display the number of bytes downloaded so far or to update a progress indicator.

To calculate the percentage of progress to show in a progress indicator, multiply the value of Progress by 100 and divide by the value of ProgressMax (unless Progress is -1, in which case the container can indicate that the operation is finished or hide the progress indicator).
