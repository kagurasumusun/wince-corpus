IWebBrowser2::Resizable

This method sets or retrieves a value that indicates whether the object can be resized.

HRESULT IWebBrowser2::get_Resizable(
VARIANT_BOOL *pValue
);

HRESULT IWebBrowser2::put_Resizable(
VARIANT_BOOL Value
);

Parameters

pValue
Pointer to a variable of type VARIANT_BOOL that receives one of the following values
Value
VARIANT_BOOL that specifies one of the following values.
Value Description
VARIANT_FALSE Object cannot be resized.
VARIANT_TRUE Default. Object can be resized.

Return Values

Returns S_OK if successful, or an error value otherwise.

Remarks

The WebBrowser object ignores this property.
