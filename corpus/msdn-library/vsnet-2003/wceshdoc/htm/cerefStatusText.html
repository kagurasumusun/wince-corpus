IWebBrowser2::StatusText

This method sets or retrieves the text in the status bar for the object.

HRESULT IWebBrowser2::get_StatusText(
BSTR *pbstr
);

HRESULT IWebBrowser2::put_StatusText(
BSTR bstr
);

Parameters

pbstr
Pointer to a variable of type BSTR that receives the status bar text.
bstr
BSTR that specifies the status bar text.

Return Values

Returns S_OK if successful, or an error value otherwise.

Remarks

The WebBrowser object ignores this property.

The caller frees the pbstr buffer with the SysFreeString function.
