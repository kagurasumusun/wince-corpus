DWebBrowserEvents2::PropertyChange

This method fires when the IWebBrowser2::PutProperty method of the object changes the value of a property.

void PropertyChange( 
BSTR szProperty
);

Parameters

szProperty
[in] BSTR that specifies the name of the property whose value has changed.

Return Values

None.

Event DISPID

DISPID_PROPERTYCHANGE

The DISPID for this event is defined in Exdispid.h. Use this value to identify the event handler when implementing IDispatch::Invoke.

Remarks

The WebBrowser object ignores this event.
