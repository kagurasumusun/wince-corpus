IWebBrowser2::Visible

This method sets or retrieves a value that indicates whether the object is visible or hidden.

HRESULT IWebBrowser2::get_Visible(
VARIANT_BOOL *pBool
);

HRESULT IWebBrowser2::put_Visible(
VARIANT_BOOL Value
);

Parameters

pBool
Pointer to a variable of type VARIANT_BOOL that receives the visible state of the object.
Value
VARIANT_BOOL that specifies the visible state of the object.
Value Description
FALSE Default. Object is hidden.
TRUE Object is visible.

Return Values

Returns S_OK to indicate that the operation was successful.

Remarks

When the Internet Explorer application is first created, it is hidden. It becomes visible after using the IWebBrowser2::Navigate or IWebBrowser2::GoSearch method.

This method only applies when automating Internet Explorer. You cocreate an instance of Internet Explorer and then call put_Visible (TRUE) to show it.
