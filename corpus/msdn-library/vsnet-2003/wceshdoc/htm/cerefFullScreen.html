IWebBrowser2::FullScreen

This method sets or retrieves a VARIANT_BOOL value that indicates whether Internet Explorer is in full-screen or normal window mode.

HRESULT IWebBrowser2::get_FullScreen(
VARIANT_BOOL *pbFullScreen
);

HRESULT IWebBrowser2::put_FullScreen(
VARIANT_BOOL bFullScreen
);

Parameters

pbFullScreen
Pointer to a variable of type VARIANT_BOOL that receives one of the following values
bFullScreen
VARIANT_BOOL that specifies one of the following values.
Value Description
VARIANT_TRUE Internet Explorer is in full-screen mode.
VARIANT_FALSE Default. Internet Explorer is in normal window mode.

Return Values

Returns S_OK if successful, or an error value otherwise.

Remarks

In full-screen mode, the Internet Explorer main window is maximized and the status bar, toolbar, menu bar, and title bar are hidden.

The WebBrowser object ignores this property.
