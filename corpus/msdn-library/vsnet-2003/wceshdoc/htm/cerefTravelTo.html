ITravelLogStg::TravelTo

This method navigates to an entry.

HRESULT TravelTo( 
ItravelLogEntry *ptle
);

Parameters

ptle
[in] Pointer to the entry in the travel log to which to navigate.

Return Values

Returns S_OK if successful, or an error value otherwise.

Remarks

ITravelLogStg::TravelTo navigates to an entry and changes the current position in the travel log to that entry. The queue is not truncated because there may be entries after the entry to which the method navigated.
