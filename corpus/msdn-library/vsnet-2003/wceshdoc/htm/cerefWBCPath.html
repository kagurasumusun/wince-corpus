IWebBrowser2::Path

This method retrieves the full path to the object.

HRESULT IWebBrowser2::get_Path(
BSTR *Path
);

Parameters

Path
Pointer to a variable of type BSTR that receives the full path. The caller frees this buffer with the SysFreeString function.

Return Values

Returns one of the following values.

Value Description
S_OK The operation was successful.
E_FAIL The operation failed.
E_OUTOFMEMORY There was not enough memory to complete the operation.

Requirements
