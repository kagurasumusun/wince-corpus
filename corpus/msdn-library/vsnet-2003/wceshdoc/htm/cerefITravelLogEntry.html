ITravelLogEntry:IUnknown

This interface provides methods to retrieve the title and URL of a travel log entry.

Method Description
ITravelLogEntry::GetTitle Retrieves the title of a page in a travel log.
ITravelLogEntry::GetURL Retrieves the URL of a travel log entry.
