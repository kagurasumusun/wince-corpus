ITravelLogStg::GetCount

This method specifies the number of entries in the travel log.

HRESULT GetCount( 
TLENUMF flags,
DWORD *pcEntries
);

Parameters

flags
[in] One or more flags from the TLENUMF enumerated type that define the entries to count.
pcEntries
[out] Pointer to a DWORD that receives the number of flag-restricted entries.

Return Values

Returns S_OK if successful, or an error value otherwise.

Remarks

The entries to be counted are determined by the flags set.
