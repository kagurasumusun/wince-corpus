TLENUMF

These values describe a travel log enumeration.

typedef enum {
    TLEF_RELATIVE_INCLUDE_CURRENT = 0x00000001,
    TLEF_RELATIVE_BACK = 0x00000010,
    TLEF_RELATIVE_FORE = 0x00000020,
    TLEF_INCLUDE_UNINVOKEABLE = 0x00000040,
    TLEF_ABSOLUTE = 0x00000031
} TLENUMF;

Constants

TLEF_RELATIVE_INCLUDE_CURRENT
The enumeration should include the current travel log entry.
TLEF_RELATIVE_BACK
The enumeration should include entries before the current entry.
TLEF_RELATIVE_FORE
The enumeration should include entries after the current entry.
TLEF_INCLUDE_UNINVOKEABLE
The enumeration should include entries that cannot be navigated to.
TLEF_ABSOLUTE
The enumeration should include all invokable entries.
