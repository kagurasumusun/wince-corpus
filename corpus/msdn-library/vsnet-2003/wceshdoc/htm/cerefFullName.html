IWebBrowser2::FullName

This method retrieves the fully qualified path of the Internet Explorer executable file.

HRESULT IWebBrowser2::get_FullName(
BSTR *pbstrFullName
);

Parameters

pbstrFullName
Pointer to a variable of type BSTR that receives the path of the Internet Explorer executable file.

Return Values

Returns one of the following values.

Value Description
S_OK The operation was successful.
E_FAIL The operation failed.
E_OUTOFMEMORY There was not enough memory to complete the operation.

Remarks

When this property is called, it allocates memory for the BSTR. The caller frees this buffer with SysFreeString.
