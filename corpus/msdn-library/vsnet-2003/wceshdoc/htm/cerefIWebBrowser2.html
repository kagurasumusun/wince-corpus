IWebBrowser2:IDispatch

This interface enables applications to implement an instance of the WebBrowser control (Microsoft ActiveX® Control) or control an instance of the Internet Explorer application (Automation). Note that not all of the methods listed below are supported by the WebBrowser object.

Method Description
IWebBrowser2::AddressBar Sets or retrieves whether the address bar of the object is visible or hidden.
IWebBrowser2::Application Retrieves the automation object for an application that is hosting the WebBrowser Control.
IWebBrowser2::Busy Retrieves a BOOL value indicating whether the object is engaged in a navigation or downloading operation.
IWebBrowser2::ClientToWindow Converts the client coordinates of a point to window coordinates.
IWebBrowser2::Container Retrieves an object reference to a container.
IWebBrowser2::Document Retrieves the automation object of the active document, if any.
IWebBrowser2::ExecWB Executes a command on an OLE object and returns the status of the command execution using the IOleCommandTarget interface.
IWebBrowser2::FullName Retrieves the fully qualified path of the Microsoft Internet Explorer executable file.
IWebBrowser2::FullScreen Sets or retrieves a VARIANT_BOOL value that indicates whether Internet Explorer is in full-screen or normal window mode.
IWebBrowser2::GetProperty Retrieves the value of a property associated with the given object.
IWebBrowser2::GoBack Navigates backward one item in the history list.
IWebBrowser2::GoForward Navigates forward one item in the history list.
IWebBrowser2::GoHome Navigates to the current home or start page.
IWebBrowser2::GoSearch Navigates to the current search page.
IWebBrowser2::Height Sets or retrieves the height of the Internet Explorer main window.
IWebBrowser2::HWND Retrieves the handle of the Internet Explorer main window.
IWebBrowser2::Left Sets or retrieves the screen coordinate of the left edge of the main window of the object.
IWebBrowser2::LocationName Retrieves the name of the resource that Internet Explorer is currently displaying.
IWebBrowser2::LocationURL Retrieves the URL of the resource that Internet Explorer is currently displaying.
IWebBrowser2::MenuBar Sets or retrieves a VARIANT_BOOL value that indicates whether the Internet Explorer menu bar is visible.
IWebBrowser2::Name Retrieves the name of the object that contains the WebBrowser Control used by Internet Explorer.
IWebBrowser2::Navigate Navigates to a resource identified by a URL or to the file identified by a full path.
IWebBrowser2::Navigate2 Navigates the browser to a location that might not be able to be expressed as a URL, such as a pointer to an item identifier list (PIDL) for an entity in the Microsoft Windows shell namespace.
IWebBrowser2::Offline Sets or retrieves a VARIANT_BOOL value that indicates whether the object is currently operating in offline mode.
IWebBrowser2::Parent Retrieves the parent of the object.
IWebBrowser2::Path Retrieves the full path to the object.
IWebBrowser2::PutProperty Sets the value of a property associated with the object.
IWebBrowser2::QueryStatusWB Queries the OLE object for the status of commands using the IOleCommandTarget::QueryStatus method.
IWebBrowser2::Quit Closes the object.
IWebBrowser2::ReadyState Retrieves the ready state of the object.
IWebBrowser2::Refresh Reloads the file that is currently displayed in the object.
IWebBrowser2::Refresh2 Reloads the file that is currently displayed in the object. Unlike IWebBrowser2::Refresh, this method contains a parameter that specifies the refresh level.
IWebBrowser2::RegisterAsDropTarget Sets or retrieves a value that indicates whether the object is registered as a drop target for navigation.
IWebBrowser2::Resizable Sets or retrieves a value that indicates whether the object can be resized.
IWebBrowser2::Silent Sets or retrieves a value that indicates whether the object can show dialog boxes.
IWebBrowser2::StatusBar Sets or retrieves a value that indicates whether the status bar for the object is visible.
IWebBrowser2::StatusText Sets or retrieves the text in the status bar for the object.
IWebBrowser2::Stop Cancels any pending navigation or download operation and stops any dynamic page elements, such as background sounds and animations.
IWebBrowser2::ToolBar Sets or retrieves a value that indicates whether the toolbar for the object is visible.
IWebBrowser2::Top Sets or retrieves the screen coordinate of the top edge of the main window of the object.
IWebBrowser2::TopLevelContainer Retrieves a value that indicates whether the object is a top-level container.
IWebBrowser2::Type Retrieves the type name of the contained document object — that is, Windows HTML Viewer.
IWebBrowser2::Visible Sets or retrieves a value that indicates whether the object is visible or hidden.
IWebBrowser2::Width Sets or retrieves the width of the main window for the object.

Remarks

The IWebBrowser2 interface derives from IDispatch indirectly. IWebBrowser2 derives from IWebBrowserApp, which in turn derives from IWebBrowser, which finally derives from IDispatch. However the members of the IWebBrowser and IWebBrowserApp interfaces are obsolete and should not be used.
