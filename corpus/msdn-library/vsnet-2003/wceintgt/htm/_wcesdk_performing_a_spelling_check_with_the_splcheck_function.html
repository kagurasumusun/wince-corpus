Performing a Spelling Check with the SplCheck Function

After you have set the SPLBUFFER structure, you should call the SplCheck function. SplCheck finds the first word in the input buffer and searches the main dictionary, internal user dictionaries, and external dictionaries for that word.

If the spelling checker finds that the word is spelled correctly, it moves to the next word. If the SplCheck function finds a misspelled word, it returns the location of the word in the buffer, the length of the word, and an error code that describes the general type of misspelling. If the spelling checker gets to the end of the input buffer without finding a spelling error, it returns SPL_OK to the SPLBUFFER structure.
