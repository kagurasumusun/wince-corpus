Microsoft Windows CE 3.0  

Integration Techniques

Microsoft Windows CE supports the integration of applications, application modules, and engines, such as a spell-checking engine, into a Windows CE-based application. Application integration implies the combination of multiple standalone applications, or parts thereof, into a new or greater "distributed" application. Application integration improves the functionality of an application by allowing multiple applications to work together to achieve a greater goal than either application could achieve alone.

The chapter Integrating Engines into an Application provides a set of guidelines on how to integrate a spell-checking engine into a Windows CE based-application. The chapter Programmer's Guide for Microsoft Pocket Outlook illustrates how to use the Pocket Outlook Object Model (POOM) to build Microsoft Visual Basic and Visual C++ applications that access the data and functionality of Pocket Outlook running on a Windows CE-based device.
