Setting the Spelling-Session Options

After you initialize a spelling session, you should call the SplOptionSet function to customize the spelling-checker operations. For example:

  • Use the SplOptionSet function to instruct the spelling checker to find repeating words, ignore Roman numerals, or ignore capitalization errors.
  • Call the SplOptionGet function to retrieve the current settings of the spelling session. You then can display the options to the user, and change the options by calling the SplOptionSet function. By default, all of the options are turned off at the beginning of the spelling session.
