Microsoft Windows CE 3.0  

Name Resolution Using the Cache

For Windows CE 2.12 and earlier, Windows CE stores the name and IP addresses resolved by Windows CE in the HKEY_LOCAL_MACHINE\Comm\Tcpip\Hosts\host name registry entry.

To enhance performance, these entries are stored in memory in Windows CE 3.0. By default, Windows CE 3.0 checks the cache, but an OEM can turn this behavior off by setting the HKEY_LOCAL_MACHINE\Comm\Afd\ResolverCheckCacheFirst registry key equal to 0. Setting this registry key equal to 0 forces Windows CE to query for the name before check the cache. In this case, Windows CE uses the cached value as a default value only if Windows CE cannot obtain any information by querying the name servers.
