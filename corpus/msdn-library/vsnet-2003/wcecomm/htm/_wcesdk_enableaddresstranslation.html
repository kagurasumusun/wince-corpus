EnableAddressTranslation

Specifies whether NAT is enabled.

Path

HKEY_LOCAL_MACHINE\Comm\ConnectionSharing

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF. A non-zero value enables NAT on the public interface specified in the PublicInterface subkey. A value of 0 specifies that NAT is not enabled.

Default Value

0, or FALSE.

Remarks

To use NAT, the HKEY_LOCAL_MACHINE\Comm\Tcpip\Parms\IpEnableRouter registry value must also be non-zero.
