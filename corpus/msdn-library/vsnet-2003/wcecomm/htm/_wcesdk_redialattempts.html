Microsoft Windows CE 3.0  

RedialAttempts

Specifies the number of redial attempts that auto dial should make.

Path

HKEY_LOCAL_MACHINE\Comm\Autodial

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF, but you should not use values larger than approximately 5.

Default Value

0
