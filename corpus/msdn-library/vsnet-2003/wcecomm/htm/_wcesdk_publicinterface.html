Microsoft Windows CE 3.0  

PublicInterface

Specifies the name of the NDIS adapter instance for the public network interface; for example, NE20001. For dial up connections, use the name of the RAS connection.

Path

HKEY_LOCAL_MACHINE\Comm\ConnectionSharing

Value Type

REG_SZ

Valid Range

The name of either a valid NDIS adapter or a valid dial-up networking connectoid.

Default Value

None
