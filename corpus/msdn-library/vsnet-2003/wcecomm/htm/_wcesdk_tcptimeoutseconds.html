Microsoft Windows CE 3.0  

TcpTimeoutSeconds

Specifies the amount of time, in seconds, before TCP mappings expire in the NAT.

Path

HKEY_LOCAL_MACHINE\Comm\IPNat

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF

Default Value

0x15180, or 86400 seconds (24 hours)

Remarks

The internal timer in the NAT runs once per minute to clean up expired mappings.
