IrSIR

IrSIR is an NDIS miniport driver that binds to the IRDA stack and is only exposed via Winsock. The IrCOMM driver (which talks to IrSIR via Winsock) creates the second COM port.

The IrSIR driver, included in the ETK, creates an additional COM port.

Serial Port Hardware
-----------------

The device index that it registers is controlled by the "Index" registry setting in project.reg. For example, the following setting creates a virtual "COM3:" serial port.

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\IrCOMM]
    "Index"=dword:3

The real COM port that will be opened by the Serial IR driver is controlled by the "Port" registry setting in platform.reg:

[HKEY_LOCAL_MACHINE\Comm\Irsir1\Parms]
    "BusNumber"=dword:0
    "BusType"=dword:0
    "Port"=dword:1
    ; 0 = Use external dongle, 1 = Use internal IR
    "IntIR"=dword:0
    ; 0 = Internal transceiver, 1 = Extended Systems JetEye dongle
    "TransceiverType"=dword:1
