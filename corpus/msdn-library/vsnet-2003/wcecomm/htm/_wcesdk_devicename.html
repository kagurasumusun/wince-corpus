Microsoft Windows CE 3.0  

DeviceName

Specifies the name of the device that is associated with the IP address that corresponds to the Address subkey that contains this DeviceName subkey.

Path

HKEY_LOCAL_MACHINE\Comm\ConnectionSharing\Addresses\Address

Value Type

REG_SZ

Valid Range

Any valid machine name less than 16 characters long.

Default Value

None

Remarks

The DHCP allocator sets this and all values for any given Address automatically when the allocator receives a new DHCP request. A user, however, can also set these values to create an address and machine name mapping.
