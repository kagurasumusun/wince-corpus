Support for IP Multicasting

Windows Sockets 1.1 provides support for IP multicasting. Multicasting is described in the Windows Sockets 1.1 specification and in the IGMP section of this document. IP multicasting is currently supported only on AF_INET sockets of types SOCK_DGRAM.

For more information on IP multicasting, see IP Multicasting.
