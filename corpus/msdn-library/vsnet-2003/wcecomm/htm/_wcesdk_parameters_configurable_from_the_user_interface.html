Parameters Configurable from the User Interface

The following parameters are created and modified automatically by the Networking control panel application as a result of user-supplied information:

  • DefaultGateway
  • EnableDhcp
  • IPAddress
  • SubnetMask

There should be no need to configure these parameters directly in the registry. These entries are located under the HKEY_LOCAL_MACHINE\Comm\Adapter Name\Parms\Tcpip registry key. For more information about these parameters, see the entries for these parameters in Parameters Configurable Using the Registry Editor.
