Microsoft Windows CE 3.0  

EnableDhcpAllocator

Specifies whether the DHCP allocator is enabled.

Path

HKEY_LOCAL_MACHINE\Comm\ConnectionSharing

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF. A non-zero value enables the DHCP allocator on the private interface specified in the PrivateInterface subkey. A value of 0 specifies that the DHCP allocator is not enabled.

Default Value

0, or FALSE.
