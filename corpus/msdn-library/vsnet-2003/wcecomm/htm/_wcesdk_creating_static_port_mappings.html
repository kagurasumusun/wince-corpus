Creating Static Port Mappings

ICS also allows you to run services on devices in the home network, and to provide access to those services from the public network through the gateway. This capability requires that users are allowed to specify the service and the local-area network machine providing the service, and it also requires that incoming session requests be directed by the gateway to the specified device. Such mappings are referred to as server mappings, and are established through the registry. Server mappings are contained under the HKEY_LOCAL_MACHINE\Comm\ConnectionSharing\Servers registry key, in Service subkeys correspoding to each service. Each Service subkey contains additional subkeys that specify information about the server mapping.

The following table shows the subkeys contained under the Service subkey.

Subkey Description
InternalName Specifies the name of the server on the home network to which the request should be sent; for example, "HTTP".
InternalPort Specifies the port number of the device listed in the InternalName subkey to which the request should be sent; for example, 80.
IsEnabled Specifies whether the service is enabled. Set to 1 to indicate that the service is enable, or set to 0 to indicate that the service is not enabled.
Port Specifies the port reserved on the gateway device; for example, 80. Usually contains the same value as InternalPort.
Protocol Specifies the protocol; for example, TCP.
