Microsoft Windows CE 3.0  

IdleTimeoutMS

Specifies the amount of time, in milliseconds, after which auto dial drops the connection.

Path

HKEY_LOCAL_MACHINE\Comm\Autodial

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF

Default Value

0x1B7740, or 1800000 milliseconds (30 minutes)
