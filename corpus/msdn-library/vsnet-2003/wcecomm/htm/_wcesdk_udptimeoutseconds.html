Microsoft Windows CE 3.0  

UdpTimeoutSeconds

Specifies the amount of time, in seconds, before UDP mappings expire in the NAT.

Path

HKEY_LOCAL_MACHINE\Comm\IPNat

Value Type

REG_DWORD

Valid Range

0 to 0xFFFFFFFF

Default Value

0x3C, or 60 seconds
