Microsoft Windows CE 3.0  

Configuration Web Page

You can configure the registry keys that define mappings between the names of devices on the home network and IP addresses by using a configuration tool, such as an administrative web page.

Note   The OEM is responsible for creating such a web page. Windows CE includes a sample configuration web page that shows OEMs an example of how to configure the settings and provide a user interface (UI) that allows the user to change these settings.

To configure the Windows CE-based gateway remotely by using a web page

  1. Use an Internet browser on a remote host to navigate to the IP address of the Windows CE-based gateway.
  2. Follow the instructions on the configuration web page.
