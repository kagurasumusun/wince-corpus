Microsoft Windows CE 3.0  

TCP/IP Troubleshooting Utilities

Many network troubleshooting tools are available for Windows CE. Microsoft Network Monitor is an excellent network tracing tool. The full version is part of Microsoft Systems Management Server, and a more limited version is included in Microsoft® Windows® 2000.

Windows CE includes the following three utilities to troubleshoot network problems:

  • Ping
  • Route
  • IPConfig
