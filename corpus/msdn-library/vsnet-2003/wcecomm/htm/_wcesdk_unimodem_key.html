Microsoft Windows CE 3.0  

Unimodem Key

The following table shows the registry settings for the HKEY_LOCAL_MACHINE\Drivers\PCMCIA\CompanyX-GenericModem-1234\Unimodem key.

Registry key Description Type Default value
DevConfig Binary structure that indicates the serial device capabilities (baud, parity, and so on). HEX 10,00, 00,00 78,00,00,00
10,01,00,00, 00,4B,00,00
00,00, 08, 00, 00,00,00,00
DeviceType Device type; the values are specified in the Unimodem.h header file in the OAK directory. DWORD 3
FriendlyName Name that is displayed to user by TAPI applications.    
Tsp Provides the TSP name that services this port; this key is set always to "Unimodem.dll" for V1 and V1.01 devices.
