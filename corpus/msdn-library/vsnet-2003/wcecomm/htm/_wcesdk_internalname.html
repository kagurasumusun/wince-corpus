Microsoft Windows CE 3.0  

InternalName

Specifies the name of the server on the home network to which the request should be sent.

Path

HKEY_LOCAL_MACHINE\Comm\ConnectionSharing\Servers\Service

Value Type

REG_SZ

Valid Range

Any IP address.

Default Value

None
