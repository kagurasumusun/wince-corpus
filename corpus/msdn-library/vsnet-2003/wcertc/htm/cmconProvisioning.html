Provisioning

The client application creates the XML profile containing the client's provisioning information. Provisioning information includes user account information, such as name, password, and URI, as well as SIP settings, such as address and transport protocol. In the profile, a client specifies an Internet Telephony Service Provider (ITSP), or third-party corporate-deployed server. The profile can also locate the SIP proxy server for calls that use SIP signaling or the SIP registrar server to route incoming calls. A SIP session routed through a PSTN gateway can also specify the gateway server on the profile.

Separate profiles can be used to provision the client with different types of services using a variety of providers, proxy servers, or gateways.

For more example profiles, see XML Profile Samples.
