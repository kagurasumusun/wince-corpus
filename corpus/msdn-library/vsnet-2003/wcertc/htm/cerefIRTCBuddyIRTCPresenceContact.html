IRTCBuddy:IRTCPresenceContact

This interface is used to retrieve contact information.

The following table shows the methods of this interface.

Method Description
IRTCBuddy::get_Data Retrieves the contact's private data.
IRTCBuddy::get_Name Retrieves the contact's displayable name.
IRTCBuddy::get_Notes Retrieves the contact's custom presence string.
IRTCBuddy::get_Persistent Retrieves the persistence type.
IRTCBuddy::get_PresentityURI Retrieves the contact's presence URI.
IRTCBuddy::get_Status Returns the contact's presence status.
IRTCBuddy::put_Data Defines the contact's private data.
IRTCBuddy::put_Name Defines the contact's displayable name.
IRTCBuddy::put_Persistent Defines the persistence type.
IRTCBuddy::put_PresentityURI Defines the contact's presence URI.
