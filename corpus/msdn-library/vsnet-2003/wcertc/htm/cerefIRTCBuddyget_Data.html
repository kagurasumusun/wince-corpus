IRTCBuddy::get_Data

This method retrieves a contact's private data.

HRESULT get_Data(
BSTR *pbstrData
);

Parameters

pbstrData
[out, retval] Pointer to the private data. The caller is responsible for freeing this memory with the SysFreeString function.

Return Values

RTC methods may return an RTC_E_ constant.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Rtccore.idl Rtccore.h Rtccore.dll
