RTCMT_ Constants

The media type constants describe the media streams available. The IRTCClient::get_PreferredMediaTypes, IRTCClient::SetPreferredMediaTypes, and IRTCClient::get_MediaCapabilities methods use the following media type flags:

RTCMT_ALL
Value: 0x0000001F

All media types are used.

RTCMT_ALL_RTP
Value: 0x0000000F

The media type is RTP.

RTCMT_AUDIO_RECEIVE
Value: 0x00000002

The media type is audio receive.

RTCMT_AUDIO_SEND
Value: 0x00000001

The media type is audio send.

RTCMT_T120_SENDRECV
Value: 0x00000010

The media type is T120 send or receive.

RTCMT_VIDEO_RECEIVE
Value: 0x00000008

The media type is video receive.

RTCMT_VIDEO_SEND
Value: 0x00000004

The media type is video send.
