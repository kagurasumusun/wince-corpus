IRTCSession::get_Profile

This method returns the profile currently used by the session. It is reliable only when the session is in the RTCSS_CONNECTED state.

HRESULT get_Profile(
IRTCProfile **ppProfile
);

Parameters

ppProfile
[out, retval] Pointer to the newly created IRTCProfile interface. This call adds a reference to the interface, which the caller is responsible for releasing.

Return Values

RTC methods may return an RTC_E_ constant.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Rtccore.idl Rtccore.h Rtccore.dll
