IRTCSession::EnumerateParticipants

This method returns an enumeration of the participants in this session, excluding the local user. If there are no participants in the session, an empty enumeration is returned.

HRESULT EnumerateParticipants(
IRTCEnumParticipants **ppEnum
);

Parameters

ppEnum
[out, retval] Pointer to the IRTCEnumParticipants interface on an enumeration object containing an IRTCParticipant pointer for each participant in the session. This call adds a reference to the enumeration object, which the caller is responsible for releasing.

Return Values

RTC methods may return an RTC_E_ constant.
