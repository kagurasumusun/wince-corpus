IRTCClientEvent:IDispatch

This interface is used to retrieve information about changes in the presence state of a contact. IRTCClientEvent is referenced by the IRTCEventNotification::Event method when an RTC_EVENT of type RTCE_CLIENT is returned.

Note   To receive contact events, the RTCEF_CLIENT event filter mask for the EventFilter method must be set.

The following table describes the methods of this interface.

Method Description
IRTCClientEvent::get_Client Returns a pointer to the IRTCClient interface.
IRTCClientEvent::get_EventType Returns the event type.
