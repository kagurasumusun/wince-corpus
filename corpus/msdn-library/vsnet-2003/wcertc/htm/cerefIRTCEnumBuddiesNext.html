IRTCEnumBuddies::Next

This method retrieves the next specified number of elements in the enumeration sequence.

HRESULT Next( 
ULONG celt, 
IRTCBuddy **ppElements,
ULONG *pceltFetched 
);

Parameters

celt
[in] Number of elements requested.
ppElements
[out] Pointer to the IRTCBuddy list of pointers returned.
pceltFetched
[in, out, ptr] Pointer to the number of elements actually supplied. May be NULL if celt is one.

Return Values

RTC methods may return an RTC_E_ constant.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Rtccore.idl Rtccore.h Rtccore.dll
