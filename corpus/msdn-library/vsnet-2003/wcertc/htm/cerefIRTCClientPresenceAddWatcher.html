IRTCClientPresence::AddWatcher

This method adds a Watcher to the allowed/blocked Watchers list.

HRESULT AddWatcher(
BSTR bstrPresentityURI,
BSTR bstrUserName,
BSTR bstrData,
VARIANT_BOOL bBlocked,
VARIANT_BOOL bPersistent,
IRTCWatcher **ppWatcher
);

Parameters

bstrPresentityURI
[in] The presentity URI of the new Watcher, with or without the sip:' namespace prefix.
bstrUserName
[in] The displayable name of the new Watcher.
bstrData
[in] An optional private data blob.
bBlocked
[in] The initial state of the Watcher (blocked or allowed). If VARIANT_TRUE, the Watcher is blocked; otherwise, it is allowed.
bPersistent
[in] If VARIANT_TRUE, the Watcher is saved in the persistent storage. If VARIANT_FALSE, the Watcher is volatile and is lost when the RTC Client is shut down.
ppWatcher
[out, retval] Pointer to the IRTCWatcher interface on the newly created Watcher object. This parameter may be NULL, indicating that the method should not return an interface. This call adds a reference to the Watcher object, which the caller is responsible for releasing.

Return Values

RTC methods may return an RTC_E_ constant.
