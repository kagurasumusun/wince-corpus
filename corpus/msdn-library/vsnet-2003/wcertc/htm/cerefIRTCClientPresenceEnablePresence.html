IRTCClientPresence::EnablePresence

This method enables the presence functionality for both outgoing and incoming subscriptions. Presence is not enabled until this method is called. This method can be called only once. 

HRESULT EnablePresence(
VARIANT_BOOL fUseStorage,
VARIANT varStorage
);

Parameters

fUseStorage
[in] Specifies whether the lists will load from storage and automatically commit any changes back to storage. A value of false will enable presence, but not use storage. Presence will be enabled with empty Contact and Watcher lists.
varStorage
[in] Specifies the persistent storage for the Contact list and the allowed and blocked Watcher lists. The variant can contain one of the following:
  • VT_BSTR File name that the Communications Service (Communications Service (RTC API) ) will use for storage.
  • VT_UNKNOWN
  • VT_DISPATCH IStream pointer to the IStorage interface that the Communications Service (RTC API) will use for storage.

Return Values

RTC methods may return an RTC_E_ constant.

Remarks

The Buddies and Watchers have a persistence property that is set when they are added to the presence list. This method determines whether they will be part of the persistent storage (varStorage).

Note   The storage used in this method is subject to change and further revisions.
