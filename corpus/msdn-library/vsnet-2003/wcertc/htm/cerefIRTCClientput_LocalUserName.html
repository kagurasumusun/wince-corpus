IRTCClient::put_LocalUserName

This method defines the displayable name used in the From: header of messages sent from a client. By default, the logon user is assumed.

HRESULT put_LocalUserName(
BSTR bstrUserName
);

Parameters

bstrUserName
[in] Local user name to be set.

Return Values

RTC methods may return an RTC_E_ constant.
