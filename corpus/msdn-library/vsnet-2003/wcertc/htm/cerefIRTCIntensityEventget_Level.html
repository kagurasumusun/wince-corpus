IRTCIntensityEvent::get_Level

This method returns the level of intensity.

HRESULT get_Level(
long *plLevel
);

Parameters

plLevel
[out, retval] Pointer to a long containing the intensity level. See IRTCIntensityEvent::get_Min and IRTCIntensityEvent::get_Max for the minimum and maximum intensity values.

RTC methods may return an RTC_E_ constant.
