IRTCSession:IUnknown

This interface contains all methods and properties related to sessions. The IRTCClient::CreateSession method creates the Session object.

The following table describes the methods of this interface.

Method Description
IRTCSession::AddParticipant Creates a participant and adds it to the session. Adding a participant to an idle session initiates the call.
IRTCSession::AddStream Adds one new media stream to the session.
IRTCSession::Answer Answers an incoming session.
IRTCSession::EnumerateParticipants Returns an enumeration of the participants in this session, excluding the local user.
IRTCSession::get_CanAddParticipants Retrieves an indication of whether it is possible to add participants to this session.
IRTCSession::get_Client Returns an IRTCClient interface for the parent RTC Client object.
IRTCSession::get_Participants Returns a collection of participants in this session, excluding the local user.
IRTCSession::get_Profile Returns the profile currently used by the session.
IRTCSession::get_RedirectedUserName Retrieves the displayable name of the current user in the redirection list.
IRTCSession::get_RedirectedUserURI Retrieves the URI of the current user in the redirection list.
IRTCSession::get_State Returns the current state of the session.
IRTCSession::get_Type Returns the type of session.
IRTCSession::NextRedirectedUser Advances the index in the array of addresses kept by the redirection context.
IRTCSession::put_EncryptionKey Defines the encryption key to be used for one or more media streams.
IRTCSession::Redirect Enables the user to change the type of session and profile for the redirected call. This method is called when an outgoing call is redirected.
IRTCSession::RemoveParticipant Removes a participant from the session.
IRTCSession::RemoveStream Removes one media stream from the session.
IRTCSession::SendMessage Sends an instant message.
IRTCSession::SendMessageStatus Sends the user's typing status for a messaging window.
IRTCSession::Terminate Terminates a session.
