IRTCWatcher::get_Persistent

This method retrieves the persistence type.

HRESULT get_Persistent(
VARIANT_BOOL *pfPersistent
);

Parameters

pfPersistent
[out, retval] Pointer to a VARIANT_BOOL containing the persistence type.

Return Values

RTC methods may return an RTC_E_ constant.

Remarks

Buddies and Watchers are saved to persistent storage when presence is enabled with storage (see IRTCClientPresence::EnablePresence). The IRTCClientPresence::Export and IRTCClientPresence::Import methods will also save the contacts to a file that is not part of the persistent storage, RTC_E_ Constants.
