IRTCProfile::get_ClientBanner

This method returns a flag that specifies if the Client should display the banner for the profile. 

HRESULT get_ClientBanner(
VARIANT_BOOL *pfBanner
);

Parameters

pfBanner
[out, retval] Pointer to a VARIANT_BOOL containing the banner flag.

Return Values

RTC methods may return an RTC_E_ constant.

Remarks

This is an optional field in the profile. If the field is not present in the profile, the method will return E_FAIL.
