IRTCClientPresence:IUnknown

This interface contains all methods and properties related to presence. It is obtained by performing QueryInterface on the Client object.

The following table describes the methods of this interface.

Method Description
IRTCClientPresence::AddBuddy Adds a contact to the contact list.
IRTCClientPresence::AddWatcher Adds a watcher to the allowed/blocked watchers list.
IRTCClientPresence::EnablePresence Enables the presence functionality for outgoing and incoming subscriptions.
IRTCClientPresence::EnumerateBuddies Returns an enumeration of available contacts on this client. If there are not any, an empty enumeration is returned.
IRTCClientPresence::EnumerateWatchers Returns an enumeration of the allowed and blocked watchers available on this client. If there are not any, an empty enumeration is returned.
IRTCClientPresence::Export Exports a snapshot of the current lists of contacts and blocked or allowed watchers.
IRTCClientPresence::get_Buddies Retrieves a collection of the available contacts on this client. If there are not any, an empty collection is returned.
IRTCClientPresence::get_Buddy Retrieves an IRTCBuddy interface for a contact whose presentity URI matches the URI given as a parameter. The contact must be present in the contact list in order for the function to succeed.
IRTCClientPresence::get_OfferWatcherMode Retrieves the way the application handles subscriptions requested by new Watchers that are not currently in the list of allowed or blocked Watchers.
IRTCClientPresence::get_PrivacyMode Retrieves the privacy mode.
IRTCClientPresence::get_Watcher Retrieves an IRTCWatcher interface for a Watcher whose presentity URI matches the URI given as a parameter. The Watcher must be present in the allowed/blocked Watchers list for the function to succeed.
IRTCClientPresence::get_Watchers Retrieves a collection of the Watchers available on this Client. If there are no Watchers on this Client, an empty collection is returned.
IRTCClientPresence::Import Imports presence information such as a Contact list and allowed/blocked Watchers list.
IRTCClientPresence::put_OfferWatcherMode Determines how the application handles subscription requests from new Watchers that are not in the list of allowed or blocked Watchers.
IRTCClientPresence::put_PrivacyMode Defines the privacy mode.
IRTCClientPresence::RemoveBuddy Removes a Contact from the Contact list.
IRTCClientPresence::RemoveWatcher Removes a Watcher from the Watcher list.
IRTCClientPresence::SetLocalPresenceInfo Defines the local presence status. All the active Watchers are instantly notified of the change.
