IRTCClient:IUnknown

This interface is the main interface to the RTC Client object. It is obtained with the CoCreateInstance function, using the CLSID_RTCClient GUID of 7a42ea29-a2b7-40c4-b091-f6f024aa89be.

Note   The Client object can only be used as an inproc server.

For information on how to create and initialize the Client object, see the Initialize the Communications Service code example.

The following table describes the methods of this interface.

Method Description
IRTCClient::CreateSession Creates a session.
IRTCClient::get_ActiveMedia Retrieves the media types for currently active streams in the session.
IRTCClient::get_AudioMuted Retrieves the mute on an audio device.
IRTCClient::get_EventFilter Returns the current event filter.
IRTCClient::get_IsTuned Returns the tuning status.
IRTCClient::get_ListenForIncomingSessions Learns how a client listens for incoming sessions.
IRTCClient::get_LocalUserName Retrieves the displayable name used in the From: header of messages sent from a client.
IRTCClient::get_LocalUserURI Retrieves the SIP URI used in the From: header of messages sent from a client.
IRTCClient::get_MediaCapabilities Retrieves the media types supported by the current hardware.
IRTCClient::get_NetworkAddresses Retrieves the IP addresses and ports a client listens on.
IRTCClient::get_NetworkQuality Retrieves the quality value of the network connection.
IRTCClient::get_PreferredAEC Retrieves the preferred AEC mode.
IRTCClient::get_PreferredAudioDevice Retrieves the preferred audio device for audio capturing or rendering.
IRTCClient::get_PreferredMediaTypes Retrieves the preferred media types for new sessions.
IRTCClient::get_PreferredVolume Retrieves the volume on an audio device.
IRTCClient::get_Volume Retrieves the volume on an audio device.
IRTCClient::Initialize Initializes the Client object. This must be called before any other methods are called on this interface.
IRTCClient::InvokeTuningWizard Invokes the tuning wizard.
IRTCClient::PlayRing Plays a ring on the OS default audio device or on the RTC default audio device.
IRTCClient::PrepareForShutdown Asynchronously prepares the Client object for shutting down.
IRTCClient::put_AudioMuted Defines the mute on an audio device.
IRTCClient::put_EventFilter Defines the event filter used to deliver events. This affects all attached event sinks.
IRTCClient::put_ListenForIncomingSessions Defines how a client behaves for incoming sessions.
IRTCClient::put_LocalUserName Defines the displayable name used in the From: header of messages sent from a client. By default, the logon user is assumed.
IRTCClient::put_LocalUserURI Defines the SIP URI used in the From: header of messages sent from a client.
IRTCClient::put_PreferredAEC Enables or disables the preferred acoustic echo cancellation (AEC) mode.
IRTCClient::put_PreferredAudioDevice Defines the preferred audio device for audio capturing or rendering.
IRTCClient::put_PreferredVolume Defines the preferred volume on an audio device.
IRTCClient::put_Volume Defines the volume on an audio device.
IRTCClient::SendDTMF Sends a DTMF to the active session and plays a feedback tone to the RTC default audio device.
IRTCClient::SetPreferredMediaTypes Defines the preferred media types for new sessions.
IRTCClient::Shutdown Cleans up the Client object. This must be called before the Client object is released.
