SIP Server Settings

This attribute specifies available servers. Multiple server and setting sets can be specified.

Address
Server's host name.
Protocol
Transport to use to connect to the server. Possible values are TCP, UDP, and TLS.
Auth
Security authentication. Possible values are Basic and Digest. If authentication is Basic, the transport must be TLS for security reasons.
Role
Server's role. The possible values are Proxy and Registrar.
Realm
Protection space used in the Authorization header when making a SIP request and used by the ITSPs to outsource their services to another carrier.
Session
Session types the server can support. The available options are computer-to-computer, computer-to-phone, phone-to-phone, and Instant Messenger. For each form of communication, the party must also be specified.
