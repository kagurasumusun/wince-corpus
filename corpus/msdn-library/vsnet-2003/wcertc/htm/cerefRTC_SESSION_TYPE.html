RTC_SESSION_TYPE

This enumeration describes the sessions. The IRTCSession::get_Type method returns a member of this enumeration.

typedef enum RTC_SESSION_TYPE{
RTCST_PC_TO_PC,
RTCST_PC_TO_PHONE,
RTCST_PHONE_TO_PHONE,
RTCST_IM
} RTC_SESSION_TYPE;

Elements

RTCST_PC_TO_PC
PC-PC call.
RTCST_PC_TO_PHONE
PC-phone call.
RTCST_PHONE_TO_PHONE
Phone-phone call. This type of call does not use any streaming resources.
RTCST_IM
Instant messaging session. This type of session does not use any streaming resources.
