IRTCClientPresence::get_Buddy

This method retrieves an IRTCBuddy interface for a Contact whose presentity URI matches the URI given as a parameter. For the function to succeed, the Contact must be present in the Contact list.

HRESULT get_Buddy(
BSTR bstrPresentityURI,
IRTCBuddy **ppBuddy
);

Parameters

bstrPresentityURI
[in] The presentity URI of the Contact, with or without the sip:' namespace prefix.
ppBuddy
[out, retval] Pointer to the IRTCBuddy interface. This call also adds a reference to the interface, which the caller is responsible for releasing.

Return Values

RTC methods may return an RTC_E_ constant.
