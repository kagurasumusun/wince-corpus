IRTCClientPresence::SetLocalPresenceInfo

This method defines the local presence status. All the active Watchers are instantly notified of the change.

HRESULT SetLocalPresenceInfo(
RTC_PRESENCE_STATUS enStatus,
BSTR bstrNotes
);

Parameters

enStatus
[in] An RTC_PRESENCE_STATUS enumeration that specifies the presence status.
bstrNotes
[in] Custom user-provided text that may have a meaning for the active Watchers.

Return Values

RTC methods may return an RTC_E_ constant.
