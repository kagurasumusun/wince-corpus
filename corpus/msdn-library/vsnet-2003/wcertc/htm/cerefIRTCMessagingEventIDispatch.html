IRTCMessagingEvent:IDispatch

This interface is for RTCE_MESSAGING events. This type of event is fired when an incoming instant message arrives, or when an update of the remote user's keystroke status is received.

When the application's implementation of the IRTCEventNotification::Event method indicates an RTC_EVENT of type RTCE_MESSAGING, the method's pEvent parameter is an IDispatch pointer for the IRTCMessagingEvent interface. The methods of this interface can be used to retrieve information concerning the change in the presence state of the Contact.

Note   You must call the IRTCClient::put_EventFilter method and set an event filter mask that includes the RTCEF_MESSAGING event to enable reception of Contact events. If you do not call IRTCClient::put_EventFilter, your application will not receive any events.

The following table describes the methods of this interface.

Method Description
IRTCMessagingEvent::get_Message Returns the instant message sent by the remote user.
IRTCMessagingEvent::get_MessageHeader Returns the header with the content type as sent by the remote user.
IRTCMessagingEvent::get_Participant Returns the Participant object associated with the messaging event.
IRTCMessagingEvent::get_Session Returns the Session object associated with the messaging event.
IRTCMessagingEvent::get_Type Returns the type of the event: message or user status.
IRTCMessagingEvent::get_UserStatus Returns the user's keystroke status.
