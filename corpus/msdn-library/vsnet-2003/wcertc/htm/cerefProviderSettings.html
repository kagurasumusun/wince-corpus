Provider Settings

The provider settings are as follows:

Name
Name of the Internet telephony service provider.
Home Page
Provider's home page Uniform Resource Identifier (URI) displayed by the client.
Help Desk
Provider help desk URI displayed by the client.
Personal
Account detail URI displayed by the provider.
Call Display
Marketing information URI displayed by the client application during a call.
Idle Display
Marketing information URI displayed by the client when calls are idle.
Data
ITSP-specific information. This XML blob, used by the client application, provides the provisioning version and other account information.
