IRTCEnumWatchers:IUnknown

This interface provides COM-standard enumeration methods for the IRTCWatcher interface. The IRTCClientPresence::EnumerateWatchers method returns a pointer to IRTCEnumWatchers.

The following table describes the methods of this interface.

Method Description
IRTCEnumWatchers::Clone Creates another enumerator that contains the same enumeration state as the current one.
IRTCEnumWatchers::Next Retrieves the next specified number of elements in the enumeration sequence.
IRTCEnumWatchers::Reset Redefines to the beginning of the enumeration sequence.
IRTCEnumWatchers::Skip Skips over the next specified number of elements in the enumeration sequence.
