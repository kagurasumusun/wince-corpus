RTC_WATCHER_STATE

This enumeration describes the state of the Watcher. The IRTCWatcher::get_State and IRTCWatcher::put_State methods use a member of this enumeration.

typedef enum RTC_WATCHER_STATE{
RTCWS_UNKNOWN,
RTCWS_OFFERING,
RTCWS_ALLOWED,
RTCWS_BLOCKED
} RTC_WATCHER_STATE;

Elements

RTCWS_UNKNOWN
This state should not happen.
RTCWS_OFFERING
The notification of the new Watcher has not completed. The Watcher is in the OFFERING state.
RTCWS_ALLOWED
The Watcher is in the list of allowed Watchers.
RTCWS_BLOCKED
The Watcher is in the list of blocked Watchers.
