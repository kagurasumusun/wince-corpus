Installing an ACM Driver

Installing an ACM driver consists of storing information about the codec in the registry. The information stored includes the name of the file that implements the ACM driver, the non-PCM wave format, and parameters required by the Communications Service.

The following code example shows the registry path and keys for a typical ACM driver registry entry.

HKEY_CURRENT_USER\Software\Microsoft\RTC\ACM
    G711
        Driver = rtcg711.acm
        PayloadType = REG_DWORD 0x0000007f
        CodecRank = REG_DWORD 0x0000003c
        FrameDuration = REG_DWORD 0x0000001e
        WaveFormat
            FormatTag = REG_DWORD 0x00000042
            Channels = REG_DWORD 0x00000001
            SamplesPerSec = REG_DWORD 0x00001f40
            AvgBytesPerSec = REG_DWORD 0x00000320
            BlockAlign = REG_DWORD 0x00000004
            BitsPerSample = REG_DWORD 0x00000000
            ExtraSize = REG_DWORD 0x00000002

The following list explains the purpose for each registry key in the previous example:

G711
The name of this key should be the codec name. This is the name used when selecting QOS settings.
Driver
File name of the ACM driver that implements the codec.
PayloadType
Static payload type. Set this value to 255 if you want the Communications Service to assign the value. If you set this Note that if a dynamic payload type is set there, it will be treated as if it were a static payload type.
CodecRank
An integer value between 0 and 100. The Communications Service uses this value to select preferred codecs with 0 being the highest priority and 100 the lowest.
FrameDuration
Time in milliseconds that corresponds to the wSamplesPerBlock parameter.
FormatTag
Waveform-audio format type.
Channels
Number of channels in the waveform-audio data. Monaural data uses one channel and stereo data uses two channels.
SamplesPerSec
Sample rate, in samples per second (hertz), at which each channel should be played or recorded.
AveBytesPerSec
Required average data-transfer rate, in bytes per second, for the format.
BlockAlign
Block alignment, in bytes. The block alignment is the minimum atomic unit of data for the FormatTag format type.
BitsPerSample
Bits per sample. If FormatTag is WAVE_FORMAT_PCM, BitsPerSample should be 8 or 16.
ExtraSize
This value corresponds to the cbSize member in the WAVEFORMATEX structure.

After the ACM-driver information is stored, identify this codec as the one you intend to use. The following code example shows the registry path and keys for defining the preferred codec.

HKEY_CURRENT_USER\Software\Microsoft\RTC\Codec
    PreferredAudioCodec = REG_DWORD 0x0000007f 
    UsePreferredCodec = REG_DWORD 0x00000001

The following list explains the purpose for each registry:

PreferredAudioCodec
Matches the PayLoadType of the codec to use.
UsePreferredCodec
If 1, use preferred codec. If 0, do not use preferred codec.
