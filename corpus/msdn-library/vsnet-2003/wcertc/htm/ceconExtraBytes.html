Extra Bytes

The cbSize member in a WAVEFORMATEX structure must contain the number of extra bytes allocated for the WAVEFORMATEX structure. Given that the only mandatory extra field passed to the ACM codec is the wSamplesPerBlock member, this value must always be 2. The ACM driver must refrain from using memory past those 2 extra bytes; the Communications Service uses that memory space for internal housekeeping.
