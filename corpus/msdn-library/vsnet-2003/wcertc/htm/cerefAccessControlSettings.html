Access Control Settings

The following parameters configure the client access information that is not related to the communications link. These settings can be configured for a specific application or for multiple applications as specified in the 'name' attribute.

The access control settings are as follows:

Domain
Server domain.
Sig
Signature, provided by Microsoft that provisions the client to use the application programming interfaces (APIs).
Client settings
Configures client information not related to the communications link. These settings can be configured for a specific application or for multiple applications specified in the Name attribute.
Name
Name of the client application. This enables the client application to retrieve settings specific to its functionality. If a name is not specified, all applications are assumed.
Banner
Defines whether a banner is displayed. If enabled, the banner window is not visible. It is disabled by default, meaning banners will be displayed.
UpdateURI
Defines the Uniform Resource Identifier (URI) for updating the client application.
MinVer
Minimum API version that is supported.
CurVer
Current API client application version.
Data
XML BLOB, specific to the client application. This data is not handled by the RTC client API.
