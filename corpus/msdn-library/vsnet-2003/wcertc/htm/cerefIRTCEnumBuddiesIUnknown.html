IRTCEnumBuddies:IUnknown

This interface provides COM-standard enumeration methods for the IRTCBuddyEvent interface. The IRTCClientPresence::EnumerateBuddies method returns a pointer to IRTCEnumBuddies.

The following table describes the methods of this interface.

Method Description
IRTCEnumBuddies::Clone Creates another enumerator that contains the same enumeration state as the current one.
IRTCEnumBuddies::Next Retrieves the next specified number of elements in the enumeration sequence.
IRTCEnumBuddies::Reset Redefines to the beginning of the enumeration sequence.
IRTCEnumBuddies::Skip Skips over the next specified number of elements in the enumeration sequence.
