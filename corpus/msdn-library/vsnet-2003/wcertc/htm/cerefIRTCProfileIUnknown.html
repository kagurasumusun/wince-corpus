IRTCProfile:IUnknown

This interface is the main interface for the Profile object. This object is created by the IRTCClientProvisioning::CreateProfile method. This interface retrieves information from the provisioning profile.

For more information on the Profile object, see the Create and Enable a Profile code example.

The following table describes the methods of this interface.

Method Description
IRTCProfile::get_ClientBanner Returns a flag that specifies if the Client should display the banner for the profile.
IRTCProfile::get_ClientCurVer Returns the current version of the Client for this profile. If the Client is lower than this version, it may upgrade by visiting the URI returned by get_ClientUpdateURI.
IRTCProfile::get_ClientData Returns the XML string from the profile that contains the Client's private data tag.
IRTCProfile::get_ClientMinVer Returns the minimum version of the Client for this profile. If the Client is lower than this version, it must attempt to upgrade by visiting the URI returned by get_ClientUpdateURI.
IRTCProfile::get_ClientName Returns the name of the Client for the specified profile.
IRTCProfile::get_ClientUpdateURI Returns the URI where updates of the Client are available for the profile.
IRTCProfile::get_Key Returns the key that uniquely identifies the profile.
IRTCProfile::get_Name Returns the name of the profile.
IRTCProfile::get_ProviderData Returns the XML string from the profile that contains the provider's private data tag.
IRTCProfile::get_ProviderName Returns the name of the provider for the profile.
IRTCProfile::get_ProviderURI Returns the provider URI for the profile.
IRTCProfile::get_SessionCapabilities Returns the types of sessions supported by the provider for the profile.
IRTCProfile::get_State Returns the current state of registration for the profile.
IRTCProfile::get_UserAccount Returns the user account associated with the profile.
IRTCProfile::get_UserName Returns the user name associated with the profile.
IRTCProfile::get_UserURI Returns the user URI associated with the profile.
IRTCProfile::get_XML Returns the XML string used to create the profile.
IRTCProfile::SetCredentials Overrides the profile credentials.
