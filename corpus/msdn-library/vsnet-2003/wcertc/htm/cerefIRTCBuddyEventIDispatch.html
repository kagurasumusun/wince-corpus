IRTCBuddyEvent:IDispatch

This interface is used to retrieve information concerning the change in the presence state of the contact. When an application's implementation of the IRTCEventNotification::Event method indicates an RTC_EVENT of type RTCE_BUDDY, the method's pEvent parameter returns an IDispatch pointer to the IRTCBuddyEvent interface.

Note   To allow an application to receive contact events, the IRTCClient::put_EventFilter method must be called. Set an event filter mask that includes the RTCEF_BUDDY event.

The following table describes the methods of this interface.

Method Description
IRTCBuddy::get_Buddy Returns the Buddy object.
