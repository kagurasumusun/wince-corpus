IRTCSession::SendMessage

This method sends an instant message. For this method to succeed, the session must be of type RTCST_IM.

The completion is notified with an RTCE_MESSAGING event of type RTCMSET_MESSAGE.

HRESULT SendMessage(
BSTR bstrMessageHeader,
BSTR bstrMessage,
long lCookie
);

Parameters

bstrMessageHeader
[in] MIME header.
bstrMessage
[in] The message that is sent.
lCookie
[in] Application-provided cookie used for pairing the notifications with the messages sent.

Return Values

RTC methods may return an RTC_E_ constant.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Rtccore.idl Rtccore.h Rtccore.dll
