ACMDM_STREAM_CLOSE

This message requests an ACM driver to close a conversion stream that was opened with an ACMDM_STREAM_OPEN message. This message is sent when a conversion stream is no longer being used. The codec should clean up any resources that were allocated for the stream.

Parameters

lParam1
Pointer to the ACMDRVSTREAMINSTANCE structure that describes an instance of a conversion stream.

Return Values

The supporting function returns zero if the function succeeds. Otherwise, the return value is an ACMERR_* or MMSYSERR_* nonzero error value. However, the codec should always close the conversion string.
