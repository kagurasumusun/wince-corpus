IRTCClientPresence::EnumerateWatchers

This method returns an enumeration of the allowed and blocked Watchers available on this Client. If there are no Watchers on this Client, an empty enumeration is returned.

HRESULT EnumerateWatchers(
IRTCEnumWatchers **ppEnum
);

Parameters

ppEnum
[out, retval] Pointer to the IRTCEnumWatchers interface on an enumeration object containing an IRTCWatcher pointer for each Watcher on this Client. This call adds a reference to the enumeration object, which the caller is responsible for releasing.

Return Values

RTC methods may return an RTC_E_ constant.
