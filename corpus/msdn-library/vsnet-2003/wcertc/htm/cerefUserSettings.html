User Settings

User settings are used for phone-to-phone sessions and define the information required by the third-party server. These settings are as follows:

URI
User's SIP Uniform Resource Identifier (URI).
Account
User's third-party server or ITSP account identifier.
Name
User's display name, which is used by the client application.
Password
User's third-party server or ITSP authentication password.
