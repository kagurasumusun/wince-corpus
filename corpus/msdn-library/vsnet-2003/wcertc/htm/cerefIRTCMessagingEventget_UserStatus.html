IRTCMessagingEvent::get_UserStatus

This method returns the user keystroke status.

HRESULT get_UserStatus(
RTC_MESSAGING_USER_STATUS *penUserStatus
);

Parameters

penUserStatus
[out, retval] Pointer to an RTC_MESSAGING_USER_STATUS enumeration containing the user status. The status indicates if the user is typing or idle.

Return Values

RTC methods may return an RTC_E_ constant.

Remarks

This method is used for IM sessions only. The applications that are participating in the IM session are responsible for setting their current user status. The status is sent to other participants with the IRTCSession::SendMessageStatus method.
