IRTCSessionStateChangeEvent:IDispatch

This interface is for RTCE_SESSION_STATE_CHANGE events. This type of event is fired when a session changes state.

When the application's implementation of the IRTCEventNotification::Event method indicates an RTC_EVENT of type RTCE_SESSION_STATE_CHANGE, the method's pEvent parameter is an IDispatch pointer for the IRTCSessionStateChangeEvent interface. The methods of this interface can be used to retrieve information concerning the change in the presence state of the Contact.

Note   You must call the IRTCClient::put_EventFilter method and set an event filter mask that includes the RTCEF_SESSION_STATE_CHANGE event to enable reception of Contact events. If you do not call IRTCClient::put_EventFilter, your application will not receive any events.

For more information on creating this interface, see the Answer a Call code snippet.

The following table describes the methods of this interface.

Method Description
IRTCSessionStateChangeEvent::get_Session Returns the Session object that changed state.
IRTCSessionStateChangeEvent::get_State Returns the new state of the Session.
IRTCSessionStateChangeEvent::get_StatusCode Returns the result code associated with the state change.
IRTCSessionStateChangeEvent::get_StatusText Returns the status text associated with the state change.
