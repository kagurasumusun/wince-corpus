SIP Server

A SIP server functions as both the SIP registrar for location information and the SIP proxy server for call routing. This server registers presence information and establishes Windows CE-SIP client, Windows CE-phone, or messaging sessions. The SIP server uses URIs to handle call signaling and call setup. After a communication link is established, the devices communicate directly.
