RTC_SESSION_STATE

This enumeration describes the ring that is played on the default Audio device. The IRTCSession::get_State method returns a member of this enumeration.

typedef enum RTC_SESSION_STATE{
RTCSS_IDLE,
RTCSS_INCOMING,
RTCSS_ANSWERING,
RTCSS_INPROGRESS,
RTCSS_CONNECTED,
RTCSS_DISCONNECTED
} RTC_SESSION_STATE;

Elements

RTCSS_IDLE
The session is idle.
RTCSS_INCOMING
The session has an incoming call.
RTCSS_ANSWERING
The session is answering an incoming session.
RTCSS_INPROGRESS
The session is in progress.
RTCSS_CONNECTED
The session is connected.
RTCSS_DISCONNECTED
The session is disconnected.

Requirements
