Provision Settings

Provision settings define basic information about the profile to make it unique. These settings are as follows:

Key
Unique identifying string for the profile.
Name
Name of the provisioning profile.
Expires
Profile expiration data and time. When this time elapses, the client must enable the profile in the application. If the profile is not enabled, this value will be 0.
