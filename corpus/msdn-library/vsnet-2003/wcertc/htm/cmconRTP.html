RTP/RTCP

Real-time Transport Protocol (RTP) is the standard Internet protocol used to transport real-time data. In Windows CE , audio (VoIP) and telephony are supported; video is not supported.

RTP is a thin protocol that supports real-time applications containing continuous media like audio, timing reconstruction, loss detection, security and content identification. Real-time Control Protocol (RTCP) extends support to real-time conferencing within a network. This support includes source identification and gateways for audio bridges and multicast-to-unicast translators. RTCP manages information about packet losses and latency in the network. In addition, RTCP offers quality-of-service feedback from receivers to the multicast group and supports synchronization for different media streams.
