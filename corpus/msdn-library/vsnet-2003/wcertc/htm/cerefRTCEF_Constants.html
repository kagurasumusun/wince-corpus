RTCEF_ Constants

The event filter constants describe the types of events the application can register to receive. The IRTCClient::get_EventFilter and IRTCClient::put_EventFilter methods use the event filter flags:

RTCEF_ALL
Value: 0x000007FF

All event filters are used to deliver events.

RTCEF_BUDDY
Value: 0x00000100

The Buddy filter is used to deliver events.

RTCEF_CLIENT
Value: 0x00000001

The Client filter is used to deliver events.

RTCEF_INTENSITY
Value: 0x00000040

The Intensity filter is used to deliver events.

RTCEF_MEDIA
Value: 0x00000020

The Media filter is used to deliver events.

RTCEF_MESSAGING
Value: 0x00000080

The Messaging filter is used to deliver events.

RTCEF_PARTICIPANT_STATE_CHANGE
Value: 0x00000010

The Participant State Change filter is used to deliver events.

RTCEF_PROFILE
Value: 0x00000400

The Profile filter is used to deliver events.

RTCEF_REGISTRATION_STATE_CHANGE
Value: 0x00000002

The Registration State Change filter is used to deliver events.

RTCEF_SESSION_OPERATION_COMPLETE
Value: 0x00000008

The Session Operation Complete filter is used to deliver events.

RTCEF_SESSION_STATE_CHANGE
Value: 0x00000004

The Session State Change filter is used to deliver events.

RTCEF_WATCHER
Value: 0x00000200

The Watcher filter is used to deliver events.
