FTP Server Implementation

As outlined in RFC 959, the minimum implementation of the FTP server allows FTP to operate with a minimum of error messages.

The following table lists the configuration values for a minimum FTP-server implementation.

Server Value
TYPE ASCII non-print
MODE Stream
STRUCTURE File and Record
COMMANDS USER, QUIT, and PORT
TYPE, MODE, STRU Default values for RETR, STOR, and NOOP

The Windows CE sample FTP server supports only the following transfer parameters.

Parameter Value
TYPE ASCII non-print
MODE Stream
STRU File
