FTP Server Data Types

To use data representations in FTP, you must specify the data representation type. This data type may implicitly, as in ASCII, or explicitly, as in Image Type, define a byte size for interpretation, referred to as the "logical byte size." The sample FTP server only supports the ASCII and IMAGE types and limits the logical byte size to 8 bits.
