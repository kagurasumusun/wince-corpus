Microsoft Windows CE .NET  

FTP Server

Microsoft® Windows® CE .NET includes a new sample File Transfer Protocol (FTP) server. This sample application is intended to be used by original equipment manufacturers (OEMs). Windows CE provides the FTP server source code to OEMs as is, so that they can customize the feature for their specific requirements. FTP is used for copying files to and from remote computer systems over a network using TCP/IP.

One application of the new sample FTP server feature can be to transfer files from Windows CE–based devices to desktop computers. In the past, OEMs were required to connect desktop computers to Windows CE–based devices through a development platform desktop computer. With the new FTP server, OEMs can establish a direct TCP/IP connection between the two for file transfer purposes.

The FTP server is implemented based on RFC 959, which defines the FTP requirements. FTP server supports the minimum implementation of the FTP server defined in RFC 959. This minimum implementation includes configuration values, transfer parameters, and supports only ASCII and Image data types.

The FTP server is installed and loaded as a service using Services.exe.

Note   The FTP server implementation is a sample provided for educational purposes. As a result, a number of features are implemented only to show correctly how the feature should operate. While the key functionality of these features is implemented, a production FTP server should address these features appropriately.
