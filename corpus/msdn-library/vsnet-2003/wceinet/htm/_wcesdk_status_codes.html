Microsoft Windows CE 3.0  

Status Codes

These are the only HTTP status codes that the Windows CE Web server can return:

200, "OK"
301, "Moved Permanently"
304, "Not Modified"
400, "Bad Request"
401, "Unauthorized"
403, "Forbidden"
404, "Object Not Found"
500, "Internal Server Error"
501, "Not Implemented"

Note   Custom response strings can be set by using ASP, ISAPI extensions, and ISAPI filters.
