Microsoft XML 2.0 Features That Windows CE Does Not Support

Windows CE does not support the following features that are available in Microsoft XML 2.0 for Windows-based desktop platforms:

  • Data islands
  • Data binding
  • Mime Type viewer
  • Backward compatibility with the Microsoft XML document object model (DOM) supported by Microsoft Internet Explorer 4.0

Windows CE also provides only limited XML security. Windows CE officially supports XML only within the Microsoft® Internet Explorer for Windows® CE Internet browser. The Microsoft® Pocket Internet Explorer Internet Explorer does not support XML. Using XML within C, or through Active Server Pages (ASP) or an Internet Server API (ISAPI) extension running on the Windows CE web server might work, but is unsupported.
