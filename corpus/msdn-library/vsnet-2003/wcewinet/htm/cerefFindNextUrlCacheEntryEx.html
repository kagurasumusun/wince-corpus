FindNextUrlCacheEntryEx

This function finds the next cache entry in a cache enumeration started by the FindFirstUrlCacheEntryEx function.

BOOLAPI FindNextUrlCacheEntryEx( 
HANDLE hEnumHandle,
LPINTERNET_CACHE_ENTRY_INFO lpFirstCacheEntryInfo,
LPDWORD lpdwFirstCacheEntryInfoBufferSize, 
LPVOID lpGroupAttributes,
LPDWORD pcbGroupAttributes, 
LPVOID lpReserved
);

Parameters

hEnumHandle
[in] Enumeration handle obtained from a previous call to FindFirstUrlCacheEntryEx.
lpFirstCacheEntryInfo
[out] Address of the buffer to hold the INTERNET_CACHE_ENTRY_INFO structure in which the cache entry data is stored.
lpdwFirstCacheEntryInfoBufferSize
[in/out] Address of an unsigned long integer variable that specifies the buffer size, in bytes.
lpGroupAttributes
Reserved; set to NULL.
pcbGroupAttributes
Reserved; set to NULL.
lpReserved
Reserved; set to NULL.

Return Values

Returns TRUE if successful, or FALSE otherwise.

Remarks

At the end of the enumeration, the application should call FindCloseUrlCache.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 and later Wininet.h Wininet.h Wininet.lib

See Also

FindFirstUrlCacheEntryEx, FindCloseUrlCache, INTERNET_CACHE_ENTRY_INFO
