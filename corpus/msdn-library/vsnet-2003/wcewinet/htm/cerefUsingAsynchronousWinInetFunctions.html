Using Asynchronous WinInet Functions

For applications that download multiple files or handle multiple tasks, waiting for each task to complete before moving on to the next task can be extremely inefficient. To avoid waiting, many of the WinInet functions provide a way to perform tasks asynchronously. For detailed information on using the Internet functions asynchronously, see this Microsoft Web site.
