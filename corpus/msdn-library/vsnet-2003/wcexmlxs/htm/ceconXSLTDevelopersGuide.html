XSLT Developer Guide

The successor to Extensible Stylesheet Language (XSL), XSL Transformations (XSLT) is an Extensible Markup Language (XML)-based language that enables you to transform one class of XML document to another. XSLT offers the ability to present and exchange data between disparate systems. For example, with XSLT style sheets, you can transform an XML purchase order from one schema to another before sending the order to a supplier. In addition, you can transform an XML document so it can be rendered on a variety of formats fitting different display requirements. The XSLT Developer Guide introduces you to some uses of XSLT, and gives you the information you need to start creating XSLT solutions. The XSLT Developer Guide is divided into the following two sections:

  • Getting Started with XSLT
  • Exploring XSLT Capabilities
