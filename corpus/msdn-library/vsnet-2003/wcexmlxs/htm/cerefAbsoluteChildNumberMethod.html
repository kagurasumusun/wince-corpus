absoluteChildNumber Method

Returns the number of the node that is relative to all siblings.

[Script]

Script Syntax

lValue = oXTLRuntime.absoluteChildNumber(pNode);

Script Parameters

pNode
Object. Node to which the child number is to be returned.

Script Return Value

Long integer. Returns the index for the node in its parent's list of all child nodes. The first entry in the list is assigned the value 1.

[C/C++]

C/C++ Syntax

HRESULT absoluteChildNumber(
IXMLDOMNode *pNode, 
long *pNumber
);

C/C++ Parameters

pNode [in]
Node for which the child number is to be returned.
pNumber [out, retval]
Index for the node in its parent's list of all child nodes. The first entry in the list is assigned the value 1.

C/C++ Return Values

Returns S_OK if successful, or an error code otherwise.

Requirements

Windows CE OS .NET 4.0 and later Msxml2.idl Msxml2.h Uuid.lib

General Remarks

This method applies to the following interface:

IXTLRuntime.
