__isascii, iswascii

This routine returns nonzero if c is a particular representation of an ASCII character.

Routine Required Header
__isascii <ctype.h>
iswascii <ctype.h> 

int __isascii( int c );
int iswascii( wint_t c );

Parameters

c
Integer to test

Libraries

All versions of the C run-time libraries.

Return Values

__isascii returns a non-zero value if c is an ASCII character (in the range 0x00 – 0x7F). iswascii returns a non-zero value if c is a wide-character representation of an ASCII character. Each of these routines returns 0 if c does not satisfy the test condition.

The result of the test condition for the __isascii function depends on the LC_CTYPE category setting of the current locale. For iswascii, the result of the test condition is independent of locale.
