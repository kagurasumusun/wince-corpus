iscntrl, iswcntrl

This routine returns nonzero if c is a particular representation of a control character.

Routine Required Header
iscntrl <ctype.h>
iswcntrl <ctype.h> 

int iscntrl( int c );
int iswcntrl( wint_t c );

Parameters

c
Integer to test

Libraries

All versions of the C run-time libraries.

Return Values

iscntrl returns a non-zero value if c is a control character (0x00 – 0x1F or 0x7F). iswcntrl returns a non-zero value if c is a control wide character. Each of these routines returns 0 if c does not satisfy the test condition.

The result of the test condition for the iscntrl function depends on the LC_CTYPE category setting of the current locale. For iswcntrl, the result of the test condition is independent of locale.
