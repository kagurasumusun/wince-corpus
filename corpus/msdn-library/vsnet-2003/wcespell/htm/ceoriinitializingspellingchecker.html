Initializing the Spelling Checker

Before you can use the spelling checker in your application, you must call the SplInit function to initialize a spelling session. SplInit performs the following tasks to initialize the spelling-checker engine:

  • It creates a handle for the spelling session.

    Your application uses this handle to associate a call to a spelling-checker function with a specific spelling session.

  • It loads the main, internal, and external user dictionaries.
