Using the Spelling Checker

After you initialize the spelling session and set the spelling-checker options, you can call a variety of functions to check spelling and suggest alternate words to use.

To use the spelling checker

  1. Set up the SPLBUFFER structure.

    The SPLBUFFER structure contains data that concerns the words to check, the location of the input and output buffers, and the status of the spelling session that is in progress.

  2. Perform the spelling check by calling the SplCheck or the SplReplace function:
    • The SplCheck function checks the input buffer of the SPLBUFFER against the dictionaries.
    • The SplReplace function checks the input buffer against the dictionaries and suggests a limited number of possible alternate spellings.
  3. If you called the SplCheck, call the SplSuggest to receive more alternate spellings.
  4. If it is necessary, alter the spelling of the misspelled word, or ignore the suggestion, and move to the next word.
