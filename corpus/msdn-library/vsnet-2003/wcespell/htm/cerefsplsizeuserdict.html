SplSizeUserDict

This function gets the number of words in an internal or external user dictionary 

int SplSizeUserDict( 
HSPL hspl, 
int nID, 
DWORD *pdw 
);

Parameters

hspl
Handle to the spelling session. An application initiates a spelling session by calling the SplInit function, which then generates this handle.
nID
Identification of the spelling dictionary.
pdw
Pointer to the DWORD the represents the size of the user dictionary.

Return Values

1 indicates success. 0 indicates failure.

Remarks

This function lets an application query the size of a user dictionary.
