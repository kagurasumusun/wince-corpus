Modifying External and Internal Dictionary Lists

You can modify both the internal and external dictionary lists to suit the needs of your users. In this way, you can check the spelling of words that are not in the internal main dictionary or in the external user-defined dictionary. For example, a user might want to enter his or her name, or a user might want to use a variety of technical languages in a specific document.

The internal and external user dictionaries are lists of null-terminated words. Two null characters in a row indicate the end of a dictionary. The following code example shows a series of possible listings from a user dictionary.

…thier\0their\0wierd\0weird\0\0

As the code example shows, the SPL_CHANGE_ALWAYS and SPL_CHANGE_ONCE internal dictionaries list the incorrect word first and the correct word second.

The following table describes the functions that you can use during a spelling session to modify internal and external user dictionaries.

Function Description
SplAddUserDict Adds a single word or a word pair to the specified dictionary
SplClrUserDict Clears all of the entries from the specified dictionary
SplRemUserDict Removes a single word or a word pair from the specified dictionary

The SplAddUserDict, SplRemUseDict, and SplClrUserDict functions all use the spelling-dictionary identifiers that are specified in the ppwz parameter of the SplInit function.

The SplEnumUserDict function enumerates the contents of a specified internal or external user dictionary. The function writes the dictionary contents to the output buffer that is specified by the pwszOut member in the SPLBUFFER structure. One use of enumeration is to present the contents of a dictionary to a user, who then can select words to be added and removed by using the SplAddUserDict and SplRemUserDict functions.
