Microsoft Windows CE 3.0  

Scrolling Through Text in an Edit Control

Windows CE provides three messages that you can send to an edit control that has scroll bars. The EM_LINESCROLL message can scroll a multiline edit control both vertically and horizontally. The lParam parameter specifies the number of lines to scroll vertically, starting from the current line, and the wParam parameter specifies the number of characters to scroll horizontally, starting from the current character. The edit control does not acknowledge messages to scroll horizontally if it has the ES_CENTER or ES_RIGHT style. The EM_LINESCROLL message applies to multiline edit controls only.

To implement scrolling in an edit control

To implement scrolling in an edit control, you can use the automatic scrolling styles, or you can add scroll bars explicitly to the edit control. To add a horizontal scroll bar, use the WS_HSCROLL style; to add a vertical scroll bar, use the WS_VSCROLL style. An edit control that has scroll bars processes its own messages related to the scroll bars.

The EM_SCROLL message scrolls a multiline edit control vertically, which has the same effect as sending a WM_VSCROLL message. The wParam parameter specifies the scrolling action. The EM_SCROLL message applies to multiline edit controls only.
