Step 1: Creating a Custom OS Image for the Emulator

In this step, you will use the Platform Wizard to create a custom OS image.

To create a custom OS image for the Emulator

  1. On the development workstation, launch the Platform Builder application.
  2. From the File menu, choose New Platform, and when the New Platform Wizard appears, choose Next.
  3. From the list of available board support packages (BSPs),select EMULATOR-X86 and then choose Next.
  4. From the list of available platform configurations, select Web Pad.
  5. In the Platform Name box, type MyPlatform as the name for your platform, and then choose Next.
  6. Choose Web Pad, and then choose Next.
  7. Choose Next to accept the default selections for Web Pad.
  8. Choose Next to accept the default selections for Application & Media.
  9. Choose Next to accept the default selections for Networking & Communications.
  10. Choose Next to acknowledge the Special Feature notifications.
  11. Choose Done.

Platform Builder generates the initial platform files for both a debug configuration and a release configuration. When these files are created, control returns to the Platform Builder IDE, and you are ready to build the OS image.
