Bitmap/Cursor/Icon Properties: Palette Tab

Shows available palette colors. If you have selected 16-color images, you have 16 choices; if you have selected 256-color images, you have 256 choices.

Select a color on the Palette tab to change the color indicator on the Colors palette of the Graphics editor to the selected color.

Double-click a color to display the Custom Color Selector dialog box, where you can create a custom color and set the color indicator to that color.
