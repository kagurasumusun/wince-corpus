Messages Tab

Break at WndProc
Enter the name of the WndProc you want to break on, or select a WndProc name from the drop-down list.
Set one breakpoint for each message to watch
Enter the message that you want to break on, or select a message from the drop-down list.
Breakpoints
Shows a list of current breakpoints. Use the check boxes to enable or disable specific breakpoints.
Remove
Deletes the breakpoint selected in the Breakpoints list.
Remove All
Deletes all Breakpoints currently set.
OK
Processes your input and moves to the next step.
Cancel
Closes the dialog box without saving any of the changes you have made.
Edit Code
Click to go to a source window containing the code where the breakpoint is set.
