Platform Builder Tutorials

Three tutorials are provided to assist you in getting started with Microsoft® Platform Builder 4.1. The first tutorial, Using Platform Builder with the Emulator, shows you how to create a custom platform and then run the platform on the Emulator. The Emulator does not require additional hardware because the Emulator runs on the development workstation.

The second tutorial, Using Platform Builder with a CEPC, shows you how to create a custom platform and then run the platform on a Microsoft Windows® CE .NET PC-based hardware development platform (CEPC). A CEPC is an x86-based desktop computer that runs Windows CE–based applications and device drivers. For information about building a CEPC, see CEPC Based SDB Recommended Hardware.

The third tutorial, Creating a Feature and Adding It to a Platform, shows you how to create a feature and add the feature to the Catalog. The tutorial also shows you how to use the Platform Builder integrated development environment (IDE) to include the feature in a platform.
