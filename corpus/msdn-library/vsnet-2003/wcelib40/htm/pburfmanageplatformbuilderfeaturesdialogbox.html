Manage Catalog Features Dialog Box

This dialog box enables you to import feature (.cec) files or to remove .cec files from the Catalog.

Imported Catalog Feature Files
File
Shows a list of the .cec files that have been imported into the catalog.
Version
Shows the version of the imported .cec files.
Vendor
Shows the vendor who created the imported .cec files.
Description
Shows a description the imported .cec files.
OK
Dismisses the dialog box.
Remove
Select to remove the selected .cec file from the catalog.
Import
Select to import a new .cec file to the catalog.
Refresh
Updates the data shown in the catalog to reflect any added or removed .cec files.
