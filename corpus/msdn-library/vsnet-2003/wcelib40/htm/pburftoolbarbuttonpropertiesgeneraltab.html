Toolbar Button Properties: General Tab

ID
A symbol defined in the header file. Type: Symbol, Integer, or Quoted String.
Width
The width of the toolbar button.
Height
The height of the toolbar button.
Prompt
Contains text that is to appear in the status bar when this menu item is highlighted. The text is placed in the string table with the same identifier as the menu item. This property is available only in resource files with Microsoft Foundation Class (MFC) support.
