KITL Security Warning

When the Kernel Independent Transport Layer (KITL) is enabled on a platform, certain security risks could potentially arise. The KITL Security Warning dialog box presents you with the option of enabling or disabling the device, to which you are downloading an image, access to your development workstation.

Yes

Select this option if you want to enable KITL. The following issues should be considered when selecting this option.

  • The current platform's _FLATRELEASELDIR is added to the list of allowed readable directories in the HKEY_CURRENT_USER\Software\Microsoft\Windows CE Tools\Platform Manager\PPFSAccessList registry key on the device. As a result, that directory is open to possible security risks because remote access to the directory has been enabled. The _FLATRELEASELDIR directory could be located on a remote share, not on your development workstation, and still be vulnerable.
  • Enabling KITL does not grant access to sub-folders. You can access only the top-level directory (_FLATRELEASELDIR) where the image lives.
  • Enables Parallel Port File System (PPFS) access to a remote machine. The PPFS service provides a means for a target device to access files on a development workstation.

No

Select this option if you want to disable KITL. The following issues should be considered when selecting this option.

  • The current Platform's _FLATRELEASELDIR is removed from the list of directories that are allowed to be read in the HKEY_CURRENT_USER\Software\Microsoft\Windows CE Tools\Platform Manager\PPFSAccessList registry key on the device.
  • The downloaded OS will not be able to start applications or modules located in the _ FLATRELEASELDIR directory.
  • Applications that are located in the _FLATRELEASELDIR directory cannot be started from the Run Programs dialog box access from the Tools menu.
  • If cemgrc and associated its associated .dll files are not built into the image downloaded to the device, the CESH startup server is disabled, and as a result, all remote tools are also disabled.

Notes

All directories listed in the HKEY_CURRENT_USER\Software\Microsoft\Platform Builder\4.10\General\PPFSAccessList registry key on the device are vulnerable to potential attack.
