Services Tab

The Services tab of the Configure Remote Connection dialog box allows you to select a download service and a kernel transport for a named connection. You must first select an active named connection. You can then select a download service and a kernel transport for the active named connection.

Active Named Connection
Displays the named connection that is active.
Add New
Adds a new named connection to Platform Manager.
Delete
Deletes the named connection displayed in the Active Named Connection box.
Named Connection Services
Displays the name of the download service and kernel transport corresponding to the named connection displayed in the Active Named Connection box.
Download
Displays the name of a download service with which to download an OS image to a target device.
Configure
Opens a dialog box in which you can modify settings for a download service.
Kernel Transport
Displays the name of a kernel transport with which to establish a kernel-level connection between the development workstation and a target device.
Configure
Opens a dialog box in which you can modify settings for a kernel transport.
Use Hardware Debugger
Enables or disables hardware debugging.
Select eXdi driver
Displays a driver to be used with the hardware debugger.
