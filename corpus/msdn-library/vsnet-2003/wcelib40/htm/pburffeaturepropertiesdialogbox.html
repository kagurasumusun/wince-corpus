Feature Properties Dialog Box

This dialog box displays information for the selected feature.

This icon and other icons with one cylinder represent features in the Feature window. You must select a feature in order to see the Supported CPUs tab.

Pushpin button
Click to keep this dialog box open on your desktop, on top of all other windows. Click again to cancel this feature.
