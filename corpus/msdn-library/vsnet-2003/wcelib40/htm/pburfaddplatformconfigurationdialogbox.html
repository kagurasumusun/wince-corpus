Add Platform Configuration Dialog Box

Configuration
Type the name to identify the new configuration. The configuration name must be unique within this platform.
Copy settings from
Choose the settings configuration from which to copy initial settings. Once the new configuration has been created, you can use the Platform Settings dialog box to modify the settings for your new configuration.
The new configuration will be called
Shows the name of the new configuration, based on the configuration information you input.
OK
Creates your new configuration and returns to the Configurations dialog box.
Cancel
Closes the dialog box without saving any of the changes you have made.
