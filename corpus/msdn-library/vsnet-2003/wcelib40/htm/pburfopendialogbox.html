Open Dialog Box

This dialog box enables you to open existing files.

Look in
Select the drive or folder that contains the file you want. The contents of the drive or folder appear below in the File list.
File list
Select the file you want to open.
File name
Select or type the name of the file you want to open.
File of type
To display the type of file you want to open, select the file type you want from the drop-down list.
Open as read only
Select the check box if you want to be able to read but not make changes in the file you open.
Open as
Select Auto to have Platform Builder automatically handle files it recognizes; for example, .pbw files will be opened as workspaces, and .rc files will be opened in the resource editor. Select Text, Binary, or Resources to open the file as that specific type of file.
OK
Opens the specified file.
Cancel
Closes the dialog box without making any changes.
