Check in files Dialog Box

Checks in changes made in the working directory of your development environment to your source code control database.

Files
Lists the files available for check in. Select the files you want to check in, or choose Select All to select all files listed.
Keep checked out
Updates the source code control database with your changes but keeps the file checked out to you.
Comment
Type a brief description of the reason for the check in.
OK
Checks in the selected files.
Cancel
Cancels the Check In command.
Select All
Selects all files listed.
Differences
Displays the Difference Options dialog box.
