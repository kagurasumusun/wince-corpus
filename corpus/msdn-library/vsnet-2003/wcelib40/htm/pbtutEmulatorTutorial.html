Tutorial: Using Platform Builder with the Emulator

This guide will help you become familiar with Platform Builder and the new features of the Windows CE .NET operating system (OS). It provides a step-by-step tutorial for creating and debugging a custom run-time OS image and a simple application that runs in the Emulator.

In this tutorial you will build a Web Pad running the Hello World application that will run in the Emulator. This tutorial assumes you have installed Platform Builder and the OS as described in the installation instructions and have selected the Emulator as one of the CPUs that you installed. This tutorial takes approximately 50 minutes to complete.

In this tutorial, you will complete the following steps:

  • Step 1: Creating a Custom OS Image for the Emulator
  • Step 2: Building the Custom OS Image for the Emulator
  • Step 3: Setting Up a Connection to the Emulator and Downloading the OS Image
  • Step 4: Debugging the OS on the Emulator Using the Kernel Debugger
  • Step 5: Localizing the OS Image for the Emulator
  • Step 6: Creating and Building an Application for the Emulator
  • Step 7: Running the Application in the Emulator on the Custom OS Image
  • Step 8: Creating an SDK for eMbedded Visual C++
