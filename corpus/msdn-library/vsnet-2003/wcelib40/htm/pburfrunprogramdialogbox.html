Run Program Dialog Box

This dialog box enables you to start or stop a specific executable file. Note that this dialog box can only be accessed when Target Control (CESH) is running. In addition, for debug kernel images only, the debugger needs to be running before accessing and using the Run Program dialog box to execute a program.

Output from this dialog box is found on the Debug tab of the Output window.

Available Programs
Displays all executables in your _flatreleasedir in this list box.
Execution command line
Displays the program and arguments that are executed when the Run button is selected. You can use the Execution command line to add arguments when starting a program.
Run Program
Runs the program that is currently in the Execution command line edit box.
Cancel
Closes the Run Program dialog box without running a program.
