Advanced Debugger Commands Dialog Box

This dialog box enables you to execute a custom command through the kernel debugger. This dialog box is available only when you are debugging and in a break state.

Command
Enter the name of the custom command.
Execute
Select to execute the command you typed in.
Close
Select to close this dialog box without making any changes.
