Project Dependencies Dialog Box

This dialog box enables you to enumerate projects that the selected project is dependent on.

Select project to modify
Select a project from the list of existing projects. You add the subprojects that you select or create to this project, and/or remove subprojects from this project.
Dependent on the following project(s)
Selects any projects on which the current project depends.
OK
Processes your input and closes the dialog box.
Cancel
Closes this dialog box without saving any change.
