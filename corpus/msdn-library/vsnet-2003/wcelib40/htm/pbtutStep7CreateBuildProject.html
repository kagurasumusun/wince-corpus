Step 6: Creating and Building an Application for the Emulator

In this step, you will create and build a simple application using Platform Builder.

To create and build an application for the Emulator

  1. From the Target menu in the IDE, choose Disconnect, and then choose OK.
  2. Verify that you want to stop debugging now without disabling KdStub by choosing Yes.

    Control returns to the IDE.

  3. Close the window for the Emulator.
  4. From the Shut Down dialog box, select Turn off Emulator, and then choose OK.
  5. From the File menu, choose New Project or File.
  6. Choose the Projects tab, and then select WCE Application.
  7. In the Project name box, type Hello, and then choose OK.
  8. Choose A typical "Hello World!" application, and then choose Finish.
  9. From the Build menu, choose Build Hello.exe to build the application.

    When the build is complete, you will see the following message: 0 error(s), 0 warning(s).

By completing this step, you have successfully created an application. You are now ready to run the application in the Emulator.
