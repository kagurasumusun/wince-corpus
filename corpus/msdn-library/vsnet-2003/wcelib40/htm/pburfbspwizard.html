BSP Wizard

The BSP Wizard guides you through the process of creating a Windows CE board support package (BSP). It automatically generates a .cec file for your BSP, copies your BSP files to the appropriate location, and imports your new .cec file into the Catalog.

The process of creating a BSP with the BSP Wizard includes the following steps:

  1. Choosing to create a new BSP, duplicate an existing BSP, or add drivers to an existing BSP.
  2. Entering the name, description, directory, source directory, and microprocessor for your BSP.
  3. Selecting which .cec file will be edited.
  4. Customizing your BSP.
