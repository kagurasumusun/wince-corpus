Source Control Tab

Note that the Source Control tab is only available if you are using source control.

Get files when opening the workspace
Select this check box display a dialog box that enables you to copy the latest versions of the master files under source-code control to your workspace when you open the project workspace.
Check out source file(s) when edited
Select this check box to automatically check out source files when you open them for editing.
Check in files when closing the workspace
Select this check box to automatically check in source files when you close the workspace.
Prompt to add files when inserted
Select this check box to automatically prompt you to add files to source control when you insert the file in the workspace.
Perform background status updates
Select this check box to updates the status of the files under source-code control at the most convenient times, as a background task.
Use dialog for checkout
Select this check box to be prompted with a dialog box when files are being checked out. Remove the checkmark to have the selected files checked out immediately, without prompting you for confirmation
Add new projects to source control
Select this check box to automatically prompt you to add new projects to source control when they are created.
Include only selected files in dialogs
When selected, only the files selected in FileView are listed in the source control dialog boxes, such as Add to Source Control and Check In File(s). Otherwise, the list contains all the files to which the specified action can be applied.
Login ID
Enter the login name you use for your source control system.
Advanced
Shows additional options in your source control system.
