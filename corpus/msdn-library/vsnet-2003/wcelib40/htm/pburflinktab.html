Link Tab

Category
Select a category from the Category list to see and change the information that pertains to that category. When you select a category, the contents of the Link tab dynamically changes.

General category

Output file name
Enter an output file and or override the default name and location of the program that the linker creates.
Object/library modules
Enter an object file or standard library (either static or import) to pass to the linker. Separate file names with a space if there is more than one.
Generate debug info
Select the Generate debug info checkbox to generate debug information. Clear the checkbox if you do not want to generate this information.
Ignore all default libraries
Select the Ignore all default libraries checkbox to remove all default libraries from the list of libraries the linker searches when resolving external references. Clear the checkbox if you want to use the default libraries.
Generate mapfile
Select the Generate mapfile checkbox to generate a mapfile. A mapfile is a text file that contains information about the program being linked, including the groups in the program and a list of public symbols. The linker names the mapfile with the base name of the program and the file name extension .map. Clear the checkbox if you do not want to generate this file.
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

Customize category

Use program database
Select the Use program database checkbox to use to place debugging information in a program database (PDB). Clear the checkbox if you do not want to use a PDB.
Program database name
Shows the name of the program database (PDB). You may type in the text box to change the name of the PDB.
Force file output
Select Force file output to generate a valid executable file or DLL even if a symbol is referenced but not defined or is multiply defined.
Output file name
Shows the name of the output file. You may override the default name and location of the program that the linker creates by typing in the text box to change the file name.
Print progress messages
Select the Print progress messages checkbox to print progress messages to display details about the linking process during a build. Clear the checkbox if you do not want to print this information.
Suppress startup banner
Select the Suppress startup banner checkbox to suppress the display of the copyright message and version number during a build. Clear the checkbox if you want the banner to appear.
Project options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

Debug category

Generate Mapfile
Select the Generate mapfile checkbox to generate a mapfile. A mapfile is a text file that contains information about the program being linked, including the groups in the program and a list of public symbols. The linker names the mapfile with the base name of the program and the file name extension .map. Clear the checkbox if you do not want to generate this file.
Mapfile name
Shows the name of the mapfile, if you have selected the Generate mapfile checkbox above it. You may type in the text box to specify a name for the mapfile other than the default.
Debug info
Select the Debug info checkbox to generate debugging information for the executable file or DLL. Clear the checkbox if you do not want this information.
Separate types
Select Separate types to distribute debugging information in the source (compiler) .pdb files. Linking can be faster with this option but debugging can be slower due to the need to locate more files. Do not use this build when more than one user will debug the build.
Microsoft format
Select the Microsoft format checkbox to format debugging information in the Microsoft implementation of COFF. The Microsoft version is also called the portable executable (PE) file format. It is derived from the UNIX specification for COFF, but includes additional headers for compatibility with the MS-DOS and 16-bit Windows operating systems. Clear the checkbox if you do not want just this format.
COFF format
Select the COFF format checkbox to format debugging information in Common Object File Format (COFF). Clear the checkbox if you do not want just this format.
Both formats
Select the Both formats checkbox to generate debugging information in both COFF and Microsoft (or PE) format. Clear the checkbox if you do not want both of these formats.
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

Input category

Object/library modules
Displays the object file or standard library (either static or import) to pass to the linker. Separate file names with a space. You may type in the text box to change the default values.
Ignore all default libraries
Select the Ignore all default libraries checkbox to remove all default libraries from the list of libraries the linker searches when resolving external references. Clear the checkbox if you want to use the default libraries.
Ignore libraries
Specify one or more default libraries to remove from the list of libraries the linker searches when resolving external references. Separate file names with a comma.
Force symbol references
Specify one or more symbols to add to the symbol table. Forces linking with the object that contains the symbol definition or definitions.
Additional library path
Provides a space for you to specify additional paths that the linker can use to search for libraries. Separate each path specification with either a comma or semicolon. These paths are in addition to the path specified in the Library files category located on the Directories tab of the Options dialog box (Tools menu).
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

Output category

Base address
Specifies a base address for a program. Specified address overrides the default location for an executable file (at 0x400000) or a DLL (at 0x10000000). You may type in the text box to change the default address.
Entry-point symbol
Specifies a starting address for an executable file or DLL. ). You may type in the text box to change the default starting address.
Reserve
Specifies the total stack allocation, in bytes, of virtual memory. The default stack size is 1 MB. ). You may type in the text box to change the default allocation.
Commit
Specifies the amount, in bytes, of physical memory to allocate from the reserve memory. You may type in the text box to change the default allocation.
Major
Specifies the major part of a version number, which precedes the decimal point, to insert into the header of an executable file or DLL. Type in the text box to enter or change the version number. There is no default value and must be an integer.
Minor
Specifies the minor part of a version number, which follows the decimal point, to insert into the header of an executable file or DLL. Type in the text box to enter or change the version number. The Minor version number field is not active unless there is a major version number. Must be an integer.
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.
