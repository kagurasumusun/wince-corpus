Step 5: Localizing the OS Image for the Emulator

Windows CE offers the ability to localize an OS image into several languages. In this step, you will localize the custom Web Pad OS image into German for the locale of Germany.

To localize the OS image for the Emulator

  1. From the Platform menu in the IDE, choose Settings.
  2. In the Settings For box, verify that EMULATOR-X86 Win32 (WCE emulator) Debug is selected.
  3. Choose the Locale tab.
  4. In the Locales list, verify that all languages are deselected.
  5. From the Default Language list, select German (Germany).
  6. Choose OK to close the Platform Settings dialog box.
  7. From the Build menu, choose Build Platform.

    During the build, a dialog box appears, warning you about the inclusion of the .NET Compact Framework Beta Release in your platform.

  8. Choose OK to acknowledge this message.

    It may take as long as twenty minutes to build the OS image. When the build is complete, you will see the following message: 0 error(s), XX warning(s).

  9. From the Target menu, choose Download/Initialize.

    The KITL Security Warning dialog box appears.

  10. For the purposes of this tutorial, choose Yes.

In approximately one minute, the localized OS image finishes downloading to the Emulator, and you are then ready to create and build an application.
