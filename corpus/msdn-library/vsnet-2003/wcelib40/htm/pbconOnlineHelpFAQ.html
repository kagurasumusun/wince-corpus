Q: How do I find sample code?

A: Use the index. In the navigation pane, choose the Index tab. In the Type in the keyword to find box, type samples. To choose a specific topic, select one of the entries from the list.

Q: How do I find integrated development environment (IDE) procedures?

A: Use the index. In the navigation pane, choose the Index tab. In the Type in the keyword to find box, type IDE procedures. To choose a specific topic, select one of the entries from the list.

Note   Because documentation for IDE procedures does not appear in the table of contents, you will not be able to use the Locate button to find these topics in context. To keep track of procedure topics that you reference often, add the topics to your list of favorites in the Favorites tab.

Q: How do I find command-line procedures?

A: Use the index. In the navigation pane, choose the Index tab. In the Type in the keyword to find box, type command-line procedures. To choose a specific topic, select one of the entries from the list.

Note   Because documentation for command-line procedures does not appear in the table of contents, you will not be able to use the Locate button to find these topics in context. To keep track of procedure topics that you reference often, add the topics to your list of favorites in the Favorites tab.

Q: Where can I find information about the differences between Windows CE 3.0 and Windows CE .NET?

A: Help contains no comparison list detailing the differences between the Microsoft® Windows® CE 3.0 OS and the Windows CE .NET OS. See the following topics:

  • Migration Issues
  • What's New

Q: Where can I find a list of all supported features in Windows CE?

A: Catalog Features contains tables listing the supported features in Windows CE and a brief description of each feature.

Q: Where can I find information about supported microprocessors?

A: For a list of currently supported processors, see this Microsoft Web site.

Q: Where can I find information about creating my first platform?

A: The tutorials will get you started building your first platform and running it on either a CEPC or the Emulator. See Platform Builder Tutorials.

Q: What is context-sensitive Help (F1 Help)?

A: Context-sensitive Help, also called F1 Help, is content that is associated with a specific dialog box or dialog box element. In the Platform Builder IDE, F1 Help is available for some dialog boxes.

Q: What do I do if Search returns too many topics?

A: Clear the Match similar words check box. This check box is located beneath the topics list.

For information on how you can refine your search, see Using Full-Text Search. You can also determine whether a topic found using search is the topic you want by looking at the Title and Location column headings. Title indicates the topic title and Location specifies where the topic is located within the Help system.

Q: Why doesn't the Locate button work?

A: The Locate button cannot synchronize a topic with the table of contents if that topic is not part of the table of contents. In general, the IDE procedure topics and command-line procedure topics are not part of the table of contents.

Q: How do I send feedback about Help or documentation issues?

A: Use the Send Feedback link at the bottom of each topic.
