Configurations Dialog Box

Platforms and configurations
Displays the existing platforms and configurations in the open platform workspace. Note that this shows platforms and configurations only when in Platform view.
Projects and configurations
Displays the existing projects and configurations in the open project workspace. Note that this shows projects and configurations only when in Project view.
Close
Processes your input and closes the dialog box.
Add
Displays a dialog box with which you can add a new configuration. For more information, see the following table:
View Dialog Box Allows you to
Platform Add Platform Configuration Dialog Box Add to the selected platform
Project Add Project Configuration Dialog Box Add to the selected project
Remove
Removes the selected configuration from the project or platform.

When in Platform View:

  • You cannot remove the platform itself. Each platform must have at least one build configuration.
  • You can remove any build configuration until only one is left.
  • You cannot remove the last build configuration.

When in Project View:

  • You can remove the project itself only if there is more than one project.
  • You cannot remove the last project. Each project must have at least one build configuration.
  • You cannot remove the last build configuration.
