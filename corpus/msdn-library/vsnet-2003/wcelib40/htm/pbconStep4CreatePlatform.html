Step 6: Creating a Platform

After adding your feature to the Catalog, you can add the feature to a platform. This step shows you how to create a basic platform. If you have already created a platform, skip to Step 7: Adding the Feature to the Platform.

The following procedure shows how to create a basic platform from the Internet Appliance configuration.

To create a platform

  1. From the File menu, choose New Platform.
  2. Choose Next.
  3. In the Available BSPs list, select EMULATOR-X86, and then choose Next.
  4. In the Available configurations list, select Internet Appliance.
  5. In the Platform Name box, type SamplePlatform, and then choose Finish.

    - or -

    In the Platform Name box, type a name of your choosing, and then choose Finish.

  6. Choose Done.

You are now ready to move on to the next step of the tutorial.
