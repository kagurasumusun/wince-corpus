Resolve Features Dialog Box

In your platform, a feature group may be unresolved, meaning that the feature group is not associated with a specific feature. You must resolve all unresolved feature groups before you can build your platform.

If your platform contains an unresolved feature group, the Resolve Features dialog box allows you to select one or more specific features compatible with your platform and board support package (BSP) to associate with the feature group. The Resolve Features dialog box also allows you to remove or modify the associations for a feature group that is already resolved.

Unresolved
Displays all unresolved feature groups for the platform. From the list, select an unresolved feature group to display the features for the feature group.
Resolved
Displays all resolved feature groups for the platform. From the list, select a resolved feature group to display the features for the feature group.
Select one or more Features
Displays the features for the selected feature group. From the list, select a feature to associate it with the feature group or unselect a feature to disassociate it from the feature group.
OK
Saves your changes to resolved and unresolved feature groups and closes the dialog box.
Cancel
Closes the dialog box without saving your changes.
