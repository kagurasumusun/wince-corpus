Platform Settings Dialog Box

This dialog box enables you to view and modify options for individual features and for an entire platform.

Note that if you select an individual feature except for the main feature or the core OS feature, you will see only two tabs, the General tab and the Custom Build tab. The General tab contains only the Exclude feature from build check box. You do not get the Custom Build tab when you select an entire platform.

Settings for
Select the configuration or configurations for which to change the settings.
Feature list
Lists features in the current platform. Choose the plus sign (+) to display the individual features, and choose the minus sign (–) to collapse the display. Depending on what you select, you can set options for an individual feature, multiple features that are compatible, or the entire platform.

This dialog contains the following tabs:

  • General Tab
  • Build Options Tab
  • Environment Tab
  • Custom Build Tab
  • Locale Tab
  • BIB Info Tab
