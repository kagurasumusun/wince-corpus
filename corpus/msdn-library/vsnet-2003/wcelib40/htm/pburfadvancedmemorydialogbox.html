Advanced Memory Window

This dialog box enables you to locate, relocate, or place data in memory.

Tab Description
Search Tab Choose to search through memory for whatever is in the data field.
Move Tab Choose to move a chunk of memory from the Start Address through the Range to the Destination.
Fill Tab Choose to fill a chunk of memory with the data from the data field.
