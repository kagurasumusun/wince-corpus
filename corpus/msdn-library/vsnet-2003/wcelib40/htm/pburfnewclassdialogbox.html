New Class Dialog Box

This dialog box enables you to add a new class to an existing project.

Class type
Shows the class type. Currently Platform Builder has only one class type, Generic Class.
Name
Type the name of the new class.
File Name
Displays the name of the implementation file for the new class name you entered.
Change
Select to enter different filenames for the new class.
Change Files Dialog Box
Header File
Type or browse to enter a new header file name.
Browse
Select to locate an existing file.
Implementation File
Type or browse to enter a new implementation file name.
Browse
Select to locate an existing file.
Derived from
Click in the Derived From column to enter the base class from which the base class is to be derived.
As
Click on the entry in the As column you wish to change, and then click the down arrow to select the type of inheritance (public, private, or protected) for that base class.
OK
Processes your selection and closes the dialog box.
Cancel
Closes the dialog box without saving any changes.
