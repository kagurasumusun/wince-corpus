Step 1: Creating a Custom OS Image for a CEPC

In this step, you will use the New Platform Wizard to create a custom platform. With the platform that you create, you will be able to build an operating system (OS) image that runs on a CEPC.

To create a custom OS image for a CEPC

  1. On the development workstation, launch the Platform Builder application.
  2. From the File menu, choose New Platform.
  3. When the New Platform Wizard appears, choose Next.
  4. From the list of available board support packages (BSPs), select CEPC-X86, and then choose Next.
  5. From the list of available platform configurations, select Web Pad.
  6. In the Platform Name box, type MyCEPCPlatform as the name for your platform, and then choose Next.
  7. Choose Web Pad, and then choose Next.
  8. To accept the default selections for Application & Media, choose Next.
  9. To accept the default selections for Networking & Communications, choose Next.
  10. In the Special Feature Notification dialog box, choose Next.
  11. On the Congratulations page, choose Done to close the New Platform Wizard.

Platform Builder generates the initial platform files for both a debug configuration and a release configuration. When these files are created, control returns to the IDE, and you are ready to build the OS image.
