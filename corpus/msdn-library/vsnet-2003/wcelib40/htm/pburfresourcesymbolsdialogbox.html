Resource Symbols Dialog Box

Use this dialog box to add a new resource symbol or modify an existing one.

Name
Shows the name and numeric value for each symbol.
Value
Shows the value of the symbol.
In Use
When the In Use field is checked, it specifies that one or more resources are using the symbol. The resource or resources are listed in the Used by box.
Show read-only symbols
When checked, displays read-only resources. Normally the Symbol Browser displays only the modifiable resources in your resource script file. Modifiable resources appear in bold text; read-only resources appear in plain text.
Used by
Displays the resource or resources using the symbol selected in the symbols list. To move to the editor for a given resource, select the resource in the Used By box and choose View Use, or double-click the resource.
Close
Processes input and carries out any default action, such as closing the dialog box.
New
Click to define a new symbol. This will open the New Symbol dialog box.
Delete
Click to delete the selected symbol. Available for unused symbols only.
Change
Click to change the name or value of a symbol. If the symbol is for a control or resource in use, the symbol can be changed only from the corresponding resource editor.
View Use
Click to open the resource that contains the symbol in the corresponding resource editor.
