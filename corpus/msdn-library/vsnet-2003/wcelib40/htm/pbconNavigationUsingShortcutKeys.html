Close Help ALT+F4
Switch between Help and other open windows ALT+TAB

The following table shows keyboard shortcuts that can be used on the Contents tab.

To Press
Display the Contents tab ALT+C
Expand and collapse a book or folder PLUS SIGN (+) and MINUS SIGN (-)
- or -
LEFT ARROW and RIGHT ARROW
Select a topic DOWN ARROW and UP ARROW
Display the selected topic ENTER

The following table shows keyboard shortcuts that can be used on the Index tab.

To Press
Display the Index tab ALT+N
Place the cursor in the Type in the keyword to find box ALT+W
Select a keyword in the list DOWN ARROW and UP ARROW
Display the selected topic ALT+D
- or -
ENTER

The following table shows keyboard shortcuts that can be used on the Search tab.

To Press
Display the Search tab ALT+S
Start a search ALT+L
Select a topic in the results list ALT+T, and then UP ARROW and DOWN ARROW
Display the selected topic ALT+D
- or -
ENTER
Search for a keyword in the results list of a prior search or clear the Search previous results check box ALT+U
Search for words similar to the keyword or clear the Match similar words check box ALT+M
Search through topic titles only or clear the Search titles only check box ALT+R

The following table shows keyboard shortcuts that can be used on the Favorites tab.

To Press
Display the Favorites tab ALT+I
Add the currently displayed topic to the Topics list ALT+A
Select a topic in the Topics list ALT+P and then UP ARROW and DOWN ARROW
Display the selected topic ALT+D
Remove the selected topic from the list ALT+R
Note   Every time you use a shortcut key in the navigation pane, you lose focus in the topic pane. To return to the topic pane, press F6. The Match similar words check box on the Search tab will be selected if you used it for your last search.
