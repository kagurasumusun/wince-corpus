Debug Zones Dialog Box

This dialog box enables you to view, add, or remove settings on process and module debug zones.

Name
Displays the modules and processes currently running on the target device. The Name list box can be used to select the DLL or EXE file you want to change the debug zones for.
Debug Zones
When the target is running, select the check box for a debug zone you want to enable. Clear the check box to disable a zone. Enabling and disabling take place immediately. When target or Target Control is not running or at a debug break, debug zones cannot be viewed or changed.
Close
Close the dialog box saving any changes you have made.
