New Custom Resource Dialog Box

Resource Type
Provides a space for you to enter the name of a custom resource type. If you do not enter the name in all capital letters, Platform Builder will capitalize the name.
OK
Processes your selection and closes the dialog box.
Cancel
Closes the dialog box without saving any changes.
