Step 2: Adding an Implementation

After creating a .cec file for the feature, you need to add information to the .cec file that describes the feature. This step shows you how to use the CEC Editor to add the implementation information that defines an instance of a component type.

To add an implementation

  1. In the CEC Editor window, expand Catalog, expand New Feature, and then select My Feature Group.
  2. From the Insert menu, choose Feature.
  3. In the Name box, type My Feature.
  4. In the Description box, type This is a sample feature of the My Feature Group feature group, and then choose OK.
  5. From the File menu, choose Save.

You have added an implementation. You are now ready to add a build method for the feature.
