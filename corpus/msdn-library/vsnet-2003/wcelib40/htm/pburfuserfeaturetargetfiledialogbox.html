Insert User Feature Dialog Box

When you insert a user-defined feature into your platform, this dialog box allows you to specify the path and file name of the file that is to be copied to the release directory for your platform.

User Feature File
Path and file name of the file to copy to the release directory for your platform. If this is a buildable project, it may require a Target Name and a Display Name.
Target File
File name created by the buildable project.
Display Name
Friendly name for the buildable project.
This feature requires the platform to support the .NET runtime
Notifies the IDE that this will produce a .NET executable.
OK
Adds the User Feature to the User feature folder in the Feature view.
Cancel
Closes the dialog box without copying a file to the release directory.
