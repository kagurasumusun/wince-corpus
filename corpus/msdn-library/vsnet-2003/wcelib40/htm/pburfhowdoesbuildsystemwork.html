How does the build system work?

After you have configured your platform, you can build a platform using the integrated development environment (IDE).

The Platform Builder build system creates an operating system (OS) image in four distinct stages: the Sysgen phase, the Feature Build phase, the Release Copy phase, and the Make Image phase. The build system generates header files, links modules, copies the resulting modules to a release directory, and generates a binary image file. Most of the source code files supplied with Platform Builder are precompiled into static libraries. These static libraries, as well as code supplied by you or a third party, are linked into modules, which are combined into a binary file called Nk.bin, which can be downloaded to your target device. The Build Platform command on the Build menu executes all of the build phases in sequence.

For a more detailed explanation of the build system, see Platform Building.
