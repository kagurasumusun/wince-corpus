Modules and Symbols Window

The Modules and Symbols window enables you to load and unload the symbols for a particular module. A symbol is a name that represents a register, an absolute value, or a memory address (relative or absolute). Symbols are generated by the compiler and explain the relationship between the source code and the object code. If you are making changes in the symbols, you can unload the symbols, make your changes, and then load the symbols again using an executable file.

The Module and Symbols window provides different information if the debugger is running or if it is at a debug stop or breakpoint.

When the debugger is running

Module
Displays the name of all modules currently running on the target device.
Image Address Range
Displays the address range in the memory of the target device where the module is located.
Relocated Data Address Range
Displays the address range of relocated data. This field is blank if no data has been relocated.
Status
Indicates the status of the module's debugger symbols.
Status Description
Loaded Debugger has loaded debugger symbols.
Unloaded Debugger has not loaded debugger symbols.
Path
Displays the path to where the module is stored on the desktop computer.
PDB Path
Displays the path to where debug information produced at link time is stored.

When Target Control (CESH) is running and the debugger is stopped

Note   If a process has been started using Cesh.exe, the Modules and Symbols window will not respond until that process has completed.
Module
Displays the name of all modules currently running on the target device.
Address
Displays the load address in the memory of the target device where the module is located.
Module/Process Handle
Displays the handle for the module or process.
InUSE
Displays the In Use status for the module. Executable (.Exe) files will say Not Available.
Shortcut menu
Right-click the window to bring up the shortcut menu. Some icons on this menu are also available as toolbar buttons. This menu contains the following functions:
Item Description
Refresh Deletes all entries in the window, and updates it to contain the most recent entry information.
Auto Refresh on Step Automatically refreshes the window as you step through a process. Click to turn on or off, if it is on.
Load Symbols Loads the debugger symbols for the currently selected module.
Unload Symbols Unloads the debugger symbols for the currently selected module.
Load All Symbols Loads the debugger symbols for all modules.
Unload All Symbols Unloads the debugger symbols for all modules.
Log Formats and copies all the current data in this window to the Log tab of the Output window.
Auto Log on Step Automatically copies the data in this window to the Output window after each debugging step. Click to turn on or off.
Debug Zones Opens the Debug Zones dialog box.
List Nearest Symbol Select to bring up the List Nearest Symbols dialog box.
Docking View Select to switch the active window from docking to nondocking mode. A check mark appears if the window is in the docking mode. When a window is in docking mode, it can be either docked to the border of the main Platform Builder window or, by pressing the CTRL key and clicking on the frame of the window, it can be changed to a floating window. This floating window can be moved outside of the main Platform Builder window and can be redocked at any time. If the window is in nondocking mode, it appears inside of the main Platform Builder window and can no longer be docked.
Hide Hides the Modules and Symbols window.
