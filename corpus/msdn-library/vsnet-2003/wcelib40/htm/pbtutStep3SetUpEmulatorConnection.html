Step 3: Setting Up a Connection to the Emulator and Downloading the OS Image

In this step, you will set up and configure a connection to the Emulator, and then you will download the custom OS image to the Emulator.

To set up a connection to the Emulator and download the OS image

  1. From the Target menu, choose Configure Remote Connection.
  2. Choose the Services tab.
  3. From the Download box under Services for active named connection, choose Emulator.
  4. Choose Configure.
  5. Ensure that the Screen Size is set to 640 x480. Otherwise the Emulator window may not completely fit on your display.
  6. In the Memory (MB) box, type or select 64, and then choose OK.
  7. From the Kernel Transport box, choose Emulator.
  8. Choose the Settings tab.
  9. Under Download / Initialize Device, verify that the Connect to Device check box is selected, and then choose OK.

    You have configured the services that allow you to connect to the Emulator. You are now ready to establish a connection to the Emulator and download the OS image.

  10. From the Target menu, choose Download/Initialize.
  11. In the KITL Security Warning dialog box, choose Yes if you want the target device to have access to only the flat release folder of the OS image and its contents.

    - or -

    Choose No if you want the target device to be unable to access any folder on the desktop; this action overrides any other custom folder settings.

    Note   For the purposes of this tutorial, choose Yes.
  12. Wait until the OS appears in the MyPlatform - Emulator for Windows CE window.

    The length of time required to display the OS depends on the size of the OS image being downloaded. The OS in this example will appear in approximately one minute. While the OS image is being downloaded, you will see intermittent activity in the Debug tab of the Output window.

After the OS successfully boots, the Windows CE OS appears in the MyPlatform - Emulator for Windows CE window. You are now ready to debug the OS.
