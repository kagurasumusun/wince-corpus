Step 7: Adding the Feature to the Platform

After creating a platform, you can add your feature to the platform.

To add the feature to the platform

  1. From the View menu in the IDE, choose Catalog.

    This action displays the Catalog, if the Catalog is not already displayed.

  2. From the View menu, choose Workspace.

    This action displays the workspace for your platform, if the workspace is not already displayed.

  3. In the Catalog, navigate to your feature.
  4. Right-click on the feature, and then choose Add to Platform.

Congratulations! You have successfully completed this tutorial. You have created a feature and added the feature to the platform.
