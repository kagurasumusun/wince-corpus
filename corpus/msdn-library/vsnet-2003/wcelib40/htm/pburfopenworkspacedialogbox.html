Open Workspace Dialog Box

This dialog box enables you to open an existing workspace. Although you can select any file, Platform Builder will try to open the file you select as a workspace. If it is not a workspace file, you will get a message that states the specified file cannot be opened as a workspace.

Look in
Select the drive or folder that contains the workspace you want. The contents of the drive or folder appear below in the File list.
File list
Select the workspace you want to open.
File name
Select or type the name of the workspace you want to open.
File of type
To display the type of file you want to open, select the file type you want from the drop-down list.
Open
Opens the specified file.
Cancel
Closes the dialog box without making any changes.
Source Control
Click to open your source-code control dialog box for accessing source-code control projects. If you have not installed a source-code control system that conforms to the Microsoft Source Code Control API Specification or if your source control system does not require this button, this button is not available.
