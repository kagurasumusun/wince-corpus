Step 7: Creating and Building an Application for the CEPC

In this step, you will create a simple application using Platform Builder.

To create and build an application for the CEPC

  1. From the Target menu in the IDE, choose Disconnect, and then choose OK.

    A dialog box appears, asking whether you want to stop debugging now without disabling KdStub.

  2. For the purposes of this tutorial, choose Yes.
  3. From the File menu, choose New Project or File.
  4. Choose the Projects tab, and then select WCE Application.
  5. In the Project name box, type Hello, and then choose OK.
  6. Choose A typical "Hello World!" application, and then choose Finish.
  7. From the Build menu, choose Build Hello.exe to build the application.

    When the build is complete, you will see the following message: 0 error(s), 0 warning(s).

By completing this step, you have successfully created an application. You are now ready to run the application on the CEPC.
