Unmapped Source File Dialog Box

The Unmapped Source File dialog box displays when a breakpoint is detected in a source file and the source file has the same name as the source file used to build a module. The dialog box displays only if the paths of the two files are not mapped. The dialog box can display when a module loads or when you set a breakpoint for a module that is already loaded.

If a mapping is not found, then the dialog box suggests a mapping. You can manually create, remove, and change the priority of a mapping in the Source Path Mapping dialog box. For more information about the Source Path Mapping dialog box, see Source Path Mapping Dialog Box.

Note   The Unmapped Source File dialog box suggests a mapping between two files. It is possible that the two files are unrelated. You must decide whether the two files are related and if they should be mapped.
PDB source file
Shows the path and file name of the source file used to build the loaded module.
IDE source file
Shows the path and file name of the source file containing the breakpoint.
Yes
Creates a mapping between the paths of the source files. The mapping allows the debugger to set a breakpoint in the module.
No
Does not create a mapping and does not set a breakpoint in the module.
Don't show this again
If cleared, the dialog box displays the next time the same source file or a similar unmapped source file is found.

If selected, the dialog box does not display for any unmapped source file.

If you select the Don't show this again check box, but later decide that you want to display the Unmapped Source File dialog box, take the following steps to allow the dialog box to display.

To allow the Unmapped Source File dialog box to display

  1. From the Tools menu, choose Options.
  2. Choose the Verbosity tab.
  3. Select the Warning: Breakpoint detected in unmapped source file check box.
