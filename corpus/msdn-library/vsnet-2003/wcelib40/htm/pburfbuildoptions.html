Microsoft Windows CE .NET  

Build Options Tab

Enable Event Tracking
Check the Enable Event Tracking to start the event-tracking subsystem
Enable Full Kernel Mode
Check Enable Full Kernel Mode to run threads in kernel mode.
Note   Enabling Full Kernel Mode will leave the entire system vulnerable, but will increase performance.
Enable Kernel Debugging
Check the Enable Kernel Debugging check box before building the platform to allow the debugger to connect and pass debugging information from the target device to the host device. When Enable Kernel Debugging is checked, IMGNODEBUGGER is 0. When cleared, IMGNODEBUGGER is 1.
Enable KITL
Check to enable Kernel Independent Transport Layer. This should be checked to allow communication between the Development Workstation and the Target Device.
Enable Profiling
Check to enable CE log kernel profiling in the platform image. This is the same as setting the IMGPROFILER or IMGCELOGENABLE environment variables to 1.
