Step 8: Creating an SDK for eMbedded Visual C++

After you have customized your platform, and booted and debugged the OS, you can use Platform Builder to create an SDK for the platform. In this step, you will create an SDK for Microsoft eMbedded Visual C++ 4.0.

To create and export an SDK for eMbedded Visual C++

  1. From the Target menu of the IDE, choose Disconnect, and then choose OK.
  2. Verify that you want to stop debugging now without disabling KdStub by choosing Yes.
  3. Close the window for the Emulator.
  4. From the Shut Down dialog box, choose Turn off Emulator, and then choose OK.
  5. From the Platform menu, choose Configure SDK.
  6. When the Export SDK Wizard appears, choose Next.
  7. In the Product name for MSI installation box, type MyPlatformSDK.
  8. In the Manufacturer name box, type MyCompany, and then choose Next.
  9. Verify that the eMbedded Visual C++ 4.0 support check box is selected, and then choose Next.
  10. Under the Custom Settings heading of the Congratulations page, choose Modify the SDK configuration settings.
  11. Choose the License File tab, and then select the Append End-User License Agreement check box.
  12. In the End-User License Agreement Path box, type the location and name of a text file that you want to use as a sample End-User License Agreement (EULA).

    - or -

    Choose Browse, select a text file that you want to use as a sample EULA, and then choose Open.

  13. Choose OK to close the window.
  14. From the Platform menu, choose Build SDK.

    The Export SDK Wizard dialog box displays information while the SDK is being built.

  15. When the build is complete, choose Done.

    Your SDK is in the Myplatform_sdk.msi file in the %_WINCEROOT%\Public\MyPlatform\SDK directory.

Congratulations! You have completed this tutorial and successfully created and debugged a custom run-time OS image and a simple application that runs in the Emulator.
