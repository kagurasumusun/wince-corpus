Download Service Dialog Box

When you choose the Configure button on the Services Tab after selecting a download service that requires configuration, Platform Manager displays a dialog box in which you can configure the download service. Depending upon the download service selected, Platform Manager displays one of the following dialog boxes:

  • Configure Emulator Download Service
  • Configure Ethernet Download Service
  • Configure Serial Download Service

Configure Emulator Download Service

This dialog box allows you to specify settings for the Emulator download service.

Screen Size (WxHxD)
Specifies the resolution of the display for the Emulator. For width, type or select a numerical value between 80 and 1024 that is a multiple of 8. For height, type or select a numerical value between 64 and 768. For color depth, choose 8, 16, or 32.
Skin File
Defines the path and file name of an XML file that contains information for an Emulator skin.
Memory (MB)
Displays the amount of memory, in megabytes (MB), to allocate for the Emulator. Type or select a value between 4 and 256.
Host Key
Defines the host key for the Emulator.
In Background
If you select the Retain foreground priority check box, the Emulator runs at foreground priority at all times, even when it is in the background.
Ethernet
Defines whether the Emulator supports networking hardware. Choose Enabled to make the Emulator support networking hardware.
Serial Port 1
Displays the properties of the first virtual communications (COM) port available to the Emulator. You can map the port to a physical COM port on the development workstation, direct the output of the virtual port to a file, or make the virtual port inactive. You can choose File to specify a file for output and then in the box below the Serial Port 1 box type the path and file name of the file.

If you include support for KITL in your OS image, the OS sends its output to Serial Port 1. If the OS supports KITL, use Serial Port 2 as a product serial port. With a retail OS image, you may be able to use both Serial Port 1 and Serial Port 2 as product serial ports.

Serial Port 2
Displays the properties of the second virtual COM port available to the Emulator. You can choose File to specify a file for output and then in the box below Serial Port 2 type the path and file name of the file.
Parallel Port
Displays the properties of the parallel port available to the Emulator.
OK
Validates and saves the settings for the Emulator download service, and then returns to the Services Tab dialog box.
Cancel
Cancels any changes you made to the settings for the Emulator download service and closes the dialog box without saving any of the changes.

Configure Ethernet Download Service

This dialog box allows you to specify settings for the Ethernet download service.

Selected Device
Displays the target device that you selected in the Available Devices box.
Available Devices
Allows you to select a target device to which to download an OS image.
OK
Validates and saves the settings for the Ethernet download service, and then returns to the Services Tab dialog box.
Cancel
Cancels any changes you made to the settings for the Ethernet download service and closes the dialog box without saving any of the changes.

Configure Serial Download Service

This dialog box allows you to specify settings for the serial download service.

Port
Displays the port to use for serial communication.
Baud Rate
Displays the baud rate for the serial connection.
Flow Control
Specifies whether you want to use hardware for flow control.
Data Bits
Specifies the number of data bits.
Parity
Specifies the parity of the serial connection, if any.
Stop Bits
Specifies the number of stop bits.
OK
Validates and saves the settings for the serial download service, and then returns to the Services Tab dialog box.
Cancel
Cancels any changes you made to the settings for the serial download service and closes the dialog box without saving any of the changes.
