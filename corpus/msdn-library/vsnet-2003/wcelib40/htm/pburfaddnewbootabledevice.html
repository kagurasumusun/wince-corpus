Add New Named Connection Dialog Box

Named Connection
Name of a new connection to add to the list of named connections displayed in the Configure Remote Connection dialog box.
OK
Processes your input and returns you to the Configure Remote Connection dialog box.
Cancel
Closes the dialog box without saving any of the changes you have made.
