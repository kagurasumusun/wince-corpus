Welcome to Microsoft Windows CE .NET

Microsoft® Windows® CE .NET with Microsoft Platform Builder 4.1 is an enhanced development environment for building customized embedded platforms based on the Windows CE .NET operating system (OS). This Help collection provides information about new features and technologies supported in Windows CE .NET, as well as existing features and technologies. Tutorials, technical support, and documentation updates are offered to help you quickly learn the basics of Windows CE .NET, assist you with unique questions, and keep you informed about the latest product developments.


What's New

Introduces a broad range of new and enhanced product features:

  • New built-in base configurations expedite development for common platforms
  • Export SDK, New Platform, and BSP wizards streamline platform development
  • Kernel Independent Transport Layer (KITL) supports customized communication services
  • Feature-based Catalog enables easy platform feature selection
  • Automatic dependency checking seamlessly adds supported features

Platform Builder Tutorials

Introduces the Platform Builder integrated development environment (IDE) and helps you create customized embedded platforms:

  • Using Platform Builder with the desktop-based Windows CE .NET Emulator
  • Using Platform Builder with a Windows CE .NET PC-based hardware development platform (CEPC)
  • Creating and adding features to a platform

Windows CE .NET Overview

Provides both broad overviews and detailed discussions of individual OS features:

  • Windows CE .NET architecture
  • New OS features
  • Migration guide for Windows CE version 3.0 users

Designing Operating System Elements

Helps you create and modify OS features, boot loaders, and board support packages (BSPs):

  • Creating a boot loader
  • Creating a BSP
  • Creating a custom shell
  • Selecting a configuration

Device Driver Development

Provides architectural information and implementation details to assist you with developing device drivers.
