Remove from Source Code Control Dialog Box

Removes a copy of the selected file(s) from your source code control.

Files
Select the file or files you want to remove.
OK
Removes the selected files.
Cancel
Cancels the Remove command and closes the dialog box.
Select All
Selects all files listed.
