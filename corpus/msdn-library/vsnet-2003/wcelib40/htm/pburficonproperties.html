Icon Properties: General Tab

File name
The name of the file containing the icon resource.
Width
The image width in pixels. This property is determined by the currently selected target-device definition. This property is displayed only and cannot be modified on the property page.
Height
The image height in pixels. This property is determined by the currently selected target-device definition. This property is displayed only and cannot be modified on the property page.
Colors
Monochrome (2 colors) or 16 colors. This property is determined by the currently selected target-device definition. This property is displayed only and cannot be modified on the property page.
