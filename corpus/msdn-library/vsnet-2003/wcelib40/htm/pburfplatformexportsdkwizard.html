Export SDK Wizard

The Export SDK Wizard guides you through the process of configuring and building a software development kit (SDK) for Visual Studio .NET, Smart Device Extensions for Visual Studio .NET, and eMbedded Visual C++ 4.0. It generates a Microsoft Windows Installer (.msi) file that contains the necessary header files, libraries, Platform Manager components, run-time files, platform extensions, and documentation. With this SDK, independent software developers can create applications for your Windows CE–based platform.

The process of configuring and building an SDK with the Export SDK Wizard includes the following steps:

  1. Entering the properties for your SDK to uniquely identify it.
  2. Selecting the development languages you want to support.
