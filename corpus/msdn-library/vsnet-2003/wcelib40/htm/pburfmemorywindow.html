Memory Window

The Memory windows display a snapshot of the data in memory at a given address.

By clicking in the Memory window you can set an insertion point on a line. The Memory window will then always start on this line when displaying the contents of variables. You can also select a variable name or expression in the editor window and drag it to the Memory window. The contents of that variable will then be displayed, beginning on the line where the item was placed.

You can make changes directly to memory by typing individual hex codes in the center column or by typing directly from the keyboard in the text column on the right. All changes that you enter will be highlighted in red.

Address
Displays an individually accessible data storage location in memory. The previous entries that you have entered will appear in this text box.
Shortcut Menu
Right-click the window to bring up the shortcut menu, which contains the following functions:
Item Description
Byte Format Displays memory information in byte format, for example, 00 0A FE 32.
Short Hex Format Displays memory information in short hexadecimal format, for example, 000A FE32.
Long Hex Format Displays memory information in long hexadecimal format, for example, 000AFE32.
Toolbar Displays the address toolbar. If the address toolbar is displayed, check mark appears. Select again to clear the check mark and remove the address toolbar.
Docking View Switches the active window from docking to nondocking mode. A check mark appears if the window is in the docking mode. When a window is in docking mode, it can be either docked to the border of the main Platform Builder window or, by pressing the CTRL key and clicking on the frame of the window, it can be changed to a floating window. This floating window can be moved outside of the main Platform Builder window and can be redocked at any time. If the window is in nondocking mode, it appears inside of the main Platform Builder window and can no longer be docked.
Hide Hides the Memory window.
