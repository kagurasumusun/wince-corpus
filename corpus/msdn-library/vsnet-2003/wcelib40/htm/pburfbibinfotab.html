BIB Info Tab

This tab allows you to define binary image builder (.bib) information for the item selected in the left pane of the Platform Settings dialog box.

Files contributing to BIB Info
List of files that contribute to .bib information.
Image Name
Name to use for the file selected in the Files contributing to BIB Info list when the file is placed in the OS image.
Memory
Memory region of the OS image in which to place the file selected in the Files contributing to BIB Info list.
Attributes for Selected File
Attributes of the file selected in the Files contributing to BIB Info list.
BIB Sections
If you choose Modules, the file selected in the Files contributing to BIB Info list is placed in the MODULES section of the .bib file. For more information, see MODULES Section.

If you choose Files, the file selected in the Files contributing to BIB Info is placed in the FILES section of the .bib file. For more information, see FILES Section.
