Change Symbol Dialog Box

Use this dialog box to change the name or value of a symbol.

Used by
Displays the resource or resources using the symbol selected in the symbols list.
View Use
Click to open the resource that contains the symbol in the corresponding resource editor.
Cancel
Closes the dialog box without saving any changes.
