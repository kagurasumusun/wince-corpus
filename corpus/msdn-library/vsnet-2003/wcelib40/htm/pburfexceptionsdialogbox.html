Exceptions Dialog Box

Exceptions are errors that occur when an application executes abnormally due to conditions outside of the application's control. Windows CE does not support C++ exception handling.

The Exceptions dialog box allows you to:

  • Add an exception.
  • Modify the name of an exception.
  • Modify the debugger's response to an exception.
Number
Displays the exception value of the selected exception. You may also type a user-defined exception value.
Name
Displays the name that the IDE displays for this exception value or you may type a user-defined name.
Stop
Select Stop to have exceptions reported individually and stop debugging. The debugger will stop the image, and inform the user that the exception has occurred. The user will then need to continue the image manually (with F5/Go).
Ignore
Select Ignore to have exceptions reported in the Output window and then continue debugging. The debugger will notify the user with a string in the Output window, and will continue debugging on the target device.
Exceptions
Displays all the exceptions, both system-generated and user-defined, if any. Select the exception you want to change and it will appear in the text boxes at the top of the dialog box.

The list in this text box shows the exception value, the exception name, and how the debugger will respond to this exception. Exceptions that do not appear in this exceptions list will be reported as unnamed exceptions and the debugger will stop for these exceptions.

OK
Saves your input and closes the dialog box.
Cancel
Closes the dialog box without saving any of the changes you have made.
Add
Select to add a new exception that you have typed in the text boxes.
Remove
Select to remove the selected exception.
Change
Select to add the changes you made to the selected exception in the exception list.
Reset
Select to return all values to what they were before you opened this dialog box.
