Export Wizard

The Export Wizard guides you through the process of collecting features from the Catalog and constructing a Microsoft Windows Installer (.msi) file.

The process of collecting features from the Catalog and constructing an .msi file with the Export Wizard includes the following steps:

  1. Selecting which features to export from the catalog.
  2. Selecting which directories or files to export.
  3. Editing the .cec and .msi file information.
