Catalog Properties Dialog Box

This dialog box displays information for the selected catalog feature. If you select a feature type (for example, drivers), you get properties about that type. If you select a specific feature implementation (for example, a ddtk30 driver), you get information about that implementation.

The information available in the Catalog Properties dialog box depends on whether it is displaying information about a feature type or a specific implementation of a feature. The icon displayed in the Catalog window for each object allows the user to tell at a glance whether the object is a feature type or a feature implementation.

You can access the following tabs from this dialog box.

  • General Tab
  • Supported CPUs Tab
  • Supported Platform Configs Tab
