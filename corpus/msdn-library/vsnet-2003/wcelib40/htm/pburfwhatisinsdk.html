What is in an SDK?

The information contained in an SDK generated by Platform Builder varies, depending on the type of SDK you create. Every SDK contains Platform Manager settings and Help based on the features included in your platform. If you create an SDK for eMbedded Visual C++ 4.0, your SDK contains header (.h) files and import libraries. If you create an SDK for the Microsoft® .NET Compact Framework Beta Release, your SDK contains profile information used by the .NET Compact Framework. This profile information specifies the device class, and determines which functionality is available to the application developers.

You can also include your own files and platform emulation in an SDK using the SDK Configuration Settings dialog box. To access this dialog box, choose Modify the SDK configuration settings from the Export SDK Wizard congratulations page.

For more information about creating an SDK and the SDK configuration settings, see Software Development Kit Customization.
