Workspace Window

When a workspace is open, the Workspace window contains information about the project in that workspace. Choose one of the following buttons on the Standard toolbar to select the view for the integrated development environment (IDE).

Button View name Description
Platform view Displays menu items, toolbars, and windows for building platforms.
Project view Displays menu items, toolbars, and windows for building projects.

The information in the Workspace window is organized on tabs. Choose the tab at the bottom of the Workspace window to see its contents.
