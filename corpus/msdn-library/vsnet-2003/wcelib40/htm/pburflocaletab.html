Locale Tab

Locales
Displays the names of valid locales you may choose. If an alternative locale is selected, it is added to the Default Language list.
Default Language
Displays the language currently chosen on the user's Windows development computer.
Codepages
Displays the list of code pages used for associating a locale with its correct Unicode implementation.
Localize the Build
Use this to choose to localize the platform during build.
Strict Localization Checking in Build
Use this to choose strict localization. Strict localization requires that all .res files are available during the makeimg.exe phase, and causes an error if the localization process fails to localize a module. Further, if a module is not localized, the build process fails to generate an OS image.
