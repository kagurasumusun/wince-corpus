Add to Source Control Dialog Box

Use this dialog box to put files under source-code control in the project associated with your project workspace. You can add files when the project workspace is created or later after the project workspace has already been created.

Files
Lists all of the files currently in your project, but not under source-code control. Select the files you want to add, or choose Select All to select all files listed.
Keep checked out
Updates the source code control database with your changes but keeps the file checked out to you.
Comment
Type a brief description about the files that you are adding.
OK
Adds the selected files to the source code control database.
Cancel
Cancels the Add command and closes the dialog box.
Select All
Selects all files listed.
