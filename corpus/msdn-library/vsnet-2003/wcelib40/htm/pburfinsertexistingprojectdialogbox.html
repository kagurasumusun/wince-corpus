Insert Existing Project Dialog Box

This dialog box enables you to add a project to an existing platform.

Look in
Select the drive or folder that contains the file you want. The contents of the drive or folder appear below in the File list.
File list
Select the file you want to insert.
File name
Select or type the name of the file you want to insert.
File of type
To display the type of file you want to open, select the file type you want from the drop-down list.
Dependency of
Select the check box to indicate that the project being added is a subproject of another project. Select the name of the parent project from the drop-down list.
Source Control
Click this button to open the project from source code control. Note that this button only appears if you are using source code control.
