CE Target Control (CESH) Dialog Box

This dialog box enables you to execute an old CESH command on the Target Device.

Command
Enter any of the following commands at the prompt:
Command, argument or example What it does
break Breaks into the debugger
s <procname> Starts new process

Note: The Process, Threads and Modules windows will not respond until <procname> has completed, nor will the Windows CE prompt be available at the command line.
gi ["proc","thrd","mod","all"]*["<pattern>"] Gets information
proc Lists all processes in the system
thrd Lists all processes with their threads
delta Lists only threads that have changes in CPU times
mod Lists all modules loaded
all Lists all of the above
Mi ["kernel", "full"] Memory information
kernel Lists kernel memory detail
full Lists full memory maps
zo ["p","m"] [index,name] [<zone>,[["on","off"][<zoneindex>]*]* Zone Options
p/m Selects whether you operate on a process or a module
index Puts the index of the procedure or module, as printed by the gi command
name Puts the name of the procedure or module, as printed by the gi command
(No specified arguments) Prints current setting with the zone names
zone Must be a number to which this procedure or module zones are to be set Prefix by 0x if this is specified in hex
on/off Specifies bits to be turned on or off relative to the current zone mask
Examples What it does
zo p 2 Prints zone names for the procedure at index 2 in the proc list
zo m 0 0x100 Sets zone for module at index 0 to 0x100
zo p 3 on 3 5 off 2 Sets bits 3&5 on, and bit 2 off for the proc[3]
win Dumps the list of windows
kp <pid> Kills process
dd <addr> [size]: Dumps a DWORD for specified process identifier
df <filename> <addr> <size>: Dumps address to file
run <filename> Runs file in batch mode

Note   The Process, Threads, and Modules windows will not respond until <procname> has completed, nor will the Windows CE prompt be available at the command line.
dis Discards all discardable memory
Execute
Select to execute the command you typed in.
Close
Select to close this dialog box.
