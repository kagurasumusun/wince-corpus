Project Settings Dialog Box

This dialog box enables you to set the compiler and linker settings as well as the output characteristics for your project.

Settings for

Select the platform or platforms for which to change the settings.

File list

Lists the files in the current project or projects. Click the plus sign (+) to display individual folders and files, and choose the minus sign (–) to collapse the display. Depending on what you select, you can set options for individual files, folders, or the entire project.

You can access the following tabs from this dialog box.

  • General Tab
  • C/C++ Tab
  • Link Tab
  • Resources Tab
  • MIDL Tab
  • Browse Info Tab
  • Custom Build Tab
  • Pre-link Step Tab
  • Post-build Step Tab
