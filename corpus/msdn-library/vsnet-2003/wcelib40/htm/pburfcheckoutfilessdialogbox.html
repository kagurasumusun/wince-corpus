Check out files Dialog Box

Checks out a copy of the selected file(s) from your source code control provider and places a writable copy in the corresponding working directory of your development environment.

Files
Lists the files available for check out. Select the files you want to check out, or choose Select All to select all files listed.
Comment
Type a brief description of the reason for the check out.
OK
Checks out the select files.
Cancel
Cancels the Check Out command and closes the dialog box.
Select All
Selects all files listed.
Advanced
Displays the Advanced Check Out Checkout dialog box.
