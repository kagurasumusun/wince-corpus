Files Tab

Files window
Click the type of file you want to create. To add the new file to an existing project when it is created, first select Add to Project, and then select the project name, and finally type a filename in the File Name box. A default location for the new file is supplied automatically, but you can change the drive and path.

To create a new file without adding it to any existing project, select a file type and click OK. A new file of the selected type is opened with a default name. You provide the filename and location when you save the new file.

Add to Project
Select the check box to add the new file to an existing project. If you have more than one existing project, press the DOWN ARROW next to the drop-down box to select the project name.
File Name
Type the name of the new document file. If you do not provide an extension, the default extension associated with the document type is appended automatically.
Location
Provides a place for you to specify the directory for the new document file. You can type a path or select one by using the browse button to the right of the Location box.
