Emulation Tab

Emulation Image
Select an emulation image to be used with the SDK from the list.
Ethernet support
Select if Ethernet support is available for the emulator.
Ports available to be configured
Select if the emulator has ports that are available to be configured.
Fixed Screen Resolution
Type the screen width in pixels, the screen height in pixels, and the screen color in color bits.
Emulator Skins
Select if emulator skins are supported. If available, add the path to the folder that contains the skin file(s).
