Step 4: Setting Up a Connection to the CEPC and Downloading the OS Image

In this step, you will set up and configure an Ethernet connection to the CEPC, and then you will download the custom OS image to the CEPC.

Before you start the following procedure, connect the development workstation and CEPC to the same subnet.

To set up a connection to the CEPC and download the OS image

  1. From the Target menu, choose Configure Remote Connection.
  2. Choose the Services tab.
  3. From the Download box under Services for active named connection, choose Ethernet.
  4. Choose Configure. Insert the boot floppy disk that you created in the previous step into the floppy disk drive of the CEPC and start the CEPC.

    After the CEPC boots, the name of the CEPC appears in the Available Devices list.

    Note   If the name of the CEPC does not appear in the Available Devices list, reboot the CEPC. If the name of the CEPC still does not appear, verify that you made the correct changes to the Autoexec.bat file on the boot floppy disk described in Step 3: Creating a Boot Floppy Disk for the CEPC. If you still have a problem, see CEPC Based SDB Recommended Hardware to troubleshoot the CEPC.
  5. From the Available Devices list, select the name of the CEPC, and then choose OK.
  6. From the Kernel Transport box, choose Ethernet.
  7. Choose the Settings tab.
  8. Under Download/Initialize Device, verify that the Connect to Device check box is selected, and then choose OK.

    You have configured the services that allow you to connect to the CEPC. You are now ready to establish a connection to the CEPC and download the OS image.

  9. From the Target menu, choose Download/Initialize.
  10. If you want the target device to have access to only the flat release folder of the OS image and its contents, in the KITL Security Warning dialog box, choose Yes.

    - or -

    If you want the target device to be unable to access any folder on the desktop, choose No; this action overrides any other custom folder settings.

    Note   For the purposes of this tutorial, choose Yes.
  11. Wait until the OS image downloads to the CEPC.

    Over an Ethernet connection, the length of time required to download an OS image depends on the size of the OS image being downloaded and the speed of the Ethernet connection. The OS image in this example may take several minutes to download. While the OS image downloads, a dialog box in the IDE displays the progress of the download.

After the OS image successfully downloads and the OS boots, the desktop for the Windows CE OS appears on the display for the CEPC. You are now ready to debug the OS.
