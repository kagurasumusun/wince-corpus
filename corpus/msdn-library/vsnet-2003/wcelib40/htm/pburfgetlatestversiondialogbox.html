Get Latest Version Dialog Box

Gets the selected files from your source code control provider and places a read-only file in the development environment project.

Files
Select the file or files you want to get.
OK
Updates the local copy of the selected files.
Cancel
Cancels the Get command and closes the dialog box.
Select All
Selects all files listed.
Advanced
Displays the Advanced Get Options dialog box.
