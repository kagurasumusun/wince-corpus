Move Tab

Copies a chunk of memory from the Start Address through the Range to the Destination. For example, if the Start Address is 0x00000000, the Range is 5 and the Destination is 0x00000006, Move would move the data in memory locations 0x00000000 - 0x00000005 to memory locations 0x00000006 - 0x0000000B.

Start Address
Enter an address in hexadecimal where you want to start a move.
Range (in bytes)
Enter the number of bytes you want to move starting from the Start Address.
Destination
Enter the address in hexadecimal of the location where you want to the move the data.
OK
Select to start a move.
Stop Move
Select to stop a move.
Close
Select to close the dialog box.
