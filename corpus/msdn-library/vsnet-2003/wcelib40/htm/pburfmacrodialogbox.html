Macro Dialog Box

This dialog box enables you to run, edit, and write new macros in VBScript to be used in Microsoft Platform Builder 3.0.

Macro Name
Select the macro you want to run or edit from the list of macros in the selected macro file, or create a new macro by typing a name for the macro in the Macro Name box.
Macro File
Displays the name of a file that contains one or more macros. Select the file containing the macro you want from the Macro name list, or create a new file by clicking the Options button, then the New File button.
Description
Explains what the selected macro does. You provide this description when you record or edit a new macro. Platform Builder puts this description at the beginning of the selected macro file.
Run
Runs the selected macro. If no macro file is selected, you can either:
  • Create a new file by clicking the Options button, then the New File button.

    - or -

  • Load an existing macro file into Platform Builder from the Add-ins and Macro Files tab in the Customize dialog box (Tools menu, Customize command).
Edit
Use Edit to change or create a macro. Click to open the selected macro in the editor. If you enter a new macro name in the Macro Name box, when you click Edit, Platform Builder creates that macro and opens it in the editor.
Record
Press to record a macro. Platform Builder displays the Add Macro dialog box in which you add a description of the macro. After adding the description, click OK to begin recording. Platform Builder appends the new macro to the end of the selected macro file and adds the description at the beginning of the file.
Close
Press to close this dialog box with saving any changes.
Help
Press to display information about this dialog box in your browser.
Options
Click to display additional macro options, such as assigning the macro to a toolbar button or key sequence, or loading the macro file into Platform Builder.
New File
Press to create a new macro file. When you click New File, you can enter the file's name and description in the New Macro File dialog box.
New Macro File Dialog Box
Name
Enter a name for the new macro.
Description
Enter a description of the new macro.
Loaded Files
Press to bring up the Add-ins and Macro Files tab of the Customize dialog box. Check the check box next to an add-in or macro file to load it and make it available. Add-ins and macro files that do not have a check mark are not loaded and are not available.
Toolbars
Press to assign a macro to a menu or toolbar button.
Keystrokes
Press to assign a macro to a key sequence.
