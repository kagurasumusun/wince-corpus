Help System Limitations

The following are some known limitations of the Help system.

  • For topics that do not appear in the table of contents, like IDE procedures and command-line procedures, the Locate button appears enabled. The Help system does not notify you that the topic is not in the table of contents.
  • If you choose the Locate button and the topic does not synchronize with the table of contents, choose the Locate button again.
  • There are some application programming interfaces (APIs) shared by the Mouse and Stylus features. These APIs appear in the table of contents under the reference node for both features. If you choose the Locate button while on one of these common APIs, the Help system locates the first instance, which might not always be the correct one.
  • In the Help menu, the links to MSDN Library Help and MSDN Online are not active.
