Bitmap Properties: General Tab

File name
The name of the file containing the bitmap resources.
Width
The image width in pixels. Type: Integer. Default: 48.
Height
The image height in pixels. Type: Integer. Default: 48.
Colors
Monochrome (2 colors), 16, or 256 colors. The current display device determines the number of colors in a bitmap.
Save compressed
Saves the image in compressed format to save space. This option is useful for large bitmaps. Only color bitmaps can be compressed. Type: Bool. Default: False.
