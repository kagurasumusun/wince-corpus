Microsoft Windows CE .NET  

Additional Files Tab

Include Subfolders
Choose Add to include subfolders in the SDK.

- or -

Choose Delete to remove subfolders from the SDK.

Source Folder
Choose Add to enter a local path name for a source file.

- or -

Browse to choose a local path name.

Target Folder
Choose Add to enter the name of a target folder in the installation directory.

- or -

Choose Delete to remove a folder from the installation directory.
