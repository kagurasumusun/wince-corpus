Workspace Tab

Docking view
Check the check boxes of the Platform Builder windows that you want to dock along the edges of the work environment. Windows that are not checked will behave like text windows within the IDE.
Display status bar
Select to display the status bar.
Display clock on status bar
Select to display the clock on the status bar.
Reload documents when opening workspace
Select to restore your document windows to the positions they last occupied in the project workspace.
Reload last workspace at startup
Select to automatically reload the last workspace you had open when Platform Builder starts.
Automatically sort window menu
Select to automatically place the most recently used windows at the top of the list on the Windows menu. Otherwise, windows are shown in the order that files were loaded.
Use screen reader compatible menus
Select to display the menu bar at the top of Platform Builder in text that is compatible with screen-reading devices and programs used by people who have impaired vision. This more traditional menu bar is not customizable.
Show recently used items on submenus
Select to list the recently used files and workspaces on submenus of the File menu. Otherwise, the recently used files and workspaces are listed on the File menu itself.
Window menu contains
Enter the number of windows that will appear on the Window menu. The default is 10 windows.
Recent file list contains
Enter the number of filenames for recently used files that will appear on the File menu (or its Recent Files submenu). The default is 4 filenames.
Recent workspace list contains
Enter the number of recently used workspaces that will appear on the File menu (or its Recent Workspaces submenu). The default is 4 workspace names.
