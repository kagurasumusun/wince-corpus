Title, Location, and Rank Columns in Search

When using Help full-text search, you can sort the topic list by selecting the Title, Location, or Rank column headings.

Title indicates the topic title. Location specifies where the topic is located within the Help documentation. The topic rankings under the Rank column are not determined by any standard, such as most hits. You can safely ignore the Rank column when trying to narrow down your search results.

The following table lists the different topic locations and their corresponding descriptions.

Location Description
Device Driver Development Topics with this location are about device driver development. If a topic with this location is included in the table of contents, you can find it under the Device Driver Development node.
Feature (Application Development) Feature indicates the name of the feature, for example, Cryptography. Topics with this location are about application development. If a topic with this location is included in the table of contents, you can find it under the Application Development node.
OS Design Guide Topics with this location include conceptual material for platform or OS development, topics on how to interact with the OS, and procedural content for creating OS elements and Catalog-selectable OS features. If a topic with this location is included in the table of contents, you can find it under the Operating System Development node.
OS Development Feature Topics with this location typically contain information about a feature's relevant registry settings, dependencies, environment variables, and implementation considerations. If a topic with this location is included in the table of contents, you can find it under the Operating System Development node.
Tools Help Topics with this location include information about the Platform Builder development tools, IDE and command-line procedures, and context-sensitive Help. If a topic with this location is included in the table of contents, you can find it under the About Platform Builder node.
Microprocessor Reference Topics with this location contain information about the various supported microprocessors. If a topic with this location is included in the table of contents, you can find it under the About Platform Builder node.
Microsoft C Run-Time Library for Windows CE .NET Topics with this location contain information about the Windows CE .NET supported functions in the full Microsoft C Run-Time Library for desktop computers. Topics with this location are found in the table of contents under the About Platform Builder node.
Glossary Topics with this location contain information found in the glossary.
