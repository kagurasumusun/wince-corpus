Bookmarks Dialog Box

This dialog box enables you to place bookmarks in your files.

Name
Enter a name in the text box to create a new bookmark at the location of your cursor in an open file, or select the name of an existing bookmark by clicking on the down arrow next to the text box.
Bookmark List
Select one of the active bookmark names to edit, delete, or go to. The file location and line number of the selected bookmark are displayed at the bottom of the dialog box.
Add
Click to add the bookmark displayed in the Name text box to the list of active bookmarks. This button is disabled if the bookmark already exists or if the Name text box is empty.
Close
Closes the dialog box, saving any changes you have made.
Delete
Click to delete the selected bookmark from the list of active bookmarks. This button is disabled until you select a bookmark.
Go To
Click to go to the selected bookmark. This button is disabled until you select a bookmark.
