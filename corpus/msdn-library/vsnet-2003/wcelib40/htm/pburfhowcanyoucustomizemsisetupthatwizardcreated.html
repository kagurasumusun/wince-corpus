How can you import features?

Features can be imported into Platform Builder using the Microsoft Windows Installer (.msi) file generated by the Export Wizard. To do this you click on the .msi file containing a feature to install that feature.

You can manually add .cec files associated with a feature to the Catalog using the Manage Catalog Features item on the File menu. However, this will not install all files associated with that feature into the correct directories, which is a function of the Export Wizard.
