Resources Tab

Reset
Choose Reset to restore all settings to their original value.
Resource File Name
Enter the name of the output (.res) file. Platform Builder assumes a path relative to the project directory.
Language
Select the natural language (such as US English, Australian English, or Mexican Spanish) used in the resource.
Additional resource include directories
Enter one or more additional directories to add to the list of directories searched for include files. Separate path names with a comma.
Ignore standard include paths
Check the check box to prevent the compiler from searching for include files in directories specified in the PATH and INCLUDE environment variables.
Preprocessor definitions
Enter one or more preprocessor macros to create.
Project options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.
