Windows Dialog Box

This dialog box enables you to make a window active, save or close a window, or have all your windows tile either horizontally or vertically.

Select Window
Select one or more currently open windows in the Select Window list. If you select a single window, you can choose Activate, Save, or Close Window(s). If you select multiple windows, you can choose Save, Close Window, Tile Vertically, or Tile Horizontally.
Activate
Click to switch to the currently selected window in the Select Window list.
OK
Processes your selection and closes the dialog box.
Save
Saves the currently selected files in the Select Window list.
Close Window(s)
Closes the window and file of each file currently selected in the Select Window list.
Tile Horizontally
Tiles the open document windows horizontally.
Tile Vertically
Tiles the open document windows vertically.
