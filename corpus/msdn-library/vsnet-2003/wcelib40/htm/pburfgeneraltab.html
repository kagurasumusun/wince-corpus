General Tab

Name
Displays the name of the Catalog feature.
Date
Displays the date the Catalog Feature was added to the catalog, if available.
Vendor
Displays the name of the object vendor, if available.
BSP Dir
Displays the directory that contains the associated BSP, if available.
Size
Displays the size of the feature file, if available.
GUID
Displays the GUID for this Catalog feature.
Description
Displays the description of the object, if available.
