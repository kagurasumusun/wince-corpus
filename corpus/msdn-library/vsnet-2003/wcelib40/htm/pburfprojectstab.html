Projects Tab

Workspace window
Choose the type of project you want to create. You must also type a project name in the Project Name box. The project will be added to your current workspace. Select the appropriate processor or processors.
Project name
Provides a place for you to type the name of the new project.
Location
Provides a place for you to specify the location of the directory for a new project. You can type a path or select one by using the Browse button to the right of the Location box.
