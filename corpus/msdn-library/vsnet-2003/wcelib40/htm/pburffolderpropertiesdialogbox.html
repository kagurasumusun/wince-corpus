Folder Properties Dialog Box

This dialog box displays information for the selected folder, which is a group of files for the project.

To create additional folders on this tab, use the New Folder Dialog Box.

Pushpin button
Click to keep this dialog box open on your desktop, on top of all other windows. Click again to cancel this feature.
Folder Name
Displays the name of folder. You may type a new name into the text box if you want to change the folder name.
File extensions
Displays file extensions that are put in this folder, separated by semicolons. Files with the listed extensions are automatically placed into this folder when they you add them to the project. You may add or remove file extensions from this text box in order to change what files are automatically placed in this folder.
