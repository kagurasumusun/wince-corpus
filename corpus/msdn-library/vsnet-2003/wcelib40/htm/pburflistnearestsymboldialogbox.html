List Nearest Symbol Dialog Box

This dialog box enables you to find function names or labels near an address in code.

Address
Enter an address in hexadecimal and press RETURN.
Results
Displays the function name or labels closest to the entered address.
OK
Select to find the symbols nearest the address you have entered.
Cancel
Closes the dialog box.
Help
Opens Help to the topic for this dialog box.
