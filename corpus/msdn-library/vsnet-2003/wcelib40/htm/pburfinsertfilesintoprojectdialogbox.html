Insert Files into Project Dialog Box

This dialog box enables you to insert an existing file into an existing project.

Look in
Select the drive or folder that contains the file you want. The contents of the drive or folder appear below in the File list.
File list
Select the file you want to open.
File name
Select or type the name of the file you want to open.
File of type
To display the type of file you want to open, select the file type you want from the drop-down list.
Insert into
Select the name of the project to which you want to add the selected file from the drop-down list.
OK
Inserts the specified file.
Cancel
Closes the dialog box without making any changes.
