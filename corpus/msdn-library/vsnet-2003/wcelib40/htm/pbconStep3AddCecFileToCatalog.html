Step 5: Adding the Feature to the Catalog

After modifying the .cec file for your feature, you can extend the Catalog to include your feature by importing the feature into the Catalog. By adding the .cec file to the Catalog, you can add the feature to a platform from within the Platform Builder IDE.

To add the feature to the Catalog

  • From the Catalog menu in the CEC Editor window, choose Add to Catalog.

You have added your feature to the Catalog.

To see the feature in the Catalog

  • In the IDE, right-click in the Catalog window, choose Refresh Catalog from the menu, and then expand the New Features folder.
