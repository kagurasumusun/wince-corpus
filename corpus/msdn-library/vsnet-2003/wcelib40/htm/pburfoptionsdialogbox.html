Options Dialog Box

This dialog box enables you to customize your Platform Builder settings. You can access the following tabs from this dialog box.

  • Editor Tab
  • Tabs Tab
  • Debug Tab
  • Compatibility Tab
  • Build Tab
  • Directories Tab
  • Verbosity Tab
  • Source Control Tab
  • Workspace Tab
  • Macros Tab
  • Format Tab
