Find in Files Dialog Box

This dialog box enables you to search in multiple files.

Find What
Type the search text or the regular expression to match. You can use the button to the right of the drop-down list to display a list of regular search expressions. When you select an expression in this list, the expression is substituted as search text in the Find What text box and the Regular Expression option is automatically checked. You can also use the drop-down list to select from a list of up to 16 previous search strings. For more information on regular expressions, search on "regular expressions" in the Index.
In files/file types
Select or type the filename extension of the type of file you want to find. You can use wildcard symbols such as the asterisk (*) and the question mark (?) in this field to match multiple files. You can also use multiple filters by separating the filters with semicolons. You can also use the drop-down list to select from a list of pre-defined filters.
In folder
Select or type the primary folder that you want to search. You can use the browse button (…) to display the Choose Directory dialog box to change drives and directories. You can also use the drop-down list to select from folders you had previously searched.
Match whole word only
Select this check box to find text strings that match the Find What string and are preceded and followed by a space, tab, or punctuation character, or at the start or end of a line. Otherwise, the search finds any matching string, including fragments of larger strings.
Match case
Select this check box to find only the text strings that exactly match the case of the characters in the Find What string. Otherwise, the command finds strings with either uppercase or lowercase characters that match the characters in the Find What string.
Regular expression
Select this check box to use regular expressions in the Find What text box.
Look in subfolders
Select this check box to extend the search to subfolders.
Output to pane 2
Select this check box to send the output of the Find in Files command to the Find in Files 2 tab of the Output window. This allows you to view the results of two Find in Files operations at the same time.
Advanced
Click to select additional folders to search. This button displays an extended dialog that allows you to add, delete, and organize folders for searching.
Look in folders for project source files
Select this check box to extend the search to folders containing source files for the project.
Look in folders for project include files
Select this check box to extend the search to folders containing include files for the project.
Look in additional folders
Provides a space for you to add additional folders for searching. To add a folder to this list, double-click the empty selection. Then type the path and filename or use the browse button (…) to display the Choose Directory dialog box to change drives and directories. To remove a folder from this list, select and delete the text entry.
