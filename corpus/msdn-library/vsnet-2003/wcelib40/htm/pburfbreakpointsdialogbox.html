Breakpoints Dialog Box

This dialog box enables you to set breakpoints for the currently open program.

Tab Description
Location Tab Choose to enter the location where you want to set a breakpoint.
Data Tab Choose to enter a variable or expression that determines whether the debugger stops at a breakpoint
Messages Tab Choose to enter a message that you want to break on.
Remove
Removes all selected items from the Breakpoints list.
Remove All
Deletes all Breakpoints currently set.
OK
Processes your input and closes the dialog box.
Cancel
Closes the dialog box without saving any of the changes you have made.
Edit Code
Takes you to a source window containing the code where the breakpoint is set.
