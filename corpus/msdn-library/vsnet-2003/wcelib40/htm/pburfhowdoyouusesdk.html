How do you use an SDK?

The software development kits (SDKs) created with Platform Builder are installed into eMbedded Visual C++ 4.0 or Visual Studio .NET. Once installed, the SDK gives an application developer access to the header files and documentation for your platform. This will allow the application developer to target applications for your specific device.

For more information regarding using an SDK, see the documentation included with your development software.
