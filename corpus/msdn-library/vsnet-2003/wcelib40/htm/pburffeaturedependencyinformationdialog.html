Feature Dependency Information Dialog Box

This dialog box shows the features upon which the selected feature is dependent. The dialog box also shows the features that are dependent upon the selected feature.

Property
Shows properties for the feature selected in the left pane of the dialog box.
Value
Shows values for the properties of the feature selected in the left pane of the dialog box.
