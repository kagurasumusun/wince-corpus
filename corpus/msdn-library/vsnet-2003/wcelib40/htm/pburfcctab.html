General category

Warning Level
Select the severity of warning for which the compiler generates messages.
Optimizations
Select an optimization category. Default, Disable, Maximize Speed, and Minimize Size are pre-determined. Selecting Customize allows you to select individual optimizations. To specify a custom set of optimizations, select Optimizations in the Category list on the C/C++ tab.
Warnings as errors
Check to emit warning messages as error messages.
Generate Browse Info
Check to generate intermediary browse (.sbr) files when you build your program. To create the .bsc file required for browsing, select the Build Browse Info File check box on the Browse Info tab.
Debug info
Specifies the type of debugging information generated by the compiler. You must also change linker settings appropriately, depending on the option you specify here. These options correspond to the following compiler switches: Line Numbers Only = /Zd; Program Database = /Zi.
Preprocessor definitions
Enter the name or names of one or more preprocessor macros to create.
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

C++ Language category

Representation Method
Select the method used by the compiler to represent pointers to class members. If you select General-Purpose Always you must also select a value in the General Purpose Representation drop-down box below.
General-purpose representation
When the representation method is General-Purpose Always, you must also select the inheritance model of classes to use from this drop-down list. Note that General-purpose representation is unavailable if the Representation Method is Best-Case Always.
Disable construction displacements
Check to suppress the vtordisp constructor/destructor displacement member, if you are certain that all class constructors and destructors call virtual functions virtually.
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

Code Generation category

Processor
Struct member alignment
Specify whether the members of a structure are packed into memory on the smaller of the size of the member type or on 1-, 2-, 4-, 8-, or 16-byte boundaries.
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

Customize Category

Disable language extensions
Check if you want the compiler to use ANSI C rules. Clear the check box, if you want to use Microsoft C language extensions.
Enable function-level linking
Check to order or exclude individual functions in a dynamic-link library (DLL) or executable file.
Eliminate duplicate strings
Check to place a single copy of identical strings into the executable file. This feature is also called string pooling and is equivalent to setting the /Gf compiler switch.
Suppress startup banner and information messages
Check to suppress display of the sign-on banner and informational messages.
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

Listing Files category

Generate Browse info
Check generate intermediary browse (.sbr) files when you build your program. To create the .bsc file required for browsing, check the Build Browse Info File check box on the Browse Info tab.
Intermediate browse info file destination
Type to specify a different file name or directory for the .sbr and .bsc files generated by selecting the Generate Browse Info option. Note that this text box is only available if you have checked Generate Browse Information.
Exclude local variables from browse info
Check to generate browse information files containing complete symbolic information, without information on local variables that you can examine in browse windows. Note that this checkbox is only available if you have checked Generate Browse Information.
Listing file type
Select the type of listing file you want to generate. If you do not want to generate a listing file, select No Listing.
Listing file name
Type to specify a different file name or directory for the listing file selected from the Listing File Type list box. Note that this text box is not available if you have selected a Listing file type of No Listing.
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

Optimizations category

Optimizations
Select an optimization category. Default, Disable, Maximize Speed, and Minimize Size are predetermined. Selecting Customize allows you to select the check box for the options you want in the list box below.
Inline file expansion
Select the type of function that you suggest for the compiler to expand inline.
Project Options
Shows the currently selected switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

Precompiled Headers category

Not using precompiled headers
Select this option to disable precompiled header files.
Automatic use of precompiled headers
Select this option to create and use precompiled header files using the Automatic Use of Precompiled Headers system.
Through header
Type the name of a header file (.h) that is included in the selected source file. If a precompiled header (.pch) file exists and matches the source code up to, and including, this header, then the compiler uses that PCH. Otherwise, the .pch file is replaced with one that matches the source code up to, and including, this header. Note that this text box is only available if you have selected Automatic use of precompiled headers.
Create precompiled header file (.pch)
Select this option to create a precompiled header (.pch) file. Select the Use precompiled header file (.pch) option to use the .pch file that you created.
Through header
Type the name of a header file (.h) included in the selected source file. The compiler creates a precompiled header (PCH) from the source code up to and including this header. Other source files in this project can use this precompiled header. Note that this text box is only available if you have selected Create precompiled header file.
Use precompiled header file (.pch)
Select this option to use a precompiled header file (PCH).
Through Header
Type the name of a header file (.h) included in the selected source file. The compiler ignores the source code up to, and including, this header and uses the contents of the precompiled header (PCH) instead. If no PCH exists, then an error occurs. Note that this text box is only available if you have selected Use precompiled header file.
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.

Preprocessor category

Preprocessor definitions
Enter the name or names of one or more preprocessor macros to create.
Undefine all symbols
Select this option to specify that every previously defined macro is undefined.
Undefined symbols
Enter the name of a macro to undefine.
Additional include directories
Provides a place for you to add one or more directories to the list of directories searched for header files. Separate directory names with a comma.
Ignore standard include paths
Check to prevent the compiler from searching for header files in directories specified in the PATH and INCLUDE environment variables.
Project Options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.
