CEC Editor Tool

The Platform Builder CEC Editor is a tool that allows you to quickly create and edit .cec files. The CEC Editor is accessed from the Tools menu.

The left side of the CEC Editor window displays the individual Catalog items from the .cec file that are being edited. These items are listed in the order that they appear when the .cec file is imported into the Catalog.

The properties for each Catalog object can be viewed on the right side of the window by selecting a feature. The Properties window will display the appropriate information for the item selected. From the Properties window, you can perform such tasks as editing the name and description of the feature being created as well as creating a new GUID.

In the CEC Editor window or in dialog boxes opened from the CEC Editor, if a field is flagged with an asterisk (*), the field is a required field.

For more information about the creation and modification of .cec files, see Catalog Feature Files.
