Step 6: Localizing the OS Image for the CEPC

Windows CE offers you the ability to localize an OS image into several foreign languages. In this step, you will localize the custom Web Pad OS image into German for the locale of Germany.

To localize the OS image for the CEPC

  1. From the Platform menu in the IDE, choose Settings.
  2. In the Settings For box, verify that CEPC-X86 Win32 (WCE x86) Debug is selected.
  3. Choose the Locale tab.
  4. From the Default Language box, choose German (Germany).
  5. In the Locales list, verify that all languages selected are cleared.
  6. Choose OK to close the Platform Settings dialog box.
  7. From the Build menu, choose Build Platform.

    During the build, a dialog box appears, warning you about the inclusion of the .NET Compact Framework Beta Release in your platform.

  8. Choose OK to acknowledge this message.

    It may take as long as twenty minutes to build the OS image. When the build is complete, you will see the following message: 0 error(s), XX warning(s).

  9. Reboot the CEPC.
  10. From the Target menu, choose Download/Initialize.
  11. In the KITL Security Warning dialog box, choose Yes.

After the localized OS image downloads to the CEPC, you are ready to create and build an application.
