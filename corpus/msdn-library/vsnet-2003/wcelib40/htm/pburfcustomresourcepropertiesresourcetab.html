Custom Resource Properties: Resource Tab

ID
A symbol defined in the header file. Type: Symbol, Integer, or Quoted String.
Language
Contains the language used for this resource.
Condition
Determines the inclusion of the resource. For example, if the condition were _DEBUG, this resource would be included only in debug builds.
File name
The name of the file containing the resource.
Preview
A box showing what the bitmap looks like. It is useful for browsing through graphics resources without opening them.
External file
If selected, the resource contents are stored in an external file listed in the File Name box. Type: Bool. Default: True.
