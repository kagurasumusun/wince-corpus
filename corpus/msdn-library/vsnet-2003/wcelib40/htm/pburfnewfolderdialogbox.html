New Folder Dialog Box

This dialog box enables you to create a new folder on the FileView tab. Note that you must be in Project view, have a project open, and then select a folder on the FileView tab for this menu item to be active. The new folder that you create will be a subfolder of the folder you have selected on the FileView tab.

Name of the new folder
Enter the name you want to appear in the new folder.
File extensions
Enter the extensions for the files to be stored in the new folder, separated by semi colons, for example: ico; bmp; gif; jpeg
OK
Select to add the new folder you just named, and close the dialog box.
Cancel
Select to close the dialog box without making any changes.
