Add/Edit Transport Dialog Box

Name
Type the display name of the transport you want to add.
Host-side file
Type the path and file name for the host-side transport .dll file.

- or -

Browse to select the path and .dll file for host-side transport.

Target-side files
Select the CPU and .dll file name for target-side transport.

- or -

Browse to select the path and .dll file for target-side transport.

GUID
Type the GUID number for the transport mechanism.
