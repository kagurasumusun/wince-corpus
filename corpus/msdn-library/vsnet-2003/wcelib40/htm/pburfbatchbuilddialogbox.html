Batch Build Dialog Box

If you have more than one configuration, this dialog box enables you to set up consecutive builds of more than one configuration.

Project Configurations
Lists the configurations of the open project. Note that the Project Configurations list appears only if you are in Project view.
Platform Configurations
Lists the configurations of the open platform. Note that Platform Configurations list appears only if you are in Platform view.
Build
Builds the specified configuration or configurations. Equivalent to the /MAKE option in a command-line build.
Rebuild All
Cleans and builds the specified configuration or configurations, including all dependent projects. Equivalent to the /REBUILD option in a command-line build.
Clean
Deletes all intermediate and output files created during the build process for the specified configuration or configurations. Does not build the platform or project. Equivalent to the /CLEAN option in a command-line build.
Cancel
Closes the dialog box without making any changes.
Selection only
Builds the specified project or platform configuration or configurations without building any dependent projects. This is equivalent to the /NORECURSE option in a command-line build.
