Build Tab

Write Build Log
Select to write a text log of the build, named activeprojectname.plg, to the active project directory.
Enable Deptree Build
Select the Enable Deptree Build check box to build the private/public tree. This is the same as using the command line: 
cebuild -c

Clear the Enable Deptree Build check box to skip the private/public tree build. This is the same as using the command line: 

cebuild -q -c
