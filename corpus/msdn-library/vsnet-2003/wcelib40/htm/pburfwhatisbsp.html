What is a BSP?

A board support package (BSP) is the software that implements the device drivers for a standard development board (SDB). A BSP contains source files, binary files, or both. You can use a BSP to rapidly bring up an operating system (OS) on an SDB and evaluate the features of the OS.

A BSP contains an OEM Adaptation Layer (OAL), which includes a boot loader for initializing and customizing your hardware, device drivers, and a corresponding set of configuration files. By editing a header (.h) file, .cec file, and so on, you can configure the BSP to select desired peripherals, OS features, file systems, and memory types.

For a more detailed explanation about BSPs, see Board Support Packages.
