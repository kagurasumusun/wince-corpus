Find Dialog Box

This dialog box enables you to search in the currently selected open file or files.

Find What
Type the search text or the regular expression to match. You can use the right-arrow button to the right of the drop-down list to display a list of regular search expressions. When you select an expression in this list, the expression is substituted as search text in the Find What text box and the Regular Expression option is automatically checked. You can also use the drop-down list to select from a list of up to 16 previous search strings.
Match whole word only
Select this check box to find text strings that match the Find What string and are preceded and followed by a space, tab, or punctuation character, or at the start or end of a line. Otherwise, the search finds any matching string including fragments of larger strings.
Match case
Select this check box to find only the text strings that exactly match the case of the characters in the Find What string. Otherwise, the command finds strings with either uppercase or lowercase characters that match the characters in the Find What string.
Regular expression
Select this check box to use regular expressions in the Find What text box. A regular expression is a search string that uses special characters to match a text pattern in a file.
Search all open documents
Select to search in all documents currently open.
Direction
Select Up to search from the current cursor position to the beginning of the file, and then from the end of the file back to the current cursor position.

Select Down to search from the current cursor position to the end of the file, and then from the beginning of the file back to the current cursor position.

Find Now
Begins the find operation specified by the values displayed in this dialog box.
Mark all
Click to place a bookmark on all instances of the word or expression in the Find What box.
Cancel
Click to close this dialog box.
