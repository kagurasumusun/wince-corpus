License Binary Image Dialog Box

This dialog box enables you to license a binary image you have made by stamping the image file (for example, nk.bin) with a product identifier (PID).

Select Binary
Enter the path to the binary file you wish to license.
Browse
Browse to the location of the binary file you wish to license.
License Key (25 digits)
Enter the license key. For information about how to obtain a license key, go to this Microsoft Web site.
Stamp Binary
Select to license the binary file you selected using the license key you entered.
Close
Close the dialog box without making any changes.
