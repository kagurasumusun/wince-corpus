Insert Resource Dialog Box

This dialog box enables you to import or create a new custom resource.

Resource type
Select the type of resource you want to make or import.
New
Click to create the selected resource and begin editing. The resource opens inside the appropriate editor, in the right-hand pane of the workspace. For example, creating a new dialog resource opens it inside the dialog editor.
Import
Click to import an existing resource file from another location to to your open project.
Custom
Click to add a new custom resource to the current resource file. Custom resources can be edited in the binary editor only.
Cancel
Click to close this dialog box without saving any of the changes you have made.
