Environment Tab

Note that some environment variables correspond to settings on the General tab. Changing these variables on the Environment tab will change the corresponding settings on the General tab. These correspondences are documented on the Platform Settings General Tab.

Environment Variable
An environment variable contains information used by the build engine during the platform build process. To add a variable or modify a value, see Variable or Value. To delete a variable, select one that you want to delete, and then choose Delete.
Variable
Type the variable name in the Variable box. You can also enter a value. Choose Set to add the new variable to the Environment Variables list.
Value
Select one of the current environment variables, type a value in the Value box, and then choose Set.
