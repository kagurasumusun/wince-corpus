Custom Build Tab

Build Step
Select one of the following build steps:
Build Step Does this
Feature Build Builds your platform
Release Copy Copies your platform to the _FLATRELEASEDIR directory
Make Image Creates a downloadable image of your platform
Settings for this build step
Click the New button to open the New Build Setting dialog box, in order to enter settings for this build step. Click the Delete button to remove a setting. Note that Settings for this build step is not available if you have selected the Release Copy build step.
Variable
Displays the currently selected variable. You may change the variable in this text box. Note that Variable is available only if you have selected a setting in the Settings for this build step list.
Value
Displays the value of the currently selected variable, if any. You may enter or change the value in this text box. Note that Value is available only if you have selected a setting in the Settings for this build step list.
Set
Select Set to apply and save changes you made to the Variable and Value fields. You must press Set in order to save changes when you press OK. Note that Set is active only if you have selected a setting in the Settings for this build step list.
New Build Setting dialog box
Variable
Enter a name for the new variable.
Value
Enter a value for the new variable.
Actions for this build step
Click the New button to enter actions for this build step. Use the Move Item Up and Move Item Down arrows to change the order of items. Use the Delete button to remove an action. Note that Actions for this build step is not available if you have selected the Make Image build step.
File
Enter the file where this command is stored, or select the Browse button to browse to the file. Note that File is available only if you have selected a #BUILD action in the Action for this build step list.
Path in which to start command
Enter the path from which to start executing your command or select the Browse button to browse to the path. Note that Path in which to start command is available only if you have selected #CUSTOM action in the Action for this build step list.
Full path to command
Enter the full path, including the executable filename command or select the Browse button to browse to the full path. Note that Full Path to command is available only if you have selected #CUSTOM action in the Action for this build step list.
Source
Enter the path to the source file you want to copy, or select the Browse button to browse to the file. Note that Source is available only if you have selected the Release Copy build step and then selected a #COPY action in the Action for this build step list.
Destination
Enter the path to the directory where you want to put the copy you are making, or select the Browse button to browse to where you want to put the copy. Note that Destination is available only if you have selected the Release Copy build step and then selected a #COPY action in the Action for this build step list.
New Build Action dialog box
Action
Select an action from the Action dropdown list. Note that File Copy is only available if you have chosen the Release Copy build step.
Action you select You must also enter the
Build Dirs/Sources Path to the Dirs or Source file
Build PBP Path to the PBP file
Build Makefile Path to the Makefile
File Copy Path to the Source and Destination file
Custom Command Command to execute and the directory where the command will be executed
File
Enter the path to the file from which to start executing your command or select the Browse button to browse to the file. Note that File is not available if you have selected Custom Command.
Path in which to start command
Enter the path from which to start executing your command or select the Browse button to browse to the path. Note that Path in which to start command is available only if you have selected Custom Command.
Full path to command
Enter the full path, including the executable filename command or select the Browse button to browse to the full path. Note that Full Path to command is available only if you have selected Custom Command.
Source
Enter the path to the source file you want to copy, or select the Browse button to browse to the file. Note that Source is available only if you have selected the Release Copy build step and then selected File Copy.
Destination
Enter the path to the directory where you want to put the copy you are making, or select the Browse button to browse to where you want to put the copy. Note that Destination is available only if you have selected the Release Copy build step and then selected File Copy.
