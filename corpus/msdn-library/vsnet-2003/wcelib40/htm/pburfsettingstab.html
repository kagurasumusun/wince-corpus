Settings Tab

Download / Initialize Device
These options determine which actions occur when you select Download Image / Initialize Device or Reset from the Target menu.
Download Image
Select this check box to have the latest OS image downloaded.
Initialize (Jump to Image)
Select this check box to jump to the OS image that has previously been downloaded to the Target Device
Connect to device
Select this check box to connect to the Target Device before downloading or initializing.
Reset
These options determine which actions occur when you select Reset Device from the Target menu.
Download always
Select this check box to download the latest OS image whenever the target device is reset
Download if image changed
Select this check box to download the latest OS image only if it differs from the relative source file(s).
Jump to image only
Select this check box to prevent the OS image from being downloaded when the target device is reset.
Force clean
Select this check box to perform a "cold boot" when the target device is reset.
Target Output Messages
Timestamps
Select this check box to display a time stamp for the target messages on the Debug tab of the Output Window.
Process IDs
Select this check box to display process Ids for the target messages on the Debug tab of the Output Window.
Thread IDs
Select this check box to display thread identifiers for the target messages on the Debug tab of the Output Window.
Send Output to file:
Specify the file and location to which logging should be saved to.
