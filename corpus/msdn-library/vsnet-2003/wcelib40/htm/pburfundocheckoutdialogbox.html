Undo Check Out Dialog Box

Overwrites your changes to a file, and copies the latest checked in version to the working directory of your development environment.

Files
Lists the currently checked out files. Select the files for which you want to undo checkout, or choose Select All to select all files listed.
OK
Cancels the check out of the selected files.
Cancel
Cancels the Undo command and closes the dialog box.
Select All
Selects all files listed.
Advanced
Displays the Undo Check Out Advanced options.
