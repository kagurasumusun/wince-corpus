Browse Info Tab

Reset
Choose Reset to restore all settings to their original value.
Browse info file name
Type the name of the browse information file that is created when you build this project. It must have the file extension .bsc.
Build browse info file
Select this check box to build a browse information file (.bsc) each time you build a program. Make sure the Generate Browse Information check box on the appropriate language tab is selected also, so that for each source file, the compiler generates .sbr files used to create the browse information file.
Suppress startup banner
Select this check box to suppress the display of the startup banner.
Project options
Shows the switches that the tool uses to build. If a project node is selected in the Settings tree, you can type into this field to add or remove switches.
