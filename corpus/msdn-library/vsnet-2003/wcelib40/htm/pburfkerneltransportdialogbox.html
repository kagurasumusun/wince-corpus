Kernel Transport Dialog Box

When you choose the Configure button on the Services Tab after selecting a kernel transport that requires configuration, Platform Manager displays a dialog box in which you can configure the kernel transport. Depending on the kernel transport selected, Platform Manager displays one of the following dialog boxes:

  • Configure Ethernet Kernel Transport
  • Configure Serial Kernel Transport

Configure Ethernet Kernel Transport

This dialog box allows you to specify settings for the Ethernet kernel transport.

Selected Device
Specifies the name of the target device with which to establish a kernel-level connection.
OK
Validates and saves the settings for the Ethernet kernel transport, and then returns to the Services Tab dialog box.
Cancel
Cancels any changes you made to the settings for the Ethernet kernel transport and closes the dialog box without saving any of the changes.

Configure Serial Kernel Transport

This dialog box allows you to specify settings for the serial kernel transport.

Port
Displays the port to use for serial communication.
Baud Rate
Displays the baud rate for the serial connection.
Flow Control
Specifies whether you want to use hardware for flow control.
Data Bits
Specifies the number of data bits.
Parity
Specifies the parity of the serial connection, if any.
Stop Bits
Specifies the number of stop bits.
OK
Validates and saves the settings for the serial kernel transport, and then returns to the Services Tab dialog box.
Cancel
Cancels any changes you made to the settings for the serial kernel transport and closes the dialog box without saving any of the changes.
