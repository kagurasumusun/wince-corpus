Breakpoint Selection Dialog Box

This dialog box allows you to specify whether you would like to set a hardware or software breakpoint.

Note   When choosing an option other than Default, the breakpoint will not be instantiated if the requested breakpoint type is not available.
Hardware
Sets a hardware breakpoint.
Software
Sets a software breakpoint.
Default
This option allows the debugger to instantiate the appropriate breakpoint type depending on the availability of system resources.
OK
Processes your input and moves to the next step.
Cancel
Closes the dialog box without saving any of the changes you have made.
