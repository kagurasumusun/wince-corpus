Directories Tab

Processor
Specifies the processor, from the list of installed processors, for which the selected directories will apply.
Show directories for
Select the type of directories displayed in the Directories list box. You may select from Executable files, Include files, Library files or Source files.
Directories
This list box contains a list of directories in which to find project files, in hierarchical search order. Click the New button to add directories from which to locate additional files for your project. Select a directory and use the Move item up and Move item down arrows to change the hierarchy of the list or the Delete button to remove the selected directory.
