New SHx Assembler Registers

When SH-4 support is enabled, SHASM recognizes new registers in addition to those available on the SH-3 and SH-3e.

The following table shows the new registers recognized by SHASM.

Registers Description
DR0/2/4/6/8/10/12/14 Double-precision floating-point
FV0/4/8/12 Single-precision floating-point vectors
XD0/2/4/6/8/10/12/14 Double-precision floating-point extended registers
XMTRX Single-precision floating-point extended register matrix
SGR Saved General Register 15
DBR Debug Vector Base Register
