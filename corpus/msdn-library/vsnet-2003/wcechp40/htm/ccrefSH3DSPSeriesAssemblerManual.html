SH3-DSP Calling Sequence Specifications

The calling sequence specification for SH3-DSP is the same as the calling sequence specification for the SH-3. Use volatile and nonvolatile registers for DSP instructions in the same way that the SH-3 Calling Sequence Specification defines register use.

The specification mandates that the program shall not modify the SR.DSP bit. The OS uses this bit to determine when it should save the DSP context or restore it on the thread context switch. The OS preserves these values across API calls.
