SH3-DSP Data Formats

The SH3-DSP has several different data formats that depend on the instruction. Valid data lengths of the data formats depend on the instruction and the DSP register.

The following list shows data formats for DSP-type instructions:

  • Fixed-point data format has the binary point between bit 31 and bit 30.
  • Integer format has the binary point between bit 16 and bit 15.
  • Logical format does not have a binary point.
