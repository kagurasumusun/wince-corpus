SHx Series Assembler

The SHx Series Assembler (SHASM) converts source programs written in assembly language into a format that can be handled by SH microprocessors, outputting the result as an object module and as an assembler listing. SHASM generates output in Microsoft Common Object File Format (COFF).

SHASM contains numerous enhancements designed to enhance the programming environment and to address compatibility issues. While SHASM closely resembles the Hitachi native assembler, it is not identical. For example, SHASM generates error and warning messages that contain not only an error number but also a descriptive message.
