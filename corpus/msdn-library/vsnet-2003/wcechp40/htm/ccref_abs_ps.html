Microsoft Windows CE .NET  

_abs_ps

This function calculates the absolute value of the upper and lower halves of a paired single independently.

double __cdecl _abs_ps(
  arg1
);

Parameters

arg1
[in] Paired single number.

Return Values

A floating-point double formed from the absolute value of the lower half of arg1 and the absolute value of the upper half of arg1.

Remarks

The compiler translates this function into the ABS.format assembly instruction.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mipsintr.h.
