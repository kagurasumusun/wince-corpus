Run-time Efficiency

Using the iwcall or iw16 declspecs will always result in faster code for interworking calls when compared to a linker-generated thunking routine. The declspecs add only a single MOV instruction to the execution path. The linker-generated thunking routine adds two instructions, a load from memory, and a branch.
