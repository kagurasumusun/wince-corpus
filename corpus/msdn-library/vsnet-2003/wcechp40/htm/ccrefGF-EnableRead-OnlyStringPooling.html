/GF - Enable Read-Only String Pooling

This option enables the compiler to place a single copy of identical strings into the executable file. Because identical strings are copied into a single memory location, programs compiled with the /GF option can be smaller than programs compiled without /GF. This space optimization is also known as string pooling. /GF does not guarantee string pooling in all cases.
