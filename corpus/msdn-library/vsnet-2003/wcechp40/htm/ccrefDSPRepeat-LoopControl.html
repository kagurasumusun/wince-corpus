DSP Repeat-Loop Control

The SH3-DSP repeat-loop control function is a special utility for controlling repetition efficiently. It executes the SETRC instruction to hold a repeat count in RC, the repeat counter, and to set an execution mode in which the repeat-loop program continues until the RC is 1. On completion of the repeat operation, the content of the RC becomes 0.

The repeat start register, RS, holds the start address of the repeated section. The repeat end register, RE, holds the ending address of the repeated section. The repeat counter, RC, holds the repeat count.

The following steps show the procedure for executing repeat control.

  1. Set the repeat start address in the RS register.
  2. Set the repeat end address in the RE register.
  3. Set the repeat count in the RC counter.
  4. Execute the repeated program loop.

The following instructions execute step 1 and step 2.

LDRS @(disp,PC);
LDRE @(disp,PC);

The repeat-loop control uses the SETRC instruction to execute steps 3 and 4. It may use immediate data or a general register to specify the repeat count as the operand of the SETRC instruction. The following instructions show how to specify a repeat counter.

SETRC #imm  ; #imm     > Rc,   enable repeat control
SETRC Rm       ; Rm         > Rc,   enable repeat control

#imm is eight bits and the RC counter is 12 bits, so to set the RC counter to a value of 256 or greater using the Rm register. The following sample shows how to do this.

     LDRS     RptStart;
     LDRE     RptEnd;
     SETRC     #imm;     RC=#imm
     instr0;

; instr1~5 executes repeatedly

RptStart:     instrl;
     instr2;
     instr3;
     instr4;
RptEnd:     instr5;
            instr6;

There are several restrictions on repeat control:

  1. At least one instruction must come between the SETRC instruction and the first instruction of the repeat program loop.
  2. Execute the SETRC instruction after executing the LDRS and LDRE instructions.
  3. When there are more than four instructions for the repeat program and there is no repeat start address at the long word boundary, one cycle stall awaiting execution is required for each repeat.
  4. The following instructions cannot be used when there are three or fewer instructions in the loop. .
    • Branch instructions such as BRA, BSR, BT, BF, BT/S, BF/S, BSRF, RTS, BRAF, RTE, JSR, and JMP
    • Repeat control instructions such as SETRC, LDRS, LDRE
    • Load instructions such as SR, RS, and RE
    • TRAPA instructions

    If such an instruction is used, illegal instruction exception handling starts and the address values are stored in SPC.

    The following table shows the PC values address stored in SPC.

    Conditions Position Address Stored in SPC
    RC>=2 Any RptStart
    RC=1 Any Program address of illegal instruction
  5. If there are four or fewer instructions in the loop, the following instructions cannot be used for the last three instructions in the loop
    • Branch instructions such as BRA, BSR, BT, BF, BT/S, BF/S, BSRF, RTS, BRAF, RTE, JSR, JMP
    • Repeat control instructions such as SETRC, LDRS, and LDRE
    • Load instructions such as SR, RS, and RE
    • TRAPA

    If such an instruction is used, illegal instruction exception handling starts and the address values shown in the following table are stored in SPC. Repeat control instructions such as SETRC, LDRS, and LDRE, and load instructions such as SR, RS, and RE, cannot be described in positions other than the repeat module.

    The following table shows the PC value addresses stored in SPC

    When there are three or fewer instructions in the loop, PC relative instructions such as MOVA (disp,PC), R0, or the like, can only be used at instr1.

    If there are four or more instructions in the loop, PC relative instructions such as MOVA (disp,PC), R0, or the like, cannot be used in the final two instructions.

  6. The SH3-DSP does not have a repeat valid flag; repeats become invalid when the RC counter becomes zero. When the RC counter is not zero and the PC counter matches the RE register contents, repeating begins. When the RC counter is set to zero, the repeat program is invalid but the loop executes once, and does not return to the loop start instruction. When the RC counter is 1, the repeat module executes only once. Though it does not return to the repeat program start instruction, the RC counter becomes zero when the repeat module executes.

    If there are four or more instructions in the loop, the branched instructions including the subroutine call back and return instructions cannot be used for the inst3 through inst5 instructions as branch destination address. If inst3 and inst5 execute, the repeat control does not work correctly. If a repeating portion of a program contains three or more instructions, and if the branching destination is RptStart or an address ahead of it, then repeat control does not work properly and the content of RC in the SR register is not updated.

  7. While the repeat executes, the SH3-DSP restricts interruption and permits no TLB instruction or data misses.

The following example shows a repeat sequence that contains one repeat instruction.

                LDRS RptStart0+8;
                LDRE RptStart0+4;
                SETRC RptCount;
                ---
RptStart0:  instr0;
RtpStart:     instr1; Repeat instruction
                instr2;

The following example shows a repeat sequence that contains three repeat instructions.

                LDRS RptStart0+4;
                LDRE RptStart0+4;
                SETRC RptCount;
                ---
RptStart0:    instr0;
RtpStart:    instr1; Repeat instruction
                instr2; Repeat instruction
RptEnd:        instr3; Repeat instruction
                instr4;
