Hitachi-specific Options

The following table shows compiler options for Hitachi microprocessors.

Option Description
-Qdsp Specifies compilation for the Hitachi SH3-DSP microprocessor.
-Qfast, -Qfastd, -Qfast - Provide Backward Compatibility Provides backward compatibility.
-Qsh3 Specifies compilation for the Hitachi SH-3 microprocessor, with no additional DSP instructions.
-Qsh4 Specifies compilation for the Hitachi SH-4 microprocessor.
