HCRYPTKEY

This data type represents handles to cryptographic keys. These handles indicate to the cryptographic service provider (CSP) module which key is used in a specific operation. The CSP module does not allow direct access to the key values. Instead, the user manipulates the key value through the key handle.

HCRYPTKEY is defined in the Wincrypt.h header file as follows.

typedef unsigned long HCRYPTKEY;

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 or later Wincrypt.h
