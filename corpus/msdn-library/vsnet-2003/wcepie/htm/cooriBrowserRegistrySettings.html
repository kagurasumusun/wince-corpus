Browser Registry Settings

Base registry settings for the Pocket Internet Explorer browser are stored in the HKEY_CURRENT_USER\Software\Apps\PocketIE key. The following table shows some of the settings that are available. The actual registry values for a particular platform are set by the device manufacturer.

Value : type Description
StartPage : REG_SZ The URL for the default homepage, specified by LOC_STARTPAGE.
SearchPage : REG_SZ The URL for the default browser search page, specified by LOC_SEARCHPAGE.
SearchURL : REG_SZ The default Search URL, specified by LOC_SEARCHURL.
UseProxy : REG_DWORD If value is set to 1, this value tells the browser to access the Internet through proxy server.
ProxyServer : REG_SZ Set to name of proxy server.
ProxyHttpPort : REG_DWORD Default setting is 80. Set to HTTP port number.

The following table shows the default settings in the HKEY_CLASSES_ROOT key, which defines how different types of files are handled.

[Subkey]Value : type Description
htmlfile : REG_SZ Stores HTML file registry values.The default is LOC_HTMLDOCUMENT.
\htmlfile\DefaultIcon : REG_SZ Default setting is "iexplore.exe, -1003".
\htmlfile\Shell\Open\Command : REG_SZ Default setting is "iexplore.exe file:%1".
gifimage : REG_SZ Default setting is LOC_GIFIMAGE. Stores GIF registry values.
\gifimage\DefaultIcon Default setting is "iexplore.exe,-1005".
\gifimage\Shell\Open\Command : REG_SZ Default setting is "iexplore.exe file:%1".
jpegimage : REG_SZ Default setting is LOC_JPEGIMAGE. Stores JPEG registry values.
\jpegimage\DefaultIcon Default setting is "iexplore.exe,-1004".
\jpegifimage\Shell\Open\Command : REG_SZ Default setting is "iexplore.exe file:%1".
urlfile : REG_SZ Default setting is LOC_URLLOCATION. Stores URL file registry values.
\urlfile\DefaultIcon Default setting is "iexplore.exe,-1002".
\urlfile\Shell\Open\Command : REG_SZ Default setting is "iexplore.exe -u:%1".
bmpimage: REG_SZ Default setting is LOC_BMPIMAGE.Stores GIF registry values.
\bmpimage\DefaultIcon Default setting is "iexplore.exe,-1005".
\bmpimage\Shell\Open\Command : REG_SZ Default setting is "iexplore.exe file:%1".
http : REG_SZ The value "URL:HyperText Transfer Protocol" specifies URL protocol.
\http\DefaultIcon : REG_SZ Default setting is "iexplore.exe,-1003".
\http\Shell\Open\Command : REG_SZ Default setting is "iexplore.exe:%1".
https : REG_SZ The value "URL:HyperText Transfer Protocol" specifies URL protocol.
\https\DefaultIcon : REG_SZ Default setting is "iexplore.exe,-1003".
\https\Shell\Open\Command : REG_SZ Default setting is "iexplore.exe:%1".
fttp : REG_SZ The value "URL:FileTransfer Protocol" specifies FTP protocol.
\ftp\DefaultIcon : REG_SZ Default setting is "iexplore.exe,-1003".
\ftp\Shell\Open\Command : REG_SZ Default setting is "iexplore.exe:%1".
