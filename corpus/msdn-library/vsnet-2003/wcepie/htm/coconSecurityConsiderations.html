Pocket Internet Explorer Security

Pocket Internet Explorer supports Secure Socket Layers SSL2 and SSL3, and Server Gated Cryptography (SGC).

Best Practices

Use authentication

If your platform supports NTLM authentication, use this mechanism to limit access to known users.

Use Secure Sockets Layer (SSL)

SSL protocol protects data from packet sniffing by anyone with physical access to the network. For more information, see SSL Support.

Ports

The following table shows the ports that Pocket Internet Explorer uses by default. A user can also specify a port in a URL, using the format <protocol>://<host>:<port-number>[<path>]. If the specified port is available at the server, it will be used in place of the default.

Protocol Default Port Number
FTP 21
HTTP 80
HTTPS 443

Default Registry Settings

Some of the registry settings for Pocket Internet Explorer may have security implications. In the registry settings documentation you will find a Security Note for those values where such a security issue exists.

For information about default registry settings, see Pocket Internet Explorer Registry Settings.
