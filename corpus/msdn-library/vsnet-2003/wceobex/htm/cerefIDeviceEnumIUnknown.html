IDeviceEnum:IUnknown

This interface is used to enumerate device elements in a sequence.

The following table shows the methods of this interface.

Method Description
IDeviceEnum::Next Retrieves the next element in the enumeration sequence.
IDeviceEnum::Skip Skips over the specified number of elements in the enumeration sequence.
IDeviceEnum::Reset Resets the enumeration sequence to the beginning.
