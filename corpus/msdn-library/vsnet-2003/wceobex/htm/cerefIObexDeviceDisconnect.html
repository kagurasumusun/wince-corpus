IObexDevice::Disconnect

This method disconnects the current connection.

HRESULT Disconnect(
IHeaderCollection  *pHeaders
);

Parameters

pHeaders
[in] Pointer to the header collection.

Return Values

This method returns one of the following values.

Return value Description
S_OK The request was completed successfully.
E_FAIL The request failed.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Obex.idl Obex.h
