Use of Streams

OBEX methods pass and accept standard OBEX headers. Body and EndOfBody headers are used to wrap the data of an object. The body sections of an object are abstracted with the COM-defined IStream interface, which is a blocking, file-like API. For file transfers, a call to OpenStreamOnFile is made to obtain a stream interface on a file. Once the stream is obtained, it can be copied to the stream obtained from the OBEX APIs. If raw data is to be sent, the Read and Write methods of IStream are used. In either case, the OBEX layer wraps the data in Body and EndOfBody headers as appropriate.
