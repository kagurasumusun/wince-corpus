IObexDevice:IUnknown

This interface exposes the name and address of the device. The address is transport-specific but presented as a string.

The following table shows the methods of this interface.

Method Description
IObexDevice::Abort Sends an Abort request to the server.
IObexDevice::Connect Connects to the specified device.
IObexDevice::Disconnect Disconnects the current connection.
IObexDevice::EnumProperties Returns a standard COM IPropertyBag or IPropertyBag2 interface that describes the device.
IObexDevice::Get Issues a Get command for an object on an OBEX server.
IObexDevice::Put Issues a Put command for an object that is passed to the server.
IObexDevice::SetPassword Sets the password for requests.
IObexDevice::SetPath Issues a SetPath command to the server.
