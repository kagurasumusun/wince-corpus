GetTextColor

This function retrieves the current text color for the specified device context. 

COLORREF GetTextColor(
HDC hdc
);

Parameters

hdc
[in] Handle to the device context.

Return Values

The current text color as a COLORREF value indicates success. CLR_INVALID indicates failure.

Remarks

The text color defines the foreground color of characters drawn by using the ExtTextOut function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Wingdi.h Windows.h Coredll.lib

ExtTextOut, SetTextColor, COLORREF
