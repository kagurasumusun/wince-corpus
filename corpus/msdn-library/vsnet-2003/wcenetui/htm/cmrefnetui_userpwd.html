NETUI_USERPWD

This structure specifies a network password for a user.

typedef struct _NETUI_USERPWD {
TCHAR szUserName[UNLEN + 1];
TCHAR szPassword[PWLEN + 1];
TCHAR szDomain[DNLEN +1];
DWORD dwFlags;
TCHAR szResourceName[RMLEN];
} NETUI_USERPWD, *PNETUI_USERPWD;

Members

szUserName[UNLEN + 1]
Specifies the user name.
szPassword[PWLEN + 1]
Specifies the password associated with the user name.
szDomain[DNLEN + 1]
Specifies the domain where the user name is located.
dwFlags
Specifies actions to take based on the user's choices on the dialog box.

The following table shows the supported values.

Value Description
NETUI_USERPWD_SAVEPWD SavePwd box is selected.
NETUI_USERPWD_SHOW_SAVEPWD Show the SavePwd control.
NETUI_USERPWD_SERVERLOGON Connecting to network server.
szResourceName[RMLEN]
Specifies the name of the resource to which the user is being logged on. This is valid only if the SERVERLOGON flag is set.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Netui.h
