NetUI Dialog Boxes

The following table shows the functions provided by NetUI. These functions may not be available on a specific platform.

Function Description
AdapterIPProperties Implements the IP Properties dialog box displayed in the network connections UI that allows users to configure IP addressing, DNS/WINS information, and wireless local area network (LAN) settings.
ConnectionDialog Implements the WNetConnectionDialog1 function when called by the redirector.
CreateScanDevice Reads the trusted Bluetooth devices from the registry and allows the user to manipulate, find, query, add, and delete other Bluetooth-enabled devices.
DisconnectDialog Implements the WNetDisconnectDialog1 function when called by the redirector.
GetDriverName Prompts the user to enter a driver for an unrecognized device. Installable bus drivers in the operating system (OS) such as universal serial bus (USB) and PC Cards call this function.
GetIPAddress Prompts for the IP address if the Serial Line Internet Protocol (SLIP) connection does not have a valid IP address. The Point-to-Point Protocol (PPP) calls this function.
GetNetString Retrieves a string resource from Netui.res, typically in preparation for calling another NetUI function such as NetMsgBox.
GetResourcePassword Prompts the user to enter a password for a password-protected network share. The redirector calls this funciton.
GetUsernamePassword Retrieves user credentials OS components such as PPP and the redirector. If the user selects the Save Credentials check box and Secur32.lib is present on the system, the user credentials will be saved in the credential manager.
LineConfigEdit Displays a dialog box that allows a user to edit the configurations of a specified modem line. This function is called when Telephony API (TAPI) calls lineConfigDialogEdit on a unimodem device.
LineTranslateDialog Displays an application-modal dialog box that enables the user to change the current location, adjust location and calling card parameters, and see the effect on a phone number about to be dialed.
NetMsgBox Displays a message box to the user for various OS components. For headless systems, the implementation of this function can be modified to log the error string to a file or to send it a remote system for diagnostic purposes.
