Ipv6 rcf

The ipv6 rcf command removes the specified route cache entries.

ipv6 rcf [IfIndex [Address]]

Parameters

IfIndex
Indicates the interface index number for which to remove an entry from the route cache.
Address
Indicates the address to remove from the route cache.
