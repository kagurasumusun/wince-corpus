IPv6 ppd

The IPv6 ppd command deletes the prefix policy.

Ipv6 [-p] ppd prefix

Parameters

-p
Saves the setting in the registry.
Prefix
Specifies the IPv6 prefix to delete.

To view the prefix policy, see Ipv6 ppt.

For information about the prefix policy table, see Default Address Selection for IPv6.
