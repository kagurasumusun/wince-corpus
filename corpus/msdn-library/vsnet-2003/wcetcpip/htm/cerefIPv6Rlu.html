IPv6 rlu

The IPv6 rlu command updates the router link address on an interface.

Ipv6 rlu IfIndex v4dst

Parameters

IfIndex
Indicates the interface index number for which to update the router link address.
v4dst
Indicates the IPv4 address of the router. For example, this is used to point to the Isatap router for the Automatic Tunneling Pseudo Interface.
