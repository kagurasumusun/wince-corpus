Ipv6 spu

The ipv6 spu command adds, removes, or updates a prefix in the site prefix table.

ipv6 spu Prefix IfIndex [life L]

Parameters

Prefix
Specifies the prefix for which to add, remove, or update a policy in the policy table. This is required
IfIndex
Indicates the interface index number for which to modify the site prefix table.
life L
Indicates the site prefix lifetime in seconds. If not specified, the default is infinite. Specifying a lifetime of zero causes the site prefix to be deleted.
