GetBestInterface

This function retrieves the index of the interface that has the best route to the specified IP address.

DWORD GetBestInterface(
IPAddr dwDestAddr, 
PDWORD pdwBestIfIndex 
);

Parameters

dwDestAddr
Specifies the destination IP address for which to retrieve the interface that has the best route.
pdwBestIfIndex
Pointer to a DWORD variable. On successful return, this variable contains the index of the interface that has the best route to the address specified by the dwDestAddr parameter.

Return Values

If the function succeeds, the return value is NO_ERROR. If the function fails, an error code is returned.

Remarks

For information about the IPAddr data type, see Microsoft Win32 Simple Data Types in the Windows SDK.

Requirements
