Use of ICMP to Diagnose Problems for IPv4

The ping command-line utility is used to send ICMP Echo Requests to an IP address, and wait for ICMP Echo Responses. Ping reports on the number of responses received and the time interval between sending the request and receiving the response. There are many different options that can be used with the ping utility. For more information about this utility, see Ping.
