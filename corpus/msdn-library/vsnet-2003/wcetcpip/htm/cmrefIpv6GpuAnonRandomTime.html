Ipv6 gpu TempRandomTime

The Ipv6 gpu TempRandomTime command sets the amount of time in seconds of the minimum temporary random time.

ipv6 [-p] gpu TempRandomTime Time

Parameters

-p
Saves the setting in the registry.
TempRandomTime Time
Specifies the amount of time in seconds of the minimum temporary random time. The temporary random time is the time period that elapses prior to the expiration of the valid time in which a temporary address can generate a new temporary address. The default value is 0 seconds.

Remarks

The IPv6 protocol for Windows CE randomly chooses a temporary random time between the values of TempRandomTime and MaxTempRandomTime. Random staggering of temporary address regeneration is done to prevent unwanted impacts on network traffic when a large number of temporary addresses become simultaneously invalid.
