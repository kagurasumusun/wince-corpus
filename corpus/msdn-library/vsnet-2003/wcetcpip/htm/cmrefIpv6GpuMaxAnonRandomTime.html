Ipv6 gpu MaxTempRandomTime

The Ipv6 gpu MaxTempRandomTime command sets the amount of time in minutes for the maximum temporary random time.

ipv6 [-p] gpu MaxTempRandomTime Time

Parameters

-p
Saves the setting in the registry.
MaxTempRandomTime Time
The amount of time in minutes for the maximum temporary random time. The temporary random time is the time period that elapses prior to the expiration of the valid time in which a temporary address can generate a new temporary address. The default value is 10 minutes.

Remarks

The IPv6 protocol for Windows CE randomly chooses a temporary random time between the values of TempRandomTime and MaxTempRandomTime. Random staggering of temporary address regeneration is done to prevent unwanted impacts on network traffic when a large number of temporary addresses become simultaneously invalid.
