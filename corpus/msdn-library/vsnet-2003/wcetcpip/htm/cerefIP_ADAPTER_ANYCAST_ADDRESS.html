IP_ADAPTER_ANYCAST_ADDRESS

The IP_ADAPTER_ANYCAST_ADDRESS structure stores a single anycast address in a linked list of addresses for a particular adapter.

typedef struct _IP_ADAPTER_ANYCAST_ADDRESS {
union {
ULONGLONG _temp;
struct {
ULONG Length;
DWORD Flags;
}
};
struct _IP_ADAPTER_ANYCAST_ADDRESS* Next;
SOCKET_ADDRESS Address;
} IP_ADAPTER_ANYCAST_ADDRESS, *PIP_ADAPTER_ANYCAST_ADDRESS;

Members

Length
Specifies the length of this structure.
Flags
Specifies flags for this address. Currently, the following values are supported.
Value Description
IP_ADAPTER_ADDRESS_DNS_ELIGIBLE The address is eligible to appear in DNS.
IP_ADAPTER_ADDRESS_TRANSIENT The address is a cluster address and should not be used by most applications.
Next
Pointer to the next adapter address structure in the list.
Address
Specifies the address.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.1 and later Iptypes.h
