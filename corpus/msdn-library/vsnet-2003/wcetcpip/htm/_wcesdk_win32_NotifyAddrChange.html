NotifyAddrChange

This function causes a notification to be sent to the caller whenever a change occurs in the table that maps IP addresses to interfaces.

DWORD NotifyAddrChange(
OUT PHANDLE Handle, 
IN LPOVERLAPPED overlapped 
);

Parameters

Handle
Pointer to a HANDLE variable that receives a handle to use in asynchronous notification.
overlapped
This parameter is not supported in Windows CE.

Return Values

If the function succeeds, the return value is NO_ERROR. If the function fails, an error code is returned.

Remarks

If the caller specifies NULL for the Handle parameter, the call to NotifyAddrChange blocks until an IP address change occurs.
