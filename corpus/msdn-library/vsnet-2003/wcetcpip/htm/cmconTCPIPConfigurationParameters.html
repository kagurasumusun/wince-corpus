TCP/IP Security

The TCP/IP stack for Microsoft® Windows® CE .NET has been implemented to avoid the most common security attacks, but some security risks remain. This feature has the following potential security risks:

This feature is designed to run over a public network, such as the Internet. If the security of the feature is compromised, it could expose the device or local network to the public network.

To further protect your device from security attacks, you should follow the security recommendations provided in the subsequent sections.

Best Practices

Enable a firewall on your network device

For enterprise environments, Microsoft recommends a network firewall with intrusion protection, such as Microsoft Internet Security and Acceleration (ISA) Server. For more information, visit this Microsoft Web site.

You can use the ipv6.exe utility to enable or disable a firewall. You should always protect your network with firewalls. You can use a hardware firewall or a client software firewall. For IPv6, you should enable a firewall in each client as well as on the routers.

To enable a firewall, type the following syntax at a command prompt:

ipv6 ifc <interface index#> Firewall

To disable a firewall, type the following syntax at a command prompt:

ipv6 ifc <interface index#> -Firewall

The IPv6 firewall is disabled by default, unless the firewall is persistently left enabled by using the -p option as shown in the following example:

ipv6 ifc <interface i#> -p Firewall

For more information on ipv6.exe, see IPv6.

Default Registry Settings

You should be aware of the registry settings that impact security. If a value has security implications you will find a Security Note in the registry settings documentation.

For TCP/IP registry information, see TCP/IP Registry Settings.
