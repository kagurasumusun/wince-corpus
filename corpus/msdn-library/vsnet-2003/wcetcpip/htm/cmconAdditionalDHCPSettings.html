Additional DHCP Settings

As discussed in Automatic Client Configuration for IPv4, the Dynamic Host Configuration Protocol (DHCP) provides a framework for passing configuration data to devices in a TCP/IP network, which eliminates the problems associated with manual TCP/IP configuration. When a DHCP server receives a request, the server automatically assigns an IP address from a pool of addresses, as well as the address mask, the default gateway, the DNS server, the domain name, WINS server, and so on.

Note   Windows CE does not support the services required to be a full DHCP server.

There are 255 possible options that a DHCP server can configure for a particular DHCP client. RFC 2132 describes these options in detail.

Windows CE provides two additional registry keys that allow you to define both the options you would like returned from the DHCP server, as well as additional options you can send from the client to the server. These registry keys are DhcpOptions and DhcpSendOptions.
