Ipv6 gpu

The ipv6 gpu command sets the value of the Hop Limit field.

ipv6 [-p] gpu DefaultCurHopLimit Hops

Parameters

-p
Saves the hop limit field setting in the registry.
Hops
Sets the value of the Hop Limit field in the IPv6 header for packets sent by the node. The default value is 128. This value can be changed by Router Advertisement messages or applications.
