Ipv6 renew

The ipv6 renew command renews the IPv6 configuration for all interfaces. 

ipv6 renew [IfIndex]

Parameters

IfIndex
Indicates the interface index number for which to display information. If no index number is entered, information about all interfaces is displayed.

Remarks

For a host, autoconfigured addresses are refreshed by sending Router Solicitation messages on the appropriate interfaces. Addresses are reconfigured on the basis of received Router Advertisement messages. For a router, multicast Router Advertisement messages are sent on all appropriate interfaces.
