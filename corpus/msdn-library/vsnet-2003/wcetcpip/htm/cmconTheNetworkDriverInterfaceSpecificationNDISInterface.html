Network Driver Interface Specification (NDIS)

Microsoft networking protocols use the Network Driver Interface Specification (NDIS) interface to communicate with network card drivers. Much of the Open Systems Interconnection (OSI) model link layer functionality is implemented in the NDIS module. This makes development of network card drivers much simpler.
