DhcpSendOptions

Windows CE 3.0 and later supports another registry key, HKEY_LOCAL_MACHINE\Comm\Adapter Name\Params\Tcpip\DhcpSendOptions, which allows you to send options to the DHCP server. These options are appended to the DHCP packet. Under the DhcpSendOptions key, you can create additional keys and set particular values in binary form that you want to exchange with the server.

You must also set the value of HKEY_LOCAL_MACHINE\Comm\Adapter Name\Params\Tcpip\Enable THCP to 1. If you fail to do so and set the DhcpSendOptions entry, your Windows CE device could experience adapter failure.

Note   You are responsible for making sure these options are valid DHCP options and that the values stored are correct. The Windows CE DHCP client does not format these values; the client only reads these values from the key and appends the values to the DHCP packet.
