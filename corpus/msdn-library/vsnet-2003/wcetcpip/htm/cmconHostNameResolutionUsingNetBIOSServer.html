Host Name Resolution Using a NetBIOS Server for IPv4

NetBIOS name resolution is the process of successfully mapping a NetBIOS name to an IPv4 address. A NetBIOS name is a 16-byte address used to identify a NetBIOS resource on the network.

The NetBIOS name acts as a session layer application identifier. For example, the NetBIOS Session service operates over TCP port 139. All NetBIOS over TCP/IP session requests will be addressed to TCP destination port 139. To identify the NetBIOS application with which to establish a NetBIOS session, the NetBIOS name is used.

NetBIOS name resolution uses an algorithm similar to the algorithm described previously in Host Name Resolution Using a DNS Server. The exact mechanism by which NetBIOS names are resolved to IPv4 addresses depends on the node's configured NetBIOS Node Type. Windows CE only operates as an H-Node, or Hybrid Node. H-node uses a NetBIOS name server for both registration and resolution. Microsoft ships a NetBIOS name server known as the Windows Internet Name Service (WINS).

Note   Windows CE does not support a WINS server running on Windows CE at this time.

If the host name has been changed from the default, Windows CE registers and defends the name of the device on the network when a new network interface becomes active.

Note   If MSMQ is part of your device configuration and you run an application that uses MSMQ, the name is automatically registered with WINS.

For information about host name resolution for IPv6, see Host Name Resolution for Dual Stack (IPv4/IPv6).

For information about host name registration, see Name Registration for IPv4.
