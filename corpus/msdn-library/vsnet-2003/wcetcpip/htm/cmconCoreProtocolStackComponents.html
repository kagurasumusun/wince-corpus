Core Protocol Stack Components

The core protocol stack components are those shown between the NDIS and Winsock in the illustration included in Architectural Model. The following list shows where Windows CE implements these components:

  • TCP/IPv4 component is implemented in Tcpstk.dll
  • TCP/IPv6 component is implemented in Tcpip6.dll

The Microsoft TCP/IPv4 stack is accessible through the Winsock 1.1 and Winsock 2.2 interfaces, whereas the TCP/IPv6 stack is accessible only through the Winsock 2.2 interface. The Winsock interface for Windows CE does not provide raw access to the protocol stack.
