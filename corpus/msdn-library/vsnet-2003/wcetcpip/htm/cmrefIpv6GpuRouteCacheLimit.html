Ipv6 gpu RouteCacheLimit

The Ipv6 gpu RouteCacheLimit command sets the maximum number of entries in the route cache for each interface.

ipv6 [-p] gpu RouteCacheLimit Number

Parameters

-p
Saves the setting in the registry.
gpu RouteCacheLimit Number
Specifies the maximum number of entries in the route cache for each interface. The default value is 32 entries.
