TCP/IP Troubleshooting Utilities

Many network troubleshooting tools are available for Windows CE. Microsoft Network Monitor is an excellent network tracing tool. The full version is part of Microsoft Systems Management Server, and a more limited version is included in Microsoft® Windows® XP.

Windows CE includes the following utilities to troubleshoot network problems:

  • Ethman
  • IPConfig
  • IPv6
  • Ipv6tun
  • Netstat
  • Ping
  • Route
Note   Configuration changes are not permanent and will be lost if you reset the device. You can save configuration changes by writing them as command lines in a batch file (.bat) that you can run after restarting the device.

For tasks that help you diagnose IPv6 connections, see Diagnosing Connections.
