Ipv6 gpu MaxTempDADAttempts

The Ipv6 gpu MaxTempDADAttempts command sets the number of times that a temporary address is checked for uniqueness.

ipv6 [-p] gpu MaxTempDADAttempts Number

Parameters

-p
Saves the setting in the registry.
MaxTempDADAttempts Number
Specifies the number of times that a temporary address is checked for uniqueness. The default number of attempts is 5.
