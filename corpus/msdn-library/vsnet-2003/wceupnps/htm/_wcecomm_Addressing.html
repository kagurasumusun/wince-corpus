UPnP Addressing

To join a UPnP-enabled network, a Windows CE–based device must first obtain an IP address. To connect to the network, each UPnP device must have a Dynamic Host Configuration Protocol (DHCP) client and search for a DHCP server. If the network does not have a DHCP server, the UPnP device can use automatic IP addressing to obtain an IP address. After the UPnP device has an IP address, the control point can locate it on the same subnet through that address.
