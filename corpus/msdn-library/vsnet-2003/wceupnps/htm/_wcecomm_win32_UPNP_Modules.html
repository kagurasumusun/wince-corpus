UPnP Modules

The following table shows the modules in your platform configuration you need to include to implement UPnP on a Windows CE–based device.

Module Library Description
UPNPHOST Upnphost.dll Contains a set of COM interfaces that are used for UPnP devices.
UPNPCAPI Upnpcapi.dll C API for platform developers.
UPNPSVC Upnpservice.dll Back-end service.
UPNPLOADER Upnploader.dll Service that loads a set of COM UPnP device implementations.
UPNPCTRL Upnpctrl.dll Contains the Control Point API implementation.
