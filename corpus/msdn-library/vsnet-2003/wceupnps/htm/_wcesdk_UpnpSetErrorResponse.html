UpnpSetErrorResponse

This function sends an error response to the control point if an error has occurred when fulfilling a control request.

UpnpSetErrorResponse(
UPNPSERVICECONTROL *pUPnPAction,
DWORD dwErrorCode,
PCWSTR pszErrorDescription
);

Parameters

pUPnPAction
Pointer to the UPnP control action.
dwErrorCode
Specifies the error code.
pszErrorDescription
Specifies the error code and provides a description for it.

Remarks

This function should only be called inside the UPNPCALLBACK function when the UPNPCB_ID is UPNPCB_CONTROL.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Upnpdevapi.h
