Registering a Hosted Device

To register a hosted device, you must provide a device description and the corresponding device control object. The UPnP device host API uses this information to create complete UPnP device descriptions and publish them on the network so that control points can access them.

You can register a device in the following ways:

  • A UPnP application can create an instance of the device control object and pass a pointer to the object to the device host API.
  • You can pass the CLSID of a device's control object to the device host API, which will instantiate the object when needed.

Although in both cases the device host API publishes and announces the device on the network after registering the device, the time when the device code is loaded differs. In the first case, the device code is loaded directly at the time of registration. In the second case, the device code is loaded only when the device receives a control or event subscription request. Although the second method is slightly more optimized, it is unsuitable for devices that must be running before any control or event subscription requests arrive for them.

A device is registered through the UpnPRegistrar object, which exposes the IUPnPRegistrar interface. To register a device with a running device control object, a UPnP application must call the IUPnPRegistrar::RegisterRunningDevice method and pass in the following parameters:

  • The text of the device's description
  • An IUnknown pointer to the device control object
  • An initialization string that will be passed to the IUPnPDeviceControl::Initialize method of the device control object
    Note   The RegisterRunningDevice method is only supported when it is called from a service that is loaded in the services.exe process.

To register a device that is not running, you can create a command-line tool and pass in the following parameters:

  • The name of the file containing the device description
  • The programmatic identifier (ProgID) of the device control object
  • An initialization string, which may be passed in a file, that will be passed to the IUPnPDeviceControl::Initialize method of the device control object
  • A container identifier consisting of a string that identifies the group to which the device belongs

A UPnP application can also register a running device by calling the IUPnPRegistrar::RegisterDevice method and passing in the following parameters:

  • The text of the device's description
  • The ProgID of the device control object
  • An initialization string that will be passed to the IUPnPDeviceControl::Initialize method of the device control object
  • The location of the resource directory
    Note   The RegisterDevice method can be called from any process.

To unregister a hosted device, the application must call the IUPnPRegistrar::UnregisterDevice method. This method permanently removes the device from the host, if the fPermanent flag is set. If the flag is not set, the device is removed, but the application can register it again by using the IUPnPReregistrar interface.
