UPnP Presentation

In a UPnP-enabled network, a control point can control a device or view its status through a presentation page in HTML that features a user interface. The URL for the presentation page is located in the device description. To retrieve the presentation page, the control point submits an HTTP GET request to the presentation URL. The device then returns the presentation page to the control point.
