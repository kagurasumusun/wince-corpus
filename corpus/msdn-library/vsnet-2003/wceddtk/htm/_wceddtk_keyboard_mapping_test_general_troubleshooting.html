General Troubleshooting

  • At the end of the test case, Tux will print a summary of test results indicating whether the test passed, failed, skipped, or aborted.

    All failures and log entries include the source file name and line number where the log event occurred.

  • If the .dll files that Tux.exe requires are missing, a Tux.exe unknown command error is displayed.
