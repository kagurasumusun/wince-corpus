TUX Demo

Before running any of the DDTK Tux.exe tests, verify that your setup is working correctly by running the Tux.exe demo, Tuxdemo.dll. Tuxdemo.dll is also a useful reference on how to write a new test .dll file.

The following is required for the TUX demo:

  • Debugger machine

    A machine running the debugger or any application that can capture the COM port output for test logging on a dedicated debugging port.

  • Target platform files:
    • Tux.exe
    • Kato.dll
    • Tooltalk.dll
    • Tuxdemo.dll

Type the following command line to start the TUX demo. The -o parameter instructs the test log to be sent to the debug output. 

tux -o -d tuxdemo

After Tux.exe has finished running the test in Tuxdemo.dll, a summary of the test results is sent to Kato.dll. This consists of the number of passed, failed, skipped, and aborted test cases. All failures and most other log entries include the source file name and the line number from which the log was made.

You should note the following:

  • The test evaluation described above applies to all of the DDTK Tux.exe tests.
  • Tuxdemo.dll is a sample Tux.exe test meant for demonstration only and the test results should be disregarded.
