Microsoft Windows CE 3.0  

Running the Test

The following command line shows the syntax for running the test.

qailtiming [test_case] [parameters]

The test cases can be described as follows:

  • Test cases 2000–2004 create threads that randomly sleep.
  • Test cases 2006–2008 verify that real-time performance is unaffected by thread creation.
  • Test case 4001 verifies that real-time performance is unaffected by the virtual memory manager.

The following table shows the test cases.

Test Case Description
1001 Type 1: Spinning test.
1002 Type 2: CeSetThreadPriority(254) test.
1003 Type 3: Two threads, SetEvent with timeout test.
1004 Type 4: Two threads, SetEvent without timeout test.
1005 No idle threads test.
2000 Sleep queue shuffler test: 10 threads.
2001 Sleep queue shuffler test: 100 threads.
2003 Sleep(1) test: 10 threads.
2004 Sleep(1) test: 100 threads.
2006 CreateThread test.
2007 CreateProcess test.
2008 LoadLibrary test.
4001 LocalAlloc/LocalFree test.

The following table shows the test case parameters.

Parameter Description
-n number Number of sample. Default: 100.
-v Verbose (save all samples).
-f file_name Save to file.
-israbs number ISR absolute error limit.
-istabs number IST absolute error limit.
-isrmul mult ISR relative error limit (multiply by mult to get error limit).
-istmul mult IST relative error limit (multiply by mult to get error limit).
-npl No process/thread list.
-b Debug break on error.
-tlonerr Output a thread list on error.
-ncs No cache sync after each interrupt. Default: flush cache after each interrupt.
-t interval Timing interval (clock ticks in microseconds). Default: 5.
-l List all test cases.
-x test_case Execute test case. Default: execute all test cases.
