Microsoft Windows CE 3.0  

CKato::SendSystemData

This function sends a buffer of raw data to a particular system on the server side.

BOOL SendSystemData (
DWORD dwSystemID, 
LPCVOID lpcvBuffer, 
DWORD dwSize );

Parameters

dwSystemID
Specifies a unique identifier that identifies the data. Only systems that recognize this identifier value accept and process the data.
lpcvBuffer
Pointer to a buffer of system dependent data.
dwSize
Specifies the size, in bytes, of the data pointer to lpcvBuffer. This value cannot exceed KATO_MAX_DATA_SIZE.

Return Values

Nonzero if successful; otherwise 0.

Remarks

This function allows Kato to be used for additional tasks besides text logging. Systems can be written to perform such features as data analysis, code profiling, statistics, graphing, and so on. SendSystemData provides the ability to transfer raw data to the server where it can be interpreted by systems that understand the format of the data.
