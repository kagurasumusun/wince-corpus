Microsoft Windows CE 3.0  

General Troubleshooting

The number of passed results should be 10. The printing output should be compared to the reference output. Each test suite consists of 10 printing jobs and 25 total pages printed out according to the following table.

Print job Description
1 1 document, which has 2 pages. Because the second page is aborted, it is blank.
2 2 documents, each of which has 2 pages.
3 1 document, which has 1 page.
4 1 document, which has 1 page.
5 1 document, which has 1 page.
6 1 document, which has 12 pages.
7 1 document, which has 1 page.
8 1 document, which has 1 page.
9 1 document, which has 1 page.
10 1 document, which has 1 page.

If the output matches the reference output, the test has passed; otherwise, a failure has occurred in the printer driver.

If the .dll files that Tux requires are missing, a Tux unknown command error is displayed.
