Running the Test

The following command line shows the syntax for using Tux.exe to run the test, where test_case is the specific test case or range of test cases to run.

tux –o –d battery –x test_case

The following command line shows the syntax for using Tux.exe to run the entire test.

tux –o –d battery

After each test case finishes, a status report is displayed indicating whether it passed, failed, skipped, or aborted. After all of the specified test cases have finished, a summary of results is displayed. All the tests should pass.

The following table shows how the test cases are categorized.

Test Case Description
11–13, 20–22, 70 Battery Test 1: GetSystemPowerStatusEx test cases.
30–32, 71–73 Battery Test 2: BatteryGetLifeTimeInfo test cases.
40–42 Battery Test 3: BatteryDrvrGetLevels test cases.
50–52, 60–62, 74 Battery Test 4: BatteryNotifyOfTimeChange test cases.
