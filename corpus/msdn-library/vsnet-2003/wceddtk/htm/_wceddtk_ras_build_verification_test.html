RAS Build Verification Test

The RAS Build Verification test, Rascheck.exe, performs a quick build verification test of all 15 Windows CE Remote Access Service (RAS) functions over a typical connection. It builds, tests, and deletes a RAS phonebook entry using either default parameters or parameters from an existing phonebook entry (specified with the -e parameter).

The following table shows the hardware requirements.

Requirements Description
A modem or direct serial (null modem) connection between the target device being tested and the development workstation. Required for RAS.

The following table shows the software requirements.

Requirements Description
Rascheck.exe Test .exe file.
Common library files Located in the Netlib directory.
RAS Server Must be installed and running on the Windows NT machine.
