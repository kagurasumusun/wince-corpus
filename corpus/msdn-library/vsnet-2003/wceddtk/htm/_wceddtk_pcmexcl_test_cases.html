Microsoft Windows CE 3.0  

Pcmexcl test cases

These test cases test the following PC Card Services APIs with I/O cards:

  • CardRequestExclusive
  • CardReleaseExclusive

The CallbackFunction, which is installed by CardRegisterClient, is tested to determine whether it receives the ExclusiveRequest event. It is also checked for various parameter values.

Boundary and parameter checking are performed for all test cases. Invalid parameters, handles, and sockets are passed to verify the proper return of error codes. Testing with threads and various clients is also performed.

Some I/O cards may not support the soft resetting of the card; for example, when the MSB of ConfigReg is one.

Syntax/Parameters

The following command lines show the syntax for the test cases. 

rats pcmexcl 0     - Smoke test for slot 1
rats pcmexcl 1     - Full  test for slot 1
rats pcmexcl 2     - Smoke test for slot 2
rats pcmexcl 3     - Full test for slot 2

Troubleshooting

  • In the debug window, a summary of results appears at the end of the test.
  • All of the tests should pass.

    If one of the tests has failed, analyze the debug output.

  • Some tests are expected to return with error codes.

    The result obtained should match the expected result.
