Test Tools

The test tools consists mainly of the Tux Test Harness (Tux.exe) and the Kato Logging Engine (Kato.dll). The DDTK includes the header files that allow you to write the test DLLs for the Tux Test Harness.

The test tools used by the DDTK are:

  • Tux.exe

    A 32-bit client/server test harness tool that executes test code modules stored in .dll files. A single server can control multiple clients. The client can also run in a standalone mode. For more information, see Tux Test Harness.

  • Kato.dll

    A 32-bit client/server logging engine that allows applications to send their log output to a single interface and have it routed to multiple user defined output devices. The server routes data from incoming logging streams to output systems. For more information, see Kato Logging Engine.

  • Keepaliv.exe

    This utility prevents the target platform from transitioning into suspend mode. It calls two APIs: SystemStarted and SystemIdleTimerReset. It is recommended that you run this utility before starting any test. It is applicable only if your Windows CE OS configuration has the specific GWES component for setting the system into suspend mode.

  • Tooltalk.dll

    This application is required by Tux.exe and Kato.dll. It handles the transport between the target device and the development workstation.
