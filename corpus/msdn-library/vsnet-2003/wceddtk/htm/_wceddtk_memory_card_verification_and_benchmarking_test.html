Memory Card Verification and Benchmarking Test

The Memory Card Verification and Benchmarking test, Rw_all.dll, benchmarks the read and write performance and correct behavior of PC memory cards.

This test scans a disk, verifying the ability to correctly read from and write to every sector on the disk. Along with this verification, it outputs information about the timing requirements of each operation. This timing information may be useful whenever you have file system problems. For example, one disk may only take 400 ms to write and passes, while another disk takes 1500 ms to write and fails.

The following table shows the hardware requirements.

Requirements Description
Any hardware using a memory block (DSK) device driver. Examples include a PCMCIA ATA disk or PCMCIA Memory Card.

The following table shows the software requirements.

Requirements Description
Rw_all.dll Test .dll file.
Tux.exe Tux Test Harness, which is required for executing the test.
Kato.dll Kato Logging Engine, which is required for logging test data.
Tooltalk.dll Application required by Tux.exe and Kato.dll. Handles the transport between the target device and the development workstation.
