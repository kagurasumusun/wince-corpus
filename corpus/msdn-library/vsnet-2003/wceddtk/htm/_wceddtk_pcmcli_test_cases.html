Microsoft Windows CE 3.0  

Pcmcli test cases

These test cases test the following PC Card Services APIs:

  • CardRegisterClient
  • CardDeregisterClient
  • CardRequestWindow
  • CardReleaseWindow
  • CardMapWindow

The smoke test cases test the CardRegisterClient and CardDeregisterClient.

The full test cases test these APIs for various values of attributes and mask. The callback function provided with the CardRegisterClient is tested for manual as well as artificial callbacks as specified by the mask parameter. The proper functioning of the callback function is critical if Plug and Play is desired. The full test cases test the CardRequestWindow and CardReleaseWindow with a combination of attribute, access speed, and size parameters. The various combinations are tested for common, I/O, and attribute memory spaces.

Boundary and parameter checking is performed for all test cases. Invalid parameters, handles, and sockets are passed to verify the proper return of the error codes. In addition, all test cases test for multiple threads and various clients.

Syntax/Parameters

The following command lines show the syntax for the test cases. 

rats pcmcli 0     - Smoke test for slot 1
rats pcmcli 1     - Full test for slot 1
rats pcmcli 2     - Smoke test for slot 2
rats pcmcli 3     - Full test for slot 2

All the tests are both for the memory and the I/O cards.

Troubleshooting

  • Not all I/O cards support 16-bit access.

    When the Attributes to CardRequestWindow is set to 16-bit access, some cards may fail in CardMapWindow.

  • In the debug window, a summary of results appears at the end of the test.
  • All of the tests should pass.

    If one of the tests has failed, analyze the debug output.

  • Some tests are expected to return with error codes.

    The result obtained should match the expected result.
