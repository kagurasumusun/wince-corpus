Microsoft Windows CE 3.0  

Cardtupl test cases

These test cases tests the following PC Card Services APIs with memory and I/O cards:

  • CardGetFirstTuple
  • CardGetNextTuple
  • CardGetTupleData
  • CardGetParsedTuple.

This test case first builds a linked list of tuples by using CardGetFirstTuple and CardGetNextTuple. Using a random seed, it then calls each of these APIs randomly.

The returned value is checked against the linked list of tuples and any mismatches are flagged as errors. Boundary and parameter checking are performed for all test cases. In addition, all test cases test for multiple threads and various clients.

Syntax/Parameters

The following command lines show the syntax for the test cases. 

rats cardtupl 0     - Smoke test for slot 1 and slot 2
rats cardtupl 1     - Full test for slot 1 and slot 2

Troubleshooting

  • In the debug window, a summary of results appears at the end of the test.
  • All of the tests should pass.

    If one of the tests has failed, analyze the debug output.

  • Some tests are expected to return with error codes.

    The result obtained should match the expected result.
