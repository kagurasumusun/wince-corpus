Building the DDTK Tests

The DDTK tests must be built before you can run them. The preferred method is to use the Platform Builder IDE to add the DDTK component to your platform; when you build your platform, the DDTK tests will be built. You can also build the DDTK tests from a Windows CE command prompt build window.
