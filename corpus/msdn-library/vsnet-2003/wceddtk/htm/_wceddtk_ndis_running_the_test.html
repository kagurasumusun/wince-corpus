Microsoft Windows CE 3.0  

Running the Test

Once the Hapi.ini configuration file is set up correctly, you are ready to run the NDISTest application. To run NDISTest, perform the following steps.

  1. Prevent the TCP/IP protocol stack from loading by adding the following entry to the Windows CE registry and rebooting the target device. 
    [HKEY_LOCAL_MACHINE\Comm\AFD]
  "Stacks"=""
  2. Copy the NDIS test files to the target device. Ndistst.dll and Ndtsys.dll should be placed in the \Windows directory.
  3. Place Hapi.exe and Hapi.ini in an NDIS directory that you have created, such as \NDISTest, and place the Cescripts directory under it.
  4. If two-machine testing is being performed, a NDIS test server must be started on a remote Windows NT machine connected via the LAN to the Windows CE network card that is being tested. You must also edit Hapi.ini and set the G_TestOptions global variable to the SKIP_1CARD_TESTS flag.

    The version of NDIS test running on the Windows NT machine must be compatible with the version of NDIS test running on the Windows CE machine. To prevent failures from occurring, use the Windows NT version of the NDIS test that is supplied with the Windows CE DDTK.

  5. If stress testing is being performed, the LAN network should only be used by the Windows CE and Window NT machines running the test.

    The version of NDIS test running on the Windows NT machine must be compatible with the version of NDIS test running on the Windows CE machine. To prevent failures from occurring, use the Windows NT version of the NDIS test that is supplied with the Windows CE DDTK.

  6. Run the specified test by typing the following command line in the Windows CE command shell on your Windows NT workstation: 
    hapi -rwork_dir\   Cescripts\Nd_cli.tst

    Unlike Windows NT, Windows CE has no concept of a current directory. You must set the -r parameter when running the test to specify the root directory that is used to access files on the Windows CE device. Note that there are two parts to this command line: The first part, work_dir, specifies the directory containing the Hapi.exe files created in step 3 and must include a trailing backslash (\). The second part specifies the script file and its path.

  7. If you have a Windows CE Shell (CESH) connection between your Windows NT workstation and the Windows CE device, you can specify a directory on the Windows NT workstation to be used to access files by prefixing it with "ppsh:".

    The following command line example shows the syntax. 

    hapi -rppsh:\NDISTest\   Cescripts\Nd_cli.tst

    This command line loads the Hapi.exe script interpreter and instructs it to start running the NDIS test client-side base script, Nd_cli.tst. Hapi.exe automatically reads Hapi.ini as it starts.

The following table shows the general test case parameters for Hapi.exe.

Parameter Description
-r work_dir script Specifies the working directory, work_dir, and the directory and name of the test script file to run, script.
