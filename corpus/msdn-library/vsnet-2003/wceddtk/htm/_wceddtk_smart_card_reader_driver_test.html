Smart Card Reader Driver Test

The Smart Card Reader Driver test, Ifdtest.exe, tests the Windows CE smart card reader driver APIs.

The smart card reader driver resides in the OEM adaptation layer (OAL) between your hardware and the Smart Card Resource Manager. The API functions are exported to the user application — the Smart Card Resource Manager — through smart card reader driver IOCTL codes.

This test covers all of the smart card reader driver IOCTL codes. It also covers data transfer by using smart card provider-defined protocols.

The following table shows the hardware requirements.

Requirements Description
Smart card reader, such as PCMCIA SCM Reader, BullTLP3 Serial Reader, or STC USB Reader. The smart card reader driver depends on the hardware; different hardware may use different drivers.
PC/SC Compliance Test Card Compliance test card used to verify reader function.
