Microsoft Windows CE 3.0  

Audio Test Cases

This test suite verifies that the audio driver is working properly.

Test Case 20 - Play Sample Test

A sample .wav file is played for the user. This test case requires user interaction, which determines its success or failure.

Test Case 21 - Volume Control Test

The driver's ability to change .wav file output volume is tested. This test case requires user interaction, which determines its success or failure.
