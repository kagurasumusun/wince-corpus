Microsoft Windows CE 3.0  

Running the Test

The following example shows the syntax for using Tux.exe to run the test, where test_case is the specific test case or range of test cases to run.

tux –o –d scardbvt –x test_case

The following example shows the syntax for using Tux.exe to run the entire test.

tux –o –d scardbvt

After each test case finishes, a status report is displayed indicating whether it passed, failed, skipped, or aborted. After all of the specified test cases have finished, a summary of results is displayed.

In order to test full functionality and the compatibility of the user driver, you should connect all supported smart card readers to the Windows CE testing machine.

A PC/SC Compliance test card must be inserted into every smart card reader before running this test.

The following table shows the test cases.

Test Case Description
1001 Smart card BVT test.
1002 Multi-smart card query BVT test.
1003 Multi-smart card tracking BVT test.
1004 Multi-smart card access BVT test.
1005 Multi-smart card direct access BVT test.
