Running a Sample Test

To run the sample test

  1. Before the PC Card is inserted in the slot, type the following command line: 
    rats pcmintr 5
  2. Insert the PC Card and type one of the following command lines: 
    rats pcmintr 1

    – Or – 

    rats pcmintr 3
  3. Remove the PC Card and type the following command line: 
    rats pcmintr 6.
