Running the DDTK Tests

Refer to an individual test topic for information on how to run it. You may run a DDTK test by using one of the following methods:

  • Eshell.exe

    Launch Eshell.exe from a Windows CE command prompt window, download the OS image to the target device, and type the DDTK test command line in the Eshell.exe command window at the Windows CE prompt. The DDTK test command line must be preceded by an "s". For more information, see the Platform Builder documentation.

  • Run Program

    After downloading the OS image to the target device, choose Run Program from the Platform Builder Target menu and type the DDTK test command line in the Execution Command Line box. For more information, see the Platform Builder documentation.

Each of the DDTK test descriptions includes the command line for launching the test via Eshell.exe.

See the Platform Builder documentation for information on the following:

  • Adding executables or files to the ROM image (*.bin).
  • Setting up the debugger for capturing the test logs.

All DDTK test instructions assume the following:

  • All additional files, such as .wav files, are already copied onto the target device's object store or are accessible via an ATA storage card.
  • The test debug output is sent to the debugger machine, which is typically the development workstation.
