Microsoft Windows CE 3.0  

Command-Line Procedures

To build the TUX demo test

  1. Open a Windows CE command prompt build window using Wince.bat.

    In order to start building the TUX demo test in the appropriate environment, you must open a command prompt build window, which prepares the build environment. For example, to open a command prompt build window for a CEPC, type the following command line in a command prompt. 

    Wince x86 i486 CE Blddtk CEPC

    Wince.bat is a batch file that sets the environment variables that define the target OS, target device, and project name. In the above example, the target OS is Windows CE for the x86 and the target device runs on the Intel 486 microprocessor. The project name, which is Blddtk for DDTK, is built in the above environment.

  2. If the project was built earlier for a different environment, Wince.bat instructs you to run Buildrel.bat for the current environment. Buildrel.bat will then copy the required files to the release directory. Otherwise, Wince.bat instructs you to perform the following instructions:
    • Navigate to the %_WINCEROOT%\Others\Ddtk30 directory and type the following command: 
      Sysgen

      Sysgen.bat calls Cesysgen.bat, which specifies all of the library files that will be linked with your application. Every project has its own Cesysgen.bat file, which can be modified according to the requirements of the project.

    • Navigate to the directory where the DDTK test case source code is present, %_WINCEROOT%\Others\Ddtk30\Tuxdemo and type the following command: 
      Sysgen
    • Type the following command line: 
      Build -cfs.

      Build.exe is a tool that compiles the application and links it with the libraries to get the required output specified in the sources file. The specified output can be a .dll, .lib, or .exe file. There are several options for building the applications, such as the -cfs option, which does a clean build of the application.

  3. Set the WINCEOEM environment variables by typing the following in the command prompt build window. 
    set WINCEOEM = 1

    This will allow OEM-specific libraries to be linked with the application.

  4. If the build is successful, the following message will be displayed: 
    Executables built

    If the build fails, examine the Build.log file, which is present in the directory where Build.exe was called. Correct the problem and type the following command line to perform a clean rebuild of the application: 

    Build -cfs
