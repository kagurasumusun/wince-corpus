Microsoft Windows CE 3.0  

KatoLog

This function logs a string to the current logging level with a specified verbosity level. The verbosity value is tallied for the given level.

BOOL KatoLog ( 
HKATO hKato, 
DWORD dwVerbosity, 
LPCTSTR szFormat,
... );

Parameters

hKato
Handle to a CKato object.
dwVerbosity
Specifies the verbosity level of this log message. This value can be between 0 and KATO_MAX_VERBOSITY.
szFormat
Address of ANSI or UNICODE format-control string.
argument(s)
Specifies one or more optional arguments. The number and type of argument parameters depend on the corresponding format-control specifications in the szFormat parameter.

Return Values

Nonzero if successful; otherwise, 0.

Remarks

Within each level of log, a tally is kept for each verbosity. Each time KatoLog is called, the counter for the specified verbosity is incremented. KatoGetVerbosityCount can be used to query a level for its verbosity tallies. Usually particular verbosity values are associated with concepts such as pass and fail. If you structure your log in this manner, you can use KatoGetVerbosityCount to query the number of passes and failures that have occurred within a given level.

Each logging system on the server side has a verbosity filter, which filters out all logs with verbosity values greater than the current filter value for that system. For this reason, applications should structure their logging so that the most critical logs get the lowest verbosity level. Typically a severe failing log gets a verbosity level of 0.
