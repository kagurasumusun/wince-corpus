Running the Test

The following command line shows the syntax for using Tux.exe to run the test, where test_case is the specific test case or range of test cases to run.

tux –o –d kvbvt –x test_case

The following command line shows the syntax for using Tux.exe to run the entire test.

tux –o –d kvbvt

After each test case finishes, a status report is displayed indicating whether it passed, failed, skipped, or aborted. After all of the specified test cases have finished, a summary of results is displayed.

The following table shows the test cases.

Test Case Description
1 Basic Virtual Memory Test 1. Reserves and commits virtual memory with one call to VirtualAlloc.
2 Basic Virtual Memory Test 2. Reserves and commits virtual memory with two separate calls to VirtualAlloc.

Test Case 1

This test case perform the following steps:

  1. Commits and reserves a buffer.
  2. Verifies the buffer by writing to every byte of the buffer.
  3. De-commits the buffer.
  4. Performs a write to the de-committed buffer with the expectation of an exception.
  5. The buffer is released and the test performs a write to this de-committed and released buffer with the expectation of an exception.

Test Case 2

This test case is a variation in the order of test case 1:

  1. Reserves a buffer.
  2. Performs a write to the buffer with the expectation of an exception.
  3. Commits the memory, which is verified with a write to every byte of the buffer.
  4. De-commits and releases the buffer.
  5. Performs a write to the de-committed and released buffer with the expectation of an exception.
