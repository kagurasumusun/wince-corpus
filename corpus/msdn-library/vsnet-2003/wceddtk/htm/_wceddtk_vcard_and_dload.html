Microsoft Windows CE 3.0  

Vcard and Dload

These tests provide details of the PC cards present in each of the slots.

The Dload test is the device driver loader. It uses the RegisterDevice and CreateFile APIs to register and load the device driver and communicates with the driver using I/O control codes.

The Vcard test starts a dialog box, registers as a card services client, which in turn sets up the callback function.

The callback function is called whenever the INSERTION, REMOVAL, or EXCLUSIVE events occur as registered in the RegisterClient function. The Vcard test retrieves the pnpid of the card when it retrieves an INSERTION event and displays it in a dialog box.

Syntax/Parameters

The following command lines show the syntax for the test cases.

s dload vcard.

Troubleshooting

  • The card is present in a slot but the dialog box shows that slot as empty.

    There is a problem with the PC card's CIS, which is causing it not to be recognized.

  • Some tests are expected to return with error codes.

    The result obtained should match the expected result.
