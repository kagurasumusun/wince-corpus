Microsoft Windows CE 3.0  

Running the Test

The following command line shows the syntax for running the test.

xtapimc [parameters]

The following table shows the general test case parameters.

Parameter Description
-v verbosity Sets the verbosity level of the debug output, from 0 (extremely terse) to 15 (extremely verbose). Default: 10.
-z Routes log output to a console window. Default: output to the debugger.
-fl Routes log output to a file on the target device.
-fr Routes log output to a remote file opened via CESH.
-l Lists all TAPI devices, then exits without making any calls.
-n number_of_calls Sets the number of calls to be made. Default:1.
-p "phone_number" Sets the telephone number to be dialed. Default: # (NULL). The number may be specified using any one of three formats:
  • If the number begins with "+", it will be read as being in canonical format ("+country code (area code) local number") and translated according to TAPI dialing rules for the current location. Example: xtapimc -p"+1 (425) 555-1212"
  • If the number begins with "#", the telephone number will be set to NULL.

    This is acceptable in some scenarios, such as when testing a null modem.

  • If the number begins with any other character, it will be dialed directly.

    Dialable numbers should be preceded with "P" for pulse or "T" for tone dialing plus any digits that may be needed to access an outside line.

    Example: xtapimc -p"T9,555-1212"

-d device_identifier Sets the TAPI device identifier of the line to be tested. A list of device identifiers may be obtained by using the –l parameter. The default value is 0, which is the external modem on most standard Windows CE configurations.
-td seconds Sets the dialing timeout, in seconds. A call will be dropped if it has not completed by this time. The default value is 30 seconds for Windows CE, which waits for a call to connect before completing it, and 5 seconds for Windows NT, which completes first and then connects.
-tc seconds Sets the connection delay, in seconds. The program will wait as long as this interval after a call completes before dropping it. The default value is 10 seconds for Windows CE, 30 seconds for Windows NT.
-th seconds Sets the hang-up command timeout interval in seconds. Default: 5. The program will execute for as long as this interval before timing out.
-tw seconds Sets the deallocation delay interval in seconds. Default: 1. The program will wait for as long as this delay interval after a call has been dropped before deallocating the call handle.
-b bearer_mode Sets the bearer mode. Bearer modes that may be specified include the following:
  • 0

    3.1 kHz analog voice. This is the default mode.

  • 1

    G.711 speech.

  • 2

    ISDN multiuse.

  • 3

    Data transfer.

  • 4

    ISDN speech/data.

  • 5

    Non-call-associated signaling connection (media stream).

  • 6

    Passthrough (direct modem control).

The bearer mode must be compatible with the TAPI device selected.
-m media mode Sets the media mode. Media modes that may be specified include the following:
  • 0

    Data modem. This is the default mode.

  • 1

    Interactive voice.

  • 2

    Automated voice.

  • 3

    Group 3 FAX.

  • 4

    Group 4 FAX.

  • 5

    Digital data.

  • 6

    Telephony Devices for the Deaf (TDD).

  • 7

    Teletex.

  • 8

    Videotex.

  • 9

    Telex.

  • 10

    ISDN mixed.

  • 11

    ADSI.

  • 12

    VoiceView

  • 13

    Unclassified.

The media mode must be compatible with the TAPI device selected.
-r baud Sets the baud. Windows CE currently ignores this parameter and sets the baud from the device configuration instead. Default: 19200.
-e Allows you to edit device configuration and current location. Two dialog boxes are opened:
  • Device Properties

    Allows the baud and other parameters for the TAPI device to be changed.

  • Dialing Properties

    Allows the location and other parameters affecting address translation to be changed.

-h Prints a short help description.

The following are additional test features:

  • Testing of null modem serial connections.

    In order for a null modem connection to complete, the bearer mode must be set to 3 (data transfer) and the baud parameters in the Device Properties dialog box must be set correctly.

  • If the logging verbosity is maximized (-v15 parameter), data from the LINEDEVCAPS structure for the device being tested will be logged.

    This provides important information, such as the name of the device and the bearer, and the media modes it supports.

  • Hayes AT modem commands may be entered using the Extra Settings box in the Device Properties dialog box.

    Commands should be listed without the leading "AT" string. For example, to turn off the modem speaker (Hayes command = ATM0), enter "M0".
