Running the Test

The following command line shows the syntax for using Tux.exe to run the test, where test_case is the specific test case or range of test cases to run.

tux –o –d gsinfo –x test_case

The following command line shows the syntax for using Tux.exe to run the entire test.

tux –o –d gsinfo

After each test case finishes, a status report is displayed indicating whether it passed, failed, skipped, or aborted. After all of the specified test cases have finished, a summary of results is displayed.

The following table shows the test cases.

Test Case Description
1001 Scans the machine for all disks and attempts to open DSK0: through DSK9: using bad parameters.
1002 Scans the machine for all disks and attempts to open DSK0: through DSK9: using good parameters.
1003 Tests the DISK_IOCTL_GETINFO I/O control code and displays all of the disk information.
1011 Tests handling of bad parameters: null handle passed.
1012 Tests handling of bad parameters: invalid IOCTL passed.
1013 Tests handling of bad parameters: null pointer to input buffer passed.
1021 Tests the DISK_IOCTL_SETINFO I/O control code.

Test Case 1001

This test case verifies the processing of the DISK_IOCTL_GETINFO control code and checks for the presence of a PC card using invalid device names, such as DSK:.

Test Case 1002

This test case verifies the processing of the DISK_IOCTL_GETINFO I/O control code and checks for the presence of a PC card. If a card is found, a message is returned that a card was found and that a handle to it was successfully opened.

Test Case 1003

This test case verifies the processing of the DISK_IOCTL_GETINFO control code. It gets information about each card inserted in the system and prints out its characteristics.

Test Cases 1011–1013

These test cases pass a series of bad parameters to the device driver and verify that the driver successfully handles them.

Test Case 1021

This test case gets device information and verifies the ability of the driver to change this information using the DISK_IOCTL_SETINFO I/O control code.
