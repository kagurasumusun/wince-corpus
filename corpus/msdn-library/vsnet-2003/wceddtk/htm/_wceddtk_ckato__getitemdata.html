CKato::GetItemData

This function retrieves the 32-bit application-specific value set by SetItemData.

DWORD GetItemData (void);

Return Values

A 32-bit application-specific value associated with the specified CKato object.

Remarks

SetItemData and GetItemData allow applications to associate application-specific data to a CKato object. This could be a single value, a pointer to some structure of data, a next pointer for a linked list, and so on.
