IDE Procedures

To build the DDTK tests

  1. Launch Platform Builder on your development workstation and create a Maxall platform using Platform Wizard.
  2. Select the DDTK30 component in the Catalog and add it to your platform.
  3. Build the platform.

    The DDTK test binary files will be copied to your %_FLATRELEASEDIR% directory.
