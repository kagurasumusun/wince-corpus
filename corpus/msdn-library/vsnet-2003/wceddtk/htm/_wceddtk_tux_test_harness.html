Tux Test Harness

The Tux Test Harness (Tux) is a 32-bit, client/server test harness that executes test code modules stored in DLLs. Tux focuses on grouping tests, maintaining statistics, and the user interface (UI). This allows testers to quickly write clean, short, platform-independent test cases without the overhead required to write a complete Windows application. As a client/server application, tests can be administered and executed on both the local machine and remote machines. Multiple clients can be controlled simultaneously by a single server. The client also has the ability to run in stand-alone mode (no server required), which provides a command-line method of quickly executing test cases and test scripts.
