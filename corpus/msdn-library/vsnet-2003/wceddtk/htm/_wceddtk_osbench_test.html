OSBench Test

The Operating System Benchmark test, Osbench.exe, is used to measure the time required for the kernel to perform key operations, such as thread switching and event synchronization.

Whenever appropriate, Osbench.exe takes two measurements: one between threads of the same process (intra-process), and one between threads of separate processes (inter-process). Osbench.exe optionally writes marker values to a virtual memory address, which allows for independent hardware testing of the values.

Osbench.exe does not require any modifications to the kernel or the OEM Abstraction Layer (OAL). It should be able to run on any configuration.

The following table shows the software requirements.

Requirements Description
Osbench.exe Main test executable file.
Osbench_dll.dll Test .dll file.
