Running the Test

The following command line shows the syntax for running the test.

iltiming [test_case] [parameters]

The following table shows the test cases.

Test Case Description
-i0 No idle priority thread (same as -ni).
-i1 Type 1 idle thread: thread that spins and does nothing.
-i2 Type 2 idle thread: thread that spins and calls SetThreadPriority(IDLE).
-i3 Type 3 idle thread: two threads that alternate calling SetEvent and WaitForSingleObject with a 10-second timeout.
-i4 Type 4 idle thread: two threads that alternate calling SetEvent and WaitForSingleObject with an infinite timeout.
-sp Start a secondary process.

The following table shows the test case parameters.

Parameter Description
-p priority IST priority. Default: 0 (highest priority).
-ni No idle priority thread (same as -i0). Default: idle priority thread spins.
-ncs No cache sync after each interrupt. Default: flush cache after each interrupt.
-t interval SYSINTR_TIMING timing interval (clock ticks in milliseconds). Default: 5.
-n interrupt Number of interrupts. Default: 10.
-all Output all data. Default: output summary only.
-o file_name Output to a comma-separated file. Default: output to debugger message window.
-h Displays list of valid test cases and parameters.
