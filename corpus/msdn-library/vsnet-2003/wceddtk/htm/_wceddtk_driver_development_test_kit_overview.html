Driver Development Test Kit Overview

The Driver Development Test Kit (DDTK) is provided to assist OEMs in testing the port of their drivers to the Windows CE operating system. The test binaries and tools contained in the DDTK have been verified with the supported CPU and hardware reference platforms of Microsoft Windows CE Platform Builder. Because Microsoft has tested each DDTK test on a Maxall build, it is recommended that you use a Maxall build when running a DDTK test.

The DDTK resides in the %_WINCEROOT%\Others\Ddtk30 directory, which contains the following subdirectories:

  • Blddtk

    A ready-to-use project that allows users to quickly build the DDTK.

  • Demo

    An example of a Tux dynamic-link library (.dll) test file.

  • Ntbin

    Binary files for DDTK tests that run on the development workstation.

  • Testbin

    Binary files for the DDTK tests.

  • Testsrc

    Source code for the DDTK tests.

  • Tools

    Binary files, header files, and .lib files for the test harness.
