Microsoft Windows CE 3.0  

Display Test Cases

This test suite verifies that the display driver is working properly.

Test Case 30 - Sliding Square Test

Tests the ability of the display driver to blit. This is an automatic test; failures are logged using the Kato Logging Engine.

Test Case 31 - Bitmap Test

Tests the ability of the display driver to handle bitmaps. This test case requires user interaction, which determines its success or failure.

Test Case 32 - GDI Properties Test

Displays the GDI properties for the tester. This test case requires user interaction, which determines its success or failure.

Test Case 33 - Color Test

Displays several colors on color devices or color-converted grays on non-color devices. This test case requires user interaction, which determines its success or failure.
