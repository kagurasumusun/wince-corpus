Smart Card Database

The resource manager uses the smart card database to manage resources. This database contains a list of known smart cards, the interfaces and primary SSP of each card, and known smart card readers and reader groups. To simplify setup utilities and ensure the integrity of the smart card database, the smart card subsystem provides the following two functions: the SCardIntroduceCardType function, which introduces a smart card into the database, and the SCardForgetCardType function, which removes a smart card from the database.
