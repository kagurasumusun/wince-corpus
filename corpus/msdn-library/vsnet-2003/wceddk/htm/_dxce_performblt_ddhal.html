Microsoft Windows CE 3.0  

PerformBlt

The PerformBlt function performs the actual blt. The default implementation ignores the DDGPEStandardHeader passed in. You need to override this function if you don't want the default behavior.

virtual SCODE PerformBlt (
DDGPEBltParms *pddgpeBltParms );

Parameters

pddgpeBltParms
A pointer to a DDGPEBltParms structure.

Return Values

The return value is S_OK if the function is successful. Otherwise an error code is returned.
