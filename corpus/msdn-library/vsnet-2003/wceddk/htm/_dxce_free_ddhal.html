Free

The Free function releases memory allocated for the current heap. Free is called automatically by the SurfaceHeap destructor, so normally your driver should not need to call this function.

This function does not release the memory occupied by the actual SurfaceHeap object. For that, you should delete the SurfaceHeap object.

Void  Free (void );

Parameters

None

Return Values

None
