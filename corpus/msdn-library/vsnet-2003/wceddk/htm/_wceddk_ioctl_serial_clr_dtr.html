Microsoft Windows CE 3.0  

IOCTL_SERIAL_CLR_DTR

This control code is used by the COM_IOControl function to set the Data Terminal Ready (DTR) signal to low.

Parameters

dwOpenData
Handle returned from a call to the COM_Open function.
dwCode
Specifies this code.
pBufIn
Ignored.
dwLenIn
Ignored.
pBufOut
Ignored.
dwLenOut
Ignored.
pdwActualOut
Ignored.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Pegdser.h
