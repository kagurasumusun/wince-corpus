Microsoft Windows CE 3.0  

Sample Parallel Port Driver

Windows CE version 2.1 and later supports a parallel port driver using the IEEE1284 Compatibility mode in the forward direction and nibble mode in the reverse direction. Source code for this driver is in the \Public\Common\Oak\Drivers\Parallel directory of your Platform Builder installation. The driver itself is compiled into a file called Parallel.dll. The parallel port driver works on the CEPC reference platform. The parallel port will support a Centronics based parallel bi-directional port and the Enhanced SPP mode (bi-direction of SPP mode). The driver has limited bi-directional support, mainly to allow printer drivers to get printer ID information.
