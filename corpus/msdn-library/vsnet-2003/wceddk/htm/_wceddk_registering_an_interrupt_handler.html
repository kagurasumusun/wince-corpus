Registering an Interrupt Handler

After a device driver is loaded, the driver creates an IST and registers it with the interrupt handler. The IST is registered for one or more logical interrupts.

OEMs who use the Microsoft MDD implementation for a particular driver do not need to write code to register the interrupt; the MDD layer registers the driver for interrupts. If you write a monolithic driver, you must implement code for registering the IST of the driver with the interrupt handler. To do this, use the InterruptInitialize function to create an event and associate it with an interrupt identifier.
