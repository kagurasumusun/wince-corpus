Registry Keys for Device Drivers

This section describes the Windows CE–based registry keys related to stream interface drivers. Some registry keys must be supplied by a driver or its installation routine, whereas others are created and maintained by the Device Manager.

Some of the registry keys documented in this section may not be available on some Windows CE–based platforms. For example, a platform with no PC Card sockets does not require an HKEY_LOCAL_MACHINE\Drivers\PCMCIA\ key or any of the subkeys and values typically contained within it.
