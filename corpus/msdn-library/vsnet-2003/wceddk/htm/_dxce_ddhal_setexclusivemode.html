Microsoft Windows CE 3.0  

SetExclusiveMode

The SetExclusiveMode callback function sets a DirectDraw object to exclusive mode. 

DWORD __stdcall SetExclusiveMode(
LPDDHAL_SETEXCLUSIVEMODEDATA psemd );

Parameters

psemd
Pointer to a DDHAL_SETEXCLUSIVEMODEDATA structure that contains the information required to set a DirectDraw object to exclusive mode.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED
