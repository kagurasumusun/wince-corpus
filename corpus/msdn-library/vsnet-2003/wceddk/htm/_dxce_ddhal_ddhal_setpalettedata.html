Microsoft Windows CE 3.0  

DDHAL_SETPALETTEDATA

The DDHAL_SETPALETTEDATA structure contains information necessary to set a palette to a specific surface. This structure passes the information to the DirectDraw HAL SetPalette callback function. 

typedef struct _DDHAL_SETPALETTEDATA
{
LPDDRAWI_DIRECTDRAW_GBL      lpDD;
LPDDRAWI_DDRAWSURFACE_LCL    lpDDSurface;
LPDDRAWI_DDRAWPALETTE_GBL    lpDDPalette;
HRESULT                      ddRVal;
LPDDHALSURFCB_SETPALETTE     SetPalette;
BOOL                         Attach;
} DDHAL_SETPALETTEDATA;

Members

lpDD
Pointer to the DDRAWI_DIRECTDRAW_GBL structure that represents the DirectDraw object.
lpDDSurface
Pointer to the DDRAWI_DDRAWSURFACE_LCL structure that represents the DirectDrawSurface object.
lpDDPalette
Pointer to the DDRAWI_DDRAWPALETTE_GBL structure that represents the palette to set to the surface.
ddRVal
Passes the DirectDraw return values.
SetPalette
This member is used by DirectDraw and should not be filled in by the driver.
Attach
Indicates whether to attach this palette to the surface.
