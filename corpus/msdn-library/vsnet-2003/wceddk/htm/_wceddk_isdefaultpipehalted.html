Microsoft Windows CE 3.0  

IsDefaultPipeHalted

This function is deprecated and always returns FALSE. The default pipe never halts.

BOOL IsDefaultPipeHalted(
USB_HANDLE hDevice, 
LPBOOL lpbHalted );

Parameters

hDevice
[IN] Handle to a USB device.
lpbHalted
[OUT] Pointer to a BOOL containing TRUE if the pipe is halted, FALSE otherwise.

Return Values

FALSE.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later
