Microsoft Windows CE 3.0  

Address

The Address function returns the address of the current heap. This address is based on the address given to the constructor of the top-level SurfaceHeap object.

ADDRESS Address (void );

Parameters

None

Return Values

This function returns the address of the current heap, based on the address given to the constructor of the top-level SurfaceHeap object.
