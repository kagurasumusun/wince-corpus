Microsoft Windows CE 3.0  

DeregisterDevice

This function deregisters a registered device.

BOOL DeregisterDevice(
Handle hDevice );

Parameters

hDevice
Handle to a registered device returned from the RegisterDevice function.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

The Device Manager calls this function when a device is removed from the system or if the system has been shut down. This function calls the device driver's XXX_Deinit function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later
