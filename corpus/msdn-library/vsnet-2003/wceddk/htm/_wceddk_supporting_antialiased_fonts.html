Supporting Antialiased Fonts

Antialiased fonts work on any device whose display driver supports them. Typically, antialiasing is supported on devices that are not palettized. If the display driver supports antialiased fonts, it must notify the GDI of this capability at system startup. It does this by returning GCAPS_GRAY16 from the GetGraphicsCaps function. The FLAT and ATI sample display drivers demonstrate how to support antialiasing in 16bpp mode.
