OHC and UHC Host Controllers

The host controller, or adapter, is a hardware layer contained within the host computer — in this case, a Windows CE–based platform. The host controller converts data to the format used on the Universal Serial Bus. There are two standard host-controller designs, open host controller interface (OHCI), defined primarily by Compaq Computer Corporation and Microsoft, and universal host controller interface (UHCI), defined by Intel Corporation. OEMs are responsible for providing driver software for the particular host controller hardware present on their Windows CE–based platforms. Windows CE 2.12 and earlier supported only OHCI-based host controllers; Windows CE 3.0 and later add support for UHCI-based host controllers. Microsoft supplies sample host controller drivers for both OHCI and UHCI that an OEM can use as a basis for a host controller driver (HCD). For more information about USB host controllers, see Writing an HCD Module.
