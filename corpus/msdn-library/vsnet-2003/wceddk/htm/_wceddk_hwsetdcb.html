Microsoft Windows CE 3.0  

HWSetDCB

This function sets the device control block.

BOOL HWSetDCB(
PVOID pContext, 
LPDCB pDCB );

Parameters

pContext
Pointer to a context structure returned by the HWInit function that contains implementation-specific data describing the hardware device.
pDCB
Pointer to the device control block to set.

Return Values

TRUE indicates success. FALSE indicates failure. If an error occurs, the caller can return the error using GetLastError.

Remarks

This function is called by the MDD after the user has called the SetCommState function.

This function supports the implementation of the Serial Port Drivers PDD.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Serhw.h
