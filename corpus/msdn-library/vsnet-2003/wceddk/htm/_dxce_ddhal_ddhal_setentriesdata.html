Microsoft Windows CE 3.0  

DDHAL_SETENTRIESDATA

The DDHAL_SETENTRIESDATA structure contains information necessary to change the palette entries in a specified palette immediately. This structure passes the information to the DirectDraw HAL SetEntries callback function. 

typedef struct _DDHAL_SETENTRIESDATA
{
LPDDRAWI_DIRECTDRAW_GBL    lpDD;
LPDDRAWI_DDRAWPALETTE_GBL  lpDDPalette;
DWORD                      dwBase;
DWORD                      dwNumEntries;
LPPALETTEENTRY             lpEntries;
HRESULT                    ddRVal;
LPDDHALPALCB_SETENTRIES    SetEntries;
} DDHAL_SETENTRIESDATA;

Members

lpDD
Pointer to the DDRAWI_DIRECTDRAW_GBL structure that represents the DirectDraw object.
lpDDPalette
Pointer to the DDRAWI_DDRAWPALETTE_GBL structure that represents the DirectDrawPalette object.
dwBase
Index into the color table of the first entry to be modified.
dwNumEntries
Number of palette entries to be changed.
lpEntries
Pointer to the color table.
ddRVal
Passes the DirectDraw return values.
SetEntries
This member is used by DirectDraw and should not be filled in by the driver.
