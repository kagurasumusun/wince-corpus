Microsoft Windows CE 3.0  

WPDM_RESTART

This message is passed to the PDD_WaveProc function to instruct the audio PDD to continue playing the paused data.

Parameters

apidir
Output only; one of the following values:
Value Description
WAPI_IN Not used.
WAPI_OUT Support required for output.
dwParam1
Pointer to the head of a list of WAVEHDR structures.
dwParam2
Not used.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 1.0 and later Waveddsi.h
