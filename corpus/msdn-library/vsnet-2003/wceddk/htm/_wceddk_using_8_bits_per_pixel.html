Using 8 Bits per Pixel

The 8-bpp format ideally should use a software-changeable palette that maps 8-bit values onto 24-bit colors. For better performance, compatibility, and image quality, Microsoft recommends using a palette that contains the default Windows CE palette, although this is not required.
