The DDGPE Classes

This chapter describes the DirectDraw Graphics Primitive Engine (DDGPE) base classes, and how it has extended the GPE classes to support DirectDraw. You will be using several of these functions very often in the implementation of the DirectDraw HAL portion of your display driver, and it is important that you familiarize yourself with the information in this chapter.

The first section of this chapter, DDGPE Base Classes, summarizes the methods that are implemented by the DDGPE, DDGPESurf, and SurfaceHeap classes, from which you should derive and write your own concrete display driver. The three sections, DDGPE class, DDGPESurf class, and SurfaceHeap class, describe, in detail, the methods summarized in the first section.
