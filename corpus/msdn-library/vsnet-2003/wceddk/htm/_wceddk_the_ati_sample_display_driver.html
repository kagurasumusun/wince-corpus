Microsoft Windows CE 3.0  

The ATI Sample Display Driver

Along with the FLAT sample display driver, Windows CE 3.0 includes an ATI sample display driver. In contrast with the FLAT driver, the ATI sample display driver supports a mixture of software and hardware acceleration, but only works with the "Victoria PCI graphics development board for Windows CE", a device that uses the ATI Rage XL graphics controller chip set. For more information, see Victoria PCI Graphics Development Board for Windows CE. In addition, the ATI sample display driver supports a 8, 16, and 32 bit color depths.

The ATI sample display driver supports a number of modes, which must be chosen at compile-time. OEMs who are using this driver must set the X and Y screen resolutions as well as the color depth before building their operating system image in order to select a specific video mode. The ATI sample driver supports the following modes:

Horizontal Resolution Vertical Resolution Color Depth (bits)
640 480 8
640 480 16
640 480 32
720 480 16
720 480 32
800 600 8
800 600 16
800 600 32
1024 768 8
1024 768 16
1024 768 32
1280 1024 8
1280 1024 16
1280 1024 32

Note that Microsoft has only tested this driver at a resolution of 800x600 and a color depth of 16 bits. Also, the ATI sample driver is only a GPE-based driver. It is not a DDGPE driver, so it supports none of the 3-D and multimedia features of the ATI Rage XL chip set.
