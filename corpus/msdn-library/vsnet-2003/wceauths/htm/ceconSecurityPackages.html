Microsoft Windows CE .NET  

Security Packages

Windows CE .NET provides the following security support providers (SSPs):

  • Kerberos Security Support Provider
  • NTLM Security Support Provider

To determine which provider is supported by a specific platform, check for unique DLLs associated with each provider. The following table shows the DLLs for Kerberos, NTLM, and Schannel security providers.

Security provider Component
Kerberos Kerberos.dll, Cryptdll.dll
NTLM Ntlmssp.dll
Schannel Schannel.dll
Note   Schannel is exposed through Winsock/WinInet and not through SSPI.
