ceiling Function

Returns the smallest integer that is not less than the argument.

number ceiling(number)

Parameters

number
A number.

Return Values

Returns the smallest integer that is not less than the argument.

Remarks

The following function call returns 3.

ceiling(2.5)

The following function call returns –2.

ceiling(-2.3)

The following function call returns 4.

ceiling(4)

Requirements

None.
