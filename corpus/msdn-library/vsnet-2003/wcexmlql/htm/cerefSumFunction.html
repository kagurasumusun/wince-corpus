sum Function

Returns the sum of all nodes in the node set. Each node is first converted to a number value before summing.

number sum(node-set)

Parameters

node-set
A node-set.

Return Values

Returns the sum of all nodes in the node set. Each node is first converted to a number value before summing.

Remarks

Given the following XML document:

<root>
  <a>1</a>
  <a>3</a>
  <a>2</a>
</root>

The following function call returns 6.

sum(//a)

Requirements

None.
