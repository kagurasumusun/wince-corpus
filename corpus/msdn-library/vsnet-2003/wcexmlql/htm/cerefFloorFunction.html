floor Function

Returns the largest integer that is not greater than the argument.

number floor(number)

Parameters

number
A number.

Return Values

Returns the largest integer that is not greater than the argument.

Remarks

The following function call returns 3.

floor(3.5)

The following function call returns –2.

floor(-1.3)

The following function call returns 4.

floor(4)

Requirements

None.
