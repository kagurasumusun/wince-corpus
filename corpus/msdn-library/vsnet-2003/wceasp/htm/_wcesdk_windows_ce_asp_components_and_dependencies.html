ASP Components and Dependencies

The ASP interpreter requires the Web server to be active. The interpreter also requires the availability of Microsoft® JScript®, Visual Basic®, Scripting Edition (VBScript), or both.

The following table shows the three components in which the ASP interpreter is provided.

Component name Description Approximate size
Aspcore Required in all configurations. 35 KB
Aspcolct Collection objects. Needed to support accessing of Form, QueryString, and Cookie. 5 KB
Aspparse Supports header files and ASP Preproc directives. 5 KB

All size approximations are based on a retail version of this product that is compiled for the Windows CE PC-based hardware development platform (CEPC).

The Web server must have the Httpisapi, Httpextn, and Httpasp components included in order for ASP support to be enabled. The smallest Web server that can be built that still supports ASP functionality is approximately 28 KB. The Web server with all of the components included is approximately 55 KB.
