MIB-II Registry Settings

The HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\SNMP\RFC1156Agent registry key contains values that are used by the MIB-II extension agent to specify the value of some of its objects. The following table shows the named values.

Value : type Description
sysContact : REG_SZ Default is not set in the registry.

Name of your system contact for the SNMP agent.
sysLocation : REG_SZ Default is not set in the registry.

Location of the computer on which the agent is running.
