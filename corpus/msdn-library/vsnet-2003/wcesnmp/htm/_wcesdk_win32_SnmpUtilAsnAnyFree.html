SnmpUtilAsnAnyFree

This function frees the memory allocated for the specified AsnAny structure. 

SNMPAPI SnmpUtilAsnAnyFree(
AsnAny *pAny 
);

Parameters

pAny
Pointer to an AsnAny structure, whose memory should be freed.

Return Values

This function has no return values.

Remarks

Call the SnmpUtilAsnAnyFree function to free the memory that has been allocated by the SnmpUtilAsnAnyCopy function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Snmp.h Snmp.h Snmp.lib
