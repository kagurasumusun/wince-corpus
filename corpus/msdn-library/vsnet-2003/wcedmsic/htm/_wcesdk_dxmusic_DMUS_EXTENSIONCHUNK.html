DMUS_EXTENSIONCHUNK

This structure describes a DLS extension chunk. All extensions to the DLS file format that are unknown to DirectMusic are downloaded in this variable-size chunk.

typedef struct {
ULONG  cbSize;
ULONG  ulNextExtCkIdx;
FOURCC ExtCkID;
BYTE   byExtCk[ ];
} DMUS_EXTENSIONCHUNK;

Members

cbSize
Size of chunk.
ulNextExtCkIdx
Index, in the DMUS_OFFSETTABLE structure, of the next extension chunk. If 0, there are no more third-party extension chunks
ExtCkID
Chunk identifier.
byExtCk[ ]
Data.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dmdls.h
