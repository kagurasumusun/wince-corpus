DMUS_IO_REFERENCE

This structure contains information about a reference to another object that might be stored in another file. It is used in the reference list chunk. For more information, see Common Chunks.

typedef struct _DMUS_IO_REFERENCE {
GUID    guidClassID;
DWORD   dwValidData;
} DMUS_IO_REFERENCE;

Members

guidClassID
Class identifier.
dwValidData
Flags to indicate which data chunks for the reference are present. For a list of values, see the corresponding member of DMUS_OBJECTDESC.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dmusicf.h
