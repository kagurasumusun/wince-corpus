DirectMusic Structures

Microsoft® DirectMusic® structures are classified into the groups shown in the following table.

Structure Description
Run-Time Structures The essential group of structures used by DirectMusic applications.
File Structures Structures that are chiefly of interest to music-authoring applications.
DLS Structures Structures for applications that edit downloadable sound (DLS) data.
