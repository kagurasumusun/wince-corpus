DMUS_CHORD_PARAM

This structure is used as the pParam parameter in calls to the various GetParam and SetParam methods when the track is a chord track and rguidType is GUID_ChordParam.

typedef DMUS_CHORD_KEY DMUS_CHORD_PARAM;

For more information, see DMUS_CHORD_KEY.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dmusicf.h
