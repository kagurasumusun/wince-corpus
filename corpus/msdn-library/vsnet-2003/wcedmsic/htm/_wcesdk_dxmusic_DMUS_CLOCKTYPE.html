DMUS_CLOCKTYPE

This enumeration is used in the ctType member of the DMUS_CLOCKINFO structure.

typedef enum {
  DMUS_CLOCK_SYSTEM = 0,
  DMUS_CLOCK_WAVE   = 1
} DMUS_CLOCKTYPE;

Elements

DMUS_CLOCK_SYSTEM
Clock is the system clock.
DMUS_CLOCK_WAVE
Clock is on a wave-playback device.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dmusicc.h
