DMUS_ARTICULATION

This structure describes a DLS instrument articulation chunk. This chunk connects all available DLS articulation data in one list. For example, it might have a DLS Level 1 chunk and a manufacturer's proprietary articulation chunk. The DLS chunk is referenced by ulArt1Idx, whereas all additional articulation chunks are referenced by the list that starts with ulFirstExtCkIdx.

typedef struct {
ULONG ulArt1Idx;
ULONG ulFirstExtCkIdx;
} DMUS_ARTICULATION;

Members

ulArt1Idx
Index, in the DMUS_OFFSETTABLE structure, of the DLS articulation chunk. If 0, there is no DLS articulation.
ulFirstExtCkIdx
Index of the first third-party extension chunk. If 0, there are no third-party extension chunks associated with the articulation.

Windows CE OS .NET 4.0 and later Dmdls.h
