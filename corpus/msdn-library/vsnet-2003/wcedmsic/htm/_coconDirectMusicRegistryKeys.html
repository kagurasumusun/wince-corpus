DirectMusic Registry Settings

The registry stores information necessary to configure the system for applications and hardware devices. The registry also contains information that the operating system continually references during operation.

DLS Sound Set

This registry key identifies the location of the downloadable sound (DLS) set.

[HKEY_LOCAL_MACHINE\Software\Microsoft\DirectMusic]
    "GMFilePath"="\\WINDOWS\\WINCE_GM.DLS"

Thread Priority Tuning

You can adjust the thread priority of the DMSynth thread to tune MIDI playback performance based on the computing power of your processor with the following registry key and value.

[HKEY_LOCAL_MACHINE\Software\Microsoft\DirectMusic\SoftwareSynth]
    "ThreadPriority" = 3

The following table shows the allowable settings for ThreadPriority.

Value Description
0 Assigns a thread priority of THREAD_PRIORITY_TIME_CRITICAL
1 Assigns a thread priority of THREAD_PRIORITY_HIGHEST
2 Assigns a thread priority of THREAD_PRIORITY_ABOVE_NORMAL
3 Assigns a thread priority of THREAD_PRIORITY_NORMAL
4 Assigns a thread priority of THREAD_PRIORITY_BELOW_NORMAL
5 Assigns a thread priority of THREAD_PRIORITY_LOWEST
6 Assigns a thread priority of THREAD_PRIORITY_ABOVE_IDLE
7 Assigns a thread priority of THREAD_PRIORITY_IDLE

If the value is not specified, DirectMusic uses a normal thread priority equivalent to setting ThreadPriority to THREAD_PRIORITY_NORMAL.
