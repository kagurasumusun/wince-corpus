GUID_MuteParam

Track type Mute.
Purpose Set or retrieve channel-mapping information.
Data type (*pParam) DMUS_MUTE_PARAM. The dwPChannel member must be initialized before this structure is passed to GetParam.
mtTime The time, in track time, at which to add the mute event to the track, or the time at or directly after the mute event to be retrieved from the track.
