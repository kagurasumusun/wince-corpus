DMUS_IO_COMMAND

This structure contains information about a command event. It is used in the Command Track Chunk.

typedef struct _DMUS_IO_COMMAND {
MUSIC_TIME  mtTime;
WORD        wMeasure;
BYTE        bBeat;
BYTE        bCommand;
BYTE        bGrooveLevel;
BYTE        bGrooveRange;
} DMUS_IO_COMMAND;

Members

mtTime
Time of the command.
wMeasure
Measure that the command falls on.
bBeat
Beat that the command falls on.
bCommand
Command type. For more information, see DMUS_COMMANDT_TYPES.
bGrooveLevel
Groove level, or 0 if the command is not a groove command.
bGrooveRange
Amount by which the groove level can be randomized. For instance, if the groove level is 35 and the range is 4, the actual groove level could be anywhere from 33 through 37.

Requirements
