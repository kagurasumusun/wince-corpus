GUID_CommandParam2

Track type Command.
Purpose Set or retrieve a groove or embellishment command.
Data type (*pParam) DMUS_COMMAND_PARAM2. The mtTime member of this structure gives the actual time of the command.
mtTime The time, in track time, at which to add the command to the track, or the time at or directly after the command to be retrieved from the track.
