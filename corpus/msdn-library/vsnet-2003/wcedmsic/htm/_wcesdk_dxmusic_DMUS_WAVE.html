DMUS_WAVE

This structure defines a wave chunk for a DLS download.

typedef struct {
ULONG        ulFirstExtCkIdx;
ULONG        ulCopyrightIdx;
ULONG        ulWaveDataIdx;
WAVEFORMATEX WaveformatEx;
} DMUS_WAVE;

Members

ulFirstExtCkIdx
Index, in the DMUS_OFFSETTABLE structure, of third-party extension chunks. If 0, no extension chunks are associated with the wave.
ulCopyrightIdx
Index, in the DMUS_OFFSETTABLE structure, of copyright chunks. If 0, no copyright information is associated with the wave.
ulWaveDataIdx
Index, in the DMUS_OFFSETTABLE structure, of wave data. For more information, see DMUS_WAVEDATA.
WaveformatEx
Wave format of the chunk.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dmdls.h
