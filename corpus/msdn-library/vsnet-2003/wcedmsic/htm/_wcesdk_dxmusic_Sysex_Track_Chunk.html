Sysex Track Chunk

The sysex track chunk contains data for a Track Form. It is an array of sysex items, as shown in the following notation.

<syex-ck> -> syex(
    <DMUS_IO_SYSEX_ITEM>
    <BYTE>...  // Data
    )...
