IDirectMusicSegment::SetDefaultResolution

This method sets the default resolution for synchronization.

HRESULT SetDefaultResolution(
DWORD dwResolution
);

Parameters

dwResolution
Desired default resolution. This value can be 0 or one of the following members of the DMUS_SEGF_FLAGS enumeration: DMUS_SEGF_MEASURE, DMUS_SEGF_BEAT, and DMUS_SEGF_GRID.

Return Values

The method returns S_OK.

Remarks

This method is used primarily by secondary segments (motifs) to define whether they are synchronized to the measure, beat, or grid resolutions.
