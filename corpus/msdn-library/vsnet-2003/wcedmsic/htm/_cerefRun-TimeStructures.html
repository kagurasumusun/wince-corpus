DirectMusic Run-Time Structures

The following topics contain reference information for the following run-time structures used in DirectMusic:

  • DMUS_BUFFERDESC
  • DMUS_CHORD_KEY
  • DMUS_CHORD_PARAM
  • DMUS_CLOCKINFO
  • DMUS_COMMAND_PARAM
  • DMUS_COMMAND_PARAM2
  • DMUS_EVENTHEADER
  • DMUS_MUTE_PARAM
  • DMUS_NOTERANGE
  • DMUS_OBJECTDESC
  • DMUS_PORTCAPS
  • DMUS_PORTPARAMS
  • DMUS_RHYTHM_PARAM
  • DMUS_SUBCHORD
  • DMUS_SYNTHSTATS
  • DMUS_TEMPO_PARAM
  • DMUS_TIMESIGNATURE
  • DMUS_VERSION
  • DMUS_WAVES_REVERB_PARAMS
  • KSPROPERTY

Special categories of structures are contained in the following topics:

  • Messages
  • File Structures
  • DLS Structures
    Note   The memory for all DirectX structures must be initialized to 0 before use. In addition, all structures that contain a dwSize member must set the member to the size of the structure, in bytes, before use. The following example performs these tasks on the structure, DMUS_BUFFERDESC.
    DMUS_BUFFERDECS dmus_bufferdesc; // Cannot use this yet.
ZeroMemory(&dmus_bufferdesc, sizeof(dmus_bufferdesc));
dmus_bufferdesc.dwSize = sizeof(dmus_bufferdesc);
// Now the structure can be used.
