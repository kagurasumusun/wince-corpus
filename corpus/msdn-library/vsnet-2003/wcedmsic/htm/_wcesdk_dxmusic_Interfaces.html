DirectMusic Interfaces

The following topics contain references for the following DirectMusic interfaces:

Interface Description
IDirectMusic Provides methods for managing buffers, ports, and the master clock.
IDirectMusicBand Represents a DirectMusic band object. A band is used to set the instrument choices and mixer settings for a set of PChannels.
IDirectMusicBuffer Represents a buffer containing time-stamped data (typically in the form of MIDI messages) to be sequenced by a port.
IDirectMusicChordMap Represents a chord map. Chord maps provide the composer (represented by the IDirectMusicComposer interface) with the information needed to create chord progressions for segments to be composed.
IDirectMusicCollection Manages an instance of a DLS file.
IDirectMusicComposer Permits access to the composition engine.
IDirectMusicDownload Represents a contiguous memory chunk used for downloading to a DLS synthesizer port.
IDirectMusicDownloadedInstrument Used to identify an instrument that has been downloaded to the synthesizer.
IDirectMusicGetLoader Used by an object parsing a stream when the object needs to load another object referenced by the stream.
IDirectMusicGraph Manages the loading and message flow of tools.
IDirectMusicInstrument Represents an individual instrument from a DLS collection.
IDirectMusicLoader Used for finding, enumerating, caching, and loading objects.
IDirectMusicObject All DirectMusic objects that can be loaded from a file support the IDirectMusicObject interface so that they can work with the DirectMusic loader. New types of objects need to implement this interface.
IDirectMusicPerformance The overall manager of music playback. It is used for adding and removing ports, mapping performance channels to ports, playing segments, dispatching messages and routing them through tools, requesting and receiving event notification, and setting and retrieving music parameters. It also has several methods for getting information about timing and for converting time and music values from one system to another.
IDirectMusicPort Provides access to a DirectMusicPort object, which represents a device that sends or receives music data.
IDirectMusicPortDownload Allows an application to communicate directly with a port that supports DLS downloading and to download memory chunks directly to the port.
IDirectMusicSegment Represents a segment, a chunk of music made up of multiple tracks.
IDirectMusicSegmentState It also provides a handle to a music segment and can be used to track the playback status of the segment.
IDirectMusicStyle Provides access to a style object. The style object provides the performance with the information that it needs to play musical patterns.
IDirectMusicThru Supports thruing of music messages from a capture port to another port.
IDirectMusicTool Tools are objects that implement the IDirectMusicTool interface. When a message is sent using IDirectMusicPerformance::SendPMsg, the message flows through tools inside graphs. The tools can modify the message, make additional messages, remove messages, and so on.
IDirectMusicTrack Represents a track object. Almost everything that has to do with the definition of a segment is stored in its tracks.
IKsControl Used to get, set, or query the support of properties, events, and methods.
IReferenceClock Represents a system reference clock.
