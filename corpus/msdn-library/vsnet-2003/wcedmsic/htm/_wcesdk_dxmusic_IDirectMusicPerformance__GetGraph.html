IDirectMusicPerformance::GetGraph

This method retrieves the tool graph of a performance.

HRESULT GetGraph(
IDirectMusicGraph **ppGraph
);

Parameters

ppGraph
Address of a variable to receive a pointer to the tool graph.

Return Values

If the method succeeds, the return value is S_OK.

If it fails, the method can return one of the following error values:

DMUS_E_NOT_FOUND
E_POINTER

Remarks

The reference count of the graph is incremented.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Dmusici.h Dmusic.lib
