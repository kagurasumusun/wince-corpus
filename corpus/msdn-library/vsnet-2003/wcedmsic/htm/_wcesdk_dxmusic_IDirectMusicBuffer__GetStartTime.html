IDirectMusicBuffer::GetStartTime

This method retrieves the start time of the data in the buffer, relative to the master clock.

HRESULT GetStartTime(
LPREFERENCE_TIME prt
);

Parameters

prt
Address of a variable to receive the start time.

Return Values

If the method succeeds, the return value is S_OK.

If it fails, the method can return one of the following error values:

DMUS_E_BUFFER_EMPTY
E_POINTER

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Dmusicc.h Dmusic.lib
