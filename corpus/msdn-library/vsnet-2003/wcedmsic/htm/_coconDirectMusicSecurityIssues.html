DirectMusic Security

DirectMusic should be used with caution in environments that require high security.

DirectMusic does not feature the intimate interaction with system hardware commonly found in other multimedia features, so it does not involve the same types of security concerns as these other features. Instead, DirectMusic can introduce vulnerabilities to a platform through interaction with other software outside the control of the platform developer or applications programmer.

DirectMusic relies on downloadable sound (DLS) collections. You should make sure that your third-party DLS collections come from trusted sources and that they have been thoroughly tested.

DirectMusic uses MIDI data, a message-based format for controlling sound output. Although MIDI is not a scripting language, DirectMusic does respond to the commands embedded in the MIDI source data. Although the vast majority of MIDI material is completely harmless and poses little security risk, if you are creating an application that demands high security, you should keep in mind that your DirectMusic application will respond to commands within the MIDI file. These commands can come from third-party sources beyond your direct control.
