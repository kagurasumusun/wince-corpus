Signpost Track Chunk

The signpost track chunk contains data for a Track Form. It is organized as follows.

<sgnp-list> -> sgnp(
    <DWORD>    // Size of DMUS_IO_SIGNPOST
    <DMUS_IO_SIGNPOST>...
    )
