IPropertyPageImpl::Activate

This method creates the dialog box window for the property page. By default, the dialog box is always modeless, regardless of the value of the bModal parameter.

E_NOTIMPL is not a valid return value.

STDMETHOD ( Activate )( 
HWND hWndParent, 
LPCRECT pRect, 
BOOL bModal );

Parameters

hWndParent
[in] Window handle of the parent of the dialog box that is being created.
pRect
[in] Pointer to the RECT structure containing the positioning information for the dialog box. This method must create its dialog box with the placement and dimensions described by this rectangle, that is, origin point at (pRect->left,pRect->top) and dimensions of (pRect->right-pRect->left, pRect->bottom-pRect->top).
bModal
[in] Indicates whether the dialog box frame is modal, TRUE, or modeless, FALSE.

Return Value

This method supports the following standard return values:

S_OK
The page dialog box was created successfully.
E_POINTER
The address in pRect is not valid. For example, it may be NULL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
