CDialogImpl::DoModal

This method creates a modal dialog box. This dialog box is automatically attached to the CDialogImpl object.

int DoModal( 
HWND hWndParent = ::GetActiveWindow( ),
LPARAM dwInitParam = NULL);

Parameters

hWndParent
[in] The handle to the owner window. The default value is the return value of the GetActiveWindow Windows CE function.
dwInitParam
[in] Specifies the value to pass to the dialog box in the lParam parameter of the WM_INITDIALOG message.

Return Value

If successful, the value of the nRetCode parameter specified in the call to EndDialog; otherwise, it is –1.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h

See Also

CWindow::m_hWnd, CDialogImpl::EndDialog
