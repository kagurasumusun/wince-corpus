Microsoft Active Template Library for Windows CE  

CComAutoThreadModule::m_pApartments

Because ATL for Windows CE does not support the apartment threading model, this data member does not do anything. It is included so that future versions of ATL for Windows CE will be backward compatible.

CComApartment* m_pApartments;

Remarks

Points to an array of CComApartment objects, each of which manages an apartment in the module. The number of elements in the array is based on the m_nThreads member.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Atlbase.h
