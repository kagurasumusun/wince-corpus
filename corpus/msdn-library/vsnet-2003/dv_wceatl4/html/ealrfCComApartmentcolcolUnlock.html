CComApartment::Unlock

This method performs an atomic decrement on the lock count of the thread. Called by CComAutoThreadModule::Unlock. The lock count on the thread is used for statistical purposes.

LONG Unlock( );

Return Value

A value that may be useful for diagnostics or testing.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Atlbase.h

See Also

CComApartment::Lock, CComApartment::GetLockCount, CComApartment::m_nLockCnt
