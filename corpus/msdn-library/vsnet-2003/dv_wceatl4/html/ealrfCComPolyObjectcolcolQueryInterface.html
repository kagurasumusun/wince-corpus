CComPolyObject::QueryInterface

This method retrieves a pointer to the requested interface.

STDMETHOD( QueryInterface )( 
REFIID iid, 
void** ppvObject );

Parameters

iid
[in] The identifier of the interface being requested.
ppvObject
[out] A pointer to the interface pointer identified by iid. If the object does not support this interface, ppvObject is set to NULL.

Return Value

A standard STDMETHOD value.

Remarks

For an aggregated object, if the requested interface is IUnknown, QueryInterface returns a pointer to the IUnknown of the aggregated object and increments the reference count. Otherwise, this method queries for the interface through the CComContainedObject data member, m_contained.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
