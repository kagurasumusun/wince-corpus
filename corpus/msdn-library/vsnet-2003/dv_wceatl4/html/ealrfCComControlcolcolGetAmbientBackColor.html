CComControl::GetAmbientBackColor

This method retrieves DISPID_AMBIENT_BACKCOLOR, the ambient background color for all controls, defined by the container.

HRESULT GetAmbientBackColor( 
OLE_COLOR& BackColor );

Parameters

BackColor
[out] The property DISPID_AMBIENT_BACKCOLOR.

Return Value

One of the standard HRESULT values.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
