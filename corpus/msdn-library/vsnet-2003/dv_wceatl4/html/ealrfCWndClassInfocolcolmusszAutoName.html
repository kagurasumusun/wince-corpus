CWndClassInfo::m_szAutoName

This data member holds the name of the window class. CWndClassInfo uses m_szAutoName only if NULL is passed for the WndClassName parameter to DECLARE_WND_CLASS or DECLARE_WND_SUPERCLASS. ATL will construct a name when the window class is registered.

TCHAR m_szAutoName[13];

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Atlwin.h
