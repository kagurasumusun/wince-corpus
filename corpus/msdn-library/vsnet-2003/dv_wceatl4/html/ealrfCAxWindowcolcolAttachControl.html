Microsoft Active Template Library for Windows CE  

CAxWindow::AttachControl

This method creates a new host object if one is not already present and attaches the specified control to the host.

The control object being attached must be correctly initialized before calling AttachControl.

HRESULT AttachControl( 
IUnknown* pControl, 
IUnknown** ppUnkContainer );

Parameters

pControl
[in] A pointer to the IUnknown of the control.
ppUnkContainer
[out] A pointer to the IUnknown of the host (the AxWin object).

Return Value

A standard HRESULT value.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Atlwin.h
