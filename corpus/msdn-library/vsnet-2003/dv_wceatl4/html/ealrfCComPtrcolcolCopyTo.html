CComPtr::CopyTo

Copies the internal pointer to a target pointer. The reference count of the pointer is incremented if successful. Returns an error if ppT is NULL.

HRESULT CopyTo( 
T** ppT );

Parameters

ppT
[in] Pointer to the target pointer.

Return value

A standard HRESULT value. Can be one of the following values:

  • S_OK The pointer was copied successfully.
  • E_POINTER ppT is NULL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
