CWindow::IsWindowEnabled

This method determines whether the window is enabled for input.

BOOL IsWindowEnabled( ) 
const;

Return Values

Nonzero indicates that the window is enabled. Zero indicates that the window is not enabled.

Remarks

A child window receives input only if it is both enabled and visible.

Example

// The following example attaches an HWND to the CWindow object and 
// calls CWindow::IsWindowEnabled() to verify if the window is enabled 
// for receiving input.

CWindow myWindow;
myWindow.Attach(hWndFoo);
BOOL bEnabled = myWindow.IsWindowEnabled();

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
