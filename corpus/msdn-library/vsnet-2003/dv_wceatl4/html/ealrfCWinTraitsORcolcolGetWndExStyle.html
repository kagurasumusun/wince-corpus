CWinTraitsOR::GetWndExStyle

This method retrieves the extended styles of the CWinTraitsOR object.

Call this method to retrieve a combination, using the logical OR operator, of the extended styles of the CWinTraits object and the default styles specified by t_dwStyle.

static DWORD GetWndExStyle( 
DWORD dwExStyle );

Parameters

dwExStyle
Extended styles used for creation of a window.

Return Value

A combination of extended styles that are passed in dwExStyle and default ones specified by t_dwExStyle, using the logical OR operator

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Atlwin.h
