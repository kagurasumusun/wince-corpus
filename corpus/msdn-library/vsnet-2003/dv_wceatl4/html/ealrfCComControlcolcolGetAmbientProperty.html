CComControl::GetAmbientProperty

This method retrieves the container property specified by id.

ATL has provided a set of helper functions to retrieve specific properties. For example, GetAmbientBackColor is one of the provided helper functions for this method. These helper functions retrieve specific properties. 

HRESULT GetAmbientProperty( 
DISPID dispid, 
VARIANT& var );

Parameters

dispid
[in] Identifier of the container property to be retrieved.
var
[in] Variable to receive the property.

Return Value

One of the standard HRESULT values.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
