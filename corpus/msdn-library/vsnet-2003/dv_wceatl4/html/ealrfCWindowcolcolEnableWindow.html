CWindow::EnableWindow

This method enables or disables input to a specified window.

BOOL EnableWindow( 
BOOL bEnable = TRUE);

Parameters

bEnable
Boolean that specifies whether to enable or disable the window. If this parameter is TRUE, the window is enabled. If the parameter is FALSE, the window is disabled.

Return Values

Nonzero indicates that the window was previously disabled. Zero indicates that the window was not previously disabled. To get extended error information, call GetLastError.

Example

// The following example attaches an HWND to the CWindow object and 
// calls CWindow::EnableWindow() to enable and disable the window
// wrapped by the CWindow object.

CWindow myWindow;
myWindow.Attach(hWndFoo);

// The following call enables the window 
// CWindow::EnableWindow() takes TRUE as the default parameter.

BOOL bEnable = myWindow.EnableWindow();

if(bEnable)
{
// Do something now that the window is enabled.
...
...
// Now it is time to disable the window again.
bEnable = myWindow.EnableWindow(FALSE);
}

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
