COM_INTERFACE_ENTRY_AGGREGATE

This macro when the interface identified by iid is queried for, COM_INTERFACE_ENTRY_AGGREGATE forwards to punk. The punk parameter is assumed to point to the inner unknown of an aggregate or to NULL, in which case the entry is ignored.

COM_INTERFACE_ENTRY_AGGREGATE( 
iid, 
punk)

Parameters

iid
[in] The GUID of the interface queried for.
punk
[in] The name of an IUnknown pointer.

Remarks

Typically, you would CoCreate the aggregate in FinalConstruct.

For example:

BEGIN_COM_MAP(COuter)
   ...
   COM_INTERFACE_ENTRY_AGGREGATE(IID_IAgg, m_pUnkAgg.p)
   ...
END_COM_MAP()

See COM_INTERFACE_ENTRY Macros for remarks about COM map entries.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
