DECLARE_CLASSFACTORY_EX

This macro declares cf to be the class factory. cf must derive from CComClassFactory and override the CreateInstance method.

DECLARE_CLASSFACTORY_EX( 
cf )

Parameters

cf
[in] The name of the class that implements your class factory object.

Remarks

For example:

class CMyClass : ..., public CComCoClass< ... >
{
   ...
   DECLARE_CLASSFACTORY_EX(CMyClassFactory)
   ...
};

CComCoClass includes the DECLARE_CLASSFACTORY macro, which specifies CComClassFactory as the default class factory. However, by including the DECLARE_CLASSFACTORY_EX macro in class definition of your object, you override this default.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
