CWindow::MapWindowPoints

This method converts a set of points from the coordinate space of the specified window to the coordinate space of another window. The second of this method allows you to convert the coordinates of a RECT structure.

int MapWindowPoints( 
HWND hWndTo, 
LPPOINT lpPoint, 
UINT nCount ) 
const; 

int MapWindowPoints( 
HWND hWndTo, 
LPRECT lpRect ) 
const;

Parameters

hWndTo
Handle to the window to which points are converted. If this parameter is NULL or HWND_DESKTOP, the points are converted to screen coordinates.
lpPoint
Pointer to an array of POINT structures that contain the set of points to be converted.
nCount
Specifies the number of POINT structures in the array pointed to by lpPoint.
lpRect
Specifies the rectangle whose points are to be converted.

Return Values

If the function succeeds, the low-order word of the return value is the number of pixels added to the horizontal coordinate of each source point in order to compute the horizontal coordinate of each destination point; the high-order word is the number of pixels added to the vertical coordinate of each source point in order to compute the vertical coordinate of each destination point.

Zero indicates failure.

To get extended error information, call GetLastError.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
