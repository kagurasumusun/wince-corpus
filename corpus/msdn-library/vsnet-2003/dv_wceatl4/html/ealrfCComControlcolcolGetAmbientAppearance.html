CComControl::GetAmbientAppearance

This method retrieves DISPID_AMBIENT_APPEARANCE, the current appearance setting for the control: 0 for flat and 1 for 3D.

HRESULT GetAmbientAppearance( 
short& nAppearance );

Parameters

nAppearance
[out] The property DISPID_AMBIENT_APPEARANCE.

Return Value

One of the standard HRESULT values.

Example

HRESULT OnDraw(ATL_DRAWINFO& di)
{
short nAppearance;
RECT& rc = *(RECT*)di.prcBounds;

// Draw 3D border if AmbientAppearance is not supported or is set to 1 .
HRESULT hr = GetAmbientAppearance(nAppearance);
if (hr!=S_OK || nAppearance==1)
{
DrawEdge(di.hdcDraw, &rc, EDGE_SUNKEN, BF_RECT);
}
else
{
Rectangle(di.hdcDraw, rc.left, rc.top, rc.right, rc.bottom);
}

SetTextAlign(di.hdcDraw, TA_CENTER|TA_BASELINE);
LPCTSTR pszText = _T("ATL 3.0 : MyCtrl");
TextOut(di.hdcDraw, 
(rc.left + rc.right) / 2, 
(rc.top + rc.bottom) / 2, 
pszText, 
lstrlen(pszText));

return S_OK;
}

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
