CWinTraits::GetWndStyle

This method retrieves the standard styles of the CWinTraits object.

static DWORD GetWndStyle( 
DWORD dwStyle );

Parameters

dwStyle
Standard styles used for creation of a window. If dwStyle is zero, default style values (t_dwStyle) are returned. If dwStyle is nonzero, dwStyle is returned.

Return Value

The standard window styles of the object.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Atlwin.h
