CComControl::m_hWndCD

This data member contains a reference to the window handle associated with the control. Part of a union with m_phWndCD.

To use this data member within your control class, you must declare it as a data member in your control class. Your control class will not inherit this data member from the base class because it is declared within a union in the base class.

HWND& m_hWndCD;

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h

See Also

CComControl::CComControl, CComControl::m_phWndCD
