CComControl::GetAmbientMessageReflect

This method retrieves DISPID_AMBIENT_MESSAGEREFLECT, a flag that indicates whether the container wants to receive window messages, such as WM_DRAWITEM, as events.

HRESULT GetAmbientMessageReflect( 
BOOL& bMessageReflect );

Parameters

bMessageReflect
[out] The property DISPID_AMBIENT_MESSAGEREFLECT.

Return Value

One of the standard HRESULT values.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
