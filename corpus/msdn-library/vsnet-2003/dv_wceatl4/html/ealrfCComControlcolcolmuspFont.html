CComControl::m_pFont

This data member stores a pointer to IFontDisp font properties.

To use this data member within your control class, you must declare it as a data member in your control class. Your control class will not inherit this data member from the base class because it is declared within a union in the base class.

IFontDisp* m_pFont;

Remarks

If you choose the FONT option from the Stock Properties tab in the ATL for Windows CE Object Wizard, the wizard automatically creates this data member in your control class, creates put and get methods for the property, and supports IPropertyNotifySink to automatically notify the container when the property changes.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
