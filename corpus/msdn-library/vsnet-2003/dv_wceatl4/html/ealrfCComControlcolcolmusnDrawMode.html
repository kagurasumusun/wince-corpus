CComControl::m_nDrawMode

This data member stores the appearance of output from the control graphics methods, for example, XOR Pen or Invert Colors.

To use this data member within your control class, you must declare it as a data member in your control class. Your control class will not inherit this data member from the base class because it is declared within a union in the base class.

long m_nDrawMode;

Remarks

If you choose the DRAWMODE option from the Stock Properties tab in the ATL for Windows CE Object Wizard, the wizard automatically creates this data member in your control class, creates put and get methods for the property, and supports IPropertyNotifySink to automatically notify the container when the property changes.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h

See Also

CComControl::m_nDrawWidth, CComControl::m_nDrawStyle
