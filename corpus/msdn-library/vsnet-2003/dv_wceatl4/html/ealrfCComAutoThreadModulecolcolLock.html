Microsoft Active Template Library for Windows CE  

CComAutoThreadModule::Lock

Because ATL for Windows CE does not support the apartment threading model, this method does not do anything. It is included so that future versions of ATL for Windows CE will be backward compatible.

LONG Lock( );

Return Value

A value that may be useful for diagnostics or testing.

Remarks

Performs an atomic increment on the lock count for the module and for the current thread. CComAutoThreadModule uses the module lock count to determine whether any clients are accessing the module. The lock count on the current thread is used for statistical purposes.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Atlbase.h

See Also

CComAutoThreadModule::Unlock, CComModule::m_nLockCnt, CComApartment::m_nLockCnt
