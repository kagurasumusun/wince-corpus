CWindow::SetFocus

This method sets the input focus to the window.

HWND SetFocus( );

Remarks

In Windows CE, you cannot set the keyboard focus to a window associated with the message queue from another thread. There is one exception. If a window on one thread is the child of the window on the other thread, or if the windows are siblings of the same parent, the thread associated with one window can set the focus to the other window even though it belongs to a different thread.

Example

// The following example attaches an HWND to the CWindow object and 
// calls CWindow::SetFocus() to set the input focus.

CWindow myWindow;
myWindow.Attach(hWndFoo);
HWND hWndLeftFocus = myWindow.SetFocus();

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
