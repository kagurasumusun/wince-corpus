IDataObjectImpl::GetDataHere

This method is similar to GetData, except the client must allocate the STGMEDIUM structure. In ATL for Window CE this function does nothing and always returns E_NOTIMPL.

The IDataObjectImpl::GetDataHere method is similar to IDataObjectImpl::GetData, except that the caller must both allocate and free the medium specified in pmedium. GetDataHere renders the data described in a FORMATETC structure and copies the data into that caller-provided STGMEDIUM structure. For example, if the medium is TYMED_HGLOBAL, this method cannot resize the medium or allocate a new hGlobal.

Some media are not appropriate in a call to GetDataHere, including GDI types such as metafiles. The GetDataHere method cannot put data into a caller-provided metafile. In general, the only storage media it is necessary to support in this method are TYMED_ISTORAGE, TYMED_ISTREAM, AND TYMED_FILE.

When the transfer medium is a stream, OLE makes assumptions about where the data is being returned and the position of the seek pointer of the stream. In a GetData call, the data returned is from stream position zero through just before the current seek pointer of the stream (that is, the position on exit). For GetDataHere, the data returned is from the stream position on entry through just before the position on exit.

STDMETHOD ( GetDataHere )( 
FORMATETC* pformatetc, 
STGMEDIUM* pmedium );

Parameters

pformatetc
[in] Pointer to the FORMATETC structure that defines the format, medium, and target device to use when passing the data. Only one medium can be specified in tymed values are valid:
  • TYMED_STORAGE
  • TYMED_STREAM
  • TYMED_HGLOBAL
  • TYMED_FILE
pmedium
[out] Pointer to the STGMEDIUM structure that defines the storage medium containing the data being transferred. The medium must be allocated by the caller and filled in by IDataObjectImpl::GetDataHere. The caller must also free the medium. The implementation of this method must always supply a value of NULL for the punkForRelease member of the STGMEDIUM structure to which this parameter points.

Return Value

The ATL for Windows CE implementation returns E_NOTIMPL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
