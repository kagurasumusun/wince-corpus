CComControl::GetAmbientSupportsMnemonics

This method retrieves DISPID_AMBIENT_SUPPORTSMNEMONICS. This flag indicates whether the container supports keyboard mnemonics.

HRESULT GetAmbientSupportsMnemonics( 
BOOL& bSupportMnemonics );

Parameters

bSupportMnemonics
[out] The property DISPID_AMBIENT_SUPPORTSMNEMONICS.

Return Value

One of the standard HRESULT values.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
