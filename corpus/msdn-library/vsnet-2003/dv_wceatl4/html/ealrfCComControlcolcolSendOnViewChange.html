CComControl::SendOnViewChange

This method notifies all registered advisory sinks that the control view has changed.

HRESULT SendOnViewChange( 
DWORD dwAspect, 
LONG lindex = –1);

Parameters

dwAspect
[in] The aspect or view of the control.
lindex
[in] The portion of the view that has changed. Only –1 is valid.

Return Value

One of the standard HRESULT values.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
