CContainedWindow::m_dwMsgMapID

This data member identifies which message map will process the message for the contained window.

The default message map, declared with BEGIN_MSG_MAP, is always identified by zero. An alternate message map, declared with ALT_MSG_MAP (msgMapID), is identified by msgMapID.

m_dwMsgMapID is first initialized by the constructor and can be changed by calling SwitchMessageMap. For an example, see the CContainedWindow overview.

DWORD m_dwMsgMapID;

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
