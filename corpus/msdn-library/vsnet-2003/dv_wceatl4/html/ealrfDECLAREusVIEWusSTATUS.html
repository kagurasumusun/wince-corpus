DECLARE_VIEW_STATUS

This macro is used in the control class of an ATL ActiveX control to specify the VIEWSTATUS flags to the container.

DECLARE_VIEW_STATUS( 
statusFlags)

Parameters

statusFlags
[in] The VIEWSTATUS flags. See VIEWSTATUS for a list of flags.

Example

DECLARE_VIEW_STATUS(VIEWSTATUS_OPAQUE)

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
