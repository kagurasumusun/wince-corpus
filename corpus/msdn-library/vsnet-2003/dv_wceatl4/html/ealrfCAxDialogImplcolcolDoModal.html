CAxDialogImpl::DoModal

This method creates a modal dialog box. This dialog box is automatically attached to the CAxDialogImpl object.

int DoModal( 
HWND hWndParent = ::GetActiveWindow(), 
LPARAM dwInitParam = NULL );

Parameters

hWndParent
[in] The handle to the owner window. The default value is the return value of the GetActiveWindow Windows CE function.
dwInitParam
[in] Specifies the value to pass to the dialog box in the lParam parameter of the WM_INITDIALOG message.

Return Value

If successful, the value of the nRetCode parameter specified in the call to EndDialog; otherwise, –1.

Remarks

To create a modeless dialog box, call Create.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Atlwin.h

See Also

CAxDialogImpl::EndDialog, CAxDialogImpl::Create
