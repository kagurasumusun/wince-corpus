CComQIPtr

The CComQIPtr class is a COM interface which ATL uses along with CComPtr to manage COM interface pointers. Both classes perform automatic reference counting through calls to AddRef and Release. Overloaded operators handle pointer operations. CComQIPtr supports automatic querying of interfaces through QueryInterface.

For an example of using CComQIPtr, see the CComPtr class overview.

Do not use CComQIPtr<IUnknown, &IID_IUnknown>. Rather, use CComPtr<IUnknown>.

template< class T, 
const IID* piid  = &_uuidof ( T ) >
class CComQIPtr

Parameters

T
A COM interface specifying the type of pointer to be stored.
piid
A pointer to the IID of T.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
