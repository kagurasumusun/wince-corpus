CComControl::GetAmbientPalette

This method retrieves DISPID_AMBIENT_PALETTE, used to access the HPALETTE of the container.

HRESULT GetAmbientPalette( 
HPALETTE& hPalette );

Parameters

hPalette
[out] The property DISPID_AMBIENT_PALETTE.

Return Value

One of the standard HRESULT values.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
