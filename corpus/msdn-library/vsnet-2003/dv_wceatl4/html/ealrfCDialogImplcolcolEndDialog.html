CDialogImpl::EndDialog

This method destroys a modal dialog box.

EndDialog must be called through the dialog procedure. After the dialog box is destroyed, Windows CE uses the value of nRetCode as the return value for DoModal, which created the dialog box.

Do not call EndDialog to destroy a modeless dialog box. Call CWindow::DestroyWindow instead.

BOOL EndDialog( 
int nRetCode );

Return Value

TRUE if the dialog box is destroyed; otherwise, it is FALSE.

Parameters

nRetCode
[in] The value to be returned by CDialogImpl::DoModal.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
