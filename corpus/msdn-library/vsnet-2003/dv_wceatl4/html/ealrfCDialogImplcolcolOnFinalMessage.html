CDialogImpl::OnFinalMessage

This method is called after receiving the last message (typically WM_NCDESTROY). Note that if you want to automatically delete your object upon the window destruction, you can call delete this; here.

virtual void OnFinalMessage( 
HWND hWnd );

Parameters

hWnd
[in] A handle to the window being destroyed.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
