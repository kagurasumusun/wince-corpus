CComCompositeControl::CalcExtent

This method calculates the size in HIMETRIC units of the dialog resource used to host the composite control. The size is returned in the size parameter.

BOOL CalcExtent( 
SIZE& size );

Parameters

size
[out] A reference to a SIZE structure to be filled by this function.

Return Value

TRUE if the control is hosted by a dialog box; otherwise, it is FALSE.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
