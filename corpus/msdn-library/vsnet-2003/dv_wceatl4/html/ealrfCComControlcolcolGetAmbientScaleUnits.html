CComControl::GetAmbientScaleUnits

This method retrieves DISPID_AMBIENT_SCALEUNITS, the ambient units of the container, such as inches or centimeters, for labeling displays.

HRESULT GetAmbientScaleUnits( 
BSTR& bstrScaleUnits );

Parameters

bstrScaleUnits
[out] The property DISPID_AMBIENT_SCALEUNITS.

Return Value

One of the standard HRESULT values.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
