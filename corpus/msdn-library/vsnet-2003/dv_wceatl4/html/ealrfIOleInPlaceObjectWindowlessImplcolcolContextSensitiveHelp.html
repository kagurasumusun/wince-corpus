IOleInPlaceObjectWindowlessImpl::ContextSensitiveHelp

This method enables context-sensitive Help. 

STDMETHOD ( ContextSensitiveHelp )( 
BOOL fEnterMode );

Parameters

fEnterMode
Specifies wheter or not to enter help mode. TRUE if help mode should be entered; FALSE if it should be exited.

Return Value

The ATL implementation returns E_NOTIMPL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
