CWindow::SetCapture

This method sends all subsequent mouse input to the window.

HWND SetCapture( );

Return Values

The handle of the window that had previously captured the mouse indicates success. NULL indicates that there is no such window.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
