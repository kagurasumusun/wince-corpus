CComVariant::operator !=

This operator indicates whether or not the CComVariant object does not equal the specified VARIANT.

bool operator !=( 
const VARIANT& varSrc ) 
const;

Parameters

varSrc
[in] The CComVariant or VARIANT used to initialize the CComVariant object.

Return Value

Returns TRUE if either the value or type of varSrc is not equal to the value or type, respectively, of the CComVariant object. Otherwise, it is FALSE.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
