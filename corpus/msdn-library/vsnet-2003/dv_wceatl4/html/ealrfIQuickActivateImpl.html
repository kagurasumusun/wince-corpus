IQuickActivateImpl

This class implements the IQuickActivate interface, which helps containers avoid delays when loading controls by combining initialization in a single call.

The QuickActivate method allows the container to pass a pointer to a QACONTAINER structure that holds pointers to all the interfaces the control needs. On return, the control passes back a pointer to a QACONTROL structure that holds pointers to its own interfaces, which are used by the container. Class IQuickActivateImpl provides a default implementation of IQuickActivate and implements IUnknown by sending information to the dump device in debug builds.
