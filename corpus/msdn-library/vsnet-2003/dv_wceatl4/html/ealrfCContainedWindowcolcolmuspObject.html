CContainedWindow::m_pObject

This data member points to the containing object.

This container, whose class must derive from CMessageMap, declares the message map used by the contained window.

The m_pObject data member is initialized by the constructor. For an example, see the CContainedWindow overview.

CMessageMap* m_pObject;

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
