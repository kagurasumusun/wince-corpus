COM_INTERFACE_ENTRY_CACHED_TEAR_OFF

This macro saves the interface specific data for every instance. If the interface is not used, this lowers the overall instance size of your object.

COM_INTERFACE_ENTRY_CACHED_TEAR_OFF( 
iid, 
x, 
punk)

Parameters

iid
[in] The GUID of the tear-off interface.
x
[in] The name of the class implementing the interface.
punk
[in] The name of an IUnknown pointer. Must be a member of the class containing the COM map. Should be initialized to NULL in the constructor of the class object.

Remarks

For example:

BEGIN_COM_MAP(COuter)
   ...
   COM_INTERFACE_ENTRY_CACHED_TEAR_OFF(IID_ITearOff2, 
      CTearOff2, m_pUnkTearOff2.p)
   ...
END_COM_MAP()

See COM_INTERFACE_ENTRY Macros for remarks about COM map entries.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
