DECLARE_CLASSFACTORY_AUTO_THREAD

This macro declares CComClassFactoryAutoThread to be the class factory.

DECLARE_CLASSFACTORY_AUTO_THREAD( )

Remarks

For example:

class CMyClass : ..., public CComCoClass< ... >
{
   ...
   DECLARE_CLASSFACTORY_AUTO_THREAD( )
   ...
};

CComCoClass includes the DECLARE_CLASSFACTORY macro, which specifies CComClassFactory as the default class factory. However, by including the DECLARE_CLASSFACTORY_AUTO_THREAD macro in the class definition of your object, you override this default.

When you create objects in multiple apartments, in an out-of-proc server, add DECLARE_CLASSFACTORY_AUTO_THREAD to your class and derive your EXE module from CComAutoThreadModule.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
