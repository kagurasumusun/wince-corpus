IPersistStreamInitImpl::Load

This method loads the properties of the object from the specified stream. ATL uses the object property map to retrieve this information.

The seek pointer is set as it was in the most recent IPersistStreamInitImpl::Save method. This method can seek and read from the stream, but cannot write to it.

On exit, the seek pointer should be left in the same position as it was on exit from Save, immediately past the end of the data.

STDMETHOD ( Load )( 
LPSTREAM pStm );

Parameters

pStm
[in] IStream pointer to the stream from which the object should be loaded.

Return Value

S_OK
The object was successfully loaded.
E_OUTOFMEMORY
The object was not loaded due to a lack of memory.
E_FAIL
The object was not loaded due to some reason other than a lack of memory.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
