Microsoft Active Template Library for Windows CE  

CComControl::OnKillFocus

This method checks that the control is in-place active and has a valid control site, then informs the container the control has lost focus.

LRESULT OnKillFocus( 
UINT uMsg, 
WPARAM wParam, 
LPARAM lParam, 
BOOL& bHandled );

Parameters

uMsg
[in] The window message identifier. Not used in the default ATL implementation.
wParam
[in] A 32-bit message parameter. Not used in the default ATL implementation.
lParam
[in] A 32-bit message parameter. Not used in the default ATL implementation.
bHandled
[in, out] Flag that indicates whether the window message was successfully handled. The default is TRUE.

Return Value

Always returns 0.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h

See Also

CComControl::m_bInPlaceActive, CComControl::m_spClientSite
