DECLARE_AGGREGATABLE

This macro specifies that your object can be aggregated. CComCoClass uses this macro to specify the default aggregation model.

DECLARE_AGGREGATABLE( 
x)

Parameters

x
[in] The name of the class you are defining as aggregatable.

Remarks

To override this default, specify either the DECLARE_NOT_AGGREGATABLE or DECLARE_ONLY_AGGREGATABLE macro in your class definition. For example:

class CMyClass : public CComCoClass< .. >, ...
{
public:
   DECLARE_NOT_AGGREGATABLE(CMyClass)
   ...
};

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
