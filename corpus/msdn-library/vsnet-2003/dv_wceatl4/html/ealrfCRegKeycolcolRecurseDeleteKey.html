CRegKey::RecurseDeleteKey

This method removes the specified key from the registry and explicitly removes any subkeys. If the key has subkeys, you must call this method under Windows NT in order to delete the key. Under Windows 98, you can call DeleteSubKey to remove the key and any subkeys.

LONG RecurseDeleteKey( 
LPCTSTR lpszKey );

Parameters

lpszKey
[in] Specifies the name of the key to delete. This name must be a subkey of m_hKey.

Return Value

If successful, returns ERROR_SUCCESS; otherwise, it is an error value.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
