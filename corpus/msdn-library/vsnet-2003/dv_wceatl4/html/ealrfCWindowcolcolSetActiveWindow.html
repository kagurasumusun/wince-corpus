CWindow::SetActiveWindow

This method activates a window, but not if the application is in the background. The window will be brought into the foregound (top of Z order) if its application is in the foreground when the system activates the window.

HWND SetActiveWindow( );

Return Values

The handle to the window that was previously active indicates success. NULL indicates failure. To get extended error information, call GetLastError.

Example

// The following example attaches a HWND to the CWindow object
// and sets the window as an active window by calling 
// CWindow::SetActiveWindow which returns the HWND of the
// previously active window.

CWindow myWindow;
myWindow.Attach(hWndFoo);
HWND hWndPrev = myWindow.SetActiveWindow();

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
