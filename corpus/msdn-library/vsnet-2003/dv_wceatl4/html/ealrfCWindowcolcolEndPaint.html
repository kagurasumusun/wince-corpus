CWindow::EndPaint

This method marks the end of painting in a specified window. If the caret was hidden by BeginPaint, EndPaint restores the caret to the screen.

void EndPaint( 
LPPAINTSTRUCT lpPaint );

Parameters

lpPaint
Long pointer to a PAINTSTRUCT structure that contains the painting information retrieved by BeginPaint.

Return Value

The return value is always nonzero.

Example

// The following example attaches an HWND to the CWindow object and 
// calls CWindow::EndPaint() in the WM_PAINT handler of a 
// CWindowImpl-derived class.

LRESULT OnPaint(UINT nMsg, WPARAM wParam,LPARAM lParam, BOOL& bHandled)
{
 ...
 CWindow myWindow;
 myWindow.Attach(m_hWnd);
 PAINTSTRUCT ps;
 HDC hDC = myWindow.BeginPaint(&ps);
 //Use hDC as much as you want
 ...
 ...
 myWindow.EndPaint(&ps);
 return 0L;
}

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
