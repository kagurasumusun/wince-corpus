NOTIFY_ID_HANDLER

This macro is similar to NOTIFY_HANDLER, but maps a WM_NOTIFY message based only on the control identifier.

NOTIFY_ID_HANDLER( 
id, 
func)

Parameters

id
[in] The identifier of the control sending the message.
func
[in] The name of the message-handler function.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h

See Also

NOTIFY_CODE_HANDLER, NOTIFY_RANGE_HANDLER, COMMAND_ID_HANDLER, MESSAGE_HANDLER
