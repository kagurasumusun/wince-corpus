IDispatchImpl::_tih

This static data member is an instance of the class template parameter, tihclass, which is CComTypeInfoHolder by default. The _tih data member manages the type information for the dual interface. 

static _tihclass _tih;

Parameters

_tihclass
The class used to manage the type information for T. The default value is CComTypeInfoHolder.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
