CComContainedObject::Release

This method decrements the reference count on the owner object.

STDMETHOD_( ULONG Release )( );

Return Value

In debug builds, Release returns a value that may be useful for diagnostics or testing. In non-debug builds, Release always returns zero.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
