CWindow::SetFont

This method changes the current font of a window by sending a WM_SETFONT message to the window.

void SetFont( 
HFONT hFont, 
BOOL bRedraw = TRUE);

Parameters

hFont
[in] The handle to the new font.
bRedraw
[in] If TRUE, the default value, the window is redrawn. Otherwise, it is not.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
