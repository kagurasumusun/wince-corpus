Methods

IPersist Methods

Method Description
GetClassID Retrieves the object CLSID.

IPersistStorage Methods

Method Description
HandsOffStorage Instructs the object to release all storage objects and enter HandsOff mode. The ATL implementation returns S_OK.
InitNew Initializes a new storage.
IsDirty Checks whether data in the object has changed since it was last saved.
Load Loads the properties of the object from the specified storage.
Save Saves the properties of the object to the specified storage.
SaveCompleted Notifies an object that it can return to Normal mode to write to its storage object. The ATL implementation returns S_OK.
