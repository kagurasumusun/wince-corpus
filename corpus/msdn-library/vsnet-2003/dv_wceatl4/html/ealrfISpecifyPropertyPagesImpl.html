ISpecifyPropertyPagesImpl

This class implements the ISpecifyPropertyPages interface, which allows a client to obtain a list of CLSIDs for an object’s property pages.

Class ISpecifyPropertyPagesImpl provides a default implementation of this interface and implements IUnknown by sending information to the dump device in debug builds.

Do not expose the ISpecifyPropertyPages interface if your object does not support property pages.
