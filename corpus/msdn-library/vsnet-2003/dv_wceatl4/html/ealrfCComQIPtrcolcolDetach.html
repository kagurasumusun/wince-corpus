CComQIPtr::Detach

Returns the member pointer and detaches it from this CComQIPtr object by setting p to NULL. The pointer's reference count is not decremented.

T* Detach( );

Return Value

A pointer to the member to be detached.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
