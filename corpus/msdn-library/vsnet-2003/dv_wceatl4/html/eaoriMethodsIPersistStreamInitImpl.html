IPersist Methods

Method Description
GetClassID Retrieves the object CLSID.

IPersistStreamInit Methods

Method Description
GetSizeMax Retrieves the size of the stream needed to save data in the object. The ATL implementation returns E_NOTIMPL.
InitNew Initializes a newly created object.
IsDirty Checks whether data in the object has changed since it was last saved.
Load Loads the properties of an object from the specified stream.
Save Saves the properties of an object to the specified stream.
