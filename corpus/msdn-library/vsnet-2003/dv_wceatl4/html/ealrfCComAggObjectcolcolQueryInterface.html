CComAggObject::QueryInterface

Retrieves a pointer to the requested interface. If the requested interface is IUnknown, QueryInterface returns a pointer to the IUnknown of the aggregated object and increments the reference count. Otherwise, this method queries for the interface through the CComContainedObject member, m_contained.

HRESULT STDMETHODCALLTYPE QueryInterface( 
Q** pp ); 

STDMETHOD QueryInterface( 
REFIID iid, 
void** ppvObject );

Parameters

pp
[out] The IUnknown of the container of the aggregated object.
iid
[in] The identifier of the interface being requested.
ppvObject
[out] A pointer to the interface pointer identified by iid. If the object does not support this interface, ppvObject is set to NULL.

Return Value

A standard HRESULT value.

Remarks

The second syntax uses the STDMETHOD macro.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
