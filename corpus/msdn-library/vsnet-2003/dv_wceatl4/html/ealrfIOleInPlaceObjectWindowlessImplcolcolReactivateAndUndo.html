Microsoft Active Template Library for Windows CE  

IOleInPlaceObjectWindowlessImpl::ReactivateAndUndo

This method reactivates a previously deactivated control.

If the user chooses the Undo command before the Undo state of the object is lost, the immediate container of the object calls ReactivateAndUndo to activate the user interface, carry out the Undo operation, and return the object to the active state.

STDMETHOD ( ReactivateAndUndo )( void );

Return Value

The ATL implementation returns E_NOTIMPL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
