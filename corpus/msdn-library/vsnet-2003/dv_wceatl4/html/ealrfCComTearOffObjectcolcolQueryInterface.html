CComTearOffObject::QueryInterface

This method returns a pointer to the requested interface on either your tear-off class, or the owner class. If the interface is not there, queries for the interface on the owner object. If the requested interface is IUnknown, returns the IUnknown of the owner.

STDMETHOD( QueryInterface )( 
REFIID iid , 
void** ppvObject );

Parameters

iid
[in] The IID of the interface being requested.
ppvObject
[out] A pointer to the interface pointer identified by iid, or NULL if the interface is not found.

Return Value

A standard STDMETHOD value.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h

See Also

CComTearOffObject::AddRef, CComTearOffObject::Release
