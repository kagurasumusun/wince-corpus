Microsoft Active Template Library for Windows CE  

atlTraceFlags

These flags are used to turn on the built-in reporting features of ATL for Windows CE.

To use these flags, call AtlTrace2 and use the category you want to trace as the first parameter. 

enum atlTraceFlags;

Remarks

See ATLTRACE2 for a list of the categories and their descriptions.

Use ATLTRACE2 only for debug builds of your application.

You can filter for specific trace flags in your project by using the global functions ATL_TRACE_CATEGORY and ATL_TRACE_LEVEL. See ATLTRACE2 for a description of their use.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
