CDynamicChain::RemoveChainEntry

This method removes a message map entry from the collections.

BOOL RemoveChainEntry( 
DWORD dwChainID );

Parameters

dwChainID
[in] The unique identifier associated with the chained object and its message map. You originally define this value through a call to SetChainEntry.

Return Value

TRUE if the message map is successfully removed from the collection; otherwise, it is FALSE.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
