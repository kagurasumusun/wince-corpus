IPersistStreamInitImpl

This class implements the IPersistStreamInit interface, which allows a client to request that your object load and save its persistent data to a single stream.

Class IPersistStreamInitImpl provides a default implementation of this interface and implements IUnknown by sending information to the dump device in debug builds.
