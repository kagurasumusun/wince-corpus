PROP_PAGE

This macro enters a property page CLSID into the property map of the object. PROP_PAGE is similar to PROP_ENTRY, but does not require a property description or DISPID.

If you have already entered a CLSID with PROP_ENTRY or PROP_ENTRY_EX, you do not need to make an additional entry with PROP_PAGE.

PROP_PAGE( 
clsid)

Parameters

clsid
[in] The CLSID of a property page.

Remarks

The BEGIN_PROP_MAP macro marks the beginning of the property map; the END_PROP_MAP macro marks the end.

Example

BEGIN_PROP_MAP( CMyClass )
   PROP_PAGE( CLSID_CMyClassPropPage1 )
   PROP_PAGE( CLSID_CMyClassPropPage2 )
END_PROP_MAP( )

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
