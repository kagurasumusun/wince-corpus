CComObjectNoLock::CComObjectNoLock

This constructor creates an instance of a CComObjectNoLock object.

CComObjectNoLock( void* = NULL );

Parameters

void*
[in] This unnamed parameter is not used. It exists for symmetry with other CComXXXObjectXXX constructors.

Remarks

Unlike CComObject, does not increment the module lock count.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
