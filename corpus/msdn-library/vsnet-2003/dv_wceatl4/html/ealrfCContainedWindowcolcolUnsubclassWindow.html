CContainedWindow::UnsubclassWindow

This method restores a previously subclassed window.

HWND UnsubclassWindow(
BOOL bForce = FALSE);

Parameters

bForce
If this value is set to False (default), any changes made to the window will not be seen but only the previously subclassed window is restored.

Return Value

The handle to the window previously subclassed.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
