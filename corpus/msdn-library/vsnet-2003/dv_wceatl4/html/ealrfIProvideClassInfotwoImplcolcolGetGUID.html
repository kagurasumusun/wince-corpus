IProvideClassInfo2Impl::GetGUID

This method retrieves the GUID for the outgoing dispinterface of the object.

STDMETHOD ( GetGUID )( 
DWORD dwGuidKind, 
GUID* pGuid );

Parameters

dwGuidKind
[in] Specifies the GUID desired on return. This parameter takes a value form the GUIDKIND enumeration.
pGuid
[out] Pointer to the variable of the caller in which to store the GUID associated with dwGuidKind.

Return Value

S_OK
The GUID was successfully returned in *pGUID.
E_UNEXPECTED
An unknown error occurred.

Remarks

E_NOTIMPL is not a valid return code since it would be pointless to implement this interface without implementing this method.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
