Microsoft Active Template Library for Windows CE  

Atladvise

This global function creates a connection between the connection point of an object and the sink of a client. The sink implements the outgoing interface supported by the connection point.

ATLINLINE ATLAPI AtlAdvise( 
IUnknown* pUnkCP, 
IUnknown* pUnk, 
const IID& iid, 
LPDWORD pdw);

Parameters

pUnkCP
[in] A pointer to the IUnknown of the object the client wants to connect with.
pUnk
[in] A pointer to the IUnknown of a client.
iid
[in] The GUID of the connection point. Typically, this is the same as the outgoing interface managed by the connection point.
pdw
[out] A pointer to the cookie that uniquely identifies the connection.

Return Value

A standard HRESULT value.

Remarks

The client uses the pdw cookie to remove the connection by passing it to ATLUnadvise.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
