CComControl::FireViewChange

This method behaves differently depending on whether or not the control is active. If the control is active, this method notifies the container that you want to redraw the entire control if the control is active. If the control is inactive, this method notifies the registered advise sinks of the control that the control view has changed.

inline HRESULT FireViewChange( );

Return Value

One of the standard HRESULT values.

Example

STDMETHODIMP CSomeCtrl::put_Shape(short newVal)
{
// Store newVal in m_nShape member.
m_nShape = newVal;

// Notify container to redraw control.
FireViewChange();
return S_OK;
}

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
