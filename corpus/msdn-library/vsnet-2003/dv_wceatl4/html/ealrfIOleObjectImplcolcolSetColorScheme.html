IOleObjectImpl::SetColorScheme

This method recommends a color scheme to the control application, if any.

The IOleObjectImpl::SetColorScheme method sends the container application the recommended color palette to the object application, which is not obliged to use it.

STDMETHOD ( SetColorScheme )( 
LOGPALETTE* pLogPal );

Parameters

pLogPal
[in] Pointer to a LOGPALETTE structure that specifies the recommended palette.

Return Value

The ATL implementation returns E_NOTIMPL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
