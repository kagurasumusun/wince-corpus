DECLARE_CLASSFACTORY

This macro declares CComClassFactory to be the class factory. CComCoClass uses this macro to declare the default class factory for your object.

DECLARE_CLASSFACTORY( )

Example

class CMyClass : ..., public CComCoClass< ... >
{
   ...
   DECLARE_CLASSFACTORY()
   ...
};

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h

See Also

DECLARE_CLASSFACTORY_EX, DECLARE_CLASSFACTORY2, DECLARE_CLASSFACTORY_AUTO_THREAD, DECLARE_CLASSFACTORY_SINGLETON
