CComUnkArray

This class holds a fixed number of IUnknown pointers, each an interface on a connection point.

template< unsigned int nMaxSize >
class CComUnkArray

Parameters

nMaxSize
The maximum number of IUnknown pointers that can be held in the static array.

Remarks

CComUnkArray can be used as a parameter to the IConnectionPointImpl template class. CComUnkArray<1> is a template specialization of CComUnkArray that has been optimized for one connection point.

The CComUnkArray methods begin and end can be used to loop through all connection points. For example, both methods will loop through all connection points when an event is fired.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
