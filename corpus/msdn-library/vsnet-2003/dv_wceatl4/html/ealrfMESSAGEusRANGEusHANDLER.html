MESSAGE_RANGE_HANDLER

This macro is similar to MESSAGE_HANDLER, but maps a range of Windows messages to a single handler function.

MESSAGE_RANGE_HANDLER( 
msgFirst, 
msgLast, 
func)

Parameters

msgFirst
[in] Marks the beginning of a contiguous range of messages.
msgLast
[in] Marks the end of a contiguous range of messages.
func
[in] The name of the message-handler function.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h

See Also

COMMAND_RANGE_HANDLER, NOTIFY_RANGE_HANDLER
