IOleObjectImpl::Unadvise

This method deletes the advisory connection stored in the m_spOleAdviseHolder data member.

Normally, containers call IOleObjectImpl::Unadvise at shutdown or when an object is deleted. In certain cases, containers can call this method on objects that are running but not currently visible as a way of reducing the overhead of maintaining multiple advisory connections. The easiest way to implement this method is to delegate the call to IOleAdviseHolder::Unadvise.

STDMETHOD ( Unadvise )( 
DWORD dwConnection );

Parameters

dwConnection
[in] Contains a token of nonzero value, which was previously returned from IOleObjectImpl::Advise through the pdwConnection parameter.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
