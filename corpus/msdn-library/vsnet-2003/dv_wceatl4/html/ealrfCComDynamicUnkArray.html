Microsoft Active Template Library for Windows CE  

CComDynamicUnkArray

This class holds a dynamically allocated array of IUnknown pointers, each an interface on a connection point. CComDynamicUnkArray can be used as a parameter to the IConnectionPointImpl template class. 

class CComDynamicUnkArray

Remarks

The CComDynamicUnkArray methods begin and end can be used to loop through all connection points (for example, when an event is fired).

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
