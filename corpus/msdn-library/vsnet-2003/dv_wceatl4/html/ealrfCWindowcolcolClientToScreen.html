CWindow::ClientToScreen

The first implementation of this method converts client coordinates to screen coordinates. The second implementation of this method allows you to convert the coordinates of a RECT structure.

The ClientToScreen function replaces the client-area coordinates in the POINT structure with the screen coordiantes. The screen coordinates are relative to the upper-left corner of the screen. Note, a screen-coordinate point that is above the client area of a window has a negative y-coordinate. Similarly, a screen coordinate to the left of a client area has a negative x-coordinate.

BOOL ClientToScreen( 
LPPOINT lpPoint ) 
const; 

BOOL ClientToScreen( 
LPRECT lpRect ) 
const;

Parameters

lpPoint
[in/out] Long pointer to a POINT structure that contains the client coordinates to be converted. The new screen coordinates are copied into this structure if the function succeeds.
lpRect
Converts the client coordinates of a given rectangle on the display to screen coordinates. The CWindow::ClientToScreen member function uses the client coordinates in the RECT structure pointed to by lpRect to compute new screen coordinates; it then replaces the coordinates in the structure with the new coordinates. The new screen coordinates are relative to the upper-left corner of the system display.

Return Values

If the function succeeds, the return value is nonzero.

If the function fails, the return value is zero.

To get extended error information, call GetLastError.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
