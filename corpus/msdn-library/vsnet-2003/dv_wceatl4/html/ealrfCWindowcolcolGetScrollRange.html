CWindow::GetScrollRange

This method retrieves the scroll bar range for the specified scroll bar.

BOOL GetScrollRange( 
int nBar, 
LPINT lpMinPos, 
LPINT lpMaxPos ) 
const;

Parameters

nBar
[in] Specifies the scroll bar from which the positions are retrieved. This parameter can be one of the following values.
Value Description
SB_CTL Retrieves the positions of a scroll bar control.
SB_HORZ Retrieves the positions of the standard horizontal scroll bar in a window.
SB_VERT Retrieves the positions of the standard vertical scroll bar in a window.
lpMinPos
[out] Pointer to the integer variable that receives the minimum position.
lpMaxPos
[out] Pointer to the integer variable that receives the maximum position.

Return Values

If the function succeeds, the return value is nonzero.

If the function fails, the return value is zero. To get extended error information, call GetLastError.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
