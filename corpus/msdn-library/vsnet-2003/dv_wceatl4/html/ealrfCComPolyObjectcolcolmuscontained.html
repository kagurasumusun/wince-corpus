CComPolyObject::m_contained

This data member delegates IUnknown calls to the outer unknown if the object is aggregated, and to the IUnknown of the object if it is not aggregated. m_contained is a CComContainedObject object derived from your class.

CComContainedObject< contained > m_contained;

Parameters

contained
[in] Your class, derived from CComObjectRoot or CComObjectRootEx, as well as from any other interfaces you want to support on the object.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
