CComCachedTearOffObject::Release

This method decrements the reference count by 1 and, if the reference count is 0, deletes the CComCachedTearOffObject object

STDMETHOD_( ULONG, Release )( );

Return Value

In non-debug builds, this always returns zero. In debug builds, it returns the value that may be useful for diagnostics or testing.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
