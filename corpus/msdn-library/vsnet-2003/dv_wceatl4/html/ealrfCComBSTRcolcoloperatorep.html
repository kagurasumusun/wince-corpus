CComBSTR::operator !

This operator returns TRUE if the m_str data member is NULL; otherwise, it is FALSE.

bool operator !( );

Example

STDMETHODIMP CPolyCtl::BSTRToUpper(BSTR bstrConv)
{
// Assign bstrConv to m_str member of CComBSTR.
CComBSTR bstrTemp;
bstrTemp.Attach(bstrConv); 

// Make sure BSTR is not a NULL string.
if(!bstrTemp)
{
// Make string uppercase.
bstrTemp.ToUpper();

// Set m_str to NULL, so the BSTR is not freed.
bstrTemp.Detach(); 

return S_OK; 
}
return E_POINTER;
}

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
