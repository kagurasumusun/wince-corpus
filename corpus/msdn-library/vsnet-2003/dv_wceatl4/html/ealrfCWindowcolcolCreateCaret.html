CWindow::CreateCaret

This method creates a new shape for the system caret.

BOOL CreateCaret( 
HBITMAP hBitmap );

Parameters

hBitmap
[in] Handle to the bitmap that defines the caret shape.

Remarks

Windows CE only supports solid carets, so you should always set the hBitmap argument to NULL.

CreateCaret automatically destroys the previous caret shape, if any, regardless of the window that owns the caret. The caret is hidden until the application calls the ShowCaret function to make the caret visible.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
