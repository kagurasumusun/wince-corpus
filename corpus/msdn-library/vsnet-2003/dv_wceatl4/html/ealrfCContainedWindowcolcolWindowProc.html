CContainedWindow::WindowProc

The WindowProc method processes messages sent to the contained window.

This static method implements the window procedure. WindowProc directs messages to the message map identified by m_dwMsgMapID. If necessary, WindowProc calls DefWindowProc for additional message processing.

static LRESULT CALLBACK WindowProc( 
HWND hWnd, 
UINT uMsg, 
WPARAM wParam, 
LPARAM lParam );

Parameters

hWnd
[in] The handle to the window.
uMsg
[in] The message sent to the window.
wParam
[in] Additional message-specific information.
lParam
[in] Additional message-specific information.

Return Value

The result of the message processing.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h

See Also

BEGIN_MSG_MAP, ALT_MSG_MAP
