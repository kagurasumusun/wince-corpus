CAxWindow::SetExternalUIHandler

This method sets the externalIDocHostUIHandlerDispatch interface for the CAxWindow object.

HRESULT SetExternalUIHandler( 
IDocHostUIHandlerDispatch* pUIHandler );

Parameters

pUIHandler
[in] A pointer to an IDocHostUIHandlerDispatch interface.

Return Value

A standard HRESULT value.

Remarks

This interface is used by controls that query the host site for the IDocHostUIHandlerDispatch interface. The WebBrowser control is one control that does this.

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Atlwin.h
