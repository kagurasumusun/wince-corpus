IPointerInactiveImpl::GetActivationPolicy

This method retrieves the current activation policy for the object. 

STDMETHOD ( GetActivationPolicy )( 
DWORD *pdwPolicy );

Parameters

*pdwPolicy
[out] Pointer to the activation policy as specified by the POINTERINACTIVE enumeration values.

Return Value

The ATL implementation returns E_NOTIMPL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
