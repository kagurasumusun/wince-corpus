CComContainedObject

This class is used in classes CComAggObject, CComPolyObject, and CComCachedTearOffObject. This class implements IUnknown by delegating to the IUnknown of the owner object. The owner is either the outer object of an aggregation, or the object for which a tear-off interface is being created.

template< class Base >
class CComContainedObject : public Base

Parameters

Base
Your class, derived from CComObjectRoot or CComObjectRootEx.

Remarks

CComContainedObject calls the CComObjectRootEx OuterQueryInterface, OuterAddRef, and OuterRelease, all inherited through Base.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
