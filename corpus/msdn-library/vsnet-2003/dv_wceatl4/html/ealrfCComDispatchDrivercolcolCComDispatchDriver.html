CComDispatchDriver::CComDispatchDriver

The constructor. If there is no lp parameter, this constructor initializes the p data member to NULL. If lp points to an IDispatch interface, the constructor sets p to that interface and calls AddRef. If lp points to an IUnknown interface, the constructor calls QueryInterface for the IDispatch interface and sets p to that interface. 

CComDispatchDriver( ); 

CComDispatchDriver( 
IDispatch* lp );

CComDispatchDriver( 
IUnknown* lp );

Parameters

lp
[in] Pointer to an IDispatch or IUnknown interface.

Remarks

The destructor calls Release on p, if necessary.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
