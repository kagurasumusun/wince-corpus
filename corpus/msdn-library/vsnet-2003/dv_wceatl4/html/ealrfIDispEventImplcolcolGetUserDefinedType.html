IDispEventImpl::GetUserDefinedType

This method retrieves the basic type of a user defined type.

VARTYPE GetUserDefinedType( 
ITypeInfo *pTI, 
HREFTYPE hrt );

Parameters

pTI
[in] A pointer to the ITypeInfo interface containing the user-defined type.
hrt
[in] A handle to the type description to be retrieved.

Return Value

The type of variant.

Remarks

For more information about the ITypeInfo interface, see ITypeInfo::GetRefTypeInfo.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h.
