CWindow::SetRedraw

This method sets or clears the redraw flag by sending a WM_SETREDRAW message to the window. Call SetRedraw to allow changes to be redrawn or to prevent changes from being redrawn.

void SetRedraw( 
BOOL bRedraw = TRUE);

Parameters

bRedraw
[in] Specifies the state of the redraw flag. If TRUE, the default value, the redraw flag is set; if FALSE, the flag is cleared.

Example

// The following example attaches an HWND to the CWindow object and 
// calls CWindow::SetRedraw() to set and reset the redraw flag.

CWindow myWindow;
myWindow.Attach(hWndFoo);
myWindow.SetRedraw();   // Sets the redraw flag to TRUE.
...
...
myWindow.SetRedraw(FALSE); // Sets the redraw flag to FALSE.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
