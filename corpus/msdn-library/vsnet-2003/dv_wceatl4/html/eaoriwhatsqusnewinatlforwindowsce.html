What's New in ATL for Windows CE

New features in the ATL Library for Windows CE include the following, available in the Pocket PC SDK:

UI Support for Pocket PC

  • Full-screen, borderless windows.
  • CWindow::LoadSHMenuBar() —Creates a menubar for the Pocket PC and loads it at the bottom of the window.
  • CWindow::ShowDoneButton() —Replaces the OK button for Pocket PC applications.

Standalone Reference documentation

Documentation for this release includes a complete standalone ATL library reference for Windows CE, eliminating the previous dependency on desktop ATL documentation or the MSDN Library. Relevant material from desktop documentation has been integrated into the current Reference.
