CComDispatchDriver::operator ->

This operator returns the IDispatch interface pointer stored in the p data member.

The operation will assert if p is NULL.

IDispatch* operator ->( );

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
