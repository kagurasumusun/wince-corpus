Microsoft Active Template Library for Windows CE  

AtlAxGetControl

This global function obtains a direct interface pointer to the control contained inside a specified window given its handle. 

ATLINLINE ATLAPI AtlAxGetControl( 
HWND h, 
IUnknown** pp);

Parameters

h
[in] A handle to the window that is hosting the control.
pp
[out] The IUnknown of the control being hosted.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlhost.h
