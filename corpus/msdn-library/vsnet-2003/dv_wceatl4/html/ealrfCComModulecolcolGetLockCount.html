CComModule::GetLockCount

This method returns the current lock count on the module. CComModule uses the lock count to determine whether any clients are accessing the module. When the lock count reaches zero, the module can be unloaded.

LONG GetLockCount( );

Return Value

The lock count on the module.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h

See Also

CComModule::Lock, CComModule::Unlock, CComModule::m_nLockCnt
