IPersistPropertyBagImpl::Load

This method loads the properties of an object from a client-supplied property bag. ATL uses the object property map to retrieve this information.

STDMETHOD ( Load )( 
LPPROPERTYBAG pPropBag, 
LPERRORLOG pErrorLog );

Parameters

pPropBag
Address of the property bag for the caller, through which the object can read properties. This cannot be NULL.
pErrorLog
Address of the error log for the caller, in which the object stores any errors that occur during initialization. This can be NULL; in that case, the caller does not receive errors.

Return Value

S_OK
The object successfully initialized itself.
E_UNEXPECTED
This member was called after IPersistPropertyBagImpl::InitNew had already been called. The two initialization methods are mutually exclusive.
E_POINTER
The address in pPropBag is not valid, such as NULL, and therefore the object cannot initialize itself.
E_FAIL
The object was unable to retrieve a property that is necessary for the successful operation of the object. The object was unable to initialize itself completely.

Remarks

All property loading must take place within the Load method call because the object cannot hold the IPropertyBag pointer.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
