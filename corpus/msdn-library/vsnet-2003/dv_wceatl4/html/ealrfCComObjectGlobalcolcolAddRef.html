CComObjectGlobal::AddRef

This method increments the reference count on the Base object.

Increments the reference count of the object by 1. By default, AddRef calls _Module::Lock, where _Module is the global instance of CComModule or a class derived from it.

STDMETHOD_( ULONG AddRef )( );

Return Value

A value that may be useful for diagnostics and testing.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h

See Also

CComObjectGlobal::Release, CComModule::Lock
