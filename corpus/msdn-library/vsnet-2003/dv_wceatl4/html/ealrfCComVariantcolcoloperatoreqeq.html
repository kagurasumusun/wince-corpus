CComVariant::operator ==

This operator indicates whether the CComVariant object equals the specified VARIANT.

bool operator ==( 
const VARIANT& varSrc ) 
const;

Parameters

varSrc
[in] The CComVariant or VARIANT used to initialize the CComVariant object.

Return Value

Returns TRUE if the value and type of varSrc are equal to the value and type, respectively, of the CComVariant object. Otherwise, it is FALSE.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
