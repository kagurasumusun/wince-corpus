IDataObjectImpl::QueryGetData

This method determines whether the data object supports a particular FORMATETC structure for transferring data. In ATL for Windows CE this method does nothing and always returns E_NOTIMPL.

STDMETHOD ( QueryGetData )( 
FORMATETC* pformatetc );

Parameters

pformatetc
[in] Pointer to the FORMATETC structrue defining the format, medium, and target device to use for the query.

Return Value

The ATL implementation returns E_NOTIMPL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h

See Also

IDataObjectImpl::GetData, IDataObjectImpl::GetDataHere, IDataObjectImpl::SetData, FORMATETC
