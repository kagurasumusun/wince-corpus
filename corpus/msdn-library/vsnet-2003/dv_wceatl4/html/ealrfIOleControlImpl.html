IOleControlImpl

This class implements the IOleControl interface, which provides the features for supporting keyboard mnemonics, ambient properties, and events in control objects.

Class IOleControlImpl provides a default implementation of the IOleControl interface and implements IUnknown by sending information to the dump device in debug builds.
