IPersistStreamInitImpl::GetSizeMax

This method retrieves the size of the stream needed to save data in the object. You can call this method to determine the size and set the necessary buffers before calling the IPersistStreamInitImpl::Save method.

STDMETHOD ( GetSizeMax )( 
ULARGE_INTEGER FAR* pcbSize );

Parameters

pcbSize
Receives a pointer to the size of the stream needed to save object.

Return Value

The ATL implementation returns E_NOTIMPL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
