IDispEventImpl::GetFuncInfoFromId

This method locates the function index for the specified dispatch identifier.

HRESULT GetFuncInfoFromId( 
const IID& iid, 
DISPID dispidMember, 
LCID lcid, 
_ATL_FUNC_INFO& info );

Parameters

iid
[in] A reference to the ID of the function.
dispidMember
[in] The dispatch ID of the function.
lcid
[in] The locale context of the function ID.
info
[in] The structure indicating how the function is called.

Return Value

A standard HRESULT value.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h.
