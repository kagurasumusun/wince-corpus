CComControl::DoVerbProperties

This method displays the control property pages. By default, this is set as the action taken when the user double-clicks the control. You can change this to another action by overriding IOleObjectImpl::DoVerbPrimary.

inline HRESULT CComControlBase::DoVerbProperties( 
LPCRECT prcPosRect, 
HWND hwndParent );

Parameters

prcPosRect
[in] Pointer to the rectangle the container wants the control to draw into. Not used in the ATL implementation.
hwndParent
[in] Handle of the window containing the control.

Return Value

One of the standard HRESULT values.

Example

// The following implementation of the WM_RBUTTONDOWN message handler
// will pop up ActiveX Control PropertyPages.

LRESULT CMyControl::OnRBtnDown(UINT nMsg, WPARAM wParam,LPARAM lParam, 
BOOL& bHandled)
{
DoVerbProperties(NULL,::GetActiveWindow());
return 0L;
}

//The control message map has the corresponding entry:
BEGIN_MSG_MAP(CMyControl)
...
...
MESSAGE_HANDLER(WM_RBUTTONDOWN, OnRBtnDown)
END_MSG_MAP()

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
