CWindow::PostMessage

This method places a message in the message queue associated with the thread that created the window and returns without waiting for the thread to process the message.

BOOL PostMessage( 
UINT message, 
WPARAM wParam = 0, 
LPARAM lParam = 0);

Parameters

message
[in] Specifies the message to be posted.
wParam
[in] Specifies additional message-specific information.
lParam
[in] Specifies additional message-specific information.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Example

// The following example attaches an HWND to the CWindow object and 
// posts a WM_PAINT message to the Window wrapped by the CWindow object 
// using CWindow::PostMessage() with the default values of WPARAM and 
// LPARAM.

CWindow myWindow;
myWindow.Attach(hWndFoo);
myWindow.PostMessage(WM_PAINT);

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h
