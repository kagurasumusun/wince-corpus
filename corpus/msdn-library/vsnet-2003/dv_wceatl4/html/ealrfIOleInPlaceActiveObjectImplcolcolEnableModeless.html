IOleInPlaceActiveObjectImpl::EnableModeless

This method enables modeless dialog boxes.

IOleInPlaceActiveObjectImpl::EnableModeless is called by the top-level container to enable and disable modeless dialog boxes that the object displays. For the container to display a modal dialog box, it must first call IOleInPlaceActiveObjectImpl::EnableModeless, specifying FALSE to disable the modeless dialog box windows of the object. When the container is through displaying its modal dialog box, it calls IOleInPlaceActiveObjectImpl::EnableModeless, specifying TRUE to reenable the modeless dialog boxes of the object.

STDMETHOD ( EnableModeless )( 
BOOL fEnable );

Parameters

fEnable
[in] Enable or disable modeless dialog box windows. TRUE to enable modeless dialog box windows; FALSE to disable them.

Return Value

The ATL implementation returns S_OK.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h
