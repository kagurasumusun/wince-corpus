CComCachedTearOffObject::QueryInterface

This method retrieves a pointer to the requested interface. If the requested interface is IUnknown, it returns a pointer to the IUnknown of the CComCachedTearOffObject and increments the reference count. Otherwise, this method queries for the interface on your tear-off class using the InternalQueryInterface method inherited from CComObjectRootEx.

STDMETHOD( QueryInterface )( 
REFIID iid , 
void** ppvObject );

Parameters

iid
[in] The GUID of the interface being requested.
ppvObject
[out] A pointer to the interface pointer identified by iid, or NULL if the interface is not found.

Return Value

A standard HRESULT value.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h

See Also

CComCachedTearOffObject::AddRef, CComCachedTearOffObject::Release
