ATLTRACE

This macro sends the specified string to the dump device. The ATLTRACE macro performs the same as the AtlTrace global function, except that in release builds ATLTRACE compiles to (void) zero, while the function AtlTrace can still be used.

For example:

ATLTRACE(_T("The value of x is %d.\n"), x) 
ATLTRACE( 
exp )

Parameters

exp
[in] The string and variables to send to the eMbedded Visual C++ 4.0 output window or any application that traps these messages.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
