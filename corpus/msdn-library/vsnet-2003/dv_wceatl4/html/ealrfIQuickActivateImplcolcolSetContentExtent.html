IQuickActivateImpl::SetContentExtent

This method informs a control of how much display space the container has assigned to it. The size is specified in HIMETRIC units.

STDMETHOD ( SetContentExtent )( 
LPSIZEL pSize );

Parameters

pSize
[in] Size of the content extent.

Return Value

S_OK
The extent was successfully set.
E_FAIL
The size of the object is fixed and the extent cannot be set.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
