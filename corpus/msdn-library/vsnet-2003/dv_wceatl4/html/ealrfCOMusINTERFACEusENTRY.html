Microsoft Active Template Library for Windows CE  

COM_INTERFACE_ENTRY

This macro is the entry type you use most often.

COM_INTERFACE_ENTRY( 
x)

Parameters

x
[in] The name of an interface your class object derives from directly.

Remarks

For example:

BEGIN_COM_MAP(CThisExample)
   COM_INTERFACE_ENTRY(IDispatch)
   COM_INTERFACE_ENTRY(IBaseThisExample)
   COM_INTERFACE_ENTRY(ISupportErrorInfo)
END_COM_MAP()

See COM_INTERFACE_ENTRY Macros for remarks about COM map entries.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlcom.h
