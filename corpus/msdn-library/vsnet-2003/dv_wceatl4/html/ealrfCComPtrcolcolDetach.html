CComPtr::Detach

Returns the member pointer and detaches it from this CComPtr object by setting p to NULL. The reference count of the pointer is not decremented.

T* Detach( );

Return Value

A pointer to the member to be detached.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
