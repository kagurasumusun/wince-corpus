CWndClassInfo::pWndProc

This data member points to the window procedure of an existing window class. CWndClassInfo uses pWndProc only when you include the DECLARE_WND_SUPERCLASS macro in your class definition. In this case, CWndClassInfo registers a window class that is based on an existing class but uses a different window procedure. The existing window class window procedure is saved in pWndProc. For more information, see the CWndClassInfo overview.

WNDPROC pWndProc;

Requirements

Windows CE versions: 2.10 and later
Header file: Declared in Atlwin.h
