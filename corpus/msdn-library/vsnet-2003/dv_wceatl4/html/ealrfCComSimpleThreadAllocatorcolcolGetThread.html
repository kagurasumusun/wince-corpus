CComSimpleThreadAllocator::GetThread

This method selects a thread by specifying the next thread in the sequence. You can override GetThread to provide a different method of selection or to use the pApt parameter.

GetThread is called by CComAutoThreadModule::CreateInstance.

int GetThread( 
CComApartment* pApt, 
int nThreads );

Parameters

pApt
[in] Not used in the default implementation of ATL.
nThreads
[in] The maximum number of threads in the EXE module.

Return Value

An integer between zero and nThreads –1. Identifies one of the threads in the EXE module.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlbase.h
