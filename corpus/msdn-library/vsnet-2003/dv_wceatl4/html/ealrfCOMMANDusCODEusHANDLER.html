COMMAND_CODE_HANDLER

This macro is similar to COMMAND_HANDLER, but maps a WM_COMMAND message based only on the notification code.

COMMAND_CODE_HANDLER( 
code, 
func)

Parameters

code
[in] The notification code.
func
[in] The name of the message-handler function.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlwin.h

See Also

COMMAND_ID_HANDLER, COMMAND_RANGE_HANDLER, MESSAGE_HANDLER, NOTIFY_CODE_HANDLER
