IPropertyPageImpl::GetPageInfo

This method fills the structure specified by pPageInfo with information contained in the data members. GetPageInfo loads the string resources associated with m_dwDocString, m_dwHelpFile, and m_dwTitle.

E_NOTIMPL is not a valid return value.

STDMETHOD ( GetPageInfo )( 
PROPPAGEINFO *pPageInfo );

Parameters

*pPageInfo
[out] Pointer to the caller-allocated PROPPAGEINFO structure in which the property page stores its page information. All allocations stored in this structure become the responsibility of the caller.

Return Value

This method supports the standard return values E_OUTOFMEMORY and E_UNEXPECTED, as well as the following:

S_OK
The structure was successfully filled.
E_POINTER
The address in *pPageInfo is not valid. For example, it may be NULL.

Requirements

Windows CE versions: 2.0 and later
Header file: Declared in Atlctl.h

See Also

IPropertyPageImpl::m_dwHelpContext, IPropertyPageImpl::m_size
