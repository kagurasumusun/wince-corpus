EAP Registry Values Example

The following example shows possible data for some of the EAP registry values.

HKEY_LOCAL_MACHINE\System\CurrentControlSet\Services\Rasman\PPP\EAP\40
    Path               (REG_EXPAND_SZ)  sample.dll 
    FriendlyName       (REG_SZ)         Sample EAP Protocol 
    ConfigUIPath       (REG_EXPAND_SZ)  sample.dll 
    IdentityPath       (REG_EXPAND_SZ)  sample.dll
    InteractiveUIPath  (REG_EXPAND_SZ)  sample.dll 
    RequireConfigUI    (REG_DWORD)      1
    ConfigCLSID        (REG_SZ)   {0000031A-0000-0000-C000-000000000046}
