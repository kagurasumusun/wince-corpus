ISAPI Extensions and Filters

ISAPI extensions provide a means of scripting for the Web server. ISAPI extensions are implemented as DLLs that are loaded into the same process as the Web server.

ISAPI filters are DLLs that are loaded into the process of the Web server when it is started, and they stay in memory until the Web server shuts down. After they are loaded, ISAPI filters can be configured to receive a number of special filter-event notifications that occur with each HTTP request that the Web server receives and with each response that the Web server generates in return.

A sample ISAPI page has been added for Windows CE that allows you to browse and administer your device remotely. The sample includes a process viewer, registry editor, and a file system browser. The source for this sample is located at %_WINCEROOT%\Public\Servers\SDK\Samples\HTTP\Sysadmin.

To include the ISAPI sample page, select the Web Administration ISAPI Extension feature from the catalog, which sets SYSGEN_SYSISAPI=1 and rebuild your platform. This will include the sysisapi.dll on your device and will add the following information to the registry.

[HKEY_LOCAL_MACHINE\COMM\HTTPD\VROOTS\SysAdmin]
    @="\windows\sysisapi.dll"
    "a"=dword:2

This will create a Web page on your device that displays the ISAPI sample. The site requires administrator privileges when you attempt to access it so you must have the appropriate user and password lists included on your device. See Web Server Authentication and Permissions for more information on creating user lists and access rights.

Note   The ISAPI sample page allows you to remotely manage and configure a device. It must be used appropriately and should be updated as necessary for your device and target audience. The sample code has been included to show how these features can be used. A sufficiently strong password and appropriate user rights must be set to avoid unauthorized access. Failure to follow these guidelines will result in a significant security risk to your device.
