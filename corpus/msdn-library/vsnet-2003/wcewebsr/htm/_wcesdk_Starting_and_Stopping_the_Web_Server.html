Starting and Stopping the Web Server

If you make changes to the Web server registry settings, it is necessary to stop the Web server and restart it to make the changes take effect.

The IsEnabled registry value is checked only when the Web server is initially loaded. If the registry value is set to 0, the Web server does not start. Note that changing this value to 0 while the Web server is running has no effect. You also must stop the Web server to make it stop accepting connections.

It is recommended that the Web server and all services that are not device drivers be run from Services.exe instead of Device.exe. Services.exe is specifically designed to host network services such as the Web server and telnet server. If Services.exe is on a system, the Web server can be administered through the Services.exe administration. See the Services.exe documentation for more information.
