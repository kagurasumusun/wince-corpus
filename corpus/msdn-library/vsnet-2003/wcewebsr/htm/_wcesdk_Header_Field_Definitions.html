Web Server Header-Field Definitions

The Web server can use the following header fields.

  • Method
  • Http-Version
  • URI
  • Date
  • Connection
  • Authorization
  • If-Modified-Since
  • Content-Length
  • Content-Type

All other headers are parsed, but they are ignored.
