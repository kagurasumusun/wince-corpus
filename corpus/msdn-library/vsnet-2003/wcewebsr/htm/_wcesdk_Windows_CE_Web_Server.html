Web Server (HTTPD)

The Microsoft® Windows® CE–based HTTP server (Web server) facilitates the use of the Internet for communication between a Windows CE–based device and network printers, scanners, and other shared equipment. The Web server applications send Hypertext Markup Language (HTML) pages to a requesting browser. Users only need to have an Internet connection and a browser to be able to make use of the Web server functionality.

If your platform supports the Windows CE Web server, it may also support the use of Active Server Pages (ASP), depending on the configuration chosen for the device by the device manufacturer. For more information on ASP, see the Active Server Pages section of the documentation. However, this section may not be present if your device does not support ASP.

Note   The Web server does not provide proxy services.
