ISAPI Extension ServerSupportFunction Implementation

Windows CE does not support the following options for the dwHSERequest parameter. If the ServerSupportFunction function receives them, it returns FALSE and sets ERROR_INVALID_PARAMETER as the last error.

  • HSE_REQ_ABORTIVE_CLOSE
  • HSE_REQ_GET_CERT_INFO_EX
  • HSE_REQ_GET_SSPI_INFO
  • HSE_REQ_REFRESH_ISAPI_ACL
  • HSE_REQ_DONE_WITH_SESSION
  • HSE_REQ_ASYNC_READ_CLIENT
  • HSE_REQ_GET_IMPERSONATION_TOKEN
  • HSE_REQ_IO_COMPLETION
  • HSE_REQ_TRANSMIT_FILE
