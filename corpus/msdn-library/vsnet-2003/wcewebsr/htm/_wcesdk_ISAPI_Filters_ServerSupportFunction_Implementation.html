ISAPI Filters ServerSupportFunction Implementation

Windows CE does not support the following options for sfReq. If the ServerSupportFunction function receives them, it returns FALSE and sets ERROR_INVALID_PARAMETER as the last error.

  • SF_REQ_GET_CONNID
  • SF_REQ_GET_PROPERTY
  • SF_REQ_NORMALIZE_URL
  • SF_REQ_SET_PROXY_INFO
