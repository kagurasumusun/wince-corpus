GetServerVariable Implementation

This information applies to the GetServerVariable function for ISAPI extensions and ISAPI filters and to the ASP-page Request.ServerVariables object.

Windows CE does not support the following options for the lpszVariableName parameter. If the ServerSupportFunction function receives them, it returns FALSE and sets ERROR_INVALID_INDEX as the last error.

  • ALL_HTTP
  • APPL_PHYSICAL_PATH
  • CERT_FLAGS
  • CERT_KEYSIZE
  • CERT_SERIALNUMBER
  • LOGON_USER
  • INSTANCE_META_PATH
  • APPL_MD_PATH
  • CERT_COOKIE
  • CERT_ISSUER
  • CERT_SECRETKEYSIZE
  • CERT_SUBJECT
  • INSTANCE_ID
    Note   The Web server ignores the members of the structure that the script can modify in the GetFilterVersion function.
