Touch Screen (Stylus) Registry Settings

The touch screen registry stores information necessary to configure the behavior of the touch screen. The touch screen registry entries are located under the HKEY_LOCAL_MACHINE\HARDWARE\DEVICEMAP\TOUCH registry key. The following code example shows the touch screen registry entries.

[HKEY_LOCAL_MACHINE\HARDWARE\DEVICEMAP\TOUCH]
    "DriverName"="touch.dll"
    "CalibrationData"

You can also modify the distance in which two stylus taps occur to be considered a double-tap by setting the HKEY_CURRENT_USER\ControlPanel\Pen\DblTapDist registry entry. When the user taps the stylus on the touch screen, the operating system (OS) establishes a rectangle centered on the location of the stylus tap. The DblTapDist registry entry controls the size of this rectangle. When the user taps the stylus a second time, the OS determines whether the second tap is still within the rectangle and calculates the time elapsed since the first tap. If the second tap is still within the rectangle and the elapsed time does not exceed the time-out value for a double-tap, the OS generates a double-tap message. The default value for the DblTapDist registry entry is 20 pixels. The following code example shows how to set this registry entry.

[HKEY_CURRENT_USER\ControlPanel\Pen]
    "DblTapDist"=dword:14
