CTimeSpan::operator =

This overloaded assignment operator copies the source CTimeSpan (timeSpanSrc) object into this CTimeSpan object.

const CTimeSpan& operator =(
const CTimeSpan& timeSpanSrc );

Example

// example for CTimeSpan::operator =
CTimeSpan ts1;
CTimeSpan ts2( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ts1 = ts2;
ASSERT( ts1 == ts2 );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
