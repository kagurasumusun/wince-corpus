COleSafeArray::GetLBound

This method retrieves the lower bound for any dimension of a safe array.

On error, this method throws a COleException.

void GetLBound(
DWORD dwDim,
long* pLBound );

Parameters

dwDim
Specifies the array dimension for which to get the lower bound.
pLBound
Specifies a pointer to the location to return the lower bound.

Example

COleSafeArray saMatrix;
DWORD numElements[] = {10, 5};

// Creates a two dimensional safearray of type VT_I2
// with size 10x5 elements, with all indices starting at zero,default.
saMatrix.Create(VT_I2, 2, numElements);

long lLBound;

// Get lower bound for 1st dimension.
saMatrix.GetLBound(1, &lLBound);

ASSERT(lLBound == 0);

// Get lower for the second dimension.
saMatrix.GetLBound(2, &lLBound);

ASSERT(lLBound == 0);

COleSafeArray saVector;
SAFEARRAYBOUND rgsabounds[] = { {5, 1} };

// Creates a one dimensional safearray of type VT_I1
// with size five elements, with the index starting at one.
saVector.Create(VT_I1, 1, rgsabounds);

// Get lower bound for the first dimension.
saVector.GetLBound(1, &lLBound);

ASSERT(lLBound == 1);
