CFile::GetPosition

This method obtains the current value of the file pointer, which can be used in subsequent calls to Seek.

virtual DWORD GetPosition( ) 
const;

Return Value

The file pointer as a 32-bit doubleword.

Example

// Example for the CFile::GetPosition method.
extern CFile cfile;
ULONGLONG dwPosition = cfile.GetPosition();

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
