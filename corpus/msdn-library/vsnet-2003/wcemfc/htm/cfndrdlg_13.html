CFindReplaceDialog::ReplaceCurrent

This method determines whether the user wants the current word to be replaced.

BOOL ReplaceCurrent( )
const;

Return Value

Nonzero if the user has requested that the currently selected string be replaced with the replace string; otherwise, it is zero.
