CCeDBDatabase::GetSortProps

This method retrieves the current sort order of the database.

void GetSortProps(
int *pnSize,
CCeDBProp *pSortProps )
const;

Parameters

pnSize
Specifies the pointer to an integer. On return, the integer contains the number of sort properties assigned to the database. This is the number of sort properties in pSortProps.
pSortProps
Specifies the pointer to an array of at least CEDB_MAXSORTORDER properties. On return, the array contains the sort properties assigned to the database. The array should be at least CEDB_MAXSORTORDER properties to ensure that all sort properties associated with the database can be accommodated. In MFC for Windows CE 2.10, CEDB_MAXSORTORDER is defined as four.

Return Values

None.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
