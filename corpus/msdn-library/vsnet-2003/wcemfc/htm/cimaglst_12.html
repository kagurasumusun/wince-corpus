CImageList::DragLeave

This method unlocks the window specified by pWndLock and hides the drag image, allowing the window to be updated.

static BOOL PASCAL DragLeave(
CWnd* pWndLock );

Parameters

pWndLock
Specifies the pointer to the window that owns the drag image.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

See the example for CImageList::EndDrag.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
