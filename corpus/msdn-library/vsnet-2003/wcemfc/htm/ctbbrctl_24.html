CToolBarCtrl::GetRect

This method retrieves the bounding rectangle for a specified toolbar button.

This method implements the behavior of the Windows CE message TB_GETRECT

BOOL GetRect(
int nID,
LPRECT lpRect )
const;

Parameters

nID
Specifies the button identifier.
lpRect
Specifies a pointer to a RECT structure to receive the bounding rectangle information.

Return Value

TRUE if it is successful; otherwise, it is FALSE.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
