CSpinButtonCtrl::SetBuddy

This method sets the buddy window for a spin button control. 

CWnd* SetBuddy(
CWnd* pWndBuddy );

Parameters

pWndBuddy
Specifies a pointer to the new buddy window.

Return Value

Returns a pointer to the previous buddy window.

Remarks

In Windows CE, spin button controls can only be buddies, with edit controls and button controls. The only values you can pass in the pWwndBuddy parameter to the CSpinButtonCtrl::SetBuddy method are a pointer to an edit control or NULL.

Requirements
