CList::RemoveTail

This method removes the element from the tail of the list and returns a pointer to it.

You must ensure that the list is not empty before calling RemoveTail. If the list is empty, then the Debug version of the Microsoft Foundation Class Library for Windows CE asserts. Use IsEmpty to verify that the list contains elements.

TYPE RemoveTail( );

Parameters

TYPE
Specifies the template parameter specifying the type of elements in the list.

Return Value

The element that was at the tail of the list is returned.

Example

// Define myList.
CList<CString,CString&> myList;

// Add two elements to the list.
myList.AddTail(CString("ABC"));
myList.AddTail(CString("123"));

// Remove the tail element and verify the list.
// NOTE: once the tail is removed, the number of
// elements in the list will be one.
CString strTail = myList.RemoveTail();
ASSERT((CString("123") == strTail) && (myList.GetCount() == 1) && (CString("ABC") == myList.GetTail()));

Requirements
