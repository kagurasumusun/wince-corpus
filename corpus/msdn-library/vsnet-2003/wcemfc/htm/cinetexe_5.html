CInternetException::m_dwError

This data member is the error that caused the exception. This error value may be a system error code, found in Winerror.h, or an error value from Wininet.h.

DWORD m_dwError

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxinet.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
