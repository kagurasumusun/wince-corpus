CControlBar::GetBarStyle

This method determines which control bar styles settings are set for the control bar. It cannot be used to get window styles.

DWORD GetBarStyle( );

Return Value

The current CBRS_ (control bar styles) settings for the control bar. See CControlBar::SetBarStyle for the complete list of available styles.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
