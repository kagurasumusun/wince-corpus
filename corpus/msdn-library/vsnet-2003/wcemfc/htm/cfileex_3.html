CFileException::OsErrorToException

This method retrieves an enumerator that corresponds to a specified lOsError value. If the error code is unknown, then the method returns CFileException::generic.

static int PASCAL OsErrorToException(
LONG lOsError );

Parameters

lOsError
Specifies an operating-system-specific error code.

Return Value

Enumerated value that corresponds to a given operating-system error value.

Example

// Example for the CFileException::OsErrorToException method.
ASSERT( CFileException::OsErrorToException( 5 ) ==
                  CFileException::accessDenied );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
