CSpinButtonCtrl::SetPos

This method sets the current position for a spin button control.

int SetPos(
int nPos );

Parameters

nPos
Specifies the new position for the control. This value must be in the range specified by the upper and lower limits for the control.

Return Value

Returns the previous position.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
