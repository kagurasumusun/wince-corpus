CListCtrl::SetSelectionMark

This method sets the selection mark in a list view control.

The SetSelectionMark method implements the behavior of the Windows CE macro, ListView_SetSelectionMark. You can use this macro or send the LVM_SETSELECTIONMARK message explicitly.

int SetSelectionMark(
int iIndex );

Parameters

iIndex
The zero-based index of the first item in a multiple selection.

Return Value

The previous selection mark, or –1 if there was no previous selection mark.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

// Set the selection mark to the first item only if no other item is
// selected.
if (pmyListCtrl->GetSelectionMark() == –1)
      pmyListCtrl->SetSelectionMark(0);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
