CTreeCtrl::HitTest

This method determines the location of the specified point relative to the client area of a tree view control.

When this method is called, the pt parameter specifies the coordinates of the point to test. The method returns the handle of the item at the specified point or NULL if no item occupies the point. In addition, the pFlags parameter contains a value that indicates the location of the specified point.

HTREEITEM HitTest(
CPoint pt,
UINT* pFlags = NULL )
const;

HTREEITEM HitTest(
TVHITTESTINFO* pHitTestInfo )
const;

Parameters

pt
Specifies the client coordinates of the point to test.
pFlags
Specifies a pointer to an integer that receives information about the results of the hit test. It can be one or more of the values listed under the flags member in the Remarks section.
pHitTestInfo
Specifies the address of a TVHITTESTINFO structure that contains the position to hit test and that receives information about the results of the hit test.

Return Value

The handle of the tree view item that occupies the specified point or NULL if no item occupies the point.

Example

// The pointer to my tree control.
extern CTreeCtrl* pmyTreeCtrl;
// The point to test.
extern CPoint myPoint;

// Select the item that is at the point myPoint.
UINT uFlags;
HTREEITEM hItem = pmyTreeCtrl->HitTest(myPoint, &uFlags);

if ((hItem != NULL) && (TVHT_ONITEM & uFlags))
{
  pmyTreeCtrl->Select(hItem, TVGN_CARET);
}
