CCeDBDatabase::Delete

This method removes the database from the object store, closing it if necessary.

BOOL Delete( );

Return Values

TRUE indicates that the operation succeeded. FALSE indicates that the database could not be deleted. To get extended error information, call GetLastError.

Remarks

The CCeDBDatabase::Delete method does not delete the CCeDBDatabase object, but, after calling this method, you cannot call any other methods on the database, except for Create and Exists.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
