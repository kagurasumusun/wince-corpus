COleObjectFactory::Register

This method registers the object factory with the system DLLs. This method is usually called by CWinApp::InitInstance when the application is launched.

virtual BOOL Register( );

Return Value

Nonzero if the factory is successfully registered; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
