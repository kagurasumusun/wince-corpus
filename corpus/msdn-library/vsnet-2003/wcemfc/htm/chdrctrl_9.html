CHeaderCtrl::GetItemCount

This method retrieves a count of the items in a header control.

int GetItemCount( )
const;

Return Value

Returns the number of header control items if successful; otherwise, it is –1.

Example

See the example for CHeaderCtrl::DeleteItem.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
