CComboBox::GetDroppedControlRect

This method retrieves the screen coordinates of the visible list box of a drop-down combo box.

void GetDroppedControlRect(
LPRECT lprect )
const;

Parameters

lprect
Pointer to the RECT structure that is to receive the coordinates.

Example

// This example moves a combo box so that the upper-left
// corner of the combo box is at a specific point.

// The pointer to a combo box.
extern CComboBox* pmyComboBox;
// The point to move the combo box to.
extern CPoint myPoint;

CRect r;

pmyComboBox->GetDroppedControlRect(&r);

pmyComboBox->GetParent()->ScreenToClient(&r);
r.OffsetRect(myPoint - r.TopLeft());
pmyComboBox->MoveWindow(&r);
