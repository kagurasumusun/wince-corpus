COleControl::InitializeIIDs

This method informs the base class of the interface identifiers (IID) the control will use.

void InitializeIIDs(
const IID* piidPrimary,
const IID* piidEvents );

Parameters

piidPrimary
Specifies a pointer to the interface ID of the primary dispatch interface of the control.
piidEvents
Specifies a pointer to the interface ID of the event interface of the control.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
