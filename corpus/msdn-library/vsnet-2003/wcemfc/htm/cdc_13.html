CDC::DrawEdge

This method draws the edges of a rectangle in the specified style.

BOOL DrawEdge (
LPRECT lpRect, 
UINT nEdge, 
UINT nFlags );

Parameters

lpRect
Pointer to a RECT structure that contains the logical coordinates of the rectangle.
nEdge
The type of inner and outer edge to draw. This parameter must be a combination of one inner-border flag and one outer-border flag.
nFlags
The flags that specify the type of border to draw. For diagonal lines, the BF_RECT flags specify the end point of the vector bounded by the rectangle parameter.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Remarks

Windows CE does not support the EDGE_BUMP flag in the nEdge parameter.

You cannot specify the BF_BOTTOMLEFT, BF_TOPLEFT, or BF_TOPRIGHT flags in the nFlags parameter.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
