CCeDocList Methods

Construction methods

Method Description
CCeDocList Constructs a CCeDocList object
Create Creates and initializes the list associated with the CCeDocList object

Operations Methods

Method Description
DeleteSelection Deletes selected items
DisableUpdate Disables updating of doclist.
EnableUpdate Enables updating of doclist.
GetCommandBar Returns pointer to the CCeCommandBar created and owned by the doclist window
GetFilterIndex Gets current file filter selection, for example, for setting the current filter for a combo box
GetItemCount Gets a count of items
GetNextItem Gets the next item in doclist.
GetNextWaveFile Selects the next .wav file
GetPrevWaveFile Selects the previous .wav file
GetSelectCount Gets the number of items selected
GetSelectedPathname Gets the pathname associated with the selected item
ReceiveIR Receives infrared
Refresh Refreshes doclist.
RenameMoveSelectedItems Displays the Rename/Move dialog box for selected items
SelectItem Selects the item associated with the pathname
SendEMail Sends e-mail
SendIR Sends infrared
SetFilterIndex Indicates file filter has been changed, for example, user has changed settings in an Options dialog box
SetFolder Sets a folder
SetItemState Changes the state of an item in the doclist.
SetSelectedPathname Causes the item associated with the path to be selected during the next refresh
SetSelection Selects an item by index
SetSortOrder Sorts doclist
Update Refreshes doclist but does not restore the selection
