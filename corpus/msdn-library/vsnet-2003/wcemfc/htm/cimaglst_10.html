CImageList::Detach

This method detaches an image list object from a CImageList object. This method returns a handle to the image list object.

HIMAGELIST Detach( );

Return Value

A handle to an image list object.

Example

See the example for CImageList::Attach.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
