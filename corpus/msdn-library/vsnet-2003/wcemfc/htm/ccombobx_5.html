CComboBox::CompareItem

This method is called by the framework to determine the relative position of a new item in the list box portion of a sorted owner-drawn combo box.

virtual int CompareItem(
LPCOMPAREITEMSTRUCT lpCompareItemStruct );

Parameters

lpCompareItemStruct
A long pointer to a COMPAREITEMSTRUCT structure.

Return Value

Indicates the relative position of the two items described in the COMPAREITEMSTRUCT structure. It can be any of the values shown in the following table:

Value Description
–1 Item 1 sorts before item 2.
0 Item 1 and item 2 sort the same.
1 Item 1 sorts after item 2.

See CWnd::OnCompareItem for a description of COMPAREITEMSTRUCT.

Remarks

By default, this method does nothing. If you create an owner-drawn combo box with the LBS_SORT style, override this method to assist the framework in sorting new items added to the list box.

Example

// CMyComboBox is an owner-drawn combo box derived from CComboBox. This
// example compares two items using strcmp to sort items in reverse
// alphabetical order. The combo box control was created with the
// following code:
//  pmyListBox->Create(
//    WS_CHILD|WS_VISIBLE|WS_BORDER|WS_HSCROLL|WS_VSCROLL|
//    LBS_SORT|LBS_MULTIPLESEL|LBS_OWNERDRAWVARIABLE,
//    myRect, pParentWnd, 1);
//
int CMyComboBox::CompareItem(LPCOMPAREITEMSTRUCT lpCompareItemStruct)
{
  ASSERT(lpCompareItemStruct->CtlType == ODT_COMBOBOX);
  LPCTSTR lpszText1 = (LPCTSTR) lpCompareItemStruct->itemData1;
  ASSERT(lpszText1 != NULL);
  LPCTSTR lpszText2 = (LPCTSTR) lpCompareItemStruct->itemData2;
  ASSERT(lpszText2 != NULL);

  return strcmp(lpszText2, lpszText1);
}
