CTreeCtrl::SetIndent

This method sets the width of indentation for a tree view control and redraw the control to reflect the new width.

void SetIndent(
UINT nIndent );

Parameters

nIndent
Specifies the width, in pixels, of the indentation. If nIndent is less than the system-defined minimum width, the new width is set to the system-defined minimum.

See the example for CTreeCtrl::GetIndent.
