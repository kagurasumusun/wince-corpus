CSplitterWnd::GetRowCount

This method retrieves the current number of rows in the splitter window. For a static splitter window, this will also be the maximum number of rows.

int GetRowCount( )
const;

Return Value

Returns the current number of rows in the splitter window. For a static splitter window, this will also be the maximum number of rows.

Requirements
