CArray::GetUpperBound

This method retrieves the current upper bound of this array. Because array indexes are zero-based, this function returns a value one less than GetSize.

int GetUpperBound( )
const;

Remarks

The condition GetUpperBound( ) = –1 indicates that the array contains no elements.
