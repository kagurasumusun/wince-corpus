CDocument::SetTitle

This method specifies the title of the document, that is, the string displayed in the title bar of a frame window. Calling this method updates the titles of all frame windows that display the document.

virtual void SetTitle(
LPCTSTR lpszTitle );

Parameters

lpszTitle
Points to the string to be used as the title of the document.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
