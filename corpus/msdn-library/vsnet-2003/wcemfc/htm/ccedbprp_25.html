CCeDBProp::SetULong

This method sets the value of an unsigned long integer property. 

void SetULong(
ULONG ulVal );

Parameters

ulVal
Specifies the value of the property.

Remarks

You can only call SetULong on a property of the type CCeDBProp::Type_ULong.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
