CInternetFile::Close

This method closes a CInternetFile and frees any of its resources. If the file was opened for writing, there is an implicit call to Flush to assure that all buffered data is written to the host. You should call Close when you have finished using a file.

virtual void Close( );

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxinet.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
