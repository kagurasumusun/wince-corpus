CRect::operator +=

This operator moves a CRect object by the specified offsets. The x and y (or cx and cy) values of the parameter are added to CRect.

Use the third overloaded implementation of this operator to inflate CRect by the number of units specified in each member of the parameter.

void operator +=(
POINT point ); 

void operator +=(
SIZE size ); 

void operator +=(
LPCRECT lpRect );

Parameters

point
Specifies a POINT structure or CPoint object that specifies the number of units to move the rectangle.
size
Specifies a SIZE structure or CSize object that specifies the number of units to move the rectangle.
lpRect
Points to a RECT structure or CRect object that contains the number of units to inflate each side of CRect.

Example

CRect  rect1(100, 235, 200, 335);
CPoint  pt(35, 65);
CRect  rect2(135, 300, 235, 400);

rect1 += pt;

ASSERT(rect1 == rect2);

Requirements
