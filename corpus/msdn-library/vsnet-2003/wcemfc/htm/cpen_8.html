CPen::operator HPEN

This casting operator gets the attached Windows CE GDI handle to the CPen object. This operator supports direct use of an HPEN object.

operator HPEN( )
const;

Return Value

If successful, it is a handle to the Windows GDI object represented by the CPen object; otherwise, it is NULL.

Example

// Create a solid red pen of width 2.
CPen myPen(PS_SOLID, 2, RGB(255,0,0));

// Get the handle of the pen object.
HPEN hPen = (HPEN) myPen;

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
