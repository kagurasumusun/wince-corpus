CDocument::ReleaseFile

This method is called by the framework to release a file, making it available for use by other applications. If bAbort is TRUE, ReleaseFile calls CFile::Abort, and the file is released. CFile::Abort will not throw an exception.

Override this method to require an action by the user before the file is released.

virtual void ReleaseFile(
CFile* pFile,
BOOL bAbort );

Parameters

pFile
Specifies a pointer to the CFile object to be released.
bAbort
Specifies whether the file is to be released by using either CFile::Close or CFile::Abort. FALSE if the file is to be released using CFile::Close; TRUE if the file is to be released using CFile::Abort.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
