COlePropertyPage::OnInitDialog

This method is called by the framework when the dialog box of the property page is initialized. Override this method if any special action is required when the dialog box is initialized. The default implementation calls CDialog::OnInitDialog and returns FALSE.

virtual BOOL OnInitDialog( );

Return Value

The default implementation returns FALSE.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
