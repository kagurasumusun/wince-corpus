CWnd::GetCaretPos

This method retrieves the client coordinates of the current position of the caret as a CPoint object.

The caret position is given in the client coordinates of the CWnd window.

static CPoint PASCAL GetCaretPos( );

Return Value

CPoint object containing the position coordinates of the caret.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
