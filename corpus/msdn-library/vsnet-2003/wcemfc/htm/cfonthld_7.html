CFontHolder::InitializeFont

This method initializes a CFontHolder object. Call this function after constructing a CFontHolder object.

If pFontDispAmbient is not NULL, the CFontHolder object is connected to a clone of the IFont interface used by the ambient Font property of the container.

If pFontDispAmbient is NULL, a new Font object is created either from the font description pointed to by pFontDesc or, if pFontDesc is NULL, from a default description.

void InitializeFont(
const FONTDESC* pFontDesc = NULL
LPIDISPATCH pFontDispAmbient = NULL );

Parameters

pFontDesc
Pointer to a font description structure, FONTDESC, that specifies the characteristics for the font.
pFontDispAmbient
Pointer to the ambient Font property of the container.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
