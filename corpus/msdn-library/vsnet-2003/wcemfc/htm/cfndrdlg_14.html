CFindReplaceDialog::SearchDown

This method determines whether the user wants the search to proceed in a downward direction.

BOOL SearchDown( )
const;

Return Value

Nonzero if the user wants the search to proceed in a downward direction; zero if the user wants the search to proceed in an upward direction.
