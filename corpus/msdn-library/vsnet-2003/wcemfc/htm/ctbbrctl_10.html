CToolBarCtrl::CheckButton

This method checks or clears a specified button in a toolbar control. When a button has been checked, it appears to have been pressed. To change more than one button state, consider calling SetState instead.

BOOL CheckButton(
int nID,
BOOL bCheck = TRUE );

Parameters

nID
Specifies the command identifier of the button to check or clear.
bCheck
Specifies TRUE to check the button, or FALSE to clear it.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
