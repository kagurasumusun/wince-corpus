CCeDBProp::SetUShort

This method sets the value of an unsigned short integer property. 

void SetUShort(
USHORT uiVal );

Parameters

uiVal
Specifies the value of the property.

Remarks

You can only call SetUShort on a property of the type CCeDBProp::Type_UShort.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
