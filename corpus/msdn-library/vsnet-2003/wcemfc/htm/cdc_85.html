CDC::SetOutputDC

This method sets the output device context, m_hDC.

virtual void SetOutputDC(
HDC hDC );

Parameters

hDC
The Windows device context.

Remarks

This method can only be called when a device context is not attached to the CDC object. This method sets m_hDC but does not attach the device context to the CDC object.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
