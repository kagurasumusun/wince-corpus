Date/Time

CTime and CTimeSpan

MFC for Windows CE includes the general-purpose time classes CTime and CTimeSpan. These classes encapsulate most of the functionality associated with the ANSI-standard time library.

Not supported in MFC for Windows CE version 3.0 are the CTime methods Format, FormatGmt, GetAsSystemTime, and GetGmtTm. All other methods and operators of desktop CTime are present, as are those of CTimeSpan.

COleDateTime and COleDateTimeSpan

COleDateTime and COleDateTimeSpan encapsulate functionality for the Automation DATE data type.

All methods and operators for these Automation classes that appear in the desktop version are included in version 3.0 of MFC for Windows CE, with the following exceptions:

  • COleDateTime::Format() has only one form (rather than the three available on the desktop)
  • COleDateTimeSpan::Format is not supported.
