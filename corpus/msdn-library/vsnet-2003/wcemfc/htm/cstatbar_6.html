CStatusBar::DrawItem

This method is called by the framework when a visual aspect of an owner-drawn status bar changes.

virtual void DrawItem(
LPDRAWITEMSTRUCT );

Parameters

lpDrawItemStruct
A pointer to a DRAWITEMSTRUCT structure that contains information about the type of drawing required.

Remarks

The itemAction member of the DRAWITEMSTRUCT structure defines the drawing action that is to be performed. Override this method to implement drawing for an owner-draw CStatusBar object. The application should restore all graphics device interface (GDI) objects selected for the display context supplied in lpDrawItemStruct before the termination of this method.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
