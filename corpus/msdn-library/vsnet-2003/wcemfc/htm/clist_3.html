CList::AddHead

This method adds a new element or list of elements to the head of this list. The list can be empty before the operation.

POSITION AddHead(
ARG_TYPE newElement ); 

void AddHead(
CList* pNewList );

Parameters

ARG_TYPE
Specifies the template parameter specifying the type of the list element. The list element can be a reference.
newElement
Specifies the new element.
pNewList
Specifies a pointer to another CList list. The elements in pNewList will be added to this list.

Return Value

The first version returns the POSITION value of the newly inserted element.

Example

// Declarations of the variables are used in the example.
CList<CString,CString&> myList;
CList<CString,CString&> myList2;

// There are two versions of CList::AddHead: one adds a single
// element to the front of the list, the other version adds another list
// to the front.

// This version adds the string "ABC" to the front of myList.
// myList is a list of Cstrings, that is, defined as CList<CString,CString&>.
myList.AddHead(CString("ABC"));

// This version adds the elements of myList2 to the front of myList.
myList.AddHead(&myList2);
