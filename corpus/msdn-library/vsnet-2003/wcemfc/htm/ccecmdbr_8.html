CCeCommandBar::InsertMenuBar

This method inserts a menu bar into the command bar. 

CMenu* InsertMenuBar(
UINT nResourceID,
int nButton = CMDBAR_END )

CMenu* InsertMenuBar(
LPCTSTR lpszMenuName, 
int nButton = CMDBAR_END);

Parameters

nResourceID
Specifies the integer to convert to a menu resource.
nButton
Specifies the zero-based index of a button in the command bar.
lpszMenuName
Specifies the long pointer to the null-terminated string that contains the name of menu to insert.

Return Values

A pointer to the menu identified by nButton, or NULL if the function fails.

Remarks

The implementations of this method identify the menu to add, either by resource identifier number or by name, respectively.

This method inserts the menu to the left of the button identified by nButton.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Wcebar.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
