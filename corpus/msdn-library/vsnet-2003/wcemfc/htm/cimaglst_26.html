CImageList::operator HIMAGELIST

This operator is used to retrieve the attached handle of the CImageList object. This operator is a casting operator, which supports direct use of an HIMAGELIST object.

operator HIMAGELIST()
const;

Return Value

If successful, a handle to the image list represented by the CImageList object; otherwise, it is NULL.

Example

// Pointer to the myImageList.
extern CImageList* pmyImageList;

// Get the safe handle to the image list.
HIMAGELIST hImageList = *pmyImageLIst;

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
