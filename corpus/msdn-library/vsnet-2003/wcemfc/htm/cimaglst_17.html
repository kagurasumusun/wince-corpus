CImageList::EndDrag

This method ends a drag operation. To begin a drag operation, use the BeginDrag method.

static void PASCAL EndDrag( );

Example

// Pointer to the myImageList.
extern CImageList* pmyImageList;
// A pointer to the window in which to drag the image.
extern CWnd* pmyWnd;

// Terminate the drag image, usually called from WM_LBUTTONUP.
pmyImageList->DragLeave(pmyWnd);
pmyImageList->EndDrag();

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
