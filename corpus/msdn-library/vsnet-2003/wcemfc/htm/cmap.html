CMap

The CMap class is a dictionary collection class that maps unique keys to values. Once you have inserted a key-value pair, element, into the map, you can efficiently retrieve or delete the pair using the key to access it. You can also iterate over all the elements in the map.

template<
class KEY,
class ARG_KEY,
class VALUE,
class ARG_VALUE >
class CMap : public CObject

Parameters

KEY
Specifies the class of the object used as the key to the map.
ARG_KEY
Specifies the data type used for KEY arguments; usually a reference to KEY.
VALUE
Specifies the class of the object stored in the map.
ARG_VALUE
Specifies the data type used for VALUE arguments; usually a reference to VALUE.

Remarks

A variable of type POSITION is used for alternate access to entries. You can use a POSITION to remember an entry and to iterate through the map. Alhough this iteration seems sequential by key value, it is not. The sequence of retrieved elements is indeterminate.

Certain methods of this class call global helper functions that must be customized for most uses of the CMap class. The following list of global helper functions can be called indirectly by methods within this class:

  • CompareElements
  • ConstructElements
  • CopyElements
  • DestructElements
  • DumpElements
  • HashKey
  • SerializeElements

CMap incorporates the IMPLEMENT_SERIAL macro to support serialization and dumping of its elements. Each element is serialized in turn if a map is stored to an archive, either with the overloaded insertion (<<) operator or with the Serialize method.

If you need a diagnostic dump of the individual elements in the map, the keys and the values, you must set the depth of the dump context to one or greater.

When a CMap object is deleted, or when its elements are removed, both the keys and values are also removed.

Map class derivation is similar to list derivation.
