COleDateTimeSpan::GetHours

This method retrieves the hour portion of this date/time-span value.

The return values from this function range between – 23 and 23.

long GetHours( )
const;

Return Value

Returns the hours portion of this date/time-span value.

Remarks

For other functions that query the value of a COleDateTimeSpan object, see the following methods:

  • GetDays
  • GetMinutes
  • GetSeconds
  • GetTotalDays
  • GetTotalHours
  • GetTotalMinutes
  • GetTotalSeconds

Example

COleDateTimeSpan ts( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ASSERT( ts.GetHours() == 1 );

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
