CInternetSession::GetContext

This method gets the context value for an Internet or application session.

DWORD GetContext( )
const;

Return Value

Returns the application-defined context identifier.

Remarks

OnStatusCallback uses the context identifier returned by GetContext to report the status of a particular application. For example, when a user activates an Internet request that involves returning status information, the status callback uses the context identifier to report status on that particular request. If the user activates two separate Internet requests that both involve returning status information, OnStatusCallback uses the context identifiers to return status about their corresponding requests. Consequently, the context identifier is used for all status callback operations, and it is associated with the session until the session is ended.
