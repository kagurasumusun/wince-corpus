CGdiObject::Attach

This method attaches a Windows CE GDI object to a CGdiObject object.

BOOL Attach(
HGDIOBJ hObject );

Parameters

hObject
Specifies a HANDLE to a Windows GDI object. For example, HPEN or HBRUSH.

Return Value

Nonzero if attachment is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
