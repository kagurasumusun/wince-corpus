CCeDBProp::SetBlob

This method sets the value of a binary large object (BLOB) property. 

void SetBlob(
CEBLOB blob,
UINT nMode = Copy);

Parameters

blob
Initialized CEBLOB structure.
nMode
Specifies whether to allocate memory to store the object passed in CEBLOB structure. It is one of the following values:
Value Description
CCeDBProp::Copy Creates a copy of the data buffer pointed to by the lpb member of the CEBLOB structure passed in the blob parameter. This memory is released when the CCeDBProp object is destroyed.
CCeDBProp::NoCopy The property maintains a pointer to the same data buffer pointed to by Ipb member of the CEBLOB structure passed in the blob parameter, but doesn't own it. The memory is not released when the CCeDBProp object is destroyed.

Remarks

The blob parameter must be properly initialized.

You can only call SetBlob on a property of the type CCeDBProp::Type_Blob.

Requirements
