CWinApp::DoMessageBox

This method is called by the framework to implement a message box for the AfxMessageBox global function.

Do not call this method to open a message box; use AfxMessageBox instead.

Override this method to customize your application-wide processing of AfxMessageBox calls.

virtual int DoMessageBox(
LPCTSTR lpszPrompt,
UINT nType,
UINT nIDPrompt );

Parameters

lpszPrompt
Specifies the address of text in the message box.
nType
Specifies the message box style.
nIDPrompt
Specifies an index to a Help context string.

Return Value

Returns the same values as AfxMessageBox.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
