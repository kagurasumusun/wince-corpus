COlePropertyPage::GetControlStatus

This method to determine whether the user has modified the value of the property page control with the specified resource identifier.

BOOL GetControlStatus(
UINT nID );

Parameters

nID
Specifies the resource ID of a property page control.

Return Value

TRUE if the control value has been modified; otherwise, it is FALSE.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
