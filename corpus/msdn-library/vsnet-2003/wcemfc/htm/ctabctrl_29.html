CTabCtrl::SetMinTabWidth

This method implements the behavior of the Windows CE message TCM_SETMINTABWIDTH. 

int SetMinTabWidth(
int cx );

Parameters

cx
Specifies the minimum width to be set for a tab control item. If this parameter is set to –1, the control will use the default tab width.

Return Value

Returns the previous minimum tab width.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
