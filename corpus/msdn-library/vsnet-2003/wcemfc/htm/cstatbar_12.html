CStatusBar::GetStatusBarCtrl

This method allows direct access to the underlying common control.

CStatusBarCtrl& GetStatusBarCtrl( )
const;

Return Value

Contains a reference to a CStatusBarCtrl object.

Remarks

Use GetStatusBarCtrl to take advantage of the functionality of the Windows CE status-bar common control, and to take advantage of the support CStatusBarCtrl provides for status-bar customization. For example, by using the common control, you can specify a style that includes a sizing grip on the status bar, or you can specify a style to have the status bar appear at the top of the client area in a parent window.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
