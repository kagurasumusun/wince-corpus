CDC::IsPrinting

This method determines whether the device context is being used for printing.

BOOL IsPrinting( )
const;

Return Value

Nonzero if the CDC object is a printer device context; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
