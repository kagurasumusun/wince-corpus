CListCtrl::GetStringWidth

This method determines the minimum column width necessary to display all of a specified string.

The returned width takes into account the current font and column margins in the control, but not the width of a small icon.

int GetStringWidth(
LPCTSTR lpsz )
const;

Parameters

lpsz
Specifies the address of a null-terminated string whose width is to be determined.

Return Value

The width, in pixels, of the string pointed to by lpsz.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

CString strColumn;
int nWidth;

// Insert six columns in the list view control. Make the width of
// the column be the width of the column header plus 50%.
for (int i=0;i < 6;i++)
{
  strColumn.Format(TEXT("column %d"), i);
  nWidth = 3*pmyListCtrl->GetStringWidth(strColumn)/2;
  pmyListCtrl->InsertColumn(i, strColumn, LVCFMT_LEFT, nWidth);
}

Requirements
