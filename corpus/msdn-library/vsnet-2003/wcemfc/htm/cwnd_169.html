CWnd::SendChildNotifyLastMsg

This method is called by the framework to provide a notification message to a child window, from the parent window, so the child window can handle a task.

SendChildNotifyLastMsg send the current message to the source if it is a message that is reflected.

BOOL SendChildNotifyLastMsg(
LRESULT* pResult = NULL );

Parameters

pResult
Specifies the result generated by the child window to be returned by the parent window.

Return Value

Nonzero if the child window has handled the message sent to its parent; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
