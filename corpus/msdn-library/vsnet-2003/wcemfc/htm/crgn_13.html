CRgn::RectInRegion

This method determines whether any part of the rectangle specified by lpRect is within the boundaries of the region stored in the CRgn object.

BOOL RectInRegion(
LPCRECT lpRect )
const;

Parameters

lpRect
Points to a RECT structure or CRect object. The RECT structure has the following form: 
typedef struct tagRECT {
   int left;
   int top;
   int right;
   int bottom;
} RECT;

Return Value

Nonzero if any part of the specified rectangle lies within the boundaries of the region; otherwise, it is zero.

Requirements
