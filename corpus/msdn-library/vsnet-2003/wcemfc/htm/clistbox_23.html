CListBox::GetSelCount

This method retrieves the total number of selected items in a multiple-selection list box.

int GetSelCount( )
const;

Return Value

The count of selected items in a list box. If the list box is a single-selection list box, the return value is LB_ERR.

Example

See the example for CListBox::GetSelItems.

// Pointer to the myListBox.
extern ClistBox* pmyListBox;

// Get the indexes of all the selected items.
int nCount = pmyListBox->GetSelCount();
CArray<int, int> aryListBoxSel;

aryListBoxSel.SetSize(nCount);
pmyListBox->GetSelItems(nCount, aryListBoxSel.GetData());

// Dump the selection array.
#ifdef _DEBUG
  afxDump << aryListBoxSel;
#endif
