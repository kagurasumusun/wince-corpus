CWnd::ValidateRect

This method validates the client area within the specified rectangle by removing the rectangle from the update region of the window. The CWnd::BeginPaint method automatically validates the entire client area. The ValidateRect method should be called if a portion of the update region needs to be validated before WM_PAINT is next generated.

Windows CE continues to generate WM_PAINT messages until the current update region is validated.

void ValidateRect (
LPCRECT lpRect );

Parameters

lpRect
Points to a CRect object or RECT structure that contains client coordinates of the rectangle to be removed from the update region. If lpRect is NULL, the entire window is validated.

Remarks

In Windows CE, you have to pass a valid RECT pointer in the lpRect parameter. Windows 98 and Windows NT validate the entire window if the lpRect parameter is set to NULL. This is not supported in Windows CE.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
