COleControl::PostModalDialog

This method notifies the container that a modal dialog box has been closed. You must call this function so that the container can enable any top-level windows disabled by PreModalDialog. This function should be paired with a call to PreModalDialog.

void PostModalDialog(
HWND hWndParent = NULL );

Parameters

hWndParent
Specifies a handle to the parent window of the control.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
