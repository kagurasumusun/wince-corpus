CString::AllocSysString

This method allocates a new Automation–compatible string of the type BSTR and copies the contents of the CString object into it, including the terminating null character. A CMemoryException is thrown if insufficient memory exists. This method is normally used to return strings for Automation.

BSTR AllocSysString ( )
const;

Return Value

Points to the newly allocated string.

Remarks

In the rare case the client receiving the returned string does not free memory in the string, you might have to free it yourself by using ::SysFreeString.

You must link with OLECE300D.LIB to obtain this function if you are using MFC in a shared library and building in debug mode. You can cause the linker to get OLECE300D.LIB automatically by including <Afxdisp.h> in your Stdafx.h file.

IF you use this method, be sure to include <afxdisp.h> in your stdafx.h file, to ensure the correct runtime DLL linkage.

For more information about OLE allocation functions in Windows CE, see ::SysAllocString.

Example

CString str("Hockey is Best!");
BSTR bstr = str.AllocSysString();

// bstr now contains "Hockey is best", and can be
// passed to any OLE function requiring a BSTR.
// Normally, the function receiving the BSTR will
// free the string when it is done using it.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
