CSliderCtrl::ClearSel

This method clears the current selection in a slider control.

void ClearSel(
BOOL bRedraw = FALSE );

Parameters

bRedraw
Specifies the redraw flag. If this parameter is TRUE, the slider is redrawn after the selection is cleared; otherwise, the slider is not redrawn.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
