COleObjectFactory::VerifyLicenseKey

This method verifies that the container is licensed to use the control. The default version calls COleObjectFactory::GetLicenseKey to get a copy of the control license string and compares it with the string in bstrKey. If the two strings match, the function returns a nonzero value; otherwise, it returns zero.

You can override this function to provide customized verification of the license.

virtual BOOL VerifyLicenseKey(
BSTR bstrKey );

Parameters

bstrKey
A BSTR storing the container version of the license string.

Return Value

Nonzero if the run-time license is valid; otherwise, it is zero.

Remarks

The method COleObjectFactory::VerifyUserLicense verifies the design-time license.

Requirements
