COleObjectFactory::UpdateRegistryAll

This method registers all of the object factories of the application with the system registry. This method is usually called by CWinApp::InitInstance when the application is launched.

static BOOL PASCAL UpdateRegistryAll(
BOOL bRegister = TRUE );

Parameters

bRegister
Determines whether the object factory of the control class is to be registered.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
