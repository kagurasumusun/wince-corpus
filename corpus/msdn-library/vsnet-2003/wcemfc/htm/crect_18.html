CRect::Size

This method retrieves the size of a CRect object. The cx and cy members of the return value contain the height and width of the CRect object. Either the height or width can be negative.

The rectangle must be normalized or this method may fail. You can call NormalizeRect to normalize the rectangle before calling this method.

CSize Size( )
const;

Return Value

A CSize object that contains the size of CRect.

Example

CRect rect(10, 10, 50, 50);
CSize sz = rect.Size();
ASSERT(sz.cx == 40 && sz.cy == 40);
