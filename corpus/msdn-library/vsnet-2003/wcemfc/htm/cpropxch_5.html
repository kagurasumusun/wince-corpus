CPropExchange::ExchangeProp

This method exchanges a property between the control and a storage medium. The CArchivePropExchange::ExchangePersistentProp, CResetPropExchange::ExchangePersistentProp, and CPropsetPropExchange::ExchangePersistentProp methods override this pure virtual method.

If the property is being loaded from the medium to the control, the value of the value is retrieved from the medium and stored in the object pointed to by pvProp. If the property is being stored to the medium, the value of the object pointed to by pvProp is written to the medium.

virtual BOOL ExchangeProp(
LPCTSTR pszPropName,
VARTYPE vtProp,
void* pvProp,
const void* pvDefault = NULL ) = 0;

Parameters

pszPropName
Specifies the name of the property being exchanged.
vtProp
Specifies a symbol specifying the type of the property being exchanged. Possible values are:
Symbol Property Type
VT_I2 short
VT_I4 long
VT_BOOL BOOL
VT_BSTR CString
VT_CY CY
VT_R4 float
VT_R8 double

pvProp
Specifies a pointer to the value of the property.
pvDefault
Specifies a pointer to a default value for the property.

Return Value

Nonzero if the exchange was successful; zero if it is unsuccessful.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
