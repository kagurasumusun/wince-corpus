CTreeCtrl::Expand

This method expands or collapses the list of child items, if any, associated with the specified parent item.

BOOL Expand(
HTREEITEM hItem,
UINT nCode );

Parameters

hItem
Specifies the handle of the tree item being expanded.
nCode
Specifies a flag indicating the type of action to be taken. This flag can have one of the following values:
  • TVE_COLLAPSE   Collapses the list.
  • TVE_COLLAPSERESET   Collapses the list and removes the child items.
  • TVE_EXPAND   Expands the list.
  • TVE_TOGGLE   Collapses the list if it is currently expanded or expands it if it is currently collapsed.

Return Value

Nonzero if it is successful; otherwise, it is zero.
