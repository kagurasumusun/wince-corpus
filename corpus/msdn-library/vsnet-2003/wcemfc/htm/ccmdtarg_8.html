CCmdTarget::IsResultExpected

This method determines whether a client expects a return value from its call to an automation method. 

BOOL IsResultExpected( );

Return Value

Nonzero if an automation function should return a value; otherwise, it is zero.

Remarks

The COM interface supplies information to MFC about whether the client is using or ignoring the result of a method call. MFC, in turn, uses this information to determine the result of a call to CCmdTarget::IsResultExpected. If production of a return value is time-intensive or resource-intensive, you can increase efficiency by calling this method before computing the return value.

This function returns zero only once so that you get valid return values from other automation functions if you call them from the automation function that the client has called.

CCmdTarget::IsResultExpected returns a nonzero value if called when an automation function call is not in progress.
