CComboBox::GetLocale

This method retrieves the locale used by the combo box. The locale is used, for example, to determine the sort order of the strings in a sorted combo box.

LCID GetLocale( )
const;

Return Value

The locale identifier (LCID) value for the strings in the combo box.

Example

See the example for CComboBox::SetLocale.
