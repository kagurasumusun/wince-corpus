CSliderCtrl::SetBuddy

This method assigns a window as the buddy window for a trackbar control. Trackbar buddy windows are automatically displayed in a location relative to the orientation of the control, both horizontal or vertical.

CWnd* SetBuddy(
CWnd* pWndBuddy,
BOOL fLocation = TRUE );

Parameters

pWndBuddy
A pointer to a CWnd object that will be set as the slider control buddy.
fLocation
Value specifying the location at which to display the buddy window. This value can be one of the following:
  • TRUE   The buddy will appear to the left of the trackbar if the trackbar control uses the TBS_HORZ style. If the trackbar uses the TBS_VERT style, the buddy appear above the trackbar control.
  • FALSE   The buddy will appear to the right of the trackbar if the trackbar control uses the TBS_HORZ style. If the trackbar uses the TBS_VERT style, the buddy appears below the trackbar control.

Return Value

A pointer to a CWnd object that was previously assigned to the slider control at that location.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
