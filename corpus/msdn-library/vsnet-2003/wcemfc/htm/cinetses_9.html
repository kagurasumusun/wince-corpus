CInternetSession::QueryOption

This method provides possible asserts for error checking.

BOOL QueryOption(
DWORD dwOption,
LPVOID lpBuffer,
LPDWORD lpdwBufLen )
const;

BOOL QueryOption(
DWORD dwOption,
DWORD& dwValue )
const;

BOOL QueryOption( 
DWORD dwOption,
CString& refString )
const;

Parameters

dwOption
Specifies the Internet option to query.
lpBuffer
Specifies a buffer that receives the option setting.
lpdwBufLen
Specifies a pointer to a DWORD containing the length of lpBuffer. On return, this contains the length of the data placed into lpBuffer.
dwValue
Sent to QueryOption in place of lpBuffer.
refString
Specifies the reference string.

Return Value

If the operation was successful, a value of TRUE is returned. If an error occurred, a value of FALSE is returned. If the call fails, the Windows CE function GetLastError may be called to determine the cause of the error.

Remarks

See CInternetSession::SetOption to select and set the specific option to query.

The possible settings for INTERNET_OPTION_HANDLE_TYPE include the following:

  • INTERNET_HANDLE_TYPE_INTERNET
  • INTERNET_HANDLE_TYPE_CONNECT_HTTP
  • INTERNET_HANDLE_TYPE_HTTP_REQUEST

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxinet.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
