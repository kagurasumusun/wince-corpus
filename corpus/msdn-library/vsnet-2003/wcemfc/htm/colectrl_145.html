COleControl::SetInitialDataFormats

This method is called by the framework to initialize the list of data formats supported by the control.

The default implementation specifies two formats: CF_METAFILEPICT and the persistent property set.

virtual void SetInitialDataFormats ( );

Requirements

  Header file: Declared in Afxctl.h
