COleControl::GetEnabled

This method retrieves the value of the stock Enabled property.

BOOL GetEnabled( );

Return Value

Nonzero if the control is enabled; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
