CCommandLineInfo::CCommandLineInfo

This constructor creates an instance of a CCommandLineInfo object with default values. The default is to show the splash screen (m_bShowSplash = TRUE) and to execute the New command on the File menu (m_nShellCommand = NewFile).

The application framework calls ParseParam to fill data members of this object.

CCommandLineInfo( );

Example

CCommandLineInfo cmdinfo;
ProcessCommandLine(cmdinfo);

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
