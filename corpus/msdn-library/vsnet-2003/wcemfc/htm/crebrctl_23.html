CReBarCtrl::MinimizeBand

This method resizes a band in a rebar control to its smallest size.

This method implements the behavior of the Windows CE message RB_MINIMIZEBAND. 

void MinimizeBand(
UINT uBand );

Parameters

uBand
Specifies the zero-based index of the band to be minimized.

Example

UINT nCount = m_pReBarCtrl->GetBandCount();

for (UINT i=0; i<nCount; i++)
  m_pReBarCtrl->MinimizeBand(i);

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
