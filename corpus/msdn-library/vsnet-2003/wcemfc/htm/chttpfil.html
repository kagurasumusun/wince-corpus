CHttpFile

This class provides the functionality to request and read files on an HTTP server. If your Internet session reads data from an HTTP server, you must create an instance of CHttpFile.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxinet.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
