CFrameWnd::OnCreateClient

This method is called by the framework during the execution of OnCreate. Do not call this method.

virtual BOOL OnCreateClient(
LPCREATESTRUCT lpcs,
CCreateContext* pContext );

Parameters

lpcs
Specifies a pointer to a Windows CREATESTRUCT structure.
pContext
Specifies a pointer to a CCreateContext structure.

Return Value

Nonzero if successful; otherwise, it is zero.

Remarks

The default implementation of this function creates a CView object from the information provided in pContext, if possible.

Override this method to override values passed in the CCreateContext object or to change the way controls in the main client area of the frame window are created. The CCreateContext members you can override are described in the CCreateContext class.

Do not replace values passed in the CREATESTRUCT structure. They are for informational use only. If you want to override the initial window rectangle, for example, override the CWnd method PreCreateWindow.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
