CStatusBar::GetPaneText

This method retrieves the text that appears in a status-bar pane. The second implementation of this method fills a CString object with the string text.

CString GetPaneText(
int nIndex )
const; 

void GetPaneText(
int nIndex,
CString& rString )
const;

Parameters

nIndex
Specifies the index of the pane whose text is to be retrieved.
rString
Specifies a reference to a CString object that contains the text to be retrieved.

Return Value

A CString object containing the text in a pane.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
