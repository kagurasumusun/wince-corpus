CRectTracker::OnChangedRect

This method is called by the framework whenever the tracker rectangle has changed during a call to Track. At the time this method is called, all feedback drawn with DrawTrackerRect has been removed. The default implementation of this method does nothing.

Override this method when you want to perform any actions after the rectangle has been resized.

virtual void OnChangedRect(
const CRect& rectOld );

Parameters

rectOld
Contains the old device coordinates of the CRectTracker object.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
