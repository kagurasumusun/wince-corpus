COleControl::OnEdit

This method causes the control to be UI-active, which means that its user interface will be visible in a separate window. This method has the same effect as the OLEIVERB_UIACTIVATE verb of the control.

virtual BOOL OnEdit(
LPMSG lpMsg,
HWND hWndParent,
LPCRECT lpRect );

Parameters

lpMsg
Specifies a pointer to the Windows message that invoked the verb.
hWndParent
Specifies a handle to the parent window of the control.
lpRect
Specifies a pointer to the rectangle used by the control in the container.

Return Value

Nonzero if the call is successful; otherwise, it is zero.

Remarks

This method is typically used as the handler function for an ON_OLEVERB message map entry. This makes an Edit verb available on the control, Object menu; for example:

ON_OLEVERB(AFX_IDS_VERB_EDIT, OnEdit)

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
