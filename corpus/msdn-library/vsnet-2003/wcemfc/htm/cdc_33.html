CDC::GetCurrentBrush

This method retrieves a pointer to the selected CBrush object. This method may return temporary objects.

CBrush* GetCurrentBrush( )
const;

Return Value

Pointer to a CBrush object, if successful; otherwise, it is NULL.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
