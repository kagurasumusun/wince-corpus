What's New in MFC for Windows CE

Several new features have been added to MFC for Windows CE. These features are available in the new Pocket PC SDK. They include the following:

Classes brought over from the desktop MFC library

  • CMutex
  • CMultiLock

Updates to existing MFC for Windows CE classes

  • Boolean and Double datatypes, along with their constructors, and Set and Get member functions have been added to CCeDBProp.
  • A private member variable of type CEOID (m_iCEOID) and two public member functions to Get and Set the m_iCEOID have been added to CCeDBRecord.
  • In CCeDBDatabase, member function DeleteCurrRecord has been modified to accept an argument of type CEOID, and AddRecord has been overloaded to let you obtain the CEOID of a record just entered.

New items specifically designed for Pocket PC development

  • New classes CCeDocList, CCeDocListDocTemplate, and CCeSaveModifiedDlg
  • New CWnd members ShowDoneButton and SHRecognizeGesture
  • New CDialog member m_bFullScreen
  • New CFindReplaceDialog members m_bShowBar and IsBarVisible

Standalone Reference documentation

Documentation for this release includes a complete standalone MFC library reference for Windows CE, eliminating the previous dependency on desktop MFC documentation or the MSDN Library. Relevant material from desktop documentation has been integrated into the current Reference.
