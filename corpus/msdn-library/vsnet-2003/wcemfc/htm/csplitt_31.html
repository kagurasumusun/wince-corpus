CSplitterWnd::SplitColumn

This method is called when a vertical splitter window is created. SplitColumn indicates the default location where the split occurs.

This method is called by the framework to implement the logic of the dynamic splitter window, that is, if the splitter window has the SPLS_DYNAMIC_SPLIT style. It can be customized, along with the CreateView virtual method, to implement more advanced dynamic splitters.

virtual BOOL SplitColumn(
int cxBefore );

Parameters

cxBefore
Specifies the position, in pixels, before which the split occurs.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
