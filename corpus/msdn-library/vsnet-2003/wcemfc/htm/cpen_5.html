CPen::FromHandle

This method obtains a pointer to a CPen object when you have a handle to a Windows CE GDI pen object. If a CPen object is not attached to the handle, a temporary CPen object is created and attached. This temporary CPen object is valid only until the next time the application has idle time in its event loop, at which time all temporary graphic objects are deleted. In other words, the temporary object is only valid during the processing of one window message.

static CPen* PASCAL FromHandle(
HPEN hPen );

Parameters

hPen
Specifies the HPEN handle to Windows GDI pen.

Return Value

A pointer to a CPen object if it is successful; otherwise, it is NULL.

Example

// Convert an HPEN to a CPen*.
// NOTE: hPen is a valid pen handle.
CPen* pPen = CPen::FromHandle(hPen);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
