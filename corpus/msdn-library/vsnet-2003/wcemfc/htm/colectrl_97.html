COleControl::OnGetPredefinedValue

This method is called by the framework to obtain the value that corresponds to one of the predefined strings previously returned by an override of COleControl::OnGetPredefinedStrings.

virtual BOOL OnGetPredefinedValue(
DISPID dispid,
DWORD dwCookie,
VARIANT* lpvarOut );

Parameters

dispid
Specifies the dispatch ID of a property of the control.
dwCookie
Specifies a cookie value previously returned by an override of COleControl::OnGetPredefinedStrings.
lpvarOut
Specifies a pointer to a VARIANT structure through which a property value will be returned.

Return Value

Nonzero if a value has been returned in lpvarOut; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
