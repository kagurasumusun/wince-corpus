COleControl::ControlInfoChanged

This method is called after the set of mnemonics handled by the control has changed.

Upon receiving this notification, the container of the control obtains the new set of mnemonics by making a call to IOleControl::GetControlInfo. Note that the container is not required to respond to this notification.
