CImageList::DragShowNolock

This method shows or hides the drag image during a drag operation, without locking the window.

The CImageList::DragEnter method locks all updates to the window during a drag operation. This method, however, does not lock the window.

static BOOL PASCAL DragShowNolock(
BOOL bShow );

Parameters

bShow
Specifies whether the drag image is to be shown.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
