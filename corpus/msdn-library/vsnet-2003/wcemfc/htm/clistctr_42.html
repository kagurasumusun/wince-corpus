CListCtrl::GetViewRect

This method retrieves the bounding rectangle of all items in the list view control. The list view must be in icon view or small icon view.

BOOL GetViewRect(
LPRECT lpRect )
const;

Parameters

lpRect
Specifies the address of a RECT structure.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
