CInternetSession::OpenURL

This method sends the specified request to the HTTP server and allows the client to specify additional RFC822, MIME, or HTTP headers to send along with the request. 

CStdioFile* OpenURL(
LPCTSTR pstrURL,
DWORD dwContext = 1,
DWORD dwFlags = INTERNET_FLAG_TRANSFER_ASCII,
LPCTSTR pstrHeaders = NULL,
DWORD dwHeadersLength = 0);

Parameters

pstrURL
Specifies a pointer to the name of the URL to begin reading. Only URLs beginning with file: or http: are supported. ASSERTS if pszURL is NULL.
dwContext
Specifies an application-defined value passed with the returned handle in callback.
dwFlags
Specifies the flags describing how to handle this connection. See the Remarks section for more information about the valid flags. The following list shows the valid flags:
  • INTERNET_FLAG_TRANSFER_ASCII   The default. Transfer the file as ASCII text.
  • INTERNET_FLAG_TRANSFER_BINARY   Transfer the file as a binary file.
  • INTERNET_FLAG_RELOAD   Get the data from the wire even if it is locally cached.
  • INTERNET_FLAG_DONT_CACHE   Do not cache the data, either locally or in any gateways.
  • INTERNET_FLAG_SECURE   This flag is applicable to HTTP requests only. It requests secure transactions on the wire with Secure Sockets Layer or PCT.
  • INTERNET_OPEN_FLAG_USE_EXISTING_CONNECT   If possible, reuse the existing connections to the server for new requests generated by OpenUrl instead of creating a new session for each connection request.
  • INTERNET_FLAG_PASSIVE   Used for an FTP site. Uses passive FTP semantics. Used with CInternetConnection of OpenURL.
pstrHeaders
Specifies a pointer to a string containing the headers to be sent to the HTTP server.
dwHeadersLength
Specifies the length, in characters, of the additional headers. If this is -1L and pstrHeaders is non-NULL, then pstrHeaders is assumed to be zero terminated and the length is calculated.

Return Value

Returns a file handle for HTTP and FILE-type Internet services only. Returns NULL if parsing was unsuccessful.

The pointer that OpenURL returns depends on the type of service in pszURL. The table below illustrates the possible pointers OpenURL can return.

URL type Returns
file:// CStdioFile*
http:// CHttpFile*

Remarks

MFC for Windows CE supports only the following values for the dwFlags parameter:

  • INTERNET_FLAG_NO_AUTO_REDIRECT
  • INTERNET_FLAG_SECURE
  • INTERNET_FLAG_TRANSFER_ASCII
  • INTERNET_FLAG_TRANSFER_BINARY

The dwFlags parameter must include the INTERNET_FLAG_TRANSFER_ASCII flag or the INTERNET_FLAG_TRANSFER_BINARY flag, but not both. The remaining flags can be combined with the bitwise OR operator (|).

OpenURL, which wraps the Windows CE function InternetOpenURL, allows only downloading, retrieving, and reading the data from an Internet server. OpenURL allows no file manipulation on a remote location, so it requires no CInternetConnection object.

To use connection-specific, that is, protocol-specific functions, such as writing to a file, open a session, then open a particular connection type, and use that connection to open a file in the desired mode. See CInternetConnection for more information about connection-specific functions.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxinet.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
