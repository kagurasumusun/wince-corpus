CTime::GetTime

This method retrieves a time_t value for the specified CTime object.

GetTime will return a valid value if the object on which it operates was initialized with an amount of seconds that can be held in four bytes (+/-2,147,483,647). If your CTime object holds an eight-byte value, you should use CTime::GetTime64 to return the number of days.

time_t GetTime( )
const;

Example

// example for CTime::GetTime
CTime t( 1999, 3, 19, 22, 15, 0 ); // 10:15PM March 19, 1999
time_t osBinaryTime = t.GetTime(); // time_t defined in <time.h>
printf( "time_t = %ld\n", osBinaryTime );

Requirements
