COleControl::OnClose

This method is called by the framework to notify the control that IOleControl::Close has been called. By default, OnClose saves the control object if it has been modified and dwSaveOption is either OLECLOSE_SAVEIFDIRTY or OLECLOSE_PROMPTSAVE.

virtual void OnClose(
DWORD dwSaveOption );

Parameters

dwSaveOption
Specifies the flag that indicates whether the object should be saved before loading. Valid values are:
  • OLECLOSE_SAVEIFDIRTY
  • OLECLOSE_NOSAVE
  • OLECLOSE_PROMPTSAVE

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
