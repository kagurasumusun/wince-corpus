CDocument::GetPathName

This method retrieves the fully qualified path of the disk file in the document.

const CString& GetPathName( )
const;

Return Value

The fully qualified path for the document. This string is empty if the document has not been saved or does not have a disk file associated with it.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
