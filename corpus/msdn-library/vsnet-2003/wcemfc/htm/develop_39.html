Current Time

The following procedure shows how to create a CTime object and initialize it with the current time. (Be aware that uninitialized CTime objects are not initialized to a valid time.)

To get the current time

  1. Allocate a CTime object, as follows: 
    CTime theTime;
  2. Call the CTime::GetCurrentTime function to fetch the current time from the operating system. This function returns a CTime object that you can use to set the value of CTime, as follows: 
    theTime = CTime::GetCurrentTime();

    The class name and scope operator (::) are required because GetCurrentTime is a static member function of the CTime class.

The preceding two steps are typically combined into a single statement as follows:

CTime theTime = CTime::GetCurrentTime();
