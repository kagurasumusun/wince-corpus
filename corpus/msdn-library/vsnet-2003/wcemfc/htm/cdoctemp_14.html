CDocTemplate::RemoveDocument

This method removes the document pointed to by pDoc from the list of documents associated with this template. The derived class CSingleDocTemplate overrides this method. If you derive your own document-template class from CDocTemplate, the derived class must override this method.

virtual void RemoveDocument(
CDocument* pDoc );

Parameters

pDoc
Specifies the pointer to the document to be removed.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
