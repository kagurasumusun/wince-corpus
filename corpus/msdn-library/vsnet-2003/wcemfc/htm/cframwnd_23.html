CFrameWnd::LoadFrame

This method loads the Windows CE frame window and associated resources and attaches the frame window to the CFrameWnd object.

To construct a CFrameWnd object, invoke the constructor, which constructs the CFrameWnd object, and then call LoadFrame.

virtual BOOL LoadFrame(
UINT nIDResource,
DWORD dwDefaultStyle = WS_OVERLAPPEDWINDOW | FWS_ADDTOTITLE,
CWnd* pParentWnd = NULL,
CCreateContext* pContext = NULL);

Parameters

nIDResource
Specifies the ID of shared resources associated with the frame window.
dwDefaultStyle
MFC for Windows CE does not use the dwDefaultStyle parameter.

Specifies the style of the frame. Include the FWS_ADDTOTITLE style if you want the title bar to automatically display the name of the document represented in the window.

pParentWnd
Specifies a pointer to the parent frame window.
pContext
Specifies a pointer to a CCreateContext structure. This parameter can be NULL.

Remarks

Construct a CFrameWnd object in two steps. First invoke the constructor, which constructs the CFrameWnd object, then call LoadFrame, which loads the Windows frame window and associated resources and attaches the frame window to the CFrameWnd object. The nIDResource parameter specifies the menu, the accelerator table, the icon, and the string resource of the title for the frame window.

Use the Create method rather than LoadFrame when you want to specify all of the creation parameters in a frame window.

The framework calls LoadFrame when it creates a frame window using a document template object.

The framework uses the pContext argument to specify the objects to be connected to the frame window, including any contained view objects. You can set the pContext argument to NULL when you call LoadFrame.

Requirements
