CSplitterWnd::GetColumnCount

This method retrieves the current number of columns in the splitter. For a static splitter, this will also be the maximum number of columns.

int GetColumnCount( )
const;

Return Value

Returns the current number of columns in the splitter. For a static splitter, this will also be the maximum number of columns.

Requirements
