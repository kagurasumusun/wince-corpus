COleDateTime::GetHour

This method retrieves the hour represented by this date/time value.

Valid return values range between 0 and 23. If the status of this COleDateTime object is not valid, the return value is AFX_OLE_DATETIME_ERROR.

int GetHour( )
const;

Return Value

The hour represented by the value of this COleDateTime object.

Remarks

For information on other methods that query the value of this COleDateTime object, see the following methods:

  • GetDay
  • GetMonth
  • GetYear
  • GetMinute
  • GetSecond
  • GetDayOfWeek
  • GetDayOfYear

Example

COleDateTime t(1999, 3, 19, 22, 15, 0);  // 10:15PM March 19, 1999
ASSERT(t.GetSecond() == 0);
ASSERT(t.GetMinute() == 15);
ASSERT(t.GetHour() == 22);
