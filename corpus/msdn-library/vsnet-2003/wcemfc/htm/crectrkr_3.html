CRectTracker::AdjustRect

This method is called by the framework when the tracking rectangle is resized by using a resize handle. The default behavior of this method allows the orientation of a rectangle to change only when Track and TrackRubberBand are called with inverting allowed.

Override this method to control the adjustment of the tracking rectangle during a dragging operation. One method is to adjust the coordinates specified by lpRect before returning.

Special features that are not directly supported by CRectTracker, such as snap-to-grid or keep-aspect-ratio, can be implemented by overriding this method.

virtual void AdjustRect(
int nHandle,
LPRECT lpRect );

Parameters

nHandle
Specifies the index of handle used.
lpRect
Specifies a pointer to the current size of the rectangle. The size of a rectangle is given by its height and width.
