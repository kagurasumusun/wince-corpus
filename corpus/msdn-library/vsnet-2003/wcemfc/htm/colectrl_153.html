COleControl::TransformCoords

This method transforms coordinate values between a container and the control.

The first two flags, XFORMCOORDS_POSITION and XFORMCOORDS_SIZE, indicates whether the coordinates should be treated as a position or a size. The remaining two flags indicate the direction of transformation.

void TransformCoords(
POINTL* lpptlHimetric,
POINTF* lpptfContainer,
DWORD flags );

Parameters

lpptlHimetric
Specifies a pointer to a POINTL structure containing coordinates in HIMETRIC units.
lpptfContainer
Specifies a pointer to a POINTF structure containing coordinates in the unit size of the container.
flags
Specifies a combination of the following values:
  • XFORMCOORDS_POSITION   A position in the container.
  • XFORMCOORDS_SIZE   A size in the container.
  • XFORMCOORDS_HIMETRICTOCONTAINER   Transform HIMETRIC units to the units in a container.
  • XFORMCOORDS_CONTAINERTOHIMETRIC   Transform the units of the container to HIMETRIC units.

Requirements
