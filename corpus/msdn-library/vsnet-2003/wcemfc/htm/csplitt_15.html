CSplitterWnd::GetActivePane

This method is called by the framework to determine the active pane in a splitter window.

Override to require an action by the user before getting the active pane.

virtual CWnd* GetActivePane(
int* pRow = NULL,
int* pCol = NULL );

Parameters

pRow
Specifies a pointer to an int to retrieve the row number of the active pane.
pCol
Specifies a pointer to an int to retrieve the column number of the active pane.

Return Value

Returns a pointer to the active pane. NULL if no active pane exists.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
