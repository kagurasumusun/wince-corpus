CDC::GetTextMetrics

This method retrieves the metrics for the current font using the attribute device context.

BOOL GetTextMetrics(
LPTEXTMETRIC lpMetrics )
const;

Parameters

lpMetrics
Pointer to the TEXTMETRIC structure that receives the metrics.

Return Value

Nonzero if the function is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
