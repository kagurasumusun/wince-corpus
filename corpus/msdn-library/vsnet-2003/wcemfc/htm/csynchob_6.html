CSyncObject::operator HANDLE

Use this operator to get the handle of the CSyncObject object. You can use the handle to call Windows APIs directly.

operator HANDLE( )
const;

Return Value

If successful, the handle of the synchronization object; otherwise, it is NULL.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxmt.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
