CWinApp::ProcessWndProcException

This method is called by the framework whenever the handler does not catch an exception thrown in one of the message or command handlers of your application.

virtual LRESULT ProcessWndProcException(
CException* e,
const MSG* pMsg );

Parameters

e
A pointer to an uncaught exception.
pMsg
A MSG structure that contains information about the windows message that caused the framework to throw an exception.

Return Value

The value that should be returned to Windows. Normally this is 0L for windows messages, 1L, TRUE, for command messages.

Remarks

Do not call this method directly.

The default implementation of this method creates a message box. If the uncaught exception originates with a menu, toolbar, or accelerator command failure, the message box displays a, Command failed, message; otherwise, it displays an, Internal application error, message.

Override this method to provide global handling of your exceptions. Only call the base functionality if you wish the message box to be displayed.

Requirements

  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
