CSliderCtrl::SetLineSize

This method sets the size of the line for a slider control. The line size affects how much the slider moves for the TB_LINEUP and TB_LINEDOWN notifications.

int SetLineSize(
int nSize );

Parameters

nSize
Specifies the new line size of the slider control.

Return Value

Returns the previous line size.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
