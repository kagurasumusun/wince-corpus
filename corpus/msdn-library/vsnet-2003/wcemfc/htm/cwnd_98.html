CWnd::OnAmbientProperty

This method is called by the framework to obtain ambient property values from a window that contains ActiveX controls. Override this method to alter the default ambient property values returned by an ActiveX control container to its controls. Any ambient property requests not handled by an overriding method should be forwarded to the base class implementation.

virtual BOOL OnAmbientProperty(
COleControlSite* pSite,
DISPID dispid,
VARIANT* pvar );

Parameters

pSite
Specifies a pointer to the site of the control that requested the ambient property.
dispid
Specifies the dispatch ID of the requested ambient property.
pvar
Specifies a pointer to a caller-allocated VARIANT structure, through which the ambient property value will be returned.

Return Value

TRUE if the ambient property is supported; if not, it is FALSE.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
