CArray::GetSize

This method retrieves the size of the array. Because indexes are zero-based, the size is one greater than the largest index.

int GetSize( )
const;

Example

CArray<CPoint,CPoint> myArray;

// Add elements to the array.
for (int i=0;i < 10;i++)
    myArray.Add( CPoint(i, 2*i) );

// Modify all the points in the array.
for (i=0;i < myArray.GetSize();i++)
{
  CPoint& pt = myArray.ElementAt(i);
  pt.x = 0;
}

Requirements
