CToolBarCtrl::SetCmdID

This method sets the command identifier, which is sent to the owner window when the specified button is pressed.

BOOL SetCmdID(
int nIndex,
UINT nID );

Parameters

nIndex
Specifies the zero-based index of the button whose command ID is to be set.
nID
Specifies the command ID to set the selected button to.

Return Value

Returns nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
