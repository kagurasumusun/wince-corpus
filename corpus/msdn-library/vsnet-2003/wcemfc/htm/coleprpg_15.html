COlePropertyPage::SetHelpInfo

This method specifies a brief text string describing the purpose of this property page and its Help file name and the Help context.

void SetHelpInfo(
LPCTSTR lpszDocString,
LPCTSTR lpszHelpFile = NULL,
DWORD dwHelpContext = 0 );

Parameters

lpszDocString
Specifies a string containing brief help information for display in a status bar or other location.
lpszHelpFile
Specifies the name of the property page help file.
dwHelpContext
Specifies the Help context for the property page.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
