COleDateTimeSpan::GetTotalHours

This method retrieves the number of hours this COleDateTimeSpan object represents. The return values from this function range between approximately –8.77e7 and 8.77e7.

double GetTotalHours( )
const;

Return Value

This date/time-span value expressed in hours. Although this method is prototyped to return a double, it always returns an integer value.

Remarks

For other methods that query the value of a COleDateTimeSpan object, see the following methods:

  • GetDays
  • GetHours
  • GetMinutes
  • GetSeconds
  • GetTotalDays
  • GetTotalMinutes
  • GetTotalSeconds

Example

// Example for COleDateTimeSpan::GetTotalXxx functions.
COleDateTimeSpan ts( 3, 1, 5, 12 ); // 3 days, 1 hour, 5 min, and 12 sec
ASSERT( ts.GetTotalDays() == 3 );
ASSERT( ts.GetTotalHours() == 73 );
ASSERT( ts.GetTotalMinutes() == 4385 );
ASSERT( ts.GetTotalSeconds() == 263112 );
