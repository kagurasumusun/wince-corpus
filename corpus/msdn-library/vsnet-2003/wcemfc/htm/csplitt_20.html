CSplitterWnd::GetRowInfo

This method obtains information about the specified row. The cyCur parameter is filled with the current height of the specified row, and cyMin is filled with the minimum height of the row.

void GetRowInfo(
int row,
int& cyCur,
int& cyMin )
const;

Parameters

row
Specifies a row.
cyCur
Specifies the reference to int to be set to the current height of the row in pixels.
cyMin
Specifies the reference to int to be set to the current minimum height of the row in pixels.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
