CWnd::PreTranslateMessage

This method is used by class CWinApp to translate window messages before they are dispatched to the Windows CE TranslateMessage and DispatchMessage functions.

virtual BOOL PreTranslateMessage(
MSG* pMsg );

Parameters

pMsg
Points to a MSG structure that contains the message to process.

Return Value

Nonzero if the message was translated and should not be dispatched; zero if the message was not translated and should be dispatched.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
