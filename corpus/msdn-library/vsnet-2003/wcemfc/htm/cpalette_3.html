CPalette::CreatePalette

This method initializes a CPalette object by creating a Windows CE logical color palette and attaching it to the CPalette object.

BOOL CreatePalette(
LPLOGPALETTE lpLogPalette );

Parameters

lpLogPalette
Points to a LOGPALETTE structure that contains information about the colors in the logical palette.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
