CToolBar::GetItemID

This method returns the command identifier of the button or separator specified by nIndex.

UINT GetItemID(
int nIndex )
const;

Parameters

nIndex
Index of the item whose ID is to be retrieved.

Return Value

The command ID of the button or separator specified by nIndex.

Requirements

  Windows CE versions: 2.10 and later
