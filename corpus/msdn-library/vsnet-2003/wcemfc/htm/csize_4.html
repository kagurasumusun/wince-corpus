CSize::operator ==

This operator checks for equality between two sizes. 

BOOL operator ==(
SIZE size )
const;

Return Vale

Returns nonzero if the sizes are equal, otherwise, it is zero.

Example

CSize sz1(135, 135);
CSize sz2(135, 135);

ASSERT(sz1 == sz2);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
