COleControl::IsModified

This method determines whether the control state has changed.

BOOL IsModified( );

Return Value

Nonzero if the control state has been modified since it was last saved; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
