CTreeCtrl::SortChildren

This method sorts the child items of the specified parent item in a tree view control. If hItem is NULL, the entire tree control is sorted.

BOOL SortChildren(
HTREEITEM hItem );

Parameters

hItem
Specifies the handle of the parent item whose child items are to be sorted. If hItem is NULL, sorting will proceed from the root of the tree.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// The pointer to my tree control.
extern CTreeCtrl* pmyTreeCtrl;

// Sort all of the items in the tree control.
pmyTreeCtrl->SortChildren(TVI_ROOT);

Requirements
