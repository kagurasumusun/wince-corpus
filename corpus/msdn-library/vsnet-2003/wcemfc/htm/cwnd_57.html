CWnd::GetOwner

This method obtains a pointer to the owner of the window. If the window has no owner, then a pointer to the parent window object is returned by default. Note that the relationship between the owner and the owned differs from the parent-child aspect in several important aspects. For example, a window with a parent is confined to its parent window client area. Owned windows can be drawn at any location on the desktop.

The ownership concept of this method is different from the ownership concept of GetWindow.

CWnd* GetOwner( )
const;

Return Value

Returns a pointer to a CWnd object.
