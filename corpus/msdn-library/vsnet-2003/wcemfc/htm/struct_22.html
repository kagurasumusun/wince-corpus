POINT

This structure defines the x- and y-coordinates of a point.

typedef struct tagPOINT
{
    LONG   x;
    LONG   y;
} POINT, *PPOINT, NEAR *NPPOINT, FAR *LPPOINT;

Members

x
Specifies the x-coordinate of a point.
y
Specifies the y-coordinate of a point.

Example

//Alternate ways to initialize a POINT structure:

POINT ptA;
ptA.x = 370;
ptA.y = 550;

POINT ptB = {370,550};

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Windef.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
