CScrollView::GetScrollPosition

This method retrieves the current horizontal and vertical positions of the scroll boxes in the scroll bars. This coordinate pair corresponds to the location in the document to which the upper-left corner of the view has been scrolled.

GetScrollPosition returns values in logical units. If you want device units, use GetDeviceScrollPosition instead.

CPoint GetScrollPosition( )
const;

Return Value

The horizontal and vertical positions, in logical units, of the scroll boxes as a CPoint object.

Requirements
