CListBox::SetAnchorIndex

This method sets the anchor in a multiple-selection list box to begin an extended selection. In a multiple-selection list box, the anchor item is the first or last item in a block of contiguous selected items.

void SetAnchorIndex(
int nIndex );

Parameters

nIndex
Specifies the zero-based index of the list-box item that will be the anchor.

Example

// Pointer to the myListBox.
extern CListBox* pmyListBox;
// Point where mouse was clicked.
extern CPoint myPoint;

BOOL bOutside;
UINT uItem = pmyListBox->ItemFromPoint(myPoint, bOutside);

if (!bOutside)
{
  // Set the anchor to be the middle item.
  pmyListBox->SetAnchorIndex(uItem);
  ASSERT(pmyListBox->GetAnchorIndex() == uItem);
}
