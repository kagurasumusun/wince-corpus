CScrollView::SetScaleToFitSize

This method scales the viewport size to the current window size automatically. With scroll bars, only a portion of the logical view may be visible at any time. But with the scale-to-fit capability, the view has no scroll bars and the logical view is stretched or shrunk to exactly fit the client area in the window. When the window is resized, the view draws its data at a new scale based on the size of the window.

void SetScaleToFitSize(
SIZE sizeTotal );

Parameters

sizeTotal
Specifies the horizontal and vertical sizes to which the view is to be scaled. The size of the scroll view is measured in logical units. The horizontal size is contained in the cx member. The vertical size is contained in the cy member. Both cx and cy must be greater than or equal to 0.

Remarks

You will typically place the call to SetScaleToFitSize in your override of the view OnInitialUpdate method. If you do not want automatic scaling, call the SetScrollSizes method instead.

SetScaleToFitSize can be used to implement a Zoom to Fit operation. Use SetScrollSizes to reinitialize scrolling.

SetScaleToFitSize assumes that the size of the view window has been set. If the view window size has not been set when SetScaleToFitSize is called, you will get an assertion. To ensure that this does not happen, make the following call before calling SetScaleToFitSize:

GetParentFrame()->RecalcLayout();

Because Windows CE only supports the MM_TEXT mapping mode, this method does not do anything in MFC for Windows CE.
