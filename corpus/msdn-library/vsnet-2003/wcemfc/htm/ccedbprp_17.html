CCeDBProp::SetDouble

This method sets the value of a double property. 

void SetDouble (
DOUBLE dDouble );

Parameters

dDouble
Specifies the value of the property.

Remarks

You can call SetDouble only on a property of the type CCeDBProp::Type_Double.
