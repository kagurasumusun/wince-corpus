CImageList::Read

This method reads an image list from an archive.

BOOL Read(
CArchive* pArchive );

Parameters

pArchive
Specifies a pointer to a CArchive object from which the image list is to be read.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// Pointer to the myImageList.
extern CImageList* pmyImageList;

// Open the archive to load the image list from.
CFile   myFile(TEXT("myfile.data"), CFile::modeRead);
CArchive ar(&myFile, CArchive::load);

// Load the image list from the archive.
pmyImageList->Read(&ar);

Requirements
