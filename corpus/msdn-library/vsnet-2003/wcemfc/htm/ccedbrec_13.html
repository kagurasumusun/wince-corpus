CCeDBRecord::operator =

This assignment operator copies the m_PropArray data member of rec into the m_PropArray data member of the CCeDBRecord object. The m_PropArray data member contains the array of properties that belong to the record.

CCeDBRecord& operator=(
const CCeDBRecord& rec );

Parameters

rec
Specifies the CCeDBRecord object to copy.

Remarks

This operator does a shallow copy. It only copies pointers to the properties belonging to rec; it does not make copies of the properties themselves.

Requirements
