CRuntimeClass::m_pfnCreateObject

This method retrieves the pointer to the default constructor that creates an object of your class. This pointer is only valid if the class supports dynamic creation; otherwise, the data member returns NULL.

CObject* (PASCAL* m_pfnCreateObject)( )
