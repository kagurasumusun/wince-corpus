CInternetConnection::CInternetConnection

This constructor creates an instance of a CInternetConnection object.

You never call CInternetConnection yourself; instead, call the following CInternetSession method for the type of connection you want to establish:

  • CInternetSession::GetHttpConnection
CInternetConnection(
CInternetSession* pSession,
LPCTSTR pstrServer,
INTERNET_PORT nPort = INTERNET_INVALID_PORT_NUMBER,
DWORD dwContext = 1);

Parameters

pSession
Specifies a pointer to a CInternetSession object.
pstrServer
Specifies a pointer to a string containing the server name.
nPort
Specifies the number that identifies the Internet port for this connection.
dwContext
Specifies the context identifier for the CInternetConnection object. See the Remarks section for more information about dwContext.

Remarks

The default value for dwContext is sent by MFC to the CInternetConnection-derived object from the CInternetSession object that created the InternetConnection-derived object. The default is set to one; however, you can explicitly assign a specific context identifier in the CInternetSession constructor for the connection. The object and any work it does will be associated with that context ID. The context identifier is returned to CInternetSession::OnStatusCallback to provide status on the object with which it is identified.

Requirements
