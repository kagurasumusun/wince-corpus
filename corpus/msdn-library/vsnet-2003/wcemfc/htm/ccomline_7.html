CCommandLineInfo::m_strFileName

This data member contains a CString object that stores the value of the first nonflag parameter on the command line. This parameter is the name of the file to open.

CString m_strFileName;

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
