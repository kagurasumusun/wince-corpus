CFile::Write

This method writes data from a buffer to the file associated with the CFile object.

Write throws an exception in response to several conditions, including the disk-full condition.

virtual void Write( 
const void* lpBuf,
UINT nCount );

Parameters

lpBuf
Specifies a pointer to the user-supplied buffer that contains the data to be written to the file.
nCount
Specifies the number of bytes to be transferred from the buffer. For text-mode files, carriage return–linefeed pairs are counted as single characters.

Remarks

You can use the Cfile::Open method to write to files in the Windows CE object store.

Example

// Example for the CFile::Write method.
extern CFile cfile;
TCHAR pbuf[100];
cfile.Write( pbuf, 100 );

In addition, see the examples for CFile::CFile and CFile::Open.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
