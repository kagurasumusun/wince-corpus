CToolBarCtrl::IsButtonEnabled

This method determines whether the specified button in a toolbar control is enabled.

BOOL IsButtonEnabled(
int nID )
const;

Parameters

nID
Specifies the command identifier of the button in the toolbar.

Return Value

Nonzero if the button is enabled; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
