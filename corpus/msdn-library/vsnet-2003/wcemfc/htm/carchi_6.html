CArchive::GetFile

This method obtains the CFile object pointer for the current archive. Flush the archive before using GetFile.

CFile* GetFile( ) 
const;

Return Value

A constant pointer to the CFile object in use.

Example

extern CArchive ar;
const CFile* fp = ar.GetFile();

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
