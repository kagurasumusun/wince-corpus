CReBarCtrl::SetBkColor

This method sets the default background color for a rebar control.

This method implements the behavior of the Windows CE message RB_SETBKCOLOR.

COLORREF SetBkColor(
COLORREF clr );

Parameters

clr
Specifies the COLORREF value that represents the new default background color.

Return Value

Returns a COLORREF value that represents the previous default background color.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
