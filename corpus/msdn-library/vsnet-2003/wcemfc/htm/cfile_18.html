CFile::SeekToBegin

This method sets the value of the file pointer to the beginning of the file. SeekToBegin is equivalent to Seek( 0L, CFile::begin ).

void SeekToBegin( );

Example

// Example for the CFile::SeekToBegin
extern CFile cfile;
cfile.SeekToBegin();

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
