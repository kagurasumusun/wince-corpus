CWnd::GetWindow

This method obtains a pointer to the requested window.

CWnd* GetWindow (
UINT nCmd )
const;

Parameters

nCmd
Specifies the relationship between CWnd and the returned window. It can take one of the following values:
  • GW_CHILD   Identifies the CWnd first child window.
  • GW_HWNDFIRST   If CWnd is a child window, returns the first sibling window. Otherwise, it returns the first top-level window in the list.
  • GW_HWNDLAST   If CWnd is a child window, returns the last sibling window. Otherwise, it returns the last top-level window in the list.
  • GW_HWNDNEXT   Returns the next window on the window manager list.
  • GW_HWNDPREV   Returns the previous window on the window manager list.
  • GW_OWNER   Identifies the CWnd owner.

Return Value

Returns a pointer to the window requested, or it is NULL if none.

The returned pointer may be temporary and should not be stored for later use.

Remarks

Windows CE 1.0 does not support owned windows, except for dialog boxes. In version 1.0, you cannot pass the GW_OWNER value in the nCmd parameter unless the specified window is a dialog box.

Windows CE versions 2.0 and later support owned windows.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
