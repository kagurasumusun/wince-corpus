COleVariant::Attach

This method attaches the specified VARIANT object to the current COleVariant object. This method sets the VARTYPE of varSrc to VT_EMPTY.

void Attach(
VARIANT& varSrc );

Parameters

varSrc
Specifies an existing VARIANT object to be attached to the current COleVariant object.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
