CMonthCalCtrl::HitTest

This method determines which portion of a month calendar control is at a specified point on the screen.

HitTest uses the MCHITTESTINFO structure, which contains information about the hit test.

DWORD HitTest(
PMCHITTESTINFO pMCHitTest );

Parameters

pMCHitTest
Specifies a pointer to a MCHITTESTINFO structure containing hit testing points for the month calendar control.

Return Value

A DWORD value. Equal to the uHit member of the MCHITTESTINFO structure.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxdtctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
