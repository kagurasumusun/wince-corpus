CFont::GetLogFont

This method retrieves a copy of the LOGFONT structure for CFont.

int GetLogFont(
LOGFONT* pLogFont );

Parameters

pLogFont
Specifies the pointer to the LOGFONT structure to receive the font information.

Return Value

Nonzero if the function succeeds, otherwise, it is zero.

Example

// This code fragment shows how to retrieve a copy of the
// LOGFONT structure for a currently selected font of a window.

CFont* font = pWnd->GetFont();
if (font)
{
   LOGFONT lf;
   font->GetLogFont(&lf);
   TRACE(_T("Typeface name of font = %s\n", lf.lfFaceName);
}

Requirements

  Windows CE versions: 1.0 and later
