CTreeCtrl::SelectItem

This method selects the specified tree view item.

BOOL SelectItem(
HTREEITEM hItem );

Parameters

hItem
Specifies the handle of a tree item.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// The pointer to my tree control.
extern CTreeCtrl* pmyTreeCtrl;
// The point to test.
extern CPoint myPoint;

// Select the item that is at the point myPoint.
UINT uFlags;
HTREEITEM hItem = pmyTreeCtrl->HitTest(myPoint, &uFlags);

if ((hItem != NULL) && (TVHT_ONITEM & uFlags))
{
  pmyTreeCtrl->SelectItem(hItem);
}

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
