CPoint::operator ==

This operator checks for equality between two points.

BOOL operator ==(
POINT point )
const;

Parameters

point
Contains a POINT structure or CPoint object.

Return Value

Nonzero if the points are equal; otherwise, it is zero.

Example

CPoint ptFirst(256, 128);
CPoint ptTest(256, 128);

ASSERT(ptFirst == ptTest);

// This works with POINTs, too.

POINT pt;
pt.x = 256;
pt.y = 128;

ASSERT(ptTest == pt);

// Note that pt == ptTest is not correct!
