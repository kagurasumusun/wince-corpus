CToolBarCtrl::PressButton

This method presses or releases the specified button in a toolbar control.

If you want to change more than one button state, consider calling SetState instead.

BOOL PressButton(
int nID,
BOOL bPress = TRUE );

Parameters

nID
Specifies the command identifier of the button to press or release.
bPress
TRUE to press the specified button; FALSE to release the specified button.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
