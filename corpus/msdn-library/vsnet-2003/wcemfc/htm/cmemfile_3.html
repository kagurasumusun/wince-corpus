CMemFile::Alloc

This method is called by CMemFile methods. Override this method to implement custom memory allocation. If you override this method, you will probably also want to override Free and Realloc.

virtual BYTE * Alloc(
DWORD nBytes );

Parameters

nBytes
Specifies the number of bytes of memory to be allocated.

Return Value

A pointer to the memory block that was allocated, or NULL if the allocation failed.

Remarks

The default implementation uses the run-time library function malloc to allocate memory.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
