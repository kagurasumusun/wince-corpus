CListCtrl::InsertColumn

This method inserts a new column in a list view control. The leftmost column in a list view control must be left-aligned.

The LVCOLUMN structure contains the attributes of a column in report view. It is also used to receive information about a column. This structure is described in the Platform SDK.

int InsertColumn(
int nCol,
const LVCOLUMN* pColumn );

int InsertColumn(
int nCol,
LPCTSTR lpszColumnHeading,
int nFormat = LVCFMT_LEFT,
int nWidth = –1,
int nSubItem = –1 );

Parameters

nCol
Specifies the index of the new column.
pColumn
Specifies the address of an LVCOLUMN structure that contains the attributes of the new column.
lpszColumnHeading
Specifies the address of a string containing the heading of the column.
nFormat
Specifies the integer specifying the alignment of the column. It can be one of these values: LVCFMT_LEFT, LVCFMT_RIGHT, or LVCFMT_CENTER.
nWidth
Specifies the width of the column, in pixels. If this parameter is -1, the column width is not set.
nSubItem
Specifies the index of the subitem associated with the column. If this parameter is –1, no subitem is associatied with the column.

Return Value

The index of the new column if it is successful; otherwise, it is –1.

Requirements
