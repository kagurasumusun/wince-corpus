CDC::LPtoDP

This method does not do anything in Windows CE. It is included for compatibility with existing code.

void LPtoDP (
LPPOINT lpPoints, 
int nCount = 1 )
const; 

void LPtoDP (
LPRECT lpRect )
const; 

void LPtoDP (
LPSIZE lpSize )
const;

Parameters

lpPoints
Pointer to an array of points. Each point in the array is a POINT structure or a CPoint object.
nCount
The number of points in the array.
lpRect
Pointer to a RECT structure or a CRect object. This parameter is used for the common case of mapping a rectangle from logical to device units.
lpSize
Pointer to a SIZE structure or a CSize object.

Remarks

In Windows CE, you cannot change the window and viewport origins or extents, which means that device coordinates are always the same as logical coordinates. Because of this, the CDC::LPtoDP method does not do anything with the values you pass it.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
