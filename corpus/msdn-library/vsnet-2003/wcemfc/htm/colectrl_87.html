COleControl::OnEnumVerbs

This method is called by the container to enumerate the verbs of a control.

Override this function to change the default way of enumerating verbs.

virtual BOOL OnEnumVerbs(
LPENUMOLEVERB* ppenumOleVerb );

Parameters

ppenumOleVerb
Specifies a pointer to the IEnumOLEVERB object that enumerates the verbs of the control.

Return Value

Nonzero if verbs are available; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
