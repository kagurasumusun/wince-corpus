CGdiObject::CreateStockObject

This method retrieves a handle to one of the predefined stock pens, brushes or fonts, and attaches the GDI object to the CGdiObject object. Call this method with one of the derived classes that corresponds to the Windows CE GDI object type, such as CPen for a stock pen.

BOOL CreateStockObject (
int nIndex );

Parameters

nIndex
A constant specifying the type of stock object desired. See the parameter fnObject for GetStockObject for a description of appropriate values.

Return Value

Nonzero if the function is successful; otherwise, it is zero.

Remarks

Windows CE does not support the following stock objects in the nIndex parameter:

  • ANSI_FIXED_FONT
  • ANSI_VAR_FONT
  • DEFAULT_PALETTE
  • OEM_FIXED_FONT
  • SYSTEM_FIXED_FONT

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
