CPrintInfo::SetMinPage

This method specifies the number of the first page of the document. Page numbers normally start at 1. This value is stored in the CPrintDialog object referenced by the m_pPD member.

void SetMinPage(
UINT nMinPage );

Parameters

nMinPage
Specifies the number of the first page of the document.
