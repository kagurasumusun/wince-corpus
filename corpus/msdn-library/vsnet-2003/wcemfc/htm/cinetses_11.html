CInternetSession::SetOption

This method sets options for the Internet session.

BOOL SetOption(
DWORD dwOption,
LPVOID lpBuffer,
DWORD dwBufferLength,
DWORD dwFlags =0);

BOOL SetOption(
DWORD dwOption,
DWORD dwValue ,
DWORD dwFlags =0);

Parameters

dwOption
Specifies the Internet option to set.
lpBuffer
Specifies a buffer that contains the option setting.
dwBufferLength
Specifies the length of lpBuffer.
dwFlags
Indicates various options such as caching and asynchronous behavior. The default is set to 0.

Return Value

If the operation was successful, a value of TRUE is returned. If an error occurred, a value of FALSE is returned. If the call fails, the Windows CE function GetLastError may be called to determine the cause of the error.

Remarks

In Windows CE, the dwFlags parameter must be zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxinet.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
