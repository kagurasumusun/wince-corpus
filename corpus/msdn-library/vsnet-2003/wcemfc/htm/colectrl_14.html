COleControl::BoundPropertyChanged

This method notifies the container that a bound property has been changed. This must be called every time the value of the property changes, even in cases where the change was not made through the property Set method. Be particularly aware of bound properties that are mapped to member variables. Any time such a member variable changes, BoundPropertyChanged must be called.

void BoundPropertyChanged(
DISPID dispid );

Parameters

dispid
Specifies the dispatch ID of a bound property of the control.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
