CGdiObject::Detach

This method detaches a Windows CE GDI object from a CGdiObject object and returns a handle to the Windows CE GDI object.

HGDIOBJ Detach( );

Return Value

A HANDLE to the Windows GDI object detached; otherwise, it is NULL if no GDI object is attached.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
