CScrollBar::CScrollBar

This constructor creates an instance of a CScrollBar object. After constructing the object, call the Create method to create and initialize the Windows CE scroll bar.

CScrollBar( );

Example

// Declare a CScrollBar control.
CScrollBar m_ScrollBar;

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
