CWinApp::LoadStandardIcon

This method loads the Windows CE predefined icon resource that lpszIconName specifies.

Use the LoadStandardIcon or LoadOEMIcon method to access the predefined Windows CE icons.

HICON LoadStandardIcon(
LPCTSTR lpszIconName )
const;

Parameters

lpszIconName
Specifies a manifest constant identifier that specifies a predefined Windows CE icon. These identifiers are defined in Windows.h. For a list of the possible predefined values and their decriptions, see the lpIconName parameter in LoadIcon.

Return Value

A handle to an icon if it is successful; otherwise, it is NULL.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also
