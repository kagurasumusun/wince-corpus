CWnd::GetScrollBarCtrl

This method obtains a pointer to the specified sibling scroll bar or splitter window.

This method does not operate on scroll bars created when the WS_HSCROLL or WS_VSCROLL bits are set during the creation of a window. The CWnd implementation of this function simply returns NULL. Derived classes, such as CView, implement the described functionality.

virtual CScrollBar* GetScrollBarCtrl(
int nBar )
const;

Parameters

nBar
Specifies the type of scroll bar. The parameter can take one of the following values:
  • SB_HORZ   Retrieves the position of the horizontal scroll bar.
  • SB_VERT   Retrieves the position of the vertical scroll bar.

Return Value

A sibling scroll-bar control, or NULL if none.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
