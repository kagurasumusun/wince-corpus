COleControl::GetRectInContainer

This method retrieves the control rectangle relative to its container.

BOOL GetRectInContainer(
LPRECT lpRect );

Parameters

lpRect
Specifies a pointer to the rectangle structure into which the control coordinates will be copied.

Return Value

Nonzero if the control is in-place active; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
