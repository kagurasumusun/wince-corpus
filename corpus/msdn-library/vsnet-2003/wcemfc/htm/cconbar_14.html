CControlBar::SetBarStyle

This method sets the desired control bar styles. It cannot be used to set window styles.

void SetBarStyle(
DWORD dwStyle );

Parameters

dwStyle
Specifies the desired styles for the control bar. Can be one or more of the following:
  • CBRS_ALIGN_TOP   Allows the control bar to dock at the top of the client area of a frame window.
  • CBRS_ALIGN_BOTTOM   Allows the control bar to dock at the bottom of the client area of a frame window.
  • CBRS_ALIGN_LEFT   Allows the control bar to dock on the left side of the client area of a frame window.
  • CBRS_ALIGN_RIGHT   Allows the control bar to dock on the right side of the client area of a frame window.
  • CBRS_ALIGN_ANY   Allows the control bar to dock on any side of the client area of a frame window.
  • CBRS_BORDER_TOP   Causes a border to be drawn on the top edge of the control bar when it is visible.
  • CBRS_BORDER_BOTTOM   Causes a border to be drawn on the bottom edge of the control bar when it is visible.
  • CBRS_BORDER_LEFT   Causes a border to be drawn on the left edge of the control bar when it is visible.
  • CBRS_BORDER_RIGHT   Causes a border to be drawn on the right edge of the control bar when it is visible.
  • CBRS_FLOAT_MULTI   Allows multiple control bars to float in a single mini-frame window.
  • CBRS_TOOLTIPS   Causes ToolTips to display for the control bar.
  • CBRS_FLYBY   Causes message text to update at the same time as ToolTips.
  • CBRS_GRIPPER   Causes a gripper bar, similar to that used on bands in a CReBar object, to be drawn for any CControlBar-derived class.

Requirements

  Header file: Declared in Afxext.h
