CHeaderCtrl::DeleteItem

This method deletes an item from a header control.

BOOL DeleteItem(
int nPos );

Parameters

nPos
Specifies the zero-based index of the item to delete.

Return Value

Nonzero if successful; otherwise, it is zero.

Example

// The pointer to myheader control.
extern CHeaderCtrl* pmyHeaderCtrl;

int nCount = pmyHeaderCtrl->GetItemCount();

// Delete all of the items.
for (int i=0;i < nCount;i++)
{
  pmyHeaderCtrl->DeleteItem(0);
}

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
