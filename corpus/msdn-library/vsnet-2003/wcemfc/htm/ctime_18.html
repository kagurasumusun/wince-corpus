CTime Comparison Operators

These operators compare two absolute times and return nonzero if the condition is true; otherwise, they return zero.

BOOL operator == (
CTime time )
const; 

BOOL operator != (
CTime time )
const; 

BOOL operator < (
CTime time )
const; 

BOOL operator > (
CTime time )
const; 

BOOL operator <= (
CTime time )
const; 

BOOL operator >= (
CTime time )
const;

Example

// example for CTime comparison operators
CTime t1 = CTime::GetCurrentTime();
CTime t2 = t1 + CTimeSpan( 0, 1, 0, 0 );    // 1 hour later
ASSERT( t1 != t2 );
ASSERT( t1 < t2 );
ASSERT( t1 <= t2 );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
