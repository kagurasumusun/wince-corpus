CListCtrl::GetFirstSelectedItemPosition

This method gets the position of the first selected item in the list view control.

POSITION GetFirstSelectedItemPosition( )
const;

Return Value

A POSITION value that can be used for iteration or object pointer retrieval; NULL if no items are selected.

Example

// CListCtrl* pListCtrl = (CListCtrl*) GetDlgItem(IDC_YOURLISTCONTROL);
ASSERT(pListCtrl != NULL);

POSITION pos = pList->GetFirstSelectedItemPosition();
if (pos == NULL)
   TRACE0("No items were selected!\n");
else
{
  while (pos)
  {
     int nItem = pList->GetNextSelectedItem(pos);
     TRACE1("Item %d was selected!\n", nItem);
     // you could do your own processing on nItem here
  }
}

Requirements
