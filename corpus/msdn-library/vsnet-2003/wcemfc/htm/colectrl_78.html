COleControl::OnAppearanceChanged

This method is called by the framework when the stock Appearance property is changed. Override this function if you want notification after this property changes. The default implementation calls InvalidateControl.

virtual void OnAppearanceChanged ( );

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
