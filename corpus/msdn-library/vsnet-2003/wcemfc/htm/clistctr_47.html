CListCtrl::Scroll

This method scrolls the content of a list view control.

BOOL Scroll(
CSize size );

Parameters

size
A CSize object specifying the amount of horizontal and vertical scrolling, in pixels. The y member of size is divided by the height, in pixels, of the list view control line, and the control scrolls by the resulting number of lines.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements
