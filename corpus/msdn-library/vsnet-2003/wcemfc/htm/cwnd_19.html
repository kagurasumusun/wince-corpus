CWnd::Default

This method calls the default window procedure. The default window procedure provides default processing for any window message that an application does not process. This method ensures that every message is processed. 

LRESULT Default( );

Return Value

Depends on the message sent.

Example

// This sample shows how to avoid any button handling in base class,
// if any, and call the default window procedure directly.
void CTestwndView::OnLButtonDown(UINT nFlags, CPoint point)
{
  CWnd::Default();
}

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
