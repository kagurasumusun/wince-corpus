CSliderCtrl::GetLineSize

This method retrieves the size of the line for a slider control. The line size affects how much the slider moves for the TB_LINEUP and TB_LINEDOWN notifications. The default setting for the line size is one.

int GetLineSize( )
const;

Return Value

The size of a line for the slider control.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
