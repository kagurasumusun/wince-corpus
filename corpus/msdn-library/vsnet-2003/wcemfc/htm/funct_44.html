AfxOleInit

This function initializes the OLE DLLs.

BOOL AFXAPI AfxOleInit( );

Return Value

Nonzero if successful; 0 if initialization fails, possibly because incorrect versions of the OLE system DLLs are installed.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxdisp.h.
  Platform: H/PC Pro, Palms-size PC, Pocket PC
