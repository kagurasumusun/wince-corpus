CEdit::GetLineCount

This method retrieves the number of lines in a multiple-line edit control. 

int GetLineCount( )
const;

Return Value

An integer containing the number of lines in the multiple-line edit control. If no text has been entered into the edit control, the return value is one.

Remarks

GetLineCount is only processed by multiple-line edit controls.

For more information, see the Windows CE message EM_GETLINECOUNT.

Example

#ifdef _DEBUG
  // The pointer to my edit.
  extern CEdit* pmyEdit;

  int i, nLineCount = pmyEdit->GetLineCount();
  CString strText, strLine;

  // Dump every line of text in the edit control.
  for (i=0;i < nLineCount;i++)
  {
    pmyEdit->GetLine(i, strText.GetBuffer(pmyEdit->LineLength(i)));
    strText.ReleaseBuffer();

    strLine.Format(TEXT("line %d: '%s'\r\n"), i, strText.GetBuffer(0));
    afxDump << strLine;
  }
#endif

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
