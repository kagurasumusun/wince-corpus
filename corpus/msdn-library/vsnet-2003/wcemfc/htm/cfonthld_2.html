CFontHolder::CFontHolder

This constructor creates an instance of a CFontHolder object. You must call InitializeFont to initialize the resulting object before using it.

CFontHolder(
LPPROPERTYNOTIFYSINK pNotify );

Parameters

pNotify
Specifies the pointer to the IPropertyNotifySink interface of the font.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
