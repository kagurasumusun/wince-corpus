CArchive::Write

This method writes a specified number of bytes to the archive. The archive does not format the bytes.

void Write(
const void* lpBuf,
UINT nMax );

Parameters

lpBuf
A pointer to a user-supplied buffer that contains the data to write to the archive.
nMax
An integer that specifies the number of bytes to write to the archive.

Remarks

You can use the Write method within your Serialize function to write ordinary structures that are contained in your objects.

Example

extern CArchive ar;
char pb[100];
ar.Write( pb, 100 );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
