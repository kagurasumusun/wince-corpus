CEditView::CEditView

This constructor creates an instance of a CEditView object. After constructing the object, you must call the CWnd::Create method before the edit control is used. If you derive a class from CEditView and add it to the template using CWinApp::AddDocTemplate, the framework calls both this constructor and the Create method.
