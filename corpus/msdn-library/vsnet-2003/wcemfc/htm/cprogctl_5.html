CProgressCtrl::GetRange

This method retrieves the current lower and upper limits of the progress bar control. It also copies the values of the lower and upper limits to the integers referenced by nLower and nUpper, respectively.

void GetRange(
int& nLower,
int& nUpper );

Parameters

nLower
Specifies a reference to an integer receiving the lower limit of the progress bar control.
nUpper
Specifies a reference to an integer receiving the upper limit of the progress bar control.

Example

CProgressCtrl myCtrl;

// Create a child progress control.
myCtrl.Create(WS_CHILD|WS_VISIBLE, CRect(10,10,200,30), pParentWnd, 1);

// Set the position to be one-fourth of the total range.
int nLower, nUpper;
myCtrl.GetRange( nLower, nUpper );
myCtrl.SetPos( (nUpper-nLower)/4 );
