CImageList::GetImageInfo

This method retrieves information about an image.

The IMAGEINFO structure contains information about an image in an image list.

BOOL GetImageInfo(
int nImage,
IMAGEINFO* pImageInfo )
const;

Parameters

nImage
Specifies the zero-based index of the image.
pImageInfo
Specifies the pointer to an IMAGEINFO structure that receives information about the image. The information in this structure can be used to directly manipulate the bitmaps for the image.

Return Value

Nonzero if successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
