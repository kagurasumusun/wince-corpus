CCeSocket::OnAccept

This method is called by the framework to notify a listening socket that it can accept pending connection requests. Override this method to do special processing.

virtual void OnAccept(
int nErrorCode );

Parameters

nErrorCode
Specifies the most recent error on a socket. Zero indicates that the method executed successfully. WSAENETDOWN indicates that the network subsystem failed.

Return Values

None.

Remarks

This method calls CSocket::OnAccept by default.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcesock.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
