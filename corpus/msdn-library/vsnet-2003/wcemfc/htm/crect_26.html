CRect::operator =

This operator assigns the srcRect rectangle to a CRect object.

void operator =(
const RECT& srcRect );

Parameters

srcRect
Refers to a source rectangle. Can be a RECT or CRect.

Example

CRect rect(0, 0, 127, 168);
CRect rect2;

rect2 = rect;

ASSERT(rect2 == CRect(0, 0, 127, 168));

Requirements

  Header file: Declared in Afxwin.h
