COleControl::AmbientTextAlign

This method retrieves the type of text alignment specified by the container. This property is available to all embedded controls and is defined by the container. Note that the container is not required to support this property.

short AmbientTextAlign( );

Return Value

Returns the status of the ambient TextAlign property of the container. If this property is not supported, this function returns zero.

The following is a list of valid return values:

Return Value Description
0 General alignment (numbers to the right, text to the left).
1 Left justify
2 Center
3 Right justify

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
