CImageList::Remove

This method removes an image from an image list object. All items following nImage now move down one position. For example, if an image list contains two items, deleting the first item will cause the remaining item to now be in the first position. nImage=0 for the item in the first position.

BOOL Remove(
int nImage );

Parameters

nImage
Zero-based index of the image to remove.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// Pointer to the myImageList.
extern CImageList* pmyImageList;

// Remove every other image from the image list.
for (int i=0;i < pmyImageList->GetImageCount();i++)
{
  pmyImageList->Remove(i);
}

Requirements
