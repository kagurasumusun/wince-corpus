CCeDBProp::GetString

This method retrieves the value of a property, when the property data type is a wide (Unicode) character string.

LPWSTR GetString( )
const;

Return Values

A pointer to the string represented by the property.

Remarks

You can only call GetString on a property of the type CCeDBProp::Type_String.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
