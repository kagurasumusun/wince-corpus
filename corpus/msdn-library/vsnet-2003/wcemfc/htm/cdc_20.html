CDC::EndPage

This method informs the device that the application has finished writing to a page. This method is typically used to direct the device driver to advance to a new page.

int EndPage( );

Return Value

Greater than or equal to zero if successful; otherwise, it is one of the following error values:

SP_ERROR
General error.
SP_APPABORT
Job was ended because the abort function of the application returned zero.
SP_USERABORT
User ended the job through the print manager.
SP_OUTOFDISK 
Not enough disk space is available for spooling, and no more space will become available.
SP_OUTOFMEMORY 
Not enough memory is available for spooling.

Remarks

This method replaces the NEWFRAME printer escape. Unlike NEWFRAME, this function is always called after printing a page.
