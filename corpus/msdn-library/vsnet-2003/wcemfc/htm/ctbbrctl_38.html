CToolBarCtrl::LoadImages

This method loads bitmaps into an image list of a toolbar control.

This method implements the behavior of the Windows CE message TB_LOADIMAGES.

void LoadImages(
int iBitmapID,
HINSTANCE hinst );

Parameters

iBitmapID
Specifies the ID of a bitmap that contains the images to be loaded. To specify your own bitmap resource, set this parameter to the ID of a bitmap resource and set hInst to NULL. Your bitmap resource will be added to the image list as a single image. You can add standard, system-defined bitmaps by setting hinst to HINST_COMMCTRL and setting this parameter to one of the following IDs:
Bitmap ID Description
IDB_HIST_LARGE_COLOR Explorer bitmaps in large size
IDB_HIST_SMALL_COLOR Explorer bitmaps in small size
IDB_STD_LARGE_COLOR Standard bitmaps in large size
IDB_STD_SMALL_COLOR Standard bitmaps in small size
IDB_VIEW_LARGE_COLOR View bitmaps in large size
IDB_VIEW_SMALL_COLOR View bitmaps in small size

hinst
Specifies the program instance handle to the calling application. This parameter can be HINST_COMMCTRL to load a standard image list.
