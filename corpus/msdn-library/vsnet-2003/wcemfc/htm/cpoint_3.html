CPoint::Offset

This method adds to the values of the x and y members of the CPoint object.

void Offset(
int xOffset,
int yOffset ); 

void Offset(
POINT point ); 

void Offset(
SIZE size );

Parameters

xOffset
Specifies the amount to offset the x member of the CPoint.
yOffset
Specifies the amount to offset the y member of the CPoint.
point
Specifies the amount, in POINT or CPoint, to offset the CPoint.
size
Specifies the amount, in SIZE or CSize, to offset the CPoint.

Example

CPoint  ptStart(100, 100);
ptStart.Offset(35, 35);

CPoint  ptResult(135, 135);
ASSERT(ptStart == ptResult);

// This works with POINT, too.

ptStart = CPoint(100, 100);
POINT pt;

pt.x = 35;
pt.y = 35;

ptStart.Offset(pt);

ASSERT(ptStart == ptResult);

// It works with SIZE, too.

ptStart = CPoint(100, 100);
SIZE size;

size.cx = 35;
size.cy = 35;

ptStart.Offset(size);

ASSERT(ptStart == ptResult);
