CTypedPtrArray::SetAt

This method sets the array element at the specified index. SetAt will not cause the array to grow. Use CTypedPtrArray::SetAtGrow if you want the array to grow automatically.

You must ensure that your index value represents a valid position in the array. If it is out of bounds, then the Debug version of the library asserts.

void SetAt(
int nIndex,
TYPE ptr );

Parameters

nIndex
Specifies an integer index that is greater than or equal to 0 and less than or equal to the value returned by CObArray::GetUpperBound.
TYPE
Specifies the type of the elements stored in the base-class array.
ptr
Specifies a pointer to the element to be inserted in the array at the nIndex. A NULL value is allowed.

Requirements
