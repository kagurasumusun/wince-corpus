CHttpFile::SendRequest

This method sends a request to an HTTP server.

BOOL SendRequest(
LPCTSTR pstrHeaders = NULL,
DWORD dwHeadersLen = 0,
LPVOID lpOptional = NULL,
DWORD dwOptionalLen = 0);

BOOL SendRequest(
CString& strHeaders,
LPVOID lpOptional = NULL,
DWORD dwOptionalLen = 0);

Parameters

pstrHeaders
Specifies a pointer to a string containing the name of the headers to send.
dwHeadersLen
Specifies the length of the headers identified by pstrHeaders.
lpOptional
Specifies any optional data to send immediately after the request headers. This is generally used for POST and PUT operations. This can be NULL if there is no optional data to send.
dwOptionalLen
Specifies the length of lpOptional.
strHeaders
Specifies a string containing the name of the headers for the request being sent.

Return Value

Nonzero if it is successful; otherwise, it is zero. If the call fails, determine the cause of the failure by examining the thrown CInternetException object.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxinet.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
