COleCurrency::operator <<, >>

The insertion (<<) operator is used for diagnostic dumping and storing to an archive. The extraction (>>) operator is used for loading from an archive.

CDumpContext& AFXAPI operator <<(
CDumpContext& dc,
COleCurrency curSrc ); 

CArchive& AFXAPI operator <<(
CArchive& ar,
COleCurrency curSrc ); 

CArchive& AFXAPI operator >>(
CArchive& ar,
COleCurrency& curSrc );

Parameters

dc
Specifies the CDumpContext object as the device context used by the COleCurrency object.
curSrc
An existing COleCurrency object to be copied into the new COleCurrency object.
ar
A CArchive object to use with the COleCurrency object.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
