CGdiObject::FromHandle

This method obtains a pointer to a CGdiObject object given a handle to a Windows CE GDI object. If a CGdiObject object is not already attached to the Windows CE GDI object, a temporary CGdiObject object is created and attached.

This temporary CGdiObject object is only valid until the next time the application has idle time in its event loop, at which time all temporary graphic objects are deleted. Alternately, the temporary object is only valid during the processing of one window message.

static CGdiObject* PASCAL FromHandle(
HGDIOBJ hObject );

Parameters

hObject
Specifies a HANDLE to a Windows GDI object.

Return Value

Returns a pointer to a CGdiObject that may be temporary or permanent.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
