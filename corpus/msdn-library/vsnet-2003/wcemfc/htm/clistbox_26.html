CListBox::GetTextLen

This method retrieves the length of a string in a list-box item.

int GetTextLen(
int nIndex )
const;

Parameters

nIndex
Specifies the zero-based index of the string.

Return Value

Returns the length of the string in bytes, excluding the terminating null character. If nIndex does not specify a valid index, the return value is LB_ERR.

See the example for CListBox::GetText.
