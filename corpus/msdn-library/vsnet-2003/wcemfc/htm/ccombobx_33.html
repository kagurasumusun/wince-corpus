CComboBox::Paste

This method inserts the data from the clipboard in the edit control of the combo box at the current cursor position. Data is inserted only if the clipboard contains data in CF_TEXT format.

void Paste( );

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Replace the text in the combo box edit control with the text in the
// clipboard.
pmyComboBox->SetEditSel(0, -1);
pmyComboBox->Paste();

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
