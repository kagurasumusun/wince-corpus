CToolBarCtrl::SetBitmapSize

This method sets the size of the actual bitmapped images to be added to a toolbar control. This method must be called only before adding any bitmaps to the toolbar. If the application does not explicitly set the bitmap size, it defaults to 16 by 15 pixels.

BOOL SetBitmapSize(
CSize size );

Parameters

size
Specifies the width and height, in pixels, of the bitmapped images.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
