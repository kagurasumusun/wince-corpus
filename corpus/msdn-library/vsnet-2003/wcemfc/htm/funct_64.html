AfxThrowOleException

This function creates an object of type COleException and throws an exception. The version that takes an HRESULT as an argument converts that result code into the corresponding SCODE. 

void AFXAPI AfxThrowOleException(
SCODE sc );
void AFXAPI AfxThrowOleException(
HRESULT hr );

Parameters

sc
Specifies an OLE status code that indicates the reason for the exception.
hr
Specifies the tandle to a result code that indicates the reason for the exception.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palms-size PC, Pocket PC
