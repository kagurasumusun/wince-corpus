CPropExchange::ExchangePersistentProp

This method exchanges a property between the control and a file. The CArchivePropExchange::ExchangePersistentProp, CResetPropExchange::ExchangePersistentProp, and CPropsetPropExchange::ExchangePersistentProp methods override this pure virtual method.

If the property is being loaded from the file to the control, the property is created and initialized from the file. If the property is being stored, its value is written to the file.

virtual BOOL ExchangePersistentProp(
LPCTSTR pszPropName,
LPUNKNOWN* ppUnk,
REFIID iid,
LPUNKNOWN pUnkDefault ) = 0;

Parameters

pszPropName
Specifies the name of the property being exchanged.
ppUnk
Specifies a pointer to a variable containing a pointer to the IUnknown interface of the property. This variable is typically a member of your class.
iid
Specifies the interface ID of the interface on the property that the control will use.
pUnkDefault
Specifies the default value for the property.

Return Value

Nonzero if the exchange was successful; zero if it is unsuccessful.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
