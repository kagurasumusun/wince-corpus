CFormView

This class is the base class used for views containing controls. A form view is essentially a view that contains controls. These controls are laid out based on a dialog-template resource. Use CFormView if you want forms in your application. These views support scrolling, as needed, using the CScrollView functionality.

When you are creating a forms-based application, you can base its view class on CFormView, making it a forms-based application.

You can also insert a new form topic into document-view-based applications. Even if your application did not initially support forms, eMbedded Visual C++ will add this support when you insert a new form.

The WCE MFC AppWizard and the New Form command are the preferred methods for creating forms-based applications.
