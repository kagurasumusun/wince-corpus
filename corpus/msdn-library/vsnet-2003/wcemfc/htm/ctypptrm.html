CTypedPtrMap

This class provides a type-safe wrapper for objects of class CPtrMap or CObMap. When you use CTypedPtrMap rather than CPtrList or CObMap, the C++ type-checking facility helps eliminate errors caused by mismatched pointer types.

Because all CTypedPtrMap functions are inline, use of this template does not significantly affect the size or speed of your code.

template<
class BASE_CLASS,
class KEY,
class VALUE >
class CTypedPtrMap :
public BASE_CLASS

Parameters

BASE_CLASS
Specifies the base class of the typed pointer map class; must be a pointer map class (CMapPtrToPtr, CMapPtrToWord, CMapWordToPtr, or CMapStringToPtr).
KEY
Specifies the class of the object used as the key to the map.
VALUE
Specifies the class of the object stored in the map.
