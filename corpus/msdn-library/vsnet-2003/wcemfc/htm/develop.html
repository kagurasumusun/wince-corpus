Developing Applications

Using MFC to develop applications for Windows CE is basically the same as using MFC to develop desktop applications. Your experience as an MFC developer and the resources to which you are accustomed will provide a significant benefit to you as you develop applications for Windows CE platforms.

The major differences between developing for the desktop and for Windows CE platforms include the following:

  • Small target devices require that you cope with limited data storage and limited battery power.
  • The desktop MFC library is somewhat customized for Windows CE. The MFC for Windows CE library includes classes not available for the desktop, and some desktop classes not fully supported for Windows CE. Some desktop classes are not supported at all.

    To view the differences between the desktop and Windows CE library contents, see "Differences from Desktop MFC."

  • Different target platform SDKs may present you with different development guidelines, depending on the target device. For example, it might not be appropriate to utilize a given class on a particular device, even though it is supported. User interface issues are particularly dependent on the specific target.

The topics that follow in this "Developing Applications" section provide sample issues in application development. These issues are not meant to be exhaustive. For collateral material:

  • Continue to use the same MFC documentation and resources that you are familiar with. Just be aware of the different library contents as described in "Differences from Desktop MFC."
  • Refer to the documentation in the Table of Contents under Microsoft® eMbedded Visual C++® 3.0, of which this MFC documentation is a subset. Many additional MFC techniques are described in the eMbedded Visual C++ documentation.
  • Review the documentation for your target SDK.
  • Take advantage of the many MFC sample projects provided with eMbedded Visual C++. The Introduction to the MFC Samples section briefly describes each project and provides a link to its more detailed description. Each detail topic provides you with a button that opens the project in the IDE.
