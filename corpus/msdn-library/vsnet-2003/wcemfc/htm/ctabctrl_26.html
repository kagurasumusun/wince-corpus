CTabCtrl::SetItemExtra

This method implements the behavior of the Windows CE message TCM_SETITEMEXTRA. 

BOOL SetItemExtra(
int nBytes );

Parameters

nBytes
Specifies the number of extra bytes to set.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
