CDocTemplate::GetNextDoc

This method retrieves the list element identified by rPos, and sets rrPos to the POSITION value of the next entry in the list. If the retrieved element is the last in the list, then the new value of rPos is set to NULL.

virtual CDocument* GetNextDoc(
POSITION& rPos )
const = 0;

Parameters

rPos
Specifies a reference to a POSITION value returned by a previous call to GetFirstDocPosition or GetNextDoc.

Return Value

A pointer to the next document in the list of documents associated with this template.

Remarks

You can use GetNextDoc in a forward iteration loop if you establish the initial position with a call to GetFirstDocPosition.

You must ensure that your POSITION value represents a valid position in the list. If it is invalid, then the Debug version of MFC for Windows CE asserts.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
