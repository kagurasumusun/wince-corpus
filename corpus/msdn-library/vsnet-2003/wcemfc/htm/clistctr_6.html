CListCtrl::DeleteAllItems

This method deletes all items from the list view control.

BOOL DeleteAllItems( );

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

// Delete all of the items from the list view control.
pmyListCtrl->DeleteAllItems();
ASSERT(pmyListCtrl->GetItemCount() == 0);

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
