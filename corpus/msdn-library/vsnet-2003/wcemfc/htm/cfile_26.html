CFile::m_hFile

This data member contains the operating-system file handle for an open file. It contains CFile::hFileNull, an operating-system-independent empty file indicator, if the handle has not been assigned.

Use of m_hFile is not recommended because the meaning of the member depends on the derived class. m_hFile is made a public member for convenience in supporting nonpolymorphic use of the class.

UINT m_hFile;

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
