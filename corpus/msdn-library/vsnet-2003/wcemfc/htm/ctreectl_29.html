CTreeCtrl::GetRootItem

This method retrieves the root item of the tree view control.

HTREEITEM GetRootItem( )
const;

Return Value

The handle of the root item; otherwise, it is NULL.

Example

See the example for CTreeCtrl::EditLabel.
