Microsoft® Foundation Class Library for Windows® CE

Microsoft® eMbedded Visual Tools 3.0 includes MFC library versions that support each of the three SDKs included in the toolkit: the H/PC Pro, Palm-size PC 1.2, and the new Pocket PC.

These library versions are designed to be used in conjunction with Microsoft® eMbedded Visual C++® 3.0.

The Reference section of the documentation covers the H/PC Pro, Palm-size PC 1.2, and Pocket PC SDKs.

For the latest information about Windows CE, visit the Microsoft Windows CE World Wide Web site, www.microsoft.com/windowsce/.
