CPoint::operator +=

This operator adds the x (or cx) member of the right operand to the x member of the CPoint object and the y (or cy) member of the right operand to the y member of the CPoint object.

For example, adding CPoint(5, -7) to a variable which contains CPoint(30, 40) changes the variable to CPoint(35, 33).

void operator +=(
SIZE size ); 

void operator +=(
POINT point );

Parameters

size
Contains a SIZE structure or CSize object.
point
Contains a POINT structure or CPoint object.

Example

CPoint  ptStart(100, 100);
CSize  szOffset(35, 35);

ptStart += szOffset;

CPoint  ptResult(135, 135);

ASSERT(ptResult == ptStart);

// This also works on SIZE.

ptStart = CPoint(100, 100);

SIZE  sz;
sz.cx = 35;
sz.cy = 35;

ptStart += sz;

ASSERT(ptResult == ptStart);
