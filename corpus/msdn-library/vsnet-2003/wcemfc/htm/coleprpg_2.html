COlePropertyPage::COlePropertyPage

This constructor creates an instance of a property page object. When you subclass COlePropertyPage, the constuctor of your subclass should call the COlePropertyPage constructor to identify the dialog-template resource on which the property page is based and the string resource that contains its caption.

COlePropertyPage(
UINT idDlg,
UINT idCaption );

Parameters

idDlg
Specifies the resource ID of the dialog template.
idCaption
Resource ID of the property page caption.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
