CMemFile::GrowFile

This method is called by several of the CMemFile methods. Override this method to change the way CMemFile grows its memory file.

The default implementation calls Realloc to grow an existing block, or Alloc to create a memory block, allocating memory in multiples of the nGrowBytes value specified in the constructor or Attach call.

virtual void GrowFile(
DWORD dwNewLen );

Parameters

dwNewLen
Specifies the new size of the memory file.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
