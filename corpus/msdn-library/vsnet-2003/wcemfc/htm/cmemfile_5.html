CMemFile::Detach

This method closes the memory file and retrieves a pointer to the memory block being used by the CMemFile object.

BYTE* Detach( );

Return Value

A pointer to the memory block that contains the contents of the memory file.

Remarks

Calling this method also closes the CMemFile. You can reattach the memory block to CMemFile by calling Attach. If you want to reattach the file and use the data in it, you should call CFile::GetLength to get the length of the file before calling Detach. Note that if you attach a memory block to CMemFile so that you can use its data, nGrowBytes == 0, you will not be able to grow the memory file.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
