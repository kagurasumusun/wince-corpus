CToolBarCtrl::SetButtonInfo

This method sets the information for an existing button in a toolbar.

The method implements the behavior of the Windows CE message TB_SETBUTTONINFO.

BOOL SetButtonInfo(
int nID,
TBBUTTONINFO* ptbbi );

Parameters

nID
Specifies the button identifier.
ptbbi
Specifies a pointer to a TBBUTTONINFO structure that receives the button information.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
