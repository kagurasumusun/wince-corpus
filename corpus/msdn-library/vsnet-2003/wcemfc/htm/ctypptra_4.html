CTypedPtrArray::Copy

This method retrieves a temporary reference to the specified element within the array. This method is used to implement the left-side assignment operator for arrays.

void Copy(
const CTypedPtrArray <
BASE_CLASS, TYPE>& src );

Parameters

BASE_CLASS
Specifies the base class of the typed pointer array class; must be an array class (CObArray or CPtrArray).
TYPE
Specifies the type of the elements stored in the base-class array.
src
Specifies the source of the elements to be copied to an array.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxtempl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
