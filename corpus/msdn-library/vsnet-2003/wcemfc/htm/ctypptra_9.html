CTypedPtrArray::SetAtGrow

This method sets the array element at the specified index. The array grows automatically if necessary; that is, the upper bound is adjusted to accommodate the new element.

void SetAtGrow(
int nIndex,
TYPE newElement );

Parameters

nIndex
Specifies an integer index that is greater than or equal to 0.
TYPE
Specifies the type of the elements stored in the base-class array.
newElement
Specifies the object pointer to be added to this array. A NULL value is allowed.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxtempl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
