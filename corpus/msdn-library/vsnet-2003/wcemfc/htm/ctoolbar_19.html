CToolBar::SetHeight

This method sets the height of the toolbar to the value, in pixels, specified in cyHeight.

After calling SetSizes, use this method to override the standard toolbar height. If the height is too small, the buttons will be clipped at the bottom.

void SetHeight(
int cyHeight );

Parameters

cyHeight
The height in pixels of the toolbar.

Remarks

If this function is not called, the framework uses the size of the button to determine the toolbar height. Call the SetHeight method after SetSizes, as this method overrides the bitmap size.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
