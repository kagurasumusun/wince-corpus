CProgressCtrl::SetStep

This method specifies the step increment for a progress bar control. The step increment is the amount by which a call to CProgressCtrl::StepIt increases the current position in the progress bar.

The default step increment is 10.

int SetStep(
int nStep );

Parameters

nStep
Specifies the new step increment.

Return Value

Returns the previous step increment.

Example

CProgressCtrl myCtrl;

// Create a child progress control.
myCtrl.Create(WS_CHILD|WS_VISIBLE, CRect(10,10,200,30), pParentWnd, 1);

// Set the size to be 1/10 of the total range.
int nLower, nUpper;
myCtrl.GetRange( nLower, nUpper );
myCtrl.SetStep( (nUpper-nLower)/10 );
