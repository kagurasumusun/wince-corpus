CListCtrl::GetOrigin

This method retrieves the current view origin for a list view control.

BOOL GetOrigin(
LPPOINT lpPoint )
const;

Parameters

lpPoint
Specifies the address of a POINT structure that receives the view origin.

Return Value

Nonzero if it is successful; otherwise, it is zero. However, if the control is in report view, the return value is always zero.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
