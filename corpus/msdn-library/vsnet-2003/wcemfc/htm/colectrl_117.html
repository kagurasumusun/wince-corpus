COleControl::OnSetExtent

This method is called by the framework when the extent of the control needs to be changed, as a result of a call to IOleObject::SetExtent. The default implementation handles the resizing of the extent of a control. If the control is in-place active, a call to the OnPosRectChanged of the container is then made.

Override this function to alter the default resizing of your control.

virtual BOOL OnSetExtent(
LPSIZEL lpSizeL );

Parameters

lpSizeL
Specifies a pointer to the SIZEL structure that uses long integers to represent the width and height of the control, expressed in HIMETRIC units.

Return Value

Nonzero if the size change was accepted; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
