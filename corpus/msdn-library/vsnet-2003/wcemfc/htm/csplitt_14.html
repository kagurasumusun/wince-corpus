CSplitterWnd::DoScrollBy

This method is called by the framework in response to a scroll message, to perform synchronized scrolling of the split windows by the amount, in pixels, indicated by sizeScroll. Positive values indicate scrolling down and to the right; negative values indicate scrolling up and to the left.

Override to require an action by the user before allowing scroll.

virtual BOOL DoScrollBy(
CView* pViewFrom,
CSize sizeScroll,
BOOL bDoScroll = TRUE );

Parameters

pViewFrom
Specifies a pointer to the view from which the scrolling message originates.
sizeScroll
Specifies the number of pixels to be scrolled horizontally and vertically.
bDoScroll
Determines whether the specified scrolling action occurs. If bDoScroll is TRUE, that is, if a child window exists, and if the split windows have a scroll range, then the specified scrolling action can take place; if bDoScroll is FALSE, that is, if no child window exists, or the split views have no scroll range, then scrolling does not occur.

Return Value

Nonzero if synchronized scrolling occurs; otherwise, it is zero.

Requirements
