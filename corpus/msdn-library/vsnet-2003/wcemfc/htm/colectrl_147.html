COleControl::SetModifiedFlag

This method changes the modified state of a control. For example, if the value of a persistent property changes, call this method with bModified TRUE.

void SetModifiedFlag(
BOOL bModified = TRUE );

Parameters

bModified
Specifies the new value for the modified flag of the control. TRUE indicates that the state of the control has been modified; FALSE indicates that the state of the control has just been saved.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
