COleStreamFile::Attach

This method associates the supplied COM stream with the COleStreamFile object. The object must not already be associated with a COM stream.

void Attach(
LPSTREAM lpStream );

Parameters

lpStream
Points to the OLE stream (IStream) to be associated with the object. Cannot be NULL.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxole.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
