CEdit::Cut

This method deletes or cuts the current selection in the edit control and copies the deleted text to the clipboard in CF_TEXT format.

void Cut();

Remarks

The deletion performed by Cut can be undone by calling the Undo method.

To delete the current selection without placing the deleted text into the Clipboard, call the Clear method.

For more information, see the Windows CE message WM_CUT.

Example

// The pointer to my edit.
extern CEdit* pmyEdit;

// Delete all of the text and copy it to the clipboard.
pmyEdit->SetSel(0, -1);
pmyEdit->Cut();

Requirements

  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
