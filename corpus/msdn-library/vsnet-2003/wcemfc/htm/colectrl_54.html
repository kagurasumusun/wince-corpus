COleControl::GetFocus

This method determines whether the COleControl object has the focus. An activated windowless control receives the focus when COleControl::SetFocus is called.

CWnd* GetFocus( );

Return Value

If the control is activated and windowless, returns this if the control currently has the keyboard focus, as determined by the control container, or NULL if it does not have the focus.

Otherwise, returns the CWnd object that has the focus, this is the same as CWnd::GetFocus.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
