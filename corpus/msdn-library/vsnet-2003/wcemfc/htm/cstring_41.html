CString::operator <<, >>

This insertion (<<) operator for diagnostic dumping and storing to an archive.

Use this extraction (>>) operator for loading from an archive.

The CDumpContext operators are valid only in the Debug version of the MFC for Windows CE.

friend CArchive& AFXAPI operator <<(
CArchive& ar,
const CString& string );

friend CArchive& AFXAPI operator >>(
CArchive& ar,
CString& string );

friend CDumpContext& AFXAPI operator <<(
CDumpContext& dc,
const CString& string );

Parameters

string
Specifies CString objects to concatenate.

Example

The following example demonstrates the use of CString::operator <<, >>.

// example for CString::operator <<, >>
    extern CArchive ar;
    CString s( "abc" );
#ifdef _DEBUG
    afxDump << s;  // Prints the value (abc)
    afxDump << &s;  // Prints the address
#endif

    if( ar.IsLoading() )
        ar >> s;
    else
        ar << s;

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
