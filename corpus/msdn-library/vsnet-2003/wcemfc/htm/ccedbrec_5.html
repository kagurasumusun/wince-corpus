CCeDBRecord::DeleteAllProps

This method deletes all the properties from the record.

void DeleteAllProps( );

Return Values

None.

Remarks

DeleteAllProps releases all pointers to properties stored in the internal list of the record, and frees their associated member strings CEBLOB structures. The internal list of the CCeDBRecord object only contains pointers to properties that are created by calling ReadCurrRecord. If there are properties in the record that have been added using the AddProp or AddProps methods, DeleteAllProps does not release the memory occupied by those properties.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Wcedb.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
