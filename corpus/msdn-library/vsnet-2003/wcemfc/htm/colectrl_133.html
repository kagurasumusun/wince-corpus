COleControl::SerializeExtent

This method serializes or initializes the display space for the control.

void SerializeExtent(
CArchive& ar );

Parameters

ar
Specifies a CArchive object to serialize to or from.

Remarks

You can improve the binary persistence performance of a control by using SerializeExtent, SerializeStockProps, and SerializeVersion to override COleControl::Serialize. See the following example.

Example

void CMyCtrl::Serialize(CArchive& ar)
{
    DWORD dwVersion =
        SerializeVersion(ar, MAKELONG(_wVerMinor, _wVerMajor));
    SerializeExtent(ar);
    SerializeStockProps(ar);

    if (ar.IsLoading())
    {
        // Load custom properties here.
    }
    else
    {
        // Save custom properties here.
    }
}

Requirements
