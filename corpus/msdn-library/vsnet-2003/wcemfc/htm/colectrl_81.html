COleControl::OnClick

This method is called by the framework when a mouse button is clicked or the stylus is tapped on a touch screen, to fire the stock Click event.

Override this method to modify or extend the default handling.

virtual void OnClick(
USHORT iButton );

Parameters

iButton
Specifies the index of a mouse button. Can have one of the following values:
  • LEFT_BUTTON   The left mouse button was clicked.
  • MIDDLE_BUTTON   The middle mouse button was clicked.
  • RIGHT_BUTTON   The right mouse button was clicked.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
