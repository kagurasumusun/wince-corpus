CRebar::AddBar

This method adds a band to the rebar.

BOOL AddBar(
CWnd* pBar,
LPCTSTR pszText = NULL,
CBitmap* pbmp = NULL,
DWORD dwStyle = RBBS_GRIPPERALWAYS | RBBS_FIXEDBMP ); 

BOOL AddBar(
CWnd* pBar,
COLORREF clrFore,
COLORREF clrBack,
LPCTSTR pszText = NULL,
DWORD dwStyle = RBBS_GRIPPERALWAYS );

Parameters

pBar
Specifies a pointer to a CWnd object that is the child window to be inserted into the rebar. The referenced object must have a WS_CHILD.
pszText
Specifies a pointer to a string containing the text to appear on the rebar. NULL by default. The text contained in pszText is not part of the child window; it is on the rebar itself.
pbmp
Specifies a pointer to a CBitmap object to be displayed on the rebar background. NULL by default.
dwStyle
Specifies a DWORD containing the style to apply to the rebar. See the fStyle function description in the Windows CE structure REBARBANDINFO for a complete list of band styles.
clrFore
Specifies a COLORREF value that represents the foreground color of the rebar.
clrBack
Specifies a COLORREF value that represents the background color of the rebar.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

// Define a pointer to a CRebar in your class definition,
// such as: CReBar* m_pReBar; More often, however, you
// would probably specify an instance in your class
// definition, such as: CReBar m_ReBar;
m_pReBar = new CReBar();
m_pReBar->Create(this);
m_wndDlgBar.Create(this, IDR_MAINFRAME, CBRS_ALIGN_TOP,
   AFX_IDW_DIALOGBAR);
m_pReBar->AddBar(&m_wndDlgBar);
