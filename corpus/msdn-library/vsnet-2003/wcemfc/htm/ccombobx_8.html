CComboBox::Cut

This method cuts the selection in the combo box edit control and copies the deleted text to the clipboard in CF_TEXT format.

void Cut( );

Remarks

To delete the selection without placing the deleted text onto the clipboard, call the Clear method.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Delete the text from the combo box edit control and copy it
// to the clipboard.
pmyComboBox->SetEditSel(0, -1);
pmyComboBox->Cut();

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
