CTypedPtrList::SetAt

This method writes the object pointer to the specified position in the list. The pos parameter is a key for the list. It is not the same as an index, and you cannot operate on its value yourself.

void SetAt(
POSITION pos,
TYPE newElement );

Parameters

pos
Specifies the POSITION of the element to be set.
TYPE
Specifies the type of the elements stored in the base-class list.
newElement
Specifies the object pointer to be written to the list.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxtempl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
