COleControl::ReleaseCapture

This method releases mouse capture. If the control currently has the mouse capture, the capture is released. Otherwise, this function has no effect.

BOOL ReleaseCapture( );

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC

See Also

COleControl::SetCapture, COleControl::GetCapture
