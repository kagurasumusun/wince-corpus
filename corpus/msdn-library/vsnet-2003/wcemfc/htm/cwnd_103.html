CWnd::OnChildNotify

This method is called by the parent window of this window when it receives a notification message that applies to this window.

virtual BOOL OnChildNotify(
UINT message,
WPARAM wParam,
LPARAM lParam,
LRESULT* pLResult );

Parameters

message
Specifies a Windows CE message number sent to a parent window.
wParam
Specifies the wparam associated with the message.
lParam
Specifies the lparam associated with the message.
pLResult
Specifies a pointer to a value to be returned from the parent window procedure. This pointer will be NULL if no return value is expected.

Return Value

Nonzero if this window is responsible for handling the message sent to its parent; otherwise, it is zero.

Remarks

Never call this method directly.

The default implementation of this method returns zero, which means that the parent should handle the message.

Override this method to extend the manner in which a control responds to notification messages.

Requirements

  Windows CE versions: 1.0 and later

  Platform: H/PC Pro, Palm-size PC, Pocket PC
