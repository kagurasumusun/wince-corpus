COleDispatchDriver::DetachDispatch

This method detaches the current IDispatch connection from this object. The IDispatch is not released.

LPDISPATCH DetachDispatch( );

Return Value

A pointer to the previously attached OLE IDispatch object.

Example

LPDISPATCH CreateLPDispatch(LPCTSTR lpszProgId)
{
    COleDispatchDriver disp;

    disp.CreateDispatch(lpszProgId);

    return disp.DetachDispatch();
}

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
