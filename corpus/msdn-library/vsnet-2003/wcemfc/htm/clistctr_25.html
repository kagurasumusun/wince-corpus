CListCtrl::GetItem

This method retrieves some or all of the attributes in a list view item.

BOOL GetItem(
LVITEM* pItem )
const;

Parameters

pItem
Pointer to an LVITEM structure that receives the attributes of the item.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
