CEdit::GetRect

This method retrieves the formatting rectangle of an edit control. The formatting rectangle is the limiting rectangle of the text, which is independent of the size of the edit-control window. 

void GetRect(
LPRECT lpRect )
const;

Parameters

lpRect
Points to the RECT structure that receives the formatting rectangle.

Remarks

The formatting rectangle of a multiple-line edit control can be modified by the SetRect and SetRectNP methods.

For more information, see the Windows CE message EM_GETRECT.

Example

See the example for CEdit::LimitText.

Requirements
