CFontHolder::GetFontDispatch

This method retrieves a pointer to the dispatch interface of a font. Call InitializeFont before calling GetFontDispatch.

LPFONTDISP GetFontDispatch( );

Return Value

A pointer to IFontDisp interface of the CFontHolder object. Note that the function calling GetFontDispatch must also call IUnknown::Release on this interface pointer when done with it.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
