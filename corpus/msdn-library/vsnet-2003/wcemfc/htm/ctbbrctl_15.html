CToolBarCtrl::GetBitmapFlags

This method retrieves the bitmap flags from the toolbar. Call it after creating the toolbar but before adding bitmaps to the toolbar.

The return value indicates whether the display supports large bitmaps or not.

UINT GetBitmapFlags( )
const;

Return Value

A UINT that has the TBBF_LARGE flag set if the display can support large toolbar bitmaps, clear otherwise.

Remarks

If the display supports large bitmaps and if you choose to use them, call SetBitmapSize and SetButtonSize before adding your large bitmap using AddBitmap.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
