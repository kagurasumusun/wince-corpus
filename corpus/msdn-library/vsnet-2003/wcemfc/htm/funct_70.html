CopyElements

This function is called directly by CArray::Append and CArray::Copy. The default implementation uses the simple assignment operator ( = ) to perform the copy operation. If the type being copied does not have an overloaded operator=, then the default implementation performs a bitwise copy.

template< class TYPE >
void AFXAPI CopyElements( TYPE* pDest,
const TYPE* pSrc,
int nCount );

Parameters

TYPE
Template parameter specifying the type of elements to be copied.
pDest
Specifies the pointer to the destination where the elements will be copied.
pSrc
Specifies the pointer to the source of the elements to be copied.
nCount
Specifies the number of elements to be copied.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Afxtempl.h
  Platform: H/PC Pro, Palms-size PC, Pocket PC
