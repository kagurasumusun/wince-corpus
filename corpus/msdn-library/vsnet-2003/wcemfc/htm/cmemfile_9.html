CMemFile::Realloc

This method is called by several CMemFile methods. Override this method to implement custom memory reallocation. If you override this method, you will probably also want to override Alloc and Free.

virtual BYTE* Realloc(
BYTE* lpMem,
DWORD nBytes );

Parameters

lpMem
Specifies a pointer to the memory block to be reallocated.
nBytes
Specifies the new size for the memory block.

Return Value

A pointer to the memory block that was reallocated, and possibly moved, or it is NULL if the reallocation failed.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
