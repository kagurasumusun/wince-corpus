CStatusBarCtrl::SetParts

This method sets the number of parts in a status bar control and the coordinate of the right edge of each part.

BOOL SetParts(
int nParts,
int* pWidths );

Parameters

nParts
Specifies the number of parts to set. The number of parts cannot be greater than 255.
pWidths
Specifies the address of an integer array having the same number of elements as parts specified by nParts. Each element in the array specifies the position, in client coordinates, of the right edge of the corresponding part. If an element is –1, the position of the right edge for that part extends to the right edge of the control.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

const int nParts = 4;
CRect rect;

m_wndStatusBarCtrl.GetClientRect(&rect);
int widths[nParts] = { rect.right-300, rect.right-200, rect.right-100, –1 };

VERIFY( m_wndStatusBarCtrl.SetParts(nParts, widths) );

Requirements
