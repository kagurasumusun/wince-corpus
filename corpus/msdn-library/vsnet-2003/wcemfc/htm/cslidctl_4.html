CSliderCtrl::ClearTics

This method removes the current tick marks from a slider control.

void ClearTics(
BOOL bRedraw = FALSE );

Parameters

bRedraw
Specifies the redraw flag. If this parameter is TRUE, the slider is redrawn after the tick marks are cleared; otherwise, the slider is not redrawn.

Requirements

  Windows CE versions: 1.0 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
