CWnd::GetForegroundWindow

This method obtains a pointer to the foreground window, that is, the window with which the user is currently working. The foreground window applies only to top-level windows, such as frame windows or dialog boxes.

static CWnd* PASCAL GetForegroundWindow( );

Return Value

Returns a pointer to the foreground window. This may be a temporary CWnd object.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
