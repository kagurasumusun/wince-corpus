CToolBarCtrl::SetButtonStructSize

This method specifies the size of the TBBUTTON structure.If you wanted to store extra data in the TBBUTTON structure, you could either derive a new structure from TBBUTTON, adding the members you needed, or create a new structure that contains a TBBUTTON structure as its first member. You would then call this function to tell the toolbar control the size of the new structure.

See CToolBarCtrl::AddButtons for more information on the TBBUTTON structure.

void SetButtonStructSize(
int nSize );

Parameters

nSize
Specifies the size, in bytes, of the TBBUTTON structure.

Requirements
