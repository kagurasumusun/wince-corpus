CWnd::PreSubclassWindow

This method is called by the framework to allow other necessary subclassing to occur before the window is subclassed.

Overriding this method allows for dynamic subclassing of controls. It is an advanced overridable.

virtual void PreSubclassWindow( );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
