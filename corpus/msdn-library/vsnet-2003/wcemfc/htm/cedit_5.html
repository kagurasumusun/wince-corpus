CEdit::Clear

This method deletes or clears the current selection in the edit control.

The deletion performed by Clear can be undone by calling the Undo method.

To delete the current selection and place the deleted contents into the Clipboard, call the Cut method.

void Clear( );

Example

// The pointer to my edit.
extern CEdit* pmyEdit;

// Delete all of the text.
pmyEdit->SetSel(0, -1);
pmyEdit->Clear();

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
