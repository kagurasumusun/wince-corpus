COleControl::ExchangeStockProps

This method serializes the stock properties of the control. This method is normally called by the default implementation of COleControl::DoPropExchange.

void ExchangeStockProps(
CPropExchange* pPX );

Parameters

pPX
Specifies a pointer to a CPropExchange object. The framework supplies this object to establish the context of the property exchange, including its direction.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
