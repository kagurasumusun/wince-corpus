CFont::FromHandle

This method obtains a pointer to a CFont object when given an HFONT handle to a Windows CE GDI font object. If a CFont object is not already attached to the handle, a temporary CFont object is created and attached. This temporary CFont object is valid only until the next time the application has idle time in its event loop, at which time all temporary graphic objects are deleted. An alternate way to state this is that the temporary object is valid only during the processing of one window message.

static CFont* PASCAL FromHandle(
HFONT hFont );

Parameters

hFont
Specifies an HFONT handle to a Windows CE font.

Return Value

A pointer to a CFont object if successful; otherwise, it is NULL.

Example

// This code fragment shows how to create a font object using
// Windows API CreateFontIndirect(), convert the HFONT to a
// CFont* before selecting the font object into a DC (device
// context) for text drawing, and finally delete the font object.

// Initialize a CFont object with the characteristics given
// in a LOGFONT structure.
LOGFONT lf;
memset(&lf, 0, sizeof(LOGFONT));          // Clear out structure.
lf.lfHeight = 12;                         // Request a 12-pixel-height
                                          // font.
lstrcpy(lf.lfFaceName, _T("Arial"));
// Request a face name "Arial".
HFONT hfont = ::CreateFontIndirect(&lf);  // Create the font.

// Convert the HFONT to CFont*.
CFont* pfont = CFont::FromHandle(hfont);

// Use the font you just created.
CClientDC dc(this);
CFont* def_font = dc.SelectObject(pfont);
dc.ExtTextOut(5, 5, ETO_OPAQUE, NULL, _T("Hello"), NULL);
dc.SelectObject(def_font);

// Finished with the font, now delete the font object.
::DeleteObject(hfont);

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
