CReBarCtrl::CReBarCtrl

This constructor creates an instance of a CReBarCtrl object. 

CReBarCtrl( );

Example

CReBarCtrl* pReBarCtrl = new CReBarCtrl();
CRect rect;
GetWindowRect(rect);
pReBarCtrl->Create(RBS_BANDBORDERS, rect, this, AFX_IDW_REBAR);
// Use ReBar Control.
...
delete pReBarCtrl;

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
