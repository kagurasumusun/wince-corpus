COleControl:: OnMnemonic

This method is called by the framework when a mnemonic key of the control is pressed.

virtual void OnMnemonic(
LPMSG pMsg );

Parameters

pMsg
Specifies a pointer to the Windows CE message generated by a mnemonic key press.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
