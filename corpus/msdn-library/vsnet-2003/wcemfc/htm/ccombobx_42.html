CComboBox::SetItemDataPtr

This method sets the 32-bit value associated with the specified item in a combo box to be the specified pointer (void*).

int SetItemDataPtr(
int nIndex,
void* pData );

Parameters

nIndex
A zero-based index to the item.
pData
The pointer to associate with the item.

Return Value

CB_ERR if an error occurs.

Remarks

This pointer remains valid for the life of the combo box, even though the relative position of the item in the combo box might change as items are added or removed. Hence, the item’s index in the box can change, but the pointer remains reliable.

Example

// The pointer to a combo box.
extern CComboBox* pmyComboBox;

// Set the data pointer of each item to be NULL.
for (int i=0;i < pmyComboBox->GetCount();i++)
{
  pmyComboBox->SetItemDataPtr(i, NULL);
}

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
