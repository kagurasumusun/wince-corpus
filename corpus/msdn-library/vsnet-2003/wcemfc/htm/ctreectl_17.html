CTreeCtrl::GetItem

This method retrieves the attributes of the specified tree view item.

BOOL GetItem(
TV_ITEM* pItem )
const;

Parameters

pItem
Specifies a pointer to a TVITEM structure.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Example

See the example for CTreeCtrl::DeleteItem.

Requirements
