CPalette

This class encapsulates a Windows CE color palette. A palette provides an interface between an application and a color output device, such as a display device.

The interface allows the application to take full advantage of the color capabilities of the output device without severely interfering with the colors displayed by other applications. Windows uses the logical palette of the application, a list of needed colors, and the system palette, which defines available colors, to determine the colors used.

A CPalette object provides methods for manipulating the palette referred to by the object. Construct a CPalette object and use its methods to manipulate its entries and other properties and to create the actual palette and a graphics device interface (GDI) object.

Remarks

MFC for Windows CE does not support the following methods of the CPalette class:

  • CPalette::AnimatePalette
  • CPalette::CreateHalftonePalette
  • CPalette::ResizePalette

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
