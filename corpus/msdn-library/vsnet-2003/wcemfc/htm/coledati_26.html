COleDateTime::operator <<, >>

This insertion (<<) operator is used for diagnostic dumping and storing to an archive. This extraction (>>) operator is used for loading from an archive. 

CDumpContext& AFXAPI operator <<(
CDumpContext& dc,
COleDateTime dateSrc ); 

CArchive& AFXAPI operator <<(
CArchive& ar,
COleDateTime dateSrc ); 

CArchive& AFXAPI operator >>(
CArchive& ar,
COleDateTime& dateSrc );

Example

COleDateTime t(1999, 3, 19, 22, 15, 0); // 10:15PM March 19, 1999
afxDump << t << "\n";    // Prints 'CTime("Fri Mar 19 22:15:00 1999")'.
extern CArchive ar;
if( ar.IsLoading() )
  ar >> t;
else
  ar << t;

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxdisp.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
