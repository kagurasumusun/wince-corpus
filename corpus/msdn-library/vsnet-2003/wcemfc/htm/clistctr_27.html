CListCtrl::GetItemData

This method retrieves the 32-bit application-specific value associated with the item specified by nItem. This value is the lParam member of the LVITEM structure; for more information about this structure, see GetItem.

DWORD GetItemData(
int nItem )
const;

Parameters

nItem
Specifies the index of the list item whose data is to be retrieved.

Return Value

A 32-bit application-specific value associated with the specified item.

Example

// Pointer to the list view control.
CListCtrl* pmyListCtrl;

// If any data in an item is equal to zero then reset it to –1.
for (int i=0;i < pmyListCtrl->GetItemCount();i++)
{
  if (pmyListCtrl->GetItemData(i) == 0)
  {
    pmyListCtrl->SetItemData(i, (DWORD) –1);
  }
}

Requirements
