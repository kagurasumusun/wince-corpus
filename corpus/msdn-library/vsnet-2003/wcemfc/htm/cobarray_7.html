CObArray::FreeExtra

This method frees any extra memory that was allocated while the array was grown. This method has no effect on the size or upper bound of the array.

void FreeExtra( );

Remarks

The following table shows other methods that are similar to CObArray::FreeExtra.

Class Method
CByteArray void FreeExtra( );
CDWordArray void FreeExtra( );
CPtrArray void FreeExtra( );
CStringArray void FreeExtra( );

CWordArray void FreeExtra( );

Example

See CObList::CObList for a listing of the CAge class used in all collection examples.

CObArray myArray;
  int i;

  // Allocate memory for at least 32 elements.
  myArray.SetSize(32, 128);

  // Add elements to the array.
  CAge** ppAge = (CAge**) myArray.GetData();
  for (i=0;i < 32;i++,ppAge++)
    *ppAge = new CAge( i );

  // Only keep first 5 elements and free extra (unused) bytes.
  myArray.SetSize(5, 128);
  myArray.FreeExtra();

#ifdef _DEBUG
    afxDump.SetDepth( 1 );
    afxDump << "myArray: " << &myArray << "\n";
#endif
