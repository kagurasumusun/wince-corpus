COleControl::GetExtendedControl

This method retrieves a pointer to an extended control object belonging to the container. The method that calls this method is responsible for releasing the pointer when finished with the object. Note that the container is not required to support this object.

LPDISPATCH GetExtendedControl( );

Return Value

A pointer to the extended control object of the container. If there is no object available, the value is NULL.

This object may be manipulated through its IDispatch interface. You can also use QueryInterface to obtain other available interfaces provided by the object. However, the object is not required to support a specific set of interfaces. Note that relying on the specific features in the extended control object of a container limits the portability of your control to other arbitrary containers.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
