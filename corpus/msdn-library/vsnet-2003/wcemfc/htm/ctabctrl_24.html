CTabCtrl::SetImageList

This method assigns an image list to a tab control.

CImageList* SetImageList(
CImageList* pImageList );

Parameters

pImageList
Specifies a pointer to the image list to be assigned to the tab control.

Return Value

Returns a pointer to the previous image list or NULL if there is no previous image list.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxcmn.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
