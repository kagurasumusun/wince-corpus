CMonthCalCtrl::GetSelRange

This method retrieves date information that represents the upper and lower limits of the date range currently selected by the user

This method implements the behavior of the Windows CE message MCM_GETSELRANGE.

GetSelRange will fail if applied to a month calendar control that does not use the MCS_MULTISELECT style.

In the MFC for Windows CE implementation of GetSelRange, you can specify COleDateTime usage, a CTime usage, or a SYSTEMTIME structure usage.

BOOL GetSelRange(
COleDateTime& refMinRange,
COleDateTime& refMaxRange )
const; 

BOOL GetSelRange(
CTime& refMinRange,
CTime& refMaxRange )
const; 

BOOL GetSelRange(
LPSYSTEMTIME pMinRange,
LPSYSTEMTIME pMaxRange )
const;

Parameters

refMinRange
Specifies a reference to a COleDateTime or CTime object containing the minimum date allowed.
refMaxRange
Specifies a reference to a COleDateTime or CTime object containing the maximum date allowed.
pMinRange
Specifies a pointer to a SYSTEMTIME structure containing the date at the lowest end of the range.
pMaxRange
Specifies a pointer to a SYSTEMTIME structure containing the date at the highest end of the range.

Return Value

Nonzero if it is successful; otherwise, it is zero.

Requirements

  Windows CE versions: 2.10 and later  
  Header file: Declared in Afxdtctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
