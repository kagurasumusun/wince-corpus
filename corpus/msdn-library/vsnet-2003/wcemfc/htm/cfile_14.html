CFile::ReadHuge

This method reads data into a buffer from the file associated with the CFile object.

This function differs from Read in that ReadHuge can read more than 64K–1 bytes of data. This function can be used by any object derived from CFile.

ReadHuge is provided only for backward compatibility. ReadHuge and Read have the same semantics under Windows CE.

DWORD ReadHuge( 
void* lpBuffer,
DWORD dwCount );

Parameters

lpBuffer
Specifies the pointer to the user-supplied buffer that is to receive the data read from the file.
dwCount
Specifies the maximum number of bytes to be read from the file. For text-mode files, carriage return–linefeed pairs are counted as single characters.

Return Value

The number of bytes transferred to the buffer. Note that for all CFile objects, the return value can be less than dwCount if the end of file was reached.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afx.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
