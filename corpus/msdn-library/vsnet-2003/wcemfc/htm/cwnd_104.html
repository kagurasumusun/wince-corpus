CWnd::OnClose

This method is called by the framework as a signal that the CWnd object or the application is to terminate. The default implementation calls DestroyWindow.

afx_msg void OnClose( );

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
