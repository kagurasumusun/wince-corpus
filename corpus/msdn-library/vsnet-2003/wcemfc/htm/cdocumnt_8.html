CDocument::GetFirstViewPosition

This method retrieves the position of the first view in the list of views associated with the document.

virtual POSITION GetFirstViewPosition( )
const;

Return Value

Returns a POSITION value that can be used for iteration with the GetNextView method.

Example

//To get the first view in the list of views:

POSITION pos = GetFirstViewPosition();
CView* pFirstView = GetNextView( pos );
// This example uses CDocument::GetFirstViewPosition
// and GetNextView to repaint each view.
void CMyDoc::OnRepaintAllViews()
{
   POSITION pos = GetFirstViewPosition();
   while (pos != NULL)
   {
      CView* pView = GetNextView(pos);
      pView->UpdateWindow();
   }
}
