CWnd::ExecuteDlgInit

This method initiates a dialog box resource. 

BOOL ExecuteDlgInit(
LPCTSTR lpszResourceName );

BOOL ExecuteDlgInit(
LPVOID lpResource );

Parameters

lpszResourceName
Specifies a pointer to a null-terminated string specifying the name of the resource.
lpResource
Specifies a pointer to a resource.

Return Value

TRUE if a dialog resource is executed; otherwise, it is FALSE.

Remarks

ExecuteDlgInit will use resources bound to the executing module, or resources from other sources. To accomplish this, ExecuteDlgInit finds a resource handle by calling AfxFindResourceHandle. If your MFC for Windows CE application does not use the shared DLL (MFCx0[U][D].DLL), AfxFindResourceHandle calls AfxGetResourceHandle, which returns the current resource handle for the executable. If your MFC for Windows CE application that uses MFCx0[U][D].DLL, AfxFindResourceHandle traverses the CDynLinkLibrary object list of shared and extension dlls looking for the correct resource handle.

Requirements

  Windows CE versions: 1.0 and later
  Header file: Declared in Afxwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
