CControlBar::DrawBorders

This method draws the borders, if any, of the CControlBar object.

void DrawBorders(
CDC* pDC,
CRect& rect );

Parameters

pDC
Specifies a pointer to the device context in which the painting occurs.
rect
Specifies a reference to the rectangle of the control.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Afxext.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
