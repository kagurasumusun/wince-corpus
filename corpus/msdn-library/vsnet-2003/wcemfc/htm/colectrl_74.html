COleControl::IsOptimizedDraw

This method determines whether the container supports optimized drawing for the current drawing operation. If optimized drawing is supported, the control does not need to select old objects, such as pens, brushes, fonts, etc., into the device context when drawing is finished.

BOOL IsOptimizedDraw( );

Return Value

TRUE if the container supports optimized drawing for the current drawing operation; otherwise, FALSE.

Requirements

  Windows CE versions: 2.0 and later  
  Header file: Declared in Afxctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
