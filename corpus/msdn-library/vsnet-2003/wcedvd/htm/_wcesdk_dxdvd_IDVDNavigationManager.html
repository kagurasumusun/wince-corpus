IDVDNavigationManager

This interface sets the global context for the navigation manager.

Method Description
IDVDNavigationManger::SetVolume Sets the volume that the navigation manager will control.
IDVDNavigationManager::GetSParameter Returns the value of a specified system parameter (SPRM).
IDVDNavigationManager::GetGParameter Returns the value of a specified general parameter (GPRM).
IDVDNavigationManager::SetSParameter Sets the value of a specified system parameter (SPRM).
IDVDNavigationManager::GetScanCaps Returns a bitmask identifying which scan modes the DVD-Video API renderer supports.
IDVDNavigationManager::GetPlaybackState Returns a value indicating the current playback state of the player.
IDVDNavigationManger::UseRenderer Allows you to select the DVD-Video renderer that your application will use.
IDVDNavigationManager::ButtonSelectDirect Allows your application to select a button by specifying its button number from the button information table (BTNIT).

The IDVDNavigationManager, like all COM interfaces, inherits the IUnknown interface methods. The IUnknown interface supports the following three methods:

  • AddRef
  • QueryInterface
  • Release

Remarks

You can obtain a pointer to an IDVDNavigationManager interface by calling the IUnknown::QueryInterface method of a DVDNavigationManager object and specifying the IID_IDVDNavigationManager reference identifier.
