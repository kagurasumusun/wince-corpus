IDVDUserOperation::ParentalLevelSelect

This method sets a specified parental level for playback.

HRESULT ParentalLevelSelect(
BYTE byteLevel
);

Parameters

byteLevel
[in] Number specifying the parental level for playback. Allowable values are 1, 6, 8, and 0xF. A value of 0xF indicates that parental levels are disabled.

Return Values

If the function succeeds, the return value is S_OK.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dvdnav.idl Dvdnav.h Ddvdids.lib
