IDVDNavigatorSink

This interface is a COM connection point that allows applications to monitor the dynamic state of DVD playback. As the DVD-Video API encounters navigation-based events, it issues callbacks through the IDVDNavigatorSink interface. You must implement the specific IDVDNavigatorSink methods within your DVD player application.

The following table lists the methods for IDVDNavigatorSink in the order the compiler calls them.

Method Description
IDVDNavigatorSink::OnSPRMChange Called whenever a system parameter (SPRM) value changes.
IDVDNavigatorSink::OnGPRMChange Called whenever a general parameter (GPRM) value changes.
IDVDNavigatorSink::OnNewProgramChain Called whenever the player switches to a new program chain (PGC).
IDVDNavigatorSink::OnNewProgram Called whenever the player switches to a new program (PG).
IDVDNavigatorSink::OnNewCell Called whenever the player switches to a new cell.
IDVDNavigatorSink::OnGOPUserData Called when the player encounters user data in a group of pictures (GOP).
IDVDNavigatorSink::OnUOPChange Called when the navigation manager receives a new user operation (UOP).
IDVDNavigatorSink::OnPlaybackStateChange Called whenever the playback state changes.
IDVDNavigatorSink::OnDiskReadError Called whenever the navigation manager is unable to read from the DVD volume.
IDVDNavigatorSink::ConfirmTemporaryParentalLevel Called when the navigation manager receives a navigation command that changes the parental level (PTL_LVL).
IDVDNavigatorSink::OnNavigationException Called when the navigation manager receives a navigation request that it cannot complete.

The IDVDNavigatorSink interface, like all COM interfaces, inherits the IUnknown interface methods. The IUnknown interface supports the following three methods:

  • AddRef
  • QueryInterface
  • Release

Remarks

You can obtain a pointer to an IDVDNavDataStatusSink interface by calling the IUnknown::QueryInterface method of a DVDData object and specifying the IID_IDVDNavDataStatusSink reference identifier.
