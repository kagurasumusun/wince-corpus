IDVDStreamControlInfo::GetEndSequencePTM

This method returns the video object unit sequence end presentation time (VOBU_SE_E_PTM) from the presentation control information general information (PCI_GI) for the current video object unit (VOBU).

HRESULT GetEndSequencePTM(
UINT32  *pMpegTime
);

Parameters

pMpegTime
[out] Pointer to VOBU_SE_E_PTM for the current VOBU.

Return Values

This method always returns S_OK.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dvdata.idl Dvdata.h Ddvdids.lib
