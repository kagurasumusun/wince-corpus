IDVDVideoVolume::GetFirstPlay

This method returns an IDVDDomain interface for the volume's first play domain (FP_DOM).

HRESULT GetFirstPlay(
IDVDDomain  *ppDomain
);

Parameters

ppDomain
[out] Address of a pointer to the IDVDDomain interface of first play domain. Null is returned if no information is available.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be one of the following error values.

Error value Description
E_OUTOFMEMORY There was not enough memory available for the operation.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dvdata.idl Dvdata.h Ddvdids.lib
