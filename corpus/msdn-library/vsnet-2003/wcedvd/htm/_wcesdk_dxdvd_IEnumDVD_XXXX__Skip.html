IEnumDVD_XXXX::Skip

This method skips over a specified number of items in the enumeration sequence.

HRESULT Skip(
ULONG celt
);

Parameters

celt
[in] Number of elements to skip.

Return Values

This method returns the following values

Value Description
S_OK The number of skipped elements is celt.
S_FALSE The number of skipped elements is not equal to celt.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dvdata.idl Dvdata.h Ddvdids.lib
