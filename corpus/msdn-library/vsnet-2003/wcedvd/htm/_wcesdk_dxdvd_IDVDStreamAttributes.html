IDVDStreamAttributes

This interface provides information about the current video, subpicture, and audio streams.

The following table lists the methods for IDVDStreamAttributes in the order they are called by the compiler.

Method Description
IDVDStreamAttributes::GetVideoAttr Returns the video attributes of the current video object set (VOBS).
IDVDStreamAttributes::GetAudioCount Returns the number of audio streams in the current video object set (VOBS).
IDVDStreamAttributes::GetAudioAttr Returns the attributes of a specified audio stream number in the current video object set (VOBS).
IDVDStreamAttributes::GetAudioMultichannelUseAttr Returns the video title set multichannel audio stream attribute (VTS_MU_AST_ATR) of a specified audio stream number.
IDVDStreamAttributes::GetSubpictureCount Returns the number of subpicture streams in the current video object set (VOBS).
IDVDStreamAttributes::GetSubpictureAttr Returns the attributes of a specified subpicture stream number in the current video object set (VOBS).

The IDVDStreamAttributes interface, like all COM interfaces, inherits the IUnknown interface methods. The IUnknown interface supports the following three methods:

  • AddRef
  • QueryInterface
  • Release

Remarks

You can obtain a pointer to an IDVDStreamAttributes interface in the following ways:

  • By calling the IUnknown::QueryInterface method of a DVDData object and specifying the IID_IDVDStreamAttributes reference identifier.
  • By calling the IDVDVideoVolume::GetTitleSetAttributes method.
  • By calling the IDVDDomain::GetStreamAttributes method.
