IDVDHighlightInfo

This interface is used by applications to gain access to the current highlight information.

The following table lists the methods for IDVDHighlightInfo in the order they are called by the compiler.

Method Description
IDVDHighlightInfo::GetStreamingInfo Returns the IDVDStreamControlInfo interface for the current highlight information.
IDVDHighlightInfo::GetPTMs Returns start, end, and button selection end presentation times for highlight information (HLI_S_PTM, HLI_E_PTM, and BTN_SL_E_PTM).
IDVDHighlightInfo::GetButtonMode Returns the button mode (BTN_MD) from the general highlight information (HL_GI).
IDVDHighlightInfo::GetButtonOffset Returns the button offset number (BTN_OFN) from the highlight general information (HL_GI).
IDVDHighlightInfo::GetButtonCount Returns the number of buttons (BTN_Ns) from the highlight general information (HL_GI).
IDVDHighlightInfo::GetNumberedButtonCount Returns the number of numerical select buttons (NSL_BTN_Ns) from the highlight general information (HL_GI).
IDVDHighlightInfo::GetInitialSelectionButton Returns the forcedly selected button number (FOSL_BTNN) from the highlight general information (HL_GI).
IDVDHighlightInfo::GetDefaultActionButton Returns the forcedly activated button number (FOAC_BTNN) from the highlight general information (HL_GI).
IDVDHighlightInfo::GetButtonColorInfo Returns color information from the button color information table (BTN_COLIT) for a specified button color information (BTN_COLI) set.
IDVDHighlightInfo::GetButtonPositionInfo Returns the button position information (BTN_POSI) from a specified button information (BTNI) set in the button information table (BTNIT).
IDVDHighlightInfo::GetAdjacentButton Returns the adjacent button position information (AJBTN_POSI) from a specified button information (BTNI) set in the button information table (BTNIT).
IDVDHighlightInfo::GetButtonCommand Returns the button command (BTN_CMD) from a specified button information (BTNI) set in the button information table (BTNIT).
IDVDHighlightInfo::GetHLIStatus Returns the highlight information status (HLI_SS) from the highlight general information (HL_GI).

The IDVDHighlightInfo interface, like all COM interfaces, inherits the IUnknown interface methods. The IUnknown interface supports the following three methods:

  • AddRef
  • QueryInterface
  • Release

Remarks

You can obtain a pointer to an IDVDHighlightInfo interface in the following ways:

  • By calling the IUnknown::QueryInterface method of a DVDData object and specifying the IID_IDVDHighlightInfo reference identifier.
  • By calling the IDVDStreamControlInfo::GetHighlightInfo method.
