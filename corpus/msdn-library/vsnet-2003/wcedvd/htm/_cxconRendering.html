DVD-Video API Rendering

The DVD-Video API is optimized for hardware, but a software-based renderer is also possible, though not provided by the DVD-Video API. If implemented, the entire DVD renderer layer at the bottom of the architecture would be implemented in software rather than being passed off to hardware. For instance, it would be possible to place a Microsoft DirectShow® based DVD decoder/render into the DVD-Video API stack at the renderer level.
