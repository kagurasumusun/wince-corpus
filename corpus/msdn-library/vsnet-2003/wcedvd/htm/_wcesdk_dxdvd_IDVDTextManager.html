IDVDTextManager

This interface provides information about and access to the current text items.

The following table lists the methods for IDVDTextManager in the order they are called by the compiler.

Method Description
IDVDTextManager::EnumerateTextLanguageUnits Returns an IEnumDVD_TEXT_LANGUAGE_UNIT interface to enumerate all of the text data language unit search pointers (TXTDT_LU_SRP).
IDVDTextManager::GetTextItemsCount Returns the number of item text search pointers (IT_TXT_SRP_Ns) for a specified title in a specified text data language unit (TXTDT_LU).
IDVDTextManager::EnumerateTitleTextItems Returns an IEnumDVD_TEXT_ITEM interface to enumerate the item text (IT_TXT) elements for a specified title in a specified text data language unit (TXDT_LU).

The IDVDTextManager interface, like all COM interfaces, inherits the IUnknown interface methods. The IUnknown interface supports the following three methods:

  • AddRef
  • QueryInterface
  • Release

Remarks

You can obtain a pointer to an IDVDTextManager interface in the following ways:

  • By calling the IUnknown::QueryInterface method of a DVDData object and specifying the IID_IDVDTextManger reference identifier.
  • By calling the IDVDVideoVolume::GetTextDataManager method.
