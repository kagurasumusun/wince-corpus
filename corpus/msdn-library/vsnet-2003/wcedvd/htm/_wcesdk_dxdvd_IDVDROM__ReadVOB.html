IDVDROM::ReadVOB

This method reads the video object (VOB) for the requested video title set number (VTSN). This method is used internally by the DVD-Video API and is not generally used by applications.

HRESULT ReadVOB(
UINT16 hVOB,
INT8  *buf,
UINT32 startBlock,
UINT32 endBlock
);

Parameters

hVOB
[out] VOB handle.
buf
[in/out] Buffer to store the VOB.
startBlock
[in] Starting block number.
endBlock
[in] Ending block number.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be one of the following error values.

Error value Description
E_INVALIDARG One or more arguments is invalid.
E_FAIL The method failed.

Requirements

Windows CE OS .NET 4.0 and later Dvdata.idl Dvdata.h Ddvdids.lib
