IDVDVideoVolume::GetMenu

This method returns an IDVDMenu interface for the volume's video manager menu (VMGM).

HRESULT GetMenu(
IDVDMenu  *ppMenu
);

Parameters

ppMenu
[out] Pointer to an IDVDMenu interface for the volume's VMGM. If the volume does not have a VMGM then this method returns an E_NOINTERFACE error.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be one of the following error values.

Error value Description
E_NOINTERFACE The method was unable to obtain and return an interface pointer.
E_OUTOFMEMORY There was not enough memory available for the operation.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dvdata.idl Dvdata.h Ddvdids.lib
