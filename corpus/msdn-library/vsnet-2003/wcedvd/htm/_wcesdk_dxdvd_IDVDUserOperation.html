IDVDUserOperation

This interface provides the main interface for controlling DVD playback. IDVDUserOperation is the DVD-Video API implementation of the DVD Specification for Read-Only Disc, Annex J.

The following table lists the methods for IDVDUserOperation in the order the compiler calls them.

Method Description
IDVDUserOperation::TitlePlay Plays a specified title.
IDVDUserOperation::PartPlay Plays a specified part of title (PTT) from a specified title unit (TTU) in the current video title set (VTS).
IDVDUserOperation::TimePlay Begins playing at the specified time in the title.
IDVDUserOperation::Stop Halts execution of the current program chain.
IDVDUserOperation::GoUp Stops playing the current program chain and starts playing the GoUp program chain.
IDVDUserOperation::TimeSearch Stops the current presentation and starts presentation at the specified time on the current title.
IDVDUserOperation::PTTSearch Stops the current presentation and starts presentation from the beginning of a specified part of title (PTT) in the current title.
IDVDUserOperation::ProgramSearch Stops the current presentation and starts a new presentation at a specified point in the current program chain (PGC).
IDVDUserOperation::ForwardScan Performs scan play at the specified speed.
IDVDUserOperation::BackwardScan Performs scan play in reverse at the specified speed.
IDVDUserOperation::MenuCall Calls a specified system menu.
IDVDUserOperation::Resume Returns to the current domain from menu space.
IDVDUserOperation::ButtonSelect Applies the select action for a specified button.
IDVDUserOperation::ButtonActivate Activates the currently highlighted button.
IDVDUserOperation::ButtonSelectAndActivate Highlights a specified button and then activates it.
IDVDUserOperation::StillOff Releases stills found in video object units (VOBU), cells, and program chains (PGC).
IDVDUserOperation::Pause Pauses or resumes the current presentation.
IDVDUserOperation::MenuLanguageSelect Selects the language for the system menu.
IDVDUserOperation::ChangeAudioStream Changes the current audio stream to the specified audio stream number.
IDVDUserOperation::ChangeSubPictureStream Changes the current subpicture stream to the specified subpicture stream number.
IDVDUserOperation::ChangeAngle Changes the camera angle to the specified number.
IDVDUserOperation::ParentalLevelSelect Sets a specified parental level for playback.
IDVDUserOperation::ParentalCountrySelect Sets the country/region code (CTY_CD) for parental management.
IDVDUserOperation::VideoPresentationModeChange Changes the aspect ratio and display mode of the video output.

The IDVDUserOperation interface, like all COM interfaces, inherits the IUnknown interface methods. The IUnknown interface supports the following three methods:

  • AddRef
  • QueryInterface
  • Release

Remarks

You can obtain a pointer to an IDVDUserOperation interface in the following ways:

  • By calling the IUnknown::QueryInterface method of a DVDNavigationManager object and specifying the IID_IDVDDataSearchInfo reference identifier.
  • By calling the IDVDStreamControlInfo::GetDataSearchInfo method.

The IDVDUserOperation interfaces are not protected against use if IDVDROM::Bind fails. You can get access violation errors if you do not make sure that all the steps in your initialization sequence are successful.
