The DVDSample Control Panel

DVD Sample provides the user with a control panel containing the input and output features commonly found on a commercial DVD player. The control panel's layout and operation should be familiar and understandable to anyone who has used a general media playback application. The following screenshot shows the DVDSample control panel.

This following table lists the elements shown in the DVDSample control panel.

Control Panel Element Description
File menu Exits the application.
Playback menu Provides access to all playback and navigation controls.
Options menu Sets global DVD playback options such as language, parental level, angle, and other options.
Help menu Provides version information for the application.
Playback state icon Indicates the playback command currently running on the player.
Current title number Indicates the title number that is currently playing.
Current chapter number Indicates the chapter number that is currently playing.
Player status message Provides information to the user regarding the player's current actions.
Current angle indicator Indicates the seamless angle that is currently being displayed.
Audio stream indicator Indicates which audio stream is currently being output.
Subpicture stream indicator Indicates which subpicture stream is currently being displayed.
Parental level indicator Indicates the parental level that playback is current limited to.
Play button Causes the player to begin playback at the current title using the current playback option settings.
Pause button Causes the playback to temporarily halt at the current frame. When playback halts, this button becomes the frame advance button. When the Play button is pressed playback will resume from this frame.
Stop button Causes playback to stop. When the play button is pressed playback will begin again from the beginning.
Previous chapter button Causes playback to stop and then resume at the beginning of the previous chapter.
Backward scan button Causes rapid backward playback. Repeated activation of this button will alter the scan speed. Using this button when playback is paused will cause playback to resume at slow-motion speeds until Play is pressed.
Forward scan button Causes rapid forward playback. Repeated activation of this button will alter the scan speed. Using this button when playback is paused will cause playback to resume at slow-motion speeds until Play is pressed.
Next chapter button Causes playback to jump to the next chapter.
Menu button Causes the player to begin or resume playback in the menu domain.
Frame advance button Causes playback to proceed one frame at a time. This button is only available when playback is paused.
