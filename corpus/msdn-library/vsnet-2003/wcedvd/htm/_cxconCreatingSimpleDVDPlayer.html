Creating a Simple DVD Player

The best way to begin understanding the DVD-Video API is to step through the process of creating a basic sample application that plays a DVD-Video disc.

The following topics describe the major aspects of creating a simple DVD player application that takes input from a keyboard and directs its output to the default video renderer. The code examples found in these topics are all taken from the sample application DVDPlay.
