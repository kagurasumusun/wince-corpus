IDVDStreamControlInfo::GetHighlightInfo

This method returns the IDVDHighlightInfo interface for the presentation control information (PCI) in the current video object unit (VOBU).

HRESULT GetHighlightInfo(
IDVDHighlightInfo  **ppHLI
);

Parameters

ppHLI
[out] Pointer to the IDVDHighlightInfo interface for the current VOBU.

Return Values

If this method succeeds, the return value is S_OK.

If this method fails, the return value may be one of the following error values.

Error value Description
E_INVALIDARG One or more arguments is invalid.
E_NOINTERFACE The method was unable to obtain and return an interface pointer.
E_OUTOFMEMORY There was not enough memory available for the operation.
E_POINTER The returned pointer is invalid.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dvdata.idl Dvdata.h Ddvdids.lib
