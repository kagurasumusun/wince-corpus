IDVDVideoVolume

This interface provides and controls access to the DVD-Video volume. Several IDVDVideoVolume methods expose data found in the volume's video manager information management table (VMGI_MAT).

The following table lists the methods for IDVDVideoVolume in the order the compiler calls them.

Method Description
IDVDVideoVolume::InitData Initializes the volume data.
IDVDVideoVolume::Lock Locks the volume from other threads or processes.
IDVDVideoVolume::Unlock Unlocks the volume for other threads or processes.
IDVDVideoVolume::GetSpecVersion Retrieves the DVD specification version number (VERN) from the video manager information management table (VMGI_MAT).
IDVDVideoVolume::GetCategory Retrieves the region code bitmask for the player.
IDVDVideoVolume::GetVolumeSetInfo Retrieves the volume set identifier (VLMS_ID).
IDVDVideoVolume::GetVideoTitleSetsCount Retrieves the number of video title sets (VTS) in the DVD-Video volume.
IDVDVideoVolume::GetProviderID Returns the provider identification
IDVDVideoVolume::GetPOSCode Retrieves the POS code.
IDVDVideoVolume::GetFirstPlay Returns an IDVDDomain interface for the volume's first play domain.
IDVDVideoVolume::GetMenu Retrieves the DVD-Video volume's menu information.
IDVDVideoVolume::GetTotalTitleUnitCount Retrieves the total number of title units (TTU).
IDVDVideoVolume::GetTitleUnitInfo Retrieves information about the title unit (TTU).
IDVDVideoVolume::GetTitleSet Retrieves a specified video title set (VTS).
IDVDVideoVolume::GetTitleSetAttributes Retrieves the video title set attributes (VTS_ATR).
IDVDVideoVolume::GetParentalManagementTable Retrieves the parental management information table (PTL_MAIT) for the video manger (VMG).
IDVDVideoVolume::GetTextDataManager Retrieves the text data manager (TXTDT_MG).

The IDVDVideoVolume interface, like all COM interfaces, inherits the IUnknown interface methods. The IUnknown interface supports the following three methods:

  • AddRef
  • QueryInterface
  • Release

Remarks

You can obtain a pointer to an IDVDVideoVolume interface in the following ways:

  • By calling the IUnknown::QueryInterface method of a DVDData object and specifying the IID_IDVDVideoVolume reference identifier.
  • By calling the IDVDDomain::GetVolume method.
  • By calling the IDVDTitleSet::GetVolume method.
