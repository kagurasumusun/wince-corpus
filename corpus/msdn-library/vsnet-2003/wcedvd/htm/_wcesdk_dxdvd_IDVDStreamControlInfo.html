IDVDStreamControlInfo

This interface allows you to set the current navigation pack and provides control information about the current output stream.

The following table lists the methods for IDVDStreamControlInfo in the order the compiler calls them.

Method Description
IDVDStreamControlInfo::SetNavigationPack Sets the current navigation pack (NV_PCK) to the one specified.
IDVDStreamControlInfo::GetBlockAddress Returns the navigation pack logical block number (NV_PCK_LBN) for the current video object unit (VOBU).
IDVDStreamControlInfo::GetCategory Returns the video object unit category (VOBU_CAT) for the current video object unit (VOBU).
IDVDStreamControlInfo::GetUserOperationControlMask Returns the video object unit user operation controls (VOBU_UOP_CTL) for the current video object unit (VOBU).
IDVDStreamControlInfo::GetPresentationTimes Returns the video object unit start presentation time (VOBU_S_PTM) and video object unit end presentation time (VOBU_E_PTM) for the current video object unit (VOBU).
IDVDStreamControlInfo::GetEndSequencePTM Returns the video object unit sequence end presentation time (VOBU_SE_E_PTM) for the current video object unit (VOBU).
IDVDStreamControlInfo::GetCellRelativeStartTime Returns the cell elapsed time (C_ELTM) for the current video object unit (VOBU).
IDVDStreamControlInfo::GetNonSeamlessAngleChangeAddress Returns a specified non-seamless angle cell destination address (NSML_AGL_Cn_DSTA) for the current video object unit (VOBU).
IDVDStreamControlInfo::GetHighlightInfo Returns the IDVDHighlightInfo interface for the current video object unit (VOBU).
IDVDStreamControlInfo::GetDataSearchInfo Returns the IDVDDataSearchInfo interface for the current video object unit (VOBU).
IDVDStreamControlInfo::GetRecordingVideoInfo Returns the recording information (RECI) for the current video object unit (VOBU).
IDVDStreamControlInfo::GetRecordingAudioInfo Returns the ISRC information for the current video object unit's (VOBU) video stream (ISRC_V).
IDVDStreamControlInfo::GetRecordingSubpictureGroup Returns the ISRC subpicture selection (ISRC_SP_SEL) group for the current video object unit (VOBU).
IDVDStreamControlInfo::GetRecordingSubpictureInfo Returns the ISRC information for a specified set of subpicture streams (ISRC_SPn) in the current video object unit (VOBU).
IDVDStreamControlInfo::ReaderLock Locks the current stream control information.
IDVDStreamControlInfo::ReaderUnlock Unlocks the current stream control information.

The IDVDStreamControlInfo interface, like all COM interfaces, inherits the IUnknown interface methods. The IUnknown interface supports the following three methods:

  • AddRef
  • QueryInterface
  • Release

Remarks

You can obtain a pointer to an IDVDStreamControlInfo interface in the following ways:

  • By calling the IUnknown::QueryInterface method of a DVDData object and specifying the IID_IDVDStreamControlInfo reference identifier.
  • By calling the IDVDDataSearchInfo::GetControlInfo method.
