IDVDDomain::GetStreamAttributes

This method returns the IDVDStreamAttributes interface for the current domain.

HRESULT GetStreamAttributes(
IDVDStreamAttributes **ppAttr
);

Parameters

ppAttr
[out] Returns the IDVDStreamAttributes interface for this domain.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be one of the following error values.

Error value Description
E_INVALIDARG One or more arguments is invalid.
E_OUTOFMEMORY There was not enough memory available for the operation.
E_POINTER The returned pointer is invalid.
E_NOINTERFACE The method was unable to obtain and return an interface pointer.
