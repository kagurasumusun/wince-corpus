DVD_TEXT_LANGUAGE_UNIT

This structure contains text data language unit search pointer (TXTDT_LU_SRP) data.

typedef struct _structDVD_TEXT_LANGUAGE_UNIT {
UINT16 tdlc;
UINT8  charset;
} DVD_TEXT_LANGUAGE_UNIT, *PDVD_TEXT_LANGUAGE_UNIT;

Members

tdlc
TXTDT_LCD element of TXDT_LU_SRP.
charset
CHRS element of TXTDT_LU_SRP.
