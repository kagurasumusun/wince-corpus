IDVDDataSearchInfo

This interface provides access to the data search information (DSI) for a video object unit (VOBU).

The following table lists the methods for IDVDDataSearchInfo in the order the compiler calls them.

Method Description
IDVDDataSearchInfo::GetControlInfo Returns the IDVDStreamControlInfo interface.
IDVDDataSearchInfo::GetSCRBase Returns the system clock reference base (SCR_base) of the current navigation pack (NV_PCK).
IDVDDataSearchInfo::GetUnitEndAddress Returns the video object unit end address (VOBU_EA) from the data search information general information (DSI_GI).
IDVDDataSearchInfo::GetRefPictureAddress Returns the relative address of the first, second, or third reference picture in the video object unit (VOBU).
IDVDDataSearchInfo::GetVOB_ID Returns the video object unit's video object identification number (VOBU_VOB_IDN).
IDVDDataSearchInfo::GetC_IDN Returns the video object unit's cell identification number (VOBU_C_IDN).
IDVDDataSearchInfo::GetSeamlessCategory Returns the video object unit's seamless playback category (VOBU_SML_CAT).
IDVDDataSearchInfo::GetInterleavedUnitEndAddress Returns the interleaved unit's end address (ILVU_EA).
IDVDDataSearchInfo::GetNextInterleavedUnit Returns the next interleaved unit's start address (NXT_ILVU_SA) and the next interleaved unit's size (NXT_ILVU_SZ).
IDVDDataSearchInfo::GetAudioGapInfo Returns information about audio discontinuities in the current video object (VOB).
IDVDDataSearchInfo::GetSeamlessAngleChangeAddress Returns a specified seamless angle change's destination address (SML_AGL_Cn_DSTA) and size.
IDVDDataSearchInfo::GetUnitStepAddress Returns the address of a video object unit (VOBU) that is a specified distance forward or behind in the presentation.
IDVDDataSearchInfo::GetSyncAudioAddress Returns the target audio pack address (A_SYNCA) for a specified audio stream.
IDVDDataSearchInfo::GetSyncSPAddress Returns the video object unit (VOBU) start address for the target subpicture (SP_SYNCA) of a specified subpicture stream.

The IDVDDataSearchInfo interface, like all COM interfaces, inherits the IUnknown interface methods. The IUnknown interface supports the following three methods:

  • AddRef
  • QueryInterface
  • Release

Remarks

You can obtain a pointer to an IDVDDataSearchInfo interface in the following ways:

  • By calling the IUnknown::QueryInterface method of a DVDData object and specifying the IID_IDVDDataSearchInfo reference identifier.
  • By calling the IDVDStreamControlInfo::GetDataSearchInfo method.
