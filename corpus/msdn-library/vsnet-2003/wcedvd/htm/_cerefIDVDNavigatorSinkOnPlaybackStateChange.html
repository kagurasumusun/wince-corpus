IDVDNavigatorSink::OnPlaybackStateChange

This method is called whenever the playback state changes. This method provides the application with the new playback state.

HRESULT OnPlaybackStateChange(
EDDVDPlaybackState eState
);

Parameters

eState
[out] An EDDVDPlaybackState value identifying the new playback state.

Return Values

If the function succeeds, the return value is S_OK.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Dvdnav.idl Dvdnav.h Ddvdids.lib
