IDVDDomain::GetSpace

This method returns a bitmask indicating all of the spaces to that contain the current domain.

HRESULT GetSpace(
UINT8 *pSpaceSet 
);

Parameters

pSpaceSet
[out] Returns the bitmask for the DVD space(s). The returned bitmask is a logical OR of DVD_SYSTEM_SPACE_BIT, DVD_MENU_SPACE_BIT, DVD_VMG_SPACE_BIT, and DVD_VTS_SPACE_BIT.

Return Values

This method always succeeds. The return value is S_OK.

Requirements

Windows CE OS .NET 4.0 and later Dvdata.idl Dvdata.h Ddvdids.lib
