Telnet Server Installation and Usage

To install the Telnet Sample, build the source code for the appropriate device and copy the executable to \windows\Telnetd.dll.

To have device.exe load Telnet, add the following key to your registry. Telnet will restart automatically after you make these changes and hard reset your device.

[HKEY_LOCAL_MACHINE\Drivers\BuiltIn\TELNETD]
    "Dll"="TELNETD.Dll"
    "Order"=dword:9
    "Keep"=dword:1
    "Entry"="TelnetDInitialize"

To stop the Telnet server when running from Device.exe, it is necessary to set the IsEnabled registry value to 0, as described above. Once Telnet has been loaded by Device.exe, it cannot be unloaded. To uninstall telnetd from a system when running in this configuration, you must first delete the registry key above, hard reset your device, and then delete Telnetd.dll.
