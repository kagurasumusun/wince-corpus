Microsoft Windows CE .NET  

Telnet Server

The Microsoft® Windows® CE .NET operating system (OS) includes a sample Telnet server, also referred to as telnetd, which can be installed on Windows CE–based devices to allow remote administration through a standard telnet client.

Using the Telnet sample, you can alter the OS exactly as if you were running the command prompt (cmd.exe) on the device itself. For example, this can be an extremely convenient way to administer devices that do not have a display. You can use any of the built-in commands for cmd.exe when running Telnet, such as copy, del, and dir. You can also run any executable program that does not create a Windows–based user interface (UI) through a telnet client.

Source code for the sample Telnet server is provided as is, with out any warranties. You may modify the source code and make any feature additions or bug fixes as you see fit. Please see the End User License Agreement (EULA) for more information.

However, please note that the Telnet sample has not been through the same rigorous testing as most Microsoft products, and is not guaranteed to be of the same quality as released products. The sample code is primarily intended to show you how to write a Telnet server on Windows CE that operates as a device driver.

Note   Before running the Windows CE–based Telnet sample, please read all topics pertaining to the Telnet server to become familiar with the security risks and limitations involved.
