Microsoft Windows CE 3.0  

KD_IOCTL_QUERY_CBP

This input/output control is used to query the number of code breakpoints that are available. It is passed to OEMKDIoControl.

Parameters

dwIoControlCode
Set to KD_IOCTL_QUERY_CBP.
lpBuf
Pointer to a buffer that allocates space for a KD_BPINFO structure.
nBufSize
Size of the buffer pointed to by lpInBuf. This is set to the size of the KD_BPINFO structure.

Remarks

The OEM sets the ulCount member of KD_BPINFO to the number of code breakpoints available.

Return Values

If TRUE is returned, then the input/output control was successfully processed; otherwise, FALSE is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Pkfuncs.h
