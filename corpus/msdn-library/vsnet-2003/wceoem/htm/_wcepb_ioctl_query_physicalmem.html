Microsoft Windows CE 3.0  

IOCTL_QUERY_PHYSICALMEM

This input/output control provides information about a range of physical pages. It is passed to KernelIoControl and OEMIoControl.

Parameters

dwIoControlCode
Set to IOCTL_QUERY_PHYSICALMEM.
lpInBuf
Pointer to the address to be queried.
nInBufsize
Not used.
lpOutBuf
Pointer to the output buffer. This is set to a buffer allocated to hold the PHYSICAL_BASIC_INFORMATION structure.
nOutBufSize
Maximum number of bytes that can be returned in lpOutBuf. Set to the size of the PHYSICAL_BASIC_INFORMATION structure.
lpBytesReturned
Actual number of bytes returned in lpOutBuf.

Return Values

If TRUE is returned, then the input/output control was successfully processed; otherwise, FALSE is returned.

Remarks

OEMs must implement this API in order for the debugger to take advantage of additional features.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Pkfuncs.h
