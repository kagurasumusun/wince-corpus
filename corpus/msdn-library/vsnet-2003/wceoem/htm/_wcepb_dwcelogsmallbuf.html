Microsoft Windows CE 3.0  

dwCeLogSmallBuf

The OEM uses this global variable to adjust the size of the secondary logging buffer. This buffer is used to log interrupt events and must not be larger then 50% of the size of dwCeLogLargeBuf.

extern dwCeLogSmallBuf;

Remarks

The default value of dwCeLogSmallBuf is 4 KB, which can be overridden in OEMInit by declaring it and setting it to another value.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Celog.h
