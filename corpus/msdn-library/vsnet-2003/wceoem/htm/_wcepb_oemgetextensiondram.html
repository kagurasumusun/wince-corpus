Microsoft Windows CE 3.0  

OEMGetExtensionDRAM

This function gets information about extension DRAM, if present on the device.

BOOL OEMGetExtensionDRAM ( 
LPDWORD lpMemStart, 
LPDWORD lpMemLen );

Parameters

lpMemStart
[out] Page-aligned starting address of the extension DRAM, if present.
lpMemLen
[out] Length of the extension DRAM, if present. The length is a multiple of the size of a memory page.

Return Values

TRUE if extension DRAM is present; otherwise, FALSE.

Remarks

The kernel calls this function to determine whether additional memory is present.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Nkintr.h

MainMemoryEndAddress, OEMInit
