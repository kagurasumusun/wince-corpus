waveui_AfterDialogBox

This function is called after the DialogBoxParam function returns so that the dialog box can start its own message loop to retrieve and dispatch messages.

void waveui_AfterDialogBox (
LPVOID pChooseStruct, 
BOOL fIsFormatDialog);

Parameters

pChooseStruct
Pointer to the chooser structure.
fIsFormatDialog
Flag indicating whether the chooser structure is ACMFORMATCHOOSE, if the flag is TRUE, or ACMFILTERCHOOSE, if the flag is FALSE.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Waveui.c
