Microsoft Windows CE 3.0  

EDBG_ADAPTER

This structure contains information about the debug Ethernet adapter.

typedef struct {
EDBG_ADDR Addr;
DWORD SysIntrVal;
DWORD DHCPLeaseTime;
DWORD EdbgFlags;} 
EDBG_ADAPTER;

Members

Addr
Ethernet and IP address of the debug Ethernet adapter.
SysIntrVal
Logical interrupt for the Ethernet adapter. To register no interrupts, set to EDBG_SYSINTR_NOINTR. The adapter can then be accessed only in polling mode. In polling mode, if a packet is lost, the caller must block until an acknowledgement is received, which may take several seconds. While the system is waiting, it may appear to not be responding. In interrupt mode, acknowledgements are transparently processed by the interrupt thread, so this perceived delay does not occur.
DHCPLeaseTime
Duration of Dynamic Host Configuration Protocol (DHCP) IP lease in seconds. Should be set to 0 if DHCP is not being used for address assignment; otherwise, set to the value returned from the DHCP server.
EdbgFlags
Bitmask indicating information about the debug Ethernet adapter. Values for this field may include:
Value Description
EDBG_FLAGS_STATIC_IP Static IP addressing is being used
DEFAULT_DHCP_LEASE Number of seconds (259,200) in a three-day lease

Remarks

If the EDBG_FLAGS_STATIC_IP bit is set in the EdbgFlags field, then the IP address was statically assigned (not obtained from DHCP) and so no DHCP packets are sent for renewal. ARP packets are sent to defend the static IP address at about half the DHCPLeaseTime. If this bit is cleared, then the IP address was obtained from DHCP and the EDBG system renews the lease when necessary.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Halether.h
