Microsoft Windows CE 3.0  

EDBG_BOOTME_DATA

This structure defines the BootMe data that is broadcast by the target device. The data is Ethernet address information.

typedef struct _EDBG_BOOTME_DATA {
UCHAR VersionMajor;
UCHAR VersionMinor;
USHORT MACAddr[3];
DWORD IPAddr;
UCHAR PlatformId[EDBG_MAX_DEV_NAMELEN+1];
UCHAR DeviceName[EDBG_MAX_DEV_NAMELEN+1];
UCHAR CPUId;
UCHAR uBootmeVer;
DWORD dwBootFlags;
USHORT wDownloadPort;
USHORT wSvcPort;
} EDBG_BOOTME_DATA, *PEDBG_BOOTME_DATA;

Members

VersionMajor
Unsigned character that specifies the major version of the Ethernet boot loader.

Note that VersionMajor defines the Ethernet boot loader protocol, and it should not be changed in your OEM adaptation layer (OAL). Generally, all boot loaders with the same major version work with the same version of Eshell.exe. For example, for the Windows CE 2.1 version of Eshell.exe, the major version is 2.

VersionMinor
Unsigned character that specifies the minor version of the Ethernet boot loader.
MACAddr
Array of unsigned short integers that contain the Ethernet address of the target device (net byte order).
IPAddr
DWORD that contains the IP address of the target device (net byte order).
PlatformId
Unsigned character that contains the platform identifier string (NULL terminated).
DeviceName
Unsigned character that contains the device name string (NULL terminated). Should include platform and unique device identifier. DeviceName can be based on Ethernet address (for example, "Odo42").
CPUId
Unsigned character that contains the CPU identifier—the upper nibble of this byte value identifies the CPU type. The following table shows the CPU type identifiers that are defined:
Value Description
EDBG_CPU_TYPE_SHX EDBG_CPU_SH3
EDBG_CPU_SH4
EDBG_CPU_TYPE_MIPS EDBG_CPU_R3000
EDBG_CPU_R4102
EDBG_CPU_R4111
EDBG_CPU_R4200
EDBG_CPU_Rr300
EDBG_CPU_TYPE_X86 EDBG_CPU_i486
EDBG_CPU_TYPE_ARM EDBG_CPU_SA1100
EDBG_CPU_ARM720
EDBG_CPU_TYPE_PPC EDBG_CPU_PPC821
uBootmeVer
BOOTME version. This value must be in the range from 2 to the value of EDGE_CURRENT_BOOTME_VERSION. Otherwise, Eshell ignores all remaining fields and uses default settings.
dwBootFlags
DWORD that contains flags specifying options used by Eshell.exe to control download behavior, or otherwise indicate capabilities of the target device or bootloader. The following table shows the flag that is currently defined:
Flag Value Description
EDBG_BOOTLOAD_FORCE_DOWNLOAD 0x0001 Forces Eshell.exe to download a new image, regardless of the user's settings in the Options menu. Useful if a bootloader determines that the image currently loaded into flash is not present or is corrupt, for example.
EDBG_CURRENT_BOOTME_VERSION 2 Sets the current BOOTME version. This value must be 2 or higher.

All other bits are reserved for future use and should be set to 0.

wDownloadPort
Download port number, in net byte order. This value must be in the range from 0 to the value of EDBG_DOWNLOAD_PORT.
wSvcPort
Service port number, in net byte order. This value must be in the range from 0 to the value of EDBG_SVC_PORT.

Remarks

The target device broadcasts EDBG_BOOTME_DATA information during Ethernet boot load to the subnet broadcast address.
