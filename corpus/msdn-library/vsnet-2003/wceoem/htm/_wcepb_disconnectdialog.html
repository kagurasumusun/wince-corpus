Microsoft Windows CE 3.0  

DisconnectDialog

This function displays a dialog box that allows a user to disconnect from a network. This function is called by the network redirector when the application calls the WNetDisconnectDialog API.

BOOL DisconnectDialog ( 
HWND hParent, 
DWORD dwType);

Parameters

hParent
Handle to the parent window to which the dialog box is to be attached.
dwType
DWORD specifying the type of network resource from which to disconnect.

Return Values

TRUE indicates success. FALSE indicates either a failure or that the user has chosen Cancel on the dialog box.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Netui.h
