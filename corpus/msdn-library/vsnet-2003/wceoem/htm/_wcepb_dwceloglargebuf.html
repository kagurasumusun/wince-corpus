Microsoft Windows CE 3.0  

dwCeLogLargeBuf

The OEM uses this global variable to adjust the size of the main logging buffer. This value is in bytes and must be page-aligned.

extern dwCeLogLargeBuf;

Remarks

The default value of dwCeLogLargeBuf is 128 KB, which can be overridden in OEMInit by declaring it and setting it to another value.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Celog.h
