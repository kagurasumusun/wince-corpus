OEMProfileTimerEnable

This function enables a profiler timer.

void OEMProfileTimerEnable ( 
DWORD dwUSecInterval );

Parameters

dwUSecInterval
[in] Period of the profiler timer, in microseconds.

Return Values

None.

Remarks

Use OEMProfileTimerDisable to stop the profiler timer.

This function is defined in the sample code in Mdprof.c.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Profiler.h
