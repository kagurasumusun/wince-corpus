DEBUGLED

This macro conditionally outputs WORD values to the LED.

DEBUGLED (Condition, (Parameters))

Return Values

None.

Remarks

This macro may be used to conditionally output a debug LED pattern. The pattern is output if the Boolean input expression evaluates to TRUE. The parameters wIndex and dwPattern are passed to the WriteDebugLED function. Note that these parameters must be enclosed by parentheses to prevent syntax errors being generated by the preprocessor.

Requirements

Windows CE OS 2.10 and later Dbgapi.h
