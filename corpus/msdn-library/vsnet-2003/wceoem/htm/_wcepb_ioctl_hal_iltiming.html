Microsoft Windows CE 3.0  

IOCTL_HAL_ILTIMING

This input/output control is used by ILTiming.exe when it calls KernelIoControl with the ILTIMING_MESSAGE structure.

Parameters

dwIoControlCode
Set to IOCTL_HAL_ILTIMING.
lpInBuf
Pointer to the input buffer. This is set to a buffer containing the ILTIMING_MESSAGE structure.
nInBufsize
Set to the size of the ILTIMING_MESSAGE structure.
lpOutBuf
Not used; set to NULL.
nOutBufSize
Not used; set to 0.
lpBytesReturned
Not used; may be set to NULL.

Return Values

If TRUE is returned, then the input/output control was successfully processed; otherwise, FALSE is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Pkfuncs.h    

See Also

ILTIMING_MESSAGE, KernelIoControl
