Ioctl_Register_DataCollector

This function registers a data logging engine with Collection Manager.

HRESULT Ioctl_Register_DataCollector(
LPVOID pId, 
DWORD dwIDSize, 
LPVOID pBuffer, 
DWORD dwBufSize );

Parameters

pId
Pointer to a buffer that stores an identifier that uniquely identifies the logging engine to Collection Manager. The default logging engine uses a GUID to uniquely identify itself.
dwIDSize
Size of the buffer pointed to by pID.
pBuffer
Pointer to a buffer that contains zone information.
dwBufSize
Size of the buffer pointed to by pBuffer.

Remarks

Collection Manager, if present in the system, assigns the pointer pIoctl_Register_DataCollector the address of the Ioctl_Register_DataCollector function. If you are replacing Celog.lib, you must declare the following:

extern HRESULT (*pIoctl_Register_DataCollector)(LPVOID,DWORD,LPVOID,DWORD);

Before making a call to pIoctl_Register_DataCollector, verify that it is not NULL according to the following code example.

If (pIoctl_Register_Collector)
   pIoctl_Register_DataCollector(...);

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Oemioctl.c
