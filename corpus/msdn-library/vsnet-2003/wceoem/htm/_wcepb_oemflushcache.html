Microsoft Windows CE 3.0  

OEMFlushCache

This function is called by the kernel in response to a CacheSync request. 

_OEMFlushCache PROC NEAR PUBLIC

Return Values

None.

Remarks

The cupuid instruction is usually used to flush the cache. However, because the cupid instruction is not supported on some older x86 microprocessor designs, some OEMs will need to use the x86 cache flush instruction. For an example of this function, see the Oeminit.asm file in the %_WINCEROOT\Platform\Cepc\Kernel\Hal\X86 directory.

Example

_OEMFlushCache PROC NEAR PUBLIC
    xor    eax, eax
    pushad
;   cpuid
    DB     00fH
    DB     0a2H
    popad
    ret
_OEMFlushCache ENDP

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later
