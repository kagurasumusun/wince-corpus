Microsoft Windows CE 3.0  

IOCTL_COLLECTOR_SEND

This input/output control makes a request to call Ioctl_Send_DataCollector. This request is made by calling KernelIoControl with IOCTL_SEND_REGISTER.

Parameters

dwIoControlCode
Set to IOCTL_COLLECTOR_SEND. Supports calling Ioctl_Send_DataCollector.
lpInBuf
Set to Ioctl_Send_DataCollector PId parameter.
nInBufSize
Set to Ioctl_Send_DataCollector dwIDSize parameter.
lpOutBuf
Set to Ioctl_Send_DataCollector pBuffer parameter.
nOutBufSize
Set to Ioctl_Send_DataCollector dwBufSize parameter.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later
