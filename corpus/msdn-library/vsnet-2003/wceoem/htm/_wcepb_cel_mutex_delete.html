CEL_MUTEX_DELETE

This structure specifies that a mutex has been deleted from memory.

typedef struct __CEL_MUTEX_DELETE {
HANDLE hMutex;
} CEL_MUTEX_DELETE, *PCEL_MUTEX_DELETE;

Members

hMutex
Handle of the mutex that has been deleted.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Celog.h
