EdbgDeregisterBootCallback

This function deregisters the EDBG_BOOT_CALLBACK_FUNC callback function with the kernel.

BOOL EdbgDeregisterBootCallback( 
UCHAR Id, 
EDBG_BOOT_CALLBACK_FUNC pCallBack, 
PVOID pParam );

Parameters

Id
[in] Identifier of the client identifier. Passing in ID_ALL_DEVICES registers callback for all devices.
pCallBack
[in] Pointer to the address in memory of the callback function.
pParam
[in] Pointer to the parameter to pass to the EDBG_BOOT_CALLBACK_FUNC callback function.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

If there are no registered callbacks, deregister the callback function and clean up the broadcast listener thread and sockets. All parameters should be the same as those passed to EdbgRegisterBootCallback.

EdbgDeregisterBootCallback is implemented only in the version of Edbg.dll that is loaded by an application on the development workstation; it is not implemented in the OEM adaptation layer (OAL) on the target device.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ethdbg.h   Edbg.dll
