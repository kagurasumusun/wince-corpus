Microsoft Windows CE 3.0  

Creating a Custom Shell

The shell architecture in Windows CE allows you to implement a wide variety of shells, including a fully customized shell that is adapted to your platform. A Windows CE shell consists of shell components, each of which provides a specific area of shell functionality. Based on the hardware requirements of your device, you can select only the components you need to develop a custom shell. For example, if your device does not have a display, you can select the Cmd and Console components. These components provide a console-based Command Processor shell.

To provide a shell on your platform, you can use a Windows CE–supplied shell or develop your own custom shell.

The following table shows the shells that Windows CE supplies.

Shell Components Description
Command Processor Cmd, Console Command-line shell
Handheld PC style Explorer, Asform, Ceshell Similar to the Windows Explorer shell on Windows-based desktop platforms
Sample Taskman Displays the desktop and taskbar

If you choose to implement the Command Processor or Handheld PC style shell, you must use the shell as provided. You cannot modify either of these shells.

If you choose to develop your own custom shell, you can use the Sample shell as a foundation for your shell. Windows CE supplies the source code for the Sample shell in Public\Wceshellfe\Oak\Taskman. You can modify the source code to adapt the Sample shell to your Windows CE–based platform.

Once you have implemented a shell on your device, you can add other shell components to enhance it. These supplemental shell components provide features such as common dialog boxes and Control Panel components. You can also enable shell callback functions so that Windows CE can forward certain shell functions to your shell.
