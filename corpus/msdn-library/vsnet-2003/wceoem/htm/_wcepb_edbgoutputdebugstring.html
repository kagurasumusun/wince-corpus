Microsoft Windows CE 3.0  

EdbgOutputDebugString

This function prints the specified message to the debug serial port using the specified format.

void EdbgOutputDebugString( 
const char * fmt, 
const char valist... );

Parameters

fmt
[in] Character that contains the format string.
valist
[in] Characters comprising a list of variable arguments.

Return Values

None.

Remarks

This function is provided for debugging support of the debug Ethernet services. It formats and prints a message to the debug serial port, even if debug messages (NKvDbgPrintf) are routed over Ethernet

Format string Type
u unsigned
d int
c char
s string
x 4-bit hex number
B 8-bit hex number
H 16-bit hex number
X 32-bit hex number

EdbgOutputDebugString also calls the OEMWriteDebugByte function to write characters to the debug serial port.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Halether.h
