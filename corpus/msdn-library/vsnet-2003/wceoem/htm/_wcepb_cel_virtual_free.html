CEL_VIRTUAL_FREE

This structure specifies that a virtual memory allocation has been freed with VirtualFree.

typedef struct __CEL_VIRTUAL_FREE {
DWORD dwAddress;
DWORD dwSize;
DWORD dwType;
BYTE bReserved[0];
} CEL_VIRTUAL_FREE, *PCEL_VIRTUAL_FREE;

Members

dwAddress
Corresponds to the lpAddress parameter of VirtualFree.
dwSize
Corresponds to the dwSize parameter of VirtualFree.
dwType
Corresponds to the dwFreeType parameter of VirtualFree.
bReserved
Array reserved for future use.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Celog.h
