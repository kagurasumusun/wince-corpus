Microsoft Windows CE 3.0  

CeClearReplChangeBitsEx

This function clears the replication bits based on the replication partnership mask that is passed.

BOOL CeClearReplChangeBitsEx(
PCEGUID pguid,
CEOID oid,
DWORD mask
);

Parameters

pguid
Pointer to a CEGUID that identifies a mounted database volume or the internal object store.
oid
Object identifier.
mask
Replication partnership mask. Set one or both bits of the mask to clear the change for one or both partners.

Return Values

If the function succeeds, then TRUE is returned; otherwise, FALSE is returned.

Remarks

To clear the replication bit for a partner, you must first use REPL_CHANGE_WILLCLEAR with CeGetReplChangeBitsEx when reading the state of the partner bit.
