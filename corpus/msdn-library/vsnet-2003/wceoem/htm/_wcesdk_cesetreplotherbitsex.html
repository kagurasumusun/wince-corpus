CeSetReplOtherBitsEx

This function sets a private replication bit that can be used by the replication process.

BOOL CeSetReplOtherBitsEx(
PCEGUID pguid,
CEOID oid,
DWORD bits
);

Parameters

pguid
Pointer to a CEGUID that identifies a mounted database volume or the internal object store.
oid
Object identifier to query.
bits
A DWORD that stores a bit mask that is used to set or clear a private replication bit. Only bit position zero of the bit mask holds meaning The bit is either set or not set and the meaning is based on how an application uses it's replication processes.

Return Values

If the function succeeds, then TRUE is returned; otherwise, FALSE is returned.
