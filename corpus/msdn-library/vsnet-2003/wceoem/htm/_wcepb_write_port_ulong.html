Microsoft Windows CE 3.0  

WRITE_PORT_ULONG

This macro writes a ULONG value to the specified port address.

VOID WRITE_PORT_ULONG (
PULONG Port, 
ULONG Value )

Parameters

Port
[in] Pointer to the port, which must be a mapped memory range in I/O space.
Value
[in] Specifies a ULONG value to be written to the port.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ceddk.h
