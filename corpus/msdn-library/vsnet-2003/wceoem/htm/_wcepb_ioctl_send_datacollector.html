Ioctl_Send_DataCollector

This function sends data to Collection Manager.

HRESULT Ioctl_Send_DataCollector(
LPVOID pId, 
DWORD dwIDSize, 
LPVOID pBuffer, 
DWORD dwBufSize );

Parameters

pId
Pointer to a buffer that stores an identifier that uniquely identifies the logging engine to Collection Manager. The default logging engine uses a GUID to uniquely identify itself.
dwIDSize
Size of the buffer pointed to by pID.
pBuffer
Pointer to a buffer storing data that is to be sent to Collection Manager.
dwBufSize
Size of the buffer pointed to by pBuffer.

Remarks

Data Collection manager, if present in the system, assigns the pointer pIoctl_Send_DataCollector the address of the Ioctl_Send_DataCollector function. If you are replacing Celog.lib, you must declare the following:

extern HRESULT (*pIoctl_Send_DataCollector)(LPVOID,DWORD,LPVOID,DWORD);

Before making a call to pIoctl_Send_DataCollector, verify that it is not NULL according to the following code example.

If (pIoctl_Send_DataCollector)
   pIoctl_Send_DataCollector(...);

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Oemioctl.c
