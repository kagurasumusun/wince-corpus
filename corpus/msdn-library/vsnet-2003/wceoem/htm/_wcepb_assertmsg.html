ASSERTMSG

This macro invokes the DEBUGMSG and DBGCHK macros to produce a formatted debugging message and an assertion check with a default ("Unknown") module name.

ASSERTMSG (Message, Expression)

Return Values

None.

Remarks

This macro may be used to check the value of a Boolean expression and produce a formatted text message, as well as generating a DebugBreak if the expression evaluates FALSE. This macro calls the DEBUGMSG macro, followed by the DBGCHK macro. A default ("Unknown") module name is supplied to DBGCHK when invoked. Note that the parameter Message must be enclosed by parentheses to prevent syntax errors being generated by the preprocessor.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Dbgapi.h
