Microsoft Windows CE 3.0  

_SH3CacheLines

This variable defines the number of cache lines available to the kernel. By default, the SH3 ODO implementation sets this variable to 512 or 1024, depending upon the SH3 CPU model.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later
