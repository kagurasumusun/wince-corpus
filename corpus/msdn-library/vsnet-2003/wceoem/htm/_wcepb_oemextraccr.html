Microsoft Windows CE 3.0  

OEMExtraCCR

This global variable is used to configure the cache control register (CCR). For example, setting the cache to write-back or write-through mode.

DWORD OEMExtraCCR;

Remarks

This global variable applied only to SHx-specific devices and is optional; the default value is 0. For more information, see the Microprocessor Reference. This variable is defined in the OAL.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later
