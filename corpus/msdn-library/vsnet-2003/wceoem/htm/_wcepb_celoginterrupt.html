Microsoft Windows CE 3.0  

CeLogInterrupt

The kernel calls this function twice for each interrupt; once when the interrupt occurs and before the ISR is called, and again when the ISR returns to the kernel.

void CeLogInterrupt (
DWORD dwLogValue );

Parameters

dwLogValue
This parameter is divided into two parts. The upper word is the wSysIntr member of the CEL_INT_DATA structure, while the lower word is the wNestingLevel member of the CEL_INT_DATA structure. The upper bit of the wNestingLevel member indicates whether the event is an interrupt entry or exit.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Celog.h
