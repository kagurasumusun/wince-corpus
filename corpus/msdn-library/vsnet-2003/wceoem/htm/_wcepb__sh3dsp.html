Microsoft Windows CE 3.0  

_SH3DSP

This variable is used to identify an SH3 CPU with DSP support.

Remarks

The _SH3DSP variable is set to the following value:

_SH3DSP   .data.l 0

This variable is not currently supported, but is available for future use.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later
