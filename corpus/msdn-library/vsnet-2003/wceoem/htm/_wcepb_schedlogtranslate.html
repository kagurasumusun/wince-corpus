Microsoft Windows CE 3.0  

SchedLogTranslate

This function enables a thread identifier or process identifier forwarded by the OAL logging functions to be converted into a Windows CE object handle.

void SchedLogTranslate ( 
DWORD dwThreadID, 
HANDLE *pThreadHandle, 
DWORD dwProcID, 
HANDLE *pProcessHandle );

Parameters

dwThreadID
Thread identifier provided by the OAL logging functions.
pThreadHandle
Pointer to a handle that stores the thread handle upon return. If pThreadHandle is NULL, then no thread translation occurs.
dwProcID
Process identifier (ProcessID) provided by the OAL logging functions.
pProcessHandle
Pointer to a handle that stores the process handle on return. If pProcessHandle is NULL, then no process translation occurs.

Return Values

None.

Remarks

Call this function if the SCHEDLOG component has been linked into the kernel and you need to obtain a thread or process handle.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Schedlog.h

LogThreadCreate, LogThreadDelete, LogThreadSwitch
