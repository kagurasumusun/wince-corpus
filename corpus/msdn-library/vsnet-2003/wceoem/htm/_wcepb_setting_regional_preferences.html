Setting Regional Preferences

Platform Builder offers the Regional Settings application in the Control Panel, which allows users to set the preferences for the appearance of numbers, currencies, dates, and times. To include the Regional Settings application within your Control Panel, include one of the following modules in your Cesysgen.bat file:

Intll
For a Regional Settings Control Panel application with landscape orientation
Intlp
For a Regional Settings Control Panel application with portrait orientation
Note   The landscape versions of Control Panel applications are fully supported and tested by Microsoft. The portrait versions of these applications are provided as a convenience to OEMs and are not fully supported or tested by Microsoft. If you are using the Maxall configuration, the CPLMAIN_LP flag enables you to switch between portrait and landscape orientations.
