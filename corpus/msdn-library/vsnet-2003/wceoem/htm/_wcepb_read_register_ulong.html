READ_REGISTER_ULONG

This macro reads a ULONG value from the specified register address.

ULONG READ_REGISTER_ULONG (
PULONG Register )

Parameters

Register
[in] Pointer to the register, which must be a mapped range in memory space.

Return Values

This macro returns the ULONG value read from the specified register address.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ceddk.h
