Microsoft Windows CE 3.0  

IOCTL_EDBG_REGISTER_CLIENT

This input/output control supports a call to the Ethernet debug function EdbgRegisterClient (Target Device). A request to call EdbgRegisterClient (Target Device) is made by calling OEMIoControl with IOCTL_EDBG_REGISTER_CLIENT.

Parameters

dwIoControlCode
Set to IOCTL_EDBG_REGISTER_CLIENT. Supports a call to the Ethernet debug function EdbgRegisterClient (Target Device)

Return Values

If TRUE is returned then the input/output control was successfully processed; otherwise, FALSE is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Pkfuncs.h
