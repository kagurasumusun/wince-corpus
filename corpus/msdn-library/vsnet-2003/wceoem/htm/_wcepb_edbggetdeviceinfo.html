Microsoft Windows CE 3.0  

EdbgGetDeviceInfo

This function retrieves information from Eshell regarding a specified device. This function is available only on a development workstation.

BOOL EdbgGetDeviceInfo( 
char *DeviceName, 
UCHAR Id, 
EDBG_BOOTME_DATA *pBootMeData );

Parameters

DeviceName
[in] Character which is currently unsupported and must be NULL.
Id
[in] Identifier of the client registered using EdbgRegisterClient.
pBootMeData
[out] Pointer to BOOTME information on the target device.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This function returns a BOOTME structure sent by the device. This structure contains addressing, version, and platform information. This function can return information specified by client identifier (EdbgRegisterClient must have previously succeeded) or device name.

Returning information by device name is not supported in the version of Edbg.dll shipped with Windows CE 2.1.

This function is implemented only in Ethdbg.lib on the target device.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Ethdbg.h   Edbg.dll
