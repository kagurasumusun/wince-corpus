Microsoft Windows CE 3.0  

UIPARAM

This structure contains event data and type information.

struct _UIPARAM { 
DWORD dwType, 
DWORD dwValue };

Members

dwType
Flag indicating the type of data stored in dwValue. The possible flag values are shown in the following table.
Value Description
UIPARAM_VALUE The data in dwValue is a value that can be passed directly to FormatMessage.
UIPARAM_STRINGID The data in dwValue is a resource string identifier.
dwValue
Value or resource string identifier as specified by dwType. The following table shows the possible resource string identifiers when dwType is equal to UIPARAM_STRINGID.
Value Description
IDS_FATUI_SCANERR_REPAIR Text displayed: "Do you want this problem automatically repaired now?"
IDS_FATUI_SCANERR_ADVISE Text displayed: "The system is unable to repair this error. Select OK to continue checking for errors on this volume, or cancel to stop."
IDS_FATUI_HIDDEN_STRING Hidden
–1 No associated resource string.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Fatui.h
