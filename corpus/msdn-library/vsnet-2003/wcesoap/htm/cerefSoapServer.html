SoapServer

This object provides a server-side, high-level interface whose methods process the incoming Simple Object Access Protocol (SOAP) request and return a SOAP response.

The following tables show the methods and properties supported by the SOAPServer object.

Method Description
Init Initializes the SoapServer object with the Web Services Description Language (WSDL) and Web Services Meta Language (WSML) files provided as input.
SoapInvoke Gets the Simple Object Access Protocol (SOAP) method out of the incoming SOAP message (request), executes the method, generates a SOAP outgoing message (response), and sends the response to the client.
