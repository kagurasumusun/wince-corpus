Types Element

The <types> element in a Web Services Description Language (WSDL) file is a container for defining the various data types used in exchanging messages.

Here is the code example from Calc.wsdl containing the <types> element:

<types>
  <schema targetNamespace='http://tempuri.org/type'
    xmlns='http://www.w3.org/2001/XMLSchema'
    xmlns:SOAP-ENC='http://schemas.xmlsoap.org/soap/encoding/'
    xmlns:wsdl='http://schemas.xmlsoap.org/wsdl/'>
  </schema>
</types>

In this example, the schema in the <types> element is a simple one and does not define any data types because the <message> elements in the WSDL file define the data types of various message parts exchanged in a Simple Object Access Protocol (SOAP) message.
