elementName Property (SoapMapper)

This property specifies the name of the element that appears in a Simple Object Access Protocol (SOAP) message for the given message part.

HRESULT get_elementName(
BSTR *pbstrElementName
);

Parameters

pbstrElementName
[out] Name of the element that is being mapped.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.
