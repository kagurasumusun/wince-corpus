Microsoft Windows CE .NET  

SOAP Sample Applications

The sample applications included in Windows CE .NET cover the basics of how to use the Windows CE .NET Simple Object Access Protocol (SOAP) Toolkit. These basic sample applications let you create, execute, and see how to send and receive SOAP messages.

To use these samples, you must include DCOM, Microsoft Foundation Classes (MFC), and Active Template Library for Windows CE (ATL) in your image because the samples require some of the functionality in these features. However, SOAP does not necessarily require DCOM, MFC, and ATL. It depends on the your applications.

To create a Microsoft eMbedded Visual C++ project, see Creating a Project for the Client-Side Sample and Creating a Project for the Server-Side Sample.

You can find the following sample applications in %_WINCEROOT%\Public\Servers\SDK\Samples\SOAP directory. Each sample subdirectory contains a project file that you can use to build the sample applications for many of the BSPs:

  • The Calc application is a simple calculator that can add, multiply, divide, and subtract numbers. It illustrates the most basic use of the toolkit. The service takes parameters of simple data types and returns a value of a simple data type. The samples include a client and a server application. You can find the samples in the %_WINCEROOT%\Public\Servers\SDK\Samples\SOAP\Calc directory.

    The Calc\Client\RPC subdirectory contains the low level API samples and the Calc\Client\SRSZ subdirectory contains high level API samples. The server applications in Calc\Service subdirectory follow the same naming scheme.

  • DataType application illustrates the passing of each data type supported by the toolkit between a client and a service. You can find the samples in the %_WINCEROOT%\Public\Servers\SDK\Samples\SOAP\Datatype directory.
  • Fault application illustrates how faults can be generated on the server and passed back to the client. You can find the samples in the %_WINCEROOT%\Public\Servers\SDK\Samples\SOAP\Fault directory.
  • MultiClient is a client application that uses the information contained in a WSDL document to send requests to any service. You can find the samples in the %_WINCEROOT%\Public\Servers\SDK\Samples\SOAP\Mclient directory.

To register COM components, you can use regsvr32 application, which is located in %_WINCEROOT%\Public\DCOM\SDK\Samples\Regsvr directory.
