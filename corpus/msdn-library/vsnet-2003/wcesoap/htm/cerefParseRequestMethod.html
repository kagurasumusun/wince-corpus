ParseRequest Method

This method inspects the Simple Object Access Protocol (SOAP) request message, and returns the port (WSDLPort object) and operation (WSDLOperation object) corresponding to the request.

HRESULT ParseRequest(
IsoapReader *pReader, 
IWSDLPort **ppIWSDLPort, 
IWSDLOperation **ppIWSDLOperation
);

Parameters

pReader
[in] SoapReader object loaded with the SOAP request message.
ppIWSDLPort
[out] WSDLPort object corresponding to the port that defines the operation identified by the SOAP message.
ppIWSDLOperation
[out] WSDLOperation object corresponding to the operation identified by the SOAP message.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.
