SoapConnector

This interface implements the transport protocol used by objects that send and receive Simple Object Access Protocol (SOAP) messages. Each object can implement a different transport protocol such as HTTP (Hypertext Transfer Protocol), SMTP (Simple Mail Transfer Protocol), or FTP (File Transfer Protocol).

The SOAP Toolkit provides the following SoapConnector implementions:

  • HttpConnector — Implements the standard SOAP HTTP protocol binding.

The following tables show the methods and properties supported by the SoapConnector interface.

Method Description
BeginMessage Signals the start of a SOAP message being sent to the server.
BeginMessageWSDL Signals the start of a SOAP message being sent to the server. Use this method when using WSDLReader object model.
Connect Initializes the SoapConnector object and prepares the connection.
ConnectWSDL Initializes the SoapConnector object and prepares the connection. Use this method when using WSDLReader object model.
EndMessage Signals the end of a SOAP message being sent to the server.
reset Resets the connection.
Property Description
InputStream (read-only) Provides the stream that sends data to the server.
OutputStream (read-only) Provides the stream that receives data from the server.
Property Sets or gets the value of a property specific to a SoapConnector implementation.

Remarks

You can configure additional SoapConnector implementations. For more information, see SoapConnectorFactory.
