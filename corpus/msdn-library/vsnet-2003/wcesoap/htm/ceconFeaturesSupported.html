Microsoft Windows CE .NET  

Features Supported

The following list shows the highlights of the features supported in the Windows CE .NET Simple Object Access Protocol (SOAP) Toolkit:

  • Support for the World Wide Web Consortium (W3C) Web Services Description Language (WSDL) 1.1, W3C Note 15 March 2001 specification.
  • Support for W3C Simple Object Access Protocol (SOAP) 1.1, W3C Note 08 May 2000 specification.
  • Support for the W3C XML Schema Proposed Recommendations:
    • XML Schema Part 0: Primer, W3C Recommendation.
    • XML Schema Part 1: Structures, W3C Recommendation.
    • XML Schema Part 2: Datatypes, W3C Recommendation.
  • Support for arrays of simple types, and arrays of complex types.
  • Support for multidimensional arrays.
  • Support for complex types.
  • Support for RPC-encoded and document-literal Web Services Description Language (WSDL) operations.
  • Support for SOAP headers.
