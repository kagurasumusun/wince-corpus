SoapReader

This interface reads Simple Object Access Protocol (SOAP) messages. The methods in this object read the SOAP message and parse the message into a DOM. You can then retrieve the individual elements from the DOM.

The Calc sample application in SOAP Sample Applications topic uses the SoapReader object.

Various SoapReader properties make it easy to extract information out of the SoapMessage (DOM) without having to know the message's structure.

Note   While you can also retrieve information from a Simple Object Access Protocol (SOAP) message using the Microsoft® XML Parser (MSXML) DOM API, the SoapReader properties make it easier to do the same thing.

The following tables show the methods and properties supported by SOAPReader object.

Method Description
load Loads an XML document from a file, stream, or a URL.
loadXML Loads an XML document string provided as input.
Property Description
Body Returns the <Body> element of a SOAP message.
BodyEntries Returns a collection of entries in the <Body> element of a SOAP message.
BodyEntry Returns the first entry in the <Body> element of a SOAP message that matches the given local name and namespace URI.
DOM Provides a reference to the DOM document.
Envelope Returns the <Envelope> element in a SOAP message (thus, the entire SOAP message).
Fault Returns the <Fault> element in a SOAP message.
faultactor Returns the <faultactor> element of the <Fault> element in the SOAP message.
faultcode Returns the <faultcode> element of the <Fault> element in the SOAP message.
FaultDetail Returns the <detail> element of the <Fault> element in the SOAP message.
faultstring Returns the <faultstring> element of the <Fault> element in the SOAP message.
Header Returns the <Header> element in a SOAP message.
HeaderEntries Returns a collection of entries in the <Header> element of a SOAP message.
HeaderEntry Returns the first entry in the <Header> element of a SOAP message that matches the given local name and namespace URI.
MustUnderstandHeaderEntries Returns all entries from the <Header> element in a Simple Object Access Protocol (SOAP) message that have a mustUnderstand attribute equal to 1.
RPCParameter Returns the first child element of the first entry within the <Body> element of a SOAP that matches the given local name and namespace URI.
RPCResult Returns the first child element of the first entry in the <Body> element of a SOAP message.
RPCStruct Returns the first entry in the <Body> element of a SOAP message.
soapAction Returns the "SOAPAction" HTTP header, if the input was a request object.
