Analyzing WSDL and WSML Files

The object model discussed in this topic provides methods and properties that allow you to programmatically analyze the Web Services Description Language (WSDL) and Web Services Meta Language (WSML) files. In fact, this is the same object model used when processing a Simple Object Access Protocol (SOAP) request at the server.

Note   In most cases you do not need to analyze the WSDL and WSML files. This discussion of the object model allows you to use the object model to build your own SoapClient replacement. For example, you may want to create a SoapClient replacement if you want to display a list of available ports or available operations to the user for a more dynamic environment.

The WSDLReader object loads and analyzes WSDL and WSML documents. It then makes the information in those documents available though the EnumWSDLService, WSDLService, EnumWSDLPort, WSDLPort, EnumWSDLOperation, WSDLOperation, EnumSoapMapper, and SoapMapper objects.

The WSDLReader object can also inspect an incoming SOAP message to identify the operation being requested.
