SoapSerializer

The interface builds a Simple Object Access Protocol (SOAP) message.

The following tables show the methods and properties supported by the SoapSerializer object.

Method Description
startBody Begins the <Body> element in a SOAP message.
endBody Ends the <Body> element for a Simple Object Access Protocol (SOAP) message.
startElement Begins an entry in the <Body> element.
endElement End of an entry (child element) in the <Body> element.
startEnvelope Begins an <Envelope> element in a SOAP message
endEnvelope Ends an <Envelope> element in a SOAP message.
GetPrefixForNamespace Retrieves the prefix for existing namespace.
startFault Begins a <Fault> element in a SOAP message.
endFault Ends a <Fault> element in a SOAP message.
startFaultDetail Begins a <detail> element within a <Fault> element in a SOAP message.
endFaultDetail Ends the <detail> element within a <Fault> element in a SOAP message.
startHeader Begins a <Header> element in a SOAP message.
endHeader Ends a <Header> element in a SOAP message.
startHeaderElement Begins a child element in the <Header> element.
endHeaderElement Ends a child element in the <Header> element.
Init Initializes the SoapSerializer object.
reset Resets the SoapSerializer object to its initial state.
SoapAttribute Adds an attribute to an element when building a SOAP message.
SoapDefaultNamespace Sets the default namespace for the SOAP message
SoapNamespace Defines a namespace prefix and uses it to qualify the SOAP message elements.
writeBuffer Writes the value of an element to the SOAP message.
writeString Writes the value of an element to the SOAP message.
writeXML Writes a CDATA section into the stream.
Property Description
EncodingStream Property Returns the EncodingStream on the destination.

Remarks

All the methods in the SoapSerializer object build SOAP messages. Before using any of these methods, you must set the Stream property to a stream to which the SoapSerializer object can write the SOAP message. Also, you have to call the reset method between messages build using SoapSerializer.
