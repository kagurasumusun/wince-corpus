name Property (WSDLPort)

This property returns the name attribute of a <port> element in the Web Services Description Language (WSDL) file.

HRESULT get_name(
BSTR *pbstrPortName
);

Parameters

pbstrPortName
[out] Name of the port.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.

Requirements

Windows CE OS .NET 4.0 and later   Mssoap.h Mssoap1.dll
