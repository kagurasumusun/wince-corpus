Creating a Project for the SOAPUtils library

To create a project for the SOAPUtils library

  1. Open Microsoft eMbedded Visual C++ 4.0.
  2. From the File menu, choose New.
  3. Choose the Projects tab.
  4. Select WCE Static Library.
  5. In the Project Name box, enter SOAPUtils as the name of your project.
  6. Select the Create new workspace option.
  7. Verify the CPU selection.
  8. Choose OK.
  9. Choose Finish.

    The New Project Information dialog box confirms the choices that you made in the previous steps.

  10. Choose OK.
  11. From the Project menu, choose Add To Project, and then choose Files.
  12. Add all the source files in the %_WINCEROOT%\Public\Servers\SDK\Samples\SOAP\SOAPUtils folder to the project.
  13. Choose OK.
  14. From the Project menu, choose Settings.
  15. In the Settings For box, select All Configurations.
  16. Choose the C/C++ tab.
  17. In the Category box, select Preprocessor.
  18. In the Additional include directories box, add the following paths:
    • %_WINCEROOT%\Public\Servers\SDK\Samples\SOAP\SOAPUtils
    • %_WINCEROOT%\Others\ATL\Include
    • %_WINCEROOT%\Others\MFC\Include
  19. Choose OK.
  20. From the Build menu, choose Build [F7] to build the project.
