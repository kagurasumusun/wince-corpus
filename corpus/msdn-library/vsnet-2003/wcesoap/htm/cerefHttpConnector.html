HttpConnector

This interface implements the standard HTTP protocol binding for objects that send and receive Simple Object Access Protocol (SOAP) messages. HttpConnector is an HTTP-specific implementation of the SoapConnector interface.

The following tables show the methods and properties supported by the HttpConnector interface.

Method Description
BeginMessage Signals the start of a Simple Object Access Protocol (SOAP) message being sent to the server.
Connect Initializes the object and prepares the connection.
EndMessage Signals the end of a SOAP message being sent to the server.
reset Resets the connection.
Property Description
InputStream (read-only) Provides the stream that sends data to the server.
OutputStream (read-only) Provides the stream that receives data from the server.
Property Sets or gets the value of a property specific to an HttpConnector implementation.

The HttpConnector object implements the SoapConnector interface. Therefore, for a description of all HttpConnector methods and properties other than the Property property, see SoapConnector members.

Remarks

You can configure additional SoapConnector implementations. For more information, see SoapConnectorFactory.
