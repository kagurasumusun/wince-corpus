Creating a Project for the Client-Side Sample

Use this procedure to create a project for the client-side samples in Soap Sample Applications.

To create the client executable application

  1. Open Microsoft eMbedded Visual C++ 4.0.
  2. From the File menu, choose New.
  3. Choose the Projects tab.
  4. Select WCE Application.
  5. In the Project Name box, enter the name of your project.
  6. Select the Create new workspace option.
  7. Verify the CPU selection.
  8. Choose OK.
  9. Select the An Empty Project option.
  10. Choose Finish.

    The New Project Information dialog box confirms the choices that you made in the previous steps.

  11. Choose OK.
  12. From the Project menu, choose Add To Project, and then choose Files.
  13. Add all the files in the Client sample folder to the project.
  14. From the Project menu, choose Settings.
  15. In the Settings For box, select All Configurations.
  16. Choose the General tab.
  17. In the Microsoft Foundation Classes box, select Use MFC in a Shared DLL.
  18. Choose the C/C++ tab.
  19. In the Category box, select Preprocessor.
  20. In the Additional include directories box, add the following paths:
    • %_WINCEROOT%\Public\Servers\SDK\Samples\SOAP\SOAPUtils
    • %_WINCEROOT%\Others\ATL\Include
    • %_WINCEROOT%\Others\MFC\Include
  21. Choose the Link tab.
  22. In the Category box, select Output.
  23. In the Entry-Point Symbol box, modify the symbol to wWinMainCRTStartup.
  24. In the Category box, select Input.
  25. In the Object/Library modules box, add SOAPUtils.lib*.
  26. In the Ignore libraries box, add Comsupp.lib and User32.lib.
  27. Choose the Resources tab.
  28. In the Additional resource include directories box, add the path to %_WINCEROOT%\Others\MFC\Include.
  29. Choose OK.
  30. From the Build menu, choose Build[F7] to build the project.
