Code Listing for the Calc.wsdl File

You can find the Calc.wsdl sample file in %_WINCEROOT%\Public\Servers\SDK\Samples\SOAP\Calc\Service\RPC\Isapicpp. The following code shows the entire content of the file.

Note   You need to change the value of the location attribute of the <soap:address> element. The URL specifies a test device. Change it to the server name as appropriate.

  </types>
  <message name='Calc.Multiply'>
