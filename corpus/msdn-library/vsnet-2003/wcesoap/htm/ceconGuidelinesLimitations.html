Guidelines and Limitations

  • The WSDL implementation in the SOAP Toolkit is WSDL 1.1 Specification compliant.
  • The following are suggestions and hints for creating COM objects to be used with this implementation of SOAP.
  • Optional parameters are not supported in interfaces mapped to SOAP. Values must be provided for all defined parameters.
  • While the SOAP Toolkit high-level interfaces use normal COM calls to expose objects through SOAP, the SOAP Toolkit is not a general replacement for DCOM. Many DCOM features like lifetime-management, passing objects by reference, and some COM data types do not map to the current SOAP specification. These DCOM are not supported by the SOAP Toolkit and probably never will be. While the SOAP Toolkit may allow you to expose existing COM objects through SOAP, this is not true in all cases. Wrapper objects and possibly custom mappers may be required to expose some existing objects. While the SOAP Toolkit continues to support more DCOM-like features, the support will never be complete.
  • In this release, custom type mappers do not support user defined data types (VT_RECORD).
