getElementMapperbyName Method

This method creates and returns the type mapper for the specified element name. The getElementMapperbyName method looks in the schema identified by the addSchema method for the specified XML Schema Definition (XSD) element, and then creates a type mapper for that element.

HRESULT getElementMapperbyName(
BSTR  bstrElementName, 
BSTR  bstrElementNamespace, 
IsoapTypeMapper **ppSoapTypeMapper
);

Parameters

bstrElementName
[in] Name of the element.
bstrElementNamespace
[in] Namespace of the element.
ppSoapTypeMapper
[in] Type mapper for the element.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.
