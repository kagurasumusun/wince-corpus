Recipients Define Meeting Requests

In the Outlook 98 object model, you must set the MeetingStatus property of an appointment item to mark is as a meeting request. Thus, you can have appointments with recipients that are not meeting requests. This is not possible on a Windows CE device. In POOM, an appointment is a meeting request if it has a Recipients collection. The MeetingStatus property is a read-only property and can only take on the value olNonMeeting or olMeeting.

On the Recipient object the Address property is a read/write property; on Outlook 98, it is a read-only property. This is because there is no Resolve method to resolve the display name to an e-mail address.
