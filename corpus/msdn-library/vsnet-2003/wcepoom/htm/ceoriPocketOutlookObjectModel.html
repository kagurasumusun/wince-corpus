Pocket Outlook Object Model

The Pocket Outlook Object Model (POOM) allows you to manipulate Contact, Calendar, and Tasks data in Inbox electronic messaging software. It also supports viewing City information related to the World Clock.

POOM is modeled after the desktop Microsoft Outlook® 97 and 98 object models. To provide a smaller footprint more suited for Windows CE devices, POOM is a subset of the desktop Outlook object model.
