ITask::Save

This method saves a Task item.

HRESULT Save ();

Return Values

S_OK indicates that the Task item was saved successfully. If the Task cannot be saved, the appropriate HRESULT is returned.

Example

The following code example creates and saves a Task.

void CreateTask (IPOutlookApp *polApp)
{
ITask *pTask;
SYSTEMTIME st;
DATE date;

// Create task
polApp->CreateItem (olTaskItem, (IDispatch**)&pTask);
pTask->put_Subject (TEXT ("A Task"));

// Convert Monday, 4/5/99 to a DATE
memset (&st, 0, sizeof (SYSTEMTIME));
st.wMonth = 4;
st.wDay   = 5;
st.wYear  = 1999;
polApp->SystemTimetoVariantTime (&st, &date);

// Set the start date and save the task
polTask->put_StartDate (date);
polTask->put_Importance (olImportanceHigh);
polTask->Save ()

// Release objects
pTask->Release ();
}
