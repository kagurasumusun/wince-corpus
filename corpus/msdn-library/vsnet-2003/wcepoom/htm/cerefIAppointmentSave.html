IAppointment::Save

This method saves an Appointment item.

HRESULT Save ();

Return Values

S_OK indicates that the Appointment item was saved successfully. If the Appointment cannot be saved, the appropriate HRESULT is returned.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.0 and later   Pimstore.h
