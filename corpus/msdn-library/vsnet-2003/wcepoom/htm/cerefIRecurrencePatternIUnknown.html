IRecurrencePattern:IUnknown

This interface sets the recurrence of a Task or Appointment. To get an IRecurrencePattern object, call GetRecurrencePattern on a Task or Appointment.

A recurrence pattern for an Appointment supports the following method.

Methods in Vtable Order

Method Description
IRecurrencePattern::GetOccurrence Returns a specific instance of an appointment for a specific date.
