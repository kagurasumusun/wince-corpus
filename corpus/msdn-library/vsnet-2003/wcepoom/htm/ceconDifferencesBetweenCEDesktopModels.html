Differences Between the Windows CE and Desktop Models

The following topics discuss the principal differences between the Windows CE and desktop models:

  • Cancel Method
  • City Item
  • Infrared Support
  • No Inspector or Explorer Object
  • No Events
  • No NameSpace Object
  • OID Instead of EntryID
  • Outlook Compatibility
  • Reminder Methods
  • Recipients Define Meeting Requests
