City Item

POOM includes an extra default item type, City, which lets the user view information about all the cities used by the World Clock application. The TimeZoneFromIndex method and the following properties were added to the Application object to support the City item.

Property Description
CurrentCityIndex Whether the current city is the home or visiting city.
HomeCity The current home city.
VisitingCity The current visiting city.

The TimeZone object displays information about individual time zones. Although City is a read-only object, you can still access cities the same way you would any other item type by retrieving the Cities folder. You can filter or find cities based on a restriction.
