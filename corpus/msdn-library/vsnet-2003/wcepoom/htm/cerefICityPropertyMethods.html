ICity Property Methods

The ICity interface properties and property methods are described in the following table.

Properties in Vtable Order

Property Description
Longitude 
HRESULT get_Longitude
([out] long *plLongitude);
HRESULT put_Longitude
([in] long lLongitude);
 Returns or sets the longitude for the city.

This is an integer value equal to 100 times the decimal representation of the actual longitude in degrees.

Positive values are locations in the Eastern hemisphere and negative values are locations in the Western hemisphere, relative to the Greenwich meridian.
Latitude 
HRESULT get_Latitude
([out] long *plLatitude);
HRESULT put_Latitude
([in] long lLatitude);
 Returns or sets the latitude for the city.

This is an integer value equal to 100 times the decimal representation of the actual latitude in degrees.

Positive values are locations in the Northern hemisphere and negative values are locations in the Southern hemisphere, relative to the equator.
TimezoneIndex 
HRESULT get_TimezoneIndex
([out] long *plTimezoneIndex);

HRESULT put_TimezoneIndex
([in] long lTimezoneIndex);
 Returns or sets the time zone index for the city.

Cities return a one-based time zone index rather than an ITimeZone object, to provide better filtering support.

To retrieve the corresponding ITimeZone object, call GetTimeZoneFromIndex on the Pocket Outlook IPOutlookApp object.
AirportCode 
HRESULT get_AirportCode
([out] BSTR *pbstrAirportCode);
HRESULT put_AirportCode
([in] BSTR bstrAirportCode);
 Returns or sets the airport code for the city.
CountryPhoneCode 
HRESULT get_CountryPhoneCode
([out] BSTR *pbstrCountryPhoneCode);
HRESULT put_CountryPhoneCode
([in] BSTR bstrCountryPhoneCode);
 Returns or sets the telephone country/region code for the city.
AreaCode 
HRESULT get_AreaCode
([out] BSTR *pbstrAreaCode);
HRESULT put_AreaCode
([in] BSTR bstrAreaCode);
 Returns or sets the area or city code for the city.
Name 
HRESULT get_Name
([out] BSTR *pbstrName);
HRESULT put_Name
([in] BSTR bstrName);
 Returns or sets the name of the city.
Country 
HRESULT get_Country
([out] BSTR *pbstrCountry);
HRESULT put_Country
([in] BSTR bstrCountry);
 Returns or sets the country/region for the city.
InROM 
HRESULT get_InROM
([out] VARIANT_BOOL *pbInROM);
 Returns whether the city is stored in ROM.

TRUE if the city is stored in ROM, FALSE if the city is user-defined.
Application 
HRESULT get_Application
([out] IPOutlookApp **ppIPOutlookApp);
 Returns the main Pocket Outlook application object.

Return Values

Each property method supports the standard HRESULT return values, including S_OK.

Remarks

Most of the cities used by the World Clock are provided in ROM and cannot be deleted. If you attempt to delete a city that is stored in ROM, you get the error code E_CITYINROM. You can set the values for any city's property that supports the put_ method. However, the changes are stored in RAM. If the user cold-boots the device, property values revert to the initial values stored in ROM and any user-created cities are lost.

If you are running a version of Pocket Outlook earlier than 1.1 and you try to save changes to properties of a city stored in ROM, the Save method returns E_CITYINROM.
