Making the Home City Seattle, WA

The following C++ code example shows how to set the current home city to Seattle, WA, and to make that the currently selected city on the device. Note that this will automatically change the system's time and time zone if necessary. We assume that we already have an Application object.

IFolder *pFolder;
IPOutlookItemCollection *polItems;
ICity *pCity;

// Get the Cities folder.
polApp->GetDefaultFolder (olFolderCities, &pFolder);

// Get the Item Collection for this folder.
pFolder->get_Items (&polItems);

// Find Seattle, WA in this item collection.
polItems->Find (TEXT ("[Name] = \"Seattle, WA\""), (IDispatch**)&pCity);

// Make this the home city.
polApp->put_HomeCity (pCity);

// Make the current city the home city.
polApp->put_CurrentCityIndex (olHomeCity);

// Release objects.
pFolder->Release ();
polItems->Release ();
pCity->Release ();

The following Visual Basic code does the same thing.

Dim pCity as PocketOutlook.CityItem

' Due to a bug in VBCE, you cannot use the constant olFolderCities.
' Use the constant 101, from the table in the Constants section.
Set pCity = polApp.GetDefaultFolder(101).Items.Find ("[Name] = ""Seattle, WA""")
PolApp.HomeCity = pCity

' The constant olHomeCity is replaced with 0.
PolApp.CurrentCityIndex = 0
