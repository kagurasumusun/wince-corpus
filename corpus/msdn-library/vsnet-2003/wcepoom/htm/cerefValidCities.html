Valid Cities

A user-created City must meet the following requirements.

  • Longitude must be between -18000 and +18000.
  • Latitude must be between -9000 and +9000.
  • TimezoneIndex must correspond to a valid time zone.
  • Name and Country properties must be set.
  • String values must not exceed 256 characters.

It a City does not fulfill these requirements, it will not be saved successfully. Any attempt to set an illegal value for a City will fail.

Remarks

In Pocket Outlook earlier than 1.1, attempting to save changes to a city stored in ROM returns the error code E_CITYINROM.

In Pocket Outlook version 1.1 and later, you can change the properties for any City whether it is stored in RAM or ROM.

You can add or remove Cities stored in RAM.

The World Clock program does not accept City changes while it is running. Attempting to do so returns the error code E_CLOCKRUNNING.
