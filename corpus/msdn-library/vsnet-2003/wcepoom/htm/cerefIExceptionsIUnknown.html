IExceptions:IUnknown

This interface provides a read-only collection of exceptions to a recurring appointment. You can get this collection, valid only for appointments, from the Exceptions property in the IRecurrencePattern object. Add or edit exceptions with the GetOccurrence method in the IRecurrencePattern object.

This interface supports one method.
