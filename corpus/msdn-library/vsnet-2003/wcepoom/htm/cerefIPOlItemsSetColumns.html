IPOlItems::SetColumns

This method lets you retrieve Contacts more quickly by specifying only those properties you want to retrieve. The specified properties are set to their current values, and all other properties are set to NULL.

This method applies only to collections of Contacts.

HRESULT SetColumns(
BSTR Columns
);

Parameters

Columns
[in] A string with the columns you want to retrieve. For example, to retrieve FileAs and BusinessTelephoneNumber, specify "FileAs,BusinessTelephoneNumber".

Return Values

S_OK indicates the string was parsed correctly. If an error occurs, the appropriate HRESULT is returned.

Remarks

Use this method when you want to quickly examine just one or two fields. For example, to examine the FileAs and BusinessTelephoneNumber properties of all Contacts, call SetColumns as follows.

pContacts->SetColumns ("FileAs, BusinessTelephoneNumber")

Then when you use the IPOutlookItemCollection interface method Item to get a contact, it will have only these two properties set.

When using SetColumns, you cannot modify the contacts found with the columns set. Use it when you need to examine or use only a few properties, but need to modify few or none of them.

To modify a contact, you can use IPOutlookApp::GetItemFromOid to get the contact and modify it. (Oid and Application are special properties still available after you call SetColumns.) Alternatively, you can use a second Contact Items collection pointer that has not had SetColumns called on it, and use the Item method on it to get the Contact and modify it.

Example

The following code example shows how to set columns and get a contact.

void FindContact (IPOutlookItemCollection *pContacts)
{
IPOutlookApp *pApplication;
IPOlItems *pContacts2;
IContact *pContact;
long lOid;

pContacts->QueryInterface (IID_IPOlItems, (LPVOID*)&pContacts2);
pContacts2->SetColumns (TEXT ("CompanyName"));

// Put all the companies you have into a list
int numItems;
pContacts2->get_Count (&numItems);
for (i = 1; i <= numItems; i++)
{
// Read the contact
pContacts2->Item (i, (IDispatch**)&pContact);

// Use or manipulate the company name in some way...
// For example, if the company name is Hotmail, change to MSN.
if (IsCompanyHotmail (pContact))  {
   pContact->get_Application (&pApplication);
   pContact->get_Oid (&lOid);
   pApplication->GetItemFromOid (lOid, (IDispatch**)&pContact);
   pContact->put_Company (TEXT("MSN"));
   }
}
\\ Release objects
pApplication->Release ();
pContacts2->Release ();
pContact->Release ();
}
