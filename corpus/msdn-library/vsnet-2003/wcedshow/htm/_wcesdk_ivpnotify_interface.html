IVPNotify Interface

This interface enables you to control the properties of a filter that uses a video port. This interface derives from the IVPBaseNotify interface. See also IVPBaseConfig and IVPConfig.

When to Implement

The Overlay Mixer filter implements this interface so you will not need to implement it in most cases. Implement this interface when you need to alter the default behavior.

When to Use

Use this interface in your application when you need to access video port properties.

Methods in Vtable Order

The following tables show the methods that appear in the Vtable beneath the standard COM methods inherited from IUnknown.
