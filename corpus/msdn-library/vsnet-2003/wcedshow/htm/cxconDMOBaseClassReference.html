DMO Base Class Reference

Microsoft DirectX for Windows CE includes a base-class template for creating DirectX Media Objects (DMOs). You do not have to use the template to create a DMO. However, the template handles various tasks that are common to all DMOs. Using the template, you can focus on the functionality that is specific to your DMO. In addition, the template helps to ensure that you create a robust implementation.
