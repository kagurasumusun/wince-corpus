Supported Audio Codecs and Renderers

The following table shows all the audio codecs and renderers supported by DirectShow on Windows CE.

Feature Function Windows CE version
Audio Renderer A generic audio rendering filter that you can connect to the output of any of the following filters, if they contain WAV audio:
  • File source (Async)
  • File source (URL)
  • MPEG-1 stream splitter
  • AVI splitter
  • WAVE parser
  • Any audio transform filter
 2.12 or later
DirectSound Audio Renderer A generic audio rendering filter that you can connect to the output of any of the following filters, if they contain WAV audio:
  • File Source (Async)
  • File Source (URL)
  • MPEG-1 Stream Splitter
  • AVI Splitter
  • WAVE Parser
  • Any audio transform filter
 2.12 or later
MPEG Audio Decoder The MPEG Audio Decoder filter decompresses MPEG-1 layers 1 and 2 audio data. 2.12 or later
