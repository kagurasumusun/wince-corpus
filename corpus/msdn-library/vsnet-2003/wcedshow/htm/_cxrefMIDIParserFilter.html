MIDI Parser Filter

The MIDI Parser filter reads MIDI data that is found in .mid and .rmi files. The filter accepts a stream from the file source (async) filter or file source (URL) filter and outputs MIDI samples to the MIDI renderer for playback.

The following table shows the filter properties.

Filter property Description
Filter Interfaces IBaseFilter, IAMMediaContent
Input Pin Media Types MEDIATYPE_Stream, MEDIASUBTYPE_Midi
Input Pin Interfaces IPin, IQualityControl
Output Pin Media Types MEDIATYPE_Midi, MEDIASUBTYPE_NULL
Output Pin Interfaces IMediaSeeking, IQualityControl, IPin
Filter CLSID CLSID_MIDIParser
Executable Quartz.dll
Merit MERIT_UNLIKELY
Category CLSID_LegacyAmFilterCategory

Remarks

For more information, see MIDI renderer.
