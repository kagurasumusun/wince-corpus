IAMPlayListItem Interface

This interface provides the detailed property information for an item in a playlist.

Methods in Vtable Order

The following table shows the methods that appear in the Vtable beneath the standard COM methods inherited from IUnknown.

Method Description
IAMPlayListItem::GetFlags Returns properties for an item in the playlist.
IAMPlayListItem::GetSourceCount Returns the number of sources for an item in a playlist.
IAMPlayListItem::GetSourceURL Returns the URL of a specified source for an item in a playlist.
IAMPlayListItem::GetSourceStart Returns the starting time of a source for an item in a playlist.
IAMPlayListItem::GetSourceDuration Returns the duration time of a source for an item in a playlist.
IAMPlayListItem::GetSourceStartMarker Returns the start marker of a source for an item in a playlist.
IAMPlayListItem::GetSourceEndMarker Returns the end marker of a source for an item in a playlist.
IAMPlayListItem::GetSourceStartMarkerName Returns the name of the start marker of a source for an item in a playlist.
IAMPlayListItem::GetSourceEndMarkerName Returns the name of the end marker of a source for an item in a playlist.
IAMPlayListItem::GetLinkURL Returns the link URL for an item in a playlist.
IAMPlayListItem::GetScanDuration Returns the scan duration of a source for an item in a playlist.
