IAMPlayList::GetNamedEvent

This method retrieves the item on the playlist that is associated with a given event for a specified item on the playlist.

HRESULT GetNamedEvent(
WCHAR pwszEventName,
DWORD dwItemIndex,
IAMPlayListItem **ppItem,
DWORD *pdwFlags
);

Parameters

pwszEventName
[in] Pointer to a named event.
dwItemIndex
[in] Index number of the specified playlist item.
ppItem
[out] Pointer to an IAMPlayListItem interface pointer corresponding to the playlist item that the dwItemIndex playlist item associates with the pwszEventName event.
pdwFlags
[out] Flags for the ppItem playlist item.

Return Values

Returns an HRESULT value.
