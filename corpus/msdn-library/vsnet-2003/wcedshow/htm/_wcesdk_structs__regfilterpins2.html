REGFILTERPINS2

This structure contains information for registering a filter through the IFilterMapper2 interface. 

typedef struct {
DWORD dwFlags;
UINT cInstances;
UINT nMediaTypes; 
const REGPINTYPES *lpMediaType; 
UINT nMediums;
const REGPINMEDIUM *lpMedium;
const CLSID *clsPinCategory;
} REGFILTERPINS2;

Members

dwFlags
Combination of REG_PINFLAG flags.
cInstances
Number of instances of the pin, if known.
nMediaTypes
Number of media types supported by this pin.
lpMediaType
Array of nMediaTypes REGPINTYPES providing media type information.
nMediums
Number of mediums.
lpMedium
Array of REGPINMEDIUM containing medium information for each pin.
clsPinCategory
Pin category (for kernel streaming pins) as defined in the Windows NT® DDK.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements. See Setting Up the Build Environment for more information.

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 or later. Version 2.12 requires DXPAK 1.0 or later.   Dshow.h
