QuickTime Decompressor

The QuickTime Decompressor filter decompresses Apple QuickTime 2.0 video. This format is typically used in older QuickTime files.

The following table shows the decompressor properties.

Decompressor property Description
Filter Interfaces IBaseFilter
Input Pin Media Types MEDIATYPE_Video, FORMAT_VideoInfo

The following subtypes are valid:

  • MEDIASUBTYPE_QTRpza
  • MEDIASUBTYPE_QTSmc
  • MEDIASUBTYPE_QTRle
  • MEDIASUBTYPE_QTJpeg
Input Pin Interfaces IMemInputPin, IPin, IQualityControl
Output Pin Media Types MEDIATYPE_Video, MEDIASUBTYPE_NULL, FORMAT_VideoInfo
Output Pin Interfaces IMediaPosition, IMediaSeeking, IPin, IQualityControl
Filter CLSID CLSID_QTDec
Executable Quartz.dll
Merit MERIT_NORMAL
Category CLSID_LegacyAmFilterCategory
