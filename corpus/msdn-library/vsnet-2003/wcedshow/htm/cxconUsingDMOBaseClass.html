Using the DMO Base Class

The Microsoft DirectX for Windows CE software development kit (SDK) includes a base-class template for creating DMOs, IMediaObjectImpl. You do not have to use the class template when you create a DMO, as long as your DMO fully supports the IUnknown and IMediaObject interfaces. However, the class template provided by Microsoft handles many of the bookkeeping tasks, such as validating input parameters. By using the template, you can focus on the functionality that is specific to your DMO. In addition, the template helps to ensure that you create a robust implementation.
