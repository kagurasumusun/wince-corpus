IVideoWindow::put_WindowState

This method sets the video window's state. 

HRESULT put_WindowState(
long WindowState
);

Parameters

WindowState
[in] Describes the video window's state.

Return Values

Returns NOERROR.

Remarks

This method is a wrapper for the Win32 ShowWindow function. IVideoWindow::put_WindowState passes the WindowState parameter on to CBaseWindow::DoShowWindow, which in turn passes it on to ShowWindow. Hence, WindowState can be any value that is valid for ShowWindow.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements. See Setting Up the Build Environment for more information.

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 or later. Version 2.12 requires DXPAK 1.0 or later.
