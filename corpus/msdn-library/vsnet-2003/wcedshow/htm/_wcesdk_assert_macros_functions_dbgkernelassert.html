DbgKernelAssert

This function is called in a debug build to print the condition onto the kernel debugger, including the condition text, source file name, and source line number. 

void WINAPI DbgKernelAssert(
const TCHAR *pCondition,
const TCHAR *pFileName,
INT iLine
);

Parameters

pCondition
Pointer to a string version of a Boolean expression.
pFileName
Pointer to a source file name.
iLine
Line number within the source file.

Remarks

This function is available only in a debug build. Usually, DbgKernelAssert is called by macros, not directly from other code.

Unlike DbgAssert, when macros call DbgKernelAssert in a debug build, no message box appears.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements. See Setting Up the Build Environment for more information.

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 or later. Version 2.12 requires DXPAK 1.0 or later.
