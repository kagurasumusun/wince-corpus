FILTER_INFO

This structure contains information about a filter.

typedef struct  _FilterInfo{
WCHAR achName[ 128 ];
IFilterGraph __RPC_FAR *pGraph;
}     FILTER_INFO;

Members

achName
Name of the filter.
pGraph
Pointer to the IFilterGraph interface to which the filter is connected.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements. See Setting Up the Build Environment for more information.

Runs on Versions Defined in Include Link to
Windows CE OS 2.12 or later. Version 2.12 requires DXPAK 1.0 or later.   Dshow.h
