IAMPlayListItem::GetSourceEndMarkerName

This method returns the name of the end marker of a source for an item in a playlist.

HRESULT GetSourceEndMarkerName(
DWORD dwSourceIndex,
BSTR *pbstrEndMarker
);

Parameters

dwSourceIndex
[in] Identifies a specific source for an item in a playlist.
pbstrEndMarker
[out] Pointer to the end marker name for the source identified by dwSourceIndex.

Return Values

Returns an HRESULT value.

Remarks

You can use IAMPlayListItem::GetSourceCount to determine how many sources an item has.

Requirements
