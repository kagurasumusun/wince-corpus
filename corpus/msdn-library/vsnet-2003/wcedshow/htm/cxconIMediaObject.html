IMediaObject

This interface provides methods for manipulating a Microsoft DirectX Media Object (DMO).

The following table shows the methods for IMediaObject in the order the compiler calls them.

Method Description
IMediaObject::GetStreamCount Retrieves the number of input and output streams.
IMediaObject::GetInputStreamInfo Retrieves information about a specified input stream.
IMediaObject::GetOutputStreamInfo Retrieves information about a specified output stream.
IMediaObject::GetInputType Retrieves a preferred media type for a specified input stream.
IMediaObject::GetOutputType Retrieves a preferred media type for a specified output stream.
IMediaObject::SetInputType Sets the media type on an input stream or tests whether a particular media type is acceptable.
IMediaObject::SetOutputType Sets the media type on an output stream or tests whether a particular media type is acceptable.
IMediaObject::GetInputCurrentType Retrieves the media type that was previously set for an input stream, if any.
IMediaObject::GetOutputCurrentType Retrieves the media type that was previously set for an output stream, if any.
IMediaObject::GetInputSizeInfo Retrieves the buffer requirements for a specified input stream.
IMediaObject::GetOutputSizeInfo Retrieves the buffer requirements for a specified output stream.
IMediaObject::GetInputMaxLatency Retrieves the maximum latency on a specified input stream.
IMediaObject::SetInputMaxLatency Sets the maximum latency on a specified input stream.
IMediaObject::Flush Flushes all internally buffered data.
IMediaObject::Discontinuity Signals a discontinuity on the specified input stream.
IMediaObject::AllocateStreamingResources Allocates any resources needed by the DMO.
IMediaObject::FreeStreamingResources Frees resources allocated by the DMO.
IMediaObject::GetInputStatus Queries whether a specified input stream can accept more input data.
IMediaObject::ProcessInput Delivers a buffer to the specified input stream.
IMediaObject::ProcessOutput Generates output from the current input data.
IMediaObject::Lock Acquires or releases a lock on the DMO.

The IMediaObject interface, like all COM interfaces, inherits the IUnknown interface methods. The IUnknown interface supports the following three methods:

  • AddRef
  • QueryInterface
  • Release
