MoDeleteMediaType

This function deletes a media type structure that was previously allocated.

HRESULT MoDeleteMediaType(
    DMO_MEDIA_TYPE *pmt
);

Parameters

pmt
Pointer to an initialized DMO_MEDIA_TYPE structure.

Return Values

Returns an HRESULT value. Possible values include the following.

Value Description
S_OK Success
E_POINTER NULL pointer argument

Remarks

This function frees the allocated members of the media type structure by calling MoFreeMediaType and then it frees the media type structure itself.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.1 and later Dmort.h Dmo.h
