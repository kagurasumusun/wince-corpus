Object Register Debugging

The CBaseObject class is at the root of all DirectShow base classes. It maintains the object register, which is the list of objects (in those classes) that have been created but not yet destroyed. It exists primarily to provide debugging assistance by keeping a count of all active DirectShow objects. All base class constructors in derived base classes provide a debugging object name as the first parameter and call the CBaseObject constructor. You can view the debugging object name sent to this base class on a debugging monitor.

Function Description
DbgDumpObjectRegister Displays details about all objects in the object register.
