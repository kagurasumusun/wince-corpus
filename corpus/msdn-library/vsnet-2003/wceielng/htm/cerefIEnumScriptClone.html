IEnumScript::Clone

This method clones the enumeration object.

HRESULT Clone( 
IEnumScript **ppEnum
);

Parameters

ppEnum
[out] Address of a pointer that received the IEnumScript interface of the cloned enumeration object.

Return Values

Returns S_OK if successful, otherwise returns an error value.
