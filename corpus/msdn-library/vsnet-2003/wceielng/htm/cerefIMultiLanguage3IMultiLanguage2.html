IMultiLanguage3:IMultiLanguage2

This interface extends IMultiLanguage2 by adding outbound text detection functionality to it.

Method Description
DetectOutboundCodePage Detects the encoding of outbound Unicode text.
DetectOutboundCodePageInIStream Detects the encoding of outbound Unicode text. This method resembles IMultiLanguage3::DetectOutboundCodePage, except that the source text is in an IStream object.

Remarks

This interface is used by applications such as Microsoft® Outlook® to detect the encoding of outbound messages. Unicode text messages are parsed and the most appropriate encoding is returned.
