IMultiLanguage2::GetRfc1766Info

This method retrieves an RFC1766INFO structure that corresponds to the given locale identifier (LCID) value.

HRESULT GetRfc1766Info( 
LCID Locale,
LANGID LangId,
PRFC1766INFO pRfc1766Info
);

Parameters

Locale
[in] Locale identifier that specifies the locale.
LangId
[in] LANGID that specifies the language.
pRfc1766Info
[out] Pointer to the RFC1766INFO structure that receives the information.

Return Values

The following table shows the possible return values.

Value Description
S_OK Success.
E_FAIL The method could not get the information from the database or the system.
E_POINTER An invalid pointer was specified.
E_INVALIDARG One or more arguments are invalid.
