Internet Explorer Multiple-Language API

The global scope of the Internet poses a variety of international and multilingual challenges for Web developers. The Multiple-Language application programming interface (API) (MLang) addresses these issues by providing:

  • Code page and locale enumeration from the Multipurpose Internet Mail Extensions (MIME) database.
  • Code page, locale, and character set information retrieval.
  • Code page, string, and character set conversions.
  • Code page, locale, and string detection methods.
  • Font linking to merge characters from different character sets.
  • Locale-aware line breaking for console-based applications.

The MLang API topics provide an overview of MLang functionality and its objects, interfaces, and methods. Knowledge of Component Object Model (COM) programming is assumed. For more information about using the MLang API, see this Microsoft Web site.
