IEnumRfc1766::Reset

This method resets the Locale Enumeration object to the beginning of the enumeration sequence. 

HRESULT Reset(void);

Parameters

None.

Return Values

Returns NOERROR.

The following example shows the syntax for retrieving 10 RFC1766INFO structures from the middle of the enumeration sequence. Then, using the IEnumRfc1766::Reset function, it retrieves the first 10 structures. 

pMultiLanguage->EnumRfc1766(&pEnumRfc1766);
PRFC1766INFO pcpInfo;
ULONG ccpInfo;
pcpInfo=(PRFC1766INFO)CoTaskMemAlloc(sizeof(RFC1766INFO)*10);
pEnumRfc1766->Skip(6);
pEnumRfc1766->Next(10, pcpInfo, &ccpInfo);
// Use the information returned about these 10 locales.
pEnumRfc1766->Reset();
pEnumRfc1766->Next(10, pcpInfo, &ccpInfo);
// Use the information returned about the first 10.
CoTaskMemRealloc((void*)pcpInfo, sizeof(RFC1766INFO)*ccpInfo);
