IMultiLanguage2::SetMimeDBSource

This method sets the MIME database to be used by MLang.

HRESULT SetMimeDBSource( 
MIMECONTF dwSource
);

Parameters

dwSource
[in] MIMECONTF value that indicates which MIME database to use. This can be one of the following values:
  • MIMECONTF_MIME_IE4
  • MIMECONTF_MIME_LATEST
  • MIMECONTF_MIME_REGISTRY

Return Values

Returns S_OK if successful or an error value otherwise.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Mlang.idl Mlang.h Mlang.dll
