IMultiLanguage::GetCodePageInfo

This method retrieves the MIMECPINFO structure corresponding to the code page specified in uiCodePage. 

HRESULT GetCodePageInfo( 
UINT uiCodePage,
PMIMECPINFO pCodePageInfo
);

Parameters

uiCodePage
[in] Code page identifier value for which the caller wants to retrieve the information.
pCodePageInfo
[out] Address of the buffer to receive a MIMECPINFO structure corresponding to uiCodePage.

Return Values

Returns S_OK if successful or E_FAIL if either of the arguments is invalid or if the information is not found for the required code page.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Mlang.idl Mlang.h Mlang.dll
