IMultiLanguage2::GetCodePageDescription

This method retrieves the code page description that corresponds to uiCodePage. 

HRESULT GetCodePageDescription( 
UINT uiCodePage,
LCID lcid,
LPWSTR lpWideCharStr,
int cchWideChar
);

Parameters

uiCodePage
[in] Code page identifier value for which the caller wants the information.
lcid
[in] Local language identifier (LCID) that specifies the user-preferred language.
lpWideCharStr
[in, out] Pointer to a Unicode character string for which the client is requesting the code page description.
cchWideChar
[in] Value indicating the number of characters in lpWideCharStr.

Return Values

The following table shows the possible return values.

Value Description
S_OK Success.
S_FALSE The method cannot validate the code page.
E_FAIL An error occurred.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Mlang.idl Mlang.h Mlang.dll
