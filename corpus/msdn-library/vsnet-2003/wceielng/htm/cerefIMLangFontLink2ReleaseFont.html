IMLangFontLink2::ReleaseFont

This method releases a font object created by the IMLangFontLink2::MapFont method.

HRESULT ReleaseFont( 
HFONT hFont
);

Parameters

hFont
[in] Handle to the font object to be deleted.

Return Values

Returns S_OK if successful or E_FAIL otherwise.
