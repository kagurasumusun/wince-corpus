Internet Protocols

The MLang API uses the Multipurpose Internet Mail Extensions (MIME) and RFC1766 protocols. The MIME protocol, documented in RFC 1521 and RFC 1522, defines the representation for complex message bodies. A complex message body is any mail message other than a simple ASCII mail message, for example a message with a file attachment, or an embedded object, or a message sent in Japanese.

The RFC 1766 protocol describes a language tag that indicates the language used in an information object, how to register values for use in the language tag, and a construct for matching such language tags.

For more information about these protocols, see the request for comments (RFC) documents for their specifications. These documents are available at the Internet Engineering Task Force Web site.
