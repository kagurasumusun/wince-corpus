MLDETECTCP

This enumerated type is used with the code page detection methods IMultiLanguage2::DetectInputCodepage and IMultiLanguage2::DetectCodepageInIStream to specify the type of the incoming data. 

typedef enum tagMLDETECTCP {
    MLDETECTCP_NONE = 0,
    MLDETECTCP_7BIT = 1,
    MLDETECTCP_8BIT = 2,
    MLDETECTCP_DBCS = 4,
    MLDETECTCP_HTML = 8
} MLDETECTCP;

Constants

MLDETECTCP_NONE
Default setting will be used.
MLDETECTCP_7BIT
Input stream consists of 7-bit data.
MLDETECTCP_8BIT
Input stream consists of 8-bit data.
MLDETECTCP_DBCS
Input stream consists of double-byte data.
MLDETECTCP_HTML
Input stream is an HTML page.

Requirements
