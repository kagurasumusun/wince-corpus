Working with Sound

Adding sound to an application can make the application more efficient to use. By using sounds to draw attention at critical points, you can help users avoid mistakes and notify them when a time-consuming operation concludes. This section describes two different ways to play sound in an application. The first part of this section describes how to use the PlaySound function. PlaySound provides all of the capabilities that are necessary for playing waveform audio sounds on a Windows CE–based device. The latter part of this section describes how to use the Waveform Audio application programming interface (API). This interface gives an application exact control over waveform audio input/output (I/O) devices.
