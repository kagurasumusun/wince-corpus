ISAXLexicalHandler::comment Method

Receives XML comments from either inside or outside the document element, including comments in the external document type definition (DTD) or schema subset.

Comments in the DTD must be properly nested inside startDTD/endDTD and startEntity/endEntity events (if used). Note that XML comments use the familiar HTML comment notation as the following code sample shows.

<!-- comments go here. --> 

HRESULT comment(
const wchar_t *pwchChars,
int cchChars
);

Parameters

pwchChars
[in] The comment data.
cchChars
[in] The length of the comment string.

Return Values

S_OK
Returned if the comment data is returned successfully.
E_FAIL
Returned if the parse operation should be aborted.

Requirements

Windows CE OS .NET 4.0 and later Msxml2.idl Msxml2.h Uuid.lib
