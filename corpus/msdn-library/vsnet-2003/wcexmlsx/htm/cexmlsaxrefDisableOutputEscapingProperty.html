disableOutputEscaping Property

Matches the disable-output-escaping attribute of <xsl:text> and <xsl:value-of> elements. For example, typical escaped built-in entities such as "&amp;" for "&" are put through literally.

[propput]
HRESULT disableOutputEscaping(
[in] VARIANT_BOOL fValue
);
[propget]
HRESULT disableOutputEscaping(
[out, retval] VARIANT_BOOL *fValue
);

Parameters

fValue
A Boolean expression (True/False) specifying whether the feature is on or off.

Remarks

If this property is set to True, the XML output will not be well-formed or valid.

Value Description
True Writer cannot escape input when writing output.
False (default) Writer should escape input when writing output.

Return Values

S_OK
Returned if no errors are reported.
