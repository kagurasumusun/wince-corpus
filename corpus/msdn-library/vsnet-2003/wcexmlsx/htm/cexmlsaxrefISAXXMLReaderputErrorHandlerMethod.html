ISAXXMLReader::putErrorHandler Method

Allows an application to register an ErrorHandler. If the application does not register an ErrorHandler, all error events reported by the reader are ignored. It is strongly recommended that all SAX2 (Simple API for XML) applications implement an ErrorHandler to avoid unexpected bugs. An application can register a new or different handler while in the middle of parsing a document, and the reader will immediately start using the new handler.

ISAXErrorHandler *pHandler
);

Parameters

pHandler

Return Values

S_OK
Returned if the ErrorHandler is successfully registered.
