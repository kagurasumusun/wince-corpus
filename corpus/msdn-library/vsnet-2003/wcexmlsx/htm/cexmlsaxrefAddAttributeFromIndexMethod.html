addAttributeFromIndex Method

Adds an attribute, whose value is equal to the indexed attribute in the input attributes object, to the end of the list.

HRESULT addAttributeFromIndex(
VARIANT varAtts,
int nIndex
);

Parameters

varAtts
[in] The variant type.
nIndex
[in] The attribute's index value.

Return Values

S_OK
Returned if no errors are reported.
E_FAIL
Returned if index is out of range.
