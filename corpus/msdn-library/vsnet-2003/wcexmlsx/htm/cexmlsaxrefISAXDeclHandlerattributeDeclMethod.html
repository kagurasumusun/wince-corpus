ISAXDeclHandler::attributeDecl Method

Reports an attribute type declaration. Only the first declaration for an attribute is reported. The attribute type can be either of the following two choices:

  • One of the following strings: "CDATA", "ID", "IDREF", "IDREFS", "NMTOKEN", "NMTOKENS", "ENTITY", "ENTITIES", or "NOTATION".
  • A parenthesized token group with the separator (|) and all white space removed.

Parameters

pwchElementName
[in] The name of the associated element.
cchElementName
[in] The length of the element's name string.
pwchAttributeName
[in] The name of the attribute.
cchAttributeName
[in] The length of the attribute's name string.
pwchType
[in] A string representing the attribute type.
cchType
[in] The length of the attribute-type string.
pwchValueDefault
[in] A string representing the attribute default ("#IMPLIED", "#REQUIRED" or "#FIXED") or Null (if none of these apply).
cchValueDefault
[in] The length of the attribute's default string.
pwchValue
[in] A string representing the attribute's default value or Null (if there is none).
cchValue
[in] The length of the attribute's default value.

Return Values

S_OK
Returned if no errors are reported.
E_FAIL
The parse operation should be aborted.
