IMXReaderControl:IDispatch

The IMXReaderControl interface provides limited control of reader behavior. Specifically, it allows a Simple API for XML (SAX2) application to abort, suspend, or resume parsing. Note that this interface is not standard. If you use this feature, you may not be able to migrate your program logic to other SAX implementations. This interface is targeted to applications that require a low-level parser API.

Method Description
abort Stops the parsing operation.
resume Resumes parsing after the reader has been suspended.
suspend Suspends parsing and returns control to the application.
