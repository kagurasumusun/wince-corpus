byteOrderMark Property

Determines whether or not to write the Byte Order Mark (BOM).

Setting this property to True makes MXXMLWriter follow XML 1.0 specifications and output BOM for appropriate encoding. Setting it to False prohibits MXXMLWriter from putting BOM into the resulting XML document.

You can use this property to output fragments of larger XML documents that can be assembled into a single XML document later.

[proput]
HRESULT byteOrderMark (
[in] VARIANT_BOOL fWriteByteOrderMark
);
[propget]
HRESULT byteOrderMark (
[out, retval] VARIANT_BOOL *fWriteByteOrderMark
);

Parameters

fWriteByteOrderMark
A Boolean expression (True/False) specifying whether the feature is on or off.

Remarks

The default of this property is dependent on implementation. MXXMLWriter never outputs BOM if the output is set to a string.

Value Description
True MXMXLWriter follows XML 1.0 specifications and outputs BOM for encoding.
False MXMXLWriter is prohibited from putting BOM into the resulting XML document.

Return Values

S_OK
Returned if no errors are reported.
