output Property

Determines the output for MXXMLWriter. By default, the output property is a BSTR (string) value. You can also set this property to any implementation of the IStream interface, and the resulting document will be written into the provided IStream. Setting this property to the empty value (VT_EMPTY or " ") will return output to the internal string and reset it.

When this property is accessed, the output should be flushed. For more information, see flush Method.

The output property can be set to affect only the destination itself. For example, you can get generated XML file in chunks by getting the next portion from the output property and then resetting it to an empty value.

[propput]
HRESULT output(
[in] VARIANT varDestination
);
[propget]
HRESULT output(
[out, retval] VARIANT *varDestination
);

Parameters

varDestination
Variant destination.

Remarks

The default is VT_EMPTY to output to string.

Return Values

S_OK
Returned if no errors are reported.
