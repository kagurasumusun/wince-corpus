ISAXAttributes::getName Method

Returns all information related to the name of an attribute at a given index. Each return string can be disabled by passing Null in for the text out parameter.

HRESULT getName(
int nIndex, 
const wchar_t **ppwchUri, 
int *pcchUri,
const wchar_t **ppwchLocalName,
int *pcchLocalName,
const wchar_t **ppwchQName,
int *pcchQName
);

Parameters

nIndex
[in] The attribute's index value.
ppwchUri
[out] The attribute's URI.
pcchUri
[out] The length of the URI string.
ppwchLocalName
[out] The attribute's local name.
pcchLocalName
[out] The length of the local name string.
ppwchQName
[out] The qualified prefixed name of the attribute.
pcchQName
[out] The length of the qualified name string.

Return Values

S_OK
Returned if successful.
E_FAIL
Returned if an internal error occurs.
E_INVALIDARG
Returned if an invalid index is provided.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Msxml2.idl Msxml2.h Uuid.lib
