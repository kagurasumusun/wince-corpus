ISAXLocator::getColumnNumber Method

Returns the column number where the current document event ends.

Note that this is the number of the first character after the text associated with the document event. The getColumnNumber method is permitted to show position within the text associated with the text event.

HRESULT getColumnNumber(
int *pnColumn
);

Parameters

pnColumn
[out, retval] The column number (the first column in a line is #1). The pnColumn is –1 if the Locator object is not associated with some source input or a position within the source input.

Return Values

S_OK
Returned if column number returned successfully.
