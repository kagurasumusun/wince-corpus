ISAXLexicalHandler::startCDATA Method

Receives the beginning of a character data (CDATA) section. The contents of the CDATA section are reported through the regular characters event. The startCDATA event reports only the end boundary of the CDATA section.

A CDATA section provides a way to include characters such as "<", ">", and "&" in an XML document that would typically interfere with processing. The following code sample shows a CDATA section.

<![CDATA[text goes here]]>.

HRESULT startCDATA();

Parameters

None.

Return Values

S_OK
Returned if successful.
E_FAIL
Returned if the parse operation should be aborted.
