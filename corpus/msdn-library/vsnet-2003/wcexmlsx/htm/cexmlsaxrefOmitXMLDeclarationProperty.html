omitXMLDeclaration Property

Forces the MXXMLWriter to skip the XML declaration. It can be used to output fragments of larger XML documents that can be assembled into a single XML document later.

[propput]
HRESULT omitXMLDeclaration (
[in] VARIANT_BOOL fValue
);
[propget]
HRESULT omitXMLDeclaration (
[out, retval] VARIANT_BOOL *fValue
);

Parameters

fValue
A Boolean expression (True/False) specifying whether the feature is on or off.

Remarks

Value Description
True Omit XML declaration.
False (default) Provide XML declaration.

Return Values

S_OK
Returned if no errors are reported.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Msxml2.idl Msxml2.h Uuid.lib
