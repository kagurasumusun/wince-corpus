ISAXAttributes::getQName Method

Finds an attribute's qualified name by index. For the xmlns name space, the qname value is empty.

HRESULT getQName(
int nIndex, 
const wchar_t **ppwchQName, 
int *ppchQName
);

Parameters

nIndex
[in] The attribute's index value.
ppwchQName
[out] The attribute's qualified name.
ppchQName
[out] The length of the qualified name string or –1 (if zero-terminated).

Return Values

S_OK
Returned if the qualified name (QName) is returned successfully.
E_FAIL
Returned if an internal error is reported.
E_INVALIDARG
Returned if QName is not found.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Msxml2.idl Msxml2.h Uuid.lib
