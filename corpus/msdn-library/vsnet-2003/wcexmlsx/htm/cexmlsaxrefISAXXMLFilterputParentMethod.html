ISAXXMLFilter::putParent Method

Sets the parent of the filter to an instance of ISAXXMLReader.

HRESULT putParent(
ISAXXMLReader *pReader
);

Parameters

pReader
[in] The instance of the ISAXXMLReader to use as the parent.

Remarks

This method allows the application to link the filter to a parent reader (which may be another filter). The argument may not be Null.

Return Values

S_OK
Returned when the instance of ISAXXMLReader is set as expected.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Msxml2.idl Msxml2.h Uuid.lib
