ISAXDeclHandler::externalEntityDecl Method

Reports a parsed external entity declaration. Only the first declaration for each entity is reported.

HRESULT externalEntityDecl(
const wchar_t *pwchName,
int cchName,
const wchar_t *pwchPublicId,
int cchPublicId,
const wchar_t pwchSystemId,
int cchSystemId
);

Parameters

pwchName
[in] The name of the entity. If it is a parameter entity, the name begins with a "%".
cchName
[in] The length of the entity's name string.
pwchPublicId
[in] The declared public identifier of the entity or Null (if none is declared).
cchPublicId
[in] The length of the public identifier string.
pwchSystemId
[in] The declared system identifier of the entity.
cchSystemId
[in] The length of the system identifier string.

Return Values

S_OK
Returned if no errors reported.
E_FAIL
Returned if the parse operation should be aborted.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Msxml2.idl Msxml2.h Uuid.lib
