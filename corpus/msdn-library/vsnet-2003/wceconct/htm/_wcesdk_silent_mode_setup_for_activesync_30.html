Silent Mode Setup for ActiveSync 3.0

In a corporate environment, system administrators often need to be able to install applications in specific configurations, such as in a particular directory. In these circumstances, many administrators may want a setup program that does not require user intervention. The Setup program for ActiveSync 3.0 provides these capabilities through a feature called Silent Mode Setup. Silent mode setup includes the following features:

  • Can be run by a single command, without any further user interaction.
  • Supports SMS 1.2 and 2.0
  • Supports both new installations and upgrades from previous versions of WCES.
  • Can use a configuration file so that the setup process can be pre-configured.
  • Supports status and error logging.
  • Configuration file can be located anywhere on the local machine or on the network.

However, ActiveSync 3.0 setup also contains the following limitations:

  • Other applications on the ActiveSync 3.0 CD are not supported in Silent Mode.
  • Uninstall for ActiveSync 3.0 does not support Silent Mode: that is, there is no Silent Uninstall.
  • If you installed a previous version of WCES using the unattended installation feature, the scripts you used previously are not compatible with ActiveSync 3.0 Silent Mode Setup.
  • If you are using SMS, the SMS version number must be 1.2 (with SMS Service Pack 3) or higher.
  • If using SMS 1.2, user systems running Windows 9x must have the user logged off before Setup.
  • If using SMS 1.2, user systems running Windows NT must have the user logged on before Setup.
    Note   Microsoft System Management Server (SMS) is not required to run ActiveSync 3.0 Silent Mode Setup.

This section describes how to run ActiveSync Setup in Silent Mode from the command line, how to run Silent Mode using SMS, and how to create a silent mode .ini file.
