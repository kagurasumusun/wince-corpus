Running ActiveSync 3.0 Silent Mode Setup Using SMS

To run ActiveSync 3.0 in Silent Mode using SMS

  1. Ensure that the minimum system requirements are met.
  2. Modify the Silent.ini file templates as needed.
  3. Make sure you have all the files in the Main directory on the ActiveSync CD.
  4. Create an SMS package, using the directory from Step 3 as the source.
  5. Run setup.exe on the target machine with the desired arguments.

    Consult your SMS documentation for details on configuring the SMS package to run setup.exe on a target machine with the desired arguments, and distributing the package to your users. For SMS 1.2, read your documentation on Service Pack 3 about unattended installation on a Windows NT machine running SMS's PCMSERVICE.)

Setup places the wcesetup.log file in the directory where Setup installed the ActiveSync application, or in the %tmp% directory if setup is unsuccessful. For more information on interpreting the wcesetup.log file, see Detecting a Successful Setup.

If you have any other changes necessary to customize the ActiveSync setup, you can run the changes after setup is complete.
