Microsoft Windows CE 3.0  

Managing Connection Notifications, File Converters, and Partnerships

This section provides information on methods and tools that you can use to manage aspects of a connection partnership between a Microsoft Windows CE–based device and its companion Windows-based desktop computer. This section includes:

  • Handling a Connection Notification, which explains how to launch applications automatically when a device is connected to or disconnected from the desktop computer by using either registry-based or COM interface–based notification.
  • Transferring Files, which describes how to register file types; how to register, implement, and use a file filter; and how to implement a dummy file filter for transferring and converting data.
  • Using the CEUTIL Helper DLL for ActiveSync, which explains how to use the CEUTIL utility to manage registry entries for ActiveSync and to gain access to device partnerships.
