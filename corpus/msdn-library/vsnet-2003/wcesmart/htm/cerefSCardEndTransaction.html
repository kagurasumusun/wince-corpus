SCardEndTransaction

This function completes a previously declared transaction, enabling other applications to resume interactions with the card.

LONG SCardEndTransaction(
IN SCARDHANDLE hCard, 
IN DWORD dwDisposition 
);

Parameters

hCard
Handle to the reference value obtained from a previous call to SCardConnect.
dwDisposition
Specifies what to do with the card in the connected reader on close. The following table shows the possible values for dwDisposition.
Value Description
SCARD_LEAVE_CARD Do not do anything special.
SCARD_RESET_CARD Reset the card.
SCARD_UNPOWER_CARD Power down the card.
SCARD_EJECT_CARD Eject the card.

Return Values

The following table shows the possible return values.

Value Description
SCARD_S_SUCCESS Succeeds
An error value (see Smart Card Error Values for a list of all error values). Fails

Remarks

SCardEndTransaction is a smart card and reader access function.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 3.0 and later Winscard.h   Winscard.lib
