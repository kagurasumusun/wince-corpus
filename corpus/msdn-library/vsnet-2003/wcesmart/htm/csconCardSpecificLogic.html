Card Specific Properties

The following table shows the card specific properties for the Smart Card CSP for Windows CE.

Property Description
KP_CERTIFICATE A DER-encoded X.509 certificate. The public key in the certificate must match with the corresponding signature or exchange key.
KP_KEYEXCHANGE_PIN A NULL-terminated ASCII string that sets the password used to enable the private key for the key exchange.
KP_SIGNATURE_PIN A NULL-terminated ASCII string that sets the password used to enable the signature private key.
