IOleControlNavigation2:IUnknown

This interface provides methods that support television-style (five-key) navigation in a browser-based application.

The IOleControlNavigation2 interface exposes the following methods.

Method Description
GetControlNavigationCapabilities Determines the capabilities of the navigation control.
GetNavigationRectCount Determines the number of navigational rectangles in the navigation control.
GetNavigationRects Passes the list of the navigation rectangles to the browser.
ActivateRect Activates the navigation rectangle when it receives focus.
DeactivateRect Deactivates the navigation rectangle when focus is removed.
GetCurrentRectIndex Returns the index of the current rectangle.
NavigateInControl Notifies the Navigation control that it is handling navigation.
