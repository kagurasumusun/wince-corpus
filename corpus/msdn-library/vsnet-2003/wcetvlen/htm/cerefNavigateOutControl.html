NavigateOutControl

Notifies the browser when the user tries to navigate outside the bounds of the control. 

HRESULT STDMETHODCALLTYPE  NavigateOutControl( 
RECT currentRect, 
NVFOCUS_DIRECTION direction
);

Parameters

[in]currentRect
The current FocusRect within the control.
[in]direction
The direction used to exit the control, as enumerated in NVFOCUS_DIRECTION. Note that FOCUS_NONE has no effect, because it is not valid in this context.

Return Values

S_OK indicates success.

S_FALSE indicates that the focus must stay inside the control.

Remarks

The browser uses the currentRect parameter to determine where to move the focus outside of the control. If there is nowhere to navigate outside of the control, then S_FALSE is returned and the focus must stay within the control.
