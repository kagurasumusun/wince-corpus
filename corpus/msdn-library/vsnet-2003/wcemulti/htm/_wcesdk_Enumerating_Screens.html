Enumerating Screens

To enumerate the screens that intersect a clipping region, call the EnumDisplayMonitors function. This function returns the HMONITOR handle for each screen, which you can use when calling the GetMonitorInfo function.

To enumerate all the screens covered by the virtual screen, call EnumDisplayMonitors with the hdc and lprcClip parameters set to NULL. The following code example shows how to enumerate all the screens covered by the virtual screen.

EnumDisplayMonitors(NULL, NULL, MyInfoEnumProc, 0);
