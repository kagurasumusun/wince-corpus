TIME

This command displays or sets the system time.

TIME [/T] [time]

Parameters

/T
Displays the current time, without prompting for a new time.
time
Specifies the new time.

Remarks

If you enter the TIME command without any parameters, the command processor shell displays the current time and prompts for a new one. Press the ENTER key if you do not want to change the time.
