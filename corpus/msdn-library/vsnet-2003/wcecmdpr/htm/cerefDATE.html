DATE

This command displays or sets the date.

DATE [\TT] [date]

Parameters

\TT
Specifies that the DATE command should output the current date without prompting for a new date.
date
Specifies the date that you want to set.

Remarks

Use DATE without parameters to display the current date and a to display a prompt for a new date. Press the ENTER key at the prompt to keep the same date.
