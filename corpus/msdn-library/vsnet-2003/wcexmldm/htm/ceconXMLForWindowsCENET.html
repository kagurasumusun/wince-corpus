XML for Windows CE

MSXML for Microsoft Windows CE supports a subset of XML functionality. The components that the device manufacturer selects determine the level of XML support.

Windows CE only provides limited XML security support in any configuration.

The following list shows XML features that are not supported by Windows CE:

  • The ServerXMLHTTP object.
  • The IWinHttp interface; set through setServerHttpRequest.
  • Data Source Object (DSO) support.
  • Data island support.
  • The FreeThreadedDOMDocument object.
  • The XSLTemplate and IXSLProcessor interfaces. MSXML supports XSLT through TransformNode method, but does not support template caching.
  • Backward compatibility with the MSXML DOM supported by Microsoft® Internet Explorer 4.0
