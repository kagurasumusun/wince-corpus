CComModule::Lock

Performs an atomic increment on the lock count of the module. CComModule uses the lock count to determine whether any clients are accessing the module.

LONG Lock( );

Return Value

A value that may be useful for diagnostics or testing.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
