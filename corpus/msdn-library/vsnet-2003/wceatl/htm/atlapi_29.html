BEGIN_SINK_MAP

This macro declares the beginning of the event sink map for the composite control.

BEGIN_SINK_MAP(
_class)

Parameters

_class
[in] Specifies the control.

Example

BEGIN_SINK_MAP(CMyObj)
   SINK_ENTRY(IDC_CIRCCTL1, DISPID_CLICK, OnClick_CircCtrl1)
   SINK_ENTRY(IDC_CIRCCTL2, DISPID_CLICK, OnClick_CircCtrl2)
END_SINK_MAP()

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
