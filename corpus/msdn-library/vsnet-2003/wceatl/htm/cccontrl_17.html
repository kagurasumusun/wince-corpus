CComControl::GetAmbientFont

This method retrieves DISPID_AMBIENT_FONT, a pointer to the ambient IFont dispatch interface of the container.

HRESULT GetAmbientFont(
IFont** ppFont );

Parameters

ppFont
[out] The property DISPID_AMBIENT_FONT.

Return Value

One of the standard HRESULT values.

Remarks

If the property is NULL, the pointer is NULL. If the pointer is not NULL, the caller must release the pointer.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
