CComObjectGlobal::Release

This method decrements the reference count of the object by 1. By default, Release calls _Module::Unlock, where _Module is the global instance of CComModule or a class derived from it.

STDMETHOD_( ULONG Release )( );

Return Value

In debug builds, Release returns a value that may be useful for diagnostics and testing. In non-debug builds, Release always returns zero.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
