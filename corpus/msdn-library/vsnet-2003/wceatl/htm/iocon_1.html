Methods

IOleControl Methods

Method Description
FreezeEvents Indicates whether or not the container ignores or accepts events from the control.
GetControlInfo Fills in information about the keyboard behavior of the control. The ATL implementation returns E_NOTIMPL.
OnAmbientPropertyChange Informs a control that one or more of the ambient properties of the container has changed. The ATL implementation returns S_OK.
OnMnemonic Informs the control that a user has pressed a specified keystroke. The ATL implementation returns E_NOTIMPL.
