CContainedWindow::SubclassWindow

Subclasses the window identified by hWnd and attaches it to the CContainedWindow object. The subclassed window now uses CContainedWindow::WindowProc. The original window procedure is saved in m_pfnSuperWindowProc.

Do not call SubclassWindow if you have already called Create. 

BOOL SubclassWindow(
HWND hWnd );

Parameters

hWnd   
[in] The handle to the window being subclassed.

Return Value

TRUE if the window is successfully subclassed; otherwise, it is FALSE.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
