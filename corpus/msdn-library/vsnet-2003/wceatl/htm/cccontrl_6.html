CComControl::DoesVerbActivate

This method checks that the iVerb parameter used by IOleObjectImpl::DoVerb either activates the user interface of the control (iVerb equals OLEIVERB_UIACTIVATE), defines the action taken when the user double-clicks the control (iVerb equals OLEIVERB_PRIMARY), displays the control (iVerb equals OLEIVERB_SHOW), or activates the control (iVerb equals OLEIVERB_INPLACEACTIVATE).

BOOL DoesVerbActivate(
LONG iVerb );

Parameters

iVerb
[in] Value indicating the action to be performed by DoVerb.

Return Value

Returns FALSE if none of the conditions within the initial description are met.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
