CComContainedObject::QueryInterface

This method retrieves a pointer to the interface requested on the owner object.

HRESULT STDMETHODCALLTYPE QueryInterface(
Q** pp );

Parameters

Q
[in] Type of the interface.
pp
[out] Pointer to the resulting interface pointer.

Return Value

A standard STDMETHODCALLTYPE value.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
