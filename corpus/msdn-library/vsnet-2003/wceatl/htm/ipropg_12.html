IPropertyPageImpl::Show

This method makes the property page dialog box visible or invisible.

Calls to this method must occur after a call to IPropertyPageImpl::Activate and before a corresponding call to IPropertyPageImpl::Deactivate.

E_NOTIMPL is not a valid return value. E_OUTOFMEMORY is not a valid return value, since no memory should be used in implementing this method.

STDMETHOD ( Show )(
UINT nCmdShow );

Parameters

nCmdShow
[in] Command describing whether to become visible (SW_SHOW or SW_SHOWNORMAL) or hidden (SW_HIDE). No other values are valid for this parameter.

Return Value

This method supports the standard return value E_UNEXPECTED, as well as the following:

S_OK
The show command was successfully invoked.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
