CComControl::GetAmbientShowGrabHandles

This method retrieves DISPID_AMBIENT_SHOWGRABHANDLES. This flag indicates whether the container allows the control to display grab handles for itself when active.

HRESULT GetAmbientShowGrabHandles(
BOOL& bShowGrabHandles );

Parameters

bShowGrabHandles
[out] The property DISPID_AMBIENT_SHOWGRABHANDLES.

Return Value

One of the standard HRESULT values.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
