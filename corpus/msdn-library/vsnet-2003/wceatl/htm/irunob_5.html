IRunnableObjectImpl::Run

This method forces the control to run.

Containers call IRunnableObjectImpl::Run to force their objects to enter the running state. If the object is not already running, calling Run can be an expensive operation, on the order of many seconds. If the object is already running, then this method has no effect on the object.

STDMETHOD ( Run )( LPBINDCTX);

Return Value

S_OK
The object was successfully placed in the running state.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
