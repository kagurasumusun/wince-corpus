IDataObjectImpl::EnumFormatEtc

This method creates an enumerator to iterate through the FORMATETC structures supported by the data object. In ATL for Windows CE this function does nothing and always returns E_NOTIMPL. 

STDMETHOD ( EnumFormatEtc )(
DWORD dwDirection,
IEnumFORMATETC** ppenumFormatEtc );

Parameters

dwDirection
[in] Direction of the data through a value from the enumeration DATADIR.
ppenumFormatEtc
[out] Address of IEnumFORMATETC* pointer variable that receives the interface pointer to the new enumerator object.

Return Value

The ATL for Windows CE implementation returns E_NOTIMPL.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
