CComAutoThreadModule::m_Allocator

Because ATL for Windows CE does not support the apartment threading model, this data member does not do anything. It is included so that future versions of ATL for Windows CE will be backward compatible.

ThreadAllocator m_Allocator;

Remarks

The object managing thread selection. By default, the ThreadAllocator class template parameter is CComSimpleThreadAllocator.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
