IViewObjectExImpl::Unfreeze

This method unfreezes the drawn representation of the control. 

STDMETHOD ( Unfreeze )(
DWORD dwFreeze );

Parameters

dwFreeze
[in] Contains a key previously returned from IViewObjectExImpl::Freeze that determines which view object to unfreeze.

Return Value

The ATL implementation returns E_NOTIMPL.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
