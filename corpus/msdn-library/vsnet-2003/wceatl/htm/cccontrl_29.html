CComControl::GetAmbientUserMode

This method retrieves DISPID_AMBIENT_USERMODE. This flag indicates whether the container is in run-mode, TRUE, or design-mode, FALSE.

HRESULT GetAmbientUserMode(
BOOL& bUserMode );

Parameters

bUserMode
[out] The property DISPID_AMBIENT_USERMODE.

Return Value

One of the standard HRESULT values.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
