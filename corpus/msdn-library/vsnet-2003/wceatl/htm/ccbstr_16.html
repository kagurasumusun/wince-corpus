CComBSTR::operator &

This operator returns the address of the BSTR stored in the m_str data member.

BSTR* operator &( );

Example

CComBSTR bstrStr = "Hello World";
//...
// Free 'Hello World' and point the BSTR to 'Bye'.
::SysReAllocString(&bstrStr, OLESTR("Bye"));

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
