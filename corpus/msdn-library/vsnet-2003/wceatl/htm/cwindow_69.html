CWindow::SetDlgCtrlID

This method sets the the window identifier to the specified value.

int SetDlgCtrlID(
int nID );

Parameters

nID
[in] The new value to set for the window identifier.

Return Value

If successful, the previous identifier of the window; otherwise, it is zero.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
