IOleControlImpl::GetControlInfo

This method fills in information about the keyboard behavior for the control. 

STDMETHOD ( GetControlInfo )(
LPCONTROLINFO pCI );

Parameters

pCI
[in, out] Pointer to the caller-allocated CONTROLINFO structure to be filled in.

Return Value

The ATL implementation returns E_NOTIMPL.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
