CComControl::GetDirty

This method returns the value of the m_bRequiresSave data member. This value is set in SetDirty.

BOOL GetDirty( );

Return Value

Returns the value of data member m_bRequiresSave.

Requirements

  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
