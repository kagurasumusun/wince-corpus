CWindow::GetParent

This method retrieves the immediate parent window.

HWND GetParent( )
const;

Return Values

A handle to the parent window indicates success. NULL indicates that the window has no parent window. To get extended error information, call GetLastError.

Remarks

For more information, see the Windows CE function GetParent.

Example

// The following example attaches a HWND to the CWindow object
// and calls CWindow::GetParent to find out the parent
// window of the window wrapped by CWindow object.

CWindow myWindow;
myWindow.Attach(hWndFoo);
HWND hWndParent = myWindow.GetParent();

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
