CContainedWindow::RegisterWndSuperclass

This method registers the window class of the contained window.

This window class is based on an existing class but uses CContainedWindow::WindowProc. The name and window procedure of the existing window class are saved in m_lpszClassName and m_pfnSuperWindowProc, respectively.

ATOM RegisterWndSuperClass( );

Return Value

If successful, an atom that uniquely identifies the window class being registered; otherwise, zero.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
