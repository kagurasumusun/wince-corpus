IPropertyPage2Impl::EditProperty

This method specifies which property control receives the focus when the property page is activated.

If this method is called before a page is activated, the page should store the property and set the focus to it in the next call to IPropertyPage::Activate. If the page is already active, IPropertyPage2Impl::EditProperty should set the focus to the specific property field.

STDMETHOD ( EditProperty )(
DISPID dispID );

Parameters

dispID
[in] Identifies the property that is to receive the focus.

Return Value

The ATL implementation returns E_NOTIMPL.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
