CContainedWindow::m_pfnSuperWindowProc

This data member points to the original window procedure of the window class.

If the contained window is superclassed, meaning it is based on a window class that modifies an existing class, m_pfnSuperWindowProc points to the window procedure of the existing window class.

The DefWindowProc method sends message information to the window procedure saved in m_pfnSuperWindowProc.

WNDPROC m_pfnSuperWindowProc;

Requirements

  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
