CWindow::SetDlgItemInt

This method changes the text in a control to the string representation of an integer value.

BOOL SetDlgItemInt(
int nID, 
UINT nValue, 
BOOL bSigned = TRUE);

Parameters

nID
[in] Specifies the control to be changed.
nValue
All values passed in the nValue parameter are assumed to be signed.
bSigned
The bSigned parameter is not used in Windows CE. Set to zero.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
