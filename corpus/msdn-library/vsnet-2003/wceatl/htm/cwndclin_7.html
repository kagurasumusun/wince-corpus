CWndClassInfo::m_lpszOrigName

This data member contains the name of an existing window class. CWndClassInfo uses m_lpszOrigName only when you include the DECLARE_WND_SUPERCLASS macro in your class definition. In this case, CWndClassInfo registers a window class based on the class named by m_lpszOrigName. For more information, see the CWndClassInfo overview.

LPCTSTR m_lpszOrigName;

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
