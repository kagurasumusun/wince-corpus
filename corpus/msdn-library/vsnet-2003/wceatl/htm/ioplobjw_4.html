IOleInPlaceObjectWindowlessImpl::GetWindow

This method is called by the container to get the window handle of the control. Some containers will not work with a control that has been windowless, even if it is currently windowed. 

STDMETHOD ( GetWindow )(
HWND* phwnd );

Parameters

phwnd
[out] Pointer to where to return the window handle.

Remarks

In the ATL for Window CE implementation, if the control class, data member m_bWasOnceWindowless is TRUE, the function returns E_FAIL. Otherwise, if phwnd is not NULL, GetWindow sets *phwnd to the control class data member m_hWnd and returns S_OK.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
