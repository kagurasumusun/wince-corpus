CComPtr::operator ==

Compares two pointers for equivalence.

bool operator ==(
T* pT )
const;

Parameters

pT
[in] Pointer to be compared with the internal pointer.

Return value

Returns TRUE if the two pointers are equivalent; otherwise, FALSE.
