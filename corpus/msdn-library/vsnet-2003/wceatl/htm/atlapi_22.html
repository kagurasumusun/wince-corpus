ATLTRACENOTIMPL

This macro in debug builds of ATL, sends the string, funcname is not implemented, to the dump device and returns E_NOTIMPL. In release builds, this macro simply returns E_NOTIMPL.

ATLTRACENOTIMPL(
funcname)

Parameters

funcname
[in] A string containing the name of the function that is not implemented.

Example

ATLTRACENOTIMPL(_T("IOleControl::GetControlInfo"));

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
