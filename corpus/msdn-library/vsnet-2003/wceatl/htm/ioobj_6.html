IOleObjectImpl::DoVerbHide

This method tells the control to discard any undo state it is maintaining.

Deactivates and removes the user interface of the control, and also hides the control. 

HRESULT DoVerbHide(
LPCRECT prcPosRect ,
HWND hwndParent );

Parameters

prcPosRect
[in] Pointer to the rectangle the container wants the control to draw into.
hwndParent
[in] Handle of the window containing the control. Not used in the ATL implementation.

Return Value

Returns S_OK.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
