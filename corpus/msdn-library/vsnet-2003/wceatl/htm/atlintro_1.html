Using this ATL Documentation

Documentation for this release of ATL for Windows CE is targeted at the experienced ATL desktop developer. You can continue to use your experience and resources (such as books and other reference material) that you have used in ATL desktop development.

  • The Overview section focuses on the differences in class support you will find between desktop and Windows CE.

    This Overview is meant to be a supplement to the eMbedded Visual C++ documentation, where you will find many additional topics dealing with ATL development.

  • The Samples section offers brief documentation on several ATL sample projects that ship with Microsoft® eMbedded Visual C++®. These samples demonstrate the use of many of the classes available for Windows CE development. Each topic in the Samples section provides a button control that lets you automatically open the sample in the eMbedded Visual C++ IDE.
  • The heart of the documentation is the Reference section, where you will find all of and only those ATL classes and members that are supported in the SDKs included with this package. To locate information on a class or member, use the Help Index or Search functions.

This documentation is meant to be used in conjunction with other Help files included in the Help collection, especially topics provided by your target SDK and basic Windows CE topics.
