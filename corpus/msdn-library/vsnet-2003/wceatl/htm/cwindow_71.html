CWindow::SetDlgItemText

This method changes the text in a control.

BOOL SetDlgItemText(
int nID,
LPCTSTR lpszString );

Parameters

nID
[in] Identifies the control with a title or text that is to be set.
lpszString
Long pointer to a null-terminated string to be used as the new title or control text.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
