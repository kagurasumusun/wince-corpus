DECLARE_EMPTY_MSG_MAP

This macro declares an empty message map. DECLARE_EMPTY_MSG_MAP is a convenience macro that calls the macros BEGIN_MSG_MAP and END_MSG_MAP to create an empty message map.

END_MSG_MAP
