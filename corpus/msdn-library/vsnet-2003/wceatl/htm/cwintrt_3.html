CWinTraits::GetWndExStyle

This method retrieves the extended styles of the CWinTraits object.

static DWORD GetWndExStyle(
DWORD dwExStyle );

Parameters

dwExStyle
Extended styles used for creation of a window. If dwExStyle is zero, default style values (t_dwExStyle) are returned. If dwExStyle is nonzero, dwExStyle is returned.

Return Value

The extended window styles of the object.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
