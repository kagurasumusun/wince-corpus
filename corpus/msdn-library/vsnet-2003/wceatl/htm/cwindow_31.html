CWindow::GetScrollPos

This method retrieves the position of the scroll box in a specified scroll bar.

int GetScrollPos(
int nBar )
const;

Parameters

nBar
[in] Specifies the scroll bar to be examined. This parameter can be one of the following values.
Value Description
SB_CTL Retrieves the position of the scroll box in a scroll bar control.
SB_HORZ Retrieves the position of the scroll box from standard horizontal scroll bars in a window.
SB_VERT Retrieves the position of the scroll box from a standard vertical scroll bar of a window.

Return Values

If the function succeeds, the return value is the current position of the scroll box.

If the function fails, the return value is zero. To get extended error information, call GetLastError.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
