CWindowImpl::UnsubclassWindow

This method detaches the subclassed window from the CWindowImpl object and restores the original window procedure, saved in m_pfnSuperWindowProc. 

HWND UnsubclassWindow(
BOOL bForce = FALSE);

Parameters

bForce
If TRUE this parameter restores the original window procedure even if it is not the active window procedure. The default is FALSE.

Return Value

The handle to the window previously subclassed.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
