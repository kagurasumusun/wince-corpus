CWindow::GetDlgItem

This method retrieves the specified child window.

The GetDlgItem method only works for immediate child controls of a dialog box—it does not search through nested dialog boxes. 

HWND GetDlgItem(
int nID )
const;

Parameters

nID
[in] Specifies the identifier of the control that receives the message.

Return Value

If the function succeeds, the return value is the window handle of the specified control. If the function fails, the return value is NULL, indicating an invalid dialog box handle or a nonexistent control.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
