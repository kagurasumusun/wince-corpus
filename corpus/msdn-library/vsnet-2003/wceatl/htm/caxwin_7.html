CAxWindow::QueryControl

This method retrieves the IUnknown interface of the hosted control.

HRESULT QueryControl(
REFIID iid,
void** ppUnk ); 

template <class Q>
HRESULT QueryControl(
Q** ppUnk );

Return Value

A standard HRESULT value.

Parameters

iid
[in] Specifies the IID of the control interface.
ppUnk
[out] A pointer to the IUnknown interface of the control. In the template version of this function, there is no need for a reference ID and the interface can be specified.
Q
[in] The interface that is being queried for.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
