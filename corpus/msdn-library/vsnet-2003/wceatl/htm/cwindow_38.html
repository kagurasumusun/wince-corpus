CWindow::GetWindow

This method retrieves the specified window.

An application that calls GetWindow to perform in a loop risks being caught in an infinite loop or referencing a handle to a window that has been destroyed.

HWND GetWindow(
UINT nCmd )
const;

Parameters

nCmd
Specifies the relationship between CWindow and the returned window.

Return Values

A window handle indicates success. NULL indicates that no window exists with the specified relationship to the specified window. To get extended error information, call GetLastError.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
