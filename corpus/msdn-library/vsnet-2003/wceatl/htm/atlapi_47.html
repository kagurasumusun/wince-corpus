COM_INTERFACE_ENTRY_FUNC_BLIND

This macro is the same as COM_INTERFACE_ENTRY_FUNC, except that querying for any IID results in a call to func. Any failure will cause processing to continue on the COM map. If the function returns an interface pointer, it should return S_OK.

COM_INTERFACE_ENTRY_FUNC_BLIND(
dw,
func)

Parameters

dw
[in] A parameter passed through to the func.
func
[in] The function that gets called when this entry in the COM map is processed.

Remarks

See COM_INTERFACE_ENTRY Macros for remarks about COM map entries.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
