CAxDialogImpl::DestroyWindow

This method destroys the specified modeless dialog box. Do not call DestroyWindow to destroy a modal dialog box. Call CAxDialogImpl::EndDialog instead.

BOOL DestroyWindow( );

Return Value

TRUE if the window is successfully destroyed; otherwise, FALSE.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
