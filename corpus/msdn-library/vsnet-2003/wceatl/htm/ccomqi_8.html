CComQIPtr::IsEqualObject

Compares the two objects for equivalence. This method performs IUnknown comparisons.

bool IsEqualObject(
IUnknown* pOther );

Parameters

pOther
[in] Pointer to the other object.

Return value

Returns TRUE if the two objects are equal; otherwise, FALSE.
