IOleInPlaceObjectWindowlessImpl::InPlaceDeactivate

This method is called by the container to deactivate an in-place active control. This method performs a full or partial deactivation depending on the state of the control.

If necessary, the control user interface is deactivated, and the control window, if any, is destroyed. The container is notified that the control is no longer active in place. The IOleInPlaceUIWindow interface used by the container to negotiate menus and border space is released. 

STDMETHOD ( InPlaceDeactivate )( void );

Requirements
