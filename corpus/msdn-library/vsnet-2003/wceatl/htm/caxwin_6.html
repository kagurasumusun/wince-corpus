CAxWindow::GetWndClassName

This method retrieves the name of the window class.

static LPCTSTR GetWndClassName( );

Return Value

A pointer to a string containing the name of the window class, in this case, AtlAxWin.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
