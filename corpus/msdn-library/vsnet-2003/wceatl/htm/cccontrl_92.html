CComControl::m_spDataAdviseHolder

This data member provides a standard means to hold advisory connections between data objects and advise sinks. A data object is a control that can transfer data and that implements IDataObject, whose methods specify the format and transfer medium of the data.

To use this data member within your control class, you must declare it as a data member in your control class. Your control class will not inherit this data member from the base class because it is declared within a union in the base class.

CComPtr<IDataAdviseHolder> m_spDataAdviseHolder;

Remarks

The interface m_spDataAdviseHolder implements the IDataObject::DAdvise and IDataObject::DUnadvise methods to establish and delete advisory connections to the container. The container for the control must implement an advise sink by supporting the IadviseSink interface.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
