AtlAxWinInit

This global function initializes the AxWin hosting code. You must call this global function first by any process that uses the containment functionality.

This global function registers the window class as ATLAXWin so it can be used in calls to CreateWindow or CreateWindowEx, as described in the Windows CE SDK. 

ATLINLINE ATLAPI_(BOOL) AtlAxWinInit( );

Return Value

TRUE, if the registration of the control was successful; otherwise, it is FALSE.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlhost.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
