ATL for Windows CE Samples

The following applications provide examples of using ATL for Windows CE.

You can choose File | Open in the eMbedded Visual C++ IDE to open any sample dating back to the Handheld PC 2.0 and Palm-size PC 1.0 SDKs. Be sure to select the version of the sample that belongs with the platform you are targeting. Even though they mostly share the same names, sample files are platform-specific, and are located in the folder of the appropriate SDK.

The following table shows the default path for samples in the SDKs shipped with eMbedded Visual Tools.

SDK Path
H/PC Pro Windows CE Tools\wce211\MS HPC Pro\samples\atl\
Palm-size PC Windows CE Tools\wce211\ms palm size pc\samples\atl\
Pocket PC Windows CE Tools\wce300\MS Pocket PC\samples\atl\
You can also open Pocket PC projects automatically by clicking on buttons displayed at the top of the sample topic.

Sample applications include the following:

COUNT/COUNTCTN Demonstrates how to use containment in an ATL control.
COMPCTRL/COMPCNTR Demonstrates how to use a composite control to contain other ActiveX controls.
POLYGON/POLYCNTR Demonstrates how to implement custom properties, events, and a property page for an ATL control.
SKETCH/SKETCNTR Demonstrates how to capture mouse/stylus messages from the touch screen and use them to draw on the display.
