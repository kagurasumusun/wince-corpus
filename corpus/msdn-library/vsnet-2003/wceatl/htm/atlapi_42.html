COM_INTERFACE_ENTRY_AUTOAGGREGATE_BLIND

This macro is the same as COM_INTERFACE_ENTRY_AUTOAGGREGATE, except that querying for any IID results in forwarding the query to punk, and if punk is NULL, automatically creating the aggregate described by the clsid. If the interface query fails, processing of the COM map continues.

COM_INTERFACE_ENTRY_AUTOAGGREGATE_BLIND(
punk,
clsid)

Parameters

punk
[in] The name of an IUnknown pointer. Must be a member of the class containing the COM map.
clsid
[in] The identifier of the aggregate that will be created if punk is NULL.

Remarks

For example, from the ATL sample COMMAP:

BEGIN_COM_MAP(COuter)
   ...
   COM_INTERFACE_ENTRY_AUTOAGGREGATE_BLIND(m_pUnkAutoAggB.p, CLSID_CAutoAggB)
   ...
END_COM_MAP()

See COM_INTERFACE_ENTRY Macros for remarks about COM map entries.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
