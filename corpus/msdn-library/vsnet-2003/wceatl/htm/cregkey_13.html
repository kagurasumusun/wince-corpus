CRegKey::SetValue

This method stores data in the specified value field of an open registry key. The first two versions of SetValue use m_hKey as the open key. The third version allows you to create or open a subkey of hKeyParent, and then set the value field of the subkey. 

LONG SetValue(
DWORD dwValue,
LPCTSTR lpszValueName ); 

LONG SetValue(
LPCTSTR lpszValue,
LPCTSTR lpszValueName = NULL ); 

inline LONG WINAPI SetValue(
HKEY hKeyParent,
LPCTSTR lpszKeyName,
LPCTSTR lpszValue,
LPCTSTR lpszValueName );

Parameters

dwValue
[in] Specifies the data to be stored.
lpszValueName
[in] Specifies the value field to be set. If a value field with this name does not already exist in the key, it is added.
lpszValue
[in] Specifies the data to be stored. This parameter must be non-NULL.
bMulti
Indicates whether the string must be inserted as multi string. If true, it is set lpszValue as follows: 
lpszValue = "String 1\\0String2\\0";
hKeyParent
[in] The handle of an open key.
lpszKeyName
[in] Specifies the name of a key to be created or opened. This name must be a subkey of hKeyParent.

Return Value

If successful, returns ERROR_SUCCESS; otherwise, it is an error value.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
