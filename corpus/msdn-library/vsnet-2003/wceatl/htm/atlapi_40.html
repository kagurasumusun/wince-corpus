COM_INTERFACE_ENTRY_AGGREGATE_BLIND

This macro is the same as COM_INTERFACE_ENTRY_AGGREGATE, except that querying for any IID results in forwarding the query to punk. If the interface query fails, processing of the COM map continues.

COM_INTERFACE_ENTRY_AGGREGATE_BLIND(
punk)

Parameters

punk
[in] The name of an IUnknown pointer.

Remarks

For example:

BEGIN_COM_MAP(COuter)
   ...
   COM_INTERFACE_ENTRY_AGGREGATE_BLIND(m_pUnkAggBlind.p)
   ...
END_COM_MAP()

See COM_INTERFACE_ENTRY Macros for remarks about COM map entries.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlcom.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
