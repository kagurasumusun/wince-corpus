CComModule::UnregisterClassHelper

This method removes the standard class registration of an object from the system registry. The UpdateRegistryClass method calls UnregisterClassHelper.

inline HRESULT WINAPI UnregisterClassHelper(
const CLSID& clsid,
LPCTSTR lpszProgID,
LPCTSTR lpszVerIndProgID );

Parameters

clsid
[in] The CLSID of the object to be unregistered.
lpszProgID
[in] The ProgID associated with the object.
lpszVerIndProgID
[in] The version-independent ProgID associated with the object.

Return Value

A standard HRESULT value.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
