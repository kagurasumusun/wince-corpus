CComObjectRootEx::ObjectMain

Called by the framework when initializing, or terminating, the related COM object. For example, this function is called when the OBJECT_ENTRY macro, referencing this object, is encountered while processing the object map.

static void WINAPI ObjectMain(
bool bStarting );

Parameters

bStarting
[out] The value is true if the object is being initialized; otherwise, it is false.

Remarks

Define this function in your COM object class to implement custom initiation and termination code. For example:

class ATL_NO_VTABLE CMyObj :
  public CComObjectRootEx<CComSingleThreadModel>,
  public CComCoClass<CMyObj, &CLSID_MyObj>,
  public IDispatchImpl<IMyObj, &IID_IMyObj, &LIBID_TESTLib>
{
public:
  CMyObj()
  {
  }

static void WINAPI ObjectMain(bool bStarting)
{
  if(bStarting)
    // Perform custom initialization routines.
  else
    // Perform custom termination routines.
}

. . .
// IMyObj
public:
};

Requirements

  Header file: Declared in Atlcom.h
