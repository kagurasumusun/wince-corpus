NOTIFY_CODE_HANDLER

This macro is similar to NOTIFY_HANDLER, but maps a WM_NOTIFY message based only on the notification code.

NOTIFY_CODE_HANDLER(
cd,
func)

Parameters

cd
[in] The notification code.
func
[in] The name of the message-handler function.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
