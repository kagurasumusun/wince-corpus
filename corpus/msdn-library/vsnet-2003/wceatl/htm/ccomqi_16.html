CComQIPtr::operator ->

This operator returns the interface pointer, p, cast to a _NoAddRefReleaseOnCComPtr*. _NoAddRefReleaseOnCComPtr is a class derived from the interface used as the template parameter T. This class changes the access level on the AddRef and Release methods to private to prevent common reference counting bugs.

This means that you cannot call the raw AddRef and Release methods through operator->. If you need to call these methods directly on the contained pointer, use the p member.

The operation will assert if p is NULL.
