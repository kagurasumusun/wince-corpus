CComAutoThreadModule::m_nThreads

Because ATL for Windows CE does not support the apartment threading model, this data member does not do anything. It is included so that future versions of ATL for Windows CE will be backward compatible.

int m_nThreads;

Remarks

Contains the number of threads in the EXE module. When Init is called, m_nThreads is set to the nThreads parameter value. Each associated apartment in a thread is managed by a CComApartment object.

Requirements

  Windows CE versions: 2.10 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
