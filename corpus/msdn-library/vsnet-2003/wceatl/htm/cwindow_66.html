CWindow::SendNotifyMessage

This method sends a message to the window. If the window was created by the calling thread, SendNotifyMessage does not return until the window procedure has processed the message. Otherwise, it returns immediately.

BOOL SendNotifyMessage(
UINT message, 
WPARAM wParam = 0, 
LPARAM lParam = 0);

Parameters

message
[in] Specifies the message to be sent.
wParam
[in] Specifies additional message-specific information.
lParam
[in] Specifies additional message-specific information.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
