IOleObjectImpl::DoVerbOpen

This method causes the control to be open-edited in a separate window. 

HRESULT DoVerbOpen(
LPCRECT prcPosRect ,
HWND hwndParent );

Parameters

prcPosRect
[in] Pointer to the rectangle the container wants the control to draw into.
hwndParent
[in] Handle of the window containing the control.

Return Value

The default implementation simply returns S_OK.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
