CComVariant::Detach

This method detaches the underlying VARIANT from the CComVariant object.

HRESULT Detach(
VARIANT* pDest );

Parameters

pDest
Pointer to the destination where the VARIANT will be detached.

Return Value

A standard HRESULT value.

Requirements
