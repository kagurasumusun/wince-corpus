CWindow::GetIcon

This method retrieves the handle to the large or small icons of the window. GetIcon sends a WM_GETICON message to the window.

HICON GetIcon(
BOOL bBigIcon = TRUE )
const;

Parameters

bBigIcon
[in] If TRUE, the default value, the method returns the large icon. Otherwise, it returns the small icon.

Return Value

An icon handle.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlwin.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
