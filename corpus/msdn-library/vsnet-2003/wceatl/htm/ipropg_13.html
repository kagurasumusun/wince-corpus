IPropertyPageImpl::TranslateAccelerator

This method processes the keystroke specified in pMsg.

Calls to this method must occur after a call to IPropertyPageImpl::Activate and before the corresponding call to IPropertyPageImpl::Deactivate.

STDMETHOD ( TranslateAccelerator )(
MSG *pMsg );

Parameters

*pMsg
[in] Pointer to the MSG structure describing the keystroke to process.

Return Value

This method slupports the standard return value E_UNEXPECTED, as well as the following:

S_OK
The property page handles the accelerator.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlctl.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
