CComPtr::Attach

Attaches a pointer without incrementing its reference count. The reference count of the pointer has had its reference count incremented by calling IUnknown::AddRef.

void Attach(
T* p2 );

Parameters

p2
[in] A pointer.

Requirements

  Windows CE versions: 2.0 and later
  Header file: Declared in Atlbase.h
  Platform: H/PC Pro, Palm-size PC, Pocket PC
