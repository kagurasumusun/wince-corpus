MSGQUEUEINFO

This structure contains information about a message queue.

typedef MSGQUEUEINFO{
DWORD dwSize;
DWORD dwFlags;
DWORD dwMaxMessages;
DWORD cbMaxMessage;
DWORD dwCurrentMessages;
DWORD dwMaxQueueMessages;
WORD wNumReaders;
WORD wNumWriters
} MSGQUEUEINFO, *PMSGQUEUEINFO, FAR *LPMSGQUEUEINFO;

Members

dwSize
[in] Size of the structure.
dwFlags
[out] Describes the behavior of the message queue. This member can be set to one or more of the following.
Flag Description
MSGQUEUE_NOPRECOMMIT This flag allocates message buffers on demand. The message buffers will be free after they are read.
MSGQUEUE_ALLOW_BROKEN This flag enables a read or write operation to complete even if there is no corresponding writer or reader present.
dwMaxMessages
[out] Maximum number of messages that are allowed in a message queue.
cbMaxMessage
[out] Maximum size of each message in a message queue.
dwCurrentMessages
[out] Number of messages in the queue.
dwMaxQueueMessages
[out] Maximum number of messages that have ever been in the queue at one time.
wNumReaders
[out] Number of readers reading from the queue.
wNumWriters
[out] Number of writers writing to the queue.

Return Values

If the MSGQUEUE_ALLOW_BROKEN flag is not specified and either the read or write exists, assuming a single read and writer, the queue will be deleted from memory and only the open handle to the queue will exist. The only option at this point is to close the remaining open handle and reopen the queue if necessary.
