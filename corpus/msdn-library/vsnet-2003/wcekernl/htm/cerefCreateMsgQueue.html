CreateMsgQueue

This function creates or opens a user-defined message queue.

HANDLE WINAPI CreateMsgQueue(
LPCWSTR lpszName,
LPMSGQUEUEOPTIONS lpOptions
);

Parameters

lpszName
[in] Specifies the name of the message queue. The lpszName parameter can also be set to NULL or must be no larger than the MAX_PATH characters including the NULL character.
lpOptions
[in] Specifies a pointer to a MSGQUEUEOPTIONS structure that sets the properties of the message queue.

Return Values

If the function succeeds, the return value is an read-only or write-only handle to the specified queue. If the specified queue exists before the function call, a new handle will be create that points at the same queue. The queue already exists if a call to the GetLastError function returns ERROR_ALREADY_EXISTS, even though the function has succeeded. If the message queue does not exist before the call, GetLastError returns ERROR_SUCCESS.

If the function fails, the return value is NULL. To get extended error information, call GetLastError.

Remarks

A queue can only be created for GENERIC_READ or GENERIC_WRITE access and not both in a single application programming interface (API) call. You can call CreateMsgQueue twice to obtain a read-only and write-only handle. Use the CloseMsgQueue function to close an object handle returned by CreateMsgQueue.

Handles returned from CreateMsqQueue can be used in calls to the WaitForSingleObject or WaitForMultipleObjects functions. Returned handles can indicate a time-out or that the status of the queue has changed.

A queue status change marks the change from an empty queue to non-empty queue, marks the change from a queue full to queue not full, or marks that a queue has broken if MSGQUEUE_ALLOW_BROKEN is not specified.
