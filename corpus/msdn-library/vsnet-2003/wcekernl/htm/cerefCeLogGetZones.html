CeLogGetZones

This function is called to determine which zones are currently set, and which zones are supported by the kernel.

BOOL CeLogGetZones(
LPDWORD lpdwZoneUser, 
LPDWORD lpdwZoneCE, 
LPDWORD lpdwZoneProcess,
LPDWORD lpdwAvailableZones 
);

Parameters

lpdwZoneUser
User-defined zones that are currently active. This parameter can be NULL if it is not desired.
lpdwZoneCE
The predefined system zones that are currently active on the device. This parameter can be NULL if it is not desired.
lpdwZoneProcess
The processes that are currently being logged. This parameter can be NULL if it is not desired.
lpdwAvailableZones
Indicates which zones are supported by the kernel. This parameter can be NULL if it is not desired.

Return Values

This function returns TRUE if the zone settings are successfully queried, and returns FALSE otherwise.

Remarks

CeLogGetZones allows the UI that tracks the zones to determine if the zones are being enabled and disabled over time, and also determines which zones a user can enable and disable.
