OpenMsgQueue

This function opens a handle to an existing message queue based on a message queue handle.

HANDLE WINAPI OpenMsgQueue(
HANDLE hSrcProc,
HANDLE hMsgQ,
LPMSGQUEUEOPTIONS lpOptions
);

Parameters

hSrcProc
[in] Handle to a source process that owns the hMsgQ message queue handle.
hMsgQ
[in] Specifies the handle to a message queue returned by the CreateMsgQueue function.
lpOptions
[in] Specifies a pointer to a MSGQUEUEOPTIONS structure that sets the properties of the message queue.

Return Values

Returns a handle to a message queue. Returns NULL if the queue could not be opened.

Remarks

Use CloseMsgQueue to close the handle returned from OpenMsgQueue. Only the dwSize parameter and the flags of the bReadAccess parameter of lpOptions are checked while calling OpenMsgQueue.
