ReadMsgQueue

This function is used to read a single message from a message queue.

BOOL ReadMsgQueue(
HANDLE hMsgQ,
LPVOID lpBuffer,
DWORD cbBufferSize,
LPDWORD lpNumberOfBytesRead,
DWORD dwTimeout,
DWORD *pdwFlags
);

Parameters

hMsgQ
[in] Handle to an open message queue.
lpBuffer
[out] Pointer to a buffer that will be used to store a read message. This parameter cannot be NULL.
cbBufferSize
[in] Size of the buffer, in bytes, specified by lpBuffer. This parameter cannot be zero.
lpNumberOfBytesRead
[out] Number of bytes stored in lpBuffer. This parameter cannot be NULL.
dwTimeout
[in] Amount of time, in milliseconds, before the read operation will time out. If 0 is specified, the read operation will not block if there is no data to read. If the parameter is set to INFINITE, the read operation will block until data is available or the queue status changed.
pdwFlags
[out] Pointer to a DWORD that indicates the properties of the message. It can be set to the following value.
Value Description
MSGQUEUE_MSGALERT The message is an alert message.

Return Values

If the read operation succeeded, TRUE is returned; otherwise, FALSE is returned. For extended error information, call the GetLastError function.

If the buffer specified by lpBuffer is too small to read a message, the read will be successful but only cbBufferSize bytes of data will be copied and the error value returned by GetLastError will equal ERROR_INSUFFICIENT_BUFFER.

If no writers are attached to the message queue and MSGQUEUE_ALLOW_BROKEN is not specified, ERROR_PIPE_NOT_CONNECTED will be returned.

If dwTimeout is 0 and there is no data to read, ERROR_TIMEOUT is returned.

If all the writers exit while a reader is blocked and MSGQUEUE_ALLOW_BROKEN is not specified, the read will fail and ERROR_PIPE_NOT_CONNECTED is returned.
