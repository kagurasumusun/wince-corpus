WriteMsgQueue

This function is used to write a single message to a message queue.

BOOL WINAPI WriteMsgQueue(
HANDLE hMsgQ,
LPVOID lpBuffer,
DWORD cbDataSize,
DWORD dwTimeout,
DWORD dwFlags
);

Parameters

hMsgQ
[in] Handle to an open message queue.
lpBuffer
[in] Pointer to a buffer that contains data to be written to a message queue. This parameter cannot be NULL.
cbDataSize
[in] Number of bytes store in lpBuffer that make up a message. This parameter cannot be zero.
dwTimeout
[in] Amount of time, in milliseconds, before the write operation will time out. If 0 is specified, the write operation will not block if the write operation cannot succeed. If the parameter is set to INFINITE, the write operation will block until the write operation succeeds or the queue status changed.
dwFlags
[in] Specifies the characteristics of the message. It can be set to the following value.
Value Description
MSGQUEUE_MSGALERT The message is an alert message.

Return Values

If the write operation succeeded, TRUE is returned; otherwise, FALSE is returned. For extended error information, call the GetLastError function.

If the return value is ERROR_INSUFFICIENT_BUFFER, the size of lpBuffer is too large to hold a message. If the return value is ERROR_TIMEOUT, the write operation timed out before it could write its data. An error value of ERROR_PIPE_NOT_CONNECTED indicates that there are no readers attached to the message queue.

If MSGQUEUE_ALLOW_BROKEN is specified, the error ERROR_PIPE_NOT_CONNECTED will not result when a message is written to the queue for which there is no reader.

If all the readers exit while the writer is blocked and MSGQUEUE_ALLOW_BROKEN is not specified, the writer will fail and ERROR_PIPE_NOT_CONNECTED is returned.

Remarks

If MSGQUEUE_NOPRECOMMIT is specified, and not enough memory can be allocated for the message, ERROR_OUTOFMEMORY is returned.
