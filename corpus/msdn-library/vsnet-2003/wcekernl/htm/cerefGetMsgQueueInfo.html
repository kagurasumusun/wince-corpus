GetMsgQueueInfo

This function returns information about a message queue.

BOOL GetMsgQueueInfo(
HANDLE hMsgQ,
LPMSGQUEUEINFO lpInfo
);

Parameters

hMsgQ
[in] Handle to an open message queue.
lpInfo
[out] Pointer to a MSGQUEUEINFO structure that returns information about the message queue.

Return Values

If the operation succeeded, TRUE is returned; otherwise, FALSE is returned. For extended error information, call the GetLastError function.
