IsProcessorFeaturePresent

This function retrieves information about the supported x86 processor features in your system.

WINBASEAPI BOOL WINAPI IsProcessorFeaturePresent(
DWORD dwProcessorFeature
);

Parameters

dwProcessorFeature
The feature that you want to verify support for.

Return Values

Returns TRUE if the processor feature is support; otherwise, the function returns FALSE.

Remarks

Currently, only the following flags are supported in Windows CE .NET. These flags will always return FALSE on non-86 platforms.

  • PF_FLOATING_POINT_EMULATED
  • PF_MMX_INSTRUCTIONS_AVAILABLE
  • PF_3DNOW_INSTRUCTIONS_AVAILABLE
  • PF_RDTSC_INSTRUCTION_AVAILABLE

All other PF_XXX flags to IsProcessorFeaturePresent will return FALSE.
