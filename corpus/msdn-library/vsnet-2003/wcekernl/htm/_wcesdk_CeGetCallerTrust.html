CeGetCallerTrust

This function retrieves the assigned trust level of a process.

DWORD CeGetCallerTrust (void);

Parameters

None.

Return Values

The following table shows the possible values that can be returned.

Value Description
OEM_CERTIFY_TRUST (2) The OEM trusts the process to perform any OS function calls.
OEM_CERTIFY_RUN (1) The OEM trusts the process to run, but restricts the module from making certain function calls.
NULL The OEM does not trust this calling process.

Remarks

The trust level is assigned by an OEM when a process is loaded or by setting an attribute in a .bib file. A Driver DLL that exists in the Device Manager's address space can call this function to determine whether the calling process' trust level is sufficient to complete all operations. If the Driver DLL is required to run in a trusted mode and the calling process is not trusted then the driver should return NULL to the application's request to get a handle to the driver.
