Statically Configured Networks

In statically configured networks, IP addresses are permanently assigned to computers and rarely change. DNS provides forward or reverse lookup. Configuration can be stored in the host's file on Windows NT or the [HKEY_LOCAL_MACHINE\COMM\TCPIP\Hosts] registry key on Windows CE.

This is the simplest MSMQ configuration and does not require MSMQ to provide any registration services or take steps to query WINS servers.
