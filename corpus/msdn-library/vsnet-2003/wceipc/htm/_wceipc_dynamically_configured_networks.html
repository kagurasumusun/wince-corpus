Dynamically Configured Networks

Dynamically configured networks are networks in which configuration (IP addresses for networked computers and information about network servers – WINS, DNS etc) is provided dynamically, usually over DHCP protocol.

Dynamically connected networks can present several challenges to MSMQ. For example, IP addresses can change. A machine has one IP address when connected via dial-up link and another IP address when connected via network card and these addresses change every time a new connection is established. Changing an IP address means that the name servers must be updated. In particular, on dial-up connection they must be updated quickly because a user is unlikely to wait for 20 minutes while the DNS server learns the new IP address for the name.
