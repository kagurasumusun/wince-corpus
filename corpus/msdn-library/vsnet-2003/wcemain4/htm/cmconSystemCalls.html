System Calls

Along with being the core of the Windows CE operating system (OS), the kernel (nk.exe) is also the process that handles all system calls for the OS. A system call is a function that resides in another process that the kernel is notified about.

When a process calls a system call, it calls into a wrapper function for that system call that is defined in Coredll.dll. The function that is defined in Coredll.dll prepares the function's parameters for the kernel and causes a software exception to occur. The kernel then handles this exception and determines the correct destination process to send the function call request to. The process that owns the actual function executes the function using the same stack and register values that the original thread contains in the calling process. Because the actual function call exists in another process, the existence of that process must be verified in order to successfully execute the system call. The overhead of a system call can be measured with the measurement tool OSBench.exe.
