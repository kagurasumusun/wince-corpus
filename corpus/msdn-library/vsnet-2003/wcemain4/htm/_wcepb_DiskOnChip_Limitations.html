DiskOnChip Limitations

If you use DiskOnChip, note the following:

  • If the CEPC has a DiskOnChip device and is booted with an OS image that recognizes this device, only one of the PC Card slots works correctly. This is because the DiskOnChip is set by default to use the address D0000, which conflicts with the address that the PC Card controller hardware uses for one of the PC Card slots. This situation arises only for the CEPC, and you can customize your hardware, drivers, and OS accordingly on your platform.

    Use one of the following solutions:

    • Use only one PC Card slot.
    • Configure the DiskOnChip device to use a C8000 address range by using the jumper settings as described in the product documentation for the device. You must also update the platform registry to reflect the new address range, and then rebuild the OS. Typically, the PCMCIA driver uses the D0000 through DFFFF address range, which may conflict with the default setting of the DiskOnChip.
    • Modify %_WINCEROOT%\Public\Common\Oak\Drivers\Pcmcia\i82365\Window.c so that the memory windows use a different address range for the i82365 driver. Or add a registry key under HKEY_LOCAL_MACHINE\Drivers\PCMCIA called MemWin with the base address that you want the memory windows to use for the TI-1250 driver. You will also have to modify Config.bib to change the PCMCIABUF range.
