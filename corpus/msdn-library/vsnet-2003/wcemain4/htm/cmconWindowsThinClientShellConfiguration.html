Windows Thin Client Shell Configuration

The Windows Thin Client software includes a shell that enables task switching between emulation software. The Windows Thin Client Shell is the software component that provides users with an interface to start sessions or to switch among active sessions. This is a dedicated shell that is designed specifically for Windows Thin Client, and it does not expose an interface for starting arbitrary applications.

The Windows CE shell is not required, because Windows Thin Client performs no local application processing. Windows Thin Client requires only a shell for session management.
