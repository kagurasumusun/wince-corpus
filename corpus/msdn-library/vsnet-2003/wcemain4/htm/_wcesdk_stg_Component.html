stg Component

The stg component supports OLE lightweight storage.

Functions for Application Developers

The stg component contains function for application developers, which is defined in the Objbase.h header file. To import this function, you must link to the Stg.lib file. The following functions are included in the stg component:

  • CreateStreamOnHGlobal
  • GetHGlobalFromStream
  • StgCreateDocfile
  • StgOpenStorage
