Writing the MAC address to the Intel SA1110/SA1111 (Assabet) Development Kit

  1. Use JFlash to download %_WINCEROOT%\Platform\SA11X0BD\Eboot\Ebootpcm\bin\eboot.nb0, which is the Ethernet boot loader for downloading images over a PCMCIA network card to the device.
  2. Navigate to the %_WINCEROOT%\Platform\SA11X0BD\ProgMac directory.
  3. Type build –c to generate the Progmac.exe file.

    The ProgMac.exe file will be stored in the %_PROJECTOAKROOT%\Target\ARMV4\%WINCEDEBUG% directory.

  4. Copy ProgMac.exe to your release directory.
  5. Place the Ethernet CF card in the top PCMCIA slot, slot 0, and connect the Ethernet cable to it.
  6. Copy %_WINCEROOT%\Platform\SA11X0BD\EbootSmc\Nkpcc.bin to your release directory.
  7. In the Build Release directory, select the Nkpcc.bin file in Platform Builder to download to the device.
  8. In Platform Builder, select the device name associated with the CF NE2000 Ethernet card that is inserted into the PCMCIA slot.
  9. Reset the Intel SA1110/SA1111 (Assabet) Development Kit and download the Nkpcc.bin file to the device.
  10. From the Target menu, execute ProgMac.exe remotely on the device, and then choose Run Programs with the MAC address to use.

    The syntax at the command prompt is as follows. 

    ProgMac <address>

    For example ProgMac 00800f60009b.

  11. Use JFlash to download %_WINCEROOT%\Platform\SA11X0BD\Eboot\Ebootsmc\Bin\Eboot.nb0, which is the Ethernet boot loader for downloading images over the internal network card to the device.
  12. Download the OS image to the Intel SA1110/SA1111 (Assabet) Development Kit.
