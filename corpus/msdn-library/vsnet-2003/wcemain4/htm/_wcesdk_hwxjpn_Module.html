hwxjpn Module

The hwxjpn module provides support for Japanese handwriting input.

Functions for Application Developers

The hwxjpn module contains functions for application developers, which are defined in the Recog.h header file. To import these functions, you must link to the hwxjpn.lib file. The following table shows the functions that are included in the hwxjpn module.

Function
HwxALCPriority HwxInput
HwxALCValid HwxProcess
HwxConfig HwxResultsAvailable
HwxCreate HwxSetAbort
HwxDestroy HwxSetContext
HwxEndInput HwxSetGuide
HwxGetResults HwxSetPartial
