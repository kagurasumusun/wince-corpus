httpextn Component

The httpextn component supports ISAPI extensions.

Functions for Application Developers

The httpextn component includes functions for application developers, which are defined in the Httpext.h header file. To import these functions, you must link to the Httpextn.lib file. The following functions are included in the httpextn component:

  • GetServerVariable
  • ReadClient
  • ServerSupportFunction
  • WriteClient
