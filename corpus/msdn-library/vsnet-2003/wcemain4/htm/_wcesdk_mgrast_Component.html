mgrast Component

The mgrast component supports a raster font engine.

Functions for Application Developers

The mgrast component includes functions for application developers, which are defined in the Wingdi.h header file. To import these functions, you must link to the mgrast.lib file. The following functions are included in the mgrast component:

  • AddFontResource
  • CreateFontIndirect
  • ExtTextOut
  • GetTextExtentExPoint
  • GetTextMetrics
  • RemoveFontResource
