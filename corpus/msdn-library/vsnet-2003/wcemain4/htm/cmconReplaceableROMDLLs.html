Replaceable ROM DLLs

A DLL stored in the RAM file system can override its ROM equivalent, even if another module is statically linked to the ROM DLL. Applications that had previously used GetProcAddress to get around a static link limitation in previous versions of Windows CE can now statically link to any DLL. If you overwrite a statically linked ROM DLL with a RAM DLL, you may see exceptions related to the RAM DLL during debugging. The debugger was designed to include these exceptions; they will have no effect on your application's execution.
