CEPC Based SDB Recommended Hardware

Windows CE will work with most x86 SDBs using any of the motherboards and microprocessors shown in the following table.

Hardware component Supported
Motherboard Any newer x86
Microprocessor P5, PII, PIII, Pentium 4, Celeron, K6x, K7, Athlon, Duron

The following table shows the required products to build a PC based SDB.

Required product Description
Case Enlight, Supercase, Jumbo, and so on. Mini ATX Mid Tower Case 250W, 300W for Pentium 4 and Athlon/Duron.
Memory 32 MB PC100/133 3.3v, 64 MB recommended.
Video card 3D Labs Oxygen VX1, TVIA CyberPro 5050, and any VESA 2.0 compatible card.
Debug Ethernet card for Ethernet downloading and Ethernet debugging CEPC-based SDBs support any NE2000 or SMC9000 compatible debug Ethernet cards, National Semiconductor DP83815 (NetGear FA-312), and RealTek RTL8139.
Other 3.5-inch 1.44mb floppy disk, heat sink, and fan.

The default display driver is the FLAT driver. The FLAT driver works with any video card that has a VESA video BIOS, VBE 2.x or later. Many of the latest video cards support VBE 2.x by default and work with the FLAT driver.

To verify if your video card works with the FLAT driver, use Vesatest.exe. Vesatest.exe is on the CEPC boot floppy. Vesatest.exe detects if your video hardware supports VBE 2.x, and what video modes the card supports.

When you boot your PC based SDB, choose Run the VESATEST option or boot to the MS-DOS prompt and manually run Vesatest.exe.

The following list shows the video cards that are tested to work with the FLAT:

  • ATI Rage Fury
  • ATI Expert2000
  • ATI RagePro
  • ATI Expert98
  • ATI XL series
  • Diamond Stealth S540
  • Number Nine SR9
  • Creative Labs TNT2 and TNT2 Ultra
  • Diamond Viper V770 and V770 Ultra
  • Voodoo3 2000 and 3000 series
  • Matrox G400 and G200 series
  • 3D Labs Oxygen VX1
  • Latest versions of the S3 Virge GX, GX/2, VX cards.

Some older model video cards such as the ATI Mach32/64, S3Trio64, Cirrus Logic 5434, and older versions of the S3 Virge or S3 Virge DX do not support VBE 2.x, so these cards will not work with the FLAT driver. To use these cards, include either the VGA8BPP or the S3Virge display driver in the OS image which is available at this Microsoft Web site.
