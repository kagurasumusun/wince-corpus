FORMAT_OPTIONS

This structure contains options specified by clients of format disk.

typedef struct _FORMAT_OPTIONS {
DWORD dwClusSize;
DWORD dwRootEntries;
DWORD dwFatVersion;
DWORD dwNumFats;
BOOL  fFullFormat;
} FORMAT_OPTIONS;

Members

dwClusSize
Desired cluster size in bytes, must be power of 2.
dwRootEntries
Desired number of root directory entries
dwFatVersion
FAT Version. Either 12, 16, or 32.
dwNumFats
Number of FATs to create.
fFullFormat
TRUE if full format requested.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Formatdisk.h Formatdisk.h
