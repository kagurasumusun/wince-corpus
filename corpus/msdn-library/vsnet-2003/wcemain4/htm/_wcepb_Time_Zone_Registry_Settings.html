Time Zone Registry Settings

The following registry value is used while the target device is running.

[HKEY_LOCAL_MACHINE\Time]
    "TimeZoneInformation": (REG_BINARY): TIME_ZONE_INFORMATION (structure)

The following registry value is used during a cold boot.

[HKEY_LOCAL_MACHINE\Time Zones]
    "@": REG_SZ

The default data value of the Time Zones subkey is the name of a standard time zone used as the default time zone for the system during a cold boot. This value is used if the TIME_ZONE_INFORMATION structure is not available. The name of the time zone corresponds to one of the following additional time zone entries that are used to provide information for a specified time zone.

[HKEY_LOCAL_MACHINE\Time Zones\Standard time zone name]
    "TZI": REG_BINARY
    "Dlt": REG_SZ

The standard time zone name registry key corresponds to the StandardName member of the TIME_ZONE_INFORMATION structure. Therefore, the same rules and conditions that apply to the structure apply to this registry key. For each time zone in the world you can create a separate entry in the registry. See the Wceshellfe.reg file in the WCESHELL project for details on these registry entries.

The following code example shows the structure for the TZI registry data value, which corresponds to the TIME_ZONE_INFORMATION structure.

typedef struct tag TZREG {
LONG Bias;
LONG StandardBias;
LONG DaylightBias;
SYSTEMTIME StandardDate;
SYSTEMTIME DaylightDate;
} TZREG;

The Dlt registry value is the name used for daylight time. This value corresponds to the DaylightName member of the TIME_ZONE_INFORMATION structure. Therefore, the same rules and conditions that apply to the structure apply to this registry value.

A call to the GetTimeZoneInformation function retrieves the TIME_ZONE_INFORMATION structure. The data in the TIME_ZONE_INFORMATION structure provides the information that the function returns. If the structure is not found, then the @ data value of the Time Zones subkey, which is the default value, is retrieved. If this value is missing, then the Pacific Time Zone is used.

A call to the SetTimeZoneInformation function sets the registry data value TimeZoneInformation to the TIME_ZONE_INFORMATION structure passed into the API. In addition, the NOTIFICATION_EVENT_TIME_CHANGE notification event is triggered.

When the OS boots, Filesys.exe makes a call to the GetTimeZoneInformation function to set time zone information for the OS.
