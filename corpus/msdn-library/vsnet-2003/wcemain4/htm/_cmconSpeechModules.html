Speech Modules

The speech modules provide support for the Speech API (SAPI) Version 5.0. The following table shows the SAPI modules.

Module Description Note Library
sapi Provides core support for the Speech API. Exposes the SAPI interfaces. sapi.lib
sapisvr Provides shared speech COM interfaces. Exposes no public functions or interfaces. sapisvr.lib
spcommon Supports elements that are common to both text-to-speech and speech recognition engines. Exposes no public functions or interfaces. spcommon.lib
sreng Supports the null speech recognition engine, which converts voice input into a text string. Exposes no public functions or interfaces. sreng.lib
ttseng Supports the null text-to-speech engine, which converts a text string into speech. Exposes no public functions or interfaces. ttseng.lib
