Japanese Pocket IME

Microsoft® Windows® CE .NET supports the Japanese Pocket Input Method Editor (IME) version 2.0. An IME is a program that allows users to enter complex characters and symbols, such as Japanese Kanji characters, by using a standard keyboard. Pocket IME is a small-size IME that can support embedded systems without keyboards that have small screens and a minimum memory footprint.

For version 2.0, the architecture of Pocket IME has been redesigned to provide more options for OEMs to customize an IME for a Windows CE–based platform. Pocket IME 2.0 also provides an improved integration of input methods (IMs) that provides optimum handling of character input on keyboard-less devices.

Pocket IME 2.0 supports the following new features:

  • The Pocket IME 2.0 kernel conversion module exposes interfaces that allow you to write your own UI component. Windows CE provides the Pocket IME user interface as a sample source code so that you can create a customized version. For more information, see Pocket IME UI Source Code Files.
  • Pocket IME provides a Dictionary Compiler that allows you to create a customized system dictionary.
  • Pocket IME includes a conversion engine that supports a Registry Settings for User Dictionary and word registration. The word registration feature allows users to register user-defined words.
  • Pocket IME 2.0 provides support for multiple dictionaries. For more information, see Multiple Dictionary Support.
  • Pocket IME 2.0 includes new registry settings through which you can configure the default behaviors of a Windows CE–based platform. These settings remain effective when the user warm boots a device.
  • The UI of Pocket IME 2.0 supports user input through an input panel and through a mouse and stylus. You can also customize the UI behavior for user input. For more information, see Working with the Input Method Editor and Programming a Software-Based Input Panel.
