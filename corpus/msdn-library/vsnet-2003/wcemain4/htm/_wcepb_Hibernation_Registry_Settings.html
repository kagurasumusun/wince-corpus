Hibernation Registry Settings

The following registry settings allow you to define the point at which the system enters a limited-memory state. The H/PC shell uses the following registry settings.

[HKEY_LOCAL_MACHINE\SYSTEM\Hibernate]
    "Bytes"=dword:20000
    "Pages"=dword:28
