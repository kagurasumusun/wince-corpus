Display Hardware

You must provide a video display for all Windows Thin Client devices. The following list shows minimum display requirements:

  • Windows Thin Client devices must support a minimum of 8 bits per pixel (BPP).

    Windows CE supports pixel depths from 1 BPP to 32 BPP. Windows Thin Client supports 8 BPP, 16 BPP, and 24 BPP.

    Because 24 BPP color requires significant memory and CPU resources, it is only used when the resolution is 640 x 480 or smaller.

  • Windows Thin Client devices must support a minimum resolution of 640 x 480 pixels at 8 BPP.

    Windows Thin Client must support at least a 640 x 480-pixel resolution. The Windows Thin Client software supports desktop resolutions that run at 640 x 480, 800 x 600, 1024 x 768, 1280 x 1024, and 1600 x 1200 pixels.

    Windows Thin Client devices must include video hardware that supports acceleration.

For best video performance, your device hardware should use hardware-accelerated graphics.
