Downloading the NEC DDB-Vr4122 (Eagle) SDB Boot Loader to Flash

  1. Turn off the NEC DDB-Vr4122 (Eagle) SDB.
  2. Move all the DIP switches in S1 to the Off position and turn on the NEC DDB-Vr4122 (Eagle) SDB.

    This will run the persistent system Eboot program.

    Once the system is restarted, the Ethernet boot loader is downloaded just like a standard OS image.

  3. From the Build menu in Platform Builder, choose Open Build Release Directory to open a command prompt.
  4. Type kshell at the command prompt, and then choose the device name that was displayed over the serial port as follows.

    Device name: <DEVICE>

  5. Choose Eboot.bin as the image to download to the NEC DDB-Vr4122 (Eagle) SDB.

    The download will start.

  6. Download the OS image to the NEC DDB-Vr4122 (Eagle) SDB.
