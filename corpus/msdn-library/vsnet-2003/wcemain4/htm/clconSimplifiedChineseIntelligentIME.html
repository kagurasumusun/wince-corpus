Simplified Chinese Pinyin IME

Microsoft® Windows® CE .NET supports the Microsoft Pinyin (MSPY) Input Method Editor (IME) 2.0 for Simplified Chinese. The MSPY IME uses an intelligent, bigram-based language model. It is a sentence-based input method. When you use MSPY 2.0, you can select any one of three lexical databases. There are slight progressive differences in conversion accuracy between the three databases that correspond to their differences in size. That is, larger databases offer higher accuracy.

Windows CE does not provide source code for the MSPY IME.
