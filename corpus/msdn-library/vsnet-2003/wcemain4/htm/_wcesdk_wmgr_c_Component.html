wmgr_c Component

The wmgr_c component implements the window manager.

Functions for Application Developers

The wmgr_c component includes functions for application developers, which are defined in the Winuser.h header file. To import these functions, you must link to the Wmgr_c.lib file. The following table shows the functions included in the wmgr_c component.

Function
EnableWindow mouse_event
GetClassInfo RegisterClass
GetMouseMovePoints SendInput
GetSysColor UnregisterClass
IsWindowEnabled
