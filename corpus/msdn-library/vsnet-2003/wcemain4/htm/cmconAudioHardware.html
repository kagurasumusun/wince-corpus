Audio Hardware

The Remote Desktop Protocol version 5.1 supports audio playback redirection. This means that a server application has the capability to playback at the server or client audio output hardware. Audio output hardware, therefore, is a recommended feature for Windows Thin Client devices.

  • Audio-output hardware, if it is present, must meet minimum Windows Thin Client device requirements.

    Windows Thin Client devices that support audio must support the playback of 8-bit, monophonic ("Mono"), and pulse-coded modulation-formatted audio files.

    The minimum requirements for audio output are the following:

    • The Windows Thin Client device must have a single channel, 8-bit D/A converter.
    • The Windows Thin Client device must have a 22.05 KHz sampling rate.
    • For better results, upgrade to 16 bits per sample and 44.1 KHz sample rate.
