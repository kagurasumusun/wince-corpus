MUI Locale Considerations

The system default locale selects certain aspects of the system that may not be fully switchable later. For example, the system selects the Input Method Editor (IME) for East Asian locales, and may also use special versions of some applications and system modules, default fonts, and so on.

Hence, it may not be possible to build a system that is fully switchable between certain languages, particularly between multiple East Asian languages, such as between Chinese, Japanese, and Korean. For example, the edit control supports one East Asian language at a time.

Therefore, it is easiest to build a device to switch between related languages especially languages that share a single code page, such as the 1252 code page shared by most western European languages.

It may be possible to build a device that switches between a single East Asian locale and one or more non-Asian locales, such as a device that supports Japanese and English. However, the default UI language must be the East Asian locale. For example, if a user switches the UI from Japanese to English, the code base that supports the Japanese IME is still available, even if it is not visible in the new language.

Registry Content

Special consideration must also be given to localizable content that is typically handled in the registry, as in the case of the Handheld PC (H/PC) shell. Locale content that is set in the registry is not switchable. The values are set when the device boots, and are fixed afterward. This implies that folders and desktop icons such as the "Recycle Bin" and "My Computer" will not switch to the new UI. Moreover, some dependencies may exist between registry entries and .res file resources. If the same item is referenced in the registry and the .res file, the localization results may impact functionality.

If you create a custom shell for your target device and want to use an MUI, you can ensure that no localized resources are set in the registry.

The following UI-specific resource identifiers in ceshell.res must match the default system language:

  • 37122 - Start Up
  • 37123 - Recent
  • 37124 - Favorites
  • 36930 - Fonts
  • 36932 - Desktop
  • 36933 - My Documents

Default UI Value

Note   If your device uses a Control Panel, you can determine the default UI locale using the Regional Settings dialog box. On a system that has no UI components installed, the system shows the default UI value.

Because the Regional Settings dialog box does not currently include a user notification message for the required reset, you will need to display a message to the user prompting a reset. For example, once an end-user has selected a language, you can create a Message Box to indicate that a system reset is required.
