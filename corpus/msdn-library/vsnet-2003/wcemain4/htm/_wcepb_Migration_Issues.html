Migration Issues

Most operating system (OS) components and applications that were developed for Microsoft® Windows® CE version 3.0 and earlier will also run on Windows CE .NET. However, some changes within the new OS may cause your component or application to fail. The following topics address issues that arise while migrating platforms and applications from Windows CE 3.0 or 2.12 to Windows CE .NET:

  • Migration from Windows CE 3.0 to Windows CE .NET
  • Migration from Windows CE 2.12 to Windows CE .NET

If you based your platform on one of the Windows CE 3.0 sample platforms and you want to migrate it to Windows CE .NET, see Migration Map.
