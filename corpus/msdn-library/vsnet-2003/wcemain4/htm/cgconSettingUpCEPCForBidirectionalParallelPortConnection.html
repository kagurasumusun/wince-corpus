Setting Up a CEPC for a Bidirectional Parallel Port Connection

  1. Reboot the CEPC, and then start the BIOS ROM setup utility.

    Usually, you need to press certain keys, such as ALT and F1, or DELETE, immediately after rebooting to start the BIOS ROM setup utility. However, some PCs require a setup utility disk to make changes to the CMOS memory.

  2. Verify that the parallel port I/O port address is set to 378H.

    This is the default address for the Ppshell.sys driver. If another device is using this address, select an available port address and note its value; 278H is a good second choice.

  3. Verify that the parallel port IRQ is set to 7; this is the default IRQ setting for the Ppshell.sys driver.

    If another device is using this IRQ, select an available IRQ and note its value. It is common to assign IRQ 7 to port address 378H and IRQ 5 to port address 278H.

  4. Verify that the parallel port mode is set to Bidirectional.

    For many desktop computers, the default mode for the parallel port is Normal. The bidirectional mode may be called Enhanced, EPP, or something else, depending on the desktop computer.

    Note   Some desktop computers offer PS/2 or AT as the choices for bidirectional mode. In this case, you should add an ISA-based card that is EPP-compatible, so you can set the jumpers manually. A PCI-based EPP-compatible card is not recommended because resources might be remapped when the system boots.
  5. Save the changes, and then exit the BIOS ROM setup utility.

    The CEPC automatically reboots. If the CEPC has an AMIBIOS, turn off the CEPC for two minutes after saving the changes to ensure that the changes take effect.

  6. Install the custom parallel port cable between the development workstation and the CEPC.
  7. Create a boot disk.

When you boot the CEPC, choose 3. Boot CE/PC (parallel direct) from the menu of boot options.
