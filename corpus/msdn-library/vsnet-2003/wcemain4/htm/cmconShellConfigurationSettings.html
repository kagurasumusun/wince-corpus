Shell Configuration Settings

The registry settings that are used to configure the Windows Thin Client Shell are set in the subkey HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Shell. The following table shows the named values.

The following entry names are used to configure the shell; they are not required:

Value Description
ConnectionDefaultKey: REG_SZ No default setting. The ConnectionDefaultKey value specifies the connection key for the default connection.

This value is optional.

ConnectionDefaultType: REG_SZ No default setting. The ConnectionDefaultType entry specifies the connection type for the default connection. It must specify the name of the registered client entry. This entry name must not be confused with the Type entry of a registered client.

This value is optional. .
DisableConfigureTab: REG_DWORD Default setting is 0 in Project.reg. The DisableConfigureTab entry specifies whether the Configure tab on the connection manager is present. If the value for this entryis greater than 0, then the Configure tab is not present. If this value is 0, then the Configure tab is present.

This value is optional.

EnableAutoConnect: REG_DWORD Default setting is 0 in Project.reg. The EnableAutoConnect entry specifies whether the shell must start the default connection automatically. If this value is greater than 0, then the default connection starts automatically. If this value is 0, then the default connection does not start automatically.

This value is optional.

EndTaskWaitTime: REG_DWORD Default setting is 10,000. The EndTaskWaitTime entry specifies the amount of time, in milliseconds, that the shell waits after the End button has been clicked before prompting the user either to Wait, EndTask, or Cancel if the process has not ended already.

This value is optional.

SetupExe: REG_SZ Default setting is Wbtsetup.exe in Project.reg. The SetupExe entry specifies the name of the Setup Properties Sheets executable file.

This value is optional.

SetupCmdLine: REG_SZ No default setting. The SetupCmdLine entry specifies the command-line parameters to pass to the program that is specified by SetupExe.

This value is optional.

TaskmanTitle: REG_SZ Default setting is "Terminal Connection Manager" in Project.reg. The TaskmanTitle specifies the text to display in the title bar of the Connection Manager. You can name the connection manager by using this registry value. However, the name must end with the words "Connection Manager".

This value is optional however, an entry must be set to avoid an undesirable default value.
