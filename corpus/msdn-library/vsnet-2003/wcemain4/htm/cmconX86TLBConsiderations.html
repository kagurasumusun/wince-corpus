x86 Translation Look-aside Buffer Considerations

For security reasons the kernel will flush the x86 translation look-aside buffer (TLB) when required. The bit 0x00000020 of ROMFLAGS will prevent this from happening but will enable a security hole. If real-time performance is required without any security concerns, then this flag should be set.
