NEC DDB-Vrc5476 (Boston) SDB Hardware Restrictions

If you are using the MQ200 display card, be sure that switch S1 on the MQ200 is set to the DOWN position or the MQ200 will not function correctly.

The NEC DDB-Vrc5476 (Boston) SDB supports the following video cards:

  • ATI
  • MQ200
  • TVIA5000
  • Permedia 3

The NEC DDB-Vrc5476 (Boston) SDB supports Ethernet debugging, and Ethernet image download.

The NEC DDB-Vrc5476 (Boston) SDB requires a network connection and a serial connection. The network connection handles most of the communication between the development workstation and the NEC DDB-Vrc5476 (Boston) SDB. The serial connection monitors the setup process.
