Editing Autoexec.bat

Because you can use either an ISA-based or a PCI-based Ethernet card, you must verify that Autoexec.bat on the boot disk is set up correctly for the debug Ethernet card you have chosen.

The following shows example syntax for LoadCEPC.exe. Note the : between %NET_IOBASE% and %NET_IRQ%.

loadcepc /b:38400 /v /e:1:%NET_IOBASE%:%NET_IRQ% %RES% eboot.bin
Note   If you use the /D switch to specify the display mode, you cannot use the DDI_FLAT driver.

The following table shows how to edit Autoexec.bat for an ISA-based Ethernet network card.

Code example Description 
set NET_IRQ=5
set NET_IOBASE=340
set NET_IP=
 Change lines 20 through 22 as shown if you are using an ISA-based debug Ethernet card, for example, Linksys Ether16 LAN card, model number LNE2000, and a DHCP server. A DHCP server provides IP addresses automatically in the network environment, so the NET_IP flag should be left blank. 
set NET_IRQ=5
set NET_IOBASE=340
set NET_IP=<valid IP address>
 Change lines 20 through 22 as shown in if you are using an ISA-based debug Ethernet card, for example, a Linksys Ether16 LAN card, model number LNE2000, without a DHCP server.

An example of a valid IP address is 151.128.1.10; however, use an IP address that is valid for your network environment. Use the subnet mask that applies to the development workstation, and obtain an unused IP address from your network administrator.

In both of these code examples, the IRQ parameter is set to 5 and the I/O base address is set to 340. You must use the network utilities provided by the card manufacturer to manually set these parameters on the ISA-based Ethernet network card.

The following table shows how to edit Autoexec.bat for a PCI-based Ethernet network card.

Code example Description 
set NET_IRQ=0

set NET_IOBASE=0
set NET_IP=
Include this command prompt in Autoexec.bat if you are using a PCI-based debug Ethernet network card, for example, the Kingston EtherRx Client PCI Ethernet Adapter, model number KNE30T or KNE30BT, and a DHCP server. A DHCP server provides IP addresses automatically in the network environment, so the NET_IP flag should be left blank. 
set NET_IRQ=0

set NET_IOBASE=0
set NET_IP=<valid IP address>
Include this command prompt in Autoexec.bat if you are using a PCI-based debug Ethernet network card, for example, the Kingston EtherRx Client PCI Ethernet Adapter, model number KNE30T or KNE30BT, and a static IP address, without a DHCP server.

An example of a valid IP address is 151.128.1.10; however, use an IP address that is valid for your network environment. Use the subnet mask that applies to the development workstation, and obtain an unused IP address from your network administrator.

In both of these code examples, the IRQ parameter is set to 0 and the I/O base address is set to 0. Eboot.bin automatically finds the first available network card, reads the I/O base address and IRQ of the card, and then uses the correct address for network operation. Therefore, it is not necessary to manually set the configuration parameters on the Ethernet network card, as is the case when you use an ISA-based Ethernet network card. If NET_IRQ is set to a non-zero value, Eboot.bin will find the network card with the corresponding IRQ. This is useful in systems with multiple network cards.

The parameter 1 in /e:1 in these code examples signifies the type of network card used for the CEPC. Because only a NE2000-compatible Ethernet network card is supported if you are using the recommend hardware components and configurations for the CEPC, this parameter must always be set to 1.

Note   When Autoexec.bat is created on the boot disk; it is configured by default to be used with the Linksys Ethernet network card and a DHCP server.
