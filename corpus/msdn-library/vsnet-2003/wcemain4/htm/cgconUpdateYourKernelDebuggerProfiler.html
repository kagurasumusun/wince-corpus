Microsoft Windows CE .NET  

Update your Kernel, Debugger, and Profiler

  1. Use the new Kernel libraries and directories.

    The debugger is no longer statically linked into the kernel. The kernel's Withkd.exe and Profkd.exe are obsolete and can be deleted. The following list shows the new kernels built in Windows CE .NET:

    • Kitlnokd.exe is now renamed to kernkitl.exe.
    • Nkprof.exe is renamed to kernkitlprof.exe.
    • Kern.exe is a new kernel, which is built without KITL support, has been added.

    The following changes are required in your BSP to account for the new kernels. See the CEPC platform for examples.

    • %_TARGETPLATROOT%\Kernel\Buildexe\Dirs should contain the 3 new directory names, kern, kernkitl and kernkitlprof.
    • The old directories nokd and profiler should be renamed to kernkitl and kernkitlprof, respectively. The sources files in each of these directories should be modified to have TARGETNAME = kernkitl and TARGETNAME = kernkitlprof, respectively.
    • Add a new kern directory to build a kernel without KITL support. See the CEPC platform for an example. The Kitlstub.c file stubs out functions normally found in Halether.c and Halkitl.c in %_TARGETPLATROOT%\Kernel\Hal in order to have them removed in the link process.
  2. Use the new Profilers.
