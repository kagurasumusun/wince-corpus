msgqueue Component

Th msgqueue component supports message queue operations.

Functions for Application Developers

The msgqueue component includes functions for application developers, which are defined in the Msgqueue.h header file. To import this function, you must link to the Msgqueue.lib file. The following functions are included in the msgqueue component:

  • CloseMsgQueue
  • CreateMsgQueue
  • GetMsgQueueInfo
  • OpenMsgQueue
  • ReadMsgQueue
  • WriteMsgQueue
