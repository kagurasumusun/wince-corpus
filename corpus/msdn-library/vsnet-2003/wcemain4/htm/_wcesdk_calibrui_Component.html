calibrui Component

The calibrui component implements the UI for calibration. This component is responsible for drawing the various screens used when calibrating the touch screen.

Functions for Operating System Developers

The calibrui component includes functions for OS configuration, which are defined in the ClaibrUi.h header file. The following functions are included in the calibrui component:

  • TouchCalibrateUI_Done
  • TouchCalibrateUI_DrawConfirmationScreen
  • TouchCalibrateUI_DrawMainScreen
  • TouchCalibrateUI_HandleUserInputMessage
  • TouchCalibrateUI_Initialize
  • TouchCalibrateUI_WaitForConfirmation
