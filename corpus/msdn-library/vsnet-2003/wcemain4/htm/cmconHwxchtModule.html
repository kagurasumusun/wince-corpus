hwxcht Module

The hwxcht module provides support for Chinese Traditional handwriting input.

Functions for Application Developers

The hwxcht module contains functions for application developers, which are defined in the Recog.h header file. To import these functions, you must link to the hwxcht.lib file. The following table shows the functions that are included in the hwxcht module.

Function
HwxALCPriority HwxInput
HwxALCValid HwxProcess
HwxConfig HwxResultsAvailable
HwxCreate HwxSetAbort
HwxDestroy HwxSetContext
HwxEndInput HwxSetGuide
HwxGetResults HwxSetPartial
