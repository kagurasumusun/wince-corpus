coresip Component

The coresip component provides input-panel support.

Functions for Application Developers

The coresip component includes functions for application developers, which are defined in the Sipapi.h header file. To import these functions, you must link to the coresip.lib file. The following table shows the functions included in the coresip component.

Function
SipEnumIM SipSetDefaultRect
SipGetCurrentIM SipSetInfo
SipGetInfo SipShowIM
SipRegisterNotification SipStatus
SipSetCurrentIM
