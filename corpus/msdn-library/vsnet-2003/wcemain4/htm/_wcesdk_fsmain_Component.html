fsmain Component

The fsmain component supports the Windows CE object store.

Functions for Application Developers

The fsmain component includes functions for application developers, which are defined in the Winbase.h header file. To import these functions, you must link to the fsmain.lib file. The following table shows the functions included in the fsmain component.

Function
CopyFile FlushFileBuffers
CreateDirectory GetDiskFreeSpaceEx
CreateFile GetFileTime
DeleteAndRenameFile MoveFile
DeleteFile ReadFile
DeviceIoControl RemoveDirectory
FindFirstFile SetEndOfFile
FindFirstFileEx SetFileTime
FindNextFile WriteFile
