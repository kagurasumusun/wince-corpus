Terminal Services

The Terminal Services system consists of the following components:

  • Terminal Server

    Terminal Server itself consists of one or more of the following servers:

    • Microsoft® Windows NT® Server version 4.0
    • Terminal Server Edition (Terminal Server)
    • Microsoft Windows® 2000 Server, or Windows XP Professional
  • Remote Desktop Protocol (RDP)
  • Windows Thin Client

    Windows Thin Client itself consists of one or more of the following technologies:

    • Device hardware running the Microsoft Windows CE .NET operating system (OS)
    • Terminal Services client and the Remote Desktop Protocol (RDP)
    • In the case of Windows-based Terminals, optional third-party emulators and presentation protocols

RDP, Citrix Independent Computing Architecture (ICA), and the optional third-party emulators and presentation protocols allow two-way communication between a Terminal Server and its related clients.

For more information about Citrix ICA see the Frequently Asked Questions document (wbtfaq.doc) and the ReadMe file (readmewbt.txt) located in the %_WINCEROOT%\Public\Rdp\Ica directory.
