msmqrt Module

The msmqrt module supports the main Message Queuing run-time API set.

Functions for Application Developers

The msmqrt module includes functions for application developers, which are defined in the Mq.h header file. To import these functions, you must link to the Msmqapix.lib file. The following table shows the functions that are included in the msmqrt module.

Function
MQCloseCursor MQGetQueueProperties
MQCloseQueue MQHandleToFormatName
MQCreateCursor MQOpenQueue
MQCreateQueue MQPathNameToFormatName
MQDeleteQueue MQReceiveMessage
MQFreeMemory MQSendMessage
MQGetMachineProperties MQSetQueueProperties
