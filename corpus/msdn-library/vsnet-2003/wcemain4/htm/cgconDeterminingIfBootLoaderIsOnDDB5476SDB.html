OEM Boot Loader Output for the NEC DDB-Vrc5476 (Boston) SDB

The following is the OEM boot loader output.

DDB 5476 Boot Monitor
NEC Electronics Inc 
DDB 5476 rev 2.2 
Revision Date      : Jan 20 2000


>

If you type an h at the > prompt, you see the following.

Available functions: 
[L] Download the S record file to Flash 
[E] Erase entire Flash 
[D] Read and Display Memory 
[T] Run Tests on 5476 card 
[I] Print identification information 
[B] Select the Baudrate 
[F] Download the BootLoader to Flash 
[W] List PCI Devices 
[X] Run Microsoft CPCI Test 

>

The following message appears if you use a PCI card that requires a lot of PCI memory resources.

>  Not enough memory space allocated for PCI Bus
Error: Failed to initialize PCI bus devices.
