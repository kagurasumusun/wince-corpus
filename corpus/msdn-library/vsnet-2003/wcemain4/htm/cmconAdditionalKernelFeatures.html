Additional Kernel Features

In addition to the core kernel features of Windows CE, the kernel contains several other features. Some of these features include allowing the system developer to turn off hardware floating point support for the x86 processor family, the ability to save and restore coprocessor registers from multiple coprocessors, date handling functions, and have the entire system placed into a state called full kernel mode, which allows all threads to run in kernel mode.

For more information about these additional kernel features, see the following topics:

  • Floating Point Emulation for x86
  • Implementing Save and Restore Coprocessor Register Support
  • Two-Digit and Four-Digit Dates
  • Full-Kernel Mode
