accel_c Component

The accel_c component provides client-side support for user accelerator tables.

Functions for Application Developers

The accel_c component includes functions for application developers, which are defined in the C_accel.h header file. To import these functions, you must link to the accel_c.lib file. The following functions are included in the accel_c component:

  • CreateAcceleratorTable
  • DestroyAcceleratorTable
  • LoadAccelerators
