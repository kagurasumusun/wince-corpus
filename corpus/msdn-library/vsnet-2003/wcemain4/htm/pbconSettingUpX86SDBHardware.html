Setting Up the x86 SDB Hardware

In addition to the following instructions, refer to the hardware manual provided by the OEM or independent hardware vendor (IHV) with the x86 SDB. Details, such as the type of the connector, port, cable, and so on, are specific for each board and are explained in the hardware manual. Depending on the x86 SDB, you might have to use a display card, an Ethernet card, or connect a VGA monitor to the device.

  1. From the serial port on the x86 SDB, connect a serial cable to a serial port on your development workstation.

    This is required for receiving messages with HyperTerminal.

  2. From the x86 SDB, connect an Ethernet cable to an Ethernet port that uses the same subnet as the development workstation.
    Note   If you are using the National Geode SP4SC30 Development Platform, use the 3.3V Netgear (National Semiconductor DP83815) network card provided with the system.
  3. Using a ribbon or appropriate cable, connect a floppy disk drive to the x86 board. A floppy drive is required to download the OS image from the development workstation to the x86 SDB.

    - or -

    If you are using the National Geode SP4SC30 Development Platform, insert the CF card into the CF reader.

  4. Connect a keyboard and mouse to the x86 SDB.
    Note   If you are using the National Geode SP4SC30 Development Platform, the keyboard and mouse connect to a proprietary plug-in card inside of the chassis.
  5. Connect a power cable to the x86 SDB and to a surge-protected power socket, and then turn on the x86 SDB.
