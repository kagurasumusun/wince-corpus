Intel DBPXA250 Development Platform for XScale PXA250 Application Microprocessors Hardware Restrictions

The following list shows the hardware that is not supported:

  • Suspend/Resume
  • USB host
  • IrDA
  • BT Serial Port, this is the UART closest to the back of the board, labeled BT SERIAL

Intel DBPXA250 Development Platform for XScale PXA250 Application Microprocessors Hardware Restrictions

XScale performance can be improved by changing the Branch Target Buffer Enable bit. To enable this, have the OAL change the bit in OEMInit. The branch target buffer enable bit is bit 11 of the ARM control register.
