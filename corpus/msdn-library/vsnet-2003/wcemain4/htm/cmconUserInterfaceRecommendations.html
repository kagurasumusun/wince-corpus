User Interface Recommendations

The Windows Thin Client user interface (UI) consists of the Windows Thin Client Shell, the Windows Thin Client Setup Wizard and Properties Sheets, and client software helper applications. The following list contains recommendations for the Windows Thin Client UI:

  • The Microsoft Windows Thin Client Shell must be included.
  • Ensure the Windows Thin Client Shell follows hot-key guidelines, and that hot-key support is enabled.
  • Include a Setup wizard that runs the first time that a Windows Thin Client is turned on.

The Windows Thin Client UI must include the Properties Sheets to change terminal settings after the Setup wizard has performed the initial configuration.
