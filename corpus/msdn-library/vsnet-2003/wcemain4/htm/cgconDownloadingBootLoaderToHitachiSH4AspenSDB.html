Downloading the Boot Loader to the Hitachi US7750 HARP (Aspen) SDB to Flash

Before downloading the Ethernet boot loader, determine if the boot loader is on the Hitachi US7750 HARP (Aspen) SDB. For more information, see OEM Boot Loader Output for the Hitachi US7750 HARP (Aspen) SDB.

  1. Turn off the Hitachi US7750 HARP (Aspen) SDB.
  2. Move DIP switch S1-1 and S1-4 to the On position, and turn on the Hitachi US7750 HARP (Aspen) SDB.

    This will run the boot monitor.

  3. Once the system is restarted and DIP switch S1-1 is in the On position, the following message appears in HyperTerminal: 
    Cold Reset 0x0
Hitachi SH4 Aspen SH4 Monitor 5.04
Hitachi Semiconductor (America), Inc.
Little-endian BOOT from ROM at 0x0FFE0000
DMON>
  4. Type ppsh at the DMON> command prompt.
  5. From the Build menu in the Platform Builder IDE, choose Open Build Release Directory.
  6. Type cesh eboot.bin at the command prompt in the Build Release Directory to download the Windows CE boot loader. Output of the following format will appear. 
    Ready to down load BIN file.
Image start 80000000h length 21084h.
        Erased successfully.   Image going to FLASH.

Vaddr=0x80021074, cbRecord=0x10, checksum=0x40E
Vaddr=0x80000000, cbRecord=0x10, checksum=0x303
Vaddr=0x8001F484, cbRecord=0x154, checksum=0x2289
Vaddr=0x0, cbRecord=0x80000004, checksum=0x0
Done....
Download successfull!
DMON>
  7. Turn off the Hitachi US7750 HARP (Aspen) SDB.
  8. Move DIP switch S1-1 and S1-4 to the Off position so the Windows CE boot loader executes from flash memory after reset.
  9. Restart the system and you will see the Windows CE boot loader auto boot messages. The following is an example of the Windows CE boot loader message.
