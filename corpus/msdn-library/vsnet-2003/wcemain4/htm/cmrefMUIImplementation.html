MUI Implementation

The MUI includes resources for each supported UI language, separated from their binaries, and provided in separate language directories. To achieve the goal of user-switchable language in a specific Microsoft® Windows® CE .NET–based device, the device must have the locale data, code pages, and fonts for all the UI languages to be supported. These are configured when the device ROM image is created or can be added later.

In addition, you must set any needed operating system UI resources in ROM, such as the localized resources for the default language. Additional languages can be included in the device ROM image, or potentially installed later.

The following steps show how to implement a multilingual UI.

  1. Select the Multiple Language Support catalog feature. For more information, see APIs for MUI.
  2. Create the MUI Modules. For more information, see MUI Module Creation.
  3. Build a multilingual ROM image. For more information, see Multilingual ROM Image.
