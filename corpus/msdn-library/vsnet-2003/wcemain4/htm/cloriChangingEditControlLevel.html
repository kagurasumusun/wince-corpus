Changing the Edit Control Level

You can change the level of the Japanese Edit Control feature by specifying a value for the Imelevel registry key.

The following table shows the registry settings for HKEY_LOCAL_MACHINE\SYSTEM\GWE\EDIT.

Registry key Type Value Description
Imelevel DWORD 3 Sets the Japanese Edit Control to level 3.
Imelevel DWORD Default setting or a value unequal to 3. Sets the Japanese Edit Control to level 2.
