Pointing Device

You must provide the Windows Thin Client device with a pointing device for user input, typically a mouse or a touch screen. The following list defines the requirements for the pointing device:

  • The pointing device must emulate mouse movement and button events.

    The Microsoft Windows NT Server 4.0, Terminal Server Edition, and Windows 2000 application software requires that any pointing device must correctly emulate mouse events. Specifically, mouse-movement events must be separate and independent of button events.

  • The pointing device must support minimum coordinate resolution.

    Any pointing device that is implemented must provide coordinates to a minimum of pixel resolution.

  • The pointing device must support minimum sampling rates.

    The pointing device must provide a minimum of 100 samples per second at regular intervals.

  • The pointing device must support minimum bits per sample to provide accurate coordinate resolution.

    The pointing device must provide resolution with enough bits per sample to provide a minimum of per-pixel coordinate accuracy.

  • The pointing device must provide per-sample interrupts.
  • Pointing device filtering and calibration must be supported for devices that require these capabilities for proper functionality.

    Touch screens and glide pads require filtering to remove erroneous samples that are caused by noise. Touch screens require a method to calibrate them properly to their displays. This calibration can be done with either hardware or software.
