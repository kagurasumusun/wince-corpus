datasync Modules

The datasync module group includes modules that support data synchronization between a Windows-based desktop computer and Microsoft® Windows® CE–based portable devices.

The following table shows the modules that the datasync module group contains.

Module Description Note Library
cefobj Supports file synchronization. Exposes no public functions. Cefobj.lib
eventrst Supports base synchronization. Exposes no public functions. Eventrst.lib
pegobj Supports e-mail and personal information manager (PIM) synchronization. Exposes no public functions. Pegobj.lib
rapisrv Supports base synchronization. Exposes no public functions. Rapisrv.lib
rra_stm Supports base synchronization. Exposes no public functions. Rra_stm.lib
systemcpl Supports base synchronization. Exposes no public functions. Systemcpl.lib
udp2tcp Implements the User Datagram Protocol (UDP) to TCP client. Exposes no public functions. Udp2tcp.lib
