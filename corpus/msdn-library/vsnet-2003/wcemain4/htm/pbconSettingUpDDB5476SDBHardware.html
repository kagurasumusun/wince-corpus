Setting Up the NEC DDB-Vrc5476 (Boston) SDB Hardware

  1. On the NEC DDB-Vrc5476 (Boston) SDB, connect an Ethernet cable to the network connector and to the development workstation or Ethernet hub.
  2. On the NEC DDB-Vrc5476 (Boston) SDB, connect the serial cable to the COM port next to the PS/2 connector labeled DBG SER and to any COM port on the development workstation.

    HyperTerminal uses this connection to communicate with the NEC DDB-Vrc5476 (Boston) SDB.

  3. If you are using the MQ200 display card, be sure that switch S1 on the MQ200 is set to the Down position or the MQ200 will not function correctly.
  4. Connect an ATX power supply to the NEC DDB-Vrc5476 (Boston) SDB and to a power source.
  5. Modify the NEC DDB-Vrc5476 (Boston) SDB switches and jumpers.
  6. Turn on the NEC DDB-Vrc5476 (Boston) SDB by pressing the momentary switch.

    This is located next to the ATX power connector.
