Font Compression

East Asian fonts have a large memory footprint. You can use the Agfa AC3 font compression capability in Windows CE to reduce software memory requirements. Agfa AC3 fonts are TrueType fonts that have been compressed into a new format.

The following list shows some of the benefits of AC3 technology.

  • AC3 works with any TrueType font
  • No glyph data hints are lost during compression or decompression
  • Calling the font decompresses a subset of the fonts characters, rather than the entire font file.

You can include both compressed AC3 files and non-compressed files such as .ttf and .ttc. If font compression is on, Windows CE looks first for a font file with an .ac3 extension; if one is not found, it uses a non-compressed font. For more information, see Agfa AC3 Font Compression and Decompression.
