Microsoft Windows CE .NET  

User Applications

Microsoft® Windows® CE .NET provides many applications for users, such as communication applications, word processing applications, and games.

The following table shows the user applications that platform developers can include in a platform.

Feature Description
Bluetooth Gateway Configuration Utility A sample Bluetooth application that illustrates how to set up a Bluetooth local area network (LAN) server.
FLASH Update Sample Application A sample application that demonstrates how to flash a new operating system (OS) image onto a device.
FreeCell An application that allows a user to play the FreeCell version of Solitaire.
Help The Windows CE HTML-based Help system application.
Inbox The Windows CE e-mail application.
Input Method Selector Sample Application A sample application for dynamically selecting any available input method.
Internet Explorer 5.5 Sample Browser A sample application that implements a user interface for Internet Explorer 5.5 for Windows CE.
Pocket Internet Explorer A compact, limited feature browser for personal digital assistants (PDAs) and other resource-constrained devices.
Remote Desktop Protocol (RDP) Allows a thin client, such as a Windows-based Terminal, to communicate with a terminal server across a local area network (LAN) or a wide area network (WAN) or by means of a dial-up Integrated Services Digital Network (ISDN), digital subscriber line (DSL), or virtual private network (VPN) connection.
Solitaire An application that allows a user to play Solitaire.
Terminal Emulator A sample terminal emulation application that allows a user to create a teletypewriter (TTY) or VT100 emulation mode to a remote host over an installed Telephony API (TAPI) device.
Transcriber Handwriting Recognizer Application An application that recognizes all handwriting, be it cursive, printed, or a combination of both. In addition to recognizing letters, numbers, and words, application recognizes common symbols and various control gestures.
Windows Media Player Application An application that uses OCX playback capabilities for a variety of network streaming and non-streaming multimedia formats.
Windows Messenger Allows a user to send an instant message to a contact or communicate with several contacts at once. It also notifies a user when his or her contacts are online.
WordPad The Windows CE–based word processing application.
