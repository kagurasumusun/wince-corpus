Microsoft Windows CE .NET  

Traditional Chinese Input Methods

Input methods (IM) are tightly bonded to a related Input Method Editor (IME). Microsoft® Windows® CE .NET provides two Traditional Chinese IMs, which are described in the following table. Other IMs can be created.

IM File name Description
Phonetic Phonim.dll Allows phonetic input based on the Bopomofo standard. This is a sample IM with a soft keyboard that allows phonetic input. It is closely tied to the Phonetic IME. The source code is located in %_WINCEROOT%\Public\Wceshellfe\Oak\InputMethods\Chinese.
Chang Jei Chajeiim.dll Allows Chang Jei input, which builds the characters based on its radicals. This is a sample IM with a soft keyboard that allows Chang Jei input. It is closely tied to the Chang Jei IME. The source code is located in %_WINCEROOT%\Public\Wceshellfe\Oak\InputMethods\Chinese.
HWXCHT Hwxcht.dll A handwriting recognition engine for supporting user-drawn ideographs and characters. If used, the OEM must develop a UI.
Mboxcht   A sample IM for Chinese Traditional handwriting input that works with HWXCHT. It requires Softkb.dll and Hwxcht.dll. The source code is located in %_WINCEROOT%\Public\Common\Sdk\Samples\Mboxcht
Sipselect   A sample program for selecting any available IM on the fly; it is interactive with Softkb.dll and the shell with taskbar. The source code is located in %_WINCEROOT%\Public\Common\Sdk\Samples\Sipselect

When an IM is activated, it causes the associated IME to also be activated. However, the opposite is not true: activating an IME will not update the selected IM. For example, if a user uses the IME status window to change the current input mode from Chinese to English, the IME will be disabled, but the IM will not be disabled. To avoid this inconsistency, you can remove the IME status window from the IME UI module.

The source code for the Traditional Chinese IM is located in the following directory.

%_WINCEROOT%\Public\Wceshellfe\Oak\InputMethods\Chinese
