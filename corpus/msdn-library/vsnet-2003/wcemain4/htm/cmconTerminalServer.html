Terminal Server

Terminal Server is a multi-user version of Windows NT; it provides the ability to host multiple, simultaneous client sessions on Windows 2000. Terminal Server can host a variety of Windows-based desktops directly, and can support computers that are running other operating systems (OSs) by way of third-party add-on products. You can use Terminal Server to perform the following tasks:

  • Upgrade existing "green screen" ASCII terminals, or computers that are functioning as terminal emulators, to a Windows programming environment; this provides a more productive graphical user interface (GUI).
  • Deliver Windows-based applications to a range of desktops, including those that are running UNIX, Macintosh, or the Microsoft MS-DOS® OS. Terminal Server can also deliver Windows-based applications to Windows-based computers that cannot be upgraded to a 32-bit Windows OS due to hardware limitations.
  • Extend a Windows OS to thin clients, giving users another option for Windows-based applications, and help lower the total cost of ownership.

In addition to the Remote Desktop Protocol (RDP), Terminal Server supports third-party presentation protocols. This document makes no recommendations regarding design guidelines for Windows Thin Clients that are running third-party software. This document is limited to Windows Thin Clients that are powered by Windows CE and that use the RDP.
