Using the Intel DBPXA250 Development Platform Ethernet Boot Loader

The SMC MAC address is stored in flash. Intel provides a sticker on the board with the MAC address. The Ethernet boot loader menu is used to enter and save the SMC MAC address (option #8), which is stored in system flash.

If you make changes to any settings through the menu, you must exit the menu by entering D or L. This causes the settings to be saved. If you reset the device without exiting the menu, your settings will not be saved.

Note   The SMC is labeled on the hardware as SMSC. The second S is offset.

The menu is below.

Ethernet Boot Loader Configuration:

0) IP address: 192.168.80.2
1) Subnet mask: 255.255.255.255
2) # bootme's: 25
3) Boot delay: 5 seconds
4) DHCP: Enabled
5) Reset to factory default configuration
6) Download new image at startup
7) Program RAM image into FLASH (Disabled)
8) Program SMSC MAC address
9) Boot device order: SMSC -> PCMCIA -> CF
D) Download image now
L) Launch existing flash resident image now
