File Partition Formatting

Like any other media, the file partition in flash memory contains tables, pointers, and variables that must be initialized before files can be stored. This initializing occurs during a format operation.

The Intel Persistent Storage Manager (PSM) gives the original equipment manufacturer (OEM) control over how the media will be formatted, allowing the OEM to tailor PSM to their application. The default format settings are designed to work well in most systems, and an OEM does not need to modify them initially. However, if the OEM can anticipate what the kind of files will be stored in the array, and what the write performance needs to be, they can optimize both storage efficiency and write performance by modifying the default settings.
