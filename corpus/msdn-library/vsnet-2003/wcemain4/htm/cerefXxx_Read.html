Microsoft Windows CE .NET  

xxx_Read

This function is to be implemented by a service and will be called by Services.exe. This function need only be implemented by a streaming service.

DWORD xxx_Read(
DWORD dwData,
LPVOID pBuf,
DWORD dwLen
);

Parameters

dwData
Value returned by xxx_Open for the given service instance.
pBuf
Storage location for the data that is read.
dwLen
Number of bytes to be read.

Return Values

Returns the number of bytes read.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Service.h
