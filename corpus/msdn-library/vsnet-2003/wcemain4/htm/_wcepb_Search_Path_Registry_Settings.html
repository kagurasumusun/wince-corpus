Search Path Registry Settings

You can extend the default search path that the kernel uses to locate .dll files and .exe files. To extend the search path, you must set the following registry value.

[HKEY_LOCAL_MACHINE\Loader]
    "SystemPath":REG_MULTI_SZ

You can add several additional paths. This registry value has a maximum length of MAX_PATH characters, including the terminating nul character. A path specified by the platform developer is the last path to be searched when locating a .dll or .exe file. This registry value is read only when the OS boots.

For more information about these registry settings, see CreateProcess and LoadLibrary.
