Downloading the Boot Loader to the Hitachi US7729 HARP (Keywest) SDB to Flash

  1. Set DIP switch SW1 on the Hitachi US7729 HARP (Keywest) SDB to the settings shown in the following table.

    The switch is located on the backside of the Hitachi US7729 HARP (Keywest) SDB, on the left, near the power connecter.

    Switch Setting
    SW1-1 Off
    SW1-2 Off
    SW1-3 Off
    SW1-4 On
  2. From the Build menu, select Open Build Release Directory to open a command prompt.
  3. Select the image you want to download in either Kshell or Platform Builder.

    For a stand-alone Eboot.bin, use the image located in %_WINCEROOT%\Platform\Keywest\StandAloneEboot\Bin.

  4. Press the Reset button on the Hitachi US7729 HARP (Keywest) SDB.
  5. Type eboot and press ENTER at the HyperTerminal prompt.
  6. Download the OS image to the Hitachi US7729 HARP (Keywest) SDB.
