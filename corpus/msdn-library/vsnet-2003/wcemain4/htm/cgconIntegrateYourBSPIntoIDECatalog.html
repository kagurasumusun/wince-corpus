Add the BSP to the Catalog

The BSP Wizard, CEC Editor, and Export Wizard are provided to add your BSP and device driver definitions to the Catalog. These tools help you create, edit, and manage .cec file definitions for BSP components such as drivers, OALs, boot loaders, OS images, and so on.

The BSP Wizard and the CEC Editor simplify creating .cec file definitions. Depending on your development stage, the BSP Wizard can be used in different ways. There are several things you can do in the BSP Wizard. The following table shows the different ways this tool can be used to create BSP and driver definitions in the Catalog.

Task Description
Creating a BSP definition for your BSP. This assumes that you have already created a BSP from the command line and have generated all the source files, build files, .bib files, and .reg files needed to build the BSP from the command line.

In this case, you should choose Create a New BSP in the BSP Wizard. This choice assists you in easily creating a BSP definition and the .cec files for your BSP and allows you to add or remove device drivers into the BSP with minimal coding efforts.
Cloning an existing a BSP to create a new BSP for your SDB. This assumes that you are going to start from nothing and create a BSP for your SDB. The easiest approach here is to model your BSP after an existing BSP in Windows CE.

In this case, you should choose Clone a BSP in the BSP Wizard and choose one of the existing BSPs that closely matches your SDB and CPU peripherals. Cloning a BSP provides you with a copy of all the files from the existing BSP you have chosen and creates all the .cec descriptions for the new BSP. You can also add or remove device drivers to and from the BSP with minimal coding efforts.
Adding or Remove drivers to or from an existing BSP. This assumes you want to add a new driver or remove a driver to or from a BSP that you have already created in the Catalog. This is also an easy way for you to create a CEC description for your driver. Associating the driver with a BSP can do this, then using the CEC Editor to change the BSPs and microprocessors supported. By using the BSP Wizard you shorten the number of steps that are needed to create the .cec descriptions.
Exporting a BSP as an MSI file for use in Platform Builder projects. This assumes that you have already created the BSP source files and integrated the BSP in to the IDE catalog using the BSP Wizard. Using the Export Wizard from the IDE can do this. The Export Wizard packages all the BSP files into an MSI file that can be imported into a Platform Builder project easily.
Importing a BSP that is available as an .msi file from the Web site. This assumes that a BSP has already been created and exported using Platform Builder and is available on the Microsoft Web site. From the Platform Builder Start Page, click on the Downloads tab. Search for the BSP you want and click on it. The BSP source and other files are downloaded to your machine and the BSP definition shows up in the Catalog. You can then modify the BSP definition by either adding or removing drivers as necessary. Finally, you can use this BSP in creating new projects. To open the BSP Wizard, from the Platform menu, choose BSP Wizard. Follow the information presented to create the .cec file descriptions. To edit .cec files directly, use the CEC Editor. To start the CEC Editor, from the Tools menu, choose CEC Editor.
