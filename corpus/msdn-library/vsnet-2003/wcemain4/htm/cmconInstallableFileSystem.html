Installable File System

Intel Persistent Storage Manager (PSM) needs to know where the flash and file partition are located. The structure PSM_OEMInfo, in Plat_api.c and Plat_api.h, contains this information. PSM_OEMInfo lists the physical and virtual locations of the flash along with other array parameters. This structure contains the following information:

  • The flash array location. Both physical and virtual addresses are required.
  • The location of the file partition in the array.
  • The size of accesses to use when writing to the array.

The first three entries of the PSM_OEMINFO structure, which are array addresses, are used in two different places, the registry utilities and the Installable File System Manager (IFS), so there are two versions. The registry utilities require virtual addresses, so there is a compile-time option, PSM_PRE_OS_ACCESS, which is defined when the registry support is compiled and linked. PSM_PRE_OS_ACCESScauses the first version of the address variables, the virtual ones, to be made available to those utilities. The IFS accesses the flash using physical addresses. When it is built, PSM_PRE_OS_ACCESS will not be defined, so the second version of the address parameters, the physical ones, will be made available to the IFS.

Add the following registry entries to HKEY_LOCAL_MACHINE\System\StorageManager\AutoLoad\PSM so the OS loads PSM.

[HKEY_LOCAL_MACHINE\System\StorageManager\AutoLoad\PSM]
    "Dll"="PSMFSD.dll"
    "Paging"=dword:0

The typical location for the default registry settings is Platform.reg. The default registry is typically Platform.Reg, contained within the board support package. For example, for the SA11X0BD BSP, the default registry is found in %_WINCEROOT%\Platform\SA11X0BD\Files.
