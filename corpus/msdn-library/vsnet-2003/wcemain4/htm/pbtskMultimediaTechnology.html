Multimedia Technologies

The following table shows the Core OS Catalog features that appear in Platform Builder. The table includes features for headless devices and display-based devices.

Feature Sysgen variable Description
WMA & MP3 Local Playback SYSGEN_LOCALAUDIO A grouping of features to enable Windows Media™ Audio and MP3 playback from a local source.

Available in both headless and display-based devices.

For more information, see Basic Multimedia Overview.
WMA & MP3 Streaming SYSGEN_STREAMAUDIO A grouping of features to enable Windows Media Audio and MP3 playback from a streaming source.

Available in both headless and display-based devices.

For more information, see Basic Multimedia Overview.
WMV & MPEG-4 Streaming SYSGEN_STREAMAV A grouping of features to enable audio, Microsoft Windows Media™ Video, and MPEG-4 playback from a streaming source.

Available only in display-based devices.

For more information, see Basic Multimedia Overview.
Audio Compression Manager SYSGEN_AUDIO_ACM A software layer to support transparent run-time audio compression and decompression, wave-form-audio data format selection, filter selection, format conversion, and data filtering.

Available in both headless and display-based devices.
GSM 6.10 Codec SYSGEN_ACM_GSM610 A codec for GSM 6.10 audio stream playback within Microsoft DirectShow®.

Available in both headless and display-based devices.
MSFilter Codec SYSGEN_ACM_MSFILTER A sample ACM filter that performs format and sample rate conversion and is intended to demonstrate how to write an ACM codec.

Available in both headless and display-based devices.
DirectSound® SYSGEN_DSOUND An API to provide low-latency mixing, hardware acceleration, and direct access to the sound device.

Available in both headless and display-based devices.

For more information, see DirectSound Overview.
Waveform Audio SYSGEN_AUDIO An API to control waveform audio input/output (I/O) devices including hardware audio mixer support.

Available in both headless and display-based devices.

For more information, see Waveform Audio Overview.
Digital Rights Management (DRM) SYSGEN_DSHOW_WMT_DRMV7 A method for protecting multimedia content from unauthorized playback or duplication.

Available in both headless and display-based devices.

For more information, see Digital Rights Management Overview.
DRM for Portable Devices SYSGEN_DSHOW_WMT_PDDRM The core functionality for DRM. It allows you to transfer content from a desktop computer to the local store of a Windows CE device or to a supported portable media device connected to a Windows CE device.

Available in both headless and display-based devices.

For more information, see DRM for Portable Devices.
DRM License Acquisition OCX SYSGEN_DSHOW_WMT_DRMOCX An ActiveX control that enables a device to negotiate the request, acceptance, and transfer of DRM licenses from Microsoft DRM license servers.

Available only in display-based devices.
Direct3D® SYSGEN_DIRECT3D An API that supports interactive three-dimensional (3-D) graphics applications by allowing device-dependent access to 3-D video display hardware in a device-independent manner.

Available only in display-based devices.

For more information, see Direct3D Overview.
Reference Rasterizer SYSGEN_DIRECT3D_RAST A slow, high-quality software-based renderer used to check Direct3D driver compliance.

Available only in display-based devices.

For more information, see Reference Device.
DirectDraw® SYSGEN_DDRAW An API for two-dimensional (2-D) graphics. It allows you to directly manipulate display memory and the hardware blitter. It also provides hardware overlay and flipping surface support.

Available only in display-based devices.

For more information, see DirectDraw Overview.
DirectMusic® SYSGEN_DMUSIC An API to convert message-based, musical data into wave samples either in hardware or in a software synthesizer.

Available in both headless and display-based devices.

For more information, see DirectMusic Overview.
ACM Wrapper Filter SYSGEN_DSHOW_ACMWRAP A filter to enable a standard Audio Compression Manager driver within DirectShow.

Available in both headless and display-based devices.

For more information, see ACM Wrapper Filter.
DirectSound Audio Renderer SYSGEN_DSHOW_DSNDOUT A DirectShow filter that communicates with the DirectSound audio subsystem to render audio data.

Available in both headless and display-based devices.

For more information, see DirectSound Audio Renderer.
G.711 Audio Codec SYSGEN_DSHOW_MSG711 A codec for G.711 audio stream playback within DirectShow.

Available in both headless and display-based devices.
GSM 6.10 Audio Codec SYSGEN_DSHOW_MSGSM610 A codec for GSM 6.10 audio stream playback within DirectShow.

Available in both headless and display-based devices.
IMA ADPCM Audio Codec SYSGEN_DSHOW_IMAADPCM A codec for IMA ADPCM audio stream playback within DirectShow.

Available in both headless and display-based devices.
MP3 Codec SYSGEN_DSHOW_MP3 A codec for MP3 file playback within DirectShow.

Available in both headless and display-based devices.
MPEG-1 Layer 1 & 2 Audio Codec SYSGEN_DSHOW_MPEGA A codec for MPEG-1 Layer 1 and 2 audio stream playback within DirectShow.

Available in both headless and display-based devices.
MS ADPCM Audio Codec SYSGEN_DSHOW_MSADPCM A codec for MS ADPCM audio stream playback within DirectShow.

Available in both headless and display-based devices.
Waveform Audio Renderer SYSGEN_DSHOW_WAVEOUT A renderer for waveform audio that can be used in a DirectShow filter graph.

Available in both headless and display-based devices.
WMA Codec SYSGEN_DSHOW_WMA A codec for Windows Media Audio stream playback within DirectShow. It includes support for Windows Media Audio versions 2.0, 7.0, and 8.0.

Available in both headless and display-based devices.
DirectShow Core SYSGEN_DSHOW An API that provides access to the underlying stream control architecture for applications, and simplifies media playback, format conversion, and capture tasks.

Available in both headless and display-based devices.
DMO Wrapper Filter SYSGEN_DSHOW_DMO A filter that enables a DirectShow application to use a Microsoft DirectX® Media Object (DMO) within a filter graph.

Available only in display-based devices.

For more information, see DMO Wrapper Filter.
AVI Filter SYSGEN_DSHOW_AVI A filter to playback legacy video formats through DirectShow.

Available only in display-based devices.
MIDI Filter SYSGEN_DSHOW_MIDI A filter playback MIDI encoded audio data.

Available only in display-based devices.
MPEG-1 Parser/Splitter SYSGEN_DSHOW_MPEGSPLITTER A filter that parses and splits MPEG-1 audio and video data for playback within DirectShow.

Available in both headless and display-based devices.
Wave/AIFF/au/snd File Parser SYSGEN_DSHOW_WAV A filter that parses the data from any of the following formats for playback within DirectShow: Wave, AIFF, au, and snd.

Available in both headless and display-based devices.
Cinepak Video Codec SYSGEN_DSHOW_CINEPAK A codec for Cinepak video stream playback within DirectShow.

Available only in display-based devices.
DirectShow Video Renderer SYSGEN_DSHOW_VIDREND A filter that provides video rendering support for multimedia data.

Available only in display-based devices.
MPEG-1 Video Codec SYSGEN_DSHOW_MPEGV A codec for MPEG-1 video stream playback within DirectShow.

Available only in display-based devices.
MS RLE Video Codec SYSGEN_DSHOW_MSRLE A codec for MS RLE video stream playback within DirectShow.

Available only in display-based devices.
QuickTime V2 Video Codec SYSGEN_DSHOW_QT A codec for QuickTime version 2 video stream playback within DirectShow.

Available only in display-based devices.
WMV/MPEG-4 Video Codec SYSGEN_DSHOW_WMV A codec for Windows Media Video stream playback within DirectShow. It includes support for MPEG-4 2.0 and 3.0, MS MPEG-4 ISO 1.0 and Windows Media 7.0 and 8.0.

Available only in display-based devices.
DVD-Video SYSGEN_DIRECTDVD A complete middleware framework, including application and driver interfaces, for DVD-video playback applications.

Available in both headless and display-based devices.

For more information, see DVD-Video API Overview.
Windows Media Player Application SYSGEN_CEPLAYER A standalone application for playing back various multimedia data formats including Windows Media Audio and video.

Available only in display-based devices.
Windows Media Player OCX SYSGEN_DSHOW_WMP A Microsoft ActiveX control you can use to add multimedia playback capabilities to Web pages or COM-based documents and applications.

Available in both headless and display-based devices.
Windows Media Technologies SYSGEN_DSHOW_WMT A rich set of components, along with state-of-the-art Windows Media audio/video codecs to enable audio and video streaming.

Available in both headless and display-based devices.

For more information, see Windows Media Technologies Overview.
ASX v1 and M3U File Support SYSGEN_DSHOW_WMT_ASXV1 Support for Advanced Stream Redirector (ASX) 1.0 and M3U play lists.

Available in both headless and display-based devices.
ASX v2 File Support SYSGEN_DSHOW_WMT_ASXV2 Support for ASX 2.0.

Available in both headless and display-based devices.
ASX v3 File Support SYSGEN_DSHOW_WMT_ASXV3 Support for ASX 3.0.

Available in both headless and display-based devices.
NSC File Support SYSGEN_DSHOW_WMT_NSC Support for streaming from Windows Media Station (NSC) files.

Available in both headless and display-based devices.
Windows Media Multicast and Multi Bit Rate SYSGEN_DSHOW_WMT_MULTI Support for IP multicast streaming through Windows Media Station files (NCS) and multibit rate content.

Available in both headless and display-based devices.
Windows Media Streaming from Local Storage SYSGEN_DSHOW_WMT_LOCAL Support for playback of Windows Media data from local storage.

Available in both headless and display-based devices.
Windows Media Streaming over HTTP SYSGEN_DSHOW_WMT_HTTP Support for playback of Windows Media data streamed from a Web server.

Available in both headless and display-based devices.
Windows Media Streaming over MMS SYSGEN_DSHOW_WMT_MMS Support for playback of Windows Media data streamed from a Microsoft Media Server.

Available in both headless and display-based devices.
