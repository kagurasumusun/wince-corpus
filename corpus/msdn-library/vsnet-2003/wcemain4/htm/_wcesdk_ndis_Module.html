ndis Module

The ndis module contains the APIs that are required to implement the Network Driver Interface Specification (NDIS).

Functions for Application Developers

The ndis module contains functions for device driver developers, which are defined in the Ndis.h and Rndis.h header files. To import these functions, you must link to the ndislib.lib file. The following table shows the functions that are included in the ndis module.
