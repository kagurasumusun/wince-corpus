Connections Key

The Windows Thin Client Shell must have information about how to start, edit and delete each connection that it manages. This information is specified in the Connections key.

The Connections key is located in the root of each client registry key. Each subkey in the Connections key represents a connection entry. The shell will enumerate the Connections key to determine the list of connections that are defined for each client.

The following code example shows how to create the necessary registry subkey.

Registered Client\Connections\Connection Subkey Entry

The shell requires that each client assume full ownership and maintenance of its connection key. The shell has read-only access to a connection key.

The client is not required to store all of its information in its connection key. Only those values that are required by the shell must be maintained in the connection key.

The system does not need to be reset when a user modifies the connection subkey entries for a client. The shell updates the connection information of a client after an add operation, an edit operation, or a delete operation by a user.

The Connections registry subkey is

HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Clients\Registration\Your client name\Connections\Your connection name

Connection named values must be placed in the root of the key defined for each connection. If the registry values of a connection are incomplete or are not valid, then the shell will ignore the connection and the connection will not be listed in the shell. However, an error message is not posted to the user if the shell encounters an improperly configured connection.

The following table shows the named values for a connection.

Value Description
Description: REG_SZ No default setting. The Description value specifies the display name for the connection. The Windows Thin Client Shell displays connections by names that are obtained from this value.

This value is required.

StartExe: REG_SZ No default setting. The StartExe value specifies the executable file to launch when creating a new connection.

This value is required.

StartCmdLineArgs: REG_SZ No default setting. The StartCmdLineArgs value specifies the command-line arguments to pass to the executable that is specified by the StartExe value.

This value is required.

PropertiesExe: REG_SZ No default setting. The PropertiesExe value specifies the helper application to call when modifying the properties or editing an existing connection.

This value is required.

PropertiesCmdLineArgs: REG_SZ No default setting. The PropertiesCmdLineArgs value specifies the command-line arguments to pass to the helper application that is specified by the PropertiesExe value.

This value is required.

DeleteExe: REG_SZ No default setting. The DeleteExe value specifies the helper application to call when deleting a connection.

This value is required
DeleteCmdLineArgs: REG_SZ No default setting. The DeleteCmdLineArgs value specifies the command-line arguments to pass to the helper application that is specified by the DeleteExe value.

This value is required.
