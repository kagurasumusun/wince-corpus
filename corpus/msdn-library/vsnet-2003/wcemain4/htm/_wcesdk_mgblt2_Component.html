mgblt2 Component

The mglblt2 component supports bitmap transfers.

Functions for Application Developers

The mglblt2 component includes functions for application developers, which are defined in the Wingdi.h header file. To import these functions, you must link to the mgblt2.lib file. The following functions are included in the mglblt2 component:

  • MaskBlt
  • PatBlt
  • TransparentImage
