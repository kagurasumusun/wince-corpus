coreimm Component

The coreimm component supports the Input Method Manager (IMM). The IMM handles communication between input method editors and applications.

Functions for Application Developers

The coreimm component includes functions for application developers, which are defined in the Winuser.h header file. To import these functions, you must link to the coreimm.lib file. The following table shows the functions included in the coreimm component.
