fileinfo Component

The fileinfo component is a shell-related component of the coredll module that retrieves information about files and directories.

Functions for Application Developers

The fileinfo component includes a function for application developers, which is defined in the Shellapi.h header file. To import this function, you must link to the fileinfo.lib file. The following function is included in the fileinfo component:

  • SHGetFileInfo
