Windows Thin Client

The Windows Thin Client platform configuration provides the starting point for remote-desktop terminals, including those features necessary to support Terminal Services, such as the Windows Thin Client Shell, and the Remote Desktop Protocol (RDP). Formerly, development of a Windows-based thin client required the stand-alone Windows-based Terminal Kit, which included documentation about how to design and develop a Windows-based terminal.
