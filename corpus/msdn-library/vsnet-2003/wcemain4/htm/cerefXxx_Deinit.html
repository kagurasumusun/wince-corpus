xxx_Deinit

This function is to be implemented by a service and will be called by Services.exe. Called during DeregisterService.

DWORD xxx_Deinit(
DWORD dwData
);

Parameters

dwData
Value returned by xxx_Init for the given service instance.

Return Values

Services.exe ignores the value returned by xxx_Deinit.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Service.h
