Board Support Packages

The following table shows the board support packages (BSPs) that appear in the Platform Builder Catalog.

BSP Description
ARM Integrator AP: ARMV4I A BSP for the ARM Integrator AP SDB with the ARM920 microprocessor. The platform uses the OS that is built for the ARM v4 architecture using the ARM instruction set with Thumb Interworking enabled.
ARM Integrator AP: ARMV4T A BSP for the ARM Integrator AP SDB with the ARM920 microprocessor. The platform uses the OS that is built for the ARM v4 architecture using the 16-bit Thumb instruction set with ARM Interworking enabled.
CEPC: x86 A BSP for a Windows CE PC–based hardware reference platform. The platform uses the OS that is built for the x86 architecture.
Emulator: x86 A BSP for the Emulator platform. The platform uses the OS that is built for the x86 architecture.
Hitachi US7729 HARP: SH3 A BSP for the Hitachi US7729 HARP (Keywest) SDB. The platform uses the OS that is built for the SH3 and SH3DSP architectures.
Hitachi US7750 HARP: SH4 A BSP for the Hitachi US7750 HARP (Aspen) SDB. The platform uses the OS that is built for the SH4 architecture.
Intel DBPXA250 Dev Platform: ARMV4I A BSP for the Intel DBPXA250 Development Platform for XScale PXA250 application microprocessors. The platform uses the OS that is built for the ARM v4 architecture using the ARM instruction set with Thumb Interworking enabled.
Intel DBPXA250 Dev Platform: ARMV4T A BSP for the Intel DBPXA250 Development Platform for XScale PXA250 application microprocessors. The platform uses the OS that is built for the ARM v4 architecture using the 16-bit Thumb instruction set with ARM Interworking enabled.
Intel SA1110/SA1111 Dev Kit: ARMV4 A BSP for the Intel SA1110/SA1111 (Assabet) Development Kit. The platform uses the OS that is built for the ARM v4 architecture.
National Geode: x86 A BSP for the National Semiconductor Geode microprocessor-based standard development boards (SDBs). The National Geode SP4SC30 development platform, Lanner EM-350 and EM-351 embedded single board computers (SBCs), and Advantech PCM-5822 and PCM-5823 Biscuit PC are a few of the supported SDBs. The platform uses the OS built for the x86 architecture.
NEC DDB-Vrc5476: MIPSII_FP A BSP for the NEC DDB-Vrc5476 (Boston) SDB. The platform uses the OS that is built for the MIPSII architecture with hardware floating-point support.
NEC DDB-Vrc5476: MIPSII A BSP for the NEC DDB-Vrc5476 (Boston) SDB. The platform uses the OS that is built for the MIPSII architecture with floating point emulation support.
NEC DDB-Vrc5476: MIPSIV A BSP for the NEC DDB-Vrc5476 (Boston) SDB. The platform uses the OS that is built for the MIPSIV architecture with floating point emulation support.
NEC DDB-Vrc5476: MIPSIV_FP A BSP for the NEC DDB-Vrc5476 (Boston) SDB. The platform uses the OS that is built for the MIPSIV architecture with hardware floating-point support.
NEC DDB-Vr4122: MIPS16 A BSP for the NEC DDB-Vr4122 (Eagle) SDB. The platform uses the OS that is built for the MIPSII architecture with MIPS16 and floating-point emulation support.
NEC DDB-Vr4122: MIPSII A BSP for the NEC DDB-Vr4122 (Eagle) SDB. The platform uses the OS that is built for the MIPSII architecture with floating point emulation support.
