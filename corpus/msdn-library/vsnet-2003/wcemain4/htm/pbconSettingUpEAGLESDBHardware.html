Setting Up the NEC DDB-Vr4122 (Eagle) SDB Hardware

  1. Connect the main board and the debug board.
  2. Connect an Ethernet cable to the network connector on the NEC DDB-Vr4122 (Eagle) SDB and to the development workstation or Ethernet hub.
  3. Connect a serial cable to the debug serial port that is labeled Dsub9<2>.

    This is only necessary if you need to download a new boot loader.

  4. If you are using the MQ200 display card, be sure that switch S1 on the MQ200 is set to the DOWN position or the MQ200 will not function correctly.
  5. Connect an ATX power supply to the NEC DDB-Vr4122 (Eagle) SDB and to a power source.
  6. Modify the NEC DDB-Vr4122 (Eagle) SDB switches and jumpers.
