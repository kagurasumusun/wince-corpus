Setting Up a CEPC for an Ethernet Connection

  1. Install the debug Ethernet card in an appropriate slot.
  2. If it is an ISA card, configure the card with unique IRQ and memory settings to prevent conflicts with other hardware.
    Note   For ISA-based Ethernet network cards that are Plug and Play, disable the Plug and Play capability, and then configure the card to a known I/O base address and IRQ.
  3. For ISA based NE2000 NIC cards, set BSP_NIC_NE2000_ISA and clear BSP_NIC_NE2000_PCI.
  4. For PCI based NE2000 cards, set BSP_NIC_NE2000_PCI and clear BSP_NIC_NE2000_ISA.
