Downloading the OS Image to the Intel DBPXA250 Development Platform

  1. Set up Platform Builder for download.
  2. Start HyperTerminal.
  3. Make sure that switch S14 is set to the Dot position.

    This will turn off the flash chip write-protection.

  4. Set switch S15 appropriately to choose which bank of flash chips will be programmed and booted at reset.

    The Dot setting is flash banks labeled U59 and U64, which is what you will want to choose.

  5. Turn on the Intel XScale Microarchitecture Handheld Development Platform by moving toggle switch S16 to the far left position.
  6. Download the OS image.

If the image was built for flash, that is, IMGFLASH=1, it will be written to flash after it is downloaded to a RAM cache.
