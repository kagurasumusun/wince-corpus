coreloc Component

The coreloc component provides global national language support (NLS). This component is required to address locales other than English (United States).

Functions for Application Developers

The coreloc component includes functions for application developers, which are defined in the Winsl.h header file. To import these functions, you must to link to the coreloc.lib file. The following table shows the functions included in the coreloc component.
