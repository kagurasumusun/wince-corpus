msdxm Module

The msdxm module selects all Windows Media Player components.

Components

The following table shows the components contained in the msdxm module.

Component Description Note Library
bkgndbmp Supports a background bitmap file that is displayed in a media window while media is loading. Selectively compiled to library. Exposes no public functions. Msdxm.lib
statbar Implements a status bar. Selectively compiled to library. Exposes no public functions. Msdxm.lib
toolbar Implements transport controls, such as Play and Pause. Selectively compiled to library. Exposes no public functions. Msdxm.lib
