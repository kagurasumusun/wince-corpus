Microsoft Windows CE .NET  

Internet Client Services

The following table shows the Core OS catalog features that appear in Platform Builder. The table includes features for headless devices and display-based devices.

Feature Sysgen variable Description
Internet Explorer 5.5 for Windows CE - Standard Components SYSGEN_IE The components for Microsoft® Internet Explorer 5.5, optimized for Windows CE .NET.

Available only in display-based devices.

For more information, see Internet Explorer 5.5 Overview.
Internet Explorer 5.5 Sample Browser SYSGEN_IESAMPLE A sample application that implements a user interface for Internet Explorer 5.5 for Windows CE.

Available only in display-based devices.
TV-Style Navigation Components SYSGEN_TVLENS_ALL The television-style navigation feature in Windows CE .NET that gives users a way to navigate through Web pages on devices that have a limited display size and a 5-key navigational system, for example, a television and remote control. Navigational aids include directional tabbing, fixed width layout to eliminate horizontal scrollbars, and the ability to disable vertical scrollbars.

Available only in display-based devices.

For more information, see Adding Television-Style Navigation to a Browser.
Pocket Internet Explorer SYSGEN_PIE A compact, limited feature browser for personal digital assistants (PDAs) and other resource-constrained devices.

Available only in display-based devices.

For more information, see Pocket Internet Explorer Overview.
Internet Explorer Browser Control Host SYSGEN_SHDOCVW The Layout Manager Microsoft ActiveX® control to provide navigation and other user-level functionality to Internet client browser applications.

Available only in display-based devices.

For more information, see Internet Explorer Browser Control Host.
Internet Explorer HTML/DHTML API SYSGEN_MSHTML The parsing and rendering engines, including editing, style sheet, and ActiveX support.

Available only in display-based devices.

For more information, see Internet Explorer MSHTML/DHTML API.
Internet Explorer Multiple-Language API SYSGEN_MLANG A set of services that support the internationalization of Internet data.

Available in both headless and display-based devices.

For more information, see Internet Explorer Multiple-Language API.
Internet Explorer TV-Style Navigation SYSGEN_TVLENS The television-style navigation modules.

Available only in display-based devices.
Directional Tabbing SYSGEN_TVLENS_DTA A spatial navigation system based on the location of selectable objects relative to each other, rather than on the HTML design of the page. The browser displays a yellow rectangle around the selectable element that currently has focus.

Available only in display-based devices.
Disable Vertical Scroll Bar & Events SYSGEN_TVLENS_NOVSCRL A service that disables vertical scroll bars. Vertical scroll bar events are available and applications that host the browser can provide a scroll indicator UI element to replace the scroll bars.

Available only in display-based devices.
Fixed-Width Layout SYSGEN_TVLENS_FWL A service that eliminates horizontal scrolling by compressing images and removing extra white space from between objects or within columns on tables. Multiple scrolling areas (frames) are reformatted to fit the fixed widths of the individual scrolling objects.

Available only in display-based devices.
URL Moniker Services SYSGEN_URLMON The support services for URL Monikers, Hit Logging, Asynchronous Pluggable Protocols and URL Security Zones.

Available only in display-based devices.

For more information, see URL Moniker Services Overview.
Windows Internet Services SYSGEN_WININET Base Internet functionality, including support for File Transport Protocol (FTP), Autodial, Auto Proxy, Passport, and Credential Manager.

Available only in display-based devices.

For more information, see Windows Internet Services Overview.
Pocket Internet Explorer HTML View (WEBVIEW) SYSGEN_WEBVIEW The Pocket Internet Explorer HTML Web view controls.

Available only in display-based devices.
Sample IE 5.5 Internet Options Control Panel SYSGEN_INETCPL A sample application that implements Control Panel for setting Internet Options.

Available only in display-based devices.
JScript 5.5 SYSGEN_IE_JSCRIPT The run-time support for Microsoft JScript® 5.5 Internet scripting language.

Available in both headless and display-based devices.

For more information, see JScript 5.5 Overview.
VBScript 5.5 SYSGEN_IE_VBSCRIPT The run-time support for Microsoft Visual Basic® 5.5 Scripting Edition (VBScript) programming language.

Available in both headless and display-based devices.

For more information, see VBScript 5.5 Overview.
