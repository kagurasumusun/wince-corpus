timer Component

The timer component provides Win32 timer functionality.

Functions for Application Developers

The timer component includes functions for application developers, which are defined in the Winuser.h header file. To import these functions, you must link to the timer.lib file. The following functions are included in the timer component:

  • KillTimer
  • SetTimer
