mgbase Component

The mgbase component supports basic GDI functionality.

Functions for Application Developers

The mgbase component includes functions for application developers, which are defined in the Wingdi.h header file. To import these functions, you must link to the mgbase.lib file. The following table shows the functions that are included in the mgbase component.

Function
CreateCompatibleDC GetObjectType
DeleteDC GetStockObject
DeleteObject GetTextColor
GetBkColor SelectObject
GetBkMode SetBkColor
GetCurrentObject SetBkMode
GetDeviceCaps SetTextColor
GetObject
