Registry Settings

The registry is a centralized hierarchical database that stores information to configure the operating system (OS) for applications and hardware devices. During operation, the OS repeatedly refers to information stored in the registry.

For information about registry settings and keys associated with an OS feature or device drivers, see Operating System Features or Drivers, and then navigate to the feature or device driver to obtain its registry settings and keys information. Windows CE .NET also provides the following registry settings that are not associated with OS features or device drivers:

  • Console Registry Settings
  • Daylight Savings Time Registry Settings
  • Desktop Registry Settings
  • Dialing Registry Settings
  • Windows CE Explorer Registry Settings
  • GWES Registry Settings
  • Hibernation Registry Settings
  • Out-of-Memory Registry Settings
  • Search Path Registry Settings
  • Time Zone Registry Settings

For information about the registry (.reg) files from which the build system constructs registry entries for an OS image, see Registry File.
