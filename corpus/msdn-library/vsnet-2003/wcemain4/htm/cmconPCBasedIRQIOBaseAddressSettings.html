CEPC Based IRQ and I/O Base Address Settings

The following table shows the default IRQ and I/O Base address settings for all devices and drivers in an OS image that is built using the Enterprise Terminal OS configuration. Entries that appear in bold type show drivers that use the same IRQ. You cannot use both of these devices at the same time unless you update the Platform.reg file. For example, ISA product Ethernet and USB OHCI drivers both use IRQ 15, so you cannot use both of these drivers at the same time unless you update the Platform.reg file.

The CEPC has the following resource setting requirements for devices on the ISA bus:

  • Devices must not respond to memory addresses in the range of 0xD0000 through 0xDFFFF.
  • Devices must not use I/O ports 0x3E0 through 0x3E3 and 0X300 through 0X340.
  • Devices must not use IRQ 11.
