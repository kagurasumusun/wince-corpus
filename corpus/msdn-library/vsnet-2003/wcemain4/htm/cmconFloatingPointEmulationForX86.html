Floating Point Emulation for x86

By default, the x86 kernel only supports a hardware based FPU. If you have a processor that is x86 based and does not have a hardware FPU, you need to set the following environment variable.

BSP_FPEMUL=1

This is set in your <Platform>.bat file that is run when your platform is built. This setting causes the component FPEMUL to be linked into Coredll.dll enabling support for floating point emulation.
