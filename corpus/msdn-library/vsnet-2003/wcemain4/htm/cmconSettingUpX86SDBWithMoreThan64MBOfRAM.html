Setting up an x86 SDB with more than 64 MB of RAM

The OEMInit code that determines whether it should look for additional memory keys off the memory end address is specified in Config.bib. If you change Config.bib, this check may be skipped. Currently the RAM end address is 28 MB, unless it is a non-U.S. image or you specify an IMGRAM* variable.

Assuming Config.bib is the default 28 MB, otherwise change OEMInit by searching for IsDRAM in Cfwpc.c, the following steps show how to set up an x86 SDB with more than 64 MB of RAM.

  1. In %_WINCEROOT%\Public\Common\Oak\Csp\i486\Inc\Pc.h, change CEPC_EXTRA_RAM_SIZE to a value equal to the total amount of RAM you want to support minus the amount assumed by Config.bib; 28 MB is the default.

    For example, to support 128 MB of RAM, change the value to 0x6400000. The default is 0x2400000.

  2. In %_WINCEROOT%\Public\Common\Oak\Csp\i486\Oal\OEMInit.asm, change the first entry of _OEMAddressTable to map the total amount of memory to be supported.

    The default value is 0x04000000, which is 64 MB. To support 128 MB of RAM, change the value to 0x8000000.

  3. Build i486oal.lib with the following commands. 
    cd %_WINCEROOT%\Public\Common\Oak\Csp\i486\Oal
build -c
sysgen i486oal
  4. Build that platform with the following commands. 
    cd %_WINCEROOT%\Platform\<Platform>\Kernel\Buildexe
set WINCEREL=1
build –c
makeimg
    Note   This is the minimal set of commands.
