toolhelp Module

The toolhelp module implements the ToolHelp debugger and supports the ToolHelp API functions.

Functions for Application Developers

The toolhelp module contains functions for application developers, which are defined in the Toolhelp.h header file. To import these functions, you must link to the Toolhelp.lib file. The following table shows the functions that are included in the toolhelp module.

Function
CloseToolhelp32Snapshot Module32Next
CreateToolhelp32Snapshot Process32First
Heap32First Process32Next
Heap32ListFirst Thread32First
Heap32ListNext Thread32Next
Heap32Next Toolhelp32ReadProcessMemory
Module32First  
Note   Current process is not included in the module list.
