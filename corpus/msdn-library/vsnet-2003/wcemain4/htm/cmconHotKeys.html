Hot Keys

The following default hot-key connections apply to task switching between emulator sessions and process management, when a user creates and ends sessions:

  • CTRL+ALT+END

    Brings the Windows Thin Client Shell UI to the foreground.

    Security Note   The Thin Client shell sends the CTRL+ALT+DEL key combination to the Terminal Server host machine to present the Windows Security dialog.
  • CTRL+ALT+UP ARROW

    Switches to the next active session without bringing the shell forward. The next active session is the session that is above the current session, as viewed from the shell UI.

  • CTRL+ALT+DOWN ARROW

    Switches to the next active session without bringing the shell forward. The next active session is the session that is below the current session, as viewed from the shell UI.

  • CTRL+ALT+HOME

    Switches to the default connection, if it is running. If it is not running, then the shell starts the connection.

These hot-key connections are modifiable. At the minimum, the default connection must be set for each Windows Thin Client device.

Hot-key support must be available to the user. Hot-key support must be enabled by using the specified default guidelines. You must provide a UI in the Setup Property Sheets by which the user can enable hot-key support or make it unavailable. You have the option of making the hot keys configurable.

The hot key settings are stored in the registry in the subkey HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Shell. The following table shows the named values for this subkey.

Note   The shell allows for three hot keys to be specified. Either all three are enabled, or none of them is enabled. You cannot enable one or two hot keys. For hot-key support to be enabled, all of the hot keys must be registered successfully. If any key fails to register as a hot key, then hot-key support is made unavailable.
Value Description
HotKeyEnable: REG_SZ Default setting is 0. The HotKeyEnable value specifies whether to enable hot-key support. If this named value has a setting greater than 0, then hot-key support is enabled. If this named value is set to 0, then hot-key support is made unavailable.

No restart is required when the setting is changed.
HotKey1VKey: REG_DWORD Default setting is 0x26 (VK_UP). The HotKey1Vkey value specifies the virtual-key code of the hot key that delivers an "up" action. This hot key brings the next active session forward so that it is above the current session, relative to the shell UI. The action is circular; if the session reaches the top of the list, then it goes to the bottom of the list and continues upward.

No restart is required when the setting is changed.
HotKey1fMod: REG_DWORD Default setting is 0x03. The HotKey1fMod value specifies the key-state modifiers for the hot key that is specified by the HotKey1Vkey value. The following list shows the key modifiers and their values:
  • ALT key: 0x0001
  • CTRL key: 0x0002
  • SHIFT key: 0x0004

Any combination of these modifiers can be specified for the virtual key. The value must be determined by running the OR operator on the desired modifiers to produce a single value. For example, to generate a hot-key message for the CTRL+ALT+PAGE UP key combination, you must specify the following hot-key values.

HotKey1Vkey = 0x21 (VK_PRIOR)
HotKey1fMod = 0x03

No restart is required when the setting is changed.
HotKey2VKey: REG_DWORD Default setting is 0x28 (VK_DOWN). The HotKey2Vkey value specifies the virtual-key code of the hot key that delivers a "down" action. This hot key brings forward the next active session that is below the current session, relative to the shell UI. The action is circular; if the session reaches the bottom of the list, then it goes to the top of the list and continues downward.

No restart is required when the setting is changed.
HotKey2fMod: REG_DWORD Default setting is 0x03. The HotKey2fMod value specifies the key-state modifiers for the hot key that is specified by the HotKey2Vkey value. For more information, see the HotKey1fMod value.

No restart is required when the setting is changed.
HotKey3VKey: REG_DWORD Default setting is 0x24 (VK_HOME). The HotKey3Vkey value specifies the virtual-key code of the hot key that delivers a "home" action. This hot key brings forward the default session. If the default connection is not active, then the shell activates it and brings it forward.

No restart is required when the setting is changed.
HotKey3fMod: REG_DWORD Default setting is 0x03. The HotKey3fMod value specifies the key-state modifiers for the hot key that is specified by the HotKey3Vkey value.

No restart is required when the setting is changed.
