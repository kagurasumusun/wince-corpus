fsdbase Component

The fsdbase component provides database functionality. It also supports database volumes on any mounted file system, including continued support for object-store databases.

Functions for Application Developers

The fsdbase component includes functions for application developers, which are defined in the Windbase.h header file. To import these functions, you must link to the fsdbase.lib file. The following table shows the functions included in the fsdbase component.
