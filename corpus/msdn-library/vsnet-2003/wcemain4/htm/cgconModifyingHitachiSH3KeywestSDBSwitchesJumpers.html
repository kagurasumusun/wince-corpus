Modifying the Hitachi US7729 HARP (Keywest) SDB Switches and Jumpers

  1. The following table shows the functionality of switch S1. In order to write to the flash, DIP switch S1-3 needs to be in the Off position.
    S1-1 S1-2 S1-3 S1-4 Function
    On Off Off On Code executes from boot monitor after reset.
    Off Off Off On Code executes from flash memory after reset.
    X X Off X Flash is not write-protected.
    X X On X Flash is write-protected.
  2. Build the platform.
