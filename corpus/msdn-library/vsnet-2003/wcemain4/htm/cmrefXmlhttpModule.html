xmlhttp Component

The xmlhttp component implements the XMLHTTP object.

Functions for Application Developers

The xmlhttp component contains functions for application developers. To import these functions, you must link to the Xmlhttp.lib file. The following functions are included in the xmlhttp component:

  • abort Method (IXMLHTTPRequest)
  • getAllResponseHeaders Method (IXMLHTTPRequest)
  • getResponseHeader Method (IXMLHTTPRequest)
  • open Method (IXMLHTTPRequest)
  • send Method (IXMLHTTPRequest)
  • setRequestHeader Method (IXMLHTTPRequest)

Interfaces

The xmlhttp module exposes the IXMLHTTPRequest interface.
