schedlog Component

The schedlog component provides functions to assist OEMs using the LogThread* and LogProcess* APIs.

Functions for OS Developers

The schedlog component includes functions for OS configuration, which are defined in the Schedlog.h header file. To import these functions, you must link to the Schedlog.lib file. The following functions are included in the schedlog component:

  • SchedLogGetProcessName
  • SchedLogGetThreadProgramCounter
  • SchedLogTranslate
