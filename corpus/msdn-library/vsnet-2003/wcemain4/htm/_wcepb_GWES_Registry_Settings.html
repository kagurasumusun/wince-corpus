GWES Registry Settings

The Graphics, Windowing, and Events Subsystem (GWES) module in Windows CE supports the windows, dialog boxes, controls, menus, and resources that make up the Windows CE user interface (UI).

General GWES-related settings are controlled by registry values under the following registry key.

[HKEY_LOCAL_MACHINE\SYSTEM\GWE]

The following registry value enables window animations.

"Animate"=dword:<0 or 1>

The following registry value specifies the height of the non-client caption.

"cyCap"=dword:<height>

The following registry value specifies the minimum height of the scroll thumb (for multiple pages).

"cyThMin"=dword:<height>

The following registry value specifies the default height of the scroll thumb.

"cyThDef"=dword:<height>

The following registry value specifies the size of widget images for non-client buttons and menu checkmarks: 0=normal, 1=Big.

"WidgSz"=dword:<0 or 1>

The following registry value specifies the width of a non-client button.

"cxWidg"=dword:<height>

The following registry values specify the values for SM_CXHSCROLL, SM_CYHSCROLL, SM_CXVSCROLL, and SM_CYVSCROLL.

"cxHScr"=dword:<width>
"cyHScr"=dword:<height>
"cxVScr"=dword:<width>
"cyVScr"=dword:<height>

The following registry value specifies the system colors

"SysColor"=hex:<array of RGB values>

The following registry value enables repaint at power on. Default is 1, 0 disables repaint at power on.

"PORepaint"=dword:<0 or 1>

The following registry value specifies the number of milliseconds before search mode of ListBox terminates. Default=1000.

"dtLBSrch"=dword:<milliseconds>

The following registry key example shows how to customize general GWES settings.

[HKEY_LOCAL_MACHINE\SYSTEM\GWE]
    "cyCap"=dword:2A
    "WidgSz"=dword:1
    "cyThMin"=dword:15
    "cyThDef"=dword:32
    "cxWidg"=dword:32
    "cxHScr"=dword:38
    "cyHScr"=dword:38
    "cxVScr"=dword:38
    "cyVScr"=dword:38
    "SysColor"=hex:E0,E0,E0,00, 00,80,80,00, 80,80,FF,00, 80,80,80,00,
                   C0,C0,C0,00, FF,FF,FF,00, 00,00,00,00, 00,00,00,00,
                   00,00,00,00, FF,FF,00,00, C0,C0,C0,00, C0,C0,C0,00,
                   80,80,80,00, 00,00,FF,00, FF,FF,00,00, C0,C0,C0,00,
                   80,80,80,00, 80,80,80,00, 00,00,00,00, C0,C0,C0,00,
                   FF,FF,FF,00, 00,00,00,00, DF,DF,DF,00, 00,00,00,00,
                   FF,FF,E1,00

For the system color array in the example above, byte 1 is the red value of COLOR_SCROLLBAR, byte 2 is the green color, byte 3 is the blue color, and byte 4 is 0. The cycle then repeats itself: byte 5 is the red value of COLOR_BACKGROUND, byte 6 the green color, byte 7 the blue color, and byte 8 is 0.

Notification-related settings are controlled by registry values under the following registry key.

[HKEY_LOCAL_MACHINE\SYSTEM\GWE\Notify]

The following registry value specifies the name of the file that stores the notification databases.

"volume"="\\hard disk\\notify.db"

If the Volume key does not exist, the operating system (OS) creates a database named DB_notify_queue in the object store by default.

The following registry value specifies the delay for blocking the CeEventHasOccured function while the OS initializes, in milliseconds.

"ShortApiTimeout"=DWORD:5000

The default value for ShortApiTimout is set to 5000 milliseconds.

The following registry value specifies the delay to block all other APIs while the OS initializes, in milliseconds.

"LongApiTimeout"=DWORD:15000

The default value for LongApiTimeout is 15000 milliseconds.

The following registry value specifies the delay for which the OS should wait for external file systems to initialize, in milliseconds.

"MountTimeout"=DWORD:20000

The default value for MountTimeout is 20000 milliseconds. MountTimeout determines how many times the OS attempts to mount the database volume. After each attempt, the thread that is trying to mount the volume waits for 5000 milliseconds before the next attempt. This fact means that the OS makes a maximum of MountTimeout/5000 attempts to mount a database volume.
