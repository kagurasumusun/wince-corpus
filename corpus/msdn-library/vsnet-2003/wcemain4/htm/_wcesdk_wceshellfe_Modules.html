wceshellfe Modules

The wceshellfe module group supports the following Windows CE shell-related modules: Handheld PC–style shell, Microsoft Pocket Internet Explorer, Help, and Control Panel applications.

The following table shows the modules contained in the wceshellfe group.

Module Description Note Library
advbacklight Supports advanced backlight functionality.   AdvBacklight.dll
asform Shell support module. Required for Handheld PC–style shell, included in the full-version OS. Exposes no public functions. Asform.lib
bthpnl Supports Bluetooth settings for wireless communications. Exposes no public functions. Bthpnl.lib
ceshell Shell support module. Required for Handheld PC–style shell, included in the full-version OS. Ceshell.lib
chajeiim Supports an input method (IM) with a soft keyboard that allows Chang Jei input. Exposes no public functions. Chajeiim.lib
chsime98 Supports the Simplified Chinese (Pinyin) Input Method Editor (IME). Exposes no public functions. Chsime98.lib
control Control Panel application module. Required for Windows CE Control Panel, included in the full-version OS. Exposes no public functions. Control.lib
cplmain This module supports the main Control Panel application. Windows CE Control Panel allows users to set a variety of system-wide properties, such as mouse sensitivity, network configuration, and the desktop color scheme. This module includes a set of components. Contains components required for Windows CE Control Panel. This module is included in the full-version OS. Cplmain.lib
ctlpnl Control Panel helper process module. Required for Windows CE Control Panel, included in the full-version OS. Exposes no public functions. Ctlpnl.lib
explorer Supports Handheld PC–style shell. Included in the full-version OS. Exposes no public functions. Explorer.lib
hrts_dll Supports the FreeCell application. Exposes no public functions. Hrts_dll.lib
htmlview Hypertext Markup Language (HTML) Help engine control module. Included in the full-version OS. Exposes no public functions. Htmlview.lib
iexplore Supports Microsoft Pocket Internet Explorer browser. Included in the full-version OS. Exposes no public functions. Iexplore.lib
imgdecmp Supports Pocket Internet Explorer image decompression. Included in the full-version OS. Exposes no public functions. Imgdecmp.lib
intll Regional Settings Control Panel application module for landscape orientation. Included in the full-version OS. Exposes no public functions. Intll.lib
intllime Supports the Microsoft Pinyin IME. Exposes no public functions. Intllime.lib
intlp Regional Settings Control Panel application module for portrait orientation. Included in the full-version OS. Exposes no public functions. Intlp.lib
kimeui Supports the Korean IME. Exposes no public functions. Kimeui.lib
msimecj Supports Chang Jei input. Exposes no public functions. Msimecj.lib
msimeph Supports phonetic input based on the Bopomofo standard. Exposes no public functions. Msimeph.lib
msimepy Supports PinYin (phonetic) input. Exposes no public functions. Msimepy.lib
msimesp Supports Shuang Pin input. Exposes no public functions. Msimesp.lib
msimeuic Default IME UI module. Exposes no public functions. Msimeuic.lib
msimk Supports a sample IM with a soft keyboard that allows Hangul input. Exposes no public functions. Msimk.lib
pegcards Supports the Solitaire application. Exposes no public functions. Pegcards.lib
peghelp Supports HTML-based Help files. Included in the full-version OS. Exposes no public functions. Peghelp.lib
phonim Supports phonetic input based on the Bopomofo standard. Exposes no public functions. Phonim.lib
pimetcdb Supports database for traditional Chinese pocket IME. Exposes no public functions. Pimetcdb.lib
solitare Supports the Solitaire application. Exposes no public functions. Solitare.lib
spim Supports Shuang Pin input. Exposes no public functions. Spim.lib
stguil Provides storage manager UI settings for a landscape orientation. Exposes no public functions. Stguil.lib
stguip Provides storage manager UI settings for a portrait orientation. Exposes no public functions. Stguip.lib
taskman Supports a sample Task Manager shell. Exposes no public functions. Taskman.lib
transcriber Supports the Transcriber Handwriting Recognizer application. Exposes no public functions. Transcriberdeu.lib, Transcriberenu.lib, Transcriberfra.lib
webview Pocket Internet Explorer HTML module. Included in the full-version OS. Exposes no public functions. Webview.lib
