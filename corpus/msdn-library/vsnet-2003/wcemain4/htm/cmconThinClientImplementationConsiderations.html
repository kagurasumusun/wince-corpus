Thin Client Implementation Considerations

Windows Thin Clients have the following design requirements. Related recommendations and considerations are defined later in this guide.

  • Optional terminal emulators. Windows-based Terminal devices may include optional third-party terminal emulators.
  • Windows Thin Client minimal shell. Windows Thin Client devices include a minimal shell to support process management of the terminal emulation software. Windows Thin Client devices are restricted from including the Handheld PC shell.
