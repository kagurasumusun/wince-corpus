Microsoft Windows CE .NET  

OAL Migration Issues

The following table describes migration issues for the OAL.

Issue Description
All microprocessors: GetIdleTime The support of this function requires that you declare and calculate the following variables in the OAL. 
// translation constant in 1 ms units
extern DWORD idleconv;
// 64-bit idle time in ms
extern DWORD curridlehigh, curridlelow;
All microprocessors In Windows CE .NET, the OEMIdle function name is common to all microprocessors.
X86: IOCTL_HAL_REBOOT In Windows CE .NET, the x86 microprocessor includes code that enables a device with this microprocessor to soft reset to the startup routine or to the Eboot boot loader startup routine.
X86: OEMFlushCache The OEMFlushCache flush function is needed for all x86 platforms. The kernel calls this function when the CacheSync function is called.
SHx: SH3DSP In Windows CE .NET, you need to declare the following variable: export_SH3DSP. Set the data to the following value. 
_SH3DSP   .data.l 0

The SH3DSP variable is used to identify an SH3 microprocessor with DSP support. Setting the value to 0 indicates there is no DSP present on the SH3 processor and 1 indicates there the DSP is present.
SHx: SH4CacheLines This variable describes the number of cache lines supported by the SH4 microprocessor.
SHx: nested interrupts In the SHx architecture, the kernel uses the IntrPrio structure that provides information on nested interrupts. The structure provides the kernel with the information on what interrupts are masked when the current interrupt is being handled.

To gain access to the structure, the following variable must be declared in the OAL: extern BYTE IntrPrio[];
MIPS: nested interrupts In the MIPS architecture, the kernel uses the IntrPriority and IntrMask structures to provide information about nested interrupts. The structures provide the kernel with the information about what interrupts are masked when the current interrupt is being handled.
IOCTL_QUERY_PHYSICALMEM You need to implement this IOCTL to support applications such as the kernel debugger.
ARM: OEMARMCacheMode This function allows you to change the cache bits configurations in the page table entries for only the ARM processors. These bits determine cache mode and write buffer usage. The ARM kernels still default to their previous settings but in Windows CE .NET you can change those settings if desired, and the ARM microprocessor supports the change. This function is required in every ARM OAL.
ARM: OEMInterruptHandlerFIQ Windows CE .NET enables the routing of the Fast Interrupt reQuest (FIQ) OAL. To facilitate the routing, you need to implement the following required function. 
void OEMInterruptHandlerFIQ(void);

This function must be part of the your OAL for any ARM build to succeed, even if it is just a stub.
ARM: OEMInterruptHandler Windows CE .NET enables nesting support if you require it. The kernel calls the OEMInterruptHandler function when a normal interrupt occurs. You need to determine if nesting is required.

The following is a code example of the function.

int OEMInterruptHandler(unsigned int ra)
