Windows Media Player Control Summary

The Windows Media player control was created to enable Windows Media player functionality to exist as a ActiveX control inside a Web page along with other content and hosted by the Windows CE Web browser. The Windows Media Player control is a versatile tool for presenting local and streaming multimedia files. Combined with DirectShow, it supports Windows Media Technologies and other major media file formats. These file formats can be streamed from locally stored files using just the Windows Media Player control, and, when combined with Windows Media Technologies, they can be streamed over networks.

The Windows Media Player control for Windows CE is almost identical to the version of the control that is available for x86-based PCs. The Windows CE Windows Media Player control supports an essential subset of the properties, methods, and events of the desktop control.
