MUI Module Creation

Two batch files are required to create the MUI modules. The following list shows the installation process required:

  1. Create an OS build.
  2. Call CREATEMUI<LCID> from _FLATRELEASEDIR.
  3. Locate *.MUI files and Multiui.bib.
  4. Open the Multiui.bib file and append the contents into common.bib in the Files section.
  5. Modify the common.reg and set the UI for the Locale Identifier (LCID) that you want to display. This should be the same LCID provided to CREATEMUI, and should be the same as the system default language. The following code shows the registry settings needed for creating the MUI module. 
    ;@CESYSGEN IF COREDLL_MULTIUI
[HKEY_LOCAL_MACHINE\MUI
    ;Update the enable field to enable the MUI
    "Enable"=dword:1
    ;Update the Syslang field to set the system default LANGID
    "Syslang"=dword:0409
[HKEY_CURRENT_USER\MUI]
    ;Update the CurLang field to set the user default LANGID
    "CurLang"=dword:0412
    ;@CESYSGEN ENDIF
  6. Run Makeimg again from the command line to create the new OS image by typing the following command: 
    makeimg
  7. Download and start the OS.
