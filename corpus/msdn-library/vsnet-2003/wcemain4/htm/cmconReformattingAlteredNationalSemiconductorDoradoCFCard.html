Reformatting an Altered National Semiconductor Dorado CF Card

  1. Insert the CF card into a Windows 95/98–based development workstation.
  2. Open an MS-DOS command prompt window.
  3. Format and copy the MS-DOS system files to the CF card by typing format [drive]: /s.

    drive is the drive letter of your CF card reader on your Windows 95/98–based development workstation.

    - or -

    If the CF card is already FAT-formatted, you can use sys to copy the system files to the CF card by typing format sys [drive]:.

    Note   Windows 2000 and Windows XP do not have a MS-DOS environment, so you cannot complete this step on one of those operating systems.
  4. Proceed with creating a boot disk for an x86 SDB.
