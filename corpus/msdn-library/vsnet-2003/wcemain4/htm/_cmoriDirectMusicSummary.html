DirectMusic Summary

DirectMusic is a different type of API than the waveform audio API and DirectSound. DirectMusic is designed less around providing access to hardware resources and more around the idea of providing software support for the MIDI music format. It takes message-based musical data and converts it into wave samples using a software-based synthesizer. It also contains a compositional engine that dynamically plays back musical elements authored by a human composer.
