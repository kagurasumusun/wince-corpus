mgprint Component

The mgprint component provides support for printing.

Functions for Application Developers

The mgprint component includes functions for application developers, which are defined in the Wingdi.h header file. To import these functions, you must link to the mgprint.lib file. The following functions are included in the mgprint component:

  • AbortDoc
  • EndDoc
  • EndPage
  • SetAbortProc
  • StartDoc
  • StartPage
