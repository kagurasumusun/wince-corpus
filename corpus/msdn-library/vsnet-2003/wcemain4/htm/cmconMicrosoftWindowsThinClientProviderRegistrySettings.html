Thin Client Provider Registry Settings

The following code example shows the default registry settings for your shell configuration contained in the Project.reg file.

[HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Shell]
    "TaskmanTitle"= "Terminal Connection Manager"
    "EnableAutoConnect"=DWORD:0
    "DisableConfigureTab"=DWORD:0
    "SetupExe"="Wbtsetup.exe"
    "ScreenSaver"="SSFloat.dll"
    "ScreenSaverEnable"=DWORD:1
    "HotKeyEnable"=DWORD:1
    "HotKey1VKey"=DWORD:26
    "HotKey1fMod"=DWORD:3
    "HotKey2VKey"=DWORD:28
    "HotKey2fMod"=DWORD:3
    "HotKey3VKey"=DWORD:24
    "HotKey3fMod"=DWORD:3  
[HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Shell\Startup\10]
    "Application"="Wbtwizrd.exe"
    "CmdLine"=""
    "WaitOnProcess"=DWORD:1
[HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Clients\Registration\RDP]
    "Description"="Microsoft Remote Desktop Client"
    "Type"="RDP"
    "NewExe"="Tsconwiz.exe"
    "NewCmdLineArgs"=""

You also can set up the default client by specifying the following registry value.

[HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Clients\Registration]
    "DefaultClient"="<client key>"
