mgdraw Component

The mgdraw component supports drawing tool functionality.

Functions for Application Developers

The mgdraw component includes functions for application developers, which are defined in the Wingdi.h header file. To import these functions, you must link to the mgdraw.lib file. The following table shows the functions that are included in the mgdraw component.

Function
CreateDIBPatternBrushPt GetPixel
CreatePatternBrush GetSysColorBrush
CreatePen PatBlt
CreatePenIndirect Polygon
CreateSolidBrush Polyline
DrawEdge Rectangle
DrawFocusRect RoundRect
Ellipse SetBrushOrgEx
FillRect SetPixel
FillRgn SetROP2
