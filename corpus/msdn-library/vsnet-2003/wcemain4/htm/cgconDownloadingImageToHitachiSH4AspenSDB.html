Downloading the OS Image to the Hitachi US7750 HARP (Aspen) SDB

You can only start here if the Window CE boot loader has already been downloaded to the Hitachi US7750 HARP (Aspen) SDB. If you need to determine if the boot loader has been downloaded, see OEM Boot Loader Output for the Hitachi US7750 HARP (Aspen) SDB.

  1. Turn off the Hitachi US7750 HARP (Aspen) SDB.
  2. Be sure DIP switch S1-1 is in the Off position.
  3. Turn on the Hitachi US7750 HARP (Aspen) SDB.
  4. Download the OS image.
