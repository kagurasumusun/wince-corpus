Setting Up the Hitachi US7750 HARP (Aspen) SDB Hardware

  1. Detach the Tahoe board from the Hitachi US7750 HARP (Aspen) SDB.
  2. Connect a 25-pin ribbon cable to the CN4 connector on the Hitachi US7750 HARP (Aspen) SDB, so that pin 1 is near the Dbg Ser port.

    You can identify pin 1 by the red stripe on the 25-pin ribbon cable.

  3. Attach the power supply to the Hitachi US7750 HARP (Aspen) SDB.
  4. Reattach the Tahoe board to the Hitachi US7750 HARP (Aspen) SDB.
  5. If you are using the MQ200 display card, be sure that switch S1 on the MQ200 is set to the Down position or the MQ200 will not function correctly.
  6. Connect a serial port on the development workstation to the Hitachi US7750 HARP (Aspen) SDB debug serial port. Set the baud rate to 57600.

    The debug serial port is located on the front panel and is labeled Dbg Ser.

  7. Modify the Hitachi US7750 HARP (Aspen) SDB Switches and Jumpers.
