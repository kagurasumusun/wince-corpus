Creating a Boot Disk for an x86 SDB

Downloading an OS image to an x86 SDB requires a DOS-formatted boot disk containing LoadCEPC.exe, Eboot.bin, AutoExec.bat, and other files. AutoExec.bat may need to be altered for your specific configuration.

On the CEPC, Lanner and Advantech you have the choice of using a floppy disk as the boot disk, a disk-on-chip, or a hard drive. But on the National Geode SP4SC30 Development Platform you will have to use a properly formatted CF card as the boot disk.

If you are using the National Semiconductor Geode SP4SC30 Development Platform with a new CF card or if your CF card contents become corrupted, you will need to format the CF card. Formatting the CF card will require access to a system that can format a bootable FAT partition and copy over the DOS system files. A Microsoft Windows 95/98/Me-based development workstation may work best. Another option is to add a floppy drive to the National Semiconductor Geode SP4SC30, boot from a DOS diskette, and then format the CF card, which appears as a fixed disk to DOS.

To create a boot floppy for an x86 SDK

  1. In %CEPBDir%\Cepb\Utilities, run WebSetup.exe.

    This will install utility tools to the default Microsoft Windows directory on your development workstation.

    Note   This only needs to be done once. Once the utility tools are installed, the *.144 file just needs to be run.
  2. On your development workstation, insert the boot disk, and in %CEPBDir%\Cepb\Utilities, run CEPCBoot.144.
  3. When the imaging dialog appears, select the A Drive button and the utility will prepare the floppy.
  4. On the boot disk, open the AutoExec.bat file, and verify that network card values listed for NET_IRQ and NET_IOBASE are correct.

    The NET_IRQ interrupt request (IRQ) value used by the Ethernet card is typically displayed by the BIOS when the x86 SDB boots. Note this value and set it in the AutoExec.bat file.

    If you are using a PCI-based Ethernet card, set NET_IRQ and NET IOBASE equal to 0 to allow Eboot.bin to automatically locate and use the first PCI network card found for downloading. If NET_IRQ is specified, but NET_IOBASE is 0, Eboot.bin will search for the first PCI network card with a matching IRQ and use it. If both the NET_IRQ and NET_IOBASE values are provided, then a card matching those settings must be present in the system.

  5. If you are using the National Semiconductor Geode SP4SC30 Development Platform, copy the contents of the boot disk to the bootable CF card.
