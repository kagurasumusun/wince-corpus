IME98 Registry Keys

Microsoft IME98 uses the registry to store various settings. However, .reg files provided in Platform Builder do not have any IME98-specific registry entries. IME98 writes default registry values at its first boot.

You can find IME98 registry entries in HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Ime\Japan\IME98. You may export the key for modification using Remote Registry Editor.
