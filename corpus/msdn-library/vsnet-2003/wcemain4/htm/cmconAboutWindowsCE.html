About Windows CE .NET

A Windows CE .NET operating system is built from individual components that can be organized into major technology areas. The following topics describe the major technology areas in Windows CE and provide guidance on selecting the types of components that will meet the needs of your platform.

Technology area Description
Applications and Services Development Technologies, such as Microsoft ActiveSync®, COM, Microsoft Foundation Classes (MFC) for Windows CE, and Extensible Markup Language (XML), to help developers create applications and services for your platform.
Board Support Packages Software that implements and supports the OEM adaptation layer (OAL) and device drivers for a standard development board.
Communication Services and Networking Technologies, such as 802.11 networking, Web servers, Universal Plug and Play, and the Telephony API, that can allow your platform to share information with other devices.
Core OS Services Information about the Windows CE kernel and other features common to all Windows CE platforms.
Internationalization Technologies to support platform localization as well as input methods for Asian languages.
Multimedia Technologies Technologies, such as waveform audio, Microsoft Direct3D®, Microsoft Windows Media™ support, and the DVD-Video API, to support high-performance graphics and sound applications.
Object Store and Registry Technologies, such as file systems, the object store, and the registry, to provide various types of data storage capabilities on your platform.
Registry Settings Descriptions of the configuration information that you can store in the registry for applications and hardware running on your operating system.
Security Services Technologies, such as the CryptoAPI, Secure Sockets Layer, and smart card, that help keep your platform, its applications, and their data secure.
Shell and User Interface Technologies, such as graphics device interface (GDI), Graphics, Windowing, and Events Subsystem (GWES), and input methods, supporting the interface between the user, the applications, and the operating system.
User Applications Standard applications, such as Microsoft Internet Explorer, Windows Media player, and games, that you can add to your platform.
