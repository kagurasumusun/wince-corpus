Creating a Dictionary Source File

The dictionary source file consists of a text file in Shift Japanese Industrial Standard (JIS) format. The dictionary compiler reads the source file and converts it into Pocket IME 2.0 dictionary format.

The following example shows how to create a dictionary source file.

The first line specifies the title of the dictionary. The title of the dictionary must be different from the dictionary file name. The dictionary title contains a human-readable string that is used in the Microsoft Pocket IME System Dictionary Property dialog box of Pocket IME. The dictionary title can contain a maximum of 20 full-width characters (40 bytes) and must be written in Shift JIS format.

The lines immediately following the title line list specific data elements consisting of character strings that will be included in the dictionary. These data elements must be specified in the following order.

{reading}<tab>{display}<tab>{part of speech}<tab>{cost}

The reading string can contain characters in full-width Hiragana and the Western alphabet, as well as numeric characters and symbols, which must be all in full width. The Western alphabets must be in lower-case. The maximum length of the reading string is 63 bytes.

The display string can contain any printable character. The maximum length of the reading string is 63 bytes. You can include characters that are encoded in Unicode, but not in Shift JIS format. The following example shows how to specify a character in Unicode.

##{Unicode Character Code in Hexadecimal}
E.g., ##9dd7

After specifying the display string, you need to select a code for the part of speech and assign it to the data element. The part-of-speech code consists of a decimal number and must be written in half-width numeric characters. For a list of applicable codes, see Part-of-Speech Codes.

The word cost defines a conversion priority for the selected data element. If there are two words that share the same reading string and part-of-speech code, the conversion engine will choose the low-cost word as the primary candidate. The cost value must be specified with a half-width digit character with a value ranging from 0 to 255.

If a word in the dictionary source file exists in the standard system dictionary, the word will not be added to the dictionary file. The dictionary checks in the standard system dictionary first before it adds a data element to an add-on dictionary.
