ceshell Module

This module supports the Windows shell.

Functions for Application Developers

The ceshell module exposes functions, which are defined in the Ceshell.h header file. To import these functions, you must link to the Ceshell.lib file. The following functions are contained in the ceshell module:

  • SHAddToRecentDocs
  • SHBrowseForFolder
  • SHGetFileInfo
  • SHGetMalloc
  • SHGetPathFromIDList
  • SHGetSpecialFolderLocation
