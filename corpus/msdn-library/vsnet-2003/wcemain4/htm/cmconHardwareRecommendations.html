Hardware Recommendations

The following list contains recommendations for the core system in Windows Thin Client hardware:

  • Sufficient nonvolatile RAM. Windows Thin Client must have sufficient nonvolatile RAM for the registry to grow to at least 50 kilobytes (KB).
  • An accelerated video graphics adapter.
  • A software-controlled power button that would allow a registry flush operation prior to loss of power. This prevents any loss of persistent settings for the Windows Thin Client device.

Additionally, it is useful for all Windows Thin Client devices to have contrast control, and for all Windows Thin Client devices that have color displays to have brightness control as well.
