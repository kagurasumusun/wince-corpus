mgdc Component

The mgdc component provides device context functionality.

Functions for Application Developers

The mgdc component includes functions for application developers, which are defined in the Wingdi.h header file. To import these functions, you must link to the mgdc.lib file. The following functions are included in the mgdc component:

  • CreateDC
  • ExtEscape
  • RestoreDC
  • SaveDC
