Persistent Storage Manager

Intel Persistent Storage Manager (PSM) is an installable file system for Intel StrataFlash memory and is designed only for SA11xx platforms. PSM handles many of the tasks associated with optimizing linear flash memory.

Linear flash refers to the way a memory location is accessed. When connected directly to a memory bus of a microprocessor, the contents of linear flash memory appear as single, contiguous blocks. You can read specific locations in flash memory, but not randomly modify them. Instead, you can program locations, and you can erase groups of locations, which are called blocks.

For more information about flash memory and technical support for PSM, see the Intel Web site.
