International Issues

The following list shows updates affecting internationalization:

  • The environment variable %COUNTRY% has been replaced with %LOCALE%. The format of values has changed from the 3-characters standard to the 4-hex standard; so now COUNTRY=USA is LOCALE=0409.
  • For East Asian locales, we no longer pull in the Input Method Editors (IMEs) by default. All IMEs are now Sysgen components that can be selected in the Catalog. For example, if you choose the Japanese locale as the default system language, IME98 is not automatically pulled in. Instead, you select the IME in the Catalog.
  • Default fonts used for East Asia have been changed as follows, however the old fonts are available:
    • For Japanese, an additional font has been added to the MSGothic.ttc font. The MSUIGothic font is now used for the UI; thus, discontinuing the practice of using half-width characters in the UI.
    • For Simplified Chinese, the default font has changed from Sunfon to SimSun.
    • For Traditional Chinese, the default font has changed from MSMing to MingLiu.
    • For Korean, the default font has changed from GL_CE to Gulim. However, this is still the same font.
  • The default edit control for Japanese has been changed from Level 3 to Level 2.
