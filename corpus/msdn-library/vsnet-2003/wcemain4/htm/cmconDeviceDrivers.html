Device Drivers

A board support package (BSP) indicates that it does not support a particular hardware feature by using the BSP_NO* variables — BSP_NOAUDIO, BSP_NODISPLAY, BSP_NOKEYBD, BSP_NOETHER, BSP_NOPARALLEL, BSP_NOSERIAL, BSP_NOPCMCIA, BSP_NOSIR, BSP_NOUSB, and BSP_NOUSBSER. In the Platform Builder Catalog, component types typically indicate that they should be excluded from a project when a given variable is set. Typically, this is a BSP_NO* variable. For example, the audio component type indicates that it should be excluded from any project when BSP_NOAUDIO=1. This means that an initial project integrated development environment (IDE), just after closing the New Platform Wizard, will not include an audio driver because the platform does not support audio. If you later select from the Catalog a driver from this component type — for example, Ensoniq ES1371 — the action you took overrides the BSP_NOAUDIO variable.

When you select some device drivers from the Catalog that do not automatically have a SYSGEN variable set, you need to select a feature that automatically sets the SYSGEN variable from the Core OS category to enable the device drivers you have selected. For example, if you selected the Ensoniq ES1371 driver, you also need to select the Waveform Audio feature in the Catalog under Core OS, Display based devices (or Headless devices), Multimedia Technologies, Multimedia Components, and then Audio to set SYSGEN_AUDIO.
