Japanese IME98 Architecture

IME98 consists of the following dynamic-link libraries (DLLs), executables, and data files.

File Description
Ime98ceh.htm Online Help
Msime98.dll IME UI and interfaces to IMM
Msime98c.dll Advanced settings dialog boxes
Msime98d.dll Dictionary tool
Msime98g.grm Grammar dictionary
Msime98k.dll IME core functionality and conversion engine
Msime98m.dic Standard lexical database
Msime98m.exe System tray icon support
Msime98s.dic Compact lexical database
Msime98t.dll Miscellaneous support functions
Msime98u.dll Property dialog boxes
