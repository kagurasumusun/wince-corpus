Multilingual ROM Image

Typically, you select the set of languages that a device is capable of supporting by including particular code pages and locales when building the ROM image. A device that includes the code-page 1252 would, for example, usually include all the western European locales that use that code-page (because the bulky portion of locale support is the code-page, the incremental cost of including all locales that share a code page is small). Such a device might ship with the UI resources for say, English and French. If the user later wanted to upgrade the device to also support German, they would simply need to install the UI resource DLLs for German for the OS and for all their applications.

To enable the UI to display correctly for all the supported languages, you must include the appropriate fonts in the image. The OS includes several fonts to support all localized OS languages. By default, all appropriate fonts are included in the .BIB file for each language. To add more fonts to the OS image, you can include new entries in the FILES section of the PROJECT.BIB file. The following code example shows the addition of five fonts to an OS image.

//project.bib
FILES
;  Name          Path                               Memory Type
  tahoma.ttf     $(_FLATRELEASEDIR)\tahoma.ttf       NK     SHU
   cour.ttf      $(_FLATRELEASEDIR)\cour.ttf         NK     SHU
   arial.ttf     $(_FLATRELEASEDIR)\arial.ttf        NK     SHU
   symbol.ttf    $(_FLATRELEASEDIR)\symbol.ttf       NK     SHU
   times.ttf      $(_FLATRELEASEDIR)\times.ttf       NK     SHU

The U uncompress flag prevents any performance penalty associated with a compressed file. In most circumstances, fonts should be left uncompressed. To ensure that the desired font gets copied to the _FLATRELEASEDIR, add the font files to the directory.

public\<My Project>\Oak\Files

Finally, select the system's default language. To do this, set the LOCALE environment variable before running MAKEIMG. In the above example to set the default locale to English, set LOCALE=0409.
