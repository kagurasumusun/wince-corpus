File System Loading

FSD Manager calls the MyFSD_MountDisk function that is exported by MyFSD.dll. You can load an FSD two different ways. The following table shows the two ways an FSD can load.

Type of file system Loading method
Automatically loaded file systems If an FSD is listed under HKEY_LOCAL_MACHINE\System\StorageManager\AutoLoad registry key, it is loaded automatically. These files do not require a block driver under them. An example is the Intel persistent storage manager (PSM). For more information on the Intel PSM, see Persistent Storage Manager.
Block driver based file systems The Storage Manager loads all partition drivers whose block driver registry keys contain the IClass registry subkey. For an example of the IClass registry subkey, see the ATADISK and ATAPI registry keys. Using the specified partition driver, the Storage Manager enumerates partitions and loads file systems. For more information on the Storage Manager, see Storage Manager.

With the two methods of loading a file system, the actual file system is loaded multiple times with the help of the Storage Manager, and you can only call FSDMGR_RegisterVolume once per instance of an FSD.
