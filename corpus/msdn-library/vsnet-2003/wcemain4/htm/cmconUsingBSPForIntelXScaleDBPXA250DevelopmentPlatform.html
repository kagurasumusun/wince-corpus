Using the BSP for the Intel XScale DBPXA250 Development Platform

You can find any updates to the BSP for the Intel XScale DBPA250 Development Platform on the Intel Web site. Microsoft does not support the BSP on the Intel Web site.

The following steps show you the process of building a platform and installing an operating system (OS) image on the BSP for the Intel XScale DBPXA250 Development Platform.

  1. Install Microsoft® Windows® CE .NET 4.1 with Microsoft Platform Builder 4.1 and select support for the XScale microprocessor.
  2. Review the supported hardware and software features on the SDB and note any limitations that may impact your platform on the board. For more information, see Intel DBPXA250 Development Platform Supported Features.
  3. Set up the SDB hardware. For more information, see Setting up the Intel DBPXA250 Development Platform Hardware.
  4. Modify the switch and jumper settings on the SDB. For more information, see Modifying the Intel DBPXA250 Development Platform Switches and Jumpers.
  5. Configure the Microsoft HyperTerminal application to receive debug messages. For more information, see Configuring HyperTerminal for BSPs.
  6. Build the platform by choosing the Build menu in the Platform Builder IDE.
  7. Download the Ethernet boot loader to ROM or flash the SDB. For more information, see Downloading the Boot Loader to the Intel DBPXA250 Development Platform for the First Time.
  8. Download the OS image that you created for your platform to the SDB. For more information, see Downloading the OS Image to the Intel DBPXA250 Development Platform.
