icon Component

The icon component provides support for Win32 icons.

Functions for Application Developers

The icon component includes functions for application developers, which are defined in the Winuser.h header file. To import these functions, you must link to the icon.lib file. The following functions are included in the icon component:

  • CreateIconIndirect
  • DestroyIcon
  • DrawIconEx
  • LoadIcon
