mcombase Component

The mcombase component provides support for the Minimal COM feature.

Functions for Application Developers

The mcobase component contains functions for application developers. To import these functions, you must link to the Mcombase.lib file. The following functions are included in the mcobase component:

  • CoInitializeEx
  • CoUninitialize
  • CoCreateInstance
  • CoGetClassObject
  • CoFreeUnusedLibraries
  • CoSetState
