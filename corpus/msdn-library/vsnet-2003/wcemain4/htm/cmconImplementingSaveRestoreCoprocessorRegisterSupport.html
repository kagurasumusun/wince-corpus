Implementing Save and Restore Coprocessor Register Support

You can use the single set of variables and functions to save and restore coprocessor registers from a number of coprocessors at the same time. You must coordinate the single set of functions and variables to ensure that the proper state is saved and restored when the coprocessor is active and needs to have its state saved. The following example considers the case of saving and restoring debug registers.

  1. During OEMInit, set cbNKCoProcRegSize to be the maximum size buffer that will be required to save and restore state for all coprocessor registers.
  2. Set fNKSaveCoProcReg to 0 until coprocessor state must be saved.
  3. Set up the function pointers to point to OAL functions that will be used to initialize, save, and restore coprocessor state.
  4. If you intend to save debug registers, you only want to have the kernel call the save and restore functions when necessary.
  5. In OEMKDIoControl, the IOCTLs KD_IOCTL_SET_CBP, KD_IOCTL_CLEAR_CBP, KD_IOCTL_SET_DBP, and KD_IOCTL_CLEAR_DBP are used to set and clear data and code hardware break points. When a break point is set, you can increment fNKSaveCoProcReg by one and when a break point is cleared you can decrement fNKSaveCoProcReg.
  6. In addition to the fNKSaveCoProcReg value, you will need to track the location of the debug register data in the buffer area. You can do this by defining a structure that is static, but encompasses all the data that will ever be stored in the buffer.
