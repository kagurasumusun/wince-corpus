Event Tracking Issues

The event tracking subsystem has been changed to support a more dynamic model. Celog.lib is no longer linked to the kernel. Instead a dynamic-link library (DLL) is created that is loaded on demand or during boot time. In addition, you can load it on a retail OS or profile built OS. There is a new zone called CELZONE_MIGRATE, which is specific to the CELID_THREAD_MIGRATE event type.
