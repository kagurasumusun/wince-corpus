mgdibsec Component

The mgidbsec component creates device-intependent bitmap sections.

Functions for Application Developers

The mgidbsec component includes a function for application developers, which is defined in the Wingdi.h header file. To import this function, you must link to the mgdibsec.lib file. The following function is included in the mgidbsec component:

  • CreateDIBSection
