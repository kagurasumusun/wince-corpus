snmp Module

The snmp module contains the APIs that are required to support the Simple Network Management Protocol (SNMP). To implement SNMP in a Windows CE–based platform, you must include the ppp module in the platform configuration.

Functions for Application Developers

The snmp module contains functions for application developers, which are defined in the Snmp.h header file. To import these functions, you must link to the Snmp.lib file. The following table shows the functions that are included in the snmp module.
