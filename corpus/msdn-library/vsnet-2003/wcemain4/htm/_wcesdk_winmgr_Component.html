winmgr Component

The winmgr component provides support for the window manager.

Functions for Application Developers

The winmgr component includes functions for application developers, which are defined in the Winuser.h header file. To import these functions, you must link to the winmgr.lib file. The following table shows the functions that are included in the winmgr component.
