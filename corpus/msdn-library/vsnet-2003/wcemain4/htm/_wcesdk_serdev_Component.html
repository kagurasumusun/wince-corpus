serdev Component

The serdev component supports serial device drivers.

Functions for Application Developers

The serdev component includes functions for application developers, which are defined in the Winbase.h header file. To import these functions, you must link to the serdev.lib file. The following table shows the functions included in the serdev component.

Function
ClearCommBreak PurgeComm
ClearCommError SetCommBreak
EscapeCommFunction SetCommMask
GetCommMask SetCommState
GetCommModemStatus SetCommTimeouts
GetCommProperties SetupComm
GetCommState TransmitCommChar
GetCommTimeouts WaitCommEvent
