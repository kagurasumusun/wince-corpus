coredll Module

The coredll module is the basic operating system (OS) module that provides core functionality to other modules. This module must be present on all platforms, but not all of its components are always required.

Functions for OS Developers

The coredll component includes functions for OS configuration, which are defined in the Celog.h, Pkfuncs.h, Pwinreg.h, Pwinuser.h, and Windbase.h header files. To import these functions, you must link to the coredll.lib file. The following table shows the functions included in the coredll component.

CeLogData RegisterTaskBar
CeLogReSync RegRestoreFile
CeLogSetZones SetOOMEvent
