device Module

The device module is the device manager, which provides loading and unloading APIs, provides power notification callbacks, tracks all loaded devices, and issues notifications. It is included on all Microsoft® Windows® CE–based platforms.

Functions for Application Developers

The device module contains functions for application developers, which are defined in the Winbase.h header file. To import these functions, you must link to the device.lib file. The following table shows the functions included in the device component.

Function
ActivateDevice RegisterDevice
ActivateDeviceEx RequestDeviceNotifications
CeResyncFilesys ResourceCreateList
DeactivateDevice ResourceRelease
DeregisterDevice ResourceRequest

LoadFSDEx
