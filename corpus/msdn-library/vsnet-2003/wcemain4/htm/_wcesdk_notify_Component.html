notify Component

The notify component supports the Windows CE event notification system.

Functions for Application Developers

The notify component includes functions for application developers, which are defined in the Notify.h header file. To import these functions, you must link to the notify.lib file. The following table shows the functions that are included in the notify component.

Function
CeClearUserNotification CeRunAppAtEvent
CeGetUserNotification CeRunAppAtTime
CeGetUserNotificationHandles CeSetUserNotification
CeGetUserNotificationPreferences CeSetUserNotificationEx
CeHandleAppNotifications
