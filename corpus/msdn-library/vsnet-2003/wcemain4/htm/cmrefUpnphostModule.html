upnphost Module

The upnphost module supports the UPnP device-hosting feature.

Interfaces

The upnphost module implements the following interfaces:

  • IUPnPEventSink
  • IUPnPEventSource
  • IUPnPRegistrar
  • IUPnPReregistrar
  • IUPnPDeviceControl
