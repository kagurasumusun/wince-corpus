msmq Modules

The msmq modules support Message Queuing functionality. Message Queuing supports communication between the various parts of a distributed application. Message Queuing technology enables applications that are running at different times to communicate across networks and systems that might be temporarily offline. To accomplish this functionality, applications communicate with each other by sending messages to various message queues.

The following table shows the modules contained in the msmq group.

Module Description Note Import file
mqoa Supports Message Queuing Server. Exposes no public functions. Mqoa.lib
msmqadm Provides Message Queuing administration and configuration functionality. Exposes no public functions. Msmqadm.lib
msmqd Supports the main Message Queuing engine, which is implemented in a device driver. Exposes no public functions. Msmqd.lib
msmqrt Supports the main Message Queuing run-time application programming interface (API) set. Implements the Message Queuing API set. Msmqapix.lib
visadm GUI support for Msmqadm.exe and the Message Queuing configuration. Exposes no public functions. Visadm.lib
