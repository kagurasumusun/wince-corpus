Microsoft Windows CE .NET  

Migration Map

The documentation for Microsoft® Windows® CE 3.0 presented several sample configurations to help you start configuring a platform. Your platform may be based on one of these configurations. If it is, the following topics will help you migrate your platform to a Windows CE .NET platform. Each of the following topics maps the Windows CE 3.0 features within a sample configuration to the equivalent Windows CE .NET features and associated SYSGEN variables:

  • Minkern

    A minimal version of Windows CE.

  • Mininput

    A version of Windows CE that featured user input and device driver support for devices used directly by the Graphics, Windows, and Events Subsystem (GWES) module.

  • Mincomm

    A version of Windows CE that featured communications and networking.

  • Mingdi

    A version of Windows CE that featured graphics device interface (GDI) support.

  • Minwmgr

    A version of Windows CE that featured window management.

  • Minshell

    A nearly complete version of Windows CE that featured the Task Manager and the Command Processor.

  • Maxall

    A fully configured version of Windows CE that included the majority of the operating system (OS) components, including communication applications and H/PC applications.

  • IESample

    A demonstration system that used Microsoft Internet Explorer components.

  • MaxDX

    A nearly complete version of Windows CE that included all Microsoft DirectX® application programming interface components.

If you are migrating OS components or applications, see Migration Issues.
