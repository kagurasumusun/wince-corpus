East Asian Line Breaking

When platform developers include the MGFE component in your OS image, the DrawText function applies non-Roman line breaking rules to the range of Unicode non-Roman characters. Windows CE provides default rules for Kinsoku, double-byte character set (DBCS), half-width Katakana, and ASCII English characters. A string will not break on one of these characters.

For more information about East Asian Line Breaking, see Enabling Asian Line Breaking.
