PC Card Requirements

There are two limitations that affect the use of PC Cards on a CEPC.

  1. The CEPC has the following PC Card socket controller, ISA-based, requirements:
    • The Windows CE PC Card driver was originally written to control an Intel 82365 PCIC socket controller chip. However, other compatible chips exist. The socket controller chip requires two I/O port addresses, either 0x3E0 and 0x3E1 or, in the case of some compatible chips, 0x3E2 and 0x3E3.
    • To control the socket controller chip, the Windows CE PC Card driver uses IRQ 11 and 64 KB of low memory at a memory address range of 0xD0000 through 0xDFFFF for accessing common and attribute memory spaces. The memory address range for slot 1 is 0xD0000 through 0xD7FFF. The memory range for slot 2 is 0xD8000 through 0xDFFFF.
  2. The CEPC also has support for a PCI-based PC Card socket controller based on the TI-1250 controller (TI-1225 also works).
  3. The TI-1250 driver requires a BIOS capable of configuring a CardBus adapter. The driver can assign memory windows, but cannot configuring IRQ routing.
  4. If you know that the reader has been assigned an interrupt, but it is not being indicated in the InterruptLine field of the PCI configuration registers for the device, you can manually set the IRQ and SysIntr used by setting IRQ and SysIntr entries under HKEY_LOCAL_MACHINE\Drivers\PCMCIA.
