Japanese Pocket IME Interfaces

Pocket IME 2.0 exposes a set of interfaces that enable the Pocket IME UI to communicate with the kernel. The following table lists the interfaces that are exposed through the Pocket IME module.

Interface Description
IFEDictionary Allows clients to access a user dictionary of Pocket IME 2.0.
IImeIPoint2 Manages the behavior of the conversion kernel.
IImeIPointNotifySink Called by the IME conversion service to notify the UI of composition buffer changes and to request action and information from the IME UI.
