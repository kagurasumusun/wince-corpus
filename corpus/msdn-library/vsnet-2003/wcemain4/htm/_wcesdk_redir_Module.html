redir Module

The redir module implements the network redirector module and provides support for Microsoft® Win32® Wnet application programming interfaces (APIs).

Functions for Application Developers

The redir module contains functions for application developers, which are defined in the Winnetwk.h header file. To import these functions, you must link to the Redir.lib file. The following table shows the functions that are included in the redir module.

Function
WnetAddConnection3 WnetEnumResource
WnetCancelConnection2 WnetGetConnection
WnetCloseEnum WnetGetUniversalName
WnetConnectionDialog1 WnetGetUser
WnetDisconnectDialog WnetOpenEnum
WnetDisconnectDialog1
