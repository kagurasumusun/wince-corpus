rdp Modules

The rdp module group includes modules that support the ability to connect remotely to a desktop computer or a terminal server based on Microsoft® Windows NT®, Windows® 2000, and Windows XP Professional.

The following table shows the modules contained in the rdp module group.

Module Description Note Library
mstscax The Microsoft ActiveX® component that handles all communications for the Remote Desktop Protocol (RDP) client.   Mstscax.lib
prnprxy The printer proxy component used to redirect RDP printer data to the local printer. Exposes no public functions. Prnprxy.lib
ssblank Implements a blank screen saver for the Windows Thin Client shell. Exposes no public functions. Ssblank.lib
ssfloat Implements the floating style screen saver for the Windows Thin Client shell. Exposes no public functions. Ssfloat.lib
sstiled Implements the titled style screen saver for the Windows Thin Client shell. Exposes no public functions. Sstilde.lib
wbtprncpl Launches the Add Printer Wizard from the Control Panel tab of the Terminal Properties page. Exposes no public functions. Wbtprncpl.lib
wbtshell The Windows Thin Client executable shell that controls the user interface (UI). Exposes no public functions. Wbtshell.lib
