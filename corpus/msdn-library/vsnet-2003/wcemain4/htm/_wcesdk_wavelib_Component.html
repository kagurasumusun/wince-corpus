wavelib Component

The wavelib component supports the wave API set that is used to implement wave (.wav) audio files.

Functions for Application Developers

The wavelib component includes functions for application developers, which are defined in the Mmsystem.h header file. To import these functions, you must link to the Wavelib.lib file. The following table shows the functions included in the wavelib component.
