d3d8 Module

The d3d8 module supports Direct3D core functionality.

Functions for Application Developers

The d3d8 module contains a function for application developers. To import this function, you must link to the D3d8.lib file. The following function is included in the d3d8 module.

  • Direct3DCreate8

Interfaces

The following table shows the interfaces exposed by the d3d8 module.
