mgtt Component

The mgtt component provides support for TrueType fonts.

Functions for Application Developers

The mgtt component includes functions for application developers, which are defined in the Wingdi.h header file. To import these functions, you must link to the mgtt.lib file. The following table shows the functions that are included in the mgtt component.

Function
AddFontResource ExtTextOut
CreateFontIndirect GetTextExtentExPoint
EnableEUDC GetTextFace
EnumFontFamilies GetTextMetrics
EnumFonts RemoveFontResource
