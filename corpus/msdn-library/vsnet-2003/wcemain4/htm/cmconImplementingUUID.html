Working with UUIDs

A universally unique identifier (UUID), also known as a globally unique identifier (GUID), is a 16-byte integer that is represented as a string and is virtually guaranteed to be unique. Each Windows-based Terminal (Windows Thin Client) must have a UUID as part of the licensing agreement for Windows Thin Clients. The following string shows a UUID that was generated on the computer of the author.

4208fb66-e22a-11d1-a7d7-00a0c982c00d

Microsoft has defined the following structure as a container for the 16 bytes that are required by a UUID or by a /GUID.

typedef struct _GUID
{
  DWORD Data1;
  WORD Data2;
  WORD Data3;
  BYTE Data4[8];
} GUID;

You must store the UUID for a Windows Thin Client in a region of nonvolatile memory. You must ensure that the UUID cannot be erased or overwritten after the device has been shipped. This is especially true of Windows Thin Clients that can have their software upgraded in the field.

Generating UUIDs

You must generate UUIDs by using the UUIDGEN program that is available as part of Microsoft® Windows® CE .NET with Microsoft Platform Builder. A different UUID must be generated for each Windows Thin Client. For more information about using UUIDGEN, see this Microsoft Web site. Alternately, another way to generate a device UUID is to use a unique hardware identifier, such as an Ethernet MAC address, a logic array, and so on.
