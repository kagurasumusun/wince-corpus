Thin Client Registry Keys

The Thin Client registry stores information necessary to configure the system for applications and hardware devices. The registry also contains information that the operating system continually references during operation.

Before a connection can be established, the Windows Thin Client Shell must have the following information for each client that it manages:

  • How to create the connection
  • The Description value, or a display name to show when creating a new connection
  • The Type value, or an eight-character description to display in List View

Software must be registered with the shell to make this information available. The shell uses the Microsoft Windows CE registry to obtain client information for all of the connection software that is installed on the system. The shell does not manage unregistered software.

Client information is read once — each time that the shell starts up — and, therefore, cannot be changed dynamically. If new client software is installed on the Windows Thin Client, then the system must be reset before connections that are based on that software can be created.

For information about the following registry subkeys, see Client Information Key.

  • HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Clients\Registration
  • HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Clients\Registration\Your client name

For information about the following registry key, see Connections Key.

  • HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Clients\Registration\Your client name\Connections\Your connection name

For information about the following registry subkeys, see Control Panel Utility Keys.

  • HKEY_LOCAL_MACHINE\SYSTEM\CtlpnlApplet
  • HKEY_LOCAL_MACHINE\SYSTEM\CtlpnlApplet\WizCplApplet
  • HKEY_LOCAL_MACHINE\SYSTEM\CtlpnlApplet\TermPropCplApplet

For information about the following registry subkey, see Terminal Server Client Registry Settings.

  • HKEY_LOCAL_MACHINE\Software\Microsoft\Terminal Server Client

For information about the following registry subkey, see Shell Configuration Settings.

  • HKEY_LOCAL_MACHINE\Software\Microsoft\WBT\Shell
