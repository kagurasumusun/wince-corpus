rectapi Component

The rectapi component provides GDI support for rectangles.

Functions for Application Developers

The rectapi component includes functions for application developers, which are defined in the Winuser.h header file. To import these functions, you must link to the rectapi.lib file. The following table shows the functions included in the rectapi component.

Function
CopyRect PtInRect
EqualRect SetRect
InflateRect SetRectEmpty
IntersectRect SubtractRect
IsRectEmpty UnionRect
OffsetRect
