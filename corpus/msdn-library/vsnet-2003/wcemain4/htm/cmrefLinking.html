Linker Changes

The following table shows the linker machine types set by Makefile.def.

Microprocessor Linker machine
MIPSII, MIPSII_FP -machine:MIPS
MIPSIV, MIPSIV_FP -machine:MIPSFPU
MIPS16 -machine:MIPS16
ARMV4 -machine:ARM
ARMV4I -machine:THUMB
ARMV4T -machine:THUMB
SH3 -machine:SH3
SH4 -machine:SH4
x86 -machine:ix86

For more information, see %_WINCEROOT%\Public\Common\Oak\Misc\Makefile.def.
