winsock Module

The winsock module provides support for Windows Sockets (Winsock).

Functions for Application Developers

The winsock module contains functions for application developers, which are defined in the Winsock2.h header file. To import these functions, you must link to the Ws2.lib file. The following table shows the functions that are included in the winsock module.

Function
accept ioctlsocket
bind listen
closesocket ntohl
connect ntohs
freeaddrinfo recv
getaddrinfo recvfrom
gethostbyaddr select
gethostbyname send
gethostname sendto
getpeername setsockopt
getnameinfo shutdown
getsockname socket
getsockopt WSACleanup
htonl WSAGetLastError
htons WSAIoctl
inet_addr WSASetLastError
inet_ntoa WSAStartup

Components

The following table shows the components contained in the winsock module.

Component Description Note Import file
sslsock Secure Sockets Layer (SSL) Winsock support component. Exposes no public functions. Sslsock.lib
