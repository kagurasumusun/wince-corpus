GetSystemMemoryDivision

This function retrieves information from the kernel pertaining to object store and system memory.

BOOL GetSystemMemoryDivision( 
LPDWORD lpdwStorePages, 
LPDWORD lpdwRamPages, 
LPDWORD lpdwPageSize 
);

Parameters

lpdwStorePages
Long pointer to the number of pages dedicated to the store.
lpdwRamPages
Long pointer to the number of pages dedicated to system memory.
lpdwPageSize
Long pointer to the number of bytes in a page.

Return Values

TRUE indicates success; FALSE indicates failure.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS 2.10 and later Pwindbas.h Windows.h Coredll.lib
