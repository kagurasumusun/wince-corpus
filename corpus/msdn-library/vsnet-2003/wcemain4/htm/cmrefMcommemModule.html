mcommem Component

The mcommem component provides support for the Minimal COM feature.

Functions for Application Developers

The mcommem component contains functions for application developers. To import these functions, you must link to the Mcommem.lib file. The following functions are included in the mcommem component:

  • CoTaskMemAlloc
  • CoTaskMemRealloc
  • CoTaskMemFree
