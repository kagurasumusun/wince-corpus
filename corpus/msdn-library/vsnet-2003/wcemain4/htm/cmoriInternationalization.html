Internationalization

Internationalization is made up of a collection of features that provide general locale services and locale-specific support for certain key capabilities.

Microsoft® Windows® CE .NET provides general locale services for numerous code pages, and linguistic and cultural conventions through Unicode and national language support (NLS). Unicode is a universal character encoding system, while NLS carries information on date, time, calendar, number, and currency formats. NLS also provides sorting and character-type information for all the locales supported by the operating system (OS).

Internationalization spans a variety of language-specific features. These features support several East Asian language input methods (IM) and Input Method Editors (IME) that are uniquely designed for a specific language. East Asian languages require IMEs in order to input characters from a keyboard or stylus tablet.

In addition to general and language-specific features, internationalization includes support for a handwriting recognition engine that is extremely useful when working with East Asian languages and the Multilingual User Interface (MUI), a feature that makes it possible for users to switch the language and locale of the user interface (UI).

The following topics discuss some of the features that can help you internationalize your application.

Topic Description
Multilingual User Interface Allows end-users to select the language of the user interface.
Programming with Unicode and NLS Supports a worldwide character encoding standard, and provides functions that support different language-specific and locale-specific requirements.
Unicode Surrogates Provides additional character support for languages that need more than provided in the Unicode code space.
Handwriting Recognition Provides a handwriting recognition (HWX) engine that supports user-drawn ideographs and characters.
Transcriber Handwriting Recognizer Application Overview Allows user input through touch screen for English, French, and German.
Japanese Pocket IME Supports user input of complex Japanese characters and symbols through a variety of input methods.
Japanese IME98 Supports user input of Japanese characters through the keyboard or software input panel. In addition, IME98 provides higher conversion accuracy than the Pocket IME.
Japanese Input Methods Provides five input methods for the Japanese locale: Bushu-kensaku, Soukakusu-kensaku, MS Kana, MS Roma, HWX, and Sipselect.
Edit Control for Japanese Configures a set of editing features.
Simplified Chinese Pocket IME Supports user-input of Simplified Chinese characters and symbols through a choice of Pinyin or Shuang Pin IMs.
Simplified Chinese Input Method Allows Shuang Pin input.
Simplified Chinese Pinyin IME An intelligent, bigram-based editor that allows PinYin input.
GB18030 Data Converter Converts text from the PRC GB18030 standard format.
Traditional Chinese Pocket IME Supports user-input of Simplified Chinese characters and symbols through a choice of Phonetic or Chang Jei IMs.
Traditional Chinese Input Methods Provides choice of two input methods that allow Phonetic or Chang Jei input.
Korean IME Supports user-input of Hangul characters and symbols through a variety of input methods.
Korean Input Methods Supports four input methods: Hangul, HWX, Sipselect, and a sample input method for Korean handwriting input.
