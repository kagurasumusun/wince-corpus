drawmbar Component

The drawmbar component supports menu bar functionality.

Functions for Application Developers

The drawmbar component includes a function for application developers, which is defined in the Winuser.h header file. To import this function, you must link to the drawmbar.lib file. The following function is included in the drawmbar component:

  • DrawMenuBar
