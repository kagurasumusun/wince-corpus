Japanese IME98

Microsoft® Windows® CE .NET supports the Microsoft Input Method Editor (IME98) for Japanese. IME98 is a program that allows users to enter complex characters and symbols, such as Japanese Kanji characters, by using a standard keyboard. IME98 offers higher conversion accuracy than Pocket IME and provides variety of UI features that help users to enter Japanese characters efficiently.

When you use IME98, you can select one of two lexical databases. There are progressive differences in conversion accuracy between the two databases that correspond to their differences in size. That is, larger databases offer higher accuracy.

IME98 does not include software input panels for Japanese. However, you can use IME98 with any Japanese input methods (IM) that are based on the Windows CE software input panel architecture and provided in Windows CE .NET. For more information about the Japanese IM, see Japanese Input Methods.

Windows CE does not provide source code for the IME 98.
