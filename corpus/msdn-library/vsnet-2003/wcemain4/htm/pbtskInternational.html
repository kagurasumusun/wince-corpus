International

The following table shows the Core OS catalog features that appear in Platform Builder. The table includes features for headless devices and display-based devices.

Feature Sysgen variable Description
English (US) National Language Support Only SYSGEN_LOCUSA The English (USA) locale-specific NLS data only.

Available in both headless and display-based devices.
National Language Support (NLS) SYSGEN_CORELOC The National Language Standards (NLS) data for all supported locales.

Available in both headless and display-based devices.
Agfa AC3 Font Compression SYSGEN_AGFA_FONT Provide decompression code for Agfa AC3 compression/decompression technology, which reduces the memory footprint for font files. This is available for Chinese (Simplified), Chinese (Traditional), Japanese, and Korean.

Available only in display-based devices.
SC_Song SYSGEN_FONTS_SUNFON The SC_Song font that provides support for East Asian languages.

Available only in display-based devices.
SimSun & NSimSun SYSGEN_FONTS_SIMSUN The SimSun.TTC font for Simplified Chinese.

Available only in display-based devices.
SimSun & NSimSun (Subset 2_50) SYSGEN_FONTS_SIMSUN_2_50 A Subset 2_50 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
SimSun & NSimSun (Subset 2_60) SYSGEN_FONTS_SIMSUN_2_60 A Subset 2_60 font that includes only the CP1252 and GB2312 characters.

Available only in display-based devices.
SimSun & NSimSun (Subset 2_70) SYSGEN_FONTS_SIMSUN_2_70 A Subset 2_70 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
SimSun & NSimSun (Subset 2_80) SYSGEN_FONTS_SIMSUN_2_80 A Subset 2_80 font that includes only the CP1252, GB2312, and Big5 characters.

Available only in display-based devices.
SimSun & NSimSun (Subset 2_90) SYSGEN_FONTS_SIMSUN_2_90 A Subset 2_90 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
GB18030 Data Converter SYSGEN_GB18030 A data converter to handle People's Republic of China GB18030 standard.

Available only in display-based devices.
MSPY2 for Windows CE SYSGEN_MSPY2_SC An intelligent, bigram-based IME for Simplified Chinese that supports Pinyin input and offers a choice between three lexical databases.

Available only in display-based devices.
1.1 MB - Minimal Database SYSGEN_MSPY2_DB_1 The minimal lexical database (1.1 MB) for MSPY2.

Available only in display-based devices.
1.3 MB - Compact Database SYSGEN_MSPY2_DB_3 The compact lexical database (1.3 MB) for MSPY2.

Available only in display-based devices.
1.7 MB - Standard Database SYSGEN_MSPY2_DB_7 The standard lexical database (1.7 MB) for MSPY2.

Available only in display-based devices.
Pocket IME SYSGEN_PIME_SC A compact Simplified Chinese Input Method Editor (IME) for Shuang Pin and Pinyin input. The UI is provided as a customizable sample.

Available only in display-based devices.
MingLiU & PMingLiU SYSGEN_FONTS_MINGLIU The MingLiU.TTC font for Traditional Chinese.

Available only in display-based devices.
MingLiU & PMingLiU (Subset 2_70) SYSGEN_FONTS_MINGLIU_2_70 A Subset 2_70 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
MingLiU & PMingLiU (Subset 2_80) SYSGEN_FONTS_MINGLIU_2_80 A Subset 2_80 font that includes only the CP1252 and Big5 characters.

Available only in display-based devices.
MingLiU & PMingLiU (Subset 2_90) SYSGEN_FONTS_MINGLIU_2_90 A Subset 2_90 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
MS Ming SYSGEN_FONTS_MSMING The MS Ming font for Traditional Chinese.

Available only in display-based devices.
Pocket IME SYSGEN_PIME_TC A compact Traditional Chinese Input Method Editor (IME) for Phonetic and Chang Jei input. The UI is provided as a customizable sample.

Available only in display-based devices.
Handwriting Recognizer Engine (HWX) and Sample UI SYSGEN_HWX A handwriting recognition engine for a specific language. Handwriting recognition engines exist for English, Traditional Chinese, Japanese, and Korean (Hangul and Hanja).

A sample UI is provided for the Traditional Chinese and Korean versions.

Available only in display-based devices.
Transcriber Handwriting Recognition Application SYSGEN_TRANSCRIBER An application for English, French, and German that recognizes all handwriting, whether it is cursive, printed, or a combination of each. In addition to recognizing letters, numbers, and words, Transcriber recognizes common symbols and various control gestures.

Available only in display-based devices.
Spelling checker (USA) SYSGEN_SPLUSA An English (United States) spelling checker.

Available only in display-based devices.
MS Gothic & MS PGothic & MS UI Gothic SYSGEN_FONTS_MSGOTHIC A font for the Japanese language. Contains the JIS0212 standard and Msuigothic file.

Available only in display-based devices.
MS Gothic & MS PGothic & MS UI Gothic (Subset 1_50) SYSGEN_FONTS_MSGOTHIC_1_50 A Subset 1_50 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
MS Gothic & MS PGothic & MS UI Gothic (Subset 1_60) SYSGEN_FONTS_MSGOTHIC_1_60 A Subset 1_60 font that contains the Msuigothic file, includes only the CP1252, ShiftJIS/JIS0208, and 6000 non-ShiftJIS characters. This character range matches the range in the MS Gothic & MS PGothic & MS UI Gothic (Reduced 30) font.

Available only in display-based devices.
MS Gothic & MS PGothic & MS UI Gothic (Subset 1_70) SYSGEN_FONTS_MSGOTHIC_1_70 A Subset 1_70 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
MS Gothic & MS PGothic & MS UI Gothic (Subset 1_80) SYSGEN_FONTS_MSGOTHIC_1_80 A Subset 1_80 font that contains the Msuigothic file. The Msuigothic file includes only the CP1252 and ShiftJIS/JIS0208 characters and removes 6000 non-ShiftJIS characters.

Available only in display-based devices.
MS Gothic & MS PGothic & MS UI Gothic (Subset 1_90) SYSGEN_FONTS_MSGOTHIC_1_90 A Subset 190 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
MS Gothic (Subset 30) SYSGEN_FONTS_MSGOTHIC30 A Subset 30 font that adheres to ShiftJIS/JIS0208 and does not include the Msuigothic file in the collection.

Available only in display-based devices.
MS Gothic & MS PGothic (Subset 30_1_19) SYSGEN_FONTS_MSGOTHIC30_1_19 A Subset 30_1_19 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
IME 98 SYSGEN_IME98 The Japanese Input Method Editor that provides a variety of UI features, with a choice of either Compact or Standard lexical databases.

Available only in display-based devices.
Compact Database SYSGEN_IME98_COMPACT_DATA The compact database for IME98.

Available only in display-based devices.
Standard Database SYSGEN_IME98_STANDARD_DATA The standard database for IME98.

Available only in display-based devices.
Pocket IME SYSGEN_PIME The Japanese Compact Input Method Editor that allows customization and includes a customizable UI. It includes one default and two optional lexical databases.

Available only in display-based devices.
Name/Place Database SYSGEN_PIME_NAME_PLACE_DATA The Name/Place lexical database for Japanese Pocket IME.

Available only in display-based devices.
Supplemental Database SYSGEN_PIME_SUPPLEMENTAL_DATA A supplemental lexical database for Japanese Pocket IME.

Available only in display-based devices.
Test IME SYSGEN_TESTIME The Japanese Test Input Method Editor (IME).

Available only in display-based devices.
Multibox HWX Sample UI SYSGEN_MULTIBOX A sample Input Method for handwriting that works with the HWX engine.

Available only in display-based devices.
Input Method Selector Sample Application SYSGEN_SIPSELECT A sample application for selecting any available Input Method at any given moment.

Available only in display-based devices.
Kana Soft Keyboard SYSGEN_ IM_KANA An on-screen keyboard that enables input of Hiragana and Katakana.

Available only in display-based devices.
Romaji/English Soft Keyboard SYSGEN_IM_ROMA An on-screen keyboard that enables input of the Western alphabet directly through a traditional keyboard layout.

Available only in display-based devices.
Search by Radical SYSGEN_IM_RADICAL Bushu-kensaku: a search by radical engine that enables complex Kanji character selection based on their radicals.

Available only in display-based devices.
Search by Stroke SYSGEN_IM_STROKE Soukakusu-kensaku: a search by stroke engine that enables complex Kanji character selection based on the character strokes.

Available only in display-based devices.
Gulim (GL_CE) SYSGEN_FONTS_GL_CE The Gulim (GL_CE.TTF).font file for Korean that shipped in Windows CE 3.0.

Available only in display-based devices.
Gulim & GulimChe (Subset 1_30) SYSGEN_FONTS_GULIM_1_30 A Subset 1_30 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
Gulim & GulimChe (Subset 1_40) SYSGEN_FONTS_GULIM_1_40 A Subset 1_40 font without Hanja characters.

Available only in display-based devices.
Gulim & GulimChe (Subset 1_50) SYSGEN_FONTS_GULIM_1_50 A Subset 1_50 font that includes only the 12,13,15,16 PPEM bitmap ranges.

Available only in display-based devices.
Gulim & GulimChe (Subset 1_60) SYSGEN_FONTS_GULIM_1_60 A Subset 1_60 font that contains the Gulim and Gulimche files in the collection.

Available only in display-based devices.
IME 97 SYSGEN_K_IME97 A Korean Input Method Editor (IME) with a sample customizable UI.

Available only in display-based devices.
Korean Soft Keyboard Sample SYSGEN_MSIMK A sample soft keyboard input method for Korean.

Available only in display-based devices.
Multilingual User Interface (MUI) SYSGEN_MULTIUI Support for switching the user interface language. Allows creating one ROM image for multiple target markets.

Available only in display-based devices.
