Reading UUIDs

For the Windows Thin Client to have read access to a UUID, you must follow a short coding procedure.

To read a UUID

  • Implement the KernelIoControl function that reads the UUID from nonvolatile memory. The control code that is specified for reading a UUID is IOCTL_HAL_GET_UUID.

    The following code example shows how to read a UUID. 

    BOOL GetUUID () 
{
  GUID myUUID;
  BOOL bRetVal;
  DWORD dwBytesReturned;

  bRetVal = KernelIoControl (IOCTL_HAL_GET_UUID, NULL, 0, &myUUID, 
                             sizeof (myUUID), &dwBytesReturned);
  if (!bRetVal) 
  {
    RETAILMSG(1, TEXT("KernelIoControl call failed!\r\n"));
    return FALSE;
  }

  RETAILMSG(
    1,
    TEXT("UUID: %08X-%04X-%04X-%02X%02X-%02X%02X%02X%02X%02X%02X\r\n"),
    myUUID.Data1,
    myUUID.Data2,
    myUUID.Data3,
    myUUID.Data4[0],
    myUUID.Data4[1],
    myUUID.Data4[2],
    myUUID.Data4[3],
    myUUID.Data4[4],
    myUUID.Data4[5],
    myUUID.Data4[6],
    myUUID.Data4[7]);

  return TRUE;
}

You also must implement the section of code in the OEM Adaptation Layer (OAL) to handle the call to the KernelIoControl function.
