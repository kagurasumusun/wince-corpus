ole232 Component

The ole232 component supports OLE services.

Functions for Application Developers

The ole232 component contains functions for application developers, which are defined in the Ole2.h header file. To import these functions, you must link to the ole232.lib file. The following table shows the functions that are included in the ole232 component.

Function
CreateOleAdviseHolder OleSetMenuDescriptor
OleCreate ReadClassStg
OleDraw ReadClassStm
OleIsRunning ReleaseStgMedium
OleRun WriteClassStg
OleSave WriteClassStm
OleSetContainedObject
