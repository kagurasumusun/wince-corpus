Desktop Registry Settings

You can display desktop wallpaper by retrieving the current wallpaper configuration from the following registry key.

[HKEY_CURRENT_USER\ControlPanel\Desktop]

The following registry value specifies the name of the wallpaper bitmap to retrieve.

"Wallpaper": REG_SZ

The following registry value specifies whether or not to tile the wallpaper bitmap.

"Tile": REG_DWORD
