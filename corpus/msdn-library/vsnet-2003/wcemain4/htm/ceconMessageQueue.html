Message Queue Point-to-Point

The message queue needs to be designed to use as little memory as possible and be efficient. The only support provided is for point-to-point. If there are several readers, each reader will only get to read the current message at the head of the queue when a read request is made. The CreateMsgQueue API enables the specification of a remote queue.

In addition to the buffer allocated to store messages, there is also a special single message buffer used to store a high priority message or alert message.
