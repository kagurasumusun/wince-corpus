sapi Module

The sapi module supports the Speech API (SAPI) Version 5.0.

Interfaces

The sapi module implements the following interfaces:

  • _ISpPrivateEngineCall
  • IEnumSpObjectTokens
  • ISpAudio
  • ISpCFGInterpreter
  • ISpContainerLexicon
  • ISpDataKey
  • ISpErrorLog
  • ISpEventSink
  • ISpEventSource
  • ISpGramCompBackend
  • 5ISpGrammarBuilder
  • ISpGrammarCompiler
  • ISpITNProcessor
  • ISpLexicon
  • ISpMMSysAudio
  • ISpNotifyCallback
  • ISpNotifySink
  • ISpNotifySource
  • ISpRecoContext
  • ISpRecognizer
  • ISpRecoGrammar
  • ISpRecoResult
  • ISpRegDataKey
  • ISpResourceManager
  • ISpSRAlternates
  • ISpSREngine
  • ISpSREngineSite
  • ISpStream
  • ISpStreamFormat
  • ISpStreamFormatConverter
  • ISpTask
  • ISpTaskManager
  • ISpThreadControl
  • ISpThreadTask
  • ISpTokenUI
  • ISpTranscript
  • ISpTTSEngine
  • ISpTTSEngineSite
  • ISpVoice
