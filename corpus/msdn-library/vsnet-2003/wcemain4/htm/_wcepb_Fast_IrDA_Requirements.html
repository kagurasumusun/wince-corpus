Fast IrDA Requirements

If you are using a Fast IrDA (FastIR) controller on a CEPC, you must ensure that the controller matches these required settings. The following table shows the configuration settings for a FastIR driver.

Configuration Setting
Configuration base register The default is 0x398.
I/O base register The default is 0x2E8.
IRQ The default is 5.
Direct memory access (DMA) channel The default is 3.
