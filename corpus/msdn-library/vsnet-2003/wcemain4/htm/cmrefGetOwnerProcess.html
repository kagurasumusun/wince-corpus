GetOwnerProcess

This function returns the process handle of the current thread owner.

HANDLE GetOwnerProcess (void);

Parameters

None.

Return Values

Handle to the owner process.

Remarks

This function is typically used by a driver to determine which process really owns the thread making the function call. Because a driver runs in a different process space (device.exe) than a calling process, it is important, in certain situations, to know which process is really making the call. To map a pointer from the current calling process address space, you can use this function in conjunction with the MapPtrToProcess function in a driver.
