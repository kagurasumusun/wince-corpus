Microsoft Windows CE .NET  

Applications - End User

The following table shows the core OS Catalog features that appear in Platform Builder. The table includes features for headless devices and display-based devices.

Feature Sysgen variable Description
ActiveSync® SYSGEN_AS_BASE A service manager that maintains a device partnership with a computer host, enabling remote procedure call services and data synchronization.

Available in both headless and display-based devices.

For more information, see ActiveSync Overview.
File Sync SYSGEN_AS_FILE A service provider that enables file synchronization.

Available in both headless and display-based devices.
Inbox Sync SYSGEN_AS_MAIL A service that provides a synchronization solution for e-mail. It works in conjunction with Pocket Outlook Object Model (POOM) API.

Available in both headless and display-based devices.
Pocket Outlook Database Sync SYSGEN_AS_PIM A service that provides a synchronization solution for PIM (calendar, contacts, and tasks) components. It works in conjunction with POOM API.

Available in both headless and display-based devices.
Microsoft Excel Viewer SYSGEN_VIEWER_XLS A file viewer that displays documents created in Microsoft Excel 97, Excel 2000, and Excel XP.

Available only in display-based devices.
Microsoft Image Viewer SYSGEN_VIEWER_IMAGE A file viewer that allows the user to control how images are viewed to create a slide show. Images can be sorted, rotated, or zoomed. The timing between slides can be set and there are a variety of transition effects to choose from.

Available only in display-based devices.
Microsoft PDF Viewer SYSGEN_VIEWER_ACROBAT A file viewer that displays Portable Document Format (PDF) files. For information about PDF specifications, see the Portable Document Format Reference Manual version 1.3 by Adobe Systems Incorporated.

Available only in display-based devices.
Microsoft PowerPoint Viewer SYSGEN_VIEWER_PPT A file viewer that displays presentations created in Microsoft PowerPoint® 97, PowerPoint 2000, and PowerPoint XP.

Available only in display-based devices.
Microsoft Word Viewer SYSGEN_VIEWER_DOC A file viewer that displays documents created in Microsoft Word 97, Word 2000, and Word XP.

Available only in display-based devices.
FLASH Update Sample Application SYSGEN_FTPUPDATE A sample application that demonstrates how to flash a new OS image onto a device.

Available only in display-based devices.
FreeCell SYSGEN_FREECELL An application that allows a user to play the FreeCell version of Solitaire.

Available only in display-based devices.

Solitaire SYSGEN_SOLITARE An application that allows a user to play Solitaire.

Available only in display-based devices.

Help SYSGEN_HELP An HTML-based Help system application.

Available only in display-based devices.

Inbox SYSGEN_PMAIL A Windows CE e-mail application.

Available only in display-based devices.

Remote Desktop Protocol (RDP) SYSGEN_RDP A service that allows a thin client, such as a Windows-based Terminal (WBT), to communicate with a terminal server across a LAN, WAN, or by means of a dial-up, ISDN, DSL, or virtual private network (VPN) connection.

Available only in display-based devices.

For more information, see Remote Desktop Protocol Overview.
Terminal Emulator SYSGEN_PEGTERM A sample terminal emulation application that allows the user to create a TTY or VT100 emulation mode to a remote host over an installed Telephony API (TAPI) device.

Available only in display-based devices.
Windows Messenger SYSGEN_MESSENGER A service that detects presence of contacts and enables text and voice messaging and file transfers using Hotmail and Communications Service protocols.

Available only in display-based devices.

For more information, see Windows Messenger Overview.
WordPad SYSGEN_PWORD A basic word processing application.

Available only in display-based devices.
