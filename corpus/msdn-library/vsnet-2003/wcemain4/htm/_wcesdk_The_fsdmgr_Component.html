fsdmgr Component

This component supports the file system driver (FSD) manager. The FSD manager manages all system interactions with installable FSDs. It creates file handles, registers volumes, installs necessary functions, and maps application calls to the installed functions. FSD manager invokes these functions when an application accesses folders and files on mounted volumes using the file system functions.

Functions for Application Developers

The fsdmgr component includes functions for application developers, which are defined in the Fsdmgr.h header file. To import these functions, you must link to the fsdmgr.lib file. The following table shows the functions included in the fsdmgr component.

Function
FSDMGR_CreateFileHandle FSDMGR_ReadDisk
FSDMGR_CreateSearchHandle FSDMGR_ReadDiskEx
FSDMGR_DeregisterVolume FSDMGR_RegisterVolume
FSDMGR_GetDiskInfo FSDMGR_WriteDisk
FSDMGR_GetVolumeName FSDMGR_WriteDiskEx
