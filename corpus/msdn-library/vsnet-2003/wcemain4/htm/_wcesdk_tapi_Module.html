tapi Module

The tapi module supports the Telephony API (TAPI).

Functions for Application Developers

The tapi module contains functions for application developers, which are defined in the Tapi.h and Tapicomn.h header files. To import these functions, you must link to the Tapi.lib file. The following table shows the functions that are included in the tapi module.
