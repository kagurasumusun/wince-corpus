ie Modules

The modules that are included in the ie group provide Internet functionality for Windows CE–based platforms.

The following table shows the modules contained in the ie group.

Module Description Note Import file
ieceext   Exposes no public functions. Ieceext.lib
iepeers Provides printing functionality for Microsoft® Internet Explorer. Exposes no public functions. Iepeers.lib
iesample Builds an Internet-demonstration system using Internet Explorer components. Exposes no public functions. Iesample.lib
iesimple A sample browser container application with a full-screen, windowless, user interface. It depends on shdocvw. Exposes no public funcitons. Iesimple.lib
inetcpl Provides a sample Internet Control Panel. Exposes no public functions. Inetcpl.cpl
mlang Implements a set of services that help convert Internet data to international markets. Exposes no public functions. Mlang.lib
mshtml Provides support for the Microsoft HTML parsing and rendering engine (MSHTML). Exposes no public functions. Mshtml.lib
msls31   Exposes no public functions. Msls31.lib
msxml3 Implements Microsoft XML Parser version 3.0 (MSXML) SP1, which is a parser for Extensible Markup Language (XML) files.   Msxml3.lib
shlwapi   Exposes no public functions. Shlwapi.lib
shdocvw ActiveX control also known as the Layout Manager. This module acts as a wrapper that adds a number of high-level functions, including navigation functions, to a Web browser. Exposes no public functions. Shdocvw.lib
tvlens Module Supports television-style navigation.   Tvlens.lib
urlmon Provides support for urlmon. This module monitors Uniform Resource Locators (URLs) and reports changes to Web sites. Exposes no public functions. Urlmon.lib
wininet Supports the Microsoft Win32® Internet API set. This module can be used to make the Internet an integral part of any application.   Wininet.lib
