AMD Socket A Based SDB

The A7V-E is based on VIA KT133 chipset in ATX form factor for the latest support in AMD AthlonTM / DuronTM 550MHz to 1GHz+ processors. This chipset is ASUS's first Socket A series that incorporates 200MHz FSB and 1GB PC133 / PC100 / VCM133 SDRAM capability in the x86 platforms. This mainboard features support for Stepless Frequency Selection, which allows microprocessor frequency settings to be set in 1MHz-increments and also Ultra DMA/100 data transfer, 4 USB Ports, and AGP 4X/2X. The additional upgrades provided include Realtek RTL 8139C 100/10Mbps LAN Controller.

It is a two-chip set consisting of VT8363 North Bridge and VT82C686B South Bridge controllers. Additional key support features include up to four USB Ports v1.1, Audio/Modem Riser, PC Health Monitoring, PCI v2.2, Creative PCI Audio, and Suspend-to-RAM.
