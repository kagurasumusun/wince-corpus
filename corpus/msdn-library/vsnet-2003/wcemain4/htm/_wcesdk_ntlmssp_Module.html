ntlmssp Module

The ntlmssp module supports the Microsoft Windows NT® LAN Manager secure-socket provider.

Functions for Application Developers

The ntlmssp module contains a function for application developers, which is defined in the Sspi.h header file. To import this function, you must link to the Ntlmssp.lib file. The following function is included in the ntlmssp component:

  • InitSecurityInterface
