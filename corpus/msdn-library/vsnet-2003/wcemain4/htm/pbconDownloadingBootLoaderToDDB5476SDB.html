Downloading the Boot Loader to the NEC DDB-Vrc5476 (Boston) SDB

Once you have downloaded the initial boot loader, use that boot loader to download a new eboot image. In other words, use Platform Builder to download Eboot.bin and it will flash the image again. The following steps are only required for your initial platform set up, or if you set up your flash incorrectly.

  1. Turn off the NEC DDB-Vrc5476 (Boston) SDB.
  2. Move DIP switch S1-1 to the On position. Move S1-2 through S1-6 to the Off position, and turn on the NEC DDB-Vrc5476 (Boston) SDB.

    This will run the boot ROM monitor program.

  3. Once the system is restarted and the DIP switch S1-1 is in the On position, the following message appears in your HyperTerminal window: 
    DDB 5476 Boot Monitor
NEC Electronics Inc
DDB 5476 rev 2.2
Revision Date: Jan 20 2000
>
  4. To view the following table, type H and press ENTER while the boot ROM monitor program is running.
    Command Description 
    L
    		 Runs the s-record loader. Subsequent serial data is interrupted in the standard s-record format and written to Flash. 
    E
    		 Erases all of system Flash and returns to the > prompt when complete. 
    D <hexadecimal address>
    		 Reads and displays eight DWORD values starting from <hexadecimal address>. The boot ROM monitor program clearly indicates the address and data being read and returns to the > when complete. 
    T
    		 Runs the self-test. The self-test tests all of the installed RAM and Flash and verifies that 64 MB of RAM and 32 MB of Flash exist on the card. The self-test is independent of external connections. The boot ROM monitor program does not support any peripheral except for the Debug Serial Port. 
    I
    		 Prints out the SDB information list so that the device is identified. 
    B <baud rate in decimal>
    		 Modifies the baud rate of the Debug Serial Port to the specified value if it is supported by the hardware. The default setting is 38.4 Kbps. 
    H
    		 Prints out the command menu. 
    F
    		 Downloads the boot loader provided by NEC to Flash. 
    W
    		 Outputs a list of the PCI devices. 
    X
    		 Runs the Microsoft SDBTEST program.
  5. To download the Windows CE boot loader to the flash memory, type F and press ENTER at the boot-ROM monitor program command prompt.

    The following message appears: 

    Flash Write is disabled. Do you want to enable it? (Y/N)
  6. Press Y to make the flash memory writeable. The following message appears: 
    Upload raw firmware file via serial port
C
    Note   HyperTerminal is now waiting for input.
  7. From the Transfer menu in HyperTerminal, choose Send File.
  8. In the Send File window, from the Protocol list, choose the 1K Xmodem.
  9. Choose Browse, and then locate the directory where the Eboot.rom file is located.

    This file is located in %_WINCEROOT%\Platform\DDB5476\Eboot, and is created automatically from the Eboot.bin file while building the platform code. You can also use %_WINCEROOT%\Platform\DDB5476\Eboot\Bin, which is a tested and valid binary image.

  10. Select the Eboot.rom file, choose Open, and then choose Send.
  11. After the transfer is completed, the following message appears: 
    WriteRegion:::
Dest = 0xa5c00000
Scr = 0x80001000
Ulen = 0x16100

[Write Block] …………

DDB 5476 Boot Monitor

  12. Turn off the NEC DDB-Vrc5476 (Boston) SDB.
  13. Move DIP switch S1-1 to the Off position so the Windows CE boot loader executes from the flash memory after reset.
  14. Restart the system and you will see the Windows CE boot loader auto boot messages. The following is an example of the Windows CE boot loader auto boot loader messages:

[3|R] Run firmware monitor program
[4|W] List PCI devices

  17. Find the line with the following format: 
    Device Name = <device name>
  18. Use the <device name> in the Configure Remote Services window in the Platform Builder IDE.
  19. Download the OS Image to the NEC DDB-Vrc5476 (Boston) SDB.
