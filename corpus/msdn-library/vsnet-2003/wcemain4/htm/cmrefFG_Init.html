FG_Init

This function formats the file partition.

void FG_Init(
PSM_OEMInfoPtr oem_info_ptr, 
PSM_FormatOptionsPtr format_options_ptr
);

Parameters

oem_info_ptr
[in] Set to a structure of type PSM_OEMInfo to pass OEM-specific information about the hardware platform to the Intel Persistent Storage Manager (PSM) software stack during initialization.
format_options_ptr
[in] Set to a structure of type PSM_FormatOptions to pass user-configurable format options.

Return Values

None.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later      

See Also

PSM_FormatOptions, PSM_OEMInfo
