Thin Client Hardware and Software

The Windows Thin Client consists of the following hardware and software components:

Windows Thin Client Device

The Windows Thin Client device is the remote terminal — which consists of hardware components, the Windows CE OS, and a shell — that hosts client-side connections to a remote Terminal Server.

Microsoft Terminal Server Client

Microsoft Terminal Server Client (MSTSC) software allows customers to gain access to Windows-based applications from a range of new and existing desktop hardware devices:

  • Windows Thin Client devices that are powered by Windows CE
  • Computers that are running Microsoft Windows 95/98, Windows XP Home Edition, Windows XP Professional, or Windows NT Workstation
  • Computers that are running Microsoft Windows for Workgroups version 3.11

Windows Thin Client topics discussed here are limited to Windows Thin Clients powered by Windows CE.

Optional Third-party Emulators or Presentation Protocols

Optional third-party emulator or presentation protocol software is available or can be developed for use with Windows-based Terminals. For more information, contact the software vendor that is associated with these products.
