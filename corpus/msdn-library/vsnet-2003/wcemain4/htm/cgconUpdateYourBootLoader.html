Update your Boot Loader

A boot loader from Microsoft® Windows® CE version 3.0 may function correctly with no modifications in Windows CE .NET. At a minimum, no changes should be required to the boot loader code. But the following other changes should be made or considered in the boot loader for your BSP:

  1. Use BLCOMMON infrastructure.

    The boot loader common library provides an infrastructure for all boot loaders. For information about the boot loader common interface, see %_WINCEROOT%\Public\Common\Oak\Inc\BLCommon.h, Creating a Boot Loader, and Boot Loader Development. To minimize porting and migrating efforts, you should use this infrastructure while developing a boot loader for your BSP.

  2. Update the .BIB files.

    Be sure the boot loader BIB file is compatible with the Windows CE .NET BSP Config.bib file.

  3. Remove PCI code.

    If using the PCI bus driver, only initialize your PCI KITL device, for example, your NIC, and any intermediate PCI bridges. Leave all other PCI configuration to the PCI bus driver.

  4. Remove code to clear memory.

    Since the KITL library provides routines to perform these operations, you do not need to implement code to force a clean OS boot in your boot loader.
