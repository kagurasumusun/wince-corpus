File System Considerations

The file system drivers that are released with Windows CE are not real time, and OEMs should avoid making file system calls from their real-time threads. Like GWES, the File System Manager and the supplied file system drivers use critical sections to protect critical data. The use of a single critical section per file system means that a lower-priority thread can block a higher-priority thread from running if the lower-priority thread has acquired the critical section before the higher-priority thread is ready to run.
