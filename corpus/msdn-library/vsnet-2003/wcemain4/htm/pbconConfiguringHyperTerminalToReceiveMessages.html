Configuring HyperTerminal for BSPs

HyperTerminal displays the messages sent from the serial port on each standard development board (SDB). These messages are useful for checking whether or not the boot loader is on the SDB, whether there are problems during boot-up, and for obtaining the name of the SDB to use in the Platform Builder integrated development environment (IDE). The serial output in the section for each BSP is sample output. Any terminal emulation program can be used.

To set up HyperTerminal

  1. From the Windows Start menu, point to All Programs, and then point to Accessories.
  2. Point to Communications, and then choose HyperTerminal.
  3. Type a name, choose an icon for your connection to the SDB, and then choose OK.
  4. From the Connect using list, select which COM port with which to connect.

    This is the COM port identifier on the host side.

  5. Choose OK.
  6. Adjust the settings in the COM Properties window to match the settings in the following table, according to your BSP.

    The following table shows the settings to use when adjusting the COM properties.

    BSP Bits per second Data bits Parity Stop bits Flow control
    All BSPs 38400 8 None 1 None
    Hitachi US7750 HARP SDB 57600 8 None 1 None
    x86 Emulator N/A N/A N/A N/A N/A
