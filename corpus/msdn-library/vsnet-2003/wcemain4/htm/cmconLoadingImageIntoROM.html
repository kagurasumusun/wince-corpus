Loading the Image into ROM

There are three ways a boot loader can load a multiple XIP image:

  • Platform Builder and .bin files
  • Multiple XIP regions in a single file
  • Absolute Binary Data Format – NB0 files

    There is no change to the image download process if your boot loader uses the ABDF format.
