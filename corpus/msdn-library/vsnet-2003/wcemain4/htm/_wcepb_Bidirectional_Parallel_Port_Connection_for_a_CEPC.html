Bidirectional Parallel Port Connection for a CEPC

Most desktop computers equipped with Intel Pentium processors and Intel i486 processors include a bidirectional parallel port on the motherboard. You can configure this port and save the configuration changes to the CMOS memory using a setup utility stored in the BIOS ROM. The same bidirectional setup must exist on both the development workstation and the CEPC.

Note   Some Intel i486 processors and most i386 processors do not provide a bidirectional parallel port on the motherboard. You must purchase an expansion card equipped with a bidirectional parallel port. Follow the instructions provided with the expansion card for setting up the port.
