commctrl Module

The commctrl module implements the common controls Control Panel. Common controls offer users a familiar interface for performing common tasks, which makes applications easier to learn and use.

Functions for Application Developers

The commctrl module contains functions for application developers, which are defined in the Commctrl.h header file. To import these functions, you need to link to the Commctrl.lib file. The following table shows the functions found in the commctrl module.
