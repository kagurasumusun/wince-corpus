mcomlib Component

The mcomlib component provides support for the Minimal COM feature.

Functions for Application Developers

The mcomlib component contains functions for application developers. To import these functions, you must link to the Mcomlib.lib file. The following functions are included in the mcomlib component:

  • CoFreeLibrary
  • CoLoadLibrary
