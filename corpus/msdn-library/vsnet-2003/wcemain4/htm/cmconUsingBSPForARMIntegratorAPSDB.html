Using the BSP for the ARM Integrator AP SDB

The following steps show you the process of building a platform and installing an operating system (OS) image on the BSP for the ARM Integrator AP SDB.

  1. Install Microsoft® Windows® CE .NET 4.1 with Microsoft Platform Builder 4.1 and select support for one of the ARM4I or ARM4T microprocessors.
  2. Review the supported hardware and software features on the SDB and note any limitations that may impact your platform on the board. For more information, see ARM Integrator AP SDB Supported Features.
  3. Set up the SDB hardware. For more information, see Setting Up the ARM Integrator AP SDB Hardware.
  4. Modify the switch and jumper settings on the SDB. For more information, see Modifying the ARM Integrator AP SDB Switches and Jumpers.
  5. Configure the Microsoft HyperTerminal application to receive debug messages. For more information, see Configuring HyperTerminal for BSPs.
  6. Build the platform by choosing the Build menu in the Platform Builder IDE.
  7. Download the Ethernet boot loader to ROM or flash the SDB. For more information, see Flashing the Windows CE Boot Loader for the First Time on the ARM Integrator AP SDB.
  8. Download the OS image that you created for your platform to the SDB. For more information, see Downloading the OS Image to the ARM Integrator AP SDB.
