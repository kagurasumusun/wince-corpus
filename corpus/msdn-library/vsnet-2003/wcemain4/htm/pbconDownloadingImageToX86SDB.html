Downloading the x86 SDB OS Image

You can download an OS image to a CEPC through Ethernet, parallel, or serial. By default, all the sample x86 BSPs are set to use Ethernet download. Ethernet sharing is enabled by default so you do not need to free up a controller for product Ethernet. To use the native Ethernet port for product Ethernet, you must disable Ethernet downloading. For more information, see the section for each x86 SDB.
