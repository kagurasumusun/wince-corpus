Ethernet Connection for a CEPC

You can use an Ethernet connection to connect a CEPC to a development workstation. The Ethernet connection can be used for both downloading and debugging, or, if your CEPC contains only a product Ethernet card, for downloading only.

If you are using one Ethernet card for downloading, and one card for debugging, set the CEPC_NE2000_PCI environment variable and make sure you do not have any interrupt conflicts.

The following table shows the hardware and software required for using debug Ethernet with a CEPC.

Requirement Description
CEPC boot diskette DOS-bootable disk, version 6.22 or later, containing Himem.sys, Loadcepc.exe, and Eboot.bin.
NE2000-compatible debug Ethernet card, RTL8139, DP83815 ISA-based or PCI-based.
Ethernet cable Standard Ethernet cable.
