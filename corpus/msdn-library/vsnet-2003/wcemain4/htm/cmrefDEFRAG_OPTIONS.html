DEFRAG_OPTIONS

This structure contains options specified by clients of defrag disk.

typedef struct _DEFRAG_OPTIONS {
DWORD dwFatToUse;
BOOL  fVerifyFix;
} DEFRAG_OPTIONS, *PDEFRAG_OPTIONS;

Members

dwFatToUse
Which FAT to use for scanning before beginning defrag.
fVerifyFix
Indicates where to prompt user to verify fix in scanning.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Defragdisk.h Defragdisk.h
