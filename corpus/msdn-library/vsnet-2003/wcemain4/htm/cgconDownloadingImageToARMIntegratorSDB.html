Downloading the OS Image to the ARM Integrator AP SDB

  1. Set the S1 DIP switches to the following settings to run the boot monitor.
    S1-1 S1-2 S1-3 S1-4
    Off Off Off On
  2. Turn on the ARM Integrator AP SDB.
  3. Restart the ARM Integrator AP SDB.

  4. In the previous message, find the following line. 
    INFO: Using device name: '<device name>'

    The <device name> is what Platform Builder will call the ARM Integrator AP SDB.

  5. Download the OS image.
