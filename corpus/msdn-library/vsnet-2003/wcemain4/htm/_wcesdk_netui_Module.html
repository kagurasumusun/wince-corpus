netui Module

The netui module supports the Network User Interface (NetUI), which defines configuration settings for the Communications icon in Microsoft® Windows® CE Control Panel.

Functions for OS Developers

The netui module contains functions for operating system configuration, which are defined in the netui.h header file. To import these functions, you must link to the netui.lib file. The following table shows the functions that are included in the netui module.

Function
AdapterIPProperties GetResourcePassword
ConnectionDialog GetUsernamePassword
DisconnectDialog LineConfigEdit
GetDriverName LineTranslateDialog
GetIPAddress NetMsgBox
GetNetString
