Windows CE Explorer Registry Settings

Settings for Windows CE Explorer are controlled by values under the following registry key.

[HKEY_LOCAL_MACHINE\Explorer]
    "Suspend"=dword:0

If the value of Suspend equals zero, then suspend is not supported on the target device. If the value of Suspend is non-zero or not found, Windows CE Explorer attempts to suspend by calling the GwesPowerOff function.
