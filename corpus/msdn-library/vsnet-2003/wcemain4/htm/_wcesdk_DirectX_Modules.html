directx Modules

The DirectX modules implement Microsoft DirectX® application programming interface (API) functionality and provide support for the DirectX API.

The following table lists the modules that provide DirectX functionality. A module that has public functions or components is linked to topics that describe the module in greater detail.

Module Description Note Library
amcompat Provides Microsoft ActiveMovie® compatibility for the Windows Media™ Player. Exposes no public functions. Amcompat.lib
amstream Supports Microsoft DirectShow® multimedia streaming. Exposes no public functions. Amstream.lib
anxjtest Test application for Annex J digital video disc (DVD) commands. Exposes no public functions. Anxjtest.lib
captureecho Includes a sample Microsoft DirectSound® capture application. Exposes no public functions. Captureecho.lib
cedrm2 Supports license acquisition of ActiveX controls for Digital Rights Management (DRM). Exposes no public functions. Cedrm2.lib
cedrmutil Supports DRM for portable devices. Exposes no public functions. Cedrmutil.lib
ceplayer Supports the Windows Media player application. Exposes no public functions. Ceplayer.lib
d3d8 Supports Microsoft Direct3D® core functionality.   D3d8.lib
d3dref8 Supports a reference rasterizer for Direct3D. Exposes no public functions. D3dref8.lib
d3dsamples Supports sample applications for Direct3D. Exposes no public functions. simple.lib, boids.lib
ddcaps Provides Microsoft DirectDraw® capabilities for a sample viewer application. Exposes no public functions. Ddcaps.lib
ddcore Supports DirectDraw core functionality.   Ddcore.lib
ddhel Implements the DirectDraw hardware emulation layer for emulated blits (including alpha blits). Exposes no public functions. Ddhel.lib
ddraw Supports DirectDraw functionality.   Ddraw.lib
ddsamples Contains DirectDraw sample applications, such as ddex1, ddex2, ddex3, ddex4, mosquito, donuts, and foxbear. Exposes no public functions. Ddex1.lib, Ddex2.lib, Ddex3.lib, Ddex4.lib, Mosquito.lib, Donuts.lib, Foxbear.lib
ddvd Supports Windows CE DVD-Video API by enabling DVD access and playback.   Ddvdids.lib
directdraw Selects all core DirectDraw components, but not sample drivers. Exposes no public functions. Ddraw.lib
directsound Selects all core DirectSound components. Exposes no public functions. Dsound.lib
dmcompos Supports the Microsoft DirectMusic® Composer.   Dmcompos.lib
dmsynth Provides a software synthesizer. Required for MIDI playback. Exposes no public functions. Dmsynth.lib
dmusic Provides a MIDI playback engine. Required for MIDI playback.   Dmusic.lib
dmusicsamples Contains DirectMusic sample programs. Exposes no public functions. dmmidi.lib, dmecho.lib, donuts.lib, playmidi.lib, playmotif.lib, playpri.lib
dpnhupnp Supports a network address translation (NAT) interface for Communications Service. Exposes no public functions. Dpnhupnp.lib
dshowsamples Contains DirectShow sample programs, such asceplayit and playwnd. Exposes no public functions. ceplayit.lib. playwnd.lib
dsound Provides support for DirectSound mixers.   Dsound.lib
dsplay Includes a simple DirectSound sample application that allows you to play .wav files with DirectSound. Exposes no public functions. Dsplay.lib
dvdplay Supports a sample DVD player application. Exposes no public functions. Dvdplay.lib
dvdsample Supports a sample application that plays back DVD-Video API through a window on the screen of a Windows CE–based device. Exposes no public functions. Dvdsample.lib
dxmasf Contains all Windows Media Technologies core components.   Dxmasf.lib
dxmrtp Supports the Real-time Transport Protocol (RTP) and codecs. Exposes no public functions. Dxmrtp.lib
dxview Includes a viewer sample application with general DirectX capabilities. Exposes no public functions. Dxview.lib
icm Supports the Video Compression Manager. Exposes no public functions. Icm.lib
imaadpcm Provides support for the Interactive Multimedia Association Adaptive Differential Pulse Code Modulation (IMA ADPCM) audio codec. Exposes no public functions. Imaadpcm.lib
l3codec Supports the Fraunhofer MP3 codec. Exposes no public functions. L3codec.lib
mixerapi Contains the Audio Mixer API client-side DLL. Exposes no public functions. mixerapi.dll
mmtimer Provides multimedia services required by the quartz module. Exposes no public functions. Mmtimer.lib
mpg4ds32 Supports the MPEG4 version 3 codec. Exposes no public functions. Mpg4ds32.lib
msacmce Contains the ACM driver used by DirectShow. Exposes no public functions. Msacmce.lib
msadpcm Supports the Microsoft ADPCM audio codec. Exposes no public functions. Msadpcm.lib
msaud32 Implements the Microsoft audio compression manager. Exposes no public functions. Msaud32.lib
msdls Contains a wave sample for software synthesizer. Required for MIDI playback. Exposes no public functions. Msdls.lib
msdxm Selects all Windows Media Player core components.   Msdxm.lib
msg711 Supports the G.711 audio codec. Exposes no public functions. Msg711.lib
msgslang Supports resources that can be localized for Windows Messenger. Exposes no public functions. Msgslang.lib
msgsm610 Provides support for the GSM 6.10 audio codec. Exposes no public functions. Msgsm610.lib
msmsgs Supports the Windows Messenger feature. Exposes no public functions. Msmsgs.lib
msrle32 Supports the RLE8 video codec. Exposes no public functions. Msrle32.lib
pcmconv Includes a PCM bit/sample rate ACM conversion codec. Exposes no public functions. Pcmconv.lib
quartz Provides DirectShow functionality. Core DirectShow module.   Quartz.lib
rtcclient Supports the Communications Service feature.   Rtcclient.lib
rtcimsp Supports the Windows Messenger feature. Exposes no public functions. Rtcimsp.lib
vrctl Implements a windowless video control. Exposes no public functions. Vrctl.lib
wmaudio Supports the Windows Media Audio codec 2.0. Exposes no public functions. Wmaudio_XXX.lib
