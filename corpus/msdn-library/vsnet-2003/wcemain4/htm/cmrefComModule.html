com Component

The com component provides support for the COM feature.

Functions for Application Developers

The com component contains functions for application developers. To import these functions, you must link to the Com.lib file. The following table shows the functions that are included in the com component.

Function
CLSIDfromProgID CoTaskMemAlloc
CLSIDfromString CoTaskMemFree
CoCreateInstance CoTaskMemRealloc
CoFreeLibrary CoUninitialize
CoFreeUnusedLibraries CreateBindCtx
CoGetClassObject GetClassFile
CoInitializeEx StringfromCLSID
CoLoadLibrary StringfromGUID2
CoSetState StringFromIID
