wininet Module

The wininet module supports the Microsoft Win32 Internet (WinInet) API set. WinInet provides access to common Internet protocols, including Gopher, FTP, and HTTP. Using WinInet, you can write Internet client applications at a higher level of programming, without having to deal with WinSock, TCP/IP, or the details of specific Internet protocols. WinInet provides a consistent set of functions for all three protocols, with a familiar Win32 API interface.
