Downloading the Boot Loader to the Intel DBPXA250 Development Platform for the First Time

To download the Windows CE Ethernet boot loader for the first time, use the Intel jflash utility and the Eboot.nb0 image. Once the boot loader is flashed, you can perform future boot loader updates by downloading the Eboot.bin image with the current boot loader.

For more information about downloading the OS image to the platform, see Downloading the OS Image to the Intel DBPXA250 Development Platform.

For more information, see the Intel Web site and download the Flash Memory Programmer.
