ddraw Module

The ddraw module supports DirectDraw functionality.

Functions for Application Developers

The ddraw module contains functions for application developers. To import these functions, you must link to the Ddraw.lib file. The following functions are included in the ddraw module:

  • DirectDrawCreate
  • DirectDrawCreateClipper
  • DirectDrawEnumerate
  • DirectDrawEnumerateEx

Interfaces

The ddraw module exposes the following interfaces:

  • IDDVideoPortContainer
  • IDirectDraw4
  • IDirectDrawClipper
  • IDirectDrawColorControl
  • IDirectDrawPalette
  • IDirectDrawSurface5
  • IDirectDrawVideoPort
