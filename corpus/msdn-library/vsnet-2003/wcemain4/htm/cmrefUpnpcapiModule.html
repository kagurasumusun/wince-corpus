upnpcapi Module

The upnpcapi module supports the UPnP feature.

Functions for Application Developers

The upnpcapi module exposes functions, which are defined in the Upnpcapi.h header file. To import these functions, you must link to the Upnpcapi.lib file. The following table shows the functions that are included in the upnpcapi component.

Function
UpnpAddDevice UpnpSetControlResponse
UpnpGetSCPDPath UpnpSetErrorResponse
UpnpGetUDN UpnpSetRawControlResponse
UpnpPublishDevice UpnpSubmitPropertyEvent
UpnpRemoveDevice UpnpUnpublishDevice
