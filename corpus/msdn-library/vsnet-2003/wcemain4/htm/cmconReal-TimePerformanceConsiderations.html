Real-Time Performance Considerations

To ensure that Windows CE maintains real-time responsiveness, you should consider several factors that can affect the real-time performance of the operating system (OS). Windows CE is used in both real-time environments and environments that are not real-time. You should avoid using features in the OS within real-time threads and using those components that are not real-time. When you are developing a real-time OS, you should only use functionality and components such as demand paging, power management, and device I/O in an appropriate manner. These components and features are not specifically designed for real-time OSs. Before using them in any real-time OS, you should completely understand their impact on the OS.
