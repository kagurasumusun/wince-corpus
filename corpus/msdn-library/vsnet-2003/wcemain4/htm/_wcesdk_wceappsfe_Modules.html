wceappsfe Modules

The wceappsfe module group supports the following Windows CE application modules: WordPad and Inbox.

The following table shows the modules contained in the wceappsfe group.

Module Description Note Library
addrstor Supports the Pocket Outlook Object Model (POOM) feature.   Addrstor.lib
calnot Supports POOM. Exposes no public functions. Calnot.lib
calstore Supports POOM. Exposes no public functions. Calstore.lib
citydb Supports POOM. Exposes no public functions. Citydb.lib
imap4 Microsoft Exchange Server client-server messaging and groupware module. Exposes no public functions. Imap4.lib
labledit Inbox module. Exposes no public functions. Labledit.lib
mailutil Inbox module. Exposes no public functions. Mailutil.lib
msgstore Inbox module. Exposes no public functions. Msgstore.lib
office Supports Microsoft pocket applications. Exposes no public functions. Office.lib
pimprint Supports Microsoft pocket applications. Exposes no public functions. Pimprint.lib
pimres Supports POOM. Exposes no public functions. Pimres.lib
pimstore Supports POOM. Exposes no public functions. Pimstore.lib
pimutil Supports POOM. Exposes no public functions. Pimutil.lib
pmail Inbox module. Exposes no public functions. Pmail.lib
pwd_res Supports WordPad. Exposes no public functions. Pwd_res.lib
pword Supports WordPad. Exposes no public functions. Pword.lib
pwwiff Supports WordPad. Exposes no public functions. Pwwiff.lib
riched20 Supports Microsoft pocket applications. Exposes no public functions. Riched20.lib
