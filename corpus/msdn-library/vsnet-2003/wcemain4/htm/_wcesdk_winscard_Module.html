winscard Module

The winscard module supports the Windows Smart Card implementation.

Functions for Application Developers

The winscard module contains functions for application developers, which are defined in the Winscard.h header file. To import these functions, you must link to the Winscard.lib file. The following table shows the functions that are included in the winscard module.

Function
ScardBeginTransaction ScardIntroduceCardType
ScardCancel ScardIntroduceReader
ScardConnect ScardListCards
ScardControl ScardListInterfaces
ScardDisconnect ScardListReaders
ScardEndTransaction ScardLocateCards
ScardEstablishContext ScardReconnect
ScardForgetCardType ScardReleaseContext
ScardForgetReader ScardSetAttrib
ScardGetAttrib ScardStatus
ScardGetProviderId ScardTransmit
ScardGetStatusChange
