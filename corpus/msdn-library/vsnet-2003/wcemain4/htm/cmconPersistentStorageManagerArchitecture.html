Flash Memory Operations

This topic explains the flash memory operations that are valid with the PSM.

Reading

Because each linear flash memory location can be randomly read within approximately 100 nanoseconds, a linear flash device is ideal for storing executable code. Advanced interfaces for flash memory exist that allow read transfer rates up to 100 megabytes (MB) per second. Moreover, because flash memory powers-up in read mode, it can be used to store boot code.

Erasing

Erasing is the process of converting zeros to ones. Individual memory locations cannot be erased; they must be erased in blocks. The size of a block varies from device to device and ranges from 8 KB to 128 KB.

For example, if a bit in a flash memory is a zero, to erase that bit, or to write a one to that bit requires that the entire block be erased. This erase process will convert all zeros in the specified block into ones.

The typical erase time for a block is 1 second. One of the biggest jobs of a flash file driver is to efficiently store and modify files of different sizes in a flash device that has a block-erase requirement.

Programming

Programming a location is the process of converting a one to a zero. Programming 0xFF into an erased byte has no effect on the contents, because no ones are converted to zeros; programming 0xEB into an erased byte converts bits two and four to zero.

To program a location, the microprocessor must send a few simple commands to the device along with the address and data to be programmed. Upon receiving this command, the flash device performs the requested program operations. When the program operation is finished, a status register within the flash component will indicate that the program operation was completed and whether or not an error occurred.

A single byte or word can be programmed in a flash memory device; it can take from 5 to 200 or more microseconds to program a location, depending on the particular flash memory device used.

Special Voltages

A flash memory cell requires that specific voltages be available in order to perform the erase and program functions. The current flash devices generate these voltages internally, so the designer need only apply a single voltage, to the device. On devices with a programming voltage pin, that pin can usually be tied to the single voltage.

Reading While Programming or Erasing

Once the command to program a flash memory location or to erase a flash memory block has been received, the flash may become unavailable for execution. This is necessary because the read, program, and erase operations all share circuitry in the flash device, and each operation requires that different voltages be applied internally to the array. You need not worry about supplying these special voltages; the flash device generates these voltages internally.

Suspending Operations

Most flash devices support suspending an erase operation, program operation, or both. This capability allows a system to gain access to time critical code or data while the flash is busy programming or erasing. When the flash receives a suspend command, it waits for an appropriate time to stop the current operation. This time period is called the suspend latency. It saves the exact state of the operation and makes the array available for reading. The suspended operation can be resumed where it left off. The suspend and resume cycle can be performed repeatedly during longer operations such as a block erase.

Event Management

Event management is a technique used to coordinate executing code from the same component that stores files. When a high priority event occurs during a program or erase operation, the event manager suspends the flash programming or erase operation and makes the flash available for execution. When the high priority task is finished, the event manager resumes the flash operation.
