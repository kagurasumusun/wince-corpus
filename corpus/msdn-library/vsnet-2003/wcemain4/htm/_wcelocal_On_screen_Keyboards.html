Japanese IM On-screen Keyboards

To include an on-screen keyboard IM on a Windows CE–based platform, you need to select the corresponding feature in your platform configuration. The search panels do not include or depend on the functionality of an Input Method Editor (IME). To incorporate an IME that works in conjunction with an IM in your target platform, you need to include the IME feature in addition to the IM feature in your platform configuration.

The following table shows and describes the on-screen keyboards that are supported in Windows CE.

Input method Description DLL Static library
Ms Kana IM Enables input of Hiragana and Katakana directly using traditional phonic layout. Mskana.dll Mskana.lib
Ms Roma IM Enables input of the Western alphabet directly through traditional keyboard layout. Msroma.dll Msroma.lib
