caret Component

The caret component provides support for carets. A caret is a flashing line, block, or bitmap that marks the location of the insertion point in the client area of a window.

Functions for Application Developers

The caret component includes functions for application developers, which are defined in the Winuser.h header file. To import these functions, you must link to the caret.lib file. The following table shows the functions that are included in the caret component.

Function
CreateCaret HideCaret
DestroyCaret SetActiveWindow
GetActiveWindow SetCaretBlinkTime
GetCaretBlinkTime SetCaretPos
GetCaretPos SetFocus
GetFocus SetForegroundWindow
GetForegroundWindow ShowCaret
