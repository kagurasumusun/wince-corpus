Screen Savers

The Windows Thin Client Shell supports screen savers. If you want the shell to load a screen saver after a specified period of time, then you must include the dynamic-link library (DLL) of the screen saver in your image. Screen-saver support also requires that the registry be properly configured. The following registry key shows the required settings for Windows Thin Client.

[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Power]
    "BattPowerOff"=DWORD:0
    "ExtPowerOff"=DWORD:0
    "ScreenPowerOff"=DWORD:300

The ScreenPowerOff registry entry specifies the amount of time, in seconds, that must elapse with no user input before the shell starts the screen saver. To prevent the network from resetting the no-activity timer, the following registry setting must be entered.

[HKEY_LOCAL_MACHINE\Comm\CXport]
    "NoIdleTimerReset"=DWORD:1

When the user presses the CTRL+ALT+END key combination, the Windows Thin Client Shell brings the shell UI to the foreground. To configure this key combination, set the following registry entries.

[HKEY_LOCAL_MACHINE\HARDWARE\DEVICEMAP\KEYBD]
    "DriverName"="Kbdmouse.dll"
    "CalVKey"=DWORD:0
    "ContLessVKey"=DWORD:0
    "ContMoreVKey"=DWORD:0
    "TaskManVKey"=DWORD:23

The registry subkey HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\WBT\Shell for the thin client shell is used to configure the screen saver. This subkey has two named values, ScreenSaver and ScreenSaverEnabled as described below.

  • ScreenSaver (REG_SZ)

    The ScreenSaver entry specifies the DLL to load when starting the screen saver. This entry can only be made at build time. 

    [HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\WBT\Shell] 
    "ScreenSaver"="<screen saver DLL>"
    "ScreenSaverEnable"=dword:1

    Three screen savers are included with the Windows-based Terminal user interface source: SSFloat (ssfloat.dll), SSBlank (ssblank.dll), SSTile (sstile.dll). However, only one can be included as the screen saver. To include one of these screen savers, list the name of the desired screen saver in the RDP_MODULES environment variable (%_PROJECTROOT%\Oak\Misc\Cesysgen.bat).

  • ScreenSaverEnable (REG_DWORD)

    The ScreenSaverEnable entry specifies whether to enable the screen saver. If ScreenSaverEnable is equal to 0, then the screen saver is not enabled. If ScreenSaverEnable is greater than 0, then the screen saver is enabled. Thiscan be changed dynamically, because the shell queries this registry every time that it receives a WM_POWERBROADCAST message. If ScreenSaverEnable is set, then the shell attempts to load the specified screen saver.

    You must configure the registry. The following code example shows how to configure the registry. 

    [HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Power]
    "BattPowerOff"=DWORD:0
    "ExtPowerOff"=DWORD:0
    "ScreenPowerOff"=DWORD:<screen-saver timeout (in seconds)>
