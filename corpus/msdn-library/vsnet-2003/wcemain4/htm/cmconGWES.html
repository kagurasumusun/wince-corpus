Graphics, Windowing, and Events Subsystem

The Graphics, Windowing, and Events subsystem (GWES) provides the functionality needed to display windows, draw objects, and enable notifications. However, this functionality has no guaranteed latency. Because GWES utilizes a single critical section to protect access to its internal data structures, a thread can be blocked for an unbounded length of time while it waits for another thread to complete an operation. For this reason, an OEM should not make any GWES API calls in the same thread that also requires a real-time response. Also, OEMs should not use SetTimer as a real-time timer. SetTimer is a timer based on Windows CE message queues, in which there is no guarantee for the signaling time. In addition to impacting real-time threads through its direct use of the APIs, GWES can also impact performance through their use of display drivers.
