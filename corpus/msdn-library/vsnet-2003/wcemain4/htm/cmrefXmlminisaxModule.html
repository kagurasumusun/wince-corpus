xmlminisax Component

The xmlminisax component supports a minimal XML parser using a scaled down version of the Simple API for XML (SAX).

Interfaces

The xmlminisax component exposes the following interfaces:

  • ISAXAttributes
  • ISAXXMLReader
  • ISAXContentHandler
