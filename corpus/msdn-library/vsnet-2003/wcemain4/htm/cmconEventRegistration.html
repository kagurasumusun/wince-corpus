Event Registration

For an OS component that requires a mechanism to trigger applications, it is required to trigger the following registry key.

[HKEY_LOCAL_MACHINE\System\Events]
     <Event Name>:REG_SZ"<Event Description>"

<Event Name> is the name of the event that will be created when the system boots.

<Event Description> is the description of the event-based name. This can be a NULL string. The entry to add the <Event Name> value will be controlled by the Sysgen process.

The following table shows some predefined OS events names.

Event name Description
SYSTEM/GweApiSetReady Owned by GWES.exe. This signals that the GDI and USER APIs are registered and ready to be used.
SYSTEM/BootPhase2 Owned by Filesys.exe. This is triggered when the registry has switched from the boot registry to the real system registry.

OEMs can define their own event names, for example, OEM/EventX. However, event names starting with SYSTEM/ should not be used because event names starting with SYSTEM/ are reserved. This will avoid name collisions later on.
