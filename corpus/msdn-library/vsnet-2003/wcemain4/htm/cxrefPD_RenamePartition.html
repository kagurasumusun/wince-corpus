PD_RenamePartition

This function renames a partition on the storage volume.

DWORD PD_RenamePartition(
DWORD dwStoreId, 
LPCTSTR szOldName, 
LPCTSTR szNewName
);

Parameters

dwStoreId
[in] This is returned from a PD_OpenStore call.
szOldName
[in] Old name of the partition.
szNewName
[in] New name of the partition.

Return Values

TRUE if the call was successful, FALSE otherwise.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later   Partdrv.h
