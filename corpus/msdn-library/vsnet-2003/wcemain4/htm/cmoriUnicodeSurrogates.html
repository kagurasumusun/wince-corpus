Unicode Surrogates

The Unicode standard defines surrogates. A surrogate or surrogate pair is a pair of 16-bit Unicode code values that represent a single character. Surrogates provide additional character support for the languages that need more than the 65,536 characters in the 16-bit Unicode code space.

Planes two and three defined in ISO/IEC 10646 are reserved for ideographic characters. These planes fall in the high surrogate range of U+D840 to U+D8BF. The first (high) surrogate is a 16-bit code value in the same range, U+D800 to U+DBFF. The second (low) surrogate is a 16-bit code value in the range U+DC00 to U+DFFF. Using surrogates, Unicode can support over one million characters.

The Microsoft® Windows® CE .NET operating system (OS) provides Unicode surrogate support at the OS level and in Microsoft Internet Explorer 5.5. The support is limited to surrogate handling and display; editing is not supported.
