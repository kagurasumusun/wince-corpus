Microsoft Windows CE .NET  

Obsolete Functionality

The following table describes obsolete functionality.

Issue Description
OEMClockFreq The kernel no longer requires the OAL variable OEMClockFreq. You can remove the following code from your platform code. 
unsigned long OEMClockFreq = OEM_CLOCK_FREQ;
Profiling The KCP_xxx functions are no longer required by the kernel to perform profiling.
