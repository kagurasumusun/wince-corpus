Traditional Chinese Pocket IME UI Module Registry Key

The Traditional Chinese Pocket IME allows OEMs to supply a customized UI module. To use a custom UI module on the target platform, you need to update the UI Module registry subkey under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Layouts for your IME.

Phonetic

The following table shows the UI module entry for the HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Layouts\e0010404 registry key. The e0010404 subkey is the keyboard layout value assigned to the Phonetic IME.

Registry key Type Default value Description
UI Module REG_SZ Msimeuic.dll The DLL name for the UI module.

Chang Jei

The following table shows the UI module entry for the HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Layouts\e0020404 registry key. The e0020404 subkey is the keyboard layout value assigned to the Chang Jei IME.

Registry key Type Default value Description
UI Module REG_SZ Msimeuic.dll The DLL name for the UI module.
