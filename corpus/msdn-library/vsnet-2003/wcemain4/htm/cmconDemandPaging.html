Demand Paging

Demand paging allows memory to be shared among more processes. In a demand-paging environment, pages from one process can be discarded and removed from memory when memory is low. Because there is a penalty for using demand paging in a real-time environment, it should be avoided. An OEM can turn off demand paging for the entire system by using the Config.bib file. An OEM can also turn off demand paging for an individual dynamic-link library (DLL) by using LoadDriver or by creating a file system driver that does not support demand paging. When demand paging is turned off, all of the code for a module is loaded into memory and never discarded.
