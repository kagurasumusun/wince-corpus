PSM_FormatOptions

This structure stores user-configurable format options.

typedef struct PSM_FormatOptions {
UINT32 MinimumReclaimSize;
UINT16 StreamingGranularity;
UINT16 MaxFilenameLength;
UINT8 ReclaimThreshold;
UINT8 StreamingOverhead;
UINT8 UpdateAccessTimesEnabled;
UINT8 Reserved;
} PSM_FormatOptions, *PSM_FormatOptionsPtr;

Members

MinimumReclaimSize
This defines the minimum amount of dirty space, in bytes, that must exist in an erase block before it can automatically be reclaimed in a threshold reclaim operation. Allowable range is 0 KB to 252 KB. This member works in conjunction with the ReclaimThreshold member.
StreamingGranularity
This defines the smallest granularity, in bytes, that an object can be allocated at when using the streaming interface. For example, a five-byte data object written using the streaming interface will cause StreamingGranularity bytes to be reserved for future additions to the original logical unit. Nonstreamed writes use a much smaller, internal granularity that is not user-definable.

Values less than 1 KB decrease overall performance significantly. Allowable values are 256, 512, 1024, 2048, 4096, and 8192.

MaxFilenameLength
The maximum length in characters of a single path element like a file or directory name. Includes all file name characters, name, extension, '.' delimiter, and so on. Allowable range is 8 to 1024.
ReclaimThreshold
This defines the minimum amount of dirty space that must exist in an erase block before it can automatically be reclaimed in a threshold reclaim operation. This differs from the MinimumReclaimSize member in that it is expressed as a percentage of the total available space in the erase block, rather than a fixed value. For example, if this is set to 20, a block will only be eligible for threshold reclaim if 20% of its available space is dirty.

This value is always overridden by the MinimumReclaimSize member, in case the percentage works out to be a very small value.

StreamingOverhead
This defines the amount of overhead that is set-aside during the format to ensure that a constant data rate can be maintained during overwrite and streaming data operations.

It is always set to the PSM_StreamingOverheadNone which indicates that no extra overhead will be set aside. No constant data rates can be guaranteed.

UpdateAccessTimesEnabled
When set to TRUE, a file or directory's time and date stamp is updated every time it is accessed, or whenever its contents are updated. When set to FALSE, this information is not stored, greatly reducing the amount of flash that is dirtied. In this latter case, the creation timestamp will be returned in place of the update and access timestamps.
Reserved
This member is reserved for future use. Its contents are undefined, and are ignored by the PSM software stack.

Remarks

These parameters are in %_WINCEROOT%\Platform\SA11X0BD\PSM\OEM\Plat_api.c and %_WINCEROOT%\Platform\SA11X0BD\PSM\INC\Plat_api.h. The default parameters are appropriate for general applications. They can be modified to improve storage efficiency or file system performance as appropriate. These parameters are members of a structure of type PSM_FormatOptions. A pointer to the structure is passed to those functions that format the file partition.
