File Systems and Data Store

The following table shows the Core OS catalog features that appear in Platform Builder. The table includes features for headless devices and display-based devices.

Feature Sysgen variable Description
Compression SYSGEN_NKCOMPR API that compresses the data in the RAM and ROM file systems, as well as the database volumes.

Available only in headless devices.

For more information, see File Compression.
Database support SYSGEN_FSDBASE API that provides built-in database support.

Available only in headless devices.
Bit-based SYSGEN_FSREPLBIT Identifies what changes have occurred in a database or RAM file system on the device and therefore must be replicated on the desktop. This model relies on four bits per object to replicate the data.

Available in both headless and display-based devices.

For more information, see Bit-Based Replication.
Change Numbers SYSGEN_FSREPLCOUNT Identifies what changes have occurred in a database or RAM file system on the device and therefore must be replicated on the desktop. This model relies on a DWORD that contains a counter identifying when a change occurred.

Available in both headless and display-based devices.
RAM & ROM File System SYSGEN_FSRAMROM A file system driver capable of reading data from the ROM file system and the RAM file system in the object store.

Available in both headless and display-based devices.
ROM-only File System SYSGEN_FSROMONLY A file system driver capable of reading data from the ROM file system.

Available in both headless and display-based devices.
Hive-based Registry SYSGEN_FSREGHIVE A registry system that stores data inside files, or hives, which can be kept on any file system.

Available in both headless and display-based devices.

For more information, see Hive-Based Registry.
RAM-based Registry SYSGEN_FSREGRAM A system that stores all registry data within the object store.

Available in both headless and display-based devices.

For more information, see RAM-Based Registry.
Storage Manager SYSGEN_STOREMGR The Storage Manager is responsible for all external storage items, such as file systems, file system filters, and partitioning.

Available in both headless and display-based devices.

For more information, see Storage Manager.
CD/UDFS File System SYSGEN_UDFS A file system driver that supports both Compact Disc File System (CDFS) and Universal Disc File System (UDFS) and reads compact discs (CDs), digital video discs (DVDs), and CD-ROMs.

Available in both headless and display-based devices.

For more information, see CD/UDFS File System.
FAT File System SYSGEN_FATFS A file system driver that supports the file allocation table (FAT) file system.

Available in both headless and display-based devices.

For more information, see FAT File System.
System Password SYSGEN_FSPASSWORD API that allows a password to be associated with a device to prevent unauthorized access.

Available only in headless devices.
