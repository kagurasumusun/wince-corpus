Control Panel Utility Keys

The base registry subkey for the Control Panel utility is HKEY_LOCAL_MACHINE\SYSTEM\CtlpnlApplet. The following table shows the named values for this subkey.

Value Description
SingleInstance: DWORD Default setting is 0.

The subkey for the Control Panel wizard settings is HKEY_LOCAL_MACHINE\SYSTEM\CtlpnlApplet\WizCplApplet. The following table shows the named values for this subkey.

Value Description
CplApplet0 Default setting is LOC_WBTSHELL_CPL_NETWORK.
CplApplet1 Default setting is LOC_WBTSHELL_CPL_PRINTERS.

The subkey for the Control Panel property utilities is HKEY_LOCAL_MACHINE\SYSTEM\CtlpnlApplet\TermPropCplApplet. The following table shows the named values for this subkey.

Value Description
CplApplet0 Default setting is LOC_WBTSHELL_CPL_NETWORK.
CplApplet1 Default setting is LOC_WBTSHELL_CPL_PRINTERS.
CplApplet0 Default setting is LOC_WBTSHELL_CPL_NETWORK
CplApplet1 Default setting is LOC_WBTSHELL_CPL_PRINTERS
CplApplet2 Default setting is LOC_WBTSHELL_CPL_KEYBOARD
CplApplet3 Default setting is LOC_WBTSHELL_CPL_SYSTEM
CplApplet4 Default setting is LOC_WBTSHELL_CPL_MOUSE
CplApplet5 Default setting is LOC_WBTSHELL_CPL_VOLUMEANDSOUNDS
CplApplet6 Default setting is LOC_WBTSHELL_CPL_DATETIME
CplApplet7 Default setting is LOC_WBTSHELL_CPL_ACCESSIBILITY
CplApplet8 Default setting is LOC_WBTSHELL_CPL_REGIONAL
