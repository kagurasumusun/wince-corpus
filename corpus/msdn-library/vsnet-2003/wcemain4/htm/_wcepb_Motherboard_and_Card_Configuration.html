CEPC Based SDB Motherboard and Card Configuration

Consult the motherboard documentation for information on configuring the motherboard, the jumper settings for the microprocessor, and system memory. The following table shows a typical hardware configuration for a CEPC based on the Asus P5A motherboard. The hardware configuration for your CEPC may be different, depending on the type of motherboard you have chosen and the number of available I/O slots.
