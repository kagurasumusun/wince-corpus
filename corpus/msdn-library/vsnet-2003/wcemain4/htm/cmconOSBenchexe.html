OSBench.exe

This tool enables you to collect timing samples to measure the performance of the kernel by conducting scheduler performance-timing tests. A scheduler performance- timing test measures how much time is required for a basic kernel operation, such as a synchronization action. An example of a synchronization action is scheduling a thread that is waiting on an event that has just been set by another thread. Wherever appropriate, the test runs two sets of metrics: thread-to-thread within a process and thread-to-thread across processes. If appropriate, a stress suite can be applied while running the test.

The OSBench.exe tool enables you to determine how long it takes to perform the following tasks:

  • Acquire or release a critical section
  • Wait or signal an event
  • Create a semaphore or mutex
  • Yield a thread
  • System API call

You can use the following command-line parameters with this tool.

osbench [-all] [-t test_case] [-list] [-v] [-n number] [-m address] 
[-o file_name] [-h]

Parameters

-all
Run all tests. Default: run only those specified by the -t parameter.
-t test_case
Identifier of the test case to run. A separate -t parameter is required for each test.
-list
List test identifiers with descriptions.
-v
Verbose; show all measurements. Default: summary output only.
-n number
Number of samples per test. Default: 100.
-m address
Virtual address to write marker values. Default: none.
-o file_name
Output to comma-separated file. Default: output to debugger message window.
-h
Display help screen.
