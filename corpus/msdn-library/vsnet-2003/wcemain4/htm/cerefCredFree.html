CredFree

This function frees the buffer allocated by CredRead.

CredFree( 
PVOID pCred 
);

Parameters

pCred
[in] Pointer to the credential structure to delete.

Return Values

None.

Remarks

Because the pointer is declared void, this function can be used to free any buffer of any type.

Requirements

Runs on Versions Defined in Include Link to
Windows CE OS .NET 4.0 and later Credmgr.h Credmgr.h Secur32.lib
