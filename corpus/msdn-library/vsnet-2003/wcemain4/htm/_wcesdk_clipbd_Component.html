clipbd Component

The clipbd component provides clipboard functionality.

Functions for Application Developers

The clipbd component includes functions for application developers, which are defined in the Winuser.h header file. To import these functions, you must link to the clipbd.lib file. The following table shows the functions that are included in the clipbd component.

Function
CloseClipboard GetClipboardOwner
CountClipboardFormats GetOpenClipboardWindow
EmptyClipboard GetPriorityClipboardFormat
EnumClipboardFormats IsClipboardFormatAvailable
GetClipboardData OpenClipboard
GetClipboardDataAlloc RegisterClipboardFormat
GetClipboardFormatName SetClipboardData
