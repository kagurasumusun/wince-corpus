xmldom Component

The xmldom component supports the basic Document Object Model (DOM) for MSXML.

Interfaces

The following table shows the interfaces exposed by the xmldom component.

Interface
DOMDocument IXMLDOMImplementation
IXMLDOMAttribute IXMLDOMNamedNodeMap
IXMLDOMCDATASection IXMLDOMNode
IXMLDOMCharacterData IXMLDOMNodeList
IXMLDOMComment IXMLDOMNotation
IXMLDOMDocumentFragment IXMLDOMParseError
IXMLDOMDocumentType IXMLDOMProcessingInstruction
IXMLDOMElement IXMLDOMText
IXMLDOMEntity IXTLRuntime
IXMLDOMEntityReference
