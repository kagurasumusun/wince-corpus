ppp Module

The ppp module supports the Point-to-Point Protocol (PPP) and provides remote access server (RAS) functionality.

Functions for Application Developers

The ppp module contains functions for application developers, which are defined in the Ras.h header file. To import these functions, you must link to the ppp.lib file. The following table shows the functions that are included in the pp module.

Function
RasDeleteEntry RasGetLinkStatistics
RasDial RasGetProjectionInfo
RasEnumConnections RasHangUp
RasEnumDevices RasRenameEntry
RasEnumEntries RasSetEntryDialParams
RasGetConnectStatus RasSetEntryProperties
RasGetEntryDialParams RasValidateEntryName
RasGetEntryProperties
