waveapi Module

The waveapi module controls waveform audio capture and playback and manages wave API components. The following table shows the components contained in the waveapi module.

Module Description Note Library
wapiacm The Audio Compression Manager component. Optional. Exposes no public functions. wapiacm.lib
wapiacmui Provides a UI for the Audio Compression Manager. Optional. Exposes no public functions. wapiacmui.lib
wapimap The wave mapping component. Optional. Exposes no public functions. wapimap.lib
wapiwave Provides the waveform audio services API, the hardware mixer API, and the play sound API. Optional. Exposes no public functions. wapiwave.lib
