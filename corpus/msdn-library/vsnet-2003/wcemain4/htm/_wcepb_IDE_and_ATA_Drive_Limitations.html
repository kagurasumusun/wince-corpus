IDE and ATA Drive Limitations

This topic describes a potential limitation or danger if your CEPC has an IDE drive, such as a hard disk and a PCMCIA ATADisk. If the PCMCIA reader has more than one slot, it is possible for a conflict to occur between the IDE hard disk and the second PCMCIA card. Microsoft recommends using only the first slot on a dual slot PCMCIA card reader if a hard disk is installed.
