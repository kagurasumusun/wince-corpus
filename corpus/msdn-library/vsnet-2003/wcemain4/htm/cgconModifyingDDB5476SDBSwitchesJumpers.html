Modifying the NEC DDB-Vrc5476 (Boston) SDB Switches and Jumpers

  1. If you are not using the Compact PCI connector, the following jumper settings are necessary.
    Jumper Setting
    J11 Connect pins 2 and 3
    J12 Connect pins 2 and 3

    - or -

    If you are using the Compact PCI connector (PCI REQ and GNT signals for built in PCI slot marked PCI4 are routed to the Compact PCI connector) the following jumper settings are necessary.

    Jumper Setting
    J11 Connect pins 1 and 2
    J12 Connect pins 1 and 2
  2. The following table shows the functionality of DIP switch S1.
    S1-1 S1-2 S1-3 S1-4 Function
    On X X X Code executes from boot ROM monitor program after reset.
    Off X X X Code executes from flash memory after reset.
    X X X On Boot loader software reads S1-4 and jumps directly to the image.
    X X X Off Boot loader software reads S1-4 and downloads the image before jumping.
  3. Build the platform.
