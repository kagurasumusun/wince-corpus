Flash Memory File Partition

As the file system manages the file partition it occasionally copies files into a spare block before erasing another block. Consequently, the file partition must always have a spare block, and the minimum size for a file partition is two blocks, or two block-pairs if there are two devices per bank. Apart from the spare block restriction, the file partition can be any number of blocks.
