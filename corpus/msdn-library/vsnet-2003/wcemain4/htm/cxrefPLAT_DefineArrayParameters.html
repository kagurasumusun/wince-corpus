PLAT_DefineArrayParameters

This function supplies platform-specific information to the Intel Persistent Storage Manager (PSM) software stack.

UINT8 PLAT_DefineArrayParameters(
PSM_OEMInfoPtr oem_info_ptr
);

Parameters

oem_info_ptr
[out] On input, this variable points to a PSM_OEMInfo structure. This structure must be completely filled with valid information before this function returns.

Return Values

This function returns FALSE if no error occurs, otherwise a nonvalue indicates an error condition.

Remarks

The PSM stack calls this function during initialization, to retrieve information about the location of the flash array, as well as information about the size and start offset of the data partition.

Normally, this function just copies the contents of the local PSM_OEMInfo structure out to the caller's memory space. This procedure is defined as a function to give OEMs the opportunity to analyze the current state of their system, and adjust these values accordingly if that is desired.
