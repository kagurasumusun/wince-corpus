fspass Component

The fspass component supports password functionality.

Functions for Operating System Developers

The fspass component includes functions for OS configuration, which are defined in the Winbase.h header file. To import these functions, you must link to the fspass.lib file. The following functions are included in the fspass component:

  • CheckPassword
  • GetPasswordActive
  • SetPassword
  • SetPasswordActive

Functions for Application Developers

The fspass component includes function for application developers, which is defined in the Winbase.h header file. To import this function, you must link to the fspass.lib file. The following function is included in the fspass component:

  • CheckPassword
