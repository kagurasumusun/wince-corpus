Format Parameters

Format parameters are in %_WINCEROOT%\Platform\SA11X0BD\PSM\OEM\Plat_api.c and %_WINCEROOT%\Platform\SA11X0BD\PSM\INC\Plat_api.h. The default values are appropriate for general applications. The default values can be modified to improve storage efficiency or file system performance as appropriate. These parameters are members of a structure of type PSM_FormatOptions. A pointer to the structure is passed to those functions that format the file partition.

Controlling When a Reformat Happens

At a cold boot, the Installable File System Manager (IFS) examines the file partition to see if it is valid. If it is valid, the PSM initializes itself to access files. However, if the file partition appears invalid, PSM will invoke PLAT_FormatRecovery. This function gives the OEM the option of reformatting the partition. If this function returns a TRUE value, the media will be reformatted using a structure of type PSM_FormatOptions, pointed to by format_options_ptr. If the function returns FALSE, the media will not be formatted.

Of course, any reformatting operation erases everything in the partition, so the OEM may want to make sure this is the best thing to do. To make sure the media is truly corrupted, and not temporarily impaired by low batteries or some other problem, the OEM could use this function to rule out any obvious causes for soft read errors, like low battery. Once this has been done, and the PSM still reports corrupted media, the OEM can allow the format to proceed.

Commanding a Format

When the OS image loads the PSM, the OS image's initialization routines examine the file partition and verify that it has a valid format. If the file partition has a valid format, PSM makes the files available to the OS. If the partition does not have a valid format, PSM gives the OEM the option of formatting it when it invokes PLAT_FormatRecovery.

The OEM does not have to wait for a cold boot to do a format, they can cause a format at any time by calling FG_Init and passing a pointer to both an empty buffer for a memory map structure of type PSM_OEMInfo and to a structure of type PSM_FormatOptions. PSM_OEMInfo is only a buffer that PSM uses to pass information internally. PSM_FormatOptions is a constant that describes how to format the media.

The following code shows how to command a format.

PSM_OEMInfo oem_info;
static const PSM_FormatOptions format_options = {
/* MinimumReclaimSize   */ 8192,
/* StreamingGranularity */ 1024,
/* MaxFilenameLength    */ 260,
/* ReclaimThreshold     */ 50,
/* StreamingOverhead    */ PSM_StreamingOverheadNone,
/* UpdateAccessTimesEnabled */ FALSE
};
FG_Shutdown(); /* Causes PSM to exit all file operations */
FG_Init(&oem_info, &format_options); /* formats the file partition */
