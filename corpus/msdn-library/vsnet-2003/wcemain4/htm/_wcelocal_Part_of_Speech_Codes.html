Part-of-Speech Codes

This section describes the most common POS codes and provides an example for each code.

Noun

Nouns define a part of speech used to specify the name of a person, place, or thing. The word in this part of speech can be an object or subject in sentence.

The following table provides a list of nouns and their corresponding POS codes:

Code Part of Speech Description / Example (in Japanese)
100 Noun

106 Human name

107 Family name

108 Given name

109 Place name

118 Proper noun

Pseudo Noun Followed by Suru / Zuru

A pseudo noun defines a part of speech that functions as a noun if it has no conjugation and functions as a verb if it has the conjugation "-suru" or "-zuru".

The following table provides a list of pseudo nouns and their corresponding POS codes:

Code Part of Speech Example (in Japanese)
101 Pseudo noun followed by suru

102 Pseudo noun followed by zuru

Special Noun

Special nouns specify nouns that have unique usages.

The following table provides a list of special nouns and their corresponding POS codes:

Code Part of Speech Description / Example (in Japanese)
103 Adjectival noun

104 Adverbial noun

105 Pseudo adjectival noun

Verb

Verbs define a part of speech that contains words used to show that an action is taking place, or to indicate the existence of a state or condition. A verb is classified by its conjugated form.

The following table provides a list of verbs and their corresponding POS codes:

Code Part of Speech Description / Example (in Japanese)
200 5th-step verb suffixed with –a/wa

201 5th-step verb suffixed with -ka

202 5th-step verb suffixed with -ga

203 5th-step verb suffixed with -sa

204 5th-step verb suffixed with -ta

205 5th-step verb suffixed with -na

206 5th-step verb suffixed with -ba

207 5th-step verb suffixed with -ma

208 5th-step verb suffixed with -ra

213 1st-step verb

Adjective / Nominal Adjective

Adjectives define a part of speech that contains words used to qualify or describe a noun or pronoun.

The following table provides a list of adjectives and their corresponding POS codes:

Code Part of Speech Description / Example (in Japanese)

400 Nominal Adjective
