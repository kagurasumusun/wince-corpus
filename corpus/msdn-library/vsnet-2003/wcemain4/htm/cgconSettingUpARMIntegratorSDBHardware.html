Setting Up the ARM Integrator AP SDB Hardware

The following steps show you how to connect the ARM Integrator AP SDB to a development workstation. If you are using the MQ200 display card, be sure that switch S1 on the MQ200 is set to the Down position. Otherwise, the MQ200 will not function correctly.

  1. Connect a serial cable to the DBG SER port labeled J14 on the ARM Integrator AP SDB and to the development workstation.
  2. Connect a keyboard and a mouse to the ARM Integrator AP SDB.

    The top PS/2 connector is for the mouse and the bottom PS/2 connector is for the keyboard. This is silk screened on the SDB.

  3. Optionally connect the Multi-ICE probe to the microprocessor card to the connector labeled J6.
    Note   The Multi-ICE probe is only needed when flashing a boot loader for the first time (Eboot.rom). After that, the boot loader itself can be used to download new boot loaders (Eboot.bin).
  4. Connect an ATX power supply
  5. Modify the ARM Integrator AP SDB switches and jumpers.
  6. Turn on the ARM Integrator AP SDB by pressing the red button.
