Audio Technologies

Adding sound to an application can make the application more efficient to use. By using sounds to draw attention at critical points, you can help users avoid mistakes and notify them when a time-consuming operation concludes. Windows CE .NET supports three multimedia APIs dedicated to audio:

  • DirectSound
  • DirectMusic
  • Waveform Audio

The waveform audio APIs combined with the ability to mix waveform output and DirectSound gives you exceptional audio flexibility in device applications.

The unified audio model (UAM) introduced with Windows CE .NET makes it possible, but not mandatory, for OEMs to write one audio driver that supports both waveform audio and DirectSound output. A practical outcome of UAM is that because it now contains mixing support, DirectSound is really only necessary now for very specialized situations. In many cases, DirectSound is only used on a platform for legacy support of older applications.
