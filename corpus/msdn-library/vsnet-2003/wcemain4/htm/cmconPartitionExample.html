Flash Memory Partition Example

Consider a flash array that consists of two 8-MB 28F640J3 components connected to 32 MB chips, to a StrongARM SA1100 microprocessor. The boot code is 220 KB, the OS image is 12161 KB, the maximum size of the registry will be 150 KB and the rest of the array will be used for file storage. All partitions will be in a single bank.

The 28F640J3 is an 8-MB component with a 128-KB block. The array-size is 16 MB, and the block-pair size is 256 KB.

The first step is to decide and calculate how many block-pairs each partition will be. The boot code will be located in its own blocks, so that the OS image can be erased and reprogrammed without affecting the boot code. It is 220 KB and will fit in a single block-pair. The OS image is 12161 KB; so 48-block pairs will be needed. The total number of block-pairs for code will be 49. The registry will fit in a single block-pair; so two block-pairs will be reserved. The array has a total of 64 block-pairs. Fifty-one are used to store code and the registry leaving thirteen for file storage.

The following table shows the memory map of the example system.

Block number Address Contents
0 through 1 0x0000000 through 0x003FFFF Boot code
1 through 49 0x0040000 through 0xC3FFFF OS Image
49 through 62 0xC40000 through 0xF7FFFF Files
62 through 64 0xF80000 through 0xFFFFFF Registry
