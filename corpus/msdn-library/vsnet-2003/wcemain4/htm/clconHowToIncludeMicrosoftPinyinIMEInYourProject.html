Including Simplified Chinese Pinyin IME in a Project

You can include Microsoft Pinyin (MSPY) IME 2.0 for Windows CE in your project from Platform Builder. Simply drag and drop the MSPY2 for Windows CE feature from the Catalog window to the FeatureView window of your project. When you add the Pinyin IME to your project, you must also select one of the lexical database options. The following table shows the three databases that are available.

Database Description
Minimal Database 1.1 MB
Compact Database 1.3 MB
Standard Database 1.7 MB
