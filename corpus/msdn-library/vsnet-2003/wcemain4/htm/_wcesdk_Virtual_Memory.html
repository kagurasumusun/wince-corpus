Virtual Memory

Windows CE implements a paged virtual memory management system similar to other Microsoft Win32®–based operating systems. In Windows CE, a page comprises either 1,024 or 4,096 bytes depending on the microprocessor. Each process in Windows CE has only 32 MB of virtual address space. This is space used for your process, dynamic-link libraries (DLLs), heaps, stacks, and virtual memory allocations. Memory allocated through memory-mapped files or large VirtualAllocs are not part of a process' virtual address space.
