dsound Module

The dsound module provides support for DirectSound mixers.

Functions for Application Developers

The dsound module contains functions for application developers. To import these functions, you must link to the Dsound.lib file. The following functions are included in the dsound module:

  • DirectSoundCaptureCreate
  • DirectSoundCaptureEnumerate
  • DirectSoundCreate
  • DirectSoundEnumerate

Interfaces

The dsound module exposes the following interfaces:

  • IDirectSound
  • IDirectSoundBuffer
  • IDirectSoundCapture
  • IDirectSoundCaptureBuffer
  • IDirectSoundNotify
  • IKsPropertySet

Components

The following table shows the components contained in the dsound module.

Component Description Note Library
dsmixer Fixed-rate DirectSound mixer. Exposes no public functions. Dsounds.lib
dsmixermr Multi-rate DirectSound mixer. Exposes no public functions. Dsounds.lib
