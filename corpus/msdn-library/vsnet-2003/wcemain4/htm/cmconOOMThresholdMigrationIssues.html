OOM Threshold Migration Issues

The default out-of-memory (OOM) critical threshold set by the OOM component has changed from 24K to 80K. The OOM low threshold remains at 128K. You can override these OOM component settings in the registry or override the settings by calling the SetOomEvent function if the OOM component is not included.
