coremain Component

The coremain component provides base functionality for time, critical sections, and interlock.

Functions for Application Developers

The coremain component includes functions for application developers, which are defined in the Winbase.h header file. To import these functions, you must link to the coremain.lib file. The following table shows the functions included in the coremain component.

Function
CompareFileTime InitializeCriticalSection
DeleteCriticalSection LeaveCriticalSection
EnterCriticalSection LocalFileTimeToFileTime
ExitThread Memchr

FileTimeToSystemTime SetSystemTime
GetLocalTime SetTimeZoneInformation
