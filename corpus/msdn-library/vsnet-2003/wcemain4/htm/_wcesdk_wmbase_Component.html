wmbase Component

The wmbase component provides support for the window manager.

Functions for Application Developers

The wmbase component includes functions for application developers, which are defined in the Winuser.h header file. To import these functions, you must link to the wmbase.lib file. The following table shows the functions that are included in the wmbase component.

Function
CreateWindowEx GetWindowThreadProcessId
DestroyWindow IsWindow
GetClassLong IsWindowVisible
GetDoubleClickTime SetClassLong
GetSystemMetrics
