DirectSound Structures

This section contains reference information for the following structures used with DirectSound:

  • DSBCAPS
  • DSBPOSITIONNOTIFY
  • DSBUFFERDESC
  • DSCAPS
  • DSCBCAPS
  • DSCBUFFERDESC
  • DSCCAPS
Note   The memory for all DirectX structures must be initialized to zero before use. In addition, all structures that contain a dwSize member must set the member to the size of the structure, in bytes, before use. The following example performs these tasks on a common structure, DSCAPS_wcesdk_DSCAPS_dsound.
DSCAPS dscaps; // Cannot use this yet.
 
ZeroMemory(&dscaps, sizeof(dscaps));
dscaps.dwSize = sizeof(dscaps);
 
// Now the structure can be used.
.
