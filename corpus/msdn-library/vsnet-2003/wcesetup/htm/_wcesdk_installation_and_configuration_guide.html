Microsoft Windows CE 3.0  

Installation and Configuration Guide

The Installation and Configuration Guide describes tools that you can use to install applications on a Windows CE-based device, including:

  • The CAB Wizard.
  • The Application Manager application, CeAppMgr.exe.

This guide also explains how to add additional menu items to the Tools menu in the Windows CE Explorer window by using code to directly place values in the proper registry locations.
