SourceDisksNames

The [SourceDisksNames] section is required and describes the name and path of the disk on which your application resides.

[SourceDisksNames]
disk_id= ,comment,,path
[disk_id= ,comment,,path]

The following code example shows a typical [SourceDisksNames] section.

[SourceDisksNames]                   ; Required section
1 = ,"Common files",,C:\app\common   ; Using an absolute path

[SourceDisksNames.SH3]
2 = ,"SH3 files",,sh3                ; Using a relative path

[SourceDisksNames.MIPS]
2 = ,"MIPS files",,mips              ; Using a relative path
