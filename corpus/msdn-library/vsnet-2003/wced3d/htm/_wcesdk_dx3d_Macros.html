Direct3D Macros

This section contains reference information for the macros provided by Microsoft® Direct3D®.

Macro Description
D3DCLIPPLANEn Defines bit patterns that enable user-defined clipping planes.
D3DCOLOR_ARGB Initializes a color with the supplied alpha, red, green, and blue values.
D3DCOLOR_COLORVALUE Initializes a color with the supplied red, green, blue, and alpha floating-point values.
D3DCOLOR_RGBA Initializes a color with the supplied red, green, blue, and alpha values.
D3DCOLOR_XRGB Initializes a color with the supplied red, green, and blue values.
D3DFVF_TEXCOORDSIZEn Constructs bit patterns that are used to identify texture coordinate formats within a flexible vertex format description.
D3DTS_WORLD Identifies the transformation matrix being set as the world transformation matrix.
D3DTS_WORLDn Identifies subsequent transformation matrices that can be used to blend vertices by using the corresponding matrix and a blending (beta) weight value specified in the vertex format.
D3DTS_WORLDMATRIX Maps indices in the range 0 through 255 to the corresponding transform states.
Flexible Vertex Format Flags Used to describe the contents of vertices stored interleaved in a single data stream.
Texture Argument Flags Arguments that affect the color or alpha channel of the texture.
