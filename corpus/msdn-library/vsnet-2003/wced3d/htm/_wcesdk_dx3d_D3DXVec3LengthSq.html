D3DXVec3LengthSq

This function returns the square of the length of a 3-D vector.

FLOAT D3DXVec3LengthSq(
CONST D3DXVECTOR3 *pV
);

Parameters

pV
[in] Pointer to the source D3DXVECTOR3 structure.

Return Values

The vector's squared length.
