C++ Specific Features

C++ programmers can take advantage of the constructor overloading, operator overloading, and type casting extensions offered by the Direct3DX utility library. The extensions are implemented in the following structures.

Extension Description
D3DXMATRIX Extensions Supplies operator overloads and type casts for D3DXMATRIX structures.
D3DXVECTOR3 Extensions Supplies operator overloads and type casts for D3DXVECTOR3 structures.
D3DXVECTOR4 Extensions Supplies operator overloads and type casts for D3DXVECTOR4 structures.
