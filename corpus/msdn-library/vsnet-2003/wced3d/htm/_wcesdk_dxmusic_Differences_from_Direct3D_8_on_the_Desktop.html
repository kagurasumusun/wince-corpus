Differences from Direct3D 8 on the Desktop

Direct3D for Windows CE is based on the Direct3D interfaces found in DirectX 8 for Windows desktop operating systems. Although Direct3D for Windows CE provides a basic set of powerful interfaces for 3-D applications, it is a subset of the desktop version. You must consider these differences if you are faced with porting code from the desktop. These differences will also be important if you are making use of the large body of valuable Direct3D information that is not specifically written for Direct3D on Windows CE.

The following list highlights some features in Direct3D 8 for the desktop that are not supported in Direct3D for Windows CE:

  • Bump Mapping
  • Environment Mapping
  • Geometry Blending
  • Indexed Vertex Blending
  • Patches
  • Point Sprites
  • Procedural Pixel Shader
  • Procedural Vertex Shaders
  • Quaternions
  • Spotlights
  • Tweening
  • Vertex Blending
  • Visual Basic
  • Volume Textures

Direct3D for Windows CE supports a subset of the desktop Direct3DX utility library. The specific Direct3DX elements supported by Windows CE can be found in the Direct3DX Reference.

Direct3D for Windows CE has no real capability of working with multiple screens or rotated displays. For more information, see Multiple Screens and Rotated Displays.

If you are attempting to port code from the desktop, you must take into account that Direct3D for Windows CE only supports Direct3D 8 interfaces. This behavior is different from the desktop, which supports all prior Direct3D releases in every new version.
