Comparing Shading Modes

In flat shading mode, the pyramid below is displayed with a sharp edge between adjoining faces because each faces is rendered with its own uniform intensity. In Gouraud shading mode, however, intensities can be interpolated across the edgegiving the final appearance of a curved surface.

Both shading models derive intensities across a face from values at the vertices. Flat shading uses a constant value across a face, whereas Gouraud shading interpolates values across a face. When two adjacent faces have common vertex normal values on their shared vertices, Gouraud shading can smoothly interpolate intensities from one face to the other. This can produce a more realistic appearance than the hard edge breaks common to flat shading. This effect is particularly obvious if there is a nearby point source.

Gouraud shading can result in Mach bands, which are bands of color or light that are not smoothly blended across adjacent polygons. Your application can reduce the appearance of Mach bands by increasing the number of polygons in an object, increasing screen resolution, or increasing the color depth of the application.

Gouraud shading can miss some details. One example is the case shown by the following illustration, in which a spotlight is completely contained within a polygon face.

In this case, Gouraud shading would miss the spotlight altogether because the light from the spotlight does not affect any of the vertices that define the boundary conditions for the interpolation. The face would be rendered as though the spotlight did not exist.
