D3DTS_WORLD

This macro identifies the transformation matrix being set as the world transformation matrix. 

D3DTS_WORLD  D3DTS_WORLDMATRIX(0)

Parameters

None.

Remarks

This macro is provided to facilitate porting existing applications to Microsoft® DirectX® 8.0.

Requirements

Runs on Versions Declared in Link to
Windows CE OS .NET 4.0 and later D3d8types.h
