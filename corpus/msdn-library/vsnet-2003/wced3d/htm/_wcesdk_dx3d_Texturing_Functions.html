Texturing Functions

Direct3DX supplies the following texturing functions.

Function Description
D3DXCheckTextureRequirements Checks texture-creation parameters.
D3DXCreateTexture Creates an empty texture, adjusting the calling parameters as needed.
D3DXCreateTextureFromFileEx Creates a texture from a file specified by a Unicode string.
D3DXCreateTextureFromResourceEx Creates a texture from a resource specified by a Unicode string.
D3DXFilterTexture Filters the mipmap levels of a texture.
D3DXLoadSurfaceFromFileInMemory Loads a surface from a file in memory.
D3DXLoadSurfaceFromFile Loads a surface from a file specified by a Unicode string.
D3DXLoadSurfaceFromMemory Loads a surface from memory.
D3DXLoadSurfaceFromResource Loads a surface from a resource specified by a Unicode string.
D3DXLoadSurfaceFromSurface Loads a surface from another surface with color conversion.
