Direct3DX Structures

This section contains information about the structures included in the Direct3DX utility library.

Structure Description
D3DXIMAGE_INFO Contains a description of the original contents of an image file.
D3DXMATRIX Describes a matrix.
D3DXVECTOR3 Describes a vector in three-dimensional (3-D) space.
D3DXVECTOR4 Describes a vector in four-dimensional (4-D) space.
