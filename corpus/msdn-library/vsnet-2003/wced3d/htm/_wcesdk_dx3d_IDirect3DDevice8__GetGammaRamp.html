IDirect3DDevice8::GetGammaRamp

This method retrieves the gamma correction ramp for the swap chain.

void GetGammaRamp(
D3DGAMMARAMP *pRamp
);

Parameters

pRamp
[in, out] Pointer to an application-supplied D3DGAMMARAMP structure to fill with the gamma correction ramp.

Return Values

None.
