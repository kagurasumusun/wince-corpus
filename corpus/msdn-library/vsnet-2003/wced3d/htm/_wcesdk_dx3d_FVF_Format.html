FVF Format

You can specify the FVF format by passing the appropriate type when calling the IDirect3DDevice8::SetVertexShader method as shown in the following code example.

g_d3dDevice->SetVertexShader( CUSTOM_FVF );

The following topics cover FVF format types:

  • Vertex Type
  • LVertex Type
  • TLVertex Type
