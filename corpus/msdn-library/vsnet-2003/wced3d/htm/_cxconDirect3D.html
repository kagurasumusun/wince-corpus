Direct3D

This section provides information about using the Microsoft® Direct3D® application programming interfaces (APIs) for Microsoft® Windows® CE .NET.

Information on Microsoft® Direct3D® is presented in the following sections.

Introduction to Direct3D. An overview of what Direct3D is and what it can do for your application, together with a look at some key principles and necessary background information.

Understanding Direct3D. A deeper look at the underlying structure. This section will not teach you how to implement directional lighting or texture mapping in your application, but it will help you understand the mechanics of the API when you get into the details.

Using Direct3D. A guide to using the API. You will probably want to familiarize yourself with the table of contents for this section and then refer to parts of it as you need specific information. Use it in conjunction with the reference section.

Programming Tips and Tools. Miscellaneous information about compiling, debugging, and optimizing Direct3D applications. In addition, this section contains information on issues that may be encountered when using pre-DirectX 8.0 drivers.

Direct3D Tutorials. Step-by-step implementation of basic functionality. If you learn best by doing, this is a good place to start.

Direct3D Reference. Detailed information for all the API elements declared in the Microsoft Direct3D® header files.

Direct3DX Reference. Detailed information for all the API elements declared in the Direct3DX utility library header files.
