Math Functions

The math library provided by the Direct3DX utility library supplies functions to compute both basic and complicated 3-D mathematical operations.

The 3-D math application functions can be organized into the following groups.

3-D Vector D3DXVec3Add
  D3DXVec3Cross
  D3DXVec3Dot
  D3DXVec3Length
  D3DXVec3LengthSq
  D3DXVec3Normalize
  D3DXVec3Scale
  D3DXVec3Subtract
  D3DXVec3Transform
4-D Matrix D3DXMatrixfDeterminant
  D3DXMatrixIdentity
  D3DXMatrixInverse
  D3DXMatrixLookAtLH
  D3DXMatrixMultiply
  D3DXMatrixOrthoOffCenterLH
  D3DXMatrixPerspectiveFovLH
  D3DXMatrixPerspectiveOffCenterLH
  D3DXMatrixScaling
  D3DXMatrixTranslation
  D3DXMatrixTranspose
4-D Vector D3DXVec4Add
  D3DXVec4Cross
  D3DXVec4Dot
  D3DXVec4Length
  D3DXVec4LengthSq
  D3DXVec4Normalize
  D3DXVec4Scale
  D3DXVec4Subtract
  D3DXVec4Transform
Note   All the math functions can take the same object as the passed [in] and returned [out] parameters. Also, out parameters are typically returned as return values, so that the output of one math function may be used as a parameter for another math function.
