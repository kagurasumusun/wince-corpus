Microsoft Windows CE .NET  

EC_PLEASE_REOPEN

This event code indicates that the graph should be re-rendered.

Parameters

lParam1
Void.
lParam2
Void.

Remarks

This event code is sent when things have changed enough to indicate that the graph should be re-rendered. This event code does not provide any information on the root cause of the changes.

For information about how to use this event code, see CBaseFilter::NotifyEvent.
