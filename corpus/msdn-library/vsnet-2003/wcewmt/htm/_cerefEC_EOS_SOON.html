EC_EOS_SOON

This event code indicates that the source filter is about to deliver an end-of-stream (EOS) message downstream.

Parameters

lParam1
Void.
lParam2
Void.

Remarks

For information about how to use this event code, see CBaseFilter::NotifyEvent.
