IP Phone Security

Security for IP phones requires special attention because the network interface used by the phone provides an access point to the rest of the network. This access could be used remotely by an attacker.

If the security of the IP phone is compromised, it could compromise the security of the other nodes on the network.

Because IP phones are designed for use over a network, to mitigate potential security risks, you should use all appropriate network security resources.

For detailed security information about major components of the Windows CE IP phone functionality, see the following topics. You should also review the security information for any other components that your IP phone device uses.

  • TUI Security
  • VAIL Security
  • RTC Client API Security
  • Exchange Client Security
  • PC Authentication Security
  • Phone IME Security
