Developing a Target Device Without Using a Design Template

To develop a target device, you must create an OS design, build it into a run-time image, and then deploy the image to a device.

You can create an OS design without using a design template by manually selecting the necessary Catalog items from the catalog. For specific steps, see How to Develop an OS Design Without Using a Design Template.
