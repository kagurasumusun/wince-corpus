Configuring a Printer in Thin Client

To add a printer, use the printer wizard after you download the Windows Thin Client run-time image. For information about the registry settings for the installed printers, see Configured Printers in a Thin Client.

Note   You should always add a printer through the printer wizard rather than configure it in the registry. This wizard adds critical binary data to the registry that is used for the redirected printing.
