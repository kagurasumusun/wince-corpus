Common IP Phone Customization Tasks

The topics in this section discuss how to customize or replace parts of the VoIP functionality provided in Windows CE.

Each topic in this section:

  • Summarizes the objective of the customization.
  • Explains the options you have for this type of customization.
  • Recommends a definitive, preferred alternative, if one is available.
  • Provides references to specific information in the other topics to explain how to make the changes.

Unless otherwise noted, for the sake of simplicity, the information assumes that you are using the other parts of the Windows CE IP phone solution. However, you can make modifications explained in one topic independently of modifications explained in another topic.

For example, Adding or Changing SIP Headers and Verbs discusses extending or replacing the SIP stack provided by the RTC Client API Catalog item. For ease of explanation, the discussion assumes you are using the TUI and the VAIL. However, you can customize the SIP stack while not using the TUI or the VAIL.
