Adding Support for Wireless Access Point

You can customize your gateway to function as a wireless access point by adding the Wireless Access Point (802.11) Support Catalog item. You can also add the Catalog item by setting the SYSGEN_NWIFI_AP variable.

For information about creating a Gateway that functions as a wireless AP, see How to Build a Wireless Access Point Using Windows CE.
