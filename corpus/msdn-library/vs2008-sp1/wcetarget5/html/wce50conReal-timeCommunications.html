Real-time Communications

A primary piece of IP phone functionality provided by Windows CE is the Real-time Communications (RTC) Client API. In contrast to the TUI and the VAIL, RTC is not provided in source code form.

You can add RTC to a run-time image by adding the Real-time Communications (RTC) Client API Catalog item available in the Voice over IP Phone Services section of the Platform Builder Catalog. For more information about the RTC Client API Catalog item, see Real-time Communications (RTC) Client API.

RTC includes a SIP stack for call control and for additional functionality like presence tracking and instant messaging. It also includes an RTP implementation for media transport.
