Adding Environment Variables

Depending on your hardware, you may need to set some environment variables to enable support for your target device. To create a gateway, set the following environment variables to match the hardware and functionality that your target device supports.

Setting type Environment variable
Required settings PRJ_ENABLE_FSREGHIVE=1

BSP_ICS=1

BSP_NOSHAREETH=1
Hardware specific examples BSP_DISPLAY_MEDIAGX=1

BSP_NIC_RTL8139=1

BSP_NIC_RTL81392=1

BSP_PCMCIA_I82365=1
Optional settings examples BSP_NOAUDIO=1

BSP_NOUSBSER=1

BSP_USB_OHCI=1

BSP_USB_UHCI=1
