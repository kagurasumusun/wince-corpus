IP Phone Registry Settings

The Catalog items that comprise the VoIP functionality in Windows CE have registry settings that control the operation of the functionality in that Catalog item. For example, the TUI has its own set of registry settings.

The following list provides links to registry settings for these Catalog items.

  • TUI Registry Settings
  • VAIL Registry Settings
  • RTC Client API Registry Settings
  • PC Authentication Registry Settings
  • Exchange Client Registry Settings

For more information about the functionality in these Catalog items, see IP Phone Functionality in Windows CE.
