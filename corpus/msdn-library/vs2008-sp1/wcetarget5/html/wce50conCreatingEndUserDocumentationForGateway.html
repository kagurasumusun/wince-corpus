Creating End User Documentation for a Gateway

The following list shows documentation considerations for a gateway:

  • User's Guide for your device.
  • Quick Start Reference Card. Consider adding a separate, very small Quick Start Reference Card with short, to-the-point instructions for the most important user tasks, useful shortcuts, and useful but hard-to-discover features.
  • Quick Start Guide. Consider creating a Quick Start Guide to explain how to set up the device for its initial use, and how to get started using the device. For more information, see Creating a Quick Start Guide for a Gateway
