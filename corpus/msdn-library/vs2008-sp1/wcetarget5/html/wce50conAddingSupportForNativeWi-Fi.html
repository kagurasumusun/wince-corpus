Adding Support for Native Wi-Fi

You can add support for Native Wi-Fi to your Gateway OS design. Windows CE includes the following Catalog items for Native Wi-Fi support.

Catalog Item Description
Native Wi-Fi WLAN Access Point Components Provides support for Native Wi-FI WLAN access point (AP).
Native Wi-Fi WLAN STA Provides support for Native Wi-FI WLAN station (STA).

For information about creating a Gateway that functions as a wireless AP, see How to Build a Wireless Access Point Using Windows CE.

For Native Wi-Fi hardware-related information, see Gateway Hardware Requirements.
