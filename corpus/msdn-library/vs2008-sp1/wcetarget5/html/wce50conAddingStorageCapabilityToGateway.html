Adding Storage Capability to a Gateway

You can add storage capability to your Gateway OS design by selecting one of the following options in Step 5 of the New Platform Wizard, on the Gateway Extensions page.

  • File Server to enable clients to access files from a server
  • Print Server to enable clients to access printers from a server

For step-by-step instructions on creating a File Server device, see How to Configure a File Server.
