Gateway Design Template

When you create a Gateway OS design using the New Platform Wizard, a set of basic Catalog items are included in the OS design by default. Although some of the default Catalog items are optional, a set of required Catalog items is also included.

In addition to the Catalog items in the design template and those that you add after the New Platform Wizard has finished, some Catalog items are added when building the run-time image because of Catalog item dependencies.

Note   Because one Sysgen variable may be set by another Sysgen variable, not all of the Sysgen variables in these files directly correspond to a Catalog item in the catalog.

For information about how to view a list of Sysgen variables, see Build Demo Tool.
