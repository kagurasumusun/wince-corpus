Developing IP Phone End User Documentation

User documentation is a key part of a user's initial and continued experience with an IP phone. Windows CE includes user documentation templates specifically designed for an IP phone device. You can extend and use this user documentation for your specific device.

For detailed information, see Creating End User Documentation for an IP Phone.
