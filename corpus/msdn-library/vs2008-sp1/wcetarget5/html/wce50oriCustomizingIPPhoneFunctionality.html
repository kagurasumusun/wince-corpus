Customizing IP Phone Functionality

This section explains how you can customize the IP phone modules and components provided with Windows CE.

In This Section

Customizing TUI
Discusses how the TUI can be modified to have a different appearance, use included functionality differently, or use custom functionality. Also discusses how the TUI can be replaced entirely.
Customizing Non-UI IP Phone Functionality
Discusses how the underlying functionality used by the TUI, like the VAIL and Exchange integration, can be customized.
Customizing RTC
Discusses how the core multimedia communications functionality provided by the Real-time Communications (RTC) Client API can be modified or replaced entirely.
