Debugging and Testing an IP Phone

The following information can be useful when debugging and testing an IP phone that uses Windows CE. (For general information about testing and debugging, see Strategies for Debugging a Run-Time Image, Tools for Debugging and Testing, and Debugging Reference.)

  • The Telephony User Interface (TUI) defines a set of debug zones you can use to output debugging information for different parts of the TUI application. For more information, see Debugging Using TUI Debug Zones.
  • The Windows CE Test Kit (CETK) includes a set of automatable tests that validate correct operation of much of the Windows CE IP phone functionality, including making and receiving calls, provisioning, and Exchange integration. For general CETK information, see Windows CE Test Kit.
  • You can manually verify correct compilation and operation of a default IP phone run-time image, including making and receiving phone calls, by following the instructions in How to Create a Default IP Phone on a CEPC and How to Create a Default IP Phone on an Emulator.
