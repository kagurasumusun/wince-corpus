Configuring Filtered File Storage Redirection

File storage redirection allows you to view and manage folders on your local drives in a remote session. If file storage redirection is enabled, you can use filtered file storage redirection to specify the directories that are available within the RDP session. File storage redirection works by using an internal virtual channel.

Specify the root of the file system to which the redirection filter applies in the HKEY_LOCAL_MACHINE\System\StorageManager\AutoLoad\FilterFsd registry key. The following table shows the named values.

Value Description
RootPath The root of the file system to which the redirection filter applies

For more information about drive redirection, see RDP Registry Settings.
