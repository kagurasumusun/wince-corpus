IP Phone Samples

Windows CE includes Catalog items that contain applications and samples that demonstrate how to use different parts of the VoIP functionality in Windows CE.

Telephony User Interface (TUI) Catalog Item

The TUI is the primary example of an application that uses the VoIP functionality included in Windows CE.

The TUI is a full-featured, tested application that includes the source code. You can use it to learn how to access VoIP functionality in your code, and as a base for your own IP phone designs.

For more information about the TUI Catalog item, see Telephony User Interface (TUI) and TUI Samples. You can also read about how the TUI demonstrates Windows CE VoIP functionality in VAIL Samples, PC Authentication Samples, and Exchange Client Samples.

For information about learning and customizing the TUI, see Telephony User Interface Functionality and Customizing TUI.

RTC Client API Catalog Item

The RTC Client API Catalog item contains the VoIPdemo application, which demonstrates how to use the RTC client API for instant messaging and voice telephony.

The VoIPdemo application does not use the dedicated VoIP functionality — such as the TUI or the VAIL — included with Windows CE.

For more information about this sample, see RTC Client API Samples.
