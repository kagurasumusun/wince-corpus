Gateway Samples

Windows CE includes a sample Gateway user interface (UI). This sample UI is located in the %_WINCEROOT%\public\servers\oak\gwadmin directory. For more information, see Customizing the Template Gateway User Interface.

Windows CE also includes samples for most of the technologies that are used by the Gateway or may be relevant for your Gateway OS design. For sample-related information about the technologies that are specific to the Gateway, see the following topics:

  • Network Bridging Samples
  • File Server Samples
  • IP Firewall Samples
  • Parental Controls Samples
  • Reference Gateway User Interface Samples
  • Remote Configuration Framework Samples
  • SNTP Samples
  • UPnP Internet Gateway Device Schema Sample
  • USB Flash Config Tool Samples
  • Web Proxy Samples
  • Web Server Samples
