Adding Support for USB Flash Config Tool

You can add support for Windows Connect Now by adding the Windows Connect Now Catalog item to your OS design. You can also add the Catalog item setting the SYSGEN_SRV_USB_FLASH_CONFIG variable. For more information, see USB Flash Config Tool.
