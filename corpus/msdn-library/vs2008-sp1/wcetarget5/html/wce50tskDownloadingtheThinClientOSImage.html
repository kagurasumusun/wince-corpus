Downloading a Run-Time Image to a CEPC

After you customize the OS design and then build the run-time image, you are ready to download the run-time image to your device. In this example, you will download the image to a CEPC.

To download a run-time image to the CEPC

  1. If you have not previously created a boot floppy disk for the CEPC, do so now. For more information, see Creating a Boot Floppy Disk for an x86 SDB.
  2. Insert the boot floppy disk into drive A of the CEPC target device.
  3. From the Target menu, select Attach Device.

    The Download Runtime Image to CE Device dialog box appears. Perform one of the following tasks:

    • If the image downloads, UI appears on the CEPC. Proceed with the next step.
    • If the status bar in this dialog box does not show download progress within a few minutes, restart the CEPC. After the image is downloaded, UI appears on the CEPC.
  4. If a setup wizard appears, follow the instructions in the wizard.

    You are now ready to test the run-time image.
