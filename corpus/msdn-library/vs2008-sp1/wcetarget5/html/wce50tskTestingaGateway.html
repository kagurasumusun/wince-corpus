Setting up a Gateway from a Remote Connection

If you have a proxy server on the public side of the gateway, you may need to turn off the proxy server to connect to the gateway and browse the Remote Configuration pages. For more information, see Bypassing the Proxy Server.

To verify the names of the network interfaces on the target device and the IP addresses, type s ipconfig /d /all in the Target Control window of Platform Builder. The Debug output window displays the IP address of the target device, and the interface or adapter names.

The VMINI1 adapter allows a shared connection between the target device and the debugger. During development, this allows you to use a two-only adapter for your gateway and debugging. The VMINI1 adapter is the public interface.

To set up your gateway from a remote computer

  1. Connect a network hub to the private network interface card, and then connect one or more computers to the hub.

    The public network interface card must be connected to your development workstation and the workstation must be connected to the Internet or a WAN. The VMINI1 adapter serves both as a debugging interface and as a WAN interface.

  2. From a client computer on the private network, use a browser to access the Internet.
  3. To launch the gateway user interface, on your client computer, in the address bar of the browser, type http://<gateway IP address>, and then press ENTER.

    For example, if you have configured your Gateway to use the static IP address of 192.168.0.1, type http://192.168.0.1 in the address bar of your browser.

    The Windows CE Remote Management Tool appears.

  4. On the Welcome page, choose Next.
  5. On the Set the password for your Gateway page, type a password, confirm the password, and then choose Next.
  6. On the Configure your Internet connection page, choose the I do not want to set up an Internet connection now option, and then choose Finish. The gateway will reset.

    After the gateway has finished resetting, the Enter Network Password dialog box appears.

  7. In the Enter Network Password dialog box, enter the following information, and then choose OK.
    Item Text to be entered
    User Name admin
    Password <the password you created in Step 5>
    Domain None
  8. You can now select one of the gateway configuration options on the left column, such as Parental Controls, and configure your gateway.
