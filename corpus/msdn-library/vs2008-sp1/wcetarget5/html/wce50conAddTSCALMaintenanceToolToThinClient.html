Adding the TS CAL Maintenance Tool to the Thin Client

Remote Desktop Protocol (RDP) adds the Terminal Services Client Access License (TS CAL) maintenance tool to the Thin Client Shell Control Panel. This tool is used to read and manage TS CAL tokens for devices that connect to a Terminal Server. This tool provides an easy method of managing TS CALs, but does not replace the need to purchase them by using the appropriate sales channels. TS-CAL tokens are electronic representations of real licenses, but they are not actual licenses.

This tool is provided in public code in the following location: %_WINCEROOT%\Public\Rdp\Oak\Uit\licinfo.cpp.

The tool can be used as-is, or you can use it as a template and design your own user interface (UI) for presenting license information. If you design your own UI, you must link your code to the helper library, licinfo.lib, in the same manner as the TS CAL maintenance tool does.

For more information about this tool, see TS CAL Maintenance Tool.

For information about how to create or modify a Control Panel application, see How to Implement a Control Panel Application.
