Testing an Internet connection from a CEPC

You can test an application or a device in an IPv6 environment before you deploy it in a production environment.

To test an Internet connection using your new run-time image

  1. When the shell appears on the CEPC, from the Start menu choose Settings, and then choose Control Panel.
  2. From Control Panel, choose Internet Options.
  3. From Internet Settings, choose the Connection tab.
  4. Select Use LAN.
  5. If you are using a proxy server, select Access the Internet using a proxy server, and type the proxy address and port number into their respective fields.
  6. To close the Internet Options and return to the Windows CE desktop, click OK.
  7. Double-click the Internet Explorer icon and type a known URL, for example, www.microsoft.com, into the Address field.

    If the expected Web site does not appear, check your proxy settings and try again. For more information, see Troubleshooting: Cannot Connect from a CEPC to a Network After Configuring the CEPC.
