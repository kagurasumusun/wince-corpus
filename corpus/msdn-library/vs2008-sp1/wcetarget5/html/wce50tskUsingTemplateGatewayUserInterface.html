Customizing the Template Gateway User Interface

The Gateway design template includes a template gateway user interface (UI). that is designed for use by end users of the gateway. OEMs can further customize the template UI to include branding and other hardware specific functionalities.

For a detailed list of all the HTML pages that are included in the Gateway design template, see Gateway User Interface Overview.

OEMs can customize the application using the HTML template and cascading style sheet-based pages.

The following list shows the customization tasks that must be accomplished prior to shipping the UI:

  • Add OEM branding to all HTML pages.
  • Include a product registration page in the Setup Wizard.
  • Provide a hardware reset button for the target device that restores the factory settings.
  • Configure the gateway options to match the hardware capability. For example, you can add a firewall or wireless capability to the gateway.
  • Update the Quick Start guide template based on selected hardware and branding. For more information see Creating a Quick Start Guide for a Gateway.
  • Provide a user's guide that explains how to use the configuration utility.

The following list shows the optional customization tasks that OEMs can do prior to shipping the UI:

  • Provide context sensitive help.
  • Allow third-party providers to use the output messages from the firewall for an intrusion-detection application.
  • Add menu items and links to additional products and services included with the gateway target device.
  • Modify the setup wizard for guided installation of key functionality.
