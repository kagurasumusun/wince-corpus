Migrating an IP Phone

The IP phone support in Windows CE 5.0 has been greatly expanded from the IP phone support in Windows CE 4.2.

A user interacting with the Telephony User Interface (TUI) will notice a significant amount of additional functionality — like Exchange integration and call conferencing — and a more refined user interface. For detailed information about migrating an OS design that used the Windows CE .NET 4.2 TUI to the TUI included with Windows CE 5.0, see TUI Migration.

The VoIP Application Interface Layer (VAIL) and Real-time Communications (RTC) functionality used by the TUI has also seen significant changes. For more information, see VAIL Migration and RTC Client API Migration.
