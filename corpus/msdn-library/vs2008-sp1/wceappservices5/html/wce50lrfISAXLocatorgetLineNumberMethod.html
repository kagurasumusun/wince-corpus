ISAXLocator::getLineNumber Method

This method returns the line number where the current document event ends.

HRESULT getLineNumber(
  int* pnLine
);

Parameters

pnLine
[out, retval] Pointer to the line number. The value is –1 if the Locator object is not associated with some source input or a position within the source input.

Return Values

S_OK
Returned if line number returned successfully.

Remarks

This number is the line position of the first character after the text associated with the document event. This method is permitted to show position within the text associated with the text event.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
Link Library: Uuid.lib.
