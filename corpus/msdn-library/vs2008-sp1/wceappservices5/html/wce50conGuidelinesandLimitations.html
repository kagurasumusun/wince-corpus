SOAP Guidelines and Limitations

Windows CE includes the following usage guidelines and limitations for SOAP Toolkit support:

  • The WSDL implementation in the SOAP Toolkit is WSDL 1.1 Specification-compliant.
  • The following are suggestions and hints for creating COM objects to be used with this implementation of SOAP.
    • Optional parameters are not supported in interfaces mapped to SOAP. Values must be provided for all defined parameters.
    • Although the SOAP Toolkit high-level interfaces use normal COM calls to expose objects through SOAP, the SOAP Toolkit is not a general replacement for DCOM.

      Much of the DCOM functionality, like lifetime-management, passing objects by reference, and some COM data types, does not map to the current SOAP specification.

      This DCOM functionality is not supported by the SOAP Toolkit and probably never will be.

      Although the SOAP Toolkit might allow you to expose existing COM objects through SOAP, this is not true in all cases.

      Wrapper objects and possibly custom mappers might be required to expose some existing objects.

      Although the SOAP Toolkit continues to support more DCOM-like functionality, the support will never be complete.

  • In this release, custom type mappers do not support user defined data types (VT_RECORD).
