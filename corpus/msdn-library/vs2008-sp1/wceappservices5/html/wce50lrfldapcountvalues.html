ldap_count_values

This function counts the number of values in a list.

ULONG ldap_count_values(
  UNICODE PTCHAR* vals
);

Parameters

vals
[in] Array of values returned by ldap_get_values.

Return Values

If this function succeeds, it returns the number of values.

If this function fails, the return value is 0.

Remarks

This function returns the number of values in an array of strings. To count binary values (in an array of berval structures) call the ldap_count_values_len function.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winldap.h.
Link Library: Wldap32.lib.
