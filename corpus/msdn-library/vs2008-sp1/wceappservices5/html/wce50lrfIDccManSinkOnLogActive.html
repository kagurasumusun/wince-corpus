IDccManSink::OnLogActive

This method indicates that a connection is established between the client application and Connection Manager.

STDMETHODIMP IDccManSink::OnLogActive(void);

Parameters

None.

Return Values

This method should always return NOERROR.

Remarks

The IDccManSink::OnLogActive method is implemented by a client application and is called when a socket connection is established between the client application and Connection Manager.

When this notification occurs, Connection Manager starts any applications that are registered with the registry key HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\AutoStartOnConnect.

During this notification is a good time for the client application to initialize the remote application programming interface (RAPI) by calling the RAPI function CeRapiInit. A call to CeRapiInit does not return until a connection is established between the desktop computer and the target device.

To determine whether the platform supports this interface, see Determining Supported COM APIs.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Dccole.h.
Link Library: Ole32.lib, Uuid.lib.
