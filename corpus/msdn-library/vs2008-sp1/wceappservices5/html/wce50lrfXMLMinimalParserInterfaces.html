XML Minimal Parser Interfaces

The following table shows the XML minimal parser interfaces, with a description of the purpose of each.

Programming element Description
ISAXAttributes:IUnknown This interface allows access to a list of attributes by attribute index, namespace-qualified name, and qualified (prefixed) name.
ISAXContentHandler:IUnknown This interface receives notification of the logical content of a document.
ISAXXMLReader:IUnknown The XML Minimal Parser provides two co-classes that implement the XML Reader interface.
