IExceptions:IUnknown

This interface provides a read-only collection of exceptions to a recurring appointment. You can get this collection, valid only for appointments, from the Exceptions property in the IRecurrencePattern interface. Add or edit exceptions with the GetOccurrence method in the IRecurrencePattern interface. This interface supports one method.

Methods in Vtable Order

Method Description
Item Gets an exception from the collection of exceptions.
