ISAXLexicalHandler::endCDATA Method

This method receives the end of a character data (CDATA) section. The contents of the CDATA section are reported through the characters event. The endCDATA event reports only the end boundary of the CDATA section.

HRESULT endCDATA();

Parameters

None.

Return Values

S_OK
Returned if no errors occur.
E_FAIL
Returned if the parse operation should be aborted.

Remarks

A CDATA section provides a way to include characters such as "<", ">", and "&" in an XML document that would typically interfere with processing. The following code sample shows a CDATA section.

<![CDATA[text goes here]]>.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
Link Library: Uuid.lib.
