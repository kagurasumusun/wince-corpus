IMXReaderControl:IDispatch

The IMXReaderControl interface provides limited control of reader behavior. Specifically, it allows a Simple API for XML (SAX2) application to abort, suspend, or resume parsing.

This interface is not standard. If you use this feature, you may not be able to migrate your program logic to other SAX implementations. This interface is targeted to applications that require a low-level parser API.

The following table shows the methods for this interface.

Method Description
abort This method stops the parsing operation.
resume This method resumes parsing after the reader has been suspended.
suspend This method suspends parsing and returns control to the application.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
Link Library: Uuid.lib.
