ISAXXMLReader::putContentHandler Method

This method allows an application to register a content handler.

HRESULT putContentHandler(
  ISAXContentHandler* pHandler
);

Parameters

pHandler
[in] Pointer to the content handler to register.

Return Values

S_OK
Returned if the content handler is successfully registered.

Remarks

If the application does not register a content handler, all content events reported by the reader will be ignored. An application can register a new or different handler while in the middle of parsing a document, and the reader will immediately start using the new handler.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
Link Library: Uuid.lib.
