About the WSDL/WSML Generator

To generate WSDL and WSML files from COM interfaces and objects, you can run wsdlstb_ce.exe using the command line from the desktop computer.

This utility generates the WSDL and WSML files using parameters you provide. You can find this utility in %_WINCEROOT%\Public\Common\OAK\Bin\i386.

The following code example shows the syntax.

wsdlstb_ce [-U] [-P{CLSID}PROGID] [-I Interfacename] [-I Interfacename::method1,method2...] COMObjectPath ASPListenerURI WSDLFilePath

The following are required parameters:

  • PROGID, interface
  • COM object path
  • ASP listener
  • WSDL file path

The following code example illustrates the usage.

wsdlstb_ce -P {699815E5-6F9E-403B-8C35-53476BABA89E} -I ISoapReader -I ISoapSerializer -I WSDLReader:Load,ParseRequest c:\SoapSDK\mssoap1.dll http://localhost/mssoapinterface.wsdl c:\soapsdk\mssoapinterface.wsdl

You can also call wsdlstb_ce without parameters, but you are prompted to enter the required parameters.

The following table describes the parameters.

Parameter Descriptions
-U Creates WSDL file in Unicode (utf-16). Default is utf-8.
-P Specifies the PROGID for a CLSID. The {} are part of the syntax.
-I Specifies the interfaces you want to include in the WSDL file.

If you use -I without an interface name argument, all SOAP interfaces are included.

If you specify only the interface name, all methods for the interface are included. You can also specify the interface name and only specific methods.

The following example shows the format for specifying methods for a given interface.

-I Interfacename:method1,method2,method3
COMObjectPath Specifies the path to the file containing the COM Object.
ASPListener Specifies the URI path to the listener file.
WSDLFilePath Specifies the path to the WSDL file to generate.
schemaVersion Specifies the schema version to generate. The default generates version 2001. You can specify 1999, 2000, or 2001.
