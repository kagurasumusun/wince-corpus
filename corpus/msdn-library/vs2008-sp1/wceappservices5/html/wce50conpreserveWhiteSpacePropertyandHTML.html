preserveWhiteSpace Property and HTML

If you have HTML presented as well-formed XML, the preserveWhiteSpace property should have no impact on the Web page displayed in the browser. HTML browsers automatically remove excess white space upon display unless it is contained in <pre></pre> (preserve) or <xmp></xmp> (example) tags.

In this implementation of the Microsoft XML Parser (MSXML) for Windows CE, if preserveWhiteSpace is set or defaulted to FALSE, XSLT white space will have no effect. In addition, for Microsoft Internet Explorer for Windows CE, the XML parser is set to ignore unnecessary white space from XSLT transformations. (In other words, preserveWhiteSpace is set to FALSE). To see these results, you must first transform the output through an Active Server Page (ASP) or Microsoft JScript® script or a similar mechanism; you cannot rely on XSLT alone to see the result of most of the white space options.
