varType Method

This method returns the expected variant type.

HRESULT varType(
  long* pvtType
);

Parameters

pvtType
[out] Pointer to the variant type expected by the write method and returned by the read method.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mssoap.h.
Link Library: Uuid.lib.
