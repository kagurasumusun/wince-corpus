Platform Builder for Microsoft Windows CE 5.0  

No Inspector or Explorer Object

There is no rich way to view items in POOM. The only way a user can view an item is through the Display method, which is limited compared to the desktop.

You can only display an unmodified item. To display a modified item, you have to release and reload it.
