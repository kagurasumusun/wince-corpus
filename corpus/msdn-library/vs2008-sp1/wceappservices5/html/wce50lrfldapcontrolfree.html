ldap_control_free

This function frees an LDAPControl structure.

ULONG ldap_control_free(
  LDAPControl* Control
);

Parameters

Control
[in] LDAPControl structure to free.

Return Values

If this function succeeds, the return value is LDAP_SUCCESS.

If this function fails, it returns an error code. See the LDAP_RETCODE enumeration for a list of possible return values.

Remarks

Use this function to dispose of a previously allocated LDAPControl structure.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winldap.h.
Link Library: Wldap32.lib.
