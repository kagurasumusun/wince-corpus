LDAP_TIMEVAL

This structure is used to represent an interval of time.

typedef struct l_timeval {
  LONG tv_sec;
  LONG tv_usec;
} LDAP_TIMEVAL, * PLDAP_TIMEVAL;

Members

tv_sec
Seconds component of time interval.
tv_usec
Microseconds component of time interval.

Remarks

Clients use this structure to specify a local timeout; that is, how long to wait for the server to complete a search operation.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winldap.h.
