.NET Compact Framework

The Microsoft® .NET Compact Framework is a hardware-independent program execution environment for applications that target resource-constrained computing devices.

In This Section

.NET Compact Framework OS Design Development
Provides information that is helpful when designing and developing a Windows CE OS design that uses .NET Compact Framework Catalog items. This includes dependencies of the .NET Compact Framework, the modules and components that implement the .NET Compact Framework, and .NET Compact Framework Sysgen variables.
.NET Compact Framework Migration
Provides information that is useful if you are migrating from an OS design that includes .NET Compact Framework Catalog items and is based on an earlier version of Windows CE.
