ICreateTypeInfo::SetVarHelpContext

This method sets the Help context identifier for a variable. 

HRESULT SetVarHelpContext( 
  unsigned int index, 
  unsigned long dwHelpContext
);

Parameters

index
[in] Index of the variable described by the type description.
dwHelpContext
[in] Specifies the handle to the Help context identifier for the Help topic on the variable.

Return Values

The following table shows the return values for this function.

Value Description
S_OK Success.
STG_E_INSUFFICIENTMEMORY Out of memory.
E_OUTOFMEMORY Out of memory.
E_ACCESSDENIED Cannot write to the destination.
TYPE_E_ELEMENTNOTFOUND The element cannot be found.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Oaidl.h, Oaidl.idl.
Link Library: Oleaut32.lib, Uuid.lib.
