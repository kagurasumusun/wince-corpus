IXTLRuntime

Part of the Extensible Stylesheet Language (XSL) implementation. Implements the following methods, which can be called from within XSL Transformations (XSLT) style sheets:

  • absoluteChildNumber
  • ancestorChildNumber
  • childNumber
  • depth
  • formatDate
  • formatIndex
  • formatNumber
  • formatTime
  • uniqueID

This interface inherits from IXMLDOMNode. For more information, see XSLT Reference.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
Link Library: Uuid.lib.
