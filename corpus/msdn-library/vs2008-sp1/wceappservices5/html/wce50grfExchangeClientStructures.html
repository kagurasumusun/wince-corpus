Exchange Client Structures

The following table shows the Exchange Client structures with a description of the purpose of each.

Programming element Description
ContactsSearchCriteria This structure contains criteria for queries for contact information.
FreeBusyCriteria This structure contains criteria for queries for free/busy information.
GALSearchCriteria This structure contains criteria for queries for global address list (GAL) information.
