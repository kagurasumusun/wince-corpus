ISpCFGInterpreterSite

This interface sets properties and text replacements in a phrase. It is used by rule interpreters, such as objects implementing ISpCFGInterpreter.

Methods

The following table shows the methods for the ISpCFGInterpreterSite interface.

Method Description
AddProperty Adds one text replacement to the phrase.
AddTextReplacement Adds a property entry to the phrase object.
GetResourceValue Gets the resource information for a grammar.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Sapiddk.h, Sapiddk.idl.
Link Library: Sapilib.lib.
