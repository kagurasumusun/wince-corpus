This topic contains migration information that is specific to XML DOM.

For general migration information, see Migrating from an Earlier Version of Windows CE.

Migrating from Windows CE .NET 4.2 to Windows CE 5.0

MSXML error strings were automatically included in the run-time image in Windows CE .NET 4.2.

However, in Windows CE 5.0, you should explicitly include the XML Error Strings catalog item in your OS design if you want errror strings in your run-time image.
