ISAXXMLFilter::putParent Method

This method sets the parent of the filter to an instance of ISAXXMLReader.

HRESULT putParent(
  ISAXXMLReader* pReader
);

Parameters

pReader
[in] Pointer to the instance of the ISAXXMLReader to use as the parent.

Return Values

S_OK
Returned when the instance of ISAXXMLReader is set as expected.

Remarks

This method allows the application to link the filter to a parent reader (which may be another filter). The argument may not be NULL.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
Link Library: Uuid.lib.
