IPOutlookApp::Logoff

This method logs the user off of an Pocket Outlook session. It should be the last method called for a POOM object.

HRESULT Logoff ();

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Pimstore.h.
Link Library: Pimstore.lib.
