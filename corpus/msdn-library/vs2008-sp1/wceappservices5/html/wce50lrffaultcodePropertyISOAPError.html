faultcode Property (ISOAPError)

This read-only property provides the value of the <faultcode> element for the SOAP <Fault> element.

HRESULT get_faultcode( 
  BSTR* bstrFaultcode
);

Parameters

bstrFaultcode
[out] SOAP-defined fault code.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.

Remarks

The <faultcode> element contains the value of the faultcode property with a namespace prefix that identifies the namespace URI returned by the faultcodeNS property. For example, if the faultcode property returns "Code" and the faultcodeNS property returns "http://tempuri.org/Code", the <faultcode> element is similar to the following.

<faultcode xmlns:SOAPSDK3='http://tempuri.org/Code'>
  SOAPSDK3:Code
</faultcode>

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mssoap.h.
Link Library: Uuid.lib.
