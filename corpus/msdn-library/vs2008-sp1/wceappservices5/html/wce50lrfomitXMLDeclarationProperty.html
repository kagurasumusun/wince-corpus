omitXMLDeclaration Property

This property forces the MXXMLWriter to skip the XML declaration. It can be used to output fragments of larger XML documents that can be assembled into a single XML document later.

[propput]
HRESULT omitXMLDeclaration(
[in] VARIANT_BOOL fValue
);
[propget]
HRESULT omitXMLDeclaration(
[out, retval] VARIANT_BOOL* fValue
);

Parameters

fValue
Boolean expression (TRUE/FALSE) specifying whether the feature is on or off, as shown in the following table.
Value Description
TRUE Omit XML declaration.
FALSE (default) Provide XML declaration.

Return Values

S_OK
Returned if no errors are reported.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
