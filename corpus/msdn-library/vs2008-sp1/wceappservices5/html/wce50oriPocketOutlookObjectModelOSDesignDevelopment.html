Pocket Outlook Object Model OS Design Development

The following tables provide an overview of the modules and components that implement Microsoft Pocket Outlook Object Model (POOM), and the sysgen variables that enable this functionality.

OS Design Information

The following table shows operating system design information for POOM.

Concept Description
Dependencies The POOM Catalog item includes the data stores for appointments, contacts, tasks, and addresses and the application programming interface (API) needed to access and manipulate these stores.
Hardware considerations None.

Modules and Components

The following table shows the components and modules that implement the POOM.

Item Module Component
Pocket Outlook Object Model addrstor, calnot, calstore, citydb, pimres, pimstore, pimutil None
Supplemental Pocket Outlook Object Model modules labledit, msgstore, tnefex, tnefu, tnefutil, uicom None

Pocket Outlook Object Model Implementation Considerations

The following Sysgen variables control the POOM.

Sysgen variable Description
SYSGEN_POOM Setting this flag brings in the related data stores and the API modules.
