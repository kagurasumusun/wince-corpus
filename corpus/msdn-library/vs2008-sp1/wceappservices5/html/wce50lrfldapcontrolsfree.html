ldap_controls_free

This function frees an array of LDAPControl structures.

ULONG ldap_controls_free(
  LDAPControl** Controls
);

Parameters

Controls
[in] Array of LDAPControl structures to free.

Return Values

If this function succeeds, the return value is LDAP_SUCCESS.

If this function fails, it returns an error code. See the LDAP_RETCODE enumeration for a list of possible return values.

Remarks

Use this function to dispose of a previously allocated array of LDAPControl structures.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winldap.h.
Link Library: Wldap32.lib.
