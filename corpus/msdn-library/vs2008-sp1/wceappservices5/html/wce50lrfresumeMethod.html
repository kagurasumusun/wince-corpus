resume Method

This method resumes parsing after the reader has been suspended with the suspend method.

HRESULT resume( );

Parameters

None.

Return Values

The following table shows the return codes for the resume method based on the state of the reader.

State Return code
Ready E_FAIL. Resume executes, but the reader remains in the ready state.
Parsing E_FAIL. Resume executes, but the reader continues to parse.
Suspended The return code is defined by the parse/resume methods or handler. After resume executes, the reader starts parsing.

Remarks

The resume method must be called from outside a handler call.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
Link Library: Uuid.lib.
