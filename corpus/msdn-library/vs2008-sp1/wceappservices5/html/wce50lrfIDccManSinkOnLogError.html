IDccManSink::OnLogError

This method indicates that Connection Manager failed to start communications between the desktop computer and the target device.

STDMETHODIMP IDccManSink::OnLogError(void);

Parameters

None.

Return Values

This method should always return NOERROR.

Remarks

The IDccManSink::OnLogError method is implemented by a client application and is called if Connection Manager failed to start the Remote Access Service (RAS) communications between the desktop computer and the target device.

OnLogError may also be called whenever a general Connection Manager-related error occurs. For example, OnLogError is called if the communications port — selected in the Communications settings of Connection Manager Communications Properties — is already in use or is not available.

To determine whether the platform supports this interface, see Determining Supported COM APIs.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Dccole.h.
Link Library: Ole32.lib, Uuid.lib.
