DVEXTENTINFO

This structure is used to provide sizing hints from the container for the object to use as the user resizes it.

typedef struct tagDVEXTENTINFO{
  ULONG cb;
  DWORD dwExtentMode;
  SIZEL sizelProposed;
} DVEXTENTINFO;

Members

cb
Size of the structure, in bytes. The size includes this member as well as the dwExtentMode and sizelProposed members.
dwExtentMode
Indicates whether the sizing mode is content or integral sizing.
sizelProposed
Specifies the proposed size in content sizing or the preferred size in integral sizing.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Ocidl.h.
