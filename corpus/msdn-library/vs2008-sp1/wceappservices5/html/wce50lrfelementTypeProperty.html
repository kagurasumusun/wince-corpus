elementType Property

This property specifies the value of the type attribute for the message part in the Web Services Description Language (WSDL) file.

HRESULT get_elementType(
  BSTR* pbstrElementType
);

Parameters

pbstrElementType
[out] Data type of the message part.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mssoap.h.
Link Library: Uuid.lib.
