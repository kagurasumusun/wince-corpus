IErrorInfo

This interface provides detailed contextual error information for applications that receive rich information.

Methods

The following table shows the methods for this interface in the order that the compiler calls the methods. Like all COM interfaces, this interface inherits the methods for the IUnknown interface.

Method Description
IErrorInfo::GetGUID This method returns the globally unique identifier (GUID) of the interface that defined the error.
IErrorInfo::GetSource This method returns the language-dependent programmatic identifier for the class or application that raised the error.
IErrorInfo::GetDescription This method returns a textual description of the error.
IErrorInfo::GetHelpFile This method returns the path of the Help file that describes the error.
IErrorInfo::GetHelpContext This method returns the Help context identifier for the error.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Oaidl.h, Oaidl.idl.
Link Library: Oleaut32.lib, Uuid.lib.
