ISAXAttributes::getLocalName Method

This method finds an attribute's local name by index. For xmlns, this value is empty.

HRESULT getLocalName(
  int nIndex, 
  const wchar_t** ppwchLocalName, 
  int* pcchLocalName
);

Parameters

nIndex
[in] Attribute's index value.
ppwchLocalName
[out] Pointer to the pointer to the attribute's local name.
pcchLocalName
[out] Pointer to the length of the local name string.

Return Values

S_OK
Returned if the local name is returned successfully.
E_FAIL
Returned if an internal error occurs.
E_INVALIDARG
Returned if the local name cannot be found.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
Link Library: Uuid.lib.
