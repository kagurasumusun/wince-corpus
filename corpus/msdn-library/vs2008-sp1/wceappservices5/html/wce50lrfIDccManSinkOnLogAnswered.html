IDccManSink::OnLogAnswered

This method indicates that Connection Manager has detected the communications interface. 

STDMETHODIMP IDccManSink::OnLogAnswered(void);

Parameters

None.

Return Values

This method should always return NOERROR.

Remarks

The IDccManSink::OnLogAnswered method is implemented by a client application and is called when Connection Manager has detected the presence of the communications interface.

To determine whether the platform supports this interface, see Determining Supported COM APIs.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Dccole.h.
Link Library: Ole32.lib, Uuid.lib.
