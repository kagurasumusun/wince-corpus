reset Method

This method resets the SoapSerializer object (accessed using the ISoapSerializer interface) to its initial state. You have to call reset between messages.

HRESULT reset(void);

Parameters

None.

Return Values

The following table describes the common return values.

Value Description
S_OK Success.
E_NOTIMPL The function contains no implementation.
E_OUTOFMEMORY Out of memory.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mssoap.h.
Link Library: Uuid.lib.
