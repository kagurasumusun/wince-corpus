ldap_value_free_len

This function frees berval structures that were returned by a call to the ldap_get_values_len function.

ULONG ldap_value_free_len(
  struct berval** vals
);

Parameters

vals
[in] Structure to free.

Return Values

If this function succeeds, the return value is LDAP_SUCCESS.

If this function fails, it returns an error code. See the LDAP_RETCODE enumeration for a list of possible return values.

Remarks

Call this function to free berval structures returned by ldap_get_values_len.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winldap.h.
Link Library: Wldap32.lib.
