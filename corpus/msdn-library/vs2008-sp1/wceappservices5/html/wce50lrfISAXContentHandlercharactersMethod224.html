ISAXContentHandler::characters Method

This method receives notification of character data. 

HRESULT characters(
  const wchar_t* pwchChars,
  int cchChars
);

Parameters

pwchChars
[in] Pointer to the character data.
cchChars
[in] Length of the character string.

Return Values

S_OK
Returned if the character data is returned successfully.
E_FAIL
Returned if an internal error occurs.

Remarks

The reader calls the characters method to report each chunk of character data. The reader can return all contiguous character data in a single chunk or split it into several chunks. All characters in a single event, however, must come from the same external entity so that the Locator object can provide useful information. The application must not attempt to read from the array outside the specified range.

The characters method does not convert carriage-return line feed ("\r\n") to the Java language line feed('\n').

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
Link Library: Uuid.lib.
