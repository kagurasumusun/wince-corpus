IDccManSink::OnLogIpAddr

This method indicates that an Internet Protocol (IP) address has been established for communication between the desktop computer and the target device.

STDMETHODIMP IDccManSink::OnLogIpAddr( 
  DWORD dwIpAddr
);

Parameters

dwIpAddr
Specifies the IP address of the target device.

Return Values

This method should always return NOERROR.

Remarks

The IDccManSink::OnLogIpAddr method is implemented by a client application and is called when Connection Manager has determined what IP address is used to connect to the target device. At this point, the connection is completely established.

To determine whether the platform supports this interface, see Determining Supported COM APIs.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Dccole.h.
Link Library: Ole32.lib, Uuid.lib.
