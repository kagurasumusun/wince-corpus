ISAXXMLReader::putErrorHandler Method

This method allows an application to register an error handler. 

HRESULT putErrorHandler(
  ISAXErrorHandler* pHandler
);

Parameters

pHandler
[in] Pointer to the error handler to use.

Return Values

S_OK
Returned if the error handler is successfully registered.

Remarks

If the application does not register an error handler, all error events reported by the reader are ignored. It is strongly recommended that all SAX2 (Simple API for XML) applications implement an error handler to avoid unexpected bugs. An application can register a new or different handler while in the middle of parsing a document, and the reader will immediately start using the new handler.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msxml2.h, Msxml2.idl.
Link Library: Uuid.lib.
