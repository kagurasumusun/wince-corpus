9/7/2007

This macro marks the end of the prolog area.

Syntax

PROLOG_END

Parameters

None.

Return Values

None.

Remarks

This macro must appear following a NESTED_ENTRY (ARM) or LEAF_ENTRY (ARM) macro.

It appears after the prolog area and before the matching ENTRY_END (ARM) macro.
