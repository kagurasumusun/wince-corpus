Smart Device Development
Compilers for Smart Devices
 





9/7/2007

Visual Studio includes the following compilers that target microprocessors used in smart devices:

  • A 32-bit C/C++ compiler used to compile and link ARM and Thumb C and C++ programs.

  • A 32-bit C/C++ compiler used to compile and link Renesas SH-4 C and C++ programs.

  • A 32-bit C/C++ compiler used to compile and link MIPS16, MIPS32, and MIPS64 C and C++ programs.

The compilers produce Common Object File Format (COFF) object files.
