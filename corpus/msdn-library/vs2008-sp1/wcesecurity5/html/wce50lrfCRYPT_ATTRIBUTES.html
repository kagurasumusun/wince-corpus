CRYPT_ATTRIBUTES

This structure contains an array of attributes.

typedef struct _CRYPT_ATTRIBUTES {
  DWORD cAttr;
  PCRYPT_ATTRIBUTE rgAttr;
} CRYPT_ATTRIBUTES, *PCRYPT_ATTRIBUTES, CMSG_ATTR;

Members

cAttr
Number of elements in the rgAttr array.
rgAttr
Pointer to an array of CRYPT_ATTRIBUTE structures.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Wincrypt.h.
