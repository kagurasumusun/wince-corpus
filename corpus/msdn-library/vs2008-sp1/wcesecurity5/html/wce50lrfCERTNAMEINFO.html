CERT_NAME_INFO

This structure contains subject or issuer names. The information is represented as an array of CERT_RDN structures.

typedef struct _CERT_NAME_INFO {
  DWORD cRDN;
  PCERT_RDN rgRDN;
} CERT_NAME_INFO, *PCERT_NAME_INFO;

Members

cRDN
Number of elements in the array defined in rgRDN.
rgRDN
Pointer to an array of CERT_RDN structures.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Wincrypt.h.
