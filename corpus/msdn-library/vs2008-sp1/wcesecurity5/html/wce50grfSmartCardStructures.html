Smart Card Structures

The following table shows the Smart Card Services structures with a description of the purpose of each.

Programming element Description
SCARD_IO_REQUEST This structure begins a protocol control information structure.
SCARD_READERSTATE This structure is used by functions for tracking smart cards within readers.
SCARD_ATRMASK This structure is used by the SCardLocateCardsByATR function to locate cards.
