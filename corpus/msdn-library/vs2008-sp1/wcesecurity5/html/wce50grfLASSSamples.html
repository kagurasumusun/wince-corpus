Platform Builder for Microsoft Windows CE 5.0  

LASS Samples

The following table shows the LASS and LAP samples included in Windows CE.

Name Description
LASSCTL Utility that enables you to configure and test LASS and its associated LAPs. LASSCTL can force LAP enrollment, set or reload a LASS configuration, and force LASS to reload its settings.

To include the LASSCTL utility in your design template, go to %_WINCEROOT%\Public\Common\Sdk\Samples\Lassctl from the build window, and type build.
Password LAP Sample for a Password LAP. The sample is located in the %_WINCEROOT%\Public\Common\Sdk\Samples\Lap directory.
Smartcard LAP Sample for a Smartcard LAP. The sample is located in the %_WINCEROOT%\Public\Common\Sdk\Samples\Lap directory.
