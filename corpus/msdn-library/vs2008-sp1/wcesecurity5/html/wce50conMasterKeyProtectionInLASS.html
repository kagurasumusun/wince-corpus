Master Key Protection in LASS

LASS supports master key protection to help ensure data protected by the master key cannot be decoded without the user's secret data. For more information about master keys and master key storage, see Master Key Storage.

Master key protection for LASS is implemented in LAPs that collect verification data from the user but that do not persist the data. An example of a LAP that does not persist user data is the password LAP, for which the user data is the password. For more information about creating a LAP with master key protection, see Implementing Master Key Protection in a LAP.
