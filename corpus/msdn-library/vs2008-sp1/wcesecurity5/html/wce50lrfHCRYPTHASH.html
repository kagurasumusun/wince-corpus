HCRYPTHASH

This data type represents handles to hash objects. It indicates to the cryptographic service provider (CSP) which hash is used in a particular operation. The CSP does not allow direct manipulation of the hash values. Instead, the user manipulates the hash values through the hash handle.

typedef unsigned long HCRYPTHASH;

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Wincrypt.h.
