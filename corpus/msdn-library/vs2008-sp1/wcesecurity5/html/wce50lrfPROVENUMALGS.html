PROV_ENUMALGS

This structure is returned by calls to the CryptGetProvParam or CPGetProvParam function. This structure holds information on the algorithms supported by a CSP.

typedef struct _PROV_ENUMALGS {
  ALG_ID aiAlgid; 
  DWORD dwBitLen; 
  DWORD dwNameLen; 
  WCHAR szName[20]; 
} PROV_ENUMALGS;

Members

aiAlgid
ALG_ID indicating an algorithm supported.
dwBitLen
DWORD value indicating the length of the key.
dwNameLen
DWORD value indicating the length of the name of the algorithm.
szName
Null-terminated sting containing the name of the algorithm.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Wincrypt.h.
