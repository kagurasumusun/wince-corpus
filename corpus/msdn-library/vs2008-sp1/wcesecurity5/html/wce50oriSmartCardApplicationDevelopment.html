Smart Card Application Development

The Windows CE smart card subsystem supports the Cryptography API and the Windows CE–based device driver model for developing smart card readers.

In This Section

Smart Card Subsystem
Provides high-level information about the modules that make up the smart card functionality.
Smart Card Concepts
Defines the smart card terminology and describes the interaction between users, applications, and smart cards.
Smart Card Resource Manager
Describes the smart card resource manager which manages the access to readers and smart cards.
Smart Card CSP
Provides information about the smart card cryptographic service providers (CSPs), which are dynamic-link libraries (DLLs) that enable access to specific services.

Related Sections

Cryptography
Provides information about how you can use the cryptography functionality to enable application developers to encrypt and decrypt sensitive data.
Cryptography Application Development
Provides an overview of the Microsoft Cryptographic System and describes how to use cryptography services in Windows CE.
