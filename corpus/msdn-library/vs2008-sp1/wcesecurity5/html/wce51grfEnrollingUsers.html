Enrolling Users

Each LAP supports a type of user enrollment, and your application must be able to communicate with the specific LAPs that it needs to access. For example, if a user needs to set a password to be authenticated, your application must be able to handle password enrollment and communicate with a password LAP as needed. For more information about enrollment, see LASS OS Design Development.

To handle user enrollment, your application should call the LASS function CreateEnrollmentConfigDialog.
