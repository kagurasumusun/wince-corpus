Additional Kernel Functionality

In addition to the core kernel features of Windows CE, the kernel contains other functionality, including allowing the OEM to turn off hardware floating point support for the x86 processor family. The kernel also has the ability to save and restore coprocessor registers from multiple coprocessors, to date handling functions, and to have the entire system placed into a state called full kernel mode, which allows all threads to run in kernel mode.

For more information about additional kernel functionality, see the following topics:

  • Floating Point Emulation for x86
  • Implementing Save and Restore Coprocessor Register Support
  • Two-Digit and Four-Digit Dates
  • Full-Kernel Mode
