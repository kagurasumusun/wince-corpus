UnhookInterrupt

This function deregisters an ISR with a specific hardware interrupt.

BOOL UnhookInterrupt( 
  INT hwInterruptNumber, 
  FARPROC pfnHandler 
);

Parameters

hwInterruptNumber
[in] Hardware interrupt line. Note that this value indicates the actual hardware IRQ value and not the logical interrupt identifier.
pfnHandler
[in] Pointer to the ISR that is to handle interrupts for the specified IRQ.

Return Values

TRUE indicates success; FALSE indicates failure.

Remarks

This function removes the pfnHandler pointer from the location in a kernel table indicated by hwInterruptNumber and, instead, installs a dummy handler at this location.

Requirements

OS Versions: Windows CE 2.10 and later.
Header: Nkintr.h.
Link Library: Nk.lib.
