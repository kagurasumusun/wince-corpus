Platform Builder for Microsoft Windows CE 5.0  

Loading the Image into ROM

A boot loader can load a multiple XIP image in these ways:

  • Using Microsoft Platform Builder and .bin files
  • Using multiple XIP regions in a single file
  • Using .nb0 files in the Absolute Binary Data (ABF) file format

    There is no change to the image download process if your boot loader uses the ABF format.
