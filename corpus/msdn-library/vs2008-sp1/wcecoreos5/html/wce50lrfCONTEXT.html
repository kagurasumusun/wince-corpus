CONTEXT

This structure contains processor-specific register data.

Currently there are CONTEXT structures for the following processors:

  • Intel
  • MIPS
  • Alpha
  • SHx
  • ARM

For definitions of these structures, see the Winnt.h header file.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Winbase.h.
