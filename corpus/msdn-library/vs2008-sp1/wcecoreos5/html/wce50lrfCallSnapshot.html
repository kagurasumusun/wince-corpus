CallSnapshot

This structure is used to store information about stack frames.

typedef struct _CallSnapshot {
  DWORD dwReturnAddr;
} CallSnapshot;

Members

dwReturnAddr
Return address of the stack frame.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Pkfuncs.h.
