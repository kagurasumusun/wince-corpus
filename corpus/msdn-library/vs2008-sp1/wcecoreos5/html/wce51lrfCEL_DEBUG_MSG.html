CEL_DEBUG_MSG

This structure is logged when a debug message is printed.

typedef struct __CEL_DEBUG_MSG { 
  DWORD pid;
  DWORD tid;
  WCHAR  szMessage[0];
} CEL_CEL_DEBUG_MSG, *PCEL_CEL_DEBUG_MSG;

Members

pid
Process ID of the process that printed the message.
tid
Thread ID of the thread that printed the message.
szMessage
Text of the message. Message length is inferred from event length.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Celog.h.
