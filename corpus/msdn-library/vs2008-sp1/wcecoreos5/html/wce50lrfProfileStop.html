ProfileStop

This function stops the Windows CE instrumented kernel or Monte Carlo profiling and displays a profile report on a debug terminal.

VOID ProfileStop (void);

Parameters

None.

Return Values

None.

Requirements

OS Versions: Windows CE 2.10 and later.
Header: Profiler.h.
Link Library: Coredll.lib.
