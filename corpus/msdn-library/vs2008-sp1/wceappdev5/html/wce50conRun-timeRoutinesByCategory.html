Run-time Routines by Category

The Microsoft run-time library provides routines for programming for the Microsoft Windows CE operating system. These routines automate many common programming tasks that are not provided by the C and C++ languages.

The following list shows Microsoft run-time library routines by category. For reference convenience, some routines are listed in more than one category. Wide-character routines, where they exist, are grouped with single-byte character counterparts.

  • Buffer manipulation
  • Character classification
  • Data conversion
  • Floating-point support
  • Input and output
  • Memory allocation
  • Process control
  • Sorting
  • String manipulation
