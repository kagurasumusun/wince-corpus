Data Type Mappings

The following data-type mappings are defined in Tchar.h.

Generic-Text Data Type Name _UNICODE Defined
_TCHAR wchar_t
_TINT wint_t
_TSCHAR wchar_t
_TUCHAR wchar_t
_TXCHAR wchar_t
_T or _TEXT L (converts following character or string to its Unicode counterpart)
