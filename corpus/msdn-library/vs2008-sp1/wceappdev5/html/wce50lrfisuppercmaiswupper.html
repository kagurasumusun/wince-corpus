isupper, iswupper

This routine returns nonzero if c is a particular representation of an uppercase letter.

int isupper( 
   int c 
);

int iswupper( 
   wint_t c 
);

Parameters

c
Integer to test.

Return Values

isupper returns a non-zero value if c is an uppercase character (a – z).

iswupper returns a non-zero value if c is a wide character that corresponds to an uppercase letter, or if c is one of an implementation-defined set of wide characters for which none of iswcntrl , iswdigit, iswpunct, or iswspace is true.

Each routine returns 0 if c does not satisfy the test condition.

The result of the test condition is independent of locale.
