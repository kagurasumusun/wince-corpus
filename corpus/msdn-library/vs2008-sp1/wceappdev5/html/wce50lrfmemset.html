memset, wmemset

Sets buffers to a specified character.

void *memset(
   void* dest, 
   int c, 
   size_t count 
);

whar_t *wmemset( 
   wchar_t* dest,
   wchar_t c, 
   size_t count 
);

Parameters

dest
Pointer to destination.
c
Character to set.
count
Number of characters.

Return Values

memset and wmemset return the value of dest.

Remarks

The memset and wmemset functions set the first count characters of dest to the character c.

Example

/* MEMSET.C: This program uses memset to
 * set the first four characters of buffer to "*".
 */

#include <memory.h>
#include <stdio.h>

void main( void )
{
   char buffer[] = "This is a test of the memset function";

   printf( "Before: %s\n", buffer );
   memset( buffer, '*', 4 );
   printf( "After:  %s\n", buffer );
}

Output

Before: This is a test of the memset function
After:  **** is a test of the memset function

Requirements

OS Versions: Windows CE 2.0 and later.
Header: stdlib.h.
Link Library: coredll.dll.
