Platform Builder for Microsoft Windows CE 5.0  

Application Development with an Imported SDK

You can import an SDK created by Platform Builder into eMbedded Visual C++ 4.0 or Visual Studio 6.0. An application developer can then use the SDK to create applications that run on the Windows CE–based run-time image from which the SDK was exported.

The Platform Builder Add-in Wizard installs in the correct location when you run Setup for Platform Builder.

After it is installed, you access the Platform Builder wizard from the Visual C++ Add-in Wizard of Microsoft Visual Studio 6.0.

If you install Visual C++ 6.0 and then install Platform Builder, the Platform Builder Add-in Wizard is available when you start the Visual C++ 6.0 wizard.

If you install Platform Builder before installing Visual C++ 6.0, you must make the Platform Builder add-in available by manually copying the file PBAddInWiz.awx from <Platform Builder installation path>\Cepb\Bin to <DRIVE:>\Program Files\Microsoft Visual Studio\Common\MSDev98\Bin\IDE.
