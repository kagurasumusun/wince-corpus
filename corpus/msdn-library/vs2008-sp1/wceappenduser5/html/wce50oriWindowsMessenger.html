Windows Messenger

The Microsoft® Windows® Messenger for Windows CE real-time communications software combines real–time voice and text communications with file transfer capability.

In This Section

Windows Messenger OS Design Development
Presents information that is helpful when designing and developing a Windows CE OS design that uses the Windows Messenger Catalog item. This includes dependencies of Windows Messenger, the modules and components that implement Windows Messenger, and Windows Messenger Sysgen variables.
Windows Messenger Registry Settings
Provides information about the configurable registry settings used by Windows Messenger.
Windows Messenger Security
Provides security best practice information relevant to Windows Messenger.
Windows Messenger Migration
Provides information that is useful if you are migrating from an OS design that includes the Windows Messenger Catalog item and is based on a previous version of Windows CE.
