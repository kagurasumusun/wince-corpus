FindObjects

This device module function is called by the server to locate objects in the device's object store. 

HRESULT (*PFINDOBJECTS)(
  PFINDOBJINFO pInfo
);

Parameters

pInfo
[in] Pointer to a FINDOBJINFO structure.

Return Values

Returns S_OK if successful. If the function is not successful, it can return E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, or E_FAIL.

Requirements

Pocket PC: Pocket PC 2000 and later.
Smartphone: Smartphone 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: Cesync.h.
Library: None.
