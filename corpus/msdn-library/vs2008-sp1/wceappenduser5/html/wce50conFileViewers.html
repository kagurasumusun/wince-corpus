File Viewers

The file viewers included with Microsoft® Windows® CE provide a way to read common Microsoft Office file types as well as Portable Document Format (PDF) files.

In This Section

File Viewers OS Design Development
Provides information that is helpful when designing and developing a Windows CE OS design that uses file viewers. This includes dependencies of file viewers, the modules and components that implement file viewers, and file viewer SYSGEN variables.
File Viewers Registry Settings
Provides information about the configurable registry setting used by the file viewer applications.
