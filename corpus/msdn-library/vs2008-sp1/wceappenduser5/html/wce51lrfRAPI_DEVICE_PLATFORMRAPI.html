RAPI_DEVICE_PLATFORM (RAPI)

This structure contains information that identifies a Windows CE device's platform.

typedef struct {
  BSTR bstrName;
  DWORD dwMajor;
  DWORD dwMinor;
} RAPI_DEVICE_PLATFORM;

Members

bstrName
The name of the platform running on the Windows CE-based device. For example, Microsoft Windows Mobile 2005.
dwMajor
The major version number of the operating system running on the Windows Mobile-based device. For example, 5.1.
dwMinor
The minor version number of the operating system running on the Windows Mobile-based device. For example, 5.1.

Requirements

OS Versions: Windows CE 5.0 and later
Header: rapitypes.h
Library: rapi.lib
