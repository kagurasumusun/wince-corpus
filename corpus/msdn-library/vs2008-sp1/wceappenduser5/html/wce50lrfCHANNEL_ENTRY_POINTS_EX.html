CHANNEL_ENTRY_POINTS_EX

This structure contains pointers to the functions called by a client-side DLL to access virtual channels. This structure is passed through your VirtualChannelEntryEx.

typedef struct tagCHANNEL_ENTRY_POINTS_EX
{
  DWORD cbSize;
  DWORD protocolVersion;
  PVIRTUALCHANNELINITEX  pVirtualChannelInitEx;
  PVIRTUALCHANNELOPENEX  pVirtualChannelOpenEx;
  PVIRTUALCHANNELCLOSEEX pVirtualChannelCloseEx;
  PVIRTUALCHANNELWRITEEX pVirtualChannelWriteEx;
} CHANNEL_ENTRY_POINTS_EX, FAR * PCHANNEL_ENTRY_POINTS_EX;

Members

cbSize
Size, in bytes, of this structure.
protocolVersion
Protocol version. Terminal Services sets this member to VIRTUAL_CHANNEL_VERSION_WIN2000.
pVirtualChannelInit
Pointer to a VirtualChannelInitEx function.
pVirtualChannelOpen
Pointer to a VirtualChannelOpenEx function.
pVirtualChannelClose
Pointer to a VirtualChannelCloseEx function.
pVirtualChannelWrite
Pointer to a VirtualChannelWriteEx function.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Cchannel.h.
