Windows CE Terminal Services Client (CETSC)

Windows CE Terminal Services Client (CETSC) supports the user interface for Windows Terminal Server and Remote Desktop Protocol (RDP). It is software that enables a thin client that is not using the Windows Thin Client Shell to access Windows-based applications on the Terminal Server. This software is derived from the Microsoft Terminal Services Client (MSTSC) found on Windows-based desktop systems. CETSC is included in SYSGEN_RDP.

CETSC is a sample shell that provides a user interface (UI). When the CETSC shell is used, user preferences are saved in .rdp files. This file is created when an operating system (OS) that contains RDP is run in a remote location and then the session is closed. This behavior differs from a device that is using the Windows Thin Client Shell, in which case the user settings are saved in the registry. For more information, see Terminal Services Client Configuration through the .rdp File.

CETSC is also the host to Microsoft ActiveX® (mstcax) control. Mstcax contains the code that handles all communications for the RDP client and the code that performs graphical updates in the client window.
