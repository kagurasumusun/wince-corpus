File Viewer Command-Line Execution

You can open any of the Microsoft file viewers in Windows CE by double-clicking the associated icon on the target device, or by running the associated executable module from the command line.

In addition, each file viewer offers an HTML-based Help file that contains descriptive information about the viewer and instructions for using all the viewer options.

The following table shows the command-line instructions for each viewer.

Viewer Supported file types Command line
Microsoft Excel Viewer .xls xls <filename>
Microsoft ImageViewer .jpg, .bmp, .gif, .wss imageviewer <filename|...>

imageviewer /S <filename>.wss
Microsoft PDF Viewer .pdf pdfviewer <filename>
Microsoft PowerPoint Viewer .ppt, .pps presviewer <filename>
Microsoft Word Viewer .doc, .txt docviewer <filename>

Remarks

The Image Viewer application supports two options:

  • imageviewer <filename|...>

    Displays a full-screen image of a .jpg, .bmp, or .gif file.

  • imageviewer /S <filename>.wss

    Starts a previously created image slide show stored as a .wss file.
