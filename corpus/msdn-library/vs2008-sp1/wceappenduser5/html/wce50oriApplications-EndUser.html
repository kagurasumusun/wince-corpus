Platform Builder for Microsoft Windows CE 5.0  

Applications - End User

This section describes the operating system functionality that is available for developing end user applications.

In This Section

ActiveSync
This technology provides support for synchronizing data between a Windows-based desktop computer and Microsoft® Windows® CE-based devices.
File Viewers
This technology provides end users with a way to read common Microsoft® Office® file types as well as PDF files.
Remote Desktop Protocol
This technology enables users to connect remotely to a desktop computer running Windows XP Professional, or a server running Microsoft® Windows NT® Server 4.0, Terminal Server Edition or later.
Windows Messenger
This technology combines real–time voice and text communications with file transfer capability.
User Help
This technology enables you to include user help files in your custom shell by modifying existing Help topics or creating new ones.
