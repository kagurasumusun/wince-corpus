Disabling Terminal Services Functionality

For enhanced security, you might choose to disable Terminal Services functionality such as clipboard redirection and printer redirection for clients that connect to Terminal Servers using the Remote Desktop ActiveX Control.

To disable Terminal Services functionality

  1. Add the following keys to the registry of the server. 
    HKEY_LOCAL_MACHINE\Software\Microsoft\Terminal Server\DisableClipRedirection
HKEY_LOCAL_MACHINE\Software\Microsoft\Terminal Server\DisablePrinterRedirection
  2. Set the value of both keys to DWORD 1.
