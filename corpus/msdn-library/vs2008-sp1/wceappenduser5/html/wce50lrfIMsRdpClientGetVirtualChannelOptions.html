IMsRdpClient::GetVirtualChannelOptions

This method retrieves the options set for a virtual channel. 

HRESULT GetVirtualChannelOptions(
  BSTR ChanName,
  LONG* pChanOptions
);

Parameters

ChanName
[in] The name of a virtual channel that was specified in the call to the IMsTscAx::CreateVirtualChannels method.
pChanOptions
[out] The options set for the virtual channel specified by the ChanName parameter. For a description of possible options, see the CHANNEL_DEF structure

Return Values

If the method succeeds, the return value is S_OK.

If it fails, the method returns a nonzero error code.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Discodlg.h. Mstsax.idl.
Link Library: Mstsax.lib.
