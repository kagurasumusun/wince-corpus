ICeFileFilterOptions:IUnknown

This interface is optionally implemented by a version 2.0 file converter dynamic-link library (DLL).

Method Description
SetFilterOptions Sets the filter options using a pointer to the CFF_CONVERTOPTIONS structure.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Replfilt.h.
Link Library: Coredll.lib.
