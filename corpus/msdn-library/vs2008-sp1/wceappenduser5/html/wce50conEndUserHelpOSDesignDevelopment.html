Platform Builder for Microsoft Windows CE 5.0  

User Help OS Design Development

The User Help catalog item supports user help functionality and contents.

In addition, if your run-time image does not include a browser application, you can include user help by adding SYSGEN_HELP to your OS design.

OS Design Information

The following table shows OS design information for Help Applications.

Concept Description
Dependencies for MSHTML-based help applications Internet Explorer 6
Dependencies for Pocket Internet Explorer help applications Microsoft Pocket Internet Explorer
Hardware considerations None
Note   For run-time images that do not include a browser application, if you need to include help, add SYSGEN_HELP to your OS design.

Modules and Components

The following table shows the modules and components that implement user help applications.

Item Module Component
Help for Windows CE-base Internet Explorer htmlhelp Peghelp, Htmlview

User Help Implementation Considerations

The following Sysgen variables control the User Help functionality listed.

Sysgen Variable Functionality
SYSGEN_HELP Adds the Help Catalog item to your OS design.
