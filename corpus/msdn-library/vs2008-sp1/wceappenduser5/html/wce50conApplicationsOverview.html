Applications - End User Catalog Items

The following table shows the Catalog items in the Applications - End User section of the Catalog.

Catalog item Sysgen Variable Description
ActiveSync SYSGEN_AS_BASE This item provides support for synchronizing data between a Windows-based desktop computer and Microsoft® Windows® CE-based devices.

For more information, see ActiveSync.
File Sync SYSGEN_AS_FILE This item includes ActiveSync file synchronization.

For more information, see ActiveSync OS Design Development.
Inbox Sync SYSGEN_AS_MAIL This item includes ActiveSync Inbox mail synchronization.

For more information, see ActiveSync OS Design Development.
Pocket Outlook Database Sync (product name is Outlook Mobile) SYSGEN_AS_PIM This item includes ActiveSync Inbox contact, task, and appointment synchronization.

For more information, see ActiveSync OS Design Development.
CAB File Installer/Uninstaller SYSGEN_WCELOAD This item includes an application that enables installing and uninstalling CAB files. This application is for use with devices that include a display.
Microsoft Excel Viewer SYSGEN_VIEWER_XLS This item includes an application for viewing Microsoft Excel documents.

For more information, see File Viewers.
Microsoft Image Viewer SYSGEN_VIEWER_IMAGE This item includes an application for viewing images.

For more information, see File Viewers.
Microsoft PDF Viewer SYSGEN_VIEWER_ACROBAT This item includes an application for viewing PDF documents.

For more information, see File Viewers.
Microsoft PowerPoint Viewer SYSGEN_VIEWER_PPT This item includes an application for viewing Microsoft PowerPoint® documents.

For more information, see File Viewers.
Microsoft Word Viewer SYSGEN_VIEWER_DOC This item includes an application for viewing Microsoft Word documents.

For more information, see File Viewers.
FLASH Update Sample Application SYSGEN_FTPUPDATE This item includes a sample application that demonstrates how to flash an upgrade on to a device.
Freecell SYSGEN_FREECELL This item includes the FreeCell solitaire game for Windows CE.
Solitaire SYSGEN_SOLITAIRE This item includes the standard Solitaire game for Windows CE.
Help SYSGEN_HELP This item includes the Windows CE HTML-based Help system application.

For more information, see User Help.
Inbox SYSGEN_PMAIL This item includes the Windows CE-based e-mail application.

You can specify the default mail handler by specifying a value for the HKEY_CLASSES_ROOT\mailto\shell\open\command registry entry. The default value of this registry entry is Pmail.exe, which specifies the Inbox application.
Remote Desktop Protocol (RDP) SYSGEN_RDP This item includes support for the Remote Desktop Protocol (RDP), which enables a Windows CE-based device to connect remotely to a desktop computer running a supported Microsoft operating system.

For more information, see Remote Desktop Protocol.
Audio Playback Direction SYSGEN_RDP_AUDIO This item enables RDP audio redirection.

For more information, see RDP OS Design Development.
Cut/Copy/Paste Clipboard Redirection SYSGEN_RDP_CLIPBOARD This item enables RDP cut, copy, and paste clipboard redirection.

For more information, see RDP OS Design Development.
File Storage Redirection SYSGEN_RDP_DRIVE This item enables RDP file storage redirection.

For more information, see RDP OS Design Development.
Filtered File Storage Redirection SYSGEN_RDP_FILTERFSD This item enables RDP filtered file storage redirection.

For more information, see RDP OS Design Development.
Printer Redirection SYSGEN_RDP_PRINTER This item enables RDP printer direction.

For more information, see RDP OS Design Development.
Serial and Parallel Port Redirection SYSGEN_RDP_PORT This item enables RDP serial and parallel port redirection.

For more information, see RDP OS Design Development.
Smart Card Redirection SYSGEN_RDP_SMARTCARD This item enables RDP smart card redirection for terminal server login and application usage.

For more information, see RDP OS Design Development.
User Interface Dialog Boxes SYSGEN_RDP_UI This item includes RDP user interface dialog boxes.

For more information, see RDP OS Design Development.
Terminal Emulator SYSGEN_PEGTERM This item includes a terminal emulation application.
Windows Messenger SYSGEN_MESSENGER This item includes a Windows CE-based version of the Windows Messenger application.

For more information, see Windows Messenger.
WordPad SYSGEN_PWORD This item a Windows CE-based word processing application.
