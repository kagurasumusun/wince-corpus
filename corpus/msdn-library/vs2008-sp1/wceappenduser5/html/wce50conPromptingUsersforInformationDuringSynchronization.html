Prompting Users for Information During Synchronization

Users do not like being prompted for information during synchronization. Taking focus from the ActiveSync window is poor interface design:

  • ActiveSync has been designed for the majority of cases.
  • The existing design is optimized for ease of use.
  • Separating error messages from the main synchronization cycle enhances usability.
  • The resolution cycle is designed to handle special cases. The user should be prompted only during the resolution cycle.
