Supporting User Settings

Users can change service provider settings by clicking the Settings button in the New Partnership dialog box, or by selecting Options from the Tools menu of ActiveSync's main window. Either action displays the Options dialog box.

The user then selects the program corresponding to a service provider and clicks the Settings button. The Settings button is available only for enabled service providers — those with marked check boxes next to their programs' names. This displays the Settings dialog box for the service provider, which is identical to the dialog box displayed when the user clicks Settings in the New Partnership dialog box.
