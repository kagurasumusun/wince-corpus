Windows Messenger Architecture

The Windows Messenger client application uses two possible server types:

  • Real-time Communications (RTC)

    Enables you to communicate with Session Initiation Protocol (SIP) clients. Uses the RTC Client API.

  • .NET Messenger Service

    Enables you to communicate with contacts using a .NET Passport account. This service is also known as the MSN Messenger service.
