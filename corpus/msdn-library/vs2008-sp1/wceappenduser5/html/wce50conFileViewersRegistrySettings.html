File Viewers Registry Settings

File viewers use the registry to store font configuration data.

Note   The default registry values vary depending on which Catalog items are included in your OS design. For more information, see Default Registry Settings.

The following table shows the registry value for the HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft File Viewers key.

Value : type Description
ClearType : REG_DWORD Default setting is 0; file viewers do not use ClearType font-smoothing technology.

Enables the use of ClearType in file viewer applications.

If set to 1, file viewers use ClearType.
