Enumerating Device Objects

Enumerating objects on a Windows CE-based device differs from enumerating objects on a desktop. In contrast to desktop enumeration, the service manager enumerates each object and calls the ObjectNotify function of each device provider when a user connects a Windows CE-based device. If an object on a Windows CE-based device needs synchronizing, the device provider must inform the service manager.
