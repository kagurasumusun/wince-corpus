IMsTscAdvancedSettings::put_Compress

This method sets the value of the Compression property, which enables or disables compression.

HRESULT put_Compress(
  long compress
);

Parameters

compress
[in] The value the Compression property is to be set to. If set to zero, compression is disabled. If set to any other value, compression is enabled.

Return Values

If the method succeeds, the return value is S_OK.

If it fails, the method returns a nonzero error code.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Discodlg.h. Mstsax.idl.
Link Library: Mstsax.lib.
