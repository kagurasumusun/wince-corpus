Important End-user Notification for ActiveSync

Microsoft recommends that all synchronization cables ship with a tag or sticker on the desktop computer end of the USB cable or serial cable connector. This tag or sticker should advise the user to install ActiveSync on the desktop computer before attaching the cradle and cable to it. Failing to do so could cause the desktop computer operating system to install the incorrect drivers. If ActiveSync is installed first, the proper drivers will be recognized.
