Implementing the Device Functions

The ActiveSync provider on the Windows CE-based device must implement the InitObjType, ObjectNotify and GetObjTypeInfo functions. ReportStatus is optional. In Windows CE 2.1 and later, the provider can also implement FindObjects and SyncData.

InitObjType both initializes and terminates a Windows CE-based device ActiveSync provider. ObjectNotify handles object identification and change detection. GetObjTypeInfo retrieves Windows CE-based device information about the object type. ReportStatus allows a Windows CE-based device ActiveSync provider to be informed about particular events.
