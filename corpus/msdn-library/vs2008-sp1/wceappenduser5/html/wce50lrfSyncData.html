SyncData

This device module function synchronizes data between the ActiveSync service provider and the device. For more information, see Sending and Receiving Data with the SyncData Function.

HRESULT (*PSYNCDATA)(
  PSDREQUEST psd 
);

Parameters

psd
[in, out] Pointer to an SDREQUEST structure.

Return Values

Returns S_OK if successful. If the function is not successful, it can return E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, or E_FAIL.

Requirements

Pocket PC: Pocket PC 2000 and later.
Smartphone: Smartphone 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: Cesync.h.
Library: None.
