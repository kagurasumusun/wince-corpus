JScript

The JScript functionality for Microsoft® Windows® CE provides a run-time engine for parsing and translating Microsoft JScript® code on Web pages and in other host applications. Hosting for JScript is provided by Microsoft Pocket Internet Explorer or by the Browser Control Host (SHDOCVW) in Internet Explorer 6 for Windows CE.
