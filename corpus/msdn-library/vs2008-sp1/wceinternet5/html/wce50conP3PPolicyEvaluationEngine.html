P3P Policy Evaluation Engine

The WinInet module includes the P3P Policy Evaluation engine that determines how to handle a Web site request to store a cookie on the device. A Web site sends the compact policy that is stored in the P3P header. The policy is evaluated against the restrictions imposed by privacy settings on the device. The engine then applies the possible cookie action based on the evaluation of the P3P header.

For more information about cookie actions and P3P templates, see Privacy Templates.

For more information about the P3P project, see the Platform for Privacy Preferences (P3P) Project specification at this officical W3C Web site.
