Platform Builder for Microsoft Windows CE 5.0  

Browser Applications

Microsoft® Windows® CE supports two browser applications: Internet Explorer 6 and the mobile Internet browser, Pocket Internet Explorer.

Internet Explorer 6 for Windows CE is a feature-rich browser control and provides technologies that can be used to build a custom browser for a specific device or market.

The mobile Internet browser for Windows CE provides a compact mobile Web browser that is optimized for devices with small, vertically oriented displays and for cached or customized content.
