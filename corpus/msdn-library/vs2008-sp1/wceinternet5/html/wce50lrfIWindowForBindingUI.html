IWindowForBindingUI

This interface allows clients of URL monikers to display information in the client's user interface when necessary.

Method Description
GetWindow Retrieves a handle to a window to present information in the user interface during a bind operation.

Remarks

This interface is usually implemented by OLE containers that also implement the IBindHost interface.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Urlmon.h, Urlmon.idl.
Link Library: Urlmon.lib.
