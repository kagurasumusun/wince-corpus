IMultiLanguage::GetCodePageInfo

This method retrieves the MIMECPINFO structure corresponding to the code page specified in the uiCodePage parameter.

HRESULT GetCodePageInfo( 
  UINT uiCodePage,
  PMIMECPINFO pCodePageInfo
);

Parameters

uiCodePage
[in] Code page identifier value for which the caller wants to retrieve the information.
pCodePageInfo
[out] Address of the buffer to receive a MIMECPINFO structure corresponding to the code page specified in the uiCodePage parameter.

Return Values

Returns S_OK if successful or E_FAIL if either of the arguments is invalid or if the information is not found for the required code page.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mlang.h, Mlang.idl.
Link Library: Mlang.dll.
