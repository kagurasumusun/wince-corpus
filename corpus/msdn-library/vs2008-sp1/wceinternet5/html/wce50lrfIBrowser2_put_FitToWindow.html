IBrowser2::put_FitToWindow

The FitToWindow property gets or sets a Boolean value indicating that resizing of content to fit in the browser window is enabled or disabled.

To set the value of the FitToWindow property, call the property method described here.

To get the value of the FitToWindow property, see the get_FitToWindow property method.

Syntax

HRESULT put_FitToWindow(
  VARIANT_BOOL bFitToWindow
);

Parameters

bFitToWindow
[in] Boolean value; VARIANT_TRUE if content resizing is enabled and VARIANT_FALSE if content resizing is disabled.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: webvw.h
Library: wvuuid.lib
