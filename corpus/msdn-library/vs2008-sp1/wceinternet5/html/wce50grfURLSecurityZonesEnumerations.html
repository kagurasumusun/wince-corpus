URL Security Zones Enumerations

The following table shows the URL security zones enumerations with a description of the purpose of each.

Programming element Description
PSUACTION This enumeration contains the flags passed into the CoInternetGetSecurityUrl function.
PUAF This enumeration contains the flags passed into the IInternetSecurityManager::ProcessUrlAction method.
SZM_FLAGS This enumeration contains the flag values used for creating and enumerating security zone mappings.
URLTEMPLATE This enumeration contains the security level templates.
URLZONE This enumeration contains all the predefined zones used by Microsoft Internet Explorer.
URLZONEREG This enumeration contains the registry location values.
ZAFLAGS This enumeration contains the zone attribute flags.
