IBrowser2::get_LayoutWidth

The LayoutWidth read-only property gets a value indicating the width of the document currently displayed in the browser.

Syntax

HRESULT get_LayoutWidth(
  int * piLayoutWidth
);

Parameters

piLayoutWidth
[out] Reference to a variable that receives the content width in pixels.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Remarks

This method retrieves the width of the document that can be scrolled.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: webvw.h
Library: wvuuid.lib
