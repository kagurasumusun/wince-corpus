Transition Methods

The following table shows transition methods supported in Microsoft® Windows® CE that must be called by the function that applies a transition effect to an image.

Programming element Description
apply (Internet Explorer) Captures the initial display of an object's content for a transition.
play (Internet Explorer) Plays the transition.
stop (Internet Explorer) Stops transition playback.
