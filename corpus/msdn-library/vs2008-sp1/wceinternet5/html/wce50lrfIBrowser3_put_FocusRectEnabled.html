IBrowser3::put_FocusRectEnabled

The FocusRectEnabled property gets or sets a Boolean value indicating that focus rectangles are enabled or disabled. A focus rectangle indicates that an object has input focus.

To set the value of the FocusRectEnabled property, call the property method described here.

To get the value of the FocusRectEnabled property, see the get_FocusRectEnabled property method.

Syntax

HRESULT put_FocusRectEnabled(
  VARIANT_BOOL bFocusRectEnabled
);

Parameters

bFocusRectEnabled
[in] Boolean value; VARIANT_TRUE if focus rectangles are enabled and VARIANT_FALSE if focus rectangles are disabled.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: webvw.h
Library: wvuuid.lib
