Adding Filters and Transitions

The Internet Explorer Filters and Transition functionality in Microsoft® Windows® CE enables you to add visual effects to Web page content. While filters modify the appearance of the static content on a Web page, adding transitions provides visual effects when navigating between pages.

The following topics contain more information about the filters and transitions supported in Windows CE.
