Internet Explorer Multiple-Language API Migration

In Windows CE .NET 4.2, the Multi-Language (MLang) Catalog item was divided into separate components. To retain prior functionality when migrating from versions prior to Windows CE .NET 4.2, replace the SYSGEN_MLANG Sysgen variable with SYSGEN_MLANG_ALL. For more information, see Internet Explorer Multiple-Language API OS Design Development.
