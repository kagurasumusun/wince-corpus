IMLangFontLink2::CodePageToScriptID

This method retrieves the script identifier associated with a code page.

HRESULT CodePageToScriptID( 
  UINT uiCodePage,
  SCRIPT_ID* pSid
);

Parameters

uiCodePage
[in] Unsigned integer value that specifies the code page.
pSid
[out] Pointer to a SCRIPT_ID value that receives the script identifier associated with the code page.

Return Values

Returns S_OK if successful or an error value otherwise.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mlang.h, Mlang.idl.
Link Library: Mlang.dll.
