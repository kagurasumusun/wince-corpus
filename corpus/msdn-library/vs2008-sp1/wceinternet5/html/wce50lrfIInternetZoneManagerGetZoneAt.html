IInternetZoneManager::GetZoneAt

This method retrieves the zone associated with the specified index on the given enumerator.

HRESULT GetZoneAt(
  DWORD dwEnum,
  DWORD dwIndex,
  DWORD* pdwZone
);

Parameters

dwEnum
[in] Unsigned long integer value that specifies the enumerator created by IInternetZoneManager::CreateZoneEnumerator.
dwIndex
[in] Unsigned long integer value that specifies the index of the zone in the enumerator.
pdwZone
[out] Address of an unsigned long integer value that specifies the zone.

Return Values

Returns S_OK if successful or an error value otherwise.

Remarks

The index set in dwIndex must be greater than or equal to zero and less than or equal to the value pointed to by pdwCount in the call to IInternetZoneManager::CreateZoneEnumerator.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Urlmon.h, Urlmon.idl.
Link Library: Urlmon.lib.
