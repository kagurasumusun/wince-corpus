Internet Explorer MLang Structures

The following table shows the Internet Explorer MLang structures with a description of the purpose of each.

Programming element Description
DetectEncodingInfo This structure contains the results of code page detection by the IMultiLanguage2::DetectCodepageInIStream and IMultiLanguage2::DetectInputCodepage methods.
MIMECPINFO This structure contains detailed information gathered from the Multipurpose Internet Mail Extensions (MIME) database about a given code page.
MIMECSETINFO This structure contains information about a given charset.
RFC1766INFO This structure contains information about a given locale identifier (LCID) value, including the corresponding RFC1766-conforming name.
SCRIPTINFO This structure contains the information about the specified script.
UNICODERANGE This structure contains the Unicode range supported by a particular font.
