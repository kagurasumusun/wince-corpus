IBrowser::get_IsFrame

The IsFrame property gets or sets a Boolean value indicating whether the instance of IBrowser is a frame.

To get the value of the IsFrame property, call the property method described here.

To set the value of the IsFrame property, see the put_IsFrame property method.

Syntax

HRESULT get_IsFrame(
  VARIANT_BOOL * pvbIsFrame
);

Parameters

pvbIsFrame
[out] Reference to a Boolean value; VARIANT_TRUE if the instance of IBrowseris a frame and VARIANT_FALSE if the instance of IBrowser is not a frame.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: webvw.h
Library: wvuuid.lib
