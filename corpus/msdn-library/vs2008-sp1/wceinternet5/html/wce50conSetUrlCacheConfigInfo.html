SetUrlCacheConfigInfo

This function sets cache configuration information.

BOOLAPI SetUrlCacheConfigInfoA(
  LPINTERNET_CACHE_CONFIG_INFOA lpCacheConfigInfo, 
  DWORD dwFieldControl
);

Parameters

lpCacheConfigInfo
[in] Specifies when the browser will check for updated pages. Must be one of the following values. Note that "1" is not a valid value.
Value Description
0
Never check for updates. (Always use cached page.)
2
Check for updates once per session.
3
Check for updates whenever page is visited.
4
Automatically check for updated pages. This is the default mode.
dwFieldControl
[in] Always set to CACHE_CONFIG_SYNC_MODE_FC.

Return Values

Returns TRUE if successful, or FALSE otherwise.

Remarks

You can also set the cache configuration information through the system registry. See WinInet Registry Settings for more information.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Wininet.h.
Link Library: Wininet.lib.
