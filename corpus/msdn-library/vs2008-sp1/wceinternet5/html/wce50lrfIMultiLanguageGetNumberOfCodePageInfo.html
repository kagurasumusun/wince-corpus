IMultiLanguage::GetNumberOfCodePageInfo

This method returns the number of code pages for which there is information available on the system. 

HRESULT GetNumberOfCodePageInfo( 
  UINT* pcCodePage
);

Parameters

pcCodePage
[out] Address of the buffer that receives the number of code pages available on the system.

Return Values

Returns NOERROR if successful or E_FAIL otherwise.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mlang.h, Mlang.idl.
Link Library: Mlang.dll.
