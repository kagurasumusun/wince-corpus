Additional Resources for JScript Developers

The following resources are also available when using JScript:

  • MSDN® Library

    The JScript 5.5 Programmer's Guide, JScript language reference, and sample scripts are included in the MSDN Library available at this Microsoft Web site.

  • Developer community

    This Microsoft Web site provides a place for you to share information with other developers and get answers from subject matter experts on virtually any programming question.

  • Books and periodicals

    There are a number of books and magazines available that can help you make the most of JScript in your Web applications, as follows:

    • MSDN Magazine, a magazine for software developers, is published monthly. It is available at newsstands, by subscription, or online at this Microsoft Web site.
    • Microsoft® Visual InterDev® 6.0 Web Technologies Reference
      Author: Microsoft
      ISBN: 1-57231-871-6
    • Microsoft® Visual InterDev® 6.0 Programmer's Guide
      Author: Microsoft
      ISBN: 1-57231-867-8
    • Programming Microsoft Internet Explorer 5
      Author: Scott Roberts
      ISBN: 0-7356-0781-8

    For more information about these titles, see this Microsoft Web site.

  • Newsgroups

    Share information with other Web developers by subscribing to these Usenet newsgroups:

    • microsoft.public.scripting.jscript
    • microsoft.public.dotnet.scripting
    • microsoft.public.inetexplorer.scripting
    • microsoft.public.dotnet.jscript.general
    • microsoft.public.dotnet.languages.jscript

    For additional newsgroups, see this Microsoft Web site.
