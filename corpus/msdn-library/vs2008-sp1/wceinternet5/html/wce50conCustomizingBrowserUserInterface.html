Customizing the Browser User Interface

You can modify the appearance of the browser by customizing fonts, applying Windows XP visual style, and replacing default message boxes. In addition, Microsoft® Windows® CE includes resources you can use to modify the user interface elements of the browser-host. These resources are located in the %_WINCEROOT%\PUBLIC\IE\OAK\SHDOCVWUI\RESDLL directory. The following topics provide more information about customizing the browser user interface.

  • Replacement of the MSHTML User Interface
  • Replacement of the Urlmon User Interface
  • Replacement of the WinInet User Interface
  • Adding Theme Support
  • Customizing the Browser Font Table
