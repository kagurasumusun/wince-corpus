MONIKERPROPERTY

This enumeration contains values that identify properties of a moniker.

typedef enum {
  MIMETYPEPROP = 0x00000000
} MONIKERPROPERTY;

Elements

MIMETYPEPROP
Indicates the MIME type associated with the moniker.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Urlmon.h, Urlmon.idl.
