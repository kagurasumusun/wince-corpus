Pocket Internet Explorer Registry Settings

The Pocket Internet Explorer registry stores information necessary to configure the system for applications and hardware devices. The mobile Internet browser registry also contains information that the operating system continually references during operation.

In This Section

Browser Registry Settings
Lists the base registry settings for the mobile Internet browser.
Browser Object Registry Settings
Lists the registry settings for the browser object and control-wrap classes.
