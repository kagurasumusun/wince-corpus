Internet Explorer MSHTML/DHTML API Samples

The samples included with Microsoft® Windows® CE provide a starting point for adding functionality to your browser.

Note   These samples have not been tested and are not intended for production use.

The IETHEME sample implements the filter and transition functionality. For more information about this functionality, see Adding Filters and Transitions.

Sample Location

The filter and transition sample is located in the %_WINCEROOT%\PUBLIC\IE\OAK\IETHEME directory.
