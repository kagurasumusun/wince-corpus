IInternetProtocol::LockRequest

This method locks the requested resource so that the IInternetProtocolRoot::Terminate method can be called and the remaining data can be read. 

HRESULT ockRequest(
  DWORD dwOptions
);

Parameters

dwOptions
[in] Reserved. Must be set to zero.

Return Values

Returns S_OK if successful or an error value otherwise.

Remarks

For asynchronous pluggable protocols that do not need to lock a request, the method should return S_OK.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Urlmon.h, Urlmon.idl.
Link Library: Urlmon.lib.
