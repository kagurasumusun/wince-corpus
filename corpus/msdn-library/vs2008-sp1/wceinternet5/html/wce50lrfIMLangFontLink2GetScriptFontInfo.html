IMLangFontLink2::GetScriptFontInfo

This method retrieves the font information for the specified script.

HRESULT GetScriptFontInfo( 
  SCRIPT_ID sid,
  DWORD dwFlags,
  UINT* puiFonts,
  SCRIPTFONTINFO* pScriptFont
);

Parameters

sid
[in] SCRIPT_ID value that indicates what script to retrieve the font information for. This can be one of the SCRIPTCONTF values.
dwFlags
[in] Unsigned long integer value that contains the flags that control the enumeration. These flags are found in SCRIPTFONTCONTF.
puiFonts
[in, out] Pointer to an unsigned integer value.
pScriptFont
[out] SCRIPTINFO structure that contains the font information for the specified script.

Return Values

Returns S_OK if successful or E_FAIL otherwise.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mlang.h, Mlang.idl.
Link Library: Mlang.dll.
