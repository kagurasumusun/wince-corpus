Locale Enumeration

This object retrieves a sequence of RFC1766INFO structures.

Remarks

The Locale Enumeration object maintains the position of the client in the enumeration sequence of RFC1766INFO structures. This position is advanced or reset by calls to the methods for the IEnumRfc1766 interface.

Creation/Access Functions

IMultiLanguage::EnumRfc1766

Interfaces Implemented

IEnumRfc1766

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mlang.h, Mlang.idl.
Link Library: Mlang.dll.
