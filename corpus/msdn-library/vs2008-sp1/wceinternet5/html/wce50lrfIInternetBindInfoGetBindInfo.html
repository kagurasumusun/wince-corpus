IInternetBindInfo::GetBindInfo

This method gets the BINDINFO structure associated with the binding operation. 

HRESULT GetBindInfo(
  DWORD* grfBINDF,
  BINDINFO* pbindinfo
);

Parameters

grfBINDF
[out] Address of a value taken from the BINDF enumeration indicating whether the bind should proceed synchronously or asynchronously.
pbindinfo
[in, out] Address of the BINDINFO structure, which describes how the client wants the binding to occur.

Return Values

Returns S_OK if successful or an error value otherwise.

Remarks

Keep in mind that, effective with Microsoft® Internet Explorer 4.0, the size of the BINDINFO structure changed. Your application should check the size of the BINDINFO structure that it receives before writing to members of the structure.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Urlmon.h, Urlmon.idl.
Link Library: Urlmon.lib.
