International Language Functionalities

The Pocket Internet Explorer user interface is localized in the same languages localized as Windows CE. Any Windows CE-based device that includes the mobile Internet browser also includes the MLang API, which provides the following:

  • Code page and locale enumeration from the Multipurpose Internet Mail Extensions (MIME) database.
  • Code page, locale, and character set information retrieval.
  • Code page, string, and character set conversions.
  • Code page, locale, and string detection methods.
  • Font linking to merge characters from different character sets.
  • Locale-aware line breaking for console-based applications.

For more information about MLang functionality, see Internet Explorer Multiple-Language API Application Development.
