Asynchronous Pluggable Protocols Structures

The following table shows the asynchronous pluggable protocols structures with a description of the purpose of each.

Programming element Description
PROTOCOLDATA This structure contains state information about the protocol that is transparent to the transaction handler.
PROTOCOLFILTERDATA This structure contains the IInternetProtocolSink and IInternetProtocol interfaces of an application that is calling a pluggable Multipurpose Internet Mail Extensions (MIME) filter.
