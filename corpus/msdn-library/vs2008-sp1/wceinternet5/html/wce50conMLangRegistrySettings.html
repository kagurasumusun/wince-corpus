Internet Explorer Multiple-Language API Registry Settings

The HKEY_CURRENT_USER\Software\Microsoft\Internet Explorer\International registry key and its subkeys contain the international settings for Internet Explorer.

The subkey nnnn is a 3- or 4-digit number that identifies a particular code page in Microsoft Windows. The subkey ss, used as a child of the Scripts key, is a number in the range 0-255 that identifies a particular script.

Note   The default registry values vary depending on which Catalog items are included in your OS design. For more information, see Default Registry Settings.

The following table shows the named values.

Subkey\Value : type Description
Default_CodePage : REG_DWORD Specifies the default code page. Default setting in hex The following list shows the default values.
  • 0411 - hex:f4,c6,00,00
  • 0412 - hex:b5,03,00,00
  • 0404 - hex:b6,03,00,00
  • 0804 - hex:a8,03,00,00

For all other locales, default value is hex:e4,04,00,00.
AcceptLanguage : REG_SZ Specifies the default language(s). The following list shows the default values.
  • 0411 - "ja,en-us;q=0.5"
  • 0412 - "ko,en-us;q-0.5"
  • 0404 - "zh-tw;en-us;q=0.5"
  • 0804 - "zh-cn;en-us;q=0.5"

For all other locales, the default setting is "en-us".

nnnn\Script : REG_SZ Specifies the default alphabet to use for this locale, for example "Universal Alphabet", or "Cyrillic".
nnnn\Default_InternetEncoding : REG_DWORD Specifies the default Internet Encoding scheme to use, in this hexadecimal format:nn,nn,nn,nn.
Scripts\ss\IEFixedFontName : REG_SZ Specifies the default fixed-width font, for example, "Lucida Console".
Scripts\ss\IEPropFontName : REG_SZ Specifies the default proportional-width font, for example, "Arial".

MIME Database Codepage Settings

The subkeys of the HKEY_CLASSES_ROOT\MIME\Database\Codepage registry key contain settings for a particular MIME codepage, as specified by the subkey nnnn.

The following table shows the named values.

Subkey\Value : type Description
nnnn\BodyCharset : REG_SZ Specifies the default charset, for example "ibm852".
nnnn\Description : REG_SZ Specifies the locale description, for example LOC_DESCRIPTION_852.
nnnn\FixedWidthFont : REG_SZ Specifies the default fixed-width font.
nnnn\ProportionalFont : REG_SZ Specifies the default proportional-width font.
nnnn\Encoding : REG_DWORD Specifies the type of Internet encoding, in the following format:hex:nn,nn,nn,nn.
nnnn\Family : REG_DWORD Specifies the codepage family, for example 000004e2.

MIME Database RFC1766 Settings

By default, MLang uses internal data to map Rfc1766 codepage identifiers to their respective languages. You can instruct MLang to use mapping information in the HKEY_CLASSES_ROOT\MIME\Database\Rfc1766 registry key instead by calling the IMultiLanguage2::SetMimeDBSource method and passing MIMECONTF_MIME_REGISTRY.
