CBaseControlWindow::SetWindowPosition

Sets the window position on the desktop. 

HRESULT SetWindowPosition(
  long Left,
  long Top,
  long Width,
  long Height
);

Parameters

Left
New left coordinate.
Top
New top coordinate.
Width
Width of the window.
Height
Height of the window.

Return Values

Returns an HRESULT value.
