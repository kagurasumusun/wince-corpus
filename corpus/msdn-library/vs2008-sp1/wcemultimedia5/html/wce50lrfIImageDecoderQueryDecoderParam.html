IImageDecoder::QueryDecoderParam

This method is used to determine whether a decoder supports a specific capability.

HRESULT QueryDecoderParam(
  GUID Guid
);

Parameters

Guid
[in] A GUID value specifying the parameter to query the decoder for.

Set this value to a decoder parameter identifier. For more information, see Imaging GUIDs.

Return Values

If successful, this method returns S_OK.

This method may return E_NOTIMPL if it fails.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Imaging.h.
Link Library: Imaging.lib.
