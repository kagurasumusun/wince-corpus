DirectShow Migration

This topic contains information about migrating DirectShow functionality from earlier versions of Windows CE.

For general migration information, see Migrating from an Earlier Version of Windows CE.

Migrating from Windows CE .NET 4.1 to Windows CE 5.0

  • Effective with Windows CE .NET 4.2, the Cinepak (SYSGEN_DSHOW_CINEPAK) and Quicktime (SYSGEN_DSHOW_QT) video codecs are no longer supported.

Migrating from Windows CE .NET 4.2 to Windows CE 5.0

  • Effective with Windows CE 5.0, Windows CE no longer provides a MIDI filter for DirectShow. Third party solutions for MIDI support through DirectShow are still possible.
  • Because Windows CE 5.0 does not support DirectSound, the DirectShow Audio Renderer (SYSGEN_DSHOW_DSNDOUT) is no longer supported. Applications that had been using the DirectSound Audio Renderer should now use the Waveform Audio Renderer instead.
