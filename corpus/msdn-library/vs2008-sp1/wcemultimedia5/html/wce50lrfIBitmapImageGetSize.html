IBitmapImage::GetSize

This method returns the bitmap image dimensions in pixels.

HRESULT GetSize(
  SIZE* size
);

Parameters

size
[out] A pointer to a SIZE structure containing the height and width dimensions, in pixels, of the bitmap image.

Return Values

If successful, this method returns S_OK.

If it fails, this method should return one of the following error values:

  • IMGERR_OBJECTBUSY
  • E_FAIL

For more information, see Error Codes for the Imaging API.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Imaging.h.
Link Library: Imaging.lib.
