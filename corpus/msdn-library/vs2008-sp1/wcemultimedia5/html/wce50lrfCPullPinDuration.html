CPullPin::Duration

Retrieves the total duration of the media stream. 

HRESULT Duration(
  REFERENCE_TIME* ptDuration 
);

Parameters

ptDuration
Duration measured in bytes multiplied by UNIT (10,000,000).

Return Values

Returns an HRESULT value.
