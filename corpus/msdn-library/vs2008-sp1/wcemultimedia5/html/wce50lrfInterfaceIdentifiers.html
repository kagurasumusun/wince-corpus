DVD-Video API Interface Identifiers

The following interface identifiers are used to obtain pointers to the DVD-Video API interfaces.

Constant Description
IID_IDVDUserOperation Used to obtain a pointer to an IDVDUserOperation interface.
IID_IDVDNavigationManager Used to obtain a pointer to an IDVDNavigationManager interface.
IID_IDVDROM Used to obtain a pointer to an IDVDROM interface.
IID_IDVDVideoVolume Used to obtain a pointer to an IDVDVideoVolume interface.
IID_IDVDDataSearchInfo Used to obtain a pointer to an IDVDDataSearchInfo interface.
IID_IDVDDomain Used to obtain a pointer to an IDVDDomain interface.
IID_IDVDHighlightInfo Used to obtain a pointer to an IDVDHighlightInfo interface.
IID_IDVDMenu Used to obtain a pointer to an IDVDMenu interface.
IID_IDVDNavDataStatusSink Used to obtain a pointer to an IDVDNavDataStatusSink interface.
IID_IDVDParentalManagementTable Used to obtain a pointer to an IDVDParentalManagementTable interface.
IID_IDVDProgramChain Used to obtain a pointer to an IDVDProgramChain interface.
IID_IDVDStreamAttributes Used to obtain a pointer to an IDVDStreamAttributes interface.
IID_IDVDStreamControlInfo Used to obtain a pointer to an IDVDStreamControlInfo interface.
IID_IDVDTextManager Used to obtain a pointer to an IDVDTextManager interface.
IID_IDVDTimeMap Used to obtain a pointer to an IDVDTimeMap interface.
IID_IDVDTitleSet Used to obtain a pointer to an IDVDTitleSet interface.
