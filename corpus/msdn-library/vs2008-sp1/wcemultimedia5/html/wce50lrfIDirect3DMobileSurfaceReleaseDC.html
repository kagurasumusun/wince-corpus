IDirect3DMobileSurface::ReleaseDC

Release a device context handle.

HRESULT ReleaseDC(
  HDC hdc
);

Parameters

hdc
[in] Handle to a device context.

Return Values

If the method succeeds, the return value is D3DM_OK (see D3DM Values).

If the method fails, the return value can be D3DMERR_INVALIDCALL (see D3DMERR Values).

Remarks

An handle to a device context (HDC) is a Microsoft Windows resource. It must be released after use so Windows can return it to the pool of available resources.

This method will release only the device context returned by IDirect3DMobileSurface::GetDC; otherwise, this method will fail.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dm.h.
Link Library: D3dm.lib, D3dmguid.lib.
