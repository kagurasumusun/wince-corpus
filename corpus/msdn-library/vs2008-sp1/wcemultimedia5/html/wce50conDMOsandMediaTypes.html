DMOs and Media Types

A media type is a description of the format associated with a stream of media data. The following topics describe how Microsoft DirectX Media Objects (DMOs) handle media types. It is primarily intended for developers who are writing their own custom DMOs. For applications that use DMOs, see Using DirectX Media Objects.
