Waveform Audio Structures

The following table shows the structures that the wave API uses.

Programming element Description
AUDIOGAINCLASS This structure defines the parameters of an audio gain class.
STREAMPROPS This structure defines the properties of a waveform- audio stream.
WAVEFORMATEX This structure defines the format of waveform-audio data.
WAVEHDR This structure defines the header used to identify a waveform-audio buffer.
WAVEINCAPS This structure describes the capabilities of a waveform-audio input device.
WAVEOUTCAPS This structure describes the capabilities of a waveform-audio output device.
