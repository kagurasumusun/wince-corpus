IAMPlayListItem::GetFlags

This method returns properties for an item in the playlist.

HRESULT GetFlags(
  DWORD* pdwFlags
);

Parameters

pdwFlags
[out] Identifies properties based on the following flags.
Flag Description
AMPLAYLIST_STARTINSCANMODE Determined from the PreviewMode tag.
AMPLAYLIST_FORCEBANNER Determined from the ForceBanner tag.

Return Values

Returns an HRESULT value.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements. See Setting Up the Build Environment for more information.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
