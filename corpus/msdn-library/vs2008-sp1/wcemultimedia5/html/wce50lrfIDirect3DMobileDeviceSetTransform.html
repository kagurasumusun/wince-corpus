IDirect3DMobileDevice::SetTransform

This method is used to define the properties of a transformation matrix.

HRESULT SetTransform(
  D3DMTRANSFORMSTATETYPE State,
  CONST D3DMMATRIX* pMatrix,
  D3DMFORMAT Format
);

Parameters

State
[in] A D3DMTRANSFORMSTATETYPE value that identifies the type of transformation matrix.
pMatrix
[in] A pointer to a D3DMMATRIX structure that contains the data for the matrix.
Format
[in] A D3DMFORMAT value that identifies the numerical format of the data in the matrix. This value can only be D3DMFMT_D3DMVALUE_FLOAT or D3DMFMT_D3DMVALUE_FIXED.

Return Values

If the method succeeds, the return value is D3DM_OK (see D3DM Values).

If the method fails, the return value can be D3DMERR_INVALIDCALL (see D3DMERR Values).

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dm.h.
Link Library: D3dm.lib, D3dmguid.lib.
