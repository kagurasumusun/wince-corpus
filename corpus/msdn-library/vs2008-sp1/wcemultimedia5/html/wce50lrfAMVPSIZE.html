AMVPSIZE

This structure specifies the width and height for a VP image. 

typedef struct _AMVPSIZE{
  DWORD dwWidth;
  DWORD dwHeight;
} AMVPSIZE, *LPAMVPSIZE;

Members

dwWidth
Width, in pixels.
dwHeight
Height.

Remarks

The context could be anything such as scaling, cropping, and so on.
