IImageDecoder::GetImageInfo

This method is used to obtain basic information about the image.

HRESULT GetImageInfo(
  ImageInfo* imageInfo
);

Parameters

imageInfo
[out] A pointer to an ImageInfo structure that is populated with information about the image.

This is the same information the decoder passes to IImageSink::BeginSink.

Return Values

If successful, this method returns S_OK.

This method may return E_FAIL if it fails.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Imaging.h.
Link Library: Imaging.lib.
