IDVDTitleSet::GetSpecVersion

This method returns the DVD specification version number (VERN) from the video title set information management table (VTSI_MAT).

HRESULT GetSpecVersion(
  UINT16* pVersion
);

Parameters

pVersion
[out] Pointer to the DVD-Video recording's VERN, taken from the VTSI_MAT.

Return Values

This method always returns S_OK.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
