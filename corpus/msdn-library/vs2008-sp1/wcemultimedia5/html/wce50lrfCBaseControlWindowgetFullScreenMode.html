CBaseControlWindow::get_FullScreenMode

Retrieves the current full-screen mode. 

HRESULT get_FullScreenMode(
  long* FullScreenMode
);

Parameters

FullScreenMode
Current full-screen mode.

Return Values

Returns an HRESULT value.

Remarks

This member function returns E_NOTIMPL by default.

This informs the IVideoWindow plug-in distributor that this renderer does not implement a full-screen renderer.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 3.0 and later.
