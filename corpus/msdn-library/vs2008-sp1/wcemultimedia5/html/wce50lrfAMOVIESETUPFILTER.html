AMOVIESETUP_FILTER

This structure contains filter information for registering a filter. 

typedef struct _AMOVIESETUP_FILTER{
  const CLSID* clsID;
  LPWSTR strName;
  DWORD dwMerit;
  UINT nPins;
  LPAMOVIESETUP_PIN lpPin;
} AMOVIESETUP_FILTER

Members

clsID
Class identifier of the filter.
strName
Name of the filter.
dwMerit
Merit used by the IGraphBuilder interface when constructing a filter graph.
nPins
Number of pins on the filter.
lpPin
AMOVIESETUP_PIN structure providing pin information.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
Header: Dshow.h.
