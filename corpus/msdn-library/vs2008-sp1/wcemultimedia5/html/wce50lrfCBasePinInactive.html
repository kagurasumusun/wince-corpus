CBasePin::Inactive

Switches the pin to an inactive state. 

virtual HRESULT Inactive(void);

Parameters

None.

Return Values

Returns NOERROR for a base class implementation.

The overriding member function returns a standard HRESULT value and should not fail if the pin is set as inactive.

Remarks

This member function is called by the IMediaFilter implementation when the state changes to inactive.

This member function should be overridden to decommit allocators and free hardware resources obtained in the CBasePin::Active call.

The default implementation of the base class member function does nothing.

The filter graph manager's internal state variable is not updated until after this member function returns, so avoid testing the filter graph manager's state (directly or indirectly) from within this member function.

Requirements

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
