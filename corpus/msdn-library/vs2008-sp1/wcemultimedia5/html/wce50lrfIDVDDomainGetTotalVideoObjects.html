IDVDDomain::GetTotalVideoObjects

This method returns the count of video objects (VOB) and cell pieces in the current domain.

HRESULT GetTotalVideoObjects(
  UINT16* pTotalVobs,
  UINT32* pCellPieceCount
);

Parameters

pTotalVobs
[out] Pointer to the VOB count for the current domain.
pCellPieceCount
[out] Pointer to the number cell pieces in the current domain.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be the following error value.

Error value Description
E_NOINTERFACE The method was unable to obtain and return an interface pointer.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
