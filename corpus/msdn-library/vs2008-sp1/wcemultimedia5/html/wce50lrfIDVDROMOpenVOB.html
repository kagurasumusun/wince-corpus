IDVDROM::OpenVOB

This method opens the video object (VOB) for the requested video title set number (VTSN). This method is used internally by the DVD-Video API and is not generally used by applications.

HRESULT OpenVOB(
  UINT16* hVOB,
  INT16 obVTSN
);

Parameters

hVOB
[out] Address of the VOB handle.
obVTSN
[in] Requested VTSN.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be one of the following error values.

Error value Description
E_INVALIDARG One or more arguments is invalid.
E_HANDLE The method encountered an invalid handle.
E_ACCESSDENIED General access denied error.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
