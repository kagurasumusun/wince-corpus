IVideoWindow::GetMinIdealImageSize

This method retrieves the ideal minimum image size for the video image playback (client) area. 

HRESULT GetMinIdealImageSize(
  long* pWidth,
  long* pHeight
);

Parameters

pWidth
[out] Image width.
pHeight
[out] Image height.

Return Values

Returns an HRESULT value.
