IEnumDVD_CELL_PIECE

This interface is used to enumerate lists of DVD_CELL_PIECE structures.

IEnumDVD_CELL_PIECE is an IEnumDVD_XXXX interface and therefore has the standard methods as all such interfaces: Next, Skip, Reset, and Clone.

Remarks

You can obtain a pointer to an IEnumDVD_CELL_PIECE interface in the following ways:

  • By calling the IUnknown::QueryInterface method of a DVDData object and specifying the IID_IEnumDVD_CELL_PIECE interface identifier, see DVD-Video API Interface Identifiers.
  • By calling the IDVDDomain::GetCellPieceEnumerator method.
  • By calling an existing IEnumDVD_CELL_PIECE interface's Clone method.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
