waveOutGetID

This function gets the device identifier for a waveform output device.

MMRESULT waveOutGetID(
  HWAVEOUT hwo, 
  LPUINT puDeviceID 
);

Parameters

hwo
Handle to the waveform-audio output device.
puDeviceID
Pointer to a variable to be filled with the device identifier.

Return Values

One of the values described in the following table is returned.

Value Description
MMSYSERR_NOERROR Success.
MMSYSERR_INVALHANDLE The hwo parameter specifies an invalid handle.
MMSYSERR_NODRIVER No device driver is present.
MMSYSERR_NOMEM Unable to allocate or lock memory.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Mmsystem.h.
Link Library: Coredll.lib.
