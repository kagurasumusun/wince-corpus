CanSeekToMarkers

This property indicates whether markers in the file can be located with a seek operation. This property is read-only.

Compatibility: Windows Media Player

[ bSeekToMarkers = ] MediaPlayer.CanSeekToMarkers

Parameters

bSeekToMarkers
Boolean value specifying whether markers in the file can be located with a seek operation. If true, the file can seek to markers. There is no default value.

Remarks

You can seek to a marker only if the file contains markers and is either stored locally or on a Windows Media server (for example, not on an HTTP server or broadcast by using multicast routing).

The value of this property is false if the FileName property is not set.

Requirements

OS Versions: Windows CE 3.0 and later.
