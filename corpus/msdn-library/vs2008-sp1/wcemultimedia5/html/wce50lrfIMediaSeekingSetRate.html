IMediaSeeking::SetRate

This method sets a new playback rate. 

HRESULT SetRate(
  double dRate
);

Parameters

dRate
[in] New rate, where 1 is the normal rate, 2 is twice as fast, and so on.

Return Values

Returns an HRESULT value that depends on the implementation of the interface.

The default DirectShow implementation returns S_OK for success, E_INVALIDARG if the parameter is invalid, or E_NOTIMPL if the method is not implemented.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

Pocket PC Platforms: Windows Mobile 5.0 and later
Smartphone Platforms: Windows Mobile 5.0 and later
