First Play in DVDSample

When DVDSample is launched, it immediately begins playing back the program chain (PGC) in the disc's first play domain (FP_DOM).

The following list shows the steps that DVDSample takes leading up to first play, assuming that all HRESULT values and other indicators are positive and no error handling is required.

  • CApp::InitInstance is called.
  • The CAppState object is instantiated and initialized.
  • CDvdCore is instantiated with the m_pCallback parameter containing a pointer to the CAppState object cast to an IDvdCallback interface. This sets m_fFirstPlay and m_fShowWindow both to TRUE.
  • CDvdCore::Init is called.
  • Within CDvdCore::Init, CDvdCore::InitDVDInterfaces obtains a pointer, m_pAnnexJ, to an IDVDUserOperation interface.
  • Within CDvdCore::Init, CDvdCore::InitInternalObjects is called.
  • The CDevMon object is instantiated within CDvdCore::InitInternalObjects.
  • The CDevMon object is initialized with call to CDevMon::Init.
  • The monitoring thread is created within CDevMon::Init.
  • Execution in the monitoring thread begins in CDevMon::ThreadProc.
    • While CDevMon::ThreadProc executes on the new thread, CDvdCore::InitMessageSink is called on the original thread.
    • Within CDvdCore::InitMessageSink, a new window is created with CDvdCore::WndProc as the message processor.
  • CDevMon::ThreadProc receives an initial notification about the status of the DVD drive. Assuming this is successful, CDevMon::Notify is called.
  • CDevMon::Notify posts a WM_DVD_DriveReady message to CDvdCore::WndProc.
  • The message handler within CDvdCore::WndProc calls CDvdCore::OnDvdDriveReady and passes the value TRUE.
  • CDvdCore::OnDvdDriveReady sets the window created in CDvdCore::InitMessageSink as the message window for the CDevMon object
  • CDvdCore::OnDvdDriveReady calls CDvdCore::LoadDvd to bind the DVD-Video API DVDData and DVDNavigator objects to the DVD drive. LoadDvd returns a presumably successful HRESULT.
  • CDvdCore::OnDvdDriveReady calls m_pCallback->OnDvdDriveReady where m_pCallback is a pointer to the CAppState object.
  • CAppState::OnDvdDriveReady posts an ID_PLAYBACK_PLAY message to the main application window.
  • The ID_PLAYBACK_PLAY message is handled by CApp::WndProc resulting in a call to CDvdCore::Play.
  • CDvdCore::Play calls CDvdVideo::Start. This sets up the overlay window if the Windows CE device's display adapter is capable of supporting it.
  • CDvdCore::Play calls IDVDUserOperation::TitlePlay(0) through the m_pAnnexJ pointer.
