CBaseFilter::GetSyncSource

Retrieves the current reference clock in use by this filter. 

HRESULT GetSyncSource(
  IReferenceClock** pClock
);

Parameters

pClock
Pointer to a reference clock; will be set to the IReferenceClock interface.

Return Values

Returns an HRESULT value.

Remarks

This member function implements the IMediaFilter::GetSyncSource method.

It returns the value of m_pClock after adding a reference to it.

Release the interface by calling the IUnknown::Release method when finished with the pointer.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 3.0 and later.
