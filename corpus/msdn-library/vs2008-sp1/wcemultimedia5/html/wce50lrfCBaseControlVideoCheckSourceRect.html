CBaseControlVideo::CheckSourceRect

Determines if a source rectangle is valid. 

virtual HRESULT CheckSourceRect(
  RECT* pSourceRect
);

Parameters

pSourceRect
Source rectangle to check.

Return Values

Returns E_INVALIDARG if not valid; otherwise, returns NOERROR (S_OK).

Remarks

This member function checks that the source rectangle requested does not exceed the available source video.

The left and top coordinates cannot be negative, and the width and height cannot exceed the right and bottom of the video.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
