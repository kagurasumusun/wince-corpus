CMediaSample::SetPointer

Sets the buffer pointer and length. 

SetPointer(
  BYTE* ptr,
  LONG cBytes 
);

Parameters

ptr
Pointer to a buffer.
cBytes
Length of the buffer, in bytes.

Return Values

None.

Remarks

Allocators that require variable-sized pointers or pointers into data that has already been read use this member function.

This is available only through a CMediaSample class, not an IMediaSample interface, so only the filter that owns the allocator knows how to access this member function (not any filter or pin that is passed the object's IMediaSample interface pointer).

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
