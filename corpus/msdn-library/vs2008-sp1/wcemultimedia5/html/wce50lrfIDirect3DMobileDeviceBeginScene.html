IDirect3DMobileDevice::BeginScene

This method begins a scene.

HRESULT BeginScene();

Parameters

None.

Return Values

If the method succeeds, the return value is D3DM_OK (see D3DM Values).

If the method fails, the return value can be D3DERR_INVALIDCALL (see D3DMERR Values).

Remarks

Applications must call this method before performing any rendering and must call IDirect3DMobileDevice::EndScene when rendering is complete and before calling IDirect3DMobileDevice::BeginScene again.

If the IDirect3DMobileDevice::BeginScene method fails, the device was unable to begin the scene, and there is no need to call the IDirect3DMobileDevice::EndScene method. In fact, calls to IDirect3DMobileDevice::EndScene will fail if the previous call to IDirect3DMobileDevice::BeginScene failed.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dm.h.
Link Library: D3dm.lib, D3dmguid.lib.
