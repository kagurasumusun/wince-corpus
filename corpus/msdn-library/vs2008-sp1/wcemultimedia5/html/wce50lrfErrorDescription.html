ErrorDescription

This property contains the description of the current error state. This property is read-only.

Compatibility: Windows Media Player

[ "sError" = ] MediaPlayer.ErrorDescription

Parameters

sError
String value specifying the description of the current error state. There is no default value.

Requirements

OS Versions: Windows CE 3.0 and later.
