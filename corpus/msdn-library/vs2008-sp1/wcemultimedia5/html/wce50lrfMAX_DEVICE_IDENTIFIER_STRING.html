MAX_DEVICE_IDENTIFIER_STRING

This macro is the value representing the maximum string length, in bytes, of a device identifier.

#define MAX_DEVICE_IDENTIFIER_STRING        512

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dmtypes.h.
