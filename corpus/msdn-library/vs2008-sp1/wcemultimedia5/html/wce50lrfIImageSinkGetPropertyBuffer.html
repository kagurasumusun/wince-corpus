IImageSink::GetPropertyBuffer

This method is used to obtain a buffer from the image sink that the image source can fill with property data about the image. 

HRESULT GetPropertyBuffer(
  UINT            uiTotalBufferSize,
  PropertyItem**  ppBuffer
);

Parameters

uiTotalBufferSize
[in] A UINT value specifying the total size, in bytes, of property items associated with the image.
ppBuffer
[in, out] A pointer to a PropertyItem pointer representing the array of property items associated with the image.

Return Values

If successful, this method returns S_OK.

This method may return E_NOTIMPL if it fails.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Imaging.h.
Link Library: Imaging.lib.
