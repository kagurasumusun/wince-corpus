PIN_INFO

This structure contains information about a pin. 

typedef struct _PinInfo {
  IBaseFilter* pFilter;
  PIN_DIRECTION dir;
  WCHAR achName[128];
} PIN_INFO;

Members

pFilter
Pointer to the IBaseFilter interface of the owning filter.
dir
Direction of the pin (input or output).
achName[128]
Name of the pin.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

Pocket PC Platforms: Windows Mobile 5.0 and later
Smartphone Platforms: Windows Mobile 5.0 and later
OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
