MM_WOM_ATTENUATED

This message indicates that an audio stream is controlled by an audio gain class.

MM_WOM_ATTENUATED 
  wParam = (DWORD) dwAttenuation
  lParam = 0

Parameters

dwAttenuation
The attenuation value of the audio stream.
lParam
Reserved; must be zero.

Return Values

None.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Mmsystem.h.
