IDVDStreamControlInfo::GetBlockAddress

This method returns the navigation pack logical block number (NV_PCK_LBN) from the presentation control information general information (PCI_GI) for the current video object unit (VOBU).

HRESULT GetBlockAddress(
  UINT32* pLBN
);

Parameters

pLBN
[out] Pointer to the current NV_PCK_LBN.

Return Values

This method always returns S_OK.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
