GetBitmapSize

This function finds the number of bytes needed to hold an image. 

DWORD GetBitmapSize(
  const BITMAPINFOHEADER* pHeader
);

Parameters

pHeader
Pointer to a Win32 BITMAPINFOHEADER structure.

Return Values

Returns the number of bytes needed to hold an image.

Requirements
