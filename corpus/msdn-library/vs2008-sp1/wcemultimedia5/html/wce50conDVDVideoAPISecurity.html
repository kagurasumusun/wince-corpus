DVD-Video API Security

The DVD-Video API should be used with caution in environments that require high security.

The DVD-Video API exists to enable high-performance multimedia applications. It does this by providing applications with low-level access to DVD-Video decoding and display hardware.

The DVD-Video API omits many common security-oriented precautions to achieve higher multimedia performance. For example, the DVD-Video API does not perform such tasks as checking for buffer overruns or re-authenticating requests.

These implementation approaches and others can leave a DVD-Video API enabled platform open to security vulnerabilities.
