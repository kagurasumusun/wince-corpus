DVD-Video API Common Terms

The following table lists terms and abbreviations commonly encountered with the DVD-Video API and DVD technology.

Term Definition
COM Component Object Model.
DVD-Video API A set of COM interfaces for DVD-Video playback. This term is also used to refer to the middleware that these COM interfaces control.
DVD An acronym that does not actually stand for anything. Digital Video Disc and Digital Versatile Disc are two historical phrases commonly associated with DVD.
DVD-ROM DVD Read-Only Memory, which is the core format of DVD.
DVD-Video An encoding standard for high-quality digital video and audio on a disc format.
ISRC International Standard Recording Code.
ISV Independent software vendor.
NTSC National Television Systems Committee, which is the television standard used in the United States, Canada, and Japan.
OEM Original equipment manufacturer.
OSD On-screen display.
OSTA Optical Storage Technology Association.
PAL Phase Alternate Line, which is the television standard used in Europe.
PCI Presentation Control Information, which is data in the DVD-Video format for aspect ratios, angle changes menu highlights, timing, and so on.
STB Set-top box.
UDF Universal Disk Format.
