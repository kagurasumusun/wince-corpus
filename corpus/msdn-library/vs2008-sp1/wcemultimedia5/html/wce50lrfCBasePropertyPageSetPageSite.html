CBasePropertyPage::SetPageSite

This method initializes the property page and provides a pointer to the property frame's IPropertyPageSite interface. This method implements the IPropertyPage::SetPageSite method.

HRESULT SetPageSite(
  IPropertyPageSite* pPageSite
);

Parameters

pPageSite
Pointer to the IPropertyPageSite interface.

Return Value

Returns an HRESULT value. Possible values include the following.

Value Description
S_OK Success.
E_UNEXPECTED Unexpected failure.

Remarks

The method stores the pPageSite pointer in the CBasePropertyPage::m_pPageSite member variable.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
