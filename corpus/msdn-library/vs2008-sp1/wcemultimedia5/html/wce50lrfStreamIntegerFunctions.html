Stream Integer Functions

The Pstream.h header file in the DirectShow base classes contains a set of stream integer functions.

These functions encode an integer in a stream object as 11 Unicode characters followed by one Unicode space.

The interface to these functions might truncate to 32 bits.

Values such as (unsigned) 0x80000000 would be written as -2147483648, but still load as 0x80000000 again through ReadInt.

Programming element Description
ReadInt Reads a Unicode string-encoded integer from a stream.
WriteInt Writes an integer to a stream encoded as a Unicode string.
