CBasePropertyPage::OnActivate

This method is called when the property page is activated. 

virtual HRESULT OnActivate(void);

Return Value

The base-class implementation returns S_OK.

Remarks

The CBasePropertyPage::Activate method calls the CBasePropertyPage::OnActivate method. In your derived class, override CBasePropertyPage::OnActivate to initialize the dialog box.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
