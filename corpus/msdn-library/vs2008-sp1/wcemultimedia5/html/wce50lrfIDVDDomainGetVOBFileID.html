IDVDDomain::GetVOBFileID

This method returns the file ID of the current video object (VOB).

HRESULT GetVOBFileID(
  UINT16* pFileID 
);

Parameters

pFileID
[out] Pointer to the file ID of the current VOB.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be the following error value.

Error value Description
E_NOTIMPL The method is not implemented.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
