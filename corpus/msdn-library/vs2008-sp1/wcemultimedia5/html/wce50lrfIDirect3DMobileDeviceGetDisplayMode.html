IDirect3DMobileDevice::GetDisplayMode

This method retrieves the display mode's spatial resolution, color resolution, and refresh frequency.

HRESULT GetDisplayMode(
  D3DMDISPLAYMODE* pMode
);

Parameters

pMode
[out] Pointer to a D3DMDISPLAYMODE structure containing data about the display mode of the device.

Return Values

If the method succeeds, the return value is D3DM_OK (see D3DM Values).

If the method fails, the return value can be D3DMERR_INVALIDCALL (see D3DMERR Values).

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dm.h.
Link Library: D3dm.lib, D3dmguid.lib.
