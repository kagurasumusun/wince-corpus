IMediaObject::GetInputCurrentType

This method retrieves the media type that was set for an input stream, if any.

HRESULT GetInputCurrentType(
  DWORD dwInputStreamIndex,
  DMO_MEDIA_TYPE* pmt
);

Parameters

dwInputStreamIndex
Zero-based index of an input stream on the DMO.
pmt
[out] Pointer to a DMO_MEDIA_TYPE structure allocated by the caller. The method fills the structure with the media type.

Return Values

Returns an HRESULT value. Possible values include the following.

Value Description
S_OK Success
DMO_E_INVALIDSTREAMINDEX Invalid stream index
DMO_E_TYPE_NOT_SET Media type was not set
E_OUTOFMEMORY Insufficient memory

Remarks

The caller must set the media type for the stream before calling this method. To set the media type, call the IMediaObject::SetInputType method.

If the method succeeds, call MoFreeMediaType to free the format block.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Dmo.h.
Link Library: Dmoguid.lib.
