DVD_TEXT_ITEM

This structure contains item text search pointer (IT_TXT_SRP) data.

typedef struct _structDVD_TEXT_ITEM {
  UINT8* pTextData;
  UINT8 itemCode;
} DVD_TEXT_ITEM, *PDVD_TEXT_ITEM;

Members

pTextData
IT_TXT_SA element of IT_TXT_SRP.
itemCode
IT_TXT_IDCD element of IT_TXT_SRP.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
