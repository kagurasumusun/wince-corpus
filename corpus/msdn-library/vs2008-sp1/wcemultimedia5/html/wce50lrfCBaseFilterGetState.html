CBaseFilter::GetState

Retrieves the current state of the filter. 

HRESULT GetState(
  DWORD dwMilliSecsTimeout,
  FILTER_STATE* State
);

Parameters

dwMilliSecsTimeout
Duration of the time-out, in milliseconds.
State
Returned state of the filter.

Return Values

Returns S_OK.

Remarks

This member function implements the IMediaFilter::GetState method.

It returns the value of the m_State data member.

Override this member function if the state changes in your filter are not synchronous.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 3.0 and later.
