IImageSink::PushPropertyItems

This method is used by an image source to send a set of property items for an image to an image sink. 

HRESULT PushPropertyItems(
  UINT          numOfItems,
  UINT          uiTotalBufferSize,
  PropertyItem* item
);

Parameters

numOfItems
[in] A UINT value specifying the number of property items being sent to the image sink.
uiTotalBufferSize
[in] A UINT value specifying the total size, in bytes, of the buffer containing all property items being sent to the image sink.
item
[in] A pointer to an array of PropertyItem objects containing the data for property items being sent to the image sink.

Return Values

If successful, this method returns S_OK.

This method may return one E_NOTIMPL if it fails.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Imaging.h.
Link Library: Imaging.lib.
