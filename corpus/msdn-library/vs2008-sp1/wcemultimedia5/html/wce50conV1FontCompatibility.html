Platform Builder for Microsoft Windows CE 5.0  

V1 Font Compatibility

This Catalog item provides font compatibility for applications written for versions of Windows CE earlier than Windows CE 2.0. It allows you to set registry subkeys to override problematic fonts used in some of these applications.

For more information see Replacing OS Design Fonts.

Implementation Considerations

The following table shows the Sysgen variables that enable V1 font compatibility.

Sysgen variable Description
SYSGEN_GDI_FONTFIX Set this Sysgen to enable V1 font compatibility.

Modules and Components

The following table shows the components and modules that implement V1 font compatibility.

Item Module Component
V1 font compatibility mgfntfix None

Hardware Considerations

There are no special hardware considerations for V1 font compatibility.
