Windows Media Player Control Unsupported Items

Listed below are the methods, properties, and events in the Windows Media Player and ActiveMovie controls that are not currently supported on Windows CE. Attempting to access these items will not cause an error. Unsupported items are treated as described in Handling of Unsupported Items.
