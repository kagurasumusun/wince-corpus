IDVDVideoVolume::GetTitleSetAttributes

This method retrieves the video title set attributes (VTS_ATR) for a specified video title set (VTS).

HRESULT GetTitleSetAttributes(
  UINT16 vtsn,
  UINT32** pVTSCategory,
  IDVDStreamAttributes** ppVideoAttr
);

Parameters

vtsn
[in] Video Title Set number.
pVTSCategory
[out] Address of the category information for the specified VTS.
ppVideoAttr
[out] Address of the IDVDStreamAttributes interface pointer returned for the specified VTS.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be one of the following error values.

Error value Description
E_OUTOFMEMORY There was not enough memory available for the operation.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
