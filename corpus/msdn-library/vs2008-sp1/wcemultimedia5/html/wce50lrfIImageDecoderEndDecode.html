IImageDecoder::EndDecode

This method is used to stop the image codec from decoding the current frame.

HRESULT EndDecode(
  HRESULT statusCode
);

Parameters

statusCode
[in] An HRESULT value used to determine whether an error occurred while stopping the decode process.

If IImageDecoder::EndDecode encounters an internal error, the method returns an error value; otherwise, the method returns the value passed in with statusCode.

Return Values

See the definition of the statusCode parameter.

If successful, this method returns S_OK.

This method may return E_FAIL if it fails.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Imaging.h.
Link Library: Imaging.lib.
