Imaging Macros

The following list shows categories of macros and GUIDs associated with the Imaging API.

Macro Description
Error Codes for the Imaging API The standard error codes used throughout the Imaging API.
MAKEARGB Creates an ARGB value from alpha, red, green, and blue values.
PixelFormat Values Flags used to identify the numerical formats of pixels in images.
PropertyTag Values Values that correspond to metadata items supported by the Imaging API
PropertyTagType Values Used to identify the data type of an image's metadata.
