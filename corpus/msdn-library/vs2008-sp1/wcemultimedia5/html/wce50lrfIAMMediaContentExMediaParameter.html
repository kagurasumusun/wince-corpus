IAMMediaContentEx::MediaParameter

This method returns a value for a given parameter name and entry number.

HRESULT MediaParameter(
  long EntryNum,
  BSTR bstrName,
  BSTR* pbstrValue
);

Parameters

EntryNum
[in] Entry number in an ASX file containing the parameter being sought.
bstrName
[in] Name of the parameter in being sought in EntryNum. If you only have the index number of a parameter, you can use the IAMMediaContentEx::MediaParameterName method to retrieve the parameter's name.
pbstrValue
[out] Value of the parameter identified by EntryNum and bstrName.

Return Values

Returns an HRESULT value.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements. See Setting Up the Build Environment for more information.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
