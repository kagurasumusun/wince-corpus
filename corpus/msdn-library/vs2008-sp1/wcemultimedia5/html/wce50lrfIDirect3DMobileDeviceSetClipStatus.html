IDirect3DMobileDevice::SetClipStatus

This method is used to reset the internal data structures that a driver uses to monitor clipping operations on primitives. Calling this function allows the driver to start processing with a known starting value. The driver will then AND and OR the appropriate bits into the structure as primitives are processed.

HRESULT SetClipStatus(
  CONST D3DMCLIPSTATUS* pClipStatus
);

Parameters

pClipStatus
[in] A pointer to a D3DMCLIPSTATUS structure that contains the new clipping data for the driver to use.

Return Values

If the method succeeds, the return value is D3DM_OK (see D3DM Values).

If the method fails, the return value can be D3DMERR_INVALIDCALL (see D3DMERR Values).

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dm.h.
Link Library: D3dm.lib, D3dmguid.lib.
