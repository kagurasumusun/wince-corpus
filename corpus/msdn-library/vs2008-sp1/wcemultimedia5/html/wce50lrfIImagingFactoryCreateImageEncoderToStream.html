IImagingFactory::CreateImageEncoderToStream

This method creates and initializes an IImageEncoder interface to output to a stream in a specified image format.

HRESULT CreateImageEncoderToStream(
  const CLSID*    clsid,
  IStream*        stream,
  IImageEncoder** encoder
);

Parameters

clsid
[in] A pointer to a CLSID value that specifies the encoder's COM component.
stream
[in] A pointer to an IStream interface representing the output data stream.
encoder
[out] A pointer to the resulting IImageEncoder interface pointer.

Return Values

If successful, this method returns S_OK.

This method may return IMGERR_CODECNOTFOUND if it fails.

For more information, see Error Codes for the Imaging API.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Imaging.h.
Link Library: Imaging.
