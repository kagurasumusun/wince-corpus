AllowChangeDisplaySize

This property specifies whether the display size can be changed. This property is read/write.

Compatibility: Windows Media Player

MediaPlayer.AllowChangeDisplaySize [ = bAllowChange ]

Parameters

bAllowChange
Boolean value indicating whether the user can change the display size. If true, the user can change the display size. The default value is true.

Remarks

This property determines whether the DisplaySize property can be set at run time.

Requirements

OS Versions: Windows CE 3.0 and later.
