Hardware Audio Mixer Messages

The following table shows the messages that are used with audio mixers.

Programming element Description
MM_MIXM_CONTROL_CHANGE Notifies an application that the state of a control associated with an audio line has changed.
MM_MIXM_LINE_CHANGE Notifies an application that the state of an audio line on the specified device has changed.
