DefaultFrame

This property specifies the default target HTTP frame. This property is read/write.

Compatibility: Windows Media Player

MediaPlayer.DefaultFrame [ = "sFrame" ]

Parameters

sFrame
String value representing the default target HTTP frame.

Remarks

This property specifies which browser frame displays a new location when a URL-type ScriptCommand event occurs.

If the ScriptCommand event specifies the frame, however, the property is ignored.

Requirements

OS Versions: Windows CE 3.0 and later.
