D3DMCLEAR Values

The following table shows values that are flags that identify options for clearing various types of surfaces.

Value Description
D3DMCLEAR_TARGET Clears the render target.
D3DMCLEAR_ZBUFFER Clears the depth buffer.
D3DMCLEAR_STENCIL Clears the stencil buffer.
D3DMCLEAR_VALID     Used as a mask to validate combinations of the other flags.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dmtypes.h.
