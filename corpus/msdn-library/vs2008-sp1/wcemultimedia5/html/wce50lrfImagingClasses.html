Imaging Classes

The following list shows the classes associated with the Imaging API.

Class Description
BitmapData Used to create objects that contain information to describe pixel data for a rectangular area of bitmap images.
EncoderParameter Used to create objects that contain data describing the properties of an image encoder.
EncoderParameters Used to create objects that collect lists of parameters for an image encoder.
ImageCodecInfo Used to create objects that describe the characteristics of an image decoder or an image encoder.
PropertyItem Used to create objects that contain data describing image properties
