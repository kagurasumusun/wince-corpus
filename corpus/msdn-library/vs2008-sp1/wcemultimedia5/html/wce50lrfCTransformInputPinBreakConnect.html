CTransformInputPin::BreakConnect

Informs the derived class when the connection is broken. 

HRESULT BreakConnect( );

Parameters

None.

Return Values

Returns NOERROR in this implementation.

Remarks

This member function overrides the CBasePin::BreakConnect member function and calls the CTransformFilter::BreakConnect member function.

Override CTransformFilter::BreakConnect to undo anything carried out in CTransformInputPin::CheckConnect (such as releasing extra interfaces).

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements.

For more information, see Setting Up the Build Environment.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
