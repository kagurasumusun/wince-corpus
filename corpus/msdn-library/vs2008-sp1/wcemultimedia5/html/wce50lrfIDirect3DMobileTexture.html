IDirect3DMobileTexture

This interface is the primary interface for working with texture map objects in Direct3D Mobile. It derives from IDirect3DMobileBaseTexture and adds the ability to lock levels of the texture map, as well as access to the dirty rectangle mechanism that is used by the automatic texture update functionality. The Direct3D Mobile middleware will track, at the most, six dirty rectangles before dirtying an entire surface.

Obtaining a Pointer

You can obtain a pointer to an IDirect3DMobileTexture interface by calling the IDirect3DMobileDevice::CreateTexture method.
