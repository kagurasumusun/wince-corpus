IDVDROM::CloseVOB

This method closes the video object (VOB). This method is used internally by the DVD-Video API and is not generally used by applications.

HRESULT OpenVOB(
  UINT16 hVOB
);

Parameters

hVOB
[out] VOB handle.

Return Values

If the function succeeds, the return value is S_OK.

If the method fails, the return value may be the following error value.

Error value Description
E_INVALIDARG One or more arguments is invalid.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
