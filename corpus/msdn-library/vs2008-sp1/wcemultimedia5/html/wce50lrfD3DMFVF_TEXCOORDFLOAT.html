D3DMFVF_TEXCOORDFLOAT

This macro sets the numerical format of a specified texture coordinate set in a flexible vertex format (FVF) to be IEEE 32-bit floating point values.

#define D3DMFVF_TEXCOORDFLOAT(CoordIndex) (D3DMFVF_TEXCOORDFORMAT_FLOAT)

Parameters

CoordIndex
An integer value identifying a texture coordinate set in an FVF.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dmtypes.h.
