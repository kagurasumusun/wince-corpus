Media Formats

The following table shows the media formats available for Windows CE. All of these formats are dependent on DirectShow.

Codec or Renderer Sysgen variable
AVI Filter SYSGEN_DSHOW_AVI
MPEG-1 Parser/Splitter SYSGEN_DSHOW_MPEGSPLITTER

The specific set of media formats supported by a Windows CE-based device is determined when the OS design is created. An OS design can contain all, some, or none of these media formats.
