EC_SHUTTING_DOWN

The shutdown of the filter graph is starting.

Parameters

lParam1
Zero.
lParam2
Zero.

Remarks

This event notification is not sent to the application.

This notification notifies plug-in distributors that the filter graph is shutting down.

For information on how to use this event code, see CBaseFilter::NotifyEvent.
