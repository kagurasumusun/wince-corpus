IDVDUserOperation::ButtonSelect

This method applies the select action for the button specified by byteDirection.

HRESULT ButtonSelect(
  BYTE byteDirection
);

Parameters

byteDirection
[in] Indicates the button action to take.
Value Button
DVD_SELECT_UPPER Indicates the upper button.
DVD_SELECT_RIGHT Indicates the right button.
DVD_SELECT_LOWER Indicates the lower button.
DVD_SELECT_LEFT Indicates the left button.

Return Values

If the function succeeds, the return value is S_OK.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdnav.h, Dvdnav.idl.
Link Library: Ddvdids.lib.
