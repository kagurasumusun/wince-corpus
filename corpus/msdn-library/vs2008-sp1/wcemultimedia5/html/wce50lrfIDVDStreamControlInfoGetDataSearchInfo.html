IDVDStreamControlInfo::GetDataSearchInfo

This method returns the IDVDDataSearchInfo interface for the current video object unit's (VOBU) navigation pack (NV_PCK).

HRESULT GetDataSearchInfo(
  IDVDDataSearchInfo** ppDSI
);

Parameters

ppDSI
[out] Pointer the IDVDDataSearchInfo interface for the current VOBU.

Return Values

If this method succeeds, the return value is S_OK.

If this method fails, the return value may be one of the following error values.

Error value Description
E_INVALIDARG One or more arguments are invalid.
E_NOINTERFACE The method was unable to obtain and return an interface pointer.
E_OUTOFMEMORY There was not enough memory available for the operation.
E_POINTER The returned pointer is invalid.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
