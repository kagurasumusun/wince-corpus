IAMMediaContent::get_WatermarkURL

This method retrieves a URL for the watermark.

HRESULT get_WatermarkURL(
  BSTR* pbstrWatermarkURL
);

Parameters

pbstrWatermarkURL
[out] Pointer to a variable that receives a BSTR with the information.

Return Values

Returns an HRESULT value. Possible values include those shown in the following table.

Value Description
S_OK Success.
E_NOTIMPL Not implemented.
E_OUTOFMEMORY Insufficient memory.
VFW_E_NOT_FOUND Item not found.

Remarks

If the method succeeds, the caller must free the returned BSTR by calling the SysFreeString function.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements. See Setting Up the Build Environment for more information.

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
Header: Dshow.h, Initguid.h, Qnetwork.h.
