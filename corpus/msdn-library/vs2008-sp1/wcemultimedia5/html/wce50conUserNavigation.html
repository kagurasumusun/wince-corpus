User Navigation

The DVD-Video API provides several interfaces for working with DVD-Video menus.

You can used the IDVDUserOperation::MenuCall method to allow the user to access the various menus in the DVD-Video data.

The IDVDVideoVolume and IDVDTitleSet interfaces both have methods that allow you to get the menu for the DVD-Video volume and the current title set, respectively.

The IDVDMenu interface provides your application with a way to get language and domain information for a particular menu.
