D3DMCURRENT_DISPLAY_MODE

This macro is a value used to identify the current mode when calling IDirect3DMobile methods that enumerate properties or retrieve capability bits.

#define D3DMCURRENT_DISPLAY_MODE                 0x00EFFFFF

Requirements

OS Versions: Windows CE 5.0 and later.
Header: D3dm.h.
