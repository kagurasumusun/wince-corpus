Waveform Audio Samples

The following table shows the sample applications available for waveform audio. The source code for all waveform audio sample applications is located in %_PUBLICROOT%\COMMON\SDK\SAMPLES\AUDIO\.

Sample Description
Capsrc Shows how to use the hardware audio mixer to select and adjust the volume on the audio capture source.
Wavplay Shows how to play a sound from a waveform audio file.
Wavrec Shows how to record a sound and save it as a waveform audio file.
