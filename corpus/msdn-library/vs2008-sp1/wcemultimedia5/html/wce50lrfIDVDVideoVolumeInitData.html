IDVDVideoVolume::InitData

This method initializes the volume data.

HRESULT InitData(
  IDVDROM* pDisk 
);

Parameters

pDisk
[in] Address of the DVD-Video resource.

Return Values

If the function succeeds, the return value is S_OK or S_FALSE.

If the method fails, the return value may be one of the following error values.

Error value Description
E_FAIL The method failed.
E_HANDLE The method encountered an invalid handle.
E_OUTOFMEMORY There was not enough memory available for the operation.
E_UNEXPECTED The method encountered an unexpected error.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdata.h, Dvdata.idl.
Link Library: Ddvdids.lib.
