Platform Builder for Microsoft Windows CE 5.0  

Accessibility in the IDE

Microsoft® Windows® CE 5.0 includes options that allow persons with disabilities to use Platform Builder more easily. Many users require special accommodation because of temporary or permanent disabilities, the natural effects of aging, or the environment where they work.

Functionality that you can configure in the Platform Builder integrated development environment (IDE) includes the following:

  • Shortcut keys for menu options and commands

    For more information, see Shortcut Keys.

  • Font configuration

    For more information, see Changing Font Style, Size, or Color.

  • Configuration of toolbar button style, size, image, or placement

    For more information, see Toolbar Button and Menu Command Customization.

  • Screen reader compatible menus

    For more information, see Displaying Permanently the Text-based Menu Bar That Is Compatible with a Screen Reader.

Windows CE 5.0 is also compatible with accessibility options included in the Windows desktop OS, such as high-contrast mode, sound sentry, and mouse keys.
