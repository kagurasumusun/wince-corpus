Platform Builder for Microsoft Windows CE 5.0  

Tutorials

To assist you in getting started with Microsoft® Platform Builder 5.0 and demonstrate the capabilities of the integrated development environment (IDE), the following tutorials are provided.

Tutorial Description
Tutorial: Building a Run-Time Image for the Emulator Shows how to create a run-time image based on a custom OS design and then boot the run-time image on the Emulator.

The Emulator does not require additional hardware because the Emulator runs on the development workstation.
Tutorial: Building a Run-Time Image for a CEPC Shows how to create a custom run-time image based on a custom OS design and then boot the run-time image on a Microsoft Windows® CE PC-based hardware platform (CEPC).

A CEPC is an x86-based desktop computer that runs Windows CE–based applications and device drivers.

For information about building a CEPC, see How to Set up a CEPC.
Tutorial: Creating a Catalog Item and Adding It to an OS Design Shows how to create a custom Catalog item and add that item to the Catalog.

This tutorial also shows how to use the Platform Builder integrated development environment (IDE) to include the Catalog item in an OS design.
