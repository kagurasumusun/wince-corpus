Platform Builder for Microsoft Windows CE 5.0  

Getting Assistance

Microsoft® Windows® CE 5.0 provides a variety of ways for you to find information about programming tasks, operating system design, available drivers, and other aspects of Windows CE development. In Windows CE, you will also find links to information about context-sensitive Help, product support, Help updates, community resources, and training.

Product documentation is available from the Document Explorer Help browser in Microsoft Platform Builder. From the Help browser, you can locate specific topics and learn about additional forms of assistance.

To open the Document Explorer Help browser

  1. In Platform Builder, from the Help menu, choose one of these commands to open Document Explorer:
    • Contents
    • Search
    • Index
    • How-To Topics
  2. For information about using Document Explorer, choose Help on Help from the Help menu in Document Explorer.

The following table shows the Help features in Windows CE and how to locate them.

Feature Description To locate
Accessibility Provides information about how to set up your Platform Builder integrated development environment (IDE) to accommodate people with special needs, such as those with impaired vision. In product Help, see Accessibility in the IDE.
Contents Lists all topics currently available for viewing in Help, organized by development tasks and Windows CE features.

Contents in Help corresponds to a table of contents in a printed publication.

 In Platform Builder or Document Explorer, choose Contents from the Help menu.

For more information, choose Help on Help from the Help menu in Document Explorer.
Context-sensitive Help Opens Help for dialog boxes and windows, Windows CE Test Kit (CETK) tests, and Catalog items.
  • In a Platform Builder dialog box or window, press the F1 key or choose the Help button.

    To see a list of Help topics for dialog boxes and windows, see Context-Sensitive Help.

  • In the Windows CE Test Kit window, right-click on a CETK test in the tree view control, and then choose Test Information.
  • In the Platform Builder Catalog, choose a Catalog item, and then press the F1 key.

    - or –

    Right-click on a Catalog item, and then choose Help.

Favorites Saves a list of links to Help topics you have identified for subsequent viewing. Choose Help on Help from the Help menu in Document Explorer.
Feedback to Microsoft Allows you to use the Send Feedback link at the top and bottom of any Help topic to submit feedback on product Help. In product Help, see Questions About Submitting Feedback.
Filters Reduces the list of individual topics displayed in Contents, keywords shown in the Index, and topics queried during a full-text search. In the product Help, see Help Filters.
Help updates Provides updates to Windows CE Help for downloading or for viewing in the MSDN Library. In the product Help, see Online Resources.
Index Uses a keyword to find indexed topics in Help associated with that word.

In Windows CE 5.0, the Index primarily includes keywords for programming elements.

 In Platform Builder or Document Explorer, choose Index from the Help menu.

For more information, choose Help on Help from the Help menu in Document Explorer.
Online resources Describes Windows CE newsgroups, the Microsoft online community, Quick Fix Engineering (QFE) documents about Windows CE, the MSDN® online library, and newsgroup resources. In the product Help, see Online Resources.
Product Help Provides a collection of Help topics that provide information about embedded development tasks. In Platform Builder, choose Contents, Search, Index, or How-To Topics from the Help menu.

-or-

In Document Explorer, choose Contents, Index, or Search from the Help menu.

Product support Provides links to technical support resources available online and by telephone. In product Help, see Product Support.

-or-

See this Microsoft Web site.
Search Uses text strings to search all Help topics or a filtered subset of topics. In Platform Builder or Document Explorer, choose Search from the Help menu.

For more information, choose Help on Help from the Help menu in Document Explorer.
Shortcut keys Provides keyboard equivalents for many Platform Builder development tasks. In Platform Builder, choose Keyboard Map from the Help menu.
Start page Provides links to Help topics and online resources. In Platform Builder, choose Start Page from the Help menu.
Terminology Provides definitions for terms that have changed or are widely used in Windows CE 5.0. In the product Help, see Terminology.
Tutorials Provides step-by-step lessons about how to use Platform Builder. Some tutorials are available in Help and others are available online. In the product Help, see Tutorials. Online, see this Microsoft Web site.
