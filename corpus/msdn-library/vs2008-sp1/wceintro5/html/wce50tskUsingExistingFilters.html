Using Existing Filters

The Document Explorer Help browser includes filters that you can use without modification. The following list shows the types of filters that are included:

  • Filters for major development tasks, such as debugging and testing.
  • Filters for common operating system (OS) design templates, such as IP Phone.
  • Filters for specific types of product Help, such as how-to topics.

To activate an existing Help filter

  • In Document Explorer, from the Filtered by drop-down list, select the name of the filter that you want to apply.

To deactivate a Help filter

  • In Document Explorer, from the Filtered by drop-down list, select (no filter).

For information about creating a custom Help filter, see Creating a Custom Filter.
