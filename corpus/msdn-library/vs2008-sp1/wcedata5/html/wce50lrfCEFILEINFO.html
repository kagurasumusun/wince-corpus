CEFILEINFO

This structure contains information about a file object. 

typedef struct _CEFILEINFO {
  DWORD dwAttributes; 
  CEOID oidParent; 
  WCHAR szFileName[MAX_PATH]; 
  FILETIME ftLastChanged; 
  DWORD dwLength; 
} CEFILEINFO;

Members

dwAttributes
The attributes of the file.
oidParent
Object identifier of the parent directory.
szFileName
Null-terminated string that contains the name and path of the file.
ftLastChanged
Time stamp that indicates when the contents of the file were last changed.
dwLength
The length, in bytes, of the file.

Remarks

Earlier versions of Windows CE assigned object identifiers to objects in other file systems, such as the FAT file system. These object identifiers were guaranteed to be unique within a volume, but not across multiple volumes. In Windows CE 3.0 and later, only objects in the object store have valid, unique object identifers and the object store is the only volume that can return an object identifier.

Requirements

OS Versions: Windows CE 1.01 and later.
Header: Windbase.h.
