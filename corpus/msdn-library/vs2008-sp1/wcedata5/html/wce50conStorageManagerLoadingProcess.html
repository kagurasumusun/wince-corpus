Storage Manager Loading Process

The following steps show how the Storage Manager loads a block device:

  1. The Device Manager loads the block driver.
  2. The device sends an attach notification using the GUID from the registry.
  3. The Storage Manager recognizes the GUID and requests the profile information from the block driver.
  4. The Storage Manager looks up the profile information for the device and loads the appropriate partition driver.
  5. The Storage Manager enumerates the partitions.
  6. The Storage Manager loads the FSDs based on the partition type.
  7. The Storage Manager keeps loading FSDs until all partitions are loaded.
