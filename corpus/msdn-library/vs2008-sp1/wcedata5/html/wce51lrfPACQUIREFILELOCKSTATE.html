PACQUIREFILELOCKSTATE

This data type is a pointer to a function implemented by an FSD. Used by Lock Manager to get the file/lock state associated with the specified file when a lock is being modified.

typedef VOID (*PACQUIREFILELOCKSTATE)(
    DWORD dwFile,
    PFILELOCKSTATE* ppFileLockState
    );

Parameters

dwFile
[in] File handle context passed to FSDMGR_InstallFileLockState. This should be the pointer to the value that the FSD passed to the FSDMGR_CreateFileHandle function when the file handle was created.
ppFileLockState
[out] Returns a pointer to a pFileLockState structure associated with the file referenced by the handle context, dwFile.

Return Values

None.

Remarks

This function is required to enter the PFILELOCKSTATE critical section, lpcs, before returning the PFILELOCKSTATE structure to the caller.

Before returning the PFILELOCKSTATE structure to the caller, the function should update the dwPosLow/dwPosHigh and dwAccess members based on the current file pointer and access mode of the handle context referenced by dwFile.

The following eample shows a simple implementation:

BOOL MyAcquireFileLockState(DWORD dwPfh, PFILELOCKSTATE *ppFileLockState)
{
    PFILE pFileHandle = (PFILE)dwPfh;
    PINTERNALFILE pFile = pFileHandle->pInternalFile;

    if (NULL == pFile->FileLockState.lpcs) 
    {
        return FALSE;
    }    

    // acquire file lock state; exit in MyReleaseFileLockState
    EnterCriticalSection(pFile->FileLockState.lpcs);

    // fetch file position (64-bit offsets not supported)
    pFile->FileLockState.dwPosLow = pFileHandle->dwCurrentFileOffset;
    pFile->FileLockState.dwPosHigh = 0;

    // fetch create access
    pFile->FileLockState.dwAccess = pFileHandle->dwAccessMode;

    // return file lock container
    *ppFileLockState = &pFile->FileLockState;

    return TRUE;
}

This function is a Lock Manager function provided by FSDMGR to assist FSDs with implementing MyFSD_LockFileEx and MyFSD_UnlockFileEx.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: lockmgrtypes.h.
Link Library: Fsdmgr.lib.
