TFAT Write Operations

By default, only modifications to a directory and the FAT are backed up during a transaction using TFAT. To back up modifications to the data of a file, you must use the FATFS_TRANS_DATA registry flag. If this flag is used in combination with the FILE_FLAG_WRITE_THROUGH flag, all successful write operations are committed.

Note   A decrease in performance will occur due to additional copy operations.

The following table shows the behavior of the various combinations of the FATFS_TRANS_DATA and FILE_FLAG_WRITE_THROUGH flags if two successful WriteFile operations are followed by an interrupted WriteFile operation.

Flags Behavior
FATFS_TRANS_DATA not set

FILE_FLAG_WRITE_THROUGH not set

 Unknown. A partial write of the first, second, or third operation could occur. It is also possible that none or all of the operations could have been committed.
FATFS_TRANS_DATA not set

FILE_FLAG_WRITE_THROUGH set

 The first and second write operations are committed. The third operation could be committed, partially committed, or not committed.
FATFS_TRANS_DATA set

FILE_FLAG_WRITE_THROUGH not set

 The first operation could be committed, the first and second operations could be committed, or all three operations could be committed. No partial write operations will occur.
FATFS_TRANS_DATA set

FILE_FLAG_WRITE_THROUGH set

 The first and second operations are committed. The third operation is either not committed or fully committed.
