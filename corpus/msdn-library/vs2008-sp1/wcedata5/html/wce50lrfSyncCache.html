SyncCache

This function updates the cache by reading from the disk for each cache block while maintaining the mapping between a cache block and a disk block.

DWORD SyncCache(
  DWORD dwCacheId, 
  PSECTOR_LIST_ENTRY pSectorList,
  DWORD dwNumEntries,
  DWORD dwSyncFlags
);

Parameters

dwCacheId
[in] Cache ID value returned by CreateCache.
pSectorList
[in] Pointer to a sector list describing ranges of sectors to sync.

If this value is set to NULL, the entire cache is synchronized.

dwNumEntries
[in] Number of entries in the sector list.

Set to zero if synchronizing the entire cache.

dwSyncFlags
Not used.

Return Values

Returns ERROR_SUCCESS on success.

Returns a Microsoft Win32 error code on failure.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Fsdmgr.h.
Link Library: Fsdmgr.lib.
