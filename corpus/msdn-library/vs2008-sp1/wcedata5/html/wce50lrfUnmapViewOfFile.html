UnmapViewOfFile

This function unmaps a mapped view of a file from the address space of the calling process.

BOOL UnmapViewOfFile( 
  LPCVOID lpBaseAddress 
);

Parameters

lpBaseAddress
[in] Pointer to the base address of the mapped view of a file that is to be unmapped. This value must be identical to the value returned by a previous call to the MapViewOfFile function.

Return Values

Nonzero indicates success. All dirty pages within the specified range are written lazily to disk. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

Although an application may close the file handle used to create a file-mapping object, the system holds the corresponding file open until the last view of the file is unmapped.

Requirements

OS Versions: Windows CE 1.01 and later.
Header: Winbase.h.
Link Library: Coredll.lib.
