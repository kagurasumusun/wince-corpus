RAM-Based Registry Setup

The RAM-based registry has no options and therefore requires no setup. The RAM-based registry uses the Default.fdf file that is created during the build process. On a cold boot, this file is open and the registry is created based on its contents. The .fdf file can contain duplicate entries in the file for the same data, but it will be the last entry written that will take precedence.
