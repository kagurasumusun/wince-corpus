TFAT Registry Settings

The FATFS is defined in the following registry settings.

[HKEY_LOCAL_MACHINE\System\StorageManager\FATFS]
"FriendlyName"="FAT FileSystem"
"Dll"="fatfsd.dll"
"Flags"=dword:00000024
"Paging"=dword:1
"CacheSize"=dword:0

Each block driver profile can have its own FATFS settings. For example:

[HKEY_LOCAL_MACHINE\System\StorageManager\Profiles\HDProfile] 
"Name"="IDE Hard Disk Drive"
[HKEY_LOCAL_MACHINE\System\StorageManager\Profiles\HDProfile\FATFS]
"EnableCacheWarm"=dword:0

Registry hive files are memory-mapped files, causing extremely slow performance with a registry hive on a TFAT volume.

Microsoft recommends the following registry setting for a hard drive and other media with non-atomic sector write operations.

[HKEY_LOCAL_MACHINE\System\StorageManager\Profiles\HDProfile\FATFS]
"Flags"=dword:00280014

Microsoft recommends the following registry setting for storage media with atomic sector write operations.

[HKEY_LOCAL_MACHINE\System\StorageManager\Profiles\<your profile name>\FATFS]
"Flags"=dword:00000014
