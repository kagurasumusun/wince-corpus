Default Registry Settings

Registry settings information is provided for each Windows CE feature, for example, in Cryptography Registry Settings. The default value of each registry setting is either the initial value assigned in the applicable registry (.reg) file or the value that is assumed if the value is not present in the registry. Default registry values also vary depending on the features that are included in your OS design.

Note   The registry values in Platform.reg override the default values specified in Project.reg and Common.reg. The registry values in Project.reg override the default values specified in Common.reg.

To view the actual registry values, see the applicable .reg files or use the remote registry editor. In Platform Builder, after creating the image, you can view the actual registry values in the Reginit.ini file in the %_FLATRELEASEDIR% directory.
