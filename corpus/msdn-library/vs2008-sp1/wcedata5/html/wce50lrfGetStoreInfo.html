GetStoreInfo

This function gets information about the store.

BOOL WINAPI GetStoreInfo(
  HANDLE hStore,
  PSTOREINFO pStoreInfo
);

Parameters

hStore
[in] Handle to the store returned from OpenStore.
pStoreInfo
[in, out] Pointer to a STOREINFO (Storage Manager) structure.

Return Values

Returns TRUE if successful, otherwise FALSE.

If the cbSize member of the STOREINFO structure is not set correctly, this function returns an error that indicates an invalid parameter.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Storemgr.h
Link Library: Storeapi.lib
