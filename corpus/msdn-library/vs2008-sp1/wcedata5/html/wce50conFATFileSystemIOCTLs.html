FAT File System OS IOCTLs

The following table shows the FAT file system IOCTLs with a description of the purpose of each.

Programming element Description
IOCTL_DISK_FORMAT_VOLUME This IOCTL is issued to FAT to format to perform a high level format of the volume.
IOCTL_DISK_SCAN_VOLUME This input/output control scans a disk volume for errors.
