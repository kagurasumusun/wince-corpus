Multilingual User Interface (MUI) Registry

With the Multilingual User Interface (MUI) registry, one registry entry can point to several localized strings with an active value that is based on current locale settings. The localized strings are kept in a resource section of a module, either a .dll or .exe file. The following example shows how to specify MUI registry values in your registry file.

"Folder"=mui_sz:"Sample.dll,#20"

In the above example, the localized version of the string is stored as resource #20 in the module Sample.dll. The value is stored in the registry as REG_MUI_SZ. To retrieve the value from the registry, an application must use the RegQueryValueEx function. The registry automatically locates the correct MUI module and loads the string. The string is then returned to the application as the correct value and the registry type is set to REG_SZ on return.

Use of the RegSetValueEx function overwrites the existing MUI value. If the MUI value is set with a REG_SZ value, the MUI value is replaced with the specified constant registry value. The new value is then used for all locale settings. An application must preset the registry type to REG_MUI_SZ prior to calling RegQueryValueEx to read the MUI specification string.
