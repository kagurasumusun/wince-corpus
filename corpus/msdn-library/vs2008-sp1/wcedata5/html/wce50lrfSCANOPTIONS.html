SCAN_OPTIONS

This structure contains options specified by clients of scan disk.

typedef struct _SCAN_OPTIONS {
  DWORD dwFlags;
  DWORD dwFatToUse;
} SCAN_OPTIONS, *PSCAN_OPTIONS;

Members

dwFlags
This member may be set to one or a combination of possible values. The following table shows the possible values for dwFlags.
Value Description
FATUTIL_SCAN_VERIFY_FIX Prompts the user to perform a fix. Only applicable to the UI version of FATUTIL.
FATUTIL_DISABLE_MOUNT_CHK Disables the operation to verify that the volume is currently mounted.
dwFatToUse
Indicates which FAT to use for scanning, one-based indexing.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Scandisk.h.
