SECTOR_LIST_ENTRY

This structure describes a series of logical sectors.

typedef struct _SECTOR_LIST_ENTRY {
  DWORD dwStartSector; 
  DWORD dwNumSectors; 
} SECTOR_LIST_ENTRY, *PSECTOR_LIST_ENTRY;

Members

dwStartSector
Starting sector in the series.
dwNumSectors
Number of sectors in the series.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Diskio.h
