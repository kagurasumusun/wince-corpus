PEMPTYLOCKCONTAINER

Function pointer type for a function that frees all blocked threads waiting to install a lock on a particular file. 

typedef VOID(*PEMPTYLOCKCONTAINER)(
    PFILELOCKSTATE pFileLockState
    );

Parameters

pFileLockState
[in] Pointer to a pFileLockState structure initialized by the FSDMGR_OpenFileLockState macro.

Return Values

None.

Remarks

A function pointer of this type is required by the FSDMGR_CloseFileLockState macro.

The FSDMGR_EmptyLockContainer helper function is of this type, and is typically passed to FSDMGR_CloseFileLockState.

This function is a Lock Manager function provided by FSDMGR to assist FSDs with implementing MyFSD_LockFileEx and MyFSD_UnlockFileEx.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Fsdmgr.h.
Link Library: Fsdmgr.lib.
