File System Secure Erase and Format

The file system secure erase and format operation allows you to securely erase all data, including previously stored data, from a FAT or TFAT volume. This enables the complete removal of all persistent data, ensuring that no remnants of data remain in remapped flash blocks or on unallocated blocks on a hard disk device.

To implement secure erase and format, the file system first calls the block driver to determine of it implements IOCTL_DISK_SET_SECURE_WIPE_FLAG. If the block driver implements this IOCTL, then MSFLASH implements the secure erase and format. If not, then FAT reformats the volume by passing the FATUTIL_SECURE_WIPE flag in the FORMAT_OPTIONS structure.

Once a secure erase and format operation is initiated, it continues until completion. This occurs even if the erase and format is repeatedly interrupted due to a reset or loss of power. Upon completion, no data remains on the physical storage device. For a flash media device, all unmapped physical blocks are erased in addition to the erasure of all logical blocks. For a hard disk device, a low-level format of the entire volume erases all data on the device.

A registry setting is used by the Storage Manager to determine if a secure erase and format or a traditional format operation is performed when a format request is initiated. The following registry entry enables the secure erase and format of a volume.

[HKEY_LOCAL_MACHINE\System\StorageManager\Profiles\<your profile name>\FATFS]
   "SecureWipe"=dword:1

A trusted application can also initiate a secure erase and format by calling the LoadLibrary function on Fatutil.dll.

The secure erase and format operation does not offer guaranteed protection against the physical removal of a storage device prior to completion. The secure erase and format of a hard drive does not perform multiple writes to blocks using repeat cycles or patterns. The format is a low-level format, ensuring that data that can be read from the device using a block driver is erased. A secure erase and format of multiple volumes occurs synchronously. It is not possible to designate multiple storage volumes for a secure erase and format simultaneously. Each volume must be securely erased and formatted individually.
