File Compression

Windows CE includes support for compression and automatically allocates 10K of RAM for decompression support. You can choose whether or not to include compression in your Windows CE OS design by adding or omitting the Compression Catalog item from your OS design.

The base configuration excludes compression, however, the technologies and Catalog items added to the base configuration will very likely pull in the Compression Catalog item from the Catalog in the File Systems and Data Store collection.

If the Compression Catalog item is part of your OS design, the Config.bib setting COMPRESSION can be set to ON or OFF. If the Compression Catalog item is not part of your OS design, the Config.bib setting COMPRESSION must be set to OFF.

COMPRESSION=OFF

If COMPRESSSION is set to ON and the Compression Catalog item is not added, the files in the ROM file system will be unreadable.
