VOIP_S_

The following table shows the constant that indicates a successful outcome of an application programming interface call.

Value Description
VOIP_S_DONT_TERMINATE = 0x00040000 On the e_vceMissed event from the VoIP Manager to IVoIPUI interface, this constant indicates that the VoIP Manager should not terminate the call and let IVoIPUI handle the call

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Voiperrorcodes.h
