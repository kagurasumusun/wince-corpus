RTC_S_

Real-time Communications (RTC) methods can return an RTC_S_ constant. These constants indicate the outcome of an application programming interface (API) call.

Value Description
RTC_S_ROAMING_NOT_SUPPORTED = 0x80EE0041L Server does not support this type of roaming.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Rtcerr.h.
