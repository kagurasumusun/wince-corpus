VAIL as a Part of an IP Phone

The VAIL is a key part of the VoIP functionality in Windows CE.

The Telephony User Interface (TUI) application obtains much of its functionality by using the objects and methods exposed by the VAIL.

For more information about VoIP functionality in Windows CE, including the VAIL and an explanation of how the VAIL fits into the overall Windows CE VoIP architecture, see Developing an IP Phone.

For information about the VAIL in the context of all VoIP functionality, including TUI, see IP Phone Functionality in Windows CE and Non-UI IP Phone Functionality.

For an introduction to how VoIP devices operate and how VoIP compares to a traditional phone network, see VoIP Technology and Protocol Overview.
