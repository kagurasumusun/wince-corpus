IRTCPresenceContact::PresentityURI

This method sets or gets the presentity URI of the presence contact.

HRESULT put_PresentityURI( 
  BSTR bstrPresentityURI 
);
HRESULT get_PresentityURI( 
  BSTR* pbstrPresentityURI 
);

Parameters

bstrPresentityURI, pbstrPresentityURI
[in, out] The presentity URI. On output, this parameter is a pointer to a BSTR that will be filled with the presentity URI, or an empty string if there is no entry. The method allocates the buffer. The caller is responsible for releasing this memory with SysFreeString.

Return Values

This method can return an RTC_E_ constant. The following table shows an additional possible return value.

Value Description
E_FAIL There is no presentity URI for this contact.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Rtccore.h, Rtccore.idl.
Link Library: Rtcdll.dll.
