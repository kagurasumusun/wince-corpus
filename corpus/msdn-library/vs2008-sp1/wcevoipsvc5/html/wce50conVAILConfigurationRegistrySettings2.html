VAIL Configuration Registry Settings

VAIL stores some settings in the registry for its internal operation. These settings are not exposed through the configuration data store, as the settings in VAIL Configuration Data Store Registry Settings are.

The HKEY_CURRENT_USER\Software\Microsoft\VoIPMgr registry key contains this information.

The following table shows the named value.

Value : type Description
LocalConferenceLimit : REG_DWORD The default setting is 1.

This setting specifies that only a single call can be active at a time: that is, that no conferencing is supported.

If the value is not present in the registry, no value is assumed.

Specifies the number of calls that can be active at one time on a locally mixed conference call.

The default media manager implementation, which uses the Real-time Communications (RTC) Client API RTP stack, does not support local conferencing, so the default value of this setting is 1.

If your media manager implementation supports call conferencing, by using IVoIPMediaMgr::ConferenceSessions, this setting should be the number of simultaneous calls that can be conferenced at one time.
