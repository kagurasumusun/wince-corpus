RTC Buddy Group Object

The Buddy Group object creates groups of buddies organized by functional purpose.

To access this object, use the IRTCBuddyGroup interface.

To create a Buddy Group object, use IRTCClientPresence2::AddGroup.

For more information about using the Buddy Group object, see the Buddy and Group Management information at this Microsoft Web site.
