IVoIPMediaMgr::SpeakerVolume

This method sets or gets the volume for the phone speaker.

HRESULT put_SpeakerVolume( 
  float fpVolume 
);
HRESULT get_SpeakerVolume( 
  float* pfpVolume 
);

Parameters

fpVolume, pfpVolume
[in, out] The volume for the speaker. The range is 0-1, inclusive. A value of zero (0) sets the speaker to mute and one (1) sets the speaker to full volume.

Return Values

If the HRESULT value passed to SUCCEEDED macro returns TRUE, the method succeeded. Otherwise, the method failed.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Voipmediamanager.idl.
Link Library: Voipguid.lib.
