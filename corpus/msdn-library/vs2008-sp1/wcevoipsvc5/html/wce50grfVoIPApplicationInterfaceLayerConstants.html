VAIL Constants

The following table shows the different types of VoIP Application Interface Layer constants.

Programming element Description
CONFIG_DATA_ These constants define the configuration data exposed by the VoIP configuration data store.
DCRP_VALID_ The validity constants are used by the DirectoryClientRegParams structure to specify which of the parameters are valid.
VMS_ These constants indicate the VoIP Manager states.
VOIP_E_ These constants indicate the outcome of an application programming interface (API) call.
VOIP_S_ This constant indicates a successful outcome of an API call.
