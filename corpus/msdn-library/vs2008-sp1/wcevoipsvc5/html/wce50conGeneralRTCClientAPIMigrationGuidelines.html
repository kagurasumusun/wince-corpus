General RTC Client API Migration Guidelines

The following item is important to understand when migrating an OS design that uses the RTC Client API:

  • The Real-time Communications (RTC) Client API Catalog item now exists in the Voice over IP Phone Services Catalog tree beneath Core OS / Windows CE devices. In past versions this Catalog item existed in the Networking Features tree beneath Core OS / Windows CE devices / Communication Services and Networking. The SYSGEN variables used by the RTC Client API are the same as in Windows CE .NET 4.2.
