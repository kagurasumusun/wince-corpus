IVoIPCallRecord::URI

This method sets or retrieves the URI for the recipient of this call.

HRESULT put_URI( 
  BSTR bstrURI 
);
HRESULT get_URI( 
  BSTR* pbstrURI 
);

Parameters

bstrURI, pbstrURI
[in, out] The URI of the call recipient. For get_URI, this parameter is a BSTR that will be filled with the URI of the recipient, or an empty string if there is no entry. The method allocates the buffer. The application is responsible for releasing the memory by using the SysFreeString function.

Return Values

If the HRESULT value passed to SUCCEEDED macro returns TRUE, the method succeeded. Otherwise, the method failed.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Voipstore.idl.
Link Library: Voipguid.lib.
