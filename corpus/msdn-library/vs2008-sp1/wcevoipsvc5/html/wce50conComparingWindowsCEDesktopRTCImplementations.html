Comparing Windows CE and Desktop RTC Implementations

In general, the Windows CE implementation of the RTC Client API supports the same functionality and uses the same external API as the desktop implementation.

However, there are two major pieces of functionality that Windows CE does not support:

  • Video sessions
  • Whiteboard (T120) sessions

For information about how the RTC Client API desktop version numbers compare to the versions shipped with Windows CE, see RTC Client API Version Comparison.

For the documentation for the desktop version of RTC, see this Microsoft Web site.
