VAIL Structures

The following table shows the VoIP Application Interface Layer structures .

Programming element Description
DirectoryClientRegParams This structure describes the registration parameters for a directory client.

Note   As of Windows CE 5.0, this structure is longer supported.
SIPServerRegistrationParameters This structure contains parameters used to register the VoIP manager with a SIP proxy/registrar server.
VoIPMgrParameters This structure contains the VoIP Manager parameters.

Note   As of Windows CE 5.0, this structure is longer supported.
