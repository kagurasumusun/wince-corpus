IRTCProfile::UserAccount

This method gets the user account associated with this profile.

HRESULT get_UserAccount(
  BSTR* pbstrUserAccount
);

Parameters

pbstrUserAccount
[out] Pointer to a BSTR that will be filled with the user account, or an empty string if there is no entry. The method is responsible for allocating the buffer. The caller is responsible for releasing this memory with SysFreeString.

Return Values

This method can return an RTC_E_ constant. The following table shows additional information about a specific return value.

Value Description
RTC_E_NOT_EXIST The user account is an optional field in the profile. The field is not present in the profile.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Rtccore.h, Rtccore.idl.
Link Library: Uuid.lib.
