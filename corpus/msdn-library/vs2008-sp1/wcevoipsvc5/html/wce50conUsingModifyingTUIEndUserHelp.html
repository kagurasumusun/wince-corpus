Using and Modifying TUI User Help

The TUI includes context-sensitive user help. Each state can have a string that is displayed when a user in that state requests help.

When using the TUI application, you can see this help by pressing and holding the MENU key. In the Emulator or CEPC, press and hold the END key on the keyboard to display help. For more information about using the keyboard with the Emulator or a CEPC, see TUI Hardware Requirements and PC Keyboard Hotkeys.

Not all screens include help. To see one example of a screen that includes help, press Directory (Return/Enter with a keyboard), then choose Global Address List. On the Global Address List screen, press and hold Menu (again, END on a keyboard).

The actual help content, which you can modify, is in the voipui.rc file, in %_WINCEROOT%\Public\VoIP\Oak\Phone\TUI\App. To find the help content, search the voipui.rc file for this string:

IDS_SCREENHELP_

For information about general user documentation considerations for the Windows CE IP phone solution, see Creating End User Documentation for an IP Phone.
