Voice over IP Phone Services Catalog Items

The following table shows the Catalog items for voice over IP phone services.

Catalog item Sysgen Variable Description
PC Authentication SYSGEN_VOIPPHONE_LAP Functionality that the TUI uses to control access to private information depending on whether an associated PC is locked or unlocked.

For more information, see PC Authentication.
Phone IME SYSGEN_VOIPPHONE_PHONEIME "Triple-tap" functionality that the TUI uses to enable users to enter text with a numeric keypad.

For more information, see Phone IME.
Real-time Communications (RTC) Client API SYSGEN_VOIP Low-level functionality for Voice over IP (VoIP), messaging, and presence support. This includes Session Initiation Protocol (SIP) and Real-time Transport Protocol (RTP) stacks.

For more information, see Real-time Communications (RTC) Client API.
SIREN/G.722.1 Codecs SYSGEN_VOIP_SIREN SIREN codecs for use with the RTC Client API via the Audio Compression Manager.

For more information, see Real-time Communications (RTC) Client API.
Telephony User Interface SYSGEN_VOIPPHONE_UI A full-featured phone application that can make and receive calls, interact with Exchange to provide contact and other information, and more.

For more information, see Telephony User Interface (TUI).
VoIP Application Interface Layer (VAIL) SYSGEN_VOIPPHONE_MGR Core VAIL functionality and API elements.

This Catalog item includes VoIP Manager functionality. It does not include other VAIL functionality, like the media manager, provisioner, and so on, all of which are children of this Catalog item.

For more information, see VoIP Application Interface Layer (VAIL).
Phone Provisioner SYSGEN_VOIPPHONE_CONFIGURATIONSTORE Configuration data store functionality provided by the VAIL and used by the TUI for provisioning.

For more information, see VoIP Application Interface Layer (VAIL).
Reference Media Manager SYSGEN_VOIPPHONE_REFMEDIA Reference media manager implementation that uses the RTP stack provided by the RTC Client API Catalog item.

For more information, see VoIP Application Interface Layer (VAIL).
VAIL Database Store SYSGEN_VOIPPHONE_DBSTORE Reference implementation of caller information and call log stores, using Windows CE databases.

For more information, see VoIP Application Interface Layer (VAIL).
