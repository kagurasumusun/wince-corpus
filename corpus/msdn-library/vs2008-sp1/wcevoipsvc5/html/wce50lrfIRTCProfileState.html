IRTCProfile::State

This method gets the current state of registration for the profile.

HRESULT get_State(
  RTC_REGISTRATION_STATE* penState
);

Parameters

penState
[out] Pointer to an RTC_REGISTRATION_STATE enumeration value specifying the current registration state of the profile.

Return Values

This method can return an RTC_E_ constant.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Rtccore.h, Rtccore.idl.
Link Library: Uuid.lib.
