Other TUI Windows

Most screens provided by the TUI use a list box to display information. Those that do not use a list box, like the PIN entry and Home screens, use special-purpose window classes.

These windows use the ATL window classes and are defined in the %_WINCEROOT%\Public\VoIP\OAK\Phone\TUI\Controls directory in files like EnterPINDialog.cpp (and EnterPinDialog.h) and HomeScreen.cpp (and HomeScreen.h). For more information about ATL window files, see How TUI Uses ATL.
