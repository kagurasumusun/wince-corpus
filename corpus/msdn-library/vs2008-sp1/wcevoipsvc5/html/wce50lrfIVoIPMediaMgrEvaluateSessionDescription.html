IVoIPMediaMgr::EvaluateSessionDescription

This method allows evaluation of a session description. It is called by the VoIP manager when the phone receives an INVITE request from a remote party. The VoIP manager uses the retrieved information to allow the application to decide whether to handle the incoming session description negotiations through the media manager, or let the RTC Client API handle these negotiations.

HRESULT EvaluateSessionDescription( 
  BSTR bstrContentType, 
  BSTR bstrSessionDescription,
  VARIANT_BOOL* pfApplicationSession
);

Parameters

bstrContentType
[in] The content type for the session.
bstrSessionDescription
[in] The SDP information from the other party.
pfApplicationSession
[in, out] VARIANT_TRUE if the application (through the media manager) will handle the media. In this case, RTC will set the session type to RTCST_APPLICATION. A setting of VARIANT_FALSE indicates that RTC should handle the media in the future, with a session type of RTCST_PC_TO_PC.

Return Values

If the HRESULT value passed to SUCCEEDED macro returns TRUE, the method succeeded. Otherwise, the method failed.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Voipmediamanager.idl.
Link Library: Voipguid.lib.
