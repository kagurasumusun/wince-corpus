IRTCSessionReferredEvent::ReferCookie

This method gets the cookie for the referred session. The cookie contains context information on the session. This method is called by the recipient in the session transfer.

HRESULT get_ReferCookie(
  BSTR* pbstrReferCookie
);

Parameters

pbstrReferCookie
[out] Pointer to a BSTR that is filled with the cookie that is stored for the referred session, or an empty string if there is no entry.

The method allocates the buffer.

The caller is responsible for releasing this memory with SysFreeString.

Return Values

This method can return an RTC_E_ constant.

The following table shows additional possible return values.

Value Meaning
E_POINTER The pbstrReferCookie parameter is not a valid pointer.
E_OUTOFMEMORY Insufficient memory to perform this operation.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Rtccore.h, Rtccore.idl.
Link Library: Uuid.lib.
