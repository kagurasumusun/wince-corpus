IRTCBuddyGroupEvent:IDispatch

This interface retrieves information about an event of type RTCE_GROUP. This type of event is used when roaming group information is updated. It is triggered when a buddy is added to or removed from a group, or the group is renamed.

Methods

The following table shows the methods for this interface in vtable order. This is the order in which the compiler calls the methods. This interface inherits the methods for the IUnknown and IDispatch interfaces.

The following table shows the IDispatch methods.

Method Description
GetIDsOfNames Maps a single member name and an optional set of parameter names to a corresponding set of integer dispatch identifiers (DISPIDs). These identifiers can then be used on subsequent calls to IDispatch::Invoke.
GetTypeInfo Retrieves the type information for an object.
GetTypeInfoCount Retrieves the number of type information interfaces that an object provides, either 0 or 1.
Invoke Provides access to properties and methods exposed by an object.

The following table shows the IRTCBuddyGroupEvent methods.

Method Description
EventType Gets the event type.
Group Gets the buddy group associated with this event.
Buddy Gets the buddy group associated with this event.
StatusCode Gets the result code of the completed operation.

Obtaining a Pointer

When the application's implementation of the IRTCEventNotification::Event method indicates an RTC_EVENT enumeration value of RTCE_GROUP, the method's pEvent parameter is an IDispatch pointer for the IRTCBuddyGroupEvent interface.

Remarks

To enable reception of buddy group events, the application must call the IRTCClient::EventFilter method and set an event filter mask that includes the RTCE_GROUP event. If the application does not call IRTCClient::EventFilter, it will not receive any events.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Rtccore.h, Rtccore.idl.
Link Library: Uuid.lib.
