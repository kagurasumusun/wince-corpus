Real-time Communications Architecture

The Windows CE RTC Client API implementation includes the following protocol stacks:

  • Session Initiation Protocol (SIP)
  • Real-Time Transport Protocol (RTP)
  • PSTN/Internet (PINT) internetworking service

The RTC Client API provides the ability to build applications that do the following:

  • Create sessions through SIP
  • Use codecs to compress and decompress audio data through RTP
  • Communicate with PSTN phones using PINT
