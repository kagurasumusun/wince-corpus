VAIL Registry Settings

The VAIL uses configurable registry settings for multiple purposes:

  • To identify the appropriate implementation to use for media management, call log storage, and caller information storage. For more information about these registry settings, see VAIL Plugin Registry Settings.
  • To persist configuration information. For more information about these registry settings, see VAIL Configuration Data Store Registry Settings.
  • To store settings used by VAIL that are not exposed through the configuration data store. For more information about these registry settings, see VAIL Configuration Registry Settings.

For the registry entries created for use by VAIL, see the Voip.reg file in %_WINCEROOT%\Public\VoIP\Oak\Files.

This file does not contain all registry settings used by the VAIL. Many VAIL registry settings are created by the VAIL code when the VAIL is used. For more information about settings that are created by the VAIL when it runs, see VAIL Configuration Data Store Registry Settings.
