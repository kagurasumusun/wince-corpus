Setting up the PC Authentication LAP on a Windows CE Device

The PC Authentication LAP must be set up to handle LASS authentication requests in the same way any LAP is configured. In general this involves setting information in the registry section that LASS uses.

For a specific example of the registry settings required to configure the PC Authentication LAP, see the Telephony User Interface (TUI) source code, specifically, the InitializeVoIPLAP function in %_WINCEROOT%\Public\VoIP\OAK\Phone\TUI\Utilities\Laputils.cpp.

For general information about LASS registry settings and detaild about the settings used by the LAPs, see LASS Registry Settings.
