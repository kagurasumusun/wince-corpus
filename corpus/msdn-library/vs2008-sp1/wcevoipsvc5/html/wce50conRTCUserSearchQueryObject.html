RTC User Search Query Object

The User Search Query object customizes search parameters when searching for other users on the Internet.

To access this object, use the IRTCUserSearchQuery interface.

To create a User Search Query object, use IRTCUserSearch::CreateQuery.

For more information about using the User Search Query object, see the User Search Capabilities information at this Microsoft web site.
