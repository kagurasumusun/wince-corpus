RTC 1.2 Code Examples

Windows CE 5.0 includes RTC version 1.2.

For code examples that demonstrate RTC 1.2 enhancements, see this Microsoft Web site.

For conceptual and overview information about RTC 1.2 enhancements, see this Microsoft Web site.

These web sites document the desktop version of the RTC Client API. The Windows CE version is similar but does not support all of the functionality of the desktop implementation.

For a summary of the differences between the desktop and Windows CE implementations of the RTC Client API, see Comparing Windows CE and Desktop RTC Implementations.

Note   Windows CE .NET 4.2 included a slightly different implementation of RTC version 1.2. The code examples and documentation in these links may not work correctly on Windows CE .NET 4.2. For information about how the desktop versions of RTC compare to the versions shipped with Windows CE, refer to RTC Client API Version Comparison.
