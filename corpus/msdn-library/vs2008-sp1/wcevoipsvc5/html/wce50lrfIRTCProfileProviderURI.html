IRTCProfile::ProviderURI

This method gets the provider Universal Resource Identifier (URI) for the profile.

HRESULT get_ProviderURI(
  RTC_PROVIDER_URI enURI,
  BSTR* pbstrURI
);

Parameters

enURI
[in] An RTC_PROVIDER_URI enumeration value that specifies the URI type.
pbstrURI
[out] Pointer to a BSTR that will be filled with the provider URI, or an empty string if there is no entry. The method is responsible for allocating the buffer. The caller is responsible for releasing this memory with SysFreeString.

Return Values

This method can return an RTC_E_ constant. The following table shows additional information about a specific return value.

Value Description
RTC_E_NOT_EXIST The provider URI is an optional field in the profile. The field is not present in the profile.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Rtccore.h, Rtccore.idl.
Link Library: Uuid.lib.
