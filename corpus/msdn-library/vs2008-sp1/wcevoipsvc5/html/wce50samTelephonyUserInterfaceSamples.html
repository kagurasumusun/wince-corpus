Platform Builder for Microsoft Windows CE 5.0  

TUI Samples

The TUI application is a sample, and also provides the prime set of demonstration code for Windows CE technologies that it uses to implement IP phone functionality.

The TUI source code is in the %_WINCEROOT%\Public\VoIP\Oak\Phone\TUI directory.

The TUI application demonstrates the use of the following VoIP technologies, among others:

  • VoIP Application Interface Layer (VAIL)
  • Real-time Communications (RTC) Client API

    Used directly from the TUI application for presence. Used indirectly by VAIL for call control and media transport.

  • Exchange Client
  • PC Authentication
