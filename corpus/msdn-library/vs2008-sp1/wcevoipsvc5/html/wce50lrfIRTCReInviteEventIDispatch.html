IRTCReInviteEvent:IDispatch

This interface retrieves information about an event of type RTCE_REINVITE.

This type of event informs the application of a REINVITE request for a session that the application is handling SDP negotiations for. The application can retrieve the session and accept or reject the REINVITE request.

This method initiates a REINVITE for the session, not just a media stream.

Methods

The following tables show the methods for this interface in vtable order. This is the order in which the compiler calls the methods.

This interface inherits the methods for the IUnknown and IDispatch interfaces.

The following table shows the IDispatch methods.

Method Description
GetIDsOfNames Maps a single member name and an optional set of parameter names to a corresponding set of integer dispatch identifiers (DISPIDs).

These identifiers can then be used on subsequent calls to IDispatch::Invoke.

GetTypeInfo Retrieves the type information for an object.
GetTypeInfo Retrieves the number of type information interfaces provided by an object, either zero (0) or 1.
Invoke Provides access to properties and methods exposed by an object.

The following table shows the IRTCReInviteEvent methods.

Method Description
Session Gets the SDP session for the incoming REINVITE request.
Accept Specifies the content type and body for the response to the REINVITE request.
Reject Rejects the incoming REINVITE request.
State Gets the state of the reinvite event.
GetRemoteSessionDescription Retrieves the session description from the remote client.

Obtaining a Pointer

When the application's implementation of IRTCEventNotification::Event indicates an RTC_EVENT enumeration value of RTCE_REINVITE, the method's pEvent parameter is an IDispatch pointer for the IRTCReInviteEvent interface.

Remarks

To enable reception of reinvite events, the application must call the IRTCClient::EventFilter method and set an event filter mask that includes the RTCE_REINVITE event.

If the application does not call IRTCClient::EventFilter, it will not receive events.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Rtccore.h, Rtccore.idl.
Link Library: Uuid.lib.
