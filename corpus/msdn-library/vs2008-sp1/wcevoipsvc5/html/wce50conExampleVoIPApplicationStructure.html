Example VAIL Application Structure

The Telephony User Interface (TUI) Catalog item provides an example application that uses the VAIL VoIP manager object.

You see the TUI when you create an OS design using the IP Phone design template, by following the instructions in How to Create a Default IP Phone on a CEPC and How to Create a Default IP Phone on an Emulator.

For details about the structure of an application that uses the VAIL VoIP manager, specifically about VoIP manager startup and shutdown, see the following sections:

  • VoIP Manager Setup
  • VoIP Manager Shutdown

For more information about the TUI, including details of the source code and how it uses the VAIL, see Telephony User Interface (TUI).
