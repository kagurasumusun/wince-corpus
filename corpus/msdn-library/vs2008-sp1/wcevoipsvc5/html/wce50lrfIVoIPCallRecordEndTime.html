IVoIPCallRecord::EndTime

This method sets or retrieves the end time for this call.

HRESULT put_EndTime( 
  SYSTEMTIME time 
);
HRESULT get_EndTime( 
  SYSTEMTIME* ptime 
);

Parameters

time, ptime
[in, out] SYSTEMTIME structure containing the call end time.

Return Values

If the HRESULT value passed to SUCCEEDED macro returns TRUE, the method succeeded. Otherwise, the method failed.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Voipstore.idl.
Link Library: Voipguid.lib.
