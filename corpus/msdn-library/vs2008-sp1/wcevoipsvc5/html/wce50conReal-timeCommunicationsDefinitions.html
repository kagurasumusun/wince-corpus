Real-time Communications Definitions

This topic provides definitions of terms used in presence-based communications and collaboration applications.

Presentity

The entity whose presence information is tracked. The Presentity registers its status, location, and other attributes with the Presence (registrar) Server.

Presence

Presence is a service that can implement the following functions:

  • Registration/Deregistration. A service that provides the update of Presentity capabilities, location, and online status.
  • Query. A Watcher can query for Presentity status. A message-routing service can also query for status, which it uses in routing decisions.
  • Notification. The Watchers are notified of changes in the Presentity status.
  • Subscription. Subscription/unsubscription allows a Watcher to register its interest in a Presentity.

Buddy

Same as Presentity. The entity whose presence information is tracked. The Buddy registers its status, location, and other attributes with the Presence (registrar) Server.

Watcher

The entity to be informed of the status of the Presentity or Buddy. The Watcher can query for the status of the Presentity and is notified of changes in the status of the Presentity.

Whiteboard

An application that displays a window for two users to exchange information.

Windows CE does not support whiteboard functionality.

Application Sharing

The ability to share an application between two computers, both of which can view and interact in the session.

Windows CE does not support application sharing functionality.
