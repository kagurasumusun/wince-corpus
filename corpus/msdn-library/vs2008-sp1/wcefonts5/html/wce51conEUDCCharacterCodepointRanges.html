End User Defined Character Codepoint Ranges

Windows CE has valid ranges for End User Defined Characters (EUDC) based upon locale. These ranges are as follows:

  Locale Id Range
Japanese 0x0411 0xe000, 0xe757
Korean 0x0412 0xe000, 0xe0bb
Chinese Simplified 0x0804 0xe000, 0xe4df
Chinese Traditional 0x0404 0xe000, 0xf8ff

The system's locale at boot time determines which element in this list is used to limit the EUDC range. If the system locale is not one of the above, the EUDC characters will default to the Japanese locale.
