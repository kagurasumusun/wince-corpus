Font Registry Settings for Korea

The HKEY_LOCAL_MACHINE\System\GDI registry key enables font linking. The following table shows the named value for the GDI parameters.

Note   The default registry values vary depending on which Catalog items are included in your OS design. For more information, see Default Registry Settings.
Value : type Description
FontLinkMethods : REG_DWORD Indicates whether font linking is enabled. Set to 1 to enable font linking.

The HKEY_LOCAL_MACHINE\Software\Microsoft\FontLink\SystemLink registry key can be used to indicate whether the Gulim TrueType font for Korean is linked with a specified standard system font. The following table shows the named values for the SystemLink parameters.

Value : type Description
Arial : REG_SZ Set to "\\Windows\\gulim.ttc,±".
Times New Roman : REG_SZ Set to "\\Windows\\gulim.ttc,±".
Tahoma: REG_SZ Set to "\\Windows\\gulim.ttc,±".
Courier New : REG_SZ Set to "\\Windows\\gulim.ttc,±".
Symbol : REG_SZ Set to "\\Windows\\gulim.ttc,±".

The HKEY_LOCAL_MACHINE\Software\Microsoft\FontLink\SystemLink registry key can also be used to indicate whether the Gulim Agfa AC3 compressed font for Korean is linked with a specified standard system font. The following table shows the named values for the SystemLink parameters.

Value : type Description
Arial : REG_SZ Set to "\\Windows\\gulim.ac3,±".
Times New Roman : REG_SZ Set to "\\Windows\\gulim.ac3,±".
Tahoma: REG_SZ Set to "\\Windows\\gulim.ac3,±".
Courier New : REG_SZ Set to "\\Windows\\gulim.ac3,±".
Symbol : REG_SZ Set to "\\Windows\\gulim.ac3,±".

The following table shows the registry value for HKEY_LOCAL_MACHINE\Software\Microsoft\FontLink\SkipTable.

Value : type Description
Tahoma : REG_SZ Set to "005c".

The following table shows the registry value for HKEY_CURRENT_USER\EUDC.

Value : type Description
SystemDefaultEUDCFont : REG_SZ Set to "\\Windows\\eudc.tte".
