Replacing Fonts

For some OS designs or applications, you may need to be able to replace the default Windows CE fonts with other fonts, including custom fonts. You can modify the Windows CE registry to replace default fonts, to replace fonts used on an OS design, and to replace raster fonts with TrueType fonts.
