General Font Registry Settings

If a user changes the font size within Help for Windows CE, the new font size is saved in the HKEY_CURRENT_USER\SOFTWARE\Microsoft\HELP\ZoomSetting registry entry. Help for Windows CE uses the font size specified by this registry setting, rather than the size specified by the registry setting for Microsoft Pocket Internet Explorer, when the user subsequently uses Help for Windows CE.
