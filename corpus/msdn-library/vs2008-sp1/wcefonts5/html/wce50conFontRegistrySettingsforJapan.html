Font Registry Settings for Japan

The HKEY_LOCAL_MACHINE\System\GDI registry key enables font linking. The following table shows the named value for the GDI parameters.

Note   The default registry values vary depending on which Catalog items are included in your OS design. For more information, see Default Registry Settings.
Value : type Description
FontLinkMethods : REG_DWORD Indicates whether font linking is enabled. Set to 1 to enable font linking.

The HKEY_LOCAL_MACHINE\System\GDI\GlyphCache registry key specifies the size limit for character glyphs. The following table shows the named value for the GlyphCache parameters.

Value : type Description
limit : REG_DWORD Indicates size limit for character glyph cache. Set to 400.

The HKEY_LOCAL_MACHINE\Software\Microsoft\FontLink\SystemLink registry key can be used to indicate whether the MS Gothic TrueType font for Japanese is linked with a specified standard system font. The following table shows the named values for the SystemLink parameters.

Value : type Description
Arial : REG_SZ Set to "\\Windows\\msgothic.ttc,MS UI Gothic".
Times New Roman : REG_SZ Set to "\\Windows\\msgothic.ttc,MS UI Gothic".
Tahoma: REG_SZ Set to "\\Windows\\msgothic.ttc,MS UI Gothic".
Courier New : REG_SZ Set to "\\Windows\\msgothic.ttc,MS UI Gothic".
Symbol : REG_SZ Set to "\\Windows\\msgothic.ttc,ce"'SVbN'".

The HKEY_LOCAL_MACHINE\Software\Microsoft\FontLink\SystemLink registry key can also be used to indicate whether the MS Gothic Agfa AC3 compressed font for Japanese is linked with a specified standard system font. The following table shows the named values for the SystemLink parameters.

Value : type Description
Arial : REG_SZ Set to "\\Windows\\msgothic.ac3,MS UI Gothic".
Times New Roman : REG_SZ Set to "\\Windows\\msgothic.ac3,MS UI Gothic".
Tahoma: REG_SZ Set to "\\Windows\\msgothic.ac3,MS UI Gothic".
Courier New : REG_SZ Set to "\\Windows\\msgothic.ac3,MS UI Gothic".
Symbol : REG_SZ Set to "\\Windows\\msgothic.ac3,ce"'SVbN'".

The following table shows the registry value for HKEY_LOCAL_MACHINE\Software\Microsoft\FontLink\SkipTable.

Value : type Description
Tahoma : REG_SZ Set to "005c,00a5,007e,0391-03c9,2026,2116,221a,25a0-25ff".

The following table shows the registry values for HKEY_CURRENT_USER\EUDC.

Value : type Description
SystemDefaultEUDCFont : REG_SZ Set to "\\Windows\\eudc.tte".
ceo"'SVbN' : REG_SZ Set to "\\Windows\\eudc.tte".
ceoPOP' : REG_SZ Set to "\\Windows\\eudc.tte".
