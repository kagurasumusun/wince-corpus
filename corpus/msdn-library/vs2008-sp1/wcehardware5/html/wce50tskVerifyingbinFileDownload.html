Verifying .bin File Download

You must verify that you can successfully download a .bin file using Platform Builder before you can continue with the boot loader development process. To create a test .bin file to use for download, see Creating a Test .bin File for Download.

To verify .bin file download using Platform Builder

  1. Use Platform Builder to open the test Eboot.bin file you previously created.

    For information about how to create a test .bin file for download, see the Creating a Test .bin File for Download.

  2. Download the Eboot.bin file.
  3. After you have verified that the download process works, restore the Eboot.bib file from the backup file you previously created.
  4. Rebuild the boot loader.

    For more information, see Rebuilding the Boot Loader.
