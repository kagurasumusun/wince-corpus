Modifying the Renesas US7750R HARP (Aspen) SDB Switches and Jumpers

You modify the switches and jumpers on the Renesas US7750R HARP (Aspen) SDB to write to flash memory and execute the boot loader code.

To modify the Renesas US7750R HARP (Aspen) SDB switches and jumpers

  • Verify that the switches are in the correct On or Off position.

    The following table shows the functionality of switch S1. To write to flash memory, S1-switch 3 needs to be in the Off position.

    S1-1 S1-2 S1-3 S1-4 Function
    On Off Off On Code executes from boot monitor after reset.
    Off Off Off On Code executes from flash memory after reset.
    Off Off Off Off The Ethernet boot loader executes to download the new image after reset.
    X X Off X Flash memory is not write-protected.
    X X On X Flash memory is write-protected.
