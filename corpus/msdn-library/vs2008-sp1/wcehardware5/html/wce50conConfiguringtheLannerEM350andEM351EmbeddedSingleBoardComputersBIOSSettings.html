Configuring the Lanner EM-350 and EM-351 Embedded Single Board Computers BIOS Settings

To successfully configure an x86 SDB to download an run-time image, you must correctly configure the BIOS and verify that there are no device conflicts. If two devices share the same interrupt request (IRQ), you cannot use both of these devices at the same time unless the drivers support interrupt sharing, which enables multiple devices to use the same interrupt.

To configure the BIOS settings

  1. Restart the Lanner EM-350 and EM-351 SDB, and then press DELETE to initiate BIOS setup.
  2. Configure all interrupts to avoid conflict.
