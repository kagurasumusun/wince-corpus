BSP Tools

With the BSP tools in the Microsoft® Platform Builder IDE, you can accomplish the following tasks:

  • Create a BSP by cloning an existing BSP and adding it to the IDE Catalog using the BSP Wizard. For more information, see Cloning an Existing BSP.
  • Add an existing BSP to the IDE Catalog by creating a BSP definition with the BSP Wizard. For more information, see Creating a New BSP Definition.
  • Use your BSP in a sample OS design by using the New Platform Wizard tool. For more information, see Creating an OS Design with the New Platform Wizard.
  • Export a BSP for use by OEM customers by using the Export Wizard tool. For more information, see Export Wizard Overview.
  • Import a third-party BSP into the IDE Catalog.

For information about adding a boot loader to a BSP, see Adding a Boot Loader to a BSP Definition.

For information about adding a device driver to your BSP, see Adding a Driver to an Existing BSP.
