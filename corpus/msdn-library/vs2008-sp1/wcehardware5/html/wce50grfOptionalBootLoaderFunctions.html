Optional Boot Loader Functions

The following table shows the optional boot loader functions.

Programming element Description
OEMCheckSignature This function verifies the signature in the .bin file.
OEMMultiBINNotify This function saves the number of .bin files to be downloaded and their addresses and sizes.
OEMVerifyMemory This function verifies that the address provided is in valid memory.
