Downloading the Run-Time Image to the Broadcom VoIP Screen Phone

If the Windows CE boot loader is downloaded to the Broadcom VoIP Screen Phone, you can download the run-time image using Microsoft® Platform Builder.

To download the run-time image to the Broadcom VoIP Screen Phone

  1. Be sure the phone is on.
  2. Download the run-time image.

    For more information, see Downloading a Run-Time Image.
