PCI Library

The PCI library supports a simplified initialization of the PCI configuration space to provide support for the boot loader and OS startup. This library supports bus initialization to allow KITL initialization of a PCI resident network interface card (NIC). For more information, see %_WINCEROOT%\Platform\Common\Src\Inc\Oal_pci.h.

To support the PCI bus, the OAL (OEMInit) or boot loader code (OEMPlatformInit) must call the OEMPCIBusConfigure function. OEMPCIBusConfigure accepts the valid PCI memory and I/O address ranges for the hardware platform. The information and associated bridge window registers are hardware platform-specific.

OAL Interface

typedef union {
struct {
UINT8 fnc; // function
UINT8 dev; // device
UINT8 bus; // bus
};
UINT32 logicalLoc;
} OAL_PCI_LOCATION, *POAL_PCI_LOCATION;
This structure defines the location of the PCI bus, device, and function.
BOOL OALPCIInit();
This function initializes the PCI module. It is called from the OEMInit function to initialize the PCI bus. In most cases, OALPCIInit is implemented in the SOC library or it is hardware platform-specific.
UINT32 OALPCICfgRead(UINT32 busId, OAL_PCI_LOCATION pciLoc,
UINT32 offset, UINT32 size, VOID *pData);
This function reads the PCI configuration space located at the address specified by the pciLoc parameter. OALPCICfgRead is hardware dependent and, in most cases, it is implemented in the SOC library or it is hardware platform specific.
UINT32 OALPCICfgWrite(UINT32 busId, OAL_PCI_LOCATION pciLoc,
UINT32 offset, UINT32 size, VOID *pData);
This function writes the PCI configuration space at the location specified by pciLoc. OALPCICfgWrite is hardware dependent and, in most cases, it is implemented in the SOC library or it is hardware platform-specific.
VOID OALPCIPowerOn(UINT32 busId);
This function powers on the PCI hardware, restores the PCI clock, and issues a PCI bus reset. It is called from the power module to restore the PCI hardware after the system is powered off or suspended. The PCI bus driver should save the PCI bus configuration.
VOID OALPCIPowerOff(UINT32 busId);
This function prepares the PCI hardware to be powered off or suspended. It is called from the power module. The PCI bus driver should save the PCI bus configuration when it powers off. OALPCIPowerOff should only power off the PCI clock and other hardware related to PCI support.
BOOL OALPCITransBusAddress(UINT32 busId, UINT64 busAddress,
UINT32 *pAddressSpace, UINT64 *pSystemAddress);
This function translates the PCI bus-relative address to the CPU address space.
BOOL OALPCIConfig(UINT32 busId, UINT32 memBase,
UINT32 memSize, UINT32 ioBase, UINT32 ioSize,
UINT32 pciLocCount, OAL_PCI_LOCATION *aPciLoc);
This function provides simple PCI bus configuration. It configures the PCI bus device resources. By default, this function configures all bridges and devices specified in the location list specified by the pciLocCount and aPciLoc parameters. When pciLocCount is set to -1, all devices are configured. In most cases, you should configure only the device used by KITL because configuration does not optimize resource use.
BOOL OALPCIRegisterAsUsed(UINT32 busId, OAL_PCI_LOCATION pciLoc);
This fuction registers the KITL device as used in the OS registry.
BOOL OALPCIFindNextId(UINT32 busId, UINT32 deviceId,
OAL_PCI_LOCATION *pPciLoc);
This function searches the PCI bus for cards that match deviceId. Search starts from the position next to the actual position specified by pPciLoc. When a device with a specified identifier is found, OALPCIFindNextId returns TRUE. The device location is specified in pPciLoc.

Helper Functions - KITL

KITL uses the following helper functions to read specific configuration registers:

UINT32 OALPCIGetId(UINT32 busId, OAL_PCI_LOCATION pciLoc);

UINT32 OALPCIGetMBAR(UINT32 busId, OAL_PCI_LOCATION pciLoc, UINT32 index);

UINT32 OALPCIGetInterruptPin(UINT32 busId, OAL_PCI_LOCATION pciLoc);

UINT8 OALPCIGetHeaderType(UINT32 busId, OAL_PCI_LOCATION pciLoc);

UINT8 OALPCIGetSecBusNum(UINT32 busId, OAL_PCI_LOCATION pciLoc);

UINT8 OALPCIGetSubBusNum(UINT32 busId, OAL_PCI_LOCATION pciLoc);

Helper Functions - Dump

The following helper functions dump information about the device or bus configuration space:

VOID OALPCIDumpConfig(UINT32 busId, OAL_PCI_LOCATION pciLoc);

VOID OALPCIDump(UINT32 busId, BOOL full);
