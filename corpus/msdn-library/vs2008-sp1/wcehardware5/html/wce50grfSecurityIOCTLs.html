Security IOCTLs

The following table shows the security IOCTLs.

Programming element Description
IOCTL_HAL_AUTHENTICATE_DEVICE This IOCTL authenticates the device before the device is allowed to boot and be used by a user. It is predefined for an OEM.
IOCTL_HAL_GET_IMAGE_SIGNED_STATE This IOCTL retrieves the signed state of an OS image.
IOCTL_HAL_GET_RANDOM_SEED This IOCTL returns random bytes from a hardware source.
