Lanner EM-350 and EM-351 Embedded Single Board Computers

The Lanner EM-350 and EM-351 are both Geode-based single board computers (SBCs) manufactured by Lanner Electronics that are similar to each other. The only difference is that EM-350 has a single Ethernet port and EM-351 has dual Ethernet ports. The following table provides information on the hardware peripherals available on the Lanner EM-350 and EM-351 Embedded SBCs for National Geode GX1 microprocessors and the driver to use in the BSP.

Note   When storing the boot loader in ROM on the Lanner EM-351, the COM2 serial port interrupt, IRQ 3, is shared with other onboard peripherals. Under these circumstances, the serial port is not usable unless the driver is modified to support interrupt sharing. To avoid this, replace the boot loader in ROM with the BIOS and reserve IRQ 3, and then use %_WINCEROOT%\Platform\Cepc\Eboot\Bin\Eboot.bin to load the image.
