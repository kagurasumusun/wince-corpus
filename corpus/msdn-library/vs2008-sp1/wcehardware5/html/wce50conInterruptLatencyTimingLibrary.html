Interrupt Latency Timing Library

The interrupt latency timing library implements the functionality related to ILTiming, which is usually used during the development process. For more information, see %_WINCEROOT%\Platform\Common\Src\Inc\Oal_ilt.h.

Kernel Interface

IOCTL_HAL_ILTIMING
The kernel calls OEMIoControl with this control code to use ILTiming.exe.
BOOL OALIoCtlHalILTiming(UINT32, VOID*, UINT32, VOID*, UINT32, UINT32*);
This function is called by OEMIoControl for IOCTL_HAL_ILTIMING code.

OAL Interface

extern OAL_ILT_STATE g_oalILT;
This variable exports the OAL interrupt latency timing control block. This is the global instance of the internal ILT module variables.
typedef struct {
BOOL active; // Is IL timing active?
UINT16 interrupts; // IL interrupt counter
UINT32 isrTime1; // IL start of ISR
UINT32 isrTime2; // IL end of ISR
UINT32 savedPC; // IL saved PC
UINT32 counter; // IL counter
UINT32 counterSet; // IL counter set value
} OAL_ILT_STATE, *POAL_ILT_STATE;
This structure specifies the timer module component control block. It encapsulate all the OAL internal module variables that can be used by other modules.
