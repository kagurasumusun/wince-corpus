KD_IOCTL_QUERY_DBP

This IOCTL is used to query the number of data breakpoints that are available.

The OEMKDIoControl function calls this IOCTL.

Parameters

dwIoControlCode
[in] Set to KD_IOCTL_QUERY_DBP.
lpBuf
[out] Pointer to a buffer that allocates space for a KD_BPINFO structure.
nBufSize
[in] Size of the buffer pointed to by lpBuf.

This is set to the size of the KD_BPINFO structure.

Remarks

The OEM sets the ulCount member of KD_BPINFO to the number of data breakpoints available.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Pkfuncs.h.
