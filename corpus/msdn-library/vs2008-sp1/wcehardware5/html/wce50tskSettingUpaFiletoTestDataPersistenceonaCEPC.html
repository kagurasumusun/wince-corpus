Setting Up a File to Test Data Persistence on a CEPC

You can use any file type for verifying data persistence, but be sure that you have included the proper applications in your run-time image. In the following procedure, you use Microsoft WordPad as the test application to create a text file. By saving a test file to the hard disk, you can verify that your data is still on the hard disk after you reboot your CEPC.

To set up a file to test data persistence on a CEPC

  1. On the CEPC, from the taskbar, choose Start, Programs, Accessories, and then choose WordPad.
  2. From the WordPad File menu, choose Save.
  3. In WordPad, navigate to the Hard Disk directory.
  4. Enter a file name and choose OK to save the file to the Hard Disk directory.
