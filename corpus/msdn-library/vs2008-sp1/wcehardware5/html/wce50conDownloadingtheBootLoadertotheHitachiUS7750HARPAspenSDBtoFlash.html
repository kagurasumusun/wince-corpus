Downloading the Boot Loader to the Renesas US7750R HARP (Aspen) SDB to Flash

If you are installing the Windows CE boot loader for the first time, or if you are restoring a boot loader that was corrupted, use the following procedure to download the Windows CE boot loader to the Renesas US7750R HARP (Aspen) SDB.

To download the boot loader to the Renesas US7750R HARP (Aspen) SDB to flash memory

  1. Determine if the OEM boot loader is on the Aspen SDB.

    For more information, see OEM Boot Loader Output for the Renesas US7750R HARP (Aspen) SDB.

  2. Turn off the Aspen SDB.
  3. Boot your device to the OEM boot monitor, DMON.

    To boot to the DMON prompt, set the switches to the following settings:

    S1-1 S1-2 S1-3 S1-4
    On Off Off Off
  4. On your development workstation, start your terminal emulation software to create a new serial connection and then choose COM1 or COM2, as appropriate.
  5. Configure your terminal emulation software to the following settings:
    Bits per second Data bits Parity Stop bits Flow control
    57600 8 None 1 None
  6. Connect a NULL modem serial cable between the debug serial port on the Aspen SDB and the COM port on your development workstation.
  7. Turn on the Aspen SDB.

    The debug serial output that ends with the DMON prompt, DMON>, appears.

  8. At the DMON command prompt, type L to download to RAM; then press ENTER.
    Note   DMON does not acknowledge the command at this point.
  9. In the terminal emulator window, choose Send File and then browse to the location where you copied Eboot.sre for the Aspen SDB.
  10. After you locate the file, select it so it can be transferred to RAM.

    After the file transfer is complete, the DMON prompt returns.

  11. At the DMON command prompt, type P and press ENTER.

    This writes the boot loader to flash memory.

  12. After the boot loader is written to flash memory, set the S1-1 switch to Off.
    Note   All other switches remain the same.
  13. Reconfigure your terminal emulation software to the following settings:
    Bits per second Data bits Parity Stop bits Flow control
    38400 8 None 1 None
  14. Reset the Aspen SDB and verify that you have successfully downloaded the Windows CE boot loader.

    To see the format of the Windows CE boot loader message, see Windows CE Boot Loader Output for the Renesas US7750R HARP (Aspen) SDB.
