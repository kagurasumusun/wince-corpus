Platform Builder for Microsoft Windows CE 5.0  

curridlelow

This global variable contains the low DWORD of the 64-bit idle time, in milliseconds, and is used to support GetIdleTime.

extern DWORD curridlelow;

Parameters

None.

Return Values

None.

Remarks

This global variable is calculated as part of the OEMIdle routine, which determines how long a device has been in an idle state.

For an example, see Cfwp2.c in %_WINCEROOT%\Platform\%BSP%\Kernel\Hal.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Cfwp2.c.
