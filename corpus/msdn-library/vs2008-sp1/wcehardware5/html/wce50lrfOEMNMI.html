OEMNMI

This function is implemented by the OEM to support a nonmaskable interrupt. This function is specific to SH4.

Parameters

In the register bank, 1 is the exceptions block.

Return Values

This function must return SYSINTR_NOP, which is stored in register r0.

NMI signaling IST is not supported.

Remarks

The registers r0-r3 and r6 are available for use during the NMI by default.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Not applicable.
Link Library: Nk.lib.
