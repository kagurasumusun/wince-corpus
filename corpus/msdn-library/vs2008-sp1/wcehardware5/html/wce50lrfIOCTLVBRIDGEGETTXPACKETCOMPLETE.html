IOCTL_VBRIDGE_GET_TX_PACKET_COMPLETE

This IOCTL is used by VMINI to return the transmit buffer obtained through IOCTL_VBRIDGE_GET_TX_PACKET to VBridge.

The OEMIoControl function calls this IOCTL.

Parameters

dwIoControlCode
[in] Set to IOCTL_VBRIDGE_GET_TX_PACKET_COMPLETE.
lpInBuf
[in] Pointer to buffer obtained in IOCTL_VBRIDGE_GET_TX_PACKET.
nInBufSize
[in] Size of the buffer pointed to by lpInBuf.
lpOutBuf
Not used.
nOutBufSize
Not used.
lpBytesReturned
Not used.

Return Values

None.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Pkfuncs.h.
