Downloading the Run-Time Image to the NEC Solution Gear 2-Vr4131 Development Kit

If the Windows CE boot loader is downloaded to the NEC Solution Gear 2-Vr4131 Development Kit, you can download the run-time image.

To download the run-time image to the NEC Solution Gear 2-Vr4131 Development Kit

  1. Turn on the Solution Gear 2-Vr4131.
  2. Download the run-time image.

    For more information, see Downloading a Run-Time Image.
