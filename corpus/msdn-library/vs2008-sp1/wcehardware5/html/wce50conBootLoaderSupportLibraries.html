Boot Loader Support Libraries

Microsoft provides a number of static libraries in Microsoft® Windows® CE that can help you significantly shorten your boot loader development time. The libraries encapsulate many of the tasks described in the topic How to Develop a Boot Loader.

For more information about the code libraries you can use to create a boot loader, see one of the following topics:

  • BLCOMMON Code Library
  • Eboot Code Library
  • Bootpart Code Library
  • Ethernet Debug Libraries
