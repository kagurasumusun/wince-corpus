Advantech PCM-5823 SDB Dual Ethernet Port Functions and IRQs

The Advantech PCM-5823 SDB includes dual Ethernet ports. Using the Advantech PCM-5823 SDB dual port function may interfere with IRQ capabilities. The following table shows the Advantech PCM-5823 SDB USB controller-enabled settings.

USB Controller-enabled settings Setting
USB controller Enabled
USB legacy support Enabled
On-board PCI LAN chip 1 Disabled
On-board PCI LAN chip 2 Enabled

The following table shows the Advantech PCM-5823 SDB dual Ethernet-enabled settings.

Dual Ethernet-enabled settings Setting
USB controller Disabled
On-board PCI LAN chip 1 Enabled
On-board PCI LAN chip 2 Enabled
