Platform Builder for Microsoft Windows CE 5.0  

Boilerplate Interface Routines

The sample OAL provided with Platform Builder includes generic implementations of the following functions:

  • QueryPerformanceCounter
  • QueryPerformanceFrequency
  • OEMIdle
  • SC_GetTickCount

    The kernel calls SC_GetTickCount to service the GetTickCount system call.
