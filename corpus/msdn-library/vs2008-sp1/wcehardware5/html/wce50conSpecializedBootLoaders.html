Specialized Boot Loaders

In addition to the Ethernet boot loader provided with each board support package (BSP), Microsoft® Windows® CE also provides specialized boot loaders. Currently, these specialized boot loaders only address the needs of x86-based hardware platform solutions.

For more information about specialized boot loaders, see the following topics:

  • x86 BIOS Boot Loader
  • x86 Serial Boot Loader
  • x86 ROM Boot Loader
