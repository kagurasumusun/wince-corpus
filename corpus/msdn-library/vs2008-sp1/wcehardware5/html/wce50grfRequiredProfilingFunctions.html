Required Profiling Functions

The following table shows the required profiling functions. These functions are required when building a profiling OS image.

Note   These functions are required by all CPUs.
Programming element Description
OEMProfileTimerDisable This function clears and disables a profiler timer.
OEMProfileTimerEnable This function enables a profiler timer.
