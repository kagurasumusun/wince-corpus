Downloading the Boot Loader to the Broadcom VoIP Screen Phone

You must download the Windows CE boot loader to the Broadcom VoIP Screen Phone before you can download the run-time image and evaluate the features in Windows CE 5.0.

To download the Windows CE boot loader to the Broadcom VOIP Screen Phone

  1. Be sure the serial cable is connected to your development workstation and the phone.
  2. On your development workstation, configure the terminal emulation software to the settings shown in the following table.
    Bits per second Data bits Parity Stop bits Flow control
    115200 8 None 1 None
  3. Reboot the phone by pressing the Reset button.

    If you cannot find the Reset button, you can also reboot the phone by unplugging the power adapter, and then plugging it in again.

  4. On your development workstation, press CTRL+Z to go into the boot loader configuration mode.
  5. Press 6, and then press ENTER to clear any old registry settings.
  6. If necessary, press 5, and then press ENTER to change the upgrade flash setting from 0 to 1.
  7. If necessary, press 3, and then press ENTER to change the boot from Ethernet KITL.
  8. Press 9, and then press ENTER to save the boot loader settings.
  9. Download the boot loader image through the kernel independent transport layer (KITL) using Platform Builder.
    Note   The boot loader image should download to flash memory.
  10. Wait for 3 to 5 minutes for the image to be written into flash memory.

    Once the image has been written into flash memory, it should boot on the device.

  11. Reboot the phone.
  12. Press CTRL+Z to return to the boot loader configuration mode.
  13. Press 3, and then press ENTER to make the boot loader boot from flash memory rather than KITL.
  14. Press 9, and then press ENTER to save the new boot loader settings.
  15. Unplug the phone and wait for a few seconds before plugging it in again.
