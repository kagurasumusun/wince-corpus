Setting Up the SMDK2410 Samsung MCU Development Kit Hardware

Before you can download the Windows CE boot loader to your SDB, you must set up and connect the SMDK2410 Samsung MCU Development Kit hardware to a development workstation.

To set up the SMDK2410 Samsung MCU Development Kit hardware

  1. Connect the power supply to the CPU board and the LCD display.
    Note   Be sure the red switch is set from 230 VAC to 115 VAC and that you only use the power supply provided with the Development Kit.
  2. Choose whether to connect the serial cable provided to the COM1 or COM 2 serial port:
    • Connect to COM1 if you are downloading the Windows CE boot loader for the first time.

      Then, connect the other end of the serial cable to your development workstation.

    • Connect to COM2 if the Windows CE boot loader is installed on the SMDK2410.

      Then, connect the other end to your development workstation.

  3. Verify that there is a Media Access Control (MAC) address sticker on the motherboard, unless a MAC address is already stored in the system's flash memory.
  4. Verify that the jumper settings on your motherboard are correct.

    For more information, see Modifying the SMDK2410 Samsung MCU Development Kit Switches and Jumpers.
