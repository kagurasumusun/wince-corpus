SMDK2410 Samsung MCU Development Kit Hardware Limitations

Keep in mind the following SMDK2410 Samsung MCU Development Kit hardware limitations:

  • If you are experiencing flash memory problems, press down the sides of socket U10 while you adjust the NOR flash memory part, and then release pressure on the socket.

    Examples of problems are if a Multi-ICE probe server application cannot write to flash memory or the boot loader image does not boot.

  • To avoid such problems as Multi-ICE causing the system to power down, always use the ATX power supply provided with the SMDK2410 Samsung MCU Development Kit.
  • There are no handshaking signals on COM1.

    To use COM2 for handshaking or RAS, be sure that jumper J17 is set. For more information about the correct settings for jumper J17, see Modifying the SMDK2410 Samsung MCU Development Kit Switches and Jumpers.
