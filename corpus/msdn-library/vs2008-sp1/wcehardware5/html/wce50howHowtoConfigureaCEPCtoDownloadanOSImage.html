How to Configure and Download a Run-Time Image to a CEPC

To configure a CEPC to download a run-time image, you must establish software connections between Platform Builder on your development workstation and the CEPC. You can then download, debug, and view run-time images on your CEPC.

Hardware and Software Assumptions

  • You are familiar configuring settings in your hardware's basic input/output system (BIOS).
  • You have set up your CEPC hardware based on the features you want to evaluate. For more information, see How to Set Up a CEPC.
  • Both your development workstation and CEPC have floppy disk drives.
  • You have a blank 3.5-inch 1.44 MB floppy disk for creating a boot floppy disk.
  • Your CEPC has a supported debug Ethernet card. For more information, see Choosing an Ethernet Card for a CEPC.
  • You have built a CEPC run-time image. For more information, see How to Configure and Build a Run-Time Image for a CEPC.

To track your progress in the following table, select the check box next to each step.

  Step Topic
1. Configure the BIOS on the CEPC to prevent device interrupt conflicts and violation any of the resource setting requirements of the ISA bus. Configuring the BIOS on the CEPC
2. Configure a terminal emulator program to view serial debug output from the COM1 serial port on the CEPC. Configuring HyperTerminal for BSPs
3. Create a boot floppy disk for the CEPC. Creating a Boot Floppy Disk for an x86 SDB
4. Verify that you have included the minimum set of required files on your CEPC boot floppy disk. x86 SDB Boot Floppy Disk Contents
5. Based on type of Ethernet card you chose for the CEPC, you may need to edit the Autoexec.bat file settings on the CEPC boot floppy disk. Editing the Autoexec.bat File for an x86 SDB
6. Insert the CEPC boot floppy disk into the CEPC floppy disk drive. Not applicable
7. Configure a remote connection to the CEPC. Choose the correct topic based on whether you have an Ethernet or a serial connection. Configuring an Ethernet Remote Connection

Configuring a Serial Remote Connection
8. Choose a display mode for the CEPC based on the type of video card you chose for the CEPC. Choosing LoadCEPC.exe Parameters
9. Download a run-time image to the CEPC through your remote connection. Downloading a Run-Time Image
