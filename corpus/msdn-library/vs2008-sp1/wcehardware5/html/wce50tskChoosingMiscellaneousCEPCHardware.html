Choosing Miscellaneous CEPC Hardware

Depending on the operating system (OS) features you want to evaluate, you may need to add hardware to or remove hardware from your CEPC. For current Windows CE hardware list, see this Microsoft Web Site.

To choose miscellaneous CEPC hardware

  • Using the examples in the following table as a guide, choose additional hardware for your CEPC.
