Modifying the AMD DBAu1100 Development Board Switches and Jumpers

To execute the boot loader code, modify the switches and jumpers on the AMD DBAu1100 Development Board.

To modify the AMD DBAu1100 Development Board switches and jumpers

  • Verify that the switches are in the correct On or Off position.

    The following table shows the functionality of the SWAP_BOOT switch labeled S8.

    S8 Function
    No dot (upper position) Boot ROM monitor program
    Dot (lower position) Jump to the flash memory image
