A StencilCaps that indicates the supported stencil-buffer operations.

Remarks

Stencil data is commonly used to mask drawing to particular screen pixels.

The supported stencil operations are assumed to be valid for all three stencil-buffer operation render states (StencilFail, RenderStateManager.StencilPass, and StencilZBufferFail). For more information, see the StencilOperation enumerated type.
