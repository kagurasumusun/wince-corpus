Testing Wireless Connectivity Using WEP Authentication

Connecting to a shared wireless network requires that you provide a WEP key to authenticate to the network. You are not required to enroll your CEPC for a certificate to connect to the SHARED access point.

To test wireless connectivity with a WEP-based access point

  1. Remove the PCMCIA adapter from the PCMCIA slot on your CEPC.
  2. To disable VMINI, perform the following steps:
    1. Choose Start, choose Settings, and then choose Network and Dial-up Connections.
    2. Right-click the VMINI1 icon, and then choose Disable. Do not disconnect your CEPC from PBHOST.
  3. Insert a wireless LAN adapter into the PCMCIA slot on your CEPC.

    A dialog box with the name of your wireless adapter prompts you to select a network from the dropdown list.

  4. Choose SHARED and choose Connect.

    The Wireless Network Properties dialog box appears.

  5. From the Encryption dropdown box, select WEP.
  6. From the Authentication dropdown box, choose SHARED.
  7. Clear the checkbox for The key is provided automatically.
  8. In the Network key field, type the 10-digit WEP key you specified when configuring the SHARED access point.
  9. In the Key index field type 1, and then choose OK.

    Your CEPC tries to associate with the SHARED access point. The dialog box that is titled with the name of your wireless adapter displays the following messages:

    • Scanning
    • Associating
    • Associated with SHARED
    • Connected

    Once the connection has been established, the red mark on the network connection status icon in the taskbar disappears.

  10. To verify that you have successfully connected to your network, launch the Web browser on your CEPC and type the IP address of the SHARED access point in the address bar. If you are connected to the network, the configuration page for SHARED appears.
