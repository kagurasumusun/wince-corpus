Run-Time Image Selection

Before you download a run-time image to a target device, you must choose a type of run-time image to build.

You can choose a debug run-time image or a release run-time image.

You can enable debugger support in either type of run-time image.

For more information about the type of debugging that you can perform with each type of run-time image, see Levels of Debugging Support.
