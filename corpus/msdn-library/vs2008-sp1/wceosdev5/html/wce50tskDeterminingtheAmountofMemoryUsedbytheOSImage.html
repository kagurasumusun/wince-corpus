Determining the Amount of Memory Used by the Run-Time Image

If you build a run-time image and want to determine the amount of memory it uses, you can perform one of the following tasks:

  • Use the command-line tool Viewbin.exe
  • Use the output messages on the Build tab during the Make Image phase

For more information, see Viewbin Tool and Build Phases.

To determine the amount of memory used by the run-time image using Viewbin.exe

  1. From a command prompt build window, enter the following command, where <path> indicates the directory path where Nk.bin is located: 
    viewbin <path>nk.bin
  2. Find the length information from the output to determine the size of the run-time image.

    The number corresponding to the length entry specifies the size of the run-time image.

    The following example shows output produced using the Viewbin tool.

    In this example, the size of the run-time image is 0x00F9F76C or 16,381 KB. 

    ViewBin... nk.bin 
Image Start = 0x00220000, length = 0x00F9F76C
      Start address = 0x00227A08

Checking record #121 for potential TOC (ROMOFFSET = 0x80000000)
Found pTOC  = 0x811bd29c
ROMOFFSET = 0x80000000
Done.

To determine the amount of memory used by the run-time image using output messages from the IDE build window

  1. If you have just built a run-time image using the IDE, examine the end of the output messages on the Build tab in the Output window.
  2. Find the total ROM size information to determine the size of the run-time image.

    The number corresponding to the total ROM size entry specifies the size of the run-time image.
