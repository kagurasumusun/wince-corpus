Configuring Remote Access Policies with Windows Server 2003

After creating your IAS clients, to set the appropriate access permissions and add the required security settings, you need to define the remote access policies for each client.

To configure remote access policies

  1. On TESTSERVER, from Administrative Tools, open Internet Authentication Service.
  2. Create the following policies.
    Policy name Group Authentication type
    EAP-TLS Authentication EAP-TLS Smart Card or other certificate
    EAP-PEAP Authentication EAP-PEAP Protected EAP (PEAP)
    1. On the console tree, right-click the Remote Access Policies node, and then choose New Remote Access Policy.

      The New Remote Access Policy Wizard starts. Choose Next.

    2. On the Policy Configuration Method page, choose Use the wizard to set up a typical policy for a common scenario, then in the Policy name field, type the name of the policy, and then choose Next.
    3. On the Access Method page, choose Wireless, and then choose Next.
    4. On the User or Group Access page, choose Group, and then choose Add. The Select Groups dialog box appears.
    5. In the Enter the object names to select box, type the appropriate group name for your policy, then choose Check Names, and then choose OK.
    6. On the User or Group Access page, choose Next.
    7. On the Authentication Methods page, from the Type dropdown list, select the appropriate authentication type as shown in the previous table, and then choose Next.
    8. Choose Finish to close the New Remote Access Policy Wizard.
