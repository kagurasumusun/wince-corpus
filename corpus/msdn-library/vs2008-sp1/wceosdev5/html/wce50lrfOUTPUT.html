Platform Builder for Microsoft Windows CE 5.0  

OUTPUT

This configuration option specifies the optional output directory where Romimage.exe places the resulting run-time image file.

This option uses the following syntax.

OUTPUT = path

Parameters

path
The full path where Romimage.exe places the output.

Remarks

By default, Romimage.exe puts the output in the same directory as the first module file.
