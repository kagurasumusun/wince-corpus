OS Design Template Options

The New Platform Wizard uses a design template to determine which Catalog items to include by default when it creates an OS design.

In the New Platform Wizard, you can choose a design template for a category of devices as a starting point for an OS design.

For some categories of devices, the New Platform Wizard provides more than one design template. For example, the New Platform Wizard provides several design templates for IP Phone.

By choosing a design template that best fits the functionality you require, you instruct Platform Builder to include relevant Catalog items in the initial OS design.

Note   For some categories of devices, the New Platform Wizard provides only one design template.
