Platform Builder for Microsoft Windows CE 5.0  

Stopping a Build

If you are building a run-time image from an OS design and you want to interrupt the build process, you can stop Platform Builder from completing the build process.

To stop a build

  • From the Build OS menu, choose Stop Build.

    This option is available only when you are building a run-time image.

    If possible, the integrated development environment (IDE) stops the currently executing rule. Otherwise, it stops the build as soon as the currently executing rule finishes.

    Note   If you selected Clean Before Building before running the build, it is recommended that you allow the build to complete.
