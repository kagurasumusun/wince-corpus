ddcore Module

The ddcore module supports the core functionality of DirectDraw.

Components

The following table shows the component that the ddcore module contains.

Component Description Note Library
d3dhook Provides a graphics device interface (GDI)-mapping layer. Exposes no public functions. D3dhook.lib
