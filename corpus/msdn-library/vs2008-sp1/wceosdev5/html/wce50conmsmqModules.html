msmq Modules

The msmq modules support Message Queuing functionality. Message Queuing supports communication between the various parts of a distributed application. Message Queuing technology enables applications that are running at different times to communicate across networks and systems that might be temporarily offline. To accomplish this functionality, applications communicate with each other by sending messages to various message queues. For more information, see Message Queuing.

The following table shows the modules contained in the msmq group.

Module Description Import file
mqoa Supports the Message Queuing server. Mqoa.lib
msmqadm Provides Message Queuing administration and configuration functionality. Msmqadm.lib
msmqd Supports the main Message Queuing engine, which is implemented in a device driver. Msmqd.lib
msmqrt Supports the main Message Queuing run-time application programming interface (API). Msmqapix.lib
visadm GUI support for Msmqadm.exe and configuring Message Queuing.

Source code for this utility is in %_WINCEROOT%\Public\Servers\Sdk\Samples\Msmq.

srmpisapi ISAPI extension that forwards SRMP requests to the MSMQ service.
