commctrl Module

The commctrl module implements the common controls Control Panel. Common controls offer users a familiar interface for performing common tasks, which makes applications easier to learn and use.

The commctrl module contains functions for application developers. For more information, see Working with Common Controls.

These functions are defined in the Commctrl.h header file. To import these functions, link to the Commctrl.lib file.
