Selecting the Supported Transport Layers for an SDK

After you create an SDK for an OS design, you can choose which transport layers you want your SDK to support.

For more information about transport layers, see Custom Transport Layer Additions to an SDK.

To select a supported transport layer for an SDK

  1. From the Platform menu, choose SDK and then choose Configure SDK.

    The SDK Settings dialog box appears.

  2. Choose the Transports tab.
  3. In the Available transports list, select the check box next to each transport layer that you want your SDK to support.

    The SDK can support any built-in protocol. You cannot edit or delete a built-in protocol.

  4. Optional. To add support for a custom protocol, choose Add.

    For information about adding a custom transport layer, see Adding a Custom Transport Layer to an Exported SDK.

  5. Choose OK to close the SDK Settings dialog box and save your changes.
