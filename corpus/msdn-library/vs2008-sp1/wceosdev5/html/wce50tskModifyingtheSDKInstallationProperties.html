Modifying the SDK Installation Properties

After you create an SDK for an OS design, you can modify the properties of the SDK installer by changing the settings on the Install tab of the SDK Settings dialog box.

To modify the SDK installation properties

  1. From the Platform menu, choose SDK and then choose Configure SDK.

    The SDK Settings dialog box appears.

  2. Choose the Install tab.
  3. In the SDK target directory path box, type the path where you want to place the .msi file, or choose Browse to find the location.
  4. In the OS design name box, type the name of your OS design.
  5. In the MSI file name box, type a name for the .msi file to create.
  6. Choose Compress files into the MSI database file (more compact) or Leave files uncompressed in installation subfolder (faster).

    The .msi file that is created contains the entire SDK.

  7. If you want to automatically install the SDK on the current development workstation, select the Launch MSI installation file after successful build check box.

    For more information about these properties, see SDK Installation and Product Properties.

  8. When you finish modifying the settings for your SDK, choose OK to close the SDK Settings dialog box and save your changes.
