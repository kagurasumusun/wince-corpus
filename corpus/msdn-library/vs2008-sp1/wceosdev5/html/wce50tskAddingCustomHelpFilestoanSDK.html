Adding Custom Help Files to an SDK

After you create an SDK for an OS design, you can add custom Help files to the SDK.

If the SDK already contains custom Help files, you can remove the files.

For more information about the tab, see Help Tab.

For more information about Help files, see Custom Help Files.

To add a custom Help file to an SDK

  1. From the Platform menu, choose SDK and then choose Configure SDK.

    The SDK Settings dialog box appears.

  2. Choose the Help tab.
  3. Select the Include custom help files in SDK check box.
  4. In the Path to master CHM (compiled help) file box, type the path of the master .chm file that contains your custom Help.

    - or -

    To view the file system on the development workstation and locate the master .chm file, choose the Browse button, select the .chm file, and then choose Open.

  5. If the master .chm file includes a link to an additional Help file, choose Add, select the additional .chm file, and then choose Open.

    Repeat this step for each linked .chm file.

  6. Choose OK to close the SDK Settings dialog box and save your changes.
