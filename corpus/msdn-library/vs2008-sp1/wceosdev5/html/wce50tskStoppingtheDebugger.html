Stopping the Debugger

After you build and download a run-time image to a target device, and start the debugger, you can stop debugging at any point.

To stop the debugger

  • Press SHIFT+F5, or from the Debug menu, choose Stop Debugging.

    You might need to restart the target device before you can start the debugger again.
