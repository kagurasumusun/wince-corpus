Run-Time Image Download Considerations

You can download a run-time image from a development workstation to a target device by using any communications hardware that Platform Manager supports.

You can add support for your hardware to Platform Manager if Platform Manager does not support it.

If you cannot use the provided Ethernet, serial, or parallel download service with your hardware, you must also create a custom download service.

For more information about download services, see Download Service Selection.

For information about hardware that Platform Manager supports and about adding support for other hardware, see Download Service Selection.

Before you prepare to download a run-time image to a target device with the IDE, consider the following items:

  • Hardware Configuration
  • Run-Time Image Selection
  • Boot Loader Selection
