Platform Builder for Microsoft Windows CE 5.0  

netcf Modules

The modules included in the netfc modules group support the SQL Server 2000 Windows CE and the Microsoft Windows .NET Compact Framework operating system component. For more information, see .NET Compact Framework.

The following table shows the modules contained in the netfc module group.

Module Description Note Library
dotnet The Compact Framework and the files that support it. The Compact Framework is a hardware independent program execution environment for more secure, downloadable applications targeting resource-constrained computing devices. Exposes no public functions in native code. Not applicable.
sqlce20_dp The SQL Server CE 2.0 data provider, the native SQL Server CE 2.0, and the Compact Framework and files that support it. The data provider is used to connect to, execute commands in, and retrieve results from SQL Server CE databases. Exposes no public functions in native code. Not applicable.
sql2000_dp The SQL Server 2000 data provider, and the Compact Framework and files that support it. The data provider is used to connect to, execute commands in, and retrieve results from SQL Server databases (versions 7.0 or later). Exposes no public functions in native code. Not applicable.
