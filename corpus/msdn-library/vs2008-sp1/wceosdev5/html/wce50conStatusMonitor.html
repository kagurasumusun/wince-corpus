Platform Builder for Microsoft Windows CE 5.0  

Status Monitor

The right side of the status bar in the IDE displays the status of each service as an icon. You can hover over an icon to display the name of the corresponding service and a description of its status.

You can run the status monitor in standard mode or in enhanced mode. To switch modes, right-click on the status bar and then choose Standard Target Status or Enhanced Target Status.

The following table shows the information that the status monitor displays in standard mode.

Service Possible status values
Build Building, and Not Building
Download Waiting to Download, Downloading, and Not Downloading
Target Not Connected, Waiting to Connect, and Connected

The following table shows the information that the status monitor displays in enhanced mode.

Service Possible status values
Build Building, and Not Building
Download Waiting to Download, Downloading, and Not Downloading
Target Messages Stopped, Running, and Waiting
Target Control Stopped, Running, Waiting, and Timed Out
Debugger Stopped, Running, Waiting, and Breaking
