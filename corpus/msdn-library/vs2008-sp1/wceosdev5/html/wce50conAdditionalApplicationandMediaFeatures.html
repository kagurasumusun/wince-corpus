Additional Applications and Media Catalog Items

When it is appropriate for the target device, the New Platform Wizard provides you with a list of applications and media Catalog items available for the OS design you are creating.

This step depends on the OS design template you selected to base your OS design on. For example, if you base your OS design on a design template for a network device, this step does not appear in the New Platform Wizard. Applications such as Microsoft WordPad for Windows CE or Internet Explorer are not typically associated with this kind of device.

The Catalog items selected by default are based on the OS design template you chose. These defaults are a starting point, not mandatory Catalog items and settings for your OS design.

You can add or remove the applications and media Catalog items by checking or clearing them in the New Platform Wizard, or by manually making these changes from the Catalog.
