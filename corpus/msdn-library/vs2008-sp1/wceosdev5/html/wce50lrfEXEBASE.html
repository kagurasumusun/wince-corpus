EXEBASE

This macro definition specifies the base address for an .exe file in memory, which is the location in memory that the executable must load.

You can override the default address, 0x00010000, by specifying an alternate address, which can be either the hard-coded base address, or a hex address.

You should only use this macro when TARGETTYPE is set to PROGRAM, which occurs when you build an executable.
