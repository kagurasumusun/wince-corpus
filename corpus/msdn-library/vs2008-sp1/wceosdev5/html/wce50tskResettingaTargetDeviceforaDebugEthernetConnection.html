Resetting a Target Device for a Debug Ethernet Connection

You can reset a target device if it is connected to your development workstation using a debug Ethernet connection.

To reset a target device for a debug Ethernet connection

  • On the Target menu, choose Reset Target Device.
    Note   This menu item works with a debug Ethernet connection only. It is dependent on the hardware platform's implementation of IOCTL_HAL_REBOOT.

    The CEPC hardware platform implements this input/output control. However, other hardware platforms might not implement this control, and might require hardware modification to enable a soft reset.
