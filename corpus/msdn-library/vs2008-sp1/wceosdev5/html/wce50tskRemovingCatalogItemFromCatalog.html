Removing a Catalog Item from an OS Design

After you create an OS design, you can modify it by selecting and removing Catalog items.

To remove a Catalog item

  1. From the View menu, choose Workspace and then choose the OSDesignView tab in the Workspace window.
  2. Select the Catalog item you want to remove from your OS design.
  3. From the context menu, select Delete.

    - or -

    From the Edit menu, select Delete.

  4. If the Remove Dependent Catalog Item dialog box appears, remove the listed Catalog items that depend on the selected item first, and then remove the selected item.

After you successfully remove the selected Catalog item, the list of Catalog items displayed on the OSDesignView tab updates. If it does not update, press the F5 key to refresh the list.
