Adding an Implementation

You can use the CEC Editor to add implementation information that defines a Catalog item.

In your implementation, you can provide information such as the name that identifies an item in the Catalog, and where the item should appear in the tree. For example, you can choose different implementations of audio device drivers from the Catalog item group Audio to include in your OS design.

For more information, see Catalog Item Files.

To add an implementation

  1. From the Tools menu in the IDE, choose CEC Editor.
  2. In the CEC Editor, from the File menu, choose Open and select a .cec file to open.
  3. In the CEC Editor window, navigate to Catalog\Third Party and select the Catalog item group where you want to add an implementation.
  4. From the Insert menu, choose Catalog Item.

    - or -

    From the context menu, choose Insert Catalog Item.

  5. On the General tab, in the Name and Description boxes, type a name and description for the Catalog item you want to add to the Catalog.
  6. Choose the Compatibility tab, select which CPUs will support your Catalog item, and choose OK.
  7. To save your changes to the .cec file, from the File menu, choose Save.

You have added a basic implementation to a .cec file.
