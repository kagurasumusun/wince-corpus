Adding an End-User License Agreement to an SDK

When you create an SDK for an OS design, Platform Builder includes an end-user license agreement (EULA), which is necessary to protect the intellectual property rights of Microsoft components in the SDK. You can choose to include a custom EULA in the SDK.

Adding an end-user license agreement to an SDK

  1. From the Platform menu, choose SDK and then choose Configure SDK.

    The SDK Settings dialog box appears.

  2. Choose the EULA/Readme tab.
  3. Select the Include custom end-user license agreement check box.
  4. In the End-user license agreement path box, type the path to your EULA or choose Browse to find the location of your EULA.

    Your EULA must be saved as a rich text format (.rtf) file.

  5. Choose OK to close the SDK Settings dialog box and save your changes.
