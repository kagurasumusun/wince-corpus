Adding a Transport Layer to the Catalog

If you want other developers to be able to include your transport layer in their OS designs, you can create a Catalog item file (.cec) and add it to the Catalog.

To add a transport layer to the Catalog

  1. Use any text editor to create the .cec file for your transport layer.
  2. Save the .cec file in the workspace.

    You can view the .cec file on the FileView tab of the Workspace window.

  3. Choose Manage Catalog Items from the File menu.
  4. Choose Import.
  5. Choose the .cec file in the Import Catalog Items dialog box, and then choose Open.
  6. If the Catalog is not displayed, display it by doing one of the following:
    • From the View menu, choose Catalog.
    • On the Standard toolbar, click the Catalog button.
  7. Click to expand the entry in the Catalog window that corresponds to the value you specified in the group statement in your .cec file.

    Your newly added transport layer appears under this entry in the Catalog.
