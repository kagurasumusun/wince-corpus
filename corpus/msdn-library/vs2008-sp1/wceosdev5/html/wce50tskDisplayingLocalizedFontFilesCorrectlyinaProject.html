Displaying Localized Font Files Correctly in a Run-time Image

If your run-time image is localized to a locale that requires font files, perform the following steps to display localized font files correctly.

To display localized font files correctly

  1. From the Platform menu choose Settings.
  2. Choose the Locale tab.
  3. From the Locales list, select the language in which your OS design will be localized.
    Note   All the languages that correspond to code page 437 are selected by default. You can remove any languages that are not applicable from the Locales list.
  4. From the Default Language list, select the language to set as the default language.
  5. Choose OK.
