Creating IAS Clients on Windows 2000 Server

A wireless access point that is configured as an Internet Authentication Service (IAS) client functions as a remote network access device. The remote access device will forward all connection and authentication requests from users to the IAS server. To enable IAS-based authentication on your wireless network, you need to configure your Remote Access Service (RAS) server and the 802.1x enabled access point as IAS clients. The IAS server processes the request and either grants or rejects the connection request. If the request is granted, the client is authenticated, and unique keys, from which the WEP key is derived, can be generated for that session.

Because the RAS server and the IAS server are both located on TESTSERVER, you can create a client with the same IP address that is assigned to TESTSERVER.

To create the IAS clients

  1. On TESTSERVER, from Administrative Tools, open Internet Authentication Service.
  2. In the console tree, right-click the Internet Authentication Service (Local) node, and then choose Register Service in Active Directory.
  3. When the Register Internet Authentication Service in Active Directory dialog box appears, choose OK.
  4. When the Services Registered dialog box appears, choose OK.
  5. Create the following IAS clients.
    Friendly name IP address
    TESTSERVER 10.11.0.1
    CE8021X 10.11.0.13

    Perform the following steps for each client:

    1. In the console tree, right-click Clients, and then choose New Client.
    2. In the Friendly name field, type the friendly name for the client, and then choose Next.
    3. In the Client address (IP or DNS) field, type the IP address for the client, and verify that RADIUS Standard appears in the Client-Vendor field.
    4. Type a shared secret, and confirm the shared secret. You will be asked to provide the shared secret for each access point when configuring your wireless access points.
    5. Verify that the Clients must always send the signature attribute in the request checkbox is cleared.
    6. Choose Finish.
  6. To verify that you have configured each IAS client correctly, double-click the Clients node in the console tree to view a list of your IAS clients.

For more information about configuring IAS, see the topic titled, "Checklist: Configuring IAS for dial-up and VPN access" in the Windows 2000 Server Help.
