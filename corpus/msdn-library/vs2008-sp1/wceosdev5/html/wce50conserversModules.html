Platform Builder for Microsoft Windows CE 5.0  

servers Modules

The modules that are included in the servers group provide server support for Windows CE–based OS designs. For more information, see Applications and Services Development.

The following table shows the modules contained in the servers group.

Module Description Note Import file
asp Supports Active Server Pages (ASP). Contains components. Asp.lib
btconfig Supports the Bluetooth gateway configuration utility for an OS design that includes the HTTPD Web server. Exposes no public functions. Btconfig.lib
ftpd Supports the FTP server. Exposes no public functions. Ftpd.lib
genericucp UPnP sample "generic" control point application. Not applicable. genericucp.lib
httpd Supports the Web server implementation. Contains components. Httpd.lib
httpdadm Provides administrative functionality for the Web server. Exposes no public functions. Httpdadm.lib
igd Provides the UPnP sample, the Internet Gateway Device schema implementation. Used in network gateway devices to allow clients to find, and interact with, the gateway igd.lib
mqoa Supports the MSMQ automation service that allows scripting languages to make use of MSMQ functionality. Not applicable. mqoa.lib
msmqadm Provides the MSMQ administration sample. Command line based admin application. msmqadm.lib
msmqadmext Supports the Message Queuing administration Internet Server API (ISAPI) plug-in. Exposes no public functions. Msmqadmext.lib
msmqd Supports the main Message Queuing engine, which is implemented in a device driver. Not applicable. msmqd.lib
msmqrt Supports the main Message Queuing run-time application programming interface (API). Not applicable. msmqrt.lib
mssoap1 Supports the SOAP Toolkit. Not applicable. mssoap1.lib
mssoapr Provides resources for SOAP. Exposes no public functions. Mssoapr.lib
natadmin Supports a sample administration utility for the Gateway. Exposes no public functions. Natadmin.dll
obexapi Provides APIs for the Object Exchange Protocol (OBEX). Exposes no public functions. Obexapi.dll
obexexec Supports OBEX. Exposes no public functions. Obexexec.lib
obexfile Provides file server for OBEX. Exposes no public functions. Obexfile.dll
obexinbx Provides default inbox for OBEX. Exposes no public functions. Obexinbx.dll
obexsrvr Provides server dynamic-link library (DLL) for OBEX. Exposes no public functions. Obexsrvr.dll
obexuuid Supports OBEX. Exposes no public functions. Obexuuid.lib
routenbtd Supports the Netbios gateway proxy. Not applicable. routenbtd.lib
services Hosts services that do not require direct access to the system and isolates those services from the system. Exposes no public functions. Services.lib
smbserver Supports the file & print sharing service. Exposes no public functions. smbserver.lib
soapisap Supports an ISAPI handler. Exposes no public functions. Soapisap.dll
soapprxy The SOAP proxy component. Exposes no public functions. Soapprxy.lib
srmpIsapi ISAPI extension that marshals SRMP requests over HTTP to MSMQ component. Exposes no public functions. srmpisapi.lib
sysisapi Provides a sample ISAPI Web page. Exposes no public functions. Sysisapi.lib
telnetd Supports the Telnet Server. Exposes no public functions. Telnetd.lib
timesvc Supports the SNTP (Network time) client and service. Not applicable. timesvc.lib
upnpcapi Supports Universal Plug and Play (UPnP). Not applicable. Upnpcapi.lib
upnpctrl Supports the UPnP. Exposes no public functions. Upnpctrl.lib
upnphost Supports UPnP device-hosting. Not applicable. Upnphost.lib
upnploader Supports UPnP. Exposes no public functions. Upnploader.lib
upnpreg Supports the UPnP registration tool. Not applicable. upnpreg .lib
upnpsvc Supports UPnP. Exposes no public functions. Upnpsvc.lib
visadm Supports the graphical MSMQ administration utility. Provides a UI on top of msmqadm. visadm.lib
wisc10 Supports SOAP. Exposes no public functions. Wisc10.lib
