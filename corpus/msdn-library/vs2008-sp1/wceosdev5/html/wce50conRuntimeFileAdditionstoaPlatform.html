Platform Builder for Microsoft Windows CE 5.0  

Adding a Run-Time File to an OS Design

Platform Builder includes optional support for Microsoft run-time libraries, including Microsoft Foundation Classes (MFC) for Windows CE and Active Template Library (ATL) for Windows CE.

If you are porting an MFC-based application or an ATL-based application to Platform Builder, you can use the MFC and ATL source files according to the provisions of the license agreement included with the product.

Platform Builder Installation Disk 1 contains Windows CE, MFC, and ATL run-time files.

The following table shows the location of the run-time library files on Disk 1.

Run-time library CD#1 directory
MFC Disk1\CEPB\Others\MFC
ATL Disk1\CEPB\Others\ATL

After Platform Builder is installed, the functionality represented by these files are displayed in the Catalog.

To add support for these libraries on your OS design, from the Catalog, drag the Catalog item onto the OSDesignView tab in the Workspace window, or from the shortcut menu for the Catalog item, choose Add to OS Design.

Note   You create MFC for Windows CE and ATL for Windows CE applications using eMbedded Visual C++ 4.0 or later.
