snmp Module

The snmp module contains the APIs that are required to support the Simple Network Management Protocol (SNMP). For more information, see Simple Network Management Protocol.

To implement SNMP in a Windows CE–based OS design, you must include the ppp module in the OS design.

The snmp module contains functions for application developers, these functions are defined in the Snmp.h header file. To import these functions, you must link to the Snmp.lib file.
