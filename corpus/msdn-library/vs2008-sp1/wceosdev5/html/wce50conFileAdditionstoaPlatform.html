File Additions to an OS Design

You add files to an OS design by adding a project from the Project menu, or by adding individual files.

Files can include any type of file, and including them directly in your OS design allows you to add audio, video, and icons.

If your file requires additional functionality for the file to process, make sure the associated Catalog items are included in your OS design.

You can use custom build settings from the Custom Build Actions tab to add files to your release directory from another location. For more information, see Adding a File to a Run-time Image.

By default, files are entered into CE.bib as files.

The files appear in the Windows directory on your device.
