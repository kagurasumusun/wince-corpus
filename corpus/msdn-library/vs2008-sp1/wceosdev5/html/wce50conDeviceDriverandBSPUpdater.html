Platform Builder for Microsoft Windows CE 5.0  

Device Driver and BSP Updater

In Microsoft® Platform Builder 3.0, the board support package (.bsp) file notified the IDE which drivers to include for a specific operating system (OS) configuration.

In Microsoft® Windows CE 5.0, the .bsp files have been replaced by the driver resolver, which determines the type of driver to add based on your BSP and on the OS configuration you have selected.

The following topics describe the updated driver resolver and the BSP and driver Catalog information:

  • Driver Resolver
  • BSP Catalog Data
  • Driver Catalog Data
