Platform Builder for Microsoft Windows CE 5.0  

Creating a Simple OS Design for Windows Media

Use the following steps to create a simple OS design that can play Windows Media audio and video files.

To create an OS design with Windows Media support

  1. Start Platform Builder on your development workstation.
  2. From the File menu, choose New Platform.

    The New Platform Wizard appears.

  3. Choose Next.
  4. In the Name field, type a name for the OS design, such as MyOSDesign, and then choose Next.
  5. Select the CEPC: X86 check box and choose Next.
  6. Choose Custom Device and then choose Finish.

    The final page of the wizard appears.

  7. Choose Finish.
  8. In the Catalog, expand the Catalog node and add the following Catalog items to your OS design.
    • Standard Shell (follow the path Core OS\Windows CE devices\Shell and User Interface\Shell\Graphical Shell)
    • Streaming Media Playback (follow the path Core OS\Windows CE devices\Graphics and Multimedia Technologies\Media)

    For specific steps, see Adding an Item from the Catalog.

  9. In the Workspace window, on the OSDesignView tab, verify that the Catalog items were added to your OS design.
