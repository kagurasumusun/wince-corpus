Adding the BSP to the Catalog

The BSP Wizard, CEC Editor, and Export Wizard are provided to add your BSP and device driver definitions to the Catalog. These tools help you create, edit, and manage Catalog item (.cec) file definitions for BSP components such as drivers, OALs, boot loaders, or run-time images.

The BSP Wizard and the CEC Editor simplify creating .cec file definitions. Depending on your development stage, the BSP Wizard can be used in different ways.

For more information, see BSP Wizard Overview, CEC Editor, and Export Wizard Overview

To create a definition for your BSP

This procedure assumes that you have created a BSP from the command line and have generated all source, build, binary image builder (.bib), and registry editor (.reg) files to build the BSP.

  • Choose Create a new BSP in the BSP Wizard.

    This choice leads you through creating a BSP definition and the .cec files for your BSP. You can also add drivers to or remove drivers from the BSP with minimal coding efforts.

To clone an existing BSP

This procedure assumes that you are going to start from nothing and create a BSP for your standard development board (SDB). The easiest approach here is to model your BSP after an existing BSP in Windows CE.

  1. From the Platform menu, choose BSP Wizard.
  2. In the BSP Wizard, choose Clone an existing BSP.
  3. Choose an existing BSP that closely matches your SDB and CPU peripherals.

    This choice provides you with a copy of all files from the existing BSP and creates all .cec descriptions for the new BSP.

    You can also add or remove device drivers to and from the BSP with minimal coding efforts.

To add or remove drivers to or from an existing BSP

This procedure assumes you want to add a driver to or remove a driver from a BSP that you have created and added to the Catalog.

Do one of the following:

  • From the Platform menu, choose BSP Wizard and then choose Modify an Existing BSP.
  • In Platform Builder, edit the Catalog item (.cec) file to modify which BSPs and microprocessors are supported.

    This is also an easy way for you to create a driver description in the .cec file. For information, see Catalog Item Files.

To export a BSP as an Windows Installer (.msi) file for use in Platform Builder OS designs

This procedure assumes that you have created the BSP source files and integrated the BSP into the Catalog using the BSP Wizard.

  • Use the Export Wizard in Platform Builder, which packages all BSP files into an .msi file that can be imported into a Platform Builder OS design.

    For more information, see Export Wizard Overview.

To import a BSP that is available as an .msi file from a Microsoft Web site

This procedure assumes that a BSP has been created and exported using Platform Builder and is available on the Microsoft Web site.

  1. From the Platform Builder Start Page, select Downloads.
  2. Search for and choose the BSP you want.

    All necessary BSP files are downloaded to your computer and the BSP definition is added to the Catalog. You can then modify the BSP definition by either adding or removing drivers as necessary. Finally, you can use this BSP in creating new projects.
