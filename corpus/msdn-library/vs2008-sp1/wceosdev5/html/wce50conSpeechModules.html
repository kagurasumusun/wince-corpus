Speech Modules

The speech modules provide support for the SAPI Application Development.

The following table shows the SAPI modules.

Module Description Note Library
sapi Provides core support for the Speech API. Exposes the SAPI interfaces. sapi.lib
sapisvr Provides shared speech COM interfaces. Exposes no public functions or interfaces. sapisvr.lib
