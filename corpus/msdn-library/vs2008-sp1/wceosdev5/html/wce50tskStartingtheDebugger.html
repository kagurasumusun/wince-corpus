Platform Builder for Microsoft Windows CE 5.0  

Starting the Debugger

After you build and download a run-time image to a target device, you can begin debugging if the image includes debugging support.

To start the debugger

  • Press F5, or from the Debug menu, choose Go.

    The Debug tab on the Output window displays debug messages.

If you try to reset the target device immediately after connecting the debugger, you might interrupt the target device while it performs a load notification. If so, the debugger displays a dialog box showing a connection error.

To resolve the problem, from the dialog box, choose Abort, close the debugger, restart Platform Builder, and then manually reset the target device.

To avoid the problem, connect the debugger only after you reset the target device, or wait for all modules to load before resetting the target device.
