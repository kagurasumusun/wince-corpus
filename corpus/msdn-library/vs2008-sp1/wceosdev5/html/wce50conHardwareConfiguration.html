Platform Builder for Microsoft Windows CE 5.0  

Hardware Configuration

You must appropriately configure the communications hardware that connects a development workstation to a target device before downloading a run-time image to the target device.

For example, if you use an Ethernet connection to download a run-time image to a target device and to debug the run-time image on the target device, you must install a debug Ethernet network card.

A debug Ethernet card is a card used for debugging a Windows CE–based device over a standard Ethernet network and requires specific settings for IRQ and I/O base address.

A Windows CE PC-based hardware platform (CEPC) is an example of a target device that supports an Ethernet connection.
