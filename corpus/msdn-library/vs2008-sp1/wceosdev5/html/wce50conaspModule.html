asp Module

The asp module supports the implementation of ASP. ASP provides an open application environment in which you can combine HTML pages, scripts, and ActiveX components to create Web-based applications. The asp module exposes no public functions. For more information, see ASP Functionality in Windows CE.

Components

The following table shows the components contained in the asp module.

Component Description Note Library
aspcolct Collection of ASP objects. Exposes no public functions. Aspcolct.lib
aspparse Supports header files and ASP preprocessor directives. Exposes no public functions. Aspparse.lib
