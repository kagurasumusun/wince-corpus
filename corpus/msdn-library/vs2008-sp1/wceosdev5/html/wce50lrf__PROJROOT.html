__PROJROOT

This macro defines the location of a project.

The following table shows the four conditions covered by makefile.def in the macro declaration.

Build condition Macro declaration Example
Sysgen __PROJROOT=$(_PROJECTROOT)\cesysgen C:\WINCE500\public\cebase\cesysgen
Dependency tree build __PROJROOT=$(_PUBLICROOT)\common C:\WINCE500\public\common
WINCEPROJ set __PROJROOT=$(_PUBLICROOT)\$(WINCEPROJ) C:\WINCE500\public\directx
User project __PROJROOT=$(_PROJECTROOT) C:\WINCE500\public\cebase

For user projects, this macro is used with the _COMMONPUBROOT macro to define the separate public tree created for every user project. The following code example shows how to use these macros.

_COMMONPUBROOT=$(_PUBLICROOT)\common
__PROJROOT = $(_PUBLICROOT)\$(WINCEPROJ)
