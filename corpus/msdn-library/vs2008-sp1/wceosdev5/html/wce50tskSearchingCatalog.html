Searching the Catalog

You can perform a search for a selected Catalog item or Sysgen variable in the Catalog using different parameters.

Note   When searching for a Sysgen variable, be sure to check the properties of the Catalog item to verify the Sysgen variable. For example, a search for SYSGEN_AUDIO results in finding other variables, including SYSGEN_AUDIO_ACM.

To search the Catalog

  1. Right-click in the Catalog and then choose Find.
  2. In the Find what box, enter a full or partial name or description.
  3. Choose the parameters of the search from the following:
    • Search Name
    • Search Description
    • Search Both
  4. Choose which direction you want to search in from your position in the Catalog from the following:
    • Up
    • Down
  5. To find the next instance of your search string, choose Find Next.
  6. To stop the search, choose Cancel.
