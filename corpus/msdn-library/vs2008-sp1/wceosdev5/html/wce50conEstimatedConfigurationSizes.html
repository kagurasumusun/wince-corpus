Estimated Run-Time Image Sizes for OS Designs

Organized by microprocessor type, the following table shows the estimated run-time image sizes in kilobytes (KB) that are built from OS designs based on each design template in Platform Builder.

Estimations are based on test builds using the default settings.

Estimations for the run-time image built from an OS design based on theTiny Kernel design template are based on the size of a release build.

Note   The default settings for Tiny Kernel produce a debug run-time image, which is more than double the size of a release build.
