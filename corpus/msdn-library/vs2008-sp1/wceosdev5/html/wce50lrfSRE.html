SRE

This configuration option specifies whether Romimage.exe generates an .sre file, which is recognized by most ROM burners.

This option uses the following syntax.

SRE = OFF | ON

Parameters

OFF
By default, Romimage.exe does not produce an .sre file.
ON
Romimage.exe produces an .sre file.
