ntlmssp Module

The ntlmssp module supports the Microsoft Windows NT® LAN Manager secure-socket provider.

The ntlmssp module contains a function for application developers, which is defined in the Sspi.h header file. To import this function, you must link to the secure32.lib file that exposes Security Support Provider Interface (SSPI) functions.

For a list of the functions and structures that are supported in the ntlmssp module, see SSPI Functions and Structures.
