Adding a Splash Screen to an SDK Installation

After you create an SDK for an OS design, you can add a splash screen that appears when the SDK is installed.

To add a splash screen to an SDK installation

  1. From the Platform menu, choose SDK and then choose Configure SDK.

    The SDK Settings dialog box appears.

  2. Choose the Splash Screen tab.
  3. Select the Show OEM splash screen at SDK installation check box.
  4. In the Bitmap box, type the path to the bitmap (.bmp) file you want to use as a splash screen, or choose Browse to find the location of the .bmp file.
  5. In the Duration in seconds box, specify the length of time, in seconds, for which the installer displays the splash screen.
  6. Choose OK to close the SDK Settings dialog box and save your changes.
