Creating Project Files for a Transport Layer

Although Platform Builder includes host and server code for TCP/IP and Point-to-Point Protocol (PPP) communications, you can develop your own transport layers, if necessary.

To create project files for a transport layer

  1. From the File menu, choose New Project or File.
  2. In the New Project or File dialog box, choose the Projects tab.
  3. In the Projects box, select WCE Transport Layer.
  4. In the Project name box, type a name for the transport layer and then choose OK.
  5. (Optional) Enter information that will be included in the associated Readme.txt file.
  6. Choose Next, and then Finish to close the Wizard.
