toolhelp Module

The toolhelp module implements the ToolHelp debugger and supports the ToolHelp API functions. For more information, see ToolHelp Reference.

The toolhelp module contains functions for application developers, these functions are defined in the Toolhelp.h header file. To import these functions, you must link to the Toolhelp.lib file.
