EXEENTRY

This macro definition specifies the function that is used as an entry point for the .exe file if TARGETTYPE is set equal to PROGRAM.

EXEENTRY can use the following values.

main
Entry point for a C language application.
WinMain
Entry point for a Windows application. This is the default value, which initializes the C runtime library functions and calls initializers for global C++ objects before calling this function.
Startup
For example, the entry point for a boot application.
