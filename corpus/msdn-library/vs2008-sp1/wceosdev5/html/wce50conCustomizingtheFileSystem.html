Customizing the File System

You can customize your file system by modifying the registry type, changing how the file system stores data, and adding support for user profiles. You can also request additional security keys and synchronize file and database information. The following table shows the topics for customizing the file system.

Topic Description
Selecting the Internal File System for your Target Device Explains the various file system options for your target device.
Selecting the Registry for Your Target Device Explains the various registry options for your target device.
User Profiles Explains how to implement user profiles along with associated registry changes.
Requesting Additional Secure Registry Keys Explains how to send a request for additional secure registry keys.
File and Database Replication Explains the concept of file and database replication.
