Opening the Release Directory

When you build a run-time image based on an OS design, Platform Builder places the completed run-time image in the release directory. This is the location from which you download the run-time image to a target device for further debugging and testing.

The default location of the release directory for your workspace is %PBWORKSPACEROOT%\RelDir\<configuration of OS design>.

To open the release directory

  • From the Build OS menu, choose Open Release Directory.

    A command prompt build window opens in %PBWORKSPACEROOT%\RelDir\<configuration of OS design>.
