Verifying a New Component

The files copied to your release directory constitute your component.

After you build a component, the component files are created in the source directory and replace existing files in the release directory.

To verify a component

  1. Use Windows File Explorer to navigate in your directory tree to the release directory.
  2. Search for the component files in the release directory and then view the modification date to be sure they are the new component files.

    - or -

    Delete the component files after backing them up and then verify the creation date and time after building the new component.
