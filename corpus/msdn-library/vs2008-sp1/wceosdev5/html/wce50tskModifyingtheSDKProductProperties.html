Modifying the SDK Product Properties

After you create an SDK for an OS design, you can modify the product properties of the SDK.

To modify the SDK product properties

  1. From the Platform menu, choose SDK and then choose Configure SDK.

    The SDK Settings dialog box appears.

  2. Choose the Product Properties tab.
  3. To generate a new SDK installation, in the Product name that is displayed when .msi file runs box, type a name that does not match a name from the list.

    - or -

    To update an existing SDK installation, from the list, choose a name previously used.

    The name that you specify appears in the Add/Remove Programs dialog box of Control Panel.

  4. In the Manufacturer name box, type the name of your company.
  5. In the Locale language box, choose the language for your SDK.
  6. In the Product version area, for each subsequent version of the SDK, increment the value in the Build box.

    An SDK has an associated version so that the installer can compare different installations of the SDK. In the Major box and the Minor box, the SDK Wizard provides a default value that matches the version of the Windows CE OS.

  7. When you finish modifying the settings for your SDK, choose OK to close the SDK Settings dialog box and save your changes.
