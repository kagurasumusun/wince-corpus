Preparing to Build a Project

After you create a project in your workspace, if you have previously built a run-time image based on your OS design, you can build your project independently of your OS design.

To prepare to build a project

  1. In the Workspace window, choose the FileView tab and expand the Projects node to display the projects in the workspace..
  2. Select the project you want to build.
  3. From the Build OS menu, choose Set Active Configuration and then select a configuration for your OS design.
    Note   If you estimate your final run-time image size to be at least 32 MB, you must enable a run-time image size that is larger than 32 MB. For more information, see Enabling a Run-Time Image Size Larger Than 32 MB.
  4. From the Project menu, choose Settings; then verify that all tabs in the Project Settings dialog box display the correct settings and that any project conditionals you added are correct.

    When the settings are correct, you can build your project based on your OS design.

    For more information, see Project Settings Dialog Box.

  5. Choose OK to close the dialog box.

    You are ready to build a project. For more information, see Building a Project or Building a Selected Project.
