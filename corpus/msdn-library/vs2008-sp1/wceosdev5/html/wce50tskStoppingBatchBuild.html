Stopping a Batch Build

When you build multiple run-time images based on your OS design using the Batch Build command, you can choose to stop the build from progressing.

Note   If you select Clean Before Building when configuring the batch build, it is recommended that you allow the build to complete.

To stop a batch build

  1. From the Build OS menu, choose Stop Build.

    The IDE stops the currently executing rule, if possible. Otherwise, it stops the build as soon as the currently executing rule finishes.

    The build in progress ends.

    A dialog box appears, asking if you want to continue building using the remaining configurations of your OS design.

  2. If you want the batch build to continue from the next configuration in the list, choose Yes.

    – or –

    If you want to stop the entire batch build, choose No.
