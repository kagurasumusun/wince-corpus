upnpcapi Module

The upnpcapi module supports UPnP. For more information, see Universal Plug and Play (UPnP).

The upnpcapi module exposes functions, which are defined in the Upnpcapi.h header file. To import these functions, you must link to the Upnpcapi.lib file.
