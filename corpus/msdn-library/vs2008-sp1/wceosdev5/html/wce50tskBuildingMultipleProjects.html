Building Multiple Projects

When your workspace contains multiple projects, you can choose to build them consecutively.

To build multiple projects

  1. For the batch build, from the Build Project menu, select from the following flags.
    • To delete intermediate and output files before running the build, select Clean before Building.
    • To create a run-time image from files in the release directory after the build completes, select Make run-time image after building.
  2. From the Build Project menu, choose Build All Projects.
