Development Language Selection for an SDK

If you want developers to use your SDK as a basis for developing applications, you must support a development language in your SDK,

You can configure your SDK to include support for eMbedded Visual C++ and Visual Studio .NET. These development environments consist of the following:

  • An integrated set of windows
  • Tools
  • Menus
  • Toolbars
  • Directories
  • Elements to help create, test, and debug a Windows CE-based application
