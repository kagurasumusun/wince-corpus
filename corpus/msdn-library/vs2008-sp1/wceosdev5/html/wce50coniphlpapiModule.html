iphlpapi Module

The iphlpapi module supports the IP Helper application programming interface (API). For more information, see IP Helper Reference and ICMP Functions.

The iphlpapi module contains functions for application developers, which are defined in the Iphlpapi.h header file. To import these functions, you must link to the iphlpapi.lib file.
