Configuring a Catalog Item

When you configure the implementation for an application, driver, or other Catalog item, you are providing information that the build system requires to build and include the Catalog item in a run-time image, such as which CPUs support this Catalog item.

To configure a Catalog item

  1. In the CEC Editor, from the File menu, select Open, select a .cec file to open, and then choose Open.
  2. In the CEC Editor window, select a Catalog item group to edit.

    For example, if you created a Catalog item group named MyCatalogItem, select its icon in the left pane.

  3. From the Insert menu, choose Catalog Item.
  4. In the right pane, on the General tab, enter information in the required Name field.

    You can also enter additional information about your Catalog item.

  5. On the Compatibility tab, from the CPUs list, select which CPUs your Catalog item will be supported on.
  6. If your Catalog item is BSP-specific, in the right pane, on the Variables tab, in the BSP Directory field, enter the name of the BSP directory for the BSP that will support your Catalog item.

    If your Catalog item is not BSP-specific, leave the BSP Directory field blank.

  7. If your Catalog item is not a Platform Builder user-created project, in the Variable field, enter the variable you set to include your Catalog item in an OS design.
  8. If your Catalog item requires other variables to be set, do the following in the Variables set by this Catalog item grouping:
    • In the Name field, enter the name of the variable.
    • In the Value field, enter a value for the variable and then choose Add.
  9. To save your changes and add your Catalog item to the .cec file, choose OK.
