Configuring Project Build Order

If you have more than one existing project in your workspace, you might want to configure the order your projects are built in.

This is helpful when you have projects that depend upon each other to function.

To accomplish this, you can use the integrated development environment (IDE) to edit the dirs files associated with the project in your workspace.

For more information, see Dirs File.

For more information about adding projects to your OS design, see Adding a Project to an OS Design.

To configure project build order

  1. From the Project menu, choose Set Project Build Order.

    The Workspace Projects Build Order dialog box appears.

  2. Choose from the following:
    • To move a project earlier in the build order, select the project and choose Up.
    • To move the project later in the build order, choose Down.
    • To close the dialog box and save your settings, choose OK.
