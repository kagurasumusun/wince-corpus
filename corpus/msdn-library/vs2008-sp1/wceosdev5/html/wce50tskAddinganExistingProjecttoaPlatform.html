Adding an Existing Project to an OS Design

After you create an OS design, you can add existing projects to your design in the IDE. For more information, see Creating a Project.

To add an existing project to an OS design

  1. From the Project menu, choose Insert and then choose Existing Project.

    - or -

    In the Workspace window, on the FileView tab, select the Projects node; then from the context menu, choose Insert Existing Project.

  2. In the Open dialog box, from the Files of type list, select the type of project you want to add.
  3. Browse to the location of the file for the project you want to add.
  4. Choose OK.
  5. Verify that the project you added appears in the Workspace window on the OSDesignView tab.
