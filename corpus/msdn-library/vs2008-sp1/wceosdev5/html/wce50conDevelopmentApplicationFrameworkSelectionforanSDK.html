Platform Builder for Microsoft Windows CE 5.0  

SDK Support for Application Frameworks

Platform Builder enables you to include application frameworks in your SDK.

Application frameworks are collections of classes, macros, and global functions that provide a skeleton for building applications, components, and controls. They also supply standard UI implementations that can be placed onto these skeletons.

If a framework is included in your OS design, your SDK supports that framework by default.

If your OS design does not contain a framework, you can still add support for a framework in your SDK using the SDK settings.

Windows CE supports implementations of the following frameworks:

  • MFC
  • MFC ActiveX controls
  • The Active Template Library (ATL) for Windows CE
  • Console applications
  • The Microsoft® .NET Compact Framework supported by Visual Studio .NET

If you include support for a framework that is not in your OS design, the .NET Compact Framework IDE dynamically loads that framework to the target device during development. This allows your OS design to support .NET Compact Framework development on demand, saving valuable ROM space if .NET Compact Framework development is never used.

For more information about the .NET Compact Framework, see information on MSDN Online.
