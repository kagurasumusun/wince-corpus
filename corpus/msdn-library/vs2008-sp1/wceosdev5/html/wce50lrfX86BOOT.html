X86BOOT

This configuration option specifies whether a jump instruction is inserted at the x86 reset vector address. Optionally, you can specify the target jump address.

This option uses the following syntax.

X86BOOT = OFF | ON | address

Parameters

OFF
This parameter, which is the default, ensures that no jump instruction is added to the run-time image.
ON
This parameter adds a jump instruction to the run-time image at the reset vector location. By default, this jump instruction branches to the beginning of the kernel run-time image address.
address
This parameter, which is a hexadecimal address, adds a jump instruction to the specified address at the reset vector location in the run-time image.

Remarks

If you specify a target jump address, the low-order word subtracts 0xFFF3, as shown in the following code example.

jump_offset = LOWORD(x86boot) - LOWORD(0xfff3);

If you select the ON parameter, the same operation is applied to the startup address and used as the jump_offset.
