__COMMONPUBROOT

This macro defines the location of a user project.

For user projects, this macro is used with the _PROJROOT macro to define the separate public dependency tree created for every user project. The following code example shows how to use these macros.

_COMMONPUBROOT=$(_PUBLICROOT)\common
__PROJROOT = $(_PUBLICROOT)\$(WINCEPROJ)
