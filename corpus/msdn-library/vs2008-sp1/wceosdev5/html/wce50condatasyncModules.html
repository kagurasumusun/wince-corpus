Platform Builder for Microsoft Windows CE 5.0  

datasync Modules

The datasync module group includes modules that support data synchronization between a Windows-based desktop computer and Microsoft Windows CE–based portable devices. For more information, see ActiveSync.

The following table shows the modules that the datasync module group contains.

Module Description Note Library
cefobj Supports file synchronization. Exposes no public functions. Cefobj.lib
dmconsol Sample application that uses the device management SDK. Not applicable. dmconsol.lib
dminfos A sample DLL that supplies the core device management engine with hardware inventory information. Not applicable. dminfos.lib
dmscript Device Management Script engine. Not applicable. dmscript.lib
dmsdk Exposes the device management API. Not applicable. dmsdk.lib
dmsvc Core device management service. Not applicable. dmsvc.lib
eventrst Supports base synchronization. Exposes no public functions. Eventrst.lib
pegobj Supports e-mail and personal information manager (PIM) synchronization. Exposes no public functions. Pegobj.lib
rapisrv Supports base synchronization. Exposes no public functions. Rapisrv.lib
repllog Supports Microsoft® ActiveSync® 3.0 or later, which synchronizes data and monitors the connection between the device and the host computer. Exposes no public functions. This module, along with the rapiserv module, must be included in the OS design to make calls to RAPI APIs. Not applicable.
rra_stm Supports base synchronization. Exposes no public functions. Rra_stm.lib
systemcpl Supports base synchronization. Exposes no public functions. Systemcpl.lib
udp2tcp Implements the User Datagram Protocol (UDP) to TCP client. Exposes no public functions. Udp2tcp.lib
unload The Windows CE application uninstaller. Not applicable. unload.lib
wceload The Windows CE application installer. Not applicable. wceload.lib
