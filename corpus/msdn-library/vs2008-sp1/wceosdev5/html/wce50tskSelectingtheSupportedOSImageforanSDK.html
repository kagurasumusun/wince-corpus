Choosing the Configuration that the SDK Supports

When you configure an SDK for an OS design, you must select a CPU that the SDK supports, and you must choose a configuration.

Note   To configure an SDK for the Emulator, choose the Emulation tab. You cannot configure the SDK for the Emulator if your OS design does not support the Emulator. For more information, see Modifying Emulation Settings for an SDK.

To choose the configuration that the SDK supports

  1. Be sure you have run the SDK Wizard for the OS design.

    For information about using the SDK Wizard, see Configuring an SDK.

  2. From the Platform menu, choose SDK and then choose Configure SDK.
  3. Choose the CPU tab.
  4. Select the check box next to the CPU family you want the SDK to support.

    For more information, see CPU Tab.

  5. Select the CPU family and then choose Edit.
  6. From the list, select a configuration to support and then choose OK.
  7. Choose OK to close the SDK Settings dialog box and save your changes.
