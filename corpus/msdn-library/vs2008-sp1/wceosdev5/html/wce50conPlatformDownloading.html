Run-Time Image Downloading Process

After you create an OS design and build a run-time image, you must download the run-time image to a target device.

The integrated development environment (IDE) provides a mechanism that allows you to download, using a number of types of communications hardware, a run-time image to a target device.

To download a run-time image to a target device, you must first configure a connection from a development workstation to the target device. For more information about establishing such a connection, see Downloading a Run-Time Image.
