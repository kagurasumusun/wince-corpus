Platform Builder for Microsoft Windows CE 5.0  

ie Modules

The modules that are included in the ie group provide Internet functionality for Windows CE–based OS designs. For more information, see Internet Explorer 6 for Windows CE Components.

The following table shows the modules contained in the ie group.

Module Description Note Import file
htmlhelp Provides end user help for Windows CE-based Internet Explorer. Exposes no public functions. htmlhelp.lib
ieceext A component internal to Internet Explorer. Exposes no public functions. Ieceext.lib
iepeers Provides printing functionality for Microsoft® Internet Explorer. Also supports the ClientCaps behavior. Exposes no public functions. Iepeers.lib
iesample Builds an Internet-demonstration system using Internet Explorer components. Exposes no public functions. Iesample.lib
iesimple A sample browser container application with a full-screen, windowless, user interface. It depends on shdocvw. Exposes no public functions. Iesimple.lib
imaging Image decoding library for Microsoft Pocket Internet Explorer. Exposes no public functions. imaging.lib
Imgutil Plug-in for Image decoder. Exposes no public functions. imgutil.lib
inetcpl Provides a sample Internet Control Panel. Exposes no public functions. Inetcpl.cpl
mlang Implements a set of services that help convert Internet data to international markets. Exposes the MultiLanguage API. Mlang.lib
mshta Provides support for the HTML Applications (HTA) API. Exposes no public functions. mshta.lib
mshtml Provides support for the Microsoft HTML parsing and rendering engine (MSHTML). Exposes no public functions. Mshtml.lib
msls31 Text Layout engine. Exposes no public functions. Msls31.lib
msxml3 Implements Microsoft XML Parser version 3.0 (MSXML) SP1, which is a parser for Extensible Markup Language (XML) files. Not applicable. Msxml3.lib
pngfilt Provides support for PNG Image. Exposes no public functions. pngfilt.lib
shdoclc Contains the User Interface component for shdocvw. Exposes no public functions. shdoclc.lib
shdocvw ActiveX control host, also known as the Layout Manager. This module acts as a wrapper that adds a number of high-level functions, including navigation functions, to a Web browser. Exposes the IWebBrowser2 document viewer API. Shdocvw.lib
shlwapi A component internal to Internet Explorer. Exposes no public functions. Shlwapi.lib
tvlens Module Supports television-style navigation.   Tvlens.lib
urlmon Provides support for Uniform Resource Locator (URL) Moniker Services (URLMON). This module monitors URLs and reports changes to Web sites. Not applicable. Urlmon.lib
urlmonui Supports the URLMON replaceable user interface. Not applicable. urlmonui.lib
uuid Includes GUID and CLSID information. Exposes no public functions. Uuid.lib
wininet Supports the Microsoft Win32® Internet API set. This module can be used to make the Internet an integral part of any application. Not applicable. Wininet.lib
wininetui Supports the WinInet replaceable user interface. Not applicable. wininetui.lib
