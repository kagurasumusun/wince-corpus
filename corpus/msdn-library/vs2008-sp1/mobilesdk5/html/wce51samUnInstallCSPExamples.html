UnInstall Configuration Service Provider Examples for OMA Client Provisioning

Send Feedback on this topic to the authors

The following XML examples can be used as templates to configure settings for the UnInstall Configuration Service Provider.

Note   A provisioning document that contains XML to uninstall an application should contain only that XML and no other provisioning information. Following this practice is the cleanest way to uninstall an application.
  • Query the Device for All Applications that can be Uninstalled Example
  • Querying the Device to See if an Application can be Uninstalled Example
  • Uninstalling an Application Example

In these examples, below the UnInstall characteristic type, replace the values for each parm and characteristic type with values that correspond to your system.
