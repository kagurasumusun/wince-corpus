File Change Notification

Send Feedback on this topic to the authors

This code sample is named FileChangeNotif. It demonstrates how to enlist a window for receiving file system change notifications.

Feature Area

  • Shell Application Development for Windows Mobile-based Devices

Relevant APIs

  • Shell and User Interface Reference
  • SHChangeNotifyRegister function
  • SHChangeNotifyDeregister function

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution file is copied to the following folder:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\FileChangeNotif\FileChangeNotif.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

To use the application

  1. Click on the AV icon at the bottom of the Today screen.
  2. Click Start to begin receiving file change notifications.
  3. Make a change to the file system (for example, create or delete a file).
  4. Return to the application and click Refresh Display. A report on the file system changes displays.

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
