EM_GETPENMODE

Send Feedback on this topic to the authors

The EM_GETPENMODE message gets the new pen mode, pen, select, or space, of the RichInk control.

EM_GETPENMODE
  wParam = (WPARAM) 0; 
  lParam = (LPARAM) 0;

Parameters

wParam
Reserved; set to 0.
lParam
Reserved; set to 0.

Return Values

Returns the value of penMode, which contains the pen mode (one of the following values MODE_PEN, MODE_SELECT, or MODE_SPACE).

Flag Information
MODE_PEN User can draw.
MODE_SELECT User can select text.
MODE_SPACE User can collapse and expand white space.

No error conditions are returned.

Remarks

#define EM_GETPENMODE (WM_USER + 328)

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: None
OS Versions: Windows CE 3.0 and later
Header: richink.h
Library: richink.lib
