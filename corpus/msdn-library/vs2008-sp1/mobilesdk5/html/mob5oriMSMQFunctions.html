MSMQ Functions

Send Feedback on this topic to the authors

The following table shows the MSMQ functions with a description of the purpose of each.

Programming element PPC SP Description
MQCloseCursor X X This function closes a specific cursor, allowing Message Queuing (MSMQ) to release the associated resources.
MQCloseQueue X X This function closes a given queue.
MQCreateCursor X X This function creates a cursor for a specific queue and returns a handle to the cursor.
MQCreateQueue X X This function creates a private queue.
MQDeleteQueue X X This function deletes a queue from the local computer.
MQFreeMemory X X This function frees memory allocated by MSMQ.
MQGetMachineProperties X X This function retrieves information about a Queue Manager on the local machine.
MQGetQueueProperties X X This function retrieves the specified set of properties for a local queue.
MQHandleToFormatName X X This function returns a direct format name for the queue based on its handle.
MQMgmtAction X X This function changes the state of a computer or queue.
MQMgmtGetInfo X X This function retrieves information about a queue or the Message Queuing installation on a computer.
MQOpenQueue X X This function opens a queue for sending messages to the queue or for reading its messages.
MQPathNameToFormatName X X This function returns a private direct format name based on the MSMQ path name provided.
MQReceiveMessage X X This function allows you to read messages in the queue.
MQSendMessage X X This function sends a message to the queue corresponding to the handle hDestinationQueue.
MQSetQueueProperties X X This function sets the properties of a local queue.
