Fonts Functions

Send Feedback on this topic to the authors

The following table shows the fonts functions with a description of each.

Programming element PPC SP Description
AddFontResource X X This function adds the font resource from the specified file to the Windows font table. The font can subsequently be used for text output by any Microsoft Windows CE 5.0–based application.
CreateFontIndirect X X This function creates a logical font that has the characteristics specified in the specified structure. An application can subsequently select the font as the current font for any device context (DC).
DrawText X X This function draws formatted text in the specified rectangle. DrawText formats the text according to the specified format method.
EnableEUDC X X This function enables or disables end-user-defined characters (EUDC).
EnumFontFamilies X X This function enumerates the fonts in a specified font family that are available on a specified device. This function supersedes the EnumFonts function.
EnumFontFamProc X X This function is an application-defined callback function that retrieves data that describes the available fonts.
EnumFonts X X This function enumerates the fonts available on a specified device. This function is provided for compatibility with early versions of the Microsoft Windows SDK. Whenever possible, applications should use the EnumFontFamilies function.
EnumFontsProc X X This function is an application-defined callback function that processes font data from the EnumFonts function.
ExtTextOut X X This function draws a character string by using the currently selected font. You can provide an optional rectangle that ExtTextOut can use for clipping, opaquing, or both.
GetCharABCWidths X X This function retrieves the widths, in logical units, of consecutive characters in a specified range from the current TrueType font. This function succeeds only with TrueType fonts.
GetCharWidth32 X X This function retrieves the widths, in logical coordinates, of consecutive characters in a specified range from the current font.
GetTextAlign X X This function retrieves the text-alignment setting for the specified device context.
GetTextColor X X This function retrieves the current text color for the specified device context.
GetTextExtentExPoint X X This function retrieves the number of characters in a specified string that fit within a specified space and fills an array with the text extent for each of those characters. A text extent is the distance between the beginning of the space and a character that fits in the space.
GetTextExtentPoint X X This function computes the width and height of the specified string of text.
GetTextExtentPoint32 X X This function computes the width and height of the specified string of text.
GetTextFace X X This function retrieves the typeface name of the font that is selected into the specified device context (DC).
GetTextMetrics X X This function fills the specified buffer with the metrics for the currently selected font.
RemoveFontResource X X This function removes the fonts in the specified file from the Windows CE font table.
SetTextAlign X X This function sets the text-alignment value for the specified device context.
SetTextColor X X This function sets the text color of the specified device context to the specified color.
