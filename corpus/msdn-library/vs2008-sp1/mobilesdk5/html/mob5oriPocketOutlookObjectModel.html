Pocket Outlook Object Model Application Development for Windows Mobile-based Devices

Send Feedback on this topic to the authors

The Pocket Outlook Object Model API is a COM-based library that provides programmatic access to Personal Information Manager (PIM) data on Windows Mobile-based devices. It also provides functionality for manipulating PIM item collections and folders.
