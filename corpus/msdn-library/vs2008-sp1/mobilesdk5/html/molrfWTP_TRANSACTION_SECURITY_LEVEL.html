WTP_TRANSACTION_SECURITY_LEVEL

Send Feedback on this topic to the authors

This enumeration defines Wireless Transaction Protocol (WTP) secure transaction security levels.

enum WTP_TRANSACTION_SECURITY_LEVEL
{
  WTP_TRANSACTION_SECURITY_LEVEL_NOTSECURE = 1,
  WTP_TRANSACTION_SECURITY_LEVEL_SECURENOAUTH,
  WTP_TRANSACTION_SECURITY_LEVEL_GATEWAYAUTH,
};

Elements

WTP_TRANSACTION_SECURITY_LEVEL_NOTSECURE
The connection is not secure.
WTP_TRANSACTION_SECURITY_LEVEL_SECURENOAUTH
The connection is more secure, but no authentication was performed.
WTP_TRANSACTION_SECURITY_LEVEL_GATEWAYAUTH
Authentication was performed at the gateway.

Requirements

Pocket PC Platforms: Pocket PC 2002 and later.
Smartphone Platforms: Smartphone 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: Wap.h.
