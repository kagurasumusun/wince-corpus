WAP Structures

Send Feedback on this topic to the authors

The following structures are used with Wireless Application Protocol.

Structure Description
PUSHMSG This structure represents the message delivered from the push router client by the function PushRouter_GetMessage.
WAP_ADDRESS This structure represents a source or destination address.
WAP_PRIMITIVE_BASE This structure represents the primitive type from which all other primitive types are derived.
WDP_UNITDATA This structure represents unit data and is used for transmitting data as unreliable datagrams.
WTP_ABORT This structure defines the mechanism used for stopping an existing transaction and identifying an existing transaction that has been stopped.
WTP_INVOKE This structure defines the mechanism used for initiating a new transaction and indicating that a new transaction has been initiated.
WTP_RESULT This structure defines the result of a previously initiated class 2 transaction, as sent by the responder to the transaction.
