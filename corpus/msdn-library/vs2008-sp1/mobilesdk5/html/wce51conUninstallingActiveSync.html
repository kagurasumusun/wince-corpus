Uninstalling Applications using Microsoft ActiveSync

Send Feedback on this topic to the authors

The ActiveSync Application Manager displays a list of applications installed on the device and enables the user to remove applications by completing the following steps:

  1. From the ActiveSync main menu, select Tools, and then select Add/Remove Programs. All applications on the device appear in a list. A check box appears to the left of each application in the list. A check mark in the check box indicates that the application is installed on the device, or that the application has a desktop component that is also installed.
  2. Clear the check box next to the application to remove it from the device. If the application has a desktop component, that item remains in the list but its check box remains cleared. If the application does not have a desktop component, clearing the check box removes the application from the list and the device.
    Note   Selecting an application and then selecting the Remove button at the bottom of the screen removes the application from the device and also removes any desktop component.
