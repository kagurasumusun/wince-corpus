EM_UNDOEVENT

Send Feedback on this topic to the authors

The EM_UNDOEVENT message reverts to the state of the last action.

EM_UNDOEVENT
  wParam = (WPARAM) 0;
  lParam = (LPARAM) 0;

Parameters

wParam
Reserved; set to 0.
lParam
Reserved; set to 0.

Return Values

None.

#define EM_UNDOEVENT (WM_USER 234)

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: None
OS Versions: Windows CE 3.0 and later
Header: richink.h
Library: richink.lib
