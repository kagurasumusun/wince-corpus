Property Sheets Structures

Send Feedback on this topic to the authors

The following table shows the property sheets structures with a description of the purpose of each.

Programming element Description
PROPSHEETHEADER This structure defines the frame and pages of a property sheet.
PROPSHEETPAGE This structure defines a page in a property sheet.
PSHNOTIFY This structure contains information for the PSN_APPLY and PSN_RESET messages.
