IPOutlookApp::get_VisitingCity

Send Feedback on this topic to the authors

The VisitingCity property gets or sets an ICity object that represents the city in which the user is currently visiting.

Note   This method is supported only for Windows Mobile 2000 software for Pocket PCs.

To get the value of the VisitingCity property, call the property method described here.

To set the value of the VisitingCity property, see the IPOutlookApp::put_VisitingCity property method.

Syntax

HRESULT get_VisitingCity(
  ICity ** ppVisitingCity
);

Parameters

ppVisitingCity
[out] Reference to an ICity object that represents the city in which the user is currently visiting.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: None
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
