Control Panel Engine (SP Only)

Send Feedback on this topic to the authors

Control Panel Engine is used to generate the Settings control panels and to execute subsequent user requests for settings updates. When the user requests to view a certain Settings control panel, Control Panel Engine sends an XML document to Configuration Manager that queries all the settings on the requested Settings control panel. The Settings control panel then receives an XML document that contains those settings and information about how to display them in the Settings control panel. The UI is then generated, and the user can change the values of the settings. When the user is finished, Control Panel Engine sends back an XML document detailing the settings and the new values that need to be set, which Configuration Manager then executes.
