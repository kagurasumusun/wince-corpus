Home Screen Structures

The following table shows the Windows Mobile-based Smartphone structures for the Home Screen.

Structure Description
PEKeyDown (SP) Handles a PE_KEYDOWN event.
PEPaint (SP) Provides information about the paint event.
PluginEvent (SP) Specifies one of the enumerators from the PluginEventID enumeration.
