Storage Manager Functions

Send Feedback on this topic to the authors

The following table shows the Storage Manager functions.

Programming element PPC SP Description
CeGetVolumeInfo X X This function retrieves information on a specific volume.
CreatePartition X X This function creates a partition on the store and marks the partition with the default file system.
CreatePartitionEx X X This function creates the store.
DeletePartition X X This function deletes a partition from the store. A partition can only be used if it has not been mounted.
DismountPartition X X This function dismounts the partition and the file system residing on top of it.
DismountStore X X This function dismounts all file systems mounted on a store.
FindClosePartition X X This function closes the partition search handle.
FindCloseStore X X This function closes the store search handle.
FindFirstPartition X X This partition finds the first partition on the store.
FindFirstStore X X This function finds the first store registered in the system.
FindNextPartition X X This function continues a partition search from a previous call to the FindFirstPartition function.
FindNextStore X X This function finds the next store registered in the system.
FormatPartition X X This function formats the partition with the default file system of the loaded partition driver.
FormatPartitionEx X X This function formats the partition with the default file system of the loaded partition driver.
FormatStore X X This function performs a clean format of the storage volume. This removes all partitioning information in the store.
GetPartitionInfo X X This function gets information on the partition.
GetStoreInfo X X This function gets information about the store.
MountPartition X X This function mounts the partition by loading a file system on top of it.
OpenPartition X X This function opens a partition and returns a handle to the partition.
OpenStore X X This function opens the storage volume.
RenamePartition X X This function renames the partition.
SetPartitionAttributes X X This function sets the attributes for the partition.
