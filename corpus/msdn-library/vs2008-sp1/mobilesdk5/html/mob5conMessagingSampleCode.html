Windows Mobile Version 5.0 SDK  

Messaging Sample Code

Send Feedback on this topic to the authors

The Windows Mobile Version 5.0 Pocket PC and Smartphone SDKs ship with a set of code samples that demonstrate how to use MAPI. The default install location for them is C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\.

Sample Description
Hello (SMS) Demonstrates a simple Short Message Service (SMS) message sender.
Sending Data over SMS Demonstrates how to send and receive WDP messages over Short Message Service (SMS), using SMS to transport data.
Context Menu Extension Handler Demonstrates how to use customized context menus.
MAPI Rules Demonstrates how to implement a MAPI Rules Client.
Sending e-mail Demonstrates how to send an e-mail message using MAPI.
New Messaging Transport Demonstrates how to create a customized Messaging transport.
