IImageSinkFilter Interface

Send Feedback on this topic to the authors

This interface is used to set the properties of the image sink filter.

In addition to the methods inherited from IUnknown, the interface exposes the following methods.

Method Description
IImageSinkFilter::SetQuality Sets the quality level for image encoding.
IImageSinkFilter::SetEncoderParameters Used to pass values for image encoding parameters to the image sink filter.
