MAPI Configuration Service Provider Constants

Send Feedback on this topic to the authors

These constants specify the amount of message body to download. They are used by Configuration Service Providers.

Constant Value Description
kdwOptionValueNone 0 Do not download any of the message body.
kdwOptionValueAll 0xFFFFFFFF Download the entire message body.
