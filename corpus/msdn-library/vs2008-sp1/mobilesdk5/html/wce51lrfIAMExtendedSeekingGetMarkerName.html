IAMExtendedSeeking::GetMarkerName

Send Feedback on this topic to the authors

This method retrieves the name associated with the specified marker.

HRESULT GetMarkerName(
  long  MarkerNum,
  BSTR* pbstrMarkerName
);

Parameters

MarkerNum
[in] Specifies the marker number.
pbstrMarkerName
[out] Pointer to a variable that receives the marker name.

Return Values

If the method succeeds, it returns S_OK. If it fails, it returns an HRESULT error code.

Remarks

The caller must release the returned BSTR by calling SysFreeString.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements. See Setting Up the Build Environment for more information.

Pocket PC Platforms: Windows Mobile 5.0 and later
Smartphone Platforms: Windows Mobile 5.0 and later
OS Versions: Windows CE 5.01 and later.
