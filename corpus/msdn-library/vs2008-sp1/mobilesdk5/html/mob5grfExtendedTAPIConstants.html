Extended TAPI Constants

Send Feedback on this topic to the authors

The following constants are used with Extended TAPI.

Constant Description
Air Interface Rates Identify the rate at which the mobile device and the base station could communicate.
Barring Modes Identify the type of phone services the line is capable of supporting (e.g., voice, data, etc.).
Caller ID State Identify whether to send Caller ID information.
Channel Rates Identify possible per-channel rates at which the mobile device could communicate with the network.
Equipment States Identify the equipment states.
GPRS Classes Identify General Packet Radio Service (GPRS) classes.
Line Capability Classes Identify line capability classes.
Mute State Identify mute states.
Operator Formats Identify operator formats.
Radio Presence Indicate radio presence or absence.
Radio States Identify the state of the radio hardware.
Registration Status Identify the registration status of the device.
System Type Identify the CDMA or GSM line system types.
