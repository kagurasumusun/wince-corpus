Available Platform Builder Components (No Support Provided)

Component Name Description
USB Host-Side and Human Interface Devices (HID) Drivers Enables connection of USB-compliant devices to Windows CE-based devices.
Real-time communication (RTC) Enables messaging, presence, and audio (voice over IP) between any two IP-enabled devices.

RTC is based on the Session Initiation Protocol (SIP), which is an Internet Engineering Task Force (IETF) standard.

Microsoft Systems Management Server Client Enables full integration of Windows CE-based devices with enhanced management environments like those supplied by Microsoft Systems Management Server.
Sample Bluetooth Profiles Enables OEMs to develop Bluetooth profiles on top of Microsoft's Bluetooth stack, expanding the number of support profiles.
