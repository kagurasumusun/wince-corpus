APPLICATION Configuration Service Provider Classes

Send Feedback on this topic to the authors

OMA considers each transport to be an application and requires a corresponding APPLICATION Configuration Service Provider. For more information, see APPLICATION Configuration Service Providers.

The following classes are used to implement thes Configuration Service Providers:

  • Application class
  • AppAuth class
  • AppAddr class
  • AppPort class
