UPnP C Device Host Functions

Send Feedback on this topic to the authors

The following table shows the UPnP C Device Host functions with a description of the purpose of each.

Programming element PPC SP Description
UpnpAddDevice X X This function creates a UPnP device instance as described by the UPNPDEVICEINFO structure.
UpnpGetSCPDPath X X This function sends out UPnP announcements for this device tree.
UpnpGetUDN X X This function retrieves the UPnP Unique Device Name (UDN) for a device. The
UpnpPublishDevice X X This function sends out UPnP announcements for this device tree.
UpnpRemoveDevice X X This function terminates an existing UPnP device instance.
UpnpSetControlResponse X X This function sends a response to the control point after the hosted device has received a control request.
UpnpSetErrorResponse X X This function sends an error response to the control point if an error has occurred when fulfilling a control request.
UpnpSetRawControlResponse X X This function sends a raw control response to the control point after the hosted device has received a control request.
UpnpSubmitPropertyEvent X X This function sends one or more evented variables to all remote subscribers using the UPnP event notification scheme.
UpnpUnpublishDevice X X This function announces that the device is leaving the network.
