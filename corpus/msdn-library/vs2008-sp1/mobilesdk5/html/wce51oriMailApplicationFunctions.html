New Messaging Functions for Windows Mobile Version 5.0

Send Feedback on this topic to the authors

The following table shows the new Messaging functions with a description of the purpose of each.

Function Description
MailComposeMessage Displays a new message, determined by the information in the MAILCOMPOSEFIELDS structure.
MailDisplayMessage Displays an existing message. The message is specified by the ENTRYID.
MailSwitchToFolder Switches to a folder.
MailSwitchToAccount Switches to an account.
MailSyncMessages Synchronizes mail.
