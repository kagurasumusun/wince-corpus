Messaging API (MAPI)

Send Feedback on this topic to the authors

The Windows Mobile-based Messaging API (MAPI) provides the messaging architecture for Windows Mobile-based devices. It is the mobile device implementation of MAPI for the desktop computer. MAPI is used by applications and transports to manipulate mail data, to create folders and messages, and to support notifications of changes to existing MAPI related data. MAPI for Windows Mobile-based devices provides a set of classes, interfaces, functions, and other data types to facilitate the development of messaging applications for mobile devices.
