Device Configuration API

Send Feedback on this topic to the authors

The Device Configuration API provides the functionality that enables access to the configuration management components of a Windows Mobile-based device.

The following table shows the functions used for device configuration.

Function PPC SP Description
DMProcessConfigXML X X This function grants local access to the configuration management functionality of the mobile device.
QueryPolicy X X This function retrieves the value of the policy specified.
