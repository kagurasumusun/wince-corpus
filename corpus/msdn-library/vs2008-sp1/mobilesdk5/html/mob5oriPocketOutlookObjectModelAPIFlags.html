Pocket Outlook Object Model API Flags

Send Feedback on this topic to the authors

This section provides detailed information about the Pocket Outlook Object Model API flags described in the following table.

Flag PPC SP Description
Contact Chooser Flags X X Defines the behavior of the Contact Chooser.
Drawing State Flags X X Indicates the drawing state for a PIM item.
GetIDsFromNames Flags X X Indicates how a named property is created.
Notification Flags X X Identifies the type of change (either local, remote, or both) made to a data store.
Source Provider Customization Type Flags X X Describes the types of customizations that a particular Source Provider supports.
Source Provider PIM Type Ownership Flags X X Describes the types of PIM items that are associated with a particular Source Provider.
