VR_STYLE

Send Feedback on this topic to the authors

The VR_STYLE enumeration describes how the Voice Recorder behaves. Its values are arguments for the dwStyle member of the CM_VOICE_RECORDER structure, which represents the Voice Recorder Control.

typedef enum tagVR_STYLE {
  VRS_NO_OKCANCEL = 0x0001,
  VRS_NO_NOTIFY  = 0x0002,
  VRS_MODAL    = 0x0004,
  VRS_NO_OK    = 0x0008,
  VRS_NO_RECORD  = 0x0010,
  VRS_PLAY_MODE  = 0x0020,
  VRS_NO_MOVE   = 0x0040,
  VRS_RECORD_MODE = 0x0080,
  VRS_STOP_DISMISS = 0x0100,
} VR_STYLE;

Enumerators

VRS_NO_OKCANCEL
The notification OK/CANCEL is not displayed.
VRS_NO_NOTIFY
There is no parent notification.
VRS_MODAL
The control is modal.
VRS_NO_OK
The notification OK is not displayed.
VRS_NO_RECORD
The RECORD button is not displayed.
VRS_PLAY_MODE
It will immediately play the supplied file when launched.
VRS_NO_MOVE
Grip is removed and the user cannot move around the control.
VRS_RECORD_MODE
It will immediately record when launched.
VRS_STOP_DISMISS
Dismiss control when stopped.

Requirements

Smartphone Platforms: Smartphone 2002 and later
Pocket PC Platforms: Pocket PC 2000 and later
OS Versions: Windows CE 3.0 and later
Header: voicectl.h
Library: voicectl.lib
