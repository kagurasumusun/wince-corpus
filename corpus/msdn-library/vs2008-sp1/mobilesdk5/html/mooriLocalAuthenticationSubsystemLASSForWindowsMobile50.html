Local Authentication Subsystem (LASS) for Windows Mobile-based Devices

Send Feedback on this topic to the authors

Security services in Microsoft Windows CE 5.0 include the Local Authentication Subsystem (LASS). LASS provides the infrastructure that enables user authentication independent of the application and the specific authentication mechanism. Password authentication provides only one option, a password, for verification. However, LASS allows you to support sophisticated authentication mechanisms, such as biometrics. In addition, you can use LASS functionality to specify event-based policies to authenticate users.

If you are an application developer, you might want to create an application that installs an AE and performs user verification. For more information about writing applications for LASS, see LASS Application Development.
