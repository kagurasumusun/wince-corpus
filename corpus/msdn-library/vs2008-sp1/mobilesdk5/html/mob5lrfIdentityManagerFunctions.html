Identity Manager Functions

Send Feedback on this topic to the authors

The following table shows the Identity Manager functions with a description of the purpose of each.

Programming element PPC SP Description
PeerCreatePeerName X X This function creates a new name based on the existing name of the specified peer identity and classifier.
PeerEnumGroups X X This function creates and returns a peer enumeration handle that is used to enumerate all the peer-to-peer groups associated with a specific peer identity.
PeerEnumIdentities X X This function creates and returns a peer enumeration handle that is used to enumerate all the peer identities that belong to a specific user.
PeerIdentityCreate X X This function creates a new peer identity and returns its name.
PeerIdentityDelete X X This function permanently deletes a peer identity.
PeerIdentityExport X X This function allows a user to export one peer identity.
PeerIdentityGetCryptKey X X This function retrieves a handle to a cryptographic service provider (CSP).
PeerIdentityGetFriendlyName X X This function retrieves the friendly name of the peer identity.
PeerIdentityGetXML X X This function retrieves an XML description of the peer identity.
PeerIdentityImport X X This function imports a peer identity.
PeerIdentitySetFriendlyName X X This function modifies the friendly name for a specified peer identity.
