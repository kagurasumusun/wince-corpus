DLN_DOWN

Send Feedback on this topic to the authors

The DLN_DOWN notification message is sent to indicate the VK_DOWN key was pressed while the document list view was open.

Syntax

DLN_DOWN
  PDLNHDR = (DLNHDR) lParam;

Parameters

PDLNHDR
Reference to a DLNHDR structure is sent as the lParam of a WM_NOTIFY SendMessage to the parent window of the document list.

The nmHdr.code member of the DLNHDR structure is set to DLN_DOWN.

The iItem member of the DLNHDR structure is set to -1.

The pszPath member of the DLNHDR structure is set to NULL.

Return Values

None.

Requirements

Pocket PC: Pocket PC 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: doclist.h.
Library: doclist.lib.
