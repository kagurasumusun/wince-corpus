OlItemType

Send Feedback on this topic to the authors

The OlItemType enumeration identifies POOM item types.

Syntax

enum OlItemType {
  olAppointmentItem = 1,
  olContactItem     = 2
  olTaskItem        = 3
  olCityItem        = 102
};

Elements

olAppointmentItem
An Appointment item.
olContactItem
A Contact item.
olTaskItem
A Task item.
olCityItem
A City item.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
