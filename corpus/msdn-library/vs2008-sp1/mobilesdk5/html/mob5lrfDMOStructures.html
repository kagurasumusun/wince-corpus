DMO Structures

Send Feedback on this topic to the authors

The following table describes the Microsoft DirectX Media Object (DMO) structures.

Structure PPC SP Description
DMO_MEDIA_TYPE X X Describes the format of the data used by a stream in a DMO.
DMO_OUTPUT_DATA_BUFFER X X Describes an output buffer used by a DMO.
DMO_PARTIAL_MEDIATYPE X X Partially describes a media type used by a DMO.
