w2 APPLICATION Configuration Service Provider Examples for OMA Client Provisioning

Send Feedback on this topic to the authors

This example can be used as a template to configure settings for the APPLICATION Configuration Service Provider when W2 is the APPID. To use this example, you must replace the values as appropriate. For more information about the syntax of the provisioning file, see OMA Client Provisioning Files.

Adding a New Favorite

This example creates the following favorites in a folder named Shopping:

  • Phones
  • Cars
  • Videos

On Smartphones, these favorites are listed in positions 0, 1 & 2. In this example, www.cars_inc.com is set as the Start page.

Note   You can provision Multiple W2 sections on a device. However, only one W2 file should have the STARTPAGE parameter set. If more than one has this parameter set, the last one seen is set as the Start page.
<wap-provisioningdoc version="1.0">
 
   <characteristic type="APPLICATION">
      <parm name="APPID" value="w2"/>

      <parm name="NAME" value="Shopping"/>
 
      <characteristic type="RESOURCE">
         <parm name="URI" value="http://www.phones_inc.com"/>
         <parm name="NAME" value="Phones"/>
         <parm name="ORDER" value="0"/>
      </characteristic>
 
      <characteristic type="RESOURCE">
         <parm name="URI" value="http://www.cars_inc.com"/>
         <parm name="NAME" value="Cars"/>
         <parm name="ORDER" value="1"/>
         <parm name="STARTPAGE"/>
      </characteristic>
 
      <characteristic type="RESOURCE">
         <parm name="URI" value="http://www.videos_inc.com"/>
         <parm name="NAME" value="Videos"/>
         <parm name="ORDER" value="2"/>
      </characteristic>
 
   </characteristic>
</wap-provisioningdoc>
