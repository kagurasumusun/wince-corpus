Metabase Settings for FileOperation Configuration Service Provider

Send Feedback on this topic to the authors

Using the FileOperation Configuration Service Provider, an OEM or Mobile Operator can implement security for files.

The following table shows the default state of the metabase. These settings represent the implementation of the current version and may change in future versions. These settings can also be customized by OEMs and Mobile Operators.

This table may be useful for troubleshooting purposes, or as an example of how you can restrict a new file.
