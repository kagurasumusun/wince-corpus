Start Menu

Send Feedback on this topic to the authors

The Start Menu contains all applications installed on a Windows Mobile-based Pocket PC and Smartphone, and is where users launch the applications. The list is ordered so that the first four applications are predefined: Inbox, Contacts, Calendar, and Internet Explorer. All other applications are by default in alphabetical order. The Start Menu displays eight applications on each screen page. If there are many applications available on the device, the Start Menu will wrap onto several screens.

The following topics describe how to customize the Start menu in a Windows Mobile-based Pocket PC and Smartphone.
