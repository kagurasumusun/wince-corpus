IXMLParser::GetRoot

Send Feedback on this topic to the authors

This method gets the root object of the current node.

Syntax

HRESULT GetRoot( 
  PVOID * ppRoot
);

Parameters

ppRoot
[in] Pointer to the root object of the node created by using IXMLNodeFactory::CreateNode.

Return Values

This function returns S_OK if the function is successful, otherwise an error code is returned (E_FAIL).

Remarks

The IXMLParser::SetRoot method provides the pNodeParent argument for all root level IXMLNodeFactory::CreateNode calls. Because any reference counting that may be required on this object must be handled manually, it might be necessary to call the IXMLParser::GetRoot method after parsing.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: xmlparser.h
