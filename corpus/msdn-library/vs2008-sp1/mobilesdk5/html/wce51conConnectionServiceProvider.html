Connection Manager Configuration Service Provider

Send Feedback on this topic to the authors

Connection Manager configuration service providers are certain configuration service providers that provide connection information, such as routes and costs, to the ConnMgr.exe application. A Connection Manager configuration service provider must be configured specifically for Connection Manager as described in Connection Manager Configuration. Connection Manager configuration service providers are implemented as dynamic link libraries (DLLs).

For example, a Connection Manager RAS configuration service provider can contain connection information representing the worldwide RAS telephone numbers for a corporate network, or information on how to establish a link to a corporate network through an Internet connection. The Connection Manager RAS configuration service provider also knows which function calls must be made to establish a RAS connection.

Note   Even though all the numbers and routes to corporate networks represent a separate connection each, this information is not displayed on the device. The device UI only shows a single connection, the corporate network, which is automatically connected on demand.
