Virtual Private Networks

Send Feedback on this topic to the authors

Mobile devices can establish a virtual private network (VPN), which is an authenticated private communication channel over a public network. The supported VPNs are the Point-to-Point Tunneling Protocol (PPTP) and Internet Protocol Security (IPSec)/Layer 2 Tunneling Protocol (L2TP).

For more detailed information about VPNs, PPTP, or IPSec/L2TP, see MSDN.
