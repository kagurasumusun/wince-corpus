Use WML

Send Feedback on this topic to the authors

Internet Explorer Mobile supports Wireless Markup Language (WML) specification 1.3. WML is a markup language based on XML, and is used to specify content and user interface for narrowband devices, including cellular phones and pagers.

More details can be found at the Open Mobile Alliance (OMA) Forum web site //www.wapforum.org/what/technical.htm
