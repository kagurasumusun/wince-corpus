RapiConfig Tool

Send Feedback on this topic to the authors

RapiConfig.exe is a desktop configuration tool that enables the execution of provisioning XML on a Windows Mobile-based device or emulator connected using ActiveSync.

RAPICONFIG [/P] [/M] filename

Parameters

/P
Process the document
/M
Return metadata
filename
Specifies XML configuration document

Remarks

Either the mobile operator or the corporate manager can use this method to configure the device. For information about provisioning a device using this tool, see Provisioning From a Desktop Computer Using Remote API and ActiveSync.

Note   Bootstrapping a Windows Mobile-based device using RAPI is disabled by default. For more information see Enabling Remote API (RAPI) Bootstrapping.

As of Windows Mobile Version 5.0, if you enable Normal mode on the non-phone version of Pocket PC (I.e., Lock the device), you can change it back to Trusted mode using RapiConfig. If you change the Grant Manager Role from USER_AUTH to MANAGER, and then enable Normal mode, you can no longer change it back to Trusted mode using RapiConfig.
