Extensible Authentication Protocol

Send Feedback on this topic to the authors

The Extensible Authentication Protocol allows third-party authentication code to interact with the implementation of the Point-to-Point Protocol (PPP) included in the Windows CE–based Remote Access Service (RAS). The Extensible Authentication Protocol (EAP) is also used with 802.1x and EAP over LAN (EAPOL) authentication.
