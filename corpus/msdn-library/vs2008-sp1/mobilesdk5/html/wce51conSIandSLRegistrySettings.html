SI and SL Registry Settings

Send Feedback on this topic to the authors

Service Indication (SI) and Service Loading (SL) is contained in the Windows Mobile-based Pocket PC and is available in the GSM Phone SKU. The following code example shows how to set the HKEY_LOCAL_MACHINE\Software\Microsoft\SIClnt registry key:

[HKEY_LOCAL_MACHINE\Software\Microsoft\SIClnt]
"ForceWSPProtocol"=dword:1

Setting ForceWSPProtocol to 1 causes the SI/SL URIs to change so that WSP is used as the protocol for retrieving content. For example, http://www.windowsmobilepocketpc.com becomes, and is displayed as, wsp://www.windowsmobilepocketpc.com. The default for ForceWSPProtocol is off.

To enable WSP protocol, add the registry key to the device's platform.reg file in the Adaptation Kit.

Another, more specific way to force the download over the work connection, usually over WAP, is for Connection Manager to exception the URLs by using a regular expression.

Note   To avoid potential security problems it is important to follow the guidelines for setting the push proxy gateway address and over-the-air (OTA) policies. For more information, see Setting Push Router Policies and Security Roles.

The following table shows the SI /SL HKEY_LOCAL_MACHINE\Security\Policies\Policies registry key values.

SI/SL Setting Registry key
Enable SI setting "0000100d"=dword:c00

The default policy setting is SECROLE_PPG_AUTH | SECROLE_PPG_TRUSTED.

Default setting for a Windows Mobile-based Pocket PC and Smartphone.

Disable SI setting "0000100d"=dword:0
Enable SL setting (Smartphone default) "0000100c"=dword:800

The default policy setting is SECROLE_PPG_TRUSTED.
Disable SL setting "0000100c"=dword:0

Default setting for Windows Mobile-based Pocket PC.
Note   SI/SL is also disabled if the registry values do not exist.

The following code examples show how to enable and disable SI and SL:

  • Enable SI setting. This is the Windows Mobile-based Pocket PC and Smartphone default.

    The default policy setting is SECROLE_PPG_AUTH | SECROLE_PPG_TRUSTED. 

    [HKEY_LOCAL_MACHINE\Security\Policies\Policies]
"0000100d"=dword:c00
  • Disable SI setting. 
    [HKEY_LOCAL_MACHINE\Security\Policies\Policies]
"0000100d"=dword:0
  • Enable SL setting. This is the Windows Mobile-based Smartphone default setting.

    The default policy setting is SECROLE_PPG_TRUSTED. 

    [HKEY_LOCAL_MACHINE\Security\Policies\Policies]
"0000100c"=dword:800
  • Disable SL setting. This is the Windows Mobile-based Pocket PC default setting. 
    [HKEY_LOCAL_MACHINE\Security\Policies\Policies]
"0000100c"=dword:0

Setting Protocol Prefixes for SI Messages

The HKEY_LOCAL_MACHINE\System\Inbox\SIClnt\SIProtocols registry setting identifies the protocol prefixes that SI messages can receive. SI messages that contain links with protocol prefixes not defined in this registry key are dropped silently.

Security Note   SI messages that allow execution of file links mean that an unsuspecting user could launch a malicious application instead of downloading content onto their device.

The following are the default settings for the SI protocol filter:

[HKEY_LOCAL_MACHINE\System\Inbox\SIClnt\SIProtocols]

"http"=dword:0

"https"=dword:0

"wsp"=dword:0

"wsps"=dword:0

OEMs and Mobile Operators can change this list by adding similar registry settings. Although the values must be type DWORD, the actual DWORD value is ignored.
