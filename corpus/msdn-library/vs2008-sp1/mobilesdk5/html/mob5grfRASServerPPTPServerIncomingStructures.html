RAS Server/PPTP Server (Incoming) Structures

Send Feedback on this topic to the authors

The following table shows the RAS server structures with a description of the purpose of each.

Programming element Description
RASCNTL_SERVERSTATUS This structure contains information about the status of a RAS server.
RASCNTL_SERVERLINE This structure contains server line-specific information.
RASCNTL_SERVERUSERCREDENTIALS This structure contains information specific to a server user.
RASCNTL_SERVERCONNECTION This structure contains information about the connection status of an enabled line.
RASCNTL_SERVER_IPV6_NET_PREFIX This structure contains information about the IPv6 network prefix pool that can be assigned by the server.
