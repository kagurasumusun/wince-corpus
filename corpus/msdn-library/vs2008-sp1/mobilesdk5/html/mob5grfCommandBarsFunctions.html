Command Bars Functions

Send Feedback on this topic to the authors

The following table shows the command bar functions with a description of the purpose of each.

Programming element PPC SP Description
CommandBar_AddBitmap X X This function adds one or more images to the list of button images available for use in the command bar.
CommandBar_AddAdornments X X This function adds the Close button (X) to the command bar.
CommandBar_InsertComboBox X X This function inserts a combo box into the command bar.
CommandBar_InsertMenubar X X This function inserts a menu bar into the command bar.
CommandBar_InsertMenubarEx X X This function inserts a menu into a command bar.
CommandBar_Create X X This function instantiates a new command bar.
CommandBar_DrawMenuBar X X This function repositions and redraws the command bar after a menu in the command bar has been modified.
CommandBar_GetMenu X X This function retrieves the handle to a menu on the command bar.
CommandBar_Height X X This function retrieves the height of the command bar in pixels.
CommandBar_Show X X This function shows or hides the command bar.
