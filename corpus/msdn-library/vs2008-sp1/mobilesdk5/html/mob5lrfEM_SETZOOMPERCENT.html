EM_SETZOOMPERCENT

Send Feedback on this topic to the authors

The EM_SETZOOMPERCENT message sets the zoom percentage of the RichInk control.

EM_SETZOOMPERCENT
  wParam = (WPARAM) (UINT) zoomPercent;
  lParam = (LPARAM) 0;

Parameters

zoomPercent
Zoom percent to set.
lParam
Reserved; set to 0.

Return Values

None.

Remarks

#define EM_SETZOOMPERCENT (WM_USER + 290)

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: None
OS Versions: Windows CE 3.0 and later
Header: richink.h
Library: richink.lib
