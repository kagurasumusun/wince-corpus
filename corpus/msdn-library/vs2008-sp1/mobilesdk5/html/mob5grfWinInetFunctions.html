WinInet Functions

Send Feedback on this topic to the authors

On Windows CE, all WinInet functions are aliased to call the Unicode implementation. (On the desktop WinInet functions are aliased to call the ANSI implementation.)

The following table shows the WinInet functions with a description of the purpose of each.

Programming element PPC SP Description
CommitUrlCacheEntry X X This function stores data in the specified file in the Internet cache and associates it with the given Uniform Resource Locator (URL).
CreateUrlCacheEntry X X This function creates a local file name for saving the cache entry based on the specified URL and the file extension.
DeleteUrlCacheEntry X X This function removes the file associated with the source name from the cache, if the file exists.
FindCloseUrlCache X X This function closes the specified cache enumeration handle.
FindFirstUrlCacheEntry X X This function begins the enumeration of the Internet cache.
FindFirstUrlCacheEntryEx X X This function begins a filtered enumeration of the Internet cache.
FindNextUrlCacheEntry X X This function retrieves the next entry in the Internet cache.
FindNextUrlCacheEntryEx X X This function finds the next cache entry in a cache enumeration started by the FindFirstUrlCacheEntryEx function.
FtpCommand X X This function issues an arbitrary FTP command to the FTP server.
FtpCreateDirectory X X This function creates a new directory on the FTP server.
FtpDeleteFile X X This function deletes a file stored on the FTP server.
FtpFindFirstFile X X This function searches the specified directory of the specified FTP session.
FtpGetCurrentDirectory X X This function retrieves the current directory for the specified FTP session.
FtpGetFile X X This function retrieves a file from the FTP server and stores it under the specified file name, creating a new local file in the process.
FtpGetFileEx X X This function retrieves a file from the FTP server and stores it under the specified file name, creating a new local file in the process.
FtpGetFileSize X X This function retrieves the file size of the requested FTP resource.
FtpOpenFile X X This function initiates access to a remote file for writing or reading.
FtpPutFile X X This function stores a file on the FTP server.
FtpPutFileEx X X This function stores a file on the FTP server.
FtpRemoveDirectory X X This function removes the specified directory on the FTP server.
FtpRenameFile X X This function renames a file stored on the FTP server.
FtpSetCurrentDirectory X X This function changes to a different working directory on the FTP server.
GetUrlCacheEntryInfo X X This function retrieves data about a cache entry.
GetUrlCacheEntryInfoEx X X This function searches for the Uniform Resource Locator (URL) after translating any cached redirections applied in offline mode by the HttpSendRequest function.
HttpAddRequestHeaders X X This function adds one or more Hypertext Transfer Protocol (HTTP) request headers to the HTTP request handle.
HttpEndRequest X X This function ends an HTTP request that was initiated by HttpSendRequestEx.
HttpOpenRequest X X This function opens an HTTP request handle.
HttpQueryInfo X X This function queries for information about an HTTP request.
INTERNET_STATUS_CALLBACK X X This function is a prototype for an application-defined status callback function.
InternetAttemptConnect X X This function attempts to make a connection to the Internet.
InternetCheckConnection X X This function allows an application to check if a connection to the Internet can be established.
InternetCloseHandle X X This function closes a single Internet handle or a subtree of Internet handles.
InternetCombineUrl X X This function combines a base and relative URL into a single URL. The resultant URL is canonicalized.
InternetConfirmZoneCrossing X X This function checks for changes between secure and nonsecure URLs.
InternetConnect X X This function opens an FTP or HTTP session for a specified site.
InternetCrackUrl X X This function breaks down a URL into its component parts.
InternetCreateUrl X X This function creates a URL from its component parts.
InternetErrorDlg X X This function displays a dialog box for the error that is passed to it, if an appropriate dialog box exists.
InternetFindNextFile X X This function continues a file search from a previous call to FtpFindFirstFile.
InternetGetConnectedState X X This function retrieves the connected state of the local system.
InternetGetConnectedStateEx X X This function retrieves the connected state of the specified Internet connection.
InternetGetCookie X X This function retrieves the cookie for the specified URL.
InternetGetLastResponseInfo X X This function retrieves the last WinInet function error description or server response on the thread calling this function.
InternetGoOnline X X This function prompts the user for permission to initiate connection to a URL.
InternetLockRequestFile X X This function allows the user to place a lock on the file that is being used.
InternetOpen X X This function initializes an application's use of the WinInet functions.
InternetOpenUrl X X This function begins reading a complete FTP or HTTP Universal Resource Locator (URL).
InternetQueryDataAvailable X X This function queries the amount of data available.
InternetQueryOption X X This function queries an Internet option on the specified handle.
InternetReadFile X X This function reads data from a handle opened by the InternetOpenUrl, FtpOpenFile, or HttpOpenRequest function.
InternetReadFileEx X X This function reads data from a handle opened by the InternetOpenUrl, FtpOpenFile, or HttpOpenRequest function.
InternetSetCookie X X This function creates a cookie associated with the specified URL.
InternetSetCookieEx X X This function creates a cookie associated with the specified URL.
InternetSetFilePointer X X This function sets a file position for InternetReadFile.
InternetSetOption X X This function sets an Internet option on the specified handle.
InternetSetOptionEx X X This function sets an Internet option.
InternetSetStatusCallback X X This function sets up a callback function that WinInet functions can call as progress is made during an operation.
InternetTimeFromSystemTime X X This function formats a date and time according to the specified RFC format — as specified in the Hypertext Transfer Protocol (HTTP) Specification 1.0.
InternetTimeToSystemTime X X This function takes an HTTP time/date string and converts it to a SYSTEMTIME structure.
InternetUnlockRequestFile X X This function unlocks a file that was locked using InternetLockRequestFile.
InternetWriteFile X X This function writes data to an open Internet file.
RetrieveUrlCacheEntryFile X X This function locks the cache entry file associated with the specified URL.
SetUrlCacheEntryInfo X X This function sets the specified members of the INTERNET_CACHE_ENTRY_INFO structure.
UnlockUrlCacheEntryFile X X This function unlocks the cache entry that was locked while the file was retrieved for use from the cache.
InternetSetPerSiteCookieDecisionA X X Sets a decision on cookies for a given domain. ANSI implementation.
InternetSetPerSiteCookieDecisionW X X Sets a decision on cookies for a given domain. Unicode implementation.
InternetGetPerSiteCookieDecisionA X X Retrieves a decision on cookies for a given domain. ANSI implementation.
InternetGetPerSiteCookieDecisionW X X Retrieves a decision on cookies for a given domain. Unicode implementation.
InternetClearAllPerSiteCookieDecisions X X Clears all decisions that were made about cookies on a site by site basis.
InternetEnumPerSiteCookieDecisionA X X Retrieves the domains and cookie settings of Web sites for which site-specific cookie regulations are set. ANSI implementation.
InternetEnumPerSiteCookieDecisionW X X Retrieves the domains and cookie settings of Web sites for which site-specific cookie regulations are set. Unicode implementation.
PrivacySetZonePreferenceW X X Retrieves the privacy settings for a given URLZONE and PrivacyType. Unicode implementation.
PrivacyGetZonePreferenceW X X Sets the privacy settings for a given URLZONE and PrivacyType. Unicode implementation.
