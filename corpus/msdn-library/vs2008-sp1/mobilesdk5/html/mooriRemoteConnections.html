Remote Connections

Send Feedback on this topic to the authors

The following topics provide information about technologies and services for accessing resources from a remote location.

In this Section

Remote API (RAPI) Reference
Describes the programming elements for RAPI, an interface that enables an application running on a desktop computer to make function calls on a Windows Mobile–based device.
Remote API 2 (RAPI2)
Describes the RAPI functions that are an extension of the Windows CE Remote API.
Extensible Authentication Protocol
Describes an authentication protocol used by RAS servers.
Remote Access Service (RAS)
Describes the RAS interface, which is a method of connecting to remote servers over PPP.
