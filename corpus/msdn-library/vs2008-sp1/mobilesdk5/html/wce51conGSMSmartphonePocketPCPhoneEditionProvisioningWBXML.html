WBXML and Windows Mobile-Based Devices

Send Feedback on this topic to the authors

Windows Mobile Version 5.0 supports all of the binary encoded XML (WBXML) tokens supported by Windows Mobile 2003-based devices. This includes tokens defined in WAP Client Provisioning version 1.0 and Microsoft custom tokens.

Windows Mobile Version 5.0 also supports, WBXML files as defined in OMA Provisioning Content Specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C). This specification defines a standard for compressing XML text files, using a tokenized format, in order to achieve over the air transmission efficiency. The specification is located at this OMA website.

This section defines the token tables for custom parameters and continuous provisioning that are specific to Microsoft Windows Mobile-based devices. These tokens are in addition to those already defined in section 7 of the OMA Provisioning Content Specification, which are not repeated here.

The Microsoft custom tokens for WBXML files specified in OMA Client Provisioning version 1.1 are in new code pages (202, 201, 203, and 204). They include tokens for new settings, available only in Windows Mobile Version 5.0.

  • Element Tokens
  • Attribute Start Tokens
  • Attribute Value Tokens
