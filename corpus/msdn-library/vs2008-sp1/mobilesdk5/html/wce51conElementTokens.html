Element Tokens

Windows Mobile Version 5.0 supports all of the standard tokens in code page 0 as defined in OMA-WAP-ProvCont-v1_1-20030813-C.

The following Microsoft custom element tokens are in Windows Mobile Version 5.0 code page 200.

Tag name Token
characteristic-query Element 20
parm-query Element 21
nocharacteristic Element 22
noparm Element 23
characteristic-error Element 24
parm-error Element 25
characteristic-query-error Element 26
parm-query-error Element 27
nocharacteristic-error Element 28
noparm-error Element 29
