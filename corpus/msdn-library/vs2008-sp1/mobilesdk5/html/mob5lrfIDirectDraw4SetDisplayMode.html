IDirectDraw::SetDisplayMode

Send Feedback on this topic to the authors

This method sets the mode of the display-device hardware.

HRESULT SetDisplayMode(
  DWORD dwWidth, 
  DWORD dwHeight, 
  DWORD dwBPP, 
  DWORD dwRefreshRate, 
  DWORD dwFlags
);

Parameters

dwWidth
Width of the new mode.
dwHeight
Height of the new mode.
dwBPP
Bits per pixel (bpp) of the new mode.
dwRefreshRate
Refresh rate of the new mode. Set this value to 0 to request the default refresh rate for the driver.
dwFlags
No additional flags are currently supported. This parameter must be set to 0.

Return Values

If the method succeeds, the return value is DD_OK.

If the method fails, the return value may be one of the following error values:

DDERR_GENERIC
DDERR_INVALIDMODE
DDERR_INVALIDOBJECT
DDERR_INVALIDPARAMS
DDERR_LOCKEDSURFACES
DDERR_SURFACEBUSY
DDERR_UNSUPPORTED
DDERR_WASSTILLDRAWING

Remarks

As Windows CE does not support display mode changes, DDERR_INVALIDMODE will be returned if any mode other than the current one is passed to SetDisplayMode.

Windows CE does not support DDSDM_STANDARDVGAMODE.

Requirements

Pocket PC Platforms: Windows Mobile 5.0 and later
Smartphone Platforms: Windows Mobile 5.0 and later
OS Versions: Windows CE 5.01 and later
Header: Ddraw.h.
Library: Ddraw.lib.
