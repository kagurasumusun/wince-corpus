Data from Push Router

Send Feedback on this topic to the authors

After the Push Router has received a document and determined that the push message body (payload) should go to Configuration Manager, the Push Router starts Configuration Host, which is a component that is responsible for loading and unloading Configuration Manager. The Push Router then sends the message to Configuration Manager. While Configuration Manager is processing the configuration message, the Push Router queues incoming payloads and forwards them one at a time for processing to the Configuration Manager component.
