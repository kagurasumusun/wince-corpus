File Management Functions

Send Feedback on this topic to the authors

The following table describes the functions you can use with device storage cards to manage files.

Function PPC SP Description
EnumProjectsEx X X A Projects Control API function that enumerates folders in main memory or on a mountable file system, such as a storage card.
EnumProjectsFilesEx X X A Projects Control API function that enumerates all projects in main memory or on the specified mountable file system, such as a storage card.
FindFirstFlashCard X X A Projects Control API function that returns the handle to the first mountable file system, such as a storage card.
FindFirstProjectFile X X A Projects Control API function that searches a directory, subdirectory, or storage card for a file whose name matches the specified file name.
FindNextFlashCard X X A Projects Control API function that finds the next mountable file system, such as a storage card.
FindNextProjectFile X X A Projects Control API function that continues a file search from a previous call to the FindFirstProjectFile function.
SHGetAutoRunPath X X A Shell function that searches for the first storage card and constructs the path that would be used to look for an autorun.exe file.
SHGetDocumentsFolder     A Shell function that retrieves the path to the documents directory.
