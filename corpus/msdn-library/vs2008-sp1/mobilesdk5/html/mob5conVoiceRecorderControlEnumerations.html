Voice Recorder Control Enumerations

Send Feedback on this topic to the authors

The following enumerations are used with the Voice Recorder Control.

Enumeration Description
VR_ECODE Must be the same as in VoiceDll.h.
VR_MSG Contains messages generated by the SendMessage function to the Voice Recorder Control application.
VR_STYLE Describes how the Voice Recorder behaves.
