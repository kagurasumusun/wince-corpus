DLM_SENDIR

Send Feedback on this topic to the authors

The DLM_SENDIR message is sent by an application to send information using the IR port of the device.

Syntax

DLM_SENDIR
  wParam = (WPARAM) res; 
  lParam = (LPARAM) pszPath;

Parameters

res
This parameter is reserved for future use; the value of this parameter must be set to 0.
pszPath
Reference to the path name buffer.

Return Values

None.

Requirements

Pocket PC: Pocket PC 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: doclist.h.
Library: doclist.lib.
