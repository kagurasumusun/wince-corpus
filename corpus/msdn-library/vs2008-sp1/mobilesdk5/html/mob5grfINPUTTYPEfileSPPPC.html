INPUT TYPE=file HTML Element

Send Feedback on this topic to the authors

The INPUT TYPE=file element creates a file upload element with a text box and Browse button.

Attributes

Attribute Value Description
ACCESSKEY   Gives access or focus to an active HTML element by using a keypad number.
CLASS   Associates the element with a CSS style.
DISABLED   Disables the element so that it appears dimmed and does not respond to user input.
ID   Uniquely identifies the element within a document.
NAME String Specifies the element name.
ONBLUR   Event that occurs when the element loses focus by the pointing device or by tabbing navigation.
ONCHANGE   Event that occurs when the element loses input focus and its value has been modified since gaining focus.
ONCLICK   Event that occurs when the user chooses the Browser button.
ONFOCUS   Event that occurs when the element receives focus by the pointing device or by tabbing navigation.
ONSELECT   Event that occurs when the element is selected.
STYLE   Provides the definition of the CSS styles used for this element.
TABINDEX   Sets the order in which elements are tabbed to.
VALUE String Specifies the initial value for the text box.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
