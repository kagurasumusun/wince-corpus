Making a Voice Call Using Connection Manager

Send Feedback on this topic to the authors

To make a voice call, Connection Manager and the voice application complete the following steps:

  1. The voice application, such as Dialer or Contacts, calls TapiRequestmakeCall or ConnMgrProviderMessage with the TPC_REQ_DIAL_VOICE constant set.
  2. The connection service provider voice connection service provider module creates a connection request and passes it to Connection Manager.
  3. Connection Manager passes the connection request to Connection Planner.
  4. Because of the high priority of a voice call, Connection Planner causes Connection Manager to disconnect any active data calls.
  5. Connection Manager opens a voice connection.
  6. The application calls the Connect method in the connection service provider Voice module. The connection is now established.
