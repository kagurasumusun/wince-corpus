Calendar List View

Send Feedback on this topic to the authors

This code sample is named CalendarView. It illustrates how to use the Pocket Outlook Object Model (POOM) IItem interface for Appointment items, and POOM Notifications. It displays a list-view with all appointments.

Feature Area

  • Pocket Outlook Object Model (POOM)
  • Message Queue Reference

Relevant APIs

  • CEPROPVAL interface
  • GetCursor function
  • IDispatch interface
  • IFolder interface
  • IItem interface
  • InitCommonControlsEx structure
  • INITCOMMONCONTROLSEX structure
  • IPOutlookApp2 interface
  • IPOutlookItemCollection interface
  • LoadCursor function
  • LVCOLUMN structure
  • LVITEM structure
  • MSG structure
  • SetCursor function
  • SHINITDLGINFO structure
  • SHMENUBARINFO structure

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution file is copied to the following folder:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Calendarview\CalendarView.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Remarks

It is assumed that you have already created a few Calendar items.

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
