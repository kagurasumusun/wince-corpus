Crossword

This code sample is named Crossword. It demonstrates how to build system metric awareness into an application. Crossword can detect screen resolution and orientation.

Feature Area

  • High DPI Display
  • Screen Orientation Modes

Relevant APIs

  • ChangeDisplaySettingsEx function
  • GetDeviceCaps function
  • GetSystemMetrics function
  • SHGetUIMetrics function
  • WM_SETTINGCHANGE message
  • WM_SIZE message

Projects

This solution consists of three projects.

BaseSample
The basic application, which is a crossword game.
HiDpiAware
The HiDPI-aware version of BaseSample.
LandscapeAware
The Landscape/Portrait-aware version of BaseSample.

Usage

To run the code sample

  1. Navigate to one of the solution files (*.sln), and double-click it. By default, the solution files are copied to the following folders:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Crossword\BaseSample\BaseSample.sln

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Crossword\Landscapeaware\LandscapeAware.sln

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Crossword\Hidpiaware\HidpiAware.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
