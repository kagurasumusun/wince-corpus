ITask::put_ReminderTime

Send Feedback on this topic to the authors

The ReminderTime property gets or sets when a reminder occurs before the start or due date of a task.

To set the value of the ReminderTime property, call the property method described here.

To get the value of the ReminderTime property, see the ITask::get_ReminderTime property method.

Syntax

HRESULT put_ReminderTime(
  DATE st
);

Parameters

st
[in] Reference to the date object that defines the reminder time.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Remarks

The date must be set before midnight (or 8 A.M.) on the due date, and no more than 45 days before the start date.

The default for this property is the user setting in the Task application Options dialog box.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
