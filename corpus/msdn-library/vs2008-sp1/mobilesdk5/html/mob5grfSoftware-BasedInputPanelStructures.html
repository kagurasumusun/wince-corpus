Software-based Input Panel Structures

Send Feedback on this topic to the authors

The following table shows the software-based input panel structures with a description of the purpose of each.

Programming element Description
IMINFO This structure contains information regarding the size and available bitmaps for the input method (IM).
IMENUMINFO This structure contains information on an installed input method (IM).
LMDATA This structure is used by the IIMCallback2::SendAlternatives2 interface to send information from an input method (IM) to an input method editor (IME).
SIPINFO This structure contains information about the current state of the software-based input panel, such as the software-based input panel size, screen location, docked status, and visibility status.
