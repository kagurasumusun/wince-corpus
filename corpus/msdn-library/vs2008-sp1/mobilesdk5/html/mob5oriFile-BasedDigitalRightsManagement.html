File-Based Digital Rights Management

Send Feedback on this topic to the authors

File-Based Digital Rights Management (FDRM) describes a systematic approach to protecting digital-based content for files such as audio, video, and image files.

The Windows Mobile FDRM application programming interface (API) defines the interface to FDRM-managed content for Windows Mobile-based devices. Developers use this API to enable DRM within an application.
