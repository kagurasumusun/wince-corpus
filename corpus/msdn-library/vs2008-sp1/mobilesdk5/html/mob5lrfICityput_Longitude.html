ICity::put_Longitude

Send Feedback on this topic to the authors

The Longitude property gets or sets the longitude for the city.

To set the value of the Longitude property, call the property method described here.

To get the value of the Longitude property, see the ICity::get_Longitude property method.

Note   This method is supported only for Windows Mobile 2000 software for Pocket PCs.

Syntax

HRESULT put_Longitude(
  long lLongitude
);

Parameters

lLongitude
[in] Reference to the longitude.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Remarks

This is an integer value equal to 100 times the decimal representation of degrees.

Relative to the Greenwich meridian, positive values represent locations in the Eastern Hemisphere and negative values represent locations in the Western Hemisphere.

Requirements

Pocket PC: Pocket PC 2000 only
Smartphone: None
OS Versions: Windows CE 2.0 and later
Header: pimstore.h
Library: pimstore.lib
