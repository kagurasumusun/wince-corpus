Imaging Classes

Send Feedback on this topic to the authors

The following list shows the classes associated with the Imaging API.

Class PPC SP Description
BitmapData X X Used to create objects that contain information to describe pixel data for a rectangular area of bitmap images.
EncoderParameter X X Used to create objects that contain data describing the properties of an image encoder.
EncoderParameters X X Used to create objects that collect lists of parameters for an image encoder.
ImageCodecInfo X X Used to create objects that describe the characteristics of an image decoder or an image encoder.
PropertyItem X X Used to create objects that contain data describing image properties
