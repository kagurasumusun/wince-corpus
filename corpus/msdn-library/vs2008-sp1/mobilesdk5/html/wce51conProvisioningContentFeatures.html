Windows Mobile Version 5.0 SDK  

Provisioning Content Features

Send Feedback on this topic to the authors

Windows Mobile-based Smartphones and Windows Mobile-based Pocket PCs (GSM) Phone Edition can be provisioned over the air. The content of the provisioning file is encoded through Wireless Application Protocol Binary Extensible Markup Language (WBXML) and interpreted on the device. For detailed information about encoding content, see the Open Mobile Alliance (OMA) Provisioning Content Specification Version 1.1, OMA-WAP-ProvCont-v1_1-20021112-C, available from this OMA website.

The following table shows the Push Message features

Push Message feature Description
ProvCont-CSE-C-001 UTF-8 Character Encoding Universal Transformation Format 8 (UTF-8) character encoding is implemented as described in "Connectivity Character Set" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).
ProvCont-CSE-C-005 Processing Reference Content Type (No Meta-Information) Reference content is processed on Windows Mobile-based devices as described in "Connectivity Character Set" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).
ProvCont-CSE-C-006 Character Entities Character entities of the provisioning XML file are encoded as described in "Connectivity Character Set" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).
ProvCont-CO-C-001 wap-provisioningdoc DTD Is Used The wap-provisioningdoc document type definition (DTD) is used with the provisioning XML file as described in "Connectivity Reference Information" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).
ProvCont-CO-C-002 Textual Form of the wap-provisioningdoc (text/vnd.wap.connectivity-xml) The textual form of the wap-provisioningdoc DTD is implemented as described in "Overview of Data Model" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).
ProvCont-CO-C-003 wap-provisioningdoc in Tokenized Form (application/vnd.wap.connectivity-wbxml) The wap-provisioningdoc DTD can be used in tokenized form, as described in "WBXML Encoding" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).
ProvCont-CO-C-004 MAC Media Type Parameter The MAC media type parameter is used in the provisioning XML file for conveying security information as described in "Media Type Parameter" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).
Note   Windows Mobile-based Pocket PCs do not support the quoted text encoded mac attribute.

Windows Mobile-based Smartphones support only the token text encoded mac attribute; Windows Mobile-based Smartphones do not support the quoted text encoded mac attribute.
ProvCont-CO-C-005 SEC Media Type Parameter The SEC media type parameter is used in the provisioning XML file for conveying security information as described in "Media Type Parameter" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).

The wap-provisioningdoc element (ProvContCEA-C-001) is used in the provisioning XML file, as described in "The WAP-PROVISIONINGDOC element" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).

  • The version attribute (ProvCont-CEA-C-004) of the wap-provisioningdoc element is used in the provisioning XML file, as described in "The WAP-PROVISIONINGDOC element" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).

The characteristic element (ProvCont-CEA-C-002) is used in the provisioning XML file, as described in "The CHARACTERISTIC element" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).

  • The type attribute (ProvCont-CEA-C-005) of the characteristic element is used in the provisioning XML file, as described in "The CHARACTERISTIC element" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).

The parm element (ProvCont-CEA-C-003) is used in the provisioning XML file, as described in "The PARM element" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).

  • The name attribute (ProvCont-CEA-C-006) of the parm element is used in the provisioning XML file, as described in "The PARM element" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).
  • The value attribute (ProvCont-CEA-C-007) of the parm element is used in the provisioning XML file, as described in "The PARM element" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).
