IPOlItems2

Send Feedback on this topic to the authors

The IPOlItems2 interface represents a PIM item, and provides access to PIM item properties for an item at a given index within a collection, without the need to instantiate the item.

Methods in Vtable Order

  • IUnknown methods
  • IDispatch methods
IPOlItems2 methods PPC SP Description
GetProps X X Gets the list of property values for a PIM item at a given index, without the need to instantiate an object for the item.

Requirements

Pocket PC: Windows Mobile Version 5.0 and later
Smartphone: Windows Mobile Version 5.0 and later
OS Versions: Windows CE 5.01 and later
Header: pimstore.h
Library: pimstore.lib
