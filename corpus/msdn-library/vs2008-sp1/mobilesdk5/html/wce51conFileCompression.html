File Compression Alternatives for Windows Mobile-Based Devices

Send Feedback on this topic to the authors

Windows Mobile-based devices that use Global System for Mobile Communications (GSM) support Wireless Access Protocol (WAP) Binary XML (WBXML) compression for over-the-air push provisioning messages.

WBXML tokenization is a standard way to compress XML text files to a tokenized format for OTA transmission efficiency. For information about the WBXML token tables used by OTA Push provisioning messages, and for information about Microsoft custom parameter token tables, see WBXML and Windows Mobile-Based Devices.

If the XML provisioning file is provided in a .cab file (.cpf file), use MSZIP to compress the provisioning file which typically results in compression gains of greater than 50 percent. The Windows Mobile-based devices CAB Installer automatically decompresses the .cpf file and extracts the .cab file contents.
