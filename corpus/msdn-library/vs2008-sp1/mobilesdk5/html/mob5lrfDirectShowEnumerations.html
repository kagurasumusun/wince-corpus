DirectShow Enumerations

Send Feedback on this topic to the authors

This section describes the Microsoft® DirectShow® enumerated data types.

Programming element PPC SP Description
_AM_FILTER_MISC_FLAGS X X Contains flags that indicate whether a filter is a source filter or a renderer filter.
AM_FILESINK_FLAGS X X Provides values that describe a file sink.
AM_SAMPLE_PROPERTY_FLAGS X X Specifies values for the dwSampleFlags member of the AM_SAMPLE2_PROPERTIES structure.

These values describe the properties of media samples.

AM_VIDEO_RENDERER_MODE X X Identifies rendering modes used by the DirectShow Video Renderer Filter.
AMExtendedSeekingCapabilities X X Describes the extended seeking capabilities of a filter.
CameraControlFlags X X Provides values that indicate whether a particular camera setting is controlled manually or automatically.
CameraControlProperty X X Provides values that identify types of camera settings.
CompressionCaps X X Indicates video compression capabilities.
Merit X X Defines the order in which the Filter Graph Manager tries filters during graph building.
PIN_DIRECTION X X Indicates a pin's direction.
VideoControlFlags X X Provides values that specify the video mode of operation for a video device.
VideoProcAmpFlags X X Indicates whether a particular video property is controlled manually or automatically.
VideoProcAmpProperty X X Specifies video properties on a video capture device.
