IContact::put_Anniversary

Send Feedback on this topic to the authors

The Anniversary property gets or sets the wedding anniversary date for the contact. The date must fall between 1/1/1900 and 12/31/2999 inclusive.

To set the value of the Anniversary property, call the property method described here.

To get the value of the Anniversary property, see the IContact::get_Anniversary property method.

Syntax

HRESULT put_Anniversary(
  DATE st
);

Parameters

st
[in] Reference to the date object that defines the wedding anniversary date.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
