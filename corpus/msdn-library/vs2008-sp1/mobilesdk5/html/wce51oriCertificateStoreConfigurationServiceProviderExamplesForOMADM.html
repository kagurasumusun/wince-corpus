CertificateStore Configuration Service Provider Examples for OMA DM

Send Feedback on this topic to the authors

The following XML examples can be used as templates to query settings for the DevInfo Configuration Service Provider.

  • Adding Certificates to the Privileged, Unprivileged, and SPC Stores Example for OMA DM
  • Deleting a Certificate Example for OMA DM
  • Querying Certificate Stores Example for OMA DM
  • Querying Certificates Output Example for OMA DM

To use these examples, you must replace the values as appropriate, and add the node as a child of the SyncBody node in an OMA DM provisioning file. For more information about the syntax of the provisioning file, see OMA DM Provisioning Files.
