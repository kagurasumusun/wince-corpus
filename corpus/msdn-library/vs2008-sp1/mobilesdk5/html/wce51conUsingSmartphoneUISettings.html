Using UI Settings (SP Only)

Send Feedback on this topic to the authors

The following partial list provides the path to configure the various basic configurable settings through the UI for Windows Mobile-based Smartphones:

  • To configure the device with data connections, such as WAP proxy, HTTP proxy, SOCK proxy, dial-up connections, General Packet Radio Services (GPRS) settings, and virtual private network (VPN) connections: From the Home screen, select Start, and then select Settings. From the Settings control panel, select Connections, and then select the connection to configure.
  • To configure settings such as Accessibility, Profiles, Home Screen, Power, Telephony, Sounds, and Security: From the Home screen, select Start, Settings, and then select the specific setting name.
  • To access the wizard for configuring e-mail: From the Home screen, select Start, and then select an account. From Messaging, select the Menu button, select Options, and then select New Account.
  • To configure synchronization settings: From the Home screen, select ActiveSync. From ActiveSync, select the Menu button, and then select Configure Server.
  • To configure Internet Explorer Mobile: From the Home screen, select Start. From Programs, select Internet Explorer. In Internet Explorer, select the Menu button, and then select Options.
