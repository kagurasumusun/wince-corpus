IShellPropSheetExt::AddPages

Send Feedback on this topic to the authors

The AddPages method adds pages when a registered property sheet extension is found for a particular type of object.

Syntax

HRESULT AddPages (
  LPFNADDPROPSHEETPAGE lpfnAddPage,
  LPARAM lParam
);

Parameters

lpfnAddPage
[in] Specifies the callback function.
lParam
[in] Specifies the opaque handle to be passed to the callback function.

Return Values

This method should return S_OK if it was successful or appropriate errors if not.

Remarks

For each additional page, the extension creates a page object by calling the Windows CE CreatePropertySheetPage function and then calls the function specified in lpfnAddPage.

Requirements

Pocket PC: Windows Mobile 2003 and later.
Smartphone: none
OS Versions: Windows CE .NET 4.2 and later.
Header: Declared in shlobj.h.
