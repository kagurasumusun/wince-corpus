FILECHANGEINFO

Send Feedback on this topic to the authors

This structure contains detailed information about a file system event.

typedef struct _FILECHANGEINFO {
  DWORD cbSize;
  LONG wEventId;
  ULONG uFlags;
  DWORD dwItem1;
  DWORD dwItem2;
  DWORD dwAttributes;
  FILETIME ftModified;
  ULONG nFileSize;
} FILECHANGEINFO, *LPFILECHANGEINFO;

Members

cbSize
The size of the structure.
wEventId
Notification flag. This is one of the SCHNE_ flags listed in the dwEventMask member of the SHCHANGENOTIFYENTRY structure.
uFlags
Indicates the meaning of the dwItem1 and dwItem2 members. The uFlags member must be one of the following values.
Value Description
SHCNF_DWORD The dwItem1 and dwItem2 members are DWORD values. This flag is currently not supported.
SHCNF_IDLIST This flag is currently not supported. The dwItem1 and dwItem2 members are the addresses of ITEMIDLIST structures that represent the items affected by the change. Each ITEMIDLIST must be relative to the desktop folder.
SHCNF_PATH The dwItem1 and dwItem2 members are pointers to string arrays that contain the full path names of the items affected by the change.
SHCNF_PRINTER The dwItem1 and dwItem2 members are pointers to string arrays that represent the friendly names of the printers affected by the change. This flag is currently not supported.
dwItem1
Notification-specific value that is dependent on the value of uFlags. If uFlags is SHCNF_PATH then dwItem1 and dwItem2 are pointers to strings that contain the full pathnames of the item(s) affected by the change.
dwItem2
Notification-specific value that is dependent on the value of uFlags. If uFlags is SHCNF_PATH then dwItem1 and dwItem2 are pointers to strings that contain the full pathnames of the item(s) affected by the change.
dwAttributes
The file attributes.
ftModified
The modified time.
nFileSize
The size of the file.

Requirements

Pocket PC: Pocket PC 2002 and later.
Smartphone: Smartphone 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: shlobj.h
Library: ceshell.lib.
