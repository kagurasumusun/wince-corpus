Get Device ID

Send Feedback on this topic to the authors

This code sample is named GetDeviceID. It demonstrates how to use the System Management API's to retrieve a mobile device's unique identifier. The application calls GetDeviceUniqueID two times, with each call using different information to show that different values are returned for different data.

Feature Area

  • OS Services

Relevant APIs

  • System Management API
  • GetDeviceUniqueID function

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution files are copied to the following folders:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Getdeviceid\GetDeviceID.sln

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Smartphone SDK\Samples\CPP\Win32\Getdeviceid\GetDeviceID.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Remarks

GetDeviceUniqueID protects the privacy of a device.

Multiple applications need to use a device's unique identifier to communicate with servers. To protect a device's privacy, multiple servers should not be able to correlate data from the same device.

GetDeviceUniqueID does not use any additional information other than the data that is provided by the application, so any application that passes in the same application data buffer will obtain the same hash.

GetDeviceUniqueID can be called be any application regardless of the trust level of the application.

Requirements
