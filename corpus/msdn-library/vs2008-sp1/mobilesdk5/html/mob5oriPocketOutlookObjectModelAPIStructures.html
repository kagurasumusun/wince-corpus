Pocket Outlook Object Model API Structures

Send Feedback on this topic to the authors

This section provides detailed information about the Pocket Outlook Object Model API structures described in the following table.

Structure PPC SP Description
CHOOSECONTACT X X Used as an input parameter to the ChooseContact function. It contains information about the Contact item to choose, and the behavior of the Contact Chooser control.
SRCCUSTOMDRAW X X Used as an input parameter to the IPimSrcContactListIcon::Paint method. It contains device context information, and information about the state of the PIM item being drawn.
