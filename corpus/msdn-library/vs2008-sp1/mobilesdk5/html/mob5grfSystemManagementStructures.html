System Management Structures

Send Feedback on this topic to the authors

The following table shows the system management structures with a description of the purpose of each.

Programming element Description
OSVERSIONINFO This structure contains operating system (OS) version information.
String This structure depicts the organization of data in a file-version resource.
StringFileInfo This structure depicts the organization of data in a file-version resource.
StringTable This structure depicts the organization of data in a file-version resource.
SYSTEM_INFO This structure contains information about the current computer system.
Var This structure depicts the organization of data in a file-version resource.
VarFileInfo This structure depicts the organization of data in a file-version resource.
VS_FIXEDFILEINFO This structure contains version information about a file.
VS_VERSIONINFO This structure depicts the organization of data in a file-version resource.
