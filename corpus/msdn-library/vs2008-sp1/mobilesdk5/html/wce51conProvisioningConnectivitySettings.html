Provisioning Connectivity Settings

Send Feedback on this topic to the authors

Requests to query or change connectivity settings are carried out by Configuration Service Providers. Each characteristic in an OMA Client Provisioning provisioning XML document is associated with a Configuration Service Provider. Similarly, there is a Configuration Service Provider associated with each OMA DM object. The following list shows examples of Configuration Service Providers for a few typical connectivity settings supported by Windows Mobile-based devices.

Metanetworks (such as the Internet) and URL Mapping
ACCESS Configuration Service Provider (OMA DM)

CM_Mappings Configuration Service Provider (OMA Client Provisioning)

CM_Networks Configuration Service Provider (OMA Client Provisioning)

Connections
CM_GPRSEntries Configuration Service Provider (OMA Client Provisioning)

CM_NetEntries Configuration Service Provider (OMA Client Provisioning)

CM_PPPEntries Configuration Service Provider (OMA Client Provisioning)

NAP Configuration Service Provider (OMA DM)

Proxy
CM_ProxyEntries Configuration Service Provider (OMA Client Provisioning)

PROXY Configuration Service Provider (OMA DM)

Wi-Fi
Wi-Fi Configuration Service Provider (OMA Client Provisioning and OMA DM)
VPN
CM_VPNEntries Configuration Service Provider (OMA Client Provisioning)

VPN Configuration Service Provider (OMA DM)

Connection Planner
CM_Planner Configuration Service Provider (OMA Client Provisioning)

CMPLANNER Configuration Service Provider (OMA DM)

Bluetooth
Bluetooth Configuration Service Provider (OMA Client Provisioning and OMA DM)
Obex
Obex Configuration Service Provider (OMA Client Provisioning and OMA DM)
