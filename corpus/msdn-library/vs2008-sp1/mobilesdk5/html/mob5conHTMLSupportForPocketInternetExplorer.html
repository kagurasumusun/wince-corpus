HTML Support for Internet Explorer Mobile

Send Feedback on this topic to the authors

Internet Explorer Mobile is more reliant on well-formed HTML than is Internet Explorer on a desktop computer. Internet Explorer on the desktop computer performs additional work to correct nonvalid HTML, but in the interest of performance and memory usage, Internet Explorer Mobile performs much less of such auto-correction.

HTML compliance depends on the version of Internet Explorer Mobile on the device, as follows:

  • Internet Explorer Mobile 2000 is not fully HTML 3.2 compliant but supports a large subset of the standard and disregards tags that it cannot parse and display.
  • Internet Explorer Mobile 2002 is HTML 3.2 compliant. Therefore, all HTML tags that are defined by this standard can be displayed in Internet Explorer Mobile.
  • Internet Explorer Mobile 2003 supports HTML 4.01 CSS and Extensible HTML (XHTML).
