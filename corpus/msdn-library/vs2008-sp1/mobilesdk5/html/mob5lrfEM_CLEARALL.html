EM_CLEARALL

Send Feedback on this topic to the authors

The EM_CLEARALL message clears all of the current document's data.

EM_CLEARALL
  wParam = (WPARAM) (BOOL) fDirty; 
  lParam = (LPARAM) 0;

Parameters

fDirty
Set to TRUE to repaint the window after it is cleared.

Return Values

None.

Remarks

#define EM_CLEARALL (WM_USER + 331)

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: None
OS Versions: Windows CE 3.0 and later
Header: richink.h
Library: richink.lib
