SMSIM

Send Feedback on this topic to the authors

This code sample is named SMSIM. It demonstrates how to use C# to write a managed code version of a Short Messaging Service (SMS) interception application. The application provides a User Interface (UI) for managing multiple instant messaging conversations over SMS.

Feature Area

  • Managed Code
  • Pocket Outlook Object Model (POOM)
  • Pocket Outlook Object Model Application Development for Windows Mobile-based Devices

Relevant APIs

  • MessageInterceptor Class

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution files are copied to the following folders:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\Cs\Smsim\SmsIM.sln

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Smartphone SDK\Samples\Cs\Smsim\SmsIM.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
