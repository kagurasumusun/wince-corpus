Internet Explorer Mobile Product Reference Guide

The following table shows improvements to Internet Explorer Mobile.

Item Description
Secure connection icon (PPC+SP) When an end user connects to a site requiring their user name and password, they will see a connection icon in the user interface showing them their connection has enhanced security.
Download progress bar (PPC+SP) The current browser provides an animation which indicates the browser is doing something, but users desire more information about the download status. In Windows Mobile Version 5.0 there will be a "progress bar" which shows when the browser is connecting, when it has connected, and how much of the page has been downloaded.
Editable favorites (PPC+SP) In Windows Mobile 5.0, you can edit the URL for a favorite after creating the favorite.
Improved browser scripting support (PPC+SP) Using script to enhance Web pages is very common in Web page design. Previously in Internet Explorer, there were several instances where some script elements weren't supported and as a result, the page wouldn't load correctly. If end users went to one of these pages the browser would fail pretty badly. Windows Mobile 5.0 will support many more of these script elements reducing script errors and allowing more pages to load correctly.
Improved browser control hosting support (PPC+SP) It is common for developers to host HTML controls or use a browser window in their application for some portion of the user interface. Windows Mobile 5.0 will expose two APIs providing more options in this scenario. IWebBrowser2 provides control of features, such as navigation, for a separately running instance of the Internet Explorer application or a hosted WebBrowser control. The DWebBrowserEvents2 dispinterface enables an application to receive event notifications from a WebBrowser control, such as DownloadBegin, DownloadComplete, PropertyChange and TitleChange.
Save browser content locally (PPC+SP) From a Web page viewed on the device, a user can save a piece of content (sound or image) to the destination of choice, for example, My Documents, storage card.
Full screen view (PPC+SP) Allows the browser window to use the full screen by hiding the title bar and soft keys.
Improved Web page display Provides support for one column layout on Web pages.
HTTP support for Accept-Language header (PPC+SP) Enables a Web page author to change the content served based on the language of the device. By default, this is set to the language of the device and therefore does not need to be configured unless you want to send a more detailed header containing multiple languages or a header in a language other than that of the default language on the device. This is only supported over HTTP.
HTTP resume download (PPC+SP) Continues an interrupted file download from the point of interruption rather than from the beginning of the file.
Note   HTTP resume will function only on servers that support HTTP 1.1 and allow resume.
Security zones (PPC+SP) You can create custom zones and apply custom security settings to those zones. This allows you to configure a special zone using a set of security settings for web pages from specific domains, such as an OEM portal or a corporate intranet. You should review the default zone settings and decide explicitly if you need more or less security for any given setting.
Trusted API update Internet Explorer Mobile now runs untrusted on Smartphone devices. This means that ActiveX controls that use trusted APIs will no longer function properly on Windows Mobile 5.0 devices without an update not to use those APIs.
Managed code for Internet Explorer Mobile COM API (PPC+SP) Managed code applications can use browser functions.
Browser favorites configuration Operators will be able to use the standard WAP (also called OMA client provisioning) XML to configure browser favorites.
Note   Browser favorites cannot be configured using OMA DM SyncML.
Improvements in DOM support Document.all and style object support are extremely helpful in creating more interesting default web pages.
