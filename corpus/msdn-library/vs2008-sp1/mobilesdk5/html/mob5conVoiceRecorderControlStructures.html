Voice Recorder Control Structures

Send Feedback on this topic to the authors

The following structures are used with the Voice Recorder Control.

Structure Description
CM_VOICE_RECORDER Contains placement, style, parent handles, child identifier, and default file information about the Voice Recorder Control.
NM_VOICE_RECORDER Contains information about notification messages sent by a Voice Recorder Control to a parent application.
