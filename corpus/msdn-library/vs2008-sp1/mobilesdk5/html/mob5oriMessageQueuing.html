Message Queuing

Send Feedback on this topic to the authors

The Message Queuing (MSMQ) implementation in Windows Mobile version 5.0 makes it possible for applications to communicate with other applications across networks and systems that might be temporarily offline.

For information about differences between the MSMQ implementation available for Windows Mobile-based Pocket PC and Smartphone devices and that available for Windows CE devices, see MSMQ in Windows Mobile-based Pocket PC and Smartphone Devices.
