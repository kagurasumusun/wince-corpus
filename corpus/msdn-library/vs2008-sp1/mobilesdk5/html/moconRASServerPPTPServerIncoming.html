RAS Server/PPTP Server (Incoming)

Send Feedback on this topic to the authors

The RAS Server/PPTP Server (Incoming) functionality in Windows CE-based devices provides support for a Remote Access Service (RAS) server. You can use RAS in any computing environment that has a wide area network (WAN) or a virtual private network (VPN).
