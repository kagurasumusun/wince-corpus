Changing a Registry Setting Example

Send Feedback on this topic to the authors

The following example illustrates how use the Replace command to change a device Registry setting. The current SampleKey value is replaced by the value specified in the command by the <Data> element:

<SyncHdr>
  <VerDTD>1.1</VerDTD>
  <VerProto>DM/1.1</VerProto>
  <SessionID>1</SessionID>
  <MsgID>1</MsgID>
  <Target>
    <LocURI>{unique device ID</LocURI>
  </Target>
   <Source>
     <LocURI>https://www.operator.org/mgmt-server</LocURI>
   </Source>
</SyncHdr>
<SyncBody>
   <!-- change a registry settings -->
   <Replace>
     <CmdID>2</CmdID>
     <Item>
       <Target>
          <LocURI>./Vendor/MSFT/Registry/SampleKey</LocURI>
       </Target>
       <Data>16</Data>
     </Item>
   </Replace>
   <Final />
</SyncBody>
