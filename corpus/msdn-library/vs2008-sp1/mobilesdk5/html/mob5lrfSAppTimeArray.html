SAppTimeArray

Send Feedback on this topic to the authors

The SAppTimeArray structure contains an array of time values.

Syntax

struct { 
  ULONG cValues; 
  double FAR *lpat; 
} SAppTimeArray;

Members

cValues
Count of values in the array pointed to by lpat.
lpat
Pointer to an array of application time values.

Remarks

The SAppTimeArray structure is used to define properties of type PT_MV_APPTIME.

Requirements

Pocket PC: Pocket PC 2002 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: mapidefs.h
