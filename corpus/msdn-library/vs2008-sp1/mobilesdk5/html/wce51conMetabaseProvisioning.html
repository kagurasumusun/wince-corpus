Provisioning the Metabase

Send Feedback on this topic to the authors

The metabase contains security and UI information for every setting on a Windows Mobile-based device. Configuration Service Providers access the metabase in order to query or change settings information. You send an XML provisioning document in order to change a setting or obtain information about it. For example, if you add a new key to the registry, you may want to restrict the ability to change that key to the mobile operator. To restrict permissions on the key, you would send a provisioning message, which includes XML that addresses the Metabase Configuration Service Provider. The XML specifies the path to the registry key and the OPERATOR only access role. The new registry key would then be available only to the mobile operator . For more information about the metabase, see Metabase Settings and Metabase and OMA DM.
