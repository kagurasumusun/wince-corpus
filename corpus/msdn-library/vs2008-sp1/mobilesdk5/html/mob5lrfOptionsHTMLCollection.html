options HTML Collection

Send Feedback on this topic to the authors

The options collection retrieves a collection of OPTION objects in a SELECT object.

Property Data type Access Description
length Long Read-only Retrieves the number of options in the collection.
item Object Read/write Sets or retrieves the ordinal position of an OPTION object in a list box.
Note   Supported only for devices running Windows Mobile 2002 software or later.

Requirements

Pocket PC: Windows Mobile 2000 and later
Smartphone: Windows Mobile 2002 and later
OS Versions: Windows CE 3.0 and later
