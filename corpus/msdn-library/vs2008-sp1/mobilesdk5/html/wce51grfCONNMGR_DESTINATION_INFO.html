CONNMGR_DESTINATION_INFO

Send Feedback on this topic to the authors

This structure provides information about a specific network.

typedef struct {
  GUID guid;
  TCHAR szDescription[CONNMGR_MAX_DESC];
  BOOL fSecure;
} CONNMGR_DESTINATION_INFO;

Members

guid
GUID associated with the network to which the connection is established.
szDescription
Description of the network. The value of the CONNMGR_MAX_DESC constant defines the size of this member. This value is set to 128.
fSecure
Specifies if multi-homing is allowed on the network.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Connmgr.h.
