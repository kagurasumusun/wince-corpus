parm-error Element

Send Feedback on this topic to the authors

If an error occurs while a parm element is processing, the erroneous element will be changed to a parm-error element.

Attributes

name
Contains the name of the parm element that causes the error.
value
Specifies the original value of the parm element set in the input document.
desc
Contains a description of the error.
