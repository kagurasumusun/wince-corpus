CompactNav

Send Feedback on this topic to the authors

This code sample is named CompactNav. It demonstrates how to implement a basic .NET Compact Framework file-system navigator, as well has how to use "Platform Invoking" (PInvoke) to make calls to unmanaged APIs (in this case, CreateProcess).

Some exception handling is shown, as well as how to load images from the file system. Executable files can be launched by selecting them (using CreateProcess through pInvoke). Directories can be navigated to, by selecting them and then pressing the action key. Parent directories can be accessed using a menu item (UpDir), or by selecting the conventional ".." directory.

Feature Area

  • Managed Code
  • Shell

Relevant APIs

  • List-View Controls API
  • PInvoke
  • System.Runtime.InteropServices

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution file is copied to the following folder:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Smartphone SDK\Samples\Cs\Compactnav\CompactNav.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
