Dialog Boxes Structures

Send Feedback on this topic to the authors

The following table shows the dialog boxes structures, with a description of the purpose of each.

Programming element Description
DLGITEMTEMPLATE This structure defines the dimensions and style of a control in a dialog box.
DLGITEMTEMPLATEEX This structure is not defined in any standard header file.
DLGTEMPLATE This structure defines the dimensions and style of a dialog box.
DLGTEMPLATEEX This structure is not defined in any standard header file.
