Get Device's Phone Number

Send Feedback on this topic to the authors

This code sample is named GetPhoneNumber. It demonstrates how to retrieve a mobile device's phone number.

Feature Area

  • Networking and Communication

Relevant APIs

  • lineGetAddressCaps function
  • lineGetDevCaps function
  • lineInitializeEx function
  • lineNegotiateAPIVersion function
  • Telephony API (TAPI) API

Source File Listing

getphonenumber.cpp
The application entry point (message box containing phone number if available).
stdafx.cpp
The precompiled type source file.
stdafx.h
The precompiled header.

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution files are copied to the following folders:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\GetPhoneNumber\GetPhoneNumber.sln

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Smartphone SDK\Samples\CPP\Win32\GetPhoneNumber\GetPhoneNumber.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Remarks

If the mobile device uses a SIM, it is assumed that the phone number for the SIM is programmed into it.

This application does not need to run Trusted (i.e., it does not need to be signed with a certificate from the privileged store).

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
