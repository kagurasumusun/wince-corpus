Image Lists Functions

Send Feedback on this topic to the authors

The following table shows the image lists functions with a description of the purpose of each.

Programming element PPC SP Description
ImageList_Add X X This function adds an image or images to an image list.
ImageList_AddMasked X X This function adds an image or images to an image list, generating a mask from the specified bitmap.
ImageList_BeginDrag X X This function begins dragging an image.
ImageList_Copy X X This function copies images within a specified image list.
ImageList_Create X X This function creates a new image list.
ImageList_Destroy X X This function destroys an image list.
ImageList_DragEnter X X This function locks updates to the specified window during a drag operation and displays the drag image at the specified position within the window.
ImageList_DragLeave X X This function unlocks the specified window and hides the drag image, allowing the window to be updated.
ImageList_DragMove X X This function moves the image that is being dragged during a drag-and-drop operation.
ImageList_DragShowNolock X X This function shows or hides the image being dragged.
ImageList_Draw X X This function draws an image list item in the specified device context (DC).
ImageList_DrawEx X X This function draws an image list item in the specified device context (DC).
ImageList_DrawIndirect X X This function draws an image list image based on an IMAGELISTDRAWPARAMS structure.
ImageList_Duplicate X X This function creates a duplicate of an existing image list.
ImageList_EndDrag X X This function ends a drag operation.
ImageList_GetBkColor X X This function retrieves the current background color for an image list.
ImageList_GetDragImage X X This function retrieves the temporary image list that is used for the drag image.
ImageList_GetIcon X X This function creates an icon from an image and mask in an image list.
ImageList_GetIconSize X X This function retrieves the dimensions of images in an image list.
ImageList_GetImageCount X X This function retrieves the number of images in an image list.
ImageList_GetImageInfo X X This function retrieves information about an image.
ImageList_LoadImage X X This function creates an image list from the specified bitmap or icon resource.
ImageList_Merge X X This function creates a new image by combining two existing images.
ImageList_Remove X X This function removes an image from an image list.
ImageList_RemoveAll X X This function removes an image from an image list.
ImageList_Replace X X This function replaces an image in an image list with a new image.
ImageList_ReplaceIcon X X This function replaces an image with an icon.
ImageList_SetBkColor X X This function sets the background color for an image list.
ImageList_SetDragCursorImage X X This function creates a new drag image by combining the specified image with the current drag image.
ImageList_SetIconSize X X This function sets the dimensions of images in an image list and removes all images from the list.
ImageList_SetImageCount X X This function resizes an existing image list.
ImageList_SetOverlayImage X X This function adds a specified image to the list of images to be used as overlay masks.
