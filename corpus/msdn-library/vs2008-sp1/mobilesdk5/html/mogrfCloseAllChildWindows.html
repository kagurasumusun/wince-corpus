Close all Child Windows

Send Feedback on this topic to the authors

This code sample is named CloseWindow. It demonstrates how to force an application to revert back to its base state when it is relaunched, and how to destroy a chain of child windows.

Feature Area

  • Shell Application Development for Windows Mobile-based Devices

Relevant APIs

  • Shell and User Interface Reference
  • GetWindow function
  • GetWindowThreadProcessId function
  • IsWindowVisible function
  • IsWindowEnabled function

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution file is copied to the following folder:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Smartphone SDK\Samples\CPP\Win32\Closewindow\closewindow.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Remarks

If any window has a NULL parent, this code sample will not work properly.

Requirements

Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
