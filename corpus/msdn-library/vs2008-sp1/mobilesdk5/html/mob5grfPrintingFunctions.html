Printing Functions

Send Feedback on this topic to the authors

The following table shows the printing functions with a description of the purpose of each.

Programming element PPC SP Description
AbortDoc X   This function stops the current print job.
AbortProc X   This function is an application-defined callback function used with the SetAbortProc function.
EndDoc X   This function ends a print job.
EndPage X   This function informs the device that the application has finished writing to a page.
SetAbortProc X   This function sets the application-defined function that allows a print job to be canceled during printing.
StartDoc X   This function starts a print job.
StartPage X   This function prepares the printer driver to accept data.
