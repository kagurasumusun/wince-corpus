The following table shows International functionality added to Windows Mobile Version 5.0.

Item Description
Language pack architecture (MUI building architecture) (PPC+SP) Unified core code into a universal base and placed language-specific components into Language Packs taking advantage of Image Update technology. Code changes provide an architecture that allows original equipment manufacturers and PRT to implement code changes that can be tested only once, instead of in every language version they plan to ship
Upgraded Japanese Input Method Editor (PPC Only) The Input Method Editor is the API for allowing different input methods (predictive text, handwriting, keyboard, etc.) to take input from the hardware and write to the screen. The only new functionality being delivered in IME 3.1 is the ability for users to add new words to the dictionary.
Upgraded Chinese Input Method Editor (PPC Only) The Input Method Editor is the API for allowing different input methods (predictive text, handwriting, keyboard, etc.) to take input from the hardware and write to the screen. Windows Mobile 5.0 will include a new Chinese Input Method Editor which is fully compatible with HW keyboard input, allows the user to type a complete pinyin sentence without selecting each word, and provides a word registration feature.
