APPLICATION Class Implementation

Send Feedback on this topic to the authors

Each implemented class must have an IsValidClassName class where ClassName is the class name. For example, IsValidApp() or IsValidPort().

IsValidApp() and IsValidPort() are used to check the validity of each objects data before it is committed.

For information about the APPLICATION Configuration Service Provider, see APPLICATION Configuration Service Provider.
