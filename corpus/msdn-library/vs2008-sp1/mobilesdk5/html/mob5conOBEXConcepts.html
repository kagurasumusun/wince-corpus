OBEX Application Development for Windows Mobile-based Devices

Send Feedback on this topic to the authors

The Object Exchange Protocol (OBEX) technology for Microsoft Windows Mobile-based devices, provides a compact binary protocol that enables a wide range of devices to exchange data spontaneously in a simple, efficient manner.
