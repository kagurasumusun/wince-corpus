BOOTSTRAP

Send Feedback on this topic to the authors

The mapping of the parameters in the BOOTSTRAP characteristic element to the Bootstrap Configuration Service Provider is done based on the BOOTSTRAP characteristic type element included in the bootstrap message. Configuration Manager routes the BOOTSTRAP parms to the Bootstrap Configuration Service Provider, which processes the configuration changes. The Configuration Service Provider stores the encrypted URL of the Trusted Provisioning Server (TPS) in the registry.

Set the characteristic type to BOOTSTRAP to identify the module for the Bootstrap Configuration Service Provider. For more information see BOOTSTRAP Configuration Service Provider

WAP characteristic
WAP parm
Comments
BOOTSTRAP    
  NAME If NAME is not provided, the predefined value Trust WAP Config Server is used. NAME will be set as a Microsoft® Internet Explorer Mobile favorite name for PROVURL.
  PROVURL PROVURL is used to provide the authority and path of a TPS. Push Router uses PROVURL to distinguish whether a provisioning message is pushed from a TPS. PROVURL will be set as a Internet Explorer Mobile favorite if the PROXY-ID parm is provided in the BOOTSTRAP characteristic.
  PROXY-ID If PROXY-ID is not specified, the TPS PROVURL will not be added as a favorite in Internet Explorer Mobile.
  CONTEXT-ALLOW The device supports only a value of 0.
