Winsock SPI Functions

Send Feedback on this topic to the authors

The following table lists the Winsock SPI functions.

Programming element PPC SP Description
NSPCleanup X X This function terminates the use of a particular Windows Sockets name space service provider.
NSPGetServiceClassInfo X X This function retrieves all the pertinent class information (schema) pertaining to the name-space provider.
NSPInstallServiceClass X X This function registers service class schema within the name-space providers.
NSPLookupServiceBegin X X This function initiates a client query that is constrained by the information contained within a WSAQUERYSET structure.
NSPLookupServiceEnd X X This function is called to free the handle after previous calls to NSPLookupServiceBegin and NSPLookupServiceNext.
NSPLookupServiceNext X X This function is called after obtaining a handle from a previous call to NSPLookupServiceBegin in order to retrieve the requested service information.
NSPRemoveServiceClass X X This function permanently removes a specified service class from the name space.
NSPSetService X X This function registers or deregisters a service instance within a name space.
NSPStartup X X This function retrieves the dynamic information about a provider, such as the list of the DLL entry points.
WPUCloseEvent X X This function closes an open event object handle.
WPUCloseSocketHandle X X This function closes an existing socket handle.
WPUCompleteOverlappedRequest X X This function performs overlapped I/O completion notification for overlapped I/O operations.
WPUCreateEvent X X This function creates a new event object.
WPUCreateSocketHandle X X This function creates a new socket handle.
WPUFDIsSet X X This function checks the membership of the specified socket handle.
WPUGetProviderPath X X This function retrieves the DLL path for the specified provider.
WPUQueryBlockingCallback X X This function returns a pointer to a callback function the service provider should invoke periodically while servicing blocking operations.
Note   This function is not supported for the default TCP/UDP provider in Windows CE. However, third parties can implement their own provider and have support for this function if they choose.
WPUQuerySocketHandleContext X X This function queries the context value associated with the specified socket handle.
WPUResetEvent X X This function resets the state of the specified event object to nonsignaled.
WPUSetEvent X X This function sets the state of the specified event object to signaled.
WSCDeinstallProvider X X This function removes the specified transport provider from the system configuration database.
WSCEnumProtocols X X This function retrieves information about available transport protocols.
WSCInstallNameSpace X X This function installs a name-space provider.
WSCInstallProvider X X This function installs the specified transport provider into the system configuration database.
WSCUnInstallNameSpace X X This function uninstalls the indicated name-space provider.
WSPAccept X X This function conditionally accepts a connection based on the return value of a condition function.
WSPAddressToString X X This function converts all parts of a sockaddr structure into a human readable–numeric string representation of the address.
WSPAsyncSelect X X This function requests Windows message-based event notification of network events for a socket.
WSPBind X X This function associates a local address (that is, name) with a socket.
WSPCleanup X X This function terminates use of the Windows Sockets service provider.
WSPCloseSocket X X This function closes a socket.
WSPConnect X X This function establishes a connection to a peer, and exchanges connect data.
WSPDuplicateSocket X X This function returns a structure that can be used to create a new socket descriptor for a shared socket.
WSPEnumNetworkEvents X X This function reports occurrences of network events for the indicated socket.
WSPEventSelect X X This function specifies an event object to be associated with the supplied set of network events.
WSPGetOverlappedResult X X This function returns the results of an overlapped operation on the specified socket.
WSPEnumNetworkEvents X X This function reports occurrences of network events for the indicated socket.
WSPEventSelect X X This function specifies an event object to be associated with the supplied set of network events.
WSPGetOverlappedResult X X This function returns the results of an overlapped operation on the specified socket.
WSPGetPeerName X X This function gets the address of the peer to which a socket is connected.
WSPGetSockName X X This function gets the local name for a socket.
WSPGetSockOpt X X This function retrieves a socket option.
WSPIoctl X X This function controls the mode of a socket.
WSPJoinLeaf X X This function joins a leaf node into a multipoint session, and exchanges connect data.
WSPListen X X This function establishes a socket to listen for incoming connections.
WSPRecv X X This function receives data on a socket.
WSPRecvDisconnect X X This function terminates reception on a socket and retrieves the disconnect data, if the socket is connection oriented.
Note   This function is not supported for the default TCP/UDP provider in Windows CE. However, third parties can implement their own provider and have support for this function if they choose.
WSPRecvFrom X X This function receives a datagram and stores the source address.
WSPSelect X X This function determines the status of one or more sockets.
WSPSend X X This function sends data on a connected socket.
WSPSendDisconnect X X This function initiates termination of the connection for the socket and sends disconnect data.
Note   This function is not supported for the default TCP/UDP provider in Windows CE. However, third parties can implement their own provider and have support for this function if they choose.
WSPSendTo X X This function sends data to a specific destination using overlapped I/O.
WSPSetSockOpt X X This function sets a socket option.
WSPShutdown X X This function disables sends and/or receives on a socket.
WSPSocket X X This function creates a socket.
WSPStartup X X This function initiates use of a Windows Sockets service provider by a client.
WSPStringToAddress X X This function converts a human-readable numeric string to a socket address structure (sockaddr) suitable to passing to Windows Sockets routines that take such a structure.
