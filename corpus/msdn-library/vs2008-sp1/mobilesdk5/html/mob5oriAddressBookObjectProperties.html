Address Book Properties

Send Feedback on this topic to the authors

These properties appear on address book objects.

Constant Description Data type Property ID Property Tag
PR_DISPLAY_TYPE Contains a value used to associate an icon with a particular row of a table. PT_LONG 0x3900 0x39000003
PR_TEMPLATEID Contains an entry identifier that can find the code associated with a service provider. PT_BINARY 0x3902 0x39020102
PR_PRIMARY_CAPABILITY Obsolete address book property. PT_BINARY 0x3904 0x39040102
