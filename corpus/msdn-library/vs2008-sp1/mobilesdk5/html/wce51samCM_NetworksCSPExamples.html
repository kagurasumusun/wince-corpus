Caution   If the default network can satisfy the connection configuration requirements, do not modify the network. If the default network cannot satisfy the connection configuration requirements, carefully read this document and Connection Manager Configuration before using this Configuration Service Provider to make any changes to the network. When the mobile device processes Wireless Application Protocol (WAP) connectivity documents, network and connection mapping table entries are automatically generated. The entries are then maintained internally. If modifications are necessary, use this Configuration Service Provider to modify only those networks that you set.
