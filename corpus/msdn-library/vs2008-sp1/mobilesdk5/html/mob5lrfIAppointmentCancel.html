IAppointment::Cancel

Send Feedback on this topic to the authors

The Cancel method sends a cancellation of a meeting request.

Syntax

HRESULT Cancel ();

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Remarks

This method does not remove an appointment from the user's calendar. To both cancel and remove an appointment, you must first call Cancel and then call IAppointment::Delete.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
