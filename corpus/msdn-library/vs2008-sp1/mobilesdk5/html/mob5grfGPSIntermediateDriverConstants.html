GPS Intermediate Driver Constants

Send Feedback on this topic to the authors

The following table shows the GPS Intermediate Driver constants.

Constant Description
GPS_DATA_FLAGS_ Provides information about the state of the information retrieved in a call to GPSGetPosition.
GPS_MAX_ Specifies limits for internal GPS Intermediate Driver data.
GPS_VALID_ Specifies which of the fields in the GPS_POSITION structure are valid.
