Personal Applications Product Reference Guide

The following table shows improvements to Personal Applications.

Item Description
Pocket Outlook Object Model API Improvements (PPC+SP) It is quite common for developers to write applications that need to access the Contacts database on the device, as with MMS clients or line of business applications like sales force automation. Device makers are also interested in this functionality for scenarios such as showing the incoming caller name on a second display.
User Interface Improvements to the Contacts summary card (PPC+SP) The contact summary card is mostly accessed when the end user wants to reference a contact's information or start some form of communication. A user can also access the summary card from tapping a recipient in inbox or call history. In addition to the contact methods available in Windows Mobile 2003 (phone, e-mail, SMS, etc.), in Windows Mobile Version 5.0, end users will also be able to choose "send MMS" and initiate instant messaging chats.
Per-contact ring tones (PPC Only) End users are able to assign specific ring tones to specific people. When the phone rings, the callers assigned ring tone with play.
Managed access to the Pocket Outlook Object Model API (PPC+SP) The Microsoft.WindowsMobile.PocketOutlook Namespace is a managed class library that provides an elegant approach to manipulating and extending the Outlook Mobile personal information management system, the contents of its data store, and its PIM item processing services.
Pictures browse view (PPC+SP) An end user can browse through photos on their device that they either took using a built-in camera or that they copied from the desktop
Image capture view (PPC+SP) An end user can take a picture from an attached or integrated camera
Video capture view (PPC+SP) An end user can take a video from an attached or integrated camera. By default the application records in WMV. The original equipment manufacturer can plug in a third-party video/audio encoder (for example, MPEG4 or H.263/AMR).
Edit picture view (PPC+SP) End users can make the basic changes to a picture to make it presentable before sending it to someone else. This includes crop, rotate, and auto-brightness/contrast.
Picture picker control (PPC+SP) An end user wants to select a picture from a non-Microsoft application. The user can use this control to pick a picture. It is also used in the Contacts application to pick a picture for a contact, and can be leveraged by MMS applications.
Video picker (PPC+SP) An end user can select a video using UI from e-mail and MMS. This is one part of the end-to-end scenario for video messaging.
List view contacts extensibility (PPC+SP) This work allows a service provider to draw a graphic element next to a contact's name in list view using an "owner-list draw API" for a custom property. A high-priority user scenario for this work is to show a graphic element that represents presence in the Contacts list view.
One-handed dialing from Contacts (PPC Only) User can easily find and dial a contact with one hand. This includes improvements to the Summary Card and also soft keys in all PIM applications. This also includes two line display in the list view of contacts which shows the full name and communication method on Pocket PC. A user can call directly from the list view by selecting the contact in list view, pressing right or left to choose the communication method you want and then pressing the talk button to call.
Menu extensibility in Pictures and Camera (PPC+SP) Provides menu extensibility in the Pictures and Camera applications. This allows an ISV or original equipment manufacturer to add code so that, for example, a picture can be uploaded to a backend service.
Native and managed Camera API (PPC+SP) Developers in both native and managed code can call the UI for taking a picture or video.
New address parser for Contacts (PPC Only) The user enters an address in a single field in Contacts, and the parser breaks up address into different fields. The improvements are mostly for East Asian and European addresses.
Slideshow view for pictures (PPC+SP) The end user is able to have all the pictures in a folder display one after another without have to manually switch between pictures.
Contact searching improvements (PPC Only) Users can enter text strings in the contacts search field including full names (first and last), e-mail address, and phone numbers.
Updated contact chooser control (PPC+SP) The ChooseContact function is provided. On Pocket PC, the contact chooser control has also been updated to make the process of inviting attendees to meetings or messages easier.
File-based digital rights management integration with Pictures Album application (SP Only) The picture browse view and picker properly respect rights associated with content that is protected by file-based digital rights management (FDRM). These rights include Forward Lock, Combined Delivery, and Separate Delivery.
File-based digital rights management integration with Contacts application (SP Only) The Contacts application properly respects rights associated with content that is protected by file-based digital rights management (FDRM). These rights include Forward Lock, Combined Delivery, and Separate Delivery, as they relate to assigned ring tones.
SIM contacts integrated in Contacts application (PPC Only) An end user can view phonebook entries on the SIM from within the Contacts application.
Soft keys in PIM applications (PPC+SP) One-handed navigation has been improved in all PIM applications by implementing soft keys.
Take pictures and videos (PPC+SP) The Camera Capture dialog box is a Shell function that allows the user to take pictures and videos, and to set parameters related to these tasks.
