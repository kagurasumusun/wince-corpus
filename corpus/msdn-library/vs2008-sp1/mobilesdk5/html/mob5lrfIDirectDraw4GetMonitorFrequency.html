IDirectDraw::GetMonitorFrequency

Send Feedback on this topic to the authors

This method retrieves the frequency of the monitor being driven by the DirectDraw object.

HRESULT GetMonitorFrequency(
  LPDWORD lpdwFrequency
);

Parameters

lpdwFrequency
Address of the variable that will be filled with the monitor frequency, reported in Hz.

Return Values

If the method succeeds, the return value is DD_OK.

If the method fails, the return value may be one of the following error values:

DDERR_INVALIDOBJECT
DDERR_INVALIDPARAMS
DDERR_UNSUPPORTED

Requirements

Pocket PC Platforms: Windows Mobile 5.0 and later
Smartphone Platforms: Windows Mobile 5.0 and later
OS Versions: Windows CE 5.01 and later
Header: Ddraw.h.
Library: Ddraw.lib.
