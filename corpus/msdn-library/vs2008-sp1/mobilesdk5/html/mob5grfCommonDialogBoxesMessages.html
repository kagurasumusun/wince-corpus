Common Dialog Boxes Messages

Send Feedback on this topic to the authors

The following table shows the common dialog boxes messages with a description of the purpose of each.

Programming element Description
CDM_SETDEFEXT This message sets the default filename extension for an Explorer-style Open or Save As common dialog box.
CDN_TYPECHANGE This message is sent by an Explorer-style Open or Save As common dialog box when the user selects a new file type from the file types combo box.
