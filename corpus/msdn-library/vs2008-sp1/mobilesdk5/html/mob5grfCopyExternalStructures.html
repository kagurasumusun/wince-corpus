Copy External Structures

Send Feedback on this topic to the authors

The following table shows the copy external structures with a description of the purpose of each.

Programming element Description
DISK_COPY_EXTERNAL This structure contains the necessary input for IOCTL_DISK_COPY_EXTERNAL_START.
FILE_COPY_EXTERNAL This structure contains the necessary input for FSCTL_COPY_EXTERNAL_START.
SECTOR_LIST_ENTRY This structure describes a series of logical sectors.
