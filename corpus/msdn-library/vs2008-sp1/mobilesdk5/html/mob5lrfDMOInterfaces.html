DMO Interfaces

Send Feedback on this topic to the authors

The following topics contain reference entries for all the Microsoft DirectX Media Object (DMO) COM interfaces and their methods:

Interface PPC SP Description
IDMOQualityControl X X Supports quality control on a DMO.
IDMOVideoOutputOptimizations X X Supports video optimizations on DMO.
IEnumDMO X X Provides methods for enumerating DMOs.
IMediaBuffer X X Provides methods for manipulating a data buffer. Any buffer passed to a DMO must implement this interface.
IMediaObject X X Provides methods for manipulating a DMO.
IMediaObjectInPlace X X Provides methods for processing data in place.
