Porting Applications between Windows Mobile-based Devices

Send Feedback on this topic to the authors

Windows Mobile-based Pocket PC and Smartphone share Windows Mobile APIs, with some variation to account for differences in form factor, user interface, and other device specific features. For information about porting an application from one Windows Mobile–based device to another see topics below.

In This Section

Creating Portable Applications
Provides information about developing applications on Windows Mobile-based Pocket PC that can be ported to the Windows Mobile-based Smartphone.
User Interface Considerations When Porting
Provides a list of User Interface considerations to keep in mind when porting an application from a Windows Mobile-based Pocket PC to a Smartphone or vice versa.
Display Considerations When Porting
Provides a list of Display considerations to keep in mind when porting an application from a Windows Mobile-based Pocket PC to a Smartphone or vice versa.
