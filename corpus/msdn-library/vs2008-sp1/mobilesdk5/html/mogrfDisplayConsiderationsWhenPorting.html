Display Considerations When Porting

Send Feedback on this topic to the authors

Windows Mobile-based Pocket PC and Smartphone devices have different screen sizes. The SDK emulators include settings that cover all supported screen sizes.

The following table shows all currently supported screen sizes.

Device Width (pixels) Height (pixels)
Smartphone 176 220
Smartphone QVGA 240 320
Pocket PC 240 320
Pocket PC Square 240 240
Pocket PC VGA 480 640
Pocket PC VGA Square 480 480

In addition, the Windows Mobile-based Pocket PC display can be rotated by the user from portrait to landscape mode.
