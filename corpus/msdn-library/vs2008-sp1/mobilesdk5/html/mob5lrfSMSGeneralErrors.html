SMS General Errors

Send Feedback on this topic to the authors

The following errors may occur on the layer that handles all communication between core cellular architecture modules and the radio hardware. These errors will be passed through when no more specific error value is applicable.

Name Description
SMS_E_MISC A radio hardware error that falls into none of the following classes.
SMS_E_PASSWORD Problem relates to passwords.
SMS_E_SIM Problem with the subscriber identity module (SIM).
SMS_E_NETWORKACCESS Cannot access the network.
SMS_E_NETWORK Error in the network.
SMS_E_MOBILE Error in the mobile.
SMS_E_NETWORKUNSUPPORTED Unsupported by the network.
SMS_E_MOBILEUNSUPPORTED Unsupported by the mobile.
SMS_E_BADPARAM An invalid parameter was supplied.
SMS_E_STORAGE Error relating to storage.
SMS_E_SMSC Error relates to the Short Message Service Center (SMSC).
SMS_E_DESTINATION Error in destination mobile.
SMS_E_DESTINATIONUNSUPPORTED Unsupported by destination mobile.
SMS_E_RADIOUNAVAILABLE The radio hardware is unavailable.

Requirements

Smartphone Platforms: Smartphone 2002 and later
Pocket PC Platforms: Pocket PC 2002 and later
OS Versions: Windows CE 3.0 and later
Header: sms.h
Library: sms.lib
