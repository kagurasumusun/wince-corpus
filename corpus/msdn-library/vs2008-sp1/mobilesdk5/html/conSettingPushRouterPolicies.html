Setting Push Router Policies

Send Feedback on this topic to the authors

A mobile operator can customize how Windows Mobile-based devices are configured by specifying support for a particular method of over-the-air (OTA) configuration and provisioning. The OEM or mobile operator can specify this support by changing the default policy settings.

The following table shows the supported policies related to the Push Router.

Security Policy Policy
WSP Push policy Policy 4113
Unauthenticated Message policy Policy 4110
WAP Signed Message policy Policy 4107

For a detailed description of various policies, see Security Policies. For details about how to change policy values by using provisioning XML, refer to Provisioning Security Settings.
