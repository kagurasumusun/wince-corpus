Audible Notification for WAP Push Messages

Send Feedback on this topic to the authors

Windows Mobile 5.0 supports audible notification for incoming Service Indication (SI) and Service Loading (SL) messages and for Configuration Service Provider provisioning messages. Notification sounds are played for all SI and SL messages. An audible alert is given whenever a dialog is displayed to prompt the user for manual authentication in response to OTA WAP provisioning.

Notification and Alert Sounds

The following table shows the notification and alert sounds that are associated with each WAP Push message type.

Push Message Type Notification or Alert Sound
Configuration Service Provider provisioning requiring PIN Exclamation Alert sound
Configuration Service Provider provisioning from unknown source Warning Alert sound
Configuration Service Provider provisioning transaction rollback failure Warning Alert sound
SI signal-low New Text Message Notification sound
SI signal-medium New Text Message Notification sound
SI signal-high New Text Message Notification sound
SL cache New Text Message Notification sound
SL execute-low Exclamation Alert sound
SL execute-high Exclamation Alert sound
SL download error New Text Message Notification sound

Disabling Notification and Alert Sounds

Notification and Alert sounds are enabled by default. To disable them you must modify the appropriate registry settings.

To turn off the notification sound that plays when the PIN dialog appears the setting NoSoundWithPin must be added to the registry. It can be set to any value. 

[HKEY_LOCAL_MACHINE\Security\PushRouter\Settings]
"NoSoundWithPin" = "{any value}"

OMA Client Provisioning example

wap-provisioningdoc>
   <characteristic type="Registry">
      <characteristic type="HKLM\Security\PushRouter\Settings">
         <parm name="NoSoundWithPin" value="{any value}" datatype="dword"/>
      </characteristic>
   </characteristic>
</wap-provisioningdoc>

OMA DM Provisioning example

<Add>
   <CmdID>5000</CmdID>
   <Item>
          <Target><LocURI>./Vendor/MSFT/HKLM/Security/Pushrouter/Settings/NoSoundWithPin</LocURI></Target>
          <Meta>
            <Format xmlns="syncml:metinf">int</Format>
          </Meta>
          <Data>{any value}</Data>
   </Item>
</Add>

To turn off all WAP Push Message notification sounds the setting NoAudibleAlertForAllSISL must be set to 1. If it is set to any other value the notification sounds will be enabled. 

[HKLM\Software\Microsoft\SIClnt]
"NoAudibleAlertForAllSISL" = "1"

OMA Client Provisioning example

wap-provisioningdoc>
   <characteristic type="Registry">
      <characteristic type="HKLM\Software\Microsoft\SIClnt">
         <parm name="NoAudibleAlertForAllSISL" value="1" datatype="dword"/>
      </characteristic>
   </characteristic>
</wap-provisioningdoc>

OMA DM Provisioning example

<Replace>
   <CmdID>5001</CmdID>
   <Item>
          <Target><LocURI>./Vendor/MSFT/HKLM/Software/Microsoft/SIClnt/NoAudibleAlertForAllSISL</LocURI></Target>
          <Meta>
            <Format xmlns="syncml:metinf">int</Format>
          </Meta>
          <Data>1</Data>
   </Item>
</Replace>
