DTM_ISSELECTION

Send Feedback on this topic to the authors

This message is sent by an application to determine if some text was selected in the HTML control.

Syntax

DTM_ISSELECTION
  wParam = 0;
  lParam = 0;

Parameters

None.

Return Values

Returns TRUE if text is selected. Returns FALSE if no text is selected.

Remarks

To determine if text was selected in the HTML control send the DTM_ISSELECTION message.

The following example shows how you might use this message.

bIsTextSelected = (BOOL)SendMessage(hwndHTML, DTM_ISSELECTION, 0, 0);

Requirements

Pocket PC: Windows Mobile 2003 and later
Smartphone: Windows Mobile 2003 and later
OS Versions: Windows CE .NET 4.2 and later
Header: htmlctrl.h
Library: htmlctrl.lib
