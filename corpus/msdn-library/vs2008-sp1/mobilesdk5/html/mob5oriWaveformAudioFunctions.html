Waveform Audio Functions

Send Feedback on this topic to the authors

The following functions are used by the wave API.

Programming element PPC SP Description
PlaySound X X Plays a sound specified by a file name, resource, or system event.
sndPlaySound X X Plays a waveform sound.
waveInAddBuffer X X Sends an input buffer to the specified waveform-audio input device.
waveInClose X X Closes the specified waveform-audio input device.
waveInGetDevCaps X X Retrieves the capabilities of a specified waveform-audio input device.
waveInGetErrorText X X Retrieves a textual description of the error identified by the specified error number.
waveInGetID X X Gets the device identifier for the specified waveform-audio input device.
waveInGetNumDevs X X Retrieves the number of waveform input devices present in the system.
waveInGetPosition X X Retrieves the current input position of the specified waveform input device.
waveInGetProperty X X Queries the value of a specific property in a property set for waveform audio input.
waveInMessage X X Sends messages to the waveform output device drivers.
waveInOpen X X Opens a specified waveform input device for recording.
waveInPrepareHeader X X Prepares a buffer for waveform input.
waveInProc X X Callback function used with the waveform-audio input device.
waveInReset X X Stops input on a specified waveform input device and resets the current position to 0.
waveInSetProperty X X Sets the value of a specific property in a property set for waveform audio input.
waveInStart X X Starts input on the specified waveform input device.
waveInStop X X Stops waveform input.
waveInUnprepareHeader X X Cleans up the preparation performed by waveInPrepareHeader.
waveOutBreakLoop X X Breaks a loop on a specified waveform output device.
waveOutClose X X Closes the specified waveform output device.
waveOutGetDevCaps X X Queries a specified waveform device to determine its capabilities.
waveOutGetErrorText X X Retrieves a textual description of the error identified by the specified error number.
waveOutGetID X X Gets the device identifier for a waveform output device.
waveOutGetNumDevs X X Retrieves the number of waveform output devices present in the system.
waveOutGetPitch X X Queries the current pitch setting of a waveform output device.
waveOutGetPlaybackRate X X Queries the current playback rate setting of a waveform output device.
waveOutGetPosition X X Retrieves the current playback position of the specified waveform output device.
waveOutGetProperty X X Queries the value of a specific property in a property set for waveform audio output.
waveOutGetVolume X X Queries the current volume setting of a waveform output device.
waveOutMessage X X Sends messages to the waveform output device drivers.
waveOutOpen X X Opens a specified waveform output device for playback.
waveOutPause X X Pauses playback on a specified waveform output device.
waveOutProc X X Callback function used with the waveform-audio output device.
waveOutPrepareHeader X X Prepares a waveform data block for playback.
waveOutReset X X Stops playback on a specified waveform output device and resets the current position to 0.
waveOutRestart X X Restarts a paused waveform output device.
waveOutSetPitch X X Sets the pitch of a waveform output device.
waveOutSetPlaybackRate X X Sets the playback rate of a waveform output device.
waveOutSetProperty X X Sets the value of a specific property in a property set for waveform audio input.
waveOutSetVolume X X Sets the volume of a waveform output device.
waveOutUnprepareHeader X X Cleans up the preparation performed by waveOutPrepareHeader.
waveOutWrite X X Sends a data block to the specified waveform output device.
