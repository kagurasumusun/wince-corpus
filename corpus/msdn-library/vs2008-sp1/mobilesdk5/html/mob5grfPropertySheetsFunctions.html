Property Sheets Functions

Send Feedback on this topic to the authors

The following table shows the property sheet functions with a description of the purpose of each.

Programming element PPC SP Description
AddPropSheetPageProc X X This callback function is application-defined.
CreatePropertySheetPage X X This function creates a new page for a property sheet.
DestroyPropertySheetPage X X This function destroys a property sheet page for the handle returned from the CreatePropertySheetPage function.
ExtensionPropSheetPageProc X X This callback function is application-defined.
PropertySheet X X This function creates a property sheet and adds the pages defined in the specified property sheet header structure.
PropSheetPageProc X X This function is an application-defined callback function that a property sheet calls when a page is created and when it is about to be destroyed.
PropSheetProc X X This function is an application-defined callback function that the system calls when the property sheet is being created and initialized.
