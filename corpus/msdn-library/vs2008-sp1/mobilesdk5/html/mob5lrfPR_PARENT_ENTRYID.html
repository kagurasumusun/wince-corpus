PR_PARENT_ENTRYID

Send Feedback on this topic to the authors

The PR_PARENT_ENTRYID property contains the entry identifier of the folder containing a folder or message.

Additional Information

Must be exposed by: Folder and message objects
May be a column in: Folder contents tables
Identifier: 0x0E09
Property type: PT_BINARY
Property tag: 0x0E090102

Remarks

The PR_PARENT_ENTRYID property is computed by message stores for all folders and messages.

For a message store root folder, PR_PARENT_ENTRYID contains the folder's own entry identifier.

Requirements

Pocket PC: Pocket PC 2002 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: mapitags.h
Library: cemapi.lib
