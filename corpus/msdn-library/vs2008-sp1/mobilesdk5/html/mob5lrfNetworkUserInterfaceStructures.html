Network User Interface Structures

Send Feedback on this topic to the authors

The following table shows the Network User Interface structures .

Programming element Description
ADDCONNECT_DLGPARAMS Defines the parameters for a dialog box that enables a user to connect to a network.
GETDRIVERNAMEPARMS Defines the parameters for a newly inserted PC Card.
LINECONFIGDATA Specifies the configuration information for a modem line.
NETUI_NEWPWD Specifies the password for GetNewPassword.
NETUI_RESPWD Specifies a resource password.
NETUI_USERPWD Specifies a network password for a user.
