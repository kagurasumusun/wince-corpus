Vibrate Functions

Send Feedback on this topic to the authors

The following table shows the Windows Mobile-based Pocket PC and Smartphone functions for the Vibrate API.

Structure PPC SP Description
Vibrate X X Plays the specified vibration song.
VibrateGetDeviceCaps X X Gets the current device vibration capabilities.
VibrateStop X X Stops all current vibration songs.
