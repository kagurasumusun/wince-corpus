Imaging Macros

The following list shows categories of macros and GUIDs associated with the Imaging API.

Macro PPC SP Description
Error Codes for the Imaging API X X The standard error codes used throughout the Imaging API.
MAKEARGB X X Creates an ARGB value from alpha, red, green, and blue values.
PixelFormat Values X X Flags used to identify the numerical formats of pixels in images.
PropertyTag Values X X Values that correspond to metadata items supported by the Imaging API
PropertyTagType Values X X Used to identify the data type of an image's metadata.
