FDRM Application Development

Send Feedback on this topic to the authors

Applications can access FDRM-protected content by calling the generic Windows Mobile FDRM APIs. To create FDRM-enabled applications, you must adhere to a set of requirements for application development. For more information on these requirements, see Requirements for Making Applications FDRM Enabled.
