IMessageFormEx::CloseForm

Send Feedback on this topic to the authors

The CloseForm method is called by Messaging to close the form.

Syntax

HRESULT CloseForm (
  BOOL fSave = FALSE
);

Parameters

fSave
[in] An optional parameter that indicates whether to save the changes to the message.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
Indicates success.

Remarks

After calling FormClosing on the host, the custom form must post a WM_CLOSE message to the parent window it received from the Messaging application on creation. This action cleans up the handle to the window that is no longer in use.

Requirements

Pocket PC: Windows Mobile 2003 and later
Smartphone: Windows Mobile 2003 and later
OS Versions: Windows CE .NET 4.2 and later
Header: cemapi.h
Library: cemapi.lib
