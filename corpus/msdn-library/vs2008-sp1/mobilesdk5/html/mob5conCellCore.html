CellCore

Send Feedback on this topic to the authors

CellCore provides a basic set of wireless connection oriented services that include the Radio Interface Layer (RIL), Short Message Service support (SMS), Wireless Application Protocol Support (WAP), an Extended TAPI and TSP, Subscriber Identity Module (SIM) card support, AT Command Interpreter (ATCI) and a Connection Manager.

The following CellCore topics apply to Windows Mobile-based Smartphones and Pocket PCs.

In This Section

WAP Wakeup
Describes the WAP Wakeup feature that enables applications to conserve memory.
Short Message Service Provider Registration
Describes how to associate message types with a Short Message Service (SMS) provider by modifying the registry.
Enabling Enhanced Messaging Service (EMS) Processing
Describes how to enable EMS processing by modifying the registry.
Short Message Service (SMS) API
Provides reference information for the Short Message Service (SMS) feature that supports sending messages of up to 160 characters to mobile based-devices.
SIM Manager API
Provides reference information for the SIM Manager feature that enables access to information stored on the SIM card.
Wireless Application Protocol (WAP) API
Provides reference information for the WAP feature that is the standard for the presentation and delivery of wireless information and telephony services.
