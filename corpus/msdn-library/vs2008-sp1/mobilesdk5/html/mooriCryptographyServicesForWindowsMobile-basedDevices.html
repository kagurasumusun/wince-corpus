Cryptography Services for Windows Mobile-based Devices

Send Feedback on this topic to the authors

Cryptography services in Windows Mobile help to ensure information confidentiality, data integrity, entity authentication, and data origin authentication. Cryptography provides a way to distribute or receive information in secret code, so only the intended parties can read or send it.

Windows Mobile provides cryptography services that enable application developers to add cryptographic security to their applications. This includes Cryptography APIs, Cryptographic Service Providers (CSP), issuing and managing certificates, and developing customizable public-key infrastructures, certificate and smart card enrollment. Cryptography services help to provide security for data and communication in your Windows CE–based applications.

In This Section

Cryptography for Windows Mobile-based Devices
Provides information about how you can use the cryptography functionality to enable application developers to encrypt and decrypt sensitive data.
Smart Card for Windows Mobile-based Devices
Provides information about how you can use the smart card dynamic-link libraries (DLLs), smart card resource manager application programming interface (API), and the smart card reader hardware device drivers that make up the smart card functionality.
