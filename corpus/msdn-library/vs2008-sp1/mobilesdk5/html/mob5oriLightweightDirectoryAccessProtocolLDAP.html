Lightweight Directory Access Protocol (LDAP)

Send Feedback on this topic to the authors

LDAP Client for Microsoft Windows CE-based devices supports Lightweight Directory Access Protocol (LDAP) version 3.0, which is used to access the membership directory that stores names, addresses, phone numbers, and other types of information.
