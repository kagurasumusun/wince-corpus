Internet Explorer MLang Objects

Send Feedback on this topic to the authors

The following table shows the Internet Explorer MLang objects with a description of the purpose of each.

Programming element Description
Code Page Enumeration This object retrieves a list of all the code pages the system recognizes.
Conversion This object is a conversion engine dedicated to a specified combination of source and destination code pages.
Locale Enumeration This object retrieves a sequence of RFC1766INFO structures.
IMultiLanguage This object is the primary object that provides access to all other objects and interfaces in the Multiple-Language interface.
Script Enumeration This object retrieves a list of all the scripts on the system.
