DevDetail Configuration Service Provider Examples for OMA DM

Send Feedback on this topic to the authors

The following XML examples can be used as templates to configure settings for the DevDetail Configuration Service Provider.

  • Query the Top-Level node of the DevDetail Object Example
  • Query the Software Version Example
  • Recursive Query the URI Example

To use these examples, you must replace the values as appropriate, and add the node as a child of the SyncBody node in an OMA DM provisioning file. For more information about the syntax of the provisioning file, see OMA DM Provisioning Files.
