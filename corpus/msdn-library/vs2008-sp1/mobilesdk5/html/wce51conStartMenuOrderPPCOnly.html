Start Menu Order (PPC Only)

Send Feedback on this topic to the authors

The Start menu on a Windows Mobile-based Pocket PC is ordered into the following three sections:

  • Pinned applications

    This section of the Start menu displays the pinned applications. The pinned applications can be selected from a list of items in the menu Control Panel application (CPL). Pinned applications are always displayed in the alphabetical order, with the exception of the Today application which always appear at the top of the list. The maximum number of items that can be displayed in this section is 7. You cannot remove the Today application from this list, so the minimum number of items displayed in this section is 1.

    This behavior is constant throughout the portrait, square and landscape orientations.

  • Most Recent Programs

    This section of the Start menu displays the most recently accessed applications. The maximum number of items displayed in this section depends on the number of pinned applications and the number of items in the Programs/Settings/Help section.

    In the portrait orientation, these items are displayed as a list view.

    In the landscape or square orientation, only the icons corresponding to the applications are displayed at the top of the Start menu. The number of application icons displayed is dependent on the longest string used in the pinned applications section.

  • Programs/Settings/Help

    This section displays Programs, Settings, and Help items. The Programs and Settings items are not removable from this list. The Help item can be removed if necessary.

    This behavior is constant throughout the portrait, square and landscape orientations.
