Short Message Service Enumerations

Send Feedback on this topic to the authors

The following table shows the Windows Mobile-based Smartphone enumerations supported for Short Message Service (SMS).

Enumeration Description
BROADCAST_PROVIDER_SPECIFIC_GEOGRAPHICAL_SCOPE Identifies the geographical area over which the message code of a message is unique
NOTIFICATION_PROVIDER_SPECIFIC_INDICATOR_TYPE Identifies the cellular line the notification is for.
NOTIFICATION_PROVIDER_SPECIFIC_MSG_WAITING_TYPE (SP) Identifies the type of message that is waiting.
PROVIDER_SPECIFIC_MESSAGE_CLASS Identifies the message class.
PROVIDER_SPECIFIC_REPLACE_OPTION Identifies the message replacement type.
SMS_ADDRESS_TYPE Identifies the phone number type.
SMS_DATA_ENCODING Specifies the data encoding for outgoing text messages.
WCMP_PROVIDER_SPECIFIC_MESSAGE_TYPE Contains provider-specific data.
WDP_PROVIDER_SPECIFIC_PORT_ADDRESSING Contains provider-specific data.
