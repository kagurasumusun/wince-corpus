ITimeZone::get_StandardDate

Send Feedback on this topic to the authors

The StandardDate property determines when a time zone enters standard time. Usage depends on whether this is an absolute date, such as October 31, or a relative date, such as the last Sunday in October.

Syntax

HRESULT get_StandardDate(
  DATE * pDate
);

Parameters

pDate
[out] Reference to the date object that defines when the time zone entered standard time.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Remarks

  • If IsStandardAbsoluteDate is TRUE, ignore the year.
  • If IsStandardAbsoluteDate is FALSE, use only the hours, minutes, and seconds portion of the date.

StandardDate is undefined if SupportsDST is FALSE.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
