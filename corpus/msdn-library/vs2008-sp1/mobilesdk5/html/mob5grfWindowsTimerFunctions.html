Windows Timer Functions

Send Feedback on this topic to the authors

The following table shows the windows timer functions with a description of the purpose of each.

Programming element PPC SP Description
KillTimer X X This function destroys the specified timer.
SetTimer X X This function creates a timer with the specified time-out value.
SystemIdleTimerReset X X This function resets a system timer that controls whether or not the device will automatically go into a suspended state.
TimerProc X X This function is an application-defined callback function that processes WM_TIMER messages.
