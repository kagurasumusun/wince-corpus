Chatting over Bluetooth

Send Feedback on this topic to the authors

This code sample is named BthChat. It demonstrates how to establish Bluetooth wireless peer-to-peer communications between mobile devices.

Feature Area

  • Bluetooth
  • Networking and Communication

Relevant APIs

  • Bluetooth API
  • Bluetooth Device Discovery

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution file is copied to the following folder:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Bluetooth\BthChat\BthChat.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Remarks

This code sample requires a discoverable Bluetooth device to run properly.

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: None.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
