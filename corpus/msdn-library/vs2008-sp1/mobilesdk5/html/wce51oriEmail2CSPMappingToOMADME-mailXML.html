Email2 Configuration Service Provider Mapping to OMA DM E-mail XML

Send Feedback on this topic to the authors

This section provides a mapping of OMA DM E-Mail XML to the existing EMAIL2 Configuration Service Provider. There are three separate OMA DM E-Mail XML schemas. There is a schema for POP3, IMAP, and SMTP settings. The topics in this section contain mapping tables indicating which parm names are supported and which are not unsupported. Supported parm names are mapped to Email2 Configuration Service Provider parm names.

All other parm names are either unsupported, or use values that require transformation or special handling in order to be used by the EMAIL2 Configuration Service Provider. These are addressed specifically in the section following each mapping table.
