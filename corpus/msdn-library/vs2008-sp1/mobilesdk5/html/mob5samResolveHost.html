Resolve Host

Send Feedback on this topic to the authors

This code sample is named Resolve. It demonstrates how to resolve a host name (for example, www.microsoft.com) into an IP address, or an IP address into a host name.

Feature Area

  • Communication Services and Networking

Relevant APIs

  • gethostbyaddr function
  • gethostbyname function
  • Winsock API

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution file is copied to the following folder:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Resolve\resolve.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

To use the application

  1. Enter a host name or an IP address into the upper edit control.
  2. Tap either "IP to Host" or "Host to IP".

    The result display in the lower edit control.

Remarks

This sample operates in the emulator or on a mobile device.

Accessing Internet addresses might require that you enter your proxy information in Connection Manager.

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
