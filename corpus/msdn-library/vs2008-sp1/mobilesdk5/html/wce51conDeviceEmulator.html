Device Emulator

Send Feedback on this topic to the authors

The Device Emulator is a tool that mimics the behavior of a Microsoft® Windows® CE–based hardware platform. It provides a virtual hardware platform that you can use to test applications on your Windows CE–based run-time image.

In this Section

Contains information about the Device Emulator, its purpose, and its functionality.
Launching the Device Emulator from Visual Studio
Provides step-by-step instructions for launching the Device Emulator from the Visual Studio Tools menu, or from the Device Emulator Manager.
Accessing Device Emulator Documentation
The Device Emulator documentation is programmatically associated with the Device Emulator feature. This topic provides information about accessing the Device Emulator documentation.
