Barring Modes

Send Feedback on this topic to the authors

The Barring Modes are listed in the following table.

Value Description
LINEBARRMODE_OUT Bar all outgoing calls.
LINEBARRMODE_OUT_INT Bar all international outgoing calls.
LINEBARRMODE_OUT_INTEXTOHOME Bar all international outgoing calls except to home.
LINEBARRMODE_IN Bar all incoming calls.
LINEBARRMODE_IN_ROAM Bar incoming calls when roaming.
LINEBARRMODE_IN_NOTINSIM Bar incoming calls not in Subscriber Identity Module (SIM) phone book.
LINEBARRMODE_ALL All barring services.
LINEBARRMODE_ALL_OUT All outgoing barring services.
LINEBARRMODE_ALL_IN All incoming barring services.

Requirements

Pocket PC: Pocket PC 2002 and later.
Smartphone: Smartphone 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: Extapi.h.
Library: Cellcore.lib.
