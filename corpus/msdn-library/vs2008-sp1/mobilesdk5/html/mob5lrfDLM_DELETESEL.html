DLM_DELETESEL

Send Feedback on this topic to the authors

The DLM_DELETESEL message is sent by an application to delete the item or items selected in the document list.

Syntax

DLM_DELETESEL
  wParam = (WPARAM) res1; 
  lParam = (LPARAM) res2;

Parameters

res1
This parameter is reserved for future use; the value of this parameter must be set to 0.
res2
This parameter is reserved for future use; the value of this parameter must be set to 0.

Return Values

Returns one of the standard HRESULT values.

Requirements

Pocket PC: Pocket PC 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: doclist.h.
Library: doclist.lib.
