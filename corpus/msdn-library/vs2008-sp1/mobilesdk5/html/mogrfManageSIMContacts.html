Manage SIM Contacts

Send Feedback on this topic to the authors

This code sample is named SIMMgr. It demonstrates how to add phone numbers to, and delete phone numbers from, a Subscriber Identity Module (SIM).

Feature Area

  • Networking
  • Telephony
  • CellCore

Relevant APIs

  • SIM Manager API
  • SimDeinitialize function
  • SimGetDevCaps function
  • SimInitialize function
  • SimReadPhonebookEntry function
  • Telephony API

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution file is copied to the following folder:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Smartphone SDK\Samples\CPP\Win32\Simmgr\SIMMgr.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Remarks

It is assumed that either you have a SIM in your Smartphone, or that you are using the Smartphone Emulator.

Requirements

Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
