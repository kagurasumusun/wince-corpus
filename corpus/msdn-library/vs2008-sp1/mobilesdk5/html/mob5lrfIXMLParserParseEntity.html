IXMLParser::ParseEntity

Send Feedback on this topic to the authors

This method parses the value of an internal entity reference <!ENTITY bar "<x>internal</x>">. IXMLNodeFactory::CreateNode calls will be made for the contents of the entity.

Syntax

HRESULT ParseEntity( 
  const WCHAR * pwcText,
  ULONG ulLen,
  BOOL fpe
);

Parameters

pwcText
[in] The internal entity reference text to be parsed.
ulLen
[in] The length of the text to be parsed.
fpe
[in] Specifies that this is a parameter entity.

Return Values

This function returns S_OK if the function is successful, otherwise an error code is returned.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: xmlparser.h
