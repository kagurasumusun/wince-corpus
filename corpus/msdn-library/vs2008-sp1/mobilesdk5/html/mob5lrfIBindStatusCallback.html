IBindStatusCallback

Send Feedback on this topic to the authors

This interface accepts information on an asynchronous bind operation.

The following methods are used with the IBindStatusCallback interface.

Method Description
IBindStatusCallback::GetBindInfo Provides information about how the bind operation should be handled when called by an asynchronous moniker.
IBindStatusCallback::GetPriority Obtains the priority for the bind operation when called by an asynchronous moniker.
IBindStatusCallback::OnDataAvailable Provides data to the client as it becomes available during asynchronous bind operations.
IBindStatusCallback::OnObjectAvailable Passes the requested object interface pointer to the client.
IBindStatusCallback::OnProgress Indicates the progress of the bind operation.
IBindStatusCallback::OnStartBinding Notifies the client about the callback methods it is registered to receive. This notification is a response to the flags the client requested in the RegisterBindStatusCallback function.
IBindStatusCallback::OnStopBinding Indicates the end of the bind operation.

Remarks

A client requesting an asynchronous bind operation must provide a notification object exposing the IBindStatusCallback interface. The asynchronous moniker provides information on the bind operation to the client by calling notification methods on the client's IBindStatusCallback interface. This interface also allows the client to pass additional bind information to the moniker by calling the IBindStatusCallback::GetBindInfo and IBindStatusCallback::GetPriority methods after receiving a call from IMoniker::BindToObject or IMoniker::BindToStorage.

Only the last IBindStatusCallback interface that was registered will be called.
