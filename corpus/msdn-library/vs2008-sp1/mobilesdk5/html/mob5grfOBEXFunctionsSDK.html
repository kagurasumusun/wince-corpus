The following table lists the functions for OBEX.

These functions are implemented to create a custom OBEX service extension.

Function PPC SP Description
ServerCallback X X Provides the necessary callback to the server from the specified server extension.
ServiceCallback X X Provides a pointer to the OBEXTRANSACTION structure.
