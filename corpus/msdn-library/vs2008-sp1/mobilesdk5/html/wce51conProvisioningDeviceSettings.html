Provisioning Device Settings

Send Feedback on this topic to the authors

Requests to query or change device settings are carried out by Configuration Service Providers. Each characteristic in an OMA Client Provisioning provisioning XML document is associated with a Configuration Service Provider. Similarly there is a configuration Service Provider associated with each OMA DM object. The following list shows examples of Configuration Service Providers for a few typical device settings

  • Locale - Locale Configuration Service Provider
  • Sounds - Sounds Configuration Service Provider
  • Speeddial - SpeedDial Configuration Service Provider
  • HomeScreen - Home Configuration Service Provider
  • TAPI - TAPI Configuration Service Provider
  • Clock - Clock Configuration Service Provider
