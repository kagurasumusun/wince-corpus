Custom Today Screen Items

Send Feedback on this topic to the authors

The Today screen provides a central place for users to easily view summary and high-priority information on Windows Mobile-based Pocket PCs. Developers can create custom Today screen items to present key information from their applications. For example, a sales force automation application could present key data about the customers the salesperson is planning to call on that day. The device also automatically times out and returns to the Today screen after a user-configurable period of disuse; the default is four hours.

Note   By default, Pocket PCs include Today screen applications for Messaging, Calendar, Tasks, and Owner Information. The user can choose whether and in what order these appear on the Today screen.
