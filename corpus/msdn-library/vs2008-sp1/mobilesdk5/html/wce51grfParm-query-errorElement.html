parm-query-error Element

Send Feedback on this topic to the authors

If an error occurs while a parm-query element is being processed, the erroneous element will be changed to a parm-query-error element.

Attributes

name
Contains the name of the parm-query element that causes the error.
desc
Contains a description of the error.
