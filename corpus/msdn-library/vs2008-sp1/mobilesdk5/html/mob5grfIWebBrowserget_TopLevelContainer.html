IWebBrowser2::get_TopLevelContainer

Send Feedback on this topic to the authors

This method uses the TopLevelContainer property to indicate whether the object is a top-level container.

HRESULT IWebBrowser2::get_TopLevelContainer(
  VARIANT_BOOL *pBool
);

Parameters

pBool
[out] Pointer to a VARIANT_BOOL value that receives VARIANT_FALSE if the object is not a top-level container and VARIANT_TRUE if the object is a top-level container.

Return Value

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

DISPID

DISPID_WEBBROWSER_TOPLEVELCONTAINER

The DISPID is defined in piedocvw.h. Use this value to identify the event handler when implementing IDispatch::Invoke.

Requirements

Pocket PC: Windows Mobile Version 5.0 and later
Smartphone: Windows Mobile Version 5.0 and later
OS Versions: Windows CE 5.01 and later
Header: piedocvw.h
Library: piedocvw.lib
