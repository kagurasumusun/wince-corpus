Copy a File to a Device

Send Feedback on this topic to the authors

This code sample is named Pput. It demonstrates how to programmatically copy a file from the desktop computer to a mobile device using the Remote API (RAPI) interface .

Feature Area

  • Networking and Communication

Relevant APIs

  • CeCloseHandle function
  • CeCloseHandle function
  • CeRapiInit function
  • CeRapiUninit function
  • CeReadFile function
  • CeWriteFile function
  • Remote API (RAPI) interface

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution files are copied to the following folders:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Rapi\Pput\pput.sln

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Smartphone SDK\Samples\CPP\Win32\Rapi\Pput\pput.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

To use the application

For example, if you want to copy a file from "c:\readme.txt" on the desktop computer to "\windows\readme.txt" on the mobile device, execute the command:

Pput c:\readme.txt \windows\readme.txt

Remarks

The code sample runs on the desktop host computer.

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
