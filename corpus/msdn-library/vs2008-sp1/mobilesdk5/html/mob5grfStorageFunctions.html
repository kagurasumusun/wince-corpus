Storage Functions

Send Feedback on this topic to the authors

The following table shows the Storage functions with a description of the purpose of each.

Programming element PPC SP Description
ReadClassStg X X This function reads the CLSID previously written to a storage object with the WriteClassStg.
ReadClassStm X X This function reads the CLSID previously written to a stream object with the WriteClassStm method.
StgCreateDocfile X X This function creates a new compound file storage object using the OLE-provided compound file implementation for the IStorage interface.
StgCreateDocfileOnILockBytes X X This function creates and opens a new compound file storage object on top of a byte array object provided by the caller.
StgOpenStorage X X This function opens an existing root storage object in the file system.
StgOpenStorageOnILockBytes X X This function opens an existing storage object that does not reside in a disk file, but instead has an underlying byte array provided by the caller.
WriteClassStg X X This function stores the specified CLSID in a storage object.
WriteClassStm X X This function writes a CLSID to the specified stream object so it can be read by the ReadClassStm function.
