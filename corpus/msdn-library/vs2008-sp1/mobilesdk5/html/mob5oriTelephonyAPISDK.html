Telephony API

Send Feedback on this topic to the authors

Windows CE supports a subset of the Microsoft Telephony API (TAPI) 2.0 and some parts of TAPI 2.1. TAPI is a set of APIs that simplify and abstract the details of making telephony connections between two or more devices. TAPI abstracts call-control functionality to allow different, and seemingly incompatible, communication protocols to expose a common interface to applications through its support of telephony service providers (TSPs).
