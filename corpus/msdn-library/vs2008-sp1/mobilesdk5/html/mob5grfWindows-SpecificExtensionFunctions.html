Windows-Specific Extension Functions

Send Feedback on this topic to the authors

The following table lists the Windows-specific extension functions.

Programming element PPC SP Description
WSAAccept X X This function conditionally accepts a connection based on the return value of a condition function and allows the transfer of connection data.
WSAAddressToString X X This function converts all parts of a sockaddr structure into a human-readable string representation of the address.
WSACleanup X X This function terminates use of the ws2.dll.
WSACloseEvent X X This function closes an open event object handle.
WSAConnect X X This function establishes a connection to another socket application and exchanges connect (Windows Sockets) data.
WSACreateEvent X X This function creates a new event object.
WSAEnumNameSpaceProviders X X This function retrieves information about available name spaces.
WSAEnumNetworkEvents X X This function discovers occurrences of network events for the indicated socket, clear internal network event records, and reset event objects (optional).
WSAEnumProtocols X X This function retrieves information about available transport protocols.
WSAEventSelect X X This function specifies an event object to be associated with the supplied set of FD_XXX network events.
WSAGetLastError X X This function gets the error status for the last operation that failed.
WSAGetOverlappedResult X X This function returns the results of an overlapped operation on the specified socket.
WSAHtonl X X This function converts a u_long from host byte order to network byte order.
WSAHtons X X This function converts a u_short from host byte order to network byte order.
WSAIoctl X X This function allows for miscellaneous control of a socket.
WSAJoinLeaf X X This function joins a leaf node into a multipoint session, and exchanges connect data.
WSALookupServiceBegin (Windows Sockets) X X This function initiates a client query that is constrained by the information contained within a WSAQUERYSET (Windows Sockets) structure. This function only returns a handle, which should be used by subsequent calls to the WSALookupServiceNext (Windows Sockets) function to get the actual results.
WSALookupServiceEnd (Windows Sockets) X X This function is called to free the handle after previous calls to WSALookupServiceBegin (Windows Sockets) and WSALookupServiceNext (Windows Sockets).
WSALookupServiceNext (Windows Sockets) X X This function is called after obtaining a handle from a previous call to the WSALookupServiceBegin (Windows Sockets) function to retrieve the requested service information.
WSANSPIoctl X X This function enables developers to make I/O control calls to a registered namespace.
WSANtohl X X This function converts a u_long from network byte order to host byte order.
WSANtohs X X This function converts a u_short from network byte order to host byte order.
WSARecv X X This function receives data from a connected socket.
WSARecvFrom X X This function receives data on a socket and stores the source address.
WSAResetEvent X X This function resets the state of the specified event object to nonsignaled.
WSASend X X This function sends data on a connected socket.
WSASendTo X X This function sends data to a specific destination, using overlapped I/O where applicable.
WSASetEvent X X This function sets the state of the specified event object to signaled.
WSASetLastError X X This function sets the error code that can be retrieved through the WSAGetLastError function.
WSASetService (Windows Sockets) X X This function registers or removes from the registry a service instance within one or more name spaces.
Note   This function is not supported for the default TCP/UDP provider in Windows CE. However, third parties can implement their own provider and have support for this function if they choose.
WSASocket X X This function creates a socket that is bound to a specific transport service provider.
WSAStartup X X This function initiates use of ws2.dll by a process.
WSAStringToAddress X X This function converts a numeric string to a sockaddr structure suitable for passing to Windows Sockets routines that take such a structure.
WSAWaitForMultipleEvents X X This function waits for multiple events and returns either when one or all of the specified event objects are in the signaled state, or when the timeout interval expires.
