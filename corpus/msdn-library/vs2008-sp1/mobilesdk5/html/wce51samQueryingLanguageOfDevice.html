Querying the Language of the Device

Send Feedback on this topic to the authors

This example is a query of the Lang child node.

<Get>
   <CmdID>2</CmdID>
   <Item>
      <Target>
         <LocURI>./DevInfo/Lang</LocURI>
      </Target>
   </Item>
</Get>

The response to this query identifies the language of the device by using the two-letter language code of the ISO 639 standard.
