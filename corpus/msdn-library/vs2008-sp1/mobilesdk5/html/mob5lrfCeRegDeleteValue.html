CeRegDeleteValue (RAPI)

Send Feedback on this topic to the authors

This function removes a value from the specified registry key on a remote Microsoft® Windows® CE–based device.

LONG CeRegDeleteValue( 
  HKEY hKey, 
  LPCWSTR lpszValueName 
);

Parameters

hKey
[in] Handle to a currently open key or any of the following predefined reserved handle values:

HKEY_CLASSES_ROOT

HKEY_CURRENT_USER

HKEY_LOCAL_MACHINE

HKEY_USERS

lpszValueName
[in] Pointer to a null-terminated string that names the value to remove. If this parameter is NULL or points to an empty string, the default value of the key is removed. A default value is created by calling CeRegSetValueEx with a NULL or empty string value name.

Return Values

ERROR_SUCCESS indicates success. A nonzero error code defined in Winerror.h indicates failure. To get a generic description of the error, call FormatMessage with the FORMAT_MESSAGE_FROM_SYSTEM flag set.

Remarks

The key identified by the hKey parameter must have been opened with KEY_SET_VALUE access (KEY_WRITE access includes KEY_SET_VALUE access).

Requirements

Pocket PC: Pocket PC 2002 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: Rapi.h
Library: Rapi.lib
