Window Class Functions

Send Feedback on this topic to the authors

The following table shows the window class functions with a description of the purpose of each.

Programming element PPC SP Description
GetClassInfo X X This function retrieves information about a window class.
GetClassLong X X This function retrieves the specified 32-bit (LONG) value from the WNDCLASS structure associated with the specified window.
GetClassName X X This function retrieves the name of the class to which the specified window belongs.
GetWindowLong X X This function retrieves information about the specified window.
RegisterClass X X This function registers a window class for subsequent use in calls to the CreateWindow or CreateWindowEx function.
SetClassLong X X This function replaces the specified 32-bit (LONG) value at the specified offset into the extra class memory of the WNDCLASS structure for the class to which the specified window belongs.
SetWindowLong X X This function changes an attribute of the specified window.
UnregisterClass X X This function removes a window class, freeing the memory required for the class.
UnregisterHotKey X X This function frees a hot key previously registered by the calling thread.
