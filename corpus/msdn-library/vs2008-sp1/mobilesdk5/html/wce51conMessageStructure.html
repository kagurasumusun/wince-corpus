Message Structure

Send Feedback on this topic to the authors

For an SI with the action attribute value set to signal-low, or an SL with the action set to cache, the user receives an unopened message in the Inbox that adds to the unread messages count.

The structure of an SI message and the structure of an SL message differ. SL messages have the same three options as SI messages; however, the Retrieve command executes the content that was already downloaded into cache.
