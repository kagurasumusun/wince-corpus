BT_CONNECT_EVENT

Send Feedback on this topic to the authors

This structure stores information about the BTE_CONNECTION (100) event for the Baseband connection.

typedef struct {
  DWORD dwSize;
  USHORT hConnection;
  BT_ADDR bta;
  UCHAR ucLinkType;
  UCHAR ucEncryptMode;
} BT_CONNECT_EVENT, *PBT_CONNECT_EVENT;

Members

dwSize
Size of this structure.
hConnection
Handle to the Baseband connection.
bta
Address of the remote Bluetooth device as a BT_ADDR type.
ucLinkType
Type of connection. ACL (1) or SCO (0).
ucEncryptMode
Encryption mode.

Requirements

Pocket PC Platforms: Windows Mobile 5.0 and later.
Smartphone Platforms: Windows Mobile 5.0 and later.
OS Versions: Windows CE 5.01 and later.
Header: Bt_api.h.
