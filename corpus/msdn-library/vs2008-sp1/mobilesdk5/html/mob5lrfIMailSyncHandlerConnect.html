IMailSyncHandler::Connect

Send Feedback on this topic to the authors

The Connect method is called by Messaging to request the transport to connect to the servers.

Syntax

HRESULT Connect (
  DWORD dwReserved,
  SYNCCREDENTIALS * pCredentials
);

Parameters

dwReserved
[in] Not used; set to zero.
pCredentials
[in] Reference to credentials used to connect. There is no need to free this buffer or hold onto it. It is valid only for the duration of the call.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
Indicates success.

Remarks

Messaging calls Connect to tell the transport to connect to the mail servers. The mail transport should connect to the server and get authenticated by the server at this time but should not do any synchronizing of mail or other data.

Requirements

Pocket PC: Pocket PC 2002 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: cemapi.h
Library: cemapi.lib
