PR_EMAIL_ADDRESS

Send Feedback on this topic to the authors

The PR_EMAIL_ADDRESS property contains the messaging user's e-mail address.

Additional Information

Must be exposed by: Distribution list and messaging user objects
Identifier: 0x3003
Property type: PT_TSTRING
Property tag: 0x3003001F

Remarks

The PR_EMAIL_ADDRESS property is one of the base address properties for all messaging users. It is a null-terminated string format that has meaning only for the underlying messaging system.

PR_EMAIL_ADDRESS is used in conjunction with the PR_ADDRTYPE and PR_MESSAGE_CLASS properties in addressing messages. The string format is qualified by PR_ADDRTYPE.

A valid PR_EMAIL_ADDRESS example is:

Bruce@XYZZY.COM

Requirements

Pocket PC: Pocket PC 2002 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: mapitags.h
Library: cemapi.lib
