PXLOGICAL Configuration Service Provider Examples for OMA Client Provisioning

Send Feedback on this topic to the authors

The PXLOGICAL Configuration Service Provider adds, removes, and modifies WAP logical and physical proxies by using WAP or the standard Windows Mobile-based device techniques. For more information, see the Update Standard WAP Connectivity Parameters.

Note   The PXLOGICAL and PXPHYSICAL mwid attribute is a Microsoft provisioning XML attribute. The mwid attribute is optional when adding a NAP or a proxy. It is required when updating and deleting existing NAPs and proxies and must have its value set to 1.

Device technique is the Microsoft format that promotes the ID parm into a characteristic around the other parms and subcharacteristics. The following list shows the ID parms:

  • PROXY-ID in the PXLOGICAL Configuration Service Provider
  • PXPHYSICAL-PROXY-ID in the PXPHYSICAL Configuration Service Provider

The following examples can be used as templates to configure settings for the PXLOGICAL Configuration Service Provider. Below the PXLOGICAL characteristic type, replace the value for each parm and characteristic type with values that correspond to your system. Not all parameters are shown in the examples.

  • Adding a Logical and a Physical Proxy Example (WAP Technique)
  • Adding and Modifying a Logical and a Physical Proxy Example (Device Technique)
  • Deleting a Physical Proxy Example (Device Technique)
  • Deleting a Logical Proxy Example (Device Technique)
  • Adding a Domain Example (Device Technique)
