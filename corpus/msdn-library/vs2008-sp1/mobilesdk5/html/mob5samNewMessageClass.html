New Message Class

Send Feedback on this topic to the authors

This code sample is named TV_Inbox. It demonstrates how to implement a new message class appropriate for SMS notifications from a Digital Video Recorder (DVR).

Feature Area

  • Messaging Forms
  • Short Message Service (SMS) API

Relevant APIs

  • IFormProviderEx interface
  • IMailRuleClient interface

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution file is copied to the following folder:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Tv_inbox\TV_Inbox.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

To use the application

  1. Build the project and register the DLL.
  2. Restart the messaging application.
  3. Receive an SMS message that begins with the prefix string "{TV}".

    Note the unique message class behavior in Inbox's list-view and form.

Remarks

Message Class is assigned to SMS messages with a "{TV}" prefix via an SMS interception rule.

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
