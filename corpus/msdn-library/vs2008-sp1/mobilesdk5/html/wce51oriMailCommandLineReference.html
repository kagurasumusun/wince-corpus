New Messaging APIs for Windows Mobile Version 5.0

Send Feedback on this topic to the authors

The following list shows the actions that the new Messaging APIs for Windows Mobile Version 5.0 enable application to perform:

  • Start up the Messaging Application (Inbox) and switch accounts.
  • Syncronize an account.
  • Create a new message form.
  • Open an existing message.
