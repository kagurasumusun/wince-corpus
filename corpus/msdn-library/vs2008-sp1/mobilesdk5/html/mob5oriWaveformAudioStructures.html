Waveform Audio Structures

Send Feedback on this topic to the authors

The following table shows the structures that the wave API uses.

Programming element PPC SP Description
AUDIOGAINCLASS X X This structure defines the parameters of an audio gain class.
STREAMPROPS X X This structure defines the properties of a waveform- audio stream.
WAVEFORMAT_MIDI X X This structure describes the waveform audio format for MIDI data.
WAVEFORMAT_MIDI_MESSAGE X X This structure contains MIDI messages that will be played by the audio driver.
WAVEFORMATEX X X This structure defines the format of waveform-audio data.
WAVEHDR X X This structure defines the header used to identify a waveform-audio buffer.
WAVEINCAPS X X This structure describes the capabilities of a waveform-audio input device.
WAVEOUTCAPS X X This structure describes the capabilities of a waveform-audio output device.
