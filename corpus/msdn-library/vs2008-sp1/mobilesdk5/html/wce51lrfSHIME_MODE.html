SHIME_MODE

Send Feedback on this topic to the authors

This enumeration specifies the input modes in the Input Method Editor (IME).

typedef enum tagSHIME_MODE {
   SHIME_MODE_NONE                = 0,
   SHIME_MODE_SPELL               = 1,
   SHIME_MODE_SPELL_CAPS          = 2,
   SHIME_MODE_SPELL_CAPS_LOCK     = 3,
   SHIME_MODE_AMBIGUOUS           = 4,
   SHIME_MODE_AMBIGUOUS_CAPS      = 5,
   SHIME_MODE_AMBIGUOUS_CAPS_LOCK = 6,
   SHIME_MODE_NUMBERS             = 7,
   SHIME_MODE_CUSTOM              = 8,
} SHIME_MODE;

Enumerators

SHIME_MODE_NONE
Input mode is None.
SHIME_MODE_SPELL
Input mode is Spell.
SHIME_MODE_SPELL_CAPS
Input mode is Spell Caps.
SHIME_MODE_SPELL_CAPS_LOCK
Input mode is Spell Caps Lock.
SHIME_MODE_AMBIGUOUS
Input mode is Ambiguous.
SHIME_MODE_AMBIGUOUS_CAPS
Input mode is Ambiguous Caps.
SHIME_MODE_AMBIGUOUS_CAPS_LOCK
Input mode is Ambiguous Caps Lock.
SHIME_MODE_NUMBERS
Input mode is numbers.
SHIME_MODE_CUSTOM
Input mode is custom.

Requirements

Smartphone: Windows Mobile 5.0 and later.
OS Versions: Windows CE 5.01 and later.
Header: Aygshell.h
