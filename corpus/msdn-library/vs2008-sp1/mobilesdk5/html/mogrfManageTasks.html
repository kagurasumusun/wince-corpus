Manage Tasks

Send Feedback on this topic to the authors

This code sample is named POOMTasks. It demonstrates how to write a Personal Information Manager (PIM)/Messaging application that uses API members from the Pocket Outlook Object Model (POOM) to create, delete, and otherwise manage tasks.

Feature Area

  • Pocket Outlook Object Model (POOM)

Relevant APIs

  • IPOutlookItemCollection Interface
  • IRecurrencePattern Interface
  • ITask Interface

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution file is copied to the following folder:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Smartphone SDK\Samples\CPP\Win32\Poomtasks\poomtasks.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Source File Listing

poomdata.cpp
Contains most of the code that deals with interacting with POOM.
poomtasks.cpp
Controls most of the windows and dialog boxes. This source file contains the WinProcs and initializes.

Requirements

Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
