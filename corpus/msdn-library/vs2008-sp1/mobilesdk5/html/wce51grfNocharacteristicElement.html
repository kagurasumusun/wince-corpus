nocharacteristic Element

Send Feedback on this topic to the authors

In a request message, this element indicates the settings to be removed. In a response message, this element indicates the elements that do not exist.

Attributes

type
In a request message, indicates the type of characteristic element to be removed.

In a response message, indicates the characteristic elements that do not exist.

mwid
This attribute is used in the Microsoft–specific section of a continuous provisioning WAP connectivity document. It indicates that the associated characteristic is a Network Access Point (NAP) or proxy ID.

This attribute must be present when updating existing NAPs or Proxies and must be set to "1".

If that parm value is "1", this is an Identification value. If the parm value does not exist, the mwid characteristic is not a WAP connectivity NAP or proxy ID.

Remarks

In some cases, the nocharacteristic tag will work on the top two levels to delete all, or specific, entries. This is true in the following Configuration Service Providers.

  • CM_NetEntries Configuration Service Provider
  • CM_ProxyEntries Configuration Service Provider
  • CM_VPNEntries Configuration Service Provider
  • CM_WiFiEntries Configuration Service Provider

When deleting top levels, the proper syntax is as follows. As an example only, the CM_ProxyEntries Configuration Service Provider is used.:

<wap-provisioningdoc>
 <nocharacteristic type="CM_ProxyEntries"/>
</wap-provisioningdoc>
