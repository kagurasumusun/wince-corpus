CM_Mappings Configuration Service Provider Examples for OMA Client Provisioning

Send Feedback on this topic to the authors

The following XML examples can be used as templates to configure the CM_Mappings Configuration Service Provider.

  • Configuring Connection Manager Using the Default Mappings
  • Configuring Multiple URLs to Use a Metanetwork
  • Adding a Mapping
  • Removing a Mapping
  • Provisioning an MMS Network Connection Using CM_Mappings

Below the CM_Mappings characteristic type, replace the values for each parameter and characteristic type with values that correspond to your system.

Caution   If the default mapping entries can satisfy the connection configuration requirements, do not make modifications (especially deletions) to the mapping table. If the default mapping entries cannot satisfy the connection configuration requirements, then carefully read this document and Connection Manager Configuration before using this Configuration Service Provider to make any changes to the mapping table. If modifications are necessary, it is strongly recommend that you change only the mapping entries that you created.
