ITask::get_DateCompleted

Send Feedback on this topic to the authors

The DateCompleted property determines when the task is completed. It gets set to the current date on the device when you set the Complete property. Dates must be set between 1/1/1900 and 12/31/2999, inclusive.

Syntax

HRESULT get_DateCompleted(
  DATE * pst
);

Parameters

pst
[out] Reference to the date object that defines the date completed.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
