IInternetBindInfo

Send Feedback on this topic to the authors

This interface is implemented by the system and provides data that the protocol might need to bind successfully.

The following methods are used with the IInternetBindInfo interface.

Method Description
IInternetBindInfo::GetBindInfo Gets the BINDINFO structure associated with the binding operation.
IInternetBindInfo::GetBindString Retrieves the strings needed by the protocol for its operation.
