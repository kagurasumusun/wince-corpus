Configuration Manager Message Processing

Send Feedback on this topic to the authors

Configuration Manager lies at the heart of configuration message processing. It handles XML documents that conform to the provisioning DTD and passes the requests to appropriate service providers that can handle the requests. Every provisioning XML document has a set of characteristic elements below the top level. Configuration Manager splits the incoming document depending on the top characteristic elements and their association with the Configuration Service Providers. Configuration Manager parses the document, invokes the needed Configuration Service Providers, and passes the appropriate nodes to those Configuration Service Providers for further action.
