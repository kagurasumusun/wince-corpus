Attribute Value Tokens

Send Feedback on this topic to the authors

Some common values of parameters should be tokenized. They are defined in every code page ranging from 0x80 to 0xFF, except the tokens that are defined as global tokens (80~84, C0~C4).

Windows Mobile Version 5.0 supports all of the standard Attribute Value tokens as defined in OMA-WAP-ProvCont-v1_1-20030813-C.

The following Microsoft custom Attribute Value tokens are in Windows Mobile Version 5.0 code page 201.
