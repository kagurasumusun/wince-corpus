Remote API 2 (RAPI2) Enumerations

Send Feedback on this topic to the authors

The following table shows lists the enumeration for the Remote API 2 enumerations.

Enumeration Description
RAPI_DEVICESTATUS Specifies a Windows CE-based device's connection state.
RAPI_GETDEVICEOPCODE Specifies whether an operation code run on a Windows CE-based device is blocking.
RAPI_CONNECTIONTYPE Specifies the type of connection that exists between a Windows CE-based device and a host computer.

The RAPI_CONNECTIONINFO structure contains a member of this type
