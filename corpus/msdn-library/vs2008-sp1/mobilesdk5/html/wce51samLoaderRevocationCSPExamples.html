LoaderRevocation Configuration Service Provider Examples for OMA Client Provisioning

Send Feedback on this topic to the authors

The LoaderRevocation Configuration Service Provider can add certificate (.cer files), binary (.exe and .dll files), and cabinet (.cab files) file hashes to the revocation list, remove these hashes from the revocation list, and retrieve information about the hashes in the list.

The following XML examples can be used as templates to configure settings for the LoaderRevocation Configuration Service Provider. Below the LoaderRevocation characteristic type, replace the value for each parm and characteristic type with values that correspond to your system.

  • Adding Two Revocation Hashes to the Revocation List Example
  • Querying the Stores for All Revocation Hashes in the Store Example
  • Output from the Revocation List Query Example
  • Removing a Hash from the Revocation List Example
  • Querying for Individual Hashes in the Revocation List Example
  • Output from the Query for an Individual Hash Example
