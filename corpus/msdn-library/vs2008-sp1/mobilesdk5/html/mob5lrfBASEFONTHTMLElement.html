BASEFONT HTML Element

Send Feedback on this topic to the authors

The BASEFONT element sets attributes of the default font to be used when rendering text. This element does not require a closing tag.

Attributes

Attribute Value Description
COLOR Special Specifies the default color of the enclosed text.
Note   Supported only for Windows Mobile 2002 software or later.
FACE Special Specifies a comma-separated list of font names in which the text is rendered.
SIZE 1...7

3 (default)

 Specifies an integer font size.

Requirements

Pocket PC: Pocket PC 2002 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
