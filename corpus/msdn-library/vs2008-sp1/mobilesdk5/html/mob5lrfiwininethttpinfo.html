IWinInetHttpInfo

Send Feedback on this topic to the authors

This interface checks information on HTTP requests made through the underlying Microsoft® Win32® Internet functions.

The following method is used with the IWinInetHttpInfo interface.

Method Description
IWinInetHttpInfo::QueryInfo Retrieves the specified information from an HTTP request.

Remarks

Client applications can call QueryInterface on the IBinding interface to get a pointer to the IWinInetHttpInfo interface after your implementation of the IBindStatusCallback::OnProgress method has been called.
