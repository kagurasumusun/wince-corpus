IMAGE HTML Object

Send Feedback on this topic to the authors

The IMAGE object contains information about the browser.

Properties

Property Data type Access Description
alt String Read-only Sets or retrieves a text alternative to the graphic.
border Variant Read-only Sets or retrieves the width of the border to draw around the object.
height Long Read/write Sets or retrieves the height of the object.
hspace Long Read-only Sets or retrieves the horizontal margin for the object.
src String Read/write Sets or retrieves a URL to be loaded by the object.
vspace Long Read-only Sets or retrieves the vertical margin for the object.
width Long Read/write Sets or retrieves the calculated width of the object.

Requirements

Pocket PC: Windows Mobile 2003 and later
Smartphone: Windows Mobile 2003 and later
OS Versions: Windows CE .NET 4.2 and later
