WAP NAPDEF

Send Feedback on this topic to the authors

The WAP NAPDEF characteristic and its parms are sent to the remote access or General Packet Radio Services (GPRS) configuration of Connection Manager. For more information see NAPDEF Configuration Service Provider.

The following table shows the NAP parms that are supported on Windows Mobile-based devices.

Characteristic Parm Comments
NAPDEF   A network GUID will be generated for each acceptable NAPDEF. A network entry will be sent to the Connection Manager network configuration. The format of the network name is:#NAME + "@" + NAPID + "@NAPDEF"
  NAPID The name of WAP PPP/GPRS entry is a combination of NAPID and a predefined word "WAP":#NAPID + "@WAP"
Note   This maximum length for this string is 16 characters if the BEARER value is GSM-CSD.
  NAME Set as part of the name of the created network.
  BEARER GSM-circuit-switched data (CSD) and GSM-GPRS are supported. Other bearer settings will be discarded.
  NAP-ADDRESS  
  NAP-ADDRTYPE E164 and Access Point Name (APN) are supported.
  CALLTYPE CALLTYPE and LINKSPEED are used together to set the BearerInfoSpeed parm under the DevSpecificCellular characteristic in the CM_PPPEntries in the Connection Manager Configuration Service Provider.
  LINKSPEED  
  LINGER This parm is not used by Windows Mobile-based Smartphone or Windows Mobile-based Pocket PC
  LOCAL-ADDR If BEARER= "GSM-GPRS" and LOCAL-ADDRTYPE = "IPV4", LOCAL-ADDR is used by Windows Mobile-based devices to provision a client static GPRS IP address — DevSpecificCellular/GPRSInfoAddress. On Windows Mobile-based Smartphone 2003 and Windows Mobile-based Pocket PC 2003 devices, provisioning the GPRS IPV6 address is supported.
  LOCAL-ADDRTYPE If BEARER= "GSM-GPRS" and LOCAL-ADDRTYPE = "IPV4", LOCAL-ADDR is used by Windows Mobile-based devices to provision the client static GPRS IP address — DevSpecificCellular/GPRSInfoAddress. Windows Mobile-based Smartphone 2003 and Windows Mobile-based Pocket PC 2003 devices support IPV6.
NAPDEF/ NAPAUTHINFO    
NAPDEF/ NAPAUTHINFO AUTHTYPE (PAP, CHAP)  
NAPDEF/ NAPAUTHINFO AUTHNAME  
NAPDEF/ NAPAUTHINFO AUTHSECRET  
  TRAFFIC-CLASS A mapping table is required to translate WAP GPRS quality of service (QoS) (3GPP R99) settings to GPRS QoS (GSM -GPRS) settings supported on Windows Mobile-based devices. The mapping table that follows lists all parms that can be converted to supported QoS parms. The entire mapping table is listed in 3GPP TS 23.107 V3.5.0 (2000-12).
  TRAFFIC-HANDL-PRIO  
  SDU-ERROR-RATIO  
  RESIDUAL-BER
