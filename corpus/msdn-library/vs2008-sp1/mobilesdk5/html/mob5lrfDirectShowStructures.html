DirectShow Structures

Send Feedback on this topic to the authors

This section describes the Microsoft® DirectShow® structures.

Programming element PPC SP Description
ALLOCATOR_PROPERTIES X X Contains the allocator's count, size, alignment, and prefix properties.
AM_MEDIA_TYPE X X Describes a media sample type.
AM_SAMPLE2_PROPERTIES X X Describes the properties of a generic media sample.
FILTER_INFO X X Contains information about a filter.
PIN_INFO X X Contains information about a pin.
POSITION X X Placeholder for linked lists.
Quality X X Describes a quality message by indicating Flood or Famine in the renderer and specifying the percentage of frames to drop or add to optimize the renderer's performance.
StructEncoderParameter X X Used to describe the properties of imaging parameters when using the IImageSinkFilter interface.
