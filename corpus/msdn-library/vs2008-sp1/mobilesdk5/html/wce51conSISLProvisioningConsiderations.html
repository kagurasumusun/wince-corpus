SI and SL Provisioning Considerations

Send Feedback on this topic to the authors

You can deliver provisioning XML by Using Service Indication (SI) and Service Location (SL). The following table shows the Security policies to use:

Policy Description
Service Indication (SI) Message Policy Indicates whether SI messages are accepted. An SI messages sent to the Windows mobile-based smart phone to notify users of a new services, service update, and provisioning services. The provisioning file should be wrapped in signed cab file
Service Loading (SL) Message Policy Indicates whether SL messages are excepted. An SL message downloads new services or provisioning file to the Windows mobile-based device. The provisioning file should be wrapped in signed cab file

This policy allows the Mobile Operator to override HTTPS to use HTTP or wsps to use wsp.

For more information about these policies, see the following topics:

  • Security Policy Settings
  • SI and SL Security
  • SI and SL XML Files
