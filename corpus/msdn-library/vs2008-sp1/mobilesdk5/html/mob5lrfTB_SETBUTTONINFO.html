TB_SETBUTTONINFO

Send Feedback on this topic to the authors

The TB_SETBUTTONINFO message sets the information for an existing button on a soft key bar. The information can include the ID, text, and state of the button.

Syntax

TB_SETBUTTONINFO
  wParam = (WPARAM) (int) iID;
  lParam = (LPARAM) (LPTBBUTTONINFO) lptbbi;

Parameters

iID
The button identifier.
lptbbi
References a Windows CE TBBUTTONINFO structure that contains the new button information.

Windows Mobile-based Smartphone supports setting the following information in the Windows CE TBBUTTONINFO structure:

  • fsState (TBSTATE_ENABLED and TBSTATE_HIDDEN only)
  • idCommand
  • pszText

Return Values

Returns nonzero if successful, or zero otherwise.

Remarks

The cbSize and dwMask members of a Windows CE TBBUTTONINFO structure must be assigned values prior to sending the TB_GETBUTTONINFO message.

Requirements

Pocket PC: Pocket PC 2002 and later.
Smartphone: Smartphone 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: Aygshell.h.
Library: Aygshell.lib.
