FDRM API Reference

Send Feedback on this topic to the authors

This language reference section contains descriptions of File Based Digital Rights Managed (FDRM) programming elements for Windows Mobile-based Smartphones and Pocket PCs.

These programming elements define the interface for FDRM-protected content on Windows Mobile-based Smartphones and Pocket PCs. The programming elements are used by device applications to access FDRM-protected content. The FDRM API enables you to plug in the FDRM Engine of your choice. An OMA DRM V1 engine is an example of a DRM engine which can be integrated into the FDRM API.
