VR_ECODE

Send Feedback on this topic to the authors

This enumeration must be the same as in VoiceDll.h.

typedef enum tagVR_ErrorCodes {
  ER_SUCCESS,
  ER_FAIL,
  ER_OUTOFMEMORY,
  ER_UNUSED1,
  ER_INVALIDPARAM,
  ER_UNUSED2,
  ER_WRITE_FILE_FAIL,
  ER_UNUSED3,
  ER_OOM_STORAGE,
  ER_MAX_FILE_SIZE,
  ER_BUSY,
} VR_ECODE;

Enumerators

ER_SUCCESS
No error.
ER_FAIL
Unknown error.
ER_OUTOFMEMORY
Out of memory.
ER_UNUSED1
Not used.
ER_INVALIDPARAM
Invalid parameter.
ER_UNUSED2
Not used.
ER_WRITE_FILE_FAIL
Error while writing to a file.
ER_UNUSED3
Not used.
ER_OOM_STORAGE
Out of storage.
ER_MAX_FILE_SIZE
Maximum file size reached during recording.
ER_BUSY
Control is busy recording or playing.

Requirements

Smartphone Platforms: Smartphone 2002 and later
Pocket PC Platforms: Pocket PC 2000 and later
OS Versions: Windows CE 3.0 and later
Header: voicectl.h
Library: voicectl.lib
