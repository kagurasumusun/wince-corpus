Synchronization Functions

Send Feedback on this topic to the authors

The following table shows the kernel synchronization functions.

Programming element PPC SP Description
CreateEvent X X This function creates a named or an unnamed event object.
CreateMutex X X This function creates a named or unnamed mutex object.
CreateSemaphore X X This function creates a named or unnamed semaphore object.
DeleteCriticalSection X X This function releases all resources used by a critical section object that is not owned.
DuplicateHandle X X This function duplicates an object handle. The duplicate handle refers to the same object as the original handle. Therefore, any changes to the object are reflected through both handles.
EnterCriticalSection X X This function waits for ownership of the specified critical section object.
InitializeCriticalSection X X This function initializes a critical section object.
InterlockedCompareExchange X X This function performs an atomic comparison of the specified values and exchanges the values based on the outcome of the comparison.
InterlockedCompareExchangePointer X X This function performs an atomic comparison of the specified parameter values and exchanges the values based on the outcome of the comparison.
InterlockedDecrement X X This function both decrements (decreases by one) the value of the specified 32-bit variable and checks the resulting value.
InterlockedExchange X X This function atomically exchanges a pair of 32-bit values.
InterlockedExchangeAdd X X This function performs an atomic addition of an increment value to an Addend variable.
InterlockedExchangePointer X X This function atomically exchanges a pair of values.
InterlockedIncrement X X This function both increments (increases by one) the value of the specified 32-bit variable and checks the resulting value.
InterlockedTestExchange X X This function is an interlocked function that performs a conditional setting of a variable.
LeaveCriticalSection X X This function releases ownership of the specified critical section object.
OpenEvent X X This function opens an existing named event object.
PulseEvent X X This function provides a single operation that sets to signaled the state of the specified event object and then resets it to nonsignaled after releasing the appropriate number of waiting threads.
ReleaseMutex X X This function releases ownership of the specified mutex object.
ReleaseSemaphore X X This function increases the count of the specified semaphore object by a specified amount.
ResetEvent X X This function sets the state of the specified event object to nonsignaled.
SetEvent X X This function sets the state of the specified event object to signaled.
TryEnterCriticalSection X X This function attempts to enter a critical section without blocking.
WaitForMultipleObjects X X This function returns when either any one of the specified objects is in the signaled state, or the time-out interval elapses.
WaitForSingleObject X X This function returns when the specified object is in the signaled state or when the time-out interval elapses.
