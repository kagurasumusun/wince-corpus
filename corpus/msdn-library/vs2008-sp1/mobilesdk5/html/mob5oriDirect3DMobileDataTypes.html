Direct3D Mobile Data Types

Send Feedback on this topic to the authors

The following table shows the data types for Microsoft® Direct3D® Mobile.

Data Type PPC SP Description
D3DMVALUE X X This data type describes a generic 32-bit value. Values stored in this type can either be fixed or floating point.
D3DMCOLOR X X This data type represents a color using the D3DMFMT_A8R8G8B8 format.
