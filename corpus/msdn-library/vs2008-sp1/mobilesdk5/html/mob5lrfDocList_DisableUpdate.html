DocList_DisableUpdate

Send Feedback on this topic to the authors

The DocList_DisableUpdate macro prevents the document list view from updating.

DocList_DisableUpdate (HWND hwnd)

Parameters

hwnd
Handle to the document list view window.

Return Values

None.

Requirements

Pocket PC: Pocket PC 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: doclist.h.
Library: doclist.lib.
