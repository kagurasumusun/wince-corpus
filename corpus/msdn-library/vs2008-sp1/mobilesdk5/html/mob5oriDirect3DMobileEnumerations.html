Direct3D Mobile Enumerations

Send Feedback on this topic to the authors

The following table shows the enumerations for Microsoft® Direct3D® Mobile.

Enumeration PPC SP Description
D3DMBACKBUFFER_TYPE X X Defines constants that describe the types of back buffers.
D3DMBLENDOP X X Provides values that identify functions for alpha blending operations.
D3DMBLEND X X Provides values that identify scaling factors for alpha blending operations.
D3DMCMPFUNC X X Provides values that identify comparison functions for various render states.
D3DMCULL X X Defines the possible values for the D3DMRS_CULLMODE render state.
D3DMDEVTYPE X X This enumeration is not currently used.
D3DMFILLMODE X X Provides values that describe how primitives should be rasterized.
D3DMFOGMODE X X Provides values that identify fog equations used in various render states.
D3DMFORMAT X X Defines the various types of surface formats.
D3DMLIGHTTYPE X X Provides values used in the D3DMLIGHT structure to describe the types of lights that are available in Direct3D Mobile.
D3DMMATERIALCOLORSOURCE X X Provides values that describe material colors for render states.
D3DMMULTISAMPLE_TYPE X X Defines levels of full-scene multisampling that the device can apply.
D3DMPOOL X X Provides values that describe the memory pools for allocating Direct3D Mobile resources.
D3DMPRIMITIVETYPE X X Defines the primitives supported by Microsoft Direct3D Mobile.
D3DMPROFILE X X Identifies all of the Direct3D Mobile profiles defined by Microsoft.
D3DMRENDERSTATETYPE X X Provides values that identify render states.
D3DMRESOURCETYPE X X Identifies the types of Direct3D Mobile-specific resources available to an application.
D3DMSHADEMODE X X Provides values that describe the type of shading model to use when rendering a primitive.
D3DMSTENCILOP X X Provides values used to identify actions that the Direct3D Mobile pixel pipeline will take as the result of a stencil test.
D3DMSWAPEFFECT X X Povides values to identify the possible ways to present a scene.
D3DMTEXTUREADDRESS X X Povides values that identify texture coordinate addressing modes.
D3DMTEXTUREFILTERTYPE X X Provides values for the texture stage states used for texture filtering and for mipmaps.
D3DMTEXTUREOP X X Provides values that identify the possible operations for the texture stage states D3DMTSS_COLOROP and D3DMTSS_ALPHAOP (see D3DMTEXTURESTAGESTATETYPE).
D3DMTEXTURESTAGESTATETYPE X X Provides values that are used to identify texture stage states.
D3DMTEXTURETRANSFORMFLAGS X X Provides flags that control when a transformation matrix is applied to a texture in a texture stage state.
D3DMTRANSFORMSTATETYPE X X Provides values that define types of transformation matrices.
D3DMZBUFFERTYPE X X Provides values that identify types of depth buffering.
