Credential Manager Type Provider Functions

Send Feedback on this topic to the authors

The following table shows the functions that a type provider must implement, with a description of the purpose of each.

Programming element PPC SP Description
HandleBlob X X This function enables type providers to determine what information has to be cached by the credential manager.
Load X X This function registers a primitive credential type with a type provider.
MatchTarget X X This function enables the type provider to determine if two different target strings are semantically equivalent.
MatchUser X X This function enables the type provider to determine if two different user strings are semantically equivalent.
Unload X X This function unregisters a primitive credential type with a type provider.
