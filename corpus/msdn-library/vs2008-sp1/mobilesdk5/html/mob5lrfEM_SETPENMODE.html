EM_SETPENMODE

Send Feedback on this topic to the authors

The EM_SETPENMODE message sets the new pen mode, pen, select, or space, of the RichInk control.

EM_SETPENMODE
  wParam = (WPARAM) (UINT) penMode; 
  lParam = (LPARAM) 0;

Parameters

penMode
Contains pen mode (MODE_PEN, MODE_SELECT, or MODE_SPACE).
lParam
Reserved; set to 0.

Return Values

None.

Remarks

#define EM_SETPENMODE (WM_USER + 329)

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: None
OS Versions: Windows CE 3.0 and later
Header: richink.h
Library: richink.lib
