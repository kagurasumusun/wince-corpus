IItem::get_Application

Send Feedback on this topic to the authors

The get_Application method gets the main Outlook Mobile IPOutlookApp object.

Syntax

HRESULT get_Application(
  IPOutlookApp ** ppolApp
)

Parameters

ppolApp
[out] Reference to the Outlook Mobile application object.

Return Values

This method returns the standard values HRESULT_FROM_WIN32(GetLastError()), E_INVALIDARG, and S_FAIL, as well as the following:

S_OK
The method completed successfully.

Requirements

Pocket PC: Windows Mobile Version 5.0 and later
Smartphone: Windows Mobile Version 5.0 and later
OS Versions: Windows CE 5.01 and later
Header: pimstore.h
Library: pimstore.lib
