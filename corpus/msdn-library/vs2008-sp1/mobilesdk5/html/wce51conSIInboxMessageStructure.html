SI Inbox Message Structure

Send Feedback on this topic to the authors

The text in the SI notification and the href attribute value are the body of the message in the Inbox.

The following graphic displays the Inbox with one SI message.

If the href attribute is not provided, the Retrieve command does not exist.

The following list describes all of the features of an SI notification:

  • Sent   The value of the created attribute after it is converted to the format specified by the Regional Settings on the mobile device.
  • From   The Push Initiator (server) URL. If no server URL is found, a predefined string is used: "Unidentified Sender".
  • Subject   The URI from the href attribute. For example, "Message from <www.adatum.com>". If the href attribute does not exist, a predefined string is used: "Message".
