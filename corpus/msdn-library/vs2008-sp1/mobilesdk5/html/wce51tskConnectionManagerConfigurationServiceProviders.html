Connection Manager Configuration Service Providers

Send Feedback on this topic to the authors

There are two different classes of configuration service providers for Connection Manager. One class of configuration service providers uses the OMA Client Provisioning (formerly WAP) protocol, and the other class uses the OMA DM protocol.

If you want to provision a connection as secure, or if you want to provision an AlwaysOn connection, use the OMA Client Provisioning (formerly WAP) configuration service providers. The OMA DM protocol provides a bit more flexibility in configuring multiple connections using connection references.

The following table shows configuration service providers that can be used in configuring Connection Manager using the OMA Client Provisioning (formerly WAP) protocol. For a complete list of available configuration service providers, see Configuration Service Providers.

Configuration Service Provider Description
CM_Networks Configures the metanetworks, such as the Internet, on the device.
CM_Planner Configures the preferred connections for Connection Manager.
CM_Mappings Configures the URL mapping table that determines the network where the URL resides.
CM_GPRSEntries Configures General Packet Radio Services (GPRS) entries on the device.
CM_PPPEntries Configures the Point-to-Point Protocol (PPP) entries on the device.
CM_ProxyEntries Configures proxy connections on the device.
CM_VPNEntries Configures VPN entries on the device.
CM_NetEntries Configures additional network entries, such as Desktop Passthrough, on the device.

The following table shows configuration service providers that can be used in configuring Connection Manager using the OMA DM protocol. For a complete list of available configuration service providers, see Configuration Service Providers.

Configuration Service Provider Description
ACCESS Configures the metanetworks, such as the Internet, and the URL mapping table on the device.
CMPLANNER Configures the preferred connections for Connection Manager.
NAP Configures data and cellular connections on the device.
PROXY Configures proxy connections on the device.
VPN Configures VPN connections on the device.

Microsoft Windows Mobile-based platforms ship with default mapping and network information for the CM_Mappings and CM_Networks Configuration Service Providers. These Configuration Service Providers do not need to be manually configured before establishing a connection.
