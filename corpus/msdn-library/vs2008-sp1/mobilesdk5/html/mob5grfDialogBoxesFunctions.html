Dialog Boxes Functions

Send Feedback on this topic to the authors

The following table shows the common dialog boxes functions with a description of the purpose of each.

Programming element PPC SP Description
CheckDlgButton X X This inline function sets the check state of a radio button or check box in a specified dialog box.
CreateDialog X X This function creates a modeless dialog box from a dialog box template resource.
CreateDialogIndirect X X This function creates a modeless dialog box from a dialog box template in memory.
CreateDialogIndirectParam X X This function creates a modeless dialog box from a dialog box template in memory.
CreateDialogParam X X This function creates a modeless dialog box from a dialog box template resource.
DefDlgProc X X This function carries out default message processing for a window procedure belonging to an application-defined dialog box class.
DialogBox X X This function creates a modal dialog box from a dialog box template resource.
DialogBoxIndirect X X This function is defined as a macro and creates a modal dialog box from a dialog box template in memory.
DialogBoxIndirectParam X X This function creates a modal dialog box from a dialog box template in memory.
DialogBoxParam X X This function creates a modal dialog box from a dialog box template resource.
DialogProc X X This function is an application-defined callback function that processes messages sent to a modal or modeless dialog box.
EndDialog X X This function destroys a modal dialog box, causing the system to end any processing for the dialog box.
GetDialogBaseUnits X X This function returns the dialog box base units used by Windows to create dialog boxes.
GetDlgCtrlID X X This function returns the identifier of the specified control.
GetDlgItem X X This function retrieves the handle to a control in the specified dialog box.
GetDlgItemInt X X This function translates the text of a specified control in a dialog box into an integer value.
GetDlgItemText X X This function retrieves the title or text associated with a control in a dialog box.
GetNextDlgGroupItem X X This function retrieves the handle to the first control in a group of controls that precedes or follows the specified control in a dialog box.
GetNextDlgTabItem X X This function retrieves the handle to the first control with the WS_TABSTOP style that precedes or follows the specified control.
IsDialogMessage X X This function determines whether a message is intended for the specified dialog box and, if it is, processes the message.
IsDlgButtonChecked X X This inline function retrieves the check state of a radio button or check box in a specified dialog box.
MapDialogRect X X This function converts, or maps, the specified dialog box units to screen units, or pixels.
MessageBeep X X This function plays a waveform sound.
MessageBox X X This function creates, displays, and operates a message box.
SendDlgItemMessage X X This function sends a message to the specified control in a dialog box.
SetDlgItemInt X X This function sets the text of a control in a dialog box to the string representation of a specified integer value.
SetDlgItemText X X This function sets the title or text of a control in a dialog box.
