InitInkX

Send Feedback on this topic to the authors

The application calls this function to load and initialize the control properly. The control can be inserted as a dialog box custom control with class setting InkX.

void InitInkX (void);

Parameters

None.

Return Values

None.

Remarks

APIs are used in RichInk.h to implement a menu bar user interface (UI).

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: None
OS Versions: Windows CE 3.0 and later
Header: inkx.h
Library: inkx.lib
