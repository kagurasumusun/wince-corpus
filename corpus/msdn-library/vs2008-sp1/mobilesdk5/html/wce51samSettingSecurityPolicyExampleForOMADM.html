Setting a Security Policy Example for OMA DM

Send Feedback on this topic to the authors

The following XML example can be used as templates to configure settings for the SecurityPolicy Configuration Service Provider.

Note   To use this example, you must replace the values as appropriate, and add the node as a child of the SyncBody node in an OMA DM provisioning file. For more information about the syntax of the provisioning file, see OMA DM Provisioning Files.

The following example sets the security policy 4111 to 0.

        <CmdID>1</CmdID>

        <Replace>
            <CmdID>Change the policy </CmdID>
            <Item>
                <Target><LocURI>./Vendor/MSFT/SecurityPolicy/4111</LocURI></Target>
                <Meta>
                    <Format xmlns="syncml:metinf">int</Format>
                </Meta>
                <Data>0</Data>
            </Item>
        </Replace>
