Message Recipient Properties

Send Feedback on this topic to the authors

These properties appear on message objects, and pertain to recipients and senders.

Constant Description Data type Property ID Property Tag
PR_CONTENT_INTEGRITY_CHECK Contains an ASN.1 content integrity check value that allows a message sender to help protect message content from disclosure to unauthorized recipients. PT_BINARY 0x0C00 0x0C000102
PR_EXPLICIT_CONVERSION Contains a value that indicates that a message sender has requested a message content conversion for a particular recipient. PT_LONG 0x0C01 0x0C010003
PR_IPM_RETURN_REQUESTED Contains TRUE if this message should be returned with a report. PT_BOOLEAN 0x0C02 0x0C02000B
PR_MESSAGE_TOKEN Contains an ASN.1 security token for a message. PT_BINARY 0x0C03 0x0C030102
PR_NDR_REASON_CODE Contains an encoded reason for nondelivery that forms part of a nondelivery report. PT_LONG 0x0C04 0x0C040003
PR_NDR_DIAG_CODE Contains a diagnostic code that forms part of a nondelivery report. PT_LONG 0x0C05 0x0C050003
PR_NON_RECEIPT_NOTIFICATION_REQUESTED Contains TRUE if a message sender wants notification of non-receipt for a specified recipient. PT_BOOLEAN 0x0C06 0x0C06000B
PR_DELIVERY_POINT Contains a value that specifies the nature of the functional entity by means of which a message was or would have been delivered to the recipient. PT_LONG 0x0C07 0x0C070003
PR_ORIGINATOR_NON_DELIVERY_REPORT_REQUESTED Contains TRUE if a message sender requests a nondelivery report for a particular recipient. PT_BOOLEAN 0x0C08 0x0C08000B
PR_ORIGINATOR_REQUESTED_ALTERNATE_RECIPIENT Contains an entry identifier for an alternate recipient designated by the sender. PT_BINARY 0x0C09 0x0C090102
PR_PHYSICAL_DELIVERY_BUREAU_FAX_DELIVERY Contains TRUE if the messaging system should use a fax bureau for physical delivery of this message. PT_BOOLEAN 0x0C0A 0x0C0A000B
PR_PHYSICAL_DELIVERY_MODE Contains a bitmask of flags defining the physical delivery mode (for example, special delivery) for a message designated for a specific recipient. PT_LONG 0x0C0B 0x0C0B0003
PR_PHYSICAL_DELIVERY_REPORT_REQUEST Contains the mode of a report to be delivered to a particular message recipient upon completion of physical message delivery or delivery by the message handling system. PT_LONG 0x0C0C 0x0C0C0003
PR_PHYSICAL_FORWARDING_ADDRESS Contains the physical forwarding address of a message recipient and is used only with message reports. PT_BINARY 0x0C0D 0x0C0D0102
PR_PHYSICAL_FORWARDING_ADDRESS_REQUESTED Contains TRUE if a message sender requests the message transfer agent to attach a physical forwarding address for a message recipient. PT_BOOLEAN 0x0C0E 0x0C0E000B
PR_PHYSICAL_FORWARDING_PROHIBITED Contains TRUE if a message sender prohibits physical message forwarding for a specific recipient. PT_BOOLEAN 0x0C0F 0x0C0F000B
PR_PHYSICAL_RENDITION_ATTRIBUTES Contains an ASN.1 object identifier used for rendering message attachments. PT_BINARY 0x0C10 0x0C100102
PR_PROOF_OF_DELIVERY Contains an ASN.1 proof of delivery value. PT_BINARY 0x0C11 0x0C110102
PR_PROOF_OF_DELIVERY_REQUESTED Contains TRUE if a message sender requests proof of delivery for a particular recipient. PT_BOOLEAN 0x0C12 0x0C12000B
PR_RECIPIENT_CERTIFICATE Contains a message recipient's ASN.1 certificate for use in a report. PT_BINARY 0x0C13 0x0C130102
PR_RECIPIENT_NUMBER_FOR_ADVICE Contains a message recipient's voice telephone number to call to advise of the physical delivery of a message. PT_TSTRING 0x0C14 0x0C14001F
PR_RECIPIENT_NUMBER_FOR_ADVICE_W Contains a message recipient's voice telephone number to call to advise of the physical delivery of a message. UNICODE compilation. PT_UNICODE 0x0C14 0x0C14001F
PR_RECIPIENT_NUMBER_FOR_ADVICE_A Contains a message recipient's voice telephone number to call to advise of the physical delivery of a message. Non-UNICODE compilation. PT_STRING8 0x0C14 0x0C14001E
PR_RECIPIENT_TYPE Contains the recipient type for a message recipient. PT_LONG 0x0C15 0x0C150003
PR_REGISTERED_MAIL_TYPE Contains the type of registration used for physical delivery of a message. PT_LONG 0x0C16 0x0C160003
PR_REPLY_REQUESTED Contains TRUE if a message sender requests a reply from a recipient. PT_BOOLEAN 0x0C17 0x0C17000B
PR_REQUESTED_DELIVERY_METHOD Contains a binary array of delivery methods (service providers), in order of a message sender's preference. PT_LONG 0x0C18 0x0C180003
PR_SENDER_ENTRYID Contains the message sender's entry identifier. PT_BINARY 0x0C19 0x0C190102
PR_SENDER_NAME Contains the message sender's display name. PT_TSTRING 0x0C1A 0x0C1A001F
PR_SENDER_NAME_W Contains the message sender's display name. UNICODE compilation. PT_UNICODE 0x0C1A 0x0C1A001F
PR_SENDER_NAME_A Contains the message sender's display name. Non-UNICODE compilation. PT_STRING8 0x0C1A 0x0C1A001E
PR_SUPPLEMENTARY_INFO Contains additional information for use in a report. PT_TSTRING 0x0C1B 0x0C1B001F
PR_SUPPLEMENTARY_INFO_W Contains additional information for use in a report. UNICODE compilation. PT_UNICODE 0x0C1B 0x0C1B001F
PR_SUPPLEMENTARY_INFO_A Contains additional information for use in a report. Non-UNICODE compilation. PT_STRING8 0x0C1B 0x0C1B001E
PR_TYPE_OF_MTS_USER Contains the type of a message recipient, for use in a report. PT_LONG 0x0C1C 0x0C1C0003
PR_SENDER_SEARCH_KEY Contains the message sender's search key. PT_BINARY 0x0C1D 0x0C1D0102
PR_SENDER_ADDRTYPE Contains the message sender's e-mail address type. PT_TSTRING 0x0C1E 0x0C1E001F
PR_SENDER_ADDRTYPE_W Contains the message sender's e-mail address type. UNICODE compilation. PT_UNICODE 0x0C1E 0x0C1E001F
PR_SENDER_ADDRTYPE_A Contains the message sender's e-mail address type. Non-UNICODE compilation. PT_STRING8 0x0C1E 0x0C1E001E
PR_SENDER_EMAIL_ADDRESS Contains the message sender's e-mail address. PT_TSTRING 0x0C1F 0x0C1F001F
PR_SENDER_EMAIL_ADDRESS_W Contains the message sender's e-mail address. UNICODE compilation. PT_UNICODE 0x0C1F 0x0C1F001F
PR_SENDER_EMAIL_ADDRESS_A Contains the message sender's e-mail address. Non-UNICODE compilation. PT_STRING8 0x0C1F 0x0C1F001E
