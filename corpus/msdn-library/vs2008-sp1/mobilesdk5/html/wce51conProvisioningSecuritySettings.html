Provisioning Security Settings

Send Feedback on this topic to the authors

Windows Mobile-based devices are shipped with default security policy settings. You can query or modify these settings. To modify the default settings you create a custom security policy document. This is a provisioning XML file in which you define the new security policy settings for the device.

Requests to query or change device settings are carried out by Configuration Service Providers. Each characteristic in a OMA Client Provisioning XML document is associated with a Configuration Service Provider. Similarly there is a configuration Service Provider associated with each OMA DM object. The following list shows the security related Configuration Service Providers.

  • Security Policy - SecurityPolicy Configuration Service Provider (OMA Client Provisioning and OMA DM)
  • Certificate Store - CertificateStore Configuration Service Provider (OMA Client Provisioning and OMA DM)
  • Loader Revocation - LoaderRevocation Configuration Service Provider (OMA Client Provisioning and OMA DM)
