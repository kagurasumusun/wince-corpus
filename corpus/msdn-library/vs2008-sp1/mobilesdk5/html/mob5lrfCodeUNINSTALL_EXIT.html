codeUNINSTALL_EXIT

Send Feedback on this topic to the authors

The codeUNINSTALL_EXIT enumeration specifies the possible return values for the Uninstall_Exit function after the application is uninstalled.

Syntax

typedef enum {
  codeUNINSTALL_EXIT_DONE = 0 
} codeUNINSTALL_EXIT;

Enumerators

codeUNINSTALL_EXIT_DONE
Exit the uninstallation successfully.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: ce_setup.h
Library: None
