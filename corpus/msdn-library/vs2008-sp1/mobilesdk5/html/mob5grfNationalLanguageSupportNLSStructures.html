National Language Support (NLS) Structures

Send Feedback on this topic to the authors

The following table shows the NLS structures with a description of each.

Programming element Description
CPINFO This structure contains information about a code page.
CURRENCYFMT This structure contains information that defines the format of a currency string.
NUMBERFMT This structure contains information that defines the format of a number string.
