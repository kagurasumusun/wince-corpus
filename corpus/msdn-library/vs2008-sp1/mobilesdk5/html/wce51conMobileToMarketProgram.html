Mobile2Market Program

Send Feedback on this topic to the authors

Mobile2Market is the Microsoft certification and marketing program for mobile applications for independent software and hardware vendors. You can certify your applications through the Designed for Windows Mobile-based Smartphone and Pocket PC logo programs. For code signing, Mobile2Market partners provide certificate authority and digital signature services for Windows Mobile-based Pocket PCs and Smartphones. In addition, once certified you can market your applications to mobile operators worldwide by submitting them to Mobile2Market's Mobile Application catalog.

For more information about the Mobile2Market Program see this Microsoft Web site.
