WDP over SMS

Send Feedback on this topic to the authors

This code sample is named WDP_SMS. It demonstrates how to send and receive data using the Wireless Datagram Protocol (WDP), over the Short Messaging Service (SMS) transport. Data is sent from one port on the mobile device, back to another port on the same device.

Feature Area

  • CellCore

Relevant APIs

  • Short Message Service (SMS) API
  • WapOpen function
  • WapSend function
  • WapRead function
  • WapClose function

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution files are copied to the following folders:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Cellcore\Wdp_sms\WDP_SMS.sln

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Smartphone SDK\Samples\CPP\Win32\Cellcore\Wdp_sms\WDP_SMS.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

Remarks

This code sample application has no user interface. All output goes to the Output window in Visual Studio.

For more information on the Wireless Datagram Protocol. see the Open Mobile Alliance.

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
