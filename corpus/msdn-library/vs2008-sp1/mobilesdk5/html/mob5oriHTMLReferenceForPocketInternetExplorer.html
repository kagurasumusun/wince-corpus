HTML Reference for Internet Explorer Mobile

Send Feedback on this topic to the authors

This reference section describes the HTML collections, elements, and objects that can be used in Web pages that are displayed on Windows Mobile-based devices. If you want your Web site to be usable for a Windows Mobile-based device, you must limit your HTML to the subset available for Internet Explorer Mobile, described in the following sections.

HTML Reference section Description
Internet Explorer Mobile HTML Collections Specifies the HTML object collections that are supported for Windows Mobile-based devices.
Internet Explorer Mobile HTML Elements Specifies the HTML elements that are supported for Windows Mobile-based devices.
Internet Explorer Mobile HTML Objects For scripting Web page behavior in Internet Explorer Mobile.
