Imaging Interfaces

Send Feedback on this topic to the authors

The following list shows the interfaces in the Imaging API.

Interface PPC SP Description
IBasicBitmapOps X X Performs basic operations on bitmap images.
IBitmapImage X X Allows applications to access pixel data of a bitmap image object.
IImage X X The basic interface to an image object.
IImageDecoder X X A low-level interface to an image decoder object.
IImageEncoder X X Used for encoding images.
IImageSink X X Allows an image source, such as an image decoder, and an image sink to exchange data.
IImagingFactory X X Used to create bitmaps and images and to manage image encoders and decoders.
