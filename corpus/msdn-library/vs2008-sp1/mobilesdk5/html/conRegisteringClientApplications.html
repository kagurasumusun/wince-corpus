Registering Push Client Applications

Send Feedback on this topic to the authors

Push Client applications must be registered in the Push Router's registration table, so that specific incoming push messages can be processed correctly. The registration table lists the following for Push Router client applications:

  • The client applications
  • Instructions for the client applications
  • Paths to their respective executable files

The table also lists header format information, including a Content-Type header for compressed or uncompressed message types, and an Application Identifier (AppID) header for uniquely identifying client applications. Header information is located in the header section of an incoming message.
