APPLICATION Characteristic Features

Send Feedback on this topic to the authors

The APPID parameter for Application characteristic elements is used in the provisioning XML file to indicate the type of application service available as described in "Parameters for APPLICATION characteristics" in the OMA Provisioning Content specification version 1.1 (OMA-WAP-ProvCont-v1_1-20021112-C).

OMA considers each transport to be an application and requires a corresponding APPLICATION Configuration Service Provider. The following table shows the supported transports and related characteristic features topics.

Transport Topic
110, for POP3 110 APPLICATION Characteristic Features
143 for IMAP 143 APPLICATION Characteristic Features
25, for SMTP 25 APPLICATION Characteristic Features
w2, for adding a new favorite. w2 APPLICATION Characteristic Features
w7, for bootstrapping a device with an OMA DM account. w7 APPLICATION Characteristic Features
