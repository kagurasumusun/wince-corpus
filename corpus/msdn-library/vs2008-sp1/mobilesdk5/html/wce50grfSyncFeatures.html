ActiveSync Product Reference Guide

The following table shows improvements to Microsoft ActiveSync.

Item Description
ActiveSync setup experience (PPC+SP) More reliable install, upgrade, and uninstall experiences. IT managers can deploy desktop ActiveSync as they do all other MSI applications.
Synchronization to multiple data sources and cross-pollination of data (PPC+SP) Users can synchronize Contacts, Calendar, and Tasks with multiple data sources, replicating data among those sources.
Enhanced Server ActiveSync Stability and Server Sync Logging (PPC+SP) Increase the reliability of Server ActiveSync and provide intelligent retry logic depending on what sort of issues are preventing a successful synchronization, for example, low wireless network coverage versus intermittent coverage.
Improved bandwidth when using Server ActiveSync (PPC+SP) Compress the data being sent from Server ActiveSync to device.
ActiveSync over Bluetooth (PPC+SP) When the mobile device and PC are bonded, the PC is on, and the device comes into range of the PC, the user can initiate ActiveSync from the device UI.
Server ActiveSync tasks (PPC+SP) With Exchange 2003 SP2, users can synchronize Tasks with Server ActiveSync.
Removed offline favorites sync from ActiveSync 4.0 (PPC+SP) A user will no longer be able to synchronize Offline favorites content from a PC to his device.
Remote API (PPC+SP) Improved flexibility, security, and design for developers using Remote API.
Synchronized pictures in Contacts (PPC+SP) Synchronize pictures in Contacts in Outlook 2003 between device and desktop ActiveSync 4.0, or between device and server (Exchange 2003 SP2).
New device ActiveSync UI (PPC+SP) New UI provides friendlier and more useful status and error reporting.
More secure ActiveSync (PPC+SP) ActiveSync will be more secure, on both communications and applications levels. Improved security includes using Windows-approved HTTP Listener, encryption and authentication for RAPI communications, and security review of the code.
Desktop sync for Calendar, Contacts, Inbox and Tasks migrated to AirSync. (PPC+SP) Calendar, Contacts, Inbox and Tasks desktop synchronization is more reliable because of reduced data duplicates and data loss.
Synchronization to desktops with and without proxy settings (PPC+SP) User can synchronize with a desktop that is configured with proxy settings, and then synchronize easily with home PC.
Improved ActiveSync device UI experience (PPC+SP) User will no longer have frustration of multiple dialogs in ActiveSync opening at the same time.
New ActiveSync desktop UI (PPC+SP) ActiveSync now has an attractive new desktop UI.
New contact properties added to Pocket Contacts (PPC+SP) Added new properties to Contacts (SMS, MMS, GUID). The properties are phone-specific and can be synchronized with the desktop or server under custom properties. Available with Desktop ActiveSync 4.0 and Exchange 2003 SP2.
Exposed two developer APIs: IsCradling (via Statutory) and a COM interface for start and stop (PPC+SP) Providing support so that third-party device applications can start synchronization, stop synchronization, and detect if the device is cradled.
Support for new device unified installer and new .cab file format. ActiveSync 4.0 works with the Application Manager to transfer .cab files to the device and launch the CAB installer to install applications on the device.
Removing remote desktop sync from ActiveSync 4.0 (PPC+SP) A LAN or Wi-Fi user will no longer be able to synchronize PIM or e-mail from a PC on the network.
New Media Sync support and integration with Windows Media Player 10 (PPC+SP) Users can click a Media checkbox SSP that will walk them through setting up automatic synchronization with a storage card. On subsequent synchronizations, ActiveSync will fire WMP 10 sync.
RAPI Restricted mode (PPC Only) Original equipment manufacturers or operators who want to create application-locked devices can help protect the security by enabling RAPI Restricted mode.
