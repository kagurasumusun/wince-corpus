GAPI Structures

Send Feedback on this topic to the authors

This section provides detailed information about the Windows Mobile-based Game API (GAPI) structures described in the following table.

Note   GAPI is deprecated. Use DirectDraw and Direct3D Mobile APIs instead.

Structure Description
GXDisplayProperties Provides information about the video frame buffer (VFB) memory.
GXKeyList Provides information about the default hardware button assignments.
