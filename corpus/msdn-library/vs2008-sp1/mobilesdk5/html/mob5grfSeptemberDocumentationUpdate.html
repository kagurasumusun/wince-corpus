Windows Mobile Version 5.0 SDK  

September Documentation Update

Send Feedback on this topic to the authors

The following table shows the new topics in the September documentation release for the Windows Mobile Version 5.0 Software Development Kit (SDK). Please provide feedback by using the Send Feedback link included in the topics.

Topic Description
Configuration Service Providers
  • APPLICATION Configuration Service Provider (updated)
    • Added the new example, Create a POP3 Account with SMTP Example. (new)
    • APPLICATION E-Mail Configuration Service Provider for POP3 Example was renamed from "WAP Application E-Mail CPS XML" and relocated under the correct Configuration Service Provider.
  • CertificateStore Configuration Service Provider (updated) -- Added Remarks section that explains how security roles are used with certificates.
  • DevDetail Configuration Service Provider (updated) -- Corrected the node to DevDetail/DevTyp
  • DevInfo Configuration Service Provider (updated) -- Updated child nodes to the format of chr.
  • EMAIL2 Configuration Service Provider (updated)
    • Updated artwork: added parameters to the TAGPROPS characteristic.
    • Enabling SSL Example (new)
    • Creating an IMAP4 Account Example for OMA Client Provisioning (new)
  • FileOperation Configuration Service Provider Example for OMA Client Provisioning (updated) -- Corrected erroneous code example.
  • NAP Configuration Service Provider (updated) -- Documented Microsoft extended properties.
  • Proxy Configuration Service Provider (updated) -- removed DestID parameter.
  • Registry Configuration Service Provider (updated):
    • Removed Default Metabase Settings for Registry Configuration Service Provider topic. The information that was in this topic is now presented in Metabase Settings for Registry Configuration Service Provider.
    • Corrected error in the example code: Adding a Key and Values, and Modifying a Value Example.
  • UnInstall Configuration Service Provider (updated)

    Updated to reflect that, over the OMA DM protocol, you can only query applications that are installed on the device; you cannot uninstall an application.

  • Updated all DDF files. For a link to all of the DDF Files, see Configuration Service Providers Managed over OMA DM.
Managing Devices Revoking Applications (updated) -- Added information about the revoke.exe tool.
Mobile Device Services (MDS) (Removed) Removed MDS documentation and references. MDS was the content and application management and distribution system hosted by Microsoft. This is not currently supported.
Provisioning for Windows Mobile-Based Devices Added the following new topics:
  • Provisioning XML Considerations (new) -- discusses considerations when initially configuring a device for each type of deployment scenario. It also includes the following subtopics:
    • OTA Provisioning Considerations
    • MMS Provisioning Considerations
    • SI and SL Provisioning Considerations
  • Provisioning XML Considerations when Changing Security Settings (new) -- discusses considerations when you change security settings, including certificates and the level of access that you want to allow.
Security for Windows Mobile-based Devices Security Policy Settings (updated) -- added policies from the topic Security Policies.
Windows Mobile Tools RapiConfig Tool (updated) -- Added syntax and parameters to documentation.
Wireless Application Protocol (WAP) API WAP API Sample for Usage at the WTP Layer (new) -- Provides a code example that shows how to send a WTP invoke request and read a WTP invoke indication.
