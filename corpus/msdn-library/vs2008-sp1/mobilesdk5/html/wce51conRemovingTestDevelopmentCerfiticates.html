Windows Mobile Version 5.0 SDK  

Removing Test and Development Certificates

Send Feedback on this topic to the authors

You must not ship a Windows Mobile–based device to an end user with a test certificate in any certificate store. Use the IMGTESTCERTS build flag to ensure that the test certificates included by Microsoft are not included in the ROM image.

If you include other test certificates in the Windows Mobile–based device during development or test, you must also remove these certificates from the Windows Mobile–based device before shipping.
