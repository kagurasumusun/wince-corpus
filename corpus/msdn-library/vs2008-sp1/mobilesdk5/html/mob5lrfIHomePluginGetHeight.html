IHomePlugin::GetHeight

Send Feedback on this topic to the authors

The GetHeight method gets the height of the plug-in.

Syntax

HRESULT GetHeight (
  int * pdyPlugin
);

Parameters

pdyPlugin
[out] Size, in pixels, of the plug-in height.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
Indicates success.

Remarks

For the device to redraw the plug-in, the plug-in must call the IHomePluginEnvironment::InvalidatePlugin method after changing the plug-in height.

Requirements

Pocket PC: None
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: Declared in home.h
