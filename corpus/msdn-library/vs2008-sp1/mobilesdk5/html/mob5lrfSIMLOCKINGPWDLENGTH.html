SIMLOCKINGPWDLENGTH

Send Feedback on this topic to the authors

The SIMLOCKINGPWDLENGTH structure determines the minimum password length for the SIM. This structure is part of the SIM Manager API set that enables access to information stored on the SIM card.

typedef struct simlockingpwdlength {
   DWORD dwFacility;
   DWORD dwPasswordLength;
} SIMLOCKINGPWDLENGTH, FAR *LPSIMLOCKINGPWDLENGTH;

Members

dwFacility
The locking facility.
dwPasswordLength
The minimum password length.

Requirements

Smartphone Platforms: Smartphone 2002 and later
Pocket PC Platforms: Pocket PC 2002 and later
OS Versions: Windows CE 3.0 and later
Header: simmgr.h
Library: cellcore.lib
