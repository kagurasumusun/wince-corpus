IRecurrencePattern::put_DayOfMonth

Send Feedback on this topic to the authors

The DayOfMonth property gets or sets a recurrence pattern expressed as a day of the month.

To set the value of the DayOfMonth property, call the property method described here.

To get the value of the DayOfMonth property, see the IRecurrencePattern::get_DayOfMonth property method.

Syntax

HRESULT put_DayOfMonth(
  long lDay
);

Parameters

lDay
[in] An integer value indicating the day of the month when the recurrence pattern occurs (a value between 1 and 31, inclusive).

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Remarks

You must set the RecurrenceType property before setting this property.

If lDay references a value greater than the actual number of days in a particular month, you should interpret the recurrence as occurring on the last day of the month.

Valid for OlRecurrenceType enumeration recurrence types olRecursMonthly, and olRecursYearly.

Requirements

Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
