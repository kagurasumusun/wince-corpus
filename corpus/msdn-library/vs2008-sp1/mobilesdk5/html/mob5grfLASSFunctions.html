LASS Functions

Send Feedback on this topic to the authors

The following table shows the LASS functions with a description of the purpose of each.

Programming element PPC SP Description
CreateEnrollmentConfigDialog X X This function displays the LAP enrollment dialog.
LASSClose X X This function closes a LASSHandle object.
LASSGetResult X X This function returns the results of a VerifyUserAsync call.
LASSGetValue X X This function provides a method to query the LASS for values.
LASSReloadConfig X X This function causes the LASS to reload its configuration settings.
VerifyUser X X This function authenticates the user.
VerifyUserAsync X X This function starts a VerifyUser request. This function is equivalent to a synchronous VerifyUser call except it does not block, and results will be made available when the LASSHandle becomes signaled.
