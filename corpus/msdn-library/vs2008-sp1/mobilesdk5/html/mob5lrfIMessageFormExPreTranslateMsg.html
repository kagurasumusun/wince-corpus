IMessageFormEx::PreTranslateMsg

Send Feedback on this topic to the authors

The PreTranslateMsg method enables the message form to pre-translate any messages received by the message pump in Messaging.

Note   The messages that PreTranslateMsg operates on are not MAPI messages but are the internal messages that Windows sends to processes.

Syntax

HRESULT PreTranslateMsg (
  MSG * pmsg,
  BOOL * pfProcessed
);

Parameters

pmsg
[in] The message for the form to pre-translate.
pfProcessed
[out] Set to TRUE if the message was pre-translated.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
Indicates success.

Requirements

Pocket PC: Windows Mobile 2003 and later
Smartphone: Windows Mobile 2003 and later
OS Versions: Windows CE .NET 4.2 and later
Header: cemapi.h
Library: cemapi.lib
