Imaging Types

Send Feedback on this topic to the authors

The following data types are introduced by the Imaging API.

Type PPC SP Description
ARGB X X Used to describe the color of a pixel that has alpha, red, green, and blue components.
PixelFormat X X Used to define pixel formats for images.
PixelFormatID X X Equivalent to PixelFormat.
