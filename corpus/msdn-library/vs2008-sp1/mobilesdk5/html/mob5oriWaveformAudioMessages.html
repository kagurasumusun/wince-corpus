Waveform Audio Messages

Send Feedback on this topic to the authors

The following messages are used by the wave API.

Programming element PPC SP Description
MIDI_MESSAGE_UPDATETEMPO X X Sent to the driver to set a new tempo for MIDI playback.
MIDI_MESSAGE_FREQGENON X X Commands the driver to begin generating a MIDI note at a specified frequency.
MIDI_MESSAGE_FREQGENOFF X X Commands the driver to stop generating a MIDI note at a specified frequency.
MM_WIM_CLOSE X X This message is sent to a window when a waveform-audio input device is closed.
MM_WIM_DATA X X This message is sent to a window when waveform-audio data is present in the input buffer and the buffer is being returned to the application.
MM_WIM_OPEN X X This message is sent to a window when a waveform-audio input device is opened.
MM_WOM_ATTENUATED X X This message indicates that an audio stream is controlled by an audio gain class.
MM_WOM_CLOSE X X This message is sent to a window when a waveform-audio output device is closed.
MM_WOM_DONE X X This message is sent to a window when the given output buffer is being returned to the application.
MM_WOM_FORCESPEAKER X X This message is used to make sure that an audio stream is routed to the external speaker on a Windows Mobile-based device.
MM_WOM_OPEN X X This message is sent to a window when the given waveform-audio output device is opened.
MM_WOM_SETSECONDARYGAINCLASS X X This message associates a stream context with an attenuation class.
MM_WOM_SETSECONDARYGAINLIMIT X X This message places a limit on the maximum volume for all streams associated with an attenuation class and scales the streams' volumes accordingly.
WIM_CLOSE X X This message is sent to the given waveInProc callback function when a waveform-audio input device is closed.
WIM_DATA X X This message is sent to the given waveInProc callback function when waveform-audio data is present in the input buffer and the buffer is being returned to the application.
WIM_OPEN X X This message is sent to a waveInProc callback function when a waveform-audio input device is opened.
WOM_CLOSE X X This message is sent to a waveOutProc callback function when a waveform-audio output device is closed.
WOM_DONE X X This message is sent to a waveOutProc callback function when the given output buffer is being returned to the application.
WOM_OPEN X X This message is sent to a waveOutProc callback function when a waveform-audio output device is opened.
