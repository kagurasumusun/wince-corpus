Windows Mobile Version 5.0 SDK  

July Documentation Update

Send Feedback on this topic to the authors

The following table shows the new topics in the July documentation release for the Windows Mobile Version 5.0 Software Development Kit (SDK). Please provide feedback by using the Send Feedback link included in the topics.

Topic Description
Best Practices for Developing Windows Mobile Applications
  • Best Practices for Managing Performance in a Windows Mobile Application

    Provides best practices for managing performance in a Windows Mobile application.

  • Best Practices for Managing Power in a Windows Mobile Application

    Provides best practices for managing power in a Windows Mobile application.

  • Best Practices for Managing Storage in a Windows Mobile Application

    Provides best practices for managing storage in a Windows Mobile application.

Bluetooth (New content)
  • Changing the Bluetooth Radio Mode

    Provides information and about changing the Bluetooth radio mode. This topic also includes sample code in C++, C#, and Visual Basic.NET.

  • Developing Managed Bluetooth Applications

    Provides information about the managed wrapper available in shared source.

  • Best Practices for Creating Bluetooth Applications

    The section provides general best practices for creating Bluetooth applications.

Code Samples Enhanced documentation for code samples included with the SDK in the following ways:
  • Added topics for new samples.
  • Added information denoting sample compatibility with Smartphone or Pocket PC.
  • Specified language and platform for each sample.
  • Expanded the used APIs noted for each sample.
Configuration Service Providers
  • E-Mail APPLICATION Configuration Service Provider (updated) -- Characterisitc and parms were updated.
  • SecurityPolicy DDF File (new) -- Added the SecurityPolicy DDF file topic.
  • UnInstall Configuration Service Provider (updated):
    • Added that this Configuration Service Provider can be managed over OMA DM.
    • LocURI is case sensitive in Uninstall Configuration Service Provider root.
    • Added the new topic UnInstall DDF File (new).
  • Updated DDF files for all Configuration Service Providers. For a link to all DDF files, see Configuration Service Providers Managed over OMA DM.
  • UnInstall Configuration Service Provider (updated) --
  • PXLOGICAL Configuration Service Provider (updated) -- PXLOGICAL Configuration Service Provider does not support IPv6.
Creating Windows Mobile Applications Added the following new topics:
  • Walkthrough: Create and Run a Simple Windows Application In Managed Code -new walkthrough to help users get started by creating a simple Windows in managed code.
  • Walkthrough: Create and Run a Simple Windows Application In Native Code.- new walkthrough to help users get started by creating a simple Windows in native code
  • Preparing a Device for Development - describes the ways to install SDK certificates to your device.
  • Deciding on the Type of Certificate to Sign an Application - describes the privileged and unprivileged SDK certificates.
  • Signing an Application During Day-to-Day Development - provides procedures for signing C, C++, C#, and Visual Basic .NET applications.
  • Signing a Cabinet File During Day-to-Day Development - provides a procedure for signing a cabinet file if you are not using Visual Studio 2005 Beta 2 to create your cabinet file.
  • Building and Testing Windows Mobile-based Pocket PC Help - provides procedures for creating Help content.
Deploying Windows Mobile Applications Added the following new topics:
  • Signing an Application or Cabinet File for Release to the Public - provides guidance for signing applications and cabinet files.
  • Testing How an Application Will Behave Under Different Security Configurations - provides information about security configurations and tools (SecurityViewer, Rapiconfig) for determining the security configuration of a device.
Fonts Application Development for Windows Mobile-based Devices New topics about using Fonts functionality in application development.
  • Using Fonts
  • Working with TrueType and Raster Fonts
  • Working with ClearType Fonts
  • Installing and Using Fonts
  • Enumerating Fonts
  • Formatting Text
  • Drawing Text
  • Drawing and Formatting Text
  • Enabling Font Linking
  • Creating End User Defined Characters
Functions for Pocket PC Phone Edition List of functions that are specific to the Windows Mobile-based Pocket PC Phone Edition and not in the Pocket PC Standard or Pocket PC Premium
Functions for Pocket PC Premium and Pocket PC Phone Edition List of functions that are specific to the Windows Mobile-based Pocket PC Premium and Phone Editions and not in Pocket PC Standard Edition
High DPI Display Added new topics in the following areas:
  • Developing DPI Aware Applications - Discusses issues and concerns in developing applications for high dpi screens.
  • Internet Explorer Mobile High DPI - Discusses issues and concerns in developing web pages for Internet Explorer Mobile.
International Application Development for Windows Mobile-based Devices New topics about designing an International Application.
  • Programming and Designing a Global Application
  • Programming with Unicode and NLSProvides guidelines on internationalizing software and shows how to create an international user interface.
  • Fonts
  • Software-based Input Panel Migration
Messaging Application Development for Windows Mobile-based Devices Added a host of new messaging conceptual topics.
  • APPLICATION Configuration Service Provider Classes - Contains UML class diagrams showing the class schema.
  • Customized Messaging Rules Clients - Contains an overview of the Messaging Rules Client mechanism.
  • Email2 Configuration Service Provider Mapping to OMA DM E-mail XML - Provides a mapping of OMA DM E-Mail XML to the existing EMAIL2 Configuration Service Provider.
  • How to Create a Messaging Application - Contains topics that present procedures with code examples that show you exactly how to use MAPI to create a messaging application.
  • Hyperlinking in Messages - Contains an overview of how the Messaging Application recognizes and acts on hyperlinks embedded in messages.
  • Message Stores - Describes what Message Stores are, how they work, and how to programmatically manipulate them.
  • Messaging Extensibility Settings - Contains an overview of how to setup and configure custom messaging account settings.
  • Messaging Forms - Contains an overview of how to change the behavior of the Messaging Application using customized read and compose forms.
  • Messaging Transports - Contains an overview of what messaging transports are, how to create them, and how to use them.
  • Messaging Sample Code - Contains a listing of the messaging code samples that ship with the Windows Mobile Version 5.0 Pocket PC and Smartphone SDKs.
  • Mobile Device Service Management with SI and SL - Contains an overview of Service Indication (SI) and Service Loading (SL) WAP Push features.
  • New Messaging APIs for Windows Mobile Version 5.0 - Lists the new Messaging APIs that ship with Windows Mobile Version 5.0.
  • POP3 and SMTP Transport Method - Contains an overview of how to change the transport method associated with all POP3 and SMTP accounts created using the Messaging Application's Inbox Account Wizard.
  • Transport Account Names - Describes the way Windows Mobile Version 5.0 names transport accounts.
Microsoft Standards for Provisioning Windows Mobile-Based Devices Added the APPLICATION Characteristic Features topics that list the Wireless Application Protocol provisioning standards that were used as guidelines for Windows Mobile Version 5.0 provisioning. The following new subtopics were added:
  • 110 APPLICATION Characteristic Features -- used for E-mail POP3 settings.
  • 143 APPLICATION Characteristic Features -- used for E-mail IMAP4 settings
  • 25 APPLICATION Characteristic Features -- used for E-mail SMTP settings.
  • w2 APPLICATION Characteristic Features -- used for adding a new browser favorite.
  • w7 APPLICATION Characteristic Features -- used for bootstrapping a device with an OMA DM account.
Migrating and Porting Applications The following topics have been completely revised:
  • Migrating Applications to Windows Mobile 5.0- An overview of Migrating applications to Windows Mobile 5.0.
  • Porting Applications between Windows Mobile-based Devices- An overview of porting an application from one Windows Mobile–based device.
QVGA Home Screen (SP Only) Provides details about the supported QVGA screen sizes.
Security for Windows Mobile-based Devices Added the following new topics:
  • Windows Mobile-based Device Security Model -- Describes the security model that is used in Windows Mobile-based devices.
  • XML Example for Security Policy -- Provides an Extensible Markup Language (XML) example that shows how to setup the security policy.
  • Customizing Security Settings -- Provides information about how to customize security settings, including How To Query Security Policies, Determining the Security Policies and Roles on a Device, and How To Change Security Policies.
Shell and User Interface
  • Added the following new topics:
  • Shell Application Development for Windows Mobile-based Devices
  • Shell Functions - new functions added - SHImeGetClearMessage, SHImeOnKeyPress, SHImeSetCustomInputIcons, SHImeSetModeIcon.
SKU Matrix for Windows Mobile Version 5.0 Matrix for list of supported features for the different SKUs.
Speaker-Dependent Speech Support New topics on speaker-dependent speech support for Smartphones and Pocket PCs
  • Speech Support Overview
  • Customizable Talk button
  • Best Practices for Enabling Voice Recognition
  • SAPI-Lite Implementation Considerations
  • SAPI-Lite Error Codes
Window and Control Styles Documents the supported window, message box, and control styles.
