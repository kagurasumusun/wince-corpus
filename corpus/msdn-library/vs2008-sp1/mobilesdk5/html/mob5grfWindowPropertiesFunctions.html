Window Properties Functions

Send Feedback on this topic to the authors

The following table shows the window properties functions with a description of the purpose of each.

Programming element PPC SP Description
EnumPropsEx X X This function enumerates all of the entries in the property list of a window by passing the entries, one by one, to a specified callback function.
GetProp X X This function retrieves a data handle identified by a specified character string from the property list of a specified window.
PropEnumProcEx X X This function receives property entries from the property list for a window.
RemoveProp X X This function removes an entry identified by a specified character string from the property list of a specified window.
SetProp X X This function adds a new entry or changes an existing entry in the property list of a specified window.
