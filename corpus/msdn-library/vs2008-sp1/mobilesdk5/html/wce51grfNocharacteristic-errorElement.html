nocharacteristic-error Element

Send Feedback on this topic to the authors

Indicates that an error occurred while a nocharacteristic element was processed. When an error occurs, the erroneous element is changed to a nocharacteristic-error element.

Attributes

type
Specifies the name of the nocharacteristic element that causes the error.
desc
Describes the error.
