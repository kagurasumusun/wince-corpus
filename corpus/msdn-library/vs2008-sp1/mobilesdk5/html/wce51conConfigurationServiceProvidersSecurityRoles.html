Configuration Service Providers and Security Roles

Send Feedback on this topic to the authors

The security roles that provide access to each Configuration Service Provider are listed in the default metabase settings list. The following table describes the possible security roles.

Security role Definition
Operator Setting can be changed by the mobile operator.
Operator-TPS Setting can be changed by a Wireless Application Protocol (WAP) Trusted Provisioning Server (TPS).
Manager Setting can be changed by the manager or administrator.
AuthenticatedUser Setting can be changed by an authenticated user.
UnauthenticatedUser Setting can be changed by anyone.

For informaton about the default role for each Configuration Service Provider, see Default Roles for Configuration Service Providers.

Note   Because OEMs and Mobile Operators can selectively disallow access to Configuration Service Providers, ask them about the availability. For more information about roles, see Security Roles and Default Roles for Configuration Service Providers.

For more detailed information about security roles, see Security Policies and Security Roles.
