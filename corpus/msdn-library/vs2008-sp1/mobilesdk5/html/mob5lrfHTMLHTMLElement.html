HTML HTML Element

The HTML element identifies the document as containing HTML elements. This element requires a closing tag.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
