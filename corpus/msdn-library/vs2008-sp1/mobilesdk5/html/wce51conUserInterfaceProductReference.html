Windows Mobile Version 5.0 SDK  

User Interface Product Reference Guide

Send Feedback on this topic to the authors

The following table shows improvements to the user interface.

Item Description
Extensible title bar icons (PPC+SP) Title bar icons are used to show critical information to users at all times, such as new messages, battery level, and signal strength. In the event that an operator requires an icon to represent, for example a network service or device state, the original equipment manufacturer will be able to add that icon to the system in an architected way and have it show up on the title bar in conjunction with priority logic for that spot in the user interface. This is how we have enabled manufacturers to add 3G icons for connectivity to 3G networks.
More icons on Phone/Today screen status bar (PPC Only) Per original manufacturer requests, we now show more status icons (for example, call forwarding, roaming, GPRS attached, line 1 or 2) on the Phone and Today screens of Pocket Pc.
Soft keys (PPC Only) There are two main scenarios where stylus input is not ideal. The first main scenario is "basic phone usage" such as dialing contacts and incoming phone calls. The second is "maintaining a keyboard posture" on keyboarded devices. In the second case, the keyboards are designed to be thumb driven, so Soft keys allows most device functionality to be accessed from the keyboard posture.
State and Notifications Broker (PPC+SP) Provides a unified system for storing device, application, and system-state information. This includes the capability to read system information, read and store the device's own status, and notification of status changes.
Improves Smartdial User Experience (SP Only) Before many new Smartphone customers figure out the Smartdial filtering method, they try to triple tap a contacts name. For example, to search for Bob, they type 2,2,6,6,6,2,2 instead of 2,6,2. As a result they see a confusing error message saying the contact couldn't be found. This work items would improve this scenario and give users better information to learn how Smartdial works.
Open appointment from reminder (PPC+SP) Windows Mobile-based Pocket PC reminders UI is completely updated to be better aligned with the device look and feel. The reminder now shows more information (incl. meeting location) and is hardware navigable. Few minor UI fixes made to Smartphone as well. When a reminder goes off, the user will be able to open the appointment directly from the reminder. One of the main scenarios for this is for looking up "location" when a reminder goes off. Currently, the reminder doesn't show the location (for security reasons), so it is very common to navigate to the appointment just after a reminder goes off. Currently, the reminder must be dismissed and then the user has to navigate to the Calendar using some other mechanism.
Full navigation from keyboard posture (PPC Only) The goal of this work is to ensure that the entire Windows Mobile-based Pocket PC user interface can be operated (navigation and input) from a keyboard posture without having to use a stylus. This work has been done in key places on Windows Mobile-based Pocket PC (such as Inbox, Contacts, and Calendar), but there are still many applications (like Internet Explorer Mobile) and many control panels (like in Settings) where navigation and input requires using the stylus. We are not doing anything specifically for Internet Explorer. Navigation to the title bar is available for notifications (via Soft keys) and Start menu via dedicated button on keyboarded devices.
Start menu grid view (SP Only) Users can access programs on the Windows Mobile-based Smartphone through a grid user interface. When moving focus from one icon to another, the icon gaining focus will be able to show a new icon and the icon losing focus will revert to its default icon. I
Title bar and soft keys visual refresh (PPC+SP) Users will see a softer, more friendly user interface that better aligns with Windows Mobile branding. Personalization will allow the color hue to change, but the not the Windows Mobile hue pattern.
"Hue shifting" color definition (PPC+SP) This work will change the underling architecture for how colors are defined allowing for more flexibility in color usage.
Segoe system font (SP Only) Change the Smartphone font to "Segoe" which is used in Windows. Smartphone will continue to use Segoe font for East Asia languages.
Startup and shutdown animation (SP Only) When turning a Windows Mobile-based Smartphone on or off, the user will now be able to see an animated operator and Microsoft graphic.
Improved low-memory algorithm (PPC Only) The algorithm that handles low memory condition will be optimized to account for newer memory boundaries and will modified to properly work on persistent store devices
File-based digital rights management for Pocket PC (PPC Only) Pocket PCs can use FDRM-protected images on the home screen and FDRM-protected sound files for all device sounds, such as ring tones for incoming phone calls.
Optimized SP Setting (SP Only) It is now easier to find commonly used settings, for example, access to the alarm clock, security, and connections settings. Less frequently used settings have been moved to the second screen.
Align screen unlock with Nokia standard (SP Only) Users will be able to unlock Smartphone by pressing the left soft key and then the "*" key, similar to the way Nokia phones unlock.
Fix Back navigation in Smartphone Start menu (SP Only) When users go into a folder on Smartphone and then press Back, they are returned up one level rather than back to the first page of Programs.
"More" on left soft key in Smartphone Start menu (SP Only) When in either list or grid view of the Start Menu, the option for "more" will be on the soft key.
Customizable Start menu watermarks (SP Only) Original equipment manufacturers or operators can now customize watermarks in the Windows Mobile-based Smartphone Start menu. Watermarks can be chosen for each subfolder. For example, the Games folder can have a different watermark from other folders, such as Accessories. Watermarks can also be customized as part of Themes.
Pinnable home screen plugins (PPC Only) Original equipment manufacturers are able to create one or two home screen plugins that will not scroll off the screen and cannot be removed by the user
