PhoneCloseCallLog

Send Feedback on this topic to the authors

This function closes the call log.

HRESULT PhoneCloseCallLog (
HANDLE h );

Parameters

h
Handle of the call log.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Remarks

PhoneCloseCallLog provides the functionality for the fourth and final step in the process of extracting information from a call log. After opening a call log and retrieving the necessary information, use PhoneSeekCallLog to close the call log.

Requirements

Smartphone: Windows Mobile 2002 and later
Pocket PC: Windows Mobile 2002 and later
OS Versions:
Header: phone.h
Library: phone.lib
