DLM_GETPREVWAVE

Send Feedback on this topic to the authors

The DLM_GETPREVWAVE message is sent by an application to retrieve the previous listed WAV file.

Syntax

DLM_GETPREVWAVE
  wParam = (WPARAM) res; 
  lParam = (LPARAM) (int *) pIndex;

Parameters

res
This parameter is reserved for future use; the value of this parameter must be set to 0.
pIndex
Reference to an integer; set to the index of the current WAV file or -1 to retrieve the first WAV file in the document list. The index of the previous WAV file is returned through this pointer.

Return Values

Returns TRUE if there is another WAV file to get.

Requirements

Pocket PC: Pocket PC 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: doclist.h.
Library: doclist.lib.
