Windows Mobile Version 5.0 SDK  

Miscellaneous Functionality Added to Windows Mobile Version 5.0

Send Feedback on this topic to the authors

The following table shows functionality added to Windows Mobile 5.0.

Item Description
Improved AT Command Interface (PPC+SP) The AT Command Interface has been brought from the Windows Mobile-based Smartphone to the Pocket PC to allow use of the device as a "modem" to a laptop. Microsoft has also improved the stability of the code based on feedback and will publish it in a form that original equipment manufacturers can modify as needed for additional enhancements.
GPS Intermediate Driver with API (PPC Only) User is able to use the data fed into a Windows Mobile-based device from the GPS module, either a built-in module or an accessory from a third party, within several different applications on the device.
Using OMA DM protocol to initiate firmware update (PPC+SP) A critical security patch need to deliver to the device to fix a serious security problem in OS/The radio need to be patched/A driver needs to be updated. Operator sends a SMS message to the device to initiate a DM session over operator DM server. The device DM client responds to the server. The server delivers the patch download link to the device. The device downloads the patch and installs it.
Configure proxy and network access point over OMA DM protocol (PPC+SP) The mobile operator wants to add a new WAP gateway and a new GPRS access point to the device. The operator sends a SMS message to the device to initiate a DM session over operator DM server. The device DM client responds to the server. The server configures the device, the new gateway, and GPRS access point. The device notifies the server of configuration success
.NET Compact Framework v2 (PPC+SP) .NET Compact Framework is a lightweight version of the .NET Framework on the desktop that Microsoft is driving developers toward. Version 2 of the Compact Framework includes more granular security and more extensive integration with native APIs.
ARM emulator support (PPC+SP) The Microsoft development tools now include an ARM emulator.
