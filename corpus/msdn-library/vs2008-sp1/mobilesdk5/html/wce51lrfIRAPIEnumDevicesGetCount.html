IRAPIEnumDevices::GetCount

Send Feedback on this topic to the authors

This method returns the number of remote devices in the enumerator.

HRESULT GetCount(
  ULONG* pcElt
);

Parameters

pcElt
[out] The number of devices in the enumerator.

Return Values

If the operation was successful, the return value is NOERROR.

Remarks

In Windows CE 5.01 and earlier, the count of devices in the enumerator will be either 1 or 0.

Requirements

OS Versions: Windows CE 5.01 and later.
Header: Rapi2.h.
Link Library: Ole32.lib, Rapiuuid.lib.
