DeviceInformation Configuration Service Provider Examples for OMA Client Provisioning

Send Feedback on this topic to the authors

The following examples shows how to use the DeviceInformation Configuration Service Provider for OMA Client Provisioning:

  • Changing the Backlight Timeout while on AC Power for OMA Client Provisioning
  • Changing the Backlight Timeout while on Battery Power for OMA Client Provisioning
  • Querying Values Changed by the DeviceInformation Configuration Service Provider for OMA Client Provisioning

These examples can be used as a template to configure settings for the DeviceInformation Configuration Service Provider. To use this example, you must replace the values as appropriate
