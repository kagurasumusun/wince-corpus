Configuring the Connection Manager using OMA DM-based Connectivity Objects

Send Feedback on this topic to the authors

Windows Mobile supports Open Mobile Alliance Device Management (OMA DM) connectivity objects. OMA DM connectivity objects provide a standard mechanism to provision connectivity settings for Windows Mobile-based devices. The OMA DM connectivity objects provide an easy-to-use and scalable XML definition to add new types of network settings. OMA DM also enables some additional operator requirements that are not supported by the WAP standard, such as mapping specific applications or port numbers to specific network connectivity objects. OMA DM connectivity objects provide the following backward compatibility with the existing Connection Manager XML provisioning standard:

  • WAP (XML) for bootstrapping (device startup)
  • Connectivity objects for over-the-air provisioning, for example if the name of an APN changes
