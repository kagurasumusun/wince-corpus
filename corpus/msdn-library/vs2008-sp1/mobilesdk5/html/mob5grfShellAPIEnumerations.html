Shell Enumerations

Send Feedback on this topic to the authors

The following table shows the Shell enumerations for Smartphones with a description of the purpose of each. For the list of structures for Pocket PCs, see the table below.

Programming element Description
CAMERACAPTURE_MODE Used in the SHCAMERACAPTURE structure to specify the camera mode used to initialize the SHCameraCapture function.
CAMERACAPTURE_STILLQUALITY Used in the SHCAMERACAPTURE structure, by the SHCameraCapture function, to specify the compression level used for still image capture.
CAMERACAPTURE_VIDEOTYPES Used in the SHCAMERACAPTURE structure, by the SHCameraCapture function, to specify the video quality profile to use for video capture.
SHIC_FEATURE Used by the SHSetInputContext function to specify the type of context feature to change in the specified input window.
SHIME_MODE Specifies the modes for a status icon in the Input Method Editor (IME).
SHNP Contains notification priority data and belongs to the Shell API Notifications system.
SHUIMETRIC Used by the SHGetUIMetrics function to specify the unit of measure for the system font size.
SIPSTATE Enumerates input panel states.
SND_EVENT Indicates the sound event type to set or query.
SND_SOUNDTYPE Indicates the type of sound for the SNDFILEINFO structure.
