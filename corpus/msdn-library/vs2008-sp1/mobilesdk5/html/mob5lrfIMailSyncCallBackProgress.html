IMailSyncCallBack::Progress

Send Feedback on this topic to the authors

The Progress method notifies Messaging of the progress of a synchronization that is in session, which Messaging then reports to the user.

Syntax

HRESULT Progress (
  LPCWSTR pszProfile,
  SYNCPROGRESSITEM * pinfo
);

Parameters

pszProfile
[in] The profile string that is passed into the transport when the transport is initialized.
pinfo
[in] A SYNCPROGRESSITEM structure that describes the progress.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
Indicates success.

Remarks

To give the user up-to-date progress status, the transport should call Progress regularly during a synchronization.

Requirements

Pocket PC: Pocket PC 2002 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: cemapi.h
Library: cemapi.lib
