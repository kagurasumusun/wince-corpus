Imaging Enumerations

Send Feedback on this topic to the authors

The following list shows the enumerations used with the Imaging API.

Enumeration PPC SP Description
BufferDisposalFlag X X Provides values that are used to describe how a memory buffer should be released when a task is completed.
DecoderInitFlag X X Provides flags used to describe the properties of an image decoder.
EncoderValue X X Provides values that are used to describe the properties of an image encoder.
EncoderParameterValueType X X Provides values that are used to describe the properties of an image encoder.
ImageCodecFlags X X Provides information about image codecs.
ImageFlags X X Provides values that identify properties of images.
ImageLockMode X X Provides flags that describe image access modes for the IBitmapImage::LockBits method.
InterpolationHint X X Provides values that identify algorithms used to interpolate pixel values during resizing and rotation operations.
SinkFlags X X Describes the properties of an image source.
