Independent Software Vendors (ISVs), Original Equipment Manufacturers (OEMs), and Mobile Operators (MOs), can refer to the technical specifications contained in this section when coding Windows Mobile applications. This Developer's Reference contains both Native and Managed language reference material that details the Application Programming Interfaces (APIs) that publicly expose the Windows Mobile feature set. In addition, this section also contains procedures, "How To's," and code examples that demonstrate how to make practical use of the APIs.

Contains technical reference details on the Windows Mobile native APIs.
