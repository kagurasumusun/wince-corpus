IInternetPriority::SetPriority

Send Feedback on this topic to the authors

Sets the priority of the request being sent to the pluggable protocol handler.

Syntax

HRESULT SetPriority(
  LONG nPriority
);

Parameters

nPriority
[in] Long integer value that contains the current thread priority.

Return Values

Returns S_OK if successful, or an error value otherwise.

Remarks

For the default protocol handlers, IInternetPriority::SetPriority maps to the Microsoft® Win32® Internet function InternetSetOption, using the INTERNET_OPTION_REQUEST_PRIORITY option flag. IInternetPriority::SetPriority must be called before the initial call to IInternetProtocolRoot::Start is made. All IInternetPriority::SetPriority calls made after IInternetProtocolRoot::Start has been called are ignored.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: urlmon.h
Library: urlmon.lib
