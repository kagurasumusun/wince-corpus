DocList_GetSelectedPathname

Send Feedback on this topic to the authors

The DocList_GetSelectedPathname macro retrieves the path name associated with the selected item.

DocList_GetSelectedPathname (HWND hwnd, LPTSTR szPath, int size)

Parameters

hwnd
Handle to the document list view window.
szPath
Output buffer filled with the path name of the selected item.
size
Input size of szPath buffer.

Return Values

Returns TRUE if the szPath information is provided successfully.

Requirements

Pocket PC: Pocket PC 2002 and later.
OS Versions: Windows CE 3.0 and later.
Header: doclist.h.
Library: doclist.lib.
