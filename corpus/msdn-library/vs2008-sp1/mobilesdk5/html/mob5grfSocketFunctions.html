Socket Functions

Send Feedback on this topic to the authors

The following table lists the socket functions.

Programming element PPC SP Description
accept (Windows Sockets) X X This function permits an incoming connection attempt on a socket.
bind (Windows Sockets) X X This function associates a local address with a socket.
closesocket X X This function closes an existing socket.
connect (Windows Sockets) X X This function establishes a connection to a specified socket.
freeaddrinfo X X This function frees address information that the getaddrinfo function dynamically allocates in its addrinfo structures.
getaddrinfo X X This function provides protocol-independent translation from host name to address.
gethostbyaddr X X This function retrieves the host information corresponding to a network address.
Note   The gethostbyaddr function has been deprecated by the introduction of the getnameinfo function. Developers who create Windows Sockets 2 applications are urged to use the getnameinfo function instead of the gethostbyaddr function.
gethostbyname X X This function retrieves host information corresponding to a host name from a host database.
Note   The gethostbyname function has been deprecated by the introduction of the getaddrinfo function. Developers who create Windows Sockets 2 applications are urged to use the getaddrinfo function instead of gethostbyname.
gethostname X X This function returns the standard host name for the local machine.
getnameinfo X X This function provides name resolution from an address to the host name.
getpeername (Windows Sockets) X X This function retrieves the name of the peer to which a socket is connected.
getsockname (Windows Sockets) X X This function retrieves the local name for a socket.
getsockopt (Windows Sockets) X X This function retrieves a socket option.
htonl X X This function converts a u_long from host to TCP/IP network byte order, which is big-endian.
htons X X This function converts a u_short from host to TCP/IP network byte order, which is big-endian.
inet_addr X X This function converts a string containing an (Ipv4) Internet Protocol dotted address into a proper address for the in_addr structure.
inet_ntoa X X This function converts an (Ipv4) Internet network address into a string in Internet standard dotted format.
ioctlsocket X X This function controls the I/O mode of a socket.
listen X X This function places a socket at a state where it is listening for an incoming connection.
ntohl X X This function converts a u_long from TCP/IP network order to host byte order, which is little-endian on Intel processors.
ntohs X X This function converts a u_short from TCP/IP network byte order to host byte order, which is little-endian on Intel processors.
recv X X This function receives data from a connected socket.
recvfrom X X This function receives a datagram and stores the source address.
select X X This function determines the status of one or more sockets, waiting if necessary, to perform synchronous I/O.
send X X This function sends data on a connected socket.
sendto X X This function sends data to a specific destination.
sethostname X X This function is used to register the host name on a network with the Windows Internet Naming Service (WINS).
setsockopt (Windows Sockets) X X This function sets a socket option.
shutdown X X This function disables sends or receives on a socket.
socket (Windows Sockets) X X This function creates a socket that is bound to a specific service provider.
