SimReadPhonebookEntry

Send Feedback on this topic to the authors

The SimReadPhonebookEntry function reads a phone book entry from the SIM card. This function is part of the SIM Manager API set that enables access to information stored on the SIM card.

HRESULT SimReadPhonebookEntry (
   HSIM hSim,
   DWORD dwLocation,
   DWORD dwIndex,
   LPSIMPHONEBOOKENTRY lpPhonebookEntry
);

Parameters

hSim
Contains a valid HSIM handle.
dwLocation
A phone book storage location value; equal to one of the SIM_PBSTORAGE constant values.
Value Description
SIM_PBSTORAGE_EMERGENCY Emergency dial list.
SIM_PBSTORAGE_FIXEDDIALING SIM fixed dialing list.
SIM_PBSTORAGE_LASTDIALING SIM last dialing list.
SIM_PBSTORAGE_OWNNUMBERS SIM own numbers lists.
SIM_PBSTORAGE_SIM General SIM Storage.
SIM_NUMPBSTORAGES Number of phonebook storages.
dwIndex
Index of the entry to retrieve.
lpPhonebookEntry
A pointer to a phone book entry structure.

Return Values

HRESULTs are either S_OK for success, or one of the SIM_E error constants defined in the SIM Manager Error Constants table.

Requirements

Smartphone Platforms: Smartphone 2002 and later
Pocket PC Platforms: Pocket PC 2002 and later
OS Versions: Windows CE 3.0 and later
Header: simmgr.h
Library: cellcore.lib
