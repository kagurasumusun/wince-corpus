links HTML Collection

Send Feedback on this topic to the authors

The links collection contains a collection for all A and AREA elements that have an HREF attribute.

Property Data type Access Description
length Long Read-only The number of link objects in the collection.
item Object Read-only Returns a particular link object, given its name or index.
Note   Supported only for devices running Windows Mobile 2002 software or later.

Requirements

Pocket PC: Windows Mobile 2000 and later
Smartphone: Windows Mobile 2002 and later
OS Versions: Windows CE 3.0 and later
