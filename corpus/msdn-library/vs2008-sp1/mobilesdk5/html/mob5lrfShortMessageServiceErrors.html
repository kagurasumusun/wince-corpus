Short Message Service Errors

Send Feedback on this topic to the authors

The following errors are used with Short Message Service (SMS).

Error Description
SMS Specific Errors Errors specific to parts of SMS.
SMS General Errors Errors that are passed through when no more specific error value is applicable.
