Mapping OMA WAP XML to Email2 Configuration Service Provider (IMAP)

Send Feedback on this topic to the authors

Use POP3 mapping for IMAP values. The IMAP schema for OMA Configuration Service Provider XML is exactly the same as for POP3 except for the two Parm Names SERVICETYPE and INPORTNBR which contain different values in the IMAP schema.

The following table shows the mapping for SERVICETYPE and INPORTNBR.

Characteristic Parm name Values Description E-mail2 Configuration Service Provider
APPLICATION APPID 143 n/a SERVICETYPE
PORT PORTNBR 143, default.

993

or a non-standard port number

 Port number to connect to INPORTNBR

This is a new parm.
