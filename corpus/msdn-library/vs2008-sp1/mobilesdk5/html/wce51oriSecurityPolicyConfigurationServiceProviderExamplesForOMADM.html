SecurityPolicy Configuration Service Provider Examples for OMA DM

The following XML examples can be used as templates to configure settings for the SecurityPolicy Configuration Service Provider.

  • Querying a Security Policy Example for OMA DM
  • Setting a Security Policy Example for OMA DM

To use this example, you must replace the values as appropriate, and add the node as a child of the SyncBody node in an OMA DM provisioning file. For more information about the syntax of the provisioning file, see OMA DM Provisioning Files.
