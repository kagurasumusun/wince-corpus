PNRP API

Send Feedback on this topic to the authors

The Peer Name Resolution Protocol (PNRP) Namespace Provider (NSP) is a server-less DNS technology that allows nodes to discover each other. PNRP uses the Winsock 2 Namespace Provider API. This topic contains information about the PNRP programming elements.
