IWebBrowser2::Stop

Send Feedback on this topic to the authors

The Stop method cancels any pending navigation or download operation and stops any dynamic page elements.

HRESULT Stop(VOID);

Parameters

None

Return Value

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

DISPID

DISPID_WEBBROWSER_STOP

The DISPID is defined in piedocvw.h. Use this value to identify the event handler when implementing IDispatch::Invoke.

Remarks

When the Stop method is called, the DWebBrowserEvents2::DownloadComplete and DWebBrowserEvents2::DocumentComplete events fire.

Requirements

Pocket PC: Windows Mobile Version 5.0 and later
Smartphone: Windows Mobile Version 5.0 and later
OS Versions: Windows CE 5.01 and later
Header: piedocvw.h
Library: piedocvw.lib
