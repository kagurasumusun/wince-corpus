Internet Explorer Mobile Browser Enumerations

Send Feedback on this topic to the authors

The following table shows the Internet Explorer Mobile Browser enumerations.

Enumerations Description
CommandStateChangeConstants Contains values used by the DWebBrowserEvents2::CommandStateChange event.
READYSTATE Contains values that indicate what state an object is in. The values are used by the IWebBrowser2::get_ReadyState property.
SecureLockIconConstants Contains values used by the DWebBrowserEvents2::SetSecureLockIcon event.
