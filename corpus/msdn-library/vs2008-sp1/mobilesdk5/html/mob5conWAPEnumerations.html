WAP Enumerations

Send Feedback on this topic to the authors

The following enumerations are used with Wireless Application Protocol.

Enumeration Description
WAP_ADDRESS_TYPE This enumeration defines supported WAP address types.
WAP_LAYER This enumeration defines protocols for WAP layers.
WAP_PRIMITIVE_ID This enumeration identifies WAP service primitives, which represent services between WAP layers.
WAP_PRIMITIVE_TYPE This enumeration defines the types of service primitives.
WTP_TRANSACTION_CLASS_TYPE This enumeration defines transaction class types.
WTP_TRANSACTION_HANDLE Defines the transaction handle.
WTP_TRANSACTION_SECURITY_LEVEL This enumeration defines Wireless Transaction Protocol (WTP) secure transaction security levels.
