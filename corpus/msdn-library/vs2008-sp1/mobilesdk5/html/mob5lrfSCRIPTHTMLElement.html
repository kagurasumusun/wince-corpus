SCRIPT HTML Element

Send Feedback on this topic to the authors

The SCRIPT element specifies a block containing script to be interpreted by the script engine.

Attributes

Attribute Value Description
DEFER   Sets or retrieves the status of the script. If this attribute exists, the script isn't processed until the document is finished loading. If this attribute is missing, the script is processed immediately.
Note   Supported only for devices running Windows Mobile 2003 software or later.
EVENT Special Specifies the name of the event handler that the enclosed script is bound to.
Note   Supported only for devices running Windows Mobile 2002 software or later.
FOR Special Specifies the name of the object that the event script is bound to.
Note   Supported only for devices running Windows Mobile 2002 software or later.
LANGUAGE Special Specifies the script language. If the attribute or value is omitted, the default value is JScript. Equivalent values are: jscript, javascript, javascript1.1. If another value is specified, such as javascript1.2, vbs, or vbscript, the script is not parsed and does not execute.
SRC URL Specifies an external script code source.
Note   Supported only for devices running Windows Mobile 2002 software or later.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
