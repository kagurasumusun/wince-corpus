Telephony Service Provider (TSP) API

Send Feedback on this topic to the authors

The Telephony Service Provider API includes the following area of functionality:

  • Telephony Service Provider

    The prototypes that are defined in the Tsp.h file address the TAPI Service Provider (TSP), which is a large part of making telephony applications work. A Telephony Application Programming Interface (TAPI), TSP is a DLL that supports communications device control through a set of exported service functions. A TAPI application uses standardized commands, TAPI passes information to the telephony service provider, and the TSP handles the specific commands that must be exchanged with the device.

The following elements are associated with Telephony Service Provider feature area:

  • Telephony Service Provider Structures
  • Telephony Service Provider Enumerations
