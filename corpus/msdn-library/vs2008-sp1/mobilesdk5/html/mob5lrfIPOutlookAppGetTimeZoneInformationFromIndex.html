IPOutlookApp::GetTimeZoneInformationFromIndex

Send Feedback on this topic to the authors

The GetTimeZoneInformationFromIndex method uses a time zone index to get the TIME_ZONE_INFORMATION structure (declared in Winbase.h) for the corresponding time zone.

Syntax

HRESULT GetTimeZoneInformationFromIndex(
  int iIndex,
  TIME_ZONE_INFORMATION * ptz
);

Parameters

iIndex
[in] The index of the time zone you want to retrieve.
ptz
[out] Reference to a TIME_ZONE_INFORMATION structure to receive the indexed time zone parameters.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Remarks

This function can be called by C/C++ code to get information about a time zone. This structure cannot be used in Visual Basic because it is not supported by Automation. In Visual Basic, use GetTimeZoneFromIndex to get the ITimeZone object, which can provide all the information contained in a TIME_ZONE_INFORMATION structure.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
