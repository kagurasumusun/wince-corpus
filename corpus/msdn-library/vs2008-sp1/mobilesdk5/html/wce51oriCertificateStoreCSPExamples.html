CertificateStore Configuration Service Provider Examples for OMA Client Provisioning

Send Feedback on this topic to the authors

The following XML examples can be used as templates to configure settings for the CertificateStore Configuration Service Provider:

  • Adding Certificates to the Privileged, Unprivileged, and SPC Stores Example
  • Querying Certificate Stores Example
  • Querying the Certificate Stores Output Example
  • Querying Certificates Example
  • Querying Certificates Output Example
  • Parm Query for a Characteristic Example
  • Parm Query Output Example
  • Deleting a Certificate Example

In these examples, below the CertificateStore characteristic type, replace the values for each parm and characteristic type with values that correspond to your system.

Note   You cannot add only a role mask to the certificate store; you must also include a certificate.
