File Mapping Functions

Send Feedback on this topic to the authors

The following table shows the file mapping functions with a description of the purpose of each.

Programming element PPC SP Description
CreateFileForMapping X X This function creates a file that can be used for memory mapping. This function is deprecated. To create or open a file that can be used for memory mapping, call CreateFile.
CreateFileMapping X X This function creates a named or unnamed file-mapping object for the specified file.
FlushViewOfFile X X This function writes to the disk a byte range within a mapped view of a file.
MapViewOfFile X X This function maps a view of a file into the address space of the calling process.
UnmapViewOfFile X X This function unmaps a mapped view of a file from the address space of the calling process.
