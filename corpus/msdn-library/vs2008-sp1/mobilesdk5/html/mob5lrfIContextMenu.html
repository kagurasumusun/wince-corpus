IContextMenu

Send Feedback on this topic to the authors

The IContextMenu interface is used by the shell when working with context menu extensions.

When to Implement

Implement IContextMenu when you want to use context menu extensions.

When to Use

Use this interface to add and invoke extra context menu items.

Methods in Vtable Order

  • IUnknown methods
    IContextMenu methods Description
    QueryContextMenu Adds the extra menu items to the context menu.
    InvokeCommand Runs a context menu command when the user selects one that was inserted with QueryContextMenu.
    GetCommandString Called by the shell to validate that the command exists, to get the command name, or to get the command help text.

Remarks

IID_IExtractIcon is not supported. You cannot use the Windows CE IShellFolder::GetUIObjectOf method to request an IID_IExtractIcon interface. GetUIObjectOf returns E_NOTIMPL.

Requirements

Pocket PC: Pocket PC 2000 and later.
Smartphone: none
OS Versions: Windows CE 3.0 and later.
Header: Declared in shlobj.h.
