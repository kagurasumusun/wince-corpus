UPnP AV Constants

Send Feedback on this topic to the authors

The following table shows the different types of UPnP AV Framework constants.

Constants Description
BIT_AV_ Constants that define the bit positions for the debug zones used by the UPnP AV Framework.
ZONE_AV_ Constants that define debug zone masks and debug zone names used by the UPnP AV Framework.
AV String Constants Predefined string constants the UPnP AV Framework makes available for communicating changes to string-based state variables.
