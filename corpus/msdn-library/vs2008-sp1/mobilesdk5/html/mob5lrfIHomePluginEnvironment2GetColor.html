IHomePluginEnvironment2::GetColor

Send Feedback on this topic to the authors

The GetColor method provides information about the Home screen color scheme so that plug-ins can draw themselves.

Syntax

HRESULT GetColor (
  HPLUGIN hPlugin,
  BSTR bstrColorName,
  COLORREF * pcr
);

Parameters

hPlugin
[in] Handle to the plug-in for which the color scheme is being retrieved.
bstrColorName
[in] String data for the color scheme.
pcr
[out] Supplies the data on the color scheme.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
Indicates success.

Requirements

Pocket PC: None
Smartphone: Windows Mobile 2003 and later
OS Versions: Windows CE .NET 4.2 and later
Header: home.h
