Telephony Service Provider Structures

Send Feedback on this topic to the authors

The following structures are used with Telephony Service Provider.

Structure Description
CELLBEARERINFO Contains bearer information.
CELLDATACOMPINFO Contains data compression information.
CELLDEVCONFIG A service-provider-specific configuration structure.
CELLGPRSCONNECTIONINFO Contains General Packet Radio Service (GPRS) connection information.
CELLGPRSQOSSETTINGS Contains General Packet Radio Service (GPRS) Quality Of Service (QOS) settings.
CELLRADIOLINKINFO Contains radio link protocol settings.
LINECALLPARAMSDEVSPECIFIC Contains device specific parameters.
