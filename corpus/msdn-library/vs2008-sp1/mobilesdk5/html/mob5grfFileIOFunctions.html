File I/O Functions

Send Feedback on this topic to the authors

The following table shows the file I/O functions with a description of the purpose of each.

Programming element PPC SP Description
CeGenRandom X X This function fills a buffer with random bytes.
CeGetCanonicalPathName X X This function returns the canonical form and the length of the canonical form of the specified path.
CeGetFileNotificationInfo X X This function retrieves file notification information.
CloseHandle X X This function closes an open object handle.
CopyFile X X This function copies an existing file to a new file.
CopyFileEx X X This function copies an existing file to a new file.
CreateDirectory X X This function creates a new directory.
CreateFile X X This function creates, opens, or truncates a file, COM port, device, service, or console.
DeleteAndRenameFile X X This function deletes the source file after it copies the content of the source file to the destination file.
DeleteFile X X This function deletes an existing file from a file system.
FindClose X X This function closes the specified search handle.
FindCloseChangeNotification X X This function stops change notification handle monitoring.
FindFirstFileEx X X This function searches a directory for a file whose name and attributes match those specified in the function call.
FindFirstChangeNotification X X This function creates a change notification handle and sets up initial change notification filter conditions.
FindFirstFile X X This function searches a directory for a file or subdirectory whose name matches the specified file name.
FindNextChangeNotification X X This function requests that the operating system (OS) signal a change notification handle the next time it detects an appropriate change.
FindNextFile X X This function continues a file search from a previous call to the FindFirstFile function.
FlushFileBuffers X X This function clears the buffers for the specified file and causes all buffered data to be written to the file.
GetDiskFreeSpaceEx X X This function obtains information about the amount of space available on a disk volume: the total amount of space, the total amount of free space, and the total amount of free space available to the user associated with the calling thread.
GetFileAttributes X X This function returns attributes for a specified file or directory.
GetFileAttributesEx X X This function obtains attribute information about a specified file or directory.
GetFileInformationByHandle X X This function retrieves information about the specified file.
GetFileSize X X This function retrieves the size, in bytes, of the specified file.
GetFileVersionInfo X X This function returns version information about a specified file.
GetFileVersionInfoSize X X This function determines whether the operating system (OS) can obtain version information about a specified file.
GetStoreInformation X X This function fills in a STORE_INFORMATION structure with the size of the object store and the amount of free space currently in the object store.
GetTempPath X X This function retrieves the path of the directory designated for temporary files.
GetTempFileName X X This function creates a name for a temporary file.
MoveFile X X This function renames an existing file or a directory, including all its children.
LockFileEx X X This function locks the specified file for exclusive access by the calling process.
ReadFile X X This function reads data from a file, starting at the position indicated by the file pointer.
RemoveDirectory X X This function deletes an existing empty directory.
SetEndOfFile X X This function moves the end-of-file position for the specified file to the current position of the file pointer.
SetFileAttributes X X This function sets the attributes of a file.
SetFilePointer X X This function moves the file pointer of an open file.
UnlockFileEx X X This function unlocks a region in an open file. Unlocking a region enables other processes to access the region.
WriteFile X X This function writes data to a file.
