EM_GETVIEW

Send Feedback on this topic to the authors

The EM_GETVIEW message gets the view style, typing, writing, or drawing, of the RichInk control.

EM_GETVIEW
  wParam = (WPARAM) 0; 
  lParam = (LPARAM) 0;

Parameters

wParam
Reserved; set to 0.
lParam
Reserved; set to 0.

Return Values

Returns the current view as one of the following flags.

Flag Information
VT_TYPINGVIEW Typing view
VT_WRITINGVIEW Writing view
VT_DRAWINGVIEW Drawing view

Remarks

#define EM_GETVIEW (WM_USER + 254)

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: None
OS Versions: Windows CE 3.0 and later
Header: richink.h
Library: richink.lib
