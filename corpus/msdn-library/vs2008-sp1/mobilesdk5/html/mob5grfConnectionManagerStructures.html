Connection Manager Structures

Send Feedback on this topic to the authors

The following table shows the Connection Manager structures with a description of the purpose of each.

Programming element Description
CONNMGR_CONNECTION_DETAILED_STATUS Contains detailed information about the status of available connections.
CONNMGR_CONNECTION_IPADDR Contains IP address information for an active connection.
CONNMGR_CONNECTIONINFO This structure provides information about a connection request.
CONNMGR_DESTINATION_INFO This structure provides information about a specific network.
PROXY_CONFIG Tells an application which proxy server to use.
SCHEDULEDCONNECTIONINFO This structure provides information about a scheduled connection.
