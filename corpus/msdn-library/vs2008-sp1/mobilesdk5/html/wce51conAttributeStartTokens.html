Windows Mobile Version 5.0 SDK  

Attribute Start Tokens

Send Feedback on this topic to the authors

Windows Mobile Version 5.0 supports all of the standard Attribute Start tokens as defined in OMA-WAP-ProvCont-v1_1-20030813-C.

Microsoft custom tokens are also defined in the attribute code page ranging from 0x00 to 0x7F, except those defined as global tokens (0~4, 40~44):

Start Tokens on Code Page 200

Start Tokens on Code Page 201

Start Tokens on Code Page 202

Start Tokens on Code Page 203

Start Tokens on Code Page 204
