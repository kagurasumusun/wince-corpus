input type=submit HTML Object

Send Feedback on this topic to the authors

The input type=submit object creates a button object that, when clicked, submits the form.

Properties

Property Data type Access Description
accesskey String Read/write Sets or retrieves the number associated with the accesskey attribute.
Note   Supported only for devices running Windows Mobile 2002 software or later.
disabled Boolean Read/write Sets or retrieves the value that indicates whether the user can interact with the object.
Note   Supported only for devices running Windows Mobile 2002 software or later.
form Object Read-only Retrieves a reference to the form that the object is embedded in.
Note   Supported only for devices running Windows Mobile 2002 software or later.
name String Read-only Sets or retrieves the name of the input type=submit control.
Note   Supported only for devices running Windows Mobile 2002 software or later.
type String Read-only Always returns — submit.
value String Read/write Sets or retrieves the value of the input type=submit control.

Events

Event Description
onclick Occurs when the user selects on the submit button element and only when the user presses the pen down on and then lifts up the pen over the same submit button. The author can specify a special handler for this event.
onblur Occurs when an element loses focus either by the pointing device or by keypad navigation.
Note   Supported only for devices running Windows Mobile 2002 software or later.
onfocus Occurs when an element receives focus either by the pointing device or by tabbing navigation.
Note   Supported only for devices running Windows Mobile 2002 software or later.

Methods

Method Syntax Description
click submit.click Simulates a click on the input type=submit control by causing the onclick event to occur.
focus submit.focus Sets focus to the input type=submit control.

Requirements

Pocket PC: Windows Mobile 2000 and later
Smartphone: Windows Mobile 2002 and later
OS Versions: Windows CE 3.0 and later
