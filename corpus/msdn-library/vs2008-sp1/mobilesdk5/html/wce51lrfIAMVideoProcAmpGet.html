IAMVideoProcAmp::Get

Send Feedback on this topic to the authors

This method retrieves the current setting of a video property. 

HRESULT Get(
  long  Property,
  long* lValue,
  long* Flags
);

Parameters

Property
[in] A long value that specifies the property to retrieve, as a value from the VideoProcAmpProperty enumeration.
lValue
[out] A pointer to a long variable that receives the value of the property.
Flags
[out] A pointer to a long variable that receives a member of the VideoProcAmpFlags enumeration. The returned value indicates whether the setting is controlled manually or automatically.

Return Values

This method returns an HRESULT value. The following tbale shows possible return values.

Value Description
S_OK No error.
E_POINTER Null pointer argument.

Requirements

DirectShow applications and DirectShow filters have different include file and link library requirements. See Setting Up the Build Environment for more information.

Pocket PC Platforms: Windows Mobile 5.0 and later
Smartphone Platforms: Windows Mobile 5.0 and later
OS Versions: Windows CE 5.01 and later.
