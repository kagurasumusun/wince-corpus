IPOutlookApp::get_CurrentCityIndex

Send Feedback on this topic to the authors

The CurrentCityIndex property gets or sets either the HomeCity or the VisitingCity property, depending on whether the current city in use by World Clock is the home or visiting city.

To get the value of the CurrentCityIndex property, call the property method described here.

To set the value of the CurrentCityIndex property, see the IPOutlookApp::put_CurrentCityIndex property method.

Note   This method is supported only for Windows Mobile 2000 software for Pocket PCs.

Syntax

HRESULT get_CurrentCityIndex(
  long * pnolCity
);

Parameters

pnolCity
[out] Integer value representing the city.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: None
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
