IRecurrencePattern::put_DayOfWeekMask

Send Feedback on this topic to the authors

The DayOfWeekMask property gets or sets a bitmask that represents the combination of OlDaysOfWeek enumeration values that make up a recurrence pattern.

To set the value of the DayOfWeekMask property, call the property method described here.

To get the value of the DayOfWeekMask property, see the IRecurrencePattern::get_DayOfWeekMask property method.

Syntax

HRESULT put_DayOfWeekMask(
  long lMask
);

Parameters

lMask
[in] An integer value indicating the days of the week when the recurrence pattern occurs (for example, every Monday, Wednesday, and Friday).

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Remarks

You must set the RecurrenceType property before setting this property.

lMask is the result of performing a bitwise OR on multiple OlDaysOfWeek enumeration values.

Valid for the following OlRecurrenceType enumeration recurrence types: olRecursDaily, olRecursWeekly, olRecursMonthNth, and olRecursYearNth.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
