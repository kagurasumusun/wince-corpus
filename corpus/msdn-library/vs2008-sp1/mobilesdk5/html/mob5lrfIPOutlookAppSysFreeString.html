IPOutlookApp::SysFreeString

Send Feedback on this topic to the authors

The SysFreeString method frees a string that was previously allocated.

Syntax

HRESULT SysFreeString(
  BSTR bstr
);

Parameters

bstr
[in] Unicode string that was allocated previously.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Remarks

This method was needed for devices running software prior to Windows Mobile 2000. Its current implementation simply calls the Windows CE function SysFreeString, passing the same parameter.

Requirements

Pocket PC: Pocket PC 2000 and later
Smartphone: Smartphone 2002 and later
OS Versions: Windows CE 3.0 and later
Header: pimstore.h
Library: pimstore.lib
