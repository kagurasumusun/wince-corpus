This enumeration defines the type of connection reference.

typedef enum _ConnMgrConRefTypeEnum{
  ConRefType_NAP = 0,
  ConRefType_PROXY
} ConnMgrConRefTypeEnum;

Elements

ConRefType_NAP
Defines the NAP connection reference.
ConrefType_PROXY
Defines the proxy connection reference.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Connmgr.h.
