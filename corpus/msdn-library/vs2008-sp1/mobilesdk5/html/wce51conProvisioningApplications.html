Provisioning Applications

Send Feedback on this topic to the authors

Requests to query or change application settings are carried out by Configuration Service Providers. There is a Configuration Service Provider associated with each characteristic in a provisioning XML document used in OMA Client Provisioning. Similarly there is a configuration Service Provider associated with each OMA DM object. The following list shows examples of Configuration Service Providers that allow you to change a few typical applications supported by Windows Mobile-based devices:

  • ActiveSync - Sync Configuration Service Provider (OMA Client Provisioning and OMA DM)
  • Email - EMAIL2 Configuration Service Provider (OMA Client Provisioning and OMA DM)
  • Registry - Registry Configuration Service Provider (OMA Client Provisioning and OMA DM)
