OLE Functions

The following table shows the OLE functions with a description of the purpose of each.

Programming element PPC SP Description
CreateOleAdviseHolder X X This function instantiates an advise holder object for managing compound document notifications.
CreateStreamOnHGlobal X X This function creates a stream object stored in global memory.
GetHGlobalFromStream X X This function retrieves the global memory handle to a stream that was created through a call to the CreateStreamOnHGlobal function.
OleCreate X X This function creates an embedded object identified by a CLSID.
OleDraw X X This helper function provides a convenient way to draw objects by encapsulating the IViewObject::Draw method and other related maintenance functions for the drawing rectangle.
OleIsRunning X X This function determines whether a compound document object is currently in the running state.
OleLoadFromStream X X This function loads an object from the stream.
OleRun X X This function puts an OLE compound document object into the running state.
OleSave X X This function saves an object opened in transacted mode into the specified storage object.
OleSaveToStream X XX This function saves an object with the IPersistStream interface on it to the specified stream.
OleSetContainedObject X X This function notifies an object embedded in an OLE container to ensure correct reference.
OleSetMenuDescriptor X X This function installs or removes OLE dispatching code from the container's frame window.
ReleaseStgMedium X X This function frees the specified storage medium.
