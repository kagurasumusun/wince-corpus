SimChangeLockingPassword

Send Feedback on this topic to the authors

The SimChangeLockingPassword function changes a locking password. This function is part of the SIM Manager API set that enables access to information stored on the SIM card.

HRESULT SimChangeLockingPassword (
   HSIM hSim,
   DWORD dwLockingFacility,
   LPTSTR lpszOldPassword,
   LPTSTR lpszNewPassword
);

Parameters

hSim
Points to a valid HSIM handle.
dwLockingFacility
A SIM_LOCKFACILITY constant.
Value Description
SIM_LOCKFACILITY_CNTRL Lock control surface.
SIM_LOCKFACILITY_PH_SIM Lock phone to SIM card.
SIM_LOCKFACILITY_PH_FSIM Lock phone to first SIM card.
SIM_LOCKFACILITY_SIM Lock SIM card.
SIM_LOCKFACILITY_SIM_PIN2 Lock SIM card.
SIM_LOCKFACILITY_SIM_FIXEDIALING SIM fixed dialing memory.
SIM_LOCKFACILITY_NETWORKPERS Network personalization.
SIM_LOCKFACILITY_NETWORKSUBPERS Network subset personalization.
SIM_LOCKFACILITY_SERVICEPROVPERS Service provider personalization.
SIM_LOCKFACILITY_CORPPERS Corporate personalization.
lpszOldPassword
Pointer to the old password.
lpszNewPassword
Pointer to the new password.

Return Values

HRESULTs are either S_OK for success, or one of the SIM_E error constants defined in the SIM Manager Error Constants table.

Remarks

This is a privileged function. For more information about Smartphone security and privileged APIs, see the "Operating System Security" topic in the Mobile Device Adaptation Kit.

Requirements

Smartphone Platforms: Smartphone 2002 and later
Pocket PC Platforms: Pocket PC 2002 and later
OS Versions: Windows CE 3.0 and later
Header: simmgr.h
Library: cellcore.lib
