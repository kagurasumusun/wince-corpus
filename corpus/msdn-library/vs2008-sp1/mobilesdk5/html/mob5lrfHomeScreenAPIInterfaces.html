Home Screen Interfaces

Send Feedback on this topic to the authors

The following table shows the Smartphone interfaces for the Home Screen.

Interface Description
IHomePlugin (SP) Creates a new plug-in based on the information contained in XML files.
IHomePluginEnvironment (SP) Interface that the plug-in uses to make requests to the home application.
IHomePluginEnvironment2 (SP) Extends the IHomePluginEnvironment interface with the GetColor method.
