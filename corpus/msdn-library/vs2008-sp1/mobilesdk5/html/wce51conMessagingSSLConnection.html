Messaging SSL Connection

Send Feedback on this topic to the authors

Messaging queries the server with multiple attempts to establish an SSL connection. Therefore Messaging is not required to use the SERVICE parm setting.

If Require SSL Connection is checked

If Require SSL Connection is checked an SSL connection is required and Messaging performs the following steps:

  1. Attempts to establish an SSL Connection.
  2. On a failure to establish a connection, Messaging again attempts to connect and issues the STARTTLS command.
  3. If there is still a failure to establish a connection,the attempt to establish an SSL Connection fails.

If Require SSL Connection is not checked.

If Require SSL Connection is not checked the same steps are followed as for Require SSL Connection checked except instead of failing after the first two SSL attempts, Messaging falls back to an Unsecure connection.
