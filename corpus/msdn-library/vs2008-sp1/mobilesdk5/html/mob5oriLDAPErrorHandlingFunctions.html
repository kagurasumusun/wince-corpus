LDAP Error Handling Functions

Send Feedback on this topic to the authors

The following table shows the LDAP error handling functions with a description of the purpose of each.

Programming element Description
ldap_err2string This function converts a numeric LDAP error code into a character string describing the error.
ldap_result2error This function parses a message and returns the error code.
LdapGetLastError This function retrieves the last error code returned by an LDAP call.
LdapMapErrorToWin32 This function translates an LdapError value to the closest Microsoft® Win32® error code.
