Memory Watcher

Send Feedback on this topic to the authors

This code sample is named Memwatcher. It demonstrates how to create a custom Today Screen for Pocket PC.

Feature Area

  • Shell Application Development for Windows Mobile-based Devices

Relevant APIs

  • Shell and User Interface Reference
  • Today Screen API

Usage

To run the code sample

  1. Navigate to the solution file (*.sln), and double-click it. By default, the solution file is copied to the following folder:

    C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Pocket PC SDK\Samples\CPP\Win32\Memwatcher\memwatcher.sln

    Microsoft Visual Studio 2005 Beta 2 launches and loads the solution.

  2. Build the solution (Ctrl+Shift+B).
  3. Deploy the solution (F5).

To use the application

  1. Copy the CAB file to your mobile device and execute it.
  2. From the Start menu on the mobile device, click Settings > Personal > Today > Items.
  3. Click OK. This causes Windows Mobile to reload all of the Today Screen applications, including Memwatcher.

Remarks

This sample builds as a DLL called Memwatcher.dll, and creates a CAB file called memwatchercab.cab.

Requirements

Pocket PC SDK: Windows Mobile 5.0 Pocket PC SDK.
Smartphone SDK: Windows Mobile 5.0 Smartphone SDK.
Development Environment: Visual Studio 2005 Beta 2.
ActiveSync: Version 4.0.
