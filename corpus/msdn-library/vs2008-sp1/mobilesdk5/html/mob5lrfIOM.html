IOM

Send Feedback on this topic to the authors

The IOM enumeration specifies the caller ID type.

typedef enum {
IOM_MISSED,
IOM_INCOMING,
IOM_OUTGOING
} IOM;

Parameters

IOM_MISSED
An unanswered (missed) incoming call.
IOM_INCOMING
An answered incoming call.
IOM_OUTGOING
An outgoing call.

Requirements

Smartphone: Windows Mobile 2002 and later
Pocket PC: Windows Mobile 2002 and later
OS Versions:
Header: phone.h
Library: phone.lib
