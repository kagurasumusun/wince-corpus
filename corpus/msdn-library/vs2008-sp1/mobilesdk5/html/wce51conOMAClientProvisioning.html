OMA Client Provisioning

Send Feedback on this topic to the authors

This section discusses Windows Mobile Version 5.0 support for managing Windows Mobile-based devices through the Open Mobile Alliance (OMA) Client Provisioning protocol.

In This Section

OMA Client Provisioning Files
Provides an overview of the structure and content of OMA Client provisioning XML files and discusses extensions implemented by Microsoft to enable support of continuous provisioning.
Microsoft Standards for Provisioning Windows Mobile-Based Devices
Lists the standards supported for OMA Client provisioning of Windows-mobile based devices.
WBXML and Windows Mobile-Based Devices
Defines the token tables for custom parameters and continuous provisioning that are specific to Windows Mobile-based devices.

Related Sections

OMA Client Provisioning Device Management
Lists Windows Mobile Version 5.0 supported features of the OMA Client Provisioning protocol, extensions and exceptions implemented by Microsoft, and server requirements.
