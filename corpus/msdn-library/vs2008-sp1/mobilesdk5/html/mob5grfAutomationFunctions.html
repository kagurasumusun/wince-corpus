Automation Functions

The following table shows the Automation functions with a description of the purpose of each.

Programming element PPC SP Description
BstrFromVector X X This function returns a BSTR, assigning each element of the vector to a character in the BSTR.
CreateErrorInfo X X This function creates an instance of a generic error object.
CreateTypeLib2 X X This function creates a type library in the file/in-memory format that makes use of memory-mapped files for 32-bit platforms.
DispGetIDsOfNames X X This function uses type information to convert a set of names to DISPIDs.
DispGetParam X X This function retrieves a parameter from the DISPPARAMS structure, checks both named parameters and positional parameters, and coerces the parameter to the specified type.
DispInvoke X X This function automatically calls member functions on an interface, given the type information for the interface.
GetErrorInfo X X This function obtains the error information pointer set by the previous call to SetErrorInfo in the current logical thread.
LoadRegTypeLib X X This function uses registry information to load a type library.
LoadTypeLib X X This function loads and registers a typelib2 type library.
RegisterTypeLib X X This function adds information about a type library to the system registry.
SafeArrayAccessData X X This function increments the lock count of an array, and retrieves a pointer to the array data.
SafeArrayAllocData X X This function allocates memory for a safearray, based on a descriptor created with SafeArrayAllocDescriptor.
SafeArrayAllocDescriptor X X This function allocates memory for a safearray descriptor, allowing the creation of safearrays that contain elements with data types other than those provided by SafeArrayCreate.
SafeArrayCopy X X This function creates a copy of an existing safearray.
SafeArrayCopyData X X This function copies the source array to the target array after releasing any resources in the target array.
SafeArrayCreate X X This function creates a new array descriptor, allocates and initializes the data for the array, and returns a pointer to the new array descriptor.
SafeArrayCreateVector X X This function creates a one-dimensional array whose lower bound is always zero.
SafeArrayDestroy X X This function destroys an existing array descriptor and all of the data in the array.
SafeArrayDestroyData X X This function destroys all the data in a safearray.
SafeArrayDestroyDescriptor X X This function destroys a descriptor of a safearray.
SafeArrayGetDim X X This function returns the number of dimensions in the array.
SafeArrayGetElement X X This function retrieves a single element of the array.
SafeArrayGetElemsize   X This function retrieves the size (in bytes) of the elements of a safearray.
SafeArrayGetLBound X X This function returns the lower bound for any dimension of a safearray.
SafeArrayGetUBound X X This function returns the upper bound for any dimension of a safearray.
SafeArrayLock X X This function increments the lock count of an array, and places a pointer to the array data in pvData of the array descriptor.
SafeArrayPtrOfIndex X X This function returns a pointer to an array element.
SafeArrayPutElement X X This function assigns a single element to the array.
SafeArrayRedim X X This function changes the right most or least significant bound of a safearray.
SafeArrayUnaccessData X X This function decrements the lock count of an array, and invalidates the pointer retrieved by SafeArrayAccessData.
SafeArrayUnlock X X This function decrements the lock count of an array so it can be freed or resized.
SetErrorInfo X X This function sets the error information object for the current thread of execution.
SysAllocString X X This function allocates a new string and copies the passed string into it.
SysAllocStringByteLen X X This function takes an ANSI string as input, and returns a BSTR that contains an ANSI string.
SysAllocStringLen X X This function allocates a new string, copies cch characters from the passed string into it, and then appends a null character.
SysFreeString X X This function frees a string allocated previously by SysAllocString, SysAllocStringByteLen, SysReAllocString, SysAllocStringLen, or SysReAllocStringLen.
SysReAllocString X X This function allocates a new BSTR and copies the passed string into it, then frees the BSTR referenced by pbstr, and finally resets pbstr to point to the new BSTR.
SysReAllocStringLen X X This function creates a new BSTR that contains a specified number of characters from an old BSTR, and frees the old BSTR.
SysStringByteLen X X This function returns the length (in bytes) of a BSTR.
SysStringLen X X This function returns the length of a BSTR.
SystemTimeToVariantTime X X This function converts the variant representation of time to system-time values.
UnRegisterTypeLib X X This function removes type library information from the system registry.
VarBoolFromCy X X This function converts variant data types to BOOL from CURRENCY.
VarBoolFromDate X X This function converts variant data types to BOOL from DATE.
VarBoolFromDec X X This function converts variant data types to BOOL from DECIMAL.
VarBoolFromDisp X X This function converts variant data types to BOOL from IDispatch.
VarBoolFromI2 X X This function converts variant data types to BOOL from short.
VarBoolFromI4 X X This function converts variant data types to BOOL from long.
VarBoolFromR4 X X This function converts variant data types to BOOL from float.
VarBoolFromR8 X X This function converts variant data types to BOOL from double.
VarBoolFromStr X X This function converts variant data types to BOOL from OLECHAR.
VarBoolFromUI1 X X This function converts variant data types to BOOL from unsigned char.
