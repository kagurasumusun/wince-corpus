Debug NOTE (Message) Macros

Send Feedback on this topic to the authors

The NOTE macros provide debug message abilities in the Microsoft Foundation Class (MFC) for Windows CE style.

Programming element PPC SP Description
NOTE X X Logs a debug message with zero additional parameters.
NOTE1 X X Logs a debug message with one additional parameter.
NOTE2 X X Logs a debug message with two additional parameters.
NOTE3 X X Logs a debug message with three additional parameters.
NOTE4 X X Logs a debug message with four additional parameters.
NOTE5 X X Logs a debug message with five additional parameters.
