FindMatchingContact Property ID's

Send Feedback on this topic to the authors

The following table contains the complete set of property identifiers used with the FindMatchingContact function. These property identifiers indicate the type of Contact properties to search through when performing a Contact search.

Property ID Description String name for queries
PIMPR_ALL_COMMUNICATION_METHODS Search all numbers and addresses. This includes:

PIMPR_ALL_EMAIL
PIMPR_ALL_INSTANT_MESSAGING
PIMPR_ALL_PHONE_AND_SIM
PIMPR_ALL_TEXT_MESSAGING

This property is not a valid POOM property. IItem treats it as an unknown property. It is only valid for FindMatchingContact. Read-only.

 AllCommunicationMethods
PIMPR_ALL_EMAIL Search all of the e-mail addresses. This includes:

PIMPR_EMAIL1_ADDRESS
PIMPR_EMAIL2_ADDRESS
PIMPR_EMAIL3_ADDRESS

This property is not a valid POOM property. IItem treats it as an unknown property. It is only valid for FindMatchingContact. Read-only.

 AllEmail
PIMPR_ALL_INSTANT_MESSAGING Search all of the instant messaging addresses. This includes:

PIMPR_IM1_ADDRESS
PIMPR_IM2_ADDRESS
PIMPR_IM3_ADDRESS

This property is not a valid POOM property. IItem treats it as an unknown property. It is only valid for FindMatchingContact. Read-only.

 AllInstantMessaging
PIMPR_ALL_PHONE Search all of the phone numbers. This includes:

PIMPR_ALL_VOICE
PIMPR_BUSINESS_FAX_NUMBER
PIMPR_HOME_FAX_NUMBER
PIMPR_PAGER_NUMBER

This property is not a valid POOM property. IItem treats it as an unknown property. It is only valid for FindMatchingContact. Read-only.

 AllPhone
PIMPR_ALL_PHONE_AND_SIM Search all of the phone numbers, including those in the SIM. This includes:

PIMPR_ALL_PHONE
PIMPR_SIM_PHONE

This property is not a valid POOM property. IItem treats it as an unknown property. It is only valid for FindMatchingContact. Read-only.

 AllPhoneAndSIM
PIMPR_ALL_TEXT_MESSAGING Search all of the Short Message Service (SMS) addresses. This includes:

PIMPR_MMS
PIMPR_SMS

This property is not a valid POOM property. IItem treats it as an unknown property. It is only valid for FindMatchingContact. Read-only.

 AllTextMessaging
PIMPR_ALL_VOICE Search all of the voice phone numbers. This includes:

PIMPR_ASSISTANT_TELEPHONE_NUMBER
PIMPR_BUSINESS_FAX_NUMBER
PIMPR_BUSINESS_TELEPHONE_NUMBER
PIMPR_BUSINESS2_TELEPHONE_NUMBER
PIMPR_CAR_TELEPHONE_NUMBER
PIMPR_COMPANY_TELEPHONE_NUMBER
PIMPR_HOME_FAX_NUMBER
PIMPR_HOME_TELEPHONE_NUMBER
PIMPR_HOME2_TELEPHONE_NUMBER
PIMPR_MOBILE_TELEPHONE_NUMBER
PIMPR_PAGER_NUMBER
PIMPR_RADIO_TELEPHONE_NUMBER

This property is not a valid POOM property. IItem treats it as an unknown property. It is only valid for FindMatchingContact. Read-only.

 AllVoice

Smartphone: Windows Mobile Version 5.0 and later
OS Versions: Windows CE 5.01 and later
Header: pimstore.h
Library: pimstore.lib
