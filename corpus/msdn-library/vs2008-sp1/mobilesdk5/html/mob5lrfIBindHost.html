IBindHost

Send Feedback on this topic to the authors

This interface is implemented by an ActiveX® container to allow controls to perform asynchronous data transfers through the container.

The following methods are used with the IBindHost interface.

Method Description
IBindHost::CreateMoniker Creates a moniker to bind to a URL.
IBindHost::MonikerBindToObject Binds a moniker to an object.
IBindHost::MonikerBindToStorage Binds a moniker to storage.
