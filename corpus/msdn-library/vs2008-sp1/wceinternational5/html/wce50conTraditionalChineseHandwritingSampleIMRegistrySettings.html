Traditional Chinese Handwriting Sample IM Registry Settings

The HKEY_CLASSES_ROOT\CLSID\{0CA0AAFA-E999-4993-9AAA-4FB0ECE28A8D} registry key is set when using the Traditional Chinese Handwriting Sample input method (IM). This registry key is set to "CHT HWX sample UI" to specify the input method.

The following table shows the named values for the HKEY_CLASSES_ROOT\CLSID\{0CA0AAFA-E999-4993-9AAA-4FB0ECE28A8D} registry key.

Value : type Description
InprocServer32 : REG_SZ Default set to "\\windows\\mboxcht.dll". Specifies the name of the DLL for the Traditional Chinese Handwriting Sample IM.
IsSIPInputMethod : REG_DWORD Default set to 1 to enable SIP. Allows applications to switch to software-based input panel IM.
DefaultIcon : REG_SZ Default set to "\\windows\\mboxcht.dll,0". Specifies the source file for the default IM icon.
