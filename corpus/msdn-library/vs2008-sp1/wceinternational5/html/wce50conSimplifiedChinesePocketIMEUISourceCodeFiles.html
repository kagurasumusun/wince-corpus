Simplified Chinese Pocket IME UI Source Code Files

The source code for the Simplified Chinese Pocket IME UI is located in the following directory.

%_WINCEROOT%\Public\Wceshellfe\Oak\Lang\Ime\Cimeui

The following table lists the individual files that contain source code for the Simplified Chinese Pocket IME.

File Description
Imeui.cpp Creates the main IME UI window.
Compui.cpp Creates a composition window.
Candui.cpp Creates a candidate window.
Statusui.cpp Creates a status window.
Init.cpp Initializes parts of the UI.
Uipriv.h Defines private UI structures.
