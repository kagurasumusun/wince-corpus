WM_IME_STARTCOMPOSITION

This message is sent immediately before the IME generates a composition string because of a keystroke. The message is a notification to an IME window to open its composition window. An application should process this message if it displays composition characters itself.

WM_IME_STARTCOMPOSITION
  wParam = 0;
  lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

None.

Remarks

If an application has created an IME window, it should pass the WM_IME_STARTCOMPOSITION message to that window. The DefWindowProc function processes this message by passing it to the default IME window.

Windows CE applications cannot create IME windows.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Imm.h.
