Indic OS Design Development

Windows CE provides support for the following Indic locales:

  • Gujarati
  • Hindi
  • Kannada
  • Marathi
  • Punjabi
  • Tamil
  • Telugu

For each of these locales, Windows CE provides support for the locale-specific keyboards and fonts.

Note   Windows CE does not support non-Unicode encoding for Indic or embedded fonts.

Windows CE supports dynamic switching of the keyboard layout. The default key combination for switching the keyboard layout is Alt + Shift. For more information, see Multiple Input Language Support.
