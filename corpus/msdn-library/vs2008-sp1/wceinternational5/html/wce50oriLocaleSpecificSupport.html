Locale Specific Support

Windows CE provides support for several different locales. The locale-specific support in Windows CE includes fonts, keyboards and keyboard drivers, Input Method Editors (IMEs), and Input Methods (IMs).

Windows CE supports the following locales:

  • Arabic
  • Chinese (Simplified)
  • Chinese (Traditional)
  • English (U.S.)
  • English (Worldwide)
  • French
  • German
  • Hebrew
  • Indic
  • Japanese
  • Korean
  • Thai
