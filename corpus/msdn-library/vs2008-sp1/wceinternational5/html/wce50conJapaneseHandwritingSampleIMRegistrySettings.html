Japanese Handwriting Sample IM Registry Settings

The following registry keys are used for the Japanese Handwriting Sample input method (IM).

The HKEY_CLASSES_ROOT\CLSID\{0CBEA010-F68E-11d1-8C63-0060977B4593}\LOC_MULTIBOX registry key has the following subkeys.

Key : type Description
KBMode : REG_DWORD Default set to 5. Specifies the keyboard mode.
InprocServer32 : REG_SZ Default set to \\windows\\multibox.dll. Specifies the name of the DLL for Japanese Handwriting Sample IM.
IsSIPInputMethod : REG_DWORD Default set to 1 to enable SIP. Allows applications to switch to software-based input panel (SIP) IM.
DefaultIcon : REG_SZ Default set to \\windows\\multibox.dll,0. Specifies the source file for the default IM icon.

The HKEY_CURRENT_USER\ControlPanel\SIP registry key is set when using the Japanese Handwriting Sample input method and SIP. The following table shows the named values for the registry key.

Value : type Description
AllowChange : REG_DWORD Default set to 1. Specifies whether applications can change the SIP settings or not.
DragStyle : REG_DWORD Default set to 1. Specifies whether the SIP is dragable or not.
DefaultIm : REG_SZ Default set to {0CBEA010-F68E-11D1-8C63-0060977B4593} for Japanese Handwriting Sample IM. Specifies the CLSID for the input method.
