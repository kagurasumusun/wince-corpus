Implementing Japanese IME 3.1

You can implement Japanese IME 3.1 in your OS design by following these instructions.

To implement Japanese IME 3.1

  1. Launch Platform Builder.
  2. In the Catalog, navigate to Core OS\Display based Devices\International\Locale Specific Support\Japanese\Input Method Editor and then add the IME 3.1 Catalog item.

    This adds the minimum set of IME 3.1 functionality, including the Compact Dictionary Database.

  3. If you need additional functionality, expand the IME 3.1 node in the Catalog, and add any additional Catalog items.
  4. Build the run-time image.
