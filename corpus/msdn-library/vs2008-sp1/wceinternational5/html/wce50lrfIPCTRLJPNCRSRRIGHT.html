IPCTRL_JPN_CRSRRIGHT

This control identifier requests the conversion service to move the target clause to the right. It specifies the number to move the target clause. You can use IPCTRLPARAM_DEFAULT instead of specifying 1.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Msime.h.
