Chinese (Simplified) Registry Settings

In This Section

Simplified Chinese MSPY 3.0 IME Configuration Registry Settings
Provides registry information required to configure Microsoft Pinyin (MSPY).
Simplified Chinese MSPY 3.0 IME Hot Key Registry Settings
Provides registry information required to configure hot keys for the Chinese MSPY 3.0 Input Method Editor (IME).
Simplified Chinese Pocket IME UI Module Registry Settings
Provides registry information required to configure an OEM-supplied UI module for the Simplified Chinese Pocket IME user interface (UI).
Simplified Chinese Pocket IME Hot Key Registry Settings
Provides registry information required to configure the hot keys used in the Simplified Chinese Pocket IME.
Simplified Chinese Pocket IME UI Configuration Registry Settings
Provides registry information required to configure the Simplified Chinese Pocket IME, including how to enable hot keys, enable the hot key toggle when Pinyin IME is installed, enable full and half-width toggle, and enable symbol input toggle from the keyboard directly.
