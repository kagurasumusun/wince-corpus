Japanese Registry Settings

The registry stores information necessary to set up the system for applications and hardware devices. The registry also contains information that the operating system continually references during operation. The registry contains named values for Japanese configuration.

In This Section

Japanese All Character IM Registry Settings
Provides registry information required to configure the Japanese All Character input method (IM).
Japanese Character Auto Complete (CAC) IM Registry Settings
Provides registry information required to configure the Japanese Character Auto Complete (CAC) input method.
Japanese Handwriting Sample IM Registry Settings
Provides registry information required to configure the sample handwriting input method, including settings for configuring the Software-based Input Panel (SIP).
Japanese IM and IME Registry Settings
Provides registry information required to configure the keyboard layout and the dictionary settings for Japanese Pocket Input Method Editor (IME).
Japanese IM Hot Key Registry Settings
Provides registry information required to configure the Japanese IM hot keys.
Japanese MS Kana IM Registry Settings
Provides registry information required to configure the Japanese MS Kana IM, including settings for configuring the SIP.
Japanese MS Roma IM Registry Settings
Provides registry information required to configure the Japanese MS Roma IM, including settings for configuring the SIP.
Japanese Search by Radical IM Registry Settings
Provides registry information required to configure the Japanese Search by Radical IM, including settings for configuring the SIP.
Japanese Search by Stroke IM Registry Settings
Provides registry information required to configure the Japanese Search by Stroke IM, including settings for configuring the SIP.
