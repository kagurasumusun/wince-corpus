CImeCUIDefCompWindow::GetTextColor

This method retrieves the color of the text in the guideline window.

static COLORREF GetTextColor(void);

Parameters

None.

Return Values

The return value is a COLORREF value that specifies the text color.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Imjpskin.h.
