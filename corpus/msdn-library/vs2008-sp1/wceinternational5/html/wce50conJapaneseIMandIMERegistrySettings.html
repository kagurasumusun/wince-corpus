Japanese IM and IME Registry Settings

The HKEY_CURRENT_USER\Keyboard Layout\Preload\1 registry key is set when using the Input Method Manager (IMM). The following table shows the named value for the registry key.

Value : type Description
@ : REG_SZ Default set to e0010411 for locale 0411. Specifies the keyboard layout settings for the IME.

The HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Layouts\e0010411 registry key is used to set the keyboard layout when using the Japanese Pocket IME. The following table shows the named values for the registry key.

Value : type Description
Layout text : REG_SZ Default set to Microsoft pIMECE (JPN). Specifies the source for the layout text.
Ime File : REG_SZ Default set to imejppui.dll for Japanese Pocket IME. Specifies the associated DLL for the IME.

The HKEY_LOCAL_MACHINE\Software\Microsoft\Pocket IME registry key is used to set Pocket IME registry settings. The following table shows the named values for the registry key.

Value : type Description
RegisteredWordBufferSize : REG_DWORD Default set to 64. Specifies the buffer size for registered words.
SaveRegisteredWordBuffer : REG_DWORD Default set to 1. Specifies the buffer size for saving registered words.
LearnedWordBufferSize : REG_DWORD Default set to 64. Specifies the buffer size for learned words.
RecentlyUsedWordBufferSize : REG_DWORD Default set to 64. Specifies the buffer size for recent words.
SaveLearningBuffers : REG_DWORD Default set to 1. Specifies whether learning buffers should be saved.
Learning : REG_DWORD Default set to 1 to enable learning. Specifies whether word learning is turned on.

The HKEY_LOCAL_MACHINE\Software\Microsoft\Pocket IME\Dictionaries registry key is used to set Pocket IME dictionary settings. The following table shows the named values for the registry key.

Value : type Description
DIC0 : REG_SZ Set to \\windows\\imejppu.dic,1.
DIC1 : REG_SZ Set to \\windows\\imejpps.dic,1.
DIC2 : REG_SZ If using Supplemental and Name/Place dictionary, set to \\windows\\imejppn.dic,1.

If using only Name/Place dictionary, set to \\windows\\imejppn.dic,1.

If using only Supplemental dictionary, do not set.
DIC3 : REG_SZ If using Supplemental and Name/Place dictionary, set to \\windows\\imejppm.dic,1.

If using only Supplemental dictionary, set to \\windows\\imejppm.dic,1.

If using only Name/Place dictionary, do not set.

The HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Layouts\e0010411 registry key is used to set the registry settings when using TESTIME. The following table shows the named values for the registry key.

Value : type Description
Layout text : REG_SZ Specifies the source for layout text. Set to KBD e0010411 for TESTIME.
Ime File : REG_SZ Specifies the associated DLL for the IME. Set to testime.dll for TESTIME.
