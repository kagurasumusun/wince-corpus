Japanese IM Hot Key Registry Settings

The HKEY_CURRENT_USER\Control Panel\Input Method\Hot Keys\00000030 registry key is used to set the Japanese Input Method (IM) registry settings. The following table shows the named values for the registry key.

Value : type Description
VK : REG_DWORD Specifies the hot keys for input mode switch. Set to 19.
KM : REG_DWORD Specifies the key modifier value for the hot key. Set to C001.
ime : REG_DWORD Specifies the associated IME settings for input mode switch. Set to e0010411.
