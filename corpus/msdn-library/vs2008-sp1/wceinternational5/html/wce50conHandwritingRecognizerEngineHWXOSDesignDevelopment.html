Handwriting Recognizer Engine (HWX) OS Design Development

Handwriting Recognizer Engine (HWX) for Windows CE provides a handwriting recognition engine that supports user-drawn ideographs and characters.

OS Design Information

The following table shows operating system design information for HWX.

Concept Description
Dependencies Requires the Touch Screen (Stylus) Catalog item and a keyboard driver.
Hardware considerations Requires a touch screen.

Modules and Components

The following table shows the components and modules that implement HWX.

Item Module Component
Handwriting Recognizer Engine for Traditional Chinese hwxcht None
Handwriting Recognizer Engine for Japanese hwxjpn None
Handwriting Recognizer Engine for Korean hwxkor None
Handwriting Recognizer Engine for English (U.S.) hwxusa None

Handwriting Recognizer Engine (HWX) Implementation Considerations

The following table shows the Sysgen variable for HWX.

Sysgen variable Description
SYSGEN_HW When this variable is set, the Transcriber HWX Catalog item is included in the OS design.
