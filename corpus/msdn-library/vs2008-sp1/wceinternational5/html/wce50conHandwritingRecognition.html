Handwriting Recognizer Engine (HWX)

Handwriting Recognizer Engine (HWX) for Windows CE provides a handwriting recognition engine that supports user-drawn ideographs and characters.

In This Section

Provides information about the handwriting recognizer engine support that is helpful when designing and developing a Windows CE OS. This includes dependency information, the modules and components that implement HWX, and HWX implementation considerations.

Provides an overview of the handwriting recognition architecture in Windows CE, shows how to recognize a hand-drawn character, and provides instructions on performing handwriting recognition.

Contains reference pages for the HWX application programming interface.
