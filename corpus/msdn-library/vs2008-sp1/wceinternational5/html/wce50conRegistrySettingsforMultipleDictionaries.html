Registry Settings for Multiple Dictionaries

You can add up to eight dictionaries to the Pocket IME support of an OS design. To add a dictionary to an OS design, you need to specify it as a registry value under the dictionaries registry key.

The following table shows the registry settings for HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Pocket IME.

Registry key Type Value
Dictionaries REG_SZ "DIC0" = "\\windows\\imejppu.dic,1"
"DIC1" = "\\windows\\imejpps.dic,1"
"DIC2" = "\\windows\\imejppm.dic,1"
"DIC3" = "\\windows\\imejppn.dic,1"

The dictionaries registry key can contain eight REG_SZ values. Each value corresponds to a dictionary. The following template shows how to correctly set the dictionaries registry key.

"DIC<number>" = "<full path of dictionary file>,<dictionary lookup flag>"

When setting the dictionaries registry key, you need to fill the following values:

  • Append a dictionary number to the DIC string. Dictionary number 0 is used for the user dictionary, 1 is used for the standard system dictionary, and numbers 2 through 7 are reserved for add-on system dictionaries.
  • Insert the full path to the dictionary file.
  • Include a dictionary lookup flag after the path to the dictionary flag. The lookup flag determines whether the kernel searches for words in the dictionary. If this flag is set to a nonzero value, the kernel will look up words in the dictionary. If the flag is set to zero, the kernel will not look up words in the dictionary. The dictionary lookup flag does not affect how the kernel behaves toward writing data to a user dictionary and reading grammar data from the standard dictionary.

If the kernel is configured to use the user dictionary file and the DIC0 value has not been set in the registry or the registry value is empty, the kernel writes the following value to the registry by default.

"DIC0" = "\windows\imejppu.dic,1"

If the DIC1 value has not been set in the registry or the registry value is empty, the kernel writes the following value to the registry by default.

"DIC1" = "\windows\imejpps.dic,1"

If the specified dictionary is invalid or does not exist, the kernel causes an error in the initialization phase.

The kernel only uses an add-on dictionary if it has been specified in the registry.
