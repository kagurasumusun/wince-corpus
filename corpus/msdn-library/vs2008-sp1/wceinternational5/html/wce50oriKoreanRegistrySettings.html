Korean Registry Settings

The registry stores information necessary to set up the system for applications and hardware devices. The registry also contains information that the operating system continually references during operation. The registry contains named values for Korean configuration.

In this Section

Korean IME UI Configuration Registry Settings
Provides registry information required to configure some of the user interface (UI) settings for the Korean Input Method Editor (IME), including displaying the status window and accelerators, and positioning the candidate list.
Korean IME97 Registry Settings
Provides registry information required to configure the predefined hot keys for Korean IME97.
Korean IME97 Hot Key Registry Settings
Provides registry information required to configure the Korean IME97 hot keys.
Korean Handwriting Sample IM Registry Settings
Provides registry information required to configure the Korean Handwriting Sample input method (IM).
Korean Soft Keyboard IM Registry Settings
Provides registry information required to configure the Korean IM and Software-based Input Panel (SIP).
