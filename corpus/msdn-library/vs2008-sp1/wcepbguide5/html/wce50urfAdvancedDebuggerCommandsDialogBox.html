Platform Builder for Microsoft Windows CE 5.0  

Advanced Debugger Commands Dialog Box

Use this dialog box to execute a custom command through the kernel debugger.

This dialog box is available only when you are debugging and in a break state.

The following options are available:

Command
Enter the name of the custom command.
Execute
Select to execute the command you typed in.
Close
Select to close this dialog box without making changes.
