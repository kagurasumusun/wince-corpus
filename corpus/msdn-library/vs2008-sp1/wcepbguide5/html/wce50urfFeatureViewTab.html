Workspace Window: OSDesignView Tab

The OSDesignView tab shows the functionality that makes up your OS design.

To view the files that your OS design contains, change the focus of the Workspace window to the FileView tab. For more information, see FileView Tab.

After you create an OS design, you can modify it by adding and removing Catalog items, such as the following:

  • Core OS features
  • Reference hardware drivers
  • Board support packages (BSPs)
  • Run-time libraries

You can create and add your own custom Catalog items, and you can also add Catalog items from third-party vendors.

You can also customize the items that are available in the Catalog. For more information, see Catalog Customization.

For information about icons used on the OSDesignView tab, see Catalog Item Icon Types.
