Compiler Warning (level 1) C4555

expression has no effect; expected expression with side-effect

This warning, which is off by default, informs you when an expression has no effect.

For example:

// compile with cl /c
#pragma warning(default:4555)

void func1() {
1;//C4555
}

void func2() {
int x;
x;//C4555
}
