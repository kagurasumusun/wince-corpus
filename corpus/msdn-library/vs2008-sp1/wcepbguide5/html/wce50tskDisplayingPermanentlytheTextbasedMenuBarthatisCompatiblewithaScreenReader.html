Displaying Permanently the Text-based Menu Bar That Is Compatible with a Screen Reader

You can permanently display the text-based menu bar that is compatible with a screen reader.

To permanently display the text-based menu bar that is compatible with a screen reader

  1. From the Tools menu, choose Options and then choose the Workspace tab.
  2. Select the Use Screen Reader Compatible Menus check box.

Platform Builder displays a text-based menu bar at the top of the UI.

If you are using this option, you cannot customize the menus by adding graphics.
