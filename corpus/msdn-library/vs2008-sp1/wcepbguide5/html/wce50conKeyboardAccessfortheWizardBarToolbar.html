Keyboard Access for the WizardBar Toolbar

By assigning shortcut keys to WizardBar toolbar commands, you can gain full keyboard access to all WizardBar toolbar commands.

The following WizardBar toolbar keyboard commands are available.

Command Description
WBActionButtonActive Places the focus on the Action control button.
WBClassComboActive Places the focus on the Class combo box.
WBFilterComboActive Places the focus on the Filter combo box.
WBMembersComboActive Places the focus on the Members combo box.
WBAddNewMember Opens the Add Member Function dialog box.
WBCreateNewVirtualFunction Opens the Add Virtual Function dialog box.
WBCreateNewWindowsMessageHandler Opens the Add Windows Message Handler dialog box.
WBDefaultAction Carries out the current default action.
WBGoToClassDefinition Jumps to the definition for the selected class.
WBGoToMember Jumps to the definition or implementation for the selected member.
WBGoToMemberDeclaration Jumps to the declaration for the selected function.
WBGoToNext Jumps to the next function in the current file.
WBGoToPrevious Jumps to the previous function in the current file.
WBHelp Displays a Help topic in the WizardBar toolbar.
WBOpenInclude Opens the associated header file for the current file in the text editor.

After you assign shortcut keys to the WizardBar toolbar commands, you can perform all available WizardBar toolbar actions from the keyboard.

Additionally, by tabbing between the WizardBar toolbar combo boxes and the Action menu you gain access to all functions that are available for the combo box or the Action menu.

You can also use the keyboard to display the Action menu at any time when the focus is on the WizardBar toolbar.
