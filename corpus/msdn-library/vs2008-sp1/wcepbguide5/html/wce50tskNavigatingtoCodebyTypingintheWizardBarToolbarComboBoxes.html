Navigating to Code by Typing in the WizardBar Toolbar Combo Boxes

You can use the combo boxes on the WizardBar toolbar to navigate source code.

To navigate to code by using the WizardBar

  1. Place the focus on a WizardBar toolbar combo box.

    The list opens.

    To place the focus on a WizardBar toolbar combo box from the keyboard, you must first assign a shortcut key to it.

  2. Begin typing the first few letters of the class, filter, or member you want to navigate to.

    As you type, the list is updated to include only entries that match what you type, and the box fills with the first complete possible match.

  3. When the element you want to navigate to appears, press TAB to move to the next combo box.

    Pressing ENTER performs the default action for the current context; pressing TAB moves you to the next combo box without performing the default action. In either case, the WizardBar toolbar combo boxes update their hierarchical dependencies.

    For example, when you select a new class, the Members list is updated to reflect all members of that class.
