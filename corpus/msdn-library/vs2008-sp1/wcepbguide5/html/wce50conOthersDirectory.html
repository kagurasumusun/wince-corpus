Platform Builder for Microsoft Windows CE 5.0  

Others Directory

The Others directory contains run-time Common Object File Format (COFF) library (.lib) and dynamic-link library (.dll) files, as well as the methods for including them in an OS image.

This directory also contains Microsoft Foundation Classes (MFC) for Windows CE; Active Template Library (ATL) for Windows CE header files; registry files; and batch files that are used to add files to an run-time image.

Pbmerge.exe helps build the OS design into a run-time image.

The Others directory contains the following directories.

Directory Contents
ATL Source files for adding ATL run-time files to an OS design.
DOTNET .NET processor-specific binaries and portable Microsoft® .NET Compact Framework files.
MFC Source files for adding MFC run-time files to an OS design.
SAMPLES Sample ATL and MFC applications.
WCETK The Windows CE Test Kit client (target) files.
