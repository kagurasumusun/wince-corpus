Renaming a Toolbar Button or Menu Command

You can rename a toolbar button or menu command.

To rename a toolbar button or menu command

  1. Display the toolbar that has the button or menu command you want to change.
  2. From the Tools menu, choose Customize.

    The Customize dialog box must remain open; however, you can move it.

  3. To rename a toolbar button, right-click the toolbar button on the toolbar and then choose Button Appearance from the shortcut menu.

    – or –

    To rename a menu command, select the menu that has the menu command you want to change, right-click the menu command, and then choose Button Appearance from the shortcut menu.

  4. In the Button Text box, type the new name.

    To specify a letter as the shortcut key, insert an ampersand (&) before the letter when you type the name.

If the toolbar button does not display text, you can verify the name change by viewing the ToolTip.
