Changing Default Key Mappings for IntelliSense Options

You can change default key mappings for IntelliSense options.

To change default key mappings for IntelliSense options

  1. Choose Customize from the Tools menu.
  2. Choose the Keyboard tab.
  3. Choose Edit from the Category List.
  4. Choose Text from the Editor list.
  5. Choose from the following commands in the Commands list:
    • CompleteWord
    • ListMembers
    • ParameterInfo
    • TypeInfo
  6. Type your new key mapping in the Press New Shortcut Key box, and then choose Assign.
