i18n Warnings

PREfast detects several errors related to the process of localization.

The following warnings are reported in this category:

Warning number Description
PREfast Warning 400 Using <function> to perform a case-insensitive compare to constant <string>.
PREfast Warning 401 Using <function> in default locale <locale> to perform a case-insensitive compare to constant <string>.
