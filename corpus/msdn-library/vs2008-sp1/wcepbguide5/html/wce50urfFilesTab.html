Platform Builder for Microsoft Windows CE 5.0  

New Dialog Box: Files Tab

This tab includes the following items.

Files window
Use to select the type of file you want to create.
Add to Project
Select to add a new file to an existing project.

If you have more than one existing project, press the DOWN ARROW next to the drop-down box to select the project name.

File Name
Use to type the name of the new document file.

If you do not provide an extension, the default extension associated with the document type is appended automatically.

Location
Use to specify the directory for the new document file.

You can type a path or select one by using the Browse button at the right of the Location box.
