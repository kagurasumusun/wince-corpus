Ram Pages for ROM Breakpoints

The debugger uses RAM pages to keep copies of ROM pages when setting breakpoints in ROM.

There are 10 RAM pages allocated for this task.

Each time you set a ROM breakpoint, the debugger might use an additional RAM page. When the number of RAM pages reaches the allocation, no more ROM breakpoints can be set.

To set other ROM breakpoints, remove ROM breakpoints to free RAM pages.
