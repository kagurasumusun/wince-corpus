Moving or Copying a Menu from One Toolbar to Another

You can move or copy a menu from one toolbar to another.

To move or copy a menu from one toolbar to another

  1. Display the toolbar that has the menu you want to move or copy, and the toolbar that you want to move or copy the menu to.
  2. From the Tools menu, choose Customize.

    The Customize dialog box must remain open; however, you can move it.

  3. To move a menu, select the menu on the toolbar and then drag it to the new location on the same toolbar or another toolbar.
  4. To copy a menu, press CTRL and then drag the menu to the new location.
