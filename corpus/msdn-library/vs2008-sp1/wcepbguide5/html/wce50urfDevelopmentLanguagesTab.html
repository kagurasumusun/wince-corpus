Platform Builder for Microsoft Windows CE 5.0  

SDK Settings Dialog Box: Development Languages Tab

On this tab, you can choose the development languages that you want your SDK to support.

eMbedded Visual C++ 4.0 support
Select if Visual C++ is supported.
ATL for Windows CE applications
Select if Active Template Library (ATL) for Windows CE applications will be supported.

This option is available for selection after you select eMbedded Visual C++ 4.0 support.

MFC for Windows CE applications
Select if Microsoft Foundation Classes (MFC) for Windows CE applications will be supported.

This option is available for selection after you select eMbedded Visual C++ 4.0 support.

MFC for Windows CE ActiveX controls
Select if MFC ActiveX controls will be supported.

This option is available for selection after you select eMbedded Visual C++ 4.0 support.

.NET Compact Framework
Select if Microsoft .NET Compact Framework development languages will be supported.

This option is unavailable when creating an SDK for some OS design configurations.
