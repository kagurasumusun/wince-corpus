Platform Builder for Microsoft Windows CE 5.0  

Batch Build Dialog Box

If you have more than one configuration, this dialog box enables you to set up consecutive builds of more than one configuration.

This dialog box includes the following items.

Configurations
Displays the configurations of the open OS design.
Sysgen
Use to link libraries in the specified configurations.

Equivalent to the Blddemo -q norel command in a command-line build.

Build and Sysgen
Use to build the specified configurations, including all dependent projects.

Equivalent to the Blddemo norel command in a command-line build.

Clean
Select to delete all intermediate and output files created during the build process for the specified configurations before running a build.
Cancel
Use to close the dialog box without making changes.
