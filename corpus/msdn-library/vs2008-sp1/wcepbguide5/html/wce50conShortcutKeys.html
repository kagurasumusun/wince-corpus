Platform Builder for Microsoft Windows CE 5.0  

Shortcut Keys

Shortcut keys offer an alternative method for performing keyboard actions. Some commands in Platform Builder are assigned shortcut keys by default.

Use commands in Platform Builder to complete the following actions:

  • Change the existing shortcut key assignments
  • Create shortcut keys for commands that do not have shortcut keys by default
  • Assign more than one shortcut key for a command
  • Delete shortcut key assignments
  • Assign shortcut keys for each editor
  • Reset all shortcut keys to their default settings
  • Display the current shortcut keys, including custom key settings and editor emulation
