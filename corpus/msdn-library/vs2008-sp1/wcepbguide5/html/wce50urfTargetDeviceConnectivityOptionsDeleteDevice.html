Target Device Connectivity Options: Delete Device

You can delete the connections that you configure for downloading run-time images to a target device.

For more information about this dialog box, see Target Device Connectivity Options Dialog Box.

Name
Choose the check box associated with the connection you configured.
Associated OS design
Specifies the OS design associated with the connection to a target device.
ID
Specifies the ID for the named connection.
Delete
Apply your changes without closing the dialog box.
Close
Close the dialog box without applying changes.
