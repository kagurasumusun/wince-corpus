Platform Builder for Microsoft Windows CE 5.0  

Open Workspace Dialog Box

This dialog box enables you to open an existing workspace (.pbxml) file.

When you select a file, Platform Builder tries to open the file you select as a workspace. If it is not a workspace file, you get a message that states the specified file cannot be opened as a workspace.

This dialog box includes the following items.

Look in
Use to select the drive or folder that contains the workspace you want.

The contents of the drive or folder appear below in the File list.

File name
Use to specify the name of the workspace you want to open.
Files of type
Use to display the type of file you want to open by selecting the file type you want from the drop-down list.
Open
Select to open the specified file.
Cancel
Select to close the dialog box without saving changes.
