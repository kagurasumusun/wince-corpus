Platform Builder for Microsoft Windows CE 5.0  

Supported Compilers

Windows CE includes compilers for all supported microprocessors. The compilers use a standard name, cl.exe, but are segregated into processor-specific directories, as shown in the following examples:

  • The path for the MIPs compiler files is 
    sdk\bin\i386\mips\...
  • The path for the ARM compiler files is 
    sdk\bin\i386\arm\...

The following compiler programs are provided in Windows CE.

  • A 32-bit C/C++ compiler used to compile and link 32-bit ARM C and C++ programs
  • A 32-bit C/C++ compiler used to compile and link 32-bit Renesas SH-4 C and C++ programs
  • A C/C++ compiler used to compile and link MIPS16, MIPS32, MIPS64 C and C++ programs
  • A C/C++ complier used to compile and link x86 C and C++ programs
