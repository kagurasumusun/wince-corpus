Sizing a Control

You can change the size of a control.

To change the size of a control

  1. Select the control.
  2. Drag the sizing handles to change the size of the control.

    Sizing handles at the top and sides change the horizontal or vertical size, and sizing handles at the corners change both horizontal and vertical size.

  3. To resize a control, one dialog unit at a time, hold down the SHIFT key and use the ARROW keys.

    As you type command text in a control, the control resizes to fit the text.

  4. Disable this function by manually resizing the control with the sizing handles.
  5. To return to the automatic resizing of a control to fit the text within it, choose Size To Content from the Layout menu.
