Compiler Error C2248

'member' : cannot access 'access' 'member' declared in class 'class'

A private or protected member of a class, structure, or union was accessed.

Possible causes

  • Attempting to access a member declared as private or protected.
  • Accessing a public member of a base class inherited with private or protected access.

Possible solutions

  • Declare the member public.
  • Access the member through a member function with public access.

Example

class X
{
public:
   int  m_pubMemb;
   void setPrivMemb( int i ) { m_privMemb = i; }
protected:
   int  m_protMemb;
private:
   int  m_privMemb;
} x;

class Y : X {} y;    // default access to X is private

void main()
{
   x.m_pubMemb;      // OK, m_pubMemb is public
   x.setPrivMemb( 0 ); // OK, uses public access function
   x.m_protMemb;     // error, m_protMemb is protected
   x.m_privMemb;     // error, m_privMemb is private
   y.m_pubMemb;      // error, Y inherits X as private
   y.setPrivMemb( 0 ); // error, Y inherits X as private
}
