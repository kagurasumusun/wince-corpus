Target Device Connectivity Options: Service Status

You can view information about the current status of the services running on the connection to a target device.

For more information about this dialog box, see Target Device Connectivity Options Dialog Box.

Target device
Identifies the target device that you have configured a connection to.

You can select a different target device to view the services associated with that connection.

Name
Displays the name of a service.
Settings
Displays the settings associated with the service.
Status
Displays the current status of the service.
