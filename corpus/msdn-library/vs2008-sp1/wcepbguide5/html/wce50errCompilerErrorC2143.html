Compiler Error C2143

syntax error : missing 'token1' before 'token2'

The compiler expected a specific token (a language element other than whitespace) and found another token instead.

Possible causes

  • The first nonwhitespace character following an if statement should be a left parenthesis. The compiler cannot translate anything else. For example, 
    if j < 25    // syntax error : missing '(' before 'j'
  • Missing closing brace, parenthesis, or semicolon on the line where the error is detected or a few lines above. For example, 
    class X
{
   int member
} x;          // error, missing ; on previous line
  • Invalid tag in a class declaration. For example, 
    class X
{
   int member;
} x;
class + {};   // error, + is an invalid tag name
  • A label not attached to a statement. If you must place a label by itself (for example, at the end of a compound statement), attach it to a null statement. For example, 
    void func1()
{
   end:      // error
}            // this line is not a statement
void func2()
{
   end:      // OK
    ;        // this label attached to null statement
}
  • Single-line comments with /Za (ANSI compatibility). 
    int i;    // syntax error : missing ';' before 'division operator'
int j;    /* no error */
  • Invalid attribute syntax. Although the following instruction is valid in a MIDL file, it is not valid in a C++ source code file. 
    typedef [public] long MEMBERID;

    Instead, you would need to issue the following: 

    [public] typedef long MEMBERID;

Check the C/C++ Language Quick Reference to determine where code is syntactically incorrect.

Because the compiler might report this error after the line that causes the problem, check the few lines of code that precede the error.
