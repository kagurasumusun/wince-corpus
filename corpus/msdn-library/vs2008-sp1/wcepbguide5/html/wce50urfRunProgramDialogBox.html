Run Program Dialog Box

This dialog box enables you to start or stop a specific executable file.

This dialog box can only be accessed when the Target Control service is running.

In addition, for run-time images built from debug configurations only, the debugger needs to be running before accessing and using the Run Program dialog box to execute a program.

Output from this dialog box is found on the Debug tab of the Output window.

This dialog box includes the following items.

Available Programs
Use to see all executables in your %_FLATRELEASEDIR% in this list box.
Execution command line
Use to see the program and arguments that are executed when the Run button is selected.

You can use the Execution command line to add arguments when starting a program.

Run Program
Use to run the program that is in the Execution command line edit box.
Cancel
Use to close the Run Program dialog box without running a program.
