Installing a Macro File

To help automate Platform Builder, you can install files that contain one or more macros. If you do not install these macros, they are not available for use.

To install a macro file in Platform Builder

  1. From the Tools menu, choose Customize.
  2. Choose the Add-ins and Macro Files tab.

    The name of the macro file appears in the window.

    If the name does not appear, choose Browse and locate the file.

  3. Select the macro file you want to install in Platform Builder.

    The IDE adds a check mark, indicating that the file is loaded. This check mark also directs the IDE to load the file the next time you start the program.

    If you clear the check mark from a macro file, the IDE unloads it. All macros in the file lose their toolbar and keystroke assignments, and the IDE does not load the macro file the next time you start the program.

If you assign a macro to a toolbar button or key sequence, you can run the macro by choosing the button or pressing the assigned keys.
