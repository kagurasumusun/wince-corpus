Defining a Mnemonic Key for a Control That Includes Command Text: Command Buttons, Check Boxes, and Radio Buttons

You can define a mnemonic key for a control that includes command text. Examples include command buttons, check boxes, and radio buttons.

To define a mnemonic key

  1. Select the control.
  2. Choose Properties from the View menu and then choose the General tab.
  3. Type an ampersand (&) in front of the letter you want as the mnemonic for that control in the Caption box.

    Underlined command text indicates the mnemonic key.
