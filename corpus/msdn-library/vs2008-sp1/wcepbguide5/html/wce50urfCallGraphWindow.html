Browse Source Windows: Call Graph Window

The Call Graph Window displays relationships among selected functions as a graph, using nodes to represent functions.

If the function is an overloaded function, or a member function of more than one class, the Resolve Ambiguity dialog box appears.

The following table describes the window elements in the Call Graph Window.

Window element Function Action
Left Pane Displays the call graph for the selected function. Click the plus or minus sign to expand or contract the graph.

To display information for a function, click the class name or folder icon.

To open the source file for a function, double-click the class name or folder icon.
Right pane Displays a list of available definitions and references for the function selected in the left pane. Double-click the definition or reference you want to see.
Pushpin Determines whether the window disappears after it loses focus. Select to push or pull the pin.
Help button Displays Help for the window. Select for Help.
