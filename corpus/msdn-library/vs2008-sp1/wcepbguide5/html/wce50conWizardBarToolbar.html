WizardBar Toolbar

The WizardBar toolbar simplifies working with classes, members, and resources.

You can perform the following tasks using the WizardBar:

  • Add a class or form
  • Create a function, including message handling functions
  • Jump to an existing function or method
  • Switch between a dialog box and the code that implements it

The WizardBar toolbar extends ClassView functionality by tracking your context, which updates what appears on the WizardBar toolbar when the focus shifts. The WizardBar toolbar displays the following changes to reflect where you have jumped:

  • When your cursor is in the text editor, the WizardBar toolbar tracks and displays the current class or C++ member function.
  • When your cursor is in a section of code, such as code comments or C++ Include statements, the display of the WizardBar toolbar Members combo box is dimmed and reflects the nearest recognizable code segment.

The WizardBar toolbar tracks all class declarations, including definitions for classes that do not contain members yet. If your cursor is closest to such a class declaration, the WizardBar toolbar combo boxes display the following information:

  • The Class combo box displays the class name.
  • The Filter combo box displays the message All Class Members.
  • The Members combo box displays the message No members – Create C/C++ Member Function.

    Selecting this message in the Members list displays the Add Member Function dialog box, which you can use to define a stub function quickly. Adding a new member function is the default action for empty classes.

In any development session, your focus can switch from the text editor to the dialog editor, to the ClassView window, and back to the text editor.

Because the WizardBar toolbar does not track your context from every location in the IDE, there are visual cues that indicate whether the WizardBar toolbar is currently in tracking mode. For example, the Action button changes color to indicate the current state of the WizardBar toolbar.

Also, the items displayed in the WizardBar toolbar combo boxes are dimmed unless the WizardBar toolbar is in tracking mode.

The WizardBar toolbar also tracks code elements within the dialog editor.

The WizardBar toolbar does not track your location in code under the following circumstances:

  • If the current file does not belong to the active project.

    If your project contains a subproject, or if you have multiple projects open in the workspace, the file that has the focus might not belong to the active project. In this case, you can change the active project.

  • If the current file is not part of the project.

    The file you are viewing might belong to a separate project in the workspace, to another workspace entirely, or it might be included in the project for building purposes without belonging to the project.

    For example, choosing Open Include File from the WizardBar toolbar Action menu provides a list of all header files that are included in the current file. These header files might or might not belong to the project.

    Opening a file does not add the file to the project. If you add the file to your project, the WizardBar toolbar tracks the members in the file.

  • If the current file is included in the project but it is not written in a programming language.

    These files include files that cannot be built, such as plain text files, and document server objects, such as Microsoft® Excel spreadsheets.

  • If the window you are in does not support context tracking.

    The WizardBar toolbar context tracking is not supported in product windows other than the text editor or the dialog editor. If the focus is on a window, such as the Output window or ClassView window, context tracking is disabled.

  • If multiple instances of the IDE are open simultaneously, and you are viewing the same active project.

    In this case, the WizardBar toolbar and the ClassView tab are available only in the first instance of the IDE you opened.

Even when the WizardBar toolbar is not tracking the location of your cursor in source code, you can use all navigational and code creation functionality that is available from the WizardBar toolbar.

Many navigational commands are available from the Action menu. You can do the following tasks using the Action menu:

  • Jump to C++ class or function definitions or declarations
  • Jump to the next or previous function or method
  • Open a C++ header file from the current project
  • Jump to the dialog editor for a class that implements a dialog box

You can also jump directly to the definition for a class member by selecting it from the Members list, or by typing it into a WizardBar toolbar combo box. Selecting a dialog resource from the Members list opens the resource inside the dialog editor.

You can also use the WizardBar toolbar to add new classes and members.
