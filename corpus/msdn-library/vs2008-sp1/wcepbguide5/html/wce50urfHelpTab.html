Platform Builder for Microsoft Windows CE 5.0  

SDK Settings Dialog Box: Help Tab

On this tab, you can configure the Help files included in the SDK.

Include custom help files in SDK
Select to include custom help files in the SDK.
Path to master CHM (compiled help) file
Type the path to the directory that contains the master help file.

This option is not available if you have not selected the Include custom help files in SDK check box.

Help file list
Choose from the following:
  • Choose Add to browse for one or more files to include in the SDK
  • Choose Delete to delete a file you want to remove.

This option is not available if you have not selected the Include custom help files in SDK check box.
