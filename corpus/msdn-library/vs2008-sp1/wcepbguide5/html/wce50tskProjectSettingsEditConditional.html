Platform Builder for Microsoft Windows CE 5.0  

Project Settings: Edit Conditional

In this dialog box, you can enter conditionals specific to the active project.

For ease of entry, Platform Builder provides a cascading menu from which you can select commonly used conditionals to insert. Choosing the arrow in this dialog box can access these conditionals.

For more information about the Project Settings dialog box and the tabs that you can select, see Project Settings Dialog Box.

The following table shows the conditional elements that you can select.

Conditional Element Description
Well-known Macros Values that you can select include the following:
  • CPU

    Specify the target CPU.

  • CPU Family

    Specify the target CPU family.

  • BSP Folder

    Specify the target board support package (BSP).

  • Project Name

    Specify the name of the current workspace.

  • OS Version

    Specify the Windows CE OS version.

  • Configuration Name

    Specify the selected configuration for your OS design.

For more information, see Miscellaneous Environment Variables.
Well-known Macro Values Values that you can select include the following:
  • CPU

    Specify the target CPU.

  • CPU Family

    Specify the target CPU family.

  • BSP Folder

    Specify the target board support package (BSP).

The values that Platform Builder displays are based on the CPUs and BSPs installed on your development workstation.

Keywords Values that you can select include the following:
  • !IF
  • !IFDEF
  • !IFNDEF
  • !ELSE
  • !ELSEIF
  • !ELSEIFDEF
  • !ELSEIFNDEF
  • !UNDEF
Logical Operators Values that you can select include the following:
  • Logical OR
  • Logical AND
  • Equals
  • Does Not Equal
