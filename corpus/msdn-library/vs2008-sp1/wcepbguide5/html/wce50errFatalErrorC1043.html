Platform Builder for Microsoft Windows CE 5.0  

Fatal Error C1043

cannot open compiler intermediate file

The compiler cannot create intermediate files for reasons that cannot be determined.

Possible solutions

  • Be sure the TMP environment variable points to a drive and directory where a file can be created.
  • Delete unneeded files in the TMP directory.
