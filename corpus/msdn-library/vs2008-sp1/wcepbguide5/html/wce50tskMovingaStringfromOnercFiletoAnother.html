Moving a String from One .rc File to Another

After you create a string, you can move it from one resource (.rc) file to another.

To move a string

  1. Open the string editor windows in both .rc files.
  2. Select the string to move.
  3. Choose Cut from the Edit menu.
  4. Place the cursor in the target string editor window.
  5. Choose Paste from the Edit menu.

If the identifier or value of the moved string conflicts with an existing identifier or value in the destination file, either the identifier or the value of the moved string changes.

If a string exists with the same identifier, the identifier of the moved string changes.

If a string exists with the same value, the value of the moved string changes.
