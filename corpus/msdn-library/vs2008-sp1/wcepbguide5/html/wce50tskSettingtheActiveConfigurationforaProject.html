Setting the Active Configuration for a Project

You can change the active configuration used for a project on the workspace or OS design level.

To set the active configuration

  1. From the View menu, choose Workspace.
  2. In the Workspace window, choose the OSDesignView tab.
  3. From the Build OS menu, choose Set Active Configuration and then select a configuration.

    – or –

    On the Build toolbar, in the Select Active Configuration list, select a configuration.

To view the Build toolbar, point to a blank area on the menu bar, right-click, and choose Build.
