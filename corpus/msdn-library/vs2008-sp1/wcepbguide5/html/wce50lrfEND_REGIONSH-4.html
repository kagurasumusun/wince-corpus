END_REGION (SH-4)

This macro marks the end of a contiguous range of text or data.

END_REGION NameEnd

Parameters

NameEnd
NameEnd labels the end of the range.

Return Values

None.

Remarks

NameEnd is in the global name space.

Requirements

Header: Kxshx.h.
