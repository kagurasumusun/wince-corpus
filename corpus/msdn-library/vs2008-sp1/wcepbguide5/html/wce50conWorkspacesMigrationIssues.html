Platform Builder for Microsoft Windows CE 5.0  

Workspaces Migration

In Microsoft® Windows CE 5.0, when you use the New Platform Wizard to create a workspace, Platform Builder creates a directory, typically in %_WINCEROOT%\PBWorkspaces, that contains an XML-based Platform Builder workspace (.pbxml) file that tracks all information about the OS design and associated user-created projects.

For information about migrating an existing OS design to Windows CE 5.0, see How to Migrate a Windows CE .NET 4.2 OS Design to Windows CE 5.0.
