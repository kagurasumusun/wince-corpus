Compiler Error C2354

'reference' : initialization of reference member requires a temporary variable

A constructor initializes a reference to a member instead of initializing the member.

It is illegal to initialize a reference member of a class in the class's constructor with a temporary variable.

An attempt to do so generates the C2354 error, as illustrated by this sample code: 

 
    {
        int member;
        Test();
 
    {

When this error is encountered, change the code so the reference member is not initialized to a temporary variable.

The reference must be initialized to an object that exists for the lifetime of the reference member.
