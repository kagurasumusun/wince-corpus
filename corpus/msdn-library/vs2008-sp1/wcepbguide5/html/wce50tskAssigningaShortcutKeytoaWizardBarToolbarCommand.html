Assigning a Shortcut Key to a WizardBar Toolbar Command

After you create a toolbar command using the WizardBar, you can assign a shortcut key to the command.

To assign a shortcut key

  1. From the Tools menu, choose Customize and then choose the Keyboard tab.
  2. In the Category list, select WizardBar.
  3. In the Commands list, select the command you want to assign the shortcut key to.

    For information about shortcut keys that can be assigned to the WizardBar toolbar commands, see Keyboard Access for the WizardBar Toolbar.

  4. Place the cursor in the Press New Shortcut Key box, press the shortcut key or key combination you want to use, and then choose Assign.

    If you press a key or key combination that is not valid, no key appears.

    You cannot assign key combinations with ESC, F1, or combinations such as CTRL+ALT+DELETE that are used by your OS.

    If you press a key or key combination that is assigned to another command, that command appears in the dialog box under Currently Assigned To.
