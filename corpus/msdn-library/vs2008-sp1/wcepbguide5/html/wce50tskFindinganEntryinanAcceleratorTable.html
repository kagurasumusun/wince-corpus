Finding an Entry in an Accelerator Table

If you have multiple entries in an accelerator table, you can use the Find function to find an entry quickly.

To find an entry

  1. Choose Find from the Edit menu.
  2. Select a previous search string from the Find What list, and then type the shortcut key to find ID_ACCEL1, for example.

    – or –

    Type a regular expression to match a pattern.

  3. Choose the button to the right of the Find What box to display a list of regular expressions.

    When you select an expression from this list, it is substituted as the search text in the Find What box. If you use regular expressions, ensure that Regular Expression is selected.

  4. Select any of the Find options.
  5. Choose Find Next.
