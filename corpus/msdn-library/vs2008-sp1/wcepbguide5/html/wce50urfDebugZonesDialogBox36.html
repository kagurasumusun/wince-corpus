Platform Builder for Microsoft Windows CE 5.0  

Debug Zones Dialog Box

This dialog box enables you to view, add, or remove settings on process and module debug zones.

This dialog box includes the following items.

Name
Use to see the modules and processes running on the target device.

The Name list box can be used to select the DLL or EXE file you want to change the debug zones for.

Debug Zones
Use to do the following:
  • When the target is running, select for a debug zone you want to enable.
  • Clear to disable a zone.

Enabling and disabling take place immediately.

When target or Target Control is not running, or at a debug break, debug zones cannot be viewed or changed.

Close
Use to close the dialog box saving changes.
