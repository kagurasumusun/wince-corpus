Selecting Multiple Controls

You can select multiple controls.

To select multiple controls

  1. Select the pointer on the Controls toolbar.
  2. Drag the pointer to draw a selection box around the controls you want to select.

    Controls partially outside the selection box are not selected.

    When you release the left mouse button, all controls inside the selection box are selected.

    After you select one or more controls, you can add or remove individual controls without disturbing the selection as a whole. To do this, hold down the SHIFT key and select the control to remove it from the selection or add it to the selection.
