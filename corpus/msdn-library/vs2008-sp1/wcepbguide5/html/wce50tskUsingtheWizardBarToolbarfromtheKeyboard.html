Using the WizardBar Toolbar from the Keyboard

You can access WizardBar toolbar commands using the keyboard.

To use the WizardBar toolbar from the keyboard

  1. Press the shortcut key for the WizardBar toolbar functionality you want to access.

    The focus is on the UI element. If the UI element is a combo box, such as Class, Member, or Filter, the list opens to display available functions.

  2. Depending on which UI element the focus is on, choose one of the following actions:
    • In a combo box, press the DOWN ARROW or type the function name in the combo box to select a function; then press ENTER to execute it.
    • From the Action menu, press ENTER to carry out the default action immediately.
    • From the Action menu, press the DOWN ARROW to select an action; then press ENTER to execute it.

    When the focus is on the Action menu, it has a gray, dotted outline.
