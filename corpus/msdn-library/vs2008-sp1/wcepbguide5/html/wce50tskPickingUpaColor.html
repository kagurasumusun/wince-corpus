Picking Up a Color

You can pick up a color from the current graphic.

To pick up a color

The Color Pickup tool makes any color on the graphic the current foreground color or background color, depending on whether you click the left or right mouse button. To cancel the Color Pickup tool, choose another tool.

  1. Choose the Color Pickup tool from the Graphics toolbar.
  2. Select the color to pick up from the graphic.

    After you pick up a color, the graphics editor reopens the most recently used tool.

  3. Draw using the left mouse button for the foreground color or the right mouse button for the background color.
