Platform Builder for Microsoft Windows CE 5.0  

Searching and Replacing Commands

The following table shows Epsilon searching and replacing command emulation.

Epsilon command Platform Builder text editor command
incremental-search SearchIncremental
reverse-incremental-search SearchIncrementalBack
regex-search FindRegExpr
reverse-regex-search FindRegExprPrev
grep FileFindInFiles
next-match FindNext
previous-match FindPrev
replace-string FindReplace
query-replace FindReplace
regex-replace FindReplaceRegExpr
word-mode, regular-expression-mode, case-sensitive-mode, and incremental-mode (These commands are available only in incremental search mode, and not in dialog mode. The commands cannot be bound to any keys.)
