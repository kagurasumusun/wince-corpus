Platform Builder for Microsoft Windows CE 5.0  

/WINDOWSCE

This specification is passed to CVTRES. The EMULATION convert argument is used for building a desktop Windows CE application that runs under the emulator. CONVERT forces bitmaps to be converted to grayscale, as was used by Windows CE 1.0.

/WINDOWSCE:{CONVERT|EMULATION}
Note   Setting level to 0 does not disable warning messages.
