Compiler Error C2202

'function' : not all control paths return a value

Some paths through the function do not return a value.

Example

int func1( int i )
{
   if( i ) return 3;  // error, nothing returned if i == 0
}

To fix this error, modify the code so that all paths assign a return value:

int func1( int i )
{
   if( i ) return 3;
   else return 0;     // OK, always returns a value
}

A function can be a function that never returns, as in the following example: 

int gloo()
{
   if(...)
  return 1;
   else if(...)
  return 0;
   else
  fatal();
}

This code also generates an error, because the compiler does not know that fatal never returns.

To prevent this code from generating an error message, declare fatal using __declspec(noreturn).
