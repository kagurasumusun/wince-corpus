Changing the Properties of Multiple Shortcut Keys

You can change the properties of multiple shortcut keys.

To change the properties of multiple shortcut keys

  1. Select the shortcut keys you want to change.

    To select multiple shortcut keys, hold down the CTRL or SHIFT key while selecting shortcut keys.

  2. Choose Properties from the View menu.

    The Multiple Selection Properties dialog box appears. Changes you make on this page are reflected on each item selected.

  3. If you need to undo a change, choose Undo from the Edit menu.

    The change is undone on each item selected.
