Creating a New Resource from a Template

You can use a template to create a new resource.

To create a new resource from a template

  1. From the Project menu, choose Insert and then choose Resource.
  2. Select a resource type and then double-click the resource icon to create a default resource template object.

    – or –

    Expand the resource node to navigate the hierarchy of customized template files that are children of that resource; then double-click the specific template file to create a new resource based on that customized template.
