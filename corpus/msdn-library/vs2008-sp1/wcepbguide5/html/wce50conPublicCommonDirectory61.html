Platform Builder for Microsoft Windows CE 5.0  

Public Common Directory

The Common directory contains the following:

  • Windows CE OS component files, supplied by Microsoft, that are common to all Windows CE OS designs.
  • Directories that contain the platform-independent libraries supplied by Microsoft.

The Common directory contains the following directories.

Directory Contents
Cesysgen Files used to build the selected Windows CE modules and components.
DDK Header files for the driver development kit (DDK).
OAK OS component files.
SDK SDK component files.
