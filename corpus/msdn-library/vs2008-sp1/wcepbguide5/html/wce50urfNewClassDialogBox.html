Platform Builder for Microsoft Windows CE 5.0  

New Class Dialog Box

This dialog box enables you to add a new class to an existing project, and includes the following items.

Class type
Select to show the class type.

Currently, Platform Builder has only one class type, Generic Class.

Name
Use to type the name of the class.
File Name
Select to display the name of the implementation file for the class name you enter.
Change
Select to enter different file names for the class.
Derived from
In the Derived From column, click to enter the base class that the new base class is derived from.
As
Use to specify the type of inheritance for a base class.

In the As column, click on an entry to change; then click the DOWN ARROW to select the type of inheritance (public, private, or protected) for that base class.

OK
Click to process your selection and close the dialog box.
Cancel
Click to close the dialog box without saving changes.

Change Files Dialog Box

When you choose Change in the New Class dialog box, the Change Files dialog box appears, with the following items .

Header File
Use to enter a header file name.
Browse
Select to locate a file.
Implementation File
Use to enter an implementation file name.
Browse
Select to locate an existing file.
