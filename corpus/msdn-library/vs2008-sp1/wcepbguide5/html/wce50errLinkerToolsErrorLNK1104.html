Platform Builder for Microsoft Windows CE 5.0  

Linker Tools Error LNK1104

cannot open file "filename"

The tool could not open the given file.

Possible causes

  • Not enough disk space.
  • File does not exist.
  • Incorrect filename or path.
  • Invalid drive specification.
  • Insufficient file permissions.
  • Path for filename expands to more than 260 characters.
  • If the file is named LNKn, which is a filename generated by the linker for a temporary file, the directory specified in the TMP environment variable might not exist, or more than one directory is specified for the TMP environment variable. (Only one directory path should be specified for the TMP environment variable.)
  • If the error occurs on the executable filename, an earlier version of the executable might still be running. Terminate the executable before linking it.

    In Microsoft® Windows NT®, Windows® 95, or Windows 98 you can use the utility Process Viewer to look for and stop instances of the application. Pview95.exe is shipped with Microsoft eMbedded Visual C++®.

  • If the error message occurs for a library name, and you recently ported the .mak file from a previous eMbedded Visual C++ development system, the library might not be valid. Make sure the library exists.
  • The compiler might be inserting linker directives into the object files.

    The compiler inserts a linker directive for the static portion of the C runtime library (Libc.lib) to match the model you are compiling for.

    It can also insert linker directives into an object file as a result of a #pragma comment directive, which is used frequently in Active Template Library (ATL) for Windows CE and Microsoft Foundation Classes (MFC) for Windows CE.

    A typical #pragma comment directive is shown in the following code example. 

    #pragma comment(lib, "comctl32.lib")

    To cause the linker to ignore embedded linker directives it finds, do the following:

    1. From the Project menu, choose Settings.
    2. Choose the Link tab.
    3. From the Category list, select General.
    4. Set Ignore All Default Libraries.

    An alternate solution is to select Input from the Category list and add Libc.lib to the Ignore Libraries box.
