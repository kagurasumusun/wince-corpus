Platform Builder for Microsoft Windows CE 5.0  

Fatal Error C1034

file: no include path set

The INCLUDE environment variable is not set.

To set the INCLUDE variable in eMbedded Visual C++

  1. From the Tools Menu, click Options.
  2. In the Options dialog box, select the Directories tab.
  3. In the Show Directories For box, select Include Files.
  4. In the Directories box, enter the path for include files.

To set the INCLUDE variable from the command line

  • Run the VCVARS32.bat batch file.
