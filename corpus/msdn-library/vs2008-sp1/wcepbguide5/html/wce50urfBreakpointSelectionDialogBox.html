New Breakpoint Dialog Box: Breakpoint Selection Dialog Box

Use this dialog box to specify a hardware or software breakpoint.

The following options are available.

Note   When choosing an option other than Default, the breakpoint is not instantiated if the requested breakpoint type is not available.
Hardware
Sets a hardware breakpoint.
Note   This button is enabled only while eXDI Hardware-Assisted Debugging is available.
Software
Sets a software breakpoint.
Default
Allows the debugger to instantiate the appropriate breakpoint type, depending on the availability of system resources.
OK
Processes your input and moves to the next step.
Cancel
Closes the dialog box without saving changes you made.
