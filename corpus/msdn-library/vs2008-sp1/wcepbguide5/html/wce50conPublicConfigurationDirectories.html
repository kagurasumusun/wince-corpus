Platform Builder for Microsoft Windows CE 5.0  

Public Configuration Directories

The Public directory contains a group of directories that contain configuration information for the Windows CE OS.

Each configuration directory contains the batch file that defines the environment variables for an OS design, and the Build Demo tool, Blddemo.bat, which is used to build the demonstration object files and Cesysgen.bat.

The Files directories in the configuration directories contain binary image builder (.bib) and registry (.reg) files.
