Renesas Technology Guide

Renesas Technology designs and manufactures high-performance, power-efficient RISC microprocessors.

The Renesas SuperH RISC core uses a fixed 16-bit instruction length for improved efficiency, load-store architecture with 16 32-bit general-purpose registers, and a 5-stage pipeline that executes one instruction per clock cycle.

Renesas optimizes each processor family for specific applications.
