Creating a New Window for an Open Source File

You can create a new window for a source file that is open.

To create a new window for a source file that is open

  1. Switch to the source window.
  2. From the Window menu, choose the New Window command.

    A second copy of the source file is displayed with a suffix that shows the number of source windows that are open. As you open more windows showing the source file, the suffix value increases.

    You can scroll and split each window independently.

    You can make changes to the source file from any window.

    When you first open a file, if you select the Open as Read-Only check box in the Open dialog box, the current window and any split windows remain read-only.
