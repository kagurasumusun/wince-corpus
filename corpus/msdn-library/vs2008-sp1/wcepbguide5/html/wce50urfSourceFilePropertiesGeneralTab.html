Platform Builder for Microsoft Windows CE 5.0  

Source File Properties: General Tab

Use this tab to configure settings for a source file.

File name
The name of the current source file.
Language
The programming language associated with the file extension.

You can select a different language by clicking the one you want on the drop-down list.

Size
The size of the file in both bytes and lines.
Saved
The time and date the file was last saved.
Tab size
The number of space characters that equals one tab character.

You can change the size by typing a different number in the box.

Indent size
The number of space characters used to indent a line.

You can change the indent size by typing a different number in the box.
