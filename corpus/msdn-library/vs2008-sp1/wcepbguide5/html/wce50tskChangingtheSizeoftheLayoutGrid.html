Changing the Size of the Layout Grid

After you turn the layout grid on, you can change the intervals used in the grid spacing.

To change the size of the layout grid

  1. Choose Guide Settings from the Layout menu.
  2. Type the width and height in dialog units for the cells in the grid in the Width and Height boxes under Grid Spacing.

    The minimum width or height is 4 dialog units.
