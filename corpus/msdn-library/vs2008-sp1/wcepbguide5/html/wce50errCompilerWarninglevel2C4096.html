Compiler Warning (level 2) C4096

'Attribute1' must be used with 'Attribute2'

Attribute2 requires Attribute1. For example:

  • Functions with a variable number of arguments require __cdecl.
  • __interrupt functions require __far and __cdecl.

The compiler applies the missing required attribute.

Example

#include <oledlg.h>

The line above generates the following warning when compiled with /Gr:

d:\msdev4\include\oledlg.h(1689): warning C4096 '__cdecl' must be used with '...'

/Gr sets the default calling convention to __fastcall. Because CDECL in the prototype is defined to nothing, the warning points to the location of the prototype:

int EXPORT FAR CDECL OleUIPromptUserA(int nTemplate, HWND hwndParent, ...)

To fix this example, add the following preprocessor directive to the project:

#define DOSWIN32

which defines CDECL properly.
