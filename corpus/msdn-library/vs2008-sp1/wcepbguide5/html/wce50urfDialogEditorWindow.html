Platform Builder for Microsoft Windows CE 5.0  

Dialog Editor Window

Use the Dialog Editor window to complete the following tasks:

  • Create dialog boxes
  • Place and arrange controls
  • Test the finished dialog box
  • Add ActiveX controls
  • Import Microsoft® Visual Basic® forms to a dialog box resource
  • Save dialog boxes as templates for future dialog boxes.

For easier layout, guides or a grid helps align groups of controls.

You can right-click this window to display a shortcut menu of commands.
