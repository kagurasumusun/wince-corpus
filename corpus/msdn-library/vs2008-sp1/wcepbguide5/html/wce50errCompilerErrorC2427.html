Compiler Error C2427

'identifier' : jump referencing label is out of range

A branch to the specified label contains code that cannot be jumped over.

Example

        jz label1
        inc EAX

label1: inc ECX

In this example, fix the error by removing extra code between the branch and the label, or by inverting the jump:

        jnz label2
        jmp label1
label2: inc EAX

label1: inc ECX
