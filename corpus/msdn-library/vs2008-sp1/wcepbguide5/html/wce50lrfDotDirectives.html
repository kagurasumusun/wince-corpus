Dot Directives

Specify dot directives outside a description block, at the start of a line.

Dot directives begin with a period (.) and are followed by a colon (:).

Spaces and tabs are allowed.

Dot directive names are case-sensitive and are uppercase.

The following table shows the dot directives used by Nmake.exe.

Directive Description
.IGNORE : Ignores nonzero exit codes returned by commands, from the place it is specified to the end of the .mak file.

By default, Nmake.exe stops if a command returns a nonzero exit code.

To restore error checking, use !CMDSWITCHES.

To ignore the exit code for a single command, use the hyphen (-) modifier.

To ignore exit codes for an entire file, use /I.

.PRECIOUS : targets Preserves targets on disk if the commands to update them are stopped; has no effect if a command handles an interrupt by deleting the file.

Separate the target names with one or more spaces or tabs.

By default, Nmake.exe deletes a target if a build is interrupted by CTRL+C or CTRL+BREAK.

Each use of .PRECIOUS applies to the entire .mak file; multiple uses are cumulative.

.SILENT : Suppresses display of executed commands, from the place it is specified to the end of the .mak file.

By default, Nmake.exe displays the commands it invokes.

To restore echoing, use !CMDSWITCHES.

To suppress echoing of a single command, use the @ modifier.

To suppress echoing for an entire file, use /S.

.SUFFIXES : list Lists extensions for inference-rule matching; predefined as .exe, .obj, .asm, .c, .cpp, .cxx, .bas, .cbl, .for, .pas, .res, and .rc

To change the .SUFFIXES list order or to specify a new list, clear the list and specify a new setting.

The following code example shows how to clear the list by specifying no extensions after the colon.

.SUFFIXES :

The following example shows the syntax for adding suffixes to the end of the list.

.SUFFIXES : SuffixList

The value for SuffixList is a list of the additional suffixes, separated by one or more spaces or tabs. To see the current setting of .SUFFIXES, run Nmake.exe with /P.
