Platform Builder for Microsoft Windows CE 5.0  

Fatal Error C1081

'symbol': file name exceeds number bytes in length

The length of a file pathname exceeds _MAX_PATH (defined by STDLIB.h as 260 characters).

Possible cause

  • If you call CL.exe with a short filename, the compiler might need to generate a full pathname. For example, cl -c myfile.cpp might cause the compiler to generate the following: 
    D:\<very-long-directory-path>\myfile.cpp
