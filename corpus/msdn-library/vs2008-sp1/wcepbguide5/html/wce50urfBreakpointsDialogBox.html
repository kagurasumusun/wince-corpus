Platform Builder for Microsoft Windows CE 5.0  

New Breakpoint Dialog Box

Use this dialog box to set breakpoints for the open program.

The following options are available.

Tab Description
Location Tab Choose to enter the location where you want to set a breakpoint.
Data Tab Choose to enter a variable or expression that determines whether the debugger stops at a breakpoint.
Messages Tab Choose to enter a message you want to break on.
OK
Processes your input and closes the dialog box.
Cancel
Closes the dialog box without saving changes you made.
