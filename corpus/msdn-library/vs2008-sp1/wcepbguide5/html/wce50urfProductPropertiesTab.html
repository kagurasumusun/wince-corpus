Platform Builder for Microsoft Windows CE 5.0  

SDK Settings Dialog Box: Product Properties Tab

On this tab, you can configure the properties for your software development kit (SDK).

Product name that is displayed when .msi file runs
Type or select the product name that will appear in the Windows Installer dialog boxes for the SDK at installation time.
Manufacturer name
Type the name of the product manufacturer.
Locale language
Choose the locale of the SDK from the list.
Product version
Type the product version major number, minor number, and (if available) build number.
