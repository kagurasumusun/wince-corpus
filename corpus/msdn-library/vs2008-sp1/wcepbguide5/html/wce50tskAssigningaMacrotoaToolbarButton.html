Assigning a Macro to a Toolbar Button

You can assign a macro to a toolbar button for quicker access in the IDE.

To assign a macro to a toolbar button

  1. From the Tools menu, choose Customize.
  2. Choose the Commands tab.
  3. In the Category list, select Macros.
  4. From the Commands box, drag the macro name to the toolbar where you want a button for the macro.
  5. Under Images in the Button Appearance dialog box, select an image for the toolbar button and choose OK.

    The IDE adds a button with that image to the toolbar.
