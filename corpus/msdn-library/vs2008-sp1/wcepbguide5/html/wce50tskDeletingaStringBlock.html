Deleting a String Block

You can delete a string block from a version information resource

To delete a string block

  1. With a version information resource open, select one of the block headers.
  2. Choose Delete Version Info Block from the Insert submenu of the Project menu.
  3. Choose OK.

This command deletes the selected header and leaves the remaining version information intact.
