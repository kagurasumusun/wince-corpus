Platform Builder for Microsoft Windows CE 5.0  

Target Device Connectivity Options Dialog Box

This dialog box enables you to configure connection settings between the development workstation and the target device.

After you configure a connection, you can download run-time images to the target device, which can be the Emulator, a CEPC, or another physical device.

The left side of the window is divided into two sections that control the options displayed on the right side.

Device Configuration
Links that enable you to add or delete connections to target devices from the list that Platform Builder has configured.

For more information, see Target Device Connectivity Options: Add Device and Target Device Connectivity Options: Delete Device.

Service Configuration
Links that enable you to configure kernel services and core services, and to view the status of these services.

For more information, see Target Device Connectivity Options: Kernel Service Map, Target Device Connectivity Options: Core Service Settings, and Target Device Connectivity Options: Service Status.
