Using the Fill Tool

The graphics editor provides the Fill tool for filling an enclosed graphic area with the current drawing color or the current background color.

To use the Fill tool

  1. Choose the Fill tool from the Graphics toolbar.
  2. If necessary, choose drawing colors.

    Click the left mouse button to select a foreground color or the right mouse button to select a background color from the Colors palette.

  3. Move the Fill tool to the area to fill.
  4. Click the left or right mouse button to fill with the foreground color or the background color, respectively.
