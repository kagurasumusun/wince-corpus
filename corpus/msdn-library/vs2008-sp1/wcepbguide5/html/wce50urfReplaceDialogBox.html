Replace Dialog Box

This dialog box enables you to replace text or regular expressions in the currently open file.

The dialog box includes the following items.

Find What
Use to type the string or the regular expression to match.

You can use the menu button at the right of the drop-down list to display a list of regular search expressions.

When you select an expression in this list, the expression is substituted as a string in the Find What text box.

If you use regular expressions, be sure the Regular Expression check box is selected.

You can also use the drop-down list to select from a list of up to 16 previous search strings.

For more information on regular expressions, search on "regular expression" in the Index.

Replace with
Use to type or select the text or tagged expression to replace the string or regular expression found.

You cannot use regular expressions in this string.

The menu button at the right of the list box brings up a list of tagged expressions.

Match whole word only
Select to find text strings that match the Find What string and are preceded and followed by a space, tab, or punctuation character, or at the start or end of a line.

Otherwise, the search finds any matching string, whether it is a fragment of a larger string or not.

Match case
Select to find only the text strings that exactly match the case of the characters in the Find What string.

Otherwise, the command finds strings with either uppercase or lowercase characters that match the characters in the Find What string.

Regular expression
Select to use regular expressions in the Find What text box.
Replace in
Choose from the following:
  • Select Selection to replace strings in the current selection only.
  • Select Whole file to replace strings in the entire file.
Find Next
Click to repeat the most recent find operation specified by the values displayed in this dialog box.
Replace
Click to replace the currently selected string with the string specified in the Replace with text box.
Replace all
Click to replace all strings that match the Find What string automatically, without requiring confirmation for each replacement.
Cancel
Click to close this dialog box without saving changes.
