Selection Margin

The selection margin is an area to the left of each line of text. The selection margin is used to show breakpoints, temporary bookmarks, current and caller line, and error line. When the cursor is moved into the selection margin, the pointer changes direction.

The following table shows how to use the selection margin.

To Do the following
Select the entire line to the right of the pointer Click in the selection margin.
Select multiple consecutive lines Click in the selection margin and move the pointer.
Extend a selection Click in the margin and move the pointer while pressing SHIFT.
Select an entire file Click anywhere in the margin while pressing CTRL. This is equivalent to choosing the Select All command from the Edit menu.
