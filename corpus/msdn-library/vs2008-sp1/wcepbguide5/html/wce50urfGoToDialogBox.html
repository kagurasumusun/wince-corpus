Platform Builder for Microsoft Windows CE 5.0  

Go To Dialog Box

This dialog box enables you to set links to particular types of expressions, and includes the following items.

Pushpin button
Choose to keep this dialog box open on your desktop, on top of all other windows. Choose again to cancel this functionality.

This dialog provides the following items.

Go to what Text box label says Available when
Address Enter address expression The debugger is running and the Memory or Disassembly window has the focus.
Bookmark Enter bookmark name You have previously created a bookmark.
Definition Enter identifier A workspace containing one or more OS designs is open.
Error/Tag Enter error/tag The Build tab of the Output Window reports build errors, or when either Find in Files tab contains the results of a search.
Line Enter line number A text file is open.
Offset Enter offset A binary file is open.
Reference Enter identifier A workspace containing one or more OS designs is open.
Go to
Use to go directly to the item displayed in the Go to what list and the Go to that edit box.

For example, if you select Line in the Go to what list and enter 180 in the Go to that edit box, you move in the current document to line 180.

(Go To is not available for Bookmark and Error/Tag.)

Next
Use to go directly to the next item of the type selected in the Go to what list.

For example, if Bookmark is selected in the list box, click Next to move to the next bookmark in the current document.

(Next is only available for Bookmark and Error/Tag.)

Previous
Use to go directly to the previous item of the type selected in the Go to what list.

For example, if Bookmark is selected in the list box, click Previous to go to the previous bookmark in the current document.

Close
Use to close the dialog box.
