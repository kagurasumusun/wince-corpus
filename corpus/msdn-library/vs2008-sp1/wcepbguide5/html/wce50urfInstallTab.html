Platform Builder for Microsoft Windows CE 5.0  

SDK Settings Dialog Box: Install Tab

On this tab, you can select installation options for the SDK that you create.

SDK target directory path
Type the path for the directory where the SDK will be created.
OS Design Name
Type the OS design name for the SDK.
MSI file name
Type the name of the Microsoft Installer (.msi) file to be used.

By default, the SDK is named <OS Design Name>_SDK.msi.

Compress files into the MSI database file (more compact)
Select if you want files to be compressed
Leave files uncompressed in installation subfolder (faster)
Select if you want files to remain uncompressed.
Launch MSI installation file after successful build
Select if you want the SDK installed on the build machine.
