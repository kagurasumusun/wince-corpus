Platform Builder for Microsoft Windows CE 5.0  

Debug Message Options Dialog Box

This dialog box enables you to customize the debug messages that Platform Builder displays when you are debugging and testing a run-time image that has been downloaded to and booted on a target device.

Timestamps
Select to display a time stamp for the target messages on the Debug tab of the Output Window.
Process IDs
Select to display process identifiers for the target messages on the Debug tab of the Output Window.
Thread IDs
Select to display thread identifiers for the target messages on the Debug tab of the Output Window.
Send to Output Window
Select to display logging in the Output Window.
Append new line
Select to append a new line to an output message before displaying it in the Output Window or sending it to the output file.
Send to file
Use to specify the file and location where logging should be saved.
