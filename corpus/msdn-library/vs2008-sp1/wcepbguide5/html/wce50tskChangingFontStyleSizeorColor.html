Changing Font Style, Size, or Color

You can change the font style, size, or color used in a selected text editor.

To change font style, size, or color

  1. From the Tools menu, choose Options.
  2. Choose the Format tab.
  3. In the Category box, select the window in which you want to change font formatting.
  4. Select the font you want in the Font list.

    The Font list displays the different fonts installed on your system. The text sample in the sample box changes to the font that you select.

  5. Select the font size you want in the Size list.

    The Size list displays the sizes available for the selected font. The text sample in the sample box changes to the size that you select.

  6. Select the type of text you want to color in the Colors list.
  7. Select a foreground color in the Foreground list.
  8. Select a background color in the Background list.

    The Foreground and Background lists display the 16 standard colors and the Automatic setting. The text sample displayed in the Sample box changes to the color that you select.

  9. Choose OK.
