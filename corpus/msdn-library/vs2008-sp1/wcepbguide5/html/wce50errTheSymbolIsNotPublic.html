The Symbol Is Not Public

The OBJ PST table contains only global functions and variables. An "Unresolved Externals" might result if you try to access static functions or variables.

Functions declared with the static modifier, by definition, have file scope. Static variables have the same limitation.

Trying to access static variables from outside of the file in which they are declared can result in a compile error or an unresolved external, depending on the specific coding of the source files.

MAIN.CPP

extern void func1(void);

void main(void)
{
 func1(); 
}

TEST.CPP

static void func1(void)
 {
  //Do something
 }
