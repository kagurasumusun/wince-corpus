Fatal Error C1024

cannot open include file filename

The preprocessor cannot find or open a file specified in an #include directive or the compiler has run out of file handles.

Running out of file handles commonly occurs when include files are deeply nested.

Other possible causes

  • Incorrect filename in the #include directive. Make sure the name is spelled correctly and the file extension is correct.
  • If you compile from the command prompt, the INCLUDE environment variable might be invalid or contain an incorrect path.
  • If you compile in the eMbedded Visual C++ environment, the Include Files directories might be set incorrectly. From the Tools menu, select the Options dialog box and check the Directories tab.
  • If you access include files over a network, the server might be unavailable or you might lack read permission. You might need to reboot your machine to reset the network interface card.

To increase the number of file handles available to the compiler

  • Close other files and applications.
  • Increase the number of file handles the OS makes available to applications.
  • Reduce the nesting of include files.
