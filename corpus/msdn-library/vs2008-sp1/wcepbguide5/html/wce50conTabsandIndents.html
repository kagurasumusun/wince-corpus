Tabs and Indents

You can set tab and indent properties to make it easier to create a source file or document. Auto Indent indents your source code using the default tab and indent sizes set in the Tabs tab. Smart Indent indents the opening and closing braces in your source code.

When you press the TAB key, the insertion point moves to the next indent level. You can display or hide nonprinting characters, including the tab, by selecting Advanced from the Edit menu, and then selecting View Whitespace.

You can also use Auto Indent, without Smart Indent, to automatically indent new lines to match the previous line.

The File Type box on the Tabs tab contains a list of file types. The initial tab settings for each file that you load are assigned based on the file name extension and the setting of this box.

You can use the Tab Size and Indent Size boxes on the Tabs tab or on the Source File property page to specify individual settings for these two fields on a per-file basis, as needed.
