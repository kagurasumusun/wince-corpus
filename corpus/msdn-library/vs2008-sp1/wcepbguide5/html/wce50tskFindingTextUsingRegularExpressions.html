Finding Text Using Regular Expressions

You can use regular expressions to find text in a file.

To use regular expressions to find text

  1. Choose either Find or Replace from the Edit menu.
  2. Type a regular expression in the Find What text box.
  3. Choose the right-pointing arrow to the right of the text box to display a list of regular search expressions.

    When you choose an expression from this list, the expression is substituted as the search string in the Find What text box. If you use regular expressions, ensure that Regular Expression is selected.

  4. In the Replace With text box, type a regular expression, if required.
  5. Start the search by choosing Find Next, Mark All, Replace, or Replace All.
