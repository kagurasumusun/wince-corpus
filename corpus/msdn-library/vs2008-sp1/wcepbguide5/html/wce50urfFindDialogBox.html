Find Dialog Box

This dialog box enables you to search in the selected open files.

The dialog box includes the following items.

Find what
Enter the string or regular expression to match.

You can use the right-arrow button at the right of the drop-down list to display a list of regular search expressions.

When you select an expression in this list, the expression is substituted as a string in the Find what text box and the Regular Expression option is automatically selected.

You can also use the drop-down list to select from a list of up to 16 previous search strings.

Match whole word only
Select to find text strings that match the Find What string and are preceded and followed by a space, tab, or punctuation character, or at the start or end of a line.

Otherwise, the search finds any matching string including fragments of larger strings.

Match case
Select to find only the text strings that exactly match the case of the characters in the Find what string.

Otherwise, the command finds strings with either uppercase or lowercase characters that match the characters in the Find What string.

Regular expression
Select to use regular expressions in the Find What text box.

A regular expression is a search string that uses special characters to match a text pattern in a file.

Search all open documents
Select to search in all documents currently open.
Direction
Choose from the following:
  • Select Up to search from the current cursor position to the beginning of the file, and then from the end of the file back to the current cursor position.
  • Select Down to search from the current cursor position to the end of the file, and then from the beginning of the file back to the current cursor position.
Find Now
Use to begin the find operation specified by the values in this dialog box.
Mark all
Select to place a bookmark on all instances of the word or expression in the Find What box.
Cancel
Choose to close this dialog box without saving changes.
