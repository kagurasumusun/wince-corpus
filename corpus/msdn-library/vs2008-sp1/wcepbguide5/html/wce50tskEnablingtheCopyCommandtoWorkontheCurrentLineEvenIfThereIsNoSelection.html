Enabling the Copy Command to Work on the Current Line Even If There Is No Selection

You can enable the Copy command to work on the current line even if there is no selection.

To enable the Copy command

  1. From the Tools menu, choose Options.
  2. Choose the Compatibility tab, and then select Enable Copy Without Selection.

    This enables the Copy command to work on the current line if there is no selection.
