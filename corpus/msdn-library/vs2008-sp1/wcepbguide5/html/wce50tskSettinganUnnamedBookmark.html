Setting an Unnamed Bookmark

In a file, you can set an unnamed bookmark.

To set an unnamed bookmark

  1. Move the insertion point to the line where you want to set a bookmark.
  2. Use the key combination you have chosen to invoke the BookmarkToggle command.

    The line is selected, or marked in the margin if you have set the selection margin.
