Export Wizard

The Export Wizard guides you through the process of selecting .cec files or user projects for export to a Microsoft® Windows Installer (.msi) file.

This process includes the following steps:

  1. Selecting which Catalog items to export from the Catalog.
  2. Selecting which associated directories or files to export.

For more information, see Exporting Items from the Catalog.
