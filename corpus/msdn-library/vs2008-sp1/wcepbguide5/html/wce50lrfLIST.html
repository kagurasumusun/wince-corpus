Platform Builder for Microsoft Windows CE 5.0  

LIST

Writes the defect log to the console.

prefast LIST filtername
prefast LIST logfile
prefast /LOG=logfile LIST

Parameters

filtername
Specifies the use of the filter preset to apply to the Message List window.
logfile
Specifies a location for the defect log file.

If nothing is specified, a default location is used.
