Browse Source Windows: Definitions and References Window

The Definitions and References window displays symbol information about the active project.

The following table shows the window elements, their functions, and the user's actions.

Window element Function Action
Left pane Displays the selected symbol or a list of matching symbols if you used a wildcard.

If the symbol is not fully qualified, it is followed by the symbol's type.

 To display information for a symbol, select the symbol name.

To open the source file for a symbol, double-click the class name or folder icon.
Right pane Displays definitions and references for the symbol selected in the left pane. Double-click the definition or reference you want to see.
Pushpin Determines whether the window disappears after it loses focus. Select to push or pull the pin.
Help button Displays Help for the window. Select to open Help.
