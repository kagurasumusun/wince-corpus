Setting a Text Editor Emulation

You can set the emulation that Platform Builder uses for a text editor.

To set the emulation for a text editor

  1. Choose Options from the Tools menu.
  2. Choose the Compatibility tab.
  3. Select the text editor that you wish to emulate in the Current Source Editor Emulation box.

    The default text editor is the one included with the IDE.

  4. Clear or select the appropriate check box to change the status of predefined text editor options in the Options area.
  5. Choose OK.
