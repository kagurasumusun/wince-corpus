Platform Builder for Microsoft Windows CE 5.0  

Insert Resource Dialog Box

This dialog box enables you to import or create a custom resource, and includes the following items.

Resource type
Use to select the type of resource you want to create or import.
New
Click to create the selected resource and begin editing.

The resource opens inside the appropriate editor, in the right pane of the workspace.

For example, creating a new dialog resource opens it inside the dialog editor.

Import
Click to import an existing resource file from another location to your open project.
Custom
Click to add a custom resource to the current resource file.

Custom resources can be edited in the binary editor only.

Cancel
Click to close without saving changes.
