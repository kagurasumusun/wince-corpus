Adding a Default Menu to a Toolbar

You can add a default menu to a toolbar.

To add a default menu to a toolbar

  1. Display the toolbar that you want to add the default menu to.
  2. From the Tools menu, choose Customize and then choose the Commands tab.
  3. In the Category list, select Menus.
  4. Drag the menu from the Commands box to the toolbar.
