Sorting Members in a Class

By default, ClassView groups the members that are displayed under a class in alphabetical order; however, you can also group class members by their access specifier. These specifiers are private, protected, or public.

The sort order applies to all classes in all projects in the workspace.

To sort members in a class

  1. Choose a class member node in a project.
  2. Right-click to display the context menu.
  3. Choose Group By Access to switch the grouping.

    If the command is selected, the members are grouped by access specifier. If not, they are grouped alphabetically.
