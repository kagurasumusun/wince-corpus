Platform Builder for Microsoft Windows CE 5.0  

Customize Dialog Box: Toolbars Tab

This tab includes the following settings that you can use to configure toolbars and menus in Platform Builder.

Toolbars
Use to see standard and custom toolbars.

When this is selected, the toolbar is displayed. Otherwise, the toolbar is hidden.

The menu bar cannot be hidden, except when you edit in full-screen mode.

Toolbar name
Use to see the name of the custom toolbar selected in the Toolbars list.

You can edit the name by typing in the text box.

Show ToolTips
Select to display on-screen descriptions of toolbar buttons when you float your cursor over the button.
With shortcut keys
Select to display the shortcut key in the ToolTip for a toolbar button (if one is available).
Large buttons
Use to enlarge toolbar buttons so they are easier to see.

This is especially useful when giving presentations or for those who have impaired vision.

New
Use to create a custom toolbar.
New Toolbar Dialog Box
Use to enter the name of the toolbar.
Delete
Use to deletes a selected custom toolbar.
Reset
Use to reset the selected default toolbar to its original settings.
Reset All
Use to reset all default toolbars to the original settings.
