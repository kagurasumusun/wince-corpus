Resource Symbols: Change Symbol Dialog Box

Use this dialog box to change the name or value of a symbol.

The dialog box contains the following items.

Used by
Use to see the resources using the symbol selected in the symbols list.
View Use
Use to open the resource that contains the symbol in the corresponding resource editor.
Cancel
Use to close the dialog box without saving changes.
