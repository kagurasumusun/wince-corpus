Platform Builder for Microsoft Windows CE 5.0  

Public Wceappsfe Directory

The Wceappsfe directory contains files that support the Windows CE–based application modules, which are Microsoft WordPad for Windows CE and Microsoft Outlook® Mobile.

The Wceappsfe directory contains the following directories.

Directory Contents
Cesysgen Files used to build the selected Windows CE modules and components.
OAK OS component files.
SDK SDK component files.
