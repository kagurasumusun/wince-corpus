Creating a New Toolbar

You can create a new toolbar.

To create a new toolbar

  1. From the Tools menu, choose Customize and then choose the Toolbars tab.
  2. Choose New; then, in the Toolbar Name box, type a name for the new toolbar; then choose OK.
  3. Move the Customize dialog box so you can see the new toolbar and then choose the Commands tab.
  4. In the Category list, select the category that has the item you want to add to the new toolbar.
  5. Drag the item to the new toolbar.
