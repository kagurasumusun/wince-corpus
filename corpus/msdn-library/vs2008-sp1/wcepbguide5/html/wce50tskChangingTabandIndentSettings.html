Changing Tab and Indent Settings

You can configure the settings for tabs and indenting in a file.

To change tab and indent settings

  1. From the Tools menu, choose Options.
  2. Choose the Tabs tab.
  3. In the Tab Size box, type the number of spaces to use as a tab stop.

    The default is four spaces.

  4. Type the number of spaces to use for indents in the Indent Size box.

    The default is four spaces.

  5. Select the Keep Tabs option to treat each tab mark as a single tab character when the file is saved.

    – or –

    Select the Insert Spaces option to use spaces as specified in the Tab Size box.

  6. Choose OK.

Backspacing over a tab character deletes that tab character, regardless of the indent setting. If you select the Insert Spaces option, a tab character is not inserted, and spaces are inserted to reach the next indent level.
