Icon Editor Window

In some ways, icons and cursors are like bitmaps.

You edit them in the same way, but icons and cursors have attributes that distinguish them from bitmaps. For example, each icon or cursor resource can contain multiple images for different target devices.

In addition, a cursor has a hot spot — the location Windows uses to track its position.

Note   The Icon Editor window does not have a shortcut menu because the right mouse button is used for image editing functions.
