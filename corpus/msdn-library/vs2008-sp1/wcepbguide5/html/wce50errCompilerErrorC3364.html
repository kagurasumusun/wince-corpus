Compiler Error C3364

'delegate' : invalid second argument for Delegate constructor

The second parameter of the delegate's constructor takes either the address of a member function or the address of a static member function of any class. Both are treated as simple addresses.

For example, this is one way to use delegates:

delegate int D( int, int);

class C
{
public:
    int mbrf(int,int){return 1;}
};

int main()
{
    C c = new C;
    Microsoft.Runtime.Delegate pdlgt = new D(c,&C::mbrf);
    return 0;
}
