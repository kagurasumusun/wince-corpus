Platform Builder for Microsoft Windows CE 5.0  

New Platform Wizard

The New Platform Wizard guides you through the process of creating a Windows CE–based OS design.

The process of creating a new OS design with the New Platform Wizard includes the following steps:

  1. Selecting an installed board support package (BSP).

    For more information, see Supported Board Support Packages.

  2. Selecting a configuration for your OS design.

    For more information, see Design Template Selection.

  3. Selecting a design template that is appropriate for your OS design.

    For more information, see OS Design Template Options.

  4. Selecting additional functionality for your OS design.

    For more information, see Additional Application and Media Catalog Items and Additional Networking and Communications Catalog Items.
