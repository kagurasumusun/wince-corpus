Platform Builder for Microsoft Windows CE 5.0  

SDK Settings Dialog Box: Emulation Tab

On this tab, you can configure emulation options for the SDK you have created.

Configuration
Select a configuration for the active OS design from the list.

This is used as the basis for building your SDK.

For information, see Levels of Debugging Support.

Ethernet support
Select if Ethernet support is available for the emulator.
Ports available to be configured
Select if the emulator has ports that are available to be configured.
Fixed screen resolution
Type the screen width and screen height in pixels, and the screen color in color bits.
Emulator skins
Select to add support for emulator skins to your SDK.

If you add this support, you must add the path to at least one folder that contains files for the emulator skins you want to support.

Note   When you build an SDK, the skin files must be in a separate directory. They cannot reside in the root directory.
