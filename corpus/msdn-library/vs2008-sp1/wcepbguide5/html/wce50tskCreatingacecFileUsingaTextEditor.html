Creating a .cec File Using a Text Editor

You can add items to the Platform Builder Catalog by creating a Catalog item (.cec) file, which contains information needed by Platform Builder to display the new Catalog item and to include it in future OS designs. For more information, see Catalog Item Files.

  1. Using a text editor, create a document.
  2. From the File menu, choose Save As.
  3. In the Save In box, navigate to the root directory for your OS design; for example, %_WINCEROOT%\PBWorkspaces\MyDesign.
  4. In the File Name box, type MyItem.cec and choose Save.

You have created a basic .cec file.

To complete the Catalog item file, create or copy the proper information and syntax into this file or open this file from the Platform Builder CEC Editor.
