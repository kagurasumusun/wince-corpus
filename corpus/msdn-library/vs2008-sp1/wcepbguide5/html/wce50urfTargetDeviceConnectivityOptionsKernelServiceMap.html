Target Device Connectivity Options: Kernel Service Map

You can select a download service and a kernel transport to associate with a named target device. If you have created a run-time image that contains debugging functionality, you can also configure debugger settings.

For more information about this dialog box, see Target Device Connectivity Options Dialog Box.

Target Device
Display the named target device that you are configuring service settings for. To change the target device, select a named target device from the drop down list.
Download
Display the name of a download service that you want to use to download a run-time image to a target device. Default settings for each download service are displayed underneath the box.
Settings
Open a dialog box where you can modify settings for a download service. For more information, see Target Device Connectivity Options: Download Service Dialog Box.
Transport
Display the name of a kernel transport that you want to use to establish a kernel-level connection between the development workstation and a target device. Default settings for each kernel transport are displayed underneath the box.
Settings
Open a dialog box in where can modify settings for a kernel transport. For more information, see Target Device Connectivity Options: Transport Dialog Box.
Debugger
Enable or disable hardware debugging. This functionality is available only when the active OS design contains debugging functionality.

For information about configuring debug message output, see Debug Message Options Dialog Box.

Settings
Open a dialog box where you can modify settings for the debugger.
Apply
Apply your changes without closing the dialog box.
Close
Close the dialog box without applying your changes.
