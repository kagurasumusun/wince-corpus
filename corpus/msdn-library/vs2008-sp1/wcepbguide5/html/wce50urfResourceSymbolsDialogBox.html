Resource Symbols Dialog Box

Use this dialog box to add a new resource symbol or modify an existing one.

This dialog box includes the following items.

Name
Use to see the name and numeric value for each symbol.
Value
Use to see the value of the symbol.
In Use
Select to specify that one or more resources are using the symbol.

The resource or resources are listed in the Used by box.

Show read-only symbols
Select to see read-only resources.

Typically the Symbol Browser displays only the modifiable resources in your resource script file. Modifiable resources appear in bold text; read-only resources appear in plain text.

Used by
Use to see the resources using the symbol selected in the symbols list.

To move to the editor for a given resource, select the resource in the Used By box and choose View Use, or double-click the resource.

Close
Use to process input and carry out a default action, such as closing the dialog box.
New
Use to define a new symbol.

This opens the New Symbol dialog box.

Delete
Use to delete the selected symbol.

Available for unused symbols only.

Change
Use to change the name or value of a symbol.

If the symbol is for a control or resource in use, the symbol can be changed only from the corresponding resource editor.

View Use
Use to open the resource that contains the symbol in the corresponding resource editor.
