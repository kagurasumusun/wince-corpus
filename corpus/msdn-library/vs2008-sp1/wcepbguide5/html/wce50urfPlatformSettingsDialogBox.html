This dialog box enables you to view and modify options for individual Catalog items and for an entire OS design.

Select the configuration to change the settings for.

This dialog box contains the following tabs:

  • Platform Settings: General Tab

  • Platform Settings: Environment Tab

  • Platform Settings: Image Settings Tab
