BKPT

This ARM10 instruction causes a software breakpoint to occur. The common _trap intrinsic supports BKPT.

int __trap(
  int Arg1
);

Parameters

Arg1
[in] Address of breakpointed instruction.

Return Values

None.

Requirements

Header: Armintr.h.
