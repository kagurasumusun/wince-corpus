Platform Builder for Microsoft Windows CE 5.0  

Public DirectX Directory

The DirectX directory contains files and directories for multimedia OS designs that use Microsoft® DirectX, waveform audio, the Microsoft Windows® CE DVD-Video API, or Microsoft Windows Media®.

The DirectX directory contains the following directories.

Directory Contents
Cesysgen Files used to build the selected Windows CE modules and components.
OAK OS component files.
SDK SDK component files.
