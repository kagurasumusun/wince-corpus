Customizing a Print Job

You can customize a print job.

To customize a print job

  1. From the File menu, choose Page Setup.
  2. In the Header and Footer boxes, type header or footer text, print control codes, or both.
  3. Use the right arrow to display a menu that enables you to insert control codes into the text box.
  4. You can type separate alignment options for file name, page number, current time, and current date. Always type the alignment option first, then the data.

    For example, &L&F&C&P specifies that the file name (&F) should be left-aligned (&L) and that the page number (&P) should be center-aligned (&C).

  5. In the Margins area, type the left, right, top, and bottom measurements.
  6. Choose OK.
