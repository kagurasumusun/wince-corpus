Expanding or Contracting a Window in Docked Mode

You can expand or contract a window when it is in docked mode.

To expand or contract a window in docked mode

  • Choose the Expand or Contract button.

    The Expand and Contract buttons are dual-purpose buttons.

    When the window is fully expanded, the function is Contract; otherwise, the function is Expand.

    The ToolTip and the button name indicate the current function.
