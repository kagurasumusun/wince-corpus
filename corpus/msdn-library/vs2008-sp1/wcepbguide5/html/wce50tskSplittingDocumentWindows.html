Splitting Document Windows

You can split document windows in the IDE.

To split document windows

  1. From the Window menu, choose Split.

    The split bar appears. A split bar is the horizontal or vertical double line that separates a window into two panes.

  2. Drag the split bar in the window to the location you want and click the left mouse button.
