Menu and Menu Item Customization

Some customization affects individual items on a menu; other customization changes affect the menu as a whole.

You can add, delete, copy, or move menu items. You can rename a menu or restore the original settings for a default menu.

If you delete a default command (a command that is supplied by the UI) from a menu, you can put it back later or add it to a different menu or toolbar.

If you are using a screen reader or related software, you can use the text-based menu bar, which is compatible with a screen reader.
