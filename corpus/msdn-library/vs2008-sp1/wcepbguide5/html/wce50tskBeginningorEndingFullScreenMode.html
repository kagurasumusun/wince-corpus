Beginning or Ending Full-Screen Mode

You can choose to display a file in full-screen mode for editing. Open a file for editing before beginning full-screen mode; otherwise, full-screen mode is displayed as a large, empty screen. If this happens, press the ESC key to restore the original screen mode.

To begin or end full-screen mode

  • To begin full-screen mode, from the View menu, choose Full Screen.

    Initially, when you choose full-screen mode, a toolbar button with a small graphic of a computer screen is displayed. You can turn full-screen mode on and off by choosing this button.

  • To end full-screen mode, choose the Full-screen toolbar button or press ESC.
