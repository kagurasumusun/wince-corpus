Reopening a Recently Used Workspace

If you have recently opened a workspace, you can open it again from the list of recently used workspaces on the File menu.

You can specify the number of workspaces defined as recently used. For information, see Workspace Tab.

To reopen a recently used workspace

  • From the File menu, choose Recent Workspaces and then choose the name of the recently used workspace.
