Restoring the Customize Command to the Tools Menu

If you removed the Customize command from the Tools menu or if you removed the Tools menu, you can still customize a toolbar.

To restore the Customize command to the Tools menu

  1. Right-click any toolbar or the menu bar and then choose Customize from the shortcut menu.
  2. With the Customize box open, right-click Tools on the menu bar and then choose Reset from the shortcut menu.
