Custom Image Dialog Box

Use this dialog box to configure settings for a custom image in the graphics editor.

Width
Provides a space for you to enter the width of the custom image in pixels.
Height
Provides a space for you to enter the height for the custom image in pixels.
Colors
Provides a space for you to choose the number of colors for the custom image: 2, 16, or 256 colors.
