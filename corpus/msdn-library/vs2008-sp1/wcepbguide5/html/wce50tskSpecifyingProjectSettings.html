Specifying Project Settings

After you create a project, you can customize it by specifying settings that are applied on a per-project basis. These settings are separate from those for the OS design.

To specify project settings

  1. From the Project menu, choose Settings.
  2. Select the tab containing the settings you want to change.

    - or -

    Insert or modify conditionals for the project. For more information, see Project Settings: Edit Conditional.

  3. Make changes to the project.
  4. Save the settings and close the Project Settings dialog box by choosing OK.

If you specify settings that are incompatible with the type of functionality you chose when you created the project, you might get unexpected results. For more information, see Project Settings Dialog Box.

Note   By default, Platform Builder does not recompile files that have not changed in the active project. This can cause build errors that appear during future rebuilds. To prevent this, if you have changed the settings for your project, do the following:
  1. From the Build Project menu, verify that Clean Before Building and Make Run-Time Image After Build are selected.
  2. Then, from the Build Project menu, choose Build and Sysgen Current Project.
