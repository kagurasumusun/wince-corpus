Creating a New Resource

After you create a resource, to use it, you must add it to your project.

To create a new resource

  1. From the Project menu, select Insert and then select Resource.
  2. Select the type of resource you want to create and then choose New.

    The IDE creates the new resource and assigns it a unique identifier. For example, a unique identifier could be IDD_Dialog1.

  3. Change the resource identifier by right-clicking the resource, choosing Properties, and typing the new identifier in the ID box of the property page.
  4. Save your resource files in a directory path that does not include spaces.
  5. In the Workspace window, on the FileView tab, expand the node for your project, select Resource Files and then, from the context menu, select Add Files.
  6. Navigate to the directory containing the resource files that you created and then choose Open.
