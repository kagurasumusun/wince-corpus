Disconnecting Add-ins from the Development Environment

If you no longer want to use an add-in, you can disconnect it from the Platform Builder environment.

To disconnect an add-in from the environment

  1. On the Tools menu, choose Customize.
  2. Choose the Add-ins and Macro Files tab.

    The names of the add-ins appear in the window.

  3. Clear the check boxes next to the add-ins you want to disconnect.
    Note   If you remove the check mark from an add-in, you will unload it. When you unload it, the add-in loses all of its toolbar and keystroke assignments. Additionally, if you remove the check mark, Platform Builder will not automatically load the add-in when you start Platform Builder again.

When you start Platform Builder again, the add-ins will no longer be available.
