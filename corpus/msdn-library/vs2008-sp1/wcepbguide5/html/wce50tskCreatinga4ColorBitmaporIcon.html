Creating a 4-Color Bitmap or Icon

You can use the New Project Wizard to create a bitmap or icon for a project.

To create a bitmap or icon

  1. From the File menu, choose New Project or File.
  2. Choose the Files tab.
  3. In the File name box, type the name of the bitmap or icon.
  4. Choose from the following; then choose OK.
    • To create a bitmap, choose Bitmap File.
    • To create an icon; choose Icon File.

    A blank bitmap or icon appears in a window, with the appropriate resource editor.

  5. Use the resource editor to create a bitmap or icon.

    – or –

    Import a bitmap or icon by choosing Resource from the Insert submenu of either the Project or Platform menu; then choose a bitmap or icon and choose Import.

  6. Convert the image from grayscale to color by choosing from the following:
    • For bitmap images, on the Image menu, choose Convert to 4-Color.
    • For icons, on the Image menu, choose New Device Image and add the two 4-color image sizes to your icon.
