Catalog Item Dependencies Dialog Box

This dialog box shows the Catalog items that the selected item is dependent on. The dialog box also shows the items that are dependent upon the selected item. These are displayed in the left pane.

The right pane displays information about the selected Catalog item. By default, when you open the dialog box, it displays information about the Catalog item in your OS design that you selected.

The following list shows the information displayed in the right pane:

Name
Shows the name of the Catalog item.
Vendor
Shows the name of the vendor who created the Catalog item.
Version
Shows the version of the Catalog item.
Date
Shows the release date of the Catalog item.
EnvironmentVariable
Shows the variable used to add the Catalog item to an OS design.
GUID
Shows the GUID of the Catalog item.
Locale
Shows the locale that the Catalog item is localized to.
Size
Shows the estimated size of the Catalog item in the run-time image that is downloaded to a target device.
SupportedConfigurations
Shows the configurations that are supported by the Catalog item.
SupportedCPUs
Shows the CPUs that are supported by the Catalog item.
