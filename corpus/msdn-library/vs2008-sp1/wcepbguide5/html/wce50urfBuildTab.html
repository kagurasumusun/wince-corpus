Platform Builder for Microsoft Windows CE 5.0  

Options Dialog Box: Build Tab

This tab includes the following items.

Write Build Log (.plg)
Select to write a text log of the build, named <Active OS Design Name>.plg, to the active OS design directory.
Default OS Build Tree (_WINCEROOT)
Use to type the path to the directory you want to use as your default root directory.
Tools only (no _WINCEROOT selected)
Select if you do not have a full Platform Builder installation on your development workstation.
