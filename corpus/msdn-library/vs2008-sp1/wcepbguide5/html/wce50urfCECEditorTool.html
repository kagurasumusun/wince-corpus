Platform Builder for Microsoft Windows CE 5.0  

CEC Editor Tool

The Platform Builder CEC Editor allows you to create and edit Catalog item (.cec) files in the IDE.

The CEC Editor is accessed from the Tools menu.

The left side of the CEC Editor window displays the individual items from the .cec file that are being edited. These items are listed in the order that they appear when the .cec file is imported into the Catalog.

The properties for a selected Catalog item can be viewed on the right side of the window.

From this window, you can perform tasks such as editing the name and description of the Catalog item being created, associated variables, and creating a new GUID.

In the CEC Editor window or in dialog boxes opened from the CEC Editor, if a field is flagged with an asterisk (*), it is a required field.

To successfully import a .cec file into the Catalog, do not use line feed or carriage return characters in the CEC Editor when you enter the information for the .cec file. If you use a line feed or carriage return character when you enter information, you cannot import the resulting .cec file into the Catalog.

Note   To save a .cec file, use only the .cec file name extension and use lower case letters. If you attempt to save a .cec file using a file name extension other than .cec, the file is not saved and the CEC Editor does not notify you that the file is not saved.

For more information about the creation and modification of .cec files, see Catalog Item Files.
