Platform Builder for Microsoft Windows CE 5.0  

Customize Dialog Box: Keyboard Tab

This tab includes the following settings that you can use to configure shortcut keys in Platform Builder.

Category
Use to see the menus containing the items you can assign a shortcut key to.

The commands for the selected menu appear in the Commands box below.

Editor
Use to specify the editor or view that you want to assign shortcut keys to.

For example, select Text to assign a shortcut key that will be available when you work in the Text editor.

Commands
Use to see the commands on the menu selected in the Categories box.

Select the command you want to assign to a shortcut key.

A brief description of the command appears in the Description box.

Current keys
Use to see the shortcut key combinations assigned to the command selected in the Commands box.
Press new shortcut key
Use to specify a new shortcut key combination.

To test a new shortcut key combination for the command selected in the Commands box, press the keys you want to assign.

If the key combination is assigned to another command, the command appears in the Currently Assigned To box.

To assign the new shortcut key combination, click Assign.

Assign
Use to assign the shortcut key combination displayed in the Press New Shortcut Key box to the command selected in the Commands box.
Remove
Use to remove the shortcut key combination selected in the Current Keys box.
Reset All
Use to remove the shortcut key combination selected in the Current Keys box.
