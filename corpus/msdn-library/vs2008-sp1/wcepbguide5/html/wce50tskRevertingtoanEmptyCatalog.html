Reverting to an Empty Catalog

If the Catalog for Platform Builder becomes corrupt, you can clean the underlying database using the following procedure.

If you clean the database using this procedure, Catalog item (.cec) files you imported since you installed Platform Builder will be disassociated from the Catalog. After cleaning the database, re-import these Catalog item files to associate them with the Catalog again.

For more information about importing a Catalog item file, see Adding a .cec File to the Catalog.

To revert to an empty Catalog

  1. Close Platform Builder.
  2. Open a command prompt window.
  3. At the command prompt, change the directory to <Platform Builder installation path>\Cepb\Bin.
  4. At the command prompt, type cleandb.bat and press ENTER.
  5. Open Platform Builder.

    The Catalog no longer shows Catalog items that were previously imported.
