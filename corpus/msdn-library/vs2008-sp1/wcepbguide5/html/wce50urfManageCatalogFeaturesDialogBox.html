Manage Catalog Items Dialog Box

This dialog box enables you to add or remove Catalog items by adding or removing the associated Catalog item (.cec) files from the Catalog.

The dialog box includes the following.

Imported .cec files
Displays .cec files that have been imported into the Catalog on your development workstation.
File
Displays the names of .cec files that have been added to the Catalog.
Version
Displays the version of the imported .cec files.
Vendor
Displays the vendor who created the imported .cec files.
Description
Displays a description of the imported .cec files.
OK
Choose to close the dialog box.
Remove
Choose to remove the selected .cec file from the Catalog.
Import
Choose to import a new .cec file to the Catalog.
Refresh
Use to update the data shown in the Manage Catalog Items dialog box and the Catalog to reflect added or removed .cec files.
