Workspace Window

When a workspace is open, the Workspace window contains information about the OS design in that workspace.

The information in the Workspace window is organized on tabs. Choose the tab at the bottom of the Workspace window to see its contents. You can also press shortcut keys to bring up the corresponding tab.

The following table shows the accelerator keys for each tab available in the Workspace window.

Workspace tab Shortcut keys
OSDesignView Tab CTRL+SHIFT+ALT+E
ParameterView Tab CTRL+SHIFT+ALT+P
ClassView Tab CTRL+SHIFT+ALT+C
ResourceView Tab CTRL+SHIFT+ALT+R
FileView Tab CTRL+SHIFT+ALT+V

For information about icons used on these tabs, see Catalog Item Icon Types.
