Help Menu Options

The options on the Help menu enable you to work with the Help documentation available in Platform Builder.

The following options are available.

Command Description
Contents Use to display the online documentation for Platform Builder.
Search Use to search the online documentation.
Index Use to display the index for the online documentation.
Keyboard Map Use to display shortcut keys available in Platform Builder.

For more information, see Shortcut Keys.
Technical Support Use to display technical support for Platform Builder.
Start Page Use to display the Start Page for Platform Builder.
Microsoft on the Web Use to select options for viewing Microsoft content related to Platform Builder on the Web.
About Platform Builder Use to display the program and copyright information for Platform Builder.
