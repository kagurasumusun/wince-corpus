Folder Properties Dialog Box

This dialog box displays information for the selected folder, which is a group of files for the project.

To create additional folders on this tab, use the New Folder Dialog Box.

This dialog box includes the following items.

Pushpin button
Click to keep this dialog box open on your desktop, on top of all other windows. Click again to cancel this functionality.
Type
Displays the type of folder.
Path
Displays the full file path to the location of this folder.
Modified
Displays the date and time when this folder was last modified.
