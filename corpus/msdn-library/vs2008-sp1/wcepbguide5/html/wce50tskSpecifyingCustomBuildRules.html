Specifying Project Conditionals

You can specify conditionals for a selected project.

To specify conditionals for a project

  1. From the Project menu, choose Settings.
  2. In the left pane, select Global Block; then, from the context menu, choose Insert New Conditional.
  3. In the Edit Conditional box, choose the first line and then type or select the command you want to run on the input file.

    If you type more than one command, the build process runs them in order, from top to bottom.

    A command must include all required options.

    You might want to use a directory macro to specify the location for the output file.

    For information on the macros, macro values, keywords, and logical operators that you can select, see Project Settings: Edit Conditional.
