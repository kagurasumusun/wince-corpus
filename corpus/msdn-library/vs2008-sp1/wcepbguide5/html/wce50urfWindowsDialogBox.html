Platform Builder for Microsoft Windows CE 5.0  

Windows Dialog Box

This dialog box enables you to do the following:

  • Make a window active
  • Save or close a window
  • Have all your windows tile horizontally or vertically

This dialog box includes the following.

Select Window
Use to select one or more currently open windows in the Select Window list.

If you select a single window, you can choose Activate, Save, or Close Window(s).

If you select multiple windows, you can choose Save, Close Window, Tile Vertically, or Tile Horizontally.

Activate
Click to switch to the currently selected window in the Select Window list.
OK
Use to process your selection and close the dialog box.
Save
Use to save the currently selected files in the Select Window list.
Close Window(s)
Use to close the window and file of each file selected in the Select Window list.
Tile Horizontally
Use to tile the open document windows horizontally.
Tile Vertically
Use to tile the open document windows vertically.
