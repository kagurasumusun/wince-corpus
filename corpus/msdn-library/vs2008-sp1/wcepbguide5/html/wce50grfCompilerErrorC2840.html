Compiler Error C2840

Instruction word argument not constant

You specified an argument that is not a compile-time constant.

Note: This is a backend error, and does not occur if you compile with the compiler option -GL -c.

The following code example shows how this error can occur using the ARM _emit intrinsic function.

#include <armintr.h>
typedef void (*PFNJUMP)(void);

PFNJUMP g_pfnJUMP;
const unsigned int xxx=0xffff, yyy=0xeeee;

int main(void)
{
   __emit(xxx); // Error
   __gregister_set(0, (unsigned int)(&g_pfnJUMP));
   __emit(yyy); // Error
   return 0;
}
