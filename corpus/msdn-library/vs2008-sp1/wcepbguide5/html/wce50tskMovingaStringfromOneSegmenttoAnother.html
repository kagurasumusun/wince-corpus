Moving a String from One Segment to Another

After you create a string, you can move it from one segment to another.

To move a string

  1. Select the string to move.
  2. Choose Properties from the View menu.
  3. Change the string value in the ID box so that it falls in the range you want.

    For example, to move a string with a name of IDS_MYSTRING and a value of 100 to a segment in the 200 range, type IDS_MYSTRING=201 in the ID box.

  4. Press ENTER.
