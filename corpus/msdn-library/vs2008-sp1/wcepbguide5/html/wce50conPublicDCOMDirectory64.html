Platform Builder for Microsoft Windows CE 5.0  

Public DCOM Directory

The DCOM directory contains the files required to add support for the Distributed Component Object Model (DCOM).

The DCOM directory contains the following directories.

Directory Contents
Cesysgen Files used to build the selected Windows CE modules and components.
OAK OS component files.
SDK SDK component files.
