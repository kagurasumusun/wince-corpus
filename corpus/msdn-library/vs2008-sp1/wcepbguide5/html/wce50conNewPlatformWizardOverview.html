Platform Builder for Microsoft Windows CE 5.0  

New Platform Wizard Overview

The New Platform Wizard guides you through the process of creating a workspace containing a Windows CE-based OS design that you use to build a run-time image for download to a target device.

When you run the wizard, tasks you perform include the following:

  • Choose a BSP for your OS design

    For information about BSPs you can choose, see Supported Board Support Packages.

  • Choose a design template for your OS design

    For information about OS design templates you can choose, see OS Design Template Options.

  • Add or remove a selection of Catalog items

    For more information, see Additional Applications and Media Catalog Items and Additional Networking and Communications Catalog Items.
