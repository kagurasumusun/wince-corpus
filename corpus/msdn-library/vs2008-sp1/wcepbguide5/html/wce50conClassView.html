ClassView

In the Workspace window, the ClassView tab provides simple and direct ways to perform common tasks with your application classes.

On the ClassView tab, you can perform the following tasks:

  • Navigate among class members
  • Modify interfaces
  • Set breakpoints for the integrated debugger
  • Generate a new form for your project
  • Add the initial code for classes and members
  • Modify the ClassView display

By using the functionality available in ClassView, you can navigate among your source code files without having to think about which file to open. You can perform the following tasks by selecting ClassView icons or options from the shortcut menu:

  • Create a new class or form
  • Jump directly to code, such as class or function definitions and declarations
  • Create function or method declarations and implementations
  • Jump to the dialog editor

Also, ClassView interacts closely with the text editor, dynamically updating the text editor display to reflect code as you type it without needing to first save the file you are working in.

When you expand a project in ClassView, ClassView displays the classes that are included in that project. If you expand any class, ClassView displays the members in that class.
