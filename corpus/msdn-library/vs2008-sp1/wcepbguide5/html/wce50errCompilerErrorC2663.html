Compiler Error C2663

'function' : number overloads have no legal conversions for 'this' pointer

The compiler could not convert this to any of the overloaded versions of the member function.

Possible cause

  • Invoking a non-const member function on a const object.

Possible solutions

  • Remove the const from the object declaration.
  • Add const to one of the member function overloads.

Example

class C {
public:
void f() volatile;
void f(); // adding const here would fix problem
};

const C *pcc;

void main()
{
pcc->f();// error
}
