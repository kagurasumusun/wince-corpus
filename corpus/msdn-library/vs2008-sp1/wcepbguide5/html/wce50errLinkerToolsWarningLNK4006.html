Linker Tools Warning LNK4006

symbol already defined in object; second definition ignored

The given symbol, displayed in its decorated form, was multiply defined. When this warning is encountered, symbol is added twice, but only its first form is used.

Tips

  • The given symbol might be a packaged function, created by compiling with /Gy. This symbol was included in more than one file but was changed between compilations. Recompile all files that include the symbol.
  • The given symbol might have been defined differently in two member objects in different libraries.
  • An absolute might have been defined twice, with a different value in each definition.
  • If the error message is received when combining libraries, symbol exists in the library being added to.

If you are rebuilding the C run-time library, you can ignore this message.
