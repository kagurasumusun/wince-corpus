Project Settings Dialog Box

This dialog box enables you to set the compiler and linker settings and the output characteristics for your project.

You can access the following tabs from this dialog box.

  • Project Settings: General Tab
  • Project Settings: C/C++ Tab
  • Project Settings: Managed Code
  • Project Settings: Link Tab

You can also insert project-specific conditionals into this dialog box. To do this,

  1. In the left pane, select Global Block.
  2. From the context menu. select Insert Conditional

For more information, see Project Settings: Edit Conditional.
