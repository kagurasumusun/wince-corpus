Removing a Command from the Tools Menu

You can remove a command from the Tools menu.

To remove a command from the Tools menu

  1. From the Tools menu, choose Customize and then choose the Tools tab.
  2. Select the command that you want to delete in the Menu Contents box; then choose the Delete button.
