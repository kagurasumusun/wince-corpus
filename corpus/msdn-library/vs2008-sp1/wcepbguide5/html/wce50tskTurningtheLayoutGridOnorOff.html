Turning the Layout Grid On or Off

You can toggle the layout grid on and off.

To turn the layout grid on or off

  1. Choose Guide Settings from the Layout menu.
  2. Select or clear the Grid button.

    You can still control the grid in individual dialog editor windows using the Toggle Grid button on the Dialog toolbar.
