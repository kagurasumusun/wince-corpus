Document Windows

Document windows are associated with the workspace.

When you close a workspace, Platform Builder records the characteristics for the document windows, such as positions, sizes, selections, splitting, and so on.

When you open the workspace again, Platform Builder restores these characteristics.

Document windows include the following types:

  • Editor windows, for text or resources
  • The resource browser window (except when it is used for active project resources in the workspace)

When you work with documents by using a text editor or other resource editors, you can switch to full-screen mode.

The status bar displays useful information, such as

  • The currently selected menu command
  • The action of the button under the pointer
  • Progress information about the current operation

In a text editor window, the status bar shows the following:

  • The line and column position of the insertion point
  • The state of the record keystrokes and column mode
  • Whether the text editor is in insertion mode or overstrike mode
  • Whether the file is set for read-only access

You can also display the clock on the status bar.
