Compiler Error C2061

syntax error : identifier 'identifier'

The compiler found identifier where it was not expected.

Possible cause

  • Initializer enclosed by parentheses. To avoid this problem, enclose the declarator in parentheses or make it a typedef.

Example

class X {};
class Y {};
class Z {};
class W : public  X, public Y, public Z {};

void func ( W* pW )
{
    X* pX ( pW );     // Error: unexpected identifier 'pW'

    Y ( *pY ) ( pW ); // OK, declarator in parentheses

    typedef Z *pZ_t;
    pZ_t pZ ( pW );   // OK, typedef used for Z
}
