Saving a Graphic in a Different File Format

You can save a graphic in different file format than the one the graphic is currently using.

To save a graphic in a different file format

  1. Choose Save As from the File menu.
  2. Type the file name and the file name extension in the File Name box.

    For example, type myfile.gif.

  3. Choose Save.

You can open GIF or JPEG files in the graphics editor and save them as bitmaps. Also, you can open a bitmap file and save it as a GIF or JPEG file.
