License Run-Time Image Dialog Box

This dialog box enables you to license a run-time image by stamping the run-time image file with a product identifier (PID).

The dialog box includes the following items.

Select Binary
Use to enter the path to the binary file you want to license.
Browse
Use to browse to the location of the binary file you want to license.
License Key (25 digits)
Use to enter the license key.

For information about how to obtain a license key, go to this Microsoft Web site.

Stamp Binary
Select to license the binary file you selected using the license key you entered.
Close
Close the dialog box without saving changes.
