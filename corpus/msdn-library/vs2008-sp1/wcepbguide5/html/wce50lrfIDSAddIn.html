Platform Builder for Microsoft Windows CE 5.0  

IDSAddIn

This interface exposes objects and methods that support Platform Builder Add-ins.

Methods

The following table shows the methods for the IDSAddIn interface.

Method Description
OnConnection Loads an add-in.
OnDisconnection Unloads an add-in.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Addauto.h.
Link Library: Developer implemented.
