Including an Existing Project As a Subproject

If a project depends on another project, you can specify the order that the projects are built in. This ensures that if one project is depended on by another project, that the first project's files are built first.

To specify project build order

  1. Open the workspace that has the projects whose build order you want to modify.
  2. (Optional) If the workspace does not contain the projects you want to build, add them to the workspace by, from the Project menu, choosing Insert, and then Existing Project.

    Navigate to the directory containing the project file that you want to insert, select the file, and then choose Open.

  3. From the Project menu, choose Set Project Build Order.
  4. In the Workspace Projects Build Order dialog box, select the project whose position you want to change in the list of included projects.
    • To specify that the project will be built later in the build process than the other projects, choose Down.
    • To specify that the project will be built earlier in the build process than the other projects, choose Up.
  5. Choose OK.
