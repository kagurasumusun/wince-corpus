Platform Builder for Microsoft Windows CE 5.0  

Menu Descriptions

The Platform Builder IDE provides menus you can use to work with OS designs and projects.

File Menu Options
The options on the File menu enable you to work with workspaces.
Edit Menu Options
The options available from the Edit menu enable you to work with files and source code.
View Menu Options
The options on the View menu enable you to work with source files and the IDE itself.
Project Menu Options
The options on the Project menu enable you to work with projects.
Platform Menu Options
The options on the Platform menu enable you to work with existing OS designs.
Target Menu Options
The options on the Target menu enable you to download a run-time image to a target device for debugging and testing.
Build Project Menu Options
The options on the Build Project menu enable you to work with existing projects.
Build OS Menu Options
The options on the Build OS menu enable you to build run-time images based on OS designs that you created.
Tools Menu Options
The options on the Tools menu enable you to use remote tools and macros to work with OS designs that you created.

You can also configure the Tools toolbar and the IDE.

Window Menu Options
The options on the Windows menu enable you to work with the windows that you can create in the Platform Builder IDE.
Help Menu Options
The options on the Help menu enable you to work with the Help documentation available in the Platform Builder IDE.
