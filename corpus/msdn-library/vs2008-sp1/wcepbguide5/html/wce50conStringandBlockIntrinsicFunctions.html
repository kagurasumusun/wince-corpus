String and Block Intrinsic Functions

These functions implement common string operations and similar operations on arbitrary blocks of memory.

These functions are part of the Microsoft C Run-time Library for Windows CE for Windows CE; the intrinsic versions perform the same operation as the run-time versions except as noted. For more information, see Microsoft C Run-Time Library for Windows CE.

The following table lists the supported intrinsic functions for string and block operations.

Function Description
memchr, wmemchr Searches for a byte in a memory block.

This function is part of the Microsoft C Run-Time Library for Windows CE, and the intrinsic version performs the same operation as the run-time version.

memcmp, wmemcmp Compares specified number of characters from two buffers.

This function is part of the Microsoft C Run-Time Library for Windows CE, and the intrinsic version performs the same operation as the run-time version.

memcpy, wmemcpy Copies specified number of characters from one buffer to another.

This function is part of the Microsoft C Run-Time Library for Windows CE, and the intrinsic version performs the same operation as the run-time version.

memset, wmemset Uses given character to initialize specified number of bytes in the buffer.

This function is part of the Microsoft C Run-Time Library for Windows CE, and the intrinsic version performs the same operation as the run-time version.

strcat, wcscat Append a C string to the end of another.

This function is part of the Microsoft C Run-Time Library for Windows CE, and the intrinsic version performs the same operation as the run-time version.

strcmp, strncmp
wcscmp, wcsncmp		 Compare two C strings.

This function is part of the Microsoft C Run-Time Library for Windows CE, and the intrinsic version performs the same operation as the run-time version.

strcpy, strncpy
wcscpy, wcsncpy		 Copy a C string to a new address.

This function is part of the Microsoft C Run-Time Library for Windows CE, and the intrinsic version performs the same operation as the run-time version.

strlen, wcslen Get the length of a C string.

This function is part of the Microsoft C Run-Time Library for Windows CE, and the intrinsic version performs the same operation as the run-time version.

_strset, _wcsset Reset all characters in a C string.

This function is part of the Microsoft C Run-Time Library for Windows CE, and the intrinsic version performs the same operation as the run-time version.
