Opening Two or More Files In or Out of Sequence

You can open two or more files in or out of sequence.

To open two or more files in or out of sequence

  1. From the File menu, choose Open.
  2. Select the drive and directory where the files are stored.

    The default selection is the current drive and directory.

  3. Specify the types of files to display in the Files Of Type box.

    Files with the chosen file name extension are displayed in the list box. The Files Of Type box initially lists commonly used file name extensions.

    You can specify wildcard characters in the File Name box to display file types. You can use any combination of wildcard characters, delimited by semicolons. For example, if you type *.h;*.cpp, all files with these extensions are displayed. The wildcard characters that you specify are retained until you close the dialog box.

  4. Select the first file or directory that you want. Press the SHIFT key while you select the last file or directory in the group, and then choose Open.

    - or -

    Press the CTRL key while you select each file or directory that you want. Choose Open after your selection is complete. To cancel a selection, press CTRL while you select the file or directory that you want to remove from the selection.
