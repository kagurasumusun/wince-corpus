Running a Macro from the Macro Dialog Box

If you do not want to create a permanent macro, you can create and save a temporary macro.

To record a quick macro

  1. From the Tools menu, choose Macro.
  2. In the Macro File box, select the file containing the macro to run.

    If this file is not in the list, install the file and then select it in the Macro File box.

  3. In the Macro Name box, double-click the macro name you want to run, or select the macro name you want to run and choose Run.
