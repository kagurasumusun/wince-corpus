Restoring the Tools Menu to the Menu Bar

You can restore the Tools menu to the menu bar if you removed it.

To restore the Tools menu to the menu bar

  1. Right-click any toolbar or the menu bar and then choose Customize from the shortcut menu.
  2. Choose the Commands tab and then select Menus in the Category list.
  3. Drag Tools in the Commands box to the menu bar.
