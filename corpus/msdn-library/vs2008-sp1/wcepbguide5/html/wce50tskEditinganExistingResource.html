Editing an Existing Resource

After you create a resource, you can edit it.

To edit a resource

  1. In the Workspace window, on the ResourceView tab, navigate to and expand the folder for the project containing the resources you want to view.
  2. Expand the folder containing the resource type to view.

    For example, to view a dialog resource, expand the Dialog folder.

  3. Select the resource to edit, and press ENTER.

    The resource opens in the appropriate editor. For example, the resource opens in the dialog editor for a dialog resource.
