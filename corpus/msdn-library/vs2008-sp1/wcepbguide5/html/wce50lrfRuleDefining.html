Rule Defining

The following example shows the syntax for defining an inference rule.

.FromExt.ToExt:
commands

The FromExt represents the extension of a dependent file and ToExt represents the extension of a target file.

Extensions are not case-sensitive.

Macros can be invoked to represent FromExt and ToExt; the macros are expanded during preprocessing.

The period (.) preceding FromExt must appear at the beginning of the line.

The colon (:) is preceded by zero or more spaces or tabs. It can only be followed by

  • Spaces or tabs
  • A semicolon (;) to specify a command
  • A number sign (#) to specify a comment
  • A newline character

No other spaces are allowed.

Commands are specified as they are in description blocks.

The following example shows the syntax for an inference rule that specifies paths.

{FromPath}.FromExt{ToPath}.ToExt:
commands

An inference rule applies to a dependency only if the paths that are specified in the dependency exactly match the inference-rule paths.

Specify the dependent's directory in FromPath and the target's directory in ToPath;.

No spaces are allowed.

Specify only one path for each extension.

A path on one extension requires a path on the other.

To specify the current directory, use a period (.) or empty braces ({ }).

Macros can represent FromPath and ToPath and are invoked during preprocessing.
