Changing the Identifier of a Toolbar Button

You can change the identifier of a toolbar button.

To change the identifier of a toolbar button

  1. Choose the toolbar button.
  2. Choose Properties from the View menu.
  3. Type the new identifier in the ID box, or use the list to select a new identifier.
