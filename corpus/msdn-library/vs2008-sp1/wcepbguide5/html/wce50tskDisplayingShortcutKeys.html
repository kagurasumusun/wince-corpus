Displaying Shortcut Keys

You can display a list of assigned shortcut keys in Platform Builder.

To display shortcut keys

  • From the Help menu, choose Keyboard Map and then perform one or more of the following actions in any order:
    • To sort the shortcut key list alphabetically in different ways, select Editor, Command, Keys, or Description.
    • To copy the list to the Clipboard so you can paste the list into a word processor or other text editor, choose the Copy button.
    • To print a copy of the list, choose the Print button.
    • To filter the shortcut key list, select All Commands, Bound Commands, or a category name from the Category list.
