Compiler Warning (level 1) C4228

nonstandard extension used : qualifiers after comma in declarator list are ignored

Use of qualifiers like const or volatile after a comma when declaring variables is a Microsoft extension (/Za).

Example

int j, const i = 0;  /* warning C4228 */
int k;
int const m = 0;  /* ok */
