Workspace Tabs

The Workspace window provides several tabs with different views. Switch from one view to another by choosing the tab you want.

Note   None of these tabs are available for empty projects. The ResourceView tab is only available for Catalog items and projects that contain resources.

The following tabs are available in the workspace.

Tab Description
OSDesignView Displays Catalog items included in the OS design you created.
ParameterView Displays OS design source configuration files for the Common, Hardware Specific, and Project Specific directories.
ClassView Displays classes that are defined in your projects. Expanding the folders shows the classes; expanding a class shows its members.
ResourceView Displays the resource files that are included in your projects. Expanding the resource type folders shows the resources.
FileView Displays files in the OS design you created.
