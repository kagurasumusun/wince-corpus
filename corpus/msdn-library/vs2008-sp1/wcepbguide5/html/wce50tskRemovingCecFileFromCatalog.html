Removing a .cec File from the Catalog

You can remove a Catalog Item from the Catalog by removing the Catalog Item (.cec) file it is associated with.

To remove a .cec File from the Catalog

  1. From the File menu, choose Manage Catalog Items.
  2. Select the Catalog item (.cec) file that you want to remove, and then choose Remove.
  3. To confirm your choice, choose Yes.
  4. Choose the Refresh button to update the Catalog, and then choose OK to close the Manage Catalog Items dialog box.
  5. If the Catalog is not open, choose Catalog from the View menu.

    - or -

    Choose the Catalog button on the Standard toolbar.

  6. Navigate to the node in the Catalog window and ensure that the selected Catalog item has been successfully removed.
