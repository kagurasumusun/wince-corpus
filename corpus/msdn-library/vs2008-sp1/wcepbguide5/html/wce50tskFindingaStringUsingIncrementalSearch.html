Finding a String Using Incremental Search

You can find a string using an incremental search.

To find a string

  1. Choose Advanced from the Edit menu, and then choose Incremental Search.

    The cursor moves to the status bar.

  2. Begin typing the search string.

    As you type each character, the text editor selects the matching string in your file.

  3. If necessary, press the Incremental Search shortcut key combination to go to the next match in your file.
  4. Press the ESC key or use any of the navigational commands to end the search.

    If there is no match, the text editor beeps and displays a warning in the status bar.
