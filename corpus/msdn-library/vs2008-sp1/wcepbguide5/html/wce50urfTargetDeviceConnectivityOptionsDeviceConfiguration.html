Target Device Connectivity Options: Device Configuration

You can add or delete connections to target devices. If you have created a run-time image that contains debugging functionality, you can also configure debugger settings.

For more information about this dialog box, see Target Device Connectivity Options Dialog Box.

Add Device
Enables you to specify a name for the connection to the target device that you will download a run-time image to.

You can also associate an OS design or SDK with the connection.

Delete Device
Enables you to delete a connection to a target device.
