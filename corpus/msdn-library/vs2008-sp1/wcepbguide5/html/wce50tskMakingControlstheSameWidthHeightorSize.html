Making Controls the Same Width, Height, or Size

You can resize a group of controls based on the size of the active control. You can also resize a control based on the dimensions of its command text.

To make controls the same size

  1. Select the controls to resize.
  2. Verify that the correct active control is selected.
  3. Choose Make Same Size from the Layout menu and then choose one of the following options: Width, Height, or Both.
