Platform Builder for Microsoft Windows CE 5.0  

SDK Settings Dialog Box: Additional Files Tab

On this tab, you can add files to the SDK you are creating.

The source folder is a fully qualified path to a local folder on your development workstation, and the target folder is a path relative to the installation directory for the SDK.

The following example shows the syntax that a target folder path uses: testdir\subdir.

Include Subfolders
After you add a source folder to the SDK, select this check box to include subfolders in your source folder in the SDK.
Source Folder
Choose from the following:
  • Choose Add to enter a local path name for a source folder and the associated target path.
  • Choose Edit to edit a local path name or associated target path for a source folder.
  • Choose Delete to remove a folder from the listing on this tab.

    The associated files are not deleted from your development workstation.

Target Folder
Choose from the following:
  • Choose Add to enter the name of a target folder in the installation directory.
  • Choose Edit to edit a local path name for a source file.
  • Choose Delete to remove a folder from the installation directory.
