SDK Settings Dialog Box: Transports Tab

The transports tab shows a list of currently available transports.

You can use a built-in transport, or you can add, delete, or edit a custom transport.

Add
Choose to add a transport to your SDK. For more information, see Add/Edit Transport Dialog Box.
Edit
Choose to edit an existing transport to your SDK. For more information, see Add/Edit Transport Dialog Box.
Delete
Choose to remove a transport from your SDK. If a transport is a Microsoft component, you cannot remove it from your SDK.
