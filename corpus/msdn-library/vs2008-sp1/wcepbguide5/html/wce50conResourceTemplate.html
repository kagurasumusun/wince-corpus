Resource Template

A resource template is a copy of an edited resource that is used to create additional resources.

Resource templates save you time when you develop similar resources or groups of resources.

For example, you might want to include a Help button and an icon of a company logo in a dialog box. You can do this by creating and customizing a template dialog box with the logo and the Help button. To create a new dialog box, you can use this template dialog box with those elements added.
