Platform Builder for Microsoft Windows CE 5.0  

Bookmarks Dialog Box

This dialog box enables you to place bookmarks in your files.

The following options are available:

Name
Enter a name in the text box to create a bookmark at the location of your cursor in an open file, or select the name of a bookmark by clicking the down arrow next to the text box.
Bookmark List
Select an active bookmark name to edit, delete, or go to.

The file location and line number of the selected bookmark are displayed at the bottom of the dialog box.

Add
Click to add the bookmark displayed in the Name text box to the list of active bookmarks.

This button is disabled if the bookmark exists or if the Name text box is empty.

Close
Click to close the dialog box, saving changes you made.
Delete
Click to delete the selected bookmark from the list of active bookmarks.

This button is disabled until you select a bookmark.

Go To
Click to go to the selected bookmark.

This button is disabled until you select a bookmark.
