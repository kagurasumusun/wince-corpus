System Intrinsic Functions

These functions implement behavior that cannot be modeled machine-independently in the C language, such as stack allocation and synchronization.

The following table shows the intrinsic functions for system operation.

Function Description
__assume Passes hint to optimizer.
_alloca Allocates stack memory.
This function is part of the Microsoft C Run-Time Library for Windows CE, and the intrinsic version performs the same operation as the run-time version.
_prefetch Loads the data cache from main memory, if possible.
_CopyInt32FromFloat
_CopyInt64FromFloat		 Copies a floating-point number into an integer register.
_CopyFloatFromInt32
_CopyFloatFromInt64		 Copies an integer value to a floating-point register.
_CopyInt64FromDouble Copies an integer double number into a 64-bit floating-point register
_CacheRelease Writes the cache line containing the address referenced by the pointer to main memory, and then marks the cache line as empty.
_CacheWriteBack Writes the cache line containing the address referenced by the pointer to main memory.
_ICacheRefresh Releases the cache line containing the address referenced by the pointer from the instruction cache.
__noop Signals that the function following this instruction should be ignored.
_ReturnAddress Provides the return address.
_trap Inserts a trap instruction.
__debugbreak Provides a breakpoint for debugging.
_WriteBarrier
_ReadWriteBarrier		 Provides memory system synchronization.
