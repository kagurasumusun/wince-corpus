Opening an Existing Workspace

After you create an OS design, you can reopen the workspace containing the OS design.

To open an existing workspace

  1. From the File menu, choose Open Workspace.

    By default, the dialog box displays the %_WINCEROOT%\PBWorkspaces directory.

  2. Select the directory that contains your workspace, select the .pbxml file for the workspace, and then choose Open.
