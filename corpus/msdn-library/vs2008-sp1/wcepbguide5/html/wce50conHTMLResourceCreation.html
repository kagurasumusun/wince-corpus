HTML Resource Creation

You create a new HTML resource just as you would any other Windows resource. You can also import an existing HTML file into your project resource script.

You can take advantage of the text editor's HTML syntax highlighting, and all other text editor operations, as you code your HTML page. Because the HTML page is part of your project's .rc file, typical file operations, such as saving or closing, apply to the entire resource file, not just the edited HTML page.

If your HTML page contains calls to bitmaps or other graphics, you might want to include the corresponding graphic files in your resource script to ensure their availability when the user runs the application. If you do so, use the res: Protocol to display these graphics from your page.

The res: Protocol supports displaying a resource that resides in a compiled dynamic-link library (.dll) file or executable (.exe) file.

If you have designed your Web page, or want to take advantage of other existing Web pages, you can easily include an HTML file in your project's resource script.
