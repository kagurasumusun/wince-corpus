Platform Builder for Microsoft Windows CE 5.0  

New Dialog Box: Projects Tab

This tab includes the following items.

Workspace window
Use to choose the type of project you want to create.

You must also type a project name in the Project Name box.

The project is added to your current workspace.

Project name
Use to type the name of the new project.
Location
Use to specify the location of the directory for a new project.

You can type a path or select one by using the Browse button at the right of the Location box.

Workspace project
Specify whether the project you want to create is specific to the current workspace.
Sources project
Specify whether the project you want to create is an OS project that is not specific to a workspace.
