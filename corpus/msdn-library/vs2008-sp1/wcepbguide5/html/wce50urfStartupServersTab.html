Platform Builder for Microsoft Windows CE 5.0  

SDK Settings Dialog Box: Startup Servers Tab

On this tab, you can select startup servers for your OS design to include in your SDK.

Available Startup Servers
Select all startup servers that apply to your OS design.

You can also choose which startup server to assign as the default.

Add
Add a startup server to your SDK.

For more information, see Startup Server Properties Dialog Box.

Edit
Modify a startup server.

You cannot modify a startup server if it is a Microsoft component.

For more information, see Startup Server Properties Dialog Box.

Remove
Remove a startup server from your SDK.

You cannot remove a startup server from your SDK if it is a Microsoft component.
