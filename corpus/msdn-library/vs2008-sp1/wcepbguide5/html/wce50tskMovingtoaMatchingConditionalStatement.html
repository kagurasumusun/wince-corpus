Moving to a Matching Conditional Statement

You can move to a matching conditional statement.

To move to a matching conditional statement

  1. Move the insertion point to a line that is enclosed by preprocessor statements such as #ifdef and #endif.
  2. Use the key combination you have chosen to invoke the ConditionalUp command to move the insertion point up to the line containing the matching preprocessor statement.
  3. Use the key combination you have chosen to invoke the ConditionalDown command to move the insertion point down to the line containing the matching preprocessor statement.
