Compiler Error C2539

new : 'class' : no default constructor to initialize arrays of objects

Initializing an array of objects requires a default constructor (a constructor with no parameters), which is called separately for each object in the array.

The constructor was not available.

If a constructor is defined, the compiler does not generate a default constructor and you must supply one.
