New Folder Dialog Box

This dialog box enables you to create a folder on the FileView tab.

For this menu item to be active, you must

  • Be in Project view
  • Have a project open
  • Select a folder on the FileView tab.

The folder you create will be a subfolder of the folder you select on the FileView tab.

This dialog box includes the following items.

Name of the new folder
Use to specify the name for the folder.
File extensions
Select to enter the extensions for files to be stored in the folder.

Separate the extensions by semicolons; for example, ico; bmp; gif; jpeg.

OK
Select to add the folder you just named, and close the dialog box.
Cancel
Select to close the dialog box without saving changes.
