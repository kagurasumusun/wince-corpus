Changing a String or Its Identifier

You can edit the contents of a string or its identifier.

To change a string or its identifier

  1. Select the string to edit.
  2. Choose Properties from the View menu, and then modify the string in the Caption box.
  3. Modify the string identifier in the ID box using the following method:
    • Type a new identifier, or select one from the list.
    • To change a string value, type the identifier followed by an equal sign and the new value, for example IDS_ERROR_MSG=2350.
  4. Press ENTER.
