Custom Brush Creation

A custom brush is a rectangular portion of a graphic that you use like one of the graphics editor default brushes. All operations that you can perform on a selection can be performed on a custom brush.

Pixels in a custom brush that match the current background color are usually transparent; they do not paint over the existing graphic. You can change this behavior so that pixels that have the background color paint over the existing graphic.

You can use the custom brush like a stamp or a stencil to create a variety of special effects.
