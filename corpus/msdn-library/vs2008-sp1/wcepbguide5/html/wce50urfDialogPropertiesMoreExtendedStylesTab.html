Dialog Properties: More Extended Styles Tab

Use this dialog box to configure settings for dialog box styles in the dialog editor.

Right to left layout
When selected, the dialog box is displayed in right to left reading order for languages such as Hebrew or Arabic.
No layout inheritance
When selected, the dialog box does not inherit the layout from a parent window.
