Specifying the Number of Windows That Appear on the Window Menu

You can specify the number of windows that appear on the window menu.

To specify the number of windows that appear on the window menu

  1. From the Tools menu, choose Options and then choose the Workspace tab.
  2. Enter the number of windows in the Window Menu Contains box.
