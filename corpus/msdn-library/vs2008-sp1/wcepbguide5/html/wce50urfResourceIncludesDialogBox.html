Resource Includes Dialog Box

You can use this dialog box to specify resource files that you want to include in your current resource script (.rc) file.

This dialog includes the following items.

Symbol header file
Use to type the name of the symbols file you want to use with the current .rc script.
Read-only symbol directives
Use to include header files containing shared (read-only) or calculated symbols.

Items in the Read-Only Symbol Directives box or the Compile-Time Directives box are included in the resource file exactly as shown.

Be sure there are no spelling or syntax errors.

Compile-time directives
Use to include resource files that are added to your project at compile time.

Be sure there are no spelling or syntax errors.

OK
Use to process your input and close the dialog box.
Cancel
Use to close the dialog box without saving changes.
