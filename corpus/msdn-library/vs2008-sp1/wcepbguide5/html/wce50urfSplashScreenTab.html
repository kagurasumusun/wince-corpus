Platform Builder for Microsoft Windows CE 5.0  

SDK Settings Dialog Box: Splash Screen Tab

On this tab, you can create an OEM splash screen that appears when the user launches the SDK.

Show OEM splash screen at SDK installation
Select if you want a designated splash screen to appear at SDK installation.

The splash screen appears when the installed SDK is launched.

Bitmap
Type the path to the splash screen bitmap.
Duration in seconds
Type the amount of time in seconds that you want the splash screen to be displayed.
