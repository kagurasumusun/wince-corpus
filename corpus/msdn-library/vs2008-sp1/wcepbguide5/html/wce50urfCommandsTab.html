Platform Builder for Microsoft Windows CE 5.0  

Customize Dialog Box: Commands Tab

This tab includes the following settings that you can use to configure toolbars and menus in Platform Builder.

Category
Use to see the default menus and the toolbar buttons, commands, and menus you can add to a toolbar or menu.

When you select an item in the list, toolbar buttons, commands, or menus appear in the box on the right and can be dragged onto a toolbar or menu.

Buttons
Use to see the buttons or other controls associated with the current selection in the Categories list.

To place a button, command, macro, or other item on a toolbar, drag the item you want from the box at the right of the Categories box onto a toolbar.

To create a toolbar, drag the item to the location where you want the toolbar.

Commands
Use to see the commands associated with the current selection in the Categories list.

Click the command or other item you want to add.

If the item you want is not shown, select a different category.

To display a list of every available command, select the All Commands category.

Show Menus for
Use to select the menu items to be displayed while you customize a menu.

For example, if you select All Editors, all commands available on the menu are displayed at one time, but only while you customize the menu.

After you close the Customize dialog box, only commands for the current editor are displayed.

Modify Selection
Use to edit an image graphic for a toolbar button.
Reset All Menus
Use to reset all default menus to their original image graphics, commands, and submenus.

Default submenus are restored to their original form and custom submenus are removed.

The menu bar is also reset.
