Download Run-Time Image Dialog Box

This dialog box displays the status of the action that downloads a run-time image to a target device.

Downloading
Displays the file name of the run-time image being downloaded.
Estimated time left
Displays the estimated time remaining until the download completes.
Download through
Displays the name of the download service through which the run-time image is being downloaded.
Transfer rate
Displays the rate at which data is being downloaded to the target device.
Close this dialog box when download completes
When you select this check box, the dialog box automatically closes after the download completes.
Close
Choose this button to close the dialog box.
Cancel
While the run-time image downloads, choose this button to cancel the download in progress.
