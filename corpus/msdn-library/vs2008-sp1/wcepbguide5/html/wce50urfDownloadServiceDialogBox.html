Platform Builder for Microsoft Windows CE 5.0  

Target Device Connectivity Options: Download Service Dialog Box

When you choose the Settings button associated with the Download field on the Target Device Connectivity Options: Kernel Services Tab after selecting a download service that requires configuration, Platform Builder displays a dialog box where you can configure the download service.

If you select Image Update download service, or select None, no further settings are required.

Selecting any one of the following download services displays a dialog box for configuring the download service:

  • Ethernet Download Settings
  • Serial Download Settings

For more information about this dialog box, see Target Device Connectivity Options Dialog Box.

Ethernet Download Settings

This dialog box allows you to specify settings for the Ethernet download service.

Device Boot Name
Displays the target device that you selected in the Available Devices box.
Available Devices
Allows you to select a target device to which to download a run-time image.
OK
Validates and saves the settings for the Ethernet download service, and then returns to the Kernel Service Map tab.
Cancel
Cancels any changes you made to the settings for the Ethernet download service and closes the dialog box without saving any of the changes.

Serial Download Settings

This dialog box allows you to specify settings for the serial download service.

COM Port
Displays the port to use for serial communication.
Baud Rate
Displays the baud rate for the serial connection.
Data Bits
Specifies the number of data bits.
Parity
Specifies the parity of the serial connection, if any.
Flow Control
Specifies whether you want to use hardware for flow control.
Stop Bits
Specifies the number of stop bits.
OK
Validates and saves the settings for the serial download service, and then returns to the Kernel Service Map tab.
Cancel
Cancels changes you made to the settings for the serial download service and closes the dialog box without saving changes.
