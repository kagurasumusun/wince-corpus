Creating a New Custom Resource or Data Resource

You can create a custom or data resource by placing the resource in a separate file using typical .rc file syntax; then include the file using the Resource Includes command on the View menu.

To create a custom resource or data resource

  1. Create an .rc file that contains the custom or data resource.

    You can type custom data in an .rc file as null-terminated quoted strings or as integers in decimal, hexadecimal, or octal format.

  2. From the View menu, choose Resource Includes.
  3. In the Compile-Time Directives box, type a #include statement and include the file name that contains your custom resource.

    For example, the name for a file named <mydata> is #include mydata.rc.

  4. Verify that the syntax and spelling are correct.

    The contents of the Compile-Time Directives box are inserted into the .rc file exactly as you typed them.

  5. Choose OK to record your changes.
