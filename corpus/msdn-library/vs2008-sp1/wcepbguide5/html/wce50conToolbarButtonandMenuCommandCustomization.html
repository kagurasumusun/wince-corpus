Toolbar Button and Menu Command Customization

You can customize a toolbar button or menu command in the following ways:

  • By changing the image on any toolbar button or menu command, except for a button that displays a list or a menu when you choose it.
  • By copying an image from one toolbar button to another, from one menu command to another, from a toolbar button to a menu command, and from a menu command to a toolbar button.

    You can also create an image in a graphics application and then paste it onto a button or menu command.

  • By displaying text, an icon, or both on a toolbar button. Additionally, you can display either an icon and text or text only on a menu command.
