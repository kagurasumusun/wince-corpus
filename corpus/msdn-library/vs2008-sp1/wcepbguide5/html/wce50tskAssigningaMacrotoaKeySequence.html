Assigning a Macro to a Key Sequence

You can assign a macro to a keyboard shortcut for easier access.

To assign a macro to a keyboard shortcut

  1. From the Tools menu, choose Customize.
  2. Choose the Add-ins and Macro Files tab and make sure the macro files are installed.

    For more information, see Installing a Macro File.

  3. Choose the Keyboard tab.
  4. In the Category list, select Macros.
  5. In the Commands field, select the macro you want to assign a key sequence to.
  6. In the Press New Shortcut Key field, enter the key sequence.
  7. Save your changes by choosing Assign.
