Resetting a Default Toolbar

You can reset the settings for a default toolbar. You cannot reset a custom toolbar.

To reset a default toolbar

  1. From the Tools menu, choose Customize and then choose the Toolbars tab.
  2. In the Toolbars box, select the toolbar.
  3. Choose Reset.
