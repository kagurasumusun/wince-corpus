Platform Builder for Microsoft Windows CE 5.0  

Transports Tab: Add/Edit Transport Dialog Box

On this tab, you can select and edit transport options to communicate between a development workstation and a connected device.

Name
Enter the display name of the transport you want to add.
Host-side file
Choose from the following:
  • Enter the path and file name for the host-side transport .dll file.
  • Browse to select the path and .dll file for host-side transport.
Target-side files
Choose from the following:
  • Select the CPU and .dll file name for target-side transport.
  • Browse to select the path and .dll file for target-side transport.
