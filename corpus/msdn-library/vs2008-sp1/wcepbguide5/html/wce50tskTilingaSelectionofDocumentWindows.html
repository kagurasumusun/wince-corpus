Tiling a Selection of Document Windows

You can tile a selection of document windows in the IDE.

To tile a selection of document windows

  1. From the Window menu, choose Windows.
  2. In the Windows dialog box, select the window names to tile in the list:
    • If the window names are adjacent in the list, select the first window name, press the SHIFT key, and then select the last window name to select those two window names and all window names in between.
    • If the window names are not adjacent, select the first window name, press the CTRL key, and then select each of the other window names.
  3. Choose Tile Horizontally or Tile Vertically in the Windows dialog box.
