Copying and Modifying an Existing .cec File for a Driver

You can copy an existing Catalog item (.cec) file from a driver similar to yours, and modify it for your driver using the CEC Editor. For more information about the CEC Editor, see CEC Editor.

To edit an existing Catalog item file

  1. Copy and rename an existing .cec file.

    - or -

    Copy and paste the contents of a .cec file to your own .cec file.

  2. From the Tools menu, choose CEC Editor.
  3. From the File menu, choose Open and then choose your .cec file.
  4. Update all GUIDs in the .cec file by doing the following:
    1. Navigate the tree of icons in the left pane.
    2. For each GUID in the right pane, choose New.
    3. Make any other changes, such as updating the names of environment variables.
  5. From the File menu, choose Save.
