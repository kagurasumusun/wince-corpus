Toolbar Docking and Floating

The default organization for the Platform Builder user interface (UI) displays the Standard toolbar docked at the top of the main application window.

You can use one of the following modes for the Standard toolbar or any other toolbar:

  • In docked mode, a toolbar is fixed to any of the four borders of the application window. You cannot modify the size of a toolbar when it is docked.
  • In floating mode, a toolbar has a thin title bar and can appear anywhere on your screen. A floating toolbar is always on top. You can modify the size and position of a floating toolbar.
