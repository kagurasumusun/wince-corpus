Graphic Property Modification

Use the Properties window to change most resource properties. Exceptions are new icons or cursors for additional target devices.

By default, the Properties window is hidden when it does not have the focus. To keep the Properties window in view when it does not have the focus, select the Pushpin button in the upper-left corner of the Properties window.

When you create a new graphic using the New command on the File menu, the graphic is always in a bitmap format. You can, however, save your graphic as a GIF or JPEG file.
