Platform Builder for Microsoft Windows CE 5.0  

Resource Browser (RC) Window

The Resource Browser (RC) window displays resources in a resource script file.

Expanding the top-level folder shows the resource types.

Expanding each resource type shows the individual resources of that type.

You can right-click this window to display a shortcut menu of commands.
