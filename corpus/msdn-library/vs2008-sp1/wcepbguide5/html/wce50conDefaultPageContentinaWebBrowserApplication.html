Default Page Content in a Web Browser Application

Your Web browser application can be a container for any Web content, including HTML resources that are part of your project. You use the OnInitialUpdate function of the View class to specify the content to be displayed by the application initially.

The following code example shows how to use the OnInitialUpdate function to display a URL using the Navigate2 method.

Navigate2(_T("http://www.microsoft.com"),NULL,NULL);

The following code example shows how to use the LoadFromResource function to display an HTML resource.

LoadFromResource(IDR_MyHTMLResource);

If your HTML page contains calls to bitmaps or other graphics compiled as part of your project's .rc file, you must use the res: Protocol to display them. The res: Protocol supports displaying a resource that resides in a compiled .dll file or .exe. file.
