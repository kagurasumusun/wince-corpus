_INTRINSIC_IS_INLINE

This macro tests to determine if the compiler can expand a specified intrinsic to one or more lines.

_INTRINSIC_IS_INLINE(arg)
(
  (
    (_INTRINSIC_ ## arg) & 
     _INTRINSIC_INLINE
    ) != 0
)

Parameters

arg
[in] The name of the intrinsic function of interest.

Return Values

A nonzero return value indicates that the intrinsic named by arg can be expanded to an inline sequence of one or more instructions by the compiler.

Requirements

Header: Cmnintr.h.
