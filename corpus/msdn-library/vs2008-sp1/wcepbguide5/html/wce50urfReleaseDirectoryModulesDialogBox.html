Platform Builder for Microsoft Windows CE 5.0  

Release Directory Modules Dialog Box

This dialog box enables you to load modules from the release directory onto a target device. Therefore, you can override existing modules in the run-time image without rebuilding the image.

Platform Builder generates a list of available modules from the .opt file associated with the currently active workspace. Each time you open a different workspace, the contents of Dbglist.txt are overwritten with the list of files contained in the .opt file associated with the new workspace.

Modules to load from release directory
Displays a list of modules to load onto the target device from the release directory.
Add
Adds a module to the list.
Remove
Removes a module from the list.
OK
Applies your changes and closes the dialog box.
Cancel
Closes the dialog box without applying your changes.
