Platform Builder for Microsoft Windows CE 5.0  

SDK Wizard

The SDK Wizard guides you through the process of configuring and building an SDK for Visual Studio .NET, Smart Device Extensions, and eMbedded Visual C++ 4.0.

The wizard generates a Microsoft® Windows Installer (.msi) file that contains the necessary header files, libraries, Platform Manager components, run-time files, OS design extensions, and documentation.

With this SDK, independent software developers can create applications for your Windows CE–based run-time image.

The process of configuring and building an SDK with the SDK Wizard includes the following steps:

  1. Entering the properties for your SDK to uniquely identify it.
  2. Selecting the development languages you want to support.
