Platform Builder for Microsoft Windows CE 5.0  

Workspace Window: ParameterView Tab

In Platform view, the ParameterView tab allows you to view and edit your OS design's source configuration files, including the following files:

  • Binary image builder (.bib) files
  • File system (.dat) files
  • Database (.db) files
  • Registry (.reg) files

This tab displays the source configuration files in the Common, Hardware Specific, and Project Specific directories.

Common files apply to the entire project, whereas hardware specific and project specific files apply only to the hardware platform or the current workspace, respectively.

If your workspace supports CPUs from multiple WINCEROOTs, each root is displayed with its own set of configuration files.

For information about the icons used on the ParameterView tab, see Catalog Item Icon Types.
