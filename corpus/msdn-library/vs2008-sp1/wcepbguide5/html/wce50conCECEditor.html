CEC Editor

The CEC Editor is a tool, accessed from the Tools menu, that you can create and edit Catalog item (.cec) files with. The CEC Editor displays the individual Catalog items from the .cec file that is being edited, along with the properties for each Catalog object.

For more information about creating and modifying Catalog item (.cec) files, see Catalog Item Files.
