Public Speech SDK Directory

The SDK directory contains component files.

The SDK directory contains the following directories.

Directory Contents
Inc Header files that provide support for the Speech feature.
Lib Libraries required to build Speech components.

The libraries are in directories with the following formats:

  • Cpu\Debug
  • Cpu\Retail

An example is Sh4\Retail.

Do not include your libraries in this directory.
Samples Sample applications.
