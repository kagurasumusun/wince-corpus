Custom Resource Properties: Resource Tab

Use this tab to configure settings for a custom resource in the binary editor.

ID
A symbol defined in the header file.

Type: Symbol, Integer, or Quoted String.

Language
Contains the language used for this resource.
Condition
Determines the inclusion of the resource.

For example, if the condition is _DEBUG, this resource is included only in debug configurations.

File name
The name of the file containing the resource.
Preview
A box showing what the bitmap looks like.

It is useful for browsing through graphics resources without opening them.

External file
If selected, the resource contents are stored in an external file listed in the File Name box.

Type: Bool.

Default: True.
