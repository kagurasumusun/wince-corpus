Target Device Connectivity Options: Add Device

You can add or delete the connections that you configure for downloading run-time images to a target device.

For more information about this dialog box, see Target Device Connectivity Options Dialog Box.

New target device name
Specify a name for the connection to the target device that you will download a run-time image to.
(Optional) Associated run-time image/SDK
Specify the run-time image or software development kit (SDK) that you want to associate with the target device.
Add
Apply your changes without closing the dialog box.
Close
Close the dialog box without applying your changes.
