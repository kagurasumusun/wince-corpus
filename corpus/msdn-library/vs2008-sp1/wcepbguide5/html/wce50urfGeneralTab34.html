Catalog Properties: General Tab

On this tab, you can view the properties of a selected Catalog item.

Name
Displays the name of the Catalog item.
Vendor
Displays the name of the object vendor, if available.
Date
Displays the date the Catalog item was added to the Catalog, if available.
Version
Displays the version of the Catalog item.
Size (est.)
Displays the estimated size of the Catalog item, if available.
GUID
Displays the GUID for this Catalog item.
Description
Displays the description or Sysgen variable of the Catalog item, if available.
