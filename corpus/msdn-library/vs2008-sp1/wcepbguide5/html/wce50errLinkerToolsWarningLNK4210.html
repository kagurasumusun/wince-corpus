Linker Tools Warning LNK4210

.CRT section exists; there may be unhandled static initializers or terminators

Some code introduced static initializers or terminators, but the CRT or its equivalent (which needs to run the static initializers or terminators) is not being run when the application starts.

Examples of code that would cause this are:

  • Global class variables with a constructor, destructor, or virtual function table.
  • Global variables initialized with a non-compile-time constant.

To fix this problem:

  • Add corelibc.lib to your linker command line, or
  • Remove all code with static initializers.
  • Do not use /NOENTRY.

LNK4210 can also occur if:

/ENTRY is passed something other than _DllMainCRTStartup. In this case, either remove the /ENTRY linker option, set the entry to _DllMainCRTStartup, or make sure that the DLL entry function calls _CINIT. For more information, see Run-Time Library Behavior.

The /GS - Enable Security Checks compiler option requires CRT startup code.
