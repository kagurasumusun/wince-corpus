Compiler Error C2362

initialization of 'identifier' is skipped by 'goto label'

Jumping to the label prevents the identifier from being initialized.

You cannot jump past a declaration with an initializer unless one of the following has occurred:

  • The declaration is enclosed in a block that is not entered
  • The variable has been initialized
Note: This error occurs only when compiling with the -Za compiler option.

Example

void func()
{
   goto label1;
   int i = 1;         // error, initialization skipped  
   {     
      int j = 1;      // OK, this block is never entered
   }
label1:;
}
