Feature Properties Dialog Box

This dialog box displays information for the selected Catalog item.

This icon and other icons with one cylinder represent Catalog items on the OSDesignView tab and in the Catalog window.

To see the dialog box, right-click on a selected Catalog item and choose Properties.

This dialog box includes the following item.

Pushpin button
Click to keep this dialog box open on your desktop, on top of all other windows. Click again to cancel this functionality.
