File Menu Options

The options on the File menu enable you to work with workspaces.

The following commands are available.

Command Description
New Platform Use to run the New Platform Wizard, which you use to create an OS design. For more information, see New Platform Wizard.
New Project or File Use to run the New Project Wizard, which you can use to create a project. For more information, see New Project Wizard.
Open Use to open a file or document.
Close Use to close an open file or document.
Open Workspace Use to open a workspace.

This option is unavailable if you do not have a workspace open.
Save Workspace Use to save a workspace.

This option is unavailable if you do not have a workspace open.
Close Workspace Use to close a workspace.

This option is unavailable if you do not have a workspace open.
Save Use to save an open file in the current workspace.

This option is unavailable if you do not have a file open.
Save As Use to create a copy of an open file under a new file name.

This option is unavailable if you do not have a file open.
Save All Use to save all open files in the current workspace.
Page Setup Use to change the page layout settings of the current file for viewing or printing.
Print Use to print the file.
Recent Files Use to display a list of the last files you opened.

This option is grayed out if you have not previously opened any files.
Recent Workspaces Use to display a list of the last workspaces you opened.

This option is grayed out if you have not previously opened any files.
Manage Catalog Items Use to manage Catalog items in your Platform Builder installation.

You can modify the Catalog by adding or removing Catalog item (.cec) files associated with Catalog items.
License Run-Time Image Use to add a license to the run-time image you create. For more information, see License Run-Time Image Dialog Box.
Exit Use to close Platform Builder and exit.
