Editing a Macro

If macro files are installed on your development workstation, you can use the Macro editor to modify them.

To edit a macro

  1. To edit a macro, from the Tools menu choose Macro.
  2. In the Macro File box, select the file containing the macro to edit.

    If the file is not in the list, install the file and then select it in the Macro File box.

  3. In the Macro Name box, select the macro to edit.
  4. Choose Edit.
  5. Make the changes you want.
  6. Save the macro file.
