Accelerator Property

The Accel property page enables you to control the behavior of each shortcut key. By default, the property page is dismissed when it does not have the focus. If you want this property page to remain on the screen when it does not have the focus, choose the Pushpin button in the upper-left corner of the window.

You can also select several shortcut keys together and change their properties at the same time.

You can make the following entries in the key box on the Accel property page:

  • An integer from 0 through 255 in decimal, hexadecimal, or octal format. The setting of the Type property determines if the number is an ASCII or virtual-key code.
  • Single-digit numbers are always interpreted as the corresponding key, rather than as ASCII values. To enter an ASCII value from 0 through 9, precede it with two zeros — for example, 006.
  • A single keyboard character. Uppercase letters from A through Z or numbers from 0 through 9 can be either ASCII or virtual-key values; any other character is ASCII only.
  • A single keyboard character in the range from A through Z, uppercase only, preceded by a caret, for example, ^C. This enters the ASCII value of the key when pressed with the CTRL key held down.

    When entering an ASCII value on an Accel property page, the CTRL and SHIFT modifiers for the property page are not available. You cannot use a control-key combination entered with a caret to create a virtual shortcut key.

  • Any valid virtual-key identifier. The Key box on the Accel property page contains a list of standard virtual-key identifiers.

Another way to define a shortcut key is to choose Next Key Typed in the property page and then press any key on the keyboard.

At times, you might want a menu item and a keyboard combination to issue the same command. Do this by assigning the same resource identifier to the menu item and to an entry in your application's accelerator table. Then, edit the menu item to have the accelerator name.
