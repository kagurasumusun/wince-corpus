Linker Tools Warning LNK4014

cannot find member object "objectname"

LIB could not find objectname in the library.

The /REMOVE and /EXTRACT options require the full name of the member object that is to be deleted or copied to a file. The full name includes the path of the original object file.

To see the full names of member objects in a library, use DUMPBIN /ARCHIVEMEMBERS or LIB /LIST.
