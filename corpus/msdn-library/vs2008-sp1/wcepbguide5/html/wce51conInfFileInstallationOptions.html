Device-Side Application Installation Options

On Windows Mobile-based devices, the .inf file can be set up so that the user is allowed to choose the installation volume for the application, either in the main memory volume, called \Device, or in a secondary storage volume, called \Storage Card. This secondary volume can be removable storage, such as a MultiMedia card.

If you do not want the user to choose the volume where the application is installed, you can specify where the application is installed.
