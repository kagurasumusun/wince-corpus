Options Dialog Box: Verbosity Tab

This tab allows you to enable and disable an informational or warning message that is displayed in the integrated development environment (IDE). If you enable a message, the message is displayed when you make the action that triggers the message. If you disable a message, the message is not displayed.

Messages
This list box displays the informational and warning messages that you can choose to display in the IDE. To enable a message, select the check box corresponding to the message. To disable a message, clear the check box corresponding to the message.
