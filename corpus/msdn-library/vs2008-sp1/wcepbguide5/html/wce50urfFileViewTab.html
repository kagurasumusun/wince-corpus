Workspace Window: FileView Tab

The FileView tab shows the organization of the projects and files that are included in your OS design on your hard disk.

To view the logical relationship of the functionality in your OS design, change the focus of the Workspace window to the OSDesignView tab. The icons give you information about the files.

For more information about icons used on the FileView tab, see Catalog Item Icon Types.

The FileView tab shows the relationships of the source code files and the dependent files contained in configurations of your OS design.

The active configuration that you select for your OS design determines the build options used when you build a project. You can select a different active configuration by using the Set Active Configuration command on the Build OS menu.

The FileView tab provides a graphical environment for creating, viewing, and editing files in a workspace. Your objects appear on the FileView tab as part of a directory tree.

On the FileView tab you can do the following tasks:

  • View files and folders.

    To view only files and folders for a specific project, collapse the projects you do not want to see.

  • Open a folder that contains a file you want to examine.
  • Double-click a file to open it in the workspace.
  • Use an editor to modify dirs files by inserting, removing, or rearranging listed directories. This affects the order these directories are built in.

    To do this,

    1. Select the folder containing the dirs file you want to edit.
    2. From the shortcut menu, choose Settings.

    Folders containing dirs files are identified with the icon of a folder that displays two boxes in hierarchical order.
