Platform Builder for Microsoft Windows CE 5.0  

Public IE Directory

The IE directory contains files for components that support the Microsoft® Internet Explorer 6 for Windows CE modules.

The IE directory contains the following directories.

Directory Contents
Cesysgen Files used to build the selected Windows CE modules and components.
OAK OS component files.
SDK SDK component files.
