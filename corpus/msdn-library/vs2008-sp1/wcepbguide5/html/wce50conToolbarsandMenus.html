Toolbars and Menus

You can use toolbars and menus to organize the commands in Platform Builder.

When you start Platform Builder in its default organization, the Standard toolbar appears below the menu bar. When you open various editors, other toolbars appear.

Depending on your workspace preferences and the size of your screen, you can display as many toolbars as you want, or none at all.

The menu bar and other toolbars have the following characteristics:

  • You can create custom toolbars and customize existing toolbars by adding and removing menus and buttons and changing the image or text for a button.
  • You can hide, display, resize, and move toolbars.
  • You can move the menu bar, even when you cannot hide it.
  • The menu bar always fills a complete row when docked horizontally.
  • You cannot hide the menu bar, except in full-screen mode.
  • When you are working with a document in full-screen mode, the menu bar is not displayed. However, you can access the menus with shortcut keys.
  • You can customize the menu bar in the same way that you can customize any toolbar. You can add existing commands to menus and you can delete commands.
  • If you delete a default command from a menu, you can put it back later or add it to a different menu or toolbar. A default command is a command that is supplied with the UI.
  • Some menu commands have images next to them.
  • You can create a toolbar button for a menu command.
