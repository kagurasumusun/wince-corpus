Adding or Deleting a Toolbar Button

You can add or delete a toolbar button.

To add or delete a toolbar button

  1. Display the toolbar you want to change.
  2. From the Tools menu, choose Customize and then choose the Commands tab.
  3. Add or delete buttons as follows:
    • To add a button, select the name of the category in the Category list and then drag the button from the Buttons area to the toolbar.
    • To delete a button, drag it off the toolbar.
