Moving or Copying Files from One Workspace to Another

If you have multiple workspaces, you can move or copy files from one workspace to another to make the development process easier.

To move or copy files

  1. On the FileView tab, select the files you want to move or copy.
  2. From the Edit menu, choose from the following:
    • Choose Cut to move the files.
    • Choose Copy to copy the files.
  3. Close the current workspace.
  4. Open the destination workspace.
  5. Select the project or project folder where the files will be located.
  6. From the Edit menu, choose Paste.
