Platform Builder for Microsoft Windows CE 5.0  

SDK Settings Dialog Box: EULA/Readme Tab

On this tab, you can include a custom end-user license agreement (EULA) and a custom readme file in your custom SDK. If a developer wants to use a custom SDK that includes a custom EULA, he or she must agree to the terms and conditions of both end-user license agreements before installing the custom SDK.

Include custom end-user license agreement
Select to include a custom EULA in your SDK.
End-user license agreement path
Enter the path of the file that contains the EULA.
Note   If you include a custom EULA in your custom SDK, you can only use rich text format (.rtf) files for the custom EULA.
Include custom readme file
Select if to include a custom readme file in your custom SDK.
Readme file path
Enter the path of the readme file.

This file can be in text (.txt), Microsoft Word (.doc), rich text format (.rtf), or HTML (.htm, .html) format.
