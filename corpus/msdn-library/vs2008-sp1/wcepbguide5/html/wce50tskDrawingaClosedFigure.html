Drawing a Closed Figure

From the Graphics toolbar in the IDE, you can select and use a closed-figure drawing tool to draw closed figures.

To draw a closed figure

  1. Select a closed-figure drawing tool from the Graphics toolbar.

    The closed-figure drawing tools create figures as indicated on their respective buttons.

  2. If necessary, select colors and a line width using one of the following methods:
    • Click the left mouse button to select a foreground color or click the right mouse button to select a background color from the Colors palette.
    • Select the line width in the options selector.
  3. Move the cursor to one corner of the rectangular area in which you want to draw the figure.
  4. Drag the cursor to the diagonally opposite corner.
