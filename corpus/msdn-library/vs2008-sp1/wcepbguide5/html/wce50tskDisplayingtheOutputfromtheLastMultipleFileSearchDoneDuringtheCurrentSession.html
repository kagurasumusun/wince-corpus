Displaying the Output from the Last Multiple-File Search Done During the Current Session

You can display the output from the last multiple-file search performed during the current session.

To display the output from the last multiple-file search

  1. Choose the Output command from the View menu.
  2. Choose the Find In Files tab in the Output window.
