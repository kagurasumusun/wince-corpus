Class Management

You can use the WizardBar toolbar and the ClassView window to work with your application classes. These tools give you visual access to the classes and members in your project, including interfaces and dialog resources.

For classes that implement dialog resources, the WizardBar toolbar and the ClassView window enable you to move between the dialog editor and your code.

The ClassView window and the WizardBar toolbar complement each other's functionality in many ways. However, one distinction between them is that the WizardBar toolbar provides immediate access to members of one class at a time, while the ClassView window displays all classes in all projects in the current workspace.

Similarly, the WizardBar toolbar displays, tracks, and acts on only the active project, while the ClassView window displays and acts on all projects in the workspace.

Unlike the ClassView window, the WizardBar toolbar can track and display your current location in code.

Although you can use the ClassView window or the WizardBar toolbar to jump directly to code in the source editor, when you are there, the WizardBar toolbar continues to update its display as you move within a file or from file to file. This provides you with immediate information about your location without having to scroll through the code itself.

The WizardBar toolbar also extends the functionality of the dialog editor, making it easier to switch between designing and viewing source code for a dialog box.

You can perform the following tasks from the ClassView window, but not from the WizardBar toolbar:

  • Adding and editing variables
  • Adding methods and properties to interfaces
  • Jumping to interface definitions or to definitions of methods or properties within an interface
