Specifying Custom Build Actions

You can configure custom build actions for your OS design, including which step in the build process they run at. These settings are applied on a global basis to your OS design. For more information on the syntax you can use, see Custom Build.

To specify custom build actions

  1. From the Platform menu, choose Settings; then choose the Custom Build Actions tab.
  2. Select the build step when you want to perform a custom build action; then choose New.
  3. In the Custom build actions box, type your OS batch file commands, environment variables, and build-rule macros; then choose OK.
  4. (Optional) You can edit a custom build action by selecting it from the Actions for this step list and choosing Edit.
  5. (Optional) You can modify the order of custom build actions by selecting the action you want to move and choosing the Up or Down arrows.
  6. (Optional) You can delete a custom build action by selecting the action you want to delete and choosing Delete.
