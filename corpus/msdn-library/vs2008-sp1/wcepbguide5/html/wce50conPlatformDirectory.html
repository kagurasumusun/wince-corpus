Platform Builder for Microsoft Windows CE 5.0  

Platform Directory

The Platform directory contains high-level directories where device-specific files are stored.

Each directory in the Platform directory has the same name as a hardware platform.

Note   The Public directory contains source for Windows CE OS designs. For more information, see Run-Time Image and OS Directories.

The Platform directory contains the following directories, which might vary depending on the BSPs you selected when you installed Platform Builder on your development workstation.

Directory Contents
Aspen Files and directories for the Renesas SH4 SDB.
BCM91101SP Files and directories for the Broadcom VoIP hardware platform.
CEPC Files and directories for the Windows CE PC-based hardware platform.
Common Files and directories common to all hardware platforms.
DBAU1000 Files and directories for the AMD DBAu1000 development board.
DBAU1100 Files and directories for the AMD DBAu1100 development board.
DBAU1500 Files and directories for the AMD DBAu1500 development board.
Emulator Files and directories for the Windows CE-based virtual hardware platform.
Geode Files and directories for the AMD Geode SP4SC30 development platform, Lanner EM-350 and EM351 Embedded Single Board Computers, and Advantech PCM-5822 and PCM-5823 Biscuit PCs.
MainstoneII Files and directories for the Intel MainstoneII hardware platform.
SG2_VR4131 Files and directories for the NEC Solution Gear 2-Vr4131 development kit.
SG2_VR5500 Files and directories for the NEC Solution Gear 2-Vr5500 development kit.
SDMDK2410 Files and directories for the SMDK2410 Samsung MCU development kit.
