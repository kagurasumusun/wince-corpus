Platform Builder for Microsoft Windows CE 5.0  

Shared Source Code Security Warning

In this dialog box, you are warned that when you build a run-time image based on an OS design that contains shared source code, your run-time image might contain private code that cannot be released in a product under the terms of the Microsoft EULA.

Before you modify source code, Microsoft recommends that you use the command-line tool CeBackup to create a backup of the Windows CE library (LIB) files in your OS design. The build process overwrites the original Microsoft-provided libraries with the modified libraries.

When you are ready to release a product, you can use CeBackup to restore a previously created backup of the LIB files, which replaces the original LIB files in your OS design.

For information about using CeBackup, see CeBackup Tool.

OK
