Platform Builder Directory Structure

Platform Builder for Microsoft® Windows® CE includes directories containing source code that you can use to create and modify OS designs. The directories installed on your development workstation might vary depending on the options you choose when you install Platform Builder.

In This Section

Run-Time Image and OS Directories
Describes the run-time image and OS directories included when you install Platform Builder.
Shared Source Code Directories
Provides a listing of directories that contain shared source code.

These are present only if you chose to install shared source code when you installed Platform Builder on your development workstation.
