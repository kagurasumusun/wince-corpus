Completing the Current Word

If IntelliSense is enabled, you can choose to use automatic word completion.

To complete the current word

  1. Type in the first few letters of the name, and then press CTRL+SPACE.

    IntelliSense completes the name for you. If what you have typed cannot be resolved, the Members list appears, with the nearest matching word highlighted.

  2. Continue typing to narrow the matches.
  3. Press ENTER to select a term from the list.

    Pressing CTRL+SPACE on an empty line, or outside of recognizable scope — for example, just before a function name — opens the Members list populated with global variables.
