New Project Wizard

The New Project Wizard guides you through the process of creating a Windows CE application, console application, dynamic-link library (DLL), static library, transport layer, or Tux DLL. You can also use the New Project Wizard to create files to add to existing projects.

The process of creating a new project with the New Project Wizard might include the following steps:

  1. Selecting the type of project you want to create, including the target location where the project will be created.
  2. Entering information to customize the standard Readme.txt file that is created for the project.
  3. Configuring additional design options if available for the type of project you selected.
  4. Configuring advanced build settings for your project, including selecting a release type for your project. For more information, see RELEASETYPE.

For more information, see Creating a New Project.
