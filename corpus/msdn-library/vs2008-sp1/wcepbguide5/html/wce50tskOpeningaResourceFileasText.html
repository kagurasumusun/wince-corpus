Opening a Resource File as Text

There might be times when you want to view the contents of an .rc file without opening it in a resource editor. For example, you might want to search for a string across all dialog boxes in a resource file without opening each resource separately.

You can open the resource file in text format to view all resources it contains, and perform operations supported by the text editor.

Note   Do not put #ifdef code in the .rc file. Although the resource compiler supports it, the resource editor might remove the #ifdef code. To include #ifdef code, be sure it is in a file (typically with an .rc2 extension) or in a macro, where the resource editor cannot alter it.

To open a resource file as a text file

  1. From the File menu, choose Open and navigate to the resource file you want to view in text format.
  2. From the Open As list, select Text.
