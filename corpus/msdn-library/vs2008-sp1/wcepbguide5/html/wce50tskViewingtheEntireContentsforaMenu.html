Viewing the Entire Contents for a Menu

If you add a command to a menu and the command does not appear when you want to use it, the command might be hidden because it is not available in the current editor.

To verify that the command was added to the menu, you can view all commands on the menu at the same time for all editors.

To view the entire contents for a menu

  1. From the Tools menu, choose Customize and then choose the Commands tab.
  2. In the Show Menus For list, select All Editors.

    If the missing command is listed when you display commands for All Editors, it will appear on the menu in any editor where it applies.
