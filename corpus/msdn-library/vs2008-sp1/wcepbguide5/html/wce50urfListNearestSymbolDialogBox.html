List Nearest Symbol Dialog Box

This dialog box enables you to find function names or labels near an address in code.

The dialog box includes the following items.

Address
Use to enter an address in hexadecimal.
Results
Use to see the function name or labels closest to the entered address.
OK
Select to find the symbols nearest the address you have entered.
Cancel
Use to close the dialog box without saving changes.
Help
Use to open Help to the topic for this dialog box.
