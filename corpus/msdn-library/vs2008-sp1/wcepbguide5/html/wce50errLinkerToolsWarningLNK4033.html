Linker Tools Warning LNK4033

converting object format from OMF to COFF

The format of the object file is OMF. This tool requires COFF input.

The Mircrosoft® eMbedded Visual C++® compiler does not generate .obj files in OMF. The eMbedded Visual C++ compiler generates .obj files in COFF.

You should permanently convert your OMF to COFF.

If you use a tool that can emit either OMF or COFF, choose COFF.

If your tool only emits OMF, check with your vendor for an updated tool that emits COFF.

There are limitations to OMF to COFF conversions. OMF can represent some things that cannot be represented in COFF.

If there are errors when the linker converts from OMF to COFF, you must use COFF .obj files instead of OMF .obj files as input to the linker."

To permanently convert a .OMF file, run EDITBIN, with no options.
