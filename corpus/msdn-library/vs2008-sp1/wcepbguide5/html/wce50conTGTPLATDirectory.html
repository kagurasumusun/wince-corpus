Platform Builder for Microsoft Windows CE 5.0  

%_TGTPLAT% Directory

The %_TGTPLAT% directory contains the files and directories that Microsoft supplies for a hardware platform.

The %_TGTPLAT% directory contains the following directories.

Directory Description
Cesysgen Files used to build the selected Windows CE modules and components.
Files Project-specific files used to build the run-time image, initial directory structure, initialized databases, and initialized registry.
Src Device-specific files used to build the boot loader and kernel.
