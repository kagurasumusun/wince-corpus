Options Dialog Box: Macros Tab

This tab allows you to select one of the following options to determine how to handle a macro that has changed.

  • Select Always reload the file to always reload a macro file after you change a macro in it.
  • Select Never reload the file to never reload a macro file after you change a macro in it.

    However, in the Macro editor, you can always reload a macro file by clicking the right mouse button and then clicking Reload Macro File.

  • Select Ask whether to reload the file to be prompted to reload a macro file after you change a macro in it.
