Platform Builder for Microsoft Windows CE 5.0  

Catalog Window

The Catalog window contains OS configurations, board support packages (BSPs), transport layers, reference hardware drivers, and run-time libraries.

You can import additional Catalog items into the Catalog and add projects to your OS design.

Use the OSDesignView tab and the Catalog together to view and modify your OS design.

The OSDesignView tab shows all objects in your OS design, while the Catalog shows all objects you can add to your OS design.

Always move items from the Catalog to the OSDesignView tab, rather than the other way around.

For information about the icons used in the Catalog window, see Catalog Item Icon Types.
