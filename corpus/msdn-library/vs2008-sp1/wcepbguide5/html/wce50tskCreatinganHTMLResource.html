Creating an HTML Resource

You can create an Hypertext Markup Language (.html) resource file.

To create an HTML resource

  1. Choose Resources from the Insert submenu of the Project menu.
  2. Select HTML in the Resource Type list, and choose New.

    Platform Builder creates a new HTML resource, giving it a unique identifier, such as IDR_HTML1.
