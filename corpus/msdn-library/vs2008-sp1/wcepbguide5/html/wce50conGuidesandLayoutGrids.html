Guides and Layout Grids

Whether you are moving controls, adding controls, or rearranging a current layout, guides can help you align controls accurately within a dialog box.

Guides appear as blue dotted lines across the dialog box displayed in the editor and corresponding arrows in the rulers.

When you create a dialog box, four margins are provided. Margins are modified guides and also appear as blue dotted lines.

You can use the tick marks in the rulers to help you determine the spacing of guides and controls. Like dialog boxes, tick mark are measured in dialog units. A horizontal dialog unit is the average width of the dialog box divided by four. A vertical dialog unit is the average height of the font divided by eight.

The sizing handles of controls snap to the guides when the controls are moved. , and guides snap to controls if no controls have been snapped to the guide previously. When a guide is moved, controls snapped to it move as well. Controls snapped to more than one guide are resized when one of the guides is moved.

You can use special keys in conjunction with the mouse that disable the snapping effect of the guides. Holding down the ALT key disables the snapping effect of the guide selected. Holding down the SHIFT key while moving a guide prevents snapped controls from moving with the guide.

For more precise positioning when placing or arranging controls in a dialog box, use the layout grid. When the grid is turned on, controls snap to the dotted lines of the grid as if magnetized. You can turn this functionality on and off and change the size of the layout grid cells.
