Compiler Error C2764

'parameter' : illegal use of template type-parameter

For example, the following code generates this error:

template<typename T>
class X {
public:
   const T() const;
};

int main()
{
   X<int> x1;

   return 0;
}

Depending on what is intended, one way to fix this would be:

operator const T() const;
