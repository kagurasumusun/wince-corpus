SDK Settings Dialog Box

This dialog box enables you to customize the settings for the software development kit (SDK) that you used the SDK Wizard to create. After you customize the settings for your SDK, you can build the SDK using those settings.

For information about creating an SDK, see How to Create an SDK for a Custom OS Design.

The following list shows the tabs that the SDK Settings dialog box contains.

Install
Configure settings for installation of your SDK. For more information, see Install Tab.
Product Properties
Configure product properties for your SDK. For more information, see Product Properties Tab.
EULA/Readme
Configure the end user license agreement and readme files for your SDK. For more information, see EULA/Readme Tab.
Splash Screen
Add and configure a custom splash screen for your SDK when it is installed. For more information, see Splash Screen Tab.
CPU
Select which configurations of your OS design are supported for each CPU family that your SDK supports. For more information, see CPU Tab.
Transports
Configure the supported transports for your SDK. For more information, see Transports Tab.
Startup Servers
Configure the supported startup servers for your SDK. For more information, see Startup Servers Tab.
Development Languages
Configure the development languages that your SDK supports. For more information, see Development Languages Tab.
Additional Files
Add additional files to your SDK. For more information, see Additional Files Tab.
Help
Add and configure custom Help files to your SDK. For more information, see Help Tab.
Emulation
Configure emulation settings for your SDK. For more information, see Emulation Tab.
