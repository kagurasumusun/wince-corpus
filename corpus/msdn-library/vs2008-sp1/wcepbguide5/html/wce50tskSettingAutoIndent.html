Setting Auto Indent

You can configure the setting for automatic indenting in a file.

To set Auto Indent

  1. From the Tools menu, choose Options.
  2. Choose the Tabs tab.
  3. Under Auto Indent, select the option you want.

    Select None to disable Auto Indent, select Default to set the tab and indent size to the previous level, or select Smart to use Smart Indent to automatically indent the text based on the context of the previous lines.

  4. Choose OK.
