Platform Builder for Microsoft Windows CE 5.0  

Advanced Memory Window

Use this dialog box to locate, relocate, or place data in memory.

The following options are available.

Tab Description
Search Tab Choose to search through memory for whatever is in the data field.
Move Tab Choose to move a chunk of memory from the Start Address through the Range to the Destination.
Fill Tab Choose to fill a chunk of memory with the data from the data field.
Note   This dialog box is not modal. Therefore, you can run the debugger while you locate, relocate, and place data in memory. If the debugger is running, your actions might conflict with the debugger and cause the debugger to stop responding.
