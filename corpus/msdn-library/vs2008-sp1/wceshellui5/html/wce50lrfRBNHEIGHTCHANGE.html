RBN_HEIGHTCHANGE

This message is sent by a rebar control when its height has changed. It is sent in the form of a WM_NOTIFY message. 

RBN_HEIGHTCHANGE lpnmhdr = (LPNMHDR) lParam;

Parameters

lpnmhdr
Long pointer to an NMHDR structure that contains additional information about this message.

Return Values

The return value for this message is not used.

Remarks

Rebar controls that use the CCS_VERT style send this message when their width changes.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Commctrl.h.
