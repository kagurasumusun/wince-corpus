LVN_ITEMCHANGING

This message notifies a list-view control parent window that an item is changing. It is sent in the form of a WM_NOTIFY message. 

LVN_ITEMCHANGING pnmv = (NM_LISTVIEW FAR *) lParam;

Parameters

pnmv
Pointer to an NMLISTVIEW structure that identifies the item and specifies which of its attributes are changing.

Return Values

TRUE prevents the change. FALSE accepts the change.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
