TB_ENABLEBUTTON

This message enables or disables the specified button in a toolbar. 

TB_ENABLEBUTTON wParam = (WPARAM) idButton; 
  lParam = (LPARAM)MAKELONG(fEnable,0);

Parameters

idButton
Command identifier of the button to enable or disable.
fEnable
Enable flag. If set to TRUE, the button is enabled. If set to FALSE, the button is disabled.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
