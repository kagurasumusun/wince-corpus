TreeView_GetDropHilight

This macro retrieves the tree-view item that is the target of a drag-and-drop operation. You can use this macro, or you can explicitly send the TVM_GETNEXTITEM message with the TVGN_DROPHILITE flag.

HTREEITEM TreeView_GetDropHilight(
  hwnd
);

Parameters

hwnd
Handle to the tree view control.

Return Values

The handle to the item indicates success. NULL indicates failure.

Remarks

None.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
