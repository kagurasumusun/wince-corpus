DestroyIcon

This function destroys an icon and frees any memory the icon occupied.

BOOL DestroyIcon(
  HICON hIcon
);

Parameters

hIcon
[in] Handle to the icon to be destroyed. The icon must not be in use.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

This function may be called on the icon handle returned from CreateIconIndirect, ExtractIconEx, LoadImage or LoadIcon. The icon handle is invalid after calling DestroyIcon.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
Link Library: Icon.lib.
