TVN_SETDISPINFO

This message notifies a tree view control's parent window that it must update the information it maintains about an item. It is sent in the form of a WM_NOTIFY message. 

TVN_SETDISPINFO lptvdi = (TV_DISPINFO FAR *) lParam

Parameters

lptvdi
Long pointer to a TV_DISPINFOFO structure. The itemOld and itemNew members contain valid information about the currently selected item and the newly selected item. The action member indicates whether a mouse or keyboard action is causing the selection to change. For a list of possible values, see the description of the TVN_SELCHANGED message.

Return Values

The return value is ignored.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
