ACN_START

This notification notifies an animation control's parent window that the associated AVI clip has started playing. This notification message is sent in the form of a WM_COMMAND message. 

ACN_START

Parameters

None.

Return Values

The return value is ignored.

Requirements

OS Versions: Windows CE 5.0
Header: Commctrl.h.
