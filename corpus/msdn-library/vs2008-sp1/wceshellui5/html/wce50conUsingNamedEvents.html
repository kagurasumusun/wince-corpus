Using Named Events

Windows CE supports named events. The new event-based notification trigger enables an application to create a named event by calling the CreateEvent function and then requesting that the notification subsystem set the named event when the notification event occurs. An application can request that the notification subsystem set the named event by calling the CeSetUserNotificationEx function. In the CE_NOTIFICATION_TRIGGER structure that the application passes to CeSetUserNotificationEx, the application specifies the named event in the lpszApplication member. The following code example shows the format that you should use for the string pointed to by lpszApplication when you want to use lpszApplication to support a named event.

"\\\\.\\Notifications\\NamedEvents\\Event Name"

The application can use either a manual or reset event depending on the desired behavior. By default, the notification subsystem only calls the SetEvent function to trigger the event.
