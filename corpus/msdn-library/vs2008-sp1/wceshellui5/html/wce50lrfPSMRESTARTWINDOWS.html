PSM_RESTARTWINDOWS

This message indicates that Windows needs to be restarted for the changes to take effect. An application should send this message only in response to the PSN_APPLY or PSN_KILLACTIVE message. You can send the PSM_RESTARTWINDOWS message explicitly or by using the PropSheet_RestartWindows macro.

PSM_RESTARTWINDOWS wParam = 0; 
  lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

None.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
