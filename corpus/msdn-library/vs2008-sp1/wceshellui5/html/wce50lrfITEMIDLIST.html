ITEMIDLIST

This structure contains a list of item identifiers.

Syntax

typedef struct _ITEMIDLIST { 
  SHITEMID mkid;
} ITEMIDLIST, *LPITEMIDLIST; 
typedef const ITEMIDLIST* LPCITEMIDLIST;

Members

mkid
List of item identifiers.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Shlobj.h.
