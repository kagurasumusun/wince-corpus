Platform Builder for Microsoft Windows CE 5.0  

Setting Regional Preferences

Platform Builder offers the Regional Settings application in the Control Panel, which allows users to set the appearance of numbers, currencies, dates, and times. The following table shows the modules that you can include in your Cesysgen.bat file to include the Regional Settings application with Control Panel.

Module Description
Intll Includes a Regional Settings Control Panel application with landscape orientation in your OS design.
Intlp Includes a Regional Settings Control Panel application with portrait orientation in your OS design.
Note   The landscape versions of Control Panel applications are fully supported and tested by Microsoft. The portrait versions of these applications are provided as a convenience to OS design developers and are not fully supported or tested by Microsoft.
