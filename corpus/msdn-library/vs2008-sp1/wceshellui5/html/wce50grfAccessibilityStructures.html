Accessibility Structures

The following table shows the Accessibility structures, with a description of the purpose of each.

Programming element Description
ACCESSTIMEOUT This structure contains information about the time-out period associated with the accessibility options.
HIGHCONTRAST This structure contains information about the high-contrast mode accessibility option.
MOUSEKEYS This structure contains information about the mouse keys accessibility option.
SOUNDSENTRY This structure contains information about the sound sentry accessibility option.
STICKYKEYS This structure contains information about the sticky keys accessibility option.
TOGGLEKEYS This structure contains information about the toggle keys accessibility option.
