Platform Builder for Microsoft Windows CE 5.0  

RB_SETPARENT

This message sets a rebar control's parent window. 

RB_SETPARENT wParam = (WPARAM)(HWND) hwndParent; 
  lParam = 0;

Parameters

hwndParent
Handle to the parent window to be set.
lParam
Not used.

Return Values

Returns the handle to the previous parent window, or NULL if there is no previous parent.

Remarks

The rebar control sends messages to the window you specify with this message. This message does not change the actual parent that was set when the control was created.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Commctrl.h.
