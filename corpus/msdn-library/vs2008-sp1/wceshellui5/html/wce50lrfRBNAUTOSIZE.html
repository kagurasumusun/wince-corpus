RBN_AUTOSIZE

This message is sent to the parent by a rebar control created with the RBS_AUTOSIZE style when the rebar automatically resizes itself. It is sent in the form of a WM_NOTIFY message. 

RBN_AUTOSIZE lpnmas = (LPNMRBAUTOSIZE) lParam;

Parameters

lpnmas
Long pointer to a NMRBAUTOSIZE structure that contains information about the resize operation.

Return Values

The return value for this message is not used.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Commctrl.h.
