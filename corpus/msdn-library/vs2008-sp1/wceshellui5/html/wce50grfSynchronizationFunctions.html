Message Synchronization Functions

The following table shows the message synchronization functions, with a description of the purpose of each.

Programming element Description
MsgWaitForMultipleObjects This function returns when one of the specified objects is in the signaled state, or when the time-out interval elapses.
MsgWaitForMultipleObjectsEx This function returns when either one or all of the specified objects are in the signaled state, an I/O completion routine or asynchronous procedure call (APC) is queued to the thread, or the time-out interval elapses.
