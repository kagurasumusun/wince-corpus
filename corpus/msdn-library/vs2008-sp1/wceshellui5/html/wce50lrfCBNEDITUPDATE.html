CBN_EDITUPDATE

This message is sent when the edit control portion of a combo box is about to display altered text. This message is sent after the control has formatted the text, but before it displays the text. The parent window of the combo box receives this message through the WM_COMMAND message. 

CBN_EDITUPDATE idComboBox = (int)LOWORD(wParam); 
  hwndComboBox = (HWND) lParam;

Parameters

idComboBox
Identifier of the combo box.
hwndComboBox
Handle to the combo box.

Return Values

None.

Remarks

If the combo box has the CBS_DROPDOWNLIST style, this message does not occur.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
