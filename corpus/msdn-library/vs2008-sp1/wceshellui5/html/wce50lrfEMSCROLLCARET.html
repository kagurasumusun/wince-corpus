EM_SCROLLCARET

This message scrolls the caret into view in an edit control. 

EM_SCROLLCARET 
  wParam = 0; 
  lParam = 0;

Parameters

wParam
Reserved; set to zero.
lParam
Reserved; set to zero.

Return Values

Nonzero indicates that the message is sent to an edit control.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Windows.h.
