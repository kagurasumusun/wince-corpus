LVM_GETGROUPINFOBYINDEX

This message gets the list-view group's information. This information is based on the group index. 

lResult = SendMessage(
  (hwnd) hwndControl,
  LVM_GETGROUPINFOBYINDEX,
  (WPARAM) iIndex,
  (LPARAM) pgrp
);

Parameters

iIndex
Index of the list-view group.
pgrp
Pointer to an LVGROUP structure that contains the group information.

Return Values

Returns TRUE if the operation was successful and FALSE otherwise.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Commctrl.h.
