GetDoubleClickTime

This function retrieves the current double-click time for the mouse or stylus. 

UINT GetDoubleClickTime(void);

Parameters

None.

Return Values

The return value is the maximum number of milliseconds that can elapse between the first click and the second click for the OS to consider the mouse action a double-click.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Windows.h.
Link Library: Coredll.lib.
