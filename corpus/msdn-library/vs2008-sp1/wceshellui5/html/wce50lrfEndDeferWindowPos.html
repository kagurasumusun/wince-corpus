EndDeferWindowPos

This function simultaneously updates the position and size of one or more windows in a single screen-refreshing cycle.

BOOL EndDeferWindowPos( 
  HDWP hWinPosInfo 
);

Parameters

hWinPosInfo
[in] Handle to a multiple-window – position structure that contains size and position information for one or more windows. This internal structure is returned by the BeginDeferWindowPos function or by the most recent call to the DeferWindowPos function.

Return Values

Nonzero indicates success. Zero indicates failure. To get extended error information, call GetLastError.

Remarks

In Windows CE, the EndDeferWindowPos function sends the WM_WINDOWPOSCHANGED message to each window identified in the internal structure. It does not send a WM_WINDOWPOSCHANGING message.

Requirements

OS Versions: Windows CE 2.10 and later.
Header: Winuser.h.
