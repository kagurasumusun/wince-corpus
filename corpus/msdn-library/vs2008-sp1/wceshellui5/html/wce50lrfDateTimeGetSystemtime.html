DateTime_GetSystemtime

This macro retrieves the currently selected time from a date and time picker (DTP) control and places it in a specified SYSTEMTIME structure.

DWORD DateTime_GetSystemtime(
  HWND hwndDP, 
  LPSYSTEMTIME lpSysTime
);

Parameters

hwndDP
Handle to a DTP control.
lpSysTime
Long pointer to the SYSTEMTIME structure that receives the system time information.

Return Values

Returns a DWORD value that equals GDT_VALID if the time information was successfully placed in the specified structure; or the message can return GDT_NONE if the control was set to the DTS_SHOWNONE style and the control check box was not selected.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Commctrl.h.
