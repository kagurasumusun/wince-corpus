WM_PASTE

This message is sent by an application to an edit control or combo box to copy the current content of the clipboard to the edit control at the current caret position. Data is inserted only if the clipboard contains data in CF_UNICODETEXT format. 

WM_PASTE wParam = 0; 
  lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

None.

Remarks

When sent to a combo box, the WM_PASTE message is handled by its edit control. This message has no effect when sent to a combo box with the CBS_DROPDOWNLIST style.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
