STN_DISABLE

This message is sent when a static control is disabled. The static control must have the SS_NOTIFY style to receive this message. The parent window of the control receives this message through the WM_COMMAND message. 

STN_DISABLE idStatic = (int)LOWORD(wParam); 
  hwndStatic = (HWND)LOWORD(lParam);

Parameters

idStatic
Identifier of the static control.
hwndStatic
Handle to the static control.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
