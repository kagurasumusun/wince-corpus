LVM_MOVEGROUP

This message moves the group to the specified zero-based index.

To send this message, call the SendMessage function. 

lResult = SendMessage(
   (HWND) hWndControl,
   (UINT) LVM_MOVEGROUP,
   (WPARAM) wParam,    // = (WPARAM) (int) iGroupId;
   (LPARAM) lParam     // = (LPARAM) (int) toIndex;
);

Parameters

iGroupId
Value of type int that contains the identifier (ID) of the group to move.
toIndex
Value of type int that specifies the index of the item where the group will move. If it is -1. the group is moved to the end of the list.

Return Values

Returns the index of the item that the group was moved to, or -1 if the operation failed.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Commctrl.h.
