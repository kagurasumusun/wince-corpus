GetClipboardOwner

This function retrieves the window handle to the current owner of the clipboard. 

HWND GetClipboardOwner(void);

Parameters

None.

Return Values

The handle of the window that owns the clipboard indicates success. NULL indicates that the clipboard is not owned. To get extended error information, call GetLastError.

Remarks

The clipboard can still contain data even if the clipboard is not currently owned.

In general, the clipboard owner is the window that last placed data in clipboard. The EmptyClipboard function assigns clipboard ownership.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
Link Library: Clipbd.lib.
