WM_KILLFOCUS

This message is sent to a window immediately before it loses the keyboard focus. 

WM_KILLFOCUS hwndGetFocus = (HWND) wParam;

Parameters

hwndGetFocus
Handle to the window that receives the keyboard focus; can be NULL.

Return Values

An application should return zero if it processes this message.

Remarks

If an application is displaying a caret, the caret should be destroyed at this point.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
