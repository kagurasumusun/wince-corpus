CapEdit Controls Messages

The following table shows the CapEdit control messages, with a description of the purpose of each. Because CapEdit control is a sub-class of Edit Boxes controls, all messages that apply to Edit Boxes controls also apply to CapEdit controls.

Programming element Description
CEM_UPCASEALLWORDS This message controls the conversion of the first letter of every word to uppercase while words are being typed into the edit control.
CEM_ENABLEUPCASE This message controls the conversion of characters to uppercase while they are typed into the edit control.
