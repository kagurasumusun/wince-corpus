TabCtrl_GetCurSel

This macro determines the currently selected tab in a tab control. You can use this macro or send the TCM_GETCURSEL message explicitly.

int TabCtrl_GetCurSel( 
  HWND hwnd 
);

Parameters

hwnd
Handle to the tab control.

Return Values

The index of the selected tab indicates success. –1 indicates that no tab is selected.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
