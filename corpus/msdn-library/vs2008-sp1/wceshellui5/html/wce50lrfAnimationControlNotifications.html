Animation Controls Notifications

The following table shows the animation control notifications, and a description of the purpose for each.

Notifications Description
ACN_START Notifies an animation control's parent window that the associated AVI clip has started playing.
ACN_STOP Notifies an animation control's parent window that the associated AVI clip has stopped playing.
