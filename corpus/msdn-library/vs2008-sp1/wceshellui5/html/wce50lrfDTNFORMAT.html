DTN_FORMAT

This message is sent by a date and time picker (DTP) control to request text to be displayed in a callback field. It is sent in the form of a WM_NOTIFY message. 

DTN_FORMAT lpNMFormat = (LPNMDATETIMEFORMAT) lParam;

Parameters

lpNMFormat
Long pointer to an NMDATETIMEFORMAT structure that contains information regarding this instance of the message. The structure contains the substring that defines the callback field and receives the formatted string that the control will display.

Return Values

The owner of the control must return zero.

Remarks

Handling this message allows the owner of the control to provide a custom string that the control will display. For additional information about callback fields, see Callback Fields.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Commctrl.h.
