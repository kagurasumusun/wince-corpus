ListView_GetColumnWidth

This macro retrieves the width of a column in report or list view. You can use this macro or send the LVM_GETCOLUMNWIDTH message explicitly. 

int ListView_GetColumnWidth( 
  HWND hwnd, 
  int iCol 
);

Parameters

hwnd
Handle to the list-view control.
iCol
Index of the column. This parameter is ignored in list view.

Return Values

The column width indicates success. Zero indicates failure. If this macro is used on a list-view control with the LVS_REPORT style and the specified column does not exist, the return value is undefined.

Remarks

Related message: LVM_GETCOLUMNWIDTH

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
