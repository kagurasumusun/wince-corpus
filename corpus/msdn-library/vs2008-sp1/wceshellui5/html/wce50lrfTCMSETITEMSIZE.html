TCM_SETITEMSIZE

This message sets the width and height of tabs in a fixed-width or owner-drawn tab control. You can send this message explicitly or by using the TabCtrl_SetItemSize macro. 

TCM_SETITEMSIZE wParam = 0; 
  lParam = MAKELPARAM(cx,cy);

Parameters

wParam
Not used.
cx and cy
New width and height, in pixels.

Return Values

Returns the old width and height. The width is in the low-order word of the return value, and the height is in the high-order word.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
