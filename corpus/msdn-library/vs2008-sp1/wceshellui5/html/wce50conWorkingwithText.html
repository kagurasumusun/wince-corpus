Working with Text

After selecting an edit control, a user can select text in the control by using a pointing device or keyboard keys. You can retrieve the starting and ending character positions of the current selection in an edit control by sending the control an EM_GETSEL message.

You also can select text in an edit control by sending the control an EM_SETSEL message that contains the starting and ending character indexes for the selection. For example, you can use EM_SETSEL with the EM_REPLACESEL message to delete text from an edit control. These three messages apply to both single-line and multiline edit controls.

You can replace selected text in an edit control by sending the control an EM_REPLACESEL message that contains a pointer to the replacement text. If there is no current selection, EM_REPLACESEL inserts the replacement text at the insertion point. You might receive an EN_ERRSPACE notification message if the replacement text exceeds the available memory. This message applies to both single-line and multiline edit controls. You can use EM_REPLACESEL to replace part of the text of an edit control or the SetDlgItemText function to replace all of it.
