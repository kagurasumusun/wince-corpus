LVM_SETCOLUMN

This message sets the attributes of a list-view column. You can send this message explicitly or by using the ListView_SetColumn macro. 

LVM_SETCOLUMN wParam = (WPARAM)(int) iCol; 
  lParam = (LPARAM)(const LV_COLUMN FAR *) pcol;

Parameters

iCol
Index of the column
pcol
Pointer to an LVCOLUMN structure that contains the new column attributes. The mask member specifies which column attributes to set.

If the mask member specifies the LVCF_TEXT value, the pszText member is the address of a null-terminated string and the cchTextMax member is ignored.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

Related macro: ListView_SetColumn

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
