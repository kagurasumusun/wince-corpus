TVN_DELETEITEM

This message notifies the parent window of a tree view control that an item has been deleted. It is sent in the form of a WM_NOTIFY message. 

TVN_DELETEITEM pnmtv = (NM_TREEVIEW FAR *) lParam

Parameters

pnmtv
Pointer to an NM_TREEVIEW structure. The itemOld member is a TVITEM structure whose hItem and lParam members contain valid information about the item being deleted.

Return Values

The return value is ignored.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
