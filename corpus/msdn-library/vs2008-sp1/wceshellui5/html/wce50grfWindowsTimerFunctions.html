Windows Timer Functions

The following table shows the window timer functions, with a description of the purpose of each.

Programming element Description
KillTimer This function destroys the specified timer.
SetTimer This function creates a timer with the specified time-out value.
SystemIdleTimerReset This function resets a system timer that controls whether or not the device will automatically go into a suspended state.
TimerProc This function is an application-defined callback function that processes WM_TIMER messages.
