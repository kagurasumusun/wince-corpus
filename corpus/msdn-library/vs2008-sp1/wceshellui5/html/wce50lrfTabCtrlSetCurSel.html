TabCtrl_SetCurSel

This macro selects a tab in a tab control. You can use this macro or send the TCM_SETCURSEL message explicitly.

int TabCtrl_SetCurSel( 
  HWND hwnd, 
  int iItem 
);

Parameters

hwnd
Handle to the tab control.
iItem
Index of the tab to select.

Return Values

The index of the previously selected tab indicates success. –1 indicates failure.

Remarks

A tab control does not send a TCN_SELCHANGING or TCN_SELCHANGE message when a tab is selected using the TCM_SETCUSEL message.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
