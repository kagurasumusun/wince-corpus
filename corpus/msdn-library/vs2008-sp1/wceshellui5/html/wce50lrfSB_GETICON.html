SB_GETICON

This message retrieves the icon for a part in a status bar. To send this message, call the SendMessage function as follows. 

lResult = SendMessage(
  (HWND) hWndControl,
  (UINT) SB_GETICON,
  (WPARAM) wParam,    // = (WPARAM) (INT) iPart;
  (LPARAM) lParam     // = 0; not used, must be zero 
);

Parameters

iPart
Zero-based index of the part that contains the icon to be retrieved. If this parameter is -1, the status bar is assumed to be a simple mode status bar.
lParam
Must be zero.

Return Values

Returns the handle to the icon if successful, or NULL otherwise.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Commctrl.h.
