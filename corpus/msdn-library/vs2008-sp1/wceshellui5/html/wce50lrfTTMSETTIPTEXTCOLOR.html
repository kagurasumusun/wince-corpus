TTM_SETTIPTEXTCOLOR

This message sets the text color for a ToolTip window.

TTM_SETTIPTEXTCOLOR wParam = (WPARAM)(COLORREF) clr;
  lParam = 0;

Parameters

clr
Value of type COLORREF that specifies the new text color.
lParam
Not used. Set to 0.

Return Values

None.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Commctrl.h.
