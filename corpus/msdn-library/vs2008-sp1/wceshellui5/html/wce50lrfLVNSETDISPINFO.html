LVN_SETDISPINFO

This message notifies a list-view control parent window that it must update the data it maintains for an item. It is sent in the form of a WM_NOTIFY message. 

LVN_SETDISPINFO pnmv = (LV_DISPINFO FAR *) lParam;

Parameters

pnmv
Pointer to an LV_DISPINFO structure that specifies data for the changed item. The item member of this structure is an LVITEM structure that contains data about the item that was changed. The pszText member of item contains a valid value, regardless of whether the LVIF_TEXT flag is set in the mask member of this structure.

Return Values

None.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
