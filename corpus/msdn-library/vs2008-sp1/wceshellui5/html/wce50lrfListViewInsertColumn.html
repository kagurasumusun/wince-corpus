ListView_InsertColumn

This macro inserts a new column in a list-view control. You can use this macro or send the LVM_INSERTCOLUMN message explicitly. 

int ListView_InsertColumn( 
  HWND hwnd, 
  int iCol, 
  const LV_COLUMN FAR* pcol 
);

Parameters

hwnd
Handle to the list-view control.
iCol
Index of the new column.
pcol
Pointer to an LVCOLUMN structure that contains the attributes of the new column.

Return Values

The index of the new column indicates success. -1 indicates failure.

Remarks

Related message: LVM_INSERTCOLUMN

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
