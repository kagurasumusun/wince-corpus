ListView_GetNumberOfWorkAreas

This macro retrieves the number of working areas in a list-view control. You can use this macro or send the LVM_GETNUMBEROFWORKAREAS message explicitly. 

#define ListView_GetNumberOfWorkAreas(hwnd, pnWorkAreas) \
  (BOOL)SNDMSG((hwnd), LVM_GETNUMBEROFWORKAREAS, 0, \
  (LPARAM)(UINT *)(pnWorkAreas))

Parameters

hwnd
Handle to the list-view control.
pnWorkAreas
Pointer to a UINT value that receives the number of working areas in the list-view control. If zero is placed in this variable, then no working areas are currently set. This value cannot be NULL.

Return Values

The return value for this macro is not used.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Pcommctrl.h.
