TB_PRESSBUTTON

This message releases the specified button in a toolbar. 

TB_PRESSBUTTON wParam = (WPARAM) idButton; 
  lParam = (LPARAM)MAKELONG(fPress,0);

Parameters

idButton
Command identifier of the button to press or release.
fPress
Press flag. If set to TRUE, the button is pressed. If set to FALSE, the button is released.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
