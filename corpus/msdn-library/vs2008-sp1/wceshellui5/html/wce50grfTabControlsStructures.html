Tab Controls Structures

The following table shows the tab controls structures, with a description of the purpose of each.

Programming element Description
NMTCKEYDOWN This structure contains information about a key press in a tab control.
TCHITTESTINFO This structure contains information about a hit test.
TCITEM This structure specifies or receives the attributes of a tab item.
TCITEMHEADER This structure specifies or receives the attributes of a tab.
