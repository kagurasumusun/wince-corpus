Startup_DestroyDialogCallback

This function destroys the startup dialog.

void Startup_DestroyDialogCallback(void);

Return Values

None.

Remarks

This function is not implemented by the Startui component. It is used by the Startui component when it is ready to destroy the startup dialog.

Requirements

OS Versions: Windows CE 2.10 and later.
Header: Startui.h.
