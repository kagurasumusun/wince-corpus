TreeView_SelectItem

This macro selects the specified tree-view item. You can use this macro or the TreeView_Select macro, or you can send the TVM_SELECTITEM message explicitly.

BOOL TreeView_SelectItem( 
  hwnd, 
  hitem 
);

Parameters

hwnd
Handle to the tree view control.
hitem
Handle to an item. If the hitem parameter is NULL, the control is set to have no selected item.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

When you call the TreeView_SelectItem macro, the parent window of the control receives the TVN_SELCHANGING and TVN_SELCHANGED messages. Also, if the specified item is the child of a collapsed parent item, the of child items for the parent item is expanded to reveal the specified item. In this case, the parent window receives the TVN_ITEMEXPANDING and TVN_ITEMEXPANDED messages.

Using the TreeView_SelectItem macro is equivalent to sending the TVM_SELECTITEM message with its flag parameter set to the TVGN_CARET value.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
