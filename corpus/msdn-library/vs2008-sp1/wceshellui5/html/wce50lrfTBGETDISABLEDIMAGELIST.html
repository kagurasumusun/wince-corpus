TB_GETDISABLEDIMAGELIST

This message retrieves the image list that a toolbar control uses to display disabled buttons. 

TB_GETDISABLEDIMAGELIST wParam = 0; 
  lParam = 0;

Parameters

wParam
Not used.
lParam
Not used.

Return Values

Returns the handle to the disabled image list or NULL if no disabled image list is set.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Commctrl.h.
