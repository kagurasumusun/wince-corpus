Adding Items and Subitems

Each item in a list view control has an icon, a label, a current state, and an application-defined value. By using list view messages, you can add, modify, and delete items, as well as retrieve item data. You also can find items that have specific attributes.

Each item also can have one subitem or more. A subitem is a string that, in report view, is displayed in a column that is to the right of the icon and label of an item. To specify the text of a subitem, use the LVM_SETITEMTEXT message or the LVM_SETITEM message. All of the items that are in a list view control have the same number of subitems. The number of subitems is determined by the number of columns that are in the list view control.

The LVITEM structure defines a list view item or subitem. To add an item to a list view control, use the LVM_INSERTITEM message. Before you add multiple items, you can send the control an LVM_SETITEMCOUNT message to specify the number of items that the control ultimately will contain. This message enables the list view control to reallocate its internal data structures only once, instead of every time that you add an item. Determine the number of items that are in a list view control by using the LVM_GETITEMCOUNT message.

Use the LVM_SETITEM message to change the attributes of a list view item. The LVM_SETITEMTEXT message changes only the text of an item or subitem.

To retrieve the data in a list view item, use the LVM_GETITEM message and specify the address of the LVITEM structure to fill. To retrieve only the text of an item or subitem, use the LVM_GETITEMTEXT message. To delete a list view item, use the LVM_DELETEITEM message. Delete all of the items in a list view control by using the LVM_DELETEALLITEMS message.
