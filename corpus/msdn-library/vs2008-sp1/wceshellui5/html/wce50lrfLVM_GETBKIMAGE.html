LVM_GETBKIMAGE

This message retrieves the background image in a list-view control. You can send this message explicitly or by using the ListView_GetBkImage macro.

To send this message, call the SendMessage function. 

lResult = SendMessage(
   (HWND) hWndControl,
   (UINT) LVM_GETBKIMAGE,
   (WPARAM) wParam,     // = 0; not used, must be zero
   (LPARAM) lParam      // = (LPARAM) (LPLVBKIMAGE) plvbki;
);    

Parameters

wParam
Must be zero.
plvbki
Pointer to an LVBKIMAGE structure that will receive the background image information.

Return Value

Returns nonzero if successful, or zero otherwise.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Commctrl.h.
