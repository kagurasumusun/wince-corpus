Creating an Empty Display-Based OS

The following steps describe how to create an empty display-based Windows CE OS without additional feature support.

An empty OS is a good starting point for investigating single Catalog items or other OS design changes in isolation.

Note   These steps create a small and simple OS; however, they do not create the smallest possible Windows CE-based OS.

To create an empty display-based OS

  1. In Platform Builder, from the File menu, choose New Platform.

    The New Platform Wizard - Step 1 appears.

  2. Choose Next.
  3. Type a friendly name for the platform in the Name text box, and choose Next.
  4. Select the check box that corresponds to your hardware platform and choose Next.
  5. Choose Custom Device and choose Next.
  6. Skip the subsequent dialog boxes by choosing Next until you get to the dialog box in which you specify the Shell and User Interface options.
  7. From the list of options, choose Shell and choose Finish. The wizard's final page appears.
  8. Choose Finish.
