Platform Builder for Microsoft Windows CE 5.0  

Shell and User Interface Catalog Items

The following table shows the Catalog items under the Shell and User Interface node and the associated Sysgen variable with a description of the purpose of each.

Feature Sysgen variable Description
Minimal GDI Configuration SYSGEN_MINGDI This catalog item provides support for the Minimal GDI Configuration in the run-time image.
Minimal GWES Configuration SYSGEN_MINGWES This catalog item provides support for the Minimal GWES Configuration in the run-time image.
Minimal Input Configuration SYSGEN_MININPUT This catalog item provides support for the Minimal Input Configuration in the run-time image.
Minimal Window Manager Configuration SYSGEN_MINWMGR This catalog item provides support for the Minimal Window Manager Configuration is included in the run-time image.
AYGShell API Set SYSGEN_AYGSHELL This catalog item provides support for the AYGShell API extensions in the run-time image.
Command Processor SYSGEN_CMD This catalog item provides support for the Command Processor Catalog item in the run-time image.

When this variable is not set, the Command Processor Catalog item is excluded from the run-time image.
Console Window SYSGEN_CONSOLE This catalog item includes the Console Window Catalog item in the run-time image.
Standard Shell SYSGEN_STANDARDSHELL This catalog item includes the Standard Shell functionality in the run-time image.
Windows Thin Client Shell SYSGEN_WBTSHELL This catalog item includes the Windows Thin Client Shell functionality in the run-time image.
Accessibility SYSGEN_ACCESSIB This catalog item provides support for the Accessibility Catalog item in the run-time image.
Animation Control SYSGEN_COMMCTRL This catalog item provides support for the common control functionality in the run-time image.
Common Control SYSGEN_COMMCTRL_ANIMATE This catalog item provides support for the animation control functionality in the run-time image.
Common Dialog Support SYSGEN_COMMDLG This catalog item provides support for common dialogs in the run-time image.
Control Panel Applets SYSGEN_CTLPNL This catalog item provides support for Control Panel applications in the run-time image.
Controls B Option SYSGEN_PPC This catalog item provides support for Controls Option B in the run-time image.

Controls Option B enables a set of controls with slightly different behavior than the default option, to enable Pocket PC applications to be compatible with Windows CE-based devices.

Windows XP-like Sample Skin SYSGEN_XPSKIN This catalog item provides support for Windows XP-like sample skin in the run-time image.
Menu Tool Tip SYSGEN_MENU_TAP_UI This catalog item provides support for Tap UI menus in the run-time image.
Mouse SYSGEN_CURSOR This catalog item provides support for the Mouse functionality in the run-time image.
Network User Interface SYSGEN_CONNMC When this variable is set, Network User Interface is included in the run-time image. It includes the Network and Dial-up Connections application that is used to configure dial up, VPN, LAN, and other network connection types.
Overlapping Menus SYSGEN_MENU_OVERLAP This catalog item provides support for the Overlapping Menus functionality in the run-time image.
Quarter VGA Resources - Portrait Mode SYSGEN_QVGAP This catalog item provides support for Quarter VGA Resources (Portrait Mode) in the run-time image.
Software-based Input Panel Driver SYSGEN_SOFTKB This catalog item provides support for SIP driver in the run-time image. When this variable is not set, the SIP driver is excluded from the run-time image.
SIP for Large Screens SYSGEN_LARGEKB This catalog item provides support for the IM for Large Screens in the run-time image.
SIP for Small Screens SYSGEN_MSIM This catalog item provides support for the input method (IM) for Small Screens in the run-time image.
Touch Screen (Stylus) SYSGEN_TOUCH This catalog item provides support for the Touch Screen (Stylus) in the run-time image.
