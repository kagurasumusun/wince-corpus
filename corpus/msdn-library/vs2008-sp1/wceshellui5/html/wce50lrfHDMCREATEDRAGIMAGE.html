HDM_CREATEDRAGIMAGE

This message creates a transparent version of an item's image within an existing header control. 

HDM_CREATEDRAGIMAGE wParam = (WPARAM) 
  (int) iIndex; 
  lParam = 0;

Parameters

iIndex
Zero-based index of the item within the header control. The image assigned to this item is the basis for the transparent image.
lParam
Not used.

Return Values

Returns a handle to an image list that contains the new image as its only element

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
