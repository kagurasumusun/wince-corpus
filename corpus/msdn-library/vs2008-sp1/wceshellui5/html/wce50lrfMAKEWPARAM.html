MAKEWPARAM

This macro creates an unsigned 32-bit value for use as a wParam parameter in a message. The macro concatenates two specified 16-bit values. 

LPARAM MAKEWPARAM( 
  WORD wLow, 
  WORD wHigh 
);

Parameters

wLow
Specifies the low-order word of the new long value.
wHigh
Specifies the high-order word of the new long value.

Return Values

The return value is an unsigned 32-bit value.

Remarks

The MAKEWPARAM macro is defined as follows. 

#define MAKEWPARAM(l, h)   ((LPARAM) MAKELONG(l, h))

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winuser.h.
