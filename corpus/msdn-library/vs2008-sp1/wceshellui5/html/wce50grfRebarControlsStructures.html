Rebar Controls Structures

The following table shows the rebar controls structures, with a description of the purpose of each.

Programming element Description
NMRBAUTOSIZE This structure contains information used in handling the RBN_AUTOSIZE messages.
NMREBAR This structure contains information used in handling the RBN_BEGINDRAG and RBN_ENDDRAG messages.
RBHITTESTINFO This structure contains information specific to a hit test operation.
REBARBANDINFO This structure contains information that defines a band in a rebar control.
REBARINFO This structure contains information that describes rebar control characteristics.
