TreeView_EndEditLabelNow

This macro ends the editing of a label for a tree-view item. You can use this macro or send the TVM_ENDEDITLABELNOW message explicitly.

BOOL TreeView_EndEditLabelNow( 
  hwnd, 
  fCancel 
);

Parameters

hwnd
Handle to the tree view control.
fCancel
Variable that indicates whether the editing is canceled without being saved to the label. If set to is TRUE, the system cancels editing without saving the changes. If set to FALSE, the system saves the changes to the label.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

This macro causes the TVN_ENDLABELEDIT message to be sent to the parent window of the tree view control.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
