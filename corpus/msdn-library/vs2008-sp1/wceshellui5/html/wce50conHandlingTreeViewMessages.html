Handling Tree-View Messages

A tree-view control notifies the parent window that the selection has changed from one item to another by sending the TVN_SELCHANGING and TVN_SELCHANGED messages. These messages also include data about the item that gains the selection and the item that loses the selection. You can use this data to set item attributes that depend on the selection state of the item. Returning TRUE in response to TVN_SELCHANGING rejects the selection change and returning FALSE accepts the selection change. You can change the selection by sending the TVM_SELECTITEM message.

Tree-view controls support a number of messages that retrieve data about items in the control.

The TVM_GETITEM message can retrieve the handle and attributes of an item. The attributes of an item include its current state, the indexes of the selected and unselected bit images of the item in the image list of the control, a flag that indicates whether the item has child items, the address of the label string of the item, and the application-defined 32-bit value of the item.

The TVM_GETNEXTITEM message retrieves the tree-view item that bears the specified relationship to the current item. The message can retrieve the parent of an item, the next or the previous visible item, the first child item, and so on.

The TVM_GETITEMRECT message retrieves the bounding rectangle for a tree-view item. The TVM_GETCOUNT and TVM_GETVISIBLECOUNT messages, respectively, retrieve a count of the items in a tree-view control and a count of the items that can be fully visible in the window of a tree-view control. You can ensure that a particular item is visible by using the TVM_ENSUREVISIBLE message.
