RENAME, REN

This command renames a file or files.

RENAME [path]file_name1 file_name2
REN [path]file_name1 file_name2

Parameters

path
Specifies the path for the file that you can to rename.
file_name1
Specifies the current name of the file that you want to rename.
file_name2
Specifies the new name for the file that you want to rename.

Remarks

You cannot specify a new drive or path for your destination file.
