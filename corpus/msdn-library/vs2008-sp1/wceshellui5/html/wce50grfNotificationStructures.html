Notification Structures

The following table shows the structures available to OS developers for the notification system, with a description of the purpose of each.

Programming element Description
NotifyPacket This structure describes a notification event and is used for low-level communication between OEM code and the notification subsystem.
PersistentPacket This structure contains the information about a notification as recorded in the notification database.
SettingsDialogData This structure holds data about user settings on a per-dialog basis.
