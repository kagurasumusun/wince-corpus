Dialing Characters Registry Settings

The registry settings for dialing include a registry value that contains a replacement list of legitimate dialing characters. The list does not include the characters 0-9 because the OS assumes by default that the characters 0-9 are legitimate characters. The OS reads the following registry value each time the dialog box for dialing is displayed.

[HKEY_CURRENT_USER\ControlPanel\Dial]
    "Digits": REG_SZ
