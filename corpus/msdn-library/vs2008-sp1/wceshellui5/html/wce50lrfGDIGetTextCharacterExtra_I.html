GDI::GetTextCharacterExtra_I

This method retrieves the current intercharacter spacing for the specified device context. 

int GetTextCharacterExtra(
  HDC hdc
);

Parameters

hdc
[in] Handle to the device context.

Return Values

If the method succeeds, the return value is the current intercharacter spacing, in logical coordinates.

If the method fails, the return value is 0x8000000.

Remarks

The intercharacter spacing defines the extra space, in logical units along the base line, that the Gdi::ExtTextOutW_I method adds to each character as a line is written. The spacing is used to expand lines of text.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Gdi.hpp.
