LVM_REDRAWITEMS

This message forces a list-view control to redraw a range of items. You can send this message explicitly or by using the ListView_RedrawItems macro.

Call the SendMessage function to send this message.. 

lResult = SendMessage(
  (HWND) hWndControl,
  (UINT) LVM_REDRAWITEMS,
  (WPARAM) wParam,      // = (WPARAM) (int) iFirst;
  (LPARAM) lParam       // = (LPARAM) (int) iLast; );
);

Parameters

iFirst
Index of the first item to redraw.
iLast
Index of the last item to redraw.

Return Values

TRUE indicates success. FALSE indicates failure.

Remarks

Related macro: ListView_RedrawItems

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Commctrl.h.
