Enabling Slide Animation for the Taskbar

Windows CE enables slide animation for the taskbar by default. You can turn this animation on or off by changing the value of the HKEY_LOCAL_MACHINE\Software\Microsoft\Shell\SlideTaskBar registry key. Set the value of this registry key to 1 to turn slide animation on, and set the value to 0 to turn slide animation off.

If the registry key does not exist, slide animation is turned on. Add the key and set it to 0 to disable slide animation.

Slide animation for the taskbar also requires that you turn on the autohide characteristic of the taskbar. To turn on the autohide characteristic, set the HKEY_LOCAL_MACHINE\Software\Microsoft\Shell\AutoHide registry entry.
