Standard Shell Macros

The following table shows the standard shell macros, with description of the purpose of each.

Programming element Description
InsetRect This macro calls the InflateRect function.
MapWindowRect This macro calls the function MapWindowPoints.
SetDlgMsgResult This macro maps to the SetWindowLong function.
