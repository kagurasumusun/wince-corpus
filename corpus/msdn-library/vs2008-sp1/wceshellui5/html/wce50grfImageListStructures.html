Image List Structures

The following table shows the image list structures, with a description of the purpose of each.

Programming element Description
IMAGEINFO (Graphics, Windowing and Events) This structure contains information about an image in an image list.
IMAGELISTDRAWPARAMS This structure contains information about an image list draw operation and is used with the ImageList_DrawIndirect function.
