NMKEY

This structure contains information used with key messages. 

typedef struct tagNMKEY {
  NMHDR hdr;
  WORD wVKey;
  UINT flags;
} NMKEY, FAR* LPNMKEY;

Members

hdr
Handle to a NMHDR structure that contains additional information about this message.
wVKey
Virtual key code of the key that caused the event.
flags
Flags associated with the key. These are the same flags that are passed in the high-order word of the lParam in the WM_KEYDOWN message.

Requirements

OS Versions: Windows CE 2.0 and later.
Header: Commctrl.h.
