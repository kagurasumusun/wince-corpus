Gdi::RectInRegion_I

This method determines whether any part of the specified rectangle is within the boundaries of a region.

static WINGDIAPI BOOL WINAPI RectInRegion_I(
  HRGN hrgn, 
  const RECT* lprc
);

Parameters

hrgn
[in] Handle to the region.
lprc
[in] Long pointer to a RECT structure that contains the coordinates of the rectangle. The lower and right edges of the rectangle are not included.

Return Values

Nonzero indicates that any part of the specified rectangle lies within the boundaries of the region.

Zero indicates that no part of the specified rectangle lies within the boundaries of the region.

Remarks

This method is an internal version of the RectInRegion function.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Gdi.hpp.
