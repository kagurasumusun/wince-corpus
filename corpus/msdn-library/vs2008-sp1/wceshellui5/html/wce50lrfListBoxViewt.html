ListBoxView_t

This class provides methods for drawing the UI associated with a list box.

Method Description
DrawFocus Draws or removes a focus rectangle around a list box item.
ItemHeight Retrieves the height of an item in a list box.
TopCoordinate Determines the y-coordinate at which the text for a list box item should be drawn.
