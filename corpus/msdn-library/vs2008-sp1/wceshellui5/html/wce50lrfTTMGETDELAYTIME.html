TTM_GETDELAYTIME

This message retrieves the initial, pop-up, and reshow durations currently set for a ToolTip control.

TTM_GETDELAYTIME wParam = (DWORD) dwDuration;
  lParam = 0;

Parameters

dwDuration
DWORD that specifies the type of duration that you want to retrieve. The following table shows the possible values.
Value Description
TTDT_AUTOPOP Retrieves the length of time the ToolTip window remains visible if the pointer is stationary within the bounding rectangle of a tool.
TTDT_INITIAL Retrieves the length of time the pointer must remain stationary within the bounding rectangle of a tool before the ToolTip window appears.
TTDT_RESHOW Retrieves the length of time that elapses before subsequent ToolTip windows appear when the pointer moves from one tool to another.
lParam
Not used. Set to 0.

Return Values

The return value is an integer value that contains the specified duration in milliseconds.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Commctrl.h.
