ListView_GetToolTips

This macro retrieves the ToolTip control that the list-view control uses to display ToolTips. You can use this macro or send the LVM_GETTOOLTIPS message explicitly. 

HWND ListView_GetToolTips(
   HWND hwnd
);

Parameters

hwnd
Handle to the list-view control.

Return Values

Returns the handle to the ToolTip control.

Remarks

None.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Commctrl.h.
