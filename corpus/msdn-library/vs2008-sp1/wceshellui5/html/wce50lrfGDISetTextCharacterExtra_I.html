GDI::SetTextCharacterExtra_I

This method sets the intercharacter spacing. Intercharacter spacing is added to each character, including break characters, when the system writes a line of text. 

int SetTextCharacterExtra(
  HDC hdc,
  int nCharExtra
);

Parameters

hdc
[in] Handle to the device context.
nCharExtra
[in] Specifies the amount of extra space, in logical units, to be added to each character. If the current mapping mode is not MM_TEXT, the nCharExtra parameter is transformed and rounded to the nearest pixel.

Return Values

If the method succeeds, the return value is the previous intercharacter spacing.

If the method fails, the return value is 0x80000000.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Gdi.hpp.
