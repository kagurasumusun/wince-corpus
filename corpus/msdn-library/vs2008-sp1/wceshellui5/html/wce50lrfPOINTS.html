POINTS

This structure defines the coordinates of a point. 

typedef struct tagPOINTS { 
  SHORT x; 
  SHORT y; 
} POINTS;

Members

x
Specifies the x-coordinate of the point.
y
Specifies the y-coordinate of the point.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Windef.h.
