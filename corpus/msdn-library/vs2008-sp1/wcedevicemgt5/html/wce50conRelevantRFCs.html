Relevant RFCs

The following table shows a list of RFCs that describe important technologies of SNMP.

RFC Title
1157 A Simple Network Management Protocol (SNMP), which defines SNMP
1212 Concise MIB Definitions, which defines the format that is used for constructing MIBs
1213 Management Information Base for Network Management of TCP/IP–based Internets: MIB-II, which defines MIB_II.MIB
1215 A Convention for Defining Traps for Use with the SNMP, which provides a convention for defining traps for use in SNMP
1514 Host Resources-MIB
1901 Introduction to Community–based SNMPv2
1905 Structure of Management Information for Version 2 of the Simple Network Management Protocol (SNMPv2)
1906 Transport Mappings for Version 2 of the Simple Network Management Protocol
1907 Management Information Base for Version 2 of the Simple Network Management Protocol (SNMPv2)
Note   The snmpTrapOID, snmpTrapEnterprise, and snmpSetSerialNo objects, described in RFC 1907, are not supported.
