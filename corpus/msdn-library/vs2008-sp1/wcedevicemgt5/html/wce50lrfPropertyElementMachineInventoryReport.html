Property Element (Machine Inventory Report)

This element exists within the InventoryItem element, and is used to provide information about a specific property of an inventoried item.

<Property
name="Name of property"
/>

Attributes

name
This attribute is used to name a particular property. The value of the property is provided as the inner text of the element.
