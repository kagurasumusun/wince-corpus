Device Management Client Structures

The following table shows the device management structures.

Programming element Description
DMSINVRECORD This structure stores the database records.
DMTASKINFO This structure contains task information passed from the application to Dmsdklib.
DMSDLINFO This structure defines the download information.
DMSINVPKGID This structure defines the package ID information.
