SnmpVarBind

This structure represents an SNMP variable binding. This structure is used by multiple SNMP functions. This structure is not used by the WinSNMP API functions. 

typedef struct {
  AsnObjectName name;
  AsnObjectSyntax value;
}SnmpVarBind;

Members

name
Indicates the variable's name, as an object identifier.
value
Contains the variable's name.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Snmp.h.
