goto (Device Management Client)

This command changes the execution flow of script commands.

goto [label]

Parameters

label
Specifies the label to branch to. Labels are specified as in MS-DOS batch files by starting a line with a colon followed by the label's name.

Remarks

The following code example shows the use of the goto command to change the flow of execution to a label in the case where a particular package is not installed:

if boolean `pkginstalled Sample` == FALSE
  echo "Package not installed!"
  goto error
endif
echo "No Error!"
quit

:error
echo "Package Sample not installed!"
