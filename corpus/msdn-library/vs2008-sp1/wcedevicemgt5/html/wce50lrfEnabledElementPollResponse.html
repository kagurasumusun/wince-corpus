Enabled Element (Poll Response)

This element can exist within the SoftwareInventorySettings element, FileCollectionSettings element, and the MachineInventorySettings element. In all these case, it is used to denote whether or not the feature is enabled. If the feature is enabled, the appropriate report will be generated by the client and sent to the server.

<Enabled
/>

Attributes

None.
