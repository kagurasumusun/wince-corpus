SnmpUtilMemFree

This function frees the specified memory object.

VOID SnmpUtilMemFree(
  LPVOID pMem 
);

Parameters

pMem
[in, out] Pointer to the memory object to release.

Return Values

This function has no return values.

Remarks

Call the SnmpUtilMemAlloc function to allocate the memory for the object.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Snmp.h.
Link Library: Snmpapi.lib.
