runasync

This command runs an executable on the client. Programs invoked by this command are run asynchronously. 

runasync [command line]

Parameters

command line
The exact command line to run. This should be the absolute path of a program followed by any arguments.

Remarks

The following example shows how you can use this command:

onerror Error
runasync "cmd.exe /c ipconfig"
echo "PASS!!!"
quit
:Error
echo "FAIL!!!"
