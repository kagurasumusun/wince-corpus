ClientSettings Element (Poll Response)

This element exists within the Settings element, and is the top-level element of the section that groups general client settings. These settings define values which the client uses to communicate with the server.

<ClientSettings
version="Version of settings"
/>

Attributes

version
The version of the set of settings defined by the enclosed elements.
