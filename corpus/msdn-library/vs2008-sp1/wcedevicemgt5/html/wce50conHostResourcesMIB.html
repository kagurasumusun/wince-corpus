Host Resources MIB

Host Resources MIB is defined in RFC 1215. Host Resources MIB supports the following object groups:

  • Host Resources System Group
  • Host Resources Storage Group
  • Host Resources Device Group
  • Host Resources Running Software Group
  • Host Resources Installed Software Group
    Note   Windows CE does not support the Host Resources Running Software Performance Group.
