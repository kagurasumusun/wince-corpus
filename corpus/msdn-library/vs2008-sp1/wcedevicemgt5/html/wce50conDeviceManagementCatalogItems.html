Device Management Catalog Items

The following table shows the Catalog items under the Device Management node and the associated Sysgen variable with a description of the purpose of each.

Catalog item Sysgen variable Description
Device Management Client SYSGEN_DEVMGMT This catalog item provides support for the Device Management Client in the run-time image.

For more information, see Device Management Client.
Simple Network Management Protocol (SNMP) SYSGEN_SNMP This catalog item provides support for the Simple Network Management Protocol (SNMP) in the run-time image.

For more information, see Simple Network Management Protocol.
