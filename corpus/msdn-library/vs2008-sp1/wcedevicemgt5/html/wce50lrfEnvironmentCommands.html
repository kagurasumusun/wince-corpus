Environment Commands

The following table shows the environment commands.

Command Definition
filecreated Returns the creation date of a file or directory.
fileexists Determines whether a particular file or directory currently exists on the client.
filelastmodified Returns the last modification date of a file or directory.
filesize Returns the size in bytes of a file.
reg Returns a string representing the contents of a registry value on the client.
set Sets or clears a local variable.
