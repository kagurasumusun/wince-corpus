Behavior Element (Instruction Response)

This element exists within the Recurrence element, and it defines the download behavior of recurring packages by specifying whether the device downloads and executes the package, or if it only executes the package.

The download behavior defined by this element occurs at the recurrence interval defined by the Interval element.

<Behavior
/>

Attributes

None.

Remarks

The following table shows the values that this element can take.

Behavior value Description
Download and Execute Download and execute the package.
Execute Only Execute the package.
