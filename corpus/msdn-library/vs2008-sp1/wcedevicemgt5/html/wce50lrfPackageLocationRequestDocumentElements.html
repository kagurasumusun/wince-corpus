Package Location Request Document Elements

This reference section groups all the XML elements that are used in the package location request document that the client, or device, sends to the server.

The following table shows the Package Location Request XML elements.

Element Description
PackageLocationRequest Root element of the Package Location Request document.
PackageID Unique ID for this particular package.
ClientLocation Top-level element of the section that describes the client's location.
DirectoryService Top-level element that encapsulates information about the directory service this client is a part of.
Name The name of the directory that contains this client.
IPAddresses Top-level element used to provide IP-based location information for this client.
IPAddress Top-level element used to contain IP address information.

For more information about this XML document, see Package Location Request to Server.
