IPAddress Element (Location Request)

This element exists within the IPAddresses element, and is the top-level element used to contain IP address information.

<IPAddress
address="IPaddress of client"
subnet="Subnet address of client"
/>

Attributes

address
This attribute specifies the IP address of the client to the server.
subnet
This attribute specifies the subnet address of the client to the server.
