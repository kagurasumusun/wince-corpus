Platform Builder for Microsoft Windows CE 5.0  

Samples

Your Microsoft Windows CE installation contains numerous code samples to help you learn Windows CE programming techniques and concepts. In addition to these samples there are sample board support packages (BSPs), drivers, and applications that are ready for use in a production environment. You can use many samples as final products or you can customize them to more closely suit your device requirements.

The following list shows locations of code samples in your Windows CE installation.

  • %_WINCEROOT%\PLATFORM
  • %_WINCEROOT%\PUBLIC\COMMON\OAK\CATALOG\CEC
  • %_WINCEROOT%\PUBLIC\COMMON\OAK\DRIVERS
  • %_WINCEROOT%\PUBLIC\COMMON\OAK\UTILS\SHELLEXTS
  • %_WINCEROOT%\PUBLIC\COMMON\SDK
  • %_WINCEROOT%\PUBLIC\DCOM\SDK
  • %_WINCEROOT%\PUBLIC\DIRECTX\OAK
  • %_WINCEROOT%\PUBLIC\DIRECTX\SDK
  • %_WINCEROOT%\PUBLIC\GDIEX\SDK
  • %_WINCEROOT%\PUBLIC\IE\SDK
  • %_WINCEROOT%\PUBLIC\OTHERS
  • %_WINCEROOT%\PUBLIC\PBTOOLS\SDK
  • %_WINCEROOT%\PUBLIC\SERVERS\OAK
  • %_WINCEROOT%\PUBLIC\SERVERS\SDK
  • %_WINCEROOT%\PUBLIC\SPEECH\SDK
  • %_WINCEROOT%\PUBLIC\VOIP\OAK

You will find documentation for individual operating system technologies in the Windows CE Features section of Windows CE Help.
