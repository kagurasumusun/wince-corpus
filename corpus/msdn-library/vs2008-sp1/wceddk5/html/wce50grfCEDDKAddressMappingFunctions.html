CEDDK Dynamic-Link Library Address Mapping Functions

The following table shows the CEDDK.dll address mapping functions.

Programming element Description
MmMapIoSpace This function maps a physical address space to a nonpaged, process-dependent address space. It provides a directly mapped virtual address to the device.
MmUnmapIoSpace This function unmaps an address space previously mapped by MmMapIoSpace.
TransBusAddrToStatic This function is deprecated. Use BusTransBusAddrToStatic instead. This function translates a bus address to a physical system address. Then, it creates a static, process independent, virtual address mapping for that location.
TransBusAddrToVirtual This function is deprecated. Use BusTransBusAddrToVirtual instead. This function translates a bus address to a virtual system address.
