Single Function, Multi-Function, and Combo Cards

SD cards can be divided into three types:

  • Single function cards, which have only one device instance handle in the bus driver and only one client driver is loaded
  • Multi-function cards, which implement more than one I/O function
  • Combo cards, which implement one or more I/O functions and contain SD memory function
