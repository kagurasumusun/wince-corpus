D3DM_DLL_ENTRY

This macro defines the name of the entry point for the Direct3D Mobile driver's dynamically linked library (DLL).

#define D3DM_DLL_ENTRY TEXT("D3DM_Initialize")

Requirements

OS Versions: Windows CE 5.0
Header: D3dmddk.h.
