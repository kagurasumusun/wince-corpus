OID_DOT11_RANDOM_TABLE_FLAG

When this object identifier is true, it indicates that a Random Table is present.

When the value is false, it indicates that a random table is not present and that the hop index method is to be used to determine the hopping sequence.

The default value of this object identifier is true.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Windot11.h.
