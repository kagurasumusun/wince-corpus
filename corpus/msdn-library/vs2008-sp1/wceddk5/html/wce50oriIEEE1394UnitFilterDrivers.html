IEEE 1394 Unit Filter Drivers

IEEE 1394 unit filter drivers are central repositories and intermediaries for IEEE 1394 AV/C units. For example, a camcorder that complies with the AV/C Digital Interface Command Set General Specification exports a unit representing the entire camcorder, a camera subunit, and a VCR subunit.
