SG_BUF

This structure contains information used by read and write IOCTLs.

typedef struct _SG_BUF {
  PUCHAR sb_buf;
  DWORD sb_len;
} SG_BUF, *PSG_BUF;

Members

sb_buf
Pointer to a buffer.
sb_len
Length of the buffer.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Diskio.h.
