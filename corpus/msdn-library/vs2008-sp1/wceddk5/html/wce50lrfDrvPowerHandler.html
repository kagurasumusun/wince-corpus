DrvPowerHandler

This function handles POWER_UP and POWER_DOWN notifications. 

VOID DrvPowerHandler(
  DHPDEV dhpdev,
  BOOL bOff,
);

Parameters

dhpdev
[in] Handle to the display driver to power up or power down.
bOff
[in] If TRUE, power up the device, otherwise power down the device.

Return Values

None.

Remarks

This function is not used in Windows CE .NET 4.2 and later.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Winddi.h.
Link Library: Ddi_ati_lib.lib, Ddi_flat_lib.lib, Ddi_gx_lib.lib, Ddi_mq200_lib.lib, Ddi_nop_lib.lib, Ddi_rflat_lib.lib, Ddi_rgx_lib.lib, or Ddi_tvia5_lib.lib.
