MDDFreeMem

This function frees the specified memory object allocated in MDDAllocMem.

void MDDFreeMem(
  PBYTE pBuffer
);

Parameters

pBuffer
Handle returned in MDDAllocMem.

Return Values

None.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Rndismini.h.
