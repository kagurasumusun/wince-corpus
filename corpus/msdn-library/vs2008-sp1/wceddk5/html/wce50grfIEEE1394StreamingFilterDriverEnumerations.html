IEEE 1394 Streaming Filter Driver Enumerations

The following table shows the IEEE 1394 streaming filter driver enumerations with a description of the purpose of each.

Programming element Description
AUDIO_SampleFrequency This enumeration defines the overall frequency of the samples that constitute the audio stream.
STREAM_MediaType This enumeration describes the type of medium that a specified connection will carry.
