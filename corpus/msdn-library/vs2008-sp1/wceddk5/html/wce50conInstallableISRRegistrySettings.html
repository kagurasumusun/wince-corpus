Installable ISR Registry Settings

An installable ISR is a function that runs in the kernel context and determines if a device is generating an interrupt. A generic installable ISR function called ISRHandler is provided as part of the OS in the GIISR.DLL file. This function supports a number of configurable parameters that allow it to meet the needs of most devices. For example, in order to have the MYNIC driver use the installable ISR, you must add the following settings to the registry.

{HKEY_LOCAL_MACHINE\Drivers\BuiltIn\PCI\Template\MYNIC]
    "IsrDll"="giisr.dll"
    "IsrHandler"="ISRHandler"
    "PortIsIO"=dword:1
    "PortOffset"=dword:2c
    "PortSize"=dword:2
    "PortMask"=dword"F000

The "IsrDll" and "IsrHandler" settings notify the OS that it must use the generic ISR handler function. The remaining four parameters are used to configure the generic ISR for a device allowing the OS to determine if the device has generated an interrupt by reading the interrupt status registry, and optionally the interrupt mask register. The following table lists and describes these parameters.

Parameter Description 
"PortIsIO"=dword:1
 Configures the generic ISR handler to read the interrupt status of the device from IO space. Setting this parameter to dword:0 would cause the handler to read from memory space. 
"PortOffset"=dword:3c
 Specifies the offset to the interrupt status register from the beginning of the IOBase of the device. 
"PortSize"=dword:2
 Specifies that the ISR should be read as a 16 bit value. Setting this value to dword:1 would signal an 8 bit read while setting it to dword:4 would signal a 32 bit read. 
"PortMask"=dwordF000
 Specifies the value and the ISR to determine whether or not the device is generating an interrupt.
