Copying the Windows CE .NET 4.1 or Earlier Keyboard Driver to Windows CE .NET 4.2 or Later

Avoid overwriting the installed Windows CE .NET 4.2 or later keyboard driver by taking necessary precautions. If you overwrite your Windows CE .NET 4.2 or later keyboard driver, you will have to modify your Platform Builder installation to restore the installed Windows CE .NET 4.2 or later keyboard driver.

To copy the Windows CE .NET 4.1 or earlier keyboard driver to Windows CE .NET 4.2 or later

  1. For the latest Platform Builder installation, create a new directory in %_WINCEROOT%\Platform\%_TGTPLAT%\Drivers.
  2. Name the new directory Mykbdmouse.
  3. Copy the Windows CE .NET 4.1 or earlier keyboard driver to the Mykbdmouse directory in Windows CE .NET 4.2 or later.

    For example, copy the contents of %_WINCEROOT%\Platform\%_TGTPLAT%\Drivers\Kbdmouse to the %_WINCEROOT%\Platform\%_TGTPLAT%\Drivers\Mykbdmouse directory in the latest Platform Builder installation.

  4. In the latest Platform Builder installation, open the dirs file in %_WINCEROOT%\Platform\%_TGTPLAT%\Drivers.
  5. Update the keyboard driver section of the dirs file to specify Mykbdmouse instead of Kbdmouse.

    This preserves the installed keyboard driver.
