OID_DOT11_REG_DOMAINS_SUPPORT_VALUE

There are different operational requirements that depend on the regulatory domain.

This object identifier list describes the regulatory domains the PLCP and PMD support in this implementation.

The following table shows the currently defined values and their corresponding regulatory domains.

Value Regulatory domain
Other X'00'
FCC (USA) X'10'
DOC (Canada) X'20'
ETSI (most of Europe) X'30'
Spain X'31'
France X'32'
MKK (Japan) X'40'

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Windot11.h.
