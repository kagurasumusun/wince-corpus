Sample Secure Digital Card Driver

The Secure Digital card driver supports both MultiMedia Card (MMC) and Secure Digital (SD) cards and is designed to function with an SDIO bus driver and standard Secure Digital host controllers.

The Secure Digital card driver exports a stream interface with the DSK prefix and the block device driver interface. For more information about the stream interface, see Stream Interface Driver Development Concepts.
