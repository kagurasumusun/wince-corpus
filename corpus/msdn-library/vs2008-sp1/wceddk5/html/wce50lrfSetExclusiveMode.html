LPDDHAL_SETEXCLUSIVEMODE

This callback function sets a DirectDraw object to exclusive mode.

typedef DWORD (* LPDDHAL_SETEXCLUSIVEMODE)(
  LPDDHAL_SETEXCLUSIVEMODEDATA lpsemd
);

Parameters

lpsemd
[in, out] Pointer to a DDHAL_SETEXCLUSIVEMODEDATA structure that the driver uses to set a DirectDraw object to exclusive mode.

Return Values

Returns one of the following values:

  • DDHAL_DRIVER_HANDLED
  • DDHAL_DRIVER_NOTHANDLED

Requirements

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
Header: Ddrawi.h.
Link Library: Developer implemented.
