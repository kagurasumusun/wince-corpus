Preparing a Display Driver

Once you have a basic Windows CE–based display driver written and tested, see DDHAL Functionality Implementation Without GPE.

To prepare a display driver

  1. Consult the Display Drivers topic in the device driver development guide. You should create a working display driver using the methods described in that guide.
  2. Test the driver and ensure that it works properly. You can also use this opportunity to add acceleration to certain operations in your display driver. For more information, see Windows CE Test Kit.
