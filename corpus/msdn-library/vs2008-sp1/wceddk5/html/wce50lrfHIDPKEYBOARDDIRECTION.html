HIDP_KEYBOARD_DIRECTION

This enumeration defines a key press and a key release.

typedef enum _HIDP_KEYBOARD_DIRECTION {
  HidP_Keyboard_Break,
  HidP_Keyboard_Make
} HIDP_KEYBOARD_DIRECTION;

Elements

HidP_Keyboard_Break
Indicates a key press.
HidP_Keyboard_Make
Indicates a key release.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Hidpi.h.
