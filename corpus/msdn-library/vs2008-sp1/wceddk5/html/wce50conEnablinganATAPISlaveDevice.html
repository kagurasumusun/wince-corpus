ATAPI Slave Devices

The Platform.reg file references the files that contain the registry settings for the ALI1543, Intel I82371, Promise PDC20262, and generic ATAPI/IDE controllers. The files containing these registry settings are in %_WINCEROOT%\Public\Common\OAK\Drivers\Block\ATAPI.

The following table shows which registry keys represent which hard disk drive location. Enabling a slave hard disk drive may increase the boot time of your system.

Subkey of

[$(PCI_BUS_ROOT)\Template\MyHardDiskDrive

 Description
Device0 Primary master.
Device1 Primary slave.
Device2 Secondary master.
Device3 Secondary slave.
