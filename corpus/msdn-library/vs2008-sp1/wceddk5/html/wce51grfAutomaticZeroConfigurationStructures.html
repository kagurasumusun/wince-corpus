Automatic Configuration Structures

The following table shows the Automatic Configuration structures with a description of the purpose of each.

Programming element Description
INTF_ENTRY This structure contains detailed information about an interface that is required by an RPC client.
INTF_KEY_ENTRY This structure stores the key information about an interface.
INTFS_KEY_TABLE This structure describes the table of key information for all interfaces.
WZC_802_11_CONFIG_LIST This structure stores a list of preferred wireless zero configurations.
WZC_CONTEXT This structure stores all the global service options that can be customized
WZC_EAPOL_PARAMS This structure stores information about 802.1x authentication.
WZC_WLAN_CONFIG This structure stores the information about the preferred wireless zero configuration.
