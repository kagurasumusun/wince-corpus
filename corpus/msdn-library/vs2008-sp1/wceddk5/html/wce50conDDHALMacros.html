DDHAL Macros

The following table shows the macros provided by DirectDraw.

Macro Description
GET_LPDDRAWSURFACE_GBL_MORE Traverses from a DDRAWI_DDRAWSURFACE_GBL structure to a DDRAWI_DDRAWSURFACE_GBL_MORE structure.
SURFACE_PHYSICALVIDMEM Retrieves a linear physical memory address for the surface when given a global surface object.
