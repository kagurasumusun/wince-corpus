OID_TAPI_SET_DEFAULT_MEDIA_DETECTION

The OID_TAPI_SET_DEFAULT_MEDIA_DETECTION object requests the miniport driver to use a new set of media modes to detect for the indicated line, thereby replacing whatever set it was using.

The miniport driver must not notify NDISWAN of an incoming call unless this request has been successfully completed for the incoming call's media mode.

Support for this request is mandatory.

This request uses an NDIS_TAPI_SET_DEFAULT_MEDIA_DETECTION structure.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ntddndis.h and Ndistapi.h.
