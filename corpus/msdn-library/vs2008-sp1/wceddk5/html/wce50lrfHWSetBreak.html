HWSetBreak

This function sets the line break condition on the transmit line.

VOID HWSetBreak(
  PVOID pContext 
);

Parameters

pContext
[in] Pointer to a context structure returned by the HWInit function that contains implementation-specific data describing the device.

Return Values

None.

Remarks

This function supports the implementation of the lower layers of serial port drivers. The output line should output zeroes until the HWClearBreak function is called. This is typically done by by locking the line at a positive voltage.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Serhw.h.
