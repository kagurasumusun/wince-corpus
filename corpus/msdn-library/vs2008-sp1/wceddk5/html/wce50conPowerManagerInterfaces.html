Power Manager Interfaces

The Power Manager has three different types of clients. These include:

  • Drivers for Power Manager aware devices.
  • Applications that may want to change the system power state or impose device performance requirements.
  • Applications that want to be notified of power events.

The Power Manager uses a different programming interface to communicate with each of these types of clients.
