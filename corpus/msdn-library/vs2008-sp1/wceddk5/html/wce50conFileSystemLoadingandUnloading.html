File System Loading and Unloading

The Storage Manager directly loads file systems, instead of block drivers. For more information about the Storage Manager, see Storage Manager.

When the Storage Manager receives a detach notification from the Device Manager, it unloads the store. A store is a block device that is exposed through a stream interface. The store then in turn unloads each file system driver and partition driver associated with the detached device. For more information about notifications, see Device Interface Notifications.
