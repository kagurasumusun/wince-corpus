IOCTL_NDISUIO_NIC_STATISTICS

This IOCTL uses the NIC_STATISTICS structure to determine the characteristics of the device NIC.

Parameters

lpOutBuffer
[out] Points to the NIC_STATISTICS structure.
nOutBufferSize
[in] Size of the NIC_STATISTICS structure pointed to by lpOutBuffer.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Nuiouser.h, Ntddndis.h.
