Token Ring Object Identifiers

The following table shows the Token Ring object identifiers with a description of the purpose of each.

Programming element Description
OID_802_5_CURRENT_ADDRESS This object specifies the address the NIC is currently using.
OID_802_5_CURRENT_FUNCTIONAL This object specifies the functional address enabled on the NIC for packet reception.
OID_802_5_CURRENT_GROUP This object specifies the group address enabled on the NIC for packet reception.
OID_802_5_CURRENT_RING_STATE This object specifies the current ring state.
OID_802_5_CURRENT_RING_STATUS This object specifies the last ring status indicated with an NDIS_RING_XXX status code.
OID_802_5_LAST_OPEN_STATUS This object specifies the last open error status returned for a protocol's call to NdisOpenAdapter.
OID_802_5_PERMANENT_ADDRESS This object specifies the address of the NIC encoded in the hardware.
