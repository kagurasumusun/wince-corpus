HID_DRIVER_SETTINGS

This structure describes a HID device and how to load a HID client driver.

typedef struct _HID_DRIVER_SETTINGS {
  DWORD dwVendorId;
  DWORD dwProductId;
  DWORD dwReleaseNumber;
  DWORD dwInterfaceNumber;
  DWORD dwCollection;
  DWORD dwUsagePage;
  DWORD dwUsage;
} HID_DRIVER_SETTINGS, *PHID_DRIVER_SETTINGS;

Members

dwVendorId
Vendor identifier.
dwProductId
Product identifier.
dwReleaseNumber
Release identifier.
dwInterfaceNumber
Interface-specific.
dwCollection
Interface-specific.
dwUsagePage
Report-specific per top-level collection.
dwUsage
Report-specific per top-level collection.

Remarks

The default value for each HID_DRIVER_SETTINGS member is HID_NO_INFO. Each byte must be the same.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Hiddi.h.
