Notification LED Driver Functions

The following table shows the notification LED driver functions.

Programming element Description
NLedDriverGetDeviceInfo This function returns information about the notification LED device.
NLedDriverInitialize This function initializes the notification LED.
NLedDriverPowerDown This function sends a power status change notification to the LED devices.
NLedDriverSetDevice This function changes the setting of the notification LED.
NLedGetDeviceInfo This function is a pass through function to the GWES NLedDriverGetDeviceInfo function.
NLedSetDevice This function is a pass through function to the GWES NLedDriverSetDevice function.
