DirectDraw Display Driver Structures

The following table shows the display driver structures.

Structure Description
DDHAL_GETDRIVERINFODATA Returns the driver-specific information.
DDHALINFO Collects all the information needed to create an instance of your driver.
DDHALMODEINFO Contains a description of a display mode.
