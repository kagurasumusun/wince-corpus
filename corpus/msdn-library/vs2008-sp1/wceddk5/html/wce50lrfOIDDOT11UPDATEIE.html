OID_DOT11_UPDATE_IE

This object identifier requests that the underlying card add or update one or more IEs for an already started BSS. The card must remember the passed-in parameters and use it for forming and sending out beacon and probe response frames. The NIC must not reset its state for updating the IE(s).

The operating system (OS) presents the new IEs to be added or updated as a contiguous byte array using the same format as that of the information elements specified in the standard. The NIC must parse this byte array in the same way as specified in the standard for parsing information elements to retrieve and save it internally all the parameters that it needs to include in the beacon and probe response frames.

While parsing the byte array, if the NIC comes across an information element that it does not understand, then it must save that element. If there is already a saved copy then the NIC must overwrite the saved copy with the new copy supplied by OS. In sending out beacon and probe response frames, the card then must concatenate all information elements that it could not understand.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Windot11.h.
