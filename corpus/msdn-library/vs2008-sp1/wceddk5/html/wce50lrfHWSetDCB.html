HWSetDCB

This function sets the device control block.

BOOL HWSetDCB(
  PVOID pContext,
  LPDCB pDCB 
);

Parameters

pContext
[in] Pointer to a context structure returned by the HWInit function that contains implementation-specific data describing the device.
pDCB
[in] Pointer to the device control block to set.

Return Values

TRUE indicates success. FALSE indicates failure. If an error occurs, the caller can return the error using GetLastError.

Remarks

This function is called by the upper layer after the user has called the SetCommState function.

This function supports the implementation of the lower layers of serial port drivers.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Serhw.h.
