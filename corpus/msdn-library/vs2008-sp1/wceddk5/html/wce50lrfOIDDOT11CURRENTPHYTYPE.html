OID_DOT11_CURRENT_PHY_TYPE

This object identifier is an 8-bit integer value that identifies the PHY type supported by the attached Physical Layer Convergence Protocol (PLCP) and Physical Medium Dependent (PMD) sublayer. The following table shows defined values and their corresponding PHY types.

Value PHY type
FHSS 2.4 GHz 01
DSSS 2.4 GHz 02
IR Baseband 03
OFDM 5 GHz 04
HRDSSS 05

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Windot11.h.
