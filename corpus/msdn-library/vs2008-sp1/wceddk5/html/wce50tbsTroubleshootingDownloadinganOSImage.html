Troubleshooting: Downloading a Run-Time Image

The following table shows descriptions and resolutions of problems you may encounter while your run-time image downloads.

Description Resolution
Your run-time image download does not start or complete. This solution is only valid if you are using an Ethernet connection. Check the connection to the target device. Keep in mind that the run-time image download is through Trivial File Transfer Protocol (TFTP), so heavy network traffic may affect your run-time image download.

Ensure that the Windows CE Target Control Service is set up correctly. For example, if you want to debug through an Ethernet connection, ensure that Target Control is configured for Ethernet debugging. For more information on Target Control, see Tools for Debugging and Testing.
The only output on your target device is Jumping to <hexadecimal number>. There may be a problem with the hardware configuration. For more information, check the messages from a serial port on your target device.

For more information on receiving messages from a serial port, see Troubleshooting: Debugging a Driver.
