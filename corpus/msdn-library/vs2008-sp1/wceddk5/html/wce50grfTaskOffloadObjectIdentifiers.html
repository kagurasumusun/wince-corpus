Task Offload Object Identifiers

The following API topic contains the Task Offload object identifier needed by the Network driver.

  • OID_TCP_TASK_OFFLOAD The TCP/IP transport queries OID_TCP_TASK_OFFLOAD to determine the task-offload capabilities of a miniport driver's NIC.
