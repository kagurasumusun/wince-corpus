KBDI_VKEY_TO_UNICODE_INFO

This structure contains Unicode state and Unicode character information.

struct KBDI_VKEY_TO_UNICODE_INFO {
  UINT32 cbToUnicodeState;
  UINT32 cMaxToUnicodeCharacters;
};

Members

cbToUnicodeState
Count of bytes required for Unicode state information.
cMaxToUnicodeCharacters
Maximum number of characters generated for a single virtual key.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Keybd.h.
