Testing USB Host Client Drivers for Compliance with the USB Specification

The Microsoft Logo Test Kit (LTK) provides a set of tests for specific Windows Mobile-based devices. The LTK verifies the USB functionality. All devices must meet their respective USB peripheral specification requirements. Specifically, Microsoft requires the USB Gold Tree standard integration test and electrical level tests.

The following list shows the procedure that Microsoft uses to test USB compliance:

  1. Check OEM submission documents for USB information.
  2. Verify that the device has the required number of configurable USB endpoints.
  3. Verify that these endpoints are configurable for future releases of Windows Mobile-based devices.
  4. Verify that the documentation provided by the OEM proves that the device was tested by a USB Implementors Forum (USB-IF) certified independent test lab.
