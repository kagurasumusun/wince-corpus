OID_DOT11_COUNTRY_STRING

This object identifier identifies the country in which the NIC is operating.

The first two octets of this string are the two-character country codes as described in document ISO/IEC 3166-1.

The following list shows the possible values of the third octet:

  • An ASCII space character, if the station operates under regulations that encompass all environments in the country or region.
  • An ASCII 'O' character, if the station operates under regulations for an outdoor environment only.
  • An ASCII 'I' character, if the station operates under regulations for an indoor environment only.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Windot11.h.
