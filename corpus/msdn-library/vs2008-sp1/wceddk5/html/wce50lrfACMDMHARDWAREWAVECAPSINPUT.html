ACMDM_HARDWARE_WAVE_CAPS_INPUT

This message requests an ACM driver to return hardware capabilities for a waveform input device.

Parameters

dwDeviceID
Value that specifies a driver instance identifier. The driver returns this value in response to the ACM_Open (ACM Driver) function.
hDriver
Handle to a driver.
uMsg
Value that specifies this message.
lParam1
Pointer to a WAVEINCAPS structure declared in the Mmsystem.h header file.
lParam2
Value that specifies the size of the WAVEINCAPS structure pointed to by lParam1.

Return Values

A return value of MMSYSERR_NOERROR indicates success. Otherwise, the driver returns one of the MMSYSERR error values declared in the Mmsystem.h header file or one of the ACMERR error values declared in the Msacm.h header file. If the driver does not support waveform hardware, it returns MMSYSERR_NOTSUPPORTED.

Remarks

Each time a client calls the acmMetrics function with the ACM_METRIC_HARDWARE_WAVE_INPUT index parameter, the ACM (Waveapi.dll) sends this message by calling the ACM driver's ACM_IOControl entry point through the DeviceIoControl function.

The driver then receives a pointer to a WAVEINCAPS structure. The driver is required to populate this structure.

Only ACM drivers that provide access to waveform input hardware need to support this message. If your driver supports this message, it must return ACMDRIVERDETAILS_SUPPORTF_HARDWARE in the ACMDRIVERDETAILS structure provided with the ACMDM_DRIVER_DETAILS message.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Msacmdrv.h.
