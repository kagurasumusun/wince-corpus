Remote NDIS Structures

The following table shows the Remote NDIS structures with a description of the purpose of each.

Programming element Description
DATA_WRAPPER This structure specifies the characteristics of a RNDIS data wrapper.
RNDIS_DIAGNOSTIC_INFO This structure defines the diagnostic status buffer.
RNDIS_OOBD This structure specifies OOB data from a RNDIS_PACKET.
RNDIS_PACKET This structure contains the packet descriptors for a RNDIS data packet.
RNDIS_PDD_CHARACTERISTICS This structure is used to specify the PDD functions used to handle RNDIS messages and data packets.
RNDIS_PER_PACKET_INFO This structure specifies contents associated with a data message.
