Registry Helper Structures

The following table shows the registry helper structures.

Programming element Description
DDKISRINFO This structure contains interrupt service routine (ISR) information.
DDKPCIINFO This structure tracks standard PCI device instance information.
DDKWINDOWINFO This structure contains address window information.
DEVICEWINDOW This structure describes a base and length pair.
