Display Memory Structures

The following table shows the display memory structures.

Structure Description
DDNONLOCALVIDMEMCAPS Contains the capabilities for nonlocal display memory.
VIDMEM Manages the display memory into heaps.
VIDMEMINFO Contains the display memory information.
