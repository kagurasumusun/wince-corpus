HWGetIntrType

This function returns the current interrupt type.

INTERRUPT_TYPE HWGetIntrType(
  PVOID pContext 
);

Parameters

pContext
[in] Pointer to a context structure returned by the HWInit function that contains implementation-specific data describing the device.

Return Values

This function returns one of the following interrupt types:

  • INTR_NONE
  • INTR_LINE
  • INTR_RX
  • INTR_TX
  • INTR_MODEM

Interrupt types are declared in Serhw.h.

Remarks

HWGetIntrType is called by the upper layer to determine what type of interrupt occurred.

This function supports the implementation of the lower layers of serial port drivers.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Serhw.h.
