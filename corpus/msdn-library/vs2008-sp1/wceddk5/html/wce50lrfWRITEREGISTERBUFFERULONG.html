WRITE_REGISTER_BUFFER_ULONG

This function writes a number of ULONG values from a buffer to the specified register.

VOID WRITE_REGISTER_BUFFER_ULONG(
  PULONG Register, 
  PULONG Buffer, 
  ULONG Count 
);

Parameters

Register
[in] Pointer to the register that must be a mapped range in memory space.
Buffer
[out] Pointer to a buffer to write ULONG values from.
Count
[in] Number of ULONG values to write to the register.

Return Values

None.

Remarks

The size of the buffer must be large enough to contain at least the specified number of ULONG values.

The Port parameter refers to device hardware mapped into the CPU's address space using other CEDDK.dll functions.

Requirements

OS Versions: Windows CE 2.10 and later.
Header: CEDDK.h.
Link Library: CEDDK.lib.
