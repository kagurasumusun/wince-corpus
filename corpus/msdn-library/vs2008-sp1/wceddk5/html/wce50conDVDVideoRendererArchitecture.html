DVD-Video Renderer Architecture

The Windows CE DVD-Video API design is optimized for direct support of hardware DVD decoders and renderers, while providing a framework for partial or total software decoding and rendering of DVD content.

A DVD driver is a plug-in COM component that supports a set of control interfaces that DVD playback middleware requires. Moreover, you, the DVD driver developer, can choose to implement any number of additional interfaces representing proprietary technologies of the DVD-Video renderer, such as zoom and digest. If this is the case, DVD playback middleware automatically makes them available to an application developer. The application developer can take advantage of both these proprietary technologies and standard DVD playback offered by DVD-Video API.
