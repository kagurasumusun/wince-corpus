DDHAL_DESTROYPALETTEDATA

This structure contains information necessary to destroy a specified palette. This structure passes the information to the DirectDraw hardware abstraction layer (DDHAL) DestroyPalette callback function. 

typedef struct _DDHAL_DESTROYPALETTEDATA {
  LPDDRAWI_DIRECTDRAW_GBL lpDD;
  LPDDRAWI_DDRAWPALETTE_GBL lpDDPalette;
  HRESULT ddRVal;
  LPDDHALSURFCB_DESTROYPALETTE DestroyPalette;
} DDHAL_DESTROYPALETTEDATA;

Members

lpDD
Pointer to the DDRAWI_DIRECTDRAW_GBL structure that represents the DirectDraw object.
lpDDPalette
Pointer to the DDRAWI_DDRAWPALETTE_GBL structure that represents the DirectDrawPalette object.
ddRVal
Passes the DirectDraw return values.
DestroyPalette
Used by DirectDraw and should not be filled in by the driver.

Requirements

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
Header: Ddrawi.h.
