REG_VALUE_DESCR

This structure contains information about a registry key. It is a registry value descriptor.

typedef struct _REG_VALUE_DESCR {
  LPWSTR Name;
  DWORD Type;
  DWORD Size;
  PBYTE Data;
} REG_VALUE_DESCR, *PREG_VALUE_DESCR;

Members

Name
Registry value name.
Type
Registry value type.
Size
Registry value data size.
Data
Registry value data.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Usbclient.h.
