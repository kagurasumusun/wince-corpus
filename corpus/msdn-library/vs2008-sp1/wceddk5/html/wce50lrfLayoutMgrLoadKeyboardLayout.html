PFN_LAYOUT_MGR_LOAD_KEYBOARD_LAYOUT

This function places the specified layout in the available layout list.

typedef HKL (*PFN_LAYOUT_MGR_LOAD_KEYBOARD_LAYOUT)(
  LPCWSTR pwszKLID,
  UINT Flags
);

Parameters

pwszKLID
[in] Input locale identifier.
Flags
[in] Ignored.

Return Values

If successful, this function returns the handle to the input locale identifier. Otherwise, it returns zero.

Remarks

This function fails for any input locales that are not keyboard layouts, such as Input Method Editors (IMEs).

This function must be re-entrant because the input system exposes it through the LoadKeyboardLayout function and multiple threads can call it.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Keybddr.h.
Link Library: LayoutManager.lib.
