CardMapWindowPhysical

This function maps a PC Card window to the physical address of its parent bus.

STATUS CardMapWindowPhysical(
  CARD_WINDOW_HANDLE hCardWindow,
  PCARD_WINDOW_ADDRESS pCardWindowAddr
);

Parameters

hCardWindow
[in] Window handle that is allocated from CardRequestWindow.
pCardWindowAddr
[in, out] CARD_WINDOW_ADDRESS structure.

Return Values

Returns one of the return codes defined in the Cardsv2.h header file.

Requirements

OS Versions: Windows CE 5.0 and later
Header: Cardsv2.h
Link Library: Pcc_serv.dll
