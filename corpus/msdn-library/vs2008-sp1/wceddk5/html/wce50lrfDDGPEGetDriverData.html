DDGPE::GetDriverData

This method obtains a pointer to the driver data that is associated with the current object.

virtual DDGPEDriverData* GetDriverData(void);

Parameters

None.

Return Values

This method returns a pointer to the driver data that has been attached to the current object.

Requirements

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
Header: Ddgpe.h.
Link Library: Ddgpe.lib.
