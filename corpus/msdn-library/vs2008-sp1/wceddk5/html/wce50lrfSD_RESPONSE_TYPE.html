SD_RESPONSE_TYPE

This enumerated type specifies the type of response expected from a bus request.

typedef enum _SD_RESPONSE_TYPE {
  NoResponse,
  ResponseR1,
  ResponseR1b,
  ResponseR2,
  ResponseR3,
  ResponseR4,
  ResponseR5,
  ResponseR6
} SD_RESPONSE_TYPE, *PSD_RESPONSE_TYPE;

Elements

NoResponse
No response is expected.
ResponseR1
An R1 response is expected.
ResponseR1b
An R1 with busy response is expected.
ResponseR2
An R2 response is expected.
ResponseR3
An R3 response is expected.
ResponseR4
An R4 response is expected.
ResponseR5
An R5 response is expected.
ResponseR6
An R6 response is expected.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Sdcardddk.h.
