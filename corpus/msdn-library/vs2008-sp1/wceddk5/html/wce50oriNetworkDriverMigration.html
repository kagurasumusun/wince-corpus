Network Driver Migration

This topic contains information about migrating network drivers from earlier versions of Windows CE. For general migration information, see Migrating from an Earlier Version of Windows CE.

  • Effective with Windows CE 5.0, the SYSGEN_ETH_CISCO variable has been renamed to BSP_NIC_PCX500_PCMCIA.
  • Effective with Windows CE 5.0, the SYSGEN_ETH_XIRCOM variable has been removed. This driver is no longer supported.
