Secure Digital Card Multimedia Card Compatibility

The Secure Digital (SD) electrical interface and protocol format are compatible with the multimedia card (MMC) specification, including physical form factor. The first 7 pins of an SD slot are physically arranged in the same manner as an MMC slot. This allows an SD-capable device to host MMC cards in the same slot using the same hardware. A common slot connector can be used that can supports both card types.

At a protocol level, certain SD commands are not supported on MMC devices. An SD memory-aware host can determine whether the device it controls is an MMC or SD Card.

MMC functionality is implicitly supported by the Windows CE Secure Digital I/O (SDIO) host controller.
