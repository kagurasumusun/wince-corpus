Print Spooling

No separate printer spooler component exists in Windows CE, unlike the desktop versions of the Windows OS. With Windows CE, spooling or background printing is implemented in the printer driver itself. However, because print spooling typically consumes a lot of memory, limited memory might be a problem. A practical print spooler usually has to implement a complicated compression scheme to store spooled documents before printing. Several third-party companies implement print spoolers for Windows CE.
