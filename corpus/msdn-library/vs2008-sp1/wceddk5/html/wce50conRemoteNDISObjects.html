Remote NDIS Objects

The host uses REMOTE_NDIS_QUERY_MSG and REMOTE_NDIS_SET_MSG to control the operation of the Remote NDIS device. An NDIS object identifier (OID) of the form OID_XXX is used with each such message to identify a device operational parameter or statistics counter.

Remote NDIS uses two kinds of object identifiers, general and 802.3-specific. For more information about these objects, see General NDIS Objects and NDIS Ethernet Objects.
