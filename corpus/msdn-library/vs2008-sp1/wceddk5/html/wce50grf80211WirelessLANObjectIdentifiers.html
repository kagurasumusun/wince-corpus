802.11 Wireless LAN Object Identifiers

The following table shows the 802.11 Wireless LAN object identifiers with a description of the purpose of each.

Programming element Description
OID_802_11_ADD_WEP This object identifier, when set, requests that the miniport driver set an 802.11 wired equivalent privacy (WEP) key to a specified value.
OID_802_11_AUTHENTICATION_MODE This object identifier, when set, requests that the miniport driver set its NIC's 802.11 authentication mode to a specified value.
OID_802_11_BSSID This object identifier (OID), when set, requests that a miniport driver assign a specified value to the media access control (MAC) address of the access point associated with the NIC.
OID_802_11_BSSID_LIST This object identifier returns a list of all BSSIDs detected, including their attributes specified in the NDIS_REQUEST data structure.
OID_802_11_BSSID_LIST_SCAN This object identifier requests that the miniport driver direct the 802.11 NIC to request a survey of BSSs.
OID_802_11_CONFIGURATION This object identifier, when set, requests that the miniport driver set the NIC's radio configuration parameters to specified values.
OID_802_11_DESIRED_RATES This object identifier, when set, requests that the miniport driver set its NIC's set of data transmission rates to the values specified in an array.
OID_802_11_DISASSOCIATE This object identifier requests that the miniport driver command its NIC to disassociate from the current service set and turn off the radio.
OID_802_11_FRAGMENTATION_THRESHOLD This object identifier, when set, requests that the miniport driver set the NIC's packet fragmentation threshold to a specified value.
OID_802_11_INFRASTRUCTURE_MODE This object identifier, when set, requests that the miniport driver set the 802.11 NIC's infrastructure mode to a specified value.
OID_802_11_NETWORK_TYPE_IN_USE This object identifier, when set, requests that the miniport driver set type information about the physical layer network used by the 802.11 NIC to a specified value.
OID_802_11_NETWORK_TYPES_SUPPORTED This object identifier requests that the miniport driver return an array of all physical layer network subtypes that the 802.11 NIC and the driver support.
OID_802_11_NUMBER_OF_ANTENNAS This object identifier requests that the miniport driver return the number of antennas on the NIC's radio.
OID_802_11_POWER_MODE This object identifier, when set, requests that the miniport driver set the power mode of the 802.11 NIC to the specified value.
OID_802_11_PRIVACY_FILTER This object identifier, when set, requests that the miniport driver set its NIC's 802.1X privacy filter mode to a specified value.
OID_802_11_RELOAD_DEFAULTS This object identifier requests that the miniport driver reload the available defaults of a specified type.
OID_802_11_REMOVE_WEP This object identifier requests that the miniport driver remove the wired equivalent privacy (WEP) key at the specified key index.
OID_802_11_RSSI This object identifier requests that the miniport driver return the received signal strength indication (RSSI) in response to a query or as a status indication event.
OID_802_11_RSSI_TRIGGER This object identifier when set, requests that the miniport driver set the RSSI trigger value. This value determines when an RSSI status indication event will occur.
OID_802_11_RTS_THRESHOLD This object identifier, when set, requests that the miniport driver set the Request To Send (RTS) threshold to a specified value.
OID_802_11_RX_ANTENNA_SELECTED This object identifier, when set, requests that the miniport driver set, to a specified value, the antenna number that identifies the currently selected receive (RX) antenna.
OID_802_11_SSID This object identifier, when set, requests that the miniport driver assign a specified value to the NIC's service set identifier (SSID).
OID_802_11_STATISTICS This object identifier requests that the miniport driver return the current statistics for the 802.11 interface.
OID_802_11_SUPPORTED_RATES This object identifier requests that the miniport driver return its NIC's data rate set, which includes the data rates that the NIC's radio supports.
OID_802_11_TX_ANTENNA_SELECTED This object identifier, when set, requests that the miniport driver set, to a specified value, the antenna number that identifies the currently selected transmit (TX) antenna.
OID_802_11_TX_POWER_LEVEL This object identifier, when set, requests that the miniport driver set the transmit power level of the 802.11 NIC to a specified value.
OID_802_11_WEP_STATUS This object identifier requests that the miniport driver set its NIC's 802.11 WEP status to enabled or disabled.
OID_DOT11_AP_JOIN_REQUEST This object identifier requests that the card synchronize with a BSS.
OID_DOT11_ATIM_WINDOW This object identifier specifies the announcement traffic information message (ATIM) window size in TUs.
OID_DOT11_BEACON_PERIOD This object identifier specifies the number of TU that a station uses for scheduling Beacon transmissions.
OID_DOT11_CCA_MODE_SUPPORTED This is a bit-significant value, that represents all of the CCA modes supported by the PHY.
OID_DOT11_CCA_WATCHDOG_COUNT_MAX This object identifier, together with OID_CCA_Watchdog_Timer_Max, determines when energy detected in the channel can be ignored.
OID_DOT11_CCA_WATCHDOG_COUNT_MIN The minimum value to which OID_CCA_Watchdog_Count can be set.
OID_DOT11_CCA_WATCHDOG_TIMER_MAX This object identifier, together with OID_CCA_Watchdog_Count_Max, determines when energy detected in the channel can be ignored.
OID_DOT11_CCA_WATCHDOG_TIMER_MIN The minimum value to which OID_CCA_Watchdog_Timer_Max can be set.
OID_DOT11_CF_POLLABLE This object identifier, when true, indicates that the station (STA) can respond to a CF-Poll with a data frame within a Short Inter-Frame Spacing (SIFS) time.
OID_DOT11_CFP_MAX_DURATION The object identifier describes the maximum duration of the CFP in TU that may be generated by the PCF.
OID_DOT11_CFP_PERIOD The object identifier describes the number of Delivery Traffic Indicator Message (DTIM) intervals between the start of CFPs.
OID_DOT11_CHANNEL_AGILITY_ENABLED This object identifier indicates that the PHY channel agility functionality is enabled.
OID_DOT11_CHANNEL_AGILITY_PRESENT This object identifier indicates that the PHY is capable of channel agility.
OID_DOT11_COUNTERS_ENTRY This object identifier queries statistics from the NIC.
OID_DOT11_COUNTRY_STRING This object identifier identifies the country in which the NIC is operating.
OID_DOT11_CURRENT_CCA_MODE The current CCA method in operation.
OID_DOT11_CURRENT_CHANNEL The current operating frequency channel of the DSSS PHY.
OID_DOT11_CURRENT_CHANNEL_NUMBER The current channel number of the frequency output by the RF synthesizer.
OID_DOT11_CURRENT_DWELL_TIME The current time, in TU, that the transmitter operates on a single channel, as set by the MAC. Default is 19 TU.
OID_DOT11_CURRENT_FREQUENCY The number of the currently operating frequency channel of the Orthogonal Frequency Division Multiplexing (OFDM) physical layer.
OID_DOT11_CURRENT_INDEX The current index value that the PHY LME is using to determine the CurrentChannelNumber.
OID_DOT11_CURRENT_OFFLOAD_CAPABILITY This object identifier turns on or turns off a NIC's offload capabilities.
OID_DOT11_CURRENT_OPERATION_MODE This object identifier sets the NIC into station or access point (AP) mode.
OID_DOT11_CURRENT_OPTIONAL_CAPABILITY This object identifier turns on or turns off the operational capabilities enabled on the NIC.
OID_DOT11_CURRENT_PACKET_FILTER This object identifier specifies the packet types that a NIC can indicate up to the Native 802.11 layer.
OID_DOT11_CURRENT_PATTERN The current pattern that the PHY LME is using to determine the hop sequence.
OID_DOT11_CURRENT_PHY_TYPE This object identifier is an 8-bit integer value that identifies the PHY type supported by the attached Physical Layer Convergence Protocol (PLCP) and Physical Medium Dependent (PMD) sublayer.
OID_DOT11_CURRENT_REG_DOMAIN The current regulatory domain that this instance of the PMD supports.
OID_DOT11_CURRENT_RX_ANTENNA This object identifier queries the current antenna being used to receive, if OID_DOT11_DIVERSITY_SUPPORT indicates that diversity is not supported.
OID_DOT11_CURRENT_SET The current set of patterns that the PHY LME is using to determine the hopping sequence
OID_DOT11_CURRENT_TX_ANTENNA This object identifier queries the current antenna being used to transmit.
OID_DOT11_CURRENT_TX_POWER_LEVEL The TxPowerLevel N currently being used to transmit data.
OID_DOT11_DEFAULT_WEP_OFFLOAD This object identifier passes the default key that is used to decrypt or encrypt packets.
OID_DOT11_DEFAULT_WEP_UPLOAD This object identifier removes the default key that is used to decrypt or encrypt packets.
OID_DOT11_DIVERSITY_SELECTION_RX When true, this object identifier indicates that the antenna represented by uAntennaListIndex can be used for receive diversity.
OID_DOT11_DIVERSITY_SUPPORT This object identifier supports diversity.
OID_DOT11_DTIM_PERIOD This object identifier specifies the number of beacon intervals that elapse between transmissions of Beacons frames containing a TIM element whose DTIM count field is zero.
OID_DOT11_DSSS_OFDM_OPTION_ENABLED This object identifier, when queried, returns the DSSS-OFDM option enabled truth value.

When set, this object identifier sets the DSSS-OFDM option enabled truth value.
OID_DOT11_DSSS_OFDM_OPTION_IMPLEMENTED This object identifier, when queried, returns the DSSS-OFDM option implemented truth value. This value, when true, indicates that the DSSS-OFDM option is implemented. The default value is set to FALSE.
OID_DOT11_ED_THRESHOLD The current Energy Detect Threshold that is being used by the Direct Sequence Spread Spectrum (DSSS) physical layer.
OID_DOT11_EHCC_CAPABILITY_ENABLED When this object identifier is true, it indicates that the STA is capable of operate using the HCC or EHCC algorithms to determine the hopping patterns.
OID_DOT11_EHCC_CAPABILITY_IMPLEMENTED When this object identifier is true, it indicates that the STA is capable of generating the HCC or EHCC algorithms to determine the hopping patterns.
OID_DOT11_EHCC_NUMBER_OF_CHANNELS_FAMILY_INDEX This object identifier indicates the value to be used as the maximum for the family index (a) in the HCC and EHCC algorithms.
OID_DOT11_EHCC_PRIME_RADIX This object identifier indicates the value to be used as the prime radix (N) in the HCC and EHCC algorithms.
OID_DOT11_ERP_PBCC_OPTION_ENABLED This object identifier, when queried, returns the ERP-PBCC option enabled truth value.

When set, this object identifier sets the ERP-PBCC option enabled truth value.
OID_DOT11_ERP_PBCC_OPTION_IMPLEMENTED This object identifier, when queried, returns the ERP-PBCC option implemented truth value. This value, when true, indicates that the ERP-PBCC modulation option is implemented. The default value is set to FALSE.
OID_DOT11_FRAGMENTATION_THRESHOLD This object identifier specifies the current maximum size, in octets, of the MAC Protocol Data Unit (MPDU) that may be delivered to the PHY.
OID_DOT11_FREQUENCY_BANDS_SUPPORTED The capability of the Orthogonal Frequency Division Multiplexing (OFDM) physical layer implementation to operate in the three U-NII bands.
OID_DOT11_HOP_ALGORITHM_ADOPTED This object identifier indicates which of the algorithms will be used to generate the Hopping Patterns.
OID_DOT11_HOP_MODULUS The number of channels for the hopping set.
OID_DOT11_HOP_OFFSET This object identifier queries the next position in the hopping set.
OID_DOT11_HOP_TIME The time, in microseconds, for the PMD to change from channel 2 to channel 80.
OID_DOT11_HOPPING_PATTERN This object identifier queries the hopping pattern table used by FHS file.
OID_DOT11_HR_CCA_MODE_SUPPORTED This object identifier is a bit-significant value, that represents all of the CCA modes supported by the PHY.
OID_DOT11_JOIN_REQUEST This object identifier requests that the card synchronize with a Basic Service Set (BSS).
OID_DOT11_LONG_RETRY_LIMIT This object identifier indicates the maximum number of transmission attempts of a frame, the length of which are greater than OID_DOT11_RTS_THRESHOLD that are made before a failure condition is indicated.
OID_DOT11_MAC_ADDRESS This object identifier queries the unique MAC address assigned to the STA.
OID_DOT11_MAX_DWELL_TIME The maximum time, in TU, that the transmitter is permitted to operate on a single channel.
OID_DOT11_MAX_MAC_ADDRESS_STATES This object identifier, when queried, returns the maximum number of MAC address states that a NIC can maintain at a time. A value of 0 implies that the number of MAC addresses a NIC can support is limited by system resources. Otherwise, the NIC driver must report a number which is at least 32. The NIC may choose to create a state for a MAC address based on the first MSDU transmitted to that MAC address. It may also choose to delete a MAC address when the state has remained idle for 1 minute based on a least recently used scheme.
OID_DOT11_MAX_RECEIVE_LIFETIME This object identifier is the elapsed time, in TU, after the initial reception of a fragmented MMPDU or MSDU, after which further attempts to reassemble the MMPDU or MSDU is terminated.
OID_DOT11_MAX_TRANSMIT_MSDU_LIFETIME The Max_Transmit_MSDU_Lifetime is the elapsed time, in TU, after the initial transmission of an MSDU, after which further attempts to transmit the MSDU is terminated.
OID_DOT11_MEDIUM_OCCUPANCY_LIMIT This object identifier indicates the maximum amount of time, in TU, that a point coordinator may control a wireless medium without allowing at least one instance of DCF access to the medium.
OID_DOT11_MPDU_MAX_LENGTH This object identifier queries the maximum size of the MAC Protocol Data Unit (MPDU).
OID_DOT11_MULTI_DOMAIN_CAPABILITY This object identifier is an auxiliary variable used to identify instances of the columnar objects in the Multi-Domain Capability Table.
OID_DOT11_MULTI_DOMAIN_CAPABILITY_ENABLED This object identifier, when TRUE, indicates that the ability of the NIC to operate in multiple regulatory domains is enabled.
OID_DOT11_MULTI_DOMAIN_CAPABILITY_IMPLEMENTED This object identifier, when TRUE, indicates that the NIC implementation is capable of supporting multiple regulatory domains.
OID_DOT11_NIC_POWER_STATE This object identifier sets the NIC power state. When set to TRUE, the power is turned on.
OID_DOT11_NIC_SPECIFIC_EXTENSION This object identifier represents NIC–specific extension information.
OID_DOT11_NUMBER_OF_HOPPING_SETS The number of sets field that indicates the total number of sets within the hopping patterns.
OID_DOT11_OFFLOAD_CAPABILITY This object identifier queries a NIC's offload capability.
OID_DOT11_OPERATION_MODE_CAPABILITY This object identifier queries the capability of operation mode.
OID_DOT11_OPERATIONAL_RATE_SET This object identifier specifies the set of data rates at which the station may transmit data.
OID_DOT11_OPTIONAL_CAPABILITY This object identifier queries the optional capability supported by the NIC.
OID_DOT11_PBCC_OPTION_IMPLEMENTED This object identifier, when true, indicates that the Packet Binary Convolutional Code (PBCC) modulation option as defined in sub-clause 18.4.6.6 is implemented.
OID_DOT11_POWER_MGMT_MODE This object identifier specifies the power management mode of the STA.
OID_DOT11_RANDOM_TABLE_FLAG When this object identifier is true, it indicates that a Random Table is present.
OID_DOT11_RECV_SENSITIVITY_LIST This object identifier, when queried, returns all DOT11_RECV_SENSITIVITY entries for a specified PHY type.
OID_DOT11_REG_DOMAINS_SUPPORT_VALUE There are different operational requirements that depend on the regulatory domain.
OID_DOT11_RESET_REQUEST This object identifier resets the NIC.
OID_DOT11_RF_USAGE The object identifier represents a NIC's knowledge of how busy a radio frequency (RF) spectrum is, as a percentage.
OID_DOT11_RSSI_RANGE This object identifier represents the NIC's RSSI range for the specified PHY type across all data rates for that PHY.
OID_DOT11_RTS_THRESHOLD This object identifier indicates the number of octets in an MAC Protocol Data Unit (MPDU), below which an RTS/CTS handshake is not performed.
OID_DOT11_SCAN_REQUEST This object identifier requests a survey of potential Basic Service Sets (BSS) that the station may later try to join.
OID_DOT11_SHORT_PREAMBLE_OPTION_IMPLEMENTED This object identifier, when true, indicates that the short preamble option as defined in subclause 18.2.2.2 is implemented.
OID_DOT11_SHORT_RETRY_LIMIT This object identifier indicates the maximum number of transmission attempts of a frame, the length of which are less than or equal to OID_DOT11_RTS_THRESHOLD, that are made before a failure condition is indicated.
OID_DOT11_SHORT_SLOT_TIME_OPTION_ENABLED This object identifier, when queried, returns the short slot time option enabled truth value.

When set, this object identifier sets the short slot time option enabled truth value.
OID_DOT11_SHORT_SLOT_TIME_OPTION_IMPLEMENTED This object identifier, when queried, returns the short slot time option implemented truth value. This value, when true, indicates that the short slot time option is implemented. The default value is set to FALSE.
OID_DOT11_START_REQUEST This object identifier requests that the card start a BSS.
OID_DOT11_STATION_ID The object identifier allows a manager to identify a station for its own purposes while keeping the true MAC address independent.
OID_DOT11_SUPPORTED_DATA_RATES_VALUE The Transmit bit rates that are supported by the PLCP and PMD, represented by a count from X'02-X'7f, that correspond to data rates in increments of 500Kb/s from 1 Mb/s to 63.5 Mb/s subject to limitations of each individual PHY.
OID_DOT11_SUPPORTED_PHY_TYPES This is an 8-bit integer value that identifies the PHY type supported by the attached PLCP and PMD.
OID_DOT11_SUPPORTED_POWER_LEVELS This object identifier queries the number of power levels supported by the PMD.
OID_DOT11_SUPPORTED_RX_ANTENNA When true, this object identifier indicates that the antenna represented by the uAntennaListIndex can be used as a receive antenna.
OID_DOT11_SUPPORTED_TX_ANTENNA When true, this object identifier indicates that the antenna represented by uAntennaListIndex can be used as a transmit antenna.
OID_DOT11_TEMP_TYPE This object identifier describes the current PHY's operating temperature range capability.
OID_DOT11_TI_THRESHOLD The threshold value being used to detect a busy medium (frequency). CCA reports a busy medium when it detects the Received Signal Strength Intensity (RSSI) above this threshold.
OID_DOT11_UPDATE_IE This object identifier requests that the underlying card add or update one or more IEs for an already started BSS.
OID_DOT11_WEP_ICV_ERROR_COUNT This counter increments when the following conditions are true:
OID_DOT11_WEP_OFFLOAD This object identifier passes a per-station key used for encrypting or decrypting packets.
OID_DOT11_WEP_UPLOAD This object identifier removes the per-station key for the NIC.
OID_DOT11_WPA_TSC This object identifier queries the values for current Temporal Key Integrity Protocol (TKIP) sequence counters.
