NDIS_STRING

This data type is used for all NDIS string operations.

typedef 
UNICODE_STRING NDIS_STRING, 
*PNDIS_STRING;

Remarks

NDIS_STRING is a counted, zero-terminated Unicode string.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ndis.h.
