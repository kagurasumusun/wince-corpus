USB Function Mass Storage Client Driver Functions

The following table shows the functions implemented by the mass storage client driver for the USB function controller.

Function Description
STORE_ExecuteCommand This function executes a mass storage command.
STORE_IsCommandSupported This function determines whether a mass storage command is supported.
