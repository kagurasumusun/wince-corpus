IEEE 1394 Unit Filter Driver Structures

The following table shows the IEEE 1394 unit filter driver structures with a description of the purpose of each.

Programming element Description
UNIT_AllocateLocalPlug_Request This structure is used by IOCTL_UNIT_ALLOCATE_LOCAL_PLUG.
UNIT_AllocateLocalPlug_Response This structure is used by IOCTL_UNIT_ALLOCATE_LOCAL_PLUG.
UNIT_ConnectionRequestProcessed_Request This structure is used by IOCTL_UNIT_CONNECTION_REQUEST_PROCESSED.
UNIT_DereferenceConnectionPlug_Request This structure is used by IOCTL_UNIT_DEREFERENCE_CONNECTION_PLUG.
UNIT_FreeLocalPlug_Request This structure is used by IOCTL_UNIT_FREE_LOCAL_PLUG.
UNIT_ProcessRegistryPlugs_Request This structure is used by IOCTL_UNIT_PROCESS_REGISTRY_PLUGS.
UNIT_QueryLocalPlugs_Request This structure is used by IOCTL_UNIT_QUERY_LOCAL_PLUGS.
UNIT_QueryLocalPlugs_Response This structure is used by IOCTL_UNIT_QUERY_LOCAL_PLUGS.
UNIT_RegisterSubunit_Request This structure is used by IOCTL_UNIT_REGISTER_SUBUNIT.
UNIT_RegisterSubunit_Response This structure is used by IOCTL_UNIT_REGISTER_SUBUNIT.
