PFN_KEYBD_PDD_ENTRY

This function initializes the keyboard driver platform dependent driver (PDD).

typedef BOOL (*PFN_KEYBD_PDD_ENTRY)(
  UINT uiPddId, 
  PFN_KEYBD_EVENT pfnKeybdEvent, 
  PKEYBD_PDD *ppKeybdPdd
);

Parameters

uiPddId
[in] Index of the PDD.
pfnKeybdEvent
[in] Pointer to a PFN_KEYBD_EVENT function.
ppKeybdPdd
[in] Pointer to a KEYBD_PDD structure.

Return Values

None.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Keybdpdd.h.

See Also

KEYBD_PDD | PFN_KEYBD_EVENT
