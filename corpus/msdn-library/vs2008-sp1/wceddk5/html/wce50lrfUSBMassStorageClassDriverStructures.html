USB Function Mass Storage Client Driver Structures

The following table shows the structures used by the mass storage client driver for the USB function controller.

Structure Description
TRANSPORT_COMMAND This structure describes a SCSI-2 command block.
TRANSPORT_DATA This structure describes a SCSI-2 data block.
