NDIS Support for Media Sense

Media Sense improves the roaming experience for mobile device users by allowing an enabled Microsoft® Windows® CE–based device to recognize that it is physically disconnected from a network to which it was previously connected. This is accomplished through the use of network adapters that detect voltage levels in the connection line. The majority of modern network interface cards (NICs) have this capability, as it was required for PC97 and later certification.

Note   A 10Base2 card cannot implement Media Sense, although it is possible to use Media Sense for other network topologies, such as wireless.

Support for Media Sense allows the protocol stack to react to specific events and remove any stale parameters. For example, if a Windows CE–based device is unplugged from the network, after a damping period, TCP/IP invalidates the parameters associated with the network that has been disconnected. The IP addresses no longer allow any information to be sent and any routes associated with the interface are invalidated. If an application is bound to a socket that is using an invalidated address, it should handle the event and recover in a graceful manner. It should also attempt to use another network interface on the system or notify the user of the disconnect.
