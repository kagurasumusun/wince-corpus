Testing USB Device Drivers

You can test universal serial bus (USB) drivers with the Microsoft® Windows® CE Test Kit (CETK). For information about running the CETK, see CETK Setup.

The sample USB HID driver and the USB 8x930Ax peripheral kit and evaluation board from Intel Corporation can also be used to assist in testing USB scenarios.
