Pluggable Codec Requirements

The pluggable codec interface allows you to plug in your own codec wrapped with the Microsoft standard Audio Compression Manager (ACM) interface. Therefore, a pluggable codec is also an ACM driver.

An ACM driver is required to meet certain requirements and must provide a minimal set of function calls.

The following topics explain the requirements transforming your codec to an ACM driver:

  • Recognized Formats
  • Codec Configuration
  • Extra Bytes
  • Samples per Block
  • Required Entry-point Function
