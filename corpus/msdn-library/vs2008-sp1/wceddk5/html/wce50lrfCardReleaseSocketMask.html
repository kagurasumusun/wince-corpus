CardReleaseSocketMask

This function disables the callbacks requested by the CardRequestSocketMask function for a particular socket and function pair.

STATUS CardReleaseSocketMask(
  CARD_CLIENT_HANDLE hCardClient,
  CARD_SOCKET_HANDLE hSock 
);

Parameters

hCardClient
[in] Client handle obtained from the CardRegisterClient function.
hSock
[in] Handle to a socket and function pair.

Return Values

CERR_SUCCESS indicates success. One of the following values indicates failure:

CERR_BAD_HANDLE
Indicates that an hCardClient driver handle is not valid.
CERR_BAD_SOCKET
Indicates that an hSock socket identifier is not valid or that no PC Card is in the socket. It can also be returned if no prior call was made to the CardRequestSocketMask function.

Remarks

This function does not disable the global events set by CardRegisterClient.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Cardserv.h.
Link Library: Cardserv.lib.
