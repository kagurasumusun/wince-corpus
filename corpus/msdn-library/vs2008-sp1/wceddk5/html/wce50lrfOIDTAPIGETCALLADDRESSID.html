OID_TAPI_GET_CALL_ADDRESS_ID

OID_TAPI_GET_CALL_ADDRESS_ID requests the miniport driver to return the address ID for the specified call.

Support for this request is mandatory.

This request uses an NDIS_TAPI_GET_CALL_ADDRESS_ID structure.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ntddndis.h and Ndistapi.h.
