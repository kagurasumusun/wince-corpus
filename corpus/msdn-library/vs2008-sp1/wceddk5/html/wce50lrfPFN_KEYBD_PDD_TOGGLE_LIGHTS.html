PFN_KEYBD_PDD_TOGGLE_LIGHTS

This function toggles the lights on the keyboard.

typedef void (*PFN_KEYBD_PDD_TOGGLE_LIGHTS)(
  UINT uiPddId, 
  KEY_STATE_FLAGS KeyStateFlags
);

Parameters

uiPddId
[in] Index of the PDD.
KeyStateFlags
[in] Key states defined by KEY_STATE_FLAGS.

Return Values

None.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Keybdpdd.h.
