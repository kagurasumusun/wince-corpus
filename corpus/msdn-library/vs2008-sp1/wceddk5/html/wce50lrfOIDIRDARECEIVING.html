OID_IRDA_RECEIVING

This object identifier requests the miniport driver to indicate whether it is currently receiving a frame. If the miniport driver is not currently receiving a frame, it returns a 0 to a query of this object identifier. If the miniport driver is currently receiving a frame, it returns a nonzero value to a query of this object identifier.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ntddndis.h.
