HCI_EVENT

This enumeration defines the state of the Bluetooth controller hardware.

enum HCI_EVENT {
  DEVICE_UP,
  DEVICE_DOWN,
  DEVICE_ERROR
};

Elements

DEVICE_UP
Device is up.
DEVICE_DOWN
Device is down.
DEVICE_ERROR
Device encountered an error.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Bt_hcip.h.
