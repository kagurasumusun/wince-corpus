DEVICEWINDOW

This structure describes a base and length pair.

typedef struct _DEVICEWINDOW_tag {
  DWORD dwBase; 
  DWORD dwLen;
} DEVICEWINDOW, *PDEVICEWINDOW;

Members

dwBase
Window base address.
dwLen
Window length.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ddkreg.h.
