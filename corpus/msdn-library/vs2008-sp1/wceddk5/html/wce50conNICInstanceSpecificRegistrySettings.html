NIC Instance Specific Registry Settings

Instance specific registry settings can be assigned for a NIC by setting them in HKEY_LOCAL_MACHINE\Comm\<InstanceName>\Parms. For example, if you want to assign a static IP address for the PCI\MYNIC1 adapter, you add the following registry information.

[HKEY_LOCAL_MACHINE\Comm\PCI\MYNIC1\Parms\TcpIp]
    "EnableDHCP"dword:0
    "DefaultGateway"=multi_sz:"192.168.1.1"
    "IpAddress"=multi_sz:"192.168.1.2"
    "Subnetmask"=multi_sz:"255.255.255.0"
    "UseZeroBroadcast"=dword:0

This registry entry causes the first enumerated MYNIC PCI adapter to be assigned the IP address 192.168.1.2.
