The following tables show the Italian keyboard layout. The at (@) sign, which is included as part of the character, indicates that the character is a dead key. A dead key, when pressed in combination with a second Unicode character, results in a third Unicode character. The dead-key tables show the Unicode characters that result from specific dead-key combinations. Virtual keys for the omitted scan codes equal zero (0).
