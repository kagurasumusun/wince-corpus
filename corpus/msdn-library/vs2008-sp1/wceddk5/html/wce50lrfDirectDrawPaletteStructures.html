DirectDrawPalette Structures

The following table shows the DirectDrawPalette structures.

Structure Description
DDHAL_DESTROYPALETTEDATA Destroys a specified palette.
DDHAL_SETENTRIESDATA Contains information necessary to change the palette entries in a specified palette immediately.
DDRAWI_DDRAWPALETTE_GBL Contains the global DirectDrawPalette data that can be shared between object instances.
DDRAWI_DDRAWPALETTE_INT Contains the DirectDrawPalette object's interface information.
DDRAWI_DDRAWPALETTE_LCL Contains local data for each DirectDrawPalette object.
