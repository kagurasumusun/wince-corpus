RNDIS Objects

This section lists the required and optional NDIS OIDs for RNDIS Ethernet devices. The list takes into account the unique properties of a RNDIS device and the RNDIS miniport driver, so the list is not identical to the list that a typical NDIS connectionless miniport driver would support. Some OIDs are both set and query OIDs; if a mandatory OID is defined as both, then it must be supported by a RNDIS device for both REMOTE_NDIS_SET_MSG and REMOTE_NDIS_QUERY_MSG.
