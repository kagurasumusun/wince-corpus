TIMECAPS

This structure contains information about the resolution of the timer.

typedef struct timecaps_tag {
  UINT wPeriodMin; 
  UINT wPeriodMax; 
} TIMECAPS, *PTIMECAPS;

Members

wPeriodMin
Minimum period supported.
wPeriodMax
Maximum period supported.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Mmsystem.h.
