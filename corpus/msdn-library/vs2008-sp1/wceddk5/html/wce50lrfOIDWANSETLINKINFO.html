OID_WAN_SET_LINK_INFO

This object requests the miniport driver to set information for an established link. The protocol-supplied information is formatted as an NDIS_WAN_SET_LINK_INFO structure.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ndis.h.
