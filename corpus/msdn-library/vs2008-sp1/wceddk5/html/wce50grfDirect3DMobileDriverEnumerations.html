Direct3D Mobile Driver Enumerations

This section contains information about the enumerations used with drivers for Microsoft® Direct3D®. Mobile.

The following table shows these enumerations.

Enumeration Description
D3DM_OPERATION Used in a command token header, D3DM_COMMAND, to identify the types of command tokens that the Direct3D Mobile middleware may pass to the driver .
D3DM_RESOURCEMANAGER_ACTION Used in D3DM_RESOURCEMANAGER_DATA structures to identify instructions for the driver's resource manager.
D3DM_SETLIGHT_DATATYPE Used in D3DM_SETLIGHT and D3DM_SETLIGHT_WITHDATA structures to identify the new settings for a light.
D3DM_SETPALETTE_DATATYPE Used in D3DM_SETPALETTE and D3DM_SETPALETTE_WITHENTRIES structures to identify the new settings for a palette.
