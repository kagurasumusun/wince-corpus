WAV_Close

This function closes the WAV I/O device.

BOOL WAV_Close(
  DWORD dwOpenData 
);

Parameters

dwOpenData
Specifies a value returned from a call to the WAV_Open function.

Return Values

TRUE indicates success. FALSE indicates failure.

Requirements

OS Versions: Windows CE 1.0 and later.
Header: Wavemdd.h.
