Installing the USB Host Mass Storage Client Driver on the Target Device

If you have a universal serial bus (USB) mass storage class device, you must install the USB mass storage class driver on the target device, and you must add registry keys for the device.

To install the USB host mass storage client driver on the target device

  1. Include the USB storage class driver in the Windows CE OS binary image.

    - or -

    If the driver is not in the Nk.bin image, manually copy the driver DLL, called Usbmsc.dll, to your release directory on your development workstation or to the Windows directory on the target device.

  2. On the target device, set up the correct registry entries for the storage driver.

    For more information about registry settings, see USB Host Controller Driver Registry Settings.

  3. Attach the USB storage device to the target device.

    If you have the correct registry entries set up on the target device and if the USB device is class-compliant, then the USB subsystem loads the storage driver automatically. However, if you do not have the correct registry settings on the Windows CE device, the system displays an Unknown Device dialog box.

  4. If an Unknown Device dialog box is displayed, type USBMSC in the dialog box, and then press ENTER.

    This action loads the USB storage class driver and sets the correct registry entries so the driver can load automatically next time.
