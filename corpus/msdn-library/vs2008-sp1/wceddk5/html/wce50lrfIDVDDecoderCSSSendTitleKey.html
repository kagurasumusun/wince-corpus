IDVDDecoderCSS::SendTitleKey

This method sends the title key to the appropriate location.

HRESULT SendTitleKey(
  CSS_KEY* pKey
);

Parameters

pKey
[in] Pointer to return the title key.

Return Values

The following table shows a list of possible return values.

Return value Description
S_OK The request completed successfully.
E_FAIL The request did not complete successfully.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Dvdcss.idl.
