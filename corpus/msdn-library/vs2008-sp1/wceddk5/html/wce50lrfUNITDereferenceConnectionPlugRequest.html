UNIT_DereferenceConnectionPlug_Request

This structure is used by IOCTL_UNIT_DEREFERENCE_CONNECTION_PLUG.

typedef struct {
  PVOID udcp_RegistrationToken;
  HANDLE udcp_Plug;
} UNIT_DereferenceConnectionPlug_Request;

Members

udcp_RegistrationToken
Registration token value from a previous IOCTL_UNIT_REGISTER_SUBUNIT command.
udcp_Plug
Must be completed with the plug handle provided by UNIT_ConnectToRemotePlugCB.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Avc_unit.h.
