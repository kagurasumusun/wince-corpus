DDHAL_DESTROYDRIVERDATA

This structure contains information necessary to destroy a driver. This structure passes the information to the DirectDraw hardware abstraction layer (DDHAL) DestroyDriver callback function. 

typedef struct _DDHAL_DESTROYDRIVERDATA {
  LPDDRAWI_DIRECTDRAW_GBL lpDD;
  HRESULT ddRVal;
  LPDDHAL_DESTROYDRIVER DestroyDriver;
} DDHAL_DESTROYDRIVERDATA;

Members

lpDD
Pointer to the DDRAWI_DIRECTDRAW_GBL structure that represents the DirectDraw object.
ddRVal
Passes the DirectDraw return values.
DestroyDriver
Used by DirectDraw and should not be filled in by the driver.

Requirements

OS Versions: Windows CE 2.12 and later. Version 2.12 requires DXPAK 1.0 or later.
Header: Ddrawi.h.
