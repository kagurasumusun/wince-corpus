OID_DOT11_NIC_POWER_STATE

This object identifier sets the NIC power state.

When set to TRUE, the power is turned on.

When set to FALSE, the power is turned off; this is equivalent to the NIC operating in doze state.

In the OFF state, the OS should be able to detect the presence of the NIC driver, which implies that the NIC driver remains in memory.

Default value in the NIC driver is TRUE.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Windot11.h.
