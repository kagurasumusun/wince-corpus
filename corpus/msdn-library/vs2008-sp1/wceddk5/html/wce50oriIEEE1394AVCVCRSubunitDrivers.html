IEEE 1394 AV/C VCR Subunit Drivers

IEEE 1394 AV/C VCR subunit drivers handle control of VCR devices. Commands not recognized by the IEEE 1394 AV/C VCR subunit driver are passed down to the IEEE 1394 streaming filter driver, which resides below the AV/C VCR subunit driver in the Windows CE IEEE 1394 driver stack.
