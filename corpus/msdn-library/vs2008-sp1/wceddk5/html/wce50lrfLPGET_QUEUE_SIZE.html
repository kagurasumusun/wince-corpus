LPGET_QUEUE_SIZE

This function obtains the size of the HID clients queue.

typedef DWORD (*LPGET_QUEUE_SIZE) (
  HID_HANDLE hDevice,
  PDWORD pdwSize
);

Parameters

hDevice
[in] Handle to a HID device.
pdwSize
[out] Queue size.

Return Values

The following table shows the possible return values.

Value Description
ERROR_INVALID_HANDLE hDevice was an invalid HID device handle.
ERROR_INVALID_PARAMETER pdwSize was set to NULL or there was an exception writing to pdwSize.
ERROR_SUCCESS Function returned successfully.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Hiddi.h.
