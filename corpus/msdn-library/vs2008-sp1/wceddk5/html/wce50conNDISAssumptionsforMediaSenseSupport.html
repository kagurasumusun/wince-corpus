NDIS Assumptions for Media Sense Support

NDIS assumes that every miniport falls into one of the following categories:

  • No Media Sense support
  • Support for the Media Sense query only
  • Full Media Sense support

NDIS also assumes the following is true:

  • The miniport Media Sense query indicates the correct media state.
  • Notifications are sent for miniports that claim to support them.
  • Notifications are of the correct media type.
  • Immediately after notification, the query result corresponds to the notification.

If a miniport does not implement the notification function, NDIS will simulate this notification for transports by querying the media state every 2 seconds and generating a notification whenever the media state does change.
