DVD-Video Renderer Interface Identifiers

The following interface identifiers are used to obtain pointers to DVD-Video renderer interfaces.

Constant Description
IID_IDMAChannel Used to obtain a pointer to an IDMAChannel interface.
IID_IBitstreamProcessor Used to obtain a pointer to an IBitstreamProcessor interface.
IID_IDVDRenderer Used to obtain a pointer to an IDVDRenderer interface.
IID_IDVDDecoderCSS Used to obtain a pointer to an IDVDDecoderCSS interface.
