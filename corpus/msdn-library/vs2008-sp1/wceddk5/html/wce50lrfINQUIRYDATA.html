INQUIRY_DATA

This structure contains information on the CD-ROM device.

typedef struct _INQUIRY_DATA {
  UCHAR inqDevType; 
  UCHAR inqRMB; 
  UCHAR inqVersion; 
  UCHAR inqAtapiVersion; 
  UCHAR inqLength; 
  UCHAR inqReserved[3]; 
  UCHAR inqVendor[8]; 
  UCHAR inqProdID[16]; 
  UCHAR inqRev[4]; 
  UCHAR inqReserved2[60]; 
} INQUIRY_DATA, *PINQUIRY_DATA;

Members

inqDevType
Bits 5-7: Peripheral qualifier
Bits 0-4: Device class
inqRMB
Bit 7: Removable device
inqVersion
Bits 6-7: ISO version
Bits 3-5: ECMA version
Bits 0-2: ASCII version
inqAtapiVersion
Bit 7: AEN – Asynchronous Event Notification capability
Bit 6: TIO – Terminate I/O Process support
Bit 5: Reserved
Bit 4: Reserved
Bits 0-3: Data format
inqLength
Additonal data length.
inqReserved
Reserved.
inqVendor
Manufacturer's name in ASCII.
inqProdID
Product's name in ASCII.
inqRev
Product's version in ASCII.
inqReserved2
Reserved.

Remarks

This structure directly corresponds to the sense data returned by the ATA packet interface driver. For more information, see the Small Computer System Interface Specification.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Atapi2.h.
