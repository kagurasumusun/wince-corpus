USB Function Mass Storage Client Driver Samples

The following table shows the subdirectories that contain USB mass storage client driver samples, which are located in the %_WINCEROOT%\Public\Common\OAK\Drivers\USBFN\Class\Storage directory.

Subdirectory Description
Emulation Contains emulation scheme implementation
Emulation\SCSI2 Contains SCSI-2 direct-access device emulation implementation
Emulation\SCSI2\Block Contains emulation by block device implementation
Transport Contains USB mass storage client driver transport scheme implementation
Transport\BOT Contains bulk-only transport implementation
Transport\CBIT Contains control/bulk/interrupt transport (CBIT) implementation
