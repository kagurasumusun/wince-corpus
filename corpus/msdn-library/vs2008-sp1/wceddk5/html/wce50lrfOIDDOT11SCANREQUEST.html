OID_DOT11_SCAN_REQUEST

This object identifier requests a survey of potential Basic Service Sets (BSS) that the station may later try to join. The following list shows the internal parameters that the underlying card uses when doing the scan:

  • ProbeDelayDelay (in µs) to be used prior to transmitting a probe frame during active scanning.
  • ChannelListEach channel will be selected from the valid channel range for the appropriate physical layer (PHY) and carrier set. Specifies a list of channels that are examined when scanning for a BSS.
  • MinChannelTimeThe minimum time to spend on each channel when scanning.
  • MaxChannelTimeThe maximum time to spend on each channel when scanning.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Windot11.h.
