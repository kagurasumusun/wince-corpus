USB Function Controller MDD Functions

The USB function controller driver MDD implements a stream interface. For more information, see Stream Interface Drivers. The USB function controller driver MDD also implements two other functions. The following table shows these functions.

Function Description
DllMain This function initializes any MDD-specific module level variables
SendDeviceNotification This function notifies the MDD of specified bus-level events
