RNDIS_REQUEST_ID

This data type specifies the Remote NDIS message identifier. This value is used to match device responses to host sent messages.

typedef UINT32 RNDIS_REQUEST_ID;

None.

OS Versions: Windows CE .NET 4.0 and later.
