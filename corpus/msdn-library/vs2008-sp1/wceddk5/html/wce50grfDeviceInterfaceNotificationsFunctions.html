Device Interface Notifications Functions

The following table shows the device interface notifications functions.

Programming element Description
RequestDeviceNotifications This function requests notifications for the appearance and disappearance of device interfaces.
StopDeviceNotifications This functions stops notifications of the appearance and disappearance of device interfaces.
