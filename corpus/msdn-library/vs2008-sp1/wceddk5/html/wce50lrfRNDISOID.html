RNDIS_OID

This data type is used by REMOTE_NDIS_QUERY_MSG and REMOTE_NDIS_SET_MSG to specify a Remote NDIS object identifier that queries or sets a parameter.

typedef UINT32 RNDIS_OID;

Remarks

For more information about Remote NDIS object identifiers see Remote NDIS Objects.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Rndis.h.
