OID_DOT11_WEP_ICV_ERROR_COUNT

This counter increments when the following conditions are true:

  • A frame is received with the Frame Control/WEP field set to 1.
  • The ICV value in the received frame does not match the calculated ICV value of the received frame.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Windot11.h.
