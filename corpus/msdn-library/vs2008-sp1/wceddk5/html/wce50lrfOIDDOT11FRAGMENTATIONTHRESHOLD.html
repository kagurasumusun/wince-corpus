OID_DOT11_FRAGMENTATION_THRESHOLD

This object identifier specifies the current maximum size, in octets, of the MAC Protocol Data Unit (MPDU) that may be delivered to the PHY.

An MSDU is broken into fragments if its size exceeds the value of this object identifier after adding MAC headers and trailers.

An MSDU or MMPDU is fragmented when the resulting frame has an individual address in the Address1 field, and the length of the frame is larger than this threshold.

The default value for this object identifier is the lesser of 2346 or the aMPDUMaxLength of the attached PHY and does not exceed the lesser of 2346 or aMPDUMaxLength of the attached PHY.

The value of this object identifier is never less than 256.

Requirements

OS Versions: Windows CE .NET 4.1 and later.
Header: Windot11.h.
