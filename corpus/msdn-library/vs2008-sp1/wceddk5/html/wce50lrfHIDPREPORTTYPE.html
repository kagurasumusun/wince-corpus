HIDP_REPORT_TYPE

This enumeration specifies a HID report type.

typedef enum _HIDP_REPORT_TYPE {
  HidP_Input,
  HidP_Output,
  HidP_Feature
} HIDP_REPORT_TYPE;

Elements

HidP_Input
Input report indicator.
HidP_Output
Output report indicator.
HidP_Feature
Feature report indicator.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Hidpi.h.
