Sharing Responsibilities

The lower stack layer is not responsible for understanding, interpreting, and enforcing configurable parameters negotiated by upper stack layers. For example, if the RFCOMM frame size is negotiated to be 127 bytes, RFCOMM_DataDown_In will accept an attempt to pass bigger packets if requested to do so. It is the upper layer's responsibility to comply with and enforce negotiated parameters for its connection. Conduct is with the user of a channel, not the carrier.
