Block Driver Loading

You should include registry keys under the HKEY_LOCAL_MACHINE\Drivers\Builtin registry key for your OS design so that the Device Manager loads the block device driver when the run-time image starts. For more information about the Device Manager, see Device Manager.

Block device drivers for PC Card block devices or similar removable hardware use the HKEY_LOCAL_MACHINE\Drivers\PCMCIA or HKEY_LOCAL_MACHINE\Drivers\PCCARD\PCMCIA registry key so that the Device Manager loads the driver when you connect the relevant block device to the system.
