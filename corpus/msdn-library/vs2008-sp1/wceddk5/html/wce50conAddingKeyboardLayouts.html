Platform Builder for Microsoft Windows CE 5.0  

Adding Keyboard Layouts

For run-time images that support keyboards, the default keyboard is a United States 101 keyboard. To support other keyboard layouts, set the sysgen variable for the keyboard, and then add the associated registry keys to the Platform.reg file.

For more information, see Device Layouts and Device Layout Data.
