NdisWritePortUshort

The NIC driver calls this function to write a USHORT to an I/O port.

VOID NdisWritePortUshort(
  NDIS_HANDLE NdisAdapterHandle,
  ULONG Port,
  USHORT Data
);

Parameters

NdisAdapterHandle
[in] Specifies the handle that the NDIS interface library associates with the network interface card.
Port
[in] Specifies the I/O port.
Data
[in] Specifies the USHORT value to write to Port.

Return Values

None.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ndis.h.
