PCMCIA Legacy Compatibility Layer Window Speeds

Window speed masks specify the access speed for a memory or I/O window. The following table shows the defined window speed masks.

Speed mask Description
WIN_SPEED_EXP_MASK Exponent mask
WIN_SPEED_EXP_1NS 1 nanosecond
WIN_SPEED_EXP_10NS 10 nanoseconds
WIN_SPEED_EXP_100NS 100 nanoseconds
WIN_SPEED_EXP_1US 1 microsecond
WIN_SPEED_EXP_10US 10 microseconds
WIN_SPEED_EXP_100US 100 microseconds
WIN_SPEED_EXP_1MS 1 millisecond
WIN_SPEED_EXP_10MS 10 milliseconds
WIN_SPEED_MANT_MASK Mantissa mask
WIN_SPEED_MANT_10 Mantissa value 1.0
WIN_SPEED_MANT_12 Mantissa value 1.2
WIN_SPEED_MANT_13 Mantissa value 1.3
WIN_SPEED_MANT_15 Mantissa value 1.5
WIN_SPEED_MANT_20 Mantissa value 2.0
WIN_SPEED_MANT_25 Mantissa value 2.5
WIN_SPEED_MANT_30 Mantissa value 3.0
WIN_SPEED_MANT_35 Mantissa value 3.5
WIN_SPEED_MANT_40 Mantissa value 4.0
WIN_SPEED_MANT_45 Mantissa value 4.5
WIN_SPEED_MANT_50 Mantissa value 5.0
WIN_SPEED_MANT_55 Mantissa value 5.5
WIN_SPEED_MANT_60 Mantissa value 6.0
WIN_SPEED_MANT_70 Mantissa value 7.0
WIN_SPEED_MANT_80 Mantissa value 8.0
WIN_SPEED_USE_WAIT Use wait if available
