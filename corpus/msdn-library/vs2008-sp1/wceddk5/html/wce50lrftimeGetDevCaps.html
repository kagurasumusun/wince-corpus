timeGetDevCaps

This function queries the timer device to determine its resolution.

MMRESULT timeGetDevCaps(
  LPTIMECAPS ptc,
  UINT cbtc
);

Parameters

ptc
[in] Pointer to a TIMECAPS structure.

This structure is filled with information about the resolution of the timer device.

cbtc
[in] Size, in bytes, of the TIMECAPS structure.

Return Values

Returns TIMERR_NOERROR, if successful, or TIMERR_STRUCT, if it fails to return the timer device capabilities.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
Header: Mmsystem.h.
Link Library: Mmtimer.lib.
