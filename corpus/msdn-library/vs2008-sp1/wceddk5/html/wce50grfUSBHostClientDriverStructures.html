USB Host Client Driver Structures

The following table shows the universal serial bus (USB) host client driver structures.

Structure Description
REG_VALUE_DESCR This structure contains information about a registry key. It is a registry value descriptor.
REMOVE_LOCK This structure contains information about a removal lock.
