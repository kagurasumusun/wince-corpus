RNDIS_MEDIUM

This data type defines the valid media used by RNDIS.

typedef UINT32 RNDIS_MEDIUM;

Remarks

The following table shows the RNDIS mediums.

Medium Value Description
RNdisMedium802_3 0x00000000 Specifies an Ethernet medium.
RNdisMedium802_5 0x00000001 Specifies a token ring medium.
RNdisMediumFddi 0x00000002 Not supported.
RNdisMediumWan 0x00000003 Specifies a WAN medium.
RNdisMediumLocalTalk 0x00000004 Not supported.
RNdisMediumArcnetRaw 0x00000006 Not supported.
RNdisMediumArcnet878_2 0x00000007 Not supported.
RNdisMediumAtm 0x00000008 Not supported.
RNdisMediumWirelessWan 0x00000009 Not supported.
RNdisMediumIrda 0x0000000a Specifies an IrDA (infrared) medium.
RNdisMediumCoWan 0x0000000b Not supported.
RNdisMediumMax 0x0000000d Not a real medium, defined as an upper-bound.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Rndis.h.
