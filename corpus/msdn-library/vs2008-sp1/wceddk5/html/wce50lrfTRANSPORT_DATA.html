TRANSPORT_DATA

This structure describes a SCSI-2 data block.

typedef struct _TRANSPORT_DATA_BUFFER {
  DWORD RequestLength;
  DWORD TransferLength;
  PVOID DataBlock;
} TRANSPORT_DATA, *PTRANSPORT_DATA;

Members

RequestLength
[in] Length requested.
TransferLength
[out] Number of bytes transferred.
DataBlock
[in] Pointer to the data buffer. May be NULL.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Usbmsc.h.
