NDIS Timers

A driver creates a timer for polling or timing out operations. The driver associates a function with the timer, and then calls the associated function when the period specified in the timer expires. Timers can occur once or repeatedly. Once you set a recurring timer, it continues to fire at the expiration of every period until explicitly cleared. A one-time timer must be reset each time it fires.

The following table shows the NDIS time functions.

Function Description
NdisMInitializeTimer Creates and initializes timers.
NdisMSetTimer Sets or resets a one-time timer.
NdisMSetPeriodicTimer Sets a recurring timer.
NdisMCancelTimer Clears a timer.
