NDIS_PROC

This data type is used to specify the entry point of a caller-supplied function that processes a work item when it is dequeued.

typedef
VOID (*NDIS_PROC) (
  struct _NDIS_WORK_ITEM *,
  PVOID
);

Remarks

None.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ndis.h.
