Unloading Symbols for a Module

You can unload the symbols for a module.

To unload symbols for a module

  • In the Modules and Symbols window, right-click a module and then choose Unload Symbols from the shortcut menu.

    - or -

    Choose the Unload Symbols button on the window toolbar.

    Note   Unload Symbols is only available if symbols are loaded.
