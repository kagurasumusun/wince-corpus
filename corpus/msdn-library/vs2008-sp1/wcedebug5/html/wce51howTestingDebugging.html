Testing and Debugging

If you are working with a real device, you will need to use test certificates to deploy/debug these projects for testing. Test certificates are supplied with the SDK, and can be used as follows:

  1. Put the SDK certificate onto your device.
    1. Using ActiveSync copy C:\Program Files\Windows CE Tools\wce500\Windows Mobile 5.0 Smartphone SDK\Tools\SdkCerts.cpf to \Windows\Start Menu\Games.
    2. On your device go into the games folder from the start menu and action on SdkCerts.cpf.
  2. Configure each project that you will be deploying or debugging to use these certificates. This is a per-project process.
    1. In Solution Explorer, right-click the project, and then click Properties on the shortcut menu.
    2. Click the Devices tab.
    3. Check the Authenticode Signature checkbox.
    4. Click Select Certificate.
    5. In the Select Certificate dialog box, if the certificate you want appears in the list, select it and then click OK to close the dialog box.
    6. If the certificate you want does not appear in the list, click Manage Certificates to open the Manage Certificates dialog box. Use this dialog box to import one of the SDK certificates (or, if the OEM or operator gave you a certificate as part of their developer program, use that). Remember to use the .pfx file, not the .cer file.
    7. On the Authenticode Signing page, click OK.
