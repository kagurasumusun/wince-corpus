Creating a Snapshot Window

You can create a static copy, or snapshot, of the information in a Properties windows

To create a Snapshot window

  1. In the Properties pane, choose an item or thread.
  2. Choose the User tab or the All tab to display the properties you want to copy to the snapshot.
  3. Choose the Snapshot tab.
