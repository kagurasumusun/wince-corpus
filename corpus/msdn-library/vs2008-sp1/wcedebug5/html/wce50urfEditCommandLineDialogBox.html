Platform Builder for Microsoft Windows CE 5.0  

Edit Command Line Dialog Box

In this dialog box, you can modify the command line for a selected CETK test.

Command line
Command line to execute to start the selected test.
Note   The CETK tool automatically appends the parameter -f <logfile> entry to the command line when a test runs. This command-line entry stores the results of the test in a log file. You should not add your own –f switch to the command line.
Restore
Replaces the current command line with the original command line for the test.
Target device
Name of the target device to which a temporary change to the command line is applied. If you make a permanent change to the command line, the permanent change is applied to all target devices.
Temporarily, to this target device
If selected, modifications to the command line for the test are applied only to the selected Windows CE–based device. Modifications to the command line are temporary and are not preserved when you detect peripherals for the target device, disconnect the target device, or close the CETK window.
Permanently, to all devices
If selected, modifications to the command line for the test are applied to the command line that executes when you run the test on any Windows CE–based device connected to the CETK. Modifications to the command line are permanent. You can reverse the changes by further modifying the command line or by choosing Restore.
OK
Saves changes to the command line and closes the dialog box.
Cancel
Closes the dialog box without modifying the command line.
