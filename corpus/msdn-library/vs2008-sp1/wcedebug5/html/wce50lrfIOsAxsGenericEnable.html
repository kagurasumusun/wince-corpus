IOsAxsGeneric::Enable

This method re-starts OsAccess services.

After this method executes, all associated methods operate normally again.

HRESULT Enable(
  BOOL fReset
);

Parameters

fReset
[in] If TRUE, caches in the service should be invalidated, such as when the target has been reset.

Return Values

The following table shows return values for this method.

Value Description
S_OK Indicates the function was successful.
E_FAIL Indicates an unspecified failure.

Requirements

OS Version: Windows CE 5.0 and later.
Header: OsAccess.h.
Link Library: OSAXSC.lib.
