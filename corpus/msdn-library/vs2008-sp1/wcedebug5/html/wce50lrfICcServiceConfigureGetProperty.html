ICcServiceConfigure::GetProperty

This method returns a value associated with a property within the specified service.

HRESULT   GetProperty(
  BSTR bstrPropertyName,
  BSTR* pbstrPropertyValue
);

Parameters

bstrPropertyName
[in] Name of the property to retrieve the value for.
pbstrPropertyValue
[out, retval] Value associated with the property.

Return Values

The following table shows return values for this method.

Value Description
S_OK Indicates the call was successful.
E_INVALIDARG Indicates pbstrPropertyValue or bstrPropertyName is NULL.
E_FAIL Return value for any other failure.

Requirements

OS Version: Windows CE 5.0 and later.
Header: CcServiceConfigure.h.
Link Library: none.
