Introduction to Data Collection Control

Remote Call Profiler can collect profiling information when you run an instrumented application or instrumented OS code.

To control the amount of data collected, you can use the Remote Call Profiler Collection Control window to set the initial profiling state, and then use the Remote Call Profiler Collection Control window or Remote Call Profiler data collection control functions to turn profiling on and off.

With the Remote Call Profiler Collection Control window, you can do the following:

  • Interactively control data collection during a profiling run.
  • Launch an application on the target device.
  • Start or stop the collection of data from the target device.
