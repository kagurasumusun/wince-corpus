ICcDatastore::get_Version

This method returns the version of the datastore.

HRESULT Version(
  BSTR* out_pbstrVersion
);

Parameters

out_pbstrVersion
[out, retval] Version of the datastore.

Return Values

The following table shows return values for this method.

Value Description
E_INVALIDARG Indicates that out_pbstrVersion is NULL.
S_FALSE Indicates the property is not found.
E_OUTOFMEMORY Indicates the method could not allocate memory.

Requirements

OS Version: Windows 2000, Windows XP Home, Windows XP Pro, Windows Server 2003, and Windows Server 2003 Service Pack 1.
Header: CcDatastore.h.
Link Library: none.
