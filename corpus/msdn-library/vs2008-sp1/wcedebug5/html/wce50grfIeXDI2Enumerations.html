IeXDI2 Enumerations

The following enumerations define possible values for IeXDI2 structures and interfaces.

Enumeration Description
BP_KIND Designates the possible kinds of breakpoints.
EXCEPTION_CHANCE Specifies the exception notification phase (first or second chance).

For more information about exceptions, see Exception Handling for Windows CE.
EXCEPTION_DEFAULT_ACTION_TYPE2 Lists default actions that can occur as a result of an exception.
HALT_REASON_CODE_TYPE2 Lists possible reasons for a target device execution halt.
RUN_STATUS_TYPE2 Lists possible run states for a target device.
MEM_TYPE2 Designates the possible kinds of memory resources.
TRISTATE_TYPE Specifies a generic tri-state type.
