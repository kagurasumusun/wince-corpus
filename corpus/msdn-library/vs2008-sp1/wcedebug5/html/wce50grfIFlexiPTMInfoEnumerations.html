IFlexiPTMInfo Enumerations

The following table shows the enumerations that define values in the IFlexiPTMInfo interface.

Enumeration Description
MODULE_FIELD_IDS Defines identifiers for module fields.
PROC_FIELD_IDS Defines identifiers for process fields.
THREAD_FIELD_IDS Defines identifiers for thread fields.

Requirements

OS Version: Windows CE 5.0 and later.
Header: FlexiPMTInfo.h.
