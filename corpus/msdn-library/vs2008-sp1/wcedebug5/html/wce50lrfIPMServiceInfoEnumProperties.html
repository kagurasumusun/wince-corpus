IPMServiceInfo::EnumProperties

This method enumerates the properties that are associated with the service information object.

HRESULT EnumProperties(
  IEnumVariant** ppiEnumProperty 
);

Parameters

ppiEnumProperty
[out] Pointer to a pointer to the IEnumVariant interface.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Serviceinfo.h, Cemgr.idl.
