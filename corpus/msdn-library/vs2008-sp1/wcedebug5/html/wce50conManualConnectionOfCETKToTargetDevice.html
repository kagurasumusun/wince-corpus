Manual Connection of the CETK to a Target Device

You can manually establish a connection between the CETK and a target device. In Platform Builder, you can add support for the CETK to an OS design before you build the run-time image. For more information, see Adding Support for the CETK to an OS Design in Platform Builder.

For the CETK to communicate successfully with a target device, the port number specified in the CETK application on the development workstation must match the port number specified for the target device. For information about configuring the port number settings, and then starting the Clientside.exe application on the target device, see Configuring the CETK to Communicate with a Target Device.

You can manually add support for the CETK to a target device that has a run-time image without support for the CETK. For more information, see Running the CETK Tool Without the CETK Client in the Run-Time Image.

For information about using Platform Manager to establish a connection instead of manually establishing a connection, see Connecting the CETK to a Target Device by Using Platform Manager.
