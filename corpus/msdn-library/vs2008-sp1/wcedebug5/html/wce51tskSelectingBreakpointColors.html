Selecting Breakpoint Colors

You can select the circle edge color and circle fill color for a breakpoint glyph.

To select colors for breakpoints

  1. From the Tools menu, choose Options, and then choose the Format tab
  2. In the Category box, select Source Windows
  3. In the Colors box, select Breakpoint
  4. In the Foreground and Background boxes, select the colors you want.
