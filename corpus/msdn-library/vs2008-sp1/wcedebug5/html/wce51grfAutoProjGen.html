AutoProjGen

This tool generates a VS project from a number of C# files.

Syntax

AutoProjGen -genui [path] name
AutoProjGen -fixuser userfile
AutoProjGen -addref csdprojfile refname
AutoProjGen -addfile csdprojfile filename
AutoProjGen -vstosources csdprojfile

Parameters

Parameter Description
-genui [path] name Generates UIAL from the directory specifed by name and (optionally) path.
-fixuser userfile Puts path to MobileDevicesDlls into Visual Studios user file specified by userfile.
-addref csdprojfile refName Adds the reference specified by refname into the Visual Studios project file specified by csdprojfile.
-addfile csdprojfile filename Adds the file specified by filename into the Visual Studios project file specified by csdprojfile.
-vstosources csdprojfile Converts the Visual Studios project specified by csdprojfile to sources; also creates makefile.
