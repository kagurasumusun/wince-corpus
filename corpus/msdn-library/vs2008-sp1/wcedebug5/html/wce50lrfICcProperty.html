ICcProperty

The interface provides methods that support Core Connectivity properties.

Methods

The following table shows the methods for the ICcProperty interface.

Method Description
ICcProperty::AddPropertyContainer Enables a property to contain a container, making a hierarchy of properties.
ICcProperty::Value Gets and sets the value stored in a property object.

Requirements

OS Version: Windows 2000, Windows XP Home, Windows XP Pro, Windows Server 2003, and Windows Server 2003 Service Pack 1.
Header: CcDatastore.h.
Link Library: none.
