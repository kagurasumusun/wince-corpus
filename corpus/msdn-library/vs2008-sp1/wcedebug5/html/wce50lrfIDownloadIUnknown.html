IDownload:IUnknown

This interface provides the means to download a run-time image to a target device.

The following table shows this interface's methods.

Method Description
IDownload::DownloadImage Starts the download of a run-time image to a target device.
IDownload::StopDownloadImage Cancels a run-time image download that is in progress.
IDownload::JumpToImage Jumps to a run-time image on a target device.
IDownload::StopJumpToImage Cancels a jump to a run-time image.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Download.h, Download.idl.
