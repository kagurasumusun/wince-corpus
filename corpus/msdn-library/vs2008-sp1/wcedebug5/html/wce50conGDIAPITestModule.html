GDI API Test Module

The GDI API test module, S2_gdi.exe, exercises basic functionality of the graphic device interface (GDI) API, including blitting, drawing, displaying simple text, clipping regions, and creating and deleting objects.

This test module does not require a server.

To run the GDI API test module, GDI must be present in the Windows CE OS. GDI is present on all display-based OSs, but is not present on most headless-based OSs.

To set the random seed for this test module, you can provide the value of the seed following the s2_gdi command.
