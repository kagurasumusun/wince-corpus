Adding a Custom Download Service to the Connectivity Dialog

The Target Device Connectivity Options dialog box contains a drop-down list of available download options. The Core Connectivity infrastructure uses your selection from the Download drop-down list to select which screen the Settings button displays.

For example, if you select an Ethernet Download from the drop-down list and then press Settings, the Ethernet Download Settings dialog box appears.

The Core Connectivity infrastructure obtains the download properties presented to the user from the transport as XML data stored by the Core Connectivity datastore.

When the Platform Builder user opens the Target Device Connectivity Options dialog box and chooses Settings, the following series of events is triggered:

  1. To create the service, the service host calls a query interface for ICcServiceConfigure.
  2. If the call was successful, the service host calls ICcServiceConfigure::Configure with the parent hWnd.
  3. The service host calls ICcServiceConfigure::GetServiceParamsShort to acquire the property values.

    This step returns the string of values that is displayed below the Transport drop-down list on the Target Device Connectivity Options dialog box.
