Publish/Subscribe Interfaces

The following table shows interfaces for the Publish/Subscribe (Pub/Sub) infrastructure.

Interface Description
IPublisher This interface sends control information from a subscriber to a publisher. A publisher implements this interface.
IPublisherManagement This interface obtains, for a subscriber service, buffering settings from a publisher. A publisher implements this interface.
IPublishSubscribeMgr This interface provides a subscriber service that initiates device connections and launches publishers. This interface is the public interface for Pub/Sub.
ISubscriber This interface provides allows a publisher to send information to a subscriber. The application that receives data from a publisher implements this interface.
