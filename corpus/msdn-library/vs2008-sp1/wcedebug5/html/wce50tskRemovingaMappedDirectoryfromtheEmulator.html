Removing a Mapped Directory From the Emulator

If you previously mapped a directory to the Emulator, you can remove the mapping. For information about creating a mapping, see Mapping a Directory to the Emulator.

To remove a mapped directory from the Emulator

  1. In the Emulator window, from the Emulator menu, choose Folder Sharing.
  2. Choose Do not share a folder, and then choose OK.
