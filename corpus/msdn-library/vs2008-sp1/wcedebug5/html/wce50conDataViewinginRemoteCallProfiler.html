Data Viewing in Remote Call Profiler

This section describes how to configure and use the Remote Call Profiler workspace and views.

The Remote Call Profiler viewer displays data from a Remote Call Profiler data (.icp) file.

You can configure Remote Call Profiler trace views to show only the data you are interested in.

You can specify a time segment, thread, or function you want to include in your data set, and then specify the actual and calculated timing values to display in the data grid.

You can view the full set of timing values for an event in the Properties window.

To display profiling information in the Remote Call Profiler viewer, give Remote Call Profiler access to the instrumented executable files and their associated symbol information files. For more information, see Resolving Symbol Names.

The Remote Call Profiler Timeline shows you a graphical summary of the profiling run. For more information about using the Timeline Window, see Timeline Window.

For information about different ways to display data in Remote Call Profiler, see Remote Call Profiler View Windows.
