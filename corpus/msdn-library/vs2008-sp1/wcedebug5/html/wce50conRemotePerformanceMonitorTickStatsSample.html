Remote Performance Monitor TickStats Sample

This sample demonstrates the basic requirements needed to develop a Remote Performance Monitor extension using the Platform Manager APIs.

This is a simple extension that displays the tick count for a target device. This sample consists of two executables:

  • CETickPerf.dll is the in-process server on the desktop computer that initiates the communication to the out-of-process server on the device.
  • TickStatsCE.exe is the out-of-process server on the device that responds to commands sent by CETickPerf.dll.

To use the TickStats sample

  1. In the Sdk\Wce500\Samples\Bin directory in the top-level Platman directory for Platform Manager, register the extension DLL at a command prompt by typing regsvr32 CETickPerf.dll.
  2. In the Sdk\Wce500\Samples\Bin directory in the top-level Platman directory for Platform Manager, register the counter at a command prompt by typing lodctr perfgen.ini.
  3. In the Sdk\Wce500\Samples\Bin directory, in the top-level Platman directory for Platform Manager, run the SamplesReg.vbs script.

    If you have previously executed the SamplesReg.vbs script, it is not necessary to run it again.

    This task needs to be performed once to register the .exe file on the device. This registration allows the DLL on the desktop computer to identify where TimeViewerCE.exe is located.

    Package registration also allows for CPU-specific versions to be installed.
