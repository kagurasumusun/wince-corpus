Core Connectivity Structures

The Core Connectivity infrastructure structures specify information used by the interface methods.

The following table shows the common structures used in the Core Connectivity infrastructure.

Structure Description
FileInfo Specifies the characteristics of a file.
FileVerifyInfo Specifies the properties of a file.
FileVerifyReference Specifies the name and properties of a desktop file that a device file will be checked against.
FileVerifyResult Specifies the output of a file comparison.
FileVerifyVersion Specifies the version information for a file.
SystemInfo Specifies the OS and processor architecture for a target device.

Requirements

OS Versions: Windows CE 5.0.
