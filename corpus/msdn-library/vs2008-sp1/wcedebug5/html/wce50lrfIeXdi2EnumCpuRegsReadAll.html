IeXdi2EnumCpuRegs::ReadAll

This method reads the content values of a set of CPU registers in the current list object.

HRESULT ReadAll(
  [in] DWORD dwCpuNum,
  [out] DWORD *pdwNbRegsInList,
  [out, size_is(,*pdwNbRegsInList)] REGVAL_TYPE** pprvList
);

Parameters

dwCpuNum
CPU number.

This parameter should be 0 if the CPU is not a symmetric multi-processor platform (SMP). Otherwise, assign dwCpuNum a value between 0 and n-1, where n is the CPU number in the SMP system.

pdwNbRegsInList
Number of registers in the list.

pdwNbRegsInList must match the number of elements in the list returned by IeXdi2EnumCpuRegs::GetCount.

pprvList
Pointer to an array of returned values for all registers in the list.

Return Values

The following table shows the return values for this method.

Value Description
S_OK Indicates the function was successful.
E_FAIL Indicates an unspecified failure.
EXDI_E_COMMUNICATION Indicates a communication error between host driver and debugging target.

Requirements

OS Version: Windows CE 5.0 and later.
Header: eXDI2.h.
Link Library: ole32.lib, oleaut32.lib.
