Modifying Chart Options

You can select the type of chart displayed, the update frequency, and the chart scale.

To modify chart options

  1. From the Options menu, choose Chart.
  2. Select the check box next to each item you want to display on the chart.
  3. Under Gallery, choose Graph or Histogram as the format for the display.
  4. In the Vertical Maximum box, type the maximum value that the vertical axis should extend to.
  5. Under Update Time, choose Manual Update or Periodic Update.
  6. Optional. If you choose Periodic Update, in the Interval box type a number to specify the length of time, in seconds, between chart updates.
  7. Choose OK.
