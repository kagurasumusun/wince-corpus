_WriteLocalLog

This function sends a debug message to the .log file for Cescript.exe.

void _WriteLocalLog(
  BSTR string
);

Parameters

string
Text of message to send.

Remarks

You can call this function from a script that Cescript.exe executes.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
