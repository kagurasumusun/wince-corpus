Displaying Heap Information for a Process

You can view the heap information for processes on a target device.

To display heap information for a process list

  1. From the Window menu, choose Process_List.

    For information about opening a Process_List window, see Displaying a Process List.

  2. In the Process_List window, select a process.
  3. From the File menu, choose Heap List.

    The Heap_List window displays heap information for the process identifier corresponding to the process you selected.
