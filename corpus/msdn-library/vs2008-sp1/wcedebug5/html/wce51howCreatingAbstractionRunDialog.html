Creating an Abstraction (Run Dialog)

This section and the next detail how to set up a Dialog abstraction class from scratch and invoke it from a simple test case. To skip these sections and look at the result, simply open the RunDialogSample.sln solution file from C:\MtkKit\RunDialogSample.

  1. Start by creating a copy of the TuxNetSkeleton project directory and renaming it to MyDemo. This is your working project directory.
  2. Bring up the Run Dialog
    1. From the Today screen, while holding Action (or Control on the DEVICEEMULATOR), Tap and Hold on the taskbar clock.
    2. From the menu that appears, Select Run
  3. Generate the RCML
    1. Run the Command Window shortcut under c:\MtkKit.
    2. Run the following command:
      rapistart \test\rcmlsnap
    3. After a while (maybe a minute) a dialog box should appear indicating the filename of the RCML generated. Click OK.
    4. A BMP file of this window will also be generated. These files will be placed at the root of your device.
  4. Update the RCML
    1. Move the .RCML file just generated and the associated BMP file to your working project directory (c:\mtkkit\MyDemo) using ActiveSync.
    2. Edit this .RCML file to look like c:\MtkKit\RunDialogSample\RunDialog.rcml
      This includes editing various attributes, such as DIRECTORY and FRIENDLYNAME attributes.
  5. Generate Code from the RCML
    1. In your command window cd into your working project directory
    2. Run the following command:
      rctocs -dll shell32.exe -rcml . -o
    3. Open your sample solution (c:\mtkkit\MyDemo\TuxNetSkeleton.sln).
    4. Add any .cs files generated to your working project in VS.
      1. Make sure you add it to your TuxNetSkeleton project, not to TuxNet.
      2. Never edit RunDialog.cs; edit the RCML file and regenerate rundialog.cs instead.
