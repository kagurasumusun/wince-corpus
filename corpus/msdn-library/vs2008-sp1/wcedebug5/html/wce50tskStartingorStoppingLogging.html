Starting or Stopping Logging

You can start or stop logging at any point.

To start or stop logging

  1. From the Options menu, choose Log.
  2. If Start Log is not enabled, type a name in the File Name box and add objects to log.

    - or -

    If Start Log is enabled, choose Start Log.

  3. Choose Stop Log to stop logging.
