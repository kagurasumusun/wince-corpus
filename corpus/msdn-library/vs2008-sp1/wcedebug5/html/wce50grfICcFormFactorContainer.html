ICcFormFactorContainer

This interface provides methods that support collections of ICcFormFactor objects stored for each target device.

Methods

All datastore interfaces inherit the methods for the IUnknown and ICcObject interface.

Requirements

OS Version: Windows 2000, Windows XP Home, Windows XP Pro, Windows Server 2003, and Windows Server 2003 Service Pack 1.
Header: CcDatastore.h.
Link Library: none.
