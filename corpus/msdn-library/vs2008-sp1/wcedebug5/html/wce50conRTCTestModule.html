Real-time Communications Test Module

The Real-time Communications (RTC) test module, S_rtcim.dll, requires a network connection to another Windows CE–based device that is also running the Windows CE Stress tool. The test module uses the server name specified in the Test Server Name box to establish communications with the other Windows CE–based device. For more information about options, see Options for the Windows CE Stress Tool.

The S_rtcserv.dll server module must be part of the module mix for each Windows CE–based device that participates in the test. For information about module mixes, see Creating and Modifying a Module Mix for the Windows CE Stress Tool.
