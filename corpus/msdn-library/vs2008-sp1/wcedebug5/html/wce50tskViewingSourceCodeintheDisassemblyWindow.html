Viewing Source Code in the Disassembly Window

You can view source code in the Disassembly window.

To view source code in the Disassembly window

  1. Start debugging and then wait for the debugger to stop at a breakpoint.
  2. From the View menu, choose Debug Windows and then choose Disassembly.
