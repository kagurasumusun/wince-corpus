IeXDI2 Structures

The following table shows the data structures defined for the eXDI interfaces.

Structure Description
ADDRESS_RANGE Defines an address range in memory.
BREAKPOINT_SUPPORT_TYPE2 Defines breakpoint-supported capabilities.
CODE_BP_TYPE Defines code breakpoint attributes.
CPU_REG_STRUCT Specifies a CPU register.
DATA_BP_TYPE Defines data breakpoint attributes.
DEBUG_ACCESS_CAPABILITIES_STRUCT2 Defines the debugging capabilities of the target device CPU and probe.
EXCEPTION_TYPE2 Specifies an exception.
GLOBAL_TARGET_INFO_STRUCT2 Specifies processor information about the target device.
HALT_REASON_TYPE2 Defines types of reasons to halt execution.
MEM_ACCESS_EXCLUSION_RANGE Defines an address range with an associated access restriction.
MEMMAP_DESCRIPTION_TYPE Defines the type of memory map.
MISC_EXDIACESS_SERVICE_INFO Specifies pointers for the eXDI service and for the probe handler.
