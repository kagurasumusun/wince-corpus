Test Results Tab

On the Test Results tab in the Server Settings dialog box, you can configure settings that affect how the CETK stores test results. For more information about the Server Settings dialog box, see Server Settings Dialog Box.

Folder in which to store the results of a test
Path to the directory on the development workstation where the results of CETK tests are to be stored.
Open Results Folder
Displays the contents of the directory where the results of CETK tests are to be stored.
Empty Results Folder
Deletes .log, .cab, .xml, and .xslt files and empty subdirectories from the directory where the results of CETK tests are to be stored.
Consolidate test results into a cabinet (.cab) file after tests complete
If selected, the results of CETK tests from a session of testing are consolidated into a .cab file when the last test in the session completes.
Encrypt test results
If selected, the results of CETK tests are encrypted.
OK
Saves changes to the settings for the CETK server and closes the dialog box.
Cancel
Closes the dialog box without saving changes.
Apply
Saves changes to the settings for the CETK server and leaves the dialog box open.
