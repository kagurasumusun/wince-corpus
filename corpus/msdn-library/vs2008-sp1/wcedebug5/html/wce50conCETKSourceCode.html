Source Code for CETK Tests

You can install source code for the tests that ship with the CETK. Microsoft provides source code to help you debug your device drivers and create custom tests for the CETK. However, you cannot build some of the source code, and source code for some tests is not provided.

You can install source code for CETK tests by installing Windows CE Shared Source from the Setup wizard for Windows CE. For more information, see Installing Windows CE with Shared Source Code.

For information about building CETK source code, see Building CETK Source Code.

If you use the source code to create a custom test, you can add it to the CETK. For more information about adding a custom test, see Adding a Custom Test to the CETK.
