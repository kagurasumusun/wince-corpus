Creating a Suite of Tests

With the Test Suite Editor, you can create and manage test suites for the CETK. A test suite is a selection of tests that is stored by the CETK and can be applied to any target device in the CETK window.

In the Test Suite Editor dialog box, you can create a test suite that contains tests that you want to run. Rather than selecting each test on a target device, you can simply apply the test suite to the target device to automatically select the tests that you selected in the Test Suite Editor dialog box.

To create a suite of tests

  1. From the Tests menu, choose Suite Editor.
  2. From the Test Kit box, choose the test kit for which you want to create a test suite.

    For more information about test kits, see Test Kits in the CETK.

  3. Choose New.
  4. Type a name for the test suite that you want to create, and then choose OK.
  5. In the Tests box, select the check box next to each test that you want to include in the test suite and clear the check box next to each test that you want to exclude from the test suite.
  6. Choose OK.

To apply a test suite to a target device

  1. For the target device, make active the test kit to which you want to apply a test suite.

    You can apply a test suite only to the test kit for which you created the test suite. For information about making active a test kit, see Choosing the Active Test Kit for a Target Device Connected to the CETK.

  2. Right-click on the active test kit in the CETK window, choose Test Suites, and then choose Apply Suite.
  3. In the Suite box, choose the test suite that you want to apply.
  4. Choose OK.

If you have multiple development workstations, you might find it helpful to export the information stored in one or more test suites to a file. You can then copy the file from one development workstation to another and import the information for the test suite or suites.

To export a test suite or suites to a file

  1. From the Tests menu, choose Export Test Suite.
  2. In the Test Kit box, choose the test kit that contains the test suite that you want to export.
  3. From the Test suites list, select the test suite or suites that you want to export.
  4. In the Export the test suite information to this file (*.TKS) box, type the path and name of the file to which to export the test suite or suites.

    - or -

    Choose Browse, navigate to the file to which to export the test suite or suites, and then choose Open.

  5. Choose OK.

To import a test suite

  1. From the Tests menu, choose Import Test Suite.
  2. Navigate to the Test Kit Suite (.tks) file that you want to import.
  3. Choose Open.
