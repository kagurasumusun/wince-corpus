FRAME_TYPE

This structure defines a frame pointer.

typedef struct _FRAME_TYPE {
  ADDRESS_TYPE addrFP;
  ADDRESS_TYPE addrPC;
  DWORD dwParam1;
  DWORD dwParam2;
  DWORD dwParam3;
  DWORD dwParam4;
} FRAME_TYPE;

Members

addrFP
Address of frame pointer, if applicable.
addrPC
Address of program counter.
dwParam1
First parameter.
dwParam2
Second parameter.
dwParam3
Third parameter.
dwParam4
Fourth parameter.

Requirements

OS Version: Windows CE 5.0 and later.
Header: OsAccess.h.
Link Library: OSAXSC.lib.
