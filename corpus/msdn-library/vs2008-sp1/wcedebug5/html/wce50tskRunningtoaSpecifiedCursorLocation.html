Running to a Specified Cursor Location

You can have a program run until the cursor reaches a specified location.

To run to a specified cursor location

  • Right-click a line in the Call Stack window and then choose Run to Cursor from the shortcut menu.

    The new location is marked with a yellow arrow in the Call Stack window and either the source window or the Disassembly window.
