Socket Test Module

The socket test module, Wsx_bind.exe, creates, binds, and then closes sockets simultaneously on multiple threads. This test module exercises the Winsock layer and the underlying Winsock providers. You can run this test module on both Internet Protocol version 6 (IPv6) and Internet Protocol version 4 (IPv4).

This test module does not require a server.

The following table shows the command-line option for the Wsx_bind.exe test module.

Command-line option Description 
-w
 Time, in milliseconds (ms), to wait between binds. You can use this option to reduce the chance that multiple, concurrent bind tests interfere with one another. You can also use this option to prevent the test module from cycling through ports too quickly.
