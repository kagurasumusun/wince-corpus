TestProc Messages

The following table shows the TestProc messages for Tux.

Programming element Description
TPM_EXECUTE This message is sent to the TestProc function each time Tux asks the function to execute its test code.
TPM_QUERY_THREAD_COUNT This message is sent once to the TestProc function to query the default number of threads that need to be created to execute the test.
