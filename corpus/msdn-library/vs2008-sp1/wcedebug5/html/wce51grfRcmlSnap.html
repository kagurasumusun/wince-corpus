Platform Builder for Microsoft Windows CE 5.0  

RcmlSnap

This tool generates RCML based on the top-level window currently displayed on a device.

Syntax

RcmlSnap [-filename filename] [-appname appname] [-ancestry ancestry]

Parameters

Parameter Description
-filename filename Optional. Specify the name used for the generated RCML file
-appname appname Optional. Specify the friendly name of your application
-ancestry ancestry Optional. This is a measure of how far up the tree you wish to generate rcml. If you have need of this option you will probably want to use a predefined setting:
  • InnermostAncestry (the default) will generate rcml for the innermost Dialog and all of its non-dialog children.
  • OutermostAncestry will generate rcml for the outermost top level window and all of its non-dialog children.
  • EntireTree will generate rcml for the outermost top level window and all of its children.

An ancestry value of 0 refers to the innermost visible dialog.

A value of 1 refers to the parent of the innermost dialog.

A value of 2 refers to the grandparent of the innermost dialog.

Remarks

  • This tool snaps a top-level window on the device and outputs the RCML to represent it.
  • BuildManaged should put this into your release directory for you.
  • On a device or emulator connected to Platform Builder, navigate to the screen you want RCML for.
  • In the PB command window type "s rcmlsnap"
  • Depending on the complexity of your UI, executing this command will take about 10 to 30 seconds. Don't touch the UI during the time. When it finishes, you will see a message box telling you the name of the UIAL file that was saved.
  • The location in the message box tells where the file was saved. This is the RCML for that screen. An image of the screen snapped will appear in the same location with the same name, but an extension of .bmp.
  • Add an IdnHolder class to IdnHolders.cs for your new Dialog class.
