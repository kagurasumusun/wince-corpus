Direct3D Mobile Test Module

The Direct3D Mobile test module, S2_d3d.dll, exercises a Microsoft® Direct3D® Mobile driver by rendering rotating cubes with vertices that are assigned various colors. The test module uses line lists, triangle strips, triangle lists, and triangle fans to create the cubes. The test module randomly sets the rotation speed of the cubes. The test module uses the D3DMTS_WORLD, D3DMTS_VIEW, and D3DMTS_PROJECTION transforms.

The Direct3D Mobile test module does not require a server and does not accept any command-line options. However, this test module does require a Direct3D Mobile driver.
