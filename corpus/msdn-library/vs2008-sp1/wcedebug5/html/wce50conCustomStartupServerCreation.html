Platform Builder for Microsoft Windows CE 5.0  

Custom Startup Server Creation

You can create a custom startup server for Platform Manager. The Server.idl file in the Sdk\Wce420\Platman\Include directory under the top-level Platman directory of Platform Manager provides the interfaces required to create a custom startup server.
