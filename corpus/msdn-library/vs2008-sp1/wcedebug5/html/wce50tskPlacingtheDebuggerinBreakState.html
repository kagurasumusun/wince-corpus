Breaking Execution

You can place the debugger in a break state at any point.

To place the debugger in a break state

  1. From the Debug menu, choose Break.
  2. Do one of the following:
    • Select the path to the source file and then choose OK.

      You can now do source-level debugging.

    • Choose Cancel to see the disassembly code.
