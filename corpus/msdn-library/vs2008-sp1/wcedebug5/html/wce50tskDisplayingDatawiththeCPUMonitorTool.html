Displaying Data with the CPU Monitor Tool

You can modify the format in which the CPU Monitor tool displays data from the target device.

To display or hide the data table

  • In the CPU Monitor for Windows CE window, from the View menu, choose Show Data Table.

    The data table appears if it was hidden, and disappears if it was displayed. When the table is hidden, the CPU Monitor tool continues to collect data from the target device.

To temporarily not display data points in the data table

  • In the CPU Monitor for Windows CE window, from the View menu, choose Pause Data Table.

    Entries are not added to the table, but data received from the target device is still saved into memory.
