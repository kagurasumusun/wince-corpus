Running CETK Tests

After you select the tests that you want to run on a target device in the CETK window, you are ready to launch the tests on the target device.

Note   When you run a test, the CETK copies files to the root directory of the target device. The size of the files copied to the target device varies by test. To run a test, you must allocate sufficient free space in the root directory of the target device to accommodate the files that are copied to the target device. For more information about the size of the files copied to the target device by each test, see the test-specific information for each of the CETK Tests.

The following procedure shows how to run the tests that you selected. After you launch the tests, the tests run automatically and sequentially.

To run selected tests on your target device

  • Right-click on the test kit that is active for the target device, and then choose Start Tests.

    - or –

    From the Tests menu, choose Start/Stop tests, and then choose the target device.

You can also run a single test on a target device without running other tests that are selected for the target device. The following procedure shows how to run a single test.

To run a test on a target device without running other selected tests

  • Right-click on the test, and then choose Quick Start.

Many of the tests prompt you to complete an action on the target device. Follow the instructions on the display of the target device to complete the tests. For more information about each test, see CETK Tests.
