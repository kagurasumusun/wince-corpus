Remote Call Profiler Data Collection API Reference

With the Remote Call Profiler data collection API, you can programmatically control where in your code Remote Call Profiler collects data.

For more information, see Adding a Data Control Function to a Module. For information about each of the data collection functions, see Remote Call Profiler Data Collection Functions.

In contrast to the Collection Control window, with the Remote Call Profiler API you can specify precisely the locations in your application where you want to start or stop profiling.

You can mark sections of the logging stream and name processes and threads for easier identification in the Remote Call Profiler views.
