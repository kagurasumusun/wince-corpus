Datastore Error Codes

In addition to the return codes defined individually for the methods of the Core Connectivity datastore interfaces, datastore interface methods can return one or more common datastore errors.

The following errors can be returned by many datastore interface methods, and are thus not documented with each individual method.

Error Win32 value Description
E_DATASTORE_TYPEERROR 0x0500 Incorrect data type.
E_DATASTORE_FORMAT 0x0501 Incorrect format
E_DATASTORE_RESOURCEERROR 0x0502 Indicates a requested resource is unavailable.
E_DATASTORE_DATASYNCERROR 0x0503 Indicates a problem with data synchronization.
E_DATASTORE_KERNELOBJECTERROR 0x0504 An unknown object was requested.
E_DATASTORE_EVENTLOGERROR 0x0505 Indicates the event log could not be written.
E_DATASTORE_SCHEMAFILENOTFOUND 0x0506 Indicates the schema file was not found.
E_DATASTORE_LANGUAGEFILEERROR 0x0507 Indicates a language file error.
E_DATASTORE_REGISTRYACCESS 0x0508 Indicates the registry could not be accessed.
E_DATASTORE_PROTECTED 0x0509 Indicates the requested value is protected.
E_DATASTORE_PROPERTYCONTAINER 0x050a Indicates the method encountered a PropertyContainer.
E_DATASTORE_UNEXPECTED 0x050b Indicates an unexpected datastore error.
E_DATASTORE_HASHERROR 0x050c Indicates a hash error.
E_DATASTORE_UNIQUENESS 0x050d Indicates a requested value assignment is not unique.
