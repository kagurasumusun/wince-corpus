Platform Builder for Microsoft Windows CE 5.0  

Parallel Port Test

The Parallel Port Test analyzes the functionality of the application programming interface (API) set for a parallel port driver for Microsoft® Windows® CE.

The following table shows the hardware requirements for the Parallel Port Test.

Requirements Description
PCL printer A Printer Control Language (PCL) printer attached to the parallel port of the Windows CE-based device.

The following table shows the software requirements for the Parallel Port Test.

Requirements Description
Tux.exe Tux test harness, which is required for executing the test.
Kato.dll Kato logging engine, which is required for logging test data.
Tooltalk.dll Application required by Tux.exe and Kato.dll. Handles the transport between the target device and the development workstation.
Partest.dll Test .dll file.
Note   When you run the Parallel Port Test, the CETK temporarily copies files to the root directory of the target device. Before running the test, verify that there is at least 0.4 megabytes (MB) of free space in the root directory of the target device. If there is not sufficient space in the root directory of the target device, the test cannot run.
