Platform Builder for Microsoft Windows CE 5.0  

Test Suite Name Dialog Box

In this dialog box, you can name a new test suite or modify the name of an existing test suite.

Enter the name of the suite
Name of the test suite.
OK
Creates a new test suite or saves changes to the name of an existing test suite, and then closes the dialog box.
Cancel
Closes the dialog box and discards any changes.
