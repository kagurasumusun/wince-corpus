IeXdi2OleEvents::AuthorizeTargetRestartOle

This method requests client authorization to restart a debugging target.

HRESULT AuthorizeTargetRestartOle(
  VARIANT* pfContinue,
  VARIANT* pdwRetryDelayMs
);

Parameters

pfContinue
[out] If VARIANT_TRUE, this value indicates the client accepted the request to restart the debugging target.
pdwRetryDelayMs
[out] Minimum delay before issuing another restart query, in milliseconds.

Return Values

Returns S_OK if successful.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: exdi2.h.
Link Library: ole32.lib, oleaut32.lib.
