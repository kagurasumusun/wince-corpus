GenFinder

This tool determines the Datk.WindowFinder object that should be used to locate a specific control on a device. When you have generated the UIAL project and are ready to start working on the self-test you will most likely get DatkExceptions thrown because some of your dialogs and controls can not be found. This is because the WindowFinder generated by RCTOCS is not properly configured for this control. GenFinder is a tool that can be used to discover how the WindowFinder should be configured to correctly find the control. Make sure you have the proper files in your release directory:

  • Make sure that WINCEREL=1 and _FLATRELEASEDIR is set correctly and run BuildManaged from your build window
  • Build in private\qaapps\qatools\GenFinder\

Locate the control that is causing the exception using PSPY (type pspy in your build window to bring up this tool). In the PB command window type "s GenFinder hwnd" where hwnd is found using pspy in the step above (example: "s GenFinder 0x7c012220"). After a few seconds, you will find the output in generatedFinder.txt in your release directory. Copy and paste the code from this file into the UIAL and find/replace to change the name of the WindowFinder to match the one that was failing before.
