IeXdi2OleAutoServer::GetMemMapName

This method returns a memory map name from an index in the list of memory maps.

HRESULT GetMemMapName(
  VARIANT dwListIndex,
  VARIANT* vtpbstrMemMapName
);

Parameters

dwListIndex
[in] Index of the memory map in the table of MEMMAP_DESCRIPTION_TYPE elements that associate memory map ID, name, size, and possible access width.
vtpbstrMemMapName
[out, retval] Name of memory map associated with the given index.

Return Values

The following table shows return values for this method.

Value Description
S_OK Indicates the function was successful.
E_FAIL Indicates an unspecified failure.
E_NOTIMPL Indicates the memory map is not implemented.
EXDI_E_COMMUNICATION Indicates a communication error between host driver and debugging target.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: exdi2.h.
Link Library: ole32.lib, oleaut32.lib.
