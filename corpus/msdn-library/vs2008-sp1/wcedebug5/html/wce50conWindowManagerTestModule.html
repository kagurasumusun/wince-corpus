Window Manager Test Module

The window manager test module, S2_winmgr.exe, randomly creates a variety of windows in different threads with random parent and child and owner and owned window relationships. The test module exercises the window manager API.

This test module does not require a server.

To set the random seed for this test module, you can provide the value of the seed following the s2_winmgr command.
