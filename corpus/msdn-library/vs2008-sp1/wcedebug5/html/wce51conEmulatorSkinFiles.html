Emulator Skin Files

An Emulator skin consists of up to three bitmap (.bmp) files and a single skin definition (.xml) file that contains Extensible Markup Language (XML). You place the skin definition file and the associated .bmp files in one directory.

Create a separate directory for each Emulator skin. Each directory that contains an .xml file and .bmp files for an Emulator skin must contain no other files. For information about the sample Emulator skin files provided with Platform Manager, see Emulator Skin Samples.

The following table shows a description of each .bmp file for an Emulator skin.

Bitmap (.bmp) file Required Description
Normal art Yes Shows the default appearance of the Emulator skin.
Down art No Shows the appearance of the Emulator skin with all buttons pressed.
Mapping No Shows a color code for each button in the Emulator skin.

The mapping file represents the color code for each button as a single-color area that completely covers the button. The colors that you use for the single-color areas in the mapping file are not visible in the Emulator skin.

The .xml file describes how the skin works and where to find the .bmp files. The .xml file also defines button actions based on the color code shown in the mapping file. For more information about the skin definition file, see Emulator Skin XML Schema.
