Logging

The Area Libraries should be primarily responsible for detailed logging since they are responsible for most of the UI work. Additional verbose logging that is not covered by the area library (such as the purpose of a test) should be added to the test cases themselves.

Both the Area Libraries and test cases should use the GlobalLogger for all logging needs. The GlobalLogger will ensure that all comments logged go to the correct log file. You can use GlobalLogger.AddComment to add to the log file.

You can use verbose logging to control how much the harness actually writes to the log file. To do this you call GlobalLogger.AddComment and pass it in an integer specifying the logLevel of your comment. The higher the number, the more detailed the comment. Then, you can run your test by passing the –logLevel parameter to the harness. For example, if you pass -logLevel 4 to the harness, all comments that were added with a logLevel of 4 or less will be added to the log file. All comments added with a logLevel of 5 or greater will be excluded from the log file.

There are predefined logging levels that you will likely want to use in your code. The example below shows how these predefined levels are used, and which levels are appropriate for test cases, area library methods, UIAL methods, and automation infrastructure.

/// <summary>
/// Test cases always want logging, so they generally use the
/// Summary level (lowest level) which is always logged.
/// </summary>
public void TestCaseMethod()
{
      // This will always be logged
      GlobalLogger.AddComment(
            GlobalLogger.VerboseLevel.Summary, "Test case");

      // This will also always be logged
      GlobalLogger.AddComment("Test case comment");
}

/// <summary>
/// Area libraries don't always need logging. You might want
/// to use the Info level (second lowest level).
/// </summary>
public void AreaLibraryMethod()
{
      GlobalLogger.AddComment(
            GlobalLogger.VerboseLevel.Info, "Area library");
}

/// <summary>
/// The UIAL doesn't usually need to log, so you might want to
/// use the Detailed level (third lowest level).
/// </summary>
public void UialMethod()
{
      GlobalLogger.AddComment(
            GlobalLogger.VerboseLevel.Detailed, "UIAL comment");
}

/// <summary>
/// Infrastructure like DATK, MobilityToolKit, and Utils should
/// only log when they are being debugged so they will generally
/// use the Debug level (fourth lowest level).
/// </summary>
public void MobilityToolKitMethod()
{
      GlobalLogger.AddComment(
            GlobalLogger.VerboseLevel.Debug, "MTK comment");
}
