Platform Builder for Microsoft Windows CE 5.0  

SpRcmlGen

This tool generates RCML for Smartphone CPL dialogs.

Syntax

SpRcmlGen [-c] [-d destinationFile] [-s sourceFile]

Parameters

Parameter Description
-c Optional. Forces output to console.
-d destinationFile Optional. Specifies destination file name.
-s sourceFile Optional. Specifies source file name.

Remarks

This tool will create an RCML file based on a XML file that defines a CPL (ex. %_WINCEROOT%\public\smartfon\oak\file\home.cpl.xml). The tools should be available in your path (it is checked into private\mdd\bin\i386). The resulting RCML generated may have to be hand modified to accurately match the CPL.
