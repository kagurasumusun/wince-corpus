Mobile Devices Automation Framework Overview

This documentation provides a high level overview of the Mobile Devices Automation Framework.

This framework is made primarily of .Net class libraries used to automate interaction with the device UI. These class libraries are broken out into separate layers with differing purposes. The layers are shown in the diagram below, which illustrates how the different pieces are built on top of one another:

The two pieces below the dashed line, Logging and Utils.Net, can be used by all of the other components. Tux.Net, not shown in the diagram, simply executes code from the test suites, but is built primarily on Logging and Utils.Net components.
