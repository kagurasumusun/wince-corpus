Sorting Data in the Butterfly View

The Butterfly view windows presents the relationship between calling and called functions in a tabular format.

To sort data in the Butterfly view

  1. In the Butterfly pane, choose Sort by Application to sort functions by the total application inclusive time or counter value of each function.

    - or -

    In the Butterfly pane, choose Sort By Elapsed to sort functions by the total elapsed inclusive time or counter value of each function.

  2. Choose Counter: Time to sort by CPU cycles.

    - or -

    Choose the name of a user-defined counter.
