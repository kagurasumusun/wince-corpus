IeXdi2DataBp

This interface contains methods that provide access to exdi driver-generated data breakpoint objects.

Methods

The following table shows the methods defined in the IeXdi2DataBp interface.

Method Description
IeXdi2DataBp::GetAttributes Retrieves the characteristics of a data breakpoint.
IeXdi2DataBp::LockChanges Locks a breakpoint to prevent changes or unlocks a locked breakpoint to allow changes.
IeXdi2DataBp::SetState Enables or disables breakpoints.

Requirements

OS Version: Windows CE 5.0 and later.
Header: exdi2.h.
Link Library: ole32.lib, oleaut32.lib.
