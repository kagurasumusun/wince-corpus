Export Test Suite Dialog Box

In this dialog box, you can export one or more test suites to a file.

Test Kit
Name of the test kit that contains the test suite you want to export.
Test suites
Test suites that you select from this list are exported. To simultaneously select more than one suite, press and hold the CTRL key while you select test suites.
Export the test suite information to this file (*.TKS)
Path to a .tks file where to export the selected test suites.
OK
Exports the test suite information and closes the dialog box.
Cancel
Closes the dialog box without exporting test suite information.
