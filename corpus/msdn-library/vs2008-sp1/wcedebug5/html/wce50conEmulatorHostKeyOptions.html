Emulator Host Key Options

Before you download a run-time image to the Emulator, you can specify a host key. You include the host key in each key combination where you want the Emulator to recognize that you are sending keystrokes to it. For information about the key combinations that the Emulator recognizes, see Emulator Key Combinations.

From the command line, use the /Hostkey command-line option to specify a host key. For more information about command-line options for the Emulator, see Emulator Command-Line Launch Options.
