Customizing a Skin for the Emulator

  1. Create a .bmp file that shows the default appearance of the Emulator skin.
  2. Create a .bmp file that shows the appearance of the Emulator skin with all buttons pressed.
  3. Create a .bmp file that shows the area of each button filled with a single unique color.

    If you want the appearance of each button to change independently of the other buttons in the Emulator skin, use a different color to fill the area for each button. It is recommended that you do not use white or black to fill this area. For more information about the .bmp files in an Emulator skin, see Emulator Skin Files.

  4. Create an .xml file.

    For information about the XML schema for the .xml file, see Emulator Skin XML Schema.

  5. Save the three .bmp files and the .xml file to a single directory.
  6. Download a run-time image to the Emulator and type the path and file name of the .xml file in the Emulator skin box.
