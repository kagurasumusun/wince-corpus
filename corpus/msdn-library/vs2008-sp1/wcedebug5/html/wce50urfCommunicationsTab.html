Communications Tab

On the Communications tab in the Server Settings dialog box, you can configure settings that affect communication between the CETK server and a target device. For more information about the Server Settings dialog box, see Server Settings Dialog Box.

Port to use to connect to a target device
Port that the CETK server uses to communicate with a Windows CE–based device. To successfully communicate with the target device, the port number must match the port number for Clientside.exe on the target device. For more information, see Configuring the CETK to Communicate with a Target Device.
Disconnect timeout in seconds
Number of seconds to wait for a response from the target device before showing the target device as disconnected. You can specify a value between 5 and 99,999 seconds.
OK
Saves changes to the settings for the CETK server and closes the dialog box.
Cancel
Closes the dialog box without saving changes.
Apply
Saves changes to the settings for the CETK server and leaves the dialog box open.
