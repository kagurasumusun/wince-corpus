Viewing Test Results from the Application Verifier Tool

After you test an application with the Application Verifier tool, you can view the results of the test from the Windows CE Application Verifier window. For information about testing an application with Application Verifier, see Testing an Application with the Application Verifier Tool.

To view test results from Application Verifier

  1. In the Windows CE Application Verifier window, choose Get Logs to copy test results from the target device to the development workstation.
  2. Choose View Exported Log.
  3. Select the .log file that contains the test results that you want to view, and then choose Open.
Note   Application Verifier uses a VerifierLog_<ProcessName>_<ProcessIdentifier>.log naming convention to assign the name to each .log file that the tool generates. You can use this naming convention to identify the .log file that contains the test results that you want to view.
