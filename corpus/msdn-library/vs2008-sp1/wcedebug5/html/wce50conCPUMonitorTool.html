Platform Builder for Microsoft Windows CE 5.0  

CPU Monitor Tool

The CPU Monitor tool shows you the CPU and memory usage of a Microsoft® Windows® CE–based device in the CPU Monitor for Windows CE window. The target device sends data through a network connection to the development workstation. The development workstation logs and displays the data in a graph and a list in the CPU Monitor for Windows CE window.

Note   The CPU Monitor tool receives data on port 8000 of the development workstation. You cannot change the port number over which the CPU Monitor tool receives data.
