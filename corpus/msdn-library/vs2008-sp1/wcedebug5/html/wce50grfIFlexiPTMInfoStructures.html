IFlexiPTMInfo Structures

The following table shows the data structures defined in the FlexiPMTInfo interface.

Structure Description
FLEXI_GETDATA_TYPE Defines the type of data defined in the associated PTM_RAW_DATA structure.
PTM_FIELD_DESC Describes a single field in an array of process, thread, or module values.
PTM_RAW_DATA Describes an array of values indexed by order of appearance in the description table.

Requirements

OS Version: Windows CE 5.0 and later.
Header: FlexiPMTInfo.h.
