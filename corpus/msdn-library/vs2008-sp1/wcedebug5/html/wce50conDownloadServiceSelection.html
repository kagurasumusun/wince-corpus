Platform Builder for Microsoft Windows CE 5.0  

Download Service Selection

A download service provides a way to download a run-time image to a target device. You can use the download services included with Platform Builder or write your own download service. The default download services provided with Platform Builder assume that your target device boots from a boot loader image.

Platform Builder provides the following download services by default:

  • Device Emulator Download Service
  • Ethernet Download Service
  • Serial Download Service
