Platform Builder for Microsoft Windows CE 5.0  

Tux and Tux.Net Test Harnesses

The Windows CE Test Kit includes two test harnesses: Tux Test Harness and Tux.Net Test Harness.

Tux Test Harness
Tux is a 32-bit client/server test harness that runs test files stored as classes in a dll.
Tux.Net Test Harness
Tux.Net is a managed test harness that runs test files written in C# and other managed code.
