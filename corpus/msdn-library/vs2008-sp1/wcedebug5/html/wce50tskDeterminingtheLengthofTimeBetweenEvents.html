Determining the Length of Time Between Events

You can use the Kernel Tracker ruler to determine time.

To determine the length of time between events

  1. In the ruler bar, right-click directly above an event and then choose Set Time Marker 1.
  2. If necessary, scroll to another event.
  3. In the ruler bar, right-click directly above the event and then choose Set Time Marker 2.
  4. In the lower right corner of the Remote Kernel Tracker UI, look at the numerical value adjacent to Marker Time Delta.

    Remote Kernel Tracker computes the length of time between marked events and displays it as the Marker Time Delta.
