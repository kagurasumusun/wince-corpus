Error 2020: Suspect Counter Values

Some user-defined counter values cannot be synchronized across multiple microprocessors, and so the elapsed time cannot be calculated reliably.

When this is the case, the elapsed time totals in Remote Call Profiler views are truncated to be the same as the application time.

Suspect counter values will be discarded for unsynchronized user counter.
