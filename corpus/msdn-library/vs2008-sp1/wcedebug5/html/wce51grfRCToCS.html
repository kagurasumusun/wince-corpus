Platform Builder for Microsoft Windows CE 5.0  

RCToCS

This tool generates UIAL Dialog classes based on RCML files that have been decorated with specific tags.

Syntax

rctocs –dll dllName –rcml rcmlDirectory [-o automationRoot] [-a app] [-id dialogID] [-n] [-p projectName] [-update]

Parameters

Parameter Description
–dll dllName Required. Specify the dll containing app resources (i.e. IdnStrings). This is used to look up the default dialog resource string.
–rcml rcmlDirectory Required. Specify the directory where rcml files are found.
-o automationRoot Recommended. Specify the location of the automation directory. The generated files will be put under this root.
-a app Optional. Specify the name of the application (i.e. POutlook).
-id dialogID Optional. Specify the name (no extension) of a single rcml file to use. If you do not specify an id all available rcml files are used.
-n Optional. Lists files that would be touched, but no files are changed.
-p projectName Optional. Specify the name of the project (i.e. PocketPC or SmartPhone).
-update Optional. Update Only. Will not create new dialog files from scratch.

Recommended Usage

rctocs -dll <dll> -rcml . -o %_WINCEROOT%\private\qaapps\automation

Examples

rctocs -dll cplmain.cpl -rcml . -p SmartPhone
rctocs -dll cplmain.cpl -rcml . -p PocketPC
rctocs -dll outres.dll -rcml . -p PocketPC -a POutlook
rctocs -dll outres.dll -rcml . -id 18031
rctocs -dll outres.dll -rcml . -update
rctocs -dll outres.dll -rcml . -o %_WINCEROOT%\private\qaapps\automation
