IeXdi2EnumDataBp::Clone

This method copies the enumerated list of data breakpoints.

HRESULT Clone(
  IeXdi2EnumDataBp** ppieXdi2EnumDataBp
);

Parameters

ppieXdi2EnumDataBp
[out] Copy of this enumerator.

Return Values

The following table shows return values for this method.

Value Description
S_OK Indicates the function was successful.
E_FAIL Indicates an unspecified failure.
EXDI_E_COMMUNICATION Indicates a communication error between host driver and debugging target.

Requirements

OS Version: Windows CE 5.0 and later.
Header: exdi2.h.
Link Library: ole32.lib, oleaut32.lib.
