Opening a Run-time Image for Debugging

You can open an existing run-time image for debugging or modification in the integrated development environment (IDE) of Windows Mobile 5.0.

A run-time image can be a .bin file, such as NK.bin or flash.bin, or an .nb0 file, such as diskimage.nb0 or kernel.nb0.

To open a run-time image

  1. Create the run-time image you want to debug or modify.
  2. Open Platform Builder.
  3. From the File menu, choose Open.
  4. In the dialog box that displays files, select the .bin or .nb0 image file you want and choose Open.
