Setting Debug Message Options

You can use the Debug Message Options dialog box to set preferences for the information included with a debug message. For example, you can have debug messages include timestamps, process identifiers, or thread identifiers. In addition, you can choose whether to display debug messages at the console or to have messages saved to a designated file.

The following topics describe how to make specific settings for debug message options.

  • Displaying Debug Messages with a Timestamp
  • Saving Debug Messages to a Log File
  • Displaying Debug Messages with a Process Identifier
  • Displaying Debug Messages with a Thread Identifier
