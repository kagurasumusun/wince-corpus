Remote Call Profiler Collection Control Window

You can use the Remote Call Profiler Collection Control window to control data collection during a profiling run.

You can manually turn profiling on and off at any time during the profiling run.

You can launch an application and choose whether or not to automatically collect profiling data while the application runs.

The Collection Control window also displays a summary of the information collected during the profiling run.

Note   Microsoft recommends that you do not use the Collection Control window and the Remote Call Profiler data collection functions simultaneously to control data collection.

These two methods of data collection are designed to be mutually exclusive.

If you use both methods of data collection simultaneously, data collection might fail or might produce unpredictable and erroneous results.
