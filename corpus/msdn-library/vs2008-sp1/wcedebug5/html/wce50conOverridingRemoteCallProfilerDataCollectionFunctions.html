Overriding Remote Call Profiler Data Collection Functions

You can disable Remote Call Profiler data collection functions in your code without deleting or commenting out the functions.

To override Remote Call Profiler data collection functions with the SuspendProfile function

  1. In the section of code that contains StartProfile and StopProfile functions, insert a SuspendProfile function.

    The SuspendProfile function disables all profiling for the section of code.

    This functionality is useful when you want to stop profiling a section of code in an external module, but do not want to remove the StartProfile and StopProfile function calls.

  2. To cancel the action of the SuspendProfile function, insert a ResumeProfile function, which returns the suspend/resume state to ON.

To override Remote Call Profiler data collection functions in the Cecap.h file

  1. In the Cecap.h file, use the following code example to disable the Remote Call Profiler data collection functions. 
    #ifndef PROFILE
#define PROFILE 0
#endif

    This code example disables the Remote Call Profiler data collection functions in your application by setting the preprocessor directive profile to zero.

    You can find the Cecap.h file in the Sdk\Wce420\Platman\Include directory in the top-level Platman directory for Platform Manager.

  2. Rebuild the application.

By modifying the Cecap.h file in this way, you can use the Collection Control window to control profiling of an application that contains StartProfile and StopProfile functions.
