Remote Tools for Performance Profiling

With remote tools for performance profiling, you can use a development workstation to remotely monitor performance criteria on a Microsoft® Windows® CE–based target device.

In this section

Remote Call Profiler
Provides information about the remote tool that provides a graphical interface for profiling and analysis.
Remote Kernel Tracker
Provides information about the remote tool that provides a visual representation of application and OS events that occur on a target device.
Remote Performance Monitor
Provides information about the remote tool that provides a variety of monitoring charts, logs, and viewers that allow you to measure performance on a target device.
