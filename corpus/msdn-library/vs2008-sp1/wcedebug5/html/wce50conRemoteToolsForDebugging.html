Platform Builder for Microsoft Windows CE 5.0  

Remote Tools for Debugging

With remote tools for debugging, you can use a development workstation to remotely debug a Microsoft® Windows® CE–based target device.

In this section

Remote Heap Walker
Provides information about the remote tool that displays information about the heap for each process on a target device
Remote Process Viewer
Provides information about the remote tool that displays information about each process on a target device
Remote Spy
Provides information about the remote tool that displays messages received by windows associated with applications running on a target device
