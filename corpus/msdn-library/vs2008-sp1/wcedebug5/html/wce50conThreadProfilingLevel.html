Thread Profiling Level

For Remote Call Profiler, the functions StartProfile, StopProfile, SuspendProfile, and ResumeProfile, when passed the PROFILE_THREADLEVEL constant, control data collection for a specific thread.

In a single-threaded application, you can exclusively use the thread profiling level for data collection control. For a multithreaded or cross-process application, you can use the thread profiling level to control data collection for specific threads.
