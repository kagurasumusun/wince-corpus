Properties Window

The Properties window displays detailed information about a selected item or profiling event.

In a Properties window, the All tab displays the entire set of properties for the item or event.

The User tab displays a customizable subset of properties.

The Snapshot tab preserves a static copy of the data that is displayed in the All and User tabs.

The data displayed in the Snapshot tab is independent of the data displayed in the remainder of the Properties window. You can position the snapshot outside of the Remote Call Profiler window. For information about creating a snapshot, see Creating a Snapshot Window.

For information about opening a Properties window, see Opening a Properties Window.
