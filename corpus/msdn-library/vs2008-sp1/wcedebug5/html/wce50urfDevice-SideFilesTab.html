Device-Side Files Tab

On the Device-Side Files tab in the Server Settings dialog box, you can specify a directory on the target device in which to store files required by a CETK test or tool. In this directory, the CETK also stores the file that contains the results of a test. For more information about the Server Settings dialog box, see Server Settings Dialog Box.

Before starting a CETK test or tool, on the target device create the directory that you specified. If you do not create the directory and the directory does not already exist, the CETK test or tool cannot run.

Folder on target device in which to store files for tests
Path to the location on the target device in which to store files required by a CETK test or tool. This path applies to all target devices.
Note   For each target device, you can override the path specified in this box. For more information, see Specifying a Directory to Store Files Required by CETK Tests.
Restore Default Path
Changes the value in the Folder on target device in which to store files for tests box to the default path.
OK
Saves changes to the settings for the CETK server and closes the dialog box.
Cancel
Closes the dialog box without saving changes.
Apply
Saves changes to the settings for the CETK server and leaves the dialog box open.
