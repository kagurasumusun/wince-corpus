ICcOSImage

This interface provides methods that represent a run-time image in the datastore.

Methods

The following table shows the method for the ICcOSImage interface.

Method Description
ICcOSImage::SupportedPlatform Gets and sets the platform that references this run-time image.

Requirements

OS Version: Windows 2000, Windows XP Home, Windows XP Pro, Windows Server 2003, and Windows Server 2003 Service Pack 1.
Header: CcDatastore.h.
Link Library: none.
