PPFS Service

The Parallel Port File System (PPFS) connectivity service provides a means for a target device to access files on a development workstation. With PPFS, if the file loader on the target device cannot find a file on the target device, the file loader sends a message over KITL to Platform Manager requesting the file from the development workstation. KITL looks for the file in the release directory. The release directory is the directory on the development workstation containing the file for the run-time image from which the target device booted.

The PPFS file service was originally implemented over a parallel port, but the service now operates over any KITL connection.
