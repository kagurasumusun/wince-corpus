Choosing the Number of Processes and Threads to Profile

Remote Call Profiler profiles 10 processes and 32 threads by default.

The following procedure shows how to set the number of processes and threads to profile.

To choose the number of processes and threads to profile

  1. From the Tools menu, choose User Settings.
  2. Choose the Configuration Options tab.
  3. Select Maximum Processes.
  4. In the User Settings area, in the text box type the number of processes to profile.
  5. Select Maximum Threads.
  6. In the User Settings area, in the box type the number of threads to profile.
  7. Choose OK.
