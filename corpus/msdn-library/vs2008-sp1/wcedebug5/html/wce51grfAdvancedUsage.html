Advanced Usage

Advanced users of Tux.Net may want to take advantage of two other powerful technologies: Plug-ins and custom attributes.

Plug-Ins

A Tux.Net plug-in can be used to instrument (hook) the execution of test cases, or add additional processing for results as needed. For example, the MDPlugin will automatically take a screenshot on failure. The SamplePlugin project proves a minimal template for adding plug-in functionality.

Custom Attributes

Tux.Net's test-case selection functionality can be extended by implementing attributes that derive from DeviceDescriptorAttribute, documented in Tux.Net.chm. Such attributes must implement the IsValidDevice abstract property, returning true if the device is valid and false if not. This allows any number of custom criteria to be used at run-time in deciding whether or not a particular test case or test suite should be run on a particular device.
