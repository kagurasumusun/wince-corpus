Changing Call Stack Window Options

You can set the view options for a Call Stack window.

To change the Call Stack window options

  1. From the Tools menu, choose Options and then choose the Debug tab.

    - or -

    To change some options, right-click the Call Stack window and select the option from the shortcut menu.

  2. Select or clear the Parameter Values, Parameter Types, Frame Pointer, and File Name check boxes under Call Stack Window.
