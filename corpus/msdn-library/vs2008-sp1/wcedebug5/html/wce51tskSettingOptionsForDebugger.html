Setting Options for the Debugger

You can set a variety of display options for the kernel debugger, including any of the following:

  • Formats for data values, expressions, and addresses
  • Parameter types and values
  • Frame pointers
  • File names
  • Symbol names for addresses
  • Floating-point registers
  • Timestamps for debug messages

To set display options for the kernel debugger

  1. From the Tools menu, choose Options and then choose the Debug tab
  2. Select or clear the check boxes for the display options you want.
