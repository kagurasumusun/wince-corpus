Importing a File from a Target Device

You can import a file from a target device to a desktop computer.

To import a file from a target device

  1. On the target device, select the file you want to import.
  2. From the File menu, choose Import File.
  3. Navigate to the directory on your desktop computer where you want to save the file.
  4. Choose Save.
