_BuildVersion

This function obtains the version number for the Scripting Host tool.

BSTR _BuildVersion( void );

Return Values

This function returns the version number for the Scripting Host tool.

Remarks

You can call this function from a script that Cescript.exe executes.

Requirements

OS Versions: Windows CE .NET 4.2 and later.
