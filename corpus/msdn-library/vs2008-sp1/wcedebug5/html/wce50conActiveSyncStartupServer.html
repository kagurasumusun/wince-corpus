ActiveSync Startup Server

The ActiveSync startup server uses the Microsoft ActiveSync application to load and then launch a file on a target device. To use the ActiveSync startup server, you must first use the ActiveSync application to connect the development workstation to the target device. For more information, see Establishing a Connection to a Target Device with ActiveSync.

The ActiveSync startup server does not require configuration because the ActiveSync application establishes a partnership with the target device. This partnership facilitates the transfer of files between the development workstation and the target device.
