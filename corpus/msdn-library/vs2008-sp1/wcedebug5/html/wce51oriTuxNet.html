Tux.Net

Tux.Net is a managed-code test harness used to run tests on devices. When run from a device with command line or a configuration file it will locate the specified test suites and tests inside managed assemblies and execute them. It has many options for specifying what tests or suites will be run, and how they should be run (for instance, should they be shuffled or repeated). Tux.Net looks for classes inheriting the TestSuite class and methods with the TestCase attribute to know what it can run, and it can run any assembly meeting these requirements.

Tux.Net executes Tests, but it is built primarily with the Logging library and Utils.Net. More information on Tux.Net is available in the documentation at Tux.Net Test Harness.
