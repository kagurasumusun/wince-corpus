Test Kits and Suites Tab

On the Test Kits and Suites tab in the Server Settings dialog box, you can choose a test suite to automatically apply to a target device that connects to the CETK. For more information about the Server Settings dialog box, see Server Settings Dialog Box.

Test kit to make active on a newly connected target device
Name of the test kit to make active for a target device when the target device connects to the CETK.
Test suite to apply to a newly connected target device
Name of a test suite to automatically apply to a target device when the target device connects to the CETK. Application of a test suite is optional.
OK
Saves changes to the settings for the CETK server and closes the dialog box.
Cancel
Closes the dialog box without saving changes.
Apply
Saves changes to the settings for the CETK server and leaves the dialog box open.
