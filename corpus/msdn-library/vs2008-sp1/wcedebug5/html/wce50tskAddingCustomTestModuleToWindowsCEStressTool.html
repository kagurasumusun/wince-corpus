Adding a Custom Test Module to the Windows CE Stress Tool

You can add a custom test module to the Windows CE Stress tool.

To add a custom module to the Windows CE Stress tool

  1. Run the Windows CE Stress tool, but do not start a test run.

    For information about starting the Windows CE Stress tool, see Running the Windows CE Stress Tool.

  2. Choose Show Options.
  3. Choose More Options, and then choose the Mixes and Modules tab.
  4. Choose Modules.
  5. Choose Add, and then follow the wizard to modify the module information.

    The wizard displays information in the left pane about the selected item.

    When you specify a file name, include the file name extension.

    Specify a minimum run time that reflects the maximum amount of time required to perform a single test case. This value prevents the harness from considering a module to have stopped responding if the time required to perform the test is longer than the specified module duration.

  6. Finish the wizard, and then choose OK to save your changes.

    The new module appears in the Pending Acceptance module mix. You can use the Pending Acceptance module mix to assess a test module before adding the test module to a different module mix. For more information about modifying a module mix, see Creating and Modifying a Module Mix for the Windows CE Stress Tool.
