IeXdi2OleAutoServer::GetDataBpAttributes

This method returns attributes for a data breakpoint.

HRESULT GetDataBpAttributes(
  VARIANT pieXdiDBP2,
  VARIANT* pbpKind,
  VARIANT* pMemType,
  VARIANT* pdwAddressSpace,
  VARIANT* pAddress,
  VARIANT* pAddressMask,
  VARIANT* pstrRegName,
  VARIANT* pData,
  VARIANT* pDataMask,
  VARIANT* pRWAccessType,
  VARIANT* pdwAccessWidth,
  VARIANT* pdwTotalBypassCount,
  VARIANT* pdwCurrentBypassCount,
  VARIANT* pfEnabled
);

Parameters

pieXdiDBP2
[in] Pointer to IeXdi2DataBP object interface for this breakpoint.
pbpKind
[out] Kind of breakpoint (hardware, software, or algorithmic).
pMemType
[out] Memory type (virtual memory, physical memory, or peripheral I/O).
pdwAddressSpace
[out] Address space of the breakpoint, if physical memory or peripheral I/O.
pAddress
[out] Address of data to be accessed to break on.
pAddressMask
[out] Mask to apply for address comparison.
pstrRegName
[out] Name of register to be monitored.
pData
[out] Value of data to be accessed.
pDataMask
[out] Mask to apply for data comparison.
pRWAccessType
[out] Data access type (read, write, or both).
pdwAccessWidth
[out] Data width, in bytes.
pdwTotalBypass
[out] Total number of bypasses allowed before triggering a CPU halt on this breakpoint.
pdwCurrentBypass
[out] Number of bypasses that have occurred.
pfEnabled
[out] Initial breakpoint state (enabled or disabled).

Return Values

The following table shows return values for this method.

Value Description
S_OK Indicates the function was successful.
E_FAIL Indicates an unspecified failure.
E_NORESAVAILABLE Indicates a breakpoint resource was not available and the method cannot instantiate all breakpoints.
E_OUTOFMEMORY Failed to allocate necessary memory.
E_INVALIDARG Indicates one or more arguments are invalid.
EXDI_E_COMMUNICATION Indicates a communication error between host driver and debugging target.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: exdi2.h.
Link Library: ole32.lib, oleaut32.lib.
