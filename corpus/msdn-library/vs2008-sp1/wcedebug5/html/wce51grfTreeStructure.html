Platform Builder for Microsoft Windows CE 5.0  

Tree Structure

The structure of code relevant to the automation effort is as follows:

Location in the tree Purpose
_WINCEROOT\private\qaapps\ QA code
  • Qacore\Utils.Net\
 Managed utility code
  • DATK\managed\
 DATK code
  • DATK\managed\Core
 Core DATK code
  • DATK\managed\Win32\
 Win32 API wrappers
  • Logger
 Logging
  • Misc
 Managed utility code
  • Random
 Random generator
  • Qatools
 Tools not specific to DATK automation
  • Automation
 Managed automation
  • AbstractionLayer\
 Abstraction layer
  • AreaLibrary\
 Area Library
  • Common\
 Common code
  • Common\CeStress
 Stress utilities
  • Common\Harness
 Test harness
  • Common\MobilityToolKit
 MTK code
  • Support
 DATK automation utilities that do not use Area Library
  • Tests
 Test cases
  • Tools
 DATK automation utilities that use Area Library

This structure is fixed, but there is some leeway in the organization under the AbstractionLayer, AreaLibrary, and Tests nodes. The following is an example of the recommended organization under these nodes:

Location in the tree Purpose
AbstractionLayer Abstraction Layer
  • Inbox
 Inbox UIAL
  • PocketPC
 Inbox PPC UIAL
  • SmartPhone
 Inbox SPH UIAL
AreaLibrary Area Library
  • Inbox
 Inbox Area Library
Tests Test cases
  • Inbox
 Inbox Test cases
