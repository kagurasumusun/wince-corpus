Server Settings Dialog Box

In this dialog box, you can configure the CETK server.

The following table shows the tabs in this dialog box.

Tab Description
Communications Tab Choose this tab to configure settings that affect communication between the CETK server and a target device.
Test Results Tab Choose this tab to configure settings that affect how the CETK stores test results.
Test Kits and Suites Tab Choose this tab to select a test kit and test suite to automatically apply to a target device that connects to the CETK.
Device-Side Files Tab Choose this tab to specify a directory on the target device where to store files required by a CETK test or tool.
