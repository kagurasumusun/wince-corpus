Adding Objects to a Log

You can designate which objects are monitored in a log.

To add objects to a log

  1. From the Edit menu, choose Add To Log.
  2. From Objects, select an object or set of objects to monitor, and then choose Add.
  3. Repeat the previous step for additional devices you want to monitor, and then choose Done.
