IeXdi2OleEvents

This interface provides methods that notify a client of OLE automation events.

Methods

This interface inherits the methods for the IUnknown and IDispatch interfaces.

The following table shows the IDispatch methods.

Method Description
IDispatch::GetIDsOfNames Maps a single member name and an optional set of parameter names to a corresponding set of integer dispatch identifiers (DISPIDs).

These identifiers can then be used on subsequent calls to IDispatch::Invoke.

IDispatch::GetTypeInfo Retrieves the type information for an object.
IDispatch::GetTypeInfoCount Retrieves the number of type information interfaces that an object provides, either 0 or 1.
IDispatch::Invoke Provides access to properties and methods exposed by an object.

The following table shows the methods defined for the IeXdi2OleEvents interface.

Method Description
IeXdi2OleEvents::NotifyMemoryChangeOle Notifies clients about a change in virtual memory.
IeXdi2OleEvents::NotifyCpuRegChange Notifies clients about CPU register content change.
IeXdi2OleEvents::NotifyRun Notifies clients when debugging target is running.
IeXdi2OleEvents::NotifyHalt Notifies clients when a debugging target is halted.
IeXdi2OleEvents::NotifyReset Notifies clients when a debugging target is reset.
IeXdi2OleEvents::NotifyErrorState Notifies clients when a debugging target is in an error state.
IeXdi2OleEvents::AuthorizeTargetRestartOle Requests client authorization to resume execution on a debugging target.
