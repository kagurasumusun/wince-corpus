Viewing Location Information for a Breakpoint

You can view the location properties for a location breakpoint..

To view the location information for a breakpoint

  1. From the View menu, choose Debug Windows and then choose Breakpoints List.

    The Breakpoints List window appears.

  2. Use the vertical scroll bar to move up or down the Breakpoints list.
  3. Select the location breakpoint you want to see properties for.
  4. Choose the Properties button.

    The Breakpoints Properties dialog box for a location breakpoint appears.
