IOsAxsCe50Generic

This interface defines methods that support OS awareness.

The following table shows the methods in the IOxAxsCe50Generic interface.

Method Description
IOsAxsCe50Generic::GetHdstubNotifAddress Returns an offset within nk.exe or hd.dll that will trap OS notifications.

An eXDI driver implementation must be able to trap the CPU when it executes code at this address
IOsAxsCe50Generic::GetThreadMigrationTarget Retrieves the target address of a protected server library (PSL) call.
