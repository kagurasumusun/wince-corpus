Storing Data Collected by the CPU Monitor Tool

You can save the data collected by the CPU Monitor tool in an XML file. The XML file includes the XML schema and data in XML format. You can use the DataTable object from Microsoft Visual Studio to read the XML file.

To store data collected by the CPU Monitor tool

  1. In the CPU Monitor for Windows CE window, from the Server menu, choose Save to XML.
  2. Navigate to the directory where you want to save the XML file.
  3. In the File name box, type a name for the XML file, and then choose Save.
