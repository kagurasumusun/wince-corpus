Platform Builder for Microsoft Windows CE 5.0  

AreaGen

This tool generates a skeleton Area Library project for an application.

Usage

areagen -p project

Parameter

Parameter Description
-p project Project to be generated

Example: areagen –p Microsoft.MobileDevices.AreaLibrary.pOutlook.Tasks
