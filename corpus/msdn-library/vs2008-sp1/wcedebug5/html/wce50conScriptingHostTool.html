Scripting Host Tool

The Scripting Host tool (Cescript.exe) is a Microsoft® ActiveX® scripting host. With the Scripting Host tool, you can run a script independent of a Web browser on a Microsoft Windows® CE–based device. For example, you can run a script from the Microsoft JScript® development system or Microsoft Visual Basic® Scripting Edition (VBScript) programming language.

For information about running a script with the Scripting Host tool, see Running the Scripting Host Tool.
