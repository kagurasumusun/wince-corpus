Remote Call Profiler .icp Files

The Remote Call Profiler viewer displays information in a hierarchical structure of processes and threads for each .icp file. Each top-level node represented in the viewer corresponds to one .icp file.

For information about opening an .icp file in the Remote Call Profiler viewer, see Opening an .icp File in Remote Call Profiler.
