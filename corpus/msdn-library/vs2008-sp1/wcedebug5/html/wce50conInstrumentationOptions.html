Instrumentation Options

Remote Call Profiler collects data only from modules that have been instrumented with Remote Call Profiler profiling probes.

You do not need to instrument all modules in an application to collect data from profiling probes.

Remote Call Profiler supports the following combinations of instrumented and noninstrumented modules:

  • Instrumented .exe file and instrumented DLL files.
  • Instrumented .exe file and noninstrumented DLL files.
  • Noninstrumented .exe file and instrumented DLL files.
    Note   In Remote Call Profiler, symbol information for a module that is dynamically loaded and unloaded in a process during a profiling run can become unavailable when another module is mapped into the same address space in the process.
