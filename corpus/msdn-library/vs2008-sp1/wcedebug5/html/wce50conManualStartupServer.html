Manual Startup Server

Unlike the ActiveSync Startup Server or the CESH Startup Server, the manual startup server does not copy files to or launch files on a target device. Instead, the manual startup server displays a dialog box that lists files that you must manually copy to the target device before you can establish a connection to the target device with Platform Manager. You should choose the manual startup server if you typically build the device side of Platform Manager into your run-time image or if you want to copy files manually to a target device outside of Platform Manager.

The dialog box for the manual startup server displays a command that you can use to manually run the files on the target device. After you copy the files, you must run this command from a command prompt before you can connect to the target device with Platform Manager.
