PERF_COUNTER_MULTI_TIMER_INV

The following table shows the inverse of the timer for multiple but similar items.

The counter is used when the objects are not in use.

Element Value
X CounterData
Y PerfTime
Time base PerfFreq
Data Size 8 Bytes
Display Suffix %
Calculation 100*(B1- ((X1-X0)/((Y1-Y0)/TB)))/B1
