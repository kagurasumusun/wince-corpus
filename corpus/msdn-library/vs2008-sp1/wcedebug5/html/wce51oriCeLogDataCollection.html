CeLog Data Collection

The CeLog toolset gives you several different ways to control the data collected by CeLog. In addition, you can use CeLog zones to select what data is collected.

In this section

CeLog Data Collection Overview
Provides a brief description of different ways you can collect data with CeLog.
Filtering CeLog Events
Describes how to use collection zones to filter the data CeLog collects.
Avoiding CeLog Data Loss
Describes a variety of techniques to help you avoid data loss, and to diagnose data loss when it occurs.
