Transport Selection

Platform Manager uses a transport to communicate over the physical connection between a development workstation and a target device. A transport is one of several communications protocols that Platform Manager supports to connect to a target device or tool. By default, Platform Manager supports the following transports:

  • ActiveSync Transport
  • KITL Transport
  • TCP/IP Transport

You can view and configure the properties of a transport when you alter the properties of a Platform Manager device. For more information, see Configuring the Connection to a Target Device Using Platform Manager.

You can also create a custom transport for your communications hardware. For more information, see Custom Transport Creation.
