Platform Builder for Microsoft Windows CE 5.0  

ICcPlatform

This interface provides methods that represent a platform object in the datastore.

Methods

The following table shows the methods for the ICcPlatform interface.

Method Description
ICcPlatform::DeviceContainer Returns the device container for a platform.
ICcPlatform::FormFactorContainer Gets the form factor container that holds information about the form factors for a platform.
ICcPlatform::ProjectContainer Returns the project container for a project.

Requirements

OS Version: Windows 2000, Windows XP Home, Windows XP Pro, Windows Server 2003, and Windows Server 2003 Service Pack 1.
Header: CcDatastore.h.
Link Library: none.
