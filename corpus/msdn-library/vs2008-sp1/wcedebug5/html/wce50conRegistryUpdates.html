Registry Updates

You must make several updates to the registry when you install your performance DLL.

An application that supports performance counters must have a Performance subkey under the Services subkey. Hence, to use performance counters, you must create a Performance subkey .

In addition, the names and descriptions of performance objects and their associated counters are stored using the registry. Therefore, you must add information to the registry for the objects and counters you add to the system.
