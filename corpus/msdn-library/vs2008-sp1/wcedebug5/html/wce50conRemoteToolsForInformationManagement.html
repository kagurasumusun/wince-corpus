Remote Tools for Information Management

With remote tools for information management, you can use a development workstation to remotely view system information on a Microsoft® Windows® CE–based target device.

In this section

Remote File Viewer
Provides information about the remote tool that displays a hierarchical view of the file system on a target device.
Remote Registry Editor
Provides information about the remote tool that allows you to manage and edit the registry on a target device.
Remote System Information
Provides information about the remote tool that allows you to view system settings on a target device.
Remote Zoom-in
Provides information about the remote tool that allows you to display a screen image from a target device.
