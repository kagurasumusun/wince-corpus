ICcConnection::VerifyFilesInstalled

This method verifies that a specified set of files is installed.

HRESULT VerifyFilesInstalled(
  [in] DWORD in_ArraySize,
  [in, size_is(in_ArraySize), length_is(in_ArraySize)] FileVerifyReference in_InfoArray[],
  [out, size_is(in_ArraySize), length_is(in_ArraySize)] FileVerifyResult out_ExistenceArray[]
);

Parameters

in_ArraySize
Size of array specified in the FileVerifyReference and FileVerifyResult structures.

These arrays must be the same size.

in_InfoArray
Array specified in the FileVerifyReference structure.
out_ExistenceArray
Array specified in the FileVerifyResult structure.

Return Values

If the method fails, it returns an HRESULT error code.

If the method succeeds, it returns S_OK.

Requirements

OS Version: Windows 2000, Windows XP Home, Windows XP Pro, Windows Server 2003, and Windows Server 2003 Service Pack 1.
Header: CcConnection.h.
Link Library: none.
