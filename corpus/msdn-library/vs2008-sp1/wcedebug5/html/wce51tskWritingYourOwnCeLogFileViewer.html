Writing Your Own CeLog File Viewer

You can write your own viewer to replace Remote Kernel Tracker and the Readlog viewing tool. Once you know how to interpret the log file contents, you can process them however you like.

A CeLog file consists of a series of events, stored one after the other on DWORD-aligned boundaries, each described by an event header. For more information on how to interpret the events in the log, see CeLog Event Format.

Each event has an event identifier and a data structure associated with it. The event ID tells you what type of event occurred and the data structure further describes the event. For a list of the event types that can be stored in a CeLog file, see CeLog Event Identifiers.

You can find a sample CeLog file viewer in the Windows CE SDK at %_WINCEROOT%\public\COMMON\sdk\samples\celog\reader.
