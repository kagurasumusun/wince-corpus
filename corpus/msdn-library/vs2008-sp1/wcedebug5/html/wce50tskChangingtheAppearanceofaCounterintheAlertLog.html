Changing the Appearance of a Counter in the Alert Log

You can customize the appearance of an Alert Log.

To change the appearance of a counter in the alert log

  1. From the Edit menu, choose Edit Alert Entry.
  2. In the Color box, choose a color for the alert.
  3. In the Alert If area, choose Over or Under; then in the box type the value at which you want Remote Performance Monitor to generate an alert.
  4. In the Run Program on Alert area, type the path and file name for the application or macro you want to run when the specified alert occurs.
  5. To run the application or macro every time the alert occurs, choose Every Time.

    - or -

    To run the application or macro only the first time the alert occurs, choose First Time.

  6. Choose OK.
