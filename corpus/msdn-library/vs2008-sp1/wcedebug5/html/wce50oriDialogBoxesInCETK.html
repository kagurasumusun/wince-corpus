Dialog Boxes in the CETK

The Windows CE Test Kit (CETK) provides context-sensitive help for dialog boxes in the CETK window. You can open Help for a dialog box if the dialog box has the focus by pressing the F1 key or by choosing Help.

In This Section

Server Settings Dialog Box
Provides context-sensitive help for the Server Settings dialog box, from which you can configure the CETK server.
Edit Command Line Dialog Box
Provides context-sensitive help for the Edit Command Line dialog box, from which you can modify the command line for a selected CETK test.
Test Suite Editor Dialog Box
Provides context-sensitive help for the Test Suite Editor dialog box, from which you can create and manage test suites.
Test Suite Name Dialog Box
Provides context-sensitive help for the Test Suite Name dialog box, from which you can name a new test suite or modify the name of an existing test suite.
Export Test Suite Dialog Box
Provides context-sensitive help for the Export Test Suite dialog box, from which you can export one or more test suites to a file.
Select Test Suite Dialog Box
Provides context-sensitive help for the Select Test Suite dialog box, from which you can apply a selection of tests to a target device.
Device-Side Files Folder Dialog Box
Provides context-sensitive help for the Device-Side Files Folder dialog box, from which you can specify which directory on a single target device stores files required by a CETK test or tool.
Device Connection Dialog Box
Provides context-sensitive help for the Device Connection dialog box, from which you can specify how the CETK connects to a target device.
