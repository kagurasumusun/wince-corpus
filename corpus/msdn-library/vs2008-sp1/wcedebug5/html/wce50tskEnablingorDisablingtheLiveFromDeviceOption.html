Enabling or Disabling the Live From Device Option

The following procedure enables or disables the Live From Device option only if Remote Kernel Tracker is in Data Collection Mode or Limited Buffer Mode. The Live From Device option is not available in File Mode.

To enable or disable the Live From Device option

  • From the View menu, choose Auto-Follow Mode.
