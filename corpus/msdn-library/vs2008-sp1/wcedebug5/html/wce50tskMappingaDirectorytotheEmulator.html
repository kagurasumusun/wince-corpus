Mapping a Directory to the Emulator

You can connect the Emulator to a directory on your development workstation as if the directory were a drive mounted on the Emulator. In the file system for the Emulator, the connected directory appears at the root level as Storage Card. You can connect the Emulator to only one directory at a time.

To map a directory to the Emulator

  1. On the Emulator, run a Windows CE OS that supports the ability to connect to a directory on the development workstation.
  2. In the Emulator window, from the Emulator menu, choose Folder Sharing.
  3. Choose Share this folder if the option is not already chosen.
  4. In the box under Share this Folder, type the path to the directory that you want to share.

    - or -

    Choose the Browse button, navigate to the directory that you want to share, and then choose OK.

  5. Choose OK.
