FileVerifyVersion

This structure describes file version information for verification.

typedef struct tagFileVerifyVersion{
  DWORD m_Major;
  DWORD m_Minor;
  DWORD m_Build;
  DWORD m_Revision;
} FileVerifyVersion;

Members

m_Major
Major version number.
m_Minor
Minor version number.
m_Build
Build version number.
m_Revision
Build revision number.

Requirements

OS Versions: Windows CE 5.0.
Header: cccommon.idl.
