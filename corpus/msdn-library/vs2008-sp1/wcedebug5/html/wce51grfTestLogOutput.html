Platform Builder for Microsoft Windows CE 5.0  

Test log output

By default, all Tux.Net output gets logged to a file results.log, which is created either in the Platform Builder release directory (which is mapped to \release on the device, if available) or else in the same directory Tux.Net is run from on the device. The –f switch can be used to re-direct this output to another location or file name.

The log output provides reports on pass/fail status of individual test cases, as well as a summary at the end. It also provides details about the device the test is run on.
