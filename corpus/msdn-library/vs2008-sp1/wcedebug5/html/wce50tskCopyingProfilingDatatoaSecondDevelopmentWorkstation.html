Copying Profiling Data to a Second Development Workstation

If you copy the Remote Call Profiler profiling data (.icp) file to a second development workstation for viewing, the development workstation must have access to the symbol information associated with the executable file.

To copy profiling data to a second development workstation

  1. Copy the .icp file, the profiled executable file, and all associated symbol information files to a single directory on the second development workstation.
  2. In the Remote Call Profiler window, from the File menu, choose Serialize and then choose Symbol Information.

    This action appends symbol information to the .icp file.
