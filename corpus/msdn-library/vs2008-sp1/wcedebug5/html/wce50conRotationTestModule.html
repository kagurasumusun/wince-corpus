Rotation Test Module

The rotation test module, S2_rotate.dll, exercises the screen rotation capabilities of a target device. The test module uses the ChangeDisplaySettingsEx function to rotate the screen to a random orientation approximately once per minute.

This test module does not require a server and does not accept any command-line options.

The rotation test module does not require support for screen rotation, but without support for it, the test module effectively does nothing. This test module requires the Gwes.exe module, which is in every display-based Windows CE OS.
