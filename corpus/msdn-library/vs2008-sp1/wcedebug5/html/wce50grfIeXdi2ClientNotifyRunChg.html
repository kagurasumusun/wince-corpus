IeXdi2ClientNotifyRunChg

This interface contains methods that enable the exdi service to notify the client of run-state changes.

Methods:

The following table shows the methods defined in the IeXdi2ClientNotifyRunChg interface.

Method Description
IeXdi2ClientNotifyRunChg::NotifyRunStateChange Indicates a change in the run state.
