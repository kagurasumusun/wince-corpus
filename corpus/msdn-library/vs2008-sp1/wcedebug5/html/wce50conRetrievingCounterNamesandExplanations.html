Retrieving Counter Names and Explanations

The Remote Performance Monitor tool allows you to customize what performance metrics are gathered. The information the tool gathers is recorded in an index that can be easily used in a custom application.

A performance data structure does not directly provide object type names, counter names, object explanations, and counter explanations. Instead, it contains indexes you can use to locate the names and explanations for each object and counter.

The ObjectNameTitleIndex and ObjectHelpTitleIndex members of the PERF_OBJECT_TYPE structure contain the indexes to the object name and explanation, respectively.

The CounterNameTitleIndex and CounterHelpTitleIndex members of the PERF_COUNTER_DEFINITION structure contain the indexes to the counter name and explanation, respectively.

To see the name and explanation for a counter, read the Counter and Help values in the HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Perflib\langid registry key.

Replace the langid placeholder with the ASCII representation of the 3-digit hexadecimal language identifier. For example, the langid for U.S. English is 009.

The values under this registry key store the data associated with a counter as a MULTI_SZ string. The MULTI_SZ data type consists of a list of Unicode strings, each terminated with a UNICODE_NULL constant. An additional UNICODE_NULL constant follows the last string.

The strings are listed in pairs. The first string of each pair is the Unicode string of the index, and the second string is the actual name of the index. The Counter data uses only even-numbered indexes, while the Help data has odd-numbered indexes.

To retrieve a name or explanation for an object type or counter, given its index, an application should perform the following steps.

To retrieve counter names and explanations in an application

  1. If the system is a remote system, call the RegConnectRegistry function.
  2. Use the RegOpenKeyEx function to open the registry key containing a name and explanation for a counter.
  3. Use the RegQueryValueEx function to specify the name of the value to query.
  4. Convert the returned index into Unicode or ASCII format, to match the format of your application.
  5. Search the MULTI_SZ data for the returned index.
  6. Retrieve the string associated with the matching index.

    The string contains the name and explanation for the counter.

    Note   To look up several counters, build a table of values for faster and easier retrieval of data.
