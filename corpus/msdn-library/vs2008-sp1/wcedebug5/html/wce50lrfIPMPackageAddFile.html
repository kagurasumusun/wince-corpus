IPMPackage::AddFile

This method adds a file to a package.

HRESULT AddFile(
  BSTR bstrFullPath,
  BSTR bstrKeyName,
  IPMCPU* piPMCPU,
  IPMOS* piPMOS,
  long dwLocaleId,
  long dwFlags 
  IPMPackageFile** ppiPMPackageFile 
);

Parameters

bstrFullPath
[in] Path and name of the file.
bstrKeyName
[in] Registry key for the file.
piPMCPU
[in] Pointer to the IPMCPU interface.
piPMOS
[in] Pointer to the IPMOS interface.
dwLocaleId
[in] Locale identifier for the file.
dwFlags
[in] Flags for the file.
ppiPMPackageFile
[out] Pointer to a pointer to the IPMPackageFile interface.

Return Values

Returns S_OK if the call was successfully completed. If a failure occurs, the appropriate HRESULT value is returned.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Package.h, Cemgr.idl.
