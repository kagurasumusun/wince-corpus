Device-Side Files Folder Dialog Box

In the Device-Side Files Folder dialog box, you can specify which directory on a single target device stores files required by a CETK test or tool. In this directory, the CETK also stores the file that contains the results of each test.

Before starting a CETK test or tool, on the target device create the directory that you specified. If you do not create the directory and the directory does not already exist, the CETK test or tool cannot run.

Note   The CETK temporarily stores the path that you specify for a single target device. If you close and then open the CETK window, disconnect the target device from the CETK server, or choose Redetect Peripherals for the target device, you must specify the path again.
On this target device only, store files for tests in this folder
Path for this target device. If you choose this option, the path that you specify overrides for this target device the path specified in the Server Settings dialog box for all target devices.
Store files for tests in the folder specified by system-wide settings
Path specified in the Server Settings dialog box. If you choose this option, this target device uses the path specified for all target devices that connect to the CETK.

For information about specifying a path for all target devices in the Server Settings dialog box, see Specifying a Directory to Store Files Required by CETK Tests.

OK
Saves your changes and closes the dialog box.
Cancel
Closes the dialog box without saving changes.
