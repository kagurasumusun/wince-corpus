Choosing the Active Test Kit for a Target Device Connected to the CETK

Before you can choose the active test kit for a target device, you must connect the CETK to the target device. For information about connecting the CETK to a target device, see Connecting the CETK to a Target Device by Using Platform Manager.

To choose the active test kit for a target device connected to the CETK

  1. In the tree view in the Windows CE Test Kit window, expand the node corresponding to the target device.
  2. Choose the option corresponding to the name of the test kit that you want to make active for the target device.

    In the tree view, you can expand the node for the active test kit. You cannot expand a node for an inactive test kit.
