Writing a Test Case

  1. Rename suite1.cs to RunDialogTests.cs.
  2. Open RunDialogTests.cs.
  3. Rename the TuxNetSkeletonTests class to RunDialogTests (be sure to rename both the class and the constructor).
  4. At the top of RunDialogTests.cs, expand the usings block, and add the following code:
    using Microsoft.MobileDevices.AbstractionLayer.Shell.PocketPC;
  5. Add a Launch method to the RunDialogTests class. Copy and paste the following code into the class: 
    #region Utility Methods
/// <summary>
/// Launch the run dialog using Win+R
/// </summary>
public void Launch()
{
   Utils.GlobalLogger.AddComment("Launch the Run Dialog");
   Datk.KeyBoard.SendKey(Datk.KeyBoard.Key.LWin, Datk.KeyBoard.EventFlags.KeyDown);
   Datk.KeyBoard.SendKey('R');
   Datk.KeyBoard.SendKey(Datk.KeyBoard.Key.LWin, Datk.KeyBoard.EventFlags.KeyUp);
}
#endregion
  6. Now, expand the Functional Test Cases region. Remove the code that is currently in this region and paste the following code in its place: 
    /// <summary>
/// Uses the Run dialog to launch iexplore.exe
/// NOTE: This test case will only run on a Pocket PC phone.
/// </summary>
/// <returns>LogResult.Pass on success</returns>
[TestCaseAttribute("RunDialog launching iexplore", Type = TestType.Functional)]
[MobileDevicesDescriptor ( Product = Products.PocketPC ) ]
public Log.LogResult LaunchIExplore()
{
   RunDialog run = new RunDialog();

   Launch();
   Utils.GlobalLogger.AddComment("Select the edit control");
   run.OpenTextBox.Click();
   Utils.GlobalLogger.AddComment("Enter 'iexplore'");
   Datk.KeyBoard.SendString("iexplore");
   Utils.GlobalLogger.AddComment("Click Ok");
   run.OKButton.Click();

   Utils.GlobalLogger.AddComment("Verify that iexplore is launched");
   Datk.WindowFinder iexploreFinder = new Datk.WindowFinder();
   iexploreFinder.ProcessName = "iexplore.exe";

   // This will throw an exception if the iexplore is not found,
   // effectively failing the test.
   iexploreFinder.FindForm();

   return Log.LogResult.Pass;
}
  7. Remove the BVT (Build Verification Test) region.
  8. If you are using the emulator, make sure that it is not cradled (you can not deploy to a cradled emulator using VS). You can uncradle it from the Device Emulator Manager.
  9. Use F5 to deploy and run the test case! You will see it typing into the run dialog, clicking the OK button, and then Internet Explorer being launched.
  10. You can get the log file Results.log in \test through ActiveSync.
