Saving a Screen Image

You can save a screen image from a target device to a file.

To save a screen image

  1. From the Window menu, choose the window containing the screen image you want to save.
  2. From the File menu, choose Save as.
  3. Navigate to the directory where you want to save the file.
  4. In the File name box, type a name for the file.
  5. Choose OK.
