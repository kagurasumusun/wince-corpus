Understanding the Debug Zones Dialog Box

The Debug Zones dialog box allows you to view debug zones for processes and modules. You can also turn debug zones on and off from this dialog box.

The following table shows when the Debug Zones menu item and button are enabled.

Condition Enabled
Kernel debugger is attached to the target device, the target device is running, and Target Control is running. Yes.
Kernel debugger is not attached to the target device, the target device is running, and Target Control is running. Yes.
Target device is at a debug stop. No.
Target device is empty. No.
Kernel debugger is attached to target device, the target device is running, and Target Control is not running. No.
The kernel debugger is not attached to the target device, the target device is running, and Target Control is not running. No.
