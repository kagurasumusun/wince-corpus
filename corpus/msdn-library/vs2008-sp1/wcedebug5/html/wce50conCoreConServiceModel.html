Platform Builder for Microsoft Windows CE 5.0  

Connectivity Service Model

The connectivity service model that implements Platform Builder connectivity consists of the following elements:

  • Service Categories

    Provide a base of common functionality for member services.

  • Services

    Provide specific support functionality, such as download, transport, and bootstrap.

  • Service Host

    Manages all services and service categories.

In addition, to facilitate communication between services, the connectivity infrastructure includes a Service Callback Service, and allows you to create Custom Service Configurations.
