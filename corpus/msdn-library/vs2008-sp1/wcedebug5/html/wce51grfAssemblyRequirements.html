Assembly Requirements

Any assembly can be a Tux.Net test assembly. There are a few simple things it must do:

  • The assembly must include a reference to the Tux.Net core support assembly, Microsoft.MobileDevices.TuxNet.Core.dll. This is where important Tux.Net data types are defined.
  • The assembly must include test classes derived from TestSuite, a type defined in the core support assembly.
  • The assembly's test classes must expose public test methods with the following two characteristics:
    • The methods must define the TestCaseAttribute in the core support assembly;
    • The methods must have a signature expected by Tux.Net (discussed further below).

With these characteristics, an assembly can serve multiple purposes. For instance, shipping assemblies that support product applications can include "self-tests" which Tux.Net can be used to execute.
