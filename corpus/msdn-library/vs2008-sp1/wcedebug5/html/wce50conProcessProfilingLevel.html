Process Profiling Level

The process profiling level permits or blocks data collection for all threads in a specified process.

You can use the process profiling level

  • To control data collection for all threads in a single process application with multiple threads
  • To control data collection for a specific process in a cross-process application

For Remote Call Profiler, the functions StartProfile, StopProfile, SuspendProfile, and ResumeProfile, when passed the PROFILE_PROCESSLEVEL constant, control data collection for a specific process.
