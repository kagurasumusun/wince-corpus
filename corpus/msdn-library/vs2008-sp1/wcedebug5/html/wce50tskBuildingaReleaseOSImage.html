Building a Run-Time Image From a Release Configuration

You can build a run-time image from a Release configuration.

To build a run-time image from a Release configuration

  1. From the Platform menu, choose Settings.
  2. In the Settings For box, choose a release configuration.
  3. On the Build Options tab, clear the Enable Kernel Debugger check box and then choose OK.
  4. From the Build OS menu, choose Set Active Configuration; then verify that the active configuration set for your OS design is a Release configuration.
  5. From the Build OS menu, choose Build and Sysgen.
