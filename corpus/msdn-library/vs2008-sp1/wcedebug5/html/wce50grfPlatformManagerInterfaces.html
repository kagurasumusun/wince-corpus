Platform Builder for Microsoft Windows CE 5.0  

Platform Manager Interfaces

The following table shows Platform Manager interfaces.

Programming element Description
IEnumVariant This interface provides methods for representing a collection of objects. All enumeration objects in Platform Manager use this interface.
IPMBootableDevice This interface provides the ability to access and change a specified, named connection. A named connection object stores download service settings, kernel transport settings, and other settings.
IPMConnection This interface provides the ability to access and change a specified connection object. The connection object is created by the IPMRemoteDevice::Attach method.
IPMConnectionStream This interface provides the ability to access and change a specified connection stream object.
IPMCPU This interface provides the ability to access and change a specified CPU object.
IPMOS This interface provides the ability to access and change a specified operating system (OS) object.
IPMPackage This interface provides the ability to access and change a specified package object. Package objects can be associated either with Platform Manager or a specific platform object.
IPMPackageFile This interface provides the ability to access and change a specified package file object.
IPMPlatform This interface provides the ability to access and change a specified platform object registered in Platform Manager.
IPMPlatformManager This interface provides access to any other interface exposed by Platform Manager. It is the root-level interface for Platform Manager.
IPMProperty This interface provides the ability to access and change a specified property object.
IPMPropInfo This interface provides the ability to access and change a specified property information object. A property information object holds a registry key value for a property. A property object may have one or more property information objects. Each property information object corresponds to a registry key value for the property.
IPMRemoteDevice This interface provides the ability to access and change a specified device object associated with a run-time image. A device object stores the information required to establish an application-level connection between a development workstation and a target device. For more information, see Application Connectivity.
IPMService This interface provides the ability to access and change a specified service object.
IPMServiceCategory This interface provides the ability to access and change a specified service category object.
IPMServiceInfo This interface provides the ability to access and change a specified service information object.
IPMStartupServerInfo This interface provides the ability to access and change a specified startup server object.
IPMTransportInfo This interface provides the ability to access and change a specified transport object.
