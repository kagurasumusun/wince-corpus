Checkins and Reviews

Everyone is expected to follow the conventions detailed in the Code Review Checklist and the Checkin Checklist. To ensure the highest quality code, you can also enforce the following in your team:

Everyone must do a full code review of their own code before sending a bbpack. This includes building with no warnings, running FxCop, and reviewing the code changes themselves.

Have code reviewers build and run FxCop on all code reviews.

Have code reviewers enforce meaningful xml comments (not just filling space between tags so FxCop doesnt complain about missing xml comments.

Have code reviewers enforce the use of region blocks to outline steps in test cases (see the Test Case Guidelines for more info).
