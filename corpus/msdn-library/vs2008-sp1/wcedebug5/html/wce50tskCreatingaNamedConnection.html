Creating a Named Connection

A named connection stores settings required to download a run-time image to a target device or to establish a kernel-level connection to the target device. With the Platform Builder IDE, you can create as many named connections as you want. In the Target Connectivity Options dialog box, named connections appear in the Target device box.

To create a named connection

  1. From the Target menu, choose Connectivity Options.
  2. Choose Add Device.
  3. In the New target device name box, type a name for the connection.
  4. Choose Add to create the named connection.

    The Target Connectivity Options dialog box displays the default settings for the named connection.

  5. If you want, modify the default settings in the Target Connectivity Options dialog box, and then choose Apply to save your changes.
