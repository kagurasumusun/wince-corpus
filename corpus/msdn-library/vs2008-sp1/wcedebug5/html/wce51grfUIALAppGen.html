Platform Builder for Microsoft Windows CE 5.0  

UIALAppGen

This tool generates a UIAL Application class based on a number of UIAL Dialog class files.

Syntax

UIALAppGen path outFile

Parameters

Parameter Description
path String specifying the path that contains the .cs files.
outFile String specifying the path to the output file; for example, Microsoft.MobileDevices.AbstractionLayer.Inbox.PocketPC.cs
