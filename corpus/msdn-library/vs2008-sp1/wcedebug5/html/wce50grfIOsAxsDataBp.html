IOsAxsDataBp

This interface defines methods that provide data breakpoint with process and thread affinity.

Methods

The following table shows the methods of the IOsAxsDataBp interface.

Method Description
IOsAsxDataBp::GetAttributesEx Returns the characteristics of a specified data breakpoint.

Requirements

OS Version: Windows CE 5.0 and later.
Header: OsAccess.h.
Link Library: OSAXSC.lib.
