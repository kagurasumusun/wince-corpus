IOsAxsCe50Process

This interface is used to get Windows CE-specific information about a process.

Methods

The following table shows the methods of the IOsAxsCe50Process interface.

Method Description
IOsAxsCe50Process::MapPointerToProcess Converts a pointer to a value in this process' address space.

Requirements

OS Version: Windows CE 5.0 and later.
Header: OsAccess.h.
Link Library: OSAXSC.lib.
