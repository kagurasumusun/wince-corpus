Viewing the Threads for a Selected Process

You can view the threads for a specified process.

To view the threads for a process

  • In the Processes window, right-click a process; then, from the shortcut menu, choose Open in Threads Window.

    - or -

    In the Processes window, double-click a process.

    The Thread window refreshes to display the threads for the selected process.
