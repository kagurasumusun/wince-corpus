Creating a Summary View File

A Remote Call Profiler summary view (.icx) file provides a compact means of storing data from a profile run. An .icx file contains the information that is required to display data in the Remote Call Profiler Top X View, Module Summary View, Call Graph View, or Butterfly View.

The symbol files and executable files required to view an .icp file are not required to view an .icx file.

The size of an .icx file is typically smaller than the combined size of the source .icp file and the executable files and symbol information files associated with the .icp file.

An .icx file is limited in that you cannot change the data range options for a Remote Call Profiler view from an .icx file.

To create a summary view file

  1. In the Remote Call Profiler window, select the data you want to include in the .icx file.

    For more information about selecting data, see Remote Call Profiler View Windows.

  2. From the View menu, choose New View.
  3. Choose Top X, Module Summary, Call Graph, or Butterfly.
  4. Select the view window.
  5. From the File menu, choose Save Summary.
  6. Navigate to the directory in which you want to save the .icx file.
  7. In the File name box, type a name for the .icx file.
  8. Choose Save.
