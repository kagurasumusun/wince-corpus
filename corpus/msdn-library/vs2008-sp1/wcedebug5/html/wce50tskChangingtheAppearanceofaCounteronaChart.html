Changing the Appearance of a Counter on a Chart

You can customize the appearance of a Chart View counter.

To change the appearance of a counter on a chart

  1. In the legend, select a counter.
  2. From the Edit menu, choose Edit Chart Line.
  3. In the Color box, choose a color for the line.
  4. In the Scale box, choose a vertical scale for plotting the line.
  5. In the Width box, choose a width for the line.
  6. In the Style box, choose a solid line or a dashed-line pattern.
  7. Choose OK.
  8. To update your chart selections in a settings file, from the File menu, choose Save Chart Settings.
