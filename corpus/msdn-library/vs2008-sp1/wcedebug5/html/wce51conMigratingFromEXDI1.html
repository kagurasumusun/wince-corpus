Migrating from eXDI1

The Extended Debugging Interface includes a wrapper component that adapts eXDI2/OsAccess interface to eXDI1 so that the new debugger can use existing eXDI1 drivers.

The compatibility wrapper is an eXDI service that exposes the standard eXDI2 interface.

The Target Connectivity Option dialog shows an eXDI1 service in the same manner as it shows eXDI2 services, transparently loading the compatibility wrapper.
