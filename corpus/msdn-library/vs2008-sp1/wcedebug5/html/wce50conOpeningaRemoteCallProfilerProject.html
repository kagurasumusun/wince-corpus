Opening an .icp File in Remote Call Profiler

You can add a Remote Call Profiler function that inserts a profiling mark into the profiling data (.icp) file.

To open an .icp file in Remote Call Profiler

  1. From the File menu of the Remote Call Profiler window, choose Open.
  2. Navigate to the directory where the .icp file is located.
  3. Select the file.

    - or -

    In the File name box, type the name of the file.

  4. Choose Open.
