Keyboard Mapping Test Cases

The Keyboard Mapping Test executes the tux –o –d keymap command line on default execution. There is no additional functionality that you can add to this test. The test does not require your interaction.

The following table shows the test cases for the Keyboard Mapping Test.

Test case Description
50: English Keymap Sends keyboard events and verifies that the events are received and interpreted properly. This test fails if the keyboard mapping does not work correctly or if you run the test on a non-English version of the Microsoft® Windows® CE OS.

Remarks

This test library can have one or more optional command-line entries to change the behavior of the test. To specify one or more optional command-line entries to the test library, you must use the –c command-line option. This option forces Tux to pass the specified string into the test library.
