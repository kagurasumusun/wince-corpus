ICcDatastore::get_OSImageContainer

This method retrieves a high-level run-time image container.

HRESULT get_OSImageContainer(
  ICcOSImageContainer** out_ppiOC
);

Parameters

out_ppiOC
[out, retval] Pointer to the ICcOSImageContainer object.

Return Values

The following table shows return values for this method.

Value Description
E_INVALIDARG Indicates that out_ppiOC is NULL.
E_OUTOFMEMORY Indicates the object could not be created.

Users might be able to free memory and retry the operation.

Requirements

OS Version: Windows 2000, Windows XP Home, Windows XP Pro, Windows Server 2003, and Windows Server 2003 Service Pack 1.
Header: CcDatastore.h.
Link Library: none.
