MISC_EXDIACCESS_SERVICE_INFO

This structure specifies pointers to the two primary components of an eXDI service, the eXDI handler, and the probe handler.

typedef struct _MISC_EXDIACCESS_SERVICE_INFO {
  IUnknown* piunkeXdiHandler;
  IUnknown* piunkProbeHandler;
 } MISC_EXDIACCESS_SERVICE_INFO;

Members

piunkeXdiHandler
Pointer to handler for eXDI service.
piunkProbeHandler
Pointer to IeXdi2ProbeHandler object.

Requirements

OS Version: Windows CE 5.0 and later.
Header: exdi2.h.
