Adding a Key or Entry to the Registry

You can add a registry key or registry entry using the Remote Registry Editor.

To add a key or entry to the registry

  1. In the registry, select a location for the registry key or registry entry.
  2. From the Edit menu, choose New.
  3. Choose Key to add a registry key.

    - or -

    Choose String Value, Multi String Value, Binary Value, or DWORD Value to add a registry entry.

  4. For a registry key, in the text box, type a name for the registry key.

    - or -

    For a registry entry, in the Name box, type a name for the registry entry; then, in the Value box, type a value for the registry entry.

  5. Choose OK.
