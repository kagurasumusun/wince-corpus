Copying the Name of a Registry Key

You can copy a registry key name in the registry of a target device.

To copy the name of a registry key

  1. Select a registry key.
  2. From the Edit menu, choose Copy Key Name.
  3. In the registry, select a location where you can insert a copy of the name of the registry key.
  4. From the Edit menu, choose New and then choose Key.
  5. In the text box, right-click and then choose Paste.
  6. Choose OK.
