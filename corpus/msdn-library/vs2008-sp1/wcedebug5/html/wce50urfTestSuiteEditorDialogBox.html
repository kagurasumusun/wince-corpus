Test Suite Editor Dialog Box

In this dialog box, you can create and manage test suites. A test suite is a selection of tests that is stored by the CETK and can be applied to any target device in the CETK window.

Test Kit
Name of a test kit. To create and manage test suites for a given test kit, from this box, choose the name of the test kit.
Suite
Name of the test suite to edit.
New
Displays a dialog box that allows you to create a new test suite. For more information, see Test Suite Name Dialog Box.
Rename
Displays a dialog box that allows you to rename the test suite shown in the Suite box.
Delete
Deletes the test suite shown in the Suite box.
Tests
Displays the tests that are selected for the test suite shown in the Suite box. In the Tests list, add a test to the suite by selecting the check box for the test. Remove a test from the suite by clearing the check box for the test.
Note   To select the check boxes for all tests, in the Tests list, right-click the node for the test kit or the node for a test category, and then choose Select All. To clear the check boxes for all tests, right-click the node for the test kit or the node for a test category, and then choose Deselect All.
OK
For the test suite shown in the Suite box, saves changes to the test suite and closes the dialog box.
Cancel
Closes this dialog box without saving changes to the test suite shown in the Suite box.
Note   When you select a test suite from the Suite box or add a new test suite, changes to the test suite previously shown in the Suite box are automatically saved.
