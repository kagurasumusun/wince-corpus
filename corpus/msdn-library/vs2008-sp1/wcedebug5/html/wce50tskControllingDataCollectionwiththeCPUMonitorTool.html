Controlling Data Collection with the CPU Monitor Tool

With the CPU Monitor tool, you can stop collecting data from a target device at any time. You can start collecting data again at a time of your choosing. When you start collecting data, the tool deletes the data that is currently stored. Before deleting the data, the tool prompts you to save the collected data to an Extensible Markup Language (XML) file. For more information about saving stored data, see Storing Data Collected by the CPU Monitor Tool.

To stop collecting data from a target device

  • In the CPU Monitor for Windows CE window, from the Server menu, choose Stop.

To start collecting data from a target device

  1. From the Server menu, choose Start.
  2. If you want to save data collected previously by the CPU Monitor tool, choose Yes. Navigate to the directory where you want to save the XML file. In the File name box, type a name for the XML file, and then choose Save.

    - or -

    If you want to discard data collected previously, choose No.

To temporarily stop collecting data from a target device

  • From the View menu, choose Pause Saving Data.

    To resume data collection, from the View menu, again choose Pause Saving Data.
