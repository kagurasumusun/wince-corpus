Collecting Data On A Standalone Device With OSCapture

You can collect CeLog event tracking data on a device that does not have a connection to a development workstation. You can collect data on any OS design; there are no required settings in order to use CeLog or OSCapture.

To use OSCapture on a standalone device

  1. Copy CeLog.dll and OSCapture.exe into \Windows directory of the device.
  2. From a command prompt, run OSCapture.exe.

You may find it useful to use the registry or command-line settings to configure options like the CeLog zones and buffer size. An especially useful option is to turn on the "UI" setting, to make OSCapture display dialog boxes informing you of its operation.

You may also find it useful to configure the registry to launch OSCapture.exe automatically for you during boot. For more information, see Configuring the Process Boot Phase.

OSCapture will execute in the background, buffering CeLog data. It will not write any data to a file until you trigger it.

For more information, see Storing Data from OSCapture in a Log File.
