Viewing Debug Zones for a Process

You can view the contents of the debug zones for a process.

To view debug zones

  • In the Processes window, right-click a process and then choose Debug Zones from the shortcut menu.

    The Debug Zones dialog box displays the debug zones for the selected process. For more information about debug zones, see Understanding the Debug Zones Dialog Box.
