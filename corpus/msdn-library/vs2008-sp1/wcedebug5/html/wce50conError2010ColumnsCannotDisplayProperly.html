Error 2010: Columns Cannot Display Properly

This message can appear when you open a trace view or when you resize a view.

The error occurs when Remote Call Profiler cannot allocate enough space in the view window to display the fixed property column and at least one of the scrollable property columns of each thread in a trace view.

The error can be caused by a combination of the following conditions:

  • Selecting too many items for the view.
  • Selecting too many properties to display in a view.
  • Sizing the fixed property column to a size that is too large.
  • Resizing the window to a size that is too small.
The columns in this view cannot be displayed properly. Resize the window, 
or close this view and reduce the number of threads or properties in the view.
