Displaying Information About a Process

The Remote Process Viewer window displays information associated with each process running on a target device.

To display information about a process

  • In the process pane of the Remote Process Viewer window, select a process running on the target device.

    The thread pane and the module pane display the threads and modules corresponding to the selected process.
