Logging the Contents of the Call Stack Window

At any point, you can save the contents of the Call Stack into a log file

To log the contents of the Call Stack window

  • Right-click the Call Stack window and then choose Log from the shortcut menu.

    – or –

    On the Call Stack window toolbar, choose the Log button.

    The contents of the Call Stack window are displayed on the Log tab of the Output window.
