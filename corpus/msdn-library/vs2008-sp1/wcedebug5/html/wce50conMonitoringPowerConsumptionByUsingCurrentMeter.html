Monitoring Power Consumption by Using a Current Meter and Platform Builder Tools

The output of a current meter that is connected to a target device shows if the device is entering the idle mode. Output from a typical device in idle mode shows many sections of very low power usage, along with spikes of varying intensities that correspond to active CPU usage.

If the current meter output does not show this pattern, it can mean that OEMIdle is not being called, or that OEMIdle is returning too quickly and not actually putting the CPU into idle mode. For more information, see Diagnosing Idle Mode Problems.
