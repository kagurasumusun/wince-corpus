IeXdi2OleAutoServer::GetExceptionAction

This method returns an exception action from an index in the list of exceptions.

HRESULT GetExceptionAction(
  VARIANT dwListIndex,
  VARIANT *pdwAction
);

Parameters

dwListIndex
[in] Index in list of exception codes.
pdwAction
[out, retval] Action to take (notify, ignore, or stop).

Return Values

The following table shows return values for this method.

Value Description
S_OK Indicates the function was successful.
E_FAIL Indicates an unspecified failure.
E_OUTOFMEMORY Failed to allocate necessary memory.
E_INVALIDARG Indicates one or more arguments are invalid.
EXDI_E_COMMUNICATION Indicates a communication error between host driver and debugging target.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: exdi2.h.
Link Library: ole32.lib, oleaut32.lib.
