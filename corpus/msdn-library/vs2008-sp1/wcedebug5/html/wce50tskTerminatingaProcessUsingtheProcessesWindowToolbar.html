Terminating a Process Using the Processes Window Toolbar

You can terminate a process using the Process Window.

To terminate a process using the Processes window toolbar

  • On the Processes window toolbar, choose the Terminate Process button.

    - or -

    Right-click a process in the Processes window and then choose Terminate Process from the shortcut menu.

    The display in the Process window is refreshed and the terminated process no longer appears in the window.

    The Terminate Process option is not available if the target is at a debug stop or if Target Control is not running.
