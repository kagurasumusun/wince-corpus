Platform Builder for Microsoft Windows CE 5.0  

Device Connection Dialog Box

In this dialog box, you can specify how the CETK connects to a target device and then establish a connection to the target device.

Connect
Downloads the Clientside.exe file to the target device and then runs Clientside.exe on the target device. The Clientside.exe application provides a mechanism through which the target device communicates with the CETK.
Use Windows Sockets for the client/server communication
If selected, instructs the CETK to communicate with the target device by using Winsock.

If cleared, instructs the CETK to communicate with the target device by using Platform Manager.

Note   Regardless of the state of the Use Windows Sockets for the client/server communication check box, when you choose Connect, the CETK downloads the Clientside.exe file to the target device by using Platform Manager. For information about manually connecting the target device to the CETK, see Running the CETK Tool Without the CETK Client in the Run-Time Image.
Settings
Opens the Windows CE Platform Manager Configuration dialog box. In the Windows CE Platform Manager Configuration dialog box, you can configure Platform Manager to communicate with the target device. For more information, see Configuring the Connection to a Target Device Using Platform Manager.
Manual Connection Info
Displays information about connecting the CETK to a target device manually. For more information, see Running the CETK Tool Without the CETK Client in the Run-Time Image.
Close
Closes the dialog box without connecting the CETK to a target device.
