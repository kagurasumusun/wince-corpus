Displaying Messages for a Window

You can view the messages send to a window on a target device using Remote Spy.

To display messages for a Window

  1. From the Spy menu, choose Windows List.
  2. In the Windows List (Windows CE) window, select the icon corresponding to a window on the target device.
  3. From the Spy menu, choose Messages.
