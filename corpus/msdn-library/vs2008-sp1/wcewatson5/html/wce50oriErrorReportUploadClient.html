Report Upload Client

The Report Upload Client uploads an error-report dump file created on a device to the watson.microsoft.com web site.

The Upload Client uploads the file using HTTP or HTTPS across the Internet. It either uploads directly from the device, or uses a desktop-based Active Sync pass-through. In both cases, it uses the secure HTTPS protocol.
