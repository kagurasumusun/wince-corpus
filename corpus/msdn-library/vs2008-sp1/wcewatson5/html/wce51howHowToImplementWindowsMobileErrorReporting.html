Platform Builder for Microsoft Windows CE 5.0  

How to Implement Error Reporting

To enable Error Reporting, you must add support to your BSP and reserve enough memory for generated dump files.

Hardware and Software Assumptions

  • You have installed Platform Builder for Windows Mobile 5.0
  Step Topic
1. Familiarize yourself with the binaries that implement Error Reporting. Error Reporting Catalog Items
2. Review the types of dump files that Error Reporting offers. Types of Crash Dump Files
3. Review reserved memory requirements for Error Reporting. Reserving Memory for Error Reporting Dumps
4. Review the OAL programming elements that support Error Reporting. OAL Elements for Error Reporting
5. Initialize dwNKDrWatsonSize Enabling Error Reporting in the OAL
6. Set associated registry values. Error Reporting Modes and Settings
