Error Reporting Features

Windows Mobile Error Reporting supports several features that help protect users.

  • User Consent for Error Reporting Upload

    Windows Mobile Error Reporting supports capturing detailed crash information for all application crashes.

    The crash information potentially contains personal and private information about the user. Because of this, the upload process requires the user's consent before uploading the data for analysis. The proper consent dialogs are included with this feature.

  • Privacy Protection

    Windows Mobile Error Reporting complies with the Federal Trade Commission's Safe Harbor Agreement, including the Fair Information Practice Principles. Together, these govern the collection and use of personal data in the United States.

    In addition, the Safe Harbor agreement is a subset of the European Union Data Protection Directive, to which all companies operating to and from Europe are required to comply.

  • Connection Scheduling

    To avoid the potential of additional cost to the user, the Windows Mobile Error Reporting default setting uploads crash dump files only if a no-cost connection is available.

    If the operator or administration determines that a cellular telephone user has an unlimited plan, the operator can set Error Reporting to upload crash dump files over any available connection.
