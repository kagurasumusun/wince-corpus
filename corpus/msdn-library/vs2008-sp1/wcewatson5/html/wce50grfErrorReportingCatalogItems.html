Platform Builder for Microsoft Windows CE 5.0  

Error Reporting Catalog Items

The following Windows CE Error Reporting Catalog items appear in Platform Builder.

Catalog item Sysgen Variable Description
Error Report Generator SYSGEN_WATSON_DMPGEN Functionality that generates an error report dump upon a second-chance exception, or when called by a capturing function.

For more information, see Error Report Generator.
Error Report Transfer Driver SYSGEN_WATSON_XFER Functionality that generates the transfer driver to move error reports from reserved memory to the file system.

For more information, see Error Report Transfer Driver.
Error Report Control Panel SYSGEN_WATSON_CTPNL Functionality that generates the Control Panel icon and functionality for Error Reporting.

For more information, see Error Report Control Panel.
Report Upload Client SYSGEN_WATSON_CLIENT Functionality that uploads error reports to the Watson web site.

For more information, see Report Upload Client.
Report Upload Client UI SYSGEN_WATSON_CLIENT_UI Functionality that provides a user interface for error report upload.

For more information, see Report Upload Client.
