Report Upload Client OS Design Development

You can include the Report Upload Client when you create your OS design.

OS Design Information

The following table shows OS design information for the Error Report Upload Client.

Concept Description
Dependencies
  • Error Report Generator
  • Error Report Transfer Driver
  • Reserved memory
Hardware considerations Might require target device with user interface.

Modules and Components

The following table shows the components and modules that implement the Report Upload Client.

Item Module Component
Report Upload Client Dw.exe Windows CE Error Reporting
Report Upload Client User Interface DwUI.exe Windows CE Error Reporting

Implementation Considerations

The following table shows the Sysgen variables for Report Upload Client.

Sysgen variable Description
SYSGEN_WATSON_CLIENT Generates the Report Upload Client executable.
SYSGEN_WATSON_CLIENT_UI Generates the Report Upload Client UI DLL.
SYSGEN_WATSON Enables the minimum set of modules for Error Reporting by setting the following SYSGENs:
  • SYSGEN_WATSON_DMPGEN
  • SYSGEN_WATSON_XFER
  • SYSGEN_WATSON_CLIENT
SYSGEN_REPLACE_DWCONN Enables replacement of the connection management code.
SYSGEN_ETHERNET This variable might need to be enabled if the client upload requires Ethernet support.
