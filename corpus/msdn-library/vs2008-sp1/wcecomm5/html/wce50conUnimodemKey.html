Unimodem Key

The Unimodem key contains information specific to the Unimodem device.

The following table shows the registry settings for the HKEY_LOCAL_MACHINE\Drivers\PCMCIA\CompanyX-GenericModem-1234\Unimodem key.

Value : type Description
DevConfig : REG_HEX Default settings for this binary structure are:

20,00, 00,00 78,00,00,00
10,01,00,00, 00,4B,00,00
00,00, 08, 00, 00,00,00,00

Indicates the serial device capabilities (baud, parity, and so on).

DeviceType : REG_DWORD Default setting is 0. Specifies the device type; the values are specified in Unimodem.h at the %_WINCEROOT%\Public\common\oak\inc directory.
FriendlyName : REG_SZ Specifies the name that is displayed to the user by TAPI applications.
TSP : REG_SZ Provides the name of the Telephony Service Provider (TSP) that services this port. This key is set always to Unimodem.dll for version 1 and 1.01 devices.
