Sending a Number in a Message (COM)

Sending a message consists of the following processes:

  • Opening a queue with send access
  • Creating the message
  • Calling the MSMQMessage.Send method
  • Closing the queue

The following procedure and example code show how this is done when sending a message whose body contains a number.

To send a number in a message

  1. Declare MSMQQueueInfo, MSMQQueue, and MSMQMessage objects.
  2. Create a destination queue and open it with send access.
  3. Send the message with a number body type.
  4. Open the destination queue with receive access and retrieve the message.
  5. Verify that the body of the retrieved message is an Integer type.
