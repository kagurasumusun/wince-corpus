IUPnPDevice::PresentationURL

This method returns the URL of the presentation page for the device.

HRESULT get_PresentationURL(
  BSTR* pbstr
);

Parameters

pbstr
[out] Receives a reference to a string that contains the presentation URL for the Web page. This string must be released when it is no longer needed. If the device does not specify a presentation URL, this parameter receives an empty string.

Return Values

S_OK
This method was successful.

Otherwise, the method returns one of the COM error codes defined in WinError.h.

Remarks

This property is optional and can return NULL.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
