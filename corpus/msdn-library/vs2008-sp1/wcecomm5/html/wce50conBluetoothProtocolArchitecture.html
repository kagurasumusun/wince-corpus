Bluetooth Protocol Architecture

The complete protocol stack consists of both Bluetooth-specific protocols and non-Bluetooth-specific protocols.

The protocol stack was designed to enable the re-use of existing protocols for various functions. This also allows for the adaptation of existing applications to work with Bluetooth and to ensure that these applications work smoothly and are interoperable.

Microsoft Windows CE Bluetooth stack complies with Bluetooth specification version 1.2. If you are using hardware that is compatible with this version, the following features are available to you.

  • Faster connection
  • Adaptive frequency hopping

For more information about the Bluetooth stack implementation in Windows CE, see the Bluetooth Protocol Stack.

For more information about the core specification, see the Official Bluetooth Wireless Info Web site
