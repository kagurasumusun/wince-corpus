UPnP Generic Control Point and Device Samples

A few different samples demonstrate use of the generic (that is, non-DCP-specific) UPnP Control Point and Device Host APIs.

These samples are located in the following directories.

  • %_WINCEROOT%\Public\Servers\Oak\Samples\UPnP\DiscoverService
  • %_WINCEROOT%\Public\Servers\SDK\Samples\UPnP\Device (for information about building and using this sample, see the readme.txt file in the Device directory)
  • %_WINCEROOT%\Public\Servers\SDK\Samples\UPnP\UPnPSpy
