EVENTLOG

The EVENTLOG module logs system events. Other modules in the Remote Configuration Framework can query EVENTLOG to obtain information about recent system events.

The following table shows the configurable settings for EVENTLOG.

Value : Type Access Index Description
Eventlog : Array Read-only EventLog If an event log is available, this value lists the names of all the log files that exist on the system. If no event log is available, this value does not exist.
