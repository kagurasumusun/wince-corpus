Remote Configuration Framework Application Development

The Remote Configuration Framework provides the structure for creating Web-based user interfaces for headless devices. Windows CE includes a set of remote UI modules that can be used to customize your device. These modules are located in %WINCEROOT_\PUBLIC\SERVERS\OAK\SAMPLES\REMOTEADMIN\MODULES. You can also use the Remote Configuration Framework interfaces to create a customized Remote UI module that can be added to the OS design of your headless device.
