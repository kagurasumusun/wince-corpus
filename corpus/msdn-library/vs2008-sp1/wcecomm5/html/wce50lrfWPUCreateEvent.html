WPUCreateEvent

This function creates a new event object.

WSAEVENT WPUCreateEvent(
  LPINT lpErrno 
);

Parameters

lpErrno
[out] Pointer to the error code.

Return Values

If no error occurs, this function returns the handle of the event object.

Otherwise, the return value is WSA_INVALID_EVENT and a specific error code is available in lpErrno. The following table shows the possible error code.

Error value Description
WSA_NOT_ENOUGH_MEMORY Not enough free memory available to create the event object.

Remarks

The event object created by this function is manual reset with an initial state of nonsignaled. If a Microsoft Win32® service provider wants auto reset events, it can call the Win32 CreateEvent function directly.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ws2spi.h.
Link Library: Ws2.lib.
