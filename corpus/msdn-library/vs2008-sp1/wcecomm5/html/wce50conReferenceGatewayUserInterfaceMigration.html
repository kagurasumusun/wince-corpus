Reference Gateway User Interface Migration

The reference gateway user interface that was supported in Windows CE 4.2 has been replaced with an enhanced, more user-friendly UI. A user interacting with the gateway UI will notice a significant amount of additional functionality — such as parental controls — and a more refined UI. The name of the gateway UI has been changed from admin2.dll to remoteadmin.dll.

The following table shows the location of the Reference Gateway User Interface Catalog item for Windows CE 5.0.

Catalog Item Location in 4.2 Location in 5.0
Reference Gateway User Interface Shell and User Interface\Web-based User Interface Communication Services and Networking\Networking Features
