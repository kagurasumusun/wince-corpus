Platform Builder for Microsoft Windows CE 5.0  

Networking - General

This section provides links to topics that contain information about general networking technologies supported in Microsoft Windows CE.

In This Section

IPSec v4
Provides information about IPSec support in Windows CE. This technology enables Windows CE-based devices to participate in networks that are secured by IPSec.
Domain Discovery
Provides information about Domain Discovery support in Windows CE. This technology enables a Windows CE device to discover an Active Directory server to query.
Extensible Authentication Protocol
Provides information about Extensible Authentication Protocol (EAP) support in Windows CE. This technology provides a standardized support mechanism for authentication schemes such as token cards, certificates, Public Key, and S/Key.
Firewall
Provides information about IP Firewall support in Windows CE. This technology helps protect the device on which it runs and helps to protect devices on the private side of the gateway. The firewall blocks IP traffic at the IP and transport layers.
Internet Connection Sharing
Provides information about Internet Connection Sharing (ICS) support in Windows CE. This technology supports a collection of technologies that work together to enable multiple devices on a private network to share a single Internet connection.
NDIS Packet Capturing
Provides information about NDIS Packet Capturing support in Windows CE. This technology captures network traffic so that it can be read by the Microsoft Windows Network Monitor (NetMon).
Network Bridging
Provides information about Network Bridging support in Windows CE. This technology interconnects network segments in a multiple-segment network by forwarding frames from one segment to another.
Network Utilities
Provides information about Network Utilities support in Windows CE. This technology provides utilities for troubleshooting various network problems.
TCP/IP
Provides information about TCP/IP support in Windows CE. This technology supports a set of protocols that allow cooperating computers and devices to share resources across a network.
Internet Protocol Version 6
Provides information about Internet Protocol Version 6 (IPv6) support in Windows CE. This technology provides a suite of standard protocols that is the next generation of network layer protocols for the Internet. IPv6 is a connectionless, unreliable protocol used primarily for addressing and routing packets between hosts.
Reference Gateway User Interface
Provides information about the gateway user interface (UI) that is included in Windows CE. This Catalog item includes a set of .htm pages that can be used for a headless gateway device.
Remote Configuration Framework
Provides information about Remote Configuration Framework support in Windows CE. This technology provides the structure for creating Web-based user interfaces for headless devices.
Windows Connect Now
Provides information about Windows Connect Now support in Windows CE. This technology provides a mechanism to automate the configuration of wireless networks (AP and STA). The technology uses the subset of an XML schema supported in Microsoft Windows XP SP2.
Windows Networking API/Redirector
Provides information about Windows Networking API/Redirector support in Windows CE. This technology manages network connections and accesses remote file systems and printers.
Windows Sockets
Provides information about Windows Sockets support in Windows CE. This technology is used to discover and use the communications capabilities of underlying transport protocols. It enables programmers to create advanced Internet, intranet, and other network-capable applications to transmit application data across the wire, independent of the network protocol being used.
