PEER_DATA

This structure contains binary data.

typedef struct peer_data_tag {
  ULONG cbData;
  PBYTE pbData;
} PEER_DATA,*PPEER_DATA;

Members

cbData
Size of pbData, in bytes.
pbData
Pointer to a buffer.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: p2p.h.
Link Library: p2p.lib.
