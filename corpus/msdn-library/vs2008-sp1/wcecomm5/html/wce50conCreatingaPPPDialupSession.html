Creating a PPP Dial-up Session

To create a PPP dial-up session between a Windows CE–based device and a server device, both computers must complete three distinct phases of negotiation before data can be transferred between the two devices. The three phases of negotiation are Phase 1: PPP link establishment, Phase 2: PPP User authentication and Phase 3: Invoking network layer protocol. Once negotiation has completed, Data Transfer can begin.

You can programmatically create a PPP dial-up session using the RasDial function. Instructions for using the RasDial function appear in Starting a RAS Connection.
