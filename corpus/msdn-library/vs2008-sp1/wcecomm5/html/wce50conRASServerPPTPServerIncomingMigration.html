RAS Server/PPTP Server (Incoming) Migration

Effective with Windows CE .NET 4.2, RAS Server/PPTP Server (Incoming) functionality has been separated from the Dial-up Networking Catalog item (SYSGEN_PPP). To retain the previous functionality, add SYSGEN_PPP_SERVER to your cesysgen.bat file.

For general migration information, see Migrating from an Earlier Version of Windows CE.
