DIRECTION

This enumeration represents the directions of media streams in the UPnP AV DCP.

enum DIRECTION
{
  OUTPUT,
  INPUT
};

Elements

OUTPUT
The stream is being sent from the device represented by the current ConnectionManager service.
INPUT
The stream is being received from the device represented by the current ConnectionManager service.

Remarks

The values of this enumeration are used by the IConnectionManager::PrepareForConnection and IConnectionManager::GetCurrentConnectionInfo methods.

For more information about the actions defined by the UPnP AV DCP, see UPnP AV DCP Documentation.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Av_upnp.h.
Link Library: Av_upnp.lib.
C++ Namespace: av_upnp.
