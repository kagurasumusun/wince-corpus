IUPnPService::LastTransportStatus

This method returns the HTTP status of the last IUPnPService::InvokeAction operation or IUPnPService::QueryStateVariable.

HRESULT get_LastTransportStatus(
  long* plValue
);

Parameters

plValue
[out] Receives a reference to the status. If plValue is 200, the operation was successful.

Return Values

S_OK
This method was successful.

Otherwise, the method returns one of the COM error codes defined in WinError.h.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
