IPropertyBagEnum::Clone

This method creates another enumerator with the same enumeration state as the current enumerator.

HRESULT Clone(
  IPropertyBagEnum * ppenum
);

Parameters

ppenum
[out] Destination pointer for the enumerated property bag.

Return Values

This method returns the standard values E_INVALIDARG, E_OUTOFMEMORY, E_UNEXPECTED, and E_FAIL, as well as the following:

S_OK
The method completed successfully.

Requirements

OS Versions: Windows CE 3.0 and later

Header: Obex.h

Library: Uuid.lib
