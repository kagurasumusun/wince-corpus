MSMQQueue.Close

This method closes this instance of the queue.

HRESULT Close(void);

Parameters

None.

Return Values

The following table describes common return values.

Value Description
S_OK Success
E_INVALIDARG One or more arguments are invalid
E_NOTIMPL The function contains no implementation
E_OUTOFMEMORY Out of memory

Remarks

When Message Queuing successfully closes the queue, it sets the MSMQQueue.Handle property to INVALID_HANDLE_VALUE but does not delete the MSMQQueue object.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Mqoai.h.
Link Library: Mqoa.lib.
