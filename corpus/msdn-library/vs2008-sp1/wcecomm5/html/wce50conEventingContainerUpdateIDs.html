Eventing ContainerUpdateIDs

The ContentDirectory service defines a state variable called ContainerUpdateIDs. This state variable is used to notify subscribed control points of changes in the content maintained by the ContentDirectory instance. It consists of a comma-separated list of pairs, in which each pair consists of ContainerID and ContainerUpdateID values.

For more information about the ContainerUpdateIDs state variable, see the ContentDirectory documentation referenced in UPnP AV DCP Documentation.

A ContentDirectory device that uses the UPnP AV Framework should call OnStateChanged once for each pair, using a comma to separate the ContainerID and ContainerUpdateID values. The UPnP AV Framework concatenates all calls to OnStateChanged with this state variable and sends a single string.

For example, to represent two container updates, you should use code similar to the following.

m_pSubscriber->OnStateChanged( av::ContentDirectoryState::ContainerUpdateIDs, L"ContainerID1,UpdateID1" );
m_pSubscriber->OnStateChanged( av::ContentDirectoryState::ContainerUpdateIDs, L"ContainerID2,UpdateID2" );
