Phone-Extension Component

The Phone-Extension component provides a simple message box user interface to allow the user to select the device — the headset or hands-free device, or the cellular phone — that must be used to handle incoming and outgoing calls. Because this component is implemented as a library, you can easily extend the functionality by using the phone-extension interfaces provided by Windows CE.

The following list shows the Phone Extension component functions that are called by the Audio Gateway (AG) service.

  • BthAGPhoneExtDeinit
  • BthAGGetLastDialed
  • BthAGGetNameByPhoneNumber
  • BthAGGetSpeedDial
  • BthAGPhoneExtInit
  • BthAGPhoneExtEvent
  • BthAGOverrideCallIn
  • BthAGOverrideCallOut
  • BthAGSetServiceCallback
