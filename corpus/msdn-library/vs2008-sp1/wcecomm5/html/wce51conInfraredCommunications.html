Infrared Communications

Many Microsoft Windows CE–based devices have an infrared port compliant with the Infrared Data Association (IrDA). The IrDA specifies standards for hardware specifications and software protocols. Windows CE supports an IrDA-compliant stack that enables two IR devices to communicate with each other.

For more information about IrDA standards, see this Official IrDA Web site.
