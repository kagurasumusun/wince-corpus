IUPnPDevices::Count

This method returns the number of devices in the collection.

HRESULT get_Count(
  long* plCount
);

Parameters

plCount
[out] Receives a reference to the number of devices in the collection.

Return Values

S_OK
This method was successful.

Otherwise, the method returns one of the COM error codes defined in WinError.h.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
