Configuring ROUTER1

In Creating the Run-Time Images for the IPv6 Test Lab, you preconfigured ROUTER1 to route packages between Subnet1 and Subnet2 in the IPv6 test lab. You do not need to configure ROUTER1 on the Windows CE-based device.
