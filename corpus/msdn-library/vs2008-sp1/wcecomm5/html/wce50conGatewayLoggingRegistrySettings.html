Gateway Logging Registry Settings

The following table shows the named values for the [HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\EventLog\<LogName>] registry key that you can use to configure Gateway Logging.

Value : type Description
MaxSize : REG_DWORD Default set to 32 KB. Specifies the maximum size, in bytes, of the log file.

If you include Gateway Logging and Parental Controls in your Gateway run-time image, your Gateway device will include the following registry values for the [HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\EventLog\<LogName>] registry key:

  • Parental Controls: Parental Controls stores all log messages to this log.
  • System: All other log messages are stored to this log.
