Viewing the IPv6 Routing Table

You can view the entries in the route table. Internet Protocol (IP) compares the destination address to entries in this table and decides what action to take.

To view an IPv6 route

  • At a command prompt, type ipv6 [-v] rt, and then press ENTER.
