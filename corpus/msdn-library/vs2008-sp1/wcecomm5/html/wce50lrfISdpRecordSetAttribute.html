ISdpRecord::SetAttribute

This method adds or replaces an attribute and its value.

HRESULT SetAttribute(
  USHORT attribute,
  NodeData* pNode
);

Parameters

attribute
[in] Attribute to add or replace.
pNode
[in] Pointer to the NodeData structure containing the attribute data.

Return Values

None.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Bthapi.h, Bthapi.idl.
Link Library: Btdrt.lib.
