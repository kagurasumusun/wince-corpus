RAS Server/PPTP Server (Incoming)

The RAS Server/PPTP Server (Incoming) functionality in Windows CE provides support for a Remote Access Service (RAS) server. You can use RAS in any computing environment that has a wide area network (WAN) or a virtual private network (VPN).

In This Section

RAS Server/PPTP Server (Incoming) OS Design Development
Providesw information about RAS Server support that is helpful when designing and developing a Windows CE OS. This includes dependency information, the modules and components that implement RAS Server, and RAS Server implementation considerations.

Provides an overview of the RAS Server architecture in Windows CE. Describes how to programmatically configure a RAS server. Includes an overview of RAS Server authentication.

Provides a list of the configurable registry settings for RAS Server.
RAS Server/PPTP Server (Incoming) Security
Provides security information for RAS Server and security best practices.

Describes sample code that is available in the %_WINCEROOT%\Public\Common\Oak\Drivers\Netsamp\Rasserver directory.
RAS Server/PPTP Server (Incoming) Reference
Includes reference pages for the RAS Server programming elements.
