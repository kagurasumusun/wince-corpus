BTH_REMOTE_NAME

This structure obtains the user-friendly name of another Bluetooth device. The user-friendly name enables the user to distinguish one Bluetooth device from another.

typedef struct _BTH_REMOTE_NAME {
  BT_ADDR bt;
  WCHAR szNameBuffer[248]; 
} BTH_REMOTE_NAME, *PBTH_REMOTE_NAME;

Members

bt
Target device.
szNameBuffer
Returned name.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ws2bth.h.
