WSAResetEvent

This function resets the state of the specified event object to nonsignaled.

BOOL WSAResetEvent(
  WSAEVENT hEvent
);

Parameters

hEvent
[in] Handle that identifies an open event object handle.

Return Values

If no error occurs, this function returns TRUE. If the function fails, the return value is FALSE. To get extended error information, call WSAGetLastError.

Remarks

This function is used to set the state of the event object to nonsignaled.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winsock2.h.
Link Library: Ws2.lib.
