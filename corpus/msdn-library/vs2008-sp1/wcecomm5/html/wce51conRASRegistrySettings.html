RAS Registry Settings

The RAS registry settings must be added to your hardware platform's Platform.reg file. The Platform.reg file for each platform is in %_WINCEROOT%\Platform\%_TGTPLAT%\Files.

The HKEY_CURRENT_USER\Comm\RasBook\<Connection Name> registry key contains information about the RAS phone book entries for the specified connection. <Connection Name> must match the value specified in the HKEY_CURRENT_USER\ControlPanel\Comm\Cnct registry key.

Value : type Description
DevCfg : REG_HEX Indicates the serial device capabilities (baud, parity, and so on).
Entry : REG_HEX Contains the RAS phone book entry for the connection.
