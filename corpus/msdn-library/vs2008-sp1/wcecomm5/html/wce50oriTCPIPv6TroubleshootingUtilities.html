TCP/IPv6 Troubleshooting Tools

Many network troubleshooting tools are available for Windows CE. Microsoft Network Monitor is an excellent network tracing tool. The full version is part of Microsoft Systems Management Server, and a more limited version is included in Microsoft® Windows® XP.

Note   Changes to the IPv6 addresses and properties are not permanent and will be lost if you reset the device. You can save changes by writing them as command lines in a batch file (.bat) that you can run after restarting the device.

Windows CE includes several tools to troubleshoot network problems. You can add these tools to the OS by adding the Network Utilities Catalog item to your OS design.

For tasks that help you diagnose IPv6 connections, see Diagnosing Connections.
