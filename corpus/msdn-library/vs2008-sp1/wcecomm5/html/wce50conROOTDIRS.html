ROOTDIRS

This module manages and configures root directories for the Remote Configuration Framework.

The following table shows the configurable settings for ROOTDIRS.

Value : Type Access Index Description
Dir : DWORD Read-write Directory If this value is set to 1, a root directory has been specified. If no root directory has been specified, this value does not exist.
