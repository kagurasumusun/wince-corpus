Routing Audio to the Bluetooth Hardware

The AG service provides the functionality for routing audio to the Bluetooth chip. This is done by sending the message, WODM_BT_SCO_AUDIO_CONTROL that the audio driver receives to route audio.

Note   The Audio Gateway service automatically creates a SCO connection to the headset device.

Microsoft® Windows® CE provides a sample audio driver, Btscosnd that processes this message in the WAV_IOControl function to provide audio routing. WODM_BT_SCO_AUDIO_CONTROL offsets the need for the hardware platform to provide this functionality.

For more information about Btscosnd, see Protocol Extension Sample.
