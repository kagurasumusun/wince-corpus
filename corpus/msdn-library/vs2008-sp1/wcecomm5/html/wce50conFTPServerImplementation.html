FTP Server Implementation

The implementation of FTP Server in Windows CE is based on RFC 959. The included FTP server supports the minimum implementation of the FTP protocol defined in RFC 959. This minimum implementation includes configuration values, transfer parameters, and ASCII and Image data types, and allows FTP to operate with a minimum of error messages.

For more information about the FTP protocol, see RFC 959 at the Internet Engineering Task Force Web site.
