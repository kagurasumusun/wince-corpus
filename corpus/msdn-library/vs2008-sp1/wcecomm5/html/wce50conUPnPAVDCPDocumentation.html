UPnP AV DCP Documentation

The UPnP AV Framework provides functionality that makes it easier to implement UPnP AV devices and control points. Everything it provides is built to work with version 1.01 of the UPnP AV device control protocol (DCP). Understanding the UPnP specifications and documents is an important part of building UPnP AV devices and control points.

This UPnP Forum AV Web siteprovides details about version 1.01 of the UPnP AV DCP, including:

  • An overview document that describes the UPnP AV architecture.
  • Detailed documentation about the MediaRenderer and MediaServer devices.
  • Detailed documentation about the AVTransport, ConnectionManager, ContentDirectory, and RenderingControl services.
  • Device and service description XML files. (These XML files are included with Platform Builder in %_WINCEROOT%\Public\Servers\Oak\Samples\UPnP\AV\XML.)

The documentation, by necessity, covers some of the same material in the documentation available from the UPnP Forum. However, it often defers specific implementation details to the UPnP documentation.

For general UPnP information, see this UPnP Forum Web site.
