UPnP AV Classes

The following table shows the different types of UPnP AV Framework classes.

Classes Description
UPnP AV Interface and Implementation Classes Pure virtual classes that define interfaces and classes that derive from these interfaces and provide implementations.
UPnP AV Control Point Utility Classes Classes that provide additional functionality to control point applications.
UPnP Other Utility Classes Class that provides utility functions to UPnP AV Framework devices and control points.
