Audio Gateway Configuration Tool Sample

The Audio Gateway Configuration Tool sample demonstrates using the Audio Gateway Core component IOCTLs to configure the Audio Gateway.

The sample implements the provides the functionality to perform the following tasks:

  • Enable and disable the Bluetooth audio.
  • Close the service level connection to the Audio Gateway.
  • Set the volume of the microphone and the speaker.
  • Enable and disable the power save mode.

The compiled sample generates an executable, Btagconfig.exe.

Sample Location

%_WINCEROOT%\Public\Common\Oak\Drivers\Bluetooth\Sample\AG\Btagconfig
