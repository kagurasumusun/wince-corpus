OID_PAN_DISCONNECT

This object identifier (OID), when set, disconnects a Bluetooth device from the network specified by OID_PAN_CONNECT. You must specify the address of the Bluetooth device in the BD_ADDR structure.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: bt_ddi.h
