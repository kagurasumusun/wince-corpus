Reference Gateway User Interface

Windows CE includes the Reference Gateway User Interface Catalog item. This Catalog item includes a set of .htm pages that can be used for a headless gateway device. The reference gateway user interface that was supported in Windows CE 4.2 has been replaced with an enhanced, more user-friendly UI. A user interacting with the gateway UI will notice a significant amount of additional functionality and a more refined UI.
