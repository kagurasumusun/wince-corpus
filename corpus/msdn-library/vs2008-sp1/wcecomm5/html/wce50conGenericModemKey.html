GenericModem Key

The following table shows the registry settings for the HKEY_LOCAL_MACHINE\Drivers\PCMCIA\CompanyX-GenericModem-1234 key.

Value : type Description
DeviceArrayIndex : REG_DWORD Driver-specific description; this key is set always to 1 for V1 PC Card devices.
DLL Specifies the name of the import DLL, for example Serial.dll.
Prefix Specifies the device prefix, for example COM.
ResetDelay : REG_DWORD Default setting is 300. Specifies a number of milliseconds of delay that are used during the PC Card reset sequence; this key is optional.
