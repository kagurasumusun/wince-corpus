IPv6 gpu NeighborCacheLimit

This command sets the maximum number of entries in the neighbor cache for each interface.

ipv6 [-p] gpu NeighborCacheLimit Number

Parameters

-p
Saves the setting in the registry.
gpu NeighborCacheLimit Number
Specifies the maximum number of entries in the neighbor cache for each interface. The default value is eight entries.
