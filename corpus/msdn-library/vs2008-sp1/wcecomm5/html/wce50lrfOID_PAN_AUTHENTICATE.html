Platform Builder for Microsoft Windows CE 5.0  

OID_PAN_AUTHENTICATE

This object identifier (OID) sets or resets authentication for the specified Bluetooth PAN adapter. To set authentication, pass 1 in the DWORD parameter, otherwise pass zero (0).

Remarks

If you reboot your device the values, set by using this OID, are lost. To persist authentication settings, configure the registry. For more information about the values to set, see Personal Area Network (PAN) Profile Registry Settings

Requirements

OS Versions: Windows CE 5.0 and later.
Header: bt_ddi.h
