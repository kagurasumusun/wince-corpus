Unsupported FTP Commands

The following table shows the FTP commands that the Windows CE minimum implementation of the FTP server does not support.

FTP command Description
ABOR Abort previous subcommand.
ACCT Send account information.
ALLO Allocate specific storage space to receive a file.
APPE Append date to end of file.
REIN Reinitialize.
REST Restart.
SMNT Structure mount.
STAT Status.
STOU Store unique.
