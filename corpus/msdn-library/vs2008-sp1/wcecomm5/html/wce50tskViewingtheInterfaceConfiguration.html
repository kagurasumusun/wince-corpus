Viewing Interface Information

You can view interface information from a command prompt.

To viewing interface information

  1. At the command prompt, type ipv6 [-v] if [IfIndex], where IfIndex indicates the interface index number for which to display information. If no index number is entered, information about all interfaces is displayed.
  2. Press ENTER.
