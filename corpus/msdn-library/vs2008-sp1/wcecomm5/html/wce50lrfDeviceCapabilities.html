DeviceCapabilities

This structure contains information about the device the AVTransport service instance uses for playback and, optionally, for recording.

struct DeviceCapabilities
{
  wstring strPossiblePlayMedia;
  wstring strPossibleRecMedia;
  wstring strPossibleRecQualityModes;
};

Members

strPossiblePlayMedia
Comma-separated list of storage media that the device can play. Contains strings that have constants described in Medium. Corresponds to the PossiblePlaybackStorageMedia state variable.
strPossibleRecMedia
Comma-separated list of storage media onto which the device can record. Contains strings that have constants described in Medium. Corresponds to the PossibleRecordStorageMedia state variable.
strPossibleRecQualityModes
Comma-separated list of recording quality modes supported by the device. Corresponds to the PossibleRecordQualityModes state variable.

Remarks

You can retrieve information about the device using IAVTransport::GetDeviceCapabilities.

The members of this structure correspond to OUT parameters in the AVTransport service's GetDeviceCapabilities action.

For more information about the actions and state variables defined by the UPnP AV DCP, see UPnP AV DCP Documentation.
