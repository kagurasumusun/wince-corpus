Point-to-Point Protocol over Ethernet (PPPoE) Implementation Considerations

You can include the Point-to-Point Protocol over Ethernet (PPPoE) item in your OS design by choosing the Point-to-Point Protocol over Ethernet (PPPoE) item from the Catalog. Choosing this Catalog item sets the appropriate Sysgen variable for enabling Point-to-Point Protocol over Ethernet (PPPoE).

The following table shows the Sysgen variable that enables Point-to-Point Protocol over Ethernet (PPPoE).

Sysgen variable Description
SYSGEN_PPPOE When this variable is set, Point-to-Point Protocol over Ethernet (PPPoE) is included in the run-time image.
