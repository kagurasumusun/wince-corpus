Bluetooth OS Structures

The following table shows the Bluetooth structures with a description of the purpose of each.

Programming element Description
NetworkCallFailedInfo This structure stores information about the call type and error code in case of a failure.
BASEBAND_CONNECTION_DATA This structure stores information about the baseband connection.
