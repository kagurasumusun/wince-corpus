Registering an Advanced Certificate on the Windows CE-based Web Server

After storing the certificate on the Windows CE-based Web server as described in Installing the Certificate on a Windows CE-based Web Server, you must make the Web server aware of the new certificate. This is done by configuring the Web Server Registry Settings.

To register the certificate

  1. Add the following registry key. 
    [HKEY_LOCAL_MACHINE\COMM\HTTPD\SSL] 
"IsEnabled"=dword:1 
"CertificateSubject"="<Name of the certificate>"
Note   To include this configuration in the run-time image, add this registry setting in %_WINCEROOT%\PBWorkspaces\<Workspace name>\<Hardware platform>\Oak\Files\Project.reg file and rebuild the image.
  1. Open the Target Control pane in Platform Builder by selecting CE Target Control from the Target menu.
  2. At the Target Control prompt, type the following command to refresh the Web server. 
    s services -d refresh htp0:

    You must refresh the Web server so that the server can access the updated certificate information. You can use the command line option for Services.exe, if the AllowCmdLine value is set to 1 under the HKEY_LOCAL_MACHINE\Services registry key. For more information about using these options, see Using Services.exe from the Command Line.

    Note   You must refresh the Web server after installing the certificate on the device, even if the registry settings are configured in the run-time image.

The SSL certificate is now registered on the device. This enables you to browse secure Web sites (https://).
