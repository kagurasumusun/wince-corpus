SMBPRINT

This module manages and configures the SMB print server for the Remote Configuration Framework.

The following table shows the configurable settings for SMBPRINT.

Value : Type Access Index Description
Description : STRING Read-only Not applicable Contains a description for the printer device.
Model : STRING Read-only Not applicable Specifies the printer model.
