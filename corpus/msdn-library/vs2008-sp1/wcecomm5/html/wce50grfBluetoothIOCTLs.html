Bluetooth Application Development IOCTLs

The following table shows the Bluetooth IOCTLs with a description of the purpose of each.

Programming element Description
IOCTL_BLUETOOTH_GET_PEER_DEVICE Retrieves the address of a peer Bluetooth device.
IOCTL_BLUETOOTH_GET_RFCOMM_CHANNEL Determines the RFCOMM channel assigned when RFCOMM_CHANNEL_MULTIPLE is used with PORTEMUPortParams to configure the server channel to be auto-bound.
