IP Firewall Enumerations

The following table shows the firewall enumerations.

Programming element Description
FW_ACTIONS This enumeration defines values for the firewall actions for a packet.
FW_DAYS This enumeration defines values for days of the week, weekdays, or weekends.
FW_DIRECTIONS This enumeration defines values that specify traffic direction.
FW_RULE_FLAGS This enumeration defines values that specify rule flags.
FW_RULE_MASKS This enumeration defines values that specify rule masks.
