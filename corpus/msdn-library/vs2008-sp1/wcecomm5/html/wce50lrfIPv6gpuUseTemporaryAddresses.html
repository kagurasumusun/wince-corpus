IPv6 gpu UseTemporaryAddresses

This command determines whether temporary addresses are used at a global level.

ipv6 [-p] gpu UseTemporaryAddresses [yes|no|always|Counter]

Parameters

-p
Saves the UseTemporaryAddresses setting in the registry.
UseTemporaryAddresses [yes|no|always|Counter]
Specifies whether to use temporary addresses. The following list shows how the parameters are used for the interface:
  • Yes generates one temporary address for the interface.
  • No does not generate any temporary address for the interface.
  • Always generates a random interface address for each address assigned to the interface.
  • Counter indicates that temporary addresses use interface identifiers. Typically, you would use this for test purposes.
