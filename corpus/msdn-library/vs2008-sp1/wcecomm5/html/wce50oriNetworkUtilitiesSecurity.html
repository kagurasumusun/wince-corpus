Network Utilities Security

To isolate internal data packets from exposure to the Internet, you can add a network firewall. This also prevents random Internet traffic from entering your internal network.

Network Utilities includes the IPv6tun command-line tool that configures the 6to4 and ISATAP tunneling capabilities. When using tunneling protocols, be sure to enable the IP Firewall as appropriate to minimize the internal network's vulnerability.

For information about configuring the IP firewall to properly manage traffic destined for an internal network, see IP Firewall OS Design Development.

Ports

No specific ports are used for Network Utilities.

Registry Settings

There are no registry settings for Network Utilities.
