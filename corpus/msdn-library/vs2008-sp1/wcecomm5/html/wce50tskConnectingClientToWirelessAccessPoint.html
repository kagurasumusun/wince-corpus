Connecting a Client to the Wireless Access Point

After you configure your wireless access point, you can connect a wireless client computer to it and browse the Remote Configuration pages.

To connect a wireless client to the wireless access point

  1. Insert a wireless network adapter into your client computer.
  2. On your client computer from the Start menu, choose Connect to, and then choose Wireless Network Connection.
  3. In Wireless Network dialog box, select the Wireless Networks tab.
  4. If your access point has been configured correctly, TESTAP will in the Available networks box. Choose Configure. The Wireless network properties dialog box appears.
  5. On the Association tab, clear The key is provided for me automatically.
  6. In the Network key box, type the 10-digit WEP key you created in Step 11 in Using the Remote Configuration Tool to Configure the Access Point, confirm the WEP key, choose OK, and then choose OK again.

    The client computer will associate with and then connect to the wireless access point.

  7. On your client computer, open Internet Explorer.
  8. To launch the configuration pages for your access point, in the address bar of the browser, type http://192.168.0.1, which is the default access point IP address used in this example, and then press ENTER.
  9. A dialog box appears asking for a user name and password. Enter the following information, and then choose OK.
    Item Text to be entered
    User Name admin
    Password <the password you created for your access point>

    The Windows CE Remote Management Tool dialog box appears. You can now configure additional options for your wireless access point.
