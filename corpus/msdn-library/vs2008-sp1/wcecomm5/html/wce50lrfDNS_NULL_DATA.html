DNS_NULL_DATA

This structure represents NULL data for a DNS resource record.

typedef struct {
  DWORD dwByteCount;
  BYTE Data[1];
} DNS_NULL_DATA, *PDNS_NULL_DATA;

Members

dwByteCount
[in] Number of bytes represented in Data.
Data
[in] Null data.

Remarks

This structure is used in conjunction with the DNS_RECORD structure to programmatically manage DNS entries.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Windns.h.
