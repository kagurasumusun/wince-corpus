Auto Dial Registry Subkeys

You can configure auto dial by using registry entries under the HKEY_LOCAL_MACHINE\Comm\AutoDial registry key. Auto dial reads these registry values every time that auto dial attempts to make a connection.

For information about the registry settings that control auto dial, see Auto Dial Registry Settings.
