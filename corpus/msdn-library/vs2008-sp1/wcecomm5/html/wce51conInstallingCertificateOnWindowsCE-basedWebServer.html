Installing the Certificate on a Windows CE-based Web Server

After requesting the advanced certificate as described in Retrieving an Advanced Certificate, you must install and register the certificate on the Windows CE-based device functioning as a Web server.

Note   The following procedure only applies to Windows CE -based devices that have a control panel UI.

To install the certificate on your device

  1. Copy the certificate (.cer file) and the private key (.pvk file) from your development workstation to your Windows CE-based device.
  2. On the device, select the Start-> Settings-> Control Panel -> Certificates menu.
  3. On the Certificates dialog box, select My Certificates from the drop down list on the Stores tab.
  4. Select Import.. to import the certificate file (.cer).
  5. On the Import Certificate or Key dialog box, select the From a File option and choose OK.
  6. On the Select a Certificate File dialog box, select the .cer file and choose OK.
  7. The certificate name is displayed in the list of personal digital certificates.
  8. Choose the My Certificates store
  9. Select Import.. to import the private key file (.pvk).
  10. On the Import Certificate or Key dialog box, select the From a File option and choose OK.
  11. On the Select a Certificate File dialog box, choose Private Keys in the Type list, select the .pvk file, and choose OK.
  12. Enter the password for the private key in the Private Key Password dialog box and choose OK.
  13. Choose OK to close the Certificates dialog box.

The certificate is now available for you to register on the device. For more information, see Registering an Advanced Certificate on the Windows CE-based Web Server.
