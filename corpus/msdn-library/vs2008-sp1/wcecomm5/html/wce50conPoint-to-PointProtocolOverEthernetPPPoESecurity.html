Point-to-Point Protocol over Ethernet (PPPoE) Security

PPPoE supports both the Kerberos and Secure Sockets Layer (SSL) authentication mechanisms.

Sensitive information can be encrypted before being sent over the network. This prevents unauthorized users from viewing data in transmitted packets.
