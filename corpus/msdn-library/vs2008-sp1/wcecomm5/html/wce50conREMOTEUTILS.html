REMOTEUTILS

The REMOTEUTILS module manages the registry entries for each Remote UI module. It also manages other networking data, such as reboot information and IP address of the connecting client. For more information, see Remote Configuration Framework Registry Settings.

Value : Type Access Index Description
Registry : STRING Read-write user-assigned variable name Specifies the registry entry to be created and read.
DelRegistry : STRING Write-only user-assigned variable name Specifies the registry entry to be deleted.
Reboot : STRING Write-only Not applicable If this variable is present, the device will reboot.
ClientIP : STRING Read-only Not applicable Specifies the IP of the connecting client.
