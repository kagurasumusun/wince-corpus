PPTP

PPTP is a network protocol that adds a security infrastructure for the transfer of data from a remote client to a private enterprise server, thus creating a virtual private network (VPN) by using TCP/IP-based data networks.

In This Section

Presents information about PPTP that is helpful when designing and developing a Windows CE OS. This includes dependency information, the modules and components that implement PPTP, and PPTP implementation considerations.

Provides information about the PPTP implementation in Windows CE. Describes how to programmatically establish a PPTP connection.
PPTP Registry Settings
Provides information about the configurable registry settings for PPTP.

Provides security information for PPTP including security best practices.

Provides information about issues to consider when migrating to a newer version of Windows CE.
PPTP Samples
Provides a code sample that shows how to establish a PPTP connection.
