Socket Options

This section describes Winsock Socket Options for Windows CE. Use the getsockopt and setsockopt functions for more getting and setting socket options. To enumerate protocols and discover supported properties for each installed protocol, use the WSAEnumProtocols function.

The following list shows the possible protocols.

  • IPPROTO_IP
  • IPPROTO_IPV6
  • IPPROTO_TCP
  • IPPROTO_UDP
  • SOL_SOCKET
  • SOL_IRLMP
