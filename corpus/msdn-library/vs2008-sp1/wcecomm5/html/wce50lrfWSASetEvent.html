WSASetEvent

This function sets the state of the specified event object to signaled.

BOOL WSASetEvent(
  WSAEVENT hEvent
);

Parameters

hEvent
[in] Handle that identifies an open event object.

Return Values

If the function succeeds, the return value is TRUE.

If the function fails, the return value is FALSE. To get extended error information, call WSAGetLastError.

Remarks

This function sets the state of the event object to be signaled.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winsock2.h.
Link Library: Ws2.lib.
