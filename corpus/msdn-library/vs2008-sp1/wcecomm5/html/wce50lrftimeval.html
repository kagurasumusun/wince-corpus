timeval

This structure is used to specify time values.

struct timeval {
  long tv_sec;
  long tv_usec;
};

Members

tv_sec
Time value, in seconds.
tv_usec
Time value, in microseconds.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winsock2.h.
