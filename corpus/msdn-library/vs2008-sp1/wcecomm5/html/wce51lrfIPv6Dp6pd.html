IPv6 dp6pd

This command lists the prefix obtained by using DHCPv6 for the specified interface.

ipv6 dp6pd [ifindex]

Parameters

p
Saves the setting in the registry.
IfIndex
Indicates the interface index number for which to obtain the prefix.
