ISdpRecord::SetAttributeFromStream

This method adds or replaces an attribute and its value from a raw SDP stream.

HRESULT SetAttributeFromStream(
  USHORT attribute,
  UCHAR* pStream,
  ULONG size
);

Parameters

attribute
[in] Attribute to add or replace.
pStream
[in] Pointer to a stream that contains the desired attribute data.
size
[in] Number of bytes of the stream specified by the pStream parameter.

Return Values

None.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Bthapi.h, Bthapi.idl.
Link Library: Btdrt.lib.
