Network Bridging OS Design Development

Network Bridging in Microsoft® Windows® CE allows you to connect multiple Ethernet network segments into a single subnet by forwarding frames from one segment to another.

The following table shows the Sysgen variables for Network Bridging.

Sysgen variable Description

SYSGEN_BRIDGE2 When this variable is set, a second instance of Network Bridging is included in the OS design.
