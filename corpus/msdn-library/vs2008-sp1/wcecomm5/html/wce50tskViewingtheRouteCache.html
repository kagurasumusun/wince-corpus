Viewing the Route Cache

You can view the route cache that includes the destination address, the interface identifier and next-hop address, the interface identifier and address used as a source address when sending to the destination, and the path MTU for the destination.

To view the route cache

  1. At a command prompt, type ipv6 rc [IfIndex [Address]], where IfIndex indicates the interface index number.

    If you specify the interface and address, the route cache entry used to reach the address through the interface is displayed. Otherwise, all route cache entries are displayed.

  2. Press ENTER.
