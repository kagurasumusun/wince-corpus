Platform Builder for Microsoft Windows CE 5.0  

VERSION

This module manages and configures versioning and IDs of devices on the network.

The following table shows the configurable settings for VERSION.

Value : Type Access Index Description
Major : DWORD Read-only Not applicable Specifies the major version number of the device.
Minor : DWORD Read-only Not applicable Specifies the minor version number of the device.
BuildSysVer : DWORD Read-only Not applicable Specifies the version of the build system.
BuildVer : DWORD Read-only Not applicable Specifies the version of the build.
PresetId : WCHAR Read-only Not applicable Specifies the preset ID.
PlatformID : CHAR Read-only Not applicable Specifies the platform ID.
