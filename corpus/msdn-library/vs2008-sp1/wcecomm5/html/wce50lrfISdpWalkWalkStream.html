ISdpWalk::WalkStream

This method walks a raw SDP stream.

HRESULT WalkStream(
  UCHAR elementType,
  ULONG elementSize,
  UCHAR* pStream
);

Parameters

elementType
[in] Type of element.
elementSize
[in] Size of the element.
pStream
[in] Pointer to the stream.

Return Values

None.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Bthapi.h, Bthapi.idl.
Link Library: Btdrt.lib.
