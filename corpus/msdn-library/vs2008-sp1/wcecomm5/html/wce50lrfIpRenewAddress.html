IpRenewAddress

This function renews a lease on an IP address previously obtained through Dynamic Host Configuration Protocol (DHCP).

DWORD IpRenewAddress(
  PIP_ADAPTER_INDEX_MAP AdapterInfo 
);

Parameters

AdapterInfo
[in] Pointer to an IP_ADAPTER_INDEX_MAP structure identifying the adapter associated with the IP address to renew.

Return Values

Returns NO_ERROR if successful. If the function fails, it returns an error code. For a complete list of error codes, see Error Values or the SDK header file Winerror.h.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Iphlpapi.h.
Link Library: Iphlpapi.lib.
