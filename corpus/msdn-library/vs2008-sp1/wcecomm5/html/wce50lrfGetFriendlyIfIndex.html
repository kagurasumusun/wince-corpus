GetFriendlyIfIndex

This function takes an interface index and returns a backward-compatible interface index, that is, one that uses only the lower 24 bits.

DWORD GetFriendlyIfIndex(
  DWORD IfIndex 
);

Parameters

IfIndex
[in, out] An interface index from which the backward-compatible or friendly interface index is derived.

Return Values

Returns NO_ERROR if successful. If the function fails, it returns an error code. For a complete list of error codes, see Error Values or the SDK header file Winerror.h.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Iphlpapi.h.
Link Library: Iphlpapi.lib.
