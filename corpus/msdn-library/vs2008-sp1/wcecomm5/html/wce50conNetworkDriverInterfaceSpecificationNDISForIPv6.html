Network Driver Interface Specification (NDIS) for IPv6

Microsoft networking protocols use the Network Driver Interface Specification (NDIS) interface to communicate with network card drivers. IPv6 uses NDIS in the same manner as IPv4.

For more information about NDIS and IPv4, see Network Driver Interface Specification (NDIS).
