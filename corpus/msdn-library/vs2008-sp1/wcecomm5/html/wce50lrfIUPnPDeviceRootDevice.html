IUPnPDevice::RootDevice

This method returns the topmost device in the device tree. The root device represents a physical object.

HRESULT get_RootDevice(
  IUPnPDevice** ppudRootDevice
);

Parameters

ppudRootDevice
[out] Receives a reference to an IUPnPDevice:IDispatch object that describes the root device. This reference must be released when it is no longer required.

Return Values

S_OK
This method was successful.

Otherwise, the method returns one of the COM error codes defined in WinError.h.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
