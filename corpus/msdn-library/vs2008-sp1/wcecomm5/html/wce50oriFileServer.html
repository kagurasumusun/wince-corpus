File Server

The File Server functionality in Microsoft® Windows® CE enables clients to access files and other resources over the network.

In This Section

File Server OS Design Development
Provides information about File Server support that is helpful when designing and developing a Windows CE OS. This includes dependency information, the modules and components that implement File Server, and File Server implementation considerations. Describes how to configure the File Server through the registry and how to configure the FATFS cache parameter.
File Server Application Development
Provides an overview of the File Server technology and describes how to programmatically reload the server settings.
How to Configure a File Server
Provides step-by-step instructions on building and configuring a file server device.
File Server Registry Settings
Provides a list of the configurable registry settings for File Server.
File Server Security
Provides security information for File Server and security best practices.
File Server Migration
Provides information about issues to consider when migrating to a newer version of Windows CE.
File Server Samples
Provides sample-related information for File Server.

Related Sections

Services.exe
Provides a comprehensive overview of the Core Server support in Windows CE. Describes how to use the Services.exe API to activate, register, control, and stop a service programmatically. Includes the configurable registry settings for Services.exe and reference pages for the Services.exe programming elements.
