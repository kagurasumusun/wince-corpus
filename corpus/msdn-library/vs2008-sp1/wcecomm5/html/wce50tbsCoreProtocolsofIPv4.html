Core Protocols of IPv4

The following table shows the core protocols of IPv4.

Protocol Description
Address Resolution Protocol Address Resolution Protocol (ARP) performs IPv4 address-to-Media Access Control (MAC) address resolution for outgoing packets.
Internet Control Message Protocol (ICMP) Internet Control Message Protocol (ICMP) is a network layer protocol that delivers flow control, error messages, routing, and other data between Internet hosts.
Internet Group Management Protocol (IGMP) IGMP is used for IPv4 multicast to exchange membership status data between IPv4 routers that support multicasting and members of multicast groups.
