IPSec Functions

The following table shows the IPSec functions.

Function Description
StartIPSec Starts IPSec.
StopIPSec StopsIPSec.
IsIPSecRunning Determines if IPSec is already running.
SetIPSecMode Used to configure the IPSec mode.
ResetIPSecMode Resets the current IPSec mode if a mode has been previously specified.
