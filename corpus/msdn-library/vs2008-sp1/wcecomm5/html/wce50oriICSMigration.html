ICS Migration

There are no specific steps for migrating ICS from earlier versions of Windows CE.

Windows CE 5.0 includes Gateway Logging that writes various system events to a log file on the Gateway device. For more information, see Gateway Logging and Gateway Logging Registry Settings.

For general migration information, see Migrating from an Earlier Version of Windows CE.
