Platform Builder for Microsoft Windows CE 5.0  

Plug and Play

Windows CE supports automatic and dynamic detection and configuration of devices attached to extendable bus architectures, such as PCMCIA and USB. The TCP/IP stack and NDIS support in Windows CE 3.0 and later have been modified to handle dynamic network interfaces that can be added or removed at any time. This modification allows support for expansion through bus types currently not supported natively in Windows CE.
