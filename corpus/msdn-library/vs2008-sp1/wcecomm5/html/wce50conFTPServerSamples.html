Platform Builder for Microsoft Windows CE 5.0  

FTP Server Samples

Windows CE includes source code for a sample FTP Server implementation in %_WINCEROOT%\Public\Servers\Sdk\Samples\Ftpd. This code sample is intended for use by original equipment manufacturers (OEMs). Windows CE provides the FTP server source code as is, so that you can customize its implementation for your specific requirements. FTP is used for copying files to and from remote computer systems over a network using TCP/IP.
