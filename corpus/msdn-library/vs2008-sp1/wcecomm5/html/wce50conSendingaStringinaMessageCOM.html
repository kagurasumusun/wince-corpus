Sending a String in a Message (COM)

Sending a message consists of the following tasks:

  • Opening a queue with send access
  • Calling the MSMQMessage.Send method
  • Closing the queue

The following procedure and example code show how this is done when sending a message whose body contains a string.

To send a string in a message

  1. Declare the objects needed to send a message.

    The example uses MSMQQueueInfo, MSMQQueue, and MSMQMessage objects.

  2. Open the destination queue with send access.

    This example creates a public queue on the local computer if the specified queue does not exist.

  3. Call Send to send the string message.
  4. Call MSMQQueue.Close to close the queue.

For a code example using C++ COM, see C++ COM Code Example: Sending a String.
