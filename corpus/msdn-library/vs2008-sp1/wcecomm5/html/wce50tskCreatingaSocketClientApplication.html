Creating a Socket Client Application

To create a socket client application

  1. Perform name resolution to obtain a list of addresses to communicate with.
  2. Open a socket with the socket function using the properties returned in the addrinfo structure returned by the getaddrinfo function.
  3. Attempt to connect to the server with the connect function using the addresses returned by getaddrinfo.
  4. Exchange data with a server, using the send/sendto and recv/recvfrom functions.
  5. For connection-oriented sockets, shut down the socket with the shutdown function.
  6. Close the socket with the closesocket function.

For an example of a socket client application, see Socket Client.
