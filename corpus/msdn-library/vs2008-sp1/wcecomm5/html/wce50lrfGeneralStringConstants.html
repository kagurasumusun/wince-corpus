General String Constants

The strings represented by these constants are valid states for multiple state variables.

For example, the NotImpl constant is a valid value for the AVTransport service's PlaybackStorageMedium variable, AVTransport's RecordMediumWriteStatus, and so on. For more information about the state variables and valid values defined by the UPnP AV DCP, see UPnP AV DCP Documentation.

Because they are used by multiple state variables, unlike other constants like those defined in TransportState, these constants are not defined in a specific C++ namespace (they are defined in the normal av_upnp namespace used by all UPnP AV Framework programming elements).

const LPCWSTR
  NotImpl                 = L"NOT_IMPLEMENTED",
  OK                      = L"OK";

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Av_upnp.h.
Link Library: Av_upnp.lib.
C++ Namespace: av_upnp.
