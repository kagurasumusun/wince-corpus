Parental Controls OS Design Development

Windows CE provides support for parental controls. Parental controls allow administrators of private networks to create rules to block objectionable Web sites, which prevents specific users from accessing the content.

OS Design Information

The following table shows operating system design information for Parental Controls.

Concept Description
Dependencies Web Proxy/
Hardware considerations Parental Controls is designed to be used in a gateway setting. For more information, see Gateway Hardware Requirements.

Modules and Components

The following table shows the components and modules that implement Parental Controls.

Item Module Component
Parental Controls pcfilter, pclogdll None

Parental Controls Implementation Considerations

The following table shows the Sysgen variable for Parental Controls.

Sysgen variable Description
SYSGEN_PARENTAL_CONTROL When this variable is set, the Parental Controls Catalog item is included in the OS design.
