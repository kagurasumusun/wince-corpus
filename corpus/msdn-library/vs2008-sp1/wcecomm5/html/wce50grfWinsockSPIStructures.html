Winsock SPI Structures

The following table shows the Winsock SPI structures that are supported in Windows CE.

Programming element Description
NSP_Routine This structure contains information regarding all the functions implemented by a service provider.
WSATHREADID This structure enables a provider to identify a thread to run.
WSPDATA This structure is used to store information about Windows sockets

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Ws2spi.h.
