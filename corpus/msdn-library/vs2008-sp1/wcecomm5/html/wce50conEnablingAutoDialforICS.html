Enabling Auto Dial for ICS

The following steps show how to enable auto dial for a Windows CE-based device.

To enable auto dial

  • Set the HKEY_LOCAL_MACHINE\Comm\AutoDial\Enabled registry key to a non-zero value.

The auto dial routines in Windows CE are called only when network packets are dropped because an error occurred when looking up information in a route table, or on requests from the DNS proxy or local name resolver. Calling the gethostbyname or getaddrinfo function on the local host does not initiate auto dial. After auto dial has established the network connection, auto dial is not called again. After a configurable period of time, however, auto dial disconnects the device.

To change the amount of time before auto dial disconnects the device

  • Set the HKEY_LOCAL_MACHINE\Comm\AutoDial\IdleTimeoutMS registry key equal to the number of seconds that you want auto dial to wait before auto dial disconnects an idle device.
