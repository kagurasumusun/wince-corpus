SNTP Migration

For Windows CE 5.0, the Simple Network Time Protocol (SNTP) technology has been componentized. As a result, the SYSGEN_TIMESVC Sysgen variable has been replaced with the following three Sysgen variables.

Sysgen variable Catalog item
SYSGEN_TIMESVC_API SNTP Automatic Updates and Server Synchronization
SYSGEN_TIMESVC_DST SNTP Client with DST
SYSGEN_TIMESVC_SNTP SNTP Server

In Windows CE 5.0 and later, SNTP supports multiple servers. The name of each server can be specified in the Server registry key. Windows CE 4.2 supports only single servers . For more information on the Server registry key, see SNTP Registry Settings.
