ISdpRecord::GetAttributeAsStream

This method retrieves the value of an attribute as a raw SDP stream.

HRESULT GetAttributeAsStream(
  USHORT attribute,
  CHAR** ppStream,
  ULONG* pSize
);

Parameters

attribute
[in] Attribute to retrieve.
ppStream
[out] Destination pointer for the raw SDP stream that contains the value of the attribute.
pSize
[out] Number of bytes of the allocated stream at ppStream.

Return Values

None.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Bthapi.h, Bthapi.idl.
Link Library: Btdrt.lib.
