IPv6 ppu

This command updates the prefix policy table. Entries in the prefix policy table can modify the behavior of source and destination address selection. 

ipv6 [-p] ppu Prefix precedence PrecedenceValue srclabel SourceLabelValue [dstlabel DestinationLabelValue]

Parameters

-p
Saves the setting in the registry.
Prefix
Specifies the prefix for which to add a policy in the policy table.
precedence PrecedenceValue
Specifies the precedence value used for sorting destination addresses in the policy table.
srclabel SourceLabelValue
Specifies the source label and value.
dstlabel DestinationLabelValue
Specifies the destination label and value.

Remarks

The source and destination labels and values are used for policies that prefer a particular source address prefix for use with a destination address prefix.

For more information about the site prefix table, see the Internet draft titled "Default Address Selection for IPv6."

For information about the prefix policy table, see Default Address Selection for IPv6.
