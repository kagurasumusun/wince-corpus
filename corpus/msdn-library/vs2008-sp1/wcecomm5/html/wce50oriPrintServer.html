Print Server

The Print Server functionality in Windows CE enables you to share and access printers over the network. Print Server uses the Common Internet File System (CIFS). Which is an extension of the Server Message Block (SMB) file sharing protocol. CIFS enables a network-enabled application to access and manipulate files and directories on a remote server in the same way that the application accesses and manipulates files and directories on the local system.
