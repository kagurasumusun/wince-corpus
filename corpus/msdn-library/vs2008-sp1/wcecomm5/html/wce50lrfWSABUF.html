WSABUF

This structure enables the creation or manipulation of a data buffer.

typedef struct __WSABUF {
  u_long len;
  char FAR* buf;
} WSABUF, FAR* LPWSABUF;

Members

len
Length of the buffer.
buf
Pointer to the buffer.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Winsock2.h.
