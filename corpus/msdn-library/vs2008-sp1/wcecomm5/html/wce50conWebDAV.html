WebDAV

Web Distributed Authoring and Versioning (WebDAV) is a remote file configuration protocol defined by RFC 2518 that uses HTTP as its transport. WebDAV clients can view, modify, move, copy, and delete files on a WebDAV server across the Internet. By using Microsoft Windows XP and later, you can map virtual roots to drive letters as if they were SMB network shares.

Windows CE 4.2 and later implement WebDAV as an optional part of the Web Server. You can only use WebDAV if it is included in the device along with the Web Server.
