IUPnPDevice::IsRootDevice

This method is used to determine if the device is the topmost device in the device tree.

HRESULT get_IsRootDevice(
  VARIANT_BOOL* pvarb
);

Parameters

pvarb
[out] Receives a reference to a VARIANT_BOOL that contains the value VARIANT_TRUE if the device is the topmost device in the device tree; otherwise, it contains the value VARIANT_FALSE.

Return Values

S_OK
This method was successful.

Otherwise, the method returns one of the COM error codes defined in WinError.h.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
