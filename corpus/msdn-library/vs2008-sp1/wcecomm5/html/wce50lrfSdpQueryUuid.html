SdpQueryUuid

This structure contains the UUID to query for attribute or attribute service searching.

typedef struct _SdpQueryUuid {
  SdpQueryUuidUnion u;
  USHORT uuidType;
} SdpQueryUuid;

Members

u
SdpQueryUuidUnion value. The value can be SDP_ST_UUID128, SDP_ST_UUID32, or SDP_ST_UUID16.
uuidType
UUID type.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Bthsdpdef.h.
