ISdpWalk:IUnknown

This interface walks the stream.

Note   The application developer must implement this interface and pass a pointer for it to the IsdpNodeContainer::Walk method or the IsdpRecord::Walk method.

Methods

The following table shows the methods for this interface in alphabetical order. Like all COM interfaces, this interface inherits the methods for the IUnknown interface.

Method Description
WalkNode Walks an SDP node.
WalkStream Walks an SDP stream.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Bthapi.h, Bthapi.idl.
Link Library: Btdrt.lib.
