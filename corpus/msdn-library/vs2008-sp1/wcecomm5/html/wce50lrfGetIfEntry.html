Platform Builder for Microsoft Windows CE 5.0  

GetIfEntry

This function retrieves information for the specified interface on the local computer.

DWORD GetIfEntry(
  PMIB_IFROW pIfRow
);

Parameters

pIfRow
[in, out] Pointer to a MIB_IFROW structure containing information for an interface on the local computer. The dwIndex member of MIB_IFROW must be set to the index of the interface for which to retrieve information.

Return Values

Returns NO_ERROR if successful. If the function fails, it returns an error code. For a complete list of error codes, see Error Values or the SDK header file Winerror.h.

Requirements

OS Versions: Windows CE 3.0 and later.
Header: Iphlpapi.h.
Link Library: Iphlpapi.lib.
