PNRP Enumerations

The following table shows the PNRP enumerations with a description of the purpose of each.

Programming element Description
PNRP_CLOUD_FLAGS This enumeration specifies the validity of a cloud name.
PNRP_CLOUD_STATE This enumeration specifies the different states a PNRP cloud can be in.
PNRP_RESOLVE_CRITERIA This enumeration specifies the criteria that PNRP uses to resolve searches.
