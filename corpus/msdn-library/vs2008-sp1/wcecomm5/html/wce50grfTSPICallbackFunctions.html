TSPI Callback Functions

The following table shows the TSPI callback with a description of the purpose of each.

Programming element Description
ASYNC_COMPLETION Implemented by TAPI and supplied to the service provider as a parameter to the TSPI_providerInit function.
LINEEVENT Implemented by TAPI and supplied to the service provider as a parameter to the TSPI_lineOpen function.
PHONEEVENT Implemented by TAPI and supplied to the service provider as a parameter to the TSPI_phoneOpen function.
