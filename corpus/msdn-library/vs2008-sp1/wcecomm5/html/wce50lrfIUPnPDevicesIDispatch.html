IUPnPDevices:IDispatch

This interface enumerates a collection of devices.

The following table lists and describes this interface's members.

Method Description
_NewEnum Returns the enumerator interface for the collection. This method is not visible in Microsoft® Visual Basic® .NET; use the for...each programming construct instead.
Count Returns the number of devices in the collection.
Item Returns an IUPnPDevice:IDispatch object for the specified device in the collection.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
