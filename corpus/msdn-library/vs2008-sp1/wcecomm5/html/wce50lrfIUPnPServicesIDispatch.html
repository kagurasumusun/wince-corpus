IUPnPServices:IDispatch

This interface enumerates a collection of services.

The following table lists and describes this interface's members.

Method Description
_NewEnum Property that returns the enumerator interface for the collection. This method is not visible in Microsoft® Visual Basic® .NET; use the for...each programming construct instead.
Count Property that returns the number of services in the collection.
Item Property that returns the IUPnPService:IDispatch object for the specified service in the collection.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
