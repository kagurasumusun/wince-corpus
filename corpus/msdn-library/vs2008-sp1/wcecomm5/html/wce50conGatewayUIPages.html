Remote Configuration Framework Modules

Windows CE includes a set of Remote UI modules that you can use to customize your device. These modules are located in %WINCEROOT_\PUBLIC\SERVERS\OAK\SAMPLES\REMOTEADMIN\MODULES.

The following table shows the modules that comprise the Remote UI.

Modules Description
EVENTLOG Logs system events. Can be queried by other Remote UI modules.
FIREWALL Implements and configures the firewall for the Remote Configuration Framework.
HOSTNAME Configures the host name.
MODULESLIST Manages the list of Remote UI modules. Configures the addition of new modules and toolbars. Manages the registry entry for the Remote UI modules.
NAT Configures and manages Network Address Translation (NAT) for the Remote Configuration Framework.
NATIVEWIFI Implements and configures Native Wi-Fi.
NETLOG Manages and implements the Netlog tool for the Remote Configuration Framework. For more information, see Netlog.
NETWORK Performs general networking functionalities, such as host name resolution, adapter binding, IP address renewal and release, and network bridging for the Remote Configuration Framework.
PASSWORD Configures and implements the password settings for the Remote Configuration Framework.
PARENTALCONTROLS Configures and manages Parental Controls.
PORTFORWARD Implements port forwarding and configures port forwarding rules.
RAS Configures the Remote Access Service (RAS) settings and creates Point-to-Point Protocol over Ethernet (PPPoE) connectoids.
REMOTEUTILS Manages the registry entries for each Remote UI module.
ROOTDIRS Manages and configures root directories for the Remote Configuration Framework.
SMBFILE Manages and configures the SMB file server for the Remote Configuration Framework.
SMBPRINT Manages and configures the SMB print server for the Remote Configuration Framework.
TIMESERVICE Manages and configures the time service for the Remote Configuration Framework.
USERS Manages and configures user names for the Remote Configuration Framework.
VERSION Manages and configures versioning and IDs of devices on the network.
WATSON Configures Watson support for the Remote Configuration Framework.
