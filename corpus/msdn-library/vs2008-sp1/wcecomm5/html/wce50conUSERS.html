USERS

This module manages and configures user names for the Remote Configuration Framework.

The following table shows the configurable settings for USERS.

Value : Type Access Index Description
User : STRING Read-only User Name Specifies the user name.
Add : STRING Read-write User Name Specifies the name of the user to be added.
Pwd : STRING Read-write User Name Specifies the password of the user to be added.
Pwdverify : STRING Read-write User Name Specifies the verification of the password to be added.
Delete : STRING Read-write User Name Specifies the name of the user to be deleted.
