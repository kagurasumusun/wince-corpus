Core Protocol Stack for IPv4

The core protocol stack components are those shown between the NDIS and Winsock in the illustration included in TCP/IP Architectural Model. TCP/IPv4 component is implemented in Tcpstk.dll

The Microsoft TCP/IPv4 stack is accessible through the Winsock 1.1 and Winsock 2.2 interfaces. The Winsock interface for Windows CE does not provide raw access to the protocol stack.
