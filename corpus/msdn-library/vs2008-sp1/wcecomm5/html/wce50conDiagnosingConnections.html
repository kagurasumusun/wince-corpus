Diagnosing Connections

The following table shows tasks to help you diagnose IPv6 connections.

Diagnostic Tasks Relevant Procedures
Diagnose the network for a specific destination. Testing an IPv6 Connection by Using the Ping Command
Test reachability for a specific destination. Testing IPv6 Connectivity by Using the Ping Command
View interface information. Viewing Interface Information
View the interface identifier for the neighbor cache entry, the neighboring node IPv6 address, and the corresponding link-layer address. Viewing the Neighbor Cache
View the destination address, the interface identifier and next-hop address, the interface identifier and address used as a source address when sending to the destination, and the path MTU for the destination. Viewing the Route Cache
Troubleshoot the connection for devices that have Network Connection Status UI. Diagnosing Connectivity Problems using the Network Connection Status UI

For more information about troubleshooting IPv6, see Troubleshooting IPv6.
