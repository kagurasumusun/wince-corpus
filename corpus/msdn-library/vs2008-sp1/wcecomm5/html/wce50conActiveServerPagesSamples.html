Platform Builder for Microsoft Windows CE 5.0  

Active Server Pages Samples

Windows CE contains a sample tool that uses ASP to remotely configure the Web Server. This tool is implemented as a set of ASP pages that display the Web Server status to the user, and a set of COM objects that read and write Web Server configuration settings on the server.

This sample is located in the %_WINCEROOT%\PUBLIC\SERVERS\SDK\SAMPLES\HTTP\ASP.
