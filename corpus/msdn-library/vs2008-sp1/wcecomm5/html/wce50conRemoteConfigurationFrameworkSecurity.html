Remote Configuration Framework Security

The Remote Configuration Framework is closely tied to the Web server. Each module in the Remote Configuration Framework communicates with the Web server through an ISAPI extension. Because it relies primarily on the Web server technology for communication, the Remote Configuration Framework has the same potential security risks as the Web server. For a list of Web server-related security risks and best practices, see Web Server Security.
