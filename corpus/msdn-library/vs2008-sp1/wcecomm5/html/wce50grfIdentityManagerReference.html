Identity Manager Reference

The peer-to-peer Identity Manager enables the creation of secure peer names that PNRP can use. By having secure registration, application developers can be assured that the person publishing the name officially owns the name. These peer names, also called identities, are used to identify the individuals who are participating in the group. The Identity Manager API allows you to create, enumerate, and manage peer-to-peer identities.

This language reference section contains descriptions of the Identity Manager programming elements.
