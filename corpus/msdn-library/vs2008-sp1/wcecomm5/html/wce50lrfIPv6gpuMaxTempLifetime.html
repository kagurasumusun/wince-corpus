IPv6 gpu MaxTempLifetime

This command sets the valid and preferred lifetimes of temporary addresses.

ipv6 [-p] gpu MaxTempLifetime Valid[/Preferred]

Parameters

-p
Saves the setting in the registry.
MaxTempLifetime Valid[/Preferred]
Specifies the valid and preferred lifetimes of temporary addresses. The default valid lifetime is seven days. The default preferred lifetime is one day.
