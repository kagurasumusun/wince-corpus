IP4_ARRAY

This structure stores an array of IPv4 addresses.

typedef struct _IP4_ARRAY {
  DWORD AddrCount;
  IP4_ADDRESS AddrArray[1];
} IP4_ARRAY, *PIP4_ARRAY;

Members

AddrCount
[in] Number of IPv4 addresses in AddrArray.
AddrArray
[in] Array of IPv4 addresses.

Remarks

Check the header file for changes to AddrArray when MIDL pass conditions are met.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Windns.h.
