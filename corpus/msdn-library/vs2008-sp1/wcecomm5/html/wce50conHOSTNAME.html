Platform Builder for Microsoft Windows CE 5.0  

HOSTNAME

The HOSTNAME module configures the host name for the device.

The following table shows the configurable settings for HOSTNAME.

Value : Type Access Index Description
Name : STRING Read-write Not applicable Specifies the hostname to get or set.
NotSet : DWORD Read-only Not applicable If this value is set to 1, a host name has not been set. If a host name has been set for the device, the value is not present.
