RAS Messages

The following table shows the RAS messages with a description of the purpose of each.

Programming element Description
WM_RASDIALEVENT This message is sent by the operating system (OS) to a window procedure when a change of state event occurs during a Remote Access Service (RAS) connection process and a window has been specified to handle notifications of such events by using the notifier parameter of RasDial.
