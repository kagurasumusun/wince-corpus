Microsoft Challenge-Handshake Authentication Protocol 2.0 (MS CHAP V2)

Microsoft Windows CE 3.0 and later support Microsoft CHAP 2.0. Microsoft CHAP 2.0 offers an enhanced security framework over Microsoft CHAP. These improvements include a server authentication scheme and a single change password packet.

Registry Settings

The following example shows the registry settings for MS CHAP V2.

[HKEY_LOCAL_MACHINE\Comm\EAP\Extension\26]
    "FriendlyName"="MSV2-Challenge"
    "InvokePasswordDialog"=dword:1
    "InvokeUserNameDialog"=dword:1
    "Path"="eapchap.dll"
    "InteractiveUIPath"="eapchap.dll"
