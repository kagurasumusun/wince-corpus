Configuring CLIENT1

In the IPv6 test lab, configure CLIENT1 as a client computer.

To configure CLIENT1

  1. Configure the TCP/IP protocol using the following addresses:
    • IP address: 10.0.1.3
    • Subnet mask: 255.255.255.0
    • Default gateway: 10.0.1.1

    For more information, see Configuring a Device with a Static Address for the IPv6 Test Lab.

  2. Verify the IP address by using IPConfig.
