Invoking the Custom-Scripting DLL

If the user activates a connection for a phone-book entry that has RASEO_CustomScript set, RAS invokes the custom-scripting DLL. In this scenario, RAS invokes the custom-scripting DLL from RasDial.

To invoke the custom-scripting DLL programmatically, establish the connection using the RasDial function.
