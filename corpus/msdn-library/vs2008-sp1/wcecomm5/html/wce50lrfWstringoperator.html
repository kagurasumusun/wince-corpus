wstring::operator+=

This operator appends the specified characters to the string. 

wstring& operator+=(
  const wstring& _X
);
wstring& operator+=(
  const wchar_t* _S
);

Parameters

_X
The wstring whose characters are to be appended to this string.
_S
The C-style string whose characters are to be appended to this string.

Return Values

A reference to the new wstring object.

Requirements

OS Versions: Windows CE 5.0 and later.
Header: Av_upnp.h.
Link Library: Av_upnp.lib.
C++ Namespace: av_upnp.
