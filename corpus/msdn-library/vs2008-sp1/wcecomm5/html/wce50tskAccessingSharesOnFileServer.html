Accessing Shares on the File Server

After you have configured your file server using the remote configuration tool, you can access and browse the two root directories you created in the previous step.

To access the root directories and files on your file server

  1. On the development workstation, from the Start menu, choose Run.
  2. In the Open box, type \\fileserver, and then choose OK. The Connect to fileserver dialog box appears.
  3. In the Connect to fileserver dialog box, type the user name you created and the corresponding password, and then choose OK. A window appears that shows the two root directories you created.

    You can now browse the two root directories you created and access specific files in these directories.
