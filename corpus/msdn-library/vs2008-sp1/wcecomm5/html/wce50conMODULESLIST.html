MODULESLIST

The MODULESLIST module manages the list of Remote UI modules. This module lists the current modules and toolbars.

The following table shows the configurable settings for MODULESLIST.

Value : Type Access Index Description
Available : Array Read-only ModuleName If the name of the module is available, this value is set to 1; if the module name is not available, this value does not exist.
Toolbar : Array Read-only Integer value starting at 0 Indicates the name of the function or file for the toolbar utility, which is specified in the HKLM\Comm\HTTPD\VROOTS\/RemoteAdmin\ToolBar registry key. For more information, see Remote Configuration Framework Registry Settings.
