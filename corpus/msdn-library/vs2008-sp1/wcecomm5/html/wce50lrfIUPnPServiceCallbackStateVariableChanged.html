IUPnPServiceCallback::StateVariableChanged

This method is invoked when a state variable has changed. 

HRESULT StateVariableChanged(
  IUPnPService* pus,
  LPCWSTR pcwszStateVarName,
  VARIANT varValue
);

Parameters

pus
[in] Reference to an IUPnPService:IDispatch object that specifies the service about which UPnP is sending the notification.
pcwszStateVarName
[in] Reference to a string that specifies the state variable that has changed.
varValue
[in] Specifies the new value. The type of the data returned depends on the data type of the state variable about which the notification is being sent.

Return Values

UPnP does not expect the application to return any specific value. Any value returned is ignored by UPnP.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
