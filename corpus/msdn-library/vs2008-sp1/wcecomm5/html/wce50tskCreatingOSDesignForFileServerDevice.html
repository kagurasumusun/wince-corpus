Creating an OS Design for a File Server Device

Before you build a file server run-time image, you must create an OS design using Platform Builder.

To create an OS design for a file server device

  1. On the development workstation, open Platform Builder.
  2. From the File menu, choose New Platform, and then complete the New Platform Wizard. The following list shows the choices to make in the New Platform Wizard:
    1. In the Name box, type a name for your file server OS design.
    2. Choose the CEPC x86 BSP.
    3. Choose the Enterprise Web Pad design template.
    4. Ignore the Applications & Media page on the New Platform Wizard, and choose Next.
    5. On the Networking & Communications page, expand the Local Area Network (LAN) node, and then select the Wired Local Area Network check box. Choose Next.
    6. Read the security warnings, and then choose Next.
    7. On the Completing the New Platform Wizard page, choose Finish.
  3. Locate the following Catalog items in the Catalog and drag them to the Workspace window of your OS design:
    Catalog item Sysgen variable Location in Catalog
    File Server SYSGEN_SMB_FILE Communication Services and Networking\Servers
    File Server Customizable UI SYSGEN_SMB_UI Communication Services and Networking\Servers\File Server
    NTLM SYSGEN_AUTH_NTLM Security\Authentication Services (SSPI)
    Note   Selecting File Server does not automatically bring in the File Server Customizable UI Catalog item. Add the File Server Customizable UI Catalog item to the OS design separately .
