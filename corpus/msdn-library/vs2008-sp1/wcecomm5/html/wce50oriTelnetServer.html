Telnet Server

The Telnet Server functionality in Microsoft® Windows® CE provides a sample Telnet server can be installed on a device to allow remote administration through a standard Telnet client. Using the Telnet sample, the current device can be manipulated as if it is running the command prompt on the device itself.
