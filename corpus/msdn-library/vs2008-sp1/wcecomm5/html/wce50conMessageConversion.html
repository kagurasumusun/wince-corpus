Message Conversion

The message processor can also convert message formats between the new SOAP/HTTP based format and the old native MSMQ format.

Combined with the message routing capability, this enables HTTP based messages to be used between a queue on the public network and a queue on the edge device.

In addition, native MSMQ messages are used on the private or internal network.
