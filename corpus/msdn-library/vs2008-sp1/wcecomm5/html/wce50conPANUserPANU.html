PAN User (PANU)

A PAN User (PANU) is a Bluetooth device that communicates as a client with a Group Ad-hoc Network (GN), or a Network Access Point (NAP), or with another Bluetooth device, through a point-to-point connection.

For a PANU to connect to a NAP, a GN, or another PANU, it must do the following:

  1. Discover a NAP, a GN, or another PANU, by sending a baseband inquiry and conducting a Service Discovery Protocol (SDP) search.
  2. Request a connection from the Bluetooth device if a connection does not already exist. For connecting to Bluetooth devices that provide the NAP or GN service, a master/slave switch is required. You can toggle the master/slave switch by configuring the registry. For more information, see Personal Area Network (PAN) Profile Registry Settings.
  3. Create an L2CAP channel for Bluetooth Network Encapsulation Protocol (BNEP) to transmit network packets. The PANU can use the BNEP control commands that are defined in the BNEP specification to initialize the BNEP connection.
  4. Transfer Ethernet packets across the link.

Either the PANU or the other Bluetooth device may terminate the connection at anytime.

For more information about the procedures related to the PANU service, see the Personal Area Networking Profile Specification at this Official Bluetooth Wireless Info Web site.
