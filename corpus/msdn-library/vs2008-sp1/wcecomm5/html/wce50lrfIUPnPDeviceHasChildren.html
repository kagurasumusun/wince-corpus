IUPnPDevice::HasChildren

This method returns a flag that specifies whether the device has any child devices. However, the number of child devices is not returned.

HRESULT get_HasChildren(
  VARIANT_BOOL* pvarb
);

Parameters

pvarb
[out] Receives a reference to a VARIANT_BOOL that contains the value VARIANT_TRUE if the device has one or more child devices; otherwise, it contains the value VARIANT_FALSE.

Return Values

S_OK
This method was successful.

Otherwise, the method returns one of the COM error codes defined in WinError.h.

Remarks

Use this method to determine whether or not the application should call IUPnPDevice::Children.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnp.h.
Link Library: Uuid.lib.
