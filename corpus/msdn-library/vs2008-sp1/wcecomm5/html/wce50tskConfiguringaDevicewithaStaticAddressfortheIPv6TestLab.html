Configuring a Device with a Static Address for the IPv6 Test Lab

In the IPv6 test lab, configure Windows CE-based devices with static addresses.

Note   You must be logged on as an Administrator or a member of the Administrators group in order to complete this procedure. If your computer is connected to a network, network policy settings may prevent you from completing this procedure.

To configure a device with a static address

  1. On the Windows CE-based device, open Network and Dialup Connections.
  2. Right-click the network adapter you want to configure, and then choose Properties.
  3. On the IP Address tab, choose Specify an IP address.
  4. In IP address, Subnet mask, and Default gateway, type the IP address, subnet mask, and default gateway addresses.
  5. Choose OK.
