Enabling the DNS Proxy

The following steps show how to enable the DNS proxy included with ICS.

To enable DNS proxy

  1. Enable the DHCP Allocator as described in DHCP Allocator.
  2. Set the HKEY_LOCAL_MACHINE\Comm\ConnectionSharing\EnableDNSProxy registry key equal to a non-zero value.
  3. Set the HKEY_LOCAL_MACHINE\Comm\ConnectionSharing\PrivateInterface registry key to a list of private interfaces that you want to enable the DNS proxy on.
