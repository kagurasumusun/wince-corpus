Platform Builder for Microsoft Windows CE 5.0  

User Credential Information

Windows CE does not support direct registry access to user credential information. To set or modify user credential information, use the RASCNTL_SERVER_USER_SET_CREDENTIALS and RASCNTL_SERVER_USER_DELETE_CREDENTIALS IOCTLs.
