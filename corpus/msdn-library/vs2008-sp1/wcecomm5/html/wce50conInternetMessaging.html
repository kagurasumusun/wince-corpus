Internet Messaging

MSMQ provides support for sending messages over the Internet. MSMQ provides an out-of-the-box support for Internet-deployed applications and for the business-to-business market. More specifically, MSMQ adds the following enhancements:

  • HTTP as an optional transport protocol.
  • An XML-based SOAP extension that defines a reliable end-to-end messaging protocol, the SOAP Reliable Messaging Protocol (SRMP).
  • Support for message routing through a gateway or firewall.
  • Support for message format conversion to or from native MSMQ and the HTTP protocol.
