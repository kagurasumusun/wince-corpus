UPNPSERVICECONTROL

This structure is handed in to the callback as pvSvcParam when the callback ID is UPNPCB_CONTROL.

typedef struct {
  PCWSTR pszRequestXML;
  PCWSTR pszSID;
  PCWSTR pszServiceType;
  PCWSTR pszAction;
  PCWSTR pszUDN;
  DWORD iAction;
  DWORD cInArgs;
  UPNPPARAM* pInArgs;
  PVOID Reserved1; 
} UPNPSERVICECONTROL;

Members

pszRequestXML
Raw SOAP request.
pszSID
Service identifier from the device description.
pszServiceType
Service type.
pszAction
Name of control action.
pszUDN
Unique device name.
iAction
Reserved.
cInArgs
Number of input parameters.
pInArgs
Array of input parameters.
Reserved1
Reserved.

Requirements

OS Versions: Windows CE .NET 4.0 and later.
Header: Upnpdevapi.h.
