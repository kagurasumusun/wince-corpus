EAP Enumerations

The following table shows the Extensible Authentication Protocol enumerations with a description of the purpose of each.

Programming element Description
PPP_EAP_ACTION This enumeration specifies actions that Remote Access Service (RAS) should take on behalf of the authentication protocol.
RAS_AUTH_ATTRIBUTE_TYPE This enumeration specifies attribute values used for session authentication.
