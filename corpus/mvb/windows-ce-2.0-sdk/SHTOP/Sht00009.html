Specifying SHCL Options

You can specify SHCL options on the command line, in response files, and in the CL environment variable. Options specified in response files and the CL environment variable are used everytime you invoke SHCL. Unlike either the command line or the CL environment variable, a response file allows you to use multiple lines of options and filenames.

Options to the SHCL command consist of either a forward slash (/) or a dash ( ) followed by one or more letters. Certain options take arguments; in some of these options, a space is required between the option and the argument; in others, no space is allowed. The spacing rules for the options are given in their descriptions. Options (except for the /HELP option) are case sensitive. For example, /C and /c are different options.

Order of Options

With the exception of the /link option, which precedes all options to be passed to the linker, options can appear anywhere on the SHCL command line. The compiler reads options from left to right. It begins with options specified in the CL environment variable and reads the content of response files when it encounters a @filename during its left-to-right scan of the command line. After gathering all options, the compiler applies each option to all files on the command line. If SHCL encounters conflicting options, the rightmost option will be used.
