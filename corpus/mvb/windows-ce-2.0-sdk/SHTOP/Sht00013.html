SHCL Options Alphabetical Reference

Option
Description
/C
Preserve comments during preprocessing
/c
Compile without linking
/D
Define constants and macros
/E
Copy preprocessor output to standard output
/EP
Copy preprocessor output to standard output
/F
Set stack size
/Fa
Rename assembler file listing
/FA
Create assembler/machine/source listing file
/Fe
Rename executable file
/FI
Preprocess specified header file first
/Fm
Create map file
/Fo
Rename object file
/Fp
Specify precompiled header filename
/FR, /Fr
Generate browser files
/Gf
Enable string pooling (see the preferred /GF)
/GF
Enable read-only string pooling
/GR
Do not use: runtime libraries do not support this compiler switch for runtime type identification.
/Gy
Enable function-level linking
/H
Restrict length of external names
/HELP
List the compiler options
/I
Search directory for include files
/J
Change default char type
/Ld, /Lw
Control library selection
/LD
Create a dynamic-link library
/link
Linker-control options
/nologo
Suppress display of sign-on banner
/O1, /O2
Specify small or fast code
/Obn
Control inline expansion
/Od
Disable optimization
/Og
Enable global optimization
/Oi
Generate intrinsic functions
/Op, /Op
Improve floating-point consistency
/Os, /O, /Ot
Specify small or fast sequences of machine code
/Ox
Use maximum optimization for fast code
/Oy, /Oy
Omit or generate frame pointer in the program stack
/P
Create preprocessor-output file
/Qsh3r[4...8]
Specify the SH-3 chip revision number for which to generate code
/Qtime
Time/space tradeoff
/S
Generate .asm files and stop
/Tc
Specify C source file
/Tp
Specify C++ source file
/u
Remove all predefined names
/Uname
Remove specified predefined names
/vdn
Suppress or enable hidden vtordisp class members
/vmb
Use best case for pointers to class members
/vmg
Use full generality for pointers to class members
/vmm
Declare multiple inheritance
/vms
Declare single inheritance
/vmv
Declare virtual inheritance
/vmx
Specify type of pointers to members of classes
/Vstring
Set version string
/W, /w
Set warning level
/X
Ignore standard include directory
/Yc, /Yu
Create and use precompiled header
/Yd
Duplicate debugging information in all object files (default)
/Yu
Use precompiled header
/YX
Automate precompiled header
/Z7
Generate complete (C7) debugging information
/Za
Compile for ANSI compatibility
/Zd
Generate line numbers only
/Ze
Enable language extensions
/Zg
Generate function prototypes
/Zi
Produce Program Database
/Zl
Remove default-library name from object file
/Zn
Turn off browser file packing
/Zp
Pack structure members
/Zs
Check syntax only
