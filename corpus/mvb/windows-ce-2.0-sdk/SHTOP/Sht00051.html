/Qtime

The compiler can reduce many C and C++ constructs to different, but functionally similar, sequences of machine code. Occasionally these differences offer tradeoffs with respect to the size or the speed of the code. The optimizing code generation option /Qtime allow you to specify a preference for either small machine code or fast machine code when the compiler recognizes the existence of such a choice. The /Qtime option is similar to the /Os and /Ot options, but /Qtime provides finer-grained control on a scale from zero (smallest) to nine (fastest).

Example:

/Qtime0 Optimizes for smallest code

/Qtime1 (Optimization implied by /01)

/Qtime2 (Optimization implied by /Os)

/Qtime5 Default optimization

/Qtime7 (Optimization implied by /Ot)

/Qtime9 Optimizes for fastest code

/Qtime overrides /Os and /Ot.

/Qtime without other optimization options does not imply any optimization.
