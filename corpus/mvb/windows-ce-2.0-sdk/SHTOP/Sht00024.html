/FA (Create Listing Files)

Option:

/FA[[string]]

Use the /FA option to create a listing file containing source code, assembler code, and/or machine code. The string argument can be any of the following:

(null)

c

s

cs

sc

Listing-File Control

Letter
Action
c
Listing file contains machine code
s
Listing file contains source code
If you use /FA without an argument, only an assembler listing is generated. If c is specified, the default file extension is .COD, otherwise the default file extension is .ASM.
