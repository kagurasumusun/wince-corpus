Learning and Using SH-3 Assembly Language

This document is not intended to be a tutorial on how to program SH-3 assembly code. Rather, it describes the syntax, semantics and restrictions for the inline assembly language. For a complete description of the stand-alone SH-3 assembler, see the Hitachi COFF Assembler Manual for SH-3.

Since it is not intended for extensive use, the inline assembly language contains a subset of the features available in the stand-alone assembler. For the features it does provide, the inline assembly language is compatible with the stand-alone assembler.
