/O1, /O2 (Specify Small or Fast Code)

The /O1 and /O2 options select a predefined set of options not all of which are optimization (/O) options that affect the size and speed of executable files. The /O1 option produces very small executable files. The /O2 option produces very fast executable files. Both options are designed to produce executable files or DLLs that will run well on most machines. The result of using /O1 or /O2 is more comprehensive than that of using /Os or /Ot.

The table below shows the options that the optimizing compiler uses to implement /O1 and /O2.
