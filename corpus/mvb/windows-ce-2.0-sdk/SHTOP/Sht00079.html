Inline Assembly Language

The inline assembly language provides a capability for manually inserting SH-3 assembly code in C/C++ routines, especially in situations where the compiler cannot generate equivalent code. The directives required to specify entry and exit points for a routine are not supported, so to write complete routines, the routine entry and exit generated by the C/C++ compiler must be used.
