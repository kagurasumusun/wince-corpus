/Fo (Rename Object File)

Option:

/Fofilename

By default, SHCL gives each object file it creates the base name of the corresponding source file plus the extension .OBJ. The /Fo option lets you give different names to object files or create them in a different directory. No space is allowed between the option and filename. The /Fo option requires a filename argument.

You can give any name and extension you want for filename. However, it is recommended that you use the conventional .OBJ extension since the linker and the LIB library manager use .OBJ as the default extension when processing object files.

Example:

SHCL /FoB:\OBJECT\ THIS.C

In this example, SHCL compiles the source file THIS.C and gives the resulting object file the name THIS.OBJ by default. The directory specification B:\OBJECT\ tells SHCL to create THIS.OBJ in the directory named \OBJECT on drive B.
