/vmm (Declare Multiple Inheritance)

Use the /vmm option with the /vmg option. The /vmm option specifies the most general representation of a pointer to a member of a class to be one that uses multiple inheritance. This representation is larger than that required for single inheritance.

If the inheritance model of a class definition for which a pointer to a member is declared is virtual, the compiler generates an error.

The corresponding argument to the pointers_to_members pragma is multiple_inheritance.
