SHCL Compiler Reference

The compiler-driver program SHCL.EXE is a 32-bit C/C++ compiler, which is used to compile and link 32-bit Hitachi SH-3 C and C++ programs. The compiler produces Common Object File Format (COFF) object files. The linker produces executable files or dynamic-link libraries (DLLs).

This online reference explains how to use SHCL from the command line.
