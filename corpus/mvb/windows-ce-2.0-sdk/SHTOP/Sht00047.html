/Oy, /Oy- (Omit or Generate Frame Pointer)

/Oy is the default, and should work for all programs.

Use the /Oy option to suppress the creation of frame pointers on the call stack. This option has two benefits: It speeds function calls, since no frame pointers need be set up and removed, and it frees one more register, FP(R14), for storing frequently used variables and subexpressions. The /Oy option is implied by the /Ox and /O2 options, discussed above.
