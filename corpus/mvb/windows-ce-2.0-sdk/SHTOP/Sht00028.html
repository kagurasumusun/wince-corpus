/Gf (Enable String Pooling)

Attention: /Gf is still supported but is not recommended. The preferred flag is /GF, which stores the strings in a read-only section.

The /Gf option enables the compiler to place a single copy of identical strings into the executable file. Because identical strings are copied into a single memory location, programs compiled with the /Gf option can be smaller than those compiled without /Gf. This space optimization is sometimes called string pooling. Use of /Gf does not guarantee string pooling in all cases. String pooling does, however, occur in most cases.

Example:

When the following two source files 

// file1.c
char * sz = "String"; 
// file2.c
printf( "String" );

are compiled and linked with the following command line

cl /Gf file1.c file2.c

only one copy of "String" will exist in the resulting executable file.

Note:

When using /Gf, you must not write over pooled strings; therefore consider using instead the flag /GF (Enable Read-Only String Pooling).
