__asm Intrinsic Prototype

Inline assembly code is specified using the __asm statement, which is treated as an intrinsic call. Before an __asm call is invoked, it must first be declared as a function prototype. In C++ files, the compiler reports an error unless one of the following declarations is included before any __asm calls:

extern "C" { void __asm(const char *, ...); }

extern "C" { int __asm(const char *, ...); }

extern "C" { unsigned int __asm(const char *, ...); }

For C files, the compiler does not recognize an __asm call as an intrinsic unless one of the following declarations is included before an __asm statement:

void __asm(const char *, ...);

int __asm(const char *, ...);

unsigned int __asm(const char *, ...);
