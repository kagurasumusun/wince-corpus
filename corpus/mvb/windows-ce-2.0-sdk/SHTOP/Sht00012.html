Optimization Options

Option:

/Ostring

The /O options allow you to control the level of optimization that is applied to the code that the compiler generates for your program. In general, use the /Od option to disable optimization and thus speed compilation and simplify debugging; and use the /Og option to enable a basic set of global optimizations.

The string argument is one or more letters, with no intervening spaces. The letters following the /O, including the number argument to /Obn and the minus argument to /Op, can appear in a continuous series in any order. Detailed descriptions of all /O options follow in the table below.

Supported Optimization Options

Letter
Optimizing procedure
/O1, /O2
Specify small or fast code
/Obn
Control inline expansion, where n is a digit from 0 through 2
/Og
Enable global optimization
/Od
Disable optimization
/Oi
Generate intrinsic functions
/Op, /Op
Improve floating-point consistency
/Os
Specify short sequences of machine code
/O, /Ot
Specify fast sequences of machine code (default)
/Ox
Use maximum optimization
/Oy, /Oy
Omit or generate frame pointers on the program stack
