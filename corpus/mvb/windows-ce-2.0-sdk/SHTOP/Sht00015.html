/c (Compile Without Linking)

The /c option instructs SHCL to compile all C source files given on the command line. Only object files are created. SHCL does not pass object files to the linker. No executable file or DLL is produced.

Example:

SHCL /c FIRST.C SECOND.C THIRD.OBJ

This example compiles FIRST.C, creating the object file FIRST.OBJ, and then compiles SECOND.C, creating the object file SECOND.OBJ. No processing is performed with THIRD.OBJ because SHCL stops the build process after compilation and before linking.
