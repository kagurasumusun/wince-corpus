/vmv (Declare Virtual Inheritance)

Use the /vmv option with the /vmg option. The /vmv option specifies the most general representation of a pointer to a member of a class to be one that uses virtual inheritance. In terms of pointer size and the code required to interpret the pointer, this is the most expensive option. This option, however, never causes an error and is the default.

The corresponding argument to the pointers_to_members pragma is virtual_inheritance.
