/link (Linker-Control Options)

Option:

/link [[option]]

This option passes to LINK the linker options, nondefault library names, and library search paths specified by the option argument. The /link option and its associated linker options must appear after any source or object filenames and SHCL options. A space is required between /link and option.

The following SHCL options also affect the linker:

SHCL options that affect the linker

Option
Description
/F hexnum
Resets stack size to specified hexadecimal number. This option is the same as passing the STACK option to LINK.
/Fm
Produces a map file.
