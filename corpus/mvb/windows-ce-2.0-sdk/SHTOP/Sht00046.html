/Ox (Use Maximum Optimization)

The /Ox option is a shorthand way to combine optimizing options to produce the fastest possible program. The effect is the same as using the following options on the same command line:

/Ogity /Gs

Example:

SHCL /Ox FILE.C

This command tells the compiler to use the optimizing compiler to compile FILE.C with the following options:

Option
Action
/Og
Enable global optimizations
/Oi
Generate intrinsic functions
/Ot
Specify fast sequences of machine code
/Oy
Omit frame pointer (default)
