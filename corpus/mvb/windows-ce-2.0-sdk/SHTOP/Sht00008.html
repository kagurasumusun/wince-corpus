Filename Syntax

A filename can contain any combination of uppercase and lowercase letters, hyphens, underscores, and a period. Any filename can include a full or partial path. A full path includes a drive name and one or more directory names separated by backslashes (\). A partial path omits the drive name, which SHCL assumes to be the current drive. If you don’t specify a path, SHCL assumes the file is in the current directory.

The filename extension determines how files are processed. The filename extensions and the processes performed on the associated files are listed below.
