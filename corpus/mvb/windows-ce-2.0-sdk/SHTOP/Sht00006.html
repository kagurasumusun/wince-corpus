SHCL Command Reference

The reference is arranged in three sections. The first describes the syntax and the input rules for the SHCL command line. The second section discusses the use of SHCL to compile and link programs and describes response files and the CL environment variable. The third section offers a quick alphabetical reference to all of the SHCL options, followed by more detailed descriptions and examples, organized by category.
