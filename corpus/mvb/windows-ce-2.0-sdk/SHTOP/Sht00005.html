CL Environment Variable

Note:

Do not confuse the CL Environment Variable used by the SHCL cross compiler with CL.EXE, a separate compiler program.

Use the CL environment variable to specify files and options without giving them on the command line. The environment variable has the following syntax:

SET CL=[[ [[option]] ... [[file]] ...]] [[/link [[ link-libinfo]] ]]

The CL environment variable is useful if you often specify a large number of files and options when you compile. Ordinarily, MS-DOS limits the command line to 128 characters. The files and options that you define with the CL environment variable, however, do not count toward this limit. Therefore, you can define the files and options you use most often with the CL variable and then give only the files and options you need for specific purposes on the command line.

Note that if you have given an option in the CL environment variable, you cannot turn off or change the option from the command line. You must reset the CL environment variable and omit the file or option that you do not want to use. The information defined in the CL variable is treated as though it appeared before the information given on the SHCL command line.

With MS-DOS, you cannot use CL to set options that use an equal sign (for example, the /Didentifier= string option). With Microsoft C and C++, the define constants and macros option (/D) accepts the number sign (#) as an equal sign (=). You can now use the CL environment variable to define preprocessor constants and macros (for example, /D identifier #string).

You can use wildcards in filenames to specify multiple files with CL.

Example:

In the following example, the CL environment variable tells the SHCL command to use the /Zp, /Ox, and /I options during compilation and then to link with the object file \LIB\BINMODE.OBJ.

SET CL=/Zp2 /Ox /I\INCLUDE\MYINCLS \LIB\BINMODE.OBJ INPUT.C

Both the CL environment variable above and the SHCL command below specify structure packing on 2-byte boundaries, perform maximum optimizations, and search for include files in the \INCLUDE\MYINCLS directory for the source file INPUT.C.

SHCL /Zp2 /Ox /I\INCLUDE\MYINCLS \LIB\BINMODE.OBJ INPUT.C

In the following example, the CL environment variable instructs the SHCL command to compile and link the source files FILE1.C and FILE2.C:

SET CL=FILE1.C FILE2.C

>SHCL FILE3.OBJ

The preceding SHCL command line has the same effect as the command line:

SHCL FILE1.C FILE2.C FILE3.OBJ
