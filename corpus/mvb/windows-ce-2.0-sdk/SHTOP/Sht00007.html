SHCL Command-Line Syntax

The SHCL command line uses the following syntax:

SHCL [[option...]] file... [[option | file]]... [[lib...]] [[/link link-opt...]][[@response-file]]

The following list describes input to the SHCL command:

Entry
Meaning
option
One or more SHCL options.
Note:
All options apply to all specified source files.
File
The name of one or more source files, object files, or libraries. You must specify at least one filename. SHCL compiles source files and passes the names of the object files and libraries to the linker.
Lib
One or more library names. SHCL passes the names of these libraries to the linker for processing.
link-opt
One or more of the linker options. The SHCL command passes these options to the linker for processing.
Response-file
A file that can contain multiple options and filenames which you would otherwise type on the command line or specify by using the CL environment variable.

You can specify any number of options, filenames, and library names, as long as the length of the command line does not exceed the limit dictated by the operating system.
