/F (Set Stack Size)

Option:

/F number

The /F option sets the program stack size to number bytes. The number argument is a hexadecimal number that can range from a lower limit of 0001 to an upper limit determined by the maximum stack size accepted by your linker. A space is required between the option and number. Decimal and octal numbers are not allowed. If you don’t specify this option, a stack size of 1 MB is used by default.

You may want to increase the stack size if your program gets stack-overflow diagnostic messages. If your program uses little stack space, you may want to decrease the size of your program by reducing the stack size.
