5.7.5 .HEADING: Source Program Listing Header Setting

Syntax:

.HEADING[<expression> [,<expression>...]]

Statement Elements:

Label: The label field is not used

Operation: Enter the .HEADING mnemonic in the operation field

Operands: Enter the header for the source program listing in the operand field

Description:

.HEADING is the assembler directive that sets the header for the source program listing. The .HEADING directive can have as operands zero or more expressions (including constants and symbols) whose values may be numbers or strings. If the .HEADING directive is used with no operands, it disables the current heading (if any). Otherwise, the results of the operands are concatenated, and the concatenated result is used as the new heading. If numeric symbols or expressions are used, they must evaluate to absolute values.

Example:

.heading “Sample Program”

; the heading is now: Sample Program

.heading “Code for SH”, _M_SH, “ revision”, _M_SH_REV

; the heading is now: Code for SH-3 revision 6

The .HEADING directive can be used any number of times in a given source program. The range of validity for a given use of the .HEADING directive is as follows:

When the .HEADING directive is on the first line of a page, it is valid starting with that page

When the .HEADING directive appears on the second or later line of a page, it is valid starting with the next page

See section 2.9, Character Strings.

Example:

.HEADING """SAMPLE.SRC"" WRITTEN BY YAMADA"
