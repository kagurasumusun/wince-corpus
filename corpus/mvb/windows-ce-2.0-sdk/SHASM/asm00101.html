5.7.1 .PRINT: Assembler Listing Output Control

Syntax:

.PRINT<output specifier>[,<output specifier>...]

Statement Elements:

Label: The label field is not used

Operation: Enter the .PRINT mnemonic in the operation field

Operands: (output specifier) The output specifier controls assembler listing output as listed in Table 5.15

Table 5.15 Assembler Listing Output Specifier

Output Specifier
Assembler Action
LIST
An assembler listing is output
NOLIST (default)
No assembler listing is output

Description:

.PRINT is the assembler directive that controls assembler listing output. If the .PRINT directive is used two or more times in a program with inconsistent output specifiers, an error occurs.

Example:

.PRINT LIST

.PRINT LIST ; OK

.PRINT NOLIST ; Error

The assembler gives priority to command line option specifications concerning assembler listing output. See also section 11.3 Assembler Listing Command Line Options.

Example:

Note:

This example and its description assume that no command line options concerning assembler listing output are specified.

.PRINT LIST ; An assembler listing is output
