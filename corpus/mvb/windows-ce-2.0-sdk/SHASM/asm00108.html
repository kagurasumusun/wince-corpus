5.8 Other Assembler Directives

5.8.1 .RADIX: Default Integer Constant Radix Setting

5.8.2 .END: Source Program End Declaration

5.8.3 .WEAK: Define "Weak External" Symbol

The assembler provides the following additional assembler directives:

.RADIX: Sets the radix in which integer constants with no radix specifier are interpreted

.END: Declares the end of the source program

.WEAK: Declares "weak external" symbols
