11.3.4 COLUMNS: Setting the Number of Columns in the Assembler Listing

Syntax:

—COLUMNS=<column count> ; Abbreviated form is -CO.

Description:

COLUMNS is the command line option that sets the number of columns in a single line of the assembler listing. The range of valid values for the column count is from 79 to 255. The COLUMNS specification is only valid in cases where an assembler listing is being output. See section 5.7.1, .Print: Assembler Listing Output Control, and section 11.3.1, LIST/NOLIST: Assembler Listing Output Control.
