5.3 Symbol Handling Assembler Directives

5.3.1 .EQU: Symbol Value Setting (Resetting Not Allowed)

5.3.2 .ASSIGN: Symbol Value Setting (Resetting Allowed)

5.3.3 .REG: Alias of a Register Name Definition

The assembler provides the following symbol directives:

.EQU: sets a symbol value

.ASSIGN: sets and resets a symbol value

.REG: defines the alias of a register name
