8.5.3 .SUBSTR: Character Substring Extraction

Syntax:

.SUBSTR[](<character string>,<start position>

,<extraction length>)

Description:

.SUBSTR extracts from the specified character string a substring starting at the specified start position of the specified length. .SUBSTR evaluates to the extracted character. The character string argument may be any expression whose value is a character string, including a preprocessor variable defined with .ASSIGNC, a constant string enclosed in double quotation marks (" "), and the .SUBSTR function and/or + operation. (Nested .SUBSTR uses are permitted.)

The value of the extraction start position must be 0 or greater. The value of the extraction length must be 1 or greater. If illegal or inappropriate values are specified for the <start position> or <extraction length> parameters, this function evaluates to a blank space ( ).

Example:

.MACRO RESERVE_STR P1=0,P2

.SDATA .SUBSTR("ABCDEFG",\P1,\P2)

.ENDM

RESERVE_STR 2,2

RESERVE_STR ,3 ; Macro parameter P1 is omitted.

Expanded results are as follows:

.SDATA "CD"

.SDATA "ABC"
