7.2.4 .ERROR and .AERROR

Syntax:

.ERROR[<expression>[,<expression>...]]

Statement Elements:

Label: The label field is not used

Operation: Enter the .ERROR (or .AERROR) mnemonic in the operation field

Operands: Enter zero or more expressions with string or absolute numeric result values

Description:

The .ERROR directive may be used to report errors detected at assembly time by user code. If a .ERROR directive is assembled, its operands (if any) are evaluated, the results concatenated, and the result of the concatenation is used as the error message. The operands may have either string or numeric values. The alternate spelling .AERROR is also supported, for compatibility with other Hitachi assemblers.

Example:

.section .text

.org 0x202 ; force the .error to be assembled

.aif $ - .text > 0x200

.error “PC overflow: is ”, $, “, expecting < ”, 0x200

.aendi
