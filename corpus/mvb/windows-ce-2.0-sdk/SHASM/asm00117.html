7.1.2 Conditional Assembly

The conditional assembly function determines whether or not to assemble a specified part of a source program according to the specified condition.

Example:

.AIF <condition1>

<Statements to be assembled when condition1 is satisfied>

.AELSIF <condition2>

<Statements to be assembled when condition1 is not satisfied, but condition2 is satisfied>*

.AELSE

<Statements to be assembled when neither condition1 nor condition2 is satisfied>*

.AENDI

Note:

These parts can be omitted from the coding.

Example:

.AIF \&FLAG == "ON"

MOV R0,R10 ; These statements

MOV R1,R11 ; will be assembled

MOV R2,R12 ; when FLAG is "ON".

.AELSIF \&FLAG == "OFF"

MOV R10,R0 ; These statements

MOV R11,R1 ; will be assembled

MOV R12,R2 ; when FLAG is "OFF".

.AELSE

; issue error if FLAG has unexpected value

.ERROR "FLAG is ""\&FLAG""; expecting ""ON"" or ""OFF""."

.AENDI
