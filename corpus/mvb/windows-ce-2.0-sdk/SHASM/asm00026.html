2.2.4 Comment Coding

Assembler comments may be written in any of three ways. A single-line comment may be written following two slashes, as in C++, or following a semicolon (;), as in other assembler languages. The assembler regards all characters from the slashes or semicolon to the end of line as the comment. Alternately, a multi-line comment may be written beginning with a slash-star (/*) and ending with a star-slash (*/), as in C or C++. In this case, the assembler regards all characters between the slash-star and the star-slash, including any complete lines between them, as the comment.

Example:

nop ; this is a comment that starts with

; a semicolon and ends at the end of

; the line

; sleep

nop // this is similar, only it uses the

// C++ // comment syntax.

// sleep

nop /* this comment begins here

sleep (this line is part of the comment)

and ends here */

In the preceding examples, the three nop instructions would be assembled, while the three sleep instructions are each considered part of a comment and so are not assembled.
