1.7 Additional Information

The SH Series Cross Assembler converts source programs written in assembly language into a format that can be handled by SH microprocessors, outputting the result as an object module and as an assembler listing.

The Assembler provides several functions to support efficient program development:

Assembler directives: Gives the assembler various instructions.

File inclusion function: Includes files into a source file.

Conditional assembly function: Selects source statements to be assembled or repeats assembly according to a specified condition.

Macro function: Gives a name to a sequence of statements and defines it as one instruction.

Automatic literal pool generation function: Interprets data transfer instructions (MOV.W #imm, MOV.L #imm, and MOVA #imm) that are not provided by the SH microprocessor as extended instructions and expands them into SH microprocessor-executable instructions and constant data (literals).
