10.2 File Specification Format

Files handled by the assembler are specified in the following format.

<file name>.[<file format>]

The term file name as used in this manual normally refers to both the file name and the file format.

Example:

file.src: A file with the file name file and file format src.

prog.obj: A file with the file name prog and the file format obj.

The file format is used as an identifier to distinguish the contents of the file. Thus two files with differing formats are different files even if the file name is the same.

These file names specify different files:

file.src

prog.obj

The assembler handles the following types of files:

Source file: Source program file. If a source program file is specified without the file format, the file format src will be supplied.

Object file: Output destination file for object modules. If an object file is specified without the file format, the file format obj will be supplied. If an object file is not specified to the assembler, a file with the same name as the source file (the first specified source file) and with the file format obj will be used.

Listing file: Output destination file for assembler listings. If a listing file is specified without the file format, the extension lst will be supplied. If a listing file is not specified to the assembler, a file with the same name as the source file (the first specified source file) and with the file format lst will be used.
