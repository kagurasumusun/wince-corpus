5.4.9 .SDATAZB: Character String Data Blocks Reservation With Zero Terminator

Syntax:

[<symbol>[:]].SDATAZB<block count>,<character string>

Statement Elements:

Label: Enter a reference symbol in the label field if required

Operation: Enter the .SDATAZB mnemonic in the operation field

Operands: First operand: (block count) Enter the number of character strings as the first operand
Second operand: (character string) Enter the character string to be reserved as the second operand

Description:

.SDATAZB is the assembler directive that reserves the specified number of character strings (each with zero terminator) consecutively in memory. A character string with zero terminator is a character string with an appended trailing byte with the value H'00 that indicates the end of the string. See section 2.9, Character Strings. The block count specification must be an absolute value, and forward reference symbols must not appear in the specification. A value of 1 or larger must be specified as the block count. The maximum value of the block count depends on the length of the character string data. The length of the character string data multiplied by the block count must be less than or equal to H'FFFFFFFF (4,294,967,295 bytes).

A control character can be appended to a character string. The syntax for this notation is as follows:

<character string><<ASCII code for a control character>>

The ASCII code for a control character specification must be an absolute value, and forward reference symbols must not appear in the specification.

Example:

.ALIGN 4 ; This statement adjusts the value of

; the location counter.

X: .SDATAZB 2,"AAAAA" ; This statement reserves two character

; string data blocks.

.SDATAZB 2,"""BBB""" ; The character string in this example

; includes double quotation marks.

.SDATAZB 2,"ABAB"<H'07> ; The character string in this example

; has a control character appended.
