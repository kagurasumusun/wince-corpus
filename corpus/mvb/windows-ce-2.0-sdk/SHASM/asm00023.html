2.2.1 Label Coding

The label is written in one of two ways:

1. Written starting in the first column.

2. Written with a colon (:) appended to the end of the label.

Example:

LABEL1 ; This label is written starting in the first column.

LABEL2: ; This label is terminated with a colon.

LABEL3 ; This label is regarded as an error by the assembler

; since it is not written starting in the first column,

; and does not terminate with a colon.
