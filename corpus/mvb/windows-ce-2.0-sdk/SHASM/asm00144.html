8.5.1 .LEN: Character String Length Count

Syntax:

.LEN[](<character string>)

Description:

.LEN counts the number of characters in a character string and evaluates to the number of characters in the string. The argument to .LEN may be any expression whose value is a character string, including a preprocessor variable defined with .ASSIGNC, a constant string enclosed in double quotation marks (" "), and the .SUBSTR function and/or + operator.

Example:

.MACRO RESERVE_LENGTH P1

.ALIGN 4

.SRES .LEN("\P1")

.ENDM

RESERVE_LENGTH ABCDEF

RESERVE_LENGTH ABC

Expanded results are as follows:

.ALIGN 4

.SRES 6 ; "ABCDEF" has six characters.

.ALIGN 4

.SRES 3 ; "ABC" has three characters.
