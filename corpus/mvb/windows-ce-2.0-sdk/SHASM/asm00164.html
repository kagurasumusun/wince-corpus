11.3 Assembler Listing Command Line Options

Table 11.4 lists the command line options concerned with the assembler listing.

Table 11.4 Command Line Options

Command Line Option
Description
LIST
These control output of an assembler listing
NOLIST

SHOW
These control output of the source program listing
NOSHOW

LINES
This sets the number of lines in the assembler listing
COLUMNS
This sets the number of columns in the assembler listing
