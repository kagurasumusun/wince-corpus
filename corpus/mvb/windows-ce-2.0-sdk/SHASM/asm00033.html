2.6.1 Integer Constants

Integer constants are expressed with a prefix that indicates the radix. The radix prefix indicates the base of the constant. Table 2.2 lists integer types and their radix prefix.

Table 2.2 Integer Constants

Integer
Prefix
Binary numbers
The radix indicator B' plus a binary constant
Octal numbers
The radix indicator Q' or O' plus an octal constant
Decimal numbers
The radix indicator D' plus a decimal constant
Hexadecimal numbers
The radix indicator H' or X' or 0x plus a hexadecimal constant

The assembler does not distinguish upper-case and lower-case letters in the radix indicator. The radix indicator and the constant value must be written with no intervening space.

Example:

.DATA.B B'10001000

.DATA.B Q'210 ; These source statements all have the same

.DATA.B O'210 ; numerical value.

.DATA.B D'136

.DATA.B H'88

.DATA.B X'88

.DATA.B 0x88

The radix indicator can be omitted. Integer constants with no radix indicator are normally decimal constants, although the radix for such constants can be changed with the .RADIX assembler directive. See section 5.8.1, .RADIX: Default Integer Constant Radix Setting.
