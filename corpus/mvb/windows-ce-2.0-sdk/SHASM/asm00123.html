7.2.3 .AIF, .AELSIF, .AELSE, and .AENDI: Conditional Assembly

Syntax:

.AIF<condition1>

<Source statements assembled if condition1 is satisfied>

.AELSIF<condition2>

<Source statements assembled if condition1 is not satisfied, but condition2 is satisfied>

.AELSE

<Source statements assembled if neither condition1 nor condition2 is satisfied>

.AENDI

Statement Elements:

Label: The label field is not used

Operation: Enter the .AIF, .AELSIF (can be omitted), .AELSE (can be omitted), or .AENDI mnemonic in the operation field

Operands: .AIF or .AELSIF: Enter the condition. For .AELSE and .AENDI the operand field is not used

Description:

.AIF, .AELSIF, .AELSE, and .AENDI are the assembler directives that select whether or not to assemble source statements according to the condition specified. The .AELSIF and/or .AELSE directives can be omitted. Multiple .AELSIF directives are permitted with a single .AIF, to test a list of conditions in sequence. There may be at most one .AELSE per .AIF. The alternate spellings .AELIF or .AELSEIF may be used in place of .AELSIF. The condition may be any expression with an absolute numeric result value. Expressions whose result is a relative value, or which involve forward references or external references, are not permitted. If the value is non-zero, the source statements up to the following .AELSIF, .AELSE, or .AENDI are assembled, and then any remaining statements up to the .AENDI are skippd. If the value is zero, the next .AELSIF (if any) is considered. If no .AELSIF's remain, and if all of the conditions have been zero, the source statements following the .AELSE are assembled.

For compatibility with other Hitachi assemblers, the following syntax is also supported. Term 1 and term 2 may be any expression (including constants).

The condition may be specified as follows:

.AIF<term1><relational operator><term2>

Terms are specified with numeric values or character values. Table 7.2 lists the relational operators that can be used.

Table 7.2 Relational Operators

Operator
Explanation
EQ
term1 = term2
NE
term1 != term2
GT
term1 > term2
LT
term1 < term2
GE
term1 >= term2
LE
term1 <= term2
Note:

Numeric values are handled as 32-bit signed integers.

Example:

.AIF "\&FLAG" EQ "ON"

MOV R0,R10 ; These statements

MOV R1,R11 ; are assembled

MOV R2,R12 ; when FLAG is "ON".

.AELSE

MOV R10,R0 ; These statements

MOV R11,R1 ; are assembled

MOV R12,R2 ; when FLAG is not "ON".

.AENDI
