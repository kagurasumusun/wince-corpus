1.5 Shasm Warnings & Errors

Shortcuts: 1 40 101 301 400 500 540 611 801 851

1 (FATAL)
Internal error: %s
You should never see this message. If you do, there is a bug in Shasm. It is most helpful if you can report the exact message, and supply a sample program that causes Shasm to issue the message; however, just a report of the precise message is better than not reporting the error at all.
2 (FATAL)
Too many errors (%d) -- stopping assembly
The maximum number of errors was exceeded. You can control the maximum number of errors using the -maxerrors command line option.
3 (FATAL)
%s not yet implemented
You generally should not see this message. If you do, you have attempted to use a feature that is not yet implemented in Shasm, which may (or may not) be a bug; please report the exact message.
10 (ERROR)
No input files were specified -- nothing to do
After parsing all of the command line options, Shasm has no input files that it was able to find and open.
20 (ERROR)
Cannot open file %s: %s
Shasm failed to find or open an input file that you have specified.
21 (ERROR)
Error reading file: %s
You generally should not see this message; it indicates that Shasm was suddenly unable to continue reading input from a file that it successfully opened.
30 (ERROR)
Unknown command line switch "%s"
You specified a command line option that Shasm does not recognize or support.
31 (ERROR)
Syntax error in command line switch "%s": %s
Shasm thinks it knows which command line option you were trying to use, but it doesn’t understand what you meant.
32 (ERROR)
An argument is required for %s
You did not supply an argument for a command line option that requires one.
33 (ERROR)
A numeric argument is required for %s
You did not supply an argument, or you supplied a non-numeric argument, for a command line option that requires a numeric argument.
34 (ERROR)
%s is out of range; must be >= %d and <= %d
You specified a numeric argument that is not within the valid range. The error message will show the valid range for the argument.
35 (ERROR)
Invalid -show/-noshow option list: "%s"
Shasm could not parse some part of a -show or -noshow command line option.
36 (WARNING)
Ignoring unimplemented option "%s"
You used a command line option or assembler directive that specifies a feature that is not currently implemented by Shasm.
37 (WARNING)
Interpreting option "%s" as "%s"
You specified a command line option in a way that could be interpreted in more than one way by Shasm; this message tells you which way Shasm chose to interpret the option. For instance, “-DEBUG” could mean the -D option with the argument EBUG (meaning to define EBUG as 1) or it could mean the switch -debug (enabling output of debugging information). You can avoid this particular case by using -debug (or -DEBUG=1 if you really wanted an EBUG equate).

"%c" is not a valid radix specifier (use HDQBXO)
You attempted to use a radix specifier that Shasm doesn’t recognize. Use one of H, D, Q, B, X, O, h, d,q, b, x, or o.
75 (ERROR)
"%s" is not a valid radix specifier (use HDQBXO)
You attempted to use a radix specifier that Shasm doesn’t recognize. Use one of H, D, Q, B, X, O, h, d,q, b, x, or o.
76 (ERROR)
Overflow in numeric constant
You attempted to write a numeric constant that cannot be represented in 32 bits. The valid range is -2,147,483,648 to 4,294,967,295 or H’00000000 to H’FFFFFFFF.
77 (ERROR)
A backquoted symbol name cannot span multiple lines
You wrote a backquote character (`) which may be used to enclose a symbol whose name contains characters that are not ordinarily allowed, but no matching backquote character was found on the same line. These characters must travel in pairs (with a symbol name between them).
78 (ERROR)
A backquoted symbol name cannot be null (``)
You wrote two adjacent backquote characters (``) which would represent a symbol whose name is null (zero-length), but such a symbol name is illegal. Shasm will also issue this error message if you write a backquote (`) as the last character on a line.
80 (ERROR)
Parser error: %s
You should not see this message; if you do, there is a bug in Shasm (because it should recover from the error and give you a more helpful error message). Please report the exact message, and if possible, provide a source file that causes Shasm to issue the message.
81 (ERROR)
Failed to parse input
You should not see this message; if you do, there is a bug in Shasm (because it should recover from the error and give you a more helpful error message). Please report the exact message, and if possible, provide a source file that causes Shasm to issue the message.
101 (ERROR)

150 (ERROR)
Cannot put a %s instruction in a delay slot
You have attempted to place an instruction in a delay slot that is not allowed in a delay slot.
151 (ERROR)
Can't compute PC displacement in a delay slot
Shasm is not able to compute the PC displacement for a PC-relative addressing mode in a delay slot, because such a displacement must be relative to the PC of the branch target, and that’s hard. Maybe someday, especially since version 2.0 of the Hitachi assembler can do it, and you have to keep up with the Joneses, after all.

312 (ERROR)

400 (ERROR)
Character constant longer than 4 characters: "%s"
A character constant may be no longer than four characters. You may also see this message if you supply a string (or a string-valued symbol or expression) in a context where a number is expected.
402 (ERROR)
%d (0x%x) is out of range; must be >= %d and <= %u
An operand value is outside of the legal range. The message will tell you what the valid range is. You may also see this message when attempting a PC-relative operation (such as a branch, or a MOV @(disp, PC),Rn) to a location that is too far away, or is a backward reference for an instruction that can only support forward references.
403 (ERROR)

404 (ERROR)

405 (ERROR)
Can't %s import symbols or between sections
Only certain arithmetic operations are supported on relative values and external symbols; refer to section 1.6 (Expressions, above) for more information.
406 (ERROR)
Can't %s expr w/%d reloc%s and expr w/%d reloc%s
Only certain arithmetic operations are supported on relative values and external symbols; refer to section 1.6 (Expressions, above) for more information.
408 (ERROR)
Cannot divide by zero
Really, you can’t.
413 (ERROR)

The only supported relational operators (besides the regular C operators) are EQ, NE, GT, LT, GE, and LE (regardless of upper or lower case).

870 (WARNING)

871 (WARNING)

Beware! When you write a PC-relative instruction in a delay slot, the PC that it is relative to is the PC of the branch destination!
876 (WARNING)

880 (WARNING)
Function end after delayed branch
Shasm encountered a .ENDF directive (or the end of the input file or section) with a branch’s delay slot still unfilled. Shasm supplies a NOP to fill the delay slot, since executing garbage is no fun.
882 (WARNING)
Can't align delay slot instruction for SH-3 rev 3
You’ll only see this message if you use the -Qsh3r3 command line option; it means that Shasm wanted to align an instruction, but it couldn’t because the instruction in question was in a delay slot. You’re on your own for that one. Consider using .AIF to conditionalize any change you make on the value of _M_SH_REV, so that you won’t affect your code except when assembling for the SH-3 revision 3.
886 (WARNING)
