5.6.9 .DEBUG: Symbolic Debug Information Output Control

To support the requirements of structured exception handling and provision of stack traces in the debugger, object files must contain information regarding where functions begin and end, and what part of each function is devoted to setting up the function’s stack frame. Programmers coding in assembly language provide this information using the following directives:

.ENTRY: Defines a function and marks its beginning.

.BIGENTRY: Defines a large function and marks its beginning.

.PROLOG: Marks the end of the function prolog. The function prolog is the code at the beginning of the function that sets up the function’s stack frame, in accordance with the Calling Standard Specification.

.ENDF: Marks the end of the function.

.PDATA: Defines the language specific exception handler, and optionally data for that handler, for the following or current function.

Note:

For more detailed information on prolog code and related topics, refer to the Calling Standard Specification document. This section is primarily concerned with the syntax and semantics of the relevant assembler directives. It is recommended that programmers use the calling convention macros described in the Calling Standard Specification, rather than directly using these directives.
