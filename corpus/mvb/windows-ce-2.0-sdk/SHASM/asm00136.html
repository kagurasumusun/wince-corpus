8.3.2 Preprocessor Variable Reference

Preprocessor variables can be referenced in macro bodies. The syntax for preprocessor variable reference is as follows:

\&<preprocessor variable name>[']

To clearly distinguish the formal parameter name from the rest of the source statement, add an apostrophe (').

It is important to note that preprocessor variable references are handled differently in macro bodies. Outside of macro bodies, these symbols always consistute a token of their own (either a numeric constant or a string constant); you may not include them as part of another token. Inside a macro body, you may insert a preprocessor variable reference anywhere, and it will be substituted before token boundaries are determined.

Example:

.MACRO PLUS1

ADD #1,R\&V1 ; Preprocessor variable V1 is referenced.

.SDATA "\&V'1" ; Preprocessor variable V is referenced.

.ENDM

V .ASSIGNC "R" ; Preprocessor variable V is defined.

V1 .ASSIGNC 1 ; Preprocessor variable V1 is defined.

PLUS1 ; PLUS1 is expanded.

Expanded results are as follows:

ADD #1,R1 ; Preprocessor variable V1 is referenced.

.SDATA "R1" ; Preprocessor variable V is referenced.
