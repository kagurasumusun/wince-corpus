8.3.7 Macros Defined By (Within) Other Macros

Macros can be defined by (in) another macro, although it is not possible to define a macro inside an .AWHILE or .AREPEAT loop. This works much as might be expected; the only non-obvious part is ensuring that the .ENDM for the nested macro isn't interpreted as the end of the outer macro. The following examples show two methods of accomplishing this.

Example:

.macro defit name,code,dummyarg

.macro \name

\code

\dummyarg .endm

.endm

.macro defit2 name,code,endmarg=“.endm”

.macro \name

\code

\endmarg

.endm

.macro defit3 name,code,argpref,endmarg=“.endm”

.macro \name arg

\code \argpref\(\arg)

\endmarg

.endm

defit narp,nop

defit2 slurp,sleep

defit3 trabbit,trapa,”#”

narp ; same as nop

slurp ; same as sleep

trabbit 4 ; same as trapa #4
