7.2.8 .ALIMIT: Limit .AWHILE Expansion

Syntax:

.ALIMIT<maximum count>

Statement Elements:

Label: The label field is not used

Operation: Enter the .EXITM mnemonic in the operation field

Operands: Enter the maximum number of times to expand .AWHILE statements

Description:

The .ALIMIT directive specifies the upper limit value for expansion of the .AWHILE directive in the preprocessor. During expansion of the .AWHILE directive, if the statement expansion count exceeds the upper limit value specified by this directive, a warning message is output and the expansion is terminated. If this directive is not specified, the upper limit value is 65535.

Example:

FLG .ASSIGNA 0

.ALIMIT 20

.AWHILE \&FLG eq 0

NOP

.AENDW
