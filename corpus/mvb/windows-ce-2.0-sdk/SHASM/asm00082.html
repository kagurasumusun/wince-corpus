5.4.10 .RES: Data Area Reservation

Syntax:

[<symbol>[:]].RES[.<operation size>]<area count>

Statement Elements:

Label: Enter a reference symbol in the label field if required

Operation: Enter .RES mnemonic in the operation field

Operation size: The specifier determines the size of one area; the longword size is used when the specifier is omitted, as shown in Table 5.10

Operands: Enter the number of areas to be reserved in the operand field

Table 5.10 Operation Size

Specifier
Data Size
B
Byte
W
Word (2 bytes)
L default)
Longword (4 bytes)

Description:

.RES is the assembler directive that reserves data areas in memory. The area count specification must be an absolute value, and forward reference symbols must not appear in the specification. The range of values that can be specified as the area count varies with the operation size, as listed in Table 5.11.

Table 5.11 Operation Size Specified by Area Count Range

Operation Size
Area Count Range
B
H'00000001 to H'FFFFFFFF (1 to 4,294,967,295)
W
H'00000001 to H'7FFFFFFF (1 to 2,147,483,647)
L
H'00000001 to H'3FFFFFFF (1 to 1,073,741,823)

Example:

.ALIGN 4 ; This statement adjusts the value of the location

; counter.

X: .RES.L 2 ; This statement reserves 2 longword size areas.

.RES.W 3 ; This statement reserves 3 word size areas.

.RES.B 5 ; This statement reserves 5 byte size areas.
