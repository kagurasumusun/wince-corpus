5.4.7 .SDATACB: Character String Data Blocks Reservation with Length

Syntax:

[<symbol>[:]].SDATACB<block count>,<character string>

Statement Elements:

Label: Enter a reference symbol in the label field if required

Operation: Enter the .SDATACB mnemonic in the operation field

Operands: First operand: (block count) Enter the number of character strings as the first operand
Second operand: (character string) Enter the character string to be reserved as the second operand

Description:

.SDATACB is the assembler directive that reserves the specified number of character strings (each with length) consecutively in memory. A character string with length is a character string with an inserted leading byte that indicates the length of the string. The length indicates the size of the character string (not including the length) in bytes. See section 2.9, Character Strings. The block count specification must be an absolute value, and forward reference symbols must not appear in the specification. A value of 1 or larger must be specified as the block count. The maximum value of the block count depends on the length of the character string data. The length of the character string data multiplied by the block count must be less than or equal to H'FFFFFFFF (4,294,967,295 bytes).

A control character can be appended to a character string. The syntax for this notation is as follows:

<character string><<ASCII code for a control character>>

The ASCII code for a control character specification must be an absolute value, and forward reference symbols must not appear in the specification.

Example:

.ALIGN 4 ; This statement adjusts the value of

; the location counter.

X: .SDATACB 2,"AAAAA" ; This statement reserves two character

; string data blocks.

.SDATACB 2,"""BBB""" ; The character string in this example

; includes double quotation marks.

.SDATACB 2,"ABAB"<H'07> ; The character string in this example

; has a control character appended.
