2.5.2 Symbol Coding

Keep the following protocol in mind when coding symbols:

Available characters: The following members of the ASCII character set can be used:

Upper-case and lower-case letters (A to Z, a to z)

Numbers (0 to 9)

The underscore character (_)

The dollar sign character ($)

The assembler distinguishes between upper-case and lower-case in symbols

Initial Symbol Characters: The first character in a symbol must be one of the following:

Upper-case and lower-case letters (A to Z, a to z)

The underscore character (_)

The dollar sign character ($)

The assembler provides a method to reference symbols whose names contain characters other than those normally allowed. This is required in order to support “mangled” names for C++, such as output by the compiler when it is given the -S or -FAs options.

Any symbol name may be enclosed in backquotes (ASCII character 0x60); the symbol name will then be comprised of any and all characters occurring between the first and second backquotes. There is no way to define a symbol whose name contains a backquote character. It is possible to use this method to reference symbols whose names may be handled incorrectly by other tools (such as the linker, operating system loader, etc.); the assembler does no checking of any kind on the validity of the name.

Example:

`.legal?symbol@thisway`: .data 0

.import `_??abc@@@xyz`

mov #`_??abc@@@xyz`+5,r1

Maximum length of a symbol: A symbol may contain an unlimited number of characters. Reserved words cannot be used as symbols. The following names must not be used because they are used as internal symbols by the assembler:

_$$nnnnn (n is a number from 0 to 9.)

Note:

1. Internal symbols are necessary for assembler internal processing. internal symbols are not output to assembler listings.

Note:

2. The dollar sign character used alone is a reserved word that expresses the location counter. See section 2.4, Reserved Words.
