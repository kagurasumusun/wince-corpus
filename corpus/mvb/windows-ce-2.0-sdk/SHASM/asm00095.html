5.6.5 .PDATA: Language Handler and/or Handler Data

Syntax:

.PDATA<handler address>[,<handler data>]

Statement Elements:

Label: The label field is not used

Operation: Enter the .PDATA mnemonic in the operation field

Operands: Enter the address of the language specific handler, optionally followed by the address of the data to be used by the handler

Description:

The .PDATA directive specifies a language specific exception handler for the following or current function. The .PDATA directive must appear before the .ENTRY or .BIGENTRY section to which it applies. The exception handler should be the address of a function, although no warning or error will be issued for a non-relative operand. The programmer may optionally also provide one longword (4 bytes) of data for use by the exception handler. Depending on the handler, that data may also be a pointer (an address). The handler address and handler data operands may be arbitrary expressions.

Forward references and relative values are permitted. The .PDATA directive is not persistent; it applies to no more than one function. To specify an exception handler (and optionally handler data) for more than one function, a .PDATA directive must be supplied for each such function. Also, function information (including information supplied by .PDATA directives) is maintained separately for each section. The .PDATA directive is optional. The assembler issues no error or warning messages if the .PDATA directive is not supplied.

Example:

.section .text

.import ex_handler

.import handler_data

; set up exception handler for following function (fun1 in

; this case).

.pdata ex_handler,handler_data

fun1: .entry

.prolog

rts

nop

.endf

; fun1 uses ex_handler & handler_data.

fun2: .entry

.prolog

rts

nop

.endf

; fun2 has no exception handler or handler data (both 0).

.pdata ex_handler

fun3: .entry

.prolog

rts

nop

.endf

; fun3 uses ex_handler; handler data is 0 (the default).

.pdata fun4,5

fun4: .entry

.prolog

rts

nop

.endf

; fun4 is its own exception handler (probably a bad idea);

; handler data is a constant 5.

fun5: .entry

.prolog

rts

nop

.endf

.pdata ex_handler

; fun5 has no exception handler or handler data; the .pdata

; directive above applies to the next function. (The assembler

; issues a warning if no function follows in the same section,

; since in that case the .pdata directive would have no effect.)
