8.3.6 Character String Manipulation Functions

Character string manipulation functions can be used in the body of a macro as well as anywhere else an expression is valid. Table 8.1 lists the character string manipulation functions. For more information, see section 8.5, Character String Manipulation Functions.

Table 8.1 Character String Manipulation Functions

Function
Purpose
.LEN
Character string length
.INSTR
Character string search
.SUBSTR
Character string substring
