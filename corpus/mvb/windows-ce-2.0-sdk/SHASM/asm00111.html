5.8.3 .WEAK: Define "Weak External" Symbol

Syntax:

.WEAK<weak name>,<default name>[,<type>]

Statement Elements:

Label: The label field is not used

Operation: Enter the .WEAK mnemonic in the operation field

Operands: Enter the name of the symbol to define weakly, followed by the name of the symbol to use as the definition if no other definition is found at link time, optionally followed by the weak external type

Description:

The .WEAK directive may be used to define a “weak external” symbol. Weak externals are a mechanism for programs allowing flexibility at link time. A .WEAK directive such as:

.weak unlink,__unlink

indicates that when the program is linked, if the the symbol “unlink” is defined by any object file, then references to “unlink” are resolved to its definition normally. However, if the symbol “unlink” is not defined by any object file, then references to “unlink” are resolved to “__unlink” instead. (The symbol “__unlink” must be defined in exactly one of the object files, or an error will result.)

The optional type argument is an expression (whose value must be absolute) giving the type of weak external. If the value is zero or the third argument is omitted, the “alias” type of weak external is generated. This is generally desirable; the optional third argument would not normally be used.

Example:

.weak foo,bar,1

NO_SEARCH .equ 1

SEARCH_LIB .equ 2

.weak ick,yuk,NO_SEARCH

.weak snap,crackle,SEARCH_LIB

If a symbol appears in the third argument position, and the symbol happens to be relative, the assembler will issue error 404. The error does not indicate that relative symbols or expressions cannot be used in a .WEAK directive, but that the third argument has to have an absolute value.

Note that the C and C++ compilers prepend a _ (an underscore) to each symbol name. Consequently, if unlink and __unlink were defined and referenced in assembly language, the .WEAK directive would be coded as shown in the first above example. If unlink and __unlink were defined and referenced in C code, the .WEAK directive would be coded as follows:

.weak _unlink,___unlink
