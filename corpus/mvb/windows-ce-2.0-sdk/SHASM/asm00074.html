5.4.2 .DATA: Integer Data Reservation

Syntax:

[<symbol>[:]].DATA[.<operation size>]<integer data>[,<integer data>...]

Statement Elements:

Label: Enter a reference symbol in the label field if required

Operation: Enter .DATA mnemonic in the operation field

Operation size: The specifier determines the size of the reserved data; the longword size is used when the specifier is omitted (Table 5.5)

Operands: Enter the values to be reserved as data in the operand field

Table 5.5 Operation Size Determined by Specifier

Specifier
Data Size
B
Byte
W
Word (2 bytes)
L (default)
Longword (4 bytes)

Description:

.DATA is the assembler directive that reserves integer data in memory. Arbitrary values, including relative values and forward reference symbols, can be used to specify the integer data.

The range of values that can be specified as integer data varies with the operation size, as listed in Table 5.6.

Table 5.6 Integer Data Value Ranges

Operation Size
Integer Data Range
B
H'00000000 to H'000000FF (0 to 255)

H'FFFFFF80 to H'FFFFFFFF (-128 to -1)
W
H'00000000 to H'0000FFFF (0 to 65,535)

H'FFFF8000 to H'FFFFFFFF (-32,768 to -1)
L
H'00000000 to H'7FFFFFFF (0 to 4,294,967,295)

H'80000000 to H'FFFFFFFF (-2,147,483,648 to -1)

Example:

.ALIGN 4 ; This statement adjusts the value of

; the location counter.

X: .DATA.L H'11111111 ;

.DATA.W H'2222,H'3333 ; These statements reserve integer data.

.DATA.B H'44,H'55 ;
