8.5.2. INSTR: Character String Search

Syntax:

.INSTR[](<character string 1>,<character string 2>

[,<start position>])

Description:

.INSTR searches character string 1 for character string 2, and evaluates to the numerical value of the position of the found string (with 0 indicating the start of the string). .INSTR evaluates to -1 if character string 2 does not appear in character string 1. The character string arguments may be any expression whose value is a character string, including a preprocessor variable defined with .ASSIGNC, a constant string enclosed in double quotation marks (" "), and the .SUBSTR function and/or + operation.

The <start position> parameter specifies the search start position as a numerical value, with 0 indicating the start of the string. Zero is used as default when this parameter is omitted.

Example:

.MACRO FIND_STR \P1

.DATA.W .INSTR("ABCDEFG","\P1",0).

.ENDM

FIND_STR CDE

FIND_STR H

Expanded results are as follows:

.DATA.W 2 ; The start position of "CDE" is 2 (0 indicating the

; beginning of the string) in "ABCDEFG"

.DATA.W -1 ; "ABCDEFG" includes no "H".
