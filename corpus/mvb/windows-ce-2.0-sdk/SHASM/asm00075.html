5.4.3 .DATAB: Integer Data Block Reservation

Syntax:

[<symbol>[:]].DATAB[.<operation size>]<block count>,<integer data>

Statement Elements:

Label: Enter a reference symbol in the label field if required

Operation: Enter .DATAB mnemonic in the operation field

Operation size: The specifier determines the size of the reserved data; the longword size is used when the specifier is omitted (Table 5.7)

Operands: First operand: (block count) Enter the number of times the data value is repeated as the first operand
Second operand: (integer data) Enter the value to be reserved as the second operand

Table 5.7 Integer Data Block Reservation Sizes

Specifier
Data Size
B
Byte
W
Word (2 bytes)
L (default)
Longword (4 bytes)

Description:

.DATAB is the assembler directive that reserves the specified number of integer data consecutively in memory. The block count specification must be an absolute value, and forward reference symbols must not appear in the specification. Arbitrary values, including relative values and forward reference symbols, can be used to specify the integer data.

The range of values that can be specified as the block size and as the integer data varies with the operation size is listed in Table 5.8. Block size limits are theoretical. The maximum values that can be successfully used are smaller and depend on the amount of memory available.

Table 5.8 Operation Size Specified by Block Size Range

Operation Size
Block Size Range

B
H'00000001 to H'FFFFFFFF (1 to 4,294,967,295)
W
H'00000001 to H'7FFFFFFF (1 to 2,147,483,647)
L
H'00000001 to H'3FFFFFFF (1 to 1,073,741,823)
Table 5.9 Operation Size Specified by Integer Data Range

Operation Size
Integer Data Range
B
H'00000000 to H'000000FF (0 to 255)

H'FFFFFF80 to H'FFFFFFFF (-128 to -1)
W
H'00000000 to H'0000FFFF (0 to 65,535)

H'FFFF8000 to H'FFFFFFFF (-32,768 to -1)
L
H'00000000 to H'7FFFFFFF (0 to 4,294,967,295)

H'80000000 to H'FFFFFFFF (-2,147,483,648 to -1)

Example:

.ALIGN 4 ; This statement adjusts the value of the

; location counter.

X: .DATAB.L 1,H'11111111 ; This statement reserves one block of longword-size

; integer data.

.DATAB.W 2,H'2222 ; This statement reserves two blocks of word-size integer ; data.

.DATAB.B 3,H'33 ; This statement reserves three blocks of byte-size

; integer data.
