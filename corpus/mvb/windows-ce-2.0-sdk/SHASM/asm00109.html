5.8.1 .RADIX: Default Integer Constant Radix Setting

Syntax:

.RADIX<radix specifier>

Statement Elements:

Label: The label field is not used

Operation: Enter the .RADIX mnemonic in the operation field

Operands: (radix specifier) This specifier sets the radix (base) for integer constants with no radix specification (Table 5.18)

Table 5.18 Radix Specifier Integer Constants

Radix Specifier
Radix of Integer Constants
B (or b)
Binary
Q (or q)
Octal
O (or o)
Octal
D (or d) (default)
Decimal
H (or h)
Hexadecimal
X (or x)
Hexadecimal

Description:

.RADIX is the assembler directive that sets the radix (base) for integer constants with no radix specification. When there is no radix specification with the .RADIX directive in a program, integer constants with no radix specification are interpreted as decimal numbers. If hexadecimal (radix specifier H) is specified as the radix for integer constants with no radix specification, integer constants whose first digit is A through F must be prefixed with a 0 (zero). The assembler interprets expressions that begin with A through F to be symbols. Specifications with the .RADIX directive are valid from the point of specification forward in the program.

Example:

.RADIX D

X: .EQU 100 ; This 100 is decimal.

.RADIX H

Y: .EQU 64 ; This 64 is hexadecimal.

.RADIX X

Z: .EQU 0F ; A zero is prefixed to this constant "0F"

; since it would be interpreted as a symbol if

; it were written as simply "F".
