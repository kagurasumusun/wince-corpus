3.4.2 Declaration of Export Symbols and Import Symbols

When a source program consists of multiple files, referencing a symbol defined in one file from another file is called external reference or import. When referencing a symbol externally (this declaration is called external definition or export), it is necessary to declare to the assembler that this symbol is shared between multiple files.

Export Symbol Declaration: This declaration is used to declare that the definition of the symbol is valid in other files. The .EXPORT or the .GLOBAL assembler directive is used to make this declaration.

Import Symbol Declaration: This declaration is used to declare that a symbol is defined in another file. The or the .GLOBAL assembler directive is used to make this declaration.

Declaration of Export Symbols and Import Symbols: The assembler does not support the use of .IMPORT, .EXPORT, or .GLOBAL for absolute symbols. Only relative symbols can be imported and exported. This restriction is due to limitations of the MS-COFF object format.

Example:

In this example, the symbol TABLE is defined in file A and referenced in file B.

File A:

.EXPORT TABLE ; Declares TABLE to be an export symbol

TABLE: .DATA.L 11,9,68 ; Defines TABLE

.DATA.L 3,17,72

File B:

.IMPORT TABLE ; Declares TABLE to be an import symbol

MOV #TABLE,R1 ; References TABLE (R1 = address of TABLE)

MOV.L @(8,R1),R2 ; Loads 3rd item from table (R2 = 68)

See section 5.5, Export and Import Assembler Directives.
