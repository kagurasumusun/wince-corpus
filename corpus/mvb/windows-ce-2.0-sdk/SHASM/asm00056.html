4.1.2 Operation Size

The operation size is the unit for processing data. The operation sizes vary with the executable instruction. The assembler does not distinguish upper-case and lower-case letters in the operation size. Table 4.1 lists the size of the data by specifier.

Table 4.1 Specifier Data Size

Specifier
Data Size
B
Byte
W
Word (2 bytes)
L
Longword (4 bytes)
