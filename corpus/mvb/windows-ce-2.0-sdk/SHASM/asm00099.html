5.6.9 .DEBUG: Symbolic Debug Information Output Control

Syntax:

.DEBUG<output specifier>

Statement Elements:

Label: The label field is not used

Operation: Enter the .DEBUG mnemonic in the operation field

Operands: (output specifier) The output specifier controls symbolic debug information output, as shown in Table 5.13

Table 5.13 Symbolic Debug Information Specifier

Output Specifier
Output Control
ON (default)
Symbolic debug information is output starting with the next source statement
OFF

Symbolic debug information is not output starting with the next source statement

Description:

.DEBUG is the assembler directive that controls the output of symbolic debug information. This directive allows assembly time to be reduced by restricting the output of symbolic debug information to only those symbols required in debugging. The specification of the .DEBUG directive is only valid when both an object module and debug information are output.

See also section 11.2, Command Line Option Reference, and section 5.6.8, .OUTPUT: Object Module Output Control.

Example:

.DEBUG OFF ; Starting with the next statement, the

; assembler does not output symbolic debug

; information.

.DEGUG ON ; Starting with the next statement, the

; assembler does output symbolic debug

; information.

Note:

The term symbolic debug information refers to the parts of debug information concerned with symbols.
