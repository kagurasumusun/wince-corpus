2.8.3 Notes on Expressions

Internal Processing: The assembler regards expression values as 32-bit signed values.

Example:

~H'F0

; The assembler regards H'F0 as H'000000F0.

; Therefore, the value of ~H'F0 is H'FFFFFF0F (note that this is not

; H'0000000F).

Arithmetic Operators: Any expressions (arithmetic) involving relative symbols (symbols whose values cannot by determined until link time) must be reducible (by computing subparts of the expression whose operands are known at assembly time) to one of the following forms:

expr: constant

| symbol

| expr + expr

| expr - constant
