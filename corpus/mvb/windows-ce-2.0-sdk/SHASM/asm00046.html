3.2.2 Relative Values

The relative values handled by the assembler include relative address values, external reference values, and other relative values.

Relative Address Values:

The location counter referenced in a relative address segment

Symbols that have the above as a value are referred to as relative address symbols

External Reference Values: Symbols that reference another file are referred to as import symbols.

Other Relative Values: Expressions whose value is determined by the linkage editor.
