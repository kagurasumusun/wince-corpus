9.2 Extended Instructions Related to Automatic Literal Pool Generation

The assembler automatically generates a literal pool corresponding to an extended instruction (MOV.W #imm, Rn; MOV.L #imm, Rn; or MOVA #imm, R0) and calculates the PC relative displacement value.

A move immediate instruction can be written as follows:

MOV #expr,Rn

Note the absence of any operation size specifier. The assembler computes the value of expr and automatically selects the most appropriate operation size. If expr is an absolute value in the range -128 to +127, inclusive, a MOV.B #expr,Rn instruction will be generated. If expr is an absolute value in the range -32768 to +32767, inclusive, a MOV.W @(disp, PC),Rn and a corresponding word-size literal pool entry will be generated. Otherwise, including any case where expr's value relies on imported symbols or forward references, a MOV.L @(disp, PC),Rn and a corresponding longword-size literal pool entry will be generated.

An extended instruction source statement is expanded to an executable instruction and literal data as shown in Table 9.1.
