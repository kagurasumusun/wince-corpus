5.4.1 .COMMON: Data Reservation with Default Zero Initialization

Syntax:

.COMMON<symbol name>[,<size>]

Statement Elements:

Label: The label field is not used

Operation: Enter .COMMON mnemonic in the operation field

Operands: Enter the name of the common symbol to define, optionally followed by the number of bytes that the data occupies (defaults to zero)

Description:

The .COMMON directive may be used to define a symbol that should be initialized to zero unless some other object file calls for it to be initialized to a specific value. This facility is necessary to support the equivalent of (and assemblable listing for) C code such as the following example, which in external (file) scope means that if no other file defines and initializes variable a, then a should be placed in the .bss section, which causes it to be initialized to 0.

Example:

int a;

If another file defines a, such as in the following example, then both files will refer to the same variable a, which will be initialized to 5, and no link error will result.

Example:

int a = 5;

Note:

This works differently in C++; the C++ language requires that linking the above example would result in a link error.

Example:

.common _foo,4

.common _bar,2

.common __fltused

The preceding examples are equivalent to this C code:

int foo;

short bar;

void f (void)

{

float a = 4.5; // force __fltused symbol

}
