2.2.2 Operation Coding

The operation is written starting in the second or later column when there is no label, and written after the label, separated by one or more spaces or tabs, when there is a label.

Example:

ADD R0,R1 ; An example with no label.

LABEL1: ADD R1,R2 ; An example with a label.

Note:

Since white spaces and tabs are ASCII characters, each space or tab requires a byte of storage.
