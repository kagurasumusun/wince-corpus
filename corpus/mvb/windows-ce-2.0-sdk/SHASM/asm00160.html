11.1 Overview of Command Line Options

Command line options are detailed specifications of the assembly processing. Table 11.1 shows an overview of the command line options.

Table 11.1 Command Line Options

Type
Command Line Option
Function
Object module specifications
-OBJECT
-NOOBJECT
Control output of an object module

-DEBUG
-NODEBUG
Control output of debug information



Assembler listing specifications
-LIST
-NOLIST
Control output of an assembler listing

-SHOW
-NOSHOW
Control output of the source program listing

-LINES
Sets the number of lines in the assembler listing

-COLUMNS
Sets the number of columns in the assembler listing

-FoOBJPATH
Where OBJPATH is the path to which the object should be written
Essentially a synonym for the -o=OBJPATH (-object=OBJPATH) option. Provided for compatibility with Microsoft-based tools.



Other specifications
-wide[_listing]
Shows up to 8 bytes of machine code or data per line in the assemble listing. Default is 4 bytes per line.

-nowide[_listing]
Shows up to 4 bytes of machine code or data per line in the assemble listing. This is the default behavior.

-tab[_expand][=<number>]
Expands tab characters in the assemble listing. The number, if specified, is the spacing of tab stops. Default is 8.

-Notab[_expand]
Writes tab characters into the assemble listing unchanged. This is the default behavior.

-maxerr[ors]=<number>
Aborts the assembly after <number> errors have been reported. Default is 100.

-Qsh<version>[r<revision>]
Selects SH microprocessor version <version>, revision <revision> which controls the setting of the _M_SH and _M_SH_REV predefined symbols. Default is version 3, revision 6 (ie, -Qsh3r6).

-nologo
Instructs not to print the logo banner (copyright notice) when it runs.

-help and -usage (currently identical)
Output a detailed command line usage message and exit immediately.

-D<name>[=<number>]
Predefines an equate; for example, -DFOO is equivalent to "FOO: .equ 1" in the source file; -DFOO=3 means "FOO: .equ 3".

The assembler listing is a listing to which the results of the assembly processing are output. See appendix C, Assembler Listing Example, for a detailed description of the assembler listing.
