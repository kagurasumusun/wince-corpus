5.6.3 .PROLOG: End of Function's Prolog Code

Syntax:

.PROLOG

Statement Elements:

Label: The label field is not used

Operation: Enter the .PROLOG mnemonic in the operation field

Operands: The operand field is not used

Description:

The .PROLOG directive marks the end of the prolog code of a function. The prolog code is the code at the beginning of a function that sets up the stack frame for the function, in accordance with the Calling Standard Specification. This includes saving the PR register, pushing other registers onto the stack, setting up the frame pointer, etc. See the Calling Standard Specification for reference. The .PROLOG directive should appear between the last line of prolog code and the first line of non-prolog code for the function. If the function has no prolog code, then the .PROLOG directive should appear between the .ENTRY directive for the function and the first line of code in the function.

It is important that the .PROLOG directive be used appropriately, and that the prolog code (and the epilog code) of each function conform to the Calling Standard Specification. Otherwise, structured exception handling may not work correctly, and the debugger may be unable to provide stack traces. If the .PROLOG directive is not specified for a function (ie, an .ENDF directive is encountered without a .PROLOG directive having been encountered since the most recent .ENTRY directive), the assembler will issue a warning, and act as though the .PROLOG directive had been specified immediately following the .ENTRY directive. This effectively indicates that the function has no prolog code. If the function does in fact have prolog code, then structured exception handling and stack tracing may not operate properly. It is best to always use a .PROLOG directive, even if the function has no prolog code.

Example:

fun6: .entry

; this is the prolog code:

mov.l r14,@-sp

mov.l r8,@-sp

sts.l pr,@-sp

mov sp,fp

add #12,fp

; end of prolog code.

.prolog ; mark end of prolog code

add #-16,sp

; function code goes here

mov fp,r2

add #-12,r2

lds.l @r2+,pr

mov.l @r2+,r8

mov r2,sp

rts

mov.l @sp+,fp

.endf
