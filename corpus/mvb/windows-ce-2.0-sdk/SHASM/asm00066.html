5.2.2 .ORG: Location Counter Value Setting

Syntax:

.ORG<location-counter-value>

Statement Elements:

Label: The label field is not used

Operation: Enter the .ORG mnemonic in the operation field

Operands: Enter the new value for the location counter in the operand field

Description:

.ORG is an assembler directive that sets the value of the location counter within the current section. The .ORG assembler directive is used to place executable instructions or data at a specific address. The location counter value specified must be an absolute value, and forward reference symbols must not appear in the specification. The values allowed for the location counter value are from H'00000000 to H'FFFFFFFF (-2,147,483,648 to 4,294,967,295 in decimal). However, a practical limit is imposed by the size of available memory.

The .ORG assembler directive may not be used to set the location counter backward (e.g., to set the location counter to a value which is less its current value). When the .ORG assembler directive is used to set the location counter forward, the memory locations between the old location counter value and new location counter value are set to zero.

Example:

.SECTION DT,DATA

.DATA.L H'11111111

.ORG H'00000F00 ; This statement sets the value of the location

; counter.

.DATA.L H'22222222 ; The integer data H'22222222 is stored at

; offset H'00000F00 within section DT.

Example:

.SECTION .text

.DATA.L 0

; the location counter is now 4.

.ORG 0x100

; the location counter is now 0x100;

; locations from 0x4 to 0xFF (inclusive) are set to 0 (zero).

.DATA.L 0x100

; the location counter is now 0x104

.ORG 0x80 ; this directive is illegal!

; the previous line got an error message;

; the location counter is still 0x104.
