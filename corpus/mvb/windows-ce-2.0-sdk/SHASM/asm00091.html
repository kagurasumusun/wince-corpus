5.6.1 .ENTRY: Function Definition

Syntax:

<symbol>[:].ENTRY

Statement Elements:

Label: Enter a reference symbol in the label field; this is required

Operation: Enter the .ENTRY mnemonic in the operation field

Operands: The operand field is not used

Description:

The .ENTRY directive marks the beginning of a function, and associates a name with that function. The .ENTRY (or .BIGENTRY) directive should be inserted before the first line of code (.DATA and related directives are fine). If the assembler encounters code before any .ENTRY (or after a .ENDF, with no intervening .ENTRY), a warning is issued and the assembler acts as though a .ENTRY directive had been found immediately before the line of code.

The label operates as a normal label (causing the symbol to be defined with the current value of the location counter as the value of the symbol). The label also associates the symbol with the function.

Refer to examples given in the PDATA directive section.
