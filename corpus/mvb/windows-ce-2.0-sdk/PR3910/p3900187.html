9.4.3 Servicing

The unused bits of the SDBBP instruction (bit 26 to 6) can be used for passing additional information to the exception handler. In order to allow these bits to be looked at, the user program should load the contents of the memory word containing this instruction, using the DEPC register. When Cause register BD bit is set as 1 (SDBBP instruction in branch delay slot), the value in EPC register should be added +4.
