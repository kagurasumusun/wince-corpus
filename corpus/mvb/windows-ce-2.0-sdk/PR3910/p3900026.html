4.2.1 Reserved Registers and Bits for CP0

There are two types of CP0 registers - CP0 baseline registers and implementation-dependent registers. CP0 baseline registers are the status, cause, epc, badvaddr and prid registers. All other registers are implementation dependent. The following is how the reserved registers and bits should be treated:

All unused registers are reserved and undefined. Users should not write to these registers. If users want to write to these registers, only zeroes should be written.

All reserved bits for the CP0 baseline and the implementation-dependent registers must be written with 0’s. Writing a different value may cause undefined results for future generation cores.
