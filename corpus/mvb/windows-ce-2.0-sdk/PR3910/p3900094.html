CACHE CACHE

Format : CACHE op, offset(base)

Description : The 16-bit offset is sign-extended and added to the contents of general register base to form a virtual address.The virtual address is translated to a physical address and the 5-bit sub-opcode specifies a cache operation for that address.

If CP0 is unusable (in User mode), the status register CP0 enable bit is cleared and a Coprocessor Unusable exception is taken.The operation of this instruction or any cache combinations other than those listed in the table below is undefined. The operation of this instruction on uncached addresses is also undefined. The Index operation uses part of the virtual address to specify a cache block.

For a primary cache of 2CACHESIZE bytes with 2BLOCKSIZE bytes per tag, a block is designated as vAddrCACHESIZE-1..BLOCKSIZE for direct cache.

The Hit operation accesses the specified cache as normal data references, and performs the specified operation if the cache block contains valid data with specified physical address (a hit). If the cache block is invalid or contains a different address (a miss) no operation is performed. Bits 17..16 of the instruction specify the cache as follows:
