LW Load Word

Format : LW rt,offset(base)

Description : The 16-bit offset is sign-extended and added to the contents of general register base to form a 32-bit unsigned effective address. The contents of the word at the memory location specified by the effective address are loaded into general register rt. If either of the two least significant bits of the effective address is non-zero, an address error exception occurs.

Operation :

T: vAddress (offset15)16 || offset15..0 + GPR[base]

(pAddress, nonCacheable) AddrTranslation (vAddress)

mem LoadMemory (nonCacheable, WORD,pAddress)

byte vAddress1..0

T + 1: GPR[rt] mem;

Exceptions : Bus error exception

Address error exception
