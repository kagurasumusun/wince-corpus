3.1.2 Interlocked Load Delay Slots

If the compiler cannot find an instruction that can be executed in a load delay slot, the PR3910 core will interlock for one CPU cycle so that the load data is available for the ALU.

Figure 3-3 Interlocked Load Delay Slot

For compilers that do not assume delay slot can be interlocked, they typically put a nop instruction in the unitized delay slot.
