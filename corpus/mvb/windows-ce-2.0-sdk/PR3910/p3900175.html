9.2.6 Instruction Break Address Mask 0

This register specifies mask value for Instruction Break Address Register (IBA0). Each bit is correspond to a bit in address register. It is located at address 0xFF30-0108.

Register Instruction Break Address Mask 0 - IBAM0 Read/Write

0: Data bit is not masked, data bit is compared

1: Data bit is Masked, data bit is not compared
