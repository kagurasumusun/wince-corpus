3.1.3 Branch Delay Slot

Jump or branch instructions require more than one CPU cycles to execute, because the target address of the jump or branch must be calculated. Therefore, an instruction follows a jump or branch instruction, can be executed prior to the branch while the branch target address is being generated. A branch delay slot is illustrated in 1.

Figure 3-4 Jump/Branch Delay Slot

As seen above, the address for the jump or branch is not available for calculation until the RD phase of the jump or branch instruction. The target address is therefore not available until the instruction following the jump or branch. A delay slot is added following each jump or branch taken. This delay slot is usually filled by an instruction that can always be executed and the penalty for this delay slot is eliminated.

The PR3910 instruction set includes branch likely instructions. A branch likely instruction allows the instruction at a branch target to be placed in the branch delay slot and be executed if the branch is taken. If the branch is not taken, the instruction in the delay slot is teated as a NOP. If there is no instruction is placed in the delay slot, a NOP is placed just after the branch instruction.
