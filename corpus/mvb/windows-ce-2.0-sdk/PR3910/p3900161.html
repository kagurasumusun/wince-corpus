8.3.1 Cache Organization

8.3.1.1 Instruction Cache

The instruction cache is 4KBytes (1K words), with 4 words per line. Refill size is programmable, and can be 1, 2, 4 or 8 lines (i.e., 4, 8, 16 or 32 words), as determined by the Config register.

8.3.1.2 Data Cache

The data cache is 1KBytes (256 words), with 1word per line. Refill size is programmable, and can be 1, 4, 8, 16, 32 words, as determined by Config register.
