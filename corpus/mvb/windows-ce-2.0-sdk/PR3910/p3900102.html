JAL Jump And Link

Format : JAL target

Description : The 26-bit target address is shifted left two bits, combined with the high order 4 bits of the current program counter, and the program unconditionally jumps to the calculated address, with a delay of one instruction. The address of the instruction after the delay slot is placed in the link register, r31.

Operation :

T: temp PC31..28 || target || 0 2

GPR[31] PC + 8

T+1: PC temp

Exceptions : None.
