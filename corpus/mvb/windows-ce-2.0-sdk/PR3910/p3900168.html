9.1.2 Debug Exception Program Counter Register (DEPC)

The DEPC register holds the address where processing is to resume after the debug exception has taken care of. The address that goes in he DEPC register is the virtual address of the instruction that cause the debug exception. If the instruction is in the branch delay slot, the virtual address of the immediately preceding branch or jump instruction goes in this register. execution of the DERET instruction causes a jump to the DEPC address.
