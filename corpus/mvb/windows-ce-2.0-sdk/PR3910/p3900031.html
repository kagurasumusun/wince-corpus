4.2.6 EPC Register

The 32-bit read-only Exception Program Counter register contains the address where processing can resume after an exception has been serviced.

For synchronous exceptions, this register contains the virtual address of the instruction that was the direct cause of the exception. When that instruction resides in a branch delay slot, the EPC register contains the address of the immediately proceeding branch or jump instruction, and the Branch Delay bit is set in the Cause register.

Register 14 EPC - Exception Program Counter Read Only

The EPC register is accessed by the MFC0 instruction as coprocessor register 14.

This is a 32-bit, read only register that contains the address where processing can resume after an exception has been serviced. This register is not valid for a reset exception.

If the instruction that caused an exception is in the branch delay slot, the immediately preceding branch address is indicated in the EPC and the BD bit in the cause register is set to a one. This register also contains the address of the NMI exception.
