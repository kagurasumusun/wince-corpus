1.1.1 Architecture Features

MIPS R3000A upward compatible instruction set. Including R3000A TLB Instruction set support.

5-stage MIPS R3000A compatible Pipeline.

R3000A memory manganate and TLB support

Branch likely instructions for performance improvement and code compaction.

Hardware interlock to stall the pipeline at the load delay slot when there is a data dependency for code compaction.

Nonblocking Load function to execute next instruction regardless of previously cache miss

4Kbyte direct instruction cache and 1Kbyte two-way set associative data cache

Cache Lock Function to lock one set of two way set associative data cache to lock data in the cache.

Data Cache Snoop Function to invalidate data cache for cache coherency during DMA transfer cycle to cacheable memory

Fast 32 X 32 MAC instruction and fast multiply instruction for DSP application.

Debug Support for single step execution and breakpoint

Multiple power-down modes including Halt and Doze mode
