9.4.2 Debug Breakpoint Exception (DBp)

9.4.2.1 Cause

This exception is raised when as SDBBP instruction is executed.

9.4.2.2 Exception masking

This exception can not be masked. (Note: Its behavior during another debug exception is undefined).

9.4.2.3 Instruction causing the exception

SDBBP

9.4.2.4 Processing

When this exception is raised, processing jumps to a special debug exception handler at 0xBFC0 0200. (This is mapped in uncacheable address space).

The DBp bit in the debug register is set.

The DEPC register points to the SDBBP instruction, unless that instruction is in the branch delay slot, in which case the DEPC register points to the branch instruction and DBD bit is set to 1.
