6.8.6 Overflow Exception

Cause

This exception occurs due to a 2’s complement overflow as a result of ADD, ADDI and SUB. Additionally, the optional Multiply Accumulate block may cause this exception.

This exception is not maskable.

Handling

The General Exception Vector is used for this exception, and the OV code is set in the Cause register’s ExcCode field.

The EPC register points at the instruction that caused the exception, unless the instruction is in a branch delay slot: in that case, the EPC register points at the instruction that preceded the exception-causing instruction and sets the BD bit of the Cause register.

Servicing

When the exception occurs, control is transferred to the applicable system routine.

In case of Unix, the process executing at the time of the exception is handed a UNIX SIGFPE/FPE_INTOVF_TRAP signal. This error is usually fatal to that process.
