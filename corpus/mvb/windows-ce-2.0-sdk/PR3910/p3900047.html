6.2 Exception Handling Registers

The System Control Coprocessor (CP0) has seven registers that are used for exception processing. The software examines these registers during exception processing to determine the cause of an exception and the state of the PR3910 core at the time of the exception. Refer to Processor Register chapter for more detail description of each registers.

Cause Register (CP0 register 13) Indicates the nature of the most recent exception.

Exception Program Counter (EPC) Register (CP0 register 14) Holds the program counter at the time the exception occurred, indicating the address where processing can resume after the exception has been serviced.

Status Register (CP0 register 12) Holds status information about the processor, such as interrupt masking status, diagnosis status, etc.

BadVAddr Register (CP0 register 8) Holds the entire bad virtual address for any address exception: AdEL or AdES.

PRID (Processor Revision Identifier) register Shows the revision number of the PR3910 processor core.

Cache Register Controls the instruction cache (reserved) and the data cache autolock bits.

DEPC Register (CP0 register 17) The DEPC register holds the address where the processing is to resume after debug exception has been taken care of. Refer to Debug Module for more description.

Debug Control Register (CP0 register 16) This register controls debug Exception, refer to debug module chapter for more description.
