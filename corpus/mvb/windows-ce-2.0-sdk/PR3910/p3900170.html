9.2.1 Debug Control Register

Debug Control Register located at address 0xFF30 0000.

Register Debug Control Register - DCR Read/Write

Bit(s)
Mnemonic
Description
0
TM
Trace Mode. (0 at Reset)
0: This mode will output PC trace information at Real-time
1: This mode will completely output PC Trace information (Real-time is not guaranteed)
1
MRst*
Mask User Reset. (1 at reset)
0: Will mask user reset during debug mode
1: User reset is allowed during debug mode
User reset is always permitted during normal mode or when DBGE*= high regardless of MRst bit value.
2
MP
Memory Protection. (1 at reset)
0: Write into monitor area is possible at debug mode.
1: Write into monitor area (FF20 0000 - FF3F-FFFF) except DCR register is protected in debug mode.
3
MNmi
Mask Non-Mask Interrupt. (1 at reset)
0: Mask NMI to the core
1: Enable NMI to the core
4
MInt
Mask Interrupt. (1 at reset)
0: Mask external interrupt [int(5:0)] to the core
1: Enable external interrupt [int(5:0)] to the core
29
ENM
Endianness. (Read Only bit)
0: Little Endian
1: Big Endian
30
HIS
Halt Status. (Read Only bit). It indicates the halt signal value when DINT* of core becomes active
0: This is not a halt status
1: This is halt status

31
DZS
Doze Status. (Read Only bit)
It indicates the Doze signal value when DINT* of core become active
0: This is not a Doze status
1: This is a doze status
