COPz Coprocessor Operation Format

Format : COPz cofun

Description : A coprocessor operation is performed. The operation may specify and reference internal coprocessor registers, and may change the state of the coprocessor condition line, but does not modify state within the processor or the cache/memory system. Some CP0 instructions are pre-defined (see 1).

Operation :

T: CoprocessorOperation (z, cofun)

Exceptions : Coprocessor unusable exception
