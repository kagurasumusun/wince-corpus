9.2.5 Instruction Break Control

This register specified if the address break instruction is valid or not.

Check paper on this is located at address 0xFF30-0104.

Register Instruction Break Control 0 - IBC0 Read/Write

Bit(s)
Mnemonic
Description
0
BE
Break Enable. (at Reset = 0).
This bit specifies the validity of address break function.
0: Address break instruction is not valid
1: Address break instruction is valid
2
TE
Trace Trigger Enable. (at Reset = 0)
0: Address trace trigger function is not valid
1: Address trace trigger function is valid. When trace trigger is valid and the instruction virtual address and the address set by IBA0 register matches, trace trigger information TST(010) is outputted into PCST[2:0] signal pins and BS0 bit is set at instruction break status register.
