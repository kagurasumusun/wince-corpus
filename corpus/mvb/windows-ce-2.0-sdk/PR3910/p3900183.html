9.3.7 Processor Bus Trace Trigger function

By setting TE=1 bit in Processor control register, processor bus trace trigger becomes effective. Debug Unit will monitor the processor bus and depending on the bit setting for Instruction fetch from Uncache area or Data load/store in Uncache or Cache region (i.e. IFUC, DLUC, DSUC, PBC0 bits) address and data comparison is performed.

When the address set by PBA0 register and the data set by PBD0 register matches according to data mask value. Trace information TST(010) or TSQ(001) is outputted into PCST[2:0].
