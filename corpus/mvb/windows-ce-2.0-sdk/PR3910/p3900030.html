4.2.5 Status Register

This register contains all major status bits. Any exception puts the system in Kernel mode. All bits in the Status Register (SR) are readable and writable. 1 shows the format of the Status Register and summarizes the functions performed by each bit.

Register 12 Status Register - SR Read/Write

The SR is accessed using the MTC0 and MFC0 instructions as CP0 register 12.

20
NMI(PE)
Non-maskable Interrupt. This bit is set when a non-maskable interrupt (NMI) is sensed. This bit is cleared by writing a one to it. Writing a zero has no effect. In the R3000A this bit is the parity error (PE) bit. For R3000A compatibility the NMI must be hard-wired to be inactive and this bit must be read as zero. Writing any value to this bit when NMI is disabled has not effect. This bit cleared (zero) by a reset exception.
21
TS
If TLB Shutdown has Occurred. This bit is set to one when the external MMU is NOT present. When an external MMU is present this bit indicates an error condition in the translation buffer of the MMU. When this bit is set by an external MMU it can only be cleared by an external reset.
22
BEV
Boot Exception Vectors. Controls the location of the exception vectors. When this bit is set to 0, the normal exception vectors are used; when the bit is set to 1, bootstrap vector locations are used.
24-23
0
Ignored on Write; Zero when Read, 0 at reset.
25
RE
Reverse Endian. Used to reverse the endianness of the machine in User mode. PR3910 processors are available in either Little-endian or Big-endian configuration. This native endian orientation is used in Kernel and User modes when the RE bit is 0; setting this bit to 1 inverts the native endianness in User mode.
27-26
0
Ignored on Write; Zero when Read, 0 at reset.
31-28
CU
Coprocessor Usable. Controls the usability of each of the four coprocessor. If a bit is set to 1, the corresponding coprocessor is usable; if a bit is cleared (0), the coprocessor is marked unusable. All coprocessor instructions require that the target coprocessor be marked usable or a Coprocessor Unusable Exception occurs. The System Control Coprocessor (CP0) is always usable when in Kernel mode, regardless of the setting of CU[0].
