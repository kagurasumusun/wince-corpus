SLT Set On Less Than

Format : SLT rd,rs,rt

Description : The contents of general register rt are compared with the contents of general register rs. Considering both quantities as signed 32-bit integers, if the contents of general register rs are less than the contents of general register rt, the result is set to one, otherwise the result is set to zero. The result is placed into general register rd. No overflow exception occurs under any circumstances. The comparison is valid even if the subtraction used during the comparison overflows.

Operation :

T: if GPR[rs] < GPR[rt] then

GPR[rd] 031 || 1

else

GPR[rd] 032

endif

Exceptions : None.
