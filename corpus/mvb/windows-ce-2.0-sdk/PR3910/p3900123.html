MTLO Move To LO

Format : MTLO rs

Description : The contents of general register rs are loaded into special register LO. If a MTLO operation is executed following a MULT, MULTU, DIV, DIVU, MADD, or MADDU instruction, but before any MFLO, MFHI, MTLO, or MTHI instructions, the contents of special register HI can be undefined (implemented dependent).

Operation :

T-2: LO undefined

T-1: LO undefined

T: LO GPR[rs]

Exceptions : None.
