MTHI Move To HI

Format : MTHI rs

Description : The contents of general register rs are loaded into special register HI. If a MTHI operation is executed following a MULT, MULTU, DIV, DIVU, MADD, or MADDU instruction, but before any MFLO, MFHI, MTLO, or MTHI instructions, the contents of special register LO can be undefined (implementation dependent).

Operation :

T-2: HI undefined

T-1: HI undefined

T: HI GPR[rs]

Exceptions : None.
