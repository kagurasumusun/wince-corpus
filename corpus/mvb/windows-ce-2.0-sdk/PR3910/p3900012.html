3 PR3910 Pipeline

The PR3910 core is based on a R3000A RISC architecture with a 5-stage pipeline. This means that during any one clock cycle five instructions are in different stages of execution. When the pipeline is fully utilized, five instructions are executed at the same time. The five pipeline stages in order of execution are instruction fetch (IF), Instruction decode (RD), ALU operation (ALU), memory (MEM) and write back (WB).
