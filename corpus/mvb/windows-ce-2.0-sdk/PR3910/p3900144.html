SUBU Subtract Unsigned

Format : SUBU rd,rs,rt

Description : The contents of general register rt are subtracted from the contents of general register rs to form a 32-bit result. The result is placed into general register rd. No overflow exception occurs under any circumstances. Note that the only difference between this instruction and the SUB instruction is that SUBU never causes an overflow exception.

Operation :

T: GPR[rd] GPR[rs] - GPR[rt]

Exceptions : None.
