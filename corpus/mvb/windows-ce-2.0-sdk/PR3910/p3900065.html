7.2 Instruction Notation Conventions

In the following instruction set descriptions the opcodes and function codes are provided in binary and are broken into fields which map to the hex nibbles of the 32 bit instruction word. Other fields use mnemonics which are defined in 1.

Table 7-1 Instruction Mnemonics

Mnemonic
Description
rs
Source register field (5-bit)
rt
Target (source/destination) register or branch condition (5-bit)
rd
Destination register (5-bit)
base
Register which contains base address for load/store ops (5-bit)
immediate
Branch displacement or address displacement (16-bit)
target
Jump target address (26-bit)
shamt
Shift amount (5-bit)
rsvd
Reserved field, set to zero by compiler. Must be zero.

The instruction descriptions contain several types of information in the instruction template. This information is detailed in 1.
