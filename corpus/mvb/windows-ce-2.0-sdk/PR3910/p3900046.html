6.1 Exceptions Defined for the PR3910 Core

1 contains the possible PR3910 exception types.

Table 6-1 PR3910 Core Exception Types

Exception
Cause Code
Cause
Reset
Reset
This exception is raised when the reset signal is de-asserted after having been asserted.
UTLB Refill
UTLB
User TLB Miss. A reference is made (in either User mode or Kernel mode) to a page in kuseg that has no matching entry.
TLB Refill
TLBL
TLBS
A reference TLB entry’s Valid bit isn’t set or there is a reference to a kseg2 page that has no matching entry.
TLB
Modified
Mod
During store operation, the Valid bit is set but the Dirty bit is not set.
Bus Error
IBE
DBE
An external interrupt signaled by the bus interface circuitry. A bus error can occur for events such as bus time-out, bus parity errors, and invalid memory addresses or invalid access types. IBE is for instructions and DBE for data.
NonMaskable Interrupt
NMI
This exception is raised at the falling edge of the non-maskable interrupt signal
Address Error
AdEL
AdES
An attempt is made to load, fetch, or store a word not aligned on a word boundary, or load or store a halfword not aligned on a halfword boundary, or to reference a virtual address with the most significant bit set in User mode.
Overflow
Ov
Twos complement overflow during add or subtract.
System Call
Sys
Execution of a SYSCALL instruction.
Breakpoint
Bp
Execution of a BREAK instruction.
Reserved Instruction
RI
Execution of an instruction opcode which is undefined or reserved.
Coprocessor Unusable
CpU
Execution of a coprocessor instruction when the corresponding CU (Coprocessor Usable) bit is not set in the Status register.
Interrupt
Int
Assertion of one of the six external hardware interrupt signals or setting one of the two software interrupt bits in the Cause register.
Debug Exception
DSS, DBp
For Debug Single Step exception and Debug Breakpoint exception caused by the Debug Support Module. See Debug module Chapter for details.
