6.8.9 NMI Exception

Cause

This exception occurs when the NMI hardware signal is asserted and hen deasserted.

This exception is not maskable.

The PR3910 core will wait for a bus cycle to end before the taking the exception.

Handling

The PR3910 branches to the Reset Exception vector for this exception. The MMU must be designed so that the Reset Vector esides in the unmapped and uncached address space, so that it is not necessary to have a working TLB or cache to handle this exception.

The contents of all PR3910 core registers are the retained except for the following:

The NmI bit of the status register is set to 1.

The EPC register and the BD bit in the cause register behaves like any other non-Reset Exceptions.

The cause register CE and ExcCode bits are undefined.

Servicing

The NmI exception can be serviced in a manner similar to Reset Exception. User can examine the NmI bit in the status register to determine whether a Reset or NMI Exception has occurred before servicing the exception.
