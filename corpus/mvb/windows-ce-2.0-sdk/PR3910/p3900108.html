LHU Load Halfword Unsigned

Format : LHU rt,offset(base)

Description : The 16-bit offset is sign-extended and added to the contents of general register base to form a 32-bit unsigned effective address. The contents of the halfword at the memory location specified by the effective address are zero-extended and loaded into general register rt. If the least significant bit of the effective address is non-zero, an address error exception occurs.

Operation :

T: vAddress (offset15)16 || offset15..0 + GPR[base]
