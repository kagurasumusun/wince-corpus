2.1 Overview

Full 32-bit registers and datapaths. The PR3910 core is a 32-bit core with full 32-bit data paths and the standard MIPS R3000A general purpose registers.

Five stage RISC pipeline. The PR3910 core is a true RISC processor core and achieves close to one instruction per clock cycle. It is based on a load/store architecture and implements a five stage pipeline to achieve this low cycles per instruction (CPI) rate.

Large address space. A full 32-bit address space is available giving access to 4 G Bytes of virtual address space. Users can define their own virtual-to-physical address translators, kernel/user segmentations and memory protection schemes to protect kernel software or other critical codes.
