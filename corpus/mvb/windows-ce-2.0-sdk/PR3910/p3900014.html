3.1.1 Load Delay Slots

Loads require two CPU cycles to make the data available, these instructions have a “load delay slot” immediately after the load instruction. This load delay slot can be used to execute any instruction that does not require the data being loaded (no data dependency), or else an interlock can occur. Noting that the data fetched from the data cache during the MEM stage of the load word (LW) instruction is not ready in time for the ALU stage of the following instruction. It is ready for the ALU stage of the instruction following the delay slot. Usually the assembler can find an instruction that can be executed and put it into the load delay slot.
