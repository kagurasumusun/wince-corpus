8.3.4 Cache Testing Function

1. Cache disable

ICE and DCE bit in Config register is used to disable/enable Instruction and Data cache.

When a cache is disabled all the cache references are cached missed. (same non-cacheable memory).

2. Cache flushing

Both the instruction and data cache are flushed when the reset exception is raised.

The instruction cache is flushed by the CACHE instruction IndexInvalidate and disabling the instruction cache (ICE=0 in Config register). The data cache is flushed by CACHE instruction HitInvalidate.

Note: Disabling the instruction cache, streaming should be stopped by inserting a branch instruction after MTC0;

Example:

MTC0 Rn, Config (Clear ICE to 0)

J L1 (Branch to L1; stop streaming)

Nop

8.3.4.1 Cache Refill

Both cache are refilled from the head of the refill boundary regardless of the refill size.

8.3.4.2 Cache Snoop

To maintain the cache coherency with the memory during DMA cycle. The PR3910 snooped the bus master. if the an address access by the external bus master matches as address stored in the data cache tag (cache hit), the valid bit (V) for that cache data is cleared to 0.

Locked data cannot be invalidated, even when a hit occurs in a snoop operation.

After a cache block has been invalidated in a snoop, the LRU bit points to the invalidated cache set.
