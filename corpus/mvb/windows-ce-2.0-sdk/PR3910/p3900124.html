MULT Multiply

Format : MULT rs,rt

MULT rd, rs, rt

Description : The contents of general registers rs and rt are multiplied, treating both operands as 32-bit 2’s-complement values. No overflow exception occurs under any circumstances. When the operation completes, the low-order word of the double result is loaded into general register rd and in special register LO, and the high-order word of the double result is loaded into special register HI. Pipeline details are implementation dependent.

Operation :

T: t GPR[rs] * GPR[rt]

LO t31..0

HI t63..32

GPR[rt] t31.. 0

Exceptions : None.
