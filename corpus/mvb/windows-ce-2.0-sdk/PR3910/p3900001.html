1 Introduction

This manual describes RISC PR3910 core with R3000A memory management and TLB support for embedded control. The PR3910 core is derived from the R3000A MIPS RISC processor. It maintains instruction set compatibility with the R3000A. In addition, it supports instruction set and architectural enhancements to the R3000A for better embedded control.

For a thorough description of the MIPS R3000A architecture, instruction set, and programmers model, refer to the book: “MIPS RISC Architecture” by Gerry Kane and Joe Heinrich, published by Prentice-Hall.
