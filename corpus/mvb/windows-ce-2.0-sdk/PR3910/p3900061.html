6.8.8 Reset Exception

Cause

This exception occurs when the RESET hardware signal is asserted and then deasserted.

This exception is not maskable.

Handling

The PR3910 branches to the Reset Exception vector for this exception. The memory management unit (MMU) must be designed such that the Reset Vector resides in the unmapped and uncached address space, so that it is not necessary to have a working TLB or cache to handle this exception.

The contents of all PR3910 core registers are undefined with the exception of the following bits of the Status register: NmI, SR, TS, SwC, KUc, and IEc, which are 0, and BEV which is 1.

Servicing

Again, the MMU must be designed such that the Reset exception vector is selected to appear within the uncached, unmapped memory space of the core, so instructions can be fetched and executed without working caches and or TLB.

The Reset exception is serviced by initializing all processor registers, coprocessor registers, caches, and the memory system; by performing diagnostic tests; and by bootstraping the operating system and the rest of the hardware.

Configuration Register (Config)

The most significant 16 bits of the 32-bit CP0 configuration register (config) have programmable reset values, i.e., these bits will have the values loaded from core pin straps upon reset. These bits can later be overwritten in software. The other 16 bits are reset to 0’s upon reset. Refer to Chapter Error! Bookmark not defined. for details.
