MFC0 Move from System Control Coprocessor

Format : MFC0 rt,rd

Description : The contents of coprocessor register rd of System Control Coprocessor (CP0) are loaded into general register rt.

It should be noted that there must be one delay slot after this instruction before the data can be used. There is no interlock for this delay slot. User must fill this delay slot with an instruction.

Operation :

T: Data CPR[0, rd]

T + 1: GPR[rt] data

Exceptions : Coprocessor unusable exception
