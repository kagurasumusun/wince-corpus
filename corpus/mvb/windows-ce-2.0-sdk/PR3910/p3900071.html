ADDU ADD Unsigned

Format : ADDU rd,rs,rt

Description : The contents of general register rs and the contents of general register rt are added to form a 32-bit result. The result is placed into general register rd. No overflow exception occurs under any circumstances. Note that the only difference between this instruction and the ADD instruction is that ADDU never causes an overflow exception.

Operation :

T: GPR[rd] GPR[rs] + GPR[rt]

Exceptions : None.
