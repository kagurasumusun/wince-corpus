3.2.1 Multiply and Multiply/Add Instruction (MULT, MULTU, MADD, MADDU)

The PR3910 processor can execute multiply and multiply/add instructions continuously in a single cycle. The results in the HI and LO registers is immediately available following instructions, without pipeline stall.

Example

MADD r9, r5, r1

MADD r9, r6, r2

MADD r9, r7, r3

MADD r9, r8, r4

MFHI r10

The PR3910 requires only one clock cycle to use the results of a general purpose register for multiply instruction.

MULT r3, r2, r1

ADD r5, r4, r3 (pipeline is stalled for one cycle before r3 is available for ADD instruction).
