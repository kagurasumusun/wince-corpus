4.2.8 PIRd register

The Processor Revision Identification (PRId) register contains information that identifies the implementation and revision level of the CPU, CP0, and various options.

Register 15 Processor Revision Identification - PRId Read Only

The Processor Revision Identification register is accessed by the MFC0 instruction as coprocessor register 15.
