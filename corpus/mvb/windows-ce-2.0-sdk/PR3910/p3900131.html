SDBBP Software Debug Breakpoint

Format : SDBBP Code

Description : This instruction raises a Debug Breakpoint exception, passing control to an exception handler.The code field can be used for passing information to the exception handler, but the only way to have the code field retrieved by the exception handler is to load the contents of the memory word containing this instruction, using the DEPC register.

Operation :

T: PC ExceptionHandlerVector

if DBD = 0, DEPC Address of SDBBP instruction

else DEPC Address of branch (taken) instruction

Exceptions : Debug Breakpoint Exception
