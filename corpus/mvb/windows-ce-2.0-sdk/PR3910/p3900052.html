6.7 Exception Vector Locations

Addresses for exceptions are a combination of a vector offset and a base address. The exception vector base address is controlled by the Bootstrap Exception Vector (BEV) bit in the Status register. This bit is set by a Reset, and when set, the vector base address is 0xbfc00100 (non-cacheable). When BEV is zero, the vector base address is 0x80000000 (cacheable). This is illustrated in 1.
