MTCz Move to Coprocessor

Format : MTCz rt,rd

Description : The contents of general register rt are loaded into coprocessor register rd of coprocessor unit z.

It should be noted that some coprocessor registers are implementation dependent. No bypasses are performed for this instruction. User must implement any necessary delay in software.

Operation :

T: data GPR[rt]

T + 1: CPR[z,rd] data

Exceptions : Coprocessor unusable exception
