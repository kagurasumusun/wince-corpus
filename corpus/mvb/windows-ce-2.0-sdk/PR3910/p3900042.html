5.2.4 CP0 Registers

The following CP0 registers are used

EntryHi and EntryLo These registers are used to hold a TLB entry. EntryHi also holds the ASID of the current process.

Index Determines which TLB entry will be read/written by the tlbp and tlbwi instructions.

Random This is a counter that is used to simulate a pseudo-random number used by the tlbwr instruction to write a TLB entry into a “randomly”selected location.

Context This register is provided to speed up the processing of TLB Refill traps. The high-order bits are read/write, the lower order 21 bits reflect the BadVAddr value.

Random
Random: a pseudo random index (with a value from 0 to 63). This register is basically a counter that decrements on every clock cycle but which is constrained to count from 63 to 8. This guarantees that the random will never address the first 8 entries of the TLB. This register may be used during the processing of a TLB miss exception, suggesting the TLB entry to be written with the correct translation.The instruction TLB write random (tlbwr) is used for this purpose.
