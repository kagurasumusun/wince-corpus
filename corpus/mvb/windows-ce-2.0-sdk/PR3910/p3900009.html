2.3 The PR3910 Pipeline

The PR3910 core is based on a RISC architecture with a 5-stage pipeline. This means that during any one clock cycle five instructions are in different stages of execution. The five pipeline stages in order of execution are instruction fetch (IF), decode (RD), ALU operation (ALU), memory (MEM) and write back (WB).
