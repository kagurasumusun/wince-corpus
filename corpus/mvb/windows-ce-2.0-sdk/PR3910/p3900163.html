8.3.3 Cache Lock

The lock function can be used to lock data in one data cache set. Setting the Cache register DALc bit enable the cache lock function. The Cache register DALc bit can be set at the head of a subroutine thereby locking into the cache the data accessed by the subroutine. If an exception is raised while the lock function is enable, the stack is pushed the DALc and DALp bit values are saved in DALp and DALo respectively) and DALc is cleared, disabling the lock function.

The lock bit for an entry is cleared using the CACHE instruction IndexLockBitClear. Clear the lock bit as follows when data written to a locked line should be stored in main memory.

1. Read the Lock data from Cache memory

2. Clear the Lock bit

3. Store the data that was read
