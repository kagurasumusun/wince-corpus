9.3.5 Processor Bus Break Status

It is located at address 0xFF30-000C.

Register Instruction Break Status- PBS Read/Write

Bit(s)
Mnemonic
Description
0
BS0
Break Status 0. (0 at reset)
This bit indicates that processor bus break or processor bus trigger has generated.
0: Processor bus break or processor bus trace trigger for channel 0 has NOT generated.
1: When BE bit in Processor Bus Control Register is set (BE=1). It indicates the processor bus break or processor bus trace trigger has generated.
BS0 can not be cleared by debug reset, only by writing in 0 during debug reset handler.
27..24
BCN
Break Channel Number. (read only bits)
This indicates the channel number for processor bus break.
0000: Reserved
0001: Channel 1
.......
1111: Channel 15
