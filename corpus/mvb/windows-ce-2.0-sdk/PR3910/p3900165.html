9 Debugging Unit

This section describes the debug unit implemented in the PR3910. It is used to access the internal state of PR3910 through dedicated external pin. These pins with external third party hardware and software provide a real-time debugging system.

In addition, there are two new instructions (i.e. SDBBP, DERET) implemented to provide software debug breakpoint and to support debugging. Refer to PR3910 instruction set for more detailed information.

The debug unit is independent of the R3000A architecture which make them transparent to user program.
