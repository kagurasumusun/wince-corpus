DERET Debug Exception Return

Format : DERET

Description : This instruction executes a return from a self-debugging interrupt or exception. It has a branch delay slot like that of branch or jump instruction cycle. The DERET can not be in the delay slot itself.

The return address stored in the DEPC register is copied to PC and processing returns to the original program.

Notes: If a MTC0 instruction was used to set the return address in the DEPC register a minimum of two instruction must be executed before executing DERET.

Operation :

T: temp DEPC

T+1: PC temp

Debug30 0

Exceptions : Coprocessor Unusable exception
