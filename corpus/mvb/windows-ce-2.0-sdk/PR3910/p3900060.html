6.8.7 Reserved Instruction Exception

Cause

Attempting to execute an instruction whose major opcode (bit31..26) is undefined, or a special instruction whose minor opcode (bit 5..0) is undefined.

Attempting to excute reserved instruction (LWCz and SWCz).

This exception is not maskable.

Handling

The General Exception Vector is used for this exception (0x8000 0080), and the RI code is set in the Cause register’s ExcCode field.

The EPC register points at the instruction that caused the exception, unless the instruction is in a branch delay slot: in that case, the EPC register points at the instruction that preceded the exception-causing instruction and sets the BD bit of the Cause register.
