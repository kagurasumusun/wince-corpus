5.2 TLB-Based Address Translation

The PR3910 MMU provides a mechanism for dynamically translating program addresses in the kuseg and kseg2 regions. This translation is implemented with the help of a on-chip TLB, or “translation look-aside buffer”, which is a look-up table of virtual to physical translations.

The memory management is paged: the memory is divided in pages of a fixed size of 4 Kbytes. This means that with the help of the TLB, any 4 KB virtual page can be mapped to any 4 KB physical page.
