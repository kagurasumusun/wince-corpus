5.2.6 TLB Shutdown

The Status register contains a single bit that indicates whether the TLB is operating properly. This bit, once set, may only be cleared by a reset. There are two reasons that this bit might be set:

during reset, if there is no TLB present, this bit is set.

after reset the bit was cleared, but subsequently during the operation of the TLB multiple virtual to physical mappings were detected for the same VPN. this may be the consequence of improper software or hardware. In this case, the TLB will be shutdown, and all address translations are undefined.
