SRAV Shift Right Arithmetic Variable

Format : SRAV rd,rt,rs

Description : The contents of general register rt are shifted right by the number of bits specified by the low-order 5 bits of the contents of general register rs, sign-extending the high order bits. The 32-bit result is placed in register rd.

Operation :

T: GPR[rd] (GPR[rt]31)GPR[rs]4..0 || GPR[rt]31..(GPR[rs]4..0)

Exceptions : None.
