9.1.1 Debug Register

Debug registering CP0 is used to control debug exception. It is shown in 1.

Register Debug Register Read Only (except SSt, BsF)

These bits are read-only except SSt and BsF bits which are read/write bits.

Other Exception Status. When this bit is set indicates exception other than reset, NMI, or UTLB Refill has occurred at the same time as a debug exception. In this case the Status, Cause, EPC, and BadVaddr registers assume the usual status after occurrence of such an exception, but the address in the DEPC is not the other exception vector address. Instead, 0xBFC0 0180 (if BEV=1) or 0x8000 0080 (if BEV=0) is put in DEPC by the debug exception handler software, after which processing returns directly from the debug exception to the other exception handler.

Instead, 0xBFC0 0000 is put in DEPC by the debug exception handler software after which processing returns directly from the debug exception to the non-maskable interrupt handler.
