4.2.2 Configuration Register

This register designates the PR3910 Coprocessor Core configuration.

Register 3 CONFIG Configuration Register Read / Write

The Configuration Register is accessed via the MTC0 and MFC0 instructions as coprocessor zero register 3.

Bit(s)
Mnemonic
Description

DRSize
Data Burst Refill Size, 00 at reset, Read/Write bits
These Data Cache Burst Refill size is valid if DCBR bit in Config reg. is set to 1
00: 4 words
01: 8 words
10: 16 words
11: 32 words

Instruction Cache burst Refill size
00: 4 words
01: 8 words

DCE
Date Cache Enable, 1 at reset, Read/Write bit
Set to 1 enable the Data Cache
5
ICE
Instruction Cache Enable, 1 at reset, Read/Write bit
Set to 1 enable the Instruction Cache
6
DCBR
Data Cache Burst Refill, 0 at reset, Read/Write
1: value in DRSize used as the data cache refill size
0: The data cache refill size is 4 words
7
Lock
Lock Config Register, 0 at reset, Read
1: prevents further write to the config register.
8
Halt
Halt, 0 at reset, Read/Write bit
1: Puts PR3910 is in Halt Mode. Halt mode greatly reduces the power consumption than Doze mode.
Halt state can be cleared (0) by Reset exception when the reset signal is received or NMI signal, or interrupt signals. Data cache snoops are not possible in Halt mode and operation is undefined when both Doze bit and Halt bit is set to 1.
9
Doze
Doze Mode, 0 at reset, Read/Write bit
1: Puts PR3910 is in the Doze mode and install the pipeline.
Doze state can be cleared to 0 by Reset exception when the reset signal is received or NMI signal, or interrupt signals even it interrupts are masked. Data cache snoops are possible in Doze mode and operation.
