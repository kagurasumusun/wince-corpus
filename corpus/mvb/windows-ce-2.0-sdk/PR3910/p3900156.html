XORI Exclusive Or Immediate

Format : XORI rt,rs,immediate

Description : The 16-bit immediate is zero-extended and combined with the contents of general register rs in a bit-wise logical exclusive-OR operation. The result is placed into general register rt.

Operation :

T: GPR[rt] GPR[rs]31...16 || (immediate xor GPR[rs]15..0)

Exceptions : None.
