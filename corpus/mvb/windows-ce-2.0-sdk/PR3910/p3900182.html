9.3.6 Processor Bus break Function

Processor bus break becomes effective by setting Processor Bus Control Register bits.

Debug Unit will monitor the processor bus and depending on the bit setting for instruction fetch from uncache area or Data load/store in Uncache or Cache region (i.e. IFUC, DLUC, DSUC, PBC0 bits) address and data comparison is performed.

PBA0, PBD0 and PBM are holding the address, data and mask value to be compared for debug interruption.
