2.2.1 Processor Registers

The processor registers consist of a set of 32 general purpose registers of 32-bits each. In addition there are two 32-bit registers used for the hardware multiplier/divider result and a 32-bit program counter.

2.2.1.1 General Purpose Registers

The general purpose register set consists of 31 read write registers, (r1 through r31) and one register which is permanently zero (r0).The 31 registers which can be read and written are treated symmetrically and are accessible in both kernel and user modes of operation.

The registers have predefined uses by the system architecture and the compiler. The compiler mnemonics are given after the register names in Error! Bookmark not defined..

2.2.1.2 MAC/Multiply/Divide Registers

The two 32-bit registers used to support the hardware multiplier, divider and the multiplier-accumulator (MAC) are the HI and LO registers. When a multiply or multiply-add operation is performed, the HI register contains the upper 32-bits of the 64-bit result and the LO register contains the lower 32-bits of the 64-bit result.

For divide operations the quotient is loaded into the LO register and the remainder (modulus) is loaded into the HI register.

2.2.1.3 Program Counter

The processor contains a 32-bit program counter allowing a full 4 GB virtual address space. The program counter is not directly accessible by any instruction and can only be modified by executing one of the jump or branch instructions.

The program counter is indirectly accessible by executing one of the jump and link or branch and link instructions or by examining the exception program counter (EPC) register after an exception has been taken.
