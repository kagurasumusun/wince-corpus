BCzTL Branch On Coprocessor z True Likely

Format : BCzTL offset

Description : A branch target address is computed from the sum of the address of the instruction in the delay slot and the 16-bit offset, shifted left two bits and sign-extended to 32 bits. If the coprocessor z’s condition signal (CpCond[z]) is true, as sampled during the previous instruction then the target address is branched to with a delay of one instruction. If the condition is false, the instruction in the delay slot is nullified.
