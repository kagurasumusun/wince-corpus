SUB Subtract

Format : SUB rd,rs,rt

Description : The contents of general register rt are subtracted from the contents of general register rs to form a 32-bit result. The result is placed into general register rd. An overflow exception occurs if the two highest order carry-out bits differ (two’s complement overflow).

Operation :

T: GPR[rd] GPR[rs] - GPR[rt]

Exceptions : Overflow exception
