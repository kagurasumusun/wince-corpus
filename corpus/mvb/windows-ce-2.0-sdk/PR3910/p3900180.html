9.3.4 Processor Bus Control 0

This register specifies the validity of processor bus break. It is located at address 0xFF30-030C.

Register Processor Bus Control Read/Write

Bit(s)
Mnemonic
Description
0
BE
Break Enable (0 at reset); Specifies the validity of processor bus break
0: Processor break is not valid
1: Processor break is valid. Trace trigger information TST(010) or TSQ(001) is outputted into PCST[2:0].
1
----
Zero.
2
TE
Trace Trigger Enable. (0 at reset). Specifies the validity of processor bus trace trigger.
0: Processor bus trace trigger is not valid.
1: Processor bus trigger is valid. Trace trigger information TST(010) or TSQ(001) is outputted into PCST[2:0].
3
----
Zero
4
IFUC
Instruction Fetch from Uncache Area.
Specifies whether to compare address and data from uncache area.
0: Address and data is not compared from Uncache area Instruction fetch.
1: Address and data is compared from uncache area instruction fetch.
5
DLUC
Data load from Uncache Area. It specifies whether to compare address and data from data load from Uncache area.
0: Address and data is not compared for data load from uncache area.
1: Address and data is compared for data load from Uncache area.

6
DSUC
Data Store to Uncache Area. It specifies whether to compare address and data for storing data to Uncache area.
0: Address and data is not compared for storing data in Uncache area.
1: Address and data is compared for storing data in Uncache area.

7
DSCA
Data Store to Cache Area. It specifies whether to compare address and data for storing data in cached area.
0: Address and data is not compared for storing data in cached area.
1: Address and data is compared for storing data in cached area.

23-8
LAM
Lower Address Mask
This register specifies mask value for 16 bit lower processor bus break address. Each bit is correspond to a bit in processor bus break address register (PBA).

Zero
