BGEZ Branch On Greater Than Or Equal To Zero

Format : BGEZ rs,offset

Description : A branch target address is computed from the sum of the address of the instruction in the delay slot and the 16-bit offset, shifted left two bits and sign-extended to 32 bits. If the contents of general register rs have the sign bit cleared, then the program branches to the target address, with a delay of one instruction.
