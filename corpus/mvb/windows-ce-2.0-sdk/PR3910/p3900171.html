9.2.2 Instruction Break Status

It is located at address 0xFF30-0004. Following figure shows the format of the Instruction break Status register.

Mnemonic

BS0
Break Status 0.
This bit indicates that address break instruction or address trigger instruction has generated.
0: Address break instruction or address trace trigger instruction for channel 0 has NOT generated.
1: When BE bit in instruction break control register is set or TE=1. It indicates the address break exception or address trigger has generated.
BS0 can not be cleared by debug reset, only by writing in 0 during debug reset handler.
