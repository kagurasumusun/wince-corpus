Handling and Deleting User Notifications

The taskbar annunciator for an active notification remains in the taskbar until the user handles the notification. In cases where an application has multiple active notifications, all of its active notifications must be handled before the annunciator icon is removed.

There are two ways user notifications can be handled. The first way is by clicking the OK button, for those notifications that include a dialog box. The other way to handle notifications is for the application to call CeHandleAppNotifications. CeHandleAppNotifications marks as "handled" all active notifications for that application. It also removes the taskbar annunciator icon. Note, it only handles active notifications (not registered ones). Also, it only handles notifications for the given application.

Use CeClearUserNotification when you want to delete registered user notifications. For example, a user may set a calendar appointment and then delete the appointment before the specified time.
