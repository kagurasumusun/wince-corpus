raster font

Or bitmap font, nonscalable font. A font in which each glyph (character or symbol) is of a particular size and style, designed for a specific resolution of device and described as a unique bitmap. Windows CE supports only raster fonts. There are seven rasterized system fonts available in several sizes stored in ROM. The built-in fonts are built into the Windows CE operating system.

record

A Windows CE database consists of an arbitrary number of records, where each record consists of one or more properties. Each of the records in a specific database typically contain a similar set of properties. A Windows CE database should not be confused with a full-fledged relational database. It is simply a general-purpose, flexible, structured collection of data.

reentrant code

Code written so that it can be shared by several programs or threads within a single process at the same time. When code is reentrant, one thread can safely interrupt the execution of another thread, execute its own code, and then return control to the first thread in such a way that the first thread does not fail or behave in an unexpected way.

registered notification

The state of a user notification from the time CeSetUserNotification is called until the time the user is notified.

registry

A database used by the operating system to store configuration information.

Remote Access Server

A Windows NT feature by which a single serial connection provides a remote workstation with host connectivity, NT file services, or Novell file and printing services (NWLink). Windows CE supports the standard Win32 RAS functions; however it allows only one connection at a time. RAS functions can be implemented for direct serial connections or dial-up modem connections.

Remote Application Programming Interface

The Windows CE Remote API (RAPI) gives applications running on the desktop PC (the RAPI client) the ability to make function calls on the H/PC (the RAPI server). RAPI runs over Winsock and TCP/IP.
