Registry Sample

The Registry sample application demonstrates the registry API functions needed to access the H/PC registry. Registry.exe can be used to traverse the various branches of the registry tree, displaying the individual key's data values and also allowing the values to be edited. Registry.exe creates a dialog box that displays several edit fields, list boxes and command buttons.

The Key list box displays the currently selected registry key name, and the list box in the center of the dialog box displays the child keys of the current key. When Registry.exe starts, by default the child keys list box displays the following predefined key handles of the Windows CE registry:
HKEY_LOCAL_MACHINEHKEY_CURRENT_USER HKEY_USERS HKEY_CLASSES_ROOT

The dialog box functions are provided in the following table.

Control Description
Key list box Displays the key that was selected from the adjacent list box (the child list box). A key can be selected by highlighting it and tapping the Next/Down command button. A key can also be selected by double-tapping on the key name.

The selected key is then displayed in the Key list box, and the key's child keys then appear in the child list box.

Class list box Displays the class name of the selected registry key when viewing keys in HKey_Local_Machine\Software.
Values list box Displays the number of name values found for the selected Key.

The list box directly above the Values list box displays the value names of the currently selected key (shown in the Key list box).

When a named value is highlighted, the data type is displayed in the Type list box, and the data value is displayed in the Entry list box.
Path list box Displays the current registry path.
Next/Down command button Changes the Key to the parent key.
Back/Up command button Changes the Key to the selected child key.
Type list box Displays the data type for the named value selected above the Values list box.
Entry list box Displays the data value for the named value selected above the Values list box.
