Cmdbar Sample

The Cmdbar sample is a simple Windows CE application that shows some common buttons on the command bar and how to create, add bitmaps to, and destroy the command bar. This sample also demonstrates the CommandBar_InsertMenubar function. If the command bar sample is built for a desktop Win32 emulation application, the application window that is created is centered, and the size emulates the command bar look with respect to the number of buttons the command bar holds. The Button Bitmaps menu allows the user to select from three different sets of buttons that can be displayed, based on the two standard bitmaps added to the command bar. See CommandBar_AddBitmap.
