Data Link Protocols (NDIS and PPP/SLIP)

Windows CE provides data-link layer support for both serial I/O and local area networks (LANS):

  • The PPP and SLIP protocols are supported for serial and modem based networking.

  • For LANs, the Dynamic Host Configuration Protocol (DHCP) and the Address Resolution Protocol (ARP) are supported.

  • Windows CE also includes a subset of NDIS4.0:
    • Only Ethernets are supported.

    • Only Miniport drivers are supported, not intermediate or legacy drivers.

NDIS 4.0 does not expose an API to applications. For information related to device drivers, see the Windows CE Device Driver Kit documentation.

NDIS 4.0 for Windows CE is packaged as a DLL, rather than a .sys file. This feature permits the ARP and NDIS modules to be partially installed. If an OEM chooses this option, this means that the network stack will be configured for them but the modules will not be added to ROM. If they are needed for an application, the user must be prompted to add the DLLs to RAM.
