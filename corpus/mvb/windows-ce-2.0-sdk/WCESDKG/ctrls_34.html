Scroll Bar Functions

Windows CE supports a subset of the scroll bar functions Windows 95 and Windows NT support, with a couple of minor differences.

You can't use the SW_SCROLLCHILDREN flag in the flags parameter to the ScrollWindowEx function and you have to set either the dx or dy parameter to zero.

In Windows CE 2.0, if you pass a null pointer in the lpsi parameter of the SetScrollInfo function, it will return zero, rather than the current position of the scroll box.

Windows CE supports the following functions the same way Windows 95 and Windows NT support them.

GetScrollInfo

SetScrollPos

SetScrollRange

Windows CE doesn't support the EnableScrollBar, GetScrollPos, GetScrollRange, ScrollWindow, or ShowScrollBar functions. Use the GetScrollInfo function to retrieve the current position and range of the scroll bar.
