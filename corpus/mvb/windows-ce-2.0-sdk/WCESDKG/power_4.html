Resuming Operation, Rebooting and Resetting the Computer

Resuming computer operation from the idle or suspend mode does not alter computer memory or change application settings. In contrast, rebooting or resetting the computer does alter memory and affect program operation. The following table summarizes the differences between these transitions.

Transition Description
wake-up
(or resume)		 The transition from suspend mode to full-speed mode. Does not change memory or application settings.
cold boot
(or cold reset)		 The device is completely reset. All applications are terminated, the working memory is cleared, and the object store is cleared.
warm boot
(or warm reset)		 All applications are terminated and working memory is cleared. The object store integrity is maintained.
power-on reset The transition from dead to on state. Same consequences as cold boot.

The power-on reset and cold boot transitions occur when power is first applied to the computer, or when all power is removed from the computer then reapplied after a minute. Unless the computer uses nonvolatile memory, the user will have to load or reload applications after a power-on reset. Object store data is lost after a cold boot.

The user warm boots the computer by pressing the reset button. Because this button is normally protected from accidental activation by being placed in a pin-hole recess or under the battery cover, users warm boot the computer only when it has stopped responding or has become unstable. A warm boot stops running applications and clears the memory used for application execution. Memory used for the object store and file system is preserved.
