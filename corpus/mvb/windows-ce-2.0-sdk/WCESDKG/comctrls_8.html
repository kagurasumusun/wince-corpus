Using the Command Bar

To create the command bar
  1. Initialize a INITCOMMONCONTROLSEX structure with ICC_BAR_CLASSES in the dwICC field.

  2. Register the command bar class by calling the InitCommonControlsEx function, passing in the INITCOMMONCONTROLSEX structure.

  3. Create the commands bands control by calling the CommandBar_Create function.

  4. Add controls to the command bar by calling the CommandBar_InsertMenubar, CommandBar_AddBitmap, CommandBar_AddButtons, and CommandBar_InsertComboBox functions.

  5. Add the Close and Help buttons by calling the CommandBanr_AddAdornments function, passing CMDBAR_HELP in the dwFlags parameter. (The Close button is added by default.)
// Register the command bar class.
INITCOMMONCONTROLSEX icex;
icex.dwSize = sizeof(icex);
icex.dwICC  = ICC_BAR_CLASSES;
InitCommonControlsEx(&icex);

HWND hwndCB, hwnd;

// Create the command bar.
hwndCB = CommandBar_Create(g_hInst, hwndParent, ID_COMMANDBAR);

// Insert the menu bar.
CommandBar_InsertMenubar(hwndCB, g_hInst, IDM_MAINMENU, 0);

// Add the bitmap containing system-defined button images. 
CommandBar_AddBitmap(hwndCB, HINST_COMMCTRL, IDB_STD_SMALL_COLOR, 15, 16, 16);

// Add the buttons. (tbButtons is an array of 
// TBBUTTON structures, created previously.)
CommandBar_AddButtons(hwndCB, sizeof(tbButtons)/sizeof(TBBUTTON), tbButtons);

// Insert a combo box.
hwndCombo = CommandBar_InsertComboBox(hwndCB, g_hInst, COMBO_WIDTH, 
	CBS_DROPDOWNLIST | WS_VSCROLL, ID_COMBOBOX, 16);
// (Add strings to the combo box.)

// Add the Close and Help buttons.
CommandBar_AddAdornments(hwndCB, CMDBAR_HELP, 0);

For an example of how to use a command bar in an application, see the Cmdbar sample application, included in the Wce\Samples\Win32 directory.
