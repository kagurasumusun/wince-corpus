Inbox

Inbox is a mail client application provided with Windows CE

Independent Hardware Vendor

An independent hardware vendor (IHV) is a company that manufactures devices that connect to Windows CE platforms, such as PC Cards. IHVs must also produce Installable Device Drivers for their devices.

INF file

INF files are CAB Wizard input files that specify information about the application.

INI file

INI or initialization files register an application with Application Manager. They contain information such as the location of CAB files, icon files, install directory, etc.

Information Access Service

Information Access Service is part of the IrDA infrared communication protocol, an Information Access Service (IAS) is specified through which a device can learn about the services offered by another device.

Installable Device Driver

An Installable Device Driver is a user-level DLL that drives devices connected to a Windows CE platform. It presents the functionality of such a device to applications in terms of standard Win32 file I/O functions.

IP address

Internet Protocol

Internet Protocol is the basic protocol of the Internet. It enables the delivery of individual packets from one host to another. It makes no guarantees about whether or not the packet will be delivered, how long it will take, or if multiple packets will arrive in the order they were sent. Protocols built on top of this add the notions of connection and reliability.

IrCOMM

An infrared implementation, per the IrDA standard, of the serial line communication driver. IrCOMM is supported by Windows CE.

IrDA

The Infrared Data Association (IrDA) specification is the industry standard for infrared communication protocols. Windows CE supports the IrDA standard through the WinSock API. Windows CE applications that communicate over serial cables using the WinSock API will communicate over IrDA-compliant IR links without any reprogramming

IrLAP

The IR Link Access Protocol is part of the basic IrDA protocol, it is a data link layer protocol providing a reliable point-to-point link, which effectively replaces a three-wire serial cable connection.

IrLMP

The IR Link Management Protocol (IrLMP) is part of the basic IrDA protocol, it is a service multiplexing protocol, which provides for multiple sessions over a single point-to-point link.

IrLPT

The IrLPT is a protocol, per the IrDA standard, for printing via a serial infrared connection.

IRQ

IrSOCK

An IrSOCK is an implementation, per the IrDA standard, of the Winsock protocol.
