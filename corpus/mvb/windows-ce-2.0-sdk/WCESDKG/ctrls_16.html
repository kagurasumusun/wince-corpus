Group Boxes

A group box is a rectangular area within a dialog box in which you can group together other controls that are semantically related. The controls are grouped by drawing a rectangular border around them. Any text associated with the group box is displayed in its upper left hand corner.

Windows CE supports group boxes the same way Windows 95 and Windows NT do, with one minor restriction. You must always add group boxes to your dialog template after you've added everything else you're going to add. This is because group boxes are opaque in Windows CE. Anything you add to the template after the group box will be hidden underneath it. By adding group boxes last, you ensure that the group boxes are at the bottom of the Z-order and won't hide your other controls.

You create a group box by specifying the BS_GROUPBOX style in the CreateWindow or CreateWindowEx function. This style is the same in Windows CE as it is in Windows 95 and Windows NT.

For general guidelines on using group boxes in user interface design, see The Windows Interface Guidelines for Software Design.
