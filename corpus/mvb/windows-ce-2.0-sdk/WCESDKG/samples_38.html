Svcsampl Sample

The Svcsampl sample implements a transport service DLL (Svcsampl.dll) that is used with the Windows CE Inbox client. The sample transport service interfaces with the file system and performs message service routines by creating, writing to, and reading from files that are located in the Inbox.

For more information on implementing and using a transport service DLL, see Mail Transport Service.

To build the Svcsampl sample
  • Follow the procedure described in Building the Sample Applications, selecting one of the valid project configurations in the table below.
    Source code location Build target options
    Wce\Samples\Win32\Svcsampl Windows CE platform

To use the Svcsampl transport service with Windows CE Inbox
  1. Build Svcsampl.dll for your target platform using the sample code.

  2. Register the DLL in the H/PC registry.

    On the Tools menu select Remote Registry Editor. Use the WCE Remote Registry Editor to add the entries shown in the file Reginit.ini, located in the Svcsampl directory. When finished, on the Registry menu select Export Registry to WCE.

  3. Connect the sample service within Inbox.

    On the H/PC, launch Inbox. On the Compose menu select Options… On the Options dialog box select the Services tab. Tap Add and in the Service dialog box select Sample Service Library. Tap OK. Use the Service Name dialog box to give the service a unique name.
