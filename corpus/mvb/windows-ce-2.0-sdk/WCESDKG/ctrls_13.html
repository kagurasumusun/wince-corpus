Edit Control Messages

The following edit control messages are the same in Windows CE as they are in Windows 95 and Windows NT. You can use message cracker macros to send some of these messages. See Edit Control Macros.

EM_CANUNDO EM_SETLIMITTEXT
EM_CHARFROMPOS EM_SETMARGINS
EM_EMPTYUNDOBUFFER EM_SETMODIFY
EM_FMTLINES EM_SETPASSWORDCHAR
EM_GETFIRSTVISIBLELINE EM_SETREADONLY
EM_GETLIMITTEXT EM_SETRECT
EM_GETLINE EM_SETRECTNP
EM_GETLINECOUNT EM_SETSEL
EM_GETMARGINS EM_SETTABSTOPS
EM_GETMODIFY EM_UNDO
EM_GETPASSWORDCHAR WM_CLEAR
EM_GETRECT WM_COMMAND
EM_GETSEL WM_COPY
EM_LIMITTEXT WM_CTLCOLOREDIT
EM_LINEFROMCHAR WM_CUT
EM_LINEINDEX WM_GETFONT
EM_LINELENGTH WM_GETTEXT
EM_LINESCROLL WM_GETTEXTLENGTH
EM_POSFROMCHAR WM_PASTE
EM_REPLACESEL WM_SETFONT
EM_SCROLL WM_SETTEXT
EM_SCROLLCARET WM_UNDO

Windows CE doesn't support the EM_GETHANDLE, EM_GETTHUMB, EM_GETWORDBREAKPROC, EM_SETHANDLE, or EM_SETWORDBREAKPROC edit control messages.
