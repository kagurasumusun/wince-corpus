List Views

A list view is a common control that displays a collection of items, such as files or folders. Each item has an icon and a label. A user can choose whether to have the items displayed as large icons, small icons, a list, or a detailed list. A user can also drag an item to a new location within the list view, or sort the collection by tapping a column header.

You create a list view by specifying WC_LISTVIEW in the lpClassName parameter to the CreateWindowEx function. This class is registered when the common control dynamic-link library (DLL) is loaded. You can use the InitCommonControls function to ensure that this DLL is loaded.

To register the list view class using the InitCommonControlsEx function, specify the ICC_ LISTVIEW_CLASSES flag in the dwICC field of the INITCOMMONCONTROLSEX structure you pass in the lpInitCtrls parameter.

In Windows CE, list views support several new features. For information on these features, see New Features for List Views.

Tip You can speed up the creation of large list views by disabling the painting of the list view before adding the items. You do this by sending a WM_SETREDRAW message, with the fRedraw flag (wParam) set to FALSE. When you're finished adding items, re-enable painting by sending a WM_SETREDRAW message, with the fRedraw flag (wParam) set to TRUE. It's also a good idea to send the LVM_SETITEMCOUNT message with the cItems parameter (wParam) set to the number of items you'll be inserting, before inserting them. When you do this, the list view will allocate the memory it needs all at once, instead of having to reallocate more memory incrementally as the internal data structures grow.
