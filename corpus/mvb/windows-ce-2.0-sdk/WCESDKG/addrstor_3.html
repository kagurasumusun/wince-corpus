Adding and Removing Address Cards

To add an address card to the Contacts database
  1. Initialize an AddressCard structure to hold whatever properties the new card is to have.

  2. Call the SetMaskfunction on the initialized AddressCard with a (HHPR _) property tag for each property to be present in the new card. Only properties that are enabled by SetMask can be saved to the object store.

  3. Call the AddAddressCard function to insert the new address card into the database.

    AddAddressCard returns the object identifier (myAC_oid) and position index (myAC_posIndex) if the operation is successful. The position index is determined by the current sort order.

The following example illustrates this procedure:

ADDRESSCARD myAC;
PEGOID myAC_oid;
int myAC_posIndex;

memset(myAC,0,sizeof(myAC));    // to make sure everything starts from 0
myAC.stBirthday.wYear=1969;
myAC.stBirthday.wMonth=1;
myAc.stBirthday.wDay=19;
myAC.pszGivenName="Mimmo";
SetMask(&myAC, HHPR_BIRTHDAY);
SetMask(&myAC, HHPR_GIEVN_NAME);
if(!AddAddressCard(&myAC, &myAC_oid, &myAC_posIndex)) {
     // error handling
}
To remove an address card from the Contacts database
  • Call the DeleteAddressCard function on the object identifier of the card.
