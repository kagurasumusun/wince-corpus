Windows CE Notification Functions

The Windows CE notification API exposes six functions for scheduling and handling user notification events.

To give the user a choice of notification events, call the CeGetUserNotificationPreferences function. This function displays a dialog box, showing the valid user notification options for the hardware platform on which the application is running. These options may include displaying the application's icon on the taskbar, displaying a message box, playing a sound, flashing an LED, or vibrating the device. The function records the user's preferences in a CE_USER_NOTIFICATION structure.

Use the CeSetUserNotification function to create a new user notification or to modify an existing one. You pass this function a pointer to a CE_USER_NOTIFICATION structure, containing information on what type of notification event to schedule, and what time to schedule it for.

Use the CeClearUserNotification to delete a user notification.

The CeHandleAppNotifications function marks all notifications previously registered by the application as handled. This function turns off any notification currently in progress for the given application, and removes the taskbar annunciator.

Use the CeRunAppAtTime to request the system to start running the application at the specified time. If an application is registered to run at a certain time, and the time zone changes, the registration will be cleared and the application will not run at the scheduled time. If you pass NOTIFICATION_EVENT_TIME_CHANGE in the lWhichEvent parameter, your application will be notified whenever the time-zone changes, and you can call CeRunAppAtTime again to reschedule it.

Use the CeRunAppAtEvent to request the system to start running the application when the specified event occurs. The application can request to be notified when any of the following events occur.

  • Data synchronization is completed.

  • A PCMCIA device is changed.

  • An RS232 connection is made.

  • The system time is changed.

  • A full device data restore is completed.

You can also use CeRunAppAtEvent to remove all event registrations for the current application.
