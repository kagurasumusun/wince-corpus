Rectangle Support

Rectangles are very useful in Windows applications. You use them to specify clipping regions, scrolling regions, sections of the client area that need to be repainted, and areas for displaying text or graphics. You can also use rectangles to fill a portion of the client area with a particular brush and to retrieve the coordinates of a window or a window's client area.

For an overview of rectangle functions and structures supported in Windows CE, see Rectangle Functions and Rectangle Structures.
