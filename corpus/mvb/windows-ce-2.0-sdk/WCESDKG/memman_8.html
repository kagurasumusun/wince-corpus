System Out of Memory Dialog Box

The operating system displays a System Out of Memory Dialog Box in some low-memory scenarios. This dialog box is a special, "system modal" dialog box which freezes the rest of the system. When it is invoked, socket connections hang and other threads stop running.

The Dialog Box informs the user that memory is critically low on the device and prompts the user to either close applications or increase the amount of RAM allocated to Program Memory.

After the dialog box closes, any selected applications are shut down just as if the Close button was pressed. Applications have eight seconds to close. If more memory is requested after four seconds have passed and memory is still critically low, the dialog box reappears. See System Low Memory Handler.

Note The success of this approach depends on the ability of applications to shut down in response to a WM_CLOSE message without needing to allocate much additional memory in the process. If a significant amount of memory is needed for a graceful shutdown, one possible approach is to cache the needed memory. For example, you could hide a Do You Want to Save Your Document Dialog Box, then make it visible if you need to close the application unexpectedly.
