Porting Win32 Applications to Windows CE

Because Windows CE is a Win32-based operating system, you may be able to re-use code developed for Windows desktop platforms with little modification. Though porting existing code may be quicker and easier than writing it from scratch, keep the following differences between Windows CE and desktop platforms in mind when reusing code:

  • Hardware design and function.

  • User interface. The conventional PC model of a user interface that features a keyboard, mouse, and screen may not be appropriate for a Windows CE device.

  • Win32 API and related development tools. Windows CE supports a subset of what is available for desktop platforms.

  • Extensions to the Win32 API. Some unique features of Windows CE may have no Win32 counterparts, for example the Remote API. Others may replace comparable Win32 functionality, for example the command bar API.
