event

An event is an occurance that triggers a notification. Windows CE supports timer and system events.

event object

An event object is a synchronization object that allows one thread to notify another that an event has occurred. Event objects are useful when a thread needs to know when to perform its task. For example, a thread that copies data to a data archive needs to be notified when new data is available. By using an event object to notify the copy thread when new data is available, the thread can perform its task as soon as possible.

exception handling

Exceptions occur when a program executes abnormally due to conditions outside the program's control. Windows CE does not support C++ exception handling.

execute in place

The H/PC executes some code directly from ROM this is referred to as executing in place. Modules shipped in the H/PC device are stored in ROM, which is addressable as if it were RAM. Code and other read-only sections of the applications are stored as uncompressed, page-aligned, and relocated so that the virtual memory capabilities of the CPU map the ROM pages into the virtual address space as if they were RAM. Executing the code in place, instead of copying the code into RAM for executing, saves system resources. Applications in other file systems, such as PC Cards, cannot be executed in this way since they cannot be mapped directly into the virtual address space, and because applications are not properly relocated and page aligned.

extension keys

Extension keys are an entry in the registry, corresponding to the extension of a given file, that specifies which file filter will handle conversions for that file type.
