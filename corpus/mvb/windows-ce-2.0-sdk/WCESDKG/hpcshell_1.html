Windows CE Shell Functions

The Windows CE shell supports some, but not all, of the functions the Windows 95 and Windows NT shells support. Windows CE also supports the following four new shell functions that are not supported by Windows 95 and Windows NT.

Use the SHCreateShortcut function to create a shortcut to a file.

Use the SHGetShortcutTarget function to retrieve the target path of an existing shortcut.

Use the SHLoadDIBitmap function to load a device independent bitmap from a file.

Use the SHShowOutOfMemory function to display a system-defined dialog box telling the user there's no memory available.

Note The SHCreateShortcut, SHGetShortcutTarget, SHLoadDIBitmap, and SHShowOutOfMemory functions aren't supported in other versions of Windows.

The SHAddToRecentDocs function works the same way it does in Windows 95 and Windows NT, except that you can't add more than ten documents at a time to the Recent list.

When you set the SHGFI_ICON flag in the uFlags parameter to the SHGetFileInfo function, the icon's handle is copied to the hIcon member of the SHFILEINFO structure passed by reference in the psfi parameter. Windows CE doesn't automatically destroy icon objects when a process terminates so, when writing applications for Windows CE, you have to call DestroyIcon on this icon handle, or you'll have a memory leak.

The following shell functions are the same in Windows CE as they are in Windows 95 and Windows NT.

SHGetMalloc

SHGetPathFromIDList

SHGetSpecialFolderLocation

ShellExecuteEx

Shell_NotifyIcon

Windows CE doesn't support the DragAcceptFiles, DragFinish, DragQueryFile, DragQueryPoint, ShellAbout, ShellExecute, ShellProc, SHAppBarMessage, SHBrowseForFolder, SHChangeNotify, SHFileOperation, SHFreeNameMappings, SHGetDataFromIDList, SHGetDesktopFolder, SHGetInstanceExplorer, or SHLoadInProc shell functions.
