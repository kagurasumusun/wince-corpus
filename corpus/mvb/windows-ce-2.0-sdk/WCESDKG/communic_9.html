Accessing Remote File Systems (Wnet API)

For access to remote file systems, Windows CE supports a Common Internet File System (CIFS) redirector (CIFS is also referred to as the Server Message Block, or SMB, protocol). A redirector is a module through which one computer gains access to another. The function of the redirector is to:

  • Reestablish disrupted connections.

  • For remote file-system requests, package them and send them to the target host for processing. The target host returns the results to the originating machine.

Applications gain access to the redirector either through the Windows CE Wnet API or the Universal Name Convention (UNC). The Windows CE redirector allows connections to computers running Windows NT, Windows 95, or any other server that is compliant with the NT LM 0.12 dialect of the Common Internet File System (CIFS) specification.

If you are familiar with the Wnet under Win32, the Windows CE implementation is similar but with the following differences:

  • Windows CE supports Universal Name Convention (UNC) names (that have the form: \\server\share). These names can be up to 260 characters (MAX_PATH) in length.

  • Windows CE name support does not include Drive Letters.

  • Persistent connections are not restored when the user logs in. Instead, the information is stored in the registry and appears in the list of remembered resources. This information can be retrieved by calling WNetOpenEnum with the dwScope parameter set to RESOURCE_REMEMBERED.

  • Windows CE does not expose APIs for mail slots or named pipe operations.

  • Windows CE does not support the WNetGetLastError function. Use GetLastError instead.

  • Windows CE WNet API functions return an ERROR_xxx code, rather than the WN_xxx error codes returned by Win32. The WN_xxx error codes have been mapped onto the ERROR_xxx codes for backward compatibility (see winnetwk.h).

  • The LanMan remote APIs are not available. All such operations must be handled through the WNet API.

  • Windows CE devices do not belong to a specific network context. The only network provider supported in the current release is "Microsoft Windows Network".

To use the Wnet functions under Windows CE, the redirector DLL (redir.dll) and the NetBios DLL (netbios.dll) must be installed on the system. If these DLLs are not installed, the WNet functions will return ERROR_NO_NETWORK.

Note The netbios DLL contains only what is necessary to support the SMB redirector. The NETBIOS applications interface is not supported by Windows CE.
