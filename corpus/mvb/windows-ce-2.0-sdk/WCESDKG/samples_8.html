Reversi Sample

Reversi is a sample game. It demonstrates basic use of the Graphics Device Interface (GDI) for Windows CE.

To build the Reversi sample
  • Follow the procedure described in Building the Sample Applications, selecting one of the valid project configurations in the table below.
