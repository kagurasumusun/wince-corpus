Designing with Color and Grayscale Palettes

Designers often rely on color to make an application aesthetically pleasing. However, using color randomly or excessively can affect usability. Try to limit your use of color to no more than four selections. Always use color in combination with other techniques of emphasis to discriminate areas on the interface and identify crucial features. Never use color alone to distinguish elements, since many users are color deficient and may have difficulty distinguishing colors in inadequate lighting. To distinguish screen elements, use fonts, icons, screen placement, or patterns in addition to color.Because many users do not have color displays, design applications for a grayscale display whenever possible. Then, when the application is finished, you can add color.

The color design model for Windows CE-based devices is based on the 16-color Windows palette, similar to the Windows 95 color scheme, and is measured in bits per pixel (bpp).Windows CE supports 2-, 4-, and 8-bpp color devices, and can logically support 32-bpp device independent bitmaps (DIBs).

Note An 8-bpp display driver can display a 32-bpp device independent bitmaps (DIBs) by mapping each color in the DIB's color table to a specific color on the device. The mapping used is determined by the palette available in the application displaying the bitmap. The application can lose color information if it does not use an appropriate palette or if a bitmap uses more colors than the palette can hold.

Some Windows CE devices support only a 2-bpp palette, with four gray-scale colors: black (RGB 0,0,0), white (RGB 255,255,255), light gray (RGB 192,192,192), and dark gray (RGB 128,128,128). When designing for a grayscale display, a single-pixel graphical element, such as a dot or a line, can be difficult to distinguish without a strong, contrasting color adjacent to it. For example, white and light gray can be hard to see unless presented against a black or dark gray background. When using lighter colors, you may also need to double the thickness of the pixels or lines to strengthen them. Light gray works well for creating a shadow effect around large controls on a white background and for anti-aliasing. Anti-aliasing involves adding colored pixels to smooth the jagged edges of a graphic. When using light gray as a background color for your screen, use a white line to visually separate key areas such a command bar or owner drawn menu from other areas of the screen.
