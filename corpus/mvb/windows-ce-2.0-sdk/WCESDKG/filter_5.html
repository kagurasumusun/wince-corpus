Registering a File Filter

A file filter must be registered in two places. The first place is under the file type's extension key (defined below) in the InstalledFilters subkey. This associates the file filter with the file type it can convert. The other place is under the HKEY_CLASSES_ROOT\CLSID key. This registration gives information on the file filter's capabilities and its DLL.Optionally, it can also be registered under the file type's extension key as the DefaultImport and/or DefaultExport named value. As the names imply, they define the default file filters for the file type.

DefaultImport and DefaultExport

Each key under the HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\Filters key is the name of a file extension. These are the extension keys. Each extension key may have a DefaultImport and a DefaultExport named value, which is the CLSID for a file filter. This identifies which filter, if any, to use as a default when importing or exporting files with the given extension.

InstalledFilters subkey

Under each extension key is the InstalledFilters subkey. This key has any number of named values, each of which is a CLSID identifying a file filter object. The CLSID must identify an OLE component object model (COM) object that is used for the file filter conversion.. These filters will then be listed in the Windows CE Services user interface as filter options, with the DefaultImport or DefaultExport value shown as the default.

Note Any filter defined as the DefaultImport or DefaultExport named value must be listed in the InstalledFilters subkey also.

The following is the structure of the Filters key and the InstalledFilters subkey.

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\Filters

   \.<file extension>
      [DefaultImport = <Default import filter CLSID>]
      [DefaultExport = <Default export filter CLSID>]
      \InstalledFilters
         [<clsid1>]
         . . .
         [more CLSID's for this extension]
    . . .
    [more extensions]

HKEY_CLASSES_ROOT\CLSID key

This key gives basic information concerning file filters. Each file filter that has been identified in the HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\Filters key must be registered under the HKEY_CLASSES_ROOT\CLSID key. The following is the structure of this key and its subkeys.

HKEY_CLASSES_ROOT\CLSID

   \<clsid>
      \(Default) = <Description listed in "Edit Conversion Settings" listbox>
      \DefaultIcon = <filename,index for the icon for this type>
      \InProcServer32 = <filename of the DLL that handles his type>
         ThreadingModel = Apartment
      \PegasusFilter
         [Import]
         [HasOptions]
         Description = <String to display in the conversion dialog>
         NewExtension = <extension of converted file>
   \. . . [more clsids for filters]

The CLSID key contains the following subkeys.

  • <clsid>

    The clsid key is a named value that is the CLSID of the registered file filter. This key contains the DefaultIcon, InProcServer32, and PegasusFilter subkeys.

    • DefaultIcon

      Defines the icon-name string or icon resource identifier for the icon associated with the file filter DLL.

    • InProcServer32

      The default value identifies the file filter DLL. The ThreadingModel named value defines the Apartment model capabilities of the installed file filter.

    • PegasusFilter

      Provides information on the specific capabilities of the file filer. This key may have the following named values:

      Named Value Description
      Import If this named value exists, the conversion type is for importing files from the desktop PC to the Windows CE device. Otherwise, the conversion type is for exporting files from the desktop PC to the Windows CE device.
      HasOptions If this named value exists, the file filter supports the ICeFileFilter::FilterOptions method.
      Description The data for this named value is a string that describes the conversion. The Windows CE Services application displays this text on the property sheets displayed by selecting the DeviceàDesktop or DesktopàDevice tab control selections from the File Conversion Properties selection dialog box and then selecting the Edit button to display the Edit Conversion Settings dialog box.

      For example, if the Import named value exists, then on the DesktopàDevice property sheet, the data value defined by the Description named value will be displayed under the file conversions details "Convert to HPC files of the type".

      NewExtension This named value defines the extension of the file that will be created on the destination device.
