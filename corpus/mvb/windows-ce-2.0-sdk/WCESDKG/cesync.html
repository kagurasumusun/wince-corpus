Data Synchronization for Windows CE Services

The synchronization interfaces provide a means to develop an ActiveSync module to synchronize any data between a Windows CE platform and a desktop PC running the Windows 95 or Windows NT operating system. Once the developed components are installed on both the Windows CE platform and the desktop PC, and the required registry entries have been made, Windows CE Services automatically utilizes the components to synchronize user-defined data between the Windows CE platform and the desktop PC. Windows CE Services also provides a user interface that allows the user to configure an ActiveSync module. One example of these modules is the Schedule+ synchronization that synchronizes Schedule+ data with various Personal Information Manager (PIM) applications on the Windows CE platform.

The following requirements for a desktop store must be satisfied before you can develop an ActiveSync module:

  • All objects that need to be synchronized must be enumerated.

  • A globally unique identifier must be defined for each object.

  • The object identifier must be persistent.

  • The object identifier of a deleted object cannot be reused for a new object.

  • The object identifier must have an order. That is, given any two identifiers, the ActiveSync service provider must be able to determine which identifier comes first and which comes second.

  • Given an object identifier, an application must be able to determine if the object has been changed since the last time it was synchronized. Typically, an ActiveSync service provider associates a last modified time stamp or a change number with the object identifier.

  • The ActiveSync service provider must have read/write access to the store while synchronization is taking place. It must be able to create, read, write and delete any objects in the store.

  • The ActiveSync service provider must be able to read an object and convert it into a series of bytes; it must also be able to take such a series of bytes and convert them back to an object.
