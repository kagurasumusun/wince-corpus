ActiveSync Architecture

You can develop customized ActiveSync modules that can be easily incorporated into the synchronization user interface in Windows CE Services. Windows CE Services provides many common services, so all you need to develop is the code related to your specific data. These services include connecting and disconnecting between the Windows CE platform and the desktop PC, automatic detection of changes and deletions made in both the platform and the desktop PC, and automatic conflict resolution.

You must develop components for both the Windows CE platform and the desktop PC.

  • Desktop Components

    On the desktop PC, an OLE in-proc server must implement the following two OLE interfaces:

    • IReplStore

    • IReplObjHandler
  • Windows CE Platform Components

    On the Windows CE platform, the ActiveSync module must export the following functions:

    • InitObjType

      GetObjTypeInfo

      ObjectNotify

    The following function is optional:

    • ReportStatus
