Trackbar Structures

Windows CE supports a new structure for trackbars, called NMCUSTOMDRAW. This structure is used to support the new custom draw service. If a trackbar provides this service, it passes an NMCUSTOMDRAW structure in the lParam of the NM_CUSTOMDRAW notifications it sends during drawing operations. This structure contains the information necessary to draw the customized trackbar.

Use the following values to specify the parts of a trackbar in the dwItemSpec field of the NMCUSTOMDRAW structure.

TBCD_CHANNEL Identifies the channel that the trackbar control's thumb marker slides along. This is the part of the control that the user moves.
TBCD_THUMB Identifies the trackbar control's thumb marker.
TBCD_TICS Identifies the tic marks that are displayed along the trackbar control's edge.

For information on the custom draw service, see The Custom Draw Service.
