Toolbar Standard Button Image Index Values

The standard button image index values correspond to images within standard image lists that the toolbar control creates for your convenience. The images depict actions that Windows applications commonly perform. Use these values to specify an image index within a standard image list that was loaded with the TB_LOADIMAGES message.

Windows CE supports all of the IDB_STD_LARGE_COLOR and IDB_STD_SMALL_COLOR index values and all of the IDB_VIEW_LARGE_COLOR and IDB_VIEW_SMALL_COLOR index values.

Windows CE also supports the following new index values for IDB_VIEW_LARGE_COLOR and IDB_VIEW_SMALL_COLOR.

Index Bitmap Description
VIEW_NETCONNECT Connect to network drive.
VIEW_NETDISCONNECT Disconnect from network drive.
VIEW_NEWFOLDER New folder.
VIEW_PARENTFOLDER Go to parent folder.

Windows CE doesn't support the IDB_HIST_LARGE_COLOR and IDB_HIST_SMALL_COLOR values.
