Using Remote API Calls in a File Filter

The remote application programming interface (RAPI) should not be initialized (via CeRapiInit) in the file filter DLL. Rather, the application that calls the converter should have already performed the RAPI initialization and established a connection between the desktop PC and the Windows CE device.

If a RAPI call fails because there is no connection established, the filter converter should perform some type of default action other than completely failing. For example, this could involve querying the user to select from various options.

For more information on connectivity between the desktop PC and the Windows CE device, see the "Connection Manager" section. For more information on RAPI, see Remote Access Service (RAS).
