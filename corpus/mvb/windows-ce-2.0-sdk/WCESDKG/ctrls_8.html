Combo Box Messages

Windows CE supports most of the combo box messages supported by Windows 95 and Windows NT, but there are a few differences.

In Windows CE applications, you don't need to specify the amount of memory to allocate when you send a CB_INITSTORAGE message. The lParam parameter to this function is not used. Specify zero for this parameter, and Windows CE will calculate the amount of memory to allocate.

Windows CE supports the following combo box messages the same way Windows 95 and Windows NT do. You can use message cracker macros to send some of these messages. See Combo Box Macros.

CB_ADDSTRING CB_SETDROPPEDWIDTH
CB_DELETESTRING CB_SETEDITSEL
CB_FINDSTRING CB_SETEXTENDEDUI
CB_FINDSTRINGEXACT CB_SETHORIZONTALEXTENT
CB_GETCOUNT CB_SETITEMDATA
CB_GETCURSEL CB_SETITEMHEIGHT
CB_GETDROPPEDCONTROLRECT CB_SETLOCALE
CB_GETDROPPEDSTATE CB_SETTOPINDEX
CB_GETDROPPEDWIDTH CB_SHOWDROPDOWN
CB_GETEDITSEL WM_CLEAR
CB_GETEXTENDEDUI WM_COMMAND
CB_GETHORIZONTALEXTENT WM_COPY
CB_GETITEMDATA WM_COMPAREITEM
CB_GETITEMHEIGHT WM_CUT
CB_GETLBTEXT WM_DELETEITEM
CB_GETLBTEXTLEN WM_ENABLE
CB_GETLOCALE WM_GETFONT
CB_GETTOPINDEX WM_GETTEXT
CB_INSERTSTRING WM_GETTEXTLENGTH
CB_LIMITTEXT WM_PASTE
CB_RESETCONTENT WM_SETFONT
CB_SELECTSTRING WM_SETREDRAW
CB_SETCURSEL WM_SETTEXT

Windows CE doesn't support the CB_DIR or CB_MULTIPLEADDSTRING combo box messages.
