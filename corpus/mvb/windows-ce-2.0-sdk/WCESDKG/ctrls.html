Windows Controls

A standard windows control is a predefined child window used in conjunction with another application window to provide a standardized way for users to make selections, carry out commands, and perform input and output tasks. Controls offer users a familiar interface for interacting with an application, making applications easier to use and learn.

When writing applications for Windows CE, you can use most of the same controls you use when writing applications for Windows 95 and Windows NT. However, there are some minor differences in the way some controls are supported.

To use windows controls, you must include either the Windows.h or the Winuser.h header file in your application. (Windows.h includes Winuser.h, so if you include Windows.h, you don't need to include Winuser.h).

Windows CE supports the following controls.

Check Boxes

Combo Boxes

Edit Controls

Group Boxes

List Boxes

Push Buttons

Radio Buttons

Scroll Bars

Static Controls

See also Common Controls.

For design guidelines on using controls in Windows CE, see Designing Controls. For general guidelines on using controls in user interface design, see The Windows Interface Guidelines for Software Design.
