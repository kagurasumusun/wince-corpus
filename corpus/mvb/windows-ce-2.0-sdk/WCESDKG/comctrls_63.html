In Windows CE, the TCITEM structure replaces the TC_ITEM structure. There are two new fields in the TCITEM structure. The lpReserved1 field has been replaced by the dwState field, and the lpReserved2 field has been replaced by the dwStateMask field. The dwState field contains one of the state values described in the Tab Control Item States topic. The dwStateMask field is a bit field that specifies which bits of the value in the dwState field are valid. The mask field supports a new value, TCIF_STATE, which indicates whether the dwState field is valid.

In Windows CE, the following structures have been renamed to conform to standard naming conventions. Otherwise, these structures are the same as the corresponding structures in Windows 95 and Windows NT.
