Timers

A timer is a system resource that can notify an application at regular intervals. An application associates a timer with a window and sets the timer for a specific time-out period. When the timer expires, it notifies the application either by sending a WM_TIMER message to the window or by using a callback procedure specified in the call to SetTimer.

The smallest possible interval a timer can measure is the system tick interval, which is 25 milliseconds. However, timer messages and callbacks are processed through a GetMessage (or PeekMessage) loop, and have a low priority. The window associated with a timer will be notified sometime after the timer interval expires, but there's no way to determine the exact time at which it will receive the notification.

Windows CE only calls the TimerProc callback procedure when an application calls GetMessage or PeekMessage.

Windows CE supports the WM_TIMER message and the KillTimer and SetTimer functions the same way Windows 95 and Windows NT do.
