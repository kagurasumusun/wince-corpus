Adding Custom Menus to Windows CE Explorer

Windows CE Services allows additional menu items to be added to the Tools menu in the Explorer Window. In order to add a custom menu, you must create a subkey and add several values underneath HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\ CustomMenus:

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\WINDOWS CE Services\CustomMenus]
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\WINDOWS 
CE Services\CustomMenus\subkey]
"DisplayName"="displayName"
"Command"="myApp.exe"
"StatusHelp"="StatusHelpText"
"Version"=version_number
subkey (string)
the subkey to be created under the Tools menu.
DisplayName (string)
the display name of menu item. An ampersand (&) specifies a hot key.
myApp.exe (string)
the command that will be executed via WinExec when the user selects the menu item.
StatusHelpText (string)
the status/help text appearing in the status bar when user browses the menu item.
version_number
the application version; it should be 0x00020000
Example:  this sample reg file adds a calculator menu item
REGEDIT4
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\WINDOWS CE Services\CustomMenus]
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\WINDOWS 
CE Services\CustomMenus\MyApp]
"DisplayName"="&My Calculator"
"Command"="calc.exe"
"StatusHelp"="Brings up the calculator"
"Version"=dword:00020000
