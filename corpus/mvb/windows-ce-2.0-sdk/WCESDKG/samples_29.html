Pdir Sample

The Pdir sample lists the files in a specified directory of the Windows CE object store. This sample uses the following Remote functions:
CeRapiInit

CeRapiUninit

CeFindFirstFile

CeFindNextFile

CeFindClose

To run the Pdir sample program
  • Enter the following from the command line:

    pdir [dir_path]

    dir_path can be a directory name or a path and filename. For example, enter pdir \Windows\Calc.exe

    If dir_path is not specified, then Pdir lists the root directory of the device.
