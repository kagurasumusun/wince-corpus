SETUP.DLL

The device-specific Setup.dll file is an optional ISV-created file that allows the ISV to perform custom operations such as handling errors, ensuring that a "main" component is present , deleting database and user data, etc. The file must export the following functions:

Install_Init() called before the application is installed;

Install_Exit() called after the application is installed;

Uninstall_Init() called before the application is uninstalled;

Uninstall_Exit() called after the application is uninstalled,

Note Once the "Setup.DLL" file is incorporated into the CAB file, it is renamed. You cannot make any assumptions on filename or location of this DLL on the device.

Note You need to include the SDK public header file "ce_setup.h"

Install_Init

this is called before the application is installed. This can be used for custom operations such as application version checking in a reinstall scenario, checking if a "dependent application" is present, etc.

Syntax

codeINSTALL_INIT
Install_Init(
HWND hwndParent,
BOOL fFirstCall,
BOOL fPreviouslyInstalled,
LPCTSTR pszInstallDir
);

Parameters
hwndParent
handle to the parent window
fFirstCall
TRUE¾this is the first time this function is being called

(Note: Install_Init may be called multiple times, each time with a different string for pszInstallDir (for example, when the current directory does not have enough room). ISVs should do "first time" processing when fFirstCall is TRUE and to be aware that subsequent calls to Install_Init may result in different string values for pszInstallDir.


fPreviouslyInstalled
TRUE--the current application is already installed
pszInstallDir
the user-selected install directory of the application
Return value

codeINSTALL_INIT_CONTINUE //continue installation

codeINSTALL_INIT_CANCEL //cancel installation

Install_Exit

this is called after the installation is over. This can be used for error handling that occurred during the installation.

codeINSTALL_EXIT
Install_Exit (
HWND hwndParent,
LPCTSTR pszInstallDir,
WORD cFailedDirs,
WORD cFailedFiles,
WORD cFailedRegKeys,
WORD cFailedRegVals,
WORD cFailedShortcuts
);

Parameters
hwndParent
handle to the parent window
pszInstallDir
final install directory
cFailedDirs
count of the directories that failed to be created
cFailedFiles
count of files that failed to be created
cFainedRegKeys
count of the registry keys that failed to be created
cFailedRegVals
count of the registry values that failed to be created
cFailedShortcuts
count of the shortcuts that failed to be created
return value

codeINSTALL_EXIT_DONE //exit, installation successful

codeINSTALL_EXIT_UNINSTALL //uninstall application before exiting

Uninstall_Init

this is called before the uninstallation begins.

codeUNINSTALL_INIT
Uninstall_Init(
HWND hwndParent,
LPCTSTR pszInstallDir
);
Parameters
hwndParent
handle to the parent window
pszInstallDir
install directory of the application
return value

codeUNINSTALL_INIT_CONTINUE //continue with uninstallation

codeUNINSTALL_INIT_CANCEL //cancel uninstallation

Uninstall_Exit

this is called after the uninstallation. This can be used for any special error handling routines.

codeUNINSTALL_EXIT
Uninstall_Exit(
HWND hwndParent
);

Parameters
hwndParent
handle to the parent window
return value

codeUNINSTALL_EXIT_DONE // a successful uninstallation
