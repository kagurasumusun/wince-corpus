Web Browser Control Events

The Windows CE WebBrowser control supports the following events the same way Windows 95 and Windows NT support them.

DWebBrowserEvents::BeforeNavigate

DWebBrowserEvents::FrameBeforeNavigate

DWebBrowserEvents::FrameNavigateComplete

DWebBrowserEvents::FrameNewWindow

DWebBrowserEvents::NavigateComplete

DWebBrowserEvents::NewWindow

DWebBrowserEvents::TitleChange

The Windows CE WebBrowser control doesn't support the CommandStateChange, DownloadBegin, DownloadComplete, ProgressChange, PropertyChange, Quit, or StatusTextChange events.
