Desktop Connectivity

Many Windows CE devices are intended to perform as an adjunct to a desktop PC. To support such devices, Windows CE provides the following tools to facilitate managing and transferring data between a desktop PC and an attached Windows CE device. These services include:

  • A Connection manager for establishing and maintaining the connection between a desktop application and an attached Windows CE device. For further information, see the "Connection Notification" chapter.

  • A data synchronization interface to allow synchronization of shared data between a Windows CE device and a desktop PC. For further information, see the "Data Synchronization for Windows CE Services" chapter.

  • File filters for importing and exporting files. For further information, see the "File Filters" chapter.

  • A Remote API (RAPI) for enabling a client on a desktop PC to request services such as file manipulation from a server on an attached Windows CE device. For further information, see the "Invoking Windows CE Functions Remotely" chapter.

  • Application installation and management services for installing and uninstalling Windows CE applications from an attached desktop PC (or other sources). For further information, see the "Application Installation and Management" chapter.
