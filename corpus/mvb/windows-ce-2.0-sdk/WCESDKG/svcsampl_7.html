Transport Service Interface Functions

Inbox expects a set of Transport functions that are exported by the transport service DLL. To create a transport service you must export and provide an implementation for each of the transport interface functions listed in the table below, except for those marked as optional. Even if the non-optional function is not relevant to your service, you must still provide a stub for the function.

The following functions are used by Inbox and must be exported by a transport service DLL. These functions are identified by the prefix Transport.

Function Description
TransportConnect Connects to a service for transmission or reception.
TransportCount Determines the number of message present on the service.
TransportDel Deletes a message on the mail server.
TransportDisconnect Disconnects the current service.
TransportError Returns a transport defined value for the last error that occurred.
TransportErrorMsg Returns a string describing the last error.
TransportFreeMsg Allows the transport service to free any data maintained for the specified message; for example, the MailMsg heap allocated by TransportRecv. See Managing Memory for Mail Allocations for more information.
TransportInit This is the first routine called after the service DLL is loaded. The service should initialize global variables and other such tasks, such as creating a private SERVICE structure.
TransportNonIpm (Optional) Sets non-Inter-Personal Message (non-IPM) properties to a message
TransportProps Provides a dialog for setting up or modifying the transport service properties (that is, the registry entries).
TransportRecv Gets and handles received messages. The number of MailMsg messages that can be retrieved is between 1 and the number returned by TransportCount.
TransportRelease This routine is called before the service DLL is unloaded, allowing the transport service to free any data maintained for the entire connection, for example, the SERVICE heap created by TransportInit.
TransportSend Sends a message, in the form of a MailMsg structure.
TransportSetPassword Changes user's service password.
TransportView (Optional) Processes and displays the body of a message. This is called in response to viewing a message that contains a "Type:" field in the message header, if the DLL is registered to support that message type.
