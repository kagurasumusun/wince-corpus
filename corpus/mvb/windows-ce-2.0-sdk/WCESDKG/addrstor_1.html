Programming with the Contacts Database

Your Contacts database application will include the following processes:

  • Opening the Contacts database

  • Adding and removing address cards

  • Opening address cards

  • Modifying address cards

  • Closing the opened address cards

  • Closing the database

In addition, you can use wrapper functions to map a user-defined setting to a system-defined one. For an application that tracks a doctor's patient visits, you can use the stBirthDate and stAnniversary fields to hold the time and dates of the previous and future office visits, and write a SetOfficeVisitDates function to set these two fields as follows:

void SetOfficeVisitDates(SYSTEMTIME stVisit, BOOL fPrev, ADDRESSCARD * myAC)
{
    if(fPrev) 
         myAC.stBirthdate=stVisit;  // previous office visit
    else
         myAC.stAnniversary=stVisit;  // future office visit
}

Similarly, write a (SYSTEMTIME) GetOfficeVisitDates to return the appropriate office-visit date as follows:

SYSTEMTIME GetofficeVisitDate(BOOL fPrev, ADDRESSCARD myAC)
{
    if(fPrev) 
        return myAC.stBirthdate;    // previous office visit
    else
        return myAC.stAnniversary;  //  future office visit
}
