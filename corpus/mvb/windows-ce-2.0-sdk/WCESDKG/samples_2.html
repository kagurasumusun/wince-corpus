Generic Sample

This sample contains the source to a generic Windows CE application that illustrates some of the basic graphics and windowing functionality of Windows CE. The Generic application creates a window and draws a horizontal and a vertical line. Each line bisects the client area, creating four equal quadrants. The WndProc routine processes the mouse clicks (for a Win32 emulation target build) or screen taps (for a MIPS or SH3 target build) and responds as defined in the table below.

Quadrant Description
Upper left quadrant Exits application.
Upper right quadrant Cycles through color palette.
Lower left quadrant Changes Z order of window.
Lower right quadrant Draws a square the size of 1/6 the window width with the lower left corner at the point of mouseclick.
