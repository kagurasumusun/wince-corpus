File Filter Structures

The following structures are used by a vendor-supplied file filter (file converter) DLL.

Structure Description
CFF_CONVERTINFO Contains information that the ICeFileFilter::NextConvertFile method uses to perform file conversions.
CFF_DESTINATIONFILE Contains information about a destination file. A pointer to this structure is passed in the call to the ICeFileFilter::NextConvertFile method.
CFF_SOURCEFILE Contains information about a source file. A pointer to this structure is passed in the call to the ICeFileFilter::NextConvertFile method.
