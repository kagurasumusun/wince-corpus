Other Controls

Windows CE currently supports two controls that are neither standard Windows controls nor common controls. Both of these controls are provided to make it easy to add HTML support to your applications.

The HTML Viewer control provides a simple interface for rendering HTML text, displaying embedded images, and notifying the application of user events.

The Web Browser ActiveX control provides full Web-browsing capability, including the ability to automatically retrieve images and sounds. It supports the HTTP, HTTPS, FTP, and FILE protocols.

For information on these controls, see HTML Viewer Control and Web Browser ActiveX Control.
