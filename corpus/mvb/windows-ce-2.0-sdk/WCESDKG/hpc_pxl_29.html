Pocket Excel 2.0 Formulas

Pocket Excel 2.0 supports one parsething that is not supported in Pocket Excel 1.0 : ptgUPlus. Also, the ptgStr parsething is in Excel 97 format, which is as follows:

Parameter Type Name Description
BYTE cch String length in characters
BYTE flags Always 1 in Pocket Excel 2.0-generated parsethings
WCHAR awch[cch] String contents
