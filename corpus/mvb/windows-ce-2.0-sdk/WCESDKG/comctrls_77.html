Trackbar Messages and Notifications

The following trackbar messages are the same in Windows CE as they are in Windows 95 and Windows NT.

TBM_CLEARSEL TBM_GETTICPOS
TBM_CLEARTICS TBM_SETLINESIZE
TBM_GETCHANNELRECT TBM_SETPAGESIZE
TBM_GETLINESIZE TBM_SETPOS
TBM_GETNUMTICS TBM_SETRANGE
TBM_GETPAGESIZE TBM_SETRANGEMAX
TBM_GETPOS TBM_SETRANGEMIN
TBM_GETPTICS TBM_SETSEL
TBM_GETRANGEMAX TBM_SETSELEND
TBM_GETRANGEMIN TBM_SETSELSTART
TBM_GETSELEND TBM_SETTHUMBLENGTH
TBM_GETSELSTART TBM_SETTIC
TBM_GETTHUMBLENGTH TBM_SETTICFREQ
TBM_GETTHUMBRECT WM_NOTIFY
TBM_GETTIC

Windows CE also supports the following two new messages for trackbars. These messages are used to assign and retrieve the handle of a trackbar's buddy window. A trackbar may have up to two buddy windows.

TBM_GETBUDDY

TBM_SETBUDDY

Windows CE doesn't support the new TBM_GETTOOLTIPS, TBM_SETTIPSIDE, or TBM_SETTOOLTIPS messages, because Windows CE doesn't currently support tool tips for trackbars.

In Windows CE, trackbars support a new notification message called NM_CUSTOMDRAW. A trackbar sends this notification during drawing operations if it provides the new custom draw service. For information on the custom draw service, see The Custom Draw Service.
