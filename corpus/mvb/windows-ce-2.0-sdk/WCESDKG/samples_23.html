TTY Sample Application-Defined Functions

Function Module Description
ClearScreen Screen.c Clears the Terminal window.
CommDlgProc Settings.c Displays and handles the communications settings for the port that was opened by InitPort.
FillScreen Screen.c Fills the TTY window with formatted lines.
InitPort Port.c By default, opens the COM1: device ¾ or the device name passed in from the TTY command line. It initializes the communications settings and creates a thread for ReadThread.
InitScreenSettings Screen.c Initializes the font settings and resizes the screen. After application initialization, this function is called when a WM_SIZE message is received.
MainWndProc TTY.c Handles messages for the TTY window.
PaintScreen Screen.c Refreshes/resets the terminal application window. This function is called when a WM_PAINT message is received.
PortWrite Port.c Writes one byte to the communications device.
PrintDCB Port.c Fills a DCB structure and defines the control setting for a serial communications device.
ProcessChar Screen.c Updates the cursor position on the screen when a carriage return or line feed character is generated from the keyboard.
PutCursorOnScreen Screen.c Called by ProcessChar if the cursor is to remain visible.
ReadThread Port.c Waits for an event to occur on the communications device. If a Receive Character event (EV_RXCHAR) occurs, ReadThread reads the byte from the device and then processes it using ProcessChar.
ScrollDown Screen.c Called by PutCursorOnScreen to scroll the cursor down.
ScrollRight Screen.c Called by PutCursorOnScreen to scroll the cursor right.
SetLightIndicators TTY.c Sends the message to check or uncheck the check box button when the DSR, CTS, RLSD, or RING button is selected.
TermWndProc TTY.c Handles the scroll messages for the terminal window.
