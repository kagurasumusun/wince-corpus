Up-down Control Messages and Notifications

Most of the up-down control messages are the same in Windows CE as they are in Windows 95 and Windows NT but, because up-down controls can only be "buddies" with edit controls, the hwndBuddy parameter in the UDM_SETBUDDY message must either specify the handle of an edit control or be set to NULL.

The following up-down control messages are the same in Windows CE as they are in Windows 95 and Windows NT.

UDM_GETACCEL

UDM_GETBASE

UDM_GETBUDDY

UDM_GETPOS

UDM_GETRANGE

UDM_SETACCEL

UDM_SETBASE

UDM_SETPOS

UDM_SETRANGE

WM_HSCROLL

WM_VSCROLL

The UDN_DELTAPOS notification is the same in Windows CE as it is in Windows 95 and Windows NT.
