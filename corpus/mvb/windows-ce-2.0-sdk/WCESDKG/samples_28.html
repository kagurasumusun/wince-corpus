Pdblist Sample

The Pdblist sample uses the remote database functions to list summary information of databases on the H/PC. This sample uses the following Remote functions:
CeFindAllDatabases

CeRapiInit

CeRapiUninit

CeRapiFreeBuffer

To run the Pdblist sample program
  • Enter the following from the command line:pdblist [Db_Type]

    Db_Type is the Database type. If Db_Type is zero, all databases are listed; this is the default if no option is specified.
