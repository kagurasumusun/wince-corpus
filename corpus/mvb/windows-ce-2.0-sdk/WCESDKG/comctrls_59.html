Extended Tab Control Styles

Windows CE supports a new extended tab control style. Use the TCM_SETEXTENDEDSTYLE message or its corresponding macro, TabCtrl_SetExtendedStyle to set this extended style, and the TCM_GETEXTENDEDSTYLE or its corresponding macro, TabCtrl_GetExtendedStyle to retrieve it.

Note This extended style is not the same as an extended window style; you can't pass it to CreateWindowEx when you create a tab control.

The TCS_EX_FLATSEPARATORS extended style draws separators between tab items in tab controls that have the TCS_BUTTONS or TCS_FLATBUTTONS style. When you create a tab control with the TCS_FLATBUTTONS style, this extended style is set by default.

Windows CE doesn't support the new TCS_EX_REGISTERDROP style.
