Ctlpnl Sample

The Ctlpnl sample creates a control panel DLL named Backlite.cpl. If the control panel (.cpl) file is copied to the Windows directory on the H/PC, the Windows CE Control Panel application will load Backlite.cpl and then call the CTlApplet callback function that is implemented in the Ctlpnl code. When the Control Panel sends the CPL_NEWINQUIRE message, Backlite.cpl returns information about the Backlite applet, using the NEWCPLINFO structure. For example, the szName member is set to "BackLight"; this is the caption that appears under the BackLight applet that appears in the Control Panel window.

When the Control Panel sends the CPL_DBLCLK message, the Backlite DLL displays the Backlight Properties dialog box. This contains the Backlight and General tab controls. The Ctlpnl sample does not actually implement the code to adjust the brightness of the touch screen but rather provides a template for such an implementation.

Following are the messages sent by the Windows CE Control Panel to the Backlite DLL with the call to CTlApplet.

Message Description
CPL_INIT First message sent; indicates that the CPlApplet function exported by the .cpl DLL was found.
CPL_GETCOUNT Second message sent to request the number of applets to be displayed.
CPL_NEWINQUIRE Third message sent to request information about each applet. Backlite.cpl returns a pointer to a NEWCPLINFO structure.
CPL_SELECT Indicates that the application icon was selected; not supported by Windows CE.
CPL_DBLCLK Indicates that the application icon was double-tapped on the H/PC. Backlite.cpl responds by displaying the Backlight Properties dialog box.
CPL_STOP Indicates that the Windows CE Control Panel application is exiting; sent prior to CPL_EXIT.
CPL_EXIT Sent just before the Control Panel frees Backlite.cpl, using FreeLibrary.

To run the Ctlpnl sample using Control Panel
  • Tap Start and then tap Settings. In the Control Panel window, double-tap the Backlite applet.
To run the Ctlpnl sample from an application
  • From an application, run the control panel application using the following form, where each parameter of the command line argument string is separated only by a comma.

ctlpnl.exe cpl_filename.cpl,applet_name,applet_index,tab_index

cpl_filenam

Full path to the control panel DLL. The DLL has an extension of .cpl.

applet_name
Name of the applet. This string appears beneath the applet icon that appears in the Windows CE Control Panel window.
applet_index
Index to applet with one .cpl file.
tab_index
Index to the tab control (on the property sheet) index with the applet.

For example, the Backlight applet is invoked with the following command.

ctlpnl.exe backlite.cpl,BackLight,0,0
