Windows CE Shell

Most Windows CE devices will have a shell, to manage the UI and handle such tasks as launching applications. Windows CE includes a standard shell and related services that give the Windows CE user interface the distinctive look and feel of Microsoft Windows desktop systems. It provides a familiar interface for accessing documents, launching applications, switching between tasks, browsing the file system, and performing other services. It includes:

  • A Control Panel with applets familiar to desktop Windows users, such as Display, System, and Communications. It also includes applets specific to Windows CE, such as Power and Stylus.

  • A Notification API that lets an application register its name and an event with the system. When the event occurs, the kernel will automatically start the named application.

  • Windows CE common controls, that are designed to provide clear, simple, and meaningful information to the user, and provide a means for the user to furnish input to the system and applications as needed.

Windows CE devices that make use of the Windows CE shell typically offer a display screen size that is smaller than that of a desktop computer. To maximize the display space available for applications (the client area), the Windows CE shell supports a new type of control called the command bar. A single command bar replaces the separate menu and tool bars found in desktop Windows applications.
