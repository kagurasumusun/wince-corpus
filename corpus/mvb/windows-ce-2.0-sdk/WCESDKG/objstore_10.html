Functions for Working With the Registry

Windows CE supports a subset of the standard Win32 registry API functions. The Windows CE functions provide all the functions you need to create, read and write, and delete registry entries. The following API functions are provided:

Windows CE Registry Operations API Functions
Enumeration operations RegEnumKeyEx, RegEnumValue
Create, open and close operations RegCreateKeyEx, RegOpenKeyEx, RegCloseKey
Read and write operations RegQueryInfoKey, RegQueryValueEx, RegSetValueEx
Delete operations RegDeleteKey, RegDeleteValue

For information about these functions, see the Windows CE reference documentation.
