Web Browser ActiveX Control

The WebBrowser control is an ActiveX™ control that developers can use to add Internet browsing capabilities to applications.

The WebBrowser control in Windows CE is very similar to the WebBrowser control in Windows 95 and Windows NT, but there are some differences.
