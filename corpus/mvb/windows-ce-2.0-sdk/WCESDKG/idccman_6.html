Connection Notification Interfaces

The Windows CE Services connection manager communicates connection information with a desktop PC application by calling interface methods supported by the client notification application. This section describes the IDccManSink interfaces that a client application implements to receive connection notifications. It also describes the IDccMan interface implemented by the Windows CE Services connection manager.

The following methods are implemented by a client application.

Method Description
IDccManSink Interface that is implemented by a client application that wants to be notified by the Windows CE Services connection manager about connection and disconnection events.
IDccManSink::QueryInterface Defined by the Component Object Model (COM).
IDccManSink::AddRef Defined by COM.
IDccManSink::Release Defined by COM.
IDccManSink::OnLogActive Called when a socket connection is established between the client application and the DCC connection manager.
IDccManSink::OnLogAnswered Called when the Windows CE Services connection manager has detected presence of the communications interface.
IDccManSink::OnLogDisconnection Called when the Windows CE Services connection manager terminates the connection between the desktop PC and the mobile device.
IDccManSink::OnLogError Called if the Windows CE Services connection manager failed to start communications between the desktop PC and the mobile device.
IDccManSink::OnLogInactive Called to indicate that the Windows CE Services connection manager has initiated a disconnection between the desktop and the mobile device.
IDccManSink::OnLogIpAddr Called when the Windows CE Services connection manager has determined what IP address is used to talk to the mobile device.
IDccManSink::OnLogListen Called when the DCC connection manager is waiting for a connection to be established between the desktop PC and the mobile device.
IDccManSink::OnLogTerminated Called when the Windows CE Services connection manager has been shut down.

The following methods are implemented by the Windows CE Services connection manager.

Method Description
IDccMan Interface that is implemented by the Windows CE Services connection manager. This interface allows an application some control of the connection manager and the ability to register for connection notifications.
IDccMan::QueryInterface Defined by COM.
IDccMan::AddRef Defined by COM.
IDccMan::Release Defined by COM.
IDccMan::Advise Called by a client application to register an IDccManSink object for receiving connection notifications from the Windows CE Services connection manager.
IDccMan::ShowCommSettings Called by a client application to show the communications settings dialog box for setting the communications port.
IDccMan::Unadvise Called by a client application when it wishes to stop receiving connection notifications.
IDccMan::AutoconnectEnable This method is currently not implemented.
IDccMan::AutoconnectDisable This method is currently not implemented.
IDccMan::ConnectNow This method is currently not implemented.
IDccMan::DisconnectNow This method is currently not implemented.
IDccMan::SetIconDataTransferring This method is currently not implemented.
IDccMan::SetIconNoDataTransferring This method is currently not implemented.
IDccMan::SetIconError This method is currently not implemented.
