The Windows CE Kernel

The Windows CE kernel contains the core operating system functionality that must be present on all Windows CE platforms. It includes support for memory management, process management, exception handling, and multitasking and multithreading.

The Windows CE kernel borrows much of what is best from Windows desktop operating systems. For example, all Windows CE applications run in a fully-preemptive, multitasking environment, in protected memory spaces. Windows CE supports native UNICODE strings, allowing the internationalization of applications.

Unlike Windows desktop platforms, the Windows CE kernel uses dynamic-link libraries (DLLs) to maximize available memory. They are written as reentrant code, which allows an application to simultaneously share common routines. This approach minimizes the amount of memory-resident code required to execute applications.
