Printing from an H/PC

H/PC applications may enable the printing capability by invoking the PrintDlg common print dialog box. You should initialize the PrintDlg function call by setting up the PRINTDLG structure appropriately.

The H/PC printing model is based on the concept of remote printing. That is, users can print documents when away from the office. This is made possible thanks to the built-in infrared and serial ports on the H/PC devices.

Serial capability makes printing available to most laser and thermal transfer printers. Direct IR printing is most convenient if IR-enabled printers are readily available. For printers that have parallel interfaces, parallel printing is possible via an IR dongle.
