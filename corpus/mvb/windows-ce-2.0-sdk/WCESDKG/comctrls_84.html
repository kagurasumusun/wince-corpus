Tree View Structures

The following tree view structures are the same in Windows CE as they are in Windows 95 and Windows NT.

NM_TREEVIEW

TV_DISPINFO

TV_HITTESTINFO

TV_INSERTSTRUCT

TV_ITEM

TV_KEYDOWN

TV_SORTCB

Windows CE also supports a new tree view structure, called NMTVCUSTOMDRAW. If a tree view provides the new custom draw service, it passes an NMTVCUSTOMDRAW structure in the lParam of the NM_CUSTOMDRAW notifications it sends during drawing operations. This structure contains the information necessary to draw the customized tree view. For information on the custom draw service, see The Custom Draw Service.

In Windows CE, the TV_KEYDOWN structure has been renamed NMTVKEYDOWN, to conform to standard naming conventions, but the two structures are identical.

Windows CE doesn't currently support tool tips for tree views, so it doesn't support the new NMTVGETINFOTIP structure.
