Power Management

Windows CE supports active power management to extend the limited lifetime of batteries operating the hardware device. The operating system automatically selects a power consumption level to match the state of operation of the device. Windows CE maintains three operation modes: full-speed, which is normal consumption, idle, which is lower consumption, and suspend, which is the lowest consumption).

In addition to increasing battery life, the Windows CE power management system monitors the lifetime of the battery and notifies the user when the battery needs to be replaced.

The Windows CE SDK includes programming interface functions that can be called by an application to obtain power information, reset the activity timer, or set timer events to switch the computer on or off.
