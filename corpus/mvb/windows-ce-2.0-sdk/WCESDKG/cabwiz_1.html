A General Procedure for Application Installation

Since the CAB files are self-contained setup packages, they are source-independent (e.g. they can be installed from a partnered desktop PC, or transferred from another device using an IR link).

To create the multiple device-specific CAB files for a single application:

1. Create a single Win32 Setup INF file (with Windows CE-specific modifications).

2. Optionally create a Setup.DLL (which provides custom control of the installation process).

3. Start CAB Wizard with the Setup INF file and the device-specific application files.

To support the typical desktop-to-device installation method of distribution, these additional steps are required:

1. Create a single Application Manager INI file, which provides information about the application for Application Manager.

2. Create a desktop setup program, using any available third-party desktop setup program, which will:

  • copy the multiple device-specific CAB files to the desktop PC

  • launch the Application Manager, with the Application Manager INI file as a parameter, to "register" your application with Application Manager.

Once the application is "registered" with Application Manager, the user can install and uninstall the application to multiple devices from the desktop PC using Application Manager, without having to run the desktop setup program again.
