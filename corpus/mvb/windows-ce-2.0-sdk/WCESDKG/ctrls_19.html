List Box Messages

Windows CE supports most of the list box messages supported by Windows 95 and Windows NT, but there are a few differences.

In Windows CE applications, you don't need to specify the amount of memory to allocate when you send an LB_INITSTORAGE message. The lParam parameter to this function is not used. Specify zero for this parameter, and Windows CE will calculate the amount of memory to allocate.

Because Windows CE doesn't support the LBS_OWNERDRAWVARIABLE style, there's no need to specify an item index in the index parameter to the LB_SETITEMHEIGHT message. Always set the index parameter to zero.
