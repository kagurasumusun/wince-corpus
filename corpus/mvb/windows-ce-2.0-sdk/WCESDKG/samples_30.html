Pget Sample

The Pget sample copies a file from the H/PC to the desktop PC. The file is not filtered by a file filter DLL like Copyfilt. This sample uses the following Remote functions:
CeRapiInit

CeRapiUninit

CeFindFirstFile

CeFindClose

CeCreateFile

CeReadFile

CeCloseHandle

To run the Pget sample program
  • Enter the following from the command line:pget [Desktop_File WinCE_File]

    Desktop_File specifies the file on the desktop PC; WinCE_File specifies the file on H/PC. Both parameters must be specified. For example, enter

    pget \Windows\Tmp.txt c:\Temp\TmpDesktop.txt
