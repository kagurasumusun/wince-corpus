Image List Functions

You use most of the standard image list functions the same way in Windows CE you use them in Windows 95 and Windows NT, but there are a couple of minor differences.

Windows CE currently doesn't support the ILC_COLOR4, ILC_COLOR8, ILC_COLOR16, ILC_COLOR24 and ILC_COLOR32 values in the flags parameter to the ImageList_Create function.

ImageList_ExtractIcon and ImageList_LoadBitmap are implemented as macros in Windows CE, but they work the same way they do in Windows 95 and Windows NT.

Because Windows CE doesn't have cursors (except for the wait cursor), you can't specify the IMAGE_CURSOR flag in the uType parameter to the ImageList_LoadImage function. Windows CE doesn't support any of the OEM image identifiers, so you have to use the HINSTANCE of an application or DLL containing an image for the hinst parameter. Windows CE also doesn't support any of the flags that specify how to load an image, so you have to set the uFlags parameter to zero.

Windows CE doesn't support the ImageList_Read or ImageList_Write functions.

Windows CE also provides the following new image list functions.

Use the ImageList_Copy function to move or copy images within an image list.

Use the ImageList_DrawIndirect function to specify custom drawing properties for an image in an image list. This function takes a pointer to an IMAGELISTDRAWPARAMS structure as a parameter. The IMAGELISTDRAWPARAMS structure contains information about how to draw the image.

Use the ImageList_Duplicate function to copy an entire image list.

Use the ImageList_SetImageCount function to resize an existing image list.

Use the ImageList_RemoveAll function to remove all images from the image list.
