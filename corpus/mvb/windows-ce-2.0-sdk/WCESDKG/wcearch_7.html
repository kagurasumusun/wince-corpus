Persistent Storage

The storage memory portion of RAM is referred to as the object store and includes three types of data storage:

  • The Windows CE file system contains application and data files. It functions like a File Access Table (FAT) file system on a desktop PC.

  • The Windows CE Database offers structured storage. It provides an alternative to storing user and application data in files or the registry.

  • The Windows CE system registry, is used to store the system configuration and any other information that an application must access quickly.

The Windows CE file system is largely used to hold executable and data files that are installed or created by the user. They are normally stored in compressed form. Applications access the file system with standard Win32 functions. Refer to the "Accessing Persistent Storage" chapter for a detailed discussion of file management under Windows.

To reduce the possibility that data will be lost due to a critical failure (such as loss of power) the Windows CE file system is a transactioned system. The file system also implements a transactioned mirroring scheme to track FAT file system operations that are not transactioned. The purpose this feature is to restore the FAT volume if power is lost while critical operations are being performed.

The file system can support up to nine FAT volumes. Each volume is treated as a storage card. If a storage card has multiple partitions, then each partition is treated as a separate volume.

It is possible to support other types of file system by writing block device drivers. The database provides flexible, general-purpose, structured storage of data. It can be used for such purposes as storing contacts or e-mail. Windows CE provides an API to manage database storage. See "Accessing Persistent Storage" for a detailed discussion.

The system registry is essentially similar to that found on desktop Windows systems. Applications running on a Windows CE device can access and modify information in the registry with standard Win32 functions. See "Accessing Persistent Storage" for further discussion.

If the Windows CE device is connected to a desktop PC (by a serial cable, for instance), it is possible to access and modify the object store remotely. The Windows CE remote API (RAPI) includes set of functions that can be used for manipulating the file system and registry. They are invoked by an application running on the desktop, but act on the storage memory of the linked Windows CE device. See "Invoking Windows CE Functions Remotely" for a detailed discussion.

Windows CE offers an extensive and sophisticated set of tools for transferring data between a desktop PC and an attached Windows CE device. Among other tasks, it can be used to synchronize data on a Windows CE device, with a related data set on an attached PC (when updating a list of contacts, for instance). See "Synchronizing a Windows CE Platform and a Desktop PC" for full details.

Storage memory, including both the file system and registry, can also be modified when installing an application. See "Application Installation and Management" for further discussion.
