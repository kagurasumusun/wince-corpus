Tab Control Macros

The following tab control macros are the same in Windows CE as they are in Windows 95 and Windows NT. You can use these macros to send tab control messages. See Tab Control Messages.

TabCtrl_AdjustRect

TabCtrl_DeleteAllItems

TabCtrl_DeleteItem

TabCtrl_GetCurFocus

TabCtrl_GetCurSel

TabCtrl_GetImageList

TabCtrl_GetItem

TabCtrl_GetItemCount

TabCtrl_GetItemRect

TabCtrl_GetRowCount

TabCtrl_HitTest

TabCtrl_InsertItem

TabCtrl_RemoveImage

TabCtrl_SetCurSel

TabCtrl_SetImageList

TabCtrl_SetItem

TabCtrl_SetItemExtra

TabCtrl_SetItemSize

TabCtrl_SetPadding

Windows CE also provides the following new tab control macros, which you can use to send the new tab control messages.

TabCtrl_DeselectAll

TabCtrl_GetExtendedStyle

TabCtrl_HighlightItem

TabCtrl_SetExtendedStyle

TabCtrl_SetMinTabWidth

Note For backward compatibility reasons, the TabCtrl_SetExtendedStyle macro has not been updated to use the dwExMask (wParam) parameter of the TCM_SETEXTENDEDSTYLE message.

Windows CE doesn't support the TabCtrl_GetToolTips or TabCtrl_SetToolTips macros, because it currently only supports tool tips for command bar buttons.
