Registering File Types and File Filters

It is crucial to register each file type and file filter properly. Windows CE Services uses the registry entries to determine which conversions are available for a given file type and how to invoke the filter that supports the conversion..

The steps for registering file types and their filters are:
  1. register the file extension type,

  2. generate a class identifier (CLSID) for the file filter,

3. register the file filter.
