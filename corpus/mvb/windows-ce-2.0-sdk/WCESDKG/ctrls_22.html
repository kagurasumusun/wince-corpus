Push Buttons

A push button, also known as a command button, is a small rectangular control that a user can turn on or off by tapping it with the stylus. A push button has a raised appearance in its default (off) state and a depressed appearance when it's turned on. Windows CE supports owner-drawn push buttons.

The DRAWITEMSTRUCT and MEASUREITEMSTRUCT structures for owner-drawn push buttons are the same in Windows CE as in Windows 95 and Windows NT.
