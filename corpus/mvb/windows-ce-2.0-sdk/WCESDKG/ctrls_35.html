Scroll Bar Messages

Windows CE supports most of the scroll bar messages that other Windows platforms support.

However, in Windows CE 2.0, if you pass a null pointer in the lpsi parameter (lParam) of the SBM_SETSCROLLINFO message, it will return zero, rather than the current position of the scroll box.

The following scroll bar messages are the same in Windows CE as they are in Windows 95 and Windows NT.

SBM_GETPOS

SBM_GETRANGE

SBM_GETSCROLLINFO

SBM_SETPOS

SBM_SETRANGE

SBM_SETRANGEREDRAW

WM_CANCELMODE

WM_COMMAND

WM_CTLCOLORSCROLLBAR

WM_HSCROLL

WM_VSCROLL

Windows CE doesn't support the SBM_ENABLE_ARROWS message.
