Platname Sample

The Platname sample builds Platname.dll that serves as a wrapper DLL for the sample test application Testapp.exe. Platname.dll demonstrates the Load_PegGetPlatformName function (defined in Platname.h). This function is used to distinguish between the SH3, MIPS R4100, and MIPS R3910 CPU types.

Testapp.exe loads Ppcload.dll and Platname.dll and calls the function Load_GetCPU (exported by Ppcload.dll) which returns a string identifying the general type CPU type: "MIPS" or "SH3". Testapp calls Load_PegGetPlatformName to get more specific information about the type of Windows CE platform to which the desktop PC is connected.

Using the Windows CE remote registry function calls, Platname opens the key HKLM\Platform

on the H/PC registry and reads the Name named value. If successful, Platname returns this string value to Testapp. Testapp then loads the appropriate configuration of Testgdi.exe onto the H/PC, in the directory \Program Files\Test App.

Identifying the specific type of target platform is useful for determining the component configuration that should be copied to the target platform when loading applications onto the H/PC.

To build the Platname sample DLL
  • Follow the procedure described in Building the Sample Applications, selecting one of the valid project configurations in the table below.
    Source code location Build target options
    Wce\Samples\Win32\Platname Desktop PC Win32 application

To build the Testapp sample application
  • Follow the procedure described in Building the Sample Applications. Select a project configuration and on the Build menu select Rebuild All
    Source code location Build target options
    Wce\Samples\Win32\Platname\Testapp Desktop PC Win32 application

To run the Testapp and Platname samples
  1. From the command line in the Testapp directory, run Renfils.bat.

    This renames the *.lod and Testgdi.* files to a format expected by Testapp.exe, Ppcload.dll, and Platname.dll. Specifically, Ppcload.dll requires a .load file ending.

  2. On the Build menu select Execute Testapp.exe.

    Testapp copies Testgdi.exe to the H/PC (in the directory \Program Files\Test App) and Testgdi starts.

  3. To exit Testgdi on the H/PC enter Alt-Tab to bring up the H/PC Task Manager and use Task Manager to end the TestGDI task.

Note To run Testapp from the command line go to the Testapp directory and from the command line, enter

dir_name\Testapp [opts]

where dir_name is either Release or Debug, depending on the build configuration. Entering a command line option of 1 causes Testapp to display various status message boxes that reflect the Testapp's actions.
