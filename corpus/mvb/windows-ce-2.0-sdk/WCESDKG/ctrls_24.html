Push Button Messages

Windows CE supports the following push button messages the same way Windows 95 and Windows NT do. You can use message cracker macros to send some of these messages. See Push Button Macros.

BM_CLICK

BM_GETSTATE

BM_SETSTATE

BM_SETSTYLE

WM_COMMAND

WM_CTLCOLORBTN

WM_DRAWITEM

WM_ENABLE

WM_GETFONT

WM_GETTEXT

WM_GETTEXTLENGTH

WM_SETFONT

WM_SETTEXT

Tip The WM_DRAWITEM message isn't generated by the window manager; it's part of the interface between a button and its owner. When you use a built-in button class, the button's window procedure automatically sends the WM_DRAWITEM message to the button's parent window when the button receives a WM_PAINT message. If you create a new class of button (not a built-in button), and you want it to support the WM_DRAWITEM message, you have to be sure to send the WM_DRAWITEM message to the button's parent window whenever the button needs to be redrawn.

Windows CE doesn't support the BM_GETIMAGE or BM_SETIMAGE messages.
