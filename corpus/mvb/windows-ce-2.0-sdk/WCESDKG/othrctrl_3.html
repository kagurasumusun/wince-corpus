HTML Viewer Control Notifications

Windows CE defines the following notifications for the HTML viewer control.

The HTML viewer control sends the NM_BASE notification when it encounters a BASE tag in an HTML document. It uses this notification to pass the URL to the container application.

It sends the NM_CONTEXTMENU notification to inform the container application when a user ALT+Taps inside the control, and where the ALT+Tap event occurred.

The HTML viewer control sends the NM_HOTSPOT notification when a user taps a link or submits a form.

It sends the NM_INLINE_IMAGE to tell the container application to load an image.

It sends the NM_INLINE_SOUND to tell the container application to load a sound.

The NM_META notification provides the application with the HTTP-EQUIV and CONTENT parameters of the META tag in an HTML document.

The NM_TITLE notification provides the application with the title of the current HTML document.
