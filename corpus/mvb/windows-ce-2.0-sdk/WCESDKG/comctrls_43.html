Progress Bar Messages

The following progress bar messages are the same in Windows CE as they are in Windows 95 and Windows NT.

PBM_DELTAPOS

PBM_SETPOS

PBM_SETRANGE

PBM_SETSTEP

PBM_STEPIT

Windows CE also provides the following three new progress bar messages to support progress bars with a 32-bit value range.

PBM_GETPOS

PBM_GETRANGE

PBM_SETRANGE32

Tip The range values in a progress bar are considered signed integers. Any number greater than 0x7FFFFFFF is interpreted as a negative number.
