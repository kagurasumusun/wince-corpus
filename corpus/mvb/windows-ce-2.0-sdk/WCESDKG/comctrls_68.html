Toolbar Notifications

The TBN_GETBUTTONINFO notification is the same in Windows CE as it is in Windows 95 and Windows NT.

Windows CE supports the following new notification messages for toolbars. For information on how to use these notifications, see New Features for Toolbars, The Custom Draw Service, and Supporting Drop-Down Toolbar Buttons.

TBN_DROPDOWN

NM_CUSTOMDRAW

NM_KEYDOWN

Windows CE doesn't support user customization of toolbars, so it doesn't support the TBN_BEGINADJUST, TBN_CUSTHELP, TBN_ENDADJUST, TBN_GETBUTTONINFO, TBN_QUERYDELETE, TBN_QUERYINSERT, TBN_RESET, TBN_SETHOTITEM, or TBN_TOOLBARCHANGE notifications or the new TBN_GETOBJECT notification. Because Windows CE doesn't support drag and drop for toolbars, it doesn't support the TBN_BEGINDRAG or TBN_ENDDRAG notifications. It doesn't support the NM_RCLICK notification because there's no right mouse button on Windows CE-based platforms.
