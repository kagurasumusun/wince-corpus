Managing Network Connections with WNet

There are two functions that can be used to establish a network connection:

  • If the information needed to identify the network resource is known, WNetAddConnection3 can be used.

  • If you need feedback from the user, WNetConnectDialog1 prompts the user with a dialog box to select a local name or UNC.

Network resource information is contained in a NETRESOURCE data structure. At least three members, lpLocalName, lpRemoteName, and dwType, must be specified. The way in which the resource appears to the system depends on the lpLocalName member.

  • If a specific name is used, the subfolder will be given that name.

  • If "*" is used, the local name will be given a default name in the form of "<share> on <server>", with the share name taken from lpRemoteName (it will have the form: \\server\share).

  • If the lpLocalName field is NULL or empty, the connected resource will be nameless and no subfolder will show up in the \NETWORK directory.

There are three ways to terminate a connection

  • The WNetCancelConnection2 function breaks the connection and removes the folder from the \NETWORK directory.

  • The WNetDisconnectDialog starts a general browsing dialog box that allows the user to manage the disconnection.

  • The WNetDisconnectDialog1 function attempts trys to disconnect from a network resource. If the underlying network returns WN_OPEN_FILES, the function prompts the user for confirmation. If there is any error, it informs the user.
