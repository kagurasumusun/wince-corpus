New Features for Toolbars

Windows CE supports some new toolbar functionality that was unavailable in previous versions of Windows.

You can create transparent toolbars in Windows CE by specifying the TBSTYLE_FLAT or TBSTYLE_TRANSPARENT style. If you give a toolbar the TBSTYLE_FLAT style, the toolbar displays buttons in the usual way, but the toolbar on which the buttons sit is transparent. If you give a toolbar the TBSTYLE_TRANSPARENT style, the client area shows through the buttons as well as the underlying toolbar.

In Windows CE, you can use image lists to customize the way a toolbar displays buttons in various states. You can set and retrieve image lists for toolbar buttons by using the TB_GETIMAGELIST and TB_SETIMAGELIST messages for buttons in their default (unpressed) state, and the TB_GETDISABLEDIMAGELIST and TB_SETDISABLEDIMAGELIST messages for buttons in their disabled (grayed) state. You load images into a toolbar's image list by using the TB_LOADIMAGES message. For information on how to use standard button images in a toolbar's image list, see Toolbar Standard Button Image Index Values.

Windows CE supports a new style of toolbar button, called a drop-down button. When a user taps a button that has the TBSTYLE_DROPDOWN style, the toolbar sends the TBN_DROPDOWN notification to its parent window. This notification takes an NMTOOLBAR structure, an its lParam argument, that contains information about the button that was tapped. The parent window usually responds by displaying a pop-up menu or list box under the drop-down button. For more information on drop-down toolbar buttons, see Supporting Drop-Down Toolbar Buttons.

Toolbars in Windows CE also support the new custom draw service, which gives you greater flexibility to customize a toolbar's appearance. If a toolbar provides this service, it sends the new NM_CUSTOMDRAW notification at specific times during drawing operations. The lParam of the NM_CUSTOMDRAW notification is a pointer to an NMCUSTOMDRAW structure, which contains the information necessary to draw the customized toolbar. For information on the custom draw service, see The Custom Draw Service.

In Windows CE, a toolbar sends the NM_KEYDOWN message when it has the focus and a user presses a key on the keyboard. The lpnmk (lParam) parameter is a pointer to an NMKEY structure that contains information about the key that was pressed.

For information on using these new toolbar elements, see Toolbar Control Update.
