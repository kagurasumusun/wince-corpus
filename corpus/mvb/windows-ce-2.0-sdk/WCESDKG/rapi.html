INVOKING WINDOWS CE FUNCTIONS REMOTELY

Windows CE supports a Remote API (RAPI) that gives an application running on a desktop PC (the RAPI client) the ability to invoke function calls on a Windows CE device (the RAPI server). The communication uses Windows Sockets and can take place over a serial link, a modem connection, or a network connection.

The function calls behave as much as possible like the equivalent Windows CE functions. For the most part, RAPI functions have the same syntax, parameters, and return values as the corresponding Windows CE versions. Any differences are noted in the RAPI function descriptions.

Note RAPI serves as a thin layer over the actual Windows CE calls, so string and character parameters must be in Unicode format. If your application is non-Unicode, use the appropriate conversion routines.
