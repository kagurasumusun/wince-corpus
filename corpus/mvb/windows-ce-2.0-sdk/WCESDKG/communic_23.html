Remote Access Service (RAS)

Remote Access Service (RAS) is a software-based multi-protocol router, used to connect a remote device (a RAS Client) to a host PC (the RAS Server). RAS applications are normally executed on the client device and connect with the server via PPP/SLIP.

Windows CE provides support for a RAS client. While most of the standard Win32 RAS functions are supported, only one point-to-point connection at a time is allowed. The connection can be a direct serial connection or a dial up modem connection.

Entries in the RAS phone-book contain the information necessary to establish a RAS connection. Windows CE stores these entries in the registry. The RAS phone-book information includes:

  • The phone number to dial, along with country code and area code.

  • The IP addresses to use while the connection is active.

  • The network protocols.

  • The type of device being used to make the connection.

Windows CE applications running under emulation that use RAS can either link to coredll.lib to resolve the RAS API entrypoints (this is the proper method for device builds) or use the NT RAS API set (that is, link to NT rasapi32.lib). The NT Remote Access Service will need to be installed on the desktop machine with at least one port configured for dial out. A modem is also required for using RAS.

Windows CE supports the following RAS functions:
Function Description
RasDeleteEntry Deletes an entry from the phone book.
RasDial Establishes a connection between client and server.
RasEnumConnections Lists all active RAS connections.
RasEnumEntries Lists all entry names in the phone book.
RasGetConnectStatus Retrieves the current status of a connection.
RasGetEntryDevConfig Retrieves device configuration information.
RasGetEntryDialParams Retrieves connection information for a phone book entry.
RasGetEntryProperties Retrieves the properties of a phone book entry.
RasHangup Terminates a connection.
RasRenameEntry Changes the name of a specified phone book entry.
RasSetEntryDevConfig Saves device configuration information.
RasSetEntryDialParams Changes the connection information for a phone book entry.
RasSetEntryProperties Changes the connection information for a phone book or creates a new entry.
RasValidateEntryName Validates the format of a connection entry name.
