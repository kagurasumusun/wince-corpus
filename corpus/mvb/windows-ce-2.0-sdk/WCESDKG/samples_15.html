Treedir Sample

The Treedir sample application highlights the following functionality:

  • Tree Control, using the TreeView_* functions.

  • File system functions such as FindFirstFile and FindNextFile

Treedir allows the user to browse the file system and display all directories and files by name. Treedir.exe uses the OutputDebugString function to provide feedback (displayed in the IDE Output window) to the user while debugging.
