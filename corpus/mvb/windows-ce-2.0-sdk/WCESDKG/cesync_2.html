ActiveSync Example

Using Schedule+ synchronization as an example, the desktop component is Scdstore.dll. This DLL synchronizes data for three different object types: Appointment, Contact, and Task. A 32-bit OLE in-proc server implements IReplStore and various IReplObjHandler interfaces (one for each object type). The Windows CE platform component is a DLL named Pegobj.dll. This DLL exports the required functions mentioned in the ActiveSync Architecture Overview.

For Windows CE Services to use a synchronization module, valid registry entries must exist in the registry on both the desktop PC and on the Windows CE platform.

On the desktop PC, a new module should register itself under HKEY_LOCAL_MACHINE\Software\Microsoft\Windows CE Services\ Services\Synchronization\Objects. Under Objects there is a list of keys corresponding to the object type. There are five values under every such key: Default, Store,Disabled, Display Name, and Plural Name.

The Default value can be anything; it is usually the description of the object type. The Store value is the OLE programmatic identifier (ProgID) of the store that implements the IReplStore and IReplObjHandler interfaces. Disabled indicates whether the service is shown as disabled or enabled in Windows CE Services. A non-zero value indicates the service is disabled. The Display Name and Plural Name are names for the object (for example, "Appointment" and "Appointments").

The ActiveSync module must also be correctly registered for OLE to recognize it as a valid in-proc server. This means creating a Class Id, a ProgID, etc. and registering it under HKEY_CLASSES_ROOT (see the OLE documentation for details on registration). For example, the ProgID should be registered under HKEY_CLASSES_ROOT\<ProgID>\Clsid.

The Default value of the Clsid key is the GUID for the store. In the example of Schedule+, it is "{a417bc10-7be1-11ce-ad82-00aa006ec559}".

To specify the location of the OLE in-proc server, the following keys are used: HKEY_CLASSES_ROOT\Clsid\<Class ID>\InProcServer32 and HKEY_CLASSES_ROOT\Clsid\<Class ID>\ProgID.

The Default value of the InprocServer32 key is the full path of the 32-bit DLL that implements the IReplStore interface. In this example, this value contains the path to the Schedule+ synchronization module Scdstore.dll. The Default value of ProgID key is the ProgID of the store; in this example, this value is MS.Pegasus.SchedulePlus.

On the Windows CE platform, the registry settings are similar to those for the desktop PC. The object types and the corresponding DLL need to be registered under HKEY_LOCAL_MACHINE\Windows CE Services\Synchronization\Objects. Under Objects key there is a list of keys, one key for each object type. The only value needed is for Store which specifies the name of the DLL that exports the necessary functions; in this example it is Pegobj.dll.
