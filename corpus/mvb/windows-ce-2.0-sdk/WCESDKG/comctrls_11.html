Date and Time Picker Messages

Windows CE supports the following date and time picker messages. You can use macros to send these messages. See Date and Time Picker Macros.

DTM_GETMCCOLOR

DTM_GETMCFONT

DTM_GETMONTHCAL

DTM_GETRANGE

DTM_GETSYSTEMTIME

DTM_SETFORMAT

DTM_SETMCCOLOR

DTM_SETMCFONT

DTM_SETRANGE

DTM_SETSYSTEMTIME
