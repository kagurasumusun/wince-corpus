Handling RAPI Errors

In addition to errors associated with their non-RAPI counterparts, RAPI functions can fail because of RAPI-related errors. Network errors, for example, will need to be communicated back to the calling application.

RAPI functions that fail due to a RAPI-related error will return the error value defined for their Win32-based counterpart. To distinguish between RAPI and non-RAPI errors there are two error functions. To determine if an API failed because of RAPI errors call CeRapiGetError For non-RAPI errors call CeGetLastError, which works the same as GetLastError.
