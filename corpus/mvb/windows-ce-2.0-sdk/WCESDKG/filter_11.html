Implementing a Dummy File Filter

A dummy file filter gives the appearance that files are being converted, without actually implementing a file filter or performing a filter conversion.

Implementing such a dummy filter may be desirable for files that have a unique or "non-standard" file extension name (that is, a file type not already registered in the desktop registry) but do not need any conversion when transferred between the desktop Windows Explorer and the Explorer window for the mobile device. Normally, if a file with an unregistered file type is being copied to the mobile device, the Explorer window for the mobile device will display a No Converter Selected dialog warning. This states that the file will be transferred without conversion. Implementing a dummy filter for this case would avoid alarming the user with the file conversion warning.

Note The No Converter Selected dialog warning will be displayed only if the mobile device's File Conversions Properties is set to enable file conversion. If the "Enable File Conversion" checkbox is unchecked, then the No Converter Selected dialog warning will not be displayed.

To Register a Dummy File Filter
  1. Modify the desktop PC registry key HKLM\Software\Microsoft\Windows CE Services\Filters by adding a subkey that is the name of the file extension for the type of files that should be converted using the "null" file conversion. For example, if you are converting files with extension ".abc", then you must add a subkey .abc.

  2. Under the .abc subkey, create a string value named DefaultImport that is set to "Binary Copy". This identifies the conversion for files with extension .abc that are imported from the desktop PC to the Windows CE device.

  3. Under the .abc subkey, create a string value named DefaultExport that is set to "Binary Copy". This identifies the conversion for files with extension .abc that are exported from Windows CE device to the desktop PC.

The following .reg file registers the example .abc dummy file filter.

REGEDIT4
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\Filters\.abc]
"DefaultImport"="Binary Copy"
"DefaultExport"="Binary Copy"

So in this example, when a file with extension .abc is copied between the desktop PC and the Windows CE device, it will appear as though a conversion process is taking place (that is, there is no No Converter Selected message from Windows CE Services). However, no filter actually is being used, since an InstalledFilters subkey has not been added under the .abc key.
