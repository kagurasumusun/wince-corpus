HTML Viewer Control Messages

Windows CE defines the following messages for the HTML viewer control.

Use the DTM_ADDTEXT message to add text to the HTML viewer. DTM_ADDTEXTW is the Unicode version of this message.

Use the DTM_ANCHOR message to tell the HTML viewer control to jump to a specified anchor. DTM_ANCHORW is the Unicode version of this message.

Use the DTM_ENABLESHRINK message to tell the HTML viewer to shrink images, if necessary, to make the page fit the window.

Use the DTM_ENDOFSOURCE message to inform the control that the current document retrieval operation is complete.

Use the DTM_IMAGEFAIL message to inform the control that the image indicated by the cookie that was specified in the dwCookie field of the INLINEIMAGEINFO structure, passed to the DTM_SETIMAGE message, could not be loaded. The HTML viewer will display the broken image icon.

Use the DTM_SETIMAGE message to pass the HTML viewer the information necessary to display an image.

Windows CE 2.0 introduces a new message, called DTM_SELECTALL. Use this message to tell the control to select all text in the current HTML page.
