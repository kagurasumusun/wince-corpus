Supporting Callback Fields in a DTP control

If you plan to use callback fields with date and time picker (DTP) controls in your application, you must be prepared to handle DTN_FORMATQUERY, DTN_FORMAT, and DTN_WMKEYDOWN notification messages.

This section contains information about how your application can process these notification messages, providing source code for application-defined functions as examples. The following list shows notification messages with sample functions that process them.

Notification message Sample Function
DTN_FORMATQUERY DoFormatQuery
DTN_FORMAT DoFormat
DTN_WMKEYDOWN DoWMKeydown
