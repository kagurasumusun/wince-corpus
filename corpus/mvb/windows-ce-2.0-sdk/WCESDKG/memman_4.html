Selecting a Memory Allocation Method

The following criteria are useful when deciding which memory allocation method is best in a given situation:

  • For a single large allocation (multiple pages), use VirtualAlloc. See Virtual Memory.

  • For a set of small data items that have the same lifetime, use a separate heap created by HeapCreate. See Separate Heaps.

  • For data items that exist for the lifetime of the application, consider putting them in the R/W static data section if there is sufficient space. See Static Data.

  • For small items that exist for the scope of a function, use the stack. See Stack.

  • For small items with random overlapping lifetimes, use the default heap. Try to keep the total size of the heap consistent and predictable. See Default Heap.
