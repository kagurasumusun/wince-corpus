CAB Wizard

The CAB Wizard creates a Windows CE-specific CAB file using the Win32 Setup INF file, an optional ISV-created Setup.dll file, and the application files.

The command line for CAB Wizard is:

cabwiz.exe "inf-file" [/dest dest-directory] [/err error-file] [/cpu cpu-type [cpu-type]]

Note The "/cpu" parameter followed by multiple CPU values must be the last qualifier in the command line.

Note The following Windows CE SDK files must be installed on the desktop PC: "cabwiz.exe", "makecab.exe", and "cabwiz.ddf".

inf-file
absolute full path for the setup INF file
dest-directory
absolute destination directory for the resultant CAB files. If no directory is specified, the CAB files will be created in the directory of inf-file.
error-file
filename for a log file that will contain all warnings/errors encountered during the compilation of the CAB files. If no filename is specified, errors will be displayed in message boxes. If a filename is used, CAB Wizard will run without the UI, which is useful for automated builds.
cpu-type
creates a CAB file for each "processor tag" specified. A "processor tag" is a label used in the Win32 Setup INF file to differentiate between different processor types.
example:  this creates CAB files for the SH3 and MIPS chips, assuming that the Win32 Setup INF file contains the "SH3" and "MIPS" tags:
	cabwiz.exe  "c:\myfile.inf"  /err myfile.err  /cpu  sh3  mips
