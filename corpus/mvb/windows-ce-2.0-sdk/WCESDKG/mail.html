Mail Interface

The Windows CE Inbox application provides users with access to electronic mail via Simple Mail Transport Protocol (SMTP) and Post Office Protocol 3 (POP3). It works with any TCP/IP network such as the Internet.

Inbox was designed as an H/PC-based companion to a Microsoft Exchange client running on the users desktop PC. It is an integral part of the personal information management software that comes bundled with Windows CE for the H/PC.

Windows CE Inbox has an open application programming interface. Application developers can take advantage of this open API to write additional mail transport and storage applications.

The mail interface enables any application to send and receive mail messages mediated through Inbox. When a specified type of message is received, Inbox can also automatically launch an application and pass it the message.

Note Windows CE does not support the Microsoft Messaging API (MAPI) standard. Messaging applications must use the mail interface described here.

Writing a mail application involves:

  1. Maintaining a local message heap to work with each message.

  2. Setting up the MailMsg and MailAtt structures for a message and its attachment.

  3. Storing, retrieving, and querying messages in the message store.
