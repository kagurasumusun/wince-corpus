Graphics, Windowing, and Event Subsystem

Windows CE combines the graphics device interface (GDI) and windowing functionality into the Graphics, Windowing, and Events Subsystem (GWES) module. The event manager and window manager are analogous to Win32 User, and the Win32 GDI is replaced with a smaller, multi-platform GDI more suitable for Windows CE devices. The Windows CE GDI supports the following graphics and display features:

  • Full graphical printing.

  • TrueType and raster fonts.

  • 1, 2, 4, 8, 16, 24, and 32 bit per pixel (bpp) color formats. 2 bpp color formats are unique to Windows CE.

  • Color and custom palettes.

  • Bit block transfer functionality for moving, storing, and transforming bitmaps, including full raster operation code support .

  • Advanced cursor functionality, including user defined cursors.

  • Functions for drawing rectangles, rounded rectangles, polygons, and ellipses.

  • Memory, display, and printer device contexts.
