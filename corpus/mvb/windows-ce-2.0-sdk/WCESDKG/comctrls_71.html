Toolbar Button Styles

The following toolbar styles are the same in Windows CE as they are in Windows 95 and Windows NT.

Style Description
TBSTYLE_BUTTON Creates a toolbar button that looks like a standard push button.
TBSTYLE_CHECK Creates a button that toggles between the pressed and not pressed states each time the user clicks it. The button has a different background color when it is in the pressed state.
TBSTYLE_CHECKGROUP Creates a check button that stays pressed until another button in the group is pressed.
TBSTYLE_GROUP Creates a button that stays pressed until another button in the group is pressed.
TBSTYLE_SEP Creates a separator, providing a small gap between button groups. A button that has this style does not receive user input.

Windows CE supports the following two new toolbar button styles.

Style Description
TBSTYLE_AUTOSIZE Calculates the button's width based on the text of the button, not on the size of the image.
TBSTYLE_DROPDOWN Creates a drop-down list button.

For information on using the TBSTYLE_DROPDOWN style, see New Features for Toolbars and Supporting Drop-Down Toolbar Buttons.
