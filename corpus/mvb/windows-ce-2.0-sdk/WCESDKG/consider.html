Programming Considerations

Windows CE is a new operating system designed to run on compact platforms. Whether you are an experienced software developer or a beginner, there are some unique features about Windows CE that you must consider. The first thing to determine is the configuration of the platform., because Windows CE is a modular operating system, device manufacturers use specific components to configure their devices. You need to know what Windows CE components are supported as well as the design of the hardware. For example, if you are programming for an H/PC the typical 4 megabytes of available memory must influence your program design.

Once you are familiar with your target platform, your next concern is the Windows CE API and development environment. Although Windows CE uses the Win32 programming model and a subset of the Win32 Application Programming Interface (API), there are differences in the operating system that even the most experienced Win32 programmer must become familiar with, the most important being which functions are supported and which are not. Also, you need to know what functions are specific to the Windows CE API, such as those in the Remote API. The Windows CE Integrated Development Environment (IDE) has the look and feel of the Win32 IDE therefore, Win32 programmers should have no problem building, debugging and testing Windows CE applications. To help you debug and test your application Windows CE added an emulator and remote tools.

If you plan to port Windows desktop applications to Windows CE, you will need to convert your code to use 16-bit characters since the native text format of Windows CE is Unicode. The Unicode environment makes developing international software easier because you are not forced to manipulate both single byte and double characters. Also Windows CE supports the National Language Support API which is necessary for international applications. The following sections briefly discuss these considerations and point out references that provide additional information on the topics. One general source of current information is http://www.microsoft.com/windowsce/.
