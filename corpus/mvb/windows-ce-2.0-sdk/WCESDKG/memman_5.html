Monitoring An H/PC Application's RAM Usage

There are two tools to monitor how much memory of each type the system is currently using.

Tool Description
Map File Memory map data file.
Remote Memory Viewer Used to remotely view all of the virtual memory usage in the Windows CE system.

Use the map file to determine how much memory is used in each static section. The length of each section is provided at the top of the file. You should also look at the read-only section, .rdata. The R/W data section is composed of two subsections: .data, which consists of all initialized global data, and .bss, which contains uninitialized data. This type of data is initialized to zero by the loader

Make sure you understand how the system and your application are using a specific module's memory. Note the section number (typically 2 for R/W). Then look in the symbols area of the map file to see what data is in this section and how much space each item uses. To calculate, for instance, the total amount of memory that is taken up by R/W, add the amount needed by .data and .bss and round up the next multiple of the page size.
