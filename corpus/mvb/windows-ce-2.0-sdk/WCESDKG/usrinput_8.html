Using the Caret

A window that receives keyboard input typically displays the characters the user types in the window's client area. A window should use a caret to indicate the position in the client area where the next character will appear. The window should also create and display the caret when it receives the keyboard focus, and hide and destroy the caret when it loses the focus. A window can perform these operations in the processing of the WM_SETFOCUS and WM_KILLFOCUS messages.

You can use the EnableHardwareKeyboard function to enable and disable the keyboard. This is useful for applications in which a user can write on the touch screen. When the keyboard is disabled, a user can rest their hand on it without causing spurious keyboard input. When this function changes the enabled state of the keyboard, it causes menus, tabs, buttons and static controls to repaint themselves, so they can change they way they display keyboard accelerators or other relevant information.

You can use the GetKeyboardStatus function to determine whether there is a keyboard present on the system, and whether it is enabled

Use the keybd_event function to synthesize a keystroke. The system can use such a synthesized keystroke to generate a WM_KEYUP or WM_KEYDOWN message.

Use the MapVirtualKey function to translate a virtual key code to an unshifted charactor.
