Web Browser Control Methods

Windows CE supports the IWebBrowser::Navigate method, but ignores the Flags and Headers parameters. Set the Flags parameter to zero and the Headers parameter to the empty string ("").

The Windows CE WebBrowser control supports the following methods the same way Windows 95 and Windows NT support them.

IWebBrowser::Refresh

IWebBrowser::Refresh2

IWebBrowser::Stop

The Windows CE Web browser control doesn't support the GoBack, GoForward, GoHome, or GoSearch methods, because the top-level shell already supports this functionality.
