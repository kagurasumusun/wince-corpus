Rebar Styles

Windows CE supports most of the standard rebar styles.

Windows CE also introduces a new style, called RBS_SMARTLABELS. A band in a rebar can have a text label, an icon, or both. When you assign a rebar the RBS_SMARTLABELS style, the rebar will only display a band's icon when the band is minimized, and will only display it's text label when the band is either in its restored or maximized state. A band's icon and label are never displayed at the same time. This saves space while making it easy to identify bands, even when minimized.

Note The RBS_SMARTLABELS style isn't supported for rebar controls in other versions of Windows.

Windows CE rebars support the following styles.

Style Description
CCS_VERT Causes the control to appear vertically at the left side of the parent window.
RBS_AUTOSIZE Specifies the layout of the bands will automatically change when the size or position of the control changes. An RBN_AUTOSIZE notification will be sent when this occurs.
RBS_BANDBORDERS Displays narrow lines to separate adjacent bands.
RBS_FIXEDORDER Always displays bands in the same order. A user can move bands to different rows, but the band order is static.
RBS_SMARTLABELS If a band has an icon, the icon is only displayed when the band is minimized. If a band has a text label, the label is only displayed when the band is either in its restored or maximized state.
RBS_VARHEIGHT Displays bands at the minimum required height, when possible. Without this style, the command bands control displays all bands at the same height, using the height of the tallest visible band to determine the height of other bands.
RBS_VERTICALGRIPPER Displays the size grip vertically, instead of horizontally, in a vertical command bands control. This style is ignored for command bands controls that do not have the CCS_VERT style.

Windows CE doesn't currently support drag and drop or tool tips for rebars, so it doesn't support the new RBS_REGISTERDROP or RBS_TOOLTIPS styles.

Windows CE also supports a new rebar band style, called RBBS_NOGRIPPER. When you assign this style to a band in a rebar band, the band doesn't have a gripper. This style applies to individual bands, not to the entire rebar.
