Retrieving Messages

Before using a message and its related information, you must retrieve the message from the message store.

If you know the object ID of the message, you can call MailGet to retrieve the message directly from the message store. Otherwise, you need to use MailFirst to get the first message. You can then step through the message store with repeated calls to MailNext.

You can specify the type of messages to be retrieved to focus the effort to a subset of messages. For example, if you want to retrieve a message from the Inbox folder only, you can set the dwFlags member field of the MailMsg structure to MAIL_FOLDER_INBOX before you call MailFirst on this MailMsg structure.
