Transport Service DLL Structures

The transport service DLL primarily uses the following two structures.

Structure Description
SERVICE Contains information needed to handle mail objects; this includes the identifiers for all messages. SERVICE is a private definition defined by the transport service. A handle to this service (hService) is returned by TransportInit. Using this structure is the primary means of passing information to and from the outside world, and between various members of the DLL The sample transport service structure is defined in \Wce\Samples\Svcsampl\svcsampl.h.
MailMsg Contains information about a specific message.You can access the actual contents of a message using the MailMsg structure. For the transport service, this structure is accessed by using a handle that is passed to the Transport functions. The MailMsg structure can also be accessed through the message store API. This structure contains pointers to the mail headers and message body, along with other related information. For more information on the Mail Message Store Interface, see the Mail Interface section.
MailAtt Contains information about an attachment to a mail message. An attachment consists of a header and the attached file. The file can be local or non-local.
