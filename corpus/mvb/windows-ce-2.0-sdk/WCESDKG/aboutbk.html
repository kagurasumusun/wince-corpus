About This Book

The Microsoft Windows CE Programmer's Guide provides all the information you need to write state-of-the-art applications for Windows CE devices. This book describes how to effectively use Windows CE Application Programming Interfaces (APIs) to develop software applications as well as provides tips and tricks you can use to simplify the development process.

The Windows CE Programmer's Guide is intended for the following audiences:

  • Win32 developers

    These include traditional, Win32, independent software vendors (ISVs), independent hardware vendors (IHVs), service provider writers, and corporate MIS developers. Developers should be reasonably proficient in basic Win32 programming. They should understand the essentials of the Windows message-driven programming model, and at least the most widely used features of the Win32 API.

  • Embedded developers

    These include developers experienced in using 32-bit embedded development tools and modern embedded operating systems. Developers should have significant experience using C or C++ and object-oriented methods.

  • Internal developers and OEMs

    These include internal developers, responsible for creating internal build tools, and OEM developers who use the OEM Adaptation Kit to port Windows CE to their hardware platforms.
