RAPI Functions

This section lists all the RAPI functions, organized in functional groups. Refer to the Windows CE Reference for details.

RAPI-Specific Functions
Function Description
CeRapiFreeBuffer Frees the memory on the desktop PC allocated by a call to CeFindAllDatabases, CeFindAllFiles, or CeReadRecordProps.
CeRapiGetError Reports remote API related failures. It can be used to determine if a call failed due to a failure in the remote API.
CeRapiInit Initializes the Windows CE Remote API synchronously.
CeRapiInitEx Attempts to initialize the Windows CE Remote API asynchronously.
CeRapiInvoke This can be used as a general-purpose mechanism to remotely execute a routine on the Windows CE device
CeRapiUninit Uninitializes the Windows CE Remote API.

Database Functions
Function Description
CeCreateDatabase Creates a new database.
CeDeleteDatabase Removes a database from the object store.
CeDeleteRecord Deletes a record from a database.
CeFindAllDatabases Retrieves information about all databases of a given type residing on the device.
CeFindFirstDatabase Opens an enumeration context for all databases in the system.
CeFindNextDatabase Retrieves the next database in an enumeration context.
CeOpenDatabase Opens an existing database.
CeRapiFreeBuffer Frees the memory on the desktop PC allocated by a call to CeFindAllDatabases, CeFindAllFiles, or CeReadRecordProps.
CeReadRecordProps Reads properties from the current record.
CeSeekDatabase Seeks a record in an open database.
CeSetDatabaseInfo Sets various database parameters.
CeWriteRecordProps Writes a set of properties to a single record.

File and Object Store Management Functions
Function Description
CeCloseHandle Closes an open object handle.
CeCopyFile Copies an existing file to a new file.
CeCreateDirectory Creates a new directory.
CeCreateFile Creates, opens, or truncates a file, pipe, communications resource, disk device, or console.
CeDeleteFile Deletes an existing file.
CeFindAllFiles Retrieves information about all files in a given path.
CeFindClose Closes a search handle.
CeFindFirstFile Searches a directory for a file.
CeFindNextFile Continues a file search from a previous call to the CeFindFirstFile function.
CeGetFileAttributes Returns the attributes of a file or directory.
CeGetFileSize Retrieves the size, in bytes, of a file.
CeGetFileTime Retrieves the date and time that a file was created, last accessed, and last modified.
CeGetStoreInformation Gets the size of the object store and the amount of free space currently in it.
CeGetTempPath Gets the path to the Temp directory.
CeMoveFile Renames an existing file or a directory ¾ including all its children.
CeOidGetInfo Retrieves information about an object in the object store.
CeRapiFreeBuffer Frees the memory on the desktop PC allocated by a call to CeFindAllDatabases, CeFindAllFiles, or CeReadRecordProps.
CeReadFile Reads data from a file.
CeRemoveDirectory Deletes an existing empty directory.
CeSetEndOfFile Moves the end-of-file position to the current position of the file pointer.
CeSetFileAttributes Sets a file's attributes.
CeSetFilePointer Moves the file pointer of an open file.
CeSetFileTime Sets the date and time that a file was created, last accessed, or last modified.
CeWriteFile Writes data to a file.

Miscellaneous RAPI Functions
Function Description
CeCheckPassword Compares a string to the system password.
CeCreateProcess Creates a new process and its primary thread.
CeGetDesktopDeviceCaps Retrieves device-specific information.
CeGetLastError Returns the calling thread's last-error value, equivalent to calling GetLastError on the device.
CeGetSpecialFolderPath Gets the path to a special shell folder.
CeGetSystemInfo Returns information about the current system.
CeGetSystemMetrics Retrieves the system configuration settings and the dimensions of display elements.
CeGetSystemPowerStatusEx Retrieves the system power status.
CeGetVersionEx Obtains extended information about the currently running version of the operating system.
CeGlobalMemoryStatus Gets information on the physical and virtual memory of the system.
CeSHCreateShortcut Creates a shortcut.
CeSHGetShortcutTarget Retrieves the path a shortcut points to.

Registry Functions
Function Description
CeRegCloseKey Releases a key handle.
CeRegCreateKeyEx Creates a key.
CeRegDeleteKey Deletes a key and all its descendants.
CeRegDeleteValue Deletes a value from a key.
CeRegEnumKeyEx Enumerates the subkeys of an open key.
CeRegEnumValue Enumerates the values of an open key.
CeRegOpenKeyEx Opens a key.
CeRegQueryInfoKey Retrieves information about a key.
CeRegQueryValueEx Retrieves the type and data for a value name associated with an open key.
CeRegSetValueEx Stores data in the value field of an open key.

Window Management Functions
Function Description
CeGetClassName Retrieves the name of a window's class.
CeGetWindow Retrieves a window handle.
CeGetWindowLong Retrieves information about a window.
CeGetWindowText Gets the text of a window's title bar ¾ if it has one.
