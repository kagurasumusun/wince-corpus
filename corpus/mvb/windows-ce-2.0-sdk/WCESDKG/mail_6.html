Summary of Mail Functions

The following functions are used for mail and defined in the Msgstore.h file.

To obtain and release resources:

Function Description
MailOpen Opens the message store
MailClose Closes the message store
MailFree Frees the local heap created for opened messages
MailOpenNotify Opens the message store and specifies a window handle to receive notifications of database changes made by other mail handles.

To manipulate messages:

Function Description
MailPut Puts a message into a message store folder
MailGet Gets a message from a message store folder
MailFirst Gets the first message of the specified type from the message store
MailNext Gets the next message of the specified type from the message store
MailDelete Deletes a message from the message store
MailUpdate Updates a message in the message store
MailGetSvcId Gets the object ID of a message based on the value of the service ID

To manipulate folders:

Function Description
MailGetFolderId Gets the ID of a specified message store folder
MailGetFolderName Gets the name of a specified message store folder
MailPutFolder Used to add, delete, or rename folders

To manipulate headers (in the pwcHeaders field of the MailMsg structure):

Function Description
MailHeaderLen Computes the number of characters in a message header string
MailGetField Returns the value of a specified field
MailSetField Sets the value of a specified field

To work with attachments:

Function Description
MailDeleteAttachment Deletes a mail attachment.
MailGetAttachment Get an attachment to the current message.
MailPutAttachment Creates a new mail attachment to the current message.
MailRequestAttachment Requests that an attachment be downloaded from the server when a connection is made.
MailLocalAttachmentLen Gives the total size of all local attachments on the message.

To sort messages:

Function Description
MailGetSort Retrieves the current sort order
MailSetSort Set a new sort order

To check error status:

Function Description
MailError Retrieves the error condition set by the last called mail interface function
MailErrorMsg A verbose version of MailError
