Power Management States

In the most general sense, a portable computer can be in one of three states: dead, on, or off. Because an H/PC is rarely completely off, these terms have slightly different definitions than for a desktop computer. The following table defines the possible states for an H/PC.

Device state Description
dead The computer has no batteries, or all batteries are completely dead. All contents of RAM are lost. (The device is purchased in this state.)
on Any time the display, keyboard, and touch panel are active, the device is in the on state. The CPU can be in either full-speed or idle CPU mode but this is transparent to the user.
off In most cases the CPU is in suspend mode.

With the exception of the dead state, the computer never completely stops using power. In the off state, the computer switches to a minimum power state to maintain its clock and the applications and persistent data stored in RAM. Unneeded circuits and devices, such as the keyboard decoder, display, scratch-pad memory, and processor are de-energized in this state to reduce power requirements. The power used by PC Cards in the off state is determined by their drivers. For more information about device drivers, see the Windows CE DDK.

When the computer is in the on state, it selects various modes of operation to manage its power usage. These CPU operating modes expand the definitions of the on and off device states. The following table defines the possible CPU modes.

CPU Mode Description
full-speed The CPU is running at normal operating frequency.
idle The CPU internal clock is stopped and the CPU is using little power. Peripherals and DRAM may be on or off. The CPU can enter and exit this mode in approximately 10 msec.
suspend The CPU internal and external clocks are stopped and the CPU is using extremely low power. Peripherals and DRAM are usually off. The CPU might take as long as 100 milliseconds to wake-up from this mode.

Of these modes, applications are most affected by the idle and suspend modes.
