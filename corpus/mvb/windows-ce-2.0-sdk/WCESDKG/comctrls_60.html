Tab Control Messages

The following tab control messages are the same in Windows CE as they are in Windows 95 and Windows NT. You can use macros to send most of these messages.See Tab Control Macros.

TCM_ADJUSTRECT

TCM_DELETEALLITEMS

TCM_DELETEITEM

TCM_GETCURFOCUS

TCM_GETCURSEL

TCM_GETIMAGELIST

TCM_GETITEM

TCM_GETITEMCOUNT

TCM_GETITEMRECT

TCM_GETROWCOUNT

TCM_HITTEST

TCM_INSERTITEM

TCM_REMOVEIMAGE

TCM_SETCURFOCUS

TCM_SETCURSEL

TCM_SETIMAGELIST

TCM_SETITEM

TCM_SETITEMEXTRA

TCM_SETITEMSIZE

TCM_SETPADDING

WM_NOTIFY

Windows CE also supports the following new messages for tab controls, which you can use to reset all the items belonging to a tab control, get or set it's extended styles, set the minimum width of its tabs, and set a tab item's highlight state.

TCM_DESELECTALL

TCM_GETEXTENDEDSTYLE

TCM_HIGHLIGHTITEM

TCM_SETEXTENDEDSTYLE

TCM_SETMINTABWIDTH

Use the TCM_SETEXTENDEDSTYLE and TCM_GETEXTENDEDSTYLE messages to set and retrieve extended list view styles. For descriptions of these styles, see Extended Tab Control Styles.

Windows CE doesn't support the TCM_GETTOOLTIPS or TCM_SETTOOLTIPS messages, because it currently only supports tool tips for command bar buttons.
