Window Management Structures

You use the same data structures for managing windows in Windows CE that you use in Windows 95 and Windows NT, with the following modifications.

Because Windows CE doesn't support all the window styles Windows 95 and Windows NT support, the CREATESTRUCT structure only supports a subset of the values supported by Windows 95 and Windows NT in the style and dwxStyle fields. See CreateWindow and CreateWindowEx for details on which window styles are supported.

In the WNDCLASS structure, the values in the cbClsExtra and cbWndExtra fields have to be multiples of four. You can't use atoms in the lpszClassName field; you have to use strings. The only style you can specify in the style field is CS_DBLCLKS. You can also set this filed to NULL. Windows CE doesn't support default menus, so you have to set the lpszMenuName field to NULL. Unless you're using the Windows CE Iconcurs component, which provides support for cursors on appropriate Windows CE-based devices, you must also set the hCursor field to NULL.

The COPYDATASTRUCT, NOTIFYICONDATA, PAINTSTRUCT, and STYLESTRUCT structures are the same in Windows CE as they are in Windows 95 and Windows NT.

Windows CE doesn't support the CLIENTCREATESTRUCT, MDICREATESTRUCT, MINMAXINFO, NCCALCSIZE_PARAMS, WINDOWPLACEMENT, or WNDCLASSEX structures.
