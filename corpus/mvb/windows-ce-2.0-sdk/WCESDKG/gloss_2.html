CAB file

CAB or cabinet files are self-contained files used for application installation and setup. It is a common method of installing applications.

class identifier (CLSID)

A class identifier is a universally unique identifier (UUID) that identifies a type of OLE object. Each type of OLE object (item) has its CLSID in the registry so that it can be loaded and programmed by other applications. For example, a spreadsheet may create worksheet items, chart items, and macrosheet items. Each of these item types has its own CLSID that uniquely identifies it to the system.

client area

The client area or client rectangle is the portion of a window where the application displays output such as text or graphics.

command bar

A command bar is a control window that can contain buttons, combo boxes, and menu bars. Windows CE applications can use a command bar rather than separate menu and tool bar to efficiently utilize available screen space.

Component Object Model

A component-object model is an open architecture for cross-platform development of client/server applications. It is based on object-oriented technology as agreed upon by Digital Equipment Corporation and Microsoft Corporation. The Component Object Model defines an interface (similar to an abstract base class), IUnknown, from which all COM-compatible classes are derived.

contacts database

The contacts database is a collection of names, addresses, telephone numbers, and other information stored on an H/PC by the Contacts application. The database is divided into a set of records called address cards. The database contains any number of address cards, limited only by the amount of memory available on the H/PC.

critical section object

A critical section object is a segment of code which is not reentrant and therefore, does not support concurrent access by multiple threads. Often, a critical section is used to protect shared resources
