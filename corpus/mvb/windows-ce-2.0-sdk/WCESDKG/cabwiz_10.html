CEUTIL¾A Helper DLL for Windows CE Services

CEUTIL is a utility dll that provides the following services:

registration of desktop file filters,

registration of desktop synchronization services,

addition of custom menu items,

access to device partnership settings.

CEUTIL is the recommended method when dealing with the desktop registry entries for Windows CE Services. It encapsulates the registry top-level locations, helping to ensure forward-compatibility for applications and provides helper functions for browsing device partnerships, querying the currently connected or selected device settings, etc. In general, this API is a replacement for (and compatible with) the Win32 registry API usage when referring to any subkeys under the Windows CE Services root.

Registry Structure

This section briefly describes the desktop directory structure used by Windows CE Services and the corresponding identifiers used in CEUTIL to refer to particular keys in the hierarchy. General information is stored under HKEY_LOCAL_MACHINES\Software\Microsoft\Windows CE Services (henceforth referred to as MACHINE_ROOT) and partnership information is stored under HKEY_CURRENT_USER\Software\Microsoft\Windows CE Service (henceforth referred to as LOCAL_ROOT). The first time a device is connected to the desktop and a partnership is created, the various synchronization and filter settings are copied from the MACHINE_ROOT to the partnership subkey under LOCAL_ROOT.

The following table maps registry locations to pre-defined constants used by CEUTIL APIs.

Registry Key CEUTIL Constants Description
MACHINE_ROOT CESVC_ROOT_MACHINE Root of Windows CE Services hierarchy under HKEY_LOCAL_MACHINE
MACHINE_ROOT\Filters CESVC_FILTERS Filters reg root. New filters should register themselves here
MACHINE_ROOT\CustomMenus CESVC_CUSTOM_MENUS Custom menus reg root
MACHINE_ROOT\Services CESVC_SERVICES_COMMON Services reg root
MACHINE_ROOT\Services \Synchronization CESVC_SYNC_COMMON Synchronization reg root. New sync services should register here
LOCAL_ROOT CESVC_ROOT_USER Root of Windows CE Services hierarchy under HKEY_CURRENT_USER
LOCAL_ROOT\Partners CESVC_DEVICES Individual device subkeys are created under this key
LOCAL_ROOT\Partners\<device id> CESVC_DEVICEX Particular device root subkey
LOCAL_ROOT\Partners\<selected device id> CESVC_DEVICE_SELECTED Root subkey for the currently selected device
LOCAL_ROOT\Partners\<device id>\Services CESVC_SERVICES_USER Root Services subkey for a particular device
LOCAL_ROOT\Partners\<device id>\Services\Synchronization CESVC_SYNC Synchronization reg root for a particular device

CeSvcOpen

opens and returns a handle to the registry root for a specified logical position as specified by the CEUTIL constants shown in the table above.

Syntax

HRESULT CeSvcOpen(
UINT uSvc,
LPTSTR pszPath,
BOOL fCreate,
PHCESVC phSvc
);

Parameters
uSvc
logical subkey in registry as identified by CESVC_keys
pszPath
specifies either a subpath to append to the logical subkey, or a DWORD device id (if uSvc is CESVC_DEVICEX)
fCreate
TRUE¾subkey should be created if it doesn't exist
phSvc
returns the logical handle to the registry subkey. This handle is equivalent to a HKEY and can be used by other CEUTIL APIs as well as Win32 registry manipulation routines.
Return value
HRESULT
standard Win32 error code

Example 1: enumerate device partnerships and get file sync folder path

HCESVC	hsvc = NULL;
HCESVC	hsvcSync = NULL;
HCESVC	hsvcProfile = NULL;
DWORD	cProfilesEnum = 0;
DWORD	nProfileID	= 0;

//Enumerate all profiles
while (SUCCEEDED (CeSvcEnumProfiles(&hsvc, cProfilesEnum, &nProfileID)))
{
	if (nProfileID != (DWORD)-1)
	{
		// Open the registry root for the device
		if (SUCCEEDED(CeSvcOpenEx(hsvcProfile, TEXT("Services\\Synchronization"), FALSE, &hsvcSync)))
			{
				TCHAR szPath[MAX_PATH];
				if (SUCCEEDED(CeSvcGetString(HsvcSync, TEXT("Briefcase Path"), szPath, sizeof(szPath)/sizeof(TCHAR))))
				{
					// do whatever…
				}
				CeSvcClose(hsvcSync);
			}
			CeSvcClose(hsvcProfile);
		}
	}
	cProfilesEnum++;
}

Example 2:  add a custom menu
HCESVC	hsvcMyMenu = NULL;

// Create and open the registry root for Custom Menu
if (SUCCEEDED(CeSvcOpen(CESVC_CUSTOM_MENUS, TEXT("MyApp"), TRUE, &hsvcMyMenu)))
{
	CeSVCSetString(hsvcMyMenu, TEXT("DisplayName"), TEXT("&My Calculator"));
	CeSVCSetString(hsvcMyMenu, TEXT("Command"), TEXT("calc.exe"));
	CeSVCSetString(hsvcMyMenu, TEXT("StatusHelp"), TEXT("Displays calculator"));
	CeSVCSetString(hsvcMyMenu, TEXT("Version"), 0x00020000);
	CeSvcClose(hsvcMyMenu);
}
