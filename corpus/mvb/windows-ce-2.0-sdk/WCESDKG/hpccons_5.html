Managing Memory on the H/PC

The minimum amount of RAM an H/PC must have is 2MB. OEMs may add additional memory (several models currently are offered with 4MB), and more can be added via the PC Card slot. The operating system and a collection of bundled applets are loaded on 8MB of ROM and execute in place. However, some RAM is also required (for stack space, among other things). Another chunk of RAM is taken up by the UI. Since there is no disk drive or other mass storage device, applications and data must be stored on RAM. These applications do not execute in place, so additional RAM is needed in addition to that required for storage.

Note H/PC 2.0 is optimized for 8MB ROM configuration and strives to be backward compatible with the earlier versions which requires only 4MB of ROM. However, not all the new features and functionality may be available if an H/PC 1.01 device is to be upgraded to H/PC 2.0.

In short, memory is limited, and must be used carefully. A 350K application may seem small by desktop PC standards, but it occupies an appreciable portion of the available memory on a 2MB H/PC. Applications that are intended to run on all H/PCs must be particularly careful with memory usage, as they must be able to fit within the 2MB minimum.

For further discussion of memory management with Windows CE, and some suggestions on how to limit the size of your applications, see Porting Windows 95 Programs to Windows CE and Managing Memory.
