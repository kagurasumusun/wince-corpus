In Windows CE, the following structures have been updated to accommodate new features and functionality.

The LVCOLUMN structure replaces the LV_COLUMN structure. Two new fields have been added to LVCOLUMN. The iOrder field specifies where in the list view to position the column. Zero specifies the leftmost column. The iImage field contains the zero-based index of an image in an image list to display next to the column's title. The mask field supports two new constants, LVCF_IMAGE and LVCF_ORDER, to indicate whether the two new fields contain valid information. The fmt field also supports two new constants. The LVCFMT_IMAGE value specifies that the column will display an image from an image list. The LVCFMT_BITMAP_ON_RIGHT value specifies that a bitmap associated with the column will appear to the right of the text. (This flag is only valid for bitmaps; it doesn't apply to columns using images from an image list.)

The LVHITTESTINFO structure replaces the LV_HITTESTINFO structure. A new field, called iSubItem, has been added to LVHITTESTINFO. This field receives the index of the subitem that matches the hit test. If the matching item isn't a subitem, the value in this field is zero. If the matching item is a subitem, the value in the iItem field is zero.

The LVITEM structure replaces the LV_ITEM structure. A new field, called iIndent, has been added to LVITEM, that specifies how far to indent the item in the list. The mask field supports a new constant, LVIF_INDENT, that indicates whether the iIndent field is valid.

Windows CE also provides the following new structures to support new features and functionality, such as virtual list views and the custom draw service. For an overview of how to use these new features, see New Features for List Views. For more information on the custom draw service, see The Custom Draw Service.

In Windows CE, the following structures have been renamed to conform to standard naming conventions. Otherwise, these structures are the same as the corresponding structures in Windows 95 and Windows NT.

Windows CE Windows 95
NMLISTVIEW NM_LISTVIEW

Windows CE doesn't support background images or tool tips for list views, so it doesn't support the new LVBKIMAGE or NMLVGETINFOTIP notifications.
