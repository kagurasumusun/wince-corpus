Windows CE Shell Services

The shell is the user interface to the Windows CE operating system. The Windows CE shell is based on the Windows 95 shell and provides many familiar features, like the desktop window, the recycle bin, the taskbar, and drag and drop functionality.

The Windows CE shell also provides some unique features that aren't available on Windows 95 or Windows NT. One new feature of Windows CE 2.0 is that the shell is fully integrated with the Windows CE Pocket Internet Explorer. You can still use the Windows CE shell the same way you use the Windows 95 shell for manipulating files and shortcuts on the H/PC desktop, but you also have the option of using the browser as your shell interface.

Note The term H/PC desktop refers to the first screen you see when you turn on your H/PC.

To use the browser interface, double-tap My Handheld PC on your H/PC desktop. The My Handheld PC screen looks very similar to the My Computer screen on standard Windows platforms, except that it has a command bands control at the top. The command bands control includes the standard Internet Explorer Forward and Back buttons on its toolbar, and also has an address bar band. You can access a file on your H/PC by entering its name in the address bar's text box, just as you would enter a URL to access an internet site. You can also enter a URL to browse the world wide web from your H/PC shell. You can use either the Forward and Back buttons or the address bar's history list to browse back and forth between web sites and files on your H/PC. To use the browser interface directly from the H/PC desktop, tap the Up One Level button on the command bands control. This will return you to your H/PC desktop, while retaining the command bands control at the top of the screen.

Because Windows CE is often installed on mobile devices, the shell provides a Notification API you can use to create applications that are particularly suited to mobile users. You can use the functions in this API to notify a user when a particular event occurs, or to start and run your application automatically at a pre-specified time.

Another unique feature of the Windows CE shell is the hibernation message. It's important for applications sharing limited resources to cooperate with one another. The Windows CE shell facilitates this by sending out a WM_HIBERNATE message whenever system resources are running low. This message advises applications that they should release any resources they don't need to recover their current state when they're reactivated. This frees up resources for whatever application currently has the foreground, so it can complete its task.

The clipboard works the same way in Windows CE as it does in Windows 95 and Windows NT, except that Windows CE doesn't support clipboard viewers or private clipboard formats.

Windows CE is a portable operating system that runs on many different hardware platforms. Not all of these platforms require a shell, but for those that do, the similarity of the Windows CE shell to the Windows 98 shell makes it easy to leverage your knowledge of the Windows CE shell API when writing applications for Windows CE.
