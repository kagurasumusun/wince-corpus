Providing Help

Users can access Help in the H/PC either by selecting the Help command on the Start menu or by tapping a Help (?) button included on a window's command bar. This Help button looks similar to the What's This? button in Windows 95 and Windows NT, but it functions differently. The What's This? button activates a Help mode in which the user can select a field about which to receive information. On the H/PC, the Help (?) button brings up the Help contents for the current window. Use ALT+H as the shortcut key for accessing Help.

Author your application's Help file in HTML. Create each topic as a text file with an .htp extension. Create your contents page as a text file also, but save it with an .htc extension.
