Platform and Shell Considerations

Your platform configuration dictates what kind of shell or user interface you need. Unlike Windows 95 and Windows NT there is no one Windows CE interface. The target hardware determines the user interface components. Although most devices require some kind of user interface many do not require a Windows-like interface, and devices incorporated into larger systems or machines may have no user interface at all.

Most applications require some kind of user interface. If you need a Windows-like interface Windows CE provides a shell component similar to Windows 95 and Windows NT. However, if you need other kinds of shells, you must build your own. For this purpose, Windows CE provides a Shell API as well as interface elements which are not available in Windows 95 and Windows NT. For example, you can write applications which allow the user to write directly on the device's screen with a stylus or control the program with audio commands.
