Pput Sample

The Pput sample copies a file from the H/PC to the desktop PC. The file is not filtered by a file filter DLL like Copyfilt. This sample uses the following Remote functions:
CeRapiInit

CeRapiUninit

CeGetFileAttributes

CeCreateFile

CeWriteFile

CeCloseHandle

To run the Pput sample program
  • Enter the following from the command line:pput [WinCE_File Desktop_File]

    WinCE_File specifies the file on H/PC; Desktop_File specifies the file on the desktop PC. Both parameters must be specified. For example, enter

    pget c:\Temp\TmpDesktop.txt \Windows\Tmp.txt
