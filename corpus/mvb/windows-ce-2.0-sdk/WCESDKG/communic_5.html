Windows CE Networking

Windows CE supports a variety of networking options ranging from serial link networking over a modem, to wireless communication. Its capabilities include:

  • Sending an ICMP "Ping" request.

  • Support for browser-related protocols such as HTTP.

  • Access to remote file systems

  • Security features

  • Access to an infrared transceiver via the IrDA protocols

Output options include:

  • Local area networking (via NDIS 4.0)

  • Serial-link networking using the PPP or SLIP protocols (including support for wireless services).

  • Infrared networking with the IrDA protocols.

As with virtually all operating systems, Windows CE network support is organized in layers. The network "stack" is responsible for taking information from applications, breaking it into one or more "packets", and adding whatever header information is necessary to ensure that the packet arrives at its destination. Applications can access the network stack through APIs exposed by the upper two layers.

  • The Windows Sockets API (Winsock) provides applications with the means to exchange packets with a remote site, but leaves the format of the data entirely up to the application.

  • Support for higher level protocols like HTTP or FTP is provided by the uppermost layer. These APIs ensure that the data is properly structured, and also relieve applications of the need to use Winsock directly.
