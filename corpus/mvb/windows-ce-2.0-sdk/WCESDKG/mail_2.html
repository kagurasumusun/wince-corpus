Message Store

The message store is a database in the object store used to store messages. It is partitioned into folders arranged in a flat hierarchy. Five types of folders are defined by the system:

  • Inbox

    Stores all incoming messages.

  • Outbox

    Queues messages to be sent the next time a connection is made.

  • Sent Items

    Built-in folder that (optionally) stores a copy of sent messages.

  • Deleted Items

    Built-in pseudo-folder that displays messages marked for delete.

  • User-Defined

    Users can create up to 21 additional folders. Folder names are limited to 31 characters.

The built-in folders cannot be renamed or deleted. Deleted messages actually remain in their respective folders, but are marked with a flag and visible only in the Deleted Items pseudo folder. When a user recovers a deleted message, the flag is unmarked and the message reappears in the original folder.
