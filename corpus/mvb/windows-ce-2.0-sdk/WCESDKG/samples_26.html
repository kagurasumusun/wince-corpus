Copyfilt Sample

The Copyfilt sample demonstrates creating and registering a file filter between an H/PC and the desktop.

For more information on how to write a file filter (converter) DLL, see Implementing a File Filter and File Filter Registry Entries .

Source Code Location Build Target Options
Wce\Samples\Win32\copyfilt Desktop PC Win32 application

To build and run the Copyfilt sample
  1. Open Project Workspace and build Copyfilt.dll for Win32 Release.

  2. Open Copy.reg and make changes to registry entries if the project does not reside in c:\devstudio\wce\samples\win32\copyfilt. Also note that all backslash characters are doubled. The following three registry entries in copy.reg have hardcoded paths and may need to be changed prior to running copy.reg. The path is the location of Copyfilt.dll.

    a. [HKEY_CLASSES_ROOT\CLSID\{DA6C8F00-9CF2-11cf-8011-00A0C90A8F78}\InProcServer32] @="c:\\devstudio\\wce\\samples\\win32\\copyfilt\\release\\copyfilt.dll"

    b. [HKEY_CLASSES_ROOT\binfile\DefaultIcon] @="c:\\devstudio\\wce\\samples\\win32\\copyfilt\\release\\copyfilt.dll,-102"

    c. [HKEY_CLASSES_ROOT\pbnfile\DefaultIcon] @="c:\\devstudio\\wce\\samples\\win32\\copyfilt\\release\\copyfilt.dll,-103"

  3. Run the desktop Explorer. Double click on Copy.reg from the Explorer. This will set the appropriate registry settings.

  4. Run the H/PC Explorer.

  5. Use the desktop Explorer to drag the file "MSG00001.bin" from the \wce\samples\copyfilt" directory to the H/PC Windows directory this will invoke the Copyfilt.dll for file filtering. The file is renamed with a .pnb extension on the H/PC after file copy is complete.

Note When installing a new file filter the SetUp program should register the keys programmatically. 

REGEDIT4

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\Filters\.bin]
"DefaultImport"="{DA6C8F00-9CF2-11cf-8011-00A0C90A8F78}"

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\Filters\.bin\InstalledFilters]
"{DA6C8F00-9CF2-11cf-8011-00A0C90A8F78}"=""

[HKEY_CLASSES_ROOT\CLSID\{DA6C8F00-9CF2-11cf-8011-00A0C90A8F78}]
@="COPYFILT Sample"

[HKEY_CLASSES_ROOT\CLSID\{DA6C8F00-9CF2-11cf-8011-00A0C90A8F78}\DefaultIcon]
@="copy.dll,-102"

[HKEY_CLASSES_ROOT\CLSID\{DA6C8F00-9CF2-11cf-8011-00A0C90A8F78}\InProcServer32]
@="%Msdevdir%\\wce\\samples\\win32\\copyfilt\\debug\\copy.dll"
"ThreadingModel"="Apartment"

[HKEY_CLASSES_ROOT\CLSID\{DA6C8F00-9CF2-11cf-8011-00A0C90A8F78}\PegasusFilter]
"Import"=""
"Description"="COPYFILT: Copy a .bin to a .pbn"
"NewExtension"="pbn"

[HKEY_CLASSES_ROOT\.bin]
@="binfile"

[HKEY_CLASSES_ROOT\binfile]
@="COPYFILT: Desktop BIN File"

[HKEY_CLASSES_ROOT\binfile\DefaultIcon]
@="%Msdevdir%\\wce\\samples\\win32\\copyfilt\\debug\\copy.dll,-102"

[HKEY_CLASSES_ROOT\.pbn]
@="pbnfile"

[HKEY_CLASSES_ROOT\pbnfile]
@="COPYFILT: H/PC Bin File"

[HKEY_CLASSES_ROOT\pbnfile\DefaultIcon]
@="%Msdevdir%\\wce\\samples\\win32\\copyfilt\\debug\\copy.dll,-103"
