Using the Taskbar in Windows CE

The Windows CE taskbar is very similar to the taskbar in Windows 95 and Windows NT but, in several ways, it's even more important.

Because Windows CE applications don't have title bars, users identify a running application primarily by the icon and text displayed on its taskbar button.

You can associate a 16 x 16 icon with your application, to be displayed on its taskbar button, by sending a WM_SETICON message to your application's main window. Windows CE doesn't support the RegisterClassEx function.

In Windows CE, users can't minimize or maximize windows. Instead, a user can send a window to the back of the Z order, or restore it to the foreground, by tapping its button on the taskbar.

Windows CE only assigns taskbar buttons to visible, top level windows that have the WS_OVERLAPPED style. If a window is hidden, or if it has the WS_POPUP or WS_CHILD styles, it won't have a button on the taskbar.
