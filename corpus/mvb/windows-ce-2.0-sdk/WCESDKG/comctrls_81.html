Tree View Messages

The following tree view messages are the same in Windows CE as they are in Windows 95 and Windows NT. You can use macros to send most of these messages. See Tree View Macros.

TVM_CREATEDRAGIMAGE TVM_GETNEXTITEM
TVM_DELETEITEM TVM_GETVISIBLECOUNT
TVM_EDITLABEL TVM_HITTEST
TVM_ENDEDITLABELNOW TVM_INSERTITEM
TVM_ENSUREVISIBLE TVM_SELECTITEM
TVM_EXPAND TVM_SETIMAGELIST
TVM_GETCOUNT TVM_SETINDENT
TVM_GETEDITCONTROL TVM_SETITEM
TVM_GETIMAGELIST TVM_SORTCHILDREN
TVM_GETINDENT TVM_SORTCHILDRENCB
TVM_GETISEARCHSTRING WM_NOTIFY
TVM_GETITEM WM_SETREDRAW
TVM_GETITEMRECT

Windows CE also supports a new tree view message, called TVM_EXPAND. This message expands or collapses the list of child items associated with a parent item. You can send use the new TreeView_Expand macro to send this message.

Tip You can speed up the creation of large tree views by disabling the painting of the tree view before adding the items. You do this by sending a WM_SETREDRAW message with the fRedraw flag (wParam) set to FALSE. When you're finished adding items, re-enable painting by sending a WM_SETREDRAW message with the fRedraw flag (wParam) set to TRUE.

Windows CE doesn't currently support tool tips for tree views, so it doesn't support the new TVM_GETTOOLTIPS or TVM_SETTOOLTIPS messages.
