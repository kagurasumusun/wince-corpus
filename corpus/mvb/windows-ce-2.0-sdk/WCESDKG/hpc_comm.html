Communications and Connectivity for the H/PC

The ability to exchange information with Windows-based desktop computers is one key feature of the H/PC. Much of the software designed for the H/PC consists of two elements: the application running on the H/PC and a full featured companion application on the Windows-based desktop PC. Many extend the functionality of Desktop applications by providing a portable companion version with a subset of the features for the H/PC.

The H/PCs portability also makes it an excellent tool for sending and receiving e-mail and faxes from remote locations, and despite their limited screen size, H/PCs are proficient Internet web browsers. This section outlines the communications and connectivity capabilities of the H/PC.

Windows CE provides support for a number of standard and optional communications and connectivity devices on the H/PC. All H/PCs are equipped with the following communications hardware:

  • RS-232C 9 pin serial communications port

  • Infrared Data Association (IrDA) compliant infrared port.

Many H/PC manufacturers include optional communication and connectivity hardware and software, such as the following:

  • Type II PC Card slot

  • Internal modems

  • One-way pagers

  • Support for modems connected to the serial port.

Windows CE also provides plug-and-play support for a variety of communication devices that connect to the H/PC through the PC Card slot.
