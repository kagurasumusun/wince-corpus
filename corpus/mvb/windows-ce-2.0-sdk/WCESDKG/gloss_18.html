unicode

A 16-bit character set capable of encoding all known characters and used as a worldwide character-encoding standard. Windows CE uses Unicode exclusively at the system level.

Uniform Resource Locator

The address of a resource on the Internet. URL syntax is in the form Protocol://Host/Localinfo, where Protocol specifies the means of fetching the object (such as HTTP or FTP), Host specifies the remote location where the object resides, and Localinfo is a string (often a file name) passed to the protocol handler at the remote location. Also called Universal Resource Locator, Uniform Resource Identifier (URI).

Unimodem

1. The universal modem driver, Unimodem.dll, that is provided with Windows CE. The Unimodem driver is a standard part of TAPI. TAPI function calls typically send AT commands to your modem. The TAPI APIs are contained in tapi.dll, which in turn calls the Telephony Service Provider (TSP) API. Modem functions are contained in a TSP and implemented in a DLL. Unimodem translates TSPI calls into AT commands, and sends the commands to a virtual device driver that actually talks to the modem.

2. A universal modem; a modem that supports standard modem ATI commands. These commands are supported by ISA, Serenum, and PCMCIA Plug-and-Play modems, and non-Plug-and-Play modems. Of these Windows CE currently supports only PCMCIA modems.

Universally Unique Identifier

Or globally unique identifier (GUID). A 128-bit value that uniquely identifies objects such as OLE servers, interfaces, manager entry-point vectors, and client objects. Universally unique identifiers are used in cross-process communication, such as RPC, and OLE.

user notification

A user notification is designed to alert the user about a timer event. The notification may require the user to perform some action to handle the notification or may generate a sound to alert the user. For example, the system may display a dialog box and play a sound before a scheduled appointment. The user would tap the dialog box OK button to acknowledge the appointment. User notifications are always associated with an application.
