Check Boxes

A check box is a small square box with a label next to it. A user can turn a check box on or off by tapping it with the stylus. The box is empty in its default (off) state and has a check mark in it when it's turned on.

Windows CE doesn't support the CheckDlgButton or IsDlgButtonChecked functions.
