Fully Recognized Tokens

These tokens are fully recognized by Microsoft Pocket Word 2.0 and produce the expected effect on the document for that RTF.

Example

Center Justify \qc

All paragraphs with this property are displayed centered justified.

Pocket Word 2.0 supports tokens for:
