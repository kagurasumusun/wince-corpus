The Clipboard

The Clipboard is the standard Windows method of transferring data between a source and a destination, as in copy, cut, and paste operations. Because all applications have access to the clipboard, data can easily be transferred either within a single application or between applications.

You use the clipboard the same way in Windows CE that you use it in Windows 95 and Windows NT, except that Windows CE currently doesn't support clipboard viewers, or private clipboard formats.

The METAFILEPICT structure is the same as it is in Windows 95 and Windows NT.

For an overview of clipboard functions and messages supported in Windows CE, see Clipboard Functions and Clipboard Messages.
