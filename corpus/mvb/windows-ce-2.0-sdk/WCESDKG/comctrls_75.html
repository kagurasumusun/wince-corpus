Tool Tips

A tool tip is a tiny rectangular pop-up window that displays a brief description of a command bar button's purpose when the user holds the stylus on the button for more than .5 second. If the user lifts the stylus from the screen while it's still positioned over the button, the button is activated. If the user moves the stylus away from the button before raising the stylus from the screen, the button isn't activated.

Windows CE only supports tool tip functionality for Command Bar buttons. Windows CE doesn't support tool tips for the menus or combo boxes in a command bar, and doesn't support tool tip controls outside of the command bar. To add tool tips to a command bar, use the CommandBar_AddTooltips function.

The CommandBar_AddtoolTips function doesn't make a copy of the array of tool tip strings you pass it. It directly uses the memory address you pass to it in the lpToolTips parameter. Don't release the memory allocated for this array until the program exits.

Tool tips usually only display the name of a button's command, but they can also display the command's shortcut key. For more information about shortcut keys, see Keyboard Accelerators.

For guidelines on tool tip design for command bars, see Designing Command Bars.
