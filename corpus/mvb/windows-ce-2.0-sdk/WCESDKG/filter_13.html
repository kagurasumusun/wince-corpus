File Filter Interfaces

Following is a summary of the ICeCeFileFilterSite interface and methods that are implemented by the Windows CE Services.

Method Description
ICeFileFilterSite Interface that is implemented by the Windows CE Services.
ICeFileFilterSite::QueryInterface Defined by the Component Object Module (COM).
ICeFileFilterSite::AddRef Defined by COM.
ICeFileFilterSite::Release Defined by COM.
ICeFileFilterSite::OpenSourceFile Called by a file filter to open a source file.
ICeFileFilterSite::OpenDestinationFile Called by a file filter to open a destination file.
ICeFileFilterSite::CloseSourceFile Called by a file filter to close a source file.
ICeFileFilterSite::CloseDestinationFile Called by a file filter to close a destination file.
ICeFileFilterSite::ReportProgress Called by a file filter to report the progress of a file conversion.
ICeFileFilterSite::ReportLoss Called by a file filter to report any information that it intentionally discarded during a file conversion.

Following is a summary of the ICeFileFilter interface and methods that are implemented by a vendor-supplied file converter DLL.

Method Description
ICeFileFilter Interface that is implemented by a file converter DLL.
ICeFileFilter::QueryInterface Defined by the Component Object Model (COM). (See the IUnknown interface).
ICeFileFilter::AddRef Defined by COM. (See the IUnknown interface).
ICeFileFilter::Release Defined by COM. (See the IUnknown interface).
ICeFileFilter::NextConvertFile Called by Windows CE Services when the user imports a file to the target device or exports a file to the desktop PC. This method is called repeatedly until the filter DLL indicates that the file conversion is complete.
ICeFileFilter::FilterOptions Called by Windows CE Services to display a dialog box that lets the user select among the file filtering options supported by a file filter.
ICeFileFilter::FormatMessage Called by Windows CE Services to format a message string.

Method Description
ICeFileFilterOptions::QueryInterface defined by the Component Object Module (COM)
ICeFileFilterOptions::AddRef defined by the COM
ICeFileFilterOptions::Release defined by the COM
