Registry-Based Notification

In registry-based notification, a command line is placed in the system registry. This method is appropriate when it is only necessary to execute the command line for an application at the time the mobile device connects or disconnects.

Two registry keys are used in this method¾AutoStartOnConnect and AutoStartOnDisconnect¾which are located under HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services. When the mobile device is docked, the Windows CE Services connection manager executes the command line under AutoStartOnConnect.. Likewise, when the mobile device is undocked, the command line under AutoStartOnDisconnect is executed.

To Register an Application for Automatic Execution
  1. Under the AutoStartOnConnect and/or AutoStartOnDisconnect subkeys, register a named value that uniquely identifies the application to be started upon connection or disconnection between the desktop PC and the mobile device. The named value should include a company and product name (for example, MicrosoftHPCExplorerAutoConnect).

  2. Define the named value as the application (including command line arguments) that is to be executed.
The following registry initialization (.Reg) file gives an example of registering command lines. When the mobile device is connected, Notepad.exe is opened with a command line argument of c:\config.sys. When the mobile device is disconnected, it is opened with a command line argument of c:\autoexec.bat.
REGEDIT4
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\AutoStartOnConnect]
"MicrosoftAutoConnectSample"="notepad c:\\config.sys"
[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows CE Services\AutoStartOnDisconnect]
"MicrosoftAutoDisconnectSample"="notepad c:\\autoexec.bat"
