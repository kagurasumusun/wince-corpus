User Input Devices

A user interacts with objects on the H/PC interface using different types of input devices. The H/PC v2.0 supports both a keyboard and a stylus/touch screen device. It does not support a mouse, and therefore, does not have hover capability.

The H/PC keyboard layout resembles a standard PC keyboard. Because of size considerations, however, hardware platforms are not required to support all the keys a standard keyboard supports. Most H/PC keyboard devices do not provide the following keys:

DELETE
INSERT
NUM LOCK
PAUSE
PRINT SCRN
SCROLL LOCK
FUNCTION KEYS

Users can use the SHIFT+Backspace as a substitute for the DELETE key.

The H/PC supports the Windows key, but Microsoft does not require hardware platforms to include it. Therefore, avoid writing applications that require users to use keys that may not be supported.

The conventions for stylus interaction are generally the same as the conventions that apply to mouse input or pen input.

When the user presses the stylus to the screen, the input focus moves to the object under the stylus. If the object is a button, it displays its pressed appearance. If the user moves the stylus off the control without lifting the stylus from the screen, the control returns to its original state. Moving the stylus back over the control while the stylus is still touching the screen returns the control to its pressed state. The command associated with the control is only activated if the user lifts the stylus from the screen while the stylus is over the control. If the stylus is not over the control when the user lifts it, no action occurs. If the user presses the stylus to the screen over an object that can be dragged, and then moves the stylus while still touching the screen, the object moves with the stylus.

There is no built-in equivalent on the H/PC for a right button mouse-click, but Windows CE supports an ALT+Tap convention instead. When a user presses the ALT key while tapping the stylus on the screen, you should handle this action the same way you would handle a right-click mouse event.

The H/PC conventions for supporting selection using a stylus are the same as the standard Windows conventions for selection using a pen or mouse. The H/PC supports standard drag-and-drop operations using the stylus. It does not support non-default drag-and-drop operations, however, which are the right mouse button drag-and-drop operations on desktop platforms.

The H/PC does not currently provide handwriting recognition functionality. However, it does support 3rd party handwriting recognition applications. If you support this functionality in your applications, see The Windows Interface Guidelines for Software Design for implementation conventions.
