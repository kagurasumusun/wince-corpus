Clipboard Messages

The following clipboard messages are the same in Windows CE as they are in Windows 95 and Windows NT.

WM_CLEAR

WM_COPY

WM_CUT

WM_DESTROYCLIPBOARD

WM_PASTE

WM_RENDERALLFORMATS

WM_RENDERFORMAT

WM_UNDO

Because Windows CE doesn't support clipboard viewers or private clipboard formats, it doesn't support the WM_CHANGECBCHAIN, WM_DRAWCLIPBOARD, WM_HSCROLLCLIPBOARD, WM_PAINTCLIPBOARD, WM_SIZECLIPBOARD, or WM_VSCROLLCLIPBOARD messages. It also doesn't support the WM_ASKCBFORMATNAME message.
