List View Messages

Windows CE supports most of the same messages for list views that Windows 95 and Windows NT support.

Windows CE supports a new value for the iImageList parameter (WPARAM) of the LVM_GETIMAGELIST and LVM_SETIMAGELIST messages. The LVSIL_HEADER value specifies that the image list you're setting or retrieving is the list of images displayed in the list view's header control in report view.

Use the LVM_SETEXTENDEDLISTVIEWSTYLE and LVM_GETEXTENDEDLISTVIEWSTYLE messages to set and retrieve extended list view styles. For descriptions of these styles, see Extended List View Styles.

Windows CE doesn't support hot tracking, hover selection, or background images for list views, so it doesn't support the new LVM_GETBKIMAGE, LVM_GETHOTCURSORLVM,_GETHOTITEM, LVM_GETHOVERTIME, LVM_SETBKIMAGE, LVM_SETHOTCURSOR, LVM_SETHOTITEM, LVM_SETHOVERTIME messages.
