Scroll Bar Macros

You can use the following message cracker macros to send scroll bar messages. These macros pack their parameters into the appropriate wParam/lParam format and then call SendMessage. For more information, refer to the macro definitions in Windowsx.h and the documentation for the corresponding button message. See Scroll Bar Messages.

ScrollBar_Enable(hwndCtl, flags) (corresponds to the EnableWindow function)

ScrollBar_GetPos(hwndCtl) ScrollBar_GetRange(hwndCtl, lpposMin, lpposMax) ScrollBar_SetPos(hwndCtl, pos, fRedraw) ScrollBar_SetRange(hwndCtl, posMin, posMax, fRedraw)

ScrollBar_Show(hwndCtl, fShow) (corresponds to the ShowWindow function)
