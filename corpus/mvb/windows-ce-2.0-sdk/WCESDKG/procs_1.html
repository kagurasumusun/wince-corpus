Working with Processes and Threads

When you start a Windows application, the operating system automatically creates a process and a primary thread for that process. Additional threads are created by calling the CreateThread function. The ExitThread function is called to free up the resources used by a thread when it is no longer needed. Calling Exit Thread for an application's primary thread causes the application to terminate.

Windows CE creates a stack for each thread. Each stack has an initial size of at least 1K (the stack size is CPU dependent; the system allocates 4K for each stack on some devices). Consequently, the maximum number of threads is dependent upon the amount of available memory.

In addition to its own stack, a message queue is created for a thread when it uses one of the messaging functions.

Note Unlike processes on Windows desktop platforms, a Windows CE process will terminate if its primary thread is terminated, even if there are other active threads in existence for the process.

Windows CE supports the following functions for manipulating processes.

Function Description
CreateProcess Creates a process with a primary thread and executes a program.
GetCurrentProcess Returns a pseudohandle to the current process object.
GetCurrentProcessId Returns the process identifier to the current process object.
TerminateProcess Terminates the process.

Windows CE supports the following functions for manipulating threads.

Function Description
CreateThread Creates a new thread of execution in the current address space.
ExitThread Ends a thread's execution. When this function is called by the primary thread the application exits.
GetCurrentThread Returns a pseudohandle to the current thread.
GetCurrentThreadId Returns the thread identifier of the calling thread.
GetExitCodeThread Retrieves the termination status of a specified thread.
GetThreadPriority Retrieves the priority level of a specified thread.
ResumeThread Checks the thread's suspend count. If the count is zero then the thread is not suspended. If the count is greater than zero then it decrements the count. When the count reaches zero the thread execution is continued.
SetThreadPriority Sets the priority of a specified thread.
SuspendThread Suspends execution of the code and increments the thread's suspend count.
Sleep Suspends execution of a thread for a specified interval of time.

For an overview of processes and threads, see Architectural Overview of the Windows CE Operating System.
