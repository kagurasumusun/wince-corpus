User Notifications

The CeSetUserNotification function is used to register a user notification. It specifies the time when the notification should occur, the way the notification appears to the user (e.g. a flashing LED or a sound), and the name of the associated application.

At the specified time, the system places the primary icon of the application into the taskbar. If the specified time has already passed, the system immediately places the icon in the taskbar. An icon placed into the taskbar is called a taskbar annunciator. The taskbar can contain multiple annunciator icons at the same time if they are for different applications. But only one icon for a given application will be displayed at any time.

When the user taps the annunciator icon, the system starts a new instance of the corresponding application. It also passes a command line parameter that tells the application why it is being started. If an instance of the application is already running, the new instance should use an application-defined message to send the notification to the previous instance. The new instance should then shut down.

User notifications exist in either a registered or an active state. The notification is registered from the time you call CeSetUserNotification until the time the user is notified. The notification is active from the time the user is notified until the event is handled.

The user can be notified of an event in one of the following ways, when supported on a device:

  • Playing a .wav file.

    The user can choose a specific sound for each notification.The user can override sound notifications using the Volume/Sounds setup from the Control Panel.

  • Flashing the light-emitting diode (LED).

    When a notification causes the LED to flash, the flashing continues until the user handles the notification. If multiple notifications cause the LED to flash, the flashing stops only when all notifications are handled.

  • Displaying a dialog box.

    A notification dialog box contains an application-defined title, application-defined text, an OK button, and a Snooze button. If the user clicks the OK button, the notification is handled. Clicking the Snooze button does not handle the notification. When the user clicks Snooze, the dialog box is redisplayed after five minutes.

  • Vibrating the Windows CE device.

The actions that the system performs for a particular notification should be based on preferences selected by the user. A user's preferences are obtained by calling CeGetUserNotificationPreferences. CeGetUserNotificationPreferences displays a dialog box containing the options available on the particular Windows CE device (this will vary by manufacturer). The user's responses are used to fill a CE_USER_NOTIFICATION structure. The structure's address is specified in the call to CeSetUserNotification which makes the user's preferences available to the system.

CeSetUserNotification is used not only for creating a new user notification but also for modifying an existing notification.
