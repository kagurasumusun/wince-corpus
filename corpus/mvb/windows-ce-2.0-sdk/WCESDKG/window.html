The Windowing Environment

The windowing environment allows you to create and manage an application's user interface. In Windows CE, as in Windows desktop platforms, you use windows, rather than the screen itself, as the primary output device. The operating system manages all direct output to the screen.

Since many Windows CE-based platforms are portable, with small displays or no screen at all, many of the windowing features of a desktop operating system do not apply. Whether or not a window is visible, an application must have one to receive messages from the operating system. Therefore, even if your target device has no display, you need to create and manage windows.
