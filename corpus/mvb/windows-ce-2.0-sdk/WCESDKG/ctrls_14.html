Edit Control Macros

You can use the following message cracker macros to send edit control messages. These macros pack their parameters into the appropriate wParam/lParam format and then call SendMessage. For more information, refer to the macro definitions in Windowsx.h and the documentation for the corresponding edit control message. See Edit Control Messages.

Edit_CanUndo(hwndCtl) Edit_EmptyUndoBuffer(hwndCtl)

Edit_Enable(hwnd, fEnable) (corresponds to the EnableWindow function)

Edit_FmtLines(hwndCtl, fAddEOL) Edit_GetFirstVisibleLine(hwndCtl) Edit_GetLine(hwndCtl, line, lpch, cchMax) Edit_GetLineCount(hwndCtl) Edit_GetModify(hwndCtl) Edit_GetPasswordChar(hwndCtl) Edit_GetRect(hwndCtl, lprc) Edit_GetSel(hwndCtl)

Edit_GetText(hwndCtl, lpch, cchMax) (corresponds to the GetWindowText function)

Edit_GetTextLength(hwndCtl) (corresponds to the GetWindowTextLength function)

Edit_LimitText(hwndCtl, cchMax) Edit_LineFromChar(hwndCtl, ich) Edit_LineIndex(hwndCtl, line) Edit_LineLength(hwndCtl, line) Edit_ReplaceSel(hwndCtl, lpszReplace)

Edit_Scroll(hwndCtl, dv, dh) (corresponds to EM_LINESCROLL)

Edit_ScrollCaret(hwndCtl) Edit_SetModify(hwndCtl, fModified) Edit_SetPasswordChar(hwndCtl, ch) Edit_SetReadOnly(hwndCtl, fReadOnly) Edit_SetRect(hwndCtl, lprc)

Edit_SetRectNoPaint(hwndCtl, lprc) (corresponds to EM_SETRECTNP)

Edit_SetSel(hwndCtl, ichStart, ichEnd) Edit_SetTabStops(hwndCtl, cTabs, lpTabs)

Edit_SetText(hwndCtl, lpsz) (corresponds to the SetWindowText function)

Edit_Undo(hwndCtl)

Windows CE doesn't support the Edit_GetHandle, Edit_SetHandle, Edit_GetWordBreakProc, or Edit_SetWordBreakProc macros.
