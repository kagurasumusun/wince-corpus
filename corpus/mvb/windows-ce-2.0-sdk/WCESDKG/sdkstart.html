Welcome to Windows CE!


The Windows CE Version 2.0 Platform SDK contains all the tools you need to develop great applications for platforms that run Windows CE.


This SDK includes new API functions and interfaces for Windows CE version 2.0, including: Support for selected COM and ActiveX interfaces and support for color displays.


The Windows CE documentation is HTML-based. You can start reading now by clicking on one of the categories you see at the right. Or you can use the InfoViewer Contents pane for a hierarchical view of the Table of Contents.


For the latest information about developing for Windows CE, visit the Microsoft Windows CE World Wide Web site, http://www.microsoft.com/ windowsce/developer.
