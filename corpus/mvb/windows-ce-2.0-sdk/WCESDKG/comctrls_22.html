Image Lists

An image list is a collection of images that are all the same size, such as bitmaps or icons. You can create the images in a single, wide bitmap or as individual bitmaps that you add to the list one at a time. Image lists manage images but don't display them directly. They're designed to be used with list view and tree view controls.

You create an image list by calling the ImageList_Create function.

The INDEXTOOVERLAYMASK macro is the same in Windows CE as it is in Windows 95 and Windows NT.
