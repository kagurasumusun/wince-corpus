Message Header

The message header (pwcHeaders) normally contains information such as the name and address of the sender and receiver of the message. It consists of one or more entries, each of which containing two fields: name, and value. Both fields are Unicode strings that can be read with MailGetField and modified with MailSetField.

For example a message header might contain the following entries.

Name Field Value Field
To john@street.com
From frank@hill.com
cc bob@river.com
Subject The way it was, is and will be

When creating a message header string, the Name and Value strings are each terminated by a NULL character. The final Value field is terminated by two NULL characters to indicate the end of the header.

For the most part, the strings assigned to the Name fields have no special meaning to the system unless it is "Type". In this case, the system checks the corresponding value field to see if it matches the name of a dynamic-link library registered with the system. The body of the message is passed to thus matched DLL for processing.
