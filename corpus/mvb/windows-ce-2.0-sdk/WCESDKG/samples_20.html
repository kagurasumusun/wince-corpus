HTMLview Sample

The Htmlview sample allows the user to browse and open hypertext markup language files, including the help (.htp) files supplied with Windows CE. This sample code demonstrates the notifications and structures defined in Htmlctrl.h.

To build the HTMLview sample
  • Follow the procedure described in Building the Sample Applications, selecting one of the valid project configurations in the table below.
    Source code location Build target options
    Wce\Samples\Win32\HTMLview Desktop PC Windows CE emulation

    Windows CE platform (MIPS or SH)
