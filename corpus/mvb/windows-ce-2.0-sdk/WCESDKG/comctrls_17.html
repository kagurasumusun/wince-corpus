Header Control Messages

The following header control messages are the same in Windows CE as they are in Windows 95 and Windows NT. You can use macros to send most of these messages. See Header Control Macros.

HDM_DELETEITEM

HDM_GETITEM

HDM_GETITEMCOUNT

HDM_HITTEST

HDM_INSERTITEM

HDM_LAYOUT

HDM_SETITEM

WM_NOTIFY

Windows CE also provides the following new header control messages to support the use of image lists, drag and drop functionality, and custom ordering of header control items. For an overview of how to use these new messages, see New Features for Header Controls.
HDM_CREATEDRAGIMAGE

HDM_GETIMAGELIST

HDM_GETITEMRECT

HDM_GETORDERARRAY

HDM_ORDERTOINDEX

HDM_SETHOTDIVIDER

HDM_SETIMAGELIST

HDM_SETITEM

HDM_SETORDERARRAY
