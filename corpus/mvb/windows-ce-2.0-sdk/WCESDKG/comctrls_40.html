Month Calendar Structures and Data Types

Windows CE supports the following month calendar structures.

MCHITTESTINFO

NMDAYSTATE

NMSELCHANGE

Windows CE supports a new data type for month calendar controls, called MONTHDAYSTATE, which is a bit field in which bits 1 though 31 represent days in a month. This data type is used with the MCM_SETDAYSTATE and MCN_GETDAYSTATE notification messages.

For more information on supporting day states, see Day States, MONTHDAYSTATE Data Type, Processing the MCN_GETDAYSTATE Notification Message and Preparing the MONTHDAYSTATE Array.
