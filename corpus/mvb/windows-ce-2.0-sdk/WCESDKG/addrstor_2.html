Opening the Contacts Database

To open the Contacts database

1. Call the OpenAddressBookfunction.

If successful, you can proceed to access the database.

1. If the call fails, obtain specific error information by calling GetLastError. If the error value is ERROR_FILE_NOT_FOUND, the Contacts database does not exist.

2. If the database does not exist, create the database by invoking the CreateAddressBookfunction before re-opening it. 3. Specify up to four property tags for the hhSortProp parameter - Or -

Set the hhSortProp parameter to NULL to use the default properties: surname, company name, office telephone number, and home telephone number. The OpenAddressBook function then uses the sort property array to specify the current sort order.Call CloseAddressBook to close the Contacts database.

The following example illustrates this procedure:
// make sure the Contacts database exists and can be opened.
If(!OpenAddressBook(hwndParent, hhSortProp)) {
     dwError=GetLastError();
     if(dwError==ERROR_FILE_NOT_FOUND) {
          if(!CreateAddressBook(NULL, 0))
                return FALSE;
          if(!OpenAddressBook(hwndParent, hhSortProp))
                return FALSE;
          // the Contacts database is now opened and ready for use.
          
     }
     
Calling OpenAddressBook to open an existing Contacts database can fail if the hhSortProp array has been altered by another thread. In this case, GetLastError will return ERROR_INVALID_PARAMETER. Multiple applications can open the Contacts database simultaneously. To coordinate data access and preserve data integrity, the operating system sends object-store notification messages to attached applications whenever the database has been modified. The OpenAddressBook function specifies the window handle, hwndParent, to receive such notification messages which have the DB_PEGOID_ prefix and are defined in the Windbase.h header file. Upon receiving a notification message, call the RecountCardsfunction to re-enumerate the number of records in the database.

The following sample code illustrates how to open the Contacts database. When OpenAddressBook fails because the database does not exist, the example creates the database. When the creation is successful, the example then tries to open the database again. The GetPropertyDataStruct function examines address card properties to ensure that the database has not been corrupted. The example returns TRUE if the database was successfully opened or FALSE otherwise: 

// OpenUpTheAddressBook - Opens the Contacts database, creating it 
// if it doesn't exist. Returns TRUE if successful or FALSE otherwise.
// hwndParent - handle of the parent window that is to receive database 
// notifications (DB_PEGOID_*).
// hhSortProp - property tag for setting the sort order.
BOOL OpenUpTheAddressBook(HWND hwndParent, HHPRTAG hhSortProp)
{
    DWORD dwError;                   // Error code
    HHPRTAG propList[MAX_COLUMNS];   // Sort-order property tags
    int nColumns;                    // Number of sortable columns 
    int index;                       // Loop index

    // Attempt to open the Contacts database.
    if (!OpenAddressBook(hwndParent, hhSortProp)) {
        dwError = GetLastError();
        if (dwError == ERROR_FILE_NOT_FOUND) {

            // The Contacts database doesn't exist, so try to create 
            // it.  Use the default sort order properties.
            if (!CreateAddressBook(NULL, 0)) {
                goto InitError;
            }
   
            // The Contacts database was created, now try 
            // again to open it.
            if (!OpenAddressBook(hwndParent, hhSortProp)) {
                goto InitError;
            }

        // Check for an invalid parameter error. 
        } else if (dwError == ERROR_INVALID_PARAMETER) {
            // Another application may have changed the sort orders. 
            // Try opening the database without specifying a 
            // sort order. 
            if (!OpenAddressBook(hwndParent, 0)) {
                goto InitError;
            }

            // Retrieve the column properties.
            nColumns = MAX_COLUMNS;
            if (!GetColumnProperties(&propList, &nColumns)) {
                goto InitError;
            }

            // Make sure the properties are valid.
            for (index = 0; index < nColumns; index++) {
                if (GetPropertyDataStruct(GPDS_PROPERTY, 
                        propList[index], NULL) == GPDS_ERR) {
                    // The database is corrupt.
                    MessageBox(hwndParent, IDS_CORRUPT_DATABASE, 
                        MB_ICONEXCLAMATION | MB_OK);
                    goto InitError;
                }
            }

            // Try opening the database one last time.
            hhSortProp = propList[0];
            if (!OpenAddressBook(hwndParent, hhSortProp)) {
                goto InitError;
            }
        } else {
            goto InitError;
        }
    }
        return TRUE;

    InitError:
        return FALSE;
}
