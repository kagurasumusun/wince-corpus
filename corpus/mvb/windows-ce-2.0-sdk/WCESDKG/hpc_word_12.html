Pictures

Microsoft Pocket Word 2.0 can support pictures defined as device-independent bitmaps or device-dependant bitmaps.

Token Description
bin Binary data
dibitmap Device independent bitmap
pich Height
pichgoal Goal height
picscalex Scale horizontal
picscaley Scale vertical
pict Picture
picw Width
picwgoal Goal width
wbitmap Bitmap
wbmbitspixel Bitmap bits per pixel
wbmplanes Bitmap planes
wbmwidthbytes Bitmap bytes per row
