Using the TTY Sample

To run the TTY sample
  1. On the desktop PC, start HyperTerminal and select a communications port that will be connected to a built-in serial device on the H/PC. Note that applications such as H/PC Explorer or the remote tools cannot be run while running the TTY sample.

  2. On the H/PC, tap Start, then tap Run, then enter tty.

  3. From the TTY menu, tap Settings to display the Communications dialog box.

    Select a Baud Rate that matches the HyperTerminal port settings.

  4. Type on the desktop keyboard and verify the keyboard inputs appear on the H/PC TTY window. Type on the H/PC keyboard and verify the keyboard inputs appear on the desktop HyperTerminal window.

    The following table describes the Tty.exe functions with respect to the Flow control options provided in the Communications dialog box.

    Flow control Description
    None If the RTS check box is checked, each character is received by the H/PC's serial port and displayed in the TTY buffer window. If the RTS check box is unchecked, the received characters are queued in the serial port's buffer and are displayed in the TTY window after the RTS check box is again checked.
    RTS/CTS Checking or unchecking DTS or RTS check boxes does not affect communication - each character is displayed as it is received.
    XON/XOFF Same as for XON/XOFF flow control.

  5. To clear the TTY display, tap the Edit menu and select Clear Buffer.
