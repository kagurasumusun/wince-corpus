Handling Recurring Events

You must register a separate notification for each instance of a recurring timer event. Typically, an application sets all of the instances for a specified period of time upon startup. To handle cases where the specified time period elapses without the user running the application, a CeRunAppAtTime function can be registered to run the application and register all notifications for the next time period.

Notification functions and structure

Windows CE supports the following notification functions and structure:

CeClearUserNotification deletes a registered user notification.
CeGetUserNotificationPreferences creates a new user notification or modifies an existing one.
CeHandleAppNotifications marks as "handled" all active notifications for the given application.
CeRunAppAtEvent starts an application when a given event occurs.
CeRunAppAtTime prompts the system to start an application at a given time.
CeSetUserNotification queries the user for notification settings.
CE_USER_NOTIFICATION stores information describing what happens when the notification time is reached.
