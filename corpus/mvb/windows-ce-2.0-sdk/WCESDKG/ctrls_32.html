Scroll Bars

A scroll-bar is a rectangle that contains a scroll box (or thumb) and has direction arrows at both ends. When a user taps one of the arrows with the stylus, the visible area of the scroll bar's parent window scrolls one line in the direction of the arrow. When a user taps the stylus in the shaft of the scroll bar, above or below the scroll box, the page scrolls up or down by one screen. The user can also drag the scroll box to scroll to a particular place in the document. The size of the scroll box, in relation to the shaft, is proportional to the percentage of the document that's displayed on the screen.

The SCROLLINFO structure is the same in Windows CE as it is in Windows 95 and Windows NT.
