TTY Sample

The TTY sample application is an example of porting the Win32 TTY sample to the Windows CE environment. This sample runs only on the H/PC. The terminal emulation can be monitored on the desktop PC using a terminal application such as HyperTerminal. The TTY sample demonstrates the Serial Communication API.

To build the TTY sample
  • Follow the procedure described in Building the Sample Applications, selecting one of the valid project configurations in the table below.
    Source code location Build target options
    Wce\Samples\Win32\Tty Windows CE platform
