Property Sheet Structures

The PSHNOTIFY structure is the same as it is in Windows 95 and Windows NT.

Windows CE doesn't support icons in the caption (title) of a property sheet, so you can't specify PSH_USEHICON or PSH_USEICONID in the dwFlags field of the PROPSHEETHEADER structure. Windows CE doesn't support wizards so you can't specify PSH_WIZARD in this field either.

Because Windows CE doesn't support icons in property page captions, you can't specify the PSP_USEHICON or PSP_USEICONID flags in the dwFlags field of the PROPSHEETPAGE structure, and the hIcon and pszIcon fields aren't used. Enter zero in these two fields.

Windows CE supports a new flag you can specify in the dwFlags field of the PROPSHEETPAGE structure, called PSP_PREMATURE. Setting this flag causes the page to be created when the property sheet is created. If this flag isn't specified, the page isn't created until the first time it's selected.
