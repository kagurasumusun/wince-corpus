Check Box Styles

Windows CE supports most of the check box styles Windows 95 and Windows NT do, but it doesn't support the BS_LEFTTEXT style. You can achieve the same effect (placing the check box to the right of the associated text) by using the BS_RIGHTBUTTON style.

The following check box styles are the same in Windows CE as they are in Windows 95 and Windows NT.

Style Description
BS_3STATE Creates a check box in which the box can be grayed as well as checked or unchecked. Use the grayed state to show that the state of the check box is not determined.
BS_AUTO3STATE Creates a three-state check box in which the state cycles through checked, grayed, and unchecked each time the user selects the check box.
BS_AUTOCHECKBOX Creates a check box in which the check state automatically toggles between checked and unchecked each time the user selects the check box.
BS_CHECKBOX Creates a small, empty check box with a label displayed to the right of it. To display the text to the left of the check box, combine this flag with the BS_RIGHTBUTTON style.
BS_LEFT Left-aligns the text in the button rectangle on the right side of the check box.
BS_RIGHT Right-aligns text in the button rectangle on the right side of the check box.
BS_RIGHTBUTTON Positions a check box's square on the right side of the button rectangle.
WS_TABSTOP In a dialog box, any control with this style will be a tab stop when a user tabs through the controls.

Windows CE doesn't support the BS_PUSHLIKE style.
