Accessing Persistent Storage

The persistent storage that Windows CE makes available to applications is called the object store. The object store is used for files, registry entries and Windows CE databases.

Each object in the object store¾whether a directory, file, database, or database record¾is associated with a unique object identifier. The object identifier is normally used for dealing with databases and their records. However, it can be used to obtain information on any object.

Object type Where to obtain the object identifier
directory or file dwOID field of WIN32_FIND_DATAW from FindFirstFile or FindNextFile

dwOID field of BY_HANDLE_FILE_INFORMATION from GetFileInformationByHandle
database return value of CeCreateDatabase or CeFindNextDatabase.
database record return value of CeSeekDatabase, CeReadRecordProps, or CeWriteRecordProps.

To get information about an object in the object store, a Windows CE application calls the API function CeOidGetInfo and supplies the object identifier in the parameter of type CEOID. CeOidGetInfo returns the object data in a CEOIDINFO structure. This structure's wObjType field contains a flag that indicates the object type. The data in the structure depends on the type of object. For example, if the object is a database record, the CEOIDINFO structure wObjType field contains the flag OBJTYPE_RECORD, indicating that the data for the object consists of a CERECORDINFO structure. If there is no valid object for the object identifier the return value of CeOidGetInfo is FALSE.

The following sample fragment demonstrates how to use the object identifier to obtain the object type of any object in the object store. 

// sample fragment that demonstrates using the object identifier
CEOID WceObjID;  // object identifier
CEOIDINFO WceObjInfo;  // structure that contains info about the object
TCHAR szMsg[MAX_STRING];  // string to display with object info
... 
if (CeOidGetInfo(WceObjID, &WceObjInfo)) { 
    // TRUE return indicates valid data
    switch (WceObjInfo.wObjType) {
        case OBJTYPE_FILE:
            wsprintf(szMsg, TEXT("Object is a file: %s"), 
                            WceObjInfo.infFile.szFileName); 
            break;
        case OBJTYPE_RECORD:
            wsprintf(szMsg, TEXT("Object is a record"));
                            // can use WceObjInfo.infRecord.oidParent 
            break;
        case OBJTYPE_DATABASE: 
            wsprintf(szMsg, TEXT("Object is a database: %s"), 
                            WceObjInfo.infDatabase.szDbaseName); 
            break;
        case OBJTYPE_DIRECTORY: 
            wsprintf(szMsg, TEXT("Object is a directory: %s"), 
                            WceObjInfo.infDirectory.szDirName); 
            break;
        default:
            // handle error ...
            break;
     } // end case
} // end if CeOidGetInfo succeeds
// display the string
