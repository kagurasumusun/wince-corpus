H

H/PC

Acronym for Handheld PC.

heap

A portion of memory reserved for a program to use for the temporary storage of data structures whose existence or size cannot be determined until the program is running. The program can request free memory from the heap to hold such elements, use it as necessary, and later free the memory.

hook

A hook is a point in the Windows message-handling mechanism where an application can install a subroutine to monitor the message traffic in the system and process certain types of messages before they reach the target window procedure. Windows CE does not support hooking.

HTML

Hypertext Markup Language: A markup language derived from SGML. Used to create a text document with formatting specifications that tells a software browser how to display the page or pages included in the document.
