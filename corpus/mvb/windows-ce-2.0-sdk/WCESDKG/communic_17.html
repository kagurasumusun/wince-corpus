Network Security Features

Windows CE supports the Secure Sockets Layer (SSL) versions 2.0 and 3.0, and PCT1.0 security protocols. These protocols are available either through the WinINET API, or by going directly to Winsock.

The simplest approach to using the security protocols is the WinINET API.

To access security protocols with WinINET

  1. Connect with InternetConnect, using the INTERNET_FLAG_SECURE flag.

  2. For HTTP, invoke HttpOpenRequest, with the desired security flags set (INTERNET_FLAG_SECURE, in particular).

  3. Proceed with the remainder of the session as usual.

Security protocols can also be accessed directly via Winsock. The details are specified by calls to WSAIoctl. There are several WSAIoctl control codes that have been defined for use with security protocols (see the reference documentation for a complete description):

Control Code Description
SO_SSL_GET_CAPABILITIES Retrieve a set of flags describing the WinSock security provider's capabilities.
SO_SSL_GET_CONNECTION_INFO Get cryptographic information about a current connection
SO_SSL_GET_FLAGS Retrieve the socket's current flag values.
SO_SSL_GET_PROTOCOLS Retrieve a list of protocols that the provider currently supports on this socket.
SO_SSL_PERFORM_HANDSHAKE Initiate a secure handshake
SO_SSL_SET_FLAGS Set the socket's current flag values
SO_SSL_SET_PROTOCOLS Specify a list of protocols the provider is to support on the socket
SO_SSL_SET_VALIDATE_CERT_HOOK Set the pointer to the socket's certificate validation hook.
