Serial Communications

Serial is I/O is the simplest form of communication supported by Windows CE. It is used when there is a direct one-to-one connection between two devices. It can take place over a variety of hardware connections, but most Windows CE devices will probably use simple serial cable links or infrared transceivers.

Transferring information over a simple serial cable connection is similar to reading from or writing to a file, and uses some of the same functions. There are also a number of functions that can be used to manage the connection. They can be used to open, close, and manipulate COM ports, and read from and write to them.

Direct serial I/O over an infrared link is available using the usual serial communication functions. The I/O will be "raw" which means, for instance, that there will be no collision detection.

More robust serial IR communication utilizing the IrDA protocols is available through IrSock (an extension of WinSock). As an alternative to using IrSock directly, IrComm uses essentially the same function calls as ordinary serial communication but uses IrSock and the IrDA protocols internally.

See the "Windows CE Communications" chapter for a more complete discussion of serial communications.
