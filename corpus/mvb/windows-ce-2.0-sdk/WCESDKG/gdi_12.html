Regions

In Windows CE, a region is a rectangle that can be filled, painted, inverted, framed, and tested to see if it contains a cursor.

You create a region by calling CreateRectRgn or CreateRectRgnIndirect. These functions return a handle identifying the new region. Once you have a handle to a region, you can select the region into a device context with the SelectObject function. You can perform a variety of operations on a region You can combine or compare it with another region, paint or invert its interior, draw a frame around it, retrieve its dimensions, and test whether or not the cursor lies within it.

Note When using the CreateRectRgn and CreateRectRgnIndirect functions,use values for regions that can be represented by 16-bit integers since that is how region data is stored in Windows CE.

You can use the CombineRgn function to combines two regions together in one of five following ways.

Value Meaning
RGN_AND The intersecting parts of two original regions define a new region.
RGN_COPY A copy of the first (of the two original regions) defines a new region.
RGN_DIFF The part of the first region that does not intersect the second defines a new region.
RGN_OR The two original regions define a new region.
RGN_XOR Those parts of the two original regions that do not overlap define a new region.

You can use the EqualRgn function to determine whether or not two regions are equal in size and shape. You can use the the FillRgn function to paint the interior of a region with a specified brush.

To invert the colors within a region, call the InvertRgn function. On monochrome displays, InvertRgn makes white pixels black and black pixels white. On color screens, the effects of InvertRgn depend on the technology used to generate the screen colors.

You can retrieve the dimensions of a region's bounding rectangle by calling the GetRgnBox function. (The bounding rectangle is the smallest rectangle that be drawn around a region Use the OffsetRgn function to move a region a specified number of logical units. Use GetRegionData to retrieve data describing a region.

Note Since Windows CE represents regions differently than Windows desktop platforms, GetRegionData function may return a greater number of rectangles for a given region than the equivalent Windows desktop function.

The PtInRegion function determines if a cursor is inside a specified rectangle. To use this function, you must pass it the location of the cursour (which can be retrived by processing mouse messages such as WM_LBUTTONDOWN or WM_LBUTTONUP) and then passing this location, along with a pointer to a rectangle, to PtInRegion.
