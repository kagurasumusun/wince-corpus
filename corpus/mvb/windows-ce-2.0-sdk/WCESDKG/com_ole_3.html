Type Libraries and Object Description Language

An ActiveX object makes use of type libraries to expose type information and object characteristics. Windows NT supports two types of type libraries, typelib1 and typelib2, which may be built as a resource in a DLL and an EXE file, or as standalone type libraries. In Windows CE, however, only the typelib2 type library is supported and it must be loaded from a resource. Windows CE will not load any binary foreign or standalone type libraries.
