Tab Control Styles

The following tab control styles have the same meanings in Windows CE as they have in Windows 95 and Windows NT.

Style Meaning
TCS_BUTTONS Displays tabs as buttons with no border drawn around the display area.
TCS_FIXEDWIDTH Specifies that all tabs are the same width. You can't combine this style with the TCS_RIGHTJUSTIFY style.
TCS_FOCUSNEVER Creates a tab control that never receives the input focus.
TCS_FOCUSONBUTTONDOWN Specifies that tabs receive the input focus when clicked.
TCS_FORCEICONLEFT Aligns icons with the left edge of each fixed-width tab. This style can only be used with the TCS_FIXEDWIDTH style.
TCS_FORCELABELLEFT Aligns labels with the left edge of each fixed-width tab; that is, it displays the label immediately to the right of the icon instead of centering it. This style can only be used with the TCS_FIXEDWIDTH style, and it implies the TCS_FORCEICONLEFT style.
TCS_MULTILINE Displays multiple rows of tabs, if necessary, so all tabs are visible at once.
TCS_OWNERDRAWFIXED Specifies that the parent window is responsible for drawing tabs.
TCS_RAGGEDRIGHT Does not stretch each row of tabs to fill the entire width of the control. This style is the default.
TCS_RIGHTJUSTIFY Increases the width of each tab, if necessary, so that each row of tabs fills the entire width of the tab control. This window style is ignored unless the TCS_MULTILINE style is also specified.
TCS_SINGLELINE Displays only one row of tabs. The user can scroll to see more tabs, if necessary. This style is the default.
TCS_TABS Displays tabs as tabs and draws a border around the display area. This style is the default.

Windows CE also supports the following new tab control styles.

Style Description
TCS_BOTTOM Displays the tabs at the bottom of the control. If the TCS_VERTICAL style is also specified, this style is interpreted as TCS_RIGHT.
TCS_FLATBUTTONS When a tab is selected, it appears to be indented while other tabs appear to be on the same plane as the background. This style only applies to tab controls that have the TCS_BUTTONS style.
TCS_FLIP Flips the tabs. If they were on top, applying this style places them on the bottom. If they were on the left, it places them on the right.
TCS_MULTISELECT Specifies that multiple tabs can be selected by holding down CTRL when clicking. This style only applies to tabs that have the TCS_BUTTONS style.
TCS_RIGHT Displays the tabs vertically on the right side of controls that use the TCS_VERTICAL style. If the TCS_VERTICAL style is not specified, this style is interpreted as TCS_BOTTOM.
TCS_SCROLLOPPOSITE Specifies that unused tabs scroll to the opposite side of the control when a new tab is selected.
TCS_VERTICAL Displays the tabs vertically on the left side of the control. This style is valid only when used with the TCS_MULTILINE style. To make tabs appear on the right side of the control, combine this style with the TCS_RIGHT style.

Because Windows CE doesn't support tool tips for any controls other than command bar buttons, it doesn't support the TCS_TOOLTIPS style.
