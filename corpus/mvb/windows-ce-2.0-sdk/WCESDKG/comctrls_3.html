Command Bands

The command bands control is a rebar control with a fixed band at the top that contains a toolbar that has a close (X) button and, optionally, a help (?) button and an OK button, in the upper right corner. By default, each band in the command bands control contains a command bar. You can override this, however, if you want a band to contain some other type of child window.

You create a command bands control by using the CommandBands_Create function.

Before creating the control, register the command bands control class using the InitCommonControlsEx function. Specify the ICC_COOL_CLASSES and ICC_BAR_CLASSES flags in the dwICC field of the INITCOMMONCONTROLSEX structure you pass in the lpInitCtrls parameter.

Command bands controls support the new custom draw service, which makes it easy to customize a command bands control's appearance. For information on the custom draw service, see The Custom Draw Service.
