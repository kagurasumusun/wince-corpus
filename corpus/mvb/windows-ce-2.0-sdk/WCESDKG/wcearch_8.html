Windows CE Communications

Windows CE supports a variety of communications hardware and data protocols. The following features are available for inclusion on a device:

  • Serial I/O support

  • Networking support including:
    • A subset of WinSock version 1.1, including Secure Sockets

    • TCP/IP and IRDA

    • NDIS for local area networking

    • PPP and SLIP for serial link and modem networking

    • Support for a Remote Access Server (RAS) client

    • ICMP ("Ping") support

    • Access to remote file systems.

    • Support for internet clients, including the HTTP and FTP protocols
  • A subset of the Win32 Telephony API (TAPI)

  • Infrared transceiver support
