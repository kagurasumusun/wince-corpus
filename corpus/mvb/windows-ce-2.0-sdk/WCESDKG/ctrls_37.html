Static Controls

A static control is a control used to display text, to draw frames or lines separating other controls, or to display icons. A static control doesn't accept user input, but it can notify its parent of stylus taps if it's created with SS_NOTIFY style.

Windows CE doesn't support owner-drawn static controls, so you can't specify ODT_STATIC in the CtlType field of the DRAWITEMSTRUCT structure.
