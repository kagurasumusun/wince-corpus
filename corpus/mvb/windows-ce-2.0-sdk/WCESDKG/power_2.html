Idle Mode

The computer switches from the on mode to idle mode when all processes are idle. Switching to the idle mode is transparent to the user and most applications¾peripheral modes do not change and the system continues to process interrupts (including the time slice interrupt).

Applications that retain control by using idle loops or using functions that do not let the operating system block operation prevent the operating system from switching the computer to the idle mode. All applications can contribute to power management by using functions that let the operating system block a return to the application (for example, GetMessage) rather than using functions that do not let the system block a return (for example, PeekMessage). Returning control to the operating system when possible lets the operating system determine when the system is inactive and it can select the most efficient operating state for the computer.
