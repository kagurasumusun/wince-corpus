Pregdmp Sample

The Pregdmp sample uses remote registry functions to dump the H/PC registry key

HKEY_LOCAL_MACHINE

to the console output. This sample uses the following Remote functions:
CeRapiInit

CeRapiUninit

CeRegEnumKeyEx

CeRegOpenKeyEx

CeRegEnumValue

CeRegCloseKey

To run the Pregdmp sample program
  • Enter

    pregdmp

    from the command line. This sample takes no parameters.
