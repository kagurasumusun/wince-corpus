Determining Available Network Resources

The WNet API includes a set of functions to enumerate the network resources that are available.

To create a network resource list

  1. Call WNetOpenEnum, which returns an enumeration handle used in step 2.

  2. Call the WNetEnumResource function to package the information about the resources in the form of an array of NETRESOURCE structures.

  3. Call the WNetOpenEnum function to enumerate a container's resources (a container is a network resource that contains other resources).

  4. Call the WNetCloseEnum function to close the enumeration handle.

To retrieve other network information

  • Call WNetGetConnection to retrieve the name of the network resource associated with a local device.

  • Call the WNetGetUser to retrieve the name of the user associated either with a local device connected to a network resource or with the name of a network.

  • To get error information, call GetLastError.
