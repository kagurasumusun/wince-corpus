Combo Box Macros

You can use the following macros to send combo box messages. These macros pack their parameters into the appropriate wParam/lParam format and then call SendMessage. For more information, refer to the macro definitions in Windowsx.h and the documentation for the corresponding combo box message. See Combo Box Messages.

ComboBox_AddItemData(hwndCtl, data) (corresponds to CB_ADDSTRING)

ComboBox_AddString(hwnd, lpsz) ComboBox_DeleteString(hwndCtl, index)

ComboBox_Enable(hwnd, fEnable) (corresponds to the EnableWindow function)

ComboBox_FindItemData(hwndCtl, indexStart, data) (corresponds to CB_FINDSTRING)

ComboBox_FindString(hwndCtl, indexStart, lpszFind) ComboBox_FindStringExact(hwndCtl, indexStart, lpszFind) ComboBox_GetCount(hwndCtl) ComboBox_GetCurSel(hwndCtl) ComboBox_GetDroppedControlRect(hwndCtl, lprc) ComboBox_GetDroppedState(hwndCtl) ComboBox_GetEditSel(hwndCtl) ComboBox_GetExtendedUI(hwndCtl) ComboBox_GetItemData(hwndCtl, index) ComboBox_GetItemHeight(hwndCtl) ComboBox_GetLBText(hwndCtl, index, lpszBuffer) ComboBox_GetLBTextLen(hwndCtl, index) ComboBox_GetText(hwndCtl, lpch, cchMax) ComboBox_GetTextLength(hwndCtl)

ComboBox_InsertItemData(hwndCtl, index, data) (corresponds to CB_INSERTSTRING)

ComboBox_InsertString(hwndCtl, index, data) ComboBox_LimitText(hwndCtl, cchLimit) ComboBox_ResetContent(hwndCtl)

ComboBox_SelectItemData(hwndCtl, indexStart, data) (corresponds to CB_SELECTSTRING)

ComboBox_SelectString(hwndCtl, indexStart, lpszSelect) ComboBox_SetCurSel(hwndCtl, index) ComboBox_SetEditSel(hwndCtl, ichStart, ichEnd) ComboBox_SetExtendedUI(hwndCtl, flags) ComboBox_SetItemData(hwndCtl, index, data) ComboBox_SetItemHeight(hwndCtl, cyItem) ComboBox_SetText(hwndCtl, lpsz) ComboBox_ShowDropdown(hwndCtl, fShow)

Windows CE doesn't support the ComboBox_Dir macro.
