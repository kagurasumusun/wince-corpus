The following code examples show how the date and time picker can be used.

The DoFormatQuery Application-Defined Function provides an example of how an application might handle the DTN_FORMATQUERY notification by calculating the widest possible string for a given callback field.

The DoFormat Application-Defined Function provides an example of how an application might handle the DTN_FORMAT notification messages by providing a text string for a callback field.

The DoWMKeydown Application Defined Function provides an example of how an application might handle the how DTN_WMKEYDOWN notification to provide custom responses to input the user types into a callback field.
