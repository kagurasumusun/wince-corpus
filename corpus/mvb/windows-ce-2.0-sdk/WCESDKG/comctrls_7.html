Command Bar Functions

Windows CE defines eight new functions for creating and manipulating command bars.

Use the CommandBar_AddAdornments function to add the Close button (X), the Help button (?), and the OK button to the command bar. Every command bar has to have a close button. The OK button and the Help button are optional. Don't call the CommandBar_AddAdornments function until after you've added all the other elements to the command bar.

A command bar stores the information needed to draw the button images in an internal list. When the command bar is created, the list is empty. Each image has a zero-based index that's used to associate the image with a button. Use the CommandBar_AddBitmap function to add an array of images to the end of the list. This function returns the index of the first new image that was added. The system includes a set of predefined command bar button images. To use the predefined images, specify HINST_COMMCTRL in the hInst parameter, and either IDB_STD_SMALL_COLOR or IDB_VIEW_SMALL_COLOR in the idBitmap parameter, depending on which images you want to use. The header files define constant values for the indexes of the predefined images.

Use the CommandBar_AddButtons function to add several command bar buttons or separators at once to a command bar. (To create a separator, specify TBSTYLE_SEP in the fsStyle field of the TBBUTTON structure you pass in the lpButton parameter.)

Use the CommandBar_AddTooltips function to add tool tips describing the command bar buttons.

Use the CommandBar_Create function to create a new command bar.

The window procedure for a command bar automatically sets the size of the command bar and positions it along the top of the parent window's client area. It also destroys the command bar when its parent window is destroyed. You can use the CommandBar_Destroy function to destroy the command bar without destroying the parent window.

After modifying a menu bar on the command bar, call CommandBar_DrawMenuBar to redraw the command bar. Don't use the DrawMenuBar function for menu bars on the command bar.

To obtain the handle of a menu bar in a command bar, use the CommandBar_GetMenu function. To obtain the handle of a sub-menu on the menu bar, use the GetSubMenu function.

Unlike scroll bars and status bars, the command bar is part of the client area of your application. To determine the useable portion of the application window, use the CommandBar_Height function to retrieve the command bar's height in pixels and subtract the height of the command bar from the size of the client rectangle, which you obtain by calling GetClientRect.

Use the CommandBar_InsertButton function to add a single button or separator to a command bar.

To create a combo box and insert it into a command bar, use the CommandBar_InsertComboBox function. CommandBar_InsertComboBox always creates a combo box with the WS_CHILD and WS_VISIBLE styles. You can specify other supported combo box styles, as well. You can use either the CommandBar_InsertMenubar or CommandBar_InsertMenubarEx function to insert a menu bar into a command bar. Use CommandBar_InsertMenubar to insert a menu bar identified by a resource ID. Use CommandBar_InsertMenubarEx to insert a menu bar identified by either a resource name or menu handle.

Note Each element in a command bar has a zero-based index by which command bar functions can identify it. The leftmost element has an index of zero, the element immediately to its right has an index of one, and so on. When you use any of the CommandBar_Insert* functions, the menu bar, button, or combo box is inserted to the left of the button whose index you specify in the iButton parameter.

Use the CommandBar_IsVisible function to determine whether a command bar is visible.

Although Microsoft's style guidelines recommend that you always have either a command bar or a command bands control in Windows CE applications, you can provide users with the option to hide the command bar, as long as it can be retrieved. Use the CommandBar_Show function show or hide the command bar.

Note Don't use 0xFFFFFFFF as the command ID of a command bar control. This ID is reserved for use by the command bar.

For guidelines on command bar design, see Designing Command Bars
