Scheduling Threads

When the operating system creates a new process, it also creates at least one thread and assigns that thread a priority level. Processes running under Windows CE are not assigned a priority class, so preemption is based solely on the thread's priority. Threads with a higher priority are scheduled to run first. Threads with the same priority level run in a round-robin fashion, with each receiving a slice of execution time. Threads at a lower priority do not run until all threads with a higher priority have finished. All threads are created with a default priority of THREAD_PRIORITY_NORMAL. If you need to change the priority of a thread use the SetThreadPriority function.

To change the priority level of a thread

  • Call the SetThreadPriority function passing in one of eight level values.

  • For a list of the thread priority levels, see Architectural Overview of the Windows CE Operating System.
