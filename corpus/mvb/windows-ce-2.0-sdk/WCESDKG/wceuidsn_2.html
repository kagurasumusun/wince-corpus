Designing Menus

Menus are collections of commands, attribute selections, separators, and other elements that are selectable. All menus in Windows CE are implemented as top-level, pop-up windows that do not support buttons. Although Windows CE supports owner-drawn menu items, it handles them as it would other menu items.

Windows CE does not support menu bars. Instead, it combines the functionality of a menu bar and a tool bar in one control, called a command bar, which makes efficient use of the screen space available on many Windows CE-based devices. Windows CE supports four types of menus: pop-up, scrolling, cascading, and drop-down.

  • Pop-up menus

    A pop-up menu is a floating menu that displays commands specific to the object selected by the user, or to the object's immediate context. When users access a pop-up menu, the pop-up menu appears at the location on the screen where the accessed it. Windows CE does not support the System menu usually found on the title bar in Windows desktop applications.

  • Scrolling menus

    Scrolling menus are unique to Windows CE devices. With scrolling menus, you do not have to limit the size of a menu to the number of items that fit on the display screen. If a menu is taller than the height of the display area, Windows CE adds scrolling arrows so the user can scroll the menu up and down. If a menu has too many columns to fit within the width of the display area, Windows CE ignores all column breaks and makes the menu a single-column scrolling menu.

  • Cascading menus

    A cascading menu is a secondary or submenu that appears when a certain option in the parent menu is selected. A triangular arrow next to the parent item in a menu indicates a cascading menu. Cascading menus in Windows CE are displayed in alphabetical order. If the height of a cascading menu exceeds the maximum screen height of 240 pixels, the menu adopts a multiple column mode, which shows the remaining menu items in an adjacent column.

  • Drop-down menus

    A drop-down menu contains commands accessed from a command or menu bar.
