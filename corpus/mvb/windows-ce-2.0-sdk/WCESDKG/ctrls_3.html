Check Box Messages

Windows CE supports the following check box messages the same way Windows 95 and Windows NT do. You can use message cracker macros to send some of these messages. See Check Box Macros.

BM_CLICK

BM_GETCHECK

BM_GETSTATE

BM_SETCHECK

BM_SETSTYLE

WM_COMMAND

WM_CTLCOLORBTN

WM_ENABLE

WM_GETFONT

WM_GETTEXT

WM_GETTEXTLENGTH

WM_SETFONT

WM_SETTEXT
