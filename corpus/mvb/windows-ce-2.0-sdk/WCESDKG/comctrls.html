Common Controls

A common control is a control that provides a standardized way for users to view and organize information and to set or change attributes and properties. Common controls offer users a familiar interface for performing common tasks, which makes applications easier to use and learn. Most common controls send the WM_NOTIFY message instead of the WM_COMMAND message sent by Windows Controls.

When writing applications for Windows CE, you can use most of the same common controls you use when writing applications for Windows 95 and Windows NT. It's important to remember, though, that Windows CE-based devices have small display areas and users select controls by touching the screen with a stylus, which isn't as precise as using a mouse. To facilitate user interaction with your application, always make interactive controls at least 23 pixels high and 23 pixels wide. Leave at least 4 pixels between a control and the edge of the screen (unless the control has to be aligned with the command bar), and at least 2 pixels between adjacent controls.

To use most of the common controls, you must include the Commctrl.h header file in your application. To use property sheets, you must include the Prsht.h header file.

Before you can create or use any common controls, you have to register them. You can do this in two ways. You can call the InitCommonControls function, which registers all the common controls at once, except for the rebar, month calendar and date and time picker controls. Or you can call the InitCommonControlsEx function, which registers a specific common control class. Calling either of these functions ensures the common control dynamic-link library (DLL) is loaded.

Note InitCommonControlsEx is a new function that wasn't available in previous version of Windows.

Windows CE supports three new common controls that weren't available in previous version of Windows. It also supports a lot of new functionality for existing common controls, such as the custom draw service. For information on the new controls, see the CommandBands, Date and Time Picker Controls, and Month Calendar Controls. For information on the custom draw service, see The Custom Draw Service.

For an overview of styles and structures used with common controls, see Common Control Styles and Common Control Structures.

Up-down Controls

Windows CE doesn't support animation controls, the new ComboBoxEx control, drag lists, flat scroll bars, hot keys, IP address controls, or rich edit controls. It only supports tool tips for tool bar and command bar buttons.

Windows CE doesn't support the GetEffectiveClientRect function.

For more detailed information on the latest common controls and common control features, see The New Common Controls and New Common Control Features topics.
