Architectural Overview of the Windows CE Operating System

Microsoft Windows CE is a compact, highly efficient, multi-platform operating system. It is not a "cut-down" version of Windows 95, but was designed from the ground up as a multithreaded, fully preemptive, multitasking operating system for platforms with limited resources. Its modular design allows it to be customized for products ranging from handheld PCs to consumer electronic devices to specialized industrial controllers.

General Features of Windows CE
  • Provides system designers with a modular operating system that can customized for specific products. The basic core of the operating system requires less than 200K of ROM.

  • Designed to run on a wide variety of platforms.

  • Supports a substantial subset of the Win32 API, along with familiar development models and tools.

  • Supports a variety of user-interface hardware, including color displays with up to 32 bits per pixel color depth.

  • Supports a variety of serial and network communication technologies

  • Supports COM/OLE, OLE Automation, and other advanced methods of inter-process communication.

A key feature of Windows CE is that it can be customized for a particular device, allowing a system designer to construct an operating system that is no larger than necessary for their product. To enable customization, Windows CE is structured as a collection of modules. Each module is a self contained subset of the operating system. and interacts with other modules and applications through Win32-compatible interfaces. Many of the modules are, in turn, subdivided into smaller components, which permits the modules themselves to be customized.

Customization involves selecting a set of modules and components that provide the needed services, and omitting those that don't. OEMs must also implement an OEM Adaptation Layer (OAL) that acts as an interface between the kernel and the device hardware, as well as any built-in device drivers that are required. See the Windows CE Embedded Development Kit for more details on customizing the operating system.

There are five primary modules:

  • The kernel module supports basic services such as process and thread handling and memory management.

  • The core system interface module allows applications to access the operating system.

  • The file system module supports persistent storage of information

  • The graphics windowing and events subsystem (GWES) module controls graphics and window-related features.

  • The communications module allows the exchange of information with other devices.
