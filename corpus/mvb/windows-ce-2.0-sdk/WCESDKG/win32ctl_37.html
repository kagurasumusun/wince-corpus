Changing Fonts And Colors

Your application can use Custom Draw to change an item's font. To do this, simply select the HFONT you want into the device context specified by the hdc member of the NMCUSTOMDRAW structure associated with that notification. Since the font you select might have different metrics than the default font, make sure you include the CDRF_NEWFONT bit in the return value for the notification message. For more information on using this functionality, see the sample code in Processing the NM_CUSTOMDRAW Notification Message.

The font that your application specifies is used to display that item when it is not selected. Custom Draw does not allow you to change the font attributes for selected items.
