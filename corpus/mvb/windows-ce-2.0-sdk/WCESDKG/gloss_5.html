File Allocation Table

A table that contains the status of various segments of disk space used for file storage. Also, the file system that maintains the table.

file filter

A file filter is a dynamic-link library (DLL) that controls the transfer of data between a desktop PC and an H/PC. File filters are used by the H/PC Explorer application to convert files automatically as they are transferred.

file system API

The Windows CE file system API consists of a subset of the standard Win32 file system functions. These functions let you create directories and data files, read and write file data, and retrieve file and directory information.

free threading model

A free threading model is a model in which an object can be used on any thread at any time. Compare apartment-model threading, single threading model.
