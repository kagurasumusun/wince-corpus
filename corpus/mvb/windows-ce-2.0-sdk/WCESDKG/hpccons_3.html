Handling H/PC Screen Display

You may need to redesign your application for the H/PC screen aspect ratio.

Because windows cannot be resized, most applications should use the full screen. Do not hardcode the screen dimensions into applications. Call GetSystemMetrics (with SM_CXSCREEN and SM_CYSCREEN) to get the full screen size. Note that the command bar is part of the client area. Call GetSystemMetrics with SM_CYMENU to get its height and subtract it from the screen dimensions to get the usable screen size.

In general, it is best to work in relative coordinates. Support for Bit Block Transfers (blt) is limited.

Bitmaps and icons should be in the proper format. The screen can be backlit, but the contrast between the shades is not great. Use as high a contrast as possible. In general, monochrome graphics are best for text or line drawings.
