Toolbar Structures

The TBNOTIFY structure is the same in Windows CE as it is in Windows 95 and Windows NT.

In Windows CE, the TBNOTIFY structure has been renamed NMTOOLBAR, to conform to standard naming conventions, but the two structures are identical.

Windows CE also supports the following new toolbar structures. For an overview of how to use these structures, see New Features for Toolbars and The Custom Draw Service.

NMCUSTOMDRAW

NMKEY

TBREPLACEBITMAP

Windows CE doesn't support the new NMTBHOTITEM structure.
