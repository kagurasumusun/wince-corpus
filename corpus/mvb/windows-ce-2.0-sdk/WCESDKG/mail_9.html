Using Message Flags

You can use other message flags to further enhance the performance of your application. Two of the message flags in the MailMsg structure, MAIL_GET_BODY and MAIL_GET_FLAGS, can be used to determine how much of the message is to be read into memory. Using these flags will reduce the amount of memory required if only part of the message is of interest.

To read the entire message into memory, set MAIL_GET_BODY. If no flag is set, everything except the message body is read into memory. In both these cases, the system will allocate memory from the local heap. A handle to the heap is passed back through the hHeap member of the MailMsg structure. To get minimal information about the messages in the message store, without having to allocate memory, set dwFlags with MAIL_GET_FLAGS.
