Static Control Macros

You can use the following message cracker macros to send static control messages. These macros pack their parameters into the appropriate wParam/lParam format and then call SendMessage. For more information, refer to the macro definitions in Windowsx.h and the documentation for the corresponding button message. See Static Control Messages.

Static_Enable(hwndCtl, fEnable) (corresponds to the EnableWindow function)

Static_GetText(hwndCtl, lpch, cchMax) Static_GetTextLength(hwndCtl) Static_SetText(hwndCtl, lpsz)
