Exception Handling

Windows CE COM/OLE ignores any exceptions thrown by an application when invalid and, under some circumstances, NULL pointers are passed to the COM/OLE API functions. As a result, threads which generate such exceptions will be terminated. To prevent applications from being terminated unexpectedly, it is important that no invalid nor unwarranted NULL pointers be passed into the COM/OLE functions unless customized exception handling routine (using try/except) be implemented in the application that calls the APIs.
