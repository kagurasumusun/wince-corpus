Using Communications

A key feature found on virtually all Windows CE devices is the ability to transmit and receive data. Both serial and network communication modes are supported. Some examples of how Windows CE can be used for communication include:

  • Downloading files from a PC or network

  • Exchanging information with another Windows CE device

  • Sending and receiving e-mail

  • Sending data to a server

  • Internet browsing

  • Reading bar codes

Digital communication has two basic aspects. One is the hardware used to convey the bits from one computer to another. The other is the way that the information is processed by the sending and receiving devices.

To support the many different types of communication, Windows CE devices may include a variety of supporting hardware. Some (a connector for a serial cable or an infrared transceiver, for instance) may be an integral part of the device. If a PC card slot is available, users can also extend the built-in capabilities of the device with a range of third-party communications hardware (modems or bar-code readers, for example). Currently available communication hardware includes:

  • Serial cables

  • Infrared transceivers

  • Wireless transceivers

  • Modems

  • Bar code readers

The way information is processed depends in part on the hardware, and in part on where the information is being sent. There are two basic approaches to handling information: serial and network communication. Strictly speaking, both approaches normally transmit data serially. The difference lies in how the information is packaged.

Serial communication is commonly used when two devices are directly connected to each other. Because there is no ambiguity about where the information is going, it is often simply streamed from one device to the other, with only minimal processing. Some examples of serial communication include:

  • Transferring information from a desktop PC to a Windows CE device via a cable

  • Sending text to a printer using an infrared transceiver

Networks have multiple devices connected together. This means that any transmission will usually be received by more than one device. To communicate with a specific member of a network, the transmitted data needs to include an "address" that identifies the intended recipient. Addressing and related tasks are handled by the Windows CE network stack. Networking can be used for a wide variety of purposes including:

  • Downloading a file from a corporate local area network.

  • Browsing the internet using a modem connection to an independent service provider.

  • Sending e-mail on the road using a wireless service.

The remainder of this chapter discusses the details of the communication support provided by Windows CE.
