Remote Function and Application Execution

Besides the specific RAPI function calls, there are two functions which provide a way to execute functions and applications which reside on the Windows CE device:

  • CeCreateProcess

    This function creates a new process which runs a specified executable file residing on the Windows CE device.

  • CeRapiInvoke

    This function remotely executes a function residing on the Windows CE device, providing for both input parameters and output data. It operates in either block (synchronous) or stream (asynchronous) mode.

    In block mode, the caller passes both input parameters and output data in a single buffer. As this is a synchronous call, all input data must be present in memory at the time of the call and all output data must be present before the function finishes.

    In stream mode, an IStream type interface which is used to exchange arbitrary sized data in any order and direction. The caller can still pass input data in a single buffer, but from that point on all data should be exchanged via the stream. Thus the data can be read, written, and stored in chunks. The interface used is based on IStream, but has two additional methods to allow the setting of timeouts.
