Application Interfaces

Windows CE may have one or more built-in applications pre-installed. The currently available applications include:

  • Contacts

    A database application for personal information management.

  • Inbox

    A mail application to provide users with access to electronic mail.

These are open applications of general utility. If application developers have more specialized requirements, these applications may be used as the processing engines inside proprietary code. For this purpose, the Windows CE SDK exposes a set of functions and structures that a custom application can use to interface with the built-in contacts and mail applications. They are:

  • The Contacts Database API

    This API supports functions and structures for querying and manipulating the records in the contacts database. For information, see the "Contacts Database" chapter.

  • The Mail Interface

    This API supports functions and structures that make applications compatible with the Windows CE Inbox mail client. They also provide additional services for mail transport and storage. For information, see the "Mail Interface" chapter.

  • The Mail Transport Service API

    This API supports functions that can be used by a mail client application, such as the Windows CE Inbox. For information, see the "Mail Interface" chapter.
