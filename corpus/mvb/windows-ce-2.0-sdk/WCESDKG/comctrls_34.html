New Features for List Views

Windows CE provides several new features for list views.

In Windows CE, you can set the order of the columns in report view by setting the new iOrder field in the LVCOLUMN structure when you add a column to a list view control, and by using the new LVM_GETCOLUMNORDERARRAY and LVM_SETCOLUMNORDERARRAY messages.

To display an image from an image list next to the title of a column in report view, specify LVCF_IMAGE in the mask field, LVCFMT_IMAGE in the fmt field, and the zero-based index of an image in the list in the iImage field of the LVCOLUMN structure when you add a column to a list view control.

List view controls in Windows CE support the new custom draw service, which gives you greater flexibility to customize a list view's appearance. If a list view provides this service, it sends the new NM_CUSTOMDRAW notification at specific times during drawing operations. The lParam of the NM_CUSTOMDRAW notification is a pointer to an NMLVCUSTOMDRAW structure, which contains the information necessary to draw the customized list view. For information on the custom draw service, see The Custom Draw Service.

Windows CE supports a new list view style, LVS_OWNERDATA, for creating a virtual list view. A virtual list view doesn't manage any data except for input focus and item selection information. All other data is managed by the owner of the list view. This enables a list view to handle very large data sets, especially in cases where the data is stored in a database that has its own data access methods. For information on creating and using virtual list views, see List View Control Update.
