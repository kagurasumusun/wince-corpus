Exposing ActiveX Objects

In general, ActiveX objects are exposed in Windows CE in the same way as in Windows 95/Windows NT, with the following two minor exceptions:

  • A Windows CE application must use CoInitializeEx to initialize the Automation library. OleInitialize is not supported.

  • OleUnitialize may not be used to uninitialize the OLE Automation library, as the function is not supported in Windows CE.
