HTML Viewer Control Structures

Windows CE aupports three structures for use with the HTML viewer control.

The NM_HTMLVIEW structure contains information relevant to the specific notification being sent. An HTML viewer control passes a pointer to this structure in the lParam of the WM_NOTIFYmessage.

The INLINEIMAGEINFO structure contains information about an image. An application passes a pointer to this structure in the lParam of the DTM_SETIMAGE message it sends to an HTML viewer control.

The HTMLCONTEXT structure contains information about an ALT+Tap event. It passes a pointer to this structure in the lParam of the NM_CONTEXTMENU notification it sends to the application when a user ALT+Taps in the control.
