Common Control Structures

Each of the common controls has its own set of structures that are specific to the control, but there are some structures you use with all common controls.

The NMHDR structure, which is passed by reference as the lParam to the WM_NOTIFY message, is the same in Windows CE as it is in Windows 95 and Windows NT.

Windows CE also provides the following new structures to encapsulate information required by some of the new features.

The INITCOMMONCONTROLSEX structure contains information about the common controls you want to register when you call the InitCommonControlsEx function.

The NMMOUSE contains information about a mouse notification message.

Windows CE doesn't support the NMOBJECTNOTIFY structure.

For information on structures supported by a specific common control, see the Structures topic for that control.
