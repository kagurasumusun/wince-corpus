Paragraph Shading

The following shading properties are preserved for paragraphs that do not lie inside tables. Shading inside tables is not preserved.

Token Description
bgbdiag Background backward diagonal
bgcross Background cross
bgdcross Background diagonal cross
bgdkbdiag Background dark backward diagonal
bgdkcross Background dark cross
bgdkdcross Background dark diagonal cross
bgdkfdiag Background dark forward diagonal
bgdkhoriz Background dark horizontal
bgdkvert Background dark vertical
bgfdiag Background forward diagonal
bghoriz Background horizonal
bgvert Background vertical
cbpat Color background pattern
cfpat Color forground pattern
shading Shading
