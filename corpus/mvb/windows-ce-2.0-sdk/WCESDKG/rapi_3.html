Retrieving Information

To retrieve path information

  • Call CeGetTempPath to get the path to the directory designated for temporary files.

    - Or -

  • Call CeGetSpecialFolderPath to get the path to one of the special shell folders, depending on the input parameter.

    The possibilities include the recycle bin, Start menu directory, document template directory, network directory, folders for fonts or installed printers, and several others.

To retrieve other information

  • Call CeFindAllDatabases to get information about all databases of a given type

    The information is returned in an array of CEDB_FIND_DATA structures.

    - Or -

  • Call CeFindAllFiles to get information about all files and directories in a specified directory of the Windows CE object store.

    The information is returned in an array of CE_FIND_DATA structures.

You must free the memory allocated by the CeFindAllDatabases, CeFindAllFiles, or CeReadRecordProps functions by calling the CeRapiFreeBuffer function.
