The Non-Client Area

In Windows CE, the non-client area of the window is controlled solely by the window manager. Windows CE doesn't send applications any messages dealing with the non-client area.

The only non-client area function Windows CE supports is the DrawFrameControl function. You can't use this function to draw menus, so you can't pass the DCF_MENU value in the uType parameter, or the DFCS_MENUARROW, DFCS_MENUBULLET, or DFCS_MENUCHECK values in the uState parameter. Windows CE doesn't support minimizing or maximizing windows, so you can't use the DFCS_CAPTIONMAX, DFCS_CAPTIONMIN, DFCS_CAPTIONRESTORE values in the uState parameter, either. You also can't pass the DFCS_BUTTONRADIOIMAGE, DFCS_BUTTONRADIOMASK, DFCS_ADJUSTRECT, DFCS_FLAT, DFCS_MONO, or DFCS_SCROLLSIZEGRIP values in the uState parameter. Windows CE supports a new constant for the uState parameter, called DFCS_CAPTIONOKBTN, that you can use to draw the OK button.

Note The DFCS_CAPTIONOKBTN value is unique to Windows CE. You can't use it in Windows 95 or Windows NT applications.

For an overview of non-client area styles supported by Windows CE, see Non-Client Area Styles.
