Check Box Notifications

The following check box notifications are the same in Windows CE as they are in Windows 95 and Windows NT.

BN_CLICKED

BN_DOUBLECLICKED

BN_HILITE

BN_KILLFOCUS

BN_PAINT

BN_SETFOCUS

Windows CE supports the BN_PAINT, BN_DISABLE, and BN_UNHILITE notifications for compatibility with applications written for earlier versions of Windows.
