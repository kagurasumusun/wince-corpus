Web Browser Control Properties

The Windows CE WebBrowser control supports the following two properties the same way Windows 95 and Windows NT support them.

Property Access method
Busy IWebBrowser::get_Busy
LocationURL IWebBrowser::get_LocationURL

The Windows CE WebBrowser control currently doesn't support the Application, Container, Document, Height, Left, LocationName, Parent, Top, TopLevelContainer, Type, or Width properties.
