TrueType and Raster Fonts

Windows CE supports raster and TrueType font technologies but allows only one type to be used on a given system. The choice of TrueType or Raster Font Types is made when a system is designed, and cannot be changed afterwards by an application.

The differences between raster and TrueType fonts has to do with the way the glyph for each character or symbol is stored in the respective font-resource file. A raster font glpyh is a tiny bitmap that represents a single character. Since the bitmaps for each glyph in a raster font are designed for a specific resolution on a particular device, raster fonts are generally considered to be device dependent.

A TrueType fonts glyph contains both line and curve commands and hints. Windows CE uses these hints to adjust the length of the lines and shapes of the curves used to draw the character or symbol. These hints and the respective adjustments are based on the amount of scaling used to reduce or increase the size of the bitmap. Since TrueType characters can be scaled up or down and still retain their original shape, they are considered to be device-independent.

A font's glyphs are stored in a font-resource file. A font-resource file for a raster or vector font is stored in a .FON file. TrueType fonts, have two files, a short .FOT header file, and a .TTF file that contains the actual data.
