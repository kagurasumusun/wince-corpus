List View Notifications

The following list view notifications are the same as they are in Windows 95 and Windows NT.

LVN_BEGINDRAG

LVN_BEGINLABELEDIT

LVN_COLUMNCLICK

LVN_DELETEALLITEMS

LVN_DELETEITEM

LVN_ENDDRAG

LVN_ENDLABELEDIT

LVN_GETDISPINFO

LVN_INSERTITEM

LVN_ITEMCHANGED

LVN_ITEMCHANGING

LVN_KEYDOWN

LVN_SETDISPINFO

Windows CE also provides the following new list view notifications

LVN_ITEMACTIVATE

LVN_MARQUEEBEGIN

LVN_ODCACHEHINT

LVN_ODFINDITEM

LVN_ODSTATECHANGED

NM_CUSTOMDRAW

In Windows CE, the NM_CLICK notification for list views supplies a NMLISTVIEW structure instead of an NMHDR structure for the lParam.

Because there's no right mouse button equivalent, Windows CE doesn't support the LVN_BEGINRDRAG, LVN_ENDRDRAG, NM_RCLICK, or NM_RDBLCLK notifications. Windows CE doesn't support hot tracking or tool tips for list views, so it doesn't support the new LVN_GETINFOTIP or LVN_HOTTRACK notifications.
