File Filters

A file filter is a dynamic-link library (DLL) that controls the transfer of data between the desktop PC and the Windows CE device. File filters are used by the Windows CE Services application on the desktop PC to automatically convert files as they are transferred.

File formats used by the Windows CE operating system and Windows CE-based applications are generally different from those of the corresponding Windows-based applications. For example, Pocket Word does not support OLE compound files. Windows CE Services automatically adjusts file formats as files are transferred between the desktop PC and the Windows CE device.

Some of the common filters provided with Windows CE Services include:

  • Pocket Word (.pwd) to Microsoft Word (.doc)

  • Microsoft Word (.doc) to Pocket Word (.pwd)

  • Pocket Excel (.pxl) to Microsoft Excel 5.0 (.xls)

  • Microsoft Excel (.xls) to Pocket Excel (.pxl)

· Windows bitmap (.bmp) to Windows CE 4-color bitmap (.2bp)

You can extend Windows CE Services's file filtering capability by defining your own application-specific filters. The subtopics in this section describe file filters and the interfaces used to create them.

Implementing a file filter is basically the same for importing as for exporting files. The only difference is in the registry settings and how the body of the file filter (that is, the converter function) changes data. The examples presented here are only for importing files, but typically you would write a converter function that handles both importing and exporting, using dual registry settings that indicate both the import and export functionality.

Note The words "importing" and "exporting" in this chapter are used relative to the Windows CE device. This is exactly opposite to the way it is used in the User Interface section. Thus, importing a file (using a file filter) transfers a file from the desktop PC to the Windows CE device, while exporting (using a file filter) transfers a file from the Windows CE device to the desktop.
