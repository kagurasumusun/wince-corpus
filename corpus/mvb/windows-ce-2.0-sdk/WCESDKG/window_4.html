Window Messages

Windows CE supports many of the window messages Windows 95 and Windows NT support, but it supports some of them a little bit differently than Windows 95 and Windows NT do.

Windows CE also defines a new window message, called WM_HIBERNATE, that notifies an application when system resources are running low. When an application receives this message, it should attempt to release as many resources as possible. Every Windows CE program must implement a handler for the WM_HIBERNATE message. See Handling a Hibernation Message for more information.

Note In the current implementation of Windows CE, if an application's window isn't visible, it can't receive a WM_HIBERNATE message. This is because the WM_HIBERNATE message is only sent to applications that have a button on the taskbar, and an application only has a button on the taskbar if it's visible.

In Windows CE, DefWindowProc does not automatically post a WM_QUIT message when it handles a WM_DESTROY message.

The WM_SETTINGCHANGE message (which replaces the WM_WININICHANGE message) is a little different than it is in Windows 95 and Windows NT. In Windows CE, the pszSection parameter (lParam ) is a constant defined in Winuser.h, rather than a pointer to a string. At this time, the only value defined for it is INI_INTL, which indicates that a user has made a change to the regional settings in the control panel. The wFlag parameter (wParam) is set to NULL.

Because users can't resize windows, the only value the WM_SIZE message supports in the fwSizeType parameter (wParam) is SIZE_RESTORED.

In Windows CE, you can define your own messages to send within a private window class just like you can in Windows 95 and Windows NT. (Use numbers in the range WM_USER through 0x7FFF for these messages.)

The only values you can pass in the uCmdType parameter (wParam) to the WM_SYSCOMMAND message are SC_CLOSE and SC_KEYMENU.

The following window messages are the same in Windows CE as they are in Windows 95 and Windows NT.

WM_CANCELMODE WM_HSCROLL
WM_CLOSE WM_MEASUREITEM
WM_COMMAND WM_MOVE
WM_COMPAREITEM WM_NOTIFY
WM_COPYDATA WM_PAINT
WM_CREATE WM_QUIT
WM_DELETEITEM WM_SETFONT
WM_DRAWITEM WM_SETREDRAW
WM_ENABLE WM_SETTEXT
WM_ERASEBKGND WM_SHOWWINDOW
WM_FONTCHANGE WM_STYLECHANGED
WM_GETFONT WM_SYSCOLORCHANGE

Windows CE also doesn't support the WM_ACTIVATEAPP, WM_CHILDACTIVATE, WM_COMPACTING, WM_DISPLAYCHANGE, WM_ENDSESSION, WM_ENTERSIZEMOVE, WM_EXITSIZEMOVE, WM_GETMINMAXINFO, WM_ICONERASEBKGND, WM_INPUTLANGCHANGE, WM_INPUTLANGCHANGEREQUEST, WM_MOVING, WM_PAINTICON, WM_PARENTNOTIFY, WM_POWER, WM_PRINT, WM_PRINTCLIENT, WM_QUERYDRAGICON, WM_QUERYENDSESSION, WM_QUERYOPEN, WM_SIZING, WM_STYLECHANGING, or WM_WINDOWPOSCHANGING window messages.
