List Boxes

A list box is a window that displays a list of character strings. The user selects a string from the list by tapping it with the stylus. When a string is selected, it's highlighted. You can use a vertical or horizontal scroll bar with a list box to scroll lists that are too long for the control window. The list box automatically hides or shows the scroll bar, as needed.

Windows CE doesn't support the DlgDirList or DlgDirSelectEx functions.

Because Windows CE doesn't support owner-drawn list boxes, it doesn't support the COMPAREITEMSTRUCT structure, and you can't specify ODT_LISTBOX in the CtlType field of the DRAWITEMSTRUCT or MEASUREITEMSTRUCT structures.

The DELETEITEMSTRUCT structure is the same in Windows CE as it is in Windows 95 and Windows NT.
