The Windows CE Notification API

The notification application programming interface (API) is unique to Windows CE. You can use the functions in this API to schedule your application to run automatically either when a particular event occurs, or at a precise time specified by the user. You can also use these functions to schedule user notification events, such as appointment reminders.

Windows CE provides a notification options dialog box that displays a list of the types of feedback the host device supports, and allows the user to select the notification signal they prefer. Possible options include displaying an icon in the notification area of the taskbar, playing a sound, or flashing an LED. Your application must handle removing the icon, or turning of the sound or LED, when the user acknowledges the notification.

Note When a user replaces all the data on their Windows CE-based device with data they had previously backed up onto their desktop computer, the user notifications database is cleared.

The CE_USER_NOTIFICATION structure contains information on what type of notification event to schedule, and what time the notification event should occur. You use this structure with the CeGetUserNotificationPreferences and CeSetUserNotification functions.

For information on Windows CE notification functions, see Windows CE Notification Functions.

For more information on the Windows CE notification API, see Using Windows CE Notifications.
