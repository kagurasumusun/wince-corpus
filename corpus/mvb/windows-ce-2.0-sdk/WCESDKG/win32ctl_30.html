New Common Control Features

Windows CE supports several new features for common controls. The custom draw feature, which applies to many common controls, gives you greater flexibility in customizing a control's appearance. Windows CE also supports virtual list views, transparent toolbars, drop-down toolbar buttons, and the new TVS_CHECKBOXES style, which makes it possible to use check boxes as items in a tree view control.
