Property Sheets

A property sheet is a window that contains one or more related Dialog Boxes, called property pages. Each property page has a tab, similar to a tab in a file folder or notebook. A user selects a property page by tapping its tab with the stylus. A property sheet is used to view or modify the attributes, or properties, of an object.

Property sheets in Windows CE are just like property sheets in Windows 95 and Windows NT, except that they don't support the Apply button, and the OK and Dismiss buttons are located at the top of the window.

Windows CE doesn't currently support wizards.

You create a property sheet by calling the PropertySheet function, passing in a reference to a PROPSHEETHEADER structure that contains information about the property pages that belong to the property sheet.

To use Property sheets, you must include the prsht.h header file in your application.
