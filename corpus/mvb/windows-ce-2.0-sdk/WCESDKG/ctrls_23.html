Push Button Styles

Windows CE supports most of the push button styles supported by Windows 95 and Windows NT, but there are a few differences.

Note When you use the BS_OWNERDRAW style for a button, you assume all responsibility for drawing the button. You can't use BS_OWNERDRAW with any other button styles. It's important to note that buttons are drawn by their parent window (they don't draw themselves).This means, when using an owner-drawn button, you have to trap the WM_DRAWITEM message in the button's parent window's window procedure and put the code that draws the button there. The parent window of an owner-drawn button is also responsible for erasing the background, if necessary, before drawing the button.

The following push button styles are the same in Windows CE as they are in Windows 95 and Windows NT.

Style Description
BS_BOTTOM Places the text at the bottom of the button rectangle.
BS_CENTER Centers the text horizontally in the button rectangle.
BS_DEFPUSHBUTTON Creates a push button with a heavy black border. If the button is in a dialog box, the user can select the button by pressing the ENTER key, even when the button does not have the input focus. This style is useful for enabling the user to quickly select the most likely (default) option.
BS_LEFT Left-aligns the text in the button rectangle.
BS_NOTIFY Enables a button to send BN_DBLCLK, BN_KILLFOCUS, and BN_SETFOCUS notification messages to its parent window. Note that buttons send the BN_CLICKED notification message regardless of whether it has this style.
BS_OWNERDRAW Creates an owner-drawn button. The owner window receives a WM_MEASUREITEM message when the button is created and a WM_DRAWITEM message when a visual aspect of the button has changed.
BS_PUSHBUTTON Creates a push button that posts a WM_COMMAND message to the owner window when the user selects the button.
BS_RIGHT Right-aligns text in the button rectangle.
BS_TOP Places text at the top of the button rectangle.
BS_VCENTER Places text in the middle (vertically) of the button rectangle.
WS_TABSTOP In a dialog box, any control with this style will be a tab stop when a user tabs through the controls.

Windows CE doesn't support the BS_BITMAP, BS_FLAT, BS_ICON, BS_MULTILINE, BS_PUSHBOX, BS_TEXT, or BS_USERBUTTON styles. Use the BS_OWNERDRAW style to create the effects you'd otherwise achieve by using the BS_BITMAP, BS_ICON, or BS_USERBUTTON button styles.
