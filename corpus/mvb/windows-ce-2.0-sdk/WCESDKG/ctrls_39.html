Static Control Messages

Windows CE supports most static control messages and notifications the same way Windows 95 and Windows NT do, except for the STM_GETIMAGE and STM_SETIMAGE messages. Windows CE only supports the IMAGE_BITMAP and IMAGE_ICON flags for the fImageType (wParam) parameter in these messages. You can't use cursors or enhanced metafiles in static controls, so the IMAGE_CURSOR and IMAGE_ENHMETAFILE flags aren't valid.

The following static control messages are the same in Windows CE as they are in Windows 95 and Windows NT. You can use message cracker macros to send some of these messages. See Static Control Macros.

WM_CTLCOLORSTATIC

WM_GETFONT

WM_GETTEXT

WM_GETTEXTLENGTH

WM_SETFONT

WM_SETTEXT
