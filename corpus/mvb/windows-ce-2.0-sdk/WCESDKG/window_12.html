Non-Client Area Styles

Windows CE supports many of the non-client area window styles Windows 95 and Windows NT support.

Windows CE also defines a new window style, called WS_EX_NODRAG. This style creates a stationary window. Specify this style when you want to prevent a user from dragging a window by its title bar.

Note The WS_EX_NODRAG style is available only to applications running under Windows CE. This style isn't supported in Windows 95 or Windows NT.

Windows CE only assigns taskbar buttons to top level windows that have the WS_OVERLAPPED style.

Windows CE doesn't have a system menu, but you can use the WS_SYSMENU style to add the standard Close (X) button to a window's title bar.

Windows CE supports the following non-client area styles.

Style Meaning
WS_BORDER Creates a window that has a thin-line border.
WS_CAPTION Creates a window that has a title bar (includes the WS_BORDER style).
WS_DLGFRAME Creates a window that has a border style typically used with dialog boxes. A window with this style can't have a title bar.
WS_HSCROLL Creates a window that has a horizontal scroll bar.
WS_OVERLAPPED Creates an overlapped window. An overlapped window has a title bar and a border.
WS_SYSMENU Creates a window that has a window-menu on its title bar. The WS_CAPTION style must also be specified.
WS_VSCROLL Creates a window that has a vertical scroll bar.
WS_EX_CAPTIONOKBTN Includes an OK button in the title bar.
WS_EX_CLIENTEDGE Creates a window that has a border with a sunken edge.
WS_EX_CONTEXTHELP Includes a help button (?) in the title bar of the window.
WS_EX_DLGMODALFRAME Creates a window that has a double border.
WS_EX_NODRAG Creates a stationary window that can't be dragged by its title bar
WS_EX_OVERLAPPEDWINDOW Combines the WS_EX_CLIENTEDGE and WS_EX_WINDOWEDGE styles.
WS_EX_STATICEDGE Creates a window that has a three-dimensional border style. This style should be used for items that don't accept user input.
WS_EX_WINDOWEDGE Creates a window that has a border with a raised edge.
