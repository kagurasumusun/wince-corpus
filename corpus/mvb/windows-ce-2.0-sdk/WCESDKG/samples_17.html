DBView Sample

The Dbview sample application demonstrates the use of the Windows CE database functions.

Note that Dbview.exe uses the TreeView_* functions to display all of the available databases. When the database node is selected, database information is displayed in the edit control to the right. By expanding the Database node, the available database properties are displayed. When a database property is selected, the property's information is also displayed in the edit control.

To create a database using Dbview
  1. Select the Object Store menu button and then select Create Database.

  2. Enter a database name and tap OK.

    Dbview creates a database using the specified database name suffixed with the string "_TEST". The Dbview application does this so that Dbview does not delete databases that are not created using Dbview.exe. The created database contains seven records containing various properties and values.

To delete a database using Dbview
  1. Select the Object Store menu button and then select Delete Database.

  2. Tap YES to delete the database.

    Dbview only allows databases created by Dbview to be deleted. Only one database can be deleted at a time, and only the currently selected database is deleted.

To run under Windows CE emulation
  • When running under emulation, Dbview uses an emulated object store; this information is stored in the Wceobstr.dat file, located in the directory \Wce\Emul. To debug using database information located on the H/PC, copy the desired databases from the H/PC to the desktop object store using the Remote Object Viewer tool provided with the Windows CE SDK. See Remote Object Viewer.
