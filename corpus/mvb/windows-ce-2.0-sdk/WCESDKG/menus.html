Menus

All menus in Windows CE are implemented as top-level pop-up windows.

Windows CE does not support menu bars, but the command bar combines the functionality of the menu bar and tool bar in one control. This makes more efficient use of the limited screen space available on Windows CE-based devices.

Windows CE does not support menu buttons.

Windows CE introduces a new feature, called scrolling menus. If a menu does not fit on the screen, Windows CE adds scrolling arrows so users can scroll the menu up and down. You do not have to do anything to take advantage of scrolling menus in your applications. This feature is enabled automatically. For information on scrolling menus, see Scrolling Menus.

Windows CE supports owner-drawn menu items, but it handles them a little differently than the desktop Windows platforms do. In some respects, it treats an owner-drawn item as it would any other menu item. When a menu receives a WM_DRAWITEM message, the lParam is a pointer to a DRAWITEMSTRUCT. The hDC member of this structure is the handle to the device context (DC) the menu must use to draw the owner-drawn item. On other Windows platforms, this DC is initialized to its default state. Under Windows CE, however, the DC is initialized to the grayed or highlighted status of the current item. Also, Windows CE automatically highlights an owner-drawn menu item when it has the keyboard focus. Other versions of Windows do not.

For general guidelines on menu design, see The Windows Interface Guidelines for Software Design.

Scrolling menus are a new feature, specifically designed for Windows CE. With scrolling menus, you do not have to limit the size of a menu to the number of items that will fit on the display screen.

If a menu is taller than the height of the display area, Windows CE adds an up arrow at the top of the menu and a down arrow at the bottom. When the user cannot scroll any further in one direction or the other, the associated arrow is grayed. Pressing the up or down arrow will scroll the menu one item at a time. No menu item is highlighted while the user is scrolling. Changing the selection by using a keyboard arrow or keyboard mnemonic causes the newly selected item to scroll into view if it is not already displayed.

If a menu has too many columns to fit the width of the display area, Windows CE ignores all column breaks and makes the menu a single column scrolling menu.

If an individual menu item is too large to be drawn without being clipped by the up or down arrow, the item is not drawn at all. This may leave a large blank space next to an arrow.

A pop-up menu is a floating menu that displays commands specific to the object selected by the user, or to the object's immediate context. Users access pop-up menus by using the ALT+Tap action, and the pop-up menu appears at the location on the screen where the user tapped the stylus.
