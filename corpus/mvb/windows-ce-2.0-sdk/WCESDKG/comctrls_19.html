Header Control Notifications

The following header control notifications are the same as they are in Windows 95 and Windows NT.

HDN_BEGINTRACK

HDN_DIVIDERDBLCLICK

HDN_ENDTRACK

HDN_ITEMCHANGED

HDN_ITEMCHANGING

HDN_ITEMCLICK

HDN_ITEMDBLCLICK

HDN_TRACK

Windows CE also provides the following new header control notifications to support drag and drop and the new custom draw service. For an overview of how to use these new notifications, see New Features for Header Controls. For information on the custom draw service, see The Custom Draw Service.

HDN_BEGINDRAG

HDN_ENDDRAG

HDN_GETDISPINFO

NM_CUSTOMDRAW
