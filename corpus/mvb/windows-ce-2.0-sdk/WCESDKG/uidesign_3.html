Taskbar Design

The H/PC taskbar is very similar to the taskbar in Windows 95 and Windows NT but, in several ways, it's even more important. Because H/PC applications do not have title bars, users identify a running application primarily by the icon and text displayed on its taskbar button.

By default, the taskbar is the top most window in the shell. When fully displayed, the taskbar is 26 pixels tall and either 480 or 640 pixels wide depending on the resolution of the display.

Like Windows, the taskbar for the H/PC v2.0 supports auto hide functionality. While hidden, the taskbar is 5 pixels tall. When a user hides the taskbar, a notification is sent to all applications that the usable vertical screen is increased by 21 pixels. To reactivate a hidden taskbar, each H/PC touch screen contains a 2.5mm tap region around all four edges of the display. This combined with the height of the taskbar, provides a generous tap region for activating the taskbar.

Additionally, the H/PC taskbar contains the following elements:

  • Start Menu

    The Start menu has two components: the main menu and cascading menus. The main menu has a maximum height equal to the height of the display (240 pixels). Thus, the menu displays only the number of items is can fit into this region. If the contents exceeds this number, the menu displays as many items as possible in alphabetical order. The width of the main menu cannot exceed 120 pixels. Any menu items wider than 120 pixels are cropped. The cropped text is replaced with an ellipses.

    Cascading menus are also displayed in alphabetical order. They have a maximum height of 240 pixels. If the number of items displayed exceeds the height of the screen, the menu adopts a multiple column mode and shows the remaining menu items in the adjacent column.

    Like other Windows platforms, main and cascading menus use the 16 by 16 pixel icon associated with the menu item. Items that cascade to additional menus are appended with a triangular arrow. If a menu item opens a folder that does not contain items, display a menu item with the caption "empty."

  • Window Buttons

    The H/PC displays Window buttons for all open parent windows. Window buttons are 23 pixels tall. The button width is equal to the width of the available taskbar tray area divided by the number of buttons. The maximum button width is 1/3 of the available tray area. The minimum button width is 26 pixels.

    Like Windows 95 and Windows NT, Windows buttons display an icon and caption. The icon size is 16 by 16 pixels so that the Window button is always able to display the entire icon. The caption truncates as the width of the button decreases in size. Activated Window buttons do not have bolded captions.

  • Desktop Button

    The Desktop button provides quick access to the desktop. When the button is tapped, it brings the desktop forward, into focus. Tapping on the Desktop button while the desktop is depressed causes the previously active application to reactivate. The Desktop button is 23 by 22 pixels, the size of the standard toolbar button, and is located on the far right edge of the taskbar.

  • Notification Area

    You can add a status indicator to the notification area of the taskbar. Indicators are represented by graphics supplied by your application. They contain information that is global in nature or needs monitoring by the user when working with other applications. When adding a status indicator to the taskbar, provide a pop-up window that displays additional information or controls for the object when the user taps the indicator icon as well as a one that displays commands for the object when the user performs an ALT+TAP combination on the indicator icon. Carry out the default command defined in the pop-up menu when the user double-taps the indicator icon. Display a tool tip that indicates what the status indicator represents, provide the user with an option not to display the status indicator.

    Status indicators are 16 by 16 pixels, except for the clock which occupies a fixed space. All status indicators are placed 3 pixels to the left of the clock with 0 pixels between each indicator.

    If you add a status indicator to the taskbar, you must define its access method. The methods supported by the taskbar include Down-Tap, Up-Tap, Double-Tap, and ALT+Tap.
