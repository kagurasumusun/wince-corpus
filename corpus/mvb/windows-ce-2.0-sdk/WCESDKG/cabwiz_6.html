Application Manager

This program (CeAppMgr.exe) resides on the desktop computer. It is responsible for adding and removing applications on the Windows CE device, as well as deleting the application files from the desktop computer.

To register the application with Application Manager:

1. copy the application CAB file to the desktop computer.

2. copy the CeAppMgr INI file for the application to the desktop computer.

3. run CeAppMgr with the INI file as a parameter.

This process can be done using a third-party desktop install program. CeAppMgr then automatically installs the application on the Windows CE device. If the Windows CE device is not docked, CeAppMgr notes that the application has not been installed. When the device is subsequently docked, CeAppMgr will automatically complete the installation.

The command line is:

CEAppMgr.exe [/report] "CEAppMgr-INI-file" ["CEAppMgr-INI-file"]

CEAppMgr-INI-file
the full file and pathname of the CEAppMgr INI file for a single application. Note that if the application has multiple components, CEAppMgr can be run once with the multiple INI files, one for each component.
report
an optional parameter that provides information concerning the installation process in the event of problems. This should not be included in the final setup program.

The full file and pathname of CEAppMgr can be extracted from the default registry value of the registry key: "HKLM\Software\Microsoft\Windows\CurrentVersion\App Paths\CEAppMgr.exe". Since the returned value is the full file and pathname of CEAppMgr.exe, you can strip off the "CEAppMgr.exe" filename to get the desktop install directory of Windows CE Services. This is useful to use as the default parent directory (appending your application's subdirectory) when installing the files to the desktop computer.

The installation procedure registers the application's CAB files with CEAppMgr, so that it can be reinstalled on the device at a later time or on another device.
