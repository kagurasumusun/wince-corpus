Memory Pages

Because an average of a half page is apt to be wasted in any independent memory section, a larger page size tends to create more wasted memory. A smaller page size requires more operating system overhead in order to keep track of pages. It also decreases the amount of memory the translation look-aside buffer (TLB) can address-potentially reducing its effectiveness.

The actual page size on a given device is OEM-dependent. However, since RAM usage is a major concern, page size is generally kept as small as possible. At present, it ranges from 1KB or 4KB. A good rule of thumb is to assume a 1K page size when making memory allocation decisions. If you need to know the exact page size, use the Remote Memory Viewer tool.
