Tree View Notifications

The following tree view notifications are the same in Windows CE as they are in Windows 95 and Windows NT.

TVN_BEGINDRAG

TVN_BEGINLABELEDIT

TVN_DELETEITEM

TVN_ENDLABELEDIT

TVN_GETDISPINFO

TVN_ITEMEXPANDED

TVN_ITEMEXPANDING

TVN_KEYDOWN

TVN_SELCHANGED

TVN_SELCHANGING

TVN_SETDISPINFO

Windows CE provides a new tree view control notification, called NM_CUSTOMDRAW, which supports the new custom draw service. A tree view control that provides this service sends this notification during drawing operations. For information on the custom draw service, see The Custom Draw Service.

Because there's no right mouse button equivalent, Windows CE doesn't support the TVN_BEGINRDRAG notification. Windows CE doesn't currently support tool tips for tree views, so it doesn't support the new TVN_GETINFOTIP notification.
