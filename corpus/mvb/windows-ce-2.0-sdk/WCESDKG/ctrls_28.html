Radio Button Styles

Windows CE supports most of the radio button styles Windows 95 and Windows NT support, but it doesn't support the BS_LEFTTEXT style. You can achieve the same effect (placing the radio button to the right of the associated text) by using the BS_RIGHTBUTTON style.

The following radio button styles are the same in Windows CE as they are in Windows 95 and Windows NT.

Style Description
BS_AUTORADIOBUTTON Creates a radio button for which , when a user selects it, all other buttons in the same group are automatically unchecked.
BS_RADIOBUTTON Creates a small circle with a label displayed to the right of it. To display the text to the left of the circle, combine this flag with the BS_RIGHTBUTTON style.
BS_LEFT Left-aligns the text in the button rectangle on the right side of the check box.
BS_RIGHT Right-aligns text in the button rectangle on the right side of the check box.
BS_RIGHTBUTTON Positions a check box's square on the right side of the button rectangle.
WS_TABSTOP In a dialog box, any control with this style will be a tab stop when a user tabs through the controls.

Windows CE doesn't support the BS_FLAT or BS_PUSHLIKE styles.
