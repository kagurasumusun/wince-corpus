Connection Notification

This chapter deals with the Windows CE Services connection manager, which manages the link between the desktop PC and a docked Windows CE mobile device. It notifies a registered desktop application when a mobile device has docked or undocked, and allows application startup to proceed automatically.

For example, the following applications register with the connection manager:

  • Explorer Window for Windows CE Services

  • Remote tools applications provided with the Windows CE SDK.

    These tools use a common implementation of the connection notification interfaces. For information about how to use these tools, see Windows CE Remote Tools.

  • Connection Notification Client Sample.

    This sample is provided with the Windows CE SDK and provides a basic template for receiving connection notifications. See Connection Notification Client Sample.

Connection notification requires that the desktop application be registered with the Windows CE connection manager. The two methods used are:

  • Registry-Based Notification, using command lines that are registered in the system registry,

  • COM Interface-Based Notification., using two Component Object Model (COM) interfaces, one implemented by the connection manager and the other by the application, to perform the registration.
