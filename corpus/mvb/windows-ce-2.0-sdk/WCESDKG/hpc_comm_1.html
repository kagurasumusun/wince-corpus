Establishing Connections with the H/PC

Their functionality can be incorporated by applications keeping their code size to a minimum. For example, the Terminal applications can be used to configure modems and set up dialing properties.

The following communication applications are bundled with the H/PC and reside in ROM:

  • Remote Networking Application

    Combines the functionality of two Windows 95 applications:

    • Dial-Up Networking for connecting to Remote Access Service (RAS) server. Unlike Windows 95 Dial-Up Networking, Remote Networking only allows the H/PC to be a dial-up client. The H/PC supports connections to RAS servers using Point-to-Point Protocol(PPP) with TCP/IP as the underlying network protocol.

    • Direct Cable Connection (DCC) for establishing a direct serial connection between the H/PC client and a Windows-based desktop PC host. Direct Cable Connection allows the client to share the resources of the host computer. DCC uses PPP to establish a data link level connection for running network and transport layer protocols. The state of the DCC connection can be determined using the RAS API set.
  • Terminal

    Uses a serial cable or modem connection to connect the H/PC with a desktop PC to transfer files or act as a remote terminal. Terminal can also be used to connect to remote Bulletin Board Systems (BBS). While it does not support any file transfer protocols, it can be used to cut and paste information from the BBS.

    The Terminal application provides for the following terminal emulation:

    • Generic TTY

    • VT-100/ANSI
  • PC Link

    PC Link REPLLOG is used by H/PC Explorer and the remote tools to establish a connection between the H/PC and a desktop PC.
