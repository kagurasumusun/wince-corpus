TAPI Callback Function

TAPI sends messages back to the application through a callback function. This function must be implemented by the application. It is specified when the telephone line is initialized through the lpfnCallBack parameter of lineInitialize.Applications must implement the callback function according to the following definition. Note that the name used, LineCallbackFunc, is a placeholder. Any suitable name can be used. 
void CALLBACK LineCallbackFunc (DWORD hDevice, DWORD dwMsg, DWORD wCallbackInstance, DWORD dwParam1, DWORD dwParam2, DWORD dwParam3);
hDevice
A handle to the line device associated with the callback. Do not use the HANDLE type for this parameter.
dwMsg
The line device message.
dwCallbackInstance
The callback instance data..
dwParam1
A message parameter.
dwParam2
A message parameter.
dwParam3
A message parameter.

The last three parameters are used by TAPI to pass messages back to the application. See the Windows CE Developers Reference for details.

LineCallbackFunction Message Description
LINE_ADDRESSSTATE The status of an address on a line that is currently open has changed
LINE_CALLINFO Call information has changed.
LINE_CALLSTATE The status of the call has changed
LINE_CLOSE The line device has been forcibly closed
LINE_CREATE A new line device has been created
LINE_DEVSPECIFIC A device-specific event has occurred
LINE_LINEDEVSTATE The state of a line device has changed
LINE_REMOVE A device has been removed (usually, permanently)
LINE_REPLY Reports the results of function calls that completed asynchronously
LINE_REQUEST Reports the arrival of a new request from another application

Windows CE supports the following TAPI functions. TAPI functions are identified as "asynchronous" if they can return before making a call to the application's callback function, otherwise they are considered "synchronous."

TAPI function Description
lineClose Closes specified line device. Synchronous.
lineConfigDialogEdit Displays a dialog box allowing user to change line device configuration. Synchronous
lineDeallocateCall Releases the specified call handle. Synchronous.
lineDrop Disconnects a call or abandons a call attempt in progress. Asynchronous.
lineGetDevCaps Returns the capabilities of a given line device. Synchronous.
lineGetDevConfig Returns the configuration of a media stream device. Synchronous.
lineGetID Retrieves the device ID for a specified open line, address, or call. Synchronous.
lineGetTranslateCaps Returns address translation capabilities. Synchronous.
lineInitialize Initializes TAPI line abstraction. Synchronous.
lineMakeCall Makes an outbound call and returns a handle to tghe call. Asynchronous.
lineNegotiateAPIVersion Allows an application to negotiate which API version to use. Synchronous.
lineOpen Opens a specified line device for monitoring and/or controlling the line. Synchronous.
lineSetDevConfig Sets the configuration of the specified media stream device. Synchronous.
lineSetStatusMessages Specifies status changes the application wants notification of. Synchronous.
lineShutdown Shuts down the application's use of the line TAPI. Synchronous.
lineTranslateAddress Translates between canonical address format and dialable address format. Synchronous.
lineTranslateDialog Displays a dialog box allowing user to change location. Synchronous.
