Functions for Working With File Systems

The file system functions available to Windows CE applications are those supported by the Windows CE kernel. Note that the C Runtime library does not include any file access functions, such as fopen, fread, and fprintf.

CreateFile opens existing files as well as creating new files. To write to a file in the equivalent of append mode, call CreateFile and SetFilePointer. To write to a file such that you overwrite its existing contents, call CreateFile and SetEndOfFile.

Read, write operations ReadFile, WriteFile, FlushFileBuffers
