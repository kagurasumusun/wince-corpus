Toolbar Button Structures

The following toolbar button structures are the same in Windows CE as they are in Windows 95 and Windows NT.

TBADDBITMAP

TBBUTTON

TBNOTIFY

Windows CE also supports a new structure for toolbar buttons, called TBBUTTONINFO. This structure contains information about a toolbar button, including its style, state, text, size, image, and the command associated with it.

Windows CE doesn't currently support the COLORMAP structure.
