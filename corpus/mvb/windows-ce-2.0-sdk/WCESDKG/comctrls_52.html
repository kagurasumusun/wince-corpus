Rebar Messages

Windows CE supports the following rebar messages.

RB_BEGINDRAG RB_HITTEST
RB_DELETEBAND RB_IDTOINDEX
RB_DRAGMOVE RB_INSERTBAND
RB_ENDDRAG RB_MAXIMIZEBAND
RB_GETBANDCOUNT RB_MINIMIZEBAND
RB_GETBANDINFO RB_GETTEXTCOLOR
RB_GETBANDBORDERS RB_SETBANDINFO
RB_GETBARHEIGHT RB_SETBARINFO
RB_GETBARINFO RB_SETBKCOLOR
RB_GETBKCOLOR RB_SETPARENT
RB_GETRECT RB_SETTEXTCOLOR
RB_GETROWCOUNT RB_SHOWBAND
RB_GETROWHEIGHT RB_SIZETORECT
RB_GETTEXTCOLOR

Windows CE doesn't currently support drag and drop, palettes, or tool tips for rebars, so it doesn't support the RB_GETDROPTARGET, RB_GETPALETTE, RB_GETTOOLTIPS, RB_MOVEBAND, RB_SETPALETTE, or RB_SETTOOLTIPS messages.
