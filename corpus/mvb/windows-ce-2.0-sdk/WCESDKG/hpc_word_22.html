Preserved but Ignored Tokens

Some tokens do not produce the full RTF-specified behavior for that RTF. The tokens are preserved, however, to be written to the file when the document is saved. This allows other RTF readers to process the tokens if necessary.

Example

Paragraph Shading \shading

Paragraphs with this property will be displayed with no shading in Microsoft Pocket Word 2.0. When the document is saved, the token is saved with the appropriate paragraphs.

Tokens that do not produce the full RTF-specified behavior include:
