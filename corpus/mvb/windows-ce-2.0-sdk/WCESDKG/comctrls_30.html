List View Macros

Windows CE supports most of the same macros for list views that Windows 95 and Windows NT suppport.

Windows CE supports a new constant for the iImageList parameter of the ListView_GetImageList and ListView_SetImageList macros. The LVSIL_HEADER value specifies that the image list you're setting or retieving is the list of images displayed in the list view's header control in report view.

Windows CE doesn't support hot tracking or background images for list views, so it doesn't support the new ListView_GetBkImage, ListView_GetHotCursor, ListView_GetHotItem, ListView_GetHoverTime, ListView_SetBkImage, ListView_SetHotCursor, ListView_SetHotItem, and ListView_SetHoverTime macros.
