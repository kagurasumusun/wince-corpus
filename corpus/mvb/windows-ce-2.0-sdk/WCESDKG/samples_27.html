Remote API Samples

The basic purpose of these samples is to demonstrate the Windows CE Remote APIs. For the H/PC, most of the Windows CE Remote APIs behave exactly the same as Win32 APIs behave on the desktop PC.

To build the Remote API samples
  • The Windows CE SDK includes seven samples (located under the directory \Wce\Samples\Win32\Rapi) demonstrating various functions from the remote API (RAPI). Follow the procedure described in Building the Sample Applications, selecting one of the valid project configurations in the table below. All seven samples are built as standard Win32 Console applications. Hence, they are best run from the Command Prompt. Running these samples from the Build menu causes them to execute in a transitory console window which vanishes upon completion.

    Note These sample applications are run only on the desktop PC - the remote APIs access the H/PC. For more information on RAPI, see Remote API Functions.
