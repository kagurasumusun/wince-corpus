Working with Attachments

There are five Mail* functions exposed in the SDK to let you create, delete, request, get and query for the length of mail attachments. These functions are listed in the Summary of Mail Functions section above.

You can also work with attachments the way you would with a message. In particular, you register an intended operation in the dwFlags parameter of the MailAtt structure. For example, you set the parameter to ATT_DISP_RETRIEVE when you want the attachment downloaded to the local device.

The Mail Interface API uses the szLocalName member of MailAtt to determine whether the attachment is local or non-local. For a non-local attachment, you must set szLocalName to NULL before passing it to, say, MailPutAttachment. For a non-local attachment, you must also specify the length (ulSize) of the original file. (For local attachments, the size is determined by actually examining the file.)
