COM/OLE Support

The Microsoft Component Object Model has proven to be a powerful tool for object-oriented development. Windows CE provides a set of functions and structures designed to support COM. There are two types of services:

  • COM

    A simple protocol that defines COM objects along with a library that offers object management services.

  • Automation (also known as OLE Automation)

    A more sophisticated set of object management services that allows applications to coordinate their interactions with each other.

Windows CE COM-based object services are derived from a subset of the Windows NT object services. See the Windows Platform SDK for more information on the use of COM/OLE.
