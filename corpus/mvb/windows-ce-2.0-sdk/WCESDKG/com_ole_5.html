The COM library

A Windows NT application may invoke CoInitialize or CoInitializeEx to initialize the COM library and call OleInitialize to initialize the OLE Automation library. But a Windows CE application uses CoInitializeEx only to initialize both the COM and the OLE libraries. To close the libraries, a Windows CE application needs to issue a single call to the CoUnitialize function. Furthermore, OleInitialize and OleUninitialize are redundant and are no longer supported in Windows CE.
