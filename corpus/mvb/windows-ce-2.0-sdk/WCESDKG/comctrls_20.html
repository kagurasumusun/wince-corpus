Header Control Structures

The following structures are the same in Windows CE as they are in Windows 95 and Windows NT.

HD_HITTESTINFO

HD_ITEM

HD_LAYOUT

HD_NOTIFY

In Windows CEthe HDITEM structure replaces the HD_ITEM structure. Two new fields have been added to HDITEM. The iImage field contains the zero-based index of an image in an image list to display with the header item. The iOrder field specifies where in the header control to position the header item. The mask field supports two new constants, HDI_IMAGE and HDI_ORDER, to indicate whether the two new fields contain valid information. The fmt field also supports a new constant, HDF_IMAGE, which specifies that the header item will display an image from an image list. (You associate an image list with a header control by using the HDM_SETIMAGELIST message.)

Windows CE also supports the following two new header control structures to support the use of callback items and the new custom draw service. For an overview of how to use these new structures, see New Features for Header Controls. For information on the custom draw service, see The Custom Draw Service.

NMCUSTOMDRAW

NMHDDISPINFO
