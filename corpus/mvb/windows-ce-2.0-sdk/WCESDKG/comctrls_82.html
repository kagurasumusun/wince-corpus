Tree View Macros

The following tree view macros are the same in Windows CE as they are in Windows 95 and Windows NT. You can use these macros to send tree view messages. Several of them correspond to same message, but with different flags set. See Tree View Messages.

TreeView_CreateDragImage

TreeView_DeleteAllItems (sends the TVM_DELETEITEM message with hItem set to TVI_ROOT)

TreeView_DeleteItem

TreeView_EditLabel

TreeView_EndEditLabelNow

TreeView_EnsureVisible

TreeView_Expand

TreeView_GetChild (corresponds to the TVM_GETNEXTITEM message)

TreeView_GetCount

TreeView_GetDropHilite (sends the TVM_GETNEXTITEM message with the TVGN_DROPHILITE flag set)

TreeView_GetEditControl

TreeView_GetFirstVisible (sends the TVM_GETNEXTITEM message with the TVGN_FIRSTVISIBLE flag set)

TreeView_GetImageList

TreeView_GetIndent

TreeView_GetISearchString

TreeView_GetItem

TreeView_GetItemRect

TreeView_GetNextItem

TreeView_GetNextSibling (sends the TVM_GETNEXTITEM message with the TVGN_NEXT flag set)

TreeView_GetNextVisible (sends the TVM_GETNEXTITEM message with the TVGN_NEXTVISIBLE flag set)

TreeView_GetParent (sends the TVM_GETNEXTITEM message with the TVGN_PARENT flag set)

TreeView_GetPrevSibling (sends the TVM_GETNEXTITEM message with the TVGN_PREVIOUS flag set)

TreeView_GetPrevVisible (sends the TVM_GETNEXTITEM message with the TVGN_PREVIOUSVISIBLE flag set)

TreeView_GetRoot (sends the TVM_GETNEXTITEM message with the TVGN_ROOT flag set)

TreeView_GetSelection (sends the TVM_GETNEXTITEM message with the TVGN_CARET flag set)

TreeView_GetVisibleCount (sends the TVM_GETNEXTITEM message with the TVGN_GETVISIBLECOUNT flag set)

TreeView_HitTest

TreeView_InsertItem

TreeView_Select (see TVM_SELECTITEM)

TreeView_SelectDropTarget (see TVM_SELECTITEM)

TreeView_SelectItem

TreeView_SelectSetFirstVisible (see TVM_SELECTITEM)

TreeView_SetImageList

TreeView_SetIndent

TreeView_SetItem

TreeView_SortChildren

TreeView_SortChildrenCB

Windows CE also supports a new tree view macro, called TreeView_Expand. This message expands or collapses the list of child items associated with a parent item. You can use this macro to send the new TVM_EXPAND message.
