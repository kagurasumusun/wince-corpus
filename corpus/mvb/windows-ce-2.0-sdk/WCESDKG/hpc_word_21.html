Fields

In most cases when Microsoft Pocket Word 2.0 encounters the Field group, the text contained in the Field Result subgroup will be extracted and treated as regular document text. The rest of the Field-related RTF will be ignored. The only two exceptions to this Field group handling are for the SYMBOL and HYPERLINK groups.

  • The Symbol definition is read from the data following the \fldinst token, and is not read from the field result subgroup.

  • The Hyperlink text is read from the data following the \fldinst token, and is not read from the field result subgroup.

When the document is later saved, no Field-related RTF is written to the file. The following field-related RTF tokens are supported by Microsoft Pocket Word 2.0.

Token Description
field Field
fldinst Field instruction
fldrslt Field result
