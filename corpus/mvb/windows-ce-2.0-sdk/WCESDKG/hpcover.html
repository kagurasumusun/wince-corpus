Handheld PC

The Handheld Personal Computer (H/PC) is a category of mobile computing devices based on the Windows CE operating system. More than a personal digital assistant, the H/PC is a full featured computer that extends the Microsoft Windows family to platforms of miniature footprint.

An H/PC is housed in a clamshell with an embedded keyboard, touch-sensitive screen and stylus. The stylus is used to replace a mouse for selection and manipulation of screen objects.

H/PC serves as a mobile companion to the Windows desktop PC. The programming model and development environment are very similar. As such, many desktop applications can easily be ported to the H/PC. In addition, the Windows CE shell and user interface bear a close resemblance to Windows 95, keeping the learning curve to a minimum for even casual Windows users.

In general, an H/PC embodies the following elements:

  • Hardware

    Manufacturers can choose different Windows CE components to include in their products, so not all H/PC devices have the same features.

    For more information, see User Input and Output Devices and Communications and Connectivity Hardware.

  • Software

    Bundled software can include a Windows CE shell, network communications software, and a suite of personal information management and productivity applications. Some of these applications expose an open API, providing a ready-made back-end engine for more special-purpose custom applications.

    For more information, see Applications Bundled with the H/PC

  • Desktop Connectivity

    H/PCs can establish a serial connection with a Windows-based desktop PC to transfer files, debug remotely, and synchronize databases on the two machines.

    For more information, see Desktop Connectivity.

  • Printing

    The built-in serial and IR ports enable remote printing.

    For more information, see Printing.
