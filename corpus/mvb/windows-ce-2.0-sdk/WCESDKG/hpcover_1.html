User Input and Output Devices

Windows CE input and output features include:

  • Display Screen

    The H/PC has at minimum a 480 ´ 240-pixel liquid crystal display (LCD) arranged in a landscape orientation. The LCD screen can have 2-, 4- or 8-bits-per-pixel color resolution. This renders the display in black and white, gray scale, or 256 colors.

  • Touch panel

    A continuous resistive touch panel lies on top of the LCD. The touch panel allows users to directly manipulate the objects on the screen similar to the way a mouse works on a desktop PC. Tapping the screen sends the same kind of messages generated by clicking the left mouse button on standard Windows-based PCs. Since there is no mouse, cursor support is limited to a spinning hourglass used as a wait cursor. Limited cursor support means you cannot change the shape of the cursor to indicate active targets like hyperlinks.

  • Keyboard

    The H/PC has a QWERTY-style keyboard designed to be as similar as possible to a standard PC keyboard. The keyboard includes keys such as CTRL, ALT, and two SHIFT keys. Infrequently used keys such as PRINT SCREEN and SCROLL LOCK and are not included. The keyboard supports separate key down and key up events.

  • Sound

    All H/PCs have built-in audio output hardware. Use the audio hardware to associate sounds with notification events or to play wave (.wav) files. Access .wav files stored in ROM to reduce code size.

  • Printer

    The H/PC serial port and the IR transceiver can be used for printing. Serial printing is available to most laser and thermal printers. IR printing is convenient if IR-enabled printers are readily available. The IR port can also be used to communicate with printers that have parallel interfaces.
