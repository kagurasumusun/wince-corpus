Designing Icons and Bitmaps

In a graphical user interface, icons convey attributes or tasks. Good icons clearly represent their function and are easy to remember, bad icons reduce the usability of your application by making the application appear obscure and unapproachable.

Icons are most often used on buttons, but can be used as indicators as well. When a Windows CE color icon has a Windows 95 equivalent, both icons use the same design. However, you must create a 16-color version and a grayscale version of the icon to ensure that it displays correctly on both color and 2-bpp devices. The icon editor in the Windows CE Toolkit for Visual C++ 5.0 can create .ico files that retain both 16-color and 2-bpp gray versions of an icon.

In addition to using Windows 95 icon equivalents, you can create your own icons using the standard Windows 16-color palette. To add dimensionality an icon, use highlights and shadows, but remember, the icons you create must translate correctly to 2-bpp gray if your device supports both grayscale and color displays.
