Communications and Connectivity Hardware

Windows CE supports the following connectivity devices:

· Serial Port

All H/PCs have a nine-pin serial port. Applications use the serial port for communication between the H/PC and a desktop PC. H/PCs can connect to desktop PCs by way of a serial cable, or though an optional docking cradle (available from some H/PC manufacturers) connected to the desktop PC. Some H/PCs support data communications through a modem connected to the serial port.

Windows CE supports standard protocols for serial communications like, PPP and TCP/IP. The WinSock, RAS, TAPI, and Win32 Serial APIs are exposed for developing serial communication applications.

· Infrared Communications Hardware

H/PCs have an infrared communications serial port that conforms to the Infrared Data Association (IrDA) specifications. H/PCs can communicate with other H/PCs, Desktop PCs, or Printers with IrDA compliant infrared ports.

· Hardware Expansion Slot

While some H/PCs have an internal modem and one-way pager built into the main hardware, many utilize the PC Card slot for adding communication hardware. Because the Windows CE operating system supports only a portion of the PCMCIA standard, not all modems are supported. However, because the system supports installable device drivers, third-party software and hardware vendors can add support for additional devices by providing device drivers that are installed into the H/PC RAM.
