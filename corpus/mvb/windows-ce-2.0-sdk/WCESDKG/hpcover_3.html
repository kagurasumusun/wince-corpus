Applications Bundled with the H/PC

The applications that come packaged with the H/PC include:

  • Microsoft Pocket Word

  • Microsoft Pocket Excel

  • Microsoft Pocket Internet Explorer

  • Inbox

  • Contacts

. Each of these applications has a counterpart that runs on a desktop PC. Windows CE provides a file conversion utility to transfer data files between platforms. Data files can also be synchronized to reflect changes made on either machine.

The applications included on the H/PC are stored in ROM. To conserve RAM these applications execute in place. That is, static data is located in the process address space in ROM, while RAM is used by the application exclusively for storing variables and a stack that is created for each thread.

Windows CE supports a number of open APIs for manipulating the data used by the bundled applications. These Windows CE-unique APIs turn the bundled applications into back-end engines and are intended to facilitate rapid application development on H/PCs. For example an Address Store API is supported for building applications that work with the Contacts information manager. This API exposes functions for adding, sorting, modifying and deleting records that appear in Contacts.
