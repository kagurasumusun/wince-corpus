Implementing a File Filter

The Windows CE SDK includes a sample file filter, named Copyfilt, that imports a binary file (.bin) from the desktop PC to a binary file (.pbn) on the target device. The Copyfilt sample demonstrates the following basic operations to implement a file filter.

To Implement a File Filter
  1. A setup application must register the file filter DLL.

    See Registering a File Filter.

  2. The file filter DLL must implement the ICeFileFilter interface and methods.

    See File Filter Interfaces and Structures.

  3. The Windows CE Services calls the QueryInterface method for the file filter's ICeFileFilterOptions interface. If this interface is available, it then calls the ICeFileFilterOptions::SetFilterOptions method with a correctly initialized CFF_CONVERTOPTIONS structure. The bNoModalUI member specifies whether the converter is allowed to bring up modal UI while performing the conversion.

  4. The Windows CE Services calls the file filter's ICeFileFilter::NextConvertFile method to perform the custom file conversion. The caller passes information about the file conversion and about the source and destination files via pointers to the CFF_CONVERTINFO, CFF_DESTINATIONFILE, and CFF_SOURCEFILE structures.

    Within the file filter filter's ICeFileFilter::NextConvertFile method, call the following methods in the ICeFileFilterSite interface during the file conversion.

    • Open the source file, using the ICeFileFilterSite::OpenSourceFile method, to read the file contents and perform the desired data manipulation (filtering).

    • Open the destination file, using the ICeFileFilterSite::OpenDestinationFile method, for writing the converted data.

    • Read data from the stream file opened using the OpenSourceFile method, convert the data, and write the converted data to the stream file opened using the OpenDestinationFile method.

    • At a frequency specifed by the file filter, report the file conversion progress by calling the ICeFileFilterSite::ReportProgress method. The Windows CE Services updates a graphical status bar to show the percentage completion of the file conversion.

    • If the file filter DLL intentionally discards any of the file data, the filter has the option of calling the ICeFileFilterSite::ReportLoss method, so that the Windows CE Services can display a message when the file conversion is complete. Depending on the error format passed in the call, the Windows CE Services may call the file filter's ICeFileFilter::FormatMessage method, in order to properly format the message.

    • Close the source file, using the ICeFileFilterSite::CloseSourceFile method, and close the destination file, using the ICeFileFilterSite::CloseDestinationFile method.
