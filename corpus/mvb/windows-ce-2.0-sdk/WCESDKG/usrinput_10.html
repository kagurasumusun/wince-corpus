Client Area Stylus Messages

A window receives a client area stylus message when a stylus event occurs within the window's client area. The system posts the WM_MOUSEMOVE message to the window when the user moves the cursor within the client area. It posts one of the following messages when the user presses or releases a stylus button while the cursor is within the client area.

Windows CE supports the following messages for stylus input.

Message Meaning
WM_LBUTTONDBLCLK The user double-tapped the touch-screen while the stylus was pressed to the touch screen.
WM_LBUTTONDOWN The user pressed the touch-screen.
WM_LBUTTONUP The user released the stylus from the touch-screen.
WM_MOUSEMOVE The user moved the stylus while the tip was pressed to the screen.

Message Parameters

The lParam parameter of a client area stylus message indicates the position of the cursor hot spot. The low-order word indicates the x-coordinate of the hot spot, and the high-order word indicates the y-coordinate. The coordinates are given in client coordinates. In the client coordinate system, all points on the screen are given relative to the coordinates (0,0) of the upper left corner of the client area.

The wParam parameter contains flags that indicate the status of the other stylus buttons and the CTRL and SHIFT keys at the time of the stylus event. You can check for these flags when stylus-message processing depends on the state of another stylus button or of the CTRL or SHIFT key. The lParam parameter can be a combination of the following values.

Value Meaning
MK_CONTROL The CTRL key is down.
MK_LBUTTON The stylus is touching the screen.
MK_SHIFT The SHIFT key is down.
