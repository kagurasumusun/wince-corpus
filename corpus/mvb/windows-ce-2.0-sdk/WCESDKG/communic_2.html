Implementing Serial Communications

To use serial communication

  1. Determine which COM port you need to open. Port numbers are stored in the registry (\HKEY_LOCAL_MACHINE\Drivers). Active drivers are listed under \HKEY_LOCAL_MACHINE\Active.

  2. Call CreateFile with lpFileName set to the COM port name ("COM1:", for example.). Note that "COM1" (i.e., no colon) will not work. The lpSecurityAttributes parameter should be set to NULL and the dwFlagsAndAttributes parameter set to zero.

  3. For raw-IR transmission, the port must be placed in IR mode. Invoke EscapeCommFunction with hFile set to the handle returned by CreateFile, and dwFunc set to SETIR. Check the return value to be sure that raw IR is supported.

  4. Call SetCommTimeouts to set the communication timeouts.

    The timeout parameters can be queried by calling the GetCommTimeouts function. For more information about communication timeouts, see COMMTIMEOUTS.

  5. Call the ReadFile and WriteFile functions to transmit and receive serial data. Set the lpOverlapped parameter for each function to NULL.

    When one thread is waiting for a ReadFile function to return, ReadFile calls issued by other threads will be blocked until the initial ReadFile call returns. The same is true for the WriteFile function.

  6. Call CloseHandle to close the serial port.
