Status Bar Messages and Notifications

The following status bar messages are the same in Windows CE as they are in Windows 95 and Windows NT.

SB_GETBORDERS

SB_GETPARTS

SB_GETRECT

SB_GETTEXT

SB_GETTEXTLENGTH

SB_SETMINHEIGHT

SB_SETPARTS

SB_SETTEXT

SB_SIMPLE

WM_NOTIFY

Windows CE also supports a new status bar message. Use SB_ISSIMPLE to determine if a status bar is in simple mode.

Windows CE supports a new status bar notification, called SBN_SIMPLEMODECHANGE, which a status bar sends when the simple mode changes as a result of receiving an SB_SIMPLE message.
