Programming Considerations for the H/PC

When writing an application for H/PC, an application developer must pay special attention to features unique to Windows CE. Limited memory, the lack of easily accessible static storage, a restricted power supply, the small landscape-oriented display, and the touch screen replacing the mouse as the main source of user input, all present an assortment of challenges to programmers.

On the other hand, the Windows CE shell incorporates a number of controls that give the H/PC user interface the distinctive look and feel of Windows 95. Because the controls are supported by libraries that are part of the shell, they are commonly available to all applications. See the Windows CE User Interface Design Guidelines and the H/PC version 2.0 User Interface Design Guildlines for information on designing a user interface for an H/PC.
