Using the Connection Notification Client Sample

Running Cnxnotif.exe establishes a remote connection (calling IDccMan::Advise) between the desktop PC and the H/PC. The Dccman icon appears in the desktop task bar tray , indicating the connection status. This icon is a symbol showing two connected terminals.

The application then displays a Connection Notification Test dialog box that allows the user to call the IDccMan methods listed on the Send menu. Selecting this menu displays the following options.

Note Only the ShowCommSettings method is implemented by the IDccMan interface. None of the other IDccMan methods are implemented by the Connection Manager (in Rapi.dll). The remaining options simply display a message in the Notification Messages: list box.

Send menu item Description
ShowCommSettings Calls the method IDccMan::ShowCommSettings that displays the Communications Properties dialog box. This is used to select the communication port that connects the desktop PC to the H/PC.
AutoconnectEnable Calls the method IDccMan::AutoconnectEnable.
AutoconnectDisable Calls the method IDccMan::AutoconnectDisable.
ConnectNow Calls the method IDccMan::ConnectNow.
SetIconDataTransferring Calls the method IDccMan::SetIconDataTransferring.
SetIconNoDataTransferring Calls the method IDccMan::SetIconNoDataTransferring.
SetIconError Calls the method IDccMan::SetIconError.

To exit the application click the Done button. (IDccMan::Unadvise is called to stop receiving notifications and to disconnect).
