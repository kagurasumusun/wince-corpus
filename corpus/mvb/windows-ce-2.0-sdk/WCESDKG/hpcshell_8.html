Clipboard Functions

You use most clipboard functions in Windows CE the same way you use them in Windows 95 and Windows NT.

Windows CE also provides a new clipboard function, called GetClipboardDataAlloc. This function is similar to the GetClipboardData function except that the memory for the data is allocated and owned by the calling process, rather than by the clipboard. This can save an extra memory allocation when clipboard data is being transferred.

Windows CE doesn't perform any automatic data format conversions between clipboard formats in the GetClipboardData or SetClipboardData functions.

Because Windows CE doesn't support private clipboard formats, you can't use the CF_DSPBITMAP, CF_DSPENHMETAFILE, CF_DSPMETAFILEPICT, CF_DSPTEXT, CF_GDIOBJFIRST through CF_GDIOBJLAST, CF_OWNERDISPLAY, or CF_PRIVATEFIRST through CF_PRIVATELAST values in the uFormat parameter to the SetClipboardData function. You also can't use the CF_ENHMETAFILE, CF_HDROP, CF_LOCALE, or CF_METAFILEPICT values.

Note Always allocate the data you're placing in the clipboard by using the LocalAlloc function. (Certain flags aren't supported for this function in Windows CE. See LocalAlloc for details.)

Windows CE only supports the Unicode version of RegisterClipboardFormat.

Use the following clipboard functions in Windows CE the same way you use them in Windows 95 and Windows NT.

CloseClipboard

CountClipboardFormats

EmptyClipboard

EnumClipboardFormats

GetClipboardFormatName

GetClipboardOwner

GetOpenClipboardWindow

OpenClipboard

Because Windows CE doesn't support clipboard viewers, you can't use the ChangeClipboardChain, GetClipboardViewer, or SetClipboardViewer functions.
