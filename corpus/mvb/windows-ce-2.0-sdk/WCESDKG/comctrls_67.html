Toolbar Messages

The TB_SETTOOLTIPS message has been adapted for Windows CE, and is very different than it is in Windows 95 and Windows NT. Because Windows CE doesn't support an actual tool tip control, you can't pass it a handle to a tool tip control. Instead, the TB_SETTOOLTIPS message in Windows CE takes a wParam, which is the number of tool tip strings to associate with the toolbar, and an lParam, which is the array of tool tip strings to associate with the toolbar buttons.

In Windows CE, the resource identifier you pass to TB_ADDSTRING in the idString parameter (LPARAM) has to reference a single string without substrings or separators.

The following toolbar messages are the same in Windows CE as they are in Windows 95 and Windows NT.

TB_ADDBITMAP TB_GETTOOLTIPS
TB_ADDBUTTONS TB_HIDEBUTTON
TB_AUTOSIZE TB_INDETERMINATE
TB_BUTTONCOUNT TB_INSERTBUTTON
TB_BUTTONSTRUCTSIZE TB_ISBUTTONCHECKED
TB_CHANGEBITMAP TB_ISBUTTONENABLED
TB_CHECKBUTTON TB_ISBUTTONHIDDEN
TB_COMMANDTOINDEX TB_ISBUTTONINDETERMINATE
TB_DELETEBUTTON TB_ISBUTTONPRESSED
TB_ENABLEBUTTON TB_PRESSBUTTON
TB_GETBITMAP TB_SETBITMAPSIZE
TB_GETBITMAPFLAGS TB_SETBUTTONSIZE
TB_GETBUTTON TB_SETCMDID
TB_GETBUTTONTEXT TB_SETPARENT
TB_GETITEMRECT TB_SETROWS
TB_GETROWS TB_SETSTATE
TB_GETSTATE

Windows CE doesn't support the TB_SAVERESTORE message.

Windows CE also provides the following new toolbar messages. Many of these messages are used to support the use of image lists in toolbars. For an overview of how to use these messages, see New Features for Toolbars.

TB_GETBUTTONINFO TB_REPLACEBITMAP
TB_GETBUTTONSIZE TB_SETBUTTONINFO
TB_GETDISABLEDIMAGELIST TB_SETBUTTONWIDTH
TB_GETIMAGELIST TB_SETDISABLEDIMAGELIST
TB_GETRECT TB_SETDRAWTEXTFLAGS
TB_GETSTYLE TB_SETIMAGELIST
TB_GETTEXTROWS TB_SETINDENT
TB_HIGHLIGHTBUTTON TB_SETMAXTEXTROWS
TB_ISBUTTONHIGHLIGHTED TB_SETSTYLE
TB_LOADIMAGES

Windows CE doesn't support the IDB_HIST_SMALL_COLOR and IDB_HIST_LARGE_COLOR values in the iBitmapID (wParam) parameter of the TB_LOADIMAGES message.

Windows CE doesn't support user customization of toolbars, so it doesn't support TB_CUSTOMIZE message.

Windows CE doesn't support anchor highlighting or hot tracking functionality, so it doesn't support the new TB_GETANCHORHIGHLIGHT, TB_GETHOTIMAGELIST, TB_GETHOTITEM, TB_SETANCHORHIGHLIGHT, TB_SETHOTIMAGELIST or TB_SETHOTITEM messages. Because Windows CE doesn't support drag and drop for toolbars, it doesn't support the new TB_GETOBJECT message either.
