Inserting Messages

The basic procedure for inserting a new message into a message store folder is:

  • Create the message body and header string.

  • Create a MailMsg structure.

  • Point the szBody member of the structure to the message body.

  • Use MailSetField to put the headers string into the pwcHeaders member.

  • Set the message flags to point to the desired folder.

  • Set any other relevant flags (MAIL_STATUS_COMPOSED, for instance)

  • Fill in the dwMsgLen, ftDate, and szSvcNam members, if relevant.

  • Use MailPut to put the message in the desired folder.

This basic procedure works well for simple mail messages without attachments or other non-IPM messages. However, if you need to add non-IPM properties or attachments to the newly created message, you must be aware that a transport may be registered to receive database notifications and may attempt to manipulate the message as soon as it is written. This is of special consequence for a message created in the Outbox folder, as the transport may move or delete the message in that folder. This could before the call to MailPutAttachment. Thus, it is recommended that you create such outgoing messages in the Inbox folder. Only after it is completely written to the message store and ready to be sent should you use MailUpdate(hMail, pmm, FALSE) to move the message to the Outbox.
