Spintest Sample

The Spintest sample application (Spintest.exe) uses the dynamic-link library (DLL) Spincube.dll. Spincube.dll provides a template for building a DLL to demonstrate the use of DLL entry points; it also provides an example of how to create a custom control class that can be used with Spintest.exe. The Spintest directory contains the source code needed to build Spintest.exe. The Spincube subdirectory contains the source code needed to build Spincube.dll.

Spintest.exe displays a window with four quadrants in which a spinning cube is displayed. Tapping (on the H/PC) or clicking (on the H/PC emulator) on a quadrant clears that portion of the display and toggles the display mode of the spinning cube.
