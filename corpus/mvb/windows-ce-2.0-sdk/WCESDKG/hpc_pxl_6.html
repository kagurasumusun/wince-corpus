COLINFO: Column Formatting Information (7Dh) [PXL 1.0]

The COLINFO record describes the column formatting for a column.

Record Data

Offset Name Size Contents
0 col 2 Column
2 grbit 2 Column width, in pixels
4 ixfe 2 Index to the XF record that contains the default format for the column

Parameters

grbit
The grbit field is set up as follows
Bit Size Name Contents
0 14 coldx Column width, in pixels
14 1 fHidden Set if the column is hidden
15 3 Unused Unused by Pocket Excel
