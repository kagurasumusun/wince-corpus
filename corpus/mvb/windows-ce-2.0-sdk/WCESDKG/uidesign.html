H/PC User Interface Design

Because the H/PC is designed to be a companion to Windows-based desktop PCs, the shell and the core applications look like their desktop counterparts. This leverages the end user's knowledge of Windows and starts many new Windows CE H/PC applications off with a solid base of existing consumers.

H/PC users will recognize elements of Windows desktop platforms such as a desktop, taskbar, windows, icons, cascading and drop-down menus, controls, and dialog boxes. These elements, described in the following table, allow the user to control the H/PC environment.

Desktop/Shell The desktop forms a visual background for all operations as well as provides a location to place objects stored in the file system.
Windows and Dialog Boxes Windows enable the user to view and interact with data. Consistency in window design is important because it enables users to easily transfer their learning skills and focus on tasks rather than learn new conventions. Dialog boxes differ from primary windows in their behavior and use. For example, dialog boxes do not appear on the taskbar. Additionally, dialog boxes obtain or display supplemental information related to objects appearing in a primary window.
Taskbar The taskbar is used to switch between open windows and access global commands and other frequently used objects. Similar to Windows 95 and Windows NT, the taskbar contains the Start button, window buttons, and a status area. It also contains a Desktop button that provides quick access to the Desktop from any application.
Menus The H/PC supports four types of menus: drop-down menus, pop-up menus, cascading menus, and scrolling menus. See the Windows CE User Interface Design Guide for information on designing menus.
Controls and Command Bars Controls are graphic objects that represent the properties or operations of other objects. The H/PC supports most common controls. It also supports controls specific to Windows CE including box select, date and time picker, edit control style, and gripper controls. Command bars are unique to the H/PC because they combine a menu bar, toolbar, and address bar. The H/PC supports multiple command bars. They each have gripper controls which enable users to hide buttons and menus.
User Input Devices The H/PC supports a keyboard and stylus, but does not support a mouse.
Help The H/PC supports online window-level help. It does not support field level help.

The user interface design guidelines for an H/PC generally follow the same conventions as the design guidelines presented in The Windows Interface Guidelines for Software Design and in Windows CE User Interface Design Guide.

However, the H/PC has limited screen space, no mouse, and supports user interaction devices such as a stylus and a touch-sensitive display screen. These features require additional design considerations.

The topics included in this guide discuss how to design an effective user interface specifically for the H/PC. Information is presented as a supplement, rather than a substitute, for the user interface design recommendations discussed in The Windows Interface Guidelines for Software Design and in Windows CE User Interface Design Guide.
