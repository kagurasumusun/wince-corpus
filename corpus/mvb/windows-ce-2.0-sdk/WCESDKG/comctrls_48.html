Property Sheet Notifications

The following property sheet notifications are the same in Windows CE as they are in Windows 95 and Windows NT.

PSN_APPLY

PSN_HELP

PSN_KILLACTIVE

PSN_QUERYCANCEL

PSN_RESET

PSN_SETACTIVE

Windows CE doesn't support the PSN_WIZBACK, PSN_WIZFINISH, PSN_WIZNEXT, or PSN_GETOBJECT notifications.
