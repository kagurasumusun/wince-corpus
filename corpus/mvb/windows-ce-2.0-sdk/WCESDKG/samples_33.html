Prun Sample

The Prun sample launches a specified program on the H/PC. The executable must exist on the H/PC. Prun searches the path on the H/PC and the .exe file ending is optional. No arguments to the executable are allowed. Prun uses the following Remote functions:
CeRapiInit

CeRapiUninit

CeCreateProcess

CeCloseHandle

To run the Prun sample program
  • Enter the following from the command line:

    prun [Program_name]

    For example, to run the calculator application, enter

    prun calc.
