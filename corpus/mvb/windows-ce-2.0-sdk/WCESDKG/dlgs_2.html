Common Dialog Boxes

A common dialog box is a system defined dialog box that provides a standardized way for users to perform complex operations that are common to most applications. Windows CE supports the Color, Print, Open, and Save As common dialog boxes.

The Color dialog provides users with a standardized way to select a color from a set of basic colors, determined by the display driver, or from a set of custom colors.

The Open common dialog box provides users with a way to select a file to open.

The Save As common dialog box provides users with a way to save a file under a name other than the name with which it was opened.

The Print dialog provides users with a standardized way to select print job options, such as the range of pages and the number of copies to print, and to start the printing process. In Windows CE, you cannot set page ranges. You have to either print the entire document or the currently selected portion. In Windows CE, you cannot specify the number of copies you want to print and can therefore, print only one copy at a time.

In Windows CE, there is no PrintSetup dialog box. However, a user can set the widths and minimum widths of the left, top, right, and bottom margins of the printed page by including values for the rcMargin and rcMinMargin fields of the PRINTDLG structure. The settings in the Print dialog box are always initialized to the current default printer. If the user has never used the Print dialog box before, the first printer registered in the registry is the default. After that, the last printer the user selected is the default.

In Windows CE, common dialog boxes are not movable; they are always centered vertically and horizontally on the screen. Common dialog boxes in Windows CE always have the Help button displayed.

In the current version of Windows CE, you cannot set page ranges or specify the number of copies to print. You can either print the entire document or the currently selected portion, and you can only print one copy at a time.
