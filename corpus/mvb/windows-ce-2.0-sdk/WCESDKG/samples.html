Windows CE Sample Applications

In addition to the sample code presented in the documentation, the Windows CE SDK provides a collection of sample applications illustrating various aspects of the development environment. For a detailed description of how to compile and run one of the samples, see Building the Sample Applications.

  • Generic Sample demonstrates the basic graphics and windowing functionality of Windows CE.

  • Etcha Sample demonstrates capturing mouse messages from the touch screen and using the Polyline function to draw the points captured by the application.

  • Reversi Sample demonstrates basic use of the Graphics Device Interface (GDI) for Windows CE.

  • Spintest Sample demonstrates the use of custom controls and the Windows CE GDI. The application displays a window with four quadrants in which a spinning cube is displayed.

  • Cmdbar Sample demonstrates some common buttons on the command bar and how to create, add bitmaps to, and destroy the command bar.

  • Treedir Sample demonstrates the file system API and tree controls. The application allows the user to browse the file system and display all directories and files by name.

  • Registry Sample demonstrates the registry API functions needed to access the H/PC registry.

  • Dbview Sample demonstrates the use of the Windows CE database functions

  • Ctlpnl Sample demonstrates creating a control panel DLL for Windows CE. The control panel displays the Backlight Properties dialog box containing the Backlight and General tab controls. The Ctlpnl sample does not actually implement the code to adjust the brightness of the touch screen, but rather provides a template for such an implementation.

  • HTMLview Sample demonstrates the notifications and structures for viewing Hypertext Markup Language which are defined in Htmlctrl.h.

  • TTY Sample demonstrates the Serial Communication API. It is a port of the Win32 TTY sample to the Windows CE environment. The terminal runs on the H/PC and the emulation can be monitored on the desktop PC using a terminal application such as HyperTerminal

  • Copyfilt Sample demonstrates the Windows CE file filter capabilities. Copyflt implements a file filter that imports a .bin file on the desktop PC to a .pbn file on the Windows CE device.

  • Remote API Samples demonstrate the Windows CE Remote APIs. The remote API samples are a collection of console applications run on the desktop PC.

  • Connection Notification Client Sample demonstrates the use of COM objects in Windows CE. The connection notification application (Cnxnotif.exe) registers with the H/PC connection manager, in order to receive notifications based on the connection and disconnection events that are handled by the connection manager.

  • Platname Sample demonstrates the Load_PegGetPlatformName function, which is used to distinguish between the SH3, MIPS R4100, and MIPS R3910 CPU types.

  • Svcsampl Sample demonstrates a transport service DLL that is used with the Windows CE Inbox client.
