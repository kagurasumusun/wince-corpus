Check Box Macros

You can use the following message cracker macros to send check box messages and to enable or disable a check box. These macros pack their parameters into the appropriate wParam/lParam format and then call SendMessage. For more information, refer to the macro definitions in Windowsx.h and the documentation for the corresponding button message. See Check Box Messages.

Button_Enable(hwndCtl, fEnable) (corresponds to the EnableWindow function)

Button_GetCheck(hwndCtl) Button_GetState(hwndCtl) Button_GetText(hwndCtl, lpch, cchMax) Button_GetTextLength(hwndCtl) Button_SetCheck(hwndCtl, check) Button_SetStyle(hwndCtl, style, fRedraw) Button_SetText(hwndCtl, lpsz)
