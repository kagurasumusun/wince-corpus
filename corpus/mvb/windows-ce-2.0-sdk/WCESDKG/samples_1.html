Building the Sample Applications

The sample applications can be built for a variety of devices using the SH3 CPU, the MIPS CPU, or the x86 Windows CE emulator running on a desktop PC, although not all of these options are available for each application. In addition, the sample applications can be compiled in either debug or release mode. The following example gives step-by-step instructions for building the Reversi Sample for the X86 emulator in debug mode. The process is analogous for the other applications and build configurations.

To compile the Reversi sample for the X86 emulator in debug mode
  1. On the File menu select Open Workspace.

  2. Navigate to the DevStudio\Wce\samples\Win32\Reversi directory. Select Reversi.dsw and click Open.

  3. On the Build menu select Set Active Configuration. The configurations available for this sample are displayed in the Select Active Configuration dialog box. Select reversi-Win32 (WCE x86em) debug. Click OK.

  4. On the Build menu select Rebuild All.

  5. If this is the first time you have built the sample for the specific configuration you will be prompted with a Copying Executable Path and File Name dialog box. Click OK.

When compiling has completed, on the Build menu select Execute Reversi.exe. To exit the H/PC emulator click the Start button on the emulator and select Suspend.
