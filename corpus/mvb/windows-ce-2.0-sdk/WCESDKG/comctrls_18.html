Header Control Macros

The following tab control macros are the same in Windows CE as they are in Windows 95 and Windows NT. You can use these macros to send header control messages. See Header Control Messages.

Header_DeleteItem

Header_GetItem

Header_GetItemCount

Header_InsertItem

Header_Layout

Header_SetItem

Windows CE also provides the following new header control macros to support the use of image lists, drag and drop functionality, and custom ordering of header control items.

Header_CreateDragImage

Header_GetImageList

Header_GetItemRect

Header_GetOrderArray

Header_OrderToIndex

Header_SetHotDivider

Header_SetImageList

Header_SetItem

Header_SetOrderArray
