Toolbar Buttons

Toolbar buttons are supported the same way in Windows CE as they are in Windows 95 and Windows NT. Toolbar buttons aren't child windows, like other buttons; they're bitmap images. When a user selects a toolbar button, the toolbar sends its parent window a WM_COMMAND message with the button's command identifier.

A toolbar button can display a string in addition to, or instead of, an image. The toolbar maintains an internal list of all the strings assigned to buttons. You add strings to the list by using the TB_ADDSTRING message.

If you want to assign a shortcut key to a toolbar button, you can use the button's tool tip to let the user know what the shortcut is. See Tool Tips for more information on adding shortcut information to tool tips.

Windows CE supports a new type of toolbar button, called a drop-down button. For more information, see New Features for Toolbars and Supporting Drop-Down Toolbar Buttons.
