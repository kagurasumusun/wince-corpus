Stylus Input

In many Windows CE environments, users interact with applications by using a stylus and a touch screen, rather than a mouse. The stylus and touch screen provide a direct and intuitive alternative to mouse interaction, without requiring extra space or a flat surface. Tapping the screen with a stylus has the same effect as clicking the left button on a mouse.

There's no direct equivalent of a right mouse-click event when using a stylus on a touch screen, but you should always handle an ALT+Tap action the same way you would handle a right-click mouse event. To handle ALT+Tap events, use the GetAsyncKeyState function to see if the ALT key (VK_MENU) is depressed when processing WM_LBUTTONDOWN messages. Don't use the GetKeyState function for this purpose because there may be a problem with timing issues. You can also use the GetAsyncKeyState function to determine the state of the stylus tip (up or down) on the touch screen, by using the virtual-key code constant VK_LBUTTON.

The stylus generates an input event whenever the user touches the screen with a. stylus or moves the stylus when the tip is touching the screen.Windows converts stylus input events into messages and posts them to the appropriate thread's message queue. When stylus messages are posted faster than a thread can process them, Windows discards all but the most recent stylus message.

Windows CE supports a new function, called GetMouseMovePoints. Normally, many points associated with WM_MOUSEMOVE messages are discarded because an application can't process them as fast as it receives them. This function retrieves these points, making it possible to improve inking performance by tracking stylus input at a higher resolution.

A window receives a stylus message when a stylus event occurs while the cursor is within the borders of the window, or when the window has captured the stylus. Stylus messages are divided into two groups: client area messages and nonclient area messages. Typically, an application processes client area messages and ignores nonclient area messages.
