Handling a Hibernation Message

When system resources are low, the shell sends a WM_HIBERNATE message to every application that has a button on the taskbar. If necessary, the shell repeats the message every five seconds until enough system resources are available to complete the current operation.

When an application receives the WM_HIBERNATE message, it should release as many system resources as possible. It can do this by unloading dialogs, destroying windows, and freeing up local storage. However, the application must preserve whatever information is necessary to restore it to its pre-hibernation state when it's reactivated.

An application can only receive the WM_HIBERNATE message if it has a button on the taskbar. To have a button on the taskbar, a window must be visible, it must be a top level window, and it must have the WS_OVERLAPPED style. If a window is hidden, it won't receive this message, even if it's a top-level overlapped window. For more information about taskbar buttons, see Using the Taskbar in Windows CE.

For more information on the WM_HIBERNATE message, see WM_HIBERNATE and Application Hibernation.
