Application Installation and Management

The Windows CE SDK uses cabinet (CAB) files as a self-contained setup package to install applications on a Windows CE platform. This allows installations from several sources, such as a desktop computer or a Website. The installation and removal of applications to and from the desktop is overseen by Application Manager. This section describes the methods and tools available for these processes.

In addition, other issues regarding the management of applications are dealt with here. These include registration of desktop file filters and synchronization services, addition of custom menu items, and access to partnership settings.
