Connecting to a Desktop PC

Easy and powerful connectivity to desktop PCs running Windows 95 is a key feature of the H/PC. Windows CE supports the following tasks:

  • Database Synchronization

    The ability to synchronize databases on the device with a corresponding database on the desktop PC. Windows CE automatically synchronizes the Schedule+ data on the desktop PC with the personal information manager applications on the device. You can write similar synchronization applications using RAPI functions.

  • Converting files

    Windows CE supports an API for converting files transferred between the desktop and the H/PC. For example, Microsoft Word documents are converted to a slightly different format when they are transferred to the HPC. Microsoft Pocket Word does not incorporate all of the features of Word on the desktop PC, so before a document can be transferred for use on the H/PC, items like unsupported fonts and OLE objects need to be converted or stripped from the file. Altering the files before they are transferred is accomplished with file filters.

    A file filter is a DLL that controls the transfer between the desktop PC and the device. The H/PC Explorer automatically adjusts file formats for some types of files and you can extend its file filtering capabilities by defining new application-specific filters of your own. See File Filters for more about existing filters and how to write new filters.

  • Installing applications

    A distinct set of functions and load file commands are supported for installing applications on the H/PC. These functions can be used to retrieve information about the H/PC, load application files, update the registry, and create a script for unloading the file App Install

  • Remote debugging

    The Windows CE Integrated Development Environment supports making remote connections for debugging applications. Remote debugging can be performed using either UDP or TCP/IP protocol. UDP is faster than TCP/IP, however it is not as reliable.
