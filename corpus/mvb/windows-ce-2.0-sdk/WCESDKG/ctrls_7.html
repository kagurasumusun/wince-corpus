Combo Box Styles

Windows CE supports most of the combo box styles Windows 95 and Windows NT support. It also supports a new extended style, called CBS_EX_CONSTSTRINGDATA. If you specify this style, when the application inserts a string into the list part of combo box, the combo box stores the pointer passed to it by the application rather than copying the string. This saves RAM resources when you have a large table of strings in ROM that you want to insert into a combo box.

All combo boxes in Windows CE have the LBS_HASSTRINGS style by default.

One popular combo box style Windows CE doesn't support is the CBS_SIMPLE style. This is the style in which the list box is always visible and the current selection is displayed in the edit control. Because of the inherent limitations on screen space in Windows CE-based devices, it's more efficient in Windows CE applications to use either the CBS_DROPDOWN or CBS_DROPDOWNLIST style than the CBS_SIMPLE style. In these styles, the list box isn't displayed until the user selects an icon next to the edit control. This conserves space on the screen. The difference between the CBS_DROPDOWN style and the CBS_DROPDOWNLIST style is that, instead of an edit control, the CBS_DROPDOWNLIST style has a static text field that always displays the current selection.

The following combo box styles are the same in Windows CE as they are in Windows 95 and Windows NT.

Style Description
CBS_AUTOHSCROLL Automatically scrolls the text in an edit control to the right when the user types a character at the end of the line. If this style is not set, only text that fits within the rectangular boundary is allowed.
CBS_DISABLENOSCROLL Shows a disabled vertical scroll bar in the list box when the box doesn't contain enough items to scroll. Without this style, the scroll bar is hidden when the list box doesn't contain enough items.
CBS_DROPDOWN Displays only the edit control by default. The user can display the list box by selecting an icon next to the edit control.
CBS_DROPDOWNLIST Similar to CBS_DROPDOWN, except that the edit control is replaced by a static text field that displays the current selection in the list box.
CBS_LOWERCASE Converts any uppercase characters entered into the edit control of a combo box to lowercase.
CBS_NOINTEGRALHEIGHT Specifies that the combo box will be exactly the size specified by the application when it created the combo box. Normally, Windows sizes a combo box so that it does not display partial items.
CBS_OEMCONVERT Converts text entered in the combo box edit control from the Windows character set to the OEM character set and then back to the Windows set. This style is most useful for combo boxes that contain file names, and applies only to combo boxes created with the CBS_DROPDOWN style.
CBS_SORT Automatically sorts strings entered into the list box.
CBS_UPPERCASE Converts any lowercase characters entered into the edit control of a combo box to uppercase.
WS_TABSTOP In a dialog box, any control with this style will be a tab stop when a user tabs through the controls.

Windows CE doesn't support the CBS_OWNERDRAWFIXED or CBS_OWNERDRAWVARIABLE styles for combo boxes.
