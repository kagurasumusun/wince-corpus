Binary Large OBject

  1. A Binary Large OBject is a large piece of data, such as a bitmap. It is characterized by large field values, an unpredictable table size, and data that is formless from the perspective of a program.

  2. A keyword designating the BLOB structure, which contains information about a block of data.

block mode

Block mode is a synchronous method of calling CeRapiInvoke by storing input parameters and output data in a single buffer.

Built-in Device Driver

A built-in device driver is software that is built into the Windows CE operating system to drive devices that are built into the Windows CE platform. A built-in driver consists of an MDD layer and a PDD layer, which makes it possible for user-level applications to access physically different, but functionally equivalent hardware resources such as a keyboard in the same way on all Windows CE platforms. See also MDD and PDD.
