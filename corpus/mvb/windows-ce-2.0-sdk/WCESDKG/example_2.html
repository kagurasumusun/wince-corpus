The Windows CE WinMain Function

As with other Windows-based programs, the WinMain function is the entry point to all applications written for Windows CE. The Windows CE WinMain function accepts the same four parameters as in other Windows-based programs with the following minor deviations:

  • hInstance. The handle to this instance of the program. This parameter is identical to the corresponding parameter in other Windows-based programs.

  • hPrevInstance. This parameter is obsolete for Windows CE and should always be NULL.

  • szCmdLine. Command line parameters. For Windows CE this parameter is a pointer to a wide string to accommodate UNICODE. The type has been changed from LPSTR to accept a LPTSTR.

  • nCmdShow. A flag indicating how the window should be displayed. Windows CE does not support all of the nCmdShow flags supported by Windows 95. A description of the flags can be found in the WinMain function section of the reference.
