Connection Notification Client Sample

The Connection Notification Client source code uses the IDccMan interface and implements the IDccManSink interface. The use of DCC in the module names and function names refers to Direct Cable Connect.

The connection notification application (Cnxnotif.exe) registers with the H/PC connection manager, in order to receive notifications based on the connection and disconnection events that are handled by the connection manager. This sample program implementation follows the basic steps outlined in the COM Interface-Based Notification section in the Connection Notification overview. The following table notes some of the key methods and functions used in the sample code.

Connection notification module
Description
Testdcc.cpp

Main Program

 Implements the interfaces and basic steps summarized in the COM Interface-Based Notification section.

1. Calls CoInitialize to initialize the COM library.

2. Registers with the connection manager by calling CoCreateInstance, using the registered CLSID_DccMan

3. Calls DoTestDccDlg (in Dlg.cpp) to invoke the "TestDcc Dialog Procedure".

4. Releases the IDccMan object by calling IDccMan::Release.

5. Releases the COM library by calling CoUninitialize.
Dlg.cpp

(Dialog Procedure)

 Creates the TestDCC dialog box that allows the user to exercise the IDccMan methods. The Send menu options provide a means to call the respective IDccMan methods (for example, IDccMan::ShowCommSettings). The dialog inputs are handled by the CTestDccDlg::DialogProc method.

This module also implements all of the OnLog* methods of the IDccManSink interface. These are called asynchronously by the connection manager, as connection events occur. In this sample, the OnLog* methods simply display a log message in the DCC Messages listbox of the TestDCC dialog box. This can serve as a simple test tool to identify various Connection Notification Scenarios.
Testdcc.h Includes definitions used by Testdcc.cpp and Dlg.cpp.
Resource.h Provides the definitions for the "TestDCC Resources" (Resource.rc).
Resource.rc Provides the resource definitions for the TestDCC dialog box.
