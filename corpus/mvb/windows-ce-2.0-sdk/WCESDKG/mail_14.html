Copying and Moving Messages

This paragraph describes how an application can move and copy messages in the store. To move an existing message, simply change the folder flag and pass the resulting MailMsg structure to MailUpdate. To copy a message, change the folder flag and pass the structure to MailPut.

This paragraph describes how the user can move and copy service-linked messages. When Inbox downloads messages from a service provider, it checks the copy and move status flags of all messages in the Inbox folder that belong to the service provider (specified by the szSvcID and szSvNam members of the MailMsg structure).

  • If MAIL_STATUS_MOVE is set, the message is moved to the specified folder.

  • If MAIL-STATUS_COPY is set, the message is copied to the specified folder, with the original message remaining in the Inbox folder.
