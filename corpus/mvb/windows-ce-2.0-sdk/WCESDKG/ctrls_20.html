List Box Macros

You can use the following message cracker macros to send list box messages. These macros pack their parameters into the appropriate wParam/lParam format and then call SendMessage. For more information, refer to the macro definitions in Windowsx.h and the documentation for the corresponding list box message. See List Box Messages.

ListBox_AddItemData(hwndCtl, data) (corresponds to LB_ADDSTRING)

ListBox_AddString(hwnd, lpsz) ListBox_DeleteString(hwndCtl, index)

ListBox_Enable(hwnd, fEnable) (corresponds to the EnableWindow function)

ListBox_FindItemData(hwndCtl, indexStart, data) (corresponds to LB_FINDSTRING)

ListBox_FindString(hwndCtl, indexStart, lpszFind) ListBox_FindStringExact(hwndCtl, indexStart, lpszFind) ListBox_GetCaretIndex(hwndCtl) ListBox_GetCount(hwndCtl) ListBox_GetCurSel(hwndCtl) ListBox_GetHorizontalExtent(hwndCtl) ListBox_GetItemData(hwndCtl, index) ListBox_GetItemHeight(hwndCtl, index) ListBox_GetItemRect(hwndCtl, index, lprc) ListBox_GetSel(hwndCtl, index) ListBox_GetSelCount(hwndCtl) ListBox_GetSelItems(hwndCtl, cItems, lpItems) ListBox_GetText(hwndCtl, lpch, lpszBuffer) ListBox_GetTextLength(hwndCtl, index) ListBox_GetTopIndex(hwndCtl)

ListBox_InsertItemData(hwndCtl, index, data) (corresponds to LB_INSERTSTRING)

ListBox_InsertString(hwndCtl, index, lpsz) ListBox_ResetContent(hwndCtl)

ListBox_SelectItemData(hwndCtl, indexStart, data) (corresponds to LB_SELECTSTRING)

ListBox_SelectString(hwndCtl, indexStart, lpszFind) ListBox_SelItemRange(hwndCtl, fSelect, first, last) ListBox_SetCaretIndex(hwndCtl, index) ListBox_SetColumnWidth(hwndCtl, cxColumn) ListBox_SetCurSel(hwndCtl, index) ListBox_SetHorizontalExtent(hwndCtl, cxExtent) ListBox_SetItemData(hwndCtl, index, data) ListBox_SetItemHeight(hwndCtl, index, cy) ListBox_SetSel(hwndCtl, fSelect, index) ListBox_SetTabStops(hwndCtl, cTabs, lpTabs) ListBox_SetTopIndex(hwndCtl, indexTop)

Windows CE doesn't support the ListBox_Dir macro.
