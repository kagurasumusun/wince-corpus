Filter Defined Error Values

Typically, a file filter function returns NOERROR if it succeeds or an HRESULT error code if it fails (using the HRESULT_FROM_WIN32 macro). Alternatively, the NextConvertFile function can return a filter-defined error code in the variable pointed to by the perr parameter. The error code must be defined by using the CF_DECLARE_ERROR macro defined in the Replerr.h header file, and the filter DLL must include a message table that contains the error code and a corresponding message string. When the Windows CE Services receives the filter-defined error code, it uses the Win32 FormatMessage function to create the error string, checking the filter object first for the relevant string (using ICeFileFilter::FormatMessage). For more information about message tables, see the Error Handling topics in the Win32 Programmer's Reference.
