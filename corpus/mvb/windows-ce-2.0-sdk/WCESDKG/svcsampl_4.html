Registry Entries Used by Inbox and the Transport Service

Following are descriptions of the registry values under the example MyMail subkey that are specific to, and set by, the transport but are also used by Inbox. These registry values are usually set by the Service Definition dialog that gets called when a mail service (for example MyMail) is being added. Note that, once the MyMail service is connected, these and other values under the MyMail registry subkey may be modified or added by the service's TransportProps routine.

Note The "Type" entry in the table defines the registry value type.

Registry Value Type Description
CopyMaxLines REG_DWORD Maximum number of messsage body lines to copy from the server.

This value is relevant only if the CopyAllLines value is set to zero.
CopyAllLines REG_DWORD If non-zero, indicates that the entire message body should be copied from the server.

If this value is zero, then CopyMaxLines lines of the message body are copied.
GrabRead REG_DWORD Indicates whether a remote message should be saved locally when it is read from the server.

If the TypeOfGrab (below) value is one (1), then the messages are not remote. GrabRead will be ignored.

If this value is not zero, then the remote message is saved locally.

If this value is zero, then the remote message is not stored locally when read (note that if your service allows this option, messages with attachments and non-IPM messages will not work properly in this scenario).
TypeOfGrab REG_DWORD Indicates whether only the message header or the entire message should be copied from the server.

If this value is zero, then only the message headers are copied.

If this value is one, then the entire messages, headers and bodies, are copied. However, the amount of the body to be copied is limited to CopyMaxLines.
SvcAutoDisco REG_DWORD Indicates whether Inbox should force an automatic disconnect when after the service is done sending or receiving messages.

If this value is zero, the user must manually disconnect the service.

If this value is one, Inbox automatcally disconnects the service after performing a connect and the implied send and receive operations.
NewMailNotify REG_DWORD Indicates what type of notification Inbox should perform when a new message arrives.

If this value is zero, Inbox plays a beep.

If this value is one, Inbox plays a beep and also displays a message box.
RefreshTime REG_DWORD Number of minutes between refreshes. This is relevant only if the DoRefresh value is one.
DoRefresh REG_DWORD Indicates whether messages should periodically be refreshed (that is, disconnect and reconnect to the service to get messages); the interval is defined by the RefreshTime registry value.

If this value is zero, then Inbox does not do a periodic refresh.

If this value is one, then Inbox does a refresh every RefreshTime minutes.
SvcAddrBook REG_SZ A Unicode string that indicates which address book (data base contacts) field to use for queries. For example, SvcAddrBook could be set to one of the following values:

"Internet"

"2-Way Paging"

Each of these strings is a long name (a "property name") of a database property. This property name can be obtained by specifying a property with a call to GetPropertyDataStruct function. GetPropertyDataStruct also returns a database position index of the specified property.

The property name returned can then be used with GetMatchingEntry.

Note that the transport service can set SvcAddrBook to the long name of any property identifier to be searched. For a list of property identifiers, see Properties and Property Tags.

SvcRemember REG_DWORD Indicates whether the password should be remembered.

If this value is zero, Inbox displays a dialog and prompts the user for a password each time the service connects. If this value is one, the password is remembered, and Inbox does not display the dialog.
SvcRtn REG_SZ A Unicode string that defines the default return address to use. On a "Reply", Inbox will place this string in the "From:" field of the message header.

The service driver could check and/or modify this entry, to provide an appropriate or desired return address.
SvcPass REG_SZ A Unicode string that stores (remembers) the password provided at the time of logon.
SvcKey REG_SZ An encrypted unicode string that identifies the registry key that corresponds to the currently connected service; this key is under the ServiceLibs subkey.

This indicates to Inbox the DLL that is to be loaded when the SvcName service is connected by the user within the Inbox application.

See the topic, Registering a Transport Service.
