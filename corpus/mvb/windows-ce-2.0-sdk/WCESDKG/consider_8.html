Remote Debugging

In addition to desktop emulation, theWindows CE IDE contains several tools that enable you to examine your application as it runs on a Windows CE device. The remote tools are described in the following table.

Tool Purpose
Remote Connection Server Creates a network connection between your desktop PC and the H/PC. The Remote Connection Server will not perform synchronization between the remote device and the desktop PC.
Remote Zoomin Enlarges a section of the H/PC screen.
Remote Registry Editor Edits the Windows CE registry. Since there is no tool like RegEdit on the H/PC, you view and edit the H/PC registry using this desktop tool.
Remote Object Viewer Allows you to view the object store on a remote H/PC device and on your desktop PC.
Remote Spy Displays a graphical view on a desktop computer of the system processes, threads, windows, and window messages that are running on a remote Windows CE device.

In order to use the remote tools, you must connect your desktop computer to your remote device with a standard serial cable connection. See your user's guide for information on how to physically connect your desktop and remote device. Read the following for additional information on setting up the software link.
