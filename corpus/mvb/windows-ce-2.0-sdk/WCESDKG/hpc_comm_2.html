Using the Built-In Serial Port

The built-in 9 pin serial port on the H/PC operates identically to RS232-compliant serial ports on a desktop PC. Windows CE provides support for applications that communicate over the built-in 9 pin serial port by exposing many of the serial and file functions as well as Windows Socket functions used by Windows 95 communications applications.

Unlike Windows 95 and Windows NT, the Windows CE CreateFile function requires a ':' (colon) appended to the device name. In most cases, COM1: designates the built-in serial port on an H/PC.
