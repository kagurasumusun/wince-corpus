Prolog and Epilog

The prolog contains the code that sets up the stack frame for a routine. The epilog contains the code that removes the routine's frame and then returns from the routine.

The Virtual Unwinder emulates a subset of the instructions in prolog and epilog code to reconstruct the context which existed upon entry to a routine. This subset includes adding or subtracting a value from a register, loading or storing a register on the stack frame, loading integer constants into registers, moves between integer registers, and copying the PR register to an integer register. Other instructions found in the prolog or epilog sequences will be ignored.

To make the unwinding process as efficient as possible, only a small subset of the SH-3 instruction set is emulated. This section lists the instruction forms that are emulated in prolog and epilog code.
