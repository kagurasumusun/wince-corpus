Registers

The SH-3 has 16 general purpose registers. This calling convention assigns them to the following roles.


R0
Return Value - Temporary Register (Note 1)

R1-R3
Temporary Registers

R4-R7
Arguments - Temporary Registers (Note 2)

R8-R13
Permanent Registers

R14
Frame Pointer - Permanent Register (Note 3)

R15
Stack Pointer - Permanent Register





Note:
1. R0 is used as a temporary register when expanding assembly language pseudo-instructions. It is also used as an implicit source or destination in byte and 16-bit operations. Finally, it holds the return value on return from a function.

Note:
2. Registers R4 through R7 hold the first four words of incoming arguments. Remaining arguments are constructed in the caller’s argument build area which also provides space into which R4 through R7 may be spilled.

Note:
3. R14 is the recommended frame pointer. Any other permanent register may serve as the frame pointer, and leaf routines may even use a temporary register as the frame pointer. A frame pointer is needed to access frame data in functions which use the alloca() intrinsic. A frame pointer may also be established by a function to allow for more efficient access to frame data in larger stack frames. If a frame pointer is not established by a function, or if another register is used as the frame pointer, then R14 may be used for other purposes.
