Special Prologs

Prolog and Epilog

In addition to the standard prologs which have been previously detailed, there are several varieties of special prologs used within system code. Crafting these prologs involves detailed knowledge of the SEH mechanism that is beyond the scope of this document

Most special prologs are never actually executed and are preceded by a comment indicating this. They exist only to be decoded and interpreted by the Virtual Unwinder. These prologs are created for such special cases as trap vector entry points and implementing the GetContextThread and SetContextThread system services.

Typically, prologs only save permanent registers to the stack when they need to be used by the callee. There are special cases however where the prolog saves all permanent registers to the stack. Examples are the exception dispatch function, which needs the values of all registers so it can build a ContextRecord, and the context swapper, where the values of all registers need to be saved before swapping to a new thread.

Prologs such as these often contain special instruction sequences which are recognized and treated specially by the unwinder.
