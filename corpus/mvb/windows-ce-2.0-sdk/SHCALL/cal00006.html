Return Values

A single-word integer and integer-equivalent return value is returned in R0.

Single-precision floating-point values are returned in R0.

For structure return values which are more than 4 bytes in size, the caller allocates re-entrant memory (i.e., on the stack in the locals area) for the return value and passes a pointer to that memory as the first argument in the call (i.e., in R4). Before returning, the callee copies the return value to the memory locations indicated by this first argument. This pointer is also returned in R0.

Structs or unions which are 4 bytes or less in size are returned in R0.

64-bit integer and 64-bit floating point values are returned via the same method used to return structs more than 4 bytes in size.
