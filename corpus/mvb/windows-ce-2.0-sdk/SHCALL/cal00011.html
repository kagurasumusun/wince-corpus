Assembler Macros

This section presents a list of assembler-level macros used to isolate the programmer from the details involved with using Assembler Directives. (Some of these macros are not related to calling sequence but are listed here to provide a complete list of available macros.) These macros are available in the header file kxsh3.h.

START_REGION NameBegin

END_REGION NameEnd

NESTED_ENTRY Name[,[Section=]SectionName]

LEAF_ENTRY Name[,[Section=]SectionName]

NESTED_BIGENTRY Name[,[Section=]SectionName]

LEAF_BIGENTRY Name[,[Section=]SectionName]

ALTERNATE_ENTRY Name[,[Section=]SectionName]

ENTRY_END [Name]

EXCEPTION_HANDLER Handler

EXCEPTION_HANDLER_DATA Handler,HandlerData

PROLOG_END
