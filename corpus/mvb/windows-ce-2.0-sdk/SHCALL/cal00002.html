alloca()

Dynamic memory allocated on the stack outside of a routine's prolog, typically via the compiler's alloca intrinsic.

alloca() local

Dynamic memory allocated on the stack outside of a routine's prolog, typically via the compiler's alloca intrinsic.

callee

A routine that is invoked by another routine, particularly when discussing code near the callee's prolog and epilog.

caller

A routine that invokes another routine, particularly when discussing code near the actual call.

context

Also, context record. The processor state at a specific point in time. It includes the contents of all registers, including special processor registers, and the current instruction pointer. When reconstructed by walking the stack, only the contents of the permanent registers and the instruction pointer are accurate.

epilog

The epilog is the code following the routine's last executable statement up to and including the return instruction. This code restores preserved register values, releases the allocated stack frame, and returns to the calling routine.

frame pointer

The address of a fixed reference point in a routine's stack frame; a register containing such an address.

leaf routine

A routine which does not call another routine.

permanent register

Also called a callee-save register, a permanent register is assumed to be preserved across a call.

prolog

The prolog is the live code which sets up the routine's stack frame and is between the routine's entry point and the code for its first executable statement. This is the traditional definition.

RSA

The register save area allocated at the top of the stack frame to save permanent registers that are modified in the routine. If necessary, the return address is also saved in this area.

SEH

Structured exception handling.

stack frame

A routine's activation record as declared by its prolog.

stack pointer

The address of the lowest addressed word in a routine's stack frame; a register containing such an address. R15 is always the designated stack pointer

temporary register

Also called a caller-save register, a temporary register is assumed to be destroyed across a call.

varargs

The technique of passing a variable number of arguments to a callee that is capable of walking the list. ANSI C defines a safe mechanism but existing system and application source code is full of unsafe abuses of that mechanism.

virtual unwinding

This is the process used by SEH and other run-time facilities to walk up the stack. Starting with a context record and an instruction address, the unwinding process interprets instructions in a function’s prolog or epilog to reconstruct the context as it existed on entry to the function.
