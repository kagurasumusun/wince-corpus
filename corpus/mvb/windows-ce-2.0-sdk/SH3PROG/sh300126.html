8.2.3 Slot Length

The number of states (system clock cycles) S for the execution of one slot is calculated with the following conditions:

S = (the cycles of the stage with the highest number of cycles of all instruction stages contained in the slot)This means that the instruction with the longest stage stalls others with shorter stages.The number of execution cycles for each stage:

IThe number of memory access cycles for instruction fetch

IAlways one cycle

EAlways one cycle

MThe number of memory access cycles for data access

WAlways one cycle
