6.57 SHAL (Shift Arithmetic Left): Shift Instruction

Format
Abstract
Code
Cycle
T Bit
SHAL Rn

Description:

Arithmetically shifts the contents of general register Rn to the left by one bit, and stores the result in Rn. The bit that is shifted out of the operand is transferred to the T bit (figure 6.8).


Figure 6.8 Shift Arithmetic Left

Operation:

SHAL(long n) /* SHAL Rn (Same as SHLL) */

{

if ((R[n]&0x80000000)==0) T=0;

else T=1;

R[n]<<=1;

PC+=2;

}

Example:

SHAL R0 Before execution R0 = H'80000001, T = 0

After execution R0 = H'00000002, T = 1
