6.38 MOVT (Move T Bit): Data Transfer Instruction

Format
Abstract
Code
Cycle
T Bit
MOVT Rn
T Rn
0000nnnn00101001
1
-

Description:

Stores the T bit value into general register Rn. When T = 1, 1 is stored in Rn, and when T = 0, 0 is stored in Rn.

Operation:

MOVT(long n) /* MOVT Rn */

{

R[n]=(0x00000001 & SR);

PC+=2;

}

Example:

XOR R2,R2 R2 = 0

CMP/PZ R2 T = 1

MOVT R0 R0 = 1

CLRT T = 0

MOVT R1 R1 = 0
