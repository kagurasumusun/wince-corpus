6.14 CLRMAC (Clear MAC Register): System Control Instruction

Format
Abstract
Code
Cycle
T Bit
CLRMAC
0 MACH, MACL
0000000000101000
1
-

Description:

Clears the MACH and MACL registers.

Operation:

CLRMAC() /* CLRMAC */

{

MACH=0;

MACL=0;

PC+=2;

}

Example:

CLRMAC Initializes the MAC register

MAC.W @R0+,@R1+ Multiply and accumulate operation

MAC.W @R0+,@R1+
