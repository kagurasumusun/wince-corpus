6.59 SHLD (Shift Logical Dynamically): Shift Instruction

Format
Abstract
Code
Cycle
T Bit
SHLD Rm,Rn
Rn << Rm Rn (Rm ³ 0)
Rn >> Rm Rn (Rm < 0)
0100nnnnmmmm1101
2
-

Description:

Arithmetically shifts the contents of general register Rn. General register Rm indicates the shift direction and shift count (figure 6.10). T bit is the last shifted bit of Rn.

Shift directionRm ³ 0, left
Rm < 0, rightShift count: Rm (4-0) are used; if negative, two's complement is set to Rm.
The maximum magnitude of the left shift count is 31 (0-31).
The maximum magnitude of the right shift count is 32 (1-32).


Figure 6.10 Shift Logical Dynamically

Operation:

SHLD(long m,n) /* SHLD Rm,Rn */

{

long cont, sgn;

sgn = R[m]&0x80000000;

cnt = R[m]&0x0000001F);

if (sgn==0) R[n]<<=cnt;

else R[n]=R[n]>>((~cnt+1)&0x1F);

PC+=2;

}

Example:

SHLD R1,R2 Before execution R1 = H'FFFFFFEC, R2 = H'80180000

After execution R1 = H'FFFFFFEC, R2 = H'00000801
