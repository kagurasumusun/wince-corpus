Indirect register addressing with displace-ment
@(disp:4, Rn)
The effective address is Rn plus a 4-bit displacement (disp). The value of disp is zero-extended, and remains the same for a byte operation, is doubled for a word operation, and is quadrupled for a longword operation.


Byte: Rn + disp
Word: Rn + disp 2
Longword: Rn + disp 4

Indirect indexed register addressing

The effective address is the Rn value plus R0.

Indirect GBR addressing with displace-ment
@(disp:8, GBR)
The effective address is the GBR value plus an 8-bit displacement (disp). The value of disp is zero-extended, and remains the same for a byte operation, is doubled for a word operation, and is quadrupled for a longword operation.


Byte: GBR + disp
Word: GBR + disp 2
Longword: GBR + disp 4

Indirect indexed GBR addressing

@(R0, GBR)

Indirect PC addressing with displace-ment
@(disp:8, PC)
The effective address is the PC value plus an 8-bit displacement (disp). The value of disp is zero-extended, and remains the same for a byte operation, is doubled for a word operation, and is quadrupled for a longword operation. For a longword operation, the lowest two bits of the PC are masked.


Word: PC + disp 2
Longword: PC & H'FFFFFFFC + disp 4
