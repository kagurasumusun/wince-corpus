6.75 XTRCT (Extract): Data Transfer Instruction

Format
Abstract
Code
Cycle
T Bit

Description:

Extracts the middle 32 bits from the 64 bits of general registers Rm and Rn, and stores the 32 bits in Rn (figure 6.15).


Figure 6.15 Extract

Operation:

XTRCT(long m,long n) /* XTRCT Rm,Rn */

{

unsigned long temp;

temp=(R[m]<<16)&0xFFFF0000;

R[n]=(R[n]>>16)&0x0000FFFF;

R[n]|=temp;

PC+=2;

}

Example:

XTRCT R0,R1 Before execution R0 = H'01234567, R1 = H'89ABCDEF

After execution R1 = H'456789AB
