List of CPU Instructions

Tables Table 2-5 through Table 2-19 list CPU instructions common to MIPS R- Series processors, along with those instructions that are extensions to the instruction set architecture. The extensions result in code space reductions, multiprocessor support, and improved performance in operating system kernel code sequences-for instance, in situations where run-time bounds-checking is frequently performed. Table 2-18 lists CP0 instructions.
