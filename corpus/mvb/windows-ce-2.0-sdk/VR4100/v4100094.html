6.1 VR4100 Signals

This chapter describes the signals used by and in conjunction with the VR4100 processor. The signals include the System interface, the Clock/Control interface, the Interrupt interface, and the Initialization interface.

Signals are listed in bold, and low active signals have a trailing asterisk—for instance, the low-active External Request signal is EReq. The signal description also tells if the signal is an input (the processor receives it) or output (the processor sends it out).
