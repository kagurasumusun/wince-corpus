Handshake Signals

The processor manages the flow of requests through the following six control signals:

ERdy is used by the external agent to indicate when it can accept a new read or write transaction.

EReq, PMaster and PReq are used to transfer control of the SysAD and SysCmd buses. EReq is used by an external agent to indicate a need to control the interface. PMaster is de-asserted by the processor when it transfers control of the System interface to the external agent. And PReq is used by the processor to indicate a need to bus, when the processor is in slave state.

The VR4100 processor uses PValid and the external agent uses EValid to indicate valid command/data on the SysCmd/SysAD buses.
