TLB Misses

If there is no TLB entry that matches the virtual address, a TLB refill (miss) exception occurs. (TLB miss exceptions are described in Chapter 5.) If the access control bits (D and V) indicate that the access is not valid, a TLB Modification or TLB Invalid exception occurs. If the C bits equal 0102, the physical address that is retrieved accesses main memory, bypassing the cache.
