MIPS Calling Conventions

Visual C++ for Windows CE supports two MIPS calling conventions: __cdecl and __fastcall. __cdecl is the default convention. It corresponds to the calling convention documented in “MIPS RISC Architecture” in Learning MIPS Assembly Language.

The /Gd compiler switch will return structs for the __cdecl convention for any function not specifically declared with another convention. __fastcall returns small structs (those of less than 8 bytes) in registers instead of returning them on the stack as __cdecl would. The command-line switch is /Gr. Either of the above conventions can be selected through the Project Settings dialog box from the Build menu, C/C++ tab, Code Generation options.

There is no __stdcall convention. The /Gz compiler switch will generate a warning from the compiler. It is important to note that the MIPS __cdecl and __fastcall conventions are not the same as the x86 conventions of the same names.

For more information on the MIPS calling convention, see the book MIPS RISC Architecture by Gerry Kane and Joe Hendrich, published by Prentice-Hall (ISBN 0-13-59072-2).
