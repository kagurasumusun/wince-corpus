MIPS Assembly Language Example

With the MIPS edition of the Visual C++ compiler, the _ _asm statement introduced in the previous chapter is especially flexible and powerful. You use the _ _asm statements within C/C++ source code in many different ways. This section provides an example that shows some of the fine points of the _ _asm statement, illustrates how instructions are generated, and shows how inline assembly code interacts with surrounding C/C++ source code.

The MIPS instruction set is designed to be used with optimizing compilers. The Microsoft Visual C++ for Windows CE MIPS compiler (CLMIPS.EXE) generates high-quality MIPS assembly-language code. Therefore, use _ _asm statements only when necessary; for example, when the Visual C++ compiler is not optimizing a certain section of code to your expectations. The example shown here has been designed to illustrate the use of _ _asm statements; they are not inherently any more efficient than the code typically produced directly by the Visual C++ compiler.
