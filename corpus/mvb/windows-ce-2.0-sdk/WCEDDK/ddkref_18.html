ACM_Open

PVOID ACM_Open(DWORD dwData, DWORD dwAccess, DWORD dwShareMode)

Device open routine

Return Value

Returns a DWORD which will be passed to Read, Write, etc or NULL if unable to open device.

Parameters
dwData
Value returned from ACM_Init call (ignored)
dwAccess
Requested access (combination of GENERIC_READ and GENERIC_WRITE) (ignored)
dwShareMode
Requested share mode (combination of FILE_SHARE_READ and FILE_SHARE_WRITE) (ignored)
