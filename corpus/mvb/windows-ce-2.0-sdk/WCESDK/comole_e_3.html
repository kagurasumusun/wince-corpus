FUNCKIND

The FUNCKIND enumeration lists various kinds of access of a function.

Syntax

typedef enum tagFUNCKIND {
FUNC_VIRTUAL,
FUNC_PUREVIRTUAL,
FUNC_NONVIRTUAL,
FUNC_STATIC,
FUNC_DISPATCH,
} FUNCKIND;
