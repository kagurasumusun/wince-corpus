PFF_DESTINATIONFILE

The PFF_DESTINATIONFILE structure contains information about a destination file. A file filter uses the information to write the converted data to the file.

Syntax

typedef struct tagPFF_DESTINATIONFILE{
 TCHAR szFullpath[_MAX_PATH];
 TCHAR szPath[_MAX_PATH];
 TCHAR szFilename[_MAX_FNAME];
 TCHAR szExtension[_MAX_EXT];
} PFF_DESTINATIONFILE;

At a Glance

Header file: Replfilt.h
Module/Component:
Platforms:
Versions: 1.0 and later

Members

szFullpath
Specifies the default full path of the destination file. For example: "C:\Temp\Myfont.fnt".
szPath
Specifies the path of the directory where the destination file should be created. For example: "C:\Temp".
szFilename
Specifies only the default name of the destination file. For example, if the destination file name is Myfont.fnt, then the value of szFilename is "Myfont".
szExtension
Specifies the file name extension of the destination file. For example, "fnt".

Remarks

Note that szFullpath and szFilename are described as default values since the file filter is allowed to modify the name of the destination file. For example, the Font file converter creates "Arial8.fnt" and "Arial10.fnt" from Arial.Ttf when the user selects the 8-point and 10-point font sizes. Note, however, that changing file names and creating multiple destination files only works when importing files from the desktop PC to the target device, and not when exporting files from the target device to the desktop PC.

Remarks

This is for Windows CE version 1.0. For version 2.0 see CFF_DESTINATIONFILE.
