PROPSHEETPAGE

The PROPSHEETPAGE structure defines a page in a property sheet.

Syntax

typedef struct _PROPSHEETPAGE { // psp
 DWORD dwSize;
DWORD dwFlags;
HINSTANCE hInstance;
union {
 LPCSTR pszTemplate;
LPCDLGTEMPLATE pResource;
};
union {
 HICON hIcon;
LPCSTR pszIcon;
};
 LPCSTR pszTitle;
DLGPROC pfnDlgProc;
LPARAM lParam;
LPFNPSPCALLBACK pfnCallback;
UINT FAR * pcRefParent;
} PROPSHEETPAGE, FAR *LPPROPSHEETPAGE;

typedef const PROPSHEETPAGE FAR *LPCPROPSHEETPAGE;

Remarks

The following dwFlags values are not supported:
PSP_USEHICON

PSP_USEICONID

The hIcon and pszIcon members are not used.

Windows CE versions 2.0 and later support a new flag, PSP_PREMATURE, for the dwFlags field. Setting this flag causes the page to be created when the property sheet is created. Normally, the page isn't created until the first time it's selected.
