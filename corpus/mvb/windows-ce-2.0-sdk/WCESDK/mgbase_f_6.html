GetCurrentObject

The GetCurrentObject function returns the currently selected object of the specified type.

Syntax

HGDIOBJ GetCurrentObject(HDC hdc, UINT uObjectType);

At a Glance

Header file: Wingdi.h
Component: mgbase
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE version 1.0 does not support the OBJ_PAL flag value for the uObjectType parameter.

In Windows CE version 2.0, this function is exactly the same as it is in Windows desktop platforms.
