DestroyMenu

The DestroyMenu function destroys the specified menu and frees any memory that the menu occupies.

Syntax

BOOL DestroyMenu(HMENU hMenu);

At a Glance

Header file: Winuser.h
Component: menu
Platforms: H/PC
Windows CE versions: 1.0 and later
