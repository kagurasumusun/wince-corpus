BITMAPINFO

The BITMAPINFO structure defines the dimensions and color information of a Windows-based device-independent bitmap (DIB).

Syntax

typedef struct tagBITMAPINFO {
BITMAPINFOHEADER bmiHeader;
RGBQUAD bmiColors[1];
} BITMAPINFO;
