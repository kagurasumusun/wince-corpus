ListView_SetItemCount

The ListView_SetItemCount macro prepares a list view control for adding a large number of items. You can use this macro or explicitly send the LVM_SETITEMCOUNT message.

Syntax

void ListView_SetItemCount(
 HWND hwnd,
 int cItems
);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later
Related message: LVM_SETITEMCOUNT
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE version 2.0 and later, if the list view control is a virtual list view (has the LVS_OWNERDATA style), use the ListView_SetItemCountEx macro instead.
