IErrorInfo : IUnknown

The IErrorInfo interface provides detailed contextual error information.

At a Glance

Header file: Oaidl.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Method Description
IErrorInfo::GetDescription The IErrorInfo::GetDescription method returns a textual description of the error.
IErrorInfo::GetGUID The IErrorInfo::GetGUID method returns the globally unique identifier (GUID) of the interface that defined the error.
IErrorInfo::GetHelpContext The IErrorInfo::GetHelpContext method returns the Help context identifier (ID) for the error.
IErrorInfo::GetHelpFile The IErrorInfo::GetHelpFile method returns the path of the Help file that describes the error.
IErrorInfo::GetSource The IErrorInfo::GetSource method returns the language-dependent programmatic ID (ProgID) for the class or application that raised the error.
