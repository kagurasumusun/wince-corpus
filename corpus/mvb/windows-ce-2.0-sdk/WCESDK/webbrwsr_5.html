DWebBrowserEvents::NavigateComplete

The NavigateComplete method notifies an application that the Web browser control has successfully navigated to a new location. The document may still be downloading, but at least part of the document has been received from the server and the viewer for the document has been created.

Syntax

void NavigateComplete (
 BSTR URL,
);
