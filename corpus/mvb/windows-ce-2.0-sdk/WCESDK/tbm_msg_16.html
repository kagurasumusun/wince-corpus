TBM_SETLINESIZE

The TBM_SETLINESIZE message sets the size of the line for a trackbar. The line size affects how much the slider moves for the TB_LINEUP and TB_LINEDOWN notification messages.

Syntax

TBM_SETLINESIZE
wParam = 0;
lParam = (LONG) lLineSize;
