WNetConnectionDialog1

The WNetConnectionDialog1 function brings up a general browsing dialog for connecting to network resources.

Syntax

DWORD WNetConnectionDialog1(LPCONNECTDLGSTRUCT lpConnectDlgStruc);

At a Glance

Header file: Winnetwk.h
Module: Rdrapi
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE ignores the dwDevNum member of the CONNECTDLGSTRUCT structure pointed to by the lpConnectDlgStruc parameter.

In Windows CE the dwFlag parameter can be either CONNDLG_RO_PATH or 0.
