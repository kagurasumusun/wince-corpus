AddressCard

The AddressCard structure contains information stored in an address card.

Syntax

typedef struct _AddressCard {
 SYSTEMTIME stBirthday;
SYSTEMTIME stAnniversary;
TCHAR *pszBusinessFax;
TCHAR *pszCompany;
TCHAR *pszDepartment;
TCHAR *pszEmail;
TCHAR *pszMobilePhone;
TCHAR *pszOfficeLocation;
TCHAR *pszPager;
TCHAR *pszWorkPhone;
TCHAR *pszTitle;
TCHAR *pszHomePhone;
TCHAR *pszEmail2;
TCHAR *pszSpouse;
TCHAR *pszNotes;
TCHAR *pszEmail3;
TCHAR *pszHomePhone2;
TCHAR *pszHomeFax;
TCHAR *pszCarPhone;
TCHAR *pszAssistant;
TCHAR *pszAssistantPhone;
TCHAR *pszChildren;
TCHAR *pszCategory;
TCHAR *pszWebPage;
TCHAR *pszWorkPhone2;
TCHAR *pszNamePrefix;
TCHAR *pszGivenName;
TCHAR *pszMiddleName;
TCHAR *pszSurname;
TCHAR *pszGeneration;
TCHAR *pszHomeAddrStreet;
TCHAR *pszHomeAddrCity;
TCHAR *pszHomeAddrState;
TCHAR *pszHomeAddrPostalCode;
TCHAR *pszHomeAddrCountry;

TCHAR *pszOtherAddrStreet;
TCHAR *pszOtherAddrCity;
TCHAR *pszOtherAddrState;
TCHAR *pszOtherAddrPostalCode;
TCHAR *pszOtherAddrCountry;

TCHAR *pszOfficeAddrStreet;
TCHAR *pszOfficeAddrCity;
TCHAR *pszOfficeAddrState;
TCHAR *pszOfficeAddrPostalCode;
TCHAR *pszOfficeAddrCountry;

BYTE *rgbReserved[84]
} AddressCard;

At a Glance

Header file:
Component:
Platforms: H/PC
Windows CE versions: 1.0 and later

Members

stBirthday
A SYSTEMTIME structure that contains the subject's date of birth.
stAnniversary
A SYSTEMTIME structure that contains the date of the subject's anniversary.
pszBusinessFax
Pointer to the telephone number of the subject's business fax machine.
pszCompany
Pointer to the name of the company for which the subject works.
pszDepartment
Pointer to the name of the department in which the subject works.
pszEmail
Pointer to the subject's electronic mail alias.
pszMobilePhone
Pointer to the telephone number of the subject's mobile telephone.
pszOfficeLocation
Pointer to the location of the subject's business office.
pszPager
Pointer to the telephone number of the subject's pager.
pszWorkPhone
Pointer to the work telephone number of the subject.
pszTitle
Pointer to the subject's job title.
pszHomePhone
Pointer to the subject's home telephone number.
pszEmail2
Pointer to the subject's second email alias.
pszSpouse
Pointer to the name of the subject's spouse.
pszNotes
Pointer to notes about the subject.
pszEmail3
Pointer to the subject's third email alias.
pszHomePhone2
Pointer to the subject's second home telephone number.
pszHomeFax
Pointer to the telephone number of the subject's home fax machine.
pszCarPhone
Pointer to the telephone number of the subject's car telephone.
pszAssistant
Pointer to the name of the subject's assistant.
pszAssistantPhone
Pointer to the telephone number of the subject's assistant.
pszChildren
Pointer to the names of the subject's children.
pszCategory
Pointer to the name of the category to which the address card belongs. For example, a business card might belong to a "business" category.
pszWebPage
Pointer to the address of the subject's page on the world-wide web.
pszWorkPhone2
Pointer to the second work telephone number of the subject.
pszNamePrefix
Pointer to the subject's name prefix ¾ for example, Mrs., Mr., Ms.
pszGivenName
Pointer to the subject's given name.
pszMiddleName
Pointer to the subject's middle name.
pszSurname
Pointer to the subject's surname.
pszGeneration
Pointer to the name of the subject's generation.
pszHomeAddrStreet
Pointer to the street address of the subject's home.
pszHomeAddrCity
Pointer to the city in which the subject lives.
pszHomeAddrState
Pointer to the state in which the subject lives.
pszHomeAddrPostalCode
Pointer to the postal code of the subject's home.
pszHomeAddrCountry
Pointer to the country in which the subject lives.
pszOtherAddrStreet
Pointer to the street address of the subject's second home
pszOtherAddrCity
Pointer to the city in which the subject's second home is located.
pszOtherAddrState
Pointer to the state in which the subject's second home is located.
pszOtherAddrPostalCode
Pointer to the postal code of the subject's second home.
pszOtherAddrCountry
Pointer to the country in which the subject's second home is located.
pszOfficeAddrStreet
Pointer to the street address of the subject's office.
pszOfficeAddrCity
Pointer to the city in which the subject's office is located.
pszOfficeAddrState
Pointer to the state in which the subject's office is located.
pszOfficeAddrPostalCode
Pointer to the postal code of the subject's office.
pszOfficeAddrCountry
Pointer to the country in which the subject's office is located.
rgbReserved
Reserved. Do not use.
