RB_SHOWBAND

The RB_SHOWBAND message shows or hides a given band in a rebar control.

Syntax

RB_SHOWBAND
wParam = (WPARAM)(INT) iBand;
lParam = (LPARAM)(BOOL) fShow;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

iBand
Zero-based index of a band in the rebar control.
fShow
A boolean value that indicates if the band should be shown or hidden. If this value is non-zero, the band will be shown. Otherwise, the band will be hidden.

Return Values

Returns nonzero if successful, or zero otherwise.
