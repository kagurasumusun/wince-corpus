TB_ADDSTRING

The TB_ADDSTRING message adds a new string to the list of strings available for a toolbar.

Syntax

TB_ADDSTRING
wParam = (WPARAM)(HINSTANCE) hinst;
lParam = (LPARAM)MAKELONG(idString,0);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The resource identifier in the idString parameter has to reference a single string without substrings or separators.
