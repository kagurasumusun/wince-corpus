STM_SETIMAGE

An application sends an STM_SETIMAGE message to associate a new image (icon or bitmap) with a static control.

Syntax

STM_SETIMAGE
wParam = (WPARAM) fImageType;
lParam = (LPARAM)(HANDLE) hImage;

At a Glance

Header file: Winuser.h
Component/Module: Static text control component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The following fImageType values are not supported:
IMAGE_CURSOR

IMAGE_ENHMETAFILE
