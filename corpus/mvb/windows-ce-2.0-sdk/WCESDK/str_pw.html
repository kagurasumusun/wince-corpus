CEDB_FIND_DATA

The CEDB_FIND_DATA structure contains information about a database in the Windows CE object store. This structure is used by the CeFindAllDatabases function.

Syntax

struct CEDB_FIND_DATA {
 CEOID OidDb;
CEDBASEINFO DbInfo;
};

At a Glance

Header file:
Module/Component:
Platforms:
Versions: 1.0 and later

Members

OidDb
Specifies the object identifier of a database in the Windows CE object store.
DbInfo
Specifies a CEDBASEINFO structure that contains information about a database.
