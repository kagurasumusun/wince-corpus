GetObjectType

The GetObjectType function returns the type of the specified object.

Syntax

DWORD GetObjectType(HGDIOBJ h);

At a Glance

Header file: Wingdi.h
Component: mgbase
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the following return values:
OBJ_EXTPEN

OBJ_METADC

OBJ_METAFILE

OBJ_ENHMETAFILE

OBJ_ENHMETADC

Windows CE version 1.0 does not support the OBJ_PAL return value.
