WriteProcessMemory

The WriteProcessMemory function writes memory in a specified process. The entire area to be written to must be accessible, or the operation fails.

Syntax

BOOL WriteProcessMemory(HANDLE hProcess, LPVOID lpBaseAddress, LPVOID lpBuffer, DWORD nSize, LPDWORD lpNumberOfBytesWritten);

At a Glance

Header file: Winbase.h
Component/Module: Nk
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation Microsoft Platform SDK

Remarks

The hProcess parameter is the handle returned from the OpenProcess function that provided full access to the process.
