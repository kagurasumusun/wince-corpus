HttpQueryInfo

The HttpQueryInfo function queries for information about an HTTP request.

Syntax

INTERNETAPI BOOL WINAPI HttpQueryInfo(HINTERNET hRequest, DWORD dwInfoLevel, LPVOID lpBuffer , LPDWORD lpdwBufferLength, LPDWORD lpdwIndex );

At a Glance

Header file: Wininet.h
Module: Wininet
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the HTTP_QUERY_FLAG_COALESCE flag for the dwInfoLeve parameterl.
