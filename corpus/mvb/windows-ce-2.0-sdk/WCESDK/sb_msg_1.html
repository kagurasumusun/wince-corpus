SB_GETPARTS

The SB_GETPARTS message retrieves a count of the parts in a status window. The message also retrieves the coordinate of the right edge of the given number of parts.

Syntax

SB_GETPARTS
wParam = (WPARAM) nParts;
lParam = (LPARAM)(LPINT) aRightCoord;
