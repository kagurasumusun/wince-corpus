DRAWITEMSTRUCT

The DRAWITEMSTRUCT structure provides information the owner window must have to determine how to paint an owner-drawn control or menu item. The owner window of the owner-drawn control or menu item receives a pointer to this structure as the lParam parameter of the WM_DRAWITEM message.

Syntax

typedef struct tagDRAWITEMSTRUCT { // dis
UINT CtlType;
UINT CtlID;
UINT itemID;
UINT itemAction;
UINT itemState;
HWND hwndItem;
HDC hDC;
RECT rcItem;
DWORD itemData;
} DRAWITEMSTRUCT;

Remarks

Ownerdraw combo boxes and list boxes are not supported.

The following CtlType values are not supported:
ODT_COMBOBOX

ODT_LISTBOX

ODT_STATIC

ODS_COMBOBOXEDIT is not supported as an itemState value.
