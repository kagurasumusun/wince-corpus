EM_SETLIMITTEXT

An application sends the EM_SETLIMITTEXT message to set the text limit for an edit control. The text limit is the maximum amount of text, in bytes, that the edit control can contain.

Syntax

EM_SETLIMITTEXT
wParam = (WPARAM) cbMax;
lParam = 0;

Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The Win32 Platform SDK erroneously states that EM_SETLIMITTEXT sets the limit to the number of bytes specified by cbMax. Both Windows NT and Windows CE set the limit to the number of chars specified by the cbMax.
