TVM_GETITEM

The TVM_GETITEM message retrieves some or all of a tree view item's attributes. You can send this message explicitly or by using the TreeView_GetItem macro.

Syntax

TVM_GETITEM
wParam = 0;
lParam = (LPARAM)(TV_ITEM FAR*) pitem;
