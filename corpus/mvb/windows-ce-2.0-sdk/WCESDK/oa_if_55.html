IPersistStorage::SaveCompleted

The IPersistStorage::SaveCompleted method notifies the object that it can revert from NoScribble or HandsOff mode, in which it must not write to its storage object, to Normal mode, in which it can.

Syntax

HRESULT SaveCompleted(
IStorage * pStgNew
);

At a Glance

Header file: Oleidl.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.
