ImageList_DragEnter

The ImageList_DragEnter function locks updates to the given window during a drag operation and displays the drag image at the specified position within the window.

Syntax

BOOL WINAPI ImageList_DragEnter(HWND hwndLock, int x, int y);

At a Glance

Header file: Commctrl.h
Component: Imgctl
Platforms: H/PC
Windows CE versions: 1.0 and later
