TBNOTIFY

The TBNOTIFY structure contains information used to process notification messages from a toolbar.

Syntax

typedef struct_TBNOTIFY {
NMHDR hdr;
INT iItem;
TBBUTTON tbButton;
INT cchText;
LPTSTR pszText;
} TBNOTIFY, FAR* LPTBNOTIFY;
