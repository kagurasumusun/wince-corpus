DB_PEGOID_CREATED

The DB_PEGOID_CREATED message is sent when a new object is created in the object store. See DB_CEOID_CREATED.

Syntax

DB_PEGOID_CREATED
oidCreated = (PEGOID) wParam;
oidParent = (PEGOID) lParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

oidCreated
Value of wParam. Identifies the newly created object.
oidParent
Value of lParam. Identifies the parent object of the newly created object.
