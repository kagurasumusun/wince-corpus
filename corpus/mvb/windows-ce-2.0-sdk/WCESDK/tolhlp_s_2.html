MODULEENTRY32

The MODULEENTRY32 structure describes an entry from a list that enumerates the modules used by a specified process.

Syntax

typedef struct tagMODULEENTRY32 { 
    DWORD   dwSize; 
    DWORD   th32ModuleID; 
    DWORD   th32ProcessID; 
    DWORD   GlblcntUsage; 
    DWORD   ProccntUsage; 
    BYTE  * modBaseAddr; 
    DWORD   modBaseSize; 
    HMODULE hModule; 
    char    szModule[MAX_MODULE_NAME32 + 1]; 
    char    szExePath[MAX_PATH]; 
} MODULEENTRY32; 
typedef MODULEENTRY32 *  PMODULEENTRY32; 
typedef MODULEENTRY32 *  LPMODULEENTRY32;

Remarks

The szModule and szExePath members are TCHAR.

All strings are UNICODE.

Windows CE supports an additional member, dwFlags, that is reserved for future use.
