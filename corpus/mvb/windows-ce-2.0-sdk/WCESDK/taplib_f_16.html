lineTranslateDialog

The lineTranslateDialog function displays an application-modal dialog box that allows the user to change the current location, adjust location and calling card parameters, and see the effect on a phone number about to be dialed.

Syntax

LONG lineTranslateDialog (HLINEAPP hLineApp, DWORD dwDeviceID, DWORD dwAPIVersion, HWND hwndOwner, LPCTSTR lpszAddressIn);
