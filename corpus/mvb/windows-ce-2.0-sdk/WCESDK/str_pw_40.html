TV_INSERTSTRUCT

The TV_INSERTSTRUCT structure contains information used to add a new item to a tree view control.

Syntax

typedef struct _TV_INSERTSTRUCT { tvins
 HTREEITEM hParent;
HTREEITEM hInsertAfter;
TV_ITEM item;
} TV_INSERTSTRUCT, FAR *LPTV_INSERTSTRUCT;
