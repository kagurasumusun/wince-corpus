TC_ITEMHEADER

The TC_ITEMHEADER structure specifies or receives the attributes of a tab. This structure is the same as the TC_ITEM structure, except that it does not include an lParam member for application-defined data.

Syntax

typedef struct _TC_ITEMHEADER {
UINT mask;
UINT lpReserved1;
UINT lpReserved2;
LPSTR pszText;
int cchTextMax;
int iImage;
} TC_ITEMHEADER;
