WINDOWPOS

The WINDOWPOS structure contains information about the size and position of a window.

Syntax

typedef struct _WINDOWPOS { // wp
HWND hwnd;
HWND hwndInsertAfter;
int x;
int y;
int cx;
int cy;
UINT flags;
} WINDOWPOS;

At a Glance

Header file:
Module/Component:
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE, the WINDOWPOS structure doesn't support the following flags in the Flags member.

  • SWP_DRAWFRAME

  • SWP_NOCOPYBITS

  • SWP_NOOWNERZORDER

  • SWP_NOREDRAW

  • SWP_NOREPOSITION

  • SWP_NOSENDCHANGING
