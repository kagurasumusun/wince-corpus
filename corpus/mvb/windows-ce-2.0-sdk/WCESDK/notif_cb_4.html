CBN_EDITUPDATE

The CBN_EDITUPDATE notification message is sent when the edit control portion of a combo box is about to display altered text. This notification is sent after the control has formatted the text, but before it displays the text. The parent window of the combo box receives this notification message through the WM_COMMAND message.

Syntax

CBN_EDITUPDATE
idComboBox = (int)LOWORD(wParam);
hwndComboBox = (HWND) lParam;
