WM_GETICON

The WM_GETICON message is sent to a window to retrieve the handle of the big or small icon associated with a window.

Syntax

WM_GETICON
fType = (BOOL) wParam;

At a Glance

Header file:
Component/Module: Icon component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Icons are stored per window class, not per window.

See Also

DefWindowProc, WM_SETICON
