GetKeyboardStatus

The GetKeyboardStatus function returns the status of the hardware keyboard.

Syntax

DWORD GetKeyboardStatus(VOID);

At a Glance

Header file: Winuser.h
Platforms: H/PC (Japanese)
Windows CE versions: Japanese version 1.0 and later

Return Values

KBDI_KEYBOARD_PRESENT
A hardware keyboard is present on the system.
KBDI_KEYBOARD_ENABLED
A hardware keyboard is currently enabled.
KBDI_KEYBOARD_ENTER_ESC
The keyboard has an Enter and an Escape key, or the equivalents.
KBDI_KEYBOARD_ALPHA_NUM
The keyboard has alphabetic and numeric keys.
