RegDeleteKey

The RegDeleteKey function deletes a key and all its descendents.

Syntax

LONG RegDeleteKey(HKEY hKey, LPCWSTR lpszSubKey);

At a Glance

Header file: Winreg.h
Component: Fsreg
Platforms:
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

With Windows CE, you can not RegDeleteKey a key which an application currently has open.
