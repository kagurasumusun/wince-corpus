gethostname

The Windows Sockets gethostname function returns the standard host name for the local computer.

Syntax

int PASCAL FAR gethostname (char FAR *name, int namelen);

At a Glance

Header file: Winsock.h
Module: Winsock
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK
