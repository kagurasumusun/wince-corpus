CreateEvent

The CreateEvent function creates an unnamed event object.

Syntax

HANDLE CreateEvent(LPSECURITY_ATTRIBUTES lpEventAttributes, BOOL bManualReset, BOOL bInitialState, LPTSTR lpname);

At a Glance

Header file: Winbase.h
Module: Nk
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support security attributes, so the lpEventAttributes parameter must be set to NULL.

Windows CE does not support named events, so the lpname parameter must be set to NULL.
