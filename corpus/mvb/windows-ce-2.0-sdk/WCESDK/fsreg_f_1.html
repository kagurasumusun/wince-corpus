RegCreateKeyEx

The RegCreateKeyEx function creates the specified key. If the key already exists in the registry, the function opens it.

Syntax

LONG RegCreateKeyEx(HKEY hKey, LPCWSTR lpszSubKey, DWORD Reserved, LPWSTR lpszClass, DWORD dwOptions, REGSAM samDesired, LPSECURITY_ATTRIBUTES lpSecurityAttributes, PHKEY phkResult, LPDWORD lpdwDisposition);

At a Glance

Header file: Winreg.h
Component: Fsreg
Platforms:
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The dwOptions and samDesired parameters are ignored and should be set to zero to ensure compatibility with future versions of Windows CE.

The lpSecurityAttributes parameter should be set to NULL. Windows CE automatically assigns the key a default security descriptor.
