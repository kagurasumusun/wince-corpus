TCM_SETCURSEL

The TCM_SETCURSEL message selects a tab in a tab control. You can send this message explicitly or by using the TabCtrl_SetCurSel macro.

Syntax

TCM_SETCURSEL
wParam = (WPARAM)(int) iItem;
lParam = 0;
