IPersist::GetClassID

The IPersist::GetClassID method retrieves the class identifier (CLSID) of an object. The CLSID is a unique value that identifies the code that can manipulate the persistent data.

Syntax

HRESULT GetClassID(
CLSID * pClassID
);
