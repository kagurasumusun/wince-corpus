Shell_NotifyIcon

The Shell_NotifyIcon function sends a message to the system to add, modify, or delete an icon from the taskbar status area.

Syntax

WINSHELLAPI BOOL WINAPI Shell_NotifyIcon(DWORD dwMessage, PNOTIFYICONDATA pnid);

At a Glance

Header file: Shellapi.h
Platforms: H/PC
Versions: 1.0 and later
