StgCreateDocfile

The StgCreateDocfile function creates a new compound file storage object using the OLE-provided compound file implementation for the IStorage interface.

Syntax

WINOLEAPI StgCreateDocfile( const WCHAR * pwcsName, DWORD grfMode, DWORD reserved, IStorage ** ppstgOpen);

At a Glance

Header file: Objbase.h
Component: Exp
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.

Remarks

For the access mode (grfMode), Windows CE supports the following flags:
STGM_DIRECT

STGM_TRANSACTED

STGM_SIMPLE

STGM_READ

STGM_WRITE

STGM_READWRITE

STGM_PRIORITY

STGM_DELETEONRELEASE

STGM_CREATE

STGM_CONVERT

STGM_FAILIFTHERE

STGM_NOSCRATCH

Passing into this function any invalid and, under some circumstances, NULL pointers will result in unexpected termination of the application. For more information about handling exceptions, see COM and Automation.
