IStream::UnlockRegion

The IStream::UnlockRegion method removes the access restriction on a range of bytes previously restricted with IStream::LockRegion.

Syntax

HRESULT UnlockRegion(
ULARGE_INTEGER libOffset,
ULARGE_INTEGER cb,
DWORD dwLockType
);
