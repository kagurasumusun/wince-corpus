PropSheet_QuerySiblings

The PropSheet_QuerySiblings macro causes a property sheet to send the PSM_QUERYSIBLINGS message to each of its pages. If a page returns a nonzero value, the property shet does not send the message to subsequent pages.

Syntax

int PropSheet_QuerySiblings(
 hPropSheetDlg,
 param1,
 param2
);
