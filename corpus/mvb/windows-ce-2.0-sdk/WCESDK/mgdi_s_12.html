LOGPALETTE

The LOGPALETTE structure defines a logical color palette.

Syntax

typedef struct tagLOGPALETTE { // lgpl
WORD palVersion;
WORD palNumEntries;
PALETTEENTRY palPalEntry[1];
} LOGPALETTE;
