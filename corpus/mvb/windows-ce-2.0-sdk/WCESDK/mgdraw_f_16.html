SetBrushOrgEx

An application calls the SetBrushOrgEx to set the brush origin of the next brush selected into the specified device context.

Syntax

BOOL SetBrushOrgEx(HDC hdc, int nXOrg, int nYOrg, LPPOINT lppt);
