GetDlgItem

The GetDlgItem function retrieves the handle to a control in the specified dialog box.

Syntax

HWND GetDlgItem(HWND hDlg, int nIDDlgItem);

At a Glance

Header file: Winuser.h
Component: Dlgmgr
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The GetDlgItem function only works for immediate child controls of a dialog box¾it will not search through nested dialog boxes.
