DTM_SETMCFONT

The DTM_SETMCFONT message sets the font to be used by the date and time picker (DTP) control's child month calendar control.

Syntax

DTM_SETMCFONT
wParam = (WPARAM)(HFONT) hFont;
lParam = (LPARAM) MAKELONG(fRedraw, 0);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: DateTime_SetMonthCalFont

Parameters

hFont
Handle to the font that will be set.
fRedraw
Specifies whether the control should be redrawn immediately upon setting the font. Setting this parameter to TRUE causes the control to redraw itself.

Return Values

The return value for this message is not used.
