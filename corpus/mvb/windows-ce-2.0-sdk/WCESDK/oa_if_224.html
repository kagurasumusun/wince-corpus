ITypeLib2::GetDocumentation2

The ITypeLib2::GetDocumentation2 method retrieves the library's documentation string, the complete Help file name and path, the localization context to use, and the context ID for the library Help topic in the Help file.

Syntax

HRESULT GetDocumentation2(
[in] int index,
[in] LCID lcid,
[out] BSTR FAR* pbstrHelpString,
[out] unsigned long FAR* pdwHelpStringContext,
BSTR FAR* pbstrHelpStringDll
);
