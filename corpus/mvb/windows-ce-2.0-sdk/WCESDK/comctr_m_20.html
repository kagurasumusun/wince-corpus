HDM_GETIMAGELIST

The HDM_GETIMAGELIST message retrieves the handle to the image list that has been set for an existing header control.

Syntax

HDM_GETIMAGELIST
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: Header_GetImageList

Return Values

Returns a handle to the image list set for the header control.
