LoadAccelerators

The LoadAccelerators function loads the specified accelerator table.

Syntax

HACCEL LoadAccelerators(HINSTANCE hInstance, LPCTSTR lpTableName);

At a Glance

Header file: Winuser.h
Component: wmgr_c
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The resource is not copied into RAM, so it may not be modified.
