GetTextExtentPoint

The GetTextExtentPoint function computes the width and height of the specified string of text.

Syntax

BOOL GetTextExtentPoint( HDC hdc, LPCTSTR lpString, int cbString, LPSIZE lpSize);

At a Glance

Header file: Wingdi.h
Component: mgtt
mgrast
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The GetTextExtentPoint function is identical to the GetTextExtentPoint32 function.
