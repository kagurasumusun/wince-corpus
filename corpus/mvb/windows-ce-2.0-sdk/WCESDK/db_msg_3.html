DB_PEGOID_CHANGED

The DB_PEGOID_CHANGED message is sent when an object in the object store has been modified. See DB_CEOID_CHANGED.

Syntax

DB_PEGOID_CHANGED
oidChanged = (PEGOID) wParam;
oidParent = (PEGOID) lParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

oidChanged
Value of wParam. Identifies the object that was modified.
oidParent
Value of lParam. Identifies the parent object of the modified object.
