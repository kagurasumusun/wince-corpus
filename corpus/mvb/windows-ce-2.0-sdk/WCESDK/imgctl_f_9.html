ImageList_Draw

The ImageList_Draw function draws an image list item in the specified device context (DC).

Syntax

BOOL WINAPI ImageList_Draw(HIMAGELIST himl, int iDraw, HDC hdcDst, int x, int y, UINT fStyle);
