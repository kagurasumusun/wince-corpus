Polygon

The Polygon function draws a polygon consisting of two or more vertices connected by straight lines. The current pen outlines the polygon, and the curent brush fills it using the specified polygon fill mode.

Syntax

BOOL Polygon(HDC hdc, const POINT *lpPoints, int nCount);

At a Glance

Header file: Wingdi.h
Component: mgdraw
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE version 1.0 supports only convex polygons.

This function is the same in Windows CE version 2.0 as it is in Windows desktop platforms.
