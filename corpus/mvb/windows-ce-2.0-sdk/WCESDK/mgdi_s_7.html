DIBSECTION

The DIBSECTION structure contains information about a device-independent bitmap (DIB).

Syntax

typedef struct tagDIBSECTION {
BITMAP dsBm;
BITMAPINFOHEADER dsBmih;
DWORD dsBitfields[3];
HANDLE dshSection;
DWORD dsOffset;
} DIBSECTION;
