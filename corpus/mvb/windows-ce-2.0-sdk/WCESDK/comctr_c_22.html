ListView_GetHeader

Macro that retrieves the handle to the header control used by a list view control.

Syntax

HWND ListView_GetHeader(hwndLV);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related message: LVM_GETHEADER

Parameters

hwndLV
Handle to a list view control.

Return Values

Returns the handle to the header control.
