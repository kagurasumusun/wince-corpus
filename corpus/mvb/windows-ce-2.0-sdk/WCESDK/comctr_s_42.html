NMTVKEYDOWN

The NMTVKEYDOWN structure contains information about a keyboard event in a tree-view control. This structure is used with the TVN_KEYDOWN notification message.

Syntax

typedef struct tagTVKEYDOWN {
NMHDR hdr;
WORD wVKey;
UINT flags;
} NMTVKEYDOWN, FAR *LPNMTVKEYDOWN;

At a Glance

Header file:
Component:
Platforms: H/PC

Members

NMHDR structure that contains information about this notification message.
