GetMessagePos

The GetMessagePos function returns a long value that gives the cursor position in screen coordinates.

Syntax

DWORD GetMessagePos(void);

At a Glance

Header file: Winuser.h
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

For devices that use a stylus rather than a mouse, the cursor position is the position of the stylus on the touch screen when the last message retrieved by the GetMessage function occurred.
