UDM_SETRANGE

The UDM_SETRANGE message sets the minimum and maximum positions (range) for a up-down control.

Syntax

UDM_SETRANGE
wParam = 0;
lParam = (LPARAM)MAKELONG((short)nUpper,(short)nLower);
