LB_ITEMFROMPOINT

An application sends the LB_ITEMFROMPOINT message to retrieve the zero-based index of the item nearest the specified point in a list box.

Syntax

LB_ITEMFROMPOINT
wParam = 0;
lParam = (LPARAM)MAKELPARAM(xPos, yPos);
