EnumFonts

The EnumFonts function enumerates the fonts available on a specified device. This function is provided for compatibility with earlier versions of the Microsoft Platform SDK. Whenever possible, applications should use the EnumFontFamilies function.

Syntax

int EnumFonts(HDC hdc, LPCTSTR lpFaceName, FONTENUMPROC lpFontFunc, LPARAM lParam);

Remarks

Windows CE version 1.0 supports only raster fonts.

Windows CE version 2.0 supports systems that use either TrueType or raster fonts but not both. The font type (raster or TrueType) is chosen at system design time, and cannot be changed by an application.
