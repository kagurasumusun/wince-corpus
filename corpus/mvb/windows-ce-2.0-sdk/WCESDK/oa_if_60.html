IStorage::CopyTo

The IStorage::CopyTo method copies the entire contents of an open storage object to another storage object.

Syntax

HRESULT CopyTo(
DWORD ciidExclude,
IID const * rgiidExclude,
SNB snbExclude,
IStorage * pstgDest
);

At a Glance

Platforms: H/PC
Windows CE versions: 2.0 and later
