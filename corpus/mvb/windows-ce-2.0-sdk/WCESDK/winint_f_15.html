InternetCanonicalizeUrl

The InternetCanonicalizeUrl function converts a URL to a canonical form, including conversion of unsafe characters into escape sequences.

Syntax

INTERNETAPI BOOL WINAPI InternetCanonicalizeUrl(LPCTSTR lpszUrl, LPTSTR lpszBuffer, LPDWORD lpdwBufferLength, DWORD dwFlags);

At a Glance

Header file: Wininet.h
Module: Wininet
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The lpdwBufferLength parameter refers to count of characters. If the function succeeds, this parameter receives the length, in characters, of the lpszBuffer buffer excluding the terminating null. If the function fails, this parameter receives the required length, in characters, of the lpszBuffer buffer, including the terminating null.
