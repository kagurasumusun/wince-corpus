HttpAddRequestHeaders

The HttpAddRequestHeaders function adds one or more HTTP request headers to the HTTP request handle.

Syntax

INTERNETAPI BOOL WINAPI HttpAddRequestHeaders(HINTERNET hHttpRequest, LPCTSTR lpszHeaders, DWORD dwHeadersLength, DWORD dwModifiers);
