CreateIconIndirect

The CreateIconIndirect function creates an icon or cursor from an ICONINFO structure.

Syntax

HICON CreateIconIndirect(PICONINFO piconinfo);

At a Glance

Header file: Winuser.h
Component: Icon
Iconcurs
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The icon component does not support cursors. When using this component, always set the fIcon field of the ICONINFO structure to TRUE.

When using the iconcurs component, you can use the CreateIconIndirect function to create either icons or monochrome cursors. Windows CE does not support color cursors.
