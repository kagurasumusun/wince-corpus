RB_IDTOINDEX

The RB_IDTOINDEX message converts a band identifier (ID) to a band index in a rebar control.

Syntax

RB_IDTOINDEX
wParam = (WPARAM)(UINT) uBandID;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

uBandID
The application-defined identifier of the band in question. This is the value that is passed in the wID member of the REBARBANDINFO structure when the band was inserted.

Return Values

Returns the zero-based band index if successful, or -1 otherwise. If duplicate band IDs exist, the first one is returned.
