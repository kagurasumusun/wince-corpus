HDM_SETIMAGELIST

The HDM_SETIMAGELIST message assigns an image list to an existing header control.

Syntax

HDM_SETIMAGELIST
wParam = 0;
lParam = (LPARAM) himl;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: Header_SetImageList

Parameters

himl
Handle to an image list.

Return Values

Returns the handle to the image list previously associated with the control. The message returns NULL upon failure or if no image list was set previously.
