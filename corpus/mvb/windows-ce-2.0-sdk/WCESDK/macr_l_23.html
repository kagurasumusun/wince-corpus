ListView_GetNextItem

The ListView_GetNextItem macro searches for a list view item that has the specified properties and bears the specified relatinship to a specified item. You can use this macro or explicitly send the LVM_GETNEXTITEM message.

Syntax

int ListView_GetNextItem(
 HWND hwnd,
 int iStart,
 UINT flags
);
