METHODDATA

The METHODDATA structure is used to describe a method or property.

Syntax

typedef struct FARSTRUCT tagMETHODDATA {
OLECHAR FAR *szName;
PARAMDATA FAR * ppData;
DISPID dispid;
unsigned int iMeth;
CALLCONV cc;
unsigned int cArgs;
unsigned short wFlags;
VARTYPE vtReturn;
} METHODDATA;
