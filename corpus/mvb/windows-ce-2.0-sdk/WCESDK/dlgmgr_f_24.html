SetDlgItemInt

The SetDlgItemInt function sets the text of a control in a dialog box to the string representation of a specified integer value.

Syntax

BOOL SetDlgItemInt(HWND hDlg, int nIDDlgItem, UINT uValue, BOOL bSigned);

At a Glance

Header file: Winuser.h
Component: Dlgmgr
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The bSigned parameter is not used. All values passed in the nValue parameter are assumed to be signed.
