TBM_SETSELEND

The TBM_SETSELEND message sets the ending position of the current selection in a trackbar.

Syntax

TBM_SETSELEND
wParam = (WPARAM)(BOOL) fRedraw;
lParam = (LPARAM)(LONG) lEnd;
