IOleAdviseHolder : IUnknown

The IOleAdviseHolder interface manages advisory connections and compound document notifications in an object server.

At a Glance

Header file: Oleidl.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.

Method Description
IOleAdviseHolder::Advise Establishes an advisory connection between an OLE object and the calling object's advise sink. Through that sink, the calling object can receive notification when the OLE object is renamed, saved, or closed.
IOleAdviseHolder::EnumAdvise Creates an enumerator that can be used to enumerate the advisory connections currently established for an object, and supplies a pointer to its IEnumSTATDATA interface
IOleAdviseHolder::SendOnClose Sends notification that the object has closed to all advisory sinks currently registered with the advise holder.
IOleAdviseHolder::SendOnRename Sends notifications to all advisory sinks currently registered with the advise holder.
IOleAdviseHolder::SendOnSave Sends notifications to all advisory sinks currently registered with the advise holder.
IOleAdviseHolder::Unadvise Deletes a previously established advisory connection.
