LVM_SETITEMPOSITION32

The LVM_SETITEMPOSITION32 message moves an item to a specified position in a list view control, which must be in icon or small icon view. This message differs from the LVM_SETITEMPOSITION message in that it uses 32-bit coordinates.

Syntax

LVM_SETITEMPOSITION32
wParam = (WPARAM)(int) iItem;
lParam = (LPARAM)(LPPOINT) lpptNewPos;
