EM_SETPASSWORDCHAR

An application sends an EM_SETPASSWORDCHAR message to set or remove a password character displayed in a single-line edit control when the user types text. When a password character is set, that character is displayed in place of each character the user types.

Syntax

EM_SETPASSWORDCHAR
wParam = (WPARAM)(UINT) ch;
lParam = 0;
