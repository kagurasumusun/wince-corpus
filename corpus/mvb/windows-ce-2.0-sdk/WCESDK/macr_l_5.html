ListView_EditLabel

The ListView_EditLabel macro begins in-place editing of the specified list view item's text. The message implicitly selects and focuses the specified item. You can use this macro or explicitly send the LVM_EDITLABEL message.

Syntax

HWND ListView_EditLabel(
 HWND hwnd,
 int iItem
);
