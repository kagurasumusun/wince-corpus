FtpGetCurrentDirectory

The FtpGetCurrentDirectory function retrieves the current directory for the specified FTP session.

Syntax

INTERNETAPI BOOL WINAPI FtpGetCurrentDirectory(HINTERNET hFtpConnect, LPCTSTR lpszDirectory, LPDWORD lpdwDirectoryLength);
