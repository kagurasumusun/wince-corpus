GetSaveFileName

The GetSaveFileName function creates a system-defined dialog box that enables the user to select a file to save.

Syntax

BOOL GetSaveFileName(LPOPENFILENAME lpofn);

At a Glance

Header file: Commdlg.h
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Not all members of the OPENFILENAME structure are defined in Windows CE. For information about the defined members, see the reference topic for the OPENFILENAME structure.
