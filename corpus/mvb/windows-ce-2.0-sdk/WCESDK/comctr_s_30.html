PBRANGE

The PBRANGE structure contains information about the high and low limits of a progress bar control. This structure is used with the PBM_GETRANGE message.

Syntax

typedef struct {
int iLow;
int iHigh;
} PBRANGE, *PPBRANGE;

At a Glance

Header file:
Component:
Platforms: H/PC
Versions: 2.0 and later

Members

iLow
Low limit currently set for the progress bar control.
iHigh
High limit currently set for the progress bar control.
