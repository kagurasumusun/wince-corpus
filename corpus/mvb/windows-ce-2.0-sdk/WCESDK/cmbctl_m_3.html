CB_FINDSTRINGEXACT

An application sends a CB_FINDSTRINGEXACT message to find the first list box string in a combo box that matches the string specified in the lpszFind parameter.

Syntax

CB_FINDSTRINGEXACT
wParam = (WPARAM) indexStart,
lParam = (LPARAM)(LPCSTR) lpszFind

At a Glance

Header file: Winuser.h
Component/Module: Combo box control component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

This message does not work across processes. You can not make the call SendMessage(CB_FINDSTRINGEXACT) to another process.
