TB_SETINDENT

The TB_SETINDENT message sets the indentation for the first button in a toolbar control.

Syntax

TB_SETINDENT
wParam = (WPARAM)(INT) iIndent;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

iIndent
Value specifying the indentation, in pixels.

Return Values

Returns nonzero if successful or zero otherwise.
