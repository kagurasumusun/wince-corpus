WM_NEXTDLGCTL

The WM_NEXTDLGCTL message is sent to a dialog box procedure to set the keyboard focus to a different control in the dialog box.

Syntax

WM_NEXTDLGCTL
wCtlFocus = wParam;
fHandle = (BOOL) LOWORD(lParam);
