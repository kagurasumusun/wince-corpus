TCM_SETMINTABWIDTH

The TCM_SETMINTABWIDTH message sets the minimum width of items in a tab control.

Syntax

TCM_SETMINTABWIDTH
wParam = 0;
lParam = (LPARAM) (INT) cx;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: TabCtrl_SetMinTabWidth

Parameters

cx
Minimum width to be set for a tab control item. If this parameter is set to -1, the control will use the default tab width.

Return Values

Returns an INT value that represents the previous minimum tab width.
