LOGPEN

The LOGPEN structure defines the style, width, and color of a pen. The CreatePenIndirect function uses the LOGPEN structure.

Syntax

typedef struct tagLOGPEN { // lgpn
UINT lopnStyle;
POINT lopnWidth;
COLORREF lopnColor;
} LOGPEN;

At a Glance

Header file: Wingdi.h
Component/Module: mgdraw
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the following values for the lopnStyle member:
PS_DOT

PS_DASHDOT

PS_DASHDOTDOT

PS_INSIDEFRAME
