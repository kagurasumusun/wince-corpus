TVM_EXPAND

The TVM_EXPAND message expands or collapses the list of child items, if any, associated with the given parent item. You can send this message explicitly or by using the TreeView_Expand macro.

Syntax

TVM_EXPAND
wParam = (WPARAM)(UINT) flag;
lParam = (LPARAM)(HTREEITEM) hitem;

Remarks

In Windows CE versions 2.0 and later, you can use the new TVE_EXPANDPARTIAL flag in the flag parameter.

When the TVE_EXPANDPARTIAL flag is set, the child items are visible and parent item's plus symbol is displayed. This flag must be used in combination with the TVE_EXPAND flag.
