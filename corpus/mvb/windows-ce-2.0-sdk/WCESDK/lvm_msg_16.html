LVM_GETITEM

The LVM_GETITEM message retrieves some or all of a list view item's attributes. You can send this message explicitly or by using the ListView_GetItem macro.

Syntax

LVM_GETITEM
wParam = 0;
lParam = (LPARAM)(LV_ITEM FAR*) pitem;
