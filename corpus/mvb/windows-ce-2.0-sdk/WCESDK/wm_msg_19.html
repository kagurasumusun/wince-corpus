WM_SYSCOMMAND

A window receives this message when the user chooses a command from the window menu (formerly known as the system or control menu) or when the user chooses the maximize button or the minimize button.

Syntax

WM_SYSCOMMAND
uCmdType = wParam;
xPos = LOWORD(lParam);
yPos = HIWORD(lParam);

Header file:
Module/Component:
Platforms:
Versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The only values Windows CE supports for the uCmdType parameter are SC_CLOSE and SC_KEYMENU.
