ioctlsocket

The Windows Sockets ioctlsocket function controls the mode of a socket.

Syntax

int ioctlsocket (SOCKET s, long cmd, u_long *argp);

At a Glance

Header file: Winsock.h
Module: Winsock
Platforms: H/PC
Windows CE versions: 1.0 and later
