EnumSystemLocales

The EnumSystemLocales function enumerates the locales that are either installed on or supported by a system.

Syntax

BOOL EnumSystemLocales(LOCALE_ENUMPROC lpLocaleEnumProc, DWORD dwFlags);

At a Glance

Header file: Winnls.h
Component: coreloc
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the LCID_ALTERNATE_SORTS flag.
