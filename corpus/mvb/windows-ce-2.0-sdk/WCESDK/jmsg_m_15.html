WM_IME_NOTIFY

The WM_IME_NOTIFY message is sent to an application to notify it of changes to the IME window. An application processes this message if it is responsible for managing the IME window.

Syntax

WM_IME_NOTIFY
dwCommand = (DWORD) wParam;
dwData = (DWORD) lParam;

Remarks

Windows CE supports the following values for the dwCommand parameter:

IMN_CHANGECANDIDATE IMN_SETCANDIDATEPOS
IMN_CLOSECANDIDATE IMN_SETCOMPOSITIONWINDOW
IMN_OPENCANDIDATE IMN_SETCONVERSIONMODE
IMN_SETOPENSTATUS
IMN_SETSENTENCEMODE
