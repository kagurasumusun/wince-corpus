ExtractIconEx

The ExtractIconEx function retrieves the handle from the given executable file or dynamic-link library (DLL).

Syntax

UINT ExtractIconEx(LPCTSTR lpszExeFileName, UINT nIconIndex, HICON *phiconLarge, HICON *phiconSmall, UINT nIcons);

At a Glance

Header file: Shellapi.h
Component: gwes/icon
gwes/iconcurs
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The nIconIndex parameter must be zero or -N where N is a specified resource identifier. The nIcons parameter must be 1.
