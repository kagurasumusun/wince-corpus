CeRegDeleteValue

The CeRegDeleteValue function removes a named value from the specified registry key. This is the RAPI version of the RegDeleteValue function.

Syntax

LONG CeRegDeleteValue(HKEY hKey, LPCWSTR lpszValueName);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegRegDeleteValue function.

For more information about using RAPI functions, see Remote API Functions.
