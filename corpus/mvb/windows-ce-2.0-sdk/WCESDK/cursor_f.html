ClipCursor

The ClipCursor function confines the cursor to a rectangular area on the screen. If a subsequent cursor position (set by the SetCursorPos function or the mouse) lies outside the rectangle, Windows CE automatically adjusts the cursor position to keep it inside the rectangular area.

Syntax

BOOL ClipCursor( CONST RECT *lpRect );
