PAINTSTRUCT

The PAINTSTRUCT structure contains information that an application uses to paint the client area of a window owned by that application.

Syntax

typedef struct tagPAINTSTRUCT { // ps
HDC hdc;
BOOL fErase;
RECT rcPaint;
BOOL fRestore;
BOOL fIncUpdate;
BYTE rgbReserved[32];
} PAINTSTRUCT;
