RAPIINIT

The RAPIINIT structure contains information used to initialize a RAPI connection.

Syntax

typedef struct _RAPIINIT { //
DWORD cbSize;
HANDLE heRapiInit;
HANDLE hrRapiInit;
} RAPIINIT;

At a Glance

Header file: Rapi.h
Module/Component:
Platforms:
Versions: 1.0 and later

Members

cbSize
Specifies the size of the RAPIINIT structure being passed in.
heRapiInit
Specifies a handle to an event. The event is set when the RAPI connection is made or an error occurs.
hrRapiInit
Specifies the results, success or failure, of the RAPI connection.
