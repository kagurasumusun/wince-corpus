GetMessage

The GetMessage function retrieves a message from the calling thread's message queue and places it in the specified structure.

Syntax

BOOL GetMessage(LPMSG lpMsg, HWND hWnd, UINT wMsgFilterMin, UINT wMsgFilterMax);

Component: msgque
Platforms: H/PC
