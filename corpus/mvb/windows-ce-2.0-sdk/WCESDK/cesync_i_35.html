IEnumReplItem

The IEnumReplItem interface enables enumeration of a collection of items.

At a Glance

Header file: Cesync.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Method Description
IEnumReplItem::Clone Creates a copy of the current state of enumeration.
IEnumReplItem::Next Attempts to advance to the next item.
IEnumReplItem::Reset Resets the enumeration to the beginning.
IEnumReplItem::Skip Attempts to skip over the next item.
