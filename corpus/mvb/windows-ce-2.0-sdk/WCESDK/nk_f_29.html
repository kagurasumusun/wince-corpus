QueryPerformanceFrequency

The QueryPerformanceFrequency function retrieves the frequency of the high-resolution performance counter (ticks per second). Returns 0 if no high-frequency counter exists.

Syntax

BOOL QueryPerformanceFrequency (
LARGE_INTEGER * lpFrequency);
