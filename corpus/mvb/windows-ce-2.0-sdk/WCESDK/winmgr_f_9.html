DestroyWindow

The DestroyWindow function destroys the specified window.

Syntax

BOOL DestroyWindow(HWND hWnd);

At a Glance

Header file: Winuser.h
Component: Winmgr
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The DestroyWindow function does not send the WM_NCDESTROY message.
