htonl

The Windows Sockets htonl function converts a u_long from host byte order to network byte order.

Syntax

u_long htonl (u_long hostlong);

At a Glance

Header file: Winsock.h
Module: Winsock
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK
