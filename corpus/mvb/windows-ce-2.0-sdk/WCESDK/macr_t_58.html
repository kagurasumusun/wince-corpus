TypeFromPropID

The TypeFromPropID macro retrieves the type identifier from a property identifier.

Syntax

WORD TypeFromPropID(
 PEGPROPID propid
);

At a Glance

Header file: Windbase.h
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

propid
Specifies the property identifier from which to retrieve the type identifier.

Remarks

The TypeFromPropID macro is defined as follows: 

#define TypeFromPropID(propid) LOWORD(propid)
