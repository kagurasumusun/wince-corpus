TVM_INSERTITEM

The TVM_INSERTITEM message inserts a new item in a tree view control. You can send this message explicitly or by using the TreeView_InsertItem macro.

Syntax

TVM_INSERTITEM
wParam = 0;
lParam = (LPARAM)(LPTV_INSERTSTRUCT) lpis;
