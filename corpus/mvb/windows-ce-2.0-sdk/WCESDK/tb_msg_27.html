TB_PRESSBUTTON

The TB_PRESSBUTTON message presses or releases the specified button in a toolbar.

Syntax

TB_PRESSBUTTON
wParam = (WPARAM) idButton;
lParam = (LPARAM)MAKELONG(fPress,0);
