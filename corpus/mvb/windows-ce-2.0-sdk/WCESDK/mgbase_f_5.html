GetBkMode

The GetBkMode function returns the current background mix mode for a specified device context. The background mix mode of a device context affects text and dashed pens.

Syntax

int GetBkMode(HDC hdc);

At a Glance

Header file: Wingdi.h
Component: mgbase
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The BkMode value is stored internally as a single byte.
