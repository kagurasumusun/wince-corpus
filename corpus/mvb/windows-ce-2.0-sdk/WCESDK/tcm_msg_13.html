TCM_SETCURFOCUS

The TCM_SETCURFOCUS message sets the focus to a specified tab in a tab control. You can send this message explicitly or by using the TabCtrl_SetCurFocus macro.

Syntax

TCM_SETCURFOCUS
iItem = (int) (WPARAM) wParam;
