WSACleanup

The WSACleanup function initiates no action and is provided only for compatibility reasons.

Syntax

int WSACleanup()

At a Glance

Header file: Winsock.h
Module/Component: Winsock
Platforms: H/PC
Windows CE versions: 1.0 and later

Parameters

None.

Return Values

WSACleanup returns zero.
