NMRBAUTOSIZE

The NMRBAUTOSIZE structure contains information used in handling the RBN_AUTOSIZE notification messages.

Syntax

typedef struct tagNMRBAUTOSIZE {
NMHDR hdr;
BOOL fChanged;
RECT rcTarget;
RECT rcActual;
} NMRBAUTOSIZE, *LPNMRBAUTOSIZE;

At a Glance

Header file:
Component:
Platforms: H/PC
Versions: 2.0 and later

hdr
NMHDR structure that contains additional information about the notification message.
fChanged t
Member that indicates if the size or layout of the rebar control has changed. Nonzero if a change occurred or zero otherwise.
rcTarget
RECT structure that contains the rectangle that the rebar control tried to size itself to.
rcActual
RECT structure that contains the rectangle that the rebar control actually sized itself to.
