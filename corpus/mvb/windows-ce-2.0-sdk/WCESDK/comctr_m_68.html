MCN_GETDAYSTATE

The MCN_GETDAYSTATE notification message is sent by a month calendar control to request information about how individual days should be displayed. This notification message is sent only by month calendar controls that use the MCS_DAYSTATE style, and it is sent in the form of a WM_NOTIFY message.

Syntax

MCN_GETDAYSTATE
lpNMDayState = (LPNMDAYSTATE) lParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

lpNMDayState
Address of an NMDAYSTATE structure. The structure contains information about the time frame for which the control needs information, and receives the address of an array that provides such data.

Remarks

Handling this notification message allows your application to customize its display by specifying that certain days be displayed in bold. For more information about processing this message, see Processing the MCN_GETDAYSTATE Notification Message.
