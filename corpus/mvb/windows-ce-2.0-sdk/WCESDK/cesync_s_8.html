DEVINFO

The DEVINFO structure is used to store information about a device.

typedef struct tagDevInfo {
DWORD pid;
char szName[ MAX_PATH];
char szType[ 80 ];
char szPath[ MAX_PATH ]
} DEVINFO, *PDEVINFO;
