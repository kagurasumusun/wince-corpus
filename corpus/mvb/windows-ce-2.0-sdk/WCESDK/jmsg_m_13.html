WM_IME_SETCONTEXT

The WM_IME_SETCONTEXT message is sent to an application when a window of the application is activated.

Syntax

WM_IME_SETCONTEXT
fSet = (BOOL) wParam;
iShow = (DWORD) lParam;

Remarks

Windows CE applications should pass this message to the DefWindowProc function.
