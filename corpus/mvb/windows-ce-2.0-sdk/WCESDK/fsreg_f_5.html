RegEnumValue

The RegEnumValue function enumerates the values for the specified open registry key. RegEnumValue copies one indexed value name and data block for the key each time it is called.

Syntax

LONG RegEnumValue(HKEY hKey, DWORD dwIndex, LPWSTR lpszValueName, LPDWORD lpcchValueName, LPDWORD lpReserved, LPDWORD lpType, LPBYTE lpData, LPDWORD lpcbData);
