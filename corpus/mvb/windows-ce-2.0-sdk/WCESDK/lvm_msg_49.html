LVM_SORTITEMS

The LVM_SORTITEMS sorts list view items using an application-defined comparison function. The index of each item changes to reflect the new sequence. You can send this message explicitly or by using the ListView_SortItems macro.

Syntax

LVM_SORTITEMS
wParam = (WPARAM)(LPARAM) lParamSort;
lParam = (LPARAM)(PFNLVCOMPARE) pfnCompare;
