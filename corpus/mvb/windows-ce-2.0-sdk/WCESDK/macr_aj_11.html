ImageList_AddIcon

The ImageList_AddIcon macro adds an icon to an image list.

Syntax

int WINAPI ImageList_AddIcon(
 HIMAGELIST himl,
 HICON hicon
);

At a Glance

Header file: Commctrl.h
Module/Component:
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE, you can only use this macro with icons, not cursors.
