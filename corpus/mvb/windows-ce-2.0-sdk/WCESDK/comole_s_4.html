CONTROLINFO

The CONTROLINFO structure contains parameters that describe a control's keyboard mnemonics and keyboard behavior.

typedef struct tagCONTROLINFO
{
ULONG cb;
HACCEL hAccel;
USHORT cAccel;
DWORD dwFlags;
} CONTROLINFO;
