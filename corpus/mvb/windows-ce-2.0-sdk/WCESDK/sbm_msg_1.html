SBM_GETRANGE

An application sends the SBM_GETRANGE message to a scroll bar control to retrieve the minimum and maximum position values for the control.

Syntax

SBM_GETRANGE
wParam = (WPARAM) (LPINT) lpnMinPos;
lParam = (LPARAM) (LPINT) lpnMaxPos;
