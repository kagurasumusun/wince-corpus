HeapSize

The HeapSize function returns the size, in bytes, of a memory block allocated from a heap by the HeapAlloc or HeapReAlloc function.

Syntax

DWORD HeapSize( HANDLE hHeap, DWORD dwFlags, LPCVOID lpMem);

Component: lmem
Platforms: H/PC
