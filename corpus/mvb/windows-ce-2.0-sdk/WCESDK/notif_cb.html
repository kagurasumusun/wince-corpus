CBN_CLOSEUP

The CBN_CLOSEUP notification message is sent when the list box of a combo box has been closed. The parent window of the combo box receives this notification message through the WM_COMMAND message.

In general, you cannot predict the order in which notifications will be sent. In particular, a CBN_SELCHANGE notification may occur either before or after a CBN_CLOSEUP notification.

Syntax

CBN_CLOSEUP
idComboBox = (int)LOWORD(wParam);
hwndComboBox = (HWND) lParam;
