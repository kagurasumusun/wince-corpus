ImageList_LoadImage

The ImageList_LoadImage function creates an image list from the specified bitmap or icon resource.

Syntax

HIMAGELIST WINAPI ImageList_LoadImage(HINSTANCE hinst, LPCSTR lpbmp, int cx, int cGrow, COLORREF crMask, UINT uType, UINT uFlags);

At a Glance

Header file: Commctrl.h
Component: Imgctl
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The hinst parameter must be an HINSTANCE of an application or DLL containing an image.

The uFlags parameter must be zero.

The uType parameter does not support the IMAGE_CURSOR flag. You can only use this function with icons, not cursors.
