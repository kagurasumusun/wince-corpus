CreateUpDownControl

The CreateUpDownControl function creates an up-down control.

Syntax

HWND CreateUpDownControl(DWORD dwStyle, int x, int y, int cx, int cy, HWND hwndParent, int nID, HINSTANCE hinst, HWND hwndBuddy, int nUpper, int nLower, int nPos);

At a Glance

Header file: Commctrl.h
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The only buddy window for up-down controls is an edit control.
