UDM_SETRANGE32

The UDM_SETRANGE32 message sets the 32-bit range of an Up-Down control.

Syntax

UDM_SETRANGE32
wParam = (WPARAM)(int) iLow;
lParam = (LPARAM)(int) iHigh;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

iLow
Integer value that represents the new lower limit of the Up-Down control range.
iHigh
Integer value that represents the new upper limit of the Up-Down control range.

Return Values

The return value for this message is not used.
