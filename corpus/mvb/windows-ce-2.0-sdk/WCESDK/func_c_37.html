CeCreateDirectory

The CeCreateDirectory function creates a new directory. This is the RAPI version of the CreateDirectory function.

Syntax

BOOL CeCreateDirectory(LPCWSTR lpPathName, LPSECURITY_ATTRIBUTES lpSecurityAttributes);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegCreateDirectory function.
