HDM_SETORDERARRAY

The HDM_SETORDERARRAY message sets the left-to-right order of header items.

Syntax

HDM_SETORDERARRAY
wParam = (WPARAM) (int) iSize;
lParam = (LPARAM) lpiArray;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: Header_SetOrderArray

Parameters

iSize
Size of the buffer at lpiArray, in elements. This value must equal the value returned by HDM_GETITEMCOUNT.
lpiArray
Address of an array that specifies the order in which items should be displayed, from left to right. For example, if the contents of the array are {2,0,1}, the control displays item 2, item 0, and item 1 in that order, from left to right.

Return Values

Returns nonzero if successful, or zero otherwise.
