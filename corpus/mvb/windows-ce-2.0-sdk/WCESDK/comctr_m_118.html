TB_GETSTYLE

The TB_GETSTYLE message retrieves the styles currently in use for a toolbar control.

Syntax

TB_GETSTYLE
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Return Values

Returns a DWORD value that is a combination of toolbar control styles.
