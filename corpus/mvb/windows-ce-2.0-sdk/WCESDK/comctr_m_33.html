LVM_GETHEADER

The LVM_GETHEADER message retrieves the handle to the header control used by the list view control.

Syntax

LVM_GETHEADER
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: ListView_GetHeader

Return Values

Returns the handle to the header control.
