PropSheetProc

The PropSheetProc function is an application-defined callback function that the system calls when the property sheet is being initialized.

Syntax

void CALLBACK PropSheetProc(HWND hwndDlg, UINT uMsg, LPARAM lParam);

At a Glance

Platforms: H/PC
