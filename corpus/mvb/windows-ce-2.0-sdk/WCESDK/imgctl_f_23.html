ImageList_ReplaceIcon

The ImageList_ReplaceIcon function replaces an image with an icon.

Syntax

int WINAPI ImageList_ReplaceIcon(HIMAGELIST himl, int iReplace, HICON hicon);

At a Glance

Header file: Commctrl.h
Component: Imgctl
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

You can only use the ImageList_ReplaceIcon function with icons, not cursors.
