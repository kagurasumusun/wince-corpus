WNetDisconnectDialog1

The WNetDisconnectDialog1 function attempts to disconnect from a network resource by bringing up a general dialog box. If the underlying network returns WN_OPEN_FILES, the function prompts the user for confirmation. Users will be informed of any errors.

Syntax

DWORD WNetDisconnectDialog1(LPDISCDLGSTRUCT lpDiscDlgStruc);
