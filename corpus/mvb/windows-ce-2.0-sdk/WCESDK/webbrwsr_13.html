IWebBrowser::Refresh2

The Refresh2 method of the Web browser control reloads the file the Web browser control is currently displaying. Unlike the IWebBrowser::Refresh method, Refresh2 has a parameter that specifies the refresh level.

Syntax

HRESULT Refresh (
VARIANT FAR* Level
);
