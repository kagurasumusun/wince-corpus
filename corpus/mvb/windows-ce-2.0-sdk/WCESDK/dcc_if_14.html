IDccManSink::OnLogDisconnection

The IDccManSink::OnLogDisconnection method indicates that the connection manager has terminated the connection between the desktop PC and the H/PC.

Syntax

STDMETHODIMP IDccManSink::OnLogDisconnection(void);

At a Glance

Header file: Dccole.h
Platforms: H/PC
Windows CE versions: 1.0 and later

Parameters

None.

Return Values

This method should always return NOERROR.

Remarks

The IDccManSink::OnLogDisconnection method is implemented by a client application and is called when the H/PC connection manager terminates the connection between the desktop PC and the H/PC.

When this notification is made, the H/PC connection manager starts any applications that are registered with the registry key HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Pegasus\AutoStartOnDisconnect.

For more information, see Connection Notification and Registry-Based Notification.
