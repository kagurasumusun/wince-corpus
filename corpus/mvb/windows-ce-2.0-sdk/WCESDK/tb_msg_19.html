TB_HIDEBUTTON

The TB_HIDEBUTTON message hides or shows the specified button in a toolbar.

Syntax

TB_HIDEBUTTON
wParam = (WPARAM) idButton;
lParam = (LPARAM)MAKELONG(fShow,0);
