DTM_ADDTEXT

A DTM_ADDTEXT message is sent by an application to add text to the HTML control.

Syntax

DTM_ADDTEXT
wParam = (WPARAM)(BOOL) bPlainText;
lParam = (LPARAM)(LPSTR) szText;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

bPlainText
Flag to indicate the format of the text to be added. If bPlainText is TRUE, the text is treated as plain text. If bPlainText is FALSE, the text is treated as HTML formatted text.
szText
Null-terminated text string to be added to the HTML control.

Return Value

This message does not return a value.
