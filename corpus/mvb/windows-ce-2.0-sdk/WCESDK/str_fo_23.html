MEASUREITEMSTRUCT

The MEASUREITEMSTRUCT structure informs Windows of the dimensions of an owner-drawn control or menu item. This allows Windows to process user interaction with the control correctly.

Syntax

typedef struct tagMEASUREITEMSTRUCT {
UINT CtlType;
UINT CtlID;
UINT itemID;
UINT itemWidth;
UINT itemHeight;
DWORD itemData;
} MEASUREITEMSTRUCT;

Remarks

Owner-drawn combo boxes and list boxes are not supported.

The following CtlType values are not supported:
ODT_COMBOBOX

ODT_LISTBOX
