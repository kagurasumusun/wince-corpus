IStorage::MoveElementTo

The IStorage::MoveElementTo method copies or moves a substorage or stream from this storage object to another storage object.

const WCHAR * pwcsName,
IStorage * pstgDest,
LPWSTR pwcsNewName,
DWORD grfFlags
