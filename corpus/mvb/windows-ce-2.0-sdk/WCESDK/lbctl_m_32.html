LB_SETITEMHEIGHT

An application sends an LB_SETITEMHEIGHT message to set the height, in pixels, of items in a list box. Otherwise, this message sets the height of all items in the list box.

Syntax

LB_SETITEMHEIGHT
wParam = (WPARAM) index;
lParam = MAKELPARAM(cyItem, 0);

At a Glance

Header file: Winuser.h
Component/Module: List box component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The index parameter must be set to zero.
