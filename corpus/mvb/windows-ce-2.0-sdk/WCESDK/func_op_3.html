PropertySheet

The PropertySheet function creates a property sheet and adds the pages defined in the specified property sheet header structure.

Syntax

int PropertySheet(LPCPROPSHEETHEADER lppsph);

At a Glance

Header file: Prsht.h
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK
