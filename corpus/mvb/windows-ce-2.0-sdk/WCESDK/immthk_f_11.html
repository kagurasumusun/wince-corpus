ImmGetProperty

The ImmGetProperty function gets the property and capabilities of the IME associated with the specified keyboard layout.

Syntax

BOOL ImmGetProperty(HKL hKL, DWORD fdwIndex);

At a Glance

Header file: Imm.h
Component: Immthunk
Platforms: H/PC (Japanese)
Windows CE versions: Japanese version 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The hKL parameter must be NULL.
