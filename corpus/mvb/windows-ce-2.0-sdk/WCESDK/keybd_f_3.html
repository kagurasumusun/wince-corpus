MapVirtualKey

The MapVirtualKey function translates (maps) a virtual-key code into a scan code or character value, or translates a scan code into a virtual-key code.

Syntax

UINT MapVirtualKey(UINT uCode, UINT uMapType);

At a Glance

Header file: Winuser.h
Component: keybd
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE supports only a value of 2 for the uMapType parameter - mapping from virtual keys to unshifted characters.
