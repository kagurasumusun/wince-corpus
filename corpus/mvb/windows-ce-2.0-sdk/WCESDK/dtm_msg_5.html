DTM_ENDOFSOURCE

A DTM_ENDOFSOURCE message is sent by an application to inform the HTML control that the document is complete.

Syntax

DTM_ENDOFSOURCE
wParam = 0,
lParam = 0,

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

None.

Return Value

This message does not return a value.

Remarks

This message implies that no more text will be added until the document is cleared. This allows the HTML control to clean up error conditions resulting from incomplete data or corrupt or invalid HTML text.
