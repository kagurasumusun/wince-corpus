LV_FINDINFO

The LV_FINDINFO structure contains information used to search for a list view item.

Syntax

typedef struct _LV_FINDINFO {
 UINT flags;
LPCSTR psz;
LPARAM lParam;
POINT pt;
UINT vkDirection;
} LV_FINDINFO;
