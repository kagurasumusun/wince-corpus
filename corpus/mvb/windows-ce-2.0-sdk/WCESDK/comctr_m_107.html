SBN_SIMPLEMODECHANGE

The SBN_SIMPLEMODECHANGE notification message sent by a status window control when the simple mode changes due to a SB_SIMPLE message. This notification is sent in the form of a WM_NOTIFY message.

Syntax

SBN_SIMPLEMODECHANGE
lpnmh = (NMHDR*) lParam;
