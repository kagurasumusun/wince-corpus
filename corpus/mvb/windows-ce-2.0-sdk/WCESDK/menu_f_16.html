TrackPopupMenu

The TrackPopupMenu function displays a floating pop-up menu at the specified location and tracks the selection of items on the pop-up menu. The floating pop-up menu can appear anywhere on the screen.

Syntax

BOOL TrackPopupMenu(HMENU hMenu, UINT uFlags, int x, int y, int nReserved, HWND hWnd, const RECT *prcRect);

At a Glance

Header file: Winuser.h
Component: menu
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the following flags for the uFlags parameter:
TPM_NONOTIFY

TPM_LEFTBUTTON

TPM_RIGHTBUTTON
