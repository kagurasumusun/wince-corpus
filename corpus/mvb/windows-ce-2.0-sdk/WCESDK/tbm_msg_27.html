TBM_SETTICFREQ

The TBM_SETTICFREQ message sets the interval frequency for tick marks in a trackbar. For example, if the frequency is set to two, a tick mark is displayed for every other increment in the trackbar's range. The default setting for the frequency is one; that is, every increment in the range is associated with a tick mark.

Syntax

TBM_SETTICFREQ
wParam = (WPARAM) wFreq;
lParam = (LPARAM)(LONG) lPosition;
