Toolhelp32ReadProcessMemory

The Toolhelp32ReadProcessMemory function copies memory allocated to another process into an application-supplied buffer.

Syntax

BOOL WINAPI Toolhelp32ReadProcessMemory( DWORD th32ProcessID, LPCVOID lpBaseAddress, LPVOID lpBuffer, DWORD cbRead, LPDWORD lpNumberOfBytesRead);

At a Glance

Header file: Tlhelp32.h
Platforms: H/PC
Versions: 2.0 and later
