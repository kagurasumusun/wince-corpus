ITypeInfo::GetDocumentation

The ITypeInfo::GetDocumentation method retrieves the documentation string, name of the complete Help file name and path, and the context identifier for the Help topic for a specified type description.

Syntax

HRESULT GetDocumentation(
MEMBERID memid,
BSTR FAR* pBstrName,
BSTR FAR* pBstrDocString,
unsigned long FAR* pdwHelpContext,
BSTR FAR* pBstrHelpFile
);
