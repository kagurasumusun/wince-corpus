LVN_ODSTATECHANGED

The LVN_ODSTATECHANGED notification message is sent by a list view control when the state of an item or range of items has changed. This notification is sent in the form of a WM_NOTIFY message.

Syntax

LVN_ODSTATECHANGED
lpStateChange = (LPNMLVODSTATECHANGE) lParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

lpStateChange
Address of an NMLVODSTATECHANGE structure that contains information about the item or items that have changed.

Return Values

The application receiving this notification must return zero.
