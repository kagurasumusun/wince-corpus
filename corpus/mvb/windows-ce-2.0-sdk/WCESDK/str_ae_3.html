CEBLOB

The CEBLOB structure contains information about a BLOB of data in the object store.

Syntax

typedef struct _CEBLOB {
 DWORD dwCount;
LPBYTE lpb;
} CEBLOB;

At a Glance

Header file: Winbase.h
Component:
Platforms: H/PC
Windows CE versions: 1.01 and later

Members

dwCount
Size, in bytes, of the BLOB.
lpb
Pointer to the beginning of the BLOB.

Remarks

When writing applications for Windows CE version 1.0, use the PEGBLOB structure .
