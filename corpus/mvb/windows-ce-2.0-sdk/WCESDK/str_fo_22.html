MAILSORTINFO

The MAILSORTINFO structure is used to describe the order in which messages are sorted for a particular mail handle.

Syntax

typedef struct _MAILSORTINFO {
MAILSORTFIELD iSort;
BOOL fAscending;
int cMsgs;
} MAILSORTINFO, *PMAILSORTINFO;

At a Glance

Header file: Msgstore.h
Component/Module:
Platforms:
Versions: 2.0 and later

Members

iSort
Specifies the field by which the database is sorted for the specified mail handle. See the MAILSORTFIELD enumeration.
fAscending
TRUE means the records are sorted in ascending order on the specified key. FALSE means descending order.
cMsgs
Specifies the number of messages currently in the store.
