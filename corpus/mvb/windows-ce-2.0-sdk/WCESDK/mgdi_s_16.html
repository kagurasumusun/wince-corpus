PALETTEENTRY

The PALETTEENTRY structure specifies the color and usage of a logical palette entry. A logical palette is defined by a LOGPALETTE structure.

Syntax

typedef struct tagPALETTEENTRY { // pe
 BYTE peRed;
BYTE peGreen;
BYTE peBlue;
BYTE peFlags;
} PALETTEENTRY;

At a Glance

Header file: Wingdi.h
Component: mgpal
Platforms: H/PC
Versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Window CE ignores the peFlags member. It should be initialized to 0.
