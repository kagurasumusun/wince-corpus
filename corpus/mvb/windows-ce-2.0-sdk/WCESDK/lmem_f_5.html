HeapReAlloc

The HeapReAlloc function reallocates a block of memory from a heap. The allocated memory is not movable.

Syntax

LPVOID HeapReAlloc(HANDLE hHeap, DWORD dwFlags, LPVOID lpMem, DWORD dwBytes);

At a Glance

Header file: Winbase.h
Component: lmem
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the HEAP_GENERATE_EXCEPTIONS value for the dwFlags parameter.
