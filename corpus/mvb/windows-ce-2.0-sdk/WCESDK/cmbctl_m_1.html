CB_DELETESTRING

An application sends a CB_DELETESTRING message to delete a string in the list box of a combo box.

Syntax

CB_DELETESTRING
wParam = (WPARAM) index,
lParam = 0

At a Glance

Header file: Winuser.h
Component/Module: Combo box control component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK
