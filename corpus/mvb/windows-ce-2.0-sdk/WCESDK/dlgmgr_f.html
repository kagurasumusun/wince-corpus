CCHookProc

The CCHookProc function is an application-defined or library-defined callback function that is used with the Color common dialog box. CCHookProc receives messages or notifications intended for the default dialog box procedure.

Syntax

UINT APIENTRY CCHookProc(HWND hdlg, UINT uiMsg, WPARAM wParam, LPARAM lParam);
