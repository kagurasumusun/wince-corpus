COMPOSITIONFORM

The COMPOSITIONFORM structure contains position information for a composition window.

Syntax

typedef _tagCOMPOSITIONFORM {
DWORD dwStyle;
POINT ptCurrentPos;
RECT rcArea;
} COMPOSITIONFORM;

Remarks

Windows CE does not support the following values for the dwStyle member:
CFS_FORCE_POSITION

CFS_POINT

CFS_RECT
