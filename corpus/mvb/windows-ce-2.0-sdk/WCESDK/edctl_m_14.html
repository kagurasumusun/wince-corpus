EM_LINESCROLL

An application sends an EM_LINESCROLL message to scroll the text vertically or horizontally in a multiline edit control.

Syntax

EM_LINESCROLL
wParam = (WPARAM) cxScroll;
lParam = (LPARAM) cyScroll;
