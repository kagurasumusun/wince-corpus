IStream::Revert

The IStream::Revert method discards all changes that have been made to a transacted stream since the last IStream::Commit call. On streams open in direct mode and streams using the OLE compound file implementation of IStream::Revert, this method has no effect.

Syntax

HRESULT Revert(void);
