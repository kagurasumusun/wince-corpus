LVM_SETCOLUMNORDERARRAY

The LVM_SETCOLUMNORDERARRAY message sets the left-to-right order of columns in a list view control.

Syntax

LVM_SETCOLUMNORDERARRAY
wParam = (WPARAM) (int) iCount;
lParam = (LPARAM) (LPINT) lpiArray;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: ListView_SetColumnOrderArray

Parameters

iCount
Size, in elements, of the buffer at lpiArray.
lpiArray
Address of an array that specifies the order in which columns should be displayed, in left-to-right order. For example, if the contents of the array are {2,0,1}, the control displays column 2, column 0, and column 1 in that order.

Return Values

Returns nonzero if successful, or zero otherwise.
