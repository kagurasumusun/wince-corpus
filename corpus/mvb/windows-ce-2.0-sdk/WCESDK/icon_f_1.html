DestroyIcon

The DestroyIcon function destroys an icon and frees any memory the icon occupied.

Syntax

BOOL DestroyIcon(HICON hIcon);

At a Glance

Header file: Winuser.h
Component: icon
iconcurs
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The DestroyIcon function may be called on the icon handle returned from CreateIconIndirect, ExtractIconEx, LoadImage or LoadIcon. The icon handle is invalid after calling DestroyIcon.
