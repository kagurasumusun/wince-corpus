WNetOpenEnum

The WNetOpenEnum function starts an enumeration of network resources or existing connections.

Syntax

DWORD WNetOpenEnum(DWORD dwScope, DWORD dwType, DWORD dwUsage, LPNETRESOURCE lpNetResource, LPHANDLE lphEnum);

At a Glance

Header file: Winnetwk.h
Module: Rdrapi
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The WNetOpenEnum function is called by the network browser application to create lists of available resources on the network.

Windows CE does not support the predefined value of RESOURCE_CONTEXT because a device cannot belong to a specific network context.
