WM_SETTINGCHANGE

The system sends the WM_SETTINGCHANGE message to all top-level windows after a system-wide change has been made.

The WM_SETTINGCHANGE message is the same as the older WM_WININICHANGE message.

Syntax

WM_SETTINGCHANGE
wParam = wFlag;
lParam = (LPARAM)(LPCTSTR) pszSection;

At a Glance

Header file:
Module/Component:
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The wParam is set to NULL.

The lParam is a constant (defined in winuser.h), rather than a pointer to a string.

At this time, the only value defined for lParam is INI_INTL, which indicates that a user has made a change to the regional settings in the control panel. This message is sent to all running applications. An application doesn't need to send this message.
