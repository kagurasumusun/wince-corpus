IViewObject::GetAdvise

The IViewObject::GetAdvise method retrieves the existing advisory connection on the object if there is one and returns the parameters used in the most recent call to the IViewObject::SetAdvise method.

Syntax

HRESULT GetAdvise(
DWORD * pdwAspect,
DWORD * padvf,
IAdviseSink ** ppAdvSink
);

Platforms: H/PC
