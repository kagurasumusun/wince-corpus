TB_SETROWS

The TB_SETROWS message sets the number of rows of buttons in a toolbar.

Syntax

TB_SETROWS
wParam = (WPARAM)MAKEWPARAM(cRows,fLarger);
lParam = (LPARAM)(LPRECT) lprc;
