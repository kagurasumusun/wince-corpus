WM_SETICON

An application sends the WM_SETICON message to associate a new big or small icon with a window.

Syntax

WM_SETICON
wParam = (WPARAM)(BOOL) fType;
lParam = (LPARAM)(HICON) hicon;

At a Glance

Header file:
Component/Module: Icon component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Icons are stored per window class, not per window.
