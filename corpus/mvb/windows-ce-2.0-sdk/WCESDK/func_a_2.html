AddPropSheetPageProc

The AddPropSheetPageProc application-defined callback function is used by a property sheet extension to add a page to a property sheet.

Syntax

BOOL CALLBACK AddPropSheetPageProc(HPROPSHEETPAGE hpage, LPARAM lParam);

At a Glance

Platforms: H/PC
Windows CE versions: 1.0 and later
