CDN_FILEOK

The CDN_FILEOK notification message is sent by an Explorer-style Open or Save As common dialog box when the user specifies a filename and clicks the OK button. Your OFNHookProc hook procedure receives this message in the form of a WM_NOTIFY message.

Syntax

CDN_FILEOK
lpon = (LPOFNOTIFY) lParam;
