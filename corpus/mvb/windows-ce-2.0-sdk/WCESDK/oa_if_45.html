IViewObject::SetAdvise

The IViewObject::SetAdvise method sets up a connection between the view object and an advise sink so that the advise sink can be notified about changes in the object's view.

Syntax

HRESULT SetAdvise(
DWORD dwAspect,
DWORD advf,
IAdviseSink * pAdvSink
);
