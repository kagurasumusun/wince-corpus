CEVALUNION

The CEVALUNION union contains a value for a property.

Syntax

typedef union _CEVALUNION {
 short iVal;
USHORT uiVal;
long lVal;
ULONG ulVal;
FILETIME filetime;
LPWSTR lpwstr;
CEBLOB blob;
} CEVALUNION;

At a Glance

Header file: Winbase.h
Component:
Platforms: H/PC
Windows CE versions: 1.01 and later

Members

iVal
Specifies an integer.
uiVal
Specifies an unsigned integer.
lVal
Specifies a long integer.
ulVal
Specifies an unsigned long integer.
filetime
Specifies a FILETIME structure.
lpwstr
Points to a null-terminated string.
blob
Specifies a CEBLOB structure.

Remarks

When writing applications for Windows CE version 1.0, use the PEGVALUNION union.
