LVN_COLUMNCLICK

The LVN_COLUMNCLICK notification message notifies a list view control's parent window that a column was tapped. This notification message is sent in the form of a WM_NOTIFY message.

Syntax

LVN_COLUMNCLICK
pnmv = (NM_LISTVIEW FAR *) lParam;
