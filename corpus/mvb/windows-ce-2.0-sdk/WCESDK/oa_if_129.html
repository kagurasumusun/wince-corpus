ITypeInfo::GetDllEntry

The ITypeInfo::GetDllEntry method retrieves a description or specification of an entry point for a function in DLL.

HRESULT GetDllEntry(
MEMBERID memid,
INVOKEKIND invKind,
BSTR FAR* pBstrDllName,
BSTR FAR* pBstrName,
unsigned short FAR* pwOrdinal
);
