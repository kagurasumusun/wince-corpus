LVM_GETNEXTITEM

The LVM_GETNEXTITEM message searches for a list view item that has the specified properties and bears the specified relationship to a given item. You can send this message explicitly or by using the ListView_GetNextItem macro.

Syntax

LVM_GETNEXTITEM
wParam = (WPARAM)(int) iStart;
lParam = MAKELPARAM((UINT)flags,0);
