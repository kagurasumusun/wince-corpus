GetParent

The GetParent function retrieves the handle to the specified child window's parent window.

Syntax

HWND GetParent(HWND hWnd);

At a Glance

Header file: Winuser.h
Component: Winmgr
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE version 1.0 does not support owned windows, except for dialog boxes.
