BINDPTR

The BINDPTR union holds a pointer to a FUNCDESC, VARDESC or ITypeComp interface.

Syntax

typedef union tagBINDPTR {
FUNCDESC FAR *lpfuncdesc;
VARDESC FAR *lpvardesc;
ITypeComp FAR *lptcomp;
} BINDPTR;

Component: ole32
