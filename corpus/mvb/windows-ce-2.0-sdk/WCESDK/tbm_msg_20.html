TBM_SETRANGEMAX

The TBM_SETRANGEMAX message sets the maximum position for the slider in a trackbar.

Syntax

TBM_SETRANGEMAX
wParam = (WPARAM) fRedraw;
lParam = (LPARAM) lMaximum;
