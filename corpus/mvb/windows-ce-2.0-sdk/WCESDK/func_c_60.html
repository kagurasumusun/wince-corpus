CeMoveFile

The CeMoveFile function renames an existing file or a directory ¾ including all its children. This is the RAPI version of the MoveFile function.

Syntax

BOOL CeMoveFile(LPCWSTR lpExistingFileName, LPCWSTR lpNewFileName);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegMoveFile function.

For more information about using RAPI functions, see Remote API Functions.
