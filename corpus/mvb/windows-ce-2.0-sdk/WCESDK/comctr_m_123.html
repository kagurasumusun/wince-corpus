TB_REPLACEBITMAP

The TB_REPLACEBITMAP message replaces an existing bitmap with a new bitmap.

Syntax

TB_REPLACEBITMAP
wParam = 0;
lParam = (LPARAM) (LPTBREPLACEBITMAP) ptbrb;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

ptbrb
Address of a TBREPLACEBITMAP structure that contains the information of the bitmap to be replaced and the new bitmap.

Return Values

Returns non-zero if successful or zero otherwise.
