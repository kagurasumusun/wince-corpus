LoadTypeLib

The LoadTypeLib function loads and registers a typelib2 type library.

Syntax

HRESULT LoadTypeLib( OLECHAR FAR * szFile, ITypeLib FAR * FAR * pptlib);

At a Glance

Header file: Oleauto.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.

Remarks

Windows CE supports only typelib2 type libraries. The LoadTypeLib function loads type libraries only from a resource, that is from DLL or EXE files. It willl not load foreign or stand-alone type library files.

Passing into this function any invalid and, under some circumstances, NULL pointers will result in unexpected termination of the application. For more information about handling exceptions, see COM and Automation.
