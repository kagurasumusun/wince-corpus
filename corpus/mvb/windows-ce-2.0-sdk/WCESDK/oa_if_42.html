IViewObject::Freeze

The IViewObject::Freeze method freezes a certain aspect of the object's presentation so that it does not change until the IviewObject::Unfreeze method is called.

Syntax

HRESULT Freeze(
DWORD dwAspect,
LONG lindex,
void * pvAspect,
DWORD * pdwFreeze
);

At a Glance

Header file: Oleidl.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.
