GetMenuItemInfo

The GetMenuItemInfo function retrieves information about a menu item.

Syntax

BOOL GetMenuItemInfo(HMENU hmenu, UINT uItem, BOOL fByPosition, LPMENUITEMINFO pmii);

At a Glance

Header file: Winuser.h
Component: menu
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The MIM_CHECKMARKS flag value is not supported for the fMask member of the MENUITEMINFO structure pointed to by the pmii parameter of this function.
