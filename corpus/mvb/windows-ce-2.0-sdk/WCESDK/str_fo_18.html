MailAtt

The MailAtt structure is used to describe a single attachment to a mail message.

Syntax

typedef struct MailAtt_s {
UINT uiAttachmentNumber;
DWORD dwFlags;
ULONG ulCharacterPosition;
ULONG ulSize;
LPWSTR szOriginalName;
LPWSTR szLocalName;
} MailAtt, *lpMailAtt;

At a Glance

Header file: Msgstore.h
Component/Module:
Platforms:
Versions: 2.0 and later

Members

uiAttachmentNumber
A number, counting from 1, to indicate which attachment is specified.
dwFlags
This parameter has three bit-masks to categorize three groups of the mail attachment flags: _ALL_, _THIS_, and _NUMBER_.
ATT_ALL_FLAGS_MASK
For flags that apply to all attachments to the message. Currently no such flags are defined in this category.
ATT_THIS_FLAGS_MASK
For flags that apply only to a specified attachment. Currently two flags are defined in this category.
ATT_THIS_FLAGS_MASK Description
ATT_DISP_RETRIEVE User has requested to download the non-local attachment to the message. Set only if ATT_DOWNLOADABLE is set.
ATT_DOWNLOADABLE The originating transport is capable of downloading the attachment independently.


ATT_NUMBER_MASK
For number masks used to mark the number of attachment files (or headers) to the mail message. Currently no number mask is defined.

ulCharacterPosition
The character position of the attachment in the text portion of the message. Not currently supported.
ulSize
The size of the attached file. For MailPutAttachment it must be specified for a non-local attachment when szLocalName is NULL. For MailgetAttachment it is assigned to the size of the attached file for either a local or a non-local attachment.
szOriginalName
The name of the original file of attached to the message, without path information.
szLocalName
The pathname of the attached file on a Windows CE device. It must be set to NULL for a non-local attachment.

Remarks

From the user point of view, an attachment is the file (szOriginalName) attached to the message. For an application developer, however, the attachment may be conveniently viewed as consisting of a header and the attached file. The header is the MailAtt data structure itself. The original file name does not contain path information.

An application developer may want to work with either local or non-local attachments. A local attachment has a header and a copy (szLocalName) of the original file (szOriginalName) stored on a Windows CE device. A non-local attachment does not store the attached file locally and is simply a place-holder for the original file. For a non-local attachment, szLocalName must be set NULL and ulSize specified.

Non-local attachments are possible only when a message is linked to a service. For some services, an attachment header can be used to make the file local on demand.
