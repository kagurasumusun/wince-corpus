OleSave

The OleSave function saves an object opened in transacted mode into the specified storage object.

Syntax

WINOLEAPI OleSave( IPersistStorage * pPS, IStorage * pStg, BOOL fSameAsLoad );

At a Glance

Header file: Ole2.h
Component: Ole232
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.

Remarks

Passing into this function any invalid and, under some circumstances, NULL pointers will result in unexpected termination of the application. For more information about handling exceptions, see COM and Automation.
