accept

The Windows Sockets accept function accepts a connection on a socket. For IrSockets implementation of this function, Af_irda.h must be included explicitly.

Syntax

SOCKET accept(SOCKET s, struct sockaddr FAR *addr, int FAR *addrlen);

At a Glance

Header file: Winsock.h
Module: Winsock
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the WSAEINTR error value.

For IrSocket implementation, the addr and addrlen parameters should always be NULL.
