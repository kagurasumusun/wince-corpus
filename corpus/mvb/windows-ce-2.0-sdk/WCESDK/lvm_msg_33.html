LVM_INSERTITEM

The LVM_INSERTITEM message inserts a new item in a list view control. You can send this message explicitly or by using the ListView_InsertItem macro.

Syntax

LVM_INSERTITEM
wParam = 0;
lParam = (LPARAM)(const LV_ITEM FAR *) pitem;
