GetSysColorBrush

The GetSysColorBrush function retrieves a handle identifying a logical brush that corresponds to the specified color index.

Syntax

HBRUSH GetSysColorBrush(int nIndex);

At a Glance

Header file: Wingdi.h
Component: mgdraw
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The values assigned to the COLOR_X flags in Windows CE are different from the values assigned to these flags in Windows desktop platforms. Therefore, you should specify the COLOR_X flag value, rather than the corresponding integer value, for the nIndex parameter.
