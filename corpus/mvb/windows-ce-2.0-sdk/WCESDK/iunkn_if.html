IUnknown

The IUnknown interface lets clients get pointers to other interfaces on a given object through the IUnknown::QueryInterface method, and manage the existence of the object through the IUnknown::AddRef and IUnknown::Release methods. All other COM interfaces are inherited, directly or indirectly, from IUnknown. Therefore, the three methods in IUnknown are the first entries in the VTable for every interface.

At a Glance

Header file: Unknown.h
Component: com
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Methods Description
IUnknown::QueryInterface Returns pointers to supported interfaces.
IUnknown::AddRef Increments reference count.
IUnknown::Release Decrements reference count.
