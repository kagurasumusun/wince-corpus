WM_LBUTTONDBLCLK

The WM_LBUTTONDBLCLK message is posted when the user double-taps the touch-screen while the stylus is pressed to the touch screen in the client area of a window. If the stylus is not captured, the message is posted to the window beneath the stylus position. Otherwise, the message is posted to the window that has captured the mouse.

Syntax

WM_LBUTTONDBLCLK
fwKeys = wParam;
xPos = LOWORD(lParam);
yPos = HIWORD(lParam);
