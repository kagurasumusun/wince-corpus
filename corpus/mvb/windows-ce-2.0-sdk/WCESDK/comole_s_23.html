STGMEDIUM

The STGMEDIUM structure describes a medium of transfer for data objects.

Syntax

typedef struct tagSTGMEDIUM {
unsigned long tymed;
union {
Handle hGlobal;
char * lpszFileName;
LPSTREAM pstm;
LPSTORAGE pstg;
};
LPUNKNOWN pUnkForRelease;
} STGMEDIUM;

At a Glance

Header file: objidl.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation Microsoft Platform SDK

Remarks

Th string you pass in the lpszFileName parameter must be allocated by using either GlobalAlloc or malloc.
