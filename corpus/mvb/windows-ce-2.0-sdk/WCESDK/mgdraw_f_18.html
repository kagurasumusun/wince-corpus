SetROP2

The SetROP2 function sets the current foreground mix mode. GDI uses the foreground mix mode to combine pens and interiors of filled objects with the colors already on the screen. The foreground mix mode defines how colors from the brush or pen are combined with the colors in the existing image.

Syntax

int SetROP2( HDC hdc, int fnDrawMode);
