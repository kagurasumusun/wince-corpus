NMMOUSE

The NMMOUSE structure contains information used with mouse notification messages.

Syntax

typedef struct tagNMMOUSE {
NMHDR hdr;
DWORD dwItemSpec;
DWORD dwItemData;
POINT pt;
} NMMOUSE, FAR * LPNMMOUSE;

At a Glance

Header file:
Component:
Platforms: H/PC
Versions: 2.0 and later

Members

hdr
NMHDR structure that contains additional information about this notification.
dwItemSpec
Control-specific item identifier.
dwItemData
Control-specific item data.
pt
A POINT structure that contains the screen coordinates of the mouse when the click occurred.
