CeRegCreateKeyEx

The CeRegCreateKeyEx function creates the specified key. If the key already exists in the registry, CeRegCreateKeyEx opens it. This is the RAPI version of the RegCreateKeyEx function.

Syntax

LONG CeRegCreateKeyEx(HKEY hKey, LPCWSTR lpszSubKey, DWORD dwReserved, LPWSTR lpszClass, DWORD dwOptions, REGSAM samDesired, LPSECURITY_ATTRIBUTES lpSecurityAttributes, PHKEY phkResult, LPDWORD lpdwDisposition);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegRegCreateKeyEx function.

For more information about using RAPI functions, see Remote API Functions.
