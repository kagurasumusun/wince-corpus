LV_KEYDOWN

The LV_KEYDOWN structure contains information about a keyboard event in a list view control.

Syntax

typedef struct tagLV_KEYDOWN {
 NMHDR hdr;
WORD wVKey;
UINT flags;
} LV_KEYDOWN;
