TYPEDESC

The TYPEDESC structure is used to describe the type of a variable, the return type of a function, or the type of a function parameter.

Syntax

typedef struct FARSTRUCT tagTYPEDESC {
union {
struct FARSTRUCT tagTYPEDESC FAR *lptdesc;
struct FARSTRUCT tagARAYDESC FAR *lpadesc;
HREFTYPE hreftype;
} UNION_NAME(u);
VARTYPE vt;
} TYPEDESC;
