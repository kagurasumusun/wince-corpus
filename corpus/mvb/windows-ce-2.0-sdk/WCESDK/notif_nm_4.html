NM_INLINE_SOUND

The NM_INLINE_SOUND notification message is sent by the HTML viewer control to notify the application to load the sound.

Syntax

NM_INLINE_SOUND
NM_HTMLVIEW *pnmHtmlView = (NM_HTMLVIEW *)lParam;
szSRCText = pnmHtmlView->szTarget;

dwLoopCount = pnmHtmlView->dwCookie;

switch(pnmHtmlView->hdr.code) {
case NM_INLINE_SOUND:
};

At a Glance

Header file: Htmlctrl.h
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

pnmHtmlView
Pointer to an NM_HTMLVIEW structure that contains information about the NM_INLINE_SOUND notification message.
szSRCText
String that contains the text from the SRC parameter of the BGSOUND tag in the HTML text.
dwLoopCount
Loop count value from the LOOP parameter of the BGSOUND tag.

Return Values

This message does not return a value.
