NM_NCHITTEST

The NM_NCHITTEST message is sent by a rebar control when the control receives a WM_NCHITTEST message. This notification message is sent in the form of a WM_NOTIFY message.

Syntax

NM_NCHITTEST
lpnmmouse = (LPNMMOUSE) lParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

lpnmmouse
Address of a NMMOUSE structure that contains information about the notification. The dwItemSpec member contains the band index over which the hit test message occurred and the pt member contains the mouse coordinates of the hit test message.

Return Values

Return zero to allow the rebar to process the hit test message normally or one of the HT* values documented under WM_NCHITTEST.
