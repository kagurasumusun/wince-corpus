DTM_ADDTEXTW

A DTM_ADDTEXTW message is sent by an application to add Unicode text to the HTML control.

Syntax

DTM_ADDTEXT
wParam = (WPARAM)(BOOL) bPlainText;
lParam = (LPARAM)(LPWSTR) szwText;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

bPlainText
Flag to indicate the format of the text to be added. If bPlainText is TRUE, the text is treated as plain text. If bPlainText is FALSE, the text is treated as HTML formatted text.
szwText
Null-terminated wide character text string to be added to the HTML control.

Return Value

This message does not return a value.

Remarks

This is the Unicode version of DTM_ADDTEXT. After the Unicode text has been added to the HTML control, the text parameters in the notification messages will be Unicode.
