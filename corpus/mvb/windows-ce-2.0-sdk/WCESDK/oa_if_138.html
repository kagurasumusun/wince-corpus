ITypeInfo::GetTypeAttr

The ITypeInfo::GetTypeAttr method retrieves a TYPEATTR structure that contains the attributes of the type description.

Syntax

HRESULT GetTypeAttr(
TYPEATTR FAR* FAR* ppTypeAttr
);
