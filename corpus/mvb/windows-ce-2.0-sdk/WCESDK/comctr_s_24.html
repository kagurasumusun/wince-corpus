NMLVFINDITEM

The NMLVFINDITEM structure that contains information the owner needs to find items requested by a virtual list view control. This structure is sent to the owner during notification using the LVN_ODFINDITEM message.

Syntax

typedef struct _NMLVFINDITEM {
NMHDR hdr;
int iStart;
LVFINDINFO lvfi;
} NMLVFINDITEM, *PNMLVFINDITEM;

At a Glance

Header file:
Component:
Platforms: H/PC
Versions: 2.0 and later

Members

hdr
NMHDR structure that contains information on this notification message.
iStart
Item index to act as the start of the search.
lvfi
LVFINDINFO structure that contains information necessary to perform a search.
