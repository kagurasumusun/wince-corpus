LB_SETTABSTOPS

An application sends an LB_SETTABSTOPS message to set the tab-stop positions in a list box.

Syntax

LB_SETTABSTOPS
wParam = (WPARAM) cTabs;
lParam = (LPARAM)(LPINT) lpnTabs;
