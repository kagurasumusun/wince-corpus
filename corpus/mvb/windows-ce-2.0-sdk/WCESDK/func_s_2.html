SetEvent

The SetEvent function sets the state of the specified event object to signaled.

Syntax

BOOL SetEvent(HANDLE hEvent);

At a Glance

Header file: Kfuncs.h
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support waiting for a process or thread. Waiting on an invalid handle will return FALSE.
