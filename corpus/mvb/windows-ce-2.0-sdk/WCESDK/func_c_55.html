CeGetVersionEx

The CeGetVersionEx function obtains extended information about the version of the operating system that is currently running. This is the RAPI version of the GetVersionEx function.

Syntax

BOOL CeGetVersionEx(LPDEGOSVERSIONINFO lpVersionInformation);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegGetVersionEx function.

For more information about using RAPI functions, see Remote API Functions.
