DTM_SETRANGE

The DTM_SETRANGE message sets the minimum and maximum allowable system times for a date and time picker (DTP) control.

Syntax

DTM_SETRANGE
wParam = (WPARAM) flags;
lParam = (LPARAM) lpSysTimeArray;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: DateTime_SetRange

Parameters

flags
Value specifying which range values are valid. This parameter can be a combination of the following values:
GDTR_MIN
The first element in the SYSTEMTIME structure array is valid and will be used to set the minimum allowable system time.
GDTR_MAX
The second element in the SYSTEMTIME structure array is valid and will be used to set the maximum allowable system time.

lpSysTimeArray
Base address of a two-element array of SYSTEMTIME structures. The first element of the SYSTEMTIME array contains the minimum allowable time. The second element of the SYSTEMTIME array contains the maximum allowable time. It is not necessary to fill an array element that is not specified in the flags parameter.

Return Values

Returns nonzero if successful, or zero otherwise.
