NM_HOTSPOT

The NM_HOTSPOT notification message is sent by the HTML viewer control if the user taps on a link or submits a form.

Syntax

NM_HOTSPOT
NM_HTMLVIEW *pnmHtmlView = (NM_HTMLVIEW *)lParam;
szHREFText = pnmHtmlView->szTarget;
szPostData = pnmHtmlView->szData;

switch(pnmHtmlView->hdr.code) {
 case NM_HOTSPOT:
};

At a Glance

Header file: Htmlctrl.h
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

pnmHtmlView
Pointer to an NM_HTMLVIEW structure that contains information about the NM_HOTSPOT notification message.
szHREFText
String that contains the contents of the HREF field in the HTML text.
szPostData
String that contains the query data for a POST form submission.

Return Value

This message does not return a value.

Remarks

The szTarget field of the NM_HTMLVIEW structure will contain the HREF text. On the click from an Anchor, the HREF text will be the contents of the HREF field. For a GET form submission, the HREF text will include the form query data. For a POST form submission, the HREF text will include only the base contained in the <FORM> tag, and the query data will be passed in the szData field of the NM_HTMLVIEW structure.
