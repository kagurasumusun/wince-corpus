PARAMDATA

The PARAMDATA structure is used to describe a parameter accepted by a method or property.

Syntax

typedef struct FARSTRUCT tagPARAMDATA {
OLECHAR FAR *szName;
VARTYPE vtReturn;
} PARAMDATA;
