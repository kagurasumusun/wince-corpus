PSM_RESTARTWINDOWS

The PSM_RESTARTWINDOWS message indicates that Windows needs to be restarted for the changes to take effect. An application should send this message only in response to the PSN_APPLY or PSN_KILLACTIVE notification message.

Syntax

PSM_RESTARTWINDOWS
wParam = 0;
lParam = 0;
