FORMATETC

The FORMATETC structure is a generalized clipboard format, enhanced to encompass a target device, the aspect, or view of the data, and a storage medium.

Syntax

typedef struct FARSTRUCT tagFORMATETC {
unsigned long cfFormat;
DVTARGETDEVICE * ptd;
unsigned long dwAspect;
long lindex;
unsigned long tymed;
} FORMATETC, * LPFORMATETC;

At a Glance

Header file: objidl.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation Microsoft Platform SDK

Remarks

Windows CE does not support the CF_ENHMETAFILE or CF_METAFILEPICT values in the cfFormat parameter.
