MailAttArray

The MailAttArray structure is used to describe a series of mail attachments.

Syntax

typedef struct MailAttArray_s {
DWORD dwFlags;
UINT uiAttCount;
lpMailAtt AttArray[];
} MailAttArray, *lpMailAttArray;

At a Glance

Header file: Msgstore.h
Component/Module:
Platforms:
Versions: 2.0 and later

Members

dwFlags
Flags that apply to all of the attachments. Flags not in the ATT_ALL_FALGS_MASK area are ignored. Currently no valid flags are supported.
uiAttCount
The count of attachments in the following AttArray.
AttArray
An array of MailAtt structures. uiAttCount specifies the number of the elements in the array.
