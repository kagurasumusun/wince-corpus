RB_GETRECT

The RB_GETRECT message retrieves the bounding rectangle for a given band in a rebar control.

Syntax

RB_GETRECT
wParam = (WPARAM)(INT) iBand;
lParam = (LPARAM)(LPRECT) lprc;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

iBand
Zero-based index of a band in the rebar control.
lprc
Address of a RECT structure that will receive the bounds of the rebar band.

Return Values

Returns nonzero if successful, or zero otherwise.
