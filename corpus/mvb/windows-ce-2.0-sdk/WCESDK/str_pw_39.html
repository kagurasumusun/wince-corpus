TV_HITTESTINFO

The TV_HITTESTINFO structure contains information used to determine the location of a point relative to a tree view control.

typedef struct _TVHITTESTINFO { tvhtst
 POINT pt;
UINT flags;
HTREEITEM hItem;
} TV_HITTESTINFO, FAR *LPTV_HITTESTINFO;
