LoadRegTypeLib

The LoadRegTypeLib function uses registry information to load a type library.

Syntax

HRESULT LoadRegTypeLib( REFGUID rguid, unsigned short wVerMajor, unsigned short wVerMinor, LCID lcid, ITypeLib FAR * FAR * pptlib);

At a Glance

Header file: Oleauto.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.

Remarks

Only typelib2 type library is supported and loadable from resource.

Passing into this function any invalid and, under some circumstances, NULL pointers will result in unexpected termination of the application. For more information about handling exceptions, see COM and Automation.
