RapiFreeBuffer

The RapiFreeBuffer function frees the memory on the desktop PC allocated by a call to PegFindAllDatabases, PegFindAllFiles, or PegReadRecordProps.

Syntax

NRESULT RapiFreeBuffer(LPVOID Buffer);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Versions: 1.0 and later

Parameters

Buffer
Pointer to the buffer to be freed.

Return Values

If the function completes successfully it returns the value SOK, otherwise it returns E_FAIL.

Remarks

Any RAPI function that allocates memory on the desktop PC on the users behalf must be freed by calling the RapiFreeBuffer function. For more information about using RAPI functions, see Remote API Functions.
