WM_SYSKEYUP

The WM_SYSKEYUP message is posted to the window with the keyboard focus when the user releases a key that was pressed while the ALT key was held down. It also occurs when no window currently has the keyboard focus; in this case, the WM_SYSKEYUP message is sent to the active window. The window that receives the message can distinguish between these two contexts by checking the context code in the lKeyData parameter.

Syntax

WM_SYSKEYUP
nVirtKey = (int) wParam;
lKeyData = lParam;

At a Glance

Header file:
Component/Module: Keyboard and virtual mapping component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Only the following lKeyData flags are supported:

  • 0-15. Specifies the repeat count. The value is the number of times the keystroke is repeated as a result of the user holding down the key.

  • 29. Specifies the context code. The value is one if the ALT key is held down while the key is pressed; otherwise, the value is zero.

  • 30. Specifies the previous key state. The value is one if the key is down before the message is sent, or it is zero if the key is up.

  • 31. Specifies the transition state. The value is one if the key is being released, or it is zero if the key is being pressed.
