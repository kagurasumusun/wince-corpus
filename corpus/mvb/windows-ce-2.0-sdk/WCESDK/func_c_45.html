CeFindNextFile

The CeFindNextFile function continues a file search from a previous call to the CeFindFirstFile function. This is the RAPI version of the FindNextFile function.

Syntax

BOOL CeFindNextFile(HANDLE hFindFile, LPCE_FIND_DATA lpFindFileData);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegFindNextFile function.

For more information about using RAPI functions, see Remote API Functions.
