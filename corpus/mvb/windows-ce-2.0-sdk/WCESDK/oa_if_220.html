ITypeLib::IsName

The ITypeLib::IsName method indicates whether a passed-in string contains the name of a type or member described in the library.

Syntax

HRESULT IsName(
OLECHAR FAR* szNameBuf,
unsigned long lHashVal,
BOOL pfName
);
