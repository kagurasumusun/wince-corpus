ListView_GetViewRect

The ListView_GetViewRect macro retrieves the bounding rectangle of all items in the list view control. The list view must be in icon or small icon view. You can use this macro or explicitly send the LVM_GETVIEWRECT message.

Syntax

BOOL ListView_GetViewRect(
 HWND hwnd,
 RECT FAR* prc
);
