MCM_GETCURSEL

The MCM_GETCURSEL message retrieves the system time portrayed by the currently selected date.

Syntax

MCM_GETCURSEL
wParam = 0;
lParam = (LPARAM) (LPSYSTEMTIME) lpSysTime;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: MonthCal_GetCurSel

Parameters

lpSysTime
Address of a SYSTEMTIME structure that will receive the system time information. The time members of this structure will not be modified.

Return Values

Returns nonzero if successful, or zero otherwise. This message will always fail when applied to month calendar controls set to the MCS_MULTISELECT style.
