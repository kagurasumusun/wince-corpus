IDccManSink::OnLogIpAddr

The IDccManSink::OnLogIpAddr method indicates that an IP address has been established for communication between the desktop PC and the H/PC.

Syntax

STDMETHODIMP IDccManSink::OnLogIpAddr(
);

At a Glance

Header file: Dccole.h
Platforms: H/PC
Windows CE versions: 1.0 and later

Parameters

dwIpAddr
The IP address of the H/PC.

Return Values

This method should always return NOERROR.

Remarks

The IDccManSink::OnLogIpAddr method is implemented by a client application and is called when the H/PC connection manager has determined what IP address is used to connect to the H/PC. At this point, the connection is completely established.

For more information, see Connection Notification.
