LCMapString

The LCMapString function maps one character string to another, performing a specified locale-dependent transformation. LCMapString can also be used to generate a sort key for the input string.

Syntax

int LCMapString(LCID Locale, DWORD dwMapFlags, LPCTSTR lpSrcStr, int cchSrc, LPTSTR lpDestStr, int cchDest);

At a Glance

Header file: Winnls.h
Component: coreloc
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The following dwMapFlags values are not supported:
LCMAP_LINGUISTIC_CASING

LCMAP_SIMPLIFIED_CHINESE

LCMAP_TRADITIONAL_CHINESE
