InitializeCriticalSection

The InitializeCriticalSection function initializes a critical section object.

Syntax

void InitializeCriticalSection(LPCRITICAL_SECTION lpCriticalSection);

At a Glance

Header file: Winbase.h
Component: coremain
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Use only the functions provided in the Windows CE application programming interface to manage critical section objects.
