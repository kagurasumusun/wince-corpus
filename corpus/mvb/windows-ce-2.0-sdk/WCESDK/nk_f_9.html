FindResource

The FindResource function determines the location of a resource with the specified type and name in the specified module.

Syntax

HRSRC FindResource(HMODULE hModule, LPCWSTR lpName, LPCWSTR lpType);

At a Glance

Header file: Winbase.h
Module: Nk
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The hModule parameter cannot be a NULL handle.

The lpName parameter does not support the resource ID zero ¾ that is, FindResource(h, 0 ,t) will not work as expected.

You cannot pass the RT_ANICURSOR or RT_ANIICON values in the lpType parameter.
