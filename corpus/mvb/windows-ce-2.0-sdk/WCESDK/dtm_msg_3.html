DTM_ANCHORW

A DTM_ANCHORW message is sent by an application to tell the HTML control to jump to the indicated anchor.

Syntax

DTM_ANCHORW
wParam = 0,
lParam = (LPARAM)(LPWSTR) szwAnchor;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

szwAnchor
Null-terminated, wide character text string that contains the name of the anchor to which the HTML control is to jump.

Return Value

This message does not return a value.

Remarks

If the anchor is already in the document, the jump occurs immediately. If the specified anchor is not in the document, the request will be remembered so that, if the anchor is added, the jump will occur as soon as the anchor is available. Note that while there is a pending anchor, any navigation commands from the user (keyboard scrolling or using the scroll bar) will abort the pending anchor jump.

This is the Unicode version of DTM_ANCHOR.
