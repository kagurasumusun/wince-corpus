INDEXTOOVERLAYMASK

The INDEXTOOVERLAYMASK macro prepares the index of an overlay mask so that the ImageList_Draw or ImageList_DrawEx function can use it.

Syntax

UINT INDEXTOOVERLAYMASK(
 UINT iOverlay
);
