PSM_QUERYSIBLINGS

The PSM_QUERYSIBLINGS message forwards the message to each page in the property sheet. If a page returns a nonzero value, the property sheet does not send the message to subsequent pages.

Syntax

PSM_QUERYSIBLINGS
wParam = (WPARAM) param1;
lParam = (LPARAM) param2;
