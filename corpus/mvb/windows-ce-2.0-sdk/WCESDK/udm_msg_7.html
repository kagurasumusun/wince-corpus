UDM_SETBUDDY

The UDM_SETBUDDY message sets the buddy window for an up-down control.

Syntax

UDM_SETBUDDY
wParam = (WPARAM)(HWND) hwndBuddy;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

If hwndBuddy is not NULL, it must specify an edit control because up/down controls can only be buddied with edit controls.
