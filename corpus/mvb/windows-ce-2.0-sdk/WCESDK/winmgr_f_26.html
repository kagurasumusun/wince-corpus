GetWindow

The GetWindow function retrieves the handle to a window that has the specified relationship to the specified window.

Syntax

HWND GetWindow(HWND hWnd, UINT uCmd);

At a Glance

Header file: Winuser.h
Component: Winmgr
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE version 1.0, the GW_OWNER flag value for the uCmd parameter is only supported for dialog boxes.
