ListView_GetImageList

The ListView_GetImageList macro retrieves the handle to an image list used for drawing list view items. You can use this macro or explicitly send the LVM_GETIMAGELIST message.

Syntax

HIMAGELIST ListView_GetImageList(
 HWND hwnd,
 int iImageList
);

Remarks

Windows CE supports a new value for the iImageList parameter. The LVSIL_HEADER constant specifies that the image list to be retireved is the image list displayed in the list view's header control in report view.
