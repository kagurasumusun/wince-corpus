HDN_ITEMCLICK

The HDN_ITEMCLICK notification message notifies a header control's parent window that the user tapped the control. This notification message is sent in the form of a WM_NOTIFY message.

Syntax

HDN_ITEMCLICK
phdr = (HD_NOTIFY FAR *) lParam;
