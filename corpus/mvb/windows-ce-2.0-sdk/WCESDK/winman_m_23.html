WM_SETREDRAW

An application sends the WM_SETREDRAW message to a window to allow changes in that window to be redrawn or to prevent changes in that window from being redrawn.

Syntax

WM_SETREDRAW
wParam = (WPARAM) fRedraw;
lParam = 0;

At a Glance

Header file: Winuser.h
Component/Module: Window management component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The window manager provides no default processing for this message. However, certain controls do support this message, including listbox, treeview and combo box.
