TVM_HITTEST

The TVM_HITTEST message determines the location of the specified point relative to the client area of a tree view control. You can send this message explicitly or by using the TreeView_HitTest macro.

Syntax

TV_HITTEST
wParam = 0;
lParam = (LPARAM)(LPTV_HITTESTINFO) lpht;
