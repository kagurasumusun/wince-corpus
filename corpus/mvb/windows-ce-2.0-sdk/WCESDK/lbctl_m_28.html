LB_SETCOLUMNWIDTH

An application sends an LB_SETCOLUMNWIDTH message to a multiple-column list box (created with the LBS_MULTICOLUMN style) to set the width, in pixels, of all columns in the list box.

Syntax

LB_SETCOLUMNWIDTH
wParam = (WPARAM) cxColumn;
lParam = 0;
