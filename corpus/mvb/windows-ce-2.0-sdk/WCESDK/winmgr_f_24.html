GetUpdateRect

The GetUpdateRect function retrieves the coordinates of the smallest rectangle that completely encloses the update region of the specified window in client coordinates. If there is no update region, GetUpdateRect retrieves an empty rectangle (sets all coordinates to zero).

Syntax

BOOL GetUpdateRect(HWND hWnd, LPRECT lpRect, BOOL bErase);
