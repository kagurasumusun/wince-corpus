Name Changes from Version 1.01 to 2.0

Several API elements have new names in Windows CE version 2.0. Occurrences of "Peg" in these names have been replaced with "Ce."

Use the "Peg" names when writing applications for version 1.01. The "Peg" names are supported in this version, but support in future versions of Windows CE is not guaranteed. Use the "Ce" names when writing applications for Version 2.0 or later.
