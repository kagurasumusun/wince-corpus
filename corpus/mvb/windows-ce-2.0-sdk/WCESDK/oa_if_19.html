IOleObject::Advise

The IOleObject::Advise method establishes an advisory connection between a compound document object and the calling object's advise sink, through which the calling object receives notification when the compound document object is renamed, save, or closed.

Syntax

HRESULT Advise(
IAdviseSink * pAdvSink,
DWORD * pdwConnection
);
