FtpOpenFile

The FtpOpenFile function initiates access to a remote file for reading.

Syntax

INTERNETAPI BOOL WINAPI FtpOpenFile(HINTERNET hFtpConnect, LPCTSTR lpszFileName, DWORD dwAccess, DWORD dwFlags, DWORD dwContext);

At a Glance

Header file: Wininet.h
Module: Wininet
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The dwContext parameter allows for status callbacks to the application, but all requests are handled synchronously.
