EM_POSFROMCHAR

An application sends the EM_POSFROMCHAR message to retrieve the coordinates of the specified character in an edit control.

Syntax

EM_POSFROMCHAR
wCharIndex = (WPARAM) wParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

On return, the x coordinate of the character is contained in the LOWORD of the LRESULT and the the y coordinate is conteinned in the HIWORD of the LRESULT.
