STYLESTRUCT

The STYLESTRUCT structure contains the window styles for a window.

Syntax

typedef struct tagSTYLESTRUCT { // ss
DWORD styleOld;
DWORD styleNew;
} STYLESTRUCT, * LPSTYLESTRUCT;
