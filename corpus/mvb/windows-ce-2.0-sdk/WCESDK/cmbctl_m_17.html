CB_SELECTSTRING

An application sends a CB_SELECTSTRING message to search the list of a combo box for an item that begins with the characters in a specified string. If a matching item is found, it is selected and copied to the edit control.

Syntax

CB_SELECTSTRING
wParam = (WPARAM) indexStart;
lParam = (LPARAM)(LPCSTR) lpszSelect;

At a Glance

Header file: Winuser.h
Component/Module: Combo box control component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support owner draw.
