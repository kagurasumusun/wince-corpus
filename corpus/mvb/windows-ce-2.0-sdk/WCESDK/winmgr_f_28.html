GetWindowLong

The GetWindowLong function retrieves information about the specified window. GetWindowLong also retrieves the 32-bit (long) value at the specified offset into the extra window memory of a window.

Syntax

LONG GetWindowLong(HWND hWnd, int nIndex);

At a Glance

Header file: Winuser.h
Component: Winmgr
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The nIndex parameter must be a multiple of 4 bytes. Unaligned access is not supported.

Windows CE does not support the GWL_HINSTANCE and GWL_HWNDPARENT values in the nIndex parameter.

Windows CE 1.0 also does not support the DWL_DLGPROC and GWL_USERDATA value in the nIndex parameter.
