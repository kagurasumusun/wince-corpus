UI/Shell Support Requirements

Consistency of the Command Bar is very important to Microsoft Windows CE-based applications. The basic order, left to right, should be consistent with Microsoft Word, Pocket Edition. Hence:

Required: Command Bar Appears at the Top of Screen by Default. Where it is supported, the Microsoft Windows CE application command bar must always appear by default at the top of the screen of the primary window. Additionally, it must by default appear "Always on top" (to borrow terminology from the Windows 95 desktop environment), although it is permissible for Logo'd applications to provide a user option to hide the command bar as long as it can be retrieved. Games and certain utilities may be exempt from the Command Bar requirement. These will be considered on a case-by-case basis.

Required: Order of Menus and Buttons: Any menus appearing in the command bar must appear in the leftmost portion of the Command Bar. Tool buttons, both Microsoft Windows CE standard and application-specific must appear to the right of the menus in the command bar (between menus and Help).

Required: Help Must be the Rightmost Button in the Command Bar. The Help button, with its characteristic question mark icon, must always appear in the rightmost available position on the command bar, just before the close button which always appears to the right edge.

Required: Certain Menus Must Appear in Order. If you provide File, Edit, View, Insert, Format, Tools, Window menus, they must appear in this order, left to right.

Required: Certain Buttons Must Appear in Order. If you provide New, Open, Save, Print buttons, they must appear in this order, left to right. It is strongly recommended that you follow the UI guidelines for button size and style.

Required: Certain Functions Must Appear in Order. If you provide Style, Font, Font Size, Bold, Italic, Underline buttons or drop-down combo boxes, they must appear in this order, left to right. It is strongly recommended that you follow the UI guidelines for button size and style.

Required: Tool Tips. Microsoft Windows CE-based applications are required to support Tooltips for their command bar buttons. First-time users of an application can thus easily determine the function of an unfamiliar button.

Required: 16x16 and 32x32 Pixel Icons for Application and File Types. Applications are required to register 16x16 and 32x32 pixel icons for their main executable and saved file types.

Required: Dialog support for OK, Cancel Buttons. Dialog boxes appearing with Microsoft Windows CE-based applications must support the Microsoft Windows CE-standard OK and Cancel (X) buttons, as they appear in the top right corner of standard Microsoft Windows CE windows.

Required: Microsoft Windows CE Address Book API Functionality not Duplicated. Applications that use address book-type data must use the Microsoft Windows CE address book API - this is required to maximize available user storage space on the Microsoft Windows CE-based platform by preventing the storage of superfluous address books in Microsoft Windows CE memory; additionally, use of the Microsoft Windows CE address book API provides a consistent user interface and simplifies communications conducted with Microsoft Windows CE.

Required: Microsoft Windows CE Msgstore API Functionality Not Duplicated. Likewise, Logo'd applications are required to use the universal inbox provided by the msgstore data API where it is appropriate. For example, some communication applications (such as two-way paging applications) may require greater functionality than the msgstore data API provides, and are exempt from this requirement. All other applications, however, are expected to use the universal inbox provided with Microsoft Windows CE.

Required: IrDA for Infrared Connectivity. Applications supporting infrared transfer of data must support IrDA standards.

Required: Support for Standard Wait Cursor. Applications must use the standard Wait Cursor (i.e., hourglass) when asked to execute a command that renders the current window, or the system as a whole, unresponsive to user input. When displayed only for the current window, the user may continue to interact with other windows, including the taskbar.

Required: Alt-tap to Access Contextual Menus and Property Sheets The Microsoft Windows CE operating system as installed on Microsoft Windows CE-based platforms supports contextual menus and property sheets. These are recommended but not required of applications bearing the Windows CE Logo. However, if they are present, it is required that they are accessed on the Microsoft Windows CE-based platform desktop by means of an Alt-tap action. In other words, anything which emulates a right mouse action on Windows 95 must be accessed by Alt-tap.

Recommended: No Overlapping or Sizable Windows. Applications bearing the Windows CE Logo should use the full screen of the Microsoft Windows CE-based platform (480 pixels x 240 pixels) for their primary window unless the application may be used in conjunction with another application and the user benefits from seeing the window under the active application.

Recommended: HTML Help. It is recommended that Logo'd applications use Help files authored in HTML; this may be a future requirement.

Recommended: Shortcuts in Programs Folder Created on Installation. Developers are encouraged to create shortcuts for their applications within the My HPC>Programs Files folder on the Microsoft Windows CE-compatible device desktop. Like HTML Help, this may be a future requirement.

Recommended: No Title Bars. To save screen space, it is strongly recommended that you do not provide a Title Bar, and do not put the title of your application in the Command Bar, but rely on the icon which appears on the taskbar. If desired, an application or document name can be supplied on the line below the command bar as is done in the Microsoft Windows CE explorer.
