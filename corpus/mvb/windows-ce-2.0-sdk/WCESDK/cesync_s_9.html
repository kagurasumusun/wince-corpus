OBJTYPEINFO

The OBJTYPEINFO structure is used to store information about an object type.

typedef struct tagObjTypeInfo {
UINT cbStruct;
OBJTYPENAMEW szObjType;
UINT uFlags;
WCHAR szName[ 80 ]
UINT cObjects;
UINT cbAllObj;
FILETIME ftLastModified
} OBJTPYEINFO, *POBJTYPEINFO;

cbStruct

szName

output. The total number of bytes used to store existing objects.
