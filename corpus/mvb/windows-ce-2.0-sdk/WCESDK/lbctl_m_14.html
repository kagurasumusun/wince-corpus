LB_GETITEMRECT

An application sends an LB_GETITEMRECT message to retrieve the dimensions of the rectangle that bounds a list box item as it is currently displayed in the list box.

Syntax

LB_GETITEMRECT
wParam = (WPARAM) index;
lParam = (LPARAM)(RECT FAR*) lprc;
