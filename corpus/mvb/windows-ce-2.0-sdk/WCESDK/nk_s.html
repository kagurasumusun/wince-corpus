CONTEXT

A CONTEXT structure contains processor-specific register data. Currently there are CONTEXT structures defined for Intel, MIPS, Alpha and PowerPC processors. Refer to the WinNT.h header file for definitions of these structures.

At a Glance

Header file: Winbase.h
Component: Nk
Platforms: H/PC
Versions: 2.0 and later

Remarks

Windows CE defines an additional CONTEXT structure for SH processors which is also found in the WinNT.h header file.
