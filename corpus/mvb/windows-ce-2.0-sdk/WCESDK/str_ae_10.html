CFF_CONVERTOPTIONS

The CFF_CONVERTOPTIONS structure contains information that the ICeFileFilterOptions::SetFilterOptions method uses to set file filter options.

Syntax

typedef struct tagCFF_CONVERTOPTIONS{
 ULONG cbSize;
BOOL bNoModalUI;
} CFF_CONVERTOPTIONS;

At a Glance

Header file: replfilt.h
Component:
Platforms: H/PC
Windows CE versions: 2.0 and later

Members

cbSize
the size of the structure. This value should be initialized by the caller.
bNoModalUI
Set to TRUE if the caller wants the converter to suppress all modal UI during the conversion.
