DISCDLGSTRUCT

The DISCDLGSTRUCT data structure is used in the WNetDisconnectDialog1 function to describe the required behavior for the disconnect attempt.

Syntax

typedef struct _wcesdk_win32_DISCDLGSTRUCT_str{
DWORD cbStructure;
HWND hwndOwner;
LPTSTR lpLocalName;
LPTSTR lpRemoteName;
DWORD dwFlags;
} DISCDLGSTRUCT, *LPDISCDLGSTRUCT;

At a Glance

Header file: Winnetwk.h
Component:
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The dwFlags may not be set the value of DISC_UPDATE_PROFILE.
