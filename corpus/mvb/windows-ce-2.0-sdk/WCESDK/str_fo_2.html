HD_LAYOUT

The HD_LAYOUT structure contains information used to set the size and position of a header control.

Syntax

typedef struct _HD_LAYOUT { // hdl
RECT FAR* prc;
WINDOWPOS FAR* pwpos;
} HD_LAYOUT;
