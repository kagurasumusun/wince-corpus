PSM_ISDIALOGMESSAGE

The PSM_ISDIALOGMESSAGE message passes a message to a property sheet dialog box and indicates whether the dialog processed the message.

Syntax

PSM_ISDIALOGMESSAGE
wParam = 0;
lParam = (LPARAM) pMsg;
