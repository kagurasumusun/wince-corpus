RasSetEntryDialParams

The RasSetEntryDialParams function changes the connection information saved by the last successful call to the RasDial or RasGetEntryDialParams function for a specified phone book entry.

Syntax

DWORD RasSetEntryDialParams(LPTSTR lpszPhoneBook, LPRASDIALPARAMS lprasdialparams, BOOL fRemovePassword);

At a Glance

Header file: Afdfunc.h
Module: Ras
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The szCallBackNumber and szPhoneNumber members of lpRasDialParams are not used and should be set to NULL.
