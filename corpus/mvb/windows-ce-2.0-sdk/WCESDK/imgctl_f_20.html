ImageList_Merge

The ImageList_Merge function creates a new image by combining two existing images. ImageList_Merge also creates a new image list to store the image.

Syntax

HIMAGELIST WINAPI ImageList_Merge(HIMAGELIST himl1, int iImage1, HIMAGELIST himl2, int iImage2, int dx, int dy);
