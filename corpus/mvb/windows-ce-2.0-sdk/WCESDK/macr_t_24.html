TreeView_EditLabel

The TreeView_EditLabel macro begins in-place editing fo the specified item's text, replacing the text of the item with a single-line edit control containing the text. This macro implicitly selects and focuses the specified item.

Syntax

HWND TreeView_EditLabel(
 hwnd,
 hitem
);
