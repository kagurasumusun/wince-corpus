CPL_DBLCLK

The CPL_DBLCLK message is sent to a Control Panel application when the user double-clicks the icon in the control panel explorer.

Syntax

CPL_DBLCLK
uAppNum = (UINT) lParam1;
lData = (LONG) lParam2;
