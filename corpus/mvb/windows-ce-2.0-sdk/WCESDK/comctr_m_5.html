DTM_GETRANGE

The DTM_GETRANGE message retrieves the current minimum and maximum allowable system times for a date and time picker (DTP) control.

Syntax

DTM_GETRANGE
wParam = 0;
lParam = (LPARAM) lpSysTimeArray;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: DateTime_GetRange

Parameters

lpSysTimeArray
Address of a two-element array of SYSTEMTIME structures.

Return Values

Returns a DWORD value that is a combination of GDTR_MIN or GDTR_MAX.

Remarks

The first element of the SYSTEMTIME array contains the minimum allowable time if GDTR_MIN is set. The second element of the SYSTEMTIME array contains the maximum allowable time if GDTR_MAX is set.
