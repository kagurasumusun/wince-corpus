DTM_SETIMAGE

A DTM_SETIMAGE message is sent by an application to associate a bitmap with an image.

Syntax

DTM_SETIMAGE
wParam = 0,
lParam = (LPARAM)(LPINLINEIMAGEINFO) lpInlineImageInfo;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

lpInlineImageInfo
Pointer to an INLINEIMAGEINFO structure that contains information about the bitmap image.

Return Value

This message does not return a value.

See Also

DTM_IMAGEFAIL, INLINEIMAGEINFO, NM_INLINE_IMAGE
