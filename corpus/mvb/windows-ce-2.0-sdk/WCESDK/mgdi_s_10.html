LOGBRUSH

The LOGBRUSH structure defines the style, color, and pattern of a logical brush.

Syntax

typedef struct tagLOGBRUSH { // lb
UINT lbStyle;
COLORREF lbColor;
LONG lbHatch;
} LOGBRUSH;

At a Glance

Header file: Wingdi.h
Component/Module: mgdraw
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE version 1.0 supports only the following lbStyle values:
BS_NULL

BS_SOLID


Windows CE version 2.0 supports the following additional lbStyle values:
BS_DIBPATTERNPT

BS_PATTERN
