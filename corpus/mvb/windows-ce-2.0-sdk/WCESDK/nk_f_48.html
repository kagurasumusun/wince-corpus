WaitForMultipleObjects

The WaitForMultipleObjects function returns when one of the following occurs:

  • Either any one or all of the specified objects are in the signaled state.

  • The time-out interval elapses.

Syntax

DWORD WaitForMultipleObjects DWORD nCount, CONST HANDLE *lpHandles, BOOL bWaitAll, DWORD dwMilliseconds );

At a Glance

Header file: Winbase.h
Module: Nk
Platforms: H/PC
Windows CE versions: 1.01 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support waiting for semaphores, change notification objects, console input, and timers. Also, it does not support waiting for process, thread, and mutex events.
