CB_SETITEMHEIGHT

An application sends a CB_SETITEMHEIGHT message to set the height of list items or the selection field in a combo box.

Syntax

CB_SETITEMHEIGHT
wParam = (WPARAM) index;
lParam = (LPARAM)(int) height;

At a Glance

Header file: Winuser.h
Component/Module: Combo box control component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support owner drawn combo boxes.

See Also
