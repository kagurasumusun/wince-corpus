MailNonIpmInfo

The MailNonIpmInfo structure is used internally by transports to describe non-IPM data on a message.

Syntax

typedef struct MailNonIpmInfo_s {
LPWSTR szMessageClass;
UINT uiPropcount;
CEPROPVAL propArray[];
} MailNonIpmInfo, *lpMailNonIpmInfo;

At a Glance

Header file: Msgstore.h
Component/Module:
Platforms:
Versions: 2.0 and later

Members

szMessageClass
The header "Type" of the non-IPM message.
uiPropCount
The count of non-IPM properties in the following propArray.
propArray
An array of CEPROPVAL structures. uiPropCount specifies the number of the elements in the array.
