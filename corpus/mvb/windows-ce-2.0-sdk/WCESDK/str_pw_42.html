TV_KEYDOWN

The TV_KEYDOWN structure contains information about a keyboard event in a tree view control. This structure is used with the TVN_KEYDOWN notification message.

Syntax

typedef struct _TV_KEYDOWN { tvkd
 NMHDR hdr;
WORD wVKey;
UINT flags;
} TV_KEYDOWN;
