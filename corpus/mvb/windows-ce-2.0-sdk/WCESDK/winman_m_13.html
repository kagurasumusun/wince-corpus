WM_GETTEXT

An application sends a WM_GETTEXT message to copy the text that corresponds to a window into a buffer provided by the caller.

Syntax

WM_GETTEXT
wParam = (WPARAM) cchTextMax;
lParam = (LPARAM) lpszText;
