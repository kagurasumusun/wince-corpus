DrawEdge

The DrawEdge function draws one or more edges of a rectangle.

Syntax

BOOL DrawEdge(HDC hdc, LPRECT qrc, UINT edge, UINT grfFlags);

At a Glance

Header file: Wingdi.h
Component: mgdraw
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the EDGE_BUMP flag for the edge parameter.

Windows CE does not support the following grfFlags values:
BF_BOTTOMLEFT

BF_TOPLEFT

BF_TOPRIGHT
