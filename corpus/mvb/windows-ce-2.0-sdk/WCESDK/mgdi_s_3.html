BITMAPFILEHEADER

The BITMAPFILEHEADER structure contains information about the type, size, and layout of a file that containing a device-independent bitmap (DIB).

Syntax

typedef struct tagBITMAPFILEHEADER {
WORD bfType;
DWORD bfSize;
WORD bfReserved1;
WORD bfReserved2;
DWORD bfOffBits;
} BITMAPFILEHEADER;
