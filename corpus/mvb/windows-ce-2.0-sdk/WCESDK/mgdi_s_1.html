BITMAPCOREHEADER

The BITMAPCOREHEADER structure contains information about the dimensions and color format of a device-independent bitmap (DIB).

Syntax

typedef struct tagBITMAPCOREHEADER { // bmch
DWORD bcSize;
WORD bcWidth;
WORD bcHeight;
WORD bcPlanes;
WORD bcBitCount;
} BITMAPCOREHEADER;

At a Glance

Header file: Wingdi.h
Component: mgbase
Platforms: H/PC
Versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE supports all of the pixel depths that Windows NT and Windows 95 do. In addition, it supports a pixel depth of 2 bits-per-pixel. You can therefore set the bcBitCount member to two or to any of the value supported in Windows desktop platforms.
