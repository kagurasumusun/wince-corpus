ENUMLOGFONT

The ENUMLOGFONT structure defines a font's attributes, full name, and style.

Syntax

typedef struct tagENUMLOGFONT { // elf
LOGFONT elfLogFont;
TCHAR elfFullName[LF_FULLFACESIZE];
TCHAR elfStyle[LF_FACESIZE];
} ENUMLOGFONT;
