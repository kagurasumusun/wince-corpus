IViewObject::GetColorSet

The IViewObject::GetColorSet method returns the logical palette that the object will use for drawing in its IViewObject::Draw method with the corresponding parameters.

Syntax

HRESULT GetColorSet(
DWORD dwAspect,
LONG lindex,
void * pvAspect,
DVTARGETDEVICE * ptd,
HDC hicTagetDev,
LOGPALETTE ** ppColorSet
);
