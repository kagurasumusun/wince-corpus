MCM_SETRANGE

The MCM_SETRANGE message sets the minimum and maximum allowable dates for a month calendar control.

Syntax

MCM_SETRANGE
wParam = (WPARAM)(SHORT) fWhichLimit;
lParam = (LPARAM)(LPSYSTEMTIME) lprgSysTimeArray;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: MonthCal_SetRange

Parameters

fWhichLimit
Flag values that specify which limit dates are being set. This value must be one or both of the following:
GDTR_MAX
The maximum allowable date is being set. The SYSTEMTIME structure at lprgSysTimeArray[1] must contain date information.
GDTR_MIN
The minimum allowable date is being set. The SYSTEMTIME structure at lprgSysTimeArray[0] must contain date information.

lprgSysTimeArray
Address of a two-element array of SYSTEMTIME structures that contains date limit information. The maximum limit must be in lpSysTimeArray[1] if GDTR_MAX is specified, and lpSysTimeArray[0] must contain the minimum limit if GDTR_MIN is specified. The time members of these structures are ignored.

Return Values

Returns nonzero if successful, or zero otherwise.
