TBM_SETRANGE

The TBM_SETRANGE message sets the range (minimum and maximum positions) for the slider in a trackbar.

Syntax

TBM_SETRANGE
wParam = (WPARAM)(BOOL) fRedraw;
lParam = (LPARAM)MAKELONG(lMinimum,lMaximum);
