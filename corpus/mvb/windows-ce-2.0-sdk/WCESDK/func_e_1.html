EnumCalendarInfoProc

An EnumCalendarInfoProc function is an application-defined callback function. It is called as a result of a call to the EnumCalendarInfo function, and receives a pointer to a string buffer containing a calendar information string.

Syntax

BOOL CALLBACK EnumCalendarInfoProc(LPTSTR lpCalendarInfoString);

At a Glance

Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the ANSI version of this function.
