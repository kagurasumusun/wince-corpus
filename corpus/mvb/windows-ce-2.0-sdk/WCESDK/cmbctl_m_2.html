CB_FINDSTRING

An application sends a CB_FINDSTRING message to search the list box of a combo box for an item beginning with the characters in a specified string.

Syntax

CB_FINDSTRING
wParam = (WPARAM) indexStart,
lParam = (LPARAM)(LPCSTR) lpszFind

At a Glance

Header file: Winuser.h
Component/Module: Combo box control component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

This message does not work across processes. You can not make the call SendMessage(CB_FINDSTRING) to another process.

See Also
