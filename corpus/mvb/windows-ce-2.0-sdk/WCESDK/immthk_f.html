ImmAssociateContext

The ImmAssociateContext function associates the specified input context with the specified window.

Syntax

HIMC ImmAssociateContext(HWND hWnd, HIMC hIMC);

At a Glance

Header file: Imm.h
Component: Immthunk
Platforms: H/PC (Japanese)
Windows CE versions: Japanese version 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

If the hIMC parameter is NULL, the ImmAssociateContext function removes any association the window may have with an input context. By default, the system associates the default input context with each window as it is created.

An application can specify only the default input context or NULL.
