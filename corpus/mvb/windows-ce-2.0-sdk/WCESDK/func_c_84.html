CeGetLastError

The CeGetLastError function returns the calling thread's last error code. This is the RAPI version of the GetLastError function.

Syntax

DWORD PegGetLastError(void);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegGetLastError function.

For more information about using RAPI functions, see Remote API Functions.
