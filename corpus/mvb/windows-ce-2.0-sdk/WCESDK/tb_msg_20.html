TB_INDETERMINATE

The TB_INDETERMINATE message sets or clears the indeterminate state of the specified button in a toolbar.

Syntax

TB_INDETERMINATE
wParam = (WPARAM) idButton;
lParam = (LPARAM)MAKELONG(fIndeterminate,0);
