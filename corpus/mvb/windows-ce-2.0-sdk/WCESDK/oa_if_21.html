IOleObject::DoVerb

The IOleObject::DoVerb method requests an object to perform an action in response to an end-user's action. The possible actions are enumerated for the object in IOleObject::EnumVerbs.

Syntax

HRESULT DoVerb(
LONG iVerb,
LPMSG lpmsg,
IOleClientSite * pActiveSite,
LONG lindex,
HWND hwndParent,
LPCRECT lprcPosRect
);

At a Glance

Platforms: H/PC
Windows CE versions: 2.0 and later
