LVM_SETITEMSTATE

The LVM_SETITEMSTATE message changes the state of an item in a list view control.

Syntax

LVM_SETITEMSTATE
wParam = (WPARAM)(int) i;
lParam = (LPARAM)(LV_ITEM FAR *) pitem;
