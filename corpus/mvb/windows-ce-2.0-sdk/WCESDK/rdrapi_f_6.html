WNetEnumResource

The WNetEnumResource function continues a network-resource enumeration started by the WNetOpenEnum function.

Syntax

DWORD WNetEnumResource( HANDLE hEnum, LPDWORD lpcCount, LPVOID lpBuffer, LPDWORD lpBufferSize);

At a Glance

Header file: Winnetwk.h
Module: Rdrapi
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The WNetEnumResource function is called by the network browser application to create lists of available resources on the network

Connections are not automatically stored when the user logs in under Windows CE.
