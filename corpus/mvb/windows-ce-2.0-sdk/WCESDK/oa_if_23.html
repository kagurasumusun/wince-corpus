IOleObject::EnumVerbs

The IOleObject::EnumVerbs method exposes a pull-down menu listing the verbs available for an object in ascending order by verb number.

Syntax

HRESULT EnumVerbs(
 IEnumOleVerb ** ppEnumOleVerb
);
