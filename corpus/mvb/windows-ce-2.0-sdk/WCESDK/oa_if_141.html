ITypeInfo::Invoke

The ITypeInfo::Invoke method invokes a method or accesses a property of an object that implements the interface described by the type description.

Syntax

HRESULT Invoke(
VOID FAR* pvInstance,
MEMBERID memid,
unsigned short wFlags,
DISPPARAMS FAR* pDispParams,
VARIANT FAR* pVarResult,
EXCEPINFO FAR* pExcepInfo,
unsigned int FAR* puArgErr
);
