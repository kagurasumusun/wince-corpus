MAILSORTFIELD

The MAILSORTFIELD enumeration specifies the fields by which mail messages may be sorted.

Syntax

typedef enum {
MAIL_SORT_FROM,
MAIL_SORT_SUBJ,
MAIL_SORT_DATE,
MAIL_SORT_SIZE
} MAILSORTFIELD;
