DVEXTENTINFO

The DVEXTENTINFO structure is used to provide sizing hints from the container for the object to use as the user resizes it.

Syntax

typedef struct tagDVEXTENTINFO{
ULONG cb;
DWORD dwExtentMode;
SIZEL sizelProposed;
} DVEXTENTINFO;
