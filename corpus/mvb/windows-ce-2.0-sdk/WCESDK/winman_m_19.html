WM_NOTIFY

The WM_NOTIFY message informs the parent window of a control that an event has occurred in the control or that the control requires some kind of information.

Syntax

WM_NOTIFY
idCtrl = (int) wParam;
pnmh = (LPNMHDR) lParam;
