TVN_ITEMEXPANDED

The TVN_ITEMEXPANDED notification message notifies a tree view control's parent window that a parent item's list of child items has expanded or collapsed. This notification message is sent in the form of a WM_NOTIFY message.

Syntax

TVN_ITEMEXPANDED
pnmtv = (NM_TREEVIEW FAR *) lParam
