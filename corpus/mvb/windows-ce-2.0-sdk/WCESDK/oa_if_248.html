ICreateErrorInfo : IUnknown

The ICreateErrorInfo interface returns error information.

At a Glance

Header file: Oaidl.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Method Description
ICreateErrorInfo::SetDescription The ICreateErrorInfo::SetDescription method sets a textual description of the error.
ICreateErrorInfo::SetGUID The ICreateErrorInfo::SetGUID method sets the globally unique identifier (GUID) of the interface that defined the error.
ICreateErrorInfo::SetHelpContext The ICreateErrorInfo::SetHelpContext method sets the Help context identifier (ID) for the error.
ICreateErrorInfo::SetHelpFile The ICreateErrorInfo::SetHelpFile method sets the path of the Help file that describes the error.
ICreateErrorInfo::SetSource The ICreateErrorInfo::SetSource method sets the language-dependent programmatic ID (ProgID) for the class or application that raised the error.
