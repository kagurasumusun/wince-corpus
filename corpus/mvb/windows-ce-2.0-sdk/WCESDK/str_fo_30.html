NM_LISTVIEW

The NM_LISTVIEW structure contains information about a list view notification message.

Syntax

typedef struct tagNM_LISTVIEW {
 NMHDR hdr;
int iItem;
int iSubItem;
UINT uNewState;
UINT uOldState;
UINT uChanged;
POINT ptAction;
} NM_LISTVIEW;
