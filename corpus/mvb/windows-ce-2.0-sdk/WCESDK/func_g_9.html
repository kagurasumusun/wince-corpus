GetExceptionCode

The GetExceptionCode function retrieves a code that identifies the type of exception that occurred. GetExceptionCode can be called only from within the filter expression or exception-handler block of a try-except exception handler.

Syntax

DWORD GetExceptionCode(void);

At a Glance

Header file: Excpt.h
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The Excpt.h file has to be explicitly included in order to use GetExceptionCode.
