lineGetID

The lineGetID function returns a device ID for the specified device class associated with the selected line, address, or call.

Syntax

LONG lineGetID(HLINE hLine, DWORD dwAddressID, HCALL hCall, DWORD dwSelect, LPVARSTRING lpDeviceID, LPCTSTR lpszDeviceClass);
