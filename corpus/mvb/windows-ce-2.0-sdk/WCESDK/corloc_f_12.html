EnumTimeFormats

The EnumTimeFormats function enumerates the time formats that are available for a specified locale.

Syntax

BOOL EnumTimeFormats(TIMEFMT_ENUMPROC lpTimeFmtEnumProc, LCID Locale, DWORD dwFlags);
