lineSetDevConfig

The lineSetDevConfig function allows the application to restore the configuration of a media-stream device on a line device to a setup previously obtained using the lineGetDevConfig function. For example, the contents of this structure could specify data rate, character format, modulation schemes, and error control protocol settings for a "datamodem" media device associated with the line.

Syntax

LONG lineSetDevConfig (DWORD dwDeviceID, LPVOID const lpDeviceConfig, DWORD dwSize, LPCTSTR lpszDeviceClass);
