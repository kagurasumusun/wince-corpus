ExitThread

The ExitThread function ends a thread.

Syntax

VOID ExitThread(DWORD dwExitCode);

At a Glance

Header file: Winbase.h
Component: coremain
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

If the primary thread calls the ExitThread function, the application will exit.
