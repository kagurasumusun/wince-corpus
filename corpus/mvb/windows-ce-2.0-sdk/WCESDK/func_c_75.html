CeRemoveDirectory

The CeRemoveDirectory function deletes an existing empty directory. This is the RAPI version of the RemoveDirectory function.

Syntax

BOOL CeRemoveDirectory(LPCWSTR lpPathName);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegRemoveDirectory function.

For more information about using RAPI functions, see Remote API Functions.
