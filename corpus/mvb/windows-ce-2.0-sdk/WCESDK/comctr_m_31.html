LVM_GETCOLUMNORDERARRAY

The LVM_GETCOLUMNORDERARRAY message retrieves the current left-to-right order of columns in a list view control.

Syntax

LVM_GETCOLUMNORDERARRAY
wParam = (WPARAM) (int) iCount;
lParam = (LPARAM) lpiArray;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: ListView_GetColumnOrderArray

Parameters

iCount
Number of columns in the list view control.
lpiArray
Address of a buffer that receives the index values of the columns in the list view control. The buffer must be large enough to hold the total number of columns * sizeof(int).

Return Values

If successful, returns nonzero and the buffer at lpiArray receives the column index of each column in the control, in the order they appear from left to right. Otherwise, the return value is zero.
