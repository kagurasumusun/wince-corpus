DeleteMenu

The DeleteMenu function deletes an item from the specified menu. If the menu item invokes a pop-up menu, DeleteMenu destroys the handle to the pop-up menu and frees the memory used by the pop-up menu.

Syntax

BOOL DeleteMenu(HMENU hMenu, UINT uPosition, UINT uFlags);
