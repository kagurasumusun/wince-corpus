INPUT

The INPUT structure is used by the SendInput function to synthesize keystrokes, stylus and mouse motions, and button clicks.

Syntax

typedef struct tagINPUT {
DWORD type;
union
{
MOUSEINPUT mi;
KEYBDINPUT ki;
HARDWAREINPUT hi;
};
} INPUT, *PINPUT, FAR* LPINPUT;

At a Glance

Header file: Addrstor.h
Component/Module:
Platforms:
Versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the INPUT_HARDWARE value in the type field.
