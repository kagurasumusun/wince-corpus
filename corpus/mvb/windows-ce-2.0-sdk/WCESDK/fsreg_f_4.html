RegEnumKeyEx

The RegEnumKeyEx function enumerates subkeys of the specified open registry key. RegEnumKeyEx retrieves information about one subkey each time it is called; it retrieves the class name of the subkey and the time it was last modified.

Syntax

LONG RegEnumKeyEx(HKEY hKey, DWORD dwIndex, LPWSTR lpszName, LPDWORD lpcchName, LPDWORD lpReserved, LPWSTR lpszClass, LPDWORD lpcchClass, PFILETIME lpftLastWriteTime);
