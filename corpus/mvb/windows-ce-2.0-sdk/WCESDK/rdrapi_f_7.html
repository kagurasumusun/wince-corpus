WNetGetUniversalName

The WNetGetUniversalName function maps a local path (for example, names in \NETWORK folder) for a network resource to a data structure containing the Universal Name Convention based name.

Syntax

DWORD WNetGetUniversalName(LPCTSTR lpLocalPath, DWORD dwInfoLevel, LPVOID lpBuffer, LPDWORD lpBufferSize);

At a Glance

Header file: Winnetwk.h
Module: Rdrapi
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not have drive letters. The lpLocalPath should point to the subfolder in the \NETWORK directory.
