BITMAP

The BITMAP structure defines the type, width, height, color format, and bit values of a bitmap.

Syntax

typedef struct tagBITMAP {
LONG bmType;
LONG bmWidth;
LONG bmHeight;
LONG bmWidthBytes;
WORD bmPlanes;
WORD bmBitsPixel;
LPVOID bmBits;
} BITMAP;
