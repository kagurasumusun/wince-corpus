SetForegroundWindow

The SetForegroundWindow function puts the thread that created the specified window into the foreground and activates the window.

Syntax

BOOL SetForegroundWindow(HWND hWnd);

At a Glance

Header file: Winuser.h
Component: Foregnd
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The thread that owns the window is not given a priority boost.
