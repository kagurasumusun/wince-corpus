MCN_SELECT

The MCN_SELECT notification message is sent by a month calendar controlwhenever the user makes an explicit date selection within a month calendar control. This notification is sent in the form of a WM_NOTIFY message.

Syntax

MCN_SELECT
lpNMSelChange = (LPNMSELCHANGE) lParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

lpNMSelChange
Address of an NMSELCHANGE structure that contains information about the currently selected date range.

Remarks

This notification message is similar to MCN_SELCHANGE, but is sent only in response to a user's explicit date selections, whereas MCN_SELCHANGE applies to any selection change.
