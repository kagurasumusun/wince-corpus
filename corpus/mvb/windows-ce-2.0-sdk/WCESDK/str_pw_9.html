PropertyDataStruct

The PropertyDataStruct structure contains information about a property of an address card in the Contacts database.

Syntax

typedef struct _PropertyDataStruct {
 TCHAR *pszReserved;
TCHAR *pszPropertyName;
ULONG uPropType;
HHPRTAG hhProp;
} PropertyDataStruct;

At a Glance

Header file:
Module/Component:
Platforms:
Versions: 1.0 and later

Members

pszReserved
Reserved; do not use.
pszPropertyName
Pointer to the name of the property, as it appears in the Contacts application.
uPropType
Property type. It can be one of the following values:
TEXT_PROPERTY
A string of text
DATE_PROPERTY
A date
PHONE_PROPERTY
A telephone number
NAME_PROPERTY
A name
ADDRESS_PROPERTY
An address
EMAIL_PROPERTY
An e-mail name
