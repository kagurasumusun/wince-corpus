IRootStorage::SwitchToFile

The IRootStorage::SwitchToFile method copies the current file associated with the storage object to a new file which is then used for the storage object and any uncommitted changes.

Syntax

HRESULT SwitchTofFile(
LPOLESTR pszFile,
);
