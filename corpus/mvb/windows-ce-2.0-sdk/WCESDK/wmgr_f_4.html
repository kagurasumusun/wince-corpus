TranslateAccelerator

The TranslateAccelerator function processes accelerator keys for menu commands. TranslateAccelerator translates a WM_KEYDOWN or WM_SYSKEYDOWN message to a WM_COMMAND message and then sends the WM_COMMAND message directly to the appropriate window procedure. TranslateAccelerator does not return until the window procedure has processed the message.

Syntax

int TranslateAccelerator(HWND hWnd, HACCEL hAccTable, LPMSG lpMsg);

At a Glance

Header file: Winuser.h
Component: wmgr_c
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

All accelerator key messages are translated into WM_COMMAND messages; Windows CE does not support the WM_SYSCOMMAND message.
