CreateToolhelp32Snapshot

The CreateToolhelp32Snapshot function takes a snapshot of the processes and the heaps, modules, and threads used by the processes.

Syntax

HANDLE WINAPI CreateToolhelp32Snapshot( DWORD dwFlags, DWORD th32ProcessID);

At a Glance

Header file: Tlhelp32.h
Platforms: H/PC
Versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE supports an additional flag for the dwFlags parameter, THCS_GETALLMODES. This value returns a list of all the modules loaded in the system. Windows CE does not support the THCS_INHERIT value for dwFlags.

The snapshot returned is a copy of the current state of the system. To close a snapshot call the CloseToolhelp32Snapshot function.
