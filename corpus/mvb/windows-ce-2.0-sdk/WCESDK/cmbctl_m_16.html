CB_RESETCONTENT

An application sends a CB_RESETCONTENT message to remove all items from the list box and edit control of a combo box. This message has no parameters.

Syntax

CB_RESETCONTENT
wParam = 0;
lParam = 0;

At a Glance

Header file: Winuser.h
Component/Module: Combo box control component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The Microsoft Platform SDK documentation says this message always returns CB_OKAY (0). This is inaccurate. This message always returns TRUE.
