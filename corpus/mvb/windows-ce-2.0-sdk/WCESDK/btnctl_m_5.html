BN_CLICKED

The BN_CLICKED notification message is sent when the user taps the pen on the touch-screen. The parent window of the button receives this notification message through the WM_COMMAND message. Unlike the other button notification messages, this message is intended for applications written for any version of Windows.

Syntax

BN_CLICKED
idButton = (int)LOWORD(wParam);
hwndButton = (HWND) lParam;
