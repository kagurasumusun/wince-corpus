CHOOSECOLOR

The CHOOSECOLOR structure contains information the ChooseColor function uses to initialize the Color common dialog box. After a user closes the dialog box, the system uses this structure to return information about the user's selection.

Syntax

typedef struct tagCHOOSECOLOR {
DWORD lStructSize;
HWND hwndOwner;
HINSTANCE hInstance;
COLORREF rgbResult;
COLORREF* lpCustColors;
DWORD Flags;
LPARAM lCustData;
LPCCHOOKPROC lpfnHook;
LPCTSTR lpTemplateName;
} CHOOSECOLOR, *LPCHOOSECOLOR;
