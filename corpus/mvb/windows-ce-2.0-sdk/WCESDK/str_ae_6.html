CERECORDINFO

The CERECORDINFO structure contains information about a record object.

Syntax

typedef struct _CERECORDINFO {
 CEOID oidParent;
} CERECORDINFO;

At a Glance

Header file: Winbase.h
Component:
Platforms: H/PC
Windows CE versions: 1.01 and later

Members

oidParent
Object identifier of the parent database.

Remarks

When writing applications for Windows CE version 1.0, use the PEGRECORDINFO structure.
