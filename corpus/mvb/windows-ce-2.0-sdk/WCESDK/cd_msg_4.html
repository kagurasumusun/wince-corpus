CDM_HIDECONTROL

The CDM_HIDECONTROL message hides the specified control in an Explorer-style Open or Save As common dialog box. The dialog box must have been created with the OFN_EXPLORER flag; otherwise, the message fails.

Syntax

CDM_HIDECONTROL
wParam = (WPARAM) id;
lParam = 0;
