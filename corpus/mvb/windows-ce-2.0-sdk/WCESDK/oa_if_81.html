IStream::Seek

The IStream::Seek method changes the seek pointer to a new location relative to the beginning of the stream, to the end of the stream, or to the current seek pointer.

Syntax

HRESULT Seek(
ULARGE_INTEGER dlibMove,
DWORD dwOrigin,
ULARGE_INTEGER plibNewPosition
);

Platforms: H/PC
