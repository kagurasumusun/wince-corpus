TB_GETBUTTONSIZE

The TB_GETBUTTONSIZE message retrieves the current width and height of toolbar buttons, in pixels.

Syntax

TB_GETBUTTONSIZE
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Return Values

Returns a DWORD value that contains the width and height values in the low word and high word, respectively.
