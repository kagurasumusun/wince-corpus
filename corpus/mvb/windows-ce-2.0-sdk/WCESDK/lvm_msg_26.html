LVM_GETSTRINGWIDTH

The LVM_GETSTRINGWIDTH message determines the width of a given string, using the specified list view control's current font. You can send this message explicitly or by using the ListView_GetStringWidth macro.

Syntax

LVM_GETSTRINGWIDTH
wParam = 0;
lParam = (LPARAM)(LPCSTR) psz;
