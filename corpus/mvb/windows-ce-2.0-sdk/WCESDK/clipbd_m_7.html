WM_UNDO

An application sends a WM_UNDO message to an edit control to undo the last operation. When this message is sent to an edit control, the previously deleted text is restored or the previously added text is deleted. This message has no parameters.

Syntax

WM_UNDO
wParam = 0;
lParam = 0;
