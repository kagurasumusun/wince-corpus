GetClipBox

The GetClipBox function retrieves the dimensions of the tightest bounding rectangle that can be drawn around the current visible area on the device. The visible area is defined by the current clipping region as well as any overlapping windows.

Syntax

int GetClipBox(HDC hdc, LPRECT lprc);
