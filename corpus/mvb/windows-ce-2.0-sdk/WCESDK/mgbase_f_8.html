GetObject

The GetObject function obtains information about a specified graphics object. Depending on the graphics object, the function places a filled-in BITMAP, DIBSECTON, LOGBRUSH, LOGFONT, or LOGPEN structure into a specified buffer.

Syntax

int GetObject(HGDIOBJ hgdiobj, int cbBuffer, LPVOID lpvObject);

At a Glance

Header file: Wingdi.h
Component: mgbase
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE version 1.0, GetObject will always return a BITMAP when it is used on a DIB section. Windows CE version 1.0 does not support the HPALETTE value for the lpvObject parameter.

This function is the same in Windows CE version 2.0 as it is in Windows desktop platforms.
