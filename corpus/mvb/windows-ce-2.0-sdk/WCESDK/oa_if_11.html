IOleClientSite : IUnknown

The IOleClientSite interface is the primary means by which an embedded object obtains information about the location and extent of its display site, its moniker, its user interface, and other resources provided by its container. An object server calls IOleClientSite to request services from the container. A container must provide one instance of IOleClientSite for every compound-document object it contains.

At a Glance

Header file: Oleidl.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.

Method Description
IOleClientSite::GetContainer Requests pointer to object's container.
IOleClientSite::GetMoniker Requests object's moniker.
IoleClientSite::OnShowWindow Notifies container when object becomes visible or invisible.
IOleClientSite::RequestNewObjectLayout Prompts container to resize display site.
IOleClientSite::SaveObject Saves embedded object.
IOleClientSite::ShowObject Prompts container to display object.
