SetClassLong

The SetClassLong function replaces the specified 32-bit (LONG) value at the specified offset into the extra class memory of the WNDCLASS structure for the class to which the specified window belongs.

Syntax

DWORD SetClassLong(HWND hWnd, int nIndex, LONG dwNewLong);

At a Glance

Header file: Winuser.h
Component: Winmgr
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The nIndex parameter is a byte offset but must be a multiple of 4 bytes. Unaligned access is not supported.

None of the standard GCL_* values are supported in the nIndex parameter, with one exception. If the device you are targetting supports a mouse cursor, you can use the GCL_HCURSOR value in the nIndex parameter.

Note Windows CE versions that support mouse cursors include the Iconcurs and Mcursor components rather than the Icon and Cursor components.
