ITypeInfo::GetContainingTypeLib

The ITypeInfo::GetContainingTypeLib method retrieves both the type library that contains a specific type description and the index of the type description within the type library.

Syntax

HRESULT GetContainingTypeLib(
ITypeLib FAR* FAR* ppTLib,
unsigned int FAR* pIndex
);
