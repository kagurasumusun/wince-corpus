TB_ISBUTTONHIGHLIGHTED

The TB_ISBUTTONHIGHLIGHTED message checks the highlight state of a toolbar button.

Syntax

TB_ISBUTTONHIGHLIGHTED
wParam = (WPARAM) idButton;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

idButton
Command ID for a toolbar button.

Return Values

Returns nonzero if the button is highlighted, or zero otherwise.
