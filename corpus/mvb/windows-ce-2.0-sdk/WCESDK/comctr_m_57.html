MCM_GETTODAY

The MCM_GETTODAY message retrieves the date information for the date specified as "today" for a month calendar control.

Syntax

MCM_GETTODAY
wParam = 0;
lParam = (LPARAM)(LPSYSTEMTIME) lpToday;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: MonthCal_GetToday

Parameters

lpToday
Address of a SYSTEMTIME structure that will receive the date information. The time members of this structure will not be modified.

Return Values

Returns nonzero if successful, or zero otherwise.
