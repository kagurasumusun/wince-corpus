GetClassInfo

The GetClassInfo function retrieves information about a window class.

Syntax

BOOL GetClassInfo(HINSTANCE hInstance, LPCTSTR lpClassName, LPWNDCLASS lpWndClass);

At a Glance

Header file: Winuser.h
Component: Winmgr
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

If lpClassName is an atom, it must be an atom returned from RegisterClass.
