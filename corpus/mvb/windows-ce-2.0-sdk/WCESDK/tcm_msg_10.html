TCM_HITTEST

The TCM_HITTEST message determines which tab, if any, is at a specified screen position. You can send this message explicitly or by using the TabCtrl_HitTest macro.

Syntax

TCM_HITTEST
wParam = 0;
lParam = (LPARAM)(TC_HITTESTINFO FAR *) pinfo;
