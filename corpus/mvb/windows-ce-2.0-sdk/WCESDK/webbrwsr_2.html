DWebBrowserEvents::FrameBeforeNavigate

The FrameBeforeNavigate method notifies an application that Web browser control is about to navigate to a different URL. The container application has an opportunity to cancel the pending navigation. This event is fired for navigations that occur inside an HTML frame.

Syntax

void FrameBeforeNavigate (
BSTR URL,
long Flags,
BSTR TargetFrameName,
VARIANT FAR* PostData,
BSTR Headers,
VARIANT_BOOL FAR* Cancel
);
