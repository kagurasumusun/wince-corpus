ImageList_LoadBitmap

The ImageList_LoadBitmap function creates an image list from the given bitmap resource. ImageList_LoadBitmap is a macro that calls the ImageList_LoadImage function.

Syntax

HIMAGELIST WINAPI ImageList_LoadBitmap(HINSTANCE hi, LPCSTR lpbmp, int cx, int cGrow, COLORREF crMask);

At a Glance

Header file: Commctrl.h
Component: Imgctl
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The ImageList_LoadBitmap function is not supported for emulation.
