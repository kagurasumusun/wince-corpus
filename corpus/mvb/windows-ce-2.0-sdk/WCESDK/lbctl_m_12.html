LB_GETITEMDATA

An application sends an LB_GETITEMDATA message to retrieve the application-defined 32-bit value associated with the specified list box item.

Syntax

LB_GETITEMDATA
wParam = (WPARAM) index;
lParam = 0;

At a Glance

Header file: Winuser.h
Component/Module: List box component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support owner draw.
