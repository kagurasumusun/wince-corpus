ntohl

The Windows Sockets ntohl function converts a u_long from network byte order to host byte order.

Syntax

u_long ntohl (u_long netlong);

At a Glance

Header file: Winsock.h
Module: Winsock
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK
