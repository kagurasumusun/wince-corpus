ILockBytes::ReadAt

The ILockBytes::ReadAt method reads a specified number of bytes starting at a specified offset from the beginning of the byte array.

Syntax

HRESULT ReadAt(
ULARGE_INTEGER ulOffset,
void * pv,
ULONG cb,
ULONG * pcbRead
);
