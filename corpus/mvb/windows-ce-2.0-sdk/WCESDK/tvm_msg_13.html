TVM_GETNEXTITEM

The TVM_GETNEXTITEM message retrieves the tree view item that bears the specified relationship to a given item. You can send this message explicitly or by using the TreeView_GetNextItem macro or one of the related macros.

Syntax

TVM_GETNEXTITEM
wParam = (WPARAM)(UINT) flag;
lParam = (LPARAM)(HTREEITEM) hitem;
