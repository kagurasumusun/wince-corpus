RefreshConstants

The RefreshConstants enumeration contains values used with the IWebBrowser::Refresh2 function.

Syntax

typedef enum RefreshConstants {
REFRESH_NORMAL = 0,
REFRESH_IFEXPIRED = 1,
REFRESH_CONTINUE = 2,
REFRESH_COMPLETELY = 3
} RefreshConstants;
