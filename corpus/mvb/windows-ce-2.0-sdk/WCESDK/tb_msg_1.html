TB_ADDBUTTONS

The TB_ADDBUTTONS message adds one or more buttons to a toolbar.

Syntax

TB_ADDBUTTONS
wParam = (WPARAM)(UINT) uNumButtons;
lParam = (LPARAM)(LPTBBUTTON) lpButtons;
