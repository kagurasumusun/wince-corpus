InsertMenu

The InsertMenu function inserts a new menu item into a menu, moving other items down the menu.

Syntax

BOOL InsertMenu(HMENU hMenu, UINT uPosition, UINT uFlags, UINT uIDNewItem, LPCTSTR lpNewItem);

At a Glance

Header file: Commctrl.h
Component: menu
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the MF_BITMAP flag or the MF_DISABLED flag in the uFlags parameter. Menu items cannot be disabled without being grayed. To disable a menu item use the MF_GRAYED flag.

Windows CE version 1.0 does not support cascading menus. If you are using Windows CE 1.0, you cannot insert an MF_POPUP menu into another pop-up menu. If using Windows CE 2.0 or later, you can.
