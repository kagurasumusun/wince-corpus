ImmReleaseContext

The ImmReleaseContext function releases the input context and unlocks the memory associated in the context. An application must call ImmReleaseContext for each call to the ImmGetContext function.

Syntax

BOOL ImmReleaseContext(HWND hWnd, HIMC hIMC);
