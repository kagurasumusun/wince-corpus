InternetConnect

The InternetConnect function opens an FTP or HTTP session for a given site.

Syntax

INTERNETAPI HINTERNET WINAPI InternetConnect(HINTERNET hInternet, LPCTSTR lpszServerName, INTERNET_PORT nServerPort, LPCTSTR lpszUserName , LPCTSTR lpszPassword , DWORD dwService, DWORD dwFlags, DWORD dwContext);

At a Glance

Header file: Wininet.h
Module: Wininet
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The InternetConnect function returns a valid handle to the FTP or HTTP session if the connection is successful, or NULL otherwise.

The dwService parameter accepts INTERNET_SERVICE_FTP and INTERNET_SERVICE_HTTP as the types of service/protocol for use in the connection. However, it does not accept INTERNET_SERVICE_GOPHER, as GOPHER is not supported in Windows CE.

If DwFlags is set with INTERNET_FLAG_PASSIVE, the data transfers for the current FTP session occur in passive mode. Other supported flags include INTERNET_FLAG_SECURE.

The dwContext parameter allows for progress status callbacks to the application, but all requests are handled synchronously.
