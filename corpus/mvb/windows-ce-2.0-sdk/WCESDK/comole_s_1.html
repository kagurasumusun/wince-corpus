AUTH_IDENTITY

The AUTH_IDENTITY structure is used to establish the identity of the client and is authentication-service specific.

Syntax

typedef struct _AUTH_IDENTITY {
[size_is(UserLength+1)] USHORT *User;
ULONG UserLength;
[size_is(DomainLength+1)] USHORT * Domain;
ULONG DomainLength;
[size_is(DomainLength+1)] USHORT *Password;
ULONG Flags;
} AUTH_IDENTITY;
