LVM_GETEXTENDEDLISTVIEWSTYLE

The LVM_GETEXTENDEDLISTVIEWSTYLE message retrieves the extended styles that are currently in use for a given list view control.

Syntax

LVM_GETEXTENDEDLISTVIEWSTYLE
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: ListView_GetExtendedListViewStyle

Return Values

Returns a DWORD that represents the styles currently in use for a given list view control. This value can be a combination of extended styles.
