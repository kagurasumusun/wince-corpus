LVN_BEGINDRAG

The LVN_BEGINDRAG notification message notifies a list view control's parent window that a drag and drop operation is being initiated. This notification message is sent in the form of a WM_NOTIFY message.

Syntax

LVN_BEGINDRAG
pnmv = (NM_LISTVIEW FAR *) lParam;
