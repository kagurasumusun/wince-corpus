Special UI/Shell Support Requirements for SDI/File Based Applications

These are applications whose primary purpose is to open, create and edit documents. Examples of non-file-based applications would include PIMs and Games.

Required: Support for Common Dialog Boxes. File-based and/or Single Document Interface applications operating on the Microsoft Windows CE-based platform must support common Microsoft Windows CE dialog boxes, including New, Save and Print (as supported), and not use proprietary interfaces for these functions.

Recommended: Recently Used File List. This must appear immediately above the Close command in the File menu, separated from other menu entries above and below by separator bars.

Required: Document Names on Taskbar Buttons. Document names (or Microsoft Windows CE assigned aliases) must appear on the associated taskbar buttons, to the right of the application icon.
