RegCloseKey

The RegCloseKey function releases the handle of the specified key.

Syntax

LONG RegCloseKey(HKEY hKey);

At a Glance

Header file: Winreg.h
Component: Fsreg
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The RegCloseKey function always writes information to the registry before returning, eliminating the need to flush keys in the Windows CE registry.
