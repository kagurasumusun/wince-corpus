GetSystemMenu

The GetSystemMenu macro allows the application to access the window menu (also known as the System menu or the Control menu) for copying and modifying.

Syntax

HMENU GetSystemMenu(HWND hWnd, BOOL bRevert);

At a Glance

Header file: Winuser.h
Component: menu
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support a system menu, but GetSystemMenu is implemented as a macro to maintain compatibility with existing code. You can use the menu handle returned by this macro to disable the close box the same way you would in a Windows desktop platform. There is no other use for the return value in Windows CE. The brevert parameter is ignored. Use the following code to disable the Close button:

EnableMenuItem (GetSystemMenu(hwnd, FALSE), SC_CLOSE,MF_BYCOMMAND | MF_GRAYED);
