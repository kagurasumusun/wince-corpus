PSN_RESET

The PSN_RESET notification message notifies a page that the user has chosen the Cancel button and the property sheet is about to be destroyed. All changes made since the user last chose the Apply Now button are canceled. This notification message is sent in the form of a WM_NOTIFY message.

Syntax

PSN_RESET
lpnmhdr = (NMHDR FAR *) lParam;
