WM_INITMENUPOPUP

The WM_INITMENUPOPUP message is sent when a pop-up menu is about to become active. This allows an application to modify the pop-up menu before it is displayed, without changing the entire menu.

Syntax

WM_INITMENUPOPUP
hmenuPopup = (HMENU) wParam;
uPos = (UINT)LOWORD(lParam);
fSystemMenu = (BOOL)HIWORD(lParam);

At a Glance

Header file:
Component/Module: Menu component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The fSystemMenu parameter is always FALSE.
