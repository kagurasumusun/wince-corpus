NMKEY

The NMKEY structure contains information used with key notification messages.

Syntax

typedef struct tagNMKEY {
NMHDR hdr;
WORD wVKey;
UINT flags;
} NMKEY, FAR * LPNMKEY;

At a Glance

Header file:
Component:
Platforms: H/PC
Versions: 2.0 and later

Members

hdr
NMHDR structure that contains additional information about this notification.
wVKey
The virtual key code of the key that caused the event.
flags
The flags associated with the key. These are the same flags that are passed in the high word of the lParam in the WM_KEYDOWN message.
