ImmGetDefaultIMEWnd

The ImmGetDefaultIMEWnd function gets the default window handle to the IME class.

Syntax

HWND ImmGetDefaultIMEWnd(HWND hWnd);

At a Glance

Header file: Imm.h
Component: Immthunk
Platforms: H/PC (Japanese)
Windows CE versions: Japanese version 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The system creates only one default IME window. Windows CE does not support the IME class.
