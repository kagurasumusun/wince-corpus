TerminateProcess

The TerminateProcesss function terminates the specified process and all of its threads.

Syntax

BOOL TerminateProcess(HANDLE hProcess, DWORD uExitCode);

At a Glance

Header file: Winbase.h
Module: Nk
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support exit codes for processes, so the uExitCode parameter is ignored.
