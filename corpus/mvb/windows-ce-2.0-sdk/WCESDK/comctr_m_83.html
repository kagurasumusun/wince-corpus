RB_GETBKCOLOR

The RB_GETBKCOLOR message retrieves a rebar control's default background color.

Syntax

RB_GETBKCOLOR
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Return Values

Returns a COLORREF value that represent the current default background color.
