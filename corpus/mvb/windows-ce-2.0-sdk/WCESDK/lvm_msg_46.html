LVM_SETITEMTEXT

The LVM_SETITEMTEXT message changes the text of a list view item or subitem.

Syntax

LVM_SETITEMTEXT
wParam = (WPARAM)(int) i;
lParam = (LPARAM)(LV_ITEM FAR *) pitem;
