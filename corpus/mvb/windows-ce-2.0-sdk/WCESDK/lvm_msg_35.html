LVM_SCROLL

The LVM_SCROLL message scrolls the content of a list view control. You can send this message explicitly or by using the ListView_Scroll macro.

Syntax

LVM_SCROLL
wParam = 0;
lParam = MAKELPARAM((int) dx, (int) dy);
