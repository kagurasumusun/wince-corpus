CompareString

The CompareString function compares two character strings, using the locale specified by the given identifier as the basis for the comparison.

Syntax

int CompareString(LCID Locale, DWORD dwCmpFlags, LPCTSTR lpString1, int cchCount1, LPCTSTR lpString2, int cchCount2);

At a Glance

Header file: Winnls.h
Component: coreloc
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the ANSI version of this function.

Windows CE does not support the following values for the dwCmpFlags parameter:
NORM_IGNOREKANATYPE

NORM_IGNORENONSPACE

NORM_IGNORESYMBOLS

NORM_IGNOREWIDTH

The dwCmpflags parameter always includes the SORT_STRINGSORT value.
