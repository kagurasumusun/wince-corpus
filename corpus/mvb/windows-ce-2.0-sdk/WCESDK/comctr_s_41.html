TBREPLACEBITMAP

The TBREPLACEBITMAP structure is used with the TB_REPLACEBITMAP message to replace one toolbar bitmap with another.

Syntax

typedef struct {
HINSTANCE hInstOld;
UINT nIDOld;
HINSTANCE hInstNew;
UINT nIDNew;
int nButtons;
} TBREPLACEBITMAP, *LPTBREPLACEBITMAP;

At a Glance

Header file:
Component:
Platforms: H/PC
Versions: 2.0 and later

Members

hInstOld
The module instance handle of the bitmap resource being replaced.
nIDOld
Resource identifier of the bitmap being replaced.
hInstNew
The module instance handle that contains the new bitmap resource.
nIDNew
Resource identifier of the new bitmap.
nButtons
The number of button images contained in the new bitmap.
