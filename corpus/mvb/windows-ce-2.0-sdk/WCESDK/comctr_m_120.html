TB_HIGHLIGHTBUTTON

The TB_HIGHLIGHTBUTTON message sets the highlight state of a given button in a toolbar control.

Syntax

TB_HIGHLIGHTBUTTON
wParam = (WPARAM) idButton;
lParam = (LPARAM) MAKELONG(fHighlight,0);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

idButton
Command ID for a toolbar button.
fHighlight
Value that specifies the highlight state to be set. If this value is TRUE, the button is highlighted; if FALSE, the button is set to its default state.

Return Values

Returns nonzero if successful or zero otherwise.
