LINE_DEVSPECIFIC

Sent to notify the application about device-specific events occurring a line, address or call. The meaning of the message and the interpretation of the parameters is device specific.

Syntax

LINE_DEVSPECIFIC
dwDevice = (DWORD) hLineOrCall;
dwCallbackInstance = (DWORD) hCallback;
dwParam1 = (DWORD) DeviceSpecific1;
dwParam2 = (DWORD) DeviceSpecific2;
dwParam3 = (DWORD) DeviceSpecific3;
