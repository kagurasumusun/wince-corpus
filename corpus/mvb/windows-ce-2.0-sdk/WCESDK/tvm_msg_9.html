TVM_GETINDENT

The TVM_GETINDENT message retrieves the amount, in pixels, that child items are indented relative to their parent items. You can send this message explicitly or by using the TreeView_GetIndent macro.

Syntax

TV_GETINDENT
wParam = 0;
lParam = 0;
