BM_SETSTYLE

An application sends a BM_SETSTYLE message to change the style of a button.

Syntax

BM_SETSTYLE
wParam = (WPARAM) LOWORD (dwStyle),
lParam = MAKELPARAM (fRedraw, 0)

At a Glance

Header file: Winuser.h
Module/Component: Button control component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The following button styles are not supported:
BS_PUSHBOX

BS_USERBUTTON
