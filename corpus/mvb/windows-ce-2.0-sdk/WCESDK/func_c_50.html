CeGetFileTime

The CeGetFileTime function retrieves the date and time that a file was created, last accessed, and last modified. This is the RAPI version of the GetFileTime function.

Syntax

BOOL CeGetFileTime(HANDLE hFile, LPFILETIME lpCreationTime, LPFILETIME lpLastAccessTime, LPFILETIME lpLastWriteTime);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegGetFileTime function.

For more information about using RAPI functions, see Remote API Functions.
