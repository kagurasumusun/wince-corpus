DB_CEOID_CHANGED

The DB_CEOID_CHANGED message is sent when an object in the object store has been modified.

Syntax

DB_CEOID_CHANGED
oidChanged = (CEOID) wParam;
oidParent = (CEOID) lParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.01 and later

Parameters

oidChanged
Value of wParam. Identifies the object that was modified.
oidParent
Value of lParam. Identifies the parent object of the modified object.

Remarks

When writing applications for Windows CE version 1.0, use the DB_PEGOID_CHANGED message.
