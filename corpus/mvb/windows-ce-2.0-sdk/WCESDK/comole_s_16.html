IDLDESC

The IDLDESC structure is used for holding information needed for transferring a structure element, parameter, or function return value between processes.

Syntax

typedef struct tagIDLDESC {
ULONG dwReserved;
USHORT wIDLFlags;
 };
} IDLDESC, *LPIDLDESC;

At a Glance

Header file: oaidl.h
Component:
Platforms: H/PC
Windows CE versions: 2.0 and later

Members

dwReserved
This reserved variable must be set to NULL.
wIDLFlags
The flag may be assigned to one of the following values:
IDLFLAG_NONE
Whether the parameter pases or receives information is unspecified.
IDLFLAG_FIN
Parameter passes information from the caller to the callee.
IDLFLAG_FOUT
Parameter returns information from the callee to the caller.
IDLFLAG_FLCID
Parameter is the local ID of a client application.
IDLFLAG_FRETVAL
Parameter is the return value of the member.
