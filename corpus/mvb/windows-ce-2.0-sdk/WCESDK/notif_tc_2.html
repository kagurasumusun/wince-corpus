TBN_GETBUTTONINFO

The TBN_GETBUTTONINFO notification message retrieves toolbar customization information and notifies the toolbar's parent window of any changes being made to the toolbar. This is sent in the form of a WM_NOTIFY message.

Syntax

TBN_GETBUTTONINFO
ptbn = (TBNOTIFY FAR *) lParam;
