ICONINFO

The ICONINFO structure contains information about an icon.

Syntax

typedef struct _ICONINFO { // ii
BOOL fIcon;
DWORD xHotspot;
DWORD yHotspot;
HBITMAP hbmMask;
HBITMAP hbmColor;
} ICONINFO;

At a Glance

Header file:
Component: gwes/Icon
gwes/Iconcurs
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

If you are not using the Iconcurs component, the fIcon member must be set to TRUE. The Windows CE Icon component doesn't support cursors. If you need mouse cursor suppport in your application, use the Windows CE Iconcurs component rather than the Windows CE Icon component.
