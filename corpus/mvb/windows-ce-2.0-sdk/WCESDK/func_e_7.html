ExtensionPropSheetPageProc

The ExtensionPropSheetPageProc function is an application-defined callback function that receives the address of the AddPropSheetPageProc function, which resides in the module that creates a property sheet. A property sheet extension must export the ExtensionPropSheetPageProc function.

Syntax

BOOL CALLBACK ExtensionPropSheetPageProc(LPVOID lpv, LPFNADDPROPSHEETPAGE lpfnAddPropSheetPageProc, LPARAM lParam);

At a Glance

Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK
