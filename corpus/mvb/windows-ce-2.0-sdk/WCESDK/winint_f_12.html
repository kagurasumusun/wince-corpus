HttpOpenRequest

The HttpOpenRequest function opens an HTTP request handle.

Syntax

INTERNETAPI HINTERNET WINAPI HttpOpenRequest(HINTERNET hConnect, LPCTSTR lpszVerb, LPCTSTR lpszObjectName, LPCTSTR lpszVersion, LPCTSTR lpszReferrer , OPTIONAL, LPCTSTR FAR * lplpszAcceptTypes , DWORD dwFlags, DWORD dwContext);

At a Glance

Header file: Wininet.h
Module: Wininet
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

For Windows CE the internet flag, dwFlags, does not accept the following values for opening an HTTP request:

INTERNET_FLAG_RELOAD
Data is always from the wire and caching is not supported.
INTERNET_FLAG_DONT_CACHE
Data is never cached.

The dwContext parameter allows for progress status callbacks to the application, but all requests will be handled synchronously.
