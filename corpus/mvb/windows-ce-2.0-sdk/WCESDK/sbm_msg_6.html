SBM_SETSCROLLINFO

An application sends the SBM_GETSCROLLINFO message to set the parameters of a scroll bar.

Syntax

SBM_SETSCROLLINFO
wParam = (WPARAM) fRedraw;
lParam = (LPARAM) (LPSCROLLINFO) lpsi;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE 2.0, if you pass a null pointer in the lpsi parameter (lParam), SBM_SETSCROLLINFO returns zero, rather than the current position of the scroll box.
