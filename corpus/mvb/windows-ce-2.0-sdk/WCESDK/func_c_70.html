CeRegEnumValue

The CeRegEnumValue function enumerates the values for the specified open registry key. CeRegEnumValue copies one indexed value name and data block for the key each time it is called. This is the RAPI version of the RegEnumValue function.

Syntax

LONG CeRegEnumValue(HKEY hKey, DWORD dwIndex, LPWSTR lpszName, LPDWORD lpcchName, LPDWORD NIETHER lpReserved, LPDWORD lpType, LPBYTE lpData, LPDWORD lpcbData);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegRegEnumValue function.

For more information about using RAPI functions, see Remote API Functions.
