CPLINFO

The CPLINFO structure contains resource information and a user-defined value for a dialog box supported by a Control Panel application.

Syntax

typedef struct tagCPLINFO { // cpli
int idIcon;
int idName;
int idInfo;
LONG lData;
} CPLINFO;
