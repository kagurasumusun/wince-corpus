IOleObject::EnumAdvise

The IOleObject::EnumAdvise method retrieves a pointer to an enumerator that can be used to enumerate the advisory connections registered for an object, so a container can know what to release prior to closing down.

Syntax

HRESULT IEnumSTATDATA(
IEnumSTATDATA ** ppenumAdvise
);

At a Glance

Header file: Oleidl.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.
