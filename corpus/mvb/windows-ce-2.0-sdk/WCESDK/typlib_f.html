CreateTypeLib2

The CreateTypeLib2 function creates a type library in the file/in-memory format that makes use of memory-mapped files for 32-bit platforms. Its output parameter (ppctlib) points to a newly created object that supports the ICreateTypeLib2 interface.

Syntax

HRESULT CreateTypeLib2( SYSKIND syskind, LPOLESTR szFile, ICreateTypeLib2 ** ppctlib);

At a Glance

Header file: Oleauto.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.

Remarks

Windows CE does not implement the ICreateTypeLib2::SaveAllChanges method.

Passing into this function any invalid and, under some circumstances, NULL pointers will result in unexpected termination of the application. For more information about handling exceptions, see COM and Automation.
