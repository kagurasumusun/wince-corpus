RasEnumEntries

The RasEnumEntries function lists all entry names in a remote access phone book.

Syntax

DWORD RasEnumEntries(LPTSTR reserved, LPTSTR lpszPhoneBookPath, LPRASENTRYNAME lpRasEntryName, LPDWORD lpcb, LPDWORD lpcEntries);
