FillRect

The FillRect function fills a rectangle using the specified brush. This function fills the rectangle's left and top borders, but excludes the right and bottom borders.

Syntax

int FillRect(HDC hDC, CONST RECT *lprc, HBRUSH hbr);

At a Glance

Header file: Wingdi.h
Component: mgdraw
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE version 1.0, the hbr parameter cannot be a color brush.

This function is the same in Windows CE version 2.0 as it is in Windows desktop platforms.
