RasValidateEntryName

The RasValidateEntryName function validates the format of a connection entry name. It must contain at least one non-white-space alpha-numeric character.

Syntax

DWORD RasValidateEntryName(LPTSTR lpszPhonebook, LPTSTR lpszEntry);
