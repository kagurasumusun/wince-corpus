MonthCal_GetCurSel

This macro retrieves the system time portrayed by the currently selected date.

Syntax

BOOL MonthCal_GetCurSel(HWND hwndMC, LPSYSTEMTIME lpSysTime);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related message: MCM_GETCURSEL

Parameters

hwndMC
Handle to a month calendar control.
lpSysTime
Address of a SYSTEMTIME structure that will receive the system time information.

Return Values

Returns nonzero if successful, or zero otherwise. This macro will always fail when applied to month calendar controls that are set to the MCS_MULTISELECT style.
