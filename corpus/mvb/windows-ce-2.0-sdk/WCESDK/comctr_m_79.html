RB_GETBANDINFO

The RB_GETBANDINFO message retrieves information about a specified band in a rebar control.

Syntax

RB_GETBANDINFO
wParam = (WPARAM)(UINT) uBand;
lParam = (LPARAM)(LPREBARBANDINFO) lprbbi;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

uBand
Zero-based index of the band for which the information will be retrieved.
lprbbi
Address of a REBARBANDINFO structure that will receive the requested band information. You must set the cbSize member of this structure to sizeof(REBARBANDINFO) and set the fMask parameter to the items you want to retrieve before sending this message.

Return Values

Returns nonzero if successful, or zero otherwise.
