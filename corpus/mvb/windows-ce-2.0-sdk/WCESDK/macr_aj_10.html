Header_SetItem

The Header_SetItem macro sets the attributes of the specified item in a header control. You can use this macro or explicitly send the HDM_SETITEM message.

Syntax

BOOL Header_SetItem(
 hwndHD,
 index,
 phdi
);

At a Glance

Header file:
Module/Component:
Platforms:
Versions: 1.0 and later (updated in 2.0)
Related message: HDM_SETITEM
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE 2.0, this macro supports item order and image list information. By using the iImage and iOrder fields of the new HDITEM structure you pass in the phdi parameter, you can control the order in which items are displayed and specify images to appear with items.
