MCM_SETMAXSELCOUNT

The MCM_SETMAXSELCOUNT message sets the maximum number of days that can be selected in a month calendar control.

Syntax

MCM_SETMAXSELCOUNT
wParam = (WPARAM)(INT) iMax;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: MonthCal_SetMaxSelCount

Parameters

iMax
INT value that will be set to represent the maximum number of selectable days.

Return Values

Returns nonzero if successful, and returns zero otherwise. This message will fail if applied to a month calendar control that does not use the MCS_MULTISELECT style.
