MonthCal_GetToday

This macro retrieves the date information for the date specified as "today" for a month calendar control.

Syntax

BOOL MonthCal_GetToday(HWND hwndMC, LPSYSTEMTIME lpToday);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related message: MCM_GETTODAY

Parameters

hwndMC
Handle to a month calendar control.
lpToday
Address of a SYSTEMTIME structure that will receive the date information.

Return Values

Returns nonzero if successful, or zero otherwise.
