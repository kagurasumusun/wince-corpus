CreatePalette

The CreatePalette function creates a logical color palette.

Syntax

HPALETTE CreatePalette( CONST LOGPALETTE * lplgpl);

At a Glance

Header file: Wingdi.h
Component: mgpal
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Since Windows CE does not arbitrate between the palettes of the foreground and background applications, palettes are not automatically padded with Windows systems colors. Therefore, the number of color entries in the palette created by this function is always the same as the palNumEntries member of the LOGPALETTE structure.
