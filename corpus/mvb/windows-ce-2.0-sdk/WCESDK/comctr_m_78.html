RB_GETBANDCOUNT

The RB_GETBANDCOUNT message retrieves the count of bands currently in the rebar control.

Syntax

RB_GETBANDCOUNT
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Return Values

Returns a UINT value that represents the number of bands assigned to the control.
