DOCINFO

The DOCINFO structure contains the information necessary for printing documents.

Syntax

typedef struct { // di
int cbSize;
LPCTSTR lpszDocName;
LPCTSTR lpszOutput;
LPCTSTR lpszDatatype;
DWORD fwType;
} DOCINFO; .

At a Glance

Header file: Wingdi.h
Component: mgprint
Platforms: H/PC
Versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the lpszDatatype and fwType members. You should initialize them to zero.
