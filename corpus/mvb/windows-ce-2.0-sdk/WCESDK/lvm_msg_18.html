LVM_GETITEMPOSITION

The LVM_GETITEMPOSITION message retrieves the position of a list view item. You can send this message explicitly or by using the ListView_GetItemPosition macro.

Syntax

LVM_GETITEMPOSITION
wParam = (WPARAM)(int) i;
lParam = (LPARAM)(POINT FAR *) ppt;
