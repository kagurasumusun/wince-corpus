TabCtrl_DeselectAll

This macro resets items in a tab control, clearing any that were set to the TCIS_BUTTONPRESSED state.

Syntax

void TabCtrl_DeselectAll(HWND hwndTab, UINT fExcludeFocus);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related message: TCM_DESELECTALL

Parameters

hwndTab
Handle to the tab control.
fExcludeFocus
Flag value that specifies the scope of the item deselection. If this parameter is set to FALSE, all tab items will be reset. If it is set to TRUE, then all but the currently selected tab item will be reset.
