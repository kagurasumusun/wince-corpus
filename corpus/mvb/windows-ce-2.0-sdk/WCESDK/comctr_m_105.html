RBN_LAYOUTCHANGED

The RBN_LAYOUTCHANGED notification message is sent by a rebar control when you change the layout of the control's bands. This notification message is sent in the form of a WM_NOTIFY message.

Syntax

RBN_LAYOUTCHANGED
lpnmhdr = (LPNMHDR) lParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

lpnmhdr
Address of an NMHDR structure that contains additional information about this notification message.

Return Values

The return value for this notification is not used.
