InternetTimeFromSystemTime

The InternetTimeFromSystemTime function formats a date and time according to the specified RFC format ¾ as specified in the HTTP version 1.0 specification.

Syntax

INTERNETAPI BOOL WINAPI InternetTimeFromSystemTime(CONST SYSTEMTIME *pst, DWORD dwRFC, LPTSTR lpszTime, DWORD cbTime);

At a Glance

Header file: Wininet.h
Module: Wininet
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The cbTime parameter refers to the count of characters.
