CB_GETLBTEXT

An application sends a CB_GETLBTEXT message to retrieve a string from the list of a combo box.

Syntax

CB_GETLBTEXT
wParam = (WPARAM) index;
lParam = (LPARAM)(LPCSTR) lpszBuffer;
