PSM_REBOOTSYSTEM

The PSM_REBOOTSYSTEM message indicates that system needs to be restarted for the changes to take effect. An application should send this message only in response to the PSN_APPLY or PSN_KILLACTIVE notification message.

Syntax

PSM_REBOOTSYSTEM
wParam = 0;
lParam = 0;
