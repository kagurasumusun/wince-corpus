HEAPENTRY32

The HEAPENTRY32 structure describes one entry (block) of a heap that is being examined.

Syntax

typedef struct tagHEAPENTRY32 
{ 
    DWORD  dwSize; 
    HANDLE hHandle; 
    DWORD  dwAddress; 
    DWORD  dwBlockSize; 
    DWORD  dwFlags; 
    DWORD  dwLockCount; 
    DWORD  dwResvd; 
    DWORD  th32ProcessID; 
    DWORD  th32HeapID; 
} HEAPENTRY32; 
typedef HEAPENTRY32 *  PHEAPENTRY32; 
typedef HEAPENTRY32 *  LPHEAPENTRY32;

Remarks

Windows CE does not support movable blocks (LF32_MOVEABLE).

Windows CE supports the following additional values for the dwFlags parameter:

LF_32DECOMMIT
Decommited memory block.
LF32_BIGBLOCK
A large piece of memory that has been virtually allocated.
