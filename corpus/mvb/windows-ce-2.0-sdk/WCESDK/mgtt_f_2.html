EnumFontFamilies

The EnumFontFamilies function enumerates the fonts in a specified font family that are available on a specified device. This function supersedes the EnumFonts function.

Syntax

int EnumFontFamilies(HDC hdc, LPCTSTR lpszFamily, FONTENUMPROC lpEnumFontFamProc, LPARAM lParam);

At a Glance

Component: mgrast2
mgtt

Windows CE versions: 1.0 or later

Remarks

Windows CE version 1.0 supports only raster fonts.

Windows CE version 2.0 supports systems that use either TrueType or raster fonts but not both. The font type (raster or TrueType) is chosen at system design time, and cannot be changed by an application.
