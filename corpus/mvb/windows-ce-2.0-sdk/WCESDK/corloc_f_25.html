GetTimeFormat

The GetTimeFormat function formats a time as a time string for a specified locale. The function formats either a specified time or the local system time.

Syntax

int GetTimeFormat(LCID Locale, DWORD dwFlags, const SYSTEMTIME *lpTime, LPCTSTR lpFormat, LPTSTR lpTimeStr, int cchTime);

At a Glance

Header file: Winnls.h
Component: coreloc
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The Locale parameter is ignored and the default system locale is always used. The Locale parameter should be set to LOCALE_SYSTEM_DEFAULT to ensure compatibility with future versions of Windows CE.

Windows CE does not support the LOCALE_NOUSEOVERRIDE flag for the dwFlags parameter.
