CreateBitmap

The CreateBitmap function creates a bitmap with the specified width, height, and bit depth.

Syntax

HBITMAP CreateBitmap(int nWidth, int nHeight, UINT cPlanes, UINT cBitsPerPel, CONST VOID *lpvBits);

At a Glance

Header file: Wingdi.h
Component: mgbitmap
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The cPlanes parameter must be 1.
