PBM_SETRANGE

The PBM_SETRANGE message sets the minimum and maximum values for a progress bar and redraws the bar to reflect the new range.

Syntax

PBM_SETRANGE
(nMinRange, nMaxRange) = (MAKELPARAM) lParam;
