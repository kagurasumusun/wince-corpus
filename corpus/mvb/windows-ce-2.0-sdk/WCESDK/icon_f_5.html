LoadIcon

The LoadIcon function loads the specified icon resource from the executable (.exe) file associated with an application instance.

Syntax

HICON LoadIcon(HINSTANCE hInstance, LPCTSTR lpIconName);

At a Glance

Header file: Winuser.h
Component: icon
iconcurs
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Predefined icons (IDI_*) are not supported.

In Windows CE 1.0, the icon must be a two bit per pixel (.ic2) icon or a monochrome icon.
