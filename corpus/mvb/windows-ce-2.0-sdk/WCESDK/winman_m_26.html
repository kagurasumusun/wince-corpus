WM_STYLECHANGED

The WM_STYLECHANGED message is sent to a window after the SetWindowLong function has changed one or more of the window's styles.

Syntax

WM_STYLECHANGED
wStyleType = wParam;
lpss = (LPSTYLESTRUCT) lParam;
