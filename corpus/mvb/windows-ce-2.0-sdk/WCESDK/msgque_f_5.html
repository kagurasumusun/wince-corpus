PeekMessage

The PeekMessage function checks a thread message queue for a message and places the message (if any) in the specified structure.

Syntax

BOOL PeekMessage(LPMSG lpMsg, HWND hWnd, UINT wMsgFilterMin, UINT wMsgFilterMax, UINT wRemoveMsg);

At a Glance

Header file: Winuser.h
Component: msgque
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

WM_PAINT messages with a null update region are not removed from the queue.
