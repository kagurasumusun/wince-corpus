Header_SetOrderArray

This macro sets the left-to-right order of header items.

Syntax

BOOL Header_SetOrderArray(HWND hwndHD, int iSize, int *lpiArray);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related message: HDM_SETORDERARRAY

Parameters

hwndHD
Handle to a header control.
iSize
Size of the buffer at lpiArray, in elements. This value must equal the value returned by HDM_GETITEMCOUNT.
lpiArray
Address of an array that specifies the order in which items should be displayed, from left to right. For example, if the contents of the array are {2,0,1}, the control displays item 2, item 0, and item 1 in that order.

Return Values

Returns nonzero if successful, or zero otherwise.
