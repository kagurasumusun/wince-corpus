InternetQueryDataAvailable

This InternetQueryDataAvailable function queries the amount of data available.

Syntax

INTERNETAPI BOOL WINAPI InternetQueryDataAvailable(HINTERNET hFile, LPDWORD lpdwNumberOfBytesAvailable, DWORD dwFlags, DWORD dwContext);

At a Glance

Header file: Wininet.h
Module: Wininet
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE stipulates that the hFile parameter must be a valid Internet file handle returned by the FtpOpenFile, FtpFindFirstFile, or HttpOpenRequestt function.

The InternetQueryDataAvailable function can be completed in either synchronous or asynchronous mode.
