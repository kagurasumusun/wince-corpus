OleCreate

The OleCreate function creates an embedded object identified by a CLSID. It is typically used to implement a menu item that allows the end user to insert a new object.

Syntax

WINOLEAPI OleCreate( REFCLSID rclsid, REFIID riid, DWORD renderopt, FORMATETC * pFormatEtc, IOleClientSite * pClientSite, IStorage * pStg, void ** ppvObject);

At a Glance

Header file: Ole2.h
Component: Ole232
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.

Remarks

Passing into this function any invalid and, under some circumstances, NULL pointers will result in unexpected termination of the application. For more information about handling exceptions, see COM and Automation.
