IEnumReplItem::GetFolderHandle

The IEnumReplItem::GetFolderHandle method gets a handle to the folder (HREPLFLD) that is currently being enumerated.

Syntax

hHREPLFLD GetFolderHandle ( );

At a Glance

Header file: Cesync.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Return Values

returns the handle to the folder (HREPLFLD) that is being enumerated.
