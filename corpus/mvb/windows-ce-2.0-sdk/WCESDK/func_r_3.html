ResetEvent

The ResetEvent function sets the state of the specified event object to nonsignaled.

Syntax

BOOL ResetEvent(HANDLE hEvent);

At a Glance

Header file: Kfuncs.h
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support waiting for processes or threads.

ResetEvent returns FALSE if the handle to the event object is invalid.
