SetCaretBlinkTime

The SetCaretBlinkTime function sets the caret blink time to the specified number of milliseconds. The blink time is the elapsed time, in milliseconds, required to invert the caret's pixels.

Syntax

BOOL SetCaretBlinkTime(UINT wMSeconds);

At a Glance

Header file: Winuser.h
Component: caret
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE, changing the caret blink time in one application will not affect the blink time in subsequently loaded applications.
