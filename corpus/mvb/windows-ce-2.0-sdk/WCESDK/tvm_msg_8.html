TVM_GETIMAGELIST

The TVM_GETIMAGELIST message retrieves the handle of the normal or state image list associated with a tree view control. You can send this message explicitly or by using the TreeView_GetImageList macro.

Syntax

TVM_GETIMAGELIST
wParam = (WPARAM) iImage;
lParam = 0;
