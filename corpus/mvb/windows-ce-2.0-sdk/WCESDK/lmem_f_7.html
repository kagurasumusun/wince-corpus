LocalAlloc

The LocalAlloc function allocates the specified number of bytes from the heap. In the linear Win32 API environment, there is no difference between the local heap and the global heap.

Syntax

HLOCAL LocalAlloc(UINT uFlags, UINT uBytes);

At a Glance

Header file: Winbase.h
Component: lmem
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the following uFlags flags:
LMEM_MOVEABLE

LHND

NONZEROLPTR

LMEM_DISCARDABLE

LMEM_NOCOMPACT

LMEM_NODISCARD

NONZEROLHND

The local heap for each process cannot exceed 1 megabyte. However, a process can create multiple heaps using the HeapCreate function and each of these heaps can be up to 1 megabyte.
