RB_DELETEBAND

The RB_DELETEBAND message deletes a band from a rebar control.

Syntax

RB_DELETEBAND
wParam = (WPARAM)(UINT) uBand;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

uBand
Zero-based index of the band to be deleted.

Return Values

Returns nonzero if successful, or zero otherwise.
