IOleObject::Close

The IOleObject::Close method changes an embedded object from the running to the loaded state. Disconnects a linked object from its link source.

Syntax

HRESULT Close(
DWORD dwSaveOption
);

At a Glance

Header file: Oleidl.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.
