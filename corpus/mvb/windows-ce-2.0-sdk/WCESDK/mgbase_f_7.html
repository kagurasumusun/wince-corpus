GetDeviceCaps

The GetDeviceCaps function retrieves information about the capabilities of a specified device.

Syntax

int GetDeviceCaps(HDC hdc, int nIndex);

At a Glance

Header file: Wingdi.h
Component: mgbase
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the following values for the nIndex parameter:
VREFRESH

DESKTOPHORZRES

DESKTOPVERTRES

BLTALIGNMENT


Windows CE version 1.0 does not support the following values for the nIndex parameter:
PHYSICALWIDTH

PHYSICALHEIGHT

PHYSICALOFFSETX

PHYSICALOFFSETY
