TBM_SETRANGEMIN

The TBM_SETRANGEMIN message sets the minimum position for the slider in a trackbar.

Syntax

TBM_SETRANGEMIN
wParam = (WPARAM) fRedraw;
lParam = (LPARAM) lMinimum;
