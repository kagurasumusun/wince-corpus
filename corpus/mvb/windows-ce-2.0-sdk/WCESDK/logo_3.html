General Requirements

These guidelines for applications which bear the Windows CE Logo were fashioned with the end user in mind. The goal of the Logo program is to foster ease of use of compliant applications by providing a consistent user interface and consistent operation to the extent possible. The Microsoft Windows CE operating system is modeled on the Windows 95 operating system, which millions of people around the world are familiar with and use every day on their desktop and portable computers. The areas in which the interface of Microsoft Windows CE differs from the interface of Windows 95 are chiefly due to the unique performance characteristics of the hardware platform for Microsoft Windows CE. Like the other Microsoft logo programs, the Windows CE Logo is intended to inform consumers that the Logo'd product complies with a set of criteria that ensure a convenient and predictable user experience.
