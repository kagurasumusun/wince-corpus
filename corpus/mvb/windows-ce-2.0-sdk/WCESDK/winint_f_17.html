InternetCombineUrl

The InternetCombineUrl function combines a base and relative URL into a single, canonicalized, URL.

Syntax

INTERNETAPI BOOL WINAPI InternetCombineUrl(LPCTSTR lpszBaseUrl, LPCTSTR lpszRelativeUrl, LPTSTR lpszBuffer, LPDWORD lpdwBufferLength, DWORD dwFlags);

At a Glance

Header file: Wininet.h
Module: Wininet
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The lpdwBufferLength parameter refers to the count of characters.
