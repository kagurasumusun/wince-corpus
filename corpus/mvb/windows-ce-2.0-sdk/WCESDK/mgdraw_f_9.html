FillRgn

The FillRgn function fills a region using the specified brush.

Syntax

BOOL FillRgn( HDC hdc, HRGN hrgn, HBRUSH hbr);

At a Glance

Header file: Wingdi.h
Component: mgdraw
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

This function is the same in Windows CE version 2.0 as it is in Windows desktop platforms.
