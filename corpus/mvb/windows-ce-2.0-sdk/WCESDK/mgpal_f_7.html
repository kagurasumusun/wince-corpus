SelectPalette

The SelectPalette function selects the specified logical palette into a device context.

Syntax

HPALETTE SelectPalette( HDC hdc, HPALETTE hpal, BOOL bForceBackground);

At a Glance

Header file: Wingdi.h
Component: mgpal
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not arbitrate between the palettes of the foreground and background applications. Therefore, Windows CE ignores the bForceBackground parameter, treating it as though it were always false.
