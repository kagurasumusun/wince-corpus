SafeArrayAllocData

The SafeArrayAllocData function allocates memory for a safe array, based on a descriptor created with SafeArrayAllocDescriptor.

Syntax

HRESULT SafeArrayAllocData(SAFEARRAY FAR * psa,);

At a Glance

Header file: Oleauto.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK.

Remarks

Passing into this function any invalid and, under some circumstances, NULL pointers will result in unexpected termination of the application. For more information about handling exceptions, see COM and Automation.

See also

SafeArrayDestroyData, SafeArrayDestroyDescriptor
