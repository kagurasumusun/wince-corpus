MaskBlt

The MaskBlt function combines the color data for the source and destination bitmaps using the specified mask and raster operation.

Syntax

BOOL MaskBlt(HDC hdcDest, int nXDest, int nYDest, int nWidth, int nHeight, HDC hdcSrc, int nXSrc, int nYSrc, HBITMAP hbmMask, int xMask, int yMask, DWORD dwRop);

At a Glance

Header file: Wingdi.h
Component: mgblt2
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE version 1.0 supports only the SRCCOPY and SRCINVERT raster operations.

This function is the same in Windows CE version 2.0 as it is in Windows desktop platforms.
