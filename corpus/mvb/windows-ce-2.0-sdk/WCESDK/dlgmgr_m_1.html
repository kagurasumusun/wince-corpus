DM_SETDEFID

An application sends a DM_SETDEFID message to change the identifier of the default push button for a dialog box.

Syntax

DM_SETDEFID
wParam = idControl;

At a Glance

Header file:
Component/Module: Dialog manager component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

This message should not be used to change the default style when doing a SetFocus to a dialog control. Use the WM_NEXTDLGCTL message instead.
