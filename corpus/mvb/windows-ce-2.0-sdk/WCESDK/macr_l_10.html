ListView_GetColumn

The ListView_GetColumn macro retrieves the attributes of a list view control's column. You can use this macro or explicitly send the LVM_GETCOLUMN message.

Syntax

BOOL ListView_GetColumn(
 HWND hwnd,
 int iCol,
 LV_COLUMN FAR* pcol
);
