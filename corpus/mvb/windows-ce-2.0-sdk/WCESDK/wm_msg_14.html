WM_PALETTECHANGED

Windows CE sends the WM_PALETTECHANGED message to all top-level and overlapped windows after the window with the keyboard focus realizes its logical palette. This message enables windows that do not have the keyboard focus to realize their logical palettes and update their client areas.

Syntax

WM_PALETTECHANGED hwndPalChg = (HWND) wParam;
