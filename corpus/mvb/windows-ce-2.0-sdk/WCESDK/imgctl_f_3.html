ImageList_Create

The ImageList_Create function creates a new image list.

Syntax

HIMAGELIST WINAPI ImageList_Create(int cx, int cy, UINT flags, int cInitial, int cGrow);

At a Glance

Header file: Commctrl.h
Component: Imgctl
Platforms: H/PC
Windows CE Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the ILC_COLOR4, ILC_COLOR8, ILC_COLOR16, ILC_COLOR24 and ILC_COLOR32 values in the flags parameter.
