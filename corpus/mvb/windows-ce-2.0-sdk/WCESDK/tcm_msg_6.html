TCM_GETITEM

The TCM_GETITEM message retrieves information about a tab in a tab control. You can send this message explicitly or by using the TabCtrl_GetItem macro.

Syntax

TCM_GETITEM
wParam = (WPARAM)(int) iItem;
lParam = (LPARAM)(TC_ITEM FAR *) pitem;
