LVM_GETCOLUMN

The LVM_GETCOLUMN message retrieves the attributes of a list view control's column. You can send this message explicitly or by using the ListView_GetColumn macro.

Syntax

LVM_GETCOLUMN
wParam = (WPARAM)(int) iCol;
lParam = (LPARAM)(LV_COLUMN FAR *) pcol;
