LVM_GETSELECTIONMARK

The LVM_GETSELECTIONMARK message retrieves the selection mark from a list view control.

Syntax

LVM_GETSELECTIONMARK
Param = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: ListView_GetSelectionMark

Return Values

Returns the zero-based selection mark, or -1 if there is no selection mark.

Remarks

The selection mark is the item index from which a multiple selection starts.
