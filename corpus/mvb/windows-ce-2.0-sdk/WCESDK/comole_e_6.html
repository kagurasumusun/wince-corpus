TYMED

The TYMED enumeration is used in the STGMEDIUM structure.

typedef enum tagTYMED {
TYMED_HGLOBAL = 1,
TYMED_FILE = 2,
TYMED_ISTREAM = 4,
TYMED_ISTORAGE = 8,
TYMED_NULL = 0,
} TYMED;

Remarks

Windows CE does not support the values TYMED_GDI, TYMED_MFPICT, or TYMED_ENHMF.
