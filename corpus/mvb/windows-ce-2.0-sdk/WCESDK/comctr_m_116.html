TB_GETIMAGELIST

The TB_GETIMAGELIST message retrieves the image list that a toolbar control uses to display buttons in their default state. A toolbar control uses this image list to display buttons in their default state; that is, when they are not hot or disabled.

Syntax

TB_GETIMAGELIST
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Return Values

Returns the handle to the image list or NULL if no image list is set.
