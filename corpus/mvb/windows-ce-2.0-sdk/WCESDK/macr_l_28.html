ListView_GetTextColor

The ListView_GetTextColor macro retrieves the text color of a list view control. You can use this macro or explicitly send the LVM_GETTEXTCOLOR message.

Syntax

COLORREF ListView_GetTextColor(
 HWND hwnd
);
