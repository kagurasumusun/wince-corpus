WM_DRAWITEM

Sent to the owner window of an owner-drawn button or menu when a visual aspect of the button or menu has changed.

Syntax

WM_DRAWITEM
idCtl = (UINT) wParam;
lpdis = (LPDRAWITEMSTRUCT) lParam;

At a Glance

Header file: Winuser.h
Component/Module: Window management component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In the case of a menu item, the receiver of this message is responsible for erasing the background if necessary.

In wi 2.0, the hDC member of the DRAWITEMSTRUCT structure that's pointed to by the lParam is initialized to the grayed or highlighted status of the current item.
