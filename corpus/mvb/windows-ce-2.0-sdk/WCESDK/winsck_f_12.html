inet_addr

The Windows Sockets inet_addr function converts a string containing a dotted address into a network address in the format of an IN_ADDR structure.

Syntax

unsigned long inet_addr (const char *cp);

At a Glance

Header file: Winsock.h
Module: Winsock
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK
