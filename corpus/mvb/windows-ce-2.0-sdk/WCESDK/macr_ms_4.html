MAKELPARAM

The MAKELPARAM macro creates an unsigned 32-bit value for use as an lParam parameter in a message. The macro concatenates two given 16-bit values.

Syntax

LPARAM MAKELPARAM(
 WORD wLow,
 WORD wHigh
);
