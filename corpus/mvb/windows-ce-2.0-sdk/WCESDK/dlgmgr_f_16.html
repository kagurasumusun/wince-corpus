GetDlgItemInt

The GetDlgItemInt function translates the text of a specified control in a dialog box into an integer value.

Syntax

UINT GetDlgItemInt(HWND hDlg, int nIDDlgItem, BOOL *lpTranslated, BOOL bSigned);

At a Glance

Header file: Winuser.h
Component: Dlgmgr
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Text strings with more than 48 characters cannot be translated.
