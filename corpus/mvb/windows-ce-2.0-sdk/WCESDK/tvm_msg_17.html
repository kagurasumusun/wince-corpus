TVM_SELECTITEM

The TVM_SELECTITEM message selects the given tree view item, scrolls the item into view, or redraws the item in the style used to indicate the target of a drag and drop operation. You can send this message explicitly or by using the TreeView_Select, TreeView_SelectItem, or TreeView_SelectDropTarget macro.

Syntax

TVM_SELECTITEM
wParam = (WPARAM) flag;
lParam = (LPARAM)(HTREEITEM) hitem;
