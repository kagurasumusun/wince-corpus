Heap32Next

The Heap32Next function retrieves information about the next block of a heap that has been allocated by a process.

Syntax

BOOL WINAPI Heap32Next( HANDLE hSnapshot, LPHEAPENTRY32 lphe);

At a Glance

Header file: Tlhelp32.h
Platforms: H/PC
Versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE supports an additional parameter:

hSnapShot
Handle to the snapshot returned from a previous call to the CreateToolhelp32Snapshot function.

This function returns ERROR_NO_MORE_FILES or ERROR_INVALID_PARAMETER.
