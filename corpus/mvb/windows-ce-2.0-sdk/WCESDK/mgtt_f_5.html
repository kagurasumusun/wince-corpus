ExtTextOut

The ExtTextOut function draws a character string by using the currently selected font. An optional rectangle may be provided, to be used for clipping, opaquing, or both.

Syntax

BOOL ExtTextOut(HDC hdc, int X, int Y, UINT fuOptions, const RECT *lprc, LPCTSTR lpString, UINT cbCount, const int *lpDx);

At a Glance

Remarks

Windows CE supports only the following flags for the fuOptions parameter.
ETO_CLIPPED

ETO_OPAQUE
