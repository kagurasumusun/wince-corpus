EM_FMTLINES

An application sends an EM_FMTLINES message to set the inclusion flag of soft line-break characters on or off within a multiline edit control. A soft line break consists of two carriage returns and a linefeed and is inserted at the end of a line that is broken because of wordwrapping.

Syntax

EM_FMTLINES
wParam = (WPARAM)(BOOL) fAddEOL;
lParam = 0;
