ListView_GetExtendedListViewStyle

Macro that retrieves the extended styles that are currently in use for a given list view control.

Syntax

DWORD ListView_GetExtendedListViewStyle(HWND hwndLV);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related message: LVM_GETEXTENDEDLISTVIEWSTYLE

Parameters

hwndLV
Handle to a list view control.

Return Values

Returns a DWORD value that represents the styles currently in use for a given list view control. This can be a combination of extended styles.
