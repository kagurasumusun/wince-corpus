IOleObject::InitFromData

The IOleObject::InitFromData method initializes a newly created object with data from a specified data object, which can reside either in the same container or on the Clipboard.

Syntax

HRESULT InitFromData(
IDataObject * pDataObject,
BOOL fCreation,
DWORD dwReserved
);
