TB_ADDBITMAP

The TB_ADDBITMAP message adds one or more images to the list of button images available for a toolbar.

Syntax

TB_ADDBITMAP
wParam = (WPARAM) nButtons;
lParam = (LPARAM)(LPTBADDBITMAP) lptbab;
