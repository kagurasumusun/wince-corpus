PBM_SETRANGE32

The PBM_SETRANGE32 message sets the range of a progress bar control to a 32-bit value.

Syntax

PBM_SETRANGE32
wParam = (WPARAM)(int) iLowLim;
lParam = (LPARAM)(int) iHighLim;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

iLowLim
A 32-bit value that represents the low limit to be set for the progress bar control.
iHighLim
A 32-bit value that represents the high limit to be set for the progress bar control.

Return Values

Returns a DWORD that holds the previous 16-bit low limit in its low word, and the previous 16-bit high limit in its high word. If the previous ranges were 32-bit values, the return value consists of the low words of both 32-bit limits.

Remarks

To retrieve the entire high and low 32-bit values, use the PBM_GETRANGE message.
