ScrollDC

The ScrollDC function scrolls a rectangle of bits horizontally and vertically.

Syntax

BOOL ScrollDC(HDC hDC, int dx, int dy, const RECT *lprcScroll, const RECT *lprcClip, HRGN hrgnUpdate, LPRECT lprcUpdate);

At a Glance

Header file: Winuser.h
Component: mgwinmgr
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Only one of the dx and dy parameters can be nonzero.
