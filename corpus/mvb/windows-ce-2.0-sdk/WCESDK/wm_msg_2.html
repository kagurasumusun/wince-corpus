WM_CHARTOITEM

The WM_CHARTOITEM message is sent by a list box with the LBS_WANTKEYBOARDINPUT style to its owner in response to a WM_CHAR message.

Syntax

WM_CHARTOITEM
nKey = LOWORD(wParam);
nCaretPos = HIWORD(wParam);
hwndListBox = (HWND) lParam;
