IOleObject::GetClipboardData

The IOleObject::GetClipboardData method retrieves a data object containing the current contents of the embedded object on which this method is called. Using the pointer to this data object, it is possible to create a new embedded object with the same data as the original.

Syntax

HRESULT GetClipboardData(
DWORD dwReserved,
IDataObject ** ppDataObject
);
