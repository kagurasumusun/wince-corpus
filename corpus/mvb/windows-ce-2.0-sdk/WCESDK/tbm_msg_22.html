TBM_SETSEL

The TBM_SETSEL message sets the starting and ending positions for the current selection in a trackbar.

Syntax

TBM_SETSEL
wParam = (WPARAM)(BOOL) fRedraw;
lParam = (LPARAM)MAKELONG(lMinimum,lMaximum);
