TB_GETDISABLEDIMAGELIST

The TB_GETDISABLEDIMAGELIST message retrieves the image list that a toolbar control uses to display disabled buttons.

Syntax

TB_GETDISABLEDIMAGELIST
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Return Values

Returns the handle to the disabled image list or NULL if no disabled image list is set.
