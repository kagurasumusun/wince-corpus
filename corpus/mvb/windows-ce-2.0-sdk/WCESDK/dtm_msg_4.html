DTM_ENABLESHRINK

A DTM_ENABLESHRINK message is sent by an application to command the HTML control to toggle the image shrink enable mode (shrink mode). If shrink mode is enabled, the HTML control will shrink images as required to make the page fit the window.

Syntax

DTM_ENABLESHRINK
wParam = 0,
lParam = (LPARAM)(BOOL) bEnableShrink;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

bEnableShrink
Indicates whether to enable shrink mode. If bEnableShrink is TRUE, shrink mode is enabled. If bEnableShrink is FALSE, shrink mode is not enabled.

Return Value

This message does not return a value.

Remarks

This message only affects graphic files that are too large to fit in the window. Usually, in this situation, part of the graphic extends beyond the right edge of the window and the horizontal scroll bar is displayed. Sending DTM_ENABLESHRINK with the lParam set to TRUE removes the horizontal scroll bar and redraws the page so it fits inside the window.
