DTM_GETSYSTEMTIME

The DTM_GETSYSTEMTIME message retrieves the currently selected time from a date and time picker (DTP) control and places it in a specified SYSTEMTIME structure.

Syntax

DTM_GETSYSTEMTIME
wParam = 0;
lParam = (LPARAM) lpSysTime;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: DateTime_GetSystemtime

Parameters

lpSysTime
Address of the SYSTEMTIME structure that receives the system time information. This parameter must be a valid address and cannot be NULL.

Return Values

Returns GDT_VALID if the time information was placed successfully in the given structure; or the message can return GDT_NONE if the control was set to the DTS_SHOWNONE style and the control check box was not selected.
