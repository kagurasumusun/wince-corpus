WM_CTLCOLORDLG

The WM_CTLCOLORDLG message is sent to a dialog box before Windows draws the dialog box. By responding to this message, the dialog box can set its text and background colors by using the given display device context handle. The DefWindowProc function selects the default system colors for the dialog box.

Syntax

WM_CTLCOLORDLG
hdcDlg = (HDC) wParam;
hwndDlg = (HWND) lParam;
