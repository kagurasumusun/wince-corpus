SHAddToRecentDocs

The SHAddToRecentDocs function adds a document to the shell's list of recently used documents or clears all documents from the list. The user gains access to the list through the Start menu of the Windows taskbar.

Syntax

WINSHELLAPI void WINAPI SHAddToRecentDocs(UINT uFlags, LPCVOID pv);

At a Glance

Header file: Shellapi.h
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE, you cannot add more than ten documents to the Recent list.
