Important Notes on Application Types

Microsoft Windows CE compatible applications are currently available in two variants:

"Microsoft Windows CE-based Applications" are those which are singularly available for the Microsoft Windows CE-based platform.

"Microsoft Windows CE-based Desktop Companion Applications" are those which operate on the desktop and interact with Microsoft Windows CE and/or Microsoft Windows CE-compatible Applications. There are several additional requirements which these applications must meet, including earning the "Designed for Microsoft Windows 95" logo.

Applications may also be file-based or non-file based; there are additional requirements for file-based applications; see below.

Forthcoming standards: Development tools which target Microsoft Windows CE may earn the Logo, as well as browser plug-ins, and add-in products such as graphics, filters, custom dictionaries or other non-executables. Specific requirements for these products will be forthcoming; meanwhile, they will be handled on a case-by-case basis.

Hardware which is bundled with your software must be tested by the Windows Hardware Quality Lab, whql@microsoft.com
