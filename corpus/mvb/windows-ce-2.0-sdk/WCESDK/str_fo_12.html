LV_COLUMN

The LV_COLUMN structure contains information about a column in report view. This structure is also used to receive information about a column.

Syntax

typedef struct _LV_COLUMN {
 UINT mask;
int fmt;
int cx;
LPSTR pszText;
int cchTextMax;
int iSubItem;
} LV_COLUMN;
