EM_GETSEL

An application sends an EM_GETSEL message to get the starting and ending character positions of the current selection in an edit control.

Syntax

EM_GETSEL
wParam = (WPARAM)(LPDWORD) lpdwStart;
lParam = (WPARAM)(LPDWORD) lpdwEnd;
