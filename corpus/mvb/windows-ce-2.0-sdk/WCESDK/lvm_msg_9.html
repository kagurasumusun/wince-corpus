LVM_GETCALLBACKMASK

The LVM_GETCALLBACKMASK message retrieves the callback mask for a list view control. You can send this message explicitly or by using the ListView_GetCallbackMask macro.

Syntax

LVM_GETCALLBACKMASK
wParam = 0;
lParam = 0;
