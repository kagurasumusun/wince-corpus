CONNECTDLGSTRUCT

The CONNECTDLGSTRUCT data structure is used in the WNetConnectionDialog1 function to specify the browsing dialog box parameters.

Syntax

typedef struct {
DWORD cbStructure;
HWND hwndOwner;
LPNETRESOURCE lpConnRes;
DWORD dwFlags;
DWORD dwDevNum;
} CONNECTDLGSTRUCT, *LPCONNECTDLGSTRUCT;

At a Glance

Header file: Winnetwk.h
Component:
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The only supported flag in dwFlags is CONNDLG_RO_PATH.
