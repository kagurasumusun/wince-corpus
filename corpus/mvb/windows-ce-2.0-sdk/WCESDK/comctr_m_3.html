DTM_GETMCFONT

The DTM_GETMCFONT message retrieves the font that the date and time picker (DTP) control's child month calendar control is currently using.

Syntax

DTM_GETMCFONT
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: DateTime_GetMonthCalFont

Return Values

Returns an HFONT value that is the handle to the current font.
