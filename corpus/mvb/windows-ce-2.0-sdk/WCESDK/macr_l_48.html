ListView_SetTextColor

The ListView_SetTextColor macro sets the text color of a list view control. You can use this macro or explicitly send the LVM_SETTEXTCOLOR message.

Syntax

BOOL ListView_SetTextColor(
 HWND hwnd,
 COLORREF clrText
);
