htons

The Windows Sockets htons function converts a u_short from host byte order to network byte order.

Syntax

u_short htons (u_short hostshort);

At a Glance

Header file: Winsock.h
Module: Winsock
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK
