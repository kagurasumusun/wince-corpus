MAKELRESULT

The MAKELRESULT macro creates an unsigned 32-bit value for use as a return value from a window procedure. The macro concatenates two given 16-bit values.

Syntax

LRESULT MAKELRESULT(
 WORD wLow,
WORD wHigh
);
