DateTime_SetMonthCalFont

The DateTime_SetMonthCalFont macro sets the font to be used by the date and time picker (DTP) control's child month calendar control.

Syntax

void DateTime_SetMonthCalFont(HWND hwndDP, HFONT hFont, LPARAM MAKELONG(hRedraw, 0));

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related message: DTM_SETMCFONT

Parameters

hwndDP
Handle to a DTP control.
hFont
Handle to the font that will be set.
fRedraw
Specifies whether the control should be redrawn immediately upon setting the font. Setting this parameter to TRUE causes the control to redraw itself.
