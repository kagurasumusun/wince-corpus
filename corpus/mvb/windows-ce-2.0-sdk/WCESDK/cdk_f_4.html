SafeArrayCreateVector

The SafeArrayCreateVector function creates a one-dimensional array whose lower bound is always zero. A safe array created with SafeArrayCreateVector is a fixed size, so the constant FADF_FIXEDSIZE is always set.

Syntax

HRESULT SafeArrayCreateVector(VARTYPE vt, long lLbound, unsigned int cElements);

At a Glance

Header file: Oleauto.h
Platforms: H/PC
Versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Passing into this function any invalid and, under some circumstances, NULL pointers will result in unexpected termination of the application. For more information about handling exceptions, see COM and Automation.
