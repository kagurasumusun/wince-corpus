SetLocaleInfo

The SetLocaleInfo function sets an item of locale information. It does so by making an entry in the process portion of the locale table. This setting only affects the user override portion of the locale settings; it does not set the system defaults.

Syntax

BOOL SetLocaleInfo(LCID Locale, LCTYPE LCType, LPCTSTR lpLCData);

At a Glance

Header file: Winnls.h
Component: coreloc
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE supports an additional LCTYPE value, LOCALE_SYEARMONTH. Windows CE does not support the LOCALE_IPAPERSIZE value.
