GetVersionEx

The GetVersionEx function obtains extended information about the version of the operating system that is currently running.

Syntax

BOOL GetVersionEx(LPOSVERSIONINFO lpVersionInformation);

At a Glance

Header file: Winbase.h
Component: coremain
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The value of the dwPlatformID member of the OSVERSIONINFO structure will be VER_PLATFORM_WIN32_CE.
