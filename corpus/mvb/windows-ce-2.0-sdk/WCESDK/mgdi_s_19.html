RGNDATA

The RGNDATA structure contains a header and an array of rectangles that comprise a region. The rectangles are sorted top to bottom, left to right. They do not overlap.

Syntax

typedef struct _RGNDATA { // rgnd
RGNDATAHEADER rdh;
char Buffer[1];
} RGNDATA;
