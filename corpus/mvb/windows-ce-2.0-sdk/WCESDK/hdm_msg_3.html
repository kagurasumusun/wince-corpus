HDM_HITTEST

The HDM_HITTEST message tests a point to determine which header item, if any, is at the specified point.

Syntax

HDM_HITTEST
wParam = 0;
lParam = (LPARAM)(HD_HITTESTINFO FAR *) phdhti;
