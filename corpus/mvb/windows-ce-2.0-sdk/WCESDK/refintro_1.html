Name Changes From Version 1.0 to 1.01

Several API elements have new names in Windows CE version 1.01. Occurrences of "Peg" in these names have been replaced with "Ce."

Use the "Peg" names when writing applications for Version 1.0 and Version 1.01. The "Peg" names are supported in version 1.01, but support in future versions of Windows CE is not guaranteed. Use the "Ce" names when writing applications for Version 1.01 or later.

The Windows CE SDK also provides corresponding remote API (RAPI) versions of these "Peg" and "Ce" functions. All RAPI functions retain the "Peg" naming convention. You should always use the older names when using these functions. For more information about the RAPI functions, see Remote API Functions.
