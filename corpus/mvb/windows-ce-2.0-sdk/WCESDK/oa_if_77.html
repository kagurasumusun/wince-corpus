IStream::CopyTo

The IStream::CopyTo method copies a specified number of bytes from the current seek pointer in the stream to the current seek pointer in another stream.

Syntax

HRESULT CopyTo(
IStream * pstm,
ULARGE_INTEGER cb,
ULARGE_INTEGER * pcbRead,
ULARGE_INTEGER * pcbWritten
);
