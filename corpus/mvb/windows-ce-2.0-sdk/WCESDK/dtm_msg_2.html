DTM_ANCHOR

A DTM_ANCHOR message is sent by an application to tell the HTML control to jump to the indicated anchor.

Syntax

DTM_ANCHOR
wParam = 0,
lParam = (LPARAM)(LPSTR) szAnchor;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later

Parameters

szAnchor
Null-terminated text string that contains the name of the anchor to which the HTML control is to jump.

Return Value

This message does not return a value.

Remarks

If the anchor is already in the document, the jump occurs immediately. If the specified anchor is not in the document, the request will be remembered such that, if the anchor is added, the jump will occur as soon as the anchor is available. Note that while there is a pending anchor, any navigation commands from the user (keyboard scrolling or using the scroll bar) will abort the pending anchor jump.
