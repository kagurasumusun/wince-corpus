SendInput

The SendInput function synthesizes keystrokes, stylus and mouse motions, and button clicks.

Syntax

UINT SendInput(UINT nInputs, LPINPUT pInputs, int cbSize);

At a Glance

Header file: Addrstor.h
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support the INPUT_HARDWARE value in the type field of the INPUT structure referred to by the pInputs parameter.
