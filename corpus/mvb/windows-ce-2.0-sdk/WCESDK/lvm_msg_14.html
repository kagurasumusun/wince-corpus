LVM_GETIMAGELIST

The LVM_GETIMAGELIST message retrieves the handle of an image list used for drawing list view items. You can send this message explicitly or by using the ListView_GetImageList macro.

Syntax

LVM_GETIMAGELIST
wParam = (WPARAM)(int) iImageList;
lParam = 0;

Remarks

Windows CE supports a new value for the iImageList parameter (WPARAM). The LVSIL_HEADER constant specifies that the image list to be retireved is the image list displayed in the list view's header control in report view.
