ImmSetCandidateWindow

The ImmSetCandidateWindow function sets information about the candidate list window.

Syntax

BOOL ImmSetCandidateWindow(HIMC hIMC, LPCANDIDATEFORM lpCandidate);

At a Glance

Header file: Imm.h
Component: Immthunk
Platforms: H/PC (Japanese)
Windows CE versions: Japanese version 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

For Japanese version 1.0 and later, the ImmSetCandidateWindow function allows an index range of 0 to 4 for the dwIndex member of the CANDIDATEFORM structure.
