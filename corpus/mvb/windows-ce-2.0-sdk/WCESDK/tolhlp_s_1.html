HEAPLIST32

The HEAPLIST32 structure describes an entry from a list that enumerates the heaps used by a specified process.

Syntax

typedef struct tagHEAPLIST32 { 
    DWORD dwSize; 
    DWORD th32ProcessID; 
    DWORD th32HeapID; 
    DWORD dwFlags; 
} HEAPLIST32; 
typedef HEAPLIST32 *  PHEAPLIST32; 
typedef HEAPLIST32 *  LPHEAPLIST32;
