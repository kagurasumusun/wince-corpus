IOleObject::GetUserType

The IOleObject::GetUserType method retrieves the user-type name of an object for display in user-interface elements such as menus, list boxes, and dialog boxes.

Syntax

HRESULT GetUserType(
DWORD dwFormOfType,
LPOLESTR * pszUserType
);
