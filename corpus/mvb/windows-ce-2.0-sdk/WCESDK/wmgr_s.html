ACCEL

The ACCEL structure defines an accelerator key used in an accelerator table.

Syntax

typedef struct tagACCEL {
 BYTE fVirt;
WORD key;
WORD cmd;
WORD pad;
} ACCEL;

At a Glance

Header file:
Component:
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

This structure has an additional member, pad, that is reserved for Windows CE.
