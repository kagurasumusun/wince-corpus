PSM_SETCURSEL

The PSM_SETCURSEL message activates the given page in a property sheet.

Syntax

PSM_SETCURSEL
wParam = (WPARAM)(int) index;
lParam = (LPARAM)(HPROPSHEETPAGE) hpage;
