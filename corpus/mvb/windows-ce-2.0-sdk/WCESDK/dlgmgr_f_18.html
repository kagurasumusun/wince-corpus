GetNextDlgGroupItem

The GetNextDlgGroupItem function retrieves the handle to the first control in a group of controls that precedes or follows the specified control in a dialog box.

Syntax

HWND GetNextDlgGroupItem(HWND hDlg, HWND hCtl, BOOL bPrevious);
