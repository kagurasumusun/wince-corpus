TB_GETTEXTROWS

The TB_GETTEXTROWS message retrieves the maximum number of text rows that can be displayed on a toolbar button.

Syntax

TB_GETTEXTROWS
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Return Values

Returns an INT value representing the maximum number of text rows that the control will display for a button.
