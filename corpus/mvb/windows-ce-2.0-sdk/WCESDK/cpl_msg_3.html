CPL_INIT

The CPL_INIT message is sent to a Control Panel application to prompt it to perform global initialization, especially memory allocation.

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The return value is not checked by the control panel explorer.

In Windows CE 1.0 an error is recognized when the applet does not fill the NEWCPLINFO structure properly in response to the CPL_NEWINQUIRE message.
