WM_GETTEXTLENGTH

An application sends a WM_GETTEXTLENGTH message to determine the length, in characters, of the text associated with a window. The length does not include the terminating null character.

Syntax

WM_GETTEXTLENGTH
wParam = 0;
lParam = 0;
