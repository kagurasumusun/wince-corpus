LINE_CREATE

The LINE_CREATE message is sent to inform the application of the creation of a new line device.

Syntax

LINE_CREATE
dwDevice = (DWORD) 0;
dwCallbackInstance = (DWORD) 0;
dwParam1 = (DWORD) idDevice;
dwParam2 = (DWORD) 0;
dwParam3 = (DWORD) 0;
