EM_GETLINE

An application sends an EM_GETLINE message to copy a line of text from an edit control and place it in a specified buffer.

Syntax

EM_GETLINE
wParam = (WPARAM) line;
lParam = (LPARAM)(LPCSTR) lpch;

At a Glance

Component/Module: Edit control component
Platforms:
