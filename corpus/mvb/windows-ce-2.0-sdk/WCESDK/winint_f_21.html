InternetFindNextFile

The InternetFindNextFile function continues a file search from a previous call to FtpFindFirstFile

Syntax

INTERNETAPI BOOL WINAPI InternetFindNextFile(HINTERNET hFind, LPVOID lpvFindData);

At a Glance

Header file: Wininet.h
Module: Wininet
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The lpvFindData parameter must be a pointer to a WIN32_FIND_DATA structure.

This Windows CE Internet API supports the full features of the corresponding Win32 Internet function for an internet handle returned by FtpFindFirstFile.
