CEFILEINFO

The CEFILEINFO structure contains information about a file object.

Syntax

typedef struct _CEFILEINFO {
 DWORD dwAttributes;
CEOID oidParent;
WCHAR szFileName[MAX_PATH];
FILETIME ftLastChanged;
DWORD dwLength;
} CEFILEINFO;

At a Glance

Header file: Winbase.h
Component:
Platforms: H/PC
Windows CE versions: 1.01 and later

Members

dwAttributes
Attributes of the file.
oidParent
Object identifier of the parent directory.
szFileName
Null-terminated string that contains the name and path of the file.
ftLastChanged
Time stamp indicating when the contents of the file were last changed.
dwLength
Length, in bytes, of the file.

Remarks

When writing applications for Windows CE version 1.0, use the PEGFILEINFO structure.
