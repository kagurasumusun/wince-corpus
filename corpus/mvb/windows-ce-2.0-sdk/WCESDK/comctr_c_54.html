TabCtrl_HighlightItem

This macro sets the highlight state of a tab item.

Syntax

BOOL TabCtrl_HighlightItem(HWND hwndTab, INT idItem, WORD fHighlight);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related message: TCM_HIGHLIGHTITEM

Parameters

hwndTab
Handle to the tab control.
idItem
Zero-based index of a tab control item.
fHighlight
Value specifying the highlight state to be set. If this value is nonzero, the tab is highlighted. If this value is zero, the tab is set to its default state.

Return Values

Nonzero if successful, or zero otherwise.
