InflateRect

The InflateRect function increases or decreases the width and height of the specified rectangle. InflateRect adds dx units to the left and right ends of the rectangle and dy units to the top and bottom. The dx and dy parameters are signed values; positive values increase the width and height, and negative values decrease them.

Syntax

BOOL InflateRect(LPRECT lprc, int dx, int dy);
