IEnumVARIANT::Next

The IEnumVARIANT::Next method attempts to get the next celt items in the enumeration sequence, and return them through the array pointed to by rgVar.

unsigned long celt,
VARIANT FAR* rgVar,
unsigned long FAR* pCeltFetched
);
