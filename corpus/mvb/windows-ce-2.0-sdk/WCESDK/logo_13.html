Other Microsoft Logo Programs

Microsoft offers a number of logo programs, which all share a common goal: providing the end user with assurance that the product he or she is buying was designed to work well with Microsoft's industry-standard operating systems and applications. Purchasers of logo'd products can rest assured that the software they buy is compatible with their existing systems and leverages the functional skills and knowledge they already posses. It is possible for applications to bear more than one logo, and developers are encouraged to take advantage of the full array of marketing opportunities presented by these programs.

The Designed for Windows 95 Logo is for commercially marketed desktop applications which run primarily on Windows 95. This logo is a requirement for Microsoft Windows CE-based Desktop Companion Applications. For additional information, see http://www.microsoft.com/windows/thirdparty.htm, or send an email to winlogo@microsoft.com. VeriTest is the authorized site for this testing, www.veritest.com, logolab@veritest.com

The Designed for Windows NT and Windows 95 Logo is for commercially marketed desktop applications which run primarily on Windows NT Workstation and Windows 95. For additional information on the Designed for Windows NT and Windows 95 Logo program, see http://www.microsoft.com/windows/thirdparty.htm, or send an email to winlogo@microsoft.com. VeriTest is the authorized site for this testing, www.veritest.com, logolab@veritest.com
