WaitForSingleObject

The WaitForSingleObject function returns when the specified object is in the signaled state or when the time-out interval elapses.

Syntax

DWORD WaitForSingleObject(HANDLE hHandle, DWORD dwMilliseconds);

At a Glance

Header file: Winbase.h
Module: Nk
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not support waiting for semaphores, change notification objects, console input, and timers. Also, it does not support waiting for process, thread, and mutex events.

Waiting on an invalid handle causes WaitForSingleObject to return WAIT_FAILED.
