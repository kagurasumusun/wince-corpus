MSG

The MSG structure contains message information from a thread's message queue.

Syntax

typedef struct tagMSG { // msg
HWND hwnd;
UINT message;
WPARAM wParam;
LPARAM lParam;
DWORD time;
POINT pt;
} MSG;

Platforms: H/PC
Versions: 1.0 and later

Remarks

On Windows CE-based devices that use a stylus and touch screen instead of a mouse, the pt field contains the coordinates of the last position touched on the screen, rather than the coordinates of the current cursor position.

If you need mouse cursor suppport in your application, use the Windows CE Iconcurs component rather than the Windows CE Icon component and the Windows CE Mcursor component rather than the Windows CE Cursor component.
