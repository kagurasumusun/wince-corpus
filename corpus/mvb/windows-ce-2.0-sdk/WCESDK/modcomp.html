Windows CE Modules and Components

Because minimizing memory use is a major design goal, Windows CE is built from modules. You can control the size of the system software by selecting only the modules that you need. Several modules are also further divided into components. By selecting the minimum set of needed components, you can minimize the memory footprint of your Windows CE operating system software.

A module or a component supports a group of related API functions. All defined modules and components are listed here in alphabetical order.
