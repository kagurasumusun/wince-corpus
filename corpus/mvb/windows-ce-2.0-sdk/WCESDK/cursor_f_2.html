DestroyCursor

The DestroyCursor function destroys a cursor created by the CreateCursor function and frees any memory the cursor occupied. Don't use this function to destroy a cursor that was not created with the CreateCursor function.

Syntax

BOOL DestroyCursor( HCURSOR hCursor );
