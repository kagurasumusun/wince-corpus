SetCursor

The SetCursor function establishes the cursor shape.

Syntax

HCURSOR SetCursor(HCURSOR hcur);

At a Glance

Header file: Winuser.h
Component: Cursor
Mcursor
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Use the cursor component when targeting a platform that does not support mouse cursors. The only cursor this component supports is the wait cursor. Use the following code to set the wait cursor:

SetCursor(LoadCursor(NULL, IDC_WAIT));

Use the mcursor component when targeting a platform that does support mouse cursors. This component does not support color cursors.
