OBJUIDATA

The OBJUIDTA structure is used by IReplStore::GetObjTypeUIData to send UI related data about an object type to the Store.

Syntax

typedef struct tagObjUIData{
 UINT cbStruct;
HICON hIconLarge;
HICON hIconSmall;
char szName[ MAX_PATH ];
char szSyncText[ MAX_PATH ];
char szTypeText[ 80 ];
char szPlTypeText[ 80 ];
} OBJUIDATA, *POBJUIDATA;

At a Glance

Header file: cesync.h
Component:
Platforms: H/PC
Windows CE versions: 2.0 and later

Members

cbStruct
The size of this structure.
hIconLarge
The handle of a large icon used in the list view display of the H/PC Explorer.
hIconSmall
The handle of a small icon used in the list view display of the H/PC Explorer.
szName
Text displayed in the "Name" column of the H/PC Explorer.
szSyncText
Text displayed in the "Sync Copy In" column of the H/PC Explorer.
szTypeText
Text displayed in the "Type" column of the H/PC Explorer.
szPlTypeText
Plural form of text displayed in the "Type" column of the H/PC Explorer.
