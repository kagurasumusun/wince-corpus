NMLVCACHEHINT

The NMLVCACHEHINT structure contains information used to update the cached item information for use with a "virtual" list view.

Syntax

typedef struct tagNMLVCACHEHINT {
NMHDR hdr;
int iFrom;
int iTo;
} NMLVCACHEHINT, *PNMLVCACHEHINT;

At a Glance

Header file:
Component:
Platforms: H/PC
Versions: 2.0 and later

Members

hdr
NMHDR structure that contains information about this notification message.
iFrom
Starting index of the requested range of items. This value is inclusive.
iTo
Ending index of the requested range of items. This value is inclusive.
