WriteClassStm

The WriteClassStm function writes a CLSID to the specified stream object so it can be read by the ReadClassStm function. Most applications do not call WriteClassStm directly.

Syntax

WINOLEAPI WriteClassStm( IStream * pStm, REFCLSID rclsid);

At a Glance

Header file: Ole2.h
Component: Ole232
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Passing into this function any invalid and, under some circumstances, NULL pointers will result in unexpected termination of the application. For more information about handling exceptions, see COM and Automation.
