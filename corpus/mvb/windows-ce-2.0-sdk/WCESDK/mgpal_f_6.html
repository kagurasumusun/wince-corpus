RealizePalette

The RealizePalette function maps palette entries from the current logical palette to the system palette.

Syntax

UNIT RealizePalette(HDC hdc);

At a Glance

Header file: Wingdi.h
Component: mgpal
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE does not arbitrate between the palettes of the background and foreground applications. The foreground application has complete control of the system palette. Therefore, Windows CE does not perform any color matching operations for foreground applications; it simply overwrites the system palette entries with the hdc parameter's palette entries.

Windows CE does not support RealizePalette for background applications.

RealizePalette will fail if the device associated with hdc does not have a settable palette. Use GetDeviceCaps to find out if the device has a settable palette before using RealizePalette.
