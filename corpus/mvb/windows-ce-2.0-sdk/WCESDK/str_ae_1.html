CANDIDATEFORM

The CANDIDATEFORM structure contains position information for the candidate window.

Syntax

typedef _tagCANDIDATEFORM {
DWORD dwIndex;
DWORD dwStyle;
POINT ptCurrentPos;
RECT rcArea;
} CANDIDATEFORM;

Remarks

The ImmSetCandidateWindow function allows a range of 0 to 4 for the dwIndex member.
