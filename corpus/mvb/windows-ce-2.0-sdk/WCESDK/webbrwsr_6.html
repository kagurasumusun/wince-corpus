DWebBrowserEvents::NewWindow

The NewWindow method notifies an application that the Web browser control is about to create a new window for displaying a resource. The container application has an opportunity to handle the new window creation itself. If it doesn't, the Web browser control creates a top-level Internet Explorer window as a separate process.

Syntax

void NewWindow (
BSTR URL,
long Flags,
BSTR TargetFrameName,
VARIANT FAR* PostData,
BSTR Headers,
VARIANT_BOOL FAR* Processed
);
