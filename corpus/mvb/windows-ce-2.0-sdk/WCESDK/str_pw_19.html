RASENTRYNAME

The RASENTRYNAME structure contains an entry name from a remote access phonebook. The RasEnumEntries function returns an array of these structures.

Syntax

typedef struct _RASENTRYNAME {
 DWORD dwSize;
TCHAR szEntryName[RAS_MaxEntryName + 1];
}RASENTRYNAME;
