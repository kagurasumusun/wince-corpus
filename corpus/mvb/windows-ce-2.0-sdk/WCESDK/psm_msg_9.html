PSM_GETCURRENTPAGEHWND

The PSM_GETCURRENTPAGEHWND message retrieves a handle to the window of the current page of a property sheet.

Syntax

PSM_GETCURRENTPAGEHWND
wParam = 0;
lParam = 0;
