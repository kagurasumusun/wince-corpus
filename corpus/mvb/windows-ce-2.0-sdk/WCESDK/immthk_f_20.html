ImmSimulateHotKey

The ImmSimulateHotKey function simulates the specified IME hot key, causing the same response as if the user had pressed the hot key in the specified window.

Syntax

BOOL ImmSimulateHotKey(HWND hWnd, DWORD dwHotKeyID);

At a Glance

Header file: Imm.h
Component: Immthunk
Platforms: H/PC (Japanese)
Windows CE versions: Japanese version 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE supports the following value for the dwHotKeyID parameter:

IME_JHOTKEY_CLOSE_OPEN
(Japanese) Alternately opens and closes the IME.
