MessageBeep

The MessageBeep function plays a waveform sound.

Syntax

BOOL MessageBeep(UINT uType);

At a Glance

Header file: Winuser.h
Component: msgbeep
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Passing 0xFFFFFFFF will cause the SystemDefault waveform to be played.
