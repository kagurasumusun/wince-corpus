NM_CONTEXTMENU

The NM_CONTEXTMENU notification message is sent by the HTML viewer control when a user ALT+Taps in the viewer window.

Syntax

NM_CONTEXTMENU
NM_HTMLCONTEXT *pnmHtmlContext =
(NM_HTMLCONTEXT*)lParam;

At a Glance

Header file: Htmlctrl.h
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

pnmHtmlContext
Pointer to an NM_HTMLCONTEXT structure that contains information about the NM_CONTEXTMENU notification message.

Return Values

This notification message does not return a value.
