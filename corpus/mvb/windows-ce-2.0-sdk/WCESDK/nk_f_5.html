CreateMutex

The CreateMutex function creates a named or unnamed mutex object.

Syntax

HANDLE CreateMutex LPSECURITY_ATTRIBUTES lpMutexAttributes, BOOL bInitialOwner, LPCTSTR lpName );

At a Glance

Header file: Winbase.h
Module: Nk
Platforms: H/PC
Windows CE versions: 1.01 and later
Complete documentation: Microsoft Platform SDK

Remarks

The lpMutexAttributes parameter must be set to NULL.
