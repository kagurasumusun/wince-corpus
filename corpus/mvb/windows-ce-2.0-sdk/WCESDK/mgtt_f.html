AddFontResource

The AddFontResource function adds the font resource from the specified file to the Windows font table. The font can subsequently be used for text output by any Windows-based application.

Syntax

int AddFontResource(LPCTSTR lpszFilename);

At a Glance

Header file: Wingdi.h
Component: mgrast
mgtt
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE version 1.0 supports only raster fonts.

Windows CE version 2.0 supports systems that use either TrueType or raster fonts but not both. The font type (raster or TrueType) is chosen at system design time, and cannot be changed by an application.
