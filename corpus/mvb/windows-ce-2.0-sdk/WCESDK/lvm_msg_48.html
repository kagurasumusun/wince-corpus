LVM_SETTEXTCOLOR

The LVM_SETTEXTCOLOR message sets the text color of a list view control. You can send this message explicitly or by using the ListView_SetTextColor macro.

Syntax

LVM_SETTEXTCOLOR
wParam = 0;
lParam = (LPARAM)(COLORREF) clrText;
