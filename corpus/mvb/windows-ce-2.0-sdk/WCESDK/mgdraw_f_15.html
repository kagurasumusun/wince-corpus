RoundRect

The RoundRect function draws a rectangle with rounded corners. The current brush outlines the rectangle and the current brush fills it.

Syntax

BOOL RoundRect(HDC hdc, int nLeftRect, int nTopRect, int nRightRect, int nBottomRect, int nWidth, int nHeight);
