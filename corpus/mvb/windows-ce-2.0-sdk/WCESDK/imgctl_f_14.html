ImageList_GetIcon

The ImageList_GetIcon function creates an icon based on an image and mask in an image list.

Syntax

HICON WINAPI ImageList_GetIcon(HIMAGELIST himl, int iImage, UINT fStyle);

At a Glance

Header file: Commctrl.h
Component: Imgctl
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

You can only use the ImageList_GetIcon function to create an icon, not a cursor.
