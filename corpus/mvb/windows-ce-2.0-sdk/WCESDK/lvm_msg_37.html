LVM_SETCALLBACKMASK

The LVM_SETCALLBACKMASK message sets the callback mask for a list view control. You can send this message explicitly or by using the ListView_SetCallbackMask macro.

Syntax

LVM_SETCALLBACKMASK
wParam = (WPARAM)(UINT) mask;
lParam = 0;
