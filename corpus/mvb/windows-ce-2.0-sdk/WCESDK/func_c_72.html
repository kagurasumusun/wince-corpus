CeRegQueryInfoKey

The CeRegQueryInfoKey function retrieves information about a specified registry key. This is the RAPI version of the RegQueryInfoKey function.

Syntax

LONG CeRegQueryInfoKey (HKEY hKey, LPWSTR lpszClass, LPDWORD lpcchClass, LPDWORD lpReserved, LPDWORD lpcSubKeys, LPDWORD lpcchMaxSubKeyLen, LPDWORD lpcchMaxClassLen, LPDWORD lpcValues, LPDWORD lpcchMaxValueNameLen, LPDWORD lpcbMaxValueData, LPDWORD lpcbSecurityDescriptor, PFILETIME lpftLastWriteTime);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegRegQueryInfoKey function.

For more information about using RAPI functions, see Remote API Functions.
