SHGetMalloc

The SHGetMalloc function retrieves a pointer to the shell's IMalloc interface. A shell extension must use this interface to allocate memory that is later freed by the shell.

Syntax

HRESULT SHGetMalloc(LPMALLOC *ppMalloc);

At a Glance

Header file: Shellapi.h
Platforms: H/PC
Versions: 2.0 and later
Complete documentation: Microsoft Platform SDK
