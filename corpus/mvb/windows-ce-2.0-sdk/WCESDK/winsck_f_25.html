socket

TheWindows Sockets socket function creates a socket. For IrSockets implementation, Af_irda.h must be explicitly included.

Syntax

SOCKET socket (int af, int type, int protocol);

At a Glance

Header file: Winsock.h
Module: Winsock
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE supports the PF_INET and AF_IRDA ARPA Internet address formats.

To use IrSock, set the af parameter to AF_IRDA and set the protocol parameter to NULL.

Windows CE supports SOCK_STREAM and SOCK_DCRAM socket types.
