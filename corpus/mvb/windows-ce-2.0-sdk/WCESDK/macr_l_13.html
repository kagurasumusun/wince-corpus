ListView_GetEditControl

The ListView_GetEditControl macro retrieves the handle to the edit control being used to edit a list view item's text. You can use this macro or explicitly send the LVM_GETEDITCONTROL message.

Syntax

HWND ListView_GetEditControl(
 HWND hwnd
);
