CoGetClassObject

The CoGetClassObject function provides a pointer to an interface on a class object associated with a specified CLSID. Call CoGetClassObject directly when you want to create multiple objects through a class object whose CLSID is already in the system registry. Most class objects implement the IClassFactory interface. You would then call IClassFactory::CreateInstance to create an uninitialized object. To create a single object on a local machine, use the CoCreateInstance function.

Syntax

STDAPI CoGetClassObject(REFCLSID rclsid, WORD dwClsContext, COSERVERINFO * pServerInfo, REFIID riid, LPVOID * ppv);

At a Glance

Header file: Objbase.h
Component: Com
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE supports only the CLSCTX_INPROC_SERVER value for the dwClsContext parameter. For any other values, the function returns E_NOTIMPL. Since no remote server is allowed, pServerInfo must point to null.

Passing into this function any invalid and, under some circumstances, NULL pointers will result in unexpected termination of the application. For more information about handling exceptions, see COM and Automation.
