LV_DISPINFO

The LV_DISPINFO structure contains information needed to display an owner-drawn item in a list view control.

Syntax

typedef struct tagLV_DISPINFO {
 NMHDR hdr;
LV_ITEM item;
} LV_DISPINFO;
