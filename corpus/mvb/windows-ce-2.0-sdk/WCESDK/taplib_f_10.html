lineNegotiateAPIVersion

The lineNegotiateAPIVersion function allows an application to negotiate an API version to use.

Syntax

LONG lineNegotiateAPIVersion(HLINEAPP hLineApp, DWORD dwDeviceID, DWORD dwAPILowVersion, DWORD dwAPIHighVersion, LPDWORD lpdwAPIVersion, LPLINEEXTENSIONID lpExtensionID);

At a Glance

Header file: Tapi.h
Component: tapilib
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The lpExtensionID parameter is ignored. Windows CE does not support provider-specific extensions.
