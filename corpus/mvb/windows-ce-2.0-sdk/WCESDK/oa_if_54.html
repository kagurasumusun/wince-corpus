IPersistStorage::Save

The IPersistStorage::Save method saves an object and any nested objects that it contains into the specified storage. The object is placed in NoScribble mode and must not write to the specified storage until it receives a call to its IPersistStorage:SaveCompleted method.

Syntax

HRESULT Save(
IStorage * pStgSave,
BOOL fSameAsLoad
);
