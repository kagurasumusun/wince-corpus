BITMAPCOREINFO

The BITMAPCOREINFO structure defines the dimensions and color information for a device-independent bitmap (DIB).

Syntax

typedef struct _BITMAPCOREINFO { // bmci
BITMAPCOREHEADER bmciHeader;
RGBTRIPLE bmciColors[1];
} BITMAPCOREINFO;

At a Glance

Header file: Wingdi.h
Component: mgbase
Platforms: H/PC
Versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE, the bcBitCount member of BITMAPCOREHEADER may be set to 2, or to any of the values permitted in in Windows desktop platforms. A bcBitcount value of 2 allows a bitmap a maximum of 4 colors.
