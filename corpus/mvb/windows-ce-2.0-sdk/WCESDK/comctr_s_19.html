LVFINDINFO

The LVFINDINFO structure that contains information used to search for a list view item.

Syntax

typedef struct tagLVFINDINFO
{
UINT flags;
LPCTSTR psz;
LPARAM lParam;
POINT pt;
UINT vkDirection;
} LVFINDINFO, FAR* LPFINDINFO;

At a Glance

Header file:
Component:
Platforms: H/PC
Versions: 2.0 and later

Members

flags
Specifies the type of search to perform. This can be one or more of the following values:
LVFI_PARAM
Searches based on the lParam member. The lParam member of the matching item's LVITEM structure must match the lParam member of this structure. If this value is specified, all other values are ignored.
LVFI_PARTIAL
Matches if the item text begins with the string pointed to by the psz member. This value implies use of LVFI_STRING.
LVFI_STRING
Searches based on the item text. Unless additional values are specified, the item text of the matching item must exactly match the string pointed to by the psz member.
LVFI_WRAP
Continues the search at the beginning if no match is found.
LVFI_NEARESTXY
Finds the item nearest to the position specified in the pt member, in the direction specified by the vkDirection member.

psz
Address of a null-terminated string to compare with the item text if flags specifies LVFI_STRING or LVFI_PARTIAL.
lParam
Value to compare with the lParam member of a list view item's LVITEM structure if the flags member specifies LVFI_PARAM.
pt
A POINT structure that specifies the starting position to search from. This member is used only if LVFI_NEARESTXY is specified in the flags member.
vkDirection
Specified the direction to search in by containing the virtual-key code of an arrow key that specified the direction to search in. This member is used only if LVFI_NEARESTXY is specified in the flags member.

Remarks

This structure supersedes the LV_FINDINFO structure.
