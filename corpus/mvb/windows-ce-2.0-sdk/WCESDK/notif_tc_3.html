TCN_KEYDOWN

The TCN_KEYDOWN notification message notifies a tab control's parent window that a key has been pressed. This message is sent in the form of a WM_NOTIFY message.

Syntax

TCN_KEYDOWN
pnm = (TC_KEYDOWN FAR *) lParam;
