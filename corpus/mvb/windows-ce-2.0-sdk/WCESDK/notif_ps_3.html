PSN_QUERYCANCEL

The PSN_QUERYCANCEL notification message indicates that the user chose the Cancel button. This notification message is sent in the form of a WM_NOTIFY message.

Syntax

PSN_QUERYCANCEL
lpnmhdr = (NMHDR FAR *) lParam;
