WM_SETFONT

An application sends a WM_SETFONT message to specify the font that a control is to use when drawing text.

Syntax

WM_SETFONT
wParam = (WPARAM) hfont;
lParam = MAKELPARAM(fRedraw,0);

At a Glance

Header file: Winuser.h
Component/Module: Window management component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Dialogs do not support DS_SETFONT. Applications can set the font for their controls manually.
