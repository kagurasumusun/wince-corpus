DWebBrowserEvents::TitleChange

The TitleChange method notifies an application that the title of a document in the Web browser control either becomes available or changes. While an HTML document is downloading, the URL of the document is set as the title. After the document's actual title, if it has one, is parsed from the HTML, the title is changed to that title.

Syntax

void TitleChange (
BSTR Text
);
