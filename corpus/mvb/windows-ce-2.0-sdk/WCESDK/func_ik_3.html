ImageList_ExtractIcon

The ImageList_ExtractIcon function creates an icon based on an image and mask in an image list. This function calls the ImageList_GetIcon function.

Syntax

HICON WINAPI ImageList_ExtractIcon(HINSTANCE hInst, HIMAGELIST himl, int iImage);

At a Glance

Header file: Commctrl.h
Component: imgctl
Platforms: H/PC
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

In Windows CE, you can only use the ImageList_ExtractIcon function to create an icon, not a cursor.

ImageList_ExtractIcon is not supported for emulation.
