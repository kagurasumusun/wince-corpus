LB_SELITEMRANGEEX

An application sends an LB_SELITEMRANGEEX message to select one or more consecutive items in a multiple-selection list box.

Syntax

LB_SELITEMRANGEEX
wParam = (WPARAM) wFirst;
lParam = (LPARAM) wLast);
