CreateDC

The CreateDC function creates a device context (DC) for a device.

Syntax

HDC CreateDC( LPCTSTR lpszDriver, LPCTSTR lpszDevice, LPCTSTR lpszOutput, CONST DEVMODE * lpInitData);

At a Glance

Header file: Wingdi.h
Component: mgdc
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

If no driver name is given for the lpszDriver parameter, Windows CE returns a screen DC.

Windows CE ignores the lpszDevice parameter.

Windows CE passes the lpInitData and lpszOutput parameters to the driver without modification.
