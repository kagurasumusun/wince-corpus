MAKEWPARAM

The MAKEWPARAM macro creates an unsigned 32-bit value for use as a wParam parameter in a message. The macro concatenates two given 16-bit values.

Syntax

LPARAM MAKEWPARAM(
 WORD wLow,
WORD wHigh
);
