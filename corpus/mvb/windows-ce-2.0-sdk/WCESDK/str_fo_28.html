NEWCPLINFO

The NEWCPLINFO structure contains resource information and a user-defined value for a dialog box supported by a Control Panel application.

Syntax

typedef struct tagNEWCPLINFO { // ncpli
DWORD dwSize;
DWORD dwFlags;
DWORD dwHelpContext;
LONG lData;
HICON hIcon;
TCHAR szName[32];
TCHAR szInfo[64];
TCHAR szHelpFile[128];
} NEWCPLINFO;

Remarks

The dwHelpCOntext and szHelpSize members are not used by the H/PC 1.0 control panel explorer.

For ldata, applications should return the icon resource ID for the control panel (same as hIcon, but the resource ID instead of the icon handle.)
