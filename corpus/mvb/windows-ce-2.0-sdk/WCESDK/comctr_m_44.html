LVN_ODFINDITEM

The LVN_ODFINDITEM notification message is sent by a virtual list view control when it needs the owner to find a particular callback item. For example, the control will send this notification when the it receives shortcut keyboard input, or when it receives an LVM_FINDITEM message.

Syntax

LVN_ODFINDITEM
pFindInfo = (PNMLVFINDITEM) lParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

pFindInfo
Address of an NMLVFINDITEM structure that includes information to be used for the search.

Return Values

Return the index of the item found, or -1 if no item is found.

Remarks

Search information is sent in the form of an LVFINDINFO structure, which is a member of the NMLVFINDITEM structure.
