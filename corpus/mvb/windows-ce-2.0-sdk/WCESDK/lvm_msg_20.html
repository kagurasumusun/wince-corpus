LVM_GETITEMSPACING

The LVM_GETITEMSPACING message determines the spacing between items in a list view control. You can send this message explicitly or by using the ListView_GetItemSpacing macro.

Syntax

LVM_GETITEMSPACING
wParam = (WPARAM)(BOOL) fSmall;
lParam = 0;
