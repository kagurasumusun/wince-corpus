RegQueryInfoKey

The RegQueryInfoKey function retrieves information about a specified registry key.

Syntax

LONG RegQueryInfoKey (HKEY hKey, LPWSTR lpszClass, LPDWORD lpcchClass, LPDWORD lpReserved, LPDWORD lpcSubKeys, LPDWORD lpcchMaxSubKeyLen, LPDWORD lpcchMaxClassLen, LPDWORD lpcValues, LPDWORD lpcchMaxValueNameLen, LPDWORD lpcbMaxValueData, LPDWORD lpcbSecurityDescriptor, PFILETIME lpftLastWriteTime);

At a Glance

Header file: Winreg.h
Component: Fsreg
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The lpcbMaxValueData and lpcbSecurityDescriptor parameters are not used and must be set to NULL.
