LVM_SUBITEMHITTEST

The LVM_SUBITEMHITTEST message determines which list view item or subitem is at a given position.

Syntax

LVM_SUBITEMHITTEST
wParam = 0;
lParam = (LPARAM)(LVHITTESTINFO FAR *)pInfo;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: ListView_SubItemHitTest

Parameters

pInfo
Address of an LVHITTESTINFO structure. The POINT structure within LVHITTESTINFO should be set to the client coordinates to be hit-tested.

Return Values

Returns the index of the item or subitem tested, if any, or -1 otherwise. If an item or subitem is at the given coordinates, the fields of the LVHITTESTINFO structure will be filled with the applicable hit information.
