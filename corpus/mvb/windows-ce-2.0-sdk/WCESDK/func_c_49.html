CeGetFileSize

The CeGetFileSize function retrieves the size, in bytes, of the specified file. This is the RAPI version of the GetFileSize function.

Syntax

DWORD CeGetFileSize(HANDLE hFile, LPDWORD lpFileSizeHigh);

At a Glance

Header file: Rapi.h
Platforms: H/PC
Windows CE versions: 2.0 and later

Remarks

When writing applications for Windows CE versions 1.0 and 1.01, use the PegGetFileSize function.

For more information about using RAPI functions, see Remote API Functions.
