Introduction to the Windows CE Reference

The Windows CE Reference contains documentation for all interfaces, functions, structures, messages, and other API elements for the following released versions of Windows CE:

  • Windows CE version 1.0

  • Windows CE version 1.01

  • Windows CE version 2.0

    Unless otherwise noted, all documented API elements are present in version 2.0.

Each reference topic includes an At a Glance table containing the following information.

At a Glance

Header file: Header file where the API element is defined.
Component: Windows CE component that includes this API element.
Platforms: Targeted platforms.
Windows CE versions: Windows CE versions that include this API element.
Complete documentation: Link to the complete documentation as originally published. Usually, this is a link to the Microsoft Platform SDK documentation.

When there is a link to original documentation, comments in the Remarks section are specific to Windows CE.
