32-Bit Requirement

Required: 32-Bitness. A Microsoft Windows CE-based Application must be a Win32® programming interface executable, compiled with a 32-bit compiler and using the Microsoft Windows CE SDK via license from Microsoft or any other authorized distributor. Or if your application is not represented in exe format [interpreted code, for example], then the "runtime engine" must be a Win32-based executable built using the Microsoft Windows CE SDK. [e.g., if you develop an application in Microsoft Access, your application is an .mdb file, not an .exe, but paccess.exe would need to be a Win32-based executable]

Required: Desktop Companion Applications Must Earn the "Designed for Windows 95" logo. This requires a separate test and fee at VeriTest. Details are available at www.veritest.com or www.microsoft.com/windows/thirdparty.htm.
