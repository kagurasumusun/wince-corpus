DTM_GETMONTHCAL

The DTM_GETMONTHCAL message retrieves the handle to a date and time picker's (DTP) child month calendar control.

Syntax

DTM_GETMONTHCAL
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: DateTime_GetMonthCal

Return Values

Returns the handle to a DTP control's child month calendar control upon success. The message returns NULL upon failure.

Remarks

DTP controls create a child month calendar control when the user clicks the drop-down arrow. When the month calendar is no longer needed, it is destroyed. Therefore, your application must not rely on a static handle to the DTP control's child month calendar.
