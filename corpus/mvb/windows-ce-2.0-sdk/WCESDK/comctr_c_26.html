ListView_SetExtendedListViewStyle

Macro that sets extended styles for list view controls.

Syntax

void ListView_SetExtendedListViewStyle(HWND hwndLV, DWORD dwExStyle);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related message: LVM_SETEXTENDEDLISTVIEWSTYLE

Parameters

hwndLV
Handle to the list view control that will receive the style change.
dwExStyle
Value specifying the extended list view control style. This parameter can be a combination of extended styles.
