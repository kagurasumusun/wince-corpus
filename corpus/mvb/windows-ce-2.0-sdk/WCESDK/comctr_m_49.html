MCM_GETFIRSTDAYOFWEEK

The MCM_GETFIRSTDAYOFWEEK message retrieves the first day of the week for a month calendar control.

Syntax

MCM_GETFIRSTDAYOFWEEK
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: MonthCal_GetFirstDayOfWeek

Return Values

Returns a DWORD value that contains two values. The high word is a BOOL that is nonzero if the first day of the week is set to something other than LOCALE_IFIRSTDAYOFWEEK, or zero otherwise. The low word is an INT value that represents the first day of the week. The low word will be one of the following values.

Value Day of Week
0 Sunday
1 Monday
2 Tuesday
3 Wednesday
4 Thursday
5 Friday
6 Saturday
