HDN_ITEMCHANGING

The HDN_ITEMCHANGING notification message notifies a header control's parent window that the attributes of a header item are about to change. This notification message is sent in the form of a WM_NOTIFY message.

Syntax

HDN_ITEMCHANGING
phdr = (HD_NOTIFY FAR *) lParam;
