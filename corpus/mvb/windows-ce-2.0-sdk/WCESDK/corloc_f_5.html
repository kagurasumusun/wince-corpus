CharUpperBuff

The CharUpperBuff function converts lowercase characters in a buffer to uppercase characters. The function converts the characters in place.

Syntax

DWORD CharUpperBuff(LPTSTR lpsz, DWORD cchLength);

At a Glance

Header file: Winbase.h
Component: coreloc
Platforms: H/PC
Windows CE versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

Windows CE supports only the Unicode version of this function.
