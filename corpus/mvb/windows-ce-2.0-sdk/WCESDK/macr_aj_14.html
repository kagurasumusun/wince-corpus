InsetRect

The InsetRect macro calls the InflateRect function, passing in the negative value of the given x and y coordinates.

Syntax

BOOL InsetRect(
 LPRECT lprc,
 int dx,
 int dy
);

At a Glance

Header file: Winuser.h
Module/Component:
Platforms:
Versions: 1.0 and later

Parameters

lprc
Pointer to the RECT structure that increases or decreases in size.
dx
Amount to increase or decrease the rectangle width. This parameter must be negative to increase the width.
dy
Amount to increase or decrease the rectangle height. This parameter must be negative to increase the height.

Return Values

If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE. To get extended error information, call GetLastError.
