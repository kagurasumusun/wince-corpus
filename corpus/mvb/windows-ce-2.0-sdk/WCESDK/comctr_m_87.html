RB_GETTEXTCOLOR

The RB_GETTEXTCOLOR message retrieves a rebar control's default text color.

Syntax

RB_GETTEXTCOLOR
wParam = 0;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Return Values

Returns a COLORREF value that represent the current default text color.
