UDM_GETRANGE32

The UDM_GETRANGE32 message retrieves the 32-bit range of an Up-Down control.

Syntax

UDM_GETRANGE32
wParam = (WPARAM)(LPINT) pLow;
lParam = (LPARAM)(LPINT) pHigh;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

pLow
Address of an integer that receives the lower limit of the Up-Down control range. This parameter may be NULL.
pHigh
Address of an integer that receives the upper limit of the Up-Down control range. This parameter may be NULL.

Return Values

The return value for this message is not used.
