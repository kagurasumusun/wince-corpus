ImageList_DrawEx

The ImageList_DrawEx function draws an image list item in the given device context (DC). ImageList_DrawEx uses the specified drawing style and blends the image with the specified color.

Syntax

BOOL WINAPI ImageList_DrawEx(HIMAGELIST himl, int iDraw, HDC hdcDst, int x, int y, int cx, int cy, COLORREF rgbBk, COLORREF rgbFg, UINT fStyle);
