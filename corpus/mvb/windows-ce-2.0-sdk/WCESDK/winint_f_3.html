FtpFindFirstFile

The FtpFindFirstFile function searches the specified directory of the given FTP session.

Syntax

INTERNETAPI BOOL WINAPI FtpFindFirstFile(HINTERNET hFtpConnect, LPCTSTR lpszSearchFile , LPWIN32_FIND_DATA lpFindFileData , DWORD dwFlags, DWORD dwContext);

At a Glance

Header file: Wininet.h
Module: Wininet
Platforms: H/PC
Windows CE versions: 2.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The dwContext parameter allows for progress status callbacks to the application, but all requests will be handled synchronously.
