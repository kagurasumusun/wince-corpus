LB_INITSTORAGE

The LB_INITSTORAGE message allocates memory for storing list box items. An application sends this message before adding a large number of items to a list box.

Syntax

LB_INITSTORAGE
wParam = (WPARAM)(int) cItems;
lParam = (LPARAM)(DWORD) cb;

At a Glance

Header file: Winuser.h
Component/Module: List box component
Platforms:
Versions: 1.0 and later
Complete documentation: Microsoft Platform SDK

Remarks

The lParam parameter is unused in Windows CE.
