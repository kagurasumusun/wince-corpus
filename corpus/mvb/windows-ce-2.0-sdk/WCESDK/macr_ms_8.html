MapWindowRect

This macro calls the function MapWindowPoints.

Syntax

MapWindowRect(
 HWND hwndFrom,
HWND hwndTo,
LPRECT lprc
);

At a Glance

Header file: Windowsx.h
Module/Component:
Platforms:
Versions: 1.0 and later

Parameters

hwndFrom
Handle to the source window.
hwndto
Handle to the target window.
lprc
Pointer to the rectangle to be mapped. During input, this rectangle is relative to the source window. During output, it is relative to the target window.
