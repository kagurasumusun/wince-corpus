RBN_AUTOSIZE

The RBN_AUTOSIZE message is sent by a rebar control created with the RBS_AUTOSIZE style when the rebar automatically resizes itself. This notification message is sent in the form of a WM_NOTIFY message.

Syntax

RBN_AUTOSIZE
lpnmas = (LPNMRBAUTOSIZE) lParam;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

lpnmas
Address of a NMRBAUTOSIZE structure that contains information about the resize operation.

Return Values

The return value for this notification is not used.
