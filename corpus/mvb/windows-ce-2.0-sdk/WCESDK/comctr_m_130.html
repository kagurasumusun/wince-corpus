TB_SETMAXTEXTROWS

The TB_SETMAXTEXTROWS message sets the maximum number of text rows displayed on a toolbar button.

Syntax

TB_SETMAXTEXTROWS
wParam = (WPARAM)(INT) iMaxRows;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later

Parameters

iMaxRows
Maximum number of rows that will be set.

Return Values

Returns nonzero if successful or zero otherwise.
