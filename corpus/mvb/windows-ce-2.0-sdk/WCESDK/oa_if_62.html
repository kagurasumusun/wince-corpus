IStorage::CreateStream

The IStorage::CreateStream method creates and opens a stream object with the specified name contained in this storage object. All elements within a storage object, both streams and other storage objects, are kept in the same name space.

Syntax

HRESULT CreateStream(
const WCHAR * pwcsName,
DWORD grfmode,
DWORD reserved1,
DWORD * reserved2,
IStream * ppstm,
);
