Header_GetItemRect

This macro retrieves the bounding rectangle for a given item in a header control.

Syntax

BOOL Header_GetItemRect(HWND hwndHD, int iIndex, LPRECT lpItemRect);

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related message: HDM_GETITEMRECT

Parameters

hwndHD
Handle to a header control.
iIndex
Zero-based index of the header control item for which to retrieve the bounding rectangle.
lpItemRect
Address of a RECT structure that receives the bounding rectangle information.

Return Values

Returns nonzero if successful, or zero otherwise.
