TCM_DESELECTALL

The TCM_DESELECTALL message resets items in a tab control, clearing any that were set to the TCIS_BUTTONPRESSED state.

Syntax

TCM_DESELECTALL
wParam = (WPARAM) (DWORD) fExcludeFocus;
lParam = 0;

At a Glance

Header file:
Component/Module:
Platforms:
Versions: 2.0 and later
Related macro: TabCtrl_DeselectAll

Parameters

fExcludeFocus
Flag that specifies the scope of the item deselection. If this parameter is set to FALSE, all tab buttons will be reset. If it is set to TRUE, then all tab items except for the one currently selected will be reset.

Return Values

The return value for this message is not used.
