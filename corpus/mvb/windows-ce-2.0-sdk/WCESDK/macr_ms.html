MAKEINTRESOURCE

The MAKEINTRESOURCE macro converts an integer value to a resource type compatible with Windows resource-management functions. This macro is used in place of a string containing the name of the resource.

Syntax

LPTSTR MAKEINTRESOURCE(
 WORD wInteger;
);
