PSHNOTIFY

The PSHNOTIFY structure contains information for the PSN_APPLY and PSN_RESET notification messages.

Syntax

typedef struct _PSHNOTIFY {
NMHDR hdr;
LPARAM lParam;
} PSHNOTIFY, FAR *LPPSHNOTIFY;
