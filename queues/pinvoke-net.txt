# PInvoke.net Windows CE relevant pages
#
# PInvoke.net is a wiki-style site that documents P/Invoke signatures for
# calling Win32 API from .NET. The site covers both desktop Windows and
# Windows CE APIs.
#
# This queue focuses on modules that are available in Windows CE:
# - coredll: CE's combined kernel32/user32/gdi32 equivalent
# - rapi: Remote API for desktop-to-CE communication
# - Common Win32 APIs that CE supports: advapi32, comctl32, crypt32, etc.
#
# The queue includes:
# - Function signatures (DllImport declarations)
# - Constants (error codes, message IDs, flags)
# - Structures (data types used by APIs)
# - Enums (enumerations)
#
# URL patterns:
# - Module index: http://www.pinvoke.net/default.aspx/{module}
# - Function page: http://www.pinvoke.net/default.aspx/{module}/{function}
# - Constants: http://www.pinvoke.net/default.aspx/Constants/{constant}
# - Structures: http://www.pinvoke.net/default.aspx/Structures/{structure}
# - Enums: http://www.pinvoke.net/default.aspx/Enums/{enum}
