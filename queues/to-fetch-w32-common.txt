# Win32-common reference pages to collect from msdn / mslearn / ms-wayback.
#
# The CE books document the shared Win32 surface by name and meaning, but
# the pages that print the *bodies* (the typedef lines, the header
# statements) are the Win32-common reference pages of the desktop library.
# One of them is already in the corpus from the pinned GitHub snapshot
# (corpus/win32/common/windows-data-types.md, tools/fetch-upstream.py
# common); this queue collects the same shared-surface material as it
# appeared on msdn.microsoft.com / learn.microsoft.com and in the Wayback
# Machine, so the archive copies can be compared and version differences
# read from the sources themselves.
#
# Format: one URL per line (see queues/README.md).  Run via
# tools/harvest.py --queue queues/to-fetch-w32-common.txt (the GitHub
# runner has the network route; the sandbox does not).
#
# Scope rule (data/win32-common-pages.tsv): only pages that document the
# SHARED base surface -- types, their declarations, type constants and
# generic-text mappings, and the style/flag constant tables of the
# shared API surface (window/control styles, hook codes, clipboard and
# menu flags).  Never a desktop-only feature area.
